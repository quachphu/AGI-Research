To solve this problem, we need to determine the minimum total energy required to remove all parts of a toy, where each part has a value and is connected by ropes. The energy cost to remove a part is the sum of the values of its adjacent parts that have not yet been removed. The goal is to find the optimal order of removal to minimize this total energy.

### Approach
The key insight is that the optimal strategy involves removing parts in such a way that each rope (edge) between two parts contributes the minimum value of the two connected parts to the total energy. This is achieved by always removing the part with the higher value first. When a part with a higher value is removed, it only contributes the value of the lower part (if still present), thus minimizing the energy cost for that edge. Summing these minimum values for all edges gives the minimum total energy required.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    m = int(input[idx])
    idx += 1
    v = list(map(int, input[idx:idx+n]))
    idx += n
    total = 0
    for _ in range(m):
        x = int(input[idx]) - 1
        idx += 1
        y = int(input[idx]) - 1
        idx += 1
        total += min(v[x], v[y])
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The input is read in one go for efficiency, especially given the constraints. The first line contains the number of parts (n) and ropes (m). The second line contains the values of each part. The subsequent lines describe the ropes connecting the parts.
2. **Calculating Minimum Energy:** For each rope connecting two parts, the minimum value of the two parts is added to the total energy. This is because removing the part with the higher value first ensures that the lower value is only counted once.
3. **Output the Result:** The sum of these minimum values for all edges is printed as the result.

This approach efficiently computes the minimum energy by leveraging the properties of graph edges and their values, ensuring an optimal solution in O(m) time complexity, where m is the number of edges.
