To solve this problem, we need to determine the number of valid subsets of sardines such that no two sardines in a subset are on bad terms. Sardines are on bad terms if their vectors are perpendicular. The solution involves grouping vectors into normalized directions and handling each group's contribution to the total count of valid subsets.

### Approach
1. **Separate Zero Vectors**: Zero vectors can only be chosen alone. Each zero vector contributes 1 to the total count.
2. **Normalize Non-Zero Vectors**: Each non-zero vector is normalized to a canonical form to handle directions and their perpendicular counterparts efficiently.
3. **Group by Directions**: Non-zero vectors are grouped by their normalized directions. Each direction and its perpendicular direction form a pair.
4. **Calculate Contributions**: For each pair of directions, the number of valid subsets is calculated. If a direction has no perpendicular counterpart, it is handled individually.

### Solution Code

import math
from collections import defaultdict

MOD = 10**9 + 7

def normalize(a, b):
    if a == 0 and b == 0:
        return (0, 0)
    g = math.gcd(abs(a), abs(b))
    dx = a // g
    dy = b // g
    if dx != 0:
        if dx < 0:
            dx = -dx
            dy = -dy
    else:
        if dy < 0:
            dy = -dy
    return (dx, dy)

def get_perpendicular(direction):
    dx, dy = direction
    perp_a = dy
    perp_b = -dx
    return normalize(perp_a, perp_b)

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    zero_count = 0
    count = defaultdict(int)
    for _ in range(N):
        a = int(input[idx])
        b = int(input[idx+1])
        idx +=2
        if a ==0 and b ==0:
            zero_count +=1
        else:
            d = normalize(a, b)
            count[d] +=1
    
    processed = set()
    product = 1
    for d in list(count.keys()):
        if d in processed:
            continue
        p = get_perpendicular(d)
        if p in count and p not in processed:
            d_cnt = count[d]
            p_cnt = count[p]
            term = (pow(2, d_cnt, MOD) + pow(2, p_cnt, MOD) - 1) % MOD
            product = (product * term) % MOD
            processed.add(d)
            processed.add(p)

            term = pow(2, d_cnt, MOD)
            product = (product * term) % MOD
