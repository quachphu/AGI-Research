### Approach
1. **Group Points by X-Coordinate**: We first group all points by their x-coordinates. This allows us to efficiently check for vertical pairs of points that might form the left and right sides of a square.
2. **Check Pairs of Points on the Same X-Coordinate**: For each x-coordinate, we consider all pairs of points (y1, y2) such that y2 > y1. The vertical distance between these points gives the side length `s` of the potential square.
3. **Check for Corresponding Points**: For each pair (y1, y2) with distance `s`, we check if the points (x + s, y1) and (x + s, y2) exist. If both points exist, a square is formed.

import sys
from collections import defaultdict

def main():
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    x_to_ys = defaultdict(set)
    for _ in range(n):
        x = int(input[idx])
        y = int(input[idx + 1])
        idx += 2
        x_to_ys[x].add(y)
    
    count = 0

    for x in x_to_ys:
        ys = sorted(x_to_ys[x])
        m = len(ys)
        for i in range(m):
            for j in range(i + 1, m):
                y1 = ys[i]
                y2 = ys[j]
                s = y2 - y1
                target_x = x + s
                if target_x not in x_to_ys:
                    continue
                if y1 in x_to_ys[target_x] and y2 in x_to_ys[target_x]:
                    count += 1

    print(count)
