To solve this problem, we need to determine if Bob can remember all the cities he passes through distinctly based on their first characters. The solution involves checking if the first characters of the cities in each test case are unique.

### Approach
1. **Input Reading**: Read the number of test cases. For each test case, read the number of cities followed by the city names.
2. **Extract First Characters**: For each city name, extract the first character.
3. **Check Uniqueness**: Use a set to determine if all first characters are unique. If the length of the set of first characters is equal to the number of cities, all characters are unique; otherwise, there are duplicates.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().splitlines()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        first_chars = []
        for _ in range(N):
            city = input[ptr].strip()
            first_chars.append(city[0])
            ptr += 1
        if len(set(first_chars)) == N:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into lines for efficient processing.
2. **Processing Each Test Case**: For each test case, we read the number of cities and then each city name, extracting the first character of each city name.
3. **Uniqueness Check**: By converting the list of first characters into a set and comparing its length with the original list, we efficiently check for duplicates. If the lengths match, all characters are unique; otherwise, duplicates exist.

This approach ensures that we handle each test case efficiently with a time complexity of O(N) per test case, where N is the number of cities, making the solution both optimal and straightforward.
