To solve this problem, we need to determine the maximum number of stones Alice can collect using two specific operations on three heaps of stones. Each operation allows Alice to take stones from different heaps under certain conditions. The goal is to maximize the total number of stones collected by optimally performing these operations.

### Approach
1. **Understand the Operations**:
   - Operation 1: Take 1 stone from the first heap and 2 stones from the second heap. This can be done if the first heap has at least 1 stone and the second heap has at least 2 stones.
   - Operation 2: Take 1 stone from the second heap and 2 stones from the third heap. This can be done if the second heap has at least 1 stone and the third heap has at least 2 stones.

2. **Constraints**:
   - Each operation can be performed multiple times as long as the constraints are met.
   - The number of times each operation can be performed is interdependent due to the shared use of the second heap.

3. **Maximizing Operations**:
   - We need to determine the maximum number of times each operation can be performed. Let `x` be the number of times Operation 1 is performed and `y` be the number of times Operation 2 is performed.
   - The constraints for `x` and `y` are derived from the availability of stones in the heaps.

4. **Iterative Approach**:
   - Iterate over possible values of `x` (from 0 to the maximum possible given the constraints).
   - For each `x`, compute the maximum possible `y` given the remaining stones in the second and third heaps.
   - Track the maximum sum of `x + y` across all valid combinations.

### Solution Code
```python
t = int(input())
for _ in range(t):
    a, b, c = map(int, input().split())
    max_sum = 0
    max_x = min(a, b // 2)
    for x in range(max_x + 1):
        remaining_b = b - 2 * x
        possible_y = min(remaining_b, c // 2)
        possible_y = max(possible_y, 0)
        current_sum = x + possible_y
        if current_sum > max_sum:
            max_sum = current_sum
    print(max_sum * 3)
```

### Explanation
1. **Reading Input**: The input consists of multiple test cases. For each test case, we read the number of stones in the three heaps.
2. **Iterating Over Possible Operations**: For each test case, we determine the maximum number of times Operation 1 (`x`) can be performed, which is constrained by the number of stones in the first heap and half the number of stones in the second heap.
3. **Calculating Remaining Stones**: For each valid `x`, we calculate the remaining stones in the second heap after performing `x` operations of type 1. Using this remaining value, we compute the maximum possible `y` (operations of type 2) considering the stones available in the third heap.
4. **Maximizing the Sum**: We track the maximum sum of `x + y` across all valid combinations and multiply this sum by 3 (since each operation collects 3 stones) to get the result for each test case.

This approach efficiently explores all valid combinations of operations while respecting the constraints, ensuring the maximum number of stones is collected.
