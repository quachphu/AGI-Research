To solve this problem, we need to determine if there exists a consistent set of coordinates for N people standing on the x-axis given M constraints. Each constraint specifies the distance between two people, and we need to check if all constraints can be satisfied simultaneously.

### Approach
1. **Graph Representation**: Model the problem as a directed graph where each person is a node and each constraint is a directed edge with a weight representing the distance. For each constraint (L, R, D), add an edge from L to R with weight D and an edge from R to L with weight -D.
2. **Breadth-First Search (BFS)**: Use BFS to traverse each connected component of the graph. Assign coordinates starting from an arbitrary node (set to 0) and propagate the coordinates based on the constraints. If a contradiction is found during this propagation (i.e., a node's calculated position does not match its previously assigned position), the constraints are inconsistent.
3. **Cycle Detection**: By ensuring that all cycles in the graph are consistent (i.e., the sum of the distances around any cycle is zero), we can verify the feasibility of the constraints.

### Solution Code
```python
import sys
from collections import deque

def main():
    n, m = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n + 1)]  # Using 1-based indexing

    for _ in range(m):
        l, r, d = map(int, sys.stdin.readline().split())
        adj[l].append((r, d))
        adj[r].append((l, -d))

    pos = [None] * (n + 1)  # Position array

    for i in range(1, n + 1):
        if pos[i] is None:
            pos[i] = 0
            q = deque()
            q.append(i)
            while q:
                u = q.popleft()
                for (v, d) in adj[u]:
                    if pos[v] is None:
                        pos[v] = pos[u] + d
                        q.append(v)
                    else:
                        if pos[v] != pos[u] + d:
                            print("No")
                            return
    print("Yes")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Graph Construction**: The adjacency list `adj` is built to represent the graph where each node points to its neighbors along with the respective distances. Each constraint (L, R, D) adds two edges: one from L to R with weight D and another from R to L with weight -D.
2. **BFS Traversal**: For each unvisited node, we start a BFS. The starting node's position is initialized to 0. As we traverse each edge, we update the neighbor's position based on the current node's position and the edge's weight. If a neighbor's position has already been set, we check for consistency.
3. **Consistency Check**: During BFS, if we encounter a node that has already been assigned a position inconsistent with the current path, we immediately output "No" and terminate. If all nodes are processed without conflicts, we output "Yes".

This approach efficiently checks for consistency using BFS, ensuring that each node and edge is processed in linear time relative to the number of nodes and edges, making it suitable for large input sizes.
