To solve this problem, we need to determine if Stepan could have rearranged the cubes between positions l and r (inclusive) in the sequence provided by Vasya, such that the resulting sequence matches the one described by Stepan. The key is to verify that the cubes outside the specified range remain unchanged and that the cubes within the range form a valid permutation of the original sequence.

### Approach
1. **Check Unchanged Elements**: First, verify that all elements outside the range [l, r] in both sequences (Vasya's original sequence and Stepan's modified sequence) are identical. If any element outside this range differs, Stepan must have lied.
2. **Check Permutation**: For the elements within the range [l, r], check if they form a permutation of each other. This is done by comparing the sorted subarrays of both sequences within the specified range. If the sorted subarrays match, then it is possible that Stepan told the truth.

### Solution Code
```python
n, l, r = map(int, input().split())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

for i in range(n):
    if i < l - 1 or i >= r:
        if a[i] != b[i]:
            print("LIE")
            exit()

a_sub = a[l-1:r]
b_sub = b[l-1:r]

print("TRUTH" if sorted(a_sub) == sorted(b_sub) else "LIE")
```

### Explanation
1. **Input Reading**: The code reads the input values for the number of cubes (n), the range [l, r], and the two sequences (a and b).
2. **Check Unchanged Elements**: The loop iterates through each element in the sequences. For elements outside the range [l, r], it checks if they are the same in both sequences. If any discrepancy is found, it immediately prints "LIE" and exits.
3. **Check Permutation**: The elements within the range [l, r] are extracted from both sequences. By sorting these subarrays and comparing them, the code determines if they are permutations of each other. If they match, "TRUTH" is printed; otherwise, "LIE" is printed.

This approach ensures that we efficiently verify both the unchanged elements and the permutation within the specified range, providing an optimal solution to the problem.
