To solve this problem, we need to determine the number of groups of three points (A, B, C) such that point B is the midpoint of segment AC. The groups are considered unordered, meaning that each valid triplet should be counted exactly once.

### Approach
1. **Problem Analysis**: The key observation is that for a point B to be the midpoint of points A and C, the coordinates of B must be the average of the coordinates of A and C. This means that B's x-coordinate is (x_A + x_C) / 2 and B's y-coordinate is (y_A + y_C) / 2. Since all points have integer coordinates, the sum of the coordinates of A and C must be even for the midpoint to have integer coordinates.

2. **Optimization Insight**: Instead of checking all possible triplets (which would be computationally expensive), we can check all pairs of points. For each pair (A, C), compute their midpoint and check if this midpoint exists in the set of given points. This reduces the complexity from O(n^3) to O(n^2), which is feasible for n up to 3000.

3. **Algorithm**:
   - Read all points and store them in a list and a set for efficient lookups.
   - Iterate over all unique pairs of points using combinations.
   - For each pair, check if their sum of x and y coordinates are even.
   - Compute the midpoint and check if it exists in the set of points.
   - Count the number of valid pairs where the midpoint exists.

### Solution Code
```python
import sys
from itertools import combinations

def main():
    n = int(sys.stdin.readline())
    points = []
    for _ in range(n):
        x, y = map(int, sys.stdin.readline().split())
        points.append((x, y))
    point_set = set(points)
    count = 0
    for a, b in combinations(points, 2):
        x1, y1 = a
        x2, y2 = b
        if (x1 + x2) % 2 != 0 or (y1 + y2) % 2 != 0:
            continue
        mid_x = (x1 + x2) // 2
        mid_y = (y1 + y2) // 2
        if (mid_x, mid_y) in point_set:
            count += 1
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The points are read from standard input and stored both in a list (to generate pairs) and a set (for O(1) lookups).
2. **Generating Pairs**: Using `itertools.combinations`, we generate all unique pairs of points.
3. **Checking Midpoint Validity**: For each pair, we check if their sum of coordinates is even. If not, the midpoint cannot be an integer and we skip the pair.
4. **Midpoint Check**: If the sum is even, compute the midpoint and check if it exists in the set of points. If it does, increment the count.
5. **Output Result**: Finally, print the count of valid pairs, which corresponds to the number of valid triplets.

This approach efficiently reduces the problem complexity and ensures that each valid triplet is counted exactly once, providing the correct solution within feasible time limits.
