To solve this problem, we need to determine if we can reorder a given string into a k-string, which is a string that can be divided into k equal parts, each part being the same. If possible, we should return the reordered string; otherwise, return -1.

### Approach
1. **Check Length Divisibility**: The length of the string must be divisible by k. If not, it's impossible to form a k-string, so we return -1.
2. **Character Frequency Check**: Each character in the string must appear a number of times that is divisible by k. This ensures that we can evenly distribute the characters across the k parts of the resulting string.
3. **Construct Base String**: If the above conditions are met, construct a base string where each character appears exactly (count // k) times. The order of characters in the base string can be arbitrary, but we use sorted order for simplicity and determinism.
4. **Generate Result**: The final result is the base string repeated k times.

### Solution Code
```python
import sys
from collections import Counter

def main():
    k = int(sys.stdin.readline())
    s = sys.stdin.readline().strip()
    n = len(s)
    
    if n % k != 0:
        print(-1)
        return
    
    counts = Counter(s)
    
    for char, cnt in counts.items():
        if cnt % k != 0:
            print(-1)
            return
    
    base = []
    for char in sorted(counts):
        base.append(char * (counts[char] // k))
    
    base_str = ''.join(base)
    print(base_str * k)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Input Reading**: Read the integer k and the string s from standard input.
2. **Length Check**: If the length of s is not divisible by k, immediately return -1.
3. **Frequency Check**: Use a counter to check the frequency of each character. If any character's frequency is not divisible by k, return -1.
4. **Base String Construction**: For each character (sorted for consistency), append (count // k) instances to form the base string.
5. **Result Generation**: Concatenate the base string k times to form the final result and print it.

This approach ensures that we efficiently check the necessary conditions and construct the required k-string if possible, leveraging sorting to maintain a consistent and deterministic order of characters in the base string.
