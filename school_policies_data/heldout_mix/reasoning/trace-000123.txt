To solve this problem, we need to find the minimum number \( n \) such that the sum of its divisors \( d(n) \) equals a given value \( c \). If no such \( n \) exists, we return -1. The solution involves understanding the properties of the sum of divisors function and efficiently factorizing the given value \( c \) into valid components.

### Approach
1. **Sum of Divisors Function**: The sum of divisors function \( d(n) \) for a number \( n \) with prime factorization \( p_1^{a_1} \times p_2^{a_2} \times \ldots \times p_k^{a_k} \) is given by the product of the sum of each prime's powers. This sum can be represented as \( \prod_{i=1}^{k} \frac{p_i^{a_i+1} - 1}{p_i - 1} \).

2. **Factorization of \( c \)**: For a given \( c \), we need to factorize it into terms of the form \( \frac{p^k - 1}{p - 1} \) where \( p \) is a prime and \( k \geq 2 \). Each term corresponds to a prime's contribution to the sum of divisors.

3. **Prime Sieve**: Precompute all primes up to \( 10^7 \) using the Sieve of Eratosthenes to efficiently check for prime numbers during factorization.

4. **Backtracking with Pruning**: Use a stack-based backtracking approach to explore possible factorizations of \( c \) into valid terms, ensuring primes are considered in increasing order and exponents are tried in descending order to minimize \( n \).

import sys
import math

def sieve(n):
    sieve = [True] * (n + 1)
    sieve[0] = sieve[1] = False
    for i in range(2, int(math.isqrt(n)) + 1):
        if sieve[i]:
            sieve[i*i : n+1 : i] = [False] * len(sieve[i*i : n+1 : i])
    primes = [i for i, is_prime in enumerate(sieve) if is_prime]
    return primes

primes = sieve(10**7)

def find_max_k(p, remaining):
    if p == 1:
        return 0
    left = 2
    right = 1
    while True:
        s = (p ** right - 1) // (p - 1)
        if s <= remaining:
            right *= 2
        else:
            break
        if right > 100:
            break
    right = min(right, 100)
    max_k = 0
    while left <= right:
        mid = (left + right) // 2
        s = (p ** mid - 1) // (p - 1)
        if s <= remaining:
            max_k = mid
            left = mid + 1
        else:
            right = mid - 1
    return max_k

def solve(c):
    if c == 1:
        return 1
    stack = [(c, -1, 1)]
    min_n = -1
    while stack:
        remaining, last_prime_idx, product = stack.pop()
        if remaining == 1:
            if min_n == -1 or product < min_n:
                min_n = product
            continue
        start = last_prime_idx + 1
        for i in range(start, len(primes)):
            p = primes[i]
            if p > remaining:
                break
            max_k = find_max_k(p, remaining)
            found = False
            for k in range(max_k, 1, -1):
                s = (p ** k - 1) // (p - 1)
                if s > remaining:
                    continue
                if remaining % s != 0:
                    continue
                new_remaining = remaining // s
                new_product = product * (p) ** (k - 1)
                stack.append((new_remaining, i, new_product))
                found = True
                break
            if found:
                break
    return min_n if min_n != -1 else -1

def main():
    input = sys.stdin.read().split()
    t = int(input[0])
    for i in range(1, t + 1):
        c = int(input[i])
        print(solve(c))

if __name__ == "__main__":
    main()
