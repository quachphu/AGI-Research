To solve this problem, we need to determine the number of white and black cells on a chessboard after two paint spills. The chessboard is initially colored in a standard black and white pattern, and then two rectangles are painted with white and black paint respectively. The challenge is to compute the final count efficiently given the constraints of very large board dimensions.

### Approach
1. **Initial Chessboard Colors**: The initial color of a cell (x, y) is determined by the parity of (x + y). If the sum is even, the cell is white; otherwise, it is black.
2. **Paint Application**: The first rectangle is painted white, and the second rectangle is painted black. The final color of cells in overlapping regions of these rectangles will be black due to the order of painting.
3. **Overlap Calculation**: Determine the overlapping region between the two rectangles to adjust the counts of white and black cells accurately.
4. **Efficient Calculation**: Use mathematical formulas to compute the number of white cells in any given rectangle based on its coordinates and dimensions, avoiding direct simulation which is infeasible for large dimensions.

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    t = int(input[idx])
    idx += 1
    for _ in range(t):
        n = int(input[idx])
        m = int(input[idx + 1])
        idx += 2
        x1 = int(input[idx])
        y1 = int(input[idx + 1])
        x2 = int(input[idx + 2])
        y2 = int(input[idx + 3])
        idx += 4
        x3 = int(input[idx])
        y3 = int(input[idx + 1])
        x4 = int(input[idx + 2])
        y4 = int(input[idx + 3])
        idx += 4
        
        # Calculate areas of white and black rectangles
        w_width = x2 - x1 + 1
        w_height = y2 - y1 + 1
        W_area = w_width * w_height
        
        b_width = x4 - x3 + 1
        b_height = y4 - y3 + 1
        B_area = b_width * b_height
        
        # Determine overlap between the two rectangles
        x_left = max(x1, x3)
        x_right = min(x2, x4)
        y_bottom = max(y1, y3)
        y_top = min(y2, y4)
        if x_left > x_right or y_bottom > y_top:
            overlap_area = 0
            white_in_overlap = 0
        else:
            overlap_width = x_right - x_left + 1
            overlap_height = y_top - y_bottom + 1
            overlap_area = overlap_width * overlap_height
            a = x_left
            b = y_bottom
            total = overlap_area
            white_in_overlap = (total + ((a + b) % 2 == 0)) // 2
        
        # Calculate white cells in initial B and W regions
        a, b = x3, y3
        total = B_area
        white_in_B = (total + ((a + b) % 2 == 0)) // 2
        
        a, b = x1, y1
        total = W_area
        white_in_W = (total + ((a + b) % 2 == 0)) // 2
        
        initial_white = (n * m + 1) // 2
        
        # Compute remaining white cells not in B or W
        white_in_remaining = initial_white - (white_in_B + white_in_W - white_in_overlap)
        
        remaining_cells = n * m - (B_area + W_area - overlap_area)
        
        total_white = (W_area - overlap_area) + white_in_remaining
        total_black = B_area + (remaining_cells - white_in_remaining)
        
        print(total_white, total_black)
