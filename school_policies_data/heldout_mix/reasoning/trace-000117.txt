   - The maximum left endpoint (`max_l`) among all segments ensures that the optimal segment starts after this point to intersect all segments.
   - The minimum right endpoint (`min_r`) among all segments ensures that the optimal segment ends before this point to intersect all segments.
3. **Optimal Segment Calculation**: The length of the optimal segment is determined by the difference between `max_l` and `min_r`. If `max_l` is less than or equal to `min_r`, the length is zero (a single point suffices). Otherwise, the length is the difference between `max_l` and `min_r`.

```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        max_l = -float('inf')
        min_r = float('inf')
        for __ in range(n):
            l = int(input[ptr])
            r = int(input[ptr+1])
            ptr += 2
            if l > max_l:
                max_l = l
            if r < min_r:
                min_r = r
        res = max(0, max_l - min_r)
        print(res)

if __name__ == "__main__":
    main()
```

3. **Calculate Result**: The result is the maximum of 0 and the difference between `max_l` and `min_r`. This ensures non-negative length values.
