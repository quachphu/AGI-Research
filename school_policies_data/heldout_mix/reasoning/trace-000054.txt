To solve this problem, we need to determine which cards are missing from a given set of cards in a standard 52-card deck. The solution should output the missing cards in a specific order: first by suit (spades, hearts, clubs, diamonds) and then by rank within each suit from lowest to highest.

### Approach
1. **Read Input:** Read the number of cards and the list of given cards.
2. **Track Existing Cards:** Use a set to keep track of the cards that are present.
3. **Generate All Possible Cards:** Iterate through all possible suits and ranks in the required order.
4. **Identify Missing Cards:** Check each possible card against the set of existing cards to determine which ones are missing.
5. **Output Missing Cards:** Print each missing card in the specified order.

### Solution Code
```python
def main():
    n = int(input())
    existing = set()
    for _ in range(n):
        parts = input().split()
        suit = parts[0]
        rank = int(parts[1])
        existing.add((suit, rank))
    
    suits_order = ['S', 'H', 'C', 'D']
    missing = []
    for suit in suits_order:
        for rank in range(1, 14):
            if (suit, rank) not in existing:
                missing.append((suit, rank))
    
    for card in missing:
        print(f"{card[0]} {card[1]}")

main()
```

### Explanation
1. **Reading Input:** The first line of input is the number of cards. Each subsequent line contains a card's suit and rank. These are read and stored in a set called `existing` to track which cards are present.
2. **Tracking Existing Cards:** The set `existing` stores each card as a tuple of (suit, rank), ensuring efficient look-up to check if a card is present.
3. **Generating Possible Cards:** We iterate through each suit in the order S, H, C, D. For each suit, we check all ranks from 1 to 13. This ensures we generate all possible cards in the required order.
4. **Identifying Missing Cards:** For each possible card, we check if it exists in the `existing` set. If not, it is added to the `missing` list.
5. **Output:** The missing cards are printed in the order they were identified, which respects the required order of suits and ranks.

This approach efficiently determines the missing cards and outputs them in the correct order, ensuring both correctness and optimal performance.
