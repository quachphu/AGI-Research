To solve this problem, we need to determine the nth XORinacci number based on the given definition. The XORinacci sequence is defined similarly to the Fibonacci sequence but uses the bitwise XOR operation instead of addition. 

### Approach
The key insight here is recognizing that the XORinacci sequence exhibits a periodic pattern every 3 steps. This periodicity allows us to determine the nth value efficiently by checking the value of `n % 3`:
- If `n % 3 == 0`, the result is the initial value `a`.
- If `n % 3 == 1`, the result is the initial value `b`.
- If `n % 3 == 2`, the result is `a XOR b`.

This approach leverages the periodic nature of the sequence to compute the result in constant time, O(1), for each test case, making the solution efficient even for very large values of `n`.

### Solution Code
```python
import sys

def xorinacci():
    T = int(sys.stdin.readline())
    for _ in range(T):
        a, b, n = map(int, sys.stdin.readline().split())
        rem = n % 3
        if rem == 0:
            print(a)
        elif rem == 1:
            print(b)
        else:
            print(a ^ b)

xorinacci()
```

### Explanation
1. **Reading Input:** The function reads the number of test cases `T` and then processes each test case by reading the values of `a`, `b`, and `n`.
2. **Periodicity Check:** For each test case, the remainder of `n` divided by 3 (`n % 3`) is computed to determine the position within the periodic cycle.
3. **Result Determination:** Based on the remainder:
   - If the remainder is 0, the result is `a`.
   - If the remainder is 1, the result is `b`.
   - If the remainder is 2, the result is the XOR of `a` and `b`.

This approach ensures that each test case is processed in constant time, making the solution highly efficient and suitable for large input sizes.
