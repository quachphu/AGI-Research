### Approach
The key insight is to traverse the permutation and handle fixed points (elements that are in their original positions) efficiently. By checking consecutive elements, we can resolve two fixed points with a single swap, thus minimizing the number of swaps needed.

1. **Traverse the Permutation**: Iterate through the permutation from left to right.
2. **Check Fixed Points**: For each element, check if it is a fixed point (i.e., the element is at its original position).
3. **Handle Consecutive Fixed Points**: If a fixed point is found, check the next element. If the next element is also a fixed point, swap them and skip the next element. This resolves two fixed points with one swap.
4. **Handle Single Fixed Points**: If the next element is not a fixed point, swap the current element with the next one. This resolves one fixed point with one swap.

This approach ensures that each fixed point is resolved with the minimum number of swaps by leveraging consecutive fixed points when possible.
