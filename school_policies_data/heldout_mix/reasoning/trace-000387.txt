To solve this problem, we need to find the shortest original title for a new problem that does not appear as a substring in any of the given problem titles. If there are multiple shortest titles, we choose the lexicographically smallest one.

### Approach
1. **Collect Forbidden Substrings**: Extract all possible substrings from the given problem titles and store them in a set for quick lookup.
2. **Generate Candidates in Lexicographic Order**: Starting from length 1, generate all possible strings in lexicographic order and check if they are present in the forbidden set. If a valid string is found, it is the answer. If not, increment the length and repeat the process.

### Solution Code
```python
import sys
import itertools

def find_original_title():
    n = int(sys.stdin.readline())
    titles = [sys.stdin.readline().strip() for _ in range(n)]
    
    forbidden = set()
    for title in titles:
        length = len(title)
        for i in range(length):
            for j in range(i, length):
                substring = title[i:j+1]
                forbidden.add(substring)
    
    chars = 'abcdefghijklmnopqrstuvwxyz'
    L = 1
    while True:
        for candidate in itertools.product(chars, repeat=L):
            s = ''.join(candidate)
            if s not in forbidden:
                print(s)
                return
        L += 1

find_original_title()
```

### Explanation
1. **Reading Input**: The input consists of the number of titles followed by the titles themselves.
2. **Building Forbidden Set**: For each title, generate all possible substrings and add them to a set. This set helps in quickly checking if a candidate title is valid.
3. **Generating Candidates**: Using itertools.product, generate all possible strings of increasing lengths starting from 1. For each length, check each string in lexicographic order. The first string not found in the forbidden set is the answer.

This approach ensures that we find the shortest possible valid title efficiently by leveraging set lookups and generating candidates in lexicographic order. The solution handles edge cases where all shorter lengths are forbidden by incrementally checking longer lengths until a valid title is found.
