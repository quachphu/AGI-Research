To solve this problem, we need to compute the total area of all possible rectangles formed by given vertical and horizontal lines on a 2D plane. The solution involves efficiently summing the contributions of all possible pairs of lines in both the x and y directions and then combining these sums to get the final result.

### Approach
1. **Problem Analysis**: Each rectangle is formed by two vertical lines (x_i, x_j) and two horizontal lines (y_k, y_l). The area of each rectangle is (x_j - x_i) * (y_l - y_k). Summing these areas for all possible pairs directly would be computationally infeasible due to the large constraints, so we need an optimized approach.

2. **Key Insight**: The total sum of areas can be broken down into two separate sums: one for the contributions of the vertical lines (sum_x) and one for the horizontal lines (sum_y). The product of these two sums gives the total area sum.

3. **Efficient Calculation**:
   - **sum_x**: For each vertical line x_i, compute its contribution to all pairs (i, j) where i < j. This can be done by considering how many times each x_i appears as a left or right boundary in these pairs.
   - **sum_y**: Similarly, compute the contributions for each horizontal line y_k.

4. **Modulo Operation**: Since the result can be very large, we take modulo 10^9 + 7 at each step to ensure numbers remain manageable.

### Solution Code
```python
MOD = 10**9 + 7

n, m = map(int, input().split())
x = list(map(int, input().split()))
y = list(map(int, input().split()))

sum_x = 0
for i in range(n):
    term = x[i] * (2 * i - (n - 1))
    sum_x += term
sum_x %= MOD

sum_y = 0
for j in range(m):
    term = y[j] * (2 * j - (m - 1))
    sum_y += term
sum_y %= MOD

total = (sum_x * sum_y) % MOD
print(total)
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of vertical lines (n), horizontal lines (m), and their respective positions.

2. **Calculating sum_x**: For each vertical line x_i, we compute its contribution using the formula `x[i] * (2 * i - (n - 1))`. This formula accounts for how many times each x_i appears as the left or right boundary in all valid pairs (i, j).

3. **Calculating sum_y**: Similarly, for each horizontal line y_j, we compute its contribution using the formula `y[j] * (2 * j - (m - 1))`.

4. **Combining Results**: The total area sum is obtained by multiplying sum_x and sum_y, then taking the result modulo 10^9 + 7 to handle large numbers.

This approach efficiently computes the required sum in O(n + m) time, making it suitable for large input sizes up to 100,000.
