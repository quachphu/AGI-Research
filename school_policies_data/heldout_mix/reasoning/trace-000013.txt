To solve this problem, we need to determine the minimum number of clone puppets that wizards must create to ensure their demonstration meets the required percentage of the city's population as mandated by the city administration.

### Approach
1. **Understanding the Requirement**: The city administration requires the demonstration to have at least `y` percent of the city's population `n`. This percentage is calculated based on the actual population `n`, not including any clones.
2. **Calculate Required Demonstrators**: Convert the percentage requirement into the minimum number of demonstrators needed. This is done by computing the ceiling value of `(y * n) / 100`, which can be efficiently calculated using integer arithmetic to avoid floating-point inaccuracies.
3. **Determine Clones Needed**: Subtract the number of wizards `x` from the required number of demonstrators. If the result is negative (meaning there are enough wizards), no clones are needed.

### Solution Code
```python
def main():
    import sys
    n, x, y = map(int, sys.stdin.readline().split())
    required = (y * n + 99) // 100
    clones = max(0, required - x)
    print(clones)

main()
```

### Explanation
1. **Reading Input**: The input consists of three integers `n`, `x`, and `y` which represent the total population, number of wizards, and the required percentage respectively.
2. **Calculate Minimum Demonstrators**: The formula `(y * n + 99) // 100` is used to compute the ceiling of `(y * n) / 100` without using floating-point arithmetic. This gives the minimum number of demonstrators required.
3. **Compute Clones Needed**: The number of clones needed is the difference between the required demonstrators and the available wizards, ensuring it is non-negative. If the number of wizards is already sufficient, the result will be zero.

This approach efficiently determines the solution using basic arithmetic operations, ensuring accuracy and optimal performance.
