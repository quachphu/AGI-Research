To solve this problem, we need to determine if we can transform materials in a laboratory such that the required amounts for an experiment can be met. The transformations between materials follow specific rules, and we need to account for these rules to check feasibility.

### Approach
1. **Problem Analysis**: Each material can be converted into another material (or vice versa) based on given ratios. The goal is to check if the available amounts can be transformed to meet the required amounts for each material.

2. **Key Insight**: The materials form a tree structure where each node (material) has a parent (another material) except the root. We process each node starting from the leaves (highest index) moving towards the root (index 1). This allows us to handle dependencies in a bottom-up manner.

3. **Algorithm**:
   - For each material from the highest index down to 2:
     - Check if the available amount meets the requirement. If there's a surplus, convert it to the parent material.
     - If there's a deficit, convert the required amount from the parent material using the given ratio. If the parent doesn't have enough, the answer is "NO".
   - After processing all materials, check if the root (material 1) has enough to meet its requirement.

### Solution Code
```python
n = int(input())
b = list(map(int, input().split()))
a = list(map(int, input().split()))
x = [0] * (n + 1)  # 1-based indices for x and k
k = [0] * (n + 1)

for i in range(2, n + 1):
    xi, ki = map(int, input().split())
    x[i] = xi
    k[i] = ki

possible = True

for i in range(n, 1, -1):
    current_b = b[i-1]
    current_a = a[i-1]
    if current_b >= current_a:
        surplus = current_b - current_a
        parent = x[i]
        b[parent - 1] += surplus
    else:
        deficit = current_a - current_b
        required = deficit * k[i]
        parent = x[i]
        parent_idx = parent - 1
        if parent_idx < 0 or parent_idx >= len(b):
            possible = False
            break
        if b[parent_idx] < required:
            possible = False
            break
        b[parent_idx] -= required

if possible and b[0] >= a[0]:
    print("YES")
else:
    print("NO")
```

### Explanation
1. **Input Reading**: The input is read and parsed into the available amounts (`b`), required amounts (`a`), and transformation rules (`x` and `k`).

2. **Processing Nodes**: Starting from the highest index material down to 2, each material is checked. Surpluses are converted to the parent material, while deficits are covered by converting from the parent material using the given ratio.

3. **Root Check**: After processing all materials, the root (material 1) is checked to ensure it meets its requirement. If all checks pass, the result is "YES"; otherwise, it's "NO".

This approach ensures that we efficiently check the feasibility of meeting the required amounts by leveraging the tree structure and processing nodes in a bottom-up manner, which allows us to handle dependencies correctly.
