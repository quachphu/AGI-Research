To solve this problem, we need to determine the volume of the scrapped material from an N x N x N cube after it has been submerged in Coke. The scrapped material consists of all 1x1x1 cubes that have at least one face exposed to the Coke.

### Approach
1. **Understanding the Problem**: When a cube is submerged in Coke, all the 1x1x1 cubes on the surface become dirty and need to be scrapped. The volume of the scrapped material is the number of these surface cubes.
2. **Mathematical Insight**: For an N x N x N cube, the number of surface cubes can be calculated by subtracting the volume of the inner cube (which is not exposed) from the total volume of the original cube. The inner cube has a side length of (N-2) if N ≥ 2. For N = 1, the entire cube is exposed.
3. **Formula Derivation**: 
   - If N = 1, the result is 1.
   - For N ≥ 2, the formula derived is \(6N^2 - 12N + 8\), which efficiently calculates the number of surface cubes without explicitly computing large powers.

### Solution Code
```python
def calculate_volume():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for n_str in input[1:T+1]:
        N = int(n_str)
        if N == 1:
            print(1)
        else:
            print(6 * N * N - 12 * N + 8)
calculate_volume()
```

1. **Reading Input**: The input is read in one go and split into a list of strings for efficient processing.
2. **Handling Test Cases**: The number of test cases (T) is read first. For each test case, the side length (N) of the cube is processed.
3. **Condition Check**: If N is 1, the result is directly 1. For other values of N, the formula \(6N^2 - 12N + 8\) is applied to compute the volume of the scrapped material.
4. **Efficiency**: The formula allows us to compute the result in constant time O(1) for each test case, making the solution efficient even for the upper constraint of N = 10^9.

This approach ensures that the solution is both optimal and easy to understand, leveraging mathematical insights to avoid unnecessary computations.
