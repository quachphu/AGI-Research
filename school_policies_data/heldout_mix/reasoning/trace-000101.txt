To solve this problem, we need to determine the eventual length of a string after repeatedly removing the leftmost occurrence of the substring 'ST' until no more such substrings exist. Given the constraints, an efficient approach is necessary to handle large input sizes.

### Approach
The key insight is to realize that each 'T' can only form an 'ST' pair with an 'S' that occurs before it. By iterating through the string and tracking the number of available 'S' characters, we can efficiently count the number of valid 'ST' pairs. Each time a 'T' is encountered and there are available 'S' characters, we form a pair, reducing both the count of available 'S' characters and incrementing the count of valid pairs. The eventual length of the string is then calculated by subtracting twice the number of valid pairs from the original length of the string.

### Solution Code
```python
def main():
    import sys
    X = sys.stdin.readline().strip()
    s_count = 0
    pair_count = 0
    for c in X:
        if c == 'S':
            s_count += 1
        else:
            if s_count > 0:
                s_count -= 1
                pair_count += 1
    print(len(X) - 2 * pair_count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input string is read from standard input.
2. **Tracking 'S' Characters**: As we iterate through the string, we maintain a count of encountered 'S' characters (`s_count`).
3. **Forming Pairs**: For each 'T' encountered, if there are available 'S' characters (i.e., `s_count` > 0), we form an 'ST' pair. This reduces the count of available 'S' characters and increases the count of valid pairs (`pair_count`).
4. **Calculating Result**: The eventual length of the string is determined by subtracting twice the number of valid pairs from the original length of the string. This is because each valid 'ST' pair removes two characters from the string.

This approach ensures an efficient O(n) time complexity and O(1) space complexity, making it suitable for large input sizes up to 200,000 characters.
