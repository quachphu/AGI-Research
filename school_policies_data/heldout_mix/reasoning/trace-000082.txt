To solve this problem, we need to determine which of the 12 possible mathematical expressions involving three given numbers x, y, and z yields the maximum value. The challenge is to compare these expressions without directly computing their potentially enormous values, which could lead to overflow or precision issues. Instead, we use logarithms to compare the expressions in a manageable way.

### Approach
1. **Logarithmic Transformation**: Convert each expression into a logarithmic form to avoid directly computing large values. This allows us to compare the expressions using their logarithms, which are more manageable.
2. **Key Comparison**: For each expression, compute a key that consists of two parts:
   - The first part indicates whether the logarithmic value is positive (indicating the original value is greater than 1) or non-positive (indicating the original value is between 0 and 1).
   - The second part is the natural logarithm of the logarithmic value if it is positive, or the original logarithmic value if it is non-positive.
3. **Case Handling**: Handle each of the 12 expressions by categorizing them into chain (e.g., \(a^{b^c}\)) and product (e.g., \((a^b)^c\)) types, and compute their respective keys based on their structure.
4. **Comparison and Selection**: Compare all computed keys to find the maximum value, ensuring to select the smallest index in case of ties.

### Solution Code
```python
import math

def main():
    import sys
    x, y, z = map(float, sys.stdin.readline().split())
    cases = [
        ('chain', x, y, z, 'x^y^z'),
        ('chain', x, z, y, 'x^z^y'),
        ('product', x, y, z, '(x^y)^z'),
        ('product', x, z, y, '(x^z)^y'),
        ('chain', y, x, z, 'y^x^z'),
        ('chain', y, z, x, 'y^z^x'),
        ('product', y, x, z, '(y^x)^z'),
        ('product', y, z, x, '(y^z)^x'),
        ('chain', z, x, y, 'z^x^y'),
        ('chain', z, y, x, 'z^y^x'),
        ('product', z, x, y, '(z^x)^y'),
        ('product', z, y, x, '(z^y)^x'),
    ]
    max_key = None
    best_expr = ''
    for case in cases:
        expr_type, a, b, c, output_str = case
        if expr_type == 'chain':
            if a > 1.0:
                try:
                    ln_a = math.log(a)
                    ln_ln_a = math.log(ln_a)
                    term1 = c * math.log(b)
                    ln_Li = term1 + ln_ln_a
                    key_part = (1, ln_Li)
                except:
                    key_part = (1, math.inf)
            else:
                try:
                    bc = math.pow(b, c)
                    ln_a = math.log(a)
                    L_i = bc * ln_a
                    key_part = (0, L_i)
                except:
                    key_part = (0, -math.inf)
        else:
            if a > 1.0:
                try:
                    ln_a = math.log(a)
                    ln_ln_a = math.log(ln_a)
                    term1 = math.log(b) + math.log(c) + ln_ln_a
                    key_part = (1, term1)
                except:
                    key_part = (1, math.inf)
            else:
                try:
                    ln_a = math.log(a)
                    L_i = b * c * ln_a
                    key_part = (0, L_i)
                except:
                    key_part = (0, -math.inf)
        if (max_key is None) or (key_part > max_key):
            max_key = key_part
            best_expr = output_str
    print(best_expr)

if __name__ == '__main__':
    main()
```

3. **Key Computation**: For each case, depending on whether it is a chain or product type, the key is computed using logarithmic transformations. This involves checking if the base is greater than 1 and handling the logarithmic calculations accordingly to avoid overflow and underflow.
4. **Comparison and Output**: The keys are compared lexicographically, and the expression corresponding to the maximum key is printed. This ensures the correct expression is selected even if multiple expressions yield the same maximum value, by choosing the smallest index as required.
