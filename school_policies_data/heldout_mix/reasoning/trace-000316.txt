To solve this problem, we need to determine the maximum number of treasure chests that can be opened using given keys, under the condition that a key can unlock a chest if the sum of their numbers is odd. This translates to pairing even-numbered chests with odd-numbered keys and odd-numbered chests with even-numbered keys.

### Approach
1. **Count Parity**: First, count the number of even and odd numbers among the chests and keys.
2. **Calculate Pairings**: The maximum number of pairs is the sum of two minima:
   - The minimum of the count of even chests and the count of odd keys.
   - The minimum of the count of odd chests and the count of even keys.

This approach works because an even number plus an odd number results in an odd number, which is the required condition for a key to unlock a chest. By efficiently counting and pairing these values, we can determine the maximum number of chests that can be opened.

### Solution Code
```python
n, m = map(int, input().split())
a = list(map(int, input().split()))
even_a = sum(1 for x in a if x % 2 == 0)
odd_a = n - even_a

b = list(map(int, input().split()))
even_b = sum(1 for x in b if x % 2 == 0)
odd_b = m - even_b

result = min(even_a, odd_b) + min(odd_a, even_b)
print(result)
```

### Explanation
1. **Reading Input**: The input is read and parsed into lists of chest numbers and key numbers.
2. **Counting Even and Odd Numbers**: For both chests and keys, we count how many are even and how many are odd. This is done using a simple loop and modulo operation.
3. **Calculating Maximum Pairs**: Using the counts of even and odd numbers, we compute the possible pairs. The result is the sum of the minimum pairs between even chests and odd keys, and between odd chests and even keys.

This solution efficiently processes the input in linear time, making it suitable for large input sizes up to 100,000 elements. The approach ensures that we maximize the number of valid key-chest pairs by leveraging parity properties.
