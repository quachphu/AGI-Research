To solve this problem, we need to determine how many positions in the k-th lexicographical permutation of integers from 1 to n are such that both the position index and the value at that index are lucky numbers. Lucky numbers are those that consist only of the digits 4 and 7.

### Approach

1. **Check Permutation Existence**: For n ≤ 20, check if the k-th permutation exists by computing n!. If n! < k, output -1. For n > 20, the permutation always exists because 20! is significantly larger than the maximum possible value of k (10^9).

2. **Determine m**: Find the minimal m such that m! ≥ k. This m represents the number of trailing elements in the permutation that need to be generated explicitly, as the first (n - m) elements are in their natural order.

3. **Generate the k-th Permutation**: Generate the k-th permutation for the trailing m elements using a factorial number system approach.

4. **Identify Lucky Numbers**: Generate all lucky numbers up to n using a BFS approach to ensure we efficiently collect all valid lucky numbers.

5. **Count Valid Positions**: For each lucky number position, check if the corresponding value in the permutation is also a lucky number. This involves checking the first (n - m) elements directly and the trailing m elements using the generated permutation.
