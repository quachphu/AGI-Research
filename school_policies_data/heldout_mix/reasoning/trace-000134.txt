   - Each task consists of `k` subtasks, each with a specific time requirement.
   - Solving all subtasks of a task gives an extra point, making it more efficient to complete tasks when possible.
   - The goal is to maximize points by optimally choosing between completing full tasks and solving individual subtasks.

2. **Intuition**:
   - Complete tasks provide bonus points, so they should be prioritized if they fit within the time constraint.
   - After solving as many complete tasks as possible, the remaining time should be used to solve the fastest available subtasks from the remaining tasks.

3. **Algorithm**:
   - **Sort Subtasks by Time**: This allows us to efficiently pick the fastest subtasks first.
   - **Iterate Over Possible Complete Tasks**: Check all possible numbers of complete tasks (from 0 to the maximum feasible number given the time constraint).
   - **Calculate Remaining Time**: For each number of complete tasks, compute the remaining time and use it to solve as many individual subtasks as possible.

### Solution Code
```python
n, k, M = map(int, input().split())
tj = list(map(int, input().split()))
sum_t = sum(tj)
sorted_t = sorted(tj)
max_points = 0

max_possible_s = min(n, M // sum_t) if sum_t != 0 else 0

for s in range(0, max_possible_s + 1):
    time_used = s * sum_t
    if time_used > M:
        continue
    rem_time = M - time_used
    current_points = s * (k + 1)
    time_left = rem_time
    for t in sorted_t:
        if t > time_left:
            break
        max_possible = n - s
        possible = min(time_left // t, max_possible)
        current_points += possible
        time_left -= possible * t
        if time_left == 0:
            break
    if current_points > max_points:
        max_points = current_points

print(max_points)
```

### Explanation
1. **Reading Input**: The input values are read and parsed into the number of tasks (`n`), subtasks per task (`k`), and the total time (`M`). The time required for each subtask is stored in a list.
2. **Sorting Subtasks**: The subtask times are sorted to facilitate efficient selection of the fastest subtasks.
3. **Iterating Over Complete Tasks**: For each possible number of complete tasks (`s`), the time used and remaining time are calculated. Points from complete tasks are added upfront.
4. **Maximizing Points from Remaining Time**: Using the remaining time, the fastest subtasks are chosen from the remaining tasks to maximize the points. This is done by iterating through the sorted subtask times and selecting as many as possible within the remaining time constraints.
5. **Output the Result**: The maximum points obtained from all possible combinations of complete tasks and individual subtasks is printed.

This approach ensures that we efficiently balance between completing tasks for bonus points and solving the fastest possible subtasks to maximize the total points within the given time limit.
