To solve this problem, we need to partition a string into the minimum number of substrings such that each substring can be rearranged into a palindrome. A string can be rearranged into a palindrome if at most one character has an odd count. 

### Approach
1. **Dynamic Programming with Bitmask Tracking**: Use dynamic programming (DP) to keep track of the minimum number of partitions needed up to each position in the string. Utilize a bitmask to efficiently track the parity (even/odd) of character counts.
2. **Bitmask Representation**: Each bit in the bitmask represents the parity of the count of a corresponding character. For example, if the 0th bit is set, it means the count of 'a' is odd.
3. **Valid Substring Check**: For each position, check all possible previous bitmasks to determine if the substring from the previous position to the current position can form a valid palindrome. This is done by ensuring the XOR of the current bitmask and a previous bitmask results in a bitmask with at most one bit set.
4. **Efficient Update**: Maintain a dictionary to track the minimum number of partitions required for each encountered bitmask, allowing for efficient look-up and updates.

### Solution Code
```python
s = input().strip()

mask_dp = {0: 0}
current_mask = 0

    current_mask ^= 1 << (ord(c) - ord('a'))

    # Check x = current_mask

        min_val = mask_dp[current_mask] + 1

        if x in mask_dp:
            if mask_dp[x] + 1 < min_val:
                min_val = mask_dp[x] + 1
    
    # Update the mask_dp for current_mask
    if current_mask in mask_dp:
```

4. **Update Minimum Partitions**: Track the minimum partitions required for each bitmask encountered, updating the dictionary to ensure efficient future look-ups.
