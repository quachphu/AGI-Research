To solve this problem, we need to determine if Roy's photos meet Facebook's requirements for a profile picture. The solution involves checking each photo's dimensions against specified criteria and providing the appropriate response based on these checks.

### Approach
1. **Input Reading**: Read the minimum side length `L` and the number of photos `N`.
2. **Dimension Checks**: For each photo, check its width `W` and height `H` against `L`:
   - If either `W` or `H` is less than `L`, the response is "UPLOAD ANOTHER".
   - If both dimensions are at least `L`, check if they form a square. If they do, the response is "ACCEPTED"; otherwise, it's "CROP IT".

### Solution Code
```python
def process_photos():
    L = int(input())
    N = int(input())
    for _ in range(N):
        W, H = map(int, input().split())
        if W < L or H < L:
            print("UPLOAD ANOTHER")
        else:
            if W == H:
                print("ACCEPTED")
            else:
                print("CROP IT")

process_photos()
```

### Explanation
1. **Reading Input**: The function starts by reading the minimum side length `L` and the number of photos `N`.
2. **Processing Each Photo**: For each photo, it reads the dimensions `W` and `H`.
3. **Check Dimensions**: 
   - If either dimension is less than `L`, it prints "UPLOAD ANOTHER".
   - If both dimensions are sufficient, it checks if they form a square. If they do, it prints "ACCEPTED"; otherwise, it prints "CROP IT".

This approach ensures that each photo is evaluated efficiently and correctly according to the given constraints, providing the required responses in an optimal manner.
