To solve this problem, we need to determine if Takahashi can buy a toy that costs C yen using two coins of denominations A yen and B yen. The solution involves checking if the sum of the two coins is sufficient to cover the cost of the toy.

### Approach
1. **Problem Analysis**: The problem requires us to check if the sum of two given coins (A and B yen) is at least equal to the cost of the toy (C yen). If the sum of the coins is greater than or equal to the cost, Takahashi can buy the toy; otherwise, he cannot.
2. **Intuition**: The solution is straightforward. By summing the values of the two coins and comparing this sum to the cost of the toy, we can determine if the purchase is possible.
3. **Algorithm**: 
   - Read the input values for A, B, and C.
   - Compute the sum of A and B.
   - Check if this sum is greater than or equal to C.
   - Print "Yes" if the condition is met, otherwise print "No".

### Solution Code
```python
a, b, c = map(int, input().split())
print("Yes" if a + b >= c else "No")
```

### Explanation
- **Reading Input**: The input values for A, B, and C are read from standard input.
- **Sum Calculation**: The sum of A and B is computed.
- **Condition Check**: The sum is compared against C. If the sum is greater than or equal to C, the output is "Yes"; otherwise, it is "No".

This approach efficiently checks the condition in constant time, O(1), making it optimal for the given problem constraints.
