To solve this problem, we need to determine the k-th day when the colors of two different chandeliers differ. The chandeliers cycle through their colors in a periodic manner, and we need an efficient way to compute the day without checking each day individually.

### Approach
1. **Identify Valid Color Matches**: First, we identify pairs of indices where the colors of the two chandeliers match. This helps us determine potential days where the colors might be the same.
2. **Use Congruence Systems**: For each valid color match, we solve a system of linear congruences to find the days when both chandeliers display the same color.
3. **Binary Search**: Instead of iterating through each day, we use binary search to efficiently determine the minimal day where the number of differing days reaches k. For each midpoint in the binary search, we compute the number of days where the colors are the same and check if the number of differing days meets the requirement.

### Solution Code
```python
import sys
import math

def main():
    n, m, k = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    b = list(map(int, sys.stdin.readline().split()))
    
    color_to_r2 = {color: idx for idx, color in enumerate(b)}
    
    valid_pairs = []
    for r1 in range(n):
        color = a[r1]
        if color in color_to_r2:
            r2 = color_to_r2[color]
            valid_pairs.append((r1, r2))
    
    g_all = math.gcd(n, m)
    lcm_all = (n * m) // g_all
    
    low = 1
    high = 10**24  # A sufficiently large upper bound
    answer = 0
    while low <= high:
        mid = (low + high) // 2
        same = 0
        for r1, r2 in valid_pairs:
            if (r1 - r2) % g_all != 0:
                continue
            c = r2 - r1
            c_div_g = c // g_all
            m_gcd = m // g_all
            n_gcd = n // g_all
            
            if m_gcd == 1:
                inv = 0
            else:
                inv = pow(n_gcd, -1, m_gcd)
            
            k_val = (c_div_g * inv) % m_gcd
            d0 = r1 + k_val * n
            
            if d0 > mid - 1:
                continue
            
            max_d = mid - 1
            count = ((max_d - d0) // lcm_all) + 1
            same += count
        
        diff = mid - same
        if diff >= k:
            answer = mid
            high = mid - 1
        else:
            low = mid + 1
    print(answer)

if __name__ == "__main__":
    main()
```

3. **Binary Search**: We perform a binary search over possible days. For each midpoint, we calculate the number of days where the colors are the same using the Chinese Remainder Theorem (CRT) to solve the congruence systems for each valid pair.
4. **Congruence Systems**: For each valid pair, we solve the system of congruences to find the earliest day they match and count how many times they match up to the current midpoint.
