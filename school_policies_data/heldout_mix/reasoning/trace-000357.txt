To solve this problem, we need to determine if a given string S conforms to the postal code format of AtCoder Kingdom. The postal code must have a hyphen '-' at the (A+1)-th position, with all other characters being digits from 0 to 9. The length of the postal code must be exactly A + B + 1, where A and B are the number of digits before and after the hyphen, respectively.

### Approach
1. **Check Hyphen Position**: Verify that the hyphen '-' is located exactly at the (A+1)-th position (0-based index A).
2. **Check Digits**: Ensure that all characters before the hyphen (first A characters) and all characters after the hyphen (next B characters) are digits.

### Solution Code
```python
A, B = map(int, input().split())
S = input().strip()

if S[A] != '-':
    print("No")
else:
    part1 = S[:A]
    part2 = S[A+1:]
    if part1.isdigit() and part2.isdigit():
        print("Yes")
    else:
        print("No")
```

### Explanation
1. **Reading Input**: The first line of input contains integers A and B. The second line contains the string S.
2. **Hyphen Check**: We check if the character at position A (0-based index) is a hyphen '-'. If not, the string is immediately invalid.
3. **Digit Check**: We split the string into two parts: the substring before the hyphen and the substring after the hyphen. We then check if both substrings consist entirely of digits using the `isdigit()` method.
4. **Output Result**: If both checks (hyphen position and digit parts) pass, we print "Yes"; otherwise, we print "No".

This approach ensures that all constraints are checked efficiently, validating both the structure and content of the postal code string.
