To solve this problem, we need to determine the minimal number of changes required to transform a given poem such that it contains no palindromic substrings of length greater than 1. A palindromic substring reads the same forwards and backwards, and we need to ensure that no such substrings exist by modifying the poem with the least number of changes.

### Approach
The key insight is that any palindromic substring of length greater than 1 must either be of length 2 or 3. Therefore, to eliminate all palindromic substrings, we need to ensure:
1. No two consecutive characters are the same (to avoid length 2 palindromes).
2. No three consecutive characters have the first and third characters the same (to avoid length 3 palindromes).

We use a dynamic programming approach to track the minimal number of changes required. For each position in the string, we maintain a state representing the last two characters and their minimal cost. This allows us to efficiently compute the minimal changes needed by considering all possible valid transitions between states.

### Solution Code
```python
import sys

def minimal_changes(s):
    n = len(s)
    if n <= 1:
        return 0
    # Initialize DP for the first character
    current_dp = {}
    original_char = s[0]
    for c in 'abcdefghijklmnopqrstuvwxyz':
        cost = 0 if c == original_char else 1
        current_dp[(None, c)] = cost
    # Process the rest of the characters
    for i in range(1, n):
        original = s[i]
        new_dp = {}
        for (prev_pp, prev_p), cost_so_far in current_dp.items():
            # Determine allowed characters for current position
            if prev_pp is None:
                # i == 1: previous character is prev_p, next must != prev_p
                allowed = [c for c in 'abcdefghijklmnopqrstuvwxyz' if c != prev_p]
            else:
                # i >= 2: new_char must != prev_p and != prev_pp
                allowed = [c for c in 'abcdefghijklmnopqrstuvwxyz' if c != prev_p and c != prev_pp]
            for c in allowed:
                new_cost = cost_so_far + (0 if c == original else 1)
                new_state = (prev_p, c)
                if new_state not in new_dp or new_cost < new_dp[new_state]:
                    new_dp[new_state] = new_cost
        current_dp = new_dp
        if not current_dp:
            return 0  # This should not happen as we can always find a way
    return min(current_dp.values()) if current_dp else 0

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        s = sys.stdin.readline().strip()
        print(minimal_changes(s))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Initialization**: For the first character, we initialize the dynamic programming (DP) table with all possible characters and their respective costs (0 if it matches the original character, 1 otherwise).
2. **Processing Each Character**: For each subsequent character, we update the DP table by considering all valid transitions. A valid transition ensures the new character is not equal to the previous character (to avoid length 2 palindromes) and not equal to the character two positions back (to avoid length 3 palindromes).
3. **State Tracking**: The DP state tracks the last two characters and their minimal cost. For each character position, we update the state transitions and compute the minimal cost.
4. **Result Extraction**: After processing all characters, the minimal cost from the final DP states gives the answer for the test case.

This approach efficiently handles the constraints and ensures that the solution is computed in linear time relative to the input size, making it suitable for large inputs.
