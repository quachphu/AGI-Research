To solve this problem, we need to determine the number of subsets of positive integers from 1 to n that have exactly k elements and sum up to a given value s. The solution involves generating all possible combinations of k elements and checking their sums against s.

### Approach
1. **Input Handling**: Read multiple datasets until encountering three zeros.
2. **Edge Cases**: Check if k is greater than n, which is impossible, or if the sum s is outside the possible range of sums for k elements.
3. **Range Check**: Calculate the minimum and maximum possible sums for k elements. If s is outside this range, the answer is 0.
4. **Combination Generation**: Use combinations to generate all possible sets of k elements from 1 to n.
5. **Sum Check**: For each combination, check if the sum equals s and count valid combinations.

### Solution Code
```python
import sys
from itertools import combinations

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n, k, s = map(int, line.split())
        if n == 0 and k == 0 and s == 0:
            break
        if k == 0 or k > n:
            print(0)
            continue
        min_sum = k * (k + 1) // 2
        max_sum = k * (2 * n - k + 1) // 2
        if s < min_sum or s > max_sum:
            print(0)
            continue
        count = 0
        for comb in combinations(range(1, n + 1), k):
            if sum(comb) == s:
                count += 1
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Input Handling**: The code reads input lines until it encounters "0 0 0", which signals the end of input.
2. **Edge Cases**: If k is zero or greater than n, it immediately outputs 0 since such subsets are impossible.
3. **Range Check**: The minimum possible sum for k elements is the sum of the first k natural numbers, and the maximum is the sum of the k largest numbers in the range 1 to n. If s is outside this range, output 0.
4. **Combination Generation**: Using `itertools.combinations`, generate all possible k-element subsets from 1 to n.
5. **Sum Check**: For each generated combination, check if the sum matches s and count the valid ones.

This approach efficiently handles the constraints and ensures that we only generate necessary combinations, making the solution both correct and efficient for the given problem constraints.
