To solve this problem, we need to generate a chessboard pattern based on given dimensions (height H and width W). The chessboard alternates between '#' and '.' starting with a '#' at the top-left corner. The solution should read multiple datasets until it encounters a line with two zeros, and it should print each chessboard followed by a blank line.

### Approach
1. **Input Handling**: Read input lines until encountering a line with both H and W as zero.
2. **Pattern Generation**: For each dataset, generate the chessboard row by row. Each cell (i, j) in the chessboard is determined by checking if the sum of the row index (i) and column index (j) is even or odd. If even, the cell is '#', otherwise '.'.
3. **Output Formatting**: After printing each chessboard, output a blank line to separate different datasets.

### Solution Code
```python
def draw_chessboard():
    import sys
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        H, W = map(int, line.split())
        if H == 0 and W == 0:
            break
        for i in range(H):
            row = []
            for j in range(W):
                if (i + j) % 2 == 0:
                    row.append('#')
                else:
                    row.append('.')
            print(''.join(row))
        print()

draw_chessboard()
```

### Explanation
1. **Reading Input**: The code reads each line from standard input. Each line is stripped of leading/trailing whitespace and split into integers H and W.
2. **Termination Condition**: If both H and W are zero, the loop terminates.
3. **Chessboard Generation**: For each row index i from 0 to H-1, a row is constructed by iterating through each column index j from 0 to W-1. The cell at (i, j) is '#' if (i + j) is even, otherwise it is '.'.
4. **Output**: Each row of the chessboard is printed as a string. After all rows of a dataset are printed, an additional blank line is printed to separate datasets.

This approach efficiently constructs the required pattern using nested loops and modular arithmetic, ensuring the correct alternation of characters. The solution handles multiple datasets and adheres to the specified formatting requirements.
