To solve this problem, we need to determine the middle three characters of a given string of odd length. If the string's length is less than 3, we should output 0. The solution involves checking the string length and extracting the appropriate substring based on the calculated middle index.

### Approach
1. **Read Input**: Read the input string from standard input.
2. **Check Length**: If the string's length is less than 3, output 0.
3. **Calculate Middle Index**: For strings of length 3 or more, compute the starting index of the middle three characters. This is done by finding the middle index of the string and adjusting it to get the start of the three-character substring.
4. **Extract Substring**: Extract the substring starting from the calculated index and spanning three characters.
5. **Output Result**: Print the extracted substring.

### Solution Code
```python
def middle_string():
    s = input().strip()
    if len(s) < 3:
        print(0)
    else:
        mid_start = (len(s) // 2) - 1
        print(s[mid_start : mid_start + 3])

middle_string()
```

### Explanation
- **Reading Input**: The input string is read and stripped of any leading or trailing whitespace.
- **Length Check**: If the string length is less than 3, the function immediately prints 0.
- **Middle Index Calculation**: For valid strings (length ≥ 3), the middle index is calculated as `(len(s) // 2) - 1`. This gives the starting index of the middle three characters.
- **Substring Extraction**: Using string slicing, the substring starting from the calculated index and spanning three characters is extracted and printed.

This approach efficiently handles the problem requirements and ensures the correct output is produced for both valid and invalid input lengths.
