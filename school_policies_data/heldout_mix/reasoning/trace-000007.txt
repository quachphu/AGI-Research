The Fenwick Tree needs to support:

- Initialization with all elements 1 to n.

- Querying the sum up to x.

- Updating the tree by subtracting x (removing x by setting its contribution to 0).

So, the Fenwick Tree will track the sum of elements present. Initially, each element x has a value of x. When x is removed, the value at position x is set to 0.

The Fenwick Tree is 1-based.

Here's the code:

class FenwickTree:
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (self.n + 1)
        # Initialize the tree with each x present.
        for x in range(1, self.n + 1):
            self.update(x, x)
    
    def update(self, idx, delta):
        # Update the tree by adding delta at position idx.
        # To remove x, delta would be -x.
        while idx <= self.n:
            self.tree[idx] += delta
            idx += idx & -idx
    
    def query(self, idx):
        # Return the sum from 1 to idx.
        res = 0
        while idx > 0:
            res += self.tree[idx]
            idx -= idx & -idx
        return res

To solve this problem, we need to reconstruct a permutation of integers from 1 to n given an array s, where each element s_i represents the sum of all preceding elements in the permutation that are smaller than the i-th element. The solution involves efficiently determining each element of the permutation using a combination of binary search and a Fenwick Tree (Binary Indexed Tree) to maintain and query sums dynamically.

### Approach
1. **Reverse Processing**: Process the array s from the end to the beginning. This allows us to use a Fenwick Tree to efficiently track the sum of elements and determine the correct element for each position in the permutation.
2. **Fenwick Tree**: Use a Fenwick Tree to maintain the sum of elements that are still available to be placed in the permutation. This helps in efficiently querying the sum of elements less than a given value.
3. **Binary Search**: For each element in the reversed s array, use binary search to find the largest possible element such that the sum of elements less than it matches the given s_i value. This ensures we correctly place each element in the permutation.

class FenwickTree:
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (self.n + 2)  # Using 1-based indexing

    def update_point(self, idx, value):
        # Update the Fenwick Tree by adding 'value' at position 'idx'
        while idx <= self.n:
            self.tree[idx] += value
            idx += idx & -idx

    def query_prefix(self, idx):
        # Query the sum from 1 to 'idx' (inclusive)
        res = 0
        while idx > 0:
            res += self.tree[idx]
            idx -= idx & -idx
        return res

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    s = list(map(int, input[1:n+1]))
    
    s_reversed = s[::-1]
    ft = FenwickTree(n)
    
    # Initialize Fenwick Tree with all elements 1 to n
    for x in range(1, n+1):
        ft.update_point(x, x)
    
    permutation = []
    
    for si in s_reversed:
        low = 1
        high = n
        ans = -1
        while low <= high:
            mid = (low + high) // 2
            current_sum = ft.query_prefix(mid - 1)
            if current_sum == si:
                ans = mid
                low = mid + 1
            elif current_sum < si:
                low = mid + 1
            else:
                high = mid - 1
        
        # Verify that ans is present
        sum_ans = ft.query_prefix(ans) - ft.query_prefix(ans - 1)
        if sum_ans == ans:
            permutation.append(ans)
            ft.update_point(ans, -ans)
        else:
            # This should not happen as per problem statement
            pass
    
    # Reverse to get the correct permutation
    permutation = permutation[::-1]
    print(' '.join(map(str, permutation)))
