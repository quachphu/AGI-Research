To solve this problem, we need to determine if it's possible to distribute four bags of candies between two friends such that both friends receive the same total number of candies. 

### Approach
1. **Check Total Sum Parity**: First, we check if the total number of candies is even. If it's odd, it's impossible to split them equally, so we immediately return "NO".
2. **Subset Sum Check**: If the total is even, we then check if there exists any non-empty subset of the bags that sums to exactly half of the total. This involves checking all possible subsets of the four bags (excluding the full set) to see if any of them meet the required sum.

### Solution Code
```python
a = list(map(int, input().split()))
total = sum(a)
if total % 2 != 0:
    print("NO")
else:
    target = total // 2
    found = False
    for mask in range(1, 15):  # Check all subsets except full set (mask 15)
        s = 0
        for i in range(4):
            if mask & (1 << i):
                s += a[i]
        if s == target:
            found = True
            break
    print("YES" if found else "NO")
```

### Explanation
1. **Input Reading and Sum Calculation**: The input is read as a list of integers. We compute the total sum of these integers.
2. **Parity Check**: If the total sum is odd, we print "NO" because an odd total cannot be split into two equal integer parts.
3. **Subset Sum Check**: If the total sum is even, we calculate the target sum (half of the total). We then use bit masking to generate all possible non-empty subsets of the four bags (excluding the full set). For each subset, we check if its sum matches the target. If any subset meets the target, we print "YES"; otherwise, we print "NO".

This approach efficiently checks all possible distributions using bitwise operations, ensuring we explore every possible way to split the candies between the two friends. The complexity is manageable due to the small fixed size of the input (four elements), making this approach both feasible and optimal.
