To solve this problem, we need to find the shortest possible "good" string such that all given strings in the set are the most frequent substrings. The solution must ensure that the good string is lexicographically smallest if multiple valid solutions exist.

### Approach
1. **Check for Duplicate Characters**: Each input string must consist of unique characters. If any string contains duplicate characters, it's impossible to form a valid good string.
2. **Build a Directed Graph**: Construct a graph where each node represents a character and edges represent consecutive characters in the input strings. This helps in determining the order of characters in the good string.
3. **Check for Conflicts and Cycles**: Ensure there are no conflicting edges (indicating multiple possible next characters) and no cycles in the graph.
4. **Collect Chains**: Identify all chains of characters from the graph. Each chain represents a sequence of characters that must appear consecutively.
5. **Validate Substrings**: Verify that each input string is a contiguous substring of one of the collected chains.
6. **Construct the Result**: Sort the chains lexicographically and concatenate them to form the shortest and lexicographically smallest good string.

### Solution Code
```python
n = int(input())
strings = [input().strip() for _ in range(n)]

# Check if any string has duplicate characters
for s in strings:
    if len(set(s)) != len(s):
        print("NO")
        exit()

from collections import defaultdict

pred = dict()
succ = dict()

# Build the successor and predecessor dictionaries
for s in strings:
    for i in range(len(s) - 1):
        a = s[i]
        b = s[i+1]
        if a in succ:
            if succ[a] != b:
                print("NO")
                exit()
        if b in pred:
            if pred[b] != a:
                print("NO")
                exit()
        succ[a] = b
        pred[b] = a

visited = set()
chains = []

# Collect all possible start nodes (nodes without a predecessor)
all_chars = set()
for s in strings:
    all_chars.update(s)

# Function to detect cycles and build chains
def build_chain(start):
    chain = []
    current = start
    while True:
        if current in visited:
            return None  # cycle detected
        visited.add(current)
        chain.append(current)
        if current not in succ:
            break
        next_char = succ[current]
        if next_char in visited:
            return None  # cycle detected
        current = next_char
    return chain

# Iterate over all characters to find start nodes (those without a predecessor)
for char in all_chars:
    if char not in pred and char not in visited:
        chain = build_chain(char)
        if chain is None:
            print("NO")
            exit()
        chains.append(chain)

# Check for any remaining characters not visited (part of cycles)
for char in all_chars:
    if char not in visited:
        # Check if it's a single node cycle (no pred or succ)
        if char in succ or char in pred:
            print("NO")
            exit()
        else:
            chains.append([char])
            visited.add(char)

# Now check if each string is a substring of any chain
for s in strings:
    found = False
    s_str = s
    for chain in chains:
        chain_str = ''.join(chain)
        if s_str in chain_str:
            found = True
            break
    if not found:
        print("NO")
        exit()

# Sort the chains lex order by their first character
chains.sort(key=lambda x: x[0])

# Concatenate the chains
result = ''.join(''.join(chain) for chain in chains)
print(result)
```
