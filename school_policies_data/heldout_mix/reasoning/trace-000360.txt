To solve this problem, we need to categorize the ages of visitors to Tsuruga Castle into specific age groups and count the number of visitors in each group for multiple datasets. The solution must efficiently handle large input sizes and multiple datasets until a termination condition is met.

### Approach
1. **Reading Input Efficiently**: Read all input data at once using `sys.stdin.read()` for efficiency, especially with large datasets.
2. **Processing Each Dataset**: For each dataset, determine the number of visitors and their ages. Use an array to count the number of visitors in each age group.
3. **Categorization Logic**: Use integer division to determine the age group for each visitor. Visitors aged 60 and above are grouped separately.
4. **Output the Results**: After processing each dataset, output the counts for each age group in the specified order.

### Solution Code
```python
import sys

def main():
    tokens = list(map(int, sys.stdin.read().split()))
    i = 0
    while i < len(tokens):
        n = tokens[i]
        if n == 0:
            break
        i += 1
        ages = tokens[i:i + n]
        i += n
        counts = [0] * 7
        for a in ages:
            if a >= 60:
                counts[6] += 1
            else:
                counts[a // 10] += 1
        for count in counts:
            print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of integers for efficient processing.
2. **Dataset Processing**: Each dataset starts with an integer `n` indicating the number of visitors. The subsequent `n` integers are the ages of the visitors.
3. **Categorization**: Each age is categorized using integer division. For example, ages 0-9 are categorized by `a // 10` which gives 0, and ages 10-19 give 1, etc. Ages 60 and above are directly assigned to the last category.
4. **Output**: After processing all ages in a dataset, the counts for each age group are printed in the specified order.

This approach ensures efficient handling of large datasets and meets the problem constraints effectively.
