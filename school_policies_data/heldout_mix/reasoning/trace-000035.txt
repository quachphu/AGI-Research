To solve this problem, we need to determine the number of distinct substrings of a given string S that contain another string T as a substring. 

### Approach
1. **Generate Substrings**: For each starting index in S, generate all possible substrings starting from that index to the end of the string. This will cover all possible consecutive character sequences in S.
2. **Remove Duplicates**: Use a set to store these substrings to automatically handle duplicates, ensuring each substring is considered only once.
3. **Check for Substring T**: For each distinct substring, check if it contains the string T. Count how many such substrings exist.

### Solution Code
```python
def main():
    import sys
    s, t = sys.stdin.read().split()
    substrs = set()
    len_s = len(s)
    for i in range(len_s):
        for j in range(i + 1, len_s + 1):
            substr = s[i:j]
            substrs.add(substr)
    count = 0
    for substr in substrs:
        if t in substr:
            count += 1
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input and split into two strings, S and T.
2. **Generating Substrings**: Using nested loops, we generate all possible substrings of S. The outer loop iterates over each starting index, and the inner loop generates substrings from each starting index to every possible end index.
3. **Storing Unique Substrings**: By adding each generated substring to a set, we ensure that only unique substrings are considered.
4. **Checking for T**: Each unique substring is checked to see if it contains T. If it does, it is counted towards the result.

This approach efficiently handles the constraints and ensures that we only process each substring once, making the solution both time and space efficient for the given input limits.
