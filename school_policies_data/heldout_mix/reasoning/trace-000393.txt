To solve this problem, we need to represent a given positive integer \( n \) as a sum of the minimum number of quasibinary numbers. A quasibinary number is defined as a number that contains only the digits 0 and 1. The key insight here is that the minimum number of quasibinary numbers required is determined by the maximum digit in the given number \( n \).

### Approach
1. **Identify the Maximum Digit**: The maximum digit in \( n \) determines the minimum number of quasibinary numbers needed. For example, if \( n \) is 32, the maximum digit is 3, so we need 3 quasibinary numbers.
2. **Construct Quasibinary Numbers**: For each position (digit) in \( n \), distribute the value of the digit across the quasibinary numbers. Each quasibinary number will have a 1 in positions where the sum of the digits at that position across all quasibinary numbers equals the original digit, and 0 otherwise.

### Solution Code
```python
n = input().strip()
digits = list(n)
max_digit = max(int(c) for c in digits)
k = max_digit
result = []

for i in range(1, k + 1):
    qb = []
    for c in digits:
        d = int(c)
        qb.append('1' if d >= i else '0')
    num = int(''.join(qb))  # Removes leading zeros automatically
    result.append(num)

print(k)
print(' '.join(map(str, result)))
```

### Explanation
1. **Reading Input**: The input number \( n \) is read as a string to process each digit individually.
2. **Determine Maximum Digit**: The maximum digit in \( n \) is found, which gives the minimum number of quasibinary numbers required (\( k \)).
3. **Constructing Quasibinary Numbers**: For each index from 1 to \( k \), we construct a quasibinary number by checking each digit of \( n \). If the digit is greater than or equal to the current index, we place a 1 in that position; otherwise, we place a 0. This ensures that each digit in \( n \) is covered by the sum of the corresponding positions in the quasibinary numbers.
4. **Output**: The result is printed, which includes the number of quasibinary numbers and the numbers themselves.

This approach efficiently constructs the required quasibinary numbers by leveraging the maximum digit to determine the number of terms and distributing the digits appropriately across these terms.
