1. **Dynamic Programming (DP) Setup**:
   - Use a DP array where `dp[i][j]` represents the number of ways to distribute `j` candies among the first `i` children.
   - Initialize the DP array with `dp[0][0] = 1` (one way to distribute 0 candies to 0 children).

2. **Prefix Sum Optimization**:
   - For each child, compute the prefix sum array of the previous DP state to efficiently calculate the sum of valid distributions for the current child.
   - The prefix sum array allows us to compute the sum of values in a subarray in constant time, reducing the time complexity from \(O(N \times K^2)\) to \(O(N \times K)\).

3. **Transition Between States**:
   - For each child, iterate over all possible candy sums up to K. For each possible sum `j`, calculate the valid range of candies the current child can receive using the prefix sum array to update the current DP state.

### Solution Code
```python
MOD = 10**9 + 7

n, k = map(int, input().split())
a = list(map(int, input().split()))

prev = [0] * (k + 1)
prev[0] = 1  # Base case: 0 candies distributed to 0 children

for ai in a:
    # Compute prefix sum of the previous DP state
    prefix = [0] * (k + 2)
    for i in range(1, k + 2):
        prefix[i] = (prefix[i - 1] + prev[i - 1]) % MOD
    
    # Calculate current DP state using the prefix sum
    curr = [0] * (k + 1)
    for j in range(k + 1):
        l = max(0, j - ai)
        sum_val = (prefix[j + 1] - prefix[l]) % MOD
        curr[j] = sum_val
    prev = curr

print(prev[k] % MOD)
```

### Explanation
1. **Initialization**:
   - Start with an array `prev` initialized to 0, except `prev[0]` which is 1, representing the base case of distributing 0 candies.

2. **Prefix Sum Calculation**:
   - For each child, compute the prefix sum array of the previous DP state. This array helps quickly compute the sum of distributions for valid candy counts.

3. **DP State Transition**:
   - For each possible number of candies `j` up to K, determine the valid range of candies the current child can receive using the prefix sum array. Update the current DP state based on the valid range from the previous state.

4. **Result Calculation**:
   - After processing all children, the result is found in `prev[k]`, which gives the number of ways to distribute exactly K candies among all children modulo \(10^9 + 7\).

This approach efficiently handles the constraints by leveraging dynamic programming and prefix sums, ensuring optimal performance even for large values of K and N.
