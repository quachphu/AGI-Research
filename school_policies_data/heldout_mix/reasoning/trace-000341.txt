To solve this problem, we need to determine the smallest positive integer that contains at least one digit from each of two given lists of non-zero digits. This integer must have digits from both lists, and we aim to find the smallest such number.

### Approach
1. **Check for Common Digits**: First, check if there are any common digits between the two lists. If there are, the smallest common digit is the answer since a single-digit number is the smallest possible integer.
2. **Generate Two-Digit Numbers**: If there are no common digits, generate all possible two-digit numbers by combining each digit from the first list with each digit from the second list in both possible orders (e.g., digit `a` from the first list followed by digit `b` from the second list, and vice versa). The smallest of these two-digit numbers is the solution.

### Solution Code
```python
n, m = map(int, input().split())
a = set(map(int, input().split()))
b = set(map(int, input().split()))

common = a & b
if common:
    print(min(common))
else:
    min_val = float('inf')
    for x in a:
        for y in b:
            num1 = x * 10 + y
            num2 = y * 10 + x
            min_val = min(min_val, num1, num2)
    print(min_val)
```

### Explanation
1. **Reading Input**: The input consists of two lists of digits. We read these lists into sets for efficient lookup operations.
2. **Check Common Digits**: Using set intersection, we check if there are any digits common to both lists. If there are, the smallest of these common digits is printed immediately.
3. **Generate Two-Digit Numbers**: If no common digits exist, we generate all possible two-digit numbers by combining each digit from the first list with each digit from the second list in both possible orders. We then find the smallest of these numbers and print it.

This approach ensures that we efficiently determine the smallest valid integer by leveraging set operations and exhaustive generation of possible two-digit combinations when necessary.
