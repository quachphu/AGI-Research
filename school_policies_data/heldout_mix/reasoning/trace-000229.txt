To solve this problem, we need to determine the number of winning squares on an n x n grid where a square is considered winning if the sum of its column is strictly greater than the sum of its row.

### Approach
1. **Read Input**: First, read the integer `n` which represents the size of the grid. Then read the next `n` lines containing the grid values.
2. **Compute Row Sums**: Calculate the sum of each row in the grid.
3. **Compute Column Sums**: Calculate the sum of each column in the grid.
4. **Count Winning Squares**: For each cell in the grid, check if the sum of its column is greater than the sum of its row. If true, increment the count of winning squares.

### Solution Code
```python
n = int(input())
grid = [list(map(int, input().split())) for _ in range(n)]
row_sums = [sum(row) for row in grid]
column_sums = [sum(row[j] for row in grid) for j in range(n)]
count = 0
for i in range(n):
    rs = row_sums[i]
    for j in range(n):
        if column_sums[j] > rs:
            count += 1
print(count)
```

### Explanation
1. **Reading Input**: The input is read and stored in a 2D list `grid` where each element represents the value at a specific row and column.
2. **Row Sums Calculation**: Using a list comprehension, we calculate the sum of each row in the grid.
3. **Column Sums Calculation**: Using another list comprehension, we calculate the sum of each column by iterating over each column index and summing the values from each row at that column index.
4. **Counting Winning Squares**: We iterate over each cell in the grid. For each cell, we compare the sum of its column with the sum of its row. If the column sum is greater, we increment the count.

This approach efficiently computes the required sums and checks each cell in linear time relative to the grid size, ensuring optimal performance even for the maximum grid size of 30x30.
