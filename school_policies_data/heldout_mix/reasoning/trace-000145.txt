To solve this problem, we need to determine the number of ways in which N distinct persons can either pair up or remain single, considering that each person can pair up with at most one other person. The solution must efficiently handle large values of N up to 1,000,000 and multiple test cases up to 100,000.

### Approach
1. **Recurrence Relation**: The problem can be broken down using a recurrence relation. Let `f(n)` represent the number of ways to pair `n` persons. The relation is:
   - `f(n) = f(n-1) + (n-1) * f(n-2)`
   - This relation comes from considering two scenarios: the nth person remains single (leading to `f(n-1)` ways) or pairs with any of the remaining `n-1` persons (leading to `(n-1) * f(n-2)` ways).

2. **Precomputation**: Given the constraints, we precompute the values for all possible N up to 1,000,000 using dynamic programming. This allows us to answer each query in constant time O(1).

3. **Modulo Operation**: Since the results can be very large, each value is computed modulo `10^9 + 7` to prevent overflow and ensure efficient computation.

### Solution Code
```python
import sys

MOD = 10**9 + 7

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    cases = list(map(int, input[1:T+1]))
    
    max_n = 10**6  # As per the problem constraints
    dp = [0] * (max_n + 1)
    dp[0] = 1
    if max_n >= 1:
        dp[1] = 1
    for i in range(2, max_n + 1):
        dp[i] = (dp[i-1] + (i-1) * dp[i-2]) % MOD
    
    results = []
    for n in cases:
        results.append(dp[n])
    
    print('\n'.join(map(str, results)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the large number of test cases.
2. **Dynamic Programming Array Initialization**: We initialize an array `dp` where `dp[i]` will store the number of ways for `i` persons.
3. **Base Cases**: The base cases `dp[0] = 1` (no persons) and `dp[1] = 1` (one person remains single) are set.
4. **Filling the DP Array**: Using the recurrence relation, we fill the `dp` array up to the maximum possible value (1,000,000). Each entry is computed modulo `10^9 + 7`.
5. **Query Handling**: For each test case, the precomputed result is retrieved from the `dp` array and printed.

This approach ensures that even for the upper limits of input constraints, the solution remains efficient and responsive.
