To solve this problem, we need to determine the maximum number of non-overlapping events that can be scheduled in a stadium. The goal is to allocate the stadium such that the maximum number of events can be held without any overlap.

### Approach
The optimal strategy for this type of interval scheduling problem is to use a greedy algorithm. The key idea is to select events that end the earliest first, which allows us to fit more events into the schedule. Here's the step-by-step approach:

1. **Calculate End Times**: For each event, compute the end time as the start time plus the duration minus one (since the start day is inclusive).
2. **Sort Events**: Sort the events based on their end times in ascending order. If two events end at the same time, the one that starts earlier will be considered first.
3. **Select Non-Overlapping Events**: Iterate through the sorted list of events and select each event if it starts after the end time of the previously selected event. Keep track of the count of such events.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    events = []
    for _ in range(n):
        s, d = map(int, sys.stdin.readline().split())
        end = s + d - 1
        events.append((end, s))
    events.sort()
    count = 0
    last_end = 0
    for end, s in events:
        if s > last_end:
            count += 1
            last_end = end
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first line gives the number of events, followed by each event's start day and duration.
2. **Calculating End Times**: For each event, the end time is calculated as the start day plus the duration minus one. This accounts for the inclusive nature of the start day.
3. **Sorting Events**: The events are sorted based on their end times to facilitate the greedy selection of the earliest ending events.
4. **Greedy Selection**: By iterating through the sorted list, we select each event if it starts after the end time of the last selected event. This ensures no overlaps and maximizes the number of events that can be scheduled.

This approach efficiently finds the maximum number of non-overlapping events using sorting and a linear scan, resulting in a time complexity of O(N log N) due to the sorting step, which is optimal for the given constraints.
