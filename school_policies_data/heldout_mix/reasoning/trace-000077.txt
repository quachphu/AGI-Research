To solve this problem, we need to determine the initial bet each player made in a game called "Generosity" based on the number of coins each player has at the end of the game. The key insight is that the total number of coins remains constant throughout the game, allowing us to derive the initial bet from the sum of the final coins.

### Approach
1. **Sum Calculation**: Calculate the total number of coins from the given final counts of the five players.
2. **Divisibility Check**: Check if this total is divisible by 5. If not, the initial bet cannot be determined, and we return -1.
3. **Non-Zero Check**: Ensure the total is non-zero. If the total is zero, it implies the initial bet was zero, which is invalid, so we return -1.
4. **Compute Initial Bet**: If the total is a valid non-zero multiple of 5, the initial bet for each player is the total divided by 5.

### Solution Code
```python
def main():
    c = list(map(int, input().split()))
    total = sum(c)
    if total == 0 or total % 5 != 0:
        print(-1)
    else:
        print(total // 5)

main()
```

### Explanation
1. **Sum Calculation**: The sum of the final coins (c1, c2, c3, c4, c5) is computed. This sum must equal 5 times the initial bet since each player starts with the same number of coins.
2. **Divisibility Check**: The sum must be divisible by 5 to ensure that the initial bet is an integer. If not divisible, output -1.
3. **Non-Zero Check**: A sum of zero would mean the initial bet was zero, which is invalid. Hence, output -1 in this case.
4. **Initial Bet Calculation**: If the sum passes the checks, the initial bet is the sum divided by 5, which is printed as the result.

This approach efficiently determines the initial bet or identifies an invalid scenario using basic arithmetic checks, ensuring optimal performance.
