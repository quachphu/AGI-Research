```python
def main():
    perm = [0] * 16
    for _ in range(17):
        line = sys.stdin.readline().strip()
        if line == 'ELEMENT':
            data = sys.stdin.readline().split()
            i = int(data[0]) - 1  # Convert to 0-based index
            val = int(data[1])
            perm[i] = val
            print(val)
        elif line == 'PERMUTATION':
            print(' '.join(map(str, perm)))

if __name__ == "__main__":
    main()
```

### Explanation
- **Initialization**: The permutation list `perm` is initialized to hold 16 zeros, corresponding to the elements of the permutation.
- **Reading Test Cases**: The loop runs exactly 17 times, once for each test case. Each iteration processes one test case.
  - **ELEMENT Handling**: For each "ELEMENT" test case, the index and value are read, the value is stored in the correct position of the permutation list, and the value is printed.
  - **PERMUTATION Handling**: When encountering the "PERMUTATION" test case, the entire permutation list is printed as a space-separated string.
- **Efficiency**: This approach efficiently processes each test case in linear time, ensuring that all elements are collected and the permutation is output correctly when required. The solution handles input and output operations directly, ensuring compatibility with standard programming competition input formats.
