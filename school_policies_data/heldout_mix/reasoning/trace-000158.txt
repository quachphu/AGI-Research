To solve this problem, we need to calculate the total distance walked when turning off N+1 lights arranged in a line. The process involves alternating between turning off the rightmost and leftmost on lights until all are off. The goal is to determine the total distance walked during this process efficiently.

### Approach
The key insight is to recognize a pattern in the distance walked. By analyzing several cases, we observe that the total distance can be computed using a mathematical formula derived from the sum of a series. The formula for the total distance walked when turning off all lights is given by:

\[ \text{Total Distance} = \frac{(N+1)(N+2)}{2} - 1 \]

This formula efficiently calculates the sum of distances for each step in the process, avoiding the need for iterative simulation of each movement. The approach leverages arithmetic series properties to ensure optimal performance even for large values of N.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    results = []
    for n_str in input[1:T+1]:
        N = int(n_str)
        res = (N + 1) * (N + 2) // 2 - 1
        results.append(res)
    print('\n'.join(map(str, results)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once using `sys.stdin.read()` to handle large input sizes efficiently. This is split into a list of strings for processing.
2. **Formula Application**: For each test case, we compute the total distance using the formula \((N + 1)(N + 2) // 2 - 1\). This formula is derived from summing the series of distances walked during each step of turning off the lights.
3. **Output Handling**: The results for all test cases are collected in a list and printed at once to minimize I/O operations, which is crucial for handling up to \(10^5\) test cases efficiently.

This approach ensures that the solution runs in linear time relative to the number of test cases, making it highly efficient and suitable for the given constraints.
