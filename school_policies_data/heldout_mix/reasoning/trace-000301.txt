To solve this problem, we need to determine the number of pairs (l, r) such that the sum of candies from the l-th to the r-th box is divisible by M. The solution leverages prefix sums and modular arithmetic to efficiently count these pairs in linear time.

### Approach
1. **Prefix Sum and Modulo Operation**: Compute the prefix sum modulo M for each position in the array. This helps in determining if the sum of any subarray (from index l to r) is divisible by M.
2. **Frequency Dictionary**: Use a dictionary to keep track of the frequency of each remainder obtained from the prefix sums modulo M. This allows us to efficiently count how many times each remainder has occurred.
3. **Counting Valid Pairs**: For each element in the array, update the current prefix sum modulo M and check how many times this remainder has been seen before. The count of previous occurrences of the same remainder gives the number of valid subarrays ending at the current position.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    input = sys.stdin.read().split()
    N = int(input[0])
    M = int(input[1])
    A = list(map(int, input[2:2+N]))
    
    mod_counts = defaultdict(int)
    mod_counts[0] = 1
    current_mod = 0
    result = 0
    
    for a in A:
        current_mod = (current_mod + a) % M
        result += mod_counts[current_mod]
        mod_counts[current_mod] += 1
    
    print(result)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input and parsed into integers N, M, and the array A.
2. **Initialization**: A dictionary `mod_counts` is initialized to keep track of the frequency of each remainder. The initial count for remainder 0 is set to 1 to handle cases where the prefix sum itself is divisible by M.
3. **Iterating Through Array**: For each element in the array, the current prefix sum modulo M is updated. The number of times this remainder has been seen before is added to the result, as each occurrence indicates a valid subarray.
4. **Updating Frequency**: The count for the current remainder is incremented in the dictionary to include the current prefix sum.

This approach ensures that we efficiently count valid pairs in linear time, making it suitable for large input sizes as specified in the problem constraints.
