To solve this problem, we need to determine how many questions AOR Ika-chan can mark before she faints due to encountering two consecutive incorrect answers ('x'). The solution involves iterating through the string of answers and checking for consecutive 'x' characters, stopping immediately when they are found.

### Approach
1. **Initialization**: Read the number of questions and the string representing the correctness of answers.
2. **Iteration**: Loop through each character in the string while keeping track of the previous character.
3. **Check for Consecutive 'x'**: For each character, check if it and the previous character are both 'x'. If they are, stop processing immediately.
4. **Count Valid Marks**: Keep a count of the valid marks written before encountering two consecutive 'x' characters.

### Solution Code
```python
n = int(input())
s = input().strip()

prev = None
count = 0

for c in s:
    if prev == 'x' and c == 'x':
        break
    count += 1
    prev = c

print(count)
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` (number of questions) and a string `s` of length `n` containing 'o' (correct) and 'x' (incorrect).
2. **Loop Through Answers**: For each character in the string, check if the current and previous characters are both 'x'. If they are, the loop breaks immediately.
3. **Update Count**: If the current character does not form two consecutive 'x's with the previous one, increment the count of valid marks and update the previous character.
4. **Output Result**: Print the count of valid marks after processing stops either due to finding consecutive 'x's or reaching the end of the string.

This approach efficiently processes each answer in linear time, ensuring that we stop as soon as the condition for fainting is met, leading to an optimal solution.
