To solve this problem, we need to determine how much honey Piglet will receive after Winnie-the-Pooh has finished eating from all the jars. Winnie-the-Pooh eats honey by always choosing the jar with the most honey, eating exactly `k` kilos each time, until the jar either has less than `k` kilos left or he has eaten from it three times. At that point, Piglet gets the remaining honey from the jar.

### Approach
1. **Data Structure**: Use a max-heap (priority queue) to efficiently retrieve the jar with the most honey each time. In Python, we can simulate a max-heap using a min-heap by storing negative values.
2. **Processing Jars**: For each jar, track the current amount of honey and the number of times Winnie has eaten from it. If a jar has less than `k` kilos left or has been eaten from three times, add the remaining honey to Piglet's total. Otherwise, subtract `k` kilos, increment the eat count, and push the jar back into the heap.
3. **Termination**: Continue processing until all jars have been given to Piglet.

### Solution Code
```python
import heapq

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    k = int(input[1])
    a = list(map(int, input[2:2+n]))
    
    heap = []
    for num in a:
        heapq.heappush(heap, (-num, 0))  # Using max-heap via negation
    
    piglet = 0
    while heap:
        neg_amt, cnt = heapq.heappop(heap)
        current = -neg_amt
        if current < k or cnt >= 3:
            piglet += current
        else:
            current -= k
            cnt += 1
            heapq.heappush(heap, (-current, cnt))
    print(piglet)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of jars `n`, the amount `k` Winnie eats each time, and the list of honey amounts in each jar.
2. **Max-Heap Initialization**: Each jar's initial honey amount is stored in the heap as a negative value to simulate a max-heap.
3. **Processing Each Jar**: The loop continues until all jars are processed. For each jar:
   - If the jar has less than `k` kilos left or has been eaten from three times, the remaining honey is added to Piglet's total.
   - Otherwise, `k` kilos are subtracted from the jar, the eat count is incremented, and the jar is pushed back into the heap.
4. **Output**: The total amount of honey Piglet receives is printed.

This approach ensures that we efficiently always process the jar with the most honey next, using a heap to maintain the order, and correctly tracks the remaining honey and eat counts to determine when each jar should be given to Piglet.
