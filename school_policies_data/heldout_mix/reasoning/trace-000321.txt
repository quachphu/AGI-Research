        while self.n < size:
            self.n <<=1
        self.size = size

To solve this problem, we need to determine the maximum possible value of the MEX (Minimum Excluded Value) of an array after each query. Each query appends an element to the array, and we can adjust each element by adding or subtracting a given integer \( x \) any number of times, provided the element remains non-negative.

### Approach
1. **Understanding MEX with Adjustments**: The key insight is that each element's remainder when divided by \( x \) determines the possible values it can be adjusted to. For example, if \( x = 3 \), an element with remainder 0 can be adjusted to 0, 3, 6, etc.
2. **Track Remainder Counts**: For each possible remainder (from 0 to \( x-1 \)), track how many times each remainder appears in the array. This helps in determining the coverage of values from 0 upwards.
3. **Efficient MEX Calculation**: The MEX is determined by the smallest value that cannot be formed using the available remainders. For each remainder \( r \), the values it can cover are \( r, r + x, r + 2x, \ldots \). The MEX is the smallest value where the required coverage is missing.

### Solution Code
```python
import heapq

class SegmentTree:
    def __init__(self, size):
        self.n = 1
        while self.n < size:
            self.n <<= 1
        self.size = size
        self.tree = [float('inf')] * (2 * self.n)
        # Initialize leaves
        for i in range(size):
            self.tree[self.n + i] = i
        # Build the tree
        for i in range(self.n - 1, 0, -1):
            self.tree[i] = min(self.tree[2 * i], self.tree[2 * i + 1])
    
    def update(self, idx, value):
        idx += self.n
        self.tree[idx] = value
        idx >>= 1
        while idx >= 1:
            new_val = min(self.tree[2 * idx], self.tree[2 * idx + 1])
            if self.tree[idx] == new_val:
                break
            self.tree[idx] = new_val
            idx >>= 1
    
    def get_min(self):
        return self.tree[1] if self.tree[1] != float('inf') else float('inf')

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    q = int(input[ptr])
    ptr += 1
    x = int(input[ptr])
    ptr += 1
    
    counts = [0] * x
    seg_tree = SegmentTree(x)
    heap = []
    
    for _ in range(q):
        y = int(input[ptr])
        ptr += 1
        s = y % x
        
        if counts[s] == 0:
            seg_tree.update(s, float('inf'))
            heapq.heappush(heap, (s + x, s))
            counts[s] = 1
        else:
            new_term = s + x * (counts[s] + 1)
            heapq.heappush(heap, (new_term, s))
            counts[s] += 1
        
        min_zero = seg_tree.get_min()
        
        # Find minimal valid positive term
        while heap:
            current_term, current_s = heap[0]
            expected_term = current_s + x * counts[current_s]
            if current_term == expected_term:
                break
            heapq.heappop(heap)
        min_positive = heap[0][0] if heap else float('inf')
        
        mex = min(min_zero, min_positive)
        print(mex)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Segment Tree**: Used to efficiently track the smallest remainder that has not been added to the array (count remains zero). This helps in quickly determining the smallest value that cannot be covered by the current elements.
2. **Min-Heap**: Maintains the smallest values formed by the remainders and their counts. This allows efficient retrieval of the smallest value that can be covered by the current elements.
3. **Updating Counts**: Each time a new element is added, its remainder is calculated. The segment tree and heap are updated to reflect the new state, ensuring that the MEX is computed efficiently after each query.

This approach ensures that each query is processed in \( O(\log x) \) time, making the solution efficient even for large input sizes.
