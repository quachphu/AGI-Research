To solve this problem, we need to determine the winner of a game played between Ashish and Utkarsh on a 2D plane. The game involves moving a token from (0,0) by increasing either the x or y coordinate by exactly k units each turn, while ensuring the token remains within a Euclidean distance d from the origin. The player who cannot make a move loses. Ashish moves first, and both players play optimally.

### Approach
1. **Understanding the Game Mechanics**: The token can only move in increments of k units. The game ends when a player cannot move without exceeding the allowed distance from the origin. The key is to determine the maximum number of moves (m) possible before the game ends.
2. **Mathematical Insight**: The maximum number of moves (m) is determined by the largest integer such that the token's position (p, q) after m moves (with p and q being multiples of k) satisfies p² + q² ≤ d². This translates to finding the maximum m where the minimal sum of squares (a² + b²) for a and b (non-negative integers summing to m) is within the allowed distance.
3. **Binary Search for Maximum Moves**: Using binary search, we efficiently determine the maximum m where the minimal sum of squares for m moves is within the allowed distance. The minimal sum for m moves is calculated based on whether m is even or odd.
4. **Determine the Winner**: The parity (even or odd) of the maximum m determines the winner. If m is odd, Ashish wins (since he starts first). If m is even, Utkarsh wins.

### Solution Code
```python
def determine_winner():
    import sys
    input = sys.stdin.read
    data = input().split()
    t = int(data[0])
    index = 1
    for _ in range(t):
        d = int(data[index])
        k = int(data[index + 1])
        index += 2
        s_squared = (d * d) / (k * k)
        low = 0
        high = 2 * 10**5  # Upper bound for binary search
        best = 0
        while low <= high:
            mid = (low + high) // 2
            m = mid
            if m % 2 == 0:
                minimal_sum = (m * m) / 2
            else:
                minimal_sum = (m * m + 1) / 2
            if minimal_sum <= s_squared:
                best = m
                low = mid + 1
            else:
                high = mid - 1
        print("Ashish" if best % 2 == 1 else "Utkarsh")

determine_winner()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Loop Through Test Cases**: Each test case processes the values of d and k.
3. **Calculate s_squared**: This represents the squared maximum allowed distance normalized by k.
4. **Binary Search**: The binary search finds the maximum number of moves (m) possible. For each midpoint (mid), the minimal sum of squares is calculated based on whether mid is even or odd.
5. **Determine Winner**: The result of the binary search (best) is checked for parity. If best is odd, Ashish wins; otherwise, Utkarsh wins.

This approach efficiently narrows down the maximum possible moves using binary search, ensuring optimal performance even for large input values.
