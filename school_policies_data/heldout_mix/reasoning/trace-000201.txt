To solve this problem, we need to determine the maximum number of cubes that can be removed by repeatedly removing adjacent red (0) and blue (1) cubes. The key insight is that the maximum number of removable cubes is determined by the minimum count of red and blue cubes, as each removal requires one of each color.

### Approach
1. **Count the Cubes**: First, count the number of red cubes (0s) and blue cubes (1s) in the given string.
2. **Determine the Minimum**: The maximum number of pairs we can form is limited by the smaller count of the two colors. Each pair consists of one red and one blue cube, thus removing two cubes per pair.
3. **Calculate the Result**: Multiply the minimum count by 2 to get the total number of cubes that can be removed.

### Solution Code
```python
s = input().strip()
count0 = s.count('0')
count1 = s.count('1')
print(2 * min(count0, count1))
```

### Explanation
- **Counting Cubes**: The code first counts the occurrences of '0' (red cubes) and '1' (blue cubes) in the input string.
- **Determine Minimum**: The minimum of these two counts gives the maximum number of pairs that can be formed.
- **Result Calculation**: Each pair removes two cubes (one red and one blue), so multiplying the minimum count by 2 gives the total number of cubes removed.

This approach efficiently computes the result in linear time, O(N), where N is the length of the input string, making it suitable for large input sizes up to 100,000 characters.
