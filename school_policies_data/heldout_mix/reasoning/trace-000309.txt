To solve this problem, we need to determine if a given text T contains each of multiple query patterns P_i. The constraints require an efficient solution due to the potential size of T and the number of queries. 

### Approach
The approach involves using a Suffix Automaton (SAM) to preprocess the text T. A Suffix Automaton is a compact data structure that efficiently represents all substrings of a given text. It allows for quick substring checks in linear time relative to the length of the query pattern.

1. **Building the Suffix Automaton**: Construct the SAM for the text T. This structure will be built in linear time relative to the length of T and will allow us to check for any substring in O(m) time, where m is the length of the query pattern.
2. **Query Processing**: For each query pattern, traverse the SAM to check if the pattern exists as a substring in T. This traversal is done in O(m) time per query.

### Solution Code
```python
import sys

class State:
    __slots__ = ['transitions', 'link', 'len']
    def __init__(self):
        self.transitions = {}
        self.link = None
        self.len = 0

def build_suffix_automaton(s):
    initial = State()
    last = initial
    for char in s:
        curr = State()
        curr.len = last.len + 1
        p = last
        while p is not None and char not in p.transitions:
            p.transitions[char] = curr
            p = p.link
        if p is None:
            curr.link = initial
        else:
            q = p.transitions[char]
            if q.len == p.len + 1:
                curr.link = q
            else:
                clone = State()
                clone.len = p.len + 1
                clone.transitions = q.transitions.copy()
                clone.link = q.link
                while p is not None and p.transitions.get(char, None) == q:
                    p.transitions[char] = clone
                    p = p.link
                q.link = clone
                curr.link = clone
        last = curr
    return initial

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = input[ptr].strip()
    ptr += 1
    Q = int(input[ptr])
    ptr += 1
    queries = []
    for _ in range(Q):
        queries.append(input[ptr].strip())
        ptr += 1

    automaton = build_suffix_automaton(T)
    for p in queries:
        current = automaton
        found = True
        for c in p:
            if c in current.transitions:
                current = current.transitions[c]
            else:
                found = False
                break
        print(1 if found else 0)

if __name__ == "__main__":
    main()
```

### Explanation
1. **State Class**: Each state in the SAM has transitions (dictionary mapping characters to other states), a suffix link (reference to another state), and a length (longest substring ending at this state).
2. **Building the SAM**: The automaton is built character by character. For each new character, a new state is created. The algorithm follows suffix links to update transitions and manage state cloning when necessary to ensure the automaton remains compact.
3. **Query Processing**: For each query, the automaton is traversed starting from the initial state. If all characters in the query are successfully followed in the automaton, the pattern exists; otherwise, it does not.

This approach ensures that preprocessing the text T is done in O(n) time, and each query is processed in O(m) time, making it efficient for large inputs.
