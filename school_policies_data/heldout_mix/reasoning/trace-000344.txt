To solve this problem, we need to determine the minimum number of points to remove from a given set such that the diameter of the remaining points does not exceed a specified value \( d \). The diameter is defined as the maximum distance between any two points in the set.

### Approach
1. **Sort the Points**: First, we sort the list of points. This helps in efficiently checking consecutive points to find the largest valid subset.
2. **Sliding Window Technique**: Using a sliding window approach, we check each possible starting point and determine the maximum valid window where the difference between the first and last point in the window does not exceed \( d \). This is done efficiently using binary search to find the farthest valid end point for each starting point.
3. **Calculate Minimum Removals**: The minimum number of points to remove is the total number of points minus the size of the largest valid subset found.

### Solution Code
```python
import bisect

n, d = map(int, input().split())
points = list(map(int, input().split()))
points.sort()
max_size = 0
for i in range(n):
    target = points[i] + d
    j = bisect.bisect_right(points, target) - 1
    current_size = j - i + 1
    if current_size > max_size:
        max_size = current_size
print(n - max_size)
```

### Explanation
1. **Sorting**: By sorting the points, we can leverage the sorted order to efficiently check consecutive points using a sliding window approach.
2. **Binary Search**: For each starting point \( i \), we use binary search (via `bisect_right`) to find the farthest point \( j \) such that the difference between points[j] and points[i] does not exceed \( d \). This gives the maximum valid window starting at \( i \).
3. **Max Subset Size**: We keep track of the maximum window size found. The minimum number of points to remove is the total number of points minus this maximum window size.

This approach ensures we efficiently find the optimal solution with a time complexity of \( O(n \log n) \) due to sorting and binary search, making it suitable for the given problem constraints.
