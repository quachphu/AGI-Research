To solve this problem, we need to determine the minimal total cost of post lamps Adilbek can buy to illuminate the entire segment [0, n] of the street using lamps of exactly one type. The solution involves checking each possible lamp power from 1 to k, considering the constraints of blocked positions and the coverage required.

### Approach
1. **Check Availability of Position 0**: If the starting position (0) is blocked, it's impossible to illuminate the segment, so we immediately return -1.
2. **Determine Available Positions**: Generate a list of available positions where lamps can be placed by excluding the blocked positions.
3. **Calculate Maximum Gap and Required Coverage**: Compute the maximum gap between consecutive available positions and the required coverage from the last available position to the end of the segment.
4. **Determine Minimum Lamp Power**: Calculate the minimum lamp power required (l_min) based on the maximum gap and required coverage.
5. **Check Feasibility**: If the minimum required lamp power exceeds the maximum available power (k), return -1 as it's impossible to illuminate the segment.
6. **Calculate Minimum Cost**: For each valid lamp power from l_min to k, compute the number of lamps needed and the total cost, then determine the minimal cost.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr]); ptr += 1
    m = int(input[ptr]); ptr += 1
    k = int(input[ptr]); ptr += 1
    
    blocked = list(map(int, input[ptr:ptr + m]))
    ptr += m
    a = list(map(int, input[ptr:ptr + k]))
    
    # Generate available positions
    blocked_set = set(blocked)
    available = []
    for x in range(n):
        if x not in blocked_set:
            available.append(x)
    if not available or available[0] != 0:
        print(-1)
        return
    
    # Compute max_gap and required_last_coverage
    max_gap = 0
    for i in range(1, len(available)):
        max_gap = max(max_gap, available[i] - available[i-1])
    required_last_coverage = n - available[-1]
    l_min = max(max_gap, required_last_coverage)
    
    if l_min > k:
        print(-1)
        return
    
    min_cost = float('inf')
    len_available = len(available)
    for l in range(l_min, k + 1):
        current_max = available[0] + l
        if current_max >= n:
            cost = a[l-1]
            if cost < min_cost:
                min_cost = cost
            continue
        
        count = 1
        current_idx = 0
        while True:
            # Find the largest available <= current_max
            next_idx = bisect.bisect_right(available, current_max) - 1
            if next_idx == current_idx:
                # No progress, but according to l >= l_min, this can't happen
                break
            current_idx = next_idx
            current_max = available[current_idx] + l
            count += 1
            if current_max >= n:
                break
        
        cost = a[l-1] * count
        if cost < min_cost:
            min_cost = cost
    
    print(min_cost if min_cost != float('inf') else -1)

if __name__ == "__main__":
    main()
```
