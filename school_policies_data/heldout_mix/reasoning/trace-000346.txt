To solve this problem, we need to determine if Chintu can fulfill his girlfriend's demand for a bracelet with at least `k` special beads. A special bead is defined as a bead whose letter appears in every strand of the bracelet.

### Approach
1. **Input Reading**: Read the number of strands `N` and the required number of special beads `k`.
2. **Set Creation**: For each strand, create a set of unique characters present in that strand. This helps in efficiently checking the presence of characters across all strands.
3. **Intersection Calculation**: Compute the intersection of all the sets created from each strand. The intersection will give us the characters that are common across all strands.
4. **Comparison**: Check if the size of the intersection (number of common characters) is at least `k`. If it is, Chintu can fulfill the demand; otherwise, he cannot.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    k = int(input[idx])
    idx += 1
    strands = []
    for _ in range(n):
        strands.append(input[idx].strip())
        idx += 1
    if n == 0:
        print(":-(")
        return
    common = set(strands[0])
    for s in strands[1:]:
        common &= set(s)
        if not common:
            break  # Early exit if no elements left
    if len(common) >= k:
        print(":-)")
    else:
        print(":-(")

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list for efficient processing. The first two elements are `N` and `k`, followed by the strands.
2. **Creating Sets**: Each strand is converted into a set of unique characters. This helps in efficiently checking common characters using set operations.
3. **Intersection Calculation**: Starting with the first strand's characters, we iteratively compute the intersection with each subsequent strand's characters. Early exit is implemented if the intersection becomes empty to save computation time.
4. **Result Check**: The size of the intersection set is compared against `k` to determine the result, which is printed accordingly.

This approach ensures that we efficiently determine the common characters across all strands using set operations, leading to an optimal solution for the given problem constraints.
