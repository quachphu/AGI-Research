3. **Offset Handling**: To handle negative sums efficiently, an offset is used to shift all possible sums into a non-negative index range.

4. **Convolution with Modulo**: Each turn's possible score changes are convolved with the current DP array to update it for the next turn. This is done using modulo arithmetic to handle large numbers.
