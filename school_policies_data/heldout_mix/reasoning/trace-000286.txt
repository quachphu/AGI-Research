To solve this problem, we need to rearrange the animals in a circular formation such that all hamsters (H) are grouped together and all tigers (T) are grouped together with the minimum number of swaps. 

### Approach
1. **Understand the Problem Requirements**: The goal is to group all H's and T's contiguously in a circle. The key insight is that in a valid configuration, the H's form a single contiguous block, and the T's form another contiguous block.
2. **Circular Array Handling**: Since the animals are arranged in a circle, we can handle this by considering the array as a doubled string (concatenated with itself) to easily manage wrap-around windows.
3. **Sliding Window Technique**: For each possible starting position in the circular array, we check a window of length equal to the number of H's. The minimum number of T's in any such window gives the number of swaps needed, as each T in the window must be swapped with an H outside the window.

### Solution Code
```python
n = int(input())
s = input().strip()

count_h = s.count('H')
if count_h == 0 or count_h == n:
    print(0)
else:
    k = count_h
    s_dup = s + s
    min_swaps = float('inf')
    for i in range(n):
        window = s_dup[i:i + k]
        current_t = window.count('T')
        if current_t < min_swaps:
            min_swaps = current_t
    print(min_swaps)
```

### Explanation
1. **Count H's**: Determine the number of H's in the input string. If all animals are already H's or T's, no swaps are needed.
2. **Check Validity**: If the count of H's is 0 or equal to the total number of animals, print 0 as no swaps are needed.
3. **Generate Windows**: Using a doubled string to handle circularity, slide a window of length equal to the number of H's across all possible starting positions.
4. **Calculate Minimum Swaps**: For each window, count the number of T's. The minimum count of T's across all windows gives the number of swaps required, as each T in the window needs to be swapped with an H outside the window.

This approach efficiently checks all possible contiguous configurations of H's in a circular manner, ensuring the minimal number of swaps is found.
