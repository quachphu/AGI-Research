To solve this problem, we need to determine if a given array could have been generated by a specific process involving the minimum excluded value (mex) of subsets. If not, we must identify the earliest step where a mistake occurred.

### Approach
1. **Understanding the Problem**: The array is built step-by-step where each element is the mex of some subset of the previous elements. The mex of a subset is the smallest non-negative integer not present in the subset.
2. **Key Insight**: For each step `m`, the new element `a_m` must be the mex of some subset of the previous elements. This means `a_m` must be less than or equal to the mex of the entire array up to the previous step.
3. **Tracking Mex**: We maintain the current mex of the array as it grows. This allows us to efficiently check if each new element is valid based on the mex of the previous elements.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
present = set()
current_mex = 0

for i in range(n):
    ai = a[i]
    mex_prev = current_mex
    if ai > mex_prev:
        print(i + 1)
        exit()
    present.add(ai)
    if ai == mex_prev:
        current_mex += 1
        while current_mex in present:
            current_mex += 1

print(-1)
```

### Explanation
1. **Initialization**: We start with an empty set `present` to track the elements in the array and `current_mex` initialized to 0.
2. **Iterate Through Elements**: For each element `ai` in the input array:
   - **Check Validity**: If `ai` exceeds the mex of the previous elements (`mex_prev`), it is invalid, and we print the current step (1-based index).
   - **Update Set and Mex**: Add `ai` to the set. If `ai` equals the current mex, increment the mex until we find a value not present in the set.
3. **Final Check**: If all elements are valid, print `-1` indicating no mistakes were made.

This approach efficiently tracks the mex of the array as it grows, ensuring each new element is valid based on the previous elements, leading to an optimal O(n) solution.
