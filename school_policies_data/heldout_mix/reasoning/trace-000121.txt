To solve this problem, we need to determine the minimum number of moves required to transform a given integer \( n \) into 1 using two operations: multiplying by 2 or dividing by 6 (if divisible). If it's impossible to achieve 1, we should return -1.

### Approach
1. **Prime Factorization Check**: First, we check if \( n \) can be factorized using only the primes 2 and 3. If there are any other prime factors, it is impossible to reach 1, and we return -1.
2. **Exponent Analysis**: We decompose \( n \) into its prime factors of 2 and 3, obtaining their respective exponents \( a \) (for 2) and \( b \) (for 3).
3. **Feasibility Check**: If the exponent of 3 (\( b \)) is less than the exponent of 2 (\( a \)), it is impossible to reduce \( n \) to 1 using the allowed operations, so we return -1.
4. **Calculate Moves**: If feasible, the minimum number of moves required is calculated using the formula \( 2b - a \), derived from the need to balance the exponents through a combination of divisions by 6 and multiplications by 2.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        if n == 1:
            print(0)
            continue
        a = 0
        b = 0
        while n % 2 == 0:
            a += 1
            n = n // 2
        while n % 3 == 0:
            b += 1
            n = n // 3
        if n != 1:
            print(-1)
        else:
            if a > b:
                print(-1)
            else:
                print(2 * b - a)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prime Factorization Check**: We repeatedly divide \( n \) by 2 and 3 to count their exponents \( a \) and \( b \). If after removing all factors of 2 and 3, \( n \) is not 1, it means there are other prime factors, making it impossible to reach 1.
2. **Exponent Analysis**: The counts of 2's and 3's (exponents \( a \) and \( b \)) determine the operations needed. Each division by 6 reduces both exponents by 1, while each multiplication by 2 increases the exponent of 2 by 1.
3. **Feasibility Check**: For the operations to be feasible, the number of 3's must be at least the number of 2's to allow sufficient divisions by 6. If not, return -1.
4. **Move Calculation**: The formula \( 2b - a \) accounts for the necessary divisions and multiplications. Each division by 6 requires one move, and each multiplication by 2 requires one move, balancing the exponents to zero.

This approach efficiently checks for feasibility and calculates the minimum moves using prime factorization and exponent analysis, ensuring optimal performance even for large values of \( n \).
