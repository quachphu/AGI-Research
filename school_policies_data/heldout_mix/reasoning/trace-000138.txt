To solve this problem, we need to determine the sum of the strengths of all possible teams of size K formed from N students, where the strength of a team is defined by the weakest member. The solution must be efficient given the constraints.

### Approach
1. **Sorting**: First, sort the array of strengths in ascending order. This allows us to efficiently determine the contribution of each element as the minimum in various subsets.
2. **Combinatorics**: For each element in the sorted array, calculate how many times it can be the minimum in a subset of size K. This is done by choosing K-1 elements from the elements that come after the current element in the sorted array.
3. **Precomputation**: Precompute factorials and inverse factorials up to the maximum possible value of N (100,000) using modular arithmetic to efficiently compute combinations.
4. **Modular Arithmetic**: Use modular arithmetic to handle large numbers and ensure results fit within standard integer limits.

### Solution Code
```python
MOD = 10**9 + 7
max_n = 10**5

# Precompute factorial and inverse factorial arrays
fact = [1] * (max_n + 1)
for i in range(1, max_n + 1):
    fact[i] = fact[i-1] * i % MOD

inv_fact = [1] * (max_n + 1)
inv_fact[max_n] = pow(fact[max_n], MOD - 2, MOD)
for i in range(max_n - 1, -1, -1):
    inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

def comb(a, b):
    if a < 0 or b < 0 or a < b:
        return 0
    return fact[a] * inv_fact[b] % MOD * inv_fact[a - b] % MOD

import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N, K = int(input[ptr]), int(input[ptr + 1])
        ptr += 2
        arr = list(map(int, input[ptr:ptr + N]))
        ptr += N
        arr.sort()
        if K == 1:
            print(sum(arr) % MOD)
            continue
        required = K - 1
        res = 0
        for i in range(N):
            m = N - i - 1
            if m >= required:
                c = comb(m, required)
                res = (res + arr[i] * c) % MOD
        print(res % MOD)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Sorting**: The array is sorted to ensure that when considering each element as the minimum of a subset, all subsequent elements are larger.
2. **Combinatorial Calculations**: For each element at position `i` in the sorted array, the number of valid subsets where this element is the minimum is determined by choosing `K-1` elements from the remaining `N-i-1` elements.
3. **Efficiency**: By precomputing factorials and their modular inverses, we can compute combinations in constant time, making the solution efficient even for large values of N and K.
4. **Modular Arithmetic**: Ensures that all operations are performed modulo `10^9 + 7` to handle large numbers and prevent overflow.

This approach efficiently computes the required sum by leveraging sorting and combinatorial mathematics, ensuring optimal performance even for the upper constraint limits.
