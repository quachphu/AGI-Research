To solve this problem, we need to determine if there are more people wearing red hats than blue hats based on a given string of hat colors.

### Approach
1. **Input Reading**: Read the integer `N` which represents the number of people, and the string `s` which represents the colors of the hats each person is wearing.
2. **Count Red Hats**: Count the occurrences of the character 'R' in the string `s`.
3. **Comparison**: Compare the count of red hats with the count of blue hats. Since the total number of people is `N`, the number of blue hats can be derived as `N - count_of_red_hats`.
4. **Output Result**: Print "Yes" if there are more red hats than blue hats, otherwise print "No".

### Solution Code
```python
def main():
    n = int(input())
    s = input().strip()
    red_count = s.count('R')
    print("Yes" if red_count > n - red_count else "No")

main()
```

### Explanation
1. **Reading Input**: The first line of input is the integer `N`, which is read and converted to an integer. The second line is the string `s`, which is read and stripped of any leading or trailing whitespace.
2. **Counting Red Hats**: Using the `count` method on the string `s`, we determine how many times 'R' appears. This gives the number of people wearing red hats.
3. **Determining Blue Hats**: The number of people wearing blue hats is calculated by subtracting the count of red hats from the total number of people `N`.
4. **Comparison and Output**: We check if the count of red hats is greater than the count of blue hats. If true, "Yes" is printed; otherwise, "No" is printed.

This approach efficiently determines the result with a time complexity of O(N), where N is the length of the string, due to the count operation and comparison. This ensures the solution is optimal for the given constraints.
