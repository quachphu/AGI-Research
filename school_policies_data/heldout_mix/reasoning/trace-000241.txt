To solve this problem, we need to determine the minimum time required to assemble a single chain of matryoshka dolls from an initial configuration of multiple chains. The operations allowed are nesting a doll into another or extracting a doll from its container, each taking one second.

### Approach
1. **Identify the Longest Consecutive Sequence**: The key insight is to find the longest consecutive sequence starting from doll 1 in the initial configuration. This sequence will help reduce the number of operations needed because these dolls are already in the desired order.
2. **Calculate Operations**: The total time required is a combination of the time needed to split all chains into individual dolls and the time needed to assemble them into the target chain. By leveraging the longest consecutive sequence, we can minimize the number of operations needed.

### Solution Code
```python
n, k = map(int, input().split())
chains = []
for _ in range(k):
    parts = list(map(int, input().split()))
    mi = parts[0]
    chain = parts[1:]
    chains.append(chain)

current_chain = None
for chain in chains:
    if chain[0] == 1:
        current_chain = chain
        break

L = 1
for i in range(1, len(current_chain)):
    if current_chain[i] == L + 1:
        L += 1
    else:
        break

C = L - 1
answer = 2 * n - k - 1 - 2 * C
print(answer)
```

### Explanation
1. **Reading Input**: The input consists of the number of dolls `n` and the number of initial chains `k`. Each chain is read and stored in a list.
2. **Finding the Relevant Chain**: We identify the chain that starts with doll 1, as this chain is critical for determining the longest consecutive sequence.
3. **Determining the Longest Consecutive Sequence (L)**: We iterate through the identified chain starting from 1 and check for consecutive numbers. The length of this sequence is stored in `L`.
4. **Calculating Minimum Time**: Using the formula `2 * n - k - 1 - 2 * (L - 1)`, we compute the minimum time required. This formula accounts for both splitting the initial chains and assembling the target chain, adjusted by the savings from the longest consecutive sequence.

This approach efficiently computes the minimum time by leveraging existing sequences in the initial configuration, thus optimizing the number of operations needed.
