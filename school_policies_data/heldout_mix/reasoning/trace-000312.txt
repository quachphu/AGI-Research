To solve this problem, we need to determine the probability that Alice will have to fetch water based on the numbers she and Bob choose. The key insight is to compute the probability that the sum of their chosen numbers is odd, which happens when one number is even and the other is odd.

### Approach
1. **Understanding Parity**: The sum of two numbers is odd if one is even and the other is odd. Therefore, we need to count the number of even and odd numbers each can choose.
2. **Counting Even and Odd Numbers**: For a range from 1 to N, the count of even numbers is `N // 2` and the count of odd numbers is `(N + 1) // 2`. Similarly for the range 1 to M.
3. **Favorable Cases**: The number of favorable cases where the sum is odd is the sum of:
   - Even numbers chosen by Alice multiplied by odd numbers chosen by Bob.
   - Odd numbers chosen by Alice multiplied by even numbers chosen by Bob.
4. **Probability Calculation**: The probability is the ratio of favorable cases to the total possible cases (N * M). This ratio is simplified using the greatest common divisor (GCD).

### Solution Code
```python
import sys
import math

def main():
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    results = []
    for _ in range(T):
        n = int(input[idx])
        m = int(input[idx + 1])
        idx += 2
        
        a_even = n // 2
        a_odd = (n + 1) // 2
        b_even = m // 2
        b_odd = (m + 1) // 2
        
        numerator = a_even * b_odd + a_odd * b_even
        denominator = n * m
        
        g = math.gcd(numerator, denominator)
        num = numerator // g
        den = denominator // g
        
        results.append(f"{num}/{den}")
    
    print('\n'.join(results))

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input Efficiently**: The input is read all at once for efficiency, especially given the large constraints.
- **Counting Even and Odd Numbers**: For each number range (N and M), we calculate the counts of even and odd numbers using integer division.
- **Calculating Favorable Cases**: The favorable cases are computed by considering both scenarios where Alice picks even and Bob picks odd, and vice versa.
- **Simplifying the Fraction**: Using the GCD of the numerator and denominator, we simplify the fraction to its irreducible form and store results for each test case.
- **Output**: Results are collected and printed at once to minimize I/O operations, which is crucial for handling up to 100,000 test cases efficiently.

This approach ensures that each test case is processed in constant time, making the solution both efficient and scalable.
