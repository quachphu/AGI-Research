To solve this problem, we need to determine the maximum possible greatest common divisor (GCD) of N integers whose product is given as P. The key insight is that the GCD of these integers must be a factor of P, and we can maximize this GCD by considering the prime factorization of P.

### Approach
1. **Prime Factorization**: Factorize the given product P into its prime factors. This helps in determining the maximum exponents of each prime factor that can be part of the GCD.
2. **Exponent Calculation**: For each prime factor, calculate the maximum exponent that can be included in the GCD. This is done by dividing the exponent of each prime factor in P by N and taking the floor of the result.
3. **Construct the Result**: Multiply each prime factor raised to the calculated maximum exponent to form the maximum possible GCD.

### Solution Code
```python
import sys

def main():
    N, P = map(int, sys.stdin.readline().split())
    factors = {}
    temp = P
    i = 2
    while i * i <= temp:
        while temp % i == 0:
            factors[i] = factors.get(i, 0) + 1
            temp = temp // i
        i += 1
    if temp > 1:
        factors[temp] = 1
    result = 1
    for prime, exp in factors.items():
        result *= prime ** (exp // N)
    print(result)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prime Factorization**: The code first factorizes P into its prime factors using trial division up to the square root of P. This is efficient for numbers up to \(10^{12}\).
2. **Exponent Calculation**: For each prime factor, the exponent in the GCD is determined by dividing the exponent in P by N. This ensures that when each of the N integers is divided by the GCD, the resulting product is an integer.
3. **Result Construction**: The product of each prime factor raised to the calculated exponent gives the maximum possible GCD. This approach ensures that the GCD is maximized while respecting the constraint that the product of the integers equals P.

This method efficiently handles the constraints and provides the correct result by leveraging prime factorization and integer division properties.
