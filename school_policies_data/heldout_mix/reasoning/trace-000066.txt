1. **Graph Representation**: Represent the cities and roads using an adjacency list.
2. **Component Analysis**: For each test case, compute the size of the component that contains city b when city a is removed, and vice versa.
3. **Component Sizes Calculation**: Calculate the number of nodes that are not reachable from b when a is removed (S_a) and the number of nodes not reachable from a when b is removed (S_b).
4. **Result Calculation**: The result for each test case is the product of S_a and S_b, which gives the number of valid pairs (x, y).

### Solution Code
```python
import sys
from collections import deque

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        m = int(input[ptr+1])
        a = int(input[ptr+2])
        b = int(input[ptr+3])
        ptr +=4
        adj = [[] for _ in range(n+1)]
        for _ in range(m):
            u = int(input[ptr])
            v = int(input[ptr+1])
            adj[u].append(v)
            adj[v].append(u)
            ptr +=2
        
        # Compute S_a: nodes not reachable from b after removing a
        visited_a = [False] * (n + 1)
        visited_a[a] = True
        count_b = 0
        if not visited_a[b]:
            q = deque()
            q.append(b)
            visited_a[b] = True
            count_b = 1
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if v == a:
                        continue
                    if not visited_a[v]:
                        visited_a[v] = True
                        count_b +=1
                        q.append(v)
        S_a = (n -1) - count_b
        
        # Compute S_b: nodes not reachable from a after removing b
        visited_b = [False] * (n + 1)
        visited_b[b] = True
        count_a = 0
        if not visited_b[a]:
            q = deque()
            q.append(a)
            visited_b[a] = True
            count_a = 1
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if v == b:
                        continue
                    if not visited_b[v]:
                        visited_b[v] = True
                        count_a +=1
                        q.append(v)
        S_b = (n -1) - count_a
        
        print(S_a * S_b)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Graph Representation**: The adjacency list is built from the input, capturing all roads between cities.
2. **Component Analysis**: For each city a and b, we perform a BFS/DFS to determine the size of the component containing the other city after removing one. This helps us understand which nodes are disconnected when either a or b is removed.
3. **Component Sizes Calculation**: By removing city a, we calculate how many nodes are not reachable from city b. Similarly, by removing city b, we calculate how many nodes are not reachable from city a. These values give us S_a and S_b.
4. **Result Calculation**: The product of S_a and S_b gives the number of valid pairs (x, y) where any path between them must pass through both a and b. This approach ensures that we efficiently determine the required pairs using graph traversal techniques.
