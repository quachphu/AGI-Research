To solve this problem, we need to determine the optimal package size for Chef's cupcakes such that the number of leftover cupcakes is maximized. Chef will choose the largest package size if there are multiple sizes that yield the same maximum number of leftovers.

### Approach
The key insight is that the maximum number of leftover cupcakes occurs when the package size is just over half of the total number of cupcakes. This is because the remainder when dividing the total number of cupcakes by the package size is maximized when the package size is the smallest integer greater than half of the total cupcakes. For a given number of cupcakes \( N \), the optimal package size \( A \) is \( \left\lfloor \frac{N}{2} \right\rfloor + 1 \). This ensures that the remainder is maximized, and if there are multiple values of \( A \) with the same remainder, the largest \( A \) is chosen.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        N = int(input[i])
        print((N // 2) + 1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings. The first element is the number of test cases \( T \).
2. **Processing Each Test Case**: For each test case, we read the number of cupcakes \( N \).
3. **Optimal Package Size Calculation**: For each \( N \), the optimal package size is calculated as \( \left\lfloor \frac{N}{2} \right\rfloor + 1 \). This value ensures the maximum number of leftovers and the largest possible package size in case of ties.

This approach efficiently computes the result in \( O(T) \) time complexity, where \( T \) is the number of test cases, making it suitable for large inputs up to the constraint limits.
