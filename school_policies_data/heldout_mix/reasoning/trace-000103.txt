To solve this problem, we need to determine the number of months it takes for a friend's savings to reach or exceed a given travel cost, based on their monthly income and expenditure. If the savings do not reach the required amount within 12 months, we should indicate this with "NA".

### Approach
1. **Input Handling**: Read the input line by line. Each dataset starts with the travel cost (L) followed by 12 lines of monthly income (M) and expenditure (N).
2. **Savings Calculation**: For each month, calculate the savings as the difference between income (M) and expenditure (N). Accumulate these savings month by month.
3. **Check Completion**: Track the cumulative savings each month. If the savings meet or exceed the travel cost (L) at any point, record the current month and break out of the loop. If after 12 months the savings are still insufficient, return "NA".

### Solution Code
```python
import sys

def main():
    while True:
        line = sys.stdin.readline()
        if not line:
            break
        line = line.strip()
        if not line:
            continue
        L = int(line)
        if L == 0:
            break
        months = []
        for _ in range(12):
            m, n = map(int, sys.stdin.readline().split())
            months.append((m, n))
        total = 0
        result = 'NA'
        for i in range(12):
            total += months[i][0] - months[i][1]
            if total >= L:
                result = i + 1
                break
        print(result)

main()
```

### Explanation
1. **Reading Input**: The input is read line by line. The first line of each dataset is the travel cost (L). If L is zero, the program stops.
2. **Processing Each Dataset**: For each valid L, read the next 12 lines which contain monthly income and expenditure. These values are stored in a list.
3. **Calculating Savings**: For each month, compute the savings (M - N) and accumulate the total savings. Check after each month if the total savings have met or exceeded the travel cost.
4. **Output Result**: If the savings meet the travel cost within 12 months, print the month number. If not, print "NA".

This approach ensures that we efficiently determine the required number of months or identify if the target cannot be met within the given timeframe. The solution handles multiple datasets and edge cases such as immediate achievement of the target or exactly meeting the target in the last month.
