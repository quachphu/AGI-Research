class FenwickTree:

    def __init__(self, size):

        self.n = size

        self.tree = [0] * (self.n +1)

    def update(self, idx, delta):

        # idx is 1-based.

        while idx <= self.n:

            self.tree[idx] += delta

            idx += idx & -idx

    def query(self, idx):

        # sum from 1 to idx.

        res = 0

        while idx >0:

            res += self.tree[idx]

            idx -= idx & -idx

        return res

To solve this problem, we need to efficiently handle two types of operations on an array: updating an element and querying the sum of elements multiplied by coefficients from a periodic sequence. The periodic sequence, known as the Zigzag sequence, depends on a given factor `z` and has a specific pattern that repeats every `2z-2` elements.

### Approach

1. **Understanding the Zigzag Sequence**: The Zigzag sequence for a given `z` is periodic with a cycle length of `2z-2`. The sequence starts from 1, increases to `z`, then decreases back to 2. For example, for `z=3`, the sequence is `[1, 2, 3, 2]`.

2. **Efficient Query Handling**: For each query, we need to compute the sum of elements in a range multiplied by their respective coefficients from the Zigzag sequence. Direct computation for each query would be too slow, so we use Fenwick Trees (Binary Indexed Trees) to efficiently manage range sum queries with updates.

3. **Fenwick Trees for Each Modulus**: We precompute Fenwick Trees for each possible cycle length (2, 4, 6, 8, 10) and each possible remainder modulo the cycle length. This allows us to quickly compute the sum of elements that fall into specific positions within the periodic cycle.

4. **Handling Updates**: When an element in the array is updated, we adjust the corresponding positions in all relevant Fenwick Trees to reflect the new value.

class FenwickTree:
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (self.n + 1)

    def update(self, idx, delta):
        while idx <= self.n:
            self.tree[idx] += delta
            idx += idx & -idx

    def query(self, idx):
        res = 0
        while idx > 0:
            res += self.tree[idx]
            idx -= idx & -idx
        return res

def generate_cycle(z):
    up = list(range(1, z + 1))
    down = list(range(z - 1, 1, -1))
    return up + down
