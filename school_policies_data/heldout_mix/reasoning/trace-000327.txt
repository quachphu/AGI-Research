To solve this problem, we need to determine the number of gears (i, j) where the gear ratio (b_j / a_i) is an integer and find the maximum such ratio, then count how many times this maximum ratio occurs.

### Approach
1. **Input Reading**: Read the number of stars on the pedal axle (n) and their respective teeth counts. Then read the number of stars on the rear wheel axle (m) and their respective teeth counts.
2. **Gear Ratio Calculation**: For each pair of stars (i, j), check if the rear wheel star's teeth count (b_j) is divisible by the pedal star's teeth count (a_i). If it is, compute the gear ratio and store it.
3. **Determine Maximum Ratio**: From the list of valid gear ratios, find the maximum value.
4. **Count Maximum Occurrences**: Count how many times this maximum ratio appears in the list of valid ratios.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
m = int(input())
b = list(map(int, input().split()))

ratios = []
for ai in a:
    for bj in b:
        if bj % ai == 0:
            ratios.append(bj // ai)

max_ratio = max(ratios)
count = ratios.count(max_ratio)
print(count)
```

### Explanation
1. **Reading Inputs**: The code starts by reading the input values for the number of stars on both axles and their respective teeth counts.
2. **Calculating Valid Ratios**: For each combination of a pedal star (a_i) and a rear wheel star (b_j), it checks if b_j is divisible by a_i. If true, the ratio (b_j // a_i) is added to the list of valid ratios.
3. **Finding Maximum Ratio**: The maximum value from the list of valid ratios is determined using the `max` function.
4. **Counting Occurrences**: The number of times this maximum ratio appears in the list is counted using the `count` method.

This approach ensures that we efficiently check all possible gear combinations, compute valid ratios, and determine the required result using straightforward arithmetic operations and list manipulations. The complexity is manageable given the problem constraints, making the solution both optimal and easy to understand.
