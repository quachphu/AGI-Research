To solve this problem, we need to determine the minimum number of seconds Valeric and Valerko must wait before starting a video so that they can watch it without any pauses. The key is ensuring that the downloaded data is always sufficient for the video playback at every moment from the start until the end of the video.

### Approach
1. **Problem Analysis**:
   - The video requires `a` units of data per second to play.
   - They can download `b` units of data per second.
   - The video length is `c` seconds.
   - The goal is to find the minimum integer `t` (waiting time) such that for every moment `t0` from `t` to `t + c`, the downloaded data up to `t0` is at least the data required to watch up to `t0 - t` seconds of the video.

2. **Key Insight**:
   - For each second `x` (from 0 to `c`), the downloaded data by time `t + x` must be at least `a * x`. This translates to the inequality `b * (t + x) >= a * x`.
   - Rearranging this inequality gives `t >= (a - b) * x / b`. The maximum value of this expression occurs when `x` is at its maximum value `c`, leading to the formula `t = ceil((a - b) * c / b)`.

3. **Algorithm**:
   - Compute the minimum waiting time `t` using integer arithmetic to avoid floating-point inaccuracies. This is done using the formula `((a - b) * c + b - 1) // b`.

### Solution Code
```python
a, b, c = map(int, input().split())
t = ((a - b) * c + b - 1) // b
print(t)
```

- **Input Handling**: Read the values of `a`, `b`, and `c` from standard input.
- **Formula Application**: Compute the minimum waiting time `t` using the derived formula. This formula ensures that we correctly handle integer division and ceiling operations without using floating-point arithmetic.
- **Output**: Print the computed minimum waiting time `t`.

This approach efficiently determines the minimum waiting time by focusing on the critical point where the required data is maximized, ensuring the solution is both optimal and correct.
