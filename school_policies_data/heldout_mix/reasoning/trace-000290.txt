To solve this problem, we need to maximize the profit from buying and selling one share of stock per day over a given period, while ensuring that we end with zero shares. The solution involves using a greedy algorithm with a priority queue (min-heap) to track the lowest buy prices and sell them at higher prices efficiently.

### Approach
1. **Greedy Strategy**: The key insight is to buy at the lowest possible price and sell at the highest possible price. We use a min-heap to keep track of the prices at which we have bought shares.
2. **Heap Operations**: For each day's price, we push the price into the heap. If the current price is higher than the minimum price in the heap (indicating a profit opportunity), we pop the minimum price, add the profit, and push the current price back into the heap. This allows us to potentially reuse the current price for future transactions.
3. **Ensuring Zero Shares**: By always selling when a higher price is encountered and re-pushing the current price, we ensure that all shares are effectively sold by the end of the period through valid transactions.

### Solution Code
```python
import heapq

def maximize_profit():
    import sys
    n = int(sys.stdin.readline())
    prices = list(map(int, sys.stdin.readline().split()))
    heap = []
    profit = 0
    for p in prices:
        heapq.heappush(heap, p)
        if p > heap[0]:
            min_p = heapq.heappop(heap)
            profit += p - min_p
            heapq.heappush(heap, p)
    print(profit)

maximize_profit()
```

### Explanation
1. **Reading Input**: The input is read from standard input, starting with the number of days followed by the stock prices for each day.
2. **Heap Initialization**: A min-heap is used to track the prices at which shares are bought.
3. **Processing Each Price**: For each price, it is added to the heap. If the current price is higher than the minimum price in the heap, a transaction is made by selling the share bought at the minimum price and buying a new share at the current price (to potentially sell it later at a higher price).
4. **Profit Calculation**: The profit from each valid transaction is accumulated, ensuring that the maximum possible profit is achieved while adhering to the constraints.

This approach efficiently tracks the optimal buy and sell points using a min-heap, resulting in an overall time complexity of O(N log N), which is suitable for large input sizes up to 300,000.
