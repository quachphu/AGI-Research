To solve this problem, we need to compute the number of particles in a box at a given time \( N \) starting with an initial number of particles \( X \). The number of particles at time \( t \) is determined by multiplying the number of particles at time \( t-1 \) by \( t \). The result must be computed modulo \( 10^6 + 3 \).

### Approach
1. **Understanding the Problem**: The number of particles at time \( N \) is \( X \times N! \) (factorial of \( N \)). Direct computation of \( N! \) for large \( N \) is infeasible due to the constraints.
2. **Modulo Properties**: For \( N \geq 10^6 + 3 \), \( N! \) modulo \( 10^6 + 3 \) is 0 because the factorial will include the modulus value as a factor.
3. **Precomputation**: Precompute factorials modulo \( 10^6 + 3 \) up to \( 10^6 + 2 \). This allows efficient look-up for \( N \) values less than the modulus.
4. **Efficient Input Handling**: Use efficient input reading methods to handle up to 100,000 test cases quickly.

### Solution Code
```python
import sys

MOD = 10**6 + 3
MAX_FACT = MOD - 1

# Precompute factorial modulo MOD up to MAX_FACT
fact = [1] * (MAX_FACT + 1)
for i in range(1, MAX_FACT + 1):
    fact[i] = (fact[i-1] * i) % MOD

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        N = int(input[idx])
        X = int(input[idx + 1])
        idx += 2
        if N >= MOD:
            ans = 0
        else:
            x_mod = X % MOD
            ans = (x_mod * fact[N]) % MOD
        print(ans)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precomputation**: We precompute the factorial values modulo \( 10^6 + 3 \) up to \( 10^6 + 2 \) (since for \( N \geq 10^6 + 3 \), the result is 0).
2. **Handling Each Test Case**:
   - If \( N \) is greater than or equal to the modulus, the result is 0.
   - Otherwise, compute \( X \mod \text{MOD} \) and multiply it by the precomputed factorial of \( N \) modulo \( 10^6 + 3 \).

This approach efficiently handles the large input constraints by leveraging precomputation and modulo arithmetic properties, ensuring quick look-up and computation for each test case.
