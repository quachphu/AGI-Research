To solve this problem, we need to efficiently search for elements in a matrix where each row and column is sorted in ascending order. The challenge is to quickly determine the position of a given element or confirm its absence.

### Approach
The matrix's sorted properties allow us to use a specific search strategy that efficiently narrows down the possible locations of the target element. The approach involves starting from the top-right corner of the matrix and moving either left or down based on comparisons with the current element:

1. **Start at the top-right corner**: This position allows us to leverage both row and column sorted properties.
2. **Move left if the current element is greater than the target**: This eliminates the current column since all elements below in the column are larger.
3. **Move down if the current element is smaller than the target**: This eliminates the current row since all elements to the left in the row are smaller.

This method ensures that each comparison either eliminates a row or a column, leading to an efficient search with a time complexity of O(N + M) per query, where N is the number of rows and M is the number of columns.

### Solution Code
```python
import sys

def main():
    data = list(map(int, sys.stdin.read().split()))
    ptr = 0
    N = data[ptr]
    ptr += 1
    M = data[ptr]
    ptr += 1
    
    matrix = []
    for _ in range(N):
        row = data[ptr:ptr+M]
        matrix.append(row)
        ptr += M
    
    Q = data[ptr]
    ptr += 1
    queries = data[ptr:ptr+Q]
    
    for x in queries:
        row, col = 0, M - 1
        found = False
        while row < N and col >= 0:
            current = matrix[row][col]
            if current == x:
                print(f"{row} {col}")
                found = True
                break
            elif current > x:
                col -= 1
            else:
                row += 1
        if not found:
            print("-1 -1")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially with large datasets. The data is split into tokens for easy processing.
2. **Matrix Construction**: The matrix is built from the input tokens, row by row.
3. **Processing Queries**: For each query, the search starts at the top-right corner of the matrix. Based on comparisons with the current element, the search moves left or down until the element is found or the search boundaries are exceeded.
4. **Output**: The positions of found elements are printed immediately, while "-1 -1" is printed if an element is not found.

This approach efficiently utilizes the sorted properties of the matrix to minimize the number of comparisons, ensuring optimal performance even for the upper constraint limits.
