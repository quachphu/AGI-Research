To solve this problem, we need to count the number of zigzag numbers that are multiples of a given integer M between two large numbers A and B. A zigzag number is one where the digits alternately increase and decrease. The solution must handle very large numbers efficiently using dynamic programming (DP).

### Approach
1. **Digit Dynamic Programming (DP)**: This technique is used to count numbers with specific properties (here, zigzag and divisible by M) up to a given number. We use DP to track the state of the number being formed, including its modulus, leading zeros, last digit, and direction of the last change.
2. **Subtract One Handling**: Since we need to compute the count of numbers between A and B, we subtract one from A and compute the difference between the counts up to B and A-1.
3. **State Tracking**: The DP state includes whether the current number is tight (exactly matches the prefix of the upper bound), leading zeros, the last digit, the direction of the last change, and the current modulus.

                            new_dir = -last_dir
                            new_mod_val = (current_mod * 10 + d) % M
                            new_state = (new_is_tight, False, d, new_dir, new_mod_val)
                            dp[pos+1][new_state] = (dp[pos+1][new_state] + count) % 10000
                        else:
                            continue

    total = 0
    for state, count in dp[len_x].items():
        is_tight, leading_zero, last_digit, last_dir, mod = state
        if not leading_zero and mod == 0:
            total = (total + count) % 10000
    return total
