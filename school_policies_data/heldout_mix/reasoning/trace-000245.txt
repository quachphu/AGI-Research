To solve this problem, we need to determine the maximum number of photos Vasya can view within a given time limit, considering the time taken to swipe between photos, rotate them to the correct orientation, and view each photo. The solution involves considering multiple scenarios to find the optimal path for viewing photos.

### Approach
1. **Initial Setup**: Calculate the time required to view the first photo, considering rotation if needed. If this time exceeds the available time, Vasya cannot view any photos.
2. **Prefix Sum Arrays**: Precompute prefix sums for both right and left directions. These arrays help in quickly calculating the cumulative time required to view photos in a specific direction.
3. **Scenarios**:
   - **Only Right or Left**: Calculate the maximum number of photos Vasya can view by moving only right or only left.
   - **Right then Left**: Calculate the maximum number of photos by moving right first, then backtracking and moving left.
   - **Left then Right**: Calculate the maximum number of photos by moving left first, then backtracking and moving right.
4. **Binary Search**: For each scenario, use binary search to efficiently determine the maximum number of photos that can be viewed within the remaining time.

### Solution Code
```python
n, a, b, T = map(int, input().split())
s = input().strip()

cost_1 = (b if s[0] == 'w' else 0) + 1
if cost_1 > T:
    print(0)
    exit()

max_photos = 1  # At least photo 1 is viewed

# Precompute sum_right (photos 2, 3, ..., n)
sum_right = [0] * n
for i in range(1, n):
    c = s[i]
    add = a + (b if c == 'w' else 0) + 1
    sum_right[i] = sum_right[i-1] + add

# Precompute sum_left (photos n, n-1, ..., 2)
sum_left = [0] * n
for i in range(1, n):
    photo_index = n - 1 - (i - 1)
    c = s[photo_index]
    add = a + (b if c == 'w' else 0) + 1
    sum_left[i] = sum_left[i-1] + add

# Scenario 1: Only right
low, high = 0, n-1
best_m = 0
t_remain = T - cost_1
while low <= high:
    mid = (low + high) // 2
    if sum_right[mid] <= t_remain:
        best_m = mid
        low = mid + 1
    else:
        high = mid - 1
max_photos = max(max_photos, 1 + best_m)

# Scenario 2: Only left
low, high = 0, n-1
best_m = 0

while low <= high:

    if sum_left[mid] <= t_remain:
        best_m = mid
        low = mid + 1
    else:
        high = mid - 1

# Scenario 3: Right then Left
for m in range(n):
    if m >= len(sum_right):
        break
    current_sum = sum_right[m]
    time_used = cost_1 + current_sum + m * a
    if time_used > T:
        break
    rem = T - time_used
    max_l = (n - 1) - m
    if max_l < 0:
        continue

    low_l, high_l = 0, max_l
    best_l = 0
    while low_l <= high_l:
        mid_l = (low_l + high_l) // 2
        if mid_l >= len(sum_left):
            high_l = mid_l - 1
            continue
        if sum_left[mid_l] <= rem:
            best_l = mid_l
            low_l = mid_l + 1
        else:
            high_l = mid_l - 1
    total = 1 + m + best_l
    if total > max_photos:
        max_photos = total

# Scenario 4: Left then Right

    if m >= len(sum_left):
        break
    current_sum = sum_left[m]
```
