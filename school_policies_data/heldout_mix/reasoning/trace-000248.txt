To solve this problem, we need to determine the winner of a typing competition between two participants based on their typing speeds and connection pings. The winner is the participant whose success information arrives first at the server. If both participants' information arrives simultaneously, the result is a draw.

### Approach
1. **Understanding the Problem**: Each participant's total time is composed of three parts:
   - The initial ping delay before they start typing.
   - The time taken to type the given text.
   - The final ping delay after they finish typing.
   
   The total time for each participant can be calculated as:
   \[
   \text{Total Time} = 2 \times \text{ping} + \text{number of characters} \times \text{typing speed per character}
   \]

2. **Input Parsing**: Read the input values which include the number of characters, typing speeds, and pings for both participants.

3. **Time Calculation**: Compute the total time for each participant using the formula derived above.

4. **Comparison**: Compare the total times of both participants to determine the winner. If the times are equal, the result is a draw.

### Solution Code
```python
def main():
    s, v1, v2, t1, t2 = map(int, input().split())
    time1 = 2 * t1 + s * v1
    time2 = 2 * t2 + s * v2
    if time1 < time2:
        print("First")
    elif time2 < time1:
        print("Second")
    else:
        print("Friendship")

main()
```

### Explanation
- **Reading Input**: The input values are read and split into five integers representing the number of characters, typing speeds, and pings for both participants.
- **Total Time Calculation**: For each participant, the total time is calculated by considering both the initial and final ping delays along with the time taken to type all characters.
- **Comparison and Result**: The computed total times for both participants are compared. The result is determined based on which participant has the shorter total time, or if both times are equal, indicating a draw.

This approach efficiently computes the result in constant time \(O(1)\), making it optimal for the given problem constraints.
