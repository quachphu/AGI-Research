### Approach
1. **Rotation Transformation**: Each 90-degree clockwise rotation of a vector (x, y) transforms it to (y, -x). By applying rotations 0, 1, 2, or 3 times, we can explore all possible orientations of vector A.
2. **Check for Each Rotation**: For each rotation of vector A, we compute the difference (delta) between vector B and the rotated vector A. We then check if this delta can be expressed as a linear combination of vector C and its rotations using non-negative integer coefficients.
3. **Linear Combination Check**: If vector C is (0, 0), the only way to achieve B is if B is a rotated version of A. Otherwise, we solve for coefficients in a linear system derived from the components of the rotated vectors.

def main():
    import sys
    input = sys.stdin.read().split()
    ax, ay = int(input[0]), int(input[1])
    bx, by = int(input[2]), int(input[3])
    cx, cy = int(input[4]), int(input[5])
    
    def rotate(x, y, r):
        if r == 0:
            return (x, y)
        elif r == 1:
            return (y, -x)
        elif r == 2:
            return (-x, -y)
        else:  # r == 3
            return (-y, x)
    
    for r in range(4):
        rx, ry = rotate(ax, ay, r)
        dx = bx - rx
        dy = by - ry

                return

        if S == 0:
            continue
        
        a_num = dx * cx + dy * cy
        b_num = dx * cy - dy * cx
        
        if a_num % S == 0 and b_num % S == 0:

            return
    
    print("NO")

if __name__ == "__main__":
