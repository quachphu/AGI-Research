To solve this problem, we need to determine the number of ways Takahashi can climb a staircase with N steps, avoiding certain broken steps, using dynamic programming. The solution must be efficient given the constraints and return the result modulo 1,000,000,007.

### Approach
1. **Dynamic Programming (DP) Setup**: Use an array `dp` where `dp[i]` represents the number of ways to reach the i-th step without stepping on any broken steps.
2. **Initialization**: Start from the 0-th step (ground) where `dp[0] = 1` since Takahashi starts here.
3. **Broken Steps Handling**: Use a set to keep track of broken steps for O(1) lookups.
4. **DP Transition**: For each step from 1 to N, if the step is broken, set `dp[i]` to 0. Otherwise, compute `dp[i]` as the sum of ways to reach the previous two steps (`dp[i-1]` and `dp[i-2]`), modulo 1,000,000,007.
5. **Edge Cases**: Handle steps 1 and 2 correctly by checking valid indices to avoid out-of-bounds errors.

### Solution Code
```python
def main():
    import sys
    MOD = 10**9 + 7
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    M = int(input[ptr])
    ptr += 1
    broken = set()
    for _ in range(M):
        a = int(input[ptr])
        ptr += 1
        broken.add(a)
    
    dp = [0] * (N + 1)
    dp[0] = 1  # Starting point
    
    for i in range(1, N + 1):
        if i in broken:
            dp[i] = 0
        else:
            total = 0
            if i - 1 >= 0:
                total += dp[i - 1]
            if i - 2 >= 0:
                total += dp[i - 2]
            dp[i] = total % MOD
    
    print(dp[N] % MOD)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially for large N. The broken steps are stored in a set for quick lookup.
2. **DP Array Initialization**: The `dp` array is initialized with size N+1 to account for all steps from 0 to N. The base case `dp[0]` is set to 1 since Takahashi starts at step 0.
3. **Filling DP Array**: For each step from 1 to N:
   - If the step is broken, `dp[i]` is set to 0.
   - Otherwise, `dp[i]` is computed as the sum of the previous two steps' values, ensuring we take modulo 1,000,000,007 to handle large numbers.
4. **Output Result**: The result is the value at `dp[N]`, which gives the number of valid ways to reach the top step, modulo 1,000,000,007.

This approach efficiently computes the number of valid paths using dynamic programming with O(N) time and space complexity, making it suitable for the given constraints.
