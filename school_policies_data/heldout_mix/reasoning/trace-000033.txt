To solve this problem, we need to determine if we can make all sugarcane heights the same by applying a powder that doubles the height of a sugarcane any number of times. 

### Approach
1. **Understanding the Problem**: The key insight is that applying the powder (doubling the height) any number of times is equivalent to multiplying the height by a power of 2. Therefore, each sugarcane's height can be adjusted by multiplying it by \(2^k\) for some non-negative integer \(k\).

2. **GCD Calculation**: Compute the greatest common divisor (GCD) of all the given heights. This helps in reducing the problem to checking if the normalized heights (each height divided by the GCD) can be adjusted to the same value by multiplying with powers of 2.

3. **Odd Part Check**: For each normalized height (height divided by the GCD), check if the odd part (the value obtained after removing all factors of 2) is the same for all heights. If all normalized heights have the same odd part, they can be adjusted to the same height using the powder; otherwise, they cannot.

### Solution Code
```python
import sys
from math import gcd
from functools import reduce

def main():
    n = int(sys.stdin.readline())
    heights = list(map(int, sys.stdin.readline().split()))
    
    if n == 1:
        print("YES")
        return
    
    current_gcd = reduce(gcd, heights)
    base_odd = None
    
    for h in heights:
        m = h // current_gcd
        # Compute the odd part by removing all factors of 2
        while m % 2 == 0:
            m //= 2
        if base_odd is None:
            base_odd = m
        elif m != base_odd:
            print("NO")
            return
    
    print("YES")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads the number of sugarcanes and their respective heights.
2. **Edge Case Handling**: If there is only one sugarcane, the answer is immediately "YES" as it is already of uniform height.
3. **GCD Calculation**: The GCD of all heights is computed to normalize the problem.
4. **Odd Part Check**: Each normalized height is divided by the GCD and reduced to its odd part by removing all factors of 2. If all these odd parts are the same, it is possible to make all heights the same using the powder; otherwise, it is not.

This approach efficiently checks the necessary conditions using mathematical properties of GCD and factors, ensuring correctness and optimal performance.
