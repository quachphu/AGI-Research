To solve this problem, we need to determine the maximum number of tools (shovels and swords) that Polycarp can craft using given numbers of sticks and diamonds. Each tool requires either two sticks and one diamond (for a shovel) or two diamonds and one stick (for a sword). Each tool can be sold for one emerald. The solution must efficiently compute the maximum number of emeralds Polycarp can earn for multiple test cases.

### Approach
1. **Understanding Constraints**: Each tool (shovel or sword) uses three resources in total (either 2 sticks and 1 diamond or 2 diamonds and 1 stick). Thus, the maximum number of tools is limited by the total number of resources divided by 3.
2. **Resource Limitation**: Additionally, the number of tools is constrained by the minimum of the available sticks and diamonds because each tool requires at least one stick and one diamond.
3. **Mathematical Insight**: The maximum number of tools is the minimum of:
   - The sum of sticks and diamonds divided by 3 (each tool uses 3 resources).
   - The smaller quantity between the number of sticks and diamonds (each tool requires at least one of each).

### Solution Code
```python
t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    print(min((a + b) // 3, min(a, b)))
```

### Explanation
1. **Reading Input**: The number of test cases `t` is read first.
2. **Processing Each Test Case**: For each test case, read the number of sticks `a` and diamonds `b`.
3. **Calculate Maximum Tools**:
   - Compute the sum of sticks and diamonds. Divide this sum by 3 to get an upper bound based on total resources.
   - Determine the minimum value between the number of sticks and diamonds to ensure each tool has at least one of each resource.
   - The result for each test case is the minimum of these two values, ensuring we do not exceed resource limits.

This approach efficiently computes the maximum number of tools using simple arithmetic operations, making it suitable for large input values up to \(10^9\). The complexity is \(O(t)\), where \(t\) is the number of test cases, ensuring optimal performance.
