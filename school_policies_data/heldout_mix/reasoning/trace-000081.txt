To solve this problem, we need to calculate the total outgoing traffic generated by a chat server processing a series of commands. The commands include adding users, removing users, and sending messages. The traffic is generated only when a message is sent, and it depends on the length of the message and the number of current participants in the chat.

### Approach
1. **Track Current Users**: Use a set to keep track of the current participants in the chat. This allows efficient addition and removal of users.
2. **Process Commands**: For each command read from the input:
   - **Add Command (+<name>)**: Add the user to the set.
   - **Remove Command (-<name>)**: Remove the user from the set.
   - **Send Command (<sender_name>:<message_text>)**: Calculate the traffic generated by the message. The traffic is the length of the message multiplied by the number of current users (including the sender).
3. **Sum Traffic**: Accumulate the traffic generated by each Send command and print the total after processing all commands.

### Solution Code
```python
import sys

def main():
    current_users = set()
    total_traffic = 0
    for line in sys.stdin:
        line = line.strip()
        if line.startswith('+'):
            name = line[1:]
            current_users.add(name)
        elif line.startswith('-'):
            name = line[1:]
            current_users.remove(name)
        else:
            colon_index = line.find(':')
            sender = line[:colon_index]
            message = line[colon_index+1:]
            message_length = len(message)
            num_users = len(current_users)
            total_traffic += message_length * num_users
    print(total_traffic)

if __name__ == "__main__":
    main()
```

### Explanation
- **Data Structure**: A set is used to track current users because it allows O(1) time complexity for both additions and removals, ensuring efficient updates.
- **Command Processing**: Each line from the input is processed to determine the type of command. Add and Remove commands directly modify the set of users. Send commands calculate the traffic by determining the message length and the number of current users.
- **Traffic Calculation**: For each Send command, the message length is determined by splitting the line at the first colon. The total traffic is updated by multiplying the message length by the number of current users, which is the size of the set.

This approach efficiently processes each command and accurately calculates the total outgoing traffic, ensuring optimal performance even with the maximum input constraints.
