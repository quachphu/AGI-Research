To solve this problem, we need to determine the minimum number of student exchanges between two groups such that each academic performance value (from 1 to 5) has the same number of students in both groups. If it's impossible to achieve this balance, we should return -1.

### Approach
1. **Check Feasibility**: For each academic performance value (1 to 5), check if the total number of students in both groups combined is even. If any value has an odd total, it's impossible to balance the groups, so we return -1.
2. **Calculate Imbalance**: For each academic performance value, compute the imbalance (delta) between the two groups. The delta for a value is calculated as the difference between the count of students in group A and the target count (half of the total students for that value).
3. **Sum Positive Imbalances**: The minimum number of exchanges required is the sum of all positive deltas. Each exchange can correct one positive and one negative delta, thus reducing the total number of required exchanges.

### Solution Code
```python
def main():
    import sys
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    b = list(map(int, sys.stdin.readline().split()))
    
    countA = [0] * 6  # Using indices 1 to 5
    countB = [0] * 6
    
    for num in a:
        countA[num] += 1
    for num in b:
        countB[num] += 1
    
    # Check if all totals are even
    possible = True
    for i in range(1, 6):
        if (countA[i] + countB[i]) % 2 != 0:
            possible = False
            break
    
    if not possible:
        print(-1)
        return
    
    # Calculate deltas
    delta = [0] * 6
    for i in range(1, 6):
        delta[i] = (countA[i] - countB[i]) // 2
    
    # Sum of positive deltas
    sum_positive = sum(d for d in delta if d > 0)
    print(sum_positive)

main()
```

4. **Delta Calculation**: Compute the difference (delta) between the current count in group A and the target count (half of the total for that value).
5. **Sum Positive Deltas**: The sum of all positive deltas gives the minimum number of exchanges needed, as each exchange reduces one positive and one negative delta.

This approach ensures that we efficiently determine the minimum number of exchanges required to balance the groups, or determine if it's impossible.
