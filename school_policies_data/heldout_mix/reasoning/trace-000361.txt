To solve this problem, we need to determine if four given sticks can form a rectangle. A rectangle requires opposite sides to be equal, which means the four sticks must be able to form two pairs of equal lengths. This includes the special case of a square, where all four sides are equal.

### Approach
1. **Input Reading**: Read the lengths of the four sticks.
2. **Frequency Counting**: Use a counter to determine how many times each length appears.
3. **Frequency Analysis**: Check if the frequencies of the lengths can form two pairs. This is true if the frequencies are either [4] (all sticks the same length) or [2, 2] (two pairs of distinct lengths).

### Solution Code
```python
from collections import Counter
import sys

def main():
    edges = list(map(int, sys.stdin.readline().split()))
    counts = list(Counter(edges).values())
    counts.sort()
    if counts == [2, 2] or counts == [4]:
        print("yes")
    else:
        print("no")

main()
```

### Explanation
1. **Reading Input**: The input is read as a list of integers representing the lengths of the sticks.
2. **Counting Frequencies**: Using the `Counter` from the `collections` module, we count how many times each length appears.
3. **Checking Conditions**: The list of frequency counts is sorted. If the sorted list is either [4] (all sticks the same length) or [2, 2] (two pairs of different lengths), we can form a rectangle, so we print "yes". Otherwise, we print "no".

This approach efficiently checks the necessary conditions using frequency analysis, ensuring that we correctly identify valid rectangles (including squares) with optimal performance.
