To solve this problem, we need to determine the rank of each student based on their marks. The rank is defined as 1 plus the number of students who have strictly higher marks. Students with the same marks will receive the same rank.

### Approach
1. **Read Input**: First, read the number of students and their respective marks.
2. **Frequency Count**: Use a frequency counter to count how many students have each mark.
3. **Sort Marks**: Sort the unique marks in descending order to facilitate the calculation of ranks.
4. **Calculate Higher Counts**: For each unique mark, compute the cumulative count of students with higher marks. This cumulative count is used to determine the rank for each mark.
5. **Generate Ranks**: For each student's mark in the original input list, look up the precomputed higher count and determine their rank.

This approach efficiently computes the ranks by leveraging sorting and cumulative counts, ensuring an optimal solution even for the upper constraint of 1000 students.

### Solution Code
```python
def compute_ranks():
    import sys
    from collections import Counter

    n = int(sys.stdin.readline())
    marks = list(map(int, sys.stdin.readline().split()))
    freq = Counter(marks)
    sorted_marks = sorted(freq.keys(), reverse=True)
    
    higher_counts = {}
    running_total = 0
    for mark in sorted_marks:
        higher_counts[mark] = running_total
        running_total += freq[mark]
    
    ranks = [higher_counts[m] + 1 for m in marks]
    print(' '.join(map(str, ranks)))

compute_ranks()
```

### Explanation
1. **Reading Input**: The input is read from standard input, which includes the number of students and their marks.
2. **Frequency Counter**: Using `Counter` from the `collections` module, we count the occurrences of each mark.
3. **Sorting Marks**: The unique marks are sorted in descending order to process higher marks first.
4. **Cumulative Count Calculation**: We maintain a running total of students processed so far. For each mark in the sorted list, we store the cumulative count of students with higher marks, then update the running total with the current mark's frequency.
5. **Rank Calculation**: For each student's mark in the original list, we use the precomputed higher counts to determine their rank, which is simply the higher count plus one.

This method ensures that we efficiently compute the ranks in O(N log N) time due to sorting, which is optimal for the given constraints.
