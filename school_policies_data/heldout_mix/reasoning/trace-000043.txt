To solve this problem, we need to determine whether the product of two positive integers, \(a\) and \(b\), is even or odd. 

### Approach
The key observation here is that the product of two integers is even if at least one of the integers is even. Conversely, the product is odd only if both integers are odd. This can be checked using the modulo operation to determine the parity (even or odd) of each integer. Specifically, an integer is even if it is divisible by 2 (i.e., \(a \% 2 == 0\)) and odd otherwise.

### Solution Code
```python
def main():
    a, b = map(int, input().split())
    if a % 2 == 0 or b % 2 == 0:
        print("Even")
    else:
        print("Odd")

main()
```

### Explanation
1. **Reading Input**: The input consists of two integers \(a\) and \(b\) which are read from standard input.
2. **Checking Parity**: We check if either \(a\) or \(b\) is even using the modulo operation. If either \(a \% 2 == 0\) or \(b \% 2 == 0\) evaluates to `True`, the product is even.
3. **Output Result**: Based on the parity check, we print "Even" if either number is even, otherwise we print "Odd".

This approach efficiently determines the result in constant time \(O(1)\) by leveraging the properties of even and odd numbers, ensuring optimal performance even for the upper limits of the input constraints.
