To solve this problem, we need to determine the number of ways Jack can choose two books of different genres from a given list of books. The solution involves efficiently counting valid pairs using combinatorial principles.

### Approach
1. **Problem Analysis**: Jack needs to pick two books of different genres. The key insight is to compute the total number of possible pairs of books and subtract the pairs that have the same genre.
2. **Combinatorial Counting**:
   - **Total Pairs**: Calculate the total number of ways to pick any two books from `n` books using the combination formula \( C(n, 2) = \frac{n(n-1)}{2} \).
   - **Same Genre Pairs**: For each genre, compute the number of ways to pick two books of that genre using \( C(c_i, 2) = \frac{c_i(c_i-1)}{2} \), where \( c_i \) is the count of books in genre `i`.
3. **Result Calculation**: Subtract the sum of same-genre pairs from the total pairs to get the number of valid pairs of different genres.

### Solution Code
```python
def main():
    import sys
    n, m = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    
    counts = [0] * (m + 1)
    for genre in a:
        counts[genre] += 1
    
    total_pairs = n * (n - 1) // 2
    same_pairs = sum(c * (c - 1) // 2 for c in counts)
    
    print(total_pairs - same_pairs)

main()
```

### Explanation
1. **Reading Input**: The input consists of the number of books `n` and genres `m`, followed by the list of genres for each book.
2. **Counting Genres**: We use an array `counts` to keep track of how many books belong to each genre.
3. **Total Pairs Calculation**: Using the combination formula, we compute the total number of ways to pick any two books.
4. **Same Genre Pairs Calculation**: For each genre, we compute the number of ways to pick two books from that genre and sum these values.
5. **Result Calculation**: Subtract the sum of same-genre pairs from the total pairs to get the number of valid pairs of different genres.

This approach efficiently computes the result in linear time relative to the number of books, making it suitable for large inputs up to the problem constraints.
