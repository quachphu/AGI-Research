To solve this problem, we need to count the number of non-empty palindromic subsequences in a given string. A palindromic subsequence is a sequence that reads the same forward and backward. The solution involves using dynamic programming (DP) to efficiently compute the count without generating all possible subsequences explicitly.

### Approach
1. **Dynamic Programming Table Setup**: We use a 2D array `dp` where `dp[i][j]` represents the number of palindromic subsequences in the substring starting at index `i` and ending at index `j`.

2. **Base Case**: Each single character is a palindrome by itself. Thus, `dp[i][i] = 1` for all `i`.

3. **Filling the DP Table**:
   - For substrings of length 2 to `n` (where `n` is the length of the string):
     - If the characters at the ends of the substring (i.e., `s[i]` and `s[j]`) are the same, the number of palindromic subsequences is the sum of the counts from the substrings `s[i+1..j]` and `s[i..j-1]` plus 1 (to account for the new palindromic subsequences formed by the current characters).
     - If the characters are different, the count is adjusted to avoid double-counting the subsequences from the overlapping subproblem `s[i+1..j-1]`.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for case_num in range(1, T + 1):
        s = input[case_num]
        n = len(s)
        if n == 0:
            print(0)
            continue
        dp = [[0] * n for _ in range(n)]
        for i in range(n):
            dp[i][i] = 1
        for l in range(2, n + 1):
            for i in range(n - l + 1):
                j = i + l - 1
                if s[i] == s[j]:
                    dp[i][j] = dp[i + 1][j] + dp[i][j - 1] + 1
                else:
                    dp[i][j] = dp[i + 1][j] + dp[i][j - 1] - dp[i + 1][j - 1]
        print(dp[0][n - 1])

if __name__ == "__main__":
    main()
```

### Explanation
- **Dynamic Programming Table Initialization**: The DP table `dp` is initialized to store counts of palindromic subsequences for all possible substrings.
- **Base Case Handling**: Each single character is a palindrome, so `dp[i][i]` is set to 1.
- **Iterative Filling**: For each substring length from 2 to `n`, compute the number of palindromic subsequences by considering whether the endpoints are the same or different. This ensures we efficiently count all valid palindromic subsequences without redundancy.
- **Result Extraction**: The value at `dp[0][n-1]` gives the total number of non-empty palindromic subsequences for the entire string, which is printed for each test case.

This approach efficiently computes the result in O(n^2) time and space complexity, making it feasible even for the maximum input size of 50 characters.
