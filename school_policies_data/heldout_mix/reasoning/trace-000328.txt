To solve this problem, we need to determine all possible values of x (the number of potatoes in the first bag) that Valera could have had, given the constraints on the total number of potatoes in both bags. The solution involves checking for valid values of x that meet specific divisibility and range conditions.

### Approach
1. **Understand the Constraints**: The sum of potatoes in both bags (x + y) must be divisible by k and must not exceed n. Additionally, x must be at least 1.
2. **Formulate the Problem**: We need to find all x such that x ≥ 1, x + y ≤ n, and (x + y) is divisible by k.
3. **Mathematical Insight**: The valid values of x must satisfy x ≡ (-y) mod k. This translates to finding multiples of k that, when added to y, fall within the range [y + 1, n].
4. **Calculate Bounds**: Determine the smallest and largest possible sums (s_min and s_max) that are multiples of k and within the valid range. Convert these sums back to x values by subtracting y.

### Solution Code
```python
y, k, n = map(int, input().split())

s_min = ((y + 1) + (k - 1)) // k * k
s_max = (n // k) * k

if s_min > n or s_max < s_min:
    print(-1)
else:
    start_x = s_min - y
    end_x = s_max - y
    x_values = list(range(start_x, end_x + 1, k))
    print(' '.join(map(str, x_values)))
```

### Explanation
1. **Reading Input**: The input values y, k, and n are read from standard input.
2. **Calculate s_min**: This is the smallest multiple of k that is at least y + 1. This ensures x is at least 1.
3. **Calculate s_max**: This is the largest multiple of k that does not exceed n.
4. **Check Validity**: If s_min exceeds n or s_max is less than s_min, there are no valid x values, so output -1.
5. **Generate x Values**: If valid, generate x values starting from s_min - y to s_max - y, stepping by k. These values are printed in ascending order.

This approach efficiently narrows down the possible values of x using mathematical properties of divisibility and modular arithmetic, ensuring the solution is optimal even for large input sizes.
