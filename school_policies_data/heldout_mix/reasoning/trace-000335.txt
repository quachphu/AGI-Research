To solve this problem, we need to dynamically maintain the count of coprime pairs in a shelf of beer glasses as they are added or removed through a series of queries. The key challenge is efficiently computing the number of coprime pairs after each query, which can be achieved using the Möbius function and divisor counts.

### Approach
1. **Precompute Divisors**: For each number up to the maximum possible value (500,000), precompute all divisors. This helps in efficiently updating counts when a beer is added or removed.
2. **Precompute Möbius Function**: The Möbius function helps in applying inclusion-exclusion principles to count coprime pairs. It is computed using a sieve method.
3. **Dynamic Count Management**: Maintain a count array where each entry represents how many numbers in the current shelf are divisible by a specific divisor. This count is updated as beers are added or removed.
4. **Efficient Delta Calculation**: When a beer is added or removed, compute the change in the number of coprime pairs (delta) by iterating over its divisors and using the precomputed counts and Möbius values.

### Solution Code
```python
import sys

def main():
    max_a = 500000
    # Precompute divisors for each number up to max_a
    divisors = [[] for _ in range(max_a + 1)]
    for d in range(1, max_a + 1):
        for multiple in range(d, max_a + 1, d):
            divisors[multiple].append(d)
    
    # Precompute the Möbius function using sieve method
    mu = [1] * (max_a + 1)
    is_prime = [True] * (max_a + 1)
    for p in range(2, max_a + 1):
        if is_prime[p]:
            # Mark multiples of p as not prime
            for multiple in range(2 * p, max_a + 1, p):
                is_prime[multiple] = False
            # Multiply mu by -1 for multiples of p
            for multiple in range(p, max_a + 1, p):
                mu[multiple] *= -1
            # Set mu to 0 for multiples of p^2
            p_square = p * p
            for multiple in range(p_square, max_a + 1, p_square):
                mu[multiple] = 0
    
    # Read input
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    q = int(input[ptr])
    ptr += 1
    a = list(map(int, input[ptr:ptr + n]))
    ptr += n
    
    shelf = [False] * n
    cnt = [0] * (max_a + 1)
    answer = 0
    
    for _ in range(q):
        x = int(input[ptr]) - 1  # Convert to 0-based index
        ptr += 1
        current_a = a[x]
        if not shelf[x]:
            # Add to shelf
            shelf[x] = True
            delta = 0
            for d in divisors[current_a]:
                delta += mu[d] * cnt[d]
                cnt[d] += 1
            answer += delta
        else:
            # Remove from shelf
            shelf[x] = False
            delta = 0
            for d in divisors[current_a]:
                cnt[d] -= 1
                delta += mu[d] * cnt[d]
            answer -= delta
        print(answer)

if __name__ == "__main__":
    main()
```

3. **Dynamic Updates**: For each query, we either add or remove a beer from the shelf. We update the divisor counts and use these counts along with the Möbius function to compute the change in the number of coprime pairs (delta).
