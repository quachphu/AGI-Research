To solve this problem, we need to rearrange the summands in a given sum such that they follow a non-decreasing order. This will allow Xenia to calculate the sum more easily.

### Approach
1. **Input Parsing**: The input string consists of digits (1, 2, 3) and plus signs. We first split this string into individual numbers using the '+' character as a delimiter.
2. **Sorting**: Convert the split string parts into integers and sort them in non-decreasing order. Alternatively, we can sort the string parts directly by converting them to integers during the comparison to avoid unnecessary type conversions.
3. **Output Formatting**: After sorting the numbers, we join them back into a string with '+' signs between each number to form the final result.

### Solution Code
```python
def main():
    s = input().strip()
    parts = s.split('+')
    parts_sorted = sorted(parts, key=lambda x: int(x))
    print('+'.join(parts_sorted))

main()
```

### Explanation
1. **Reading Input**: The input is read as a string and any leading or trailing whitespace is removed using `strip()`.
2. **Splitting the String**: The string is split into a list of substrings using the '+' character as the delimiter. This gives us the individual numbers as strings.
3. **Sorting**: The list of number strings is sorted based on their integer values using a lambda function as the key for the `sorted()` function. This ensures that the numbers are compared as integers but remain strings for easier joining later.
4. **Joining and Printing**: The sorted list of number strings is joined into a single string with '+' signs between each number, which is then printed as the final result.

This approach efficiently transforms the input into the required format while ensuring the summands are in an order that Xenia can work with.
