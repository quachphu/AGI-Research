To solve this problem, we need to select K elements from an array such that the difference between the maximum and minimum values in the selected elements is minimized. The optimal approach involves sorting the array and then examining consecutive windows of K elements to find the minimum possible difference.

### Approach
1. **Sort the Array**: Sorting the array ensures that elements are in ascending order, allowing us to efficiently check consecutive windows of K elements.
2. **Sliding Window Technique**: After sorting, we use a sliding window of size K to traverse the array. For each window, the difference between the maximum and minimum values (which are the first and last elements of the window, respectively, due to sorting) is calculated.
3. **Track Minimum Difference**: By iterating through all possible windows of size K, we keep track of the minimum difference encountered.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    k = int(sys.stdin.readline())
    arr = [int(sys.stdin.readline()) for _ in range(n)]
    arr.sort()
    min_diff = float('inf')
    for i in range(len(arr) - k + 1):
        current_diff = arr[i + k - 1] - arr[i]
        if current_diff < min_diff:
            min_diff = current_diff
    print(min_diff)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using standard input methods to handle potentially large input sizes efficiently.
2. **Sorting**: The array is sorted to facilitate the sliding window approach.
3. **Sliding Window**: By iterating through each possible starting index of a K-sized window, we compute the difference between the maximum and minimum values in that window. Since the array is sorted, the minimum and maximum values in any window are simply the first and last elements of the window.
4. **Finding Minimum Difference**: The minimum difference across all possible windows is tracked and printed as the result.

This approach ensures that we efficiently find the optimal solution with a time complexity dominated by the sorting step, O(N log N), followed by a linear scan, O(N), making it suitable for large input sizes up to 100,000 elements.
