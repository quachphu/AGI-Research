### Approach

3. **Gain Calculation**: For each cell, compute the maximum possible gain from repainting it to any color. This gain is calculated as the difference between the points from the new color minus the repainting cost and the initial points from the current color.

4. **Optimal Repaints**: Collect all positive gains from repainting cells, sort them in descending order, and sum the top K gains to maximize the total points.

5. **Result Calculation**: Add the sum of the top K gains to the base points to get the maximum possible points Chef can achieve.

import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N, M, K = map(int, input[ptr:ptr+3])
        ptr += 3

            C.append(row)

            a = A[i] - 1  # convert to 0-based index
