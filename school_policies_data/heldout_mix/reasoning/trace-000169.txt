To solve this problem, we need to determine if there exists a cycle in a directed graph where the sum of the weights of the edges in the cycle is positive. If such a cycle exists, we need to find the minimum number of rooms (nodes) visited in such a cycle. If no such cycle exists, the answer is 0.

### Approach
1. **Check for 2-node cycles**: First, we check all pairs of nodes connected by bidirectional edges. If the sum of the weights of the edges in both directions is positive, the answer is 2.
2. **Matrix exponentiation for longer cycles**: For cycles longer than 2 nodes, we use a dynamic programming approach inspired by matrix exponentiation. We compute the maximum sum of paths of increasing lengths (from 3 up to n) and check if any diagonal element of the resulting matrix (indicating a cycle) is positive.

### Solution Code
```python
import sys
import copy

def main():
    import sys
    sys.setrecursionlimit(1 << 25)
    n, m = map(int, sys.stdin.readline().split())
    INF = -float('inf')
    
    # Initialize adjacency matrix with -infinity
    adj = [[INF for _ in range(n)] for _ in range(n)]
    
    for _ in range(m):
        i, j, cij, cji = map(int, sys.stdin.readline().split())
        i -= 1  # converting to 0-based
        j -= 1
        adj[i][j] = cij
        adj[j][i] = cji
    
    def multiply(a, b):
        res = [[INF] * n for _ in range(n)]
        for i in range(n):
            for l in range(n):
                if a[i][l] == INF:
                    continue
                for j in range(n):
                    if b[l][j] == INF:
                        continue
                    if res[i][j] < a[i][l] + b[l][j]:
                        res[i][j] = a[i][l] + b[l][j]
        return res
    
    current = copy.deepcopy(adj)
    
    # Check for k=2
    current_k2 = multiply(adj, adj)
    for i in range(n):
        if current_k2[i][i] > 0:
            print(2)
            return
    
    # Check for k >=3 up to n
    current = current_k2  # current is adj^2 now
    for k in range(3, n + 1):
        current = multiply(current, adj)  # becomes adj^k
        for i in range(n):
            if current[i][i] > 0:
                print(k)
                return
    
    # If no cycle found
    print(0)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Matrix Initialization**: We start by initializing an adjacency matrix where each element represents the weight of the edge between two nodes. If there is no edge, the weight is set to negative infinity.
2. **Matrix Multiplication**: We define a function to multiply two matrices in a way that each element of the resulting matrix represents the maximum sum of paths of a given length.
3. **Check for 2-node Cycles**: We compute the matrix for paths of length 2 and check if any diagonal element (indicating a cycle starting and ending at the same node) is positive.
4. **Check for Longer Cycles**: For each possible cycle length from 3 up to n, we compute the matrix for paths of that length and check for positive cycles. If found, we immediately return the cycle length.
5. **Output Result**: If no positive cycle is found after checking all lengths up to n, we output 0.

This approach efficiently checks for the shortest positive cycle using matrix exponentiation, ensuring we find the minimum cycle length if it exists.
