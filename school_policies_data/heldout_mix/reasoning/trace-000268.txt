To solve this problem, we need to find the area of the largest rectangle composed solely of 0s in a given binary matrix. The solution leverages the concept of converting each row of the matrix into a histogram of consecutive 0s and then finding the largest rectangle in that histogram.

### Approach
1. **Convert Rows to Histograms**: For each row, compute the height of consecutive 0s ending at each column. If the current cell is 0, the height is incremented from the previous row's height; otherwise, it resets to 0.
2. **Largest Rectangle in Histogram**: For each row's histogram, use a stack-based algorithm to efficiently determine the largest rectangle. This algorithm processes each bar in the histogram, maintaining a stack of indices to track the largest rectangle that can be formed with each bar as the height.

    stack.append(-1)
    for i in range(len(heights)):
        while stack[-1] != -1 and heights[i] < heights[stack[-1]]:
            h = heights[stack.pop()]
            w = i - stack[-1] - 1
            max_area = max(max_area, h * w)
        stack.append(i)
    return max_area
