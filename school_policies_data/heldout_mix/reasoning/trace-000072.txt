To solve this problem, we need to determine all possible positions of the Smart Beaver in a queue where each beaver knows who should be in front of them, except for those who don't (marked with 0). The challenge is to account for the arbitrary order of different chains of beavers and compute the possible positions based on these permutations.

### Approach
1. **Identify Chains**: Each beaver either starts a new chain (if their predecessor is 0) or belongs to an existing chain. We need to group beavers into chains based on their dependencies.
2. **Determine Position in Chain**: For the Smart Beaver, identify which chain he belongs to and his position within that chain.
3. **Compute Subset Sums**: The possible positions of the Smart Beaver in the overall queue depend on the lengths of other chains and their permutations. We compute all possible sums of the lengths of these chains to determine the range of possible starting positions before the Smart Beaver's chain.
4. **Generate Possible Positions**: Combine the subset sums with the Smart Beaver's position within his chain to get all possible positions and sort them.

### Solution Code
```python
from collections import defaultdict

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    x = int(input[idx])
    idx += 1
    a = list(map(int, input[idx:idx+n]))
    idx += n

    root_to_nodes = defaultdict(list)

    for i in range(1, n + 1):
        # Find the root of i
        root = i
        while a[root - 1] != 0:
            root = a[root - 1]
        # Calculate depth from i to root
        current = i
        depth = 0
        while current != root:
            current = a[current - 1]
            depth += 1
        root_to_nodes[root].append((i, depth))

    chains = []
    for root in root_to_nodes:
        nodes = sorted(root_to_nodes[root], key=lambda nd: nd[1])
        chain = [nd[0] for nd in nodes]
        chains.append(chain)

    x_chain = None
    x_pos = -1
    for chain in chains:
        if x in chain:
            x_chain = chain
            x_pos = chain.index(x) + 1  # 1-based
            break

    other_lengths = [len(chain) for chain in chains if chain is not x_chain]

    subset_sums = {0}
    for l in other_lengths:
        new_sums = set()
        for s in subset_sums:
            new_sums.add(s)
            new_sums.add(s + l)
        subset_sums = new_sums

    possible_positions = sorted(s + x_pos for s in subset_sums)
    for pos in possible_positions:
        print(pos)

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read and parsed into the number of beavers, the Smart Beaver's number, and the list of predecessors.
2. **Chain Identification**: For each beaver, we determine their root (the start of their chain) and their depth within the chain. This helps in grouping beavers into chains.
