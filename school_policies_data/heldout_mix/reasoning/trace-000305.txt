To solve this problem, we need to efficiently count the occurrences of three types of terrain ("Jungle", "Ocean", and "Ice") in multiple rectangular regions of a grid. The solution involves using prefix sums to quickly compute the counts for each query.

### Approach
1. **Prefix Sum Arrays**: We create three prefix sum arrays for each type of terrain ('J', 'O', 'I'). Each prefix sum array at position (i, j) will store the count of the respective terrain type from the top-left corner (1, 1) to (i, j) in the grid.
2. **Efficient Query Processing**: For each query, we use the inclusion-exclusion principle on the prefix sum arrays to compute the count of each terrain type in the specified rectangular region in constant time.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    
    M = int(input[ptr])
    ptr += 1
    N = int(input[ptr])
    ptr += 1
    K = int(input[ptr])
    ptr += 1
    
    grid = []
    for _ in range(M):
        grid.append(input[ptr])
        ptr += 1
    
    queries = []
    for _ in range(K):
        a = int(input[ptr])
        b = int(input[ptr+1])
        c = int(input[ptr+2])
        d = int(input[ptr+3])
        queries.append((a, b, c, d))
        ptr += 4
    
    # Initialize prefix sums for J, O, I
    prefix_J = [[0]*(N+1) for _ in range(M+1)]
    prefix_O = [[0]*(N+1) for _ in range(M+1)]
    prefix_I = [[0]*(N+1) for _ in range(M+1)]
    
    for i in range(1, M+1):
        for j in range(1, N+1):
            current_char = grid[i-1][j-1]
            j_val = 1 if current_char == 'J' else 0
            o_val = 1 if current_char == 'O' else 0
            i_val = 1 if current_char == 'I' else 0
            
            prefix_J[i][j] = prefix_J[i-1][j] + prefix_J[i][j-1] - prefix_J[i-1][j-1] + j_val
            prefix_O[i][j] = prefix_O[i-1][j] + prefix_O[i][j-1] - prefix_O[i-1][j-1] + o_val
            prefix_I[i][j] = prefix_I[i-1][j] + prefix_I[i][j-1] - prefix_I[i-1][j-1] + i_val
    
    results = []
    for a, b, c, d in queries:
        j = prefix_J[c][d] - prefix_J[a-1][d] - prefix_J[c][b-1] + prefix_J[a-1][b-1]
        o = prefix_O[c][d] - prefix_O[a-1][d] - prefix_O[c][b-1] + prefix_O[a-1][b-1]
        i = prefix_I[c][d] - prefix_I[a-1][d] - prefix_I[c][b-1] + prefix_I[a-1][b-1]
        results.append(f"{j} {o} {i}")
    
    print('\n'.join(results))

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into tokens for efficient processing.
2. **Prefix Sum Calculation**: For each cell in the grid, we compute the prefix sums for each terrain type. This allows us to quickly determine the count of each terrain in any sub-rectangle using the inclusion-exclusion principle.
3. **Query Processing**: For each query, we use the prefix sums to compute the counts of each terrain type in the specified sub-rectangle in constant time, resulting in an efficient solution even for large grids and numerous queries.
