To solve this problem, we need to determine the minimum time required for all people to reach the office after picking up keys. Each person must pick a unique key, and the time taken is the maximum time among all individuals. The approach involves sorting both the positions of people and keys, then evaluating all possible subsets of keys to find the optimal solution.

### Approach
1. **Sort Positions**: First, sort the positions of the people and the keys. This allows us to efficiently explore subsets of keys in a systematic manner.
2. **Sliding Window Technique**: Use a sliding window approach to consider all possible consecutive subsets of keys (of length equal to the number of people). For each subset, compute the maximum time required for any person in that subset to reach the office.
3. **Calculate Time**: For each subset of keys, calculate the time taken for each person to pick a key and then reach the office. The maximum time in each subset is recorded, and the minimum of these maximum times across all subsets is the solution.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    k = int(input[idx+1])
    p = int(input[idx+2])
    idx += 3
    a = list(map(int, input[idx:idx+n]))
    idx += n
    b = list(map(int, input[idx:idx+k]))
    a.sort()
    b.sort()
    min_time = float('inf')
    for start in range(k - n + 1):
        current_max = 0
        for i in range(n):
            time = abs(a[i] - b[start + i]) + abs(b[start + i] - p)
            if time > current_max:
                current_max = time
        if current_max < min_time:
            min_time = current_max
    print(min_time)

main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of people, keys, and the office position. The positions of people and keys are also read and stored in lists.
2. **Sorting**: Both the people's positions and keys' positions are sorted. Sorting helps in systematically exploring consecutive subsets of keys, which is crucial for the sliding window technique.
3. **Sliding Window**: For each possible starting position of a subset of keys (window of size `n`), the code calculates the time each person would take if they picked the corresponding key in that window. The time is computed as the sum of the distance from the person's position to the key and from the key to the office.
4. **Determine Minimum Time**: For each window, the maximum time among all people is determined. The minimum of these maximum times across all windows is the result, which is printed as the solution.

This approach efficiently narrows down the optimal key assignments using sorting and sliding window techniques, ensuring that we consider all viable key subsets while maintaining computational efficiency.
