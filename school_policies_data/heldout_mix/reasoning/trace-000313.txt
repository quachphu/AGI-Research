To solve this problem, we need to determine the minimum number of edits (substitutions and deletions) required to transform the received string into the original string, ignoring case changes. The solution involves using dynamic programming to efficiently compute the minimum edits needed.

### Approach
1. **Problem Analysis**: The problem requires transforming the received string into the original string using the minimum number of edits. The allowed operations are deleting a character from the received string or substituting a character in the received string to match the original string. The case of the characters is ignored.

2. **Dynamic Programming (DP) Setup**: We use a DP table where `dp[i][j]` represents the minimum number of edits required to convert the first `j` characters of the received string into the first `i` characters of the original string.

3. **Initialization**:
   - `dp[0][j]` is initialized to `j` because converting an empty original string to a received string of length `j` requires deleting all `j` characters.
   - `dp[i][0]` for `i > 0` is set to infinity because converting a non-empty original string to an empty received string is impossible.

4. **DP Transition**:
   - If characters at positions `i-1` (original) and `j-1` (received) match (case-insensitive), the cost is 0.
   - Otherwise, the substitution cost is 1.
   - The value of `dp[i][j]` is the minimum of substituting the character or deleting the character from the received string.

### Solution Code
```python
import sys

def min_edits():
    s = int(sys.stdin.readline())
    for _ in range(s):
        original = sys.stdin.readline().rstrip('\n').lower()
        received = sys.stdin.readline().rstrip('\n').lower()
        
        m = len(original)
        n = len(received)
        
        # Initialize DP table
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        for i in range(m + 1):
            for j in range(n + 1):
                if i == 0:
                    dp[i][j] = j  # Need to delete all j characters
                elif j == 0:
                    dp[i][j] = float('inf')  # Impossible to convert to non-empty string
                else:
                    # Check if current characters match (case-insensitive)
                    if original[i-1] == received[j-1]:
                        cost = 0
                    else:
                        cost = 1
                    # Possible operations: substitution or deletion
                    substitution = dp[i-1][j-1] + cost
                    deletion = dp[i][j-1] + 1
                    dp[i][j] = min(substitution, deletion)
        
        result = dp[m][n]
        print(result if result != float('inf') else 0)

min_edits()
```

### Explanation
- **Dynamic Programming Table**: The DP table `dp` is used to store the minimum edits required for each substring of the original and received strings.
- **Base Cases**: The first row is initialized to handle deletions, and the first column (except `dp[0][0]`) is set to infinity as converting a non-empty string to an empty one is impossible.
- **Transitions**: For each character in the original and received strings, the DP table is updated by considering the minimum cost of substitution or deletion.
- **Result Extraction**: The value at `dp[m][n]` gives the minimum edits required to convert the entire received string into the original string. If the result is infinity (indicating impossibility), it is handled by printing 0, though this scenario is not expected given the problem constraints.

This approach efficiently computes the minimum edits using dynamic programming, ensuring optimal performance even for the maximum input size constraints.
