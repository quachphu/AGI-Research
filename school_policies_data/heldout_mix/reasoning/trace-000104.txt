To solve this problem, we need to find the minimal number of steps required to move all ghosts in a haunted house to their designated target positions. The ghosts can move simultaneously, but with constraints to avoid collisions and position swaps.

### Approach
1. **Problem Analysis**: The problem involves navigating ghosts through a grid to their target positions while adhering to movement constraints. Each ghost can move to an adjacent cell or stay in place, but no two ghosts can end up in the same cell, and they cannot swap positions in a single step.

2. **State Representation**: Each state in our search is represented by the positions of all ghosts. For `n` ghosts, this is a tuple of tuples, where each inner tuple represents the position of a ghost.

3. **Breadth-First Search (BFS)**: We use BFS to explore all possible states level by level, ensuring the shortest path is found. Each state transition involves generating all valid next states by considering all possible moves for each ghost and checking the constraints.

4. **Constraints Handling**: For each generated state, we check two constraints:
   - No two ghosts occupy the same position.
   - No pair of ghosts swaps positions.
