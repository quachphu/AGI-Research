### Approach
1. **Understand the Battle Mechanics**: Both Master Yang and the monster attack each other simultaneously. The damage each deals is determined by their respective ATK and the opponent's DEF. Master Yang wins if the monster's HP drops to zero or below while his HP remains positive.

2. **Attributes Optimization**: We need to consider all possible upgrades to Master Yang's attributes (HP, ATK, DEF) and calculate the minimum cost for each combination that allows him to win. The key steps are:
   - **Calculate Minimum ATK**: Master Yang's ATK must be sufficient to deal damage to the monster. The minimum ATK required is the monster's DEF + 1.
   - **Calculate Maximum ATK**: The maximum ATK needed is determined by the monster's HP and DEF to minimize the number of rounds required to defeat the monster.
   - **Calculate DEF Range**: Master Yang's DEF should be optimized to reduce the damage taken from the monster. The maximum DEF needed is the monster's ATK to nullify the damage.
   - **Calculate Required HP**: For each combination of ATK and DEF, compute the required HP to survive the battle.

3. **Iterate and Compute Costs**: Loop through all possible values of ATK and DEF upgrades, compute the required HP, and determine the total cost for each combination. Track the minimum cost encountered.

### Solution Code
```python
HPY, ATKY, DEFY = map(int, input().split())
HPM, ATKM, DEFM = map(int, input().split())
h, a, d = map(int, input().split())

min_cost = float('inf')

delta_ATK_min = max(0, DEFM + 1 - ATKY)
delta_ATK_max_candidate = DEFM + HPM - ATKY
delta_ATK_max = max(delta_ATK_min, delta_ATK_max_candidate)

if DEFY < ATKM:
    max_d_def = ATKM - DEFY
else:
    max_d_def = 0

for delta_ATK in range(delta_ATK_min, delta_ATK_max + 1):
    Y_ATK = ATKY + delta_ATK
    damageY = Y_ATK - DEFM
    if damageY <= 0:
        continue  # Cannot deal damage, skip this delta_ATK
    
    for delta_DEF in range(0, max_d_def + 1):
        Y_DEF = DEFY + delta_DEF
        damageM = max(0, ATKM - Y_DEF)
        
        t_kill = (HPM + damageY - 1) // damageY  # Ceiling division
        required_HP = damageM * t_kill + 1
        delta_HP = max(0, required_HP - HPY)
        
        total_cost = delta_ATK * a + delta_DEF * d + delta_HP * h
        if total_cost < min_cost:
            min_cost = total_cost

print(min_cost)
```
