To solve this problem, we need to determine the minimal number of fake schools Arkady has to create so that all chosen students are selected by the Technogoblet. The solution involves checking if each chosen student is the strongest in their original school. If not, they need to be moved to a fake school.

### Approach
1. **Read Input:** Read the number of students, schools, and chosen students along with their respective powers and school assignments.
2. **Determine Maximum Power per School:** For each school, compute the maximum power among its students.
3. **Check Chosen Students:** For each chosen student, check if their power is the maximum in their original school. If not, they need to be moved to a fake school.
4. **Count Fake Schools Needed:** Count the number of chosen students who are not the strongest in their original schools, as each of these students will require a fake school.

### Solution Code
```python
n, m, k = map(int, input().split())
p = list(map(int, input().split()))
s = list(map(int, input().split()))
c = list(map(int, input().split()))

school_max = {}
for i in range(n):
    school = s[i]
    current_p = p[i]
    if school not in school_max or current_p > school_max[school]:
        school_max[school] = current_p

count = 0
for student_id in c:
    idx = student_id - 1
    student_school = s[idx]
    student_power = p[idx]
    if student_power < school_max[student_school]:
        count += 1

print(count)
```

### Explanation
1. **Reading Input:** The input values are read and stored in appropriate variables. The power and school assignments of each student are stored in lists `p` and `s`, respectively.
2. **Computing Maximum Power per School:** Using a dictionary `school_max`, we track the highest power for each school by iterating through each student's data.
3. **Evaluating Chosen Students:** For each chosen student, we check if their power is less than the maximum power in their respective school. If true, it indicates they need a fake school.
4. **Counting Fake Schools:** The count of students needing fake schools is incremented each time a chosen student is not the strongest in their original school, resulting in the minimal number of fake schools required.

This approach efficiently determines the solution by leveraging dictionary lookups and linear scans, ensuring optimal performance given the problem constraints.
