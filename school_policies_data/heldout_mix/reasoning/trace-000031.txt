To solve this problem, we need to determine the minimum time required for two participants to collect all prizes located on a straight line. The participants start at positions 1 and 1,000,000, respectively, and can move one unit per second. The goal is to minimize the maximum time taken by either participant to collect their assigned prizes.

### Approach
1. **Problem Analysis**:
   - The participants can collect prizes in any order, but the optimal strategy involves splitting the prizes such that the maximum time taken by either participant is minimized.
   - The time taken by each participant is determined by the farthest prize they need to collect. For the participant starting at position 1, the time is the position of the farthest prize minus 1. For the participant starting at position 1,000,000, the time is 1,000,000 minus the position of the closest prize (smallest position) assigned to them.

2. **Key Insight**:
   - The optimal split of prizes between the two participants can be determined by considering all possible split points in the sorted list of prize positions. For each split point, the left part (up to the split point) is collected by the participant starting at position 1, and the right part (from the split point onwards) is collected by the participant starting at position 1,000,000.

3. **Algorithm**:
   - Iterate over all possible split points from 0 to n (inclusive). For each split point, compute the maximum time taken by either participant and keep track of the minimum of these maximum times.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))

min_time = float('inf')

for k in range(n + 1):
    if k == 0:
        me_time = 0
        friend_time = 10**6 - a[0] if n > 0 else 0
    elif k == n:
        me_time = a[-1] - 1 if n > 0 else 0
        friend_time = 0
    else:
        me_time = a[k-1] - 1
        friend_time = 10**6 - a[k]
    current_max = max(me_time, friend_time)
    if current_max < min_time:
        min_time = current_max

print(min_time)
```

### Explanation
1. **Reading Input**:
   - The input consists of the number of prizes and their positions. The positions are given in ascending order.

2. **Iterating Over Split Points**:
   - For each possible split point `k`, the first `k` prizes are assigned to the participant starting at position 1, and the remaining prizes are assigned to the participant starting at position 1,000,000.

3. **Calculating Times**:
   - For `k = 0`, all prizes are collected by the friend, so the time is determined by the closest prize to the friend's starting position.
   - For `k = n`, all prizes are collected by the participant starting at position 1, so the time is determined by the farthest prize from their starting position.
   - For intermediate values of `k`, the time for each participant is calculated based on the farthest prize in their respective assigned segments.

4. **Finding Minimum Time**:
   - The maximum time for each split point is computed, and the minimum of these maximum values across all split points is the answer.

This approach efficiently determines the optimal strategy by leveraging the sorted order of prize positions and iterating through all possible splits, ensuring the solution is both optimal and efficient.
