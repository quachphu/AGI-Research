The solution involves checking if the three strings can be embedded as non-overlapping subsequences after each update.

### Approach

2. **Check Subsequence Validity**: For each query, after updating the strings, check if the sum of their lengths exceeds the length of the 'Word of Universe'. If it does, output "NO".
3. **Permutations of Strings**: For each valid query, generate all permutations of the three strings to check all possible interleavings.
4. **Greedy Subsequence Check**: For each permutation, check if the strings can be embedded as non-overlapping subsequences using a greedy approach. This involves checking each string in the permutation order, ensuring that each subsequent string is checked against the remaining characters of the 'Word of Universe'.

import sys
from itertools import permutations

def main():
    n, q = map(int, sys.stdin.readline().split())
    word = sys.stdin.readline().strip()

    # Precompute next occurrence of each character for each position
    next_pos = {}
    for c in 'abcdefghijklmnopqrstuvwxyz':
        next_pos[c] = [n] * (n + 1)
        last = n
        for i in range(n-1, -1, -1):
            if word[i] == c:
                last = i
            next_pos[c][i] = last

    s1 = []
    s2 = []
    s3 = []

    def check_possible():
        len1 = len(s1)
        len2 = len(s2)
        len3 = len(s3)
        total = len1 + len2 + len3
        if total > n:
            return False
        if total == 0:
            return True

        # Prepare the three strings
        A = ''.join(s1)
        B = ''.join(s2)
        C = ''.join(s3)

        # Iterate all permutations of the three strings
        for perm in permutations([A, B, C]):
            s_a, s_b, s_c = perm

            # Precompute the next_pos arrays for each string
            dp = [[[n+1]*(len(s_c)+1) for _ in range(len(s_b)+1)] for __ in range(len(s_a)+1)]
            dp[0][0][0] = -1

            for i in range(len(s_a)+1):
                for j in range(len(s_b)+1):
                    for k in range(len(s_c)+1):
