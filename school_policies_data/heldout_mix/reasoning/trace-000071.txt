To solve this problem, we need to determine how many times a host team will wear their guest uniform during a football championship. This happens when the host team's home uniform color matches the guest team's away uniform color. 

### Approach
1. **Problem Analysis**: Each team plays every other team twice, once at home and once as a guest. The host team will wear their guest uniform if their home color matches the guest team's away color. We need to count all such occurrences.
2. **Intuition**: For each pair of teams (i, j) where i is the host and j is the guest, check if the home color of team i matches the away color of team j. If it does, increment the count.
3. **Algorithm**: 
   - Read the number of teams and their respective home and away colors.
   - For each ordered pair (i, j) where i ≠ j, check if the home color of team i matches the away color of team j.
   - Sum up all such occurrences and print the result.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    idx = 1
    teams = []
    for _ in range(n):
        h = int(input[idx])
        a = int(input[idx + 1])
        teams.append((h, a))
        idx += 2
    count = 0
    for i in range(n):
        h_i, a_i = teams[i]
        for j in range(n):
            if i != j:
                if h_i == teams[j][1]:
                    count += 1
    print(count)

main()
```

### Explanation
- **Reading Input**: The input is read in one go and split into a list for easier processing. The first element is the number of teams, followed by pairs of integers representing each team's home and away colors.
- **Storing Team Data**: Each team's home and away colors are stored in a list of tuples for quick access.
- **Checking Pairs**: For each possible host and guest pair (i, j), where i ≠ j, we check if the host's home color matches the guest's away color. If it does, we increment the count.
- **Output**: The total count is printed, which represents the number of times the host team wears their guest uniform.

This approach efficiently checks all possible pairs and ensures we count all valid occurrences where the host team must switch uniforms, resulting in an optimal solution with a time complexity of O(n²), which is feasible given the constraints (n ≤ 30).
