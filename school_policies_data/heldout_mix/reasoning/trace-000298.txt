To solve this problem, we need to determine the minimum number of pages Little Jhool needs to tear out from two types of notebooks such that no space is wasted. The first notebook allows solving 10 problems per page, and the second allows solving 12 problems per page. If it's not possible to exactly use all the space, we should return -1.

### Approach
1. **Problem Analysis**: We need to find non-negative integers \( x \) and \( y \) such that \( 10x + 12y = n \), where \( n \) is the number of problems given. The goal is to minimize the total pages \( x + y \).
2. **Iterative Check**: For each possible number of pages \( y \) from the second notebook (which can solve 12 problems per page), check if the remaining problems can be exactly solved by pages from the first notebook (which can solve 10 problems per page).
3. **Range of Check**: The maximum value of \( y \) is determined by \( n // 12 \). For each \( y \) in this range, compute the remaining problems and check if they can be solved by an integer number of pages from the first notebook.
4. **Optimization**: Track the minimum total pages required across all valid combinations of \( x \) and \( y \).

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    min_pages = float('inf')
    max_y = n // 12
    for y in range(max_y + 1):
        rem = n - 12 * y
        if rem >= 0 and rem % 10 == 0:
            x = rem // 10
            total = x + y
            if total < min_pages:
                min_pages = total
    print(-1 if min_pages == float('inf') else min_pages)
```

### Explanation
1. **Reading Input**: The first input is the number of test cases. For each test case, read the number of problems \( n \).
2. **Initialization**: Initialize `min_pages` to a large value to track the minimum pages needed.
3. **Iterate Over Possible Pages from Second Notebook**: Calculate the maximum possible \( y \) (pages from the second notebook) as \( n // 12 \). For each \( y \) from 0 to this maximum:
   - Compute the remaining problems after using \( y \) pages from the second notebook.
   - Check if these remaining problems can be exactly solved by pages from the first notebook (i.e., if the remaining problems are a multiple of 10).
   - If valid, compute the total pages and update `min_pages` if this total is smaller.
4. **Output Result**: After checking all possible \( y \), if no valid combination was found, output -1. Otherwise, output the minimum pages found.

This approach efficiently checks all possible combinations to ensure the optimal solution is found within the constraints.
