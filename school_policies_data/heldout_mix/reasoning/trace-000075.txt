To solve this problem, we need to determine if we can divide a list of apples, each weighing either 100 grams or 200 grams, into two groups such that each group has the same total weight. 

### Approach
1. **Check Total Weight Parity**: The sum of the weights of the apples must be even. However, since each apple's weight is a multiple of 100, the total weight is always a multiple of 100. Therefore, the total weight being even is guaranteed, but we need to check if the sum of the apples can be split into two equal parts.
2. **Count Apples**: Count the number of 100-gram apples (x) and 200-gram apples (y).
3. **Check Feasibility**: The key insight is to check if we can form subsets of apples that sum up to half of the total weight. This involves checking possible combinations of 100-gram and 200-gram apples that can achieve the required sum.

### Solution Code
```python
n = int(input())
weights = list(map(int, input().split()))
x = weights.count(100)
y = n - x

k = x + 2 * y
if k % 2 != 0:
    print("NO")
else:
    m = k // 2
    max_b = min(y, m // 2)
    possible = False
    for b in range(0, max_b + 1):
        a = m - 2 * b
        if 0 <= a <= x:
            possible = True
            break
    print("YES" if possible else "NO")
```

### Explanation
1. **Input Reading**: Read the number of apples and their respective weights.
2. **Count Apples**: Determine the number of 100-gram (x) and 200-gram (y) apples.
3. **Check Parity**: Calculate `k` as the sum of 100-gram apples plus twice the number of 200-gram apples. If `k` is odd, print "NO" immediately because it's impossible to split the apples into two equal parts.
4. **Feasibility Check**: If `k` is even, compute `m` as half of `k`. Check all possible counts of 200-gram apples (b) from 0 to the minimum of available 200-gram apples and half of `m`. For each possible `b`, compute the corresponding number of 100-gram apples (a) needed and check if it is feasible. If any valid combination is found, print "YES"; otherwise, print "NO".

This approach efficiently checks all possible valid combinations of apples to determine if a fair division is possible, ensuring correctness and optimal performance given the constraints.
