To solve this problem, we need to determine the number of subtractions required to reduce a given integer \( n \) to 0 using a specific algorithm. The algorithm repeatedly subtracts the smallest prime divisor of the current number until it reaches 0. 

### Approach
1. **Check if \( n \) is even**: If \( n \) is even, the smallest prime divisor is 2. Subtracting 2 repeatedly will reduce \( n \) to 0 in \( n/2 \) steps.
2. **Check if \( n \) is odd**: For an odd \( n \), we need to find the smallest prime divisor. If \( n \) is prime, it will be reduced to 0 in one step. If \( n \) is composite, subtract its smallest prime divisor once (making the result even) and then continue subtracting 2 as described for even numbers.

### Solution Code
```python
n = int(input())
if n % 2 == 0:
    print(n // 2)
else:
    d = n
    sqrt_n = int(n ** 0.5)
    for i in range(3, sqrt_n + 1, 2):
        if n % i == 0:
            d = i
            break
    if d == n:
        print(1)
    else:
        print(1 + (n - d) // 2)
```

### Explanation
1. **Even Check**: If \( n \) is even, the smallest prime divisor is 2. The number of steps is simply \( n/2 \) because each subtraction reduces \( n \) by 2.
2. **Odd Check**: For an odd \( n \):
   - Find the smallest prime divisor by checking divisibility starting from 3 up to the square root of \( n \).
   - If \( n \) is prime, the smallest prime divisor is \( n \) itself, so it takes one step.
   - If \( n \) is composite, subtract the smallest prime divisor once (resulting in an even number) and then continue subtracting 2. The total steps are \( 1 + (n - \text{smallest prime divisor}) / 2 \).

This approach efficiently handles both small and large values of \( n \) up to \( 10^{10} \) by leveraging mathematical properties and efficient divisor checks.
