The key challenge is to check if there exists a valid permutation of the alphabet such that the given list of words adheres to the lexicographical order defined by that permutation.

### Approach
1. **Prefix Check**: For each consecutive pair of words, check if the first word is a prefix of the second and vice versa. If a longer word precedes a shorter word that is its prefix, the list is invalid.
2. **Constraint Collection**: For each consecutive pair of words, identify the first differing character and create a constraint that the character from the first word must come before the character from the second word in the permutation.
3. **Cycle Detection**: Construct a directed graph where edges represent the constraints between characters. Check if this graph has any cycles. If a cycle exists, the constraints are conflicting, making the permutation impossible.
