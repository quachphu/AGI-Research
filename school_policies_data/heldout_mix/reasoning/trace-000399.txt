To solve this problem, we need to decode an encrypted word from an African crossword grid by removing all letters that appear more than once in their respective row or column. The remaining letters are then concatenated in a specific order to form the final word.

### Approach
1. **Read Input:** First, we read the dimensions of the grid and the grid itself.
2. **Check Uniqueness:** For each cell in the grid, we determine if the letter is unique in both its row and column. This is done by counting occurrences of the letter in the respective row and column.
3. **Collect Valid Letters:** If a letter is unique in both its row and column, it is collected into a result list.
4. **Output Result:** The collected letters are concatenated in the order they appear from top to bottom and left to right, which is the row-major order.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    m = int(input[1])
    grid = input[2:2+n]
    result = []
    for i in range(n):
        for j in range(m):
            c = grid[i][j]
            row_count = grid[i].count(c)
            col_count = sum(1 for k in range(n) if grid[k][j] == c)
            if row_count == 1 and col_count == 1:
                result.append(c)
    print(''.join(result))

solve()
```

### Explanation
1. **Reading Input:** The input is read as a single string split into parts. The first two parts are the dimensions `n` and `m`, followed by the grid rows.
2. **Row and Column Checks:** For each cell `(i, j)`, we count how many times the character `grid[i][j]` appears in its row and column. This is done using `row.count(c)` for the row and a generator expression for the column.
3. **Uniqueness Check:** If the character appears exactly once in both its row and column, it is added to the result list.
4. **Result Construction:** The valid characters are collected in row-major order (top to bottom, left to right) and joined into a single string, which is printed as the final result.

This approach ensures that we efficiently check each cell's uniqueness and construct the result in the required order, leading to the correct decrypted word.
