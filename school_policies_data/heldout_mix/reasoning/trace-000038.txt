To solve this problem, we need to identify and list all vowels present in each given word, maintaining their order of appearance. If no vowels are found in a word, we should output "No". The solution must handle both uppercase and lowercase vowels.

### Approach
1. **Read Input**: First, read the number of test cases.
2. **Process Each Word**: For each word, check each character to see if it is a vowel.
3. **Collect Vowels**: Gather all vowels in the order they appear in the word.
4. **Output Result**: If no vowels are found, output "No"; otherwise, output the collected vowels as a string.

### Solution Code
```python
def main():
    vowels = {'a', 'e', 'i', 'o', 'u', 'A', 'E', 'I', 'O', 'U'}
    t = int(input())
    for _ in range(t):
        word = input().strip()
        collected = [c for c in word if c in vowels]
        print(''.join(collected) if collected else "No")

main()
```

### Explanation
1. **Reading Input**: The function starts by reading the number of test cases `t`.
2. **Vowel Set**: A set of vowels (both lowercase and uppercase) is defined for quick lookup.
3. **Processing Each Word**: For each test case, the word is read and stripped of any leading/trailing whitespace.
4. **Collecting Vowels**: Each character in the word is checked against the vowel set. If it is a vowel, it is added to a list.
5. **Generating Output**: After processing all characters in the word, the collected list of vowels is joined into a string and printed. If the list is empty, "No" is printed instead.

This approach ensures that we efficiently check each character and maintain the order of appearance, providing the correct output for each test case.
