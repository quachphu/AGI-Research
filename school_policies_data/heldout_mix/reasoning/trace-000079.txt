To solve this problem, we need to determine if a given level in the game "King of Thieves" is "good." A level is considered good if there exists a sequence of five platforms (denoted by '*') such that the intervals between consecutive platforms are the same length.

### Approach
1. **Input Handling**: Read the number of segments and the level scheme.
2. **Edge Case Check**: If the number of segments is less than 5, immediately output "no" since it's impossible to have five consecutive platforms.
3. **Iterate Over Possible Starting Positions**: For each position in the level scheme that contains a platform ('*'), check if it can be the start of a valid sequence.
4. **Check Possible Step Sizes**: For each valid starting position, check all possible step sizes (d) that could form a sequence of five platforms with equal intervals.
5. **Validation**: For each combination of starting position and step size, verify if all subsequent positions (i + d, i + 2d, i + 3d, i + 4d) are within bounds and contain platforms.

### Solution Code
```python
n = int(input())
s = input().strip()

if n < 5:
    print("no")
else:
    found = False
    for i in range(n):
        if s[i] != '*':
            continue
        max_d = (n - 1 - i) // 4
        for d in range(1, max_d + 1):
            valid = True
            for k in range(1, 5):
                pos = i + k * d
                if pos >= n or s[pos] != '*':
                    valid = False
                    break
            if valid:
                print("yes")
                exit()
    print("no")
```

### Explanation
1. **Edge Case Handling**: If the number of segments (n) is less than 5, print "no" immediately since forming a sequence of five platforms is impossible.
2. **Iterate Through Positions**: Loop through each position in the level scheme. Skip positions that are pits ('.').
3. **Calculate Maximum Step Size**: For each valid starting position, calculate the maximum possible step size that allows four jumps (i.e., five platforms) without exceeding the segment bounds.
4. **Check Validity of Sequence**: For each step size, check if the next four positions (calculated using the step size) are all platforms. If a valid sequence is found, print "yes" and exit.
5. **Final Check**: If no valid sequence is found after checking all possibilities, print "no".

This approach efficiently checks all possible sequences by iterating through each starting position and step size, ensuring that we cover all potential valid configurations while adhering to the problem constraints.
