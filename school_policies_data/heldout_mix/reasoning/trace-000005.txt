To solve this problem, we need to determine the maximum number of valid phone numbers that can be formed using a given set of digit cards. A valid phone number must be exactly 11 digits long, starting with an '8', followed by 10 additional digits.

### Approach
The solution involves two key insights:
1. **Length Requirement**: Each valid phone number requires exactly 11 digits. Therefore, the maximum number of phone numbers that can be formed is constrained by the total number of digits divided by 11.
2. **Digit '8' Requirement**: Each valid phone number must start with the digit '8'. Thus, the number of phone numbers is also constrained by the count of '8's in the input string.

The maximum number of valid phone numbers is the minimum of these two constraints. If either constraint is not met (i.e., there are fewer than 11 digits or no '8's), the result is 0.

### Solution Code
```python
n = int(input())
s = input().strip()
count_8 = s.count('8')
possible = n // 11
max_phones = min(count_8, possible)
print(max_phones if max_phones > 0 else 0)
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` (number of digits) and a string `s` of length `n` containing the digits.
2. **Count '8's**: We count the occurrences of the digit '8' in the string `s`.
3. **Calculate Possible Phone Numbers**: The total possible phone numbers based on the length of the string is `n // 11` (integer division of the number of digits by 11).
4. **Determine Maximum Valid Phone Numbers**: The result is the minimum of the count of '8's and the possible phone numbers based on length. If this minimum is at least 1, it is printed; otherwise, 0 is printed.

This approach efficiently combines the two constraints to determine the maximum number of valid phone numbers that can be formed, ensuring optimal performance and correctness.
