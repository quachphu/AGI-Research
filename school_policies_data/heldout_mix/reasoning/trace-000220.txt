To solve this problem, we need to determine the minimum number of people who could have broken into the theater basement and the number of swords each person took. The solution involves analyzing the remaining swords of each type and using mathematical operations to derive the required values efficiently.

### Approach
1. **Identify the Maximum Remaining Swords (x):** The initial number of swords of each type, x, must be at least as large as the maximum number of swords remaining in any type. This is because the remaining swords of each type cannot exceed the initial count.
2. **Compute Differences:** For each type of sword, calculate the difference between the initial count (x) and the remaining count. These differences indicate how many swords were taken from each type.
3. **Calculate GCD:** The greatest common divisor (GCD) of these differences will determine the number of swords each person took (z). This is because each person must take the same number of swords, and the GCD ensures that this number is the largest possible, minimizing the total number of people.
4. **Sum and Division:** The total number of people is obtained by dividing the sum of all differences by the GCD (z). This gives the minimum number of people required.

### Solution Code
```python
import math

n = int(input())
a = list(map(int, input().split()))
x = max(a)
d = [x - ai for ai in a]

current_gcd = 0
for di in d:
    current_gcd = math.gcd(current_gcd, di)

z = current_gcd
y = sum(d) // z

print(y, z)
```

### Explanation
1. **Finding Maximum Remaining Swords (x):** The maximum value in the list of remaining swords (a) is chosen as x. This ensures that x is a valid initial count for all types.
2. **Differences Calculation:** For each type, the difference between x and the remaining swords (a_i) is computed. These differences represent the number of swords taken from each type.
3. **GCD Calculation:** The GCD of all differences is computed. This GCD (z) is the largest possible number of swords each person could have taken, ensuring that the total number of people (y) is minimized.
4. **Total People Calculation:** The sum of all differences divided by z gives the total number of people, as each person takes exactly z swords.

This approach efficiently computes the required values using mathematical properties, ensuring optimal performance even for large input sizes.
