To solve this problem, we need to build a rocket using exactly `k` stages selected from `n` available stages, each represented by a lowercase Latin letter. The rocket must be constructed such that each subsequent stage is at least two positions after the previous stage in the alphabet. The goal is to minimize the total weight of the rocket, where the weight of each stage is its position in the alphabet (e.g., 'a' is 1, 'b' is 2, etc.).

### Approach
1. **Sort the Stages**: First, we sort the available stages alphabetically to facilitate the selection of the smallest possible weights while maintaining the required spacing.
2. **Dynamic Programming (DP) Setup**: We use a DP table where `dp[j][i]` represents the minimum weight sum of selecting `j` stages with the `i`-th stage as the last one.
3. **Prefix Minimum Array**: For efficiency, we maintain a prefix minimum array to quickly find the minimum weight sum up to any point, which helps in determining the optimal previous stage for each current stage.
4. **Binary Search for Valid Previous Stages**: For each stage, we use binary search to find the latest valid previous stage that satisfies the required spacing constraint.

### Solution Code
```python
import bisect

n, k = map(int, input().split())
s = input().strip()

sorted_s = sorted(s)
values = [ord(c) - ord('a') + 1 for c in sorted_s]

INF = float('inf')

if k == 0:
    print(0)
    exit()

# Initialize DP table
dp = [[INF] * n for _ in range(k+1)]
for i in range(n):
    dp[1][i] = values[i]

for j in range(2, k+1):
    # Compute prefix_min for j-1
    prefix_min = [INF] * n
    prefix_min[0] = dp[j-1][0]
    for i in range(1, n):
        prefix_min[i] = min(prefix_min[i-1], dp[j-1][i])
    
    for i in range(n):
        current_val = values[i]
        required_prev_max = current_val - 2
        
        # Find the largest index m < i where values[m] <= required_prev_max
        low, high = 0, i-1
        m = -1
        while low <= high:
            mid = (low + high) // 2
            if values[mid] <= required_prev_max:
                m = mid
                low = mid + 1
            else:
                high = mid - 1
        
        if m == -1:
            continue
        
        if prefix_min[m] != INF:
            dp[j][i] = prefix_min[m] + current_val

# Find the minimal total weight for exactly k stages
min_total = min(dp[k][i] for i in range(n))
print(min_total if min_total != INF else -1)
```

### Explanation
1. **Sorting and Conversion**: The input stages are sorted, and each character is converted to its corresponding weight based on its position in the alphabet.
2. **DP Initialization**: The DP table is initialized to handle the base case where only one stage is selected.
3. **Prefix Minimum Calculation**: For each step in the DP, a prefix minimum array is used to efficiently find the minimum sum of weights up to any given index, ensuring we always consider the optimal previous stages.
4. **Binary Search for Valid Stages**: For each stage, binary search is used to find the latest valid previous stage that meets the spacing requirement, ensuring efficient lookup.

This approach ensures that we efficiently explore all valid combinations of stages while minimizing the total weight, leading to an optimal solution.
