To solve this problem, we need to determine the maximum number of pairs that can be formed between boys and girls such that their dancing skills differ by at most one. This problem can be efficiently solved using a bipartite matching algorithm.

### Approach
1. **Problem Analysis**: We need to form pairs where each pair consists of a boy and a girl whose dancing skills differ by at most 1. This can be modeled as a bipartite graph where each node on one side (boys) is connected to nodes on the other side (girls) if their skills meet the required condition.
2. **Graph Construction**: Construct an adjacency list where each boy is connected to all girls he can pair with based on the skill difference constraint.
3. **Bipartite Matching**: Use a Depth-First Search (DFS) based approach to find the maximum matching in the bipartite graph. This involves iterating over each boy and attempting to find a matching girl using DFS, while keeping track of visited nodes and existing matches to avoid cycles and ensure optimal pairing.

### Solution Code
```python
def max_pairs():
    import sys
    sys.setrecursionlimit(1000000)  # Increase recursion limit if necessary

    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    m = int(sys.stdin.readline())
    b = list(map(int, sys.stdin.readline().split()))

    # Create adjacency list
    adj = [[] for _ in range(n)]
    for i in range(n):
        for j in range(m):
            if abs(a[i] - b[j]) <= 1:
                adj[i].append(j)

    # Maximum bipartite matching using DFS
    match_to = [-1] * m  # Tracks which boy is matched to each girl
    result = 0

    def dfs(u, visited):
        for v in adj[u]:
            if not visited[v]:
                visited[v] = True
                if match_to[v] == -1 or dfs(match_to[v], visited):
                    match_to[v] = u
                    return True
        return False

    for u in range(n):
        visited = [False] * m
        if dfs(u, visited):
            result += 1

    print(result)
```
