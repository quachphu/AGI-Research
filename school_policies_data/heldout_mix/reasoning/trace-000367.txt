To solve this problem, we need to determine if there exists a point \( P \) inside a convex polygon such that any line passing through \( P \) divides the polygon into two regions of equal area. If such a point exists, we output its coordinates; otherwise, we output "NA".

### Approach
1. **Compute the Centroid**: The centroid (geometric center) of a polygon is the candidate point \( P \). The centroid is calculated using the formula involving the vertices of the polygon.
2. **Check Symmetry**: For the centroid to be the correct point \( P \), the polygon must be symmetric around this centroid. This means that for each vertex \((x, y)\), the reflected point \((2 \cdot cX - x, 2 \cdot cY - y)\) must also be a vertex of the polygon.
3. **Validation**: Ensure that the centroid's coordinates are such that their reflections result in integer coordinates (since all input vertices are integers). If all reflections are valid vertices, the centroid is the solution; otherwise, output "NA".

### Solution Code
```python
n = int(input())
vertices = [tuple(map(int, input().split())) for _ in range(n)]

sum_S = 0
sum_num_x = 0
sum_num_y = 0

for i in range(n):
    x_i, y_i = vertices[i]
    x_j, y_j = vertices[(i + 1) % n]
    s_i = x_i * y_j - x_j * y_i
    sum_S += s_i
    sum_num_x += (x_i + x_j) * s_i
    sum_num_y += (y_i + y_j) * s_i

if sum_S == 0:
    print("NA")
    exit()

denominator = 3 * sum_S
two_cx = 2 * sum_num_x
two_cy = 2 * sum_num_y

if (two_cx % denominator) != 0 or (two_cy % denominator) != 0:
    print("NA")
    exit()

two_cx_val = two_cx // denominator
two_cy_val = two_cy // denominator

vertex_set = set(vertices)
for x, y in vertices:
    rx = two_cx_val - x
    ry = two_cy_val - y
    if (rx, ry) not in vertex_set:
        print("NA")
        exit()

cX = two_cx_val / 2.0
cY = two_cy_val / 2.0

print("{0:.5f} {1:.5f}".format(cX, cY))
```

### Explanation
1. **Reading Input**: The input is read and stored as a list of vertices.
2. **Calculating Area and Centroid**: The area (sum_S) and the numerators for the centroid coordinates (sum_num_x and sum_num_y) are computed using the vertices.
3. **Divisibility Check**: The centroid coordinates are checked to ensure they can be reflected to integer coordinates. If not, "NA" is printed.
4. **Reflection Check**: Each vertex is reflected over the centroid, and the presence of these reflected points in the vertex list is verified. If all reflections are present, the centroid is printed with 5 decimal places; otherwise, "NA" is printed.

This approach ensures that we accurately determine the centroid and validate the symmetry required for the problem's solution.
