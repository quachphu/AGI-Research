   - \( |x + y| \equiv 0 \mod 2a \)

2. **Transformation to S and D Coordinates**: Convert the coordinates (x, y) into sums and differences (s = x + y, d = x - y). This simplifies the problem by transforming it into a grid where we only need to check for crossings of lines defined by multiples of 2a (for s) and 2b (for d).

3. **Counting Crossings**: Calculate the number of times the path from (x1, y1) to (x2, y2) crosses the lines defined by s ≡ 0 mod 2a and d ≡ 0 mod 2b. This is done by determining how many multiples of 2a lie between the transformed coordinates s1 and s2, and similarly for multiples of 2b between d1 and d2.

4. **Result Calculation**: The minimum number of bad cells visited is the maximum of the two crossing counts, as the optimal path can be arranged to maximize overlaps between crossings of s and d lines.

### Solution Code
```python
a, b, x1, y1, x2, y2 = map(int, input().split())

def compute_crosses(p1, p2, mod):
    if mod == 0:
        return 0
    min_p = min(p1, p2)
    max_p = max(p1, p2)
    start = (min_p) // mod + 1
    end = (max_p - 1) // mod
    if start > end:
        return 0
    return end - start + 1

s1 = x1 + y1
s2 = x2 + y2
s_cross = compute_crosses(s1, s2, 2 * a)

d1 = x1 - y1
d2 = x2 - y2
d_cross = compute_crosses(d1, d2, 2 * b)

print(max(s_cross, d_cross))
```

1. **Transformation**: Convert (x, y) to (s, d) coordinates where s = x + y and d = x - y. This transformation simplifies the problem by reducing it to checking crossings in a linear space.
2. **Crossing Calculation**: For each direction (s and d), determine how many times the path crosses the lines defined by multiples of 2a and 2b. This is done by checking the range between the transformed coordinates and counting the multiples within that range.
3. **Result**: The result is the maximum of the crossings in the s and d directions, as this represents the minimal number of bad cells that must be crossed by an optimal path.

This approach efficiently transforms the problem into a linear space and leverages mathematical properties to count necessary crossings, ensuring an optimal solution.
