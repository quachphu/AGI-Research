To solve this problem, we need to determine the optimal subsequence of a given length for each query. The optimal subsequence is defined as the one with the maximum possible sum, and among those with the maximum sum, it should be lexicographically smallest. 

### Approach
1. **Precompute Maximum Sums**: Using dynamic programming, precompute the maximum sum for selecting `t` elements from every possible subarray `[l, r]` of the given array. This allows efficient lookup during query processing.
2. **Process Each Query**: For each query, determine the optimal subsequence by iteratively selecting elements. At each step, choose the earliest possible element that allows the remaining elements to form the maximum sum, ensuring the lexicographically smallest sequence.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    m = int(sys.stdin.readline())
    queries = [tuple(map(int, sys.stdin.readline().split())) for _ in range(m)]
    
    # Precompute max_sum[l][r][t]
    max_sum = [[[-float('inf')] * (n + 1) for _ in range(n)] for __ in range(n)]
    
    for l in range(n):
        for r in range(l, n):
            max_t = r - l + 1
            dp = [-float('inf')] * (max_t + 1)
            dp[0] = 0
            for i in range(l, r + 1):
                current_val = a[i]
                for t in range(min(i - l + 1, max_t), 0, -1):
                    if dp[t-1] != -float('inf'):
                        dp[t] = max(dp[t], dp[t-1] + current_val)
            for t in range(max_t + 1):
                max_sum[l][r][t] = dp[t]
    
    # Process each query
    for k, pos in queries:
        S = max_sum[0][n-1][k]
        selected = []
        current_start = 0
        remaining = k
        current_sum = 0
        for _ in range(k):
            end_j = n - remaining if remaining > 0 else n - 1
            candidates = []
            for j in range(current_start, end_j + 1):
                required = S - current_sum - a[j]
                if required < 0:
                    continue
                if j + 1 >= n:
                    current_max = 0 if (remaining - 1 == 0) else -float('inf')
                else:
                    current_max = max_sum[j+1][n-1][remaining-1]
                if a[j] + current_max == S - current_sum:
                    candidates.append((a[j], j))
            candidates.sort()
            earliest_j = None
            min_val = candidates[0][0] if candidates else None
            for val, j in candidates:
                if val == min_val:
                    if earliest_j is None or j < earliest_j:
                        earliest_j = j
            selected.append(earliest_j)
            current_sum += a[earliest_j]
            current_start = earliest_j + 1
            remaining -= 1
        print(a[selected[pos-1]])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precompute Maximum Sums**: The `max_sum` 3D array is computed using dynamic programming where `max_sum[l][r][t]` stores the maximum sum of selecting `t` elements from the subarray `a[l:r+1]`.
2. **Query Processing**: For each query, determine the maximum sum `S` for the required subsequence length `k`. Then, iteratively select elements by checking each candidate position to ensure the remaining elements can form the required sum. The earliest element with the smallest value is chosen to maintain lexicographical order.
3. **Efficiency**: The precomputation ensures that each query is processed efficiently by leveraging precomputed values, making the solution both optimal and efficient for the given constraints.
