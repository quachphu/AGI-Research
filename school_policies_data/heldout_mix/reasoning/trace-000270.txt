To solve this problem, we need to determine the maximum amount of money that cannot be formed using any combination of two given prime denominations. The solution leverages a mathematical formula known as the Frobenius number for two coprime integers, which is given by \( c \times d - c - d \), where \( c \) and \( d \) are the two coprime integers. Since the input guarantees two distinct prime numbers, they are inherently coprime, making this formula directly applicable.

### Approach
1. **Understanding the Problem**: The problem requires finding the largest number that cannot be formed using any combination of two given prime numbers. This is a classic problem in number theory, and the solution is given by the Frobenius number formula.
2. **Mathematical Insight**: For two coprime integers \( c \) and \( d \), the largest number that cannot be expressed as \( ax + by \) (where \( x \) and \( y \) are non-negative integers) is \( c \times d - c - d \).
3. **Algorithm**: For each test case, compute the Frobenius number using the given primes and print the result.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        c, d = map(int, sys.stdin.readline().split())
        print(c * d - c - d)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of multiple test cases. The first line gives the number of test cases, \( T \). Each subsequent line contains two prime numbers \( c \) and \( d \).
2. **Computing the Result**: For each pair of primes \( c \) and \( d \), the result is calculated using the formula \( c \times d - c - d \).
3. **Output**: The result for each test case is printed immediately after computation.

This approach efficiently solves the problem in constant time for each test case, making it highly efficient even for the upper constraint limits. The use of the Frobenius number formula ensures correctness and optimal performance.
