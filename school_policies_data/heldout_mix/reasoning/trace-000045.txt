To solve this problem, we need to determine if three candy packs can be distributed between two students such that each student gets the same number of candies. Each pack must be given entirely to one student, and we cannot split the contents of any pack.

### Approach
1. **Check if Total is Even**: The total number of candies must be even because it's impossible to split an odd number of candies into two equal parts.
2. **Check for Half Value**: If the total number of candies is even, calculate half of this total. We then check if any single candy pack contains exactly half of the total candies. If so, one student can take that pack, and the other student can take the remaining two packs, which will also sum to half the total.

### Solution Code
```python
a, b, c = map(int, input().split())
total = a + b + c
if total % 2 != 0:
    print("No")
else:
    half = total // 2
    if a == half or b == half or c == half:
        print("Yes")
    else:
        print("No")
```

### Explanation
1. **Input Reading**: The code reads the input values for the three candy packs.
2. **Total Check**: The total number of candies is calculated. If this total is odd, it immediately prints "No" because an odd total cannot be split into two equal integer parts.
3. **Half Value Check**: If the total is even, it checks if any of the three packs has exactly half of the total candies. If such a pack exists, it prints "Yes" because the other two packs will naturally sum to the same value. If no such pack exists, it prints "No".

This approach efficiently checks the necessary conditions in constant time, making it very efficient with a time complexity of O(1).
