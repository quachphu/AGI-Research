To solve this problem, we need to determine the minimum number of bijous the princess needs to drop to successfully escape the dragon and reach the castle. The princess starts running immediately, while the dragon starts chasing her after a delay. If the dragon catches up, the princess uses a bijou to distract him, allowing her to gain more distance while the dragon returns to the cave and spends time there.

### Approach
1. **Initial Check**: If the dragon's speed is less than or equal to the princess's speed, the dragon can never catch her, so no bijous are needed.
2. **Head Start Calculation**: Calculate the distance the princess covers during the initial delay before the dragon starts chasing.
3. **Chase Simulation**: Use a loop to simulate each chase:
   - Calculate the position where the dragon catches the princess.
   - If this position is beyond the castle, the princess escapes without needing another bijou.
   - If caught, increment the bijou count and calculate the time the dragon takes to return to the cave and the additional time he spends there.
   - Update the princess's position based on the time the dragon is occupied.
4. **Termination Condition**: The loop continues until the princess reaches or exceeds the castle's distance.

### Solution Code
```python
vp = int(input())
vd = int(input())
t = int(input())
f = int(input())
c = int(input())

if vd <= vp:
    print(0)
else:
    current = vp * t
    if current >= c:
        print(0)
    else:
        count = 0
        while True:
            meet_pos = (current * vd) / (vd - vp)
            if meet_pos >= c:
                break
            count += 1
            downtime = (meet_pos / vd) + f
            current = meet_pos + vp * downtime
            if current >= c:
                break
        print(count)
```

### Explanation
1. **Initial Check**: If the dragon's speed (vd) is less than or equal to the princess's speed (vp), the dragon can never catch her, so we immediately return 0.
2. **Head Start Calculation**: The princess runs for `t` hours before the dragon starts chasing, covering `vp * t` miles.
3. **Chase Simulation**:
   - **Catch Position Calculation**: The position where the dragon catches the princess is calculated using their speeds and the current distance of the princess from the cave.
   - **Bijou Drop Check**: If the catch position is beyond the castle, the princess escapes. Otherwise, she drops a bijou, and we update her position based on the time the dragon spends returning to the cave and the additional downtime.
4. **Loop Termination**: The loop continues until the princess's updated position reaches or exceeds the castle's distance, ensuring she escapes without further bijous.

This approach efficiently simulates each encounter with the dragon and updates the princess's position dynamically, ensuring the minimal number of bijous is used.
