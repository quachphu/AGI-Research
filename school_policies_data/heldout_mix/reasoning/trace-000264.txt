To solve this problem, we need to identify employees whose total sales proceeds meet or exceed 1,000,000 for each dataset provided. The solution involves processing each dataset independently and outputting the results in the order of the employees' first appearance in the dataset.

### Approach
1. **Reading Input**: The input consists of multiple datasets, each starting with an integer `n` indicating the number of sales records. The input ends with a line containing `0`.
2. **Processing Each Dataset**:
   - For each dataset, track the cumulative sales proceeds for each employee using a dictionary.
   - Maintain the order of the first occurrence of each employee using a list.
3. **Determining Qualified Employees**:
   - After processing all records in a dataset, check which employees have total sales proceeds of at least 1,000,000.
   - Output the qualified employees in the order they first appeared in the dataset. If no employees qualify, output "NA".

### Solution Code
```python
import sys

def main():
    data = sys.stdin.read().split()
    ptr = 0
    while ptr < len(data):
        token = data[ptr]
        if token == '0':
            break
        n = int(token)
        ptr += 1
        dataset = []
        for _ in range(n):
            if ptr + 2 >= len(data):
                break  # Handle unexpected end of input
            i = data[ptr]
            p = int(data[ptr + 1])
            q = int(data[ptr + 2])
            dataset.append((i, p, q))
            ptr += 3
        totals = {}
        order = []
        for (employee_id, unit_price, quantity) in dataset:
            if employee_id not in totals:
                order.append(employee_id)
                totals[employee_id] = 0
            totals[employee_id] += unit_price * quantity
        result = [id for id in order if totals[id] >= 1000000]
        if not result:
            print("NA")
        else:
            for employee_id in result:
                print(employee_id)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into tokens for easier processing. This allows us to handle multiple datasets efficiently.
2. **Tracking Sales Proceeds**: For each dataset, a dictionary (`totals`) is used to accumulate the total sales proceeds for each employee. A list (`order`) keeps track of the order in which employees first appear.
3. **Processing Records**: Each sales record updates the cumulative total for the respective employee. If an employee is encountered for the first time, they are added to the `order` list.
4. **Generating Output**: After processing all records in a dataset, the employees whose total sales meet or exceed 1,000,000 are identified and printed in the order they first appeared. If no employees qualify, "NA" is printed.

This approach ensures that we efficiently process each dataset, maintain the required order of results, and handle edge cases such as no qualifying employees.
