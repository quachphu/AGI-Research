To solve this problem, we need to determine the probability that a certain number of students receive someone else's test when tests are distributed randomly. The solution involves combinatorial mathematics and modular arithmetic to handle large numbers efficiently.

### Approach
1. **Combinatorial Analysis**: We need to compute the number of ways exactly `X` students receive someone else's test. This involves combinations (choosing `X` students out of `N`) and derangements (permutations where no element appears in its original position).
2. **Precomputation**: 
   - **Combinations**: Precompute combinations using dynamic programming to efficiently retrieve values.
   - **Derangements**: Precompute derangements using a recurrence relation.
   - **Factorials**: Precompute factorials up to `N` to handle the denominator in the probability calculation.
3. **Modular Arithmetic**: Since results can be very large, use modular arithmetic with a modulus of \(10^9 + 7\). The result is computed as \(P \times Q^{-1} \mod (10^9 + 7)\), where \(Q^{-1}\) is the modular inverse of \(Q\).

### Solution Code
```python
MOD = 10**9 + 7

max_n = 100

# Precompute combinations (n choose k)
comb = [[0] * (max_n + 1) for _ in range(max_n + 1)]
comb[0][0] = 1
for n in range(1, max_n + 1):
    comb[n][0] = 1
    for k in range(1, n):
        comb[n][k] = comb[n-1][k-1] + comb[n-1][k]
    comb[n][n] = 1

# Precompute derangements D(m)
der = [0] * (max_n + 1)
der[0] = 1
if max_n >= 1:
    der[1] = 0
for m in range(2, max_n + 1):
    der[m] = (m - 1) * (der[m - 1] + der[m - 2])

# Precompute factorials
fact = [1] * (max_n + 1)
for i in range(1, max_n + 1):
    fact[i] = fact[i - 1] * i

# Read input
n, l, r = map(int, input().split())

# Calculate the sum of C(n, x) * D(x) for x in [L, R]
total = 0
for x in range(l, r + 1):
    if x > n:
        continue
    total += comb[n][x] * der[x]

# Calculate denominator and result
denominator = fact[n]
numerator_mod = total % MOD
denominator_mod = denominator % MOD
inv_denominator = pow(denominator_mod, MOD - 2, MOD)
result = (numerator_mod * inv_denominator) % MOD

print(result)
```

   - **Factorials**: Compute factorials to handle the denominator in the probability calculation efficiently.

2. **Sum Calculation**: For each value `X` from `L` to `R`, compute the number of valid permutations using the precomputed combinations and derangements. Sum these values to get the numerator of the probability.

3. **Modular Inverse**: Use Fermat's Little Theorem to compute the modular inverse of the factorial of `N`, which is the denominator in the probability. This allows us to handle large numbers and perform division under modulo.
