1. **Problem Analysis**:
   - The first list contains `n` errors.
   - The second list contains `n-1` errors, missing exactly one error from the first list.
   - The third list contains `n-2` errors, missing exactly one error from the second list.
   - The goal is to find the two missing errors from the first and second corrections.

2. **Key Insight**:
   - The sum of the elements in the first list minus the sum of the elements in the second list gives the first missing error.
   - The sum of the elements in the second list minus the sum of the elements in the third list gives the second missing error.

3. **Algorithm**:
   - Compute the sum of each of the three lists.
   - Subtract the sum of the second list from the sum of the first list to find the first missing error.
   - Subtract the sum of the third list from the sum of the second list to find the second missing error.

This approach is efficient with a time complexity of O(n) as it involves summing the elements of three lists, each of which is processed in linear time.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    a = list(map(int, input[ptr:ptr + n]))
    ptr += n
    b = list(map(int, input[ptr:ptr + (n - 1)]))
    ptr += (n - 1)
    c = list(map(int, input[ptr:ptr + (n - 2)]))
    
    sum_a = sum(a)
    sum_b = sum(b)
    sum_c = sum(c)
    
    first = sum_a - sum_b
    second = sum_b - sum_c
    
    print(first)
    print(second)

main()
```

- **Reading Input**: The input is read all at once and split into a list of strings for efficient processing.
- **Summing Elements**: The sums of the three lists are computed to determine the missing elements.
- **Calculating Missing Elements**: The differences between the sums of consecutive lists directly give the missing errors due to the properties of arithmetic sums.

This method efficiently handles duplicates and ensures correct results by leveraging the properties of sums, providing an optimal solution to the problem.
