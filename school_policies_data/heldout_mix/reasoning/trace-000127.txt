To solve this problem, we need to replace each '#' in the given string with one or more ')' characters such that the resulting string is "beautiful". A beautiful string must satisfy two conditions: every prefix has no more closing brackets than opening brackets, and the total number of opening and closing brackets must be equal.

### Approach
1. **Count the Brackets and Hashes**: First, count the number of opening brackets '(', closing brackets ')', and hash characters '#' in the input string.
2. **Check Feasibility**: Calculate the required sum of replacements needed for the hashes. This is determined by the difference between the number of opening and closing brackets. If this sum is negative or less than the number of hashes, it's impossible to form a beautiful string.
3. **Assign Replacements**: Assign each '#' (except the last one) a minimal replacement of 1. The last '#' is assigned the remaining required sum to meet the total needed.
4. **Simulate and Validate**: Traverse the string while simulating the replacements to ensure that every prefix maintains a non-negative balance of brackets. If any step results in a negative balance, it's impossible to form a beautiful string.

### Solution Code
```python
s = input().strip()

left = s.count('(')
right = s.count(')')
hash_count = s.count('#')

required_sum = left - right
if required_sum < hash_count or required_sum < 0:
    print(-1)
    exit()

K = required_sum - (hash_count - 1)
if K < 1:
    print(-1)
    exit()

hash_positions = [i for i, c in enumerate(s) if c == '#']
if not hash_positions:
    print(-1)
    exit()

last_hash = hash_positions[-1]

balance = 0
for i, c in enumerate(s):
    if c == '(':
        balance += 1
    elif c == ')':
        balance -= 1
    else:
        if i == last_hash:
            if balance < K:
                print(-1)
                exit()
            balance -= K
        else:
            balance -= 1
    if balance < 0:
        print(-1)
        exit()

if balance != 0:
    print(-1)
else:
    for pos in hash_positions:
        if pos == last_hash:
            print(K)
        else:
            print(1)
```

4. **Validation**: By simulating the replacements, we ensure that every prefix of the string maintains a non-negative balance. If any step fails, we return -1. If valid, we print the replacements for each hash.

This approach ensures that we efficiently check and assign the necessary replacements while maintaining the constraints required for a beautiful string.
