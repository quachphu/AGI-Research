To solve this problem, we need to determine the n-th prime number. Prime numbers are integers greater than 1 that have no divisors other than 1 and themselves. The challenge is to efficiently generate prime numbers until we reach the n-th one.

### Approach
1. **Initialization**: Start with the first prime number, which is 2.
2. **Iterative Check**: For each subsequent candidate number (starting from 3), check if it is a prime number.
3. **Prime Checking**: For a candidate number, check divisibility by all previously found primes up to the square root of the candidate. This is because if a number is not divisible by any primes up to its square root, it is a prime.
4. **Optimization**: Skip even numbers after 2 since all even numbers greater than 2 are not prime.
5. **Termination**: Continue this process until we have found the n-th prime number.

### Solution Code
```python
def nth_prime(n):
    if n == 1:
        return 2
    primes = [2]
    candidate = 3
    while len(primes) < n:
        is_prime = True
        sqrt_candidate = int(candidate ** 0.5) + 1
        for p in primes:
            if p > sqrt_candidate:
                break
            if candidate % p == 0:
                is_prime = False
                break
        if is_prime:
            primes.append(candidate)
        candidate += 2
    return primes[-1]

n = int(input())
print(nth_prime(n))
```

### Explanation
1. **Initialization**: We start with the first prime number, 2, stored in a list `primes`.
2. **Candidate Numbers**: We check each odd number starting from 3 (since even numbers greater than 2 are not prime).
3. **Prime Check**: For each candidate, we check if it is divisible by any of the primes already found, up to the square root of the candidate. This reduces the number of checks needed.
4. **Efficiency**: By only checking up to the square root and skipping even numbers, the algorithm efficiently narrows down potential primes.
5. **Termination**: The loop continues until we have found the n-th prime, which is then returned as the result.

This approach ensures that we efficiently generate prime numbers up to the required n-th prime, leveraging mathematical properties of prime numbers to minimize unnecessary computations.
