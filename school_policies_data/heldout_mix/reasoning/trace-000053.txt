To solve this problem, we need to implement the Selection Sort algorithm to sort a sequence of integers in ascending order while counting the number of swap operations performed during the sorting process. The solution must read input from standard input, sort the sequence, and then print both the sorted sequence and the number of swaps.

### Approach
1. **Understanding Selection Sort**: The Selection Sort algorithm works by repeatedly finding the minimum element from the unsorted portion of the array and swapping it with the first element of the unsorted portion. This process continues until the entire array is sorted.
2. **Counting Swaps**: Each time a swap is performed (when the index of the minimum element found is different from the current index), we increment a counter to keep track of the number of swaps.
3. **Input Handling**: The input consists of an integer `N` (the number of elements) followed by a sequence of `N` integers.
4. **Output**: The sorted array and the number of swaps are printed as specified.

### Solution Code
```python
def selection_sort():
    n = int(input())
    a = list(map(int, input().split()))
    swap_count = 0

    for i in range(n):
        mini = i
        for j in range(i, n):
            if a[j] < a[mini]:
                mini = j
        if i != mini:
            a[i], a[mini] = a[mini], a[i]
            swap_count += 1

    print(' '.join(map(str, a)))
    print(swap_count)

selection_sort()
```

### Explanation
1. **Reading Input**: The function reads the number of elements `n` and the sequence of integers from standard input.
2. **Selection Sort Implementation**:
   - For each element in the array (from index `0` to `n-1`), we assume the current element is the minimum.
   - We then iterate through the remaining elements to find the actual minimum element in the unsorted portion.
   - If the found minimum element is not at the current index, we swap them and increment the swap counter.
3. **Output**: After sorting the array, the sorted elements are printed as a space-separated string, followed by the number of swaps.

This approach ensures that the array is sorted in ascending order using the Selection Sort algorithm, and the number of swaps is counted efficiently. The algorithm runs in O(n²) time complexity, which is suitable given the constraint (1 ≤ N ≤ 100).
