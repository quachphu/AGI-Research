To solve this problem, we need to determine the minimum distance AtCoDeer the reindeer has to travel to deliver gifts to all houses along TopCoDeer street, given that he can start and end his journey at any positions.

### Approach
The key insight here is that the shortest path to visit all houses is to travel from the leftmost house to the rightmost house. This is because visiting all intermediate houses in a single pass from one end to the other without backtracking minimizes the total distance traveled. The minimum distance required is thus the difference between the positions of the rightmost and leftmost houses.

Steps:
1. Read the input values.
2. Sort the list of house positions.
3. Compute the difference between the maximum (rightmost) and minimum (leftmost) positions in the sorted list.
4. Print the computed difference as the result.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
a.sort()
print(a[-1] - a[0])
```

### Explanation
1. **Reading Input:** We first read the number of houses `n` and their respective positions.
2. **Sorting:** By sorting the list of house positions, we can easily determine the leftmost and rightmost houses.
3. **Calculating Distance:** The difference between the maximum and minimum values in the sorted list gives the minimum distance required to travel from the leftmost to the rightmost house, covering all intermediate houses in between.
4. **Output:** The result is printed, which is the computed distance.

This approach efficiently computes the minimum travel distance using sorting and simple arithmetic operations, ensuring an optimal solution with a time complexity of O(n log n) due to the sorting step.
