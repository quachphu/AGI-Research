To solve this problem, we need to determine the translation required to map the coordinates of a given constellation to a corresponding position in a photograph of the starry sky. The constellation will appear exactly once in the photograph, and we need to find the exact translation vector (dx, dy) that maps the constellation's stars to their positions in the photograph.

### Approach
1. **Input Reading**: Read the input datasets which include the number of stars in the constellation and their coordinates, followed by the number of stars in the photograph and their coordinates.
2. **Translation Calculation**: For each star in the photograph, consider it as a potential match for the first star of the constellation. Compute the translation vector (dx, dy) based on this potential match.
3. **Validation**: Check if applying this translation vector to all stars in the constellation results in all translated stars being present in the photograph.
4. **Output the Result**: Once a valid translation vector is found, output it and proceed to the next dataset.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    while True:
        m = int(input[ptr])
        ptr += 1
        if m == 0:
            break
        const = []
        for _ in range(m):
            x = int(input[ptr])
            y = int(input[ptr + 1])
            const.append((x, y))
            ptr += 2
        n = int(input[ptr])
        ptr += 1
        photo = set()
        for _ in range(n):
            x = int(input[ptr])
            y = int(input[ptr + 1])
            photo.add((x, y))
            ptr += 2
        # Process the current dataset
        cx, cy = const[0]
        found = False
        for (px, py) in photo:
            dx = px - cx
            dy = py - cy
            valid = True
            for (x, y) in const:
                tx = x + dx
                ty = y + dy
                if (tx, ty) not in photo:
                    valid = False
                    break
            if valid:
                print(f"{dx} {dy}")
                found = True
                break
        # As per problem statement, there will be exactly one solution
    return

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go and split into a list of strings for efficient processing. We then iterate through this list to parse each dataset.
2. **Storing Constellation and Photo Stars**: The constellation stars are stored in a list, while the photo stars are stored in a set for O(1) lookups to check the presence of translated coordinates efficiently.
3. **Translation Calculation**: For each star in the photograph, compute the potential translation vector (dx, dy) by comparing it with the first star of the constellation.
4. **Validation Check**: For each computed translation vector, validate if all constellation stars, when translated, exist in the photograph. If valid, the translation vector is printed and the loop breaks to move to the next dataset.

This approach ensures that we efficiently find the correct translation vector by leveraging set lookups and iterating through potential matches, ensuring the solution is both optimal and correct.
