To solve this problem, we need to determine the FLAMES result for given pairs of names. The FLAMES game involves removing common letters from both names, counting the remaining letters, and using that count to iteratively eliminate letters from the word "FLAMES" until one letter remains. Each letter in FLAMES corresponds to a specific relationship status.

### Approach
1. **Remove Common Letters**: For each pair of names, count the frequency of each letter and subtract the common occurrences. The remaining letters are the sum of absolute differences of the frequencies of each letter in the two names.
2. **Simulate Elimination Process**: Using the count of remaining letters, repeatedly eliminate letters from the word "FLAMES" in a cyclic manner until one letter remains. The position to eliminate each time is determined by the count of remaining letters.
3. **Map Result**: Map the final remaining letter from "FLAMES" to its corresponding relationship status.

def flames():
    import sys
    from collections import defaultdict

    t = int(sys.stdin.readline())
    mapping = {
        'F': 'FRIENDS',
        'L': 'LOVE',
        'A': 'ADORE',
        'M': 'MARRIAGE',
        'E': 'ENEMIES',
        'S': 'SISTER'
    }

    for _ in range(t):
        name1 = sys.stdin.readline().strip().lower()
        name2 = sys.stdin.readline().strip().lower()

        cnt1 = defaultdict(int)
        for c in name1:
            cnt1[c] += 1

        cnt2 = defaultdict(int)
        for c in name2:
            cnt2[c] += 1

        sum_n = 0
        all_chars = set(cnt1.keys()).union(cnt2.keys())
        for c in all_chars:
            sum_n += abs(cnt1[c] - cnt2[c])

        current_list = list('FLAMES')
        current_pos = 0

        while len(current_list) > 1:
            len_list = len(current_list)
            index = (current_pos + sum_n - 1) % len_list
            current_list.pop(index)
            new_len = len(current_list)
            if new_len == 0:
                break
            current_pos = index % new_len

        print(mapping[current_list[0]])
