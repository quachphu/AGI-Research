To solve this problem, we need to reorder the elements of array `b` such that the sum of all possible subarray sums of the product of elements from arrays `a` and `b` is minimized. The solution involves calculating specific weights for each element in `a`, sorting these weights, and then optimally pairing them with elements from `b`.

### Approach
1. **Calculate Weights**: For each element in array `a`, compute a weight based on its position. The weight for the `i`-th element (1-based index) is given by `i * (n - i + 1)`. This weight accounts for the number of subarrays that include the `i`-th element.
2. **Compute Coefficients**: Multiply each element in `a` by its corresponding weight to get a coefficient array.
3. **Sort Arrays**: Sort the coefficient array in descending order and sort array `b` in ascending order.
4. **Optimal Pairing**: Pair the largest coefficient with the smallest element in `b` to minimize the total sum. This is done by multiplying corresponding elements from the sorted coefficient array and sorted `b` array.
5. **Modulo Operation**: Since the result can be very large, compute the sum modulo `998244353`.

### Solution Code
```python
MOD = 998244353

n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

coeffs = [a[i] * (i + 1) * (n - i) for i in range(n)]
coeffs.sort(reverse=True)
b.sort()

total = sum(coeffs[i] * b[i] for i in range(n))
print(total % MOD)
```

### Explanation
1. **Weight Calculation**: Each element's weight is determined by its position, reflecting how many subarrays include that element. For the `i`-th element (1-based index), the weight is `i * (n - i + 1)`.
2. **Coefficient Array**: By multiplying each element in `a` by its weight, we form an array where each element's contribution to the total sum is scaled by how many subarrays include it.
3. **Sorting**: Sorting the coefficients in descending order and `b` in ascending order allows us to pair the largest coefficients with the smallest elements in `b`, minimizing the total sum.
4. **Sum Calculation**: The sum of products of corresponding elements from the sorted arrays gives the minimum possible value. Taking this sum modulo `998244353` ensures the result fits within standard integer limits.

This approach efficiently minimizes the required sum using sorting and optimal pairing, achieving a time complexity of O(n log n), which is suitable for large input sizes up to 200,000.
