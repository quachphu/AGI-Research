To solve this problem, we need to determine if after shuffling guests in Hilbert's Hotel according to a given array, each room still contains exactly one guest. The key insight is that the function mapping guests to new rooms must be a bijection, ensuring no two guests end up in the same room and no room is left vacant.

### Approach
1. **Understanding the Shuffle**: Each guest in room `k` moves to room `k + a[k % n]`, where `n` is the length of the array `a`.
2. **Residue Classes Modulo n**: For each residue `r` (0 ≤ r < n), guests in rooms congruent to `r` modulo `n` are shifted by `a[r]`.
3. **Bijection Check**: The function `k + a[k % n]` must be a bijection. This happens if and only if the set of values `(r + a[r]) % n` for each residue `r` forms a permutation of the integers from 0 to `n-1`. This ensures that each new room is uniquely assigned.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        a = list(map(int, sys.stdin.readline().split()))
        seen = [False] * n
        possible = True
        for r in range(n):
            val = (r + a[r]) % n
            if seen[val]:
                possible = False
                break
            seen[val] = True
        print("YES" if possible else "NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read efficiently using `sys.stdin.readline` to handle large input sizes.
2. **Check for Unique Residues**: For each test case, we compute `(r + a[r]) % n` for each residue `r` and check if these values are unique.
3. **Validation Using a Boolean Array**: A boolean array `seen` tracks encountered residues. If any residue is encountered more than once, the result is "NO"; otherwise, it is "YES".

This approach ensures that we efficiently check the bijection condition in linear time, making it suitable for large input sizes as specified.
