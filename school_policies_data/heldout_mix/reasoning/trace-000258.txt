To solve this problem, we need to determine the number of tuples (A, B, C) of positive integers that satisfy the equation A × B + C = N for a given positive integer N. 

### Approach
The key insight is that for each valid pair (A, B), there exists exactly one positive integer C such that C = N - A × B. Therefore, the problem reduces to counting all pairs (A, B) where A × B < N. 

1. **Range of A**: Since A must be a positive integer and A × B must be less than N, A can range from 1 to N-1.
2. **Valid B for each A**: For each A, the maximum value of B is the largest integer such that A × B < N. This can be computed as (N-1) // A, which gives the floor value of (N-1)/A.

By iterating over each possible value of A from 1 to N-1 and summing the valid B values for each A, we can efficiently compute the total number of valid tuples.

### Solution Code
```python
n = int(input())
ans = 0
for a in range(1, n):
    ans += (n - 1) // a
print(ans)
```

### Explanation
1. **Reading Input**: The input value N is read from standard input.
2. **Initialization**: We initialize a variable `ans` to accumulate the total count of valid tuples.
3. **Iterating Over A**: For each value of A from 1 to N-1, we calculate the maximum valid B using integer division. The expression `(n - 1) // a` gives the number of valid B values for each A.
4. **Summing Valid B Values**: We sum the valid B counts for each A to get the total number of valid tuples.
5. **Output**: Finally, we print the accumulated count, which is the answer.

This approach efficiently computes the solution in O(N) time, which is feasible even for the upper constraint of N = 10^6.
