To solve this problem, we need to determine the number of good substrings of even and odd lengths from a given string. A substring is considered good if, after merging all consecutive equal characters, the resulting string is a palindrome.

### Approach
1. **Identify Runs**: Split the input string into runs of consecutive characters. Each run is represented by a character and its length.
2. **Single Run Substrings**: Calculate the number of good substrings that lie entirely within a single run. These substrings are trivially good because their merged form is a single character.
3. **Multi-Run Substrings**: For substrings spanning multiple runs, check if the merged sequence of runs forms a palindrome. This is done by expanding around each possible center run and checking symmetry.
