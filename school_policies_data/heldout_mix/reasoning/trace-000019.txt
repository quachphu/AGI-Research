To solve this problem, we need to determine the number of possible ways to buy exactly `n` liters of cola using bottles of 0.5 liters, 1 liter, and 2 liters. The solution must consider the constraints on the number of each type of bottle available and efficiently count all valid combinations.

### Approach
1. **Understand the Problem Constraints**: The problem requires that the total volume from the combination of bottles equals exactly `n` liters. The bottles are available in three sizes: 0.5 liters, 1 liter, and 2 liters, with respective maximum counts of `a`, `b`, and `c`.

2. **Convert to Integer Arithmetic**: To avoid dealing with fractional values, convert the problem into integer arithmetic by multiplying the target volume `n` by 2. This transforms the equation into finding combinations of `x` (0.5L bottles), `y` (1L bottles), and `z` (2L bottles) such that `x + 2y + 4z = 2n`.

3. **Iterate Over Possible Values**: Use nested loops to iterate over possible values of `z` (2L bottles), then for each `z`, iterate over possible values of `y` (1L bottles). For each combination of `z` and `y`, compute the required `x` (0.5L bottles) and check if it meets the constraints.

4. **Check Validity**: For each combination, ensure that the computed number of 0.5L bottles (`x`) is non-negative and does not exceed the available count `a`.

### Solution Code
```python
def main():
    import sys
    n, a, b, c = map(int, sys.stdin.readline().split())
    target = 2 * n
    count = 0
    max_z = min(c, target // 4)
    for z in range(max_z + 1):
        remaining = target - 4 * z
        max_y = min(b, remaining // 2)
        for y in range(max_y + 1):
            x = remaining - 2 * y
            if x >= 0 and x <= a:
                count += 1
    print(count)

main()
```

### Explanation
1. **Convert Volume to Integer**: By multiplying `n` by 2, we avoid dealing with fractional values. This transforms the problem into finding combinations where `x + 2y + 4z = 2n`.

2. **Iterate Over Possible Bottles**: Start with the largest bottle size (2L) to minimize the number of iterations. For each possible count of 2L bottles (`z`), calculate the remaining volume needed and determine valid counts of 1L bottles (`y`).

3. **Check Validity of Combinations**: For each valid combination of `z` and `y`, compute the required number of 0.5L bottles (`x`) and check if it is within the allowed range `[0, a]`.

This approach efficiently narrows down valid combinations by leveraging nested loops and mathematical constraints, ensuring that all possible valid combinations are counted without redundant checks. The complexity is manageable within the given constraints, making the solution both efficient and effective.
