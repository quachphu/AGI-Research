To solve this problem, we need to generate all strings of length N that are in their normal form, sorted lexicographically. A string is in normal form if it is the lexicographically smallest string among all its isomorphic strings.

### Approach
1. **Understanding Isomorphism**: Two strings are isomorphic if they have the same structure of character occurrences. For example, "abcac" and "zyxzx" are isomorphic because their character occurrence patterns are identical.
2. **Normal Form**: A string is in normal form if it is the smallest lexicographical string among all its isomorphic forms. This means that each new character introduced in the string must be the smallest possible character in lexicographical order.
3. **Restricted Growth Strings (RGS)**: An RGS is a sequence where each element represents the order in which new characters are introduced. For example, the RGS for "abcac" is [0, 1, 2, 0, 2].
4. **Generating RGS**: We use a backtracking approach to generate all possible RGS of length N. Each RGS is generated by ensuring that each new element is either a repetition of a previous index or the next available index in sequence.
5. **Conversion to Strings**: Once all RGS are generated, they are converted to strings by mapping each index to the corresponding character (0 to 'a', 1 to 'b', etc.).

### Solution Code
```python
n = int(input())

if n == 0:
    print()
else:
    result = []
    def backtrack(current, current_max, pos):
        if pos == n:
            result.append(current.copy())
            return
        for next_val in range(current_max + 2):
            current.append(next_val)
            new_max = max(current_max, next_val)
            backtrack(current, new_max, pos + 1)
            current.pop()
    
    backtrack([0], 0, 1)
    
    # Convert each RGS to the corresponding string
    strings = [''.join(chr(ord('a') + x) for x in rgs) for rgs in result]
    
    # The generated RGS are already in lex order, so the strings are sorted
    for s in strings:
        print(s)
```

### Explanation
1. **Backtracking to Generate RGS**: The backtracking function starts with the initial element [0] (since the first character is always 'a'). For each subsequent position, it tries all possible values from 0 to the current maximum index + 1, ensuring the sequence grows correctly.
2. **Conversion to Strings**: Each RGS is converted to a string by mapping each index to a character starting from 'a'. This ensures the generated string is the lexicographically smallest in its isomorphism class.
3. **Output**: The generated strings are printed in lexicographical order, which is guaranteed by the order in which RGS are generated.

This approach efficiently generates all valid normal form strings using combinatorial principles and backtracking, ensuring correctness and optimal performance for the given constraints.
