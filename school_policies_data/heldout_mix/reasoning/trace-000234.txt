To solve this problem, we need to determine the number of steps required until no psycho in a line kills their right neighbor. Each psycho will kill their right neighbor if their id is greater, and all killings happen simultaneously in each step. The goal is to compute the number of steps needed until no more killings occur.

### Approach
1. **Identify Previous Greater Element**: For each psycho in the line, determine the nearest psycho to the left with a greater id using a stack. This helps in identifying potential killers for each psycho.
2. **Segment Tree for Range Maximum Query**: Use a segment tree to efficiently compute the maximum step in which any psycho in a specific range is killed. This helps in determining the step when a psycho will be killed based on their previous greater elements and the steps in which intermediate elements are killed.
3. **Dynamic Step Calculation**: For each psycho, calculate the step in which they will be killed using the results from the previous greater element and the maximum steps from the segment tree.

### Solution Code
```python
class SegmentTree:
    def __init__(self, size):
        self.n = 1
        while self.n < size:
            self.n <<= 1
        self.tree = [0] * (2 * self.n)

    def update_point(self, pos, value):
        pos += self.n
        self.tree[pos] = value
        pos >>= 1
        while pos >= 1:
            new_val = max(self.tree[2 * pos], self.tree[2 * pos + 1])
            if self.tree[pos] == new_val:
                break
            self.tree[pos] = new_val
            pos >>= 1

    def query_range(self, l, r):
        res = -float('inf')
        l += self.n
        r += self.n
        while l <= r:
            if l % 2 == 1:
                res = max(res, self.tree[l])
                l += 1
            if r % 2 == 0:
                res = max(res, self.tree[r])
                r -= 1
            l >>= 1
            r >>= 1
        return res if res != -float('inf') else 0

def compute_previous_greater(a):
    n = len(a)
    stack = []
    L = [-1] * n
    for i in range(n):
        while stack and a[stack[-1]] <= a[i]:
            stack.pop()
        if stack:
            L[i] = stack[-1]
        else:
            L[i] = -1
        stack.append(i)
    return L

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    if n == 0:
        print(0)
        return
    L = compute_previous_greater(a)
    st = SegmentTree(n)
    max_steps = 0
    for i in range(n):
        if L[i] == -1:
            current_step = 0
        else:
            left = L[i] + 1
            right = i - 1
            if left > right:
                max_step = 0
            else:
                max_step = st.query_range(left, right)
            current_step = max_step + 1
        st.update_point(i, current_step)
        if current_step > max_steps:
            max_steps = current_step
    print(max_steps)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Previous Greater Element Calculation**: Using a stack, we efficiently determine the nearest greater element to the left for each psycho. This helps in identifying potential killers for each psycho.
2. **Segment Tree**: A segment tree is used to maintain and query the maximum steps in which psychos in a specific range are killed. This allows efficient range maximum queries and updates.
3. **Dynamic Step Calculation**: For each psycho, based on the nearest greater element and the maximum steps from the segment tree, we calculate the step in which they will be killed. The maximum of these steps across all psychos gives the final result.

This approach ensures that we efficiently compute the required steps in O(n log n) time, making it suitable for large input sizes up to 100,000 elements.
