To solve this problem, we need to count the occurrences of four specific verdict types (AC, WA, TLE, RE) from a list of test case results provided as input. The goal is to efficiently read and process the input data, then output the counts in the specified format.

### Approach
1. **Reading Input Efficiently**: Given the constraints where the number of test cases can be up to 100,000, we read all input at once using `sys.stdin.read()` for efficiency. This method is faster compared to reading line by line in a loop for large inputs.
2. **Counting Verdicts**: We use a dictionary initialized with keys for each verdict type (AC, WA, TLE, RE) and set their initial counts to zero. As we process each line of input, we increment the corresponding verdict count in the dictionary.
3. **Output the Results**: After processing all input lines, we print the counts in the specified order: AC, WA, TLE, RE.

### Solution Code
```python
import sys

def main():
    lines = sys.stdin.read().splitlines()
    n = int(lines[0])
    counts = {'AC': 0, 'WA': 0, 'TLE': 0, 'RE': 0}
    for s in lines[1:n+1]:
        counts[s] += 1
    print(f"AC x {counts['AC']}")
    print(f"WA x {counts['WA']}")
    print(f"TLE x {counts['TLE']}")
    print(f"RE x {counts['RE']}")

main()
```

### Explanation
1. **Reading Input**: The input is read all at once using `sys.stdin.read().splitlines()`, which splits the input into a list of lines. The first line is converted to an integer to determine the number of test cases.
2. **Processing Each Line**: We iterate over the relevant lines (from the second line to the Nth line) and update the counts in the dictionary for each verdict type encountered.
3. **Output**: The counts are printed in the required format using formatted strings to ensure the output matches exactly what is expected.

This approach ensures that we efficiently handle large input sizes and maintain clarity in counting and outputting the results.
