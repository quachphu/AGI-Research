To solve this problem, we need to determine how many teams share the k-th position in the final results of a programming contest based on their performance. The teams are ranked first by the number of problems solved (more is better) and then by penalty time (lower is better) if they have the same number of problems solved. Teams with the same number of problems and penalty time share the same rank positions.

### Approach
1. **Input Reading**: Read the number of teams `n` and the position `k` we are interested in. Then read the number of problems solved and penalty time for each team.
2. **Sorting**: Sort the teams first by the number of problems solved in descending order and then by penalty time in ascending order to determine their ranks.
3. **Grouping**: Group consecutive teams that have the same number of problems solved and the same penalty time. Each group represents teams that share the same rank positions.
4. **Determine k-th Position Group**: Iterate through the groups to find which group contains the k-th position. The size of this group is the answer.

### Solution Code
```python
n, k = map(int, input().split())
teams = [tuple(map(int, input().split())) for _ in range(n)]

# Sort the teams by descending problems and ascending penalty time
sorted_teams = sorted(teams, key=lambda x: (-x[0], x[1]))

# Group consecutive teams with the same (p, t)
if not sorted_teams:
    print(0)
    exit()

groups = []
current_group = [sorted_teams[0]]
for team in sorted_teams[1:]:
    if team[0] == current_group[0][0] and team[1] == current_group[0][1]:
        current_group.append(team)
    else:
        groups.append(current_group)
        current_group = [team]
groups.append(current_group)

current_start = 1
for group in groups:
    group_size = len(group)
    current_end = current_start + group_size - 1
    if current_start <= k <= current_end:
        print(group_size)
        exit()
    current_start = current_end + 1

print(0)  # This line is theoretically unreachable given problem constraints
```

1. **Input Reading**: The input is read and stored in a list of tuples where each tuple represents a team's performance.
2. **Sorting**: The list of teams is sorted to prioritize higher number of problems solved and lower penalty times for teams with the same number of problems.
3. **Grouping**: Teams are grouped into consecutive elements with the same number of problems and penalty time. This helps in identifying teams that share the same rank positions.
4. **Finding the k-th Position Group**: By iterating through the groups and tracking the start and end positions each group occupies, we determine which group includes the k-th position. The size of this group is the number of teams sharing the k-th position.

This approach efficiently sorts and groups teams to determine the correct rank positions, ensuring that we accurately find the number of teams sharing the k-th position.
