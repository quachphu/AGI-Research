To solve this problem, we need to determine if a given string can be transformed into the string "keyence" by removing exactly one contiguous substring. This means that after removing a contiguous substring from the given string, the remaining parts (prefix and suffix) should exactly form "keyence".

### Approach
1. **Understand the Problem**: A KEYENCE string is one that can be split into a prefix and suffix such that these two parts form "keyence" when concatenated. The substring between the prefix and suffix can be of any length (including zero) and will be removed.
2. **Generate All Possible Splits**: The string "keyence" can be split into a prefix and suffix in multiple ways. For each possible split, check if the given string starts with the prefix and ends with the suffix.
3. **Check Each Split**: For each possible split of "keyence" into a prefix and suffix, verify if the given string starts with the prefix and ends with the suffix. If any split satisfies this condition, the answer is "YES"; otherwise, it is "NO".

### Solution Code
```python
s = input().strip()

def is_keyence(s):
    target = 'keyence'
    n = len(target)
    for i in range(n + 1):
        left = target[:i]
        right = target[i:]
        if s.startswith(left) and s.endswith(right):
            return True
    return False

print("YES" if is_keyence(s) else "NO")
```

### Explanation
1. **Generate Splits**: The code generates all possible splits of the string "keyence" into a prefix (left part) and a suffix (right part). There are 8 possible splits (from splitting at each position from 0 to 7).
2. **Check Conditions**: For each split, the code checks if the given string starts with the prefix and ends with the suffix. This ensures that removing the substring between the prefix and suffix (if any) will result in "keyence".
3. **Efficiency**: The solution efficiently checks all possible splits in linear time relative to the length of "keyence", making it very efficient even for the upper constraint of the input string length (100 characters).

This approach ensures that we cover all possible ways the given string can be transformed into "keyence" by removing a contiguous substring exactly once.
