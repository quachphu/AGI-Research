To solve this problem, we need to compute the sum of the minimum possible distances between all pairs of points moving on a coordinate axis with constant velocities. The minimum distance for each pair of points is determined by their relative velocities and initial positions.

### Approach
1. **Sort Points by Initial Position**: First, we sort the points based on their initial positions. This helps in efficiently processing each point in the order they appear on the coordinate axis.
2. **Coordinate Compression**: Since the velocities can be very large, we compress these values into a smaller range to efficiently use a Fenwick Tree (Binary Indexed Tree) for range queries and updates.
3. **Fenwick Tree for Efficient Queries**: Using a Fenwick Tree, we keep track of the count of points and their positions encountered so far. This allows us to efficiently compute the required sums for each point as we process them in sorted order.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    idx = 0
    n = int(data[idx])
    idx +=1
    x = list(map(int, data[idx:idx+n]))
    idx +=n
    v = list(map(int, data[idx:idx+n]))
    idx +=n
    
    points = list(zip(x, v))
    points.sort()  # Sort by x
    
    sorted_x = [p[0] for p in points]
    sorted_v = [p[1] for p in points]
    
    # Coordinate compression for v
    unique_vs = sorted(set(sorted_v))
    ranks = []
    for v_i in sorted_v:
        # Find the rank using bisect to handle the sorted unique_vs
        r = bisect.bisect_left(unique_vs, v_i) + 1  # 1-based index
        ranks.append(r)
    size = len(unique_vs)
    
    class FenwickTree:
        def __init__(self, size):
            self.n = size
            self.tree_count = [0] * (self.n + 1)
            self.tree_sum = [0] * (self.n + 1)
        
        def update(self, idx, delta_count, delta_sum):
            while idx <= self.n:
                self.tree_count[idx] += delta_count
                self.tree_sum[idx] += delta_sum
                idx += idx & -idx
        
        def query(self, idx):
            res_count = 0
            res_sum = 0
            while idx > 0:
                res_count += self.tree_count[idx]
                res_sum += self.tree_sum[idx]
                idx -= idx & -idx
            return (res_count, res_sum)
    
    ft = FenwickTree(size)
    total = 0
    for i in range(n):
        xi = sorted_x[i]
        r = ranks[i]
        cnt, s = ft.query(r)
        contribution = xi * cnt - s
        total += contribution
        ft.update(r, 1, xi)
    
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Sorting Points**: We start by sorting the points based on their initial x-coordinates. This ensures that we process each point in the order they appear on the axis.
2. **Coordinate Compression**: By compressing the velocity values into a smaller range, we can efficiently use a Fenwick Tree to handle the range queries and updates. This step converts each velocity into a rank that corresponds to its position in a sorted list of unique velocities.
3. **Fenwick Tree Operations**: The Fenwick Tree is used to keep track of the count of points and the sum of their positions encountered so far. For each point, we query the tree to find how many previous points have a velocity less than or equal to the current point's velocity and the sum of their positions. This allows us to compute the contribution of the current point to the total sum efficiently.

This approach ensures that we handle up to 200,000 points efficiently with a time complexity of O(n log n), making the solution both optimal and scalable.
