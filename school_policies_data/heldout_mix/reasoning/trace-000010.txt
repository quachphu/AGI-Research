To solve this problem, we need to find the minimum total reading time for Alice and Bob to read a set of books such that Alice likes at least `k` books and Bob likes at least `k` books. The solution must be efficient given the constraints.

### Approach
1. **Categorize Books**: Separate the books into three categories:
   - Books liked by both Alice and Bob (category 1).
   - Books liked only by Alice (category 2).
   - Books liked only by Bob (category 3).

2. **Sort and Compute Prefix Sums**: For each category, sort the books by their reading time and compute prefix sums. This allows us to quickly calculate the minimum time required to read any number of books from each category.

3. **Iterate Over Possible Combinations**: For each possible number of books (s) read from category 1, determine the minimum number of books required from categories 2 and 3 to meet the requirement of `k` books for both Alice and Bob. Check if the required number of books from categories 2 and 3 are available and compute the total reading time for each valid combination.

4. **Track Minimum Time**: Keep track of the minimum total reading time across all valid combinations.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n, k = int(input[idx]), int(input[idx+1])
    idx += 2
    
    c1 = []
    c2 = []
    c3 = []
    
    for _ in range(n):
        t = int(input[idx])
        a = int(input[idx+1])
        b = int(input[idx+2])
        idx += 3
        
        if a == 1 and b == 1:
            c1.append(t)
        elif a == 1 and b == 0:
            c2.append(t)
        elif a == 0 and b == 1:
            c3.append(t)
    
    # Sort each category
    c1.sort()
    c2.sort()
    c3.sort()
    
    # Compute prefix sums for each category
    def get_prefix(arr):
        prefix = [0]
        current_sum = 0
        for t in arr:
            current_sum += t
            prefix.append(current_sum)
        return prefix
    
    prefix_c1 = get_prefix(c1)
    prefix_c2 = get_prefix(c2)
    prefix_c3 = get_prefix(c3)
    
    min_time = float('inf')
    max_s = len(c1)
    
    for s in range(0, max_s + 1):
        required_a2 = max(0, k - s)
        required_b3 = max(0, k - s)
        
        if required_a2 > len(c2):
            continue
        if required_b3 > len(c3):
            continue
        
        total = prefix_c1[s] + prefix_c2[required_a2] + prefix_c3[required_b3]
        if total < min_time:
            min_time = total
    
    print(-1 if min_time == float('inf') else min_time)

if __name__ == "__main__":
    main()
```

1. **Input Reading and Categorization**: The input is read and books are categorized into three lists based on who likes them.
2. **Sorting and Prefix Sums**: Each category is sorted by reading time, and prefix sums are computed to quickly determine the sum of the first `n` books in each category.
3. **Iterative Check**: For each possible number of books from category 1, we check the minimum required books from categories 2 and 3 to meet the `k` requirement. The total reading time for valid combinations is computed and the minimum time is tracked.
4. **Result**: The minimum valid total reading time is printed, or `-1` if no valid combination exists.

This approach efficiently handles the constraints by leveraging sorting and prefix sums, ensuring that the solution is computed in O(n log n) time, which is feasible for large input sizes.
