The challenge is to find the earliest starting index of such a sequence, considering possible irrelevant prefixes and suffixes.

### Approach
1. **Input Reading**: Read multiple datasets until a line with a single zero is encountered.
2. **Prefix Sum Calculation**: Compute the prefix sum array of word lengths to efficiently calculate the sum of any subarray.
3. **Check Valid Subarray**: For each possible starting index, check all possible ending indices to see if the subarray sums to 31 (5+7+5+7+7). If it does, generate the cumulative sum array for the subarray and verify if it can be split into the required sections.
4. **Section Validation**: Ensure the cumulative sum array contains the milestones 5, 12, 17, and 24 in order, confirming the correct sectioning.

### Solution Code
```python
def is_valid(s):
    targets = [5, 12, 17, 24]
    current_pos = 0
    for target in targets:
        found = False
        for pos in range(current_pos + 1, len(s)):
            if s[pos] == target:
                current_pos = pos
                found = True
                break
        if not found:
            return False
    return True

def find_short_phrase():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    while True:
        if ptr >= len(input):
            break
        n = int(input[ptr])
        ptr += 1
        if n == 0:
            break
        words = input[ptr:ptr+n]
        ptr += n
        lengths = [len(word) for word in words]
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i+1] = prefix[i] + lengths[i]
        result = None
        for i in range(n):
            found = False
            for j in range(i, n):
                sum_ij = prefix[j+1] - prefix[i]
                if sum_ij != 31:
                    continue
                s = [0]
                current_sum = 0
                for k in range(i, j+1):
                    current_sum += lengths[k]
                    s.append(current_sum)
                if is_valid(s):
                    result = i + 1  # converting to 1-based
                    found = True
                    break
            if found:
                break
        print(result)

find_short_phrase()
```

### Explanation
1. **Input Handling**: The input is read in one go and split into tokens for efficient processing. Each dataset is processed sequentially.
2. **Prefix Sum Array**: This array helps quickly calculate the sum of any subarray, which is crucial for checking if a subarray sums to 31.
3. **Subarray Validation**: For each subarray that sums to 31, the cumulative sum array is generated. The `is_valid` function checks if this array contains the required milestones (5, 12, 17, 24) in order, ensuring the subarray can be divided into the correct sections.
4. **Efficiency**: The algorithm efficiently checks all possible starting and ending indices, ensuring the earliest valid starting index is found and returned.

This approach ensures that we efficiently and accurately determine the starting index of the valid Short Phrase while adhering to the problem constraints.
