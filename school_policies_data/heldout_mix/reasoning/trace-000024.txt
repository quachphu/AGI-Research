To solve this problem, we need to determine the minimum possible hardness of dividing a kingdom into two parts based on given intervals of roads. The hardness is defined as the maximum length of a road whose endpoints are in the same part, or -1 if all roads can be split between the two parts.

### Approach
1. **Problem Analysis**:
   - The goal is to minimize the maximum road length that remains within either part of the divided kingdom.
   - For each query, we need to check if the roads in the specified interval can form a bipartite graph. If they can, the hardness is -1. If not, we find the smallest maximum road length that, when excluded, makes the remaining roads bipartite.

2. **Key Insight**:
   - Use a Disjoint Set Union (DSU) with parity to detect odd cycles, which determine if a graph is non-bipartite.
   - Process roads in descending order of their weights. The first road that forms an odd cycle when added to the DSU determines the minimum possible hardness.

3. **Algorithm**:
   - For each query, extract the roads in the specified interval.
   - Sort these roads in descending order of their weights.
   - Use DSU with parity to check for odd cycles incrementally as each road is added. The first road causing an odd cycle gives the minimum hardness.

### Solution Code
```python
class DSU:
    def __init__(self, size):
        self.parent = list(range(size + 1))  # 1-based indexing
        self.parity = [0] * (size + 1)       # Parity from node to parent

    def find(self, u):
        if self.parent[u] != u:
            orig_parent = self.parent[u]
            self.parent[u], p = self.find(orig_parent)
            self.parity[u] ^= p
        return self.parent[u], self.parity[u]

    def union(self, u, v):
        ru, pu = self.find(u)
        rv, pv = self.find(v)
        if ru == rv:
            return pu == pv  # Returns True if creates an odd cycle
        else:
            self.parent[rv] = ru
            self.parity[rv] = (pu ^ pv) ^ 1
            return False

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    m = int(input[idx])
    idx += 1
    q = int(input[idx])
    idx += 1

    roads = []
    for _ in range(m):
        u = int(input[idx])
        idx += 1
        v = int(input[idx])
        idx += 1
        w = int(input[idx])
        idx += 1
        roads.append((u, v, w))

    for _ in range(q):
        l = int(input[idx])
        idx += 1
        r = int(input[idx])
        idx += 1
        selected = roads[l-1:r]
        sorted_edges = sorted(selected, key=lambda x: -x[2])
        dsu = DSU(n)
        ans = -1
        for u, v, w in sorted_edges:
            if dsu.union(u, v):
                ans = w

        print(ans if ans != -1 else -1)

if __name__ == "__main__":
    main()
```

### Explanation
- **DSU with Parity**: This data structure helps track the parity (even or odd path length) from each node to its root. It efficiently detects odd cycles, which indicate a non-bipartite graph.
- **Processing Queries**: For each query, roads are sorted by descending weight. Adding each road to the DSU checks if it forms an odd cycle. The first road causing an odd cycle determines the minimum hardness, as higher weight roads must be excluded to maintain bipartiteness.
- **Efficiency**: The DSU operations are nearly constant time due to path compression and union by rank, making the solution efficient even for large inputs.
