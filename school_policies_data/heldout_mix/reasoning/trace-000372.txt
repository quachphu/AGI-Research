To solve this problem, we need to generate the nth number in the Pratyush Number System (PNS), which uses only the digits 4, 5, and 6. The numbers in PNS are generated in lexicographical order and can be thought of as numbers in a base-3 system where each digit is mapped to 4, 5, or 6.

### Approach
1. **Understanding the Sequence**: The numbers in PNS are generated in lexicographical order using the digits 4, 5, and 6. Each digit position can be considered as a base-3 digit (0, 1, 2) mapped to 4, 5, 6 respectively.
2. **Determine the Number of Digits (m)**: For a given n, find the smallest m such that the sum of all PNS numbers with up to m digits is at least n. This sum is calculated using the formula for the sum of a geometric series.
3. **Position in Group**: Once the number of digits (m) is determined, compute the position of n within the group of m-digit numbers.
4. **Convert to Base-3**: Convert the position to a base-3 number, pad it with leading zeros to ensure it has m digits, and then map each digit to 4, 5, or 6.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        n = int(input[i])
        m = 1
        while True:
            sum_prev = (3**m - 3) // 2
            sum_current = (3**(m + 1) - 3) // 2
            if sum_prev < n <= sum_current:
                break
            m += 1
        pos_in_group = n - sum_prev
        x = pos_in_group - 1
        if x == 0:
            s = '0' * m
        else:
            digits = []
            tmp = x
            while tmp > 0:
                digits.append(tmp % 3)
                tmp = tmp // 3
            s = ''.join(str(d) for d in reversed(digits)).zfill(m)
        res = s.translate(str.maketrans('012', '456'))
        print(res)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Finding m**: For each test case, we determine the number of digits (m) by iterating until the sum of all numbers up to m digits is at least n.
3. **Position Calculation**: Calculate the position within the m-digit group and adjust for zero-based indexing.
4. **Base Conversion**: Convert the adjusted position to a base-3 string, pad with leading zeros, and map each digit to 4, 5, or 6 using a translation table.

This approach efficiently handles very large values of n by leveraging the properties of geometric series and base conversion, ensuring the solution is both optimal and correct.
