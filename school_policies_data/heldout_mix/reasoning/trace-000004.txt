### Approach
1. **Input Handling**: Read the input values and parse them into appropriate variables.
2. **Immediate Check**: If any element in the set is exactly equal to K, immediately return 1 as the subset exists.
3. **Filter Elements**: Remove elements greater than K and zeros, as zeros do not contribute to the subset sum.
4. **Sum Check**: If the sum of the filtered elements is less than K, return 0. If the sum is exactly K, return 1.
5. **Bitmask Technique**: Use a bitmask to track possible subset sums. Each bit in the bitmask represents whether a sum corresponding to that bit position can be achieved. This technique efficiently updates possible sums using bitwise operations.

### Solution Code
```python
import sys

def solve():
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N, K = int(input[idx]), int(input[idx+1])
        idx += 2
        S = list(map(int, input[idx:idx+N]))
        idx += N

        # Check if any element is exactly K
        if K in S:
            print(1)
            continue

        # Filter out elements greater than K and zeros
        filtered = [x for x in S if x <= K and x != 0]
        sum_f = sum(filtered)

        if sum_f < K:
            print(0)
            continue
        if sum_f == K:
            print(1)
            continue

        # Use bitmask approach to track possible sums
        mask = 1
        target = 1 << K
        for num in filtered:
            mask |= mask << num
            mask &= (1 << (K + 1)) - 1  # Keep only the relevant bits
            if mask & target:
                break  # Early exit if target sum is found

        print(1 if (mask & target) else 0)

solve()
```

3. **Sum Check**: If the sum of the filtered elements is less than K, it's impossible to form K. If the sum is exactly K, the entire filtered list is the subset.
4. **Bitmask Technique**: The bitmask tracks possible sums using bitwise operations. Each bit position represents a sum.
