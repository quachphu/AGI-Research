To solve this problem, we need to determine the length of the factorial of a given number \( n \) excluding any trailing zeros. Direct computation of \( n! \) for large \( n \) is impractical due to its rapid growth, so we use mathematical approximations and properties of logarithms and factorials to efficiently solve the problem.

### Approach

1. **Count Trailing Zeros**: The number of trailing zeros in \( n! \) is determined by the number of times 10 is a factor in \( n! \). Since 10 is the product of 2 and 5, and there are usually more 2s than 5s in the prime factorization of \( n! \), the number of trailing zeros is the sum of the integer divisions of \( n \) by 5, 25, 125, etc.

2. **Logarithmic Calculation of Factorial Length**: Using Stirling's approximation, we can approximate the natural logarithm of \( n! \) and then convert it to a base-10 logarithm. This allows us to compute the number of digits of \( n! \) efficiently without computing the factorial directly.

3. **Adjust for Trailing Zeros**: Subtract the count of trailing zeros from the logarithmic value of \( n! \) and compute the number of digits of the resulting value.

### Solution Code

```python
import math

def count_trailing_zeros(n):
    count = 0
    divisor = 5
    while divisor <= n:
        count += n // divisor
        divisor *= 5
    return count

def compute_log_fact(n):
    if n <= 20:
        log_sum = 0.0
        for k in range(1, n + 1):
            log_sum += math.log10(k)
        return log_sum
    else:
        ln_n = math.log(n)
        ln_fact = (n * ln_n) - n + 0.5 * math.log(2 * math.pi * n) + 1 / (12 * n)
        log_fact = ln_fact / math.log(10)
        return log_fact

def main():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])

        n = int(input[i])

            print(1)

            log_fact = compute_log_fact(n)
            adjusted = log_fact - z
            digits = int(adjusted) + 1
```
