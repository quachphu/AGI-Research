To solve this problem, we need to determine if Petr can rotate the lock's wheel such that after exactly n rotations, the pointer returns to zero. Each rotation can be either clockwise or counterclockwise, and the sum of all rotations modulo 360 must be zero.

### Approach
The problem can be approached by checking all possible combinations of clockwise and counterclockwise rotations. Since the number of rotations (n) is up to 15, we can use a brute-force method to explore all possible combinations efficiently. Each combination can be represented using a bitmask, where each bit indicates the direction of the corresponding rotation (clockwise or counterclockwise). We then check if any combination results in a total sum that is a multiple of 360.

### Solution Code
```python
n = int(input())
angles = [int(input()) for _ in range(n)]

found = False

for mask in range(2 ** n):
    total = 0
    for i in range(n):
        if (mask >> i) & 1:
            total += angles[i]
        else:
            total -= angles[i]
    if total % 360 == 0:
        found = True
        break

print("YES" if found else "NO")
```

### Explanation
1. **Reading Input:** We first read the number of rotations (n) and the list of angles for each rotation.
2. **Bitmask Representation:** Each possible combination of directions (clockwise or counterclockwise) is represented using a bitmask. For `n` rotations, there are `2^n` possible combinations.
3. **Sum Calculation:** For each combination (bitmask), we calculate the total rotation sum. If the bit corresponding to a rotation is set (1), we add the angle; otherwise, we subtract it.
4. **Modulo Check:** After computing the total sum for a combination, we check if it modulo 360 is zero. If any combination satisfies this condition, we print "YES" and exit. If none do, we print "NO".

This approach efficiently checks all possible combinations using bitmasking, ensuring that we consider every possible direction for each rotation. The complexity is manageable due to the constraints (n ≤ 15), making the brute-force approach feasible.
