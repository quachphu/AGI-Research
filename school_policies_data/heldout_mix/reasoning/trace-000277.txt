To solve this problem, we need to determine the minimum number of moves required to gather all figures into one cell on an n x n board where n is odd. Each move allows moving a figure to any of the 8 adjacent cells (including diagonally adjacent). The optimal solution involves moving all figures to the center cell, and the number of moves for each figure is determined by its Chebyshev distance from the center.

### Approach
1. **Chebyshev Distance**: The Chebyshev distance from a cell (i, j) to the center (c, c) is the maximum of the horizontal and vertical distances from (i, j) to (c, c). This distance represents the minimum number of moves required to move a figure from (i, j) to (c, c).
2. **Layered Sum Calculation**: The problem can be broken down into calculating the sum of Chebyshev distances from all cells to the center. This sum is efficiently computed using a mathematical formula derived from the properties of the Chebyshev distance and the structure of an odd-sized grid.
3. **Mathematical Formula**: The sum of Chebyshev distances for an n x n grid (where n is odd) can be computed using the formula:
   \[
   \text{total\_moves} = \frac{4}{3} \times k \times (k + 1) \times (2k + 1)
   \]
   where \( k = \frac{n - 1}{2} \).

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        k = (n - 1) // 2
        result = (4 * k * (k + 1) * (2 * k + 1)) // 3
        print(result)

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input consists of multiple test cases. For each test case, we read the size of the board, n.

3. **Formula Application**: Using the derived formula, we compute the total number of moves required by summing the Chebyshev distances of all cells from the center.
