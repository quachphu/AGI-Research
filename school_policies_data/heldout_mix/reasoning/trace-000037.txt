The solution can be derived using game theory principles where the losing positions are determined by the modulo operation. Specifically, if `(n-1)` is divisible by `(k+1)`, the current player (Rani) will lose if both play optimally. Otherwise, Rani will win.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    t = int(input[0])
    idx = 1
    for _ in range(t):
        n = int(input[idx])
        k = int(input[idx + 1])
        idx += 2
        if (n - 1) % (k + 1) == 0:
            print("Nandu")
        else:
            print("Rani")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Game Theory Insight**: The problem can be analyzed using the concept of losing positions in game theory. A losing position is one where any move a player makes will leave the opponent in a winning position.
2. **Modulo Operation**: The critical observation is that if `(n-1)` is a multiple of `(k+1)`, the current player (Rani) will be in a losing position. This is because no matter what value Rani subtracts (from 1 to k), Nandu can always adjust his move to maintain the losing position for Rani.
3. **Optimal Play**: Both players play optimally, meaning they will always force the opponent into a losing position if possible. Thus, if `(n-1) % (k+1) == 0`, Nandu wins; otherwise, Rani wins.

This approach efficiently determines the winner in constant time for each test case, making it suitable for large inputs. The solution uses fast I/O operations to handle the constraints effectively.
