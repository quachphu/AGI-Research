To solve this problem, we need to determine the minimum time Princess Heidi has to spend on meetings with her K Rebel ship commanders, ensuring that no two meetings overlap. The solution involves selecting K non-overlapping intervals from a sorted list of times, where each interval is a pair of consecutive times, and the sum of their differences is minimized.

### Approach
1. **Sort the Times**: First, we sort the given times to ensure we can work with consecutive intervals.
2. **Compute Differences**: Calculate the differences between consecutive times. These differences represent the duration of potential meetings.
3. **Dynamic Programming (DP)**: Use a dynamic programming approach to select K non-overlapping intervals such that the sum of their differences is minimized. We maintain two arrays to keep track of the minimum sum for selecting up to K intervals at each step.

### Solution Code
```python
import sys

def main():
    k, n = map(int, sys.stdin.readline().split())
    times = list(map(int, sys.stdin.readline().split()))
    times.sort()
    diffs = [times[i+1] - times[i] for i in range(n-1)]
    m = len(diffs)
    K = k
    INF = float('inf')
    
    # Initialize DP arrays
    prev_prev = [INF] * (K + 1)
    prev_prev[0] = 0  # Selecting 0 elements requires 0 time
    
    prev = [INF] * (K + 1)
    prev[0] = 0  # Before any elements, sum is 0 for 0 elements
    
    for i in range(m):
        curr = prev.copy()  # By default, current is previous (not taking the i-th element)
        for j in range(1, K + 1):
            # Option to take the i-th element: requires adding diff[i] to prev_prev[j-1]
            if i >= 1:
                take = prev_prev[j-1] + diffs[i]
            else:
                # For the first element, prev_prev is initial state (0 for j=1)
                take = diffs[i] if j == 1 else INF
            if take < curr[j]:
                curr[j] = take
        # Update the previous arrays for the next iteration
        prev_prev, prev = prev, curr
    
    print(prev[K])

if __name__ == "__main__":
    main()
```

1. **Sorting the Times**: By sorting the times, we can work with consecutive intervals to ensure we only consider valid meeting intervals.
2. **Differences Calculation**: The differences between consecutive sorted times give the possible durations of meetings. These differences are stored in an array.
3. **Dynamic Programming**: We use two arrays, `prev_prev` and `prev`, to keep track of the minimum sum of durations for selecting up to K intervals. For each time interval, we update the current state based on whether we include the current interval or not, ensuring no two selected intervals are adjacent.

This approach efficiently computes the minimum time required using dynamic programming, ensuring we adhere to the constraints and select the optimal intervals. The solution handles large inputs by leveraging dynamic programming to avoid redundant calculations and ensure optimal performance.
