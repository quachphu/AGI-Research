To solve this problem, we need to determine the minimum number of days Anastasia needs to collect all pebbles from the park using her two pockets, given that each pocket can hold at most `k` pebbles of the same type.

### Approach
1. **Understanding Pocket Usage**: Each pocket can hold up to `k` pebbles of a single type. For each type of pebble, we calculate the number of pockets required to carry all pebbles of that type using the ceiling of division (i.e., `(w + k - 1) // k`).
2. **Summing Pockets**: Sum the number of pockets required for all pebble types. This sum gives the total pockets needed.
3. **Calculating Days**: Since Anastasia can use both pockets each day, the minimum number of days required is the ceiling of the total pockets divided by 2. This is computed as `(total_pockets + 1) // 2`.

### Solution Code
```python
n, k = map(int, input().split())
w_list = list(map(int, input().split()))
sum_pockets = 0
for w in w_list:
    sum_pockets += (w + k - 1) // k
days = (sum_pockets + 1) // 2
print(days)
```

### Explanation
1. **Reading Input**: The first line of input contains `n` (number of pebble types) and `k` (max pebbles per pocket). The second line contains the list of pebbles for each type.
2. **Calculating Pockets per Type**: For each pebble type `w`, compute the number of pockets needed using integer arithmetic to avoid floating-point operations. This is done by `(w + k - 1) // k`, which effectively computes the ceiling of `w / k`.
3. **Summing Pockets**: Accumulate the total number of pockets required across all pebble types.
4. **Determining Days**: Convert the total pockets into days by considering that each day allows using two pockets. This is achieved by taking the ceiling of dividing the total pockets by 2, computed as `(total_pockets + 1) // 2`.

This approach efficiently handles the constraints and ensures the solution is optimal and runs in linear time relative to the number of pebble types.
