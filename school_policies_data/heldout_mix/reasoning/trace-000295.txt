To solve this problem, we need to determine the minimum number of bridges Monk must cross to travel from Island 1 to Island N in an optimal route. This problem can be efficiently solved using the Breadth-First Search (BFS) algorithm, which is well-suited for finding the shortest path in an unweighted graph.

### Approach
1. **Graph Representation**: Represent the islands and bridges using an adjacency list. Each island is a node, and each bridge is an undirected edge between two nodes.
2. **BFS Algorithm**: Use BFS starting from Island 1 to explore all reachable islands. BFS is ideal here because it explores all nodes at the present depth (number of bridges crossed) before moving to nodes at the next depth level, ensuring the shortest path is found.
3. **Early Termination**: Once we reach Island N during BFS traversal, we can immediately terminate the search as BFS guarantees the shortest path has been found.

### Solution Code
```python
import sys
from collections import deque

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        M = int(input[ptr + 1])
        ptr += 2
        adj = [[] for _ in range(N + 1)]
        for __ in range(M):
            X = int(input[ptr])
            Y = int(input[ptr + 1])
            adj[X].append(Y)
            adj[Y].append(X)
            ptr += 2
        dist = [-1] * (N + 1)
        q = deque()
        dist[1] = 0
        q.append(1)
        found = False
        while q and not found:
            u = q.popleft()
            for v in adj[u]:
                if dist[v] == -1:
                    dist[v] = dist[u] + 1
                    if v == N:
                        found = True
                        break
                    q.append(v)
            if found:
                break
        print(dist[N])

main()
```

1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints. The input is split into a list for easy access.
2. **Graph Construction**: For each test case, an adjacency list is built to represent the graph using the given edges.
3. **BFS Initialization**: The BFS starts from Island 1. A queue is used to manage the nodes to be processed, and a distance array tracks the minimum number of bridges crossed to reach each island.
4. **BFS Execution**: For each node processed, its neighbors are checked. If a neighbor hasn't been visited, its distance is updated, and it is added to the queue. If the target Island N is reached, the search terminates early to save time.
5. **Output**: The distance to Island N is printed for each test case, which represents the minimum number of bridges Monk needs to cross.

This approach ensures that the solution is both efficient and correct, handling the constraints effectively.
