To solve this problem, we need to determine how many hours Vasily can keep his room illuminated using candles, considering he can create new candles from the stubs of burned-out ones. 

### Approach
1. **Initial Burn**: Start by burning all the initial candles. Each candle burns for 1 hour, contributing directly to the total hours.
2. **Recycle Stubs**: After burning the initial candles, collect the stubs. For every `b` stubs, Vasily can create a new candle, which burns for another hour and produces another stub.
3. **Iterative Process**: Continue recycling stubs into new candles until there are not enough stubs left to create a new candle. Each iteration updates the total hours and the remaining stubs.

### Solution Code
```python
a, b = map(int, input().split())
total = a
stubs = a
while stubs >= b:
    new = stubs // b
    total += new
    stubs = stubs % b + new
print(total)
```

### Explanation
1. **Reading Input**: The input consists of two integers `a` (initial number of candles) and `b` (number of stubs needed to create a new candle).
2. **Initial Total Hours**: The initial total hours are set to `a` because each candle burns for 1 hour.
3. **Stub Recycling Loop**: Using a loop, we repeatedly convert stubs into new candles until we no longer have enough stubs. For each iteration:
   - Calculate the number of new candles (`new`) that can be made from the current stubs.
   - Add these new candles to the total hours.
   - Update the stubs to account for the remaining stubs after creating new candles and the stubs from burning the new candles.
4. **Output the Result**: Once the loop exits, the total hours accumulated is printed.

This approach efficiently calculates the maximum illumination time by iteratively recycling stubs, ensuring optimal use of resources.
