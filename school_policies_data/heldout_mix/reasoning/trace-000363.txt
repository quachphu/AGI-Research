To solve this problem, we need to reorganize freight trains in parking lines using exchange lines to minimize the number of movements. The goal is to transform the initial configuration of trains into the target configuration using the fewest moves possible.

### Approach
1. **Model the Problem as a State Space**: Each state represents the current configuration of trains in all parking lines. We need to explore transitions between states using BFS (Breadth-First Search) to find the shortest path (minimum moves) from the initial state to the target state.

2. **Exchange Lines Representation**: Use a dictionary to map each end of a parking line to the connected ends of other parking lines. This helps in efficiently determining possible moves.

3. **Generate Moves**: For each state, generate all possible next states by splitting trains at any possible position and moving a part through an exchange line. Each move is considered as a transition from one state to another.

4. **BFS for Shortest Path**: Use BFS to explore states level by level. The first time we reach the target state gives the minimum number of moves required.

from collections import deque
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    while True:
        x = int(input[ptr])
        y = int(input[ptr + 1])
        ptr += 2
        if x == 0 and y == 0:
            break
        
        exchange_map = {}
        for _ in range(y):
            part1 = input[ptr]
            part2 = input[ptr + 1]
            ptr += 2
            p1 = int(part1[:-1])
            P1 = part1[-1]
            p2 = int(part2[:-1])
            P2 = part2[-1]
            
            if (p1, P1) not in exchange_map:
                exchange_map[(p1, P1)] = []
            exchange_map[(p1, P1)].append((p2, P2))
            
            if (p2, P2) not in exchange_map:
                exchange_map[(p2, P2)] = []
            exchange_map[(p2, P2)].append((p1, P1))
        
        initial = []
        for _ in range(x):
            s = input[ptr]
            ptr += 1
            initial.append(s if s != '-' else '')
        target = []
        for _ in range(x):
            s = input[ptr]
            ptr += 1
            target.append(s if s != '-' else '')
        
        initial_tuple = tuple(initial)
        target_tuple = tuple(target)
        
        queue = deque()
        queue.append((initial_tuple, 0))
        visited = set()
        visited.add(initial_tuple)
        answer = -1
        
        while queue:
            current_state, moves = queue.popleft()
            if current_state == target_tuple:
                answer = moves
                break
            if moves >= 6:
                continue
            
            for i in range(x):
                current_line = current_state[i]
                if not current_line:
                    continue
                
                for end in ['W', 'E']:
                    key = (i, end)
                    if key not in exchange_map:
                        continue
                    connections = exchange_map[key]
                    for (j, j_end) in connections:
                        line_len = len(current_line)
                        for split_k in range(line_len + 1):
                            if end == 'W':
                                moved_part = current_line[:split_k]
                                remaining = current_line[split_k:]
                            else:
                                moved_part = current_line[split_k:]
                                remaining = current_line[:split_k]
                            
                            if not moved_part:
                                continue
                            
                            current_j_line = current_state[j]
                            if current_j_line:
                                if j_end == 'W':
                                    new_j_line = moved_part + current_j_line
                                else:
                                    new_j_line = current_j_line + moved_part
                            else:
                                new_j_line = moved_part
                            
                            new_state = list(current_state)
                            new_state[i] = remaining if remaining else ''
                            new_state[j] = new_j_line
                            new_state_tuple = tuple(new_state)
                            
                            if new_state_tuple not in visited:
                                visited.add(new_state_tuple)
                                queue.append((new_state_tuple, moves + 1))
        
        print(answer)
