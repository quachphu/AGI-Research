To solve this problem, we need to assign labels to vertices of a directed acyclic graph (DAG) such that the labels form the lexicographically smallest permutation while respecting the edge constraints. The key insight is to use a greedy approach that assigns the largest possible labels first to nodes with no outgoing edges, allowing smaller labels to be assigned to other nodes in a way that maintains the lexicographical order.

### Approach
1. **Reverse Edges and Track Out-Degrees**: For each node, track the number of outgoing edges (out-degree) and maintain a reverse adjacency list to track incoming edges.
2. **Max Heap for Eligible Nodes**: Use a max heap (priority queue) to select nodes with zero out-degree in descending order. This ensures that we always process the largest possible node first, allowing smaller nodes to take smaller labels.
3. **Label Assignment**: Starting from the largest label (n) and decrementing down to 1, assign labels to nodes as they become eligible (out-degree reaches zero). Adjust the out-degrees of nodes pointing to the current node and update the heap as nodes become eligible.

### Solution Code
```python
import heapq

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    m = int(input[idx])
    idx += 1
    
    reverse_edges = [[] for _ in range(n + 1)]
    out_degree = [0] * (n + 1)
    
    for _ in range(m):
        v = int(input[idx])
        idx += 1
        u = int(input[idx])
        idx += 1
        reverse_edges[u].append(v)
        out_degree[v] += 1
    
    heap = []
    for i in range(1, n + 1):
        if out_degree[i] == 0:
            heapq.heappush(heap, -i)
    
    labels = [0] * (n + 1)
    current_label = n
    
    while heap:
        u = -heapq.heappop(heap)
        labels[u] = current_label
        current_label -= 1
        for v in reverse_edges[u]:
            out_degree[v] -= 1
            if out_degree[v] == 0:
                heapq.heappush(heap, -v)
    
    print(' '.join(map(str, labels[1:])))
    
main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of nodes (n) and edges (m). Each edge is processed to build the reverse adjacency list and track out-degrees.
2. **Heap Initialization**: Nodes with zero out-degree are pushed into a max heap (using negative values to simulate max heap with Python's min-heap).
3. **Label Assignment Loop**: The largest available label is assigned to the node with the highest index that has zero out-degree. After assigning a label, the out-degrees of nodes pointing to the current node are decremented. Nodes whose out-degree becomes zero are added to the heap.
4. **Output**: The labels for nodes 1 to n are printed in order, forming the lexicographically smallest permutation that satisfies all edge constraints.

This approach efficiently ensures that each node is processed in the optimal order to achieve the smallest lexicographical permutation while respecting the DAG constraints.
