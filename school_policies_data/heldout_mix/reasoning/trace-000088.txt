To solve this problem, we need to determine the maximum number of points a player can achieve in a single move and the number of such moves. The game involves moving chips on a grid according to their arrows, removing each chip as it is used, and counting the number of chips removed in a single move.

### Approach
1. **Precompute Next Chips**: For each chip, precompute the list of possible next chips in the direction indicated by the arrow. This helps in efficiently determining the next move during the simulation.
2. **Simulate Moves**: For each chip, simulate the move process by following the arrows and removing chips as they are used. Track the number of chips removed in each move.
3. **Track Maximum Points**: Keep track of the maximum number of points (chips removed) and the count of moves that achieve this maximum.
