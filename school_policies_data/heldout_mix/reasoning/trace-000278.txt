To solve this problem, we need to determine if Alice can win a game where she and Bob alternately remove adjacent differing characters (0 and 1) from a binary string. The solution hinges on the optimal play of both players and the structure of the binary string.

### Approach
The key insight is that each move removes one '0' and one '1'. The maximum number of such moves possible is determined by the minimum count of '0's and '1's in the string. If this minimum count is odd, Alice wins because she makes the first move and will make the last move if the count is odd. If the minimum count is even, Bob wins because he will make the last move.

### Solution Code
```python
t = int(input())
for _ in range(t):
    s = input().strip()
    cnt0 = s.count('0')
    cnt1 = s.count('1')
    m = min(cnt0, cnt1)
    print("DA" if m % 2 == 1 else "NET")
```

### Explanation
1. **Input Reading**: Read the number of test cases.
2. **Character Counting**: For each test case, count the number of '0's and '1's in the string.
3. **Determine Minimum**: Calculate the minimum of the counts of '0's and '1's. This gives the maximum number of moves possible.
4. **Check Parity**: If the minimum count is odd, Alice wins ("DA"). If even, Bob wins ("NET").

This approach efficiently determines the winner in O(n) time per test case, where n is the length of the string, making it suitable for large inputs up to the given constraints.
