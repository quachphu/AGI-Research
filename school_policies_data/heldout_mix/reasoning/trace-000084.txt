To solve this problem, we need to determine the lexicographically largest permutation that can be obtained by swapping elements at given positions any number of times. The key insight is that positions connected through swaps form a group where elements can be rearranged in any order. By sorting these groups appropriately, we can achieve the desired permutation.

### Approach
1. **Union-Find Data Structure**: Use the Disjoint Set Union (DSU) to find connected components of positions based on the given swap pairs. Each connected component represents a group of positions that can be freely swapped among themselves.
2. **Group Processing**: For each connected component, collect the elements at those positions, sort them in descending order, and then assign them back to the sorted positions within the component. This ensures that the largest elements are placed in the earliest possible positions within each component, maximizing the lexicographical order.

### Solution Code
```python
import sys

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [1] * n
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return
        if self.rank[x_root] < self.rank[y_root]:
            self.parent[x_root] = y_root
        else:
            self.parent[y_root] = x_root
            if self.rank[x_root] == self.rank[y_root]:
                self.rank[x_root] += 1

def main():
    n, m = map(int, sys.stdin.readline().split())
    p = list(map(int, sys.stdin.readline().split()))
    dsu = DSU(n)
    for _ in range(m):
        a, b = map(int, sys.stdin.readline().split())
        dsu.union(a-1, b-1)  # Convert to 0-based indices
    
    groups = {}
    for i in range(n):
        root = dsu.find(i)
        if root not in groups:
            groups[root] = []
        groups[root].append(i)
    
    for indices in groups.values():
        indices_sorted = sorted(indices)
        values = [p[i] for i in indices]
        values_sorted = sorted(values, reverse=True)
        for idx, val in zip(indices_sorted, values_sorted):
            p[idx] = val
    
    print(' '.join(map(str, p)))

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read using efficient methods suitable for large input sizes.
2. **DSU Initialization**: The DSU structure is initialized to manage the connected components of positions.
3. **Union Operations**: For each swap pair, the union operation is performed to merge the positions into connected components.
4. **Group Collection**: After processing all swaps, each position is grouped into its connected component using the DSU find operation.
5. **Sorting and Assignment**: For each component, the indices are sorted, and the values at these indices are sorted in descending order. These sorted values are then assigned back to the sorted indices to form the largest lexicographical permutation.

This approach efficiently handles the constraints and ensures the solution is optimal both in time and space complexity.
