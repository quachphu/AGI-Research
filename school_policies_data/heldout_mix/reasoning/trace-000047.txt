### Approach
1. **Reading Input**: Read all input data at once and split it into a list of strings for easier processing.
2. **Processing Datasets**: Iterate through the list of input values. For each dataset, read the number of elements `n` and the subsequent `n` integers into an array.
3. **Bubble Sort with Swap Counting**: Implement the bubble sort algorithm on the array while keeping track of the number of swaps. Bubble sort works by repeatedly swapping adjacent elements if they are in the wrong order. Each pass through the array places the next largest element in its correct position, reducing the unsorted portion of the array by one element each time.
4. **Output the Swap Count**: After sorting each dataset, output the total number of swaps required.

### Solution Code
```python
import sys

def main():
    data = sys.stdin.read().split()
    ptr = 0
    while ptr < len(data):
        n = int(data[ptr])
        ptr += 1
        if n == 0:
            break
        a = list(map(int, data[ptr:ptr + n]))
        ptr += n
        swap_count = 0
        arr = a.copy()
        for i in range(len(arr) - 1):
            for j in range(len(arr) - i - 1):
                if arr[j] > arr[j + 1]:
                    arr[j], arr[j + 1] = arr[j + 1], arr[j]
                    swap_count += 1
        print(swap_count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once using `sys.stdin.read().split()`, which splits the input into a list of strings based on whitespace. This simplifies processing as we can handle each value sequentially.
2. **Processing Datasets**: We use a pointer `ptr` to navigate through the list of input values. For each dataset, we read the integer `n` (number of elements) and then the next `n` integers to form the array.
3. **Bubble Sort Implementation**: The outer loop runs `n-1` times, where `n` is the length of the array. The inner loop processes the unsorted portion of the array, comparing adjacent elements and swapping them if they are in the wrong order. Each swap increments the swap count.
4. **Output**: After sorting each dataset, the total number of swaps is printed. This count is accumulated during each swap operation in the inner loop.

This approach efficiently processes each dataset using bubble sort, ensuring the correct count of swaps is determined and outputted for each input array.
