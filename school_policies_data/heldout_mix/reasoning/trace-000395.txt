To solve this problem, we need to efficiently manage and query the online status of Limak's friends and determine if a friend is displayed on the system based on their relationship value. The system displays up to `k` friends with the highest relationship values.

### Approach
1. **Data Structures**:
   - **Online Tracking**: Use a boolean array to track which friends are online.
   - **Top k Values**: Maintain a list `top_k` to store the current highest `k` relationship values in descending order. Additionally, use a set `top_set` to quickly check if a friend's relationship value is among the top `k`.

2. **Handling Queries**:
   - **Type 1 (Friend comes online)**: When a friend comes online, update their status and check if their relationship value should be added to the top `k` list. If the list has fewer than `k` elements, add the value directly. If the list is full, replace the smallest value if the new value is larger.
   - **Type 2 (Check display status)**: For each check query, determine if the friend is online and if their relationship value is in the top `k` set.

3. **Efficiency**: By maintaining the top `k` values in a sorted list and using a set for quick lookups, we ensure efficient updates and queries. Sorting the list (of size up to 6) is manageable within the problem constraints.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    k = int(input[ptr])
    ptr += 1
    q = int(input[ptr])
    ptr += 1

    t = list(map(int, input[ptr:ptr + n]))
    ptr += n

    online = [False] * (n + 1)
    top_k = []
    top_set = set()

    for _ in range(q):
        typei = int(input[ptr])
        ptr += 1
        idi = int(input[ptr])
        ptr += 1

        if typei == 1:
            # Friend becomes online
            online[idi] = True
            ti = t[idi - 1]

            if len(top_k) < k:
                top_k.append(ti)
                top_k.sort(reverse=True)
                top_set.add(ti)
            else:
                if ti > top_k[-1]:
                    removed = top_k[-1]
                    top_k[-1] = ti
                    top_k.sort(reverse=True)
                    top_set.remove(removed)
                    top_set.add(ti)
        else:
            # Check display status
            if not online[idi]:
                print("NO")
            else:
                current_ti = t[idi - 1]
                if current_ti in top_set:
                    print("YES")
                else:
                    print("NO")

if __name__ == "__main__":
    main()
```

### Explanation
- **Online Tracking**: The boolean array `online` efficiently tracks which friends are online.
- **Top k Management**: The list `top_k` is kept sorted in descending order, ensuring the smallest of the top `k` values is at the end. The set `top_set` allows O(1) time complexity for checking if a value is in the top `k`.
- **Query Handling**: For each type 1 query, we update the top `k` values if necessary. For type 2 queries, we check the friend's online status and their presence in the top `k` set to determine the output.

This approach ensures that both updates and queries are handled efficiently, even for the upper constraint limits.
