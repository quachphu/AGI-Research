To solve this problem, we need to count the number of integers between 1 and N (inclusive) that contain exactly K non-zero digits when written in base ten. Given the constraints where N can be extremely large (up to 10^100), a brute force approach is infeasible. Instead, we use a dynamic programming (DP) approach known as digit DP to efficiently count the valid numbers.

### Approach
1. **Digit DP Concept**: This technique involves processing each digit of the number N one by one while keeping track of certain states such as the number of non-zero digits encountered, whether the current number being formed is still constrained by the digits of N, and whether leading zeros are still allowed.
2. **State Tracking**: The states we track are:
   - **Position (pos)**: The current digit position being processed.
   - **Count**: The number of non-zero digits encountered so far.
   - **Tight Constraint (tight)**: A flag indicating if the current number being formed is still constrained by the digits of N.
   - **Leading Zero (leading_zero)**: A flag indicating if the number formed so far consists only of leading zeros.
3. **Recursive DP with Memoization**: Using memoization, we avoid recalculating states by storing results of subproblems, which significantly improves efficiency.

            return 1 if (count == K and not leading_zero) else 0
        
        limit = int(N[pos]) if tight else 9
        total = 0
        
        for d in range(0, limit + 1):
            new_tight = tight and (d == limit)
            new_leading_zero = leading_zero and (d == 0)
            
            if leading_zero:
                if d == 0:
                    new_count = count
                else:
                    new_count = count + 1
                    new_leading_zero = False
            else:
                new_count = count + (1 if d != 0 else 0)
            
            if new_count > K:
                continue
            
            total += dp(pos + 1, new_count, new_tight, new_leading_zero)
        
        return total
    
    print(dp(0, 0, True, True))
