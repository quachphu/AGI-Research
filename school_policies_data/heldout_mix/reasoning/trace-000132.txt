To solve this problem, we need to format a string by collapsing consecutive vowels into a single instance, with exceptions for 'e' and 'o' when they appear exactly twice. The solution involves iterating through the string, grouping consecutive characters, and applying specific rules to each group.

### Approach
1. **Group Consecutive Characters**: Traverse the string and group consecutive same characters together.
2. **Check Vowel Groups**: For each group of vowels:
   - If the vowel is 'e' or 'o' and appears exactly twice, retain both instances.
   - Otherwise, collapse the group into a single instance of the vowel.
3. **Handle Non-Vowel Groups**: Directly append non-vowel groups to the result as they are.

### Solution Code
```python
n = int(input())
s = input().strip()

vowels = {'a', 'e', 'i', 'o', 'u', 'y'}
result = []

if s:
    current_char = s[0]
    count = 1

    for c in s[1:]:
        if c == current_char:
            count += 1
        else:
            # Process the current group
            if current_char in vowels:
                if current_char in ['e', 'o']:
                    if count == 2:
                        result.append(current_char * 2)
                    else:
                        result.append(current_char)
                else:
                    result.append(current_char)
            else:
                result.append(current_char * count)
            
            current_char = c
            count = 1

    # Process the last group
    if current_char in vowels:
        if current_char in ['e', 'o']:
            if count == 2:
                result.append(current_char * 2)
            else:
                result.append(current_char)
        else:
            result.append(current_char)
    else:
        result.append(current_char * count)

print(''.join(result))
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` and a string `s` of length `n`.
2. **Initialization**: We initialize a list `result` to build the output string and start processing the first character of `s`.
3. **Iterating Through String**: For each subsequent character in the string, we check if it matches the current group's character. If it does, we increment the count. If not, we process the current group and reset the current character and count.
4. **Processing Groups**:
   - **Vowel Check**: If the current group is a vowel, check if it is 'e' or 'o' and handle the exception for exactly two occurrences.
   - **Non-Vowel Handling**: Directly append non-vowel groups as they are.
5. **Final Group Processing**: After the loop, process the last group similarly.
6. **Output**: Join the processed groups into a single string and print the result.

This approach ensures efficient processing of the input string in linear time, making it suitable for large input sizes up to 100,000 characters.
