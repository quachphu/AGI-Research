To solve this problem, we need to determine if Vasya can turn on all the bulbs using the given buttons. Each button, when pressed, turns on a specific set of bulbs, and once a bulb is on, it remains on. The goal is to check if there exists a combination of button presses that results in all bulbs being turned on.

### Approach
The key insight is that the union of all bulbs covered by any subset of the buttons must include every bulb from 1 to m. If the union of all bulbs from all buttons covers all m bulbs, then pressing all buttons will turn on every bulb. If not, it is impossible to turn on all bulbs regardless of the buttons pressed.

Steps:
1. Read the number of buttons (n) and bulbs (m).
2. Collect all unique bulbs that can be turned on by any of the buttons.
3. Check if the collected bulbs cover all bulbs from 1 to m by verifying the size of the collected set equals m.

### Solution Code
```python
n, m = map(int, input().split())
bulbs = set()

for _ in range(n):
    parts = list(map(int, input().split()))
    if parts[0] > 0:
        bulbs.update(parts[1:])

print("YES" if len(bulbs) == m else "NO")
```

### Explanation
1. **Reading Input:** The first line of input gives the number of buttons (n) and bulbs (m). Each subsequent line describes the bulbs controlled by a button.
2. **Collecting Bulbs:** Using a set, we collect all unique bulbs that can be turned on by any button. This set automatically handles duplicates and ensures each bulb is only counted once.
3. **Checking Coverage:** After processing all buttons, if the size of the set equals m, it means all bulbs from 1 to m are covered, so we print "YES". Otherwise, we print "NO".

This approach efficiently checks if all bulbs can be turned on using a union operation on sets, ensuring optimal performance even for the upper constraint limits.
