To solve this problem, we need to determine the number of Hits and Blows for each dataset in the Hit and Blow game. A Hit occurs when a number in the guessed sequence is in the correct position, while a Blow occurs when a number exists in the guessed sequence but is in the wrong position.

### Approach
1. **Reading Input:** The input consists of multiple datasets, each containing two lines. The first line is the sequence imagined by player A, and the second line is the sequence guessed by player B.
2. **Calculate Hits:** Compare each element in the guessed sequence with the corresponding element in the imagined sequence. Count how many elements are in the same position (Hits).
3. **Calculate Common Elements:** Determine the number of common elements between the two sequences using set intersection.
4. **Calculate Blows:** Subtract the number of Hits from the total common elements to get the number of Blows. This is because Blows are the numbers that are present in both sequences but not in the correct positions.

### Solution Code
```python
def solve():
    import sys
    lines = sys.stdin.read().splitlines()
    for i in range(0, len(lines), 2):
        a = list(map(int, lines[i].split()))
        b = list(map(int, lines[i+1].split()))
        hit = sum(x == y for x, y in zip(a, b))
        common = len(set(a) & set(b))
        blow = common - hit
        print(hit, blow)

solve()
```

### Explanation
1. **Reading Input:** The input is read all at once and split into lines. Each pair of lines represents a dataset.
2. **Hits Calculation:** Using a generator expression with `zip`, we compare each corresponding element of the two sequences. The sum of these comparisons gives the number of Hits.
3. **Common Elements:** Convert both sequences into sets and find their intersection. The size of this intersection gives the total number of common elements.
4. **Blows Calculation:** Subtract the number of Hits from the total common elements to get the number of Blows. This works because Hits are already counted as correct positions, so the remaining common elements must be in incorrect positions.

This approach efficiently computes the required Hits and Blows for each dataset using set operations and list comprehensions, ensuring optimal performance even for the maximum input constraints.
