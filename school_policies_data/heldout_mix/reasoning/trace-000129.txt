def fwht(a):
    """In-place Fast Walsh–Hadamard Transform of array a."""
    h = 1
    while h < len(a):
        for i in range(0, len(a), h * 2):
            for j in range(i, i + h):
                x = a[j]
                y = a[j + h]
                a[j] = x + y
                a[j + h] = x - y
        h *= 2

For the inverse FWHT, we can either apply the same transform and then divide by the size (since the inverse is the same as the forward transform divided by the size for the XOR convolution).

To solve this problem, we need to minimize the number of cells with the value 1 after applying a series of row and column flips. Each flip inverts all values in a row or column. The optimal strategy involves determining the best set of row flips followed by column flips to achieve the minimum number of 1s.

### Approach
1. **Problem Analysis**: 
   - Each cell can be flipped by row or column operations.
   - The goal is to minimize the number of 1s after any number of row and column flips.
   - The key insight is that after flipping rows, each column can be independently flipped to minimize the number of 1s in that column.

2. **Intuition**:
   - For each possible row flip combination, determine the optimal column flips.
   - Use the Fast Walsh-Hadamard Transform (FWHT) to efficiently compute the minimum number of 1s for all possible row flip combinations.

3. **Algorithm**:
   - **Frequency Array**: Track the frequency of each column configuration.
   - **FWHT**: Use FWHT to compute the convolution of the frequency array with a function representing the minimal contribution of each column configuration.
   - **Inverse FWHT**: Transform back to get the result for each possible row flip combination and find the minimum value.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n, m = map(int, sys.stdin.readline().split())
    rows = [sys.stdin.readline().strip() for _ in range(n)]
    
    # Build frequency dictionary
    freq = defaultdict(int)
    for j in range(m):
        bitmask = 0
        for i in range(n):
            if rows[i][j] == '1':
                bitmask |= 1 << i
        freq[bitmask] += 1
    
    size = 1 << n
    # Initialize frequency array
    freq_array = [0] * size
    for key, count in freq.items():
        freq_array[key] = count
    
    # Initialize f0 array
    f0 = [0] * size
    for s in range(size):
        cnt = bin(s).count('1')
        f0[s] = min(cnt, n - cnt)
    
    # Define FWHT function
    def fwht(a):
        h = 1
        while h < len(a):
            for i in range(0, len(a), h * 2):
                for j in range(i, i + h):
                    x = a[j]
                    y = a[j + h]
                    a[j] = x + y
                    a[j + h] = x - y
            h *= 2
    
    # Compute FWHT of freq_array
    a = freq_array.copy()
    fwht(a)
    
    # Compute FWHT of f0
    b = f0.copy()
    fwht(b)
    
    # Element-wise multiplication
    c = [a[i] * b[i] for i in range(size)]
    
    # Inverse FWHT
    fwht(c)
    
    # Divide by size and find minimal
    minimal = min( val // size for val in c )
    
    print(minimal)

if __name__ == "__main__":
    main()
```
