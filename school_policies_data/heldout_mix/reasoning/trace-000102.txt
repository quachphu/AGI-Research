To solve this problem, we need to determine the remaining recordable time on a videotape based on the current counter value, considering both standard and triple recording modes. The tape's total length is 120 minutes (7200 seconds) in standard mode, and the remaining time in triple mode is three times that of the remaining physical tape.

### Approach
1. **Input Handling**: Read multiple datasets until a termination line (-1 -1 -1) is encountered.
2. **Convert Time to Seconds**: Convert the current counter time (given in hours, minutes, and seconds) into total seconds to determine how much of the tape has been used.
3. **Calculate Remaining Physical Tape**: Subtract the used time from the total tape length (7200 seconds) to get the remaining physical tape in seconds.
4. **Compute Remaining Time in Both Modes**:
   - **Standard Mode**: Directly use the remaining physical tape in seconds.
   - **Triple Mode**: Multiply the remaining physical tape by 3.
5. **Formatting**: Convert the remaining time in both modes from seconds back to hours, minutes, and seconds, ensuring each component is formatted as two digits.

### Solution Code
```python
def main():
    import sys

    def format_time(total_seconds):
        hours = total_seconds // 3600
        remaining = total_seconds % 3600
        minutes = remaining // 60
        seconds = remaining % 60
        return f"{hours:02d}:{minutes:02d}:{seconds:02d}"

    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        parts = list(map(int, line.split()))
        if len(parts) < 3:
            continue
        T, H, S = parts[:3]
        if T == -1 and H == -1 and S == -1:
            break
        total_used = T * 3600 + H * 60 + S
        remaining_physical = 7200 - total_used
        standard = remaining_physical
        triple = remaining_physical * 3
        print(format_time(standard))
        print(format_time(triple))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads input lines until it encounters the termination line (-1 -1 -1). Each line is split into hours (T), minutes (H), and seconds (S).
2. **Conversion to Seconds**: The input time is converted into total seconds to facilitate arithmetic operations.
3. **Remaining Physical Tape Calculation**: The remaining physical tape is computed by subtracting the used time from the total tape length (7200 seconds).
4. **Time Conversion for Modes**: 
   - **Standard Mode**: The remaining physical tape in seconds is directly converted to hours, minutes, and seconds.
   - **Triple Mode**: The remaining physical tape is tripled before converting to hours, minutes, and seconds.
5. **Formatting**: The `format_time` function ensures that each component (hours, minutes, seconds) is formatted as a two-digit number, adding leading zeros where necessary.

This approach efficiently processes each dataset and converts the remaining time into the required format, ensuring accurate results for both recording modes.
