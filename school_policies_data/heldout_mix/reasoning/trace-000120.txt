To solve this problem, we need to determine if the sequence of (plays, clears) pairs recorded by Polycarp is valid based on the game's rules. Each play increases the play count, and each clear increases both the play and clear counts. We need to check the validity of these sequences according to the constraints provided.

### Approach
1. **Check Validity of Each Pair**: For each recorded pair (p_i, c_i), ensure that the number of clears (c_i) does not exceed the number of plays (p_i).
2. **Non-Decreasing Order**: Ensure that both the play and clear counts are non-decreasing over time.
3. **Increment Validity**: For each consecutive pair, check that the increase in clears does not exceed the increase in plays. This is because each clear contributes to both counts, but plays can increase without clears.

### Solution Code
```python
import sys

def check_validity():
    T = int(sys.stdin.readline())
    for _ in range(T):
        n = int(sys.stdin.readline())
        stats = []
        valid = True
        for _ in range(n):
            p, c = map(int, sys.stdin.readline().split())
            stats.append((p, c))
            if c > p:
                valid = False  # Mark invalid but continue reading input
        
        # Check each c <= p
        if not valid:
            print("NO")
            continue
        
        # Check non-decreasing p and c
        for i in range(1, n):
            prev_p, prev_c = stats[i-1]
            curr_p, curr_c = stats[i]
            if curr_p < prev_p or curr_c < prev_c:
                valid = False
                break
        
        if not valid:
            print("NO")
            continue
        
        # Check delta_c <= delta_p for consecutive entries
        for i in range(1, n):
            prev_p, prev_c = stats[i-1]
            curr_p, curr_c = stats[i]
            delta_p = curr_p - prev_p
            delta_c = curr_c - prev_c
            if delta_c > delta_p:
                valid = False
                break
        
        print("YES" if valid else "NO")

check_validity()
```

### Explanation
1. **Reading Input**: The function reads multiple test cases. For each test case, it reads the number of recorded moments and the pairs of plays and clears.
2. **Initial Validity Check**: Each pair is checked to ensure clears do not exceed plays. If any pair fails, the test case is immediately invalid.
3. **Non-Decreasing Check**: The sequence is checked to ensure that both plays and clears never decrease.
4. **Increment Check**: For each consecutive pair, the increase in clears must not exceed the increase in plays, as each clear contributes to both counts but plays can increase independently.

This approach ensures all constraints are efficiently checked, leading to a correct determination of the validity of the recorded sequences.
