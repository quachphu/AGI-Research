To solve this problem, we need to determine the first occurrence of a multiple of a prime number \( n \) in an infinite arithmetic sequence defined by the initial term \( a \) and common difference \( d \). The sequence starts at index 0. If no such multiple exists, we return -1.

### Approach
1. **Case when \( d = 0 \)**:
   - If \( a \) is 0, every term in the sequence is 0, so the answer is 0.
   - If \( a \) is non-zero, check if \( a \) is a multiple of \( n \). If yes, the answer is 0; otherwise, return -1.

2. **Case when \( d \neq 0 \)**:
   - **Check if \( d \) is a multiple of \( n \)**:
     - If \( a \) is a multiple of \( n \), the answer is 0.
     - Otherwise, return -1.
   - **When \( d \) is not a multiple of \( n \)**:
     - Compute the remainder \( R \) of \(-a\) modulo \( n \).
     - Use Fermat's Little Theorem to compute the modular inverse of \( d \) modulo \( n \) since \( n \) is prime.
     - Calculate the smallest non-negative integer \( k \) using the modular inverse and \( R \).

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        a = int(input[ptr])
        d = int(input[ptr+1])
        ptr +=2
        n = int(input[ptr])
        ptr +=1
        
        if d == 0:
            if a % n == 0:
                print(0)
            else:
                print(-1)
        else:
            if d % n == 0:
                if a % n == 0:
                    print(0)
                else:
                    print(-1)
            else:
                R = (-a) % n
                inv_d = pow(d, n-2, n)
                k = (R * inv_d) % n
                print(k)
                
if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read all at once for efficiency, especially given the large constraints.
- **Handling \( d = 0 \)**: Directly check if \( a \) is a multiple of \( n \).
- **Handling \( d \neq 0 \)**:
  - If \( d \) is a multiple of \( n \), check if \( a \) is a multiple of \( n \).
  - For other cases, compute the necessary remainder and modular inverse to find the smallest index using modular arithmetic.

This approach efficiently handles large numbers and leverages modular arithmetic properties to ensure correctness and performance.
