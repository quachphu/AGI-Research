To solve this problem, we need to simulate the process of frogs eating mosquitoes that land on a coordinate axis. Each frog can eat a mosquito if it lands within the frog's reach, and if multiple frogs can reach the same mosquito, the leftmost frog (smallest position) will eat it. After eating a mosquito, the frog's tongue length increases, which might allow it to eat more mosquitoes. The goal is to determine how many mosquitoes each frog eats and their final tongue lengths.

### Approach
1. **Sort Frogs by Position**: First, we sort the frogs based on their positions on the coordinate axis. This helps efficiently find the leftmost frog that can reach a mosquito.
2. **Track Available Mosquitoes**: Maintain a sorted list of mosquitoes that have landed but haven't been eaten yet. This allows efficient range queries to check which mosquitoes can be eaten when a frog's tongue length increases.
3. **Binary Search for Eligible Frogs**: For each mosquito, use binary search to find the leftmost frog that can reach it. If no frog can eat the mosquito immediately, it is added to the available list.
4. **Process Available Mosquitoes on Reach Increase**: When a frog eats a mosquito and its tongue length increases, check the available mosquitoes in the new reach range and process them similarly.

import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n, m = int(input[ptr]), int(input[ptr+1])
    ptr += 2

    frogs = []
    for idx in range(n):
        x = int(input[ptr])
        t = int(input[ptr+1])
        ptr += 2
        frogs.append((x, t, idx))  # Store original index

    # Sort frogs by their x coordinate
    frogs.sort()
    x_list = [f[0] for f in frogs]
    t_list = [f[1] for f in frogs]
    original_indices = [f[2] for f in frogs]

    # To restore the original order when outputting
    output_data = [[0, 0] for _ in range(n)]  # [count, length]

    available = []

    for _ in range(m):
        pj = int(input[ptr])
        bj = int(input[ptr + 1])
        ptr += 2

        queue = [(pj, bj)]

        while queue:
            current_p, current_b = queue.pop(0)

            # Find the largest frog x <= current_p
            k = bisect.bisect_right(x_list, current_p) - 1
            if k < 0:
                # No frog can eat it, add to available
                bisect.insort(available, (current_p, current_b))
                continue

            # Find the leftmost frog in 0..k that can reach current_p
            found = False
            for i in range(k + 1):
                if x_list[i] + t_list[i] >= current_p:
                    # This frog can eat it
                    output_data[i][0] += 1
                    old_reach = x_list[i] + t_list[i]
                    t_list[i] += current_b
                    new_reach = x_list[i] + t_list[i]
                    output_data[i][1] = t_list[i]

                    # Find all available mosquitoes in (old_reach, new_reach]
                    left = bisect.bisect_right(available, (old_reach, float('inf')))
                    right = bisect.bisect_right(available, (new_reach, float('inf')))
                    extracted = available[left:right]
                    del available[left:right]

                    # Add to queue to reprocess these mosquitoes
                    queue.extend(extracted)
                    found = True
                    break

            if not found:
                bisect.insort(available, (current_p, current_b))

    # After processing all mosquitoes, fill in the counts and lengths for frogs not eating any
    for i in range(n):
        if output_data[i][1] == 0:
            output_data[i][1] = t_list[i]

    # Prepare the output in the original order
    result = [0] * n
    for i in range(n):
        orig_idx = original_indices[i]
        result[orig_idx] = (output_data[i][0], output_data[i][1])

    for count, length in result:
        print(count, length)
