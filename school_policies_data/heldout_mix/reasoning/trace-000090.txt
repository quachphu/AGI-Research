To solve this problem, we need to find the most frequent two-gram (a substring of two consecutive characters) in a given string. If there are multiple two-grams with the same maximum frequency, we return the one that appears first in the string.

### Approach
1. **Read Input**: Read the length of the string and the string itself.
2. **Count Two-grams**: Iterate through the string, generate each possible two-gram, and count their occurrences using a dictionary.
3. **Find Maximum Frequency**: Determine the highest count of any two-gram.
4. **Identify First Occurrence**: Iterate through the dictionary in the order of insertion (which maintains the order of first occurrence) to find the first two-gram with the maximum frequency.

### Solution Code
```python
n = int(input())
s = input().strip()

counts = {}
for i in range(len(s) - 1):
    two_gram = s[i] + s[i + 1]
    counts[two_gram] = counts.get(two_gram, 0) + 1

max_count = max(counts.values())
for key, value in counts.items():
    if value == max_count:
        print(key)
        break
```

### Explanation
1. **Reading Input**: The code reads the integer `n` (length of the string) and the string `s`.
2. **Counting Two-grams**: By iterating through each character in the string (except the last one), the code generates each two-gram and updates its count in a dictionary. The `get` method is used to handle new two-grams by initializing their count to 0 if they haven't been seen before.
3. **Finding Maximum Frequency**: The maximum value from the dictionary's values is computed to determine the highest count of any two-gram.
4. **Identifying the Result**: The dictionary is iterated in insertion order (maintained by Python 3.7+), and the first two-gram with the maximum count is printed. This ensures that in case of ties, the first occurring two-gram in the string is selected.

This approach efficiently counts the occurrences and ensures the correct result is found in linear time relative to the length of the string, making it optimal for the problem constraints.
