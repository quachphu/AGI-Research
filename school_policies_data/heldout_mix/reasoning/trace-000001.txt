To solve this problem, we need to compute the Greatest Common Divisor (GCD) of two numbers, A and B, where A is a small integer (up to 40000) and B can be a very large number with up to 250 digits. The challenge is to efficiently compute the GCD given the constraints on the size of B.

### Approach
1. **Input Handling**: Read the number of test cases and each pair of numbers (A, B). A is read as an integer, while B is read as a string to handle its large size.
2. **Special Case for Zero**: If A is zero, the GCD is simply B (if B is non-zero) or zero (if B is zero).
3. **Modulo Operation for Large B**: For non-zero A, compute B modulo A efficiently by processing each digit of B iteratively. This avoids converting the entire large number into an integer directly.
4. **GCD Calculation**: Use the Euclidean algorithm to compute the GCD of A and the result of B modulo A.

### Solution Code
```python
import math
import sys

def main():
    n = int(sys.stdin.readline())
    for _ in range(n):
        a_str, b_str = sys.stdin.readline().split()
        A = int(a_str)
        B = b_str
        if A == 0:
            # Check if B is all zeros
            if all(c == '0' for c in B):
                print(0)
            else:
                print(B.lstrip('0') or '0')  # Handle cases like '0000'
        else:
            mod = 0
            for c in B:
                mod = (mod * 10 + int(c)) % A
            print(math.gcd(A, mod))

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read using `sys.stdin` for efficiency, especially given the potential size of the input.
- **Handling A = 0**: If A is zero, the GCD is determined by B. If B is also zero, the result is zero. Otherwise, B is printed as the result after stripping leading zeros.
- **Efficient Modulo Calculation**: For non-zero A, the modulo of B with respect to A is computed digit by digit. This avoids handling very large integers directly and ensures the computation remains efficient.
- **GCD Calculation**: The built-in `math.gcd` function is used to compute the GCD of A and the computed modulo value, leveraging Python's optimized implementation of the Euclidean algorithm.

This approach ensures that even very large numbers are handled efficiently, making the solution both robust and performant.
