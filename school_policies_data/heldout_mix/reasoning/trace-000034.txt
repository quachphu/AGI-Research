To solve this problem, we need to merge two sorted arrays (sorted in non-increasing order) into a single sorted array, also in non-increasing order. This can be efficiently achieved using a two-pointer technique similar to the merge step in the merge sort algorithm.

### Approach
1. **Reading Input Efficiently**: Read all input at once and split it into tokens for efficient processing, especially given the constraints.
2. **Two-Pointer Technique**: Use two pointers to traverse both arrays simultaneously. Compare elements from both arrays and append the larger element to the result list. Move the pointer of the array from which the element was taken.
3. **Handle Remaining Elements**: Once one of the arrays is exhausted, append the remaining elements of the other array directly to the result list. This works because the remaining elements are already sorted in non-increasing order.

### Solution Code
```python
def merge_arrays():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        M = int(input[ptr + 1])
        ptr += 2
        a = list(map(int, input[ptr:ptr + N]))
        ptr += N
        b = list(map(int, input[ptr:ptr + M]))
        ptr += M
        i = j = 0
        merged = []
        while i < N and j < M:
            if a[i] >= b[j]:
                merged.append(a[i])
                i += 1
            else:
                merged.append(b[j])
                j += 1
        if i < N:
            merged.extend(a[i:])
        else:
            merged.extend(b[j:])
        print(' '.join(map(str, merged)))

merge_arrays()
```

### Explanation
1. **Reading Input**: The entire input is read at once and split into tokens. This approach is efficient for large inputs as it minimizes I/O operations.
2. **Two-Pointer Technique**: We initialize two pointers, `i` and `j`, to traverse the first and second arrays respectively. We compare elements at these pointers and append the larger element to the result list, moving the respective pointer forward.
3. **Appending Remaining Elements**: After one of the arrays is exhausted, the remaining elements of the other array are appended directly. This is valid because the remaining elements are already sorted in non-increasing order.

This approach ensures that we merge the two arrays in linear time, O(N + M), making it efficient even for large input sizes.
