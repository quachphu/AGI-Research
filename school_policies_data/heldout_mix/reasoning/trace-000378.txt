To solve this problem, we need to determine if we can direct the edges of a given undirected graph such that the resulting directed graph does not contain any paths of length two or greater. The solution involves checking if the graph is bipartite and then directing the edges accordingly.

### Approach
1. **Check Bipartiteness**: The graph must be bipartite to be able to direct the edges such that no paths of length two exist. A bipartite graph can be colored using two colors such that no two adjacent nodes share the same color.
2. **Direct Edges**: If the graph is bipartite, direct all edges from nodes of one color to nodes of the other color. Specifically, we direct edges from nodes colored `1` to nodes colored `0`.

### Solution Code
```python
import sys
from collections import deque

def main():
    n, m = map(int, sys.stdin.readline().split())
    edges = []
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v = map(int, sys.stdin.readline().split())
        edges.append((u, v))
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * (n + 1)
    is_bipartite = True
    q = deque()
    color[1] = 0
    q.append(1)
    
    while q and is_bipartite:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                is_bipartite = False
                break
    
    if not is_bipartite:
        print("NO")
    else:
        res = []
        for u, v in edges:
            if color[u] == 1 and color[v] == 0:
                res.append('0')
            else:
                res.append('1')
        print("YES")
        print(''.join(res))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Bipartiteness Check**: Using BFS, we attempt to color the graph with two colors. If we find any two adjacent nodes with the same color, the graph is not bipartite.
2. **Edge Direction**: If the graph is bipartite, we direct all edges from nodes colored `1` to nodes colored `0`. This ensures that no node will have both incoming and outgoing edges, thus preventing paths of length two. The direction of each edge is determined by the colors of its endpoints, and the result is output as a binary string.

This approach efficiently checks for bipartiteness and directs the edges in linear time relative to the number of nodes and edges, making it suitable for large graphs as specified in the problem constraints.
