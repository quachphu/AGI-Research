To solve this problem, we need to determine if there exists a sequence of integers that satisfies given bitwise OR and AND conditions between consecutive elements. If such a sequence exists, we must construct it.

### Approach
1. **Initial Check**: For each pair of elements from the given sequences `a` and `b`, check if the bitwise AND of `a_i` and `b_i` equals `b_i`. If this condition fails for any pair, output "NO" immediately.
2. **Generate Possible Sequences**: If the initial check passes, attempt to construct a valid sequence starting with each possible initial value (0, 1, 2, 3). For each starting value, iteratively compute the next element using the formula derived from the given OR and AND conditions. If a valid sequence is found, print it; otherwise, continue checking other starting values.
3. **Validation**: For each candidate sequence, ensure that each consecutive pair satisfies the OR and AND conditions specified by `a` and `b`.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

# Check if a_i & b_i equals b_i for all i
for ai, bi in zip(a, b):
    if (ai & bi) != bi:
        print("NO")
        exit()

# Try all possible starting values
for start in [0, 1, 2, 3]:
    current = start
    sequence = [current]
    valid = True
    for i in range(n-1):
        ai = a[i]
        bi = b[i]
        next_val = ai + bi - current
        if not (0 <= next_val <= 3):
            valid = False
            break
        if (current | next_val) != ai or (current & next_val) != bi:
            valid = False
            break
        current = next_val
        sequence.append(current)
    if valid:
        print("YES")
        print(' '.join(map(str, sequence)))
        exit()

print("NO")
```

### Explanation
1. **Initial Check**: The first loop ensures that each pair `(a_i, b_i)` is valid by checking if `a_i & b_i` equals `b_i`. This is necessary because the AND result cannot have bits set that are not present in the OR result.
2. **Generating Sequences**: For each possible starting value (0 to 3), we attempt to build a valid sequence. The next element in the sequence is calculated using the formula `next_val = a_i + b_i - current`, derived from the properties of bitwise OR and AND operations. This formula ensures that the sum of consecutive elements matches the sum of their OR and AND results.
3. **Validation**: For each candidate sequence, we check if the computed next value is within the valid range (0-3) and if it satisfies the OR and AND conditions with the current element. If all checks pass, the sequence is printed.

This approach efficiently checks all possible starting values and constructs the sequence in linear time, making it suitable for large input sizes up to 100,000 elements.
