To solve this problem efficiently, we need to determine how many strings within a given range contain a specific substring. Given the constraints, a naive approach would be too slow, so we use a preprocessing step to handle queries efficiently.

### Approach
1. **Preprocessing**: 
   - For each string, generate all possible substrings of length up to 10 and store the indices of strings containing each substring in a dictionary.
   - Each entry in the dictionary maps a substring to a list of string indices (1-based) that contain the substring.
   - Sort the list of indices for each substring to enable efficient range queries using binary search.

2. **Query Handling**:
   - For each query, check if the substring length exceeds 10. If so, the result is immediately 0.
   - If the substring exists in the preprocessed dictionary, use binary search to count how many indices fall within the given range [L, R].

### Solution Code
```python
import sys
import bisect

def main():
    n = int(sys.stdin.readline())
    substring_map = {}

    for idx in range(1, n + 1):
        s = sys.stdin.readline().strip()
        l = len(s)
        substrs = set()
        for i in range(l):
            max_j = min(i + 10, l)  # j ranges from i to i+9 (if possible), up to len(s)-1
            for j in range(i, max_j):
                substr = s[i:j+1]
                substrs.add(substr)
        for substr in substrs:
            if substr not in substring_map:
                substring_map[substr] = []
            substring_map[substr].append(idx)
    
    # Sort each list in the substring_map
    for substr in substring_map:
        substring_map[substr].sort()
    
    q = int(sys.stdin.readline())
    for _ in range(q):
        line = sys.stdin.readline().split()
        if not line:
            continue  # handle empty lines if any
        L = int(line[0])
        R = int(line[1])
        if len(line) < 3:
            substr = ''
        else:
            substr = ' '.join(line[2:])
        if len(substr) > 10:
            print(0)
            continue
        if substr not in substring_map:
            print(0)
            continue
        lst = substring_map[substr]
        left = bisect.bisect_left(lst, L)
        right_idx = bisect.bisect_right(lst, R)
        print(right_idx - left)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Preprocessing**:
   - For each string, generate all possible substrings of lengths 1 to 10. Use a set to collect unique substrings to avoid duplicate entries.
   - Store each string's index in a dictionary where keys are substrings and values are lists of indices.

2. **Query Handling**:
   - For each query, check the substring length. If it exceeds 10, output 0 immediately.
   - Use binary search to efficiently count the indices within the range [L, R] using `bisect_left` and `bisect_right` from the `bisect` module.

This approach ensures that each query is answered in O(log k) time, where k is the number of strings containing the substring, making it efficient even for large input sizes.
