To solve this problem, we need to generate an invite list from a list of names provided by Puchi, ensuring there are no duplicates and the names are sorted lexicographically. 

### Approach
1. **Reading Input Efficiently**: Given the constraints, we need to read input efficiently. Using `sys.stdin.read()` allows us to read all input at once and split it into lines, which is faster than reading line by line using `input()`.
2. **Removing Duplicates**: We use a set to store the names as sets automatically handle duplicates.
3. **Sorting the Names**: Once all names for a test case are read, we convert the set to a sorted list to get the names in lexicographical order.
4. **Output the Result**: Finally, we print each name from the sorted list on a new line.

### Solution Code
```python
import sys

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    T = int(data[idx])
    idx += 1
    for _ in range(T):
        N = int(data[idx])
        idx += 1
        names = set()
        for _ in range(N):
            name = data[idx]
            idx += 1
            names.add(name)
        sorted_names = sorted(names)
        for name in sorted_names:
            print(name)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into lines for efficient processing.
2. **Handling Test Cases**: We first read the number of test cases. For each test case, we read the number of names and then each subsequent name.
3. **Using a Set**: Names are added to a set to automatically remove duplicates.
4. **Sorting and Printing**: The set is converted to a sorted list, which is then printed line by line.

This approach ensures that we efficiently handle large inputs, remove duplicates using a set, and sort the names lexicographically to meet the problem requirements.
