To solve this problem, we need to reconstruct the original array from a given GCD table. The GCD table is provided as a list of elements in an arbitrary order. The key insight is that the original array elements are the diagonal elements of the GCD table. By leveraging the properties of GCD and using a greedy approach, we can efficiently reconstruct the original array.

### Approach
1. **Sort the Elements**: First, we sort the elements of the GCD table in descending order. This helps in identifying the largest elements first, which are crucial for forming the original array.
2. **Frequency Map**: We maintain a frequency map to keep track of how many times each element appears in the GCD table.
3. **Greedy Selection**: We iteratively select the largest remaining element and add it to the result array. For each new element added, we adjust the frequency map by subtracting the GCD values formed with all previously added elements.

### Solution Code
```python
import sys
import math
from collections import defaultdict

def main():
    n = int(sys.stdin.readline())
    g = list(map(int, sys.stdin.readline().split()))
    g.sort(reverse=True)
    freq = defaultdict(int)
    for num in g:
        freq[num] += 1
    res = []
    for num in g:
        if freq[num] <= 0:
            continue
        # Add the current number to the result
        freq[num] -= 1
        res.append(num)
        # Subtract GCDs with all previous elements
        for existing in res[:-1]:
            gcd_val = math.gcd(existing, num)
            freq[gcd_val] -= 2
        # Check if we have enough elements
        if len(res) == n:
            break
    print(' '.join(map(str, res)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Sorting and Frequency Map**: The elements are sorted in descending order to prioritize larger elements, which are more likely to be part of the original array. The frequency map helps track how many times each element appears in the input.
2. **Greedy Selection**: By iterating through the sorted elements, we add each element to the result array if it still has a positive count in the frequency map. This ensures we only include elements that are part of the original array.
3. **Adjusting Frequencies**: For each new element added to the result array, we adjust the frequency map by subtracting the GCD values formed with all previously added elements. This accounts for the pairs (i, j) and (j, i) in the GCD table, ensuring the correct elements are used.

This approach efficiently reconstructs the original array by leveraging the properties of GCD and using a greedy strategy to select elements in descending order, ensuring correctness and optimal performance.
