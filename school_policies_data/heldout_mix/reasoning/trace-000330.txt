To solve this problem, we need to determine if a given text message could have been generated by encoding a specific set of words using a predefined pattern. The encoding involves inserting a heart symbol (<3) before each word and after the last word, and then inserting random characters anywhere in the message. Our task is to check if the received message could be a valid encoded message according to these rules.

### Approach
1. **Construct the Expected Sequence**: The valid encoded message should start with a heart (<3) before each word and end with a heart after the last word. For example, for words "i", "love", "you", the expected sequence is `<3i<3love<3you<3`.
2. **Check Subsequence**: The received message must contain the expected sequence as a subsequence. This means all characters of the expected sequence must appear in the same order in the received message, but not necessarily consecutively. We can check this by iterating through both the received message and the expected sequence simultaneously.

### Solution Code
```python
n = int(input())
words = [input().strip() for _ in range(n)]
message = input().strip()

expected = []
for word in words:
    expected.append('<')
    expected.append('3')
    expected.extend(word)
expected.append('<')
expected.append('3')

e_ptr = 0
m_ptr = 0
len_expected = len(expected)
len_message = len(message)

while e_ptr < len_expected and m_ptr < len_message:
    if message[m_ptr] == expected[e_ptr]:
        e_ptr += 1
    m_ptr += 1

print("yes" if e_ptr == len_expected else "no")
```

### Explanation
1. **Reading Input**: We first read the number of words and the words themselves, followed by the received message.
2. **Constructing the Expected Sequence**: We build the expected sequence by iterating through each word and appending `<3` before each word. After processing all words, we append a final `<3`.
3. **Subsequence Check**: Using two pointers, we check if the expected sequence is a subsequence of the received message. One pointer (`e_ptr`) iterates through the expected sequence, and the other (`m_ptr`) iterates through the message. If all characters of the expected sequence are found in order, the message is valid.

This approach efficiently checks the validity of the message in linear time relative to the length of the message, making it suitable for large input sizes.
