To solve this problem, we need to determine the minimal number of bottles required to store all remaining soda and the minimal time required to pour the soda into those bottles. The solution involves two main steps: finding the minimal number of bottles and calculating the minimal pouring time.

### Approach

1. **Determine the Minimal Number of Bottles (k):**
   - Calculate the total amount of soda.
   - Sort the bottle volumes in descending order.
   - Find the smallest number of bottles (k) such that the sum of their volumes is at least the total soda amount.

2. **Calculate the Minimal Pouring Time (t):**
   - Use dynamic programming to determine the maximum sum of soda amounts that can be stored in k bottles whose total volume is at least the total soda amount.
   - The minimal pouring time is derived from the difference between the total soda and the maximum sum of soda amounts in the selected bottles.

### Solution Code

```python
n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))
total_a = sum(a)

# Find the minimal k
sorted_b = sorted(b, reverse=True)
sum_so_far = 0
k = 0
for i in range(n):
    sum_so_far += sorted_b[i]
    if sum_so_far >= total_a:
        k = i + 1
        break

# Calculate the minimal time using dynamic programming
sum_total_b = sum(b)
INF = float('-inf')
dp = [[INF] * (sum_total_b + 1) for _ in range(k + 1)]
dp[0][0] = 0

for ai, bi in zip(a, b):
    for c in range(k, 0, -1):
        for s in range(sum_total_b, -1, -1):
            if dp[c-1][s] != INF:
                new_s = s + bi
                if new_s > sum_total_b:
                    continue
                if dp[c][new_s] < dp[c-1][s] + ai:
                    dp[c][new_s] = dp[c-1][s] + ai

max_a_sum = 0
for s in range(total_a, sum_total_b + 1):
    if dp[k][s] > max_a_sum:
        max_a_sum = dp[k][s]

t = total_a - max_a_sum

print(k, t)
```

### Explanation

1. **Finding the Minimal Number of Bottles (k):**
   - The bottles are sorted by their volume in descending order to maximize the total volume quickly.
   - We accumulate the volumes starting from the largest until the sum is at least the total soda amount. The count of these bottles gives us k.

2. **Dynamic Programming to Find Maximum Soda Retention:**
   - We use a 2D DP array where `dp[c][s]` represents the maximum soda amount that can be stored using `c` bottles with a total volume `s`.
   - By iterating over each bottle and updating the DP array in reverse order (to avoid reusing the same bottle), we determine the maximum soda amount that can be retained in k bottles with a sufficient total volume.
   - The minimal time is calculated as the difference between the total soda and the maximum retained soda amount in the selected k bottles.

This approach efficiently combines sorting and dynamic programming to solve the problem within the constraints, ensuring optimal performance and correctness.
