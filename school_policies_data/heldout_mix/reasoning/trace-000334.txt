To solve this problem, we need to determine the expected number of songs recognized within a given time limit T. Each song has a recognizability probability and a specific time at which the chorus starts, ensuring recognition. The challenge is to model the probabilistic recognition and time consumption efficiently.

### Approach
1. **Dynamic Programming (DP) Setup**: Use a DP array where `dp[t]` represents the probability that exactly `t` seconds have been used after processing some number of songs.
2. **Geometric Series Handling**: For each song, compute the probability of recognizing it at each second using a geometric series to avoid redundant calculations.
3. **Efficient Transitions**: For each song and each possible remaining time, compute the contribution to the expected number of recognized songs and update the DP array accordingly.

### Solution Code
```python

    import sys
    input = sys.stdin.read().split()
    idx = 0
    n, T = int(input[idx]), int(input[idx+1])
    idx +=2
    songs = []
    for _ in range(n):
        p, t = int(input[idx]), int(input[idx+1])
        idx +=2
        songs.append((p, t))
    
    dp = [0.0] * (T + 1)
    dp[0] = 1.0
    expected = 0.0
    
    for (p, ti) in songs:
        next_dp = [0.0] * (T + 1)
        for t_prev in range(T + 1):
            if dp[t_prev] == 0:
                continue
            rem = T - t_prev
            if rem < 1:
                next_dp[t_prev] += dp[t_prev]
                continue
            s_max = min(ti, rem)
            if p == 100:
                prob = 1.0
                expected += dp[t_prev] * prob
                s = 1
                new_t = t_prev + s
                if new_t <= T:
                    next_dp[new_t] += dp[t_prev]
            else:
                r = (100 - p) / 100.0
                if s_max < ti:
                    prob_recognized = 1.0 - (r ** s_max)
                    expected += dp[t_prev] * prob_recognized
                    for s in range(1, s_max + 1):
                        prob = (r ** (s - 1)) * (p / 100.0)
                        new_t = t_prev + s
                        if new_t <= T:
                            next_dp[new_t] += dp[t_prev] * prob
                else:
                    expected += dp[t_prev] * 1.0
                    for s in range(1, ti):
                        prob = (r ** (s - 1)) * (p / 100.0)
                        new_t = t_prev + s
                        if new_t <= T:
                            next_dp[new_t] += dp[t_prev] * prob
                    prob = r ** (ti - 1)
                    new_t = t_prev + ti
                    if new_t <= T:
                        next_dp[new_t] += dp[t_prev] * prob
        dp = next_dp
    print("{0:.9f}".format(expected))

if __name__ == "__main__":
    main()
```

3. **Processing Each Song**: For each song, the DP array is updated to reflect the probability distribution of time usage after recognizing the song. The expected number of recognized songs is updated based on the current song's probabilities.
4. **Geometric Series Calculation**: For each song, the probability of recognizing it at each second is computed using a geometric series, which allows efficient calculation of contributions to the DP array.
5. **Updating DP Array**: The contributions to the next state of the DP array are calculated for each possible time spent recognizing the current song, considering both the probabilistic recognition and the guaranteed recognition at the chorus start time.
