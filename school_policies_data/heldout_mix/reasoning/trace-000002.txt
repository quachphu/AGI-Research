To solve this problem, we need to determine the number of balanced substrings in a given string of digits 4 and 7. A substring is balanced if there exists a split point where the number of 4s in the left part equals the number of 7s in the right part.

### Approach
1. **Prefix Sum Array**: Compute a prefix sum array to keep track of the number of 4s up to each position in the string.
2. **Fenwick Tree (BIT)**: Use a Fenwick Tree (Binary Indexed Tree) to efficiently count valid substrings. This data structure helps in maintaining and querying prefix sums efficiently.
3. **Iterate Over Each Position**: For each position in the string, determine the maximum valid prefix sum that allows a balanced substring and use the Fenwick Tree to count how many such valid prefixes exist.

### Solution Code

class FenwickTree:
    def __init__(self, size):
        self.size = size
        self.tree = [0] * (self.size + 1)  # 1-based indexing

    def update(self, idx, delta):
        while idx <= self.size:
            self.tree[idx] += delta
            idx += idx & -idx

    def query(self, idx):
        res = 0
        while idx > 0:
            res += self.tree[idx]
            idx -= idx & -idx
        return res
