To solve this problem, we need to determine the optimal location for a shawarma tent such that the maximum number of students pass through it on their shortest path from the school to their homes. The solution involves analyzing the paths students take and identifying the most frequented points adjacent to the school.

### Approach
1. **Understanding Paths**: Each student's shortest path from the school to their home is determined by Manhattan distance. The tent must be placed on at least one of these paths.
2. **Adjacent Points**: The optimal tent location is likely adjacent to the school in one of the four cardinal directions (east, west, north, south). This is because these points are common intersections for many paths.
3. **Count Valid Students**: For each adjacent point, count how many students' paths pass through it. This is done by checking if the student's home coordinates lie within specific ranges relative to the school.

### Solution Code
```python
n, s_x, s_y = map(int, input().split())

east_count = 0
west_count = 0
north_count = 0
south_count = 0

for _ in range(n):
    x, y = map(int, input().split())
    if x >= s_x + 1:
        east_count += 1
    if x <= s_x - 1:
        west_count += 1
    if y >= s_y + 1:
        north_count += 1
    if y <= s_y - 1:
        south_count += 1

candidates = []
# Check east point
if s_x + 1 <= 10**9:
    candidates.append((east_count, s_x + 1, s_y))
# Check west point
if s_x - 1 >= 0:
    candidates.append((west_count, s_x - 1, s_y))
# Check north point
if s_y + 1 <= 10**9:
    candidates.append((north_count, s_x, s_y + 1))
# Check south point
if s_y - 1 >= 0:
    candidates.append((south_count, s_x, s_y - 1))

# Find the candidate with maximum count
max_count = -1
best_p = (s_x, s_y)  # default, though school is invalid, but candidates should exist
for cnt, px, py in candidates:
    if cnt > max_count or (cnt == max_count and (px, py) == (best_p)):
        max_count = cnt
        best_p = (px, py)

print(max_count)
print(best_p[0], best_p[1])
```

### Explanation
1. **Input Reading**: The code reads the number of students and the school's coordinates.
2. **Counting Students**: For each student, it checks if their home lies in the range that would include each of the four adjacent points to the school.
3. **Valid Candidates**: It constructs a list of valid adjacent points (east, west, north, south) ensuring they are within the coordinate bounds.
4. **Determine Optimal Point**: The code then selects the point with the highest student count, ensuring it is not the school itself. If there are ties, the first encountered point with the maximum count is chosen.

This approach efficiently narrows down the potential optimal points to four adjacent locations, making the solution both optimal and computationally feasible.
