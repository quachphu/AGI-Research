To solve this problem, we need to determine the minimum number of seconds Karlsson needs to adjust all cupboard doors such that all left doors are in the same state (either all open or all closed) and all right doors are in the same state. Each door change takes 1 second.

### Approach
1. **Problem Analysis**: Karlsson can choose any combination of states for the left and right doors. There are four possible combinations to consider: (left open, right open), (left open, right closed), (left closed, right open), and (left closed, right closed). For each combination, we need to calculate the total number of door flips required and select the minimum.

2. **Intuition**: By evaluating all four possible target states for the doors, we ensure that we consider every scenario. For each target state, we count how many doors need to be flipped to match the target state and sum these counts. The minimum sum across all scenarios will be our solution.

3. **Algorithm**:
   - Read the number of cupboards and their current door states.
   - For each of the four target combinations (0,0), (0,1), (1,0), (1,1):
     - Calculate the total flips needed to adjust all left doors to the target left state.
     - Calculate the total flips needed to adjust all right doors to the target right state.
     - Sum these counts and keep track of the minimum sum.
   - Output the minimum sum found.

### Solution Code
```python
n = int(input())
left = []
right = []
for _ in range(n):
    l, r = map(int, input().split())
    left.append(l)
    right.append(r)

min_time = float('inf')
for target_l in [0, 1]:
    for target_r in [0, 1]:
        total = 0
        for i in range(n):
            if left[i] != target_l:
                total += 1
            if right[i] != target_r:
                total += 1
        if total < min_time:
            min_time = total

print(min_time)
```

### Explanation
1. **Reading Input**: The code reads the number of cupboards and their respective left and right door states.
2. **Evaluating Target States**: For each combination of target states (0,0), (0,1), (1,0), (1,1), the code calculates the total number of flips required to adjust all doors to match the target states.
3. **Calculating Flips**: For each cupboard, if the current state of a door does not match the target state, a flip is counted. The total flips for each target combination are summed.
4. **Finding Minimum**: The minimum number of flips across all target combinations is determined and printed as the result.

This approach ensures that we efficiently evaluate all possible scenarios and select the optimal solution with a time complexity of O(n), which is suitable given the problem constraints.
