To solve this problem, we need to determine if every substring of a given string has its reverse present within the same string. The key insight here is that if a string is a palindrome, then every substring's reverse will also be present as a substring. This is because the reverse of any substring in a palindrome will be mirrored in the structure of the palindrome itself.

### Approach
1. **Check if the String is a Palindrome**: A string is a palindrome if it reads the same forwards and backwards. For a palindrome, every substring's reverse will naturally be present as a substring due to the symmetric structure of the string.
2. **Efficient Check**: For each input string, check if it is a palindrome by comparing the string to its reverse. If it is a palindrome, the answer is "YES"; otherwise, it is "NO".

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for s in input[1:T+1]:
        print("YES" if s == s[::-1] else "NO")

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read all at once and split into a list of strings. The first element is the number of test cases, `T`.
- **Palindrome Check**: For each test case string, we check if the string is equal to its reverse using slicing (`s[::-1]`). If they are equal, the string is a palindrome, and we print "YES". Otherwise, we print "NO".
- **Efficiency**: Checking if a string is a palindrome is done in linear time, O(n), where n is the length of the string. This approach efficiently handles the constraints, ensuring the solution works within acceptable time limits even for the upper bounds of input size.
