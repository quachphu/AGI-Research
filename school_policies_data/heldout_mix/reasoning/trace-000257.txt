Now, how to implement this efficiently.

The key steps are:

- For each character in the sorted unique list, check if there's a position after the current last_pos.

This can be done using binary search for each character's occurrence list.

So for a character c, its occurrence list is a list of indices in increasing order. For example, [3, 5, 6] for a character that appears at positions 3,5,6.

To check if there's a position after last_pos, we can perform a binary search for the first occurrence in the list that is > last_pos.

If such an index exists, we can take the earliest occurrence (the first one greater than last_pos) to minimize blocking other characters.

So for each character c in the sorted unique list (from high to low), we check if the occurrence list has a position > last_pos. If yes, we take the first such position, add c to the result, update last_pos to that position, and proceed.

This approach is O(k * m), where k is the number of characters in the result (up to 26), and m is the number of unique characters (up to 26). For each character in the sorted list, we perform a binary search on its occurrence list (O(log l), where l is the number of occurrences of that character). But since we have up to 26 unique characters, and each binary search is O(log n), this is manageable even for large n.

So the steps for the code are:

1. Preprocess the string to collect the occurrence positions for each unique character.

2. Collect the unique characters, sort them in reverse order (so largest first).

3. Initialize last_pos to -1, result as empty list, and a set of remaining characters (initially all unique characters).

4. While True:

   a. Iterate through the sorted unique characters.

   b. For each character c in the sorted list:

      i. If c is not in remaining, skip.

      ii. Check if there's a position in c's occurrence list that is > last_pos.

      iii. If such a position exists:

         - Add c to the result.

         - Update last_pos to that position.

         - Break and proceed to next iteration.

      iv. If no such position exists, continue to next character.

   c. If no character is found, break the loop.

First, we need to collect the occurrences for each character. We can use a dictionary where each key is a character, and the value is a list of indices where it appears.

Then, we sort the unique characters in reverse order (so from 'z' to 'a').

For the binary search part, we can use the bisect module's bisect_right function. For example, for a list of positions sorted in increasing order, bisect_right(list, last_pos) gives the insertion point for last_pos in the list such that all elements before are <= last_pos. So if the insertion point is within the list's length, then the element at that position is the first occurrence greater than last_pos.

To solve this problem, we need to find the lexicographically greatest unique subsequence of a given string. A unique subsequence is one where all characters are distinct and appear in the same order as they do in the original string.

### Approach
1. **Preprocess Occurrences**: For each character in the string, record the positions where they appear. This helps in efficiently checking if a character can be included in the subsequence after a given position.
2. **Sort Characters**: Sort the unique characters in reverse order (from 'z' to 'a') to prioritize larger characters first.
3. **Greedy Selection**: Iterate through the sorted characters and use a greedy approach to select the largest possible character that can be included in the subsequence while ensuring it appears after the current position. This is done using binary search to find the earliest valid position for each character.

### Solution Code
```python
import bisect
from collections import defaultdict

def main():
    import sys
    n = int(sys.stdin.readline())
    s = sys.stdin.readline().strip()

    # Preprocess character positions
    char_positions = defaultdict(list)
    for idx, char in enumerate(s):
        char_positions[char].append(idx)
    
    # Extract unique characters sorted in descending order
    unique_chars = sorted(char_positions.keys(), reverse=True)
    remaining_chars = set(unique_chars)
    result = []
    last_pos = -1  # Tracks the last position added to result

    while True:
        found = False
        for char in unique_chars:
            if char not in remaining_chars:
                continue
            positions = char_positions[char]
            # Find the first occurrence after last_pos
            i = bisect.bisect_right(positions, last_pos)
            if i < len(positions):
                # Add this character to the result
                result.append(char)
                last_pos = positions[i]
                remaining_chars.remove(char)
                found = True
                break
        if not found:
            break

    print(''.join(result))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Preprocessing**: We first collect the positions of each character in the string using a dictionary. This allows us to quickly check where each character appears.
2. **Sorting Characters**: By sorting the characters in reverse order, we ensure that we consider the largest possible characters first, which helps in building the lexicographically greatest subsequence.
3. **Greedy Selection**: For each character in the sorted list, we use binary search to find the earliest valid position after the current last position. If such a position exists, we include the character in the result and update the last position. This process continues until no more valid characters can be added.

This approach efficiently combines preprocessing and greedy selection to ensure we build the desired subsequence in linear time relative to the input size, making it suitable for large strings up to 100,000 characters.
