To solve this problem, we need to simulate a game where two players, Sereja and Dima, take turns picking cards from either end of a row. Each player always picks the card with the larger value available at their turn. The goal is to determine the final scores of both players after all cards have been picked.

### Approach
1. **Initialization**: Read the number of cards and their values from the input.
2. **Two Pointers Technique**: Use two pointers, `left` starting at the beginning of the list and `right` starting at the end of the list.
3. **Turn-Based Selection**: Alternate turns between Sereja and Dima. On each turn, the current player picks the card with the larger value between the cards at the `left` and `right` pointers.
4. **Update Scores**: Add the value of the chosen card to the current player's score and adjust the pointers accordingly.
5. **Termination**: The process continues until all cards have been picked, indicated when the `left` pointer exceeds the `right` pointer.

### Solution Code
```python
n = int(input())
cards = list(map(int, input().split()))
left = 0
right = n - 1
sereja = 0
dima = 0
is_sereja_turn = True

while left <= right:
    if cards[left] > cards[right]:
        chosen = cards[left]
        left += 1
    else:
        chosen = cards[right]
        right -= 1
    if is_sereja_turn:
        sereja += chosen
    else:
        dima += chosen
    is_sereja_turn = not is_sereja_turn

print(sereja, dima)
```

### Explanation
1. **Reading Input**: The number of cards `n` and the list of card values are read from standard input.
2. **Pointer Initialization**: `left` starts at 0 (beginning of the list) and `right` starts at `n-1` (end of the list).
3. **Turn Management**: A boolean flag `is_sereja_turn` is used to alternate turns between Sereja and Dima.
4. **Card Selection**: On each turn, the current player compares the values at the `left` and `right` pointers and picks the larger one. The corresponding pointer is then adjusted (increment `left` or decrement `right`).
5. **Score Update**: The value of the chosen card is added to the current player's score.
6. **Loop Termination**: The loop continues until all cards are picked, which happens when `left` exceeds `right`.

This approach efficiently simulates the game using a linear pass through the list of cards, ensuring optimal performance with a time complexity of O(n), where n is the number of cards. This is suitable given the problem constraints (n ≤ 1000).
