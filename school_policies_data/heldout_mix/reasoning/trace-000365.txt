To solve this problem, we need to determine the largest possible capacity of a pond that can be built in a garden site based on elevation data. The pond must be a rectangular area where the outermost cells are higher than all inner cells, and the capacity is calculated based on the difference between the minimum elevation of the outermost cells and the elevations of the inner cells.

### Approach
1. **Input Reading**: Read the depth (d) and width (w) of the garden site, followed by the elevation data for each cell.
2. **Iterate Over All Possible Rectangles**: Check all possible rectangles of size at least 3x3 to determine if they can form a valid pond.
3. **Perimeter and Inner Cells Check**: For each rectangle, identify the perimeter cells and the inner cells. The minimum elevation of the perimeter cells must be greater than all inner cells for the rectangle to be valid.
4. **Capacity Calculation**: If valid, compute the capacity of the pond by summing the differences between the minimum perimeter elevation and each inner cell's elevation.
5. **Track Maximum Capacity**: Keep track of the maximum capacity found across all valid rectangles.

### Solution Code
```python
import sys

def solve():
    while True:
        line = sys.stdin.readline()
        if not line:
            break
        line = line.strip()
        if not line:
            continue
        d, w = map(int, line.split())
        if d == 0 and w == 0:
            break
        grid = []
        for _ in range(d):
            row = list(map(int, sys.stdin.readline().split()))
            grid.append(row)
        max_cap = 0
        # Iterate all possible rectangles
        for y_start in range(d):
            for y_end in range(y_start + 2, d):
                for x_start in range(w):
                    for x_end in range(x_start + 2, w):
                        # Collect perimeter cells
                        perim = []
                        # Top and bottom rows
                        for x in range(x_start, x_end + 1):
                            perim.append(grid[y_start][x])
                            perim.append(grid[y_end][x])
                        # Left and right columns (excluding top and bottom rows)
                        for y in range(y_start + 1, y_end):
                            perim.append(grid[y][x_start])
                            perim.append(grid[y][x_end])
                        min_p = min(perim)
                        # Check inner cells
                        valid = True
                        for y_inner in range(y_start + 1, y_end):
                            for x_inner in range(x_start + 1, x_end):
                                if grid[y_inner][x_inner] >= min_p:
                                    valid = False
                                    break
                            if not valid:
                                break
                        if valid:
                            # Calculate capacity
                            cap = 0
                            for y_inner in range(y_start + 1, y_end):
                                for x_inner in range(x_start + 1, x_end):
                                    cap += (min_p - grid[y_inner][x_inner])
                            if cap > max_cap:
                                max_cap = cap
        print(max_cap)

if __name__ == '__main__':
    solve()
```

3. **Perimeter and Inner Cells**: For each rectangle, the perimeter cells are collected, and their minimum elevation is determined. The inner cells are checked to ensure they are all lower than the minimum perimeter elevation.
4. **Capacity Calculation**: If valid, the capacity is calculated by summing the differences between the minimum perimeter elevation and each inner cell's elevation. The maximum capacity encountered is tracked and updated.
5. **Output**: After processing all possible rectangles, the maximum capacity found is printed for each dataset.
