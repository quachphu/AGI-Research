### Approach

   - The goal is to form a spanning tree from the given roads such that the maximum speed limit is exactly `k`.
   - We can either lower the speed limits of roads exceeding `k` or raise the speed limits of roads below `k` to achieve the desired maximum.

2. **Key Insights**:
   - **Case A**: If there are roads with speed limits ≥ `k`, we need to form a spanning tree that includes at least one such road. Lower these roads to `k` and minimize the total changes required.
   - **Case B**: If all roads have speed limits < `k`, we need to form a spanning tree and raise the maximum speed limit in the tree to `k`.

3. **Algorithm**:
   - **Case A**: Use Kruskal's algorithm to find the Minimum Spanning Tree (MST) considering roads with speed limits ≥ `k` (adjusted weight `s_i - k`) and others with weight 0. Track if any road ≥ `k` is included in the MST.
   - **Case B**: Check if roads with speed limits < `k` can form a connected graph. If so, find the maximum speed limit in their MST and compute the required changes.

import sys

class DSU:
    def __init__(self, size):
        self.parent = list(range(size + 1))
        self.rank = [0] * (size + 1)
        self.size = [1] * (size + 1)
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return False
        if self.rank[x_root] < self.rank[y_root]:
            self.parent[x_root] = y_root
            self.size[y_root] += self.size[x_root]
        else:
            self.parent[y_root] = x_root
            self.size[x_root] += self.size[y_root]
            if self.rank[x_root] == self.rank[y_root]:
                self.rank[x_root] += 1
        return True
    
    def get_size(self, x):
        return self.size[self.find(x)]
