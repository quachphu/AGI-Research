To solve this problem, we need to split a given string of digits into four integers such that their sum is maximized. Each integer must not have leading zeros and must be less than or equal to \(10^{12}\). If it's not possible to split the string into four valid integers, we should output "unlucky".

### Approach
1. **Check String Length**: If the string length is less than 4, it's impossible to split it into four parts, so we immediately return "unlucky".
2. **Generate Split Points**: For valid strings (length ≥ 4), generate all possible ways to split the string into four parts. This involves selecting three split points such that each part is non-empty.
3. **Validate Parts**: For each split, check if each part is valid (no leading zeros unless the part is a single zero, and each part's length does not exceed 12 digits).
4. **Calculate Maximum Sum**: For valid splits, compute the sum of the four parts and keep track of the maximum sum encountered.

### Solution Code
```python
import sys
import itertools

def process_string(s):
    L = len(s)
    if L < 4:
        return "unlucky"
    max_sum = -1
    split_positions = range(L - 1)  # Possible split points are 0 to L-2
    for splits in itertools.combinations(split_positions, 3):
        i, j, k = splits
        # Ensure i < j < k
        if not (i < j < k):
            continue  # This should not happen with combinations, but just in case
        # Extract the four parts
        p1 = s[0:i+1]
        p2 = s[i+1:j+1]
        p3 = s[j+1:k+1]
        p4 = s[k+1:]
        # Check validity of each part
        valid = True
        for part in [p1, p2, p3, p4]:
            if len(part) > 12:
                valid = False
                break
            if len(part) > 1 and part[0] == '0':
                valid = False
                break
        if valid:
            current_sum = int(p1) + int(p2) + int(p3) + int(p4)
            if current_sum > max_sum:
                max_sum = current_sum
    if max_sum == -1:
        return "unlucky"
    else:
        return str(max_sum)

def main():
    input = sys.stdin.read().split()
    N = int(input[0])
    for i in range(1, N+1):
        s = input[i]
        print(process_string(s))

if __name__ == "__main__":
    main()
```
