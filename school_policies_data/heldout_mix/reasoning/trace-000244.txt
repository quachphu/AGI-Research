To solve this problem, we need to determine the probability that Jerry's total sum of three drawn balls is strictly higher than Andrew's total sum, given that Andrew wins the first two rounds and Jerry wins the third. 

### Approach
1. **Understanding the Problem**: Each round, Andrew and Jerry draw two distinct balls. Andrew wins the first two rounds, and Jerry wins the third. We need to compute the probability that Jerry's total sum from all three rounds is higher than Andrew's.

2. **Key Insight**: The problem can be reduced to analyzing the differences between the numbers drawn by Andrew and Jerry in each round. Specifically, we need to check if the sum of Jerry's differences in the third round exceeds the combined differences from the first two rounds won by Andrew.

3. **Efficient Calculation Using Convolution**: Instead of enumerating all possible combinations (which is infeasible for large n), we use Fast Fourier Transform (FFT) based convolution to efficiently compute the number of valid pairs of differences from the first two rounds. This helps us determine the probability by leveraging mathematical properties of polynomial multiplication.

### Solution Code
```python
import sys
import bisect
from collections import defaultdict
import numpy as np

def main():
    n, *rest = map(int, sys.stdin.read().split())
    a = rest[:n]
    a.sort()
    
    # Generate count1 for R1 and R2
    count1 = defaultdict(int)
    for i in range(n):
        for j in range(i):
            diff = a[i] - a[j]
            count1[diff] += 1
    
    if not count1:
        print(0.0)
        return
    
    sorted_ds = sorted(count1.keys())
    max_d = sorted_ds[-1] if sorted_ds else 0
    m = len(sorted_ds)
    
    # Compute prefix_sum for suffix sums
    prefix_sum = [0] * (m + 1)
    for i in range(m-1, -1, -1):
        prefix_sum[i] = prefix_sum[i+1] + count1[sorted_ds[i]]
    
    # Create array A
    size_A = max_d + 1
    A = np.zeros(size_A, dtype=np.int64)
    for d in count1:
        A[d] = count1[d]
    
    # Compute convolution B = A * A
    B = np.convolve(A, A, mode='full')
    
    # Compute the total
    total = 0.0
    len_B = len(B)
    for s in range(len_B):
        if s > max_d:
            sum_d3 = 0
        else:
            i = bisect.bisect_right(sorted_ds, s)
            sum_d3 = prefix_sum[i]
        total += B[s] * sum_d3
    
    # Compute denominator
    c_n2 = n * (n - 1) // 2
    denominator = (c_n2 ** 3)
    if denominator == 0:
        print(0.0)
        return
    
    probability = total / denominator
    print("{0:.10f}".format(probability))

if __name__ == "__main__":
```

2. **Counting Differences**: For each valid pair (a, j) where a > j, compute the difference (a - j) and count occurrences of each difference.
