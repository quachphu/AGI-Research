To solve this problem, we need to determine the maximum amount of time students can rest while maintaining a 75% attendance rate for their classes each week. The solution involves calculating the minimum required classes to attend and then maximizing the rest time by selecting the shortest possible class durations.

### Approach
1. **Input Parsing**: Read the number of test cases and for each test case, read the schedule for each of the 7 days.
2. **Calculate Durations**: For each class in each day, compute the duration of the class using the start and end times provided.
3. **Determine Minimum Classes to Attend**: Calculate the minimum number of classes (K) required to maintain 75% attendance using the formula \( K = \left\lceil \frac{3 \times \text{total\_classes}}{4} \right\rceil \).
4. **Optimize Rest Time**: Sort the class durations in ascending order and sum the shortest K durations. Subtract this sum from the total available time in the week to get the maximum rest time.

### Solution Code
```python
t = int(input())
for _ in range(t):
    durations = []
    total_classes = 0
    for _ in range(7):
        parts = list(map(int, input().split()))
        ni = parts[0]
        total_classes += ni
        times = parts[1:]
        for i in range(ni):
            start = times[2 * i]
            end = times[2 * i + 1]
            durations.append(end - start)
    durations.sort()
    k = (3 * total_classes + 3) // 4
    sum_selected = sum(durations[:k])
    max_rest = 7 * 24 * 3600 - sum_selected
    print(max_rest)
```

### Explanation
1. **Reading Input**: The input is read for multiple test cases. Each test case consists of 7 lines representing the schedule for each day of the week.
2. **Class Duration Calculation**: For each class, the duration is calculated as the difference between the end time and start time.
3. **Sorting and Selection**: By sorting the durations of all classes, we can efficiently select the shortest K durations, ensuring we attend the minimum required classes with the least time spent.
4. **Rest Time Calculation**: The maximum rest time is derived by subtracting the total time spent in the selected classes from the total available time in the week (7 days * 24 hours/day * 3600 seconds/hour).

This approach ensures that students meet the attendance requirement while maximizing their rest time by strategically selecting the shortest class durations.
