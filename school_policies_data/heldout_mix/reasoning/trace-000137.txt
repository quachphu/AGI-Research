To solve this problem, we need to determine the minimal possible number of bacteria remaining after all possible swallow operations. A bacteria can swallow another if it is larger but not by more than a given constant K. The goal is to find the optimal way to maximize the number of swallows, thereby minimizing the remaining bacteria.

### Approach
1. **Sort the Bacteria Sizes**: Start by sorting the array of bacteria sizes in ascending order. This allows us to efficiently check each bacteria against subsequent ones.
2. **Binary Search for Swallows**: For each bacteria, use binary search to find the first bacteria that is larger and within the allowable range (i.e., not exceeding K more than the current bacteria). This helps determine if the current bacteria can be swallowed by any subsequent one.
3. **Count Unswallowed Bacteria**: If no subsequent bacteria can swallow the current one, increment the count of remaining bacteria. This count gives the minimal number of bacteria left.

### Solution Code
```python
import bisect

n, K = map(int, input().split())
a = list(map(int, input().split()))
a.sort()

count = 0
for i in range(n):
    j = bisect.bisect_right(a, a[i])
    if j < n and a[j] <= a[i] + K:
        continue
    count += 1

print(count)
```

### Explanation
1. **Sorting**: The array is sorted to facilitate efficient binary search operations. This allows us to check subsequent elements in O(log n) time.
2. **Binary Search**: For each element, we use `bisect.bisect_right` to find the first element that is larger than the current element. This index helps us determine if there exists a valid swallower within the range defined by K.
3. **Count Check**: If no valid swallower is found for the current element, it means this element will remain in the Petri dish, so we increment the count.

This approach efficiently determines the minimal number of remaining bacteria by leveraging sorting and binary search, ensuring an optimal solution with a time complexity of O(n log n), which is suitable for large input sizes up to 200,000.
