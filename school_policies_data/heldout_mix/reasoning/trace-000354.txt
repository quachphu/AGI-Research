To solve this problem, we need to determine the position of the last remaining participant in a game where every second participant is eliminated in a circular manner. This problem is a variation of the Josephus problem with a step size of 2. The solution involves a mathematical approach to efficiently compute the result without simulating the entire elimination process.

### Approach
1. **Understanding the Josephus Problem**: The Josephus problem involves people standing in a circle and eliminating every k-th person until only one remains. For k=2, the position of the last remaining person can be determined using a mathematical formula.
2. **Mathematical Insight**: For a given number of participants X, the position of the last remaining person can be found using the formula:
   \[
   J(X) = 2 \times (X - 2^{\lfloor \log_2 X \rfloor}) + 1
   \]
   Here, \(2^{\lfloor \log_2 X \rfloor}\) is the largest power of 2 less than or equal to X. This value can be efficiently computed using bit manipulation.
3. **Bit Manipulation**: In Python, the largest power of 2 less than or equal to X can be found using the bit length of X. The bit length of X gives the number of bits required to represent X in binary. The largest power of 2 is then \(1 << (X.bit_length() - 1)\).

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    for _ in range(n):
        x = int(sys.stdin.readline())
        largest_power = 1 << (x.bit_length() - 1)
        result = 2 * (x - largest_power) + 1
        print(result)

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The code reads the number of test cases and each test case value.
2. **Computing Largest Power of 2**: For each participant count X, the largest power of 2 less than or equal to X is computed using bit manipulation. This is done by shifting 1 left by (bit length of X - 1).
3. **Applying the Formula**: Using the computed largest power of 2, the formula \(2 \times (X - \text{largest\_power}) + 1\) is applied to determine the position of the last remaining participant.
4. **Output**: The result for each test case is printed.

This approach efficiently handles large values up to \(10^8\) by leveraging bit manipulation and mathematical properties, ensuring optimal performance without the need for simulation.
