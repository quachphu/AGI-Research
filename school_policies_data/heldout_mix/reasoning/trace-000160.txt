### Approach
1. **Input Parsing**: Read the number of test cases. For each test case, read the number of activities and the user's origin.
2. **Calculate Laddus**: For each activity, compute the laddus earned based on the type of activity:
   - **Contest Win**: 300 laddus plus a bonus if the rank is 20 or better.
   - **Top Contributor**: 300 laddus.
   - **Bug Found**: Laddus equal to the severity of the bug.
   - **Contest Hosted**: 50 laddus.
3. **Determine Redemption Threshold**: Based on the user's origin, set the minimum laddus required per month (200 for Indians, 400 for others).
4. **Compute Maximum Months**: Divide the total laddus by the redemption threshold to get the maximum number of months.

### Solution Code
```python
def process():
    import sys
    input = sys.stdin.read().splitlines()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        parts = input[idx].split()
        activities = int(parts[0])
        origin = parts[1]
        idx += 1
        total_laddus = 0
        for _ in range(activities):
            activity_line = input[idx].strip().split()
            idx += 1
            activity_type = activity_line[0]
            if activity_type == 'CONTEST_WON':
                rank = int(activity_line[1])
                bonus = 20 - rank if rank <= 20 else 0
                total_laddus += 300 + bonus
            elif activity_type == 'TOP_CONTRIBUTOR':
                total_laddus += 300
            elif activity_type == 'BUG_FOUND':
                severity = int(activity_line[1])
                total_laddus += severity
            elif activity_type == 'CONTEST_HOSTED':
                total_laddus += 50
        min_per_month = 200 if origin == 'INDIAN' else 400
        print(total_laddus // min_per_month)

process()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into lines for easier processing.
2. **Processing Each Test Case**: For each test case, the number of activities and user origin are read. Each activity is then processed to accumulate the total laddus.
3. **Activity Handling**: Each activity type is handled according to the specified rules to compute the laddus earned.
4. **Redemption Calculation**: Based on the user's origin, the minimum laddus required per month is determined. The total laddus are divided by this minimum to determine the maximum number of full months the user can redeem laddus.

This approach efficiently computes the result by iterating through each activity once per test case, ensuring an optimal solution with linear time complexity relative to the number of activities.
