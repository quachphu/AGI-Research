To solve this problem, we need to generate the nth Fibonacci number for a series of input positions provided by the user. The Fibonacci sequence given starts with 1, 1, 2, 3, 5, 8, etc. The program should read inputs until a 0 is encountered, and for each non-zero input, output the corresponding Fibonacci number.

### Approach
1. **Input Handling**: Read inputs one per line until a 0 is encountered. Collect all non-zero inputs into a list.
2. **Precomputation**: Determine the maximum value from the collected inputs. Precompute Fibonacci numbers up to this maximum value using an iterative approach. This ensures that each input is processed in constant time after the precomputation.
3. **Efficiency**: By precomputing Fibonacci numbers up to the maximum input value once, we avoid redundant calculations and ensure the solution is efficient even for large inputs.

### Solution Code
```python
import sys

def main():
    inputs = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        if n == 0:
            break
        inputs.append(n)
    
    if not inputs:
        return
    
    max_n = max(inputs)
    fibs = [0] * max_n
    
    if max_n >= 1:
        fibs[0] = 1
    if max_n >= 2:
        fibs[1] = 1
    
    for i in range(2, max_n):
        fibs[i] = fibs[i-1] + fibs[i-2]
    
    for n in inputs:
        print(fibs[n-1])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Inputs**: The program reads each line from standard input until it encounters a 0. Non-zero values are stored in a list for processing.
2. **Precomputation of Fibonacci Numbers**: The maximum value from the input list is determined. Using an iterative approach, Fibonacci numbers up to this maximum value are computed and stored in an array. This approach ensures that each subsequent Fibonacci number is the sum of the two preceding numbers, computed efficiently in O(n) time.
3. **Output**: For each input value, the corresponding Fibonacci number is retrieved from the precomputed array and printed. This ensures that each query is answered in constant time O(1) after the initial precomputation.

This approach efficiently handles large numbers and ensures that the solution is both time and space efficient, leveraging Python's capability to handle arbitrarily large integers.
