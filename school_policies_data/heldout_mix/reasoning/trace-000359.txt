To solve this problem, we need to compute the sum of the first `n` digits in the decimal expansion of the fraction `a/b` for multiple datasets. The solution involves simulating the long division process to extract each digit after the decimal point and summing them up.

### Approach
1. **Understanding the Problem**: The task is to find the sum of the first `n` digits in the decimal expansion of the fraction `a/b`. This requires iterating through the digits generated by the long division process.
2. **Long Division Simulation**: For each digit position:
   - Multiply the remainder of the division by 10.
   - The quotient of this multiplication divided by `b` gives the next digit.
   - Update the remainder to the modulus of the multiplication with `b`.
3. **Iterative Process**: Repeat the above steps for each of the `n` digits required and accumulate their sum.
4. **Handling Multiple Datasets**: Read input lines until end-of-file (EOF) is reached, processing each line as a separate dataset.

### Solution Code
```python
import sys

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        a, b, n = map(int, line.split())
        remainder = a % b
        sum_digits = 0
        for _ in range(n):
            remainder *= 10
            digit = remainder // b
            sum_digits += digit
            remainder = remainder % b
        print(sum_digits)

main()
```

### Explanation
1. **Reading Input**: The code reads each line from standard input, trims any leading/trailing whitespace, and skips empty lines.
2. **Processing Each Dataset**: For each line, the values of `a`, `b`, and `n` are extracted.
3. **Computing Remainder**: The initial remainder is computed as `a % b`, which gives the fractional part of the division.
4. **Digit Extraction Loop**: For each of the `n` digits:
   - The remainder is multiplied by 10.
   - The integer division of the new remainder by `b` gives the next digit.
   - This digit is added to the cumulative sum.
   - The remainder is updated to the modulus of the new remainder with `b`.
5. **Output**: After processing `n` digits, the sum is printed for each dataset.

This approach efficiently computes the required digits using the properties of integer division and modulus operations, ensuring correctness even for repeating decimals. The solution handles multiple datasets and adheres to the input/output constraints specified.
