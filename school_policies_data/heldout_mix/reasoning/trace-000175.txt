To solve this problem, we need to determine the minimum cost for Fox Ciel to buy a set of cards such that she can jump to any cell on an infinite tape. The key insight is that the greatest common divisor (GCD) of the selected jump lengths must be 1, as this allows reaching any cell. If no such subset exists, we should return -1.

### Approach
1. **Dynamic Programming (DP) Setup**: Use a dictionary to keep track of the minimum cost for each possible GCD value that can be formed using the cards processed so far.
2. **Iterate Over Cards**: For each card, update the DP dictionary by considering both the card alone and its combination with previously processed cards.
3. **Update GCD Values**: For each existing GCD value in the DP, compute the new GCD when combined with the current card's jump length and update the cost if it is lower.
4. **Check Result**: After processing all cards, check if the GCD of 1 is achievable. If so, return the minimum cost; otherwise, return -1.

### Solution Code
```python
import math

def minimal_cost():
    n = int(input())
    l = list(map(int, input().split()))
    c = list(map(int, input().split()))
    
    dp = {}
    
    for i in range(n):
        li = l[i]
        ci = c[i]
        temp = {}
        # Process existing entries in dp
        for g in list(dp.keys()):
            new_gcd = math.gcd(g, li)
            new_cost = dp[g] + ci
            if new_gcd in temp:
                if new_cost < temp[new_gcd]:
                    temp[new_gcd] = new_cost
            else:
                temp[new_gcd] = new_cost
        # Add current card alone
        if li in temp:
            if ci < temp[li]:
                temp[li] = ci
        else:
            temp[li] = ci
        # Merge temp into dp
        for g in temp:
            if g in dp:
                if temp[g] < dp[g]:
                    dp[g] = temp[g]
            else:
                dp[g] = temp[g]
    
    print(dp.get(1, -1))
```

4. **Updating Costs**: For each new GCD value, we update the DP dictionary to keep the minimum cost.
