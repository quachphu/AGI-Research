To solve this problem, we need to determine if a given string is a prime string. A prime string is defined as a string where the number of distinct characters is a prime number, and each character's occurrence count is also a prime number.

### Approach
1. **Prime Checking with Sieve of Eratosthenes**: We precompute prime numbers up to the maximum possible length of the input string (100,000) using the Sieve of Eratosthenes. This allows us to check if a number is prime in constant time.
2. **Frequency Counting**: For each test case, we count the frequency of each character in the string using a dictionary.
3. **Distinct Character Check**: Check if the number of distinct characters is a prime number.
4. **Occurrence Check**: For each character's occurrence count, verify if it is a prime number.

### Solution Code
```python
import sys
from collections import Counter

def sieve_func(n):
    sieve = [True] * (n + 1)
    sieve[0] = sieve[1] = False
    for i in range(2, int(n**0.5) + 1):
        if sieve[i]:
            sieve[i*i : n+1 : i] = [False] * len(sieve[i*i : n+1 : i])
    return sieve

def main():
    sieve = sieve_func(10**5)
    T = int(sys.stdin.readline())
    for _ in range(T):
        s = sys.stdin.readline().strip()
        freq = Counter(s)
        distinct = len(freq)
        if not sieve[distinct]:
            print("NO")
            continue
        all_primes = True
        for cnt in freq.values():
            if not sieve[cnt]:
                all_primes = False
                break
        print("YES" if all_primes else "NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prime Checking with Sieve**: The `sieve_func` generates a boolean array where each index `i` indicates whether `i` is a prime number. This is efficient and allows O(1) prime checks.
2. **Reading Input**: The input is read using `sys.stdin` for efficiency, especially given the potential size of the input strings.
3. **Frequency Dictionary**: Using `Counter` from the `collections` module, we efficiently count character occurrences in O(n) time for each string.
4. **Distinct Character Check**: The number of distinct characters is checked against the sieve array to determine if it is a prime number.
5. **Occurrence Check**: Each character's occurrence count is verified against the sieve array. If all counts are primes, the string is a prime string.

This approach ensures that we efficiently handle the constraints and provide the correct result for each test case.
