2. **Hack Contributions**:

3. **Steps**:

   - Output the final score as an integer.

### Solution Code
```python
def calculate_score():
    # Read input values
    m = list(map(int, input().split()))
    w = list(map(int, input().split()))
    hs, hu = map(int, input().split())
    
    total = 0
    
    # Calculate score for each problem
    for i in range(5):
        x = 500 * (i + 1)
        mi = m[i]
        wi = w[i]
        part1 = 0.3 * x
        part2 = x * (1 - mi / 250) - 50 * wi
        total += max(part1, part2)
    
    # Adjust for hacks
    total += hs * 100
    total -= hu * 50
    
    # Output as integer
    print(int(total))

# Execute the function
calculate_score()
```

1. **Reading Inputs**:
   - The first line contains submission times for each problem.
   - The second line contains the number of wrong submissions for each problem.
   - The third line contains the number of successful and unsuccessful hacks.

2. **Problem Score Calculation**:
   - For each problem, compute two possible scores: 30% of the maximum points and the adjusted score based on submission time and wrong submissions.
   - Use the maximum of these two values as the problem's score.

3. **Hack Adjustments**:
   - Add 100 points for each successful hack.
   - Subtract 50 points for each unsuccessful hack.

4. **Final Output**:
   - The total score is guaranteed to be an integer, so we convert the final result to an integer and print it.

This approach efficiently computes the final score using precise arithmetic operations and ensures the result is accurate and formatted correctly.
