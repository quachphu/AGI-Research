The solution involves leveraging combinatorial insights to efficiently compute the result modulo \( 10^9 + 7 \).

### Approach
1. **Understanding Cyclic Permutations**: A permutation is cyclic if the graph constructed from it contains a cycle. The graph is formed by connecting each element to the nearest larger elements on both its left and right.
2. **Complementary Counting**: Instead of directly counting cyclic permutations, we count the acyclic permutations and subtract this from the total number of permutations. This is because it's easier to compute the number of acyclic permutations.
3. **Factorial and Modular Arithmetic**: The total number of permutations of length \( n \) is \( n! \). We use modular arithmetic to compute this efficiently for large \( n \).
4. **Acyclic Permutations**: The number of acyclic permutations is found to be \( 2^{n-1} \). This is derived from the observation that each element can be placed such that it forms a linear structure (either strictly increasing or decreasing), leading to a tree structure in the graph.

### Solution Code

```python
MOD = 10**9 + 7

n = int(input())

fact = 1
for i in range(2, n + 1):
    fact = fact * i % MOD

print(result)
```
