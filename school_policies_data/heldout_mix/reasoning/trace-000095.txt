To solve this problem, we need to efficiently answer multiple queries about the sum and difference of subarrays in a given list of natural numbers. Each query specifies a range, and we need to compute two values: the sum of all elements in the range and the difference starting from the end of the range and subtracting all previous elements in reverse order.

### Approach
1. **Prefix Sum Array**: Construct a prefix sum array to quickly compute the sum of any subarray in constant time. The prefix sum array helps in reducing the time complexity for sum queries from O(n) to O(1).
2. **Difference Calculation**: For each query, compute the difference by leveraging the prefix sum array. The difference can be derived using the sum of the subarray from the start of the range to just before the end and the last element of the range.

### Solution Code
```python
import sys

def main():
    data = sys.stdin.read().split()
    ptr = 0
    n = int(data[ptr])
    ptr += 1
    q = int(data[ptr])
    ptr += 1
    arr = list(map(int, data[ptr:ptr + n]))
    ptr += n
    
    prefix_sum = [0] * (n + 1)
    for i in range(1, n + 1):
        prefix_sum[i] = prefix_sum[i-1] + arr[i-1]
    
    output = []
    for _ in range(q):
        L = int(data[ptr])
        ptr += 1
        R = int(data[ptr])
        ptr += 1
        sum_val = prefix_sum[R] - prefix_sum[L-1]
        diff_val = (prefix_sum[R] - prefix_sum[R-1]) - (prefix_sum[R-1] - prefix_sum[L-1])
        output.append(f"{sum_val} {diff_val}")
    
    print('\n'.join(output))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once using `sys.stdin.read()` for efficiency, especially given the constraints.
2. **Prefix Sum Array Construction**: The prefix sum array is built such that each element at index `i` contains the sum of all elements from the start of the list up to index `i-1` (1-based index). This allows us to compute the sum of any subarray in constant time.
3. **Handling Queries**: For each query, the sum is computed using the prefix sum array. The difference is calculated by first isolating the last element of the range using the prefix sum array and then subtracting the sum of the preceding elements in the range.

This approach ensures that each query is answered in O(1) time, making the solution efficient even for the upper constraint limits.
