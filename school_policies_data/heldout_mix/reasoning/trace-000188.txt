To solve this problem, we need to move all chess pieces to cells of the same color (either all black or all white) on a 1×n chessboard with the minimum number of moves. Each move consists of shifting a piece one cell left or right without overlapping with other pieces.

### Approach
1. **Understand the Chessboard Layout**: The chessboard alternates colors starting with black. For an even-sized board, the black cells are at odd positions (1, 3, 5, ..., n-1) and white cells are at even positions (2, 4, 6, ..., n).

2. **Generate Target Positions**: Create lists of positions for black and white cells based on the given size `n`.

3. **Sort Input Positions**: The initial positions of the pieces are sorted to facilitate optimal pairing with target positions.

4. **Calculate Minimum Moves**: For each target color (black and white), compute the total number of moves required by pairing each sorted piece position with the corresponding sorted target position. The minimum of the two totals is the answer.

### Solution Code
```python
n = int(input())
pieces = list(map(int, input().split()))
pieces.sort()

black = list(range(1, n + 1, 2))
white = list(range(2, n + 1, 2))

sum_black = sum(abs(p - b) for p, b in zip(pieces, black))
sum_white = sum(abs(p - w) for p, w in zip(pieces, white))

print(min(sum_black, sum_white))
```

### Explanation
1. **Input Reading and Sorting**: The input size `n` and piece positions are read. The positions are sorted to ensure optimal pairing with target positions.

2. **Target Position Generation**: Using list comprehensions, we generate the positions for black and white cells. For example, if `n` is 6, black positions are [1, 3, 5] and white positions are [2, 4, 6].

3. **Move Calculation**: For each target color, we compute the total moves by summing the absolute differences between each sorted piece position and the corresponding target position. This is done using a zip of the sorted pieces and target positions.

4. **Result**: The minimum of the total moves required for black and white target positions is printed as the result.

This approach ensures that we efficiently determine the minimum moves required by leveraging sorted positions and optimal pairing, leading to an O(n log n) complexity due to sorting, which is efficient for the given constraints.
