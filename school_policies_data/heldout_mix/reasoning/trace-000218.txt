To solve this problem, we need to determine the minimum number of characters to delete from a string composed of '>' and '<' such that the remaining string can be reduced to a single character through a series of operations. The operations involve choosing a character and deleting either the next or previous character based on whether it's '>' or '<'.

### Approach
The key insight is that a string can be reduced to a single character if it starts with a '>' and all subsequent characters can be deleted by repeatedly choosing the first '>', or if it ends with a '<' and all preceding characters can be deleted by repeatedly choosing the last '<'. Thus, the solution involves finding the minimum deletions required to either:
1. Make the string start with the first occurrence of '>' followed by any characters.
2. Make the string end with the last occurrence of '<' preceded by any characters.

The minimum number of deletions required is the smaller of the two values calculated from the first occurrence of '>' and the last occurrence of '<'.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    if '>' not in s or '<' not in s:
        print(0)
        continue
    first_gt = s.index('>')
    last_lt = s.rfind('<')
    option1 = first_gt
    option2 = (n - 1) - last_lt
    print(min(option1, option2))
```

### Explanation
1. **Input Reading**: Read the number of test cases.
2. **Check for Uniform Characters**: If the string contains only '>' or only '<', it is already good, so no deletions are needed.
3. **Find Key Indices**: Determine the first occurrence of '>' (`first_gt`) and the last occurrence of '<' (`last_lt`).
4. **Calculate Deletions**: Compute the deletions needed to make the string start with the first '>' (`option1`) and to make the string end with the last '<' (`option2`).
5. **Output Result**: Print the minimum of the two calculated deletions for each test case.

This approach efficiently determines the minimum deletions by leveraging the positions of the first '>' and last '<', ensuring optimal performance even for the upper constraint limits.
