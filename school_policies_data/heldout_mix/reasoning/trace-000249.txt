To solve this problem, we need to track the number of displeased employees in a company structured as a tree after each day's event where an employee either goes on vacation or returns from one. An employee becomes displeased if the number of their subordinates on vacation exceeds their bearing limit while they are not on vacation themselves.

### Approach
1. **Tree Structure and Euler Tour**: Represent the company hierarchy using a tree. Perform an Euler Tour to assign in-time and out-time for each node, which helps in efficiently querying the number of subordinates (subtree) of each node using a Fenwick Tree (Binary Indexed Tree).

2. **Fenwick Tree**: Use a Fenwick Tree to maintain the count of employees on vacation. This allows efficient range updates and point queries to track the number of subordinates on vacation for each node.

3. **Event Processing**: For each event, update the Fenwick Tree to reflect the employee's vacation status change. Traverse the tree upwards from the affected employee to the root, updating the count of displeased employees based on their bearing limits and current vacation status.

sys.setrecursionlimit(1 << 25)

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n, m = int(input[ptr]), int(input[ptr+1])
    ptr +=2

    parents = [0]*(n+1)
    for i in range(2, n+1):
        parents[i] = int(input[ptr])
        ptr +=1

    t = list(map(int, input[ptr:ptr+n]))
    ptr +=n

    queries = list(map(int, input[ptr:ptr+m]))
    ptr +=m

    # Build the tree
    tree = [[] for _ in range(n+1)]
    for i in range(2, n+1):
        p = parents[i]
        tree[p].append(i)

    # Compute in_time and out_time using BFS
    in_time = [0]*(n+1)
    out_time = [0]*(n+1)
    time = 1
    stack = [(1, False)]
    while stack:
        node, visited = stack.pop()
        if visited:
            out_time[node] = time
            time +=1
            continue
        in_time[node] = time
        time +=1
        stack.append( (node, True) )
        # Push children in reverse order to process them in order
        for child in reversed(tree[node]):
            stack.append( (child, False) )

    class FenwickTree:
        def __init__(self, size):
            self.n = size
            self.tree = [0]*(self.n +2)

            while idx <= self.n:
                self.tree[idx] += delta
                idx += idx & -idx
        
        def query(self, idx):
            res =0
            while idx >0:
                res += self.tree[idx]
                idx -= idx & -idx
            return res
        
        def range_query(self, l, r):
            return self.query(r) - self.query(l-1)

        current_total = total

        # Process ancestors (parent path)
        current = parent[x]
        while current !=0:
            in_i = in_time[current]
            out_i = out_time[current]
            prev_cnt = fenwick.range_query(in_i+1, out_i)
            new_cnt = prev_cnt + delta

            if not on_vacation[current]:
                prev_state = prev_cnt > t[current-1]
                new_state = new_cnt > t[current-1]
                if prev_state != new_state:
                    if new_state:
                        current_total +=1
                    else:
                        current_total -=1
            current = parent[current]

        # Update Fenwick Tree
        fenwick.update(in_time[x], delta)

        # Toggle on_vacation
        on_vacation[x] = not previous_on_vacation

        # Process x's own status
        if is_adding:
            # Now on_vacation[x] is True, previously was False
            # Check if previous state was displeased
            prev_cnt_x = fenwick.range_query(in_time[x]+1, out_time[x])
            if prev_cnt_x > t[x-1] and not previous_on_vacation:
                current_total -=1
        else:
            # Now on_vacation[x] is False, previously was True
            # Check if current cnt is > t[x]
            cnt_x = fenwick.range_query(in_time[x]+1, out_time[x])
            if cnt_x > t[x-1]:
                current_total +=1

        total = current_total
        output.append(str(total))

    print(' '.join(output))

if __name__ == "__main__":
    main()

### Explanation
1. **Tree Construction**: The tree is built using the parent-child relationships provided in the input.
2. **Euler Tour**: This assigns in-time and out-time to each node, which helps in efficiently querying the subtree of any node.
3. **Fenwick Tree**: This data structure is used to maintain and query the count of employees on vacation efficiently.
4. **Event Handling**: For each event, we update the Fenwick Tree to reflect the vacation status change and traverse the tree upwards to check and update the displeased status of each ancestor based on their bearing limits and current vacation status.
5. **Output**: After processing all events, the result for each day is printed.

This approach ensures that we efficiently handle the subtree queries and updates using the Euler Tour and Fenwick Tree, making the solution feasible even for large input sizes.
