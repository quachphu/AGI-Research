To solve this problem, we need to determine the number of valid pairs of positions for a bishop and a PQ-knight on an NxM chessboard such that they do not attack each other. The solution involves calculating the total number of possible pairs and subtracting the pairs where the bishop and knight can attack each other.

### Approach

1. **Total Pairs Calculation**: The total number of pairs of different positions on the chessboard is calculated as \(N \times M \times (N \times M - 1)\).

2. **Bishop Attack Calculation**: A bishop attacks along diagonals. We compute the number of pairs where the bishop can attack the knight by considering the sum of squares of the number of cells on each diagonal. This is done for both sum diagonals (x + y = constant) and difference diagonals (x - y = constant). Due to symmetry, these sums are equal, allowing us to compute them once and double the result.

3. **Knight Attack Calculation**: The PQ-knight moves in 8 possible directions. For each valid knight move, we count the number of positions where the knight can attack the bishop.

4. **Overlap Consideration**: There is no overlap between bishop and knight attacks because a knight's move cannot place it on the same diagonal as the bishop.

### Solution Code

```python
MOD = 10**9 + 7

def main():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    M = int(input[1])
    P = int(input[2])
    Q = int(input[3])
    
    # Compute sum_a
    if N <= M:
        part1 = N * (N + 1) * (2 * N + 1) // 6
        part2 = N * N * (M - N)
        part3 = (N - 1) * N * (2 * N - 1) // 6
        sum_a = part1 + part2 + part3
    else:
        part1 = M * (M + 1) * (2 * M + 1) // 6
        part2 = M * M * (N - M)
        part3 = (M - 1) * M * (2 * M - 1) // 6
        sum_a = part1 + part2 + part3
    
    B_attacks_K = 2 * sum_a - 2 * N * M
    
    directions = [(P, Q), (P, -Q), (-P, Q), (-P, -Q),
                  (Q, P), (Q, -P), (-Q, P), (-Q, -P)]
    K_attacks_B = 0
    for dx, dy in directions:
        abs_dx = abs(dx)
        abs_dy = abs(dy)
        count_x = max(0, N - abs_dx)
        count_y = max(0, M - abs_dy)
        K_attacks_B += count_x * count_y
    
    total = N * M
    ans = (total * (total - 1) - (B_attacks_K + K_attacks_B)) % MOD
    print(ans)

if __name__ == "__main__":
    main()
```

### Explanation

1. **Total Pairs Calculation**: The total number of valid pairs is computed as \(N \times M \times (N \times M - 1)\).

2. **Bishop Attack Calculation**: Using mathematical formulas, we compute the sum of squares of the number of cells on each diagonal. This sum is derived for both sum and difference diagonals, which are found to be equal due to symmetry. The result is then adjusted to account for the total pairs.

3. **Knight Attack Calculation**: For each of the 8 possible knight moves, we determine the valid positions on the board and sum these contributions to get the total number of attacking pairs for the knight.

4. **Final Answer**: Subtract the attacking pairs from the total pairs and take the result modulo \(10^9 + 7\) to get the final answer. This approach efficiently handles large values of N, M, P, and Q using mathematical optimizations rather than brute force iteration.
