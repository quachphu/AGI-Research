To solve this problem, we need to split a binary string into the minimal number of substrings such that each substring is 'good'. A substring is considered good if it contains a different number of zeros and ones. 

### Approach
1. **Check the Entire String**: First, check if the entire string is already good. If it is, we can return it as a single substring.
2. **Split into Two Parts**: If the entire string is not good (i.e., it has an equal number of zeros and ones), we need to split it into two parts. We iterate through possible split points and find the first valid split where both resulting substrings are good. By the problem's constraints, such a split always exists.

### Solution Code
```python
n = int(input())
s = input()

count0 = s.count('0')
count1 = s.count('1')

if count0 != count1:
    print(1)
    print(s)
else:
    for k in range(1, n):
        first_part = s[:k]
        c0 = first_part.count('0')
        c1 = first_part.count('1')
        if c0 != c1:
            print(2)
            print(first_part, s[k:])
            break
```

### Explanation
1. **Check the Entire String**: We count the number of zeros and ones in the entire string. If they are different, the string itself is good, and we output it as a single substring.
2. **Find Valid Split**: If the string is not good, we look for the first valid split point. For each possible split point, we check if the first part is good. Once found, the second part is guaranteed to be good because the total counts of zeros and ones are equal, making the remaining part's counts different by the same difference as the first part. This ensures both parts are good, thus providing the minimal split into two substrings. 

This approach efficiently determines the minimal number of splits by leveraging the properties of binary strings and ensuring each substring meets the criteria.
