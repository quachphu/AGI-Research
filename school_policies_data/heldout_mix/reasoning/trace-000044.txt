To solve this problem, we need to determine the nearest checkpoint for each student based on Manhattan distance. If multiple checkpoints are equally close, the student should choose the checkpoint with the smallest index.

### Approach
1. **Input Reading**: Read the number of students (N) and checkpoints (M), followed by their respective coordinates.
2. **Distance Calculation**: For each student, calculate the Manhattan distance to each checkpoint. The Manhattan distance between two points \((x1, y1)\) and \((x2, y2)\) is given by \(|x1 - x2| + |y1 - y2|\).
3. **Determine Nearest Checkpoint**: For each student, iterate through all checkpoints to find the one with the smallest Manhattan distance. If multiple checkpoints have the same minimum distance, the checkpoint with the smallest index is selected by processing checkpoints in order from 1 to M.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    M = int(input[ptr])
    ptr += 1
    
    students = []
    for _ in range(N):
        a = int(input[ptr])
        ptr += 1
        b = int(input[ptr])
        ptr += 1
        students.append((a, b))
    
    checkpoints = []
    for _ in range(M):
        c = int(input[ptr])
        ptr += 1
        d = int(input[ptr])
        ptr += 1
        checkpoints.append((c, d))
    
    for a, b in students:
        min_dist = float('inf')
        best_index = -1
        for j in range(M):
            c, d = checkpoints[j]
            distance = abs(a - c) + abs(b - d)
            if distance < min_dist:
                min_dist = distance
                best_index = j + 1  # Checkpoints are 1-based
        print(best_index)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, and then parsed to extract the number of students, checkpoints, and their respective coordinates.
2. **Processing Each Student**: For each student, iterate through all checkpoints to compute the Manhattan distance. Track the minimum distance encountered and the corresponding checkpoint index.
3. **Checkpoint Index Handling**: Checkpoints are processed in the order they are given (from 1 to M). This ensures that if multiple checkpoints have the same minimum distance, the one encountered first (smallest index) is selected automatically.

This approach efficiently computes the nearest checkpoint for each student while adhering to the constraints and ensuring optimal performance given the problem limits.
