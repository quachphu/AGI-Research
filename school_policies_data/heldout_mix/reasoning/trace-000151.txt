To solve this problem, we need to count the number of rectangles and rhombuses from a list of parallelograms given by their side lengths and a diagonal. Each parallelogram is defined by two adjacent sides and one diagonal. 

### Approach
1. **Understanding the Problem**: 
   - A rectangle is a parallelogram where the diagonals are equal and can be checked using the Pythagorean theorem. Specifically, if the given diagonal squared equals the sum of the squares of the two adjacent sides, the parallelogram is a rectangle.
   - A rhombus is a parallelogram where all four sides are equal. This can be determined by checking if the two adjacent sides are equal.

2. **Conditions**:
   - For a rectangle, check if \(a^2 + b^2 = c^2\) where \(a\) and \(b\) are the side lengths and \(c\) is the diagonal.
   - For a rhombus, check if the two adjacent sides \(a\) and \(b\) are equal.

3. **Input Handling**: Read each line of input, split the values, and convert them to integers. Then apply the conditions to count rectangles and rhombuses.

### Solution Code
```python
import sys

def main():
    rectangles = 0
    rhombuses = 0
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        parts = line.split(',')
        a = int(parts[0].strip())
        b = int(parts[1].strip())
        c = int(parts[2].strip())
        if a**2 + b**2 == c**2:
            rectangles += 1
        if a == b:
            rhombuses += 1
    print(rectangles)
    print(rhombuses)

main()
```

### Explanation
1. **Reading Input**: The input is read line by line from standard input. Each line is stripped of leading/trailing whitespace and split by commas to extract the side lengths and diagonal.
2. **Checking Conditions**: For each line:
   - The rectangle condition is checked using the Pythagorean theorem.
   - The rhombus condition is checked by comparing the two adjacent side lengths.
3. **Output**: After processing all lines, the counts of rectangles and rhombuses are printed.

This approach ensures that we efficiently determine the type of each parallelogram using mathematical properties and straightforward comparisons, leading to an optimal solution.
