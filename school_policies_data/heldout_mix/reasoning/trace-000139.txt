To solve this problem, we need to determine the winner of a game where two players, Chandu and Daspal, take turns subtracting the greatest common divisor (gcd) from two given integers. The player who makes either of the integers zero wins the game. The solution involves simulating the game steps and determining the winner based on the number of moves taken.

### Approach
1. **Game Simulation**: Each player takes turns subtracting the gcd of the current values of the two integers. This process continues until one of the integers becomes zero.
2. **Move Counting**: Track the number of moves taken to reach a state where one of the integers becomes zero.
3. **Determine Winner**: The winner is determined by the parity of the number of moves. If the number of moves is odd, the first player wins; if even, the second player wins.

### Solution Code
```python
import sys
import math

def main():
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        x = int(input[idx])
        y = int(input[idx + 1])
        first_player = input[idx + 2]
        idx += 3
        
        count = 0
        current_x, current_y = x, y
        
        while True:
            g = math.gcd(current_x, current_y)
            new_x = current_x - g
            new_y = current_y - g
            count += 1
            if new_x == 0 or new_y == 0:
                break
            current_x, current_y = new_x, new_y
        
        if count % 2 == 1:
            winner = first_player
        else:
            winner = 'Daspal' if first_player == 'Chandu' else 'Chandu'
        
        print(winner)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, and then parsed into individual test cases.
2. **Simulating Moves**: For each test case, the game is simulated by repeatedly computing the gcd of the current integers, subtracting it from both integers, and counting the moves until one of the integers becomes zero.
3. **Determining the Winner**: The number of moves is checked for parity. If the count is odd, the first player (who started the game) wins; if even, the second player wins.

This approach efficiently determines the winner by simulating the game steps and leveraging the properties of gcd, ensuring an optimal and clear solution.
