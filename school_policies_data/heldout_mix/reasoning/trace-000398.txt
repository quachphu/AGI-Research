To solve this problem, we need to determine the largest natural number \( x \) such that Masha can construct every integer from 1 to \( x \) using the digits on the faces of her cubes. Each cube can be rotated to show any of its six faces, but the digits 6 and 9 are not interchangeable.

### Approach
1. **Input Reading**: Read the number of cubes and the digits on each face of each cube.
2. **Generate Possible Numbers**: For each possible combination of cubes (considering permutations to account for different orders), generate all valid numbers that can be formed. This includes:
   - 1-digit numbers (non-zero).
   - 2-digit numbers (using two different cubes, first digit non-zero).
   - 3-digit numbers (using three different cubes, first digit non-zero).
3. **Check Consecutive Numbers**: Starting from 1, check each consecutive number to see if it can be formed using the generated possible numbers. The largest \( x \) where all numbers from 1 to \( x \) are present is the answer.

### Solution Code
```python
import itertools

n = int(input())
cubes = [set(map(int, input().split())) for _ in range(n)]

possible = set()

# Generate all possible numbers from 1-digit, 2-digit, and 3-digit combinations
for k in range(1, 4):
    if k > n:
        break
    for perm in itertools.permutations(cubes, k):
        first_cube = perm[0]
        first_digits = [d for d in first_cube if d != 0]
        if not first_digits:
            continue
        if k == 1:
            for d in first_digits:
                possible.add(d)
        else:
            other_cubes = perm[1:]
            for digits in itertools.product(first_digits, *other_cubes):
                num = 0
                for d in digits:
                    num = num * 10 + d
                possible.add(num)

max_x = 0
current = 1
while True:
    if current in possible:
        max_x = current
        current += 1
    else:
        break

print(max_x if max_x != 0 else 0)
```

1. **Input Handling**: The input is read and each cube's faces are stored as a set for efficient lookup.
2. **Permutations and Combinations**: For each possible number of digits (1, 2, or 3), generate all permutations of the cubes. For each permutation, generate all valid numbers by considering all combinations of digits from the cubes, ensuring the first digit is non-zero.
3. **Consecutive Check**: Starting from 1, check each number sequentially to find the largest \( x \) such that all numbers from 1 to \( x \) can be formed. If a number is missing, the loop breaks and the result is printed.

This approach efficiently checks all possible numbers that can be formed using the cubes and ensures that we find the maximum consecutive sequence starting from 1.
