To solve this problem, we need to determine the minimum number of adjacent row or column swaps required to move the single '*' in a given odd-sized matrix to the center. The solution involves calculating the Manhattan distance from the current position of the '*' to the center of the matrix.

### Approach
1. **Identify the Position of '*'**: First, locate the position of the '*' in the matrix.
2. **Determine the Center**: For an odd-sized matrix of size `n`, the center is at the position `(n//2, n//2)`.
3. **Calculate Manhattan Distance**: The minimum number of swaps required is the sum of the absolute differences between the current row of '*' and the center row, and the current column of '*' and the center column. This is known as the Manhattan distance.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline().strip())
        matrix = [sys.stdin.readline().strip() for _ in range(n)]
        # Find the position of '*'
        r, c = -1, -1
        for i in range(n):
            for j in range(n):
                if matrix[i][j] == '*':
                    r, c = i, j
                    break
            if r != -1:
                break
        m = n // 2
        print(abs(r - m) + abs(c - m))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first line contains the number of test cases `t`. For each test case, the first line is the size of the matrix `n`, followed by `n` lines representing the matrix rows.
2. **Locating the '*'**: Iterate through each cell of the matrix to find the coordinates `(r, c)` where the '*' is located.
3. **Calculating the Center**: The center of the matrix is determined by integer division of `n` by 2.
4. **Manhattan Distance Calculation**: The result is computed as the sum of the absolute differences between the row and column indices of the '*' and the center. This gives the minimum number of adjacent swaps needed to move the '*' to the center.

This approach efficiently computes the required number of swaps in linear time relative to the size of the matrix, making it optimal for the given constraints.
