To solve this problem, we need to determine two values from Roy's activity log over N days: the maximum daily coding streak (X) and the longest coding streak that can span multiple consecutive days (Y). 

### Approach
1. **Compute Daily Metrics**: For each day, compute:
   - **Max Streak**: The longest sequence of consecutive 'C's within the day.
   - **Prefix**: The number of leading 'C's at the start of the day.
   - **Suffix**: The number of trailing 'C's at the end of the day.
   - **All C**: A flag indicating if the entire day consists of 'C's.

2. **Calculate X**: The maximum of all daily max streaks.

3. **Calculate Y**: Track the longest coding streak that can span multiple days by considering:
   - The combined streak from the end of a previous day and the start of the current day.
   - Accumulated streaks from consecutive days where each day is entirely composed of 'C's.

### Solution Code
```python
n = int(input())
days = []

for _ in range(n):
    s = input().strip()
    
    # Calculate prefix (leading C's)
    prefix = 0
    for c in s:
        if c == 'C':
            prefix += 1
        else:
            break
    
    # Calculate suffix (trailing C's)
    suffix = 0
    for c in reversed(s):
        if c == 'C':
            suffix += 1
        else:
            break
    
    # Calculate max streak within the day
    max_streak = 0
    current = 0
    for c in s:
        if c == 'C':
            current += 1
            if current > max_streak:
                max_streak = current
        else:
            current = 0
    
    all_c = (prefix == 1440)
    days.append((max_streak, prefix, suffix, all_c))

# Compute X: maximum daily streak
X = max(day[0] for day in days)

# Compute Y: maximum overall streak
Y = 0
prev_suffix = 0
current_max = 0

for day in days:
    ms, pre, suf, allc = day
    
    # Update current_max with the current day's max streak
    current_max = max(current_max, ms)
    
    # Check combining previous suffix with current prefix
    if prev_suffix > 0:
        combined = prev_suffix + pre
        current_max = max(current_max, combined)
    
    # Update previous suffix for next iteration
    if allc:
        prev_suffix += 1440
    else:
        prev_suffix = suf
    
    # Update current_max with the new prev_suffix if it's larger
    current_max = max(current_max, prev_suffix)

Y = current_max

print(X, Y)
```

### Explanation
1. **Reading Input**: The input is read and processed to extract each day's activity string.
2. **Daily Metrics Calculation**: For each day, we compute the prefix (leading 'C's), suffix (trailing 'C's), max streak of consecutive 'C's, and check if the entire day is composed of 'C's.
3. **Compute X**: The maximum value of the daily max streaks is determined.
4. **Compute Y**: By iterating through each day, we track the longest streak that can span multiple days by combining the suffix of the previous day with the prefix of the current day. If a day is entirely composed of 'C's, it contributes to extending the ongoing streak.

This approach efficiently computes both the maximum daily streak and the longest possible streak spanning multiple days using a combination of prefix, suffix, and accumulated values.
