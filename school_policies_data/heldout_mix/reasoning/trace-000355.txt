To solve this problem, we need to efficiently process a sequence of replacement operations on an array and compute the sum of the array after each operation. The challenge is to do this efficiently given the constraints, where a direct approach would be too slow.

### Approach
1. **Initial Sum Calculation**: Compute the initial sum of the array.
2. **Frequency Dictionary**: Maintain a frequency dictionary to keep track of the count of each element in the array.
3. **Processing Queries**: For each query, determine the count of the element to be replaced, update the sum based on the replacement, and adjust the frequency dictionary accordingly.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    A = list(map(int, input[ptr:ptr + N]))
    ptr += N
    Q = int(input[ptr])
    ptr += 1
    queries = []
    for _ in range(Q):
        B = int(input[ptr])
        C = int(input[ptr + 1])
        queries.append((B, C))
        ptr += 2
    
    current_sum = sum(A)
    freq = {}
    for num in A:
        if num in freq:
            freq[num] += 1
        else:
            freq[num] = 1
    
    output = []
    for B, C in queries:
        count = freq.get(B, 0)
        if count > 0:
            current_sum += (C - B) * count
            del freq[B]
            freq[C] = freq.get(C, 0) + count
        output.append(current_sum)
    
    print('\n'.join(map(str, output)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go and split into a list for easier processing.
2. **Initial Setup**: The initial sum of the array is computed, and a frequency dictionary is created to count occurrences of each element.
3. **Processing Each Query**:
   - For each query, check the count of the element to be replaced using the frequency dictionary.
   - If the element exists, update the sum by considering the difference between the new and old values multiplied by the count of the element.
   - Adjust the frequency dictionary to reflect the replacement: remove the old element and update the count of the new element.
4. **Output**: After processing all queries, the results are printed line by line.

This approach ensures that each query is processed in constant time on average, making the solution efficient even for large input sizes.
