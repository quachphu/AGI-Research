To solve this problem, we need to reconstruct a 3x3 magic square where the main diagonal elements are missing (represented by zeros). The goal is to determine these missing elements such that the sums of all rows, columns, and both main diagonals are equal.

### Approach
1. **Understanding Magic Squares**: A magic square has all rows, columns, and both main diagonals summing to the same value. The missing elements (zeros) are located on the main diagonal.
2. **Sum Calculation**: The sum of all non-diagonal elements in the given input is calculated. Since the sum of all elements in a magic square is three times the magic constant (S), the magic constant S can be derived from the sum of non-diagonal elements divided by 2.
3. **Determine Missing Elements**: Using the derived magic constant S, the missing diagonal elements are computed by subtracting the sum of the non-diagonal elements in their respective rows from S.

### Solution Code
```python
def restore_magic_square():
    matrix = []
    for _ in range(3):
        row = list(map(int, input().split()))
        matrix.append(row)
    
    # Calculate sum of non-diagonal elements
    sum_non_diag = (
        matrix[0][1] + matrix[0][2] +
        matrix[1][0] + matrix[1][2] +
        matrix[2][0] + matrix[2][1]
    )
    
    S = sum_non_diag // 2  # Magic constant
    
    # Calculate missing diagonal elements
    a = S - (matrix[0][1] + matrix[0][2])
    b = S - (matrix[1][0] + matrix[1][2])
    c = S - (matrix[2][0] + matrix[2][1])
    
    # Update the matrix with the calculated values
    matrix[0][0] = a
    matrix[1][1] = b
    matrix[2][2] = c
    
    # Print the restored magic square
    for row in matrix:
        print(' '.join(map(str, row)))

restore_magic_square()
```

4. **Missing Elements Calculation**: Each missing diagonal element is computed by subtracting the sum of the other two elements in its row from the magic constant S.
5. **Output**: The matrix is updated with the computed diagonal elements and printed.
