To solve this problem, we need to find the maximum sum of absolute differences between adjacent elements in all permutations of numbers from 1 to N. The solution involves deriving a formula based on the parity of N (whether N is even or odd) and handling a special case for N=1.

### Approach
1. **Special Case for N=1**: When N is 1, there are no adjacent elements, so the sum is considered 1 based on the problem's sample output.
2. **Even N**: For even values of N, the maximum sum can be calculated using the formula \((N^2 - 1) // 2\).
3. **Odd N (greater than 1)**: For odd values of N, the formula is adjusted to \((N^2 - 1) // 2 - 1\).

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    results = []
    for i in range(1, T + 1):
        N = int(input[i])
        if N == 1:
            results.append(1)
        elif N % 2 == 0:
            results.append((N * N - 1) // 2)
        else:
            results.append((N * N - 1) // 2 - 1)
    print('\n'.join(map(str, results)))

main()
```

### Explanation
- **Reading Input Efficiently**: The input is read all at once and split into a list for efficient processing, especially given the constraints where T can be up to 10,000.
- **Handling Each Test Case**: For each test case, we check the value of N:
  - If N is 1, we directly append 1 to the results.
  - If N is even, we use the formula \((N^2 - 1) // 2\).
  - If N is odd and greater than 1, we adjust the even formula by subtracting 1.
- **Output**: The results for all test cases are collected in a list and printed at once to minimize the number of I/O operations, which is efficient for large input sizes.

This approach ensures that each test case is processed in constant time O(1), making the solution efficient and scalable even for the upper limits of the input constraints.
