Here is a Python function that sorts a list of integers in ascending order using the bubble sort algorithm:

```python
def bubble_sort(lst):
    n = len(lst)

    for i in range(n):
        # Create a flag that will allow the function to terminate early if there's nothing left to sort
        swapped = False

        for j in range(0, n-i-1):
            # Swap elements if current element is greater than next
            if lst[j] > lst[j+1]:
                lst[j], lst[j+1] = lst[j+1], lst[j]
                swapped = True

        # If no two elements were swapped in inner loop, then the list is already sorted.
        if not swapped:
            break
            
    return lst
```

3. To find the new side length, we take the square root of the new area: sqrt(2S^2) = S * sqrt(2).
