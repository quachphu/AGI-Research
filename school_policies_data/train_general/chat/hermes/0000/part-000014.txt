class Stack:
    def __init__(self):
        self.items = []

    def push(self, item):
        self.items.append(item)

    def pop(self):
        if not self.is_empty():
            return self.items.pop()

    def peek(self):
        if not self.is_empty():
            return self.items[-1]

    def is_empty(self):
        return len(self.items) == 0

    def __str__(self):
        return str(self.items)


if __name__ == "__main__":
    stack = Stack()
    print("Is the stack empty? ", stack.is_empty())
    stack.push(1)
    stack.push(2)
    stack.push(3)
    print("Stack: ", stack)
    print("Peek: ", stack.peek())
    print("Pop: ", stack.pop())
    print("Stack after popping: ", stack)
    print("Is the stack empty? ", stack.is_empty())

```python
def longest_common_prefix(strs):
    if not strs:
        return ""
    
    shortest_str = min(strs, key=len)
    
    for i, char in enumerate(shortest_str):
        for other in strs:
            if other[i] != char:
                return shortest_str[:i]
            
    return shortest_str
```

This function works by first checking if the input list is empty. If it is, then there's no common prefix and we return an empty string.

If the list isn't empty, we find the shortest string in the list since the common prefix can't be longer than this string.

We then iterate over each character in the shortest string. For each character, we check if it matches the corresponding character in all other strings. If it doesn't, we've found the end of the common prefix and we return the substring up to this point.

If we make it through all characters without finding a mismatch, then the entire shortest string is the common prefix and we return it.
