To solve this problem, we need to process a list of names, count their occurrences, and output them in lexicographical (dictionary) order along with their respective counts. 

### Approach
1. **Reading Input Efficiently**: Given the constraint that the number of names can be up to 100,000, we read the input efficiently using `sys.stdin` to handle large input sizes quickly.
2. **Counting Occurrences**: Use a dictionary to keep track of the frequency of each name. This allows us to count occurrences in linear time, O(n), where n is the number of names.
3. **Sorting Names**: Once all names are read and counted, we sort the dictionary keys (names) lexicographically using Python's built-in `sorted()` function, which operates in O(n log n) time complexity.
4. **Output the Results**: Finally, iterate over the sorted list of names and print each name along with its count.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    counts = {}
    for _ in range(t):
        name = sys.stdin.readline().strip()
        counts[name] = counts.get(name, 0) + 1
    for name in sorted(counts):
        print(f"{name} {counts[name]}")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The first line is read to determine the number of names. Subsequent lines are read in a loop, each stripped of any leading/trailing whitespace.
2. **Counting Frequencies**: Each name's occurrence is tracked using a dictionary where the key is the name and the value is its count.
3. **Sorting and Outputting**: The dictionary keys (names) are sorted lexicographically. Each sorted name is then printed along with its count from the dictionary.

This approach ensures efficient handling of large input sizes and leverages Python's efficient sorting and dictionary operations to meet the problem constraints effectively.
