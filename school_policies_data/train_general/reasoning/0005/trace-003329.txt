To solve this problem, we need to decode a Borze code string into its corresponding ternary number. The Borze alphabet uses specific symbols to represent ternary digits: '.' for 0, '-.' for 1, and '--' for 2. The goal is to parse the input string and convert it into the correct sequence of digits.

### Approach
1. **Input Reading**: Read the input string which contains the Borze code.
2. **Iterative Parsing**: Process each character in the string iteratively:
   - If the current character is '.', it represents the digit 0.
   - If the current character is '-', check the next character to determine if it forms '-.' (digit 1) or '--' (digit 2).
3. **Index Management**: Adjust the index appropriately based on whether the parsed symbol is one or two characters long.
4. **Result Construction**: Collect the parsed digits and concatenate them to form the final result.

### Solution Code
```python
def decode_borze():
    s = input().strip()
    result = []
    i = 0
    while i < len(s):
        if s[i] == '.':
            result.append('0')
            i += 1
        else:
            if s[i+1] == '.':
                result.append('1')
            else:
                result.append('2')
            i += 2
    print(''.join(result))

decode_borze()
```

### Explanation
1. **Reading Input**: The function reads the input string and strips any leading or trailing whitespace.
2. **Processing Each Character**: Using a loop, the function processes each character in the string. If the current character is '.', it appends '0' to the result and moves to the next character. If the current character is '-', it checks the next character to determine if it forms '-.' (digit 1) or '--' (digit 2) and appends the corresponding digit to the result. The index is then adjusted by 2 to skip the next character since it has already been processed.
3. **Building the Result**: The parsed digits are collected in a list, which is then joined into a single string and printed as the final result.

This approach efficiently processes the Borze code in linear time, ensuring each character is examined exactly once, making it optimal for the given problem constraints.
