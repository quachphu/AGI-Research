To solve this problem, we need to determine the number of ways to swap two bits in a binary number `a` such that the bitwise OR of `a` and `b` changes. The solution involves categorizing each bit position based on the values of `a` and `b` and then counting valid swaps based on these categories.

### Approach
1. **Categorize Each Position**: Each position in `a` and `b` can be categorized into one of four types based on their bit values:
   - Type 0: `a` is 0 and `b` is 0.
   - Type 1: `a` is 0 and `b` is 1.
   - Type 2: `a` is 1 and `b` is 0.
   - Type 3: `a` is 1 and `b` is 1.

2. **Count Positions by Type**: Count the number of positions falling into each of the four types.

3. **Determine Valid Swaps**: A swap between two positions is valid if it changes the bitwise OR. Valid swaps occur between specific type pairs:
   - Swapping Type 0 with Type 2.
   - Swapping Type 0 with Type 3.
   - Swapping Type 1 with Type 2.

4. **Calculate Valid Pairs**: For each valid type pair, compute the number of valid swaps considering both same-type and different-type pairs.

### Solution Code
```python
n = int(input())
a = input().strip()
b = input().strip()

count = [0] * 4  # Types 0, 1, 2, 3

for ai, bi in zip(a, b):
    ai = int(ai)
    bi = int(bi)
    if ai == 0 and bi == 0:
        count[0] += 1
    elif ai == 0 and bi == 1:
        count[1] += 1
    elif ai == 1 and bi == 0:
        count[2] += 1
    else:
        count[3] += 1
```
