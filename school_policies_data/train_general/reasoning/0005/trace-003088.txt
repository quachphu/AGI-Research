To solve this problem, we need to determine if Sasha wins a game where he and Lena take turns removing exactly `k` sticks from either end of a row of `n` sticks. Sasha wins if he makes strictly more moves than Lena.

### Approach
The key insight is that each player removes exactly `k` sticks on their turn, which reduces the total number of sticks by `k` each time. The game ends when fewer than `k` sticks remain. The total number of moves possible is given by the integer division of `n` by `k`, denoted as `m = n // k`.

Sasha starts first, so if the total number of moves `m` is odd, Sasha will make one more move than Lena, resulting in a win. If `m` is even, both players will make the same number of moves, and Sasha will not win.

### Solution Code
```python
n, k = map(int, input().split())
m = n // k
print("YES" if m % 2 == 1 else "NO")
```

### Explanation
1. **Input Reading**: The code reads the integers `n` (number of sticks) and `k` (number of sticks to remove per turn).
2. **Compute Total Moves**: Calculate `m` as the integer division of `n` by `k`. This gives the total number of full turns possible.
3. **Determine Winner**: Check if `m` is odd. If it is, Sasha makes more moves and wins (print "YES"). Otherwise, Lena makes the same number of moves (print "NO").

This approach efficiently determines the winner using simple arithmetic operations, which handle even the maximum input sizes within the constraints.
