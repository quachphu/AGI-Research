### Approach
The key insight is to leverage modular arithmetic and properties of remainders. By processing the string from right to left, we can efficiently compute the remainders of substrings using dynamic programming. Here's the detailed approach:

1. **Modular Arithmetic**: For any number formed by a substring ending at position j, we can compute its remainder modulo 2019. This allows us to track how many times each remainder has been encountered using a counter.
2. **Right-to-Left Processing**: By processing the string from right to left, we can dynamically compute the remainder of the current substring using the remainder of the previous substring and the current digit. This avoids recomputation and ensures linear time complexity.
3. **Counter for Remainders**: We maintain a counter to keep track of how many times each remainder has been seen. This allows us to quickly determine how many valid substrings end at the current position by checking how many times the current remainder has been seen before.

def main():
    import sys
    from collections import defaultdict

    S = sys.stdin.read().strip()
    MOD = 2019
    counter = defaultdict(int)
    counter[0] = 1  # To handle the case where current_remainder is 0
    current_remainder = 0
    exponent = 1  # 10^k mod MOD, starting with k=0
    result = 0

    # Process each digit from right to left
    for digit in reversed(S):
        digit = int(digit)
        current_remainder = (current_remainder + digit * exponent) % MOD
        # Add the number of times this remainder has been seen before
        result += counter[current_remainder]
        # Increment the count for this remainder
        counter[current_remainder] += 1
        # Update exponent for next digit (multiply by 10 mod MOD)
        exponent = (exponent * 10) % MOD

    print(result)

if __name__ == "__main__":
    main()

   - The result is incremented by the count of the current remainder seen so far.
   - The count for the current remainder is incremented.
   - The power of 10 (exponent) is updated for the next digit.

This approach ensures that we efficiently count all valid substrings in linear time, O(N), where N is the length of the string, making it suitable for large inputs.
