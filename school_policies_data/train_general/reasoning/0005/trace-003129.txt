Consider an n by n chessboard. Its rows are numbered from 1 to n from the top to the bottom. Its columns are numbered from 1 to n from the left to the right. A cell on an intersection of x-th row and y-th column is denoted (x, y). The main diagonal of the chessboard is cells (x, x) for all 1 ≤ x ≤ n.

A permutation of \{1, 2, 3, ..., n\} is written on the main diagonal of the chessboard. There is exactly one number written on each of the cells. The problem is to partition the cells under and on the main diagonal (there are exactly 1+2+ … +n such cells) into n connected regions satisfying the following constraints:

  1. Every region should be connected. That means that we can move from any cell of a region to any other cell of the same region visiting only cells of the same region and moving from a cell to an adjacent cell. 
  2. The x-th region should contain cell on the main diagonal with number x for all 1≤ x≤ n. 
  3. The number of cells that belong to the x-th region should be equal to x for all 1≤ x≤ n. 
  4. Each cell under and on the main diagonal should belong to exactly one region. 

Input

The first line contains a single integer n (1≤ n ≤ 500) denoting the size of the chessboard.

The second line contains n integers p_1, p_2, ..., p_n. p_i is the number written on cell (i, i). It is guaranteed that each integer from \{1, …, n\} appears exactly once in p_1, ..., p_n.

Output

If no solution exists, output -1.

Otherwise, output n lines. The i-th line should contain i numbers. The j-th number on the i-th line should be x if cell (i, j) belongs to the the region with x cells.

3
2 3 1

3 3 1

To solve this problem, we need to partition the cells under and on the main diagonal of an n x n chessboard into n connected regions. Each region must meet specific constraints regarding size, connectivity, and inclusion of a main diagonal cell with a specific value.

### Approach
The approach involves the following steps:
1. **Input Reading**: Read the size of the chessboard and the permutation of numbers on the main diagonal.
2. **Initialization**: Create a 2D array to store the region assignments for each cell.
3. **Region Assignment**: Process each main diagonal cell from top to bottom. For each cell, expand the region by first moving downwards as much as possible and then to the left, ensuring connectivity and avoiding overlaps.
4. **Validation and Output**: If a valid partition is found, print the regions. If not, print `-1`.

### Solution Code
```python
n = int(input())
p = list(map(int, input().split()))

# We need to find for each x, the row i where p[i] = x (1-based)
# Convert to 0-based
perm = [0] * (n + 1)  # perm[x] gives the row index (0-based)
for i in range(n):
    perm[p[i]] = i

ans = [[0] * n for _ in range(n)]

for i in range(n):
    x = p[i]  # region size x
    current_row = i
    current_col = i
    ans[current_row][current_col] = x
    assigned = 1
    while assigned < x:
        next_row = current_row + 1
        if next_row < n and ans[next_row][current_col] == 0:
            ans[next_row][current_col] = x
            current_row = next_row
            assigned += 1
        else:
            current_col -= 1
            if current_col < 0 or ans[current_row][current_col] != 0:
                print(-1)
                exit()
            ans[current_row][current_col] = x
            assigned += 1

# Check if all cells under or on the diagonal are filled
for i in range(n):
    for j in range(i + 1):
        if ans[i][j] == 0:
            print(-1)
            exit()

# Output the result
for row in ans:
    # Only print up to the diagonal elements (i+1 elements for row i)
    output = []
    for j in range(len(row)):
        if j > row.index(row[j]):
            break
        output.append(str(row[j]))
    print(' '.join(output[:i+1 for i, r in enumerate(ans)][row.index(row[0])]))
```

### Explanation
1. **Input Reading**: The input consists of the size of the chessboard and the permutation of numbers on the main diagonal.
2. **Permutation Mapping**: Create an array to map each number to its corresponding row on the main diagonal.
3. **Region Expansion**: For each cell on the main diagonal, expand the region by first moving downward as much as possible and then to the left. This ensures connectivity and avoids overlapping regions.
4. **Validation**: After processing all regions, check if all cells under and on the main diagonal are assigned to a region. If any cell is unassigned, print `-1`.
5. **Output**: Print the regions row by row, ensuring each row contains the correct number of elements up to the main diagonal.

This approach ensures that each region is connected, meets the size requirement, and includes the correct main diagonal cell, providing a valid solution if one exists.
