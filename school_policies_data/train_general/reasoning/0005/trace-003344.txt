def main():

    n = int(sys.stdin.readline())
    matrix = []
    for _ in range(n):
        row = list(map(int, sys.stdin.readline().split()))
        matrix.append(row)
    cells = []
    for i in range(n):
        for j in range(n):
            cells.append( (matrix[i][j], i, j) )
    # Sort cells in increasing order of value
    cells.sort()
    dp = [[1]*n for _ in range(n)]
    # For each cell in order of increasing value
    for v, i, j in cells:
        # Check four directions
        for dx, dy in [ (-1,0), (1,0), (0,-1), (0,1) ]:
            x = i + dx
            y = j + dy
            if 0 <= x < n and 0 <= y < n:
                if matrix[x][y] < v:
                    dp[i][j] += dp[x][y]
                    dp[i][j] %= MOD
    total = 0
    for row in dp:
        total = (total + sum(row)) % MOD
    print(total % MOD)

To solve this problem, we need to count the total number of decreasing paths in an N x N matrix where each path can only move to adjacent cells with strictly smaller values. The result should be returned modulo \(10^9 + 7\).

### Approach
1. **Dynamic Programming (DP) Setup**: Use a DP matrix where `dp[i][j]` represents the number of decreasing paths starting from cell `(i, j)`.
2. **Sorting Cells**: Process cells in increasing order of their values. This ensures that when we process a cell, all cells with smaller values (which can be next steps in the path) have already been processed.
3. **Neighbor Check**: For each cell, check its four possible neighbors (up, down, left, right). If a neighbor has a smaller value, add its DP value to the current cell's DP value.
4. **Modulo Operation**: Since the result can be very large, use modulo \(10^9 + 7\) to keep the values manageable.

### Solution Code
```python
import sys

MOD = 10**9 + 7

def main():
    n = int(sys.stdin.readline())
    matrix = []
    for _ in range(n):
        row = list(map(int, sys.stdin.readline().split()))
        matrix.append(row)
    
    cells = []
    for i in range(n):
        for j in range(n):
            cells.append((matrix[i][j], i, j))
    
    cells.sort()
    
    dp = [[1] * n for _ in range(n)]
    
    for val, i, j in cells:
        for dx, dy in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
            x = i + dx
            y = j + dy
            if 0 <= x < n and 0 <= y < n:
                if matrix[x][y] < val:
                    dp[i][j] = (dp[i][j] + dp[x][y]) % MOD
    
    total = 0
    for row in dp:
        total = (total + sum(row)) % MOD
    
    print(total % MOD)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The matrix is read from standard input.
2. **Sorting Cells**: Cells are collected and sorted by their values to ensure processing in increasing order.
3. **DP Initialization**: Each cell starts with a DP value of 1, accounting for the path that starts and ends at the cell itself.
4. **Processing Cells**: For each cell, after sorting, check all four neighbors. If a neighbor has a smaller value, its DP value is added to the current cell's DP value.
5. **Summing Results**: The total number of paths is the sum of all values in the DP matrix, taken modulo \(10^9 + 7\).

This approach efficiently computes the number of paths by leveraging dynamic programming and careful ordering of processing steps, ensuring correctness and optimal performance.
