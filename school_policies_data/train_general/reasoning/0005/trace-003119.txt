To solve this problem, we need to compute the result of raising a given digit to a specified exponent and then determine the sum of the digits of the resulting number. The challenge involves handling very large numbers efficiently, which Python can manage using its arbitrary-precision integers.

### Approach
1. **Read Input**: The first input is the number of test cases. For each test case, we read the digit and the exponent.
2. **Compute Exponentiation**: For each test case, compute the result of raising the digit to the given exponent. If the exponent is 0, the result is always 1 (since any number raised to the power of 0 is 1).
3. **Sum the Digits**: Convert the result of the exponentiation to a string to easily iterate over each digit, convert each character back to an integer, and sum these integers.
4. **Output the Result**: Print the computed result and the sum of its digits for each test case.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    t = int(input[idx])
    idx += 1
    for _ in range(t):
        d = int(input[idx])
        e = int(input[idx + 1])
        idx += 2
        if e == 0:
            num = 1
        else:
            num = d ** e
        s = sum(int(c) for c in str(num))
        print(num, s)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input Efficiently**: The input is read all at once and split into a list for efficient processing, which is particularly useful for handling multiple test cases.
- **Handling Zero Exponent**: A special check is made for an exponent of 0, which directly sets the result to 1.
- **Arbitrary-Precision Integers**: Python's ability to handle very large integers ensures that even the result of 9^10000 is computed correctly.
- **String Conversion for Digit Sum**: Converting the result to a string allows easy iteration over each digit, which are then summed after converting back to integers.

This approach efficiently handles the constraints and leverages Python's features to manage large numbers and straightforward string manipulation for digit summation.
