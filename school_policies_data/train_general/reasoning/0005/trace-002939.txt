To solve this problem, we need to determine how many initial strings of length `n` can be compressed down to the single character "a" using a given set of operations. Each operation replaces the first two characters of the string with a single character if they match a specified pair.

### Approach
The approach involves working backwards from the target string "a" to build all possible initial strings of length `n` that can be transformed into "a" using the given operations. This is done by reversing the operations and expanding the string step by step from length 1 up to length `n`.

1. **Reverse Mapping of Operations**: Create a mapping from each resulting character to the list of two-character strings that can be replaced by it. This allows us to efficiently look up possible predecessors for each character during the expansion process.
2. **Dynamic Expansion**: Starting from the target string "a", iteratively expand each string of length `k` to possible strings of length `k+1` using the reverse mappings. This process continues until we reach strings of length `n`.
3. **Set Management**: Use sets to keep track of valid strings at each step to avoid duplicates and efficiently manage the expansion process.

### Solution Code
```python
from collections import defaultdict

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    q = int(input[idx])
    idx += 1
    
    reverse_map = defaultdict(list)
    for _ in range(q):
        ai = input[idx]
        bi = input[idx+1]
        idx += 2
        reverse_map[bi].append(ai)
    
    current_set = {'a'}
    for _ in range(n-1):
        next_set = set()
        for s in current_set:
            if len(s) < 1:
                continue
            first_char = s[0]
            for ai in reverse_map.get(first_char, []):
                new_s = ai + s[1:]
                next_set.add(new_s)
        current_set = next_set
        if not current_set:
            break  # No possible further steps
    
    print(len(current_set))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reverse Mapping**: The `reverse_map` dictionary maps each resulting character (bi) to a list of two-character strings (ai) that can be replaced by it. This allows us to efficiently look up possible predecessors for each character during the expansion process.
2. **Dynamic Expansion**: Starting with the target string "a", we iteratively expand each string of length `k` to possible strings of length `k+1` by prepending each valid two-character string (from the reverse mapping) to the current string (excluding its first character).
3. **Set Management**: By using sets to track valid strings at each step, we ensure that each string is processed only once, avoiding duplicates and ensuring efficient expansion.

This approach efficiently explores all possible valid initial strings by working backwards from the target, ensuring that we count all valid strings of length `n` that can be compressed to "a".
