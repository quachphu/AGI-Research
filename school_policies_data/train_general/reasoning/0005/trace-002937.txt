To solve this problem, we need to determine the number of ordered pairs (i, j) such that the characters at positions i and j in a given string S are the same. The solution involves efficiently counting the occurrences of each character and using these counts to compute the total number of valid pairs.

### Approach
1. **Count Character Frequencies**: First, we count how many times each character appears in the string. This can be efficiently done using a dictionary or a counter data structure.
2. **Calculate Pairs**: For each character, the number of valid ordered pairs (i, j) is the square of its frequency. This is because each occurrence of the character can pair with every other occurrence, including itself.
3. **Sum the Pairs**: Sum the squares of the frequencies of all characters to get the total number of valid ordered pairs.

This approach ensures an efficient O(N) time complexity, where N is the length of the string, making it suitable for large inputs up to 100,000 characters.

### Solution Code
```python
import sys
from collections import Counter

def count_pairs():
    s = sys.stdin.readline().strip()
    counts = Counter(s)
    total = sum(v * v for v in counts.values())
    print(total)

count_pairs()
```

### Explanation
1. **Reading Input**: The input string is read from standard input and stripped of any leading or trailing whitespace.
2. **Counting Frequencies**: Using `collections.Counter`, we count the occurrences of each character in the string. This provides a dictionary-like structure where keys are characters and values are their respective counts.
3. **Calculating Total Pairs**: For each character frequency, we compute the square of the count (since each occurrence can pair with every occurrence) and sum these values to get the total number of valid ordered pairs.
4. **Output Result**: The result is printed, which is the sum of squares of all character frequencies.

This method efficiently handles the problem constraints and provides the correct result by leveraging the properties of character frequencies and their contribution to ordered pairs.
