To solve this problem, we need to identify customers who have transactions in both the last month and the current month, sum their total transactions across both months, and output the results sorted by customer number. 

### Approach
1. **Read Input**: The input consists of two blocks separated by a blank line. The first block represents last month's transactions, and the second block represents this month's transactions.
2. **Process Data**: Convert each block of data into a dictionary where the keys are customer numbers and the values are the counts of transactions.
3. **Find Common Customers**: Identify customers present in both dictionaries.
4. **Sum Transactions**: For each common customer, sum their transaction counts from both months.
5. **Sort and Output**: Sort the results by customer number and print them.

### Solution Code
```python
import sys

def main():
    data = sys.stdin.read().split('\n')
    try:
        split_index = data.index('')
    except ValueError:
        split_index = len(data)
    
    last_month_lines = data[:split_index]
    this_month_lines = data[split_index+1:]
    
    last_counts = {}
    for line in last_month_lines:
        line = line.strip()
        if not line:
            continue
        c, d = line.split(',')
        customer = int(c)
        last_counts[customer] = last_counts.get(customer, 0) + 1
    
    this_counts = {}
    for line in this_month_lines:
        line = line.strip()
        if not line:
            continue
        c, d = line.split(',')
        customer = int(c)
        this_counts[customer] = this_counts.get(customer, 0) + 1
    
    common = set(last_counts.keys()) & set(this_counts.keys())
    
    result = []
    for c in sorted(common):
        total = last_counts[c] + this_counts[c]
        result.append((c, total))
    
    for c, total in result:
        print(f"{c} {total}")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read as a single string and split into lines. We then find the blank line separating the two months' data.
2. **Processing Each Month's Data**: For each month, we process each line to count transactions per customer using dictionaries. This helps in efficiently summing transactions and checking for common customers.
3. **Identifying Common Customers**: By finding the intersection of customer sets from both months, we determine which customers have transactions in both periods.
4. **Summing Transactions**: For each common customer, we sum their transaction counts from both months.
5. **Sorting and Output**: The results are sorted by customer number to ensure the output is in ascending order as required.

This approach efficiently handles up to the maximum constraint of 1,000 transactions per month with a time complexity of O(n), making it suitable for the problem's constraints.
