To solve this problem, we need to determine the minimum number of changes required to convert a given sequence of integers into a permutation of numbers from 1 to n. A permutation of numbers from 1 to n contains each integer exactly once.

### Approach
1. **Identify Valid Elements**: First, we need to identify the elements in the sequence that are within the valid range (1 to n). These elements are candidates for forming the permutation.
2. **Track Unique Elements**: Use a set to track unique elements within the valid range. This helps us determine how many unique valid elements are already present in the sequence.
3. **Calculate Missing Elements**: The number of elements missing from the permutation is the difference between n (the target size of the permutation) and the number of unique valid elements found in the sequence. This difference gives the minimum number of changes needed.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
valid_elements = set()
for num in a:
    if 1 <= num <= n:
        valid_elements.add(num)
print(n - len(valid_elements))
```

### Explanation
1. **Reading Input**: The input consists of an integer n followed by a sequence of integers.
2. **Filter Valid Elements**: We iterate through each number in the sequence and check if it lies within the range 1 to n. If it does, we add it to a set to ensure uniqueness.
3. **Determine Missing Elements**: The size of the set gives the count of unique valid elements. The difference between n and this count gives the number of elements missing from the permutation, which is the number of changes needed.

This approach efficiently tracks valid elements and uses a set to handle duplicates, ensuring that we count each valid element exactly once. The solution runs in O(n) time complexity, which is optimal for the given problem constraints.
