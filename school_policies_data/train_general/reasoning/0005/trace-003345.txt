To solve this problem, we need to find the largest possible substring of a given string that meets specific criteria. The substring must be both a prefix and a suffix of the string, and it must also appear in the middle of the string (not as a prefix) ending at or before a given position K.

### Approach
1. **Prefix and Suffix Identification**: Use the Longest Prefix Suffix (LPS) array from the Knuth-Morris-Pratt (KMP) algorithm to identify all possible substrings that are both prefixes and suffixes of the string. These substrings are potential candidates.
2. **Z-Array for Substring Occurrences**: Compute the Z-array to determine the lengths of the longest substrings starting at each position that match the prefix of the string. This helps in efficiently checking if a candidate substring appears in the middle of the string.
3. **Range Maximum Query (RMQ)**: Use a sparse table to quickly query the maximum value in a range of the Z-array. This allows us to efficiently check if a candidate substring appears within the required bounds (ending at or before position K).

def compute_lps(s):
    n = len(s)
    lps = [0] * n
    for i in range(1, n):
        j = lps[i-1]
        while j > 0 and s[i] != s[j]:
            j = lps[j-1]
        if s[i] == s[j]:
            j += 1
        lps[i] = j
    return lps

def compute_z(s):
    n = len(s)
    if n == 0:
        return []
    Z = [0] * n
    Z[0] = n
    l, r = 0, 0
    for i in range(1, n):

class SparseTable:
    def __init__(self, data):
        self.n = len(data)
        self.log_table = [0] * (self.n + 1)
        for i in range(2, self.n + 1):
            self.log_table[i] = self.log_table[i // 2] + 1
        self.max_level = self.log_table[self.n] + 1
