### Approach
1. **Check String Length**: First, verify if the length of the input string is at least 4. If it is shorter than 4 characters, it cannot start with 'YAKI', so the answer is immediately "No".
2. **Check Initial Substring**: If the string is at least 4 characters long, check if the first four characters are exactly 'YAKI'. If they are, the answer is "Yes"; otherwise, it is "No".

### Solution Code
```python
def main():
    s = input().strip()
    if len(s) >= 4 and s[:4] == 'YAKI':
        print("Yes")
    else:
        print("No")

main()
```

### Explanation
1. **Reading Input**: The input string is read and any leading or trailing whitespace is removed using `strip()`.
2. **Length Check**: The string length is checked to ensure it has at least 4 characters. This avoids errors when slicing the string and ensures we only proceed if there are enough characters to form 'YAKI'.
3. **Substring Check**: The first four characters of the string are compared to 'YAKI'. If they match, "Yes" is printed; otherwise, "No" is printed.

This approach efficiently combines two checks to determine the result, ensuring correctness and optimal performance given the problem constraints.
