To solve this problem, we need to determine the minimum time required for the Old Peykan to travel from the first city to the last city, considering that each city (except the last) provides a fuel supply that can be collected every k hours. The goal is to efficiently manage fuel stops and waiting times to minimize the total travel time.

### Approach
1. **Initial Setup**: Start at the first city with an initial fuel supply from that city.
2. **Fuel Management**: Track the current fuel level and the maximum fuel supply encountered so far. This helps in deciding the optimal city to wait for fuel refills.
3. **Travel Between Cities**: For each city, check if the current fuel is sufficient to travel to the next city. If not, calculate the required waiting time to collect enough fuel, considering the cooldown period k.
4. **Update Maximum Fuel Supply**: Whenever a city with a higher fuel supply is encountered, update the maximum supply value to optimize future fuel collections.

### Solution Code
```python
m, k = map(int, input().split())
d = list(map(int, input().split()))
s = list(map(int, input().split()))

current_fuel = 0
time = 0
max_s = 0

for i in range(m):
    current_fuel += s[i]
    if s[i] > max_s:
        max_s = s[i]
    distance = d[i]
    if current_fuel >= distance:
        time += distance
        current_fuel -= distance
    else:
        deficit = distance - current_fuel
        num = (deficit + max_s - 1) // max_s
        wait_time = num * k
        time += wait_time + distance
        current_fuel += num * max_s
        current_fuel -= distance

print(time)
```

### Explanation
1. **Reading Input**: The input values for the number of roads (m), cooldown period (k), distances between cities (d), and fuel supplies (s) are read.
2. **Initialization**: Variables to track current fuel, total time, and the maximum fuel supply encountered are initialized.
3. **Loop Through Cities**: For each city:
   - Add the city's fuel supply to the current fuel.
   - Update the maximum fuel supply if the current city's supply is higher.
   - Check if the current fuel is sufficient to travel to the next city. If yes, subtract the required fuel and add the travel time.
   - If fuel is insufficient, calculate the deficit and determine the number of waiting periods needed to collect enough fuel. Add the waiting time and travel time to the total time, adjust the current fuel accordingly.
4. **Output Result**: Print the total time after processing all cities.

This approach ensures that the Old Peykan always uses the highest possible fuel supply available up to the current city, minimizing waiting times and efficiently managing fuel stops to achieve the shortest travel time.
