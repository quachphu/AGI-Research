To solve this problem, we need to distribute apples and oranges into boxes such that each box has the same number of apples and oranges, and the number of boxes is maximized. The solution involves using the greatest common divisor (GCD) to determine the optimal distribution.

### Approach
1. **Understanding the Problem Requirements**: We need to ensure that each box has the same number of apples and oranges. The number of boxes must be the maximum possible.
2. **Key Insight**: The maximum number of boxes that can be used without violating the distribution conditions is determined by the GCD of the number of apples and oranges. This is because the GCD is the largest number that divides both quantities without leaving a remainder.
3. **Calculation**:
   - Compute the GCD of the number of apples (n) and oranges (m).
   - Divide the number of apples and oranges by this GCD to get the number of apples and oranges per box, respectively.

### Solution Code
```python
import math

def main():
    n, m = map(int, input().split())
    gcd = math.gcd(n, m)
    print(f"{n // gcd} {m // gcd}")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of two integers, n (apples) and m (oranges).
2. **Computing GCD**: Using Python's `math.gcd` function, we compute the GCD of n and m. This gives the maximum number of boxes that can evenly distribute both apples and oranges.
3. **Calculating Distribution**: By dividing the number of apples and oranges by their GCD, we determine how many apples and oranges each box will contain. This ensures each box has the same number of apples and oranges, and the number of boxes is maximized.

This approach efficiently solves the problem with a time complexity of O(log(min(n, m))), which is optimal for computing the GCD using the Euclidean algorithm.
