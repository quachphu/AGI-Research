To solve this problem, we need to determine if a subsegment of an array contains a subsequence that is a cyclic shift of a given permutation. The solution involves preprocessing the array to efficiently answer each query.

### Approach
1. **Understanding Cyclic Shifts**: A cyclic shift of a permutation can be viewed as a sequence of elements formed by rotating the permutation. For example, the permutation [2, 1, 3] has cyclic shifts [2, 1, 3], [1, 3, 2], and [3, 2, 1].

2. **Next Element Mapping**: For each element in the permutation, determine the next element in the cyclic order. This helps in tracking the required sequence elements in the array.

3. **Next Position Preprocessing**: For each element in the array, compute the next position where the subsequent element in the cyclic shift appears. This is done using a reverse traversal of the array to efficiently track occurrences.

4. **Binary Lifting**: Precompute the positions reachable in steps that are powers of two. This allows efficient computation of the position after (n-1) steps using a technique similar to binary exponentiation.

5. **Sparse Table for Range Minimum Query**: Build a sparse table to quickly find the minimum position reachable within a range, which helps in answering each query efficiently.

### Solution Code
```python
import sys

def main():
    sys.setrecursionlimit(1 << 25)
    n, m, q = map(int, sys.stdin.readline().split())
    p = list(map(int, sys.stdin.readline().split()))
    a = list(map(int, sys.stdin.readline().split()))
    queries = [tuple(map(int, sys.stdin.readline().split())) for _ in range(q)]
    
    if n == 1:
        print('1' * q)
        return
    
    next_element = {}
    for i in range(n):
        next_element[p[i]] = p[(i + 1) % n]
    
    next_pos = [m] * m
    last_occurrence = {}
    for i in range(m-1, -1, -1):
        x = a[i]
        y = next_element.get(x)
        if y is not None:
            next_pos[i] = last_occurrence.get(y, m)
        last_occurrence[x] = i
    
    max_level = 20
    lift = [[m] * m for _ in range(max_level)]
    for i in range(m):
        lift[0][i] = next_pos[i]
    for k in range(1, max_level):
        for i in range(m):
            if lift[k-1][i] == m:
                lift[k][i] = m
            else:
                lift[k][i] = lift[k-1][lift[k-1][i]]
    
    R = [m] * m
    for i in range(m):
        pos = i
        remaining = n - 1
        for j in range(max_level-1, -1, -1):
            if remaining >= (1 << j):
                if pos == m:
                    break
                pos = lift[j][pos]
                remaining -= (1 << j)
        R[i] = pos
    
    log_table = [0] * (m + 2)
    for i in range(2, m + 2):
        log_table[i] = log_table[i // 2] + 1
    max_log = log_table[m] + 1
    
    st = [[m] * m for _ in range(max_log)]
    for i in range(m):
        st[0][i] = R[i]
    for k in range(1, max_log):
        for i in range(m):
            if i + (1 << k) > m:
                st[k][i] = m
            else:
                st[k][i] = min(st[k-1][i], st[k-1][i + (1 << (k-1))])
    
    output = []
    for l, r in queries:
        l -= 1
        r -= 1
        if r - l + 1 < n:
            output.append('0')
            continue
        r_prime = r - (n - 1)
        if l > r_prime:
            output.append('0')
            continue
        length = r_prime - l + 1
        if length <= 0:
            min_val = R[l]
        else:
            k = log_table[length]
            if (1 << k) > length:
                k -= 1
            a1 = l
            a2 = r_prime - (1 << k) + 1
            if a2 < a1:
                min_val = st[k][a1]
            else:
                min_val = min(st[k][a1], st[k][a2])
        if min_val <= r:
            output.append('1')
        else:
            output.append('0')
    print(''.join(output))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Next Element Mapping**: For each element in the permutation, we determine the next element in the cyclic order.
2. **Next Position Calculation**: Using a reverse traversal of the array, we determine the next occurrence of each element's cyclic successor.
3. **Binary Lifting**: We precompute the positions reachable in steps of powers of two to efficiently compute the position after (n-1) steps.
4. **Sparse Table**: This structure allows us to quickly find the minimum reachable position within a range, enabling efficient query resolution.

This approach ensures that each query is answered in logarithmic time after an initial preprocessing phase, making it efficient even for large input sizes.
