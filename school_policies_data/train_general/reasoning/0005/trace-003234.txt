To solve this problem, we need to determine the maximum number of animals that can be accepted into DravDe's farm without any of them going hungry. Each animal arrives on a specific day and consumes food from that day until the end of the dream. The goal is to maximize the number of animals while ensuring the total food consumed does not exceed the given initial amount.

### Approach
1. **Calculate Food Consumption for Each Animal**: For each animal arriving on day `i`, compute the total food it will consume from its arrival day until the end of the dream. This is given by `c_i * (n - i)`, where `c_i` is the daily consumption of the animal arriving on day `i` (1-based index) and `(n - i)` is the number of days it will stay.

2. **Sort by Consumption**: Sort the calculated total consumption values in ascending order. This allows us to consider animals with the smallest total consumption first, maximizing the number of animals we can accept without exceeding the initial food supply.

3. **Greedy Selection**: Accumulate the sorted consumption values until the sum exceeds the initial food supply. The count of animals accepted just before exceeding the supply gives the maximum number of animals.

### Solution Code
```python
n, X = map(int, input().split())
c = list(map(int, input().split()))
costs = [c[i] * (n - i) for i in range(n)]
costs.sort()

total = 0
count = 0
for cost in costs:
    if total + cost <= X:
        total += cost
        count += 1
    else:
        break

print(count)
```

### Explanation
1. **Input Reading**: Read the number of days `n` and the initial food supply `X`, followed by the daily consumption values `c`.

2. **Cost Calculation**: For each day `i`, compute the total food required by an animal arriving on that day as `c[i] * (n - i)`. This gives the total consumption from day `i` to the end of the dream.

3. **Sorting**: Sort these computed values to prioritize animals with lower total consumption.

4. **Greedy Accumulation**: Iterate through the sorted costs, accumulating the total until it exceeds `X`. The number of animals accepted before this excess is the result.

This approach ensures we maximize the number of animals while adhering to the food constraint, efficiently solving the problem using sorting and a greedy algorithm.
