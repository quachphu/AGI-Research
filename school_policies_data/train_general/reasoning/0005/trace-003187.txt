To solve this problem, we need to efficiently handle multiple queries on a binary matrix, including row flips, column flips, and calculating the unusual square of the matrix. The unusual square is defined as the sum of the dot products of each row with its corresponding column, all computed modulo 2. 

### Approach
1. **Understanding the Unusual Square**: The key insight is that the unusual square of a matrix in GF(2) (where all operations are modulo 2) simplifies to the sum of the diagonal elements modulo 2. This is because cross terms (i ≠ j) cancel out when summed modulo 2.
  
2. **Efficient Query Handling**: Instead of recalculating the matrix after each flip, we track the parity (even or odd) of the number of flips for rows and columns. Each row flip or column flip toggles the parity of the respective row or column. The sum of the diagonal elements modulo 2 can be maintained using these parities.

3. **Optimization**: By maintaining the parity of row and column flips, we can compute the result for each query in constant time O(1). This allows us to handle up to 1 million queries efficiently.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    initial_sum = 0
    for i in range(n):
        row = list(map(int, sys.stdin.readline().split()))
        initial_sum += row[i]
    initial_sum %= 2
    q = int(sys.stdin.readline())
    sum_r = 0
    sum_c = 0
    res = []
    for _ in range(q):
        query = sys.stdin.readline().split()
        if query[0] == '1':
            sum_r ^= 1
        elif query[0] == '2':
            sum_c ^= 1
        elif query[0] == '3':
            res.append(str((initial_sum + sum_r + sum_c) % 2))
    print(''.join(res))

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The matrix is read and the initial sum of the diagonal elements modulo 2 is computed.
2. **Handling Queries**: For each query:
   - **Row Flip (1 i)**: Toggle the parity of row flips.
   - **Column Flip (2 i)**: Toggle the parity of column flips.
   - **Unusual Square Query (3)**: Compute the result using the initial sum and the current parities of row and column flips.
3. **Output**: Collect results for all type 3 queries and print them as a single string.

This approach ensures that each query is processed in constant time, making the solution efficient even for large inputs.
