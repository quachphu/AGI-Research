To solve this problem, we need to determine the minimum number of character changes required in a string S such that another string T becomes a substring of S. A substring is a consecutive sequence of characters within a string. The goal is to find the optimal position in S where T can fit with the least modifications.

### Approach
1. **Understand the Problem Requirements**: We need to check each possible starting position in S where T can fit as a substring. For each position, we compare the substring of S (of the same length as T) with T and count the number of differing characters.
2. **Iterate Over Possible Positions**: For each valid starting position in S (from 0 to len(S) - len(T)), extract the substring of S starting at that position with the same length as T.
3. **Count Differences**: For each extracted substring, count how many characters differ from the corresponding characters in T.
4. **Track Minimum Changes**: Keep track of the minimum number of changes required across all possible positions.

### Solution Code
```python
def main():
    S = input().strip()
    T = input().strip()
    len_s = len(S)
    len_t = len(T)
    min_changes = len_t  # Initialize with the maximum possible changes

    for i in range(len_s - len_t + 1):
        substr = S[i:i+len_t]
        current_changes = sum(a != b for a, b in zip(substr, T))
        if current_changes < min_changes:
            min_changes = current_changes

    print(min_changes)

main()
```

### Explanation
1. **Reading Input**: The input strings S and T are read from standard input.
2. **Initialization**: The variable `min_changes` is initialized to the length of T, which is the worst-case scenario where all characters need to be changed.
3. **Loop Through Positions**: The loop iterates over each possible starting index in S where a substring of length equal to T can be extracted.
4. **Extract and Compare Substrings**: For each starting index, the substring of S is extracted and compared character by character with T. The number of differing characters is counted using a generator expression.
5. **Update Minimum Changes**: The minimum number of changes is updated whenever a smaller count is found.
6. **Output Result**: The result is printed, which is the minimum number of changes required.

This approach ensures that we efficiently check all possible positions where T can be a substring of S and find the optimal solution with minimal computational overhead.
