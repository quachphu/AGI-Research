To solve this problem, we need to determine if it's possible to reduce all elements of an array to zero using specific operations. The allowed operations are selecting an integer k (1 ≤ k ≤ n) and then either decrementing the first k elements or the last k elements by 1. 

### Approach
The key insight is to model the problem using two sequences, x and y, where:
- `x[i]` represents the number of prefix operations (decrementing the first k elements) of size at least i+1.
- `y[i]` represents the number of suffix operations (decrementing the last k elements) of size at least (n-i).

The sequences must satisfy:
1. `x` is non-increasing.
2. `y` is non-decreasing.
3. `x[i] + y[i] = a[i]` for all i.

The algorithm processes the array from left to right, maintaining the maximum possible values for `x` while ensuring that `y` remains non-negative and non-decreasing. If at any point the constraints are violated, the answer is "NO".

### Solution Code
```python
import sys

def can_zero_array():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline().strip())
        a = list(map(int, sys.stdin.readline().split()))
        if n == 1:
            print("YES")
            continue
        possible = True
        x_prev = a[0]
        for i in range(1, n):
            current_x = min(x_prev, a[i] - a[i-1] + x_prev)
            if current_x < 0:
                possible = False
                break
            y_i = a[i] - current_x
            if y_i < 0:
                possible = False
                break
            x_prev = current_x
        print("YES" if possible else "NO")

can_zero_array()
```
