To solve this problem, we need to determine the minimum number of packages Polycarp needs to buy to get exactly `n` shovels, given that he can only use packages of a single type available in sizes from 1 to `k`.

### Approach
1. **Key Insight**: The optimal solution is to use the largest possible package size that divides `n` exactly. This minimizes the number of packages required.
2. **Divisors Check**: For each test case, check if `k` is greater than or equal to `n`. If so, the answer is 1 because we can use a single package of size `n`.
3. **Finding Divisors**: If `k` is smaller than `n`, iterate through possible divisors up to the square root of `n` to find the largest divisor of `n` that is less than or equal to `k`. This ensures we efficiently check all potential divisors without redundant calculations.

### Solution Code
```python
import math

def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    t = int(data[0])
    index = 1
    for _ in range(t):
        n = int(data[index])
        k = int(data[index + 1])
        index += 2
        if k >= n:
            print(1)
        else:
            max_div = 1
            sqrt_n = math.isqrt(n)
            for i in range(1, sqrt_n + 1):
                if n % i == 0:
                    if i <= k and i > max_div:
                        max_div = i
                    j = n // i
                    if j <= k and j > max_div:
                        max_div = j
            print(n // max_div)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Handling Each Test Case**: For each test case, we check if `k` is at least `n`. If true, the answer is 1 since we can use a single package of size `n`.
3. **Finding Divisors Efficiently**: By iterating up to the square root of `n`, we efficiently check all potential divisors. For each divisor `i`, both `i` and `n/i` are checked to ensure we find the maximum valid divisor within the range [1, k].
4. **Output the Result**: The result for each test case is the quotient of `n` divided by the largest valid divisor found, ensuring the minimum number of packages.

This approach efficiently narrows down the possible divisors and ensures we find the optimal solution in a time complexity of O(√n) per test case, making it suitable for large values of `n` and `k`.
