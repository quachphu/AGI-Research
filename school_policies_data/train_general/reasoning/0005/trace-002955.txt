To solve this problem, we need to determine the highest possible score achievable by removing elements from an array according to specific rules. Each removal of an element gives points based on the product of its adjacent elements, and the goal is to maximize the total points accumulated through optimal removal order.

### Approach
The problem can be efficiently solved using dynamic programming (DP). The key insight is to consider the optimal subproblems where we compute the maximum points for subarrays and build up the solution incrementally. The approach is similar to the "burst balloons" problem, where we consider each element as the last to be removed, allowing us to split the problem into smaller subproblems.

1. **Dynamic Programming State Definition**:
   - Define `dp[left][right]` as the maximum points obtainable by removing all elements between indices `left` and `right` (exclusive), with `left` and `right` as the boundaries.

2. **Recurrence Relation**:
   - For each subarray defined by boundaries `left` and `right`, consider each possible element `k` (between `left` and `right`) as the last element to be removed. The points for removing `k` last will be the product of the elements at `left` and `right`, plus the points from the left and right subproblems.

3. **Base Case**:
   - If there are no elements between `left` and `right`, the points are zero.

4. **Filling the DP Table**:
   - Fill the DP table by considering all possible subarray lengths starting from the smallest to the largest, ensuring that we solve smaller subproblems before larger ones.

### Solution Code
```python
n = int(input())
arr = list(map(int, input().split()))
dp = [[0] * n for _ in range(n)]

for l in range(2, n):
    for left in range(n - l):
        right = left + l
        max_score = 0
        for k in range(left + 1, right):
            current = dp[left][k] + dp[k][right] + arr[left] * arr[right]
            if current > max_score:
                max_score = current
        dp[left][right] = max_score

print(dp[0][n-1])
```

### Explanation
1. **Reading Input**:
   - The first line reads the size of the array `n`.
   - The second line reads the array elements.

2. **DP Table Initialization**:
   - A 2D DP table `dp` is initialized with zeros, where `dp[left][right]` will store the maximum points for the subarray from `left` to `right`.

3. **Filling the DP Table**:
   - Iterate over all possible subarray lengths starting from 2 up to `n-1`.
   - For each subarray length, iterate over all possible starting indices `left`.
   - For each subarray defined by `left` and `right`, iterate over all possible middle indices `k` to consider each element as the last to be removed.
   - Update `dp[left][right]` with the maximum points obtained by considering each `k` as the last element to be removed.

4. **Output the Result**:
   - The result is stored in `dp[0][n-1]`, which represents the maximum points for the entire array from index 0 to `n-1`.

This approach ensures that we efficiently compute the maximum points using dynamic programming, leveraging optimal substructure and overlapping subproblems properties to achieve a time complexity of O(n^3), which is feasible for the given constraint (n ≤ 50).
