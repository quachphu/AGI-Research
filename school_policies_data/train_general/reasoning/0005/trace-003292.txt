To solve this problem, we need to find two non-negative integers X and Y that satisfy the conditions X + Y = A and X XOR Y = B, with X being the smallest possible value. If no such pair exists, we should return -1.

### Approach
1. **Check Validity of Input**: 
   - If A is less than B, it's impossible to find such X and Y, so return -1.
   - Calculate the difference between A and B. If this difference is odd, return -1 because the difference must be even for valid solutions.

2. **Calculate Potential Values**:
   - Compute C as half of the difference between A and B. This C represents the common bits that X and Y share.
   - Check if the bits in C and B overlap. If they do, return -1 because valid X and Y cannot have overlapping bits in their common part and their XOR result.

3. **Determine X and Y**:
   - If all conditions are met, X is C and Y is derived as A - C.

### Solution Code
```python
A = int(input())
B = int(input())

if A < B or (A - B) % 2 != 0:
    print(-1)
else:
    C = (A - B) // 2
    if (C & B) != 0:
        print(-1)
    else:
        print(C, A - C)
```

### Explanation
1. **Input Validity Check**: The first check ensures that A is not less than B, and the second check ensures the difference (A - B) is even. These checks are necessary because an odd difference or A being less than B makes it impossible to find valid X and Y.

2. **Common Bits Calculation**: The value C is derived from the difference divided by 2. This represents the common bits in X and Y. For X and Y to exist, C and B must not share any bits, which is checked using a bitwise AND operation.

3. **Result Calculation**: If all checks pass, the smallest X is C, and Y is computed as A - C, ensuring both conditions (sum and XOR) are satisfied.

This approach efficiently determines the existence of valid X and Y using bitwise operations and mathematical properties, ensuring optimal performance even for large input values.
