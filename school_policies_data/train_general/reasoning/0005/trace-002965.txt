To solve this problem, we need to validate a password string based on specific criteria. The password must meet all the following conditions to be considered valid: it should be at least 6 characters long, contain at least one digit, one uppercase letter, and one lowercase letter.

### Approach
1. **Check Length**: The password must be at least 6 characters long. If it is shorter, it is immediately invalid.
2. **Check for Digits**: The password must contain at least one digit (0-9).
3. **Check for Uppercase Letters**: The password must contain at least one uppercase letter (A-Z).
4. **Check for Lowercase Letters**: The password must contain at least one lowercase letter (a-z).

The approach involves checking each condition sequentially. If all conditions are satisfied, the password is valid; otherwise, it is invalid.

### Solution Code
```python
def validate_password():
    password = input().strip()
    if len(password) < 6:
        print("INVALID")
        return
    has_upper = any(c.isupper() for c in password)
    has_lower = any(c.islower() for c in password)
    has_digit = any(c.isdigit() for c in password)
    if has_upper and has_lower and has_digit:
        print("VALID")
    else:
        print("INVALID")

validate_password()
```

### Explanation
1. **Reading Input**: The password is read from standard input and any leading or trailing whitespace is removed using `strip()`.
2. **Length Check**: The length of the password is checked first. If it is less than 6 characters, the function immediately prints "INVALID" and exits.
3. **Character Checks**: Using generator expressions with `any()`, the function checks for the presence of at least one uppercase letter, one lowercase letter, and one digit. These checks are efficient as they short-circuit upon finding the first occurrence of the required character type.
4. **Final Validation**: If all checks (length, uppercase, lowercase, digit) pass, the password is valid and "VALID" is printed. Otherwise, "INVALID" is printed.

This approach ensures that all conditions are checked in an efficient manner, making the solution both optimal and easy to understand.
