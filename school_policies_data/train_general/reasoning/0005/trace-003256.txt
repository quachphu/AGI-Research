### Approach
1. **Input Reading**: Read the input string which is guaranteed to be a 4-digit sequence.
2. **Check YYMM Validity**: The last two digits of the string must form a valid month (01-12).
3. **Check MMYY Validity**: The first two digits of the string must form a valid month (01-12).
4. **Determine Result**: Based on the validity checks, determine if the string is valid in YYMM, MMYY, both (AMBIGUOUS), or neither (NA).

### Solution Code
```python
def main():
    s = input().strip()
    # Check YYMM validity: last two digits as month
    yy_part_month = int(s[2:])
    is_yy_valid = 1 <= yy_part_month <= 12
    # Check MMYY validity: first two digits as month
    mm_part_month = int(s[:2])
    is_mm_valid = 1 <= mm_part_month <= 12
    
    if is_yy_valid and is_mm_valid:
        print("AMBIGUOUS")
    elif is_yy_valid:
        print("YYMM")
    elif is_mm_valid:
        print("MMYY")
    else:
        print("NA")

main()
```

### Explanation
1. **Reading Input**: The input string `s` is read and stripped of any surrounding whitespace.
2. **YYMM Check**: The substring from the 3rd to the 4th character (indices 2 and 3) is converted to an integer and checked if it lies between 1 and 12, inclusive.
3. **MMYY Check**: The substring from the 1st to the 2nd character (indices 0 and 1) is converted to an integer and similarly checked for validity as a month.
4. **Result Determination**: Based on the validity results:
   - If both checks are valid, print "AMBIGUOUS".
   - If only YYMM is valid, print "YYMM".
   - If only MMYY is valid, print "MMYY".
   - If neither is valid, print "NA".

This approach ensures that all possible cases are covered efficiently with minimal computational overhead, making it both clear and effective.
