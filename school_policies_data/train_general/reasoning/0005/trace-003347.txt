To solve this problem, we need to split a given string into exactly K parts such that each part's integer value does not exceed a given value Z, and the sum of these parts is maximized. If it's not possible to split the string under these constraints, we should return -1.

### Approach
1. **Dynamic Programming (DP) Setup**: Use a DP table where `dp[i][j]` represents the maximum sum achievable by splitting the first `i` characters of the string into `j` parts.
2. **Precomputation**: For each possible substring of the given string, precompute its integer value and check if it is valid (i.e., <= Z).
3. **DP Transition**: For each position and each possible number of parts, check all possible previous splits to determine the maximum sum.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        K = int(input[idx])
        Z = int(input[idx + 1])
        idx += 2
        s = input[idx]
        idx += 1
        n = len(s)
        if K > n:
            print(-1)
            continue
        
        # Precompute valid and value arrays
        valid = [[False] * n for _ in range(n)]
        value = [[0] * n for _ in range(n)]
        for a in range(n):
            for b in range(a, n):
                substr = s[a:b+1]
                num = int(substr)
                value[a][b] = num
                valid[a][b] = (num <= Z)
        
        # Initialize DP
        INF = float('-inf')
        dp = [[INF] * (K + 1) for _ in range(n + 1)]
        dp[0][0] = 0
        
        for i in range(1, n + 1):
            for j in range(1, K + 1):
                for k in range(i):
                    if j - 1 >= 0 and dp[k][j-1] != INF:
                        a, b = k, i - 1
                        if valid[a][b]:
                            current = dp[k][j-1] + value[a][b]
                            if current > dp[i][j]:
                                dp[i][j] = current
        
        result = dp[n][K]
        print(result if result != INF else -1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Edge Case Handling**: If the number of parts K is greater than the length of the string, it's immediately impossible to split, so we return -1.
3. **Precomputation**: For each substring, compute its integer value and check if it is valid (<= Z). This helps in quickly determining valid splits during the DP transitions.
4. **Dynamic Programming**: The DP table `dp` is filled by considering all possible previous splits and checking if the current substring from the previous split to the current position is valid. The maximum sum is updated accordingly.
5. **Result Extraction**: After filling the DP table, the result for each test case is found at `dp[n][K]`, which gives the maximum sum for splitting the entire string into K valid parts. If this value is still negative infinity, it means no valid split was found, so we return -1.

This approach efficiently handles the constraints and ensures that we maximize the sum while adhering to the given conditions.
