To solve this problem, we need to transform an array into a strictly increasing sequence with the minimum number of operations. Each operation involves incrementing or decrementing an element by 1, and the goal is to minimize the total number of such operations.

### Approach
1. **Problem Transformation**: Convert the problem of making the array strictly increasing into a problem of making a transformed array non-decreasing. This transformation is achieved by subtracting the index from each element, i.e., for each element `a[i]`, compute `a'[i] = a[i] - i`.
2. **Max-Heap Utilization**: Use a max-heap to track the maximum value of the transformed array up to the current index. This helps in efficiently determining the minimum number of operations needed to maintain the non-decreasing property.
3. **Greedy Adjustment**: For each element in the transformed array, if it is smaller than the current maximum value in the heap, adjust the maximum value to the current element's value, accumulating the cost of this adjustment.

### Solution Code
```python
import heapq

n = int(input())
a = list(map(int, input().split()))
a_prime = [a[i] - i for i in range(n)]

heap = []
cost = 0

for num in a_prime:
    heapq.heappush(heap, -num)
    if num < -heap[0]:
        removed = -heapq.heappop(heap)
        cost += removed - num
        heapq.heappush(heap, -num)

print(cost)
```

### Explanation
1. **Transformation**: Convert the original array into a new array `a'` where each element `a'[i] = a[i] - i`. This transformation allows us to convert the problem of making the original array strictly increasing into making the transformed array non-decreasing.
2. **Max-Heap Handling**: Use a max-heap (simulated using a min-heap with negative values) to keep track of the maximum value encountered so far in the transformed array. This helps in efficiently determining the necessary adjustments.
3. **Adjustment and Cost Calculation**: For each element in the transformed array, if it is smaller than the current maximum value in the heap, adjust the maximum value down to the current element's value. The cost of this adjustment is accumulated, ensuring the minimum number of operations.

This approach efficiently maintains the non-decreasing property of the transformed array using a heap, ensuring optimal performance and correctness. The overall time complexity is O(n log n) due to heap operations, making it suitable for large input sizes up to 3000 elements.
