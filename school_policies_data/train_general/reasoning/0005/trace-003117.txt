### Approach
1. **Same Position Check**: If Chris and Rihanna are at the same coordinates, no moves are needed.
2. **Parity Check**: The sum of the coordinates (x + y) for both Chris and Rihanna must have the same parity (both even or both odd). If they don't, it's impossible for Chris to reach Rihanna.
3. **Same Diagonal Check**: If Chris and Rihanna are on the same diagonal (either the same difference x - y or the same sum x + y), Chris can reach Rihanna in one move.
4. **Two Moves Check**: If the above conditions are not met but the parity is the same, Chris can reach Rihanna in two moves.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        n = int(input[ptr])
        ptr += 1
        x1 = int(input[ptr])
        y1 = int(input[ptr + 1])
        x2 = int(input[ptr + 2])
        y2 = int(input[ptr + 3])
        ptr += 4
        
        if x1 == x2 and y1 == y2:
            print(0)
            continue
        
        sum1 = x1 + y1
        sum2 = x2 + y2
        
        if (sum1 % 2) != (sum2 % 2):
            print(-1)
            continue
        
        if (x1 - y1 == x2 - y2) or (sum1 == sum2):
            print(1)
        else:
            print(2)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once for efficiency, especially given the large number of test cases (up to 50,000).
2. **Same Position Check**: Directly check if the coordinates are the same.
3. **Parity Check**: The sum of the coordinates' parity (even or odd) must match for a valid path.
4. **Diagonal Check**: Determine if the points lie on the same diagonal by checking either the difference (x - y) or the sum (x + y) of their coordinates.
5. **Output Result**: Based on the checks, output the minimum number of moves (0, 1, 2) or -1 if unreachable.

This approach ensures that we efficiently determine the minimum moves required using mathematical checks without iterating over the grid, making it suitable for very large grid sizes.
