To solve this problem, we need to determine the maximum possible sum of an unknown integer sequence A of length N, given a known sequence B of length N-1 such that each element B_i is greater than or equal to the maximum of the corresponding elements A_i and A_{i+1} in sequence A.

### Approach
The key insight is to recognize that each element in B imposes constraints on adjacent elements in A. Specifically, each B_i constrains the maximum possible values of A_i and A_{i+1}. To maximize the sum of A, each element in A should be set as high as possible under these constraints.

1. **First and Last Elements**: The first element of A (A_1) is constrained by B_1, so it can be at most B_1. Similarly, the last element of A (A_N) is constrained by B_{N-1}, so it can be at most B_{N-1}.
2. **Middle Elements**: For each element A_i (where 2 ≤ i ≤ N-1), the maximum value is constrained by both B_{i-1} and B_i. Therefore, the maximum possible value for A_i is the minimum of these two constraints, i.e., min(B_{i-1}, B_i).

By summing these values, we obtain the maximum possible sum of the sequence A.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    B = list(map(int, input[1:n]))
    total = B[0] + B[-1]
    for i in range(len(B) - 1):
        total += min(B[i], B[i+1])
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first value is the integer N, followed by the sequence B.
2. **Initial Sum Calculation**: The initial sum is set to the sum of the first and last elements of B, which correspond to the maximum possible values of the first and last elements of A.
3. **Summing Middle Elements**: For each middle element in A, the value is determined by taking the minimum of the corresponding adjacent elements in B. This sum is accumulated to the total.
4. **Output**: The total sum is printed, which represents the maximum possible sum of the sequence A under the given constraints.

This approach efficiently computes the maximum sum by leveraging the constraints imposed by B, ensuring that each element of A is maximized within its allowable bounds. The time complexity is O(N), which is optimal for the given problem constraints.
