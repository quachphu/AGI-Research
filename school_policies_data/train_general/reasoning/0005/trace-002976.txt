To solve this problem, we need to determine the highest possible score that the first student can achieve while maintaining the same average score for the class, adhering to the constraints that all scores are integers and within the range [0, m].

### Approach
1. **Problem Analysis**:
   - The key observation is that the sum of all students' scores must remain unchanged to maintain the average.
   - To maximize the first student's score, we need to set it as high as possible while ensuring the sum of the remaining students' scores is non-negative and within the allowed range.

2. **Key Insight**:
   - The maximum possible score for the first student is constrained by two factors: the highest allowed score (m) and the total sum of all scores (sum_a). This is because the sum of the remaining students' scores must be non-negative and fit within their allowed range.

3. **Algorithm**:
   - For each test case, compute the sum of all students' scores.
   - The maximum score for the first student is the minimum of the highest allowed score (m) and the total sum of scores (sum_a), as this ensures the remaining scores can be adjusted within their constraints.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n, m = int(input[ptr]), int(input[ptr+1])
        ptr +=2
        a = list(map(int, input[ptr:ptr+n]))
        ptr +=n
        sum_a = sum(a)
        print(min(sum_a, m))
        
main()
```

### Explanation
- **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
- **Sum Calculation**: For each test case, the sum of all students' scores is computed.
- **Determine Maximum Score**: The maximum score for the first student is determined by taking the minimum of the total sum of scores (sum_a) and the highest allowed score (m). This ensures the remaining scores can be adjusted to valid values while maintaining the required sum.

This approach efficiently computes the result in O(n) time per test case, which is optimal given the problem constraints.
