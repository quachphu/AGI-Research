To solve this problem, we need to determine the basket each ball is placed into according to Valeric's rules. The goal is to efficiently find the optimal basket for each ball by considering the basket's current count of balls, its distance to the middle, and its index.

### Approach
1. **Initialization**: Calculate the middle position of the baskets using integer arithmetic to avoid floating-point precision issues.
2. **Priority Queue**: Use a min-heap (priority queue) to track baskets based on their current count of balls, distance to the middle, and index. This ensures we can quickly find the optimal basket for each ball.
3. **Heap Management**: For each ball, extract the basket with the smallest count, distance, and index from the heap. Update the basket's count and push the updated state back into the heap. This approach efficiently handles stale entries in the heap by checking if the count matches the current state.

### Solution Code
```python
import heapq

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    m = int(input[1])
    
    counts = [0] * (m + 1)  # Using 1-based indexing
    middle_numerator = m + 1
    
    heap = []
    for i in range(1, m + 1):
        d = abs(2 * i - middle_numerator)
        heapq.heappush(heap, (0, d, i))
    
    for _ in range(n):
        while True:
            current_count, d, basket = heapq.heappop(heap)
            if counts[basket] == current_count:
                print(basket)
                counts[basket] += 1
                heapq.heappush(heap, (current_count + 1, d, basket))
                break

if __name__ == "__main__":
    main()
```

### Explanation
1. **Middle Calculation**: The middle position is calculated as `(m + 1)`, avoiding floating-point operations by using integer arithmetic.
2. **Heap Initialization**: Each basket is initialized with a count of 0 and pushed into the heap with its computed distance from the middle.
3. **Ball Placement**: For each ball, the optimal basket is determined by repeatedly extracting the smallest element from the heap until a valid entry (matching the current count) is found. The basket's count is updated, and the new state is pushed back into the heap.
4. **Efficiency**: The use of a priority queue ensures that each ball placement operation is efficient, with each insertion and extraction from the heap taking logarithmic time relative to the number of baskets.

This approach ensures that each ball is placed in the optimal basket according to the given rules, efficiently handling up to the maximum constraints of the problem.
