To solve this problem, we need to determine the minimum time Vasya will need to reach a cashier after joining the queue. The goal is to find the cashier queue where Vasya can start being served the earliest, considering the time taken by all existing customers in each queue.

### Approach
1. **Understanding the Time Calculation**: Each customer in a queue contributes to the total time based on the number of items they have. Specifically, each customer takes \(5 \times \text{items} + 15\) seconds to be processed (5 seconds per item and 15 seconds for payment and change).
2. **Summing Existing Customer Times**: For each cashier, we calculate the total time required to process all existing customers in their queue. This total time is the sum of each customer's processing time.
3. **Finding the Minimum Time**: Among all the cashiers, we determine the one with the shortest total processing time for its existing customers. This minimum time is the answer, as it represents the earliest time Vasya can start being served.

### Solution Code
```python
n = int(input())
k_list = list(map(int, input().split()))
min_time = float('inf')

for _ in range(n):
    m_items = list(map(int, input().split()))
    total = sum(m * 5 + 15 for m in m_items)
    if total < min_time:
        min_time = total

print(min_time)
```

### Explanation
1. **Reading Input**: The number of cashiers \(n\) is read first. Then, the number of people in each cashier's queue is read into a list.
2. **Processing Each Cashier's Queue**: For each cashier, the number of items each customer in their queue has is read. The total time for all existing customers in the queue is calculated by summing each customer's processing time.
3. **Determining the Minimum Time**: The minimum total time across all cashiers is tracked and updated as each cashier's queue is processed. This minimum value is printed as the result.

This approach efficiently computes the required time by iterating through each cashier's queue and using straightforward arithmetic operations, ensuring an optimal solution with a time complexity of \(O(n \times k)\), where \(k\) is the maximum number of people in any queue. This is efficient given the problem constraints.
