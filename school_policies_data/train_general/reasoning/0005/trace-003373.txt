To solve this problem, we need to determine if it is possible to form a convex regular polygon with `m` vertices using the vertices of an `n`-vertex convex regular polygon such that their centers coincide. The solution involves checking if `m` is a divisor of `n`, which ensures that the vertices of the `m`-gon can be evenly spaced around the same center as the `n`-gon.

### Approach
1. **Understanding Regular Polygons**: A regular polygon with `n` vertices has its vertices equally spaced around a circle. To form another regular polygon with `m` vertices using some of these vertices, the spacing between the selected vertices must be uniform.
2. **Divisibility Check**: If `m` divides `n` (i.e., `n % m == 0`), then we can select every `n/m`-th vertex of the original `n`-gon to form the `m`-gon. This ensures the vertices are equally spaced, forming a regular polygon.
3. **Algorithm**: For each test case, check if `n` is divisible by `m`. If true, print "YES"; otherwise, print "NO".

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    print("YES" if n % m == 0 else "NO")
```

### Explanation
- **Divisibility Check**: The key insight is that if `m` divides `n`, then the vertices of the `m`-gon can be selected by taking every `n/m`-th vertex of the `n`-gon. This ensures the vertices are equidistant from the center and each other, forming a regular polygon.
- **Efficiency**: The solution runs in constant time for each test case, making it efficient even for the upper constraint of `t = 10^4`.

This approach leverages the properties of regular polygons and divisibility to quickly determine the possibility of forming the required polygon, ensuring both correctness and efficiency.
