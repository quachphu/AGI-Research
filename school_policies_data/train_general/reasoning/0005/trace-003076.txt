To solve this problem, we need to find the Least Common Multiple (LCM) of two given strings, which is the shortest non-empty string that is divisible by both input strings. If such a string does not exist, we should return -1.

### Approach
1. **Understanding Divisibility**: A string `a` is divisible by another string `b` if `a` can be formed by repeating `b` multiple times. For example, "abab" is divisible by "ab" because "ab" repeated twice gives "abab".

2. **Finding the GCD String**: The greatest common divisor (GCD) string of a string `s` is the smallest repeating unit that can generate `s` when repeated. For example, the GCD string of "ababab" is "ab".

3. **Check Compatibility**: For two strings `s` and `t` to have an LCM, their GCD strings must be the same. If they are different, no LCM exists.

4. **Calculate LCM**: If the GCD strings of both `s` and `t` are the same, compute the LCM of the repetition counts of the GCD string in each input string. The LCM string is then the GCD string repeated LCM times.

### Solution Code
```python
def get_gcd_string(s):
    n = len(s)
    divisors = []
    for i in range(1, n + 1):
        if n % i == 0:
            divisors.append(i)
    for d in divisors:
        candidate = s[:d]
        if candidate * (n // d) == s:
            return candidate
    return s  # This line is theoretically unreachable

def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

q = int(input())
```

2. **GCD of Repetition Counts**: The `gcd` function calculates the greatest common divisor of two numbers using the Euclidean algorithm, which is used to determine the LCM of the repetition counts.

3. **Main Logic**: For each test case, the code reads the input strings, computes their GCD strings, checks if they are the same, and then calculates the LCM of their repetition counts. The result is the GCD string repeated LCM times, which is printed. If the GCD strings differ, -1 is printed.
