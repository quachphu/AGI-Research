To solve this problem, we need to determine the longest chain of reposts starting from Polycarp. Each repost chain starts with Polycarp and each subsequent repost adds to the length of the chain. The goal is to find the maximum length of such a chain.

### Approach
1. **Problem Analysis**: The problem can be modeled as a directed acyclic graph (DAG) where each node represents a user, and an edge from node A to node B indicates that user A reposted from user B. The length of the longest path from the root node (Polycarp) to any leaf node gives the maximum chain length.
2. **Key Insight**: Since each repost is guaranteed to be valid (i.e., the user being reposted from already has the joke), we can process each repost in sequence, maintaining the depth of each user. The depth of a user is defined as the depth of the user they reposted from plus one.
3. **Case Insensitivity**: Usernames are case-insensitive, so we normalize all names to lowercase to handle this.
4. **Algorithm**: Use a dictionary to keep track of the depth of each user. Initialize Polycarp's depth to 1. For each repost entry, update the depth of the reposting user based on the depth of the user they reposted from, and keep track of the maximum depth encountered.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().splitlines()
    n = int(input[0])
    depths = {'polycarp': 1}
    max_depth = 1
    for line in input[1:n+1]:
        parts = line.split()
        name1 = parts[0].lower()
        name2 = parts[2].lower()
        depth = depths[name2] + 1
        depths[name1] = depth
        if depth > max_depth:
            max_depth = depth
    print(max_depth)

main()
```

### Explanation
1. **Reading Input**: The input is read as a list of lines. The first line gives the number of reposts, `n`.
2. **Initialization**: A dictionary `depths` is initialized with Polycarp's depth set to 1.
3. **Processing Each Repost**: For each repost entry, the names are converted to lowercase to handle case insensitivity. The depth of the reposting user is set to one more than the depth of the user they reposted from. This depth is tracked in the dictionary and the maximum depth is updated accordingly.
4. **Output**: After processing all entries, the maximum depth found is printed, which represents the longest repost chain.

This approach efficiently processes each repost in linear time, making it suitable for the given constraints.
