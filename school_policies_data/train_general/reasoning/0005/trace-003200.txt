To solve this problem, we need to determine the minimum cost of ladders such that each participant's ladder has a score (Euler's totient function value) at least equal to their maximum achievable score. The cost of a ladder is equal to its height. 

### Approach
1. **Precompute Euler's Totient Function (phi)**: We precompute the values of Euler's totient function for all integers up to a sufficiently large number (2,000,000 in this case) using a sieve-like method. This allows us to efficiently determine the totient values for any number within this range.

2. **Build Minimum Height Array**: Using the precomputed phi values, we construct an array `min_h` where `min_h[s]` represents the smallest integer `h` such that `phi(h) >= s`. This is done by iterating through each possible height and updating the minimum height for each score `s` that the current height can cover.

3. **Process Input and Compute Results**: For each test case, we read the scores of the participants and sum up the minimum heights required for each score using the precomputed `min_h` array.

### Solution Code
```python
import sys

def main():
    max_h = 2000000  # Precompute up to 2 million to cover required cases
    s_max = 1000000  # Maximum possible score as per problem constraints

    # Compute Euler's totient function (phi) for each number up to max_h
    phi = list(range(max_h + 1))
    is_prime = [True] * (max_h + 1)
    is_prime[0] = is_prime[1] = False

    for p in range(2, max_h + 1):
        if is_prime[p]:
            for multiple in range(p, max_h + 1, p):
                if multiple != p:
                    is_prime[multiple] = False
                phi[multiple] -= phi[multiple] // p

    # Build the min_h array where min_h[s] is the smallest h with phi(h) >= s
    min_h = [float('inf')] * (s_max + 2)
    current_max_s = 0

    for h in range(1, max_h + 1):
        s_h = phi[h]
        if s_h > current_max_s:
            start = current_max_s + 1
            end = s_h
            if start > s_max:
                break
            end = min(end, s_max)
            for s in range(start, end + 1):
                if min_h[s] == float('inf'):
                    min_h[s] = h
            current_max_s = max(current_max_s, s_h)
            if current_max_s >= s_max:
                break

    # Read input and process each test case
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        scores = list(map(int, input[ptr:ptr + n]))
        ptr += n
        total = 0
        for s in scores:
            total += min_h[s]
        print(total)

if __name__ == "__main__":
    main()
```
