To solve this problem, we need to compute the sum of pairwise GCDs for a specific range of numbers generated by the formula \(2^{2^n} + 1\), where \(n\) is a positive integer. These numbers are known as Fermat numbers and are pairwise coprime, meaning their GCD is always 1 for any two distinct numbers.

### Approach
1. **Understanding Fermat Numbers**: Fermat numbers are of the form \(2^{2^n} + 1\). They are pairwise coprime, which means the GCD of any two distinct Fermat numbers is 1.
2. **Range Analysis**: Given a range [X, Y], the sum of pairwise GCDs of the numbers in this range is equivalent to the number of pairs in the range. This is because each pair contributes exactly 1 to the sum.
3. **Combinatorial Insight**: The number of pairs in a range of \(k\) elements is given by the combination formula \(k \choose 2\), which simplifies to \(k \times (k - 1) / 2\).

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        X = int(input[idx])
        Y = int(input[idx + 1])
        idx += 2
        if X > Y:
            print(0)
        else:
            k = Y - X + 1
            print(k * (k - 1) // 2)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Handling Each Test Case**: For each test case, we read the values of X and Y.
3. **Range Check**: If X is greater than Y, the result is 0 since there are no elements in the range.
4. **Calculating Pairs**: If X ≤ Y, the number of elements in the range is \(k = Y - X + 1\). The number of pairs (and thus the sum of GCDs) is calculated using \(k \times (k - 1) / 2\).

This approach efficiently computes the result in constant time \(O(1)\) for each test case, making it suitable for large input sizes.
