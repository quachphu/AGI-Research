To solve this problem, we need to determine how many distinct strings can be generated by cyclically shifting the given string. A cyclic shift involves moving the last character of the string to the beginning. The goal is to count all unique strings that can be formed by performing any number of such shifts.

### Approach
1. **Understand Cyclic Shifts**: Each cyclic shift moves the last character to the front. For a string of length `n`, performing `n` shifts will bring the string back to its original form.
2. **Generate All Possible Shifts**: For each possible number of shifts (from 0 to `n-1`), generate the resulting string. This can be efficiently done using Python string slicing.
3. **Use a Set for Uniqueness**: Store each generated string in a set to automatically handle duplicates. The size of the set will give the number of distinct strings.

### Solution Code
```python
def main():
    s = input().strip()
    n = len(s)
    unique_shifts = set()
    for k in range(n):
        shifted = s[-k:] + s[:-k]
        unique_shifts.add(shifted)
    print(len(unique_shifts))

main()
```

### Explanation
1. **Reading Input**: The input string is read from standard input.
2. **Generating Shifts**: For each `k` from 0 to `n-1`, the string is sliced into two parts: the last `k` characters and the remaining characters. These parts are concatenated to form the shifted string.
3. **Storing Unique Strings**: Each shifted string is added to a set, which inherently handles duplicates.
4. **Output Result**: The size of the set, which represents the number of unique cyclic shifts, is printed.

This approach efficiently handles all possible cyclic shifts and ensures that duplicates are counted only once, leading to an optimal solution.
