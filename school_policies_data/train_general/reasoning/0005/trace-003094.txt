To solve this problem, we need to determine if we can assign integers to variables such that all given equality and inequality constraints are satisfied. This can be efficiently achieved using the Union-Find (Disjoint Set Union, DSU) data structure.

### Approach
1. **Union-Find Data Structure**: This helps in efficiently grouping variables into connected components based on equality constraints. Each connected component represents variables that must have the same integer value.
2. **Process Equalities First**: By uniting variables connected by equality constraints, we form the necessary groups.
3. **Check Inequalities**: After forming groups, we check each inequality constraint to ensure that the variables involved belong to different groups. If any inequality constraint involves variables from the same group, it is impossible to satisfy all constraints.

### Solution Code
```python
import sys

class DSU:
    def __init__(self, size):
        self.parent = list(range(size + 1))  # 1-based indexing
        self.rank = [1] * (size + 1)
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return
        if self.rank[x_root] < self.rank[y_root]:
            self.parent[x_root] = y_root
        else:
            self.parent[y_root] = x_root
            if self.rank[x_root] == self.rank[y_root]:
                self.rank[x_root] += 1

def main():
    data = sys.stdin.read().split()
    ptr = 0
    T = int(data[ptr])
    ptr += 1
    for _ in range(T):
        N = int(data[ptr])
        K = int(data[ptr + 1])
        ptr += 2
        dsu = DSU(N)
        inequalities = []
        for __ in range(K):
            x1 = int(data[ptr])
            R = data[ptr + 1]
            x2 = int(data[ptr + 2])
            ptr += 3
            if R == '=':
                dsu.union(x1, x2)
            else:
                inequalities.append((x1, x2))
        possible = True
        for a, b in inequalities:
            if dsu.find(a) == dsu.find(b):
                possible = False
                break
        print("YES" if possible else "NO")

if __name__ == "__main__":
    main()
```

1. **Reading Input Efficiently**: The input is read all at once and split into tokens for efficient processing, especially for large input sizes.
2. **Union-Find Initialization**: For each test case, a DSU instance is created to manage the connected components of variables.
3. **Processing Constraints**: Equality constraints are processed first to unite variables into groups. Inequality constraints are stored and checked after all equalities are processed.
4. **Checking Inequalities**: Each inequality is checked to ensure the variables involved are in different groups. If any inequality fails this check, the answer for that test case is "NO"; otherwise, it is "YES".

This approach ensures that we efficiently group variables and check constraints in nearly linear time, making it suitable for large input sizes.
