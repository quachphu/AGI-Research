To solve this problem, we need to determine how many substrings of a given binary string `a` (of the same length as another binary string `b`) have an even Hamming distance when compared to `b`. The Hamming distance between two strings is the number of positions at which the corresponding symbols are different. 

### Approach
1. **Key Insight**: The parity (even or odd) of the Hamming distance between two binary strings can be determined using the XOR operation. The Hamming distance parity between two strings is the same as the XOR of the parities of the number of 1s in each string.
2. **Efficient Calculation**: Instead of directly computing the Hamming distance for each possible substring, we can use prefix sums to efficiently compute the parity of the number of 1s in each substring of `a` of length `|b|`.
3. **Prefix Array**: Construct a prefix array where each entry at index `i` represents the cumulative sum of the first `i` elements of `a` modulo 2. This helps in quickly determining the parity of the number of 1s in any substring of `a`.
4. **Sliding Window Technique**: For each possible starting position of the substring in `a` of length `|b|`, compute the parity of the number of 1s using the prefix array. Compare this parity with the parity of the number of 1s in `b` to determine if the Hamming distance is even.

### Solution Code
```python
a = input().strip()
b = input().strip()

m = len(b)
n = len(a)

if m > n:
    print(0)
    exit()

# Compute parity of b
b_parity = sum(int(c) for c in b) % 2

# Compute prefix array for a's parity
prefix = [0] * (n + 1)
for i in range(n):
    prefix[i+1] = (prefix[i] + int(a[i])) % 2

count = 0
for i in range(n - m + 1):
    window_parity = (prefix[i + m] + prefix[i]) % 2
    if (window_parity ^ b_parity) == 0:
        count += 1

print(count)
```

### Explanation
1. **Parity Calculation for `b`**: The parity of the number of 1s in `b` is computed once and stored as `b_parity`.
2. **Prefix Array Construction**: The prefix array is built such that each entry at index `i` holds the cumulative sum of the first `i` elements of `a` modulo 2. This allows quick determination of the parity of any substring of `a`.
3. **Sliding Window Check**: For each possible starting position of the substring in `a`, compute the parity of the number of 1s in that substring using the prefix array. The XOR of this parity with `b_parity` determines if the Hamming distance is even. If the result is 0, the substring is counted.

This approach ensures that we efficiently compute the required result in linear time, making it suitable even for large input sizes up to 1,000,000 characters.
