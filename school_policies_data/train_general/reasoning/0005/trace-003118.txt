To solve this problem, we need to count the number of alphabets that are repeated in each given string for multiple test cases. The solution should be case-insensitive, meaning that uppercase and lowercase letters are considered the same.

### Approach
1. **Input Reading**: Read the number of test cases, followed by each test case string.
2. **Case Insensitivity**: Convert each string to lowercase to handle case insensitivity.
3. **Frequency Counting**: Use a frequency counter to count occurrences of each character in the converted string.
4. **Count Repeats**: Determine how many characters have a frequency of 2 or more, indicating repetition.
5. **Output Results**: For each test case, output the count of repeated characters.

### Solution Code
```python
import sys
from collections import Counter

def main():
    T = int(sys.stdin.readline())
    for _ in range(T):
        s = sys.stdin.readline().strip()
        counts = Counter(s.lower())
        repeated = sum(1 for v in counts.values() if v >= 2)
        print(repeated)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The first line of input is the number of test cases, `T`. Each subsequent line is a test case string.
2. **Case Conversion**: Each string is converted to lowercase to ensure that characters are counted regardless of their case.
3. **Frequency Counting**: Using `Counter` from the `collections` module, we count the occurrences of each character in the converted string.
4. **Counting Repeats**: For each character in the frequency counter, we check if its count is 2 or more. The sum of such characters gives the number of repeated alphabets.
5. **Output**: For each test case, the result is printed, which is the count of repeated characters.

This approach efficiently handles the problem constraints and ensures accurate results by leveraging case insensitivity and efficient counting mechanisms.
