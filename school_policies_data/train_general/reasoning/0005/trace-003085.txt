To solve this problem, we need to efficiently calculate the sum of stones in specific cells after processing multiple stairway updates. Each stairway adds a certain number of stones to a range of cells, and we need to determine the total number of stones in specific cells after all updates.

### Approach
1. **Problem Analysis**:
   - Each stairway update adds stones in a linear fashion over a range of cells.
   - Directly iterating over each cell for every stairway update would be computationally expensive, so we need an optimized approach.

2. **Key Insights**:
   - Use difference arrays to efficiently compute the total contributions of all stairways to each cell.
   - Maintain two difference arrays: one for counting the number of stairways covering each cell and another for summing the contributions of each stairway.

3. **Algorithm**:
   - **Difference Arrays**: For each stairway, update the difference arrays to mark the start and end of the range it affects.
   - **Prefix Sums**: Convert the difference arrays into prefix sum arrays to get the total contributions for each cell efficiently.
   - **Query Processing**: For each query, use the prefix sum arrays to quickly compute the total stones in the specified cells.

### Solution Code
```python
n, m, k = map(int, input().split())

diff_count = [0] * (n + 2)
diff_sum_c = [0] * (n + 2)

for _ in range(m):
    a, b, c = map(int, input().split())
    # Update count difference array
    diff_count[a] += 1
    if b + 1 <= n:
        diff_count[b + 1] -= 1
    # Update sum_c difference array
    delta = c - a
    diff_sum_c[a] += delta
    if b + 1 <= n:
        diff_sum_c[b + 1] -= delta

# Compute prefix sums for count and sum_c
count = [0] * (n + 1)
current_count = 0
sum_c = [0] * (n + 1)
current_sum = 0

for j in range(1, n + 1):
    current_count += diff_count[j]
    count[j] = current_count
    current_sum += diff_sum_c[j]
    sum_c[j] = current_sum

# Read queries and compute the total
queries = list(map(int, input().split()))
total = 0
for j in queries:
    total += sum_c[j] + j * count[j]

print(total)
```

### Explanation
1. **Difference Arrays**:
   - `diff_count` tracks the number of stairways affecting each cell. For each stairway from `a` to `b`, increment `diff_count[a]` and decrement `diff_count[b+1]`.
   - `diff_sum_c` tracks the cumulative contribution of each stairway. For each stairway, compute the initial contribution `c - a` and update the difference array similarly.

2. **Prefix Sums**:
   - Convert `diff_count` into a prefix sum array `count` where each element `count[j]` represents the number of stairways covering cell `j`.
   - Convert `diff_sum_c` into a prefix sum array `sum_c` where each element `sum_c[j]` represents the cumulative contribution of all stairways covering cell `j`.

3. **Query Processing**:
   - For each queried cell `j`, compute the total stones as `sum_c[j] + j * count[j]`, summing these values for all queried cells to get the final result.

This approach efficiently handles the problem constraints, ensuring optimal performance even for large input sizes.
