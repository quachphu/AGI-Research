To solve this problem, we need to determine the direction in which a balance scale tips based on the weights placed on its left and right pans. The solution involves comparing the total weights on both sides and determining the result based on their sums.

### Approach
1. **Input Reading**: Read the input values which represent the weights on the balance scale.
2. **Sum Calculation**: Compute the total weight on both the left and right pans.
3. **Comparison**: Compare the sums of the weights on both pans to determine if the scale tips to the left, right, or remains balanced.

### Solution Code
```python
def main():
    A, B, C, D = map(int, input().split())
    left = A + B
    right = C + D
    if left > right:
        print("Left")
    elif left == right:
        print("Balanced")
    else:
        print("Right")

main()
```

### Explanation
1. **Reading Input**: The input values are read as a single line and split into four integers representing the weights A, B (left pan) and C, D (right pan).
2. **Summing Weights**: The total weight on the left pan is calculated as the sum of A and B, while the total weight on the right pan is the sum of C and D.
3. **Comparison and Output**: 
   - If the left pan's total weight is greater, the output is "Left".
   - If both pans have equal total weights, the output is "Balanced".
   - Otherwise, the output is "Right".

This approach efficiently determines the result using basic arithmetic operations and conditional checks, ensuring optimal performance even for the upper constraint limits.
