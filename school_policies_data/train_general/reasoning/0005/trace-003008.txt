To solve this problem, we need to determine the order in which students entered the classroom based on the given records. Each record indicates the number of students present when a specific student entered, including that student. The key insight is that each student's entry time corresponds directly to the value in their record, allowing us to reconstruct the order by sorting these values.

### Approach
1. **Understanding the Records**: Each student's record value (A_i) indicates the number of students present when they entered, including themselves. This means the student with the smallest A_i entered first, the student with the next smallest A_i entered second, and so on.
2. **Sorting by Records**: By sorting the students based on their A_i values in ascending order, we can directly determine the entry order. Each student's position in the sorted list corresponds to their entry time.
3. **Efficiency Considerations**: Sorting the students based on their A_i values ensures an efficient solution with a time complexity of O(N log N), which is feasible given the constraint N ≤ 10^5.

### Solution Code
```python
n, *rest = map(int, open(0).read().split())
a = rest[:n]
students = sorted(zip(a, range(1, n+1)))
print(' '.join(map(str, [s[1] for s in students])))
```

### Explanation
1. **Reading Input**: The input is read and parsed into a list of integers. The first value is the number of students (N), followed by their respective records (A_i).
2. **Creating Tuples**: Each student is represented as a tuple (A_i, student_number), where student_number ranges from 1 to N.
3. **Sorting Tuples**: These tuples are sorted based on the A_i values in ascending order. This sorting step directly determines the entry order of the students.
4. **Extracting Student Numbers**: After sorting, the student numbers are extracted from the sorted tuples and printed in the correct order.

This approach efficiently reconstructs the entry order by leveraging sorting, ensuring the solution is both optimal and easy to understand.
