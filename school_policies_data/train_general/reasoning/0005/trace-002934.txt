To solve this problem, we need to efficiently determine how many segments on the Ox axis contain at least one point from each query. Given the constraints, a direct approach would be too slow, so we use a combination of sorting and square root decomposition to optimize the solution.

### Approach
1. **Sort Segments**: First, we sort all segments by their starting point `l`.
2. **Square Root Decomposition**: Divide the sorted segments into blocks of size approximately `sqrt(n)`. For each block, store the endpoints `r` in a sorted list.
3. **Query Processing**: For each query, process each point and use binary search to determine the range of segments that could contain the point. Use the precomputed blocks to efficiently count how many segments in this range have endpoints greater than or equal to the current point.

### Solution Code
```python
import bisect
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    m = int(input[ptr+1])
    ptr += 2
    
    segments = []
    for _ in range(n):
        l = int(input[ptr])
        r = int(input[ptr+1])
        segments.append((l, r))
        ptr += 2
    
    # Sort segments by their left coordinate
    segments.sort()
    sorted_l = [seg[0] for seg in segments]
    sorted_r = [seg[1] for seg in segments]
    
    # Prepare block decomposition for the sorted segments
    block_size = int(n**0.5) + 1
    blocks = []
    sorted_r_blocks = []
    
    for i in range(0, n, block_size):
        block = segments[i:i + block_size]
        r_list = [seg[1] for seg in block]
        r_list.sort()
        blocks.append(block)
        sorted_r_blocks.append(r_list)
    
    def query_range(L, R, x):
        """Count the number of segments in [L, R) with r >= x."""
        count = 0
        # Determine block indices for L and R
        start_block = L // block_size
        end_block = (R - 1) // block_size
        
        for block_idx in range(start_block, end_block + 1):
            block_start = block_idx * block_size
            block_end = block_start + len(blocks[block_idx])  # Actual end of the block
            
            # Calculate overlap of the block with [L, R)
            a = max(block_start, L)
            b = min(block_end, R)
            if a >= b:
                continue
            
            if a == block_start and b == block_end:
                # Full block, use binary search on the sorted r_list
                r_list = sorted_r_blocks[block_idx]
                cnt = len(r_list) - bisect.bisect_left(r_list, x)
                count += cnt
            else:
                # Partial block, check each element in the original segments
                for i in range(a, b):
                    if segments[i][1] >= x:
                        count += 1
        return count
    
    # Process each query
    output = []
    for _ in range(m):
        cnt_i = int(input[ptr])
        ptr += 1
        ps = list(map(int, input[ptr:ptr + cnt_i]))
        ptr += cnt_i
        
        ans = 0
        prev = 0  # Initially, previous point is 0
        for p in ps:
            # Find the left and right indices in the sorted_l array
            left = bisect.bisect_right(sorted_l, prev)
            right = bisect.bisect_right(sorted_l, p)
            
            if left < right:
                ans += query_range(left, right, p)
            prev = p
        
        output.append(str(ans))
    
    print('\n'.join(output))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Sorting Segments**: Segments are sorted by their starting points to facilitate efficient range queries.
2. **Block Decomposition**: By dividing segments into blocks and sorting the endpoints within each block, we can quickly count how many endpoints meet the criteria using binary search.
3. **Efficient Queries**: For each query point, we determine the range of segments that start after the previous query point and before or at the current point. Using the precomputed blocks, we efficiently count valid segments using binary search within blocks and direct checks for partial blocks.

This approach balances preprocessing and query time, ensuring that even for large inputs, the solution remains efficient.
