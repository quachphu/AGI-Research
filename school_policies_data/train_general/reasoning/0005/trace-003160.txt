To solve this problem, we need to determine which participants pass the qualification contests based on specific conditions. The participants are categorized as Japanese students, overseas students, or neither. Only Japanese and overseas students can pass, and they must meet certain criteria based on their rank and the number of already passed participants.

### Approach
1. **Input Reading**: Read the number of participants (N), the maximum number of Japanese students (A), and the maximum number of overseas students (B) who can pass. Also, read the string representing each participant's category.
2. **Counters Initialization**: Maintain two counters:
   - `total_passed` to keep track of the total number of participants who have passed so far.
   - `overseas_seen` to count the number of overseas students encountered up to the current rank.
3. **Iterate Through Participants**: For each participant:
   - If the participant is neither a student (`c`), they automatically fail.
   - For Japanese students (`a`), check if the total number of passed participants is less than the combined maximum (A + B). If so, they pass.
   - For overseas students (`b`), check two conditions:
     - The total number of passed participants is still less than A + B.
     - The current overseas student is within the first B encountered. If both conditions are met, they pass.

### Solution Code
```python
n, a, b = map(int, input().split())
s = input().strip()

total_passed = 0
overseas_seen = 0

for c in s:
    if c == 'c':
        print("No")
    elif c == 'a':
        if total_passed < a + b:
            print("Yes")
            total_passed += 1
        else:
            print("No")
    else:  # 'b'
        overseas_seen += 1
        if overseas_seen <= b and total_passed < a + b:
            print("Yes")
            total_passed += 1
        else:
            print("No")
```

### Explanation
- **Reading Input**: The input values are read and parsed to get the number of participants and their categories.
- **Processing Each Participant**:
  - For `c` (non-students), the result is immediately "No".
  - For `a` (Japanese students), check if there are still slots available in the combined maximum (A + B). If yes, they pass and the counter is incremented.
  - For `b` (overseas students), increment the count of encountered overseas students. Check if they are within the first B overseas students and if there are still slots available. If both conditions are met, they pass and both counters are updated.

This approach ensures that we efficiently determine the result for each participant in linear time, making it suitable even for the upper constraint limits.
