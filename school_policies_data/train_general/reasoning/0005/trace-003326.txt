To solve this problem, we need to determine the maximum number of occurrences of any element in an array after performing up to `k` operations, where each operation increments an element by 1. Additionally, if there are multiple elements with the same maximum occurrences, we should choose the smallest element.

### Approach
1. **Sort the Array**: Sorting helps in efficiently using a sliding window technique to find the optimal elements that can be incremented to a common value with minimal operations.
2. **Prefix Sum Array**: Compute a prefix sum array to quickly calculate the sum of any subarray, which is essential for determining the cost of converting elements in a subarray to a common value.
3. **Binary Search for Sliding Window**: For each element as the right end of the window, use binary search to find the smallest left index such that the cost of converting all elements in the window to the rightmost element (current element) is within the allowed operations `k`.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))
a.sort()

prefix = [0] * (n + 1)
for i in range(n):
    prefix[i + 1] = prefix[i] + a[i]

max_count = 0
min_target = None

for right in range(n):
    low = 0
    high = right
    best_left = None
    while low <= high:
        mid = (low + high) // 2
        window_size = right - mid + 1
        cost = a[right] * window_size - (prefix[right + 1] - prefix[mid])
        if cost <= k:
            best_left = mid
            high = mid - 1
        else:
            low = mid + 1
    if best_left is not None:
        current_count = right - best_left + 1
        if current_count > max_count:
            max_count = current_count
            min_target = a[right]
        elif current_count == max_count:
            if a[right] < min_target:
                min_target = a[right]

print(max_count, min_target)
```

### Explanation
1. **Sorting**: The array is sorted to facilitate the sliding window approach, allowing us to efficiently compute the cost of converting elements in a subarray to a common value.
2. **Prefix Sum Array**: This array helps in quickly calculating the sum of any subarray, which is crucial for determining the cost of operations required to convert elements in a window to the rightmost element.
3. **Binary Search for Optimal Window**: For each element as the right end of the window, binary search is used to find the smallest left index such that the cost of converting all elements in the window to the rightmost element is within `k`. This ensures we find the largest possible window size (maximum occurrences) efficiently.

This approach ensures that we efficiently determine the optimal number of elements that can be converted to the same value with the given constraints, while also ensuring the smallest value is chosen in case of ties. The overall complexity is O(n log n), making it suitable for large input sizes.
