To solve this problem, we need to count the number of pairs of indices (i, j) such that i < j and the sum of the elements at these indices is a power of two. Given the constraints, a brute-force approach is infeasible, so we use a more efficient method involving frequency maps and precomputed powers of two.

### Approach
1. **Precompute Powers of Two**: Generate all powers of two from \(2^1\) up to \(2^{31}\) (since the maximum possible sum of two elements is \(2 \times 10^9\)).
2. **Frequency Map**: Use a frequency map to keep track of the count of elements encountered as we iterate through the list. This helps efficiently check how many times a required complement value has appeared.
3. **Iterate and Check Complements**: For each element in the list, adjust the frequency map to exclude the current element (since we only consider elements that come after it). For each possible power of two greater than the current element, compute the required complement and check its presence in the frequency map.

### Solution Code
```python
import bisect
from collections import defaultdict

def count_power_pairs():
    n = int(input())
    a = list(map(int, input().split()))
    
    # Precompute all powers of two from 2^1 to 2^31
    powers = [2 ** x for x in range(1, 32)]
    
    # Initialize frequency map with all elements
    freq = defaultdict(int)
    for num in a:
        freq[num] += 1
    
    total = 0
    
    for num in a:
        # Remove current num from frequency map (as it's now processed)
        if freq[num] > 0:
            freq[num] -= 1
            if freq[num] == 0:
                del freq[num]
        
        # Calculate the minimum power of two to consider
        min_s = num + 1
        # Find the starting index in the powers list
        idx = bisect.bisect_left(powers, min_s)
        
        # Check each power from the starting index
        for s in powers[idx:]:
            b = s - num
            if b in freq:
                total += freq[b]
    
    print(total)

count_power_pairs()
```

### Explanation
1. **Precompute Powers**: We generate all necessary powers of two (from \(2^1\) to \(2^{31}\)) to cover all possible sums of two elements up to \(2 \times 10^9\).
2. **Frequency Map**: This map keeps track of how many times each element has been seen. As we iterate through each element, we adjust the frequency map to exclude the current element, ensuring we only consider elements that come after it.
3. **Efficient Lookup**: For each element, we determine the minimum power of two required (current element + 1) and use binary search to find the starting index in the precomputed powers list. For each power from this index onwards, we compute the complement and check its presence in the frequency map, accumulating the count of valid pairs.

This approach efficiently reduces the problem from a potential O(n^2) complexity to O(n log n), making it feasible for large input sizes.
