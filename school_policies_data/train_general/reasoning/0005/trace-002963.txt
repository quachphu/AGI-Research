To solve this problem, we need to efficiently answer multiple queries about finding the minimum absolute difference between a given value D and the closest bean hardness in a specified subarray. Given the constraints, a naive approach would be too slow, so we use a segment tree with sorted lists to handle range queries efficiently.

### Approach
1. **Segment Tree Construction**: We build a segment tree where each node stores a sorted list of the elements in its range. This allows us to efficiently merge ranges and perform binary searches.
2. **Query Processing**: For each query, we decompose the range into segments covered by the segment tree nodes. For each node's sorted list, we use binary search to find the closest elements to D and compute the minimum absolute difference.

### Solution Code
```python
import sys
import bisect
import heapq

class Node:
    __slots__ = ['start', 'end', 'left', 'right', 'sorted_list']
    def __init__(self, start, end):
        self.start = start
        self.end = end
        self.left = None
        self.right = None
        self.sorted_list = []

def merge(a, b):
    return list(heapq.merge(a, b))

def build_tree(arr, l, r):
    node = Node(l, r)
    if l == r:
        node.sorted_list = [arr[l]]
        return node
    mid = (l + r) // 2
    node.left = build_tree(arr, l, mid)
    node.right = build_tree(arr, mid + 1, r)
    node.sorted_list = merge(node.left.sorted_list, node.right.sorted_list)
    return node

def collect_nodes(node, l, r, nodes_list):
    if node.end < l or node.start > r:
        return
    if l <= node.start and node.end <= r:
        nodes_list.append(node)
        return
    collect_nodes(node.left, l, r, nodes_list)
    collect_nodes(node.right, l, r, nodes_list)

def main():
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    a = list(map(int, input[ptr:ptr + N]))
    ptr += N
    Q = int(input[ptr])
    ptr += 1
    queries = []
    for _ in range(Q):
        l = int(input[ptr])
        r = int(input[ptr + 1])
        D = int(input[ptr + 2])
        queries.append((l, r, D))
        ptr += 3
    
    root = build_tree(a, 0, N - 1)
    
    for l, r, D in queries:
        nodes_list = []
        collect_nodes(root, l, r, nodes_list)
        min_diff = float('inf')
        for node in nodes_list:
            lst = node.sorted_list
            idx = bisect.bisect_left(lst, D)
            if idx < len(lst):
                diff = abs(lst[idx] - D)
                if diff < min_diff:
                    min_diff = diff
            if idx > 0:
                diff = abs(lst[idx - 1] - D)
                if diff < min_diff:
                    min_diff = diff
        print(min_diff)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Segment Tree Construction**: The segment tree is built recursively. Each node represents a range of the array and stores a sorted list of elements in that range. This allows efficient range queries.
2. **Merge Function**: Using `heapq.merge`, we efficiently merge two sorted lists into one sorted list, which is crucial for constructing the segment tree nodes.
3. **Query Processing**: For each query, we collect all relevant segment tree nodes that cover the query range. For each node's sorted list, we use binary search to find the closest elements to D and compute the minimum absolute difference.

This approach ensures that each query is processed in O(log N) time per node, leading to efficient handling of up to 100,000 queries on an array of 100,000 elements.
