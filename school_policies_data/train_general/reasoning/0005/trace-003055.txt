To solve this problem, we need to determine if the given string `S` contains the substring "AC" as a contiguous part. The solution involves checking each pair of consecutive characters in the string to see if they form the substring "AC".

### Approach
1. **Input Reading**: Read the input string `S`.
2. **Check Contiguous Substrings**: Iterate through each character in the string (except the last one) and check if the current character is 'A' and the next character is 'C'.
3. **Output Result**: If such a pair is found, print "Yes" and exit. If the loop completes without finding such a pair, print "No".

This approach efficiently checks each possible pair of consecutive characters in the string, ensuring that we do not miss any potential occurrence of the substring "AC".

### Solution Code
```python
s = input().strip()
for i in range(len(s) - 1):
    if s[i] == 'A' and s[i+1] == 'C':
        print("Yes")
        exit()
print("No")
```

### Explanation
1. **Reading Input**: The input string `S` is read and stripped of any leading or trailing whitespace.
2. **Loop Through Characters**: We loop from the first character to the second last character of the string. For each character at position `i`, we check if it is 'A' and the next character (at position `i+1`) is 'C'.
3. **Check for Substring**: If such a pair is found, we immediately print "Yes" and exit the program. If the loop completes without finding the substring "AC", we print "No".

This solution efficiently handles all edge cases, including strings of minimum length (2 characters) and maximum length (5 characters), ensuring optimal performance given the problem constraints.
