To solve this problem, we need to determine the maximum number of composite numbers that sum up to a given integer \( n \). If it's not possible, we return -1. Composite numbers are integers greater than 1 that are not prime.

### Approach
1. **Base Cases**: If \( n \) is less than 4, it's impossible to form a sum of composites, so the result is -1.
2. **Even Numbers**:
   - If \( n \) is exactly 4, the result is 1 (since 4 itself is a composite).
   - For even \( n \) greater than 4, check the remainder when divided by 4:
     - If the remainder is 0, the result is \( n // 4 \).
     - If the remainder is 2, subtract 6 (the next smallest composite) and then divide by 4, adding 1 to the result.
3. **Odd Numbers**:
   - If \( n \) is less than 9, it's impossible to form a sum of composites.
   - If \( n \) is exactly 9, the result is 1 (since 9 is a composite).
   - For odd \( n \) greater than 9, subtract 9 (the smallest odd composite) and then handle the remaining even part as described for even numbers.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    q = int(input[0])
    for i in range(1, q + 1):
        n = int(input[i])
        if n < 4:
            print(-1)
            continue
        if n % 2 == 0:
            # Handle even case
            if n == 4:
                print(1)
                continue
            rem = n % 4
            if rem == 0:
                print(n // 4)
            elif rem == 2:
                m = n - 6
                if m < 0:
                    print(-1)
                else:
                    print((m // 4) + 1)
            else:
                print(-1)
        else:
            # Handle odd case
            if n < 9:
                print(-1)
                continue
            if n == 9:
                print(1)
                continue
            even_remaining = n - 9
            if even_remaining < 4:
                print(-1)
                continue
            # Compute summands for even_remaining
            if even_remaining == 4:
                sum_even = 1
            else:
                rem_even = even_remaining % 4
                if rem_even == 0:
                    sum_even = even_remaining // 4
                elif rem_even == 2:
                    m_even = even_remaining - 6
                    if m_even < 0:
                        sum_even = -1
                    else:
                        sum_even = (m_even // 4) + 1
                else:
                    sum_even = -1
            if sum_even == -1:
                print(-1)
            else:
                print(1 + sum_even)

solve()
```

### Explanation
- **Even Numbers**: The solution leverages the smallest composite number (4) and adjusts for remainders by using 6 when necessary.
- **Odd Numbers**: By subtracting the smallest odd composite (9), the problem is reduced to handling an even number, which is then solved using the even number strategy.
- This approach efficiently handles all edge cases and ensures the maximum number of composite summands by prioritizing smaller composites. The complexity is O(1) per query, making it suitable for large input sizes up to \( 10^5 \).
