To solve this problem, we need to determine if Ken can reach vertex T from vertex S by repeating ken-ken-pa (a sequence of exactly three steps) and find the minimum number of such sequences required if possible. 

### Approach
1. **Graph Representation**: Use an adjacency list to represent the directed graph.
2. **State Tracking**: Track the current vertex and the number of steps taken modulo 3. This helps in determining when a ken-ken-pa sequence is completed.
3. **Breadth-First Search (BFS)**: Perform BFS on a modified state space where each state is a pair (current vertex, steps modulo 3). This allows us to efficiently explore the shortest path in terms of ken-ken-pa sequences.
4. **Distance Calculation**: Maintain a distance array to track the minimum number of steps taken to reach each state. The number of ken-ken-pa sequences is derived from the distance by dividing by 3.

### Solution Code
```python
import sys
from collections import deque

def main():
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    M = int(input[ptr])
    ptr += 1

    adj = [[] for _ in range(N + 1)]
    for _ in range(M):
        u = int(input[ptr])
        ptr += 1
        v = int(input[ptr])
        ptr += 1
        adj[u].append(v)
    
    S = int(input[ptr])
    ptr += 1
    T = int(input[ptr])

    # Initialize distance array with -1 for all states
    dist = [[-1] * 3 for _ in range(N + 1)]
    dist[S][0] = 0  # Starting at S with 0 steps in the current ken-ken-pa

    q = deque()
    q.append((S, 0))

    while q:
        u, r = q.popleft()
        for v in adj[u]:
            new_r = (r + 1) % 3
            if dist[v][new_r] == -1:
                dist[v][new_r] = dist[u][r] + 1
                q.append((v, new_r))
                # Optional: Early exit if target is found (optimization)
                if v == T and new_r == 0:
                    q = deque()  # Clear the queue to exit
                    break

    if dist[T][0] != -1:
        print(dist[T][0] // 3)
    else:
        print(-1)

if __name__ == '__main__':
    main()
```

2. **State Tracking**: Each state in the BFS is represented as a tuple (vertex, steps modulo 3). This helps track the progress within each ken-ken-pa sequence.
3. **BFS Execution**: The BFS explores each state, updating the minimum steps required to reach each vertex at each step in the sequence. If a state (T, 0) is reached, it means T is reached exactly after completing a ken-ken-pa sequence.
4. **Result Calculation**: The minimum number of ken-ken-pa sequences is derived by dividing the total steps to reach (T, 0) by 3, as each sequence consists of exactly three steps.
