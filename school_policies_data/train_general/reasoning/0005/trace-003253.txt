To solve this problem, we need to efficiently compute the sum of the number of set bits (bits equal to 1) in the binary representation of all integers in the range [A, B] for multiple test cases. Given the constraints, a brute force approach is infeasible, so we use a more optimized method based on bit manipulation and mathematical patterns.

### Approach
1. **Helper Function**: We create a helper function `count_set_bits(X)` that computes the sum of set bits from 0 to X. This function leverages the observation that each bit position contributes to the total set bits in a predictable cycle.
2. **Cycle Analysis**: For each bit position `i`, the number of times it is set follows a cycle of `2^(i+1)`. Within each cycle, the first half are zeros and the second half are ones. Using this pattern, we can compute the contribution of each bit position efficiently.
3. **Range Sum Calculation**: For each test case, compute the sum of set bits from 0 to B using the helper function and subtract the sum of set bits from 0 to A-1 to get the result for the range [A, B].

### Solution Code
```python
import sys

def count_set_bits(X):
    if X < 0:
        return 0
    total = 0
    for i in range(31):  # Covering all bits up to 2^30 (sufficient for 1e9)
        mask = 1 << i
        cycle = mask << 1  # 2^(i+1)
        full_cycles = (X + 1) // cycle
        count = full_cycles * mask
        remainder = (X + 1) % cycle
        if remainder > mask:
            count += remainder - mask
        total += count
    return total

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        A = int(input[idx])
        B = int(input[idx + 1])
        idx += 2
        result = count_set_bits(B) - count_set_bits(A - 1)
        print(result)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Helper Function `count_set_bits(X)`**:
   - This function calculates the sum of set bits for all numbers from 0 to X.
   - For each bit position `i`, it calculates how many full cycles of `2^(i+1)` fit into X+1. Each full cycle contributes `2^i` set bits.
   - The remainder of the division gives the partial cycle, and any remaining numbers beyond `2^i` in this partial cycle are added to the count.

2. **Main Function**:
   - Reads all input at once for efficiency, especially given the large number of test cases.
   - For each test case, it computes the sum of set bits from 0 to B and subtracts the sum from 0 to A-1 to get the result for the range [A, B].

This approach ensures that each test case is processed in O(31) time, making the solution efficient even for the upper constraint limits.
