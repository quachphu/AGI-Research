To solve this problem, we need to determine whether to draw an additional card in a game based on the probability that the new total will be 20 or less. The decision is made by checking if this probability is 50% or higher using the known cards and the opponent's visible card.

### Approach
1. **Understand the Input**: Each input line consists of three integers representing your two cards and the opponent's visible card.
2. **Calculate Current Sum**: Compute the sum of your two cards.
3. **Identify Available Cards**: Determine the remaining cards that are not your two cards or the opponent's visible card.
4. **Check Valid Draws**: For each available card, check if adding it to your current sum results in a total of 20 or less.
5. **Probability Check**: If the number of valid draws is at least 50% of the available cards, output "YES"; otherwise, output "NO".

### Solution Code
```python
import sys

def should_draw_card():
    for line in sys.stdin:
        c1, c2, c3 = map(int, line.strip().split())
        current_sum = c1 + c2
        used = {c1, c2, c3}
        available = [x for x in range(1, 11) if x not in used]
        count = 0
        for x in available:
            if current_sum + x <= 20:
                count += 1
        print("YES" if count >= 4 else "NO")

should_draw_card()
```

### Explanation
1. **Reading Input**: The input is read line by line, each line containing three integers.
2. **Current Sum Calculation**: The sum of your two cards is computed to know the starting point before drawing another card.
3. **Available Cards**: We create a list of cards that are not already in use (your two cards and the opponent's visible card).
4. **Valid Draws Check**: For each card in the available list, check if adding it to your current sum keeps the total at 20 or less.
5. **Probability Calculation**: If 4 or more of the 7 available cards result in a valid total (≤20), the probability is 50% or higher, prompting a "YES". Otherwise, "NO" is printed.

This approach efficiently checks the conditions using simple arithmetic and list comprehensions, ensuring the solution is both optimal and easy to understand.
