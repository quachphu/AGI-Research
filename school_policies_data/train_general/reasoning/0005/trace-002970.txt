To solve this problem, we need to determine if Ravi's announced string is present in a sorted list of strings. The solution must efficiently check the presence of the string using the fact that the list is already sorted.

### Approach
1. **Input Reading**: Read all input at once and split it into tokens for efficient processing.
2. **Binary Search**: Utilize the `bisect` module to perform a binary search on the sorted list. This reduces the time complexity of each search operation to O(log N), which is efficient even for large values of N.
3. **Check Presence**: For each test case, after reading the list of strings and Ravi's string, use binary search to check if the string exists in the list. If it does, output "yes"; otherwise, output "no".

### Solution Code
```python
import bisect
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        arr = []
        for _ in range(N):
            s = input[ptr]
            arr.append(s)
            ptr += 1
        ravi_str = input[ptr]
        ptr += 1
        idx = bisect.bisect_left(arr, ravi_str)
        if idx < len(arr) and arr[idx] == ravi_str:
            print("yes")
        else:
            print("no")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of tokens. This allows for efficient processing without repeated I/O operations.
2. **Binary Search with `bisect`**: The `bisect_left` function from the `bisect` module is used to find the position where Ravi's string would be inserted to maintain the sorted order. If the string at this position matches Ravi's string, it means the string is present in the list.
3. **Efficiency**: The use of binary search ensures that each check operation is efficient, with a time complexity of O(log N), making the solution suitable even for large input sizes.

This approach efficiently handles up to the maximum constraints provided, ensuring quick and accurate results for each test case.
