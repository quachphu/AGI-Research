This involves reading input values, processing them to compute the required results, and then printing those results in the specified format.

### Approach
1. **Reading Input:** The first input line contains an integer \( N \), representing the number of distances. The second line contains \( N \) space-separated integers, each representing a distance.
2. **Reversing the Distances:** We need to reverse the order of the given distances to simulate the reverse journey.
3. **Summing the Distances:** Calculate the total distance by summing all the provided distances.
4. **Output the Results:** Print the reversed distances followed by the total sum.

### Solution Code
```python
def main():
    import sys
    n = int(sys.stdin.readline())
    distances = list(map(int, sys.stdin.readline().split()))
    reversed_distances = distances[::-1]
    total = sum(distances)
    print(' '.join(map(str, reversed_distances)))
    print(total)

main()
```

### Explanation
1. **Reading Input:** The function reads the number of distances \( N \) from the first line and the list of distances from the second line.
2. **Reversing the List:** The list of distances is reversed using slicing (`[::-1]`), which creates a new list in reverse order.
3. **Summing Distances:** The total distance is computed using the built-in `sum` function on the original list of distances.
4. **Output:** The reversed distances are printed as a space-separated string, followed by the total sum on the next line.

This approach ensures that we efficiently process the input, reverse the list, compute the sum, and output the results in the required format. The solution is straightforward and leverages Python's built-in functions for clarity and efficiency.
