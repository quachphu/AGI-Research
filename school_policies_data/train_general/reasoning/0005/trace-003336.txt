To solve this problem, we need to determine the minimum energy Vasiliy has to spend to sort a list of strings lexicographically by reversing some of them. Each reversal operation has a specific energy cost, and our goal is to achieve the sorted order with the minimum total energy cost or determine if it's impossible.

### Approach
1. **Dynamic Programming (DP) Approach**: We use dynamic programming to track the minimum energy cost required to maintain lexicographical order up to each string, considering both the reversed and non-reversed states of each string.
2. **State Tracking**: For each string, we maintain two states: one where the string is not reversed and another where it is reversed. The DP states track the minimum energy required to reach each state while maintaining the lexicographical order.
3. **Transition Between States**: For each string, we check if it can follow the previous string in either its reversed or non-reversed state, and update the current state's energy cost accordingly.
4. **Precompute Reversed Strings**: To efficiently compare reversed strings, we precompute the reversed version of each string.

### Solution Code
```python
n = int(input())
c = list(map(int, input().split()))
s = [input().strip() for _ in range(n)]
reversed_s = [string[::-1] for string in s]

if n == 0:
    print(0)
    exit()

# Initialize previous states
prev_not_rev = 0
prev_rev = c[0]

for i in range(1, n):
    curr_not_rev = float('inf')
    curr_rev = float('inf')
    
    # Check transitions for current not reversed
    if s[i] >= s[i-1]:
        curr_not_rev = prev_not_rev
    if s[i] >= reversed_s[i-1] and prev_rev < curr_not_rev:
        curr_not_rev = prev_rev
    
    # Check transitions for current reversed
    if reversed_s[i] >= s[i-1]:
        curr_rev = prev_not_rev + c[i]
    if reversed_s[i] >= reversed_s[i-1] and (prev_rev + c[i] < curr_rev):
        curr_rev = prev_rev + c[i]
    
    # Check if both states are impossible
    if curr_not_rev == float('inf') and curr_rev == float('inf'):
        print(-1)
        exit()
    
    prev_not_rev, prev_rev = curr_not_rev, curr_rev

print(result if result != float('inf') else -1)
```
