To solve this problem, we need to determine the maximum length of a regular bracket sequence that can be obtained by removing some brackets from a given string. A regular bracket sequence is one where every opening bracket '(' has a corresponding closing bracket ')' in the correct order.

### Approach
The approach to solve this problem involves using a balance counter to track the number of valid pairs of brackets as we traverse the string from left to right. Here's the step-by-step breakdown:

1. **Initialize Counters**: We use two counters, `balance` to track the number of unmatched opening brackets and `res` to track the total length of the valid bracket sequence.

2. **Traverse the String**: For each character in the string:
   - If the character is an opening bracket '(', increment the `balance` counter.
   - If the character is a closing bracket ')', check if there is an unmatched opening bracket (i.e., `balance` > 0). If so, decrement the `balance` and increment `res` by 2 (since each valid pair contributes 2 to the length).

3. **Result**: The value of `res` after processing the entire string gives the maximum length of the regular bracket sequence.

### Solution Code
```python
def max_regular_brackets():
    s = input().strip()
    balance = 0
    res = 0
    for c in s:
        if c == '(':
            balance += 1
        else:
            if balance > 0:
                balance -= 1
                res += 2
    print(res)

max_regular_brackets()
```

### Explanation
- **Balance Counter**: The `balance` counter helps ensure that each closing bracket ')' has a corresponding opening bracket '(' before it. This ensures the correct order of brackets.
- **Result Calculation**: By incrementing `res` by 2 each time a valid pair is found, we effectively count the length contributed by each pair of brackets.

This approach efficiently processes the string in a single pass, resulting in a time complexity of O(n), where n is the length of the input string. This makes the solution optimal even for the upper constraint of the input size (up to 10^6 characters).
