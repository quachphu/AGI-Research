To solve this problem, we need to determine if it's possible to stack all disks on a single pillar following specific movement rules. The key insight is that the disks must form a sequence that allows each disk to be moved to an adjacent pillar in a strictly decreasing order.

### Approach
1. **Identify the Maximum Disk**: The largest disk must be at the bottom of the final stack. This disk's position is the starting point.
2. **Check Contiguous Sequence**: The disks must be arranged such that each subsequent smaller disk can be placed adjacent to the current stack. This means checking if the indices of the disks, when sorted in descending order, form a contiguous sequence expanding from the maximum disk's position.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))

# Create a list of tuples (value, index) sorted in descending order
sorted_pairs = sorted([(val, idx) for idx, val in enumerate(a)], reverse=True, key=lambda x: x[0])
indices = [idx for val, idx in sorted_pairs]

left = right = indices[0]
possible = True

for i in range(1, n):
    current_idx = indices[i]
    if current_idx == left - 1:
        left -= 1
    elif current_idx == right + 1:
        right += 1
    else:
        possible = False
        break

print("YES" if possible else "NO")
```
