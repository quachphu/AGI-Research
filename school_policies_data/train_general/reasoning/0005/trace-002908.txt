To solve this problem, we need to simulate the Amidakuji (Japanese ladder drawing) process where horizontal lines swap the positions of numbers assigned to vertical lines. The goal is to determine the final positions of these numbers after applying all given horizontal lines.

### Approach
1. **Initialization**: Start with numbers 1 to `w` (where `w` is the number of vertical lines) in ascending order from left to right.
2. **Processing Horizontal Lines**: For each horizontal line, which connects two vertical lines, swap the numbers at those positions. The order of processing these horizontal lines is from top to bottom as given in the input.
3. **Output the Result**: After applying all horizontal lines, the final positions of the numbers are printed.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    w = int(input[0])
    n = int(input[1])
    lines = input[2:2+n]
    
    lst = list(range(1, w + 1))
    
    for line in lines:
        a, b = map(int, line.split(','))
        lst[a-1], lst[b-1] = lst[b-1], lst[a-1]
    
    for num in lst:
        print(num)

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list for easier processing. The first two elements are `w` (number of vertical lines) and `n` (number of horizontal lines).
2. **Initial Setup**: The initial list of numbers from 1 to `w` is created.
3. **Swapping Process**: For each horizontal line, the corresponding vertical line indices are determined, and the numbers at these indices are swapped.
4. **Output**: The final list after all swaps is printed, with each number on a new line.

This approach efficiently processes each horizontal line in sequence, ensuring the correct swaps are applied to simulate the Amidakuji process accurately. The solution handles up to 30 vertical and horizontal lines as specified, ensuring correctness within the problem constraints.
