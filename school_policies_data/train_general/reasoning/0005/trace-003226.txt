To solve this problem, we need to determine the number of ways to form a group of exactly `t` actors from `n` boys and `m` girls, ensuring the group has at least 4 boys and 1 girl. The solution involves calculating combinations for valid configurations of boys and girls that meet the criteria.

### Approach
1. **Understand the Constraints**: The group must have exactly `t` actors, with at least 4 boys and 1 girl. Therefore, the number of boys in the group can range from 4 to the minimum of `n` (since we can't have more boys than available) and `t-1` (since each group must have at least 1 girl).
2. **Iterate Over Possible Boys Count**: For each possible number of boys `b` (from 4 up to the determined maximum), calculate the corresponding number of girls `g` as `t - b`.
3. **Validate Girls Count**: Check if `g` is within the valid range (1 to `m`). If valid, compute the combinations for choosing `b` boys from `n` and `g` girls from `m`.
4. **Sum Combinations**: Accumulate the product of valid combinations for each valid configuration of boys and girls.

### Solution Code
```python
import math

n, m, t = map(int, input().split())
total = 0
max_b = min(n, t - 1)
for b in range(4, max_b + 1):
    g = t - b
    if 1 <= g <= m:
        total += math.comb(n, b) * math.comb(m, g)
print(total)
```

### Explanation
1. **Reading Input**: The input values for `n`, `m`, and `t` are read and parsed.
2. **Determine Maximum Boys**: Calculate the maximum number of boys (`max_b`) as the minimum of `n` and `t-1` to ensure at least 1 girl.
3. **Iterate and Validate**: For each possible number of boys `b` from 4 to `max_b`, compute the corresponding number of girls `g`. Check if `g` is within the valid range (1 to `m`).
4. **Calculate Combinations**: Use the combination formula `C(n, k)` to compute the number of ways to choose `b` boys from `n` and `g` girls from `m`. Accumulate the product of these combinations.
5. **Output Result**: Print the total number of valid groups.

This approach efficiently iterates over all valid configurations, ensuring that each combination meets the problem's constraints, and sums up the valid possibilities to get the result.
