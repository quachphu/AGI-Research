To solve this problem, we need to remove duplicate characters from each given word while preserving the order of their first appearance. The solution involves processing multiple test cases efficiently.

### Approach
1. **Read Input:** Read the number of test cases, followed by each test case word.
2. **Track Characters:** For each word, use a set to track characters that have already been encountered.
3. **Build Result:** Iterate through each character of the word. If a character has not been encountered before, add it to the result list and mark it as seen.
4. **Output Result:** After processing each word, join the characters in the result list into a string and print it.

This approach ensures that each character is processed in linear time relative to the length of the word, making the solution efficient with a time complexity of O(n) per word, where n is the length of the word.

### Solution Code
```python
import sys

def main():
    T = int(sys.stdin.readline())
    for _ in range(T):
        word = sys.stdin.readline().strip()
        seen = set()
        result = []
        for char in word:
            if char not in seen:
                seen.add(char)
                result.append(char)
        print(''.join(result))

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input:** The input is read using `sys.stdin.readline()` for efficiency, especially when dealing with multiple lines of input.
- **Tracking Characters:** A set `seen` is used to keep track of characters that have already been added to the result. This allows for O(1) average time complexity for membership checks.
- **Building Result:** A list `result` is used to maintain the order of characters as they first appear. This list is then joined into a string to form the final output for each test case.
- **Efficiency:** Each character in the word is processed exactly once, ensuring that the solution runs efficiently even for the upper constraint limits.

This method ensures that the output maintains the order of the first appearance of each character while efficiently removing duplicates.
