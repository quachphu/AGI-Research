To solve this problem, we need to determine the number of times each player (Nikephoros and Polycarpus) loses in a series of Rock-Paper-Scissors games played over `n` rounds. Each player follows a cyclic sequence of moves, and we need to efficiently compute the results without simulating each of the potentially very large number of rounds individually.

### Approach
1. **Identify Cycles**: Each player's moves repeat cyclically. The combined cycle length of both players' sequences is the least common multiple (LCM) of the lengths of their sequences. This LCM determines the period after which the interaction pattern between the two sequences repeats.
2. **Compute Losses in One Cycle**: Calculate the number of losses for each player within one full LCM cycle.
3. **Handle Full Cycles and Remainders**: Determine how many full LCM cycles fit into `n` rounds and compute the losses for these full cycles. Then, handle the remaining rounds after the last full cycle separately.

### Solution Code
```python
import math

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a_str = input[1]
    b_str = input[2]
    
    m = len(a_str)
    k = len(b_str)
    
    gcd_val = math.gcd(m, k)
    lcm = m * k // gcd_val
    
    cycle_nik = 0
    cycle_poly = 0
    
    # Calculate losses in one full LCM cycle
    for i in range(lcm):
        a = a_str[i % m]
        b = b_str[i % k]
        if a == b:
            continue
        # Determine the outcome
        if (a == 'R' and b == 'S') or (a == 'S' and b == 'P') or (a == 'P' and b == 'R'):
            cycle_poly += 1
        else:
            cycle_nik += 1
    
    full_cycles = n // lcm
    remainder = n % lcm
    
    total_nik = full_cycles * cycle_nik
    total_poly = full_cycles * cycle_poly
    
    # Calculate losses in the remaining rounds
    for i in range(remainder):
        a = a_str[i % m]
        b = b_str[i % k]
        if a == b:
            continue
        if (a == 'R' and b == 'S') or (a == 'S' and b == 'P') or (a == 'P' and b == 'R'):
            total_poly += 1
        else:
            total_nik += 1
    
    print(total_nik, total_poly)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed to extract the number of rounds `n` and the sequences of moves for both players.
2. **Cycle Length Calculation**: The LCM of the lengths of the two sequences is computed to determine the combined cycle length.
3. **Loss Calculation in One Cycle**: For each position in the combined cycle, the moves of both players are determined, and the result (win, lose, or draw) is computed. Losses for each player are accumulated over one full cycle.
4. **Full Cycles and Remainders**: The total number of losses is computed by multiplying the losses from one full cycle by the number of complete cycles and then adding the losses from any remaining rounds after the last complete cycle.

This approach efficiently handles the potentially large value of `n` by leveraging the periodic nature of the players' move sequences, ensuring that the solution runs in time proportional to the cycle length rather than `n` itself.
