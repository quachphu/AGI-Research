To solve this problem, we need to transform a given string into a "good" string by deleting the minimum number of characters. A "good" string is defined as having an even length and each pair of consecutive characters (at even and odd indices) being different.

### Approach
1. **Greedy Strategy**: We will iterate through the string and build the result character by character using a greedy approach. This ensures that we form the longest possible valid string by making locally optimal choices at each step.
2. **Pair Formation**: As we iterate through the string, we maintain a result list. If the current length of the result is even, we add the next character unconditionally. If the length is odd, we add the next character only if it is different from the last character in the result list. This ensures each pair of consecutive characters is different.
3. **Post-Processing**: After constructing the result, if its length is odd, we remove the last character to ensure the final string has an even length.

### Solution Code
```python
n = int(input())
s = input().strip()

res = []
for c in s:
    if len(res) % 2 == 0:
        res.append(c)
    else:
        if c != res[-1]:
            res.append(c)

if len(res) % 2 != 0:
    res.pop()

k = n - len(res)
print(k)
if res:
    print(''.join(res))
```

### Explanation
1. **Reading Input**: We read the input values for the string length `n` and the string `s`.
2. **Building the Result**: We iterate through each character in the string. Using a list `res`, we add characters based on whether the current length is even or odd. If the length is even, we add the character to start a new pair. If the length is odd, we add the character only if it differs from the last character in `res` to complete the current pair.
3. **Adjusting Length**: After processing all characters, if the length of `res` is odd, we remove the last character to ensure the result is even-length.
4. **Output**: We calculate the number of deletions as the difference between the original length and the length of the result. Finally, we print the number of deletions and the resulting string if it is non-empty.

This approach efficiently constructs the longest possible valid string using a linear scan, ensuring optimal performance even for the upper constraint limits.
