To solve this problem, we need to determine the total number of digits pressed by a troublemaker who calls all "boring" apartments in a specific order until someone answers. A boring apartment is defined as one where all digits are the same (e.g., 1, 22, 777). The troublemaker calls these apartments in ascending order of their digits and lengths.

### Approach
1. **Understanding the Order**: The troublemaker calls apartments starting with digit 1, then 2, up to 9. For each digit, he calls apartments of lengths 1, 2, 3, and 4 in that order.
2. **Summing Digits**: For each test case, we need to compute the total number of digits pressed up to and including the apartment that answered. This involves:
   - Calculating the sum of digits for all apartments with digits less than the answered apartment's digit.
   - Calculating the sum of digits for all apartments of the same digit but with lengths up to the answered apartment's length.

### Solution Code
```python
t = int(input())
for _ in range(t):
    x = input().strip()
    d = int(x[0])
    l = len(x)
    total = (d - 1) * 10 + (l * (l + 1)) // 2
    print(total)
```

### Explanation
1. **Reading Input**: We first read the number of test cases.
2. **Processing Each Test Case**:
   - Convert the apartment number to a string to easily determine the digit and length.
   - The digit `d` is the first character of the string converted to an integer.
   - The length `l` is the number of characters in the string.
3. **Calculating Total Digits**:
   - For digits less than `d`, each contributes 10 digits (sum of 1+2+3+4). This is calculated as `(d - 1) * 10`.
   - For the current digit `d`, the sum of digits from length 1 up to `l` is given by the formula `(l * (l + 1)) // 2`.

This approach efficiently computes the required sum using simple arithmetic operations, ensuring optimal performance even for the upper limits of the input constraints.
