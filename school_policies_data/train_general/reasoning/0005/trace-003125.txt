To solve this problem, we need to count the number of substrings of a given string that can be typed using a restricted set of characters available on a broken keyboard. The solution involves identifying contiguous blocks of allowed characters and calculating the number of valid substrings within each block.

### Approach
1. **Identify Allowed Characters**: Convert the list of allowed characters into a set for O(1) lookup time.
2. **Traverse the String**: Iterate through the string while keeping track of the length of contiguous blocks of allowed characters.
3. **Calculate Substrings**: For each contiguous block of allowed characters of length `l`, the number of valid substrings is given by the formula `l * (l + 1) / 2`. Sum these values for all blocks to get the total count of valid substrings.

### Solution Code
```python
n, k = map(int, input().split())
s = input().strip()
allowed = set(input().split())

current = 0
total = 0

for char in s:
    if char in allowed:
        current += 1
    else:
        total += current * (current + 1) // 2
        current = 0
total += current * (current + 1) // 2

print(total)
```

### Explanation
1. **Reading Input**: The input consists of the string length `n`, the number of allowed characters `k`, the string `s`, and the allowed characters.
2. **Tracking Contiguous Blocks**: As we iterate through the string, we maintain a counter `current` to track the length of the current block of allowed characters. When encountering a disallowed character, we compute the number of substrings for the current block and reset the counter.
3. **Summing Substrings**: After processing the entire string, we add the substrings count for any remaining block of allowed characters.

This approach efficiently processes the string in linear time, O(n), making it suitable for large input sizes up to 200,000 characters. The use of a set ensures quick membership checks for allowed characters.
