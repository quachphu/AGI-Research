To solve this problem, we need to determine the minimum number of moves required for Polycarp to destroy both the stone with the minimum power and the stone with the maximum power. Each move can only remove the leftmost or rightmost stone from the current row of stones.

### Approach
1. **Identify Positions**: For each test case, identify the positions of the stone with the minimum power and the stone with the maximum power.
2. **Calculate Scenarios**: Determine the minimum moves required by considering three possible scenarios:
   - Removing stones from the left until both the minimum and maximum stones are removed.
   - Removing stones from the right until both the minimum and maximum stones are removed.
   - Removing stones from both ends in a way that minimizes the total moves required.
3. **Select Optimal Solution**: The optimal solution is the minimum value derived from the three scenarios mentioned above.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    min_val = min(a)
    max_val = max(a)
    min_idx = a.index(min_val)
    max_idx = a.index(max_val)
    left = min(min_idx, max_idx)
    right = max(min_idx, max_idx)
    option1 = right + 1
    option2 = n - left
    option3 = (left + 1) + (n - right)
    print(min(option1, option2, option3))
```

### Explanation
1. **Identify Positions**: For each test case, we find the indices of the minimum and maximum values in the array.
2. **Calculate Scenarios**:
   - **Option 1**: The number of moves required if we remove stones from the left until we reach the rightmost of the two critical stones (either min or max).
   - **Option 2**: The number of moves required if we remove stones from the right until we reach the leftmost of the two critical stones.
   - **Option 3**: The sum of moves required to remove stones from the left up to the leftmost critical stone and then from the right up to the rightmost critical stone.
3. **Optimal Solution**: By taking the minimum value among the three calculated options, we ensure the least number of moves required to achieve the goal.

This approach efficiently narrows down the problem to three key scenarios, ensuring we find the optimal solution in linear time relative to the number of stones, which is efficient given the constraints.
