To solve this problem, we need to find the longest consecutive substring (stem) that occurs in all given words. If there are multiple such substrings of the same maximum length, we choose the lexicographically smallest one.

### Approach
1. **Identify the Shortest Word**: The longest possible common substring cannot be longer than the shortest word in the list. Thus, we start by identifying the shortest word to limit our search scope.
2. **Generate Substrings**: For the shortest word, generate all possible substrings starting from the longest possible length down to 1.
3. **Check Presence in All Words**: For each generated substring, check if it exists in every word provided.
4. **Select the Longest and Lexicographically Smallest**: Once valid substrings of a certain length are found, sort them lexicographically and select the smallest one. If no valid substrings are found at the current length, decrement the length and repeat the process.

### Solution Code
```python
def find_stem():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        n = int(input[ptr])
        ptr += 1
        words = input[ptr:ptr + n]
        ptr += n
        base_word = min(words, key=lambda x: len(x))
        max_len = len(base_word)
        result = ''
        for l in range(max_len, 0, -1):
            candidates = []
            for i in range(len(base_word) - l + 1):
                substr = base_word[i:i + l]
                all_present = True
                for word in words:
                    if substr not in word:
                        all_present = False
                        break
                if all_present:
                    candidates.append(substr)
            if candidates:
                candidates.sort()
                result = candidates[0]
                break
        print(result)
```

1. **Reading Input**: The input is read as a single string split into parts for easier processing. The first value is the number of test cases.
2. **Processing Each Test Case**: For each test case, read the number of words and the words themselves.
3. **Finding the Shortest Word**: Determine the shortest word to limit the substring generation to its length.
4. **Generating Substrings**: For each possible length from the maximum down to 1, generate all substrings of that length from the shortest word.
5. **Checking Validity**: For each substring, check if it exists in all words. Collect valid substrings and sort them to find the lexicographically smallest one.
6. **Output the Result**: Print the result for each test case once the valid substring is found.

This approach ensures that we efficiently find the longest common substring by leveraging the constraints and properties of substrings, while also handling ties lexicographically.
