To solve this problem, we need to simulate pouring water into a series of vertically arranged vessels and handle overflow efficiently. The key challenge is to manage the overflow process in an optimal manner to avoid excessive computational complexity.

### Approach
1. **Problem Analysis**: When water is poured into a vessel, it can overflow into subsequent vessels. Each query either adds water to a vessel or requests the current amount of water in a specific vessel. Directly simulating each overflow step by step would be too slow for large inputs, so we need an optimized approach.

2. **Union-Find Data Structure**: We use a union-find (disjoint set) data structure to efficiently track the next available vessel that can accept water. This helps in quickly finding the next vessel that is not yet full, allowing us to handle overflow in logarithmic time with path compression.

3. **Handling Queries**:
   - **Add Water**: When adding water to a vessel, we use the union-find structure to find the next available vessel. We distribute the water as much as possible and update the next available vessel if the current one becomes full.
   - **Check Water Level**: Directly return the current water level from the stored array.

### Solution Code
```python
import sys
sys.setrecursionlimit(1 << 25)

def main():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    a = [0] + a  # 1-based indexing
    m = int(sys.stdin.readline())
    
    parent = list(range(n + 2))  # 1 to n+1, parent[n+1] = n+1
    w = [0] * (n + 2)  # water in each vessel, 1-based to n

    def find(u):
        while parent[u] != u:
            parent[u] = parent[parent[u]]
            u = parent[u]
        return u

    for _ in range(m):
        query = sys.stdin.readline().split()
        if not query:
            continue
        if query[0] == '1':
            p = int(query[1])
            x = int(query[2])
            current = find(p)
            while x > 0 and current <= n:
                available = a[current] - w[current]
                if available <= 0:
                    current = find(current + 1)
                    continue
                add = min(available, x)
                w[current] += add
                x -= add
                if w[current] == a[current]:
                    # Update parent to point to the next available
                    parent[current] = find(current + 1)
                # Move to the next available vessel
                current = find(current + 1)
        else:
            k = int(query[1])
            print(w[k])

if __name__ == "__main__":
    main()
```

### Explanation
- **Union-Find Structure**: This helps track the next available vessel efficiently. When a vessel is filled, we update its parent to point to the next available vessel, allowing subsequent queries to skip over filled vessels quickly.
- **Path Compression**: This optimization ensures that each find operation runs in nearly constant time, making the union-find operations efficient even for large inputs.
- **Efficient Overflow Handling**: By using the union-find structure, we avoid iterating through each vessel sequentially during overflow, instead jumping directly to the next available vessel.

This approach ensures that each query is handled in logarithmic time, making the solution efficient and scalable for large inputs.
