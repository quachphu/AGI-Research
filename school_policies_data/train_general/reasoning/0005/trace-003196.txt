To solve this problem, we need to generate a string of length `n` using the characters 'a', 'b', and 'c' such that no three consecutive characters form a palindrome. Additionally, we want to minimize the use of the character 'c'.

### Approach
The key insight is to construct the string in a way that avoids palindromic substrings of length 3. A palindrome of length 3 occurs when the first and third characters are the same. To prevent this, we can use a repeating pattern that ensures every third character is different from the one two positions before it.

We can use a pattern such as 'aabb' repeated as necessary. This pattern ensures that no three consecutive characters form a palindrome. By alternating between 'a' and 'b' in a structured manner, we avoid the need for 'c' entirely.

### Solution Code
```python
n = int(input())
s = []
for i in range(n):
    if i % 4 in (0, 1):
        s.append('a')
    else:
        s.append('b')
print(''.join(s))
```

### Explanation
The solution uses a repeating pattern of 'aabb' to construct the string. Here's the detailed breakdown:

1. **Pattern Selection**: The pattern 'aabb' is chosen because it ensures that every third character is different from the one two positions before it. This avoids palindromic substrings of length 3.
2. **Index Handling**: For each index `i`, if `i` modulo 4 is 0 or 1, we append 'a' to the string. For all other indices, we append 'b'. This creates the 'aabb' repetition.
3. **Efficiency**: The algorithm runs in O(n) time complexity, which is efficient for the given constraint (1 ≤ n ≤ 2·10^5).

This approach ensures that the resulting string meets the problem requirements while minimizing the use of 'c', thus providing an optimal solution.
