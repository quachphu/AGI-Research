To solve this problem, we need to maximize Raju's expected number of wins by selecting non-overlapping lottery matches. The solution involves dynamic programming to efficiently compute the optimal subset of matches.

### Approach
1. **Problem Analysis**: Raju can only participate in non-overlapping matches. Each match has a start time, end time, and a winning probability. The goal is to select matches such that the sum of their winning probabilities is maximized.

2. **Dynamic Programming Insight**: This problem is a variation of the weighted interval scheduling problem. The key is to sort the matches by their end times and use dynamic programming to keep track of the maximum expected value up to each match.

3. **Binary Search for Efficiency**: For each match, we use binary search to quickly find the latest non-overlapping match. This allows us to efficiently compute the optimal subset of matches without checking all previous matches.

4. **Dynamic Programming Setup**: We maintain a DP array where each entry `dp[i]` represents the maximum expected value considering the first `i` matches. The recurrence relation considers whether including the current match (plus the best non-overlapping previous matches) or excluding it yields a higher value.

### Solution Code
```python
import bisect

def solve():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        matches = []
        for _ in range(N):
            st = int(input[ptr])
            et = int(input[ptr+1])
            wp = int(input[ptr+2])
            ptr += 3
            value = wp / 100.0
            matches.append((st, et, value))
        # Sort matches by end time
        matches.sort(key=lambda x: x[1])
        n = len(matches)
        if n == 0:
            print("0.00")
            continue
        end_times = [m[1] for m in matches]
        dp = [0.0] * n
        dp[0] = matches[0][2]
        for i in range(1, n):
            st_i = matches[i][0]
            # Find the latest non-overlapping match using bisect
            j = bisect.bisect_right(end_times, st_i, 0, i) - 1
            prev_val = dp[j] if j >= 0 else 0.0
            option1 = prev_val + matches[i][2]
            option2 = dp[i-1]
            dp[i] = max(option1, option2)
        result = dp[-1]
        print("{0:.2f}".format(result))

solve()
```

4. **Dynamic Programming Array**: The DP array is built iteratively, considering each match and deciding whether to include it based on the maximum expected value from non-overlapping matches.

This approach ensures that we efficiently compute the optimal solution using dynamic programming and binary search, resulting in a time complexity of O(N log N) per test case, which is suitable given the problem constraints.
