To solve this problem, we need to find the number of pairs (A, B) of positive integers not greater than N that satisfy the condition where the last digit of A equals the first digit of B, and the first digit of A equals the last digit of B. 

### Approach
1. **Precompute Digit Pairs**: For each number from 1 to N, compute the first and last digits. Track how many times each (first digit, last digit) pair occurs using a 2D array.
2. **Count Valid Pairs**: For each valid (first digit, last digit) pair (f, l), the valid pairs (A, B) are those where A has (f, l) and B has (l, f). Multiply the count of (f, l) pairs by the count of (l, f) pairs and sum these products to get the total number of valid pairs.

### Solution Code
```python
n = int(input())

# Initialize a 10x10 array to count occurrences of (first digit, last digit) pairs
count = [[0] * 10 for _ in range(10)]

for x in range(1, n + 1):
    last = x % 10
    if last == 0:
        continue  # Skip numbers ending with 0 as they can't form valid pairs
    first = x
    while first >= 10:
        first //= 10
    count[first][last] += 1

answer = 0
for f in range(1, 10):
    for l in range(1, 10):
        answer += count[f][l] * count[l][f]

print(answer)
```

### Explanation
1. **Reading Input**: The input value N is read, which determines the range of numbers to consider.
2. **Tracking Digit Pairs**: We use a 2D array `count` to keep track of how many times each (first digit, last digit) pair appears among the numbers from 1 to N. This is done by iterating through each number, computing its first and last digits, and updating the count array.
3. **Computing Valid Pairs**: After populating the count array, we calculate the total number of valid pairs by iterating over all possible (f, l) pairs. For each pair (f, l), the number of valid (A, B) pairs is given by the product of the count of (f, l) pairs and the count of (l, f) pairs. Summing these products gives the final answer.

This approach efficiently reduces the problem to O(N) complexity for processing each number and O(1) for summing the valid pairs, making it suitable for large values of N up to 200,000.
