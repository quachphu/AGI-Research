To solve this problem, we need to find the shortest path from the start point 'S' to the end point 'E' in a grid where we can only move through paths marked 'P' and avoid trees marked 'T'. The solution involves using the Breadth-First Search (BFS) algorithm, which is efficient for finding the shortest path in an unweighted grid.

### Approach
1. **Parse Input**: Read the grid dimensions and the grid itself.
2. **Identify Start and End Positions**: Locate the positions of 'S' (start) and 'E' (end) in the grid.
3. **Breadth-First Search (BFS)**: Use BFS to explore all possible paths from 'S' to 'E'. BFS is suitable here because it explores all nodes at the present depth level before moving on to nodes at the next depth level, ensuring the shortest path is found.
4. **Check Moves**: For each cell, check all four possible moves (up, down, left, right). If a move leads to 'E', return the number of steps taken. If a move leads to 'P', continue the BFS.

### Solution Code
```python
import sys
from collections import deque

def main():
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    grid = []
    start = None
    end = None
    for i in range(N):
        row = input[idx:idx+N]
        idx += N
        grid.append(row)
        for j in range(N):
            if row[j] == 'S':
                start = (i, j)
            elif row[j] == 'E':
                end = (i, j)
    
    if start == end:
        print(0)
        return
    
    visited = [[False for _ in range(N)] for _ in range(N)]
    q = deque()
    q.append((start[0], start[1], 0))
    visited[start[0]][start[1]] = True
    
    directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
    
    while q:
        x, y, steps = q.popleft()
        for dx, dy in directions:
            nx = x + dx
            ny = y + dy
            if 0 <= nx < N and 0 <= ny < N:
                if grid[nx][ny] == 'T':
                    continue
                if not visited[nx][ny]:
                    if (nx, ny) == end:
                        print(steps + 1)
                        return
                    visited[nx][ny] = True
                    q.append((nx, ny, steps + 1))
    
    print(-1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into a grid structure. The start ('S') and end ('E') positions are identified during this parsing.
2. **BFS Initialization**: The BFS queue is initialized with the start position and a step count of 0. A visited matrix is used to track which cells have been explored to avoid cycles.
3. **Exploring Neighbors**: For each cell dequeued, all four possible directions are checked. Valid moves (within bounds, not a tree, and not visited) are enqueued with an incremented step count.
4. **Termination**: If the end position 'E' is reached during BFS, the current step count plus one (for the move to 'E') is printed. If the queue is exhausted without finding 'E', the problem guarantees a path exists, so this scenario is not explicitly handled here but could be extended with error checking.

This approach efficiently finds the shortest path using BFS, ensuring optimal performance for the given grid size constraints.
