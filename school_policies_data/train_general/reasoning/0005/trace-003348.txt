To solve this problem, we need to determine the maximum number of students (K) that can be called by Utkarsh's mother such that she remains happy under two different distribution scenarios: one handled by Utkarsh and the other by Saharsh. 

### Approach

1. **Utkarsh's Distribution**:
   - Utkarsh distributes books randomly, so we need to ensure that even in the worst-case scenario, every pile has at least one student who received more than one book. The key insight here is that the maximum number of students (K) must be such that each pile has more books than the number of students. This ensures that it's impossible for all students to receive exactly one book from any pile. Therefore, the maximum K is determined by the smallest pile size minus one.

2. **Saharsh's Distribution**:
   - Saharsh distributes books optimally to maximize K while ensuring the mother's condition is met. The optimal way to achieve this is by distributing each pile such that each student gets at most one book from each pile except for one student who gets the remaining book. This results in the maximum K being the sum of each pile's size minus one.

### Solution Code

```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N = int(input[idx])
        idx += 1
        B = list(map(int, input[idx:idx + N]))
        idx += N
        utkarsh = min(B) - 1
        saharsh = sum(b - 1 for b in B)
        print(f"{utkarsh} {saharsh}")

main()
```

### Explanation

- **Reading Input**: The input is read in one go for efficiency, especially given the constraints. We parse the input values and process each test case individually.
- **Utkarsh's Maximum K**: For each test case, we compute the minimum value in the list of book piles and subtract one. This ensures that even the smallest pile has enough books to prevent all students from getting exactly one book.
- **Saharsh's Maximum K**: We calculate the sum of each pile's size minus one. This sum represents the optimal distribution where each pile's books are distributed such that each student gets at most one book from each pile except for one student per pile who gets the remaining book, thus satisfying the mother's condition.

This approach efficiently computes the required values using straightforward arithmetic operations and ensures the solution is optimal and correct within the problem constraints.
