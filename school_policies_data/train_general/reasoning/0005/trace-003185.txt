To solve this problem, we need to determine the minimum time Xenia needs to complete all her tasks while moving clockwise along a ringroad of houses. The key is to calculate the shortest path between consecutive tasks and sum these distances.

### Approach
1. **Initialization**: Start at house 1 and initialize the total time to 0.
2. **Iterate through each task**: For each task, compute the minimum time required to move from the current house to the task's house.
3. **Modulo Operation**: Use the modulo operation to handle the circular nature of the ringroad efficiently. This helps in calculating the shortest path when moving clockwise.
4. **Update Position**: After moving to the new house, update the current position and accumulate the time taken for the move.

### Solution Code
```python
def main():
    import sys
    n, m = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    current = 1
    total = 0
    for num in a:
        steps = (num - current) % n
        total += steps
        current = num
    print(total)

main()
```

### Explanation
1. **Reading Input**: The input consists of the number of houses `n`, the number of tasks `m`, and the list of houses where each task needs to be completed.
2. **Initial Position**: Xenia starts at house 1.
3. **Calculate Steps**: For each task, calculate the steps needed to move from the current house to the task's house using modulo arithmetic to handle the circular movement. The formula `(num - current) % n` ensures we get the correct number of steps clockwise.
4. **Update and Accumulate**: Update the current position to the task's house and add the steps taken to the total time.

This approach efficiently computes the minimum time with a linear pass through the task list, resulting in an O(m) time complexity, which is optimal for the given constraints.
