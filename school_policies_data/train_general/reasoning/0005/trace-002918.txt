def main():
    import sys
    line = sys.stdin.readline().strip()
    parts = line.split()
    if len(parts) != 3:
        print("Invalid Operator")
        return
    a_str, op, b_str = parts
    if op not in {'+', '-', '*', '/'}:
        print("Invalid Operator")
        return
    try:
        a = int(a_str)
        b = int(b_str)
    except ValueError:
        print("Invalid Operator")
        return
    if op == '+':
        print(a + b)
    elif op == '-':
        print(a - b)
    elif op == '*':
        print(a * b)
    elif op == '/':
        try:
            remainder = a % b
            if remainder == 0:
                print(a // b)
            else:
                print(a / b)
        except ZeroDivisionError:
            print("Invalid Operator")

if __name__ == "__main__":
    main()

3. **Conversion to Integers**: The operands are converted from strings to integers. Python's `int` type can handle very large integers, which is essential given the problem constraints.
4. **Arithmetic Operations**:
   - For addition, subtraction, and multiplication, the result is directly printed as an integer.
   - For division, the code checks if the division is exact using the modulus operator. If exact, it uses integer division to avoid floating-point representation issues.
