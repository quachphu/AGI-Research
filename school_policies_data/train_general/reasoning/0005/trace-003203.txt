Implementing a Fenwick Tree in Python:

The Fenwick Tree (BIT) supports two operations: update (add 1 to a position) and query (sum from 1 to k).

The code for Fenwick Tree:

class FenwickTree:
    def __init__(self, size):
        self.n = size
        self.tree = [0]*(self.n +1)
    
    def update(self, idx, delta=1):
        while idx <= self.n:
            self.tree[idx] += delta
            idx += idx & -idx
    
    def query(self, idx):
        res = 0
        while idx >0:
            res += self.tree[idx]
            idx -= idx & -idx
        return res

import bisect

class FenwickTree:
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (self.n + 1)
    
    def update(self, idx, delta=1):
        while idx <= self.n:
            self.tree[idx] += delta
            idx += idx & -idx
    
    def query(self, idx):
        res = 0
        while idx >0:
            res += self.tree[idx]
            idx -= idx & -idx
        return res

def main():
    import sys
    input = sys.stdin.read().split()
    ptr =0
    n = int(input[ptr])
    ptr +=1
    A = list(map(int, input[ptr:ptr+n]))
    ptr +=n
    B = list(map(int, input[ptr:ptr+n]))
    ptr +=n
    
    # Combine A and B for coordinate compression
    combined = A + B
    sorted_unique = sorted(set(combined))
    max_rank = len(sorted_unique)
    fenwick = FenwickTree(max_rank)
    
    T =0
    for j in range(n):
        # Process B[j]
        x = B[j]
        pos = bisect.bisect_right(sorted_unique, x)
        sum_le = fenwick.query(pos)
        current_count = j - sum_le  # j is the number of elements inserted so far (since for j=0, after processing, 1 element is added)
        T += current_count
        
        # Insert A[j] into Fenwick Tree
        a = A[j]
        a_pos = bisect.bisect_left(sorted_unique, a)
        a_rank = a_pos +1  # ranks are 1-based
        fenwick.update(a_rank)
    
    # Check if T is prime
    def is_prime(n):
        if n <=1:
            return False
        elif n <=3:
            return True
        elif n%2 ==0:
            return False

To solve this problem, we need to determine if the number of inversions between two arrays A and B is a prime number. An inversion is defined as a pair of indices (i, j) where i < j and A[i] > B[j].

### Approach
1. **Understanding Inversions**: For each element B[j] in array B, we need to count how many elements in A[0..j-1] are greater than B[j]. Summing these counts gives the total number of inversions, T.
2. **Efficient Counting with Fenwick Tree**: Using a Fenwick Tree (Binary Indexed Tree), we can efficiently maintain and query the count of elements in array A as we process each element in B. This allows us to count the required inversions in O(N log N) time complexity.
3. **Coordinate Compression**: Since the elements in arrays A and B can be very large, we compress these values into a smaller range to efficiently use the Fenwick Tree.
4. **Prime Check**: After computing T, we check if it is a prime number using the Miller-Rabin primality test, which is efficient for large numbers.
