To solve this problem, we need to determine the number of three-sided closed figures (triangles) formed on the nth day based on a specific pattern. The solution involves deriving a formula that captures the growth of triangles as each day progresses.

### Approach
The problem can be approached by identifying the pattern in which triangles are added each day. Through analysis, we observe that the number of triangles formed on each subsequent day follows a quadratic growth pattern. Specifically, the number of triangles on the nth day can be calculated using the formula \(2n^2 - 2n + 1\). This formula is derived from observing the incremental addition of triangles in a structured manner, where each day adds a new layer of triangles around the previous structure.

### Solution Code
```python
def main():
    n = int(input())
    print(2 * n * n - 2 * n + 1)

main()
```

### Explanation
The function `main` reads an integer `n` from the standard input, which represents the nth day. Using the derived formula \(2n^2 - 2n + 1\), the function computes the number of triangles formed by that day and prints the result. This formula efficiently captures the cumulative growth of triangles, ensuring that the solution is computed in constant time \(O(1)\), making it highly efficient even for large values of `n`.
