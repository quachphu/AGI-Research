To solve this problem, we need to find the shortest path cost and the number of shortest paths in a grid with special movement options. The grid allows movement to adjacent cells as well as specific "warp" moves to the edges of the grid. The solution involves using Breadth-First Search (BFS) to efficiently explore all possible paths while keeping track of the shortest path count.

### Approach
1. **BFS for Shortest Path**: BFS is suitable here because all moves have the same cost (unweighted edges). This allows us to explore the grid level by level, ensuring the shortest path is found.
2. **Track Moves**: From each cell, generate all possible moves including directional moves (up, down, left, right) and warp moves (to the edges of the grid). Each move is checked for validity.
3. **Count Paths**: For each cell, track the number of shortest paths leading to it. When multiple moves from a cell lead to the same destination, sum the paths contributed by each valid move.

### Solution Code
```python
import sys
from collections import deque

MOD = 10**9 + 7

def main():
    R, C, a_i, a_j, b_i, b_j = map(int, sys.stdin.readline().split())
    distance = [[-1 for _ in range(C)] for _ in range(R)]
    count = [[0 for _ in range(C)] for _ in range(R)]
    queue = deque()
    distance[a_i][a_j] = 0
    count[a_i][a_j] = 1
    queue.append((a_i, a_j))
    found = False
    while queue:
        e, f = queue.popleft()
        if e == b_i and f == b_j:
            found = True
            break
        moves = []
        # Generate directional moves
        if e > 0:
            moves.append((e-1, f))
        if e < R - 1:
            moves.append((e+1, f))
        if f > 0:
            moves.append((e, f-1))
        if f < C - 1:
            moves.append((e, f+1))
        # Generate warp moves
        moves.append((e, 0))
        moves.append((e, C-1))
        moves.append((0, f))
        moves.append((R-1, f))
        # Group moves by destination
        groups = {}
        for x, y in moves:
            key = (x, y)
            groups[key] = groups.get(key, 0) + 1
        # Process each group
        for (x, y), cnt in groups.items():
            if distance[x][y] == -1:
                distance[x][y] = distance[e][f] + 1
                count[x][y] = (count[e][f] * cnt) % MOD
                queue.append((x, y))
            elif distance[x][y] == distance[e][f] + 1:
                count[x][y] = (count[x][y] + count[e][f] * cnt) % MOD
    print(distance[b_i][b_j], count[b_i][b_j] % MOD)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Initialization**: The grid is initialized with distance `-1` (unvisited) and count `0` for all cells except the start cell, which has distance `0` and count `1`.
2. **BFS Queue**: The BFS queue starts with the initial cell. Each cell processed dequeues and checks all possible moves.
3. **Move Generation**: For each cell, generate valid directional moves and all warp moves. Group these moves by their destination to count how many ways each destination can be reached.
4. **Update Distance and Count**: For each destination cell, update its distance if unvisited or if found at the same level (distance + 1). Accumulate the path count using modular arithmetic to handle large numbers.

This approach ensures that we efficiently find the shortest path and count all possible shortest paths using BFS, leveraging the properties of unweighted graphs and modular arithmetic for large numbers.
