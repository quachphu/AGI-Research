To solve this problem, we need to determine if we can select k elements from a sorted array A and m elements from a sorted array B such that every selected element in A is strictly less than every selected element in B. 

### Approach
1. **Understanding the Problem**: The key insight here is that the largest element in the selected k elements from A must be strictly less than the smallest element in the selected m elements from B. Given that both arrays are sorted in non-decreasing order, we can leverage this property to efficiently determine the solution.
2. **Key Observations**:
   - The largest element in the first k elements of array A (since it's sorted) is the k-th element (0-indexed at position k-1).
   - The smallest element in the last m elements of array B (since it's sorted) is the m-th element from the end (0-indexed at position len(B) - m).
3. **Comparison**: By comparing the k-th element from array A and the m-th element from the end of array B, we can determine if all selected elements from A are less than all selected elements from B.

### Solution Code
```python
import sys

def main():
    # Read the sizes of the arrays
    nA, nB = map(int, sys.stdin.readline().split())
    
    # Read the values of k and m
    k, m = map(int, sys.stdin.readline().split())
    
    # Read the elements of array A
    A = list(map(int, sys.stdin.readline().split()))
    
    # Read the elements of array B
    B = list(map(int, sys.stdin.readline().split()))
    
    # Get the k-th smallest element in A (0-based index)
    a_val = A[k-1]
    # Get the m-th largest element in B (0-based index from the end)
    b_val = B[-m]
    
    # Check the condition
    if a_val < b_val:
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read from standard input (stdin) using `sys.stdin.readline()` for efficiency, especially given the constraints.
- **Selecting Elements**: The k-th smallest element from array A is accessed using `A[k-1]` (since arrays are 0-indexed). The m-th largest element from array B is accessed using `B[-m]`, which is equivalent to `B[len(B)-m]`.
- **Comparison**: By comparing these two elements, we determine if all selected elements from A are strictly less than all selected elements from B. If the condition holds, we print "YES"; otherwise, we print "NO".

This approach efficiently leverages the sorted nature of the arrays and ensures we only perform a constant number of operations after reading the input, making the solution both optimal and easy to understand.
