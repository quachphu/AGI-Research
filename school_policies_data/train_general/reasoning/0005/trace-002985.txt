To solve this problem, we need to determine the minimum cost to transport schoolchildren through multiple regions, considering both the bus costs and potential compensation due to high temperatures inside the buses. The key is to optimize the number of buses used in each region to minimize the total cost.

### Approach
1. **Problem Analysis**:
   - Each region has specific parameters: temperature threshold, compensation cost per child, and bus cost.
   - The goal is to minimize the total cost, which includes both the bus costs and compensation costs for regions where the temperature exceeds the threshold.

2. **Key Insights**:
   - **Temperature Check**: If the temperature in a region is inherently too high (even with one child), all buses will incur compensation costs.
   - **Optimal Bus Allocation**: If the temperature can be managed by splitting children into buses such that each bus's temperature remains below the threshold, calculate the minimum number of buses needed.
   - **Cost Comparison**: For regions where splitting children into buses to avoid compensation is possible, compare the cost of using the optimal number of buses versus using fewer buses (which might be cheaper despite compensation costs).

3. **Algorithm**:
   - For each region, determine if the temperature threshold can be respected by splitting children into buses.
   - Calculate the cost for both scenarios (using the optimal number of buses to avoid compensation and using fewer buses with compensation) and choose the minimum.

### Solution Code
```python
n, m = map(int, input().split())
total = 0
for _ in range(n):
    ti, Ti, xi, costi = map(int, input().split())
    if ti + 1 > Ti:
        # All buses in this region will have compensation
        total += costi + m * xi
    else:
        s_max = Ti - ti
        if s_max >= m:
            # One bus suffices without compensation
            total += costi
        else:
            k_min = (m + s_max - 1) // s_max
            cost_a = k_min * costi
            if costi < s_max * xi:
                # Calculate cost_b for k_less = k_min - 1
                # Since s_max < m, k_min is at least 2
                remaining = m - (k_min - 2) * s_max
                cost_b = (k_min - 1) * costi + remaining * xi
            else:
                cost_b = costi + m * xi
            total += min(cost_a, cost_b)
print(total)
```

### Explanation
1. **Temperature Check**: If the temperature in a region (plus one child) exceeds the threshold, all buses will incur compensation. The cost here is straightforward: one bus plus compensation for all children.
2. **Optimal Bus Allocation**: If the temperature can be managed by splitting children into buses:
   - Calculate the minimum number of buses needed to keep the temperature below the threshold.
   - Compare the cost of using this optimal number of buses versus using fewer buses (which might be cheaper even with compensation).
3. **Cost Calculation**: For each region, the solution dynamically calculates the minimum cost by considering both the bus costs and potential compensation, ensuring the optimal balance between these factors.

This approach ensures that we efficiently compute the minimal cost for each region and sum them up to get the total minimum cost for the entire trip.
