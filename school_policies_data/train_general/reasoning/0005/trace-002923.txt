To solve this problem, we need to determine if there exists any diverse substring in a given string. A substring is considered diverse if no character appears more than half the length of the substring. If no such substring exists, we should return "NO".

### Approach
The key insight to solve this problem efficiently is to recognize that if a string is not composed entirely of the same character, there must be at least one pair of consecutive different characters. This pair forms a valid diverse substring of length 2. Therefore, the solution can be broken down into two main steps:
1. Check if all characters in the string are the same. If they are, output "NO".
2. If not, find the first pair of consecutive different characters and output this pair as the valid diverse substring.

### Solution Code
```python
n = int(input())
s = input().strip()

if len(set(s)) == 1:
    print("NO")
else:
    for i in range(n - 1):
        if s[i] != s[i + 1]:
            print("YES")
            print(s[i] + s[i + 1])
            exit()
```

### Explanation
1. **Check Uniformity**: The first step is to check if all characters in the string are the same. This is done by converting the string into a set and checking if the size of the set is 1. If it is, all characters are the same, and we immediately print "NO".
2. **Find Consecutive Pair**: If the string is not uniform, we iterate through the string to find the first occurrence of two consecutive characters that are different. This pair forms a valid diverse substring of length 2, which we then print.

This approach ensures that we efficiently determine the presence of a diverse substring with minimal computational overhead, making it optimal for the given problem constraints.
