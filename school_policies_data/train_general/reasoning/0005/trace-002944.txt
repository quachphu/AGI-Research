To solve this problem, we need to determine the minimal path length for a quadcopter to start at a given point, fly around a flag, and return to the starting point such that the flag is strictly inside the path. The quadcopter moves in a grid-like manner, changing one coordinate by 1 unit per move.

### Approach
1. **Problem Analysis**: The quadcopter's path must form a closed loop around the flag. The loop must be a rectangle where the flag is strictly inside, and the starting point is on the perimeter of this rectangle.
2. **Key Insight**: The minimal path is determined by the smallest rectangle that can enclose the flag inside and have the starting point on its perimeter. The width and height of this rectangle are derived from the distances between the starting point and the flag.
3. **Formulation**:
   - **Width Calculation**: If the x-coordinates of the start and flag are different, the width is the absolute difference plus 1. If they are the same, the width is 2 (to ensure the flag is inside).
   - **Height Calculation**: Similarly, if the y-coordinates of the start and flag are different, the height is the absolute difference plus 1. If they are the same, the height is 2.
4. **Perimeter Calculation**: The perimeter of the rectangle is twice the sum of its width and height.

### Solution Code
```python
x1, y1 = map(int, input().split())
x2, y2 = map(int, input().split())

dx = abs(x1 - x2)
dy = abs(y1 - y2)

width = dx + 1 if dx != 0 else 2
height = dy + 1 if dy != 0 else 2

print(2 * (width + height))
```

### Explanation
1. **Input Handling**: The code reads the coordinates of the starting point and the flag.
2. **Distance Calculation**: `dx` and `dy` are the absolute differences between the respective coordinates of the start and flag.
3. **Width and Height Determination**:
   - If the x-coordinates differ, the width is `dx + 1` to ensure the flag is inside. If they are the same, the width is 2.
   - Similarly, if the y-coordinates differ, the height is `dy + 1`. If they are the same, the height is 2.
4. **Perimeter Calculation**: The perimeter is calculated as `2 * (width + height)`, which is printed as the result.

This approach ensures that the quadcopter's path forms the smallest possible rectangle enclosing the flag, with the starting point on the perimeter, thus minimizing the path length.
