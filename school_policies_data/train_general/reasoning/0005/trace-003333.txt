To solve this problem, we need to determine if we can split a given public key (a very long integer represented as a string) into two non-empty parts such that the left part is divisible by a given integer `a` and the right part is divisible by another given integer `b`. Both parts must not have leading zeros and must be positive integers.

### Approach
1. **Precompute Remainders**:
   - **Left Remainders**: Compute the remainder of the left part modulo `a` for each possible split point starting from the left end of the string.
   - **Right Remainders**: Compute the remainder of the right part modulo `b` for each possible split point starting from the right end of the string.

2. **Check Split Points**:
   - Iterate through each possible split point and check if the left part's remainder modulo `a` is 0 and the right part's remainder modulo `b` is 0.
   - Ensure the right part does not have leading zeros unless it is a single zero, which is not allowed as it is not a positive integer.

### Solution Code
```python
import sys

def main():
    s = sys.stdin.readline().strip()
    a, b = map(int, sys.stdin.readline().split())
    n = len(s)
    
    if n < 2:
        print("NO")
        return
    
    # Compute left_remainders for a
    left_remainders = []
    current = 0
    for i in range(n-1):
        current = (current * 10 + int(s[i])) % a
        left_remainders.append(current)
    
    # Compute right_remainders for b
    current_remainder = 0
    power = 1
    right_remainders = [0] * (n + 1)  # Extra space to avoid index issues
    for i in range(n-1, -1, -1):
        current_remainder = (int(s[i]) * power + current_remainder) % b
        right_remainders[i] = current_remainder
        power = (power * 10) % b
    
    # Check each possible split point
    for j in range(1, n):
        if left_remainders[j-1] == 0 and right_remainders[j] == 0:
            right_part = s[j:]
            # Check for invalid right parts
            if right_part == '0':
                continue
            if len(right_part) > 1 and right_part[0] == '0':
                continue
            # Check left part for leading zeros (impossible except when j=1 and s[0] is '0', which is invalid)
            # Since s has no leading zeros, left part is valid
            print("YES")
            print(s[:j])
            print(right_part)
            return
    
    print("NO")

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The public key is read as a string, and the integers `a` and `b` are read from the input.
2. **Edge Case Handling**: If the length of the public key is less than 2, it is impossible to split, so we immediately print "NO".
3. **Left Remainders Calculation**: We compute the remainder of the left part modulo `a` for each possible split point starting from the left end. This helps in quickly checking divisibility by `a` for any left part.
4. **Right Remainders Calculation**: We compute the remainder of the right part modulo `b` for each possible split point starting from the right end. This helps in quickly checking divisibility by `b` for any right part.
5. **Checking Split Points**: For each possible split point, we check if both parts meet the divisibility criteria and ensure the right part does not have leading zeros unless it is a single digit (which must not be zero).

This approach efficiently precomputes necessary values and checks each possible split in linear time, making it suitable even for very large input sizes.
