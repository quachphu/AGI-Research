To solve this problem, we need to format a given text into a centered alignment within a frame made of asterisks. The solution involves determining the maximum line length, creating a frame of appropriate width, and centering each line within this frame. If centering is not possible due to an odd number of padding spaces, we alternate between left and right alignment starting with the left.

### Approach
1. **Read Input Lines**: Read all lines from the input, ensuring to strip any trailing newline characters.
2. **Determine Maximum Line Length**: Find the longest line length to determine the frame width, which is the maximum line length plus 2 (for the asterisks on both sides).
3. **Create Frame Borders**: The top and bottom borders of the frame are asterisks repeated for the frame width.
4. **Center Each Line**: For each line, calculate the necessary padding to center it within the frame. If the padding is even, split it equally. If odd, alternate between left and right alignment starting with the left.

### Solution Code
```python
import sys

def main():
    lines = [line.rstrip('\n') for line in sys.stdin]
    if not lines:
        return
    max_len = max(len(line) for line in lines)
    frame_width = max_len + 2
    print('*' * frame_width)
    count_uneven = 0
    for line in lines:
        current_len = len(line)
        total_padding = max_len - current_len
        if total_padding % 2 == 1:
            if count_uneven % 2 == 0:
                left = total_padding // 2
            else:
                left = (total_padding + 1) // 2
            right = total_padding - left
            count_uneven += 1
        else:
            left = right = total_padding // 2
        centered = ' ' * left + line + ' ' * right
        print(f'*{centered}*')
    print('*' * frame_width)

if __name__ == "__main__":
    main()
```

1. **Reading Input Lines**: The input lines are read and stored in a list, with any trailing newline characters removed.
2. **Maximum Line Length**: The maximum length of the lines is determined to set the frame width.
3. **Frame Borders**: The top and bottom borders are printed as asterisks of the frame width.
4. **Centering Lines**: Each line is processed to calculate the padding. If the padding is even, it is split equally. If odd, the padding alternates between left and right starting with the left. This alternation is tracked using a counter for lines requiring uneven padding.

This approach ensures that lines are centered within the frame, with proper handling of both even and odd padding scenarios, adhering to the problem constraints and requirements.
