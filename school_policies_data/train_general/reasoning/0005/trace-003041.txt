To solve this problem, we need to determine if we can split six students into two teams of three such that the sum of their scores is equal. 

### Approach
1. **Sum Check**: First, check if the total sum of all six scores is even. If it's odd, it's impossible to split them into two equal sums, so the answer is immediately "NO".
2. **Target Calculation**: If the total sum is even, calculate the target sum for each team as half of the total sum.
3. **Combination Check**: Generate all possible combinations of three students from the six. For each combination, check if the sum of their scores equals the target sum. If any combination meets this criteria, print "YES". If none do, print "NO".

### Solution Code
```python
import sys
from itertools import combinations

def main():
    a = list(map(int, sys.stdin.readline().split()))
    total = sum(a)
    if total % 2 != 0:
        print("NO")
        return
    target = total // 2
    for combo in combinations(a, 3):
        if sum(combo) == target:
            print("YES")
            return
    print("NO")

main()
```

### Explanation
1. **Reading Input**: The input is read as a list of six integers.
2. **Sum Check**: The total sum of the list is calculated. If it's odd, the answer is "NO" because an odd total cannot be split into two equal integer sums.
3. **Target Calculation**: If the total sum is even, the target sum for each team is half of the total sum.
4. **Combination Check**: Using itertools.combinations, we generate all possible groups of three students. For each group, we check if their sum matches the target. If any group does, we print "YES" and exit. If none do, we print "NO".

This approach efficiently checks all possible ways to form the teams, ensuring correctness while maintaining computational feasibility.
