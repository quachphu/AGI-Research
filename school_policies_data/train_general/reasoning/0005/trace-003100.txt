To solve this problem, we need to compute the sum of the number of trailing zeros in the factorial of numbers within a given range [a, b] for multiple test cases efficiently. The trailing zeros in a factorial are determined by the number of times 5 is a factor in the numbers from 1 to n. 

### Approach
1. **Understanding Trailing Zeros**: The number of trailing zeros in n! (factorial of n) is given by the sum of the integer divisions of n by 5, 25, 125, etc., until the divisor exceeds n. This is because trailing zeros are formed by factors of 10, which are the product of 2 and 5, and there are always more factors of 2 than 5 in a factorial.

2. **Precomputation**: To efficiently handle multiple queries, we precompute the number of trailing zeros for each number up to the maximum constraint (1,000,000) using a delta method. This method leverages the fact that the number of trailing zeros only increases when a number is a multiple of 5, and the increase is determined by the number of times 5 is a factor in that number.

3. **Prefix Sum Array**: Using the precomputed values, we build a prefix sum array to quickly compute the sum of trailing zeros for any range [a, b] in constant time.

### Solution Code
```python
import sys

def main():
    max_n = 10**6
    z = [0] * (max_n + 1)
    
    for i in range(1, max_n + 1):
        if i % 5 != 0:
            z[i] = z[i-1]
        else:
            count = 0
            x = i
            while x % 5 == 0:
                count += 1
                x = x // 5
            z[i] = z[i-1] + count
    
    # Compute prefix sums
    prefix = [0] * (max_n + 1)
    for i in range(1, max_n + 1):
        prefix[i] = prefix[i-1] + z[i]
    
    # Read all input
    input_data = sys.stdin.read().split()
    T = int(input_data[0])
    idx = 1
    results = []
    for _ in range(T):
        a = int(input_data[idx])
        b = int(input_data[idx + 1])
        idx += 2
        results.append(prefix[b] - prefix[a-1])
    
    print('\n'.join(map(str, results)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precomputation of Trailing Zeros**: The array `z` is computed such that `z[i]` holds the number of trailing zeros in i!. For numbers not divisible by 5, `z[i]` is the same as `z[i-1]`. For numbers divisible by 5, we count how many times 5 is a factor in the number and add this count to `z[i-1]`.

2. **Prefix Sum Array**: The array `prefix` is built where `prefix[i]` is the cumulative sum of trailing zeros from 1 to i. This allows us to compute the sum of trailing zeros in any range [a, b] by subtracting `prefix[a-1]` from `prefix[b]`.

3. **Efficient Query Handling**: By reading all input at once and using the precomputed prefix sums, each query is answered in constant time, making the solution efficient even for the upper constraint limits.

This approach ensures that we handle up to 100,000 queries efficiently after an initial preprocessing step, making the solution both time and space efficient.
