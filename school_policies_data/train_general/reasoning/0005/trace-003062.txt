To solve this problem, we need to determine the shortest paths from a given source vertex in a directed graph that may contain negative edge weights. Additionally, we must detect if there exists a negative cycle that is reachable from the source vertex. If such a cycle exists, we should output "NEGATIVE CYCLE"; otherwise, we should output the shortest path costs from the source to each vertex, or "INF" if a vertex is unreachable.

### Approach
1. **Bellman-Ford Algorithm**: This algorithm is suitable for finding shortest paths in graphs with negative edge weights. It can also detect negative cycles by performing an additional relaxation pass after the standard |V| - 1 iterations.
2. **Relaxation Process**: For each vertex, we relax all edges |V| - 1 times. If we can still relax an edge in the |V|th iteration, it indicates the presence of a negative cycle.
3. **Reachability Check**: Only consider cycles that are reachable from the source vertex. If a vertex's distance remains INF (infinity), it means it is unreachable from the source, and thus any cycle involving that vertex is irrelevant.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    V = int(input[ptr]); ptr += 1
    E = int(input[ptr]); ptr += 1
    r = int(input[ptr]); ptr += 1

    edges = []
    for _ in range(E):
        s = int(input[ptr]); ptr += 1
        t = int(input[ptr]); ptr += 1
        d = int(input[ptr]); ptr += 1
        edges.append((s, t, d))

    INF = float('inf')
    dist = [INF] * V
    dist[r] = 0

    # Relax edges up to V-1 times
    for i in range(V - 1):
        updated = False
        for (u, v, w) in edges:
            if dist[u] != INF and dist[v] > dist[u] + w:
                dist[v] = dist[u] + w
                updated = True
        if not updated:
            break  # Early exit if no more updates

    # Check for negative cycles
    has_negative_cycle = False
    prev_dist = dist.copy()
    for (u, v, w) in edges:
        if prev_dist[u] != INF and prev_dist[u] + w < prev_dist[v]:
            has_negative_cycle = True
            break

    if has_negative_cycle:
        print("NEGATIVE CYCLE")
    else:
        for d in dist:
            print(d if d != INF else "INF")

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read and parsed into vertices, edges, and the source vertex. Each edge is stored as a tuple (source, target, weight).
2. **Initialization**: The distance array is initialized with infinity (INF) except for the source vertex, which is set to 0.
3. **Relaxation Process**: The algorithm relaxes each edge up to |V| - 1 times. If no updates occur in an iteration, we exit early to optimize performance.
4. **Negative Cycle Detection**: After |V| - 1 iterations, we check if any edge can still be relaxed. If so, it indicates a negative cycle reachable from the source.
5. **Output**: If a negative cycle is detected, "NEGATIVE CYCLE" is printed. Otherwise, the shortest path distances are printed, with "INF" for unreachable vertices.

This approach efficiently handles the problem constraints and ensures correctness by leveraging the properties of the Bellman-Ford algorithm to detect negative cycles and compute shortest paths.
