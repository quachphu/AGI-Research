To solve this problem, we need to efficiently answer multiple queries about the number of consecutive equal characters in specific substrings of a given string. The solution involves pre-processing the string to allow each query to be answered in constant time.

### Approach
1. **Pre-processing with Matches Array**: Create an array where each element indicates whether consecutive characters in the string are equal. This array, `matches`, has a length of \( n-1 \) for a string of length \( n \), where each element is 1 if the corresponding consecutive characters are equal, and 0 otherwise.
2. **Prefix Sum Array**: Construct a prefix sum array `pre` from the `matches` array. This array allows us to quickly compute the sum of any subarray of `matches`, which corresponds to the number of consecutive equal characters in any substring of the original string.
3. **Efficient Query Handling**: For each query, use the prefix sum array to compute the result in constant time by subtracting the prefix sum values at the boundaries of the query range.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    s = input[ptr]
    ptr += 1
    n = len(s)
    
    # Precompute matches array
    matches = []
    for i in range(n - 1):
        if s[i] == s[i + 1]:
            matches.append(1)
        else:
            matches.append(0)
    
    # Compute prefix sums
    pre = [0] * (n)
    for i in range(1, n):
        pre[i] = pre[i - 1] + matches[i - 1]
    
    m = int(input[ptr])
    ptr += 1
    results = []
    for _ in range(m):
        l = int(input[ptr])
        r = int(input[ptr + 1])
        ptr += 2
        res = pre[r - 1] - pre[l - 1]
        results.append(str(res))
    
    print('\n'.join(results))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Matches Array**: The `matches` array is constructed by iterating through the string and checking if each pair of consecutive characters are equal. This takes \( O(n) \) time.
2. **Prefix Sum Array**: The `pre` array is built such that `pre[i]` contains the sum of the first `i-1` elements of the `matches` array. This allows us to compute the sum of any subarray in constant time.
3. **Query Handling**: Each query is processed by computing the difference between two values in the prefix sum array. This allows each query to be answered in \( O(1) \) time, leading to an overall time complexity of \( O(n + m) \), where \( n \) is the length of the string and \( m \) is the number of queries.

This approach efficiently handles the problem constraints, ensuring that even for large input sizes, the solution remains performant.
