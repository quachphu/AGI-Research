To solve this problem, we need to determine the minimum cost for Polycarp to buy exactly `n` liters of water using 1-liter and 2-liter bottles, given their respective costs. The goal is to minimize the total cost for each query.

### Approach
1. **Understand the Cost Efficiency**: For each 2 liters of water, we need to decide whether using a single 2-liter bottle or two 1-liter bottles is cheaper. This is determined by comparing `2 * a` (cost of two 1-liter bottles) with `b` (cost of one 2-liter bottle).
2. **Handle Even and Odd Liters**: 
   - If `n` is even, the total cost is calculated by using the cheaper option for every 2 liters.
   - If `n` is odd, we handle the first `n-1` liters (which is even) using the cheaper 2-liter option and then add the cost of one 1-liter bottle for the remaining liter.

### Solution Code
```python
import sys

def main():
    q = int(sys.stdin.readline())
    for _ in range(q):
        n, a, b = map(int, sys.stdin.readline().split())
        two_liters = n // 2
        remainder = n % 2
        cost = two_liters * min(2 * a, b) + remainder * a
        print(cost)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of multiple queries. We first read the number of queries `q`.
2. **Processing Each Query**: For each query, we read the values `n`, `a`, and `b`.
3. **Calculate Cost for 2-liter Bottles**: We determine the number of 2-liter segments (`n // 2`) and compute the cost using the cheaper option between `2 * a` and `b`.
4. **Adjust for Odd Liters**: If `n` is odd, we add the cost of one additional 1-liter bottle.
5. **Output the Result**: The computed cost for each query is printed.

This approach ensures that we efficiently compute the minimum cost for each query in constant time, making the solution both optimal and scalable even for large values of `n`.
