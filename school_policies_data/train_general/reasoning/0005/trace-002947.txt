To solve this problem, we need to identify a common M×M section between two given maps. The first map is an N×M grid, and the second map is an M×N grid. The goal is to find the position of an M×M section in the first map that matches an M×M section in the second map, which is derived from consecutive columns of the second map.

### Approach
1. **Input Reading**: Read the dimensions N and M, followed by the two maps.
2. **Preprocessing the Second Map**: For each possible starting column in the second map, generate all possible M×M sections by taking consecutive columns and store these sections in a dictionary with their starting column as the value.
3. **Check for Common Section**: For each possible starting row in the first map, generate the M×M section starting at that row and check if it exists in the preprocessed dictionary from the second map. If a match is found, output the positions (converted to 1-based indexing).

### Solution Code
```python
n, m = map(int, input().split())

# Read the first map (N rows of M characters each)
first_map = [input().strip() for _ in range(n)]

# Read the second map (M rows of N characters each)
second_map = [input().strip() for _ in range(m)]

# Preprocess all possible MxM blocks from the second map and store them in a dictionary
second_blocks = {}
n_columns = len(second_map[0])  # This should be equal to N

for j in range(n_columns - m + 1):
    # Extract the MxM block starting at column j in the second map
    block = [row[j:j+m] for row in second_map]
    key = tuple(block)
    if key not in second_blocks:
        second_blocks[key] = j + 1  # Store 1-based index

# Check each possible MxM block in the first map against the dictionary
for i in range(n - m + 1):
    current_block = first_map[i:i+m]
    key = tuple(current_block)
    if key in second_blocks:
        print(i + 1, second_blocks[key])
        exit()
```

### Explanation
1. **Reading Input**: The input is read as two integers N and M, followed by the two grids.
2. **Preprocessing the Second Map**: For each possible starting column in the second map, we generate an M×M block by taking M consecutive columns from each row. These blocks are stored in a dictionary with their starting column (1-based) as the value.
3. **Checking for Matches**: For each possible starting row in the first map, we generate the M×M block and check if it exists in the preprocessed dictionary. If a match is found, the corresponding positions (1-based) are printed and the program exits.

This approach efficiently narrows down the search space by using a dictionary to store preprocessed blocks from the second map, allowing for quick lookups when checking blocks from the first map. This ensures the solution is both optimal and efficient given the problem constraints.
