To solve this problem, we need to determine the maximum number of candy boxes that can be paired into gifts such that each pair's sum is divisible by a given integer \( k \). Each box can only be used once in a gift.

### Approach
1. **Calculate Remainders**: For each candy box, compute the remainder when the number of candies is divided by \( k \). This helps in determining which pairs of boxes can form valid gifts.
2. **Count Frequencies**: Maintain a frequency array to count how many boxes have each possible remainder when divided by \( k \).
3. **Form Valid Pairs**: For each remainder \( r \) from 1 to \( (k-1)//2 \), pair boxes with remainder \( r \) with boxes having remainder \( k-r \). The number of valid pairs is the minimum of the counts of these two remainders.
4. **Handle Special Cases**: 
   - If \( k \) is even, boxes with remainder \( k/2 \) can form pairs among themselves.
   - Boxes with remainder 0 can only pair with other boxes having remainder 0.

### Solution Code
```python
n, k = map(int, input().split())
d = list(map(int, input().split()))

remainder_counts = [0] * k
for num in d:
    remainder_counts[num % k] += 1

total_pairs = 0

# Process pairs (r, k - r) for r from 1 to (k-1)//2
for r in range(1, (k - 1) // 2 + 1):
    complement = k - r
    total_pairs += min(remainder_counts[r], remainder_counts[complement])

# Handle the case where k is even and there's a middle remainder
if k % 2 == 0:
    mid = k // 2
    total_pairs += remainder_counts[mid] // 2

# Handle pairs with remainder 0
total_pairs += remainder_counts[0] // 2

print(total_pairs * 2)
```

### Explanation
1. **Remainder Calculation**: For each candy box, compute the remainder when divided by \( k \). This helps in identifying potential pairs whose sums are divisible by \( k \).
2. **Frequency Count**: Using an array, count how many boxes fall into each remainder category from 0 to \( k-1 \).
3. **Pair Formation**: For each remainder \( r \) from 1 to \( (k-1)//2 \), determine the number of valid pairs by considering the minimum of the counts of \( r \) and \( k-r \). This ensures that each valid pair is counted once.
4. **Special Cases Handling**: 
   - When \( k \) is even, the middle remainder \( k/2 \) can form pairs among themselves.
   - Boxes with remainder 0 can only pair with other boxes of remainder 0, so their count is halved to form pairs.
   
By following these steps, we efficiently determine the maximum number of boxes that can be paired into valid gifts, ensuring optimal performance even for large input sizes.
