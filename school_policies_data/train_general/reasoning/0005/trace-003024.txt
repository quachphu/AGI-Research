To solve this problem, we need to count the number of ways to remove exactly one substring from a given string such that all remaining characters are the same. The solution involves analyzing the prefixes and suffixes of the string to determine valid removals efficiently.

### Approach
1. **Identify Prefix and Suffix Lengths**: Calculate the length of the longest prefix consisting of the first character and the length of the longest suffix consisting of the last character.
2. **Check Character Equality**: Determine if the first and last characters of the string are the same.
3. **Calculate Valid Removals**:
   - If the first and last characters are the same, the number of valid ways is the product of the possible prefix and suffix lengths plus one (for removing the entire string).
   - If the first and last characters are different, the valid ways are the sum of the lengths of the longest prefix and suffix plus one (for removing the entire string).

### Solution Code
```python
n = int(input())
s = input().strip()

if n == 0:
    print(0)
else:
    first_char = s[0]
    L = 0
    for c in s:
        if c == first_char:
            L += 1
        else:
            break
    
    last_char = s[-1]
    R = 0
    for c in reversed(s):
        if c == last_char:
            R += 1
        else:
            break
    
    if first_char == last_char:
        ans = (L + 1) * (R + 1)
    else:
        ans = L + R + 1
    
    print(ans % 998244353)
```

### Explanation
1. **Prefix and Suffix Calculation**: We determine the longest prefix (`L`) where all characters are the same as the first character and the longest suffix (`R`) where all characters are the same as the last character.
2. **Character Comparison**: By comparing the first and last characters of the string, we decide the method to compute the valid removals.
3. **Valid Removals Calculation**:
   - When the first and last characters are the same, the valid removals are calculated by considering all possible combinations of the prefix and suffix lengths, including removing the entire string.
   - When the first and last characters differ, valid removals are the sum of the lengths of the longest prefix and suffix plus one for removing the entire string.

This approach efficiently computes the result in linear time, making it suitable for large input sizes up to 200,000 characters.
