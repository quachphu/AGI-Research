To solve this problem, we need to calculate the area of a trapezoid given the lengths of its upper base, lower base, and height. The formula for the area of a trapezoid is well-known and straightforward, which allows us to directly compute the result using the given inputs.

### Approach
1. **Understanding the Formula**: The area of a trapezoid is given by the formula \((\text{upper base} + \text{lower base}) \times \text{height} / 2\). This formula works by averaging the lengths of the two bases and then multiplying by the height.
2. **Input Handling**: We read three integers from the standard input, which represent the upper base (a), lower base (b), and height (h) respectively.
3. **Computation**: Using the formula, we compute the area. Since the height (h) is guaranteed to be even, the product of (a + b) and h will always be even, ensuring that dividing by 2 results in an integer.

### Solution Code
```python
def main():
    a = int(input())
    b = int(input())
    h = int(input())
    area = (a + b) * h // 2
    print(area)

main()
```

### Explanation
1. **Reading Inputs**: The function reads three integers from standard input. These values are read sequentially and converted to integers.
2. **Calculating the Area**: The formula \((a + b) \times h // 2\) is applied. Here, integer division (//) is used to ensure the result is an integer, which is guaranteed by the problem constraints.
3. **Output the Result**: The computed area is printed as the final result.

This approach efficiently computes the area using direct arithmetic operations, ensuring correctness and adherence to the problem constraints. The solution is optimal with a time complexity of O(1) due to the constant-time operations involved.
