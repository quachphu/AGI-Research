To solve this problem, we need to determine if Abed can travel from his initial timeline to the target timeline within a budget of 1000 coins, considering the grid's wrap-around feature. The solution involves calculating the minimal moves required in both row and column directions independently and then computing the total cost.

### Approach
1. **Input Reading**: Read the number of test cases and for each test case, read the grid dimensions, initial and target coordinates, and the cost per move.
2. **Calculate Row Moves**: Determine the minimal moves required to reach the target row considering both direct and wrap-around paths.
3. **Calculate Column Moves**: Similarly, determine the minimal moves required for the column direction.
4. **Total Cost Calculation**: Sum the minimal row and column moves and multiply by the cost per move.
5. **Result Determination**: Check if the total cost is within the budget and print the appropriate result.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        M = int(input[ptr + 1])
        ptr += 2
        x1 = int(input[ptr])
        y1 = int(input[ptr + 1])
        ptr += 2
        x2 = int(input[ptr])
        y2 = int(input[ptr + 1])
        ptr += 2
        p = int(input[ptr])
        ptr += 1
        
        dx = abs(x1 - x2)
        row_steps = min(dx, N - dx)
        
        dy = abs(y1 - y2)
        col_steps = min(dy, M - dy)
        
        total_cost = (row_steps + col_steps) * p
        
        print(total_cost)
        if total_cost <= 1000:
            print("You saved the group.")
        else:
            print("Let go of the group.")

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read all at once and split into tokens for efficient parsing. This helps in handling large inputs effectively.
2. **Row and Column Moves Calculation**: For each direction (row and column), the minimal moves are calculated by considering both direct and wrap-around paths. The minimal move is chosen to ensure the shortest path.
3. **Cost Calculation**: The total cost is derived by summing the minimal row and column moves and multiplying by the cost per move.
4. **Result Check**: The total cost is compared against the budget (1000 coins) to determine the output message.

This approach ensures that we efficiently compute the minimal path using wrap-around features and check the feasibility within the given constraints, providing an optimal solution for Abed's travel problem.
