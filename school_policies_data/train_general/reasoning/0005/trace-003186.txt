To solve this problem, we need to count the number of pairs of indices (i, j) such that the substring from i to j contains the substring "bear" at least once. The key insight is to efficiently compute the contribution of each occurrence of "bear" without double-counting overlapping pairs.

### Approach
1. **Identify Occurrences**: First, find all starting positions of the substring "bear" in the given string.
2. **Calculate Contributions**: For each occurrence of "bear" starting at position `k`, compute the number of valid pairs (i, j) that include this occurrence but do not overlap with previous occurrences. This is done by considering the range of possible i values from the start of the string up to the current occurrence and the range of possible j values from the end of the current occurrence to the end of the string.
3. **Sum Contributions**: Sum the contributions of all occurrences to get the total number of valid pairs.

### Solution Code
```python
s = input().strip()
n = len(s)
positions = []
for i in range(n - 3):
    if s[i:i+4] == 'bear':
        positions.append(i)

total = 0
prev = -1  # previous occurrence's position, initialized to -1 for the first occurrence

for k in positions:
    # The number of possible i's is (k - prev), as i can be from prev+1 to k (inclusive)
    # The number of possible j's is (n - (k + 3)), since j must be >= k+3
    contribution = (k - prev) * (n - k - 3)
    total += contribution
    prev = k  # update previous to current occurrence's position

print(total)
```

### Explanation
1. **Identify Occurrences**: The code first scans the string to find all starting positions of "bear". This is done using a loop that checks each possible starting position from 0 to `n-4` (inclusive).
2. **Calculate Contributions**: For each occurrence of "bear" at position `k`, the contribution to the total count is calculated. The contribution is determined by the number of valid i values (from the start of the string up to `k`) and valid j values (from the end of the current "bear" substring to the end of the string). The formula `(k - prev) * (n - k - 3)` ensures that we only count pairs that include the current occurrence and not those already counted by previous occurrences.
3. **Sum Contributions**: The contributions from all occurrences are summed up to get the total number of valid pairs, which is then printed as the result.

This approach efficiently computes the result in O(n) time complexity for scanning the string and O(m) time for processing each occurrence (where m is the number of "bear" occurrences), making it suitable for large input sizes.
