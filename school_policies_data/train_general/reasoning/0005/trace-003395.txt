1. **Understanding the Recursive Definitions**:
   - The sequences F(n) and G(n) are defined recursively. However, upon closer inspection, we find that F(n) remains zero for all n due to its base cases and recursive formula.
   - With F(n) being zero for all n, the sequence G(n) simplifies significantly. For n ≥ 2, G(n) is determined by a constant value derived from the input parameters.

2. **Simplifying H(n)**:
   - Since F(n) is always zero, H(n) simplifies to a linear function of G(n). This allows us to compute H(n) efficiently without recursion.

3. **Efficient Sum Calculation**:
   - The sum of H(n) values up to any n can be derived using a formula that leverages the constant values derived from the input parameters. This formula allows each query to be answered in constant time O(1).

### Solution Code

```python
MOD = 10**9 + 7

# Read input parameters
a, b, c, d, e, f = map(int, input().split())
Q = int(input())

# Precompute the necessary values modulo MOD

f_mod = f % MOD

        print(0)
    else:

        # Compute result = f * term mod MOD
        res = (f_mod * term) % MOD
        print(res)
```
