To solve this problem, we need to determine the maximum time \( T \) at which the reaction must be stopped to ensure the number of atoms does not exceed a given limit \( M \). The reaction starts with \( N \) atoms, and each atom splits into \( K \) atoms every second.

### Approach
1. **Problem Analysis**: The number of atoms after \( T \) seconds is given by \( N \times K^T \). We need to find the maximum \( T \) such that \( N \times K^T \leq M \).
2. **Key Insight**: If \( N \) is already greater than \( M \), the reaction cannot start, so \( T = 0 \). Otherwise, compute the maximum \( T \) such that \( K^T \leq \left\lfloor \frac{M}{N} \right\rfloor \).
3. **Efficient Calculation**: Directly computing \( K^T \) for large values can lead to overflow. Instead, iteratively multiply \( K \) until the product exceeds \( \left\lfloor \frac{M}{N} \right\rfloor \), counting the number of multiplications (which gives \( T \)).

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    p = int(input[0])
    idx = 1
    for _ in range(p):
        N = int(input[idx])
        K = int(input[idx + 1])
        M = int(input[idx + 2])
        idx += 3
        if N > M:
            print(0)
        else:
            X = M // N
            current = 1
            T = 0
            while True:
                next_current = current * K
                if next_current > X:
                    break
                current = next_current
                T += 1
            print(T)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Check Immediate Stop**: If \( N \) exceeds \( M \) initially, output \( T = 0 \).
3. **Iterative Calculation**: For each test case, compute \( X = \left\lfloor \frac{M}{N} \right\rfloor \). Then iteratively multiply \( K \) starting from 1 until the product exceeds \( X \), keeping track of the number of multiplications (which gives \( T \)).

This approach ensures that we efficiently determine the maximum \( T \) without overflow, handling large values within the problem constraints effectively.
