To solve this problem, we need to determine if a given ticket number meets two specific criteria to be considered "lucky" according to Petya's definition. The ticket must be a lucky number (composed only of the digits 4 and 7) and the sum of the digits in the first half must equal the sum of the digits in the second half.

### Approach
1. **Check for Lucky Number**: Verify that all digits in the ticket number are either 4 or 7. If any digit is not 4 or 7, the ticket is not lucky.
2. **Check Sum of Halves**: Split the ticket number into two equal parts. Calculate the sum of the digits in each part. If the sums are equal, the ticket is lucky; otherwise, it is not.

### Solution Code
```python
def check_lucky_ticket():
    n = int(input())
    s = input().strip()
    
    # Check if all characters are 4 or 7
    for c in s:
        if c not in {'4', '7'}:
            print("NO")
            return
    
    half = n // 2
    first_half = s[:half]
    second_half = s[half:]
    
    sum_first = sum(int(d) for d in first_half)
    sum_second = sum(int(d) for d in second_half)
    
    print("YES" if sum_first == sum_second else "NO")

check_lucky_ticket()
```

### Explanation
1. **Input Reading**: The function reads the input values for the length of the ticket number (n) and the ticket number itself (s).
2. **Lucky Number Check**: Iterate through each character in the ticket number to ensure all characters are either '4' or '7'. If any character is not, it immediately prints "NO" and exits.
3. **Splitting and Summing**: The ticket number is split into two halves. The sum of the digits in each half is calculated and compared. If the sums are equal, "YES" is printed; otherwise, "NO" is printed.

This approach efficiently checks both conditions required for the ticket to be considered lucky, ensuring correctness and optimal performance.
