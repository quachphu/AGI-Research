To solve this problem, we need to determine the minimum number of coins Taro receives as change when he pays with a 1000 yen bill at a store. The coins available are in denominations of 500, 100, 50, 10, 5, and 1 yen. The goal is to use a greedy algorithm to minimize the number of coins given as change for each transaction.

### Approach
1. **Calculate the Change**: For each transaction, compute the change as `1000 - price` where `price` is the amount paid by Taro.
2. **Greedy Algorithm**: Use the largest denominations first to minimize the number of coins. This approach works because each coin denomination is a multiple of the next smaller denomination, ensuring the greedy choice is optimal.
3. **Iterate Through Denominations**: For each denomination, determine how many coins can be used and reduce the remaining change accordingly. Sum these counts to get the total number of coins.

### Solution Code
```python
def main():
    import sys
    for line in sys.stdin:
        line = line.strip()
        if line == '0':
            break
        if not line:
            continue
        price = int(line)
        change = 1000 - price
        coins = 0
        for denom in [500, 100, 50, 10, 5, 1]:
            coins += change // denom
            change %= denom
        print(coins)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads input lines until a line containing '0' is encountered, indicating the end of input.
2. **Change Calculation**: For each valid price (non-zero), the change is computed as `1000 - price`.
3. **Coin Count Calculation**: Using a loop over the coin denominations in descending order, the code calculates how many of each coin can be used, updates the remaining change, and accumulates the total number of coins.
4. **Output**: The total number of coins for each transaction is printed immediately after processing each input line.

This approach ensures that the solution is efficient and optimal, as each step processes the input in linear time relative to the number of denominations, which is constant.
