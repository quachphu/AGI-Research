To solve this problem, we need to determine if a given number \( l \) is a power of another number \( k \). If it is, we also need to find the "importance" of \( l \), which is defined as the exponent minus one when \( l \) is expressed as \( k^m \).

### Approach
1. **Check Divisibility**: Continuously divide \( l \) by \( k \) as long as \( l \) remains divisible by \( k \).
2. **Track Exponents**: Keep a counter to track how many times the division is performed. This counter will represent the exponent \( m \) such that \( k^m = l \).
3. **Check Result**: After performing the divisions, if the remaining value is 1, \( l \) is indeed a power of \( k \). The importance is then \( m - 1 \). If the remaining value is not 1, \( l \) is not a power of \( k \).

### Solution Code
```python
def check_petriciumus():
    k = int(input())
    l = int(input())
    m = 0
    current = l
    while current % k == 0:
        current = current // k
        m += 1
    if current == 1:
        print("YES")
        print(m - 1)
    else:
        print("NO")

check_petriciumus()
```

### Explanation
1. **Reading Input**: The function reads two integers, \( k \) and \( l \), from standard input.
2. **Divisibility Check**: Using a loop, we repeatedly divide \( l \) by \( k \) as long as \( l \) is divisible by \( k \). Each successful division increments the exponent counter \( m \).
3. **Result Verification**: After exiting the loop, if the remaining value of \( l \) (after all divisions) is 1, it confirms that \( l \) is a power of \( k \). The importance is then \( m - 1 \). If the remaining value is not 1, \( l \) is not a power of \( k \).

This approach efficiently determines if \( l \) is a power of \( k \) using a linear division process, which runs in \( O(\log_k l) \) time complexity, ensuring it handles the upper constraint values efficiently.
