To solve this problem, we need to determine the minimum number of contestants who declined the invitation to compete onsite in the final round of the competition. The key insight is that the highest rank among the known finalists determines the minimum number of declines required to include all known finalists in the final list of 25 participants.

### Approach
1. **Understanding the Problem**: The competition invites the top 25 contestants initially. If any contestant declines, the next highest-ranked contestant is invited. This process continues until 25 contestants accept. The goal is to find the minimum number of declines required to include all known finalists in the final list.
2. **Key Insight**: The highest rank among the known finalists determines the minimum number of declines. If the highest rank (max_r) is greater than 25, the minimum number of declines is `max_r - 25` because each decline allows inviting the next highest-ranked contestant. If the highest rank is 25 or lower, no declines are needed as all known finalists are within the initial top 25.

### Solution Code
```python
k = int(input())
ranks = list(map(int, input().split()))
max_r = max(ranks)
print(max(max_r - 25, 0) if max_r > 25 else 0)
```

### Explanation
1. **Reading Input**: The input consists of the number of known finalists and their ranks.
2. **Finding Maximum Rank**: The highest rank among the known finalists is determined using the `max` function.
3. **Calculating Declines**: If the highest rank is greater than 25, the minimum number of declines required is `max_r - 25`. If it is 25 or lower, no declines are needed, so the result is 0.

This approach efficiently computes the result in O(K) time complexity, where K is the number of known finalists, making it optimal for the given problem constraints.
