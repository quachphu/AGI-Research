To solve this problem, we need to determine how many ways Kirti can choose consecutive digits from a given string such that the resulting number is a multiple of 8 and does not have leading zeros. The solution involves checking substrings of different lengths and leveraging the properties of numbers divisible by 8.

### Approach
1. **Single-digit Check**: Any single digit that is '0' or '8' is a valid multiple of 8.
2. **Two-digit Check**: Check all possible two-digit substrings starting with a non-zero digit and forming a number divisible by 8.
3. **Three-digit Check**: Check all possible three-digit substrings starting with a non-zero digit and forming a number divisible by 8.
4. **Longer Substrings Check**: For substrings of length 4 or more, check if the last three digits form a number divisible by 8. The substring must start with a non-zero digit.

### Solution Code
```python
def count_valid_substrings():
    import sys
    S = sys.stdin.readline().strip()
    n = len(S)
    if n == 0:
        print(0)
        return

    # Precompute valid 2-digit and 3-digit multiples of 8
    valid_2_digit = set()
    for num in range(10, 100):
        if num % 8 == 0 and num // 10 != 0:
            valid_2_digit.add(str(num).zfill(2))
    
    valid_3_digit = set()
    for num in range(0, 1000):
        if num % 8 == 0:
            valid_3_digit.add(f"{num:03}")

    # Precompute prefix sum of non-zero characters
    non_zero = [0] * (n + 1)
    for i in range(n):
        non_zero[i+1] = non_zero[i] + (1 if S[i] != '0' else 0)

    count = 0

    # Check 1-digit substrings
    count += sum(1 for c in S if c in {'0', '8'})

    # Check 2-digit substrings
    for i in range(n - 1):
        if S[i] == '0':
            continue
        two_digit = S[i] + S[i+1]
        if two_digit in valid_2_digit:
            count += 1

    # Check 3-digit substrings and longer substrings
    for i in range(n - 2):
        triplet = S[i:i+3]
        if triplet not in valid_3_digit:
            continue
        j = i + 2  # end index of the triplet
        # Check if the triplet itself is a valid 3-digit number
        if S[i] != '0':
            count += 1
        # Check longer substrings (>=4 digits)
        if j >= 3:
            count += non_zero[j - 2]  # non_zero[j-2] is sum up to (j-3) index

    print(count)

count_valid_substrings()
```

### Explanation
1. **Precompute Valid Numbers**: We precompute all valid two-digit and three-digit numbers that are divisible by 8. This helps in quickly checking substrings without converting them to integers repeatedly.
2. **Prefix Sum Array**: We use a prefix sum array to efficiently count the number of non-zero characters up to any index, which helps in quickly determining valid starting positions for longer substrings.
3. **Check Substrings**: For each possible substring length (1, 2, 3, and longer), we check if they meet the criteria of being a valid multiple of 8 without leading zeros. For longer substrings, we check the last three digits and use the prefix sum array to count valid starting positions.

This approach ensures that we efficiently check all possible valid substrings while adhering to the constraints, making the solution both optimal and scalable for large input sizes.
