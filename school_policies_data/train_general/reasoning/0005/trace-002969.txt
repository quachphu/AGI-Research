To solve this problem, we need to calculate the total memory allocated by a program when running multiple test files, where each test file adjusts the memory to exactly match its requirement. The total allocated memory is the sum of all memory increments required to meet each test file's memory needs.

### Approach
1. **Initialization**: Start with no memory allocated.
2. **Iterate through each test file**: For each test file's memory requirement, calculate the difference (delta) between the current allocated memory and the required memory.
3. **Memory Adjustment**: If the current allocated memory is less than the required memory, allocate the difference and add it to the total. If the current memory is more than required, simply deallocate to match the requirement without changing the total.
4. **Summing Up**: The total allocated memory is the sum of all positive deltas encountered during the iteration through each test case.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        M = list(map(int, input[ptr:ptr + N]))
        ptr += N
        current = 0
        total = 0
        for m in M:
            delta = m - current
            if delta > 0:
                total += delta
                current = m
            else:
                current = m
        print(total)

if __name__ == "__main__":
    main()
```

1. **Reading Input Efficiently**: The input is read all at once for efficiency, especially given the constraints. This reduces the overhead of multiple I/O operations.
2. **Processing Each Test Case**: For each test case, we initialize the current allocated memory to 0 and iterate through each memory requirement.
3. **Memory Adjustment Logic**: For each memory requirement, we compute the delta between the current memory and the required memory. If delta is positive, we add it to the total and update the current memory. If delta is negative or zero, we simply update the current memory without changing the total.
4. **Output the Result**: After processing all test files in a test case, the total allocated memory is printed.

This approach ensures that we efficiently compute the total memory allocated by considering only the necessary increments, adhering to the problem constraints and requirements.
