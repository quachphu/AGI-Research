The solution involves recognizing that this process is analogous to finding the greatest common divisor (GCD) of the list of sweets each child initially has.

### Approach
1. **Understanding the Problem**: The key insight is that the operation described (subtracting the smaller number from the larger one repeatedly) is the same as the steps taken in the Euclidean algorithm to compute the GCD of two numbers. Therefore, the final number of sweets each child will have is the GCD of all the initial numbers of sweets.
2. **Algorithm Selection**: We use the Euclidean algorithm to compute the GCD of all elements in the list. The GCD of a list of numbers can be computed iteratively by finding the GCD of the current result with the next element in the list.
3. **Complexity Analysis**: The time complexity of computing the GCD of two numbers using the Euclidean algorithm is O(log(min(a, b))). For a list of n elements, this results in an overall time complexity of O(n log(min(a, b))), which is efficient given the problem constraints.

import sys
import math
from functools import reduce
