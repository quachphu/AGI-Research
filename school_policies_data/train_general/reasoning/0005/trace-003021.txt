To solve this problem, we need to determine the number of K-prime numbers between two integers A and B for multiple test cases. A K-prime number is defined as a number that has exactly K distinct prime factors. 

### Approach
1. **Precompute Distinct Prime Factors**: Use a sieve-like algorithm to precompute the number of distinct prime factors for each number up to 100,000. This allows us to efficiently determine the count of distinct prime factors for any number in constant time.
2. **Prefix Sum Arrays**: For each possible value of K (from 1 to 5), precompute a prefix sum array that stores the cumulative count of numbers up to each index that have exactly K distinct prime factors. This allows us to quickly answer each query in constant time by computing the difference between two values in the prefix sum array.

### Solution Code
```python
import sys

def main():
    max_num = 100000
    dpf = [0] * (max_num + 1)
    
    for p in range(2, max_num + 1):
        if dpf[p] == 0:  # p is a prime
            for multiple in range(p, max_num + 1, p):
                dpf[multiple] += 1
    
    # Initialize prefix arrays for K=1 to 5
    prefix = [[0] * (max_num + 1) for _ in range(6)]  # K ranges 0-5
    
    for K in range(1, 6):
        for i in range(2, max_num + 1):
            prefix[K][i] = prefix[K][i - 1] + (1 if dpf[i] == K else 0)
    
    # Read all input at once
    input_data = sys.stdin.read().split()
    T = int(input_data[0])
    idx = 1
    
    results = []
    for _ in range(T):
        A = int(input_data[idx])
        B = int(input_data[idx + 1])
        K = int(input_data[idx + 2])
        idx += 3
        
        if K < 1 or K > 5:
            results.append(0)
        else:
            res = prefix[K][B] - prefix[K][A - 1]
            results.append(res)
    
    print('\n'.join(map(str, results)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precompute Distinct Prime Factors**: Using a sieve algorithm, we iterate through each number starting from 2. For each prime number encountered, we increment the count of distinct prime factors for all its multiples. This efficiently computes the number of distinct prime factors for each number up to 100,000.
2. **Prefix Sum Arrays**: For each K from 1 to 5, we create a prefix sum array where each entry at index i contains the count of numbers from 2 to i that have exactly K distinct prime factors. This allows us to quickly compute the count of K-prime numbers in any range [A, B] using the difference of two prefix sums.
3. **Efficient Query Handling**: Each query is answered in constant time by leveraging the precomputed prefix sum arrays, ensuring that even with the maximum constraints, the solution remains efficient and scalable.
