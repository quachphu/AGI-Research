To solve this problem, we need to generate pairs of integers (n, m) such that the maximum number of 1's in an m-free n x n matrix is exactly equal to a given value x. If no such pair exists, we should return -1.

### Approach
1. **Understanding m-free Matrix**: An m-free matrix is a binary matrix where every m x m submatrix contains at least one 0. The goal is to maximize the number of 1's in such a matrix.
2. **Key Insight**: The maximum number of 1's in an m-free n x n matrix can be determined using the formula \( x = n^2 - k^2 \), where \( k = \text{floor}(n/m) \). This formula arises from the optimal arrangement of 0's to break all possible m x m submatrices.
3. **Factorization**: For each given x, we need to find factor pairs (a, b) such that \( x = a \times b \) and both a and b have the same parity (both even or both odd). This helps in determining potential values of n and k.
4. **Determine Valid m**: For each valid factor pair (a, b), compute n and k. Check if there exists an integer m such that \( k = \text{floor}(n/m) \).

### Solution Code
```python
import math

def find_nm(x):
    if x == 0:
        return (1, 1)
    factors = []
    for a in range(1, int(math.isqrt(x)) + 1):
        if x % a == 0:
            b = x // a
            if a <= b and (a % 2) == (b % 2):
                factors.append((a, b))
    for a, b in factors:
        n = (a + b) // 2
        k = (b - a) // 2
        if k == 0:
            continue
        m_min = (n // (k + 1)) + 1
        m_max = n // k
        m_min = max(m_min, 1)
        m_max = min(m_max, n)
        if m_min > m_max:
            continue
        m = m_min
        if 1 <= m <= n:
            return (n, m)
    return (-1,)

t = int(input())
for _ in range(t):
    x = int(input())
    result = find_nm(x)
    print(' '.join(map(str, result)) if len(result) > 1 else result[0])
```
