JOI is playing sugoroku alone. There are N squares in a straight line in this sugoroku, and each has a movement instruction written on it. The starting point is the 1st square and the goal is the Nth square. JOI repeats the following until he reaches the goal.

Roll the dice and proceed from the current square by the number of rolls, and follow the instructions of that square. Do not follow the instructions of the square to which you moved according to the instructions.

The goal is not only when you stop at the Nth square, but also when the destination exceeds the Nth square.

Create a program that outputs how many times you roll the dice to reach the goal when you are given a sugoroku board and M dice rolls.

input

The input consists of multiple datasets. Each dataset is given in the following format.

Each dataset consists of 1 + N + M rows.

Two integers N, M (2 ≤ N ≤ 1000, 1 ≤ M ≤ 1000) are written on the first line of the input, separated by blanks. N represents the number of sugoroku squares, and M represents the number of dice given.

In the following N lines, integers between -999 and 999 are written one by one. The integer on the 1 + i line (1 ≤ i ≤ N) represents the indication of the sugoroku i-th cell. When both N and M are 0, it indicates the end of input. The number of data sets does not exceed 5.

To solve this problem, we need to simulate a board game where the player moves according to dice rolls and follows instructions on each square. The goal is to determine how many dice rolls are needed to reach or exceed the final square.

### Approach
1. **Input Reading**: Read the input values which include multiple datasets. Each dataset consists of the number of squares (N), the number of dice rolls (M), the instructions for each square, and the sequence of dice rolls.
2. **Simulation**: For each dataset, simulate the player's movement starting from the first square. For each dice roll:
   - Move the player forward by the dice value.
   - Check if the new position reaches or exceeds the final square. If so, record the number of rolls used.
   - If not, apply the instruction from the current square and check again if the new position reaches or exceeds the final square.
3. **Termination**: The simulation stops as soon as the player reaches or exceeds the final square, and the number of dice rolls used is printed.

### Solution Code
```python
def sugoroku():
    import sys
    data = list(map(int, sys.stdin.read().split()))
    ptr = 0
    while True:
        if ptr >= len(data):
            break
        N = data[ptr]
        M = data[ptr + 1]
        ptr += 2
        if N == 0 and M == 0:
            break
        instructions = data[ptr:ptr + N]
        ptr += N
        dice_rolls = data[ptr:ptr + M]
        ptr += M
        current = 1
        count = 0
        for dice in dice_rolls:
            count += 1
            current += dice
            if current >= N:
                print(count)
                break
            x = instructions[current - 1]
            current += x
            if current >= N:
                print(count)
                break
```

- **Reading Input**: The input is read all at once and split into a list of integers for easier processing. This list is then traversed using a pointer to extract each dataset's parameters.
- **Simulation Loop**: For each dice roll, the player's position is updated. If the new position meets or exceeds the final square, the count of rolls is printed immediately. If not, the instruction from the current square is applied, and the position is updated again. This check is repeated after applying the instruction.
- **Termination Check**: The loop ensures that the simulation stops as soon as the player reaches or exceeds the final square, ensuring efficient processing.

This approach efficiently handles the input and simulation, ensuring that the solution is both correct and optimal for the given problem constraints.
