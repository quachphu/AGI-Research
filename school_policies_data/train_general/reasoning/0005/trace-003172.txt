To solve this problem, we need to determine all possible lengths \( k \) of the original array \( x \) that could generate the given array \( a \) using the specified construction rules. The key insight is to check if the differences between consecutive elements of \( a \) form a periodic sequence with period \( k \).

### Approach
1. **Compute Differences**: Calculate the differences between consecutive elements of the given array \( a \). This differences array \( d \) will help us determine the periodic nature of \( x \).
2. **Check Validity for Each \( k \)**: For each possible \( k \) from 1 to \( n \), check if the differences array \( d \) can be divided into segments of length \( k \) where each segment matches the first segment. This ensures that the sequence of differences is periodic with period \( k \).
3. **Collect Valid Lengths**: Collect all valid \( k \) values that satisfy the periodic condition and output them in increasing order.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))

# Compute the differences array
d = []
prev = 0
for num in a:
    d.append(num - prev)
    prev = num

valid_k = []

for k in range(1, n + 1):
    valid = True
    for m in range(n):
        if m >= k:
            if d[m] != d[m % k]:
                valid = False
                break
    if valid:
        valid_k.append(k)

print(len(valid_k))
print(' '.join(map(str, sorted(valid_k))))
```

### Explanation
1. **Compute Differences**: The differences array \( d \) is constructed by iterating through the given array \( a \) and calculating the difference between each consecutive element starting from \( a_0 = 0 \).
2. **Check Periodicity**: For each candidate \( k \), check if every element in the differences array \( d \) beyond the first \( k \) elements matches the corresponding element in the first \( k \) elements. This is done by verifying \( d[m] = d[m \mod k] \) for all \( m \geq k \).
3. **Output Valid Lengths**: After checking all possible values of \( k \), collect and print the valid lengths in ascending order.

This approach efficiently checks each possible \( k \) in \( O(n^2) \) time complexity, which is feasible given the constraint \( n \leq 1000 \). This ensures we accurately determine all valid lengths of the original array \( x \).
