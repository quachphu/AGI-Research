To solve this problem, we need to determine the minimum number of contiguous subarrays such that each subarray's product equals its least common multiple (LCM) for multiple queries on an array. The key insight is that each subarray must consist of pairwise coprime elements, which means their product equals their LCM.

### Approach
1. **Factorization**: Precompute the smallest prime factors (SPF) for numbers up to 100,000 using a sieve method. This allows efficient factorization of each element in the array.
2. **Sliding Window Technique**: Use a sliding window approach to determine the farthest position `next[i]` for each index `i` such that the subarray starting at `i` and ending at `next[i]` contains only pairwise coprime elements.
3. **Binary Lifting**: Precompute jump pointers using binary lifting to efficiently answer each query in logarithmic time. This helps in quickly determining the number of partitions required for any given range.

### Solution Code
```python
import sys
import math

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    q = int(input[ptr])
    ptr += 1

    a = list(map(int, input[ptr:ptr + n]))
    ptr += n

    max_a = 10**5
    spf = list(range(max_a + 1))
    for i in range(2, int(math.sqrt(max_a)) + 1):
        if spf[i] == i:
            for j in range(i * i, max_a + 1, i):
                if spf[j] == j:
                    spf[j] = i

    def factor(x):
        primes = set()
        if x == 1:
            return primes
        while x != 1:
            p = spf[x]
            primes.add(p)
            while x % p == 0:
                x //= p
        return primes

    next_arr = [n] * n
    last_p = dict()
    left = 0

    for j in range(n):
        primes = factor(a[j])
        new_left = left
        for p in primes:
            if p in last_p and last_p[p] >= left:
                if new_left < last_p[p] + 1:
                    new_left = last_p[p] + 1
        for p in primes:
            last_p[p] = j
        if new_left > left:
            for i in range(left, new_left):
                if i >= n:
                    break
                if next_arr[i] == n:
                    next_arr[i] = j - 1
            left = new_left

    log_max = 20
    jump = [[n] * n for _ in range(log_max)]
    for i in range(n):
        if next_arr[i] < n:
            jump[0][i] = next_arr[i] + 1
        else:
            jump[0][i] = n

    for k in range(1, log_max):
        for i in range(n):
            if jump[k-1][i] >= n:
                jump[k][i] = n
            else:
                jump[k][i] = jump[k-1][jump[k-1][i]]

    for _ in range(q):
        l = int(input[ptr])
        ptr += 1
        r = int(input[ptr])
        ptr += 1
        l -= 1
        r -= 1
        if l > r:
            print(0)
            continue
        res = 0
        current = l
        for k in reversed(range(log_max)):
            if current <= r and jump[k][current] <= r:
                res += (1 << k)
                current = jump[k][current]
        if current <= r:
            res += 1
        print(res)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Factorization**: Using the smallest prime factor (SPF) sieve, we efficiently factorize each element of the array into its prime factors.
2. **Sliding Window**: For each element, we maintain a sliding window to track the leftmost index where all primes in the current window are unique. This helps in determining the farthest valid subarray starting from each index.
3. **Binary Lifting**: Precompute jump pointers to enable efficient querying. This allows us to quickly determine the number of partitions required for any subarray by jumping through precomputed intervals, reducing the query time complexity to O(log n).

This approach ensures that we efficiently handle up to 100,000 elements and queries, providing optimal performance for large input sizes.
