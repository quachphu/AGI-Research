To solve this problem, we need to sort a given string based on the frequency of its characters in ascending order. If two characters have the same frequency, they should be sorted lexicographically. The solution involves counting the characters, sorting them according to the specified criteria, and then constructing the result string.

### Approach
1. **Count Character Frequencies**: Use a counter to determine the frequency of each character in the input string.
2. **Sort Characters**: Sort the characters first by their frequency in ascending order. If two characters have the same frequency, sort them lexicographically.
3. **Construct Result String**: Build the result string by repeating each character according to its frequency, based on the sorted order.

### Solution Code
```python
import sys
from collections import Counter

def process_string(s):
    counts = Counter(s)
    sorted_chars = sorted(counts.items(), key=lambda x: (x[1], x[0]))
    result = ''.join([char * cnt for char, cnt in sorted_chars])
    return result

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        s = sys.stdin.readline().strip()
        print(process_string(s))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first line contains the number of test cases.
2. **Counting Characters**: For each string, we use `collections.Counter` to count the occurrences of each character.
3. **Sorting**: The characters are sorted using a key that first considers their frequency (ascending) and then their lexicographical order (ascending).
4. **Constructing Output**: The sorted characters are concatenated into a string where each character is repeated according to its count, forming the final result which is then printed.

This approach ensures that the string is transformed according to the specified criteria efficiently and correctly.
