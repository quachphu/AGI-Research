To solve this problem, we need to convert a binary string consisting of zeros and ones into a string of all ones with the minimum cost using two operations: reversing a substring (cost `x`) and inverting a substring (cost `y`). The goal is to determine the optimal sequence of operations to achieve this conversion at the lowest cost.

### Approach
1. **Identify Zero Runs**: The key insight is that the number of contiguous zero runs (substrings of zeros) in the string determines the minimal number of invert operations needed. Each invert operation can convert a contiguous block of zeros to ones.
2. **Cost Calculation**: 
   - If there are `k` zero runs, inverting each run individually costs `k * y`.
   - Alternatively, reversing operations can merge adjacent zero runs if it reduces the total cost. The optimal strategy is to compare the cost of using reverses to merge zero runs and then invert once versus inverting each run individually.
   - The minimal cost is determined by choosing the cheaper option between merging all zero runs using reverses (if beneficial) and inverting each run individually.

### Solution Code
```python
n, x, y = map(int, input().split())
a = input().strip()

zero_runs = 0
prev = '1'  # Initialize to '1' to detect the first zero run correctly
for c in a:
    if prev == '1' and c == '0':
        zero_runs += 1
    prev = c

if zero_runs == 0:
    print(0)
else:
    print((zero_runs - 1) * min(x, y) + y)
```

### Explanation
1. **Count Zero Runs**: Iterate through the string to count the number of contiguous zero runs. This is done by checking transitions from '1' to '0'.
2. **Calculate Minimum Cost**: 
   - If there are no zero runs, the string is already all ones, so the cost is 0.
   - Otherwise, compute the cost using the formula `(zero_runs - 1) * min(x, y) + y`. This formula considers the cheaper option between merging zero runs with reverses (if `x` is cheaper) and inverting each run individually.

This approach efficiently determines the minimal cost by leveraging the optimal use of reverse and invert operations based on their respective costs, ensuring the solution is both optimal and efficient.
