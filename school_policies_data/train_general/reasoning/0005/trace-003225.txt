To solve this problem, we need to divide an array into k non-empty consecutive subarrays such that the cost, defined as the sum of each element multiplied by the index of the subarray it belongs to, is maximized. 

### Approach
1. **Initial Sum Calculation**: Start by calculating the sum of all elements in the array, as this will be the base cost when the entire array is considered a single subarray.
2. **Suffix Sums Calculation**: Compute the suffix sums for all possible split points. A suffix sum at position i is the sum of all elements from position i+1 to the end of the array.
3. **Optimal Splits Selection**: To maximize the cost, select the top k-1 largest suffix sums. Each split after a position increases the multiplier of all subsequent elements by 1, thus contributing their suffix sum to the total cost.
4. **Result Calculation**: The final result is the initial sum plus the sum of the top k-1 largest suffix sums.

### Solution Code
```python
import sys

def main():
    n, k = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    prefix = [0]
    for num in a:
        prefix.append(prefix[-1] + num)
    if k == 1:
        print(prefix[-1])
        return
    suffix_sums = []
    for i in range(n-1):
        suffix_sums.append(prefix[-1] - prefix[i+1])
    suffix_sums.sort(reverse=True)
    total = prefix[-1] + sum(suffix_sums[:k-1])
    print(total)

main()
```

### Explanation
1. **Initial Sum Calculation**: The initial sum of all elements is computed using a prefix sum array. This gives the base cost when the array is undivided (k=1).
2. **Suffix Sums Calculation**: For each possible split point (from 0 to n-2), compute the sum of elements from the next position to the end. This is efficiently done using the prefix sum array.
