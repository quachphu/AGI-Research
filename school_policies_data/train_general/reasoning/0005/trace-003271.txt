To solve this problem, we need to determine if we can rotate each rectangle in a row such that their heights form a non-ascending sequence. Each rectangle can be rotated by 90 degrees, which swaps its width and height. The goal is to check if we can achieve a sequence where each rectangle's height is not greater than the previous one's height.

### Approach
1. **First Rectangle Handling**: For the first rectangle, we choose the maximum possible height between its width and height. This maximizes the flexibility for subsequent rectangles.
2. **Subsequent Rectangles**: For each subsequent rectangle, we check both possible heights (original and rotated). We select the largest possible height that does not exceed the previous rectangle's height. This greedy approach ensures we maintain the highest possible valid height at each step to maximize flexibility for the next rectangles.
3. **Termination Check**: If at any point no valid height can be chosen for a rectangle, we immediately determine that it's impossible to form a non-ascending sequence and return "NO". If all rectangles are processed successfully, we return "YES".

### Solution Code
```python
import sys

def can_non_ascending():
    n = int(sys.stdin.readline())
    if n == 0:
        print("YES")
        return
    rects = []
    for _ in range(n):
        w, h = map(int, sys.stdin.readline().split())
        rects.append((w, h))
    
    h_prev = max(rects[0][0], rects[0][1])
    
    for i in range(1, n):
        w, h = rects[i]
        max_current = -1
        for candidate in (w, h):
            if candidate <= h_prev and candidate > max_current:
                max_current = candidate
        if max_current == -1:
            print("NO")
            return
        h_prev = max_current
    print("YES")

can_non_ascending()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin` for efficiency, especially given the constraints of up to 100,000 rectangles.
2. **Initial Setup**: The first rectangle's height is set to the maximum of its width and height to start with the highest possible value.
3. **Iterative Check**: For each subsequent rectangle, we check both possible heights (width and height) and select the largest valid height that does not exceed the previous height. If no valid height is found, we print "NO" and exit.
4. **Output Result**: If all rectangles are processed successfully, we print "YES".

This approach ensures that we efficiently check each rectangle in linear time, making the solution optimal and scalable for large inputs.
