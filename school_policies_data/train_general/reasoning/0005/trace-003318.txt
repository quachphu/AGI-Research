To solve this problem, we need to determine how many sets of candies on an n × n grid can be split equally into m parts. Each cell (i, j) on the grid has i² + j² candies, and we need to check if this value is divisible by m for each cell.

### Approach
1. **Residue Calculation**: For each possible residue modulo m, compute the residues of squares modulo m. This helps in determining which residues of i² and j² can sum up to a value divisible by m.
2. **Count Valid Residues**: For each residue r, count how many numbers in the range [1, n] have squares that are congruent to r modulo m. This is done by checking how many numbers in the range have residues that result in the desired square residues.
3. **Sum Valid Pairs**: For each pair of residues (a, b) such that their sum modulo m is zero, compute the product of their counts and sum these products. This gives the total number of valid cells.

### Solution Code
```python
n, m = map(int, input().split())

from collections import defaultdict

# Precompute squares modulo m: for each residue r, list of s where s^2 ≡ r mod m
squares = defaultdict(list)
for s in range(m):
    r = (s * s) % m
    squares[r].append(s)

# Calculate count[r] for each residue r
cnt = [0] * m
for r in range(m):
    for s in squares[r]:
        if s == 0:
            # Numbers congruent to 0 mod m: m, 2m, ..., km <=n
            cnt[r] += n // m
        else:
            if s > n:
                continue
            # Numbers congruent to s mod m: s, m+s, ..., km +s <=n
            count = (n - s) // m + 1
            cnt[r] += count

# Compute the answer by checking pairs (a, b) where a + b ≡0 mod m
answer = 0
for a in range(m):
    b = (-a) % m
    answer += cnt[a] * cnt[b]

print(answer)
```

### Explanation
1. **Residue Calculation**: We first determine all possible residues of squares modulo m. This helps in identifying which residues of i and j will make i² + j² divisible by m.
2. **Count Valid Residues**: For each residue r, we count how many numbers in the range [1, n] have squares that give a residue r modulo m. This is done by checking each possible residue s modulo m and counting how many times each residue appears in the range.
3. **Sum Valid Pairs**: For each residue a, we find the corresponding residue b such that their sum is divisible by m. We then sum the products of their counts to get the total number of valid cells.

This approach efficiently handles large values of n by focusing on residues and their properties, ensuring the solution is both optimal and scalable.
