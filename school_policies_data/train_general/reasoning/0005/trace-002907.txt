To solve this problem, we need to determine the minimum number of contiguous subarrays such that each subarray is either non-decreasing or non-increasing. The key challenge is to efficiently check and split the array whenever the current subarray can no longer be extended while maintaining the required order.

### Approach
1. **Initialization**: Start with the first element of the array and assume it can form both a non-decreasing and non-increasing subarray.
2. **Iterate through the array**: For each subsequent element, check if it can be part of the current subarray while maintaining either non-decreasing or non-increasing order.
3. **Update Allowed Directions**: Depending on whether the current element is greater than, less than, or equal to the previous element, update the allowed directions (non-decreasing or non-increasing) for the current subarray.
4. **Check for Split**: If neither direction is allowed, split the array at this point, increment the count of subarrays, and reset the allowed directions for the new subarray starting at the current element.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    if n == 0:
        print(0)
        return
    count = 1
    allowed_inc = True
    allowed_dec = True
    prev = a[0]
    for i in range(1, n):
        curr = a[i]
        if curr > prev:
            new_inc = allowed_inc
            new_dec = False
        elif curr < prev:
            new_inc = False
            new_dec = allowed_dec
        else:
            new_inc = allowed_inc
            new_dec = allowed_dec
        if new_inc or new_dec:
            allowed_inc, allowed_dec = new_inc, new_dec
            prev = curr
        else:
            count += 1
            allowed_inc = True
            allowed_dec = True
            prev = curr
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
- **Initialization**: We start with the first element and assume both non-decreasing and non-increasing directions are possible.
- **Iteration**: For each subsequent element, we check its relation to the previous element. Based on this comparison, we update the allowed directions for the current subarray.
- **Direction Updates**: 
  - If the current element is greater than the previous, only non-decreasing direction is allowed.
  - If the current element is less than the previous, only non-increasing direction is allowed.
  - If they are equal, both directions remain allowed if they were previously.
- **Splitting**: When neither direction is possible, we split the array, increment the count of subarrays, and reset the allowed directions for the new subarray starting at the current element.

This approach ensures that we efficiently check each element in linear time, making the solution optimal for large input sizes up to \(10^5\).
