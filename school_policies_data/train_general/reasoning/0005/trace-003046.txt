To solve this problem, we need to determine if there exist two distinct elements in an array that sum up to a given integer K. The solution must efficiently handle large input sizes up to 1 million elements.

### Approach
The key insight is to use a hash set to keep track of elements we have seen so far. For each element in the array, we check if the difference between the target sum K and the current element exists in the set. If it does, we immediately know that there exists a pair of elements that sum to K. If not, we add the current element to the set and continue. This approach ensures that we only traverse the array once, resulting in an efficient O(n) time complexity with O(n) space complexity.

### Solution Code
```python
import sys

def main():
    # Read the first line for N and K
    first_line = sys.stdin.readline().split()
    N = int(first_line[0])
    K = int(first_line[1])
    
    # Read the array elements
    arr = list(map(int, sys.stdin.readline().split()))
    
    seen = set()
    found = False
    for num in arr:
        target = K - num
        if target in seen:
            found = True
            break
        seen.add(num)
    
    print("YES" if found else "NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read using `sys.stdin.readline()` to handle large input sizes efficiently.
2. **Using a Hash Set**: We maintain a set of seen elements. For each element in the array, we check if the complement (K - current element) exists in the set.
3. **Early Termination**: If the complement is found in the set, we immediately print "YES" and terminate. If the loop completes without finding a pair, we print "NO".

This approach ensures that each element is processed exactly once, making the solution both time and space efficient for large datasets.
