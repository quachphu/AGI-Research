To solve this problem, we need to determine the number of distinct pairs of integers (m, n) such that the product of m and n equals a given area A, and they satisfy specific properties. The key property is that if both dimensions are even, they must be the same. 

### Approach
1. **Precomputation of Divisors and Squares**: 
   - Precompute the number of divisors for each number up to 25,000 (since the maximum value of A/4 is 25,000 when A is 100,000).
   - Precompute whether each number up to 25,000 is a perfect square.

2. **Precompute Total Valid Pairs**:
   - For each possible value of m (from 1 to the square root of the maximum area), compute how many times each area A can be divided by m such that m is a valid divisor (i.e., m ≤ sqrt(A)).

3. **Invalid Pairs Calculation**:
   - For each area A that is divisible by 4, compute the number of invalid pairs where both dimensions are even but not equal. This is done by considering the quotient C = A/4 and using precomputed divisor counts and square checks.

4. **Efficient Query Handling**:
   - Using precomputed data, answer each query in constant time by subtracting the number of invalid pairs from the total valid pairs.

### Solution Code
```python
import sys
import math

def main():
    max_C = 25000
    num_divisors = [0] * (max_C + 1)
    for d in range(1, max_C + 1):
        for multiple in range(d, max_C + 1, d):
            num_divisors[multiple] += 1

    is_square = [False] * (max_C + 1)
    max_i = int(math.isqrt(max_C))
    for i in range(0, max_i + 1):
        square = i * i
        if square <= max_C:
            is_square[square] = True

    max_A = 10**5
    ans_total_pairs = [0] * (max_A + 1)
    max_m = int(math.isqrt(max_A))
    for m in range(1, max_m + 1):
        start = m * m
        if start > max_A:
            break
        for A in range(start, max_A + 1, m):
            ans_total_pairs[A] += 1

    ans = [0] * (max_A + 1)
    for A in range(1, max_A + 1):
        if A % 4 != 0:
            invalid = 0
        else:
            C = A // 4
            if C > max_C:
                invalid = 0
            else:
                d = num_divisors[C]
                s = 1 if is_square[C] else 0
                invalid = (d - s) // 2
        ans[A] = ans_total_pairs[A] - invalid

    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        A = int(input[i])
        print(ans[A])

if __name__ == '__main__':
    main()
```

- **Precomputation**: The code first precomputes the number of divisors and checks for perfect squares up to 25,000. This helps in efficiently determining the number of invalid pairs for areas that are multiples of 4.
- **Total Valid Pairs**: Using a sieve-like approach, the code counts the number of valid divisors for each area up to 100,000, ensuring each divisor is less than or equal to the square root of the area.
- **Invalid Pairs Calculation**: For areas that are multiples of 4, the code calculates invalid pairs by considering the quotient C = A/4 and using precomputed divisor counts and square checks.
- **Efficient Query Handling**: By precomputing all necessary values, each query is answered in constant time, ensuring optimal performance even for large inputs.
