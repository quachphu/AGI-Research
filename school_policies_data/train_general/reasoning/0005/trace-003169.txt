To solve this problem, we need to remove all integer digits from each sentence provided in the input. The goal is to process each test case, strip out any digits, and print the resulting string.

### Approach
1. **Input Reading**: Read the number of test cases, T.
2. **Processing Each Test Case**: For each test case, read the input line and remove all digits from it.
3. **Output the Result**: After removing the digits, print the processed string for each test case.

### Solution Code
```python
def process():
    import sys
    T = int(sys.stdin.readline())
    for _ in range(T):
        line = sys.stdin.readline().rstrip('\n')
        res = ''.join([c for c in line if not c.isdigit()])
        print(res)
process()
```

### Explanation
1. **Reading Input**: The first line of input is read to determine the number of test cases, T. Each subsequent line is processed as a test case.
2. **Stripping Digits**: For each test case line, we iterate through each character and filter out any digits using a list comprehension. The `isdigit()` method is used to check if a character is a digit.
3. **Output**: The processed string, which contains no digits, is printed. The `rstrip('\n')` ensures that we handle the newline character correctly when reading each line, and the `print` function ensures each result is on a new line.

This approach efficiently processes each line by removing digits and ensures the output is formatted correctly. The solution handles all edge cases as specified, including ensuring that each processed line is non-empty.
