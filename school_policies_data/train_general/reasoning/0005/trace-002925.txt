1. **Understanding the Sequence Construction**: The sequence is built in steps where each step adds \( k \) numbers followed by their sum. These sums are part of the sequence and are not included in future steps.
2. **Identify Sums**: For each step, check if \( n \) is the sum of the \( k \) numbers added in that step. If it is, the index can be directly calculated.
3. **Determine Position in Non-Sum Elements**: If \( n \) is not a sum, compute its position by considering the numbers that are not sums of any step. The index is determined by the number of elements added before the step containing \( n \) and its position within that step.

### Solution Code
```python
import sys

def find_index(n, k):
    sums = []
    current_step = 0
    while True:
        # Generate the next k numbers not in sums
        available = []
        num = 1
        while len(available) < k:
            if num not in sums:
                available.append(num)
            num += 1
        sum_step = sum(available)
        current_step += 1
        if sum_step == n:
            return current_step * (k + 1)
        if sum_step > n:
            break
        sums.append(sum_step)
    # Now check if n is a u in some step
    count_sums = len(sums)
    pos_in_useq = n - count_sums
    m = (pos_in_useq + k - 1) // k
    pos_in_step = pos_in_useq - (m - 1) * k
    index = (m - 1) * (k + 1) + pos_in_step
    return index

t = int(sys.stdin.readline())
for _ in range(t):
    n, k = map(int, sys.stdin.readline().split())
    print(find_index(n, k))
```

### Explanation
1. **Reading Input**: The input consists of multiple test cases. For each test case, we read \( n \) and \( k \).
2. **Simulating Steps**: For each step, we generate the next \( k \) numbers not in the list of sums. We compute their sum and check if it matches \( n \).
3. **Checking Sums**: If \( n \) matches the sum of the current step, we return the index directly.
4. **Handling Non-Sum Numbers**: If \( n \) is not a sum, we determine its position by subtracting the number of sums less than \( n \) from \( n \) itself. This gives the position in the sequence of non-sum numbers. We then compute the step and position within the step to determine the final index.

This approach efficiently checks each step until the sum exceeds \( n \), ensuring that we correctly identify the index whether \( n \) is a sum or part of the non-sum elements. The solution handles large values by leveraging mathematical properties of the sequence structure.
