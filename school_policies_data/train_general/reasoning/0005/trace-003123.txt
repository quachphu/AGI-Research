To solve this problem, we need to determine the optimal value of `t` such that adjusting the lengths of all sticks to be within the range `[t-1, t+1]` results in the minimum total cost. The cost of changing a stick's length from `a` to `b` is given by `|a - b|`.

### Approach
1. **Identify Range for `t`**: The optimal value of `t` will be around the maximum length of the sticks given. Thus, we consider `t` values from 1 to `max(a) + 1`, where `a` is the list of stick lengths.
2. **Calculate Cost for Each `t`**: For each potential `t`, compute the total cost of adjusting all sticks to be within the range `[t-1, t+1]`. The cost for each stick is determined by how much it needs to be adjusted to fit within this range.
3. **Track Minimum Cost**: Keep track of the minimum cost encountered and the corresponding `t` value.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
max_a = max(a)
min_cost = float('inf')
best_t = 0

for t in range(1, max_a + 2):
    current_cost = 0
    lower = t - 1
    upper = t + 1
    for num in a:
        if num < lower:
            current_cost += (lower - num)
        elif num > upper:
            current_cost += (num - upper)
    if current_cost < min_cost:
        min_cost = current_cost
        best_t = t

print(best_t, min_cost)
```

### Explanation
1. **Reading Input**: The input consists of the number of sticks and their respective lengths.
2. **Determine Range for `t`**: The maximum value in the list of stick lengths is found, and the range for `t` is set from 1 to `max(a) + 1`.
3. **Cost Calculation**: For each `t` in the determined range, calculate the total cost to adjust all sticks to be within the range `[t-1, t+1]`. If a stick's length is below `t-1`, the cost is the difference to `t-1`. If it's above `t+1`, the cost is the difference to `t+1`.
4. **Track Minimum Cost**: The minimum cost and corresponding `t` are updated whenever a lower cost is found.

This approach efficiently checks all possible values of `t` around the maximum stick length, ensuring the optimal solution is found with minimal computational complexity.
