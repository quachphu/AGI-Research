To solve this problem, we need to determine the minimum number of horseshoes Valera needs to buy so that he can wear four horseshoes of different colors to the party. 

### Approach
The key insight is that the number of horseshoes Valera needs to buy is determined by the number of duplicate colors he already has. Specifically, if Valera has `k` unique colors among his four horseshoes, he needs to buy `4 - k` more horseshoes to have four distinct colors. This is because each duplicate color must be replaced by a new unique color.

### Solution Code
```python
def main():
    shoes = list(map(int, input().split()))
    unique_colors = len(set(shoes))
    print(4 - unique_colors)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of four integers representing the colors of Valera's horseshoes.
2. **Finding Unique Colors**: Convert the list of colors into a set to automatically remove duplicates, then find the size of this set, which gives the number of unique colors.
3. **Calculating Required Horseshoes**: Subtract the number of unique colors from 4. The result is the number of additional horseshoes Valera needs to buy to ensure all four are different.

This approach efficiently computes the solution using set operations to count unique elements, resulting in a time complexity of O(1) due to the fixed input size of four elements.
