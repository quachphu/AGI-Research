To solve this problem, we need to determine the number of computers infected by a virus based on data packet transmissions. The virus spreads when an infected computer sends a packet to another computer. The challenge is to process these packets in chronological order to accurately track the spread of the virus.

### Approach
1. **Input Reading**: Read multiple datasets until encountering a line with two zeros.
2. **Sorting Packets**: For each dataset, sort the data packets by their transmission time in ascending order.
3. **Infection Tracking**: Use a set to keep track of infected computers. Start with the first infected computer (computer 1).
4. **Processing Packets**: For each packet in sorted order, check if the source computer is infected. If it is, mark the destination computer as infected.
5. **Result Calculation**: After processing all packets, the size of the infected set gives the number of infected computers.

### Solution Code
```python
import sys

def main():
    while True:
        line = sys.stdin.readline()
        if not line:
            break
        N, M = map(int, line.strip().split())
        if N == 0 and M == 0:
            break
        packets = []
        for _ in range(M):
            t, s, d = map(int, sys.stdin.readline().split())
            packets.append((t, s, d))
        packets.sort()
        infected = {1}
        for t, s, d in packets:
            if s in infected:
                infected.add(d)
        print(len(infected))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read line by line. Each dataset starts with the number of computers (N) and packets (M). If both N and M are zero, processing stops.
2. **Sorting Packets**: Packets are sorted by their transmission time to ensure they are processed in chronological order.
3. **Tracking Infections**: A set is used to efficiently track infected computers. Starting with computer 1, each packet is checked to see if its source is infected. If so, the destination is added to the set of infected computers.
4. **Output**: After processing all packets for a dataset, the size of the infected set is printed, representing the number of computers infected by the virus.

This approach ensures that we accurately track the spread of the virus in the order packets are transmitted, efficiently using set operations to manage the infected computers.
