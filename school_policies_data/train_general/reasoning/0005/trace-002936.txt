To solve this problem, we need to determine the minimum number of moves required to equalize the number of matches in each matchbox. Each move consists of transferring one match from one box to an adjacent box.

### Approach
1. **Understand the Problem**: The goal is to make all matchboxes have the same number of matches. Given that the total number of matches is divisible by the number of boxes, each box must end up with exactly the average number of matches.
2. **Calculate the Average**: Compute the average number of matches each box should have by dividing the total number of matches by the number of boxes.
3. **Compute Differences**: For each box, calculate the difference between the current number of matches and the average. This difference tells us how many matches need to be moved in or out of the box.
4. **Prefix Sums**: Use prefix sums of these differences to track the cumulative number of matches that need to be moved through each position. The sum of the absolute values of these prefix sums gives the total number of moves required.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    avg = sum(a) // n
    total_moves = 0
    prefix = 0
    for num in a:
        prefix += num - avg
        total_moves += abs(prefix)
    print(total_moves)

main()
```

### Explanation
1. **Reading Input**: The input is read as a single string split into tokens. The first token is the number of boxes, followed by the number of matches in each box.
2. **Calculate Average**: The average number of matches per box is computed by dividing the total number of matches by the number of boxes.
3. **Compute Differences**: For each box, the difference from the average is calculated. This difference indicates how many matches need to be moved in or out of the box.
4. **Prefix Sums and Moves Calculation**: By iterating through each box, we maintain a running total (prefix sum) of these differences. The absolute value of this running total at each step is added to the total number of moves, as it represents the number of matches that need to be moved through that position to achieve balance.

This approach efficiently computes the minimum number of moves using a linear scan and prefix sums, resulting in an O(n) time complexity, which is optimal for the given problem constraints.
