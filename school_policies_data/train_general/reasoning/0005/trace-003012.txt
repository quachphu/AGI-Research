To solve this problem, we need to determine the maximum number of regions that can be created by drawing `n` straight lines on a plane. The key insight is that each new line should intersect all previous lines to maximize the number of regions.

### Approach
The formula to compute the maximum number of regions formed by `n` lines is derived from the observation that each new line intersects all previous lines, creating new regions. The formula for the maximum number of regions is given by:
\[ \text{Regions} = \frac{n(n + 1)}{2} + 1 \]
This formula accounts for the cumulative effect of each line intersecting all previous lines, thereby creating the maximum number of new regions each time.

### Solution Code
```python
def main():
    import sys
    for line in sys.stdin:
        n = int(line.strip())
        print(n * (n + 1) // 2 + 1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads multiple lines from standard input until the end of the file (EOF) is reached.
2. **Processing Each Line**: Each line is converted to an integer `n`, which represents the number of lines.
3. **Computing Regions**: For each `n`, the formula \(\frac{n(n + 1)}{2} + 1\) is computed. This formula efficiently calculates the maximum number of regions by leveraging arithmetic operations.
4. **Output**: The result for each input `n` is printed immediately.

This approach ensures that we efficiently compute the result for each input value using a direct mathematical formula, making the solution both optimal and easy to understand.
