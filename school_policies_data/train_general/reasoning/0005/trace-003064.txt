To solve this problem, we need to determine the number of valid words of length \( N \) in an alien language with \( M \) distinct characters, where a valid word has no palindromic substrings of size greater than 1. The solution must be efficient given the constraints.

### Approach

1. **Understanding Constraints**:
   - A valid word must not contain any palindromic substrings of length 2 or more.
   - For \( N = 1 \), any single character is valid.
   - For \( N = 2 \), the two characters must be different.
   - For \( N \geq 3 \), each subsequent character must differ from both the previous character and the one before that to avoid any palindromic substrings.

2. **Pattern Identification**:
   - For \( N = 1 \): The number of valid words is \( M \).
   - For \( N = 2 \): The number of valid words is \( M \times (M - 1) \).
   - For \( N \geq 3 \): The number of valid words follows the pattern \( M \times (M - 1) \times (M - 2)^{N - 2} \). This is derived from ensuring each new character does not form a palindrome with the previous two characters.

3. **Modular Arithmetic**:
   - Given the large constraints, results must be computed modulo \( 10^9 + 7 \).
   - Efficient computation using modular exponentiation to handle large powers.

### Solution Code

```python
MOD = 10**9 + 7
import sys

def main():
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N = int(input[idx])
        M = int(input[idx + 1])
        idx += 2
        if N == 1:
            print(M % MOD)
        elif N == 2:
            res = (M % MOD) * ((M - 1) % MOD) % MOD
            print(res)
        else:
            part1 = (M % MOD) * ((M - 1) % MOD) % MOD
            exponent = N - 2
            base = (M - 2) % MOD
            part2 = pow(base, exponent, MOD)
            ans = (part1 * part2) % MOD
            print(ans)

if __name__ == "__main__":
    main()
```

- **Reading Input Efficiently**: The code reads all input at once for efficiency, especially given the large number of test cases.
- **Handling Different Cases**:
  - For \( N = 1 \), directly output \( M \mod 10^9 + 7 \).
  - For \( N = 2 \), compute \( M \times (M - 1) \mod 10^9 + 7 \).
  - For \( N \geq 3 \), compute the product using modular exponentiation to efficiently handle large exponents.
- **Modular Exponentiation**: Python's built-in `pow` function with three arguments efficiently computes \( (M - 2)^{N - 2} \mod 10^9 + 7 \).
