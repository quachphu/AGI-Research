To solve this problem, we need to determine how many bits change when we add 1 to a binary number stored in a memory cell with a specific bit ordering. The bits are stored such that the least significant bit (LSB) is first and the most significant bit (MSB) is last.

### Approach
1. **Understand the Input**: The input consists of an integer `n` (number of bits) and a string representing the initial state of the memory cell, where the first character is the LSB.
2. **Convert to Integer**: Convert the binary string to an integer, considering the LSB-first order.
3. **Compute New Value**: Increment the integer value by 1 and handle overflow by taking modulo `2^n`.
4. **Generate New Binary String**: Convert the new integer value back to a binary string in the same LSB-first order.
5. **Compare Bits**: Count the number of differing bits between the original and new binary strings.

### Solution Code
```python
n = int(input())
s = input().strip()

original_value = 0
for i in range(n):
    if s[i] == '1':
        original_value += 2 ** i

new_value = (original_value + 1) % (2 ** n)

new_str = []
for i in range(n):
    bit = (new_value >> i) & 1
    new_str.append('1' if bit else '0')

count = 0
for a, b in zip(s, new_str):
    if a != b:
        count += 1

print(count)
```

### Explanation
1. **Reading Input**: The code reads the number of bits `n` and the initial state of the memory cell as a string.
2. **Convert to Integer**: The initial binary string is converted to an integer by iterating over each bit and summing the corresponding powers of 2.
3. **Compute New Value**: The new value is calculated by adding 1 to the original integer and taking modulo `2^n` to handle overflow.
4. **Generate New Binary String**: The new integer is converted back to a binary string, ensuring each bit is placed in the correct position from LSB to MSB.
5. **Compare Bits**: The original and new binary strings are compared bit by bit to count the number of differing bits, which is then printed as the result.

This approach efficiently handles the conversion and comparison processes, ensuring accurate results even for edge cases like overflow where all bits flip.
