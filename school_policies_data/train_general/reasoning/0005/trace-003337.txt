To solve this problem, we need to determine the leader of a programming contest room based on the highest total points accumulated by each participant. The total points are calculated from successful and unsuccessful hacks, as well as points from solving five different problems.

### Approach
1. **Input Reading**: Read the number of participants and their respective details.
2. **Score Calculation**: For each participant, compute their total score by considering points from hacks (successful and unsuccessful) and the points from solving each problem.
3. **Determine Leader**: Track the highest score encountered and the corresponding participant's handle, ensuring we identify the unique leader as guaranteed by the problem constraints.

### Solution Code
```python
def main():
    n = int(input())
    max_total = -float('inf')
    leader = ''
    for _ in range(n):
        parts = input().split()
        handle = parts[0]
        plus = int(parts[1])
        minus = int(parts[2])
        problems = list(map(int, parts[3:8]))
        total = plus * 100 - minus * 50 + sum(problems)
        if total > max_total:
            max_total = total
            leader = handle
    print(leader)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The first input line gives the number of participants. Subsequent lines contain each participant's handle, hack counts, and problem points.
2. **Score Calculation**:
   - **Hack Points**: Each successful hack adds 100 points, while each unsuccessful hack subtracts 50 points.
   - **Problem Points**: Sum the points from each solved problem (values provided in input, 0 if not solved).
3. **Track Maximum**: For each participant, compute their total score and update the leader if this score exceeds the current maximum.

This approach efficiently processes each participant's data in a single pass, ensuring we determine the leader with optimal performance.
