To solve this problem, we need to determine the optimal strategy for Petya and Vasya when they play a game with red and blue cubes. Petya aims to maximize the number of neighboring cubes of the same color, while Vasya aims to maximize the number of neighboring cubes of different colors. Both players take turns, starting with Petya, and play optimally.

### Approach
1. **Game Analysis**: Petya and Vasya take turns placing cubes. Petya starts and wants to maximize same-color pairs, while Vasya wants to maximize different-color pairs.
2. **Optimal Play**: The optimal strategy involves both players making choices that maximize their points. Petya will try to place the same color as the previous cube, while Vasya will try to place a different color.
3. **Simulation**: We simulate the game starting with both possible initial moves (red or blue) and determine the maximum points Petya can achieve in each scenario. The result is the maximum points from these two scenarios.

### Solution Code
```python
n, m = map(int, input().split())

def compute_same_pairs(start_color, n_red, n_blue):
    # Check if starting with the given color is possible
    if (start_color == 'R' and n_red == 0) or (start_color == 'B' and n_blue == 0):
        return -float('inf')  # Invalid case
    
    same_pairs = 0
    current_color = start_color
    # Deduct the starting cube
    if start_color == 'R':
        r, b = n_red - 1, n_blue
    else:
        r, b = n_red, n_blue - 1
    
    prev_color = start_color
    turn = 1  # Start with Vasya's turn
    
    while r + b > 0:
        # Determine current player (turn is 1-based)
        if turn % 2 == 1:
            # Vasya's turn: choose different color if possible
            if prev_color == 'R':
                if b > 0:
                    chosen = 'B'
                    b -= 1
                else:
                    chosen = 'R'
                    r -= 1
            else:
                if r > 0:
                    chosen = 'R'
                    r -= 1
                else:
                    chosen = 'B'
                    b -= 1
        else:
            # Petya's turn: choose same color if possible
            if prev_color == 'R' and r > 0:
                chosen = 'R'
                r -= 1
            elif prev_color == 'B' and b > 0:
                chosen = 'B'
                b -= 1
            else:
                # Choose any available
                if r > 0:
                    chosen = 'R'
                    r -= 1
                else:
                    chosen = 'B'
                    b -= 1
        
        if chosen == prev_color:
            same_pairs += 1
        prev_color = chosen
        turn += 1
    
    return same_pairs

# Calculate possible scores for starting with red or blue
start_red = compute_same_pairs('R', n, m)
start_blue = compute_same_pairs('B', n, m)
max_same = max(start_red, start_blue)

total_pairs = n + m - 1
print(max_same, total_pairs - max_same)
```

2. **Initial Setup**: The function starts with the specified color and adjusts the remaining cube counts accordingly.
3. **Turn Simulation**: For each turn, the current player (Petya or Vasya) makes an optimal choice based on the previous cube's color. Vasya tries to switch colors to minimize same pairs, while Petya tries to continue the same color.
4. **Result Calculation**: The maximum points from starting with either red or blue are computed, and the result is printed along with Vasya's points derived from the total pairs minus Petya's points.

This approach efficiently simulates both possible starting moves and selects the optimal result, ensuring both players play optimally according to the problem constraints.
