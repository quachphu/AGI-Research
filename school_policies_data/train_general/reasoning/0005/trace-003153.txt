To solve this problem, we need to determine how Bob would write his message using words from both languages L1 and L2 such that the overall length of the message is minimized. If the lengths of the words in both languages are the same, Bob prefers using the word from L1.

### Approach
1. **Input Reading**: Read the number of words in the message (n) and the number of words in each language (m).
2. **Dictionary Construction**: Create a dictionary to map each word from L1 to its corresponding translation in L2.
3. **Message Processing**: For each word in the input message, determine whether to use the word from L1 or its translation in L2 based on their lengths. If the lengths are equal, use the word from L1.
4. **Output Construction**: Construct the output message using the determined words and print it.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().splitlines()
    idx = 0
    n, m = map(int, input[idx].split())
    idx += 1
    l1_to_l2 = {}
    for _ in range(m):
        a, b = input[idx].split()
        l1_to_l2[a] = b
        idx += 1
    message = input[idx].split()
    idx += 1
    result = []
    for word in message:
        translation = l1_to_l2[word]
        if len(translation) < len(word):
            result.append(translation)
        else:
            result.append(word)
    print(' '.join(result))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into lines for easier processing. The first line gives the values of n and m.
2. **Dictionary Construction**: The next m lines are read to build a dictionary mapping each L1 word to its L2 translation.
3. **Message Processing**: Each word in the message is checked against its L2 translation. The shorter word is chosen, with a preference for L1 if lengths are equal.
4. **Output**: The resulting words are joined into a single string and printed as the output message.

This approach ensures that the message is minimized in length efficiently, adhering to the constraints and preferences given in the problem statement.
