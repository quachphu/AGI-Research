To solve this problem, we need to efficiently handle two types of queries on an array of 0s and 1s: flipping an element and finding the k-th largest element. Given the constraints, a direct approach that sorts the array for each query would be too slow, so we use a more optimized method.

### Approach
1. **Maintain Count of 1s**: The key insight is that the k-th largest element in a sorted array of 0s and 1s is determined by the count of 1s. If there are `m` 1s, the first `m` elements in the sorted array are 1s, and the rest are 0s. Thus, the k-th largest element is 1 if `k <= m`, otherwise 0.
2. **Efficient Updates**: For each flip operation (type 1 query), update the count of 1s based on the current value of the element being flipped. This allows us to maintain the count in constant time.
3. **Direct Query Handling**: For each query to find the k-th largest element (type 2 query), simply check the count of 1s and determine the result in constant time.

### Solution Code
```python
import sys

def main():
    data = sys.stdin.read().split()
    ptr = 0
    n = int(data[ptr])
    ptr += 1
    q = int(data[ptr])
    ptr += 1
    a = list(map(int, data[ptr:ptr + n]))
    ptr += n
    ones_count = sum(a)
    for _ in range(q):
        t = int(data[ptr])
        ptr += 1
        val = int(data[ptr])
        ptr += 1
        if t == 1:
            x = val - 1
            if a[x] == 1:
                a[x] = 0
                ones_count -= 1
            else:
                a[x] = 1
                ones_count += 1
        else:
            k = val
            print(1 if ones_count >= k else 0)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once using `sys.stdin.read()` for efficiency, especially given the large possible input size.
2. **Tracking 1s Count**: The initial count of 1s is computed once using the sum of the array. This count is updated in constant time for each flip operation.
3. **Handling Queries**: Each flip operation adjusts the count of 1s and updates the array. For each query to find the k-th largest element, the result is determined by comparing `k` with the current count of 1s.

This approach ensures that each query is handled in constant time, making the solution efficient and capable of handling the upper constraint limits effectively.
