To solve this problem, we need to determine the patient who walked the longest total distance in a day for each given dataset. The solution involves reading input datasets, processing each to find the patient with the maximum combined walking distance, and outputting the result for each dataset.

### Approach
1. **Reading Input:** The input is read all at once and split into a list of integers for efficient processing.
2. **Processing Each Dataset:** For each dataset, we first read the number of patients. For each patient, we calculate the total walking distance by summing their two walking distances.
3. **Tracking Maximum Distance:** As we process each patient, we keep track of the maximum total distance encountered and the corresponding patient number.
4. **Output Results:** After processing all patients in a dataset, we output the patient number and their total walking distance. This process repeats until we encounter a dataset with zero patients, indicating the end of input.

### Solution Code
```python
import sys

def main():
    data = list(map(int, sys.stdin.read().split()))
    index = 0
    while index < len(data):
        n = data[index]
        if n == 0:
            break
        index += 1
        max_total = -1
        max_p = -1
        for _ in range(n):
            pi = data[index]
            d1 = data[index + 1]
            d2 = data[index + 2]
            total = d1 + d2
            if total > max_total:
                max_total = total
                max_p = pi
            index += 3
        print(f"{max_p} {max_total}")

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input Efficiently:** The input is read in one go and converted into a list of integers. This allows us to process the data sequentially without repeated I/O operations.
- **Sequential Processing:** Using an index pointer, we navigate through the list of integers. Each dataset starts with the number of patients, followed by their respective data.
- **Finding the Maximum:** For each patient, we compute the total walking distance and update the maximum distance and corresponding patient number whenever a higher total is found.
- **Handling Termination:** The loop terminates when encountering a zero, which marks the end of the input according to the problem constraints.

This approach ensures efficient processing of input data and correctly identifies the patient with the longest walking distance for each dataset, adhering to the problem requirements.
