To solve this problem, we need to determine if the fraction p/q in base b is a finite fraction. A fraction is finite in a given base if, after simplifying the fraction, the denominator's prime factors are all factors of the base. 

### Approach
1. **Simplify the Fraction**: For each query, simplify the fraction p/q by dividing both the numerator and the denominator by their greatest common divisor (GCD).
2. **Check Denominator Factors**: After simplification, if the denominator (d) is 1, the fraction is trivially finite. Otherwise, repeatedly divide the simplified denominator by the GCD of the denominator and the base until the GCD becomes 1. If the resulting denominator is 1, the fraction is finite; otherwise, it is infinite.

### Solution Code
```python
def main():
    import sys
    import math

    data = list(map(int, sys.stdin.read().split()))
    n = data[0]
    ptr = 1
    for _ in range(n):
        p = data[ptr]
        q = data[ptr + 1]
        b = data[ptr + 2]
        ptr += 3

        if p == 0:
            print("Finite")
            continue

        g = math.gcd(p, q)
        d = q // g

        if d == 1:
            print("Finite")
            continue

        current_d = d
        while True:
            g2 = math.gcd(current_d, b)
            if g2 == 1:
                break
            current_d //= g2
            if current_d == 1:
                break

        print("Finite" if current_d == 1 else "Infinite")

main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and split into a list of integers for efficient processing, especially given the constraints of up to 100,000 queries.
2. **Handling Zero Numerator**: If the numerator (p) is zero, the fraction is immediately finite as it represents zero.
3. **Simplifying the Fraction**: The fraction p/q is simplified by dividing both p and q by their GCD. The simplified denominator (d) is checked.
4. **Prime Factor Check**: The simplified denominator is repeatedly divided by the GCD of itself and the base (b) until no common factors remain. If the resulting denominator is 1, all prime factors were covered by the base, making the fraction finite. Otherwise, it is infinite.

This approach ensures that each query is processed efficiently, even for very large numbers, by leveraging mathematical properties of GCD and prime factorization.
