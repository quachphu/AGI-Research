To solve this problem, we need to determine if an immigrant should be allowed entry into the Kingdom of AtCoder based on the numbers written on their document. The condition for entry is that all even numbers in the document must be divisible by either 3 or 5. 

### Approach
1. **Input Reading**: Read the input values which include the number of integers and the integers themselves.
2. **Check Even Numbers**: For each number in the list, check if it is even.
3. **Divisibility Check**: For each even number, check if it is divisible by 3 or 5. If any even number fails this check, the result is immediately "DENIED".
4. **Result Determination**: If all even numbers pass the divisibility check, the result is "APPROVED".

### Solution Code
```python
def main():
    n = int(input())
    a_list = list(map(int, input().split()))
    for num in a_list:
        if num % 2 == 0:
            if num % 3 != 0 and num % 5 != 0:
                print("DENIED")
                return
    print("APPROVED")

main()
```

### Explanation
1. **Reading Input**: The first input line gives the number of integers, `n`. The second line contains the integers themselves.
2. **Iterating Through Numbers**: For each number in the list, we check if it is even using the modulus operator (`% 2 == 0`).
3. **Checking Divisibility**: For each even number, we check if it is divisible by 3 or 5. If an even number is not divisible by either, we print "DENIED" and exit immediately.
4. **Final Check**: If all even numbers pass the divisibility check, we print "APPROVED".

This approach ensures that we efficiently check each number and terminate early if any condition is violated, optimizing both time and resource usage.
