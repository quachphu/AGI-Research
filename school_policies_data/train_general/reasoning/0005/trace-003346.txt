To solve this problem, we need to determine the length of the longest increasing subsequence (LIS) from a given sequence of integers and then convert that length into its binary representation. 

### Approach
1. **Reading Input**: The input consists of two lines. The first line contains the number of elements in the sequence, and the second line contains the sequence itself.
2. **Finding LIS Length**: We use an efficient algorithm with a time complexity of O(n log n) to determine the length of the LIS. This algorithm maintains a list where each element represents the smallest possible tail value for all increasing subsequences of a given length encountered so far.
3. **Converting to Binary**: Once we have the length of the LIS, we convert it to a binary string and print it without the '0b' prefix.

### Solution Code
```python
import bisect
import sys

def main():
    t = int(sys.stdin.readline())
    nums = list(map(int, sys.stdin.readline().split()))
    tails = []
    for num in nums:
        idx = bisect.bisect_left(tails, num)
        if idx == len(tails):
            tails.append(num)
        else:
            tails[idx] = num
    length = len(tails)
    print(bin(length)[2:])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The first line is read to get the number of elements `t`. The second line is read and split into a list of integers.
2. **Finding LIS Length**: We iterate through each number in the sequence. For each number, we use binary search (via `bisect.bisect_left`) to find its position in the `tails` list. This list keeps track of the smallest possible tail values for increasing subsequences of various lengths. If the number is larger than all elements in `tails`, it is appended. Otherwise, it replaces the first element in `tails` that is greater than or equal to it. This ensures that `tails` always contains the optimal tail values for the longest possible subsequences.
3. **Binary Conversion**: The length of the `tails` list gives the length of the LIS. This length is converted to a binary string using Python's `bin` function, and the result is printed after removing the '0b' prefix.

This approach efficiently computes the LIS length and converts it to the required binary format, ensuring optimal performance even for the upper constraint of the input size.
