To solve this problem, we need to determine the maximum number of socks that were on the table at the same time while Andryusha was organizing his socks. The key insight is to track the number of socks on the table as each sock is processed and determine the maximum count during this process.

### Approach
1. **Track Socks on the Table**: Use a set to keep track of socks that are currently on the table. Each sock from a pair will be added to the set when first encountered and removed when its pair is encountered.
2. **Update Count**: Maintain a running count of socks on the table. Each time a sock is added to the table, increment the count. When a pair is found (i.e., the second sock of a pair is encountered), decrement the count as both socks are moved to the wardrobe.
3. **Determine Maximum**: Keep track of the maximum count of socks on the table during the entire process.

### Solution Code
```python
n = int(input())
socks = list(map(int, input().split()))
current = 0
max_current = 0
pair_present = set()

for x in socks:
    if x in pair_present:
        pair_present.remove(x)
        current -= 1
    else:
        pair_present.add(x)
        current += 1
    if current > max_current:
        max_current = current

print(max_current)
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` (number of pairs) and a list of `2n` integers representing the order in which socks are taken out.
2. **Set for Tracking**: A set `pair_present` is used to track socks that are currently on the table.
3. **Count Updates**: For each sock, check if it is already in the set. If it is, remove it and decrement the count (indicating the pair is moved to the wardrobe). If it is not, add it to the set and increment the count.
4. **Track Maximum**: Throughout the iteration, update the maximum count of socks on the table whenever the current count exceeds the previously recorded maximum.

This approach efficiently tracks the number of socks on the table using a set and ensures we find the maximum count in linear time, making it suitable for large input sizes up to the given constraints.
