To solve this problem, we need to determine the number of integers \( x \) such that \( 0 \leq x < m \) and \( \gcd(a, m) = \gcd(a + x, m) \). The solution involves leveraging the properties of the greatest common divisor (GCD) and Euler's Totient function (φ).

### Approach
1. **Understanding the GCD Condition**: Let \( d = \gcd(a, m) \). For \( \gcd(a + x, m) \) to be equal to \( d \), \( a + x \) must be a multiple of \( d \). This reduces the problem to finding integers \( x \) such that \( x \) is a multiple of \( d \) and the resulting value when divided by \( d \) is coprime with \( m/d \).

2. **Reduction Using Euler's Totient Function**: After dividing \( a \) and \( m \) by their GCD \( d \), we get \( a' = a/d \) and \( m' = m/d \). The problem then reduces to finding the number of integers \( k \) such that \( 0 \leq k < m' \) and \( \gcd(a' + k, m') = 1 \). This count is given by Euler's Totient function φ(m'), which counts the integers up to \( m' \) that are coprime with \( m' \).

### Solution Code
```python
import math
import sys

def factor(n):
    factors = {}
    while n % 2 == 0:
        factors[2] = factors.get(2, 0) + 1
        n = n // 2
    i = 3
    while i * i <= n:
        while n % i == 0:
            factors[i] = factors.get(i, 0) + 1
            n = n // i
        i += 2
    if n > 1:
        factors[n] = 1
    return factors

def compute_phi(n, factors):
    phi = n
    for p in factors:
        phi = phi // p * (p - 1)
    return phi

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        a = int(input[idx])
        m = int(input[idx + 1])
        idx += 2
        d = math.gcd(a, m)
        m_prime = m // d
        if m_prime == 1:
            print(1)
            continue
        factors = factor(m_prime)
        phi = compute_phi(m_prime, factors)
        print(phi)

if __name__ == "__main__":
    main()
```

1. **Factorization**: The `factor` function decomposes a number into its prime factors using trial division up to the square root of the number.
2. **Euler's Totient Function**: The `compute_phi` function calculates φ(n) using the prime factorization of \( n \). For each prime factor \( p \), φ(n) is adjusted by multiplying \( n \) by \( (p-1)/p \).
3. **Main Logic**: For each test case, we compute the GCD \( d \) of \( a \) and \( m \), then determine \( m' = m/d \). The result is φ(m'), which is computed using the prime factors of \( m' \).

This approach efficiently handles the constraints, ensuring that even for large values up to \( 10^{10} \), the solution remains feasible using trial division and properties of the totient function.
