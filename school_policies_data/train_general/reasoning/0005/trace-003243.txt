To solve this problem, we need to determine the priority factors between a user and their friends based on social media interactions. The interactions are categorized into three types, each contributing different points to the priority factor. The goal is to output the friends sorted by their priority factors with the user in descending order, and lexicographically if there are ties.

### Approach
1. **Parse Input**: Read the user's name and the number of interactions.
2. **Track Interactions**: For each interaction, determine the two people involved and the points contributed. Update their mutual priority factor.
3. **Collect Friends**: Gather all distinct names from the interactions, excluding the user.
4. **Calculate Priorities**: For each friend, compute their priority factor with the user.
5. **Sort Friends**: Sort the friends first by descending priority factor and then lexicographically if priorities are the same.
6. **Output Result**: Print the sorted list of friends.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    user = sys.stdin.readline().strip()
    n = int(sys.stdin.readline())
    all_names = set()
    priority = defaultdict(lambda: defaultdict(int))
    
    for _ in range(n):
        line = sys.stdin.readline().strip()
        tokens = line.split()
        X, Y, points = None, None, 0
        
        if tokens[1] == 'posted':
            X = tokens[0]
            Y_part = tokens[3]
            Y = Y_part.split("'")[0]
            points = 15
        elif tokens[1] == 'commented':
            X = tokens[0]
            Y_part = tokens[3]
            Y = Y_part.split("'")[0]
            points = 10
        else:  # likes
            X = tokens[0]
            Y_part = tokens[2]
            Y = Y_part.split("'")[0]
            points = 5
        
        all_names.add(X)
        all_names.add(Y)
        priority[X][Y] += points
        priority[Y][X] += points
    
    friends = [name for name in all_names if name != user]
    friends.sort(key=lambda x: (-priority[user].get(x, 0), x))
    
    for name in friends:
        print(name)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The user's name and the number of interactions are read first. Each interaction line is then processed to extract the involved users and the points contributed.
2. **Interaction Parsing**: Depending on the type of interaction (posted, commented, likes), the users involved and their respective points are determined. The points are added to both users' mutual priority factor.
3. **Collecting Friends**: All unique names from the interactions are collected, excluding the user.
4. **Sorting**: Friends are sorted based on their priority factor with the user in descending order. If two friends have the same priority, they are sorted lexicographically.
5. **Output**: The sorted list of friends is printed, ensuring the correct order based on the priority factors and lexicographical sorting when necessary.

This approach efficiently processes each interaction, tracks mutual priorities, and sorts the results as required, ensuring optimal performance and correctness.
