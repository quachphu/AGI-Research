   - The sum of even and odd numbers in the submatrix can be broken down into two parts: rows where i <= C and rows where i > C.

3. **Efficient Calculation**:
   - For rows where i <= min(R, C), directly sum the even and odd numbers.
   - For rows where i > C, each element contributes C to the sum, depending on whether i is even or odd.

4. **Mathematical Formulation**:
   - Sum of even numbers up to a limit m is calculated using arithmetic series.

import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        R = int(input[idx])
        C = int(input[idx + 1])
        idx += 2
        
        k = min(R, C)
        even_part1 = (k // 2) * ((k // 2) + 1)
        odd_part1 = ((k + 1) // 2) ** 2
        
        if R > C:
            count_even = (R // 2) - (C // 2)
            sum_even_part2 = count_even * C
            even_total = even_part1 + sum_even_part2
            
            count_odd = ((R + 1) // 2) - ((C + 1) // 2)
            sum_odd_part2 = count_odd * C
            odd_total = odd_part1 + sum_odd_part2
        else:
            even_total = even_part1
            odd_total = odd_part1
        
        print(f"{even_total} {odd_total}")

if __name__ == "__main__":
    main()
