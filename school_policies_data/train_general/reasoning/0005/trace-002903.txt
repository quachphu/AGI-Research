To solve this problem, we need to determine the number of elements in a permutation that are the second smallest among their immediate neighbors. Specifically, we check each element (except the first and last) to see if it meets the condition of being the second smallest when compared to its previous and next elements.

### Approach
1. **Input Reading**: Read the integer `n` (length of the permutation) and the permutation list `p`.
2. **Iteration**: Loop through each element from the second to the second-to-last element (indices 1 to n-2 in 0-based indexing).
3. **Triplet Comparison**: For each element, form a triplet with its immediate neighbors, sort the triplet, and check if the current element is the middle element (second smallest) in the sorted triplet.
4. **Count Valid Elements**: Maintain a counter to keep track of how many elements meet the condition.

### Solution Code
```python
n = int(input())
p = list(map(int, input().split()))
count = 0
for i in range(1, n-1):
    triplet = [p[i-1], p[i], p[i+1]]
    sorted_triplet = sorted(triplet)
    if sorted_triplet[1] == p[i]:
        count += 1
print(count)
```

### Explanation
1. **Reading Input**: The first line of input is the integer `n`, which is the length of the permutation. The second line contains the permutation values.
2. **Loop Through Elements**: We loop through each element from index 1 to n-2 (inclusive) to avoid the first and last elements.
3. **Form Triplet and Check Condition**: For each element in the loop, we form a triplet with its immediate neighbors, sort the triplet, and check if the current element is the second smallest in the sorted triplet. If it is, we increment our count.
4. **Output Result**: Finally, we print the count of elements that meet the condition.

This approach efficiently checks each relevant element in linear time, making it suitable given the constraints (n up to 20). The sorting of triplets is a constant-time operation, ensuring the solution's efficiency.
