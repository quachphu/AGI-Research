To solve this problem, we need to determine the number of ways to select bags of biscuits such that the total number of biscuits is congruent to a given value \( P \) modulo 2. The solution involves analyzing the parity (even or odd) of the number of biscuits in each bag.

### Approach
1. **Identify Parity**: The key observation is that the sum of biscuits' parity (even or odd) depends solely on the number of bags with an odd number of biscuits. Each even number contributes 0 to the sum's parity, while each odd number contributes 1.
2. **Count Odd and Even Bags**: Separate the bags into those containing odd numbers of biscuits (odd bags) and those containing even numbers (even bags).
3. **Subset Analysis**:
   - If there are no odd bags, the sum's parity is always even. Thus, if \( P \) is 0, all subsets are valid; otherwise, no subsets are valid.
   - If there are odd bags, the number of valid subsets is determined by the parity requirement. For any non-zero number of odd bags, the number of valid subsets where the sum's parity matches \( P \) is \( 2^{N-1} \), as each odd bag can be included or excluded in such a way that the parity condition is met.

### Solution Code
```python
n, p = map(int, input().split())
a = list(map(int, input().split()))
odd_count = sum(1 for x in a if x % 2 == 1)

if odd_count == 0:
    print(2 ** n if p == 0 else 0)
else:
    print(2 ** (n - 1))
```

### Explanation
1. **Reading Input**: The input consists of the number of bags \( N \), the desired parity \( P \), and the list of biscuits in each bag.
2. **Counting Odd Bags**: We count how many bags contain an odd number of biscuits.
3. **Decision Based on Odd Count**:
   - If there are no odd bags, the sum's parity is always even. If \( P \) is 0, all possible subsets (which is \( 2^N \)) are valid. If \( P \) is 1, no subsets are valid.
   - If there are odd bags, the number of valid subsets is \( 2^{N-1} \). This is because each combination of odd bags that meets the parity requirement can be paired with any subset of even bags, leading to \( 2^{N-1} \) valid subsets for each parity condition.

This approach efficiently computes the result using basic arithmetic operations and parity checks, ensuring it handles the constraints effectively.
