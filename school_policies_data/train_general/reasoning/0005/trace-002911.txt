To solve this problem, we need to determine the exit point of Taro's Nth walk in a grid where each intersection's direction (east or south) flips every time it is visited. The challenge is to efficiently simulate each walk and track the grid state changes.

### Approach
The approach involves simulating each walk step-by-step. Each walk starts from the top-left corner (1, 1) and proceeds according to the current direction of each intersection. After each step, the direction of the current intersection is flipped. The walk continues until it exits the grid either to the east or south. The grid state is updated after each walk to reflect the flipped directions.

### Solution Code
```python
import sys

def main():
    while True:
        line = sys.stdin.readline()
        if not line:
            break
        H, W, N = map(int, line.strip().split())
        if H == 0 and W == 0 and N == 0:
            break
        grid = []
        for _ in range(H):
            grid.append(list(map(int, sys.stdin.readline().strip().split())))
        
        current_i = 1
        current_j = 1
        exit_i, exit_j = 0, 0

        for _ in range(N):
            # Simulate one walk
            path = []
            i, j = 1, 1
            while True:
                if i > H or j > W:
                    exit_i, exit_j = i, j
                    break
                # Record the cell in the path
                path.append((i-1, j-1))  # 0-based index
                original = grid[i-1][j-1]
                # Move according to original direction
                if original == 1:
                    # East
                    j += 1
                else:
                    # South
                    i += 1
            # Flip all cells in the path
            for (x, y) in path:
                grid[x][y] ^= 1
        print(exit_i, exit_j)

if __name__ == "__main__":
    main()
```
