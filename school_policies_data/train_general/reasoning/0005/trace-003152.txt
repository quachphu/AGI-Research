To solve this problem, we need to determine if the frequency of the most frequent character in a given string is even or odd for multiple test cases. 

### Approach
1. **Input Handling**: Read the number of test cases. For each test case, read the string length (which can be ignored as we directly process the string) and the string itself.
2. **Frequency Counting**: Use a Counter from the collections module to efficiently count the frequency of each character in the string.
3. **Determine Maximum Frequency**: Find the maximum frequency among all characters using the Counter.
4. **Check Even/Odd**: Check if the maximum frequency is even or odd and print the corresponding result ("Yes" for even, "No" for odd).

### Solution Code
```python
import sys
from collections import Counter

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        s = sys.stdin.readline().strip()
        cnt = Counter(s)
        max_freq = max(cnt.values()) if cnt else 0
        print("Yes" if max_freq % 2 == 0 else "No")

if __name__ == "__main__":
    main()
```

### Explanation
- **Input Handling**: We read the input using `sys.stdin.readline()` for efficiency, especially given the large possible input size.
- **Frequency Counting**: The `Counter` from the `collections` module efficiently counts character frequencies in O(n) time where n is the length of the string.
- **Max Frequency Check**: The maximum frequency is found using the `max` function on the Counter values, which is efficient given the limited number of unique characters (lowercase letters only).
- **Even/Odd Check**: The result is determined by checking if the maximum frequency modulo 2 is zero, which gives us the answer in constant time.

This approach ensures that we efficiently handle up to the maximum constraints, providing a solution that is both time and space efficient.
