To solve this problem, we need to determine the length of the longest common subsequence (LCS) between two given sequences for multiple datasets. The LCS is the longest sequence that appears in the same relative order (but not necessarily consecutively) in both input sequences.

### Approach
The approach to solve this problem efficiently involves using dynamic programming (DP) with space optimization. The key idea is to use a 1D array to store intermediate results, reducing the space complexity from O(n*m) to O(n), where n is the length of the longer sequence. Here's the detailed approach:

1. **Dynamic Programming Table**: We maintain a 1D array to store the length of the LCS up to the current elements of the sequences being considered.
2. **Iterate Through Sequences**: For each character in the first sequence, update the DP array by comparing it with each character in the second sequence.
3. **Space Optimization**: By using two 1D arrays (previous and current), we can efficiently update the values without needing a full 2D table, thus saving space.

### Solution Code
```python
import sys

def lcs_length(X, Y):
    m = len(X)
    n = len(Y)
    # Swap to minimize the space usage if X is longer than Y
    if m > n:
        X, Y = Y, X
        m, n = n, m
    prev = [0] * (n + 1)
    for x in X:
        curr = [0] * (n + 1)
        for j in range(1, n + 1):
            if x == Y[j - 1]:
                curr[j] = prev[j - 1] + 1
            else:
                curr[j] = max(prev[j], curr[j - 1])
        prev = curr
    return prev[n]

q = int(sys.stdin.readline())
for _ in range(q):
    X = sys.stdin.readline().strip()
    Y = sys.stdin.readline().strip()
    print(lcs_length(X, Y))
```

3. **Updating the DP Array**: For each character in the first sequence, we update a temporary array (`curr`) by comparing it with each character in the second sequence. If characters match, we increment the value from the previous diagonal element; otherwise, we take the maximum value from the previous element in the same row or the current element in the previous column.
4. **Space Optimization**: By maintaining only two 1D arrays (`prev` and `curr`), we reduce the space complexity, making the solution efficient even for large input sizes.
