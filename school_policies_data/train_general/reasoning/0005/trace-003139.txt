To solve this problem, we need to generate a binary number where each digit is the result of an XOR operation on the corresponding digits of two input binary numbers. The XOR operation results in '1' if the digits differ and '0' if they are the same.

### Approach
1. **Read Input:** Read two binary numbers from standard input.
2. **Process Each Digit:** For each corresponding pair of digits from the two input numbers, determine if they are different. If they are different, append '1' to the result; otherwise, append '0'.
3. **Output Result:** Combine the results of each digit comparison into a single string and print it.

### Solution Code
```python
def main():
    s1 = input().strip()
    s2 = input().strip()
    result = []
    for c1, c2 in zip(s1, s2):
        result.append('1' if c1 != c2 else '0')
    print(''.join(result))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The function reads two lines of input, each representing a binary number.
2. **Digit Comparison:** Using a loop, each pair of corresponding digits from the two input numbers is compared. The loop uses the `zip` function to iterate over pairs of characters from the two input strings simultaneously.
3. **Result Construction:** For each pair of digits, if they differ, '1' is added to the result list; otherwise, '0' is added.
4. **Output:** The result list is joined into a single string and printed, ensuring that leading zeros are preserved as required.

This approach efficiently processes each digit pair in linear time, making it suitable for the given constraints where the maximum length of the input numbers is 100.
