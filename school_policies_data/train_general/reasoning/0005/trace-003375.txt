To solve this problem, we need to determine the maximum score Alice can achieve when playing a game with Bob where they alternately remove consecutive equal characters from a binary string. Alice starts first, and both players aim to maximize their scores, which are based on the number of '1's they remove.

### Approach
1. **Parse the Input String into Runs**: Convert the binary string into a list of runs, where each run is a tuple of a character and its consecutive count. For example, the string "01111001" becomes [('0', 1), ('1', 4), ('0', 2), ('1', 1)].

2. **Dynamic Programming with Memoization**: Use a recursive function with memoization to explore all possible moves and their outcomes. The state of the game is represented by the current runs and whose turn it is (Alice or Bob).

3. **State Transitions**: For each possible move (deleting a consecutive block of characters from a run), compute the new state and recursively determine the optimal score from that state. Merge adjacent runs if they become contiguous after a deletion.

4. **Optimal Play**: Alice maximizes her score while Bob minimizes Alice's score (since Bob aims to maximize his own). The recursive function returns the best possible scores for Alice and Bob from any given state.
