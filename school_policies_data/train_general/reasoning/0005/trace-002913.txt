To solve this problem, we need to determine the minimal number of 100-yen, 500-yen, and 1000-yen coins required to give change for a CD purchase at KMC's sale. The goal is to minimize the number of coins used, given that the price and the amount paid are both multiples of 100.

### Approach
1. **Input Handling**: Read multiple test cases until encountering "0 0".
2. **Calculate Change**: For each test case, compute the change required by subtracting the price from the amount paid, then convert this change into units of 100 yen.
3. **Coin Minimization Strategy**: Use a greedy algorithm to minimize the number of coins:
   - Use as many 1000-yen coins (10 units in 100-yen terms) as possible.
   - Use remaining value for 500-yen coins (5 units in 100-yen terms).
   - Use the leftover value for 100-yen coins (1 unit in 100-yen terms).

### Solution Code
```python
import sys

def calculate_change():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        A, B = map(int, line.split())
        if A == 0 and B == 0:
            break
        C = (B - A) // 100
        if C == 0:
            print(0, 0, 0)
            continue
        z = C // 10
        remaining = C % 10
        y = remaining // 5
        x = remaining % 5
        print(x, y, z)

if __name__ == "__main__":
    calculate_change()
```

### Explanation
1. **Reading Input**: The code reads lines from standard input until it encounters "0 0".
2. **Change Calculation**: For each test case, the difference between the amount paid and the price is divided by 100 to convert it into units of 100 yen.
3. **Greedy Coin Selection**: 
   - **1000-yen coins**: The maximum number of 1000-yen coins is determined by integer division of the change by 10.
   - **500-yen coins**: The remaining value after using 1000-yen coins is divided by 5 to get the number of 500-yen coins.
   - **100-yen coins**: The leftover value after using both 1000-yen and 500-yen coins gives the number of 100-yen coins.
   
This approach ensures that the number of coins is minimized by always using the highest denomination possible first, followed by lower denominations. This method guarantees the optimal solution for the given problem constraints.
