### Approach
1. **Understand the Polynomial Structure**: The polynomial is given by its coefficients, and we need to check each coefficient to see if changing it can make the polynomial evaluate to zero at x=2.
2. **Compute the Suffix Sum Array**: This helps in efficiently calculating the sum of the polynomial coefficients' contributions when evaluated at x=2.
3. **Check Divisibility by Powers of 2**: For each coefficient, determine if the polynomial's value at x=2 (denoted as S) is divisible by 2^i, where i is the coefficient's index.
4. **Valid Coefficient Change**: For each valid division, compute the new coefficient value and check if it meets the constraints (absolute value ≤ k and non-zero for the leading coefficient).

def count_trailing_zeros(s):
    if s == 0:
        return 0
    s_abs = abs(s)
    cnt = 0
    while (s_abs & 1) == 0:
        cnt += 1
        s_abs >>= 1
    return cnt

def main():

    input = sys.stdin.read().split()
    n = int(input[0])

    part2 = [0] * (n + 2)
