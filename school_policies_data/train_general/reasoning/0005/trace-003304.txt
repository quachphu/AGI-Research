To solve this problem, we need to determine the minimum time required to make a given number of takoyaki pieces using a machine that can produce a limited number of pieces per batch. Each batch takes a fixed amount of time regardless of the number of pieces produced in that batch.

### Approach
1. **Understanding the Problem**: The machine can produce at most X pieces of takoyaki in one batch, and each batch takes T minutes. We need to compute the total time required to produce exactly N pieces of takoyaki.
2. **Batches Calculation**: The number of batches required is determined by dividing the total number of pieces (N) by the machine's capacity (X). Since we can't have a fraction of a batch, we use ceiling division to ensure we round up to the next whole number if there's any remainder.
3. **Ceiling Division**: Instead of using floating-point division and then applying the ceiling function, we can achieve ceiling division using integer arithmetic with the formula `(N + X - 1) // X`. This formula effectively rounds up the division result without converting to a float.
4. **Total Time Calculation**: Once we have the number of batches, the total time is simply the product of the number of batches and the time per batch (T).

### Solution Code
```python
def main():
    import sys
    n, x, t = map(int, sys.stdin.readline().split())
    batches = (n + x - 1) // x
    print(batches * t)

main()
```

### Explanation
1. **Reading Input**: The input values for N (number of pieces), X (machine capacity), and T (time per batch) are read from standard input.
2. **Calculating Batches**: Using the formula `(N + X - 1) // X`, we compute the number of batches needed. This formula ensures that any remainder from the division of N by X results in an additional batch.
3. **Computing Total Time**: Multiply the number of batches by the time per batch (T) to get the total time required.
4. **Output the Result**: The total time is printed as the result.

This approach efficiently computes the minimum time required using integer arithmetic, ensuring accuracy and avoiding potential issues with floating-point precision. The solution handles all edge cases within the problem constraints effectively.
