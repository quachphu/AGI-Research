To solve this problem, we need to reconstruct a full binary tree with given leaves using an interactive approach where we can query the judge to determine the deepest common ancestor (LCA) of three leaves. The solution involves systematically querying triples of leaves to determine their LCAs and using this information to build the tree structure from the leaves up.

### Approach
1. **Initialization**: Start with the list of leaves (1 to n).
2. **Triple Selection**: Repeatedly select three leaves and query the judge to determine which pair has the deepest LCA.
3. **Verification**: Verify the selected pair by checking against other leaves to ensure they are siblings (nodes with the same parent).
4. **Merging Nodes**: Once a valid pair of siblings is confirmed, merge them into a parent node and update the current list of nodes.
5. **Termination**: Continue the process until all nodes are merged into a single root node.
6. **Output**: Print the parent array representing the tree structure.
