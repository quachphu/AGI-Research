To solve this problem, we need to determine two things from a given string: the length of the longest word outside any parentheses and the number of words inside all parentheses. The string consists of letters, underscores, and parentheses, with each opening parenthesis having a matching closing parenthesis and no nested parentheses.

### Approach
1. **Parse the String**: Separate the string into segments that are inside parentheses and those that are outside. This is done by iterating through the string and toggling a flag when encountering parentheses.
2. **Split Segments into Words**: For each segment (both inside and outside parentheses), split the segment into words using underscores as delimiters. Words are sequences of consecutive letters.
3. **Calculate Results**: Determine the longest word from the outside segments and count the total number of words from the inside segments.

### Solution Code
```python
def main():
    import sys
    n = int(sys.stdin.readline())
    s = sys.stdin.readline().strip()
    
    current_inside = False
    outside_parts = []
    inside_parts = []
    current_part = []
    
    for c in s:
        if c == '(':
            if not current_inside:
                if current_part:
                    outside_parts.append(''.join(current_part))
                    current_part = []
                current_inside = True
        elif c == ')':
            if current_inside:
                if current_part:
                    inside_parts.append(''.join(current_part))
                    current_part = []
                current_inside = False
        else:
            current_part.append(c)
    
    if current_part:
        if current_inside:
            inside_parts.append(''.join(current_part))
        else:
            outside_parts.append(''.join(current_part))
    
    def split_words(part):
        words = []
        current = []
        for char in part:
            if char == '_':
                if current:
                    words.append(''.join(current))
                    current = []
            else:
                current.append(char)
        if current:
            words.append(''.join(current))
        return words
    
    outside_words = []
    for part in outside_parts:
        outside_words.extend(split_words(part))
    
    max_outside = max(len(word) for word in outside_words) if outside_words else 0
    
    inside_words = []
    for part in inside_parts:
        inside_words.extend(split_words(part))
    
    count_inside = len(inside_words)
    
    print(f"{max_outside} {count_inside}")

main()
```

### Explanation
1. **Parsing the String**: The string is parsed into segments inside and outside parentheses. This is done by iterating through each character and toggling a flag when parentheses are encountered. Characters are collected into the current segment until a parenthesis is found, at which point the current segment is stored in the appropriate list (inside or outside parts).
2. **Splitting into Words**: Each segment is split into words by using underscores as delimiters. Words are sequences of letters, and any non-underscore character is part of the current word. This is done for both inside and outside segments.
3. **Calculating Results**: The longest word length from outside segments is found by checking the maximum length of all outside words. The number of words inside parentheses is simply the count of all words found in the inside segments.

This approach efficiently processes the string in linear time, ensuring that each character is handled once, making the solution both optimal and easy to understand.
