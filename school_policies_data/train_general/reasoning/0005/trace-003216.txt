### Approach
1. **Input Parsing**: Read the input datasets, each followed by a line containing a single '.'.
2. **Track Array Declarations**: For each program, maintain a dictionary to track declared arrays, their sizes, and which indices have been initialized.
3. **Evaluate Expressions**: Recursively evaluate expressions used in array indices and assignments. Check for invalid indices and uninitialized elements during evaluation.
4. **Check Assignments**: For each assignment line, evaluate both the left-hand side (LHS) and right-hand side (RHS) expressions. Check for errors in these evaluations and report the line number of the first error encountered.

import sys

def evaluate_expression(expr, arrays):
    expr = expr.strip()
    if not expr:
        return (0, "error")
    if expr.isdigit():
        return (int(expr), None)
    if '[' not in expr or not expr.endswith(']'):
        return (0, "error")
    bracket_pos = expr.find('[')
    array_name = expr[:bracket_pos]
    index_expr = expr[bracket_pos+1:-1].strip()
    index_value, error = evaluate_expression(index_expr, arrays)
    if error:
        return (0, error)
    if array_name not in arrays:
        return (0, "error")
    array_info = arrays[array_name]
    if index_value < 0 or index_value >= array_info['size']:
        return (0, "invalid index")
    if index_value not in array_info['initialized']:
        return (0, "uninitialized")
    return (array_info['initialized'][index_value], None)
