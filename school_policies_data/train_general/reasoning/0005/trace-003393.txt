To solve this problem, we need to determine the minimum number of seconds Luba needs to close all tabs outside the segment [l, r] while starting from a given position. The solution involves moving the cursor to specific positions and closing tabs either to the left or right of the cursor efficiently.

### Approach
1. **Initial Check**: If the entire range of tabs is already within [l, r], no operations are needed, so the answer is 0.
2. **Determine Needed Closures**: Check if tabs need to be closed to the left of `l` (left closure) and/or to the right of `r` (right closure).
3. **Calculate Steps**:
   - **Both Closures Needed**: Compute the minimum steps required by considering both possible orders of closing (left first then right, or right first then left).
   - **Single Closure Needed**: Directly compute the steps needed to move to the required position and close the respective side.

### Solution Code
```python
n, pos, l, r = map(int, input().split())

if l == 1 and r == n:
    print(0)
else:
    left_needed = l > 1
    right_needed = r < n
    if left_needed and right_needed:
        steps_left = abs(pos - l) + (r - l) + 2
        steps_right = abs(pos - r) + (r - l) + 2
        total = min(steps_left, steps_right)
    elif left_needed:
        total = abs(pos - l) + 1
    elif right_needed:
        total = abs(pos - r) + 1
    else:
        total = 0  # This case is unreachable due to initial check
    print(total)
```

### Explanation
1. **Initial Check**: If `l` is 1 and `r` is `n`, all tabs are already within the required range, so the result is 0.
2. **Closures Needed**: Determine if left closure (if `l > 1`) or right closure (if `r < n`) is needed.
3. **Calculate Steps for Both Closures**:
   - **Left First**: Move to `l`, close left tabs, move to `r`, and close right tabs.
   - **Right First**: Move to `r`, close right tabs, move to `l`, and close left tabs.
   - The minimum steps from both orders are considered.
4. **Single Closure**: Directly compute steps to move to `l` or `r` and perform the respective closure.

This approach ensures that we efficiently determine the minimum steps required by evaluating all necessary movements and closures in an optimal order.
