To solve this problem, we need to find the shortest path in a weighted undirected graph from vertex 1 to vertex n using Dijkstra's algorithm. If there is no path, we should return -1. Otherwise, we should return the shortest path.

### Approach
1. **Graph Representation**: Use an adjacency list to represent the graph. Each node will have a list of tuples representing its neighbors and the corresponding edge weights.
2. **Dijkstra's Algorithm**: Implement Dijkstra's algorithm using a priority queue (min-heap) to efficiently find the shortest path. This algorithm works by continuously expanding the shortest known path from the start node until the destination node is reached.
3. **Path Reconstruction**: Maintain a previous node array to keep track of the path. Once the shortest path is found, backtrack from the destination node to the start node using this array to reconstruct the path.

### Solution Code
```python
import sys
import heapq

def main():
    n, m = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        a, b, w = map(int, sys.stdin.readline().split())
        adj[a].append((b, w))
        adj[b].append((a, w))
    
    inf = float('inf')
    distance = [inf] * (n + 1)
    distance[1] = 0
    prev = [None] * (n + 1)
    
    heap = []
    heapq.heappush(heap, (0, 1))
    
    while heap:
        current_dist, u = heapq.heappop(heap)
        if u == n:
            break
        if current_dist > distance[u]:
            continue
        for v, w in adj[u]:
            if distance[v] > current_dist + w:
                distance[v] = current_dist + w
                prev[v] = u
                heapq.heappush(heap, (distance[v], v))
    
    if distance[n] == inf:
        print(-1)
    else:
        path = []
        current = n
        while current is not None:
            path.append(current)
            current = prev[current]
        path.reverse()
        print(' '.join(map(str, path)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Graph Representation**: The graph is represented using an adjacency list where each node points to a list of tuples. Each tuple contains a neighboring node and the weight of the edge connecting them.
2. **Dijkstra's Algorithm**: 
   - Initialize the distance to all nodes as infinity except the starting node (node 1), which is set to 0.
   - Use a priority queue to process nodes in order of increasing distance from the start. For each node, update the distances to its neighbors if a shorter path is found.
3. **Path Reconstruction**: After determining the shortest path distances, backtrack from the destination node (node n) to the start node using the previous node array. This path is then reversed to provide the correct order from start to destination.

This approach ensures that we efficiently find the shortest path using Dijkstra's algorithm with a time complexity of O((V + E) log V), where V is the number of vertices and E is the number of edges. The space complexity is O(V + E) for storing the graph and auxiliary data structures.
