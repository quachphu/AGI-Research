To solve this problem, we need to determine the maximum number of happiness points Takahashi can earn by exchanging his yen into 500-yen and 5-yen coins. The key is to prioritize the coins that yield the highest happiness points per yen.

### Approach
1. **Understanding Happiness Points**: Each 500-yen coin gives 1000 happiness points, and each 5-yen coin gives 5 happiness points. Therefore, we should maximize the number of 500-yen coins first, as they offer a higher happiness point yield per yen.
2. **Calculate 500-Yen Coins**: The maximum number of 500-yen coins is obtained by dividing the total yen (X) by 500.
3. **Remaining Yen After 500-Yen Coins**: After accounting for the 500-yen coins, the remaining yen is used to get as many 5-yen coins as possible.
4. **Calculate Happiness Points**: Sum the happiness points from both the 500-yen and 5-yen coins.

### Solution Code
```python
def main():
    X = int(input())
    num_500 = X // 500
    remainder = X % 500
    num_5 = remainder // 5
    print(num_500 * 1000 + num_5 * 5)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input value X is read as an integer.
2. **Calculate 500-Yen Coins**: Using integer division (`X // 500`), we determine how many 500-yen coins can be formed.
3. **Calculate Remaining Yen**: The remainder after forming 500-yen coins is found using `X % 500`.
4. **Calculate 5-Yen Coins**: The remaining yen is divided by 5 to find the maximum number of 5-yen coins.
5. **Compute Total Happiness**: The total happiness points are calculated by summing the contributions from both 500-yen and 5-yen coins.

This approach ensures that we maximize the higher-yielding 500-yen coins first and then use the remaining yen efficiently to get the maximum possible 5-yen coins, thus optimizing the total happiness points.
