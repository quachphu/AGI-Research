To solve this problem, we need to determine the winner of the Unique Bid Auction for each test case. The winner is the participant who chose the smallest unique number, and if there are no unique numbers, there is no winner.

### Approach
1. **Read Input Efficiently**: Given the constraints, we need to read input efficiently using standard input methods.
2. **Count Frequencies**: Use a frequency counter to track how many times each number appears in the list of chosen numbers.
3. **Identify Unique Numbers**: Extract the numbers that appear exactly once (unique numbers).
4. **Determine Minimum Unique Number**: If there are unique numbers, find the smallest one. If there are no unique numbers, return -1.
5. **Find First Occurrence**: Track the first occurrence of each number to quickly determine the index of the smallest unique number.

### Solution Code
```python
import sys
from collections import Counter

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        a = list(map(int, sys.stdin.readline().split()))
        freq = Counter(a)
        first_occurrence = {}
        for idx, num in enumerate(a):
            if num not in first_occurrence:
                first_occurrence[num] = idx + 1  # 1-based index
        candidates = [k for k, v in freq.items() if v == 1]
        if not candidates:
            print(-1)
        else:
            min_uniq = min(candidates)
            print(first_occurrence[min_uniq])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads multiple test cases efficiently using `sys.stdin` to handle large input sizes.
2. **Frequency Counter**: Using `Counter` from the `collections` module, we count the occurrences of each number in the list.
3. **First Occurrence Tracking**: As we iterate through the list of numbers, we record the first occurrence of each number using a dictionary. This allows us to quickly look up the index of the smallest unique number later.
4. **Finding Candidates**: We filter out numbers that appear exactly once. If there are no such numbers, we immediately return -1.
5. **Determine Result**: If there are unique numbers, we find the smallest one and use the pre-recorded first occurrence to get the 1-based index of the winner.

This approach ensures that each step is optimized for time complexity, making the solution efficient and suitable for large input sizes as specified in the problem constraints.
