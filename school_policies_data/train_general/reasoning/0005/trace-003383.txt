To solve this problem, we need to verify if the watering schedule for the school holidays is correct. The schedule is considered correct if each day is watered exactly once. If there is any day where the flowers are either not watered or watered multiple times, we need to identify the first such day.

### Approach
1. **Input Reading**: Read the number of days `n` and the number of people `m` responsible for watering the flowers.
2. **Shifts Processing**: For each person, read their start and end days of duty.
3. **Day Checking**: For each day from 1 to `n`, count how many times it is covered by any of the shifts.
4. **Validation**: Check each day to see if it is covered exactly once. If any day is not covered or covered multiple times, output the first such day and its count. If all days are covered exactly once, output "OK".

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    m = int(input[ptr])
    ptr += 1
    shifts = []
    for _ in range(m):
        a = int(input[ptr])
        ptr += 1
        b = int(input[ptr])
        ptr += 1
        shifts.append((a, b))
    
    for day in range(1, n + 1):
        cnt = 0
        for a, b in shifts:
            if a <= day <= b:
                cnt += 1
        if cnt != 1:
            print(f"{day} {cnt}")
            return
    print("OK")

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list for easier processing. The first two values are `n` (number of days) and `m` (number of people). Each subsequent pair of values represents the start and end days of a person's shift.
2. **Shifts Storage**: The shifts are stored as a list of tuples, each containing the start and end days of a person's duty.
3. **Day-by-Day Check**: For each day from 1 to `n`, we initialize a counter to zero. We then iterate over each shift and check if the current day falls within the shift's range. If it does, the counter is incremented.
4. **Validation Check**: After counting the coverage for each day, if the count is not exactly 1, we immediately print the day and its count, then exit. If all days are checked and found to be correct, "OK" is printed.

This approach ensures that we efficiently check each day's coverage and identify the first day with incorrect watering, providing an optimal solution given the constraints.
