4. **Binary Search for Minimal Days**: For each possible remainder of days modulo `n`, use binary search to find the minimal number of full cycles required such that the ship can reach the destination within the total days computed.

        E = n

        left = 0
        right = 10**18
        best_k = None
        while left <= right:
            mid = (left + right) // 2
            current_sum = abs(A - mid*C) + abs(B - mid*D)
            if current_sum <= mid * E + r:
                best_k = mid
                right = mid - 1
            else:
                left = mid + 1

        if best_k is not None:
            t_candidate = best_k * E + r
            if t_candidate >= 1 and t_candidate < min_days:
                min_days = t_candidate

    if min_days == float('inf'):

    else:
        print(min_days)
