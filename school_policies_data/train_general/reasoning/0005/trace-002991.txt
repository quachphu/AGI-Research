To solve this problem, we need to determine which leaflet contains the most occurrences of a specific substring of the Absolutely Inadmissible Swearword (s) within a given range of leaflets. The solution involves efficiently preprocessing each leaflet's text and using suffix automata to quickly count occurrences of substrings.

### Approach
1. **Suffix Automaton Construction**: For each leaflet text (ti), build a suffix automaton. This data structure helps efficiently count occurrences of any substring within ti in O(|P|) time, where |P| is the length of the substring.
2. **Query Processing**: For each query, extract the substring (P) from the swearword (s). Then, for each leaflet in the specified range, use the precomputed suffix automaton to count occurrences of P and determine the maximum occurrences.

class State:
    __slots__ = ['next', 'link', 'len', 'cnt']
    def __init__(self):
        self.next = {}
        self.link = -1
        self.len = 0
        self.cnt = 0

def build_sam(s):
    size = 1
    last = 0
    states = [State()]
    for c in s:
        p = last
        curr = size
        size += 1
        states.append(State())
        states[curr].len = states[p].len + 1
        states[curr].cnt = 1
        while p != -1 and c not in states[p].next:
            states[p].next[c] = curr
            p = states[p].link
        if p == -1:
            states[curr].link = 0
        else:
            q = states[p].next[c]
            if states[p].len + 1 == states[q].len:
                states[curr].link = q
            else:
                clone = size
                size += 1
                states.append(State())
                states[clone].len = states[p].len + 1
                states[clone].next = states[q].next.copy()
                states[clone].link = states[q].link
                while p != -1 and states[p].next.get(c, -1) == q:
                    states[p].next[c] = clone
                    p = states[p].link
                states[q].link = clone
                states[curr].link = clone
        last = curr
    ordered = sorted(range(1, size), key=lambda x: -states[x].len)
    for u in ordered:
        if states[u].link != -1 and states[u].link != 0:
            states[states[u].link].cnt += states[u].cnt
    return states

    import sys
