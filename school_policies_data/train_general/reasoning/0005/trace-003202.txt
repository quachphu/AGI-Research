To solve this problem, we need to determine the length of the longest palindromic substring for each given string in multiple test cases. A palindrome is a string that reads the same forwards and backwards. The approach involves checking each possible center of a palindrome (both for odd and even lengths) and expanding outwards to find the longest palindrome from that center.

### Approach
1. **Expand Around Center**: For each character in the string, consider it as the center of an odd-length palindrome and expand outwards. Similarly, consider the space between each pair of consecutive characters as the center of an even-length palindrome and expand outwards.
2. **Track Maximum Length**: For each center expansion, track the maximum length of the palindrome found.
3. **Iterate Through Test Cases**: Read the number of test cases and each string, then apply the expansion method to find the longest palindrome for each string.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    
    T = int(input[0])
    results = []
    
    for i in range(1, T + 1):
        s = input[i].strip()
        max_len = 0
        n = len(s)
        for j in range(n):
            # Check for odd length palindrome
            l, r = j, j
            while l >= 0 and r < n and s[l] == s[r]:
                l -= 1
                r += 1
            odd_len = r - l - 1
            # Check for even length palindrome
            l, r = j, j + 1
            while l >= 0 and r < n and s[l] == s[r]:
                l -= 1
                r += 1
            even_len = r - l - 1
            current_max = max(odd_len, even_len)
            if current_max > max_len:
                max_len = current_max
        results.append(str(max_len))
    
    print('\n'.join(results))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list for efficient processing. The first element is the number of test cases.
2. **Processing Each String**: For each string, initialize the maximum length of the palindrome found to 0.
3. **Odd-Length Palindromes**: For each character, expand around it as the center and check the length of the palindrome.
4. **Even-Length Palindromes**: For each pair of consecutive characters, expand around the center between them and check the length of the palindrome.
5. **Update Maximum Length**: After checking both odd and even length palindromes for each center, update the maximum length if a longer palindrome is found.
6. **Output Results**: Collect results for each test case and print them at the end to minimize I/O operations.

This approach efficiently checks all possible palindromic substrings by expanding around each potential center, ensuring that we find the longest palindrome in linear time relative to the string length for each test case.
