To solve this problem, we need to determine the minimum number of coins required to move all chips to the same coordinate on a number line. The key insight is that moving chips by even distances is free, while moving by odd distances costs one coin per move. 

### Approach
1. **Understand Parity**: The cost to move a chip to a target position depends on whether the target position's parity (even or odd) matches the chip's current position. Moving a chip from an even position to another even position (or odd to odd) can be done with free moves. Moving from even to odd (or vice versa) costs one coin.
2. **Count Even and Odd Positions**: By counting how many chips are at even positions and how many are at odd positions, we can determine the minimum cost. The minimum cost will be the smaller of these two counts, as we can choose the target position's parity to minimize the number of coins needed.

### Solution Code
```python
n = int(input())
x = list(map(int, input().split()))
even = sum(1 for num in x if num % 2 == 0)
odd = len(x) - even
print(min(even, odd))
```

### Explanation
1. **Reading Input**: The code reads the number of chips and their positions.
2. **Counting Parity**: It counts how many chips are at even positions and how many are at odd positions.
3. **Determine Minimum Cost**: The minimum number of coins required is the smaller count between even and odd positioned chips. This is because aligning all chips to the parity with more chips will minimize the number of moves that cost coins.

This approach efficiently computes the result in linear time, making it optimal for the given constraints.
