    a_str, k = input().split()

    k = int(k)

    digits = list(a_str)

    n = len(digits)

    for i in range(n):

        if k <=0:

            break

        # find the max digit in the window [i, i+possible]

        max_pos = i

        possible = i + k

        if possible >= n:

            possible = n-1

        for j in range(i+1, possible +1):

            if digits[j] > digits[max_pos]:

                max_pos = j

        # Now, max_pos is the position of the max digit in the window

        if max_pos != i:

            # cost is (max_pos -i) swaps

            # pop and insert

            d = digits.pop(max_pos)

            digits.insert(i, d)

            # update k

            k -= (max_pos -i)

    print(''.join(digits))

To solve this problem, we need to find the maximum possible number by swapping adjacent digits of a given number at most `k` times. The approach involves a greedy algorithm that maximizes the digit at each position from left to right, considering the remaining allowed swaps.

### Approach
1. **Convert the Input**: Convert the input number into a list of characters for easier manipulation.
2. **Iterate Through Each Digit**: For each digit starting from the leftmost position, determine the maximum digit that can be placed at the current position within the allowed number of swaps.
3. **Adjust Swaps**: Once the maximum digit is found within the allowed range, move it to the current position using the required number of swaps and update the remaining swaps.
4. **Stop Early**: If the remaining swaps (`k`) reach zero, break out of the loop early to avoid unnecessary computations.
