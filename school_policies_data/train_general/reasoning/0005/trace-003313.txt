To solve this problem, we need to find a spanning tree in a connected undirected graph such that the median value of the edge costs in the spanning tree is minimized. The graph has an even number of nodes, and we need to ensure that the spanning tree uses the minimum possible median edge cost.

### Approach
1. **Problem Analysis**: The median value in a spanning tree with \( n-1 \) edges (where \( n \) is even) is the \( (n/2 - 1) \)-th element when the edges are sorted by cost. To minimize this median value, we need to find the smallest possible value such that there exists a spanning tree with at least \( n/2 \) edges having costs less than or equal to this value.

2. **Binary Search**: We use binary search on the possible edge costs to determine the minimum value of the median. For each candidate median value, we check if we can form a spanning tree with at least \( n/2 \) edges having costs less than or equal to this candidate value.

3. **Union-Find Data Structure**: This helps efficiently manage and merge disjoint sets to form the spanning tree. We prioritize edges with costs less than or equal to the current candidate median value to maximize the number of such edges in the spanning tree.

4. **Kruskal's Algorithm Modification**: We process edges in two phases: first considering edges with costs less than or equal to the candidate median (sorted by cost), then considering the remaining edges. This ensures we maximize the number of edges with costs less than or equal to the candidate median.

import sys

class UnionFind:
    def __init__(self, size):
        self.parent = list(range(size))
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        fx = self.find(x)
        fy = self.find(y)
        if fx != fy:
            self.parent[fy] = fx

def main():
    while True:
        line = sys.stdin.readline()
        while line.strip() == '':
            line = sys.stdin.readline()
        n, m = map(int, line.split())
        if n == 0 and m == 0:
            break
        edges = []
        for _ in range(m):
            s, t, c = map(int, sys.stdin.readline().split())
            edges.append((s, t, c))
        required = n // 2
        low = 0
        high = 1000
        answer = 1000
        while low <= high:
            mid = (low + high) // 2
            good_edges = []
            for s, t, c in edges:
                if c <= mid:
                    good_edges.append((c, s-1, t-1))
            good_edges.sort()
            bad_edges = []
            for s, t, c in edges:
                if c > mid:
                    bad_edges.append((c, s-1, t-1))
            bad_edges.sort()
            uf = UnionFind(n)
            good_count = 0
            for c_g, s, t in good_edges:
                if uf.find(s) != uf.find(t):
                    uf.union(s, t)
                    good_count += 1
            for c_b, s, t in bad_edges:
                if uf.find(s) != uf.find(t):
                    uf.union(s, t)
            root = uf.find(0)
            connected = all(uf.find(i) == root for i in range(n))
            if connected and good_count >= required:
                answer = mid
                high = mid - 1
            else:
                low = mid + 1
        print(answer)

if __name__ == "__main__":
    main()
