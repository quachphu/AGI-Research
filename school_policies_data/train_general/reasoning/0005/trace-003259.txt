To solve this problem, we need to select a subset of sports such that the maximum number of participants in any selected sport is minimized. Each participant will choose the sport that appears earliest in their preference list among the selected sports.

### Approach
1. **Initialization**: For each participant, track their current favorite sport (initially the first sport in their preference list).
2. **Count Calculation**: Maintain a count of how many participants currently favor each sport.
3. **Max-Heap for Selection**: Use a max-heap to efficiently select the sport with the highest current count of participants.
4. **Iterative Selection**: Iteratively select the sport with the highest count, update the participants' current favorite sports, and adjust the counts accordingly. Track the minimum of the maximum counts encountered during this process.

### Solution Code
```python
import heapq
from collections import defaultdict

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    M = int(input[ptr])
    ptr += 1
    
    preferences = []
    for _ in range(N):
        prefs = list(map(int, input[ptr:ptr+M]))
        ptr += M
        preferences.append(prefs)
    
    current = [0] * N  # current index for each person
    selected = set()
    current_counts = defaultdict(int)
    
    for i in range(N):
        sport = preferences[i][current[i]]
        current_counts[sport] += 1
    
    heap = []
    for sport in current_counts:
        heapq.heappush(heap, (-current_counts[sport], sport))
    
    answer = float('inf')
    
    while heap:
        cnt_neg, s = heapq.heappop(heap)
        current_cnt = -cnt_neg
        answer = min(answer, current_cnt)
        if answer == 0:
            break
        
        selected.add(s)
        updates = defaultdict(int)
        
        for i in range(N):
            if current[i] >= len(preferences[i]):
                continue
            current_sport = preferences[i][current[i]]
            if current_sport == s:
                current[i] += 1
                while current[i] < len(preferences[i]) and preferences[i][current[i]] in selected:
                    current[i] += 1
                if current[i] < len(preferences[i]):
                    new_sport = preferences[i][current[i]]
                    updates[new_sport] += 1
        
        current_counts = defaultdict(int)
        for i in range(N):
            if current[i] < len(preferences[i]):
                sport = preferences[i][current[i]]
                current_counts[sport] += 1
        
        heap = []
        for sport in current_counts:
            if sport not in selected:
                heapq.heappush(heap, (-current_counts[sport], sport))
    
    print(answer)

if __name__ == "__main__":
    main()
```

5. **Result**: The minimum value of the maximum participants in any sport encountered during the process is the answer.

This approach ensures that we dynamically adjust the counts based on the selected sports, efficiently finding the optimal solution using a greedy strategy combined with a max-heap for performance.
