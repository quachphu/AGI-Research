To solve this problem, we need to determine the position of the last person remaining in a circle where every k-th person is eliminated until only one remains. This is a classic problem known as the Josephus problem. The solution involves using an iterative approach to efficiently compute the result without recursion, which avoids potential stack overflow issues with large inputs.

### Approach
1. **Understanding the Josephus Problem**: The problem can be solved using the Josephus problem's mathematical formula. The recursive formula for the Josephus problem is J(n, k) = (J(n-1, k) + k) % n, where J(1, k) = 0. However, we use an iterative approach to avoid recursion.
2. **Iterative Calculation**: Starting with the base case where there is only one person (position 0), we iteratively compute the position of the last remaining person for each number of people from 2 up to n. This is done using the formula `res = (res + k) % i` for each i from 2 to n.
3. **Adjusting for 1-based Index**: Since the problem requires a 1-based index result, we adjust the final result by adding 1 to the computed 0-based index.

### Solution Code
```python
def find_last_position():
    import sys
    n, k = map(int, sys.stdin.readline().split())
    res = 0
    for i in range(2, n + 1):
        res = (res + k) % i
    print(res + 1)

find_last_position()
```

### Explanation
1. **Reading Input**: The function reads two integers from standard input, representing the number of people (n) and the skip number (k).
2. **Initialization**: We initialize `res` to 0, which corresponds to the position of the last remaining person when there is only one person.
3. **Iterative Calculation**: For each number of people from 2 up to n, we update `res` using the formula `(res + k) % i`. This formula effectively simulates the elimination process and keeps track of the position of the last remaining person.
4. **Adjusting for 1-based Index**: After completing the iterations, we adjust the result by adding 1 to convert from 0-based index to 1-based index and print the result.

This approach efficiently computes the result in O(n) time complexity, which is optimal for this problem, and uses O(1) additional space.
