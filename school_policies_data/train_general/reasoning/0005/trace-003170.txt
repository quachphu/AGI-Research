### Approach
1. **Pattern Recognition**: The cumulative XOR from 1 to \( K \) follows a specific pattern based on \( K \mod 4 \):
   - If \( K \mod 4 = 0 \), \( F(K) = K \)
   - If \( K \mod 4 = 1 \), \( F(K) = 1 \)
   - If \( K \mod 4 = 2 \), \( F(K) = K + 1 \)
   - If \( K \mod 4 = 3 \), \( F(K) = 0 \)

2. **Reverse Engineering**: Given \( X \), we reverse-engineer \( K \) using the pattern:
   - If \( X = 0 \), the smallest \( K \) is 3 (since \( F(3) = 0 \)).
   - If \( X \mod 4 = 0 \), \( K = X \) (since \( F(X) = X \)).
   - If \( X \mod 4 = 1 \), \( X \) must be 1 (since \( F(1) = 1 \)).
   - If \( X \mod 4 = 3 \), \( K = X - 1 \) (since \( F(X-1) = X \)).
   - If \( X \mod 4 = 2 \), there is no valid \( K \).

### Solution Code
```python
import sys

def find_k(X):
    if X == 0:
        return 3
    mod = X % 4
    if mod == 0:
        return X
    elif mod == 1:
        return 1 if X == 1 else -1
    elif mod == 3:
        return X - 1
    else:  # mod == 2
        return -1

def main():
    input_data = sys.stdin.read().split()
    T = int(input_data[0])
    results = []
    for x_str in input_data[1:T+1]:
        X = int(x_str)
        results.append(find_k(X))
    print('\n'.join(map(str, results)))

if __name__ == "__main__":
    main()
```
