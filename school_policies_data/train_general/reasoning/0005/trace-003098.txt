To solve this problem, we need to generate the lexicographically smallest palindrome that can be formed by rearranging all characters of a given string. If it's not possible to form a palindrome, we should return -1.

### Approach
1. **Check Palindrome Feasibility**: A palindrome can be formed if and only if at most one character has an odd frequency. If more than one character has an odd frequency, it's impossible to form a palindrome, so we return -1.
2. **Identify Middle Character**: If there's a character with an odd frequency, it will be the middle character of the palindrome. We adjust its frequency to make it even for the remaining steps.
3. **Build Left Half**: Using the remaining characters (each with even frequencies), we construct the left half of the palindrome by appending each character in lexicographical order, each repeated half of their total frequency.
4. **Construct Palindrome**: The final palindrome is formed by concatenating the left half, the middle character (if any), and the reverse of the left half.

### Solution Code
```python
from collections import Counter

def beautiful_palindrome():
    s = input().strip()
    count = Counter(s)
    
    # Check if palindrome is possible
    odd_chars = [char for char, cnt in count.items() if cnt % 2 != 0]
    if len(odd_chars) > 1:
        print(-1)
        return
    
    # Determine the middle character
    middle = ''
    if odd_chars:
        middle_char = odd_chars[0]
        count[middle_char] -= 1
        if count[middle_char] == 0:
            del count[middle_char]
        middle = middle_char
    
    # Sort characters lexicographically
    sorted_chars = sorted(count.keys())
    
    # Build the left half
    left_half = []
    for char in sorted_chars:
        num_pairs = count[char] // 2
        left_half.append(char * num_pairs)
    left_str = ''.join(left_half)
    
    # Construct the palindrome
    palindrome = left_str + middle + left_str[::-1]
    print(palindrome)

beautiful_palindrome()
```

### Explanation
1. **Feasibility Check**: We use a frequency counter to determine if more than one character has an odd frequency. If so, we immediately return -1.
2. **Middle Character Adjustment**: If there's a valid middle character, we adjust its count to ensure all remaining character counts are even.
3. **Lexicographical Order Construction**: By sorting characters and building the left half in sorted order, we ensure the lexicographically smallest arrangement. The right half is simply the reverse of the left half.
4. **Palindrome Construction**: Combining the left half, middle character (if any), and reversed left half gives us the smallest possible palindrome.

This approach efficiently checks the feasibility and constructs the palindrome in linear time relative to the input size, ensuring optimal performance even for the maximum input constraints.
