To solve this problem, we need to determine how many criminals Limak, the police officer, can catch using the Bear Criminal Detector (BCD). The BCD provides the count of criminals at each distance from Limak's city, and based on this information, we need to identify the cities where criminals must be present.

### Approach
1. **Understanding the Problem**: Limak lives in city `a` and uses the BCD to get the number of criminals at each distance from his city. The BCD provides the count of criminals for each distance, but not their exact locations. We need to determine the cities where criminals must be present based on the BCD's information.

2. **Key Insight**: For each distance `d` from city `a`, the BCD gives the sum of criminals in all cities at that distance. If the sum of criminals (S) for a group of cities at distance `d` is greater than the number of cities in that group minus one (m-1), then all cities in that group must contain criminals. This is because if the sum S exceeds the maximum possible sum when one city is excluded, that city must be a criminal.

3. **Algorithm**:
   - For each city, calculate its distance from city `a`.
   - Form a group of cities at that distance.
   - Calculate the sum of criminals in that group.
   - If the sum exceeds the group size minus one, all cities in that group must have criminals.

### Solution Code
```python
n, a = map(int, input().split())
t = list(map(int, input().split()))
count = 0

for i in range(1, n + 1):
    d = abs(i - a)
    group = [j for j in range(1, n + 1) if abs(j - a) == d]
    m = len(group)
    s = sum(t[j-1] for j in group)
    if s > m - 1:
        count += 1

print(count)
```

### Explanation
1. **Input Reading**: Read the number of cities `n` and Limak's city `a`, followed by the list of criminals in each city.
2. **Iterate Through Cities**: For each city, calculate its distance from Limak's city `a`.
3. **Form Groups**: Create a group of cities that are at the same distance from `a`.
