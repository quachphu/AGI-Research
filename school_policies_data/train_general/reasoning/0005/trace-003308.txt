To solve this problem, we need to find the maximum number of friendly pairs between red and blue points on a two-dimensional plane. A friendly pair is formed when a red point's x and y coordinates are both smaller than those of a blue point. Each point can only be part of one pair.

### Approach
The problem can be modeled as a bipartite graph matching problem where each red point is connected to compatible blue points. The goal is to find the maximum matching in this bipartite graph, which can be efficiently achieved using the Hopcroft-Karp algorithm. This algorithm is chosen for its efficiency in handling bipartite graphs, especially with up to 100 nodes on each side, ensuring optimal performance.

### Solution Code
```python
import sys
from collections import deque

def main():
    n = int(sys.stdin.readline())
    red = [tuple(map(int, sys.stdin.readline().split())) for _ in range(n)]
    blue = [tuple(map(int, sys.stdin.readline().split())) for _ in range(n)]
    
    adj = [[] for _ in range(n)]
    for i in range(n):
        a, b = red[i]
        for j in range(n):
            c, d = blue[j]
            if a < c and b < d:
                adj[i].append(j)
    
    def hopcroft_karp():
        pair_u = [-1] * n
        pair_v = [-1] * n
        dist = [0] * n
        
        def bfs():
            queue = deque()
            for u in range(n):
                if pair_u[u] == -1:
                    dist[u] = 0
                    queue.append(u)
                else:
                    dist[u] = float('inf')
            dist_null = float('inf')
            while queue:
                u = queue.popleft()
                if dist[u] < dist_null:
                    for v in adj[u]:
                        if pair_v[v] == -1:
                            dist_null = dist[u] + 1
                        elif dist[pair_v[v]] == float('inf'):
                            dist[pair_v[v]] = dist[u] + 1
                            queue.append(pair_v[v])
            return dist_null != float('inf')
        
        def dfs(u):
            for v in adj[u]:
                if pair_v[v] == -1 or (dist[pair_v[v]] == dist[u] + 1 and dfs(pair_v[v])):
                    pair_u[u] = v
                    pair_v[v] = u
                    return True
            dist[u] = float('inf')
            return False
        
        result = 0
        while bfs():
            for u in range(n):
                if pair_u[u] == -1:
                    if dfs(u):
                        result += 1
        return result
    
    print(hopcroft_karp())

if __name__ == '__main__':
    main()
```

3. **Hopcroft-Karp Algorithm**: This algorithm is used to find the maximum bipartite matching. It employs BFS to find shortest augmenting paths and DFS to explore these paths, efficiently increasing the matching count in each iteration.
4. **Result Output**: The maximum number of friendly pairs is printed, which corresponds to the size of the maximum matching found by the algorithm.

This approach ensures that we efficiently determine the maximum number of pairs by leveraging the properties of bipartite graphs and the efficiency of the Hopcroft-Karp algorithm.
