To solve this problem, we need to determine if a given string of football players' positions (represented as '0's and '1's) contains a dangerous situation. A situation is considered dangerous if there are at least 7 consecutive players from the same team (i.e., a sequence of 7 or more '0's or '1's in a row).

### Approach
1. **Immediate Check for Short Strings**: If the input string's length is less than 7, it's impossible to have a dangerous situation, so we immediately return "NO".
2. **Track Consecutive Characters**: For strings of length 7 or more, iterate through each character while keeping track of the current character and the count of consecutive occurrences.
3. **Early Termination**: If at any point the count of consecutive characters reaches 7, immediately print "YES" and terminate the function. If the loop completes without finding such a sequence, print "NO".

### Solution Code
```python
def check_dangerous():
    s = input().strip()
    if len(s) < 7:
        print("NO")
        return
    current = s[0]
    count = 1
    for c in s[1:]:
        if c == current:
            count += 1
            if count >= 7:
                print("YES")
                return
        else:
            current = c
            count = 1
    print("NO")

check_dangerous()
```

### Explanation
1. **Reading Input**: The function reads the input string and removes any leading or trailing whitespace.
2. **Short String Check**: If the string length is less than 7, it directly outputs "NO" since a dangerous situation is impossible.
3. **Iterating Through Characters**: Starting from the second character, the function checks each character in sequence. If the current character matches the previous one, it increments the count. If the count reaches 7, it prints "YES" and exits immediately.
4. **Resetting Count**: When a different character is encountered, the current character and count are reset to start tracking the new sequence.
5. **Final Check**: If the loop completes without finding a dangerous sequence, the function prints "NO".

This approach efficiently checks for dangerous sequences with a linear scan of the input string, ensuring optimal performance even for the maximum input length.
