To solve this problem, we need to determine the minimum number of character changes required to convert a given string into a palindrome. A palindrome reads the same forwards and backwards, so each character at position `i` must match the character at the mirror position `len(S)-1-i`.

### Approach
1. **Identify Mismatched Pairs**: For each character in the first half of the string, compare it with its corresponding mirror character in the second half.
2. **Count Changes Needed**: Each pair of mismatched characters requires one change to make them match. Count these mismatches to determine the minimum number of changes required.

### Solution Code
```python
def main():
    s = input().strip()
    count = 0
    n = len(s)
    for i in range(n // 2):
        if s[i] != s[n - 1 - i]:
            count += 1
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input string is read from standard input.
2. **Initialization**: A counter is initialized to zero to keep track of the number of changes needed.
3. **Iterate Through Pairs**: Loop through the first half of the string. For each index `i`, compare the character at position `i` with the character at the mirror position `n-1-i`.
4. **Count Mismatches**: If the characters at these positions do not match, increment the counter by one.
5. **Output Result**: Print the total count of mismatches, which represents the minimum number of changes needed to make the string a palindrome.

This approach efficiently checks each necessary character pair and counts the required changes in linear time, making it optimal for the given constraints.
