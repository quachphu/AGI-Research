To solve this problem, we need to determine the maximum possible number that can be displayed on an electronic scoreboard after turning on exactly `k` segments. Each digit on the scoreboard is represented by a 7-segment display, and the segments that are currently working are given. The goal is to find the maximum number by turning on exactly `k` segments, ensuring that each digit formed is valid.

### Approach
1. **Precompute Digit Masks**: Each digit (0-9) is represented by a specific 7-segment configuration. These configurations are predefined based on the problem statement.
2. **Determine Possible Digits for Each Position**: For each digit on the scoreboard, determine which digits (0-9) can be formed by turning on additional segments. This involves checking if the target digit's segments are a superset of the current segments.
3. **Dynamic Programming (DP) for Feasibility Check**: Use a DP table to check if it is feasible to form a valid number starting from each position with a given number of remaining segments.
4. **Construct the Maximum Number**: Using the feasibility table, construct the maximum number by choosing the highest possible digit at each position while ensuring the remaining segments can be used up exactly by the subsequent digits.

digit_masks = [
    '1110111',  # 0
    '0010010',  # 1
    '1011101',  # 2

n, k = map(int, input().split())
current_masks = [input().strip() for _ in range(n)]

possible = []
for mask in current_masks:
    digits = []
    for d in range(9, -1, -1):
        target = digit_masks[d]
        valid = True
        cost = 0
        for i in range(7):
            if mask[i] == '1' and target[i] == '0':
                valid = False
                break
            if mask[i] == '0' and target[i] == '1':
                cost += 1
        if valid:
            digits.append((d, cost))
    possible.append(digits)

# Check if any digit has no possible options

# Initialize feasible table

feasible = [[False] * (max_k + 1) for _ in range(n + 1)]
feasible[n][0] = True

for i in range(n - 1, -1, -1):
    for j in range(max_k + 1):
        for (d, cost) in possible[i]:
            if cost <= j and feasible[i + 1][j - cost]:
                feasible[i][j] = True
                break  # Break early due to descending order of digits

if not feasible[0][max_k]:

else:
    res = []
    remaining = max_k
    for i in range(n):
        for (d, cost) in possible[i]:

                remaining -= cost
                break

    print(''.join(res))
