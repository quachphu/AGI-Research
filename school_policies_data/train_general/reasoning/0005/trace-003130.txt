To solve this problem, we need to determine the length of the longest common prefix among all given phone numbers of Polycarpus's friends. The phone code is defined as the longest common prefix of all the phone numbers.

### Approach
1. **Reading Input:** Read the number of friends and their respective phone numbers.
2. **Reference String:** Use the first phone number as a reference string to compare against all other phone numbers.
3. **Character Comparison:** For each character position in the reference string, check if all other phone numbers have the same character at that position.
4. **Early Termination:** As soon as a mismatch is found at a character position, the length of the common prefix is determined to be that position. If all characters match up to the length of the reference string, return that length (though this case is impossible due to input constraints ensuring all numbers are different).

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    numbers = input[1:n+1]
    ref = numbers[0]
    length = len(ref)
    for i in range(length):
        current_char = ref[i]
        for num in numbers[1:]:
            if num[i] != current_char:
                print(i)
                return
    print(length)

main()
```

### Explanation
1. **Reading Input:** The input is read as a single string split by whitespace, which includes newlines. The first element is the number of friends, followed by their phone numbers.
2. **Reference String:** The first phone number is used as the reference to compare against all others.
3. **Character Comparison:** For each character position `i` in the reference string, we check if all other phone numbers have the same character at position `i`. If any phone number differs at position `i`, we immediately print `i` (the length of the common prefix) and exit.
4. **Efficiency:** The algorithm efficiently checks each character position up to the length of the phone numbers, ensuring a time complexity of O(n * m), where `n` is the number of friends and `m` is the length of the phone numbers. This is efficient given the problem constraints.

This approach ensures we quickly determine the longest common prefix by leveraging early termination upon finding the first mismatch, making it both optimal and straightforward.
