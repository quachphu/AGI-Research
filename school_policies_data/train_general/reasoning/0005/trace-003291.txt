To solve this problem, we need to determine the dimensions of a rectangular display with exactly `n` pixels such that the number of rows (a) does not exceed the number of columns (b) and the difference between columns and rows (b - a) is minimized.

### Approach
1. **Understanding the Problem**: The goal is to find two integers `a` (rows) and `b` (columns) such that `a * b = n`, `a <= b`, and the difference `b - a` is minimized. This means we need to find the pair of factors of `n` that are closest to each other.
2. **Optimal Factor Search**: The optimal factors are those closest to the square root of `n`. This is because the closest factors to the square root will yield the smallest difference. For example, if `n` is a perfect square, the square root itself will be the optimal factor.
3. **Efficient Search**: Instead of checking all possible factors up to `n`, we start from the integer part of the square root of `n` and move downwards. The first factor found in this range will give us the optimal dimensions due to the properties of factors around the square root.

### Solution Code
```python
import math

n = int(input())
sqrt_n = int(math.sqrt(n))
for i in range(sqrt_n, 0, -1):
    if n % i == 0:
        print(i, n // i)
        break
```

### Explanation
1. **Reading Input**: The input `n` is read, which represents the total number of pixels.
2. **Square Root Calculation**: Compute the integer part of the square root of `n` to start the search from the closest possible factor.
3. **Factor Search Loop**: Starting from the integer part of the square root down to 1, check each number to see if it divides `n` without a remainder. The first valid divisor found is the optimal number of rows (`a`), and the corresponding columns (`b`) is `n // a`.
4. **Output**: Print the optimal dimensions `a` and `b`.

This approach efficiently narrows down the search space to the most probable factors, ensuring we find the solution in minimal iterations. The complexity is O(√n), which is efficient even for the upper constraint of `n` up to 10^6.
