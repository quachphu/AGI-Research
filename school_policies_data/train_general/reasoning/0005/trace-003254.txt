To solve this problem, we need to determine the number of integers in a sequence such that no other integer in the sequence divides them. This requires an efficient approach due to the constraints on the input size.

### Approach
1. **Prime Factorization using Sieve of Eratosthenes**: Precompute the smallest prime factor (spf) for every number up to the maximum possible value (1,000,000) using a sieve method. This allows us to quickly factorize any number into its prime factors.
2. **Divisor Generation**: For each number in the input array, generate all its divisors except the number itself using its prime factors.
3. **Frequency Check**: Use a frequency map to count occurrences of each number. For each unique number, check if any of its divisors (other than itself) exist in the array. If no such divisors exist and the number occurs exactly once, it is counted as valid.

### Solution Code
```python
import sys
from collections import Counter

def main():
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    freq = Counter(a)
    if not freq:
        print(0)
        return
    max_x = max(freq.keys())
    max_A = 10**6
    spf = list(range(max_A + 1))
    for i in range(2, int(max_A**0.5) + 1):
        if spf[i] == i:
            for j in range(i*i, max_A +1, i):
                if spf[j] == j:
                    spf[j] = i

    def get_prime_factors(x):
        factors = {}
        while x != 1:
            p = spf[x]
            while x % p == 0:
                factors[p] = factors.get(p, 0) + 1
                x = x // p
        return factors

    def generate_divisors(factors):
        divisors = [1]
        for p, exp in factors.items():
            temp = []
            current_powers = [p**e for e in range(exp + 1)]
            for d in divisors:
                for power in current_powers:
                    temp.append(d * power)
            divisors = temp
        return divisors

    ans = 0
    for x in freq:
        if x == 1:
            divisors = []
        else:
            factors = get_prime_factors(x)
            divisors = generate_divisors(factors)
            divisors = [d for d in divisors if d != x]
        sum_d = sum(freq.get(d, 0) for d in divisors)
        if sum_d == 0:
            if freq[x] == 1:
                ans += 1
    print(ans)

if __name__ == "__main__":
    main()
```

1. **Prime Factorization**: The sieve of Eratosthenes is used to precompute the smallest prime factor (spf) for every number up to 1,000,000. This allows efficient factorization of any number into its prime factors.
2. **Divisor Generation**: For each number, using its prime factors, generate all possible divisors. Exclude the number itself from the list of divisors.
3. **Frequency Check**: For each unique number, check if any of its divisors (excluding itself) are present in the array using the frequency map. If no divisors are found and the number occurs exactly once, it is counted as valid.

This approach efficiently reduces the problem complexity by leveraging prime factorization and divisor generation, ensuring the solution handles large input sizes within acceptable time limits.
