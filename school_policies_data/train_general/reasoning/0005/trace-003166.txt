To solve this problem, we need to determine how many unique stars are visible through any of the telescopes given their positions and directions. Each telescope has a specific field of view defined by an angular radius, and a star is visible if the angle between the star's direction vector and the telescope's direction vector is less than this angular radius.

### Approach
1. **Input Parsing**: Read the input datasets until a line containing a single zero is encountered. Each dataset contains information about stars and telescopes.
2. **Normalization**: Convert the positions of stars and the directions of telescopes into unit vectors to simplify angle calculations.
3. **Dot Product Calculation**: For each star, compute the dot product with each telescope's direction vector. The dot product helps determine the cosine of the angle between the vectors.
4. **Visibility Check**: Check if the dot product (cosine of the angle) is greater than the cosine of the telescope's angular radius. If it is, the star is visible through that telescope.
5. **Count Unique Visible Stars**: Track stars that are visible through any telescope, ensuring each star is counted only once.

### Solution Code
```python
import math
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    while True:
        if ptr >= len(input):
            break
        n = int(input[ptr])
        ptr += 1
        if n == 0:
            break
        # Read stars
        stars = []
        for _ in range(n):
            sx = float(input[ptr])
            sy = float(input[ptr+1])
            sz = float(input[ptr+2])
            ptr +=3
            mag = math.sqrt(sx**2 + sy**2 + sz**2)
            ux = sx / mag
            uy = sy / mag
            uz = sz / mag
            stars.append( (ux, uy, uz) )
        # Read telescopes
        m = int(input[ptr])
        ptr +=1
        telescopes = []
        for _ in range(m):
            tx = float(input[ptr])
            ty = float(input[ptr+1])
            tz = float(input[ptr+2])
            phi = float(input[ptr+3])
            ptr +=4
            mag_t = math.sqrt(tx**2 + ty**2 + tz**2)
            vx = tx / mag_t
            vy = ty / mag_t
            vz = tz / mag_t
            cos_phi = math.cos(phi)
            telescopes.append( ( (vx, vy, vz), cos_phi ) )
        # Count visible stars
        count = 0
        for star in stars:
            visible = False
            for (v, cp) in telescopes:
                dot = star[0] * v[0] + star[1] * v[1] + star[2] * v[2]
                if dot > cp:
                    visible = True
                    break
            if visible:
                count +=1
        print(count)

if __name__ == '__main__':
    main()
```

3. **Dot Product and Cosine Comparison**: For each star, the dot product with each telescope's direction vector is computed. If this value exceeds the cosine of the telescope's angular radius, the star is considered visible through that telescope.
4. **Efficiency**: The algorithm efficiently checks each star against all telescopes, breaking early if a star is found to be visible through any telescope, thus optimizing the process.
