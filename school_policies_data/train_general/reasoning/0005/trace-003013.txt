To solve this problem, we need to implement a binary search algorithm to determine the number of comparisons made between the target value and the central elements of the search range during the search process. The input consists of multiple datasets, each containing a sorted array and a target value. The goal is to count the number of comparisons made until the search concludes, either by finding the target or exhausting the search range.

### Approach
1. **Binary Search Setup**: Initialize pointers for the left and right boundaries of the search range.
2. **Midpoint Calculation**: In each iteration, compute the midpoint of the current search range using integer division.
3. **Comparison and Adjustment**: Compare the target value with the element at the midpoint. Adjust the search range based on whether the target is smaller or larger than the midpoint element. Increment the comparison count each time a comparison is made.
4. **Termination**: The search terminates when the target is found or the search range is exhausted (left boundary exceeds right boundary).

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    while True:
        n = int(input[ptr]) if ptr < len(input) else 0
        ptr += 1
        if n == 0:
            break
        a = []
        for _ in range(n):
            a.append(int(input[ptr]))
            ptr += 1
        k = int(input[ptr])
        ptr += 1
        count = 0
        left = 0
        right = n - 1
        while left <= right:
            mid = (left + right) // 2
            count += 1
            if a[mid] == k:
                break
            elif a[mid] < k:
                left = mid + 1
            else:
                right = mid - 1
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings for efficient processing. Each dataset is processed in sequence until encountering a zero indicating the end of input.
2. **Binary Search Execution**: For each dataset, the binary search is performed. The midpoint of the current search range is calculated, and the target is compared with the midpoint element. The search range is adjusted based on the comparison result, and the comparison count is incremented each time.
3. **Output**: After processing each dataset, the total number of comparisons made is printed.

This approach efficiently narrows down the search range by half in each iteration, ensuring logarithmic time complexity relative to the size of the input array, making it optimal for large datasets.
