To solve this problem, we need to determine if there exists a contiguous interval of Jedi Knights such that the counts of lightsaber colors exactly match the specified values for each color. 

### Approach
1. **Input Reading**: Read the input values for the number of Jedi Knights (n), the number of colors (m), the list of colors of each Jedi's lightsaber, and the target counts for each color.
2. **Sum Check**: Compute the sum of the target counts. If this sum is zero or exceeds the number of Jedi Knights, immediately output "NO" as a valid interval is impossible.
3. **Prefix Sum Calculation**: Precompute prefix sums for each color to efficiently calculate the count of each color in any interval.
4. **Interval Check**: For each possible starting index of an interval of length equal to the sum of target counts, check if the interval meets the required counts for each color using the prefix sums.

### Solution Code
```python
n, m = map(int, input().split())
colors = list(map(int, input().split()))
k = list(map(int, input().split()))

sum_k = sum(k)
if sum_k == 0 or sum_k > n:
    print("NO")
    exit()

# Precompute prefix sums for each color
prefix = {}
for c in range(1, m+1):
    prefix[c] = [0] * (n + 1)
    for i in range(1, n+1):
        prefix[c][i] = prefix[c][i-1] + (1 if colors[i-1] == c else 0)

required_length = sum_k
for i in range(n - required_length + 1):
    j = i + required_length - 1
    valid = True
    for c in range(1, m+1):
        cnt = prefix[c][j+1] - prefix[c][i]
        if cnt != k[c-1]:
            valid = False
            break
    if valid:
        print("YES")
        exit()

print("NO")
```

### Explanation
1. **Input Handling**: The input values are read and parsed into appropriate variables.
2. **Sum Check**: The sum of the target counts (sum_k) is checked to ensure it is non-zero and does not exceed the number of Jedi Knights, which would make a valid interval impossible.
3. **Prefix Sum Arrays**: For each color, a prefix sum array is created to allow quick calculation of the number of occurrences of that color in any interval.
4. **Interval Validation**: For each possible starting index of an interval of the required length, the counts of each color in the interval are checked against the target values using the prefix sums. If a valid interval is found, "YES" is printed and the program exits. If no valid interval is found after all checks, "NO" is printed.

This approach efficiently narrows down the intervals to check based on the sum of target counts and uses prefix sums to quickly validate each interval, ensuring an optimal solution.
