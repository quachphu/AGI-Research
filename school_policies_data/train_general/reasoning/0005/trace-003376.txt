1. **Input Handling**: Read the input string and determine if it is negative. If it is, strip the negative sign for processing and note that the final result should be enclosed in parentheses.
2. **Splitting Parts**: Split the number into integer and fractional parts using the decimal point. If there is no decimal point, the fractional part is considered empty.
3. **Fractional Part Processing**: Ensure the fractional part has exactly two digits by truncating or padding with zeros as needed.
4. **Integer Part Formatting**: Format the integer part by adding commas every three digits from the right. This is achieved by reversing the integer string, splitting it into chunks of three digits, reversing each chunk back, and then joining them with commas.
5. **Combining Parts**: Combine the formatted integer and fractional parts, prepend the currency symbol, and enclose in parentheses if the number was originally negative.

### Solution Code
```python
def main():
    input_str = input().strip()
    is_negative = input_str.startswith('-')
    if is_negative:
        num_str = input_str[1:]
    else:
        num_str = input_str

    if '.' in num_str:
        integer_part, fractional_input = num_str.split('.', 1)
    else:
        integer_part = num_str
        fractional_input = ''

    # Process fractional part
    fractional_part = (fractional_input + '00')[:2]

    # Process integer part
    if integer_part == '0':
        formatted_integer = '0'
    else:
        reversed_str = integer_part[::-1]
        chunks = []
        for i in range(0, len(reversed_str), 3):
            chunk = reversed_str[i:i+3][::-1]  # Reverse back to original order
            chunks.append(chunk)
        # Reverse the chunks list to get the correct grouping order
        chunks = chunks[::-1]
        formatted_integer = ','.join(chunks)

    # Combine parts
    formatted_number = f"${formatted_integer}.{fractional_part}"
    if is_negative:
        formatted_number = f"({formatted_number})"
    
    print(formatted_number)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Input Handling**: The input string is checked for a leading negative sign. If present, it is removed for processing, and the result will later be enclosed in parentheses.
2. **Splitting Parts**: The number is split into integer and fractional parts using the decimal point. If there is no decimal point, the fractional part is initialized as an empty string.
3. **Fractional Part Processing**: The fractional part is padded with zeros to ensure it has exactly two digits. If the fractional part is longer than two digits, it is truncated.
4. **Integer Part Formatting**: The integer part is reversed and split into chunks of three digits. Each chunk is reversed back to its original order, and the chunks are combined with commas to form the formatted integer string.
5. **Combining Parts**: The formatted integer and fractional parts are combined into the final financial format string. If the original number was negative, the result is enclosed in parentheses.

This approach ensures that the number is formatted correctly according to the specified rules, handling both positive and negative values appropriately.
