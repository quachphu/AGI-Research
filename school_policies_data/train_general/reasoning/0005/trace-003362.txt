In DFS, edges are recursively explored out of the most recently discovered vertex $v$ that still has unexplored edges leaving it. When all of $v$'s edges have been explored, the search ”backtracks” to explore edges leaving the vertex from which $v$ was discovered.

This process continues until all the vertices that are reachable from the original source vertex have been discovered. If any undiscovered vertices remain, then one of them is selected as a new source and the search is repeated from that source.

* $d[v]$ records when $v$ is first discovered.
* $f[v]$ records when the search finishes examining $v$’s adjacency list.

To solve this problem, we need to perform a depth-first search (DFS) on a directed graph and record the discovery and finish times for each vertex. The vertices are processed in ascending order, and the timestamps start from 1, incrementing with each discovery and finish step.

### Approach
1. **Input Reading**: Read the number of vertices and their adjacency lists. The adjacency lists are given in ascending order, ensuring that we always process the smallest available vertex first during DFS.
2. **Data Structures**: Use an adjacency list to represent the graph. Arrays are used to track discovery times (`d`), finish times (`f`), and whether a vertex has been visited.
3. **DFS Implementation**: A recursive DFS function is used to explore each vertex. The function updates the discovery and finish times using a mutable list to track the current time, allowing the time to be shared across recursive calls.
4. **Iterative DFS Calls**: After initializing the necessary structures, iterate through each vertex in ascending order. If a vertex hasn't been visited, start a DFS from that vertex to ensure all reachable vertices are processed.
5. **Output**: Print each vertex's ID along with its discovery and finish times in ascending order of vertex IDs.

### Solution Code
```python
n = int(input())
adj = [[] for _ in range(n + 1)]
for _ in range(n):
    parts = list(map(int, input().split()))
    u = parts[0]
    adj[u] = parts[2:]

d = [0] * (n + 1)
f = [0] * (n + 1)
visited = [False] * (n + 1)
time = [1]  # Using a list to allow modification in nested function

def dfs(u):
    visited[u] = True
    d[u] = time[0]
    time[0] += 1
    for v in adj[u]:
        if not visited[v]:
            dfs(v)
    f[u] = time[0]
    time[0] += 1

for u in range(1, n + 1):
    if not visited[u]:
        dfs(u)

for u in range(1, n + 1):
    print(u, d[u], f[u])
```

1. **Reading Input**: The input is read and stored in an adjacency list where each vertex points to its list of adjacent vertices.
2. **Initialization**: Arrays for discovery times (`d`), finish times (`f`), and visited status are initialized. The time is tracked using a list to allow modification within the recursive DFS function.
3. **DFS Function**: The DFS function marks a vertex as visited, records its discovery time, recursively processes all its adjacent vertices, and then records its finish time. The time is incremented after each discovery and finish step.
4. **Processing All Vertices**: The main loop ensures that each vertex is processed in ascending order, starting a DFS from any unvisited vertex to cover all components of the graph.
5. **Output**: After DFS completes for all vertices, the results are printed in ascending order of vertex IDs, showing their discovery and finish times.

This approach efficiently performs DFS while adhering to the problem constraints, ensuring correct discovery and finish times for each vertex.
