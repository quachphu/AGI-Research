def is_lapindrome(s):

To solve this problem, we need to determine if a given string is a lapindrome. A lapindrome is defined as a string that can be split into two halves (ignoring the middle character if the length is odd) such that both halves have the same characters with the same frequencies.

### Approach
1. **Input Reading**: Read the number of test cases and each string to be evaluated.
2. **String Splitting**: For each string, split it into two halves. If the string length is even, split it into two equal parts. If the length is odd, ignore the middle character and split the remaining string into two equal parts.
3. **Frequency Comparison**: Use a frequency counter to count the occurrences of each character in both halves. If the frequency counts of both halves are identical, the string is a lapindrome; otherwise, it is not.

### Solution Code
```python
import sys
from collections import Counter

def main():
    T = int(sys.stdin.readline())
    for _ in range(T):
        s = sys.stdin.readline().strip()
        n = len(s)
        mid = n // 2
        left = s[:mid]
        right = s[mid+1:] if n % 2 else s[mid:]
        if Counter(left) == Counter(right):
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads the number of test cases and each subsequent string from standard input.
2. **Splitting the String**: For each string, the length is checked to determine the midpoint. The string is split into two parts: the left half and the right half. If the string length is odd, the middle character is excluded by adjusting the split points.
3. **Frequency Counting**: Using the `Counter` class from the `collections` module, the code counts the frequency of each character in both halves of the string.
4. **Comparison**: The frequency counts of the two halves are compared. If they match, the string is a lapindrome, and "YES" is printed; otherwise, "NO" is printed.

This approach efficiently checks for the lapindrome property by leveraging frequency counters, ensuring that both the characters and their counts are identical in both halves of the string. The solution handles all edge cases, including strings of even and odd lengths, and efficiently processes inputs within the given constraints.
