To solve this problem, we need to determine the winner of a game where Chef and Misha take turns removing coins from a pile. Chef plays first, and the player who cannot make a move loses. The key insight is to identify the winning and losing positions based on the number of coins.

### Approach
The problem can be solved by recognizing a pattern in the game's winning and losing positions. Through analysis, we observe that the losing positions occur when the number of coins is a multiple of 6. This is because any move from a multiple of 6 will leave the opponent in a winning position. Therefore, the solution involves checking if the number of coins (N) is a multiple of 6. If it is, Misha wins; otherwise, Chef wins.

### Solution Code
```python
import sys

def determine_winner():
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T+1):
        N = int(input[i])
        if N % 6 == 0:
            print("Misha")
        else:
            print("Chef")

determine_winner()
```

### Explanation
1. **Reading Input:** The input is read in one go for efficiency, especially given the constraints.
2. **Check Each Test Case:** For each test case, we determine if the number of coins (N) is a multiple of 6.
3. **Determine Winner:** If N is a multiple of 6, Misha wins because Chef is left with a losing position. Otherwise, Chef wins as he can always make a move that leaves Misha in a losing position.

This approach efficiently solves the problem in constant time for each test case, making it suitable for large input sizes up to the given constraints.
