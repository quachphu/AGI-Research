To solve this problem, we need to determine the maximum possible value of the difference between the sums of two subsequences, B and C, derived from a given sequence of integers. The goal is to partition the sequence such that the difference B - C is maximized.

### Approach
1. **Understanding the Problem**: The key insight is that the difference B - C can be rewritten using the total sum of the sequence. Let S be the total sum of the sequence. Then B - C can be expressed as 2*B - S, where B is the sum of the subsequence with positive integers. This is because B + C = S, and thus B - C = 2*B - S.
2. **Optimal Subsequence Selection**: To maximize B - C, we should include all positive integers in subsequence B and exclude all non-positive integers (zeros and negative numbers) from B. This ensures that B is maximized, which directly maximizes the expression 2*B - S.
3. **Sum Calculation**: Compute the sum of all positive integers (sum_pos) and the total sum of the sequence (sum_total). The result is then given by 2*sum_pos - sum_total.

### Solution Code
```python
def main():
    n = int(input())
    a = list(map(int, input().split()))
    sum_pos = sum(x for x in a if x > 0)
    sum_total = sum(a)
    print(2 * sum_pos - sum_total)

main()
```

### Explanation
1. **Reading Input**: The code reads the input values, starting with the number of elements and then the sequence itself.
2. **Sum Calculation**: It calculates the sum of all positive integers in the sequence (`sum_pos`) and the total sum of the sequence (`sum_total`).
3. **Result Calculation**: Using the formula derived (2*sum_pos - sum_total), the code computes and prints the maximum possible value of B - C.

This approach efficiently computes the desired result in linear time, making it suitable for the given input constraints. The solution ensures that all positive integers are included in subsequence B, thus maximizing the difference B - C.
