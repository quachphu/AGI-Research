To solve this problem, we need to determine the days on which Takahashi is bound to work given the constraints of mandatory rest periods and days he cannot work. The solution involves finding days that must be included in every valid selection of workdays.

### Approach
1. **Greedy Selection from Left (Earliest Days):** We select the earliest possible days Takahashi can work, ensuring that each selected day is followed by the mandatory rest period.
2. **Greedy Selection from Right (Latest Days):** We select the latest possible days Takahashi can work, ensuring that each selected day is preceded by the mandatory rest period.
3. **Intersection of Selections:** The days that appear in both the earliest and latest selections are the days Takahashi must work on, as they are the only days common to all valid selections.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    K = int(input[1])
    C = int(input[2])
    S = input[3]

    # Compute earliest possible days
    earliest = []
    last = -10**18
    for i in range(N):
        day = i + 1
        if S[i] == 'o' and day > last + C:
            earliest.append(day)
            last = day
            if len(earliest) == K:
                break

    # Compute latest possible days
    latest = []
    last_latest = 10**18
    count = 0
    for i in reversed(range(N)):
        day = i + 1
        if S[i] == 'o' and day < last_latest - C:
            latest.append(day)
            last_latest = day
            count += 1
            if count == K:
                break
    latest.reverse()

    # Find intersection
    result = []
    for i in range(K):
        if earliest[i] == latest[i]:
            result.append(earliest[i])
    
    for day in result:
        print(day)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Earliest Days Calculation:** We iterate from the start of the days and greedily select the earliest valid days where Takahashi can work, ensuring each subsequent day is after the mandatory rest period from the last selected day.
2. **Latest Days Calculation:** We iterate from the end of the days and greedily select the latest valid days where Takahashi can work, ensuring each previous day is before the mandatory rest period from the next selected day.
3. **Intersection Check:** By comparing the earliest and latest selected days at each position, we determine the days that must be included in every valid selection, which are the days where both selections agree.

This approach efficiently narrows down the mandatory workdays using two passes (left and right) through the days, ensuring the solution is optimal with a time complexity of O(N).
