To solve this problem, we need to determine if Chandu can safely drink beer from each bottle based on the number written on it. The key insight is that a number is unsafe (poisoned) if it has strictly fewer than 4 divisors. This happens when the number is 1, a prime, or the square of a prime. 

### Approach
1. **Prime Check**: Use the Sieve of Eratosthenes to efficiently precompute prime numbers up to the maximum possible value (10^7). This allows O(1) time complexity for prime checks.
2. **Square of Prime Check**: For each number, check if it is a perfect square and then verify if its square root is a prime using the precomputed sieve.
3. **Efficiency**: The sieve is generated once, allowing each query to be processed in O(1) time, making the solution efficient even for large inputs.

### Solution Code
```python
import math
import sys

def main():
    input = sys.stdin.read().split()
    n = int(input[0])
    xs = list(map(int, input[1:n+1]))
    
    max_x = 10**7
    sieve = bytearray([1]) * (max_x + 1)
    sieve[0] = 0
    sieve[1] = 0
    for i in range(2, int(math.isqrt(max_x)) + 1):
        if sieve[i]:
            # Mark multiples of i starting from i*i as non-prime
            sieve[i*i::i] = b'\x00' * len(sieve[i*i::i])
    
    for x in xs:
        if x == 1:
            print("NO")
        elif sieve[x]:
            print("NO")
        else:
            sqrt_x = math.isqrt(x)
            if sqrt_x * sqrt_x == x and sieve[sqrt_x]:
                print("NO")
            else:
                print("YES")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Sieve of Eratosthenes**: This algorithm efficiently marks non-prime numbers up to 10^7. By using a bytearray, we minimize memory usage while maintaining quick access times.
2. **Prime Check**: For each number, we check if it is a prime using the precomputed sieve.
3. **Square of Prime Check**: If a number is not a prime, we check if it is a perfect square. If it is, we then check if the square root of the number is a prime using the sieve.
4. **Output**: Based on these checks, we determine if the number is safe (output "YES") or unsafe (output "NO").

This approach ensures that we handle up to 100,000 queries efficiently after an initial preprocessing step, making it suitable for large input sizes.
