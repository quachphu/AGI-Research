To solve this problem, we need to determine the longest subsequence from a given sequence of digits that only includes digits found on a keypad with fingerprints. The order of digits in the subsequence must match their order in the original sequence.

### Approach
1. **Input Reading**: Read the input values which include the number of digits in the sequence, the number of keys with fingerprints, the sequence of digits, and the keys with fingerprints.
2. **Filtering**: Extract the digits from the sequence that are present in the set of keys with fingerprints.
3. **Output**: Print the filtered digits in the order they appear in the original sequence. If no digits match, print an empty string.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    m = int(input[ptr])
    ptr += 1
    sequence = list(map(int, input[ptr:ptr + n]))
    ptr += n
    fingerprints = set(map(int, input[ptr:ptr + m]))
    code = [x for x in sequence if x in fingerprints]
    print(' '.join(map(str, code)) if code else '')

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings for easier processing. The first two values are the number of digits in the sequence and the number of keys with fingerprints.
2. **Processing the Sequence**: The sequence of digits is filtered to include only those digits that are present in the set of keys with fingerprints. This is done using a list comprehension.
3. **Output the Result**: The filtered digits are printed in their original order. If no digits match, an empty string is printed, which is handled by the conditional expression in the print statement.

This approach ensures that we efficiently filter and maintain the order of the digits, providing the correct longest subsequence as required.
