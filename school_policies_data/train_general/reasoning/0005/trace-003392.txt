To solve this problem, we need to count the number of distinct y-factorizations of a given positive integer x. A y-factorization of x is an array of y integers whose product is x. The result should be returned modulo \(10^9 + 7\).

### Approach

1. **Prime Factorization**: For each x, factorize it into its prime factors. This helps in determining how the exponents of these prime factors can be distributed among y elements.
2. **Combinatorial Distribution**: For each prime factor with exponent e, compute the number of ways to distribute these e exponents into y elements using combinatorics (stars and bars theorem).
3. **Sign Combinations**: Since the product of the elements must be positive (as x is positive), the number of negative elements must be even. The number of valid sign combinations is \(2^{(y-1)}\).
4. **Efficient Precomputation**: Precompute factorials and their modular inverses up to a large enough limit (2 * 10^6) to efficiently compute combinations using modular arithmetic.

import sys

MOD = 10**9 + 7

def main():
    input = sys.stdin.read().split()
    q = int(input[0])
    queries = []
    ptr = 1
    for _ in range(q):
        xi = int(input[ptr])
        yi = int(input[ptr+1])
        queries.append((xi, yi))
        ptr += 2
    
    # Precompute smallest prime factors (SPF) up to 1e6
    max_x = 10**6
    spf = list(range(max_x + 1))
    spf[0], spf[1] = 0, 1
    for i in range(2, int(max_x**0.5) + 1):
        if spf[i] == i:
            for j in range(i*i, max_x + 1, i):
                if spf[j] == j:
                    spf[j] = i
    
    # Precompute factorial and inverse factorial up to 2e6
    max_fact = 2 * 10**6
    fact = [1] * (max_fact + 1)
    for i in range(1, max_fact + 1):
        fact[i] = fact[i-1] * i % MOD
    
    inv_fact = [1] * (max_fact + 1)
    inv_fact[max_fact] = pow(fact[max_fact], MOD-2, MOD)
    for i in range(max_fact - 1, -1, -1):
        inv_fact[i] = inv_fact[i+1] * (i+1) % MOD
    
    # Process each query
    results = []
    for xi, yi in queries:
        if xi == 1:
            p = 1
        else:
            factors = {}
            x = xi
            while x != 1:
                p_spf = spf[x]
                cnt = 0
                while x % p_spf == 0:
                    cnt += 1
                    x = x // p_spf
                factors[p_spf] = cnt
            p = 1
            for e in factors.values():
                n = e + yi - 1
                k = yi - 1
                if k > n:
                    comb = 0
                else:
                    comb = fact[n] * inv_fact[k] % MOD
                    comb = comb * inv_fact[n - k] % MOD
                p = p * comb % MOD
        
        sign = pow(2, yi - 1, MOD)
        ans = (p * sign) % MOD
        results.append(ans)
    
    print('\n'.join(map(str, results)))
