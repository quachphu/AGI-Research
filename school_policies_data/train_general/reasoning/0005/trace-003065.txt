To solve this problem, we need to determine the smallest positive integer \( M \) such that the bitwise XOR of \( M \) and \( M+1 \) equals a given integer \( N \). If no such \( M \) exists, we should return -1.

### Approach
1. **Identify Valid \( N \)**: The XOR of two consecutive integers \( M \) and \( M+1 \) results in a number with all bits set to 1. Such numbers are of the form \( 2^k - 1 \). For example, \( 3 \) (binary `11`), \( 7 \) (binary `111`), etc. We can check if \( N \) is of this form by verifying if \( N \& (N + 1) \) equals 0.
2. **Determine \( k \)**: If \( N \) is valid, compute \( k \) such that \( N = 2^k - 1 \). This can be derived from the bit length of \( N + 1 \).
3. **Calculate \( M \)**: Depending on the value of \( k \):
   - If \( k = 1 \), the smallest \( M \) is 2.
   - For \( k > 1 \), the smallest \( M \) is \( 2^{(k-1)} - 1 \).

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        N = int(input[i])
        if (N & (N + 1)) != 0:
            print(-1)
        else:
            k = (N + 1).bit_length() - 1
            if k == 1:
                print(2)
            else:
                print((1 << (k - 1)) - 1)

solve()
```

1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Check Validity of \( N \)**: Using bitwise operations, we check if \( N \) is of the form \( 2^k - 1 \).
3. **Compute \( k \)**: The bit length of \( N + 1 \) gives the value of \( k \).
4. **Determine \( M \)**: Based on \( k \), we compute the smallest \( M \) using bit shifts for efficiency.

This approach efficiently checks the validity of \( N \) and computes \( M \) using bitwise operations, ensuring optimal performance even for large values of \( N \).
