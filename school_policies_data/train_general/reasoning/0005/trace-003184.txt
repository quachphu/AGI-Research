To solve this problem, we need to determine the number of button presses Manao needs in the worst-case scenario to open a lock with `n` buttons. The lock requires pressing the buttons in a specific sequence, and pressing a wrong button resets all previously pressed buttons.

### Approach
The problem can be approached by understanding the optimal strategy Manao uses to minimize the number of presses. The key insight is that each time Manao presses a wrong button, he has to restart the sequence, leading to a specific pattern of presses. The solution involves calculating the sum of presses required for each step of the sequence, considering the worst-case scenario for each step.

The formula derived to compute the number of presses in the worst-case scenario is:
\[ \text{total\_presses} = \frac{n \times (n^2 + 5)}{6} \]
This formula accounts for the sum of presses required for each possible permutation of the correct sequence, ensuring that we cover all possible wrong attempts and resets.

### Solution Code
```python
n = int(input())
print(n * (n ** 2 + 5) // 6)
```

### Explanation
1. **Formula Derivation**: The formula \(\frac{n \times (n^2 + 5)}{6}\) is derived by considering the sum of presses required for each step in the sequence. Each step involves pressing all possible wrong buttons before the correct one, leading to a cumulative sum that can be simplified using mathematical properties.
2. **Integer Division**: The formula ensures that the result is always an integer, as the product \(n \times (n^2 + 5)\) is always divisible by 6 for any positive integer `n`.
3. **Efficiency**: The solution efficiently computes the result in constant time \(O(1)\), making it suitable for large values of `n` up to 2000.

This approach optimally calculates the worst-case scenario by leveraging mathematical insights to avoid brute-force enumeration of all permutations, ensuring both correctness and efficiency.
