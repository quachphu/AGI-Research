To solve this problem, we need to determine the maximum sum of three non-negative integers that can be formed by splitting a given string into three parts. Each part must not have leading zeros (unless it is exactly "0") and each part must not exceed 1,000,000. If no valid split exists, we return -1.

### Approach
1. **Input Validation**: Check if the input string length is less than 3. If so, return -1 immediately as it's impossible to split into three parts.
2. **Generate Splits**: Iterate over all possible ways to split the string into three non-empty parts. This involves considering two split points, `i` and `j`, where `i` is the end of the first part and `j` is the end of the second part.
3. **Validation of Parts**: For each split, check if each part is a valid integer. A part is valid if:
   - It does not have leading zeros unless it is exactly "0".
   - Its integer value does not exceed 1,000,000.
4. **Sum Calculation**: If all three parts are valid, compute their sum and track the maximum sum encountered.
5. **Result**: Return the maximum sum if valid splits are found; otherwise, return -1.

### Solution Code
```python
s = input().strip()
n = len(s)
max_sum = -1

if n >= 3:
    for i in range(n - 2):
        for j in range(i + 1, n - 1):
            part1 = s[:i+1]
            part2 = s[i+1:j+1]
            part3 = s[j+1:]
            
            valid = True
            current_sum = 0
            
            for part in [part1, part2, part3]:
                if len(part) > 1 and part[0] == '0':
                    valid = False
                    break
                num = int(part)
                if num > 10**6:
                    valid = False
                    break
                current_sum += num
            
            if valid and current_sum > max_sum:
                max_sum = current_sum

print(max_sum if max_sum != -1 else -1)
```

### Explanation
- **Input Handling**: The input string is read and stripped of any leading/trailing whitespace.
- **Length Check**: If the string length is less than 3, output -1 immediately.
- **Iterate Splits**: For each possible split into three parts, validate each part:
  - Check for leading zeros in parts longer than 1 character.
  - Convert each part to an integer and ensure it does not exceed 1,000,000.
- **Sum Calculation**: If all parts are valid, compute their sum and update the maximum sum if the current sum is higher.
- **Output Result**: Print the maximum valid sum or -1 if no valid splits are found.

This approach efficiently checks all possible valid splits and ensures compliance with the problem constraints, providing an optimal solution.
