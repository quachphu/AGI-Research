To solve this problem, we need to determine the minimum time Luba needs to complete all her chores, given that she can reduce the time for up to `k` chores to `x` units each. The key is to strategically choose which chores to reduce to maximize time savings.

### Approach
1. **Problem Analysis**: 
   - Luba can reduce the time for up to `k` chores to `x` units.
   - The chores are given in non-decreasing order, meaning the longest chores come last.
   - To minimize the total time, we should replace the longest chores (those with the highest `ai` values) with `x` if they are greater than `x`.

2. **Intuition**:
   - Since the chores are sorted in non-decreasing order, the largest values are at the end. Replacing the largest values first will yield the maximum time savings.
   - Iterate through the chores from the end (largest values) and replace up to `k` chores where the chore time exceeds `x`.

3. **Algorithm**:
   - Calculate the initial total time by summing all chore times.
   - Traverse the chores in reverse order, replacing each chore time with `x` if it exceeds `x` and we still have replacements left (`k`).
   - Stop when all replacements are used or all remaining chores are already less than or equal to `x`.

### Solution Code
```python
n, k, x = map(int, input().split())
a = list(map(int, input().split()))
total = sum(a)
count = 0
for num in reversed(a):
    if count >= k:
        break
    if num > x:
        total -= (num - x)
        count += 1
    else:
        break
print(total)
```

### Explanation
1. **Reading Input**: The input values for the number of chores `n`, maximum replacements `k`, and reduced time `x` are read. The list of chore times `a` is also read.
2. **Initial Sum Calculation**: The total time is initially calculated by summing all elements in `a`.
3. **Reverse Traversal**: By iterating from the end of the list (using `reversed(a)`), we check each chore time. If the time is greater than `x` and we have replacements left, we replace it with `x`, adjust the total time, and increment the replacement count.
4. **Termination Conditions**: The loop stops when all replacements are used or when a chore time is found to be less than or equal to `x` (since all previous chores will be even smaller due to the sorted order).

This approach efficiently ensures that the maximum possible time savings are achieved by focusing on the largest chores first, leveraging the sorted order for optimal performance.
