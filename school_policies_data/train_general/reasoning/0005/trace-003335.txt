To solve this problem, we need to transform the given sequence of tree heights into a "beautiful sequence" with the minimum number of changes. A beautiful sequence is defined such that the heights of trees equidistant from the ends are equal and each subsequent pair from the ends increases by 1.

### Approach
1. **Understanding the Beautiful Sequence Structure**: 
   - The sequence must be symmetric, with the first and last elements being the same, the second and second-last elements being the same, and so on.
   - Each pair of elements equidistant from the ends should be 1 more than the previous pair.

2. **Key Insight**:
   - For each tree at position `i`, the required height in a beautiful sequence is determined by a base value `B` plus the distance from the nearest edge. The distance from the edge for position `i` is `d_i = min(i, n-1-i)`.
   - The goal is to find the base value `B` that maximizes the number of trees already matching the required height in the beautiful sequence, thus minimizing the number of changes.

3. **Algorithm**:
   - Compute the distance from the nearest edge for each tree.
   - For each tree, determine the potential base value `B` as `a_i - d_i` (where `a_i` is the current height of the tree). If this base value is valid (≥ 1), count its occurrences.
   - The optimal base value is the one with the highest occurrence count. The minimum number of changes required is the total number of trees minus this maximum count.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    freq = defaultdict(int)
    for i in range(n):
        d = min(i, n - 1 - i)
        possible_base = a[i] - d
        if possible_base >= 1:
            freq[possible_base] += 1
    max_freq = max(freq.values()) if freq else 0
    print(n - max_freq)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of the number of trees `n` and their respective heights.
2. **Distance Calculation**: For each tree, compute its distance from the nearest edge.
3. **Base Value Calculation**: For each tree, determine the potential base value that would make the tree's height fit into a beautiful sequence.
4. **Frequency Counting**: Track how often each valid base value occurs.
5. **Determine Minimum Changes**: The maximum frequency of any valid base value indicates the maximum number of trees already fitting the beautiful sequence. Subtract this from the total number of trees to get the minimum changes needed.

This approach efficiently narrows down the optimal base value by leveraging the structure of the beautiful sequence and ensures minimal changes by maximizing the reuse of existing tree heights.
