To solve this problem, we need to determine if a given square grid of characters forms an 'X' based on specific conditions. The conditions are that all characters on both diagonals must be the same, and all other characters must be the same but different from the diagonal characters.

### Approach
1. **Read Input:** First, read the size of the grid `n` and the grid itself.
2. **Check Diagonals:** Verify that all characters on both the main diagonal (where row index equals column index) and the anti-diagonal (where the sum of row and column indices equals `n-1`) are the same.
3. **Check Non-Diagonal Cells:** Ensure all characters not on the diagonals are the same and different from the diagonal characters.

### Solution Code
```python
n = int(input())
grid = [input().strip() for _ in range(n)]

# Check if all diagonal elements are the same
diag_char = grid[0][0]
valid_diag = True

for i in range(n):
    for j in range(n):
        if (i == j or i + j == n - 1):
            if grid[i][j] != diag_char:
                valid_diag = False
                break
    if not valid_diag:
        break

if not valid_diag:
    print("NO")
else:
    # Check non-diagonal elements
    other_char = None
    valid_other = True

    for i in range(n):
        for j in range(n):
            if not (i == j or i + j == n - 1):
                current = grid[i][j]
                if other_char is None:
                    other_char = current
                else:
                    if current != other_char:
                        valid_other = False
                        break
        if not valid_other:
            break

    if not valid_other or other_char == diag_char:
        print("NO")
    else:
        print("YES")
```

### Explanation
1. **Reading Input:** The input is read into a list of strings where each string represents a row of the grid.
2. **Checking Diagonals:** We iterate through each cell in the grid. If a cell is on either diagonal, we check if its character matches the first diagonal character (`diag_char`). If any mismatch is found, the grid is immediately deemed invalid.
3. **Checking Non-Diagonal Cells:** After confirming the diagonals are valid, we check the remaining cells. These cells must all be the same and different from `diag_char`. If any mismatch is found among these cells or they match the diagonal character, the grid is invalid.

This approach ensures that we efficiently verify both conditions required to form an 'X' in the grid.
