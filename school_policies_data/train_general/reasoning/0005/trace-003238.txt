To solve this problem, we need to determine the minimum number of bills required to withdraw a specific amount of money from an ATM that can dispense at most `k` bills using at most two distinct denominations. If it's not possible to withdraw the requested amount, we should return `-1`.

### Approach
1. **Single Denomination Check**: For each request, check if the amount can be dispensed using a single denomination. This is done by checking if the amount is divisible by any denomination and if the resulting number of bills is within the limit `k`.

2. **Two Denominations Check**: If the single denomination check fails, check all possible combinations of two denominations. For each combination, we check if the amount can be formed using the two denominations such that the total number of bills used is within the limit `k` and the number of bills is minimized.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n, k = int(input[ptr]), int(input[ptr+1])
    ptr +=2
    deno = list(map(int, input[ptr:ptr+n]))
    ptr +=n
    q = int(input[ptr])
    ptr +=1
    queries = list(map(int, input[ptr:ptr+q]))
    deno_set = set(deno)
    
    for xi in queries:
        min_bills = float('inf')
        # Check single denomination
        for a in reversed(deno):
            if xi % a == 0:
                cnt = xi // a
                if cnt <= k:
                    if cnt < min_bills:
                        min_bills = cnt
                    break  # largest a first, so break early
        
        # Check two denominations
        found = False
        for s in range(2, k+1):
            for m in range(1, s):
                t = s - m
                for b in deno:
                    required = xi - b * t
                    if required <= 0:
                        continue
                    if required % m != 0:
                        continue
                    a_val = required // m
                    if a_val in deno_set and a_val != b:
                        # Verify the sum to prevent cases where division causes precision issues
                        if a_val * m + b * t == xi:
                            if s < min_bills:
                                min_bills = s
                            found = True
                            break  # break b loop
                if found:
                    break  # break m loop
            if found:
                break  # break s loop
        
        if min_bills <= k:
            print(min_bills)
        else:
            print(-1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into denominations and queries.
2. **Single Denomination Check**: For each query, we check if the amount can be formed using a single denomination by iterating from the largest denomination to the smallest. If a valid denomination is found, we calculate the number of bills and update the minimum if it's within the allowed limit.
3. **Two Denominations Check**: For each possible combination of two denominations, we check if the amount can be formed using `s` bills (where `s` ranges from 2 to `k`). For each `s`, we split it into `m` and `t` (such that `m + t = s`) and check if the remaining amount after using `t` bills of one denomination can be formed using `m` bills of another denomination. If valid, we update the minimum number of bills.

This approach efficiently checks both single and two denominations cases, ensuring that the solution is both optimal and within the problem constraints.
