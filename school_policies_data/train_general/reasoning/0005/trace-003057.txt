The solution involves checking if the given numbers can be rearranged to meet this specific structure.

### Approach
1. **Understand the Haiku Structure**: A valid Haiku must have syllables in the order 5, 7, 5. This means we need exactly two instances of 5 and one instance of 7.
2. **Check the Numbers**: The given three numbers can be rearranged in any order. We need to check if after sorting, they match the required structure of [5, 5, 7].

### Solution Code
```python

```

1. **Input Reading**: The input consists of three integers which are read and split into variables `a`, `b`, and `c`.
2. **Sorting**: The numbers are sorted to facilitate the comparison with the required structure [5, 5, 7].
3. **Comparison**: After sorting, the list is checked against the target structure. If it matches, "YES" is printed; otherwise, "NO" is printed.

This approach efficiently checks the necessary conditions using sorting and a direct comparison, ensuring that the solution is both correct and optimal.
