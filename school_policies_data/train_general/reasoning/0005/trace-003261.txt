To solve this problem, we need to determine the maximum number of contests (KUPCs) that can be held, each consisting of exactly K problems with distinct starting letters. The solution involves analyzing the frequency of the starting letters of the problem names and using a binary search approach to find the optimal number of contests.

### Approach
1. **Count Frequencies**: First, count the frequency of each starting letter from the given problem names.
2. **Sum Calculation**: Calculate the total number of problems, which helps in determining the upper bound for the number of contests.
3. **Binary Search**: Use binary search to determine the maximum number of contests (T) such that each contest can be formed with K distinct starting letters. For each candidate T during the binary search, check if the sum of the minimum of each letter's count and T meets or exceeds T * K, ensuring that each contest can be formed with distinct starting letters.

### Solution Code
```python
from collections import defaultdict

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    K = int(input[idx])
    idx += 1
    
    counts = defaultdict(int)
    for _ in range(N):
        s = input[idx].strip()
        idx += 1
        c = s[0]
        counts[c] += 1
    
    count_list = list(counts.values())
    sum_counts = sum(count_list)
    upper = sum_counts // K
    
    if upper == 0:
        print(0)
        return
    
    low = 0
    high = upper
    ans = 0
    
    while low <= high:
        mid = (low + high) // 2
        total = sum(min(c, mid) for c in count_list)
        if total >= mid * K:
            ans = mid
            low = mid + 1
        else:
            high = mid - 1
    
    print(ans)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Count Frequencies**: We use a dictionary to count how many times each starting letter appears in the problem names.
2. **Sum Calculation**: The total number of problems is divided by K to get an initial upper bound for the number of contests.
3. **Binary Search**: We perform a binary search between 0 and the upper bound to find the maximum number of contests. For each midpoint value (mid) in the binary search, we check if the sum of the minimum of each letter's count and mid is at least mid * K. This ensures that we can form mid contests each with K distinct starting letters.

This approach efficiently narrows down the maximum possible contests using binary search, ensuring the solution is both optimal and efficient.
