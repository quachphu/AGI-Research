To solve this problem, we need to determine if a given nervous system (represented as a graph) is valid based on two properties: connectedness and the absence of redundant edges. The solution involves checking if the graph is a tree, which ensures both properties.

### Approach
1. **Check Edge Count**: A valid tree must have exactly `n-1` edges, where `n` is the number of nodes (brains). If the number of edges `m` is not equal to `n-1`, the system is immediately invalid.
2. **Check Connectedness**: If the edge count is valid (`m = n-1`), we then check if the graph is fully connected using a Depth-First Search (DFS) or Breadth-First Search (BFS). This ensures that all nodes are reachable from any starting node.

### Solution Code
```python
n, m = map(int, input().split())
if m != n - 1:
    print("no")
else:
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        a, b = map(int, input().split())
        adj[a].append(b)
        adj[b].append(a)
    
    visited = set()
    stack = [1]
    while stack:
        node = stack.pop()
        if node not in visited:
            visited.add(node)
            for neighbor in adj[node]:
                if neighbor not in visited:
                    stack.append(neighbor)
    
    print("yes" if len(visited) == n else "no")
```

### Explanation
1. **Edge Count Check**: The first step checks if the number of edges `m` is exactly `n-1`. If not, the graph cannot be a tree, so the answer is "no".
2. **Graph Construction**: An adjacency list is built to represent the graph, where each node points to its connected neighbors.
3. **Connectedness Check**: Using DFS starting from node 1, we traverse all reachable nodes. If all `n` nodes are visited, the graph is connected, confirming it as a valid tree. If fewer nodes are visited, the graph is disconnected, resulting in "no".

This approach efficiently combines edge count validation and connectivity check to determine the validity of the nervous system structure.
