To solve this problem, we need to determine the lexicographically smallest array possible after performing any number of allowed swaps. The allowed swaps are between two elements where their sum is odd, which means one element is even and the other is odd. 

### Approach
1. **Understanding Swaps**: We can swap an even element with an odd element. If the array contains both even and odd elements, we can use these swaps to rearrange the elements freely. This is because even and odd elements can act as intermediaries to swap elements of the same parity.
2. **Check Parity**: If the array contains both even and odd elements, we can sort the entire array to get the lexicographically smallest order. If all elements are either even or odd, no swaps are possible, and the array remains unchanged.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
has_even = any(x % 2 == 0 for x in a)
has_odd = any(x % 2 == 1 for x in a)
if has_even and has_odd:
    a.sort()
print(' '.join(map(str, a)))
```

### Explanation
1. **Input Reading**: The code reads the input values for the array and its length.
2. **Parity Check**: The code checks if there are both even and odd elements in the array using `any()` functions for efficiency.
3. **Sorting**: If both parities are present, the array is sorted to achieve the lexicographically smallest order. If not, the original array is printed as no swaps are possible.

This approach ensures that we efficiently determine the smallest possible array by leveraging the allowed swaps and understanding the parity constraints. The solution runs in O(n log n) time due to sorting, which is efficient for the problem constraints.
