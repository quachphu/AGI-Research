To solve this problem, we need to determine if a regular n-sided polygon can be rotated such that at least one of its edges is parallel to the OX-axis (horizontal) and another edge is parallel to the OY-axis (vertical) simultaneously. 

### Approach
The key insight is that a regular n-sided polygon can be rotated to meet the given condition if and only if the number of sides (n) is divisible by 4. This is because the edges of a regular polygon are spaced at equal angles, and for an edge to be aligned with both the horizontal and vertical axes, the polygon must have symmetry that allows this alignment. Specifically, if n is divisible by 4, the polygon can be rotated such that its edges align with both axes.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    print("YES" if n % 4 == 0 else "NO")
```
