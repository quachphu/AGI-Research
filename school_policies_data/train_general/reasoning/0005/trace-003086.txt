To solve this problem, we need to determine the n-th digit in the infinite string formed by concatenating all integers starting from 1. The string looks like "123456789101112131415...". The approach involves identifying the segment of numbers (1-digit, 2-digit, etc.) where the n-th digit falls, and then pinpointing the exact digit within that segment.

### Approach
1. **Identify the Segment**: The numbers are grouped by their digit count (1-digit, 2-digit, 3-digit, etc.). Each group contributes a known number of digits. For example, 1-digit numbers (1-9) contribute 9 digits, 2-digit numbers (10-99) contribute 180 digits, and so on.
2. **Adjust Position**: Subtract the total digits of each group from the given position `n` until `n` falls within the current group.
3. **Locate Exact Number**: Once the correct group is identified, determine the exact number within this group that contains the n-th digit.
4. **Extract the Digit**: Convert the identified number to a string and extract the specific digit based on the position within the number.

### Solution Code
```python
def find_nth_digit():
    n = int(input())
    digits_per_group = 1
    count = 9
    start = 1
    digits_in_group = count * digits_per_group

    while n > digits_in_group:
        n -= digits_in_group
        digits_per_group += 1
        count *= 10
        start *= 10
        digits_in_group = count * digits_per_group

    index = (n - 1) // digits_per_group
    number = start + index
    digit_pos = (n - 1) % digits_per_group

    print(str(number)[digit_pos])

find_nth_digit()
```

### Explanation
1. **Reading Input**: The input integer `n` is read, which represents the position of the digit we need to find.
2. **Initial Setup**: We start with 1-digit numbers, initializing variables to track the current digit group, the count of numbers in the current group, the starting number of the group, and the total digits contributed by the group.
3. **Adjust Position**: Using a loop, we subtract the total digits of each group from `n` until `n` falls within the current group. This helps us determine which digit group (1-digit, 2-digit, etc.) contains the n-th digit.
4. **Determine Exact Number**: Once the correct group is found, we calculate the index of the number within this group and determine the exact number by adding this index to the starting number of the group.
5. **Extract the Digit**: Convert the identified number to a string and extract the specific digit using the calculated position within the number.

This approach efficiently narrows down the search space, ensuring that we quickly locate the segment and exact digit, making the solution both optimal and easy to understand.
