To solve this problem, we need to compute the inversion number of a sequence B formed by concatenating K copies of a given array A. The inversion number is defined as the number of pairs (i, j) such that i < j and B[i] > B[j]. Given the constraints, we need an efficient approach to handle large values of K.

### Approach
1. **Inversion Count within Single Copy (inv_A)**: Calculate the number of inversions in the original array A. This is done using a nested loop approach to check all pairs (i, j) where i < j and A[i] > A[j].

2. **Cross Copy Inversions (cross_inv)**: Calculate the number of inversions between elements of different copies of A. This is done by counting all pairs (x, y) in A where x > y, regardless of their positions.

3. **Modular Arithmetic**: Given the large value of K (up to 1e9), use modular arithmetic to compute the result efficiently. The final result combines contributions from both within-copy and cross-copy inversions.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))
mod = 10**9 + 7

# Compute inv_A: number of inversions in the original array
inv_A = 0
for i in range(n):
    for j in range(i + 1, n):
        if a[i] > a[j]:
            inv_A += 1

# Compute cross_inv: number of pairs (x, y) where x > y in the original array
cross_inv = 0
for x in a:
    for y in a:
        if x > y:
            cross_inv += 1

# Calculate term1 and term2 with modular arithmetic
term1 = (inv_A * k) % mod

inv2 = 500000004  # Modular inverse of 2 under mod 1e9+7
k_mod = k % mod
k_minus_1_mod = (k - 1) % mod
prod = (k_mod * k_minus_1_mod) % mod
prod = (prod * inv2) % mod
term2 = (cross_inv * prod) % mod

total = (term1 + term2) % mod
print(total)
```

### Explanation
1. **Inversion Count within Single Copy (inv_A)**: This is calculated by iterating over all pairs (i, j) in the array A where i < j and counting how many times A[i] > A[j]. This gives the inversion count for a single copy of A.

2. **Cross Copy Inversions (cross_inv)**: This is calculated by counting all pairs (x, y) in A where x > y. Each copy of A contributes this count when compared with every subsequent copy, leading to cross_inv multiplied by the number of ways to choose two copies from K copies, which is K*(K-1)/2.

3. **Modular Arithmetic**: To handle large values of K efficiently, we use modular arithmetic. The term involving K*(K-1)/2 is computed using the modular inverse of 2 to avoid overflow and ensure correctness under the given modulus.

By combining these components, we efficiently compute the total inversion number modulo 10^9 + 7.
