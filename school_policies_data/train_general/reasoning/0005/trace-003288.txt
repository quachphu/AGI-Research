To solve this problem, we need to determine the number of items that are liked by at least a given number of friends. The solution involves counting the likes for each item across all friends and checking if the count meets or exceeds the threshold.

### Approach
1. **Input Reading**: Read the number of friends (F), items (I), and the threshold (T).
2. **Opinion Collection**: Collect the opinions of each friend regarding the items.
3. **Count Likes for Each Item**: For each item, count how many friends have liked it by checking each friend's opinion string.
4. **Threshold Check**: Compare the count of likes for each item against the threshold. If the count meets or exceeds the threshold, increment the result count.
5. **Output Result**: Print the total number of items that meet the threshold requirement.

### Solution Code
```python
def main():
    # Read the input values
    F, I, T = map(int, input().split())
    # Read each friend's opinions
    opinions = [input().strip() for _ in range(F)]
    
    count = 0
    # Iterate over each item
    for item in range(I):
        likes = 0
        # Check each friend's opinion for the current item
        for friend in opinions:
            if friend[item] == 'Y':
                likes += 1
        # Check if the likes meet or exceed the threshold
        if likes >= T:
            count += 1
    # Output the result
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The first line of input is parsed to get the number of friends (F), items (I), and the threshold (T). The subsequent lines contain each friend's opinions on the items.
2. **Opinion Collection**: Each friend's opinions are stored in a list where each element is a string representing their likes and dislikes.
3. **Counting Likes**: For each item, iterate through each friend's opinion string to count how many times the item is liked (denoted by 'Y').
4. **Threshold Check**: If the count of likes for an item meets or exceeds the threshold, that item is added to the result count.
5. **Result Output**: The total number of items that meet the threshold is printed as the final result.

This approach efficiently processes each item and friend's opinion, ensuring that we accurately count and compare against the threshold to determine the recommended items.
