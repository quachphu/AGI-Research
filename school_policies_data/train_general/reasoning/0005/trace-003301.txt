To solve this problem, we need to determine if a given string is a palindrome. A palindrome is a string that reads the same forwards and backwards. The solution involves checking if the string is equal to its reverse.

### Approach
1. **Read Input**: Read the input string from standard input.
2. **Check Palindrome**: Compare the string with its reverse. If they are the same, the string is a palindrome.
3. **Output Result**: Print "YES" if the string is a palindrome, otherwise print "NO".

The approach leverages Python's string slicing to reverse the string efficiently. By using slicing `[::-1]`, we can reverse the string in a concise and readable manner. The input is read using `input().strip()` to handle any accidental leading or trailing whitespace, although the problem guarantees that the input consists of lowercase letters only.

### Solution Code
```python
def is_palindrome():
    s = input().strip()
    print("YES" if s == s[::-1] else "NO")

is_palindrome()
```

### Explanation
1. **Reading Input**: The function `input().strip()` reads the input string and removes any leading or trailing whitespace. This ensures that any accidental whitespace does not affect the result.
2. **Reversing the String**: The slice `s[::-1]` creates a reversed copy of the string `s`. This is a common Python idiom for reversing sequences.
3. **Comparison and Output**: The code checks if the original string `s` is equal to its reversed version. If they are equal, "YES" is printed; otherwise, "NO" is printed.

This approach efficiently checks for palindromes with a time complexity of O(n), where n is the length of the string, due to the slicing operation and comparison. This is optimal for the given constraints (1 ≤ |S| ≤ 100).
