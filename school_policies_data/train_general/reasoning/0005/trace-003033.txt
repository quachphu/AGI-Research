To solve this problem, we need to determine the maximum number of steps Vasya can take in each direction specified by the given vectors without leaving the yard. The solution involves calculating the maximum valid steps for each vector and summing them up.

### Approach
1. **Input Reading**: Read the dimensions of the yard, initial coordinates, and the list of vectors.
2. **Processing Each Vector**: For each vector, calculate the maximum number of steps Vasya can take in the x and y directions without leaving the yard.
3. **Steps Calculation**:
   - For each direction (x and y), determine the maximum steps allowed by the yard's boundaries.
   - The valid steps for each vector are the minimum of the steps allowed by the x and y directions.
4. **Update Position**: After determining the valid steps for a vector, update Vasya's position and accumulate the total steps taken.

### Solution Code
```python
n, m = map(int, input().split())
xc, yc = map(int, input().split())
k = int(input())
vectors = [tuple(map(int, input().split())) for _ in range(k)]

x, y = xc, yc
total_steps = 0

for dx, dy in vectors:
    # Calculate maximum steps for x direction
    if dx == 0:
        s_x = float('inf')
    else:
        if dx > 0:
            numerator = n - x
        else:
            numerator = 1 - x
        s_upper = numerator // dx
        s_x = max(s_upper, 0) if s_upper >= 0 else 0
    
    # Calculate maximum steps for y direction
    if dy == 0:
        s_y = float('inf')
    else:
        if dy > 0:
            numerator_y = m - y
        else:
            numerator_y = 1 - y
        s_upper_y = numerator_y // dy
        s_y = max(s_upper_y, 0) if s_upper_y >= 0 else 0
    
    # Determine the minimum steps possible
    s = min(s_x, s_y)
    total_steps += s
    
    # Update current position
    x += s * dx
    y += s * dy

print(total_steps)
```

### Explanation
- **Input Reading**: The code reads the yard dimensions, initial coordinates, and vectors from standard input.
- **Steps Calculation**:
  - For each vector, the maximum steps allowed in the x and y directions are calculated separately. If the direction component (dx or dy) is zero, the steps allowed in that direction are considered infinite (no constraint).
  - The valid steps for the vector are the minimum of the steps allowed by the x and y directions.
- **Position Update**: After determining the valid steps for a vector, Vasya's position is updated, and the total steps are accumulated.

This approach ensures that Vasya's movement is always within the yard boundaries, and the solution efficiently computes the maximum steps for each vector using integer division and boundary checks.
