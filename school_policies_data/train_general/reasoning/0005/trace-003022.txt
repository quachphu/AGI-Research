To solve this problem, we need to determine the number of ways Chef can create a stack of pancakes with specific constraints on their radii. The solution involves dynamic programming to efficiently compute the number of valid configurations for each possible stack size up to 1000, which allows us to answer each test case in constant time after precomputing the results.

### Approach
1. **Dynamic Programming (DP) Setup**: We use a 2D DP array `dp` where `dp[k][m]` represents the number of ways to form a stack of `k` pancakes with the maximum radius `m`.
2. **Base Case**: The base case is `dp[1][1] = 1` because a stack with one pancake can only have a radius of 1.
3. **Transitions**: For each stack size `k` from 2 to 1000, and each possible maximum radius `m`:
   - If the previous maximum radius was `m`, the new radius can be any value from 1 to `m`, contributing `dp[k-1][m] * m` ways.
   - If the previous maximum radius was `m-1`, the new radius can be `m`, contributing `dp[k-1][m-1]` ways.
4. **Summing Results**: For each stack size `k`, the total number of valid configurations is the sum of `dp[k][m]` for all possible `m` from 1 to `k`.

### Solution Code
```python
MOD = 10**9 + 7
max_n = 1000

# Initialize DP table
dp = [[0] * (max_n + 2) for _ in range(max_n + 2)]
dp[1][1] = 1

ans = [0] * (max_n + 2)
ans[1] = 1

for k in range(2, max_n + 1):
    for m in range(1, k + 1):
        term1 = (dp[k-1][m] * m) % MOD
        term2 = dp[k-1][m-1] % MOD if m > 1 else 0
        dp[k][m] = (term1 + term2) % MOD
    ans[k] = sum(dp[k][1:k+1]) % MOD

# Read input and output results
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        N = int(input[i])
        print(ans[N])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precomputation**: We precompute the number of valid configurations for all stack sizes from 1 to 1000 using dynamic programming. This allows us to answer each test case in O(1) time.
2. **Dynamic Programming Transitions**: The transitions ensure that each new pancake's radius adheres to the problem constraints, either maintaining the current maximum radius or increasing it by 1.
3. **Efficiency**: The use of modulo operations ensures that we handle large numbers efficiently and avoid overflow.

This approach efficiently handles the constraints and provides quick responses to each test case after an initial precomputation step.
