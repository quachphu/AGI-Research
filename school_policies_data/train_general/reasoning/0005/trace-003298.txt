To solve this problem, we need to determine the last five digits of the factorial of a given number for multiple test cases. If the factorial has fewer than five digits, we must pad the result with leading zeros to ensure it is exactly five digits long.

### Approach
1. **Factorial Computation**: Directly computing the factorial of large numbers (up to 1000) is impractical due to the extremely large results. Instead, we compute the factorial modulo 100000 at each step to keep the intermediate results manageable and to efficiently capture the last five digits.
2. **Modulo Operation**: By using modulo 100000 during each multiplication step, we ensure that we only retain the last five digits of the intermediate result. This approach avoids overflow and keeps the computation efficient.
3. **Handling Leading Zeros**: After computing the modulo result, we format the result as a string with leading zeros to ensure it is always five digits long.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    cases = list(map(int, input[1:T+1]))
    MOD = 10**5
    for n in cases:
        result = 1
        for i in range(1, n+1):
            result = (result * i) % MOD
        print("{:05d}".format(result))

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings. The first element is the number of test cases, `T`, followed by the values for each test case.
2. **Modulo Factorial Calculation**: For each test case, we initialize the result to 1 and iteratively compute the factorial modulo 100000. This step ensures that we only keep the last five digits of the factorial at each multiplication step, which prevents overflow and keeps the numbers manageable.
3. **Formatting Output**: After computing the factorial modulo 100000, the result is formatted as a five-digit string with leading zeros using Python's string formatting capabilities. This ensures the output meets the requirement of exactly five digits, even if the result is smaller.

This approach efficiently handles the large numbers involved in factorial calculations and ensures the results are formatted correctly, providing an optimal and correct solution to the problem.
