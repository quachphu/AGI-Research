To solve this problem, we need to determine how many subarrays of a given array have a minimum value exactly equal to a specified integer for each query. The solution involves efficiently computing the minimum values for all possible subarrays and then using this precomputed information to quickly answer each query.

### Approach
1. **Precompute Minimum Values**: For each subarray, compute the minimum value and count how many times each minimum value occurs. This is done by iterating over all possible starting indices of subarrays and expanding each subarray while tracking the current minimum value.
2. **Efficient Query Handling**: Store the counts of each minimum value in a dictionary. For each query, simply look up the precomputed count to provide the result in constant time.

### Solution Code
```python
from collections import defaultdict

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    arr = list(map(int, input[ptr:ptr + n]))
    ptr += n
    counts = defaultdict(int)
    
    for i in range(n):
        current_min = arr[i]
        counts[current_min] += 1
        for j in range(i + 1, n):
            current_min = min(current_min, arr[j])
            counts[current_min] += 1
    
    q = int(input[ptr])
    ptr += 1
    for _ in range(q):
        k = int(input[ptr])
        ptr += 1
        print(counts.get(k, 0))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Precomputing Minimum Values**: For each starting index `i`, we initialize the minimum value to the element at `i`. As we expand the subarray by incrementing the ending index `j`, we update the current minimum and increment its count in the dictionary.
3. **Handling Queries**: After precomputing the counts, each query is answered by a simple dictionary lookup, which provides the result in constant time.

This approach ensures that we efficiently compute the required values in O(N^2) time for preprocessing and O(1) time per query, making it suitable for the given constraints.
