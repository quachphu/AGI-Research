To solve this problem, we need to find the smallest number greater than a given value X within a specified range [l, r] of an array for each query. If no such number exists, we should return -1.

### Approach
1. **Input Reading**: Read the input values which include the size of the array, the range [l, r], the number of queries, the array elements, and the queries themselves.
2. **Subarray Extraction**: For each query, extract the subarray from index l to r (inclusive).
3. **Filter and Find Minimum**: For each query value X, filter the elements in the subarray that are greater than X. If there are any such elements, find the minimum among them. If there are no such elements, return -1.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    l = int(input[ptr])
    ptr += 1
    r = int(input[ptr])
    ptr += 1
    q = int(input[ptr])
    ptr += 1
    A = list(map(int, input[ptr:ptr + n]))
    ptr += n
    queries = list(map(int, input[ptr:ptr + q]))
    
    for X in queries:
        subarray = A[l:r+1]
        candidates = [num for num in subarray if num > X]
        if candidates:
            print(min(candidates))
        else:
            print(-1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read as a single string and split into a list of strings for easy processing. We parse the integers sequentially to get the array size, range indices, number of queries, the array elements, and the query values.
2. **Subarray Extraction**: Using Python list slicing, we efficiently extract the subarray from index `l` to `r` (inclusive).
3. **Processing Queries**: For each query value X, we filter the subarray to find elements greater than X. If there are any such elements, we determine the minimum value using Python's built-in `min` function. If no elements are found, we return -1.

This approach ensures that we efficiently handle each query by directly working on the specified subarray and filtering elements as needed, providing a solution that is both straightforward and effective given the problem constraints.
