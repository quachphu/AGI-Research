To solve this problem, we need to determine if it's possible to select K different integers from the range 1 to N such that no two of the selected integers are consecutive.

### Approach
The key insight to solve this problem is understanding the maximum number of non-consecutive integers that can be selected from the range 1 to N. The maximum number of such integers is given by the formula \((\text{N} + 1) // 2\). This formula works because selecting every other number starting from 1 (or 2) ensures that no two selected numbers are consecutive. For example, if N is 5, the maximum non-consecutive numbers we can select are 1, 3, 5 (3 numbers), and if N is 6, the maximum numbers are 1, 3, 5 (3 numbers).

Once we compute this maximum value, we simply check if the given K is less than or equal to this maximum. If it is, the answer is "YES"; otherwise, the answer is "NO".

### Solution Code
```python
n, k = map(int, input().split())
max_k = (n + 1) // 2
print("YES" if k <= max_k else "NO")
```

### Explanation
1. **Reading Input**: The input values N and K are read from standard input.
2. **Compute Maximum Possible K**: Using the formula \((\text{N} + 1) // 2\), we calculate the maximum number of non-consecutive integers that can be selected from the range 1 to N.
3. **Check Condition**: We compare the given K with the computed maximum value. If K is less than or equal to the maximum value, we print "YES"; otherwise, we print "NO".

This approach efficiently determines the solution in constant time \(O(1)\), making it very efficient even for the upper constraint limits.
