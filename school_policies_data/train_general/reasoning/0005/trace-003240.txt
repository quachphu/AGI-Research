To solve this problem, we need to determine if we can restore the original sequence `a` from the given sequences `f` and `b`, or if it's impossible or ambiguous.

### Approach
1. **Understand the Problem**: The sequence `b` is derived by applying `f` to each element of `a`. Our task is to check if we can uniquely determine `a` from `b` using `f`.
2. **Build a Mapping**: Create a mapping from each value in `f` to the indices (1-based) where it occurs. This helps us quickly determine which indices in `f` produce a given value.
3. **Check for Validity**: For each value in `b`, check if it exists in the mapping. If any value in `b` is not found in the mapping, output "Impossible".
4. **Check for Ambiguity**: If any value in `b` maps to multiple indices in `f`, output "Ambiguity" because there's more than one possible sequence `a`.
5. **Construct the Result**: If all values in `b` map to exactly one index in `f`, construct and output the sequence `a`.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n, m = map(int, sys.stdin.readline().split())
    f = list(map(int, sys.stdin.readline().split()))
    b = list(map(int, sys.stdin.readline().split()))
    
    f_map = defaultdict(list)
    for idx, val in enumerate(f):
        f_map[val].append(idx + 1)  # ai is 1-based
    
    # Check for any element in b not present in f_map
    for bi in b:
        if bi not in f_map:
            print("Impossible")
            return
    
    # Check for ambiguity
    for bi in b:
        if len(f_map[bi]) > 1:
            print("Ambiguity")
            return
    
    # If all checks passed, construct the answer
    a = [f_map[bi][0] for bi in b]
    print("Possible")
    print(' '.join(map(str, a)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Mapping Construction**: We use a dictionary to map each value in `f` to the list of indices (1-based) where it appears. This helps in quickly checking which indices can produce a given value in `b`.
2. **Validity Check**: For each value in `b`, we check if it exists in the mapping. If not, it's impossible to form `a`, so we print "Impossible".
3. **Ambiguity Check**: If any value in `b` maps to multiple indices in `f`, there are multiple valid sequences `a`, so we print "Ambiguity".
4. **Result Construction**: If all values in `b` map to exactly one index in `f`, we construct the sequence `a` using these indices and print it.

This approach efficiently handles the constraints and ensures we correctly determine the possibility, impossibility, or ambiguity of restoring the original sequence.
