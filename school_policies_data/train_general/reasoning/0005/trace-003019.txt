To solve this problem, we need to perform three types of tree traversals (preorder, inorder, and postorder) on a binary tree based on the given input. The input specifies the structure of the tree, and our task is to output the node IDs in the order specified by each traversal algorithm.

### Approach
1. **Input Reading and Tree Construction**: Read the number of nodes and the details of each node to construct the tree using a dictionary. Each entry in the dictionary maps a node ID to its left and right children.
2. **Root Identification**: The root node is identified as the node that is not listed as a child of any other node.
3. **Tree Traversals**: Implement recursive functions for preorder, inorder, and postorder traversals. These functions will collect the node IDs in the required order.
4. **Output Formatting**: Print the results of each traversal in the specified format.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().splitlines()
    idx = 0
    n = int(input[idx])
    idx += 1
    
    tree = {}
    children = set()
    
    for _ in range(n):
        parts = input[idx].split()
        idx += 1
        node_id = int(parts[0])
        left = int(parts[1])
        right = int(parts[2])
        tree[node_id] = (left, right)
        if left != -1:
            children.add(left)
        if right != -1:
            children.add(right)
    
    # Find root
    root = None
    for node in tree:
        if node not in children:
            root = node
            break
    
    # Traversal functions
    def preorder(node, result):
        if node == -1:
            return
        result.append(node)
        preorder(tree[node][0], result)
        preorder(tree[node][1], result)
    
    def inorder(node, result):
        if node == -1:
            return
        inorder(tree[node][0], result)
        result.append(node)
        inorder(tree[node][1], result)
    
    def postorder(node, result):
        if node == -1:
            return
        postorder(tree[node][0], result)
        postorder(tree[node][1], result)
        result.append(node)
    
    pre_result = []
    preorder(root, pre_result)
    
    in_result = []
    inorder(root, in_result)
    
    post_result = []
    postorder(root, post_result)
    
    print("Preorder")
    print(" " + " ".join(map(str, pre_result)))
    print("Inorder")
    print(" " + " ".join(map(str, in_result)))
    print("Postorder")
    print(" " + " ".join(map(str, post_result)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Tree Construction**: The tree is built using a dictionary where each node ID maps to a tuple containing its left and right children. This allows efficient lookup of child nodes during traversal.
2. **Root Identification**: By collecting all child node IDs from the input, the root is identified as the node ID that does not appear in this collection.
3. **Traversal Functions**: 
   - **Preorder**: Visit the root node first, then recursively visit the left subtree, followed by the right subtree.
   - **Inorder**: Recursively visit the left subtree first, then the root node, followed by the right subtree.
   - **Postorder**: Recursively visit the left subtree, then the right subtree, and finally the root node.
4. **Output**: The results of each traversal are formatted as specified, with each line starting with a space followed by the node IDs separated by spaces.

This approach efficiently constructs the tree and performs the required traversals, ensuring the correct order of node visits and proper output formatting.
