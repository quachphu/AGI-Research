To solve this problem, we need to identify high school students who are suspected of being obese based on their Body Mass Index (BMI). The BMI is calculated using the formula: BMI = weight / (height^2). Students with a BMI of 25 or higher should be flagged and their IDs outputted in the order they were inputted.

### Approach
1. **Reading Input**: The input consists of multiple lines where each line contains a student's ID, weight, and height separated by commas.
2. **Parsing Data**: For each line, we split the input by commas to extract the student ID, weight, and height. These values are then converted to appropriate data types (integer for ID, float for weight and height).
3. **BMI Calculation**: Using the extracted weight and height, compute the BMI using the formula.
4. **Filtering Students**: Check if the computed BMI is 25 or higher. If so, add the student's ID to a result list.
5. **Output Results**: Print each student ID from the result list on a new line in the order they were inputted.

### Solution Code
```python
import sys

def main():
    obese_students = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        parts = [part.strip() for part in line.split(',')]
        student_id = int(parts[0])
        weight = float(parts[1])
        height = float(parts[2])
        bmi = weight / (height ** 2)
        if bmi >= 25:
            obese_students.append(student_id)
    for sid in obese_students:
        print(sid)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The code reads each line from standard input, strips any leading/trailing whitespace, and skips empty lines.
- **Parsing Data**: Each line is split into parts using commas as delimiters. The parts are stripped of any surrounding whitespace to handle potential input variations.
- **BMI Calculation**: The weight and height are converted to floats, and the BMI is computed using the formula.
- **Filtering Students**: If the computed BMI is 25 or higher, the student's ID is added to the result list.
- **Output Results**: The result list is iterated over, and each student ID is printed on a new line, maintaining the input order.

This approach ensures that we efficiently process each student's data, compute the BMI, and filter out the students who meet the obesity criteria, providing the correct output as specified.
