To solve this problem, we need to handle multiple datasets where each dataset involves processing a series of updates to a graph (adding bidirectional edges with costs) and answering queries about the shortest path between nodes. The solution must efficiently handle dynamic updates to the graph and provide real-time responses to queries using the latest graph state.

### Approach
1. **Graph Representation**: Use an adjacency list to represent the graph. Each node will have a list of tuples representing connected nodes and the corresponding edge cost.
2. **Dynamic Updates**: For each update, add two directed edges (both directions) to the adjacency list with the given cost.
3. **Shortest Path Calculation**: For each query, use Dijkstra's algorithm to compute the shortest path from the start node to the destination node using the current state of the graph. Dijkstra's algorithm is chosen due to its efficiency for graphs with non-negative weights, which fits the problem constraints.

### Solution Code
```python
import heapq
import sys

def dijkstra(a, b, adj, n):
    if a == b:
        return 0
    INF = float('inf')
    dist = [INF] * (n + 1)
    dist[a] = 0
    heap = [(0, a)]
    visited = [False] * (n + 1)
    
    while heap:
        current_dist, u = heapq.heappop(heap)
        if u == b:
            return current_dist
        if visited[u]:
            continue
        visited[u] = True
        for v, w in adj[u]:
            if not visited[v] and dist[v] > current_dist + w:
                dist[v] = current_dist + w
                heapq.heappush(heap, (dist[v], v))
    return dist[b] if dist[b] != INF else INF

def main():
    input = sys.stdin.read().split()
    ptr = 0
    while True:
        n = int(input[ptr])
        k = int(input[ptr+1])
        ptr += 2
        if n == 0 and k == 0:
            break
        adj = [[] for _ in range(n + 1)]
        outputs = []
        for _ in range(k):
            cmd = input[ptr]
            if cmd == '0':
                a = int(input[ptr+1])
                b = int(input[ptr+2])
                ptr += 3
                res = dijkstra(a, b, adj, n)
                outputs.append(res if res != float('inf') else -1)
            else:
                c = int(input[ptr+1])
                d = int(input[ptr+2])
                e = int(input[ptr+3])
                ptr += 4
                adj[c].append((d, e))
                adj[d].append((c, e))
        print('\n'.join(map(str, outputs)))
    return

if __name__ == "__main__":
    main()
```

3. **Query Handling**: For each query (starting with '0'), we use Dijkstra's algorithm to compute the shortest path from the start node to the destination node. If the destination is unreachable, we return -1; otherwise, we return the computed shortest path cost.
4. **Efficiency**: Dijkstra's algorithm is efficient for graphs with non-negative weights and works well within the problem constraints (n up to 100 and k up to 5000).
