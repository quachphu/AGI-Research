To solve this problem, we need to determine the minimum sum of money that cannot be formed using any combination of given banknotes. If all sums can be formed, we should return -1.

### Approach
The key insight to solve this problem efficiently is based on the presence of the value 1 in the list of banknotes:
1. If the list contains the value 1, then any sum can be formed by using 1 as many times as needed. Hence, there are no unfortunate sums, and the result should be -1.
2. If the list does not contain the value 1, the smallest sum that cannot be formed is 1, as we cannot form the sum 1 without a banknote of value 1.

### Solution Code
```python
def solve():
    n = int(input())
    a = list(map(int, input().split()))
    print(-1 if 1 in a else 1)

solve()
```

### Explanation
1. **Reading Input:** The function reads the number of banknotes and their values from the standard input.
2. **Check for Value 1:** The function checks if the value 1 is present in the list of banknotes.
3. **Determine Result:** 
   - If 1 is present, it prints -1 because all sums can be formed.
   - If 1 is not present, it prints 1 because 1 is the smallest sum that cannot be formed.

This approach efficiently determines the result in O(n) time complexity, where n is the number of banknotes, by simply checking the presence of the value 1. This ensures the solution is optimal and handles the constraints effectively.
