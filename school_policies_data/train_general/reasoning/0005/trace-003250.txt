To solve this problem, we need to determine the maximum length of a string that can be formed using the letters "R", "K", and "V" under specific constraints. The string must use at most two different letters and no two adjacent letters can be the same. The goal is to maximize the length of such a string given the counts of each letter.

### Approach
1. **Constraints Analysis**: The string can use at most two different letters, and adjacent letters must be different. This means we can only consider pairs of letters and determine the maximum length achievable with each pair.
2. **Pair Evaluation**: For each pair of letters (R-K, R-V, K-V), evaluate the maximum length of the string that can be formed using those two letters. This is done by considering the counts of the two letters and ensuring they alternate without repetition.
3. **Mathematical Insight**: For two letters with counts `x` and `y`, the maximum length of the alternating string is:
   - If the difference between counts is at most 1, the sum `x + y`.
   - Otherwise, `2 * min(x, y) + 1` (to handle the larger count effectively by alternating as much as possible).
4. **Edge Cases**: Handle cases where one or both counts in a pair are zero, which can only form a string of length 0 or 1.

### Solution Code
```python
import sys

def max_length(a, b, c):
    def pair(x, y):
        if x == 0 and y == 0:
            return 0
        if x == 0 or y == 0:
            return 1 if (x + y) >= 1 else 0
        diff = abs(x - y)
        if diff <= 1:
            return x + y
        return 2 * min(x, y) + 1
    
    rk = pair(a, b)
    rv = pair(a, c)
    kv = pair(b, c)
    return max(rk, rv, kv)

T = int(sys.stdin.readline())
for _ in range(T):
    a, b, c = map(int, sys.stdin.readline().split())
    print(max_length(a, b, c))
```

### Explanation
- **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency, especially given the constraints.
- **Pair Function**: The helper function `pair(x, y)` computes the maximum length for a given pair of counts. It handles edge cases where one or both counts are zero and applies the mathematical formula for alternating counts.
- **Evaluating All Pairs**: For each test case, we compute the maximum length for all three possible pairs (R-K, R-V, K-V) and return the maximum value among them.

This approach ensures that we efficiently determine the longest possible string under the given constraints, considering all valid pairs and their respective counts.
