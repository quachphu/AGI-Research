To solve this problem, we need to determine the minimum number of days required to repair a highway such that at least half of it is high-quality pavement. The weather alternates between good days (when high-quality pavement can be laid) and bad days (when low-quality pavement can be laid). The solution must efficiently handle large input values up to \(10^9\).

### Approach
1. **Understand the Requirements**: We need at least \(\lceil \frac{n}{2} \rceil\) high-quality pavement units. This is calculated as \((n + 1) // 2\).
2. **Weather Cycles**: The weather alternates between `g` good days and `b` bad days. The key is to determine how many full cycles of good and bad days are needed to meet the high-quality requirement.
3. **Calculate Minimum Days**:
   - If the required high-quality days `h` can be met within the first `g` good days, the minimum days needed is simply `max(h, n)`.
   - If more than `g` good days are needed, compute the number of full cycles required and any remaining days. This gives the total days needed to meet the high-quality requirement, which is then compared with `n` to ensure all units are repaired.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    T = int(data[0])
    index = 1
    for _ in range(T):
        n = int(data[index])
        g = int(data[index+1])
        b = int(data[index+2])
        index += 3
        h = (n + 1) // 2
        if h <= g:
            res = max(h, n)
        else:
            k = (h - 1) // g
            r = h - k * g
            d1 = k * (g + b) + r
            res = max(d1, n)
        print(res)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **High-Quality Requirement Calculation**: The required high-quality days `h` is calculated as \((n + 1) // 2\).
3. **Direct Check**: If `h` can be met within the first `g` good days, the result is the maximum of `h` and `n` to ensure all units are repaired.
4. **Full Cycles Calculation**: For cases requiring more than `g` good days, compute the number of full cycles and remaining days to determine the total days needed. The result is the maximum of this value and `n` to ensure all units are repaired.

This approach efficiently handles large values and ensures the solution is both optimal and correct.
