To solve this problem, we need to determine the maximum number of banknotes Oleg can collect from the safes without encountering any security guards. Oleg starts at a position between two guards, and he can only move within the range between these two guards.

### Approach
1. **Problem Analysis**: Oleg can move freely between the positions of the two guards but cannot step into the positions where the guards are stationed. The guards are positioned such that one is to the left of Oleg and the other is to the right. Therefore, Oleg can only access safes that are strictly between the positions of the two guards.
2. **Key Insight**: The maximum number of banknotes Oleg can collect is determined by counting how many banknotes are located in the safes that lie between the positions of the two guards (excluding the guards' positions themselves).
3. **Algorithm**: We simply count the number of banknotes that are located in the interval (b, c), where b is the position of the left guard and c is the position of the right guard.

### Solution Code
```python
a, b, c = map(int, input().split())
n = int(input())
x = list(map(int, input().split()))
count = 0
for num in x:
    if b < num < c:
        count += 1
print(count)
```

### Explanation
1. **Reading Input**: The first line of input contains the positions of Oleg (a), the left guard (b), and the right guard (c). The second line gives the number of banknotes, and the third line lists the positions of these banknotes.
2. **Counting Valid Banknotes**: We iterate through each banknote's position and check if it lies strictly between the positions of the two guards. If it does, we increment our count.
3. **Output the Result**: Finally, we print the count of valid banknotes, which represents the maximum number of banknotes Oleg can collect without encountering the guards.

This approach efficiently checks each banknote's position in linear time, making it optimal for the given problem constraints.
