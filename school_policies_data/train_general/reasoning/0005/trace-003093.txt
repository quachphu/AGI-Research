2. **Iterate Over Possible Left Elements**: For each possible number of problems solved from the left (from 0 to the maximum left count), calculate how many problems can be solved from the right end of the remaining list.
3. **Combine Left and Right Counts**: For each combination of left and right counts, keep track of the maximum number of problems solved.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))

max_l = 0
for num in a:
    if num <= k:
        max_l += 1
    else:
        break

max_total = 0
for l in range(max_l + 1):
    subarray = a[l:]
    r = 0
    for num in reversed(subarray):
        if num <= k:
            r += 1
        else:
            break
    max_total = max(max_total, l + r)

print(max_total)
```

### Explanation
1. **Reading Input**: The input consists of two integers `n` (number of problems) and `k` (Mishka's skill), followed by a list of integers representing the difficulty of each problem.
2. **Calculate Maximum Left Elements**: We iterate through the list from the left to find the maximum number of consecutive problems Mishka can solve starting from the left end.
3. **Iterate Over Possible Left Counts**: For each possible count of problems solved from the left (from 0 to the maximum left count), we consider the remaining subarray and determine how many problems can be solved starting from the right end of this subarray.
4. **Determine Maximum Problems Solved**: By combining the counts from the left and right ends for each possible scenario, we keep track of the maximum number of problems Mishka can solve.

This approach efficiently checks all possible valid combinations of left and right problem counts, ensuring that we find the optimal solution. The complexity is linear with respect to the number of problems, making it efficient for the given constraints.
