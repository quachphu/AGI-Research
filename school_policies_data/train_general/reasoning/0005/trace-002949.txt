To solve this problem, we need to determine the number of ways to arrange Sid's friends such that no two boys are adjacent. If it's impossible to arrange them under the given constraints, we should return -1.

### Approach
1. **Constraints Analysis**: The key observation is that boys cannot be adjacent. Therefore, we need enough girls to separate the boys. Specifically, the number of boys (N) must not exceed the number of girls (M) plus one (i.e., \(N \leq M + 1\)). If this condition is violated, it's impossible to arrange them, and we return -1.

2. **Combinatorial Arrangement**:
   - **Girls Arrangement**: The girls can be arranged in \(M!\) ways.
   - **Boys Placement**: The girls create \(M + 1\) slots where boys can be placed. We need to choose \(N\) slots out of these \(M + 1\) slots, which can be done in \(\binom{M+1}{N}\) ways.
   - **Boys Arrangement**: The boys can be arranged in \(N!\) ways within the chosen slots.

3. **Modular Arithmetic**: Given the constraints, we use modular arithmetic with a modulus of \(10^9 + 7\) to handle large numbers efficiently.

### Solution Code
```python
import sys

MOD = 10**9 + 7
max_n = 51

# Precompute factorials and inverse factorials modulo MOD
fact = [1] * (max_n + 1)
for i in range(1, max_n + 1):
    fact[i] = fact[i-1] * i % MOD

inv_fact = [1] * (max_n + 1)
inv_fact[max_n] = pow(fact[max_n], MOD - 2, MOD)
for i in range(max_n - 1, -1, -1):
    inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

def comb(n, k):
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % MOD * inv_fact[n - k] % MOD

def main():
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        M = int(input[idx])
        N = int(input[idx + 1])
        idx += 2
        if N > M + 1:
            print(-1)
        else:
            c = comb(M + 1, N)
            res = fact[M] * fact[N] % MOD
            res = res * c % MOD
            print(res)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precomputation**: We precompute factorials and their modular inverses up to 51 (since the maximum value of \(M\) is 50, leading to \(M + 1 = 51\)).

2. **Combination Calculation**: Using the precomputed values, we efficiently calculate combinations \(\binom{M+1}{N}\) using modular arithmetic.

3. **Efficient Input Handling**: The input is read all at once for efficiency, especially given the large possible number of test cases (up to 100,000).

4. **Modular Arithmetic**: All calculations are performed modulo \(10^9 + 7\) to prevent overflow and ensure results fit within standard integer limits.

This approach ensures that we handle up to 100,000 test cases efficiently, with each test case processed in constant time after the initial precomputation.
