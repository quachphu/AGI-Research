To solve this problem, we need to calculate the total number of handshakes that occur when each member of the Board of Directors of Biana Inc shakes hands with every other member exactly once. The solution involves using a mathematical formula derived from combinatorial principles.

### Approach
The problem can be efficiently solved using the combination formula to determine the number of ways to choose 2 people out of N, which is given by the formula \( \frac{N \times (N-1)}{2} \). This formula accounts for each pair of people shaking hands exactly once.

1. **Reading Input:** The input consists of multiple test cases. The first line contains the number of test cases, T. Each of the next T lines contains an integer N, representing the number of board members.
2. **Computing Handshakes:** For each test case, compute the number of handshakes using the combination formula \( \frac{N \times (N-1)}{2} \).

### Solution Code
```python
import sys

def main():
    data = sys.stdin.read().split()
    T = int(data[0])
    for n_str in data[1:T+1]:
        n = int(n_str)
        print(n * (n - 1) // 2)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently:** The code reads all input at once and splits it into a list of strings. This approach is efficient for handling large input sizes.
2. **Processing Each Test Case:** The first element of the input list is the number of test cases, T. The subsequent elements are the values of N for each test case. We process each value of N to compute the number of handshakes using the formula \( \frac{N \times (N-1)}{2} \), ensuring integer division to avoid floating-point results.
3. **Output the Result:** For each test case, the result is printed immediately after computation.

This approach efficiently handles the constraints and provides the correct result for each test case in constant time, \( O(1) \), after reading the input.
