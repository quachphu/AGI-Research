To solve this problem, we need to reconstruct the original list A from the given list B. Each element in list B is the average of the elements in list A up to that point. By reversing the process used to create list B, we can determine each element of list A using the derived formula.

### Approach
1. **Understanding the Relationship**: Each element in list B is the average of the elements in list A up to that point. For example, the i-th element in B (0-based index) is the average of the first i+1 elements of A.
2. **Formulating the Conversion**: Using the relationship between sums and averages, we can derive that each element in A can be computed using the formula:
   - \( A[i] = (i+1) \times B[i] - i \times B[i-1] \) for i ≥ 1.
   - For the first element (i=0), \( A[0] = B[0] \).

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    b = list(map(int, input[1:n+1]))
    a = []
    for i in range(n):
        if i == 0:
            a_val = b[i]
        else:
            a_val = (i + 1) * b[i] - i * b[i - 1]
        a.append(str(a_val))
    print(' '.join(a))

main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first value is the integer N, the size of list B. The subsequent values are the elements of list B.
2. **Reconstructing List A**: 
   - For the first element of A, it is directly taken from the first element of B.
   - For subsequent elements, each element of A is calculated using the derived formula, which leverages the previous elements in B to compute the current element in A.
3. **Output**: The elements of list A are printed as space-separated integers.

This approach efficiently computes each element of A in linear time, making it optimal for the given problem constraints.
