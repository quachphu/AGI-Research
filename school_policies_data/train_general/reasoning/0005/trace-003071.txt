To solve this problem, we need to determine the number of alignment steps required for the mountain peaks' heights to stabilize, where each step updates each mountain's height (except the first and last) to the median of itself and its two neighbors. The solution must efficiently handle large input sizes up to 500,000 elements.

### Approach
1. **Simulation with Active Tracking**: Instead of recalculating the entire array in each step, track which positions might change and only process those. This reduces redundant computations.
2. **Efficient Updates**: Use two arrays to keep track of the current and previous states, ensuring that updates are based on the previous state to avoid interference during the same step.
3. **Active Set Management**: Maintain a set of positions that might change in the next step, derived from the neighbors of positions that changed in the current step.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    
    if n <= 2:
        print(0)
        print(' '.join(map(str, a)))
        return
    
    prev = a.copy()
    curr = prev.copy()
    steps = 0
    active = set(range(1, n-1))  # 0-based indices for positions 1 to n-2
    
    while active:
        next_active = set()
        changed = False
        curr = prev.copy()
        
        for i in active:
            if i < 1 or i >= n-1:
                continue
            left = prev[i-1]
            mid = prev[i]
            right = prev[i+1]
            sorted_vals = sorted([left, mid, right])
            median = sorted_vals[1]
            if median != mid:
                curr[i] = median
                changed = True
                # Add neighbors to next_active
                for j in [i-1, i, i+1]:
                    if 0 < j < n-1:  # positions 1..n-2 (0-based)
                        next_active.add(j)
        
        if not changed:
            break
        
        prev, curr = curr, prev
        steps += 1
        active = next_active
    
    print(steps)
    print(' '.join(map(str, prev)))

if __name__ == "__main__":
    main()
```

4. **Simulation Loop**: For each step, compute the new height for each active position. If a change occurs, mark the position and its neighbors for the next step.
