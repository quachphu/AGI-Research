To solve this problem, we need to determine how many ants Mole will eat after each query segment. An ant is freed if it wins all its battles within the segment, which happens when its strength divides the strength of every other ant in the segment. The solution involves efficiently computing the greatest common divisor (GCD) of the segment and counting how many times this GCD appears in the segment.

### Approach
1. **Segment Tree for GCD Queries**: We use a segment tree to efficiently compute the GCD of any given range. This allows us to answer each query in logarithmic time.
2. **Frequency Map**: We preprocess the ant strengths to create a dictionary that maps each strength value to a sorted list of its positions. This allows us to quickly count occurrences of the GCD within any query range using binary search.

### Solution Code
```python
import sys
import math
from bisect import bisect_left, bisect_right
from collections import defaultdict

class SegmentTree:
    def __init__(self, data):
        self.n = len(data)
        self.size = 1
        while self.size < self.n:
            self.size <<= 1
        self.tree = [0] * (2 * self.size)
        # Fill leaves
        for i in range(self.n):
            self.tree[self.size + i] = data[i]
        # Build the tree
        for i in range(self.size - 1, 0, -1):
            self.tree[i] = math.gcd(self.tree[2 * i], self.tree[2 * i + 1])
    
    def query_gcd(self, l, r):
        # Convert to 0-based indices
        l -= 1
        r -= 1
        res = 0
        l += self.size
        r += self.size
        while l <= r:
            if l % 2 == 1:
                res = math.gcd(res, self.tree[l])
                l += 1
            if r % 2 == 0:
                res = math.gcd(res, self.tree[r])
                r -= 1
            l >>= 1
            r >>= 1
        return res

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    s = list(map(int, input[ptr:ptr + n]))
    ptr += n
    
    # Build segment tree
    st = SegmentTree(s)
    
    # Build frequency map
    freq = defaultdict(list)
    for idx in range(n):
        val = s[idx]
        freq[val].append(idx + 1)  # 1-based indices
    
    # Sort each list of indices
    for key in freq:
        freq[key].sort()
    
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        l = int(input[ptr])
        ptr += 1
        r = int(input[ptr])
        ptr += 1
        
        current_gcd = st.query_gcd(l, r)
        
        if current_gcd not in freq:
            print(r - l + 1)
        else:
            positions = freq[current_gcd]
            left = bisect_left(positions, l)
            right = bisect_right(positions, r)
            count = right - left
            print((r - l + 1) - count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Segment Tree Construction**: The segment tree is built to store the GCD of each segment. This allows us to quickly compute the GCD for any query range in O(log n) time.
2. **Frequency Map**: For each unique strength value, we maintain a sorted list of indices where it occurs. This allows us to efficiently count occurrences of the GCD within any query range using binary search, which operates in O(log k) time where k is the number of occurrences of the GCD.
3. **Query Processing**: For each query, we compute the GCD of the segment. Using the frequency map, we determine how many times this GCD appears in the segment. The result is the total number of ants minus the count of those that are freed.

This approach ensures that each query is processed efficiently, making the solution scalable even for large input sizes.
