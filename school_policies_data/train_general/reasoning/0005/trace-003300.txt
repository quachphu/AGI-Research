To solve this problem, we need to find the shortest path between two railway stations given a set of direct connections with distances. This is a classic shortest path problem in graph theory, which can be efficiently solved using the Floyd-Warshall algorithm. This algorithm computes the shortest paths between all pairs of nodes in a graph, making it ideal for handling multiple queries efficiently.

### Approach
1. **Input Parsing**: Read the number of stations (N), direct connections (M), station names, and queries.
2. **Graph Representation**: Use a distance matrix to represent the graph where each entry `dist[i][j]` holds the shortest distance between stations i and j.
3. **Initialization**: Initialize the distance matrix with infinity (representing unreachable paths) except for diagonal elements (distance from a station to itself is zero).
4. **Populate Direct Connections**: Update the distance matrix with given direct connections, ensuring to keep the shortest distance for each connection.
5. **Floyd-Warshall Algorithm**: Compute the shortest paths between all pairs of stations using dynamic programming to consider intermediate nodes.
6. **Query Processing**: For each query, retrieve the precomputed shortest path from the distance matrix.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().splitlines()
    idx = 0
    N, M = map(int, input[idx].split())
    idx += 1
    station_names = input[idx].split()
    idx += 1
    station_to_index = {name: i for i, name in enumerate(station_names)}
    INF = float('inf')
    dist = [[INF] * N for _ in range(N)]
    for i in range(N):
        dist[i][i] = 0
    for _ in range(M):
        parts = input[idx].split()
        s1, s2, d = parts[0], parts[1], int(parts[2])
        u = station_to_index[s1]
        v = station_to_index[s2]
        if dist[u][v] > d:
            dist[u][v] = d
            dist[v][u] = d
        idx += 1
    # Floyd-Warshall Algorithm
    for k in range(N):
        for i in range(N):
            for j in range(N):
                if dist[i][j] > dist[i][k] + dist[k][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
    Q = int(input[idx])
    idx += 1
    for _ in range(Q):
        s, d = input[idx].split()
        idx += 1
        u = station_to_index[s]
        v = station_to_index[d]
        print(dist[u][v])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Input Parsing**: The input is read line by line, and station names are stored in a list. A dictionary maps each station name to an index for easier matrix operations.
2. **Graph Initialization**: The distance matrix is initialized with infinity to represent unreachable paths initially. Direct connections are then added, updating the matrix with the shortest distances.
3. **Floyd-Warshall Algorithm**: This algorithm iteratively updates the shortest paths considering each station as an intermediate node. It ensures that the shortest path between any two stations is found by considering all possible intermediate stops.
4. **Query Handling**: After precomputing all shortest paths, each query is answered in constant time by directly accessing the precomputed distance matrix.

This approach efficiently handles multiple queries by precomputing all possible shortest paths, making it well-suited for scenarios with a large number of queries. The use of Floyd-Warshall ensures that the solution is both optimal and easy to implement for the given problem constraints.
