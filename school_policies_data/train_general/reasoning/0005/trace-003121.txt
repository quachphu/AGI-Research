To solve this problem, we need to read a list of integers from standard input, sort them in non-decreasing order, and print the sorted list. The challenge is to efficiently handle large input sizes, up to one million elements, while ensuring optimal performance.

### Approach
1. **Reading Input Efficiently**: Using `sys.stdin.read()` to read all input at once and splitting it into a list of strings. This method is more efficient than reading line by line for very large inputs.
2. **Parsing Input**: The first element of the input is the count of numbers, `t`, followed by `t` integers. Convert these integers into a list.
3. **Sorting**: Utilize Python's built-in sort function, which is efficient and runs in O(n log n) time complexity.
4. **Output Efficiently**: Convert the sorted list into a single string with newline separators and print it in one go. This reduces the number of I/O operations, which is crucial for large outputs.

### Solution Code
```python
import sys

def main():
    data = sys.stdin.read().split()
    if not data:
        return
    t = int(data[0])
    nums = list(map(int, data[1:1 + t]))
    nums.sort()
    print('\n'.join(map(str, nums)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The entire input is read at once using `sys.stdin.read().split()`, which splits the input into a list of strings based on any whitespace. This handles both spaces and newlines efficiently.
2. **Parsing**: The first element of the list is converted to an integer `t`, representing the number of subsequent integers. The next `t` elements are converted to integers and stored in a list.
3. **Sorting**: The list of integers is sorted in-place using Python's efficient Timsort algorithm.
4. **Output**: The sorted list is converted to a string where each integer is separated by a newline character. This single string is printed in one operation, which is much faster than printing each integer individually for large datasets.

This approach ensures that both input reading and output writing are handled efficiently, making the solution suitable for the upper limits of the problem constraints.
