To solve this problem, we need to compute the sum of the greatest common divisors (GCD) for all paths in a tree where one endpoint is an ancestor of the other. The tree is rooted at vertex 1, and each vertex has a given beauty value. The challenge is to efficiently compute this sum given the constraints.

### Approach
1. **Tree Structure**: The tree is represented using an adjacency list. We use BFS to determine the parent-child relationships starting from the root (vertex 1).
2. **GCD Tracking**: For each node, we maintain a list of tuples where each tuple contains a GCD value and the count of paths that result in that GCD. This helps in efficiently tracking and merging GCD values as we traverse the tree.
3. **BFS Traversal**: Nodes are processed in BFS order to ensure that each node is processed after its parent, allowing us to use the parent's GCD information to compute the current node's GCD values.
4. **Merge GCD Values**: For each node, compute new GCD values by combining the parent's GCD values with the current node's beauty value. Merge these values to avoid redundant calculations and sum their contributions.

    children = [[] for _ in range(n + 1)]
    visited = [False] * (n + 1)
    q = deque()
    q.append(1)
    visited[1] = True

    while q:
        u = q.popleft()
        for v in edges[u]:
            if not visited[v]:
                visited[v] = True
                parent[v] = u
                children[u].append(v)
                q.append(v)

    # Determine processing order (BFS order)
    processing_order = []
    q = deque()
    q.append(1)
    while q:
        u = q.popleft()
        processing_order.append(u)
        for v in children[u]:
            q.append(v)

    total = 0
    gcd_list = [[] for _ in range(n + 1)]  # Stores list of (g, cnt) for each node

    for u in processing_order:
        if u == 1:
            current_gcd = [(x[u], 1)]
            sum_u = x[u]
        else:
            # Get parent's GCD list
            p = parent[u]
            parent_gcds = gcd_list[p]
            temp = []
            for g, cnt in parent_gcds:
                new_g = math.gcd(g, x[u])
                temp.append((new_g, cnt))
            # Add the path consisting of only the current node
            temp.append((x[u], 1))
            # Merge the temp list
            merged = {}
            for g, cnt in temp:
                merged[g] = merged.get(g, 0) + cnt
            current_gcd = list(merged.items())
            sum_u = sum(g * cnt for g, cnt in current_gcd)
        # Update total
        total = (total + sum_u) % MOD
        gcd_list[u] = current_gcd

    print(total % MOD)
