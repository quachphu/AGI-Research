To solve this problem, we need to determine the optimal way to maintain JOI Park by building underpasses and repairing remaining roads to minimize the total cost. The solution involves calculating the shortest paths from a starting node, evaluating different underpass configurations, and selecting the one with the lowest cost.

### Approach
1. **Compute Shortest Paths**: Use Dijkstra's algorithm to find the shortest path from node 1 to all other nodes. This helps determine the distance of each node from node 1.
2. **Evaluate Road Contributions**: For each road, determine the maximum distance (max_d) from node 1 of its two endpoints. Roads with both endpoints within a certain distance from node 1 can be removed if underpasses are built up to that distance.
3. **Prefix Sum for Efficient Calculation**: Sort roads by their max_d values and compute a prefix sum array to efficiently calculate the sum of road lengths that can be removed for different distances.
4. **Evaluate Costs for Distances**: For each unique node distance, compute the total cost of building underpasses up to that distance and repairing the remaining roads. Track the minimum cost encountered.

### Solution Code
```python
import heapq
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    M = int(input[ptr])
    ptr += 1
    C = int(input[ptr])
    ptr += 1
    
    roads = []
    for _ in range(M):
        a = int(input[ptr])
        ptr += 1
        b = int(input[ptr])
        ptr += 1
        d = int(input[ptr])
        ptr += 1
        roads.append((a, b, d))
    
    # Dijkstra's algorithm to compute distances from node 1
    adj = [[] for _ in range(N + 1)]
    for a, b, di in roads:
        adj[a].append((b, di))
        adj[b].append((a, di))
    
    dist = [float('inf')] * (N + 1)
    dist[1] = 0
    heap = [(0, 1)]
    visited = [False] * (N + 1)
    
    while heap:
        current_dist, u = heapq.heappop(heap)
        if visited[u]:
            continue
        visited[u] = True
        for v, w in adj[u]:
            if not visited[v] and dist[v] > current_dist + w:
                dist[v] = current_dist + w
                heapq.heappush(heap, (dist[v], v))
    
    # Collect node distances and unique distances
    node_distances = [dist[i] for i in range(1, N + 1)]
    unique_distances = sorted(list(set(node_distances)))
    
    # Process roads to get max_d and sort them
    road_max_d = []
    for a, b, di in roads:
        da = dist[a]
        db = dist[b]
        maxd = max(da, db)
        road_max_d.append((maxd, di))
    
    # Sort roads by maxd
    sorted_roads = sorted(road_max_d, key=lambda x: x[0])
    maxd_list = [x[0] for x in sorted_roads]
    prefix = [0]
    current_sum = 0
    for r in sorted_roads:
        current_sum += r[1]
        prefix.append(current_sum)
    
    total_road_sum = sum(di for _, di in sorted_roads)
    min_cost = float('inf')
    
    for d in unique_distances:
        idx = bisect.bisect_right(maxd_list, d)
        sum_removed = prefix[idx]
        cost = C * d + (total_road_sum - sum_removed)
        if cost < min_cost:
            min_cost = cost
    
    print(min_cost)

if __name__ == '__main__':
    main()
```

2. **Road Processing**: Each road's maximum distance (max_d) from node 1 is calculated. Roads are sorted by this max_d to facilitate efficient range queries.
3. **Prefix Sum Array**: This array helps quickly compute the sum of road lengths that can be removed for any given distance threshold.
4. **Cost Evaluation**: By iterating over unique node distances, we evaluate the cost of building underpasses up to each distance and maintaining the remaining roads, ensuring we find the minimum cost efficiently using binary search and prefix sums.
