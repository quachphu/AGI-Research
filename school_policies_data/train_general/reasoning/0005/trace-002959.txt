To solve this problem, we need to count the number of valid triplets (A_i, B_j, C_k) such that A_i < B_j < C_k. Given the constraints, a direct approach of checking all possible triplets would be too slow, so we use a more efficient method involving sorting and binary search.

### Approach
1. **Sorting**: First, sort the arrays A and C. This allows us to use binary search to efficiently count elements that meet the required conditions.
2. **Binary Search**: For each element B_j in the middle parts array B:
   - Use binary search to find the number of elements in A that are strictly less than B_j.
   - Use binary search to find the number of elements in C that are strictly greater than B_j.
3. **Count Valid Triplets**: For each B_j, multiply the counts obtained from the binary searches to get the number of valid triplets involving that B_j. Sum these products for all elements in B.

### Solution Code
```python
import bisect

n = int(input())
A = list(map(int, input().split()))
B = list(map(int, input().split()))
C = list(map(int, input().split()))

A.sort()
C.sort()

total = 0
for b in B:
    a_count = bisect.bisect_left(A, b)
    c_count = len(C) - bisect.bisect_right(C, b)
    total += a_count * c_count

print(total)
```

### Explanation
1. **Sorting**: By sorting arrays A and C, we can leverage binary search to quickly determine the counts of elements meeting the required conditions.
2. **Binary Search for A**: Using `bisect.bisect_left` on the sorted array A gives the position where B_j would be inserted to maintain order, which corresponds to the number of elements in A that are strictly less than B_j.
3. **Binary Search for C**: Using `bisect.bisect_right` on the sorted array C gives the position where B_j would be inserted, and subtracting this from the length of C gives the number of elements in C that are strictly greater than B_j.
4. **Summing Valid Triplets**: For each element in B, compute the product of valid elements from A and C, and sum these products to get the total number of valid altars.

This approach efficiently reduces the problem complexity from O(N^3) to O(N log N), making it feasible for large input sizes up to 100,000.
