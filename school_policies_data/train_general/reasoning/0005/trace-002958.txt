To solve this problem, we need to convert a given three-digit integer composed of digits '1' and '9' into another integer where each '1' is replaced with '9' and each '9' is replaced with '1'. The solution involves reading the input, transforming each digit according to the specified replacements, and then outputting the result.

### Approach
1. **Read Input**: Read the input as a string to directly access each digit without converting it to an integer first.
2. **Replace Digits**: Iterate over each character in the input string. For each character:
   - If the character is '1', replace it with '9'.
   - If the character is '9', replace it with '1'.
3. **Construct Result**: Combine the transformed characters into a new string.
4. **Output Result**: Print the resulting string, which is the transformed integer.

### Solution Code
```python
n = input().strip()
converted = []
for c in n:
    converted.append('9' if c == '1' else '1')
print(''.join(converted))
```

### Explanation
1. **Reading Input**: The input is read as a string to facilitate character-wise manipulation.
2. **Digit Replacement**: Each character in the input string is checked. If it is '1', it is replaced with '9'; if it is '9', it is replaced with '1'. This transformation is done using a simple loop and conditional checks.
3. **Result Construction**: The transformed characters are collected into a list and then joined into a single string.
4. **Output**: The resulting string is printed, which represents the integer with digits swapped as required.

This approach efficiently handles the problem constraints and ensures that the solution is both straightforward and optimal for the given input range.
