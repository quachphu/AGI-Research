To solve this problem, we need to determine the number of ways Alice can select two boxes such that the sum of chocolates in them equals a given value \( K \). The solution must efficiently handle large input sizes up to \( 10^5 \) boxes per test case.

### Approach
1. **Frequency Map**: Use a frequency map (dictionary) to count occurrences of each chocolate count in the boxes. This helps in quickly determining how many times each number of chocolates appears.
2. **Pair Calculation**: For each unique number of chocolates \( a \) in the frequency map:
   - Calculate the complement \( K - a \).
   - If \( a \) is less than the complement, check if the complement exists in the frequency map. If it does, multiply the frequencies of \( a \) and the complement to get the number of valid pairs.
   - If \( a \) is exactly half of \( K \), use the combination formula \( C(n, 2) \) to count pairs formed by the same number.

This approach ensures we efficiently count pairs without redundant checks, leveraging the constraints that the number of chocolates per box is between 1 and 100, limiting the number of unique values to check.

### Solution Code
```python
from collections import Counter
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        arr = list(map(int, input[ptr:ptr+N]))
        ptr += N
        K = int(input[ptr])
        ptr += 1
        freq = Counter(arr)
        ans = 0
        for a in freq:
            complement = K - a
            if a < complement:
                if complement in freq:
                    ans += freq[a] * freq[complement]
            elif a == complement:
                ans += (freq[a] * (freq[a] - 1)) // 2
        print(ans)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given large input sizes. The input is split into a list for easy processing.
2. **Frequency Counting**: Using `Counter` from the `collections` module, we count occurrences of each chocolate count in the boxes.
3. **Pair Checking**: For each unique chocolate count \( a \):
   - Compute the complement \( K - a \).
   - If \( a \) is less than the complement and the complement exists in the frequency map, add the product of their frequencies to the answer.
   - If \( a \) is exactly half of \( K \), use combinations to count pairs formed by the same number.
4. **Efficiency**: The algorithm runs in \( O(N) \) time per test case for building the frequency map and \( O(1) \) for iterating through up to 100 unique values (due to the constraint on chocolates per box), making it highly efficient for large inputs.
