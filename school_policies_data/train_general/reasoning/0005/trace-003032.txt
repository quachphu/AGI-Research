To solve this problem, we need to determine the minimum number of operations required to make two given strings equal by deleting characters from the front or back of either string. The key insight is to find the longest common contiguous substring between the two strings, as this will minimize the number of deletions needed.

### Approach
1. **Identify Substrings**: Generate all possible contiguous substrings for both input strings.
2. **Check Common Substrings**: For each substring of the first string, check if it exists in the second string.
3. **Maximize Length**: Track the maximum length of any common substring found.
4. **Calculate Operations**: Use the formula `len(a) + len(b) - 2 * max_len` to compute the minimum operations required, where `max_len` is the length of the longest common substring.

### Solution Code
```python
t = int(input())
for _ in range(t):
    a = input().strip()
    b = input().strip()
    max_len = 0
    # Generate all possible substrings of a and check against b
    for i in range(len(a)):
        for j in range(i + 1, len(a) + 1):
            substr = a[i:j]
            if substr in b:
                current_len = j - i
                if current_len > max_len:
                    max_len = current_len
    print(len(a) + len(b) - 2 * max_len)
```

### Explanation
1. **Reading Input**: The code reads the number of test cases and then processes each pair of strings.
2. **Generating Substrings**: For each string `a`, all possible contiguous substrings are generated by iterating over all possible start and end indices.
3. **Checking Presence in Other String**: Each substring of `a` is checked to see if it exists in `b` using Python's `in` operator.
4. **Tracking Maximum Length**: The length of the longest common substring found is tracked.
5. **Computing Result**: The result is calculated using the formula that accounts for the deletions required from both strings to reach the longest common substring.

This approach efficiently finds the solution by leveraging substring checks and iterating over possible substrings, ensuring optimal performance given the constraints.
