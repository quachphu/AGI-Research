To solve this problem, we need to determine the minimum number of snack pieces that can be evenly distributed to the guests whether there are A guests or B guests. This requires finding the smallest number that is a multiple of both A and B, which is known as the Least Common Multiple (LCM).

### Approach
1. **Understanding the Problem**: The goal is to find the minimum number of pieces that can be evenly divided by both A and B. This is a classic LCM problem.
2. **Mathematical Insight**: The LCM of two numbers can be efficiently calculated using their Greatest Common Divisor (GCD). The formula is LCM(a, b) = (a * b) // GCD(a, b).
3. **Efficient GCD Calculation**: The Euclidean algorithm is used to compute the GCD, which is efficient and works in O(log(min(a, b))) time.
4. **Implementation**: Read the input values, compute the GCD using Python's built-in `math.gcd` function, then compute the LCM using the formula and print the result.

### Solution Code
```python
import math

a, b = map(int, input().split())
print(a * b // math.gcd(a, b))
```

### Explanation
1. **Reading Input**: The input values A and B are read from standard input.
2. **Computing GCD**: Using the `math.gcd` function, we determine the greatest common divisor of A and B.
3. **Calculating LCM**: Using the formula LCM(a, b) = (a * b) // GCD(a, b), we compute the least common multiple.
4. **Output the Result**: The computed LCM is printed as the result.

This approach ensures that we efficiently compute the required value using optimal mathematical operations, making the solution both correct and performant even for large input values up to 100,000.
