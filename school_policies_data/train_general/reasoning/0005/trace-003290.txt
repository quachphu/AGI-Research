To solve this problem, we need to determine the winner of a dice game between Mishka and Chris based on the results of multiple rounds. Each round, both players roll a die, and the player with the higher number wins the round. If both players roll the same number, the round is a tie. The overall winner is determined by who wins the most rounds, or if they tie, we declare a draw.

### Approach
1. **Input Reading**: First, read the number of rounds, `n`.
2. **Initialize Counters**: Set up counters to track the number of wins for Mishka and Chris.
3. **Process Each Round**: For each round, compare the dice values of Mishka and Chris. Increment the respective counter if one's value is higher.
4. **Determine the Result**: After processing all rounds, compare the win counters. Print "Mishka" if she has more wins, "Chris" if he has more wins, and a friendship message if they have the same number of wins.

### Solution Code
```python
def main():
    n = int(input())
    mishka_wins = 0
    chris_wins = 0
    for _ in range(n):
        m, c = map(int, input().split())
        if m > c:
            mishka_wins += 1
        elif c > m:
            chris_wins += 1
    if mishka_wins > chris_wins:
        print("Mishka")
    elif chris_wins > mishka_wins:
        print("Chris")
    else:
        print("Friendship is magic!^^")

main()
```

### Explanation
1. **Reading Input**: The first input line gives the number of rounds. Subsequent lines provide the dice results for each round.
2. **Tracking Wins**: For each round, we compare the dice values. If Mishka's value is higher, her win counter is incremented. If Chris's value is higher, his counter is incremented. Ties are ignored.
3. **Result Determination**: After processing all rounds, we check which counter is higher. The result is printed based on which player has more wins, or a draw message if both have the same number of wins.

This approach efficiently processes each round in linear time, making it suitable for the given constraints (up to 100 rounds). The solution ensures that we accurately count wins and determine the correct outcome based on the rules provided.
