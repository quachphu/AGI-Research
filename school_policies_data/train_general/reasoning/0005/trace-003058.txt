To solve this problem, we need to process multiple datasets of soccer team results and output their rankings based on points. Each team's points are calculated from their wins and draws, and the teams are sorted in descending order of points. If points are tied, the teams retain their input order.

### Approach
1. **Input Handling**: Read all input lines at once and process each dataset iteratively.
2. **Dataset Processing**: For each dataset:
   - Read the number of teams.
   - For each team, calculate their points using wins and draws.
   - Store each team's points along with their original input order to handle ties.
3. **Sorting**: Sort teams primarily by points in descending order and secondarily by their original input order to maintain stability.
4. **Output Formatting**: Print each team's name and points, separated by a comma. Insert a blank line between consecutive datasets.

### Solution Code
```python
def main():
    import sys
    lines = [line.strip() for line in sys.stdin]
    current = 0
    datasets = []
    
    while current < len(lines):
        n_line = lines[current]
        if not n_line:
            current += 1
            continue
        n = int(n_line)
        if n == 0:
            break
        teams = []
        current += 1
        for i in range(n):
            if current + i >= len(lines):
                break
            team_line = lines[current + i]
            parts = team_line.split()
            name = parts[0]
            w = int(parts[1])
            l = int(parts[2])
            d = int(parts[3])
            points = w * 3 + d * 1
            teams.append((-points, i, name, points))  # -points for descending sort
        
        sorted_teams = sorted(teams, key=lambda x: (x[0], x[1]))
        output = [f"{team[2]},{team[3]}" for team in sorted_teams]
        datasets.append(output)
        current += n
    
    for i, dataset in enumerate(datasets):
        print("\n".join(dataset))
        if i != len(datasets) - 1:
            print()

main()
```

### Explanation
- **Reading Input**: The input is read all at once and processed line by line. This helps in efficiently managing multiple datasets.
- **Team Data Processing**: Each team's data is parsed to calculate points using wins and draws. The losses are ignored as they contribute zero points.
- **Sorting**: Teams are sorted using a composite key: negative points (to sort in descending order) and original index (to maintain input order for ties).
- **Output**: The sorted results are formatted and printed. A blank line is inserted between datasets to meet the problem's formatting requirements.

This approach ensures that the solution is efficient and handles all edge cases, such as tied points and multiple datasets, correctly.
