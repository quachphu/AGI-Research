To solve this problem, we need to determine the winner of a game where two players take turns eating cupcakes from three baskets. The player who eats the last cupcake wins. Hansa, the birthday girl, always takes the first turn. The solution involves game theory, specifically the Nim game, where the optimal strategy can be determined using the XOR (nim-sum) of the basket sizes.

### Approach
1. **Understanding the Game**: The problem is a variation of the Nim game. In Nim, players take turns removing objects from heaps, and the winner is the one who takes the last object. The optimal strategy involves calculating the XOR (nim-sum) of the heap sizes.
2. **Key Insight**: If the nim-sum (XOR of all heap sizes) is non-zero, the first player (Hansa) can force a win. If the nim-sum is zero, the second player (the competitor) will win, assuming both play optimally.
3. **Algorithm**:
   - For each test case, compute the XOR of the three basket sizes.
   - If the result is non-zero, Hansa wins ("NO BILL").
   - If the result is zero, the competitor wins ("BILL").

### Solution Code
```python
import sys

def determine_winner():
    t = int(sys.stdin.readline())
    for _ in range(t):
        a, b, c = map(int, sys.stdin.readline().split())
        nim_sum = a ^ b ^ c
        print("NO BILL" if nim_sum != 0 else "BILL")

determine_winner()
```

### Explanation
1. **Reading Input**: The input consists of multiple test cases. The first line gives the number of test cases, followed by lines each containing three integers representing the cupcake counts in three baskets.
2. **Nim-Sum Calculation**: For each test case, the XOR of the three basket sizes is computed. This nim-sum determines the optimal play outcome.
3. **Determining the Winner**: Based on the nim-sum:
   - A non-zero result means Hansa can force a win.
   - A zero result means the competitor will win.

This approach efficiently determines the winner using properties of the Nim game, ensuring optimal play from both participants. The solution runs in O(1) time per test case, making it very efficient even for large input sizes.
