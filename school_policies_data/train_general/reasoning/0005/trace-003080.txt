To solve this problem, we need to maximize the number of schoolboys that can rent bikes and then minimize the total personal money they spend. The solution involves sorting the boys and bikes in specific orders and using binary search to efficiently determine the optimal number of pairs.

### Approach
1. **Sorting**: 
   - Sort the boys' personal money in descending order to prioritize boys with more money.
   - Sort the bikes' prices in ascending order to prioritize cheaper bikes.

2. **Binary Search**:
   - Use binary search to determine the maximum number of boys (r) that can rent bikes. For each candidate number of boys (mid), compute the required shared budget to check feasibility.

3. **Optimal Pairing**:
   - For each candidate number of boys (mid), pair the smallest available bikes with the largest available boys in reverse order to minimize the required shared budget.

4. **Compute Minimum Personal Money**:
   - Once the maximum number of boys (r) is determined, calculate the minimum total personal money spent by considering the sum of bike prices and the available shared budget.

### Solution Code
```python
import sys

def main():
    n, m, a = map(int, sys.stdin.readline().split())
    boys = list(map(int, sys.stdin.readline().split()))
    bikes = list(map(int, sys.stdin.readline().split()))
    
    # Sort boys in descending order and bikes in ascending order
    boys.sort(reverse=True)
    bikes.sort()
    
    R = min(n, m)
    boys = boys[:R]
    bikes = bikes[:R]
    
    # Compute prefix sums for bikes
    prefix_p = [0] * (R + 1)
    for i in range(R):
        prefix_p[i+1] = prefix_p[i] + bikes[i]
    
    # Binary search to find the maximum r
    low, high = 0, R
    best_r = 0
    
    while low <= high:
        mid = (low + high) // 2
        if mid == 0:
            current_sum = 0
            valid = True
        else:
            current_sum = 0
            valid = True
            for j in range(mid):
                b_index = mid - 1 - j
                if b_index >= len(boys) or j >= len(bikes):
                    valid = False
                    break
                diff = bikes[j] - boys[b_index]
                current_sum += max(diff, 0)
            valid = valid and (current_sum <= a)
        
        if valid:
            best_r = mid
            low = mid + 1
        else:
            high = mid - 1
    
    if best_r == 0:
        print(0, 0)
    else:
        sum_p = prefix_p[best_r]
        sum_x = sum_p - min(a, sum_p)
        print(best_r, sum_x)

if __name__ == "__main__":
    main()
```
