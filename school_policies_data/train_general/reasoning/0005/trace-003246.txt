To solve this problem, we need to determine the minimum number of times we need to concatenate the newspaper heading (s1) such that we can form the target word (s2) by deleting some characters from the concatenated string. If it's impossible to form s2 from s1, we return -1.

### Approach
1. **Check Feasibility**: First, verify if all characters in s2 are present in s1. If any character in s2 is missing in s1, it's impossible to form s2, so we return -1.
2. **Preprocess s1**: Create a dictionary that maps each character in s1 to a list of its indices. This helps in quickly locating the next occurrence of a character in s1.
3. **Track Position**: Use a variable to track the current position in the concatenated string formed by multiple copies of s1. For each character in s2, find its next occurrence in s1 starting from the current position. If the next occurrence is not found in the current copy of s1, move to the next copy.
4. **Calculate Copies**: After processing all characters in s2, compute the number of copies of s1 required based on the final position tracked.

### Solution Code
```python
import bisect

def main():
    import sys
    s1 = sys.stdin.readline().strip()
    s2 = sys.stdin.readline().strip()

    from collections import defaultdict
    chars = defaultdict(list)
    for idx, c in enumerate(s1):
        chars[c].append(idx)

    # Check if any character in s2 is missing in s1
    for c in s2:
        if c not in chars:
            print(-1)
            return

    len_s1 = len(s1)
    current_pos = 0  # Tracks the current position in the concatenated s1s

    for c in s2:
        indices = chars[c]
        offset = current_pos % len_s1
        i = bisect.bisect_left(indices, offset)
        if i < len(indices):
            j = indices[i]
            current_pos = (current_pos // len_s1) * len_s1 + j + 1
        else:
            # Need to use the next copy
            j = indices[0]
            current_pos = ((current_pos // len_s1) + 1) * len_s1 + j + 1

    copies = (current_pos - 1) // len_s1 + 1
    print(copies)

main()
```

2. **Character Indices**: By preprocessing s1, we create a dictionary that maps each character to its indices in s1. This allows efficient lookups using binary search.
3. **Tracking Position**: As we process each character of s2, we determine the next occurrence of the character in the current or subsequent copies of s1. The position is tracked using modulo arithmetic to handle wrap-around to the next copy of s1.
4. **Calculate Copies**: The number of copies needed is determined by the highest position reached in the concatenated string, which is calculated after processing all characters of s2.
