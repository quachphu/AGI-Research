To solve this problem, we need to determine the time each picture is completed by the last painter, considering the constraints on the order of painting and processing times. Each painter works sequentially on each picture, and each picture must be processed by all painters in order. The solution involves simulating the painting process efficiently.

### Approach
1. **Problem Analysis**: Each painter must work on each picture in sequence, and each picture must be processed by painters in order. The time a painter starts on a picture depends on the completion time of the previous painter on the same picture and the completion time of the same painter on the previous picture.

2. **Key Insight**: For each picture and each painter, the start time is determined by the maximum of two values: the completion time of the previous painter on the same picture and the completion time of the same painter on the previous picture. This ensures that both dependencies (order of painters and order of pictures) are respected.

3. **Algorithm**: Use a dynamic programming approach with a 1D array to keep track of the completion times for the previous picture. For each picture, compute the completion times for each painter using the previous picture's data and update the array accordingly.

### Solution Code
```python
m, n = map(int, input().split())
times = [list(map(int, input().split())) for _ in range(m)]

prev = [0] * n
result = []

for t in times:
    curr = [0] * n
    curr[0] = prev[0] + t[0]
    for j in range(1, n):
        curr[j] = max(curr[j-1], prev[j]) + t[j]
    result.append(curr[-1])
    prev = curr.copy()

print(' '.join(map(str, result)))
```

### Explanation
1. **Reading Input**: The input consists of the number of pictures `m` and painters `n`, followed by the processing times for each painter on each picture.
2. **Initialization**: We initialize an array `prev` to keep track of the completion times for the previous picture. This array is updated iteratively for each picture.
3. **Processing Each Picture**: For each picture, we compute the completion times for each painter. The first painter's time is simply cumulative. For subsequent painters, the start time is the maximum of the previous painter's completion time on the current picture and the same painter's completion time on the previous picture.
4. **Updating Results**: After processing each picture, the completion time of the last painter is recorded in the result list.
5. **Output**: The results are printed as space-separated integers.

This approach efficiently computes the completion times in O(m*n) time complexity, which is optimal given the problem constraints. The use of a 1D array ensures minimal space complexity, making the solution both time and space efficient.
