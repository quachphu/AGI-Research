To solve this problem, we need to determine if it's possible for Cat Snuke to travel from Island 1 to Island N using exactly two boat services. The solution involves checking if there exists an intermediate island that connects both Island 1 and Island N through direct boat services.

### Approach
1. **Problem Analysis**: The problem requires checking if there's an intermediate island X such that there is a boat service from Island 1 to X and another from X to Island N. This can be efficiently determined by checking the intersections of sets of islands connected directly to Island 1 and Island N.

2. **Data Structures**: Use sets to keep track of all islands directly connected to Island 1 and those directly connected to Island N. This allows efficient membership checks and intersection operations.

3. **Algorithm**:
   - Read the input values.
   - For each boat service, update the sets of islands connected to Island 1 and Island N.
   - Check if there is any common island in both sets. If there is, print "POSSIBLE"; otherwise, print "IMPOSSIBLE".

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    M = int(input[ptr])
    ptr += 1
    
    s1 = set()
    sn = set()
    
    for _ in range(M):
        a = int(input[ptr])
        ptr += 1
        b = int(input[ptr])
        ptr += 1
        
        if a == 1 or b == 1:
            other = a + b - 1
            s1.add(other)
        if a == N or b == N:
            other = a + b - N
            sn.add(other)
    
    if not s1.isdisjoint(sn):
        print("POSSIBLE")
    else:
        print("IMPOSSIBLE")

main()
```

### Explanation
1. **Reading Input**: The input is read in one go and split into tokens for efficient processing.
2. **Building Sets**: Two sets, `s1` and `sn`, are used to store islands directly connected to Island 1 and Island N, respectively. For each boat service, if one end is Island 1, the other end is added to `s1`. Similarly, if one end is Island N, the other end is added to `sn`.
3. **Checking Intersection**: The `isdisjoint` method is used to check if there is any common island between `s1` and `sn`. If there is, it means there exists a valid two-step path from Island 1 to Island N, and "POSSIBLE" is printed. Otherwise, "IMPOSSIBLE" is printed.

This approach efficiently handles the constraints and ensures that we check for the existence of a valid path in linear time relative to the number of boat services, making it suitable for large input sizes.
