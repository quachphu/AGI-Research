To solve this problem, we need to determine the winner of a game where Alice and Bob take turns adding the absolute difference of two distinct integers from a set, provided the difference is not already in the set. Alice always moves first, and the player who cannot make a move loses. The solution involves analyzing the game using mathematical properties related to the greatest common divisor (GCD) and the structure of the set.

### Approach
1. **Compute the GCD**: The key insight is that the closure of the set under the operation of taking absolute differences will consist of all multiples of the GCD of the initial set elements up to the maximum element in the set.
2. **Determine the Closure Size**: The closure size is calculated by dividing the maximum element in the initial set by the GCD. This gives the number of elements in the closure.
3. **Calculate Moves**: The number of moves possible is the difference between the closure size and the initial number of elements in the set. If this number is odd, Alice wins; if even, Bob wins.

### Solution Code
```python
import math
from functools import reduce

def compute_gcd(list_numbers):
    return reduce(math.gcd, list_numbers)

n = int(input())
a = list(map(int, input().split()))
gcd = compute_gcd(a)
max_a = max(a)
closure_size = max_a // gcd
moves = closure_size - n

print("Alice" if moves > 0 and moves % 2 == 1 else "Bob")
```

### Explanation
1. **GCD Calculation**: The GCD of all elements in the set is computed. This GCD determines the smallest step size that can be used to generate all elements in the closure.
2. **Closure Size**: The closure size is derived by dividing the maximum element by the GCD. This gives the total number of elements that will be present in the set once all possible differences are added.
3. **Move Calculation**: The number of moves is the difference between the closure size and the initial number of elements. If this number is positive and odd, Alice wins because she starts first and will make the last move. If even or zero, Bob wins as he will make the last move or Alice cannot move first.

This approach efficiently determines the winner using mathematical properties, ensuring optimal play from both Alice and Bob.
