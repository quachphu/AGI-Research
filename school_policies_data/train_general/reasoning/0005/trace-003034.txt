To solve this problem, we need to determine the minimum number of moves required to form a 3x3 black square on an n x n grid after painting cells one by one. If it's impossible to form such a square after all moves, we should return -1.

### Approach
1. **Edge Case Handling**: If the grid size `n` is less than 3, it's impossible to form a 3x3 square, so we immediately return -1.
2. **Tracking Painted Cells**: For each move, track the cells being painted and check if they contribute to forming any 3x3 square.
3. **Efficient Checking**: Instead of checking all possible 3x3 squares after each move, we maintain a count of painted cells for each possible 3x3 square. When a cell is painted, we update the counts for all relevant 3x3 squares that include this cell. If any of these counts reach 9, we know that the corresponding 3x3 square is fully painted.
