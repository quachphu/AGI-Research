To solve this problem, we need to efficiently answer multiple queries about the minimum distance between pairs of equal elements within specified subranges of an array. The solution must handle large input sizes efficiently.

### Approach
1. **Preprocessing Occurrences**: For each element in the array, track all its occurrences. This helps in identifying pairs of elements that can potentially be part of the answer for any query.
2. **Generating Pairs**: For each element's list of occurrences, generate pairs of consecutive occurrences. Each pair (s, e) represents the start and end indices of two consecutive occurrences of the same element, with the distance calculated as e - s.
3. **Sorting Pairs and Queries**: Sort the generated pairs by their end index (e) and the queries by their right boundary (R). This allows us to process pairs incrementally as we handle each query.
4. **Segment Tree for Efficient Range Queries**: Use a segment tree to maintain the minimum distances dynamically. As we process each query, we update the segment tree with relevant pairs and query the minimum distance within the required range.

        ptr += 1
        r = int(input[ptr])
        ptr += 1
        queries.append((r, l, q))  # Store as (R, L, original index)

    queries.sort()

    # Initialize Segment Tree
    st = SegmentTree(n)

    res = [-1] * m
    i_pair = 0  # Pointer to track processed pairs

    for r_val, l_val, q_idx in queries:
        # Process all pairs with e <= current R (r_val)
        while i_pair < len(pairs) and pairs[i_pair][1] <= r_val:
            s, e = pairs[i_pair]
            d = e - s
            st.update(s, d)
            i_pair += 1
        # Query for minimum d where s >= L (l_val)
        min_d = st.query(l_val, n)
        res[q_idx] = min_d if min_d != float('inf') else -1

    # Output the results in the original order
    for ans in res:
        print(ans)

class SegmentTree:
    def __init__(self, size):
        self.n = 1
        while self.n < size:
            self.n <<= 1
        self.tree = [float('inf')] * (2 * self.n)

    def update(self, pos, value):
        # Convert 1-based pos to 0-based index in the tree array
        tree_pos = pos + self.n - 1
        if self.tree[tree_pos] <= value:
            return
        self.tree[tree_pos] = value
        # Move up the tree to update parents
        tree_pos >>= 1
        while tree_pos >= 1:
            new_val = min(self.tree[2 * tree_pos], self.tree[2 * tree_pos + 1])
            if self.tree[tree_pos] == new_val:
                break
            self.tree[tree_pos] = new_val
            tree_pos >>= 1

    def query(self, l, r):
        # Query the minimum value in the range [l, r] (1-based)
        res = float('inf')
        l += self.n - 1
        r += self.n - 1
        while l <= r:
            if l % 2 == 1:
                res = min(res, self.tree[l])
                l += 1
            if r % 2 == 0:
                res = min(res, self.tree[r])
                r -= 1
            l >>= 1
            r >>= 1
        return res

### Explanation
1. **Preprocessing Occurrences**: We track where each element occurs in the array, which helps in generating pairs of consecutive occurrences.
2. **Generating Pairs**: For each element with multiple occurrences, generate pairs of consecutive indices. These pairs are sorted by their end index to facilitate incremental processing.
3. **Sorting Queries**: Queries are sorted by their right boundary to process them in increasing order of their range end.
4. **Segment Tree**: A segment tree is used to dynamically maintain and query the minimum distance efficiently. As we process each query, relevant pairs are added to the segment tree, and the minimum distance for the current query range is retrieved using a range minimum query.

This approach ensures that each query is processed in logarithmic time relative to the size of the array, making the solution efficient even for large input sizes.
