To solve this problem, we need to determine if Misha can move from his starting position on a clock face to his target position without crossing any of the clock hands (hour, minute, second). The clock hands act as barriers, and Misha can only move along the perimeter of the clock face.

### Approach
1. **Calculate the Angles**: Convert the positions of the hour, minute, and second hands into angles relative to 12 o'clock. This involves considering the exact positions of the hands based on the given time.
2. **Determine Valid Paths**: Check if there exists a continuous path from Misha's starting position to his target position either clockwise or counter-clockwise that does not intersect any of the clock hands.
3. **Check Intervals**: For both clockwise and counter-clockwise directions, determine if any of the clock hands lie within the interval that defines the path. If no hands block either path, Misha can move successfully.

### Solution Code
```python
h, m, s, t1, t2 = map(int, input().split())

# Calculate the angles of each hand
h_angle = (h % 12) * 30.0 + m * 0.5 + s * (0.5 / 60)
h_angle %= 360

m_angle = m * 6.0 + s * 0.1
m_angle %= 360

s_angle = s * 6.0
s_angle %= 360

hand_angles = [h_angle, m_angle, s_angle]

a1 = (t1 % 12) * 30.0
a2 = (t2 % 12) * 30.0

def in_interval(angle, start, end):
    if start < end:
        return start < angle < end
    else:
        return angle > start or angle < end

# Check if clockwise path (a1 to a2) is blocked
blocked_cw = any(in_interval(ha, a1, a2) for ha in hand_angles)

# Check if counter-clockwise path (a2 to a1) is blocked
blocked_ccw = any(in_interval(ha, a2, a1) for ha in hand_angles)

if not blocked_cw or not blocked_ccw:
    print("YES")
else:
    print("NO")
```

### Explanation
1. **Angle Calculation**:
   - **Hour Hand**: The hour hand moves 30 degrees per hour plus an additional 0.5 degrees per minute and 0.0083 degrees per second.
   - **Minute Hand**: The minute hand moves 6 degrees per minute plus 0.1 degrees per second.
   - **Second Hand**: The second hand moves 6 degrees per second.

2. **Interval Check**:
   - **Clockwise Path**: Check if any hand lies between the starting angle (t1) and the target angle (t2) when moving clockwise.
   - **Counter-Clockwise Path**: Check if any hand lies between the target angle (t2) and the starting angle (t1) when moving clockwise, which is equivalent to moving counter-clockwise from t1 to t2.

3. **Decision Making**: If either path (clockwise or counter-clockwise) is free of obstacles, Misha can move successfully, otherwise he cannot.

This approach ensures that we accurately check both possible paths around the clock face and determine if either is unobstructed by the clock hands.
