To solve this problem, we need to implement a priority queue that supports insert and extractMax operations efficiently. The priority queue should handle up to 2,000,000 operations, making performance a critical consideration.

### Approach
1. **Data Structure Choice**: Use a min-heap to simulate a max-heap by storing negative values. This allows us to leverage Python's `heapq` module, which provides efficient O(log n) operations for heap maintenance.
2. **Insert Operation**: Convert the input value to its negative and push it into the heap. This way, the smallest negative value (which corresponds to the largest original value) will be at the root of the min-heap.
3. **ExtractMax Operation**: Pop the smallest element from the heap (which is the negative of the largest original value) and return its positive counterpart.
4. **Input Handling**: Read all input lines at once for efficiency, especially given the large potential input size. Process each line until encountering the "end" command.
5. **Output Handling**: Collect all results from extract operations in a list and print them once at the end to minimize I/O operations, which can be slow when performed repeatedly.

### Solution Code
```python
import heapq
import sys

def main():
    heap = []
    output = []
    for line in sys.stdin:
        line = line.strip()
        if line == 'end':
            break
        if line.startswith('insert'):
            _, k = line.split()
            heapq.heappush(heap, -int(k))
        elif line == 'extract':
            val = -heapq.heappop(heap)
            output.append(str(val))
    print('\n'.join(output))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The code reads input lines using `sys.stdin`, which is efficient for large input sizes. Each line is processed as it is read, stopping when the "end" command is encountered.
2. **Heap Operations**: 
   - For insert operations, the value is negated and pushed into the heap using `heapq.heappush`.
   - For extract operations, the smallest value (most negative) is popped using `heapq.heappop`, negated back to the original value, and stored in an output list.
3. **Output Optimization**: Instead of printing each result immediately, results are collected in a list and printed all at once at the end. This reduces the number of I/O operations, which is crucial for handling large input sizes efficiently.

This approach ensures that both insert and extract operations are handled in O(log n) time, making the solution efficient and scalable for the given constraints.
