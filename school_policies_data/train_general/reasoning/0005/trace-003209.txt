To solve this problem, we need to determine the minimum number of recorders required to record all TV programs such that no two programs on different channels overlap in their recording times, considering the constraints of the recorders.

### Approach
1. **Understand the Problem Constraints**: Each recorder can record a program from time `S` to `T` but cannot switch to another channel from `S-0.5` to `T`. This creates a blocked interval `[S-0.5, T)` during which the recorder is occupied.
2. **Convert Time Intervals**: To avoid dealing with floating points, convert each program's start and end times into integer values by scaling them by a factor of 2. This transforms the interval `[s_i-0.5, t_i)` into `[2*s_i-1, 2*t_i)`.
3. **Merge Intervals by Channel**: For each channel, merge overlapping or adjacent intervals to form continuous blocked periods. This is necessary because a single recorder can handle all programs on the same channel sequentially without needing additional recorders for overlapping blocked times.
4. **Track Overlapping Intervals**: After merging intervals for each channel, collect all intervals and use a sweep line algorithm to determine the maximum number of overlapping intervals across all channels. This maximum number gives the minimum number of recorders required.

### Solution Code
```python
n, c = map(int, input().split())
channels = [[] for _ in range(c + 1)]  # 1-based indexing

for _ in range(n):
    s, t, ci = map(int, input().split())
    start = 2 * s - 1
    end = 2 * t
    channels[ci].append((start, end))

merged = []

for ci in range(1, c + 1):
    intervals = channels[ci]
    if not intervals:
        continue
    intervals.sort()
    current_start, current_end = intervals[0]
    merged_intervals = []
    for s, e in intervals[1:]:
        if s <= current_end:
            current_end = max(current_end, e)
        else:
            merged_intervals.append((current_start, current_end))
            current_start, current_end = s, e
    merged_intervals.append((current_start, current_end))
    merged.extend(merged_intervals)

events = []
for s, e in merged:
    events.append((s, 1))
    events.append((e, -1))

# Sort by time, and for the same time, process end events before start events
events.sort(key=lambda x: (x[0], x[1]))

current = 0
max_count = 0
for time, delta in events:
    current += delta
    if current > max_count:
        max_count = current

print(max_count)
```

1. **Input Handling and Conversion**: The input is read and converted into integer-scaled intervals to avoid floating point precision issues.
2. **Merging Intervals**: For each channel, intervals are sorted and merged if they overlap or are adjacent. This ensures that each channel's recording periods are consolidated into continuous blocks.
3. **Event Processing**: Using a sweep line algorithm, we process start and end events of all intervals. The maximum number of overlapping intervals at any point in time is tracked, which gives the minimum number of recorders needed.

This approach efficiently handles the constraints and ensures that we use the minimum number of recorders by considering all overlapping intervals across different channels.
