### Approach
1. **Prefix Sum Modulo Calculation**: Compute the prefix sums modulo m for the given array of scones. This helps in efficiently calculating subarray sums modulo m.
2. **Segment Tree for Efficient Queries**: Use a segment tree to maintain the minimum values of prefix sums modulo m encountered so far. This allows efficient range minimum queries to determine the optimal subarray sums.
3. **Range Queries**: For each prefix sum modulo value, determine the maximum possible leftover scones by querying the segment tree for the minimum values in relevant ranges. This involves two queries for each prefix sum:
