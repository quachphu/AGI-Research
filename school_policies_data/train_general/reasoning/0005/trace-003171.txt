The game ends when one of them reaches (p, q), and Alice always plays first. Both players play optimally.

### Approach
The problem can be modeled using the principles of Wythoff's Game, a mathematical game where two players take turns reducing the counts of two piles. The player who removes the last object wins. The key insight is that the game's losing positions (P-positions) follow a specific pattern based on the golden ratio.

1. **Transform Coordinates**: Convert the initial coordinates (m, n) and target (p, q) into relative distances from the target, resulting in coordinates (x, y) where x = m - p and y = n - q.
2. **Check P-Positions**: In Wythoff's Game, P-positions are pairs (a_k, a_k + k) where a_k is derived using the golden ratio. For a given (x, y), check if it matches any P-position. If it does, the current player (Alice) is in a losing position, and Bob will win. Otherwise, Alice will win.

import math

def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    phi = (1 + math.sqrt(5)) / 2
    for _ in range(T):
        m = int(input[idx])
        n = int(input[idx+1])
        p = int(input[idx+2])
        q = int(input[idx+3])
        idx += 4
        x = m - p
        y = n - q
        if x > y:
            x, y = y, x
        k = y - x
        a_k = int(math.floor(k * phi))
        if x == a_k and y == a_k + k:
            print("Bob")
        else:
            print("Alice")

main()
