To solve this problem, we need to determine the number of ways to pick exactly one digit from each block such that the resulting integer, when taken modulo x, equals k. Given the constraints, especially the large number of blocks (up to 1e9), we need an efficient approach using dynamic programming and matrix exponentiation.

### Approach
1. **Dynamic Programming (DP) Initialization**: Compute the initial state after the first block, which gives the count of ways to achieve each possible remainder modulo x using the digits from the first block.
2. **Transition Matrix Construction**: Construct a matrix that represents the state transitions for each subsequent block. This matrix captures how each digit from a block changes the remainder when appended to the current number.
3. **Matrix Exponentiation**: Use matrix exponentiation to efficiently compute the effect of applying the transition matrix (b-1) times, where b is the number of blocks.
4. **Result Calculation**: Multiply the initial DP state vector with the exponentiated transition matrix to get the final counts of ways to achieve each remainder, then extract the count for the desired remainder k.

### Solution Code
```python
import sys
from collections import defaultdict

MOD = 10**9 + 7

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr +=1
    b = int(input[ptr])
    ptr +=1
    k = int(input[ptr])
    ptr +=1
    x = int(input[ptr])
    ptr +=1
    digits = list(map(int, input[ptr:ptr+n]))
    ptr +=n
    
    # Frequency of each digit
    freq = defaultdict(int)
    for d in digits:
        freq[d] += 1
    
    # Compute initial dp_1
    dp_1 = [0] * x
    for d in freq:
        cnt = freq[d]
        m = d % x
        dp_1[m] = (dp_1[m] + cnt) % MOD
    
    if b == 1:
        print(dp_1[k] % MOD)
        return
    
    # Build transition matrix T
    T = [[0]*x for _ in range(x)]
    for prev_m in range(x):
        for d in freq:
            cnt = freq[d]
            new_m = (prev_m * 10 + d) % x
            T[new_m][prev_m] = (T[new_m][prev_m] + cnt) % MOD
    
    # Matrix exponentiation functions
    def multiply(a, b):
        res = [[0]*x for _ in range(x)]
        for i in range(x):
            for k in range(x):
                if a[i][k] == 0:
                    continue
                for j in range(x):
                    res[i][j] = (res[i][j] + a[i][k] * b[k][j]) % MOD
        return res
    
    def matrix_power(mat, power):
        result = [[0]*x for _ in range(x)]
        # Identity matrix
        for i in range(x):
            result[i][i] = 1
        current = mat
        while power > 0:
            if power % 2 == 1:
                result = multiply(result, current)
            current = multiply(current, current)
            power //= 2
        return result
    
    T_power = matrix_power(T, b-1)
    
    # Multiply dp_1 with T_power
    final_dp = [0] * x
    for new_m in range(x):
        total = 0
        for prev_m in range(x):
            total = (total + dp_1[prev_m] * T_power[new_m][prev_m]) % MOD
        final_dp[new_m] = total
    
    print(final_dp[k] % MOD)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of digits per block, number of blocks, desired remainder k, and modulo x. The digits in each block are also read.
2. **Frequency Calculation**: The frequency of each digit in the block is calculated to determine how many times each digit appears.
3. **Initial DP State**: The initial DP state after the first block is computed by considering the modulo x of each digit's value and summing their frequencies.
4. **Transition Matrix**: A matrix is constructed where each entry T[i][j] represents the number of ways to transition from remainder j to i by appending a digit from the block.
5. **Matrix Exponentiation**: The transition matrix is raised to the power of (b-1) using exponentiation by squaring to efficiently handle the large number of blocks.
6. **Final State Calculation**: The initial DP state is multiplied by the exponentiated transition matrix to get the final state, from which the result for remainder k is extracted and printed.

This approach efficiently handles the large number of blocks using matrix exponentiation, reducing the complexity from O(b) to O(log b) for the exponentiation step.
