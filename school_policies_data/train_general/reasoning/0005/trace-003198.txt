To solve this problem, we need to efficiently handle two types of queries on an array: replacing elements with their divisor counts and summing ranges. The challenge is to process up to 300,000 queries efficiently, given that each element can be replaced multiple times but stabilizes after a few replacements.

### Approach
1. **Precompute Divisors**: Use a sieve method to precompute the number of divisors for all integers up to \(10^6\). This allows us to quickly determine the number of divisors for any element in constant time.
2. **Segment Tree**: Use a segment tree to efficiently handle range sum queries and range updates. Each node in the segment tree tracks the sum of elements in its range and a flag indicating if all elements in the range are stabilized (i.e., they are either 1 or 2, as further replacements will not change their values).
3. **Handling Queries**: For each query, if it's a sum query, compute the sum using the segment tree. If it's a replace query, update the elements in the specified range using the precomputed divisor counts, skipping elements that have already stabilized.

### Solution Code
```python
import sys

class Node:
    __slots__ = ['start', 'end', 'sum', 'is_stable', 'left', 'right']
    def __init__(self, start, end):
        self.start = start
        self.end = end
        self.sum = 0
        self.is_stable = False
        self.left = None
        self.right = None

def build(start, end, a, divisors):
    node = Node(start, end)
    if start == end:
        val = a[start]
        node.sum = val
        node.is_stable = (val == 1 or val == 2)
    else:
        mid = (start + end) // 2
        node.left = build(start, mid, a, divisors)
        node.right = build(mid+1, end, a, divisors)
        node.sum = node.left.sum + node.right.sum
        node.is_stable = node.left.is_stable and node.right.is_stable
    return node

def query_sum(node, l, r):
    if node.end < l or node.start > r:
        return 0
    if l <= node.start and r >= node.end:
        return node.sum
    return query_sum(node.left, l, r) + query_sum(node.right, l, r)

def replace_update(node, l, r, divisors):
    if node.end < l or node.start > r:
        return
    if node.is_stable:
        return
    if node.start == node.end:
        old_val = node.sum
        new_val = divisors[old_val]
        node.sum = new_val
        node.is_stable = new_val in {1, 2}
    else:
        replace_update(node.left, l, r, divisors)
        replace_update(node.right, l, r, divisors)
        node.sum = node.left.sum + node.right.sum
        node.is_stable = node.left.is_stable and node.right.is_stable

def main():
    sys.setrecursionlimit(1 << 25)
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr +=1
    m = int(input[ptr])
    ptr +=1
    a = list(map(int, input[ptr:ptr+n]))
    ptr +=n

    max_a = 10**6
    divisors = [0]*(max_a +1)
    for i in range(1, max_a+1):
        for j in range(i, max_a+1, i):
            divisors[j] +=1

    root = build(0, n-1, a, divisors)

    for _ in range(m):
        t = int(input[ptr])
        ptr +=1
        l = int(input[ptr])
        ptr +=1
        r = int(input[ptr])
        ptr +=1
        l0 = l-1
        r0 = r-1
        if t ==2:
            print(query_sum(root, l0, r0))
        else:
            replace_update(root, l0, r0, divisors)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precompute Divisors**: We use a sieve method to count the divisors for each number up to \(10^6\). This is done in \(O(n \log n)\) time.
2. **Segment Tree Construction**: The segment tree is built recursively. Each node stores the sum of its range and a flag indicating if all elements in the range are stabilized.
3. **Query Handling**: Sum queries are processed by recursively querying the segment tree. Replace queries update elements in the specified range, skipping stabilized elements to optimize performance.
4. **Efficiency**: Each element is updated a limited number of times (until it stabilizes), leading to an efficient solution with \(O(n \log n)\) preprocessing and \(O(\log n)\) per query.
