To solve this problem, we need to compute the greatest common divisor (GCD) of pairs of natural numbers using Euclid's algorithm. The input consists of multiple lines, each containing two natural numbers, and the output should be the GCD for each pair printed on a new line.

### Approach
1. **Understanding Euclid's Algorithm**: Euclid's algorithm efficiently finds the GCD of two numbers by repeatedly replacing the larger number with the remainder of dividing the larger number by the smaller one until the remainder is zero. The non-zero remainder just before this step is the GCD.
2. **Reading Input**: The input is read from standard input (stdin). Each line contains two natural numbers.
3. **Processing Each Pair**: For each pair of numbers, compute the GCD using Euclid's algorithm and print the result.

### Solution Code
```python
import sys

def gcd(a, b):
    while b != 0:
        a, b = b, a % b
    return a

for line in sys.stdin:
    a, b = map(int, line.strip().split())
    print(gcd(a, b))
```

### Explanation
1. **Reading Input**: The code reads each line from standard input using `sys.stdin`. Each line is stripped of leading/trailing whitespace and split into two integers.
2. **Computing GCD**: The `gcd` function uses an iterative approach to apply Euclid's algorithm. It repeatedly replaces the larger number with the remainder of the division until the remainder is zero, at which point the other number is the GCD.
3. **Output**: For each pair of numbers, the computed GCD is printed on a new line.

This approach ensures that the solution is efficient and handles all valid input cases within the constraints provided. The use of Euclid's algorithm guarantees optimal performance even for the upper limit of the input values.
