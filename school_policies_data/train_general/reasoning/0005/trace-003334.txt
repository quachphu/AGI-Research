To solve this problem, we need to determine if there exists a string in the initial set that differs from each query string by exactly one character at the same position. The solution must efficiently handle up to 300,000 initial strings and 300,000 queries, each potentially having a significant length.

### Approach
1. **Preprocessing Initial Strings**: Convert each initial string into a set of masks where each character position is replaced by a wildcard ('*'). Track the characters that appear in each position for these masks.
2. **Query Processing**: For each query string, generate all possible masks by replacing each character position with a wildcard. Check if any of these masks exist in the preprocessed initial set and if there is a character different from the query's character at the corresponding position.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    m = int(input[idx+1])
    idx +=2
    
    from collections import defaultdict
    mask_dict = defaultdict(set)  # Maps mask to the set of possible characters at the wildcard position

    # Process initial strings
    for _ in range(n):
        s = input[idx]
        idx +=1
        for i in range(len(s)):
            # Create mask by replacing i-th character with '*'
            mask = s[:i] + '*' + s[i+1:]
            mask_dict[mask].add(s[i])
    
    # Process queries
    result = []
    for _ in range(m):
        s = input[idx]
        idx +=1
        found = False
        length = len(s)
        for i in range(length):
            mask = s[:i] + '*' + s[i+1:]
            if mask in mask_dict:
                chars = mask_dict[mask]
                current_char = s[i]
                for c in chars:
                    if c != current_char:
                        found = True
                        break
                if found:
                    break
        result.append("YES" if found else "NO")
    
    print('\n'.join(result))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Preprocessing**:
   - For each initial string, generate all possible masks by replacing each character position with a wildcard ('*').
   - Track the characters that appear in each position using a dictionary where keys are masks and values are sets of characters.

2. **Query Handling**:
   - For each query string, generate all possible masks by replacing each character position with a wildcard.
   - Check if the mask exists in the preprocessed dictionary. If it does, check if there are any characters in the set that differ from the query's character at that position.
   - If such a character exists, the answer is "YES"; otherwise, it is "NO".

This approach efficiently checks each query in linear time relative to the length of the query string, ensuring that the solution handles large input sizes within acceptable time limits.
