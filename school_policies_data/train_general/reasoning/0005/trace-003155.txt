To solve this problem, we need to determine how many ID cards allow passage through all gates alone. The solution involves finding the intersection of all intervals defined by the gates and counting the number of valid ID cards within this intersection.

### Approach
1. **Understanding the Problem**: Each gate allows passage if the ID card is within a specific range. To pass all gates, an ID card must lie within the intersection of all these ranges.
2. **Key Insight**: The intersection of all intervals can be found by determining the maximum lower bound (maxL) and the minimum upper bound (minR) among all gates. If maxL is greater than minR, there is no valid ID card. Otherwise, the number of valid ID cards is the count of integers between maxL and minR inclusive.
3. **Efficiency**: By iterating through each gate once to compute maxL and minR, we achieve an O(M) time complexity, which is efficient given the constraints.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    M = int(input[ptr])
    ptr += 1
    maxL = 0
    minR = N
    for _ in range(M):
        L = int(input[ptr])
        ptr += 1
        R = int(input[ptr])
        ptr += 1
        if L > maxL:
            maxL = L
        if R < minR:
            minR = R
    if maxL > minR:
        print(0)
    else:
        print(minR - maxL + 1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the large possible input size.
2. **Initialization**: `maxL` is initialized to 0 and `minR` to N (the maximum possible value for an upper bound).
3. **Iterating Through Gates**: For each gate, update `maxL` to be the maximum of all lower bounds and `minR` to be the minimum of all upper bounds.
4. **Determine Valid IDs**: If `maxL` exceeds `minR`, there are no valid IDs. Otherwise, the number of valid IDs is the difference between `minR` and `maxL` plus one (to include both endpoints).

This approach efficiently narrows down the valid ID range using a single pass through the gates, ensuring optimal performance even for the upper constraint limits.
