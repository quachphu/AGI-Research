To solve this problem, we need to determine the total volume of snow melted each day given the initial volumes of snow piles and daily temperatures. Each pile starts melting on the day it is created and continues to melt each subsequent day until it is completely gone.

### Approach
1. **Prefix Sum Array**: Compute the prefix sum of the temperatures to efficiently calculate the cumulative temperature over any range of days.
2. **Binary Search**: For each snow pile, determine the earliest day when the cumulative temperature from the day the pile was created exceeds the initial volume of the pile. This helps in identifying the days when the pile contributes fully to the melted volume and the day when it contributes partially.
3. **Difference Array**: Use a difference array to efficiently track the number of piles contributing fully to the melted volume each day.
4. **Partial Contributions**: Track the partial contributions of piles that melt completely on a specific day using a separate array.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    V = list(map(int, input[ptr:ptr+N]))
    ptr += N
    T = list(map(int, input[ptr:ptr+N]))
    ptr += N

    # Compute prefix sum of T
    prefix = [0] * (N + 1)
    for i in range(N):
        prefix[i+1] = prefix[i] + T[i]

    diff = [0] * (N + 2)
    partial_melt = [0] * N

    for code_i in range(N):
        V_pile = V[code_i]
        problem_day_i = code_i + 1  # code_i is problem_day_i-1
        target = prefix[code_i] + V_pile  # S[i-1] + V_pile

        # Binary search for the smallest m where prefix[m] >= target
        left = problem_day_i  # problem_day_i is code_i +1, prefix starts from 0
        right = N
        m = N + 1
        while left <= right:
            mid = (left + right) // 2
            if mid > N:
                break
            if prefix[mid] >= target:
                m = mid
                right = mid - 1
            else:
                left = mid + 1

        if m <= N:
            sum_full = prefix[m-1] - prefix[code_i]
            partial = V_pile - sum_full
            if m-1 < N:
                partial_melt[m-1] += partial
            a = code_i
            b = m - 2
            if a <= b:
                diff[a] += 1
                if b + 1 < N:
                    diff[b+1] -= 1
        else:
            a = code_i
            b = N - 1
            if a <= b:
                diff[a] += 1
                if b + 1 < N:
                    diff[b+1] -= 1

    # Compute count array
    count = [0] * N
    current = 0
    for j in range(N):
        current += diff[j]
        count[j] = current

    # Calculate the result
    result = []
    for j in range(N):
        res = count[j] * T[j] + partial_melt[j]
        result.append(str(res))

    print(' '.join(result))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prefix Sum Calculation**: The prefix sum array helps in quickly determining the cumulative temperature from any start day to an end day.
2. **Binary Search**: For each snow pile, we use binary search to find the earliest day when the cumulative temperature exceeds the pile's initial volume. This helps in determining the days when the pile contributes fully to the melted volume.
3. **Difference Array**: This array is used to efficiently track the number of piles contributing to each day's melted volume. By incrementing the start of the contribution range and decrementing just after the end, we can compute the number of active piles for each day using a prefix sum over the difference array.
4. **Partial Contributions**: For each pile that melts completely on a specific day, we track the remaining volume melted that day separately.

This approach ensures that we efficiently compute the total melted volume for each day in O(N log N) time, making it suitable for large input sizes.
