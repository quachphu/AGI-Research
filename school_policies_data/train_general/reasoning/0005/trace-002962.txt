To solve this problem, we need to calculate the total number of hits for each dataset provided in the input. Each dataset starts with a number `n` (a multiple of 4), followed by `n/4` integers representing the number of hits in each round of 4 shots. The task is to sum these integers and output the result for each dataset.

### Approach
1. **Reading Input**: Read each line of input until encountering `0`, which signals the end of input.
2. **Processing Each Dataset**:
   - For each dataset, read the integer `n` which indicates the total number of shots.
   - Compute the number of rounds as `n/4` since each round consists of 4 shots.
   - Read the next `n/4` integers, each representing the number of hits in a round.
   - Sum these integers to get the total number of hits.
3. **Output the Result**: Print the total number of hits for each dataset immediately after processing it.

### Solution Code
```python
def main():
    import sys
    for line in sys.stdin:
        n = int(line.strip())
        if n == 0:
            break
        k = n // 4
        total = 0
        for _ in range(k):
            hits = int(sys.stdin.readline())
            total += hits
        print(total)

main()
```

### Explanation
- **Reading Input**: The code reads input line by line using a loop over `sys.stdin`. This ensures that we handle each line efficiently.
- **Handling Each Dataset**: For each dataset, after reading the initial value `n`, we check if `n` is 0 to terminate the input processing. If not, we compute the number of rounds (`n/4`).
- **Summing Hits**: For each round, the code reads the number of hits and accumulates the total. After processing all rounds of the current dataset, the total is printed.
- **Efficiency**: The approach efficiently processes each dataset in linear time relative to the number of rounds, ensuring optimal performance even for large inputs.

This solution ensures that we correctly handle multiple datasets, efficiently sum the hits, and produce the required output format.
