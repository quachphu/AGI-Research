To solve this problem, we need to determine how many shock waves emitted from a launcher in a rectangular room hit a target after reflecting off the walls. The solution involves modeling the reflections as mirrored rooms and checking all possible paths that the shock wave can take to reach the target exactly at the given time.

### Approach
1. **Model Reflections as Mirrored Rooms**: Instead of tracking reflections, we consider the target's position in an infinite grid of mirrored rooms. Each reflection can be modeled as a mirrored room adjacent to the original.
2. **Generate Possible Positions**: For both x and y directions, generate possible mirrored positions of the target. These positions are derived by considering even and odd reflections, which translate into arithmetic sequences.
3. **Check Valid Distances**: For each possible mirrored position, calculate the distance from the launcher. If the distance matches the distance the shock wave travels (velocity multiplied by time), count this as a valid hit.

### Solution Code
```python
import math

def main():
    import sys
    w, h, v, t, x, y, p, q = map(int, sys.stdin.readline().split())
    vt = v * t

    a = p - x
    b = 2 * w - p - x
    c = q - y
    d = h - q - y

    dx_set = set()
    for dx0 in [a, b]:
        denominator = 2 * w
        if denominator == 0:
            continue
        lower = -vt - dx0
        upper = vt - dx0
        k_min = math.ceil(lower / denominator)
        k_max = math.floor(upper / denominator)
        for k in range(k_min, k_max + 1):
            dx = dx0 + 2 * w * k
            if abs(dx) > vt:
                continue
            dx_set.add(dx)

    count = 0
    for dx in dx_set:
        dy_sq = vt ** 2 - dx ** 2
        if dy_sq < 0:
            continue
        s = int(math.isqrt(dy_sq))
        if s * s != dy_sq:
            continue

        if s == 0:
            for dy in [0]:
                rem3 = (dy - c) % (2 * h)
                if rem3 == 0:
                    count += 1
                rem4 = (dy - d) % (2 * h)
                if rem4 == 0:
                    count += 1
        else:
            for dy in [s, -s]:
                rem3 = (dy - c) % (2 * h)
                if rem3 == 0:
                    count += 1
                rem4 = (dy - d) % (2 * h)
                if rem4 == 0:
                    count += 1

    print(count)

if __name__ == "__main__":
    main()
```

1. **Input Reading**: The input values are read and parsed into appropriate variables.
2. **Calculate Offsets**: Compute offsets for possible mirrored positions in both x and y directions. These offsets are derived based on the target's position relative to the launcher and the room dimensions.
3. **Generate Mirrored Positions**: For each direction (x and y), generate possible positions by iterating over valid integers to cover all possible reflections within the distance the shock wave can travel.
4. **Check Valid Distances**: For each generated position, check if the distance from the launcher matches the shock wave's travel distance. If it does, check if the corresponding y-coordinate matches a valid mirrored position and count the hit.

This approach efficiently checks all possible paths by leveraging arithmetic sequences to model reflections, ensuring all valid paths are considered without explicitly tracking each reflection.
