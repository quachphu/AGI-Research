The solution involves expanding any sequences of zero blocks represented by "::" and padding each block with leading zeros to ensure each block has exactly 4 digits.

### Approach
1. **Handle Zero Block Sequences**: If the input contains "::", split the address into left and right parts around the "::". Calculate the number of missing zero blocks needed to form 8 blocks and insert them.
2. **Split and Validate Blocks**: If there is no "::", split the input into blocks directly and ensure there are exactly 8 blocks.
3. **Pad Blocks**: Each block is padded with leading zeros to ensure it has exactly 4 hexadecimal digits.

### Solution Code
```python
def expand_ipv6(s):
    if '::' in s:
        left_part, right_part = s.split('::', 1)
        # Split left and right parts into blocks, filtering out empty strings
        left_blocks = left_part.split(':') if left_part else []
        left_blocks = [b for b in left_blocks if b]
        right_blocks = right_part.split(':') if right_part else []
        right_blocks = [b for b in right_blocks if b]
        total_existing = len(left_blocks) + len(right_blocks)
        missing = 8 - total_existing
        expanded_blocks = left_blocks + ['0000'] * missing + right_blocks
    else:
        # Split into blocks, expecting exactly 8
        blocks = s.split(':')
        expanded_blocks = blocks
    
    # Pad each block to 4 characters with leading zeros
    full_blocks = [block.zfill(4) for block in expanded_blocks]
    return ':'.join(full_blocks)
```
