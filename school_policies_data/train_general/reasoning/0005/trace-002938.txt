To solve this problem, we need to calculate the happiness of Famil Door based on the number of pairs of chocolate pieces that share the same row or column on a cake. Each pair is counted only once, even if they share both a row and a column.

### Approach
1. **Input Reading**: Read the size of the cake (n) and the grid representation of the cake.
2. **Row Analysis**: For each row, count the number of chocolates ('C') and compute the number of pairs using the combination formula \( \binom{k}{2} = \frac{k(k-1)}{2} \), where k is the count of chocolates in the row.
3. **Column Analysis**: Similarly, for each column, count the number of chocolates and compute the pairs using the same combination formula.
4. **Summing Up**: Sum the pairs from all rows and columns to get the total happiness value.

### Solution Code
```python
def main():
    n = int(input())
    grid = [input().strip() for _ in range(n)]
    total = 0
    
    # Calculate pairs in each row
    for row in grid:
        c_count = row.count('C')
        total += c_count * (c_count - 1) // 2
    
    # Calculate pairs in each column
    for col in range(n):
        c_count = 0
        for row in grid:
            if row[col] == 'C':
                c_count += 1
        total += c_count * (c_count - 1) // 2
    
    print(total)

main()
```

### Explanation
1. **Reading Input**: The input is read as an integer `n` followed by `n` lines of strings representing the cake grid.
2. **Row Pairs Calculation**: For each row, the number of chocolates is counted. Using the combination formula, the number of pairs in each row is computed and added to the total happiness.
3. **Column Pairs Calculation**: Each column is checked by iterating over each row's corresponding column index. The number of chocolates in each column is counted, and the pairs are computed similarly and added to the total.
4. **Output**: The total happiness value is printed, which is the sum of all row and column pairs.

This approach efficiently computes the required pairs using simple iteration and combination mathematics, ensuring optimal performance even for the maximum constraint (n = 100).
