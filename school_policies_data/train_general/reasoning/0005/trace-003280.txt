To solve this problem, we need to determine the permutation array `p` that describes the best friend relationships among students, given the sequences `a` and `b` which represent the notebook distribution on the third and fourth days, respectively.

### Approach
1. **Understanding the Notebook Distribution**:
   - On the third day, the notebook of student `i` is with student `a[i]` (denoted as `a[i] = p(p(i))`).
   - On the fourth day, the notebook of student `i` is with student `b[i]` (denoted as `b[i] = p(p(p(i)))`).

2. **Key Insight**:
   - The relationship between `a` and `b` can be derived as `b[i] = p(a[i])`. This means that if we know where each student's notebook is on the third day (`a`), applying the permutation `p` once more gives us the fourth day's distribution (`b`).

3. **Constructing Permutation `p`**:
   - For each student `x`, find the index `i` where `a[i] = x`. The value of `b[i]` at this index gives `p(x)`.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

# Create a dictionary to map each value in 'a' to its index
pos_a = {num: idx for idx, num in enumerate(a)}

# Generate the permutation p
p = []
for x in range(1, n + 1):
    idx = pos_a[x]
    p.append(str(b[idx]))

print(' '.join(p))
```

### Explanation
1. **Reading Input**: The input consists of the number of students `n`, followed by the sequences `a` and `b`.
2. **Mapping Indices**: We create a dictionary `pos_a` to map each value in `a` to its index. This helps in quickly finding the index `i` where `a[i] = x` for any student `x`.
3. **Constructing `p`**: For each student `x` from 1 to `n`, we find the index `i` in `a` where `a[i] = x`. Using this index, we get `p(x)` from `b[i]`.
4. **Output**: The permutation `p` is printed as a space-separated string.

This approach efficiently constructs the permutation `p` in linear time, ensuring it handles the constraints up to 100,000 students effectively.
