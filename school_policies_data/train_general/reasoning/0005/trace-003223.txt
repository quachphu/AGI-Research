To solve this problem, we need to determine the number of crosses in a given n x n matrix. A cross is defined by a center cell and its four diagonal cells (top-left, top-right, bottom-left, and bottom-right) all containing the character 'X'. The center cell must be located such that it is not on the edge of the matrix.

### Approach
1. **Input Reading**: Read the matrix dimensions and the matrix itself.
2. **Edge Case Handling**: If the matrix size is less than 3x3, there can be no valid crosses, so return 0 immediately.
3. **Matrix Traversal**: Iterate through each cell in the matrix starting from the second row and second column up to the second-to-last row and column (both inclusive) to check potential cross centers.
4. **Cross Validation**: For each cell, check if it and its four diagonal cells contain 'X'. If all conditions are met, increment the cross count.
5. **Output Result**: Print the total number of valid crosses found.

### Solution Code
```python
def count_crosses():
    n = int(input())
    if n < 3:
        print(0)
        return
    matrix = [input().strip() for _ in range(n)]
    count = 0
    for i in range(1, n-1):
        for j in range(1, n-1):
            if (matrix[i][j] == 'X' and
                matrix[i-1][j-1] == 'X' and
                matrix[i-1][j+1] == 'X' and
                matrix[i+1][j-1] == 'X' and
                matrix[i+1][j+1] == 'X'):
                count += 1
    print(count)

count_crosses()
```

### Explanation
- **Input Handling**: The matrix is read as a list of strings, each string representing a row.
- **Edge Case Check**: For matrices smaller than 3x3, output 0 immediately since no valid crosses can exist.
- **Traversal**: Loop through rows and columns from the second to the second-to-last (1-based to n-2 in 0-based indices) to avoid edge cells.
- **Validation**: Each potential center cell is checked along with its four diagonal cells. If all five cells are 'X', a cross is counted.
- **Efficiency**: The solution efficiently checks each relevant cell exactly once, resulting in a time complexity of O(n^2), which is feasible for the given constraint (n ≤ 500).

This approach ensures that we correctly identify all valid crosses in the matrix while efficiently handling edge cases and constraints.
