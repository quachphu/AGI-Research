To solve this problem, we need to efficiently manage a dynamic array through a series of operations: appending elements, accessing elements by index, and removing the last element. The solution must handle up to 200,000 operations efficiently.

### Approach
1. **Data Structure**: Use a Python list to represent the dynamic array. Python lists provide O(1) time complexity for append and pop operations at the end, which is ideal for the given operations.
2. **Input Handling**: Read all input at once using `sys.stdin.read()` for efficiency, especially given the large possible number of operations. Split the input into tokens for easy processing.
3. **Command Processing**: Iterate through the tokens, processing each command based on its type:
   - **PushBack (0 x)**: Append the integer `x` to the list.
   - **RandomAccess (1 p)**: Print the element at index `p`.
   - **PopBack (2)**: Remove the last element from the list.

### Solution Code
```python
import sys

def main():
    data = list(map(int, sys.stdin.read().split()))
    q = data[0]
    arr = []
    index = 1
    for _ in range(q):
        cmd = data[index]
        if cmd == 0:
            x = data[index + 1]
            arr.append(x)
            index += 2
        elif cmd == 1:
            p = data[index + 1]
            print(arr[p])
            index += 2
        elif cmd == 2:
            arr.pop()
            index += 1

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and split into a list of integers. This method is efficient for handling large input sizes.
2. **Processing Commands**: The loop processes each command by checking the command type and executing the corresponding operation:
   - **PushBack**: Directly appends the element to the list.
   - **RandomAccess**: Accesses the element at the specified index and prints it.
   - **PopBack**: Removes the last element from the list.
3. **Maintaining Index**: An index variable tracks the current position in the token list, ensuring commands are processed sequentially and correctly.

This approach ensures that each operation is handled in constant time, making the solution efficient and suitable for the upper constraint of 200,000 operations.
