To solve this problem, we need to determine if a given integer is less than 10. Depending on this condition, we will either print a specific message or -1. The solution must handle multiple test cases efficiently.

### Approach
1. **Input Reading**: First, read the number of test cases, T.
2. **Loop Through Test Cases**: For each test case, read the integer N.
3. **Condition Check**: Check if N is less than 10. If true, print the message "What an obedient servant you are!". Otherwise, print -1.

The solution efficiently handles up to 1000 test cases as specified in the problem constraints. Each integer is checked in constant time, making the overall time complexity O(T), where T is the number of test cases.

### Solution Code
```python
def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        print("What an obedient servant you are!" if n < 10 else -1)

main()
```

### Explanation
1. **Reading Input**: The function starts by reading the integer T, which denotes the number of test cases.
2. **Processing Each Test Case**: For each test case, the integer N is read. Using a ternary operator, we check if N is less than 10. If it is, the specified message is printed; otherwise, -1 is printed.
3. **Efficiency**: The solution processes each test case in constant time, ensuring it efficiently handles the maximum constraints.

This approach ensures that the solution is both concise and efficient, adhering to the problem constraints and requirements.
