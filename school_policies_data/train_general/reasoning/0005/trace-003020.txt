To solve this problem, we need to determine the maximum weight of oranges Chef can buy within a given budget. Chef can only buy a subset of the available oranges, and we need to find the subset with the maximum weight that does not exceed his budget.

### Approach
1. **Input Reading**: Read the number of test cases. For each test case, read the number of oranges and the budget, followed by the cost and weight of each orange.
2. **Subset Generation**: Generate all possible subsets of oranges using bitmasking. Each bit in an integer represents whether an orange is included in the subset.
3. **Cost and Weight Calculation**: For each subset, calculate the total cost and weight. Check if the total cost is within the budget. If it is, update the maximum weight if the current subset's weight is higher than the previously recorded maximum.
4. **Output the Result**: After evaluating all subsets for a test case, output the maximum weight found.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        n = int(input[ptr])
        k = int(input[ptr + 1])
        ptr += 2
        oranges = []
        for __ in range(n):
            cost = int(input[ptr])
            weight = int(input[ptr + 1])
            oranges.append((cost, weight))
            ptr += 2
        max_weight = 0
        for mask in range(1 << n):
            total_cost = 0
            total_weight = 0
            for i in range(n):
                if mask & (1 << i):
                    total_cost += oranges[i][0]
                    total_weight += oranges[i][1]
            if total_cost <= k and total_weight > max_weight:
                max_weight = total_weight
        print(max_weight)

if __name__ == "__main__":
    main()
```

### Explanation
- **Input Handling**: The input is read all at once for efficiency, and then processed using a pointer to track the current position in the input list.
- **Bitmasking**: Each integer from 0 to \(2^n - 1\) (where \(n\) is the number of oranges) represents a subset. Each bit in the integer indicates whether the corresponding orange is included in the subset.
- **Subset Evaluation**: For each subset (represented by a bitmask), the total cost and weight are calculated. If the total cost is within the budget, the subset's weight is compared to the current maximum weight.
- **Efficiency**: The approach efficiently checks all possible subsets using bitmasking, which is feasible given the constraints (maximum 10 oranges, leading to 1024 subsets per test case).

This solution ensures that we explore all possible combinations of oranges to find the optimal subset that maximizes the weight without exceeding the budget.
