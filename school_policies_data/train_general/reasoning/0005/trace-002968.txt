To solve this problem, we need to determine how many times the exact string "E869120" appears in a list of names provided as input. The solution involves reading the input, counting the occurrences of the specific string, and outputting the count.

### Approach
1. **Read Input**: First, read the integer N which indicates the number of names.
2. **Count Occurrences**: For each of the next N lines, check if the string is exactly "E869120".
3. **Output Result**: Print the count of occurrences of "E869120". If there are none, output 0.

### Solution Code
```python
def main():
    n = int(input())
    count = 0
    for _ in range(n):
        s = input().strip()
        if s == "E869120":
            count += 1
    print(count)

main()
```

### Explanation
1. **Reading Input**: The code reads the integer N to know how many names to process.
2. **Processing Each Name**: For each name, it checks if the name is exactly "E869120". Using `strip()` ensures that any accidental leading or trailing whitespace in the input does not affect the comparison.
3. **Counting Matches**: Each time a match is found, the count is incremented.
4. **Output**: Finally, the count is printed. If no matches were found, the count remains 0, which is printed as required.

This approach efficiently processes each name in linear time, making it suitable for the given constraints. The solution ensures accuracy by strictly checking for exact matches of the string "E869120".
