2. **Conversion Process**: For each test case, convert `a` into its base `b` representation. This involves repeatedly dividing `a` by `b` and collecting the remainders, which form the digits of the number in base `b` from least significant to most significant. These digits are then reversed to form the correct order.
3. **Output Generation**: After converting `a` to base `b`, concatenate the digits into a string and parse it as an integer to get the final result.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        a = int(input[idx])
        b = int(input[idx+1])
        idx += 2
        digits = []
        if a == 0:
            print(0)
            continue
        temp = a
        while temp > 0:
            digits.append(temp % b)
            temp = temp // b
        digits.reverse()
        result = ''.join(map(str, digits))
        print(int(result))
        
main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints. The first value is the number of test cases `T`.
2. **Processing Each Test Case**: For each test case, the integers `a` and `b` are extracted. The integer `a` is converted to its base `b` representation by repeatedly dividing `a` by `b` and collecting the remainders.
3. **Constructing the Result**: The collected remainders (digits) are reversed to form the correct base `b` representation. These digits are then concatenated into a string and converted to an integer, which is printed as the result.

This approach efficiently converts each number to the specified base and handles all edge cases, ensuring the solution is both correct and optimal.
