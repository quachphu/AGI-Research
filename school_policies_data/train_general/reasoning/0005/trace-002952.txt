To solve this problem, we need to determine the number of lucky permutations in a given graph. A permutation of vertices is considered lucky if every consecutive pair of vertices in the permutation is connected by an edge. This problem can be approached by generating all permutations of the vertices and checking each permutation for the required adjacency condition.

### Approach
1. **Input Reading and Graph Construction**: Read the number of vertices (N) and edges (M). Construct an adjacency matrix to represent the graph, which allows quick lookup to check if an edge exists between two vertices.
2. **Generate Permutations**: Use itertools.permutations to generate all possible permutations of the vertices.
3. **Check Validity of Permutations**: For each permutation, verify if every consecutive pair of vertices is connected by an edge in the graph. Count the number of valid permutations.

### Solution Code
```python
import sys
from itertools import permutations

def count_lucky_permutations():
    n, m = map(int, sys.stdin.readline().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        x, y = map(int, sys.stdin.readline().split())
        adj[x][y] = True
        adj[y][x] = True

    count = 0
    for perm in permutations(range(1, n + 1)):
        valid = True
        for i in range(n - 1):
            u = perm[i]
            v = perm[i + 1]
            if not adj[u][v]:
                valid = False
                break
        if valid:
            count += 1
    print(count)

count_lucky_permutations()
```

### Explanation
1. **Graph Representation**: The adjacency matrix `adj` is used to store the presence of edges. This allows O(1) time complexity to check if an edge exists between any two vertices.
2. **Permutations Generation**: Using `itertools.permutations`, we generate all possible permutations of the vertices. Each permutation is checked for the adjacency condition.
3. **Validity Check**: For each permutation, iterate through consecutive pairs and check their adjacency using the matrix. If all pairs are valid, the permutation is counted as lucky.

This approach efficiently checks all possible permutations (up to 10! for N=10), ensuring that we accurately count all valid paths. The use of an adjacency matrix ensures quick lookups, making the solution feasible even for the upper constraint of N=10.
