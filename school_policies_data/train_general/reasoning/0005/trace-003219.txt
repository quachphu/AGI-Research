To solve this problem, we need to eliminate all consecutive duplicate elements from a sorted sequence of integers. The key insight here is that since the input list is already sorted, all duplicate elements will be adjacent to each other. Therefore, we can efficiently remove duplicates by iterating through the list and keeping only the first occurrence of each element.

### Approach
1. **Read Input:** The input consists of an integer `n` followed by a list of `n` integers sorted in ascending order.
2. **Process the List:** Initialize a result list to store the elements after removing duplicates. Iterate through the input list, adding each element to the result list only if it is different from the last element added to the result list.
3. **Output the Result:** Print the elements of the result list separated by spaces.

This approach ensures that each element is checked exactly once, leading to an efficient solution with a time complexity of O(n) and a space complexity of O(n), where n is the number of elements in the input list.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    if not a:
        print()
        return
    res = [a[0]]
    for num in a[1:]:
        if num != res[-1]:
            res.append(num)
    print(' '.join(map(str, res)))

main()
```

### Explanation
1. **Reading Input:** The input is read all at once using `sys.stdin.read()` to handle potentially large input sizes efficiently. The input is split into tokens, with the first token being the integer `n` and the subsequent tokens forming the list of integers.
2. **Processing the List:** We initialize the result list with the first element of the input list. Then, for each subsequent element in the input list, we check if it is different from the last element in the result list. If it is different, we add it to the result list.
3. **Output:** The result list is converted to a space-separated string and printed.

This method ensures that all consecutive duplicates are efficiently removed while maintaining the order of the elements, as required by the problem constraints.
