To solve this problem, we need to calculate the total travel cost for Walter White as he visits a sequence of cities starting from city 1. The solution involves reading input data, mapping city names to their respective IDs, and using a cost matrix to compute the travel expenses between consecutive cities in the given path.

### Approach
1. **Read City Names and IDs**: First, we read the number of cities, followed by their names. Each city name is assigned a unique ID based on the order they are read.
2. **Read Cost Matrix**: We then read the cost matrix which provides the travel cost between each pair of cities. The matrix is structured such that the element at row `i` and column `j` represents the cost to travel from city `i+1` to city `j+1`.
3. **Read Travel Path**: Next, we read the number of cities Walter visits and the sequence of these cities. This sequence is converted to their respective IDs using the previously created mapping.
4. **Calculate Total Cost**: Starting from city 1, we iterate through the travel path, summing up the travel costs between consecutive cities using the cost matrix.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().splitlines()
    idx = 0
    
    # Read number of cities and their names
    n = int(input[idx])
    idx += 1
    city_id = {}
    for i in range(n):
        city_name = input[idx].strip()
        city_id[city_name] = i + 1  # IDs start from 1
        idx += 1
    
    # Read cost matrix
    cost_matrix = []
    for _ in range(n):
        row = list(map(int, input[idx].split()))
        cost_matrix.append(row)
        idx += 1
    
    # Read path
    p = int(input[idx])
    idx += 1
    path = []
    for _ in range(p):
        city = input[idx].strip()
        path.append(city_id[city])
        idx += 1
    
    # Calculate total cost
    current = 1  # Starting at city 1
    total_cost = 0
    for next_city in path:
        total_cost += cost_matrix[current - 1][next_city - 1]
        current = next_city
    
    print(total_cost)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into lines for easier processing. We first determine the number of cities and map each city name to its ID.
2. **Cost Matrix Storage**: The cost matrix is stored as a list of lists where each sublist represents the travel costs from a specific city to all other cities.
3. **Path Processing**: The cities Walter visits are converted to their respective IDs using the previously created dictionary. This allows us to efficiently look up travel costs in the matrix.
4. **Cost Calculation**: Starting from city 1, we iterate through each city in the path, accumulate the travel costs using the cost matrix, and update the current city to the next city in the sequence. The total accumulated cost is then printed.

This approach ensures that we efficiently and correctly compute the total travel cost using the given input constraints and structure.
