The graph includes edges between consecutive vertices with a given weight and additional edges based on the GCD condition.

### Approach
1. **Consecutive Edges**: First, we compute the edges between consecutive vertices. For each pair of consecutive vertices, we check if the GCD of their values equals their minimum value. If it does, the edge weight is the minimum of this value and a given parameter `p`. Otherwise, the edge weight is `p`.

2. **Non-consecutive Edges**: For each element in the array, we find the maximal interval where the element is the minimum and all elements in the interval are divisible by this minimum value. These intervals form edges between the start and end indices of the interval with the weight being the minimum value.

3. **Union-Find Data Structure**: Using a union-find (disjoint set) data structure, we process all edges (both consecutive and non-consecutive) in increasing order of their weights to build the MST efficiently.

            if g == m:
                w = min(m, p)
            else:
                w = p

                right +=1

            for j in range(left, right+1):
                if a[j] < current_min:
                    current_min = a[j]
            if current_min != m:
                continue
            
            if right > left:
                edges.append((m, left, right))
        
        edges.sort()
        parent = list(range(n))
        def find(u):
            while parent[u] != u:
                parent[u] = parent[parent[u]]
                u = parent[u]

            u_root = find(u)
            v_root = find(v)
            if u_root == v_root:
                return False
            parent[v_root] = u_root
            return True
