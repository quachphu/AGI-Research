To solve this problem, we need to generate the alphabetically earliest possible login for a user by combining non-empty prefixes of their first and last names. The solution involves generating all possible prefixes for both the first and last names, then combining them to find the lexicographically smallest combination.

### Approach
1. **Generate Prefixes**: For both the first and last names, generate all possible non-empty prefixes. A prefix of a string is any substring starting from the first character and extending to any length up to the full string.
2. **Combine Prefixes**: Create all possible combinations of prefixes from the first name and prefixes from the last name.
3. **Find Minimum**: Compare all combinations lexicographically to determine the smallest possible login.

### Solution Code
```python
def generate_login():
    first, last = input().split()
    
    def get_prefixes(s):
        return [s[:i] for i in range(1, len(s)+1)]
    
    first_prefixes = get_prefixes(first)
    last_prefixes = get_prefixes(last)
    
    min_login = None
    for fp in first_prefixes:
        for lp in last_prefixes:
            candidate = fp + lp
            if min_login is None or candidate < min_login:
                min_login = candidate
    print(min_login)

generate_login()
```

### Explanation
1. **Reading Input**: The input consists of two space-separated strings representing the first and last names.
2. **Generating Prefixes**: For each name, generate all possible prefixes. For example, the name "harry" will generate prefixes ["h", "ha", "har", "harr", "harry"].
3. **Combining Prefixes**: Each prefix from the first name is combined with each prefix from the last name. For example, combining "ha" (from "harry") with "p" (from "potter") results in "hap".
4. **Finding the Minimum**: By iterating through all combinations, we keep track of the lexicographically smallest string. This ensures we find the earliest possible login as required.

This approach efficiently checks all possible valid combinations, ensuring the solution is both correct and optimal given the constraints.
