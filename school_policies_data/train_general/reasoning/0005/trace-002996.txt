To solve this problem, we need to determine if a given integer sequence can be divided into an odd number of non-empty subsegments, each of which has an odd length and starts and ends with odd numbers. 

### Approach
The key insight to solve this problem efficiently is based on the following observations:
1. **Odd Length Requirement**: The entire sequence must have an odd length. This is because the sum of an odd number of odd-length subsegments must be odd.
2. **Start and End with Odd Numbers**: The sequence must start and end with odd numbers. This ensures that any valid division of the sequence into subsegments will meet the criteria of starting and ending with odd numbers.

Given these observations, the solution can be determined by checking two conditions:
1. The length of the sequence is odd.
2. The first and last elements of the sequence are odd.

If both conditions are satisfied, the answer is "Yes"; otherwise, it is "No".

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))

if n % 2 == 0:
    print("No")
else:
    if a[0] % 2 == 1 and a[-1] % 2 == 1:
        print("Yes")
    else:
        print("No")
```

### Explanation
1. **Check Length Parity**: If the length of the sequence (`n`) is even, it's immediately impossible to divide it into an odd number of odd-length subsegments, so we print "No".
2. **Check Start and End Elements**: If the sequence length is odd, we then check if the first and last elements are odd. If both are odd, the sequence can be divided into valid subsegments (starting with the entire sequence itself if necessary), so we print "Yes". Otherwise, we print "No".

This approach efficiently checks the necessary conditions in constant time, ensuring optimal performance.
