To solve this problem, we need to determine the maximum number of balls Iahub can destroy from the original row by inserting his ball at the optimal position. The destruction process involves removing groups of three or more contiguous balls of the same color, which can cause subsequent groups to form and be destroyed until no more such groups exist.

### Approach
1. **Insertion Simulation**: For each possible position in the original row, insert Iahub's ball and simulate the destruction process.
2. **Destruction Process**: After each insertion, repeatedly check for groups of three or more contiguous balls of the same color. Remove these groups and continue checking until no more such groups exist.
3. **Tracking Original Balls**: Keep track of which balls are from the original row to ensure we only count their destruction towards the result.

### Solution Code
```python
def main():
    import sys
    n, k, x = map(int, sys.stdin.readline().split())
    original = list(map(int, sys.stdin.readline().split()))
    
    max_destroyed = 0
    
    for pos in range(n + 1):
        # Create the new list with the inserted ball
        new_list = [(c, True) for c in original]
        new_list.insert(pos, (x, False))
        current_list = new_list.copy()
        destroyed = 0
        
        while True:
            groups = []
            if not current_list:
                break
            
            # Split into groups of consecutive same color
            current_group = [current_list[0]]
            for elem in current_list[1:]:
                if elem[0] == current_group[-1][0]:
                    current_group.append(elem)
                else:
                    groups.append(current_group)
                    current_group = [elem]
            groups.append(current_group)
            
            # Check for groups to remove (length >=3)
            removal = []
            for group in groups:
                if len(group) >= 3:
                    removal.extend(group)
            
            if not removal:
                break
            
            # Count original balls in removal
            for elem in removal:
                if elem[1]:
                    destroyed += 1
            
            # Rebuild the current list without the removed groups
            new_current = []
            for group in groups:
                if len(group) < 3:
                    new_current.extend(group)
            
            # Prevent infinite loop if no change
            if len(new_current) == len(current_list):
                break
            
            current_list = new_current
        
        if destroyed > max_destroyed:
            max_destroyed = destroyed
    
    print(max_destroyed)

main()
```

### Explanation
1. **Reading Input**: The input consists of the number of balls, the number of colors, the color of Iahub's ball, and the list of ball colors in the original row.
2. **Insertion Positions**: For each possible insertion position (from 0 to n), we create a new list that includes Iahub's ball.
3. **Group Formation**: For each new list, we split it into groups of contiguous balls of the same color.
4. **Destruction Simulation**: We remove groups of three or more balls, count the original balls destroyed, and update the list. This process repeats until no more groups can be removed.
5. **Result Calculation**: Track the maximum number of original balls destroyed across all insertion positions and print the result.

This approach ensures that we efficiently simulate each possible insertion and destruction process, accurately counting the maximum number of original balls destroyed.
