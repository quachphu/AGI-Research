To solve this problem, we need to determine the minimal number of passwords a hacker must select to guarantee access to the system regardless of which password is the admin's. The equivalence of passwords is defined by shared characters or through a chain of shared characters.

### Approach
1. **Character Union-Find Structure**: We use a union-find data structure to manage the connected components of characters. Each password's characters are merged into a single component, as any password with a character from this component can access any other password in the same component.
2. **Union Operations**: For each password, we connect all its characters into a single component. This ensures that any two characters in the same password are part of the same component.
3. **Component Counting**: After processing all passwords, the number of distinct connected components of characters gives the number of equivalence classes. The minimal number of passwords needed is equal to the number of these components.

    n = int(sys.stdin.readline())
    passwords = [sys.stdin.readline().strip() for _ in range(n)]
    
    # Collect all unique characters
    chars = set()
    for s in passwords:
        chars.update(s)
    if not chars:
        print(0)
        return
    
    # Initialize parent and rank for each of the 26 letters
    parent = list(range(26))
    rank = [1] * 26
    
    # Union-Find functions
    def find(u):
        while parent[u] != u:
            parent[u] = parent[parent[u]]
            u = parent[u]
        return u
    
    def union(u, v):
        u_root = find(u)
        v_root = find(v)
        if u_root == v_root:
            return
        if rank[u_root] < rank[v_root]:
            parent[u_root] = v_root
        else:
            parent[v_root] = u_root
            if rank[u_root] == rank[v_root]:
                rank[u_root] += 1
    
    # Process each password to union all characters
    for s in passwords:
        if not s:
            continue
        first = ord(s[0]) - ord('a')
        for c in s[1:]:
            curr = ord(c) - ord('a')
            union(first, curr)
    
    # Collect all roots of the unique characters
    roots = set()
    for c in chars:
        c_idx = ord(c) - ord('a')
        roots.add(find(c_idx))
    
    print(len(roots))

if __name__ == "__main__":
    main()

### Explanation
1. **Union-Find Initialization**: Each character ('a' to 'z') is initially its own parent.
2. **Processing Passwords**: For each password, we connect all its characters. This ensures that all characters in a password are in the same component.
3. **Component Counting**: After processing all passwords, we determine the number of distinct components by finding the unique roots of all characters present in the passwords. The number of unique roots is the answer, representing the minimal number of passwords needed to cover all possible admin passwords.

This approach efficiently handles the problem constraints using union-find with path compression and union by rank, ensuring optimal performance even for large inputs.
