To solve this problem, we need to form a team of k students such that each student in the team has a distinct rating. If it's impossible to form such a team, we should output "NO". Otherwise, we should output "YES" followed by the indices of the selected students.

### Approach
1. **Check for Distinct Ratings**: First, we need to determine if there are at least k distinct ratings among the students. If there are fewer than k distinct ratings, forming a team is impossible.
2. **Collect Indices**: If there are at least k distinct ratings, we collect the indices of the first occurrence of each distinct rating until we have k indices. This ensures that each selected student has a unique rating and we use the earliest possible occurrences to form the team.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))

seen = set()
indices = []

for i in range(n):
    num = a[i]
    if num not in seen:
        seen.add(num)
        indices.append(i + 1)
        if len(indices) == k:
            break

if len(indices) == k:
    print("YES")
    print(' '.join(map(str, indices)))
else:
    print("NO")
```

### Explanation
1. **Reading Input**: The first line of input contains the number of students `n` and the required team size `k`. The second line contains the ratings of each student.
2. **Tracking Distinct Ratings**: We use a set `seen` to track the ratings we have encountered. As we iterate through the list of ratings, we add each new rating to the set and record its index (adjusted to 1-based indexing).
3. **Forming the Team**: We stop as soon as we have collected `k` distinct ratings. If we collect exactly `k` indices, we print "YES" followed by the indices. If not, we print "NO".

This approach efficiently ensures that we use the earliest occurrences of each distinct rating, which simplifies the process and ensures correctness. The solution runs in O(n) time complexity, making it suitable for the given constraints.
