To solve this problem, we need to convert each character in a given string to a corresponding numeric digit based on the layout of a traditional telephone keypad. Each letter from 'a' to 'z' maps to a specific number as per the keypad's configuration. The task involves reading multiple test cases, converting each string to its numeric equivalent, and printing the results.

### Approach
1. **Mapping Creation**: Create a dictionary to map each character to its corresponding numeric digit based on the telephone keypad layout.
2. **Input Handling**: Read the number of test cases and each subsequent string.
3. **String Conversion**: For each string, convert each character to its numeric equivalent using the pre-defined mapping.
4. **Output Generation**: Concatenate the numeric equivalents of all characters in the string and print the result for each test case.

### Solution Code
```python
import sys

def main():
    mapping = {
        'a': '2', 'b': '2', 'c': '2',
        'd': '3', 'e': '3', 'f': '3',
        'g': '4', 'h': '4', 'i': '4',
        'j': '5', 'k': '5', 'l': '5',
        'm': '6', 'n': '6', 'o': '6',
        'p': '7', 'q': '7', 'r': '7', 's': '7',
        't': '8', 'u': '8', 'v': '8',
        'w': '9', 'x': '9', 'y': '9', 'z': '9'
    }
    T = int(sys.stdin.readline())
    for _ in range(T):
        s = sys.stdin.readline().strip()
        result = ''.join([mapping[c] for c in s])
        print(result)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Mapping Creation**: The dictionary `mapping` is created where each key is a lowercase letter and the value is the corresponding digit on a telephone keypad. For example, 'a', 'b', and 'c' all map to '2'.
2. **Reading Input**: The number of test cases `T` is read first. Each subsequent line is processed as a string input.
3. **String Conversion**: For each string, each character is converted to its corresponding digit using a list comprehension and the predefined `mapping` dictionary. The digits are concatenated into a single string using `join`.
4. **Output**: The resulting numeric string for each test case is printed immediately after processing.

This approach efficiently handles the conversion using a direct lookup in the dictionary, ensuring that each character is processed in constant time, leading to an overall linear time complexity relative to the length of the input strings.
