### Approach
1. **Initialization**: Start with a list of children numbered from 1 to n and set the initial leader as the first child.
2. **Simulation of Each Step**:
   - For each step, calculate the starting index from the next child after the current leader.
   - Compute the effective steps using modulo operation to handle large values efficiently.
   - Determine the index of the child to be eliminated and update the list of remaining children.
   - Adjust the leader's index for the next step based on the eliminated child's position.

### Solution Code
```python
n, k = map(int, input().split())
a_list = list(map(int, input().split()))

children = list(range(1, n + 1))
current_leader_idx = 0  # starts with the first child (index 0 in 0-based list)

result = []

for a in a_list:
    m = len(children)
    starting = (current_leader_idx + 1) % m
    steps = a - 1
    effective_steps = steps % m
    idx = (starting + effective_steps) % m
    eliminated = children[idx]
    result.append(str(eliminated))
    
    # Compute new leader's index
    new_leader_original = (idx + 1) % m
    if new_leader_original > idx:
        new_leader_new = new_leader_original - 1
    else:
        new_leader_new = new_leader_original
    
    children.pop(idx)
    current_leader_idx = new_leader_new

print(' '.join(result))
```

### Explanation
1. **Reading Input**: The input consists of the number of children `n`, the number of steps `k`, and the list of counts for each step.
2. **Initial Setup**: Create a list of children and initialize the current leader index to 0 (the first child).
3. **Processing Each Step**:
   - **Calculate Starting Index**: The starting index is the next child after the current leader.
   - **Effective Steps**: Use modulo operation to handle large counts efficiently.
   - **Determine Elimination Index**: Compute the index of the child to be eliminated using the starting index and effective steps.
   - **Update Leader**: Adjust the leader's index for the next step based on the position of the eliminated child.
4. **Output**: Collect and print the results for each step.

This approach ensures that each step is processed efficiently, even with large count values, by leveraging modulo arithmetic and list operations to maintain the correct indices after each elimination.
