To solve this problem, we need to determine the total number of matchsticks used to display a given number using seven-segment displays. Each digit from 0 to 9 uses a specific number of matchsticks, and our task is to sum these values for each digit in the input number.

### Approach
1. **Understand Matchstick Counts**: Each digit (0-9) has a fixed number of matchsticks required for its seven-segment display. We can use a dictionary to map each digit to its corresponding matchstick count.
2. **Read Input**: The input consists of multiple test cases. For each test case, read the number as a string to handle very large numbers efficiently.
3. **Calculate Total Matchsticks**: For each digit in the input number, look up the matchstick count from the dictionary and sum these values.
4. **Output the Result**: Print the total matchstick count for each test case.

### Solution Code
```python
def main():
    stick_counts = {'0': 6, '1': 2, '2': 5, '3': 5, '4': 4, 
                    '5': 5, '6': 6, '7': 3, '8': 7, '9': 6}
    t = int(input())
    for _ in range(t):
        number = input().strip()
        total = sum(stick_counts[c] for c in number)
        print(total)

main()
```

### Explanation
1. **Matchstick Count Mapping**: The dictionary `stick_counts` maps each digit to its respective matchstick count based on the seven-segment display configuration.
2. **Reading Input**: The number of test cases `t` is read first. For each test case, the number is read as a string to handle potentially very large values.
3. **Summing Matchsticks**: For each character (digit) in the input string, the corresponding matchstick count is retrieved from the dictionary and summed up.
4. **Efficiency**: The approach efficiently processes each digit in the input string in linear time, making it suitable even for the upper constraint of 100,000 digits per test case.

This solution ensures that we accurately and efficiently compute the total number of matchsticks required for any given number using a straightforward lookup and summation method.
