To solve this problem, we need to determine the minimum number of moves required to create an array with a sum of at least `n`. The array starts with a single element `1`, and we can either increment an element or append a copy of an element in each move.

### Approach
The key insight is to recognize that the optimal strategy involves creating elements of a certain value and then duplicating them. The goal is to find the minimum number of moves by considering elements that are as close as possible to the square root of `n`. This approach ensures that we minimize the total number of increments and duplications.

1. **Square Root Insight**: The optimal number of moves is found by considering values around the integer square root of `n`. This is because the product of two numbers close to the square root of `n` will be close to `n`, minimizing their sum.
2. **Candidates Check**: For each test case, we check three candidates around the integer square root of `n`: the integer part itself, one less, and one more. This ensures we don't miss a potentially better solution just outside the immediate vicinity of the square root.
3. **Ceiling Division**: For each candidate value `x`, compute the minimum number of elements `m` needed such that their product with `x` is at least `n`. This is done using ceiling division to ensure we meet or exceed `n`.

### Solution Code
```python
import math

def main():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    for i in range(1, t + 1):
        n = int(input[i])
        if n == 1:
            print(0)
            continue
        x = math.isqrt(n)
        candidates = [x - 1, x, x + 1]
        min_steps = float('inf')
        for cand in candidates:
            if cand <= 0:
                continue
            m = (n + cand - 1) // cand  # Ceiling division
            total = cand + m
            if total < min_steps:
                min_steps = total
        print(min_steps - 2)

if __name__ == "__main__":
    main()
```

4. **Ceiling Division**: For each candidate, compute the minimum number of elements needed using ceiling division to ensure the product meets or exceeds `n`.
5. **Minimum Steps Calculation**: Track the minimum steps required by evaluating each candidate and adjusting for the initial element setup.
