A beautiful rectangle is defined as one where each row and each column contains distinct values. The solution involves determining the optimal dimensions of the rectangle and then arranging the selected integers in such a way that the beautiful property is maintained.

### Approach
1. **Frequency Calculation**: First, count the frequency of each integer in the input list.
2. **Sorting Frequencies**: Sort these frequencies in non-increasing order to facilitate efficient calculations.
3. **Prefix Sum Array**: Compute a prefix sum array of the sorted frequencies to quickly calculate sums of subsets of frequencies.
4. **Determine Optimal Dimensions**: For each possible value of `m` (from 1 to the maximum frequency), calculate the maximum possible sum of elements that can form a rectangle with dimensions `p x q` where `m = min(p, q)`. This involves checking if the sum of elements can form such a rectangle and then finding the largest possible product of `p` and `q`.
5. **Construct the Grid**: Once the optimal dimensions are determined, collect the required elements and arrange them in a grid such that each row and column contains distinct values.

import sys
from collections import defaultdict
import bisect

def main():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    freq = defaultdict(int)
    for num in a:
        freq[num] += 1
    freq_list = sorted(freq.values(), reverse=True)
    max_freq = freq_list[0] if freq_list else 0

    prefix = [0] * (len(freq_list) + 1)
    for i in range(len(freq_list)):
        prefix[i + 1] = prefix[i] + freq_list[i]

    total_sum = n
    best_area = 0
    best_p = 1
    best_q = 1
    best_m = 0

    for m in range(1, max_freq + 1):
        pos = bisect.bisect_left(freq_list, m, lo=0, hi=len(freq_list), key=lambda x: -x)
        count_ge_m = pos
        sum_ge_m = count_ge_m * m
        sum_rest = total_sum - prefix[count_ge_m]
        sum_s = sum_ge_m + sum_rest

        if sum_s < m * m:
            continue

        s = int(sum_s ** 0.5)
        max_x = 0
        current_p = 0
        current_q = 0
        max_pq = min(s, sum_s // m)
        for p_candidate in range(max_pq, m - 1, -1):
            q_candidate = sum_s // p_candidate
            if q_candidate < m:
                continue
            if p_candidate * q_candidate > sum_s:
                q_candidate = sum_s // p_candidate
            if q_candidate < m:
                continue
            current_area = p_candidate * q_candidate
            if current_area > max_x and p_candidate >= m and q_candidate >= m:
                max_x = current_area
                current_p = p_candidate
                current_q = q_candidate
                break

        if max_x > best_area:
            best_area = max_x
            best_p = current_p
            best_q = current_q
            best_m = m

    p = best_p
    q = best_q

    element_counts = defaultdict(int)
    for num in a:
        if element_counts[num] < m:
            element_counts[num] += 1

    elements = []
    for num, cnt in element_counts.items():
        elements.extend([num] * cnt)

    freq_elements = defaultdict(int)
    for num in elements:
        freq_elements[num] += 1

    sorted_elements = []
    for num in sorted(freq_elements.keys(), key=lambda x: (-freq_elements[x], x)):
        sorted_elements.extend([num] * freq_elements[num])

    grid = [[0] * q for _ in range(p)]
    used_in_row = [set() for _ in range(p)]
    used_in_col = [set() for _ in range(q)]
