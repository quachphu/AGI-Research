To solve this problem, we need to determine the number of immediate subordinates each member in a company has based on their hierarchical structure. The hierarchy is defined such that each member (except the root member) has exactly one immediate boss with a smaller ID number.

### Approach
1. **Input Reading**: Read the number of members, \( N \), and the list of immediate bosses for members 2 through \( N \).
2. **Frequency Counting**: Use an array to count how many times each member ID appears as a boss in the input list. This frequency count directly gives the number of immediate subordinates for each member.
3. **Output the Results**: For each member from 1 to \( N \), output the count of their immediate subordinates.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    counts = [0] * (n + 1)  # Using 1-based indexing
    for boss in a:
        counts[boss] += 1
    for i in range(1, n + 1):
        print(counts[i])

main()
```

### Explanation
1. **Reading Input**: The first line of input is the number of members \( N \). The second line contains \( N-1 \) integers representing the immediate bosses for members 2 through \( N \).
2. **Counting Subordinates**: We initialize a counts array of size \( N+1 \) (to handle 1-based indexing). For each entry in the list of bosses, we increment the count at the corresponding index in the counts array. This effectively counts how many times each member is listed as a boss, which corresponds to their number of immediate subordinates.
3. **Output**: We iterate from 1 to \( N \) and print the count of immediate subordinates for each member.

This approach efficiently processes the input in linear time, \( O(N) \), making it suitable even for the upper constraint of \( N = 200,000 \).
