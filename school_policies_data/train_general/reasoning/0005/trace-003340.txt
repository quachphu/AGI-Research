To solve this problem, we need to determine the maximum number of students who can be awarded diplomas and certificates such that the number of certificates is exactly k times the number of diplomas, and the total number of winners does not exceed half of the total number of students. 

### Approach
1. **Understanding Constraints**: The number of certificates must be exactly k times the number of diplomas. The total number of winners (those who receive either a diploma or a certificate) must not exceed half of the total number of students.
2. **Formulating the Problem**: Let the number of diplomas be `d` and certificates be `c`. Then, `c = k * d`. The total number of winners is `d + c = d * (k + 1)`. This sum must be less than or equal to half of the total number of students, `n // 2`.
3. **Maximizing Winners**: To maximize the number of winners, we need to find the maximum integer value of `d` such that `d * (k + 1) <= n // 2`. This can be computed as `d = (n // 2) // (k + 1)`.
4. **Calculating Results**: Once we determine `d`, we can compute `c` as `k * d` and the number of non-winners as `n - (d + c)`.

### Solution Code
```python
def main():
    import sys
    n, k = map(int, sys.stdin.readline().split())
    half = n // 2
    denominator = k + 1
    d = half // denominator
    c = d * k
    non_winners = n - (d + c)
    print(d, c, non_winners)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads the input values `n` (number of students) and `k` (ratio of certificates to diplomas).
2. **Calculating Half the Students**: Compute half of the total number of students using integer division `n // 2`.
3. **Determining Maximum Diplomas**: The maximum number of diplomas `d` is determined by dividing the half count by `k + 1` using integer division.
4. **Calculating Certificates and Non-Winners**: Using the computed `d`, the number of certificates `c` is `k * d`. The number of non-winners is the remaining students after accounting for all winners.

This approach efficiently computes the solution in constant time, making it suitable for very large input values up to \(10^{12}\).
