To solve this problem, we need to determine how many generals sitting on the perimeter of a rectangular table require warm blankets because they are not within the heating range of any radiators. The solution involves generating all perimeter points of the rectangle and checking each point against the radiators' heating areas.

### Approach
1. **Identify Rectangle Boundaries**: Determine the minimum and maximum x and y coordinates from the given opposite corners of the rectangle.
2. **Generate Perimeter Points**: Calculate all integer points along the perimeter of the rectangle. These points include the top and bottom edges, and the left and right edges (excluding the corners already included in the top and bottom edges).
3. **Check Heating Coverage**: For each perimeter point, check if it lies within the heating radius of any radiator. If a point is not covered by any radiator, count it as needing a blanket.

### Solution Code
```python
# Read the coordinates of the rectangle's two opposite corners
xa, ya, xb, yb = map(int, input().split())
x_min = min(xa, xb)
x_max = max(xa, xb)
y_min = min(ya, yb)
y_max = max(ya, yb)

# Generate all perimeter points
perimeter = set()

# Top and bottom edges
for x in range(x_min, x_max + 1):
    perimeter.add((x, y_max))
    perimeter.add((x, y_min))

# Left and right edges, excluding the top and bottom corners
for y in range(y_min + 1, y_max):
    perimeter.add((x_min, y))
    perimeter.add((x_max, y))

# Read the radiators
n = int(input())
radiators = []
for _ in range(n):
    xi, yi, ri = map(int, input().split())
    radiators.append((xi, yi, ri))

# Check each perimeter point against all radiators
count = 0
for (x, y) in perimeter:
    covered = False
    for (xi, yi, ri) in radiators:
        dx = x - xi
        dy = y - yi
        if dx * dx + dy * dy <= ri * ri:
            covered = True
            break
    if not covered:
        count += 1

print(count)
```

### Explanation
1. **Reading Input**: The first line of input provides the coordinates of two opposite corners of the rectangle. The second line gives the number of radiators, followed by their coordinates and radii.
2. **Generating Perimeter Points**: The rectangle's perimeter points are determined by iterating over the edges. The top and bottom edges are horizontal lines covering all x values between the minimum and maximum x coordinates. The left and right edges are vertical lines covering y values between the minimum and maximum y coordinates, excluding the corners already included in the top and bottom edges.
3. **Checking Radiator Coverage**: For each perimeter point, we check if it lies within the heating radius of any radiator by calculating the Euclidean distance squared (to avoid floating-point operations) and comparing it with the radiator's radius squared. If a point is not covered by any radiator, it is counted as needing a blanket.

This approach efficiently checks each perimeter point against all radiators, ensuring accurate and optimal coverage determination.
