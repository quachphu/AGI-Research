To solve this problem, we need to select M different cakes from N available options such that the sum of the absolute values of their total beauty, tastiness, and popularity is maximized. The key challenge is determining the optimal combination of cakes to achieve this maximum value.

### Approach
1. **Sign Combinations**: Since the absolute values can be maximized in either the positive or negative direction for each parameter (beauty, tastiness, popularity), we consider all 8 possible combinations of signs (±1 for each parameter).
2. **Sorting and Selection**: For each combination of signs, we compute a score for each cake by applying these signs to their respective parameters. We then sort the cakes based on these scores in descending order and select the top M cakes.
3. **Sum Calculation**: For each combination of signs, we calculate the total sums of beauty, tastiness, and popularity for the selected M cakes. The maximum value is determined by taking the sum of the absolute values of these totals.

### Solution Code
```python
import itertools

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    m = int(input[1])
    data = list(map(int, input[2:]))
    cakes = []
    idx = 0
    for _ in range(n):
        x = data[idx]
        y = data[idx+1]
        z = data[idx+2]
        cakes.append((x, y, z))
        idx += 3
    
    max_total = 0
    
    for signs in itertools.product([1, -1], repeat=3):
        sorted_cakes = sorted(cakes, key=lambda cake: (signs[0]*cake[0] + signs[1]*cake[1] + signs[2]*cake[2]), reverse=True)
        selected = sorted_cakes[:m]
        sum_x = sum(c[0] for c in selected)
        sum_y = sum(c[1] for c in selected)
        sum_z = sum(c[2] for c in selected)
        total = abs(sum_x) + abs(sum_y) + abs(sum_z)
        if total > max_total:
            max_total = total
    
    print(max_total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into a list of tuples representing each cake's parameters.
2. **Generating Sign Combinations**: Using `itertools.product`, we generate all 8 possible combinations of signs (±1) for the three parameters.
3. **Sorting and Selection**: For each sign combination, we compute a score for each cake by applying the current signs. The cakes are sorted by these scores, and the top M cakes are selected.
4. **Sum Calculation**: The sums of the selected cakes' parameters are computed, and their absolute values are summed to get the total. The maximum total across all sign combinations is tracked and printed.

This approach ensures that we explore all possible ways to maximize the sum of absolute values by considering both positive and negative contributions of each parameter, leading to the optimal solution.
