To solve this problem, we need to determine the probability that the New Year Bot's decision is valid. The decision is valid if the chosen item by the bot for a randomly selected kid is present in another randomly selected kid's wish list. The solution involves calculating this probability and presenting it in a specific modular arithmetic form.

### Approach
1. **Understanding the Problem**: The bot's decision involves selecting a kid (x), an item (y) from x's wish list, and another kid (z). The decision is valid if z's wish list includes y. We need to compute the probability of this event.

2. **Mathematical Formulation**:
   - For each item y, count how many kids have y in their wish list (denoted as c(y)).
   - The probability is the sum over all possible (x, y, z) combinations where y is in z's list, divided by the total number of possible decisions.

3. **Efficient Calculation**:
   - Use a dictionary to count occurrences of each item across all kids.
   - For each kid x, compute the sum of counts of all items in their wish list, then divide by the number of items in their list (k_x).
   - Sum these values for all kids and normalize by the square of the number of kids (n^2) using modular arithmetic.

### Solution Code
```python
MOD = 998244353

n = int(input())
from collections import defaultdict

count = defaultdict(int)
lists = []

for _ in range(n):
    parts = list(map(int, input().split()))
    k_i = parts[0]
    items = parts[1:]
    lists.append((k_i, items))
    for y in items:
        count[y] += 1

total_S = 0
for k_i, items in lists:
    sum_c = 0
    for y in items:
        sum_c += count[y]
    inv_k = pow(k_i, MOD - 2, MOD)
    term = (sum_c * inv_k) % MOD
    total_S = (total_S + term) % MOD

inv_n = pow(n, MOD - 2, MOD)
inv_n_squared = (inv_n * inv_n) % MOD
result = (total_S * inv_n_squared) % MOD

print(result)
```

### Explanation
1. **Reading Input**: We read the number of kids and their wish lists, storing each list and counting the occurrences of each item using a dictionary.

2. **Counting Occurrences**: For each item in each kid's wish list, we increment its count in the dictionary.

3. **Summing Valid Probabilities**: For each kid, we compute the sum of counts of items in their wish list. Each sum is then divided by the number of items in that kid's list using modular inverse to handle division in modular arithmetic.

4. **Final Calculation**: The accumulated sum is normalized by the square of the number of kids (n^2) using modular arithmetic to get the final result.

This approach efficiently handles large inputs and ensures correctness using modular arithmetic, adhering to the problem constraints and requirements.
