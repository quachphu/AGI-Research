To solve this problem, we need to determine the largest possible integer that can be displayed on an electronic screen using no more than a given number of segments. Each digit on the screen uses a specific number of segments, and our goal is to maximize the number of digits while using the segments efficiently.

### Approach
1. **Understanding Segment Usage**: Each digit from 0 to 9 uses a different number of segments. For example, the digit '1' uses 2 segments, while '7' uses 3 segments.
2. **Maximizing Digits**: The largest possible number is achieved by using the maximum number of digits. The digit '1' uses the fewest segments (2), so using as many '1's as possible will generally yield the longest number.
3. **Handling Odd Segments**: If the total number of segments (n) is odd, we can use one '7' (which uses 3 segments) and then fill the remaining segments with '1's. This is because converting an odd number of segments into even (after using 3 segments for '7') allows us to use the remaining segments optimally.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    for i in range(1, t + 1):
        n = int(input[i])
        if n % 2 == 0:
            count = n // 2
            print('1' * count)
        else:
            count = (n - 3) // 2
            print('7' + '1' * count)

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings for efficient processing.
2. **Processing Each Test Case**: For each test case, we check if the number of segments (n) is even or odd.
   - **Even n**: If n is even, we can use all '1's, as each '1' uses 2 segments. The number of '1's is `n // 2`.
   - **Odd n**: If n is odd, we use one '7' (3 segments) and then the remaining segments (n-3) will be even. The remaining segments are filled with '1's, resulting in `(n - 3) // 2` '1's.
3. **Output the Result**: For each test case, the result is constructed as a string and printed immediately.

This approach ensures that we use the segments efficiently to form the largest possible integer by maximizing the number of digits while adhering to the segment constraints.
