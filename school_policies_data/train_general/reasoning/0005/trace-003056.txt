To solve this problem, we need to determine the maximum possible score when moving from vertex 1 to vertex N in a directed graph, considering the possibility of an infinitely increasing score due to positive cycles.

### Approach
1. **Graph Analysis**: First, identify all nodes reachable from vertex 1 and all nodes that can reach vertex N. This helps in focusing only on the relevant subgraph that can influence the score.
2. **Cycle Detection**: Check if there exists a positive cycle within the relevant subgraph (nodes that are both reachable from vertex 1 and can reach vertex N). If such a cycle exists, the score can be made infinitely large.
3. **Longest Path Calculation**: If no positive cycles are found, compute the longest path using a modified Bellman-Ford algorithm. This algorithm is adjusted to maximize the score instead of minimizing it.

### Solution Code
```python
import sys
from collections import deque

def main():
    n, m = map(int, sys.stdin.readline().split())
    edges = []
    adj = [[] for _ in range(n + 1)]
    reverse_adj = [[] for _ in range(n + 1)]

    for _ in range(m):
        a, b, c = map(int, sys.stdin.readline().split())
        edges.append((a, b, c))
        adj[a].append(b)
        reverse_adj[b].append(a)

    # Compute nodes reachable from 1
    reachable = set()
    q = deque([1])
    reachable.add(1)
    while q:
        u = q.popleft()
        for v in adj[u]:
            if v not in reachable:
                reachable.add(v)
                q.append(v)

    # Compute nodes that can reach N
    can_reach_n = set()
    q = deque([n])
    can_reach_n.add(n)
    while q:
        u = q.popleft()
        for v in reverse_adj[u]:
            if v not in can_reach_n:
                can_reach_n.add(v)
                q.append(v)

    # Collect relevant edges
    relevant_edges = []
    for a, b, c in edges:
        if a in reachable and b in can_reach_n:
            relevant_edges.append((a, b, c))

    # Bellman-Ford to find maximum path
    INF = float('-inf')
    dist = [INF] * (n + 1)
    dist[1] = 0

    for i in range(n - 1):
        updated = False
        for a, b, c in relevant_edges:
            if dist[a] != INF and dist[b] < dist[a] + c:
                dist[b] = dist[a] + c
                updated = True
        if not updated:
            break

    # Check for possible infinite score
    has_infinite = False
    for a, b, c in relevant_edges:
        if dist[a] != INF and dist[b] < dist[a] + c:
            has_infinite = True
            break

    if has_infinite:
        print("inf")
    else:
        print(dist[n])

if __name__ == "__main__":
    main()
```

2. **Relevant Edges**: Filter edges to only those that start from a reachable node and end at a node that can reach vertex N.
3. **Bellman-Ford Algorithm**: This algorithm is used to compute the longest path by relaxing edges up to N-1 times. If any edge can still be relaxed after N-1 iterations, it indicates a positive cycle, leading to an infinite score. Otherwise, the maximum score to vertex N is output.

This approach efficiently handles the constraints and ensures optimal performance for the given problem limits.
