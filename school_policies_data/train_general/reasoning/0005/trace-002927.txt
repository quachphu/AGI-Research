### Approach

2. **Key Observations**:
   - The valid pairs (x, y) must satisfy x < y and both x and y must be valid days in their respective months.
   - The maximum valid value for both x and y is the minimum of the number of months (m) and the number of days per month (d), denoted as k.

3. **Mathematical Formulation**:
   - For a pair (x, y) to be ambiguous, the difference (y - x) multiplied by (d - 1) must be divisible by the number of days in a week (w). This reduces to finding pairs where the difference (y - x) is a multiple of w divided by the greatest common divisor (gcd) of (d-1) and w.

4. **Efficient Calculation**:

### Solution Code
```python
import math
import sys

def count_ambiguous_pairs():
    t = int(sys.stdin.readline())
    for _ in range(t):
        m, d, w = map(int, sys.stdin.readline().split())
        k = min(m, d)
        if k < 2:
            print(0)
            continue
        if d == 1:
            print(k * (k - 1) // 2)
            continue
        a = d - 1
        g = math.gcd(a, w)
        mod_val = w // g
        max_diff = k - 1
        t_val = max_diff // mod_val
        ans = t_val * k - mod_val * t_val * (t_val + 1) // 2
        print(ans)

count_ambiguous_pairs()
```
