To solve this problem, we need to determine if each of the given strings found under the pillow is "Good" or "Bad" based on specific criteria. A string is considered "Good" if its length is at least 47 characters or if it contains any of the Little Elephant's favorite lucky strings as a substring.

### Approach
1. **Input Reading**: Read the number of favorite strings (K) and the number of test strings (N).
2. **Store Favorite Strings**: Store all the favorite strings provided by the Little Elephant.
3. **Check Each Test String**:
   - If the length of the test string is 47 or more, it is immediately classified as "Good".
   - If the length is less than 47, check if any of the favorite strings is a substring of the test string. If any favorite string is found as a substring, classify it as "Good"; otherwise, classify it as "Bad".

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    K = int(input[ptr])
    ptr += 1
    N = int(input[ptr])
    ptr += 1
    favorites = []
    for _ in range(K):
        favorites.append(input[ptr])
        ptr += 1
    for _ in range(N):
        bi = input[ptr]
        ptr += 1
        if len(bi) >= 47:
            print("Good")
        else:
            found = False
            for aj in favorites:
                if aj in bi:
                    found = True
                    break
            print("Good" if found else "Bad")

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings for easier processing. The first two values are K (number of favorite strings) and N (number of test strings).
2. **Storing Favorites**: The next K strings are stored in a list of favorite strings.
3. **Processing Each Test String**:
   - For each test string, check its length. If it is 47 or longer, print "Good".
   - If the length is less than 47, iterate through each favorite string and check if it is a substring of the test string using Python's `in` operator. If any favorite string is found, print "Good"; otherwise, print "Bad".

This approach efficiently checks each test string against the given criteria, ensuring optimal performance even with the maximum constraints.
