To solve this problem, we need to compute the sum of the floor values of dividing each natural number from 1 to N by 2. Given the constraints, we must ensure our solution is efficient and handles up to 100,000 test cases with N values up to 10,000.

### Approach
The key insight is to derive a mathematical formula to compute the sum in constant time O(1) for each test case. By analyzing the problem, we observe that the sum can be split into two cases based on whether N is even or odd. However, we can generalize the formula to avoid separate cases:

1. **Formula Derivation**: The sum of floor values can be expressed as:
   \[
   \text{sum\_floor} = \frac{N(N+1) - 2 \times \left\lfloor \frac{N+1}{2} \right\rfloor}{4}
   \]
   This formula efficiently combines integer arithmetic to avoid floating-point operations, ensuring precision and efficiency.

2. **Efficient Input Handling**: Reading all input at once using `sys.stdin.read()` ensures quick processing even for large input sizes.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        N = int(input[i])
        res = (N * (N + 1) - 2 * ((N + 1) // 2)) // 4
        print(res)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings for efficient processing.
2. **Loop Through Test Cases**: For each test case, we convert the input string to an integer N.
3. **Compute the Result**: Using the derived formula, we compute the result in constant time. This formula efficiently handles both even and odd values of N using integer arithmetic.
4. **Output the Result**: The result for each test case is printed immediately after computation.

This approach ensures that each test case is processed in O(1) time, making the solution highly efficient even for the upper limits of the input constraints.
