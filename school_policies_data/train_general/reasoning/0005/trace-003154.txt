To solve this problem, we need to determine the optimal integer coordinate on a number line where a meeting should be held such that the total stamina spent by all attendees is minimized. The stamina spent by each person is calculated as the square of the difference between their position and the meeting point.

### Approach
1. **Understanding the Problem**: The goal is to find the integer coordinate \( P \) that minimizes the sum of squared differences from each person's position \( X_i \). The sum of squared differences is minimized at the mean of the positions. However, since \( P \) must be an integer, we need to check the integers around the mean.

2. **Brute-force Search**: Given the constraints (positions range from 1 to 100 and the number of people \( N \) is up to 100), a brute-force approach is feasible. We check all possible integer positions between the minimum and maximum values of the given positions. This ensures we cover all potential optimal points efficiently.

3. **Algorithm**:
   - Read the input values.
   - Determine the minimum and maximum positions in the list.
   - For each integer position between these bounds, compute the total stamina spent.
   - Track the minimum stamina encountered during these computations.

### Solution Code
```python
n = int(input())
x_list = list(map(int, input().split()))
min_x = min(x_list)
max_x = max(x_list)
min_sum = float('inf')

for p in range(min_x, max_x + 1):
    total = 0
    for x in x_list:
        total += (x - p) ** 2
    if total < min_sum:
        min_sum = total

print(min_sum)
```

### Explanation
- **Reading Input**: The input consists of an integer \( N \) followed by \( N \) integers representing the positions of the people.
- **Determining Range**: Calculate the minimum and maximum positions to narrow down the range of potential meeting points.
- **Computing Stamina**: For each integer position within the determined range, compute the total stamina spent by all people if the meeting were held at that position. This is done by summing the squared differences between each person's position and the candidate meeting point.
- **Finding Minimum**: Track the minimum stamina value encountered during the iteration over all candidate positions.

This approach ensures that we efficiently explore all feasible meeting points and find the one that minimizes the total stamina expenditure, leveraging the constraints to keep the solution computationally feasible.
