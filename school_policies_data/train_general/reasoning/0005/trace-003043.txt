To solve this problem, we need to determine if each node in a directed graph can be the start of a "special walk," which is a simple path that starts and ends at the same node with all intermediate nodes being distinct and not equal to the starting node. This translates to checking if each node is part of a cycle of length at least 2.

### Approach
1. **Identify Strongly Connected Components (SCCs)**: A strongly connected component of a directed graph is a maximal subgraph where every node is reachable from every other node. Nodes in an SCC of size 2 or more are part of a cycle of length at least 2.
2. **Kosaraju's Algorithm**: This algorithm efficiently finds SCCs in linear time. It involves two depth-first search (DFS) passes:
   - **First Pass**: Process the graph and record nodes by their finishing times.
   - **Second Pass**: Process the transposed graph (reversed edges) in the order of decreasing finishing times from the first pass to identify SCCs.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    M = int(input[idx])
    idx += 1

    adj = [[] for _ in range(N + 1)]
    rev_adj = [[] for _ in range(N + 1)]
    for _ in range(M):
        u = int(input[idx])
        idx += 1
        v = int(input[idx])
        idx += 1
        adj[u].append(v)
        rev_adj[v].append(u)

    # First pass to get the order
    visited = [False] * (N + 1)
    order = []
    for node in range(1, N + 1):
        if not visited[node]:
            stack = [(node, False)]
            while stack:
                current, processed = stack.pop()
                if processed:
                    order.append(current)
                    continue
                if visited[current]:
                    continue
                visited[current] = True
                stack.append((current, True))
                # Push children in reverse order to process them in the original order
                for neighbor in reversed(adj[current]):
                    if not visited[neighbor]:
                        stack.append((neighbor, False))

    # Second pass to find components
    visited = [False] * (N + 1)
    components = []
    while order:
        node = order.pop()
        if not visited[node]:
            component = []
            stack = [node]
            visited[node] = True
            while stack:
                current = stack.pop()
                component.append(current)
                for neighbor in rev_adj[current]:
                    if not visited[neighbor]:
                        visited[neighbor] = True
                        stack.append(neighbor)
            components.append(component)

    # Prepare the result
    result = [0] * (N + 1)
    for comp in components:
        if len(comp) >= 2:
            for node in comp:
                result[node] = 1

    # Print the result from 1 to N
    print(' '.join(map(str, result[1:N+1])))

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read and parsed into adjacency lists for the graph and its transpose.
2. **First DFS Pass**: Nodes are processed and their finishing times are recorded. This helps in determining the order for the second pass.
3. **Second DFS Pass**: The transposed graph is processed in the order of decreasing finishing times from the first pass. Each DFS in this pass identifies an SCC.
4. **Determine Special Walk Feasibility**: Nodes in SCCs of size 2 or more can start a special walk, so they are marked with 1. Nodes in smaller components are marked with 0.

This approach efficiently identifies SCCs using Kosaraju's algorithm and checks their sizes to determine the feasibility of special walks, ensuring optimal performance for large graphs.
