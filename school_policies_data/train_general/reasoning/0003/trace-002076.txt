To solve this problem, we need to determine the maximum initial health of an enemy that Meka-Naruto can kill using his ability, considering the ability's cooldown and healing effects. The solution involves analyzing the net damage over time and determining if the cumulative damage can overcome the healing effects.

### Approach
1. **Immediate Check for Unbounded Health**: If the instant damage `a` is greater than the total healing from one cast (i.e., `a > b * c`), Meka-Naruto can kill any health value, so the answer is `-1`.
2. **Quadratic and Linear Analysis**:
   - **Quadratic Part**: When the number of casts `k` is within a range where healing effects overlap, the net damage can be modeled as a quadratic function. The maximum value of this quadratic function is determined by evaluating key points around its vertex.
   - **Linear Part**: When the number of casts `k` exceeds a certain threshold, the net damage becomes linear. The maximum value here is evaluated at the start of this linear part.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    t = int(input[0])
    idx = 1
    for _ in range(t):
        a = int(input[idx])
        b = int(input[idx+1])
        c = int(input[idx+2])
        d = int(input[idx+3])
        idx += 4
        
        if a > b * c:
            print(-1)
            continue
        
        m_max = c // d
        vertex_k = (2 * a + b * d) / (2 * b * d)
        k_opt_floor = int(vertex_k)
        k_opt_ceil = k_opt_floor + 1
        
        candidates = {1, m_max + 1, k_opt_floor, k_opt_ceil}
        max_quad = -1
        
        for k in candidates:
            if 1 <= k <= m_max + 1:
                sum_heals = d * (k - 1) * k // 2
                current_v = a * k - b * sum_heals
                if current_v > max_quad:
                    max_quad = current_v
        
        k_lin = m_max + 2
        sum_heals_lin = d * m_max * (m_max + 1) // 2 + c * (k_lin - 1 - m_max)
        current_v_lin = a * k_lin - b * sum_heals_lin
        max_total = max(max_quad, current_v_lin)
        
        print(max_total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Unbounded Health Check**: If the instant damage `a` exceeds the total healing from one cast, the answer is immediately `-1`.
3. **Quadratic Analysis**: The quadratic part of the solution involves evaluating potential maximum values around the vertex of the quadratic function derived from the net damage model. Key candidates (k values) around the vertex are checked.
4. **Linear Analysis**: Once the number of casts exceeds a certain threshold, the net damage becomes linear. The maximum value in this linear part is evaluated at the threshold point.

This approach efficiently combines both quadratic and linear analysis to determine the maximum health value that can be killed, ensuring optimal performance even for large input sizes.
