To solve this problem, we need to determine the number of valid configurations of a 2×n grid that can be achieved by swapping columns, such that each row and column contains distinct numbers. The solution involves analyzing the problem using graph theory to identify cycles in the grid's structure.

### Approach
1. **Graph Representation**: Represent the grid as a bipartite graph where each number in the first row (top) is connected to the corresponding number in the second row (bottom) for each column.
2. **Cycle Detection**: Each column's elements form edges in this graph. By traversing the graph, we can identify cycles, which represent groups of columns that can be swapped in a way that maintains valid permutations in both rows.
3. **Cycle Counting**: The number of valid configurations is determined by the number of cycles found in the graph. Each cycle contributes a factor of 2 to the total number of configurations, as each cycle can be either swapped or not swapped independently.

### Solution Code
```python
import sys
MOD = 10**9 + 7

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        A = list(map(int, input[ptr:ptr+n]))
        ptr += n
        B = list(map(int, input[ptr:ptr+n]))
        ptr += n
        
        adj = [[] for _ in range(n + 1)]  # Using 1-based indexing
        for i in range(n):
            a = A[i]
            b = B[i]
            adj[a].append(b)
            adj[b].append(a)
        
        visited = [False] * (n + 1)
        cycles = 0
        
        for x in range(1, n + 1):
            if not visited[x]:
                cycles += 1
                current = x
                prev = None
                while True:
                    if visited[current]:
                        break
                    visited[current] = True
                    next_nodes = adj[current]
                    # Determine the next node that is not the previous node
                    if next_nodes[0] != prev:
                        next_node = next_nodes[0]
                    else:
                        next_node = next_nodes[1]
                    prev = current
                    current = next_node
        
        ans = pow(2, cycles, MOD)
        print(ans)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in a single read operation for efficiency, especially given the constraints.
2. **Graph Construction**: An adjacency list is built where each element in the first row is connected to the corresponding element in the second row for each column.
3. **Cycle Detection**: Using a depth-first search (DFS) approach, we traverse the graph to count the number of cycles. Each cycle represents a group of columns that can be independently swapped to form valid configurations.
4. **Result Calculation**: The number of valid configurations is calculated as \(2^{\text{cycles}} \mod 10^9 + 7\), where each cycle contributes a factor of 2 due to the two possible states (swapped or not swapped).

This approach efficiently handles the constraints and ensures that the solution is computed in linear time relative to the input size, making it suitable for large inputs.
