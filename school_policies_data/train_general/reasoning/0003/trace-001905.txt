To solve this problem, we need to determine the number of islands in a 12x12 grid where each cell is either land (1) or sea (0). An island is defined as a contiguous block of land cells connected vertically or horizontally.

### Approach
1. **Input Handling**: Read all input lines, filter out any empty lines, and group the remaining lines into chunks of 12 lines each, where each chunk represents a grid.
2. **Grid Processing**: For each grid, use a Breadth-First Search (BFS) algorithm to count the number of contiguous land regions (islands).
3. **BFS Implementation**: For each land cell that hasn't been visited, initiate a BFS to mark all contiguous land cells as visited, incrementing the island count each time a new BFS is initiated.

### Solution Code
```python
import sys
from collections import deque

def count_islands(grid):
    rows = len(grid)
    if rows == 0:
        return 0
    cols = len(grid[0])
    visited = [[False for _ in range(cols)] for _ in range(rows)]
    count = 0

    for i in range(rows):
        for j in range(cols):
            if grid[i][j] == '1' and not visited[i][j]:
                count += 1
                queue = deque()
                queue.append((i, j))
                visited[i][j] = True

                while queue:
                    x, y = queue.popleft()
                    for dx, dy in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                        nx = x + dx
                        ny = y + dy
                        if 0 <= nx < rows and 0 <= ny < cols:
                            if grid[nx][ny] == '1' and not visited[nx][ny]:
                                visited[nx][ny] = True
                                queue.append((nx, ny))

    return count

def main():
    lines = [line.strip() for line in sys.stdin if line.strip()]
    datasets = [lines[i*12 : (i+1)*12] for i in range(len(lines) // 12)]
    for grid in datasets:
        print(count_islands(grid))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once, and empty lines are filtered out. The remaining lines are grouped into datasets of 12 lines each.
2. **BFS for Island Counting**: For each grid, we initialize a visited matrix to keep track of which cells have been processed. For each unvisited land cell, we initiate a BFS to explore all contiguous land cells, marking them as visited. Each BFS initiation corresponds to discovering a new island.
3. **Efficiency**: BFS ensures that each cell is processed exactly once, leading to an efficient solution with a time complexity of O(N) where N is the number of cells in the grid (12x12 = 144 cells per grid). This ensures the solution is efficient even for the maximum input size.
