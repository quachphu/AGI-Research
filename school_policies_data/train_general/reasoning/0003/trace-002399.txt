To solve this problem, we need to count the number of pairs (i, j) such that i < j and the product of the elements at these indices is greater than the sum of the elements. The solution must efficiently handle large input sizes up to 100,000 elements.

### Approach
1. **Problem Analysis**: The key insight is that for two numbers a and b, the condition a*b > a + b can be transformed into (a-1)(b-1) > 1. This transformation helps us focus on pairs where both elements are at least 2.
2. **Efficient Counting**: Using a Fenwick Tree (Binary Indexed Tree) allows us to efficiently count valid pairs by maintaining a sorted frequency of elements as we process the array from the end to the start. This helps in quickly determining how many valid elements exist after the current element.
3. **Handling Edge Cases**: Elements less than 2 (0 or 1) are ignored since they cannot form valid pairs. For elements equal to 2, we need a special check to ensure valid pairs are counted correctly.

### Solution Code
```python
import sys

class FenwickTree:
    def __init__(self, max_val):
        self.max_val = max_val
        self.tree = [0] * (max_val + 2)  # 1-based indexing

    def update(self, x, delta):
        while x <= self.max_val:
            self.tree[x] += delta
            x += x & -x

    def query(self, x):
        res = 0
        while x > 0:
            res += self.tree[x]
            x -= x & -x
        return res

def main():
    max_val = 10**6 - 1  # Since x = a-1, max x is 1e6-1
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        A = list(map(int, input[ptr:ptr+N]))
        ptr += N
        ft = FenwickTree(max_val)
        total = 0
        # Process in reverse order
        for num in reversed(A):
            if num < 2:
                continue
            x = num - 1
            if x >= 2:
                cnt = ft.query(max_val)
            else:
                sum_all = ft.query(max_val)
                sum_1 = ft.query(1)
                cnt = sum_all - sum_1
            total += cnt
            ft.update(x, 1)
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Fenwick Tree Initialization**: The Fenwick Tree is initialized to handle values up to 999,999, which is the maximum possible value for (element-1) when the element is 1,000,000.
2. **Processing Elements**: We process each element from the end of the array to the start. For each element:
   - If the element is less than 2, it is ignored.
   - For elements 2 or more, we compute x = element - 1.
