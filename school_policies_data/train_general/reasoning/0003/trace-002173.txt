To solve this problem, we need to determine if a given unweighted, undirected graph is a tree. A tree is defined as a connected graph with no cycles. For a graph with \( N \) nodes to be a tree, it must have exactly \( N-1 \) edges and must be fully connected.

### Approach
1. **Check Edge Count**: The first step is to check if the number of edges \( M \) is exactly \( N-1 \). If \( M \neq N-1 \), the graph cannot be a tree.
2. **Check Connectivity**: If the graph has \( N-1 \) edges, we then check if the graph is fully connected using a Breadth-First Search (BFS) starting from an arbitrary node (node 1 in this case). If BFS visits all \( N \) nodes, the graph is connected and thus a tree.

### Solution Code
```python
import sys
from collections import deque

def main():
    data = sys.stdin.read().split()
    ptr = 0
    N = int(data[ptr])
    ptr += 1
    M = int(data[ptr])
    ptr += 1

    if N == 1:
        print("YES" if M == 0 else "NO")
        return

    if M != N - 1:
        print("NO")
        return

    adj = [[] for _ in range(N + 1)]
    for _ in range(M):
        u = int(data[ptr])
        ptr += 1
        v = int(data[ptr])
        ptr += 1
        adj[u].append(v)
        adj[v].append(u)

    visited = set()
    q = deque([1])
    visited.add(1)

    while q:
        u = q.popleft()
        for v in adj[u]:
            if v not in visited:
                visited.add(v)
                q.append(v)

    print("YES" if len(visited) == N else "NO")

main()
```

### Explanation
1. **Edge Count Check**: The code first checks if the number of edges \( M \) is \( N-1 \). If not, it immediately outputs "NO".
2. **Adjacency List Construction**: The graph is represented using an adjacency list to efficiently store and traverse edges.
3. **BFS for Connectivity**: Starting from node 1, the BFS algorithm traverses all reachable nodes. If all \( N \) nodes are visited, the graph is connected, confirming it is a tree. If not, the graph is disconnected and thus not a tree.

This approach ensures that we efficiently determine if the graph meets both necessary conditions for being a tree: correct edge count and full connectivity. The BFS ensures we check connectivity in linear time \( O(N + M) \), making the solution efficient even for the upper constraint limits.
