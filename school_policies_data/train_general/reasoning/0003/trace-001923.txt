To solve this problem, we need to find the minimum possible total cost to collect `k` unique subsequences from a given string `s` of length `n`. The cost for each subsequence is calculated as `n - length(subsequence)`. If it's impossible to gather `k` unique subsequences, we return `-1`.

### Approach
1. **Dynamic Programming (DP) Setup**: Use a DP array to track the number of distinct subsequences of each possible length. The array `dp[l]` will store the count of distinct subsequences of length `l`.

2. **Handling Duplicates**: Maintain a dictionary `last` to track the last occurrence of each character and the counts of subsequences at that point. This helps in efficiently managing duplicate characters and avoiding overcounting subsequences.

3. **Processing Each Character**: For each character in the string, update the DP array in reverse order (from length `n` down to 1) to ensure that we correctly account for new subsequences formed by including the current character, while avoiding duplicates.

4. **Accumulating Costs**: Once the DP array is built, process the counts of subsequences in descending order of their lengths. This ensures we take the longest possible subsequences first, minimizing the total cost.

### Solution Code
```python
n, k = map(int, input().split())
s = input().strip()

# Initialize DP array where dp[l] is the number of distinct subsequences of length l
dp = [0] * (n + 1)
dp[0] = 1  # The empty subsequence

from collections import defaultdict
last = defaultdict(lambda: [0] * (n + 1))

for c in s:
    old_dp = dp.copy()
    for l in range(n, 0, -1):
        prev_last = last[c][l-1]
        new_subseq = old_dp[l-1] - prev_last
        dp[l] += new_subseq
    last[c] = old_dp.copy()

remaining = k
cost = 0

# Process from longest to shortest subsequences
for l in range(n, -1, -1):
    if remaining <= 0:
        break
    take = min(remaining, dp[l])
    cost += take * (n - l)
    remaining -= take

print(cost if remaining == 0 else -1)
```

### Explanation
1. **Dynamic Programming Array**: The DP array `dp` is initialized with `dp[0] = 1` (representing the empty subsequence) and all other values set to 0. As we process each character in the string, we update the counts of subsequences of each possible length.

2. **Handling Duplicates**: The `last` dictionary keeps track of the state of the DP array the last time each character was processed. This helps in adjusting the counts to avoid overcounting subsequences when duplicate characters are encountered.

3. **Processing Characters**: For each character, we update the DP array from the highest possible length down to 1. This ensures that we correctly compute the number of new subsequences formed by including the current character, adjusting for any duplicates.

4. **Accumulating Costs**: After building the DP array, we iterate from the longest subsequences to the shortest, taking as many as needed from each length to reach `k` subsequences. The cost is accumulated based on the length of the subsequences taken.

This approach efficiently computes the required counts and minimizes the total cost by leveraging dynamic programming and careful handling of duplicates. The solution ensures optimal performance even for the upper constraint limits.
