2. **Key Insight**:
   - For each \(m\) (from \(K\) to \(N+1\)), the possible sums of \(x_i\) form a contiguous range. The number of distinct sums for each \(m\) is given by the formula \(m \times (N - m + 1) + 1\).

def compute():

    N, K = map(int, sys.stdin.readline().split())
    a = K
    b = N + 1
    if a > b:
        print(0)
        return
    
    # Calculate sum of m from a to b
    term1 = (b % MOD) * ((b + 1) % MOD) % MOD
    term1 = term1 * inv2 % MOD
    term2 = ((a - 1) % MOD) * (a % MOD) % MOD
