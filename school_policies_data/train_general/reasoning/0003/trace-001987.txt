To solve this problem, we need to determine if a given password meets specific complexity requirements set by a company. The password must be at least 5 characters long, contain at least one uppercase letter, one lowercase letter, and one digit. If all these conditions are met, the password is considered "Correct"; otherwise, it is "Too weak".

### Approach
1. **Check Length**: The password must be at least 5 characters long. This is a straightforward check using the length of the input string.
2. **Check for Uppercase Letter**: Iterate through each character in the password to see if there is at least one uppercase letter.
3. **Check for Lowercase Letter**: Similarly, check for the presence of at least one lowercase letter.
4. **Check for Digit**: Ensure there is at least one digit in the password.

If all four conditions (length, uppercase, lowercase, digit) are satisfied, the password is deemed "Correct". If any condition fails, the password is "Too weak".

### Solution Code
```python
def check_password():
    password = input().strip()
    if len(password) < 5:
        print("Too weak")
        return
    has_upper = any(c.isupper() for c in password)
    has_lower = any(c.islower() for c in password)
    has_digit = any(c.isdigit() for c in password)
    if has_upper and has_lower and has_digit:
        print("Correct")
    else:
        print("Too weak")

check_password()
```

### Explanation
1. **Reading Input**: The password is read from standard input. The `strip()` method is used to remove any leading or trailing whitespace, which is not part of the password as per the problem constraints.
2. **Length Check**: The password's length is checked first. If it is less than 5 characters, the password is immediately deemed too weak.
3. **Character Checks**: Using generator expressions within `any()` functions, the code efficiently checks for the presence of at least one uppercase letter, one lowercase letter, and one digit.
4. **Final Decision**: After all checks, the result is printed based on whether all conditions are met.

This approach ensures that each condition is checked in an efficient manner, leveraging Python's built-in string methods and generator expressions for clarity and performance.
