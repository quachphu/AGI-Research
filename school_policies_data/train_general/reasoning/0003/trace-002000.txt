To solve this problem, we need to determine the maximum perimeter triangle that can be formed using three sticks from a given list. If multiple valid triangles exist, we choose the one with the largest possible sides in a specific order. 

### Approach
1. **Sort the Sticks**: Start by sorting the list of stick lengths in non-decreasing order. This helps in efficiently checking the largest possible triplets first.
2. **Check Triplets from Largest to Smallest**: Iterate from the end of the sorted list towards the beginning. For each triplet (a, b, c) where a <= b <= c, check if they form a valid triangle using the condition a + b > c. The first valid triplet found in this manner will be the one with the maximum perimeter and the largest possible sides.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        sticks = list(map(int, input[ptr:ptr+N]))
        ptr += N
        if N < 3:
            print(-1)
            continue
        sticks.sort()
        found = False
        # Iterate from the end towards the start
        for i in range(len(sticks)-1, 1, -1):
            a = sticks[i-2]
            b = sticks[i-1]
            c = sticks[i]
            if a + b > c:
                print(a, b, c)
                found = True
                break
        if not found:
            print(-1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Sorting**: The list of stick lengths is sorted to facilitate checking the largest triplets first.
3. **Checking Triplets**: By iterating from the end of the sorted list, we check the largest possible triplets first. The first valid triplet found (i.e., the one where the sum of the two smaller sides is greater than the largest side) is immediately returned as the result, ensuring it is the maximum perimeter triangle.
4. **Edge Cases**: If the number of sticks is less than 3, it's impossible to form a triangle, so we immediately return -1.

This approach efficiently narrows down the possible candidates using sorting and a single pass through the list, ensuring optimal performance even for large input sizes.
