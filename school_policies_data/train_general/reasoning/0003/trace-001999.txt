To solve this problem, we need to compute the total ratings of candidates after applying specific removal rules whenever a candidate scores a zero. Chandan removes both the candidate who scores zero and the immediately preceding candidate. The solution involves efficiently processing the ratings using a stack to handle these removals.

### Approach
1. **Input Reading**: Read the number of candidates and their respective ratings.
2. **Stack Processing**: Use a stack to keep track of valid candidates. For each rating:
   - If the rating is zero and the stack is not empty, remove the last candidate added to the stack (the preceding candidate).
   - If the rating is non-zero, add it to the stack.
3. **Sum Calculation**: After processing all ratings, sum the elements remaining in the stack to get the total rating of valid candidates.

This approach ensures that each candidate is processed in constant time, leading to an efficient O(n) time complexity where n is the number of candidates.

### Solution Code
```python
n = int(input())
stack = []
for _ in range(n):
    num = int(input())
    if num == 0:
        if stack:
            stack.pop()
    else:
        stack.append(num)
print(sum(stack))
```

### Explanation
1. **Reading Input**: The first input line gives the number of candidates. Subsequent lines provide each candidate's rating.
2. **Stack Operations**: As we iterate through each rating:
   - Non-zero ratings are pushed onto the stack.
   - Zero ratings trigger a check if the stack is non-empty; if so, the top element (last valid candidate) is removed, effectively handling the removal of both the zero-rated candidate and the preceding one.
3. **Summing Valid Ratings**: After processing all ratings, the sum of the remaining elements in the stack is computed and printed, giving the desired result.

This method efficiently handles the removal logic using a stack, ensuring optimal performance even for the upper constraint limits.
