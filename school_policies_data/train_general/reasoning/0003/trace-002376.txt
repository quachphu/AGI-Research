To solve this problem, we need to determine the character with the maximum frequency in a given string of lowercase letters. If multiple characters have the same maximum frequency, we select the lexicographically smallest character. Based on this character, we then check its presence in the strings 'head rush' and 'cubing club' to generate the appropriate output message.

### Approach
1. **Count Character Frequencies**: Use a dictionary to count the frequency of each character in the input string.
2. **Identify Maximum Frequency**: Determine the highest frequency of any character in the string.
3. **Select Lexicographically Smallest Character**: Among all characters with the maximum frequency, choose the lexicographically smallest one.
4. **Check Presence in Strings**: Check if the selected character is present in 'head rush', 'cubing club', both, or neither.
5. **Generate Output**: Based on the presence checks, print the corresponding message.

### Solution Code
```python
from collections import Counter

def main():
    s = input().strip()
    counts = Counter(s)
    max_freq = max(counts.values())
    max_chars = [char for char, cnt in counts.items() if cnt == max_freq]
    selected_char = min(max_chars)
    
    hr = 'head rush'
    cc = 'cubing club'
    
    in_hr = selected_char in hr
    in_cc = selected_char in cc
    
    if in_hr and in_cc:
        print('Thanks both')
    elif in_hr:
        print('Thanks head rush')
    elif in_cc:
        print('Thanks cubing club')
    else:
        print('none')

main()
```

### Explanation
1. **Reading Input**: The input string is read and stripped of any leading or trailing whitespace.
2. **Counting Frequencies**: Using `Counter` from the `collections` module, we efficiently count the occurrences of each character.
3. **Finding Maximum Frequency**: The maximum frequency is determined using the `max` function on the values of the frequency dictionary.
4. **Selecting Character**: Characters with the maximum frequency are collected, and the lexicographically smallest is selected using `min`.
5. **Presence Check**: The selected character is checked against the strings 'head rush' and 'cubing club' to determine the appropriate output message.

This approach ensures that we efficiently and correctly determine the required character and generate the correct output message based on the problem constraints.
