To solve this problem, we need to determine the minimum time required for all students to reach the top of the mountain using cable cars of their preferred colors. The cable cars operate in a cyclic order (red, green, blue) and each car can carry up to two students. The goal is to find the latest arrival time among all groups of students, which will be the total time required for everyone to reach the top.

### Approach
1. **Understand the Cable Car Schedule**: The cable cars arrive every minute in the order red, green, blue, repeating every 3 minutes. Each car takes exactly 30 minutes to reach the top.
2. **Calculate Cars Needed**: For each group (red, green, blue), determine the number of cars required using the formula `(students + 1) // 2` to account for up to two students per car.
3. **Determine Departure Times**: For each group, compute the last departure time based on the number of cars needed and their respective color's offset (red: 0, green: 1, blue: 2).
4. **Compute Arrival Times**: The arrival time for each group is the last departure time plus 30 minutes. If a group has no students, their arrival time is considered 0.
5. **Find Maximum Arrival Time**: The answer is the maximum arrival time across all groups, as this represents the time when the last student reaches the top.

### Solution Code
```python
r, g, b = map(int, input().split())

def compute_arrival(count, offset):
    cars = (count + 1) // 2
    if cars == 0:
        return 0
    last_departure = (cars - 1) * 3 + offset
    return last_departure + 30

red_time = compute_arrival(r, 0)
green_time = compute_arrival(g, 1)
blue_time = compute_arrival(b, 2)

print(max(red_time, green_time, blue_time))
```

### Explanation
1. **Reading Input**: The input consists of three integers representing the number of students in each group (red, green, blue).
2. **Function to Compute Arrival Time**: The `compute_arrival` function calculates the arrival time for a given group of students based on their count and the offset time for their preferred cable car color.
3. **Cars Calculation**: For each group, the number of cars needed is determined by `(count + 1) // 2`, ensuring we round up when there's an odd number of students.
4. **Departure and Arrival Times**: The last departure time for each group is computed using the number of cars and their color's offset. The arrival time is this departure time plus 30 minutes.
5. **Result Calculation**: The maximum arrival time across all groups is printed as the result, ensuring we account for the latest time any student reaches the top.

This approach efficiently calculates the required times using simple arithmetic and ensures we consider all groups to find the optimal solution.
