To solve this problem, we need to determine the number of candies that, when removed, result in the sum of weights of candies eaten on even days being equal to the sum of weights of candies eaten on odd days. Tanya eats the remaining candies in their original order, excluding the removed candy, which affects the parity (even/odd) of the days for subsequent candies.

### Approach
1. **Prefix Sums Calculation**: Compute prefix sums for even and odd indexed positions in the array. This helps in efficiently calculating sums for subarrays.
2. **Difference Calculation**: For each candy, compute the difference between the sum of even-indexed and odd-indexed candies for the left part (before the removed candy) and the right part (after the removed candy, with parity flipped).
3. **Comparison**: Check if the difference between the even and odd sums of the left part matches the flipped difference of the right part. If they match, the removed candy is counted as "good".

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
a = [0] + a  # 1-based indexing

prefix_even = [0] * (n + 1)
prefix_odd = [0] * (n + 1)

for j in range(1, n + 1):
    if j % 2 == 0:
        prefix_even[j] = prefix_even[j-1] + a[j]
        prefix_odd[j] = prefix_odd[j-1]
    else:
        prefix_odd[j] = prefix_odd[j-1] + a[j]
        prefix_even[j] = prefix_even[j-1]

total_even = prefix_even[n]
total_odd = prefix_odd[n]

count = 0

for i in range(1, n + 1):
    sum_even_left = prefix_even[i-1]
    sum_odd_left = prefix_odd[i-1]
    sum_even_right = total_even - prefix_even[i]
    sum_odd_right = total_odd - prefix_odd[i]
    left_diff = sum_even_left - sum_odd_left
    right_diff = sum_even_right - sum_odd_right
    if left_diff == right_diff:
        count += 1

print(count)
```

### Explanation
1. **Prefix Sums**: We maintain two arrays, `prefix_even` and `prefix_odd`, to store cumulative sums of even and odd indexed positions respectively. This allows us to quickly compute sums for any subarray.
2. **Left and Right Parts**: For each candy `i`, the left part consists of candies before `i`, and the right part consists of candies after `i`. The sums of these parts are computed using the prefix arrays.
3. **Parity Flip**: The right part's sums are adjusted by swapping even and odd contributions due to the shift in indices when a candy is removed.
4. **Comparison**: The difference between even and odd sums for the left part is compared with the adjusted difference for the right part. If they match, the removed candy is counted.

This approach efficiently computes the required sums in linear time, ensuring the solution is optimal even for large input sizes.
