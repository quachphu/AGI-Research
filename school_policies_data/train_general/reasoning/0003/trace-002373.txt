To solve this problem, we need to determine if a given positive integer is a perfect number. If it is, we generate and print a specific triangular array (Pascal's Triangle) up to the number of rows equal to the input integer. If the number is not perfect, we print an error message.

### Approach
1. **Check for Perfect Number**: A perfect number is a positive integer that is equal to the sum of its proper divisors (excluding itself). We need to verify this by iterating through potential divisors up to the square root of the number for efficiency.
2. **Generate Pascal's Triangle**: If the number is perfect, generate Pascal's Triangle up to the number of rows specified by the input. Each row in Pascal's Triangle is constructed such that each element is the sum of the two elements directly above it from the previous row.

### Solution Code
```python
import math

def main():
    n = int(input().strip())
    if not is_perfect(n):
        print("error")
        return

    triangle = []
    prev_row = []
    for i in range(n):
        current_row = []
        if i == 0:
            current_row = [1]
        else:
            current_row.append(1)
            for j in range(1, i):
                current_row.append(prev_row[j-1] + prev_row[j])
            current_row.append(1)
        triangle.append(current_row)
        prev_row = current_row

    for row in triangle:
        print(''.join(map(str, row)))

def is_perfect(num):
    if num <= 1:
        return False
    sum_div = 1
    sqrt_num = int(math.sqrt(num))
    for i in range(2, sqrt_num + 1):
        if num % i == 0:
            pair = num // i
            if i != pair:
                sum_div += i + pair
            else:
                sum_div += i
    return sum_div == num

if __name__ == "__main__":
    main()
```

### Explanation
1. **Perfect Number Check**:
   - The function `is_perfect` checks if a number is perfect by summing its proper divisors. Proper divisors are calculated efficiently by iterating up to the square root of the number and adding both the divisor and its complement when applicable.
   
2. **Generating Pascal's Triangle**:
   - The triangle is generated iteratively. Each row starts and ends with 1. The elements in between are calculated as the sum of the two elements from the previous row. This method ensures that each row is built based on the previous row, maintaining the structure of Pascal's Triangle.

This approach ensures correctness and efficiency, both in checking for perfect numbers and constructing the required triangular array.
