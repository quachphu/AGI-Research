To solve this problem, we need to determine the number of laps each student completes before they all meet again at the elementary school after starting at the same time. Each student runs their own course at their own pace, and we need to find the earliest time when all students return to the school simultaneously.

### Approach
1. **Understanding the Problem**: Each student's time per lap is determined by their course distance and running speed. The goal is to find the earliest time when all students complete an integer number of laps simultaneously.
2. **Key Insight**: The earliest meeting time is the least common multiple (LCM) of the time each student takes to complete one lap. This time can be represented as a fraction, and the LCM of these fractions can be computed using their numerators and denominators.
3. **Fraction Handling**: Convert each student's lap time into a reduced fraction (numerator and denominator). The LCM of the times is calculated using the LCM of the numerators divided by the greatest common divisor (GCD) of the denominators.
4. **Computation Steps**:
   - For each student, compute the reduced fraction of their lap time.
   - Calculate the LCM of all numerators and the GCD of all denominators.
   - Determine the number of laps each student completes by dividing the LCM of the times by each student's lap time.

### Solution Code
```python
import math
import sys

def compute_lcm(numbers):
    lcm = 1
    for num in numbers:
        lcm = lcm * num // math.gcd(lcm, num)
    return lcm

def compute_gcd(numbers):
    current_gcd = numbers[0]
    for num in numbers[1:]:
        current_gcd = math.gcd(current_gcd, num)
        if current_gcd == 1:
            break
    return current_gcd

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        if n == 0:
            break
        students = []
        for _ in range(n):
            d, v = map(int, sys.stdin.readline().split())
            g = math.gcd(d, v)
            ni = d // g
            di = v // g
            students.append((ni, di))
        # Compute LCM of all ni
        lcm_ni = compute_lcm([ni for ni, di in students])
        # Compute GCD of all di
        gcd_di = compute_gcd([di for ni, di in students])
        # Calculate each student's laps
        results = []
        for ni, di in students:
            numerator = lcm_ni * di
            denominator = gcd_di * ni
            laps = numerator // denominator
            results.append(laps)
        # Output each result on a separate line
        for res in results:
            print(res)

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The code reads multiple datasets until encountering a line with `0`. Each dataset starts with the number of students followed by their respective course distances and speeds.
2. **Reducing Fractions**: For each student, the lap time is converted into a reduced fraction by dividing both distance and speed by their GCD.
3. **LCM and GCD Calculations**: The LCM of the numerators and the GCD of the denominators of the reduced fractions are computed to determine the earliest meeting time.
4. **Laps Calculation**: For each student, the number of laps is calculated by dividing the meeting time by their individual lap time, ensuring the result is an integer.

This approach efficiently computes the required values using mathematical operations on fractions and ensures correctness even with large numbers due to Python's handling of big integers.
