To solve this problem, we need to form a delegation of students such that each chosen subject has the same number of participants, maximizing the total sum of their skill levels. If all possible valid delegations have a negative sum, we should output 0.

### Approach
1. **Group Students by Subject**: First, we group all students by their subject of specialization.
2. **Sort and Compute Prefix Sums**: For each subject, sort the students in descending order of their skill levels and compute prefix sums for the sorted list. The prefix sum up to `k` students gives the maximum possible sum for selecting `k` students from that subject.
3. **Accumulate Valid Sums**: For each possible number of students `k` (from 1 to the maximum number of students in any subject), check if the prefix sum for `k` students in a subject is positive. If it is, add this sum to a global accumulator for that `k`.
4. **Determine Maximum Sum**: The maximum value in the global accumulator across all valid `k` values is the result. If no valid `k` exists, output 0.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n, m = map(int, sys.stdin.readline().split())
    subjects = defaultdict(list)
    for _ in range(n):
        s_i, r_i = map(int, sys.stdin.readline().split())
        subjects[s_i].append(r_i)
    
    sums = defaultdict(int)
    
    for s in subjects.values():
        s.sort(reverse=True)
        current_sum = 0
        for k in range(len(s)):
            current_sum += s[k]
            if current_sum > 0:
                sums[k + 1] += current_sum
            else:
                break
    
    print(max(sums.values(), default=0))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Grouping by Subject**: We use a dictionary to group students by their subject, which allows efficient access to each subject's list of students.
2. **Sorting and Prefix Sums**: Sorting each subject's students in descending order of skill levels ensures that the prefix sums represent the maximum possible sum for selecting the top `k` students. This sorting is crucial as it allows us to efficiently compute the maximum possible sum for any number of students selected from that subject.
3. **Accumulating Valid Sums**: For each subject and each possible number of students `k`, we compute the prefix sum. If this sum is positive, it contributes to the total sum for that `k` across all subjects. We break early if the sum becomes non-positive to avoid unnecessary computations.
4. **Finding the Maximum Sum**: By iterating through all valid `k` values and their accumulated sums, we determine the maximum possible sum for a valid delegation. If no valid sums exist, the default value of 0 is returned.

This approach efficiently handles the constraints and ensures that we maximize the total skill sum while adhering to the competition rules.
