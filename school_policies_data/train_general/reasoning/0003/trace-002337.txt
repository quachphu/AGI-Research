To solve this problem, we need to determine the equivalent resistance of a circuit composed of N blocks, each containing two resistors. The result should be presented as a fraction in its simplest form modulo M. 

### Approach
1. **Problem Analysis**: The problem can be approached by recognizing a pattern in the equivalent resistance values as blocks are added. The resistance values follow a recurrence relation similar to the Fibonacci sequence but with different coefficients.
2. **Recurrence Relation**: The resistance values for N blocks can be derived using the recurrence relations:
   - Numerator: \( a(n) = 3 \times a(n-1) - a(n-2) \) with initial values \( a(1) = 1 \) and \( a(2) = 2 \)
   - Denominator: \( b(n) = 3 \times b(n-1) - b(n-2) \) with initial values \( b(1) = 1 \) and \( b(2) = 3 \)
3. **Modulo Operations**: Since the values can be very large, we compute each value modulo M to keep the numbers manageable and avoid overflow.
4. **Efficiency**: The solution uses dynamic programming to compute the values iteratively, ensuring that each value is computed in linear time relative to N.

### Solution Code
```python
import sys

def compute_resistance():
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N = int(input[idx])
        M = int(input[idx + 1])
        idx += 2
        
        if N == 1:
            a, b = 1, 1
        else:
            # Compute a(n)
            a_prev_prev, a_prev = 1, 2
            for i in range(3, N + 1):
                a_curr = (3 * a_prev - a_prev_prev) % M
                a_prev_prev, a_prev = a_prev, a_curr
            a = a_prev
            
            # Compute b(n)
            b_prev_prev, b_prev = 1, 3
            for i in range(3, N + 1):
                b_curr = (3 * b_prev - b_prev_prev) % M
                b_prev_prev, b_prev = b_prev, b_curr
            b = b_prev
        
        print(f"{a % M}/{b % M}")

compute_resistance()
```

3. **Dynamic Programming**: The values for the numerator and denominator are computed iteratively using their recurrence relations, taking modulo M at each step to ensure values remain within bounds.
4. **Output**: The results for each test case are printed in the required format, ensuring the values are reduced modulo M.
