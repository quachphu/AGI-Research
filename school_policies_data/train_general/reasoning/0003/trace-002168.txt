To solve this problem, we need to efficiently process a permutation of integers through a series of queries. Each query involves rearranging the permutation by moving a specific element to a new position, followed by its subsequent elements and preceded by its preceding elements. The challenge is to handle up to 100,000 elements and queries efficiently.

### Approach
1. **Linked List Structure**: Use a doubly linked list to represent the permutation. Each node in the list contains a value, a reference to the previous node, and a reference to the next node.
2. **Hash Map for Node Lookup**: Maintain a hash map (dictionary) to quickly find the node corresponding to any value in O(1) time.
3. **Efficient Re-linking**: For each query, split the list into two parts (elements before and after the queried element) and re-link these parts around the queried element to form the new permutation. This ensures each query is processed in O(1) time.
4. **Head and Tail Tracking**: Keep track of the head and tail of the linked list to quickly access the start and end of the list during each re-linking operation.

### Solution Code
```python
class Node:
    def __init__(self, val):
        self.val = val
        self.prev = None
        self.next = None

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    Q = int(input[ptr])
    ptr += 1
    perm = list(map(int, input[ptr:ptr+N]))
    ptr += N
    queries = list(map(int, input[ptr:ptr+Q]))
    
    # Build the linked list
    value_to_node = {}
    head = None
    tail = None
    prev_node = None
    for val in perm:
        node = Node(val)
        value_to_node[val] = node
        if prev_node is not None:
            prev_node.next = node
            node.prev = prev_node
        else:
            head = node
        prev_node = node
    tail = prev_node
    
    for q in queries:
        current = value_to_node[q]
        # Split into L and R parts
        R_head = current.next
        R_tail = tail if R_head is not None else None
        L_tail = current.prev
        L_head = head if L_tail is not None else None
        
        # Relink R to current
        if R_head is not None:
            R_tail.next = current
            current.prev = R_tail
        else:
            current.prev = None
        
        # Relink current to L
        current.next = L_head
        if L_head is not None:
            L_head.prev = current
        else:
            current.next = None
        
        # Update head and tail
        new_head = R_head if R_head is not None else current
        new_tail = L_tail if L_tail is not None else current
        head = new_head
        tail = new_tail
    
    # Collect the result
    result = []
    current_node = head
    while current_node is not None:
        result.append(str(current_node.val))
        current_node = current_node.next
    print(' '.join(result))

if __name__ == "__main__":
    main()
```

3. **Efficiency**: Each query is processed in O(1) time due to the use of the hash map for node lookup and efficient pointer manipulations in the linked list. This ensures the solution handles the upper constraint limits efficiently.
