To solve this problem, we need to determine which of the three given integers is different from the other two, where exactly two integers are the same and one is different. 

### Approach
The approach involves comparing the three integers in pairs to identify the different one. Since the input is guaranteed to have exactly two integers that are the same and one that is different, we can use the following logic:
1. Compare the first and second integers. If they are the same, the third integer is the different one.
2. If the first and second integers are not the same, compare the first and third integers. If they are the same, the second integer is the different one.
3. If neither of the above conditions is met, the second and third integers must be the same, making the first integer the different one.

This approach efficiently checks all possible pairs in constant time, ensuring an optimal solution.

### Solution Code
```python
a, b, c = map(int, input().split())
if a == b:
    print(c)
elif a == c:
    print(b)
else:
    print(a)
```

### Explanation
1. **Reading Input:** The input is read as three integers separated by spaces.
2. **First Comparison:** Check if the first and second integers are the same. If true, the third integer is the different one.
3. **Second Comparison:** If the first comparison fails, check if the first and third integers are the same. If true, the second integer is the different one.
4. **Default Case:** If both comparisons fail, the second and third integers must be the same, so the first integer is the different one.

This method ensures that we correctly identify the different integer with minimal comparisons, providing an efficient and straightforward solution.
