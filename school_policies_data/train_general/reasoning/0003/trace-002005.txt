To solve this problem, we need to determine the output based on a given integer input, which can only be 0 or 1. The output should be 1 if the input is 0, and 0 if the input is 1.

### Approach
The problem can be efficiently solved by leveraging a simple mathematical operation. Since the input is guaranteed to be either 0 or 1, we can directly compute the result by subtracting the input value from 1. This approach is both time-efficient and straightforward, ensuring that we handle all valid inputs correctly without any additional checks.

### Solution Code
```python
def main():
    x = int(input().strip())
    print(1 - x)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input using `input().strip()`, which removes any leading or trailing whitespace. This ensures that the input is clean and correctly converted to an integer.
2. **Computing the Result**: By subtracting the input value `x` from 1, we directly get the required output. If `x` is 0, the result is `1 - 0 = 1`, and if `x` is 1, the result is `1 - 1 = 0`.
3. **Output the Result**: The computed result is printed, which meets the problem's requirements precisely.

This approach is optimal with a time complexity of O(1) and constant space complexity, making it highly efficient for the given constraints.
