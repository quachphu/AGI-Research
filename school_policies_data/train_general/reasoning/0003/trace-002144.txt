To solve this problem, we need to determine the final state of a row of slimes after adding each slime one by one and merging consecutive slimes with the same value. The merging process continues until no more consecutive slimes have the same value. The key insight is that the final state of the slimes can be derived from the binary representation of the number of slimes, `n`.

### Approach
1. **Binary Representation Insight**: The final state of the slimes corresponds to the binary representation of `n`. Each bit in the binary representation of `n` that is set (i.e., 1) corresponds to a slime value. The position of each bit in the binary representation determines the value of the slime.
2. **Exponent Calculation**: For each bit set in the binary representation of `n`, the value of the slime is determined by the position of the bit (starting from 0 for the least significant bit). The value of the slime is `2^(position)`, but we need to output these values as `position + 1` in descending order of their positions.

### Solution Code
```python
n = int(input())
if n == 0:
    print(0)
else:
    exponents = []
    current = n
    i = 0
    while current > 0:
        if current & 1:
            exponents.append(i)
        current >>= 1
        i += 1
    exponents.reverse()
    result = [e + 1 for e in exponents]
    print(' '.join(map(str, result)))
```

### Explanation
1. **Reading Input**: The input is read as an integer `n`, which represents the number of slimes.
2. **Binary Decomposition**: We decompose `n` into its binary form by repeatedly checking each bit. For each bit that is set (i.e., 1), we record its position (exponent) in a list.
3. **Reversing Exponents**: The positions (exponents) of the set bits are collected in ascending order (from least significant to most significant bit). We reverse this list to process the most significant bits first.
4. **Generating Result**: Each exponent is converted to a slime value by adding 1 to it. These values are then printed in the order from the highest exponent to the lowest.

This approach efficiently computes the final state of the slimes using bit manipulation, ensuring an optimal solution with a time complexity of O(log n), which is suitable for large values of `n` up to 100,000.
