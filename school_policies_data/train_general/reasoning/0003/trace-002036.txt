To solve this problem, we need to determine the winner of a second-price auction and the price they will pay. The winner is the bidder with the highest bid, but they pay the second-highest bid amount. 

### Approach
1. **Read Input**: The first line of input gives the number of bidders, and the second line lists the bids.
2. **Track Original Indices**: Since the indices are 1-based, we use the `enumerate` function to pair each bid with its original index.
3. **Sort Bids**: Sort the list of bids in descending order of bid value. This allows us to easily identify the highest and second-highest bids.
4. **Determine Winner and Price**: The first element in the sorted list gives the highest bid and the winner's index. The second element gives the second-highest bid, which is the price the winner pays.

### Solution Code
```python
def main():
    n = int(input())
    prices = list(map(int, input().split()))
    sorted_bidders = sorted(enumerate(prices, 1), key=lambda x: (-x[1], x[0]))
    print(sorted_bidders[0][0], sorted_bidders[1][1])

main()
```

### Explanation
1. **Reading Input**: The input is read using standard input functions. The number of bidders `n` and their respective bids are parsed.
2. **Enumerating Bids**: Each bid is paired with its 1-based index using `enumerate(prices, 1)`, creating tuples of the form (index, bid).
3. **Sorting**: The list of tuples is sorted in descending order of bid value. If two bids were equal (though they are guaranteed to be unique here), the tiebreaker is the original index, sorted in ascending order.
4. **Output**: The winner is the first element's index in the sorted list, and the price they pay is the second element's bid value. These values are printed as the result.

This approach efficiently finds the required values using sorting, which ensures clarity and correctness given the problem constraints.
