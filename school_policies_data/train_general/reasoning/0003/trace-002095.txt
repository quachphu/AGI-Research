To solve this problem, we need to determine how many line segments intersect with each query line, where each query line is either horizontal (y=k) or vertical (x=k). The solution involves preprocessing the line segments to efficiently answer each query in constant time.

### Approach
1. **Classify Line Segments**:
   - **Vertical Segments**: Segments where the x-coordinates of both endpoints are the same.
   - **Horizontal Segments**: Segments where the y-coordinates of both endpoints are the same.
   - **Other Segments**: Segments that are neither vertical nor horizontal.

2. **Preprocessing**:
   - **Vertical and Horizontal Counts**: Use arrays to count the number of vertical segments at each x-coordinate and horizontal segments at each y-coordinate.
   - **Interval Coverage**: For non-vertical segments, compute the x-interval they span. For non-horizontal segments, compute the y-interval they span.

3. **Efficient Range Queries**:
   - Use prefix sum arrays to efficiently count how many intervals cover a specific point. This allows us to quickly determine how many non-vertical segments cover a given x-coordinate and how many non-horizontal segments cover a given y-coordinate.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    max_coord = 10**5  # As per constraints, coordinates and k are up to 1e5
    for _ in range(t):
        n, q = map(int, input[ptr:ptr+2])
        ptr += 2
        
        # Initialize counts for vertical and horizontal segments
        vertical_counts = [0] * (max_coord + 2)  # x can be 0 to 1e5
        horizontal_counts = [0] * (max_coord + 2)  # y can be 0 to 1e5
        
        # Collect intervals for non-vertical and non-horizontal segments
        x_intervals = []
        y_intervals = []
        
        for __ in range(n):
            x1, y1, x2, y2 = map(int, input[ptr:ptr+4])
            ptr += 4
            
            # Check if vertical (x1 == x2)
            if x1 == x2:
                vertical_counts[x1] += 1
            else:
                x_min = min(x1, x2)
                x_max = max(x1, x2)
                x_intervals.append((x_min, x_max))
            
            # Check if horizontal (y1 == y2)
            if y1 == y2:
                horizontal_counts[y1] += 1
            else:
                y_min = min(y1, y2)
                y_max = max(y1, y2)
                y_intervals.append((y_min, y_max))
        
        # Build x_cover array for non-vertical segments
        x_events = [0] * (max_coord + 2)  # 0 to 1e5+1
        for x_min, x_max in x_intervals:
            x_events[x_min] += 1
            if x_max + 1 <= max_coord + 1:
                x_events[x_max + 1] -= 1
        
        current = 0
        x_cover = [0] * (max_coord + 1)  # x ranges from 0 to 1e5
        for x in range(max_coord + 1):
            current += x_events[x]
            x_cover[x] = current
        
        # Build y_cover array for non-horizontal segments
        y_events = [0] * (max_coord + 2)
        for y_min, y_max in y_intervals:
            y_events[y_min] += 1
            if y_max + 1 <= max_coord + 1:
                y_events[y_max + 1] -= 1
        
        current = 0
        y_cover = [0] * (max_coord + 1)
        for y in range(max_coord + 1):
            current += y_events[y]
            y_cover[y] = current
        
        # Process each query
        for __ in range(q):
            a, b = map(int, input[ptr:ptr+2])
            ptr += 2
            if a == 0:
                # Query is y = b
                k = b
                res = horizontal_counts[k] + y_cover[k]
            else:
                # Query is x = a
                k = a
                res = vertical_counts[k] + x_cover[k]
            print(res)

if __name__ == "__main__":
    main()
```

3. **Interval Processing**: For non-vertical and non-horizontal segments, intervals are collected and processed to build prefix sum arrays (`x_cover` and `y_cover`). These arrays allow quick lookup of how many intervals cover a specific point.
4. **Query Processing**: Each query is resolved in constant time using the precomputed counts and prefix sum arrays, ensuring efficient performance even for large input sizes.
