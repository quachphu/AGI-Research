To solve this problem, we need to remove duplicate elements from an array such that only the rightmost occurrence of each element remains. The relative order of the remaining elements should be preserved as per their last occurrence in the original array.

### Approach
1. **Reverse Iteration**: Iterate through the array from the end to the beginning. This allows us to capture the rightmost occurrences first.
2. **Tracking Seen Elements**: Use a set to keep track of elements we have already encountered. This helps in identifying duplicates efficiently.
3. **Collecting Results**: As we iterate from the end, we collect elements that have not been seen before into a temporary list.
4. **Reversing the Result**: Since we collected elements in reverse order (from last to first), we reverse the collected list to restore the original order of the rightmost occurrences.

### Solution Code
```python
def process_array():
    n = int(input())
    arr = list(map(int, input().split()))
    seen = set()
    res = []
    for num in reversed(arr):
        if num not in seen:
            res.append(num)
            seen.add(num)
    res.reverse()
    print(len(res))
    print(' '.join(map(str, res)))

process_array()
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` (number of elements) followed by the array elements.
2. **Reverse Iteration**: By iterating from the end of the array, we ensure that the first occurrence of each element we encounter (in reverse) is the rightmost occurrence in the original array.
3. **Tracking with Set**: A set is used to track elements that have already been added to the result list. This ensures each element is added only once.
4. **Reversing the Result List**: The collected elements are in reverse order of their rightmost occurrences. Reversing this list restores the correct order as per their positions in the original array.

This approach efficiently processes the array in linear time, O(n), where n is the number of elements in the array, making it suitable for the given constraints.
