To solve this problem, we need to find the smallest magical number that is greater than a given input. A magical number is defined as \(30^n\) where \(n\) is a non-negative integer. The approach involves iterating through the powers of 30 until we find the smallest one that exceeds the input value.

### Approach
1. **Understanding the Problem**: The magical number is given by \(30^n\), which simplifies the problem to finding the smallest power of 30 that is greater than the input value.
2. **Iterative Check**: Start with the smallest magical number (1, which is \(30^0\)) and keep multiplying by 30 until the result exceeds the input value. This approach ensures that we find the smallest valid magical number efficiently.
3. **Edge Cases**: Handle cases where the input is 0 or a very small number by starting the iteration from 1 and checking each subsequent power of 30.

### Solution Code
```python
def find_magical_number():
    import sys
    X = int(sys.stdin.readline())
    result = 1
    while result <= X:
        result *= 30
    print(result)

find_magical_number()
```

### Explanation
1. **Reading Input**: The input value is read from standard input.
2. **Initialization**: Start with the smallest magical number, which is 1 (corresponding to \(30^0\)).
3. **Iteration**: Multiply the current result by 30 iteratively until the result exceeds the input value. This loop ensures that we find the smallest power of 30 that is greater than the input.
4. **Output**: Print the result once it exceeds the input value, which is the required magical number.

This approach efficiently computes the desired result with a time complexity of \(O(\log_{30} X)\), which is very efficient even for large values of X due to the exponential growth of 30's powers.
