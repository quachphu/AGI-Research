To solve this problem, we need to sort an array using at most n swaps. The goal is to find any sequence of swaps that results in a sorted array, ensuring the number of swaps does not exceed the array's length. 

### Approach
The approach leverages the selection sort algorithm, which is well-suited for this problem due to its inherent property of making at most n-1 swaps. Here's the detailed approach:

1. **Iterate through each position**: For each position from the start to the second last element, find the minimum element in the remaining unsorted subarray.
2. **Swap elements**: If the minimum element found is not already in its correct position, swap it with the element at the current position. This ensures that each element is placed in its correct position with a single swap.
3. **Record swaps**: Keep track of all swaps made during the sorting process.

This approach guarantees that the array is sorted in at most n-1 swaps, which is within the problem's constraints.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    arr = list(map(int, input[1:n+1]))
    swaps = []
    for i in range(n-1):
        min_idx = i
        for j in range(i+1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        if min_idx != i:
            swaps.append((i, min_idx))
            arr[i], arr[min_idx] = arr[min_idx], arr[i]
    print(len(swaps))
    for pair in swaps:
        print(pair[0], pair[1])

solve()
```

### Explanation
1. **Reading Input**: The input is read in one go and split into a list of integers. The first element is the size of the array, followed by the array elements.
2. **Selection Sort Logic**: For each position `i` from 0 to n-2, the algorithm finds the index of the minimum element in the subarray starting from `i` to the end. If this minimum element is not already at position `i`, it swaps the elements at positions `i` and the found minimum index.
3. **Tracking Swaps**: Each swap is recorded in a list, which is printed at the end along with the count of swaps.

This method ensures that each element is placed in its correct position with minimal swaps, adhering to the problem constraints efficiently.
