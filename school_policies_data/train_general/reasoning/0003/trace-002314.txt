To solve this problem, we need to determine the position of the last surviving White Walker in a circle where every alternate White Walker is killed. This problem is a variation of the classic Josephus problem with k=2, where every second person is eliminated in a circle until only one remains.

### Approach
The solution leverages a mathematical formula derived from the Josephus problem for k=2. The key steps are as follows:
1. **Identify the Largest Power of 2**: For a given number of White Walkers (N), find the largest power of 2 (denoted as L) that is less than or equal to N.
2. **Compute the Survivor's Position**: Using the formula derived from the Josephus problem, the position of the survivor can be determined based on the difference between N and the largest power of 2 (L). The formula is:
   - If N is exactly a power of 2, the survivor is at position 1.
   - Otherwise, the survivor is at position `2 * (N - L) + 1`.

### Solution Code
```python
def find_survivor():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        N = int(input[i])
        L = 1
        while L * 2 <= N:
            L *= 2
        l = N - L
        print(1 if l == 0 else 2 * l + 1)

find_survivor()
```

### Explanation
1. **Reading Input**: The input consists of multiple test cases. We first read the number of test cases (T) followed by each test case value (N).
2. **Finding Largest Power of 2**: For each N, we determine the largest power of 2 (L) by repeatedly doubling L until it exceeds N.
3. **Calculating Survivor's Position**: Using the difference between N and L (denoted as l), we apply the formula to compute the survivor's position. If N is a power of 2, l will be 0, and the survivor is at position 1. Otherwise, the position is `2 * l + 1`.

This approach efficiently computes the result in O(log N) time for each test case, ensuring it handles the upper constraint of N up to 100,000 efficiently.
