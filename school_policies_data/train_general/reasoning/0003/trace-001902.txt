To solve this problem, we need to predict tomorrow's weather based on today's weather, given a repeating cycle of Sunny, Cloudy, Rainy. The solution involves determining the next weather state in the cycle using modular arithmetic to handle the cyclic nature of the sequence.

### Approach
1. **Understand the Cycle**: The weather follows a fixed cycle: Sunny → Cloudy → Rainy → Sunny, and so on.
2. **Create a List Representation**: Represent the cycle as a list where each element corresponds to a weather state in the correct order.
3. **Determine the Index**: Find the index of the given weather state (today's weather) in the list.
4. **Compute Next Index**: Use modular arithmetic to compute the next index in the cycle. The modulo operation ensures that after the last element (Rainy), the cycle wraps around to the first element (Sunny).
5. **Output the Result**: Retrieve the weather state at the computed next index and print it.

### Solution Code
```python
def main():
    s = input().strip()
    cycle = ['Sunny', 'Cloudy', 'Rainy']
    current_index = cycle.index(s)
    next_index = (current_index + 1) % 3
    print(cycle[next_index])

main()
```

### Explanation
1. **Input Handling**: The input is read from standard input and stripped of any leading or trailing whitespace.
2. **Cycle List**: A list `cycle` is defined to represent the sequence of weather states.
3. **Index Calculation**: The index of today's weather in the `cycle` list is determined using the `index` method.
4. **Next Index Calculation**: The next index is calculated using `(current_index + 1) % 3`. This ensures that after the last element (index 2), the next index wraps around to 0.
5. **Output**: The weather state corresponding to the next index is printed as the result.

This approach efficiently handles the cyclic nature of the problem with constant time complexity, O(1), making it very efficient for any input size within the problem constraints.
