To solve this problem, we need to determine if there exists a tree structure such that after processing all given queries, each edge in the tree has an even number written on it. The key insight is to check the parity (even or odd) of the number of times each node appears as an endpoint in the queries.

### Approach
1. **Understanding the Queries**: Each query increments the numbers on the edges along the path between two nodes. The parity of the count of each edge after all queries must be even.
2. **Node Parity Check**: For any tree structure, the parity of the count of each edge being even translates to checking if each node appears an even number of times as an endpoint in the queries. This is because each time a node is an endpoint, it affects the parity of the edges adjacent to it.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    M = int(input[idx])
    idx += 1

    count = [0] * (N + 1)  # 1-based indexing

    for _ in range(M):
        a = int(input[idx])
        idx += 1
        b = int(input[idx])
        idx += 1
        count[a] += 1
        count[b] += 1

    for i in range(1, N + 1):
        if count[i] % 2 != 0:
            print("NO")
            return

    print("YES")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed to extract the number of nodes (N) and queries (M).
2. **Counting Node Appearances**: For each query, we increment the count for both nodes involved in the query.
3. **Checking Parity**: We check if each node's count is even. If any node has an odd count, it is impossible to form a valid tree, so we print "NO". If all nodes have even counts, we print "YES".

This approach efficiently checks the necessary and sufficient condition for the existence of a valid tree structure using a linear scan of the queries, resulting in an O(M) time complexity, which is optimal for the given constraints.
