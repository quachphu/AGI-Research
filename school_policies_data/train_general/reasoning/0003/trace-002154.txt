To solve this problem, we need to determine how many fights each fighter participates in during a tournament where fighters are paired in each round until only one remains. The solution must efficiently handle up to 100,000 fighters and 1,000,000 queries.

### Approach
1. **Simulation of Rounds**: We simulate each round of the tournament where fighters are paired, and the winner moves to the next round. This process continues until only one fighter remains.
2. **Tracking Fight Counts**: For each fighter, we maintain a count of how many fights they participate in. This count is updated every time they are paired with another fighter.
3. **Efficient Processing**: Using a list to represent the current fighters in each round, we process pairs of fighters, determine the winner, and update the fight counts. This approach ensures we handle the input size efficiently within acceptable time limits.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    N, Q = int(input[ptr]), int(input[ptr+1])
    ptr += 2
    strengths = list(map(int, input[ptr:ptr+N]))
    ptr += N
    queries = [int(input[ptr + i]) for i in range(Q)]
    
    current_fighters = list(enumerate(strengths, 1))  # (original index, strength)
    fight_count = [0] * (N + 1)  # 1-based indexing
    
    while len(current_fighters) > 1:
        next_fighters = []
        i = 0
        m = len(current_fighters)
        while i < m:
            if i + 1 < m:
                a_idx, a_str = current_fighters[i]
                b_idx, b_str = current_fighters[i+1]
                fight_count[a_idx] += 1
                fight_count[b_idx] += 1
                if a_str > b_str:
                    next_fighters.append(current_fighters[i])
                else:
                    next_fighters.append(current_fighters[i+1])
                i += 2
            else:
                next_fighters.append(current_fighters[i])
                i += 1
        current_fighters = next_fighters
    
    output = []
    for q in queries:
        output.append(str(fight_count[q]))
    print('\n'.join(output))

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read all at once for efficiency, especially given the large possible input sizes.
2. **Initial Setup**: The initial list of fighters is created with their original indices and strengths.
3. **Simulating Rounds**: For each round, fighters are processed in pairs. The winner of each pair moves to the next round. If there's an odd number of fighters, the last one automatically moves to the next round without fighting.
4. **Updating Fight Counts**: Each time a fighter is part of a pair, their fight count is incremented.
5. **Processing Queries**: After simulating all rounds, the results for each query are output efficiently by converting the results to a list of strings and printing them all at once.

This approach ensures that the solution is both efficient and straightforward, handling the constraints within acceptable time limits.
