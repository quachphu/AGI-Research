To solve this problem, we need to determine which character occurs the maximum number of times in a given string. If multiple characters have the same maximum occurrence, we should select the character with the lower ASCII value.

### Approach
1. **Read Input**: Read the input string from standard input.
2. **Count Character Frequencies**: Use a dictionary to count the occurrences of each character in the string. The `collections.Counter` class is efficient for this purpose.
3. **Determine Maximum Frequency**: Find the highest frequency of any character in the string.
4. **Identify Candidates**: Collect all characters that have this maximum frequency.
5. **Select Character with Lowest ASCII**: Among the candidates, select the character with the lowest ASCII value using the `min` function with a custom key based on the ASCII value.

### Solution Code
```python
import sys
from collections import Counter

def main():
    s = sys.stdin.read().strip()
    counts = Counter(s)
    if not counts:
        print("")
        return
    max_count = max(counts.values())
    candidates = [char for char, cnt in counts.items() if cnt == max_count]
    answer_char = min(candidates, key=lambda c: ord(c))
    print(f"{answer_char} {max_count}")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input string is read using `sys.stdin.read().strip()` to handle any leading or trailing whitespace.
2. **Counting Frequencies**: The `Counter` class from the `collections` module is used to efficiently count the occurrences of each character in the string.
3. **Finding Maximum Frequency**: The maximum value from the frequency counts is determined using `max(counts.values())`.
4. **Identifying Candidates**: A list comprehension is used to gather all characters that have the maximum frequency.
5. **Selecting the Correct Character**: The `min` function with a custom key based on the ASCII value (using `ord(c)`) ensures that the character with the lowest ASCII value is chosen if there are ties in frequency.

This approach ensures that the solution is both efficient and correct, handling all edge cases such as ties in character frequencies by using ASCII values to break them.
