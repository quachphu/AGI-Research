But to optimize, we can sort the a_i in ascending order. Then, for each a_i in the current recursion step, if the product * a_i exceeds n, we can skip this and all remaining a_i's, since they are larger or equal.

Thus, the code can be written using backtracking with pruning.

    from sys import stdin
    n, k = map(int, stdin.readline().split())
    a = list(map(int, stdin.readline().split()))
    a.sort()  # Sort to allow pruning

    # Check if any a_i is 1
    if 1 in a:
        print(0)
        return

    total = 0

    # Backtracking with pruning
    def backtrack(index, current_product, count):
        nonlocal total
        if index == k:
            if count == 0:
                return
            # Compute the contribution
            sign = (-1) ** (count + 1)
            total += sign * (n // current_product)
            return
        # Prune if multiplying by a[index] would exceed n
        if current_product > n:
            return
        # Include a[index]
        new_product = current_product * a[index]
        if new_product <= n:
            backtrack(index + 1, new_product, count + 1)
        # Exclude a[index]
        backtrack(index + 1, current_product, count)

    backtrack(0, 1, 0)
    print(n - total)

2. **Sorting**: Sorting the hit indicators allows us to prune the search space early when the product of the current subset exceeds n.
3. **Backtracking Function**: The function `backtrack` generates all possible non-empty subsets of the hit indicators. For each subset, it calculates the product and checks if it exceeds n. 4. **Inclusion-Exclusion Principle**: The contribution of each subset is determined by the size of the subset. Subsets of odd length add to the count, while subsets of even length subtract from the count. This is managed using the sign determined by `(-1) ** (count + 1)`.
