To solve this problem, we need to compute the sum of the least common multiples (LCM) of all pairs in an array, modulo 998244353. Given the constraints, a direct O(N^2) approach is infeasible, so we use a more efficient method leveraging number theory and inclusion-exclusion principles.

### Approach
1. **Frequency Array**: Count the frequency of each number in the array.
2. **Sum Arrays**: Precompute sum_x and sum_x2 for each possible divisor, where sum_x[d] is the sum of (a_i/d) for all a_i divisible by d, and sum_x2[d] is the sum of (a_i/d)^2 for all a_i divisible by d.
3. **Möbius Function**: Precompute the Möbius function values using a sieve method to handle inclusion-exclusion efficiently.
4. **Main Calculation**: For each divisor d, compute the contribution to the total sum using the precomputed sums and Möbius function values, ensuring to handle large numbers using modular arithmetic.

### Solution Code
```python
import sys

MOD = 998244353

def main():
    input = sys.stdin.read().split()
    N = int(input[0])
    if N == 0:
        print(0)
        return
    A = list(map(int, input[1:N+1]))
    max_a = max(A) if A else 0

    freq = [0] * (10**6 + 2)
    for a in A:
        freq[a] += 1

    # Precompute sum_x and sum_x2
    max_d = 10**6
    sum_x = [0] * (max_d + 2)
    sum_x2 = [0] * (max_d + 2)
    for d in range(1, max_d + 1):
        m = 1
        while True:
            k = d * m
            if k > max_d:
                break
            sum_x[d] += m * freq[k]
            sum_x2[d] += m * m * freq[k]
            m += 1

    # Compute Möbius function
    max_mu = max_d
    is_prime = [True] * (max_mu + 2)
    is_prime[0] = is_prime[1] = False
    for p in range(2, max_mu + 1):
        if is_prime[p]:
            for multiple in range(p * p, max_mu + 1, p):
                is_prime[multiple] = False

    mu = [1] * (max_mu + 2)
    for p in range(2, max_mu + 1):
        if is_prime[p]:
            for multiple in range(p, max_mu + 1, p):
                mu[multiple] *= -1
            p_square = p * p
            for multiple in range(p_square, max_mu + 1, p_square):
                mu[multiple] = 0

    inv_2 = (MOD + 1) // 2  # Modular inverse of 2

    total = 0
    for d in range(1, max_d + 1):
        res = 0
        max_g = max_d // d
        for g in range(1, max_g + 1):
            if mu[g] == 0:
                continue
            current_dg = d * g
            if current_dg > max_d:
                break
            sx = sum_x[current_dg]
            sx2 = sum_x2[current_dg]
            temp = sx * sx - sx2
            term = mu[g] * g * g * temp
            res += term
        res %= MOD
        contribution = (res * d) % MOD
        contribution = (contribution * inv_2) % MOD
        total = (total + contribution) % MOD

    print(total % MOD)

if __name__ == "__main__":
    main()
```

3. **Möbius Function**: This function helps in applying the inclusion-exclusion principle to handle pairs with specific GCDs efficiently.
4. **Main Loop**: For each divisor d, we compute contributions from pairs with GCD exactly d using precomputed sums and the Möbius function, ensuring modular arithmetic to handle large numbers.
