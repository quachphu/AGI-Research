To solve this problem, we need to ensure that each soldier receives a badge with a unique coolness factor, and we aim to achieve this with the minimum number of coins spent. Each coin increases the coolness factor of a badge by 1.

### Approach
1. **Sort the Array**: First, we sort the array of coolness factors in non-decreasing order. This allows us to process each badge in sequence and ensure that each subsequent badge has a higher coolness factor than the previous one.
2. **Iterate and Adjust**: Starting from the second element, we check each badge. If the current badge's coolness factor is less than or equal to the previous badge's factor, we adjust it to be exactly one more than the previous badge. We keep track of the total cost incurred during these adjustments.

### Solution Code
```python
n = int(input())
arr = list(map(int, input().split()))
arr.sort()
cost = 0
prev = arr[0]
for i in range(1, n):
    current = arr[i]
    if current <= prev:
        required = prev + 1
        cost += required - current
        prev = required
    else:
        prev = current
print(cost)
```

### Explanation
1. **Sorting**: By sorting the array, we can systematically ensure each badge is adjusted to be at least one more than the previous badge, which guarantees uniqueness.
2. **Adjustment Loop**: We iterate through the sorted array starting from the second element. For each element, if it is not greater than the previous element, we calculate the required value to make it unique and update the total cost. This ensures that each subsequent badge is adjusted to the minimum necessary value to maintain uniqueness, thus minimizing the cost.

This approach efficiently ensures all badges have unique coolness factors with the minimum cost, leveraging sorting and a single pass adjustment, resulting in an overall time complexity of O(n log n) due to the sorting step.
