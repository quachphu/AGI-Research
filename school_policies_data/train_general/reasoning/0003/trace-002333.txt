where $p = 2 $.

Also, it can be the Chebyshev distance

\\[ D_{xy} = max_{i=1}^n (|x_i - y_i|) \\]

where $p = \infty$

To solve this problem, we need to calculate the Minkowski distance between two n-dimensional vectors for different values of p (1, 2, 3, and infinity). The Minkowski distance generalizes several other distance metrics, including Manhattan (p=1), Euclidean (p=2), and Chebyshev (p=infinity) distances. 

### Approach
1. **Reading Input**: First, we read the input values which include the dimensionality (n) and the two vectors.
2. **Compute Absolute Differences**: Calculate the absolute differences between corresponding elements of the two vectors.
3. **Calculate Distances**:
   - **Manhattan Distance (p=1)**: Sum the absolute differences.
   - **Euclidean Distance (p=2)**: Take the square root of the sum of squared differences.
   - **Minkowski Distance (p=3)**: Take the cube root of the sum of cubed differences.
   - **Chebyshev Distance (p=infinity)**: Find the maximum of the absolute differences.
4. **Output**: Print each distance formatted to six decimal places.

### Solution Code
```python
def calculate_distances():
    n = int(input())
    x = list(map(int, input().split()))
    y = list(map(int, input().split()))
    diffs = [abs(xi - yi) for xi, yi in zip(x, y)]
    
    d1 = sum(diffs)
    d2 = (sum(d**2 for d in diffs)) ** 0.5
    d3 = (sum(d**3 for d in diffs)) ** (1/3)
    dinf = max(diffs)
    
    print("{0:.6f}".format(d1))
    print("{0:.6f}".format(d2))
    print("{0:.6f}".format(d3))
    print("{0:.6f}".format(dinf))

calculate_distances()
```

### Explanation
1. **Reading Input**: The input is read in three parts. The first line gives the integer n, the next two lines provide the two vectors x and y.
2. **Compute Differences**: Using list comprehension, we compute the absolute differences between corresponding elements of the vectors x and y.
3. **Calculate Distances**:
   - **Manhattan (p=1)**: Simply sum all the absolute differences.
   - **Euclidean (p=2)**: Sum the squares of the differences and take the square root of the sum.
   - **Minkowski (p=3)**: Sum the cubes of the differences and take the cube root of the sum.
   - **Chebyshev (p=infinity)**: Determine the maximum value among the absolute differences.
4. **Output Formatting**: Each distance is printed with exactly six decimal places using Python's string formatting to ensure precision and correct formatting.
