### Approach
The key insight to solve this problem efficiently is recognizing a pattern in the XOR results for different values of \(n\). The XOR of all numbers from 0 to \(2^n - 1\) follows a specific pattern:
- If \(n = 0\), the result is 0 because the only number in the range is 0 itself.
- If \(n = 1\), the result is 1 because the numbers are 0 and 1, and their XOR is 1.
- For \(n \geq 2\), the result is always 0. This is due to the properties of XOR operations over consecutive numbers, where the XOR of all numbers from 0 to \(2^n - 1\) (which is a number of the form \(4k - 1\)) results in 0.

```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    for n_str in input[1:T+1]:
        n = int(n_str)
        print(1 if n == 1 else 0)

if __name__ == "__main__":
    main()
```

### Explanation
The solution reads all input data at once for efficiency, especially given the constraints. The first input value is the number of test cases \(T\). For each subsequent value of \(n\), the code checks if \(n\) is 1 to output 1, otherwise it outputs 0. This approach ensures that each test case is processed in constant time \(O(1)\), making the solution efficient even for the upper limits of the input constraints.
