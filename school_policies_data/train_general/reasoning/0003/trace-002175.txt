To solve this problem, we need to determine the number of cells that will be gilded on a rectangular plate with multiple concentric rings. Each ring is 1 cell wide and forms a border around an inner rectangle. The solution involves calculating the perimeter of each ring and summing these perimeters for the given number of rings.

### Approach
1. **Understanding the Rings**: Each ring is formed by the perimeter of a rectangle. The first ring is the outermost perimeter of the original rectangle. Each subsequent ring is formed 2 cells inward from the previous ring, effectively reducing both the width and height of the rectangle by 4 cells (2 cells from each side).
2. **Perimeter Calculation**: For a rectangle with dimensions `a` (width) and `b` (height), the perimeter in terms of cells is calculated as `2 * (a + b) - 4`. This formula accounts for the four corners being counted twice when summing the sides.
3. **Iterative Summation**: For each ring from 1 to `k`, compute the dimensions of the current inner rectangle, calculate its perimeter, and accumulate the total number of gilded cells.

### Solution Code
```python
w, h, k = map(int, input().split())
total = 0
for i in range(1, k + 1):
    current_w = w - 4 * (i - 1)
    current_h = h - 4 * (i - 1)
    perimeter = 2 * (current_w + current_h) - 4
    total += perimeter
print(total)
```

### Explanation
1. **Reading Input**: The input consists of three integers `w` (width), `h` (height), and `k` (number of rings).
2. **Loop Through Each Ring**: For each ring from 1 to `k`, adjust the dimensions of the rectangle by subtracting `4 * (i - 1)` from both width and height. This adjustment ensures each subsequent ring is 2 cells inward from the previous one.
3. **Perimeter Calculation**: For each adjusted rectangle, compute the perimeter using the formula `2 * (current_w + current_h) - 4` and add this value to the total count of gilded cells.
4. **Output the Result**: After processing all rings, print the total number of gilded cells.

This approach efficiently computes the required number of cells by iterating through each ring and using a straightforward perimeter formula, ensuring accuracy and optimal performance given the problem constraints.
