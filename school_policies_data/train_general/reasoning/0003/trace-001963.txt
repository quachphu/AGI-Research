To solve this problem, we need to simulate the evolution of a one-dimensional cellular automaton over a large number of time steps efficiently. Given the constraints, a direct simulation of each time step is infeasible, so we use matrix exponentiation to compute the state after T steps in logarithmic time complexity.

### Approach
1. **Matrix Representation**: The state transitions of the cellular automaton can be represented as a matrix multiplication problem. Each cell's next state is a linear combination of its current state and its neighbors' states, modulo M.
2. **Matrix Exponentiation**: Using matrix exponentiation, we can compute the state transformation matrix raised to the power T efficiently. This reduces the time complexity from O(T) to O(log T) using binary exponentiation.
3. **Modular Arithmetic**: All matrix operations are performed modulo M to ensure the results stay within the required bounds.

### Solution Code
```python
import sys

def matrix_mult(a, b, mod):
    n = len(a)
    result = [[0]*n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            s = 0
            for k in range(n):
                s += a[i][k] * b[k][j]
                s %= mod  # Keep the sum within mod to prevent overflow
            result[i][j] = s % mod
    return result

def matrix_pow(mat, power, mod):
    n = len(mat)
    # Initialize result as identity matrix
    result = [[0]*n for _ in range(n)]
    for i in range(n):
        result[i][i] = 1
    current = [row[:] for row in mat]
    while power > 0:
        if power % 2 == 1:
            result = matrix_mult(result, current, mod)
        current = matrix_mult(current, current, mod)
        power = power // 2
    return result

def main():
    for line in sys.stdin:
        data = list(map(int, line.strip().split()))
        if len(data) == 0:
            continue
        if data == [0]*6:
            break
        N, M, A, B, C, T = data
        if N == 0:
            break
        initial = list(map(int, sys.stdin.readline().strip().split()))
        if T == 0:
            print(' '.join(map(str, initial)))
            continue
        # Build transition matrix
        mat = [[0]*N for _ in range(N)]
        for i in range(N):
            for j in range(N):
                val = 0
                if j == i - 1:
                    val += A
                if j == i:
                    val += B
                if j == i + 1:
                    val += C
                mat[i][j] = val % M  # Ensure value is within mod M
        # Compute matrix^T
        mat_power = matrix_pow(mat, T, M)
        # Multiply with initial vector
        result = [0]*N
        for i in range(N):
            s = 0
            for j in range(N):
                s += mat_power[i][j] * initial[j]
            result[i] = s % M
        print(' '.join(map(str, result)))

if __name__ == "__main__":
    main()
```

2. **Matrix Exponentiation**: By raising the transition matrix to the power T using binary exponentiation, we efficiently compute the state transformation over T steps. This approach leverages the properties of matrix multiplication to reduce the number of operations from O(T) to O(log T).
3. **Vector Multiplication**: The final state vector is obtained by multiplying the exponentiated matrix with the initial state vector, ensuring all operations are performed modulo M to maintain correctness.

This method efficiently handles the large value of T up to 1e9, ensuring the solution is both optimal and correct.
