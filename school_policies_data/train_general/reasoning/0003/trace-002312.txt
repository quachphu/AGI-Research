To solve this problem, we need to determine the number of gold and silver coins Bronn earns for each of his guesses in a game of mastermind. Gold coins are awarded for each correct color in the correct position, while silver coins are awarded for correct colors in the wrong position, after accounting for gold coins.

### Approach
1. **Reading Input:** Read the secret sequence and the number of test cases.
2. **Gold Coins Calculation:** For each guess, compare each character with the secret sequence to count how many characters are in the correct position (gold coins).
3. **Silver Coins Calculation:** After identifying gold positions, collect the remaining characters from both the secret and the guess. Use frequency counters to determine how many of each color are present in these remaining characters. The silver coins are the sum of the minimum counts for each color present in both remaining lists.

### Solution Code
```python
def main():
    import sys
    from collections import Counter

    secret = sys.stdin.readline().strip()
    t = int(sys.stdin.readline())
    
    for _ in range(t):
        guess = sys.stdin.readline().strip()
        gold = 0
        secret_remaining = []
        guess_remaining = []
        
        for s_char, g_char in zip(secret, guess):
            if s_char == g_char:
                gold += 1
            else:
                secret_remaining.append(s_char)
                guess_remaining.append(g_char)
        
        secret_counts = Counter(secret_remaining)
        guess_counts = Counter(guess_remaining)
        
        silver = 0
        for color in secret_counts:
            silver += min(secret_counts[color], guess_counts.get(color, 0))
        
        print(f"{gold} {silver}")

main()
```

### Explanation
1. **Reading Input:** The secret sequence and the number of test cases are read from standard input.
2. **Gold Calculation:** For each guess, iterate through each character and compare it with the corresponding character in the secret sequence. If they match, increment the gold count.
3. **Remaining Characters:** Collect characters from both the secret and the guess that were not part of the gold matches.
4. **Frequency Counters:** Use `Counter` from the `collections` module to count occurrences of each character in the remaining lists.
5. **Silver Calculation:** For each color present in the remaining characters of the secret, add the minimum count of that color from both the secret and guess remaining lists to the silver count.

This approach ensures that we efficiently compute both gold and silver coins by leveraging frequency counters and set operations, resulting in an optimal solution for the problem constraints.
