Array a is k-period if its length is divisible by k and there is such array b of length k, that a is represented by array b written exactly <image> times consecutively. In other words, array a is k-periodic, if it has period of length k.

Output

Print the minimum number of array elements we need to change to make the array k-periodic. If the array already is k-periodic, then print 0.

Examples

To solve this problem, we need to determine the minimum number of elements to change in an array to make it k-periodic. A k-periodic array is one that can be divided into equal segments of length k, each identical to the first segment. The solution involves analyzing each position within the segments and determining the most frequent element to minimize changes.

### Approach
1. **Input Reading**: Read the array length `n` and the period length `k`, followed by the array elements.
2. **Segment Analysis**: For each position within the first k elements (0 to k-1), collect all elements from subsequent segments that align with this position.
3. **Frequency Counting**: For each collected group of elements, count the occurrences of 1s and 2s.
4. **Calculate Changes**: For each position, determine the minimum number of changes needed by considering the majority element (either 1 or 2) in that position across all segments.
5. **Sum Changes**: Sum the minimum changes required for all positions to get the total number of changes needed to make the array k-periodic.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))
m = n // k
total = 0
for j in range(k):
    elements = [a[j + i * k] for i in range(m)]
    count1 = elements.count(1)
    count2 = m - count1
    total += min(count1, count2)
print(total)
```

### Explanation
- **Input Reading**: The first line reads the values of `n` and `k`, and the second line reads the array elements.
- **Segment Analysis**: For each position `j` from 0 to k-1, we collect elements from the array that are at positions `j, j + k, j + 2k, ...`. This forms a group of elements that must be identical in the k-periodic array.
- **Frequency Counting**: For each group, count how many times 1 appears. The count for 2 is derived by subtracting the count of 1 from the total number of elements in the group (which is `m = n // k`).
- **Calculate Changes**: The minimum number of changes for each position is determined by the smaller count between 1s and 2s, as converting all elements to the majority value minimizes changes.
- **Sum Changes**: The total changes required is the sum of changes needed for each of the k positions.

This approach efficiently computes the minimal changes by leveraging frequency analysis within each segment position, ensuring an optimal solution with a time complexity of O(n), which is efficient given the problem constraints.
