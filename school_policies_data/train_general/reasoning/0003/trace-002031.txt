To solve this problem, we need to find the lexicographically maximum subsequence of a given string. A subsequence is formed by selecting characters from the string in their original order, but not necessarily contiguously. The goal is to determine the largest possible subsequence by lexicographical order.

### Approach
1. **Precompute Maximum Suffix Array**: We first create an array `max_suffix` where each element at index `i` represents the maximum character from the substring starting at index `i` to the end of the string. This helps in quickly determining the maximum character available from any given position onwards.

2. **Character Indices Mapping**: We then build a dictionary where each character maps to a list of indices where it appears in the string. This allows us to efficiently find the first occurrence of the maximum character in any substring using binary search.

3. **Greedy Selection**: Using the precomputed `max_suffix` array and the character indices mapping, we iteratively select the lexicographically largest character available from the current position onwards. For each selected character, we update our current position to just after the selected character's index and repeat the process until we exhaust the string.

### Solution Code
```python
import bisect

def find_max_subsequence():
    s = input().strip()
    n = len(s)
    if n == 0:
        print('')
        return
    
    # Precompute the max_suffix array
    max_suffix = list(s)
    for i in range(n-2, -1, -1):
        if max_suffix[i] < max_suffix[i+1]:
            max_suffix[i] = max_suffix[i+1]
    
    # Build a dictionary mapping each character to its list of indices
    from collections import defaultdict
    char_indices = defaultdict(list)
    for idx, c in enumerate(s):
        char_indices[c].append(idx)
    
    start = 0
    result = []
    while start < n:
        current_max = max_suffix[start]
        indices = char_indices[current_max]
        # Find the first index >= start using bisect
        pos = bisect.bisect_left(indices, start)
        first_occurrence = indices[pos]
        result.append(current_max)
        start = first_occurrence + 1
    
    print(''.join(result))

find_max_subsequence()
```

### Explanation
1. **Precompute Maximum Suffix Array**: This array is constructed by iterating from the end of the string to the beginning. Each position `i` in the array holds the maximum character from the substring starting at `i` to the end of the string. This allows us to determine the maximum character available from any position in constant time.

2. **Character Indices Mapping**: For each character in the string, we maintain a list of indices where the character appears. This list is sorted, enabling efficient binary search to find the first occurrence of the maximum character from any given starting position.

3. **Greedy Selection**: Starting from the beginning of the string, we repeatedly find the maximum character available from the current position using the `max_suffix` array. We then use binary search on the precomputed indices list for this character to find the first occurrence of this character not before the current position. This character is added to the result, and the process continues from the next position until the end of the string is reached.

This approach ensures that we efficiently build the lexicographically largest subsequence by always selecting the highest possible character available at each step, leveraging precomputed data structures to maintain optimal performance.
