The solution involves using dynamic programming with bitmasking to efficiently track the state of the playlist as it is being built.

### Approach
1. **Dynamic Programming (DP) State**: We use a DP array where each state is represented by the current time, the last genre played, and a bitmask indicating which songs have been used. The state is represented as `dp[t][g][mask]`, where `t` is the current time, `g` is the last genre, and `mask` is a bitmask of used songs.
2. **Transitions**: For each state, we consider adding each song that hasn't been used yet and check if it can be added without violating the genre constraint. If valid, we update the DP state for the new time, new genre, and updated bitmask.
3. **Modulo Operation**: Since the result can be very large, we use modulo \(10^9 + 7\) to keep the numbers manageable.

                new_mask = mask | (1 << song_idx)
                # Update the new state in the DP
                dp[new_time][(g, new_mask)] = (dp[new_time].get((g, new_mask), 0) + count) % MOD

# Sum all valid states where the time is exactly T
total = 0
for (g, mask), count in dp[T].items():
    total = (total + count) % MOD
