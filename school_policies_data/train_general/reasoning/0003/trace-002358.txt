To solve this problem, we need to determine the answer to a question based on the last letter of the question. The answer is "YES" if the last letter is a vowel (including 'Y'), and "NO" otherwise. The question is guaranteed to end with a question mark, which we need to ignore, along with any trailing spaces before the question mark.

### Approach
1. **Read Input**: Read the input line which ends with a question mark.
2. **Remove Question Mark**: Strip off the last character (the question mark) from the input line.
3. **Trim Trailing Spaces**: Remove any trailing spaces from the remaining string to focus on the last letter.
4. **Identify Last Letter**: Extract the last character of the trimmed string.
5. **Check Vowel**: Determine if the last character is a vowel (case-insensitive) and print "YES" if it is, otherwise print "NO".

### Solution Code
```python
def main():
    line = input()
    stripped = line[:-1]
    trimmed = stripped.rstrip()
    last_char = trimmed[-1].upper()
    vowels = {'A', 'E', 'I', 'O', 'U', 'Y'}
    print("YES" if last_char in vowels else "NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read as a single string using `input()`.
2. **Stripping the Question Mark**: The last character (which is the question mark) is removed using slicing (`line[:-1]`).
3. **Trimming Trailing Spaces**: Any trailing spaces after the last letter are removed using `rstrip()`.
4. **Extracting Last Character**: The last character of the trimmed string is accessed using `trimmed[-1]` and converted to uppercase to handle case insensitivity.
5. **Vowel Check**: The last character is checked against a set of vowels. If it matches, "YES" is printed; otherwise, "NO" is printed.

This approach efficiently processes the input string to focus on the relevant part (the last letter) and uses a set for quick lookup to determine the answer.
