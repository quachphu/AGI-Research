To solve this problem, we need to minimize the error between two arrays after performing a specified number of operations on each array. The error is defined as the sum of squared differences between corresponding elements of the two arrays. Each operation allows us to increase or decrease an element by 1.

### Approach
1. **Calculate Differences**: Compute the initial differences between corresponding elements of the two arrays.
2. **Absolute Values**: Convert these differences to their absolute values since the goal is to minimize the sum of squares, which depends on the magnitude of the differences.
3. **Total Operations**: Combine the allowed operations on both arrays into a total number of operations (T = k1 + k2).
4. **Greedy Reduction**: Use a max-heap to efficiently reduce the largest absolute differences first. This approach ensures that each operation optimally reduces the error.
5. **Handle Excess Operations**: If the total operations exceed the sum of absolute differences, the remaining operations will alternate between increasing and decreasing the error, leading to a residual error based on the parity of the remaining operations.

### Solution Code
```python
import heapq

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    k1 = int(input[ptr + 1])
    k2 = int(input[ptr + 2])
    ptr += 3
    a = list(map(int, input[ptr:ptr + n]))
    ptr += n
    b = list(map(int, input[ptr:ptr + n]))
    
    diffs = [a[i] - b[i] for i in range(n)]
    abs_diffs = [abs(d) for d in diffs]
    total_ops = k1 + k2
    sum_abs = sum(abs_diffs)
    
    if total_ops >= sum_abs:
        remaining = total_ops - sum_abs
        print(remaining % 2)
    else:
        heap = []
        for num in abs_diffs:
            heapq.heappush(heap, -num)
        
        for _ in range(total_ops):
            current = -heapq.heappop(heap)
            current -= 1
            heapq.heappush(heap, -current)
        
        total = sum((-x) ** 2 for x in heap)
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the arrays and their respective operations.
2. **Difference Calculation**: Compute the element-wise differences between the two arrays and their absolute values.
3. **Max-Heap for Greedy Reduction**: A max-heap (simulated using negative values in a min-heap) is used to always reduce the largest current difference.
4. **Handling Excess Operations**: If the total allowed operations exceed the sum of absolute differences, the residual error is determined by the parity of the remaining operations. If even, the error cancels out; if odd, there's a residual error of 1.

This approach ensures that we minimize the error efficiently using a greedy strategy, leveraging the properties of heaps for optimal element access and modification.
