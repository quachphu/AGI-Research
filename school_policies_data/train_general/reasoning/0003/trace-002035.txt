To solve this problem, we need to determine the maximum number of crucians Valerie can eat without causing any of her teeth's viability to drop below zero. The key insight is that each row of teeth can only be used as many times as the minimum viability of the teeth in that row. 

### Approach
1. **Input Reading**: Read the number of teeth, rows, and crucians available.
2. **Track Minimum Viability**: For each row of teeth, track the minimum viability of the teeth in that row.
3. **Calculate Maximum Usage**: Sum the minimum viabilities across all rows. This sum represents the maximum number of crucians Valerie can eat without any tooth's viability becoming negative.
4. **Determine Result**: The result is the minimum of the sum of minimum viabilities and the number of crucians available, as Valerie cannot eat more crucians than available.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    m = int(input[idx])
    idx += 1
    k = int(input[idx])
    idx += 1
    
    rows = [float('inf')] * (m + 1)
    
    for _ in range(n):
        r = int(input[idx])
        idx += 1
        c = int(input[idx])
        idx += 1
        if c < rows[r]:
            rows[r] = c
    
    total = sum(rows[1:m+1])
    print(min(total, k))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, then parsed. The first three values are the number of teeth, rows, and crucians.
2. **Tracking Minimum Viability**: An array `rows` is initialized to keep track of the minimum viability for each row. As each tooth's data is read, we update the minimum viability for its respective row.
3. **Summing Minimum Viabilities**: The sum of the minimum viabilities across all rows gives the maximum number of crucians Valerie can eat without any tooth's viability turning negative.
4. **Result Calculation**: The result is the minimum of the calculated sum and the available crucians, ensuring Valerie does not exceed either her teeth's limits or the available crucians.

This approach efficiently computes the solution in linear time relative to the number of teeth, making it suitable for the given constraints.
