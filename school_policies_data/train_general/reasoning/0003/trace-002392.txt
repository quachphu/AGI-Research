1. **Understanding the Problem**: The goal is to approximate π using a fraction with the smallest possible denominator such that the approximation error does not exceed the given allowed error R. The fraction must be in its simplest form and provide the best possible approximation for its denominator.

2. **Iterative Search**: Starting from the smallest possible denominator (1), we incrementally check each denominator to find the closest fraction approximation of π. For each denominator `d`, we calculate the closest integer numerator `n` by rounding the product of π and `d`. The approximation error is then computed as the absolute difference between the fraction `n/d` and π.

3. **Precision Handling**: Using Python's `math.pi` for the value of π provides sufficient precision for this problem. The error tolerance is adjusted slightly to account for potential floating-point precision issues.

4. **Termination Condition**: The loop continues until a valid denominator is found that meets the error criteria. The search starts from the smallest denominator and stops at the first valid one to ensure the smallest possible denominator is selected.

### Solution Code
```python
import sys
import math

pi = math.pi

def find_fraction(R):
    R_val = float(R)
    if R_val <= 0.0:
        return None
    d = 1
    while True:
        n = round(pi * d)
        approx = n / d
        diff = abs(approx - pi)
        if diff <= R_val + 1e-12:  # Adding a small epsilon to handle floating point errors
            return f"{n}/{d}"
        d += 1

for line in sys.stdin:
    line = line.strip()
    if not line:
        continue
    if line == '0.0':
        break
    fraction = find_fraction(line)
    print(fraction)
```

### Explanation
- **Reading Input**: The code reads input lines until encountering "0.0", which signals the end of input.
- **Finding the Fraction**: For each allowed error R, the function `find_fraction` iterates over possible denominators starting from 1. For each denominator, it calculates the closest integer numerator and checks if the approximation error is within the allowed range.
- **Output**: The first valid fraction (smallest denominator) that meets the error criteria is printed immediately upon discovery.

This approach ensures that the solution is both efficient and accurate, leveraging Python's floating-point arithmetic and iterative search to find the optimal fraction approximation.
