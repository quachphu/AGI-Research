To solve this problem, we need to simulate the process of adding and removing boxes in a warehouse with shelves and sections. The key challenge is efficiently placing boxes in the correct positions according to the given rules and handling removal queries.

### Approach
1. **Data Structures**: 
   - A 2D list `grid` to represent the shelves and sections, where each cell can either be `None` (empty) or hold the ID of a box.
   - A dictionary `id_to_pos` to map each box ID to its current position (shelf and section).

2. **Adding a Box**:
   - When a box is added, start at the specified shelf and section. If that spot is occupied, check subsequent sections to the right. If the entire shelf is full, move to the next shelf and check from the first section onward.
   - Continue this process until an empty spot is found or all possible shelves and sections have been checked. If no spot is found, the box is discarded.

3. **Removing a Box**:
   - For a removal query, check if the box exists using the dictionary. If it exists, remove it from both the dictionary and the grid, then output its former position. If not found, output `-1 -1`.

### Solution Code
```python
n, m, k = map(int, input().split())

grid = [[None for _ in range(m)] for _ in range(n)]
id_to_pos = {}

for _ in range(k):
    parts = input().split()
    if parts[0] == '+1':
        x = int(parts[1])
        y = int(parts[2])
        idd = parts[3]
        current_shelf = x
        current_sec = y
        found = False
        # Check current shelf from current_sec to m
        for s in range(current_sec, m + 1):
            if grid[current_shelf - 1][s - 1] is None:
                grid[current_shelf - 1][s - 1] = idd
                id_to_pos[idd] = (current_shelf, s)
                found = True
                break
        if not found:
            # Check next shelves
            for sh in range(current_shelf + 1, n + 1):
                for s in range(1, m + 1):
                    if grid[sh - 1][s - 1] is None:
                        grid[sh - 1][s - 1] = idd
                        id_to_pos[idd] = (sh, s)
                        found = True
                        break
                if found:
                    break
    else:
        idd = parts[1]
        if idd in id_to_pos:
            shelf, sec = id_to_pos[idd]
            del id_to_pos[idd]
            grid[shelf - 1][sec - 1] = None
            print(shelf, sec)
        else:
            print(-1, -1)
```

### Explanation
- **Grid Initialization**: The grid is initialized with `None` to represent empty sections.
- **Adding Process**: For each "+1" command, the algorithm checks the specified starting position and subsequent positions as per the problem's rules. If an empty spot is found, the box is placed there and recorded in the dictionary.
- **Removal Process**: For each "-1" command, the dictionary is checked for the box ID. If found, the box is removed from both the grid and the dictionary, and the position is printed. If not found, `-1 -1` is printed.

This approach ensures efficient handling of both addition and removal operations, adhering to the constraints and requirements specified in the problem.
