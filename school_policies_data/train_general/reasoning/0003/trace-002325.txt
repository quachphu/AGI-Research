To solve this problem, we need to determine if a given point \( P \) lies inside a triangle formed by three other points. The solution involves checking the relative position of the point \( P \) with respect to each edge of the triangle using vector cross products.

### Approach
1. **Cross Product Method**: For each edge of the triangle, compute the cross product of the edge's direction vector with the vector from the edge's start to the point \( P \). The sign of this cross product indicates the relative position of \( P \) with respect to the edge.
2. **Check All Edges**: For each edge of the triangle, we check if the point \( P \) lies on the same side as the third vertex of the triangle (the vertex not part of the edge). This is done by comparing the signs of the cross products for the third vertex and the point \( P \).
3. **Determine Inclusion**: If the signs of the cross products for all three edges are consistent (all positive or all negative), the point \( P \) is inside the triangle; otherwise, it is outside.

### Solution Code
```python
import sys

def is_inside_triangle(A, B, C, P):
    def cross(o, a, b):
        return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])
    
    # Check edge AB with third point C
    c1 = cross(A, B, C)
    p1 = cross(A, B, P)
    if c1 * p1 < 0:
        return False
    
    # Check edge BC with third point A
    c2 = cross(B, C, A)
    p2 = cross(B, C, P)
    if c2 * p2 < 0:
        return False
    
    # Check edge CA with third point B
    c3 = cross(C, A, B)
    p3 = cross(C, A, P)
    if c3 * p3 < 0:
        return False
    
    return True

def main():
    for line in sys.stdin:
        data = list(map(float, line.strip().split()))
        if len(data) != 8:
            continue
        x1, y1, x2, y2, x3, y3, xp, yp = data
        A = (x1, y1)
        B = (x2, y2)
        C = (x3, y3)
        P = (xp, yp)
        if is_inside_triangle(A, B, C, P):
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    main()
```

2. **Edge Checks**: For each edge of the triangle, we compute the cross product for the third vertex (to determine the original side) and for the point \( P \). If the signs of these cross products differ, \( P \) is outside the triangle.
3. **Main Function**: The `main` function reads input lines, parses the coordinates, and checks if the point \( P \) is inside the triangle using the `is_inside_triangle` function. It prints "YES" if \( P \) is inside and "NO" otherwise.
