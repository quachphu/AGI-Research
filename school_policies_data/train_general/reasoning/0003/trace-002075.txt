To solve this problem, we need to determine the minimum number of cell changes required to make a conveyor belt functional. A conveyor belt is functional if any luggage placed on any cell eventually reaches the counter at cell (n, m).

### Approach
1. **Understanding the Problem**: The conveyor belt is represented as a grid where each cell (except the last cell (n, m)) has a direction either Right (R) or Down (D). Luggage moves according to the direction of the cell until it either reaches (n, m) or moves out of the grid. Our goal is to ensure that all luggage placed anywhere on the grid eventually reaches (n, m).

2. **Key Insight**: For the conveyor belt to be functional:
   - All cells in the last row (except (n, m)) must be Right (R). This ensures that any luggage in the last row moves right towards (n, m).
   - All cells in the last column (except (n, m)) must be Down (D). This ensures that any luggage in the last column moves down towards (n, m).

3. **Counting Changes**: For each test case, count the number of cells in the last row (excluding (n, m)) that are not 'R' and the number of cells in the last column (excluding (n, m)) that are not 'D'. The sum of these counts gives the minimum number of changes needed.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]
    count_r = 0
    # Check last row except last cell
    last_row = grid[-1]
    for c in last_row[:-1]:
        if c != 'R':
            count_r += 1
    # Check last column except last cell
    count_d = 0
    for i in range(n-1):
        if grid[i][m-1] != 'D':
            count_d += 1
    print(count_r + count_d)
```

### Explanation
- **Reading Input**: We start by reading the number of test cases. For each test case, we read the grid dimensions and the grid itself.
- **Checking Last Row**: We check each cell in the last row (excluding the last cell) to count how many are not 'R'.
- **Checking Last Column**: We check each cell in the last column (excluding the last cell) to count how many are not 'D'.
- **Result Calculation**: The sum of the two counts (changes needed for the last row and the last column) gives the minimum number of changes required to make the conveyor belt functional.

This approach efficiently determines the minimum changes by focusing on the critical rows and columns that ensure all paths lead to the destination cell (n, m).
