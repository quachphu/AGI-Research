To solve this problem, we need to determine the number of unique ways a knight can move from the top-left corner (1, 1) to the bottom-right corner (H, W) on a chessboard, while avoiding rocks and only moving towards the right and bottom. The result should be computed modulo 10007.

### Approach
1. **Dynamic Programming (DP) Setup**: Use a 2D DP array `dp` where `dp[r][c]` represents the number of ways to reach position (r, c) from (1, 1).
2. **Rock Handling**: Track positions of rocks using a set to ensure the knight does not land on these squares.
3. **Knight Moves**: The knight can move in two valid ways: (r+1, c+2) and (r+2, c+1). Thus, to reach (r, c), the knight must come from either (r-1, c-2) or (r-2, c-1), provided these positions are valid and not rocks.
4. **Modulo Operation**: Ensure each step's result is taken modulo 10007 to handle large numbers efficiently.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    MOD = 10007
    for case in range(1, N + 1):
        H = int(input[ptr])
        W = int(input[ptr + 1])
        R = int(input[ptr + 2])
        ptr += 3
        rocks = set()
        for _ in range(R):
            r = int(input[ptr])
            c = int(input[ptr + 1])
            rocks.add((r, c))
            ptr += 2
        dp = [[0] * (W + 1) for _ in range(H + 1)]
        dp[1][1] = 1
        for r in range(1, H + 1):
            for c in range(1, W + 1):
                if (r, c) == (1, 1):
                    continue
                if (r, c) in rocks:
                    dp[r][c] = 0
                    continue
                total = 0
                if r - 1 >= 1 and c - 2 >= 1:
                    total += dp[r - 1][c - 2]
                if r - 2 >= 1 and c - 1 >= 1:
                    total += dp[r - 2][c - 1]
                dp[r][c] = total % MOD
        print(f"Case #{case}: {dp[H][W] % MOD}")

main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, and parsed using a pointer to track the current position in the input list.
2. **Rock Positions**: Rocks are stored in a set for O(1) lookup time to check if a position is a rock.
3. **DP Initialization**: The DP array is initialized with `dp[1][1] = 1` since the knight starts at (1, 1).
4. **Filling DP Table**: For each cell (r, c), the number of ways to reach it is computed by summing the ways from valid previous positions (r-1, c-2) and (r-2, c-1), if they exist and are not rocks. Each entry is taken modulo 10007 to prevent overflow.
5. **Output**: The result for each test case is printed in the required format, ensuring the result is modulo 10007.

This approach efficiently computes the number of valid paths using dynamic programming while adhering to the constraints and modulo requirements.
