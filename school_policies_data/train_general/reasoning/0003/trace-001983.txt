To solve this problem, we need to efficiently apply multiple operations on an array based on several range queries. Each query specifies a range of operations to apply, and each operation modifies a subarray of the original array. The challenge is to handle up to 100,000 operations and queries efficiently.

### Approach
1. **Difference Array for Operation Counts**: 
   - Use a difference array to count how many times each operation is applied across all queries. This allows us to efficiently compute the number of times each operation is used in O(1) per query, followed by a prefix sum calculation.

2. **Difference Array for Array Updates**:
   - Once we know how many times each operation is applied, use another difference array to efficiently apply the cumulative effect of all operations to the original array. This avoids directly iterating over large subarrays multiple times.

### Solution Code
```python
import sys

def main():
    n, m, k = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    
    ops = []
    for _ in range(m):
        l, r, d = map(int, sys.stdin.readline().split())
        l -= 1  # Convert to 0-based
        r -= 1
        ops.append((l, r, d))
    
    # Initialize the count difference array for operations
    cnt_diff = [0] * (m + 2)  # 1-based to m
    for _ in range(k):
        x, y = map(int, sys.stdin.readline().split())
        cnt_diff[x] += 1
        cnt_diff[y + 1] -= 1
    
    # Compute the count for each operation using prefix sum
    op_counts = [0] * (m + 1)  # 1-based
    current = 0
    for i in range(1, m + 1):
        current += cnt_diff[i]
        op_counts[i] = current
    
    # Apply each operation's effect using a difference array for the main array
    a_diff = [0] * (n + 1)  # 0-based with size n+1
    for j in range(m):
        l, r, d = ops[j]
        count = op_counts[j + 1]  # op_counts is 1-based
        delta = d * count
        a_diff[l] += delta
        a_diff[r + 1] -= delta  # Handles r+1 correctly even if r is the last index
    
    # Compute the prefix sum and update the array
    current = 0
    for i in range(n):
        current += a_diff[i]
        a[i] += current
    
    print(' '.join(map(str, a)))

if __name__ == "__main__":
    main()
```
