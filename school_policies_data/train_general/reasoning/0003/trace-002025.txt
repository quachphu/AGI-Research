### Approach
1. **Understanding the Weekly Schedule**: The classes are held on specific days of the week, which repeats every 7 days. We need to consider this cyclic nature to find the optimal solution.
2. **Key Observations**:
   - **Full Weeks**: Calculate the number of classes in a full week (`s`). If `k` is a multiple of `s`, we can use the full weeks to reduce the problem size.
   - **Remaining Classes**: For the remainder when `k` is divided by `s`, we need to find the shortest period that covers these remaining classes.
3. **Expanding the Week**: To handle the cyclic nature, we expand the week into a two-week period. This helps in finding the minimal window for any number of classes, including those that wrap around the week.
4. **Precompute Minimal Windows**: For each possible number of classes (from 1 to `s`), compute the shortest continuous period that can cover exactly that number of classes. This is done by checking all possible consecutive sequences in the expanded week.

import sys

def main():
    input = sys.stdin.read().split()
    idx = 0
    t = int(input[idx])
    idx += 1
    for _ in range(t):
        k = int(input[idx])
        idx += 1
        a = list(map(int, input[idx:idx+7]))
        idx += 7
        
        ones = [i for i in range(7) if a[i] == 1]
        s = len(ones)
        expanded_ones = ones + [x + 7 for x in ones]
        
        min_windows = [float('inf')] * (s + 1)
        
        for x in range(1, s + 1):
            min_len = float('inf')
            for i in range(len(expanded_ones) - x + 1):
                start = expanded_ones[i]
                end = expanded_ones[i + x - 1]
                current_len = end - start + 1
                if current_len < min_len:
                    min_len = current_len
            min_windows[x] = min_len
        
        q, r = divmod(k, s)
        if r == 0:
            ans = (q - 1) * 7 + min_windows[s]
        else:
            ans = q * 7 + min_windows[r]
        
        print(ans)

if __name__ == "__main__":
