To solve this problem, we need to convert Roman numerals into their corresponding Arabic numerals. Roman numerals follow specific rules where the value of a numeral is added if it is placed before a larger numeral and subtracted if placed after. The challenge is to accurately apply these rules to convert the given Roman numerals into integers.

### Approach
1. **Mapping Roman Symbols to Values**: Create a dictionary to map each Roman numeral character to its corresponding integer value.
2. **Convert Input String to Values**: Convert each character of the input Roman numeral string into its respective integer value using the dictionary.
3. **Sum All Values**: Initially sum all the converted values. This sum will be adjusted based on the subtraction rule.
4. **Adjust for Subtraction Rule**: Iterate through the list of values and check if a smaller value precedes a larger value. For each such occurrence, subtract twice the smaller value from the total sum. This adjustment is necessary because the smaller value was initially added once, but it should be subtracted once (thus the total adjustment is subtracting twice the smaller value).

### Solution Code
```python
def roman_to_arabic(s):
    roman_values = {'I': 1, 'V': 5, 'X': 10, 'L': 50, 'C': 100, 'D': 500, 'M': 1000}
    values = [roman_values[c] for c in s]
    total = sum(values)
    # Adjust for subtractive cases
    for i in range(len(values) - 1):
        if values[i] < values[i + 1]:
            total -= 2 * values[i]
    return total

import sys

for line in sys.stdin:
    line = line.strip()
    if line:
        print(roman_to_arabic(line))
```

### Explanation
1. **Mapping Values**: The dictionary `roman_values` maps each Roman numeral character to its integer value.
2. **Conversion to Integer List**: The input string is converted into a list of integers using the dictionary.
3. **Initial Sum**: The sum of all integer values is computed.
4. **Adjustment for Subtraction**: By iterating through the list and checking each consecutive pair, we adjust the total sum by subtracting twice the smaller value whenever a smaller numeral precedes a larger one. This corrects the initial sum to account for the subtraction rule in Roman numerals.

This approach efficiently converts Roman numerals to integers by leveraging a two-step process of summing and adjusting, ensuring accurate conversion according to the specified rules.
