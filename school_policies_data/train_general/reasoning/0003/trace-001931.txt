To solve this problem, we need to determine the optimal starting point for Yura on the parking lot's grid lines such that the total time required to guess all cars is minimized. The time calculation is based on the square of the Euclidean distance from Yura's chosen point to the center of each car's square, multiplied by the car's rarity coefficient.

### Approach
1. **Problem Analysis**:
   - The parking lot is divided into a grid of 4x4 meter squares.
   - Yura's goal is to minimize the total time spent guessing all cars, which depends on the squared distance from his position to each car's center.
   - The optimal position can be determined by separately optimizing the coordinates along the north-south (x-axis) and west-east (y-axis) directions due to the problem's separable nature.

2. **Key Insights**:
   - The total time can be split into two independent sums: one for the x-direction and one for the y-direction.
   - Each sum can be minimized independently, leading to a significant reduction in computational complexity.

3. **Algorithm**:
   - **Row and Column Sums**: Compute the sum of rarity coefficients for each row and each column.
   - **Optimal Coordinates**: Calculate the optimal x and y coordinates using the weighted average of the row and column sums, respectively.
   - **Discrete Adjustment**: Adjust the optimal continuous coordinates to the nearest valid grid line intersections, considering possible ties and selecting the smallest indices when necessary.

4. **Complexity**:
   - The algorithm runs in O(nm) time for computing row and column sums, and O(n + m) time for determining the optimal coordinates, making it efficient even for large grid sizes.

### Solution Code
```python
import math

n, m = map(int, input().split())
c = [list(map(int, input().split())) for _ in range(n)]

row_sum = [sum(row) for row in c]
column_sum = [0] * m
for j in range(m):
    for i in range(n):
        column_sum[j] += c[i][j]

sum_row_total = sum(row_sum)
sum_column_total = sum(column_sum)

best_li = 0
if sum_row_total != 0:
    x_opt_numerator = 0
    for i in range(n):
        x_opt_numerator += row_sum[i] * (4 * (i + 1) - 2)
    x_opt = x_opt_numerator / sum_row_total
    li_candidate = x_opt / 4
    li_floor = math.floor(li_candidate)
    candidates = [li_floor, li_floor + 1]
    valid_candidates = [li for li in candidates if 0 <= li <= n]
    best_li = valid_candidates[0]
    min_diff = abs(4 * best_li - x_opt)
    for li in valid_candidates[1:]:
        current_diff = abs(4 * li - x_opt)
        if current_diff < min_diff or (current_diff == min_diff and li < best_li):
            best_li = li
            min_diff = current_diff
else:
    best_li = 0

best_lj = 0
if sum_column_total != 0:
    y_opt_numerator = 0
    for j in range(m):
        y_opt_numerator += column_sum[j] * (4 * (j + 1) - 2)
    y_opt = y_opt_numerator / sum_column_total
    lj_candidate = y_opt / 4
    lj_floor = math.floor(lj_candidate)
    candidates = [lj_floor, lj_floor + 1]
    valid_candidates = [lj for lj in candidates if 0 <= lj <= m]
    best_lj = valid_candidates[0]
    min_diff = abs(4 * best_lj - y_opt)
    for lj in valid_candidates[1:]:
        current_diff = abs(4 * lj - y_opt)
        if current_diff < min_diff or (current_diff == min_diff and lj < best_lj):
            best_lj = lj
            min_diff = current_diff
else:
    best_lj = 0

total_time = 0
x = 4 * best_li
y = 4 * best_lj
for i in range(n):
    for j in range(m):
        cx = 4 * (i + 1) - 2
        cy = 4 * (j + 1) - 2
        dx = x - cx
        dy = y - cy
        total_time += c[i][j] * (dx ** 2 + dy ** 2)

print(total_time)
print(best_li, best_lj)
```

3. **Optimal Coordinates Calculation**: Calculate the optimal x and y coordinates using weighted averages. Adjust these coordinates to the nearest valid grid intersections.
4. **Total Time Calculation**: Compute the total time using the optimal coordinates and output the result.

This approach ensures that we efficiently determine the optimal starting point by leveraging mathematical properties of quadratic functions and grid-based adjustments, leading to an optimal and efficient solution.
