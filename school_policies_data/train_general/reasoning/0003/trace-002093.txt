### Approach
1. **Initialization**: Read the input and initialize the necessary data structures to track the employees' queues on each floor, their pickup status, and the current state of the elevator.
2. **Determine Target Floors**: The elevator's movement is driven by the need to pick up employees in the order they arrived (input order). The next target floor is determined by the earliest employee who hasn't been picked up yet.
3. **Movement and Stops**: Move the elevator towards the target floor. During movement, check each floor for passengers needing to exit. If passengers exit, update the time and remove them from the elevator.
4. **Loading Passengers**: When the elevator stops at a floor, load as many passengers as possible (up to 4) from that floor's queue, ensuring they are the next in the global input order.
5. **Delivery Phase**: Once all employees are picked up, continue delivering remaining passengers to their destinations.

### Solution Code
```python
import sys
from collections import deque, defaultdict

def main():
    n = int(sys.stdin.readline())
    employees = []
    floor_queues = defaultdict(deque)
    for idx in range(n):
        a, b = map(int, sys.stdin.readline().split())
        employees.append((a, b, idx))
        floor_queues[a].append((a, b, idx))
    
    picked = [False] * n
    earliest_idx = 0
    while earliest_idx < n and picked[earliest_idx]:
        earliest_idx += 1
    
    current_floor = 1
    time = 0
    passengers = []
    
    while True:
        if earliest_idx < n:
            target_floor = employees[earliest_idx][0]
        else:
            if passengers:
                target_floor = passengers[0][1]
            else:
                break
        
        direction = 1 if target_floor > current_floor else -1
        while current_floor != target_floor:
            current_floor += direction
            time += 1
            exits = [p for p in passengers if p[1] == current_floor]
            if exits:
                time += len(exits)
                passengers = [p for p in passengers if p[1] != current_floor]
                if earliest_idx < n and employees[earliest_idx][0] == current_floor:
                    queue = floor_queues[current_floor]
                    loaded = 0
                    while queue and loaded < (4 - len(passengers)) and queue[0][2] == earliest_idx:
                        emp = queue.popleft()
                        passengers.append(emp)
                        picked[emp[2]] = True
                        loaded += 1
                        while earliest_idx < n and picked[earliest_idx]:
                            earliest_idx += 1
                    time += loaded
        
        exits = [p for p in passengers if p[1] == current_floor]
        if exits:
            time += len(exits)
            passengers = [p for p in passengers if p[1] != current_floor]
        
        if earliest_idx < n and employees[earliest_idx][0] == current_floor:
            queue = floor_queues[current_floor]
            loaded = 0
            while queue and loaded < (4 - len(passengers)) and queue[0][2] == earliest_idx:
                emp = queue.popleft()
                passengers.append(emp)
                picked[emp[2]] = True
                loaded += 1
                while earliest_idx < n and picked[earliest_idx]:
                    earliest_idx += 1
            time += loaded
        
        while earliest_idx < n and picked[earliest_idx]:
            earliest_idx += 1
    
    print(time)

    main()
```

- **Loading Passengers**: When the elevator stops at a floor, it loads as many passengers as possible from that floor's queue, ensuring they are picked up in the correct order and respecting the elevator's capacity.
- **Efficient Index Management**: The earliest employee to be picked up is tracked using an index that is updated as passengers are loaded, ensuring efficient lookups and minimizing redundant checks.
