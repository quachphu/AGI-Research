To solve this problem, we need to determine the minimum cost required to purchase a subset of books such that the combined values of their algorithms meet or exceed a specified threshold for each algorithm. If it is impossible to meet the threshold for any algorithm, we should return -1.

### Approach
1. **Problem Analysis**: The problem can be approached by considering all possible subsets of books. Each book has a cost and contributes to the values of multiple algorithms. The goal is to find the subset with the minimum cost where the sum of each algorithm's values meets or exceeds the given threshold.

2. **Brute-force with Bitmasking**: Given the constraints (N and M up to 12), a brute-force approach using bitmasking is feasible. Each bitmask represents a subset of books, where each bit indicates whether a particular book is included in the subset. We iterate over all possible subsets (from 1 to \(2^N - 1\)) to check if they meet the threshold for all algorithms and track the minimum cost.

3. **Complexity Consideration**: The number of subsets is \(2^{12} = 4096\), and for each subset, we need to compute the sum of each algorithm's values. This results in a manageable complexity of approximately \(4096 \times 12 \times 12 = 590,000\) operations, which is feasible for Python.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    m = int(input[idx])
    idx += 1
    x = int(input[idx])
    idx += 1

    books = []
    for _ in range(n):
        c = int(input[idx])
        idx += 1
        a = list(map(int, input[idx:idx + m]))
        idx += m
        books.append((c, a))

    min_cost = float('inf')

    for mask in range(1, 1 << n):
        total_cost = 0
        sum_a = [0] * m
        for i in range(n):
            if mask & (1 << i):
                total_cost += books[i][0]
                for j in range(m):
                    sum_a[j] += books[i][1][j]
        # Check if all algorithms meet or exceed X
        if all(s >= x for s in sum_a):
            if total_cost < min_cost:
                min_cost = total_cost

    print(-1 if min_cost == float('inf') else min_cost)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of books (N), number of algorithms (M), the threshold value (X), and the list of books with their respective costs and algorithm values.

2. **Bitmask Iteration**: We iterate over all possible subsets using bitmasking. Each bitmask from 1 to \(2^N - 1\) represents a subset of books.

3. **Sum Calculation**: For each subset, we calculate the total cost and the sum of each algorithm's values. If all sums meet or exceed the threshold, we update the minimum cost if the current subset's cost is lower.

4. **Result Check**: After evaluating all subsets, if no valid subset is found, we print -1. Otherwise, we print the minimum cost found.

This approach efficiently explores all possible subsets using bitmasking, ensuring we find the optimal solution within the given constraints.
