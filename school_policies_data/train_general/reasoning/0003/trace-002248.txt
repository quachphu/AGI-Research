To solve this problem, we need to determine if an array has a non-empty subsequence whose product is not a perfect square. The key insight is that if any element in the array is not a perfect square, then there exists a subsequence (specifically, that element alone) whose product is not a perfect square. Conversely, if all elements are perfect squares, every possible subsequence product will be a perfect square.

### Approach
1. **Check for Perfect Squares**: For each element in the array, check if it is a perfect square. This can be done by computing the integer square root of the element and verifying if squaring this root gives back the original element.
2. **Determine Result**: If any element is not a perfect square, the answer is "YES". If all elements are perfect squares, the answer is "NO".

### Solution Code
```python
import math

def is_perfect_square(x):
    s = math.isqrt(x)
    return s * s == x

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    has_non_square = any(not is_perfect_square(num) for num in a)
    print("YES" if has_non_square else "NO")
```

### Explanation
1. **Reading Input**: The input consists of multiple test cases. For each test case, we read the length of the array and the array elements.
2. **Perfect Square Check**: For each element in the array, we use the `is_perfect_square` function to check if the element is a perfect square. This function calculates the integer square root and checks if squaring it returns the original number.
3. **Result Determination**: If any element is found not to be a perfect square, we immediately know there exists a valid subsequence (the element itself), and we print "YES". If all elements are perfect squares, we print "NO".

This approach efficiently checks each element in linear time, ensuring the solution is optimal and handles the constraints effectively.
