To solve this problem, we need to determine if at least one card from a given hand can be played on a card currently on the table based on matching either the rank or the suit of the table card.

### Approach
1. **Input Reading**: Read the table card and the five hand cards.
2. **Extract Attributes**: Extract the rank and suit from the table card.
3. **Check Each Hand Card**: For each card in the hand, check if either its rank or suit matches the rank or suit of the table card.
4. **Determine Result**: If any card in the hand matches, output "YES"; otherwise, output "NO".

### Solution Code
```python
def check_playable():
    table_card = input().strip()
    hand_cards = input().split()
    table_rank = table_card[0]
    table_suit = table_card[1]
    for card in hand_cards:
        if card[0] == table_rank or card[1] == table_suit:
            print("YES")
            return
    print("NO")

check_playable()
```

### Explanation
1. **Reading Input**: The first line of input is the table card, and the second line contains the five hand cards.
2. **Extracting Attributes**: The rank and suit of the table card are extracted using string indexing.
3. **Checking Matches**: Each card in the hand is checked to see if its rank or suit matches the table card's rank or suit. If a match is found, "YES" is printed immediately, and the function exits.
4. **Result Determination**: If no matches are found after checking all cards, "NO" is printed.

This approach ensures that we efficiently check each card in the hand only once, leading to an optimal solution with a time complexity of O(1) since there are always exactly five cards to check. This guarantees the solution is both time-efficient and straightforward.
