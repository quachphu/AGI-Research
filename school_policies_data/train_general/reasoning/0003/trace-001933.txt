To solve this problem, we need to determine which player will win a game where two players alternately remove characters from a string. The player wins if, before their turn, the remaining characters can be reordered into a palindrome. Both players play optimally.

### Approach
1. **Palindrome Check**: A string can be reordered into a palindrome if at most one character has an odd count. For example, "abba" (even counts) and "aba" (one odd count) are palindromes.
2. **Odd Count Analysis**: The key insight is to count how many characters have odd frequencies. Let's denote this count as `k`.
3. **Winning Conditions**:
   - If `k` is 0 or 1, the first player wins immediately because the string can already be reordered into a palindrome.
   - If `k` is greater than 1, the outcome depends on the parity of `k-1`. If `(k-1) % 2 == 0`, the first player wins; otherwise, the second player wins. This is derived from the optimal moves each player would make to force the opponent into a losing position.

### Solution Code
```python
s = input().strip()
freq = [0] * 26
for c in s:
    freq[ord(c) - ord('a')] += 1

k = sum(1 for x in freq if x % 2 != 0)

if k <= 1:
    print("First")
else:
    print("First" if (k - 1) % 2 == 0 else "Second")
```

### Explanation
1. **Frequency Count**: We first count the frequency of each character in the string using an array of size 26 (for each lowercase English letter).
2. **Odd Frequency Calculation**: We determine how many characters have odd frequencies.
3. **Decision Logic**:
   - If there are 0 or 1 characters with odd frequencies, the first player wins immediately.
   - For more than 1 odd frequency, the result is determined by checking if `(k-1)` is even or odd. If even, the first player wins; otherwise, the second player wins.

This approach efficiently determines the winner by leveraging the properties of palindrome formation and optimal game strategy.
