To solve this problem, we need to determine the minimum number of coins required such that the sum of the selected coins is strictly greater than the sum of the remaining coins. This ensures that one of the twins gets a strictly larger amount of money while using the fewest coins possible.

### Approach
1. **Sort the Coins**: First, we sort the coins in descending order. This allows us to pick the largest coins first, which helps in reaching the required sum with fewer coins.
2. **Calculate Total Sum**: Compute the total sum of all the coins. This helps in determining the threshold sum needed to exceed half of the total sum.
3. **Accumulate Coins**: Iterate through the sorted coins, accumulating their values until the accumulated sum exceeds half of the total sum. The number of coins used in this accumulation is the answer.

### Solution Code
```python
n = int(input())
coins = list(map(int, input().split()))
coins.sort(reverse=True)
total_sum = sum(coins)
current_sum = 0
count = 0

for coin in coins:
    current_sum += coin
    count += 1
    if current_sum > total_sum / 2:
        break

print(count)
```

### Explanation
1. **Sorting**: By sorting the coins in descending order, we ensure that we start with the largest denominations. This strategy helps in reaching the required sum more quickly, minimizing the number of coins used.
2. **Total Sum Calculation**: The total sum of all coins is calculated to determine the threshold sum needed, which is half of the total sum. We need our accumulated sum to be strictly greater than this threshold.
3. **Accumulation Loop**: We iterate through the sorted coins, adding each coin's value to a running total. Each time a coin is added, we check if the running total exceeds half of the total sum. If it does, we immediately stop the loop and output the count of coins used.

This approach efficiently ensures that we use the minimum number of coins to meet the requirement by leveraging the largest denominations first, thus optimizing the solution.
