To solve this problem, we need to determine the minimum cost for purchasing all objects listed in a string, considering a Buy 1 Get 1 discount offer. The discount allows getting an additional object of the same type for free when one is purchased. 

### Approach
1. **Understanding the Discount**: For each pair of identical objects, we only pay for one. If there's an odd number of a particular object, the cost is rounded up (since we can't split an object into half).
2. **Frequency Count**: For each test case, count the frequency of each character in the string.
3. **Cost Calculation**: For each character, compute the cost using the formula `(count + 1) // 2`. This formula effectively handles both even and odd counts by rounding up the division by 2.
4. **Summing Costs**: Sum the costs calculated for each character to get the total minimum cost for that test case.

### Solution Code
```python
import sys
from collections import Counter

def calculate_min_cost():
    T = int(sys.stdin.readline())
    for _ in range(T):
        S = sys.stdin.readline().strip()
        counts = Counter(S)
        total = 0
        for count in counts.values():
            total += (count + 1) // 2
        print(total)

calculate_min_cost()
```

### Explanation
1. **Reading Input**: The code reads the number of test cases `T` and then processes each string `S` for each test case.
2. **Counting Frequencies**: Using `Counter` from the `collections` module, we efficiently count the occurrences of each character in the string.
3. **Computing Costs**: For each character, the cost is calculated using integer division to handle both even and odd counts correctly. The formula `(count + 1) // 2` ensures that we round up when the count is odd.
4. **Output**: The total minimum cost for each test case is printed immediately after processing the string.

This approach ensures that we efficiently compute the minimum cost by leveraging frequency counts and simple arithmetic operations, resulting in an optimal solution with linear time complexity relative to the length of the input string.
