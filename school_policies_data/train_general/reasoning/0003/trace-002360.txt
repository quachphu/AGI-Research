To solve this problem, we need to determine the minimal number of presents the Hedgehog will receive over the next N days, considering that he must receive presents on holidays and at least every K days. 

### Approach
1. **Initialization**: Start from day 0, which is not counted as a present day but serves as the reference point.
2. **Process Holidays**: For each holiday, check if it is more than K days away from the last present day. If so, insert presents every K days until the holiday is within the K-day window.
3. **Insert Presents for Holidays**: Once the holiday is within the K-day window, add a present on the holiday and update the last present day.
4. **Check Remaining Days**: After processing all holidays, check if there are any remaining days beyond the last present day that require presents to maintain the K-day rule.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    k = int(input[ptr])
    ptr += 1
    
    c = int(input[ptr])
    ptr += 1
    holidays = list(map(int, input[ptr:ptr + c]))
    ptr += c
    
    last = 0
    count = 0
    
    for h in holidays:
        while h > last + k:
            count += 1
            last += k
        count += 1
        last = h
    
    remaining = n - last
    if remaining >= k:
        count += remaining // k
    
    print(count)

main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of days (N), the interval (K), and the list of holidays.
2. **Processing Each Holiday**: For each holiday, if it is more than K days away from the last present day, we insert presents every K days until the holiday is within the K-day window. This ensures we meet the requirement of presents every K days.
3. **Adding Presents on Holidays**: Once the holiday is within the K-day window, a present is added on the holiday itself.
4. **Handling Remaining Days**: After all holidays are processed, we check if there are remaining days beyond the last present day. If so, we add presents every K days until we cover all days up to N.

This approach efficiently ensures that all constraints are met with minimal presents by strategically placing them on holidays and necessary intervals.
