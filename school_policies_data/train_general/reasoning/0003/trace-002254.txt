To solve this problem, we need to find the optimal point on a line such that the sum of distances from this point to all given points is minimized. If there are multiple such points, we should choose the leftmost one. The solution leverages the property that the median of a sorted list minimizes the sum of absolute deviations.

### Approach
1. **Understanding the Median**: The median of a list of numbers is the value that separates the higher half from the lower half. For an odd number of points, it is the middle element. For an even number of points, it can be any value between the two middle elements, but since we need the leftmost one, we take the first of the two middle elements.
2. **Sorting**: By sorting the list of points, we can easily find the median by accessing the middle element(s).
3. **Index Calculation**: The median index for both even and odd numbers of points can be calculated as `(n-1) // 2`, where `n` is the number of points. This formula works because integer division in Python effectively gives the lower middle index for even `n`.

### Solution Code
```python
def main():
    import sys
    input_data = sys.stdin.read().split()
    n = int(input_data[0])
    x = list(map(int, input_data[1:n+1]))
    x.sort()
    print(x[(n - 1) // 2])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go and split into a list of strings. The first element is the number of points, `n`, and the subsequent elements are the coordinates of the points.
2. **Sorting**: The list of coordinates is sorted to facilitate median calculation.
3. **Finding the Median**: The median is found at the index `(n-1) // 2` in the sorted list. This index ensures that for both even and odd `n`, the correct median (leftmost in case of even `n`) is selected.
4. **Output**: The median value is printed as the optimal point.

This approach efficiently handles the constraints with a time complexity of O(n log n) due to sorting, which is suitable for large input sizes up to 300,000 points. The solution ensures that the optimal point is found correctly and efficiently.
