To solve this problem, we need to determine the number of valid character builds where the final strength is strictly greater than the final intelligence after distributing all experience points. The solution involves calculating the valid range of experience points that can be allocated to strength while satisfying the given conditions.

### Approach
1. **Problem Analysis**:
   - We need to distribute all experience points such that the final strength is strictly greater than the final intelligence.
   - The key is to find the minimum number of points that must be allocated to strength to satisfy the condition, and then count all valid allocations within the range.

2. **Key Insight**:
   - Let `str` be the initial strength, `int` be the initial intelligence, and `exp` be the experience points.
   - The condition after distributing points is: `str + s > int + (exp - s)`, where `s` is the points allocated to strength.
   - Rearranging this inequality gives: `2s > int + exp - str`, leading to `s > (int + exp - str) / 2`.

3. **Algorithm**:
   - Calculate `D = int + exp - str`.
   - Determine the minimum `s` (denoted `s_min`) using integer division to handle both even and odd values of `D`.
   - Check the valid range of `s` values from `s_min` to `exp` and count the valid allocations.

### Solution Code
```python
def calculate_builds():
    import sys
    input = sys.stdin.read
    data = input().split()
    
    T = int(data[0])
    index = 1
    results = []
    
    for _ in range(T):
        str_val = int(data[index])
        int_val = int(data[index + 1])
        exp = int(data[index + 2])
        index += 3
        
        D = int_val + exp - str_val
        s_min = (D // 2) + 1
        s_min = max(0, s_min)
        
        if s_min > exp:
            results.append(0)
        else:
            results.append(exp - s_min + 1)
    
    for result in results:
        print(result)

calculate_builds()
```

1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Processing Each Query**:
   - For each query, compute `D` which represents the difference needed to check the condition.
   - Calculate `s_min` as the minimum points needed to allocate to strength to ensure it exceeds intelligence.
   - Adjust `s_min` to be non-negative and check if it exceeds the available experience points.
3. **Counting Valid Builds**: If `s_min` is within the valid range, count the number of valid allocations from `s_min` to `exp`.

This approach efficiently computes the valid character builds using mathematical insights and integer operations to handle large values within constraints.
