To solve this problem, we need to determine the largest possible number that can be formed using a given amount of sand, where each digit (1-9) has a specific sand cost. If it's impossible to form any number with the given sand, we should return -1.

### Approach
1. **Identify Feasibility**: Check if any digit can be formed with the given sand. If the minimal sand cost among all digits exceeds the available sand, it's impossible to form any number.
2. **Maximize Length**: The largest number possible is determined by the maximum number of digits. This is achieved by using the digit with the minimal sand cost.
3. **Optimize Digits**: Once the maximum length is determined, replace digits starting from the left with the highest possible digits that can be afforded using the remaining sand after forming the initial number.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        x = int(input[ptr])
        ptr += 1
        costs = list(map(int, input[ptr:ptr+9]))
        ptr +=9
        
        min_cost = min(costs)
        if min_cost > x:
            print(-1)
            continue
        
        # Find the largest digit with minimal cost
        d_min = -1
        for d in reversed(range(9)):
            if costs[d] == min_cost:
                d_min = d + 1  # since digits are 1-9
                break
        
        max_length = x // min_cost
        remaining_sand = x % min_cost
        number = [d_min] * max_length
        
        # Try to replace digits to maximize the number
        for i in range(max_length):
            if remaining_sand == 0:
                break
            current_d = number[i]
            # Check digits higher than current_d
            for d in range(9, current_d, -1):
                cost = costs[d - 1]
                diff = cost - min_cost
                if diff <= remaining_sand:
                    number[i] = d
                    remaining_sand -= diff
                    break
        
        print(''.join(map(str, number)))
        
if __name__ == "__main__":
    main()
```

4. **Optimize Digits**: Starting from the leftmost digit, replace each digit with the highest possible digit that can be afforded using the remaining sand. This ensures the largest possible number is formed by leveraging higher digits where possible.
