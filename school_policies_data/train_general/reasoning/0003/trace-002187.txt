To solve this problem, we need to determine the minimum number of moves required to collect all the books on a shelf into a contiguous segment. The key observation is that the number of moves required is determined by the gaps between existing blocks of books. Each gap contributes moves equal to its length, as each move can shift a contiguous block of books to close a gap by one position.

### Approach
1. **Identify Blocks of Books**: For each test case, identify the contiguous blocks of books (1s) in the array.
2. **Calculate Gaps Between Blocks**: For each consecutive pair of blocks, compute the number of gaps (0s) between them.
3. **Sum the Gaps**: The total number of moves required is the sum of all these gaps. Each gap of length `m` requires `m` moves to close.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    blocks = []
    i = 0
    while i < n:
        if a[i] == 1:
            start = i
            while i < n and a[i] == 1:
                i += 1
            end = i - 1
            blocks.append((start, end))
        else:
            i += 1
    total = 0
    for j in range(1, len(blocks)):
        prev_end = blocks[j-1][1]
        curr_start = blocks[j][0]
        total += (curr_start - prev_end - 1)
    print(total)
```

### Explanation
1. **Reading Input**: The code reads the number of test cases and processes each test case individually.
2. **Block Identification**: For each test case, the array is scanned to identify contiguous blocks of books. Each block is recorded with its start and end indices.
3. **Gap Calculation**: For each consecutive pair of blocks, the gap between them (number of zeros) is calculated. This is done by subtracting the end index of the previous block from the start index of the next block and adjusting for 0-based indexing.
4. **Summing Gaps**: The gaps between all consecutive blocks are summed to get the total number of moves required, which is then printed for each test case.

This approach efficiently computes the result by focusing on the gaps between blocks of books, ensuring an optimal solution with a time complexity of O(n) per test case, where n is the length of the bookshelf array.
