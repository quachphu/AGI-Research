To solve this problem, we need to determine if a given string is a valid Jabber ID based on specific rules for the username, hostname, and an optional resource. The solution involves checking each component of the string against these rules using a systematic approach.

### Approach
1. **Check for Exactly One '@'**: The input string must contain exactly one '@' character to split the username and the rest of the components.
2. **Validate Username**: The username must be between 1 and 16 characters long and can only contain Latin letters (both cases), digits, or underscores.
3. **Split Hostname and Resource**: The part after '@' is split into hostname and an optional resource using the first '/' encountered.
4. **Validate Hostname**: The hostname must be between 1 and 32 characters long, consist of valid words separated by periods, and each word must be between 1 and 16 characters long.
5. **Validate Resource (if present)**: The optional resource must be between 1 and 16 characters long and follow the same character rules as the username.

### Solution Code
```python
def is_valid_jabber_id(s):
    allowed = set("abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789_")
    
    # Check for exactly one '@'
    if s.count('@') != 1:
        return False
    username_part, host_resource_part = s.split('@', 1)
    
    # Validate username
    if not (1 <= len(username_part) <= 16):
        return False
    for c in username_part:
        if c not in allowed:
            return False
    
    # Split hostname and optional resource
    split_host_resource = host_resource_part.split('/', 1)
    hostname_part = split_host_resource[0]
    resource_part = split_host_resource[1] if len(split_host_resource) > 1 else None
    
    # Validate hostname
    if not (1 <= len(hostname_part) <= 32):
        return False
    host_words = hostname_part.split('.')
    for word in host_words:
        if not (1 <= len(word) <= 16):
            return False
        for c in word:
            if c not in allowed:
                return False
    
    # Validate resource if present
    if resource_part is not None:
        if not (1 <= len(resource_part) <= 16):
            return False
        for c in resource_part:
            if c not in allowed:
                return False
    
    return True

# Read input and output result
s = input().strip()
print("YES" if is_valid_jabber_id(s) else "NO")
```

### Explanation
1. **Check '@' Character**: The input string is split into the username and the rest of the components only if there is exactly one '@'.
2. **Username Validation**: The username is checked for length and allowed characters.
3. **Hostname and Resource Split**: The part after '@' is split into hostname and an optional resource using the first '/' found.
4. **Hostname Validation**: The hostname is checked for overall length, and each component (split by periods) is validated for length and allowed characters.
5. **Resource Validation**: If present, the resource is checked for length and allowed characters.

This approach ensures that all components of the Jabber ID are validated according to the given rules, providing an efficient and accurate solution.
