To solve this problem, we need to find the maximum number of positions in a permuted array where each element is greater than the element in the original array's corresponding position. The solution involves a systematic approach to optimally permute the elements to achieve this goal.

### Approach
1. **Sort the Array**: First, we sort the original array. This helps in efficiently finding the smallest possible element in the sorted array that can be placed at each position to maximize the count of elements greater than the original elements.
2. **Two-pointer Technique**: Using two pointers, we iterate through the sorted array to determine the maximum number of elements that can be placed such that each element is greater than the original element at the corresponding position. The two-pointer technique allows us to efficiently find the required elements in linear time.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
sorted_a = sorted(a)
count = 0
j = 0

for num in sorted_a:
    while j < n and sorted_a[j] <= num:
        j += 1
    if j < n:
        count += 1
        j += 1
    else:
        break

print(count)
```

### Explanation
1. **Sorting the Array**: By sorting the original array, we can efficiently use the two-pointer technique to find the optimal permutation. The sorted array allows us to compare elements in a structured manner.
2. **Two-pointer Technique**: 
   - We maintain two pointers, `i` (implicitly via loop iteration) and `j`, where `i` iterates through each element of the sorted array.
   - For each element in the sorted array, we move the pointer `j` until we find an element in the sorted array that is strictly greater than the current element. This ensures that we are using the smallest possible element from the sorted array that can be placed at the current position to satisfy the condition.
   - If such an element is found, we increment the count and move both pointers forward. If not, we break out of the loop as there are no more elements that can satisfy the condition.

This approach ensures that we maximize the count of elements in the permuted array that are greater than the original elements, achieving an efficient solution with a time complexity of O(n log n) due to sorting and O(n) for the two-pointer traversal.
