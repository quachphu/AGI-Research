To solve this problem, we need to efficiently handle two types of queries on an array of flowers: updating a range of flowers to a specific type and calculating the "beautiness" of the collection for a given window size. The beautiness is defined as the sum of distinct flower types in all contiguous windows of the given size.

### Approach
1. **Sliding Window for Beautiness Calculation**: For each query of type 2, we use a sliding window approach to count the number of distinct elements in each window of size K. We maintain a frequency dictionary to keep track of the counts of each flower type within the current window. As we slide the window, we update the frequency dictionary and adjust the count of distinct elements accordingly.

2. **Handling Range Updates**: For each query of type 1, we directly update the specified range in the array. This approach is straightforward but not optimized for very large inputs. However, given the problem constraints, this approach ensures correctness while maintaining simplicity.

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    N, Q = int(input[ptr]), int(input[ptr+1])
    ptr +=2
    A = list(map(int, input[ptr:ptr+N]))
    ptr +=N

        T = int(input[ptr])
        ptr +=1
        if T ==1:
            L = int(input[ptr])-1  # 0-based
            R = int(input[ptr+1])-1
            X = int(input[ptr+2])
            ptr +=3
            for i in range(L, R+1):
                A[i] = X
        else:
            K = int(input[ptr])
            ptr +=1
            if K ==0:
                print(0)
                continue
            freq = {}
            distinct = 0
            res =0
            for i in range(N):
                # Add A[i] to the window
                if A[i] in freq:
                    freq[A[i]] +=1
                else:
                    freq[A[i]] =1
                    distinct +=1
                # Remove the element leaving the window
                if i >= K:
                    left = A[i - K]
                    freq[left] -=1
                    if freq[left] ==0:
                        del freq[left]
                        distinct -=1
                # If window is valid
                if i >= K-1:
                    res += distinct
            print(res)
