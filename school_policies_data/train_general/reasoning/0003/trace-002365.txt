To solve this problem, we need to count the number of distinct geometric progressions (GPs) of length `n` where each element is an integer within the range `[l, r]` and all elements are distinct. A geometric progression is a sequence where each term after the first is found by multiplying the previous term by a fixed non-zero number called the common ratio. The solution must handle both integer and non-integer common ratios efficiently.

### Approach
1. **Special Cases**:
   - If `n` is 1, every integer in the range `[l, r]` is a valid GP. The result is simply `r - l + 1`.
   - If `n` is 2, any pair of distinct integers in the range forms a valid GP. The result is `(r - l + 1) * (r - l)`.

2. **General Case (n >= 3)**:
   - **Integer Ratios**: Handle sequences where the common ratio is an integer greater than 1 and its reciprocal.
   - **Non-integer Ratios**: Handle sequences where the common ratio is a fraction in reduced form (coprime numerator and denominator) and both are greater than 1.

3. **Efficient Calculation**:
   - For integer ratios, iterate over possible ratios and count valid starting terms.
   - For non-integer ratios, iterate over possible denominators and numerators, ensuring they are coprime and within bounds.

### Solution Code
```python
import sys
import math

def main():
    n, l, r = map(int, sys.stdin.readline().split())
    if n == 1:
        print(r - l + 1)
        return
    elif n == 2:
        k = r - l + 1
        print(k * (k - 1))
        return

    total = 0

    # Handle integer ratios (m and 1/m)
    max_m_inc = int(r ** (1 / (n - 1))) if (n - 1) != 0 else 0
    for m in range(2, max_m_inc + 1):
        m_power = m ** (n - 1)
        # Increasing case (ratio = m)
        if m_power > r:
            count_inc = 0
        else:
            max_a_inc = r // m_power
            min_a_inc = max(l, 1)
            if max_a_inc < min_a_inc:
                count_inc = 0
            else:
                count_inc = max(0, max_a_inc - min_a_inc + 1)
        # Decreasing case (ratio = 1/m)
        m_power = m ** (n - 1)
        min_a_dec = l * m_power
        if min_a_dec > r:
            count_dec = 0
        else:
            max_a_dec = (r // m_power) * m_power
            if max_a_dec < min_a_dec:
                count_dec = 0
            else:
                count_dec = (max_a_dec - min_a_dec) // m_power + 1
        total += count_inc + count_dec

    # Handle non-integer ratios (only if n is small enough)
    if n <= 24:
        max_q = int(r ** (1 / (n - 1))) + 1 if (n - 1) != 0 else 0
        for q in range(2, max_q + 1):
            q_power = q ** (n - 1)
            if q_power > r:
                continue
            # Decreasing case: p < q, p >=2, coprime with q
            for p in range(2, q):
                if math.gcd(p, q) == 1:
                    p_power = p ** (n - 1)
                    if p_power == 0:
                        continue
                    min_k = (l + p_power - 1) // p_power  # ceil division
                    max_k = r // q_power
                    if max_k >= min_k and max_k >= 1:
                        total += max_k - min_k + 1
            # Increasing case: p > q, coprime with q
            max_p = int(r ** (1 / (n - 1))) if (n - 1) != 0 else 0
            for p in range(q + 1, max_p + 1):
                if math.gcd(p, q) == 1:
                    p_power = p ** (n - 1)
                    if p_power == 0:
                        continue
                    max_k = r // p_power
                    min_k = (l + q_power - 1) // q_power  # ceil division
                    if max_k >= min_k and max_k >= 1:
                        total += max_k - min_k + 1

    print(total)

if __name__ == "__main__":
    main()
```
