To solve this problem, we need to find the segment of consecutive elements in an array of non-negative integers such that the XOR of all elements in the segment is maximized. The XOR operation is a bitwise exclusive OR, which can be computed efficiently using a prefix XOR array.

### Approach
1. **Read Input**: Read the number of elements and the array itself.
2. **Prefix XOR Array**: Construct a prefix XOR array where each element at index `i` represents the XOR of all elements from the start of the array up to index `i-1`. This allows us to compute the XOR of any subarray in constant time.
3. **Iterate Over All Subarrays**: For each possible starting index `i` and ending index `j` (where `i <= j`), compute the XOR of the subarray using the prefix XOR array. Track the maximum XOR encountered during these computations.

### Solution Code
```python
def find_max_xor():
    n = int(input())
    arr = list(map(int, input().split()))
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i + 1] = prefix[i] ^ arr[i]
    max_xor = 0
    for i in range(n):
        for j in range(i, n):
            current = prefix[j + 1] ^ prefix[i]
            if current > max_xor:
                max_xor = current
    print(max_xor)

find_max_xor()
```

### Explanation
1. **Prefix XOR Array**: The prefix XOR array is built such that `prefix[i+1]` is the XOR of the first `i` elements of the array. This allows us to compute the XOR of any subarray from index `i` to `j` (inclusive) as `prefix[j+1] ^ prefix[i]`.
2. **Maximize XOR**: By iterating over all possible starting and ending indices of subarrays, we compute the XOR for each subarray using the prefix XOR array. This reduces the time complexity to O(n^2), which is efficient enough for the given constraint (n ≤ 100).

This approach ensures that we efficiently compute the maximum XOR value for any consecutive subarray in the input array.
