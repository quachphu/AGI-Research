        print('')

        prev = tokens[i-1]
        current = tokens[i]
        if prev in punctuation:
            output.append(' ')
            output.append(current)
        elif current in punctuation:
            output.append(current)
        else:
            output.append(' ')
            output.append(current)

To solve this problem, we need to format a given text according to specific spacing rules around punctuation marks. The text must be adjusted such that words are separated by exactly one space, there are no spaces before punctuation marks, and there is exactly one space after each punctuation mark.

### Approach
1. **Parse the Input**: Split the input text into tokens where each token is either a word or a punctuation mark. This step ignores spaces and ensures that punctuation marks are treated as separate tokens.
2. **Generate Output**: Iterate through the tokens and construct the output string by inserting the correct spaces between tokens based on their types (word or punctuation). Specifically:
   - If the current token is a word and follows another word, insert one space.
   - If the current token is a punctuation mark, append it directly without a preceding space.
   - If the current token is a word following a punctuation mark, insert one space before the word.

### Solution Code
```python
def process_text():
    import sys
    text = sys.stdin.readline().strip()
    current_word = ''
    tokens = []
    punctuation = {'.', ',', '!', '?'}
    
    for c in text:
        if c in punctuation:
            if current_word:
                tokens.append(current_word)
                current_word = ''
            tokens.append(c)
        elif c == ' ':
            if current_word:
                tokens.append(current_word)
                current_word = ''
        else:
            current_word += c
    if current_word:
        tokens.append(current_word)
    
    if not tokens:
        print('')
        return
    
    output = [tokens[0]]
    for i in range(1, len(tokens)):
        prev = tokens[i-1]
        current = tokens[i]
        if prev in punctuation:
            output.append(' ' + current)
        elif current in punctuation:
            output.append(current)
        else:
            output.append(' ' + current)
    
    print(''.join(output))

process_text()
```

### Explanation
1. **Parsing the Input**: The input text is read and processed character by character. Characters are grouped into words, and punctuation marks are separated into individual tokens. Spaces are used to determine the end of a word.
2. **Constructing the Output**: Starting with the first token, each subsequent token is checked against its predecessor. Depending on whether the tokens are words or punctuation marks, the appropriate spacing is applied. Punctuation marks are appended directly after the preceding word, and words following punctuation are prefixed with a space.

This approach ensures that the output adheres strictly to the specified formatting rules, resulting in a correctly spaced text as required.
