To solve this problem, we need to determine the number of operations required to sort a given permutation using a specific process. Each operation involves rearranging the permutation by moving low elements to the front and high elements to the end, where high elements are those that are the maximum value encountered up to their position.

### Approach
The key insight here is to recognize that each operation effectively groups elements into low and high elements, with high elements forming an increasing sequence. The process continues until the permutation is sorted. The number of operations required is determined by the structure of these groups and how they evolve over each step.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    p = list(map(int, input[1:n+1]))
    
    step = 0
    sorted_p = list(range(1, n+1))
    
    while p != sorted_p:
        # Compute high elements
        high = []
        max_so_far = 0
        for x in p:
            if x > max_so_far:
                max_so_far = x
                high.append(x)
            else:
                high.append(-1)  # mark as low
        
        # Separate lows and highs
        lows = []
        highs = []
        for x, h in zip(p, high):
            if h == -1:
                lows.append(x)
            else:
                highs.append(x)
        
        # Rearrange
        p = lows + highs
        step += 1
    
    print(step)

if __name__ == "__main__":
    main()
```

3. **Loop Until Sorted**: We repeatedly perform the operation until the permutation matches the sorted array.
4. **Identify High Elements**: For each element in the current permutation, we determine if it is a high element by checking if it is the maximum encountered so far.
5. **Separate and Rearrange**: We split the permutation into low and high elements, then rearrange them by placing low elements first followed by high elements.
6. **Count Steps**: Each iteration of the loop counts as one step, and we continue until the permutation is sorted.
