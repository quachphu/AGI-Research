To solve this problem, we need to maximize the total distance of pairs of universities in a tree structure. The tree is defined such that each town is connected by roads in a way that there is exactly one path between any two towns. The goal is to pair 2k universities into k pairs such that the sum of the distances between each pair is maximized.

### Approach
1. **Tree Structure and Input Handling**: Read the number of towns (n) and the number of pairs (k). Read the list of universities and construct the tree using an adjacency list.
2. **Subtree University Count**: Perform a post-order traversal of the tree to compute the number of universities in each subtree. This helps in determining how many universities lie on either side of each edge when the tree is split by that edge.
3. **Edge Contribution Calculation**: For each edge, calculate its contribution to the total distance by considering the number of universities on both sides of the edge. The contribution of an edge is determined by the minimum number of universities on either side of the edge, as this represents the maximum number of pairs that can cross that edge.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    idx = 0
    n, k = int(data[idx]), int(data[idx+1])
    idx += 2
    unis = list(map(int, data[idx:idx+2*k]))
    idx += 2*k
    
    is_uni = [False] * (n + 1)
    for u in unis:
        is_uni[u] = True
    
    # Build adjacency list
    adj = [[] for _ in range(n + 1)]
    for _ in range(n-1):
        u = int(data[idx])
        v = int(data[idx+1])
        adj[u].append(v)
        adj[v].append(u)
        idx += 2
    
    total = 0
    
    stack = [(1, -1, False)]  # (node, parent, visited)
    count = [0] * (n + 1)
    
    while stack:
        node, parent, visited = stack.pop()
        if not visited:
            # Push back as visited and process children
            stack.append( (node, parent, True) )
            # Push children (reverse order to process in correct order)
            for neighbor in reversed(adj[node]):
                if neighbor != parent:
                    stack.append( (neighbor, node, False) )
        else:
            current_count = 0
            if is_uni[node]:
                current_count += 1
            # Sum up children's counts and accumulate contributions
            for neighbor in adj[node]:
                if neighbor != parent:
                    current_count += count[neighbor]
                    # Add the contribution of the edge node -> neighbor
                    contrib = min( count[neighbor], 2*k - count[neighbor] )
                    total += contrib
            count[node] = current_count
    
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of towns, number of pairs, and the list of universities. The adjacency list for the tree is constructed from the given edges.
2. **Post-order Traversal**: Using an iterative approach to avoid recursion depth issues, we traverse the tree starting from an arbitrary root (node 1). During the traversal, we keep track of the number of universities in each subtree.
3. **Edge Contribution Calculation**: For each edge between a node and its child (in the traversal), we calculate the number of universities in the child's subtree. The contribution of this edge to the total distance is the minimum of the number of universities in the subtree and the remaining universities outside the subtree. This value is added to the total sum.

This approach efficiently computes the maximum possible sum of distances by leveraging the properties of tree structures and ensuring each edge's contribution is maximized based on the distribution of universities.
