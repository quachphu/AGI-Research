To solve this problem, we need to count the number of line pairs from two distinct sets that intersect at integer coordinates. The lines from the first set are given by equations of the form \( y = x + p_i \), and the lines from the second set are given by \( y = -x + q_i \). The key insight is that the intersection points will have integer coordinates if and only if the parameters \( p_i \) and \( q_i \) have the same parity (both even or both odd).

### Approach
1. **Parity Check**: For each line in the first set, determine if the parameter \( p_i \) is even or odd. Similarly, check the parity of each parameter \( q_i \) in the second set.
2. **Count Parities**: Count the number of even and odd parameters in both sets.
3. **Calculate Valid Pairs**: The number of valid pairs is the sum of two products:
   - The product of the count of even parameters in the first set and the count of even parameters in the second set.
   - The product of the count of odd parameters in the first set and the count of odd parameters in the second set.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        p = list(map(int, sys.stdin.readline().split()))
        even_p = sum(1 for x in p if x % 2 == 0)
        odd_p = n - even_p
        
        m = int(sys.stdin.readline())
        q = list(map(int, sys.stdin.readline().split()))
        even_q = sum(1 for x in q if x % 2 == 0)
        odd_q = m - even_q
        
        print(even_p * even_q + odd_p * odd_q)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency, especially given the constraints.
2. **Parity Counting**: For each test case, we count the number of even and odd parameters in both sets of lines. This is done using a generator expression to iterate through the parameters and check their parity.
3. **Computing Result**: The result for each test case is computed by multiplying the counts of even parameters from both sets and adding it to the product of the counts of odd parameters from both sets. This gives the total number of valid pairs of lines intersecting at integer coordinates.

This approach ensures that we efficiently count the valid pairs in linear time relative to the input size, making it suitable for large input constraints.
