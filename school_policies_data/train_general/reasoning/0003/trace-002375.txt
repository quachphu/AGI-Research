To solve this problem, we need to determine if a given string is a palindrome. If it is, we then find the ASCII value of the middle character of the string. If the string is not a palindrome, we return -1.

### Approach
1. **Palindrome Check**: For each input string, check if it reads the same forwards and backwards. This can be efficiently done by comparing the string with its reverse.
2. **Middle Character Identification**: If the string is a palindrome, determine the middle character. For odd-length strings, the middle character is at the index `len(S) // 2`. For even-length strings, this index still gives the correct middle character as per the problem's requirements.
3. **ASCII Value Conversion**: Convert the identified middle character to its ASCII value using Python's built-in `ord()` function.

### Solution Code
```python
def main():
    import sys
    T = int(sys.stdin.readline())
    for _ in range(T):
        S = sys.stdin.readline().strip()
        if S == S[::-1]:
            mid = len(S) // 2
            print(ord(S[mid]))
        else:
            print(-1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The number of test cases `T` is read first. Each subsequent line contains a string `S`.
2. **Palindrome Check**: Each string is checked against its reverse. If they match, the string is a palindrome.
3. **Middle Character Calculation**: For a palindrome, the middle index is calculated as the integer division of the string length by 2. This works for both odd and even lengths.
4. **Output**: The ASCII value of the middle character is printed if the string is a palindrome; otherwise, -1 is printed.

This approach efficiently checks for palindromes and computes the required result in linear time relative to the length of the string, ensuring it is optimal for the given constraints.
