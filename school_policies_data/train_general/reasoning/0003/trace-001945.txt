To solve this problem, we need to efficiently compute the sum of elements in a given range for multiple queries on an array. The solution leverages a prefix sum array to achieve this efficiently.

### Approach
1. **Prefix Sum Array**: Construct a prefix sum array where each element at index `i` contains the sum of all elements from the start of the array up to index `i` (1-based index). This allows us to compute the sum of any subarray in constant time.
2. **Query Processing**: For each query, determine the sum of the subarray from index `L` to `R` using the prefix sum array. The sum can be computed as `prefix[R] - prefix[L-1]`, which is an O(1) operation.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    a = list(map(int, input[ptr:ptr + n]))
    ptr += n
    prefix = [0] * (n + 1)
    for i in range(1, n + 1):
        prefix[i] = prefix[i - 1] + a[i - 1]
    q = int(input[ptr])
    ptr += 1
    for _ in range(q):
        l = int(input[ptr])
        r = int(input[ptr + 1])
        ptr += 2
        print(prefix[r] - prefix[l - 1])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints. The input is split into a list of strings for easy processing.
2. **Prefix Sum Array Construction**: The prefix sum array is constructed such that each element at index `i` (1-based) contains the cumulative sum of the array elements from the start up to `i`. This allows us to compute the sum of any subarray in constant time.
3. **Processing Queries**: Each query is processed by computing the difference between the prefix sums at the end and start of the query range. This method ensures that each query is answered in O(1) time after the prefix sum array is built.

This approach efficiently handles the problem constraints, ensuring that even for large input sizes, the solution remains performant.
