To solve this problem, we need to maximize the total money earned by a restaurant by optimally accepting booking requests and assigning tables to groups. The key challenge is to select the best combination of requests and tables to maximize the revenue while ensuring each group can be seated at a table that fits their size.

### Approach
1. **Sort Requests by Profit**: First, we sort all booking requests in descending order based on the money they bring (pi). This ensures that we consider the highest-paying groups first, which helps in maximizing the total revenue.
2. **Sort Tables by Capacity**: Next, we sort the tables in ascending order based on their capacity. This allows us to efficiently find the smallest available table that can accommodate a group, preserving larger tables for potentially larger groups.
3. **Greedy Assignment**: For each request in the sorted list (starting from the highest profit), we use a binary search to find the smallest table that can accommodate the group. If such a table is found, we assign it to the group and remove the table from the available list.

### Solution Code
```python
import bisect

n = int(input())
requests = []
for i in range(n):
    ci, pi = map(int, input().split())
    requests.append((ci, pi, i + 1))

# Sort requests by descending pi, then ascending ci, then original index
requests.sort(key=lambda x: (-x[1], x[0], x[2]))

k = int(input())
tables = list(map(int, input().split()))
tables = [(t, i + 1) for i, t in enumerate(tables)]
tables.sort(key=lambda x: (x[0], x[1]))  # Sort by capacity, then original index

available_tables = tables.copy()

accepted = []
total_money = 0

for req in requests:
    ci, pi, req_idx = req
    # Find the first table that can accommodate ci people
    index = bisect.bisect_left(available_tables, (ci, 0))
    if index < len(available_tables):
        # Assign this table
        table = available_tables.pop(index)
        total_money += pi
        accepted.append((req_idx, table[1]))

# Output the results
print(len(accepted), total_money)
for pair in accepted:
    print(pair[0], pair[1])
```

3. **Greedy Assignment with Binary Search**: For each request, we use binary search to quickly find the smallest table that can accommodate the group. This ensures we use the smallest possible table, preserving larger tables for other potential groups.
