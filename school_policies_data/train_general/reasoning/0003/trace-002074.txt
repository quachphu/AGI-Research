To solve this problem, we need to distribute integers among friends in such a way that the sum of their happiness is maximized. Each friend's happiness is defined as the sum of the maximum and minimum integers they receive. The approach involves strategic sorting and allocation of integers to achieve the optimal result.

### Approach
1. **Sort the Array**: First, sort the array of integers in ascending order to facilitate efficient allocation of maximum and minimum values.
2. **Group Friends by Requirements**: Separate friends into two groups based on how many integers they receive. Friends who receive exactly 1 integer (Group 1) and those who receive more than 1 integer (Group 2).
3. **Allocate Maximum Values**: The largest integers from the sorted array are allocated as the maximum values for each friend. Friends in Group 1 receive the largest integers first as they contribute twice their single integer value.
4. **Allocate Minimum Values for Group 2**: For friends in Group 2, the smallest integers are allocated to form the minimum values. These are taken from the remaining integers after allocating the maximum values. The allocation is done in a way that maximizes the sum of these minimum values.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    for _ in range(t):
        n, k = int(data[idx]), int(data[idx + 1])
        idx += 2
        a = list(map(int, data[idx:idx + n]))
        idx += n
        w = list(map(int, data[idx:idx + k]))
        idx += k
        
        a.sort()
        
        group1 = []
        group2 = []
        for num in w:
            if num == 1:
                group1.append(num)
            else:
                group2.append(num - 1)  # storing x = w_i -1
        
        cnt1 = len(group1)
        maxes = a[-k:]
        maxes_sorted = sorted(maxes, reverse=True)
        
        sum_group1 = 2 * sum(maxes_sorted[:cnt1])
        
        len_group2 = len(group2)
        sum_max_group2 = sum(maxes_sorted[cnt1:cnt1 + len_group2]) if len_group2 else 0
        
        group2_x = group2
        group2_x.sort(reverse=True)
        sum_min = 0
        current_pos = 0
        min_candidates = a[:n - k]
        for x in group2_x:
            if x > 0:
                sum_min += min_candidates[current_pos]
                current_pos += x
        
        total = sum_group1 + sum_max_group2 + sum_min
        print(total)

if __name__ == "__main__":
    main()
```

1. **Sorting**: The array is sorted in ascending order to easily access the smallest and largest elements.
2. **Grouping Friends**: Friends are divided into two groups based on the number of integers they need. This helps in efficiently allocating the maximum values to those who need only one integer first.
3. **Maximizing Contributions**: By allocating the largest integers to friends who need only one integer, we ensure their contribution is doubled. For friends needing more integers, we allocate the smallest possible values to form their minimum values, ensuring the remaining integers are used optimally to maximize the sum of these minima.
4. **Efficient Allocation**: The approach ensures that the largest values are used where they contribute the most, and the smallest values are strategically allocated to maximize the sum of minima for friends needing multiple integers.

This method efficiently balances the allocation of maximum and minimum values to achieve the highest possible sum of happiness for all friends.
