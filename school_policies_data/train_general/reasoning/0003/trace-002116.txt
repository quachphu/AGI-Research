To solve this problem, we need to find the sum of the weights of the edges in the Minimum Spanning Tree (MST) of a given weighted undirected graph. The MST is a subset of edges that connects all vertices with the minimum possible total edge weight and without any cycles.

### Approach
The optimal approach to solve this problem is Kruskal's algorithm, which efficiently finds the MST using a union-find data structure (also known as Disjoint Set Union, DSU). Here's a step-by-step breakdown of the approach:

1. **Sort Edges by Weight**: First, we sort all the edges of the graph in non-decreasing order of their weights. This allows us to consider the smallest edges first, which is a greedy strategy to ensure we pick the smallest possible weights for the MST.

2. **Union-Find Data Structure**: We use the union-find data structure to keep track of connected components. This helps in efficiently determining whether adding an edge will form a cycle. The union-find structure supports two main operations:
   - **Find**: Determine which component a particular vertex belongs to.
   - **Union**: Merge two components into a single component.

3. **Construct MST**: Iterate through the sorted edges and add each edge to the MST if it connects two different components. Continue this process until we have added exactly \(|V| - 1\) edges, which is the number of edges required to form an MST for a graph with \(|V|\) vertices.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    V = int(input[ptr])
    ptr += 1
    E = int(input[ptr])
    ptr += 1
    
    edges = []
    for _ in range(E):
        s = int(input[ptr])
        t = int(input[ptr+1])
        w = int(input[ptr+2])
        edges.append((w, s, t))
        ptr += 3
    
    edges.sort()
    
    parent = list(range(V))
    size = [1] * V
    
    def find(u):
        while parent[u] != u:
            parent[u] = parent[parent[u]]
            u = parent[u]
        return u
    
    sum_weights = 0
    count = 0
    
    for w, u, v in edges:
        root_u = find(u)
        root_v = find(v)
        if root_u != root_v:
            sum_weights += w
            count += 1
            if count == V - 1:
                break
            if size[root_u] < size[root_v]:
                parent[root_u] = root_v
                size[root_v] += size[root_u]
            else:
                parent[root_v] = root_u
                size[root_u] += size[root_v]
    
    print(sum_weights)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into vertices and edges. Each edge is stored along with its weight.
2. **Sorting Edges**: The edges are sorted by their weights to facilitate the greedy selection of the smallest edges first.
3. **Union-Find Initialization**: Each vertex is initially its own parent, and each component has a size of 1.
4. **Processing Edges**: For each edge in the sorted list, we check if the vertices belong to different components using the `find` operation. If they do, we unite them using the `union` operation and add the edge's weight to the MST sum. This continues until we have formed a spanning tree with \(|V| - 1\) edges.
5. **Output the Result**: The sum of the weights of the edges in the MST is printed.

This approach ensures that we efficiently construct the MST with a time complexity of \(O(E \log E)\) due to sorting the edges, and the union-find operations are nearly constant time due to path compression and union by size. This makes the solution both optimal and efficient for large graphs.
