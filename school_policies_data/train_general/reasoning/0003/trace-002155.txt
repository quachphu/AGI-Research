To solve this problem, we need to determine the sum of the segments lit up by each digit of a given number on a seven-segment digital display. The solution involves mapping each digit to its corresponding segment count and summing these counts for each digit in the input number.

### Approach
1. **Understanding the Seven-Segment Display**: Each digit (0-9) lights up a specific number of segments on a digital display. For example, the digit '0' uses 6 segments, while '1' uses 2 segments.
2. **Mapping Digits to Segments**: Create a dictionary where each key is a digit (as a string) and the value is the number of segments it uses.
3. **Reading Input**: Read the input values, including the number of test cases and each subsequent number.
4. **Processing Each Number**: For each number, ignore any negative sign and sum the segments for each digit using the pre-defined mapping.
5. **Output the Result**: Print the sum for each test case.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    digit_map = {
        '0': 6, '1': 2, '2': 5, '3': 5, '4': 4,
        '5': 5, '6': 6, '7': 3, '8': 7, '9': 6
    }
    for i in range(1, T + 1):
        num_str = input[i].strip()
        total = 0
        for c in num_str:
            if c != '-':
                total += digit_map[c]
        print(total)

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings for easier processing. The first element is the number of test cases, `T`.
2. **Digit Mapping**: A dictionary `digit_map` is created to map each digit to its corresponding number of segments.
3. **Processing Each Test Case**: For each number, convert it to a string and iterate over each character. If the character is a negative sign, it is skipped. For each digit, the corresponding segment count is added to the total.
4. **Output**: The total segment count for each number is printed.

This approach efficiently processes each digit of the input numbers, ensuring that even very large numbers (up to 1000 digits) are handled correctly by treating them as strings. The solution is optimized for performance, handling up to 1000 test cases efficiently.
