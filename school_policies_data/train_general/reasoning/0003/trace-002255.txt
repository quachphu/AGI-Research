To solve this problem, we need to determine if Sereja can order exactly the required number of pizzas each day using only two types of discounts: buying two pizzas on the same day (double discount) or using a coupon that covers two consecutive days. The solution must ensure that no extra pizzas are ordered and no coupons remain active after the last day.

### Approach
1. **Track Coupons**: Keep track of the number of coupons that are active from the previous day.
2. **Daily Calculation**: For each day, calculate the remaining pizzas needed after accounting for active coupons from the previous day.
3. **Check Validity**: Ensure the remaining pizzas for each day can be covered using either coupons for the next day or double discounts. The number of coupons used must be valid for the next day's requirements.
4. **Parity Check**: Ensure the remaining pizzas after using coupons have an even number so they can be covered by double discounts.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
prev_coupons = 0
possible = True

for i in range(n):
    current = a[i]
    R = current - prev_coupons
    if R < 0:
        possible = False
        break
    if i == n - 1:
        if R % 2 != 0:
            possible = False
        prev_coupons = 0  # Ensure no coupons after last day
    else:
        next_a = a[i + 1]
        max_k = min(R, next_a)
        if max_k < 0:
            possible = False
            break
        # Determine the parity
        R_parity = R % 2
        max_k_parity = max_k % 2
        if R_parity == max_k_parity:
            k = max_k
        else:
            if max_k >= 1:
                k = max_k - 1
            else:
                possible = False
                break
        # Check if k is valid
        if k < 0 or k > R or (R - k) % 2 != 0:
            possible = False
            break
        # Update prev_coupons for next iteration
        prev_coupons = k

print("YES" if possible else "NO")
```

### Explanation
1. **Initialization**: Read the number of days and the list of teams present each day.
2. **Loop Through Days**: For each day, calculate the remaining pizzas needed after accounting for coupons from the previous day.
3. **Check Last Day**: If it's the last day, ensure the remaining pizzas can be covered by double discounts (even number).
4. **Coupon Calculation**: For non-last days, calculate the maximum possible coupons that can be used without exceeding the next day's team count and ensuring parity matches for valid double discounts.
5. **Update State**: Adjust the number of active coupons for the next day based on valid calculations.

This approach ensures that we efficiently check each day's requirements while maintaining valid coupon usage, leading to an optimal solution.
