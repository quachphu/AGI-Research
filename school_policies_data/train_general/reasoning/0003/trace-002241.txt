To solve this problem, we need to process a given string by removing all vowels, inserting a dot before each consonant, and converting all consonants to lowercase. Let's break down the approach and solution step by step.

### Approach
1. **Identify Vowels**: The vowels are defined as 'a', 'o', 'y', 'e', 'u', 'i' (case-insensitive).
2. **Iterate Through Each Character**: For each character in the input string, check if it is a vowel.
3. **Process Consonants**: If the character is not a vowel, convert it to lowercase, prepend a dot, and add it to the result list.
4. **Construct Result String**: Combine all processed consonants into a single string and print it.

### Solution Code
```python
def main():
    s = input().strip()
    vowels = {'a', 'o', 'y', 'e', 'u', 'i'}
    result = []
    for char in s:
        lower_char = char.lower()
        if lower_char not in vowels:
            result.append('.' + lower_char)
    print(''.join(result))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input string is read from standard input.
2. **Vowel Set**: A set of vowels is created for quick lookup.
3. **Processing Each Character**: Each character is converted to lowercase. If it is not a vowel, a dot is prepended, and the lowercase character is added to the result list.
4. **Generating Output**: The processed consonants are joined into a single string and printed.

This approach efficiently processes each character in linear time, ensuring that the solution is optimal and meets the problem constraints. The use of a set for vowels allows for constant-time lookups, making the solution both time and space efficient.
