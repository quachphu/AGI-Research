2. **Constructing the Permutation**:
   - **Even `n` (mod 4 = 0)**: Divide the permutation into groups of four elements and arrange them in a specific cycle to satisfy the given condition.
   - **Odd `n` (mod 4 = 1)**: Fix the middle element and handle the remaining elements similarly to the even case but adjusted to account for the fixed middle element.

import sys

def solve():
    n = int(sys.stdin.readline())
    if n % 4 not in (0, 1):
        print(-1)
        return
    p = [0] * n
    if n % 2 == 0:
        k = n // 4
        for j in range(1, k + 1):
            a = 2 * j - 1
            b = 2 * j
            c = n - a + 1
            d = n - b + 1
            p[a - 1] = b
            p[b - 1] = c
            p[c - 1] = d
            p[d - 1] = a
    else:
        m = (n + 1) // 2
        p[m - 1] = m
        k = (n - 1) // 4
        for j in range(1, k + 1):
            a = 2 * j - 1
            b = 2 * j
            c = n - a + 1
            d = n - b + 1
            p[a - 1] = b
            p[b - 1] = c
            p[c - 1] = d
            p[d - 1] = a
    if 0 in p:
