To solve this problem, we need to determine the number of excessive electric shocks Valentin receives after the selected letter can be uniquely identified but before he correctly guesses it. The solution involves tracking the possible letters through Valentin's actions and identifying the point when the selected letter becomes uniquely determined.

### Approach
1. **Initialization**: Start with all 26 lowercase letters as potential candidates for the selected letter.
2. **Processing Actions**: For each action (excluding the last correct guess):
   - **Type '! w'**: The selected letter must be in the word `w`. Update the possible letters by intersecting with the characters in `w`.
   - **Type '. w'**: The selected letter must not be in the word `w`. Update the possible letters by removing the characters in `w`.
   - **Type '? s'**: The selected letter is not `s` (since all guesses before the last are incorrect). Remove `s` from the possible letters.
3. **Determine the Unique Letter**: Track the first moment when the possible letters are reduced to exactly one.
4. **Count Excessive Shocks**: After the unique letter is determined, count all subsequent actions of type '!' or '?' as excessive shocks.

### Solution Code
```python
import string

n = int(input())
actions = [input().strip() for _ in range(n)]

possible = set(string.ascii_lowercase)
determined_time = -1

for i in range(n - 1):
    action = actions[i]
    typ, rest = action.split(' ', 1)
    if typ == '!':
        word = rest
        possible &= set(word)
    elif typ == '.':
        word = rest
        possible -= set(word)
    elif typ == '?':
        s = rest
        possible.discard(s)
    # Check if possible letters are determined now
    if len(possible) == 1 and determined_time == -1:
        determined_time = i

excessive_shocks = 0
if determined_time != -1:
    # Count all '!' and '?' actions after determined_time
    for i in range(determined_time + 1, n - 1):
        action = actions[i]
        if action[0] in ('!', '?'):
            excessive_shocks += 1

print(excessive_shocks)
```

### Explanation
- **Initialization**: We start with all lowercase letters as possible candidates for the selected letter.
- **Processing Actions**: Each action updates the set of possible letters based on the type of action. For example, if Valentin gets a shock ('!'), the selected letter must be in the word, so we intersect the possible letters with the characters in the word. If he doesn't get a shock ('.'), the selected letter is not in the word, so we remove those characters.
- **Determine Unique Letter**: We track the first index where the possible letters are reduced to one. This is when the selected letter can be uniquely determined.
- **Count Excessive Shocks**: After the selected letter is determined, any subsequent actions that result in shocks (either '!' or '?') are counted as excessive.

This approach efficiently narrows down the possible letters and counts the excessive shocks, ensuring optimal performance even for large inputs.
