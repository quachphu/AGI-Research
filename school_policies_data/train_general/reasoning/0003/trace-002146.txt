To solve this problem, we need to determine which column of soldiers, if any, should switch their starting leg to maximize the beauty of the parade. The beauty is defined as the absolute difference between the total number of soldiers starting with the left leg and the right leg. We can flip at most one column to achieve the maximum beauty.

### Approach
1. **Calculate Initial Values**: Compute the total number of soldiers starting with the left leg (L) and the right leg (R). The initial beauty is the absolute difference between L and R.
2. **Evaluate Each Column**: For each column, determine the effect of flipping it. This involves calculating the new difference and the resulting beauty if that column is flipped.
3. **Determine the Optimal Flip**: Track the maximum beauty achievable by flipping any column. If flipping a column results in a higher beauty than the initial, select the first such column. If no flip improves the beauty, the result is 0.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    columns = []
    for _ in range(n):
        li, ri = map(int, sys.stdin.readline().split())
        columns.append((li, ri))
    
    L = sum(li for li, ri in columns)
    R = sum(ri for li, ri in columns)
    D = L - R
    initial_beauty = abs(D)
    max_new = initial_beauty
    best_col = 0
    
    for idx in range(n):
        li, ri = columns[idx]
        delta = 2 * (ri - li)
        new_diff = D + delta
        new_beauty = abs(new_diff)
        if new_beauty > max_new:
            max_new = new_beauty
            best_col = idx + 1
    
    print(best_col if max_new > initial_beauty else 0)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin` for efficiency, especially given the constraints of up to 100,000 columns.
2. **Initial Calculations**: Sum the total soldiers starting with each leg to compute the initial difference (D) and initial beauty.
3. **Evaluate Each Column**: For each column, compute the potential new difference if the column is flipped. This is done by adjusting the initial difference by twice the difference of the column's right and left counts.
4. **Track Maximum Beauty**: Keep track of the highest beauty achievable by flipping any column and the index of the column that achieves this. If the highest achievable beauty is greater than the initial, print the column index; otherwise, print 0.

This approach ensures we efficiently compute the optimal solution in linear time, O(n), making it suitable for large input sizes.
