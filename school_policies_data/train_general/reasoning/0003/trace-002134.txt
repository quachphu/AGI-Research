1. **Special Case Handling**: If the two numbers are already equal, the excitement can be made infinitely large by incrementing both numbers indefinitely. Hence, the output for such cases is `0 0`.
2. **Difference Calculation**: For non-equal numbers, compute the absolute difference `d` between the two numbers. The maximum possible GCD after any number of operations will be a divisor of `d`.
3. **Congruence Class Calculation**: For the given difference `d`, determine the minimal number of moves required to make one of the numbers a multiple of `d` while ensuring both numbers remain non-negative. This involves finding the minimal value in a specific congruence class that meets the non-negativity constraints.

### Solution Code
```python
def compute_x(c, d, L):
    x = c
    if x < L:
        k = (L - c + d - 1) // d
        x = c + k * d
    candidate = x - d
    if candidate >= L and abs(candidate) < abs(x):
        return candidate
    else:
        return x

t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    if a == b:
        print("0 0")
    else:
        d = abs(a - b)
        L = max(-a, -b)
        c = (-b) % d
        x = compute_x(c, d, L)
        print(d, abs(x))
```

### Explanation
1. **Special Case Handling**: If `a` equals `b`, the result is `0 0` because we can infinitely increase both numbers, leading to an infinite GCD.
2. **Difference Calculation**: Compute `d` as the absolute difference between `a` and `b`. This `d` is the upper bound for the possible GCD value.
3. **Congruence Class Calculation**: Determine the smallest non-negative value `x` such that `(b + x)` is a multiple of `d` and both `a + x` and `b + x` are non-negative. This value `x` is found using modular arithmetic and ensures minimal moves.

This approach efficiently computes the required values using modular arithmetic and ensures optimal performance even for large input values.
