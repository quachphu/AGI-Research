To solve this problem, we need to determine the minimum possible time \( T \) such that BooBoo can solve all \( N \) problems in exactly \( M \) days, with each day's total time not exceeding \( T \). This problem can be efficiently solved using a binary search approach on the possible values of \( T \).

### Approach
1. **Problem Analysis**: The key insight is that the minimum time \( T \) must be at least the maximum time required for any single problem (since each problem must be completed in one day) and at most the sum of all problem times (if all problems were solved in a single day). 

2. **Binary Search**: We perform a binary search on the possible values of \( T \). For each candidate value of \( T \) during the binary search, we check if it is feasible to split the problems into \( M \) days such that each day's total time does not exceed \( T \).

3. **Feasibility Check**: For each candidate \( T \), we simulate the process of solving problems day by day. We keep track of the current day's total time and increment the day count whenever adding the next problem would exceed \( T \). If the total days required exceed \( M \), the candidate \( T \) is not feasible.

### Solution Code
```python
import sys

def main():
    n, m = map(int, sys.stdin.readline().split())
    q = list(map(int, sys.stdin.readline().split()))
    
    low = max(q)
    high = sum(q)
    
    while low < high:
        mid = (low + high) // 2
        current_sum = 0
        days = 1
        possible = True
        
        for time in q:
            if current_sum + time > mid:
                days += 1
                current_sum = time
                if days > m:
                    possible = False
                    break
            else:
                current_sum += time
        
        if possible:
            high = mid
        else:
            low = mid + 1
    
    print(low)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input values are read from standard input, including the number of problems \( N \), the number of days \( M \), and the list of times required for each problem.

2. **Initial Bounds**: The initial bounds for the binary search are set such that the lower bound (`low`) is the maximum time required for any single problem, and the upper bound (`high`) is the sum of all problem times.

3. **Binary Search Loop**: The binary search iterates to narrow down the possible values of \( T \). For each midpoint value (`mid`), we check if it is feasible to split the problems into \( M \) days without exceeding `mid` time per day.

4. **Feasibility Check**: For each midpoint value, we simulate the process of solving problems day by day. If the total days required exceed \( M \), the midpoint value is adjusted upwards; otherwise, it is adjusted downwards.

5. **Result**: The loop continues until the bounds converge, at which point the minimum feasible \( T \) is found and printed.

This approach efficiently narrows down the possible values of \( T \) using binary search, ensuring an optimal solution with a time complexity of \( O(N \log S) \), where \( S \) is the sum of all problem times. This is efficient and feasible even for large input sizes.
