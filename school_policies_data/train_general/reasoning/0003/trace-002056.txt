To solve this problem, we need to determine the minimum number of power strips required to extend Takahashi's single socket into at least B sockets using power strips each with A sockets. Each power strip converts one existing socket into A new sockets.

### Approach
1. **Problem Analysis**: Each power strip converts one existing socket into A new sockets. This means each power strip effectively adds (A - 1) new sockets. Starting with 1 socket, we need to find the minimum number of power strips (n) such that the total number of sockets is at least B.
2. **Mathematical Insight**: The total number of sockets after adding n power strips can be modeled as \( n \times (A - 1) + 1 \). We need this value to be at least B. Rearranging this inequality gives us \( n \geq \frac{B - 1}{A - 1} \). Since n must be an integer, we use ceiling division to ensure we round up to the next whole number if there's any remainder.
3. **Efficient Calculation**: Using integer arithmetic, the ceiling of the division can be computed efficiently as \( \frac{(B - 1) + (A - 2)}{A - 1} \), which simplifies to \( \frac{B + A - 3}{A - 1} \).

### Solution Code
```python
A, B = map(int, input().split())
print((B + A - 3) // (A - 1))
```

### Explanation
1. **Reading Input**: The input values A and B are read from standard input.
2. **Formula Application**: The formula \((B + A - 3) // (A - 1)\) is used to compute the minimum number of power strips needed. This formula efficiently calculates the ceiling of the division without using floating-point arithmetic, ensuring correctness and efficiency.

This approach ensures that we find the minimum number of power strips required in constant time, making the solution both optimal and straightforward.
