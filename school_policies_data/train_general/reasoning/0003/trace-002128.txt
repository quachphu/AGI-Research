To solve this problem, we need to determine the minimum number of extra tiles Tokitsukaze needs to draw to form a valid mentsu (either a triplet or a sequence) from her current hand of three tiles. 

### Approach
1. **Check for Triplets (Koutsu)**: A triplet consists of three identical tiles. For each possible tile, calculate how many additional tiles are needed to form a triplet from the current hand.
2. **Check for Sequences (Shuntsu)**: A sequence consists of three consecutive numbers in the same suit. For each possible sequence in each suit, calculate how many additional tiles are needed to form the sequence from the current hand.
3. **Determine Minimum Tiles Needed**: The minimum number of additional tiles required will be the smaller value between the minimum tiles needed for any triplet and the minimum tiles needed for any sequence.

### Solution Code
```python
tiles = input().split()
from collections import defaultdict

count = defaultdict(int)
for tile in tiles:
    count[tile] += 1

# Calculate minimum required for triplets
all_tiles = [f"{num}{suit}" for suit in ['m', 'p', 's'] for num in range(1, 10)]
triplet_min = min((3 - count[tile]) for tile in all_tiles)

# Calculate minimum required for sequences
min_sequence = float('inf')
suits = ['m', 'p', 's']
for suit in suits:
    for start in range(1, 8):  # start can be from 1 to 7 inclusive
        required = 0
        for num in [start, start + 1, start + 2]:
            tile = f"{num}{suit}"
            required += max(0, 1 - count.get(tile, 0))
        if required < min_sequence:
            min_sequence = required

result = min(triplet_min, min_sequence)
print(result)
```

### Explanation
1. **Reading Input**: The input tiles are read and stored in a list. We use a dictionary to count the occurrences of each tile in the current hand.
2. **Triplet Calculation**: For each possible tile (27 possibilities), we compute how many more tiles are needed to form a triplet. The minimum of these values is stored as `triplet_min`.
3. **Sequence Calculation**: For each possible sequence in each suit (21 possibilities in total), we compute how many more tiles are needed to form the sequence. The minimum of these values is stored as `min_sequence`.
4. **Result**: The minimum value between `triplet_min` and `min_sequence` is the answer, representing the least number of additional tiles needed to form a valid mentsu.
