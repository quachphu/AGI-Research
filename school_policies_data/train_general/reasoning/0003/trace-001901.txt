### Approach
1. **Sort the Array**: Sorting helps in efficiently determining the number of valid pairs using binary search.
2. **Binary Search on Product Values**: We perform binary search on possible product values to find the K-th smallest product.
3. **Count Valid Pairs Efficiently**: For each midpoint in the binary search, we count how many pairs have a product less than or equal to the midpoint. This is done using the bisect module to handle different cases based on the signs of the elements.

import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    K = int(input[1])

    while left < right:
