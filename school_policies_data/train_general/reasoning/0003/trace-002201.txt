To solve this problem, we need to determine the minimal possible weight of a spanning tree that includes each given edge in an undirected weighted graph. The solution involves using Kruskal's algorithm to find the Minimum Spanning Tree (MST) and then leveraging binary lifting to efficiently compute the maximum edge weight on paths within the MST.

### Approach
1. **Kruskal's Algorithm for MST**: Construct the MST using Kruskal's algorithm, which processes edges in increasing order of weight. Track which edges are included in the MST.
2. **Binary Lifting for LCA and Maximum Edge**: Preprocess the MST using binary lifting to quickly find the maximum edge weight on the path between any two nodes. This helps in efficiently determining the maximum edge weight for paths in the MST.
3. **Query Processing**: For each edge not in the MST, compute the minimal spanning tree weight that includes the edge by adjusting the MST weight using the maximum edge weight on the path between the edge's endpoints in the MST.
