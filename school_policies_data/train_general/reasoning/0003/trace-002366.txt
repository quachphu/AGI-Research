To solve this problem, we need to find a strictly increasing sequence of k positive integers that sum to n and have the maximum possible greatest common divisor (GCD). If no such sequence exists, we should return -1.

### Approach
1. **Check Feasibility**: The minimal possible sum of a strictly increasing sequence of k integers is given by the sum of the first k natural numbers, which is \( \frac{k(k+1)}{2} \). If n is less than this sum, it's impossible to form such a sequence, so we return -1.
2. **Determine Maximum GCD**: To maximize the GCD of the sequence, we need to find the largest divisor of n such that the sum of the sequence elements divided by this divisor is at least the minimal sum. This involves checking all divisors of n up to \( \frac{n}{\text{min\_sum}} \).
3. **Construct the Sequence**: Once the maximum divisor (GCD) is found, construct the sequence by starting with the smallest possible strictly increasing sequence and adjusting the last element to ensure the sum matches \( \frac{n}{\text{GCD}} \).

### Solution Code
```python
import math

def find_sequence():
    import sys
    n, k = map(int, sys.stdin.readline().split())
    min_sum = k * (k + 1) // 2
    if n < min_sum:
        print(-1)
        return
    
    x = n // min_sum
    
    def largest_divisor(n_val, max_limit):
        max_div = 0
        sqrt_n = int(math.isqrt(n_val))
        for i in range(1, sqrt_n + 1):
            if n_val % i == 0:
                if i <= max_limit and i > max_div:
                    max_div = i
                j = n_val // i
                if j <= max_limit and j > max_div:
                    max_div = j
        return max_div
    
    g = largest_divisor(n, x)
    if g == 0:
        print(-1)
        return
    
    sum_a = n // g
    sum_first = (k - 1) * k // 2
    last = sum_a - sum_first
    sequence = list(range(1, k)) + [last]
    sequence = [num * g for num in sequence]
    print(' '.join(map(str, sequence)))

find_sequence()
```

### Explanation
1. **Feasibility Check**: We first check if the given n is large enough to form the minimal sequence. If not, we immediately return -1.
2. **Finding Maximum GCD**: The largest possible divisor of n that allows the sequence sum to be valid is found by checking all divisors up to the limit derived from the minimal sum.
3. **Constructing the Sequence**: The sequence starts with the smallest possible values (1, 2, ..., k-1) and adjusts the last element to ensure the sum matches the required value when multiplied by the GCD. This ensures the sequence is strictly increasing and the GCD is maximized.

This approach efficiently narrows down the possible divisors and constructs the optimal sequence, ensuring correctness and optimality within the problem constraints.
