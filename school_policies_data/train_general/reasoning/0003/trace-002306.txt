### Approach
1. **Precompute Minimum Remaining Characters**: For each position in the string s, compute the minimum character from that position to the end of the string. This helps in determining the smallest possible character that can be encountered in the remaining part of s.
2. **Use a Stack (t)**: As we iterate through each character of s, push each character onto the stack t. After each push, check if the top character of the stack can be moved to u to maintain the lexicographical order.
3. **Greedy Popping from Stack**: After pushing a character to t, check if the top character of t is the smallest possible character available (considering both the remaining characters in s and the stack t). If it is, pop it to u. This ensures that we always move the smallest possible character to u as early as possible.

    import sys
    s = sys.stdin.readline().strip()
    n = len(s)
    if n == 0:
        print('')
        return

    min_remaining = [None] * n
    min_remaining[-1] = s[-1]
    for i in range(n-2, -1, -1):
        min_remaining[i] = min(s[i], min_remaining[i+1])

    u = []
    
    for i in range(n):
        t.append(s[i])
        # Check if we can pop from t
        while t:

            if i + 1 < n:
                current_min = min_remaining[i+1]
