To solve this problem, we need to split a given string into words based on commas and semicolons as delimiters. We then classify these words into valid nonnegative integers (without leading zeros) and other words. Finally, we format the output to display these two categories of words as specified.

### Approach
1. **Splitting the String**: Use regular expressions to split the input string into words using commas and semicolons as delimiters.
2. **Classifying Words**: For each word, check if it is a valid nonnegative integer. A valid integer must:
   - Be non-empty.
   - Consist only of digits.
   - Not have leading zeros unless it is a single zero.
3. **Formatting Output**: Collect valid integers into one list and other words into another list. Format these lists into the required output strings, using quotes if there are elements and a dash if there are none.

### Solution Code
```python
import re

def process_string():
    s = input().strip()
    words = re.split('[,;]', s)
    a = []
    b = []
    for word in words:
        valid = False
        if word:
            if word.isdigit():
                if len(word) == 1 or word[0] != '0':
                    valid = True
        if valid:
            a.append(word)
        else:
            b.append(word)
    a_str = '"{}"'.format(','.join(a)) if a else '-'
    b_str = '"{}"'.format(','.join(b)) if b else '-'
    print(a_str)
    print(b_str)

process_string()
```

### Explanation
1. **Splitting the Input**: The input string is split using regular expressions to handle both commas and semicolons as delimiters. This results in a list of words, including empty strings if there are consecutive delimiters.
2. **Validation of Words**: Each word is checked to determine if it is a valid nonnegative integer. This involves checking if the word is non-empty, consists only of digits, and does not have leading zeros (unless it is a single zero).
3. **Output Formatting**: The valid integers and other words are collected into separate lists. These lists are then formatted into strings with quotes if they contain elements, or a dash if they are empty. The formatted strings are printed as the final result.

This approach efficiently processes the input string in linear time, ensuring it handles the maximum constraints effectively.
