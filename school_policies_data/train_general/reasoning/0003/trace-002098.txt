To solve this problem, we need to determine the minimum amount of money Champa would spend to visit all cities, given that the cost of traveling between two cities is determined by the quality of the trip and the difference in their heights. The key is to find the optimal path that minimizes the total travel cost.

### Approach
1. **Understanding the Cost Calculation**: The cost between two cities is calculated as \( Q \times |A - B| \), where \( Q \) is the quality of the trip and \( |A - B| \) is the absolute difference in their heights.
2. **Optimal Path**: The minimal total cost is achieved by visiting cities in an order that minimizes the sum of absolute differences between consecutive cities. This can be done by sorting the cities by their heights in either ascending or descending order. The sum of the absolute differences in this sorted order will be the difference between the maximum and minimum heights.
3. **Special Case Handling**: If there is only one city, the cost is zero since no travel is needed.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N, Q = map(int, input[idx:idx+2])
        idx += 2
        H = list(map(int, input[idx:idx+N]))
        idx += N
        max_h = max(H)
        min_h = min(H)
        print((max_h - min_h) * Q)

main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Processing Each Test Case**: For each test case, we read the number of cities \( N \) and the quality \( Q \). We then read the heights of the cities.
3. **Calculating Minimum Cost**: By finding the maximum and minimum heights of the cities, we determine the optimal path cost as the difference between these two values multiplied by \( Q \). This works because the optimal path will always be between the highest and lowest cities, with all intermediate cities contributing to the minimal sum of differences when sorted.

This approach ensures that we efficiently compute the minimal travel cost with a time complexity of \( O(N) \) per test case, which is optimal given the problem constraints.
