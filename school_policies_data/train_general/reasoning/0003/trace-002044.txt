To solve this problem, we need to determine if an array of integers is unimodal. An array is considered unimodal if it is strictly increasing at the beginning, followed by a constant section, and then strictly decreasing at the end. Any of these sections can be absent except for the requirement that the order must be maintained.

### Approach
1. **Initialization**: Start in the increasing phase.
2. **Transition Check**: For each consecutive pair of elements in the array, check the transition between them based on the current phase:
   - **Increasing Phase**: If the next element is greater, continue in the increasing phase. If the next element is equal, transition to the constant phase. If the next element is smaller, transition to the decreasing phase.
   - **Constant Phase**: If the next element is equal, continue in the constant phase. If the next element is smaller, transition to the decreasing phase. If the next element is larger, the array is not unimodal.
   - **Decreasing Phase**: If the next element is smaller, continue in the decreasing phase. If the next element is equal or larger, the array is not unimodal.
3. **Edge Cases**: Handle cases where the array has only one element, which is trivially unimodal.

### Solution Code
```python
n = int(input())
arr = list(map(int, input().split()))

if n == 1:
    print("YES")
else:
    state = "increasing"
    valid = True
    for i in range(n - 1):
        current = arr[i]
        next_val = arr[i + 1]
        if state == "increasing":
            if next_val > current:
                continue
            elif next_val == current:
                state = "constant"
            else:
                state = "decreasing"
        elif state == "constant":
            if next_val == current:
                continue
            elif next_val < current:
                state = "decreasing"
            else:
                valid = False
                break
        elif state == "decreasing":
            if next_val < current:
                continue
            else:
                valid = False
                break
    print("YES" if valid else "NO")
```

### Explanation
- **Initialization**: We start by reading the input values and checking if the array has only one element, which is immediately valid.
- **State Transitions**: We iterate through the array, checking each consecutive element pair. Depending on the current state (increasing, constant, or decreasing), we validate the transition to the next state.
- **Validity Check**: If any invalid transition is detected (e.g., increasing again after a decrease), we mark the array as invalid and break out of the loop early.
- **Output**: Finally, we print "YES" if the array is valid according to the unimodal conditions, otherwise "NO".

This approach ensures that we check each element in the array exactly once, resulting in an efficient O(n) time complexity.
