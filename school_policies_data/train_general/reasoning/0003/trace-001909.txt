To solve this problem, we need to find the k-th shortest path in a directed graph from a start node to a goal node. The solution must consider both the path length and the lexicographical order of the node sequences when determining the order of paths.

### Approach
1. **Graph Representation**: Represent the graph using an adjacency list where each node points to a list of tuples representing the edges (target node, distance).
2. **Priority Queue**: Use a priority queue (min-heap) to explore paths in order of increasing distance. If two paths have the same distance, the lexicographically smaller path is considered first.
3. **Path Tracking**: Track each path using a tuple of nodes visited so far and a bitmask to efficiently check visited nodes to avoid cycles.
4. **Edge Sorting**: For each node, sort its outgoing edges by the target node's identifier to ensure lexicographical order when expanding paths with the same distance.

### Solution Code
```python
import heapq

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    while True:
        n = int(input[ptr])
        m = int(input[ptr+1])
        k_val = int(input[ptr+2])
        a = int(input[ptr+3])
        b = int(input[ptr+4])
        ptr +=5
        if n == 0 and m == 0 and k_val == 0 and a == 0 and b == 0:
            break
        adj = [[] for _ in range(n+1)]  # 1-based indexing
        for _ in range(m):
            x = int(input[ptr])
            y = int(input[ptr+1])
            d = int(input[ptr+2])
            ptr +=3
            adj[x].append((y, d))
        # Sort adjacency lists by target node
        for x in range(n+1):
            adj[x].sort()
        # Initialize the priority queue
        heap = []
        initial_path = (a,)
        initial_dist = 0
        initial_mask = 1 << (a - 1)
        heapq.heappush(heap, (initial_dist, initial_path, initial_mask))
        count = 0
        found = None
        while heap:
            dist, path, mask = heapq.heappop(heap)
            current_node = path[-1]
            if current_node == b:
                count += 1
                if count == k_val:
                    found = path
                    break
                continue  # Skip further processing once we reach the target
            # Explore all outgoing edges sorted by target node
            for y, d in adj[current_node]:
                if not (mask & (1 << (y - 1))):
                    new_dist = dist + d
                    new_path = path + (y,)
                    new_mask = mask | (1 << (y - 1))
                    heapq.heappush(heap, (new_dist, new_path, new_mask))
        if found:
            print('-'.join(map(str, found)))
        else:
            print('None')

if __name__ == "__main__":
```
