To solve this problem, we need to determine if we can rearrange the characters of two given strings, s and t, such that the rearranged version of s (s') is lexicographically smaller than the rearranged version of t (t'). 

### Approach
The key insight is to find the lexicographically smallest possible rearrangement of s and the lexicographically largest possible rearrangement of t. If the smallest possible s' is still smaller than the largest possible t', then it is guaranteed that there exists some valid rearrangement where s' < t'. 

1. **Lexicographically Smallest s'**: This can be achieved by sorting the characters of s in ascending order.
2. **Lexicographically Largest t'**: This can be achieved by sorting the characters of t in descending order.

By comparing these two rearranged strings, we can determine if the condition s' < t' is possible.

### Solution Code
```python
s = input().strip()
t = input().strip()

s_sorted = ''.join(sorted(s))
t_sorted = ''.join(sorted(t, reverse=True))

print("Yes" if s_sorted < t_sorted else "No")
```

### Explanation
1. **Reading Input**: The input strings s and t are read from standard input.
2. **Sorting**: 
   - The string s is sorted in ascending order to form its lexicographically smallest permutation (s_sorted).
   - The string t is sorted in descending order to form its lexicographically largest permutation (t_sorted).
3. **Comparison**: The two sorted strings are compared. If s_sorted is lexicographically smaller than t_sorted, we print "Yes". Otherwise, we print "No".

This approach ensures that we efficiently check the necessary condition using sorting operations, which are computationally feasible given the problem constraints (string lengths up to 100 characters). The time complexity is dominated by the sorting operations, which are O(n log n) where n is the length of the strings, making the solution efficient and suitable for the given input size.
