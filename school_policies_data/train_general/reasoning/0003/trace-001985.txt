To solve this problem, we need to determine the number of groups formed by magnets arranged in a row. Each magnet can either be in a "plus-minus" ("01") or "minus-plus" ("10") configuration. The interaction between consecutive magnets determines whether they form a single group or separate groups.

### Approach
1. **Initialization**: Start by reading the number of magnets. If there are no magnets, the output is 0. Otherwise, initialize the group count to 1 since at least one magnet will form a group.
2. **Track Previous Magnet's Right Pole**: For each magnet (starting from the second), compare its left pole with the right pole of the previous magnet. If they are the same, the magnets repel, forming a new group. If they are different, they attract, staying in the same group.
3. **Iterate Through Magnets**: For each magnet after the first, update the previous right pole and check the interaction with the current magnet's left pole to determine if a new group is formed.

### Solution Code
```python
n = int(input())
if n == 0:
    print(0)
else:
    count = 1
    first = input().strip()
    prev_right = first[1]
    for _ in range(n-1):
        magnet = input().strip()
        current_left = magnet[0]
        if current_left == prev_right:
            count += 1
        prev_right = magnet[1]
    print(count)
```

### Explanation
1. **Reading Input**: The first input line is the number of magnets. If there are no magnets, we immediately output 0.
2. **First Magnet Handling**: The first magnet initializes the previous right pole, which is used to compare with subsequent magnets.
3. **Iterating Through Subsequent Magnets**: For each subsequent magnet, check if its left pole matches the previous magnet's right pole. If they match, a new group is formed, incrementing the count. Update the previous right pole to the current magnet's right pole for the next iteration.
4. **Output the Result**: After processing all magnets, the total count of groups is printed.

This approach efficiently processes each magnet in linear time, making it suitable for large input sizes up to 100,000 magnets.
