To solve this problem, we need to calculate the total score each player has earned after participating in three games. The score for each player in each game is determined by the uniqueness of the number they wrote. If a number is unique among all players in a game, the player gets that number as points; otherwise, they get zero points for that game.

### Approach
1. **Input Reading**: Read the number of players and their chosen numbers for each of the three games.
2. **Frequency Counting**: For each game, count how many times each number appears using a frequency counter.
3. **Score Calculation**: For each player, check the frequency of their chosen number in each game. If the number is unique (appears exactly once), add it to their total score.
4. **Output**: Print the total score for each player after processing all three games.

### Solution Code
```python
from collections import Counter

def calculate_scores():
    n = int(input())
    players = [list(map(int, input().split())) for _ in range(n)]
    
    game_counts = []
    for i in range(3):
        game_numbers = [player[i] for player in players]
        game_counts.append(Counter(game_numbers))
    
    for player in players:
        total = 0
        for i in range(3):
            num = player[i]
            if game_counts[i][num] == 1:
                total += num
        print(total)

calculate_scores()
```

### Explanation
1. **Reading Input**: The input is read and stored in a list of lists where each inner list represents the numbers chosen by a player in the three games.
2. **Frequency Counting**: For each game, we use the `Counter` from the `collections` module to count the occurrences of each number. This helps in quickly determining if a number is unique.
3. **Score Calculation**: For each player, we check each of their numbers across the three games. If the number they chose in a particular game is unique (counted exactly once), they earn points equal to that number for that game. Otherwise, they earn zero points for that game.
4. **Output**: After calculating the total score for each player, we print each player's total score sequentially.

This approach ensures that we efficiently determine the uniqueness of numbers in each game and compute the scores in an optimal manner. The use of frequency counters allows us to quickly look up the count of each number, making the solution both effective and efficient.
