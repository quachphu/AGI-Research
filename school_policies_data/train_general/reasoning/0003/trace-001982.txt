To solve this problem, we need to find a minimal by inclusion segment in an array such that the segment contains exactly `k` distinct elements. A segment is minimal by inclusion if there is no shorter sub-segment within it that also meets the requirement of having exactly `k` distinct elements.

### Approach
1. **Sliding Window Technique**: Use a sliding window approach to track the current window of elements in the array.
2. **Frequency Map**: Maintain a frequency map to count occurrences of each element within the current window.
3. **Distinct Count**: Track the number of distinct elements in the current window.
4. **Adjust Window**: Adjust the window size dynamically to ensure it contains exactly `k` distinct elements.
5. **Check Minimal Inclusion**: Once a valid window is found, check if the leftmost and rightmost elements of the window occur exactly once. If they do, the window is minimal by inclusion.

### Solution Code
```python
from collections import defaultdict

def find_minimal_segment():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    freq = defaultdict(int)
    left = 0
    distinct = 0
    result_found = False
    
    for right in range(n):
        current = a[right]
        if freq[current] == 0:
            distinct += 1
        freq[current] += 1
        
        # Move left to ensure distinct <= k
        while distinct > k:
            left_elem = a[left]
            freq[left_elem] -= 1
            if freq[left_elem] == 0:
                distinct -= 1
            left += 1
        
        # Check if current window has exactly k distinct elements
        if distinct == k:
            # Shrink left to find the minimal valid window
            while left <= right and freq[a[left]] > 1:
                left_elem = a[left]
                freq[left_elem] -= 1
                left += 1
            
            # Check if current window's ends are unique
            if freq[a[left]] == 1 and freq[a[right]] == 1:
                print(left + 1, right + 1)
                result_found = True
                break
    
    if not result_found:
        print(-1, -1)

find_minimal_segment()
```

3. **Adjusting Window Size**: If the number of distinct elements exceeds `k`, move the left pointer to reduce the window size until the distinct count is within the limit.
4. **Check Validity**: When a window with exactly `k` distinct elements is found, shrink the window from the left to find the minimal valid window where both the leftmost and rightmost elements occur exactly once.
