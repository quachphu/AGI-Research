To solve this problem, we need to determine the maximum number of dominoes that can be placed on the edges of a graph such that each vertex has all incoming domino halves with the same number of dots. Each domino can be used at most once, and the direction of each domino on an edge matters.

### Approach
1. **Problem Analysis**: The key constraint is that each vertex must have all incoming domino halves with the same number of dots. This means that each vertex can be assigned a number from 1 to 6, and the dominoes on the edges must be placed in such a way that the numbers on the halves facing the vertices match their assigned numbers.

2. **Generating Assignments**: We generate all possible assignments of numbers (1 to 6) to each vertex. For each assignment, we check the dominoes that would be formed on each edge.

3. **Counting Unique Dominoes**: For each assignment, we compute the dominoes formed by each edge (considering the minimum and maximum of the assigned numbers of the vertices connected by the edge). We count the number of unique dominoes formed, as each unique domino can be used once.

4. **Maximizing the Count**: The solution involves iterating over all possible assignments and keeping track of the maximum number of unique dominoes that can be formed.

### Solution Code
```python
import sys
from itertools import product

def main():
    n, m = map(int, sys.stdin.readline().split())
    edges = []
    for _ in range(m):
        u, v = map(int, sys.stdin.readline().split())
        edges.append((u-1, v-1))  # Convert to 0-based indices
    
    max_dominoes = 0
    # Generate all possible assignments of 1-6 for each of the n vertices
    for assignment in product(range(1, 7), repeat=n):
        domino_set = set()
        for u, v in edges:
            a = assignment[u]
            b = assignment[v]
            domino = (min(a, b), max(a, b))
            domino_set.add(domino)
        if len(domino_set) > max_dominoes:
            max_dominoes = len(domino_set)
    print(max_dominoes)

if __name__ == "__main__":
    main()
```

4. **Counting Unique Dominoes**: We use a set to collect these dominoes and count the number of unique dominoes.
