To solve this problem, we need to determine the number of good sequences of length `k` where each element divides the next one and the sequence is non-decreasing. The result should be computed modulo `1000000007`.

### Approach
The approach involves using dynamic programming (DP) to count the number of valid sequences efficiently. Here's a step-by-step breakdown of the solution:

1. **Dynamic Programming Table Initialization**: 
   - We use a 2D array `dp` where `dp[j][x]` represents the number of valid sequences of length `j` ending with the number `x`.

2. **Base Case**:
   - For sequences of length 1 (`j=1`), each number from 1 to `n` is a valid sequence by itself. Thus, `dp[1][x]` is initialized to 1 for all `x`.

3. **DP Transition**:
   - For each possible sequence length `j` from 1 to `k-1`, and for each number `x` from 1 to `n`, we generate all multiples of `x` (i.e., numbers `y` such that `y` is a multiple of `x` and `y >= x`). For each such `y`, we update `dp[j+1][y]` by adding the count of sequences ending at `x` for length `j`.

4. **Result Calculation**:
   - After processing all lengths up to `k`, the result is the sum of all valid sequences of length `k` ending at any number from 1 to `n`.

### Solution Code
```python
n, k = map(int, input().split())
MOD = 10**9 + 7

# Initialize DP table where dp[j][x] represents the number of sequences of length j ending with x
dp = [[0] * (n + 1) for _ in range(k + 1)]

# Base case: sequences of length 1
for x in range(1, n + 1):
    dp[1][x] = 1

# Fill the DP table for lengths from 2 to k
for j in range(1, k):
    for x in range(1, n + 1):
        if dp[j][x] == 0:
            continue
        # Iterate over all multiples of x that are >= x and <= n
        for y in range(x, n + 1, x):
            dp[j + 1][y] = (dp[j + 1][y] + dp[j][x]) % MOD

# Sum all possible sequences of length k
total = sum(dp[k][x] for x in range(1, n + 1)) % MOD
print(total)
```

### Explanation
- **Dynamic Programming Table**: The DP table `dp` is used to keep track of the number of valid sequences of each length ending with each possible number.
- **Base Case Handling**: For sequences of length 1, each number from 1 to `n` is a valid sequence, hence initialized to 1.
- **Transition Logic**: For each sequence length `j`, we iterate through each number `x` and generate all possible next numbers `y` (multiples of `x`). This ensures that each subsequent element in the sequence is both a multiple and greater than or equal to the previous element.
- **Efficiency**: The approach efficiently computes the number of valid sequences by leveraging the properties of multiples and dynamic programming, ensuring the solution is feasible even for the upper limits of the input constraints.

This method ensures that we efficiently count all valid sequences using dynamic programming, leading to an optimal solution within the given constraints.
