To solve this problem, we need to determine if wolves will attack sheep based on their respective counts. The problem states that if the number of wolves is greater than or equal to the number of sheep, the wolves will attack. Our task is to read the input values, compare the counts, and print the appropriate result.

### Approach
1. **Read Input**: The input consists of two integers, S (number of sheep) and W (number of wolves).
2. **Comparison**: Check if the number of wolves (W) is greater than or equal to the number of sheep (S).
3. **Output Result**: Print "unsafe" if wolves are greater than or equal to sheep; otherwise, print "safe".

### Solution Code
```python
def main():
    S, W = map(int, input().split())
    print("unsafe" if W >= S else "safe")

main()
```

### Explanation
1. **Reading Input**: The input is read from standard input using `input().split()`, which splits the input into two strings. These strings are then converted to integers using `map(int, ...)`.
2. **Condition Check**: The code checks if the number of wolves (W) is greater than or equal to the number of sheep (S). This is done using a simple conditional expression.
3. **Output**: Based on the result of the condition, either "unsafe" or "safe" is printed. The ternary operator `print("unsafe" if W >= S else "safe")` is used for concise and efficient decision-making.

This approach ensures that the solution is both efficient and straightforward, handling all edge cases within the given constraints.
