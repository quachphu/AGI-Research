To solve this problem, we need to generate all permutations of the set {1, 2, ..., n} in lexicographic order and print each permutation on a new line. 

### Approach
The approach leverages Python's `itertools.permutations` function, which efficiently generates permutations in lexicographic order when the input is sorted. The steps are as follows:
1. Read the integer `n` from standard input.
2. Generate all permutations of the list `[1, 2, ..., n]` using `itertools.permutations`.
3. Print each permutation in the required format, with elements separated by spaces.

### Solution Code
```python
import sys
import itertools

def generate_permutations():
    n = int(sys.stdin.readline())
    for perm in itertools.permutations(range(1, n + 1)):
        print(' '.join(map(str, perm)))

generate_permutations()
```

### Explanation
1. **Reading Input**: The integer `n` is read from standard input.
2. **Generating Permutations**: Using `itertools.permutations`, we generate all permutations of the list `[1, 2, ..., n]`. This function returns permutations in lexicographic order because the input list is sorted.
3. **Printing Permutations**: Each permutation (represented as a tuple) is converted to a string with elements separated by spaces and printed.

This approach efficiently handles the constraints (1 ≤ n ≤ 9) and ensures that permutations are generated and printed in the correct order. The use of the standard library function simplifies the implementation and ensures correctness.
