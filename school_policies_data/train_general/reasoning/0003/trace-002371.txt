### Approach
The problem of finding the number of ways to climb stairs where each step can be 1 or 2 steps is a classic dynamic programming problem that can be mapped to the Fibonacci sequence. Specifically, the number of ways to reach the Nth step is equivalent to the (N+1)th Fibonacci number. 

To handle large values of N efficiently (up to 1,000,000), we use the fast doubling method. This method allows us to compute Fibonacci numbers in O(log N) time, which is significantly faster than the traditional recursive or iterative approaches. This approach avoids the need for precomputing and storing large arrays, thus saving memory and computational resources.

import sys

def fib(n):
    a, b = 0, 1
    for bit in bin(n)[2:]:  # Process each bit in the binary representation of n
        c = a * (2 * b - a)
        d = a * a + b * b
        a, b = c, d
        if bit == '1':
            a, b = b, a + b
    return a

if __name__ == "__main__":
