To solve this problem, we need to efficiently manage a disjoint-set data structure (Union-Find) to handle union and find operations. The goal is to determine if two elements belong to the same set after a series of union operations.

### Approach
1. **Disjoint-Set Data Structure**: We use a parent array to track the parent of each element and a size array to keep track of the size of each set. This helps in optimizing both union and find operations.
2. **Path Compression**: During the find operation, we compress the path to the root, making future find operations faster.
3. **Union by Size**: When uniting two sets, the smaller set is attached to the larger set to keep the tree balanced, which ensures almost constant time complexity for each operation.

### Solution Code
```python
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    n = int(data[idx])
    idx += 1
    q = int(data[idx])
    idx += 1

    parent = list(range(n))
    size = [1] * n

    def find(u):
        root = u
        while parent[root] != root:
            root = parent[root]
        # Path compression
        while parent[u] != root:
            next_parent = parent[u]
            parent[u] = root
            u = next_parent
        return root

    for _ in range(q):
        com = data[idx]
        x = int(data[idx + 1])
        y = int(data[idx + 2])
        idx += 3

        if com == '0':
            x_root = find(x)
            y_root = find(y)
            if x_root != y_root:
                if size[x_root] < size[y_root]:
                    parent[x_root] = y_root
                    size[y_root] += size[x_root]
                else:
                    parent[y_root] = x_root
                    size[x_root] += size[y_root]
        else:
            x_root = find(x)
            y_root = find(y)
            print(1 if x_root == y_root else 0)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Initialization**: The parent array is initialized such that each element is its own parent. The size array is initialized to 1 for each element, indicating each element starts in its own set.
2. **Find Operation**: The find function uses path compression to ensure that each node points directly to the root of its set, flattening the structure for future operations.
3. **Union Operation**: The union operation merges two sets by attaching the smaller set to the root of the larger set, which helps maintain balance and efficiency.
4. **Handling Queries**: For each query, we either unite two sets or check if two elements belong to the same set, printing the result for the latter.

This approach ensures efficient handling of up to 100,000 operations on a disjoint-set of up to 10,000 elements, providing near-constant time complexity per operation due to path compression and union by size.
