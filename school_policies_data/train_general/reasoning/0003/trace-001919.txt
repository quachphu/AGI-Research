To solve this problem, we need to calculate the sum of numbers between two integers \( l \) and \( r \) (inclusive) such that each number contains at most \( k \) different digits. The result should be printed modulo 998244353. Given the constraints where \( l \) and \( r \) can be as large as \( 10^{18} \), a brute force approach is infeasible. Instead, we use a digit dynamic programming (DP) approach to efficiently compute the result.

### Approach
1. **Digit Dynamic Programming (Digit DP)**: This technique allows us to process numbers digit by digit, maintaining state information about the digits used so far, whether the number is still within bounds of the upper limit, and if leading zeros are present.
2. **State Tracking**: The state in our DP includes the current position in the digit string, a bitmask representing the digits used so far, a flag for leading zeros, and whether the current number is tight (i.e., matches the upper bound's prefix up to the current position).
3. **Sum Calculation**: For each valid state transition, we track both the count of valid numbers and their sum modulo 998244353. This allows us to efficiently compute the sum without explicitly generating all numbers.
4. **Precomputation**: We precompute powers of 10 modulo 998244353 to handle large numbers efficiently.
