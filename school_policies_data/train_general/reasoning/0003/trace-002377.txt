To solve this problem, we need to determine the weight of a string based on the ASCII values of its characters and then decide whether to reverse the string or not based on the computed weight. 

### Approach
1. **Calculate the Weight (W)**: Sum the ASCII values of each character in the string.
2. **Compute the Result (F)**: Divide the weight by the length of the string and take the floor value of the division.
3. **Determine Output**: If F is odd, reverse the string; if even, print the original string.

### Solution Code
```python
def process_strings():
    import sys
    T = int(sys.stdin.readline())
    for _ in range(T):
        s = sys.stdin.readline().strip()
        sum_ascii = sum(ord(c) for c in s)
        L = len(s)
        if L == 0:
            print('')
            continue
        F = sum_ascii // L
        if F % 2 == 1:
            print(s[::-1])
        else:
            print(s)

process_strings()
```

### Explanation
1. **Reading Input**: The number of test cases (T) is read first. For each test case, the string is read.
2. **Calculate ASCII Sum**: For each character in the string, convert it to its ASCII value using `ord()` and sum these values.
3. **Compute F**: The sum of ASCII values is divided by the string length using integer division to get F.
4. **Check Parity of F**: If F is odd, the string is reversed using slicing (`s[::-1]`), otherwise, the original string is printed.

This approach efficiently handles the problem constraints and ensures correctness by directly following the problem's requirements.
