To solve this problem, we need to determine the minimum cost of training troops such that they can destroy an opponent's base within a given time, considering the base's self-healing ability. The troops available are Barbarians, Archers, and Giants, each with different costs and damage rates. The goal is to find the optimal combination of these troops to minimize the training cost while ensuring the base is destroyed within the specified time.

### Approach
1. **Calculate Effective Hit Points**: The opponent's base heals itself every minute, so the effective hit points (H_effective) are the initial hit points plus the total healing over the given time.
2. **Determine Required Damage Per Second (DPS)**: Calculate the minimum DPS needed to destroy the base within the given time. This is derived by dividing the effective hit points by the total time in seconds and rounding up to ensure the damage is sufficient.
3. **Calculate DPS Deficit**: Subtract the base DPS provided by training only Barbarians from the required DPS to determine the deficit that needs to be covered by more powerful troops.
4. **Optimize Troop Combination**: Depending on the deficit:
   - If the deficit is non-positive, Barbarians alone are sufficient.
   - If the deficit is within the number of troops, use Archers to cover the deficit.
   - If the deficit exceeds the number of troops, use a combination of Archers and Giants to cover the deficit efficiently.

### Solution Code
```python
# Read input
n = int(input())
t = int(input())
h = int(input())

h_effective = h + n * 15 * t
total_time = t * 60
required_dps = (h_effective + total_time - 1) // total_time
delta = required_dps - n

if delta <= 0:
    cost = n * 100
elif delta <= n:
    cost = n * 100 + delta * 400
else:
    cost = 1000 * delta - 500 * n

print(cost)
```

### Explanation
1. **Effective Hit Points Calculation**: The base's effective hit points (H_effective) are computed by adding the initial hit points (H) to the total healing done over T minutes, which is N*15*T.
2. **Required DPS Calculation**: The required DPS is derived by dividing the effective hit points by the total attack time in seconds and rounding up to ensure the damage is sufficient.
3. **DPS Deficit Handling**: 
   - If the deficit (delta) is non-positive, using only Barbarians (the cheapest troop) is optimal.
   - If the deficit is within the number of troops (N), covering the deficit with Archers (next cheapest) is optimal.
   - If the deficit exceeds the number of troops, a combination of Archers and Giants is used, with Giants providing higher damage at a higher cost but optimized to minimize overall cost.

This approach ensures that we use the most cost-effective troops to cover the required damage, minimizing the total training cost while meeting the time constraint.
