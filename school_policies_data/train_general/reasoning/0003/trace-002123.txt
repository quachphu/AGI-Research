To solve this problem, we need to efficiently determine the number of occurrences of a string `t` within specified substrings of another string `s` for multiple queries. Given the constraints, a direct approach for each query would be too slow, so we use preprocessing and binary search to optimize the solution.

### Approach
1. **Preprocessing**: Identify all starting positions in `s` where `t` occurs. This is done once and stored in a list.
2. **Binary Search for Queries**: For each query, convert the problem into a range query on the precomputed list of starting positions using binary search to quickly count valid positions.

### Solution Code
```python
import bisect

n, m, q = map(int, input().split())
s = input().strip()
t = input().strip()

matches = []

if m <= n and m != 0:
    for i in range(n - m + 1):
        if s[i:i+m] == t:
            matches.append(i + 1)  # Convert to 1-based index

for _ in range(q):
    l, r = map(int, input().split())
    if m > n:
        print(0)
        continue
    adjusted_r = r - m + 1
    if adjusted_r < l:
        print(0)
    else:
        left_pos = bisect.bisect_left(matches, l)
        right_pos = bisect.bisect_right(matches, adjusted_r)
        print(right_pos - left_pos)
```

### Explanation
1. **Preprocessing**:
   - We iterate through each possible starting position in `s` where `t` could fit. For each position, we check if the substring matches `t` and store the 1-based index of valid starting positions in `matches`.

2. **Query Handling**:
   - For each query, determine the valid range of starting positions for `t` within the query's substring. This range is adjusted to account for the length of `t`.
   - Use binary search (via `bisect` module) to efficiently count how many precomputed starting positions fall within the adjusted range. This allows each query to be answered in logarithmic time relative to the number of precomputed positions.

This approach ensures that preprocessing is done in O(n * m) time, and each query is handled in O(log k) time, where k is the number of valid starting positions. This efficiency makes the solution feasible even for the upper constraint limits.
