To solve this problem, we need to generate a snake pattern in an n x m grid where the snake alternates between filling entire rows and connecting rows with a single '#'. The snake starts at the top-left corner and alternates direction each time it fills a full row, creating a zig-zag pattern.

### Approach
1. **Grid Initialization**: Create an n x m grid filled with '.' characters.
2. **Full Rows**: Fill every other row starting from the first row (0-based index) with '#' characters. These rows are referred to as "full rows".
3. **Connecting Rows**: The rows between the full rows (even rows in 1-based index) will have a single '#' either at the end or the start of the row, depending on the direction of the previous full row.
4. **Direction Alternation**: Alternate the direction of filling the full rows between left-to-right and right-to-left. This direction determines where the single '#' in the connecting row will be placed.

### Solution Code
```python
n, m = map(int, input().split())

grid = [['.' for _ in range(m)] for _ in range(n)]

current_row = 0
direction = 1  # 1 for left-right (end at m-1), -1 for right-left (end at 0)

while current_row < n:
    # Fill the entire current row with '#'
    for col in range(m):
        grid[current_row][col] = '#'
    
    # Check if there's an even row (current_row + 1) to place the connecting '#'
    if current_row + 1 < n:
        col = m - 1 if direction == 1 else 0
        grid[current_row + 1][col] = '#'
    
    # Toggle direction and move to the next full row
    direction *= -1
    current_row += 2

# Print the result
for row in grid:
    print(''.join(row))
```

### Explanation
1. **Grid Initialization**: The grid is initialized with all cells set to '.'.
2. **Filling Full Rows**: Starting from the first row (0-based index), every other row is filled entirely with '#'. This is done in a loop where `current_row` is incremented by 2 each time to skip the connecting rows.
3. **Connecting Rows**: After filling a full row, the next row (if it exists) is updated to have a single '#' at the end if the direction is left-to-right (column `m-1`) or at the start if the direction is right-to-left (column `0`).
4. **Direction Toggling**: The direction alternates between left-to-right and right-to-left each time a full row is processed. This is managed by toggling the `direction` variable between 1 and -1.

This approach efficiently constructs the snake pattern by focusing on filling full rows and placing single '#' characters in the connecting rows based on the alternating direction, ensuring the correct zig-zag path of the snake.
