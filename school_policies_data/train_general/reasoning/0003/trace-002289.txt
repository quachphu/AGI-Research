To solve this problem, we need to read multiple test cases from the standard input, compute the sum of two integers for each test case, and print the results efficiently. Given the constraints, we aim to handle up to 10,000 test cases efficiently.

### Approach
1. **Reading Input Efficiently**: Instead of reading each line of input individually, we read all input at once using `sys.stdin.read()`, which is more efficient for large inputs. This approach splits the input into a list of integers.
2. **Processing Test Cases**: The first integer in the input is the number of test cases, `t`. The subsequent integers are pairs of values `a` and `b` for each test case. We process these pairs sequentially.
3. **Computing and Printing Results**: For each pair of integers, compute their sum and print the result immediately. This avoids storing results in memory and outputs them as they are computed.

### Solution Code
```python
import sys

def main():
    data = list(map(int, sys.stdin.read().split()))
    t = data[0]
    idx = 1
    for _ in range(t):
        a = data[idx]
        b = data[idx + 1]
        print(a + b)
        idx += 2

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of integers. This allows efficient processing without the overhead of repeated I/O operations.
2. **Processing the Number of Test Cases**: The first value in the list is the number of test cases, `t`.
3. **Iterating Through Test Cases**: Using a loop, we process each test case by accessing pairs of integers from the list. The index is incremented by 2 for each test case to move to the next pair of integers.
4. **Computing and Outputting Results**: For each pair of integers, their sum is computed and printed immediately. This ensures that memory usage remains constant, regardless of the number of test cases.

This approach efficiently handles the input size constraints and ensures optimal performance for up to 10,000 test cases.
