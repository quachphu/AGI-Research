To solve this problem, we need to determine the fourth district in the Berland capital where a robbery will occur, such that the four districts form the vertices of a rectangle aligned with the map's edges. The solution involves identifying the missing coordinates based on the given three districts marked with asterisks.

### Approach
1. **Input Reading**: Read the dimensions of the map and the map itself.
2. **Identify Points**: Collect the coordinates of the three given robbery districts marked with asterisks.
3. **Determine Missing Coordinates**:
   - For the rows (x-coordinates) of the three points, find the row that appears exactly once. This row will be the x-coordinate of the fourth point.
   - Similarly, for the columns (y-coordinates) of the three points, find the column that appears exactly once. This column will be the y-coordinate of the fourth point.

### Solution Code
```python
def find_fourth_point():
    import sys
    n, m = map(int, sys.stdin.readline().split())
    points = []
    for i in range(n):
        line = sys.stdin.readline().strip()
        for j in range(m):
            if line[j] == '*':
                points.append((i + 1, j + 1))  # Convert to 1-based indices
    
    x_coords = [p[0] for p in points]
    y_coords = [p[1] for p in points]
    
    # Find the x that occurs once
    if x_coords.count(x_coords[0]) == 1:
        missing_x = x_coords[0]
    else:
        missing_x = x_coords[1] if x_coords.count(x_coords[1]) == 1 else x_coords[2]
    
    # Find the y that occurs once
    if y_coords.count(y_coords[0]) == 1:
        missing_y = y_coords[0]
    else:
        missing_y = y_coords[1] if y_coords.count(y_coords[1]) == 1 else y_coords[2]
    
    print(missing_x, missing_y)

find_fourth_point()
```

### Explanation
1. **Reading Input**: The function reads the map dimensions and the map itself. It collects the coordinates of the three asterisks (robbery districts).
2. **Extracting Coordinates**: The x and y coordinates of the three points are separated into two lists.
3. **Finding Missing Coordinates**:
   - For the x-coordinates, check which value appears exactly once. This value is the missing x-coordinate.
   - Similarly, check the y-coordinates to find the missing y-coordinate.
4. **Output**: The missing coordinates are printed as the location of the fourth robbery district, completing the rectangle formed by the four points.

This approach efficiently determines the missing coordinates by leveraging the properties of rectangles aligned with the grid, ensuring that each x and y coordinate must appear exactly twice, except for the missing one which appears once in the given three points.
