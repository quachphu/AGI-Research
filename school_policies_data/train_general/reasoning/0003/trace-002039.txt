To solve this problem, we need to determine the points scored by Misha and Vasya based on their problem submissions in a Codeforces contest and compare their scores to determine the winner or if there is a tie.

### Approach
1. **Problem Understanding**: Each contestant's score is determined by the maximum of two values:
   - The points calculated using the formula \( \text{points} = \frac{p \times (250 - t)}{250} \), where \( p \) is the initial points of the problem and \( t \) is the submission time in minutes.
   - 30% of the initial points of the problem (since each contestant submitted correctly on the first attempt).

2. **Key Observations**:
   - The initial points of the problems (a for Misha and b for Vasya) are guaranteed to be divisible by 250.
   - The submission times (c for Misha and d for Vasya) are within the range [0, 180] minutes.

3. **Calculation**:
   - For each contestant, compute both possible scores and take the maximum.
   - Compare the maximum scores of Misha and Vasya to determine the result.

### Solution Code
```python
def main():
    a, b, c, d = map(int, input().split())
    
    # Calculate Misha's points
    misha_first = (a * (250 - c)) // 250
    misha_second = (3 * a) // 10
    misha = max(misha_first, misha_second)
    
    # Calculate Vasya's points
    vasya_first = (b * (250 - d)) // 250
    vasya_second = (3 * b) // 10
    vasya = max(vasya_first, vasya_second)
    
    # Determine the result
    if misha > vasya:
        print("Misha")
    elif vasya > misha:
        print("Vasya")
    else:
        print("Tie")

main()
```

### Explanation
1. **Reading Input**: The input values are read and parsed into integers representing the initial points and submission times for both contestants.
2. **Calculating Scores**:
   - **Misha's Score**: Compute both possible scores using the given formula and the 30% rule, then take the maximum.
   - **Vasya's Score**: Similarly, compute both possible scores and take the maximum.
3. **Comparison**: Compare the maximum scores of both contestants and print the result based on who has the higher score or if they tie.

This approach ensures that we accurately compute and compare the scores using integer arithmetic to avoid any floating-point inaccuracies, leveraging the given guarantees about the problem points being divisible by 250.
