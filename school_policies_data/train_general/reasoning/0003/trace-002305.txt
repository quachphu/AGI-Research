To solve this problem, we need to determine the optimal strategy for the student to win a game played on an n x n grid where players take turns painting cells such that no two painted cells are adjacent. The student can choose to be the first or second player, and both play optimally.

### Approach
The key insight is to recognize the pattern in the game based on the parity of the grid size, n. The solution hinges on the observation that the outcome of the game is determined by whether n is even or odd. This is because the maximum number of non-adjacent cells that can be painted on an n x n grid follows a specific parity rule:
- If n is odd, the maximum number of non-adjacent cells that can be painted is odd, allowing the first player to win.
- If n is even, the maximum number of non-adjacent cells that can be painted is even, allowing the second player to win.

### Solution Code
```python
n = int(input())
print(1 if n % 2 else 2)
```

### Explanation
- **Odd n**: When the grid size is odd, the maximum number of non-adjacent cells that can be painted is odd. This means the first player will always make the last move, ensuring a win.
- **Even n**: When the grid size is even, the maximum number of non-adjacent cells that can be painted is even. This means the second player will make the last move, ensuring a win.

By simply checking the parity of n, we can determine the optimal choice for the student. The solution efficiently handles even the largest possible values of n (up to \(10^{18}\)) due to its constant time complexity.
