To solve this problem, we need to determine the minimal traversal length for Shapur to visit all cities starting from city 1, considering he can end his journey in any city. The cities are connected in a tree structure, which ensures there is a unique path between any two cities.

### Approach
1. **Tree Structure Insight**: In a tree, each edge must be traversed at least twice (once to enter a subtree and once to exit) except for the edges along the longest path from the root (city 1) to the farthest leaf. These edges can be traversed once as they form the final part of the journey.
2. **Sum of Edges**: Calculate the sum of all edge weights in the tree. This sum, when doubled, represents the total distance if each edge is traversed twice.
3. **Longest Path Calculation**: Use a Breadth-First Search (BFS) to find the longest path from city 1 to any other city. This path length is subtracted from the doubled sum to get the minimal traversal length.

### Solution Code
```python
import sys
from collections import deque

def main():
    n = int(sys.stdin.readline())
    if n == 1:
        print(0)
        return
    adj = [[] for _ in range(n + 1)]
    total = 0
    for _ in range(n - 1):
        x, y, w = map(int, sys.stdin.readline().split())
        adj[x].append((y, w))
        adj[y].append((x, w))
        total += w
    max_dist = 0
    visited = [False] * (n + 1)
    q = deque()
    q.append((1, 0))
    visited[1] = True
    while q:
        node, dist = q.popleft()
        if dist > max_dist:
            max_dist = dist
        for neighbor, weight in adj[node]:
            if not visited[neighbor]:
                visited[neighbor] = True
                q.append((neighbor, dist + weight))
    print(2 * total - max_dist)

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read and parsed to build an adjacency list representing the tree structure of cities and roads. The total sum of all edge weights is computed during this step.
2. **BFS for Longest Path**: A BFS is initiated from city 1 to determine the longest path from the root to any leaf node. This path length is crucial as it allows us to avoid retracing steps for the longest path, thereby minimizing the total traversal distance.
3. **Calculating Result**: The result is computed by doubling the total sum of all edge weights (accounting for each edge being traversed twice) and subtracting the length of the longest path (since this path is traversed only once).

This approach efficiently computes the minimal traversal length using BFS, ensuring linear time complexity relative to the number of cities, making it suitable for large inputs up to the constraint limits.
