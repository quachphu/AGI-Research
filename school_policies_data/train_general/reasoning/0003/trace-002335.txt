To solve this problem, we need to determine the minimum difference in skill levels between any two horses in Chef's stable. This will help Chef host a close and interesting race. 

### Approach
1. **Input Reading**: Read the number of test cases. For each test case, read the number of horses and their respective skill levels.
2. **Sorting**: Sort the list of skill levels. Sorting helps in efficiently finding the minimum difference by only comparing consecutive elements.
3. **Finding Minimum Difference**: After sorting, iterate through the sorted list and compute the difference between each consecutive pair of elements. Track the minimum difference encountered during this iteration.

### Solution Code
```python
def find_min_difference():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        S = list(map(int, input[ptr:ptr+N]))
        ptr += N
        S.sort()
        min_diff = float('inf')
        for i in range(N-1):
            diff = S[i+1] - S[i]
            if diff < min_diff:
                min_diff = diff
        print(min_diff)

find_min_difference()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially useful for handling multiple test cases. The input is split into a list of strings for easy parsing.
2. **Sorting**: Sorting the list of skill levels ensures that the smallest differences will be between consecutive elements. This reduces the problem from checking all possible pairs (O(N^2)) to checking consecutive pairs (O(N)), which is much more efficient.
3. **Finding Minimum Difference**: By iterating through the sorted list and comparing each consecutive pair, we efficiently determine the smallest difference. This approach ensures that we only perform necessary comparisons, leading to optimal performance even for the upper constraint of 5000 elements per test case.

This method ensures that we efficiently and accurately find the minimum difference in skill levels using sorting and a linear scan, resulting in an overall time complexity of O(N log N) per test case due to the sorting step.
