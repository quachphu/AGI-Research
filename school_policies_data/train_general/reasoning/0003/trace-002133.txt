The mirrored time is considered valid if each digit in the original time can be mirrored into a valid digit and the resulting time adheres to the given hour and minute constraints.

### Approach
1. **Mirror Digit Mapping**: Define a mapping of valid mirrored digits. The valid digits when mirrored are '0', '1', '2', '5', and '8', where '2' mirrors to '5' and vice versa, and '0', '1', '8' mirror to themselves.
2. **Iterate Over Times**: Starting from the given time, check each subsequent time (including wrap-around to the next day) to see if it can form a valid mirrored time.
3. **Validation Check**: For each time, check if all digits can be mirrored and then compute the mirrored time. Validate if the mirrored time fits within the given hour and minute constraints.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    mirror = {'0': '0', '1': '1', '2': '5', '5': '2', '8': '8'}
    for _ in range(T):
        h = int(input[idx])
        m = int(input[idx + 1])
        idx += 2
        s = input[idx]
        idx += 1
        H, M = map(int, s.split(':'))
        total = H * m + M
        found = False
        max_steps = h * m
        for step in range(max_steps):
            current_total = (total + step) % max_steps
            current_h = current_total // m
            current_m = current_total % m
            # Check if all digits are valid
            h_str = f"{current_h:02d}"
            m_str = f"{current_m:02d}"
            valid = True
            for c in h_str + m_str:
                if c not in mirror:
                    valid = False
                    break
            if not valid:
                continue
            # Compute mirrored_H and mirrored_M
            # mirrored_H is formed by mirrored m_str reversed
            m1, m2 = m_str[0], m_str[1]
            mirrored_M1 = mirror[m2]
            mirrored_M0 = mirror[m1]
            mirrored_H = int(mirrored_M1 + mirrored_M0)
            # mirrored_M is formed by mirrored h_str reversed
            h1, h2 = h_str[0], h_str[1]
            mirrored_H1 = mirror[h2]
            mirrored_H0 = mirror[h1]
            mirrored_M = int(mirrored_H1 + mirrored_H0)
            # Check validity
            if mirrored_H < h and mirrored_M < m:
                print(f"{current_h:02d}:{current_m:02d}")
                found = True
                break
solve()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, and then parsed to extract the number of test cases and their respective parameters.
2. **Mirror Check**: For each time starting from the given time, the digits are checked against the valid mirrored digits. If any digit is invalid, the time is skipped.
3. **Mirrored Time Calculation**: Valid digits are mirrored, and the mirrored time is constructed by reversing the order of the minutes and hours digits after mirroring.
4. **Validation**: The mirrored time is checked against the given constraints for hours and minutes. The first valid time encountered is printed as the result.

This approach ensures that we efficiently check each possible time starting from the given time, wrapping around the day if necessary, and find the nearest valid mirrored time.
