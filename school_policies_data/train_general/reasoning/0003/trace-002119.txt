To solve this problem, we need to determine the number of "good" shuffles (derangements) for a given number of cards in a deck. A good shuffle is one where no card remains in its original position. This problem can be efficiently solved using dynamic programming to precompute the number of derangements for decks of size up to 20.

### Approach
1. **Understanding Derangements**: A derangement is a permutation where no element appears in its original position. The number of derangements of `n` elements, denoted as `!n`, can be computed using the recurrence relation:
   \[
   !n = (n-1) \times ( !(n-1) + !(n-2) )
   \]
   with base cases:
   - `!0 = 1` (by convention)
   - `!1 = 0`

2. **Dynamic Programming Precomputation**: We precompute the derangements for all values from 0 to 20 using dynamic programming. This allows us to efficiently answer each query in constant time by simply looking up the precomputed value.

3. **Reading Input and Output**: Read the number of test cases and the respective deck sizes. For each deck size, output the precomputed derangement value.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    ns = list(map(int, input[1:t+1]))
    
    # Precompute derangements up to 20
    dp = [0] * 21
    dp[0] = 1
    if len(dp) > 1:
        dp[1] = 0
    for i in range(2, 21):
        dp[i] = (i - 1) * (dp[i - 1] + dp[i - 2])
    
    for n in ns:
        print(dp[n])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precomputation**: We initialize a dynamic programming array `dp` where `dp[i]` holds the number of derangements for `i` elements. Using the recurrence relation, we fill this array up to `dp[20]`.

2. **Efficient Query Handling**: By precomputing all possible values up front, each query is answered in constant time, making the solution very efficient even for the upper limit of input constraints.

3. **Input Handling**: The input is read in one go for efficiency, and the results are printed directly from the precomputed array.

This approach ensures that the solution is both optimal and easy to understand, leveraging dynamic programming to handle up to the maximum constraint efficiently.
