To solve this problem, we need to determine the number of coins showing either heads or tails after a series of rounds in a game where each coin is flipped a specific number of times. The solution must efficiently compute the result for each game given the constraints.

### Approach
1. **Understanding the Coin Flips**: Each coin numbered `i` is flipped in every round `k` where `k >= i`. The number of flips for a coin `i` is `N - i + 1`.
2. **Odd and Even Flips**: The state of a coin (heads or tails) changes if it is flipped an odd number of times. If flipped even times, it remains in the initial state.
3. **Counting Odd Flips**: The number of coins flipped an odd number of times can be determined using the formula `(N + 1) // 2`. This formula works because it effectively counts the number of coins that start with the opposite parity of `N` when considering their positions.
4. **Result Calculation**: Depending on the initial state (heads or tails) and the desired outcome (heads or tails), we compute the result by either subtracting the odd flips from the total coins or using the odd flips directly.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        G = int(input[ptr])
        ptr += 1
        for __ in range(G):
            I = int(input[ptr])
            N = int(input[ptr + 1])
            Q = int(input[ptr + 2])
            ptr += 3
            count_odd = (N + 1) // 2
            if I == Q:
                res = N - count_odd
            else:
                res = count_odd
            print(res)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints of up to 20,000 games per test case.
2. **Processing Each Game**: For each game, we extract the initial state (I), the number of coins (N), and the desired outcome (Q).
3. **Odd Flips Calculation**: Using the formula `(N + 1) // 2`, we determine how many coins are flipped an odd number of times.
4. **Result Determination**: 
   - If the initial state (I) matches the desired outcome (Q), the result is the total coins minus the odd flips (since those coins remain unchanged).
   - If they do not match, the result is the number of odd flips (since those coins have changed state).

This approach ensures that each game is processed in constant time, making the solution efficient even for large inputs.
