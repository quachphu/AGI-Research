   - If `n` is 1, then the only valid string is "a" if `k` is 1.
   - If `k` is less than 2 or greater than `n`, it's impossible to form the string.
   - Calculate the length `m` of the initial part of the string. If `m` is less than 2, it's impossible to form the required string.

2. **Construct the String**:
   - **Initial Part**: Generate the initial part of the string using alternating 'a' and 'b' characters. This part ensures the string starts lexicographically smallest.
   - **Suffix Part**: Append the remaining `k-2` distinct characters starting from 'c' to ensure exactly `k` distinct characters are used.

### Solution Code

```python
def main():
    import sys
    n, k = map(int, sys.stdin.readline().split())
    if n == 1:
        print('a' if k == 1 else -1)
        return
    if k < 2 or k > n:
        print(-1)
        return
    m = n - (k - 2)
    if m < 2:
        print(-1)
        return
    # Generate initial part
    initial = []
    for i in range(m):
        initial.append('a' if i % 2 == 0 else 'b')
    # Generate suffix
    suffix = [chr(ord('c') + i) for i in range(k - 2)]
    # Combine and print
    print(''.join(initial + suffix))

main()
```

3. **Construct Initial Part**:
   - Generate a string alternating between 'a' and 'b' of length `m`. This ensures the string starts as small as possible lexicographically.

4. **Construct Suffix Part**:
   - Append the next `k-2` characters starting from 'c' to ensure exactly `k` distinct characters are used without any adjacent duplicates.
