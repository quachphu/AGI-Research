To solve this problem, we need to determine the median height of N stacks after processing M range-based increment instructions efficiently. The challenge is to handle large input sizes within feasible time complexity.

### Approach
1. **Efficient Range Updates**: Instead of updating each stack height for every instruction, we use a difference array to efficiently apply range updates. This allows us to perform each range update in constant time.
2. **Prefix Sum Calculation**: After processing all instructions, we compute the actual stack heights using a prefix sum on the difference array. This converts the range updates into the final heights array in linear time.
3. **Sorting and Median Calculation**: Once we have the heights array, we sort it and find the median, which is the middle element of the sorted array.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    M = int(input[ptr])
    ptr += 1

    diff = [0] * (N + 2)  # 0 to N+1 inclusive

    for _ in range(M):
        A = int(input[ptr])
        ptr += 1
        B = int(input[ptr])
        ptr += 1
        diff[A] += 1
        diff[B + 1] -= 1

    # Compute the heights using prefix sum
    current = 0
    heights = []
    for i in range(1, N + 1):
        current += diff[i]
        heights.append(current)
    
    # Find the median
    heights.sort()
    print(heights[N // 2])

main()
```

### Explanation
1. **Difference Array Initialization**: We initialize a difference array `diff` of size `N + 2` to handle range updates efficiently. This array helps in applying increments over a range in constant time.
2. **Processing Instructions**: For each instruction `A B`, we increment `diff[A]` by 1 and decrement `diff[B + 1]` by 1. This marks the start and end of the range increment.
3. **Prefix Sum Calculation**: Using the difference array, we compute the actual heights of the stacks by iterating through the array and maintaining a running sum, which gives the height of each stack.
4. **Sorting and Median**: After computing the heights, we sort them and find the median by accessing the middle element of the sorted list, which is the `N // 2`-th element (0-based index).

This approach ensures that we handle up to 100,000 stacks and 10,000 instructions efficiently, making the solution both time and space optimal.
