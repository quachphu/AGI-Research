To solve this problem, we need to determine the final distribution of particles in K nuclear reactor chambers after bombarding them with A particles, considering that each chamber can hold a maximum of N particles before triggering a reaction that moves one particle to the next chamber and resets the current chamber's count.

### Approach
The key insight here is to recognize that the process of particles moving through the chambers resembles a number system with a base of (N+1). Each chamber can be thought of as a digit in this base system. When a chamber overflows (exceeds N particles), it resets to zero and transfers one particle to the next chamber. This is analogous to carrying over in a positional number system.

1. **Base Conversion Insight**: The problem can be efficiently solved by converting the total number of particles (A) into a number represented in base (N+1). Each digit in this base representation corresponds to the particle count in each chamber.
2. **Handling Large Values**: Directly simulating each particle and reaction would be computationally infeasible for large values of A (up to 1 billion). Instead, we use mathematical properties of number systems to directly compute the particle distribution without iterative simulation.

### Solution Code
```python
def main():
    import sys
    A, N, K = map(int, sys.stdin.readline().split())
    base = N + 1
    result = []
    for i in range(K):
        divisor = base ** i
        digit = (A // divisor) % base
        result.append(str(digit))
    print(' '.join(result))

main()
```

### Explanation
1. **Reading Input**: The input values A (total particles), N (maximum particles per chamber), and K (number of chambers) are read from standard input.
2. **Base Calculation**: The base for the number system is determined as (N + 1), which represents the threshold for overflow in each chamber.
3. **Digit Calculation**: For each chamber (from 0 to K-1), we calculate the corresponding digit in the base (N+1) system. This digit represents the number of particles in that chamber after all reactions have settled.
4. **Result Construction**: The digits (particle counts) are collected and formatted into the required output format.

This approach efficiently computes the result in O(K) time complexity, which is optimal given the constraints, ensuring even large values are handled quickly and correctly.
