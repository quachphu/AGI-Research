To solve this problem, we need to determine if we can reach a target point (p_x, p_y) by following a sequence of movement commands, possibly after deleting some commands. The solution involves checking if the given commands can be adjusted to meet the required movement in both x and y directions.

### Approach
1. **Understand the Movement Commands**: Each command (U, D, R, L) moves the spaceship in a specific direction on the XY plane.
2. **Count Commands**: For each test case, count the number of each type of movement command (R, L, U, D) in the given string.
3. **Check Feasibility**:
   - **X Direction**: Determine if the number of right (R) and left (L) commands can be adjusted to reach the target x-coordinate (p_x).
   - **Y Direction**: Determine if the number of up (U) and down (D) commands can be adjusted to reach the target y-coordinate (p_y).

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    t = int(input[idx])
    idx += 1
    for _ in range(t):
        px = int(input[idx])
        py = int(input[idx+1])
        idx += 2
        s = input[idx]
        idx += 1
        R = s.count('R')
        L = s.count('L')
        U = s.count('U')
        D = s.count('D')
        ok_x = True
        if px > 0:
            if R < px:
                ok_x = False
        elif px < 0:
            if L < -px:
                ok_x = False
        ok_y = True
        if py > 0:
            if U < py:
                ok_y = False
        elif py < 0:
            if D < -py:
                ok_y = False
        print("YES" if ok_x and ok_y else "NO")

main()
```

1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Counting Commands**: For each test case, the code counts how many times each movement command (R, L, U, D) appears in the string.
3. **Checking X Direction**:
   - If the target x-coordinate (p_x) is positive, check if there are enough R commands to reach it.
   - If p_x is negative, check if there are enough L commands to reach it.
4. **Checking Y Direction**:
   - If the target y-coordinate (py) is positive, check if there are enough U commands to reach it.
   - If py is negative, check if there are enough D commands to reach it.
5. **Result Determination**: If both x and y directions can be satisfied, print "YES"; otherwise, print "NO".

This approach efficiently checks the feasibility of reaching the target coordinates by leveraging the counts of each movement command, ensuring optimal performance even for large input sizes.
