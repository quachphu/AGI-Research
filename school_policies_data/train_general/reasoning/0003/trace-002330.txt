To solve this problem, we need to find the most efficient path from a starting town to a destination town in an MMORPG game, where efficiency is defined as the total experience points earned divided by the total time taken. The path must be straightforward, meaning each consecutive town in the path must be closer to the destination than the previous one.

### Approach

1. **Shortest Distance Calculation**: Use Dijkstra's algorithm to compute the shortest time from each town to the destination town. This helps in determining which roads can be part of a straightforward path.

2. **Directed Acyclic Graph (DAG) Construction**: Construct a DAG where edges only exist if moving from one town to another brings us closer to the destination. This is determined using the shortest distances calculated earlier.

3. **Binary Search for Maximum Efficiency**: Use binary search to find the maximum efficiency. For each candidate efficiency value, check if there exists a path in the DAG such that the sum of (experience points - candidate efficiency * time) is non-negative. This check is performed using dynamic programming on the DAG processed in topological order.

### Solution Code

```python
import heapq

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    c = int(input[ptr])
    ptr += 1
    for _ in range(c):
        n = int(input[ptr])
        m = int(input[ptr + 1])
        ptr += 2
        s = int(input[ptr])
        t = int(input[ptr + 1])
        ptr += 2
        roads = []
        for __ in range(m):
            u = int(input[ptr])
            v = int(input[ptr + 1])
            e = int(input[ptr + 2])
            ti = int(input[ptr + 3])
            roads.append((u, v, e, ti))
            ptr += 4
        # Build adjacency list for Dijkstra
        adj = [[] for _ in range(n)]
        for u, v, e, ti in roads:
            adj[u].append((v, ti))
            adj[v].append((u, ti))
        # Dijkstra from t
        INF = float('inf')
        dist = [INF] * n
        dist[t] = 0
        heap = [(0, t)]
        processed = [False] * n
        while heap:
            d_u, u = heapq.heappop(heap)
            if processed[u]:
                continue
            processed[u] = True
            for v, ti in adj[u]:
                if dist[v] > d_u + ti:
                    dist[v] = d_u + ti
                    heapq.heappush(heap, (dist[v], v))
        # Build DAG adjacency list
        dag_adj = [[] for _ in range(n)]
        for u, v, e, ti in roads:
            if dist[u] > dist[v]:
                dag_adj[u].append((v, e, ti))
            if dist[v] > dist[u]:
                dag_adj[v].append((u, e, ti))
        # Generate topological order (decreasing order of dist)
        top_order = sorted([(-dist[i], i) for i in range(n)], key=lambda x: x[0])
        top_order = [i for (d, i) in top_order]
        # Binary search
        low = 0.0
        high = 1e9
        for __ in range(100):
            mid = (low + high) / 2
            dp = [-float('inf')] * n
            dp[s] = 0.0
            for u in top_order:
                if dp[u] == -float('inf'):
                    continue
                for v, e, ti in dag_adj[u]:
                    new_val = dp[u] + (e - mid * ti)
                    if new_val > dp[v]:
                        dp[v] = new_val
            if dp[t] >= 0:
                low = mid
            else:
                high = mid
        print("{0:.4f}".format(low))

if __name__ == '__main__':
    main()
```

1. **Dijkstra's Algorithm**: This is used to compute the shortest time from the destination town to all other towns, which helps in determining valid edges for the DAG.

2. **DAG Construction**: Only edges that move closer to the destination (based on shortest distances) are included in the DAG. This ensures that any path in the DAG is straightforward.

3. **Binary Search**: The binary search iterates over possible efficiency values. For each candidate value, dynamic programming is used to check if there's a path where the sum of adjusted weights (experience points minus efficiency multiplied by time) is non-negative. This is done efficiently using topological sorting of the DAG nodes.

This approach ensures that we efficiently find the path with the highest efficiency while adhering to the constraints of a straightforward path.
