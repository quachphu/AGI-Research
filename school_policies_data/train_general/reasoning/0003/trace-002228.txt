To solve this problem, we need to simulate Steve's restaurant operations where he processes customer orders based on a specific set of rules. The goal is to determine the time each customer is served after their order is fully prepared.

### Approach
1. **Menu Parsing**: Read the menu entries which include the dish name, the maximum number of dishes that can be cooked at once (limit), and the time required to cook each batch.
2. **Order Processing**: Read customer orders, which include the time the order was accepted and the list of dishes ordered.
3. **Order Queue Management**: Process orders in a first-come-first-served manner. For each order, sort the dishes based on cooking time (descending) and menu order (ascending for same cooking times).
4. **Batch Cooking**: For each dish in the sorted list, cook in batches considering all pending orders accepted up to the current time. Adjust the remaining dish counts for all relevant orders and update their serving times accordingly.
5. **Output Serving Times**: After processing all orders, output the serving times for each customer in the order they placed their orders.

```python
        self.name = name
        self.limit = int(limit)
        self.time = int(time)
        self.index = index

class Order:
    def __init__(self, Tj, dishes):
        self.Tj = int(Tj)
        self.dishes = dishes  # Dictionary {dish_name: count}
        self.serving_time = 0

def main():
    first_dataset = True
    while True:
        line = sys.stdin.readline()
        if not line:
            break
        N, M = map(int, line.strip().split())
        if N == 0 and M == 0:
            break
        if not first_dataset:
            print()  # Blank line between datasets
        first_dataset = False

        # Read menu entries
        menu_dict = {}
        menu_list = []
        for i in range(N):
            parts = sys.stdin.readline().strip().split()
            name = parts[0]
            limit = parts[1]
            time = parts[2]
            menu_entry = MenuEntry(name, limit, time, i)
            menu_dict[name] = menu_entry
            menu_list.append(menu_entry)

        # Read orders
        orders = []
        for _ in range(M):
            parts = sys.stdin.readline().strip().split()
            Tj = parts[0]
            Kj = int(parts[1])
            dish_names = parts[2:2+Kj]
            dish_counts = {}
            for name in dish_names:
                if name in dish_counts:
                    dish_counts[name] += 1
                else:
                    dish_counts[name] = 1
            order = Order(Tj, dish_counts)
            orders.append(order)

        # Process orders
        current_time = 0
        for order in orders:
            start_processing = max(current_time, order.Tj)
            current_time = start_processing

            # Sort the dishes in the order by time descending and menu index ascending
            sorted_dish_names = sorted(
                order.dishes.keys(),
                key=lambda name: (-menu_dict[name].time, menu_dict[name].index)
            )

            for dish_name in sorted_dish_names:
                while order.dishes.get(dish_name, 0) > 0:
                    # Calculate total available dishes of this type across all eligible orders
                    total_available = 0
                    for o in orders:
                        if o.Tj > current_time:
                            continue
                        total_available += o.dishes.get(dish_name, 0)

                    if total_available == 0:
                        break  # Shouldn't happen as current order's dish is >0

                    menu_entry = menu_dict[dish_name]
                    batch_size = min(total_available, menu_entry.limit)
                    end_time = current_time + menu_entry.time

                    remaining = batch_size
                    # Subtract from orders in the order they were received
                    for o in orders:
                        if o.Tj > current_time:
                            continue
                        current_count = o.dishes.get(dish_name, 0)
                        if current_count == 0:
                            continue
                        subtract = min(current_count, remaining)
                        o.dishes[dish_name] -= subtract
                        remaining -= subtract
                        if subtract > 0:
                            o.serving_time = max(o.serving_time, end_time)
                        if remaining == 0:
                            break

                    current_time = end_time

        # Output the serving times in the order of input
        for order in orders:
            print(order.serving_time)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Menu Parsing**: The menu is read and stored with details about each dish, including the maximum number that can be cooked at once and the time per batch.
2. **Order Processing**: Each order is parsed into a structure that holds the time it was accepted and the count of each dish ordered.
3. **Order Queue Management**: Orders are processed in the order they were received. For each order, dishes are sorted by cooking time and menu order.
4. **Batch Cooking**: For each dish in the sorted list, batches are cooked considering all pending orders. The earliest orders are processed first, and the serving time for each order is updated when their dishes are cooked.
5. **Output**: The serving times for each order are printed in the order they were received, ensuring the correct sequence of output.

This approach ensures that Steve efficiently processes orders by batching dishes together whenever possible, while adhering to the constraints of his kitchen capacity and maintaining the first-come-first-served principle.
