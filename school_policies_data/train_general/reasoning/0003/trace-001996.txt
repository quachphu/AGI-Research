To solve this problem, we need to maximize the total number of products sold by a shop over a given period by selecting specific days for a sell-out, where the number of products available on those days is doubled. The goal is to determine the optimal days to apply the sell-out to achieve the highest possible sales.

### Approach
1. **Understand the Problem**: Each day has a certain number of products and clients. Products sold each day are the minimum of the available products and the number of clients. Leftover products are discarded. By doubling the products on selected days (sell-out days), we aim to maximize sales.

2. **Original Sales Calculation**: Calculate the total sales without any sell-out days by summing the minimum of products and clients for each day.

3. **Gain Calculation**: For each day, determine the potential increase in sales if it were a sell-out day. This gain is calculated as the difference between the sales with doubled products and the original sales for that day.

4. **Optimal Selection of Days**: Sort the gains in descending order and select the top `f` days to maximize the total gain. Sum these gains and add them to the original sales total.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n, f = int(input[idx]), int(input[idx+1])
    idx += 2
    original_sum = 0
    gains = []
    for _ in range(n):
        ki = int(input[idx])
        li = int(input[idx+1])
        idx += 2
        orig = min(ki, li)
        original_sum += orig
        new = min(2 * ki, li)
        gain = new - orig
        gains.append(gain)
    gains.sort(reverse=True)
    sum_top = sum(gains[:f])
    print(original_sum + sum_top)

main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints. The first line gives the number of days `n` and the number of sell-out days `f`.

2. **Original Sales Calculation**: For each day, compute the sales as the minimum of products available and clients. Sum these values to get the original sales total.

3. **Gain Calculation**: For each day, compute the potential increase in sales if the day were a sell-out. This is done by comparing the sales with doubled products to the original sales.

4. **Optimal Selection**: The gains are sorted in descending order, and the top `f` gains are summed. This sum is added to the original sales total to get the maximum possible sales.

This approach ensures that we efficiently determine the optimal days for sell-outs, leading to maximum sales using a combination of sorting and greedy selection. The complexity is dominated by the sorting step, making it O(n log n), which is efficient for the given constraints.
