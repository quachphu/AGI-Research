To solve this problem, we need to find `n` positive integers such that the sum of their squares is at least `x` and their total sum is at most `y`. If no such sequence exists, we should return `-1`.

### Approach
1. **Check Feasibility of Sum**: The minimum possible sum of `n` positive integers (each being at least 1) is `n`. If `y` is less than `n`, it's impossible to form such a sequence, so we immediately return `-1`.
2. **Maximize Sum of Squares**: Given the constraints, the sum of squares is maximized when one number is as large as possible and the rest are 1. This is because the square function grows faster with larger values. Thus, we check if the maximum possible sum of squares (using this configuration) meets or exceeds `x`.
3. **Construct the Sequence**: If feasible, the sequence is constructed by having one number as `y - (n - 1)` (to ensure the sum is exactly `y`) and the remaining `n - 1` numbers as 1.

### Solution Code
```python
def solve():
    import sys
    n, x, y = map(int, sys.stdin.readline().split())
    if y < n:
        print(-1)
        return
    remaining = y - (n - 1)
    sum_sq = remaining ** 2 + (n - 1)
    if sum_sq < x:
        print(-1)
    else:
        print(remaining)
        for _ in range(n - 1):
            print(1)

solve()
```

### Explanation
1. **Feasibility Check**: The code first checks if `y` is at least `n` to ensure the minimum possible sum of `n` positive integers.
2. **Sum of Squares Calculation**: The maximum sum of squares for a given `y` is calculated by considering one element as `y - (n - 1)` and the rest as 1. This configuration maximizes the sum of squares due to the convex nature of the square function.
3. **Output Construction**: If the calculated sum of squares meets or exceeds `x`, the sequence is printed. Otherwise, `-1` is returned indicating no valid sequence exists.

This approach efficiently determines the feasibility and constructs the solution in linear time, making it suitable even for large values of `n` up to 100,000.
