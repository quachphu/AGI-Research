To solve this problem, we need to determine the minimum possible maximum element in an array of `n` positive integers such that the sum of the array is divisible by `k`. The solution involves finding the smallest sum that meets the divisibility requirement and then distributing this sum as evenly as possible among the `n` elements.

### Approach
1. **Determine the Smallest Sum**: The sum of the array must be the smallest multiple of `k` that is greater than or equal to `n`. This ensures each element is at least 1 and the sum is divisible by `k`.
2. **Calculate Minimum Maximum Element**: Once the smallest valid sum is determined, the minimum possible maximum element is found by distributing this sum as evenly as possible among the `n` elements. This is done using integer division and ceiling operations to handle the distribution.

### Solution Code
```python
import sys

t = int(sys.stdin.readline())
for _ in range(t):
    n, k = map(int, sys.stdin.readline().split())
    m = (n + k - 1) // k
    ans = (m * k + n - 1) // n
    print(ans)
```

### Explanation
1. **Reading Input**: The code reads the number of test cases `t` and then processes each test case by reading `n` and `k`.
2. **Compute Smallest Valid Sum**: The smallest valid sum `m * k` is computed where `m` is the smallest integer such that `m * k` is at least `n`. This is done using the formula `m = (n + k - 1) // k`.
3. **Distribute Sum Evenly**: The minimum possible maximum element is computed by distributing the sum `m * k` across `n` elements. This is achieved using the formula `ans = (m * k + n - 1) // n`, which effectively calculates the ceiling of the division of the sum by `n`.

This approach efficiently handles the constraints and ensures the solution is computed in constant time for each test case, making it suitable for large input values.
