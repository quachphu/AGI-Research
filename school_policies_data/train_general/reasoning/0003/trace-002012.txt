To solve this problem, we need to determine if the total study time in a day meets or exceeds a target time. If it does not, we need to calculate the shortage. The solution involves reading multiple datasets and processing each one to check the study time against the target.

### Approach
1. **Reading Input:** The input consists of multiple datasets. Each dataset starts with a target time (t), followed by the number of study periods (n), and then the start and end times of each study period. The input ends with a line containing 0.
2. **Processing Each Dataset:** For each dataset:
   - Read the target time (t) and the number of study periods (n).
   - Calculate the total study time by summing the duration of each study period.
   - Compare the total study time with the target time. If the total is equal to or exceeds the target, output "OK". Otherwise, output the shortage time.
3. **Handling Multiple Datasets:** Continue processing datasets until encountering a line with 0, which indicates the end of input.

### Solution Code
```python
def main():
    import sys
    lines = [line.strip() for line in sys.stdin if line.strip()]
    ptr = 0
    while ptr < len(lines):
        t = int(lines[ptr])
        ptr += 1
        if t == 0:
            break
        n = int(lines[ptr])
        ptr += 1
        total = 0
        for _ in range(n):
            s, f = map(int, lines[ptr].split())
            ptr += 1
            total += (f - s)
        if total >= t:
            print("OK")
        else:
            print(t - total)

main()
```

### Explanation
- **Reading Input:** The input is read all at once into a list of lines, skipping any empty lines. This helps in efficiently processing each line sequentially.
- **Loop Through Datasets:** The loop continues until a target time of 0 is encountered, which signifies the end of input.
- **Calculate Total Study Time:** For each study period, the duration is calculated as the difference between the end time and start time. These durations are summed to get the total study time.
- **Comparison and Output:** The total study time is compared with the target time. If it meets or exceeds the target, "OK" is printed. Otherwise, the difference (shortage) is printed.

This approach ensures that each dataset is processed efficiently, and the solution handles all edge cases such as non-overlapping study periods and varying numbers of datasets.
