### Approach
1. **Grid Initialization**: Start with a grid where all pixels are initially white. Track the black pixels using a set for efficient lookups.
2. **Move Processing**: For each move, check if the pixel is already black. If not, mark it as black.
3. **Square Check**: After marking a pixel as black, check all possible 2x2 squares that could include this pixel. Specifically, check the four possible squares where the newly marked pixel could be the bottom-right, bottom-left, top-right, or top-left corner.
4. **Validation**: For each valid 2x2 square, check if all four pixels are black. If a valid square is found, immediately return the current move number.

- **Grid Initialization**: The grid is represented as a set of tuples where each tuple (i, j) indicates a black pixel.

- **Square Check**: For each new black pixel, we check up to four possible 2x2 squares that could be completed by this pixel. Each check involves verifying the presence of the other three pixels required to form the square.
- **Efficiency**: The use of a set ensures O(1) average-time complexity for membership checks, making the solution efficient even for the upper limits of input constraints.
