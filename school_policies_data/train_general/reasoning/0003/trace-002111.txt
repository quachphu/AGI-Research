To solve this problem, we need to simulate a card game between two players, Taro and Hanako, following specific rules. The goal is to determine the scores of each player when the game ends, which happens when either player exhausts their cards. The score of a player is determined by the number of cards remaining in the opponent's hand when the game ends.

### Approach
1. **Input Handling**: Read multiple datasets until encountering a dataset where `n` is 0. Each dataset starts with an integer `n`, followed by `n` integers representing Taro's cards.
2. **Card Distribution**: For each dataset, generate Hanako's cards as the complement of Taro's cards within the range from 1 to `2n`.
3. **Simulation of the Game**:
   - Players take turns starting with Taro.
   - If the play area is empty, the current player plays their smallest card.
   - If the play area has a card, the current player must play the smallest card larger than the last card played. If they cannot, they pass, and the play area is cleared.
   - The game continues until one player has no cards left.
4. **Score Calculation**: The score for each player is the number of cards remaining in the opponent's hand when the game ends.

### Solution Code
```python
def simulate_game():
    import sys
    while True:
        line = sys.stdin.readline()
        if not line:
            break
        n = int(line.strip())
        if n == 0:
            break
        taro = []
        for _ in range(n):
            card = int(sys.stdin.readline().strip())
            taro.append(card)
        total = 2 * n
        hanako = []
        taro_set = set(taro)
        for i in range(1, total + 1):
            if i not in taro_set:
                hanako.append(i)
        taro_hand = sorted(taro)
        hanako_hand = sorted(hanako)
        current_player = True  # Taro's turn first
        last_card = None

        while len(taro_hand) > 0 and len(hanako_hand) > 0:
            if current_player:
                # Taro's turn
                if last_card is None:
                    played = taro_hand.pop(0)
                    last_card = played
                    current_player = False
                    if not taro_hand:
                        break
                else:
                    found = False
                    for i in range(len(taro_hand)):
                        if taro_hand[i] > last_card:
                            played = taro_hand.pop(i)
                            last_card = played
                            current_player = False
                            found = True
                            break
                    if not found:
                        last_card = None
                        current_player = False
            else:
                # Hanako's turn
                if last_card is None:
                    played = hanako_hand.pop(0)
                    last_card = played
                    current_player = True
                    if not hanako_hand:
                        break
                else:
                    found = False
                    for i in range(len(hanako_hand)):
                        if hanako_hand[i] > last_card:
                            played = hanako_hand.pop(i)
                            last_card = played
                            current_player = True
                            found = True
                            break
                    if not found:
                        last_card = None
                        current_player = True
            # Check if any hand is empty after the move
            if len(taro_hand) == 0 or len(hanako_hand) == 0:
                break

        taro_score = len(hanako_hand)
        hanako_score = len(taro_hand)
        print(taro_score)
        print(hanako_score)

simulate_game()
```

### Explanation
- **Input Handling**: The code reads input until `n` is 0. Each dataset is processed to determine Taro's and Hanako's cards.
- **Card Distribution**: Hanako's cards are derived by subtracting Taro's cards from the full set of cards (1 to 2n).
- **Game Simulation**: The game alternates turns between Taro and Hanako. Each player plays the smallest possible card according to the rules. If a player cannot play, they pass, and the play area is cleared.
- **Termination and Scoring**: The game ends when either player has no cards left. The scores are determined by the number of remaining cards in the opponent's hand, which are printed as the result for each dataset.
