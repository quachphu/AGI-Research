To solve this problem, we need to determine the number of ways to delete exactly one letter from some of the words in the scroll such that the resulting list of words is in lexicographically non-decreasing order. The solution must handle large input sizes efficiently.

### Approach
1. **Generate Candidates**: For each word, generate all possible candidates by considering the word itself and all possible deletions of one character.
2. **Count Frequencies**: Use a dictionary to count the frequency of each candidate string.
3. **Sort Candidates**: Sort the unique candidate strings lexicographically.
4. **Dynamic Programming with Prefix Sum**: Use dynamic programming (DP) with a prefix sum array to efficiently compute the number of valid sequences. For each word, maintain a DP state that tracks the number of valid sequences ending with each candidate string. Use binary search to efficiently find valid transitions between words.

### Solution Code
```python
import sys
import bisect

MOD = 10**9 + 7

def main():
    n = int(sys.stdin.readline())
    words = [sys.stdin.readline().strip() for _ in range(n)]
    
    prev_candidates = []
    prev_counts = []
    
    for i, word in enumerate(words):
        candidates = {}
        candidates[word] = 1
        for j in range(len(word)):
            s = word[:j] + word[j+1:]
            if s in candidates:
                candidates[s] += 1
            else:
                candidates[s] = 1
        
        sorted_candidates = sorted(candidates.items())
        current = [(s, cnt) for s, cnt in sorted_candidates]
        if i == 0:
            prev_candidates = [s for s, _ in current]
            prev_counts = [cnt % MOD for _, cnt in current]
        else:
            new_candidates = [s for s, _ in current]
            new_counts = []
            # Prepare prefix sum array for previous counts
            prefix = [0] * (len(prev_counts) + 1)
            for k in range(len(prev_counts)):
                prefix[k+1] = (prefix[k] + prev_counts[k]) % MOD
            
            for s, cnt in current:
                idx = bisect.bisect_right(prev_candidates, s)
                total = prefix[idx]
                new_counts.append((total * cnt) % MOD)
            
            prev_candidates = new_candidates
            prev_counts = new_counts
        
        if not prev_candidates:
            print(0)
            return
    
    total = sum(prev_counts) % MOD
    print(total)

if __name__ == "__main__":
    main()
```
