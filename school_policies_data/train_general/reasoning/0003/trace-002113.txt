To solve this problem, we need to determine the number of unique pairs of prime numbers that sum up to each given even number (greater than or equal to 4). Each pair (p1, p2) should be counted only once, considering that (p1, p2) and (p2, p1) are the same pair.

### Approach
1. **Prime Number Generation (Sieve of Eratosthenes)**: 
   - Precompute prime numbers up to the maximum possible value (32766) using the Sieve of Eratosthenes. This allows efficient prime checks during the pair counting phase.

2. **Processing Each Input**:
   - For each input number, iterate through possible prime pairs (p1, p2) where p1 ≤ p2. This is done by checking primes from 2 up to n/2. For each prime p1, check if the complement (n - p1) is also a prime.

3. **Efficiency**:
   - The sieve precomputation ensures that prime checks are done in constant time, making the solution efficient even for the upper limit of input values.

### Solution Code
```python
import sys

def generate_sieve():
    max_prime = 32766
    sieve = [True] * (max_prime + 1)
    sieve[0] = sieve[1] = False
    for i in range(2, int(max_prime ** 0.5) + 1):
        if sieve[i]:
            sieve[i*i : max_prime+1 : i] = [False] * len(sieve[i*i : max_prime+1 : i])
    return sieve

def main():
    sieve = generate_sieve()
    for line in sys.stdin:
        n = int(line.strip())
        if n == 0:
            break
        count = 0
        max_p1 = n // 2
        for p1 in range(2, max_p1 + 1):
            if sieve[p1] and sieve[n - p1]:
                count += 1
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Sieve of Eratosthenes**:
   - This algorithm efficiently marks non-prime numbers in a boolean array. Starting from the first prime (2), it marks all multiples of each prime as non-prime, up to the square root of the maximum number for optimization.

2. **Prime Pair Counting**:
   - For each input number `n`, iterate from 2 to `n//2` (inclusive). For each number `p1` in this range, check if both `p1` and `n - p1` are primes using the precomputed sieve. If both are primes, increment the count.

This approach ensures that each prime pair is checked efficiently, leveraging the precomputed sieve for constant time prime verification, resulting in an optimal solution for the given problem constraints.
