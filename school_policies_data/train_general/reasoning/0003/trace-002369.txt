To solve this problem, we need to determine the minimum number of hours Ivan has to spend at the university in a week, given that he can skip up to `k` lessons. The approach involves dynamic programming to efficiently explore all possible ways Ivan can skip lessons while minimizing his time spent at the university.

### Approach
1. **Input Parsing**: Read the input values for the number of days, hours per day, and the maximum number of lessons Ivan can skip. Also, read the timetable for each day.
2. **Precompute Minimum Hours per Day**: For each day, compute the minimum hours Ivan must spend if he skips a certain number of lessons. This is done by finding the shortest interval that contains the remaining lessons after skipping some.
3. **Dynamic Programming (DP)**: Use a DP array to keep track of the minimum hours spent for each possible number of skipped lessons. Update this array iteratively for each day, considering all possible skips for the current day and combining them with previous results.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    m = int(input[idx])
    idx += 1
    k = int(input[idx])
    idx += 1

    days = []
    for _ in range(n):
        s = input[idx].strip()
        idx += 1
        times = [j + 1 for j, ch in enumerate(s) if ch == '1']
        days.append(times)

    min_hours_list = []
    for times in days:
        c = len(times)
        if c == 0:
            min_hours = [0]
        else:
            min_hours = [0] * (c + 1)
            for s in range(c + 1):
                if s == c:
                    min_hours[s] = 0
                else:
                    needed = c - s
                    if needed == 0:
                        min_hours[s] = 0
                    else:
                        min_len = float('inf')
                        for i in range(len(times) - needed + 1):
                            j = i + needed - 1
                            current_len = times[j] - times[i] + 1
                            if current_len < min_len:
                                min_len = current_len
                        min_hours[s] = min_len
        min_hours_list.append(min_hours)

    INF = float('inf')
    dp = [INF] * (k + 1)
    dp[0] = 0

    for min_hours_day in min_hours_list:
        new_dp = [INF] * (k + 1)
        for s_prev in range(k + 1):
            if dp[s_prev] == INF:
                continue
            max_s_i = len(min_hours_day) - 1
            for s_i in range(max_s_i + 1):
                s_total = s_prev + s_i
                if s_total > k:
                    continue
                if new_dp[s_total] > dp[s_prev] + min_hours_day[s_i]:
                    new_dp[s_total] = dp[s_prev] + min_hours_day[s_i]
        dp = new_dp

    ans = min(dp[:k + 1])
    print(ans)

main()
```

### Explanation
1. **Input Parsing**: The input is read and parsed into days, each represented by the hours Ivan has classes.
2. **Precompute Minimum Hours**: For each day, compute the minimum hours Ivan would spend for each possible number of skipped lessons. This is done by sliding a window over the sorted list of class hours to find the shortest interval for the remaining classes.
3. **Dynamic Programming**: Use a DP array where `dp[s]` represents the minimum hours spent if exactly `s` lessons are skipped. For each day, update the DP array by considering all possible skips for that day and combining them with previous results to ensure the total skips do not exceed `k`.

This approach efficiently explores all possible ways to skip lessons while minimizing the time spent at the university, ensuring an optimal solution within the given constraints.
