### Approach

2. **Efficiency Consideration**: Given the constraints, we need an efficient solution. Using sets to store characters from the Text allows for O(1) average-time complexity for membership checks. This approach ensures that we can check each character in the Pattern against the Text in linear time.
3. **Algorithm**:
   - For each test case, read the Text and Pattern strings.
   - Convert the Text into a set of characters for quick lookup.
   - Check each character in the Pattern against the set of characters from the Text.
   - If any character is found in both, print "YES"; otherwise, print "NO".

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        text = input[idx]
        pattern = input[idx + 1]
        idx += 2
        text_chars = set(text)
        found = False
        for c in pattern:
            if c in text_chars:
                found = True
                break
        print("YES" if found else "NO")

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read all at once and split into a list of strings for efficient processing. The first element of this list is the number of test cases.
- **Processing Each Test Case**: For each test case, the Text and Pattern strings are retrieved. The Text string is converted into a set of characters to allow O(1) average-time complexity for membership checks.
- **Checking Common Characters**: Each character in the Pattern is checked against the set of characters from the Text. If any character is found in both, the result is immediately "YES". If no common characters are found after checking all characters, the result is "NO".

This approach ensures that we efficiently determine the presence of any common substring between the two strings, leveraging set operations for optimal performance.
