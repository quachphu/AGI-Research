To solve this problem, we need to round an integer \( N \) to the nearest multiple of another integer \( B \). If \( N \) is exactly halfway between two multiples of \( B \), we return the larger multiple.

### Approach
1. **Understand the Problem**: We need to determine the closest multiple of \( B \) to \( N \). If \( N \) is equidistant from two multiples, we choose the larger one.
2. **Handle Absolute Values**: Since the multiples of \( B \) can be both positive and negative, we first consider the absolute value of \( B \) to simplify the calculation.
3. **Calculate Multiples**: Using integer division, we find the closest lower multiple of \( B \) (denoted as `base`). The next higher multiple is `base + B`.
4. **Determine Closest Multiple**: Compare the distances from \( N \) to `base` and the next higher multiple. If the distances are equal, return the larger multiple.

### Solution Code
```python
def round_multiple(N, B):
    B_abs = abs(B)
    if B_abs == 0:
        return 0  # Assuming B is non-zero as per problem constraints
    quotient = N // B_abs
    base = quotient * B_abs
    next_multiple = base + B_abs
    distance_base = abs(N - base)
    distance_next = abs(N - next_multiple)
    if distance_base < distance_next:
        return base
    elif distance_base > distance_next:
        return next_multiple
    else:
        return max(base, next_multiple)

def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        N = int(input[idx])
        B = int(input[idx + 1])
        idx += 2
        print(round_multiple(N, B))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read as a single string and split into a list of integers for easy processing.
2. **Processing Each Test Case**: For each test case, we extract \( N \) and \( B \).
3. **Calculating Absolute Value of \( B \)**: This simplifies finding multiples as we only deal with positive values initially.
4. **Finding Base and Next Multiple**: Using integer division, we determine the closest lower multiple (`base`) and the next higher multiple.
5. **Distance Comparison**: By comparing the distances from \( N \) to `base` and the next multiple, we decide the closest. In case of a tie, the larger multiple is chosen.

This approach ensures that we efficiently and correctly determine the nearest multiple of \( B \) for any given \( N \), adhering to the problem constraints and requirements.
