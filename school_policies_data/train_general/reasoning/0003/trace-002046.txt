3. **Iterative Check**: Iterate over all possible pairs (a, b) where 1 ≤ a ≤ b ≤ n. For each pair, compute c as a XOR b. Check if c is within bounds (b ≤ c ≤ n) and if the sides form a valid triangle (a + b > c).
