To solve this problem, we need to determine if the LCM of two given numbers has a prime number of distinct prime factors. Let's break down the approach to solve this problem efficiently.

### Approach
1. **Precompute Smallest Prime Factors (SPF):** Using the Sieve of Eratosthenes, precompute the smallest prime factor for every number up to \(10^6\). This allows us to quickly factorize any number into its prime factors.
2. **Calculate LCM:** For each pair of numbers (A, B), compute their LCM using the formula \(LCM(A, B) = \frac{A \times B}{GCD(A, B)}\), where GCD is found using the Euclidean algorithm.
3. **Factorize LCM:** Using the precomputed SPF array, factorize the LCM into its distinct prime factors.
4. **Check Prime Count:** Determine if the count of distinct prime factors is a prime number. If it is, the couple is considered "lovely".

### Solution Code
```python
import sys

def main():
    max_spf = 10**6
    spf = [0] * (max_spf + 1)
    
    for i in range(2, max_spf + 1):
        if spf[i] == 0:
            spf[i] = i
            for j in range(i * 2, max_spf + 1, i):
                if spf[j] == 0:
                    spf[j] = i

    input_data = sys.stdin.read().split()
    T = int(input_data[0])
    index = 1
    
    for _ in range(T):
        A = int(input_data[index])
        B = int(input_data[index + 1])
        index += 2
        
        a, b = A, B
        while b:
            a, b = b, a % b
        gcd = a
        lcm = (A * B) // gcd
        
        if lcm == 1:
            count = 0
        else:
            primes = set()
            n = lcm
            while n != 1:
                p = spf[n]
                primes.add(p)
                while n % p == 0:
                    n //= p
            count = len(primes)
        
        if count < 2:
            print("No")
        else:
            is_prime = True
            sqrt_count = int(count ** 0.5) + 1
            for i in range(2, sqrt_count):
                if count % i == 0:
                    is_prime = False
                    break
            print("Yes" if is_prime else "No")

if __name__ == "__main__":
    main()
```
