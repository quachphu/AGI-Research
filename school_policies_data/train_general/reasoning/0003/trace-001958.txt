To solve this problem, we need to determine if a given integer C lies between two other integers A and B, inclusive. Specifically, we need to check if C is not less than A and not greater than B.

### Approach
The solution involves a straightforward check of two conditions:
1. Whether C is greater than or equal to A.
2. Whether C is less than or equal to B.

If both conditions are satisfied, the answer is "Yes"; otherwise, the answer is "No". This approach directly follows the problem statement and efficiently checks the required conditions in constant time.

### Solution Code
```python
a, b, c = map(int, input().split())
if a <= c <= b:
    print("Yes")
else:
    print("No")
```

### Explanation
1. **Reading Input**: The input is read as three integers A, B, and C.
2. **Condition Check**: We check if C is between A and B inclusive. This is done using a single compound condition `a <= c <= b`, which ensures that C is both greater than or equal to A and less than or equal to B.
3. **Output Result**: Based on the condition check, we print "Yes" if C is within the specified range, otherwise "No".

This approach efficiently checks the required conditions in O(1) time complexity, making it optimal for the given constraints.
