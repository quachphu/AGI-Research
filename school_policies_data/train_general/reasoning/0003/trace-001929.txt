To solve this problem, we need to determine the maximum number of elements Eshag can delete from an array using a specific operation. The operation involves selecting a subsequence, calculating its average, and deleting all elements in the subsequence that are strictly larger than this average. 

### Approach
The key insight here is that elements equal to the minimum value in the array cannot be deleted. This is because any subsequence containing these minimum values will have an average that is at least the minimum value, so the minimum elements themselves will never be deleted. Therefore, the maximum number of elements that can be deleted is the total number of elements minus the count of the minimum elements in the array.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    min_val = min(a)
    count = a.count(min_val)
    print(n - count)
```

1. **Reading Input**: The code starts by reading the number of test cases.
2. **Processing Each Test Case**: For each test case, the code reads the length of the array and the array elements.
3. **Finding Minimum Value**: The minimum value in the array is determined using the `min` function.
4. **Counting Minimum Elements**: The number of occurrences of this minimum value is counted using the `count` method.
5. **Calculating Result**: The result for each test case is computed as the total number of elements minus the count of the minimum elements. This gives the maximum number of elements that can be deleted.

This approach efficiently determines the solution by leveraging the properties of the minimum value in the array, ensuring an optimal and correct solution.
