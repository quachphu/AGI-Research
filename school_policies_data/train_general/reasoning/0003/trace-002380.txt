import heapq
import sys

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    Q = int(input[ptr])
    ptr +=1
    
    lower = [] # max-heap (stored as min-heap with negatives)
    upper = [] # min-heap
    sum_lower = 0
    sum_upper =0
    sum_b =0
    
    for _ in range(Q):
        query = input[ptr]
        ptr +=1
        if query == '1':
            a = int(input[ptr])
            ptr +=1
            b = int(input[ptr])
            ptr +=1
            sum_b += b
            if not lower or a <= (-lower[0]):
                heapq.heappush(lower, -a)
                sum_lower += a
            else:
                heapq.heappush(upper, a)
                sum_upper += a
            # Balance the heaps
            # Ensure len(lower) is either equal to or one more than upper
            while len(lower) > len(upper) +1:
                # move from lower to upper
                val = -heapq.heappop(lower)
                sum_lower -= val
                heapq.heappush(upper, val)
                sum_upper += val
            while len(upper) > len(lower):
                # move from upper to lower
                val = heapq.heappop(upper)
                sum_upper -= val
                heapq.heappush(lower, -val)
                sum_lower += val
        else:
            # evaluation
            m = -lower[0]
            cnt_low = len(lower)
            cnt_high = len(upper)
            sum_abs = (m * cnt_low - sum_lower) + (sum_upper - m * cnt_high)
            total = sum_abs + sum_b
            print(m, total)

To solve this problem, we need to efficiently handle two types of queries on a function that starts as a constant zero. The function is modified by adding absolute value terms and constants through update queries, and we need to determine the minimum value of the function and the corresponding x value for evaluation queries.

### Approach
1. **Data Structures**: Use two heaps to maintain the median of the values efficiently. The lower half of values is stored in a max-heap (using a min-heap with negative values), and the upper half is stored in a min-heap.
2. **Tracking Sums**: Maintain the sum of all constants added to the function and the sums of the values in the lower and upper heaps to quickly compute the sum of absolute differences.
3. **Balancing Heaps**: After each insertion, ensure the heaps are balanced such that the lower heap has at most one more element than the upper heap. This ensures the median is always at the top of the lower heap.
4. **Efficient Queries**: For evaluation queries, compute the median from the lower heap and use the precomputed sums to determine the minimum function value.

### Solution Code
```python
import heapq
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    Q = int(input[ptr])
    ptr += 1

    lower = []  # max-heap implemented as min-heap with negatives
    upper = []  # min-heap
    sum_lower = 0
    sum_upper = 0
    sum_b = 0

    for _ in range(Q):
        query = input[ptr]
        ptr += 1
        if query == '1':
            a = int(input[ptr])
            ptr += 1
            b = int(input[ptr])
            ptr += 1
            sum_b += b

            if not lower or a <= -lower[0]:
                heapq.heappush(lower, -a)
                sum_lower += a
            else:
                heapq.heappush(upper, a)
                sum_upper += a

            # Balance the heaps
            while len(lower) > len(upper) + 1:
                val = -heapq.heappop(lower)
                sum_lower -= val
                heapq.heappush(upper, val)
                sum_upper += val
            while len(upper) > len(lower):
                val = heapq.heappop(upper)
                sum_upper -= val
                heapq.heappush(lower, -val)
                sum_lower += val
        else:
            m = -lower[0]
            cnt_low = len(lower)
            cnt_high = len(upper)
            sum_abs = (m * cnt_low - sum_lower) + (sum_upper - m * cnt_high)
            total = sum_abs + sum_b
            print(m, total)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Heaps for Median Tracking**: The lower heap (max-heap) and upper heap (min-heap) are used to maintain the median efficiently. The median is always the top element of the lower heap.
2. **Sum Tracking**: By maintaining sums of the elements in each heap and the sum of constants added, we can quickly compute the sum of absolute differences when needed.
3. **Balancing Heaps**: After each insertion, the heaps are rebalanced to ensure the lower heap's size is either equal to or one more than the upper heap's size. This allows efficient median computation.
4. **Efficiency**: Each insertion and balancing operation runs in O(log n) time, and each evaluation query runs in O(1) time, making the solution efficient for large input sizes up to 200,000 queries.
