To solve this problem, we need to determine the number of disconnected wall segments in a given 2D grid representation of a wall. Each segment is defined as a group of consecutive non-empty columns, where a column is considered non-empty if it contains at least one brick ('B').

### Approach
1. **Input Reading**: Read the dimensions of the grid (rows R and columns C) and the grid itself.
2. **Column Check**: For each column, check if there is at least one brick ('B') present. This helps in identifying non-empty columns.
3. **Segment Counting**: Traverse through each column and count the number of segments. A new segment starts whenever a non-empty column is encountered after an empty column.

### Solution Code
```python
R, C = map(int, input().split())
columns = [input().strip() for _ in range(R)]

non_empty = []
for c in range(C):
    has_brick = any(row[c] == 'B' for row in columns)
    non_empty.append(has_brick)

count = 0
prev_empty = True
for c in range(C):
    if non_empty[c]:
        if prev_empty:
            count += 1
            prev_empty = False
    else:
        prev_empty = True

print(count)
```

### Explanation
1. **Reading Input**: The first line of input contains the dimensions R (rows) and C (columns). The next R lines describe the grid.
2. **Checking Columns**: For each column, we determine if it contains any brick ('B'). This is done using a list comprehension combined with the `any()` function to check each row in the column.
3. **Counting Segments**: We iterate through each column. If a column is non-empty and the previous column was empty (or it's the first column), we increment the segment count. This ensures that consecutive non-empty columns are counted as a single segment.

This approach efficiently checks each column and counts the segments in linear time relative to the number of columns, making it both optimal and easy to understand.
