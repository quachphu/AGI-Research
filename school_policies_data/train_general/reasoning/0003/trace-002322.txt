To solve this problem, we need to determine the number of valid integer values for K such that exactly half of the problems are categorized as ARC (difficulty >= K) and the other half as ABC (difficulty < K). 

### Approach
1. **Sort the Difficulties**: First, we sort the list of problem difficulties in non-decreasing order.
2. **Identify Key Elements**: After sorting, the key elements are the middle two elements of the sorted list. Specifically, the element at position \(N/2 - 1\) and the element at position \(N/2\) in the 0-based index.
3. **Determine Valid Range for K**: The valid values for K must be greater than the element at position \(N/2 - 1\) and less than or equal to the element at position \(N/2\). The number of valid integers in this range is the difference between these two elements.

### Solution Code
```python
n = int(input())
d = list(map(int, input().split()))
d.sort()
print(d[n//2] - d[n//2 - 1])
```

### Explanation
1. **Sorting**: By sorting the list of difficulties, we can easily access the middle elements that divide the list into two equal parts.
2. **Middle Elements**: The element at index \(N/2 - 1\) (after sorting) is the maximum value of the first half (ABC problems), and the element at index \(N/2\) is the minimum value of the second half (ARC problems).
3. **Valid K Values**: The valid values for K are all integers between these two middle elements. The count of these integers is given by the difference between the two middle elements, which directly gives the solution.

This approach efficiently computes the result in \(O(N \log N)\) time due to the sorting step, which is optimal given the problem constraints.
