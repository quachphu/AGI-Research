To solve this problem, we need to form the maximum number of teams of three students, each from different subjects: programming, maths, and PE. Each team must consist of exactly one student from each subject. The solution involves counting the number of students in each subject and then forming teams by selecting one student from each subject until we can no longer form a complete team.

### Approach
1. **Count Students by Subject**: First, we categorize students into three lists based on their subject (programming, maths, PE).
2. **Determine Maximum Teams**: The maximum number of teams is determined by the minimum count among the three subject lists. This is because each team requires one student from each subject, and the smallest count limits the number of complete teams we can form.
3. **Form Teams**: Using the first `m` students from each subject list, where `m` is the minimum count, we form the teams. Each team consists of one student from each subject, taken in the order they appear in their respective lists.

### Solution Code
```python
n = int(input())
t = list(map(int, input().split()))

s1 = []
s2 = []
s3 = []

for idx, num in enumerate(t):
    if num == 1:
        s1.append(idx + 1)
    elif num == 2:
        s2.append(idx + 1)
    elif num == 3:
        s3.append(idx + 1)

m = min(len(s1), len(s2), len(s3))
print(m)
for i in range(m):
    print(s1[i], s2[i], s3[i])
```

### Explanation
1. **Reading Input**: The input consists of the number of students and their respective subjects. We read these values and store the subjects in a list.
2. **Categorizing Students**: We iterate through the list of subjects and categorize each student's index into one of three lists based on their subject (programming, maths, or PE).
3. **Calculating Maximum Teams**: The maximum number of teams (`m`) is the minimum of the lengths of the three subject lists.
4. **Forming and Printing Teams**: For each of the `m` teams, we take the next available student from each subject list and print their indices. This ensures that each team has one student from each subject.

This approach efficiently categorizes students and forms the maximum number of valid teams, ensuring that each team is composed of students from different subjects. The solution is optimal and runs in linear time relative to the number of students, making it suitable for large input sizes up to 5000 students.
