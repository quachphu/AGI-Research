To solve this problem, we need to determine the number of valid combinations of three distinct integers from 1 to n that sum up to a given value x. The solution involves iterating through all possible triplets (a, b, c) where a < b < c and checking if their sum equals x.

### Approach
1. **Input Handling**: Read input lines until encountering "0 0", which signals the end of input.
2. **Triplet Generation**: For each dataset (n, x), generate all possible triplets (a, b, c) such that 1 ≤ a < b < c ≤ n.
3. **Sum Check**: For each generated triplet, check if the sum of the triplet equals x. If it does, increment the count.
4. **Output Result**: Print the count of valid triplets for each dataset.

### Solution Code
```python
def count_combinations(n, x):
    count = 0
    for a in range(1, n - 1):
        for b in range(a + 1, n):
            for c in range(b + 1, n + 1):
                if a + b + c == x:
                    count += 1
    return count

import sys

for line in sys.stdin:
    line = line.strip()
    if not line:
        continue
    n, x = map(int, line.split())
    if n == 0 and x == 0:
        break
    print(count_combinations(n, x))
```

### Explanation
1. **Input Handling**: The code reads each line from standard input. If the line contains "0 0", the loop terminates.
2. **Triplet Generation**: The nested loops ensure that a < b < c by iterating a from 1 to n-2, b from a+1 to n-1, and c from b+1 to n. This guarantees that each triplet is unique and ordered.
3. **Sum Check**: For each triplet (a, b, c), the sum is checked against x. If they match, the count is incremented.
4. **Efficiency**: The approach efficiently generates and checks all possible triplets using three nested loops, which is feasible given the constraint 3 ≤ n ≤ 100, resulting in a maximum of 161700 iterations (C(100, 3)).

This approach ensures that all valid combinations are checked efficiently and correctly, providing the required solution for each input dataset.
