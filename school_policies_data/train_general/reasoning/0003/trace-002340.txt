To solve this problem, we need to determine the number of valid TV screen dimensions (width and height) that meet given constraints on maximum width, maximum height, and a specific aspect ratio. The solution involves mathematical insights and efficient computation to handle very large numbers.

### Approach
1. **Simplify the Aspect Ratio**: The given aspect ratio (x:y) should be reduced to its simplest form by dividing both x and y by their greatest common divisor (GCD). This gives us the smallest integers that maintain the same ratio.
2. **Determine Valid Multipliers**: For the simplified aspect ratio (x', y'), the valid dimensions (w, h) can be expressed as multiples of x' and y' respectively. We need to find the maximum integer k such that k*x' ≤ a and k*y' ≤ b. The valid k values are constrained by both the maximum width and height, so the maximum valid k is the minimum of the two possible values derived from these constraints.
3. **Compute the Result**: The result is the count of valid k values, which is the minimum of the two computed values. If this minimum is non-positive, the result is zero as there are no valid dimensions.

### Solution Code
```python
import math

a, b, x, y = map(int, input().split())

g = math.gcd(x, y)
x_prime = x // g
y_prime = y // g

max_k_x = a // x_prime
max_k_y = b // y_prime

result = min(max_k_x, max_k_y)
print(max(0, result))
```

### Explanation
1. **Simplifying the Aspect Ratio**: By dividing x and y by their GCD, we get the smallest integers (x', y') that represent the same aspect ratio. This step ensures we consider all possible multiples of these base dimensions.
2. **Calculating Maximum Valid k**: The maximum valid k for width is `a // x_prime` and for height is `b // y_prime`. These values represent how many times the base dimensions can fit into the given maximum width and height.
3. **Result Calculation**: The valid number of dimensions is determined by the minimum of the two maximum k values, ensuring both width and height constraints are satisfied. If this minimum is non-positive, it means no valid dimensions exist, hence the result is zero.

This approach efficiently handles the large input constraints using mathematical properties and integer division, ensuring optimal performance even for the upper limits of the input values.
