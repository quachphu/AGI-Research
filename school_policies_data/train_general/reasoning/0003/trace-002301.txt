To solve this problem, we need to transform a given integer into the smallest possible positive number by inverting some of its digits. Inverting a digit means replacing it with `9 - digit`, but the resulting number must not start with a zero.

### Approach
1. **Problem Analysis**:
   - Each digit can be inverted to `9 - digit`.
   - The transformed number must not start with a zero.
   - The goal is to minimize the number by choosing the smallest possible digit at each position, considering the inversion rule.

2. **Key Insights**:
   - For the first digit, we must ensure it does not become zero. Thus, we compare the digit with its inverted value and choose the smaller one, provided the inverted value is not zero.
   - For subsequent digits, we can freely choose the smaller value between the digit and its inverted value, as leading zeros are only a concern for the first digit.

3. **Algorithm**:
   - Convert the input number to a string to process each digit individually.
   - For the first digit, check if it is 9 (cannot invert to 0) or if its inverted value is smaller and non-zero.
   - For other digits, simply choose the smaller value between the digit and its inverted value.

### Solution Code
```python
def main():
    x = input().strip()
    result = []
    for i in range(len(x)):
        d = int(x[i])
        if i == 0:
            if d == 9:
                result.append(str(d))
            else:
                inv = 9 - d
                if inv < d and inv != 0:
                    result.append(str(inv))
                else:
                    result.append(str(d))
        else:
            inv = 9 - d
            if inv < d:
                result.append(str(inv))
            else:
                result.append(str(d))
    print(''.join(result))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read as a string to handle each digit separately.
2. **Processing Each Digit**:
   - **First Digit**: Special handling to avoid leading zeros. If the digit is 9, it remains 9. Otherwise, compare the digit with its inverted value (if non-zero) and choose the smaller.
   - **Subsequent Digits**: Compare each digit with its inverted value and choose the smaller, as leading zeros are not a concern here.
3. **Constructing Result**: Collect the optimized digits and join them to form the final result, which is printed.

This approach ensures the smallest possible number is formed while adhering to the constraint of no leading zeros, efficiently processing each digit in linear time.
