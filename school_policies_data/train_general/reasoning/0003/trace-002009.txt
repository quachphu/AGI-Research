To solve this problem, we need to determine if there can be exactly X cats among A + B animals, where A are confirmed cats and the remaining B can be either cats or dogs. 

### Approach
The key insight is to recognize that the number of cats must be at least A (if all B animals are dogs) and at most A + B (if all B animals are cats). Therefore, the solution involves checking if X lies within this inclusive range [A, A + B].

### Solution Code
```python
def main():
    import sys
    A, B, X = map(int, sys.stdin.readline().split())
    if A <= X <= A + B:
        print("YES")
    else:
        print("NO")

main()
```

### Explanation
1. **Reading Input**: The input values A, B, and X are read from standard input.
2. **Range Check**: The code checks if X is within the range [A, A + B]. This range is derived from the minimum possible number of cats (all B animals are dogs) and the maximum possible number of cats (all B animals are cats).
3. **Output Result**: If X is within the valid range, the result is "YES"; otherwise, it is "NO".

This approach efficiently determines the possibility of having exactly X cats by leveraging a simple range check, ensuring an optimal solution with constant time complexity.
