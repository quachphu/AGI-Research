To solve this problem, we need to determine how many people are denied service at a restaurant based on the availability of one-seater and two-seater tables. The groups of people arrive in a specific order, and each group must be seated according to predefined rules.

### Approach
1. **Initialization**: Start with the given number of one-seater (a) and two-seater (b) tables. Track the number of two-seater tables that have one person (half_occupied) and the number of people denied service (denied).

2. **Processing Each Group**:
   - **Single Person (Group of 1)**:
     - Use a one-seater table if available.
     - If no one-seater tables are available, use a vacant two-seater table, converting it to a half-occupied table.
     - If no vacant two-seater tables are available, use a half-occupied table.
     - If all options are exhausted, deny service to this person.
   - **Two People (Group of 2)**:
     - Use a vacant two-seater table if available.
     - If no vacant two-seater tables are available, deny service to both people.

3. **Iterate Through Groups**: Process each group in the given order, updating the counts of available tables and denied people accordingly.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = int(input[1])
    b = int(input[2])
    groups = list(map(int, input[3:3 + n]))
    
    denied = 0
    half_occupied = 0
    
    for group in groups:
        if group == 1:
            if a > 0:
                a -= 1
            else:
                if b > 0:
                    b -= 1
                    half_occupied += 1
                elif half_occupied > 0:
                    half_occupied -= 1
                else:
                    denied += 1
        else:
            if b > 0:
                b -= 1
            else:
                denied += 2
    print(denied)

main()
```

### Explanation
- **Reading Input**: The input is read and parsed into the number of groups (n), the number of one-seater tables (a), two-seater tables (b), and the list of groups.
- **Processing Groups**: Each group is processed in order. For single-person groups, priority is given to one-seater tables, then vacant two-seater tables, and finally half-occupied tables. For two-person groups, only vacant two-seater tables are used.
- **Updating Counts**: The counts of available tables (a, b) and half-occupied tables (half_occupied) are updated dynamically as each group is processed. If a group cannot be seated, the number of denied people is incremented accordingly.

This approach efficiently tracks the state of the tables and ensures that each group is seated according to the rules, minimizing the number of people denied service.
