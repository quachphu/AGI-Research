Each dataset consists of sales data from five stores (A, B, C, D, E) for a single day, reported as morning and afternoon sales. The goal is to compute the total sales for each store, identify the store with the highest total sales, and output its name along with the total sales.

### Approach
1. **Input Handling**: Read all input lines until two consecutive lines of "0 0" are encountered, indicating the end of the input.
2. **Data Parsing**: Split the input into datasets, each containing exactly five lines of sales data.
3. **Total Sales Calculation**: For each store in a dataset, compute the total daily sales by summing the morning and afternoon sales.
4. **Determine Maximum Sales**: Identify the store with the highest total sales for each dataset.
5. **Output Results**: Print the name of the store with the highest sales and the corresponding total sales for each dataset.

### Solution Code
```python
import sys

def main():
    lines = []
    for line in sys.stdin:
        stripped = line.strip()
        if not stripped:
            continue
        lines.append(stripped)
    
    # Find the end marker (two consecutive '0 0' lines)
    end_idx = None
    for i in range(len(lines) - 1):
        if lines[i] == '0 0' and lines[i+1] == '0 0':
            end_idx = i
            break
    
    data_lines = lines[:end_idx] if end_idx is not None else lines
    
    # Split into datasets of 5 lines each
    num_datasets = len(data_lines) // 5
    datasets = [data_lines[i*5 : (i+1)*5] for i in range(num_datasets)]
    
    for dataset in datasets:
        max_total = -1
        max_store = ''
        for idx, line in enumerate(dataset):
            s1, s2 = map(int, line.split())
            total = s1 + s2
            if total > max_total:
                max_total = total
                max_store = chr(ord('A') + idx)
        print(f"{max_store} {max_total}")

if __name__ == "__main__":
    main()
```

3. **Calculating Totals**: For each store in a dataset, the total sales are computed by summing the morning and afternoon sales. The store with the highest total sales is tracked.
4. **Output**: After processing each dataset, the store with the highest sales and the corresponding total sales are printed.
