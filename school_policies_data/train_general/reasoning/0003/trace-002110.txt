To solve this problem, we need to maximize the total number of ingredients that Snuke's N servings of Skewer Meal can hold. Each serving uses two skewers, and the number of ingredients each serving can hold is determined by the shorter skewer. Therefore, the goal is to pair the skewers optimally to maximize the sum of the shorter skewers in each pair.

### Approach
1. **Sort the Skewers**: By sorting the list of skewers in non-decreasing order, we can efficiently pair the skewers to maximize the sum of the shorter ones in each pair.
2. **Pair Adjacent Skewers**: After sorting, the optimal way to pair the skewers is to take adjacent pairs. This is because the shorter skewer in each adjacent pair will be as large as possible, given the sorted order.
3. **Sum the Shorter Skewers**: The shorter skewer in each adjacent pair will be the first element of each pair. Summing these elements will give the maximum total number of ingredients.

### Solution Code
```python
n = int(input())
lst = list(map(int, input().split()))
lst.sort()
total = sum(lst[i] for i in range(0, 2 * n, 2))
print(total)
```

### Explanation
1. **Reading Input**: The input consists of an integer N and a list of 2N integers representing the lengths of the skewers.
2. **Sorting the List**: By sorting the list of skewers, we ensure that each adjacent pair will have the shortest possible difference in lengths, which helps in maximizing the sum of the shorter ones.
3. **Summing the Shorter Skewers**: By iterating through the sorted list and summing every other element starting from the first (0th index), we effectively sum the shorter skewer of each adjacent pair. This approach ensures that we are using the optimal pairing strategy to maximize the total number of ingredients.

This method efficiently computes the maximum total number of ingredients with a time complexity dominated by the sorting step, which is O(2N log 2N), making it suitable for the given constraints.
