To solve this problem, we need to determine the subnet mask such that when applied to a list of given IP addresses, it results in exactly `k` distinct networks. If there are multiple valid subnet masks, we choose the one with the least number of leading ones in its binary representation.

### Approach
1. **Convert IP Addresses to Integers**: Each IP address is converted into a 32-bit integer for easier bitwise operations.
2. **Generate Subnet Masks**: For each possible number of leading ones (from 1 to 31), generate the corresponding subnet mask. This mask is represented as a 32-bit integer.
3. **Calculate Networks**: For each subnet mask, compute the network addresses by applying the mask to each IP address. Track the number of unique network addresses.
4. **Check Validity**: If a subnet mask results in exactly `k` unique networks, record it. Among all valid masks, select the one with the smallest number of leading ones (smallest mask value).

### Solution Code
```python
import sys

def ip_to_int(ip):
    a, b, c, d = map(int, ip.split('.'))
    return (a << 24) | (b << 16) | (c << 8) | d

def int_to_ip(num):
    return '.'.join(str((num >> (24 - i * 8)) & 0xFF) for i in range(4))

def main():
    n, k = map(int, sys.stdin.readline().split())
    ips = [ip_to_int(line.strip()) for line in sys.stdin.read().splitlines()[:n]]
    
    possible_m = []
    for m in range(1, 32):
        mask = (((1 << m) - 1) << (32 - m)) & 0xFFFFFFFF
        networks = set()
        for ip in ips:
            networks.add(ip & mask)
        if len(networks) == k:
            possible_m.append(m)
    
    if not possible_m:
        print(-1)
        return
    
    best_m = min(possible_m)
    best_mask = (((1 << best_m) - 1) << (32 - best_m)) & 0xFFFFFFFF
    print(int_to_ip(best_mask))

if __name__ == "__main__":
    main()
```
