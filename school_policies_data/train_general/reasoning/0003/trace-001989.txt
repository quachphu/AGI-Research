2. **Key Insight**: The number with the maximum set bits is often the one where the highest possible bits are set. For example, numbers like 7 (111 in binary) have more set bits than numbers like 8 (1000 in binary).
3. **Algorithm**:
   - Start with the upper bound of the range, `r`, as the initial candidate.
   - For each bit position from the highest (59th bit, considering the maximum value of 10^18) down to the lowest (0th bit):
     - If the current candidate has this bit set, create a new candidate by flipping this bit to 0 and setting all lower bits to 1.
     - Check if this new candidate is within the range [l, r]. If it is, compare its number of set bits with the current candidate. Update the candidate if the new one has more set bits or the same number of set bits but is smaller.

    n = int(input[0])
    idx = 1

            if (x >> i) & 1:

                mask = (1 << i) - 1
                candidate = (x & ~(1 << i)) | mask
