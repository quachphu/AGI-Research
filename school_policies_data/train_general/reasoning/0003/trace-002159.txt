To solve this problem, we need to convert a given integer N into a specific string format similar to how columns are labeled in Excel, but starting from 'a' for 1. The conversion process involves a modified base-26 calculation where each digit ranges from 1 to 26, corresponding to 'a' to 'z' respectively.

### Approach
The key insight is to recognize that this problem can be approached using a modified base-26 conversion. However, unlike the standard base-26 system, here each digit is 1-based instead of 0-based. This means we need to adjust the number by subtracting 1 before each division step to correctly map the remainder to the corresponding letter.

1. **Subtract 1 from N**: This adjustment is necessary to handle the 1-based indexing of the letters.
2. **Compute the remainder**: The remainder after dividing by 26 gives the current character.
3. **Convert remainder to character**: Map the remainder (0-25) to 'a'-'z' using ASCII values.
4. **Update N**: Divide N by 26 and repeat the process until N becomes zero.
5. **Build the result string**: Characters are prepended to the result string to maintain the correct order.

### Solution Code
```python
def main():
    n = int(input())
    result = ''
    while n > 0:
        n -= 1
        remainder = n % 26
        result = chr(97 + remainder) + result
        n = n // 26
    print(result)

main()
```

### Explanation
1. **Reading Input**: The input integer N is read from standard input.
2. **Loop Until N is Zero**: We repeatedly process N until it becomes zero.
3. **Adjust N**: Subtract 1 from N to handle 1-based indexing.
4. **Compute Remainder**: The remainder when adjusted N is divided by 26 gives the current character.
5. **Convert to Character**: The remainder is converted to a character using ASCII values (97 is the ASCII code for 'a').
6. **Update Result**: The computed character is prepended to the result string to build the correct order.
7. **Update N**: N is updated by integer division by 26, preparing it for the next iteration.

This approach efficiently converts the number to the desired string format in O(log N) time complexity, which is optimal for large values of N up to 10^15.
