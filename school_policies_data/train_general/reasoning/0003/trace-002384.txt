To solve this problem, we need to determine the minimum cost to purchase chemical packages such that the ratio of substances A and B matches a given ratio \( M_a : M_b \). If it's not possible to achieve this ratio, we should return -1.

### Approach
1. **Dynamic Programming (DP) Setup**: We use a 2D DP array where `dp[a][b]` represents the minimum cost to obtain exactly `a` grams of substance A and `b` grams of substance B.
2. **Initialization**: Start with `dp[0][0] = 0` since no cost is incurred with zero substances. All other entries are initialized to infinity to represent initially unreachable states.
3. **Processing Packages**: For each chemical package, update the DP array by considering both including and excluding the package. This ensures we explore all possible subsets of packages.
4. **Check Valid Ratios**: After processing all packages, check all possible sums of substances A and B to find those that match the required ratio \( M_a : M_b \). Track the minimum cost for valid ratios.

            if a * M_b == b * M_a:
