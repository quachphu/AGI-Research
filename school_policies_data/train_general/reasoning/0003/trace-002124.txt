To solve this problem, we need to determine if a given undirected graph can be classified as Cthulhu. A Cthulhu graph is defined as a connected graph with exactly one cycle, which must have at least three nodes. The graph should have exactly as many edges as nodes, forming a structure where the cycle connects the roots of three or more trees.

### Approach
1. **Check Edge Count**: The graph must have exactly the same number of edges as nodes (m = n). If not, it cannot be a Cthulhu graph.
2. **Check Connectivity**: The graph must be connected. This means there must be a path from any node to any other node.
3. **Cycle Check**: By ensuring the graph is connected and has exactly n edges, we implicitly confirm the presence of exactly one cycle. Given the problem constraints (no self-loops or multiple edges), this cycle must have at least three nodes.

### Solution Code
```python
import sys
from collections import deque

def main():
    n, m = map(int, sys.stdin.readline().split())
    if m != n:
        print("NO")
        return
    
    # Build adjacency list
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, sys.stdin.readline().split())
        adj[u].append(v)
        adj[v].append(u)
    
    visited = [False] * (n + 1)
    q = deque()
    q.append(1)
    visited[1] = True
    count = 1
    
    while q:
        u = q.popleft()
        for v in adj[u]:
            if not visited[v]:
                visited[v] = True
                count += 1
                q.append(v)
    
    if count == n:
        print("FHTAGN!")
    else:
        print("NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Edge Count Check**: The code first checks if the number of edges (m) is equal to the number of nodes (n). If not, it immediately prints "NO".
2. **Adjacency List Construction**: The graph is represented using an adjacency list to efficiently store and traverse edges.
3. **BFS for Connectivity**: Using Breadth-First Search (BFS), the code checks if all nodes are reachable starting from node 1. If all nodes are visited, the graph is connected.
4. **Result Determination**: If the graph is connected and meets the edge count condition, it prints "FHTAGN!". Otherwise, it prints "NO".

This approach ensures that we efficiently determine the graph's structure and connectivity, adhering to the problem constraints and requirements.
