To solve this problem, we need to find the K-th largest positive integer that divides both given integers A and B. The solution involves computing the greatest common divisor (GCD) of A and B, then determining all divisors of this GCD, and finally selecting the K-th largest divisor from the sorted list of divisors.

### Approach
1. **Compute the GCD**: The first step is to compute the GCD of the given integers A and B. This GCD is crucial because all common divisors of A and B are exactly the divisors of their GCD.
2. **Find Divisors of GCD**: Next, we find all divisors of the computed GCD. This can be efficiently done by iterating from 1 up to the square root of the GCD, checking for divisibility, and collecting both the divisor and its complement.
3. **Sort Divisors**: Once all divisors are collected, they are sorted in descending order to facilitate the selection of the K-th largest element.
4. **Select K-th Largest Divisor**: Finally, we select the (K-1)-th element from the sorted list (since the list is 0-indexed in Python).

### Solution Code
```python
import math

def main():
    import sys
    A, B, K = map(int, sys.stdin.readline().split())
    g = math.gcd(A, B)
    divisors = set()
    for i in range(1, int(math.sqrt(g)) + 1):
        if g % i == 0:
            divisors.add(i)
            divisors.add(g // i)
    sorted_divisors = sorted(divisors, reverse=True)
    print(sorted_divisors[K-1])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input values A, B, and K are read from standard input.
2. **Computing GCD**: Using Python's `math.gcd` function, we compute the GCD of A and B.
3. **Finding Divisors**: We iterate from 1 to the integer square root of the GCD. For each number in this range, if it divides the GCD without a remainder, both the number and its complement (GCD divided by the number) are added to a set to avoid duplicates.
4. **Sorting and Selecting**: The divisors are converted to a list, sorted in descending order, and the K-th largest divisor is selected using (K-1) as the index due to 0-based indexing in Python lists.

This approach ensures that we efficiently compute the required result by leveraging mathematical properties of divisors and the GCD, making the solution both optimal and easy to understand.
