To solve this problem, we need to count the number of different paths from the bottom-left corner (1, 1) to the top-right corner (n, m) of a grid, moving only right or up, that pass through exactly i special fields for each i from 0 to k. The solution must be computed modulo 1000007.

### Approach
1. **Dynamic Programming (DP) Setup**: Use a 3D DP array `dp[r][c][s]` where `dp[r][c][s]` represents the number of paths from (1, 1) to (r, c) that pass through exactly `s` special fields.
2. **Initialization**: Start from the bottom-left corner (1, 1). If this cell is a special field, initialize `dp[1][1][1]` to 1; otherwise, initialize `dp[1][1][0]` to 1.
3. **Transition**: For each cell (r, c), compute the number of paths considering the paths from the left cell (r, c-1) and the cell below (r-1, c). Adjust the count of special fields based on whether the current cell is a special field.
4. **Modulo Operation**: Ensure all operations are performed modulo 1000007 to handle large numbers and prevent overflow.

### Solution Code
```python
MOD = 1000007

n, m, k = map(int, input().split())
special = set()
for _ in range(k):
    r, c = map(int, input().split())
    special.add((r, c))

# Initialize DP table
dp = [[[0] * (k + 1) for _ in range(m + 1)] for __ in range(n + 1)]

# Base case: starting cell (1,1)
if (1, 1) in special:
    dp[1][1][1] = 1
else:
    dp[1][1][0] = 1

for r in range(1, n + 1):
    for c in range(1, m + 1):
        if r == 1 and c == 1:
            continue  # already handled
        is_sp = 1 if (r, c) in special else 0
        for s in range(k + 1):
            total = 0
            # Check the cell above (r-1, c)
            if r > 1:
                prev_s = s - is_sp
                if 0 <= prev_s <= k:
                    total += dp[r-1][c][prev_s]
            # Check the cell to the left (r, c-1)
            if c > 1:
                prev_s = s - is_sp
                if 0 <= prev_s <= k:
                    total += dp[r][c-1][prev_s]
            dp[r][c][s] = total % MOD

# Collect the results for the top-right corner (n, m)
result = dp[n][m][:k+1]
print(' '.join(map(str, result)))
```

1. **Input Reading**: Read the grid dimensions and the list of special fields.
2. **DP Initialization**: Initialize the DP array and set the base case for the starting cell (1, 1).
3. **DP Transition**: For each cell (r, c), compute the number of paths by considering paths from the left and below, adjusting the count of special fields based on whether the current cell is special.
4. **Result Extraction**: Extract the results from the DP table for the top-right corner (n, m) for all counts of special fields from 0 to k.

This approach efficiently computes the number of valid paths using dynamic programming, ensuring correctness and efficiency within the given constraints.
