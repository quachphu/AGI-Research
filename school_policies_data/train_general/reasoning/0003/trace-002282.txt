### Approach
1. **Problem Analysis**: A subarray is non-decreasing if each element is less than or equal to the next. We need an efficient way to count all such subarrays.
2. **Key Insight**: For each element in the array, determine the length of the longest non-decreasing subarray ending at that element. This length directly gives the count of valid subarrays ending at that position.
3. **Algorithm**:
   - Traverse the array starting from the second element.
   - For each element, if it is greater than or equal to the previous element, extend the current non-decreasing subarray length by 1.
   - If it is smaller, reset the current subarray length to 1 (since each element itself is a valid subarray).
   - Sum these lengths to get the total count of non-decreasing subarrays.

def count_non_decreasing_subarrays():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        arr = list(map(int, input[ptr:ptr + N]))
        ptr += N
        total = 1
        current = 1
        for i in range(1, N):
            if arr[i] >= arr[i-1]:
                current += 1
            else:
                current = 1
            total += current
        print(total)

1. **Reading Input**: The input is read all at once for efficiency, especially for large inputs. The input is split into a list of strings and processed using a pointer.
2. **Processing Each Test Case**:

   - Initialize `total` and `current` to 1, as the first element is a valid subarray.
   - Traverse the array from the second element. For each element, update `current` based on whether the current element continues the non-decreasing sequence or not.
