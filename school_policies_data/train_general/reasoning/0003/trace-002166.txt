To solve this problem, we need to determine if two submitted programs are identical, close, or different based on their structure and string literals. The key is to identify if the programs differ only in one corresponding string literal, which would classify them as close. If they are exactly the same, they are identical. Otherwise, they are different.

### Approach
1. **Parsing the Programs**: Split each program into tokens where each token alternates between non-string parts and string literals. Non-string parts are segments outside quotes, while string literals are the content within quotes, including the quotes themselves.
2. **Comparison**: Compare the parsed tokens of the two programs:
   - If the number of tokens differs, the programs are different.
   - Check all non-string tokens for equality. If any non-string token differs, the programs are different.
   - Count the number of differing string literals. If exactly one string literal differs, the programs are close. If none differ, they are identical. Otherwise, they are different.

### Solution Code
```python
def parse(s):
    tokens = []
    mode = 'non-string'
    current = ''
    for c in s:
        if mode == 'non-string':
            if c == '"':
                tokens.append(current)
                current = c
                mode = 'string'
            else:
                current += c
        else:
            current += c
            if c == '"':
                tokens.append(current)
                current = ''
                mode = 'non-string'
    if mode == 'non-string' and current:
        tokens.append(current)
    return tokens

def judge(s1, s2):
    t1 = parse(s1)
    t2 = parse(s2)
    if len(t1) != len(t2):
        return "DIFFERENT"
    for i in range(0, len(t1), 2):
        if i >= len(t1):
            break
        if t1[i] != t2[i]:
            return "DIFFERENT"
    diff = 0
    for i in range(1, len(t1), 2):
        if t1[i] != t2[i]:
            diff += 1
    if diff == 0:
        return "IDENTICAL"
    elif diff == 1:
        return "CLOSE"
    else:
        return "DIFFERENT"

def main():
    import sys
    while True:
        line = sys.stdin.readline().rstrip('\n')
        if line == '.':
            break
        s1 = line
        s2 = sys.stdin.readline().rstrip('\n')
        print(judge(s1, s2))

if __name__ == '__main__':
    main()
```

### Explanation
1. **Parsing**: The `parse` function processes each program to split it into tokens. It alternates between collecting non-string parts and string literals. Each time a quote is encountered, it switches modes and starts collecting the next segment.
2. **Judging**: The `judge` function compares the parsed tokens of the two programs:
   - It first checks if the number of tokens is the same.
   - It then checks all non-string parts (even indices) for equality.
   - Finally, it counts the differing string literals (odd indices) to determine if the programs are identical, close, or different.

This approach ensures that we efficiently and accurately determine the relationship between the two submitted programs based on their structure and content.
