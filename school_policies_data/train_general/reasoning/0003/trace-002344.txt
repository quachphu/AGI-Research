To solve this problem, we need to determine the x-th remaining number after performing a specific algorithm on a list of numbers from 1 to n. The algorithm involves removing elements in a stepwise manner until it is no longer possible to continue. The key insight is to recognize a pattern in the remaining elements after the algorithm stops.

### Approach
1. **Understanding the Algorithm**: The algorithm removes the i-th element in the i-th step. This process continues until the number of remaining elements is less than the step number. 
2. **Pattern Recognition**: Through analysis, we observe that after the algorithm stops, the remaining elements are the even numbers starting from 2. This is because each step removes an element from the current list, effectively leaving all even numbers in their original order.
3. **Mathematical Insight**: The x-th remaining element is simply twice the value of x. This is because the remaining elements after the algorithm stops are the even numbers in sequence (2, 4, 6, ...).

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        n = int(input[idx])
        x = int(input[idx + 1])
        idx += 2
        print(2 * x)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
- **Processing Each Query**: For each query, we directly compute the result using the insight that the x-th remaining element is always twice the value of x. This avoids the need for simulating the entire removal process, which would be computationally infeasible for large values of n.
- **Output the Result**: The result for each query is computed in constant time O(1), making the solution very efficient even for the upper constraint limits.

This approach leverages the observed pattern to provide an optimal solution with a time complexity of O(T), where T is the number of queries, ensuring quick execution even for large input sizes.
