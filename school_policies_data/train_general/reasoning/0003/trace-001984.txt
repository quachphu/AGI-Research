To solve this problem, we need to determine if there exist three distinct indices \(i, j, k\) such that the length of the worm at index \(i\) is the sum of the lengths of the worms at indices \(j\) and \(k\). If such indices exist, we should return them; otherwise, we return -1.

### Approach
1. **Input Reading**: Read the number of worm forms and their respective lengths.
2. **Preprocessing**: Create a dictionary mapping each worm length to the list of indices where it occurs. This helps in quickly checking if a required value exists and accessing its indices.
3. **Triple Loop Check**: For each possible index \(i\), check all pairs of indices \(j\) and \(k\) such that \(i\), \(j\), and \(k\) are distinct and the length at \(i\) is the sum of the lengths at \(j\) and \(k\). This is done efficiently by iterating through each possible \(i\) and \(j\), computing the required target value for \(k\), and checking if this target exists in the dictionary.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    value_to_indices = defaultdict(list)
    for idx, num in enumerate(a):
        value_to_indices[num].append(idx)
    for i in range(n):
        for j in range(n):
            if i == j:
                continue
            target = a[i] - a[j]
            if target not in value_to_indices:
                continue
            for k in value_to_indices[target]:
                if k != i and k != j:
                    print(i + 1, j + 1, k + 1)
                    return
    print(-1)

main()
```

### Explanation
1. **Input Reading**: The input is read using standard input functions. The first line gives the number of worm forms, and the second line gives the lengths of these forms.
2. **Preprocessing with Dictionary**: A dictionary `value_to_indices` is created where each key is a worm length, and the value is a list of indices where this length occurs. This allows quick look-up of indices for any given length.
3. **Checking Triples**: For each index \(i\), iterate through all possible indices \(j\) (excluding \(i\)). For each pair \((i, j)\), compute the target value needed for \(k\) as \(a[i] - a[j]\). Check if this target exists in the dictionary. If it does, iterate through all indices where this target value occurs and check if any of these indices are valid (i.e., not equal to \(i\) or \(j\)). If a valid \(k\) is found, print the indices and exit. If no valid triplet is found after all checks, print -1.

This approach efficiently checks all possible triplets using a dictionary for quick look-up, ensuring that the solution is both correct and optimal for the given constraints.
