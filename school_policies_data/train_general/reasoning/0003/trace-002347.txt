To solve this problem, we need to correct words that were typed with the Caps Lock key accidentally switched on. The correction involves changing the case of each letter in the word if it meets specific conditions. 

### Approach
1. **Identify Conditions**: The word is considered to have been typed with Caps Lock on if:
   - All characters are uppercase.
   - The first character is lowercase and all subsequent characters are uppercase.

2. **Invert Case**: If either condition is met, invert the case of each character in the word. If neither condition is met, leave the word unchanged.

3. **Check Conditions**: Use string methods to check if the entire word is uppercase or if the first character is lowercase with the rest being uppercase.

4. **Process the Word**: Based on the conditions, either invert the case of each character or leave the word as it is.

### Solution Code
```python
def process_word():
    word = input().strip()
    if (word == word.upper()) or (word[0].islower() and word[1:] == word[1:].upper()):
        processed = ''.join([c.lower() if c.isupper() else c.upper() for c in word])
        print(processed)
    else:
        print(word)

process_word()
```

### Explanation
1. **Reading Input**: The function reads a single word from standard input.
2. **Condition Checks**: 
   - The first condition checks if the entire word is uppercase using `word == word.upper()`.
   - The second condition checks if the first character is lowercase and the rest are uppercase using `word[0].islower()` and `word[1:] == word[1:].upper()`.
3. **Case Inversion**: If either condition is true, each character's case is inverted using a list comprehension. This is done by converting each uppercase character to lowercase and each lowercase character to uppercase.
4. **Output**: The processed word is printed if conditions are met; otherwise, the original word is printed.

This approach ensures that words accidentally typed with Caps Lock are corrected efficiently while leaving other words unchanged.
