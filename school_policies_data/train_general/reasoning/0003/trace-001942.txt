To solve this problem, we need to determine the minimum number of turns Hongcow needs to purchase all cards from the store. Each turn can either be collecting tokens (which gives 1 red and 1 blue token) or buying a card. The cost of each card depends on the number of red and blue cards Hongcow has already purchased. The goal is to minimize the total number of turns required.

### Approach
1. **Dynamic Programming (DP) with Bitmasking**: We use a bitmask to represent the set of cards that have been purchased. Each bit in the mask corresponds to a card, where a bit set to 1 indicates the card has been bought.
2. **State Tracking**: For each bitmask (state), we track the minimum number of red and blue tokens required to reach that state. This helps in efficiently determining the optimal order of purchasing cards.
3. **Non-Dominated Pairs**: For each state, we maintain a list of non-dominated pairs of accumulated red and blue tokens. A pair (sum_r, sum_b) is dominated by another pair (sum_r', sum_b') if sum_r' ≤ sum_r and sum_b' ≤ sum_b. This ensures we only keep the most efficient token accumulations.
4. **Precomputation**: Precompute the number of red and blue cards (A and B) for each possible bitmask to quickly determine the cost of purchasing subsequent cards.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    cards = []
    for _ in range(n):
        c, r, b = sys.stdin.readline().split()
        r = int(r)
        b = int(b)
        cards.append((c, r, b))
    
    # Precompute A and B for each mask
    mask_info = []
    for mask in range(0, 1 << n):
        A = 0
        B = 0
        for i in range(n):
            if mask & (1 << i):
                if cards[i][0] == 'R':
                    A += 1
                else:
                    B += 1
        mask_info.append((A, B))
    
    # Initialize DP
    dp = [[] for _ in range(1 << n)]
    dp[0] = [(0, 0)]
    
    for mask in range(0, 1 << n):
        current_dp = dp[mask]
        if not current_dp:
            continue
        A, B = mask_info[mask]
        for i in range(n):
            if not (mask & (1 << i)):
                # Calculate the cost for buying card i next
                r_i = cards[i][1]
                b_i = cards[i][2]
                red_cost = max(r_i - A, 0)
                blue_cost = max(b_i - B, 0)
                new_pairs = []
                for (sum_r, sum_b) in current_dp:
                    new_sum_r = sum_r + red_cost
                    new_sum_b = sum_b + blue_cost
                    new_mask = mask | (1 << i)
                    # Check if this new pair is dominated by existing pairs in new_mask's dp
                    dominated = False
                    for (sr, sb) in dp[new_mask]:
                        if sr <= new_sum_r and sb <= new_sum_b:

                        filtered = []
                        for (sr, sb) in dp[new_mask]:
                            if not (new_sum_r <= sr and new_sum_b <= sb):

                        dp[new_mask] = filtered
    
    full_mask = (1 << n) - 1

        print(n)
    else:
```
