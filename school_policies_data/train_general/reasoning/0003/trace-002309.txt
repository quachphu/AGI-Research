To solve this problem, we need to determine whether a given permutation was generated using Petr's method or Alex's method. The key insight is to use the parity of the permutation, which can be derived from the number of cycles in the permutation's cycle decomposition.

### Approach
1. **Understanding Parity**: Each swap (transposition) changes the parity of the permutation. The parity of a permutation is determined by the number of transpositions (swaps) modulo 2. Starting from the identity permutation (which is even), after an even number of swaps, the permutation remains even, and after an odd number of swaps, it becomes odd.

2. **Cycle Decomposition**: The parity of a permutation can be determined by the number of cycles in its cycle decomposition. The formula for the parity is given by \((n - \text{number of cycles}) \mod 2\).

3. **Petr's and Alex's Methods**: 
   - Petr's method uses \(3n\) swaps. The parity of the permutation generated by this method is \(3n \mod 2\), which simplifies to \(n \mod 2\).
   - Alex's method uses \(7n + 1\) swaps. The parity here is \((7n + 1) \mod 2\), which simplifies to \((n + 1) \mod 2\).

4. **Determine the Source**: By comparing the permutation's parity with the expected parities from both methods, we can determine whether the permutation was generated by Petr or Alex.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    perm = list(map(lambda x: int(x) - 1, input[1:n+1]))
    visited = [False] * n
    cycle_count = 0
    for i in range(n):
        if not visited[i]:
            cycle_count += 1
            j = i
            while not visited[j]:
                visited[j] = True
                j = perm[j]
    parity = (n - cycle_count) % 2
    if parity == (n % 2):
        print("Petr")
    else:
        print("Um_nik")

main()
```

### Explanation
1. **Reading Input**: The input is read and parsed. The permutation is converted to a 0-based index for easier processing.
2. **Cycle Detection**: Using a boolean array `visited`, we traverse each element to detect cycles in the permutation. Each cycle found increments the cycle count.
3. **Parity Calculation**: The parity of the permutation is calculated using the formula \((n - \text{cycle_count}) \mod 2\).
4. **Comparison**: The calculated parity is compared against the expected parities for both methods. If it matches Petr's expected parity, "Petr" is printed; otherwise, "Um_nik" is printed.

This approach efficiently determines the source of the permutation with a time complexity of \(O(n)\), making it suitable for large values of \(n\) up to \(10^6\).
