To solve this problem, we need to determine the maximum number of occurrences of the substring "VK" in a given string after changing at most one character. The solution involves checking each possible single character change and evaluating the resulting substring count.

### Approach
1. **Initial Count**: Calculate the initial number of "VK" substrings in the given string.
2. **Evaluate Changes**: For each position in the string, consider changing the character to both 'V' and 'K' and compute the resulting number of "VK" substrings.
3. **Maximize Count**: Track the maximum count of "VK" substrings obtained from all possible single character changes (including no change).

### Solution Code
```python
def count_vk(s):
    return sum(1 for i in range(len(s)-1) if s[i] == 'V' and s[i+1] == 'K')

s = input().strip()
original = count_vk(s)
max_count = original

for i in range(len(s)):
    # Try changing to 'V'
    temp = list(s)
    original_char = temp[i]
    temp[i] = 'V'
    current = count_vk(temp)
    if current > max_count:
        max_count = current
    # Try changing to 'K'
    temp[i] = 'K'
    current = count_vk(temp)
    if current > max_count:
        max_count = current

print(max_count)
```

### Explanation
1. **Initial Count Calculation**: The function `count_vk` iterates through the string to count occurrences of "VK".
2. **Iterating Over Each Character**: For each character in the string, we simulate changing it to both 'V' and 'K' and compute the new count of "VK" substrings.
3. **Updating Maximum Count**: After evaluating each possible change, the maximum count of "VK" substrings is updated and printed.

This approach ensures that we consider all possible single character changes efficiently, leveraging an O(n^2) time complexity which is feasible given the input constraints (string length up to 100).
