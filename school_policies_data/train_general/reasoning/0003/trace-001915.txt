To solve this problem, we need to determine if specific characters in a given string appear an even or odd number of times based on multiple queries. Each query specifies a character and a parity (even or odd), and we need to check if the character's count in the string matches the specified parity.

### Approach
1. **Input Reading**: Read all input at once and split it into lines for easier processing.
2. **Frequency Counting**: Use a Counter from the collections module to count the occurrences of each character in the string efficiently.
3. **Query Processing**: For each query, check the count of the specified character and determine if it matches the requested parity (even or odd).

### Solution Code
```python
import sys
from collections import Counter

def main():
    input_lines = sys.stdin.read().splitlines()
    ptr = 0
    t = int(input_lines[ptr])
    ptr += 1
    for _ in range(t):
        # Skip empty lines before N and Q
        while ptr < len(input_lines) and input_lines[ptr].strip() == '':
            ptr += 1
        if ptr >= len(input_lines):
            break
        n, q = map(int, input_lines[ptr].split())
        ptr += 1
        
        # Skip empty lines before the string
        while ptr < len(input_lines) and input_lines[ptr].strip() == '':
            ptr += 1
        s = input_lines[ptr].strip()
        ptr += 1
        
        freq = Counter(s)
        
        for __ in range(q):
            # Skip empty lines before each query
            while ptr < len(input_lines) and input_lines[ptr].strip() == '':
                ptr += 1
            if ptr >= len(input_lines):
                break
            query = input_lines[ptr].strip().split()
            ptr += 1
            char = query[0]
            parity = query[1]
            count = freq.get(char, 0)
            if (parity == 'even' and count % 2 == 0) or (parity == 'odd' and count % 2 == 1):
                print("yes")
            else:
                print("no")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into lines to handle any potential empty lines between inputs.
2. **Processing Each Test Case**: For each test case, read the string and use a Counter to count character occurrences. This allows O(1) average time complexity for frequency lookups.
3. **Handling Queries**: For each query, check the character's count in the precomputed frequency dictionary. Compare the count's parity with the query's required parity and print "yes" or "no" accordingly.

This approach ensures that we efficiently handle up to the maximum constraints, providing quick responses to each query by leveraging precomputed character frequencies.
