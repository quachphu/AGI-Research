The key is to consider all possible valid expressions and compute their values to find the maximum.

### Approach
The problem can be approached by considering all valid arithmetic expressions formed by the three integers `a`, `b`, and `c` in their given order. The valid expressions are derived by grouping the operations in two possible ways:
1. Grouping the first two numbers and then combining the result with the third number.
2. Grouping the last two numbers and then combining the result with the first number.

For each grouping, we consider both addition and multiplication operations, leading to a total of 8 possible expressions. The maximum value among these expressions is the solution.

### Solution Code
```python
a = int(input())
b = int(input())
c = int(input())

results = [
    (a + b) + c,
    (a + b) * c,
    (a * b) + c,
    (a * b) * c,
    a + (b + c),
    a + (b * c),
    a * (b + c),
    a * (b * c)
]

print(max(results))
```

1. **Reading Input**: The three integers `a`, `b`, and `c` are read from standard input.
2. **Generating Expressions**: We generate all 8 possible expressions by considering both groupings (first two vs. last two numbers) and both operations (addition and multiplication) for each grouping.
3. **Computing Results**: Each expression is evaluated and stored in a list.
4. **Finding Maximum**: The maximum value from the list of evaluated expressions is determined and printed.

This approach ensures that all possible valid arithmetic expressions are considered, and the maximum value is efficiently found using straightforward computation and comparison.
