To solve this problem, we need to maximize the points Alex can earn by deleting elements from a sequence according to specific rules. The key challenge is to select elements such that deleting an element also removes all elements adjacent to it (numerically), and we aim to maximize the total points from the chosen elements.

### Approach
1. **Frequency Count**: First, count the frequency of each element in the sequence. This helps in determining the total points each element can contribute if chosen.
2. **Sorting Unique Elements**: Sort the unique elements of the sequence. This allows us to process elements in increasing order and handle numerical adjacency efficiently.
3. **Dynamic Programming (DP)**: Use a dynamic programming approach where we maintain two states for each element: the maximum points if we take the element (and thus exclude its adjacent elements) and the maximum points if we skip it. This is similar to the "house robber" problem but adjusted for numerical adjacency.

### Solution Code
```python
from collections import Counter

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    freq = Counter(a)
    sorted_x = sorted(freq.keys())
    take = 0
    skip = 0
    prev_x = None
    for x in sorted_x:
        current = x * freq[x]
        if prev_x is None:
            new_take = current
            new_skip = 0
        else:
            if x == prev_x + 1:
                new_take = skip + current
                new_skip = max(take, skip)
            else:
                new_take = max(take, skip) + current
                new_skip = max(take, skip)
        take, skip = new_take, new_skip
        prev_x = x
    print(max(take, skip))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into an integer list.
2. **Frequency Calculation**: Using a `Counter`, we determine how many times each element appears in the sequence.
3. **Sorting Elements**: The unique elements are sorted to handle numerical adjacency efficiently.
4. **Dynamic Programming Loop**: We iterate over each unique element, updating two states:
   - `take`: The maximum points if we include the current element, which means we cannot include the previous element if it is numerically adjacent.
   - `skip`: The maximum points if we exclude the current element, allowing us to carry forward the best result from the previous state.
5. **Result Calculation**: The maximum points Alex can earn is the maximum value between the two states after processing all elements.

This approach efficiently handles the constraints and ensures optimal selection of elements to maximize points while adhering to the deletion rules.
