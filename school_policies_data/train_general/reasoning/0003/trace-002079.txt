To solve this problem, we need to determine the minimum number of changes required to convert a given string into a "fancy" string. A fancy string is defined as one where all uppercase letters appear before any lowercase letters. The goal is to find the optimal split point where the number of case changes needed is minimized.

### Approach
1. **Problem Analysis**: The problem requires transforming the string such that all uppercase letters are on the left and all lowercase letters are on the right. The key insight is to find the optimal split point where the sum of changes needed for the left part (to uppercase) and the right part (to lowercase) is minimized.
2. **Precompute Arrays**:
   - **Prefix Array**: This array keeps track of the number of lowercase letters from the start up to each position. This helps in determining how many changes are needed to convert all characters up to a certain position to uppercase.
   - **Suffix Array**: This array keeps track of the number of uppercase letters from each position to the end of the string. This helps in determining how many changes are needed to convert all characters from a certain position to lowercase.
3. **Calculate Minimum Changes**: Using the precomputed arrays, iterate through all possible split points and compute the total changes required for each split point. The minimum value among these calculations is the answer.

### Solution Code
```python
s = input().strip()
n = len(s)

prefix_lower = [0] * (n + 1)
for i in range(1, n + 1):
    prefix_lower[i] = prefix_lower[i-1] + (1 if s[i-1].islower() else 0)

suffix_upper = [0] * (n + 1)
for i in range(n-1, -1, -1):
    suffix_upper[i] = suffix_upper[i+1] + (1 if s[i].isupper() else 0)

min_changes = min(prefix_lower[i] + suffix_upper[i] for i in range(n + 1))
print(min_changes)
```

### Explanation
1. **Reading Input**: The input string is read and its length is determined.
2. **Prefix Array Calculation**: The prefix array `prefix_lower` is computed where each entry at index `i` represents the number of lowercase letters from the start up to (but not including) index `i`.
3. **Suffix Array Calculation**: The suffix array `suffix_upper` is computed where each entry at index `i` represents the number of uppercase letters from index `i` to the end of the string.
4. **Finding Minimum Changes**: By iterating through all possible split points (from 0 to `n`), the total number of changes required for each split point is calculated as the sum of the corresponding entries in the prefix and suffix arrays. The minimum value of these sums is the result.

This approach efficiently computes the required values in linear time, making it suitable even for the upper constraint of the input string length (up to 100,000 characters).
