To solve this problem, we need to determine the maximum number of good integers that can multiply together to form a given integer \( n \). A good integer is defined as an integer consisting only of the digits 2 and 8. If \( n \) cannot be expressed as a product of good integers, we should return -1.

### Approach
1. **Generate Good Integers**: Precompute all possible good integers up to \( 10^{18} \). These integers are generated using a BFS approach to ensure all combinations of 2 and 8 are considered.
2. **Prime Factorization**: Factorize the given integer \( n \) into its prime factors. This helps in checking if all prime factors of \( n \) can be covered by the prime factors of some good integer.
3. **Check Coverage**: For each prime factor of \( n \), check if there exists at least one good integer that is divisible by that prime. If any prime factor is not covered, return -1.
4. **Dynamic Programming with Memoization**: Use a recursive approach with memoization to determine the maximum number of good integers that can multiply to \( n \). For each good integer that divides \( n \), compute the maximum possible exponent and recursively solve for the quotient.
