To solve this problem, we need to simulate the round-robin scheduling algorithm for process management. The goal is to determine the order in which processes complete their execution and the time at which each process finishes.

### Approach
1. **Input Reading**: Read the number of processes `n` and the quantum `q`, followed by the details of each process (name and time required).
2. **Queue Initialization**: Use a deque (double-ended queue) to manage the processes in the order they are read. This allows efficient insertion and removal of elements from both ends.
3. **Processing Loop**: Continuously process each element from the front of the deque:
   - For each process, determine the execution time as the minimum of the remaining time of the process and the quantum `q`.
   - Update the total elapsed time by adding the execution time used.
   - If the process completes (remaining time becomes zero), record the finish time. Otherwise, reinsert the process back into the deque with the updated remaining time.
4. **Output**: After all processes are completed, print the results in the order they finished.

### Solution Code
```python
import sys
from collections import deque

def main():
    n, q = map(int, sys.stdin.readline().split())
    queue = deque()
    for _ in range(n):
        name, time = sys.stdin.readline().split()
        queue.append((name, int(time)))
    
    elapsed = 0
    result = []
    
    while queue:
        name, time = queue.popleft()
        process_time = min(q, time)
        elapsed += process_time
        if time <= process_time:
            result.append((name, elapsed))
        else:
            queue.append((name, time - process_time))
    
    for name, time in result:
        print(f"{name} {time}")

if __name__ == "__main__":
    main()
```

### Explanation
- **Input Handling**: The input is read using `sys.stdin` for efficiency, especially with large input sizes. The first line provides `n` (number of processes) and `q` (quantum time). Subsequent lines provide the process names and their respective times.
- **Queue Management**: The deque is used to maintain the order of processes. Each process is dequeued, processed for up to `q` time units, and either completed (added to the result list) or enqueued again with the remaining time.
- **Time Tracking**: The elapsed time is updated each time a process is executed, ensuring accurate tracking of when each process finishes.
- **Result Output**: The results are collected in the order processes complete and printed at the end.

This approach ensures efficient handling of up to 100,000 processes and 1,000,000 total time units, adhering to the problem constraints while maintaining clarity and correctness.
