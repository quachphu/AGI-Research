To solve this problem, we need to determine if Harish and Ozil can split the total number of dosas such that both get an even number of dosas. The key insight is that the sum of two even numbers is even, and each person must receive at least one dosa, which translates to each person getting a positive even number of dosas.

### Approach
1. **Check Even Total**: The total number of dosas, \( N \), must be even. This is because the sum of two even numbers is even.
2. **Minimum Dosas**: Each person must receive at least 2 dosas (the smallest positive even number). Therefore, the total \( N \) must be at least 4 (since 2 + 2 = 4).

Given these two conditions, we can determine the solution by checking if \( N \) is even and \( N \geq 4 \).

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    results = []
    for n_str in input[1:T+1]:
        N = int(n_str)
        if N % 2 == 0 and N >= 4:
            results.append("YES")
        else:
            results.append("NO")
    print('\n'.join(results))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once using `sys.stdin.read()` to handle large input sizes efficiently.
2. **Check Conditions**: For each test case, we check if \( N \) is even and at least 4. If both conditions are met, the answer is "YES"; otherwise, it is "NO".
3. **Output Results**: The results are collected in a list and printed at once to minimize I/O operations, which is crucial for handling up to \( 10^6 \) test cases efficiently.

This approach ensures that we efficiently determine the answer for each test case in constant time \( O(1) \), leading to an overall time complexity of \( O(T) \), where \( T \) is the number of test cases.
