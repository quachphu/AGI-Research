To solve this problem, we need to determine if there exists a valid combination of cranes and turtles in a garden such that the total number of animals is X and the total number of legs is Y. Cranes have 2 legs each and turtles have 4 legs each.

### Approach
The key insight is that the total number of legs (Y) must be even, as both cranes and turtles contribute an even number of legs. Additionally, the minimum possible number of legs (when all animals are cranes) is 2X, and the maximum possible number of legs (when all animals are turtles) is 4X. Therefore, Y must be an even number within the inclusive range [2X, 4X].

### Solution Code
```python
def main():
    import sys
    X, Y = map(int, sys.stdin.readline().split())
    if Y % 2 != 0:
        print("No")
    else:
        min_legs = 2 * X
        max_legs = 4 * X
        if min_legs <= Y <= max_legs:
            print("Yes")
        else:
            print("No")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Check if Y is even**: If Y is odd, it's immediately impossible to have a valid combination of cranes and turtles, so we print "No".
2. **Check the range of Y**: If Y is even, we then check if it falls within the valid range [2X, 4X]. If it does, we print "Yes"; otherwise, we print "No".

This approach efficiently determines the validity of the combination using simple arithmetic checks, ensuring the solution is both optimal and easy to understand.
