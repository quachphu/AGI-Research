To solve this problem, we need to process a string such that each word starting with a lowercase Latin letter has its first character converted to uppercase, while preserving the original spacing between words. 

### Approach
1. **Split the Input String**: We use regular expressions to split the input string into tokens that are either sequences of non-space characters (words) or sequences of spaces. This helps in preserving the original spacing.
2. **Process Each Word**: For each token that is a word (not spaces), check if it starts with a lowercase letter. If it does, convert the first letter to uppercase.
3. **Reconstruct the String**: Join all the processed tokens back together to form the final output string, maintaining the original spacing.

### Solution Code
```python
import re

def process_string(s):
    tokens = re.findall(r'\S+|\s+', s)
    for i in range(len(tokens)):
        token = tokens[i]
        if not token.isspace():
            if token:  # Ensure the token is not empty
                first_char = token[0]
                if first_char.islower():
                    tokens[i] = first_char.upper() + token[1:]
    return ''.join(tokens)

s = input()
print(process_string(s))
```

### Explanation
1. **Splitting the Input**: The regular expression `r'\S+|\s+'` is used to split the input string into tokens that are either words or spaces. This ensures that the exact spacing between words is preserved.
2. **Processing Words**: Each token is checked to determine if it is a word (non-space characters). If the first character of the word is a lowercase letter, it is converted to uppercase.
3. **Reconstructing the Output**: The processed tokens are joined back together to form the final string, ensuring the original spacing is maintained.

This approach efficiently processes each word while preserving the input's structure, making it both time and space efficient for the given constraints.
