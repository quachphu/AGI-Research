To solve this problem, we need to determine the maximum marks Jam can achieve in an exam where he can select one question to double its marks, given a time constraint. This problem is a variation of the knapsack problem with an additional twist of being able to double the marks of one question.

### Approach
1. **Dynamic Programming (DP) Setup**: We use two DP arrays to keep track of the maximum marks achievable with and without using the bonus.
   - `dp0[j]` tracks the maximum marks achievable with `j` time units without using the bonus.
   - `dp1[j]` tracks the maximum marks achievable with `j` time units after using the bonus on one question.

2. **Transition States**:
   - **Without Bonus**: For each question, update `dp0` by considering the question without using the bonus.
   - **With Bonus**: For each question, update `dp1` by considering either continuing without using the bonus or using the bonus on the current question.

3. **Iterate Over Questions**: For each question, update the DP arrays in reverse order (from the maximum time down to the time required by the question) to avoid overwriting values that are still needed for subsequent computations.

4. **Compute Result**: After processing all questions, the result is the maximum value found in both `dp0` and `dp1` arrays across all possible time values up to the given total time.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    T = int(sys.stdin.readline())
    marks = list(map(int, sys.stdin.readline().split()))
    times = list(map(int, sys.stdin.readline().split()))
    
    INF = float('-inf')
    dp0 = [INF] * (T + 1)
    dp0[0] = 0  # Base case: 0 time, 0 marks without using bonus
    dp1 = [INF] * (T + 1)  # State where bonus has been used
    
    for i in range(n):
        m = marks[i]
        t = times[i]
        # Iterate from T down to t to prevent overwriting needed values
        for j in range(T, t - 1, -1):
            # Update state 0: take the question without using bonus
            if dp0[j - t] != INF and dp0[j - t] + m > dp0[j]:
                dp0[j] = dp0[j - t] + m
            # Update state 1: take the question normally (bonus already used)
            if dp1[j - t] != INF and dp1[j - t] + m > dp1[j]:
                dp1[j] = dp1[j - t] + m
            # Transition from state 0 to 1 by using bonus on this question
            if dp0[j - t] != INF and dp0[j - t] + 2 * m > dp1[j]:
                dp1[j] = max(dp1[j], dp0[j - t] + 2 * m)
    
    max_marks = 0
    for j in range(T + 1):
        current_max = max(dp0[j], dp1[j])
        if current_max > max_marks:
            max_marks = current_max
    print(max_marks)

if __name__ == "__main__":
    main()
```

### Explanation
- **Initialization**: `dp0` is initialized with 0 marks at 0 time, and all other entries as negative infinity. `dp1` starts with all entries as negative infinity.
- **Processing Each Question**: For each question, update the DP arrays in reverse order to ensure each state transition is correctly computed without overwriting values needed for the current iteration.
