To solve this problem, we need to split a list of integers into two groups such that the difference between their sums is minimized. The solution involves using a brute-force approach with bitmasking to explore all possible subsets and find the optimal division.

### Approach
1. **Problem Analysis**: The task is to divide the given list of integers into two groups such that the absolute difference between their sums is minimized. Given the constraints (n ≤ 20), a brute-force approach is feasible.
2. **Bitmasking Technique**: Each integer from 0 to 2^n - 1 (where n is the number of elements) can be represented as a bitmask. Each bit in the bitmask indicates whether the corresponding element is included in the subset.
3. **Subset Sum Calculation**: For each bitmask, compute the sum of the elements included in the subset. The difference between the sums of the two groups can be derived from the total sum of all elements and the subset sum.
4. **Optimization**: Track the minimum difference encountered during the iteration over all possible subsets.

### Solution Code
```python
import sys

def main():
    for line in sys.stdin:
        n = int(line.strip())
        if n == 0:
            break
        a = list(map(int, sys.stdin.readline().split()))
        total = sum(a)
        min_diff = float('inf')
        for mask in range(1 << n):
            subset_sum = sum(num for idx, num in enumerate(a) if (mask >> idx) & 1)
            current_diff = abs(total - 2 * subset_sum)
            if current_diff < min_diff:
                min_diff = current_diff
        print(min_diff)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads input datasets until it encounters a line with `0`, indicating the end of input.
2. **Total Sum Calculation**: For each dataset, the total sum of all elements is computed.
3. **Bitmask Iteration**: Each possible subset (represented by a bitmask) is generated. For each subset, the sum of the elements in the subset is calculated.
4. **Difference Calculation**: The difference between the sums of the two groups is computed as the absolute value of `total - 2 * subset_sum`, where `subset_sum` is the sum of the current subset.
5. **Track Minimum Difference**: The minimum difference encountered during the iteration is tracked and printed for each dataset.

This approach efficiently explores all possible subsets using bitmasking, ensuring that we find the optimal division with minimal computational overhead given the problem constraints.
