To solve this problem, we need to determine the cost of lunch at the pizzeria chosen by John and Maria based on their optimal choices. Maria aims to maximize the cost, while John aims to minimize it. The solution involves finding the maximum of the minimum costs from each row, which Maria will choose to ensure the highest possible cost given John's minimizing strategy.

### Approach
1. **Read Input**: Read the number of Boulevards (rows) and Woonerfs (columns).
2. **Compute Minimum for Each Row**: For each Boulevard (row), compute the minimum cost of the pizzerias located on that row. This represents the best choice John would make if Maria chooses that Boulevard.
3. **Determine Maximum of Minimums**: Find the maximum value among all the minimum costs computed for each row. This represents Maria's optimal choice to maximize the cost, considering John's minimizing strategy.

### Solution Code
```python
def main():
    import sys
    x, y = map(int, sys.stdin.readline().split())
    minima = []
    for _ in range(x):
        row = list(map(int, sys.stdin.readline().split()))
        minima.append(min(row))
    print(max(minima))

main()
```

### Explanation
1. **Reading Input**: The first line of input contains two integers, `x` (number of Boulevards) and `y` (number of Woonerfs). Subsequent lines contain the costs for each intersection.
2. **Row Minimum Calculation**: For each row, the minimum cost is calculated. This step ensures that we capture John's optimal choice (minimizing the cost) for each possible Boulevard chosen by Maria.
3. **Finding Maximum of Minimums**: The maximum value among these minima is determined, which represents Maria's optimal choice to ensure the highest possible cost John cannot avoid once she selects a Boulevard.

This approach efficiently combines the optimal strategies of both Maria and John, ensuring the solution is both correct and optimal within the problem constraints.
