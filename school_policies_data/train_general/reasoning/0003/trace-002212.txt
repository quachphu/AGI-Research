To solve this problem, we need to determine the number of "good pairs" of positions where breaking a stick results in at least one segment longer than a given length \( L \). The solution involves efficiently checking each possible pair of break positions while avoiding a brute-force approach to stay within time constraints.

### Approach
1. **Sort the Break Positions**: First, sort the array of break positions to simplify the process of checking pairs.
2. **Calculate Total Pairs**: Compute the total number of possible pairs using the combination formula \( C(N, 2) \).
3. **Identify Bad Pairs**: For each break position, determine the range of subsequent positions that would result in all segments being less than or equal to \( L \). Use binary search to efficiently count these positions.
4. **Subtract Bad Pairs**: Subtract the count of bad pairs from the total pairs to get the number of good pairs.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        S = int(input[ptr])
        N = int(input[ptr + 1])
        L = int(input[ptr + 2])
        ptr += 3
        A = list(map(int, input[ptr:ptr + N]))
        ptr += N
        A.sort()
        total = N * (N - 1) // 2
        bad = 0
        for i in range(N):
            a = A[i]
            if a > L:
                continue
            s_minus_L = S - L
            lower = max(s_minus_L, a + 1)
            upper = a + L
            left = bisect.bisect_left(A, lower, i + 1)
            right = bisect.bisect_right(A, upper, i + 1)
            bad += right - left
        print(total - bad)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into tokens for efficient processing.
2. **Sorting**: The break positions are sorted to facilitate efficient range queries.
3. **Total Pairs Calculation**: Using the combination formula \( N \times (N-1) / 2 \), we calculate the total number of pairs.
4. **Binary Search for Range Queries**: For each break position \( a \), we determine the valid range of subsequent positions \( b \) that would result in all segments being ≤ \( L \). This is done using binary search to quickly find the valid range in the sorted array.
5. **Counting Bad Pairs**: The number of valid \( b \) positions for each \( a \) is counted using the binary search results, and these counts are summed to get the total number of bad pairs.
6. **Result Calculation**: Subtract the number of bad pairs from the total pairs to get the number of good pairs, which is printed for each test case.

This approach ensures that we efficiently count valid pairs using sorting and binary search, leading to an optimal solution that handles the problem constraints effectively.
