To solve this problem, we need to compute the product of two integers provided as input and print the result. The solution involves reading the input, processing it to obtain the integers, performing the multiplication, and then outputting the result.

### Approach
1. **Reading Input**: The input consists of a single line with two space-separated integers. We can read this line using Python's `input()` function.
2. **Splitting and Converting**: The input string is split into two parts using the `split()` method. These parts are then converted from strings to integers using the `map()` function.
3. **Multiplication**: The two integers are multiplied together to get the product.
4. **Output the Result**: The product is printed as the result.

### Solution Code
```python
def main():
    A, B = map(int, input().split())
    print(A * B)

main()
```

### Explanation
1. **Reading Input**: The `input()` function reads a line from standard input. This line is expected to contain two integers separated by a space.
2. **Splitting and Converting**: The `split()` method splits the input string into a list of substrings based on spaces. The `map(int, ...)` function converts these substrings into integers.
3. **Multiplication**: The integers obtained are multiplied using the `*` operator.
4. **Output**: The result of the multiplication is printed using the `print()` function.

This approach ensures that we correctly handle the input, process it efficiently, and produce the desired output in a straightforward manner. The constraints given (values between 1 and 100) ensure that there are no issues with integer overflow in Python.
