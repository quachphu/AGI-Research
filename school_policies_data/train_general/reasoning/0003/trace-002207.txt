To solve this problem, we need to compute the sum of the squares of distances between all pairs of points on a plane efficiently. Given the constraints where the number of points \( N \) can be as large as 100,000, a direct approach of iterating over all pairs would be too slow. Instead, we use a mathematical formula to derive the solution in linear time.

### Approach
1. **Mathematical Insight**: The sum of the squares of distances between all pairs of points can be broken down into sums involving the coordinates of the points. Specifically, for each coordinate (x and y), we can compute the sum of squares of differences using the formula:
   \[
   \text{Total} = (N \times \text{sum of squares of coordinates} - (\text{sum of coordinates})^2)
   \]
   This formula is derived from expanding the squared distance formula and simplifying the resulting sums.

2. **Efficient Calculation**: By iterating through each point once, we accumulate the necessary sums (sum of coordinates and sum of squares of coordinates) for both x and y coordinates. Using these accumulated sums, we can compute the final result in constant time.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    sum_x = 0
    sum_y = 0
    sum_x_sq = 0
    sum_y_sq = 0
    
    for _ in range(n):
        x, y = map(int, sys.stdin.readline().split())
        sum_x += x
        sum_y += y
        sum_x_sq += x * x
        sum_y_sq += y * y
    
    total = (sum_x_sq * n - sum_x ** 2) + (sum_y_sq * n - sum_y ** 2)
    print(total)

main()
```

### Explanation
1. **Reading Input**: The input is read efficiently using `sys.stdin.readline()` to handle large input sizes.
2. **Accumulating Sums**: As we read each point, we update the sums of the x and y coordinates, as well as the sums of their squares.
3. **Applying the Formula**: Using the accumulated sums, we compute the total sum of squares of distances for both x and y coordinates separately and combine them to get the final result.

This approach ensures that we process each point in constant time, leading to an overall time complexity of \( O(N) \), which is optimal for the given problem constraints.
