Direct computation using iteration or recursion would be infeasible for large n due to exponential time complexity.

This method leverages the properties of Fibonacci numbers to break down the problem into smaller subproblems, allowing efficient computation using recursion and memoization.

### Solution Code
```python
MOD = 10**9 + 7

def fast_doubling(n, mod):
    if n == 0:
        return (0, 1)
    a, b = fast_doubling(n >> 1, mod)
    c = a * (2 * b - a) % mod
    d = (a * a + b * b) % mod
    if n & 1:
        return (d, (c + d) % mod)
    else:
        return (c, d)

def main():
    a, b, n = map(int, input().split())
    if n == 1:
        print(a % MOD)
    elif n == 2:
        print(b % MOD)
    else:
        x, y = fast_doubling(n - 2, MOD)
        res = (a * x + b * y) % MOD
        print(res)

main()
```

2. **Handling Base Cases**: For n = 1 and n = 2, the result is simply a or b modulo \(10^9 + 7\), respectively.
3. **Coefficient Calculation**: For n ≥ 3, the nth term is calculated using the (n-2)th and (n-1)th Fibonacci numbers as coefficients for a and b, respectively. This is derived from the structure of the Fibonacci sequence and ensures the correct combination of the initial values a and b.
