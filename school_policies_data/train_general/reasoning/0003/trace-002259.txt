To solve this problem, we need to determine the minimum number of lab works Vasya must redo to ensure his average grade rounds up to 5. The key insight is to compute the required sum of grades such that the average meets the threshold of 4.5, which rounds up to 5. We then find the minimum number of grade improvements needed to reach this sum.

### Approach
1. **Calculate the Required Sum**: The required sum of grades to achieve an average of at least 4.5 is derived from the formula `(9 * n + 1) // 2`, where `n` is the number of grades.
2. **Current Sum and Deficit**: Compute the current sum of Vasya's grades. If this sum already meets or exceeds the required sum, no changes are needed.
3. **Determine Gains**: For each grade less than 5, calculate the potential gain if the grade is improved to 5. Sort these gains in descending order to prioritize the largest improvements.
4. **Accumulate Gains**: Sum the largest gains until the deficit (difference between the required sum and current sum) is covered. The number of gains used gives the minimum number of lab works to redo.

### Solution Code
```python
n = int(input())
grades = list(map(int, input().split()))
current_sum = sum(grades)
required_sum = (9 * n + 1) // 2

if current_sum >= required_sum:
    print(0)
else:
    deficit = required_sum - current_sum
    gains = [5 - g for g in grades if g < 5]
    gains.sort(reverse=True)
    
    count = 0
    total_gain = 0
    for gain in gains:
        if total_gain >= deficit:
            break
        total_gain += gain
        count += 1
    print(count)
```

### Explanation
1. **Input Reading**: Read the number of grades and the grades themselves.
2. **Current Sum Calculation**: Compute the sum of the current grades.
3. **Required Sum Calculation**: Determine the minimum sum needed using the formula to ensure the average rounds up to 5.
4. **Deficit Check**: If the current sum meets the required sum, output 0. Otherwise, calculate the deficit.
5. **Gain Calculation and Sorting**: Compute the potential gain for each grade less than 5 and sort these gains in descending order to maximize the impact of each change.
6. **Gain Accumulation**: Iterate through the sorted gains, accumulating them until the deficit is covered, counting the number of changes needed.

This approach efficiently determines the minimal number of lab works to redo by leveraging a greedy algorithm to maximize the impact of each grade improvement.
