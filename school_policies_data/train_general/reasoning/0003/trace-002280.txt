### Approach
1. **Game Theory and Grundy Numbers**: The game can be modeled using Grundy numbers (or mex function) to determine the winning strategy. Each position in the string can be considered a state, and the Grundy number for each state is computed based on possible moves.
2. **Dynamic Programming (DP)**: We use a DP table to store the Grundy numbers for all possible substrings of the given string. The table is filled in increasing order of substring lengths.
3. **Preprocessing Valid Substrings**: For each test case, we preprocess which substrings of the given string exist in the dictionary to allow quick lookups during the DP computation.

        for k in range(n):
            for m in range(k+1, n+1):
                substr = S[k:m]
                if substr in dict_set:
                    valid[k][m] = True

        dp = [[0]*(n+1) for _ in range(n+1)]

        for l in range(1, n+1):  # length of the interval
            for i in range(n - l +1):
                j = i + l
                current_set = set()

                            right = dp[m_split][j]
                            current_xor = left ^ right
                            current_set.add(current_xor)

                while mex in current_set:
                    mex += 1
                dp[i][j] = mex
        # Determine the winner based on the grundy number of the entire string
