To solve this problem, we need to determine if two nodes in a directed graph belong to the same strongly connected component (SCC) for multiple queries. A strongly connected component is a subgraph where every node is reachable from every other node within the subgraph.

### Approach
1. **Kosaraju's Algorithm**: This algorithm efficiently finds SCCs in a directed graph using two passes of Depth-First Search (DFS):
   - **First Pass**: Perform DFS on the original graph to determine the finishing times of nodes, storing them in a stack.
   - **Second Pass**: Reverse the graph and perform DFS on the reversed graph in the order of decreasing finishing times obtained from the first pass. Each DFS in this pass identifies all nodes in an SCC.

2. **Component Assignment**: After identifying SCCs using Kosaraju's Algorithm, each node is assigned a component ID. For each query, we simply check if the two nodes have the same component ID.

### Solution Code
```python
import sys
sys.setrecursionlimit(1 << 25)

def main():
    input = sys.stdin.read().split()
    ptr = 0
    V = int(input[ptr])
    ptr += 1
    E = int(input[ptr])
    ptr += 1

    adj = [[] for _ in range(V)]
    reversed_adj = [[] for _ in range(V)]

    for _ in range(E):
        s = int(input[ptr])
        ptr += 1
        t = int(input[ptr])
        ptr += 1
        adj[s].append(t)
        reversed_adj[t].append(s)

    visited = [False] * V
    order = []
    for node in range(V):
        if not visited[node]:
            stack = [(node, False)]
            while stack:
                u, processed = stack.pop()
                if not processed:
                    if visited[u]:
                        continue
                    visited[u] = True
                    stack.append((u, True))
                    for v in reversed(adj[u]):
                        if not visited[v]:
                            stack.append((v, False))
                else:
                    order.append(u)

    visited = [False] * V
    component = [0] * V
    current_component = 0
    for node in reversed(order):
        if not visited[node]:
            stack = [node]
            visited[node] = True
            component[node] = current_component
            while stack:
                u = stack.pop()
                for v in reversed_adj[u]:
                    if not visited[v]:
                        visited[v] = True
                        component[v] = current_component
                        stack.append(v)
            current_component += 1

    Q = int(input[ptr])
    ptr += 1
    output = []
    for _ in range(Q):
        u = int(input[ptr])
        ptr += 1
        v = int(input[ptr])
        ptr += 1
        output.append('1' if component[u] == component[v] else '0')
    print('\n'.join(output))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the large potential size of the input.
2. **Building Adjacency Lists**: Two adjacency lists are constructed: one for the original graph and one for the reversed graph.
3. **First DFS Pass**: This pass processes each node and records the finishing times in a stack, which helps in determining the order of processing for the second pass.
4. **Second DFS Pass**: Using the reversed graph and the finishing times from the first pass, nodes are processed in reverse order of their finishing times to identify SCCs and assign component IDs.
5. **Query Processing**: For each query, the component IDs of the two nodes are compared to determine if they belong to the same SCC.

This approach ensures that each query is answered in constant time after preprocessing, making the solution efficient even for large inputs.
