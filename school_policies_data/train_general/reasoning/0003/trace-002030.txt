To solve this problem, we need to determine the maximum score Polycarp can achieve by starting at an optimal index in an array and following specific movement rules. The solution involves dynamic programming to efficiently compute the maximum score for each starting position.

### Approach
1. **Dynamic Programming (DP) Insight**: The score starting from any index `i` can be computed using the scores of subsequent indices. If we process the array from right to left, we can use previously computed values to determine the score for the current index efficiently.
2. **Right-to-Left Processing**: By iterating from the end of the array to the beginning, we ensure that when computing the score for index `i`, the scores for all possible subsequent indices (i.e., `i + a[i]`) have already been computed.
3. **DP Array Definition**: Let `dp[i]` represent the maximum score starting from index `i`. The value of `dp[i]` is determined by the value at `a[i]` plus the score from the next valid position if it exists within bounds.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        a = list(map(int, input[ptr:ptr + n]))
        ptr += n
        dp = [0] * (n + 2)  # 1-based to n
        max_score = 0
        for i in range(n, 0, -1):
            jump = a[i - 1]
            next_i = i + jump
            if next_i > n:
                current = jump
            else:
                current = jump + dp[next_i]
            dp[i] = current
            if current > max_score:
                max_score = current
        print(max_score)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the large constraints. The input is split into a list for easy access.
2. **Dynamic Programming Array Initialization**: A `dp` array of size `n + 2` is used to handle 1-based indexing and avoid boundary checks.
3. **Right-to-Left Processing**: The loop processes each index from `n` down to `1`. For each index `i`, the score is computed based on the value at `a[i-1]` (adjusted for 0-based list) and the next valid position (`i + a[i-1]`).
4. **Updating Maximum Score**: During each iteration, the maximum score is updated to ensure the highest possible score is tracked.

This approach ensures that each test case is processed in linear time O(n), making the solution efficient and suitable for the given constraints.
