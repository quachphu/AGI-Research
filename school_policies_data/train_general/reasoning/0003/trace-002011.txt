To solve this problem, we need to vertically extend an image by duplicating each row. The input consists of an image with H rows and W columns, and the goal is to output an image with 2H rows where each original row appears twice consecutively.

### Approach
1. **Read Input**: First, read the dimensions of the image (H and W) followed by the H rows of the image.
2. **Duplicate Rows**: For each row in the input image, print the row twice. This effectively doubles the height of the image while maintaining the original width.

### Solution Code
```python
def main():
    import sys
    H, W = map(int, sys.stdin.readline().split())
    rows = [sys.stdin.readline().strip() for _ in range(H)]
    for row in rows:
        print(row)
        print(row)

main()
```

### Explanation
1. **Reading Input**: The first line of input is read to get the dimensions H (height) and W (width). The subsequent H lines are read to form the image rows.
2. **Processing Rows**: Each row from the input is stored in a list. For each row in this list, the row is printed twice. This duplication of rows effectively doubles the height of the image while keeping the content of each row unchanged.

This approach ensures that the image is extended vertically by simply repeating each row, which meets the problem requirements efficiently. The solution runs in O(H) time complexity, where H is the number of rows in the original image, making it efficient given the problem constraints.
