To solve this problem, we need to determine the maximum number of days Tanya can eat two candies of different colors each day, given three piles of red, green, and blue candies. The solution involves checking the relationship between the largest pile and the sum of the other two piles to determine the optimal strategy.

### Approach
1. **Sort the Piles**: First, sort the three piles to easily identify the smallest, middle, and largest piles.
2. **Check the Largest Pile**: If the largest pile is greater than the sum of the other two piles, the maximum number of days Tanya can eat candies is the sum of the two smaller piles. This is because once the two smaller piles are exhausted, no more valid pairs can be formed.
3. **Sum of All Piles**: If the largest pile is not greater than the sum of the other two piles, the maximum number of days is the total number of candies divided by 2 (using integer division). This works because each day uses two candies, and the distribution allows for all candies to be paired optimally.

### Solution Code
```python
t = int(input())
for _ in range(t):
    r, g, b = map(int, input().split())
    s = sorted([r, g, b])
    total = sum(s)
    if s[2] > s[0] + s[1]:
        print(s[0] + s[1])
    else:
        print(total // 2)
```

### Explanation
1. **Input Reading**: The code reads the number of test cases and then processes each test case individually.
2. **Sorting**: The candies in each pile are sorted to easily identify the smallest, middle, and largest piles.
3. **Condition Check**: The code checks if the largest pile is greater than the sum of the other two piles. If true, the result is the sum of the two smaller piles. Otherwise, it calculates the result as the total number of candies divided by 2 using integer division.
4. **Output**: The result for each test case is printed immediately after processing.

This approach ensures that we efficiently determine the maximum number of days Tanya can eat the candies by leveraging sorting and simple arithmetic checks, leading to an optimal solution.
