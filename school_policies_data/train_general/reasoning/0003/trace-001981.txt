To solve this problem, we need to determine the minimum number of square flagstones required to cover a rectangular Theatre Square of dimensions \( n \times m \) meters, where each flagstone has a side length of \( a \) meters. The flagstones must be aligned with the sides of the square and cannot be broken.

### Approach
1. **Understand the Problem Requirements**: The flagstones must cover the entire area of the Theatre Square without breaking any flagstones. This means that if the dimensions of the Theatre Square are not exact multiples of the flagstone size, we need to round up to the next whole number of flagstones for each dimension.
2. **Calculate Flagstones per Dimension**: For each dimension (length and width), compute the number of flagstones required by dividing the dimension by the flagstone size and rounding up to the nearest integer. This can be efficiently achieved using integer arithmetic by the formula \( \text{ceil}(x / y) = (x + y - 1) // y \).
3. **Multiply Results**: The total number of flagstones needed is the product of the number of flagstones required for each dimension.

### Solution Code
```python
def main():
    import sys
    n, m, a = map(int, sys.stdin.readline().split())
    stones_n = (n + a - 1) // a
    stones_m = (m + a - 1) // a
    print(stones_n * stones_m)

main()
```

### Explanation
1. **Reading Input**: The input consists of three integers \( n \), \( m \), and \( a \), which are read from standard input.
2. **Calculating Flagstones for Each Dimension**:
   - For the length \( n \), the number of flagstones required is calculated as \((n + a - 1) // a\). This formula effectively rounds up the division of \( n \) by \( a \).
   - Similarly, for the width \( m \), the number of flagstones required is \((m + a - 1) // a\).
3. **Computing Total Flagstones**: The product of the two computed values gives the total number of flagstones needed to cover the entire Theatre Square.

This approach ensures that we efficiently compute the minimum number of flagstones using integer arithmetic, which handles large values up to \( 10^9 \) efficiently. The solution is optimal with a time complexity of \( O(1) \), as it involves a constant number of arithmetic operations.
