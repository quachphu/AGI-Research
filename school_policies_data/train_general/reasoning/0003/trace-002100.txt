To solve this problem, we need to generate two formatted strings from a given input word. The first string is the original word with each letter separated by a dash, and the second string is the reversed word with each letter separated by a dash. 

### Approach
1. **Reading Input**: The input word is read from standard input.
2. **Formatting the Original Word**: Convert the original word into a string where each character is separated by a dash.
3. **Reversing the Word**: Reverse the original word and then format it similarly with dashes between each character.
4. **Output**: Print both formatted strings on separate lines.

### Solution Code
```python
def process_word():
    word = input().strip()
    print('-'.join(word))
    print('-'.join(word[::-1]))

process_word()
```

### Explanation
1. **Reading Input**: The input word is read using `input().strip()` to ensure any leading or trailing whitespace is removed.
2. **Formatting the Original Word**: The `join` method is used with a dash as the separator to concatenate each character of the word into a single string.
3. **Reversing the Word**: The word is reversed using slicing (`word[::-1]`), and then the reversed word is formatted using the same `join` method with dashes.
4. **Output**: The formatted original and reversed words are printed on consecutive lines.

This approach efficiently processes the input and generates the required output in linear time relative to the length of the word, ensuring optimal performance.
