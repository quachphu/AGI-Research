To solve this problem, we need to compute the binomial coefficient \( C(N, K) \) modulo 1009 for very large values of \( N \) (up to \( 10^{15} \)). Direct computation using factorials is infeasible due to the large size, so we use Lucas's theorem to break down the problem into smaller subproblems.

### Approach
1. **Lucas's Theorem**: This theorem allows us to compute binomial coefficients modulo a prime \( p \) by decomposing \( N \) and \( K \) into their base \( p \) digits. The theorem states that \( C(N, K) \mod p \) is the product of the binomial coefficients of the corresponding digits of \( N \) and \( K \) in base \( p \).

2. **Precomputation**: Since \( p = 1009 \) is a prime, we precompute factorials and their modular inverses up to 1008. This allows efficient computation of binomial coefficients for digits in base 1009.

3. **Digit Decomposition**: Convert \( N \) and \( K \) into their base 1009 digits. If any digit of \( K \) exceeds the corresponding digit of \( N \), the result is zero. Otherwise, compute the product of the binomial coefficients of corresponding digits modulo 1009.

### Solution Code
```python
p = 1009

# Precompute factorial and inverse factorial modulo p
fact = [1] * p
for i in range(1, p):
    fact[i] = fact[i-1] * i % p

inv_fact = [1] * p
inv_fact[p-1] = pow(fact[p-1], p-2, p)
for i in range(p-2, -1, -1):
    inv_fact[i] = inv_fact[i+1] * (i+1) % p

def comb(n, k):
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % p * inv_fact[n - k] % p

def get_digits(x):
    digits = []
    if x == 0:
        digits.append(0)
    else:
        while x > 0:
            digits.append(x % p)
            x = x // p
    return digits

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    if k == 0:
        print(1)
        continue
    n_digits = get_digits(n)
    k_digits = get_digits(k)
    max_len = max(len(n_digits), len(k_digits))
    n_digits += [0] * (max_len - len(n_digits))
    k_digits += [0] * (max_len - len(k_digits))
    result = 1
    for nd, kd in zip(n_digits, k_digits):
        if kd > nd:
            result = 0
            break
        result = result * comb(nd, kd) % p
    print(result)
```

### Explanation
1. **Precomputation**: We precompute the factorial values modulo 1009 and their modular inverses using Fermat's Little Theorem. This allows us to compute binomial coefficients efficiently using these precomputed values.

2. **Digit Decomposition**: The function `get_digits` converts a number into its base 1009 digits. This helps in breaking down the problem into smaller subproblems as per Lucas's theorem.

3. **Combining Results**: For each test case, we decompose \( N \) and \( K \), pad the shorter digit list with zeros, then compute the product of binomial coefficients for each corresponding digit pair. If any digit of \( K \) exceeds the corresponding digit of \( N \), the result is immediately zero.

This approach efficiently handles the large values of \( N \) and \( K \) by leveraging modular arithmetic and Lucas's theorem, ensuring the solution is computed within feasible time limits.
