To solve this problem, we need to determine the number of distinct loops in a grid where each tile points to another tile. A loop is defined as a cycle where starting from a tile and following the jumps repeatedly leads back to the starting tile, forming an infinite cycle.

### Approach
1. **Input Reading**: Read the grid dimensions and the jump destinations for each tile.
2. **Cycle Detection**: For each tile, if it hasn't been visited, follow the path of jumps starting from that tile. Track the path taken and detect cycles by checking if a tile is revisited within the current traversal.
3. **Cycle Marking**: When a cycle is detected, mark all tiles in the cycle as visited to avoid counting the same cycle multiple times.
4. **Count Loops**: Each time a new cycle is detected, increment the loop count.

### Solution Code
```python
import sys

def main():
    while True:
        line = sys.stdin.readline()
        if not line:
            break
        N = int(line.strip())
        if N == 0:
            break
        grid = [[(0, 0) for _ in range(N)] for __ in range(N)]
        for j in range(N):
            parts = list(map(int, sys.stdin.readline().split()))
            for i in range(N):
                x = parts[2 * i]
                y = parts[2 * i + 1]
                grid[i][j] = (x, y)
        visited = set()
        count = 0
        for i in range(N):
            for j in range(N):
                if (i, j) not in visited:
                    path = []
                    current = (i, j)
                    while True:
                        if current in visited:
                            break
                        if current in path:
                            idx = path.index(current)
                            cycle = path[idx:]
                            for tile in cycle:
                                visited.add(tile)
                            count += 1
                            break
                        path.append(current)
                        x, y = grid[current[0]][current[1]]
                        current = (x, y)
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read line by line. The first line of each test case gives the grid size \( N \). Subsequent \( N \) lines provide the jump destinations for each tile in the grid.
2. **Grid Construction**: The grid is constructed as a 2D list where each element at position (i, j) contains the coordinates (x, y) of the tile it jumps to.
3. **Cycle Detection**: For each tile (i, j), if it hasn't been visited, a traversal starts from this tile. The path taken during traversal is recorded. If a tile is revisited during this traversal, a cycle is detected.
4. **Cycle Marking and Counting**: Once a cycle is detected, all tiles in the cycle are marked as visited to prevent reprocessing. The loop count is incremented each time a new cycle is found.

This approach ensures that each tile is processed exactly once, leading to an efficient solution with a time complexity of \( O(N^2) \) per test case, which is optimal for the given problem constraints.
