To solve this problem, we need to equip as many soldiers as possible with bulletproof vests given their size preferences and the available vest sizes. Each soldier can use a vest if its size falls within a specific range determined by their preferred size and two given tolerance values.

### Approach
1. **Input Reading**: Read the number of soldiers, number of vests, and the tolerance values. Then read the preferred sizes of soldiers and the available vest sizes.
2. **Two-Pointer Technique**: Use two pointers to efficiently match soldiers with vests. This technique is chosen because both lists (soldiers' preferred sizes and available vest sizes) are sorted in non-decreasing order.
3. **Greedy Matching**: For each soldier, find the smallest vest that fits within their acceptable range. If a vest is found, assign it and move both pointers forward. If not, move to the next soldier.

### Solution Code
```python
import sys

def main():
    n, m, x, y = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    b = list(map(int, sys.stdin.readline().split()))
    
    i = j = 0
    res = []
    
    while i < n and j < m:
        current_a = a[i]
        lower = current_a - x
        upper = current_a + y
        
        # Move j to the first vest >= lower
        while j < m and b[j] < lower:
            j += 1
        
        # Check if this vest is within the upper limit
        if j < m and b[j] <= upper:
            res.append((i + 1, j + 1))
            i += 1
            j += 1
        else:
            i += 1
    
    print(len(res))
    for pair in res:
        print(pair[0], pair[1])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using standard input functions. The first line contains the number of soldiers, vests, and the tolerance values. The next two lines contain the sorted lists of preferred sizes and vest sizes.
2. **Two-Pointer Technique**: We use two pointers, `i` for soldiers and `j` for vests. For each soldier, we determine the minimum and maximum vest size they can use.
3. **Greedy Matching**: The inner loop moves the vest pointer `j` to the first vest that meets the minimum size requirement of the current soldier. If this vest also meets the maximum size requirement, it is assigned to the soldier, and both pointers are moved forward. If not, the soldier pointer is moved to the next soldier.
4. **Output**: The results are collected in a list and printed in the required format.

This approach ensures that we efficiently match each soldier with the earliest possible vest that fits their range, maximizing the number of soldiers equipped with vests. The algorithm runs in linear time, O(n + m), making it suitable for large input sizes.
