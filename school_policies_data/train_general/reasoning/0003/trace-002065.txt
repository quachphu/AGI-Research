To solve this problem, we need to determine the winner between Alice and Bob based on their AOJ rates and 50m sprint times. The solution involves comparing their AOJ rates if both are valid; otherwise, their sprint times are compared.

### Approach
1. **Input Reading**: Read the input values which include the sprint times (T1, T2) and AOJ rates (R1, R2) for Alice and Bob.
2. **Check Validity of AOJ Rates**: If both AOJ rates (R1 and R2) are valid (i.e., not -1), compare them directly. The person with the higher rate wins.
3. **Handle Invalid AOJ Rates**: If either AOJ rate is invalid (i.e., -1), compare the sprint times instead. The person with the shorter time wins.
4. **Draw Conditions**: If the compared values (either rates or times) are equal, the result is a draw.

### Solution Code
```python
def determine_winner():
    T1, T2, R1, R2 = map(int, input().split())
    if R1 != -1 and R2 != -1:
        if R1 > R2:
            print("Alice")
        elif R1 < R2:
            print("Bob")
        else:
            print("Draw")
    else:
        if T1 < T2:
            print("Alice")
        elif T1 > T2:
            print("Bob")
        else:
            print("Draw")

determine_winner()
```

### Explanation
- **Reading Input**: The input values are read and parsed into integers representing the sprint times and AOJ rates.
- **AOJ Rate Comparison**: If both AOJ rates are valid, the higher rate determines the winner. If both rates are equal, the result is a draw.
- **Sprint Time Comparison**: If either AOJ rate is invalid, the sprint times are compared. The shorter time determines the winner, with a draw if the times are equal.

This approach ensures that we handle both valid and invalid AOJ rates appropriately, providing the correct winner based on the given conditions.
