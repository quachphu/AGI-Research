To solve this problem, we need to determine the minimum sum of costs required to reduce an array to a single element by repeatedly removing the larger of two adjacent elements, with the cost of each operation being the smaller element in the pair.

### Approach
The key insight is that the optimal strategy involves leveraging the smallest element in the array. Each time we remove an element, the smallest element in the array will always be the cost of the operation. This is because the smallest element will always be the smaller of any pair it is part of. Therefore, the total minimum cost is simply the smallest element multiplied by the number of operations required, which is the number of elements minus one.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        a = list(map(int, sys.stdin.readline().split()))
        min_a = min(a)
        print(min_a * (n - 1))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The input is read using standard input methods for efficiency, especially given the constraints.
2. **Finding Minimum Element:** For each test case, we determine the smallest element in the array. This element will be the cost for each operation.
3. **Calculating Total Cost:** The total number of operations needed to reduce the array to a single element is \(N-1\), where \(N\) is the initial size of the array. Multiplying the smallest element by \(N-1\) gives the minimum total cost.

This approach ensures that we efficiently compute the result in linear time for each test case, making it suitable even for the upper constraint limits.
