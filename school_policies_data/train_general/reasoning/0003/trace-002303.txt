To solve this problem, we need to determine if the input string contains the characters 'h', 'e', 'l', 'l', 'o' in sequence, allowing for other characters to be interspersed between them. The goal is to check if these characters appear in the correct order to form the word "hello".

### Approach
1. **Problem Analysis**: The problem requires checking if the input string can be transformed into the word "hello" by deleting some characters. The key insight is that the characters 'h', 'e', 'l', 'l', 'o' must appear in sequence but not necessarily consecutively.
2. **Algorithm**: We will iterate through the input string to find each character of "hello" in order. Starting from the beginning of the string, we look for 'h', then 'e' after the position of 'h', followed by the first 'l' after 'e', the second 'l' after the first 'l', and finally 'o' after the second 'l'. If all characters are found in this order, the answer is "YES"; otherwise, it is "NO".
3. **Complexity**: The time complexity of this approach is O(n), where n is the length of the input string. This is because we traverse the string once in the worst case.

### Solution Code
```python
def main():
    s = input().strip()
    target = 'hello'
    current_pos = 0
    for char in target:
        idx = s.find(char, current_pos)
        if idx == -1:
            print("NO")
            return
        current_pos = idx + 1
    print("YES")

main()
```

### Explanation
1. **Reading Input**: The input string is read from standard input.
2. **Target Sequence**: The target sequence we are looking for is "hello".
3. **Character Search**: For each character in the target sequence, we use the `find` method to locate its position starting from the current position in the input string. If any character is not found in the required order, we immediately print "NO" and exit.
4. **Update Position**: After finding each character, we update the current position to start searching from the next index to ensure characters are in the correct order.
5. **Result**: If all characters of "hello" are found in sequence, we print "YES"; otherwise, "NO".

This approach efficiently checks for the required sequence and handles all edge cases, ensuring correctness and optimal performance.
