To solve this problem, we need to determine if Limak can split a square chocolate bar into two parts such that each part contains an equal number of cherries. The split must be made either horizontally between two rows or vertically between two columns.

### Approach
1. **Input Reading**: Read the number of test cases and each test case's grid.
2. **Total Cherries Check**: Calculate the total number of cherries in the grid. If the total is odd, output "NO" immediately since an odd number of cherries cannot be split into two equal parts.
3. **Horizontal Split Check**: Compute the cumulative sum of cherries row-wise and check if there's a horizontal split where the sum of cherries in the top part equals half of the total cherries.
4. **Vertical Split Check**: If no valid horizontal split is found, compute the cumulative sum of cherries column-wise and check for a valid vertical split.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N = int(input[idx])
        idx += 1
        grid = []
        for _ in range(N):
            grid.append(input[idx])
            idx += 1
        row_sums = [row.count('#') for row in grid]
        total = sum(row_sums)
        if total % 2 != 0:
            print("NO")
            continue
        target = total // 2
        # Check horizontal cuts
        current = 0
        found = False
        for i in range(N):
            current += row_sums[i]
            if i < N - 1 and current == target:
                found = True
                break
        if found:
            print("YES")
            continue
        # Check vertical cuts
        columns = zip(*grid)
        col_sums = [col.count('#') for col in columns]
        current_col = 0
        for j in range(N):
            current_col += col_sums[j]
            if j < N - 1 and current_col == target:
                print("YES")
                break
        else:
            print("NO")

solve()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints. The grid for each test case is stored as a list of strings.
2. **Row-wise Check**: For each row, the number of cherries is counted and stored in `row_sums`. The cumulative sum of these values is computed on-the-fly to check if a valid horizontal split exists.
3. **Column-wise Check**: If no valid horizontal split is found, the grid is transposed using `zip(*grid)` to get columns. The number of cherries in each column is counted and stored in `col_sums`. The cumulative sum of these values is checked for a valid vertical split.
4. **Efficiency**: The approach efficiently checks both possible splits in O(N) time for rows and columns respectively, making the solution feasible even for the upper constraint of N = 1000.
