The solution involves checking if the graph formed by these pairs can be arranged into a straight line without any cycles and ensuring no node has more than two neighbors.

### Approach
1. **Graph Construction**: Represent the girls and their pairs as an undirected graph where each node (girl) is connected to others based on the given pairs.
2. **Degree Check**: Ensure no node has a degree greater than 2, as a node with three or more neighbors cannot be part of a straight line.
3. **Cycle Detection**: For each connected component in the graph, check if it forms a cycle. This is done by verifying if the number of edges in the component is exactly one less than the number of nodes (a tree structure), which ensures it is a chain (path) rather than a cycle.

import sys
from collections import deque

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        M = int(input[ptr + 1])
        ptr += 2
        adj = [[] for _ in range(N + 1)]
        degrees = [0] * (N + 1)
        for _ in range(M):
            x = int(input[ptr])
            y = int(input[ptr + 1])
            ptr += 2
            adj[x].append(y)
            adj[y].append(x)
            degrees[x] += 1
            degrees[y] += 1
        
        valid = True
        for i in range(1, N + 1):
            if degrees[i] > 2:
                valid = False
                break
        if not valid:
            print("NO")
            continue
        
        visited = [False] * (N + 1)
        for i in range(1, N + 1):

                visited[i] = True
                sum_deg = degrees[i]
                count_nodes = 1

                    for v in adj[u]:
                        if not visited[v]:
                            visited[v] = True
                            q.append(v)
                            sum_deg += degrees[v]

                edges = sum_deg // 2
                if edges != (count_nodes - 1):

                    break
        
        print("YES" if valid else "NO")
