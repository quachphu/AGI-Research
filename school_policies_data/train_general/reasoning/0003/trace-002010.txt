To solve this problem, we need to determine if all characters in a given string are unique. The solution involves checking the length of the string against the length of a set created from the string, as sets automatically remove duplicate elements. If both lengths are equal, all characters are unique; otherwise, there are duplicates.

### Approach
1. **Read Input**: The input string is read from standard input.
2. **Check for Unique Characters**: Convert the string into a set to remove any duplicate characters. Compare the length of the original string with the length of the set.
3. **Output Result**: If the lengths are equal, print "yes" indicating all characters are unique. Otherwise, print "no".

### Solution Code
```python
def main():
    s = input().strip()
    if len(set(s)) == len(s):
        print("yes")
    else:
        print("no")

main()
```

### Explanation
1. **Reading Input**: The function reads the input string using `input().strip()` to ensure any leading or trailing whitespace is removed.
2. **Set Conversion**: Converting the string to a set removes any duplicate characters. The length of this set is then compared to the length of the original string.
3. **Comparison and Output**: If the lengths match, it means all characters in the string are unique, so "yes" is printed. Otherwise, "no" is printed indicating the presence of duplicate characters.

This approach efficiently checks for uniqueness using the properties of sets, ensuring an optimal solution with a time complexity of O(n), where n is the length of the string.
