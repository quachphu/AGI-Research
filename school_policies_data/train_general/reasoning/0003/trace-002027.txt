To solve this problem, we need to determine if there exists a point (X, Y) on an infinite coordinate plane where all robots can gather given their movement constraints. Each robot can only move in certain directions, and we need to find a common point reachable by all robots.

### Approach
1. **Constraints Analysis**: Each robot has specific movement constraints. For instance, if a robot cannot move left (f1=0), its X-coordinate cannot be less than its initial position. Similarly, other directions constrain the robot's movement in the respective axis.
2. **Global Bounds Calculation**: For each query, calculate the global bounds for X and Y by considering all robots' constraints:
   - **X Constraints**: Determine the maximum lower bound (global_min_x) and the minimum upper bound (global_max_x) for X.
   - **Y Constraints**: Determine the maximum lower bound (global_min_y) and the minimum upper bound (global_max_y) for Y.
3. **Feasibility Check**: If the calculated global bounds for X or Y are invalid (i.e., lower bound exceeds upper bound), it is impossible for all robots to gather. Otherwise, compute the feasible point within the bounds, ensuring it lies within the range [-100000, 100000].

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    q = int(input[ptr])
    ptr += 1
    for _ in range(q):
        n = int(input[ptr])
        ptr += 1
        global_min_x = -10**18
        global_max_x = 10**18
        global_min_y = -10**18
        global_max_y = 10**18
        for __ in range(n):
            x = int(input[ptr])
            y = int(input[ptr+1])
            f1 = int(input[ptr+2])
            f2 = int(input[ptr+3])
            f3 = int(input[ptr+4])
            f4 = int(input[ptr+5])
            ptr +=6
            if f1 == 0:
                if x > global_min_x:
                    global_min_x = x
            if f3 == 0:
                if x < global_max_x:
                    global_max_x = x
            if f4 == 0:
                if y > global_min_y:
                    global_min_y = y
            if f2 == 0:
                if y < global_max_y:
                    global_max_y = y
        if global_min_x > global_max_x or global_min_y > global_max_y:
            print(0)
        else:
            # Compute X
            X = max(global_min_x, -100000)
            X = min(X, global_max_x)
            X = min(X, 100000)
            # Compute Y
            Y = max(global_min_y, -100000)
            Y = min(Y, global_max_y)
            Y = min(Y, 100000)
            print(f"1 {X} {Y}")
```
