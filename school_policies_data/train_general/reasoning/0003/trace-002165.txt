To solve this problem, we need to compute the sum of the first \( n \) prime numbers for multiple datasets efficiently. The solution involves precomputing the first 10,000 prime numbers and their cumulative sums to quickly answer each query in constant time.

### Approach
1. **Prime Generation using Sieve of Eratosthenes**: We use the Sieve of Eratosthenes algorithm to generate all primes up to a sufficiently large number (105,000). This ensures we capture the first 10,000 primes, as the 10,000th prime is known to be 104,729.
2. **Prefix Sum Calculation**: Once the primes are generated, we compute the cumulative sums of these primes. This allows us to answer each query in constant time by simply looking up the precomputed sum.

### Solution Code
```python
def sieve(limit):
    sieve = [True] * (limit + 1)
    sieve[0] = sieve[1] = False
    for i in range(2, int(limit ** 0.5) + 1):
        if sieve[i]:
            sieve[i*i : limit+1 : i] = [False] * len(sieve[i*i : limit+1 : i])
    primes = [i for i, is_p in enumerate(sieve) if is_p]
    return primes

# Generate primes up to 105000 to ensure we get the first 10000 primes
primes = sieve(105000)
primes = primes[:10000]

# Compute prefix sums
sum_list = [0] * (len(primes) + 1)
current_sum = 0
for i in range(len(primes)):
    current_sum += primes[i]
    sum_list[i+1] = current_sum

import sys

for line in sys.stdin:
    n = int(line.strip())
    if n == 0:
        break
    print(sum_list[n])
```

### Explanation
1. **Prime Generation**: The Sieve of Eratosthenes efficiently generates all prime numbers up to a given limit (105,000 in this case). This method marks non-prime numbers in a boolean array, allowing us to collect primes in linear time relative to the limit.
2. **Prefix Sum Calculation**: After generating the primes, we compute the cumulative sums of these primes. This precomputation allows each query to be answered in \( O(1) \) time by directly accessing the precomputed sums.
3. **Efficiency**: By precomputing the primes and their sums, we handle up to 50 datasets efficiently, even for the maximum \( n \) value of 10,000. The sieve method ensures we generate primes quickly, and the prefix sums allow instant query responses.

This approach ensures that the solution is both time-efficient and scalable, handling the upper limits of the problem constraints effectively.
