To solve this problem, we need to determine the maximum number of sandwiches Yun can make without any leftover bread. Each sandwich requires two breads, so the total number of breads must be even. The solution involves finding the maximum even sum of selected bread sets and then dividing that sum by two to get the number of sandwiches.

### Approach
1. **Sum Calculation**: Calculate the total sum of all bread sets.
2. **Check Even Sum**: If the total sum is even, the maximum number of sandwiches is simply half of this sum.
3. **Handle Odd Sum**: If the total sum is odd, we need to adjust it to the nearest even number. This is done by subtracting the smallest odd number from the total sum, as removing the smallest odd number will yield the largest possible even sum.
4. **Result Calculation**: The result is the adjusted even sum divided by two.

### Solution Code
```python
def main():
    import sys
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    total = sum(a)
    if total % 2 == 0:
        print(total // 2)
    else:
        min_odd = None
        for num in a:
            if num % 2 == 1:
                if min_odd is None or num < min_odd:
                    min_odd = num
        if min_odd is not None:
            print((total - min_odd) // 2)
        else:
            print(0)

main()
```

### Explanation
1. **Reading Input**: The code reads the number of bread sets and the number of breads in each set.
2. **Total Sum Calculation**: It calculates the total number of breads available.
3. **Even Sum Check**: If the total sum is even, it directly computes the number of sandwiches as half of the total sum.
4. **Odd Sum Adjustment**: If the total sum is odd, the code finds the smallest odd number in the list. Subtracting this smallest odd number from the total sum converts it to the largest possible even sum.
5. **Output Result**: The adjusted even sum is divided by two to get the maximum number of sandwiches, which is then printed.

This approach ensures that we efficiently determine the maximum number of sandwiches by leveraging mathematical properties of even and odd sums, resulting in an optimal solution.
