To solve this problem, we need to determine the smallest subset of integers from a given sequence such that the greatest common divisor (GCD) of the subset is 1. If no such subset exists, we should return -1.

### Approach
1. **Check Overall GCD**: First, compute the GCD of the entire array. If the GCD is not 1, it means all elements share a common divisor greater than 1, so no subset can have a GCD of 1. Hence, we return -1 immediately.
2. **Check for Presence of 1**: If any element in the array is 1, the smallest subset is just that element itself (size 1).
3. **Dynamic Programming Approach**: If the above checks fail, use a dynamic programming approach to track the minimal number of elements required to achieve each possible GCD value. For each element in the array, update the possible GCD values and their counts by combining with previous values.

### Solution Code
```python
import sys
import math
from functools import reduce

def main():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    
    overall_gcd = reduce(math.gcd, a)
    if overall_gcd != 1:
        print(-1)
        return
    
    if 1 in a:
        print(1)
        return
    
    current_gcds = {}
    for num in a:
        temp = {}
        # Process existing GCDs
        for g in list(current_gcds.keys()):
            new_gcd = math.gcd(g, num)
            new_count = current_gcds[g] + 1
            if new_gcd in temp:
                if new_count < temp[new_gcd]:
                    temp[new_gcd] = new_count
            else:
                temp[new_gcd] = new_count
        # Add current number as a new subset of size 1
        if num in temp:
            if 1 < temp[num]:
                temp[num] = 1
        else:
            temp[num] = 1
        # Merge temp into current_gcds
        for g in temp:
            if g in current_gcds:
                if temp[g] < current_gcds[g]:
                    current_gcds[g] = temp[g]
            else:
                current_gcds[g] = temp[g]
    
    print(current_gcds.get(1, -1))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Overall GCD Check**: The GCD of the entire array is computed first. If it is not 1, output -1.
2. **Presence of 1**: If any element is 1, the answer is 1 since a single element with value 1 has a GCD of 1.
3. **Dynamic Programming**: For each element, maintain a dictionary (`current_gcds`) that tracks the minimum number of elements required to achieve each possible GCD. For each new element, update the dictionary by combining it with existing GCD values, and check if a GCD of 1 can be achieved. The smallest count for achieving GCD 1 is the answer.

This approach efficiently tracks possible GCD values and their minimal subset sizes using dynamic programming, ensuring that we find the smallest subset with the desired GCD in a feasible time complexity.
