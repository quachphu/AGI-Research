To solve this problem, we need to determine the values of two numbers, A and B, after performing a series of operations exactly N times. The operations alternate between modifying A and B based on whether the step number is odd or even. Given the constraints, we need an efficient approach to handle very large values of N.

### Approach
1. **Identify the Cycle**: Through analysis, we observe that the operations on A and B repeat every 12 steps. This means after every 12 steps, the values of A and B return to their original values. This cycle allows us to reduce the problem size by considering only the remainder of N divided by 12.
2. **Modulo Operation**: Compute the effective number of steps as \( N \mod 12 \). If the result is 0, we use 12 steps instead (since 12 steps form a complete cycle).
3. **Simulate the Operations**: Perform the operations for the computed number of steps (up to 12), which is manageable even for very large N.

### Solution Code
```python
n = int(input())
a, b = map(int, input().split())
m = n % 12
if m == 0:
    m = 12
for i in range(1, m + 1):
    if i % 2 == 1:
        a -= b
    else:
        b += a
print(a, b)
```

### Explanation
1. **Cycle Detection**: By simulating the operations, we found that after every 12 steps, the values of A and B return to their initial values. This allows us to handle very large N efficiently by reducing the problem using modulo 12.
2. **Effective Steps Calculation**: Instead of processing all N steps, we compute \( N \mod 12 \) to determine the effective number of steps needed. If the result is 0, we use 12 steps to complete the cycle.
3. **Simulation**: For each of the effective steps, we perform the appropriate operation based on whether the step is odd or even. This ensures that we only process up to 12 steps, making the solution efficient even for the upper constraint of \( N = 10^{18} \).

This approach efficiently handles the problem constraints and ensures optimal performance by leveraging the cyclic nature of the operations.
