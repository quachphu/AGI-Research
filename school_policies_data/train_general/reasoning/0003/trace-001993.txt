To solve this problem, we need to determine the encryption of a row in a Japanese crossword. The encryption involves counting consecutive groups of black squares ('B') in a given string and outputting the count of such groups followed by their respective lengths.

### Approach
1. **Input Reading**: Read the input values, which include the length of the row (n) and the string representing the row.
2. **Tracking Groups**: Iterate through the string to track groups of consecutive 'B's. Each time a 'W' is encountered after a 'B', it signifies the end of a group. If the string ends with a 'B', ensure this final group is counted.
3. **Output the Results**: After processing the string, output the number of groups followed by the lengths of each group in order.

### Solution Code
```python
n = int(input())
s = input().strip()

current = 0
groups = []

for c in s:
    if c == 'B':
        current += 1
    else:
        if current > 0:
            groups.append(current)
            current = 0
if current > 0:
    groups.append(current)

print(len(groups))
if groups:
    print(' '.join(map(str, groups)))
else:
    print()
```

### Explanation
1. **Reading Input**: The first line of input is the length of the row, which is not directly used but helps in understanding the problem constraints. The second line is the string of 'B's and 'W's.
2. **Tracking Consecutive 'B's**: As we iterate through the string, we maintain a counter (`current`) for consecutive 'B's. When a 'W' is encountered, if we were counting a group of 'B's, we add this count to our list of groups and reset the counter.
3. **Handling End of String**: After the loop, if there's an ongoing count of 'B's (i.e., the string ends with 'B'), we add this final count to our groups list.
4. **Output**: The first output line is the number of groups. The second line lists the lengths of these groups, or an empty line if there are no groups.

This approach efficiently processes the string in linear time, ensuring that each character is checked exactly once, making it optimal for the problem constraints.
