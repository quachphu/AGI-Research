To solve this problem, we need to generate two permutations of integers from 1 to n that satisfy given comparison results. The first permutation should minimize the length of the Longest Increasing Subsequence (LIS), while the second should maximize it.

### Approach
1. **Minimal LIS Sequence**:
   - **Key Insight**: To minimize the LIS, create the longest possible decreasing runs for consecutive '>' characters. This ensures that each decreasing run contributes minimally to the LIS.
   - **Algorithm**: Traverse the comparison string from left to right. For each group of consecutive '>' characters, assign the largest available numbers in reverse order. For '<' groups, assign the smallest available numbers in increasing order.

2. **Maximal LIS Sequence**:
   - **Key Insight**: To maximize the LIS, create the longest possible increasing runs for consecutive '<' characters. This ensures that each increasing run contributes maximally to the LIS.
   - **Algorithm**: Traverse the comparison string from left to right. For each group of consecutive '<' characters, assign the smallest available numbers in increasing order. For '>' groups, assign the largest available numbers in reverse order.

def solve():
    import sys
    input = sys.stdin.read
    data = input().split()
    t = int(data[0])
    idx = 1
    for _ in range(t):
        n = int(data[idx])
        s = data[idx+1]
        idx += 2

        # Build minimal LIS sequence
        min_seq = []

        while i < len(s):

                min_seq.append(i + 1)
                i += 1
            else:
                j = i
                while j < len(s) and s[j] == '>':
                    j += 1
                # Assign from j down to i
                for k in range(j, i - 1, -1):
                    min_seq.append(k + 1)
                i = j
        if len(min_seq) < n:
            min_seq.append(n)

        # Build maximal LIS sequence
        max_seq = []
        current_min = 1
        i = 0
        while i < len(s):

                current_min += 1
                i += 1

                    j += 1

                length = j - i + 1
                for k in range(current_min + length - 1, current_min - 1, -1):
                    max_seq.append(k)
                current_min += length
                i = j
