To solve this problem, we need to determine the minimum number of moves required for a rook, a bishop, and a king to move from a starting position to a target position on a chessboard. Each piece has distinct movement rules, which we need to leverage to compute the answer efficiently.

### Approach

1. **Rook's Movement**:
   - A rook moves horizontally or vertically any number of squares.
   - If the starting and target positions are in the same row or column, the rook can reach the target in 1 move.
   - Otherwise, the rook needs 2 moves: first to align with the target's row or column, then to move directly to the target.

2. **Bishop's Movement**:
   - A bishop moves diagonally any number of squares.
   - The bishop can only reach squares of the same color. If the starting and target positions are on different colors, it is impossible (0 moves).
   - If they are on the same color, check if they are on the same diagonal (sum or difference of coordinates are equal). If yes, 1 move is needed; otherwise, 2 moves.

3. **King's Movement**:
   - A king moves one square in any direction.
   - The minimum moves required are the maximum of the horizontal and vertical distances between the starting and target positions.

### Solution Code

```python
r1, c1, r2, c2 = map(int, input().split())

# Calculate rook moves
rook = 1 if (r1 == r2) or (c1 == c2) else 2

# Calculate bishop moves
if (r1 + c1) % 2 != (r2 + c2) % 2:
    bishop = 0
else:
    if (r1 - c1 == r2 - c2) or (r1 + c1 == r2 + c2):
        bishop = 1
    else:
        bishop = 2

# Calculate king moves
king = max(abs(r1 - r2), abs(c1 - c2))

print(rook, bishop, king)
```

### Explanation

- **Rook's Moves**:
  - Check if the starting and target positions share the same row or column. If yes, the rook moves once; otherwise, it takes two moves.

- **Bishop's Moves**:
  - Determine if the starting and target positions are on the same color by checking the parity of the sum of their coordinates. If different, output 0.
  - If on the same color, check if they lie on the same diagonal (sum or difference of coordinates match). If yes, one move; otherwise, two moves.

- **King's Moves**:
  - The king moves one square at a time in any direction. The minimum number of moves is the maximum of the horizontal and vertical distances between the start and target positions.

This approach efficiently computes the required moves for each piece using straightforward mathematical checks, ensuring optimal performance and correctness.
