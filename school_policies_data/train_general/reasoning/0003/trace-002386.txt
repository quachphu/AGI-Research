To solve this problem, we need to determine the number of symmetric strings (palindromes) from a given input. A symmetric string reads the same forwards and backwards. 

### Approach
1. **Reading Input**: Read each line from the standard input until the end of the input stream.
2. **Check Symmetry**: For each line, check if the string is symmetric by comparing it with its reverse.
3. **Count Symmetric Strings**: Maintain a counter to keep track of how many symmetric strings are encountered.
4. **Output the Result**: Print the count of symmetric strings after processing all input lines.

### Solution Code
```python
import sys

def count_symmetric():
    count = 0
    for line in sys.stdin:
        s = line.strip()
        if s == s[::-1]:
            count += 1
    print(count)

count_symmetric()
```

### Explanation
1. **Reading Input**: The code uses `sys.stdin` to read each line from the input. This allows us to handle multiple lines efficiently.
2. **String Processing**: Each line read from the input is stripped of leading and trailing whitespace (including newline characters) using `strip()`.
3. **Symmetry Check**: For each processed string, we check if it is symmetric by comparing the string with its reverse (`s[::-1]`). If they are the same, the string is symmetric.
4. **Counting**: Each time a symmetric string is found, the counter is incremented.
5. **Result Output**: After processing all input lines, the total count of symmetric strings is printed.

This approach ensures that each line is processed in linear time relative to its length, making the solution efficient even for the upper limit of input constraints.
