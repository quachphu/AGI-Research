To solve this problem, we need to determine the minimum number of moves required for a robot to collect all useful items from various boxes and place them into a single box. The robot can only carry one item at a time, and each move from one box to an adjacent box while carrying an item counts as a move. The goal is to find the optimal box where the robot should collect all items to minimize the total number of moves.

### Approach
1. **Understanding the Problem**: The robot needs to move each item from its current position to a target position. The optimal target position is the one that minimizes the sum of distances from all item positions to this target. This sum of distances is minimized when the target position is the median of all item positions.
2. **Median Calculation**: The median of a list of numbers is the middle value when the numbers are sorted. For an odd number of elements, it is the middle element. For an even number of elements, it can be either of the two middle elements, both of which yield the same minimum sum of distances.
3. **Algorithm**:
   - Read the input values.
   - For each test case, sort the positions of the useful items.
   - Determine the median position from the sorted list.
   - Calculate the sum of absolute differences between each item position and the median, which gives the minimum number of moves.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        p = list(map(int, input[ptr:ptr+N]))
        ptr += N
        p.sort()
        median = p[(N - 1) // 2]
        total = sum(abs(num - median) for num in p)
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read all at once for efficiency, especially given the large possible size of input data.
- **Sorting**: The positions of the useful items are sorted to easily find the median.
- **Finding Median**: The median is determined using integer division to find the middle index of the sorted list.
- **Calculating Moves**: The total number of moves is computed by summing the absolute differences between each item position and the median. This sum is the minimum number of moves required as it leverages the property of the median minimizing the sum of absolute deviations.

This approach ensures that we efficiently compute the solution using sorting and median calculation, which are optimal for this problem's constraints. The overall complexity is O(N log N) per test case due to sorting, which is efficient given the problem constraints.
