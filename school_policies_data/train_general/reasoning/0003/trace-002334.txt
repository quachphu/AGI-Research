To solve this problem, we need to count the number of substrings in a binary string that start and end with '1'. The solution involves a mathematical insight that simplifies the problem significantly.

### Approach
1. **Problem Analysis**: 
   - A substring starting and ending with '1' can be formed between any two '1's in the string, including the same '1' (which forms a substring of length 1).
   - The number of such substrings can be determined by counting the number of '1's in the string and using combinatorial mathematics. If there are `k` '1's, the number of valid substrings is given by the formula `k * (k + 1) / 2`, which accounts for all possible pairs of '1's and individual '1's.

2. **Algorithm**:
   - Read the input values.
   - For each test case, count the number of '1's in the string.
   - Apply the formula `k * (k + 1) / 2` to compute the result for each test case.

3. **Complexity**:
   - The time complexity is O(N) for each test case where N is the length of the string, as we need to traverse the string to count the '1's. Given the constraints, the overall complexity is manageable as the sum of all string lengths across test cases is up to 100,000.

### Solution Code
```python
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    T = int(data[idx])
    idx += 1
    for _ in range(T):
        N = int(data[idx])
        idx += 1
        S = data[idx]
        idx += 1
        count = S.count('1')
        print(count * (count + 1) // 2)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read all at once for efficiency, especially given the large possible number of test cases. This approach avoids repeated I/O operations which can be slow.
- **Processing Each Test Case**: For each test case, we ignore the string length (since it can be derived from the string itself) and directly count the number of '1's in the string.
- **Mathematical Formula**: Using the formula `k * (k + 1) / 2` allows us to efficiently compute the number of valid substrings without explicitly generating each substring, leading to an optimal solution. This formula is derived from the sum of the first `k` natural numbers, which accounts for all possible pairs of '1's (including single '1's as valid substrings).

This approach ensures that we handle the problem constraints efficiently and correctly.
