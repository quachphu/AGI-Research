To solve this problem, we need to determine the number of ways to fill an n x m grid with integers such that the product of integers in each row and each column equals k (either 1 or -1). The answer must be given modulo 1000000007.

### Approach
1. **Check Validity for k = -1**: If k is -1, the sum of n and m must be even. If not, it's impossible to fill the grid, so the answer is 0.
2. **Exponent Calculation**: If the grid is valid, the number of valid configurations is determined by the formula \(2^{(n-1)(m-1) \mod (10^9+6)} \mod 10^9+7\). This is derived from the fact that the first (n-1) rows and (m-1) columns can be filled arbitrarily, with the remaining cells determined by the product constraints.

### Solution Code
```python
MOD = 10**9 + 7

n, m, k = map(int, input().split())

if k == -1:
    if (n + m) % 2 != 0:
        print(0)
        exit()

mod_exponent = MOD - 1
exponent = ((n - 1) % mod_exponent) * ((m - 1) % mod_exponent) % mod_exponent

print(pow(2, exponent, MOD))
```

### Explanation
1. **Validity Check**: For k = -1, the sum of n and m must be even. This is because the product of all elements in the grid must be consistent for both rows and columns, which is only possible if the parity of n and m matches.
2. **Exponent Calculation**: The number of valid configurations is \(2^{(n-1)(m-1)}\) modulo 1000000007. Using modular exponentiation, we efficiently compute this even for very large values of n and m by leveraging properties of modular arithmetic and Fermat's Little Theorem.

This approach ensures that we handle extremely large values of n and m efficiently and correctly, providing the solution in constant time complexity after the initial checks.
