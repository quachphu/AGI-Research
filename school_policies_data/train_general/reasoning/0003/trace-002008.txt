To solve this problem, we need to maximize the total reward from completing jobs under the constraint that each job must be completed no later than M days from today. Each job can be done on a specific day and yields a reward after a certain number of days. The key challenge is to select jobs such that they are scheduled optimally to maximize the total reward.

### Approach
1. **Filter Jobs**: First, filter out jobs that cannot be completed within M days. This is determined by checking if the day required to complete the job (A_i) exceeds M.
2. **Sort Jobs**: Sort the remaining jobs based on their rewards in descending order. This greedy approach ensures we consider higher rewards first.
3. **Union-Find Data Structure**: Use a Union-Find (Disjoint Set Union, DSU) data structure to efficiently track the latest available day for scheduling each job. This helps in assigning each job to the latest possible day it can be scheduled, ensuring optimal use of days.

### Solution Code
```python
import sys

def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    
    idx = 0
    N = int(data[idx])
    idx += 1
    M = int(data[idx])
    idx += 1
    
    jobs = []
    for _ in range(N):
        A = int(data[idx])
        idx += 1
        B = int(data[idx])
        idx += 1
        d = M - A
        if d >= 0:
            jobs.append((d, B))
    
    # Sort jobs by descending B
    jobs.sort(key=lambda x: -x[1])
    
    if M == 0:
        print(0)
        return
    
    parent = list(range(M))
    
    def find(x):
        if x < 0 or x >= M:
            return -1
        while True:
            p = parent[x]
            if p == x:
                return x
            if p == -1:
                return -1
            parent[x] = parent[p]
            x = parent[x]
    
    total = 0
    for d, b in jobs:
        root = find(d)
        if root != -1:
            total += b
            parent[root] = find(root - 1)
    
    print(total)

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read and parsed into a list of jobs. Each job's deadline (d_i) is calculated as M - A_i. Jobs with negative deadlines are discarded.
2. **Sorting Jobs**: Jobs are sorted in descending order of their rewards to prioritize higher rewards.
3. **Union-Find Initialization**: The Union-Find structure is initialized with each day pointing to itself. This helps in tracking the latest available day efficiently.
4. **Job Scheduling**: For each job, the latest available day (using the Union-Find structure) is determined. If a valid day is found, the job is scheduled, and the day is marked as used by updating the Union-Find structure to point to the previous day.

This approach ensures that we efficiently schedule the highest reward jobs first, using the latest possible days to maximize the total reward while adhering to the constraints.
