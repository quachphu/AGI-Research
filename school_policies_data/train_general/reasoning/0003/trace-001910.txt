The solution involves constructing a tree structure from the input data and then performing a pre-order traversal to print each post with the appropriate number of dots.

### Approach
1. **Input Reading**: Read the number of posts and their respective parent indices and messages.
2. **Tree Construction**: Build a tree where each node (post) keeps track of its children in the order they were added.
3. **Pre-order Traversal**: Use an iterative approach with a stack to traverse the tree in pre-order, maintaining the depth of each node to determine the number of dots for each post.

```python
children = [[] for _ in range(n + 1)]

        children[parent].append(i)

stack = [(1, 0)]

    node, depth = stack.pop()
    result.append('.' * depth + posts[node])
    for child in reversed(children[node]):
        stack.append((child, depth + 1))

for line in result:
    print(line)
```
