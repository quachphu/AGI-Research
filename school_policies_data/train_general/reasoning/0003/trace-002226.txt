To solve this problem, we need to find the first time on or after a given time where two conditions are met: no two hands of an analog clock overlap, and the angles between the second hand and the other two hands (minute and hour) are equal. The clock is an H-hour clock, meaning the hour hand completes a full rotation every H hours.

### Approach
1. **Understanding Hand Movements**: The hour, minute, and second hands move smoothly. The positions of these hands can be calculated using their respective angular speeds.
2. **Angle Equality Condition**: The angles between the second hand and the other two hands must be equal. This translates to a mathematical condition where the sum of the hour and minute angles is twice the second angle modulo 360 degrees.
3. **Formulating the Equation**: Using the angular speeds, derive an equation to find valid times when the angle condition is met. This equation is solved using modular arithmetic.
4. **Checking Overlaps**: For each candidate time derived from the equation, check if any two hands overlap. If they do, discard the candidate and check the next one.
5. **Iterative Search**: Starting from the given time, incrementally check candidate times until a valid solution is found.

### Solution Code
```python
import sys
from fractions import Fraction

def find_time(H, h, m, s):
    T_start = h * 3600 + m * 60 + s
    D = 119 * H - 1
    if D == 0:
        return  # H >=2, so D can't be zero
    denominator_k = 3600 * H
    numerator_k = T_start * D
    # Compute k_min using ceiling of (T_start * D) / (3600 H)
    k_min = (numerator_k + denominator_k - 1) // denominator_k

    while True:
        k = k_min
        # Check conditions
        cond1 = (k * (H - 1)) % D == 0
        cond2 = (k * (60 * H - 1)) % D == 0
        cond3 = (H * k * 59) % D == 0
        if not (cond1 or cond2 or cond3):
            # Valid k found
            t_candidate = Fraction(3600 * H * k, D)
            # Compute t_mod = t_candidate % (H*3600)
            H_seconds = H * 3600
            t_mod = t_candidate % H_seconds
            # Decompose into ho, mo, so
            ho = int(t_mod // 3600)
            remaining = t_mod % 3600
            mo = int(remaining // 60)
            so = remaining % 60
            # Simplify so
            so_frac = Fraction(so).limit_denominator()
            return (ho, mo, so_frac.numerator, so_frac.denominator)
        else:
            k_min += 1

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        H, h, m, s = map(int, line.split())
        if H == 0:
            break
        result = find_time(H, h, m, s)
        if result:
```
