To solve this problem, we need to determine how many menu prices in a given list are Ciel numbers. A Ciel number is defined as a positive integer that only contains the digits 3, 5, and 8, with the counts of these digits satisfying the conditions that the count of 8s is greater than or equal to the count of 5s, and the count of 5s is greater than or equal to the count of 3s.

### Approach
1. **Input Reading**: Read the number of menu items followed by each menu item's name and price.
2. **Validation of Ciel Numbers**:
   - **Check Digits**: Ensure the price only contains the digits 3, 5, and 8.
   - **Count Digits**: Count the occurrences of each digit (3, 5, and 8) in the price.
   - **Check Conditions**: Verify if the count of 8s is at least the count of 5s, and the count of 5s is at least the count of 3s.
3. **Count Valid Prices**: Count how many prices meet the criteria of being Ciel numbers.

### Solution Code
```python
def is_ciel(pi):
    allowed = {'3', '5', '8'}
    for c in pi:
        if c not in allowed:
            return False
    count8 = pi.count('8')
    count5 = pi.count('5')
    count3 = pi.count('3')
    return count8 >= count5 and count5 >= count3

def main():
    import sys
    input_lines = sys.stdin.read().splitlines()
    n = int(input_lines[0])
    count = 0
    for line in input_lines[1:n+1]:
        parts = line.rsplit(' ', 1)
        if len(parts) < 2:
            continue  # according to problem constraints, this shouldn't happen
        pi = parts[1]
        if is_ciel(pi):
            count += 1
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into lines. The first line gives the number of menu items, `N`.
2. **Processing Each Line**: For each subsequent line, the menu name and price are split using the last space as the delimiter. This handles cases where the menu name might contain spaces.
3. **Digit Check**: The function `is_ciel` checks if all characters in the price are 3, 5, or 8. If any other digit is found, it returns `False`.
4. **Digit Counting**: The counts of 3s, 5s, and 8s are determined using string methods.
5. **Condition Check**: The counts are checked to ensure they meet the required inequalities (count of 8s ≥ count of 5s ≥ count of 3s).
6. **Result**: The total count of valid Ciel numbers is printed.

This approach efficiently checks each price against the criteria, ensuring correctness and handling edge cases as specified in the problem constraints.
