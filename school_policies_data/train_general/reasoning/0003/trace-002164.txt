To solve this problem, we need to determine the number of distinct colors among three paint cans purchased by AtCoDeer. The colors are represented by integers, and we need to count how many unique integers there are among the three given values.

### Approach
The approach involves the following steps:
1. **Read Input**: Read the three integers from the standard input.
2. **Identify Unique Values**: Use a set data structure to automatically handle duplicates and store only unique values.
3. **Count Unique Values**: The size of the set, which is the number of unique elements, gives the desired count.

Using a set is efficient because inserting elements into a set and checking for duplicates are average O(1) operations, making the overall time complexity O(1) for this problem.

### Solution Code
```python
def main():
    a, b, c = map(int, input().split())
    print(len({a, b, c}))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read as a single line and split into three integers using `map(int, input().split())`.
2. **Creating a Set**: The three integers are placed into a set, which inherently removes any duplicate values.
3. **Counting Elements**: The length of the set, obtained using `len()`, gives the number of unique colors.

This approach efficiently handles the problem constraints and provides the correct result with minimal computational overhead.
