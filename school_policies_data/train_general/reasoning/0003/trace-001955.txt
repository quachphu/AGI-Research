   - The last character of `s` must be '0' because removing an edge can never result in a component of size `n`.

2. **Complement Check**:
   - For each valid component size `i` (from 1 to n-1), if `s[i-1]` is '1', then `s[n-i-1]` must also be '1' unless `i` is exactly half of `n`.

3. **Star-shaped Tree Check**:
   - If all valid components are either 1 or `n-1`, the tree can be a star-shaped tree where all nodes are connected to a central node.

4. **Chain-shaped Tree Check**:
   - If all pairs of component sizes (i, n-i) are valid, the tree can be a linear chain where each edge split results in valid component sizes.

### Solution Code
```python
s = input().strip()
n = len(s)

# Check necessary conditions
if n < 2 or s[0] != '1' or s[-1] != '0':
    print(-1)
    exit()

# Check complement conditions
for i in range(1, n):
    problem_i = i + 1  # since i starts from 0, problem_i is i+1 in 1-based terms
    if problem_i >= n:
        continue
    if s[i] == '1':
        complement = n - problem_i
        if problem_i != complement:
            if complement < 1 or complement > n or s[complement - 1] != '1':
                print(-1)
                exit()

# Check for star condition (only 1 and n-1 are '1's)
star = True
for problem_i in range(1, n):
    if problem_i == 1 or problem_i == n-1:
        if s[problem_i - 1] != '1':
            star = False
            break
    else:
        if s[problem_i - 1] == '1':
            star = False
            break

if star:
    for i in range(2, n+1):
        print(1, i)
    exit()

# Check for chain condition
chain = True
max_i = n // 2
for problem_i in range(1, max_i + 1):
    if s[problem_i - 1] != '1' or s[(n - problem_i) - 1] != '1':
        chain = False
        break

if chain:
    for i in range(1, n):
        print(i, i + 1)
    exit()

print(-1)
```

### Explanation
1. **Initial Checks**: Ensure the first and last characters of `s` are valid.
2. **Complement Check**: Ensure every valid component size `i` has a valid complement `n-i`.
3. **Star-shaped Tree**: Construct a tree where all nodes are connected to a central node if valid.
4. **Chain-shaped Tree**: Construct a linear chain if all component pairs are valid.

This approach efficiently checks the necessary conditions and constructs the tree if possible, ensuring the solution is optimal and handles large inputs within constraints.
