To solve this problem, we need to determine the sector number of the next unanswered question when the arrow stops at a specific sector on a circular table. The solution involves checking the sectors in a clockwise direction starting from the sector where the arrow points, until we find an unanswered question.

### Approach
1. **Input Reading**: Read the number of sectors `n` and the sector `k` where the arrow points. Then read the list of sectors indicating whether each sector's question has been answered (0) or not (1).
2. **Adjust for Zero-based Indexing**: Convert the sector number `k` from 1-based to 0-based index for easier manipulation.
3. **Check Sectors in Clockwise Order**: Starting from sector `k`, check each subsequent sector in a clockwise direction. If the current sector's question is unanswered, return its 1-based index. This involves using modulo arithmetic to handle the circular nature of the sectors.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))
start_idx = k - 1  # Convert to 0-based index
for i in range(n):
    current = (start_idx + i) % n
    if a[current] == 1:
        print(current + 1)
        break
```

### Explanation
1. **Reading Input**: The first line of input is split into `n` (number of sectors) and `k` (sector where the arrow points). The second line is read as a list of integers indicating the status of each sector.
2. **Adjusting Index**: Since Python uses 0-based indexing, we convert the 1-based sector number `k` to a 0-based index by subtracting 1.
3. **Circular Check**: Using a loop, we iterate through each sector starting from `k`. The modulo operation `(start_idx + i) % n` ensures that we wrap around to the beginning of the list when we reach the end. The first sector found with an unanswered question (indicated by 1) is printed as the result, converted back to 1-based indexing by adding 1.

This approach efficiently checks each sector in the required order and ensures the correct result is found in linear time, O(n), which is optimal for the given problem constraints.
