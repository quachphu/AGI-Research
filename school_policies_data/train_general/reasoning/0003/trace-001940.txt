To solve this problem, we need to count the number of distinct valid parenthesis substrings in a given string. A valid parenthesis substring is defined as a substring that can be empty, enclosed in a pair of brackets, or a concatenation of two valid sequences of brackets.

### Approach
1. **Balance Array**: Compute a balance array where each element represents the balance of parentheses up to that point. The balance increases by 1 for each '(' and decreases by 1 for each ')'.
2. **Next Smaller Element**: Use a monotonic stack to determine the next smaller balance value for each position in the balance array. This helps in identifying the valid range for potential valid substrings.
3. **Hash Map for Balance Values**: Create a hash map that maps each balance value to the indices where it occurs in the balance array.
4. **Rolling Hash**: Precompute prefix hashes and power values for efficient hash computation of substrings, allowing us to check for distinct substrings in constant time.
5. **Iterate and Validate**: For each starting index of a potential valid substring, use the next smaller element and hash map to find valid ending indices, then check if the substring is valid and add its hash to a set to ensure uniqueness.

### Solution Code
```python
import sys
import bisect

def main():
    n = int(sys.stdin.readline())
    s = sys.stdin.readline().strip()
    if n == 0:
        print(0)
        return
    
    # Compute balance array
    balance = [0] * (n + 1)
    for i in range(1, n + 1):
        balance[i] = balance[i - 1] + (1 if s[i - 1] == '(' else -1)
    
    # Compute next_smaller for each index in balance array
    next_smaller = [n + 1] * (n + 1)
    stack = []
    for i in range(n, -1, -1):
        while stack and balance[stack[-1]] >= balance[i]:
            stack.pop()
        if stack:
            next_smaller[i] = stack[-1]
        else:
            next_smaller[i] = n + 1
        stack.append(i)
    
    # Build balance_map
    from collections import defaultdict
    balance_map = defaultdict(list)
    for i in range(n + 1):
        balance_map[balance[i]].append(i)
    
    # Precompute prefix_hash and power for rolling hash
    base = 911382629
    mod = 10**18 + 3
    prefix_hash = [0] * (n + 1)
    power = [1] * (n + 1)
    for i in range(n):
        prefix_hash[i + 1] = (prefix_hash[i] * base + ord(s[i])) % mod
        power[i + 1] = (power[i] * base) % mod
    
    distinct_hashes = set()
    
    for a in range(n):
        if s[a] != '(':
            continue
        i = a  # balance array index
        balance_val = balance[i]
        next_small = next_smaller[i]
        lower_j = i + 1
        upper_j = next_small - 1 if next_small <= n else n
        
        if lower_j > upper_j:
            continue
        
        list_js = balance_map.get(balance_val, [])
        if not list_js:
            continue
        
        # Find the indices in list_js that are >= lower_j and <= upper_j
        low = bisect.bisect_left(list_js, lower_j)
        high = bisect.bisect_right(list_js, upper_j)
        valid_js = list_js[low:high]
        
        for j in valid_js:
            if j - 1 >= len(s):
                continue
            if s[j - 1] == ')':
                # Compute hash of substring s[a..j-1]
                length = j - i
                current_hash = (prefix_hash[j] - prefix_hash[i] * power[length]) % mod
                distinct_hashes.add(current_hash)
    
    print(len(distinct_hashes))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Balance Array**: This array helps track the balance of parentheses up to each position in the string.
2. **Next Smaller Element**: This array helps determine the valid range for each starting index, ensuring the balance does not drop below the initial balance.
3. **Hash Map**: This allows quick lookup of indices where specific balance values occur, aiding in finding potential valid substrings.
4. **Rolling Hash**: Efficiently computes the hash of substrings to check for uniqueness without storing the actual substrings.
5. **Validation**: For each valid starting index, the code checks all potential ending indices and uses hashing to ensure only distinct substrings are counted.

This approach efficiently narrows down potential valid substrings and uses hashing to ensure uniqueness, resulting in an optimal solution for large input sizes.
