To solve this problem, we need to determine which friend gave a gift to each friend based on the given input where each friend's gift recipient is listed. The solution involves creating an inverse mapping of the given list to find the giver for each recipient.

### Approach
1. **Understanding the Input and Output**: The input consists of a list where each element at position `i` indicates the friend to whom friend `i+1` gave a gift. The goal is to determine for each friend `j`, which friend gave them a gift.
2. **Inverse Mapping**: The key insight is to create an inverse mapping where each recipient points back to the giver. This can be efficiently done using a dictionary to map each recipient to their respective giver.
3. **Efficient Lookup**: Using a dictionary allows us to directly look up the giver for each recipient in constant time, leading to an efficient solution.

### Solution Code
```python
n = int(input())
p = list(map(int, input().split()))
giver_map = {recipient: giver + 1 for giver, recipient in enumerate(p)}
result = [giver_map[i] for i in range(1, n + 1)]
print(' '.join(map(str, result)))
```

### Explanation
1. **Reading Input**: The first line of input is the number of friends `n`, and the second line contains the list `p` where each element `p[i]` indicates the friend who received a gift from friend `i+1`.
2. **Creating the Inverse Map**: We construct a dictionary `giver_map` where each key is a recipient (from the list `p`) and the corresponding value is the giver's index (adjusted to 1-based index).
3. **Generating the Result**: Using a list comprehension, we generate the result list where each position `i` (0-based) contains the giver for friend `i+1` (1-based) by looking up the `giver_map` dictionary.
4. **Output the Result**: The result list is converted to a space-separated string and printed.

This approach efficiently constructs the required mapping and ensures that each lookup is done in constant time, resulting in an overall time complexity of O(n), which is optimal for the given problem constraints.
