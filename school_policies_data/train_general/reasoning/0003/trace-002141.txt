To solve this problem, we need to determine the minimum number of steps required to move from the block containing your home to the block containing the university in Crazy Town, where each step involves crossing a road that separates two adjacent blocks.

### Approach
1. **Problem Analysis**: The key insight is that each road (line) can act as a separator between blocks. If a road separates the home and university, you must cross it. The number of such roads directly corresponds to the minimum number of steps required.
2. **Separation Check**: For each road defined by the equation \(a_i x + b_i y + c_i = 0\), check if the home and university are on opposite sides of the road. This can be determined by evaluating the sign of the expressions \(a_i x_1 + b_i y_1 + c_i\) and \(a_i x_2 + b_i y_2 + c_i\) for the home \((x1, y1)\) and university \((x2, y2)\). If their product is negative, they are on opposite sides.
3. **Count Separating Roads**: The total number of roads that separate the home and university gives the minimum steps required.

### Solution Code
```python
x1, y1 = map(int, input().split())
x2, y2 = map(int, input().split())
n = int(input())
count = 0

for _ in range(n):
    a, b, c = map(int, input().split())
    val1 = a * x1 + b * y1 + c
    val2 = a * x2 + b * y2 + c
    if val1 * val2 < 0:
        count += 1

print(count)
```

### Explanation
1. **Reading Inputs**: The coordinates of the home and university are read first, followed by the number of roads.
2. **Evaluating Each Road**: For each road, we compute the values of the line equation at the home and university coordinates. If these values have opposite signs (their product is negative), the road separates the two points.
3. **Counting Separating Roads**: The count of such roads is incremented each time a separating road is found, which directly gives the minimum steps needed.

This approach efficiently determines the solution in \(O(n)\) time complexity, where \(n\) is the number of roads, ensuring optimal performance even for the upper constraint of \(n = 300\).
