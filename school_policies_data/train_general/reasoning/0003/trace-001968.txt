To solve this problem, we need to determine the maximum number of people present in a restaurant at any given time during its operating hours from 0 to T. Each person visits the restaurant during a specific interval [l_i, r_i), and we need to efficiently compute the peak number of visitors.

### Approach
1. **Event Collection**: For each person's visit interval [l_i, r_i), create two events: a start event at time l_i (+1) and an end event at time r_i (-1).
2. **Sorting Events**: Sort these events by time. If two events occur at the same time, end events (r_i) are processed before start events (l_i) to ensure accurate counting.
3. **Processing Events**: Traverse through the sorted events, maintaining a running count of the current number of visitors. Track the maximum count encountered during this traversal.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    T = int(input[idx + 1])
    idx += 2
    events = []
    for _ in range(N):
        l = int(input[idx])
        r = int(input[idx + 1])
        events.append((l, 1))
        events.append((r, -1))
        idx += 2
    events.sort()
    current = 0
    max_people = 0
    for time, delta in events:
        current += delta
        if current > max_people:
            max_people = current
    print(max_people)

main()
```

### Explanation
1. **Event Collection**: Each person's visit interval is split into two events: a start event (when they enter) and an end event (when they leave). This helps in tracking the changes in the number of visitors over time.
2. **Sorting Events**: Events are sorted primarily by time. If two events have the same time, end events are placed before start events to ensure that people leaving are counted before new arrivals at the same time, which avoids overcounting.
3. **Processing Events**: By iterating through the sorted events, we adjust the current number of visitors using the event values (+1 for arrivals and -1 for departures). The maximum number of visitors encountered during this iteration is recorded and printed as the result.

This approach efficiently handles up to 100,000 visitors and time points, ensuring optimal performance with a time complexity of O(N log N) due to sorting, followed by a linear scan through the events.
