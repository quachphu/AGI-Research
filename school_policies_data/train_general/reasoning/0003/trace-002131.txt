To solve this problem, we need to determine the rhyme scheme of a poem consisting of multiple quatrains. Each quatrain must follow the same rhyme scheme, and we need to identify which of the specified schemes (aabb, abab, abba, aaaa) the poem conforms to, or determine if it doesn't fit any of them.

### Approach
1. **Identify Suffixes**: For each line in the poem, compute the suffix starting from the k-th vowel from the end. If a line has fewer than k vowels, it cannot rhyme with any other line.
2. **Check All Quatrains for AAAA**: If all lines in every quatrain have the same suffix, the poem's rhyme scheme is aaaa.
3. **Determine Possible Schemes for Each Quatrain**: For each quatrain, check which of the other schemes (aabb, abab, abba) it can fit into based on the suffixes of its lines.
4. **Intersection of Possible Schemes**: Compute the intersection of possible schemes across all quatrains. If the intersection contains exactly one scheme, that is the answer; otherwise, the poem does not conform to any of the specified schemes.

### Solution Code
```python
def get_suffix(line, k):
    vowels_pos = []
    for i in reversed(range(len(line))):
        c = line[i]
        if c in {'a', 'e', 'i', 'o', 'u'}:
            vowels_pos.append(i)
            if len(vowels_pos) == k:
                break
    if len(vowels_pos) < k:
        return None
    start_pos = vowels_pos[-1]
    return line[start_pos:]
```

2. **Check Validity**: For each quatrain, check if all lines have valid suffixes. If any line in a quatrain has an invalid suffix, the poem is immediately deemed invalid.
3. **AAAA Check**: If all lines in every quatrain have the same suffix, the poem is classified as aaaa.
4. **Scheme Determination**: For each quatrain, determine which schemes it can fit into. The intersection of these possible schemes across all quatrains gives the final result. If the intersection is empty or has more than one scheme, the poem is invalid; otherwise, the single scheme in the intersection is the result.
