To solve this problem, we need to determine the shortest substring for each phone number in Polycarp's contacts such that entering this substring will uniquely display that phone number. The solution involves efficiently generating and checking substrings to ensure optimal performance even with a large number of contacts.

### Approach
1. **Generate Substrings**: For each phone number, generate all possible substrings of lengths from 1 to 9. Each substring is added to a set to avoid duplicates within the same phone number.
2. **Frequency Map**: Build a frequency map to count how many phone numbers each substring appears in. This helps in quickly checking if a substring is unique to a particular phone number.
3. **Check Uniqueness**: For each phone number, check all possible substrings in order of increasing length. The first substring found with a frequency of 1 is the answer for that phone number.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n = int(sys.stdin.readline())
    numbers = [sys.stdin.readline().strip() for _ in range(n)]
    
    # Build frequency map for substrings across all numbers
    frequency = defaultdict(int)
    for num in numbers:
        substrings = set()
        for length in range(1, 10):
            for start in range(0, 9 - length + 1):
                substring = num[start:start + length]
                substrings.add(substring)
        for s in substrings:
            frequency[s] += 1
    
    # Find the minimal unique substring for each number
    for num in numbers:
        found = False
        for length in range(1, 10):
            for start in range(0, 9 - length + 1):
                s = num[start:start + length]
                if frequency[s] == 1:
                    print(s)
                    found = True
                    break
            if found:
                break

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and stored in a list of phone numbers.
2. **Generating Substrings**: For each phone number, all possible substrings are generated. Using a set ensures each substring is counted only once per phone number.
3. **Building Frequency Map**: The frequency map tracks how many phone numbers each substring appears in. This is done by iterating through each phone number's unique substrings and updating the map.
4. **Finding Unique Substrings**: For each phone number, substrings are checked in order of increasing length. The first substring with a frequency of 1 is printed as the result, ensuring the shortest unique substring is found efficiently.

This approach ensures that we efficiently check for the shortest unique substring by leveraging sets and a frequency map, making the solution both optimal and scalable.
