To solve this problem, we need to form teams of two people such that each person's teammate is their highest possible mutual choice. The solution involves iteratively identifying pairs where each person is the best possible teammate for the other, until all pairs are formed.

### Approach
1. **Input Parsing**: Read the input values and construct a matrix to store the strength of each possible pair.
2. **Precompute Sorted Partners**: For each person, generate a list of potential teammates sorted by their strength in descending order.
3. **Iterative Pairing**: Use a greedy algorithm to iteratively find and form pairs where both members are each other's best available choice. This is done by maintaining a set of available people and repeatedly finding mutual best pairs until all are paired.

### Solution Code
```python
n = int(input())
max_person = 2 * n

# Initialize the strength matrix
strength = [[0] * (max_person + 1) for _ in range(max_person + 1)]

# Read the input and fill the strength matrix
for i in range(2, max_person + 1):
    line = list(map(int, input().split()))
    for j in range(len(line)):
        person_j = j + 1
        strength[i][person_j] = line[j]

# Precompute the sorted list of partners for each person in descending order of strength
sorted_partners = [[] for _ in range(max_person + 1)]
for x in range(1, max_person + 1):
    partners = []
    for y in range(1, max_person + 1):
        if x == y:
            continue
        if x < y:
            s = strength[y][x]
        else:
            s = strength[x][y]
        partners.append((-s, y))  # Negative for descending sort
    partners.sort()
    sorted_partners[x] = [y for (s_neg, y) in partners]

# Process to find and pair mutual best partners iteratively
available = set(range(1, max_person + 1))
result = [0] * (max_person + 1)  # 1-based indexing

while available:
    best = {}
    # Determine the current best available partner for each person
    for x in available:
        for y in sorted_partners[x]:
            if y in available:
                best[x] = y
                break
    # Collect all mutual best pairs
    pairs = []
    processed = set()
    for x in available:
        if x not in best:
            continue
        y = best[x]
        if y in best and best[y] == x:
            if x < y and x not in processed and y not in processed:
                pairs.append((x, y))
                processed.add(x)
                processed.add(y)
    # Update the result and remove paired individuals from available
    for x, y in pairs:
        result[x] = y
        result[y] = x
        available.discard(x)
        available.discard(y)

# Generate the output
print(' '.join(map(str, result[1:max_person + 1])))
```

### Explanation
1. **Input Parsing**: The input is read and stored in a matrix where the entry at `strength[i][j]` represents the strength of the team formed by person `i` and person `j` (considering `i > j`).
2. **Sorted Partners**: For each person, we generate a list of all other people sorted by the strength of their potential team in descending order. This helps in quickly determining the best available partner during each iteration.
3. **Iterative Pairing**: In each iteration, we determine the best available partner for each person. If two people are each other's best available partners, they form a team. This process repeats until all people are paired, ensuring optimal mutual choices at each step.

This approach efficiently finds the required pairs by leveraging sorted lists and greedy selection, ensuring that each person's team is formed based on the highest mutual strength possible.
