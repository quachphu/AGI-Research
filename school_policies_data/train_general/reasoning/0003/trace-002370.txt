To solve this problem, we need to determine the maximum score Resli can achieve in one move of the Mancala game. The score is calculated by collecting all stones from holes that contain an even number of stones after redistributing the stones from a chosen hole.

### Approach
1. **Input Reading**: Read the initial state of the 14 holes.
2. **Simulate Each Possible Move**: For each hole that contains stones, simulate the process of taking all stones from that hole and redistributing them.
3. **Redistribution Logic**: Efficiently distribute the stones using mathematical calculations to avoid iterating through each stone individually, which is crucial for handling large values efficiently.
4. **Score Calculation**: After redistribution, collect all even-numbered stones to compute the score for that move.
5. **Maximize Score**: Track the maximum score obtained from all possible moves.

### Solution Code
```python
def main():
    original = list(map(int, input().split()))
    max_score = 0
    for i in range(14):
        if original[i] == 0:
            continue
        new_board = original.copy()
        stones = new_board[i]
        new_board[i] = 0
        current_pos = (i + 1) % 14
        full_cycles = stones // 14
        remainder = stones % 14
        
        for j in range(14):
            new_board[j] += full_cycles
        
        for k in range(remainder):
            pos = (current_pos + k) % 14
            new_board[pos] += 1
        
        score = sum(x for x in new_board if x % 2 == 0)
        if score > max_score:
            max_score = score
    print(max_score)

main()
```

### Explanation
1. **Input Reading**: The input is read as a list of 14 integers representing the initial state of the holes.
2. **Simulating Moves**: For each hole with stones, we create a copy of the board to simulate the move. The stones from the chosen hole are redistributed starting from the next hole in a counter-clockwise direction.
3. **Efficient Distribution**: Instead of iterating through each stone, we calculate the number of full cycles of distribution (each hole gets an equal number of stones) and the remainder (additional stones distributed one by one after the full cycles). This ensures the solution handles very large numbers efficiently.
4. **Score Calculation**: After redistribution, we sum up all even-numbered stones in the modified board to get the score for that move.
5. **Maximizing Score**: The maximum score from all possible moves is tracked and printed as the result.

This approach ensures that we efficiently handle the redistribution of stones even for very large values, making the solution both optimal and scalable.
