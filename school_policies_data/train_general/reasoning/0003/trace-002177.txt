To solve this problem, we need to find the lexicographically smallest string possible by removing at most one character from the given string. The solution involves identifying the optimal position to remove a character such that the resulting string is the smallest possible.

### Approach
1. **Identify the First Dip**: Iterate through the string from left to right to find the first occurrence where a character is greater than the next character. Removing the character at this position will yield a smaller string.
2. **Handle Non-Decreasing Strings**: If the entire string is non-decreasing, removing the last character will result in the smallest possible string, as shorter strings are considered lexicographically smaller when prefixes match.

### Solution Code
```python
n = int(input())
s = input().strip()

def find_lex_smallest(s):
    for i in range(len(s) - 1):
        if s[i] > s[i + 1]:
            return s[:i] + s[i + 1:]
    return s[:-1]

print(find_lex_smallest(s))
```

### Explanation
1. **Identify the First Dip**: By iterating through the string, we check each consecutive pair of characters. The first time we encounter a character that is greater than the next character, we remove the larger character. This ensures that the resulting string starts with the smallest possible sequence of characters.
2. **Non-Decreasing Strings**: If no such dip is found, it means the string is non-decreasing. In this case, removing the last character will produce the smallest possible string because a shorter string with the same prefix is considered smaller in lexicographical order.

This approach efficiently finds the optimal character to remove in linear time, ensuring the solution is both optimal and efficient for large input sizes.
