To solve this problem, we need to determine the maximum time taken to repeatedly sum two numbers from an array until only one number remains, with each sum operation contributing to the total time. The goal is to maximize the total time by strategically choosing the order of summation.

### Approach
The key insight is that to maximize the total time, we should always merge the two largest remaining numbers. This ensures that larger numbers are included in more subsequent sums, thereby contributing more to the total time. 

The optimal strategy involves:
1. Sorting the array in ascending order.
2. Calculating the contribution of each element based on its position in the sorted array. The two largest elements will be merged first and will contribute the most, while smaller elements will contribute less as they are merged later.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        arr = list(map(int, input[ptr:ptr+N]))
        ptr += N
        arr.sort()
        total = 0
        for i in range(N):
            if i >= N - 2:
                total += arr[i] * (N - 1)
            else:
                total += arr[i] * (i + 1)
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once for efficiency, especially given the large constraints.
2. **Sorting the Array**: The array is sorted in ascending order to facilitate the calculation of contributions based on their positions.
3. **Calculating Contributions**: 
   - The two largest elements (last two elements in the sorted array) each contribute `(N-1)` times.
   - Each subsequent smaller element contributes `(i+1)` times, where `i` is its index in the sorted array.
4. **Summing Contributions**: The total time is computed by summing the contributions of all elements based on their positions.

This approach ensures that we efficiently compute the maximum possible time using sorting and a linear scan, resulting in an overall time complexity of O(N log N) per test case due to the sorting step. This is optimal and efficient for the given problem constraints.
