To solve this problem, we need to determine how many operations it takes for a given four-digit number to reach 6174 using a specific sequence of operations. If the number consists of all the same digits, we should output "NA".

### Approach
1. **Input Handling**: Read each line of input until encountering '0000', which signals the end of input. Each input line is treated as a four-digit number, padded with leading zeros if necessary.
2. **Check for Uniform Digits**: If all digits of the number are the same, output "NA".
3. **Operations to Reach 6174**: For each valid number, repeatedly perform the following steps until the number becomes 6174:
   - **Sort Descending**: Arrange the digits in descending order to form the largest possible number (L).
   - **Sort Ascending**: Arrange the digits in ascending order to form the smallest possible number (S).
   - **Compute Difference**: Subtract S from L to form the new number.
   - **Count Operations**: Track the number of operations needed to reach 6174.

### Solution Code
```python
import sys

def process_number(n_str):
    if all(c == n_str[0] for c in n_str):
        return 'NA'
    count = 0
    current = n_str
    while current != '6174':
        digits = list(current)
        L = int(''.join(sorted(digits, reverse=True)))
        S = int(''.join(sorted(digits)))
        new_num = L - S
        current = f"{new_num:04d}"
        count += 1
    return count

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n_str = line.zfill(4)
        if n_str == '0000':
            break
        result = process_number(n_str)
        print(result)

if __name__ == "__main__":
    main()
```

3. **Operations**: For each valid number, the digits are sorted in descending and ascending order to form the largest (L) and smallest (S) numbers. The difference (L - S) is computed and converted back to a four-digit string. This process repeats until the number becomes 6174, with the count of operations tracked and returned.
