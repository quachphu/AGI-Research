To solve this problem, we need to determine the total amount of money DISCO-Kun earned based on his placements in two competitions, the Coding Contest and the Robot Maneuver. The prize amounts and an additional bonus are structured as follows:

1. **Prize for Each Competition**:
   - 1st place: 300,000 yen
   - 2nd place: 200,000 yen
   - 3rd place: 100,000 yen
   - Any other place: 0 yen

2. **Bonus**: An additional 400,000 yen if DISCO-Kun secured 1st place in both competitions.

### Approach
1. **Prize Calculation Function**: Create a helper function to determine the prize money based on the placement in a single competition.
2. **Input Handling**: Read the input values for placements in both competitions.
3. **Total Prize Calculation**: Compute the total prize from both competitions using the helper function.
4. **Bonus Check**: Check if both placements are 1st to add the bonus amount.
5. **Output the Result**: Sum the prizes and bonus (if applicable) and print the result.

### Solution Code
```python
x, y = map(int, input().split())

def get_prize(place):
    if place == 1:
        return 300000
    elif place == 2:
        return 200000
    elif place == 3:
        return 100000
    else:
        return 0

total = get_prize(x) + get_prize(y)
if x == 1 and y == 1:
    total += 400000

print(total)
```

### Explanation
1. **Prize Calculation Function**: The `get_prize` function takes a placement value and returns the corresponding prize money using conditional checks.
2. **Reading Input**: The input values for placements in the Coding Contest (X) and Robot Maneuver (Y) are read and converted to integers.
3. **Total Prize Calculation**: The total prize is initially the sum of the prizes from both competitions.
4. **Bonus Check**: If both X and Y are 1, the bonus amount is added to the total.
5. **Output**: The final total is printed, which includes the sum of prizes from both competitions and the bonus if applicable.

This approach efficiently computes the total earnings by leveraging a helper function for prize calculation and straightforward checks for the bonus condition.
