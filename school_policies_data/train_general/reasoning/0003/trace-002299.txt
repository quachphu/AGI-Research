To solve this problem, we need to determine the maximum amount of bourles Vasya can have by the end of day n, given that he can buy and sell Martian dollars once. The solution involves identifying the optimal days to buy and sell the dollars to maximize profit.

### Approach
1. **Problem Analysis**:
   - Vasya can buy dollars on any day and sell them on a subsequent day.
   - The goal is to maximize the profit from buying low and selling high.
   - We need to compute the maximum possible profit by considering each day as a potential buy day and the highest subsequent price as the sell day.

2. **Key Insight**:
   - For each day, the maximum profit is determined by the highest price available on subsequent days.
   - Precompute the maximum price available after each day to efficiently determine the best sell day for any buy day.

3. **Algorithm**:
   - **Precompute Maximum Future Prices**: Create an array `max_future` where each entry at index `i` holds the highest price from day `i+1` to the end.
   - **Calculate Profit for Each Buy Day**: For each day, if the maximum future price is higher than the current price, compute the profit from buying on that day and selling on the day with the highest future price.

### Solution Code
```python
n, b = map(int, input().split())
a = list(map(int, input().split()))

if n < 2:
    print(b)
    exit()

max_future = [0] * n
max_future[-1] = 0  # No days after the last day

for i in range(n-2, -1, -1):
    max_future[i] = max(a[i+1], max_future[i+1])

max_total = b

for i in range(n-1):
    current_price = a[i]
    future_max = max_future[i]
    if future_max > current_price:
        dollars = b // current_price
        remainder = b % current_price
        total = dollars * future_max + remainder
        if total > max_total:
            max_total = total

print(max_total)
```

### Explanation
1. **Reading Input**: The input consists of the number of days `n`, initial bourles `b`, and the list of prices `a`.
2. **Edge Case Handling**: If there's only one day, no transaction can be made, so the result is `b`.
3. **Precompute Maximum Future Prices**: Using a reverse iteration from the end of the list, compute the highest price available each day for future transactions.
4. **Calculate Maximum Profit**: For each potential buy day, check if selling at the highest future price yields a profit. If it does, compute the maximum possible profit and update the result accordingly.

This approach ensures that we efficiently determine the optimal buy and sell days with a time complexity of O(n), making it suitable for the given constraints.
