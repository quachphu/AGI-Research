To solve this problem, we need to find all integer solutions \( x \) (where \( 0 < x < 10^9 \)) for the equation \( x = b \cdot s(x)^a + c \). Here, \( s(x) \) represents the sum of the digits of \( x \), and \( a \), \( b \), and \( c \) are given constants. 

### Approach
1. **Understanding Constraints**: The key insight is that the sum of the digits \( s(x) \) for any \( x \) less than \( 10^9 \) can be at most 81 (since the maximum sum of digits for a 9-digit number like 999,999,999 is 81). This allows us to limit our search to possible values of \( s(x) \) from 1 to 81.
2. **Reverse Calculation**: Instead of iterating through all possible values of \( x \), we iterate through each possible value of \( s \) (from 1 to 81). For each \( s \), we compute \( x \) using the equation \( x = b \cdot s^a + c \).
3. **Validation**: For each computed \( x \), we check if it is positive, less than \( 10^9 \), and if the sum of its digits equals the current \( s \). If all conditions are met, \( x \) is a valid solution.
4. **Result Collection**: Collect all valid solutions, sort them, and output the results.

### Solution Code
```python
def sum_digits(x):
    return sum(int(d) for d in str(x))

a, b, c = map(int, input().split())
solutions = []

for s in range(1, 82):
    x = b * (s ** a) + c
    if x <= 0 or x >= 10**9:
        continue
    if sum_digits(x) == s:
        solutions.append(x)

solutions = sorted(solutions)
print(len(solutions))
if solutions:
    print(' '.join(map(str, solutions)))
```

### Explanation
- **sum_digits Function**: This helper function calculates the sum of the digits of a given number \( x \) by converting it to a string and summing its integer digits.
- **Main Logic**: The main loop iterates over possible values of \( s \) from 1 to 81. For each \( s \), it computes \( x \) using the given equation. If \( x \) is valid (positive and less than \( 10^9 \)), it checks if the sum of the digits of \( x \) matches \( s \). Valid values of \( x \) are collected, sorted, and printed.

This approach efficiently narrows down the search space using the constraints on the sum of digits, ensuring the solution is both optimal and feasible.
