To solve this problem, we need to determine the number of ways to distribute exactly `n` candies between two sisters, Alice and Betty, such that Alice gets more candies than Betty, and both receive at least one candy. The solution should efficiently handle up to 10,000 test cases with values of `n` as large as 2 billion.

### Approach
The key insight is to recognize that the problem can be simplified using mathematical analysis. The conditions for the distribution can be translated into finding pairs of positive integers `a` and `b` such that:
- `a + b = n`
- `a > b`

By substituting `b = n - a` into the inequality `a > b`, we get `a > n/2`. This means `a` must be the smallest integer greater than `n/2` and less than `n` (since `b` must be at least 1). The number of valid values for `a` (and thus the number of valid distributions) can be determined using integer division:
- For even `n`, the valid values of `a` range from `n/2 + 1` to `n - 1`, which gives `(n/2 - 1)` valid pairs.
- For odd `n`, the valid values of `a` range from `(n + 1)/2` to `n - 1`, which gives `(n - 1)/2` valid pairs.

Both cases can be efficiently computed using the formula `(n - 1) // 2`.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        print((n - 1) // 2)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The code reads the number of test cases `t` and then processes each test case by reading the integer `n`.
2. **Computing the Result:** For each `n`, the result is computed using integer division `(n - 1) // 2`. This formula works because it effectively counts the number of valid integer pairs `(a, b)` where `a > b` and `a + b = n`.
3. **Output:** The result for each test case is printed immediately after computation.

This approach ensures that the solution is efficient and handles the upper limits of the input constraints comfortably. The time complexity is O(t), where `t` is the number of test cases, making it suitable for large inputs.
