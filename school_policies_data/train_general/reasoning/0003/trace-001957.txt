To solve this problem, we need to determine the minimum possible value displayed on an electric bulletin board after performing exactly N operations, where each operation can either double the current value (Operation A) or add a given integer K to the current value (Operation B). The initial value displayed on the board is 1.

### Approach
The key insight is to explore all possible sequences of operations to find the minimum value. This can be efficiently done using a recursive approach with memoization to avoid redundant calculations. The recursive function will consider both possible operations at each step and return the minimum value obtained from either operation. Memoization is used to store results of previously computed states to speed up the process.

### Solution Code
```python
from functools import lru_cache

n = int(input())
k = int(input())

@lru_cache(maxsize=None)
def min_value(current, steps_left):
    if steps_left == 0:
        return current
    a = min_value(current * 2, steps_left - 1)
    b = min_value(current + k, steps_left - 1)
    return min(a, b)

print(min_value(1, n))
```

### Explanation
1. **Recursive Function**: The function `min_value` takes the current value on the board and the number of remaining operations as parameters. It recursively computes the minimum possible value by considering both operations (A and B) at each step.
2. **Base Case**: When there are no operations left (`steps_left == 0`), the function returns the current value.
3. **Recursive Case**: For each remaining operation, the function calculates the result of both possible operations (doubling the value or adding K) and returns the minimum of these two results.
4. **Memoization**: The `lru_cache` decorator is used to store the results of previously computed states (current value and remaining steps) to avoid redundant calculations and improve efficiency.

This approach ensures that all possible sequences of operations are explored efficiently, leveraging memoization to handle overlapping subproblems and reduce the computational complexity. The solution is optimal and handles the constraints effectively.
