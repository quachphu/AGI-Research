To solve this problem, we need to determine the minimum ambiguity of a statement after removing some characters such that the resulting statement does not contain the subsequence "hard". The ambiguity is defined as the sum of the values associated with the removed characters.

### Approach
The approach involves using dynamic programming (DP) to track the minimum cost to prevent the formation of the subsequence "hard" at each step. We maintain four states corresponding to the first four characters of "hard" (i.e., 'h', 'a', 'r', 'd'). The goal is to ensure that the subsequence "hard" is not formed by keeping track of the minimum cost to avoid each character in the subsequence.

1. **States Definition**: We use four states to represent the minimum cost to avoid forming the subsequence up to each character:
   - `dp[0]`: Minimum cost to avoid forming 'h'.
   - `dp[1]`: Minimum cost to avoid forming 'ha'.
   - `dp[2]`: Minimum cost to avoid forming 'har'.
   - `dp[3]`: Minimum cost to avoid forming 'hard'.

2. **Transitions**: For each character in the string, we consider two options: deleting the character or keeping it. If we keep a character that matches the next expected character in "hard", we move to the next state. If we delete the character, we add its associated cost to the current state's cost.

3. **Result**: The minimum value among the four states after processing all characters gives the minimum ambiguity required to ensure the statement does not contain the subsequence "hard".

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    s = input[idx]
    idx += 1
    a = list(map(int, input[idx:idx+n]))
    idx += n
    
    INF = 1 << 60
    dp = [INF] * 4
    dp[0] = 0  # initial state: no characters matched
    
    target = "hard"
    
    for i in range(n):
        c = s[i]
        cost = a[i]
        new_dp = [INF] * 4
        
        for j in range(4):
            if dp[j] == INF:
                continue
            
            # Option 1: delete the current character
            if new_dp[j] > dp[j] + cost:
                new_dp[j] = dp[j] + cost
            
            # Option 2: keep the current character
            if c == target[j]:
                if j < 3:
                    if new_dp[j+1] > dp[j]:
                        new_dp[j+1] = dp[j]
            else:
                if new_dp[j] > dp[j]:
                    new_dp[j] = dp[j]
        
        dp = new_dp
    
    print(min(dp))

if __name__ == "__main__":
    main()
```

- **Result Calculation**: After processing all characters, the minimum value among the four states gives the minimum ambiguity required to ensure the subsequence "hard" is not present.
