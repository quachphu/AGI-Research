To solve this problem, we need to distribute balls of different colors into their respective boxes with the minimum possible penalty. The penalty is determined by the number of balls taken from a box in each turn. The key is to minimize the total penalty by optimally splitting groups of balls into either two or three non-empty groups.

### Approach
1. **Problem Analysis**: The problem can be modeled as building a tree where each internal node (representing a split) contributes its sum to the total penalty. The goal is to minimize the sum of all such internal nodes.
2. **Greedy Strategy**: Use a min-heap to always merge the smallest possible groups first. This approach is inspired by the Huffman coding algorithm but allows merging three elements when beneficial.
3. **Merge Conditions**: 
   - If the number of elements in the heap is congruent to 1 modulo 2 and there are at least three elements, merge the three smallest elements.
   - Otherwise, merge the two smallest elements. This ensures that the number of elements is reduced optimally, considering the constraints of splitting into two or three groups.

### Solution Code
```python
import heapq

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    
    if n == 1:
        print(0)
        return
    
    heapq.heapify(a)
    total = 0
    
    while len(a) > 1:
        if len(a) % 2 == 1 and len(a) >= 3:
            # Merge three smallest elements
            x = heapq.heappop(a)
            y = heapq.heappop(a)
            z = heapq.heappop(a)
            s = x + y + z
            total += s
            heapq.heappush(a, s)
        else:
            # Merge two smallest elements
            x = heapq.heappop(a)
            y = heapq.heappop(a)
            s = x + y
            total += s
            heapq.heappush(a, s)
    
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
- **Heap Initialization**: Convert the list of ball counts into a min-heap to efficiently access the smallest elements.
- **Merging Strategy**: Depending on the current number of elements in the heap, merge the smallest elements either two or three at a time. This ensures that smaller groups are merged first, minimizing their contribution to the total penalty.
- **Penalty Calculation**: Each merge operation's sum is added to the total penalty, which accumulates the sums of all internal nodes in the resulting tree structure.

This approach optimally balances between merging two and three elements to ensure the minimal total penalty, leveraging the properties of a min-heap for efficient access to the smallest elements.
