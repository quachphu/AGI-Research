   - Taro wants to pay for an item costing P yen using the minimum number of coins, considering both the coins he uses and the change he receives.
   - The clerk returns change using the minimal number of coins possible, which can be computed using a greedy algorithm.
   - We need to consider all possible sums Taro can pay (S >= P) using his available coins and compute the minimal coins used for each sum and the corresponding change.

2. **Key Insights**:

   - For each possible payment amount S (from P to P + 2500 or the maximum sum of Taro's coins), compute the minimal coins Taro uses and the change coins required.

3. **Algorithm**:
   - **Greedy Algorithm for Change**: Compute the minimal coins for change using the largest denominations first.
   - **Bounded Greedy Algorithm for Payment**: For each possible payment amount S, compute the minimal coins Taro uses by iterating from the largest to smallest denomination, using as many coins as possible without exceeding available counts.
