To solve this problem, we need to determine the number of ways to travel from city i to city j in exactly P hours using one-way roads. The solution involves matrix exponentiation to efficiently compute the number of paths of specific lengths, leveraging dynamic programming and optimized matrix multiplication.

### Approach
1. **Matrix Representation**: Represent the cities and roads using an adjacency matrix where each entry (i, j) indicates the number of direct roads from city i to city j.
2. **Matrix Exponentiation**: Precompute the number of paths of all lengths from 0 to 1000 using matrix exponentiation. This allows us to quickly answer each query by looking up the precomputed results.
3. **Optimized Multiplication**: Use an adjacency list to store non-zero entries of the adjacency matrix, which speeds up matrix multiplication by iterating only over non-zero elements.

### Solution Code
```python
import sys

def main():
    MOD = 10**9 + 7
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    R = int(input[ptr])
    ptr += 1

    # Initialize adjacency matrix
    adj = [[0] * N for _ in range(N)]
    for _ in range(R):
        u = int(input[ptr]) - 1
        v = int(input[ptr+1]) - 1
        ptr +=2
        adj[u][v] += 1

    # Precompute adjacency list for optimized multiplication
    adj_list = [[] for _ in range(N)]
    for k in range(N):
        for j in range(N):
            cnt = adj[k][j]
            if cnt > 0:
                adj_list[k].append( (j, cnt) )

    max_p = 1000
    dp = [None] * (max_p + 1)
    # Initialize dp[0] as identity matrix
    dp[0] = [[0]*N for _ in range(N)]
    for i in range(N):
        dp[0][i][i] = 1

    for p in range(1, max_p + 1):
        prev = dp[p-1]
        curr = [[0]*N for _ in range(N)]
        for i in range(N):
            for k in range(N):
                aik = prev[i][k]
                if aik == 0:
                    continue
                for (j, cnt) in adj_list[k]:
                    curr[i][j] = (curr[i][j] + aik * cnt) % MOD
        dp[p] = curr

    Q = int(input[ptr])
    ptr +=1
    results = []
    for _ in range(Q):
        i = int(input[ptr]) -1
        j = int(input[ptr+1]) -1
        P = int(input[ptr+2])
        ptr +=3
        if P > max_p:
            results.append(0)
        else:
            results.append(dp[P][i][j] % MOD)

    print('\n'.join(map(str, results)))

if __name__ == "__main__":
    main()
```

3. **Precomputation**: Using dynamic programming, precompute the number of paths for all lengths from 0 to 1000. The `dp` array stores matrices where `dp[p]` contains the number of paths of length `p` between any two cities.
