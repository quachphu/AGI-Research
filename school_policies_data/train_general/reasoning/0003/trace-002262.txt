To solve this problem, we need to divide N troops into three groups such that the sum of their strengths is as balanced as possible. The goal is to minimize the maximum sum among the three groups, ensuring that each group has at least one troop.

### Approach
1. **Generate All Possible Assignments**: Since the number of troops (N) is up to 12, we can use a brute-force approach to generate all possible ways to assign each troop to one of three groups. This is feasible because 3^12 (531,441) iterations are manageable for modern computers.
2. **Check Validity of Assignments**: For each generated assignment, we check if all three groups have at least one troop. If not, we skip that assignment.
3. **Calculate Sums for Each Group**: For valid assignments, compute the sum of strengths for each group.
4. **Determine Optimal Division**: Track the minimum possible maximum sum (S1) across all valid assignments. This involves sorting the sums of the groups in descending order and updating the minimum S1 if the current assignment yields a smaller value.

### Solution Code
```python
import itertools

def main():
    n = int(input())
    strengths = [int(input()) for _ in range(n)]
    total = sum(strengths)
    min_s1 = total  # Initial worst-case scenario

    for assignment in itertools.product(range(3), repeat=n):
        # Check if all three groups are present
        if len(set(assignment)) != 3:
            continue
        sums = [0, 0, 0]
        for idx, group in enumerate(assignment):
            sums[group] += strengths[idx]
        s1 = max(sums)
        if s1 < min_s1:
            min_s1 = s1

    print(min_s1)

main()
```

### Explanation
1. **Input Handling**: Read the number of troops and their respective strengths.
2. **Generate Assignments**: Use `itertools.product` to generate all possible assignments of troops to groups 0, 1, or 2.
3. **Validity Check**: Ensure each assignment uses all three groups.
4. **Sum Calculation**: For valid assignments, compute the sum of strengths for each group.
5. **Track Minimum S1**: Update the minimum possible maximum sum (S1) by comparing the current assignment's maximum sum with the tracked minimum.

This approach efficiently explores all possible ways to divide the troops while ensuring the constraints are met, leading to an optimal solution.
