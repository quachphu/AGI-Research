To solve this problem, we need to ensure that no two adjacent boards in a fence have the same height by increasing the height of the boards at the minimum cost. Each board can be increased any number of times, with each increment having a specific cost. The goal is to determine the minimum cost for each query to make the fence "great."

### Approach
1. **Dynamic Programming (DP) Approach**: We use a dynamic programming approach where we track the minimum cost for each possible height adjustment (0, 1, or 2 increments) for each board. This is because the minimum cost adjustments can be achieved by considering small increments, and larger increments would unnecessarily increase the cost.

2. **State Tracking**: For each board, we maintain three possible states representing the cost if the board is increased by 0, 1, or 2 units. We transition these states from one board to the next, ensuring that consecutive boards do not have the same height.

3. **Initialization and Transition**: Initialize the cost for the first board based on possible increments. For each subsequent board, compute the minimum cost for each possible increment by checking all valid transitions from the previous board's increments.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    q = int(input[ptr])
    ptr += 1
    for _ in range(q):
        n = int(input[ptr])
        ptr += 1
        boards = []
        for _ in range(n):
            a = int(input[ptr])
            b = int(input[ptr + 1])
            boards.append((a, b))
            ptr += 2
        if n == 1:
            print(0)
            continue
        a = [x[0] for x in boards]
        b = [x[1] for x in boards]
        prev = [0 * b[0], 1 * b[0], 2 * b[0]]
        for i in range(1, n):
            curr_a = a[i]
            curr_b = b[i]
            prev_a = a[i - 1]
            curr_cost = [float('inf')] * 3
            for delta_prev in range(3):
                cost_prev = prev[delta_prev]
                if cost_prev == float('inf'):
                    continue
                prev_h = prev_a + delta_prev
                for delta_curr in range(3):
                    curr_h = curr_a + delta_curr
                    if prev_h != curr_h:
                        new_cost = cost_prev + delta_curr * curr_b
                        if new_cost < curr_cost[delta_curr]:
                            curr_cost[delta_curr] = new_cost
            prev = curr_cost
        print(min(prev))
        
if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the large constraints.
2. **Handling Each Query**: For each query, we first check if there's only one board, which trivially requires no adjustments.
3. **Dynamic Programming Initialization**: The initial costs for the first board are calculated based on possible increments (0, 1, 2).
4. **State Transitions**: For each subsequent board, we compute the minimum cost for each possible increment by checking all valid transitions from the previous board's increments. This ensures that consecutive boards have different heights.
5. **Result Calculation**: After processing all boards, the minimum cost is derived from the possible increments of the last board.

This approach efficiently tracks the minimal cost transitions using dynamic programming, ensuring that the solution is both optimal and efficient for large input sizes.
