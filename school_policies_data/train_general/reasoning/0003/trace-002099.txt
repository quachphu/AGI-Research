To solve this problem, we need to determine the number of possible ranks Milly can have based on the given conditions. The conditions are that there are at least X people better than her and no more than Y people worse than her. 

### Approach
1. **Understanding the Conditions**:
   - The number of people better than Milly is at least X, which translates to her rank being at least \(X + 1\).
   - The number of people worse than Milly is at most Y, which translates to her rank being at least \(N - Y\).

2. **Formulating the Valid Ranks**:
   - The minimum possible rank (R_min) is the maximum of \(X + 1\) and \(N - Y\).
   - The maximum possible rank is \(N\), as there can't be a rank higher than the total number of students.

3. **Calculating the Number of Valid Ranks**:
   - If R_min exceeds \(N\), there are no valid ranks.
   - Otherwise, the number of valid ranks is the range from R_min to \(N\), inclusive, which is calculated as \(N - R_min + 1\).

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        N = int(input[idx])
        X = int(input[idx+1])
        Y = int(input[idx+2])
        idx += 3
        a = X + 1
        b = N - Y
        r_min = max(a, b)
        if r_min > N:
            print(0)
        else:
            print(N - r_min + 1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The code reads all input at once using `sys.stdin.read()` for efficiency, especially given the constraints of up to \(10^5\) test cases.
2. **Processing Each Test Case**:
   - For each test case, we compute the minimum valid rank (R_min) as the maximum of \(X + 1\) and \(N - Y\).
   - Check if R_min is within the valid range (1 to N). If not, the result is 0.
   - Otherwise, compute the number of valid ranks as \(N - R_min + 1\).

This approach ensures that each test case is processed in constant time \(O(1)\), making the solution efficient and scalable even for large inputs.
