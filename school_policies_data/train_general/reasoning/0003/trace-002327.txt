To solve this problem, we need to determine which team was shown on TV for the longest cumulative time during a programming contest. The team with the highest score at any given time is shown, and in case of a tie, the team with the smallest ID is chosen. The contest log records score changes, and we need to process these records efficiently to compute the result.

### Approach
1. **Initialization**: Start with all teams having a score of 0. The initial leader is team 1 since all scores are tied at zero.
2. **Heap Data Structure**: Use a max-heap (simulated using a min-heap with negative scores) to efficiently track the team with the highest score. Each entry in the heap is a tuple of the form (-score, team_id), ensuring that the highest score (and smallest team ID in case of ties) is always at the top.
3. **Event Processing**: For each event, calculate the duration since the last event and add it to the current leader's total time. Update the team's score and push the new score into the heap.
4. **Leader Determination**: After each score update, check the heap to find the new valid leader by popping invalid entries (outdated scores) until the top entry matches the current score of the team.
5. **Final Interval**: After processing all events, account for the remaining time from the last event to the end of the contest.

import heapq
import sys

def main():
    input = sys.stdin.read().split()
