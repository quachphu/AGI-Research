### Approach
1. **Identify Even Fibonacci Numbers**: Even Fibonacci numbers occur at every third position in the Fibonacci sequence. This allows us to generate them using a specific recurrence relation.
2. **Recurrence Relation**: The even Fibonacci numbers follow the recurrence relation \( E(n) = 4 \times E(n-1) + E(n-2) \), starting with the initial values 2 and 8.
3. **Sum Calculation**: For each test case, generate even Fibonacci numbers using the recurrence relation until the generated number exceeds \( n \), summing up all valid even numbers.

### Solution Code
```python
import sys

def sum_even_fib(n):
    if n < 2:
        return 0
    a, b = 2, 8
    total = 0
    if a <= n:
        total += a
    else:
        return total
    if b <= n:
        total += b
    else:
        return total
    while True:
        c = 4 * b + a
        if c > n:
            break
        total += c
        a, b = b, c
    return total

def main():
    input_data = sys.stdin.read().split()
    T = int(input_data[0])
    for i in range(1, T + 1):
        n = int(input_data[i])
        print(sum_even_fib(n))

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read all at once and split into a list of strings for efficient processing.
2. **Processing Each Test Case**: For each test case, convert the input string to an integer and compute the sum of even Fibonacci numbers up to that integer.
3. **Generating Even Fibonacci Numbers**: Using the recurrence relation \( E(n) = 4 \times E(n-1) + E(n-2) \), generate even Fibonacci numbers starting from 2 and 8. This avoids generating all Fibonacci numbers and directly computes the even ones efficiently.
4. **Summing Valid Numbers**: Check each generated even Fibonacci number to see if it is less than or equal to \( n \), adding valid numbers to the sum until the generated number exceeds \( n \).

This approach ensures that we efficiently handle very large values of \( n \) up to \( 10^{20} \) by leveraging the properties of even Fibonacci numbers and their recurrence relation.
