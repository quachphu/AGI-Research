To solve this problem, we need to decrypt a cipher text using a substitution cipher based on frequency analysis. The solution involves mapping each character in the cipher text to a character in the English frequency sequence based on their respective positions in sorted frequency sequences.

### Approach
1. **Frequency Calculation**: For each test case, compute the frequency of each lowercase letter in the cipher text.
2. **Sorting Letters**: Sort the letters of the cipher text based on their frequency in ascending order. If two letters have the same frequency, they are sorted alphabetically.
3. **Mapping Creation**: Create a mapping from each letter in the sorted cipher frequency sequence to the corresponding letter in the given English frequency sequence.
4. **Decryption**: Use the mapping to decrypt each character in the cipher text, preserving the case of each letter.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        eng_seq = sys.stdin.readline().strip()
        cipher_text = sys.stdin.readline().rstrip('\n')
        
        # Compute frequency of each lowercase letter in cipher_text
        freq = {chr(ord('a') + i): 0 for i in range(26)}
        for c in cipher_text:
            if c.isalpha():
                lower_c = c.lower()
                freq[lower_c] += 1
        
        # Generate sorted cipher frequency sequence
        letters = [chr(ord('a') + i) for i in range(26)]
        sorted_letters = sorted(letters, key=lambda x: (freq[x], x))
        
        # Create mapping from cipher's sorted letters to English sequence
        mapping = {sorted_letters[i]: eng_seq[i] for i in range(26)}
        
        # Decrypt each character in cipher_text
        decrypted = []
        for c in cipher_text:
            if c.isalpha():
                lower_c = c.lower()
                eng_char = mapping[lower_c]
                if c.isupper():
                    decrypted.append(eng_char.upper())
                else:
                    decrypted.append(eng_char.lower())
            else:
                decrypted.append(c)
        
        print(''.join(decrypted))

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read line by line, with the first line being the number of test cases. Each test case consists of an English frequency sequence and a cipher text.
2. **Frequency Calculation**: We count the occurrences of each lowercase letter in the cipher text, ignoring case.
3. **Sorting**: The letters are sorted first by their frequency and then alphabetically to form the cipher's frequency sequence.
4. **Mapping Creation**: Each letter in the cipher's sorted sequence is mapped to the corresponding letter in the English frequency sequence.
5. **Decryption**: Each character in the cipher text is replaced using the created mapping, preserving the original case (uppercase or lowercase).

This approach ensures that we efficiently decrypt the text by leveraging frequency analysis and maintaining the correct case for each character.
