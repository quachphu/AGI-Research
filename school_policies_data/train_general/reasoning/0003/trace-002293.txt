To solve this problem, we need to count the number of spruces in a given matrix for each test case. A spruce is defined as a set of cells forming a triangular shape with a specific origin and height. The solution involves dynamic programming to efficiently compute the maximum possible height of a spruce tree originating from each cell.

### Approach
1. **Dynamic Programming (DP) Table**: We use a DP table where `dp[i][j]` represents the maximum height of a spruce tree originating at cell `(i, j)`.
2. **Bottom-Up Processing**: We process the matrix from the bottom row upwards. This allows us to compute the height of spruces in higher rows based on the already computed values in the lower rows.
3. **Transition Formula**: For each cell `(i, j)` that contains an '*', the maximum height of the spruce is determined by the minimum height of the spruces originating at the cells directly below it and diagonally adjacent to it in the next row. This is because a valid spruce of height `h` requires valid spruces of height `h-1` in those positions.

### Solution Code
```python
def count_spruces():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        m = int(input[ptr + 1])
        ptr += 2
        grid = []
        for _ in range(n):
            row = input[ptr]
            grid.append(list(row))
            ptr += 1
        dp = [[0] * m for _ in range(n)]
        for i in range(n - 1, -1, -1):
            for j in range(m):
                if grid[i][j] == '.':
                    dp[i][j] = 0
                else:
                    if i == n - 1:
                        dp[i][j] = 1
                    else:
                        left = dp[i + 1][j - 1] if j > 0 else 0
                        mid = dp[i + 1][j]
                        right = dp[i + 1][j + 1] if j < m - 1 else 0
                        dp[i][j] = 1 + min(left, mid, right)
        total = sum(sum(row) for row in dp)
        print(total)

count_spruces()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **DP Table Initialization**: A 2D list `dp` is initialized to store the maximum height of spruces for each cell.
3. **Processing Rows from Bottom to Top**: Starting from the last row, each cell's value in the DP table is computed based on the values in the row immediately below it.
4. **Transition Logic**: For each cell containing an '*', the height is determined by the minimum of the heights of the cells directly below and diagonally adjacent. This ensures that the spruce structure is valid.
5. **Summing Heights**: The total number of spruces is the sum of all values in the DP table, as each value represents the count of spruces originating at that cell.

This approach efficiently computes the result in O(n*m) time complexity per test case, making it suitable for the given constraints.
