To solve this problem, we need to find the minimum time Chef needs to wait for two dogs to fetch apples of distinct types that sum up to a given value K. The dogs can be released from either end of the row of apples, and the time taken by each dog is the number of apples they check before finding the desired type.

### Approach
1. **Precompute Earliest Occurrences**: For each apple type, compute the earliest occurrence from the left and right ends. This helps in determining the minimum time each dog would take if released from either end.
2. **Identify Valid Pairs**: Identify pairs of distinct apple types (a, b) such that their sum equals K and both types exist in the list.
3. **Calculate Minimum Time for Each Pair**: For each valid pair, compute the minimum possible time by considering all possible combinations of starting points (left or right) for both dogs. The total time Chef waits is the maximum of the times taken by each dog.

### Solution Code
```python
n, k = map(int, input().split())
t = list(map(int, input().split()))

# Precompute left_min and right_min for each type
left_min = {}
for i in range(n):
    x = t[i]
    if x not in left_min:
        left_min[x] = i + 1  # 1-based index

right_min = {}
for i in range(n-1, -1, -1):
    x = t[i]
    if x not in right_min:
        right_min[x] = n - i  # time when starting from right

present = set(t)
valid_pairs = []

for a in present:
    b = k - a
    if b in present and a < b:
        valid_pairs.append((a, b))

min_time = float('inf')

for a, b in valid_pairs:
    la = left_min.get(a, float('inf'))
    lb = left_min.get(b, float('inf'))
    ra = right_min.get(a, float('inf'))
    rb = right_min.get(b, float('inf'))
    
    case1 = max(la, lb)
    case2 = max(la, rb)
    case3 = max(ra, lb)
    case4 = max(ra, rb)
    
    current_min = min(case1, case2, case3, case4)
    if current_min < min_time:
        min_time = current_min

if min_time != float('inf'):
    print(min_time)
else:
    print(-1)
```

### Explanation
1. **Precompute Earliest Occurrences**: 
   - `left_min` stores the 1-based index of the first occurrence of each type when scanned from the left.
   - `right_min` stores the time taken to find each type when scanned from the right, which is computed as `n - i` where `i` is the 0-based index from the right end.

2. **Identify Valid Pairs**: 
   - Iterate through each unique type in the list and check if its complement (K - type) exists. If both exist and are distinct, they form a valid pair.

3. **Calculate Minimum Time**: 
   - For each valid pair (a, b), compute the maximum time taken by each dog for all combinations of starting points (left-left, left-right, right-left, right-right). The minimum of these maximum values across all valid pairs gives the solution.

This approach ensures we efficiently determine the optimal strategy for releasing the dogs, leveraging precomputed values to minimize redundant calculations. The solution handles up to the maximum constraints efficiently, ensuring it runs in linear time relative to the number of apples.
