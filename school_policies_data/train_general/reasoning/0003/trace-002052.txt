   - `prev_stack` to keep track of the previous players during forward passes.
   - `back_stack` to manage backward passes and allow toggling between the current and previous players.
2. **Forward Pass (P)**: When a forward pass is made, push the current player onto `prev_stack`, update the current player to the new ID, and clear `back_stack`.
3. **Backward Pass (B)**: When a backward pass is made, handle it based on whether `back_stack` is empty:
   - If `back_stack` is empty, push the current player onto `back_stack` and pop from `prev_stack` to get the previous player.
   - If `back_stack` is not empty, swap the current player with the top of `back_stack`.

This approach ensures that each backward pass correctly reverts to the previous holder, whether it was a forward pass or another backward pass.

    import sys
    input = sys.stdin.read().splitlines()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N, initial_id = map(int, input[idx].split())
        idx += 1
        prev_stack = []
        back_stack = []
        current = initial_id
        for _ in range(N):
            parts = input[idx].strip().split()
            idx += 1
            if parts[0] == 'P':
                prev_stack.append(current)
                current = int(parts[1])
                back_stack = []
            else:
                if back_stack:
                    temp = back_stack.pop()
                    back_stack.append(current)
                    current = temp
                else:
                    back_stack.append(current)
                    current = prev_stack.pop()
