To solve this problem, we need to calculate the trace of the matrix formed by adding two matrices, A and B, which are filled in row-major and column-major order respectively. The trace is defined as the sum of the elements on the main diagonal of the resulting matrix. Given the constraints, we need an efficient approach to avoid explicitly constructing the matrices.

### Approach
1. **Matrix Construction Insight**:
   - Matrix A (row-major) elements at position (i, j) can be computed as \((i-1) \times C + j\).
   - Matrix B (column-major) elements at position (i, j) can be computed as \((j-1) \times R + i\).

2. **Diagonal Elements Sum**:
   - The trace of the sum matrix (A + B) is the sum of elements at positions (k, k) for k from 1 to min(R, C).
   - Each element at (k, k) in the sum matrix is derived from \(A[k][k] + B[k][k]\).

3. **Mathematical Formulation**:
   - For each diagonal element (k, k), the sum is \((k-1) \times (C + R) + 2k\).
   - Summing these values from k=1 to k=K (where K is min(R, C)) gives the trace.

4. **Efficient Calculation**:
   - Using summation formulas, we derive a closed-form solution to compute the trace in constant time for each test case.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        R = int(input[idx])
        C = int(input[idx + 1])
        idx += 2
        K = min(R, C)
        term1 = (R + C + 2) * K * (K + 1) // 2
        term2 = (R + C) * K
        print(term1 - term2)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input Efficiently**: The input is read all at once using `sys.stdin.read()` to handle large input sizes efficiently.
- **Mathematical Formulation**:
  - `term1` calculates the sum of the series \((R + C + 2) \times K \times (K + 1) / 2\).
  - `term2` subtracts the accumulated value of \((R + C) \times K\) from `term1` to get the final trace value.
- **Complexity**: Each test case is processed in constant time \(O(1)\), making the solution efficient even for the upper constraints.

This approach ensures that we avoid constructing large matrices and directly compute the trace using mathematical insights, leading to optimal performance.
