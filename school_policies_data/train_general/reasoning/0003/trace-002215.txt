To solve this problem, we need to determine if any permutation of a given string can form a palindrome. A string can be rearranged into a palindrome if the character frequencies meet specific criteria: at most one character can have an odd frequency (for odd-length strings) or all characters must have even frequencies (for even-length strings).

### Approach
1. **Character Frequency Count**: Count the frequency of each character in the string.
2. **Check Odd Frequencies**: Determine how many characters have an odd frequency. If this count is 0 or 1, the string can be rearranged into a palindrome; otherwise, it cannot.

### Solution Code
```python
from collections import Counter
import sys

def main():
    s = sys.stdin.readline().strip()
    counts = Counter(s)
    odd_count = sum(1 for count in counts.values() if count % 2 != 0)
    print("YES" if odd_count <= 1 else "NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input string is read from standard input and any leading/trailing whitespace is removed using `strip()`.
2. **Counting Frequencies**: Using `collections.Counter`, we count the frequency of each character in the string.
3. **Checking Odd Frequencies**: We sum the number of characters with odd frequencies. If this sum is 0 or 1, the output is "YES"; otherwise, it is "NO".

This approach efficiently checks the necessary conditions for a string to be rearranged into a palindrome, ensuring optimal performance even for the upper constraint limits.
