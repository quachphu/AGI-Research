To solve this problem, we need to count the number of pairs of non-intersecting paths from the top-left corner (1, 1) to the bottom-right corner (n, m) in a grid, where some cells are blocked by obstacles. The solution involves using dynamic programming (DP) and the Lindström–Gessel–Viennot (LGV) lemma to efficiently compute the result.

### Approach
1. **Dynamic Programming (DP) Setup**: We use DP to compute the number of valid paths from specific start points to specific end points, avoiding obstacles. This helps in breaking down the problem into manageable subproblems.
2. **LGV Lemma Application**: By transforming the problem into a form suitable for the LGV lemma, we can compute the number of non-intersecting path pairs using a determinant of a matrix formed by path counts between transformed start and end points.

### Solution Code
```python
MOD = 10**9 + 7

n, m = map(int, input().split())
grid = [input().strip() for _ in range(n)]

def compute_dp(sx, sy, n, m, grid, MOD):
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    if sx < 1 or sy < 1 or sx > n or sy > m:
        return dp
    if grid[sx - 1][sy - 1] == '#':
        return dp
    dp[sx][sy] = 1
    for i in range(sx, n + 1):
        for j in range(sy, m + 1):
            if i == sx and j == sy:
                continue
            if grid[i - 1][j - 1] == '#':
                dp[i][j] = 0
                continue
            up = dp[i - 1][j] if i > sx else 0
            left = dp[i][j - 1] if j > sy else 0
            dp[i][j] = (up + left) % MOD
    return dp

dp1 = compute_dp(1, 2, n, m, grid, MOD)
a = dp1[n - 1][m]
b = dp1[n][m - 1] if (m - 1) >= 2 else 0

dp2 = compute_dp(2, 1, n, m, grid, MOD)
c = dp2[n - 1][m] if (n - 1) >= 2 else 0
d = dp2[n][m - 1] if (m - 1) >= 1 else 0

ans = (a * d - b * c) % MOD
print(ans)
```

### Explanation
1. **Dynamic Programming Table Construction**: The `compute_dp` function calculates the number of paths from a given start point (sx, sy) to all other cells in the grid using DP. The DP table is filled by considering valid moves (right or down) and avoiding obstacles.
2. **Path Counts for Transformed Points**: We compute path counts for four specific transformed start and end points to apply the LGV lemma:
   - Paths from (1, 2) to (n-1, m)
   - Paths from (1, 2) to (n, m-1)
   - Paths from (2, 1) to (n-1, m)
   - Paths from (2, 1) to (n, m-1)
3. **Determinant Calculation**: Using the LGV lemma, the number of non-intersecting path pairs is given by the determinant of a 2x2 matrix formed by these path counts, which simplifies to `(a*d - b*c) % MOD`.

This approach efficiently handles the problem constraints and ensures we count valid non-intersecting paths using dynamic programming and combinatorial principles.
