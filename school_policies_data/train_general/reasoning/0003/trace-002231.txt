To solve this problem, Walter White wants to buy the most expensive car available, considering both the base price and the tax percentage. The goal is to determine the car with the highest total cost after tax, and in case of a tie, select the one with the higher base price.

### Approach
1. **Input Parsing**: Read the number of test cases. For each test case, read the number of cars and their respective details (name, base price, and tax percentage).
2. **Total Cost Calculation**: For each car, compute the total cost using integer arithmetic to avoid floating-point precision issues. This is done by calculating the numerator of the total cost as `C * (100 + tax_percent)`, where `C` is the base price and `tax_percent` is the tax percentage.
3. **Sorting**: Sort the cars based on their computed total cost (in descending order). If two cars have the same total cost, sort by the base price (also in descending order).
4. **Result Extraction**: The first element in the sorted list will be the car with the highest total cost after tax, or the highest base price in case of a tie.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        cars = []
        for _ in range(n):
            parts = sys.stdin.readline().split()
            name = parts[0]
            c = int(parts[1][1:])  # Remove '$' and convert to integer
            i = int(parts[2][:-1])  # Remove '%' and convert to integer
            numerator = c * (100 + i)
            cars.append((-numerator, -c, name))
        cars.sort()
        print(cars[0][2])

if __name__ == "__main__":
    main()
```

- **Input Parsing**: The input is read line by line. Each car's details are split into three parts: name, base price (with $ removed), and tax percentage (with % removed).

- **Sorting**: The cars are sorted by a tuple that first considers the negative of the total cost numerator (to sort in descending order) and then the negative of the base price (to handle ties by descending base price).
- **Result Extraction**: After sorting, the first element's name is printed, which represents the car with the highest total cost after tax, or the highest base price in case of a tie.
