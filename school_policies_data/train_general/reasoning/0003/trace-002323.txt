To solve this problem, we need to determine if we can visit all towns by traversing each road exactly once. This problem can be modeled as checking for the existence of an Eulerian trail in an undirected graph, which requires that the graph has either 0 or 2 vertices with an odd degree. The towns are connected such that the graph is always connected, so we only need to check the degrees of the vertices.

### Approach
1. **Read Input**: Read the three roads connecting the towns.
2. **Calculate Degrees**: For each town, calculate its degree based on how many roads are connected to it.
3. **Check Odd Degrees**: Count how many towns have an odd degree. If the count is 0 or 2, an Eulerian trail exists, otherwise, it does not.

### Solution Code
```python
def main():
    import sys
    degrees = [0] * 5  # Using 1-based indexing for towns 1-4
    for _ in range(3):
        a, b = map(int, sys.stdin.readline().split())
        degrees[a] += 1
        degrees[b] += 1
    odd_count = sum(1 for i in range(1, 5) if degrees[i] % 2 != 0)
    print("YES" if odd_count in {0, 2} else "NO")

main()
```

### Explanation
1. **Reading Input**: The code reads three lines of input, each representing a road between two towns.
2. **Degree Calculation**: For each road, the degrees of the connected towns are incremented.
3. **Odd Degree Check**: The code counts how many towns have an odd degree. If this count is 0 or 2, it prints "YES" indicating the existence of an Eulerian trail; otherwise, it prints "NO".

This approach efficiently checks the necessary conditions for an Eulerian trail using a straightforward degree calculation and count, ensuring optimal performance and correctness.
