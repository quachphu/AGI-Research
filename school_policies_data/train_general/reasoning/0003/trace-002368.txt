The solution involves leveraging mathematical properties to efficiently find valid values of \( n \) without iterating through all possible values up to \( x \).

### Approach
1. **Mathematical Insight**: Using Fermat's Little Theorem, we know that \( a^{p-1} \equiv 1 \mod p \). This implies that the exponents of \( a \) modulo \( p \) repeat every \( p-1 \) steps. Additionally, the term \( n \mod p \) repeats every \( p \) steps. Combining these, the behavior of \( n \cdot a^n \mod p \) repeats every \( p \cdot (p-1) \) steps.

2. **Residue Calculation**: For each possible residue \( r \) of \( n \mod (p-1) \), compute the corresponding \( a^r \mod p \). Using modular arithmetic, derive the valid residues of \( n \mod (p \cdot (p-1)) \) that satisfy the given congruence.

3. **Count Valid Values**: For each valid residue, count how many numbers up to \( x \) are congruent to that residue modulo \( p \cdot (p-1) \).

### Solution Code
```python
a, b, p, x = map(int, input().split())
m = p * (p - 1)
valid = set()

for r in range(p - 1):
    ar = pow(a, r, p)
    inv_ar = pow(ar, p - 2, p)
    c = (r - b * inv_ar) % p
    residue = ((p - 1) * c + r) % m
    if (residue * ar) % p == b % p:
        valid.add(residue)

count = 0
for res in valid:
    if res == 0:
        current = x // m
    else:
        if res > x:
            current = 0
        else:
            current = (x - res) // m + 1
    count += current

print(count)
```

3. **Residue Calculation**: For each residue \( r \) modulo \( p-1 \):
