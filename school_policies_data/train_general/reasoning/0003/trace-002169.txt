To solve this problem, we need to determine the minimal possible absolute difference between the sum of any two distinct elements in an array and a given integer K, and then count how many such pairs achieve this minimal difference.

### Approach
1. **Sort the Array**: Sorting the array helps in efficiently finding pairs using a two-pointer technique.
2. **Two-Pointer Technique for Minimal Difference**: Use two pointers to traverse the sorted array from both ends towards the center to find the minimal absolute difference between the sum of any two elements and K.
3. **Track Possible Sums**: During the traversal, track all sums that contribute to the minimal difference.
4. **Count Valid Pairs**: For each sum that contributes to the minimal difference, count the number of valid pairs using the two-pointer technique again, efficiently handling duplicates.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N, K = int(input[ptr]), int(input[ptr + 1])
        ptr += 2
        arr = list(map(int, input[ptr:ptr + N]))
        ptr += N
        arr.sort()
        
        min_diff = float('inf')
        possible_sums = set()
        left = 0
        right = N - 1
        
        while left < right:
            current_sum = arr[left] + arr[right]
            current_diff = abs(current_sum - K)
            if current_diff < min_diff:
                min_diff = current_diff
                possible_sums = {current_sum}
            elif current_diff == min_diff:
                possible_sums.add(current_sum)
            if current_sum < K:
                left += 1
            else:
                right -= 1
        
        total_count = 0
        for S in possible_sums:
            count = 0
            l = 0
            r = N - 1
            while l < r:
                s = arr[l] + arr[r]
                if s == S:
                    if arr[l] == arr[r]:
                        num = r - l + 1
                        count += num * (num - 1) // 2
                        break
                    else:
                        cnt_left = 1
                        while l + 1 < r and arr[l] == arr[l + 1]:
                            l += 1
                            cnt_left += 1
                        cnt_right = 1
                        while r - 1 > l and arr[r] == arr[r - 1]:
                            r -= 1
                            cnt_right += 1
                        count += cnt_left * cnt_right
                        l += 1
                        r -= 1
                elif s < S:
                    l += 1
                else:
                    r -= 1
            total_count += count
        
        print(min_diff, total_count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially for large input sizes.
2. **Sorting**: The array is sorted to facilitate the two-pointer approach.
3. **Finding Minimal Difference**: Using two pointers, we traverse the sorted array to find the minimal absolute difference between any pair sum and K. During this traversal, we track all sums that achieve this minimal difference.
4. **Counting Pairs**: For each sum that contributes to the minimal difference, we use the two-pointer technique again to count all valid pairs, efficiently handling duplicates by counting contiguous elements with the same value.

This approach ensures that we efficiently find the minimal difference and count the pairs in O(N) time per test case (after sorting, which is O(N log N)), making it suitable for large input sizes.
