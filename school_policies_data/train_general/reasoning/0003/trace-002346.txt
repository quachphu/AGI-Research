To solve this problem, we need to determine if it is possible to obtain an array with an odd sum by performing any number of operations where we set an element's value to another element's value. The key insight is to check the parity (even or odd) of the elements and their counts.

### Approach
1. **Check for All Even Elements**: If all elements are even, the sum will always be even, so the answer is "NO".
2. **Check for All Odd Elements**: If all elements are odd, the sum will be odd if and only if the number of elements (n) is odd. Thus, the answer is "YES" if n is odd, otherwise "NO".
3. **Check for Mixed Elements**: If there are both even and odd elements, we can always adjust the array to have an odd sum by setting the count of odd elements to be odd. Hence, the answer is "YES".

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    has_even = False
    has_odd = False
    for num in a:
        if num % 2 == 0:
            has_even = True
        else:
            has_odd = True
    if has_even and has_odd:
        print("YES")
    else:
        if has_odd:
            print("YES" if n % 2 == 1 else "NO")
        else:
            print("NO")
```

### Explanation
1. **Reading Input**: The code reads the number of test cases and processes each test case individually.
2. **Parity Check**: For each test case, it checks if there are any even or odd elements in the array.
3. **Decision Making**:
   - If both even and odd elements are present, the answer is "YES".
   - If all elements are odd, the answer depends on whether the count of elements (n) is odd.
   - If all elements are even, the answer is "NO".

This approach efficiently checks the necessary conditions in linear time relative to the number of elements in each test case, ensuring it handles the constraints effectively.
