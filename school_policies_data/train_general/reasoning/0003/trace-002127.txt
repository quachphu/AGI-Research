To solve this problem, we need to determine the probability that an array of 0s and 1s becomes sorted in non-decreasing order after exactly k random swaps. The solution involves modeling the problem using a Markov chain and matrix exponentiation to efficiently compute the probability after a large number of swaps.

### Approach
1. **Identify the Target State**: The sorted array must have all 0s followed by all 1s. The number of 0s (m) and 1s (n - m) in the array is fixed.
2. **Initial State Check**: If the array is already sorted (all 0s or all 1s), the probability is 1. Otherwise, proceed.
3. **Count Misplaced Elements**: Determine the number of 1s in the first m positions (x_initial) which indicates how far the array is from being sorted.
4. **Transition Matrix**: Construct a transition matrix where each state represents the number of misplaced elements (x). The matrix captures the probabilities of moving between states with each swap.
5. **Matrix Exponentiation**: Use matrix exponentiation to compute the state probabilities after k swaps efficiently.

### Solution Code
```python
MOD = 10**9 + 7

def main():
    import sys
    n, k = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    m = sum(1 for x in a if x == 0)
    
    if m == 0 or m == n:
        print(1)
        return
    
    x_initial = sum(1 for x in a[:m] if x == 1)
    s = min(m, n - m)
    
    if x_initial == 0:
        print(1)
        return
    
    C = n * (n - 1) // 2
    inv_C = pow(C, MOD - 2, MOD)
    
    size = s + 1
    matrix = [[0] * size for _ in range(size)]
    
    for x in range(size):
        prob_down = (x * x) % MOD
        prob_down = prob_down * inv_C % MOD
        
        up_factor = ((m - x) * ((n - m) - x)) % MOD
        prob_up = up_factor * inv_C % MOD
        
        prob_stay = (1 - prob_down - prob_up) % MOD
        prob_stay = (prob_stay + MOD) % MOD
        
        if x > 0:
            matrix[x][x - 1] = (matrix[x][x - 1] + prob_down) % MOD
        if x < s:
            matrix[x][x + 1] = (matrix[x][x + 1] + prob_up) % MOD
        matrix[x][x] = (matrix[x][x] + prob_stay) % MOD
    
    def multiply(a, b):
        res = [[0] * size for _ in range(size)]
        for i in range(size):
            for k in range(size):
                if a[i][k] == 0:
                    continue
                for j in range(size):
                    res[i][j] = (res[i][j] + a[i][k] * b[k][j]) % MOD
```
