To solve this problem, we need to determine the longest consecutive sequence of days (streak) such that if we remove exactly one day from this streak, all remaining ribbon colors will have the same number of occurrences. 

### Approach
1. **Track Frequencies**: For each day, track the frequency of each ribbon color using a dictionary.
2. **Track Frequency Counts**: Maintain another dictionary to count how many colors have each frequency. This helps in quickly checking the conditions for valid streaks.
3. **Check Valid Conditions**: For each day, after updating the frequencies, check if the current state meets any of the following conditions:
   - **All Colors with Frequency 1**: The streak length is equal to the number of colors, each appearing exactly once.
   - **One Color with Frequency 1 and Others the Same**: One color appears once, and all other colors appear the same number of times.
   - **One Color with Frequency One More Than Others**: One color appears one more time than others, which allows removing one occurrence to balance the counts.
   - **Single Color**: Only one color exists, which is always valid as removing any day leaves a valid count.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n = int(sys.stdin.readline())
    u = list(map(int, sys.stdin.readline().split()))
    freq = defaultdict(int)
    freq_counts = defaultdict(int)
    max_x = 0

    for i in range(n):
        color = u[i]
        prev_count = freq[color]
        if prev_count > 0:
            freq_counts[prev_count] -= 1
            if freq_counts[prev_count] == 0:
                del freq_counts[prev_count]
        new_count = prev_count + 1
        freq[color] = new_count
        freq_counts[new_count] += 1
        x = i + 1
        valid = False

        # Case a: all colors have count 1, x colors
        if len(freq_counts) == 1 and 1 in freq_counts and freq_counts[1] == x:
            valid = True
        # Case b: one color with count 1, others same
        elif 1 in freq_counts and freq_counts[1] == 1:
            if len(freq_counts) == 2:
                keys = list(freq_counts.keys())
                keys.remove(1)
                k = keys[0]
                if (1 + k * freq_counts[k]) == x:
                    valid = True
        # Case c: one color has a+1, others a
        elif len(freq_counts) == 2:
            keys = sorted(freq_counts.keys())
            a, b = keys
            if b == a + 1 and freq_counts[b] == 1:
                if (b + a * freq_counts[a]) == x:
                    valid = True
        # Case d: only one color
        elif len(freq_counts) == 1:
            (count, cnt) = next(iter(freq_counts.items()))
            if cnt == 1:
                valid = True

        if valid:
            max_x = max(max_x, x)

    print(max_x)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input, including the number of days and the sequence of ribbon colors.
2. **Tracking Frequencies**: For each day, update the frequency of the current ribbon color and adjust the frequency count dictionary accordingly.
3. **Checking Validity**: For each day, check if the current frequency counts meet any of the valid conditions. If so, update the maximum valid streak length.
4. **Output the Result**: After processing all days, print the longest valid streak length.

This approach ensures that we efficiently check each day in constant time, leading to an overall time complexity of O(n), which is suitable for large input sizes up to 100,000 days.
