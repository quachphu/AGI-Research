To solve this problem, we need to determine the probability of winning a prize by switching doors in a game show scenario, generalized for any number of doors. This problem is an extension of the classic Monty Hall problem.

### Approach
1. **Understanding the Problem**: The problem involves `N` doors, one of which hides a prize while the others hide sumo wrestlers. After the initial selection of a door by the player, the host opens `N-2` doors, all revealing sumo wrestlers. The player then has the choice to stick with their original door or switch to the remaining unopened door. We need to calculate the probability of winning the prize by switching doors.

2. **Key Insight**: The probability of initially choosing the correct door is `1/N`, and the probability of the prize being behind one of the other doors is `(N-1)/N`. After the host opens `N-2` doors, the remaining unopened door (other than the player's initial choice) will have the prize if the initial choice was incorrect. Thus, the probability of winning by switching is `(N-1)/N`.

3. **General Formula**: For any number of doors `N`, the probability of winning by switching is given by `(N-1)/N`.

4. **Implementation**: Read the number of test cases, then for each test case compute the probability using the formula and format the result to six decimal places.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline().strip())
        probability = (n - 1) / n
        print("{0:.6f}".format(probability))

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input consists of multiple test cases. The first line gives the number of test cases `T`. Each subsequent line contains an integer `N` representing the number of doors for that test case.
- **Probability Calculation**: For each test case, the probability of winning by switching doors is calculated using the formula `(N-1)/N`.
- **Output Formatting**: The result is formatted to six decimal places using Python's string formatting to ensure the required precision.

This approach efficiently computes the result in constant time for each test case, making it suitable for the given constraints.
