To solve this problem, we need to determine the minimum number of seconds required to transform an equilateral triangle with side length `x` into one with side length `y` by modifying one side at a time, ensuring that each intermediate step forms a valid (non-degenerate) triangle.

### Approach
The key insight is to reduce the largest side of the triangle as quickly as possible while maintaining the triangle inequality. The triangle inequality states that the sum of any two sides must be greater than the third side. By repeatedly reducing the largest side to the maximum possible value that maintains this inequality, we can efficiently reach the target side length `y`.

### Solution Code
```python
x, y = map(int, input().split())
a = b = c = x
steps = 0
while a > y or b > y or c > y:
    a, b, c = sorted([a, b, c])
    if c > y:
        target = max(y, a + b - 1)
        steps += c - target
        c = target
    elif b > y:
        target = max(y, a + c - 1)
        steps += b - target
        b = target
    else:
        target = max(y, b + c - 1)
        steps += a - target
        a = target
print(steps)
```

### Explanation
1. **Initialization**: Start with three sides all set to `x`.
2. **Loop Until Target**: Continue adjusting the sides until all sides are reduced to `y`.
3. **Sort Sides**: Always sort the sides to identify the largest side.
4. **Adjust Largest Side**: Reduce the largest side to the maximum possible value that maintains the triangle inequality. This value is determined by the sum of the other two sides minus 1, ensuring it does not drop below `y`.
5. **Track Steps**: Each adjustment counts as the difference between the current side length and the new target value.

This approach efficiently reduces the largest side in each iteration, ensuring minimal steps while maintaining valid triangles throughout the process. The complexity is linear with respect to the difference between `x` and `y`, making it efficient even for large values.
