To solve this problem, we need to determine if there exists an order of guests such that no guest gets angry when they can't find their chosen type of cookie. The solution involves checking two key conditions based on the given constraints.

### Approach
1. **Total Cookies Check**: The sum of vanilla and chocolate cookies must be at least equal to the total number of guests. This ensures there are enough cookies to serve all guests.
2. **Minority Check**: The number of type 2 guests (who choose the minority cookie) must not exceed the initial count of the minority cookie type. This ensures that type 2 guests can always find their chosen cookie type without running out.

### Solution Code
```python
t = int(input())
for _ in range(t):
    a, b, n, m = map(int, input().split())
    total = a + b
    if total >= n + m and m <= min(a, b):
        print("Yes")
    else:
        print("No")
```

### Explanation
1. **Total Cookies Check**: The sum of vanilla (`a`) and chocolate (`b`) cookies must be at least equal to the sum of type 1 (`n`) and type 2 (`m`) guests. This is checked using `a + b >= n + m`.
2. **Minority Check**: Type 2 guests will always choose the minority cookie type. Therefore, the number of type 2 guests (`m`) must not exceed the initial count of the minority cookie type, which is `min(a, b)`.

By ensuring both conditions are met, we can determine if there exists a valid order of guests where no one gets angry. If both conditions are satisfied, the answer is "Yes"; otherwise, it is "No". This approach efficiently checks the necessary conditions in constant time for each test case, making it suitable for large input sizes.
