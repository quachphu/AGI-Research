To solve this problem, we need to determine if we can transform a sequence of non-negative integers into all zeros using a specific operation. The operation allows us to subtract 1 from two adjacent elements at a time. 

### Approach
1. **Sum Check**: The sum of the sequence must be even. This is because each operation reduces the total sum by 2, so an odd sum makes it impossible to reach zero.
2. **Single Element Case**: If the sequence has only one element, it must be zero to be considered valid.
3. **Sequential Check**: For sequences with more than one element, we simulate the operations by iterating through the sequence and checking if we can balance the elements such that each element can be reduced to zero through valid operations.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    a = list(map(int, input[idx:idx+N]))
    
    if N == 1:
        print("YES" if a[0] == 0 else "NO")
        return
    
    total = sum(a)
    if total % 2 != 0:
        print("NO")
        return
    
    x = a[0]
    if x < 0:
        print("NO")
        return
    
    for i in range(1, N-1):
        x = a[i] - x
        if x < 0:
            print("NO")
            return
    
    print("YES" if x == a[-1] and x >= 0 else "NO")

solve()
```

### Explanation
1. **Sum Check**: The sum of the sequence is first checked for evenness. If it is odd, the answer is immediately "NO".
2. **Single Element Handling**: If there is only one element, it must be zero to return "YES".
3. **Sequential Validation**: For sequences with more than one element, we simulate the operations by iterating through the elements. Starting from the first element, we compute the required operations for each subsequent element. If at any point the operations required become negative or the final element does not match the required value, we return "NO".

This approach ensures that we efficiently check the feasibility of transforming the sequence into all zeros using the given operations.
