To solve this problem, we need to determine how many times an automatic door opens given the arrival times of employees and clients. The door opens when someone arrives and it is closed, and it closes after a specified duration unless someone arrives exactly at the closing time.

### Approach
1. **Event Processing**: The employees arrive at times forming an arithmetic sequence (a, 2a, 3a, ..., na), while clients arrive at specified times given in non-decreasing order. We need to process these events in chronological order.
2. **Efficient Batch Processing**: Given the constraints (n up to 10^9), we cannot generate all employee times explicitly. Instead, we process batches of employees efficiently by calculating how many can be skipped during the door's open period.
3. **Two-pointer Technique**: We use two pointers to track the next employee and client events. For each event, we determine if the door needs to open and update the closing time accordingly. If an event occurs while the door is open, we skip processing those events until the door closes.

### Solution Code
```python
n, m, a, d = map(int, input().split())
t = list(map(int, input().split())) if m else []

employee_index = 1
client_index = 0
current_closing = -1  # initialized to a value less than any possible arrival time (>=1)
count = 0

while employee_index <= n or client_index < m:
    next_employee = a * employee_index if employee_index <= n else float('inf')
    next_client = t[client_index] if client_index < m else float('inf')
    
    if next_employee < next_client:
        if next_employee > current_closing:
            count += 1
            current_closing = next_employee + d
            x_max = d // a
            remaining = n - employee_index
            x_max = min(x_max, remaining)
            employee_index += x_max + 1
        else:
            delta = current_closing - next_employee
            x_max = delta // a
            remaining = n - employee_index
            x_max = min(x_max, remaining)
            x_max = max(x_max, 0)
            employee_index += x_max + 1
    else:
        if next_client > current_closing:
            count += 1
            current_closing = next_client + d
        client_index += 1

print(count)
```

### Explanation
1. **Initialization**: We initialize pointers for the next employee and client, and track the current closing time of the door.
2. **Event Comparison**: For each iteration, we compare the next employee and client times to determine the next event to process.
3. **Employee Processing**: If the next employee arrives when the door is closed, the door opens, and we calculate how many subsequent employees can be processed in a batch during this open period. If the employee arrives while the door is open, we skip all subsequent employees during this period.
4. **Client Processing**: Similarly, if a client arrives when the door is closed, the door opens. If they arrive while the door is open, they enter without triggering a new opening.
5. **Efficiency**: By using batch processing for employees and efficiently merging events, we handle large values of n and m within feasible time complexity.

This approach ensures that we efficiently process all events in chronological order while minimizing redundant operations, making the solution both optimal and scalable.
