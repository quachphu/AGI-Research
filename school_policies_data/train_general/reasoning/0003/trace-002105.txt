To solve this problem, we need to determine the minimum number of inspectors required to cover all apple trees in a row, where each inspector can cover a range of trees from their position minus D to their position plus D (inclusive).

### Approach
The key insight to solve this problem efficiently is to use a greedy algorithm. The idea is to place each inspector as far to the right as possible while ensuring coverage of the leftmost uncovered tree. This approach ensures that each inspector covers the maximum possible range, thereby minimizing the total number of inspectors needed.

1. **Initialization**: Start with the first tree as the initial position to cover.
2. **Place Inspector**: For each position, determine the farthest right position an inspector can be placed while covering the current leftmost uncovered tree.
3. **Update Coverage**: After placing an inspector, update the next position to cover based on the farthest coverage of the current inspector.
4. **Repeat**: Continue this process until all trees are covered.

### Solution Code
```python
n, d = map(int, input().split())

count = 0
current = 1

while current <= n:
    count += 1
    i = current + d
    if i > n:
        i = n
    current = i + d + 1

print(count)
```

### Explanation
1. **Initialization**: We start with `count` set to 0 (no inspectors placed yet) and `current` set to 1 (the first tree to cover).
2. **Loop Until All Trees Are Covered**: While the current position to cover is within the range of trees (1 to N):
   - Increment the inspector count.
   - Calculate the farthest position `i` where an inspector can be placed to cover the current leftmost tree. This is `current + D`, but it must not exceed the total number of trees `N`.
   - Update the next position to cover (`current`) to be just beyond the farthest coverage of the current inspector, which is `i + D + 1`.
3. **Termination**: The loop terminates when all trees are covered, and the total count of inspectors is printed.

This approach ensures that each inspector covers the maximum possible range, leading to an optimal solution with minimal computational complexity.
