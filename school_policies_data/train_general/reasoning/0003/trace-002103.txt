To solve this problem, we need to determine the minimum number of groups required to divide people such that no two friends are in the same group. The key insight is that each group must be an independent set in the friendship graph, which is formed by considering transitive friendships.

### Approach
1. **Model the Problem as a Graph**: Each person is a node, and each friendship is an undirected edge. The goal is to find the largest connected component in this graph, as each component must be split into groups where no two friends are together.
2. **Union-Find Data Structure**: Use the Union-Find (Disjoint Set Union, DSU) data structure to efficiently determine connected components. This helps in merging nodes (people) into sets based on friendships.
3. **Component Size Calculation**: Track the size of each connected component during union operations. The minimum number of groups needed is determined by the size of the largest connected component, as each member of a component must be in a separate group.

### Solution Code
```python
import sys
sys.setrecursionlimit(1 << 25)

def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    idx = 0
    N = int(data[idx])
    idx += 1
    M = int(data[idx])
    idx += 1
    
    parent = list(range(N + 1))
    size = [1] * (N + 1)
    
    def find(u):
        while parent[u] != u:
            parent[u] = parent[parent[u]]
            u = parent[u]
        return u
    
    def union(u, v):
        u_root = find(u)
        v_root = find(v)
        if u_root == v_root:
            return
        if size[u_root] < size[v_root]:
            u_root, v_root = v_root, u_root
        parent[v_root] = u_root
        size[u_root] += size[v_root]
    
    for _ in range(M):
        a = int(data[idx])
        idx += 1
        b = int(data[idx])
        idx += 1
        union(a, b)
    
    max_size = 0
    for i in range(1, N + 1):
        if find(i) == i and size[i] > max_size:
            max_size = size[i]
    
    print(max_size)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Union-Find Initialization**: Each person starts as their own parent with a component size of 1.
3. **Union Operations**: For each friendship, the union operation merges two sets and updates the size of the resulting set.
4. **Finding the Largest Component**: After processing all friendships, the size of each root component is checked to find the maximum, which determines the minimum number of groups needed.

This approach efficiently handles up to the maximum constraints using path compression and union by size in the Union-Find structure, ensuring optimal performance.
