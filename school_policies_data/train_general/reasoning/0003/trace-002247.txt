To solve this problem, we need to determine if there is a path from vertex u to vertex v in a directed graph where edges exist based on a bitwise AND condition. The solution involves checking if the cumulative set bits up to each bit position in u are sufficient to reach the cumulative set bits in v.

### Approach
1. **Immediate Checks**: If u is greater than v, it's impossible to reach v from u. If u equals v, the answer is trivially yes.
2. **Bitwise Analysis**: For u to reach v when u < v, we need to ensure that for every bit position from the least significant to the most, the cumulative number of set bits in u up to that position is at least as many as in v. This ensures that u can transition through intermediate nodes using valid edges.

### Solution Code
```python
import sys

def can_reach(u, v):
    if u == v:
        return True
    if u > v:
        return False
    cu = 0
    cv = 0
    for i in range(31):
        cu += (u >> i) & 1
        cv += (v >> i) & 1
        if cv > cu:
            return False
    return True

def main():
    input = sys.stdin.read().split()
    q = int(input[0])
    idx = 1
    for _ in range(q):
        u = int(input[idx])
        v = int(input[idx+1])
        idx += 2
        if can_reach(u, v):
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints up to 100,000 queries.
2. **Immediate Checks**: For each query, we first check if u is greater than v (return "NO") or if u equals v (return "YES").
3. **Bitwise Cumulative Check**: We iterate through each bit position from 0 to 30. For each position, we maintain cumulative counts of set bits for both u and v. If at any bit position the cumulative count of set bits in v exceeds that in u, we return "NO".
4. **Efficiency**: Each query is processed in O(31) time, making the solution efficient and suitable for large input sizes.

This approach ensures that we efficiently determine the possibility of reaching v from u using the properties of bitwise operations and cumulative bit counts.
