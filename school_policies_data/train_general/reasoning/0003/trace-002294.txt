To solve this problem, we need to determine how many programming problems a team of three friends will solve based on their confidence in each problem. The friends will solve a problem if at least two of them are confident in the solution. 

### Approach
1. **Input Reading**: First, read the number of problems.
2. **Confidence Check**: For each problem, read the confidence values of the three friends. Sum these values to determine how many friends are confident.
3. **Decision Making**: If the sum of confident friends is 2 or more, count the problem as solvable by the team.
4. **Count Tracking**: Maintain a counter to keep track of the number of solvable problems and print this count at the end.

### Solution Code
```python
def count_problems():
    n = int(input())
    count = 0
    for _ in range(n):
        p, v, t = map(int, input().split())
        if p + v + t >= 2:
            count += 1
    print(count)

count_problems()
```

### Explanation
1. **Reading Input**: The first input line gives the number of problems `n`. For each problem, the next `n` lines contain three integers (0 or 1) representing the confidence of Petya, Vasya, and Tonya respectively.
2. **Summing Confidence Values**: For each problem, we sum the confidence values. If the sum is 2 or 3, it means at least two friends are confident, so we increment the count.
3. **Output the Result**: After processing all problems, the count of solvable problems is printed.

This approach efficiently checks each problem in constant time, leading to an overall time complexity of O(n), which is optimal for the given problem constraints.
