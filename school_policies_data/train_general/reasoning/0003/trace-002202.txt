To solve this problem, we need to determine the number of hexagonal cells situated within a distance of `n` from a given central cell on an infinite hexagonal grid. The distance is defined as the minimum number of cell border crosses required to move from the central cell to another cell.

### Approach
The key insight is to recognize the pattern in the number of cells as the distance increases. Each layer of cells at distance `k` from the center forms a hexagonal ring. The number of cells in each ring at distance `k` is `6 * k`. Summing these cells from distance 0 to `n` gives the total number of cells within that distance.

1. **Central Cell**: At distance 0, there is exactly 1 cell (the center itself).
2. **First Ring**: At distance 1, there are 6 cells.
3. **Second Ring**: At distance 2, there are 12 cells.
4. **k-th Ring**: At distance `k`, there are `6 * k` cells.

Summing these values from 0 to `n` gives the formula:
\[ \text{Total cells} = 1 + 6 \times (1 + 2 + 3 + \ldots + n) \]
The sum of the first `n` integers is given by \( \frac{n(n+1)}{2} \). Substituting this into the formula, we get:
\[ \text{Total cells} = 1 + 3 \times n \times (n + 1) \]

### Solution Code
```python
def main():
    n = int(input())
    print(1 + 3 * n * (n + 1))

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The code reads an integer `n` from the standard input.
- **Formula Application**: Using the derived formula, the code computes the total number of cells within the distance `n` from the central cell.
- **Output**: The result is printed, which is the sum of all cells from distance 0 to `n`.

This approach efficiently computes the result in constant time \( O(1) \), making it suitable for very large values of `n` up to \( 10^9 \).
