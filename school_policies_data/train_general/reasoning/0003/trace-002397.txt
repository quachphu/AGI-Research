To solve this problem, we need to determine the number of squares in a grid where all four corner cells are the same color. The squares must have edges parallel to the grid's sides and must be composed of at least four cells.

### Approach
1. **Input Reading**: Read the number of test cases and the grid configurations for each test case.
2. **Grid Traversal**: For each grid, check all possible squares starting from size 2x2 up to the minimum dimension of the grid (either rows or columns).
3. **Corner Check**: For each possible square size, check all valid positions in the grid. For each position, verify if all four corner cells of the square are the same color.
4. **Count Valid Squares**: Keep a count of all valid squares found during the traversal.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        M = int(input[ptr + 1])
        ptr += 2
        grid = []
        for _ in range(N):
            grid.append(input[ptr])
            ptr += 1
        count = 0
        max_k = min(N, M)
        for k in range(2, max_k + 1):
            for i in range(N - k + 1):
                for j in range(M - k + 1):
                    tl = grid[i][j]
                    tr = grid[i][j + k - 1]
                    bl = grid[i + k - 1][j]
                    br = grid[i + k - 1][j + k - 1]
                    if tl == tr == bl == br:
                        count += 1
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings for efficient processing.
2. **Loop Through Test Cases**: For each test case, the grid dimensions (N and M) and the grid itself are extracted.
3. **Check All Square Sizes**: For each possible square size starting from 2x2, iterate through all valid top-left positions (i, j) where the square can fit within the grid.
4. **Check Corners**: For each valid square position, check the four corners (top-left, top-right, bottom-left, bottom-right). If all four corners are the same color, increment the count.
5. **Output Result**: After processing all possible squares for a grid, print the count of valid squares for that test case.

This approach ensures that all possible squares are checked efficiently, leveraging nested loops to traverse the grid and validate each square's corners. The complexity is manageable given the constraints, making it feasible to handle the maximum input size effectively.
