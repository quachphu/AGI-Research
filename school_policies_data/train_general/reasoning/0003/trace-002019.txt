The solution involves preprocessing the array to efficiently compute the number of valid moves for each game and then determining the winner based on the parity of the count of valid moves and who starts first.

### Approach
1. **Preprocessing the Array**:
   - **Compute L and R Arrays**: For each element in the array, compute the nearest element to the left that is greater than or equal to the current element (L array) and the nearest element to the right that is strictly greater than the current element (R array). This helps in determining the number of subarrays where each element is the maximum.
   - **Frequency Map**: Using the L and R arrays, compute the number of subarrays where each element is the maximum. This frequency is stored in a map.

2. **Handling Queries Efficiently**:
   - **Sort and Prefix Sum**: Sort the unique elements from the frequency map and compute prefix sums to quickly determine the sum of elements meeting specific constraints (greater than, less than, or equal to a given value).

3. **Determine the Winner**:
   - For each query, compute the count of valid moves using the prefix sums and binary search. The winner is determined based on whether the count is even or odd and who starts the game.

import bisect
from sys import stdin

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    N, M = int(input[ptr]), int(input[ptr+1])
    ptr += 2
    A = list(map(int, input[ptr:ptr+N]))
    ptr += N

    # Compute L and R arrays using monotonic stacks
    L = [-1] * N
    stack = []
    for i in range(N):
        while stack and A[stack[-1]] < A[i]:
            stack.pop()
        if stack:
            L[i] = stack[-1]
        else:
            L[i] = -1
        stack.append(i)
    
    R = [N] * N
    stack = []
    for i in range(N-1, -1, -1):
        while stack and A[stack[-1]] <= A[i]:
            stack.pop()
        if stack:
            R[i] = stack[-1]
        else:
            R[i] = N
        stack.append(i)
    
    # Calculate frequency of each element's contribution
    freq = {}
    for i in range(N):
        cnt = (i - L[i]) * (R[i] - i)
        key = A[i]
        if key in freq:
            freq[key] += cnt
        else:
            freq[key] = cnt
    
    # Prepare sorted values and prefix sums
    sorted_values = sorted(freq.keys())
    prefix_sums = []
    current_sum = 0
    for x in sorted_values:
        current_sum += freq[x]
        prefix_sums.append(current_sum)
    total_sum = current_sum

    # Process each query
    result = []
    for _ in range(M):
        C = input[ptr]
        K = int(input[ptr+1])
        X = input[ptr+2]
        ptr += 3
        
        if C == '>':
            idx = bisect.bisect_right(sorted_values, K)
            sum_val = total_sum - (prefix_sums[idx-1] if idx > 0 else 0)
        elif C == '<':
            idx = bisect.bisect_left(sorted_values, K)
            sum_val = prefix_sums[idx-1] if idx > 0 else 0
        else:  # '='
            idx = bisect.bisect_left(sorted_values, K)
            if idx < len(sorted_values) and sorted_values[idx] == K:
                sum_val = freq[sorted_values[idx]]
            else:
                sum_val = 0
        
        # Determine the winner
        if sum_val == 0:
            winner = 'C' if X == 'D' else 'D'
        else:
            if sum_val % 2 == 1:
                winner = X
            else:
                winner = 'C' if X == 'D' else 'D'
        result.append(winner)
    
    print(''.join(result))

if __name__ == "__main__":
    main()

2. **Query Handling**:
