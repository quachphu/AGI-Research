To solve this problem, we need to predict the outcome of a competition between two contestants, Limak and Radewoosh, based on the points they accumulate by solving problems in different orders. The points for each problem decrease linearly over time, and we need to determine who scores more points or if there is a tie.

### Approach
1. **Problem Analysis**:
   - Each problem has an initial score and a time required to solve it.
   - Points for a problem submitted at time `x` are calculated as `max(0, pi - c * x)`, where `c` is the rate of point loss per minute.
   - Limak solves problems in increasing order of difficulty, while Radewoosh solves them in decreasing order.

2. **Key Insight**:
   - **Submission Time Calculation**:
     - For Limak, the submission time for each problem is the cumulative sum of times taken to solve all previous problems up to the current one.
     - For Radewoosh, the submission time for each problem is the cumulative sum of times taken to solve the current problem and all subsequent harder problems.

3. **Algorithm**:
   - Compute prefix sums for Limak's submission times.
   - Compute suffix sums for Radewoosh's submission times.
   - Calculate total points for both contestants using their respective submission times and the given formula.
   - Compare the total points to determine the winner or if there is a tie.

### Solution Code
```python
n, c = map(int, input().split())
p = list(map(int, input().split()))
t = list(map(int, input().split()))

# Compute prefix sums for Limak's submission times
prefix = []
current_sum = 0
for time in t:
    current_sum += time
    prefix.append(current_sum)

# Compute suffix sums for Radewoosh's submission times
suffix = [0] * n
current_sum = 0
for i in range(n-1, -1, -1):
    current_sum += t[i]
    suffix[i] = current_sum

# Calculate total points for Limak and Radewoosh
limak_total = sum(max(0, p[i] - c * prefix[i]) for i in range(n))
rade_total = sum(max(0, p[i] - c * suffix[i]) for i in range(n))

# Determine and print the result
if limak_total > rade_total:
    print("Limak")
elif rade_total > limak_total:
    print("Radewoosh")
else:
    print("Tie")
```

### Explanation
1. **Reading Input**: The input consists of the number of problems, the rate of point loss, the initial scores of problems, and the time required to solve each problem.
2. **Prefix Sums for Limak**: We calculate the cumulative time taken to solve each problem in order, which gives the submission times for Limak.
3. **Suffix Sums for Radewoosh**: We calculate the cumulative time starting from the hardest problem to the easiest, which gives the submission times for Radewoosh.
4. **Points Calculation**: For each problem, we compute the points using the respective submission times and sum them up for both contestants.
5. **Result Determination**: The totals are compared to determine the winner or if there is a tie.

This approach efficiently computes the required values using prefix and suffix sums, ensuring an optimal solution with a time complexity of O(n), which is suitable given the problem constraints.
