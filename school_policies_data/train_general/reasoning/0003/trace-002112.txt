To solve this problem, we need to convert a list of page numbers into an abbreviated format where consecutive pages are represented as a range (e.g., 1-3) and non-consecutive pages are listed individually. This conversion helps in saving space and adhering to citation formatting guidelines.

### Approach
1. **Reading Input**: The input consists of multiple datasets. Each dataset starts with an integer `n` indicating the number of pages, followed by a line of `n` sorted integers. The input ends when `n` is 0.
2. **Grouping Consecutive Pages**: For each dataset, iterate through the list of pages and group consecutive pages. For example, pages 1, 2, 3, 5, 6 will be grouped into [1, 2, 3] and [5, 6].
3. **Formatting Groups**: Convert each group into the required string format. If a group has a single page, it remains as is. If it has consecutive pages, it is formatted as "start-end".
4. **Output the Result**: Combine all formatted groups into a single string separated by spaces and print the result for each dataset.

### Solution Code
```python
import sys

def process_pages(pages):
    if not pages:
        return ""
    groups = []
    current_group = [pages[0]]
    for page in pages[1:]:
        if page == current_group[-1] + 1:
            current_group.append(page)
        else:
            groups.append(current_group)
            current_group = [page]
    groups.append(current_group)
    
    parts = []
    for group in groups:
        if len(group) == 1:
            parts.append(str(group[0]))
        else:
            parts.append(f"{group[0]}-{group[-1]}")
    return ' '.join(parts)

def main():
    lines = [line.strip() for line in sys.stdin if line.strip()]
    idx = 0
    while idx < len(lines):
        n = int(lines[idx])
        if n == 0:
            break
        idx += 1
        pages = list(map(int, lines[idx].split()))
        idx += 1
        output = process_pages(pages)
        print(output)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read line by line. Each dataset is processed until `n` is 0, which signals the end of input.
2. **Grouping Pages**: The pages are grouped by checking if each subsequent page is consecutive. If it is, it is added to the current group; otherwise, the current group is closed and a new group starts.
3. **Formatting Groups**: Each group is formatted based on its length. Single-page groups are converted to strings directly, while multi-page groups use hyphen notation.
4. **Output**: The formatted groups are joined into a single string and printed for each dataset.

This approach efficiently processes each dataset and ensures the correct abbreviated format is used, adhering to the problem constraints and requirements.
