### Approach
1. **Dynamic Programming Arrays**: We use two arrays, `l0` and `l1`, where `l0[i]` represents the maximum length of a substring starting at index `i` that can form an unstable string starting with '0'. Similarly, `l1[i]` represents the maximum length starting with '1'.
2. **Compute Valid Lengths**: We iterate from the end of the string to the beginning to fill these arrays. For each position, we check if the current character can match the required pattern and extend the valid length based on the next position's values.
3. **Sum Valid Lengths**: Sum all values in `l0` and `l1` to get the total number of valid substrings assuming each substring can be counted twice if it can form both patterns.
4. **Adjust for Overcounting**: Subtract the count of substrings consisting entirely of '?' since these are counted twice in the initial sum but should be counted once.

### Solution Code
```python
def count_beautiful_substrings(s):
    n = len(s)
    l0 = [0] * n
    l1 = [0] * n
    
    for j in reversed(range(n)):
        # Compute l0[j]
        if s[j] in ('0', '?'):
            if j + 1 < n:
                l0[j] = 1 + l1[j+1]
            else:
                l0[j] = 1
        else:
            l0[j] = 0
        
        # Compute l1[j]
        if s[j] in ('1', '?'):
            if j + 1 < n:
                l1[j] = 1 + l0[j+1]
            else:
                l1[j] = 1
        else:
            l1[j] = 0
    
    sum_total = sum(l0) + sum(l1)
    
    # Calculate the number of all-? substrings
    count_q = 0
    current = 0
    for c in s:
        if c == '?':
            current += 1
        else:
            if current > 0:
                count_q += current * (current + 1) // 2
                current = 0
    if current > 0:
        count_q += current * (current + 1) // 2
    
    return sum_total - count_q

t = int(input())
for _ in range(t):
    s = input().strip()
    print(count_beautiful_substrings(s))
```

### Explanation
1. **Dynamic Programming Arrays**: `l0` and `l1` are computed by checking each character from the end of the string. If the current character can match the required pattern (either '0' or '1'), we extend the valid length using the next position's values.
2. **Summing Valid Lengths**: The sum of `l0` and `l1` gives the total valid substrings assuming each all-'?' substring is counted twice.
3. **Adjusting Overcounts**: By subtracting the count of all-'?' substrings, we correct the overcounting, ensuring each valid substring is counted exactly once.

This approach efficiently computes the result in linear time, making it suitable for large input sizes.
