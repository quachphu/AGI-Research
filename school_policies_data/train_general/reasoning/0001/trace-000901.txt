To solve this problem, we need to determine the ship class based on a given class ID. The class ID can be either uppercase or lowercase, and we need to map it to the corresponding ship class name using a predefined table.

### Approach
1. **Input Reading**: Read the number of test cases, followed by the class IDs for each test case.
2. **Mapping**: Use a dictionary to map each valid class ID (case-insensitive) to its corresponding ship class name.
3. **Case Insensitivity**: Convert each input character to lowercase to handle both uppercase and lowercase inputs uniformly.
4. **Output**: For each test case, look up the ship class name using the converted character and print the result.

### Solution Code
```python
def main():
    ship_class = {
        'b': 'BattleShip',
        'c': 'Cruiser',
        'd': 'Destroyer',
        'f': 'Frigate'
    }
    t = int(input())
    for _ in range(t):
        line = input().strip().lower()
        print(ship_class[line[0]])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Dictionary Setup**: The dictionary `ship_class` maps lowercase keys (class IDs) to their respective ship class names.
2. **Reading Input**: The first input line is the number of test cases `t`. For each test case, we read a line, strip any whitespace, convert it to lowercase, and take the first character.
3. **Lookup and Output**: For each processed class ID, we use the dictionary to find the corresponding ship class name and print it.

This approach efficiently handles up to 1000 test cases with constant time complexity for each lookup, ensuring optimal performance.
