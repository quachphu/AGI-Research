To solve this problem, we need to determine the scores of two players, AltF4 and CtrlF4, who take turns selecting numbers from a matrix to maximize their respective scores. The score of a player is the sum of all elements in the submatrix defined by the rows and columns they have selected. The players play optimally, with AltF4 starting first.

### Approach
1. **Problem Analysis**: The key insight is that each player's score is determined by the sum of elements in the submatrix defined by the numbers they select. The optimal strategy involves selecting numbers in such a way that maximizes their own score while minimizing the opponent's score.

2. **Optimal Selection Strategy**: The optimal strategy for both players is to select the numbers (rows/columns) in descending order of their diagonal values. This is because the diagonal values are guaranteed to contribute to their score, and selecting higher diagonal values first maximizes their immediate gain.

3. **Implementation Steps**:
   - Read the input matrices.
   - For each matrix, create a list of tuples containing the diagonal value and its 1-based index.
   - Sort this list in descending order based on the diagonal values.
   - Distribute the sorted numbers alternately between AltF4 and CtrlF4.
   - Calculate the scores for each player based on their selected indices.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr +=1
    for _ in range(T):
        N = int(input[ptr])
        ptr +=1
        matrix = []
        for _ in range(N):
            row = list(map(int, input[ptr:ptr+N]))
            ptr += N
            matrix.append(row)
        # Create list of (diagonal value, 1-based index)
        diag = [(matrix[i][i], i+1) for i in range(N)]
        # Sort in descending order of diagonal value
        diag.sort(reverse=True, key=lambda x: x[0])
        # Split into Alt and Ctrl sets
        alt_indices = [t[1]-1 for t in diag[::2]]  # Convert to 0-based
        ctrl_indices = [t[1]-1 for t in diag[1::2]]
        # Calculate scores
        sum_alt = sum(matrix[i][j] for i in alt_indices for j in alt_indices)
        sum_ctrl = sum(matrix[i][j] for i in ctrl_indices for j in ctrl_indices)
        print(sum_alt, sum_ctrl)

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints. The matrices are parsed from the input string.

2. **Diagonal Values and Sorting**: For each matrix, we extract the diagonal values along with their 1-based indices. These values are sorted in descending order to prioritize higher values.

3. **Distributing Indices**: The sorted indices are alternately assigned to AltF4 and CtrlF4. AltF4 gets the first, third, fifth, etc., indices, while CtrlF4 gets the second, fourth, sixth, etc.

4. **Calculating Scores**: The scores are computed by summing all elements in the submatrix defined by each player's selected indices. This is done using nested loops to iterate over all pairs of indices for each player.
