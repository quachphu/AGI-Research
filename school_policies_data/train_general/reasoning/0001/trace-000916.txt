To solve this problem, we need to determine the minimum number of fake accounts Vasya needs to create in order to have a higher score than Petya in a Codeforces round with dynamic problem scoring. The dynamic scoring adjusts the maximum points for each problem based on the ratio of participants who solved the problem to the total number of participants.

### Approach
1. **Understand the Dynamic Scoring**: The maximum points for each problem depend on the ratio of solvers to total participants. The scoring tiers are as follows:
   - 500 points if the ratio is > 1/2
   - 1000 points if the ratio is > 1/4 and ≤ 1/2
   - 1500 points if the ratio is > 1/8 and ≤ 1/4
   - 2000 points if the ratio is > 1/16 and ≤ 1/8
   - 2500 points if the ratio is > 1/32 and ≤ 1/16
   - 3000 points if the ratio is ≤ 1/32

2. **Determine Optimal Fake Accounts Usage**: For each problem, Vasya can influence the maximum points by submitting solutions from fake accounts. The goal is to adjust the number of solvers (by submitting correct solutions) and the total participants to maximize Vasya's score and minimize Petya's score.

3. **Iterate Over Possible Fake Accounts**: Check each possible number of fake accounts (k) starting from 0. For each k, compute the maximum points for each problem, then calculate Vasya's and Petya's scores. If Vasya's score exceeds Petya's, return the current k.
