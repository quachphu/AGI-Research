To solve this problem, we need to determine if a given string consisting of 'T' and 'M' characters can be partitioned into one or more disjoint subsequences each equal to "TMT". Each character must be part of exactly one subsequence.

### Approach
1. **Check Counts**: The number of 'T' characters must be exactly twice the number of 'M' characters. If not, the answer is immediately "NO".
2. **Collect Indices**: Track the indices of 'T' and 'M' characters in separate lists.
3. **Validate Subsequence Structure**: For each 'M' in the string, ensure there is a 'T' before it and a 'T' after it. This is done by splitting the list of 'T' indices into two parts: the first half (for the initial 'T' in each "TMT") and the second half (for the trailing 'T' in each "TMT"). Each 'M' must be positioned between corresponding indices from these two parts.

### Solution Code
```python
import sys

def solve():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        s = sys.stdin.readline().strip()
        count_T = s.count('T')
        count_M = s.count('M')
        if count_T != 2 * count_M:
            print("NO")
            continue
        # Collect indices of Ts and Ms
        t_indices = []
        m_indices = []
        for i, char in enumerate(s):
            if char == 'T':
                t_indices.append(i)
            elif char == 'M':
                m_indices.append(i)
        m = count_M
        if len(t_indices) != 2 * m:
            print("NO")
            continue
        first_ts = t_indices[:m]
        third_ts = t_indices[m:]
        valid = True
        for i in range(m):
            if first_ts[i] >= m_indices[i] or third_ts[i] <= m_indices[i]:
                valid = False
                break
        print("YES" if valid else "NO")

solve()
```

### Explanation
1. **Count Check**: The first step ensures the ratio of 'T' to 'M' is exactly 2:1, a necessary condition for forming valid "TMT" subsequences.
2. **Index Collection**: By collecting indices of 'T' and 'M', we can efficiently verify the positions required for each subsequence.
3. **Validation**: For each 'M', we check if there is a 'T' before it (from the first half of 'T' indices) and a 'T' after it (from the second half of 'T' indices). If any 'M' fails this check, the answer is "NO".

This approach ensures we efficiently validate each condition in linear time relative to the input size, making it suitable for large input constraints.
