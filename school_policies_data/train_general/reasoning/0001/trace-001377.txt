To solve this problem, we need to determine a non-zero integer \( d \) such that after dividing each element of the array by \( d \), the number of positive numbers in the resulting array is at least half the size of the original array (rounded up). If no such \( d \) exists, we should return 0.

### Approach
1. **Understand the Requirement**: We need at least \( \lceil n/2 \rceil \) positive numbers after dividing each element by \( d \).
2. **Key Insight**: The number of positive elements after division depends on the sign of \( d \):
   - If \( d \) is positive, the count of positive numbers is the same as the number of positive elements in the original array.
   - If \( d \) is negative, the count of positive numbers is the same as the number of negative elements in the original array.
3. **Count Positives and Negatives**: Calculate the number of positive and negative elements in the array.
4. **Check Threshold**: Determine if either count of positive or negative elements meets the required threshold. If so, return any \( d \) with the corresponding sign (1 for positive, -1 for negative). If neither meets the threshold, return 0.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
threshold = (n + 1) // 2

count_pos = 0
count_neg = 0
for num in a:
    if num > 0:
        count_pos += 1
    elif num < 0:
        count_neg += 1

if count_pos >= threshold:
    print(1)
elif count_neg >= threshold:
    print(-1)
else:
    print(0)
```

### Explanation
1. **Input Reading**: The code reads the number of elements \( n \) and the array \( a \).
2. **Threshold Calculation**: The threshold \( \lceil n/2 \rceil \) is calculated using integer arithmetic as \( (n + 1) // 2 \).
3. **Counting Elements**: The code counts how many positive and negative elements are present in the array.
4. **Decision Making**: 
   - If the count of positive elements meets or exceeds the threshold, print 1 (any positive \( d \) works).
   - If the count of negative elements meets or exceeds the threshold, print -1 (any negative \( d \) works).
   - If neither count meets the threshold, print 0.

This approach efficiently determines the correct \( d \) by leveraging the properties of division and the sign of numbers, ensuring optimal performance given the constraints.
