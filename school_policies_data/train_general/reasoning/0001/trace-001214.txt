To solve this problem, we need to split a given number of coins into two piles such that each pile has exactly half of the coins, and the difference between the sums of the weights of the coins in each pile is minimized. The coins have weights that are powers of 2 starting from 2^1 up to 2^n, where n is an even number.

### Approach
The key insight is to recognize that the minimal difference can be derived from a mathematical pattern. The optimal way to split the coins is to take the largest coin and combine it with the smallest n/2 - 1 coins. This approach ensures the minimal possible difference between the sums of the two piles.

The formula to compute the minimal difference is derived as follows:
1. The largest coin, which is 2^n, is placed in one pile.
2. The smallest n/2 - 1 coins (2^1, 2^2, ..., 2^{n/2 - 1}) are added to this pile.
3. The sum of these coins forms one pile, and the remaining coins form the other pile.
4. The difference between the sums of these two piles can be computed using the formula: 2^{(n/2 + 1)} - 2.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    for i in range(1, t + 1):
        n = int(input[i])
        res = (2 ** ((n // 2) + 1)) - 2
        print(res)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The input is read all at once and split into a list of strings. The first element is the number of test cases.
2. **Processing Each Test Case:** For each test case, the value of n is read. Using the derived formula, the minimal difference is calculated as 2 raised to the power of (n/2 + 1) minus 2.
3. **Output the Result:** The result for each test case is printed immediately after computation.

This approach efficiently computes the minimal difference using a direct mathematical formula, ensuring optimal performance even for the upper constraint of n = 30. The time complexity is O(1) per test case due to the formula-based computation, making the solution very efficient.
