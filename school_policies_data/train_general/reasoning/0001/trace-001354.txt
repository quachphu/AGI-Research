To solve this problem, we need to find the number of semi-common multiples of a given sequence of even numbers between 1 and a given integer M. A semi-common multiple is defined as a positive integer X that can be expressed as \(a_k \times (p + 0.5)\) for each element \(a_k\) in the sequence, where p is a non-negative integer.

### Approach
1. **Transform the Sequence**: Convert each element \(a_k\) in the sequence to \(b_k = a_k / 2\). This transformation allows us to work with integers and simplifies the problem.
2. **Compute the Least Common Multiple (LCM)**: Calculate the LCM of all transformed elements \(b_k\). This LCM will be the smallest number that is a multiple of each \(b_k\).
3. **Check Validity**: Ensure that the LCM divided by each \(b_k\) results in an odd number. If any division results in an even number, there are no valid semi-common multiples, and the result is 0.
4. **Count Valid Multiples**: Determine how many odd multiples of the LCM exist within the range from 1 to M. This count gives the number of valid semi-common multiples.

### Solution Code
```python
import sys
import math

def main():
    from math import gcd
    input = sys.stdin.read().split()
    n = int(input[0])
    m = int(input[1])
    a = list(map(int, input[2:2+n]))
    b = [x // 2 for x in a]
    
    # Compute LCM of all elements in b
    current_lcm = 1
    for num in b:
        g = gcd(current_lcm, num)
        current_lcm = (current_lcm // g) * num
        if current_lcm > m:
            print(0)
            return
    
    # Check if all (current_lcm // num) are odd
    for num in b:
        if (current_lcm // num) % 2 == 0:
            print(0)
            return
    
    max_t = m // current_lcm
    if max_t == 0:
        print(0)
    else:
        ans = (max_t + 1) // 2
        print(ans)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Transformation**: Each element \(a_k\) is divided by 2 to form \(b_k\). This allows us to work with integers and simplifies the problem to finding common multiples of these transformed values.
2. **LCM Calculation**: The LCM of all \(b_k\) values is computed. If this LCM exceeds M at any point, the result is immediately 0 because no multiple of the LCM can be within the range [1, M].
3. **Validity Check**: For each \(b_k\), the quotient of the LCM divided by \(b_k\) must be odd. If any quotient is even, the result is 0 because it violates the semi-common multiple condition.
4. **Counting Multiples**: The valid multiples of the LCM within the range [1, M] are counted. Only odd multiples of the LCM are valid, so the count is determined by the number of odd integers up to the maximum possible multiple of the LCM within M.

This approach efficiently handles the constraints and ensures correctness by leveraging properties of LCM and parity checks.
