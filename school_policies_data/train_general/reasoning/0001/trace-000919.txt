To solve this problem, we need to determine the maximum number of elements in a "pretty set" of positions in a given string. A pretty set is defined by two conditions: all elements in the set must be distinct lowercase letters, and there must be no uppercase letters between any two positions in the set.

### Approach
1. **Segmentation by Uppercase Letters**: The string is divided into segments of contiguous lowercase letters, separated by uppercase letters. Each segment is a candidate for forming a pretty set.
2. **Count Distinct Characters**: For each segment, compute the number of distinct lowercase letters. This count represents the maximum possible size of a pretty set within that segment.
3. **Determine Maximum Count**: The answer is the maximum count of distinct lowercase letters across all segments.

### Solution Code
```python
n = int(input())
s = input().strip()

segments = []
current = []

for c in s:
    if c.islower():
        current.append(c)
    else:
        if current:
            segments.append(current)
            current = []
# Add the last segment if any
if current:
    segments.append(current)

max_unique = 0
for seg in segments:
    unique = len(set(seg))
    if unique > max_unique:
        max_unique = unique

print(max_unique)
```

### Explanation
1. **Segmentation**: The code iterates through the string, collecting contiguous lowercase letters into segments. Whenever an uppercase letter is encountered, the current segment is closed and added to the list of segments if it is non-empty.
2. **Distinct Characters Count**: For each segment, the number of unique lowercase letters is determined using a set, which automatically handles duplicates.
3. **Result Calculation**: The maximum number of unique characters from all segments is computed and printed as the result.

This approach efficiently handles the constraints by focusing on segments between uppercase letters, ensuring optimal performance and correctness.
