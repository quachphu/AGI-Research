To solve this problem, we need to split a given string into substrings such that each substring adheres to specific length constraints based on the characters it contains. The solution involves three main tasks: counting the number of valid splits, determining the maximum length of any valid substring, and finding the minimum number of substrings required.

### Approach

1. **Understanding Constraints**: Each character in the string has a maximum allowed length for the substring it can be part of. For a substring to be valid, its length must not exceed the minimum of these maximum allowed lengths for all characters in the substring.

2. **Dynamic Programming (DP) for Counting Valid Splits**: Use a DP array to count the number of ways to split the string up to each position. For each position, consider all valid substrings ending at that position and sum up the ways to form those splits.

3. **Maximum Valid Substring Length**: Precompute the maximum length of valid substrings ending at each position by checking the minimum allowed length for each possible substring length.

4. **Minimum Number of Substrings**: Use another DP array to track the minimum number of substrings needed to split the string up to each position by considering all valid substrings ending at that position.
