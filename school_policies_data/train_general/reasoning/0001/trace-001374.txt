To solve this problem, we need to compute a QuadNumber from a given set of contiguous hexadecimal digits. The QuadNumber is derived by combining the upper and lower halves of each hexadecimal digit, converting them into binary numbers, summing these numbers, and then returning the result in binary format while ignoring any carry beyond the specified length.

### Approach
1. **Parse Input**: Read the number of hexadecimal digits and the digits themselves.
2. **Convert Hex to Binary**: For each hexadecimal digit, convert it to a 4-bit binary string.
3. **Extract Halves**: Split each 4-bit binary string into upper (first two bits) and lower (last two bits) halves.
4. **Form Numbers**: Construct two binary numbers (N1 and N2) from the upper and lower halves respectively. This is done incrementally to avoid handling large strings directly.
5. **Sum and Modulo**: Compute the sum of N1 and N2, then take modulo \(2^{2N}\) to ignore any carry beyond the required length.
6. **Format Result**: Convert the result to a binary string and ensure it is padded to the correct length with leading zeros if necessary.

### Solution Code
```python
n = int(input())
quads = input().strip()

n1 = 0
n2 = 0

for c in quads:
    val = int(c, 16)
    upper = (val >> 2) & 0b11  # Extract upper two bits (B1 and B2)
    lower = val & 0b11          # Extract lower two bits (B3 and B4)
    
    n1 = (n1 << 2) | upper      # Shift left and add new upper bits
    n2 = (n2 << 2) | lower      # Shift left and add new lower bits

mod = 1 << (2 * n)
sum_val = (n1 + n2) % mod       # Compute sum and ignore carry beyond 2n bits

binary = bin(sum_val)[2:]        # Convert to binary without '0b' prefix
result = binary.zfill(2 * n)    # Pad with leading zeros to ensure correct length

print(result)
```

### Explanation
1. **Reading Input**: The input is read as two lines, where the first line gives the number of hexadecimal digits, and the second line provides the digits themselves.
2. **Hexadecimal to Binary Conversion**: Each hexadecimal digit is converted to a 4-bit binary string. This ensures we handle each digit correctly.
3. **Extracting Halves**: For each digit, the upper half (first two bits) and lower half (last two bits) are extracted using bitwise operations.
4. **Incremental Construction**: Instead of building large binary strings, we incrementally construct the integers N1 and N2 by shifting and combining the extracted bits.
5. **Sum and Modulo**: The sum of N1 and N2 is computed, and modulo operation is used to discard any carry beyond the required length.
6. **Formatting the Result**: The result is converted to a binary string and padded with leading zeros to ensure it matches the required length, which is twice the number of hexadecimal digits.

This approach efficiently handles large inputs by avoiding the creation of large intermediate strings and directly working with integer operations, which are optimized in Python.
