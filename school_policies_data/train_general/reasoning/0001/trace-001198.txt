To solve this problem, we need to determine the number of rooms in a condominium that remain lit after a series of actions that turn off the lights in specific patterns. The condominium is structured as a series of cubes, each with a varying number of floors, rows, and columns. The actions target columns, rows, or floors across these cubes, and we need to efficiently compute the number of rooms affected by these actions.

### Approach
1. **Understanding the Condominium Structure**: Each cube has a number of floors, rows, and columns equal to its position in the row (i.e., the i-th cube has i floors, each with i rows and i columns).
2. **Action Types**:
   - **Type 0**: Turn off all rooms in the k-th column from the west.
   - **Type 1**: Turn off all rooms in the k-th row from the south.
   - **Type 2**: Turn off all rooms on the k-th floor.
3. **Efficient Calculation**:
   - **Precompute Prefix Sums**: To quickly calculate the sum of squares up to any number, which helps in determining the number of rooms affected by floor actions (Type 2).
   - **Cube Identification**: For each column and row action, determine the cube that contains the k-th column or row using binary search.
   - **Inclusion-Exclusion Principle**: Use this principle to efficiently compute the number of rooms affected by multiple actions without double-counting.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    
    ptr = 0
    n = int(data[ptr])
    ptr += 1
    m = int(data[ptr])
    ptr += 1

    # Precompute prefix sums of squares
    prefix_sum_sq = [0] * (n + 1)
    for i in range(1, n + 1):
        prefix_sum_sq[i] = prefix_sum_sq[i - 1] + i * i

    s_max = n * (n + 1) // 2

    count_type0 = {}
    count_type1 = {}
    S2 = []

    for _ in range(m):
        q = int(data[ptr])
        ptr += 1
        k = int(data[ptr])
        ptr += 1

        if q == 0:
            if k > s_max:
                continue
            # Find cube i for column k
            low = 1
            high = n
            i = None
            while low <= high:
                mid = (low + high) // 2
                s_mid = mid * (mid + 1) // 2
                s_mid_prev = (mid - 1) * mid // 2 if mid > 1 else 0
                if s_mid_prev < k <= s_mid:
                    i = mid
                    break
                elif s_mid < k:
                    low = mid + 1
                else:
                    high = mid - 1
            if i is not None and i <= n:
                count_type0[i] = count_type0.get(i, 0) + 1

        elif q == 1:
            if k > s_max:
                continue
            # Find cube i for row k (same as column)
            low = 1
            high = n
            i = None
            while low <= high:
                mid = (low + high) // 2
                s_mid = mid * (mid + 1) // 2
                s_mid_prev = (mid - 1) * mid // 2 if mid > 1 else 0
                if s_mid_prev < k <= s_mid:
                    i = mid
                        break
                elif s_mid < k:
                    low = mid + 1
                else:
                    high = mid - 1
            if i is not None and i <= n:
                count_type1[i] = count_type1.get(i, 0) + 1

        elif q == 2:
            if k <= n:
                S2.append(k)

    # Process type 2 actions
    S2_sorted = sorted(S2)
    count_type2 = [0] * (n + 1)  # count_type2[i] is the number of type2 actions with k <= i
    for i in range(1, n + 1):
        cnt = bisect.bisect_right(S2_sorted, i)
        count_type2[i] = cnt

    # Compute A, B, C
    A = sum(count_type0[i] * i * i for i in count_type0)
    B = sum(count_type1[i] * i * i for i in count_type1)
    C = 0
    for k in S2_sorted:
        if k > n:
            continue
        C += (prefix_sum_sq[n] - prefix_sum_sq[k - 1])

    # Compute AB, AC, BC, ABC
    AB = 0
    AC = 0
    BC = 0
    ABC = 0
    for i in range(1, n + 1):
        a = count_type0.get(i, 0)
        b = count_type1.get(i, 0)
        c = count_type2[i]
        AB += a * b * i
        AC += a * c * i
        BC += b * c * i
        ABC += a * b * c

    total = A + B + C - AB - AC - BC + ABC

    initial_total = 0
    for i in range(1, n + 1):
        initial_total += i * i * i

    answer = initial_total - total
    print(answer)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prefix Sums**: Precompute the sum of squares to quickly determine the number of rooms affected by floor actions.
2. **Cube Identification**: Use binary search to determine which cube contains a specific column or row for Type 0 and Type 1 actions.
3. **Inclusion-Exclusion Principle**: Efficiently compute the overlap between different types of actions to avoid double-counting rooms, ensuring accurate calculation of the total number of rooms turned off.

This approach efficiently handles the constraints and ensures that we correctly account for all rooms affected by the actions, providing the correct count of rooms that remain lit.
