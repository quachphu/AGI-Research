To solve this problem, we need to determine the number of different walls Heidi can build using up to `n` bricks and a wall width of `C`. The solution involves combinatorial mathematics and modular arithmetic to efficiently compute the result under given constraints.

### Approach
1. **Problem Analysis**: The problem reduces to finding the number of ways to distribute `k` bricks (where `1 ≤ k ≤ n`) across `C` columns. Each column can have a non-negative number of bricks, and the order of columns matters. This is a classic combinatorial problem that can be solved using the "stars and bars" theorem.

2. **Combinatorial Insight**: The number of ways to distribute `k` bricks into `C` columns is given by the binomial coefficient `C(k + C - 1, C - 1)`. Summing this for all `k` from 1 to `n` gives the total number of walls. Using combinatorial identities, this sum simplifies to `C(n + C, C) - 1`.

3. **Modulo Arithmetic**: Since the result must be computed modulo `10^6 + 3` (a prime number), we use precomputed factorials and their modular inverses to efficiently compute binomial coefficients using modular arithmetic.

4. **Precomputation**: Precompute factorials and their modular inverses up to the maximum possible value of `n + C` (700,000) to allow efficient computation of binomial coefficients.

### Solution Code
```python
MOD = 10**6 + 3

n, C = map(int, input().split())
k = n + C

# Precompute factorial and inverse factorial up to k
max_fact = k
fact = [1] * (max_fact + 1)
for i in range(1, max_fact + 1):
    fact[i] = fact[i-1] * i % MOD

inv_fact = [1] * (max_fact + 1)
inv_fact[max_fact] = pow(fact[max_fact], MOD - 2, MOD)
for i in range(max_fact - 1, -1, -1):
    inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

# Calculate combination(k, C) mod MOD
comb = fact[k] * inv_fact[C] % MOD
comb = comb * inv_fact[k - C] % MOD

result = (comb - 1) % MOD
print(result)
```

### Explanation
1. **Precomputation of Factorials**: We precompute the factorials and their modular inverses up to `k = n + C` using modular arithmetic. This allows us to efficiently compute binomial coefficients using the formula `C(n, k) = n! / (k! * (n - k)!)`.

2. **Modular Inverses**: Using Fermat's Little Theorem, the modular inverse of a number modulo a prime can be computed as `a^(p-2) mod p`. This is used to precompute the inverses of factorials.

3. **Binomial Coefficient Calculation**: For each input, we compute the binomial coefficient `C(n + C, C) % MOD` using the precomputed factorials and their inverses. Subtracting 1 (to exclude the case of zero bricks) and taking modulo `10^6 + 3` gives the final result.

This approach efficiently handles the constraints and ensures the solution is computed in optimal time using precomputation and modular arithmetic.
