To solve this problem, we need to determine the ghost who wins the "Consistency Trophy" each day based on the number of "Ghost of the Day" titles they have won and their age. The trophy is awarded to the ghost with the most titles, and in case of a tie, the oldest ghost is chosen.

### Approach
1. **Track Counts**: Use a dictionary to keep track of how many times each ghost has won the "Ghost of the Day" title.
2. **Current Maximum Count**: Maintain a variable to track the highest number of titles any ghost has won so far.
3. **Max Age for Current Max Count**: Track the oldest ghost among those with the highest count of titles.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    N = int(input[0])
    M = int(input[1])
    ages = list(map(int, input[2:2 + N]))
    
    count_dict = {}
    current_max_count = 0
    max_age = 0
    
    for age in ages:
        prev_count = count_dict.get(age, 0)
        new_count = prev_count + 1
        count_dict[age] = new_count
        
        if prev_count == current_max_count:
            current_max_count = new_count
            max_age = age
        else:
            if new_count == current_max_count:
                if age > max_age:
                    max_age = age
        
        print(max_age, current_max_count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Dictionary for Counts**: `count_dict` keeps track of how many times each ghost has won the title. This allows O(1) access and update operations.
3. **Updating Maximum Count**: Each time a ghost's count is incremented, we check if this ghost was part of the group with the previous maximum count. If so, the current maximum count is updated.
4. **Tracking Oldest Ghost**: For each new maximum count, the oldest ghost (highest age) in that group is tracked. If a new ghost joins the current maximum count group and is older, the oldest age is updated.

This approach ensures that each day's processing is done in O(1) time, making the solution efficient and suitable for large input sizes up to 100,000 days.
