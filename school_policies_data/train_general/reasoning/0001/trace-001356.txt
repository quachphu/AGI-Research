To solve this problem, we need to find the length of the longest substring in a given string that consists exclusively of the characters 'A', 'C', 'G', and 'T'. These characters are referred to as ACGT characters. The solution involves iterating through the string while tracking the current length of consecutive valid characters and updating the maximum length found so far.

### Approach
1. **Initialize Variables**: We start by initializing two variables, `max_len` and `current_len`, both set to 0. `max_len` will keep track of the longest valid substring found, while `current_len` will track the length of the current valid substring as we iterate through the string.
2. **Iterate Through Characters**: For each character in the input string, check if it is one of the valid ACGT characters.
3. **Update Current Length**: If the character is valid, increment `current_len`. If `current_len` exceeds `max_len`, update `max_len` to the value of `current_len`.
4. **Reset Current Length**: If the character is not valid, reset `current_len` to 0.
5. **Output Result**: After processing all characters, `max_len` will hold the length of the longest valid substring, which is then printed.

### Solution Code
```python
def main():
    s = input().strip()
    max_len = 0
    current_len = 0
    valid_chars = {'A', 'C', 'G', 'T'}
    for c in s:
        if c in valid_chars:
            current_len += 1
            if current_len > max_len:
                max_len = current_len
        else:
            current_len = 0
    print(max_len)

main()
```

### Explanation
- **Reading Input**: The input string is read and stripped of any leading or trailing whitespace.
- **Valid Character Check**: A set `valid_chars` is used to efficiently check if a character is one of 'A', 'C', 'G', or 'T'.
- **Tracking Lengths**: As we iterate through each character, we either increment the current valid substring length or reset it if an invalid character is encountered. The maximum length encountered during this iteration is continuously updated.
- **Efficiency**: The algorithm runs in O(n) time complexity, where n is the length of the input string, making it efficient even for the maximum constraint of 10 characters.

This approach ensures that we efficiently find the longest valid ACGT substring by maintaining a running count of valid characters and resetting the count when an invalid character is encountered. This method guarantees an optimal solution with linear time complexity.
