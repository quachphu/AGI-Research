To solve this problem, we need to create a frequency distribution of student heights based on predefined intervals. Each interval (or class) spans 5 cm, and we need to count how many students fall into each class. The result is then displayed using asterisks (*) for each student in the class.

### Approach
1. **Input Reading**: Read the number of students and their respective heights.
2. **Class Initialization**: Initialize a list to keep track of the count of students in each of the 6 classes.
3. **Classification**: For each height, determine which class it belongs to and update the count for that class.
4. **Output Generation**: For each class, generate a string with the class number followed by asterisks corresponding to the count of students in that class. If a class has zero students, only the class number is displayed.

### Solution Code
```python
def process_heights():
    import sys
    n = int(sys.stdin.readline())
    counts = [0] * 6
    for _ in range(n):
        h = float(sys.stdin.readline().strip())
        if h < 165.0:
            counts[0] += 1
        elif h < 170.0:
            counts[1] += 1
        elif h < 175.0:
            counts[2] += 1
        elif h < 180.0:
            counts[3] += 1
        elif h < 185.0:
            counts[4] += 1
        else:
            counts[5] += 1
    for i in range(6):
        line = f"{i + 1}:"
        if counts[i] > 0:
            line += "*" * counts[i]
        print(line)

process_heights()
```

### Explanation
1. **Reading Input**: The function reads the number of students `n` and then reads each student's height.
2. **Classifying Heights**: Each height is checked against the intervals to determine which class it belongs to. The intervals are:
   - Class 1: Less than 165.0 cm
   - Class 2: 165.0 cm to less than 170.0 cm
   - Class 3: 170.0 cm to less than 175.0 cm
   - Class 4: 175.0 cm to less than 180.0 cm
   - Class 5: 180.0 cm to less than 185.0 cm
   - Class 6: 185.0 cm and above
3. **Generating Output**: For each class, the count is converted to asterisks. If a class has zero students, only the class number is printed without any asterisks.

This approach ensures that each height is efficiently classified into the correct interval, and the results are displayed in the required format.
