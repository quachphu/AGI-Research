To solve this problem, we need to compute the sum of a geometric series where each term is generated by multiplying the previous term by a given integer \( a \). The series is summed up to the \( n \)-th term. 

### Approach
The problem can be efficiently solved using the formula for the sum of a geometric series. The key steps are:
1. **Identify the Series**: The series is \( a, a^2, a^3, \ldots, a^n \).
2. **Sum Formula**: The sum of the first \( n \) terms of a geometric series where the first term is \( a \) and the common ratio is \( a \) can be computed using the formula:
   \[
   S = \frac{a(a^n - 1)}{a - 1} \quad \text{if} \quad a \neq 1
   \]
   If \( a = 1 \), the sum is simply \( n \) because each term is 1 and there are \( n \) terms.

### Solution Code
```python
a = int(input())
n = int(input())

if a == 1:
    print(n)
else:
    print(a * (a ** n - 1) // (a - 1))
```

### Explanation
1. **Reading Input**: The code reads two integers, \( a \) (the initial number of pathogens) and \( n \) (the number of days).
2. **Special Case for \( a = 1 \)**: If \( a \) is 1, the sum of \( n \) terms each being 1 is simply \( n \).
3. **Geometric Series Sum**: For \( a \neq 1 \), the formula \(\frac{a(a^n - 1)}{a - 1}\) is used. This formula efficiently computes the sum without iterating through each term, which is crucial for handling large values of \( n \) efficiently.

This approach ensures that the solution is both optimal and easy to understand, leveraging mathematical properties to avoid unnecessary computations.
