To solve this problem, we need to determine if an equation remains valid after removing all zeros from the numbers involved. Specifically, given two positive integers \( a \) and \( b \), we compute their sum \( c \) and check if the equation holds true when all zeros are removed from \( a \), \( b \), and \( c \).

### Approach
1. **Read Input:** Read the integers \( a \) and \( b \) from the input.
2. **Compute Sum:** Calculate \( c \) as the sum of \( a \) and \( b \).
3. **Remove Zeros:** Create a helper function to remove all zeros from a number by converting it to a string, stripping out zeros, and converting it back to an integer.
4. **Check Validity:** Check if the sum of the zero-removed versions of \( a \) and \( b \) equals the zero-removed version of \( c \).

### Solution Code
```python
def remove_zero(n):
    return int(str(n).replace('0', ''))

a = int(input())
b = int(input())
c = a + b

a_removed = remove_zero(a)
b_removed = remove_zero(b)
c_removed = remove_zero(c)

if a_removed + b_removed == c_removed:
    print("YES")
else:
    print("NO")
```

### Explanation
1. **Reading Input:** The integers \( a \) and \( b \) are read from standard input.
2. **Computing Sum:** The sum \( c \) is straightforwardly calculated as \( a + b \).
3. **Removing Zeros:** The helper function `remove_zero` converts each number to a string, removes all '0' characters, and converts the result back to an integer. This handles leading, trailing, and intermediate zeros efficiently.
4. **Validation Check:** After removing zeros from \( a \), \( b \), and \( c \), we check if the sum of the modified \( a \) and \( b \) equals the modified \( c \). If they match, the equation is still valid, and we print "YES"; otherwise, we print "NO".

This approach ensures that we correctly handle all edge cases where zeros might be present in different positions within the numbers, providing an efficient and accurate solution.
