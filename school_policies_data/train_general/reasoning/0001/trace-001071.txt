To solve this problem, we need to determine the earliest operation after which an array transformed by a series of rotations matches a target array. The solution involves efficiently tracking the rotations using an offset and checking for a match using the Knuth-Morris-Pratt (KMP) algorithm to find the required rotation offset.

### Approach

1. **Identify the Rotation Offset**: Use the KMP algorithm to find the number of left rotations needed to transform the initial array into the target array. This is done by concatenating the initial array with itself and searching for the target array within this concatenated array.

2. **Track Effective Rotations**: Instead of performing actual array rotations, track the net effect of rotations using an offset. Each left rotation increases the offset, while each right rotation decreases it. This offset is kept modulo the array length to handle wraparounds.

3. **Check for Match**: After each operation, check if the current offset matches the precomputed rotation offset needed to reach the target array. If a match is found, return the operation's ID.

### Solution Code

```python
import sys

def compute_lps(pattern):
    n = len(pattern)
    lps = [0] * n
    length = 0  # Length of the previous longest prefix suffix
    i = 1
    while i < n:
        if pattern[i] == pattern[length]:
            length += 1
            lps[i] = length
            i += 1
        else:
            if length != 0:
                length = lps[length - 1]
            else:
                lps[i] = 0
                i += 1
    return lps

def find_k(initial, target):
    n = len(initial)
    concatenated = initial + initial
    lps = compute_lps(target)
    i = 0  # Index for concatenated array
    j = 0  # Index for target array
    while i < len(concatenated):
        if target[j] == concatenated[i]:
            i += 1
            j += 1
            if j == n:
                # Found the match starting at i - j
                return i - j
        else:
            if j != 0:
                j = lps[j - 1]
            else:
                i += 1
    return -1  # Should not happen as per problem constraints

def main():
    input = sys.stdin.read().split()
    ptr = 0
    N, M = int(input[ptr]), int(input[ptr + 1])
    ptr += 2
    A = list(map(int, input[ptr:ptr + N]))
    ptr += N
    T = list(map(int, input[ptr:ptr + N]))
    ptr += N
    K = find_k(A, T)
    current_offset = 0
    result = -1
    for op_id in range(1, M + 1):
        op = input[ptr]
        X = int(input[ptr + 1])
        ptr += 2
        if op == 'L':
            current_offset += X
        else:
            current_offset -= X
        current_offset %= N  # Ensure it's within [0, N-1]
        if current_offset == K:
            result = op_id
            break
    print(result)

if __name__ == "__main__":
    main()
```

### Explanation

1. **KMP Algorithm**: The KMP algorithm is used to efficiently find the starting index of the target array within the concatenation of the initial array with itself. This index gives the number of left rotations needed to transform the initial array into the target array.

2. **Offset Tracking**: Instead of rotating the array, we track the net rotation effect using an offset. This offset is adjusted with each operation (left rotations increase it, right rotations decrease it) and kept modulo the array length to handle wraparound.

3. **Efficiency**: The approach ensures that we do not perform actual rotations, which would be inefficient for large arrays. By using modular arithmetic and the KMP algorithm, we achieve an efficient solution with time complexity O(N + M), suitable for large inputs.
