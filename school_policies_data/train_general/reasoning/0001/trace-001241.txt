To solve this problem, we need to determine the maximum consistent sum of cricket ratings over a period of matches, considering only if the sum is positive. If the maximum sum is not positive, we should output 0. The solution involves using Kadane's algorithm to efficiently find the maximum subarray sum.

### Approach
1. **Read Input**: Read the number of matches and the corresponding ratings.
2. **Edge Case Handling**: If there are no matches, immediately output 0.
3. **Kadane's Algorithm**: This algorithm efficiently computes the maximum sum of any contiguous subarray in linear time.
4. **Check Positivity**: After computing the maximum subarray sum, ensure the result is non-negative. If it's negative, output 0 instead.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    if not input:
        print(0)
        return
    n = int(input[0])
    if n == 0:
        print(0)
        return
    ratings = list(map(int, input[1:n+1]))
    max_current = max_global = ratings[0]
    for num in ratings[1:]:
        max_current = max(num, max_current + num)
        if max_current > max_global:
            max_global = max_current
    print(max(max_global, 0))

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings. This helps in efficiently handling large input sizes.
2. **Edge Case Handling**: If there are no matches (n=0), the output is immediately 0.
3. **Kadane's Algorithm**: This algorithm iterates through the list of ratings while maintaining two variables: `max_current` (the maximum sum ending at the current position) and `max_global` (the overall maximum sum found so far). For each element, it decides whether to start a new subarray or extend the previous one.
4. **Output Handling**: After computing the maximum subarray sum, the result is checked to ensure it is non-negative. If the maximum sum is negative, 0 is printed instead.

This approach ensures that we efficiently compute the required result in linear time, making it suitable for large input sizes up to 100,000 elements.
