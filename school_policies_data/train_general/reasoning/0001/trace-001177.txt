To solve this problem, we need to determine the number of admissible integer temperatures within a given range for each query. A temperature is considered admissible if it is recommended by at least `k` coffee recipes. The solution involves efficiently preprocessing the data to answer multiple range queries quickly.

### Approach
1. **Difference Array Technique**: Use a difference array to efficiently compute the frequency of each temperature being covered by the recipes. This allows us to increment and decrement ranges in constant time.
2. **Prefix Sum Array**: Convert the difference array into a frequency array using a prefix sum. This helps in determining how many recipes recommend each temperature.
3. **Admissible Temperatures Check**: Create a binary array where each entry indicates if the corresponding temperature is admissible (1 if it meets or exceeds the threshold `k`, 0 otherwise).
4. **Prefix Sum of Admissible Temperatures**: Construct a prefix sum array from the binary array to quickly compute the number of admissible temperatures within any given range.

### Solution Code
```python
import sys

def main():
    data = sys.stdin.read().split()
    ptr = 0
    n, k, q = map(int, data[ptr:ptr+3])
    ptr += 3
    
    delta = [0] * (200002)  # 0 to 200001
    
    for _ in range(n):
        l = int(data[ptr])
        r = int(data[ptr + 1])
        ptr += 2
        delta[l] += 1
        delta[r + 1] -= 1
    
    # Compute frequency array
    freq = [0] * (200001)  # 1-based to 200000
    current = 0
    for t in range(1, 200001):
        current += delta[t]
        freq[t] = current
    
    # Compute is_admissible array
    is_admissible = [0] * (200001)
    for t in range(1, 200001):
        is_admissible[t] = 1 if freq[t] >= k else 0
    
    # Compute prefix sum array for is_admissible
    pre_sum = [0] * (200001)
    for t in range(1, 200001):
        pre_sum[t] = pre_sum[t - 1] + is_admissible[t]
    
    # Process queries
    for _ in range(q):
        a = int(data[ptr])
        b = int(data[ptr + 1])
        ptr += 2
        result = pre_sum[b] - pre_sum[a - 1]
        print(result)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the large constraints.
2. **Difference Array Initialization**: The difference array `delta` is used to mark the start and end of each recipe's temperature range.
3. **Frequency Calculation**: The frequency array is built by applying the prefix sum on the difference array, which gives the count of recipes covering each temperature.
4. **Admissible Check**: Convert the frequency array into a binary array where each entry is 1 if the temperature is admissible (frequency ≥ k).
5. **Prefix Sum for Queries**: The prefix sum of the binary array allows us to quickly compute the number of admissible temperatures in any range using simple arithmetic.

This approach ensures that preprocessing is done in linear time, and each query is answered in constant time, making the solution efficient and scalable for large inputs.
