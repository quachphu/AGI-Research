To solve this problem, we need to determine if a given social network is "reasonable" based on specific conditions. The network is considered reasonable if, for every three distinct members X, Y, Z, if X is friends with Y and Y is friends with Z, then X must also be friends with Z. This implies that each connected component in the network must be a complete graph (clique).

### Approach
1. **Graph Representation**: Represent the social network as an adjacency list where each node points to its friends.
2. **Connected Components Identification**: Use BFS to traverse and identify all connected components in the graph.
3. **Clique Check**: For each connected component, check if it forms a clique. This is done by verifying that the sum of the degrees of all nodes in the component equals \( k \times (k - 1) \), where \( k \) is the size of the component. This ensures that every node in the component is connected to every other node.

### Solution Code
```python
import sys
from collections import deque

def main():
    n, m = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n + 1)]  # Using lists instead of sets for faster iteration
    for _ in range(m):
        a, b = map(int, sys.stdin.readline().split())
        adj[a].append(b)
        adj[b].append(a)
    
    visited = [False] * (n + 1)
    
    for u in range(1, n + 1):
        if not visited[u]:
            q = deque([u])
            visited[u] = True
            component_size = 0
            sum_degree = 0
            while q:
                node = q.popleft()
                component_size += 1
                sum_degree += len(adj[node])
                for v in adj[node]:
                    if not visited[v]:
                        visited[v] = True
                        q.append(v)
            if sum_degree != component_size * (component_size - 1):
                print("NO")
                return
    print("YES")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Graph Representation**: The adjacency list `adj` is built using lists to store neighbors for each node, which allows efficient iteration over neighbors.
2. **BFS for Connected Components**: For each unvisited node, a BFS is initiated to explore the entire connected component. During BFS, we track the size of the component and the sum of degrees of all nodes in the component.
3. **Clique Validation**: After identifying a component, we check if the sum of degrees of all nodes in the component equals \( k \times (k - 1) \), where \( k \) is the component size. This check ensures that every node in the component is connected to every other node, forming a clique. If any component fails this check, the network is deemed unreasonable, and we print "NO". If all components pass, we print "YES".

This approach efficiently handles the constraints by ensuring each component is checked in linear time relative to the size of the component, making it suitable for large input sizes.
