To solve this problem, we need to determine the minimal number of additional snow drifts required to ensure that Bajtek can travel from any snow drift to any other using his movement rules. The key insight is to model the problem using graph theory, where each snow drift is a node, and edges exist between nodes if they are in the same row or column. The solution involves finding the number of connected components in this graph and then determining the minimal number of edges (additional snow drifts) needed to connect all components.

### Approach
1. **Graph Representation**: Represent each snow drift as a node. Two nodes are connected by an edge if they are in the same row or column.
2. **Union-Find Data Structure**: Use the Union-Find (Disjoint Set Union, DSU) data structure to efficiently manage and merge connected components.
3. **Count Components**: After processing all pairs of nodes to form connections based on shared rows or columns, count the number of connected components.
4. **Calculate Result**: The minimal number of additional snow drifts needed is the number of connected components minus one.

### Solution Code
```python
class DSU:
    def __init__(self, size):
        self.parent = list(range(size))
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root != y_root:
            self.parent[y_root] = x_root

n = int(input())
points = []
for _ in range(n):
    x, y = map(int, input().split())
    points.append((x, y))

dsu = DSU(n)
for i in range(n):
    for j in range(i + 1, n):
        if points[i][0] == points[j][0] or points[i][1] == points[j][1]:
            dsu.union(i, j)

roots = set()
for i in range(n):
    roots.add(dsu.find(i))

print(len(roots) - 1)
```

### Explanation
1. **Graph Representation**: Each snow drift is treated as a node. If two nodes are in the same row or column, they are connected by an edge.
2. **Union-Find**: This data structure helps efficiently manage the merging of sets (connected components). The `find` method uses path compression for efficiency, and the `union` method merges two sets.
3. **Processing Pairs**: For each pair of snow drifts, check if they are in the same row or column. If they are, merge their sets in the Union-Find structure.
4. **Counting Components**: After processing all pairs, determine the number of unique connected components by finding the unique root parents for each node.
5. **Result Calculation**: The minimal number of additional snow drifts needed is the number of connected components minus one, as each additional drift can connect two components, reducing the total number by one each time.

This approach efficiently determines the solution using graph theory and the Union-Find data structure, ensuring optimal performance even for the upper limits of input constraints.
