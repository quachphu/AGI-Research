To solve this problem, we need to determine the minimum time Devu will take to learn all subjects, considering that his learning power decreases by 1 hour per chapter for each subsequent subject, but never goes below 1 hour. The optimal approach involves sorting the subjects in ascending order based on the number of chapters and then calculating the total time using the adjusted learning power for each subject.

### Approach
1. **Sort the Subjects**: To minimize the total time, we should teach subjects with fewer chapters first when Devu's learning power is higher. This is because larger chapters will be taught later when the learning power is lower, thus reducing the overall time spent.
2. **Calculate Time for Each Subject**: For each subject in the sorted list, compute the time required using the formula `max(x - i, 1)`, where `i` is the index of the subject in the sorted list. This ensures that the learning power does not drop below 1 hour per chapter.

### Solution Code
```python
def main():
    import sys
    n, x = map(int, sys.stdin.readline().split())
    c = list(map(int, sys.stdin.readline().split()))
    c.sort()
    total = 0
    for i in range(n):
        total += c[i] * max(x - i, 1)
    print(total)

main()
```

### Explanation
1. **Reading Input**: The input consists of two integers `n` (number of subjects) and `x` (initial learning power), followed by a list of integers representing the number of chapters in each subject.
2. **Sorting**: The list of chapters is sorted in ascending order to ensure that subjects with fewer chapters are taught first.
3. **Time Calculation**: For each subject in the sorted list, the time is calculated using the formula `max(x - i, 1)`, where `i` is the index of the subject. This formula ensures that the learning power decreases by 1 for each subsequent subject but never goes below 1.
4. **Summing Up**: The total time is accumulated by summing the product of the number of chapters and the adjusted learning power for each subject.

This approach ensures that we minimize the total time by leveraging the higher learning power for subjects with fewer chapters and adjusting the learning power appropriately for subsequent subjects.
