To solve this problem, we need to determine if a rectangular matrix can be constructed such that each row contains exactly `a` ones and each column contains exactly `b` ones. If such a matrix exists, we must print it; otherwise, we print "NO".

### Approach
1. **Check Validity Condition**: The first step is to check if the total number of ones from rows (`n * a`) equals the total number of ones from columns (`m * b`). If they are not equal, it's impossible to construct such a matrix, and we immediately return "NO".
2. **Construct Matrix**: If the validity condition is met, we proceed to construct the matrix. Each row starts placing `a` consecutive ones at a position determined by `(i * a) % m`, where `i` is the row index. This cyclic approach ensures that the ones are distributed as evenly as possible across the columns.
3. **Verify Column Counts**: After constructing the matrix, we verify that each column contains exactly `b` ones. If any column fails this check, we output "NO"; otherwise, we print the matrix.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, m, a, b = map(int, input().split())
    if n * a != m * b:
        print("NO")
    else:
        matrix = [[0] * m for _ in range(n)]
        for i in range(n):
            start = (i * a) % m
            for j in range(a):
                col = (start + j) % m
                matrix[i][col] = 1
        # Check columns
        valid = True
        for c in range(m):
            cnt = sum(matrix[r][c] for r in range(n))
            if cnt != b:
                valid = False
                break
        if not valid:
            print("NO")
        else:
            print("YES")
            for row in matrix:
                print(''.join(map(str, row)))
```

### Explanation
1. **Validity Check**: The condition `n * a == m * b` ensures that the total number of ones required by the rows matches the total number of ones required by the columns.
2. **Matrix Construction**: For each row `i`, we start placing `a` ones at the position `(i * a) % m`. This cyclic placement ensures that the ones are spread out evenly across the columns, which helps in meeting the column constraints.
3. **Column Verification**: After constructing the matrix, we check each column to ensure it contains exactly `b` ones. If any column fails this check, the matrix is invalid.

This approach efficiently constructs and verifies the matrix, ensuring that all constraints are met if possible. The cyclic placement of ones helps in distributing the ones uniformly, making the solution both effective and efficient.
