To solve this problem, we need to determine the minimum number of seconds required to make an array non-decreasing by selectively adding powers of 2 to its elements. Each second corresponds to a bit position, and the goal is to use the fewest seconds (highest bit position) necessary.

### Approach
1. **Problem Analysis**: The challenge is to make the array non-decreasing by adding values of the form \(2^{x-1}\) during the x-th second. The key insight is to process each bit position from the highest (30th) to the lowest (0th) and determine if it's necessary to add that bit to certain elements to maintain a non-decreasing order.

2. **Greedy Check**: For each bit position, check if the array can be made non-decreasing by allowing increments up to \(2^b - 1\) (sum of all lower bits). If not, that bit must be added to some elements.

3. **Update Array**: If a bit is required, update the array by adding \(2^b\) to necessary elements to maintain non-decreasing order.

4. **Result Calculation**: Track the highest bit required and compute the minimum seconds as the highest bit position + 1.

def solve():
