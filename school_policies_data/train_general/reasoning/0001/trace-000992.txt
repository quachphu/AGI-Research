To solve this problem, we need to determine the minimum number of edge reversals required to create a path from vertex 1 to vertex N in a directed graph. The approach involves modeling the problem as a shortest path problem in a modified graph where each edge can be traversed in its original direction with a cost of 0 or reversed with a cost of 1. 

### Approach
1. **Graph Representation**: For each directed edge from vertex u to v, we consider two possibilities:
   - Traverse the edge in its original direction (from u to v) with a cost of 0.
   - Reverse the edge (from v to u) with a cost of 1.
   
2. **0-1 BFS Algorithm**: This algorithm efficiently finds the shortest path in a graph where edge weights are either 0 or 1. We use a deque (double-ended queue) to process nodes such that nodes reachable with a cost of 0 are processed before those with a cost of 1, ensuring the shortest path is found efficiently.

### Solution Code
```python
import sys
from collections import deque

def main():
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    M = int(input[idx])
    idx += 1
    adj = [[] for _ in range(N + 1)]
    for _ in range(M):
        u = int(input[idx])
        idx += 1
        v = int(input[idx])
        idx += 1
        adj[u].append((v, 0))
        adj[v].append((u, 1))
    
    distance = [float('inf')] * (N + 1)
    distance[1] = 0
    dq = deque([1])
    
    while dq:
        u = dq.popleft()
        for (v, c) in adj[u]:
            if distance[u] + c < distance[v]:
                distance[v] = distance[u] + c
                if c == 0:
                    dq.appendleft(v)
                else:
                    dq.append(v)
    
    print(distance[N] if distance[N] != float('inf') else -1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Input Reading**: The input is read in one go for efficiency, especially given the constraints. The graph is represented using an adjacency list where each entry includes the target vertex and the cost (0 or 1).

2. **Initialization**: The distance array is initialized with infinity to represent the minimum cost to reach each vertex, starting with vertex 1 having a cost of 0.

3. **0-1 BFS Execution**: Using a deque, nodes are processed in order of their distance. Nodes reachable with a cost of 0 are added to the front of the deque, while those requiring a cost of 1 are added to the back. This ensures that nodes are processed in the order of increasing cost, guaranteeing the shortest path is found efficiently.

4. **Result Determination**: After processing all nodes, the minimum cost to reach vertex N is checked. If it remains infinity, it means vertex N is unreachable, and we output -1. Otherwise, the minimum cost is printed.

This approach efficiently handles the constraints and ensures optimal performance using the 0-1 BFS algorithm, making it suitable for large graphs with up to 100,000 vertices and edges.
