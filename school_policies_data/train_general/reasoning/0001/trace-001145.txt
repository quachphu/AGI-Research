To solve this problem, we need to find the largest binary number with exactly N digits that has a Hamming distance of D from a given binary number X. The Hamming distance is the number of positions at which the corresponding bits are different.

### Approach
1. **Understanding the Problem**: The goal is to maximize the resulting binary number by flipping bits in X such that the Hamming distance from X is exactly D. To maximize the number, we should prefer flipping 0s to 1s (as this increases the value) and flip 1s to 0s only when necessary (to minimize the reduction in value).

2. **Strategy**:
   - **Flip 0s to 1s**: Start by flipping the leftmost 0s to 1s until we reach the required Hamming distance D or run out of 0s.
   - **Flip 1s to 0s**: If after flipping all possible 0s we still need more flips, flip the rightmost 1s to 0s. This minimizes the impact on the value of the binary number.

3. **Steps**:
   - Convert the input binary string into a list of characters for easy manipulation.
   - Identify positions of all 0s and flip the leftmost ones up to D flips.
   - If additional flips are needed, flip the rightmost 1s to 0s.

### Solution Code
```python
def main():
    n = int(input())
    x = input().strip()
    d = int(input())
    bits = list(x)
    zero_positions = [i for i, c in enumerate(bits) if c == '0']
    flip_zeros = min(d, len(zero_positions))
    
    for i in zero_positions[:flip_zeros]:
        bits[i] = '1'
    
    remaining = d - flip_zeros
    if remaining > 0:
        one_positions = [i for i, c in enumerate(x) if c == '1']
        one_positions.sort(reverse=True)
        for i in one_positions[:remaining]:
            bits[i] = '0'
    
    print(''.join(bits))

main()
```

### Explanation
- **Reading Input**: The code reads the input values for N (number of bits), X (binary string), and D (Hamming distance).
- **Flipping 0s**: The code first flips the leftmost 0s to 1s until the required Hamming distance D is met or all 0s are flipped.
- **Flipping 1s**: If there are remaining flips needed after flipping all 0s, the code flips the rightmost 1s to 0s to meet the exact Hamming distance requirement while minimizing the reduction in the binary number's value.
- **Output**: The resulting binary string is printed, which is the largest possible number with the required Hamming distance from X.

This approach ensures that the binary number is maximized by prioritizing the flipping of 0s to 1s and only flipping 1s to 0s when necessary, thus efficiently achieving the desired Hamming distance.
