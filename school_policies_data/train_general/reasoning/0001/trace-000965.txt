### Approach
1. **Problem Analysis**: The problem requires transforming the initial array into the target array using adjacent swaps. The key insight is to build the target array step-by-step from left to right. For each position in the target array, we find the corresponding element in the initial array and move it to its correct position using adjacent swaps.

2. **Algorithm**:
   - **Initialization**: Copy the initial array to a working array to keep track of the current state as we perform swaps.
   - **Iterate through each position**: For each position in the target array, find the corresponding element in the current working array starting from the current position. Once found, move this element to its correct position by swapping it leftwards with adjacent elements.
   - **Track Swaps**: Record each swap made during the process.

3. **Complexity**: The algorithm runs in O(n^2) time complexity, which is efficient given the problem constraints (n ≤ 300). Each element may require up to O(n) swaps to reach its correct position.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

current = b.copy()

    # Find the position j >= i where current[j] matches a[i]
    j = i
    while j < n and current[j] != a[i]:
        j += 1
    # Move the element from j to i by swapping leftwards
    for k in range(j, i, -1):
        # Swap positions k-1 and k (0-based) which is k and k+1 in 1-based
        current[k-1], current[k] = current[k], current[k-1]
```

- **Copy Initial Array**: A copy of the initial array is made to track the current state as swaps are performed.
- **Iterate Through Positions**: For each position `i` in the target array, find the element `a[i]` in the current array starting from index `i`. Once found, this element is moved to position `i` by swapping it leftwards with adjacent elements.
- **Record Swaps**: Each swap is recorded in a list, which is printed at the end.
