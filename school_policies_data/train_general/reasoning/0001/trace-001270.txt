To solve this problem, we need to determine the number of even substrings in a given string of digits. A substring is considered even if it ends with an even digit (2, 4, 6, or 8). The key insight is that any substring ending in an even digit is itself even, regardless of the preceding digits.

### Approach
1. **Identify Even Digits**: Iterate through each character in the string and check if it is an even digit.
2. **Count Substrings**: For each even digit found at position `i` (0-based index), the number of valid substrings ending at this position is `i + 1` (since the substring can start at any position from 0 to `i`).

### Solution Code
```python
n = int(input())
s = input().strip()
total = 0
for i in range(n):
    if int(s[i]) % 2 == 0:
        total += (i + 1)
print(total)
```

### Explanation
1. **Reading Input**: The code reads the input values, which include the length of the string and the string itself.
2. **Iterate Through String**: For each character in the string, we check if it is an even digit.
3. **Count Valid Substrings**: If the character is an even digit, we add `i + 1` to the total count of even substrings. This is because each position `i` (0-based) can form `i + 1` substrings ending at that position (from start index 0 to `i`).
4. **Output Result**: Finally, the total count of even substrings is printed.

This approach efficiently counts all valid even substrings in linear time, making it suitable even for the upper constraint of the input size (n ≤ 65000).
