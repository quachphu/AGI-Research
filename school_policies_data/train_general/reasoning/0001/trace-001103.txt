To solve this problem, we need to find the length of the longest good sequence from a given list of integers. A good sequence is defined as a strictly increasing sequence where no two adjacent elements are coprime, and all elements are from the given list.

### Approach
1. **Precompute Smallest Prime Factors (SPF):** We first precompute the smallest prime factor for every number up to the maximum possible value (100,000) using a sieve method. This helps in efficiently factorizing each number into its prime factors.
2. **Dynamic Programming with Prime Tracking:** For each number in the input list, we determine the maximum length of any good sequence ending with that number. This is done by checking the prime factors of the current number and using previously computed results for those primes.
3. **Update Prime Maximums:** For each prime factor of the current number, we update the maximum sequence length associated with that prime factor to the current number's sequence length if it is larger.

### Solution Code
```python
import sys
from sys import stdin
from collections import defaultdict

def main():
    # Precompute smallest prime factors (SPF) up to 1e5
    max_a = 10**5
    spf = list(range(max_a + 1))
    for i in range(2, int(max_a**0.5) + 1):
        if spf[i] == i:  # i is a prime
            for j in range(i * i, max_a + 1, i):
                if spf[j] == j:
                    spf[j] = i

    # Read input
    n = int(stdin.readline())
    a_list = list(map(int, stdin.readline().split()))

    prime_max = defaultdict(int)
    max_length = 0

    for a in a_list:
        if a == 1:
            primes = set()
        else:
            primes = set()
            current = a
            while current != 1:
                p = spf[current]
                primes.add(p)
                while current % p == 0:
                    current //= p

        if not primes:
            current_dp = 1
        else:
            max_prev = 0
            for p in primes:
                if prime_max[p] > max_prev:
                    max_prev = prime_max[p]
            current_dp = max_prev + 1

        for p in primes:
            if current_dp > prime_max[p]:
                prime_max[p] = current_dp

        if current_dp > max_length:
            max_length = current_dp

    print(max_length)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Precompute SPF:** This step uses a sieve algorithm to determine the smallest prime factor for each number up to 100,000. This allows efficient factorization of any number by repeatedly dividing by its smallest prime factor.
2. **Dynamic Programming:** For each number in the input list, we factorize it into its prime factors. Using these primes, we determine the longest sequence that can end at the current number by checking the maximum sequence lengths associated with each prime factor. The current number's sequence length is then set to this maximum value plus one.
3. **Update Prime Maximums:** After determining the sequence length for the current number, we update the maximum sequence length for each of its prime factors to ensure future numbers can use this information efficiently.

This approach ensures that we efficiently compute the longest good sequence in linear time relative to the number of elements, making it suitable for large input sizes up to 100,000.
