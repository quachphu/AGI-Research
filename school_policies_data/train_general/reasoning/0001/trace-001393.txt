To solve this problem, we need to determine the minimum possible difficulty of a rock climbing track after removing one hold. The difficulty is defined as the maximum difference between consecutive holds. The first and last holds must remain in place.

### Approach
1. **Input Reading**: Read the number of holds and their respective heights.
2. **Iterate Over Possible Removals**: For each hold that can be removed (excluding the first and last), generate a new sequence of holds by excluding the current hold.
3. **Calculate Maximum Difference**: For each new sequence, compute the maximum difference between consecutive holds.
4. **Track Minimum Difficulty**: Keep track of the minimum difficulty encountered across all possible hold removals.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
min_diff = float('inf')

for i in range(1, n-1):
    new_a = a[:i] + a[i+1:]
    current_max = 0
    for j in range(len(new_a) - 1):
        diff = new_a[j+1] - new_a[j]
        if diff > current_max:
            current_max = diff
    if current_max < min_diff:
        min_diff = current_max

print(min_diff)
```

### Explanation
1. **Input Reading**: The number of holds `n` and their heights are read from standard input.
2. **Iterate Over Removable Holds**: Using a loop, we consider each hold from the second to the second-last (indices 1 to n-2 in 0-based indexing) for removal.
3. **Generate New Sequence**: For each hold removed, a new sequence is formed by concatenating the part of the array before the removed hold and the part after.
4. **Compute Differences**: For each new sequence, compute the differences between consecutive holds and track the maximum difference.
5. **Track Minimum Difficulty**: Update the minimum difficulty encountered after evaluating all possible removals.

This approach ensures that we efficiently check all possible removals and compute the resulting difficulties, leading to the optimal solution. The complexity is O(n^2), which is feasible given the problem constraints (n ≤ 100).
