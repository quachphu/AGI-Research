To solve this problem, we need to determine if there exists a non-leap year where the first day of a certain month is a given day of the week, and the first day of the next month is another given day of the week. 

### Approach
1. **Understanding the Problem**: The problem revolves around the Gregorian calendar's non-leap year months, where each month has a fixed number of days. The key insight is that the first day of the next month can be determined by the number of days in the current month modulo 7 (since there are 7 days in a week).

2. **Key Insight**: For each consecutive pair of months, the number of days in the first month modulo 7 determines the offset needed to transition from the first day of the current month to the first day of the next month.

3. **Algorithm**:
   - Convert the input day names into numerical values (0 for Monday, 1 for Tuesday, ..., 6 for Sunday).
   - For each consecutive pair of months, compute the number of days in the first month modulo 7.
   - Check if transitioning from the first day of the current month (given day) to the first day of the next month (another given day) is possible using the computed offset.

### Solution Code
```python
days_order = {
    'monday': 0,
    'tuesday': 1,
    'wednesday': 2,
    'thursday': 3,
    'friday': 4,
    'saturday': 5,
    'sunday': 6
}

day1 = input().strip()
day2 = input().strip()

d1 = days_order[day1]
d2 = days_order[day2]

month_days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]

possible = False
for i in range(11):
    delta = month_days[i] % 7
    if (d1 + delta) % 7 == d2:
        possible = True
        break

print("YES" if possible else "NO")
```

### Explanation
1. **Input Conversion**: The input days are converted into numerical values using a dictionary for easier arithmetic operations.
2. **Days Calculation**: The number of days in each month of a non-leap year is predefined. For each month (except December), we compute the number of days modulo 7 to determine the offset needed to transition to the next month.
3. **Check Transitions**: For each consecutive month pair, we check if adding the offset (days modulo 7) to the first day results in the second day. If such a transition exists, the answer is "YES"; otherwise, it is "NO".

This approach efficiently checks all possible transitions between consecutive months in linear time, ensuring the solution is both optimal and easy to understand.
