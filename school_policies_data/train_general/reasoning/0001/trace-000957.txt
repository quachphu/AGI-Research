The first line contains a single integer t — the number of test cases (1 ≤ t ≤ 100). The test cases follow, each in two lines.

Output

For each test case print "YES", if it is possible to reorder the elements of the array in such a way that the given formula gives the given value, and "NO" otherwise.

Example

Input


2

4 4
0 1 2 3


Output


YES
NO

Note

In the first test case one of the reorders could be [1, 2, 5]. The sum is equal to (1/1 + 2/2 + 5/3) + (2/2 + 5/3) + (5/3) = 8. The brackets denote the inner sum ∑_{j=i}^{n}{(a_j)/(j)}, while the summation of brackets corresponds to the sum over i.

To solve this problem, we need to determine if we can reorder the elements of an array such that a specific sum formula equals a given integer \( m \). The key insight is that the sum formula simplifies to the sum of the array elements, regardless of their order. This allows us to check directly if the sum of the array elements equals \( m \).

### Approach
1. **Understanding the Sum Formula**: The given formula can be simplified by analyzing how each element contributes to the sum. Each element \( a_j \) appears in the sum \( j \) times (once for each \( i \) from 1 to \( j \)), but each occurrence is divided by \( j \). This results in each element contributing exactly \( a_j \) to the total sum, making the total sum equal to the sum of the array elements.
2. **Check Sum**: For each test case, compute the sum of the array elements and check if it equals \( m \).

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    total = sum(a)
    print("YES" if total == m else "NO")
```

### Explanation
1. **Reading Input**: The input consists of multiple test cases. For each test case, we first read the integers \( n \) (number of elements) and \( m \) (target sum).
2. **Sum Calculation**: We compute the sum of the array elements.
3. **Comparison**: We check if the computed sum equals \( m \). If it does, we print "YES"; otherwise, we print "NO".

This approach efficiently solves the problem with a time complexity of \( O(t \cdot n) \), where \( t \) is the number of test cases and \( n \) is the number of elements in the array for each test case. This is optimal given the problem constraints.
