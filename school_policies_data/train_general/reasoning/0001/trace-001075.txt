To solve this problem, we need to determine the minimum number of bricks to break such that the remaining bricks form a sequence of consecutive integers starting from 1. If it's impossible to form such a sequence, we should return `-1`.

### Approach
The key insight is to identify the longest valid subsequence that starts with 1 and increments by 1 for each subsequent element. By finding the maximum length (K) of such a subsequence, we can compute the minimum number of bricks to break as \(N - K\). If no valid subsequence exists, we return `-1`.

1. **Initialization**: Start with the target value `current_target` set to 1.
2. **Iterate through the bricks**: For each brick, check if it matches the `current_target`. If it does, increment the `current_target` to look for the next consecutive integer.
3. **Determine the result**: After processing all bricks, the length of the longest valid subsequence is `current_target - 1`. If this length is at least 1, the answer is \(N - (current_target - 1)\). Otherwise, return `-1`.

This approach efficiently processes each brick exactly once, resulting in a time complexity of \(O(N)\), which is optimal for the given constraints.

### Solution Code
```python
n, *rest = map(int, open(0).read().split())
a = rest[:n] if rest else []

current = 1
for num in a:
    if num == current:
        current += 1

k = current - 1
if k == 0:
    print(-1)
else:
    print(n - k)
```

### Explanation
1. **Reading Input**: The input is read and parsed into a list of integers representing the values on the bricks.
2. **Tracking Target Values**: We iterate through each brick value, updating the `current_target` whenever we encounter the current target value. This helps us track the longest valid subsequence.
3. **Calculating Result**: After processing all bricks, we determine the length of the valid subsequence. If the length is non-zero, the minimum number of bricks to break is calculated as \(N - K\). If no valid subsequence is found (K is 0), we return `-1`.

This solution efficiently finds the optimal result by leveraging a greedy approach to track the longest valid subsequence, ensuring optimal performance for large input sizes.
