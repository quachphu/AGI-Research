To solve this problem, we need to determine the minimum number of moves required to make two buildings of given heights equal. Each move can either add a floor to the shorter building or remove a floor from the taller one.

### Approach
1. **Understanding the Problem**: The minimum number of moves required to equalize the heights of two buildings is simply the absolute difference between their heights. This is because each move can either increase or decrease the height by 1, so the total moves needed is the difference in heights.
2. **Efficient Input Handling**: Given the constraints where the number of test cases can be up to \(10^5\) and each height can be as large as \(10^{18}\), we need to read input efficiently. Using `sys.stdin.read()` allows us to read all input at once, which is faster than reading line by line.
3. **Processing Input**: After reading all input data, split it into individual tokens. The first token is the number of test cases, followed by pairs of integers representing the heights of the buildings.
4. **Computing Results**: For each pair of heights, compute the absolute difference and store the results. Finally, print all results joined by newlines.

### Solution Code
```python
import sys

def main():
    data = sys.stdin.read().split()
    T = int(data[0])
    results = []
    index = 1
    for _ in range(T):
        N = int(data[index])
        M = int(data[index + 1])
        results.append(abs(N - M))
        index += 2
    print('\n'.join(map(str, results)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once using `sys.stdin.read()`, which splits the input into a list of strings. This method is efficient for handling large input sizes.
2. **Processing Each Test Case**: The number of test cases `T` is read first. For each test case, the heights `N` and `M` are read, and their absolute difference is computed. This difference is the minimum number of moves required.
3. **Storing and Printing Results**: The results for all test cases are stored in a list and printed at once to avoid repeated I/O operations, which enhances performance.

This approach ensures that we handle up to \(10^5\) test cases efficiently, even with the maximum constraints, by minimizing the overhead of input/output operations.
