The solution involves using a greedy approach with a priority queue (min-heap) to always select the smallest possible next node that can be reached from the current nodes.

### Approach
1. **Graph Representation**: Represent the park as an adjacency list. Each node will have a list of its neighbors.
2. **Priority Queue**: Use a min-heap to always select the smallest available node next. This ensures that we explore nodes in lexicographically smallest order.
3. **Deduplication and Sorting**: To optimize the heap operations, deduplicate and sort the adjacency list for each node. This reduces redundant entries in the heap and ensures efficient processing.
4. **Traversal**: Start from node 1, mark it as visited, and use the min-heap to process nodes. For each node, add its neighbors to the heap, ensuring we always pick the smallest next node.
