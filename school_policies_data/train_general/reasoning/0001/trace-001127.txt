The password must be exactly N characters long, using K distinct characters from a special language, with each character used at most once. The solution requires computing permutations of K characters taken N at a time, modulo \(10^9 + 7\).

### Approach
1. **Understand the Problem Requirements**: The password must be of length N using K distinct characters, each used exactly once. This translates to finding the number of permutations of K characters taken N at a time.
2. **Mathematical Insight**: The number of permutations (P(K, N)) is calculated as \(K \times (K-1) \times (K-2) \times \ldots \times (K-N+1)\). This product can be computed efficiently using a loop.
3. **Modulo Operation**: Since the result can be very large, we use modulo \(10^9 + 7\) at each step to prevent overflow and ensure the result fits within standard integer limits.

### Solution Code
```python
MOD = 10**9 + 7

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N = int(input[idx])
        K = int(input[idx + 1])
        idx += 2
        res = 1
        for i in range(N):
            res = res * (K - i) % MOD
        print(res)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints. The input is split into a list of strings which are then processed sequentially.
2. **Loop Through Test Cases**: For each test case, read N and K values.
3. **Compute Permutations**: Initialize the result to 1. Iterate N times, multiplying the result by (K - i) at each step and taking modulo \(10^9 + 7\) to keep the number manageable.
4. **Output Result**: Print the computed result for each test case.

This approach ensures that we efficiently compute the required permutations using a loop that runs in O(N) time for each test case, making it suitable even for the upper constraints. The modulo operation at each step ensures no overflow and adheres to the problem's requirement for the result to be modulo \(10^9 + 7\).
