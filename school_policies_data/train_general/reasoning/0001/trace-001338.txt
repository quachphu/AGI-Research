To solve this problem, we need to determine the minimum cost for Vladik to travel from his home airport to the olympiad venue airport, considering the companies each airport belongs to and the associated flight costs.

### Approach
1. **Immediate Check for Same Airport**: If the starting and ending airports are the same, the cost is zero.
2. **Check for Same Company**: If the starting and ending airports belong to the same company, the cost is zero.
3. **Collect and Sort Airports by Company**: Separate the airports into two lists based on their company affiliations and sort them for efficient processing.
4. **Calculate Possible Costs**:
   - **Direct Flight Cost**: The cost if Vladik flies directly from the start to the end airport.
   - **Closest Airport in Destination Company**: The minimum cost to fly from the start airport to the closest airport in the destination company.
   - **Closest Airport in Start Company**: The minimum cost to fly from the closest airport in the start company to the end airport.
   - **Minimum Distance Between Companies**: The minimum distance between any airport in the start company and any airport in the destination company.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = int(input[1])
    b = int(input[2])
    s = input[3]
    
    if a == b:
        print(0)
        return
    
    a_company = s[a-1]
    b_company = s[b-1]
    
    if a_company == b_company:
        print(0)
        return
    
    # Collect airports in each company
    A = [i+1 for i in range(n) if s[i] == a_company]
    B = [i+1 for i in range(n) if s[i] == b_company]
    
    A.sort()
    B.sort()
    
    cost0 = abs(a - b)
    
    # Compute cost1: minimal |x - a| where x is in B
    cost1 = float('inf')
    if B:
        pos = bisect.bisect_left(B, a)
        candidates = []
        if pos < len(B):
            candidates.append(B[pos])
        if pos > 0:
            candidates.append(B[pos-1])
        if candidates:
            cost1 = min(abs(x - a) for x in candidates)
    
    # Compute cost2: minimal |y - b| where y is in A
    cost2 = float('inf')
    if A:
        pos = bisect.bisect_left(A, b)
        candidates = []
        if pos < len(A):
            candidates.append(A[pos])
        if pos > 0:
            candidates.append(A[pos-1])
        if candidates:
            cost2 = min(abs(y - b) for y in candidates)
    
    # Compute cost3: minimal |x - y| between A and B
    cost3 = float('inf')
    i = j = 0
    lenA, lenB = len(A), len(B)
    while i < lenA and j < lenB:
        diff = A[i] - B[j]
        current = abs(diff)
        if current < cost3:
            cost3 = current
        if cost3 == 0:
            break  # Can't get better than 0
        if A[i] < B[j]:
            i += 1
        else:
            j += 1
    
    min_total = min(cost0, cost1, cost2, cost3)
    print(min_total)

if __name__ == "__main__":
    main()
```

### Explanation
- **Immediate Check**: If the start and end airports are the same, the cost is zero.
- **Same Company Check**: If both airports belong to the same company, the direct flight is free.
- **Collect and Sort**: Airports are separated into lists based on their company and sorted for efficient closest element searches.
- **Cost Calculations**:
  - **Direct Flight**: The cost of flying directly between the start and end airports.
  - **Closest in Destination**: Using binary search to find the closest airport in the destination company to the start airport.
  - **Closest in Start**: Using binary search to find the closest airport in the start company to the end airport.
  - **Minimum Distance Between Companies**: Using a two-pointer technique to find the minimum distance between any two airports in the respective companies.

This approach ensures that all possible minimal paths are considered efficiently, leading to an optimal solution.
