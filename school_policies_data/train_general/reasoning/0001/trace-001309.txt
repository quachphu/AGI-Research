def main():

        taro = []

        hanako = []

        for _ in range(n):

            s = int(sys.stdin.readline())

            taro.append(s)

        for _ in range(m):

            s = int(sys.stdin.readline())

            hanako.append(s)

        sum_t = sum(taro)

        sum_h = sum(hanako)

        total = sum_t + sum_h

        if total %2 !=0:

            print(-1)

            continue

        required_diff = (sum_t - sum_h) //2

        valid_pairs = []

        for x in taro:

            for y in hanako:

                if x - y == required_diff:

                    valid_pairs.append( (x, y) )

        if not valid_pairs:

            print(-1)

        else:

            valid_pairs.sort(key=lambda p: (p[0]+p[1], p[0], p[1]))

            print(f"{valid_pairs[0][0]} {valid_pairs[0][1]}")

To solve this problem, we need to determine if Taro and Hanako can exchange one card each such that their total scores become equal. If they can, we must find the pair of cards with the smallest sum. If multiple pairs have the same smallest sum, we choose the pair with the smallest values first.

### Approach
1. **Input Reading**: Read multiple datasets until encountering a line with two zeros.
2. **Sum Calculation**: For each dataset, compute the total scores for Taro and Hanako.
3. **Check Feasibility**: If the combined total score of Taro and Hanako is odd, output `-1` as it's impossible to split an odd total into two equal parts.
4. **Determine Required Difference**: Calculate the required difference between Taro's and Hanako's scores to make their totals equal after the exchange.
5. **Find Valid Pairs**: Check all possible pairs of cards to find those that meet the required difference.
6. **Select Optimal Pair**: Among valid pairs, choose the one with the smallest sum. If there are ties, sort by the sum, then by Taro's card, and then by Hanako's card.

### Solution Code
```python
import sys

def main():
    while True:
        line = sys.stdin.readline()
        if not line:
            break
        n, m = map(int, line.strip().split())
        if n == 0 and m == 0:
            break
        taro = []
        hanako = []
        for _ in range(n):
            s = int(sys.stdin.readline().strip())
            taro.append(s)
        for _ in range(m):
            s = int(sys.stdin.readline().strip())
            hanako.append(s)
        sum_t = sum(taro)
        sum_h = sum(hanako)
        total = sum_t + sum_h
        if total % 2 != 0:
            print(-1)
            continue
        required_diff = (sum_t - sum_h) // 2
        valid_pairs = []
        for x in taro:
            for y in hanako:
                if x - y == required_diff:
                    valid_pairs.append((x, y))
        if not valid_pairs:
            print(-1)
        else:
            valid_pairs.sort(key=lambda p: (p[0] + p[1], p[0], p[1]))
            print(f"{valid_pairs[0][0]} {valid_pairs[0][1]}")

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The code reads each dataset's card counts and scores until encountering `0 0`.
2. **Sum Calculation**: It calculates the total scores for Taro and Hanako.
3. **Feasibility Check**: If the combined total is odd, output `-1` immediately.
4. **Required Difference**: Calculate the difference needed between Taro's and Hanako's card scores to balance their totals.
5. **Finding Pairs**: Check all possible card pairs to find those that meet the required difference.
6. **Sorting and Selection**: Valid pairs are sorted by sum, then by Taro's card, and finally by Hanako's card to determine the optimal pair.

This approach ensures we efficiently determine the optimal card exchange or identify if no solution exists, adhering to the problem constraints and requirements.
