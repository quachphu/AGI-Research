To solve this problem, we need to determine the maximum number of kids Chef can give both an eraser and a pencil to, and the minimum number of additional erasers or pencils needed to clear the remaining stock.

### Approach
1. **Input Reading**: Read the number of test cases and each test case string.
2. **Count Erasers and Pencils**: For each test case string, count the occurrences of 'E' (erasers) and 'P' (pencils).
3. **Calculate Maximum Kids**: The maximum number of kids that can receive both items is the minimum of the counts of erasers and pencils.
4. **Determine Additional Items**: The minimum number of additional items needed to clear the remaining stock is the absolute difference between the counts of erasers and pencils.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    cases = input[1:T+1]
    for case in cases:
        e = case.count('E')
        p = case.count('P')
        kids = min(e, p)
        needed = abs(e - p)
        print(kids, needed)

solve()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings. The first element is the number of test cases, followed by the test case strings.
2. **Counting Elements**: For each test case string, we count how many 'E's (erasers) and 'P's (pencils) there are.
3. **Maximum Kids Calculation**: The maximum number of kids is determined by the smaller count between erasers and pencils, as each kid needs one of each.
4. **Additional Items Calculation**: The absolute difference between the counts of erasers and pencils gives the minimum number of additional items needed to clear the stock. This is because after distributing the maximum possible pairs, the remaining items (either erasers or pencils) will be the difference between the two counts, and we need to either add that many of the other item or remove the remaining items to clear the stock.

This approach efficiently computes the required values using straightforward counting and mathematical operations, ensuring optimal performance even for the upper constraint limits.
