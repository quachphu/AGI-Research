To solve this problem, we need to determine the height of the tallest tower and the total number of towers that can be built using wooden bars of given lengths. Each tower can only consist of bars of the same length stacked on top of each other.

### Approach
1. **Read Input**: First, read the number of bars and their respective lengths.
2. **Count Frequencies**: Use a frequency counter to count how many times each length appears. This helps us determine both the height of each tower and the number of unique towers.
3. **Determine Results**: The maximum frequency from the counter gives the height of the tallest tower, while the number of unique keys in the counter gives the total number of towers.

### Solution Code
```python
from collections import Counter

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    lengths = list(map(int, input[1:n+1]))
    counts = Counter(lengths)
    max_height = max(counts.values()) if counts else 0
    total_towers = len(counts)
    print(f"{max_height} {total_towers}")

main()
```

### Explanation
1. **Reading Input**: The input is read in one go and split into a list of strings. The first element is the number of bars, and the subsequent elements are the lengths of the bars.
2. **Counting Frequencies**: Using `Counter` from the `collections` module, we count the occurrences of each bar length. This allows us to efficiently determine how many bars there are of each length.
3. **Calculating Results**: The maximum value in the frequency counter gives the height of the tallest tower. The number of unique keys in the counter gives the total number of towers since each unique length forms a separate tower.

This approach ensures that we efficiently compute the required results with a time complexity of O(N), where N is the number of bars, making it suitable for the given problem constraints.
