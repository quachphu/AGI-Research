To solve this problem, we need to determine the number of unique integers Hanako can create by selecting and arranging k cards from a given set of n cards. Each card has an integer between 1 and 99, and the order of selection matters, but duplicates formed by different card arrangements should be counted only once.

### Approach
1. **Input Reading**: Read the number of cards (n) and the number of cards to select (k) for each dataset. Continue reading datasets until both n and k are zero.
2. **Generate Permutations**: For each dataset, generate all possible permutations of k cards. Each permutation represents a unique arrangement of selected cards.
3. **Form Integers**: Convert each permutation into an integer by concatenating the string values of the cards in the permutation order.
4. **Unique Integers**: Use a set to collect all these integers, ensuring each integer is counted only once.
5. **Output Result**: The size of the set gives the number of unique integers for each dataset.

### Solution Code
```python
import sys
from itertools import permutations

def main():
    while True:
        n_line = sys.stdin.readline().strip()
        if not n_line:
            continue  # Skip any empty lines due to input formatting
        n = int(n_line)
        k_line = sys.stdin.readline().strip()
        if not k_line:
            k = 0
        else:
            k = int(k_line)
        
        if n == 0 and k == 0:
            break
        
        cards = []
        for _ in range(n):
            card = sys.stdin.readline().strip()
            cards.append(card)
        
        unique_numbers = set()
        for perm in permutations(cards, k):
            num_str = ''.join(perm)
            unique_numbers.add(num_str)
        
        print(len(unique_numbers))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads input values for n and k until both are zero. Each card's value is read as a string to handle multi-digit numbers correctly.
2. **Generating Permutations**: Using `itertools.permutations`, we generate all possible ordered selections of k cards. This ensures all permutations are considered, even if they involve different cards with the same value.
3. **Forming Integers**: Each permutation of cards is concatenated into a string and added to a set. This set automatically handles duplicate integers, ensuring each unique integer is counted once.
4. **Output**: The size of the set, which contains all unique integers formed, is printed for each dataset.

This approach efficiently handles the constraints and ensures that all possible integers are considered while eliminating duplicates using a set data structure.
