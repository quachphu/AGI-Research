To solve this problem, we need to determine if a grasshopper's jumps on a strip of cells will eventually take it out of the strip (finite) or if it will loop indefinitely (infinite). The solution involves simulating the grasshopper's movement and detecting cycles using a visited array.

### Approach
1. **Input Reading**: Read the strip length, direction string, and jump distances.
2. **Simulation**: Start from the first cell and simulate each jump according to the direction and distance specified.
3. **Cycle Detection**: Use a boolean array to track visited cells. If the grasshopper revisits a cell, it indicates a cycle, resulting in an infinite loop.
4. **Boundary Check**: After each jump, check if the new position is outside the strip. If it is, the sequence is finite.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    
    n = int(data[0])
    s = data[1]
    d = list(map(int, data[2:2+n]))
    
    visited = [False] * (n + 1)
    current = 1
    
    if current < 1 or current > n:
        print("FINITE")
        return
    
    visited[current] = True
    
    while True:
        direction = s[current - 1]
        step = d[current - 1]
        
        if direction == '>':
            next_pos = current + step
        else:
            next_pos = current - step
        
        if next_pos < 1 or next_pos > n:
            print("FINITE")
            return
        
        if visited[next_pos]:
            print("INFINITE")
            return
        
        visited[next_pos] = True
        current = next_pos

main()
```

### Explanation
- **Input Handling**: The input is read in one go and split into a list for efficient processing.
- **Visited Tracking**: A boolean array `visited` tracks which cells the grasshopper has visited to detect cycles.
- **Simulation Loop**: The loop continues moving the grasshopper according to the current cell's direction and distance. If the next position is out of bounds, it prints "FINITE". If the next position has been visited before, it prints "INFINITE".
- **Efficiency**: The algorithm runs in O(n) time complexity, where n is the number of cells, as each cell is visited at most once before a cycle is detected or the grasshopper exits the strip. This ensures the solution is efficient even for the upper constraint limits.
