To solve this problem, we need to efficiently compute the sum of prime numbers between given pairs of integers (x, y) for multiple test cases. Given the constraints, a direct approach for each test case would be too slow, so we use a precomputation strategy using the Sieve of Eratosthenes and prefix sums.

### Approach
1. **Sieve of Eratosthenes**: Generate a boolean array (sieve) where each index indicates whether the number is prime. This allows us to determine prime numbers up to \(10^6\) efficiently.
2. **Prefix Sum Array**: Construct a prefix sum array where each entry at index `i` contains the sum of all prime numbers from 0 up to `i`. This allows us to quickly compute the sum of primes in any range using prefix subtraction.
3. **Efficient Query Handling**: For each query, compute the sum of primes in the range [x, y] using the prefix sum array, which allows each query to be answered in constant time.

### Solution Code
```python
import sys

def main():
    max_num = 10**6
    sieve = [True] * (max_num + 1)
    sieve[0] = sieve[1] = False
    for i in range(2, int(max_num**0.5) + 1):
        if sieve[i]:
            sieve[i*i : max_num + 1 : i] = [False] * len(sieve[i*i : max_num + 1 : i])
    
    # Compute prefix sums of primes
    prefix = [0] * (max_num + 2)
    current_sum = 0
    for i in range(max_num + 1):
        if sieve[i]:
            current_sum += i
        prefix[i] = current_sum
    
    # Read all input
    input_data = sys.stdin.read().split()
    t = int(input_data[0])
    index = 1
    results = []
    for _ in range(t):
        x = int(input_data[index])
        y = int(input_data[index + 1])
        index += 2
        sum_val = prefix[y] - prefix[x - 1]
        results.append(sum_val)
    
    # Print all results
    sys.stdout.write('\n'.join(map(str, results)) + '\n')

if __name__ == '__main__':
    main()
```

### Explanation
1. **Sieve of Eratosthenes**: This algorithm efficiently marks non-prime numbers up to \(10^6\). By iterating from 2 to the square root of \(10^6\), we mark multiples of each prime starting from its square, ensuring all non-prime numbers are marked.
2. **Prefix Sum Array**: After generating the sieve, we build a prefix sum array where each entry at index `i` holds the cumulative sum of primes up to `i`. This allows us to compute the sum of primes in any range [x, y] in constant time using the formula `prefix[y] - prefix[x-1]`.
3. **Efficient Input/Output Handling**: Using `sys.stdin.read()` and `sys.stdout.write` ensures fast reading and writing of input and output, which is crucial given the large number of test cases.

This approach ensures that the solution is both time and space efficient, handling up to \(10^5\) queries in a timely manner.
