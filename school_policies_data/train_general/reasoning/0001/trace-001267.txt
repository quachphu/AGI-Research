To solve this problem, we need to determine the residues modulo M that cannot be obtained by summing an element from the first bag and an element from the second bag (the complement of the first bag) and then taking the result modulo M. 

### Approach
The key insight is to recognize that a residue \( c \) modulo \( M \) is unreachable if for every element \( a \) in the first bag, \( (c - a) \mod M \) is also an element of the first bag. This means that the first bag must be closed under the operation of subtracting any of its elements from \( c \) modulo \( M \).

The solution involves checking each residue \( c \) from 0 to \( M-1 \) to see if \( (c - a) \mod M \) is in the first bag for all elements \( a \) in the first bag. If this condition holds for all elements, \( c \) is an unreachable residue.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    M = int(input[idx])
    idx += 1
    A = list(map(int, input[idx:idx+N]))
    A_set = set(A)
    bad = []
    # Precompute all elements modulo M
    for c in range(M):
        valid = True
        for a in A:
            if (c - a) % M not in A_set:
                valid = False
                break
        if valid:
            bad.append(c)
    print(len(bad))
    if bad:
        print(' '.join(map(str, sorted(bad))))

if __name__ == "__main__":
    main()
```

1. **Reading Input:** The input is read and parsed into the number of elements \( N \) in the first bag, the modulus \( M \), and the elements of the first bag.

3. **Check Each Residue:** For each residue \( c \) from 0 to \( M-1 \), check if \( (c - a) \mod M \) is in the first bag for every element \( a \) in the first bag.
4. **Collect Bad Residues:** If all checks for a residue \( c \) pass, \( c \) is added to the list of unreachable residues.
5. **Output Results:** The number of unreachable residues is printed, followed by the sorted list of these residues if any exist.
