To solve this problem, we need to determine the lexicographically smallest string \( S \) that can be formed from a given string \( S' \) (which may contain '?' characters) such that \( S \) contains a specified substring \( T \). If it's impossible to form such a string, we should return "UNRESTORABLE".

### Approach
1. **Check Length Validity**: If the length of \( T \) is greater than the length of \( S' \), it's impossible for \( T \) to be a substring of \( S \), so we immediately return "UNRESTORABLE".

2. **Find Valid Positions**: Identify all valid starting positions in \( S' \) where \( T \) can be placed. A position \( i \) is valid if every character in \( S' \) from \( i \) to \( i + \text{len}(T) - 1 \) is either '?' or matches the corresponding character in \( T \).

3. **Generate Candidates**: For each valid position, generate a candidate string by replacing the corresponding segment in \( S' \) with \( T \) and replacing all other '?' characters with 'a' (to ensure lexicographic smallestness).

4. **Select the Lexicographically Smallest**: Among all valid candidates, select the lexicographically smallest one. If there are no valid candidates, return "UNRESTORABLE".

### Solution Code
```python
S = input().strip()
T = input().strip()

len_S = len(S)
len_T = len(T)

if len_T > len_S:
    print("UNRESTORABLE")
else:
    valid_positions = []
    for i in range(len_S - len_T + 1):
        valid = True
        for j in range(len_T):
            if S[i + j] != '?' and S[i + j] != T[j]:
                valid = False
                break
        if valid:
            valid_positions.append(i)
    
    if not valid_positions:
        print("UNRESTORABLE")
    else:
        candidates = []
        for i in valid_positions:
            temp = list(S)
            # Replace the T part
            for j in range(len_T):
                temp[i + j] = T[j]
            # Replace other '?' with 'a'
            for k in range(len(temp)):
                if k < i or k >= i + len_T:
                    if temp[k] == '?':
                        temp[k] = 'a'
            candidate = ''.join(temp)
            candidates.append(candidate)
        # Find the lex smallest candidate
        candidates.sort()
        print(candidates[0])
```

### Explanation
1. **Input Handling**: Read the input strings \( S' \) and \( T \).
2. **Length Check**: Immediately return "UNRESTORABLE" if \( T \) is longer than \( S' \).
3. **Valid Positions**: Check each possible starting position in \( S' \) to see if \( T \) can fit by matching characters or '?'.
4. **Generate Candidates**: For each valid position, generate a candidate string by inserting \( T \) and replacing remaining '?' with 'a'.
5. **Select Smallest**: Sort the candidates lexicographically and print the smallest one, or "UNRESTORABLE" if no valid candidates exist.

This approach ensures that we efficiently check all possible valid positions and generate the smallest possible string that meets the problem's requirements.
