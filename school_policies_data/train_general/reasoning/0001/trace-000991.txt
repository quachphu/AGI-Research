To solve this problem, we need to count the number of times the substring '01' appears in each given binary string for multiple test cases. 

### Approach
1. **Understanding the Problem**: The task is to determine how many times the substring '01' occurs in each binary string provided in the input. Each test case is a binary string, and we need to process multiple such strings efficiently.
2. **Efficient Counting**: For each binary string, iterate through each character (except the last one) and check if the current character and the next character form the substring '01'. If they do, increment the count.
3. **Input Handling**: Read the number of test cases first, followed by each binary string. Process each string to count the occurrences of '01' and print the result for each.

### Solution Code
```python
import sys

def count_01_occurrences():
    t = int(sys.stdin.readline())
    for _ in range(t):
        s = sys.stdin.readline().strip()
        count = 0
        for i in range(len(s) - 1):
            if s[i] == '0' and s[i+1] == '1':
                count += 1
        print(count)

count_01_occurrences()
```

### Explanation
1. **Reading Input**: The function starts by reading the number of test cases. For each test case, it reads the binary string and strips any leading or trailing whitespace (including newline characters).
2. **Counting Substrings**: For each string, initialize a count to zero. Iterate through the string from the start to the second last character. For each character, check if it is '0' and the next character is '1'. If so, increment the count.
3. **Output the Result**: After processing each string, print the count of '01' substrings.

This approach ensures that each string is processed in linear time, O(n), where n is the length of the string. This efficiency is crucial given the constraints, ensuring the solution handles the upper limits effectively.
