To solve this problem, we need to determine if a given board can be completely tiled with cross-shaped pieces, each covering exactly five cells. The solution involves checking several conditions and ensuring that all cells are covered without overlaps.

### Approach
1. **Check Divisibility by 5**: The total number of free cells must be divisible by 5 since each cross covers exactly five cells.
2. **Process Border Cells**: Each free cell on the border must be part of a cross whose center is one step inward. Check if these crosses can be placed without overlapping and mark them as covered.
3. **Process Inner Cells**: After handling the border cells, process the remaining inner cells to check if they can be covered by valid crosses. Use a greedy approach to place crosses wherever possible.
4. **Final Check**: Ensure all cells are covered after processing both border and inner cells.

### Solution Code
```python
n = int(input())
grid = [list(input().strip()) for _ in range(n)]
total_free = sum(row.count('.') for row in grid)

if total_free % 5 != 0:
    print("NO")
    exit()

for i in range(n):
    for j in range(n):
        if i == 0 or i == n-1 or j == 0 or j == n-1:
            if grid[i][j] == '.':
                # Determine the required center (cx, cy)
                if i == 0:
                    cx, cy = i + 1, j
                elif i == n-1:
                    cx, cy = i - 1, j
                elif j == 0:
                    cx, cy = i, j + 1
                else:  # j == n-1
                    cx, cy = i, j - 1
                
                # Check if center is within valid range
                if not (1 <= cx <= n-2 and 1 <= cy <= n-2):
                    print("NO")
                    exit()
                
                # Check all five cells of the cross
                if (grid[cx][cy] == '.' and
                    grid[cx-1][cy] == '.' and
                    grid[cx+1][cy] == '.' and
                    grid[cx][cy-1] == '.' and
                    grid[cx][cy+1] == '.'):
                    
                    # Mark them as covered
                    grid[cx][cy] = '#'
                    grid[cx-1][cy] = '#'
                    grid[cx+1][cy] = '#'
                    grid[cx][cy-1] = '#'
                    grid[cx][cy+1] = '#'
                else:
                    print("NO")
                    exit()

# Process inner cells
for i in range(1, n-1):
    for j in range(1, n-1):
        if grid[i][j] == '.':
            # Check if can place a cross here
            if (grid[i-1][j] == '.' and
                grid[i+1][j] == '.' and
                grid[i][j-1] == '.' and
                grid[i][j+1] == '.'):
                
                grid[i][j] = '#'
                grid[i-1][j] = '#'
                grid[i+1][j] = '#'
                grid[i][j-1] = '#'
                grid[i][j+1] = '#'

# Check if any free cells remain
for row in grid:
    if '.' in row:

        exit()
```
