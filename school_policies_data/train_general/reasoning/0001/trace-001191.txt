To solve this problem, we need to count the number of valid triplets (i, j, k) such that the characters at these positions are all different and the positions do not form an arithmetic progression. 

### Approach
1. **Count Characters**: First, count the occurrences of 'R', 'G', and 'B' in the string. The total number of triplets with distinct characters is the product of these counts.
2. **Subtract Invalid Triplets**: Identify and subtract the number of invalid triplets that form an arithmetic progression (i.e., j - i = k - j) and have all distinct characters. This is done by iterating through each possible middle position j and checking all possible distances d from j to find such invalid triplets.

### Solution Code
```python
n = int(input())
s = input().strip()

r = s.count('R')
g = s.count('G')
b = s.count('B')

total = r * g * b

invalid = 0
length = len(s)

for j in range(length):
    max_d = min(j, (length - 1) - j)
    for d in range(1, max_d + 1):
        i = j - d
        k = j + d
        if s[i] != s[j] and s[i] != s[k] and s[j] != s[k]:
            invalid += 1

print(total - invalid)
```

### Explanation
1. **Character Counting**: We count the occurrences of each character ('R', 'G', 'B') in the string. The product of these counts gives the total number of triplets with distinct characters.
2. **Arithmetic Progression Check**: For each possible middle position j, we check all valid distances d. For each distance, we determine the positions i and k and check if the characters at these positions form a valid triplet that needs to be excluded (i.e., they form an arithmetic progression and have distinct characters).

This approach efficiently reduces the problem complexity from O(N^3) to O(N^2), making it feasible for large input sizes up to 4000.
