To solve this problem, we need to determine the maximum number of times we can divide all integers on a blackboard by 2, given that all integers must remain even for each division operation. The solution involves calculating the number of times each integer can be divided by 2 before it becomes odd and finding the minimum value among these counts.

### Approach
1. **Understanding the Operation**: The operation involves dividing all integers by 2 only when all are even. Each time we perform this operation, every integer is divided by 2. The process stops when at least one integer becomes odd.
2. **Count Trailing Zeros**: For each integer, count how many times it can be divided by 2 before it becomes odd. This is equivalent to finding the number of trailing zeros in the binary representation of the integer.
3. **Determine Minimum Count**: The maximum number of operations possible is determined by the integer with the smallest count of trailing zeros, as this integer will be the first to become odd.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
min_count = float('inf')
for num in a:
    cnt = 0
    x = num
    while x % 2 == 0:
        cnt += 1
        x = x // 2
    if cnt < min_count:
        min_count = cnt
print(min_count)
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` followed by `n` integers. These integers are read and stored in a list.
2. **Counting Trailing Zeros**: For each integer in the list, we repeatedly divide it by 2 until it becomes odd, counting how many times this division is possible.
3. **Finding Minimum Count**: We keep track of the minimum count of trailing zeros across all integers. This minimum count is the answer, as it represents the maximum number of times all integers can be divided by 2 before one of them becomes odd.

This approach efficiently determines the solution by leveraging the properties of even numbers and their factorization by 2, ensuring an optimal and correct result.
