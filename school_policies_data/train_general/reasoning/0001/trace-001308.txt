To solve this problem, we need to convert given real numbers into their binary representations while adhering to specific constraints on the integer and fractional parts. The integer part of the binary number must be exactly 8 digits, and the fractional part must be exactly 4 digits. If the conversion does not fit within these constraints, we output "NA".

### Approach
1. **Input Handling**: Read input lines until a negative number is encountered, which signals the end of input.
2. **Splitting Values**: For each input value, split it into integer and fractional parts.
3. **Integer Conversion**: Convert the integer part to a binary string. If the binary string exceeds 8 digits, output "NA".
4. **Fractional Conversion**: Convert the fractional part to a binary string. If the conversion requires more than 4 digits or does not terminate exactly within 4 digits, output "NA".
5. **Formatting**: Combine the binary integer and fractional parts, padding with zeros to meet the required lengths.

### Solution Code
```python
import sys

def split_number(s):
    if '.' in s:
        integer_part, fractional_part = s.split('.', 1)
        if not fractional_part:
            fractional_part = '0'
    else:
        integer_part = s
        fractional_part = '0'
    return integer_part, fractional_part

def convert_to_binary(integer_part_str, fractional_part_str):
    # Process integer part
    try:
        integer = int(integer_part_str)
    except ValueError:
        return None
    binary_integer = bin(integer)[2:]
    if len(binary_integer) > 8:
        return None
    
    # Process fractional part
    k = len(fractional_part_str)
    if not fractional_part_str:
        numerator = 0
    else:
        try:
            numerator = int(fractional_part_str)
        except ValueError:
            return None
    denominator = 10 ** k
    remainder = numerator
    binary_fraction = []
    for _ in range(4):
        remainder *= 2
        if remainder >= denominator:
            binary_fraction.append('1')
            remainder -= denominator
        else:
            binary_fraction.append('0')
        if remainder == 0:
            break
    if remainder != 0:
        return None
    # Pad to 4 digits
    while len(binary_fraction) < 4:
        binary_fraction.append('0')
    fractional_binary = ''.join(binary_fraction)
    
    # Combine integer and fractional parts
    integer_binary_padded = binary_integer.zfill(8)
    return f"{integer_binary_padded}.{fractional_binary}"

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        if line.startswith('-'):
            break
        integer_part, fractional_part = split_number(line)
        result = convert_to_binary(integer_part, fractional_part)
        print(result if result is not None else "NA")

if __name__ == "__main__":
    main()
```
