To solve this problem, we need to determine if a given string contains two non-overlapping substrings "AB" and "BA". The substrings can appear in any order but must not overlap.

### Approach
The approach involves checking two scenarios:
1. The substring "AB" appears first, followed by the substring "BA" starting at least two positions after the end of "AB".
2. The substring "BA" appears first, followed by the substring "AB" starting at least two positions after the end of "BA".

By efficiently checking these two scenarios using string searching methods, we can determine if the conditions are met without resorting to an exhaustive search of all possible pairs, which would be computationally expensive.

### Solution Code
```python
s = input().strip()

# Check for AB followed by BA with non-overlapping
ab_pos = s.find('AB')
found = False

if ab_pos != -1:
    # Look for BA starting from ab_pos + 2
    ba_pos = s.find('BA', ab_pos + 2)
    if ba_pos != -1:
        found = True

if not found:
    # Check for BA followed by AB with non-overlapping
    ba_pos = s.find('BA')
    if ba_pos != -1:
        # Look for AB starting from ba_pos + 2
        ab_pos = s.find('AB', ba_pos + 2)
        if ab_pos != -1:
            found = True

print("YES" if found else "NO")
```

### Explanation
1. **Finding "AB" followed by "BA"**:
   - Locate the first occurrence of "AB" in the string.
   - Check if there is a subsequent occurrence of "BA" starting at least two positions after the end of the found "AB" to ensure non-overlapping.

2. **Finding "BA" followed by "AB"**:
   - If the first check fails, locate the first occurrence of "BA".
   - Check if there is a subsequent occurrence of "AB" starting at least two positions after the end of the found "BA".

By sequentially checking these two scenarios, we efficiently determine the presence of non-overlapping substrings "AB" and "BA" in linear time, ensuring optimal performance even for large input sizes.
