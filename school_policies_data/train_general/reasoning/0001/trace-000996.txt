To solve this problem, we need to form up to k balanced teams from a list of students such that the total number of students in these teams is maximized. A balanced team is defined as a group where the difference in programming skills between any two students is at most 5.

### Approach
1. **Sort the Array**: First, we sort the array of student skills to facilitate the identification of valid teams.
2. **Precompute Left Indices**: For each student, determine the leftmost index such that the difference between the current student's skill and the leftmost student's skill is within 5. This helps in quickly identifying the longest possible valid team ending at each student.
3. **Dynamic Programming (DP)**: Use a DP approach to keep track of the maximum number of students that can be included using up to k teams. The DP table `dp[i][j]` represents the maximum number of students using the first `i` students and `j` teams.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    k = int(input[1])
    a = list(map(int, input[2:2+n]))
    a.sort()
    
    left = [0] * n
    for i in range(n):
        target = a[i] - 5
        l = bisect.bisect_left(a, target, 0, i+1)
        left[i] = l
    
    INF = float('-inf')
    dp = [[INF] * (k + 1) for _ in range(n + 1)]
    dp[0][0] = 0
    
    for i in range(n):
        for j in range(k + 1):
            if dp[i][j] == INF:
                continue
            # Option 1: Do not take the i-th student
            if dp[i + 1][j] < dp[i][j]:
                dp[i + 1][j] = dp[i][j]
            # Option 2: Take the team ending at i
            if j + 1 > k:
                continue
            team_length = i - left[i] + 1
            prev_l = left[i]
            if prev_l == 0:
                if j == 0:
                    new_val = team_length
                else:
                    new_val = dp[prev_l][j] + team_length
            else:
                new_val = dp[prev_l][j] + team_length
            if new_val > dp[i + 1][j + 1]:
                dp[i + 1][j + 1] = new_val
    
    max_total = max(dp[n][1:k+1])
    print(max_total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Sorting**: Sorting the array helps in efficiently finding the leftmost index for each student using binary search.
2. **Precompute Left Indices**: For each student, we determine the leftmost index where the skill difference is within 5. This allows us to quickly determine the longest valid team ending at each student.
3. **Dynamic Programming**: The DP table is used to track the maximum number of students that can be included using up to k teams. For each student and each possible number of teams, we consider two options: not including the current student or forming a team ending at the current student. This ensures we explore all possible ways to form valid teams while maximizing the total number of students.

This approach efficiently combines sorting, binary search, and dynamic programming to solve the problem within acceptable time complexity for large inputs.
