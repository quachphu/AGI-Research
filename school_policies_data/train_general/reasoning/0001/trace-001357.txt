To solve this problem, we need to determine if there exists a "good string" X that satisfies specific conditions derived from two given strings S and T. If such a string exists, we must find the shortest possible length of X.

### Approach
1. **Understand the Conditions**: The string X must be such that:
   - Its length is divisible by both the lengths of S (N) and T (M).
   - When X is divided into N blocks, the first character of each block concatenated forms S.
   - When X is divided into M blocks, the first character of each block concatenated forms T.

2. **Find the Least Common Multiple (LCM)**: The smallest possible length for X that is divisible by both N and M is the LCM of N and M. This LCM is calculated using the formula: \( \text{LCM}(a, b) = \frac{a \times b}{\text{GCD}(a, b)} \).

3. **Check for Valid Positions**: For the calculated LCM, check if the characters required by S and T at overlapping positions in X are the same. If any mismatch is found, X cannot be formed, and we return -1. Otherwise, the LCM is the valid length of X.

### Solution Code
```python
import math

def find_shortest_good_string():
    n, m = map(int, input().split())
    s = input().strip()
    t = input().strip()
    
    g = math.gcd(n, m)
    lcm = n * m // g
    step_s = lcm // n  # m // g
    step_t = lcm // m  # n // g
    
    for i in range(n):
        x = i * step_s
        if x % step_t != 0:
            continue
        j = x // step_t
        if j < m and s[i] != t[j]:
            print(-1)
            return
    print(lcm)
```

2. **Determine Step Sizes**: Calculate the step sizes for dividing X into N and M blocks. These steps are derived from the LCM divided by the respective lengths of S and T.
3. **Check Overlapping Positions**: For each position in the blocks derived from S, check if it overlaps with a position in the blocks derived from T. If they overlap, ensure the characters from S and T at these positions match. If any mismatch is found, print -1 and exit.
