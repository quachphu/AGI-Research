To solve this problem, we need to determine the minimum number of seconds required for all share prices to become equal, given that each second exactly one price decreases by a fixed amount \( k \). If it's impossible for all prices to become equal, we should return -1.

### Approach
1. **Check for Feasibility**: First, we need to check if it's possible for all prices to become equal. For all prices to eventually be equal, each price must have the same remainder when divided by \( k \). If any two prices have different remainders, it's impossible to equalize them, and we return -1 immediately.

2. **Determine Target Value**: If the remainders are consistent, the target value \( T \) must be the minimum value among all prices. This is because the minimum value is the highest possible value all prices can be reduced to without any price becoming negative.

3. **Calculate Total Time**: For each price, compute how many times it needs to be reduced by \( k \) to reach the target value \( T \). Sum these counts to get the total time required.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))

if n == 1:
    print(0)
    exit()

remainder = a[0] % k
for num in a:
    if num % k != remainder:
        print(-1)
        exit()

min_price = min(a)
total = 0
for num in a:
    total += (num - min_price) // k

print(total)
```

### Explanation
1. **Feasibility Check**: We check if all elements in the list have the same remainder when divided by \( k \). If not, print -1 and exit.
2. **Target Value**: The minimum value in the list is chosen as the target value \( T \) because it's the highest possible value all prices can be reduced to without any price becoming negative.
3. **Total Time Calculation**: For each price, the difference from the target value \( T \) is divided by \( k \) to determine the number of reductions needed. Summing these values gives the total time required.

This approach ensures that we efficiently determine the minimum time required or identify if it's impossible, using straightforward mathematical checks and operations.
