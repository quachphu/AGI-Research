To solve this problem, we need to determine if a given set of binary codes is ambiguous. An encoding scheme is ambiguous if there exist two different character sequences that produce the same binary string when their codes are concatenated. The goal is to find the length of the shortest ambiguous binary sequence, or return 0 if the encoding is not ambiguous.

### Approach
The approach involves using a Breadth-First Search (BFS) algorithm to explore all possible binary strings generated by concatenating the given codes. We track each generated binary string and the sequence of codes used to form it. If a binary string is generated by two different code sequences, the length of that string is the answer. The BFS ensures that we find the shortest such string first.

### Solution Code
```python
from collections import deque
import sys

def main():
    n = int(sys.stdin.readline())
    codes = [sys.stdin.readline().strip() for _ in range(n)]
    
    # Check for duplicate codes (though the problem states they are distinct)
    seen = set()
    for code in codes:
        if code in seen:
            print(0)
            return
        seen.add(code)
    
    visited = {}
    queue = deque()
    visited[''] = tuple()
    queue.append(('', tuple()))
    
    while queue:
        current_s, current_seq = queue.popleft()
        for i in range(n):
            code = codes[i]
            new_s = current_s + code
            new_seq = current_seq + (i,)
            if new_s in visited:
                existing_seq = visited[new_s]
                if new_seq != existing_seq:
                    print(len(new_s))
                    return
            else:
                visited[new_s] = new_seq
                queue.append((new_s, new_seq))
    
    print(0)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The input is read, and the codes are stored in a list. We also check for duplicate codes, although the problem states that all codes are distinct.
2. **BFS Initialization:** We initialize a queue with the empty string and an empty code sequence. The `visited` dictionary tracks each generated binary string and the first code sequence that formed it.
3. **Processing Each State:** For each state (current binary string and code sequence), we generate new states by appending each code. The new binary string and code sequence are checked against the `visited` dictionary.
4. **Checking Ambiguity:** If a binary string is found in `visited` with a different code sequence, the length of the string is printed as the result. If no ambiguity is found after processing all possible states, 0 is printed.

This approach efficiently explores all possible binary strings in increasing order of length, ensuring the shortest ambiguous sequence is found first if it exists.
