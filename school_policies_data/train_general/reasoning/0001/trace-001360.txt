To solve this problem, we need to determine the minimum number of explosions required to defeat all monsters, where each explosion can cause significant damage to a targeted monster and lesser damage to others. The key is to find the optimal number of explosions such that all monsters' health drops to zero or below.

### Approach
1. **Binary Search**: We use binary search to efficiently determine the minimum number of explosions (T). The binary search will check if a given number of explosions (T) can potentially defeat all monsters.
2. **Damage Calculation**: For each candidate value of T during the binary search, we calculate the minimum number of times each monster needs to be the center of an explosion. This is derived from the health damage formula and ensures that the total damage from explosions meets or exceeds each monster's health.

### Solution Code
```python
import sys

def main():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    A = int(input[1])
    B = int(input[2])
    h = list(map(int, input[3:3+N]))
    
    low = 0
    high = 10**18
    ans = high
    required_diff = A - B
    
    while low <= high:
        mid = (low + high) // 2
        sum_xi = 0
        
        for hi in h:
            remaining = hi - B * mid
            if remaining > 0:
                sum_xi += (remaining + required_diff - 1) // required_diff
        
        if sum_xi <= mid:
            ans = mid
            high = mid - 1
        else:
            low = mid + 1
    
    print(ans)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Binary Search Setup**: We initialize the binary search with `low` set to 0 and `high` set to a large value (10^18) to cover all possible scenarios.
2. **Mid Calculation**: For each midpoint (mid) in the binary search, we check if `mid` explosions are sufficient.
3. **Health Check**: For each monster's health, we calculate the remaining health after `mid` explosions. If the remaining health is positive, we determine how many times that monster needs to be the explosion center to reduce its health to zero or below.
4. **Sum Check**: We sum the required explosion centers for all monsters. If this sum is less than or equal to `mid`, `mid` is a feasible solution, and we adjust the binary search bounds to find a potentially smaller valid value.

This approach efficiently narrows down the minimum number of explosions using binary search, ensuring optimal performance even for large input sizes.
