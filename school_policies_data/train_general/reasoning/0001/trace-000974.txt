To solve this problem, we need to determine if Bajirao gets a kiss or a slap based on the words he speaks. The rule is that if a word has any adjacent letters that are the same, Bajirao gets a slap; otherwise, he gets a kiss.

### Approach
1. **Input Reading**: Read the number of test cases followed by each word.
2. **Check Adjacent Characters**: For each word, check each pair of adjacent characters. If any pair is the same, immediately determine the result as a slap.
3. **Early Termination**: If an adjacent duplicate is found, stop further checks for that word to optimize performance.
4. **Output Result**: Based on the check, print 'SLAP' if duplicates are found, otherwise print 'KISS'.

### Solution Code
```python
def main():
    import sys
    t = int(sys.stdin.readline())
    for _ in range(t):
        word = sys.stdin.readline().strip()
        slap = False
        for i in range(len(word) - 1):
            if word[i] == word[i + 1]:
                slap = True
                break
        print('SLAP' if slap else 'KISS')

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads the number of test cases `t` and then processes each word individually.
2. **Checking Adjacent Characters**: For each word, iterate through each character and compare it with the next character. If any two adjacent characters are the same, set the result to 'SLAP' and break out of the loop early.
3. **Output**: After checking all pairs (or breaking early if duplicates are found), the result is printed. If no duplicates are found, 'KISS' is printed.

This approach ensures that each word is checked efficiently, and the solution handles all edge cases within the problem constraints.
