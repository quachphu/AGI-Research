To solve this problem, we need to determine if a watermelon of weight `w` can be split into two parts such that each part has an even weight and both parts are positive. 

### Approach
The key insight here is that for two even numbers to sum up to `w`, `w` itself must be even. Additionally, since each part must be positive and even, the smallest possible sum of two even positive numbers is 4 (2 + 2). Therefore, the solution must check two conditions:
1. `w` is even.
2. `w` is greater than or equal to 4.

If both conditions are met, the answer is "YES"; otherwise, it is "NO".

### Solution Code
```python
w = int(input())
if w % 2 == 0 and w >= 4:
    print("YES")
else:
    print("NO")
```

### Explanation
1. **Reading Input**: The input weight `w` is read as an integer.
2. **Check Evenness**: The first condition checks if `w` is even using `w % 2 == 0`.
3. **Check Minimum Weight**: The second condition ensures `w` is at least 4, which is the smallest even number that can be split into two positive even parts.
4. **Output Result**: Based on the checks, the result is printed as "YES" or "NO".

This approach efficiently determines the possibility of splitting the watermelon with a constant time complexity O(1), making it optimal for the given constraints.
