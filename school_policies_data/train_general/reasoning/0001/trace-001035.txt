To solve this problem, we need to determine the relative orientation of three points (p0, p1, p2) and classify their arrangement into one of five categories: COUNTER_CLOCKWISE, CLOCKWISE, ONLINE_BACK, ONLINE_FRONT, or ON_SEGMENT. This can be efficiently achieved using vector cross and dot products to analyze the geometric relationships between the points.

### Approach
1. **Cross Product Calculation**: The cross product of vectors p0p1 and p0p2 helps determine the orientation. A positive cross product indicates a counter-clockwise turn, a negative value indicates a clockwise turn, and zero means the points are collinear.
2. **Dot Product and Length Check**: When points are collinear (cross product is zero), the dot product of vectors p0p1 and p0p2, along with the squared length of p0p1, helps determine the position of p2 relative to the segment p0p1. This allows us to classify p2 as lying behind p0, beyond p1, or on the segment.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    x0 = int(input[ptr])
    ptr += 1
    y0 = int(input[ptr])
    ptr += 1
    x1 = int(input[ptr])
    ptr += 1
    y1 = int(input[ptr])
    ptr += 1
    q = int(input[ptr])
    ptr += 1

    dx1 = x1 - x0
    dy1 = y1 - y0
    len_sq = dx1 * dx1 + dy1 * dy1

    for _ in range(q):
        x2 = int(input[ptr])
        ptr += 1
        y2 = int(input[ptr])
        ptr += 1
        dx2 = x2 - x0
        dy2 = y2 - y0

        cross = dx1 * dy2 - dx2 * dy1
        if cross > 0:
            print("COUNTER_CLOCKWISE")
        elif cross < 0:
            print("CLOCKWISE")
        else:
            dot = dx1 * dx2 + dy1 * dy2
            if dot < 0:
                print("ONLINE_BACK")
            elif dot > len_sq:
                print("ONLINE_FRONT")
            else:
                print("ON_SEGMENT")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints. The first line contains the coordinates of p0 and p1, followed by the number of queries and the query points.
2. **Precomputation**: The differences (dx1, dy1) between p0 and p1 are precomputed once, along with the squared length of the segment p0p1.
3. **Cross Product Check**: For each query point p2, the cross product of vectors p0p1 and p0p2 is computed. The sign of this product determines the orientation (counter-clockwise or clockwise).
4. **Collinear Check**: If the cross product is zero, the dot product and squared length determine if p2 is on the segment, behind p0, or beyond p1.

This approach ensures efficient and accurate classification of the points' orientation and position, adhering to the problem constraints and requirements.
