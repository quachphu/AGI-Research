To solve this problem, we need to determine the number of valid pairs of towns (u, v) such that Kuro can walk from u to v without passing through Flowrisa (x) followed by Beetopia (y) in that order. The solution involves calculating the total number of possible pairs and subtracting the invalid pairs where the path from u to v includes x before y.

### Approach
1. **Tree Representation**: Represent the towns and roads as an adjacency list.
2. **Subtree Sizes Calculation**: Use a Depth-First Search (DFS) to compute the subtree sizes for each node when the tree is rooted at Flowrisa (x).
3. **Path Identification**: Determine the path from x to y using parent pointers obtained during the DFS.
4. **Invalid Pairs Calculation**: Calculate the number of invalid pairs by finding the sizes of specific subtrees that would result in paths from u to v passing through x before y.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    x = int(input[ptr])
    ptr += 1
    y = int(input[ptr])
    ptr += 1

    adj = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        a = int(input[ptr])
        ptr += 1
        b = int(input[ptr])
        ptr += 1
        adj[a].append(b)
        adj[b].append(a)

    parent = [0] * (n + 1)
    subtree_size = [1] * (n + 1)

    stack = [(x, None, False)]
    while stack:
        u, p, visited = stack.pop()
        if not visited:
            parent[u] = p
            stack.append((u, p, True))
            for v in reversed(adj[u]):
                if v != p:
                    stack.append((v, u, False))
        else:
            for v in adj[u]:
                if v != p:
                    subtree_size[u] += subtree_size[v]

    path = []
    current = y
    while current is not None:
        path.append(current)
        current = parent[current]

    path.reverse()

    q = path[1]
    size_A = n - subtree_size[q]
    size_B = subtree_size[y]
    invalid = size_A * size_B

    total = n * (n - 1)
    print(total - invalid)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Tree Representation**: The adjacency list is built from the input, representing each town and its connections.
2. **DFS for Subtree Sizes**: An iterative DFS is used to compute the parent pointers and subtree sizes for each node when the tree is rooted at x. This helps in efficiently determining the size of subtrees when edges are removed.
3. **Path Identification**: By backtracking from y to x using parent pointers, we identify the path from x to y. The first node after x on this path (q) is crucial for determining the subtree size that leads to invalid pairs.
4. **Invalid Pairs Calculation**: The number of invalid pairs is derived from the product of the sizes of two specific subtrees: one that excludes nodes in the direction of y from x (size_A) and the subtree rooted at y (size_B). The result is the total number of pairs minus these invalid pairs.

This approach efficiently computes the valid pairs using subtree sizes and path analysis, ensuring optimal performance even for large trees.
