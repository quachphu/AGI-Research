To solve this problem, we need to efficiently handle two types of queries on a binary array: flipping elements in a range and calculating the inversion count of a subarray. Given the constraints, a naive approach would be too slow, so we use a segment tree with lazy propagation to manage range updates and queries efficiently.

### Approach
1. **Segment Tree Structure**: Each node in the segment tree stores the number of 0s (c0), the number of 1s (c1), the inversion count (inv), and a flip flag for lazy propagation.
2. **Lazy Propagation**: When a range flip is applied, we toggle the flip flag of the affected nodes and propagate the flip to child nodes only when necessary, ensuring efficient updates.
3. **Inversion Count Calculation**: The inversion count for a subarray is computed by combining results from the left and right children of the segment tree nodes, considering cross inversions between the left and right segments.
