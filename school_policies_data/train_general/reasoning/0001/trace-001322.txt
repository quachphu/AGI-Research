To solve this problem, we need to reconstruct the original array `a` from the given array `b`. Each element `b_i` is derived from `a_i` and the maximum value of the previous elements in `a` (denoted as `x_i`). The challenge is to reverse this derivation efficiently.

### Approach
1. **Understanding the Relationship**: Each element `a_i` in the original array can be expressed as `a_i = b_i + x_i`, where `x_i` is the maximum value of all previous elements in `a` (starting from 0 for the first element).
2. **Iterative Calculation**: We can compute each `a_i` iteratively while maintaining the maximum value encountered so far. This maximum value will be used to compute the subsequent elements of `a`.
3. **Efficient Update**: For each element in `b`, compute the corresponding `a_i` using the current maximum value, then update the maximum value for the next iteration.

### Solution Code
```python
def restore_a():
    import sys
    input_data = sys.stdin.read().split()
    n = int(input_data[0])
    b = list(map(int, input_data[1:n+1]))
    current_max = 0
    a = []
    for bi in b:
        ai = bi + current_max
        a.append(ai)
        current_max = max(current_max, ai)
    print(' '.join(map(str, a)))

restore_a()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints. The first value is `n`, the size of the array, followed by the elements of `b`.
2. **Initialization**: `current_max` is initialized to 0, which corresponds to `x_1` for the first element.
3. **Iterating through `b`**: For each element `b_i`, compute `a_i` as `b_i + current_max`. Append this value to the result list `a` and update `current_max` to be the maximum of itself and the newly computed `a_i`.
4. **Output**: The resulting array `a` is printed as space-separated integers.

This approach ensures that each element of `a` is computed in linear time, making the solution efficient and suitable for large input sizes up to 200,000 elements.
