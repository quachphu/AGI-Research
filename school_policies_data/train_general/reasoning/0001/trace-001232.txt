To solve this problem, we need to determine the maximum number of fruits Nikolay can use to make compote following the ratio 1:2:4 for lemons, apples, and pears respectively. The goal is to find the largest possible number of compote batches that can be made using whole fruits, adhering strictly to the given ratio.

### Approach
1. **Understand the Ratio**: Each compote batch requires 1 lemon, 2 apples, and 4 pears. This means for each batch (k), we need exactly k lemons, 2k apples, and 4k pears.
2. **Determine Constraints**: The maximum number of batches (k) is constrained by the available quantities of each fruit divided by their respective ratios. Specifically:
   - The number of lemons available (a) limits k directly.
   - The number of apples available (b) limits k to b // 2 (since each batch needs 2 apples).
   - The number of pears available (c) limits k to c // 4 (since each batch needs 4 pears).
3. **Calculate Maximum Batches**: The maximum number of batches (k) is the minimum of the three values derived from the constraints above. The total number of fruits used in these batches is then 7 times the number of batches (since each batch uses 1 + 2 + 4 = 7 fruits).

### Solution Code
```python
a = int(input())
b = int(input())
c = int(input())
k = min(a, b // 2, c // 4)
print(7 * k)
```

### Explanation
1. **Reading Inputs**: The code reads three integers from the input, representing the number of lemons, apples, and pears respectively.
2. **Calculate Maximum Batches**: Using the `min` function, the code determines the maximum number of batches (k) that can be made based on the available quantities of each fruit divided by their respective ratios.
3. **Compute Total Fruits**: The total number of fruits used is calculated as 7 times the number of batches (k), which gives the result.

This approach ensures that we use the maximum possible number of fruits while adhering to the required ratio, efficiently and correctly solving the problem.
