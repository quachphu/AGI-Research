To solve this problem, we need to determine the minimum number of cash registers required in Valera's cafe to ensure that all customers are served without any customer leaving due to unavailability of a cash register. The key is to track the maximum number of customers present in the cafe at any given time, as this will dictate the number of cash registers needed.

### Approach
1. **Convert Arrival Times to Minutes**: Convert each customer's arrival time from hours and minutes into total minutes since midnight. This simplifies time calculations.
2. **Track Service Intervals**: Each customer's service time starts at their arrival time and ends one minute later (since service takes less than a minute). Create events for the start and end of each customer's service interval.
3. **Sort Events**: Sort these events by time. If two events occur at the same time, process end events before start events to ensure correct overlap counting.
4. **Count Overlaps**: Traverse the sorted events, adjusting the count of active customers (cash registers in use). Track the maximum number of active customers at any point, which gives the minimum number of cash registers needed.

### Solution Code
```python
n = int(input())
events = []

for _ in range(n):
    h, m = map(int, input().split())
    t = h * 60 + m
    events.append((t, 1))
    events.append((t + 1, -1))

events.sort()

current = 0
max_cash = 0

for time, delta in events:
    current += delta
    if current > max_cash:
        max_cash = current

print(max_cash)
```

### Explanation
1. **Reading Input**: The input is read and converted into total minutes since midnight for each customer's arrival time.
2. **Creating Events**: For each customer, two events are created: one when they start being served (arrival time) and one when they finish (arrival time + 1 minute).
3. **Sorting Events**: Events are sorted by time. If two events have the same time, end events (cashier becoming free) are processed before start events (customer arriving) to ensure accurate overlap counting.
4. **Processing Events**: By iterating through the sorted events, we maintain a count of active customers. The maximum value of this count during the iteration gives the required number of cash registers.

This approach efficiently tracks overlaps using a sorted list of events, ensuring an optimal solution with a time complexity of O(n log n) due to the sorting step, which is suitable for large inputs up to 100,000 customers.
