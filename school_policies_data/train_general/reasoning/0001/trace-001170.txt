To solve this problem, we need to determine the minimum and maximum costs of sending a letter from each city in Lineland, where each city is located on a coordinate axis. The cost is defined as the distance between two cities. 

### Approach
1. **Understanding the Problem**: Each city's position is given in ascending order. For each city, we need to compute the minimum and maximum distances to any other city.
2. **Key Observations**:
   - **Maximum Distance**: For any city, the farthest possible cities are either the leftmost (first city) or the rightmost (last city). Thus, the maximum distance from a city at position `xi` is the maximum of `xi - x[0]` (distance to the leftmost city) and `x[-1] - xi` (distance to the rightmost city).
   - **Minimum Distance**: The closest cities to any given city (except the first and last) are its immediate neighbors. For the first and last cities, their closest neighbors are the next and previous cities respectively.
3. **Efficient Calculation**: By leveraging the sorted order of cities, we can compute the minimum and maximum distances in linear time, O(n), which is efficient for large inputs.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    x = list(map(int, sys.stdin.readline().split()))
    for i in range(n):
        current = x[i]
        max_val = max(current - x[0], x[-1] - current)
        if i == 0:
            min_val = x[1] - x[0]
        elif i == n - 1:
            min_val = x[i] - x[i-1]
        else:
            min_val = min(current - x[i-1], x[i+1] - current)
        print(min_val, max_val)

main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin` for efficiency, especially with large datasets.
2. **Maximum Distance Calculation**: For each city, compute the distance to the first and last cities and take the maximum of these two values.
3. **Minimum Distance Calculation**: 
   - For the first city, the minimum distance is the distance to the next city.
   - For the last city, the minimum distance is the distance to the previous city.
   - For all other cities, the minimum distance is the smaller of the distances to the immediate previous and next cities.
4. **Output**: The results for each city are printed in the required format.

This approach ensures that we efficiently compute the required values in linear time, making it suitable for large input sizes up to 100,000 cities.
