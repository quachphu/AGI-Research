To solve this problem, we need to find the shortest good subsequence of a given path in a directed graph. A good subsequence is defined such that the original path is one of the shortest possible paths passing through the vertices of the subsequence in order.

### Approach
1. **Precompute Shortest Paths**: Use BFS to compute the shortest path distances between all pairs of vertices in the graph. This helps in efficiently checking if a segment of the original path is the shortest possible.
2. **Greedy Subsequence Construction**: Traverse the original path and construct the subsequence by ensuring that each segment between consecutive vertices in the subsequence is a shortest path. If a segment can be shortcut, the previous vertex is added to the subsequence to avoid the shortcut.

### Solution Code
```python
from collections import deque

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr +=1
    
    # Read adjacency matrix
    adj = [[] for _ in range(n)]
    for u in range(n):
        line = input[ptr]
        ptr +=1
        for v in range(n):
            if line[v] == '1':
                adj[u].append(v)
    
    # Compute shortest paths using BFS for each node
    dist = [[-1]*n for _ in range(n)]
    for u in range(n):
        q = deque()
        q.append(u)
        dist[u][u] = 0
        while q:
            current = q.popleft()
            for neighbor in adj[current]:
                if dist[u][neighbor] == -1:
                    dist[u][neighbor] = dist[u][current] + 1
                    q.append(neighbor)
    
    m = int(input[ptr])
    ptr +=1
    p = list(map(int, input[ptr:ptr+m]))
    ptr +=m
    p = [x-1 for x in p]  # Convert to 0-based
    
    if m == 1:
        print(1)
        print(p[0]+1)
        return
    
    result = [p[0]]
    prev_pos = 0
    
    for j in range(1, m):
        while True:
            current_u = p[prev_pos]
            current_v = p[j]
            if dist[current_u][current_v] < (j - prev_pos):
                result.append(p[j-1])
                prev_pos = j-1
            else:
                break
    
    if result[-1] != p[-1]:
        result.append(p[-1])
    
    # Convert back to 1-based
    result = [x+1 for x in result]
    
    print(len(result))
    print(' '.join(map(str, result)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed to get the number of vertices, the adjacency matrix, and the path.
2. **BFS for Shortest Paths**: For each vertex, BFS is used to compute the shortest path to all other vertices. This is stored in a distance matrix.
3. **Constructing the Subsequence**: The original path is traversed. For each vertex, we check if the segment from the last vertex in the subsequence can be shortcut. If it can, the previous vertex is added to the subsequence to ensure the shortest path constraint.
4. **Output**: The resulting subsequence is converted back to 1-based indexing and printed.

This approach ensures that the constructed subsequence is the shortest possible while maintaining the property that the original path is one of the shortest paths through the subsequence vertices.
