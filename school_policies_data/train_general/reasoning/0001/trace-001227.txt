To solve this problem, we need to determine if there exists a permutation of the numbers from 1 to n such that its prefix product sequence modulo n is a permutation of [0, 1, ..., n-1]. If such a permutation exists, we need to construct it.

### Approach
The key insight is that the permutation must end with the number n itself. This is because the prefix product sequence must include 0 exactly once, which can only happen if the last element introduces the factor that makes the product 0 modulo n. 

The solution can be broken down into the following steps:
1. **Check Special Cases**: For n = 1, 2, or 4, the solution exists and can be directly constructed.
2. **Prime Check**: For prime numbers, the solution exists and can be constructed using modular arithmetic properties.
3. **Composite Check**: For other composite numbers, the solution does not exist.

### Solution Code
```python
import sys

def is_prime(n):
    if n <= 1:
        return False
    if n == 2 or n == 3:
        return True
    if n % 2 == 0:
        return False
    i = 3
    while i * i <= n:
        if n % i == 0:
            return False
        i += 2
    return True

n = int(sys.stdin.readline())

    print("YES")
    print(1)

    print("YES")
    print(1)
    print(2)

    print("YES")
    print(1)
    print(3)
    print(2)
    print(4)

    if is_prime(n):
        perm = [1]
        for i in range(2, n):
            inv = pow(i-1, n-2, n)
            a = (i * inv) % n
            perm.append(a)
        perm.append(n)
        print("YES")
        for num in perm:
            print(num)
    else:
        print("NO")
```

   - If n is a prime number, we construct the permutation such that the prefix products modulo n form the sequence 1, 2, ..., n-1, 0. This is achieved using modular inverses to ensure each step's product is correct.

3. **Composite Number Handling**:
   - For composite numbers other than 4, it is impossible to form such a permutation due to the nature of factorial properties modulo composite numbers, which leads to repeated zeros in the prefix products.
