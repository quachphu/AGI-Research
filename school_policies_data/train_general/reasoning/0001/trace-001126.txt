To solve this problem, we need to determine if there exist three distinct indices \(i, j, k\) in an array such that the sum of the elements at these indices equals a given integer \(M\). The solution must be efficient given the constraints.

### Approach
1. **Sort the Array**: Sorting helps in efficiently finding the triplet using the two-pointer technique.
2. **Iterate through Each Element**: For each element in the array (up to the third last element), use two pointers to check the remaining part of the array.
3. **Two-Pointer Technique**: For each element at index \(i\), initialize two pointers, one at the next index (\(i+1\)) and another at the end of the array. Adjust these pointers to find if the sum of the three elements equals \(M\).

This approach ensures that we efficiently check all possible triplets in \(O(n^2)\) time complexity, which is feasible for the given constraints.

### Solution Code
```python
def find_triplet():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    M = int(input[1])
    arr = list(map(int, input[2:2+N]))
    if N < 3:
        print("NO")
        return
    arr.sort()
    for i in range(N - 2):
        left = i + 1
        right = N - 1
        while left < right:
            current_sum = arr[i] + arr[left] + arr[right]
            if current_sum == M:
                print("YES")
                return
            elif current_sum < M:
                left += 1
            else:
                right -= 1
    print("NO")

```

### Explanation
1. **Reading Input**: The input is read in one go and split into a list of integers. The first two integers are \(N\) (size of the array) and \(M\) (target sum).
2. **Edge Case Handling**: If \(N\) is less than 3, it's impossible to find three distinct indices, so we immediately print "NO".
3. **Sorting the Array**: Sorting the array allows us to use the two-pointer technique efficiently.
4. **Iterating through Elements**: For each element in the array (up to the third last element), we use two pointers to check the remaining elements. The two pointers start just after the current element and at the end of the array.
5. **Adjusting Pointers**: Depending on whether the current sum is less than or greater than \(M\), we move the left pointer to the right or the right pointer to the left, respectively. If the sum equals \(M\), we print "YES" and exit immediately.
6. **Final Check**: If no valid triplet is found after all iterations, we print "NO".

This approach efficiently narrows down the possible triplets using sorting and the two-pointer technique, ensuring we handle up to the maximum constraint size efficiently.
