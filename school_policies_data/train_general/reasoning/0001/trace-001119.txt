The solution must efficiently check each shot against the targets to determine if it hits any target and record the first hit.

### Approach
1. **Input Reading and Preprocessing**:
   - Read the number of targets and their properties (center and radius).
   - Convert each target into an interval on the Ox axis using its center and radius.
   - Sort these intervals by their starting points to facilitate efficient searching.

2. **Binary Search for Efficient Target Lookup**:
   - For each shot, use binary search to determine the possible target(s) whose interval on the Ox axis contains the shot's x-coordinate.
   - Check both the found target and the previous target (if applicable) to handle cases where the shot lies exactly at the boundary of two touching targets.

3. **Distance Calculation**:
   - For each candidate target, compute the distance from the shot to the target's center and check if it lies within the target's radius.

4. **Result Tracking**:
   - Track the first hit for each target using an array initialized to -1. Update this array with the shot number when a target is hit for the first time.

### Solution Code

import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0

    n = int(input[ptr])
    ptr +=1

    targets = []
    for i in range(n):
        x = int(input[ptr])
        r = int(input[ptr+1])
        ptr +=2
        start = x - r
        end = x + r
        targets.append( (start, end, x, r, i+1) )  # original index is 1-based

    # Sort targets by their start coordinate
    sorted_targets = sorted(targets, key=lambda t: t[0])
    starts = [t[0] for t in sorted_targets]

    m = int(input[ptr])
    ptr +=1

    result = [-1] * (n + 1)  # 1-based indexing

    for shot_number in range(1, m+1):
        x = int(input[ptr])
        y = int(input[ptr+1])
        ptr +=2

        # Find candidate using bisect
        i = bisect.bisect_right(starts, x) - 1

        # Check candidate i
        if 0 <= i < len(sorted_targets):
            t = sorted_targets[i]
            if x >= t[0] and x <= t[1]:
                dx = x - t[2]
                distance_sq = dx * dx + y * y
                if distance_sq <= t[3] ** 2:
                    orig_idx = t[4]
                    if result[orig_idx] == -1:
                        result[orig_idx] = shot_number

        # Check previous candidate i-1
        if i > 0:
            t_prev = sorted_targets[i-1]
            if x >= t_prev[0] and x <= t_prev[1]:
                dx_prev = x - t_prev[2]
                distance_sq_prev = dx_prev * dx_prev + y * y
                if distance_sq_prev <= t_prev[3] ** 2:
                    orig_idx_prev = t_prev[4]
                    if result[orig_idx_prev] == -1:
                        result[orig_idx_prev] = shot_number

    # Prepare output
    count = sum(1 for v in result[1:] if v != -1)
    print(count)
    print(' '.join(map(str, result[1:])))

if __name__ == "__main__":
    main()
