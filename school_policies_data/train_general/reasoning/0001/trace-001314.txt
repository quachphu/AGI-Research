To solve this problem, we need to determine the minimal and maximal possible differences between two strings where some characters are unreadable (denoted by '?'). The minimal difference is the smallest number of differing positions achievable by replacing '?' with appropriate characters, while the maximal difference is the largest number of differing positions.

### Approach
1. **Minimal Difference**: This is calculated by counting the positions where both characters are fixed (non-?) and different. If either character is '?', we can replace it to make the characters match, thus not contributing to the minimal difference.

2. **Maximal Difference**: This is calculated by considering all positions where either character is '?' or the characters are different when both are fixed. Positions where both characters are fixed and the same do not contribute to the maximal difference.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        s1 = input[idx]
        s2 = input[idx + 1]
        idx += 2
        min_diff = 0
        max_diff = 0
        for c1, c2 in zip(s1, s2):
            if c1 != '?' and c2 != '?':
                if c1 != c2:
                    min_diff += 1
                    max_diff += 1
            else:
                max_diff += 1
        print(min_diff, max_diff)

solve()
```

### Explanation
1. **Reading Input**: The input is read in one go and split into a list for efficient processing.
2. **Processing Each Test Case**: For each test case, the two strings are processed character by character.
3. **Calculating Differences**:
   - **Minimal Difference**: Incremented only when both characters are fixed and different.
   - **Maximal Difference**: Incremented for all positions except where both characters are fixed and the same.
4. **Output**: For each test case, the minimal and maximal differences are printed.

This approach efficiently computes the required differences by iterating through each character pair once, ensuring linear time complexity relative to the length of the strings, which is optimal for the given constraints.
