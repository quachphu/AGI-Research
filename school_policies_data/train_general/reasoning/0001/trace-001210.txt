To solve this problem, we need to find the smallest integer number X that is strictly greater than a given number A and is periodic with a specified length L. A number is periodic with length L if it can be formed by repeating a number P (which has exactly L digits) multiple times.

### Approach
1. **Determine the Length of X**: The length of X must be a multiple of L. We start by finding the smallest multiple of L that is greater than or equal to the length of A. This ensures X is either the same length as A (if possible) or longer.
2. **Generate Candidates**: For each candidate length (starting from the smallest multiple of L), generate possible values of X:
   - If the candidate length is greater than the length of A, the smallest X is formed by repeating the smallest L-digit number (100...0) enough times.
   - If the candidate length equals the length of A, check if the first L digits of A can form a valid periodic number. If not, increment the first L digits and check again.

### Solution Code
```python
L = int(input())
A = input().strip()
m = len(A)
current_l = ((m + L - 1) // L) * L

while True:
    if current_l > m:
        k = current_l // L
        P = '1' + '0' * (L - 1)
        X = P * k
        print(X)
        break
    else:
        k = current_l // L
        P0_str = A[:L]
        X_candidate = P0_str * k
        if X_candidate > A:
            print(X_candidate)
            break
        else:
            P0_num = int(P0_str)
            P1_num = P0_num + 1
            P1_str = str(P1_num)
            if len(P1_str) == L:
                X_candidate = P1_str * k
                print(X_candidate)
                break
            else:
                current_l += L
```

### Explanation
1. **Reading Input**: The input consists of the period length L and the number A as a string to handle very large numbers.
2. **Calculating Initial Length**: Compute the smallest multiple of L that is greater than or equal to the length of A.
3. **Generating Candidates**:
   - For lengths greater than A's length, the smallest periodic number is formed by repeating the smallest L-digit number (100...0).
   - For the same length as A, check if repeating the first L digits of A forms a valid periodic number. If not, increment the first L digits and check again. If the incremented number exceeds L digits, move to the next possible length.

This approach ensures we efficiently find the smallest valid periodic number by leveraging string operations and careful increment checks, avoiding the need for handling extremely large numbers directly.
