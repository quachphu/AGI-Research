To solve this problem, we need to construct a max-heap from a given array using the specified algorithms. A max-heap is a binary tree where each parent node is greater than or equal to its children. The solution involves two main steps: the `maxHeapify` function to maintain the max-heap property for a subtree, and the `buildMaxHeap` function to construct the max-heap from an array.

### Approach
1. **Understanding the Problem**: The goal is to transform an input array into a max-heap. This involves ensuring that each parent node is greater than or equal to its children. The transformation is done using a bottom-up approach starting from the middle of the array.

2. **maxHeapify Function**: This function ensures that the subtree rooted at index `i` satisfies the max-heap property. It compares the node with its left and right children, swaps the node with the larger child if necessary, and recursively applies the same process to the affected subtree.

3. **buildMaxHeap Function**: This function constructs the max-heap by applying `maxHeapify` to each node starting from the middle of the array down to the root. This ensures that all subtrees are processed in a bottom-up manner.

4. **Implementation Details**: The array is adjusted to be 1-indexed (using a dummy element at index 0) to simplify the calculation of child indices. After constructing the heap, the result is printed in the required format.

### Solution Code
```python
def main():
    import sys
    H = int(sys.stdin.readline())
    A = list(map(int, sys.stdin.readline().split()))
    A = [0] + A  # Convert to 1-based indexing

    def maxHeapify(arr, i, heap_size):
        l = 2 * i
        r = 2 * i + 1
        largest = i
        if l <= heap_size and arr[l] > arr[largest]:
            largest = l
        if r <= heap_size and arr[r] > arr[largest]:
            largest = r
        if largest != i:
            arr[i], arr[largest] = arr[largest], arr[i]
            maxHeapify(arr, largest, heap_size)

    def buildMaxHeap(arr, heap_size):
        for i in range(heap_size // 2, 0, -1):
            maxHeapify(arr, i, heap_size)

    buildMaxHeap(A, H)
    print(' '.join(map(str, A[1:H+1])))

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input, where the first line gives the size of the heap `H`, and the second line provides the elements of the array.

2. **1-based Indexing**: The array is converted to 1-based indexing by prepending a dummy element (0) to simplify index calculations for parent and child nodes.

3. **maxHeapify**: This function ensures that the subtree rooted at index `i` maintains the max-heap property by comparing the node with its children and swapping if necessary, then recursively checking the affected subtree.

4. **buildMaxHeap**: This function constructs the max-heap by applying `maxHeapify` starting from the middle of the array down to the root. This ensures all subtrees are processed correctly.

5. **Output**: The resulting max-heap is printed in the required format, converting the array back to 0-based indexing for output by slicing from index 1 to `H+1`.

This approach efficiently constructs the max-heap in O(H) time complexity, ensuring each node satisfies the max-heap property.
