To solve this problem, we need to determine which student from a class of 39 students will be the last to take a candy, given a specific number of candies. The students take turns in order of their student numbers, and the process repeats until all candies are taken. The student who takes the last candy is the one who keeps the class flag.

### Approach
1. **Understanding the Problem**: The students take candies in rounds. Each student takes one candy per round. If there are more candies than students, the process repeats. The key insight is to determine the position of the last student in the sequence when all candies are taken.
2. **Modular Arithmetic**: The problem can be efficiently solved using modular arithmetic. The position of the student who takes the last candy can be found using the remainder when the number of candies is divided by the number of students (39). If the remainder is zero, it means the last student in the sequence (student 39) takes the last candy. Otherwise, the remainder directly gives the position.
3. **Formatting the Result**: The student numbers are formatted as two-digit strings with leading zeros if necessary (e.g., 01, 02, ..., 39).

### Solution Code
```python
def main():
    import sys
    for line in sys.stdin:
        a = int(line.strip())
        mod = a % 39
        if mod == 0:
            mod = 39
        print(f"3C{mod:02d}")

main()
```

### Explanation
1. **Reading Input**: The program reads input lines until the end of file (EOF) is reached. Each line represents a test case with the number of candies.
2. **Modular Calculation**: For each number of candies, we compute the remainder when divided by 39. This remainder gives the position of the student who takes the last candy.
3. **Adjusting for Zero Remainder**: If the remainder is zero, it means the last candy is taken by the 39th student. Otherwise, the remainder itself is the position.
4. **Formatting the Output**: The student number is formatted as a string with "3C" followed by the two-digit position, ensuring leading zeros for positions 1 through 9.

This approach efficiently determines the result using simple arithmetic operations and handles all edge cases correctly. The solution processes each test case in constant time, making it very efficient even for the upper limit of input constraints.
