Implement DSU:

class DSU:

    def __init__(self, size):

        self.parent = list(range(size +1))  # 1-based

        self.rank = [1]*(size+1)

    def find(self, x):

        if self.parent[x] != x:

            self.parent[x] = self.find(self.parent[x])

        return self.parent[x]

    def union(self, x, y):

        x_root = self.find(x)

        y_root = self.find(y)

        if x_root == y_root:

            return False

        if self.rank[x_root] < self.rank[y_root]:

            self.parent[x_root] = y_root

        else:

            self.parent[y_root] = x_root

            if self.rank[x_root] == self.rank[y_root]:

                self.rank[x_root] +=1

        return True

To solve this problem, we need to connect all vertices of an undirected graph with the minimum possible cost. The graph can be modified by adding edges either using the regular cost (sum of the values on the vertices) or using special offers provided. The goal is to determine the minimum cost to make the graph connected.

### Approach
1. **Identify the Minimum Vertex**: The vertex with the smallest value is crucial because connecting other vertices to this vertex using the regular cost tends to be cheaper than other combinations.
2. **Generate Regular Edges**: For each vertex, generate an edge connecting it to the vertex with the smallest value. This ensures we consider the cheapest regular edges.
3. **Incorporate Special Offers**: Add all special offers provided, which might offer cheaper connections between specific vertices.
4. **Kruskal's Algorithm for MST**: Use Kruskal's algorithm to find the Minimum Spanning Tree (MST) of the combined set of edges (regular edges and special offers). This algorithm efficiently finds the MST by sorting edges by cost and using a union-find data structure to manage connected components.

### Solution Code
```python
class DSU:
    def __init__(self, size):
        self.parent = list(range(size + 1))  # 1-based indexing
        self.rank = [1] * (size + 1)
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return False
        if self.rank[x_root] < self.rank[y_root]:
            self.parent[x_root] = y_root
        else:
            self.parent[y_root] = x_root
            if self.rank[x_root] == self.rank[y_root]:
                self.rank[x_root] += 1
        return True

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    m = int(input[ptr])
    ptr += 1
    a = list(map(int, input[ptr:ptr+n]))
    ptr += n
    
    min_val = min(a)
    min_idx = a.index(min_val)
    min_node = min_idx + 1  # Convert to 1-based
    
    edges = []
    # Add regular edges from min_node to all other nodes
    for i in range(1, n+1):
        if i != min_node:
            cost = a[min_idx] + a[i-1]
            edges.append((cost, min_node, i))
    
    # Add special offers
    for _ in range(m):
        x = int(input[ptr])
        ptr += 1
        y = int(input[ptr])
        ptr += 1
        w = int(input[ptr])
        ptr += 1
        edges.append((w, x, y))
    
    # Sort edges by cost
    edges.sort()
    
    dsu = DSU(n)
    total = 0
    count = 0
    for edge in edges:
        w, u, v = edge
        if dsu.find(u) != dsu.find(v):
            dsu.union(u, v)
            total += w
            count += 1
            if count == n - 1:
                break
    print(total)

if __name__ == "__main__":
```

1. **DSU (Disjoint Set Union)**: This data structure helps efficiently manage and merge connected components, ensuring we can quickly determine if adding an edge will form a cycle.
2. **Edge Generation**: By generating edges from the minimum value vertex to all others, we ensure we consider the cheapest regular connections.
3. **Sorting and Processing Edges**: By sorting edges by cost and processing them in order, Kruskal's algorithm efficiently constructs the MST, ensuring the minimum total cost while avoiding cycles.

This approach efficiently combines the regular edges and special offers to find the optimal solution using MST algorithms, ensuring the graph is connected with minimal cost.
