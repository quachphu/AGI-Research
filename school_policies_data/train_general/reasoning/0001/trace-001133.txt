To solve this problem, we need to determine the maximum possible sum of values of blocks that can be stacked in a tower such that each block in the tower satisfies the condition that the sum of the weights of the blocks above it does not exceed its solidness.

### Approach
1. **Problem Analysis**: The key challenge is to select and order the blocks such that each block's solidness constraint is respected. The order of blocks is crucial because the sum of weights above a block depends on the blocks stacked above it.

2. **Dynamic Programming (DP) Insight**: We use a dynamic programming approach where the state tracks the maximum value achievable with a given sum of weights of blocks above the current block. The DP state transitions are managed by iterating through each block and considering whether to include it in the tower.

3. **Sorting Strategy**: To optimize the DP transitions, we sort the blocks based on the sum of their solidness and weight (s_i + w_i) in ascending order. This sorting helps in efficiently managing the constraints as we process each block from top to bottom in the stack.

4. **State Management**: The DP dictionary is used to track the maximum value for each possible sum of weights of blocks above the current block. For each block, we update the DP state to include the new possible sums and values if the block is added to the tower.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    blocks = []
    for _ in range(N):
        w = int(input[idx])
        s = int(input[idx+1])
        v = int(input[idx+2])
        blocks.append((s, w, v))
        idx += 3
    
    # Sort blocks by s_i + w_i in ascending order
    blocks.sort(key=lambda x: x[0] + x[1])
    
    dp = {0: 0}
    
    for s_i, w_i, v_i in blocks:
        new_items = {}
        for current_sum in dp:
            if current_sum <= s_i:
                new_sum = current_sum + w_i
                new_val = dp[current_sum] + v_i
                if new_sum in new_items:
                    if new_val > new_items[new_sum]:
                        new_items[new_sum] = new_val
                else:
                    new_items[new_sum] = new_val
        
        # Merge new_items into dp, keeping the maximum value for each sum
        for new_sum in new_items:
            if new_sum in dp:
                if new_items[new_sum] > dp[new_sum]:
                    dp[new_sum] = new_items[new_sum]
            else:
                dp[new_sum] = new_items[new_sum]
    
    print(max(dp.values()))

if __name__ == '__main__':
    main()
```

4. **Processing Each Block**: For each block, we check all current sums in the DP dictionary. If the sum is within the block's solidness constraint, we compute the new sum and value if the block is included and update the DP dictionary accordingly.
5. **Result Calculation**: After processing all blocks, the maximum value in the DP dictionary gives the solution.
