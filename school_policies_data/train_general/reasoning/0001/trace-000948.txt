To solve this problem, we need to determine the minimum cost of painting a 3D table such that no cell is visible from the top. This involves ensuring that each cell in the base layer is covered by at least one painted cell in the layers above, while adhering to constraints on the maximum number of cells that can be painted in each layer and their associated costs.

### Approach
1. **Problem Analysis**: The goal is to cover all cells in the base layer (N x M) by painting cells in the given layers such that the total cost is minimized. Each layer has a maximum number of cells that can be painted and a cost per cell. If the sum of all possible painted cells across all layers is less than the required number of cells (N x M), it is impossible to cover the base layer.

2. **Greedy Strategy**: To minimize the cost, we should prioritize using cells from layers with the lowest cost per cell first. This is because using cheaper cells first will reduce the overall cost.

3. **Steps**:
   - Calculate the total number of cells required (N x M).
   - Check if the sum of all possible cells across all layers meets or exceeds the required number of cells. If not, output "Impossible".
   - Sort the layers by their cost per cell in ascending order.
   - Use cells from the cheapest layers first until the required number of cells is met.

### Solution Code
```python
n, m, h = map(int, input().split())
required = n * m
layers = []
sum_t = 0

for _ in range(h):
    t, c = map(int, input().split())
    layers.append((c, t))
    sum_t += t

if sum_t < required:
    print("Impossible")
else:
    layers.sort()
    total_cost = 0
    remaining = required
    for c, t in layers:
        if remaining <= 0:
            break
        take = min(t, remaining)
        total_cost += take * c
        remaining -= take
    print(total_cost)
```

### Explanation
1. **Reading Input**: The input consists of the dimensions of the base layer (N, M), the number of layers (H), and for each layer, the maximum number of cells that can be painted (Tk) and the cost per cell (Ck).

2. **Sum Check**: We first check if the total number of paintable cells across all layers is sufficient to cover the base layer. If not, we immediately output "Impossible".

3. **Sorting Layers**: Layers are sorted by their cost per cell in ascending order to ensure we use the cheapest cells first.

4. **Greedy Selection**: We iterate through the sorted layers, using as many cells as possible from each layer (up to its limit) until the required number of cells is met. The total cost is accumulated based on the number of cells used from each layer and their respective costs.

This approach ensures that we achieve the minimum cost by leveraging the cheapest options first, efficiently covering all required cells.
