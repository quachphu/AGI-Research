To solve this problem, we need to count the number of U-shaped parabolas (of the form y = x² + bx + c) that pass through at least two given points and do not contain any other points strictly above them. The key insight is to use computational geometry concepts, specifically the upper envelope of lines in a transformed plane, to efficiently determine valid parabolas.

### Approach
1. **Preprocess Points**: For each x-coordinate, retain only the point with the highest value of (y - x²). This is because for a given x, the highest such value will dominate in forming the upper envelope.
2. **Transform Points to Lines**: Each point (x, y) is transformed into a line in the (b, c) plane, represented as c = -x*b + (y - x²).
3. **Sort Lines**: Sort these lines by their slope (which is -x) in increasing order.
4. **Compute Upper Envelope**: Use the convex hull trick to compute the upper envelope of these lines. This envelope represents the highest possible values of c for any b, ensuring no other points lie above the corresponding parabola.
5. **Count Valid Pairs**: The number of valid parabolas is the number of consecutive line pairs in the upper envelope.

            m_last, k_last = deque[-1]
            m_prev, k_prev = deque[-2]
            a = (k_prev - k_new)
            b = (m_last - m_prev)
            c = (k_prev - k_last)
            d = (m_new - m_prev)
            if a * b <= c * d:
                deque.pop()
            else:
                break
        deque.append((m_new, k_new))

    print(max(0, len(deque) - 1))
