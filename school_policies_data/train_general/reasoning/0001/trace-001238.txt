To solve this problem, we need to split a sequence into exactly `k` contiguous parts such that the sum of each part's modulo `p` score is maximized. The approach involves dynamic programming (DP) with optimization to efficiently compute the maximum possible score.

### Approach
1. **Prefix Sum Modulo Calculation**: Compute the prefix sums modulo `p` to efficiently calculate the sum of any subarray modulo `p`.
2. **Dynamic Programming Initialization**: Initialize a DP table where `dp[j][i]` represents the maximum score achievable by splitting the first `i` elements into `j` parts.
3. **Max Previous Array Optimization**: Use an array `max_prev` to track the maximum DP values for each possible modulo result from the previous split, allowing efficient computation of the current DP values.

### Solution Code
```python
n, k, p = map(int, input().split())
A = list(map(int, input().split()))

prefix_sum = [0] * (n + 1)
for i in range(1, n + 1):
    prefix_sum[i] = (prefix_sum[i-1] + A[i-1]) % p

INF = float('-inf')
dp = [[INF] * (n + 1) for _ in range(k + 1)]

# Initialize for j=1
for i in range(1, n + 1):
    dp[1][i] = prefix_sum[i]

for j in range(2, k + 1):
    max_prev = [INF] * p
    for i in range(j, n + 1):
        m = i - 1
        s_m = prefix_sum[m]
        current_val = dp[j-1][m]
        if current_val > max_prev[s_m]:
            max_prev[s_m] = current_val
        
        s_i = prefix_sum[i]
        current_max = INF
        for s in range(p):
            if max_prev[s] == INF:
                continue
            temp = max_prev[s] + (s_i - s) % p
            if temp > current_max:
                current_max = temp
        dp[j][i] = current_max

print(dp[k][n])
```

### Explanation
1. **Prefix Sum Calculation**: The prefix sums modulo `p` are computed to quickly determine the sum of any subarray modulo `p`.
2. **DP Initialization**: The first row of the DP table is initialized with the prefix sums modulo `p` for splits into 1 part.
3. **Max Previous Array**: For each possible split count `j`, the `max_prev` array keeps track of the maximum DP values for each modulo result from the previous splits. This allows efficient computation of the current DP values by considering all possible previous splits.
4. **DP Transition**: For each possible split count `j` and each position `i`, the maximum score is computed by considering all possible previous splits and their contributions to the current score.

This approach ensures that we efficiently compute the maximum score using dynamic programming with optimized space and time complexity, making it feasible for large input sizes.
