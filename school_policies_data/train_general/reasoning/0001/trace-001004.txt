To solve this problem, we need to determine the minimum number of steps required to adjust the position of point A (initially at coordinate `n`) such that there exists an integer point B on the OX-axis where the absolute difference between the distance from the origin O to B and the distance from A to B is exactly `k`.

### Approach
1. **Understanding the Problem**: The problem requires us to find an integer point B such that the absolute difference between the distances from O to B and from A to B is `k`. If this is not possible with the initial position of A, we need to adjust A's position by moving it incrementally either left or right.

2. **Key Insight**:
   - If `k` is greater than `n`, we must move A to the right until its new position `n'` equals `k`, requiring `k - n` steps.
   - If `k` is less than or equal to `n`, check the parity of `n - k`:
     - If `n - k` is even, no steps are needed as we can find a valid B.
     - If `n - k` is odd, we need exactly 1 step to adjust `n` to make `n' - k` even.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    if k <= n:
        if (n - k) % 2 == 0:
            print(0)
        else:
            print(1)
    else:
        print(k - n)
```

### Explanation
- **Case 1: `k > n`**: Moving A to the right until `n'` equals `k` is the only way to achieve the required condition, resulting in `k - n` steps.
- **Case 2: `k ≤ n`**:
  - **Even Difference**: If `n - k` is even, the point B can be found at `(n - k) / 2` or `(n + k) / 2`, requiring no steps.
  - **Odd Difference**: If `n - k` is odd, adjusting A by 1 step (either incrementing or decrementing) will make the difference even, thus requiring 1 step.

This approach efficiently determines the minimum steps required by leveraging parity checks and simple arithmetic, ensuring optimal performance even for large input values.
