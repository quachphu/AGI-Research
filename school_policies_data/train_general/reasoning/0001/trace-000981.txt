To solve this problem, we need to find the maximum possible sum of the digits of a positive integer that is not greater than a given number \( N \). The key insight is to consider numbers that have as many 9's as possible, as they contribute the highest individual digit sum. 

### Approach
1. **Initial Digit Sum**: Calculate the sum of the digits of \( N \) itself.
2. **Generate Candidates**: For each digit in \( N \), generate a candidate number by reducing the current digit by 1 and setting all subsequent digits to 9. This ensures the candidate is the largest possible number less than \( N \) with a potentially higher digit sum.
3. **Compare Sums**: Compute the digit sum for each candidate and compare it with the initial sum to determine the maximum.

### Solution Code
```python
def max_digit_sum():
    N = input().strip()
    max_sum = sum(int(c) for c in N)
    for i in range(len(N)):
        if N[i] == '0':
            continue
        current = list(N)
        current[i] = str(int(current[i]) - 1)
        for j in range(i + 1, len(current)):
            current[j] = '9'
        current_sum = sum(int(c) for c in current)
        if current_sum > max_sum:
            max_sum = current_sum
    print(max_sum)

max_digit_sum()
```

### Explanation
1. **Reading Input**: The input number \( N \) is read as a string to handle very large values efficiently.
2. **Initial Sum Calculation**: The sum of the digits of \( N \) is computed first.
3. **Generating Candidates**: For each digit in \( N \):
   - If the digit is '0', skip it (as reducing it would result in a negative number).
   - Otherwise, reduce the digit by 1 and set all subsequent digits to '9'.
4. **Sum Comparison**: The digit sum of each candidate is computed and compared with the current maximum sum. The highest sum encountered is the result.

This approach efficiently generates potential candidates and ensures we find the maximum digit sum without exceeding the given number \( N \). The complexity is linear with respect to the number of digits in \( N \), making it suitable for large values up to \( 10^{16} \).
