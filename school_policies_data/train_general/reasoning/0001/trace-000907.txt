To solve this problem, we need to count the number of pairs (i, j) in an array where the sum of elements at these indices falls within a given range [l, r]. The solution must efficiently handle large input sizes up to 200,000 elements.

### Approach
1. **Sort the Array**: Sorting the array allows us to use binary search techniques to efficiently find the valid pairs.
2. **Binary Search for Range**: For each element in the sorted array, use binary search to determine the range of subsequent elements that form valid sums within the given range [l, r].
3. **Count Valid Pairs**: For each element, calculate the number of valid subsequent elements using the binary search results and sum these counts to get the total number of valid pairs.

### Solution Code
```python
import bisect
import sys

def count_pairs():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    for _ in range(t):
        n = int(data[idx])
        l = int(data[idx+1])
        r = int(data[idx+2])
        idx +=3
        a = list(map(int, data[idx:idx+n]))
        idx +=n
        a.sort()
        count = 0
        for i in range(n):
            target_low = l - a[i]
            target_high = r - a[i]
            left = bisect.bisect_left(a, target_low, i+1)
            right = bisect.bisect_right(a, target_high, i+1)
            count += (right - left)
        print(count)

count_pairs()
```

### Explanation
1. **Sorting**: The array is sorted to leverage binary search for efficient range queries.
2. **Binary Search**: For each element `a[i]`, we determine the range of subsequent elements that can form valid sums. Using `bisect_left`, we find the smallest index where elements start being greater than or equal to `l - a[i]`. Using `bisect_right`, we find the first index where elements exceed `r - a[i]`.
3. **Counting Valid Elements**: The difference between the indices found by `bisect_left` and `bisect_right` gives the count of valid subsequent elements for each `a[i]`, which is accumulated to get the total count of valid pairs.

This approach ensures that we efficiently count valid pairs in O(n log n) time per test case, making it suitable for large input sizes.
