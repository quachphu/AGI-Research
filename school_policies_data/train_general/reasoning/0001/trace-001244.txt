To solve this problem, we need to arrange community sizes in non-decreasing order to meet the requirement of increasing pressure on Hogwarts. The solution involves sorting each list of community sizes and printing them in the sorted order.

### Approach
1. **Input Reading**: Read the number of test cases, T.
2. **Processing Each Test Case**:
   - For each test case, read the number of communities, n.
   - Read the list of community sizes.
   - Sort the list in non-decreasing order.
3. **Output the Result**: Print the sorted list for each test case, with elements separated by spaces.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline().strip())
        x = list(map(int, sys.stdin.readline().strip().split()))
        x.sort()
        print(' '.join(map(str, x)))

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency, especially with large input sizes.
- **Sorting**: Each list of community sizes is sorted using Python's built-in sort function, which sorts the list in non-decreasing order.
- **Output**: The sorted list is converted to a space-separated string and printed for each test case.

This approach ensures that the communities are sent in a sequence where each subsequent community is at least as large as the previous one, thereby maintaining the required pressure on Hogwarts. The time complexity for sorting each list is O(n log n), where n is the number of communities, making the solution efficient even for large inputs.
