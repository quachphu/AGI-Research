class FenwickTree:
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (self.n +1)  # 1-based indexing
    
    def update(self, idx, delta=1):
        while idx <= self.n:
            self.tree[idx] += delta
            idx += idx & -idx
    
    def query(self, idx):
        res =0
        while idx >0:
            res += self.tree[idx]
            idx -= idx & -idx
        return res

            idx += idx & -idx
    
    def query(self, idx):
        res =0

            res += self.tree[idx]
            idx -= idx & -idx

To solve this problem, we need to determine the number of triplets (i, j, k) such that i < j < k and the elements at these positions satisfy a_i > a_j > a_k. Given the constraints, a brute-force approach is infeasible, so we use an optimized approach involving Fenwick Trees (Binary Indexed Trees) to efficiently compute the required counts.

### Approach
1. **Rank Compression**: Since the elements are distinct, we can compress their values into ranks based on their sorted order. This helps in efficiently querying and updating using Fenwick Trees.
2. **Left Count Calculation**: For each element, compute how many elements to its left are greater than the current element using a Fenwick Tree.
3. **Right Count Calculation**: For each element, compute how many elements to its right are smaller than the current element using another Fenwick Tree.
4. **Triplet Count Calculation**: For each element, the number of valid triplets where it is the middle element is the product of its left count and right count. Sum these products to get the total weakness.

### Solution Code
```python
import sys

class FenwickTree:
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (self.n + 1)  # 1-based indexing
    
    def update(self, idx):
        while idx <= self.n:
            self.tree[idx] += 1
            idx += idx & -idx
    
    def query(self, idx):
        res = 0
        while idx > 0:
            res += self.tree[idx]
            idx -= idx & -idx
        return res

def main():
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    
    sorted_a = sorted(a)
    rank = {v: i+1 for i, v in enumerate(sorted_a)}
    ranks = [rank[x] for x in a]
    
    # Compute left counts
    max_rank = n
    ft_left = FenwickTree(max_rank)
    left_counts = []
    for x in a:
        r = rank[x]
        total = ft_left.query(max_rank)
        sum_r = ft_left.query(r)
        left = total - sum_r
        left_counts.append(left)
        ft_left.update(r)
    
    # Compute right counts
    ft_right = FenwickTree(max_rank)
    right_counts = []
    for x in reversed(a):
        r = rank[x]
        sum_r_minus_1 = ft_right.query(r - 1)
        right_counts.append(sum_r_minus_1)
        ft_right.update(r)
    right_counts = right_counts[::-1]
    
    total = 0
    for l, r in zip(left_counts, right_counts):
        total += l * r
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Rank Compression**: Convert each element to its rank based on the sorted array. This allows us to handle large values efficiently by compressing them into a smaller range.
2. **Left Count Calculation**: Using a Fenwick Tree, iterate through the array from left to right. For each element, query the number of elements greater than the current element seen so far.
3. **Right Count Calculation**: Similarly, iterate from right to left using another Fenwick Tree to count the number of elements smaller than the current element seen so far.
4. **Triplet Count**: Multiply the left and right counts for each element to get the number of valid triplets where the element is the middle one. Sum these values to get the total weakness.

This approach efficiently computes the result in O(n log n) time, making it suitable for large input sizes up to 1,000,000.
