To solve this problem, we need to determine if there exist non-empty substrings from two given strings such that their concatenation forms a palindromic string. The key insight here is that the presence of at least one common character between the two strings guarantees the existence of such substrings.

### Approach
1. **Problem Analysis**: For two strings A and B, if there exists at least one common character between them, we can always form a palindromic string by choosing that common character as both substrings from A and B. This is because the concatenation of two identical characters forms a palindrome (e.g., "aa").
2. **Key Insight**: The problem reduces to checking if there is any intersection between the characters of the two strings. If there is a common character, the answer is "Yes"; otherwise, it is "No".
3. **Algorithm**:
   - For each test case, read the two strings A and B.
   - Convert each string into a set of characters to identify unique characters.
   - Check if there is any intersection between these two sets of characters.
   - Print "Yes" if there is an intersection, otherwise print "No".

### Solution Code
```python
def check_palindrome_possible():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        A = input[idx]
        idx += 1
        B = input[idx]
        idx += 1
        set_a = set(A)
        set_b = set(B)
        if set_a & set_b:
            print("Yes")
        else:
            print("No")

check_palindrome_possible()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list for efficient processing.
2. **Processing Each Test Case**: For each test case, the strings A and B are read sequentially.
3. **Character Set Intersection**: By converting each string into a set of characters, we efficiently check for any common characters using set intersection.
4. **Result Determination**: If there is a common character, the result is "Yes"; otherwise, it is "No".

This approach ensures that we efficiently determine the possibility of forming a palindromic string by leveraging set operations, which are optimal for membership checks. The solution runs in O(n + m) time complexity per test case, where n and m are the lengths of strings A and B, respectively, due to the conversion of strings to sets. This is efficient given the problem constraints.
