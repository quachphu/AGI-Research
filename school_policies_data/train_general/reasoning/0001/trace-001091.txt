To solve this problem, we need to determine the midpoint time of a contest given its start and end times. The contest duration is guaranteed to be an even number of minutes and to occur within a single day. 

### Approach
1. **Convert Time to Minutes**: Convert both the start and end times from hours and minutes into total minutes since midnight. This simplifies arithmetic operations.
2. **Calculate Midpoint**: Compute the midpoint by averaging the total minutes of the start and end times. Since the contest duration is even, this average will be an integer.
3. **Convert Back to Hours and Minutes**: Convert the midpoint total minutes back into hours and minutes format.
4. **Format Output**: Ensure the output is formatted with leading zeros for both hours and minutes to maintain the hh:mm format.

### Solution Code
```python
def main():
    start_time = input().strip()
    end_time = input().strip()
    
    h1, m1 = map(int, start_time.split(':'))
    h2, m2 = map(int, end_time.split(':'))
    
    start_min = h1 * 60 + m1
    end_min = h2 * 60 + m2
    
    midpoint_min = (start_min + end_min) // 2
    
    h3 = midpoint_min // 60
    m3 = midpoint_min % 60
    
    print(f"{h3:02d}:{m3:02d}")

main()
```

### Explanation
1. **Reading Input**: The start and end times are read as strings and split into hours and minutes using the colon (':') as a delimiter.
2. **Conversion to Minutes**: Each time is converted into total minutes since midnight. For example, 10:30 becomes 630 minutes (10 * 60 + 30).
3. **Midpoint Calculation**: The midpoint is found by averaging the total minutes of the start and end times. This is done using integer division to ensure the result is an integer.
4. **Conversion Back to Hours and Minutes**: The midpoint in minutes is converted back to hours and minutes. Hours are obtained using integer division by 60, and minutes using the modulus operator.
5. **Formatted Output**: The result is formatted to ensure two digits for both hours and minutes, using leading zeros if necessary, and printed in the required hh:mm format.

This approach efficiently handles all edge cases and ensures the correct midpoint time is calculated and displayed in the specified format.
