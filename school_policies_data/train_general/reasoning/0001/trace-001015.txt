To solve this problem, we need to split the integers from 1 to n into two non-empty groups such that the absolute difference of their sums is minimized. The solution involves a systematic approach to determine the optimal split using a greedy algorithm.

### Approach
1. **Calculate Total Sum**: Compute the sum of all integers from 1 to n using the formula \( S = \frac{n(n+1)}{2} \).
2. **Determine Minimum Difference**: The minimum possible difference between the two groups is \( S \mod 2 \). If \( S \) is even, the difference is 0; if odd, the difference is 1.
3. **Target Sum Calculation**: The target sum for each group is \( \frac{S - \text{difference}}{2} \). This ensures that the groups' sums are as close as possible.
4. **Greedy Selection**: Starting from the largest integer, select numbers to form a subset whose sum approaches the target sum. This greedy approach ensures that we maximize the sum without exceeding the target.

### Solution Code
```python
n = int(input())
total = n * (n + 1) // 2
diff = total % 2
target = (total - diff) // 2

subset = []
current_sum = 0

for i in range(n, 0, -1):
    if current_sum + i <= target:
        subset.append(i)
        current_sum += i

print(diff)
print(len(subset), end=' ')
print(' '.join(map(str, subset)))
```

### Explanation
1. **Reading Input**: The input integer `n` is read from standard input.
2. **Total Sum Calculation**: The total sum of integers from 1 to `n` is computed using the formula \( \frac{n(n+1)}{2} \).
3. **Difference Calculation**: The difference is determined using modulo operation on the total sum.
4. **Target Sum**: The target sum for each group is derived by adjusting the total sum with the calculated difference.
5. **Greedy Algorithm**: Starting from the largest integer (n), we iteratively add integers to the subset until the sum reaches the target. This ensures that the largest possible numbers are included first, minimizing the remaining sum needed.
6. **Output**: The minimum difference is printed first, followed by the size of the subset and the elements of the subset.

This approach efficiently splits the integers into two groups with the smallest possible absolute difference in sums, leveraging a greedy strategy to achieve the optimal solution.
