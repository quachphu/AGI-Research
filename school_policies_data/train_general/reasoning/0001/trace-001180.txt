To solve this problem, we need to determine the minimal number of wooden bars of length `n` required to construct frames for two equal doors. Each door frame consists of two vertical sides of length `a` and one top side of length `b`. Therefore, we need a total of 4 vertical sides (4a) and 2 top sides (2b).

### Approach
1. **Immediate Check**: First, check if a single bar can accommodate all required pieces. If the sum of the lengths of all pieces (4a + 2b) is less than or equal to `n`, then only one bar is needed.
2. **Generate Valid Combinations**: If a single bar is insufficient, generate all possible valid combinations of vertical (a) and top (b) pieces that can fit into a single bar. Each combination (x, y) must satisfy `x*a + y*b <= n`.
3. **Breadth-First Search (BFS)**: Use BFS to explore the minimal number of bars required. The BFS tracks the current count of vertical and top pieces collected, and the number of bars used. The goal is to find the minimal number of bars such that we collect at least 4 vertical pieces and 2 top pieces.

### Solution Code
```python
from collections import deque

n = int(input())
a = int(input())
b = int(input())

# Check if all parts fit into one bar
total = 4 * a + 2 * b
if total <= n:
    print(1)
else:
    # Generate all possible (x, y) pairs that fit into a single bar, excluding (0,0)
    pairs = []
    max_x = n // a
    for x in range(max_x + 1):
        remaining = n - x * a
        if remaining < 0:
            continue
        max_y = remaining // b
        for y in range(max_y + 1):
            if x == 0 and y == 0:
                continue
            pairs.append((x, y))

    # BFS to find minimal bars
    visited = set()
    queue = deque()
    queue.append((0, 0, 0))
    visited.add((0, 0, 0))
    found = False

    while queue:
        current_a, current_b, k = queue.popleft()

        if current_a >= 4 and current_b >= 2:
            print(k)
            found = True
            break

        if k >= 6:
            continue  # No need to process further than 6 bars

        for dx, dy in pairs:
            new_a = min(current_a + dx, 4)
            new_b = min(current_b + dy, 2)
            new_k = k + 1
            state = (new_a, new_b, new_k)
            if state not in visited and new_k <= 6:
                visited.add(state)
                queue.append(state)

    if not found:
        print(6)
```

3. **BFS Exploration**: Using BFS, the code explores all possible ways to accumulate the required pieces (4 vertical and 2 top).
