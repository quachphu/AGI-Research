To solve this problem, we need to find a stable marriage matching between n men and n women such that no two people (a man and a woman) prefer each other over their current partners. This problem can be efficiently solved using the Gale-Shapley algorithm, which ensures a man-optimal and woman-pessimal stable matching.

### Approach
1. **Input Parsing**: Read the number of test cases. For each test case, read the preferences of each woman and man.
2. **Data Structures**: Use dictionaries to store the preferences of each woman and man. This allows quick lookups to determine the preference rank of any man or woman.
3. **Gale-Shapley Algorithm**: Implement the algorithm where men propose to women in the order of their preference. Women either accept the proposal if they are not engaged or if they prefer the new proposer over their current partner. If a woman accepts a new proposal, her previous partner becomes free and is added back to the list of free men.
4. **Tracking Engagements**: Use arrays to track the current engagements of men and women. This helps in efficiently determining if a man or woman is already engaged and to whom.

### Solution Code
```python
import sys
from collections import deque

def solve():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        women_rank = [dict() for _ in range(n + 1)]  # 1-based indexing
        for _ in range(n):
            w = int(input[ptr])
            prefs = list(map(int, input[ptr + 1:ptr + 1 + n]))
            ptr += 1 + n
            women_rank[w] = {m: idx for idx, m in enumerate(prefs)}
        men_prefs = [[] for _ in range(n + 1)]  # 1-based indexing
        for _ in range(n):
            m = int(input[ptr])
            prefs = list(map(int, input[ptr + 1:ptr + 1 + n]))
            ptr += 1 + n
            men_prefs[m] = prefs
        # Initialize data structures
        next_proposal = [0] * (n + 1)
        current_engagement = [None] * (n + 1)
        wife = [None] * (n + 1)
        free_men = deque(range(1, n + 1))
        while free_men:
            m = free_men.popleft()
            if next_proposal[m] >= len(men_prefs[m]):
                continue
            w = men_prefs[m][next_proposal[m]]
            next_proposal[m] += 1
            if current_engagement[w] is None:
                # Engage
                current_engagement[w] = m
                wife[m] = w
            else:
                current_m = current_engagement[w]
                if women_rank[w][m] < women_rank[w][current_m]:
                    # Replace current_m with m
                    current_engagement[w] = m
                    wife[m] = w
                    # Free the current_m
                    wife[current_m] = None
                    free_men.append(current_m)
            # Check if m is still free and has more proposals to make
            if wife[m] is None and next_proposal[m] < len(men_prefs[m]):
                free_men.append(m)
        # Output the results
        for m in range(1, n + 1):
            print(m, wife[m])

solve()

This ensures that each man proposes until he finds a stable match, and each woman always has the best possible partner she can get given the proposals.
