To solve this problem, we need to determine the favorite restaurant of Paroothi's crush based on the number of days she visited each restaurant. The favorite restaurant is the one she visited the most frequently, and in case of a tie, the smallest numbered restaurant among those with the highest visits.

### Approach
1. **Input Reading**: Read the number of days (N) and the number of restaurants (K). Then, read the list of restaurants visited each day.
2. **Frequency Counting**: Use a counter to keep track of how many times each restaurant is visited.
3. **Determine Maximum Visits**: Identify the maximum number of visits any restaurant has.
4. **Resolve Ties**: Among the restaurants with the maximum visits, select the smallest numbered one.

### Solution Code
```python
import sys
from collections import Counter

def main():
    # Read the first line containing N and K
    n, k = map(int, sys.stdin.readline().split())
    
    # Read the list of restaurant visits
    a = list(map(int, sys.stdin.readline().split()))
    
    # Count the occurrences of each restaurant
    counts = Counter(a)
    
    # Find the maximum frequency
    max_count = max(counts.values())
    
    # Find the smallest restaurant with the maximum frequency
    min_restaurant = min(restaurant for restaurant, count in counts.items() if count == max_count)
    
    print(min_restaurant)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline` for efficiency, especially given the potential size of the input.
2. **Counting Frequencies**: The `Counter` from the `collections` module is used to efficiently count the visits to each restaurant.
3. **Finding Maximum Visits**: The maximum value from the counter's values is determined to identify the highest number of visits.
4. **Selecting the Smallest Restaurant**: A generator expression is used to filter restaurants with the maximum visits and then find the smallest one using the `min` function.

This approach ensures that we efficiently handle large input sizes up to the constraints provided, while correctly resolving ties in favor of the smallest restaurant number.
