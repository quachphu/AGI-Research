### Approach
1. **Generate All Rotations**: For each dice, generate all 24 possible rotations. This is done by rotating the dice around different axes to cover all possible orientations.
2. **Check for Duplicates**: For each dice, check if any of its rotations have already been seen. If a duplicate is found, print "No" and exit. If no duplicates are found after processing all dice, print "Yes".

### Solution Code
```python
def generate_rotations(dice):
    rotations = []
    current = list(dice)
    for _ in range(6):
        for _ in range(4):
            rotations.append(tuple(current))
            # Rotate around y-axis (right turn)
            current = [
                current[0],
                current[2],
                current[4],
                current[1],
                current[3],
                current[5],
            ]
        # Rotate around x-axis (forward roll)
        current = [
            current[1],
            current[5],
            current[2],
            current[3],
            current[0],
            current[4],
        ]
    return rotations

n = int(input())
dices = [tuple(map(int, input().split())) for _ in range(n)]

seen = set()

for dice in dices:
    rotations = generate_rotations(dice)
    for rot in rotations:
        if rot in seen:
            print("No")
            exit()
    for rot in rotations:
        seen.add(rot)

print("Yes")
```

### Explanation
1. **Reading Input**: The number of dice and their face values are read from the input.
2. **Generating Rotations**: For each dice, generate all 24 possible rotations using combinations of rotations around the x-axis and y-axis.
3. **Checking for Duplicates**: Each rotation of the current dice is checked against previously seen rotations. If a match is found, it means two dice are the same, and we print "No" and exit immediately. If no duplicates are found after processing all dice, "Yes" is printed.

This approach efficiently checks for duplicate dice by leveraging precomputed rotations and a set for quick lookups, ensuring the solution is both correct and optimal.
