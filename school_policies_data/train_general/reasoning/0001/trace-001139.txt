To solve this problem, we need to create a program that reads a text from standard input, extracts all embedded positive integers, sums them up, and outputs the result as a PIN. The key challenge is to correctly identify and sum only the positive integers, excluding any zeros or sequences that convert to zero.

### Approach
1. **Reading Input**: The input is read line by line from standard input. Each line may contain alphanumeric characters, symbols, spaces, or be a blank line.
2. **Extracting Numbers**: Using regular expressions, we identify sequences of digits in each line. These sequences are then converted to integers.
3. **Filtering Positive Integers**: Only positive integers (greater than zero) are considered for the sum. This ensures that zeros and sequences that convert to zero (like "0000") are excluded.
4. **Summing Values**: The valid integers from all lines are summed to form the final PIN, which is then printed.

### Solution Code
```python
import re
import sys

def main():
    total = 0
    for line in sys.stdin:
        for digits in re.findall(r'\d+', line):
            num = int(digits)
            if num > 0:
                total += num
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The program reads each line from standard input using a loop over `sys.stdin`, which handles multiple lines efficiently.
2. **Regular Expression Matching**: The regular expression `\d+` is used to find all sequences of digits in each line. This helps in identifying both standalone numbers and numbers embedded within text.
3. **Conversion and Filtering**: Each digit sequence is converted to an integer. We then check if the integer is positive (greater than zero) before adding it to the total sum.
4. **Summing and Output**: The accumulated sum of all valid integers is printed as the final PIN.

This approach ensures that we correctly handle all edge cases, including lines with no numbers, numbers with leading zeros, and zeros themselves, providing an accurate and efficient solution.
