To solve this problem, we need to determine the minimum number of taxis required to transport groups of schoolchildren, where each group must stay together, and each taxi can carry at most four passengers. The solution involves efficiently combining groups to minimize the number of taxis used.

### Approach
1. **Count Group Sizes**: First, count the number of groups of each size (1, 2, 3, and 4 children).
2. **Handle Groups of 4**: Each group of 4 children requires exactly one taxi.
3. **Handle Groups of 3**: Each group of 3 children needs one taxi. If possible, pair each group of 3 with one group of 1 to utilize the taxi capacity fully.
4. **Handle Groups of 2**: Pair groups of 2 into taxis. If there's an odd group of 2 left, use one taxi for it and try to add up to two groups of 1 if available.
5. **Handle Remaining Groups of 1**: Combine the remaining groups of 1 into taxis, each holding up to 4 children.

### Solution Code
```python
n = int(input())
s = list(map(int, input().split()))

count_1 = s.count(1)
count_2 = s.count(2)
count_3 = s.count(3)
count_4 = s.count(4)

taxis = count_4 + count_3

# Deduct the 1's used with 3's
count_1 = max(count_1 - count_3, 0)

# Handle pairs of 2's
taxis += count_2 // 2
remaining_2 = count_2 % 2

# Handle remaining 2 and possible 1's
if remaining_2:
    taxis += 1
    count_1 = max(count_1 - 2, 0)

# Handle remaining 1's
taxis += (count_1 + 3) // 4

print(taxis)
```

### Explanation
1. **Count Groups**: We start by counting how many groups there are of each size (1, 2, 3, 4).
2. **Groups of 4**: Each group of 4 directly uses one taxi.
3. **Groups of 3**: Each group of 3 uses one taxi. Any remaining groups of 1 after pairing with groups of 3 are adjusted.
4. **Groups of 2**: Groups of 2 are paired into taxis. If there's an unpaired group of 2, it uses a taxi, and up to two groups of 1 can join if available.
5. **Remaining Groups of 1**: The remaining groups of 1 are combined into taxis, with each taxi holding up to 4 children.

This approach ensures that we use the minimum number of taxis by efficiently combining groups where possible and handling each group size appropriately.
