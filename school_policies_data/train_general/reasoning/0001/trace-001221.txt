To solve this problem, we need to maximize the sum of query results by reordering the elements of an array such that the most frequent positions in queries are assigned the largest values. This approach ensures that the highest values contribute the most to the sum of the queries.

### Approach
1. **Frequency Calculation**: Determine how many times each position in the array is covered by the given queries. This is efficiently done using a difference array technique to avoid iterating through each query range.
2. **Sorting**: Sort the array elements in descending order and the computed frequencies of each position in descending order.
3. **Optimal Assignment**: Multiply the largest elements of the sorted array with the highest frequencies to maximize the sum of the query results.

### Solution Code
```python
import sys

def main():
    n, q = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    delta = [0] * (n + 2)  # 1-based to n+1

    for _ in range(q):
        l, r = map(int, sys.stdin.readline().split())
        delta[l] += 1
        if r + 1 <= n:
            delta[r + 1] -= 1

    # Compute frequencies
    freq = []
    current = 0
    for i in range(1, n + 1):
        current += delta[i]
        freq.append(current)

    # Sort the array and frequencies in descending order
    a.sort(reverse=True)
    freq.sort(reverse=True)

    # Calculate the total sum
    total = sum(x * y for x, y in zip(a, freq))
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin` for efficiency, especially given the constraints.
2. **Difference Array**: A difference array `delta` is used to mark the start and end of each query range. This allows us to compute the frequency of each position in O(n + q) time.
3. **Frequency Calculation**: By computing the prefix sum of the difference array, we get the frequency of each position in the array.
4. **Sorting**: Both the array elements and the frequencies are sorted in descending order to align the largest values with the highest frequencies.
5. **Sum Calculation**: The sum of the product of corresponding elements from the sorted array and frequencies gives the maximum possible sum of the queries after optimal reordering.

This approach ensures that we efficiently handle the constraints and maximize the sum by leveraging sorting and frequency analysis.
