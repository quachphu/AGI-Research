To solve this problem, we need to determine the size of the connected component for each impassable cell ('*') if it were converted to an empty cell ('.'). The solution involves preprocessing the grid to identify connected components and their sizes, then using this information to efficiently compute the result for each '*' cell.

### Approach
1. **Preprocess Connected Components**: Use BFS to identify all connected components of empty cells ('.') in the grid. Each component is assigned a unique identifier, and we store the size of each component.
2. **Calculate Component Sizes for '*' Cells**: For each '*' cell, consider it as an empty cell and check its four neighboring cells. Collect the unique component IDs of these neighboring cells and sum their sizes. The result for the '*' cell is the sum of these sizes plus 1 (for the cell itself), modulo 10.

                queue.append((i, j))
                group[i][j] = current_group
                count = 1
                while queue:
                    x, y = queue.popleft()
                    for dx, dy in directions:
                        nx = x + dx
                        ny = y + dy
                        if 0 <= nx < n and 0 <= ny < m:
                            if grid[nx][ny] == '.' and group[nx][ny] == -1:
                                group[nx][ny] = current_group
                                count += 1
                                queue.append((nx, ny))
                sizes.append(count)
                current_group += 1
    
    output = []
    for i in range(n):
        row = []
        for j in range(m):
            if grid[i][j] == '.':
                row.append('.')
            else:
                adj_groups = set()
                for dx, dy in directions:
                    ni = i + dx
                    nj = j + dy
                    if 0 <= ni < n and 0 <= nj < m and grid[ni][nj] == '.':
                        adj_groups.add(group[ni][nj])
                total = sum(sizes[g] for g in adj_groups) + 1
                row.append(str(total % 10))
        output.append(''.join(row))
    
    print('\n'.join(output))

if __name__ == "__main__":
    main()

### Explanation
1. **Reading Input**: The grid dimensions and the grid itself are read from standard input.
2. **Finding Connected Components**: Using BFS, each empty cell ('.') is processed to determine its connected component. Each component is assigned a unique ID, and the size of the component is stored.
3. **Processing '*' Cells**: For each '*' cell, the neighboring cells are checked. The unique component IDs of these neighbors are collected, and their sizes are summed. This sum, plus 1, gives the size of the component if the '*' cell were converted to '.', which is then taken modulo 10.
4. **Output**: The results are formatted into a grid and printed.

This approach efficiently preprocesses the grid to avoid redundant calculations, ensuring the solution handles large grids within acceptable time limits.
