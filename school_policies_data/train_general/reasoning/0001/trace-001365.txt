To solve this problem, we need to determine the number of small cubes in a larger n×n×n cube that remain unperforated after drilling holes through marked positions on three orthogonal planes (xy, xz, yz). Each mark on a plane results in a hole that penetrates the cube along one of the coordinate axes.

### Approach
1. **Input Parsing**: Read the input values for each dataset, which include the cube size `n` and the number of marks `h`, followed by the positions of each mark.
2. **Tracking Perforated Cubes**: Use a set to keep track of all unique cubes that are perforated by the holes. This helps in efficiently managing duplicates, as each cube can be perforated multiple times from different directions.
3. **Generating Perforated Cubes**: For each mark, depending on the plane (xy, xz, or yz), generate all cubes along the corresponding axis. For example:
   - An `xy` plane mark at (a, b) perforates all cubes along the z-axis at (a, b, z) for z from 1 to n.
   - An `xz` plane mark at (a, b) perforates all cubes along the y-axis at (a, y, b) for y from 1 to n.
   - A `yz` plane mark at (a, b) perforates all cubes along the x-axis at (x, a, b) for x from 1 to n.
4. **Calculate Result**: The number of unperforated cubes is the total number of cubes (n³) minus the number of unique perforated cubes.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    while True:
        n = int(input[ptr])
        h = int(input[ptr + 1])
        ptr += 2
        if n == 0 and h == 0:
            break
        perforated = set()
        for _ in range(h):
            plane = input[ptr]
            a = int(input[ptr + 1])
            b = int(input[ptr + 2])
            ptr += 3
            if plane == 'xy':
                x, y = a, b
                for z in range(1, n + 1):
                    perforated.add((x, y, z))
            elif plane == 'xz':
                x, z = a, b
                for y in range(1, n + 1):
                    perforated.add((x, y, z))
            elif plane == 'yz':
                y, z = a, b
                for x in range(1, n + 1):
                    perforated.add((x, y, z))
        total = n ** 3 - len(perforated)
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
- **Input Handling**: The input is read all at once and split into a list for efficient processing. The pointer `ptr` is used to navigate through the input list.
- **Set for Perforated Cubes**: A set is used to store tuples representing the coordinates of perforated cubes, ensuring each cube is counted only once regardless of how many times it is perforated.
- **Generating Coordinates**: Depending on the plane specified by each mark, the appropriate loop generates all coordinates along the corresponding axis and adds them to the set.
- **Result Calculation**: The total number of cubes is calculated as \( n^3 \), and the number of unperforated cubes is derived by subtracting the count of perforated cubes from this total.

This approach efficiently handles up to the maximum constraints (n=500, h=200) by leveraging the properties of sets for uniqueness and average O(1) complexity for insertions and lookups.
