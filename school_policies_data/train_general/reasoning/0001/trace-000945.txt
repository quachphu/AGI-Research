To solve this problem, we need to determine the maximum number of 5-minute jokes Joseph can crack during a party while ensuring Harry can taste all dishes and take the required breaks. The solution involves calculating the optimal time schedule that fits within the given party duration.

### Approach
1. **Calculate Harry's Total Time**: Harry's total time includes the time to eat each dish and the mandatory breaks between dishes. This is computed as the sum of all dish times plus 10 minutes for each break (which is the number of dishes minus one).
2. **Check Feasibility**: If Harry's total time exceeds the party duration, it's impossible to schedule both Harry's activities and Joseph's jokes, resulting in an output of -1.
3. **Calculate Remaining Time for Jokes**: If Harry's total time is within the party duration, the remaining time after Harry's activities can be used for Joseph's jokes. Additionally, each of Harry's 10-minute breaks can be fully utilized for two 5-minute jokes.
4. **Compute Maximum Jokes**: The maximum number of jokes is derived from the remaining time and the breaks, considering each joke takes exactly 5 minutes.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N, d = int(input[idx]), int(input[idx+1])
        idx +=2
        t_list = list(map(int, input[idx:idx+N]))
        idx += N
        sum_t = sum(t_list)
        breaks = N - 1
        harry_time = sum_t + 10 * breaks
        if harry_time > d:
            print(-1)
        else:
            available = d - harry_time
            jokes = 2 * breaks + (available // 5)
            print(jokes)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Harry's Total Time Calculation**: For each test case, we compute the sum of all dish times and add the necessary breaks between dishes.
3. **Feasibility Check**: If Harry's total time exceeds the party duration, output -1 as it's impossible to accommodate all activities.
4. **Jokes Calculation**: If feasible, calculate the remaining time after Harry's activities. Each break allows for 2 jokes, and any remaining time is converted into additional jokes.

This approach ensures that we efficiently determine the maximum number of jokes Joseph can crack while adhering to the constraints, providing an optimal solution in linear time relative to the number of dishes.
