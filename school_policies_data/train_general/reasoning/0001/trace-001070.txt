To solve this problem, we need to determine the total number of free drives gained by all users of the Amer app based on the given number of users. Each user can share their reference code with another user exactly once, and each share results in one free drive.

### Approach
The key insight here is that each pair of users can share reference codes exactly once. Therefore, the problem reduces to finding the number of unique pairs that can be formed from N users, which is a combinatorial problem. The number of ways to choose 2 users out of N (denoted as C(N, 2)) is given by the formula \( C(N, 2) = \frac{N \times (N-1)}{2} \).

The solution involves:
1. Reading the number of test cases.
2. For each test case, reading the number of users (N).
3. Applying the formula \( \frac{N \times (N-1)}{2} \) to compute the result for each test case.
4. Printing the result for each test case.

This approach ensures that we efficiently compute the result in constant time \( O(1) \) for each test case, making the solution scalable even for large values of N.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        N = int(input[i])
        print(N * (N - 1) // 2)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The input is read all at once and split into a list of strings for efficient processing.
2. **Processing Test Cases:** The first element of the input list is the number of test cases (T). For each subsequent element (which represents the number of users N for each test case), we compute the result using the formula \( N \times (N-1) // 2 \).
3. **Output the Result:** The result for each test case is printed immediately after computation.

This approach ensures that the solution is both efficient and easy to understand, leveraging combinatorial mathematics to derive the result in constant time for each test case.
