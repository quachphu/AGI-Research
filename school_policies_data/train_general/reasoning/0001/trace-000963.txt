To solve this problem, we need to determine the maximum possible danger when mixing chemicals in a test tube. The danger increases by a factor of 2 each time a new chemical is added that reacts with any already present in the tube. The optimal order of adding chemicals will maximize the number of times the danger is doubled.

### Approach
1. **Graph Representation**: Represent the chemicals and their reactions as an undirected graph where each node is a chemical and each edge represents a reaction between two chemicals.
2. **Connected Components**: Identify all connected components in the graph. Each connected component represents a group of chemicals where each chemical can react with at least one other in the group.
3. **Danger Calculation**: For each connected component of size `k`, the maximum number of danger doublings is `k-1`. This is because the first chemical in the component does not cause a doubling, but each subsequent addition does. Summing these values across all components gives the total number of doublings.
4. **Result**: The maximum danger is calculated as 2 raised to the total number of doublings.

### Solution Code
```python
import sys
from collections import deque

def main():
    n, m = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, sys.stdin.readline().split())
        adj[u].append(v)
        adj[v].append(u)
    
    visited = [False] * (n + 1)
    total = 0
    
    for i in range(1, n + 1):
        if not visited[i]:
            q = deque([i])
            visited[i] = True
            size = 0
            while q:
                u = q.popleft()
                size += 1
                for v in adj[u]:
                    if not visited[v]:
                        visited[v] = True
                        q.append(v)
            total += (size - 1)
    
    print(1 << total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Graph Construction**: The adjacency list `adj` is built from the input reactions.
2. **Finding Connected Components**: Using BFS, each unvisited node starts a new component exploration. The size of each component is determined by traversing all reachable nodes.
3. **Summing Doublings**: For each component of size `k`, `k-1` doublings are added to the total. This is because the first node in the component does not cause a doubling, but each subsequent node does.
4. **Result Calculation**: The total number of doublings is used as the exponent for 2, yielding the maximum danger using bit shifting (`1 << total`).

This approach efficiently computes the maximum danger by leveraging graph traversal techniques and understanding the structure of connected components.
