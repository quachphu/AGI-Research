To solve this problem, we need to place k fishes in an n × m pond such that the expected number of fishes caught using an r × r scoop is maximized. The solution involves calculating the optimal positions for the fishes based on the frequency of each cell being covered by the scoop.

### Approach
1. **Calculate Coverage Frequency**: For each cell (i, j), determine how many times it can be covered by the scoop when placed in all possible positions. This is done by computing the number of valid starting positions for the scoop in both row and column directions.
2. **Sort Coverage Frequencies**: Sort the coverage frequencies for rows and columns in descending order to prioritize cells with the highest coverage.
3. **Use a Max-Heap for Optimal Selection**: Utilize a max-heap (priority queue) to efficiently select the top k cells with the highest product of row and column coverage frequencies. This ensures we get the maximum possible expected value by considering the highest coverage products first.

    def generate_counts(length, r_size, original_size):
        counts = []
        max_pos = original_size - r_size + 1
        if max_pos <= 0:
            return [0] * length
        for i in range(1, length + 1):
            start = max(1, i - r_size + 1)
            end = min(max_pos, i)
            if end < start:
                counts.append(0)
            else:
                counts.append(end - start + 1)
        counts.sort(reverse=True)
        return counts
    
    x_counts = generate_counts(n, r, n)
    y_counts = generate_counts(m, r, m)
    
    total_positions = (n - r + 1) * (m - r + 1)
    sum_total = 0.0
    heap = []
    visited = set()
    
    if x_counts and y_counts:
        initial_product = - (x_counts[0] * y_counts[0])
        heapq.heappush(heap, (initial_product, 0, 0))
        visited.add((0, 0))
    
    count = 0
    while heap and count < k:
        current = heapq.heappop(heap)
        product = -current[0]
        i, j = current[1], current[2]
        sum_total += product
        count += 1
        
        if count >= k:
            break
        
        if i + 1 < len(x_counts) and (i + 1, j) not in visited:
            visited.add((i + 1, j))
            new_product = - (x_counts[i + 1] * y_counts[j])
            heapq.heappush(heap, (new_product, i + 1, j))
        
        if j + 1 < len(y_counts) and (i, j + 1) not in visited:
            visited.add((i, j + 1))
            new_product = - (x_counts[i] * y_counts[j + 1])
            heapq.heappush(heap, (new_product, i, j + 1))
    
    expected = sum_total / total_positions
    print("{0:.10f}".format(expected))
