To solve this problem, we need to determine if a given string is a balanced string. A balanced string is defined as a string where each character from 'a' to 'z' appears exactly the same number of times.

### Approach
1. **Check Length Divisibility**: The length of the string must be divisible by 26. This is because there are 26 letters in the alphabet, and each letter must appear the same number of times. If the length is not divisible by 26, the string cannot be balanced.
2. **Calculate Required Frequency**: If the length is divisible by 26, calculate the required frequency for each letter as the length divided by 26.
3. **Count Character Frequencies**: Use a counter to count the occurrences of each character in the string.
4. **Verify Frequencies**: Check if each letter from 'a' to 'z' appears exactly the required number of times. If any letter does not meet this requirement, the string is not balanced.

### Solution Code
```python
import sys
from collections import Counter

def is_balanced(s):
    n = len(s)
    if n % 26 != 0:
        return False
    k = n // 26
    counts = Counter(s)
    for c in 'abcdefghijklmnopqrstuvwxyz':
        if counts.get(c, 0) != k:
            return False
    return True

def main():
    T = int(sys.stdin.readline())
    for _ in range(T):
        s = sys.stdin.readline().strip()
        print("Yes" if is_balanced(s) else "No")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first line contains the number of test cases, T.
2. **Check Length**: For each string, we first check if its length is divisible by 26. If not, it is immediately determined to be unbalanced.
3. **Frequency Calculation**: If the length is valid, we calculate how many times each character should appear (k = length / 26).
4. **Count Validation**: Using a counter, we check each character from 'a' to 'z' to ensure they each appear exactly k times. If any character does not meet this count, the string is unbalanced.

This approach ensures that we efficiently determine the balance of each string with a time complexity of O(n) per string, where n is the length of the string. This is efficient given the problem constraints.
