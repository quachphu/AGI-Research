To solve this problem, we need to determine the number of Takahashi days from January 1, 2018, up to a given date in the same year. A Takahashi day is defined as a date where the month and day are the same number (e.g., 1-1, 2-2, etc.).

### Approach
1. **Understanding Takahashi Days**: A Takahashi day occurs on the m-th day of the m-th month for each month m from 1 to 12. For example, January 1 (1-1), February 2 (2-2), etc.
2. **Range Consideration**: Given a date in the format a-b (month-day), we need to count all Takahashi days from January 1 (1-1) up to and including a-b.
3. **Counting Valid Days**: 
   - For months from 1 to a-1, all corresponding Takahashi days (m-m) are valid because they fall within the range.
   - For the month a, check if the day a is within the given day b. If a ≤ b, then a-a is a valid Takahashi day.

### Solution Code
```python
a, b = map(int, input().split())
print(a - 1 + (1 if a <= b else 0))
```

### Explanation
1. **Input Reading**: The input consists of two integers, a (month) and b (day).
2. **Count Calculation**:
   - For months 1 to a-1, there are exactly (a-1) Takahashi days.
   - Check if the day a (which is the same as the month a) is less than or equal to the given day b. If true, add 1 to the count.
3. **Output the Result**: The result is the sum of the counts from the previous steps.

This approach efficiently computes the number of valid Takahashi days using simple arithmetic and a conditional check, ensuring optimal performance with constant time complexity O(1).
