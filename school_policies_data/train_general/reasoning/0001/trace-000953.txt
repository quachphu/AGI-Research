To solve this problem, we need to determine if Bob can build a tower of dice such that the number of visible pips matches each of his favorite integers. The key insight is understanding the mathematical pattern that governs the visible pips when stacking dice.

### Approach
1. **Understanding the Visible Pips**: Each die in the tower contributes to the visible pips. The four side faces of each die always sum to 14, regardless of orientation. The top face of the top die adds between 1 and 6 pips.
2. **Mathematical Pattern**: For `n` dice, the total visible pips can be expressed as `14 * n + k`, where `k` is the top face of the top die (ranging from 1 to 6). Thus, for a given integer `x`, we need to check if `x` can be written in the form `14 * n + k` for some `n ≥ 1` and `1 ≤ k ≤ 6`.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    xs = list(map(int, input[1:t+1]))
    for x in xs:
        possible = False
        for k in range(1, 7):
            if (x - k) >= 14 and (x - k) % 14 == 0:
                possible = True
                break
        print("YES" if possible else "NO")

solve()
```

### Explanation
1. **Reading Input**: The input consists of `t` test cases, each containing a favorite integer `x`.
2. **Check Each Integer**: For each integer `x`, check if there exists an integer `k` (1 to 6) such that `(x - k)` is non-negative, divisible by 14, and at least 14. This ensures that the number of dice `n` (computed as `(x - k) // 14`) is at least 1.
3. **Output Result**: If any valid `k` is found, print "YES"; otherwise, print "NO".

This approach efficiently checks each possible value of `k` for each favorite integer, ensuring that we determine the possibility using constant time per integer, making the solution both optimal and easy to understand.
