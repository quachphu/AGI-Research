### Approach
1. **Check for Odd Numbers**: Each exchange step can only be performed if all three people have an even number of cookies. If any of them has an odd number, the process stops.
2. **Check for Equality**: If all three people have the same number of cookies and all are even, they will continue exchanging indefinitely, leading to an infinite loop. In this case, we return -1.
3. **Exchange Process**: If neither of the above conditions are met, perform the exchange step where each person simultaneously divides their cookies into two halves and gives one half to each of the other two people. This process is repeated until one of the stopping conditions is met.

### Solution Code

```python
def main():
    import sys
    A, B, C = map(int, sys.stdin.readline().split())
    count = 0
    while True:
        if A % 2 != 0 or B % 2 != 0 or C % 2 != 0:
            print(count)
            return
        if A == B == C:
            print(-1)
            return
        newA = (B + C) // 2
        newB = (A + C) // 2
        newC = (A + B) // 2
        A, B, C = newA, newB, newC
        count += 1

main()
```

1. **Initial Check**: The code starts by reading the initial number of cookies for each person.
2. **Loop Until Termination**: The loop continues until one of the stopping conditions is met:

   - **Equality Check**: If all three have the same number of even cookies, the loop breaks and prints -1, indicating an infinite process.
3. **Exchange Step**: Each exchange step involves recalculating the number of cookies each person has after giving away half to each of the other two. This is done using integer division to ensure the values remain integers.
