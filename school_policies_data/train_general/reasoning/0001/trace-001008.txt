To solve this problem, we need to determine the minimum number of unit shifts required to sort a sequence of integers in non-decreasing order. A unit shift involves moving the last element of the sequence to the front. If it's impossible to sort the sequence using such shifts, we should return -1.

### Approach
1. **Check if Already Sorted**: If the array is already sorted in non-decreasing order, the answer is 0.
2. **Identify Breaks**: Count the number of positions where an element is greater than the next element. If there is exactly one such position, the array can potentially be sorted by rotations.
3. **Check Validity of Rotation**: Ensure the last element of the array is less than or equal to the first element. This ensures that the rotation can result in a sorted array.
4. **Calculate Shifts**: If the above conditions are met, the minimum number of shifts required is calculated based on the position of the break.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
breaks = 0
pos = -1
for i in range(n - 1):
    if a[i] > a[i + 1]:
        breaks += 1
        pos = i

if breaks == 0:
    print(0)
elif breaks == 1 and a[-1] <= a[0]:
    print((n - 1 - pos))
else:
    print(-1)
```

### Explanation
1. **Check for Sorted Array**: The loop checks each adjacent pair of elements. If no breaks (where an element is greater than the next) are found, the array is already sorted, and we output 0.
2. **Count Breaks**: If exactly one break is found, it indicates the array can be split into two non-decreasing subarrays. The position of this break is recorded.
3. **Validate Rotation**: Check if the last element of the array is less than or equal to the first element. This ensures that rotating the array at the break point will result in a sorted array.
4. **Calculate Shifts**: The number of shifts needed is determined by the position of the break. The formula `(n - 1 - pos)` gives the required number of shifts to bring the latter part of the array to the front, resulting in a sorted array.

This approach efficiently checks the necessary conditions and computes the result in linear time, making it suitable for large input sizes up to 100,000 elements.
