2. **Build Character Mapping**: Create a mapping from each character in `s` to the corresponding character in `t`. Ensure that each character maps correctly and consistently, either to itself or to another character in a mutual swap.
3. **Validate Mapping**: Ensure that the built mapping is consistent for all characters in both strings. If any inconsistency is found, output -1.
4. **Collect Swap Pairs**: Extract the pairs of swapped characters from the validated mapping, ensuring each pair is listed only once and in the correct order.
