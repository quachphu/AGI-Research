To solve this problem, we need to calculate the total distance Batman travels to defuse all bombs planted by the Joker in Gotham City. The bombs are placed at increasing distances from the start point, and Batman can carry only one bomb at a time. The challenge is to compute the total distance modulo M efficiently given the constraints.

### Approach
1. **Problem Analysis**: Each bomb is located at a distance \( x^i \) from the start. Batman travels to each bomb and back, covering twice the distance each time. The total distance for N bombs is \( 2 \times (x + x^2 + x^3 + ... + x^N) \).

2. **Geometric Series Sum**: The sum \( x + x^2 + ... + x^N \) can be represented using the formula for the sum of a geometric series. For \( x \neq 1 \), the sum is \( x \times \frac{x^N - 1}{x - 1} \). For \( x = 1 \), the sum simplifies to \( N \).

3. **Modulo Operations**: Direct computation of large powers and sums is infeasible due to constraints. Instead, we use modular arithmetic properties to compute the sum efficiently:
   - For \( x \neq 1 \), compute the sum modulo \( (x-1) \times M \) using modular exponentiation.
   - Adjust the result to fit within the required modulus \( M \).

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N = int(input[idx])
        x = int(input[idx + 1])
        M = int(input[idx + 2])
        idx += 3
        
        if x == 1:
            sum_geo = N
        else:
            D = x - 1
            mod_product = D * M
            x_pow = pow(x, N, mod_product)
            numerator = (x * (x_pow - 1)) % mod_product
            sum_geo = numerator // D
        
        total = (2 * sum_geo) % M
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the large number of test cases.
2. **Handling Special Case (x = 1)**: When \( x = 1 \), the sum of distances is simply \( N \).
3. **Modular Exponentiation**: For \( x \neq 1 \), we compute \( x^N \mod (M \times (x-1)) \) using Python's built-in `pow` function with three arguments for efficient modular exponentiation.
4. **Sum Calculation**: The sum is adjusted using modular arithmetic to ensure it fits within the required modulus \( M \), and then doubled (for the round trip) before applying the final modulus operation.

This approach efficiently handles large values of \( N \) and \( x \) using properties of geometric series and modular arithmetic, ensuring the solution is both optimal and correct.
