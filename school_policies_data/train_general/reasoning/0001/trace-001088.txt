To solve this problem, we need to determine if both Sid and Jake are correct in their statements about the number of animals at the zoo. Sid claims that a number \( f \) is a factor of the total number of animals, while Jake claims that a number \( m \) is a multiple of the total number of animals. We need to check if there exists a valid total number of animals that satisfies both conditions.

### Approach
1. **Understanding the Conditions**:
   - For Sid to be correct, the total number of animals (let's call it \( x \)) must be a multiple of \( f \). This means \( x \) can be expressed as \( x = k \times f \) where \( k \) is a positive integer.
   - For Jake to be correct, \( x \) must be a divisor of \( m \). This means \( m \) must be a multiple of \( x \).

2. **Key Insight**:
   - If \( x \) must be both a multiple of \( f \) and a divisor of \( m \), the simplest possible \( x \) is \( f \) itself. For \( f \) to be a valid \( x \), \( m \) must be divisible by \( f \). If \( m \) is not divisible by \( f \), there can be no such \( x \) that satisfies both conditions.

3. **Efficient Check**:
   - For each test case, check if \( m \) is divisible by \( f \). If it is, print "CORRECT"; otherwise, print "WRONG".

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    t = int(input[0])
    idx = 1
    for _ in range(t):
        f = int(input[idx])
        m = int(input[idx+1])
        idx +=2
        if m % f == 0:
            print("CORRECT")
        else:
            print("WRONG")

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input Efficiently**: The input is read all at once for efficiency, especially given the constraints where \( t \) can be up to \( 10^5 \).
- **Divisibility Check**: For each test case, we check if \( m \) is divisible by \( f \) using the modulus operator. If \( m \% f == 0 \), it means \( f \) is a factor of \( m \), making both Sid's and Jake's statements true. Otherwise, at least one of their statements is false.

This approach ensures that we efficiently determine the correctness of both statements in constant time for each test case, making the solution scalable even for large inputs.
