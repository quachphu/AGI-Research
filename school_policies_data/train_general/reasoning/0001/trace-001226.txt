To solve this problem, we need to find the length of the longest common subsequence (LCS) among multiple permutations of numbers from 1 to n. The solution involves constructing a directed acyclic graph (DAG) where edges represent the order constraints from all permutations, and then finding the longest path in this DAG.

### Approach
1. **Input Reading and Position Tracking**: Read the input values and track the position of each element in each permutation.
2. **Graph Construction**: Construct a DAG where an edge from node `a` to node `b` exists if and only if `a` comes before `b` in all permutations.
3. **Topological Sorting and Dynamic Programming**: Process the nodes in the order of the first permutation (which is a valid topological order for the DAG) and use dynamic programming to find the longest path in the DAG.

### Solution Code
```python
n, k = map(int, input().split())
perms = [list(map(int, input().split())) for _ in range(k)]

# Create position arrays for each permutation
pos_list = []
for perm in perms:
    pos = [0] * (n + 1)  # 1-based indexing
    for idx, num in enumerate(perm):
        pos[num] = idx
    pos_list.append(pos)

# Build the adjacency list for the DAG
adj = [[] for _ in range(n + 1)]
for a in range(1, n + 1):
    for b in range(1, n + 1):
        if a == b:
            continue
        valid = True
        for i in range(k):
            if pos_list[i][a] >= pos_list[i][b]:
                valid = False
                break
        if valid:
            adj[a].append(b)

# Process nodes in the order of the first permutation to compute the longest path
order = perms[0]
dp = [0] * (n + 1)

for u in order:
    for v in adj[u]:
        if dp[v] < dp[u] + 1:
            dp[v] = dp[u] + 1

print(max(dp) + 1)
```

### Explanation
1. **Input Reading and Position Tracking**: For each permutation, we create an array that maps each element to its position in the permutation. This helps in quickly checking the relative order of elements across all permutations.
2. **Graph Construction**: We construct a DAG where each node represents an element, and an edge from `a` to `b` exists if `a` precedes `b` in all permutations. This ensures that any path in the DAG respects the order constraints of all permutations.
3. **Dynamic Programming on DAG**: Using the first permutation's order as a topological sort, we compute the longest path in the DAG. The dynamic programming array `dp` keeps track of the maximum path length ending at each node, which allows us to efficiently compute the LCS length by taking the maximum value in `dp` and adding 1 (to convert edge count to node count).

This approach efficiently leverages the properties of permutations and topological sorting to solve the problem in O(n^2) time complexity, which is feasible for the given constraints.
