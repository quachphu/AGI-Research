To solve this problem, we need to count the number of points in a 2D plane that lie within or on a given distance \( D \) from the origin. The solution involves efficiently checking each point to determine if its distance from the origin is within the specified range.

### Approach
1. **Understanding the Distance Formula**: The distance of a point \((X_i, Y_i)\) from the origin \((0, 0)\) is given by \(\sqrt{X_i^2 + Y_i^2}\). To avoid floating-point operations and potential inaccuracies, we compare the square of the distance \((X_i^2 + Y_i^2)\) with the square of \( D \) (i.e., \( D^2 \)).
2. **Efficient Input Handling**: Given the constraints where \( N \) can be as large as \( 2 \times 10^5 \), we read all input at once for efficiency, especially in Python, where reading from standard input line-by-line can be slow for large inputs.
3. **Iterate and Check Conditions**: For each point, compute the squared distance and compare it with \( D^2 \). If the squared distance is less than or equal to \( D^2 \), the point is counted.

### Solution Code
```python
import sys

def main():
    data = list(map(int, sys.stdin.read().split()))
    n = data[0]
    d = data[1]
    d_squared = d * d
    count = 0
    idx = 2
    for _ in range(n):
        x = data[idx]
        y = data[idx + 1]
        idx += 2
        if x * x + y * y <= d_squared:
            count += 1
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once using `sys.stdin.read()`, which is split into a list of integers. This approach is more efficient than reading line-by-line, especially for large inputs.
2. **Squared Distance Calculation**: For each point \((X_i, Y_i)\), compute \( X_i^2 + Y_i^2 \) and check if it is less than or equal to \( D^2 \). This avoids the computational cost and potential precision issues of calculating square roots.
3. **Counting Valid Points**: Maintain a counter to keep track of how many points meet the condition. This counter is incremented each time a valid point is found.

This approach ensures that the solution is both efficient and correct, handling the maximum constraints within acceptable time limits.
