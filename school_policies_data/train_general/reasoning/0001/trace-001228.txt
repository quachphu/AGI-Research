To solve this problem, we need to determine if there exists a cycle of at least 4 cells in a grid where each cell contains a dot of a certain color. The cycle must consist of cells of the same color and each consecutive cell in the cycle must be adjacent (sharing an edge).

### Approach
1. **Flood Fill Algorithm**: For each cell in the grid, if it hasn't been visited yet, use a flood fill algorithm (BFS) to collect all cells of the same color forming a connected component.
2. **Cycle Detection with DFS**: For each collected component, check if it contains a cycle of length at least 4 using a depth-first search (DFS) approach. Track the depth of each cell during the DFS traversal and detect back edges to determine cycle length.

import sys
from collections import deque

def main():
    directions = [ (0, 1), (1, 0), (0, -1), (-1, 0) ]
    n, m = map(int, sys.stdin.readline().split())
    grid = [ sys.stdin.readline().strip() for _ in range(n) ]
    visited = [ [False for _ in range(m)] for _ in range(n) ]

    for i in range(n):
        for j in range(m):
            if not visited[i][j]:
                # Flood fill to find the component
                color = grid[i][j]
                q = deque()
                q.append((i, j))
                visited[i][j] = True
                component = [ (i, j) ]
                while q:
                    x, y = q.popleft()
                    for dx, dy in directions:
                        nx, ny = x + dx, y + dy
                        if 0 <= nx < n and 0 <= ny < m and not visited[nx][ny] and grid[nx][ny] == color:
                            visited[nx][ny] = True
                            component.append((nx, ny))
                            q.append((nx, ny))
                # Check if this component has a cycle of length >=4
                if has_cycle(component, directions):
                    print("Yes")
                    return
    print("No")

def has_cycle(component, directions):
    if len(component) < 4:
        return False

    start_x, start_y = component[0]
    visited_in = { (x, y): False for x, y in component }
    depth = { (x, y): -1 for x, y in component }
    stack = [ (start_x, start_y, -1, -1, 0) ]
    depth[(start_x, start_y)] = 0

    while stack:
        x, y, px, py, d = stack.pop()
        if visited_in[(x, y)]:
            continue
        visited_in[(x, y)] = True
        depth[(x, y)] = d
        for dx, dy in directions:
            nx, ny = x + dx, y + dy
            if (nx, ny) not in visited_in:
                continue
            if (nx, ny) == (px, py):
                continue
            if not visited_in[(nx, ny)]:
                stack.append((nx, ny, x, y, d + 1))
            else:
                # Check cycle length
                cycle_length = d - depth[(nx, ny)] + 1
                if cycle_length >= 4:
                    return True
    return False

if __name__ == "__main__":
    main()

### Explanation
1. **Flood Fill**: The flood fill algorithm (BFS) is used to collect all cells of the same color starting from an unvisited cell. This helps in identifying connected components in the grid.
2. **Cycle Detection**: For each connected component, a DFS is performed to detect cycles. During the DFS traversal, we track the depth of each node and check for back edges. If a back edge is found and the cycle length (calculated using the depth difference) is at least 4, a cycle exists, and we return "Yes". If no such cycle is found in any component, we return "No".

This approach ensures that we efficiently check each connected component for cycles of the required length, leveraging both BFS for component collection and DFS for cycle detection.
