To solve this problem, we need to determine the smallest positive integer \( b \) such that when added to a given integer \( a \), the resulting number contains at least one digit '8'. This problem can be efficiently solved by checking each subsequent number starting from \( a + 1 \) until we find a number that contains the digit '8'.

### Approach
1. **Problem Analysis**: The task is to find the smallest positive integer \( b \) such that \( a + b \) contains the digit '8'. The key insight is that we need to check each number starting from \( a + 1 \) sequentially until we find one that contains '8'.
2. **Algorithm**: 
   - Start with \( b = 1 \) and increment \( b \) by 1 in each iteration.
   - For each \( b \), compute \( a + b \) and check if the result contains the digit '8'.
   - The first \( b \) that satisfies this condition is our answer.
3. **Optimization**: Converting the number to a string allows us to easily check for the presence of the digit '8'. This approach ensures that we efficiently check each subsequent number without any unnecessary computations.

### Solution Code
```python
a = int(input())
b = 1
while True:
    current = a + b
    if '8' in str(current):
        print(b)
        break
    b += 1
```

### Explanation
- **Reading Input**: The input integer \( a \) is read from standard input.
- **Loop and Check**: Starting from \( b = 1 \), we compute \( current = a + b \) in each iteration. The number \( current \) is converted to a string to check if it contains the digit '8'.
- **Termination**: The loop terminates as soon as we find a \( current \) value that contains '8', and we print the corresponding \( b \).

This approach ensures that we find the smallest \( b \) efficiently by leveraging string operations to check for the presence of the digit '8'. The worst-case time complexity is manageable due to the nature of the problem, where the digit '8' is likely to be found within a reasonable number of iterations.
