To solve this problem, we need to determine if the elements of a subarray can be rearranged such that their sum is zero. The array consists of integers -1 and 1, and each query specifies a subarray range. The solution involves checking two conditions for each query: the length of the subarray must be even, and there must be enough 1's and -1's to form a balanced subarray.

### Approach
1. **Count the Elements**: First, count the total number of 1's and -1's in the array. This helps in quickly determining if a balanced subarray can be formed for each query.
2. **Check Query Conditions**: For each query, check if the length of the subarray is even. If it's odd, the answer is immediately 0. If even, check if there are enough 1's and -1's to form a balanced subarray (equal number of 1's and -1's).

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n, m = int(input[ptr]), int(input[ptr+1])
    ptr += 2
    a = list(map(int, input[ptr:ptr+n]))
    ptr += n
    count_1 = a.count(1)
    count_neg1 = a.count(-1)
    for _ in range(m):
        l = int(input[ptr])
        r = int(input[ptr+1])
        ptr += 2
        length = r - l + 1
        if length % 2 != 0:
            print(0)
        else:
            required = length // 2
            if count_1 >= required and count_neg1 >= required:
                print(1)
            else:
                print(0)

main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Element Counting**: The counts of 1's and -1's are computed once at the beginning, which allows for constant-time checks during each query.
3. **Query Processing**: For each query, the length of the subarray is checked. If it's even, the required number of 1's and -1's to balance the subarray is calculated. The solution checks if the available counts meet these requirements.

This approach ensures that each query is processed in constant time, making the overall complexity O(n + m), which is efficient for the given constraints.
