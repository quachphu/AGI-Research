To solve this problem, we need to determine the volume of a given text. The volume of a word is defined as the number of capital letters in it, and the volume of the text is the maximum volume among all words in the text.

### Approach
1. **Input Reading**: Read the input values. The first line is an integer representing the length of the text, which can be safely ignored. The second line contains the text itself.
2. **Splitting the Text**: Split the text into individual words using spaces as delimiters.
3. **Volume Calculation**: For each word, count the number of uppercase letters. Track the maximum count encountered.
4. **Output the Result**: Print the maximum count, which represents the volume of the text.

### Solution Code
```python
def main():
    n = int(input())
    words = input().split()
    max_volume = 0
    for word in words:
        count = sum(1 for c in word if c.isupper())
        if count > max_volume:
            max_volume = count
    print(max_volume)

main()
```

### Explanation
1. **Reading Input**: The function reads the integer `n` (which is not used further) and the text line.
2. **Splitting Words**: The text line is split into words using the `split()` method.
3. **Counting Capital Letters**: For each word, iterate through its characters and count how many are uppercase using a generator expression.
4. **Tracking Maximum Volume**: Maintain a variable `max_volume` to keep track of the highest count of uppercase letters found in any word.
5. **Output**: Finally, print the maximum volume found.

This approach efficiently processes each word in linear time relative to the number of characters, ensuring optimal performance given the problem constraints.
