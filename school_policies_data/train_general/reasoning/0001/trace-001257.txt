To solve this problem, we need to efficiently handle three types of queries on a dynamic set of strings: adding a string, removing a string, and finding the lexicographically smallest string in the set that starts with a given prefix. The solution involves preprocessing the strings to enable efficient prefix-based queries using a trie data structure and maintaining a sorted list of candidate strings for each prefix.

### Approach
1. **Trie Construction**: Build a trie from all given strings. Each node in the trie represents a prefix and stores the indices of strings that end at that node.
2. **Prefix Mapping**: For each string, determine all prefixes (existing in the original list) using the trie and maintain a mapping from each prefix to the strings that start with it.
3. **Sorting**: Sort the candidate strings for each prefix lexicographically.
4. **Query Handling**: For each query, add or remove strings from the active set and check the precomputed sorted lists to find the smallest valid string for prefix queries.

### Solution Code
```python
import sys

class TrieNode:
    def __init__(self):
        self.children = {}
        self.sx_ids = []

def main():
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    strings = []
    for _ in range(N):
        strings.append(input[ptr])
        ptr += 1

    # Build trie for Sx's
    root = TrieNode()
    for sx_id in range(1, N+1):
        s = strings[sx_id - 1]
        node = root
        for c in s:
            if c not in node.children:
                node.children[c] = TrieNode()
            node = node.children[c]
        node.sx_ids.append(sx_id)

    # Preprocess prefix_map: for each sx_id, collect all sy's that start with it
    prefix_map = [[] for _ in range(N + 1)]  # prefix_map[sx_id] will contain (sy_str, sy_id)
    for sy_id in range(1, N + 1):
        s = strings[sy_id - 1]
        node = root
        collected_sx_ids = []
        for c in s:
            if c not in node.children:
                break
            node = node.children[c]
            collected_sx_ids.extend(node.sx_ids)
        # Add sy_id to all sx_ids in collected_sx_ids
        for sx_id in collected_sx_ids:
            prefix_map[sx_id].append((s, sy_id))

    # Sort each prefix_map entry by the string lex order and extract sy_ids
    sorted_sy_ids = {}
    for sx_id in range(1, N + 1):
        entries = prefix_map[sx_id]
        entries.sort(key=lambda x: x[0])  # Sort by the string
        sy_ids = [sy_id for (_, sy_id) in entries]
        sorted_sy_ids[sx_id] = sy_ids

    # Process queries
    Q = int(input[ptr])
    ptr += 1
    active = set()
    for _ in range(Q):
        k = int(input[ptr])
        id = int(input[ptr + 1])
        ptr += 2
        if k == 1:
            active.add(id)
        elif k == 2:
            active.discard(id)
        else:
            # Query type 3: check sx_id = id
            sx_id = id
            candidates = sorted_sy_ids.get(sx_id, [])
            found = -1
            for sy_id in candidates:
                if sy_id in active:
                    found = sy_id
                    break
            print(found)
```
