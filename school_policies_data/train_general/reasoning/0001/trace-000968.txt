To solve this problem, we need to track the number of unread notifications on Thor's smartphone after each event. The events can be of three types: generating a notification, reading all notifications from a specific app, and reading the first t notifications generated. The solution efficiently handles these events using a combination of tracking counts and using binary operations to minimize time complexity.

### Approach
1. **Data Structures**: Use arrays to keep track of the total notifications per app, the last read notification count per app, and the count of notifications from each app that fall within the first t global notifications.
2. **Global Tracking**: Maintain a list of all type 1 events to efficiently determine the first t notifications when processing type 3 events.
3. **Efficient Updates**: For type 3 events, incrementally update the counts of notifications from each app that fall within the new range of first t notifications. This ensures we only process each notification once, even if multiple type 3 events occur.
4. **Sum Maintenance**: Track sums of relevant values (like total notifications, last read counts, etc.) to compute the number of unread notifications efficiently after each event.

```python
    current_t_global = 0
    type1_events = []

    for _ in range(q):
        type_i = int(input[ptr])
        ptr += 1
        if type_i == 1:
            x = int(input[ptr])
            ptr += 1
            total_count[x] += 1
            sum_type1_events += 1
            type1_events.append(x)
        elif type_i == 2:
            x = int(input[ptr])
            ptr += 1
            old = last_read[x]
            last_read[x] = total_count[x]
            sum_last_read += (last_read[x] - old)
            # Update sum_min
            sum_min -= min(old, cnt_in_global[x])
            sum_min += min(last_read[x], cnt_in_global[x])
        elif type_i == 3:
            t = int(input[ptr])
            ptr += 1
            if t > current_t_global:
                # Process events from current_t_global to t-1 (inclusive)
                for k in range(current_t_global, t):
                    x = type1_events[k]
                    old_cnt = cnt_in_global[x]
                    cnt_in_global[x] += 1
                    sum_min -= min(old_cnt, last_read[x])
                    sum_min += min(old_cnt + 1, last_read[x])
                current_t_global = t
        # Calculate and print unread_total
        unread_total = sum_type1_events - sum_last_read - current_t_global + sum_min
        print(unread_total)

if __name__ == "__main__":
    main()
```

### Explanation
- **Type 1 Events**: Track each notification generated by an app and update the total count of notifications for that app.
- **Type 2 Events**: Update the last read count for the app to the current total notifications count, effectively marking all notifications up to that point as read.
- **Type 3 Events**: Process the first t notifications generated, updating counts to reflect which notifications are read. This is done incrementally to ensure efficiency.
- **Sum Maintenance**: Track sums to quickly compute the number of unread notifications without iterating through all notifications each time, ensuring the solution handles large inputs efficiently.

This approach ensures that each event is processed in constant or linear time, making the solution efficient even for the upper limits of the problem constraints.
