To solve this problem, we need to determine if there exists a non-empty subsequence of a given sequence of numbers such that the sum of the subsequence is divisible by a given number \( m \).

### Approach
1. **Immediate Check for Zero Modulo**: If any number in the sequence is directly divisible by \( m \), the answer is immediately "YES".
2. **Pigeonhole Principle**: If the size of the sequence \( n \) is greater than or equal to \( m \), we can use the pigeonhole principle to conclude that there must be a subsequence whose sum is divisible by \( m \), hence the answer is "YES".
3. **Dynamic Programming for Smaller Sequences**: For sequences where \( n < m \), use a dynamic programming approach to track possible remainders of sums modulo \( m \). This allows us to efficiently check if a valid subsequence exists without examining all possible subsets.

### Solution Code
```python
n, m = map(int, input().split())
arr = list(map(int, input().split()))

# Check if any element is divisible by m
for num in arr:
    if num % m == 0:
        print("YES")
        exit()

# Check if n >= m (pigeonhole principle)
if n >= m:
    print("YES")
    exit()

# Use dynamic programming to track possible remainders
current = set()
for num in arr:
    mod = num % m
    temp = set()
    for r in current:
        new_r = (r + mod) % m
        if new_r == 0:
            print("YES")
            exit()
        temp.add(new_r)
    temp.add(mod)
    if 0 in temp:
        print("YES")
        exit()
    current.update(temp)

print("NO")
```
