To solve this problem, we need to determine the number of chocolate pieces prepared at the beginning of a camp based on the participants' eating patterns and the remaining chocolates after the camp.

### Approach
1. **Understand the Problem**: Each participant eats chocolate on specific days starting from the 1st day and then every (A_i + 1)th day. We need to find the total chocolates consumed by all participants and add the remaining chocolates to get the initial count.
2. **Formulate the Solution**: For each participant, calculate the number of days they ate chocolate using the sequence 1, (A_i + 1), (2A_i + 1), etc., which can be simplified using integer division.
3. **Calculate Consumption**: For each participant, the number of days they eat chocolate is given by the formula `(D - 1) // A_i + 1`, where D is the total days of the camp.
4. **Sum Up**: Sum the chocolates eaten by all participants and add the remaining chocolates to get the initial count.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    D = int(input[ptr])
    X = int(input[ptr + 1])
    ptr += 2
    A = []
    for _ in range(N):
        A.append(int(input[ptr]))
        ptr += 1
    total = sum((D - 1) // a + 1 for a in A)
    print(total + X)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read as a list of strings and parsed sequentially to extract the number of participants (N), camp duration (D), remaining chocolates (X), and the list of intervals (A_i) for each participant.
2. **Calculate Days for Each Participant**: For each participant, using the formula `(D - 1) // A_i + 1`, we determine how many days they ate chocolate. This formula efficiently computes the number of terms in the sequence that fit within D days.
3. **Sum and Output**: The total chocolates consumed by all participants are summed up, and adding the remaining chocolates (X) gives the initial count of chocolates prepared, which is then printed.

This approach ensures that we efficiently compute the required values using integer operations, making the solution both optimal and easy to understand.
