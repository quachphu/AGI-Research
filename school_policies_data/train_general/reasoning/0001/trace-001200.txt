To solve this problem, we need to determine the minimum price Suraj has to pay for his items under the "Buy two, get two" offer. The offer allows Suraj to pay for the two most expensive items in a group of four and get the other two for free. The goal is to maximize the number of free items by strategically grouping them.

### Approach
1. **Sort the Items**: First, sort the list of item prices in descending order. This allows us to always consider the most expensive items first, ensuring we pay for the highest possible prices and get the lower ones for free.
2. **Grouping Strategy**: For every group of four items, the two most expensive items (first two in the sorted list) are paid for, and the next two are free. This pattern repeats for every subsequent group of four items.
3. **Sum Calculation**: Iterate through the sorted list and sum the prices of items at positions that are 0 or 1 modulo 4. These positions correspond to the items that need to be paid for in each group of four.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        arr = list(map(int, input[ptr:ptr+N]))
        ptr += N
        arr.sort(reverse=True)
        total = 0
        for i in range(len(arr)):
            if i % 4 in (0, 1):
                total += arr[i]
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints. The input is split into a list of strings for easy parsing.
2. **Sorting**: The list of item prices is sorted in descending order to prioritize the most expensive items.
3. **Summing Costs**: By iterating through the sorted list, we check the index of each item. If the index modulo 4 is 0 or 1, the item is added to the total cost. This effectively groups every four items and sums the first two in each group, which are the most expensive.

This approach ensures that we always pay the minimum possible amount by leveraging the offer optimally, thus minimizing the total cost. The complexity of this solution is dominated by the sorting step, making it O(N log N) per test case, which is efficient given the problem constraints.
