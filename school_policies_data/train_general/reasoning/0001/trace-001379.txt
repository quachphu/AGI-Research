To solve this problem, we need to determine the number of valid arrangements of footmen and horsemen such that there are no more than k1 consecutive footmen or k2 consecutive horsemen. The solution uses dynamic programming with memoization to efficiently explore all possible valid configurations.

### Approach
1. **Dynamic Programming (DP) with Memoization**: We use a recursive DP approach with memoization to avoid recomputing the same states. The state is defined by the remaining number of footmen (n1) and horsemen (n2), the last type of soldier added (0 for footman, 1 for horseman), and the count of consecutive soldiers of that type.
2. **State Transitions**: For each state, we consider adding another soldier of the same type if it does not exceed the allowed consecutive count, or switching to the other type of soldier, which resets the consecutive count.
3. **Base Case**: When there are no footmen or horsemen left, we have a valid arrangement, contributing 1 to the count.
4. **Modulo Operation**: Since the result can be very large, we take modulo \(10^8\) at each step to prevent overflow and ensure the result is within the required range.

### Solution Code
```python
import sys
from functools import lru_cache

def main():
    n1, n2, k1, k2 = map(int, sys.stdin.readline().split())
    MOD = 10**8

    @lru_cache(maxsize=None)
    def dp(remaining_n1, remaining_n2, last_type, current_count):
        if remaining_n1 == 0 and remaining_n2 == 0:
            return 1
        
        total = 0
        # Try adding the same type if possible
        if last_type == 0:  # Last was footman
            if remaining_n1 > 0 and current_count < k1:
                total += dp(remaining_n1 - 1, remaining_n2, 0, current_count + 1)
            # Switch to horseman
            if remaining_n2 > 0:
                total += dp(remaining_n1, remaining_n2 - 1, 1, 1)
        else:  # Last was horseman
            if remaining_n2 > 0 and current_count < k2:
                total += dp(remaining_n1, remaining_n2 - 1, 1, current_count + 1)
            # Switch to footman
            if remaining_n1 > 0:
                total += dp(remaining_n1 - 1, remaining_n2, 0, 1)
        
        return total % MOD

    result = 0
    if n1 > 0:
        result += dp(n1 - 1, n2, 0, 1)
    if n2 > 0:
        result += dp(n1, n2 - 1, 1, 1)
    
    print(result % MOD)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input values for the number of footmen (n1), horsemen (n2), and their respective consecutive limits (k1, k2) are read from standard input.
2. **Memoized DP Function**: The `dp` function is defined with memoization to cache results of previously computed states. It checks if adding another soldier of the same type is valid or if switching to the other type is necessary.
3. **Initial Calls**: The solution starts by considering both possibilities of starting with a footman or a horseman, if available.
4. **Modulo Operation**: The result is taken modulo \(10^8\) at each step to ensure it fits within the required constraints.

This approach efficiently explores all valid configurations using dynamic programming and memoization, ensuring optimal performance even for the upper constraint limits.
