### Solution Code
```python
import sys

def main():
    # Read the first line and split into n and x
    n, x = map(int, sys.stdin.readline().split())
    # Read the next line and split into a list of integers
    numbers = list(map(int, sys.stdin.readline().split()))
    # Check if x is present in the list
    print(1 if x in numbers else 0)

# Call the main function
main()
```

1. **Reading Input**: The `sys.stdin.readline()` method is used to read input lines. The first line is split into two integers \( n \) and \( x \).
2. **Conversion**: The second line is split into a list of integers using `map(int, ...)`.
3. **Presence Check**: A simple membership check using `x in numbers` determines if \( x \) is present in the list. The result is printed as 1 or 0 based on the check.
