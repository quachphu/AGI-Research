To solve this problem, we need to determine if Takahashi's age, given as an integer input, is one of the celebrated ages in the Shichi-Go-San tradition, which are 3, 5, and 7 years old. 

### Approach
1. **Problem Analysis**: The Shichi-Go-San tradition celebrates children who are exactly 3, 5, or 7 years old. Therefore, the solution requires checking if the given age falls into any of these specific values.
2. **Input Handling**: Read the input value, which is a single integer.
3. **Check Membership**: Verify if the input age is one of the celebrated ages (3, 5, or 7) using a set for efficient membership testing.
4. **Output Result**: Print "YES" if the age is celebrated, otherwise print "NO".

### Solution Code
```python
x = int(input())
print("YES" if x in {3, 5, 7} else "NO")
```

### Explanation
1. **Reading Input**: The input is read as an integer using `int(input())`.
2. **Checking Membership**: The age is checked against the set `{3, 5, 7}`. Sets in Python allow for O(1) average-time complexity for membership checks, making this operation efficient.
3. **Output Decision**: Based on the membership check, the result is printed as "YES" if the age is 3, 5, or 7, otherwise "NO".

This approach efficiently and directly addresses the problem requirements with a clear and concise implementation.
