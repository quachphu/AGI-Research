To solve this problem, we need to determine which player, Red or Blue, has a higher probability of winning a bet based on the digits on shuffled cards. The solution involves comparing the digits on each card and determining the outcome based on the first differing digit in a random permutation of the cards.

### Approach
1. **Problem Analysis**: The problem requires comparing two numbers formed by red and blue digits on cards arranged in random order. The key insight is that the first differing digit in the permutation determines the outcome. If all digits are the same, the result is a draw.
2. **Key Insight**: Each card can be categorized into three types:
   - Type A: Red digit is greater than blue digit.
   - Type B: Red digit is less than blue digit.
   - Type E: Red and blue digits are equal.
3. **Probability Calculation**: The outcome is determined by the first card of type A or B in the permutation. The probability of Red winning is proportional to the number of type A cards, and Blue's probability is proportional to the number of type B cards. If the counts of type A and B cards are equal, the result is a draw.

### Solution Code
```python
T = int(input())
for _ in range(T):
    n = int(input())
    r = input().strip()
    b = input().strip()
    a = 0
    blue_count = 0
    for i in range(n):
        if r[i] > b[i]:
            a += 1
        elif r[i] < b[i]:
            blue_count += 1
    if a > blue_count:
        print("RED")
    elif a < blue_count:
        print("BLUE")
    else:
        print("EQUAL")
```

### Explanation
1. **Reading Input**: The number of test cases is read first. For each test case, the number of cards and the respective red and blue digits are read.
2. **Digit Comparison**: Each card's red and blue digits are compared. The counts of type A (red digit greater) and type B (blue digit greater) cards are recorded.
3. **Result Determination**: Based on the counts of type A and B cards, the result is determined. If type A cards are more, Red wins; if type B cards are more, Blue wins; if counts are equal, the result is a draw.

This approach efficiently determines the winner by focusing on the counts of differing digits, ensuring optimal performance even for the upper limits of input size.
