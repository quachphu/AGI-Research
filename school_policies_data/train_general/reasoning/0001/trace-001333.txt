To solve this problem, we need to determine the minimum number of candles Anya should light so that each ghost's visit is illuminated by at least `r` candles burning. If it's impossible to meet this requirement, we should return `-1`.

### Approach
1. **Check Feasibility**: If the required number of candles `r` for each ghost's visit exceeds the burn duration `t` of a candle, it is impossible to meet the requirement, so we immediately return `-1`.
2. **Interval Calculation**: For each ghost visit time `wi`, calculate the interval `[wi - t, wi - 1]` during which a candle must be lit to be burning at time `wi`.
3. **Greedy Placement**: Use a greedy approach to place candles as far to the right as possible within each interval to maximize their coverage of subsequent intervals. This ensures that each candle contributes to as many intervals as possible, minimizing the total number of candles used.

### Solution Code
```python
m, t, r = map(int, input().split())
w_list = list(map(int, input().split()))

if r > t:
    print(-1)
else:
    candles = set()
    possible = True
    for wi in w_list:
        s = wi - t
        e = wi - 1
        count = 0
        for x in candles:
            if s <= x <= e:
                count += 1
        needed = r - count
        if needed <= 0:
            continue
        added = 0
        current_x = e
        new_candles = []
        while added < needed and current_x >= s:
            if current_x not in candles:
                new_candles.append(current_x)
                added += 1
            current_x -= 1
        if added < needed:
            possible = False
            break
        for x in new_candles:
            candles.add(x)
    print(len(candles) if possible else -1)
```
