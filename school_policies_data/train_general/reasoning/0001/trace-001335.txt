To solve this problem, we need to determine the minimum width of the road required for Vanya and his friends to walk in a row without being noticed by the guard. The key consideration is that each friend's height relative to the fence's height determines whether they need to bend, which affects their width.

### Approach
1. **Problem Analysis**: Each friend's height is compared to the fence's height. If a friend's height exceeds the fence's height, they must bend down, increasing their width from 1 to 2. The goal is to compute the total width required for all friends.
2. **Intuition**: For each friend, check if their height is greater than the fence's height. If it is, add 2 to the total width; otherwise, add 1. Summing these values gives the minimum required width.
3. **Algorithm**: 
   - Read the number of friends and the fence's height.
   - Read the list of friends' heights.
   - For each friend, determine their contribution to the total width based on their height relative to the fence.
   - Sum these contributions and print the result.

### Solution Code
```python
n, h = map(int, input().split())
heights = list(map(int, input().split()))
width = 0
for height in heights:
    if height > h:
        width += 2
    else:
        width += 1
print(width)
```

### Explanation
1. **Reading Input**: The first line of input contains two integers, `n` (number of friends) and `h` (fence height). The second line contains `n` integers representing the heights of the friends.
2. **Processing Each Friend**: For each friend's height, check if it exceeds `h`. If it does, the width contribution is 2; otherwise, it is 1.
3. **Summing Contributions**: Accumulate the width contributions for all friends and print the total.

This approach efficiently computes the required width in linear time, making it suitable for the given constraints (up to 1000 friends). The solution ensures that each friend's contribution is evaluated independently, leading to an optimal and correct result.
