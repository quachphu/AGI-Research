To solve this problem, we need to determine if a given triangle is right-angled, almost right-angled, or neither. A triangle is right-angled if one of its angles is 90 degrees. An almost right-angled triangle is one that can become right-angled by moving one of its vertices by exactly 1 unit in any direction (up, down, left, right) while ensuring the coordinates remain integers.

### Approach
1. **Check if the Original Triangle is Right-Angled**: Calculate the squared distances between each pair of vertices. If the largest squared distance equals the sum of the other two, the triangle is right-angled.
2. **Generate Modified Triangles**: For each vertex, move it by 1 unit in each of the four possible directions (up, down, left, right) to generate new triangles.
3. **Check Each Modified Triangle**: For each new triangle, check if it is non-degenerate (i.e., has a non-zero area) and right-angled. If any such triangle is found, the original triangle is almost right-angled.

### Solution Code
```python
x1, y1, x2, y2, x3, y3 = map(int, input().split())

original = [(x1, y1), (x2, y2), (x3, y3)]

def is_right(points):
    a, b, c = points
    ab_sq = (a[0] - b[0])**2 + (a[1] - b[1])**2
    ac_sq = (a[0] - c[0])**2 + (a[1] - c[1])**2
    bc_sq = (b[0] - c[0])**2 + (b[1] - c[1])**2
    sides = sorted([ab_sq, ac_sq, bc_sq])
    return sides[2] == sides[0] + sides[1]

def is_non_degenerate(points):
    a, b, c = points
    det = (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])
    return det != 0

original_right = is_right(original)

if original_right:
    print("RIGHT")
else:
    directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
    found = False
    for i in range(3):
        for dx, dy in directions:
            new_points = list(original)
            x, y = new_points[i]
            new_point = (x + dx, y + dy)
            new_points[i] = new_point
            if is_non_degenerate(new_points) and is_right(new_points):
                found = True
                break
        if found:
            break
    print("ALMOST" if found else "NEITHER")
```

### Explanation
1. **Check Original Triangle**: The function `is_right` checks if the original triangle is right-angled by verifying the Pythagorean theorem for the squared distances between each pair of vertices.
2. **Generate and Check Modified Triangles**: For each vertex, the code generates new positions by moving it in four possible directions. Each new triangle is checked for non-degeneracy using `is_non_degenerate` (ensuring non-zero area) and right-angled using `is_right`.
3. **Output Result**: If the original triangle is right-angled, "RIGHT" is printed. Otherwise, if any modified triangle is valid, "ALMOST" is printed. If none are valid, "NEITHER" is printed.

This approach efficiently checks all possible modifications and ensures correctness by verifying both non-degeneracy and the right-angle condition for each candidate triangle.
