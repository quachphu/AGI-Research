To solve this problem, we need to determine two key metrics based on the interactions between students in a college due to a special perfume: the maximum number of beatings received by any student and the number of mutual pairs where each student beats the other.

### Approach
1. **Understanding the Problem**: Each student (boy or girl) beats their crush's crush if they are different individuals. We need to track how many times each student is beaten and identify mutual beating pairs.

2. **Data Structures**:
   - **boys_beaten** and **girls_beaten**: Arrays to count the number of beatings each boy and girl receives.
   - **mutual_count**: To track the number of mutual pairs.

3. **Steps**:
   - **Count Beatings**: For each boy and girl, determine who they beat and update the respective count arrays.
   - **Determine Maximum Beatings**: Find the maximum value in the beat count arrays.
   - **Identify Mutual Pairs**: Check for each student if their target also targets them back, ensuring each pair is counted only once.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        boys = list(map(int, input[ptr:ptr + N]))
        ptr += N
        girls = list(map(int, input[ptr:ptr + N]))
        ptr += N
        
        boys_beaten = [0] * (N + 1)
        girls_beaten = [0] * (N + 1)
        
        for x in range(1, N + 1):
            girl_liked = boys[x - 1]
            z = girls[girl_liked - 1]
            if x != z:
                boys_beaten[z] += 1
        
        for a in range(1, N + 1):
            boy_liked = girls[a - 1]
            c = boys[boy_liked - 1]
            if a != c:
                girls_beaten[c] += 1
        
        max_boys = max(boys_beaten) if N > 0 else 0
        max_girls = max(girls_beaten) if N > 0 else 0
        max_beat = max(max_boys, max_girls)
        
        mutual_count = 0
        
        for x in range(1, N + 1):
            girl_liked = boys[x - 1]
            z = girls[girl_liked - 1]
            if x < z:
                girl_liked_z = boys[z - 1]
                z_target = girls[girl_liked_z - 1]
                if z_target == x:
                    mutual_count += 1
        
        for a in range(1, N + 1):
            boy_liked = girls[a - 1]
            c = boys[boy_liked - 1]
            if a < c:
                boy_liked_c = girls[c - 1]
                c_target = boys[boy_liked_c - 1]
                if c_target == a:
                    mutual_count += 1
        
        print(max_beat, mutual_count)

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read and parsed to extract the number of test cases and the crush lists for boys and girls.
2. **Counting Beatings**: For each boy and girl, we determine who they beat and increment the corresponding count in the `boys_beaten` or `girls_beaten` array.
3. **Finding Maximum Beatings**: The maximum value from the beat count arrays is computed to answer the first question.
4. **Identifying Mutual Pairs**: For each student, we check if their target also beats them back, ensuring each pair is counted once to avoid duplicates.

This approach efficiently handles up to the maximum constraints, ensuring the solution is both optimal and correct.
