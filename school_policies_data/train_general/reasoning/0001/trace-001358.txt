To solve this problem, we need to compute the median of an array after excluding each element one by one. Given the constraints, a direct approach of repeatedly sorting the array after each exclusion would be inefficient. Instead, we can leverage sorting and precomputation to efficiently determine the medians.

### Approach
1. **Sorting with Indices**: First, sort the array while keeping track of the original indices. This helps in efficiently determining the position of each element in the sorted array.
2. **Position Mapping**: Create a mapping from the original indices to their positions in the sorted array. This allows us to quickly determine where each element would be located in the sorted array.
3. **Median Determination**: After sorting, the median of the array excluding an element can be determined based on the position of the excluded element in the sorted array. If the element is in the first half of the sorted array, the median of the remaining elements will be the middle element of the second half. Conversely, if the element is in the second half, the median will be the middle element of the first half.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    X = list(map(int, input[1:N+1]))
    
    sorted_with_indices = sorted((x, i) for i, x in enumerate(X))
    pos = [0] * N
    for k in range(N):
        x, original_index = sorted_with_indices[k]
        pos[original_index] = k
    
    S = [x for x, i in sorted_with_indices]
    median_pos = N // 2
    
    for j in range(N):
        k = pos[j]
        if k < median_pos:
            print(S[median_pos])
        else:
            print(S[median_pos - 1])

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read and parsed into an integer `N` and a list `X` of integers.
2. **Sorting with Indices**: The list `X` is sorted along with their original indices. This sorted list helps in determining the position of each element in the original array.
3. **Position Mapping**: An array `pos` is created where `pos[i]` gives the position of the element originally at index `i` in the sorted array.
4. **Median Calculation**: For each element in the original array, based on its position in the sorted array, the median of the remaining elements is determined. If the element is in the first half of the sorted array, the median is the middle element of the second half. Otherwise, it is the middle element of the first half.
