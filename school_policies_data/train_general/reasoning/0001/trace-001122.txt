To solve this problem, we need to determine the minimum number of adjacent swaps required to ensure that each couple (represented by the same integer) is seated next to each other in a line. 

### Approach
The approach involves a greedy algorithm where we process the array from left to right, ensuring each pair of adjacent positions (starting from even indices) contains a couple. If they are not already a couple, we find the position of the other member of the couple and swap it into place, counting each adjacent swap required. This method ensures that once a pair is fixed, we do not need to revisit it, leading to an efficient solution.

### Solution Code
```python
n = int(input())
arr = list(map(int, input().split()))
swap_count = 0

for i in range(0, 2 * n, 2):
    if arr[i] == arr[i + 1]:
        continue
    # Find the index of the partner
    j = i + 1
    while j < 2 * n and arr[j] != arr[i]:
        j += 1
    # Bring the partner to i+1 by adjacent swaps
    while j > i + 1:
        arr[j], arr[j - 1] = arr[j - 1], arr[j]
        swap_count += 1
        j -= 1

print(swap_count)
```

### Explanation
1. **Reading Input:** We first read the number of pairs `n` and the list of integers representing the people in line.
2. **Initialization:** We initialize `swap_count` to zero to keep track of the number of swaps made.
3. **Processing Each Pair:** We iterate over the list in steps of 2 (starting from each even index). For each index `i`, we check if the person at `i` and `i+1` form a couple.
4. **Finding the Partner:** If they do not form a couple, we find the position `j` of the partner (the other occurrence of the same integer) starting from `i+1`.
5. **Swapping into Place:** Once the partner is found at position `j`, we perform adjacent swaps to move this partner to position `i+1`, incrementing the swap count for each swap made.
6. **Output:** Finally, we print the total number of swaps required.

This approach ensures that each couple is moved into place with the minimum number of adjacent swaps by processing each position exactly once, leading to an efficient solution.
