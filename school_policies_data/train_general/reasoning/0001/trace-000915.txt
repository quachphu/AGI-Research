To solve this problem, we need to determine the maximum number of billiard balls that can be placed on an n×m chessboard such that no two balls can reach each other. The movement of the balls is similar to a bishop in chess but with reflections at the board's edges.

### Approach
The key insight is to recognize that the problem can be reduced to finding the number of distinct equivalence classes of cells under the billiard ball's movement rules. Each equivalence class consists of cells that can be reached from each other through the ball's movement and reflections. 

The number of these equivalence classes is determined by the greatest common divisor (gcd) of (n-1) and (m-1). The formula for the maximum number of non-attacking balls is derived from this gcd value plus 1. This is because the gcd captures the periodic nature of the ball's trajectory, and adding 1 accounts for the starting point and the reflections.

### Solution Code
```python
import math

n, m = map(int, input().split())
d = math.gcd(n-1, m-1)
print(d + 1)
```

3. **Result Calculation**: The result is the gcd value plus 1, which gives the number of distinct equivalence classes where each class can hold one ball without any conflict.

This approach efficiently computes the solution using the gcd function, ensuring optimal performance even for large values of n and m up to 10^6.
