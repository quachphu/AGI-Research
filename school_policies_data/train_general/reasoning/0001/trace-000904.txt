To solve this problem, we need to determine the minimum number of matches to buy so that we can form a correct match equation (CME) using all the matches we have. The CME must be in the form `a + b = c` where `a`, `b`, and `c` are positive integers, and all matches (including those bought) are used exactly.

### Approach
1. **Understanding the Structure of a CME**: The equation `a + b = c` requires that the sum of `a` and `b` matches equals `c`. The total number of matches used in the equation is `a + b + c`. Additionally, the operators `+` and `=` do not consume any matches, so they are not counted in the total.
2. **Formulating the Problem**: Given `n` matches, we need to find the smallest number of matches `k` to buy such that `n + k` can be expressed as `a + b + c` where `a + b = c`. This translates to finding the smallest even number `m` (since `a + b + c = 2(a + b)`) that is at least 4 and greater than or equal to `n`.
3. **Key Observations**:
   - If `n` is less than 4, the minimum matches needed to form a valid CME is `4 - n`.
   - If `n` is 4 or more and even, no additional matches are needed.
   - If `n` is 4 or more and odd, one additional match is needed to make the total even.

### Solution Code
```python
q = int(input())
for _ in range(q):
    n = int(input())
    if n < 4:
        print(4 - n)
    else:
        print(0 if n % 2 == 0 else 1)
```

### Explanation
- **For `n` less than 4**: The smallest valid CME requires 4 matches (e.g., `1 + 1 = 2` uses 4 matches). Thus, the number of matches to buy is `4 - n`.
- **For `n` 4 or more**:
  - If `n` is even, it can be directly split into valid values of `a`, `b`, and `c` (e.g., `n = 8` can be split into `1 + 3 = 4` using 8 matches).
  - If `n` is odd, converting it to the next even number by adding 1 match ensures it can be split into valid values (e.g., `n = 5` becomes 6, which can be split into `1 + 2 = 3` using 6 matches).

This approach efficiently determines the minimum number of matches to buy with a constant time complexity per query, making it suitable for large input sizes up to the constraint limits.
