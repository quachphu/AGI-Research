To solve this problem, we need to determine the minimum number of vertical or horizontal segments required to turn off all alarm clocks in Inna's room. The key insight is that each vertical segment can cover all points sharing the same x-coordinate, and each horizontal segment can cover all points sharing the same y-coordinate. Thus, the solution involves counting the distinct x-coordinates and y-coordinates and choosing the smaller count.

### Approach
1. **Input Reading**: Read the number of alarm clocks and their coordinates.
2. **Coordinate Collection**: Use sets to collect all unique x-coordinates and y-coordinates from the input points.
3. **Comparison**: The minimum number of segments required will be the smaller of the counts of unique x-coordinates and unique y-coordinates.

### Solution Code
```python
n = int(input())
x_set = set()
y_set = set()

for _ in range(n):
    x, y = map(int, input().split())
    x_set.add(x)
    y_set.add(y)

print(min(len(x_set), len(y_set)))
```

### Explanation
- **Reading Input**: The input is read, starting with the number of points, followed by their coordinates.
- **Collecting Coordinates**: Using sets ensures that we only keep unique x and y values. This is efficient because set operations (insertions and lookups) average O(1) time complexity.
- **Calculating Minimum Segments**: The minimum number of segments required is determined by comparing the sizes of the sets of unique x and y coordinates. This comparison gives the optimal number of segments needed, either vertical or horizontal, whichever is fewer.

This approach efficiently computes the result with a time complexity of O(n), where n is the number of alarm clocks, making it suitable for large input sizes up to 100,000.
