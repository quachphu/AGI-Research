To solve this problem, we need to track the number of open tweets after each click operation, which can either toggle the state of a specific tweet or close all tweets. The solution involves efficiently managing the state of each tweet using a set data structure to handle the operations in constant time.

### Approach
1. **Initialization**: Start with all tweets closed. We use a set to keep track of open tweets.
2. **Processing Operations**:
   - **CLICK X**: Toggle the state of tweet X. If X is in the set, remove it (closing the tweet), otherwise add it (opening the tweet).
   - **CLOSEALL**: Clear the set, closing all tweets.
3. **Output**: After each operation, the size of the set (number of open tweets) is printed.

Using a set allows us to efficiently toggle the state of individual tweets and clear all states in constant time, leading to an overall time complexity of O(K), where K is the number of operations.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().splitlines()
    n, k = map(int, input[0].split())
    open_set = set()
    idx = 1
    for _ in range(k):
        line = input[idx].strip()
        idx += 1
        if line == 'CLOSEALL':
            open_set.clear()
        else:
            action, x = line.split()
            x = int(x)
            if x in open_set:
                open_set.remove(x)
            else:
                open_set.add(x)
        print(len(open_set))

main()
```

### Explanation
- **Reading Input**: The input is read all at once and split into lines for efficient processing.
- **Set Operations**: The set `open_set` is used to track open tweets. For each `CLICK X` operation, the presence of X in the set is checked and toggled. For `CLOSEALL`, the set is cleared.
- **Output**: After each operation, the size of the set is printed, which represents the number of open tweets.

This approach ensures that each operation is handled in constant time, making the solution efficient and suitable for the given constraints.
