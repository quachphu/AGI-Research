To solve this problem, we need to determine the smallest set of candy bags that exactly sum up to a given number X. If there are multiple sets of the same size, we must choose the lexicographically smallest one. 

### Approach
1. **Generate All Subsets**: Since the number of bags (N) is up to 20, we can use a bitmask approach to generate all possible non-empty subsets efficiently.
2. **Check Subset Sum**: For each subset, compute the sum of candies. If the sum matches X, record the subset.
3. **Track Optimal Subset**: Among all valid subsets, track the smallest size. If multiple subsets have the same smallest size, choose the lexicographically smallest one by comparing their sorted indices.

### Solution Code
```python
def find_min_lex_subset():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    X = int(input[1])
    A = list(map(int, input[2:2+N]))
    
    best_subset = None
    min_size = float('inf')
    
    for mask in range(1, 1 << N):
        current_sum = 0
        indices = []
        for i in range(N):
            if mask & (1 << i):
                current_sum += A[i]
                indices.append(i + 1)  # convert to 1-based index
        if current_sum == X:
            current_size = len(indices)
            indices_sorted = sorted(indices)
            if best_subset is None:
                best_subset = indices_sorted
                min_size = current_size
            else:
                if current_size < min_size:
                    best_subset = indices_sorted
                    min_size = current_size
                elif current_size == min_size:
                    if indices_sorted < best_subset:
                        best_subset = indices_sorted
    
    if best_subset is not None:
        print(' '.join(map(str, best_subset)))
    else:
        print(-1)

find_min_lex_subset()
```

### Explanation
1. **Reading Input**: The input is read from standard input, which includes the number of bags (N), the target sum (X), and the list of candies in each bag.
2. **Bitmask Loop**: We iterate over all possible non-empty subsets using a bitmask from 1 to 2^N - 1.
3. **Sum Calculation**: For each subset (represented by a bitmask), we calculate the sum of candies and collect the indices of the bags included in the subset.
4. **Check Validity**: If the subset sum equals X, we check if this subset is better than the current best subset by comparing sizes and lexicographical order.
5. **Output Result**: After processing all subsets, the best valid subset is printed if found; otherwise, -1 is printed.

This approach efficiently explores all possible subsets using bitmasking, ensuring we find the optimal solution within the constraints.
