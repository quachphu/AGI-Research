To solve this problem, we need to count the number of integer sequences that are similar to a given sequence and have an even product. The sequences are considered similar if each element differs by at most 1 from the corresponding element in the given sequence. The product of the sequence is even if at least one element is even.

### Approach
1. **Total Similar Sequences**: Calculate the total number of sequences similar to the given sequence. Each element in the sequence can take three possible values (A_i - 1, A_i, A_i + 1), leading to 3^N possible sequences where N is the length of the sequence.
2. **All-Odd Sequences**: Calculate the number of sequences where all elements are odd. For each element in the given sequence, determine how many of its possible similar values are odd. The product of these counts for all elements gives the total number of sequences where all elements are odd.
3. **Result Calculation**: Subtract the number of all-odd sequences from the total number of similar sequences to get the count of sequences with an even product.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))

total = 3 ** n
all_odd = 1

for x in a:
    cnt = 0
    for num in [x-1, x, x+1]:
        if num % 2 == 1:
            cnt += 1
    all_odd *= cnt

print(total - all_odd)
```

### Explanation
1. **Reading Input**: The input consists of an integer N and a sequence of N integers.
2. **Total Similar Sequences**: The total number of similar sequences is 3^N since each element has 3 possible values.
3. **Counting All-Odd Sequences**: For each element in the sequence, check how many of its possible values (A_i - 1, A_i, A_i + 1) are odd. Multiply these counts for all elements to get the total number of all-odd sequences.
4. **Result Calculation**: Subtract the count of all-odd sequences from the total number of similar sequences to get the number of sequences with an even product.

This approach efficiently computes the result using simple arithmetic and iteration, ensuring correctness within the problem constraints.
