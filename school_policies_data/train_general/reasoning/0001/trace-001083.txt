To solve this problem, we need to determine how many combinations of two or more consecutive positive integers sum up to a given positive integer \( N \). The solution involves mathematical insights and efficient iteration to check possible combinations.

### Approach
1. **Mathematical Insight**: The sum of \( k \) consecutive integers starting from \( a \) can be represented as \( k \cdot a + \frac{k \cdot (k-1)}{2} = N \). Rearranging this formula, we derive \( a = \frac{2N - k(k-1)}{2k} \). For \( a \) to be a positive integer, the numerator \( (2N - k(k-1)) \) must be divisible by \( 2k \) and result in a positive value.
2. **Divisibility Check**: For each possible \( k \) starting from 2 up to a maximum value derived from the equation \( k(k+1) \leq 2N \), check if \( 2N \) is divisible by \( k \). If true, compute the potential starting integer \( a \) and check if it is positive and valid.
3. **Efficient Iteration**: Calculate the maximum possible value of \( k \) using the quadratic formula to avoid unnecessary checks, ensuring the solution is efficient even for the upper limit of \( N = 1000 \).

### Solution Code
```python
import math
import sys

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        N = int(line)
        if N == 0:
            break
        count = 0
        if 2 * N >= 2 * (2 + 1):  # Check if max_k could be at least 2
            max_k = int((math.sqrt(1 + 8 * N) - 1) // 2)
            for k in range(2, max_k + 1):
                if (2 * N) % k == 0:
                    temp = (2 * N // k) - k + 1
                    if temp > 0 and temp % 2 == 0:
                        count += 1
        print(count)

if __name__ == "__main__":
    main()
```

3. **Divisibility and Validity Check**: For each \( k \) from 2 to the calculated maximum, the code checks if \( 2N \) is divisible by \( k \). If true, it computes the potential starting integer \( a \) and checks if it is a positive even integer.
4. **Counting Valid Combinations**: Valid combinations are counted and printed for each input \( N \).

This approach efficiently narrows down the possible values of \( k \) and checks each one using mathematical properties, ensuring the solution is both correct and optimal.
