To solve this problem, we need to determine the original string `s` that Bob used to generate the string `t` by concatenating `s` and `s'`, where `s'` is `s` with all 'a' characters removed. The solution involves verifying possible candidates for `s` and checking if they can generate the given `t`.

### Approach
1. **Prefix Sum of 'a' Characters**: Compute the prefix sum array `a_counts` where `a_counts[i]` represents the number of 'a' characters in the substring `t[0:i]`.
2. **Non-'a' Characters**: Construct a string `non_a_str` containing all non-'a' characters from `t`.
3. **Candidate Validation**: Iterate over possible lengths of `s` (denoted as `n`). For each candidate `n`, check if it satisfies the equation `2n - k = L`, where `k` is the number of 'a' characters in the first `n` characters of `t` and `L` is the length of `t`.
4. **String Comparison**: For valid candidates, verify if the substring of `t` starting from index `n` matches the first `n - k` characters of `non_a_str`.

### Solution Code
```python
def find_s():
    t = input().strip()
    L = len(t)
    if L == 0:
        print(":(")
        return
    
    # Compute a_counts where a_counts[i] is the number of 'a's in t[0..i-1]
    a_counts = [0] * (L + 1)
    current_a = 0
    for i in range(L):
        a_counts[i] = current_a
        if t[i] == 'a':
            current_a += 1
    a_counts[L] = current_a  # Handle the case where n is exactly L
    
    # Collect all non 'a' characters in t to form non_a_str
    non_a = []
    for c in t:
        if c != 'a':
            non_a.append(c)
    non_a_str = ''.join(non_a)
    
    # Iterate possible n from (L+1)//2 up to L
    start_n = (L + 1) // 2
    for n in range(start_n, L + 1):
        if n > L:
            break  # n cannot exceed the length of t
        k = a_counts[n]
        if 2 * n - k != L:
            continue
        m = n - k
        # Check if non_a_str has at least m characters
        if m > len(non_a_str):
            continue
        s_prime_candidate = non_a_str[:m]
        actual_s_prime = t[n:]
        if s_prime_candidate == actual_s_prime:
            print(t[:n])
            return
    # If no valid n found
    print(':(')

find_s()
```

### Explanation
1. **Prefix Sum Calculation**: The `a_counts` array helps quickly determine the number of 'a' characters in any prefix of `t`.
2. **Non-'a' String Construction**: `non_a_str` is used to efficiently check if the remaining part of `t` matches the expected `s'`.
3. **Candidate Validation**: By iterating over possible values of `n` starting from the midpoint of `t`, we efficiently narrow down potential candidates for `s`.
4. **String Matching**: Direct comparison of the remaining part of `t` with the corresponding part of `non_a_str` ensures correctness.

This approach ensures that we efficiently check all possible candidates while maintaining optimal time complexity, making it suitable for large input sizes.
