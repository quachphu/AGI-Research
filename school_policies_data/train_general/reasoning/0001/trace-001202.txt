To solve this problem, we need to determine if a given string represents a valid pair of chessboard cells and if the move between these cells is a valid knight move. 

### Approach
1. **Validation of Input Format**: 
   - The input string must be exactly 5 characters long.
   - The third character must be a dash ('-').
   - The first two and last two characters must be valid chessboard cells. A valid cell consists of a lowercase letter from 'a' to 'h' followed by a digit from '1' to '8'.

2. **Knight Move Validation**:
   - Convert the valid cells into numerical coordinates.
   - Calculate the differences in the x and y coordinates between the start and end cells.
   - Check if these differences correspond to a knight's L-shaped move (either 2 squares in one direction and 1 in the perpendicular, or 1 in one direction and 2 in the perpendicular).

### Solution Code
```python
def main():
    import sys
    lines = sys.stdin.read().splitlines()
    T = int(lines[0])
    for s in lines[1:T+1]:
        if len(s) != 5:
            print("Error")
            continue
        if s[2] != '-':
            print("Error")
            continue
        part1 = s[:2]
        part2 = s[3:]
        valid = True
        for part in [part1, part2]:
            if len(part) != 2:
                valid = False
                break
            c, d = part[0], part[1]
            if not ('a' <= c <= 'h'):
                valid = False
            if not ('1' <= d <= '8'):
                valid = False
        if not valid:
            print("Error")
            continue
        # Convert to coordinates
        x1 = ord(part1[0]) - ord('a')
        y1 = int(part1[1]) - 1
        x2 = ord(part2[0]) - ord('a')
        y2 = int(part2[1]) - 1
        dx = abs(x2 - x1)
        dy = abs(y2 - y1)
        if (dx == 1 and dy == 2) or (dx == 2 and dy == 1):
            print("Yes")
        else:
            print("No")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into lines for efficient processing.
2. **Validation Checks**:
   - **Length Check**: Ensures the string is exactly 5 characters.
   - **Dash Check**: Ensures the third character is a dash.
   - **Cell Validity Check**: Validates that both the start and end cells are within the bounds of a chessboard.
3. **Coordinate Conversion**: Converts the chessboard cell notation (like 'a1') into numerical coordinates for easier calculation.
4. **Knight Move Check**: Uses the differences in coordinates to determine if the move follows the knight's L-shaped pattern.

This approach efficiently checks each input string for validity and determines if the move is a valid knight move, ensuring correctness and optimal performance even for the upper constraint of 50,000 test cases.
