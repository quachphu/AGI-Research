class DSU:
    def __init__(self, n):
        self.parent = list(range(n+1))  # nodes are 1-based
        self.rank = [0]*(n+1)
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return False
        if self.rank[x_root] < self.rank[y_root]:
            self.parent[x_root] = y_root
        else:
            self.parent[y_root] = x_root
            if self.rank[x_root] == self.rank[y_root]:
                self.rank[x_root] += 1
        return True

To solve this problem, we need to determine the maximum number of roads that can be destroyed while ensuring that both men and women can still travel between any pair of cities. Men can use roads of types 1 and 3, while women can use roads of types 2 and 3. The solution involves finding the minimal set of roads that keeps both networks connected and then subtracting this number from the total number of roads.

### Approach
1. **Check Connectivity**: First, ensure that both the men's and women's networks are initially connected. If either is not connected, output -1.
2. **Spanning Trees**: Use Kruskal's algorithm to find spanning trees for both men and women. Prioritize type 3 roads for men to maximize potential overlap with women's spanning tree.
3. **Maximize Overlap**: For women's spanning tree, prioritize roads that were used in the men's spanning tree (type 3) to maximize overlap, thus minimizing the total number of unique roads required.
4. **Union of Spanning Trees**: Calculate the union of the two spanning trees. The size of this union gives the minimal number of roads required to keep both networks connected.

class DSU:
    def __init__(self, n):
        self.parent = list(range(n + 1))  # 1-based indexing
        self.rank = [0] * (n + 1)
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return False
        if self.rank[x_root] < self.rank[y_root]:
            self.parent[x_root] = y_root
        else:
            self.parent[y_root] = x_root
            if self.rank[x_root] == self.rank[y_root]:
                self.rank[x_root] += 1
        return True
