To solve this problem, we need to determine the minimum number of moves required to make a given integer \( a \) divisible by another integer \( b \) by incrementing \( a \) by 1 in each move. The solution involves calculating the remainder when \( a \) is divided by \( b \) and using this remainder to determine the required moves.

### Approach
1. **Understanding the Problem**: For each test case, we are given two integers \( a \) and \( b \). We need to find the smallest number of increments needed to make \( a \) a multiple of \( b \).
2. **Key Insight**: If \( a \) is already a multiple of \( b \), the number of moves required is 0. Otherwise, the number of moves required is \( b - (a \% b) \), where \( a \% b \) is the remainder when \( a \) is divided by \( b \).
3. **Efficient Calculation**: Directly compute the remainder and check if it is zero. If not, compute the difference between \( b \) and the remainder to get the required moves.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        a, b = map(int, sys.stdin.readline().split())
        remainder = a % b
        print(0 if remainder == 0 else b - remainder)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency, especially given the constraints where \( t \) can be up to \( 10^4 \).
2. **Processing Each Test Case**: For each test case, compute the remainder of \( a \) divided by \( b \).
3. **Determining Moves**: If the remainder is zero, \( a \) is already divisible by \( b \), so no moves are needed. Otherwise, the number of moves required is the difference between \( b \) and the remainder, which ensures \( a \) becomes the next multiple of \( b \).

This approach ensures that each test case is processed in constant time \( O(1) \), leading to an overall time complexity of \( O(t) \), which is efficient and suitable for the given constraints.
