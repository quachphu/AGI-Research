To solve this problem, we need to determine the maximum number of clients Valera can serve given the camera's memory constraints. Each client requires a certain number of low and high-quality photos, and the goal is to serve as many clients as possible without exceeding the camera's memory capacity.

### Approach
1. **Problem Analysis**:
   - Each client's request consumes memory based on the number of low and high-quality photos they require.
   - The camera's memory is cumulative; once photos are stored, they are not deleted.
   - We need to find an optimal order of serving clients to maximize the number served without exceeding the memory limit.

2. **Key Insight**:
   - Clients with zero memory requirement (both low and high-quality photos count as zero) can always be served first as they do not consume any memory.
   - For other clients, processing them in ascending order of their memory consumption allows us to fit as many clients as possible within the memory limit.

3. **Algorithm**:
   - Separate clients into those with zero memory requirement and those with non-zero.
   - Sort non-zero clients by their memory consumption in ascending order.
   - Use a greedy approach to process clients starting from the smallest memory consumption, accumulating their memory usage until the limit is reached.

### Solution Code
```python
n, d = map(int, input().split())
a, b = map(int, input().split())

zero_clients = []
non_zero_clients = []

for idx in range(1, n+1):
    x, y = map(int, input().split())
    s = a * x + b * y
    if s == 0:
        zero_clients.append(idx)
    else:
        non_zero_clients.append((s, idx))

# Sort non-zero clients by their memory requirement
non_zero_clients.sort(key=lambda x: x[0])

sum_memory = 0
selected_non_zero = []

for s, idx in non_zero_clients:
    if sum_memory + s > d:
        break
    sum_memory += s
    selected_non_zero.append(idx)

total_clients = len(zero_clients) + len(selected_non_zero)
result = zero_clients + selected_non_zero

print(total_clients)
print(' '.join(map(str, result)))
```

### Explanation
1. **Reading Input**:
   - The first line reads the number of clients and the camera's memory capacity.
   - The second line reads the memory requirements for low and high-quality photos.
   - Subsequent lines read each client's request for photos and calculate the total memory required.

2. **Client Separation**:
   - Clients are split into those with zero memory requirement and others. Zero-memory clients are stored separately as they can always be served.

3. **Sorting and Selection**:
   - Non-zero clients are sorted by their memory requirement in ascending order.
   - Using a greedy approach, we process clients starting from the smallest memory requirement, accumulating their memory usage until the camera's memory limit is reached.

4. **Output**:
   - The total number of clients served is the sum of zero-memory clients and the selected non-zero clients.
   - The indices of the served clients are printed in the order they were processed, ensuring the memory constraint is respected at each step.
