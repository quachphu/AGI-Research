To solve this problem, we need to determine the winner of a battle between two monsters, where each monster attacks in turns. The monster with health dropping to zero or below first loses the battle.

### Approach
1. **Problem Analysis**: The battle alternates between Takahashi's monster and Aoki's monster, starting with Takahashi's. Each attack reduces the opponent's health by the attacker's strength. The key is to determine who can defeat the other first.
2. **Key Insight**: Calculate the minimum number of attacks required by each monster to defeat the opponent. Specifically, compute the number of attacks Takahashi's monster needs to defeat Aoki's and vice versa. The order of attacks is crucial as Takahashi's monster attacks first.
3. **Mathematical Calculation**: 
   - Compute the minimum number of attacks (k) required by Takahashi's monster to reduce Aoki's monster's health to zero using ceiling division.
   - Calculate the damage Takahashi's monster would sustain from Aoki's monster during (k-1) attacks (since Aoki's monster attacks after each of Takahashi's attacks except the final one).
4. **Decision**: If Takahashi's monster can survive the calculated damage, he wins; otherwise, he loses.

### Solution Code
```python
A, B, C, D = map(int, input().split())

k = (C + B - 1) // B
damage_takahashi = (k - 1) * D

print("Yes" if A > damage_takahashi else "No")
```

### Explanation
1. **Reading Input**: The input consists of four integers representing the health and strength of the two monsters.
2. **Calculate Required Attacks**: Using ceiling division, determine the minimum number of attacks (k) Takahashi's monster needs to defeat Aoki's monster. This is done using `(C + B - 1) // B`.
3. **Damage Calculation**: Calculate the damage Takahashi's monster would sustain from Aoki's monster during (k-1) attacks.
4. **Determine Winner**: Check if Takahashi's monster's health remains positive after the calculated damage. If yes, Takahashi wins; otherwise, he loses.

This approach efficiently determines the winner using mathematical calculations without simulating each attack, ensuring optimal performance even for the upper constraint values.
