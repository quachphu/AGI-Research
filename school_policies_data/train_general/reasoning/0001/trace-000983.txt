To solve this problem, we need to determine the number of prime numbers less than or equal to a given integer \( n \) for multiple datasets. The solution should efficiently handle multiple queries by precomputing prime numbers up to the maximum value encountered in the input using the Sieve of Eratosthenes algorithm.

### Approach
1. **Reading Input**: Read all input values at once and store them in a list.
2. **Determine Maximum Value**: Find the maximum value \( n \) from the input list to determine the upper limit for generating prime numbers.
3. **Sieve of Eratosthenes**: Use this algorithm to precompute prime numbers up to the maximum value. This algorithm efficiently marks non-prime numbers in a boolean array.
4. **Prefix Sum Array**: Construct a prefix sum array where each entry at index \( i \) contains the count of prime numbers from 0 to \( i \). This allows each query to be answered in constant time \( O(1) \).
5. **Output Results**: For each input value, use the prefix sum array to quickly retrieve and print the number of primes up to that value.

### Solution Code
```python
import sys

def main():
    n_values = list(map(int, sys.stdin.read().split()))
    if not n_values:
        return
    
    max_n = max(n_values)
    
    # Sieve of Eratosthenes to find primes up to max_n
    is_prime = [True] * (max_n + 1)
    is_prime[0], is_prime[1] = False, False
    for i in range(2, int(max_n ** 0.5) + 1):
        if is_prime[i]:
            for j in range(i * i, max_n + 1, i):
                is_prime[j] = False
    
    # Compute prefix sums of primes count
    prefix = [0] * (max_n + 1)
    count = 0
    for i in range(max_n + 1):
        if is_prime[i]:
            count += 1
        prefix[i] = count
    
    # Output the results for each input n
    for n in n_values:
        print(prefix[n])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of integers. This ensures we handle all datasets efficiently.
2. **Sieve of Eratosthenes**: This algorithm marks non-prime numbers by iterating through each number starting from 2 and marking its multiples. The complexity is \( O(n \log \log n) \), which is efficient for large values up to 999,999.
3. **Prefix Sum Array**: This array is constructed to store cumulative counts of primes up to each index. By precomputing this array, each query can be answered in constant time.
4. **Efficiency**: Precomputing primes and using a prefix sum array allows the solution to handle up to 30 queries efficiently, each in \( O(1) \) time after an initial \( O(n \log \log n) \) setup.

This approach ensures that the solution is both time and space efficient, making it suitable for handling the upper limits of the problem constraints.
