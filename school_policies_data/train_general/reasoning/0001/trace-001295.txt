To solve this problem, we need to determine the maximum number of soldiers that can be selected from a row such that each selected soldier has a unique skill. This is equivalent to finding the longest substring without repeating characters in a given string.

### Approach
The problem can be efficiently solved using the sliding window technique. This technique involves maintaining a window of characters that ensures all characters within the window are unique. Here's the step-by-step approach:

1. **Initialize Variables**: Use a dictionary to keep track of the last seen index of each character. Also, maintain two pointers, `start` and `end`, to represent the current window's boundaries. The `max_len` variable will store the length of the longest valid window found.

2. **Expand the Window**: Iterate through the string with the `end` pointer. For each character, check if it has been seen before and if its last occurrence is within the current window (i.e., after the `start` pointer).

3. **Adjust the Window**: If the character is found within the current window, move the `start` pointer to the position right after the last occurrence of this character to maintain all unique characters in the window.

4. **Update Maximum Length**: After adjusting the window, update the maximum length if the current window length (calculated as `end - start + 1`) is greater than the previously recorded maximum length.

### Solution Code
```python
def main():
    import sys
    t = int(sys.stdin.readline())
    for _ in range(t):
        s = sys.stdin.readline().strip()
        last_seen = {}
        start = 0
        max_len = 0
        for end in range(len(s)):
            char = s[end]
            if char in last_seen and last_seen[char] >= start:
                start = last_seen[char] + 1
            last_seen[char] = end
            current_len = end - start + 1
            if current_len > max_len:
                max_len = current_len
        print(max_len)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The number of test cases `T` is read first. For each test case, the string representing the soldiers' skills is read.
- **Tracking Last Seen Indices**: The dictionary `last_seen` keeps track of the most recent index where each character was encountered.
- **Sliding Window Technique**: The `start` pointer marks the beginning of the current window. As we iterate through the string with the `end` pointer, we adjust the `start` pointer whenever a duplicate character is encountered within the current window to ensure all characters in the window are unique.
- **Calculating Maximum Length**: The length of the current window is continuously checked against the maximum length found so far, updating it if a longer valid window is found.

This approach efficiently processes each string in linear time, making it suitable for the given constraints.
