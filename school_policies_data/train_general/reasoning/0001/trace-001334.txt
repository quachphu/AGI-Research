To solve this problem, we need to determine the minimum number of direction changes a robot must make to collect all pieces of information from a line of computers. Each computer requires a certain number of other pieces to be collected before it can be hacked. The robot starts next to the first computer and can only hack a computer when adjacent to it.

### Approach
1. **Initial Setup**: The robot starts at the first computer. If the first computer can be hacked immediately (i.e., it requires 0 other pieces), the robot hacks it. Otherwise, the robot must move right to find hackable computers.
2. **Direction Passes**: The robot alternates between moving right and left, collecting all hackable computers in each direction. A direction change is counted each time the robot switches direction after being unable to collect more computers in the current direction.
3. **Greedy Collection**: In each direction pass, the robot collects as many computers as possible. If no computers are collected in a pass, the direction is changed, and the number of direction changes is incremented.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
collected = [False] * (n + 1)
current_count = 0
remaining = n
current_dir = 'right'
pos = 1
changes = 0

# Check if the first computer can be hacked initially
if a[0] <= current_count:
    collected[1] = True
    current_count += 1
    remaining -= 1

while remaining > 0:
    moved = False
    if current_dir == 'right':
        max_i = pos
        for i in range(pos, n + 1):
            if not collected[i] and a[i-1] <= current_count:
                collected[i] = True
                current_count += 1
                remaining -= 1
                max_i = i
                moved = True
        if max_i > pos:
            pos = max_i
        else:
            if remaining > 0:
                changes += 1
                current_dir = 'left'
    else:
        min_i = pos
        for i in range(pos, 0, -1):
            if not collected[i] and a[i-1] <= current_count:
                collected[i] = True
                current_count += 1
                remaining -= 1
                min_i = i
                moved = True
        if min_i < pos:
            pos = min_i
        else:
            if remaining > 0:
                changes += 1
                current_dir = 'right'
    if not moved:
        if remaining > 0:
            changes += 1
            current_dir = 'left' if current_dir == 'right' else 'right'

print(changes)
```

### Explanation
1. **Initial Check**: The robot checks if it can hack the first computer immediately. If yes, it collects it and updates the count.
2. **Right Pass**: The robot moves right from its current position, hacking any computers that meet the criteria (i.e., the number of required pieces is less than or equal to the current count). The position is updated to the furthest hacked computer.
3. **Left Pass**: If no more computers can be hacked while moving right, the robot changes direction to left and repeats the process.
4. **Direction Changes**: Each time the robot changes direction due to inability to hack more computers in the current direction, a direction change is counted.

This approach ensures the robot collects all pieces of information with the minimum number of direction changes by greedily hacking computers in each direction before switching.
