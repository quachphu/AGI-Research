To solve this problem, we need to compute the n-th Fibonacci number based on a specific recursive definition where both fib(0) and fib(1) are 1, and each subsequent number is the sum of the two preceding ones. Given the constraint that n can be as large as 44, an efficient approach is necessary to avoid the exponential time complexity of a naive recursive solution.

### Approach
The optimal approach is to use an iterative method to compute the Fibonacci sequence. This approach runs in linear time, O(n), which is efficient even for the upper limit of n=44. The steps are as follows:
1. Handle the base cases where n is 0 or 1 directly by returning 1.
2. For values of n greater than 1, use two variables to keep track of the previous two Fibonacci numbers.
3. Iterate from 2 to n, updating these variables to compute the current Fibonacci number at each step.

### Solution Code
```python
def fibonacci(n):
    if n == 0 or n == 1:
        return 1
    a, b = 1, 1
    for _ in range(2, n + 1):
        c = a + b
        a = b
        b = c
    return b

n = int(input())
print(fibonacci(n))
```

### Explanation
1. **Base Cases Handling**: The function first checks if n is 0 or 1, returning 1 immediately as per the problem definition.
2. **Iterative Calculation**: For n greater than 1, the function initializes two variables, `a` and `b`, both set to 1 (representing fib(0) and fib(1)). It then iterates from 2 to n, updating these variables to compute each subsequent Fibonacci number. In each iteration, the next Fibonacci number is the sum of the previous two, and the variables are updated to shift the window forward.
3. **Efficiency**: This approach ensures that each Fibonacci number is computed in constant time per iteration, leading to an overall time complexity of O(n), which is efficient for the given constraint.

This method efficiently computes the n-th Fibonacci number using minimal space and optimal time, making it suitable for the problem's constraints.
