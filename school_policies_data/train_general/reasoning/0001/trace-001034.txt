To solve this problem, we need to find the most efficient arrangement of the buttons on a 3x3 phone keypad such that the number of finger movements required to type a given phone number is minimized. The arrangement should be lexicographically smallest if there are multiple optimal solutions.

### Approach
1. **Problem Analysis**: The goal is to minimize the total Manhattan distance traveled by the finger when typing the phone number. The Manhattan distance between two points (x1, y1) and (x2, y2) is |x1 - x2| + |y1 - y2|. Each consecutive pair of digits in the phone number contributes to the total distance based on their positions in the keypad arrangement.

2. **Frequency Matrix**: Compute a frequency matrix that counts how many times each digit is followed by another digit in the given phone number. This helps in efficiently calculating the total distance for any keypad arrangement.

3. **Generate Permutations**: Generate all possible permutations of the digits 1 to 9. For each permutation, calculate the total distance using the precomputed frequency matrix.

4. **Optimal Arrangement**: Track the permutation with the minimum total distance. If multiple permutations have the same minimum distance, select the lexicographically smallest one.

### Solution Code
```python
import itertools

n = int(input())
s = input().strip()

    freq[a][b] += 1

min_cost = None
best_perm = None

for perm in itertools.permutations(range(1, 10)):

    for a, b in non_zero_pairs:

        bx, by = pos[b]
        current_cost += freq[a][b] * (abs(ax - bx) + abs(ay - by))
```
