To solve this problem, we need to determine if House 3 (located at coordinate C) lies on the straight path between House 1 (coordinate A) and House 2 (coordinate B) on a number line. This means checking if C is strictly between the minimum and maximum of A and B.

### Approach
1. **Input Reading**: Read the coordinates of the three houses.
2. **Determine Range**: Calculate the minimum and maximum values of A and B to define the range of the straight path between House 1 and House 2.
3. **Check Position of C**: Verify if C lies strictly within the range defined by the minimum and maximum values of A and B. If it does, print "Yes"; otherwise, print "No".

### Solution Code
```python
a, b, c = map(int, input().split())
min_ab = min(a, b)
max_ab = max(a, b)
print("Yes" if min_ab < c < max_ab else "No")
```

### Explanation
1. **Reading Input**: The input consists of three integers A, B, and C which are read and stored in variables `a`, `b`, and `c`.
2. **Determine Range**: The minimum and maximum of A and B are calculated to determine the endpoints of the straight path between House 1 and House 2.
3. **Check Position**: The code checks if C is strictly between these minimum and maximum values. If true, it prints "Yes"; otherwise, it prints "No".

This approach efficiently checks the required condition using straightforward comparisons, ensuring correctness with minimal computational overhead.
