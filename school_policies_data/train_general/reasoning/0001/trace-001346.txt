To solve this problem, we need to determine how many times we can form string B from string A by deleting some characters and rearranging the remaining characters. Each character in B must come from a unique index in A, and we need to count the number of distinct ways to achieve this.

### Approach
1. **Frequency Check**: First, check if each character in B is present in A with at least the same frequency. If any character in B is more frequent than in A, it's impossible to form B from A, and the result is 0.

2. **Precompute Factorials and Inverses**: To efficiently compute combinations, precompute factorials and their modular inverses up to the maximum possible length of A (1,000,000) using Fermat's Little Theorem.

3. **Combination Calculation**: For each character required in B, calculate the number of ways to choose the required number of that character from A using combinations. Multiply these values together modulo \(10^9 + 7\) to get the final result.

### Solution Code
```python
import sys

MOD = 10**9 + 7
max_n = 10**6

# Precompute factorial and inverse factorial arrays
fact = [1] * (max_n + 1)
for i in range(1, max_n + 1):
    fact[i] = fact[i-1] * i % MOD

inv_fact = [1] * (max_n + 1)
inv_fact[max_n] = pow(fact[max_n], MOD-2, MOD)
for i in range(max_n - 1, -1, -1):
    inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

def comb(n, k):
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % MOD * inv_fact[n - k] % MOD

def solve():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        A = input[ptr]
        ptr += 1
        B = input[ptr]
        ptr += 1
        
        # Compute frequency arrays for A and B
        freq_a = [0] * 26
        for c in A:
            freq_a[ord(c) - ord('a')] += 1
        
        freq_b = [0] * 26
        for c in B:
            freq_b[ord(c) - ord('a')] += 1
        
        # Check if B can be formed from A
        possible = True
        for i in range(26):
            if freq_b[i] > freq_a[i]:
                possible = False
                break
        if not possible:
            print(0)
            continue
        
        # Calculate the product of combinations
        result = 1
        for i in range(26):
            b_count = freq_b[i]
            if b_count == 0:
                continue
            a_count = freq_a[i]
            c = comb(a_count, b_count)
            result = (result * c) % MOD
        
        print(result)

if __name__ == "__main__":
    solve()
```

3. **Feasibility Check**: Ensure that B can be formed from A by comparing frequency arrays.
4. **Combination Product**: For each character required in B, compute the combination of selecting the required count from A's available count. Multiply these combinations modulo \(10^9 + 7\) to get the result.
