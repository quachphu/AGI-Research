To solve this problem, we need to maximize the profit from trading stocks under specific constraints. The constraints allow owning either zero or one share at a time, making up to k buy orders, and performing one buy or sell per day. The solution involves using dynamic programming for small values of k and a greedy approach for larger values of k.

### Approach
1. **Greedy Approach for Large k**: If k is large enough to allow taking all profitable consecutive day trades, we sum up all positive price differences between consecutive days.
2. **Dynamic Programming for Small k**: For smaller values of k, we use dynamic programming to track the maximum profit achievable with up to k transactions. This involves maintaining two arrays to track the maximum profit when holding or not holding a stock after each transaction.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    k = int(input[idx])
    idx += 1
    prices = []
    for _ in range(n):
        prices.append(int(input[idx]))
        idx += 1
    
    sum_consec = 0
    count_consec = 0
    for i in range(1, n):
        diff = prices[i] - prices[i-1]
        if diff > 0:
            sum_consec += diff
            count_consec += 1
    
    if k >= count_consec:
        print(sum_consec)
        return
    
    # DP approach for small k
    buy = [float('-inf')] * (k+1)
    sell = [float('-inf')] * (k+1)
    sell[0] = 0  # 0 transactions, no stock
    
    for price in prices:
        for j in range(k, 0, -1):
            # Update buy[j]: either keep previous buy or sell[j-1] - price
            if sell[j-1] != float('-inf'):
                buy[j] = max(buy[j], sell[j-1] - price)
            # Update sell[j]: either keep previous sell or buy[j] + price
            if buy[j] != float('-inf'):
                sell[j] = max(sell[j], buy[j] + price)
    
    print(max(sell))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of days (n), maximum transactions (k), and the list of stock prices.
2. **Consecutive Profit Calculation**: We compute the sum of all positive differences between consecutive days and count these profitable opportunities. If k is large enough to take all these opportunities, we directly return the sum.
3. **Dynamic Programming Setup**: For smaller k, we initialize two arrays `buy` and `sell` to track the maximum profit when holding or not holding a stock after each transaction.
4. **Updating States**: For each price, we update the `buy` and `sell` arrays in reverse order to avoid overwriting values needed for the current iteration. This ensures we track the maximum profit for each possible number of transactions up to k.

This approach efficiently handles both small and large values of k, ensuring optimal profit under the given constraints.
