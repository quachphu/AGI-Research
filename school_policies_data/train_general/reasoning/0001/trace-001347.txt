2. **Efficient Prime Checking**: To determine if a number is composite, we first need to identify prime numbers efficiently. The Sieve of Eratosthenes algorithm is an efficient way to find all primes up to N.
3. **Generate Non-Primes**: Using the sieve, we can then filter out all composite numbers by checking which numbers are not marked as primes.

### Solution Code
```python
def print_non_primes():
    n = int(input())
    if n < 2:
        return
    sieve = [True] * (n + 1)
    sieve[0] = sieve[1] = False
    for i in range(2, int(n ** 0.5) + 1):
        if sieve[i]:
            sieve[i*i : n+1 : i] = [False] * len(sieve[i*i : n+1 : i])
    for num in range(2, n + 1):
        if not sieve[num]:
            print(num)

print_non_primes()
```

### Explanation
1. **Reading Input**: The input integer N is read from standard input.
2. **Edge Case Handling**: If N is less than 2, there are no composite numbers to print, so the function returns immediately.
3. **Sieve of Eratosthenes**: This algorithm is used to mark prime numbers up to N. The sieve is initialized as a boolean list where each index represents whether the number is prime. Initially, all entries are set to `True`, except for indices 0 and 1, which are set to `False` since 0 and 1 are not primes.
4. **Marking Non-Primes**: For each number starting from 2 up to the square root of N, if the number is still marked as prime, all its multiples are marked as non-prime.
5. **Output Composite Numbers**: Finally, iterate through the sieve from 2 to N. For each number marked as non-prime in the sieve, print it.

This approach efficiently identifies all composite numbers up to N using the Sieve of Eratosthenes, ensuring optimal performance even for large values of N up to 10^4.
