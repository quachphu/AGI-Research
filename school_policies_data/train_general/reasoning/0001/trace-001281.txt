To solve this problem, we need to determine the minimal number of piles required such that each box in a pile can support the number of boxes placed on top of it according to its strength. The key insight is to use a greedy algorithm where we sort the boxes by their strength and then place each box in the earliest possible pile that can accommodate it.

### Approach
1. **Sort the Boxes**: First, sort the list of box strengths in non-decreasing order. This helps in efficiently placing each box in the earliest possible pile.
2. **Greedy Placement**: For each box, check the existing piles from left to right. Place the box in the first pile where the current length of the pile is less than or equal to the box's strength. If no such pile exists, create a new pile.
3. **Track Pile Lengths**: Maintain a list where each element represents the current length of a pile. This helps in quickly determining if a box can be placed in an existing pile.

### Solution Code
```python
n = int(input())
x = list(map(int, input().split()))
x.sort()
piles = []
for xi in x:
    placed = False
    for j in range(len(piles)):
        if piles[j] <= xi:
            piles[j] += 1
            placed = True
            break
    if not placed:
        piles.append(1)
print(len(piles))
```

### Explanation
1. **Input Reading and Sorting**: The input is read and the strengths are sorted to facilitate the greedy placement.
2. **Greedy Algorithm**: For each box strength in the sorted list, iterate through existing piles to find the first pile where the box can be placed. The box is placed if the current length of the pile is less than or equal to the box's strength. If no such pile is found, a new pile is created.
3. **Pile Management**: The list `piles` keeps track of the current length of each pile. This allows efficient checking and updating of pile lengths as boxes are added.

This approach ensures that we use the minimal number of piles by leveraging the sorted strengths and a greedy strategy, resulting in an efficient solution with a time complexity of O(n^2), which is feasible for the given constraints.
