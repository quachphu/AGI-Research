To solve this problem, we need to determine the number of local extrema in an array. A local extremum is defined as an element that is either a local maximum (strictly greater than its neighbors) or a local minimum (strictly less than its neighbors). The first and last elements of the array are not considered since they only have one neighbor each.

### Approach
1. **Input Reading**: Read the number of elements and the array itself.
2. **Edge Case Handling**: If the array has fewer than 3 elements, there can be no local extrema, so the result is immediately 0.
3. **Loop Through Middle Elements**: For each element from the second to the second-to-last, check if it is a local maximum or minimum.
4. **Count Extrema**: Maintain a counter to keep track of the number of local extrema found.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
count = 0
for i in range(1, n-1):
    if (a[i] > a[i-1] and a[i] > a[i+1]) or (a[i] < a[i-1] and a[i] < a[i+1]):
        count += 1
print(count)
```

### Explanation
1. **Reading Input**: The first line of input is the number of elements `n`, and the second line contains the array elements.
2. **Edge Case Handling**: If `n` is less than 3, the loop will not execute, and the count remains 0.
3. **Loop Through Elements**: The loop runs from the second element (index 1) to the second-to-last element (index `n-2`). For each element, it checks if it is greater than both neighbors (local maximum) or less than both neighbors (local minimum).
4. **Count Increment**: Each time a local extremum is found, the count is incremented.
5. **Output Result**: The final count is printed, which is the number of local extrema in the array.

This approach efficiently checks each relevant element in linear time, making it optimal for the given constraints.
