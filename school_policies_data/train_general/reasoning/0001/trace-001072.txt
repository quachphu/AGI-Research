To solve this problem, we need to convert an array into a magical array where each element is strictly greater than the previous one. We can achieve this by adding a given value X to any element any number of times. Our goal is to determine the minimum number of such additions required.

### Approach
1. **Understand the Requirement**: Each element in the array must be strictly greater than the previous element. If it is not, we need to add the value X enough times to make it so.
2. **Iterate Through the Array**: Start from the second element and check each subsequent element to see if it meets the required condition.
3. **Calculate Required Additions**: For each element that does not meet the condition, compute the minimum number of additions needed using integer division and ceiling principles to ensure we cover the deficit efficiently.
4. **Update Tracking Variables**: Keep track of the previous element's value after modifications to ensure subsequent elements are checked against the correct value.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N, X = int(input[ptr]), int(input[ptr+1])
        ptr +=2
        A = list(map(int, input[ptr:ptr+N]))
        ptr +=N
        prev = A[0]
        total = 0
        for i in range(1, N):
            current = A[i]
            required_min = prev + 1
            required_incr = required_min - current
            if required_incr > 0:
                k = (required_incr + X -1) // X
                total += k
                prev = current + k * X
            else:
                prev = current
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Processing Each Test Case**: For each test case, we read the values of N (size of the array) and X (the value to add).
3. **Iterating Through the Array**: Starting from the second element, we check if the current element meets the required condition (being greater than the previous element).
4. **Calculating Additions**: If the current element is not sufficient, we calculate the minimum number of additions needed using the formula `(required_incr + X - 1) // X`, which effectively computes the ceiling of the division.
5. **Updating State**: After each element check, update the total number of additions and the previous element's value to reflect any modifications made.

This approach ensures that we efficiently determine the minimum number of additions required to convert the array into a magical array while adhering to the constraints. The algorithm runs in O(N) time per test case, making it suitable for large input sizes.
