Given the constraints, a brute-force approach would be inefficient, so we use a mathematical approach based on inclusion-exclusion principles.

### Approach
1. **Problem Analysis**: The problem requires counting the number of non-negative integer solutions to X + Y + Z = S with each variable bounded by K. Directly enumerating all possibilities is infeasible for large K, so we use combinatorial mathematics and inclusion-exclusion principle to efficiently compute the count.

2. **Inclusion-Exclusion Principle**: 
   - **Total Solutions**: First, calculate the number of solutions without considering the upper bound K using the stars and bars method.
   - **Subtract Invalid Solutions**: Subtract solutions where any variable exceeds K. This involves adjusting the sum to account for the excess and recalculating the solutions.
   - **Adjust for Over-Subtraction**: Add back solutions where two variables exceed K and subtract solutions where all three variables exceed K to correct for over-subtraction.

3. **Mathematical Formulation**: Using the inclusion-exclusion principle, the formula is derived to compute valid solutions efficiently.

### Solution Code
```python
k, s = map(int, input().split())

total = 0
combinations = [1, 3, 3, 1]

for i in range(4):
    comb = combinations[i]
    adjusted_sum = s - i * (k + 1)
    if adjusted_sum >= 0:
        c = (adjusted_sum + 2) * (adjusted_sum + 1) // 2
    else:
        c = 0
    total += ((-1) ** i) * comb * c

print(total)
```

1. **Reading Input**: The values of K and S are read from standard input.
2. **Inclusion-Exclusion Calculation**:
   - For each term in the inclusion-exclusion formula (i from 0 to 3), compute the adjusted sum by subtracting i*(K+1) from S.
   - Check if the adjusted sum is non-negative. If it is, compute the number of solutions using the stars and bars method. If not, the term contributes zero.
   - Adjust the total count using the inclusion-exclusion coefficients and signs.
3. **Output the Result**: The final count is printed, which is the number of valid triples (X, Y, Z).

This approach efficiently handles the constraints and ensures we count all valid solutions without redundant checks, leveraging combinatorial mathematics for optimal performance.
