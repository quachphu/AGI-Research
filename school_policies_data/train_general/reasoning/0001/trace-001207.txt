To solve this problem, we need to find the longest subsegment of an array that has the maximum possible arithmetic mean. The key insight here is that the maximum arithmetic mean is achieved by the maximum element in the array, and the longest subsegment of consecutive occurrences of this maximum element will be the solution.

### Approach
1. **Identify the Maximum Element**: The maximum arithmetic mean of any subsegment cannot exceed the maximum element in the array. This is because a subsegment containing only the maximum element will have this value as its mean.
2. **Find Longest Consecutive Run**: Once the maximum element is identified, the next step is to determine the longest sequence of consecutive occurrences of this element in the array. This sequence will form the subsegment with the maximum arithmetic mean.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    arr = list(map(int, input[1:n+1]))
    max_val = max(arr)
    max_length = current = 0
    for num in arr:
        if num == max_val:
            current += 1
            if current > max_length:
                max_length = current
        else:
            current = 0
    print(max_length)

main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first line gives the length of the array, and the second line contains the array elements.
2. **Finding Maximum Value**: The maximum value in the array is determined using the `max` function.
3. **Tracking Consecutive Elements**: We iterate through the array, maintaining a count of consecutive occurrences of the maximum value. Each time we encounter the maximum value, we increment our current count. If we encounter a different value, we reset the current count to zero. Throughout this process, we keep track of the longest consecutive sequence encountered.

This approach efficiently finds the solution in linear time, O(n), where n is the length of the array, making it suitable for large input sizes up to 100,000 elements.
