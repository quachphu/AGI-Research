To solve this problem, we need to determine if Chotu can buy a teddy bear worth K using coins with values from 1 to N. The solution involves checking if the sum of any subset of these coins can exactly equal K.

### Approach
The key insight here is that the set of coins from 1 to N can form any sum from 1 up to the sum of the first N natural numbers, which is given by the formula \( S = \frac{N(N+1)}{2} \). Therefore, if K is within this range (1 ≤ K ≤ S), Chotu can buy the teddy bear. Otherwise, he cannot.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    index = 1
    for _ in range(T):
        N = int(input[index])
        K = int(input[index + 1])
        index += 2
        total = N * (N + 1) // 2
        if K <= total:
            print("YES")
        else:
            print("NO")

solve()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints. The first value is the number of test cases, T.
2. **Processing Each Test Case**: For each test case, we read the values of N (number of coins) and K (value of the teddy bear).
3. **Sum Calculation**: Calculate the maximum possible sum (S) of the first N natural numbers using the formula \( S = \frac{N(N+1)}{2} \).
4. **Check Condition**: Determine if K is within the range [1, S]. If it is, print "YES"; otherwise, print "NO".

This approach efficiently checks the condition for each test case in constant time, making it suitable even for large values of N and K up to the given constraints.
