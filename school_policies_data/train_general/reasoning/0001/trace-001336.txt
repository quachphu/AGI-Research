To solve this problem, we need to determine if four given sticks can form a non-degenerate triangle, a degenerate triangle (segment), or if it's impossible to form any triangle. The solution involves checking all possible combinations of three sticks from the four given and applying the triangle inequality theorem.

### Approach
1. **Generate Combinations**: Generate all possible combinations of three sticks from the four given. This results in four combinations.
2. **Check Triangle Validity**: For each combination, sort the three sticks and check if they can form a non-degenerate triangle using the triangle inequality theorem. If the sum of the two smaller sticks is greater than the largest stick, a non-degenerate triangle is possible.
3. **Check Segment Validity**: If a non-degenerate triangle is not possible, check if the sum of the two smaller sticks equals the largest stick, indicating a degenerate triangle (segment).
4. **Determine Result**: After evaluating all combinations, determine the result based on whether any combination formed a non-degenerate triangle, a segment, or neither.

### Solution Code
```python
import itertools

def determine_triangle():
    sticks = list(map(int, input().split()))
    possible_triangle = False
    possible_segment = False
    for trio in itertools.combinations(sticks, 3):
        a, b, c = sorted(trio)
        if a + b > c:
            possible_triangle = True
        elif a + b == c:
            possible_segment = True
    if possible_triangle:
        print("TRIANGLE")
    elif possible_segment:
        print("SEGMENT")
    else:
        print("IMPOSSIBLE")

determine_triangle()
```

### Explanation
1. **Reading Input**: The input is read as a list of four integers representing the lengths of the sticks.
2. **Generating Combinations**: Using `itertools.combinations`, all possible combinations of three sticks are generated.
3. **Sorting and Checking Conditions**: For each combination, the sticks are sorted. The sorted values are checked to determine if they can form a non-degenerate triangle or a segment.
4. **Result Determination**: The results from all combinations are aggregated to determine the final output. If any combination forms a non-degenerate triangle, "TRIANGLE" is printed. If not, but a segment is possible, "SEGMENT" is printed. Otherwise, "IMPOSSIBLE" is printed.

This approach ensures that all possible combinations are evaluated efficiently, leading to the correct result based on the triangle inequality theorem.
