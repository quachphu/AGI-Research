To solve this problem, we need to determine the minimum number of white cells that need to be painted black so that all black cells form a square with sides parallel to the grid edges. If it's impossible to form such a square, we should return -1.

### Approach
1. **Identify Black Cells**: First, we collect the positions of all existing black cells ('B') in the grid.
2. **Edge Case Handling**: If there are no black cells, the solution is simply to paint any single cell, resulting in a 1x1 square.
3. **Bounding Box Calculation**: For the existing black cells, compute the minimum and maximum rows and columns they occupy. This helps determine the smallest possible square that can enclose all these cells.
4. **Determine Square Size**: The side length of the smallest square (s_min) is the maximum of the height and width of the bounding box of the existing black cells.
5. **Check Possible Squares**: For each possible square size starting from s_min up to the minimum of the grid dimensions (n, m), check if a valid square of that size exists that encloses all black cells. Use a prefix sum array to efficiently compute the number of black cells in any subgrid.
6. **Validation and Calculation**: For each valid square, compute the number of white cells that need to be painted black and keep track of the minimum value.

### Solution Code

n, m = map(int, input().split())
grid = [input().strip() for _ in range(n)]

rows = []
cols = []
