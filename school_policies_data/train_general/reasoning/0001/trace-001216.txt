To solve this problem, we need to find the minimal possible total number of segments in two subarrays formed by coloring elements of the original array either white or black. The goal is to minimize the sum of segments in both subarrays after merging adjacent elements with the same value.

### Approach
The key insight is to use dynamic programming (DP) to keep track of the minimal number of segments formed by the subarrays as we process each element. We maintain states representing the last elements of the white and black subarrays (if they exist) and the minimal number of segments up to that point. For each element, we consider both possible color assignments (white or black) and update the states accordingly.

1. **State Representation**: Use a dictionary to track states where each key is a tuple `(last0, last1)` representing the last elements of the white and black subarrays, and the value is the minimal number of segments up to that state.
2. **State Transition**: For each element, compute the cost of assigning it to either color and update the states. The cost is determined based on whether the current element matches the last element in the respective subarray.
3. **Optimization**: By maintaining only the minimal number of segments for each state, we ensure efficient computation even for large input sizes.

### Solution Code
```python
import sys
from collections import defaultdict

def minimal_segments():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    
    # Initialize the states. The keys are tuples (last0, last1), values are the minimal sum.
    states = {(None, None): 0}
    
    for num in a:
        new_states = defaultdict(lambda: float('inf'))
        for (last0, last1), current_sum in states.items():
            # Assign current number to color 0 (white)
            cost0 = 1 if last0 is None else (0 if num == last0 else 1)
            new_last0 = num
            new_last1 = last1
            new_sum = current_sum + cost0
            if new_sum < new_states[(new_last0, new_last1)]:
                new_states[(new_last0, new_last1)] = new_sum
            
            # Assign current number to color 1 (black)
            cost1 = 1 if last1 is None else (0 if num == last1 else 1)
            new_last1_ = num
            new_last0_ = last0
            new_sum_ = current_sum + cost1
            if new_sum_ < new_states[(new_last0_, new_last1_)]:
                new_states[(new_last0_, new_last1_)] = new_sum_
        
        # Update states to new_states, converting defaultdict to a regular dict for efficiency
        states = dict(new_states.items())
    
    print(min(states.values()))

minimal_segments()
```

### Explanation
- **State Initialization**: Start with an initial state where both subarrays are empty.
- **Processing Each Element**: For each element, compute the cost of assigning it to either color. Update the states to reflect the new last elements of the subarrays and the accumulated segment count.
- **Cost Calculation**: The cost of adding an element to a subarray is 0 if it matches the last element of that subarray, otherwise 1. If the subarray is empty, the cost is 1 as it starts a new segment.
- **Dynamic Programming Transition**: For each element, update the possible states by considering both color assignments and keeping track of the minimal segment count for each state.

This approach efficiently computes the minimal total segments by dynamically updating possible states and their associated costs, ensuring optimal performance even for large input sizes.
