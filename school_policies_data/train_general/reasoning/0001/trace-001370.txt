To solve this problem, we need to determine if a number remains valid when viewed upside down. A number is considered valid if each of its digits can be rotated 180 degrees to form another valid digit, and the resulting number, when read upside down, is also a valid number.

### Approach
1. **Identify Valid Digits**: The digits 0, 1, 8, 6, and 9 are valid because they form another valid digit when rotated. Specifically, 6 becomes 9, 9 becomes 6, and 0, 1, 8 remain the same.
2. **Check Each Digit**: For each input number, check if all its digits are among the valid digits. If any digit is invalid, the number is not valid.
3. **Generate Rotated Number**: If all digits are valid, reverse the number and replace each digit with its rotated counterpart. This will give the number as seen when viewed upside down.
4. **Output the Result**: If valid, print "YES" followed by the rotated number; otherwise, print "NO".

### Solution Code
```python
def check_upside_down():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    cases = input[1:t+1]
    
    rotate_map = {'0':'0', '1':'1', '8':'8', '6':'9', '9':'6'}
    valid_digits = rotate_map.keys()
    
    for s in cases:
        valid = True
        for c in s:
            if c not in valid_digits:
                valid = False
                break
        if not valid:
            print("NO")
            continue
        # Reverse the string and rotate each character
        reversed_s = s[::-1]
        rotated = []
        for c in reversed_s:
            rotated.append(rotate_map[c])
        rotated_num = ''.join(rotated)
        print("YES")
        print(rotated_num)

check_upside_down()
```

### Explanation
- **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
- **Validation Check**: Each digit of the input number is checked against the set of valid digits (0, 1, 8, 6, 9). If any digit is invalid, the result is immediately "NO".
- **Rotation Process**: The valid number is reversed, and each digit is replaced by its corresponding rotated counterpart using a mapping dictionary. This creates the upside-down version of the number.
- **Output**: The result for each test case is printed based on whether the number is valid and its rotated counterpart.

This approach efficiently checks and transforms each number, ensuring correctness and handling large numbers up to 10^50 as strings to avoid overflow issues.
