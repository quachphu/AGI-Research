To solve this problem, we need to determine the Minimum Excluded String (MEX) for a given input string. The MEX is defined as the shortest string that does not appear as a contiguous substring in the input. If there are multiple such strings, the lexicographically smallest one is chosen.

### Approach
1. **Check for 1-length MEX**: The simplest MEX to check is a single character. If any character from 'a' to 'z' is missing in the input string, that character is the MEX.
2. **Check for 2-length MEX**: If all single characters are present, generate all possible 2-length strings in lexicographical order and check if each exists in the input string. The first missing string is the MEX.
3. **Check for 3-length MEX**: If all 2-length strings are present, generate all possible 3-length strings in lexicographical order. The first missing string is the MEX. Given the constraints, this step will always find a valid MEX.

### Solution Code
```python
import sys

def find_mex(s):
    # Check for 1-length MEX
    present_chars = set(s)
    for c in 'abcdefghijklmnopqrstuvwxyz':
        if c not in present_chars:
            return c

    # Check for 2-length MEX
    for c1 in 'abcdefghijklmnopqrstuvwxyz':
        for c2 in 'abcdefghijklmnopqrstuvwxyz':
            candidate = c1 + c2
            if candidate not in s:
                return candidate

    # Check for 3-length MEX (since all 2-length are present)
    for c1 in 'abcdefghijklmnopqrstuvwxyz':
        for c2 in 'abcdefghijklmnopqrstuvwxyz':
            for c3 in 'abcdefghijklmnopqrstuvwxyz':
                candidate = c1 + c2 + c3
                if candidate not in s:
                    return candidate

    # This return is theoretically unreachable given constraints
    return 'aaaa'

t = int(sys.stdin.readline())
for _ in range(t):
    n = int(sys.stdin.readline())
    s = sys.stdin.readline().strip()
    print(find_mex(s))
```
