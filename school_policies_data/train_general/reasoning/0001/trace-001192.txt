To solve this problem, we need to determine if it's possible to buy a combination of items from AtCoder Mart such that the total cost equals exactly X yen. The items available have prices ranging from 100 to 105 yen, and each item can be purchased in unlimited quantities (up to the given constraints).

### Approach
The key insight is to recognize that each item's price can be expressed as 100 plus a value from 0 to 5. By decomposing the total cost X into two parts, we can simplify the problem:
1. The sum of 100 yen contributions from each item.
2. The sum of the additional values (0 to 5 yen) from each item.

We iterate through possible values of the total number of items (m) and check if the remaining value after accounting for the 100 yen contributions can be formed using the additional values. Specifically, for each m, we calculate the remaining value (t) and check if it can be formed using up to m items, each contributing between 0 and 5 yen.

### Solution Code
```python
def main():
    X = int(input())
    max_m = X // 100
    for m in range(max_m + 1):
        t = X - 100 * m
        if t < 0:
            continue
        if t > 5 * m:
            continue
        s_min = (t + 4) // 5  # Equivalent to ceil(t / 5)
        if s_min <= m:
            print(1)
            return
    print(0)

main()
```

### Explanation
1. **Reading Input**: The input value X is read from standard input.
2. **Iterating Through Possible Values of m**: We iterate through all possible values of m, where m is the total number of items. The maximum value of m is determined by X // 100.
3. **Calculating Remaining Value (t)**: For each m, we compute t as the remaining value after subtracting 100 * m from X.
4. **Checking Validity of t**: We check if t is non-negative and can be formed using the additional values (0 to 5) from up to m items. This is done by ensuring t is within the range [0, 5 * m] and checking if the minimum number of items required to sum to t (using the maximum additional value of 5) does not exceed m.
5. **Output Result**: If any valid combination is found, we print 1. If no valid combinations are found after checking all m, we print 0.

This approach efficiently checks all possible combinations using mathematical decomposition, ensuring we cover all potential solutions within the problem constraints.
