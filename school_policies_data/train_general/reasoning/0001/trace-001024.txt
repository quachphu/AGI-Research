To solve this problem, we need to determine if the child who is "it" can catch the other child within a given time frame T, considering both children move optimally. The "it" child moves to minimize the time to catch, while the other child moves to maximize the time to be caught.

### Approach
1. **Initial Distance Calculation**: Compute the absolute distance between the initial positions of the two children.
2. **Speed Comparison**: Check if the "it" child's speed (V) is greater than the other child's speed (W). If not, the "it" child can never catch up.
3. **Time Check**: If the "it" child's speed is greater, calculate the maximum distance the "it" child can close per second (V - W). Determine if the initial distance can be closed within the given time T by checking if the product of the time T and the relative speed (V - W) is at least the initial distance.

### Solution Code
```python
A, V = map(int, input().split())
B, W = map(int, input().split())
T = int(input())

distance = abs(A - B)

if V <= W:
    print("NO")
else:
    if distance <= T * (V - W):
        print("YES")
    else:
        print("NO")
```

### Explanation
1. **Initial Distance Calculation**: The distance between the two children is found using `abs(A - B)`.
2. **Speed Comparison**: If the "it" child's speed (V) is less than or equal to the other child's speed (W), the answer is immediately "NO" because the "it" child cannot catch up.
3. **Time Check**: If the "it" child's speed is greater, we check if the product of the time (T) and the relative speed (V - W) is at least the initial distance. If true, the answer is "YES"; otherwise, it is "NO".

This approach efficiently determines the result using basic arithmetic operations, ensuring optimal performance even for large input values.
