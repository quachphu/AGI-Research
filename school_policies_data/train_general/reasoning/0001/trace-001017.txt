To solve this problem, we need to determine Lara's position in a dungeon after she makes a series of moves. The dungeon is represented as a matrix with `n` rows and `m` columns. Lara follows a specific path: she starts at the top-left corner, moves down to the bottom-left corner, and then snakes her way through the remaining cells. 

### Approach
1. **Vertical Movement**: Lara starts at (1, 1) and moves down to (n, 1). This part of the path is straightforward and covers the first `n` cells. If the number of moves `k` is less than `n`, her position can be directly determined from this vertical movement.
2. **Snake Movement**: After reaching the bottom-left corner (n, 1), Lara moves in a snake pattern through the remaining cells. This part of the path involves alternating directions for each row (right for even rows, left for odd rows). The number of steps taken in the snake pattern can be calculated by subtracting the vertical steps from `k`.

### Solution Code
```python
n, m, k = map(int, input().split())
if k < n:
    print(k + 1, 1)
else:
    rem = k - n
    cols = m - 1
    row_in_snake = rem // cols
    x = n - row_in_snake
    rem_in_row = rem % cols
    if x % 2 == 0:
        y = 2 + rem_in_row
    else:
        y = m - rem_in_row
    print(x, y)
```

### Explanation
1. **Vertical Movement Check**: If `k` is less than `n`, Lara is still in the vertical part of her path. Her position is simply `(k + 1, 1)`.
2. **Snake Movement Calculation**: For `k` values greater than or equal to `n`, we first compute the remaining steps after the vertical movement. Each row in the snake pattern has `m-1` columns. The row index in the snake pattern is determined by integer division of the remaining steps by `m-1`. The column index within that row is determined by the remainder of the division and the row's parity (even rows move right, odd rows move left).

This approach efficiently computes Lara's position using mathematical operations, avoiding the need for simulation and handling very large values of `n` and `m` efficiently.
