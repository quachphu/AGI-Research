To solve this problem, we need to construct the longest possible string from a given set of letters such that each letter's occurrence count is both within a specified limit and unique among all letters used in the string. 

### Approach
1. **Sort the Limits**: First, sort the given occurrence limits in descending order. This allows us to start with the largest possible count and work our way down, ensuring we maximize the string length.
2. **Greedy Selection**: Iterate through the sorted list and for each element, determine the maximum allowable count. This count must be less than the previous count (to ensure uniqueness) and within the given limit. If the calculated count drops to zero or below, we stop as further elements cannot contribute positively to the string length.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
a.sort(reverse=True)
total = 0
prev = 0
for num in a:
    current = num
    if prev > 0:
        current = min(num, prev - 1)
    if current <= 0:
        break
    total += current
    prev = current
print(total)
```

### Explanation
1. **Sorting**: By sorting the occurrence limits in descending order, we prioritize using the largest possible counts first, which helps in maximizing the string length.
2. **Greedy Iteration**: For each element in the sorted list, we determine the maximum possible count that is both within the limit and less than the previous count. This ensures each count is unique and as large as possible.
3. **Termination Check**: If at any point the calculated count becomes non-positive, we stop the iteration early because subsequent counts would also be non-positive, contributing nothing to the total length.

This approach efficiently balances between maximizing the counts and ensuring uniqueness, leading to the optimal solution.
