To solve this problem, we need to determine which bank provides the highest principal and interest after a given number of years using either simple or compound interest. The solution involves calculating the final amount for each bank and selecting the one with the highest return.

### Approach
1. **Input Reading**: Read the input values which include multiple datasets. Each dataset starts with the number of banks, followed by the number of years, and then the details of each bank (bank number, interest rate, and interest type).
2. **Interest Calculation**: For each bank, compute the final amount using either simple interest or compound interest based on the given interest type.
   - **Simple Interest**: The formula used is \( \text{Amount} = 1 + \left(\frac{\text{rate}}{100} \times \text{years}\right) \).
   - **Compound Interest**: The formula used is \( \text{Amount} = \left(1 + \frac{\text{rate}}{100}\right)^{\text{years}} \).
3. **Comparison**: Track the bank that yields the highest amount and print its number for each dataset.

### Solution Code
```python
import sys

def main():
    data = list(map(int, sys.stdin.read().split()))
    ptr = 0
    while ptr < len(data):
        n = data[ptr]
        ptr += 1
        if n == 0:
            break
        y = data[ptr]
        ptr += 1
        banks = []
        for _ in range(n):
            bi = data[ptr]
            ri = data[ptr + 1]
            ti = data[ptr + 2]
            banks.append((bi, ri, ti))
            ptr += 3
        max_amount = -1.0
        best_bank = -1
        for bi, ri, ti in banks:
            if ti == 1:
                amount = 1.0 + (ri / 100.0) * y
            else:
                rate = ri / 100.0
                amount = (1.0 + rate) ** y
            if amount > max_amount:
                max_amount = amount
                best_bank = bi
        print(best_bank)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and converted into a list of integers for easier processing.
2. **Loop Through Datasets**: Each dataset is processed in a loop until encountering a zero, which indicates the end of input.
3. **Bank Details Processing**: For each bank, the interest calculation is performed based on the specified type (simple or compound).
4. **Track Maximum Amount**: During the calculation, the maximum amount and the corresponding bank number are tracked to determine the best investment option.
5. **Output Result**: After processing all banks in a dataset, the bank number with the highest return is printed.

This approach ensures that each dataset is handled efficiently, and the correct bank is identified using precise mathematical calculations for both simple and compound interest.
