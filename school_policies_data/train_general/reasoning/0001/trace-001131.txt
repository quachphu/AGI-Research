To solve this problem, we need to determine if a given triple of integers (A, B, C) is "poor". A triple is considered poor if exactly two of the numbers are the same and the third is different.

### Approach
1. **Understanding the Problem**: A triple is poor if two numbers are equal and the third is different. If all three numbers are the same or all are different, the triple is not poor.
2. **Counting Frequencies**: Use a frequency counter to count how many times each number appears in the triple.
3. **Checking Conditions**: After counting the frequencies, check if the sorted list of frequency values is `[1, 2]`. This indicates that exactly two numbers are the same and one is different.

### Solution Code
```python
import sys
from collections import Counter

def main():
    a, b, c = map(int, sys.stdin.readline().split())
    counts = Counter([a, b, c])
    values = sorted(counts.values())
    print("Yes" if values == [1, 2] else "No")

main()
```

### Explanation
1. **Reading Input**: The input is read from standard input and split into three integers A, B, and C.
2. **Counting Frequencies**: Using the `Counter` from the `collections` module, we count the occurrences of each number in the triple.
3. **Checking Sorted Frequencies**: The values from the frequency counter are sorted. If these sorted values are `[1, 2]`, it means there are two occurrences of one number and one occurrence of another, making the triple poor. Otherwise, it is not poor.

This approach efficiently checks the required condition using a frequency counter and ensures correctness by leveraging the properties of sorted frequency values.
