To solve this problem, we need to determine the minimum number of straight knife strokes required to cut a pizza into exactly `n` pieces. The solution involves understanding the mathematical relationship between the number of cuts and the maximum number of pieces they can produce.

### Approach
The problem can be approached using the formula derived from the planar division problem. The maximum number of regions (pieces) `L(k)` that can be created with `k` straight cuts is given by the formula:
\[ L(k) = \frac{k^2 + k + 2}{2} \]

For a given number of pieces `n`, we need to find the smallest integer `k` such that:
\[ \frac{k^2 + k + 2}{2} \geq n \]

This can be rearranged to solve for `k` using the quadratic formula. The key steps are:
1. For `n = 1`, the answer is 0 cuts.
2. For `n > 1`, solve the quadratic equation derived from the inequality to find the minimum `k`.

### Solution Code
```python
import math

def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        n = int(input[i])
        if n == 1:
            print(0)
        else:
            x = 8 * (n - 1) + 1
            sqrt_x = math.sqrt(x)
            k = (sqrt_x - 1) / 2
            k_ceil = math.ceil(k)
            print(k_ceil)

if __name__ == "__main__":
    main()
```

   - For other values of `n`, compute the minimum number of cuts using the derived formula. This involves solving a quadratic equation to find the smallest integer `k` such that the number of pieces produced by `k` cuts is at least `n`.
3. **Mathematical Calculation:** The quadratic formula is used to efficiently determine the minimum number of cuts required. This approach ensures that we avoid iterative checks and directly compute the result using mathematical properties.

This method efficiently computes the result in constant time for each test case, making it suitable for large input sizes.
