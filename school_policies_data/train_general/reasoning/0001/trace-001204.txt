To solve this problem, we need to determine if two given strings are cyclic permutations of each other. This means that one string can be rotated to form the other. The solution involves checking if one string is a substring of the concatenation of the other string with itself.

### Approach
1. **Problem Analysis**: The key insight is that if a string `G` is a cyclic permutation of string `S`, then `G` must be a substring of the concatenation of `S` with itself (`S + S`). This is because rotating `S` any number of times will result in a string that appears as a substring in `S + S`.

2. **Algorithm**:
   - For each test case, read the two strings `S` and `G`.
   - Check if the lengths of `S` and `G` are the same. If not, output "NO".
   - Concatenate `S` with itself to form a new string.
   - Check if `G` is a substring of this concatenated string. If it is, output "YES"; otherwise, output "NO".

3. **Complexity**: The time complexity for each test case is O(n^2) where n is the length of the strings, due to the substring check. However, given the constraint that the maximum length of the strings is 15, this approach is efficient and feasible.

### Solution Code
```python
def check_rotation():
    import sys
    t = int(sys.stdin.readline())
    for _ in range(t):
        s = sys.stdin.readline().strip()
        g = sys.stdin.readline().strip()
        if len(s) != len(g):
            print("NO")
            continue
        if len(s) == 0:
            print("YES")
            continue
        doubled = s + s
        print("YES" if g in doubled else "NO")

check_rotation()
```

### Explanation
- **Reading Input**: The input is read using `sys.stdin.readline()` to handle multiple test cases efficiently.
- **Length Check**: We first check if the lengths of the two strings are the same. If not, they cannot be cyclic permutations.
- **Concatenation Check**: By concatenating `S` with itself, we create a string that contains all possible rotations of `S`. Checking if `G` is a substring of this concatenated string efficiently determines if `G` is a cyclic permutation of `S`.

This approach ensures that we correctly identify cyclic permutations using a straightforward and efficient method, adhering to the problem constraints.
