To solve this problem, we need to find the shortest path from a starting kingdom to all other kingdoms in a given graph using bidirectional edges with varying distances. The solution involves using an optimized version of Dijkstra's algorithm known as Dial's algorithm, which is efficient for graphs with small edge weights.

### Approach
1. **Problem Analysis**: The problem requires finding the shortest path from a given starting node (kingdom) to all other nodes in an undirected graph. If a node is unreachable, the distance should be marked as -1. Given the constraints, a standard Dijkstra's algorithm might be too slow, so we use Dial's algorithm which leverages the small edge weights (up to 350).

2. **Algorithm Selection**: Dial's algorithm uses a list of queues (buckets) where each bucket represents a possible distance. This allows us to efficiently manage the nodes to be processed in order of their current shortest distance, leading to a time complexity of O(M + max_distance), where M is the number of edges and max_distance is (N-1) * 350.

3. **Optimization**: By using buckets, we avoid the overhead of a priority queue, making the algorithm more efficient for large graphs with small edge weights.

### Solution Code
```python
import sys
from collections import deque

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        R = int(input[ptr + 1])
        ptr += 2
        adj = [[] for _ in range(N + 1)]  # 1-based indexing
        for __ in range(R):
            x = int(input[ptr])
            y = int(input[ptr + 1])
            d = int(input[ptr + 2])
            ptr += 3
            adj[x].append((y, d))
            adj[y].append((x, d))
        S = int(input[ptr])
        ptr += 1
        
        INF = float('inf')
        max_dist = (N - 1) * 350
        dist = [INF] * (N + 1)
        dist[S] = 0
        buckets = [deque() for _ in range(max_dist + 1)]
        buckets[0].append(S)
        
        current_distance = 0
        while current_distance <= max_dist:
            while buckets[current_distance]:
                u = buckets[current_distance].popleft()
                if dist[u] < current_distance:
                    continue
                for v, d in adj[u]:
                    new_dist = current_distance + d
                    if new_dist < dist[v]:
                        dist[v] = new_dist
                        if new_dist <= max_dist:
                            buckets[new_dist].append(v)
            current_distance += 1
        
        output = []
        for i in range(1, N + 1):
            if i == S:
                continue
            output.append(str(dist[i]) if dist[i] != INF else '-1')
        print(' '.join(output))
        
if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially for large datasets. The input is split into a list for easy access.

2. **Graph Construction**: An adjacency list is built to represent the graph, where each node points to a list of tuples representing connected nodes and the corresponding edge weights.

3. **Dial's Algorithm Initialization**: The maximum possible distance from the starting node is calculated, and an array of deques (buckets) is initialized to manage nodes based on their current shortest distance.

4. **Processing Nodes**: Nodes are processed in order of their distance from the starting node. For each node, we update the shortest distances to its neighbors and place them in the appropriate bucket if a shorter path is found.

5. **Output**: After processing all nodes, the shortest distances are collected and formatted, converting unreachable nodes (marked with infinity) to -1.

This approach ensures efficient processing of the graph, leveraging the small edge weights to optimize the shortest path calculation using Dial's algorithm.
