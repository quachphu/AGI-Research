To solve this problem, we need to determine if a given sequence of digits can be divided into two or more non-overlapping segments such that each segment's sum is equal. 

### Approach
1. **Sum Calculation**: First, compute the sum of all digits in the ticket. If the sum is zero, check if all digits are zero. If they are, the ticket is lucky (since we can split into any number of segments, each summing to zero). If not, the ticket is not lucky.
2. **Divisors Identification**: For a non-zero sum, identify all possible divisors of the sum that are less than or equal to half of the sum. These divisors are potential candidates for the target sum of each segment.
3. **Segment Validation**: For each divisor, check if the digits can be partitioned into consecutive segments where each segment's sum equals the divisor. If any valid partition is found, the ticket is lucky.

### Solution Code
```python
import math

n = int(input())
s = input().strip()
digits = [int(c) for c in s]
sum_s = sum(digits)

if sum_s == 0:
    if all(d == 0 for d in digits):
        print("YES")
    else:
        print("NO")
else:
    possible_ts = set()
    s_val = sum_s
    for i in range(1, int(math.sqrt(s_val)) + 1):
        if s_val % i == 0:
            if i <= s_val // 2:
                possible_ts.add(i)
            j = s_val // i
            if j <= s_val // 2 and j != i:
                possible_ts.add(j)
    found = False
    for t in sorted(possible_ts, reverse=True):
        current = 0
        count = 0
        valid = True
        for d in digits:
            current += d
            if current == t:
                count += 1
                current = 0
            elif current > t:
                valid = False
                break
        if current != 0:
            valid = False
        if valid and count >= 2:
            found = True
            break
    print("YES" if found else "NO")
```

### Explanation
1. **Sum Calculation**: The sum of the digits is calculated. If the sum is zero, we check if all digits are zero. If they are, the answer is "YES" because we can split into any number of segments.
2. **Divisors Identification**: For non-zero sums, we find all divisors of the sum that are less than or equal to half the sum. These divisors are potential target sums for the segments.
3. **Segment Validation**: For each divisor, we check if the digits can be partitioned into consecutive segments where each segment's sum equals the divisor. If such a partition exists with at least two segments, the answer is "YES".

This approach efficiently checks all possible target sums and ensures that we determine the correct answer with optimal performance.
