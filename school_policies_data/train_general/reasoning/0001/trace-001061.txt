To solve this problem, we need to determine the minimal radius \( r \) such that every city is within \( r \) distance from at least one cellular tower. The cities and towers are given as sorted lists of their coordinates on a straight line.

### Approach
1. **Binary Search for Closest Tower**: For each city, we use binary search to find the closest tower. The binary search helps efficiently locate the insertion point in the sorted list of towers, which allows us to check the nearest towers on either side of this insertion point.
2. **Calculate Minimum Distance**: For each city, we consider the closest towers around the insertion point (one before and one after) and compute the minimum distance to these towers.
3. **Track Maximum Distance**: The maximum of these minimum distances across all cities gives the minimal radius \( r \) required to cover all cities.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    m = int(input[1])
    cities = list(map(int, input[2:2 + n]))
    towers = list(map(int, input[2 + n:2 + n + m]))
    
    max_r = 0
    for city in cities:
        pos = bisect.bisect_left(towers, city)
        min_dist = float('inf')
        if pos < m:
            min_dist = abs(city - towers[pos])
        if pos > 0:
            min_dist = min(min_dist, city - towers[pos - 1])
        max_r = max(max_r, min_dist)
    print(max_r)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints. The input is split into the number of cities, number of towers, city coordinates, and tower coordinates.
2. **Binary Search**: For each city, we use `bisect_left` to find the position where the city would fit in the sorted list of towers. This position helps identify the nearest towers.
3. **Distance Calculation**: We check the tower at the found position and the one immediately before it (if they exist) to determine the closest tower. The minimum distance from these towers to the city is computed.
4. **Determine Maximum Radius**: The maximum of these minimum distances across all cities is the answer, as it ensures all cities are within this radius from at least one tower.

This approach efficiently leverages binary search and linear iteration, resulting in a time complexity of \( O(n \log m) \), which is optimal for the given problem constraints.
