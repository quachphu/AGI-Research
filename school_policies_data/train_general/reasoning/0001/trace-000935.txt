To solve this problem, we need to determine if a given 4-digit security code is "Bad" or "Good" based on the presence of consecutive identical digits. The code is considered "Bad" if it contains any two consecutive digits that are the same, otherwise, it is "Good".

### Approach
1. **Input Reading**: Read the input string which is guaranteed to be a 4-character string consisting of digits.
2. **Consecutive Check**: Iterate through the string from the first character to the third character (0-based index). For each character at position `i`, check if it is the same as the character at position `i+1`.
3. **Decision Making**: If any pair of consecutive characters is found to be the same, immediately print "Bad" and exit. If no such pairs are found after checking all consecutive pairs, print "Good".

### Solution Code
```python
s = input().strip()

for i in range(3):
    if s[i] == s[i+1]:
        print("Bad")
        exit()
print("Good")
```

### Explanation
1. **Reading Input**: The input string `s` is read and stripped of any leading or trailing whitespace (though the problem guarantees it will be a 4-digit string).
2. **Loop Through Consecutive Pairs**: The loop runs from index 0 to 2 (inclusive). For each index `i`, it checks if the character at `s[i]` is the same as the character at `s[i+1]`.
3. **Immediate Exit on Match**: If a match is found, the code prints "Bad" and exits immediately, ensuring efficient termination without unnecessary checks.
4. **Output Result**: If no consecutive matches are found after checking all pairs, the code prints "Good".

This approach ensures that we efficiently check each pair of consecutive digits exactly once, leading to a time complexity of O(1) (constant time) given the fixed input size of 4 digits. The solution is optimal and handles all edge cases as specified in the problem constraints.
