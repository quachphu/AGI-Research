Shi-ta's requirement is that her piece of chocolate must be a continuous range of strips, while Be-ko's requirement is that her piece must have an area of at least S and as few almonds as possible.

### Approach
1. **Input Parsing**: Read the input values for each test case, including the number of almonds, lines, width, height, and required area S.
2. **Compute Strips**: Calculate the area of each strip formed by the vertical lines. Each strip is defined by consecutive lines or the edges of the chocolate.
3. **Almond Distribution**: Determine which strip each almond belongs to using binary search based on the line equations.
4. **Sliding Window Technique**: Use a sliding window approach to find the maximum number of almonds in a contiguous range of strips such that the total area of the range does not exceed `w*h - S`. This ensures Be-ko's area requirement is met.
5. **Result Calculation**: The minimum number of almonds Be-ko receives is the total almonds minus the maximum almonds found in the valid range.

import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    while True:
        n = int(input[ptr])
        m = int(input[ptr+1])
        w = int(input[ptr+2])
        h = int(input[ptr+3])
        S = int(input[ptr+4])
        ptr += 5
        if n == 0 and m == 0 and w == 0 and h == 0 and S == 0:
            break
        l_list = []
        r_list = []
        for _ in range(m):
            l = int(input[ptr])
            r = int(input[ptr+1])
            l_list.append(l)
            r_list.append(r)
            ptr += 2
        almonds = []
        for _ in range(n):
            x = float(input[ptr])
            y = float(input[ptr+1])
            almonds.append((x, y))
            ptr += 2
        
        m_strips = m + 1
        area = [0.0] * m_strips
        almond_count = [0] * m_strips
        
        if m >= 1:
            area[0] = (w / 2) * (l_list[0] + r_list[0])
        else:
            area[0] = w * h
        
        for i in range(1, m):
            area[i] = (w / 2) * ((l_list[i] + r_list[i]) - (l_list[i-1] + r_list[i-1]))
        
        if m >= 1:
            area[m] = (w / 2) * (2 * h - (l_list[-1] + r_list[-1]))
        else:
            area[0] = w * h
        
        for x, y in almonds:
            low = 0
            high = m - 1
            best = m
            while low <= high:
                mid = (low + high) // 2
                l_mid = l_list[mid]
                r_mid = r_list[mid]
                y_mid = ((r_mid - l_mid) * x) / w + l_mid
                if y_mid > y + 1e-12:
                    best = mid
                    high = mid - 1
                else:
                    low = mid + 1
            almond_count[best] += 1
        
        target = w * h - S
        max_sum = 0
        current_sum_area = 0.0
        current_sum_almonds = 0
        left = 0
        right = 0
        
        if target >= 0:
            while left < m_strips:
                while right < m_strips and current_sum_area + area[right] <= target + 1e-9:
                    current_sum_area += area[right]
                    current_sum_almonds += almond_count[right]
                    right += 1
                if current_sum_almonds > max_sum:
                    max_sum = current_sum_almonds
                if left < right:
                    current_sum_area -= area[left]
                    current_sum_almonds -= almond_count[left]
                    left += 1
                else:
                    right += 1
                    left += 1
        
        total_almonds = sum(almond_count)
        print(total_almonds - max_sum)
