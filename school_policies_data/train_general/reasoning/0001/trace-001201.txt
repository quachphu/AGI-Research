To solve this problem, we need to determine the solution to a system of linear equations where each equation is missing one variable. The solution involves finding the values of the variables that satisfy all the equations given the constraints.

### Approach
1. **Understanding the Equations**: Each equation in the system is structured such that the sum of all variables except one (say \( x_i \)) equals a given constant \( a_i \).
2. **Sum of Variables**: Let \( S \) be the sum of all variables \( x_1, x_2, \ldots, x_N \). For each equation \( i \), the sum \( S - x_i = a_i \).
3. **Deriving the Sum \( S \)**: By summing all equations, we derive that \( S = \frac{\sum_{i=1}^{N} a_i}{N-1} \). This is because each variable \( x_i \) is excluded exactly once from the sum, leading to \( (N-1)S = \sum_{i=1}^{N} a_i \).
4. **Calculating Each Variable**: Once \( S \) is known, each variable \( x_i \) can be computed as \( x_i = S - a_i \).

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        a = list(map(int, input[ptr:ptr+N]))
        ptr += N
        sum_a = sum(a)
        S = sum_a // (N - 1)
        x = [S - ai for ai in a]
        print(' '.join(map(str, x)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once for efficiency, especially given the constraints.
2. **Processing Each Test Case**: For each test case, we read the number of equations \( N \) and the constants \( a_1, a_2, \ldots, a_N \).
3. **Sum Calculation**: The sum of all constants \( a_i \) is computed. This sum is divided by \( N-1 \) to get the total sum \( S \) of all variables.
4. **Variable Calculation**: Each variable \( x_i \) is determined by subtracting \( a_i \) from \( S \).
5. **Output**: The variables are printed in the required format, ensuring efficient conversion and space-separated output.

This approach efficiently handles the constraints and ensures correctness by leveraging mathematical properties of the system of equations.
