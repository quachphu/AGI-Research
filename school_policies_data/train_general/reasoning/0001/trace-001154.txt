1. **Sort the Weights**: First, sort the array of weights in non-decreasing order. This allows us to process each weight in ascending order, which helps in efficiently assigning the smallest possible valid weight.
2. **Greedy Assignment**: For each weight in the sorted list, attempt to adjust it to the smallest possible valid weight (either -1, 0, or +1 from the original weight). The valid weights are checked in the order of the smallest possible adjustment first (i.e., original weight -1, then original weight, then original weight +1).
3. **Track Used Weights**: Use a boolean array to keep track of which weights have already been assigned. This ensures that each weight is used exactly once.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
a.sort()

max_x = 150001  # Maximum possible x can be 150000 + 1 = 150001
used = [False] * (max_x + 2)  # To cover indices up to 150001

count = 0

for num in a:
    for delta in [-1, 0, 1]:
        x = num + delta
        if x <= 0:
            continue
        if x > max_x:
            continue
        if not used[x]:
            used[x] = True
            count += 1
            break

print(count)
```

### Explanation
1. **Sorting**: By sorting the weights, we ensure that we process each weight in ascending order. This allows us to greedily assign the smallest possible valid weight first, which helps in maximizing the number of valid assignments for subsequent weights.
2. **Greedy Weight Adjustment**: For each weight, we check the possible adjusted weights in the order of -1, 0, and +1. This order helps in utilizing the smallest possible valid weight first, leaving larger weights available for subsequent boxers.
3. **Efficient Tracking**: Using a boolean array to track used weights allows for O(1) time complexity for both checking and updating the used status of a weight. This ensures the solution is efficient even for the upper constraint of 150,000 boxers.

This approach efficiently balances between correctness and performance, ensuring we maximize the team size while adhering to the problem constraints.
