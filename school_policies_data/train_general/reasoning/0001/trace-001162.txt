To solve this problem, we need to determine the minimum number of card flips required to make at least half of the cards show the same color on their front side. The solution involves analyzing each possible color from both the front and back sides of the cards and calculating the minimum flips needed to achieve the required count of cards showing that color.

### Approach
1. **Collect Data**: Read the input values and collect the counts of each color appearing on the front and back sides of the cards. Track all unique colors encountered.
2. **Calculate Required Count**: Determine the minimum number of cards needed to form the majority, which is `(n + 1) // 2` where `n` is the total number of cards.
3. **Evaluate Each Color**: For each unique color, calculate how many cards already show this color on their front (initial count) and how many cards can be flipped to show this color (possible flips).
4. **Determine Feasibility**: Check if the sum of the initial count and possible flips for each color meets the required majority. If it does, compute the minimum flips needed and track the minimum across all colors.
5. **Output Result**: If no color meets the requirement, return -1. Otherwise, return the minimum flips needed.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n = int(sys.stdin.readline())
    front_counts = defaultdict(int)
    back_not_front = defaultdict(int)
    colors = set()
    
    for _ in range(n):
        a, b = map(int, sys.stdin.readline().split())
        front_counts[a] += 1
        colors.add(a)
        colors.add(b)
        if a != b:
            back_not_front[b] += 1
    
    required = (n + 1) // 2
    min_flips = float('inf')
    
    for c in colors:
        initial = front_counts.get(c, 0)
        possible = back_not_front.get(c, 0)
        total = initial + possible
        if total >= required:
            needed = max(0, required - initial)
            if needed < min_flips:
                min_flips = needed
    
    print(-1 if min_flips == float('inf') else min_flips)

if __name__ == "__main__":
    main()
```

### Explanation
- **Data Collection**: We use dictionaries to count occurrences of each color on the front side (`front_counts`) and track how many times a color appears on the back side when the front side is different (`back_not_front`).
- **Required Count Calculation**: The required count of cards to form a majority is computed using integer division to handle both even and odd numbers of cards.
- **Color Evaluation**: For each unique color, we check if combining the existing front occurrences and possible flips can meet the required count. The minimum flips needed for each feasible color is determined and tracked.
- **Result Determination**: The minimum flips across all feasible colors is outputted, or -1 if no color can form the majority.

This approach efficiently checks all possible colors and ensures we find the optimal solution with minimal computational overhead, making it suitable for large input sizes up to 100,000 cards.
