To solve this problem, we need to determine the number of ways to choose three sticks with different lengths that can form a triangle. The solution involves checking all possible combinations of three sticks, ensuring they have distinct lengths and satisfy the triangle inequality condition.

### Approach
1. **Input Reading**: Read the number of sticks and their respective lengths.
2. **Triple Iteration**: Generate all possible triples (i, j, k) where i < j < k.
3. **Distinct Length Check**: For each triple, check if all three sticks have distinct lengths.
4. **Triangle Inequality Check**: Verify if the three lengths can form a triangle by checking if the sum of the two smaller lengths is greater than the largest length.
5. **Count Valid Triples**: Maintain a count of all valid triples that meet both conditions.

### Solution Code
```python
n = int(input())
L = list(map(int, input().split()))
count = 0
for i in range(n):
    for j in range(i + 1, n):
        for k in range(j + 1, n):
            a, b, c = sorted([L[i], L[j], L[k]])
            if a != b and b != c and a != c:
                if a + b > c:
                    count += 1
print(count)
```

### Explanation
1. **Input Reading**: The input is read and parsed into a list of integers representing the lengths of the sticks.
2. **Triple Iteration**: Using three nested loops, we iterate over all possible combinations of three distinct indices (i, j, k) where i < j < k.
3. **Sorting and Distinct Check**: For each combination, the lengths are sorted to easily identify the smallest, middle, and largest values. We then check if all three values are distinct.
4. **Triangle Condition Check**: The sorted values are checked to see if the sum of the two smaller values is greater than the largest value, which is a necessary condition for forming a triangle.
5. **Counting Valid Triples**: Each valid triple that meets both conditions is counted, and the final count is printed.

This approach efficiently checks all possible combinations and ensures that only valid triples are counted, providing the correct solution within the problem constraints.
