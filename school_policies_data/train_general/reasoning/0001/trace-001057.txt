To solve this problem, we need to ensure that all employees in a company can communicate with each other, either directly or indirectly, through a common language. The goal is to minimize the cost of teaching new languages to achieve this connectivity.

### Approach
1. **Input Reading**: Read the number of employees (n) and languages (m), followed by the list of languages each employee knows.
2. **Union-Find Data Structure**: Use a union-find (disjoint set union, DSU) structure to group employees into connected components based on the languages they know. Employees are connected if they share a common language.
3. **Component Analysis**: Determine the connected components formed by the employees. Each component is a group of employees who can communicate with each other through shared languages.
4. **Cost Calculation**: For each language, calculate the cost to connect all components by ensuring that each component has at least one employee who knows the language. The cost is determined by the number of components that need to learn the language.
5. **Optimal Language Selection**: Find the language that results in the minimum cost by considering all possible languages and their respective costs.

### Solution Code
```python
def main():
    import sys
    from collections import defaultdict

    n, m = map(int, sys.stdin.readline().split())
    employees = []
    for _ in range(n):
        parts = list(map(int, sys.stdin.readline().split()))
        k = parts[0]
        langs = parts[1:] if k > 0 else []
        employees.append(langs)

    parent = list(range(n))

    def find(u):
        while parent[u] != u:
            parent[u] = parent[parent[u]]  # Path compression
            u = parent[u]
        return u

    def union(u, v):
        u_root = find(u)
        v_root = find(v)
        if u_root != v_root:
            parent[v_root] = u_root

    # Group employees by language
    lang_to_emps = defaultdict(list)
    for i in range(n):
        for lang in employees[i]:
            lang_to_emps[lang].append(i)

    # Merge all employees sharing the same language
    for lang, emps in lang_to_emps.items():
        if emps:
            root = emps[0]
            for emp in emps[1:]:
                union(root, emp)

    # Build components and track their languages
    components = defaultdict(set)
    for i in range(n):
        root = find(i)
        components[root].update(employees[i])

    C = len(components)
    min_cost = float('inf')

    # Check each possible language
    for L in range(1, m + 1):
        count = 0
        for comp_langs in components.values():
            if L in comp_langs:
                count += 1
        if count == 0:
            cost = C
        else:
            cost = C - count
        if cost < min_cost:
            min_cost = cost

    print(min_cost)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Union-Find Initialization**: Each employee starts in their own set. Using the union-find structure, we merge sets of employees who share a common language.
2. **Component Formation**: After processing all languages, each connected component represents a group of employees who can communicate through shared languages.
3. **Language Cost Calculation**: For each language, we count how many components already have at least one employee who knows the language. The cost to connect all components using this language is the number of components that do not know the language.
4. **Optimal Solution**: The minimal cost is determined by evaluating all possible languages and selecting the one with the lowest cost.

This approach efficiently groups employees and calculates the minimum cost using union-find and component analysis, ensuring optimal performance within the problem constraints.
