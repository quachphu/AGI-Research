To solve this problem, we need to determine the minimum number of painted squares (denoted as '#') that need to be removed from a connected grid to make it disconnected. The solution involves checking if removing a single square can disconnect the grid, and if not, checking if removing two squares can achieve the same.

### Approach
1. **Input Handling and Initial Checks**: Read the grid dimensions and the grid itself. Collect all the coordinates of the painted cells. If there are 1 or 2 painted cells, the answer is -1 because they cannot be disconnected.
2. **Check Single Square Removal**: For each painted cell, temporarily remove it and check if the remaining cells form a disconnected set using BFS. If any removal results in disconnection, the answer is 1.
3. **Check Two Squares Removal**: If no single square removal disconnects the grid, check if there are at least 4 painted cells. If so, the answer is 2 because removing any two squares from a 2-vertex-connected graph will disconnect it. If there are exactly 3 painted cells, the answer remains -1.

### Solution Code
```python
import sys
from collections import deque

def main():
    n, m = map(int, sys.stdin.readline().split())
    grid = []
    cells = []
    for i in range(n):
        line = sys.stdin.readline().strip()
        grid.append(line)
        for j in range(m):
            if line[j] == '#':
                cells.append((i, j))
    
    total = len(cells)
    if total <= 2:
        print(-1)
        return
    
    # Check for any single cell removal that disconnects the set
    for cell in cells:
        remaining = [c for c in cells if c != cell]
        if not remaining:
            continue
        visited = set()
        start = remaining[0]
        queue = deque([start])
        visited.add(start)
        while queue:
            x, y = queue.popleft()
            for dx, dy in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                nx, ny = x + dx, y + dy
                if (nx, ny) in remaining and (nx, ny) not in visited:
                    visited.add((nx, ny))
                    queue.append((nx, ny))
        if len(visited) != len(remaining):
            print(1)
            return
    
    # Check if total cells >=4 to return 2
    if total >= 4:
        print(2)
    else:
        print(-1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Input Handling**: The grid is read and stored, and the coordinates of all painted cells are collected.
2. **Single Square Check**: For each painted cell, we simulate its removal and use BFS to check connectivity. If the BFS does not visit all remaining cells, it means the grid is disconnected, and we print 1.
3. **Two Squares Check**: If no single square removal works and there are at least 4 cells, we print 2. This is based on the observation that removing two squares in a 2-vertex-connected grid will disconnect it. If there are exactly 3 cells, it's impossible to disconnect them by removing two, so we print -1.

This approach efficiently checks the minimal conditions required to disconnect the grid using BFS for connectivity checks, ensuring correctness within the problem constraints.
