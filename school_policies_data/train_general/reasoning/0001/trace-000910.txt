To solve this problem, we need to determine if a given word is a 'mirror' word. A mirror word is one that looks the same when reflected in a mirror. This means that the word must be a palindrome and consist only of characters that are symmetric in a sans-serif font.

### Approach
1. **Identify Symmetric Characters**: Only certain characters look the same when mirrored. These characters are A, H, I, M, O, T, U, V, W, X, and Y.
2. **Check for Valid Characters**: Ensure that all characters in the input word belong to the set of symmetric characters.
3. **Check Palindrome Property**: The input word must read the same forwards and backwards to be a mirror word.

### Solution Code
```python
s = input().strip()
allowed = {'A', 'H', 'I', 'M', 'O', 'T', 'U', 'V', 'W', 'X', 'Y'}

# Check all characters are allowed
valid = all(c in allowed for c in s)

# Check if the string is a palindrome
if valid and s == s[::-1]:
    print("YES")
else:
    print("NO")
```

### Explanation
1. **Symmetric Characters Check**: We first check if every character in the input string is part of the predefined set of symmetric characters. This is done using a set for O(1) look-up time.
2. **Palindrome Check**: If all characters are valid, we then check if the string is a palindrome by comparing it with its reverse. If both conditions are satisfied, the word is a mirror word.

This approach efficiently combines both checks to ensure correctness and handles the input constraints effectively. The solution runs in O(n) time complexity, where n is the length of the input string, making it suitable for large inputs up to 100,000 characters.
