To solve this problem, we need to determine how many quadratic equations from a given list have real roots. This can be achieved by checking the discriminant of each quadratic equation, which is calculated as \( D = b^2 - 4ac \). If the discriminant is non-negative, the equation has real roots; otherwise, it has imaginary roots.

### Approach
1. **Read Input**: First, read the number of quadratic equations, \( N \).
2. **Process Each Equation**: For each quadratic equation, read the coefficients \( a \), \( b \), and \( c \).
3. **Calculate Discriminant**: Compute the discriminant \( D \) using the formula \( D = b^2 - 4ac \).
4. **Check Real Roots**: If the discriminant is greater than or equal to zero, increment the count of solvable equations.
5. **Output Result**: Print the total count of equations with real roots.

### Solution Code
```python
def count_real_roots():
    import sys
    n = int(sys.stdin.readline())
    count = 0
    for _ in range(n):
        a, b, c = map(int, sys.stdin.readline().split())
        discriminant = b ** 2 - 4 * a * c
        if discriminant >= 0:
            count += 1
    print(count)

count_real_roots()
```

### Explanation
1. **Reading Input**: The function starts by reading the number of equations, \( N \), from the standard input.
2. **Loop Through Equations**: For each equation, the coefficients \( a \), \( b \), and \( c \) are read and converted to integers.
3. **Discriminant Calculation**: For each set of coefficients, the discriminant is computed. This value determines the nature of the roots of the quadratic equation.
4. **Check for Real Roots**: If the discriminant is non-negative, the equation has real roots, and the count is incremented.
5. **Output**: Finally, the count of equations with real roots is printed.

This approach efficiently processes each quadratic equation in linear time relative to the number of equations, ensuring optimal performance even for the upper constraint of \( N = 100 \).
