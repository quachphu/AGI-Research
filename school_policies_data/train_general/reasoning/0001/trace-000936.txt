To solve this problem, we need to determine the difference between Alice's and Bob's scores after they take turns picking cards optimally. The optimal strategy for both players is to always pick the largest remaining card to maximize their own score.

### Approach
1. **Sort the Cards**: First, we sort the list of card values in descending order. This allows both players to pick the largest available card on their turn.
2. **Alternate Picking**: Alice starts first and picks the card at the 0th index of the sorted list. Bob then picks the next card (1st index), and this alternation continues until all cards are taken.
3. **Sum Scores**: Calculate the sum of the cards picked by Alice (even indices) and Bob (odd indices) from the sorted list.
4. **Compute Difference**: Subtract Bob's total score from Alice's total score to get the result.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
a_sorted = sorted(a, reverse=True)
alice = 0
bob = 0
for i in range(n):
    if i % 2 == 0:
        alice += a_sorted[i]
    else:
        bob += a_sorted[i]
print(alice - bob)
```

### Explanation
1. **Input Reading**: The code reads the number of cards and their values from standard input.
2. **Sorting**: The card values are sorted in descending order to facilitate optimal picking.
3. **Score Calculation**: By iterating through the sorted list, Alice picks cards at even indices and Bob at odd indices. This ensures both players always pick the largest remaining card available on their turn.
4. **Result Calculation**: The difference between Alice's and Bob's scores is computed and printed, which gives the desired result.

This approach ensures that both players play optimally, leading to an efficient and correct solution. The time complexity is dominated by the sorting step, which is \(O(N \log N)\), where \(N\) is the number of cards. This is efficient given the problem constraints.
