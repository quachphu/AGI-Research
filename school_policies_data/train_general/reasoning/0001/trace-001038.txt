To solve this problem, we need to determine if a binary string is classified as "Good" or "Bad" based on the presence of specific substrings. According to the problem, a string is "Good" if it contains either "010" or "101" as a substring, otherwise it is "Bad".

### Approach
1. **Input Reading**: Read the number of test cases and each binary string efficiently.
2. **Check Substrings**: For each string, check if it contains either "010" or "101". This can be done efficiently by iterating through each character and checking consecutive triplets.
3. **Edge Cases Handling**: If the string length is less than 3, it is automatically classified as "Bad" since it cannot contain the required substrings.

### Solution Code
```python
import sys

def classify_feedback(s):
    n = len(s)
    if n < 3:
        return "Bad"
    for i in range(n - 2):
        if (s[i] == '0' and s[i+1] == '1' and s[i+2] == '0') or \
           (s[i] == '1' and s[i+1] == '0' and s[i+2] == '1'):
            return "Good"
    return "Bad"

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        s = sys.stdin.readline().strip()
        print(classify_feedback(s))

if __name__ == "__main__":
    main()
```

### Explanation
- **Input Handling**: The code reads the input using `sys.stdin.readline()` for efficiency, especially given the large possible input size.
- **Substring Check**: For each string, we iterate through each possible triplet starting from each character. If either "010" or "101" is found, the string is immediately classified as "Good".
- **Efficiency**: The solution efficiently checks each triplet in linear time (O(n)) per string, ensuring it handles the upper constraint limits effectively. This approach ensures that even for the maximum input size, the solution remains performant.
