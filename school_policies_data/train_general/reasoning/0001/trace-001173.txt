To solve this problem, we need to determine if we can transform a number `a` into another number `b` using two specific operations: multiplying by 2 or appending the digit 1 to the right. If possible, we should also provide the sequence of transformations.

### Approach
The optimal approach is to work backwards from the target number `b` to the initial number `a`. This reverse approach allows us to efficiently explore possible transformations by considering the inverse operations:
1. If `b` is even, it could have been formed by multiplying some number by 2.
2. If `b` ends in 1, it could have been formed by appending 1 to some number.

Using a breadth-first search (BFS) strategy, we start from `b` and apply these inverse operations until we either reach `a` or determine that it is impossible. This method ensures that we explore the shortest path first and avoid redundant checks using a visited set.

### Solution Code
```python
import sys
from collections import deque

a, b = map(int, sys.stdin.readline().split())

def solve():
    queue = deque()
    queue.append((b, [b]))
    visited = set()
    visited.add(b)
    found = False
    result = []
    while queue:
        current, path = queue.popleft()
        if current == a:
            found = True
            result = path[::-1]  # Reverse the path to get the correct order
            break
        if current < a:
            continue
        # Generate possible predecessors
        predecessors = []
        if current % 2 == 0:
            pred = current // 2
            if pred >= a:
                predecessors.append(pred)
        if current % 10 == 1:
            pred = (current - 1) // 10
            if pred >= a:
                predecessors.append(pred)
        for p in predecessors:
            if p not in visited:
                visited.add(p)
                new_path = path + [p]
                queue.append((p, new_path))
    if found:
        print("YES")
        print(len(result))
        print(' '.join(map(str, result)))
    else:
        print("NO")

solve()
```

### Explanation
1. **Initialization**: We start by reading the input values `a` and `b`. We initialize a queue with the target number `b` and a path list containing `b`. A visited set is used to track processed numbers to avoid cycles.
2. **BFS Loop**: We process each number in the queue. For each number, we check if it matches `a`. If it does, we reverse the path to get the correct transformation sequence.
3. **Predecessor Generation**: For each number, we generate possible predecessors using the inverse operations. If the number is even, we consider dividing by 2. If it ends in 1, we consider removing the last digit.
4. **Check Validity**: Each generated predecessor is checked to ensure it is valid (greater than or equal to `a` and not already visited). Valid predecessors are added to the queue.
5. **Result Handling**: If we reach `a`, we print the transformation sequence. If the queue is exhausted without reaching `a`, we print "NO".

This approach efficiently narrows down possible transformations using reverse operations and BFS, ensuring we find a valid sequence if it exists.
