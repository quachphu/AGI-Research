To solve this problem, we need to determine if a robot, following a given command string infinitely, can reach a specified target position (a, b) starting from the origin (0, 0). The robot's movement is determined by the command string, which it repeats indefinitely.

### Approach
1. **Immediate Check for Origin**: If the target position is (0, 0), the answer is immediately "Yes" since the robot starts there.
2. **Command Execution Simulation**: Track the robot's position after each step in the command string to precompute all possible positions the robot can reach during one full cycle of the command.
3. **Cycle Displacement Calculation**: Compute the displacement (dx, dy) after one full cycle of the command string. This helps in determining the robot's position after multiple cycles.
4. **Check for Zero Displacement**: If the robot returns to the origin after one full cycle (dx and dy are both zero), check if the target position is reachable within the first cycle.
5. **General Case Handling**: For each position reached during the first cycle, determine if the target position can be achieved by repeating the command string a certain number of times (cycles) followed by some steps from the next cycle.

### Solution Code
```python
a, b = map(int, input().split())
s = input().strip()

if a == 0 and b == 0:
    print("Yes")
    exit()

positions = [(0, 0)]
x, y = 0, 0
for c in s:
    if c == 'U':
        y += 1
    elif c == 'D':
        y -= 1
    elif c == 'L':
        x -= 1
    elif c == 'R':
        x += 1
    positions.append((x, y))

dx, dy = positions[-1][0], positions[-1][1]

if dx == 0 and dy == 0:
    # Check if (a, b) is in the positions list (excluding the last one)
    positions = positions[:-1]
    if (a, b) in positions:
        print("Yes")
    else:
        print("No")
else:
    found = False
    len_s = len(s)
    for m in range(len_s):
        x_m, y_m = positions[m]
        # Check x equation: a = x_m + k * dx
        # Check y equation: b = y_m + k * dy
        # Handle different cases based on dx and dy
        valid = False
        if dx == 0:
            if a != x_m:
                continue
            # x equation satisfied, check y
            if dy == 0:
                if b == y_m:
                    valid = True
            else:
                if (b - y_m) % dy != 0:
                    continue
                k = (b - y_m) // dy
                if k >= 0:
                    valid = True
        else:
            # dx != 0
            remainder_x = (a - x_m) % dx
            if remainder_x != 0:
                continue
            k_x = (a - x_m) // dx
            if k_x < 0:
                continue
            # Check y equation
            if dy == 0:
                if b != y_m:
                    continue
                valid = True
            else:
                remainder_y = (b - y_m) % dy
                if remainder_y != 0:
                    continue
                k_y = (b - y_m) // dy
                if k_y == k_x and k_y >= 0:
                    valid = True
        if valid:
            found = True
            break
    print("Yes" if found else "No")
```

### Explanation
1. **Immediate Check**: If the target is the origin, the answer is immediately "Yes".
2. **Position Tracking**: The robot's positions after each step in the command string are precomputed to understand its path during one cycle.
3. **Cycle Displacement**: The displacement after one full cycle helps in determining how the robot's position changes with each subsequent cycle.
4. **Zero Displacement Handling**: If the robot returns to the origin after each cycle, we check if the target is reachable within the first cycle.
5. **General Case**: For each position during the first cycle, we check if the target can be reached by combining the displacement from multiple cycles and some steps from the next cycle. This involves solving linear equations derived from the robot's movement pattern.

This approach efficiently checks all possible paths the robot can take, ensuring that we cover both the initial cycles and any subsequent steps needed to reach the target position.
