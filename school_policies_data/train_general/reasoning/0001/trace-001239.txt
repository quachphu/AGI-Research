To solve this problem, we need to determine the last remaining number on the board after two players alternately remove numbers, with the first player aiming to minimize the final number and the second player aiming to maximize it. The optimal strategy for both players leads to a specific outcome based on the sorted order of the numbers.

### Approach
The key insight is that the optimal moves by both players will result in the median of the sorted array being the last remaining number. This is because:
1. The first player (minimizer) will always remove the largest remaining number.
2. The second player (maximizer) will always remove the smallest remaining number.

By sorting the array and considering the median, we can determine the result efficiently. The median is found at the index `(n-1) // 2` in the sorted array, where `n` is the number of elements.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
a.sort()
print(a[(n - 1) // 2])
```

### Explanation
1. **Input Reading**: Read the number of elements `n` and the list of integers.
2. **Sorting**: Sort the list of integers in non-decreasing order.
3. **Median Calculation**: The median is found at the index `(n-1) // 2` in the sorted list. This index is chosen because each player alternately removes the largest and smallest elements, converging towards the median.
4. **Output**: Print the median value, which is the result of the optimal play by both players.

This approach efficiently computes the result in O(n log n) time due to the sorting step, which is optimal for the given problem constraints.
