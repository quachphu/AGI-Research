To solve this problem, we need to determine the time at which each video stops being recompressed on one of the available servers in a social network for dogs. The key challenge is efficiently managing the servers to minimize the total processing time for each video.

### Approach
1. **Problem Analysis**: Each server can process one video at a time, and each video must be processed in the order it arrives. The processing time for a video is equal to its duration in minutes converted to seconds. The goal is to determine the end time for each video after processing.

2. **Intuition**: Use a min-heap (priority queue) to keep track of the earliest available times for each server. This allows us to efficiently determine which server will be available next and assign the incoming video to that server.

3. **Algorithm**:
   - **Initialization**: Start with all servers available at time 0.
   - **Processing Each Video**: For each video, check the earliest available server using the heap. The start time for processing the video is the maximum of the video's arrival time and the server's available time. Update the server's available time and push it back into the heap.

4. **Complexity**: The algorithm efficiently handles each video in O(log k) time per video due to the heap operations, leading to an overall time complexity of O(n log k), where n is the number of videos and k is the number of servers.

### Solution Code
```python
import heapq
import sys

def main():
    n, k = map(int, sys.stdin.readline().split())
    heap = [0] * k
    heapq.heapify(heap)
    for _ in range(n):
        s, m = map(int, sys.stdin.readline().split())
        earliest = heapq.heappop(heap)
        start = max(s, earliest)
        end = start + m
        print(end)
        heapq.heappush(heap, end)

if __name__ == "__main__":
    main()
```

### Explanation
- **Heap Initialization**: The heap is initialized with k zeros, representing that all servers are available starting at time 0.
- **Processing Each Video**: For each video, we pop the smallest element from the heap (the earliest available server). The start time for processing the video is the maximum of the video's arrival time and the server's earliest available time. The end time is calculated and pushed back into the heap.
- **Output**: The end time for each video is printed immediately after processing, ensuring the results are in the order the videos were received.

This approach efficiently manages server availability using a priority queue, ensuring optimal scheduling and processing of each video.
