To solve this problem, we need to efficiently determine the x-th character in the sequence TN-1 formed by repeatedly concatenating strings and their reverses without explicitly constructing the entire sequence, which can be exponentially large.

### Approach
1. **Understand the Sequence Construction**: Each Ti is constructed as Ti-1 + reverse(Ti-1) + Si. This leads to exponential growth in the length of Ti, making direct construction infeasible.
2. **Precompute Lengths**: Compute the lengths of each Ti up to TN-1 using the recurrence relation L_i = 2 * L_{i-1} + len(Si). This helps in determining the segments of the sequence during query processing.
3. **Query Processing**: For each query, determine which segment (Ti-1, reversed Ti-1, or Si) the queried index x falls into by working backwards from TN-1 to T0. Adjust the index recursively to trace back to the original segment and retrieve the character efficiently.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        M = int(input[ptr + 1])
        ptr += 2
        S = []
        for _ in range(N):
            S.append(input[ptr])
            ptr += 1
        # Compute L array
        if N == 0:
            L = []
        else:
            L = [0] * N
            L[0] = len(S[0])
            for i in range(1, N):
                L[i] = 2 * L[i-1] + len(S[i])
        # Read queries
        queries = []
        for _ in range(M):
            queries.append(int(input[ptr]))
            ptr += 1
        # Process each query
        res = []
        for x in queries:
            current_x = x
            i = N - 1
            found = False
            while i > 0:
                prev_len = L[i-1]
                if current_x >= 2 * prev_len:
                    # Part 3: S[i]
                    offset = current_x - 2 * prev_len
                    res.append(S[i][offset])
                    found = True
                    break
                elif current_x >= prev_len:
                    # Part 2: reversed part
                    current_x = prev_len - 1 - (current_x - prev_len)
                # Part 1: keep current_x as is
                i -= 1
            if not found:
                res.append(S[0][current_x])
        # Output the result for this test case
        print(''.join(res))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints on the number of test cases and queries.
2. **Length Array (L)**: This array stores the length of each Ti, allowing us to quickly determine the segments of the sequence without constructing them.
3. **Query Processing**: For each query, we start from TN-1 and recursively determine the segment containing the queried index. Adjustments are made to map the index back through the sequence's construction steps until we reach the original string T0 (S0) or the relevant part of the current segment.

This approach ensures that we efficiently handle each query in O(N) time, making the solution feasible even for the upper constraint limits.
