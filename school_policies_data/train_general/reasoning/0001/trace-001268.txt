To solve this problem, we need to determine the number of distinct values Ivan would write on the blackboard when considering all possible values of \( a \) from 1 to \( 10^{18} \) for a given \( b \). The value written on the blackboard for each \( a \) is \( \text{LCM}(a, b) / a \), which simplifies to \( \frac{b}{\text{GCD}(a, b)} \). The distinct values of this expression correspond to the divisors of \( b \).

### Approach
1. **Understanding the Expression**: The expression \( \frac{\text{LCM}(a, b)}{a} \) simplifies to \( \frac{b}{\text{GCD}(a, b)} \). This means we need to find the number of distinct values of \( \frac{b}{d} \) where \( d \) is a divisor of \( b \).
2. **Divisors of \( b \)**: The distinct values of \( \frac{b}{d} \) are exactly the divisors of \( b \). Therefore, the problem reduces to finding the number of divisors of \( b \).
3. **Prime Factorization**: To efficiently count the number of divisors of \( b \), we first factorize \( b \) into its prime factors. The number of divisors is then the product of each prime factor's exponent incremented by 1.

### Solution Code
```python
b = int(input())

def count_distinct_values(b):
    if b == 0:
        return 0
    divisors_count = 1
    current = b
    i = 2
    while i * i <= current:
        if current % i == 0:
            exponent = 0
            while current % i == 0:
                exponent += 1
                current //= i
            divisors_count *= (exponent + 1)
        i += 1
    if current > 1:
        divisors_count *= 2
    return divisors_count

print(count_distinct_values(b))
```

### Explanation
1. **Reading Input**: The input value \( b \) is read from standard input.
2. **Prime Factorization**: The code uses trial division to factorize \( b \). For each prime factor \( i \), it counts how many times \( i \) divides \( b \) (exponent). The number of divisors contributed by this prime factor is \( \text{exponent} + 1 \).
3. **Handling Remaining Factor**: If after processing all possible factors up to the square root of \( b \), there is any remaining value greater than 1, it must be a prime factor itself, contributing an additional factor of 2 to the divisor count.
4. **Result Calculation**: The product of all incremented exponents gives the total number of divisors of \( b \), which is printed as the result.

This approach efficiently computes the number of distinct values using prime factorization, ensuring optimal performance even for large values of \( b \) up to \( 10^{10} \).
