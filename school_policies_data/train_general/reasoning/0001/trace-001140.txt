To solve this problem, we need to determine the rankings of teams in a round-robin baseball tournament based on their wins and losses. The ranking criteria are: teams with the most wins come first, and if two teams have the same number of wins, the one with fewer losses is ranked higher. If both wins and losses are the same, teams retain their input order.

### Approach
1. **Input Reading**: Read input datasets until encountering a line with '0'.
2. **Processing Each Dataset**:
   - For each team, read their results and count the number of wins (0s) and losses (1s).
   - Store each team's wins, losses, original input index, and name.
3. **Sorting**: Sort the teams based on:
   - Descending order of wins.
   - Ascending order of losses if wins are tied.
   - Original input order if both wins and losses are tied.
4. **Output**: Print the sorted team names.

### Solution Code
```python
import sys

def main():
    while True:
        line = sys.stdin.readline()
        if not line:
            break
        line = line.strip()
        if line == '0':
            break
        n = int(line)
        teams = []
        for i in range(n):
            parts = sys.stdin.readline().strip().split()
            name = parts[0]
            results = parts[1:]
            wins = results.count('0')
            losses = results.count('1')
            teams.append((-wins, losses, i, name))
        teams.sort()
        for team in teams:
            print(team[3])
            
if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads each line of input until it encounters a '0', which signifies the end of input.
2. **Team Data Processing**: For each team, the results are processed to count wins (0s) and losses (1s). The original index is tracked to maintain input order for tie-breaking.
3. **Sorting Mechanism**: Teams are sorted using a tuple key `(-wins, losses, original_index)` to ensure correct ordering by wins (descending), losses (ascending), and input order.
4. **Output**: After sorting, the team names are printed in the determined order.

This approach efficiently processes each dataset and ensures the correct ranking based on the given criteria, providing an optimal and clear solution.
