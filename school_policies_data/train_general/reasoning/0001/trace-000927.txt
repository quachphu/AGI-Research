To solve this problem, we need to determine if each incoming student can find another student in the classroom with the exact same number of candies. The solution involves efficiently checking for the presence of candy counts using a set data structure for constant time lookups and insertions.

### Approach
1. **Reading Input:** The input consists of multiple test cases. For each test case, read the initial number of students (N) and the number of incoming students (M), followed by a list of candy counts for all students.
2. **Initial Setup:** For each test case, initialize a set with the candy counts of the initial students.
3. **Processing Incoming Students:** For each incoming student, check if their candy count exists in the set. If it does, print "YES"; otherwise, print "NO". Add the incoming student's candy count to the set after each check to ensure future checks include this student.

### Solution Code
```python
import sys

def main():
    data = sys.stdin.read().split()
    ptr = 0
    T = int(data[ptr])
    ptr += 1
    for _ in range(T):
        N = int(data[ptr])
        M = int(data[ptr + 1])
        ptr += 2
        arr = list(map(int, data[ptr:ptr + N + M]))
        ptr += N + M
        present = set(arr[:N])
        for num in arr[N:]:
            if num in present:
                print("YES")
            else:
                print("NO")
            present.add(num)

main()
```

### Explanation
- **Reading Input Efficiently:** The input is read all at once for efficiency, especially given the potentially large size. The data is split into a list of strings for easy processing.
- **Set Utilization:** A set is used to store the candy counts of students currently in the classroom. This allows for O(1) average time complexity for both membership checks and insertions.
- **Processing Each Incoming Student:** For each incoming student, the solution checks if their candy count is already present in the set. The result of this check determines the output ("YES" or "NO"). The candy count is then added to the set to include this student in future checks.

This approach ensures that each test case is processed efficiently, handling up to the maximum constraints effectively.
