To solve this problem, we need to determine the smallest non-negative angle by which one constellation (a set of points) must be rotated to match another constellation, considering that the order of points in the two constellations may differ.

### Approach
1. **Compute Centroids**: The centroid of each constellation is calculated to translate the points such that the centroid is at the origin. This step helps in normalizing the position of the constellations.
2. **Translate Points**: Each point in both constellations is translated relative to their respective centroids.
3. **Identify Key Points**: Identify the point(s) in the first translated constellation that are farthest from the origin. These points are used as reference points to determine potential rotation angles.
4. **Match Key Points**: For each key point in the first constellation, find all points in the second translated constellation that are at the same distance from the origin (within a small tolerance).
5. **Calculate Rotation Angles**: For each pair of key points (one from each constellation), compute the rotation angle required to align them.
6. **Validate Rotation**: Check if rotating all points of the first translated constellation by the computed angle results in a set of points that matches the second translated constellation (considering permutations and floating-point precision).

import math
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    while True:
        if ptr >= len(input):
            break
        n = int(input[ptr])
        ptr += 1
        if n == 0:
            break
        # Read first photo's points
        first = []
        for _ in range(n):
            x = float(input[ptr])
            y = float(input[ptr + 1])
            first.append((x, y))
            ptr += 2
        # Read second photo's points
        second = []
        for _ in range(n):
            x = float(input[ptr])
            y = float(input[ptr + 1])
            second.append((x, y))
            ptr += 2
        # Compute centroids
        c1x = sum(p[0] for p in first) / n
        c1y = sum(p[1] for p in first) / n
        c2x = sum(p[0] for p in second) / n
        c2y = sum(p[1] for p in second) / n
        # Translate points to be around origin
        trans_first = [(x - c1x, y - c1y) for x, y in first]
        trans_second = [(x - c2x, y - c2y) for x, y in second]
        # Find maximum distance in trans_first
        max_dist_sq = 0.0
        a_list = []
        for x, y in trans_first:
            dist_sq = x * x + y * y
            if dist_sq > max_dist_sq + 1e-10:
                max_dist_sq = dist_sq
                a_list = [(x, y)]
            elif abs(dist_sq - max_dist_sq) < 1e-10:
                a_list.append((x, y))
        max_dist = math.sqrt(max_dist_sq)
        # Collect points in trans_second with distance close to max_dist
        b_list = []
        for x, y in trans_second:
            dist = math.sqrt(x * x + y * y)
            if abs(dist - max_dist) < 1e-8:
                b_list.append((x, y))
        # Check possible thetas
        min_angle = None
        eps = 1e-7
        for a in a_list:
            ax, ay = a
            a_angle = math.atan2(ay, ax)
            for b in b_list:
                bx, by = b
                b_angle = math.atan2(by, bx)
                theta = (b_angle - a_angle) % (2 * math.pi)
                # Rotate all points and check
                rotated = []
                for x, y in trans_first:
                    x_rot = x * math.cos(theta) - y * math.sin(theta)
                    y_rot = x * math.sin(theta) + y * math.cos(theta)
                    rotated.append((x_rot, y_rot))
                # Sort rotated and trans_second
                rotated_sorted = sorted(rotated, key=lambda p: (round(p[0], 9), round(p[1], 9)))
                trans_second_sorted = sorted(trans_second, key=lambda p: (round(p[0], 9), round(p[1], 9)))
                valid = True
                for (rx, ry), (sx, sy) in zip(rotated_sorted, trans_second_sorted):

                        break
