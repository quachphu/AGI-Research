To solve this problem, we need to determine the minimum cost for all jury members to be present in Metropolis for exactly k consecutive days and then return to their home cities. The solution involves efficiently processing flight schedules and using a combination of binary search and ternary search to find the optimal meeting window.

### Approach
1. **Input Processing and Grouping**: Read the input flights and group them into arrival flights (to Metropolis) and departure flights (from Metropolis) for each city.
2. **Preprocessing**: For each city, compute the minimum cost for arrival flights up to each day and the minimum cost for departure flights from each day onwards using prefix and suffix arrays.
3. **Determine Valid Meeting Window**: Calculate the earliest possible start day (S_min) and the latest possible start day (S_max) for the k-day meeting period.
4. **Ternary Search**: Use ternary search within the valid window [S_min, S_max] to find the start day that minimizes the total cost, considering the minimum arrival and departure costs for each city.

### Solution Code
```python
import sys
import bisect
from collections import defaultdict

def main():
    n, m, k = map(int, sys.stdin.readline().split())
    arrival = defaultdict(list)
    departure = defaultdict(list)
    for _ in range(m):
        d, f, t, c = map(int, sys.stdin.readline().split())
        if t == 0:
            arrival[f].append((d, c))
        elif f == 0:
            departure[t].append((d, c))
    
    arrival_data = {}
    departure_data = {}
    S_min_list = []
    S_max_list = []
    possible = True

    for i in range(1, n + 1):
        arr = arrival.get(i, [])
        if not arr:
            possible = False
            break
        arr.sort()
        days = [x[0] for x in arr]
        costs = [x[1] for x in arr]
        prefix_min = [costs[0]] * len(costs)
        for j in range(1, len(costs)):
            prefix_min[j] = min(prefix_min[j-1], costs[j])
        arrival_data[i] = (days, prefix_min)
        S_min_list.append(days[0] + 1)
        
        dep = departure.get(i, [])
        if not dep:
            possible = False
            break
        dep.sort()
        days_dep = [x[0] for x in dep]
        costs_dep = [x[1] for x in dep]
        suffix_min = [0] * len(costs_dep)
        suffix_min[-1] = costs_dep[-1]
        for j in range(len(costs_dep)-2, -1, -1):
            suffix_min[j] = min(costs_dep[j], suffix_min[j+1])
        departure_data[i] = (days_dep, suffix_min)
        S_max_list.append(days_dep[-1] - k)
    
    if not possible or not S_min_list or not S_max_list:
        print(-1)
        return
    
    S_min = max(S_min_list)
    S_max = min(S_max_list)
    if S_min > S_max:
        print(-1)
        return

    def compute_sum(S):
        total = 0
        for i in range(1, n + 1):
            days_arr, prefix_min = arrival_data[i]
            target = S - 1
            idx = bisect.bisect_right(days_arr, target) - 1
            if idx < 0:
                return float('inf')
            a_cost = prefix_min[idx]
            
            days_dep, suffix_min = departure_data[i]
            target_dep = S + k
            idx_dep = bisect.bisect_left(days_dep, target_dep)
            if idx_dep >= len(days_dep):
                return float('inf')
            d_cost = suffix_min[idx_dep]
            
            total += a_cost + d_cost
        return total

    left, right = S_min, S_max
    best = float('inf')
    for _ in range(100):
        if left > right:
            break
        mid1 = left + (right - left) // 3
        mid2 = right - (right - left) // 3
        s1 = compute_sum(mid1)
        s2 = compute_sum(mid2)
        if s1 < s2:
            right = mid2 - 1
            best = min(best, s1)
        else:
            left = mid1 + 1
            best = min(best, s2)
    
    for s in range(left, right + 1):
        current = compute_sum(s)
        if current < best:
            best = current
    
    print(best if best != float('inf') else -1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Input Processing**: Flights are read and grouped into arrival and departure lists for each city.
2. **Prefix and Suffix Arrays**: For each city, arrival flights are sorted by day, and a prefix array of minimum costs is computed. Similarly, departure flights are sorted, and a suffix array of minimum costs is computed.
3. **Valid Meeting Window**: The earliest possible start day (S_min) and latest possible start day (S_max) are determined based on the earliest arrival and latest departure flights.
4. **Cost Calculation**: For each candidate start day within the valid window, the total cost is computed using binary search to find the minimum arrival and departure costs for each city.
5. **Ternary Search**: The optimal start day is found using ternary search within the valid window, followed by a linear check of the remaining range to ensure the minimum cost is found.

This approach efficiently narrows down the possible start days and ensures the minimum cost is calculated using optimal flight combinations.
