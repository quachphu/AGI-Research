To solve this problem, we need to determine the number of standing warriors after each minute of battle, considering that warriors revive if all are killed during a minute. The solution involves efficiently tracking the cumulative arrows shot and using binary search to quickly determine the number of standing warriors.

### Approach
1. **Prefix Sum Calculation**: Compute the prefix sum array of the warriors' strengths. This helps in determining how many warriors can be killed with a given number of arrows.
2. **Cumulative Arrows Tracking**: Track the cumulative arrows shot up to each minute. If the arrows shot in a minute are enough to kill all warriors, they revive, and the count resets.
3. **Binary Search**: Use binary search on the prefix sum array to quickly determine how many warriors are alive after each minute. This reduces the complexity of each query to O(log n).

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n, q = map(int, input[ptr:ptr+2])
    ptr += 2
    a = list(map(int, input[ptr:ptr+n]))
    ptr += n
    k_list = list(map(int, input[ptr:ptr+q]))
    ptr += q

    # Compute prefix sums
    prefix_sum = []
    current_sum = 0
    for num in a:
        current_sum += num
        prefix_sum.append(current_sum)
    sum_a = prefix_sum[-1] if n > 0 else 0

    current_s = 0
    for k in k_list:
        required = sum_a - current_s
        if k >= required:
            current_s = 0
        else:
            current_s += k
        # Find the rightmost index where prefix_sum[i] <= current_s
        pos = bisect.bisect_right(prefix_sum, current_s)
        print(n - pos)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prefix Sum Array**: The prefix sum array is constructed to quickly determine the cumulative strength of warriors up to any point. This allows us to efficiently compute how many warriors can be killed with a given number of arrows.
2. **Cumulative Arrows Tracking**: For each minute, we track the cumulative arrows shot. If the arrows shot in a minute exceed the required arrows to kill all remaining warriors, they revive, resetting the count.
3. **Binary Search**: Using binary search on the prefix sum array, we determine the number of warriors alive by finding how many prefix sums are greater than the cumulative arrows shot. This allows each query to be processed in O(log n) time.

This approach efficiently handles up to the maximum constraints, ensuring optimal performance for both the number of warriors and the number of minutes.
