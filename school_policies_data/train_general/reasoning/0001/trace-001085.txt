To solve this problem, we need to determine the median of an array of non-negative integers. The median is defined as the middle element in the sorted array. If the number of elements (N) is even, the median is the (N/2)-th element in the sorted order, otherwise, it is the middle element when N is odd.

### Approach
1. **Input Reading**: Read the number of elements (N) and the array elements from the standard input.
2. **Sorting**: Sort the array to determine the order of elements.
3. **Determine Median**: 
   - If N is even, the median is the element at index (N/2 - 1) in the sorted array (0-based indexing).
   - If N is odd, the median is the element at index (N//2) in the sorted array (0-based indexing).

### Solution Code
```python
def find_median():
    n = int(input())
    arr = list(map(int, input().split()))
    arr.sort()
    if n % 2 == 0:
        print(arr[(n // 2) - 1])
    else:
        print(arr[n // 2])

find_median()
```

### Explanation
1. **Reading Input**: The function reads the input values using `input()`. The first value is the number of elements, and the second line contains the array elements.
2. **Sorting the Array**: The array is sorted using Python's built-in `sort()` method, which efficiently sorts the elements in ascending order.
3. **Calculating the Median**: 
   - For an even number of elements (N), the median is the element at the position (N/2 - 1) in the sorted array.
   - For an odd number of elements (N), the median is the element at the position (N//2) in the sorted array.

This approach ensures that we efficiently determine the median by leveraging sorting and direct index access, resulting in an overall time complexity of O(N log N) due to the sorting step, which is optimal for the given problem constraints.
