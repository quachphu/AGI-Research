### Approach
1. **Problem Analysis**:
   - The key insight is to consider the number of runs (consecutive blocks of the same color). Each run contributes to the number of adjacent pairs of the same color. For example, a run of length L contributes L-1 pairs.
   - The total number of adjacent pairs of the same color is given by N - R, where R is the number of runs. Thus, the problem reduces to finding the number of valid colorings with R runs such that N - R ≤ K, which simplifies to R ≥ N - K.

2. **Dynamic Programming and Combinatorics**:
   - Use combinatorics to count the number of ways to split N blocks into R runs, which is given by the binomial coefficient C(N-1, R-1).
   - For each run, the first block can be colored in M ways, and each subsequent run can be colored in M-1 ways (to ensure different colors from the previous run).

3. **Efficient Computation**:
   - Precompute factorials and inverse factorials modulo 998244353 to efficiently compute binomial coefficients.
   - Precompute powers of (M-1) modulo 998244353.
   - Use prefix sums to efficiently calculate the sum of terms over the required range.

MOD = 998244353

def main():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    M = int(input[1])
    K = int(input[2])
    
    if M == 1:
        if (N - 1) <= K:
            print(1)
        else:
            print(0)
        return
    
    s_min = (N - K) - 1
    s_max = N - 1
    
    max_fact = N - 1
    fact = [1] * (max_fact + 1)
    for i in range(1, max_fact + 1):
        fact[i] = fact[i-1] * i % MOD
    
    inv_fact = [1] * (max_fact + 1)
    inv_fact[max_fact] = pow(fact[max_fact], MOD-2, MOD)
    for i in range(max_fact - 1, -1, -1):
        inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD
    
    pow_m_minus_1 = [1] * (s_max + 1)
    base = M - 1
    for i in range(1, s_max + 1):
        pow_m_minus_1[i] = pow_m_minus_1[i-1] * base % MOD
    
    prefix = [0] * (s_max + 2)
    for s in range(0, s_max + 1):
        if s > (N - 1):
            comb = 0
        else:
            comb = fact[N-1] * inv_fact[s] % MOD
            comb = comb * inv_fact[(N-1) - s] % MOD
        term = comb * pow_m_minus_1[s] % MOD
        prefix[s+1] = (prefix[s] + term) % MOD
