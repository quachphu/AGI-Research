To solve this problem, we need to determine the minimum number of characters remaining after changing one character's color in a sequence such that all consecutive sequences of four or more characters of the same color are removed, including any chain reactions caused by the removal.

### Approach
1. **Precompute Runs**: Identify consecutive sequences (runs) of characters in the initial sequence. Each run is represented by its value, start index, end index, and length.
2. **Run Mapping**: Create a mapping from each position in the sequence to the run it belongs to.
3. **Left and Right Counts**: For each position and possible color, precompute the number of consecutive characters to the left and right that would form a run if the character at that position is changed.
4. **Simulate Changes**: For each possible position and color change, simulate the removal of runs and any subsequent chain reactions. Track the minimum remaining characters after all possible removals.

### Solution Code
```python
import sys

def process_dataset(N, array):
    if N == 0:
        return None
    
    # Precompute runs
    runs = []
    if N == 0:
        return []
    current_value = array[1]
    current_start = 1
    current_length = 1
    for i in range(2, N + 1):
        if array[i] == current_value:
            current_length += 1
        else:
            runs.append((current_value, current_start, i - 1, current_length))
            current_value = array[i]
            current_start = i
            current_length = 1
    runs.append((current_value, current_start, N, current_length))
    
    # Precompute run_map
    run_map = [0] * (N + 2)  # 1-based
    run_index = 0
    if runs:
        current_run = runs[run_index]
        for i in range(1, N + 1):
            if i > current_run[2]:
                run_index += 1
                if run_index >= len(runs):
                    current_run = (0, 0, 0, 0)  # dummy
                else:
                    current_run = runs[run_index]
            run_map[i] = run_index
    
    # Precompute left_counts and right_counts for each color
    left_counts = {1: [0]*(N+2), 2:[0]*(N+2), 3:[0]*(N+2)}
    right_counts = {1: [0]*(N+2), 2:[0]*(N+2), 3:[0]*(N+2)}
    
    for c in [1, 2, 3]:
        # Compute left counts
        left_counts_c = left_counts[c]
        for i in range(2, N + 1):
            if array[i-1] == c:
                left_counts_c[i] = left_counts_c[i-1] + 1
            else:
                left_counts_c[i] = 0
        
        # Compute right counts
        right_counts_c = right_counts[c]
        for i in range(N-1, 0, -1):
            if array[i+1] == c:
                right_counts_c[i] = right_counts_c[i+1] + 1
            else:
                right_counts_c[i] = 0
    
    min_remaining = N  # Initialize with maximum possible
    
    for i in range(1, N + 1):
        original_color = array[i]
        for new_color in [1, 2, 3]:
            if new_color == original_color:
                continue
            # Compute L and R
            left_count = left_counts[new_color][i]
            right_count = right_counts[new_color][i]
            L = i - left_count
            R = i + right_count
            initial_length = R - L + 1
            if initial_length < 4:
                current_remaining = N
            else:
                total_removed = initial_length
                current_left_end = L - 1
                current_right_start = R + 1
                while True:
                    # Get trailing run of current_left_end
                    trailing_run = None
                    if current_left_end >= 1:
                        run_idx = run_map[current_left_end]
                        if run_idx < len(runs):
                            trailing_run = runs[run_idx]
                    # Get leading run of current_right_start
                    leading_run = None
                    if current_right_start <= N:
                        run_idx = run_map[current_right_start]
                        if run_idx < len(runs):
                            leading_run = runs[run_idx]
                    # Check if they can be merged
                    if trailing_run and leading_run and trailing_run[0] == leading_run[0]:
                        combined_length = trailing_run[3] + leading_run[3]
                        if combined_length >= 4:
                            total_removed += trailing_run[3] + leading_run[3]
                            # Update current_left_end and current_right_start
                            current_left_end = trailing_run[1] - 1
                            current_right_start = leading_run[2] + 1
                        else:
                            break
                    else:
                        break
                current_remaining = N - total_removed
            if current_remaining < min_remaining:
                min_remaining = current_remaining
    
    return min_remaining

def main():
    for line in sys.stdin:
        N = int(line.strip())
        if N == 0:
            break
        array = [0]  # 1-based indexing
        for _ in range(N):
            num = int(sys.stdin.readline().strip())
            array.append(num)
        result = process_dataset(N, array)
        print(result)

if __name__ == "__main__":
    main()
```

1. **Precompute Runs**: Convert the sequence into runs of consecutive characters to efficiently track segments.
2. **Run Mapping**: Map each position to its corresponding run to quickly access run information.
3. **Left and Right Counts**: For each position and possible color, calculate how many consecutive characters to the left and right would form a run if the character is changed.
4. **Simulate Changes**: For each possible change, compute the initial run formed, then check for chain reactions by merging adjacent runs from the left and right parts of the removed segment. Track the minimum remaining characters after all possible removals.

This approach efficiently handles the problem constraints by leveraging precomputation and careful simulation of chain reactions, ensuring optimal performance even for large input sizes.
