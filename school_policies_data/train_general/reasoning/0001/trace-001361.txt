To solve this problem, we need to determine the number of cities connected to each city by both roads and railways. This involves analyzing the connectivity of cities using two separate networks (roads and railways) and then finding the intersection of these networks for each city.

### Approach
1. **Union-Find Data Structure**: We use the Union-Find (Disjoint Set Union, DSU) data structure to efficiently determine the connected components for both roads and railways. This structure helps in merging sets (union) and finding the root of a set (find) with path compression and union by rank optimizations.
2. **Compute Components**: For each network (roads and railways), compute the connected components using the Union-Find structure.
3. **Intersection of Components**: For each city, determine the root in both road and railway components. The number of cities that share the same pair of roots (road root, railway root) gives the required count for that city.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    K = int(input[ptr])
    ptr += 1
    L = int(input[ptr])
    ptr += 1

    parent_road = list(range(N + 1))
    rank_road = [1] * (N + 1)

    for _ in range(K):
        p = int(input[ptr])
        ptr += 1
        q = int(input[ptr])
        ptr += 1
        u = find(p, parent_road)
        v = find(q, parent_road)
        if u != v:
            if rank_road[u] < rank_road[v]:
                parent_road[u] = v
            else:
                parent_road[v] = u
                if rank_road[u] == rank_road[v]:
                    rank_road[u] += 1

    parent_rail = list(range(N + 1))
    rank_rail = [1] * (N + 1)

    for _ in range(L):
        r = int(input[ptr])
        ptr += 1
        s = int(input[ptr])
        ptr += 1
        u = find(r, parent_rail)
        v = find(s, parent_rail)
        if u != v:
            if rank_rail[u] < rank_rail[v]:
                parent_rail[u] = v
            else:
                parent_rail[v] = u
                if rank_rail[u] == rank_rail[v]:
                    rank_rail[u] += 1

    road_roots = [0] * (N + 1)
    rail_roots = [0] * (N + 1)
    for city in range(1, N + 1):
        road_roots[city] = find(city, parent_road)
        rail_roots[city] = find(city, parent_rail)

    counter = defaultdict(int)
    for city in range(1, N + 1):
        key = (road_roots[city], rail_roots[city])
        counter[key] += 1

    output = []
    for city in range(1, N + 1):
        key = (road_roots[city], rail_roots[city])
        output.append(str(counter[key]))

    print(' '.join(output))

def find(u, parent):
    while parent[u] != u:
        parent[u] = parent[parent[u]]
        u = parent[u]
    return u

if __name__ == '__main__':
    main()
```

4. **Finding Roots**: After processing all edges, the root of each city in both road and railway networks is determined.
5. **Counting Intersections**: Using a dictionary, we count how many cities share each pair of roots. This count is used to generate the output for each city.

This approach ensures that we efficiently determine the connected components and their intersections, leading to an optimal solution for the problem constraints.
