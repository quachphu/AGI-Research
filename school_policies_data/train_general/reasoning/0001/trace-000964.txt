To solve this problem, we need to maximize the sum of non-overlapping intervals of length `m` in a given sequence of integers. The solution involves dynamic programming (DP) to efficiently compute the maximum possible sum by considering each possible interval and updating the DP state accordingly.

### Approach
1. **Prefix Sum Calculation**: Compute the prefix sum array to quickly calculate the sum of any interval of length `m`.
2. **Sum of Intervals**: Precompute the sum of each possible interval of length `m` using the prefix sum array.
3. **Dynamic Programming**: Use a DP approach where `dp[j][e]` represents the maximum sum achievable by selecting `j` intervals up to the `e`-th element. Transition between states by either including the current interval or excluding it, ensuring non-overlapping intervals.

### Solution Code
```python
n, m, k = map(int, input().split())
p = list(map(int, input().split()))

prefix = [0] * (n + 1)
for i in range(n):
    prefix[i + 1] = prefix[i] + p[i]

sum_m = [0] * n
for e in range(n):
    if e >= m - 1:
        s = e - m + 1
        sum_m[e] = prefix[e + 1] - prefix[s]

prev = [0] * n  # j=0 case, sum is 0

for j in range(1, k + 1):
    current = [-float('inf')] * n
    for e in range(n):
        if e > 0:
            current[e] = current[e - 1]
        else:
            current[e] = -float('inf')  # Initialize first element

        if e >= m - 1:
            s = e - m + 1
            prev_e = s - 1
            if prev_e >= 0:
                candidate = prev[prev_e] + sum_m[e]
                if candidate > current[e]:
                    current[e] = candidate
            else:
                # Handle the case where previous is j-1=0 and prev_e = -1
                if j == 1:
                    candidate = sum_m[e]
                    if candidate > current[e]:
                        current[e] = candidate
    prev = current.copy()

print(prev[-1] if prev[-1] != -float('inf') else 0)
```

### Explanation
1. **Prefix Sum Calculation**: The prefix sum array is constructed to allow quick sum calculations of any subarray. This helps in efficiently determining the sum of any interval of length `m`.
2. **Sum of Intervals**: For each possible end index `e`, compute the sum of the interval starting from `e - m + 1` to `e` using the prefix sum array.
3. **Dynamic Programming**: The DP array is updated iteratively for each number of intervals from 1 to `k`. For each position `e`, the maximum sum is determined by either including the interval ending at `e` (if valid) or excluding it and taking the maximum sum from the previous position.

This approach ensures that we efficiently explore all possible valid intervals while maintaining non-overlapping constraints, leading to an optimal solution in O(n * k) time complexity.
