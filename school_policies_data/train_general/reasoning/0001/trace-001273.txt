To solve this problem, we need to count the number of subrectangles of size k consisting only of ones in a matrix formed by multiplying elements from two binary arrays. The key insight is that the matrix can be decomposed into runs of consecutive ones from the input arrays, and we can leverage these runs to efficiently compute the desired count.

### Approach
1. **Matrix Decomposition**: The matrix is formed by multiplying elements from two arrays, `a` (rows) and `b` (columns). Each cell in the matrix is 1 only if the corresponding elements in both `a` and `b` are 1. Thus, the 1s in the matrix form rectangles determined by runs of consecutive 1s in `a` and `b`.

2. **Run Lengths**: For each array, compute the lengths of consecutive runs of 1s. These runs help in determining possible subrectangle dimensions.

3. **Divisors of k**: Enumerate all pairs of divisors (x, y) such that x * y = k. Each pair (x, y) represents possible dimensions of subrectangles (rows x columns) in the matrix.

4. **Efficient Counting**: For each divisor pair (x, y), compute the number of runs of length x in `a` and runs of length y in `b` using binary search and prefix sums for efficiency. The product of these counts gives the number of valid subrectangles for that pair.

### Solution Code
```python
import sys
import math

def main():
    n, m, k = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    b = list(map(int, sys.stdin.readline().split()))
    
    # Function to get consecutive runs of 1s in an array
    def get_runs(arr):
        runs = []
        current = 0
        for num in arr:
            if num == 1:
                current += 1
            else:
                if current > 0:
                    runs.append(current)
                    current = 0
        if current > 0:
            runs.append(current)
        return runs
    
    runs_a = get_runs(a)
    runs_b = get_runs(b)
    
    # Sort the runs to facilitate binary search
    runs_a.sort()
    runs_b.sort()
    
    # Compute prefix sums for runs_a and runs_b
    prefix_a = [0]
    for l in runs_a:
        prefix_a.append(prefix_a[-1] + l)
    
    prefix_b = [0]
    for l in runs_b:
        prefix_b.append(prefix_b[-1] + l)
    
    # Function to compute the count for a given x and runs
    def compute_count(runs_sorted, prefix_sum, x):
        left = 0
        right = len(runs_sorted)
        while left < right:
            mid = (left + right) // 2
            if runs_sorted[mid] >= x:
                right = mid
            else:
                left = mid + 1
        index = left
        cnt_ge = len(runs_sorted) - index
        if cnt_ge == 0:
            return 0
        sum_L = prefix_sum[-1] - prefix_sum[index]
        return sum_L - x * cnt_ge + cnt_ge
    
    # Generate all possible (x, y) pairs where x * y = k
    pairs = set()
    for x in range(1, int(math.isqrt(k)) + 1):
        if k % x == 0:
            y = k // x
            pairs.add((x, y))
            pairs.add((y, x))
    
    total = 0
    for x, y in pairs:
        cnt_a = compute_count(runs_a, prefix_a, x)
        cnt_b = compute_count(runs_b, prefix_b, y)
        total += cnt_a * cnt_b
    
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Run Length Calculation**: The function `get_runs` processes each array to extract lengths of consecutive 1s. This helps in understanding the structure of the matrix.

2. **Prefix Sums and Binary Search**: By sorting the run lengths and using prefix sums, we efficiently compute the number of valid subrectangles for any given dimension using binary search. This reduces the complexity from O(n^2) to O(n log n).

3. **Divisor Pairs**: By enumerating all divisor pairs of k, we ensure we consider all possible subrectangle dimensions. Each pair is checked for valid contributions from both arrays, and their product is summed to get the total count.

This approach efficiently handles large input sizes by leveraging mathematical properties and efficient data structures, ensuring the solution is both optimal and scalable.
