To solve this problem, we need to determine how many apples Arcady can collect from the first inflorescence of a peculiar apple tree. The apples roll down from their initial positions to the base of the tree, and if two apples meet at the same inflorescence at the same time, they annihilate each other. The solution involves calculating the number of apples that survive the annihilation process and reach the first inflorescence.

### Approach
1. **Tree Structure and Depth Calculation**: Each inflorescence (except the first) has a parent inflorescence. The depth of an inflorescence is the number of steps required for an apple to roll down to the first inflorescence. We compute the depth for each inflorescence starting from the root (first inflorescence).

2. **Count Nodes by Depth**: For each depth, count how many inflorescences (nodes) exist at that depth. This helps us determine how many apples start at each depth.

3. **Survival Check Using Parity**: Apples at the same depth will arrive at the first inflorescence at the same time. The number of apples that survive annihilation at each depth is determined by the parity (even or odd) of the count of nodes at that depth. If the count is even, all apples annihilate; if odd, one apple survives.

4. **Summing Results**: The result is the sum of the parities of counts for all depths (excluding depth 0, which is the first inflorescence itself) plus 1 for the apple initially at the first inflorescence.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n = int(sys.stdin.readline())
    if n == 1:
        print(1)
        return
    p = list(map(int, sys.stdin.readline().split()))
    depth = [0] * (n + 1)  # depth[1] is 0
    depth_counts = defaultdict(int)
    depth_counts[0] = 1  # node 1's depth
    for i in range(2, n + 1):
        parent = p[i - 2]  # p is 0-based list for p2..pn
        depth[i] = depth[parent] + 1
        depth_counts[depth[i]] += 1
    
    total = 0
    for d in depth_counts:
        if d == 0:
            continue
        total += depth_counts[d] % 2
    print(total + 1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of the number of inflorescences and their parent relationships.
2. **Depth Calculation**: Using a loop, we calculate the depth of each inflorescence starting from the second one (since the first is the root).
3. **Counting Nodes by Depth**: We use a dictionary to count how many nodes exist at each depth.
4. **Parity Check**: For each depth (excluding the root's depth), we check if the count of nodes is odd or even. The parity of this count determines how many apples survive annihilation.
5. **Result Calculation**: The total number of surviving apples is the sum of the parities of all depths (excluding depth 0) plus 1 for the apple initially at the root.

This approach efficiently computes the result in linear time, making it suitable for large input sizes up to 100,000 nodes.
