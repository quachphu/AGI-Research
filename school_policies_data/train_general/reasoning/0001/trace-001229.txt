To solve this problem, we need to calculate the sum of Hamming distances between a binary string `a` and all contiguous substrings of another binary string `b` that have the same length as `a`. The Hamming distance between two strings of equal length is the sum of the absolute differences of their corresponding characters.

### Approach
1. **Problem Analysis**: The Hamming distance between two strings is determined by comparing each corresponding character. For large input sizes, a direct comparison of all substrings would be inefficient. Instead, we can optimize by analyzing each position in `a` independently and leveraging prefix sums to count differences efficiently.

2. **Key Insight**: For each position `i` in `a`, we need to count how many times `a[i]` differs from the corresponding positions in all valid substrings of `b`. This can be done by considering the number of `1`s in specific segments of `b` using a prefix sum array.

3. **Algorithm**:
   - Compute a prefix sum array for `b` to quickly determine the number of `1`s in any segment.
   - For each position `i` in `a`, determine the range of positions in `b` that need to be compared using the prefix sum array.
   - Calculate the contribution of each position `i` in `a` to the total Hamming distance based on whether `a[i]` is `0` or `1`.

### Solution Code
```python
def main():
    import sys
    a = sys.stdin.readline().strip()
    b = sys.stdin.readline().strip()
    m = len(a)
    n = len(b)
    if m > n:
        print(0)
        return
    # Compute prefix sum of 1's in b
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i+1] = prefix[i] + (1 if b[i] == '1' else 0)
    total = 0
    for i in range(m):
        start = i
        end = i + (n - m)
        ones = prefix[end + 1] - prefix[start]
        if a[i] == '0':
            total += ones
        else:
            total += (end - start + 1) - ones
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prefix Sum Array**: This array helps in efficiently calculating the number of `1`s in any segment of `b`. The value at `prefix[i]` represents the number of `1`s from the start of `b` up to index `i-1`.

2. **Range Calculation**: For each position `i` in `a`, the corresponding segment in `b` starts at `i` and ends at `i + (n - m)`, where `n` is the length of `b` and `m` is the length of `a`.

3. **Contribution Calculation**: Depending on whether `a[i]` is `0` or `1`, the contribution to the total Hamming distance is either the number of `1`s or `0`s in the corresponding segment of `b`, respectively.

This approach ensures that we efficiently compute the result in linear time, making it suitable for large input sizes up to 200,000 characters.
