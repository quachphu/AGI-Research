To solve this problem, we need to determine the absolute difference between the number of cities and the number of villages after a series of mergers. A city is formed when two or more villages merge, while a village remains as is if it does not merge with any other village.

### Approach
1. **Union-Find Data Structure**: We use the Union-Find (Disjoint Set Union, DSU) data structure to efficiently manage the merging of villages. This helps in grouping villages into connected components.
2. **Union Operation**: For each pair of villages provided in the input, we merge them using the union operation. This operation ensures that each connected component (city) is tracked correctly.
3. **Component Analysis**: After processing all mergers, we analyze each connected component to determine if it is a city (size ≥ 2) or a village (size = 1).
4. **Count Calculation**: We count the number of cities and villages based on the component sizes and compute the absolute difference between these counts.

### Solution Code
```python
def main():
    import sys
    data = sys.stdin.read().split()
    ptr = 0
    n = int(data[ptr])
    ptr += 1
    m = int(data[ptr])
    ptr += 1

    parent = list(range(n + 1))
    size = [1] * (n + 1)

    def find(u):
        while parent[u] != u:
            parent[u] = parent[parent[u]]
            u = parent[u]
        return u

    def union(u, v):
        u_root = find(u)
        v_root = find(v)
        if u_root == v_root:
            return
        if size[u_root] < size[v_root]:
            u_root, v_root = v_root, u_root
        parent[v_root] = u_root
        size[u_root] += size[v_root]

    for _ in range(m):
        a = int(data[ptr])
        ptr += 1
        b = int(data[ptr])
        ptr += 1
        union(a, b)

    roots = set()
    for i in range(1, n + 1):
        roots.add(find(i))

    city = 0
    village = 0
    for r in roots:
        if size[r] >= 2:
            city += 1
        else:
            village += 1

    print(abs(city - village))

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into tokens for efficient processing.
2. **Union-Find Initialization**: Arrays `parent` and `size` are initialized where each village is initially its own parent and has a size of 1.
3. **Find and Union Operations**: The `find` function uses path compression for efficiency, and the `union` function merges two sets by size to keep the tree balanced.
4. **Processing Mergers**: Each merger pair is processed to update the Union-Find structure.
5. **Component Identification**: After all mergers, we determine the root of each village and classify components as cities or villages based on their size.
6. **Result Calculation**: The counts of cities and villages are used to compute the absolute difference, which is then printed.

This approach ensures efficient handling of mergers and accurate classification of villages and cities, leading to the correct solution.
