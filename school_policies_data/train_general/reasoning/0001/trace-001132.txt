To solve this problem, we need to modify a given string by converting the K-th character to lowercase. The solution involves reading the input values, adjusting for 1-based indexing, and efficiently transforming the specified character.

### Approach
1. **Reading Input**: The input consists of two lines. The first line contains integers N (length of the string) and K (the 1-based index of the character to convert). The second line contains the string S.
2. **String Conversion**: Convert the string into a list of characters to allow modification since strings in Python are immutable.
3. **Index Adjustment**: Adjust the 1-based index K to a 0-based index by subtracting 1.
4. **Character Modification**: Convert the K-th character (now 0-based) to lowercase.
5. **Output the Result**: Join the modified list back into a string and print it.

### Solution Code
```python
def main():
    n, k = map(int, input().split())
    s = input().strip()
    s_list = list(s)
    s_list[k-1] = s_list[k-1].lower()
    print(''.join(s_list))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The first line of input is split into integers N and K. The second line is read as the string S.
2. **List Conversion**: The string S is converted into a list of characters to allow in-place modification.
3. **Adjusting Index**: Since K is 1-based, we subtract 1 to get the correct 0-based index in the list.
4. **Lowercase Conversion**: The character at the adjusted index is converted to lowercase using the `lower()` method.
5. **Result Construction**: The list of characters is joined back into a string and printed as the result.

This approach ensures that we efficiently and correctly modify the specified character in the string, adhering to the problem constraints and requirements.
