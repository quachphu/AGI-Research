To solve this problem, we need to determine if Takahashi can reach Button 2 starting from Button 1 using the minimum number of presses on a gym machine. If it's impossible, we should return -1.

### Approach
1. **Problem Analysis**: The problem can be modeled as a graph traversal where each button press moves us to a new button based on the given transitions. The key challenge is to detect cycles to avoid infinite loops and determine the minimum steps to reach Button 2.
2. **Cycle Detection**: Using a set to track visited buttons helps detect cycles. If we revisit a button, it indicates a cycle, making it impossible to reach Button 2.
3. **Simulation**: We simulate the button presses starting from Button 1. For each press, we move to the next button as specified. If we reach Button 2, we return the count of presses. If we encounter a cycle, we return -1.

### Solution Code
```python
n = int(input())
a = [0]  # a[0] is unused to make the list 1-based
for _ in range(n):
    a.append(int(input()))

current = 1
steps = 0
visited = set()

while True:
    if current == 2:
        print(steps)
        exit()
    if current in visited:
        print(-1)
        exit()
    visited.add(current)
    current = a[current]
    steps += 1
```

### Explanation
1. **Input Reading**: The input is read and stored in a list `a` where `a[i]` represents the button to move to when Button `i` is pressed.
2. **Initialization**: Start at Button 1 with 0 steps taken.
3. **Loop Until Termination**:
   - If the current button is 2, print the number of steps and exit.
   - If the current button has been visited before (cycle detected), print -1 and exit.
   - Add the current button to the visited set.
   - Move to the next button as specified by the current button's transition and increment the step count.

This approach efficiently tracks the path and detects cycles, ensuring the solution runs in O(N) time complexity, which is optimal for the problem constraints.
