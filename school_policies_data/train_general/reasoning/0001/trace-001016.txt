The approach involves reverse-engineering the possible values of \( X1 \) and \( X0 \) from \( X2 \) by considering all possible prime factors and their multiples.

### Approach
1. **Prime Factorization**: Identify all prime factors of \( X2 \) since each move must use a prime number.
2. **Determine Possible \( X1 \) Values**: For each prime factor \( p2 \) of \( X2 \), compute the range of possible values for \( X1 \) such that \( X2 \) is the smallest multiple of \( p2 \) greater than or equal to \( X1 \).
3. **Check Composite \( X1 \)**: For each valid \( X1 \), check if it is a composite number (since primes cannot be formed by multiplying smaller primes).
4. **Determine Possible \( X0 \) Values**: For each composite \( X1 \), find its prime factors \( p1 \) and compute the smallest possible \( X0 \) such that \( X1 \) is the smallest multiple of \( p1 \) greater than or equal to \( X0 \).

import sys

def main():
    max_n = 10**6
    spf = list(range(max_n + 1))  # Smallest Prime Factor array

    # Sieve of Eratosthenes to fill the SPF array
    for i in range(2, int(max_n**0.5) + 1):
        if spf[i] == i:  # i is a prime
            for j in range(i * i, max_n + 1, i):
                if spf[j] == j:
                    spf[j] = i

    X2 = int(sys.stdin.readline())

    def get_prime_factors(n):
        factors = set()
        if n == 1:
            return factors
        while n != 1:
            p = spf[n]
            factors.add(p)
            while n % p == 0:
                n = n // p
        return factors

    p2_list = get_prime_factors(X2)
    min_X0 = float('inf')

    for p2 in p2_list:
        X1_low = X2 - p2 + 1
        X1_high = X2

            if X1 < 2:
                continue
            if spf[X1] == X1:  # X1 is prime
                continue

            p1_set = get_prime_factors(X1)
            current_min = float('inf')
            for p1 in p1_set:
                candidate = max(p1 + 1, X1 - p1 + 1)
                if candidate < current_min:
                    current_min = candidate
            if current_min < min_X0:
                min_X0 = current_min

    print(min_X0)
