To solve this problem, we need to convert a cell number from a column-wise numbering system to a row-wise numbering system in a grid. The key challenge is to determine the cell's position in the grid based on the column-wise numbering and then compute its corresponding number in the row-wise numbering.

### Approach
1. **Understand the Numbering Systems**:
   - **Column-wise**: Cells are numbered from top to bottom in each column, moving left to right across columns.
   - **Row-wise**: Cells are numbered from left to right in each row, moving top to bottom down the rows.

2. **Determine Column and Row in Column-wise System**:
   - Given a number `x` in the column-wise system, compute the column `j` and row `i` using integer division and modulo operations.
   - Column `j` is calculated as `(x - 1) // n + 1`, where `n` is the number of rows.
   - Row `i` is derived as `x - (j - 1) * n`.

3. **Convert to Row-wise Number**:
   - Once the position `(i, j)` in the grid is known, convert it to the row-wise number using the formula `(i - 1) * m + j`, where `m` is the number of columns.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    idx = 1
    for _ in range(t):
        n = int(input[idx])
        m = int(input[idx+1])
        x = int(input[idx+2])
        idx += 3
        j = (x - 1) // n + 1
        i = x - (j - 1) * n
        ans = (i - 1) * m + j
        print(ans)

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read all at once for efficiency, especially given the potentially large number of test cases.
2. **Column Calculation**: For each test case, compute the column `j` using integer division to determine how many full columns fit into `x`.
3. **Row Calculation**: Determine the row `i` within the computed column using simple arithmetic.
4. **Row-wise Conversion**: Convert the grid position `(i, j)` to the row-wise number using the formula derived from the problem's requirements.

This approach efficiently handles the constraints and ensures that even the largest values (up to \(10^{18}\)) are processed correctly using Python's native integer type, which supports arbitrary precision.
