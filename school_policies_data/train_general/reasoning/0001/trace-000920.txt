To solve this problem, we need to determine if a given triad of musical notes forms a major, minor, or strange chord based on the distances between the notes in the musical scale. The solution involves checking all permutations of the given notes to see if they fit the criteria for major or minor triads.

### Approach
1. **Mapping Notes to Indices**: Each musical note is mapped to an index in a cyclic sequence of 12 notes. This helps in calculating the distances between notes.
2. **Permutations**: Since the triad is an unordered set, we generate all permutations of the three given notes to check each possible ordering.
3. **Distance Calculation**: For each permutation, we calculate the distances between consecutive notes. A major triad requires distances of 4 and 3 semitones, while a minor triad requires distances of 3 and 4 semitones.
4. **Check Conditions**: If any permutation meets the criteria for a major or minor triad, we output the respective result. If none do, the triad is classified as strange.

### Solution Code
```python
import sys
from itertools import permutations

def main():
    note_order = ['C', 'C#', 'D', 'D#', 'E', 'F', 'F#', 'G', 'G#', 'A', 'B', 'H']
    note_to_index = {note: idx for idx, note in enumerate(note_order)}
    input_notes = sys.stdin.read().split()
    indices = [note_to_index[note] for note in input_notes]
    
    for perm in permutations(indices):
        x, y, z = perm
        d1 = (y - x) % 12
        d2 = (z - y) % 12
        if d1 == 4 and d2 == 3:
            print("major")
            return
        if d1 == 3 and d2 == 4:
            print("minor")
            return
    print("strange")

main()
```

### Explanation
1. **Mapping Notes**: The notes are mapped to indices from 0 to 11 to facilitate arithmetic operations.
2. **Generating Permutations**: Using permutations from itertools, we generate all possible orderings of the three notes to check each possible sequence.
3. **Calculating Distances**: For each permutation, the distances between consecutive notes are calculated using modulo arithmetic to handle the cyclic nature of the musical scale.
4. **Checking Triad Type**: Each permutation is checked against the criteria for major and minor triads. If a permutation meets either criteria, the result is printed immediately. If no permutation meets the criteria, the triad is classified as strange.

This approach ensures that all possible orderings of the notes are considered, making the solution both comprehensive and efficient given the constraints.
