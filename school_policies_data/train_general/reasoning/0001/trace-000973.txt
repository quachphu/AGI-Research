To solve this problem, we need to determine the order in which burger fans receive their orders based on their order times and processing durations. The key is to sort the orders by their finish times, and in case of ties, by their original order numbers.

### Approach
1. **Read Input**: First, read the number of orders, followed by each order's time and duration.
2. **Calculate Finish Times**: For each order, compute the finish time as the sum of the order time and the processing duration.
3. **Store Orders with Indices**: Store each order along with its original index (1-based) in a list.
4. **Sort Orders**: Sort the list of orders primarily by their finish times. If two orders have the same finish time, sort them by their original indices to ensure the smaller index comes first.
5. **Output the Result**: Extract the original indices from the sorted list and print them in the required format.

### Solution Code
```python
n = int(input())
orders = []
for i in range(n):
    ti, di = map(int, input().split())
    finish_time = ti + di
    orders.append((finish_time, i + 1))

orders.sort(key=lambda x: (x[0], x[1]))
result = [str(order[1]) for order in orders]
print(' '.join(result))
```

### Explanation
1. **Reading Input**: The code starts by reading the number of orders, `n`, and then processes each subsequent line to get the order time `ti` and processing duration `di`.
2. **Calculating Finish Times**: For each order, the finish time is calculated as `ti + di`.
3. **Storing Orders**: Each order is stored as a tuple `(finish_time, original_index)` in a list.
4. **Sorting**: The list of orders is sorted using a lambda function that sorts by `finish_time` first and `original_index` second to handle ties.
5. **Generating Output**: The sorted list is processed to extract the original indices, which are then printed as a space-separated string.

This approach ensures that the orders are processed efficiently and correctly, adhering to the problem constraints and requirements.
