To solve this problem, we need to determine the winner of a rock-paper-scissors game among three players based on their gestures. The winner is the player whose gesture beats the gestures of the other two players. If no such player exists, the result is a tie, and we output "?".

### Approach
1. **Input Reading**: Read the gestures of the three players.
2. **Define Winning Rules**: Establish the rules for which gesture beats another using a dictionary.
3. **Check Each Player**: For each player, check if their gesture beats the gestures of the other two players.
4. **Determine the Winner**: Collect all players who meet the winning condition. If exactly one player meets the condition, they are the winner; otherwise, output "?".

### Solution Code
```python
def determine_winner():
    f = input().strip()
    m = input().strip()
    s = input().strip()
    
    beats = {'rock': 'scissors', 'scissors': 'paper', 'paper': 'rock'}
    candidates = []
    
    # Check Uncle Fyodor
    if m == beats[f] and s == beats[f]:
        candidates.append('F')
    # Check Matroskin
    if f == beats[m] and s == beats[m]:
        candidates.append('M')
    # Check Sharic
    if f == beats[s] and m == beats[s]:
        candidates.append('S')
    
    print(candidates[0] if len(candidates) == 1 else '?')

determine_winner()
```

### Explanation
1. **Input Reading**: The gestures of the three players (Uncle Fyodor, Matroskin, and Sharic) are read from standard input.
2. **Winning Rules**: A dictionary `beats` is used to map each gesture to the gesture it defeats. For example, 'rock' beats 'scissors'.
3. **Check Each Player**: For each player, we check if both other players' gestures are the ones that their own gesture beats. This is done by comparing each other player's gesture against the value in the `beats` dictionary corresponding to the current player's gesture.
4. **Determine the Winner**: If exactly one player's gesture beats both others, that player is declared the winner. If no player or more than one player meets the condition, the result is a tie, indicated by "?". 

This approach efficiently checks each player's potential to win and ensures the correct result is determined based on the given rules.
