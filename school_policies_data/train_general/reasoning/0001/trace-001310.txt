To solve this problem, we need to determine the minimum value of \( m = x + y + z \) given that \( x, y, z \) are non-negative integers satisfying \( x + y^2 + z^3 = e \). The approach involves iterating through possible values of \( z \) and \( y \) to find the optimal solution efficiently.

### Approach
1. **Understanding Constraints**: Given the equation \( x + y^2 + z^3 = e \), we need to find non-negative integers \( x, y, z \) such that \( x + y + z \) is minimized. 
2. **Iterating Over Possible Values**: 
   - **Z Values**: Since \( z^3 \) must be less than or equal to \( e \), the maximum possible value for \( z \) is the cube root of \( e \).
   - **Y Values**: For each \( z \), the remaining value \( e - z^3 \) is used to determine possible \( y \) values. Here, \( y^2 \) must be less than or equal to the remaining value.
3. **Calculate x**: For each valid pair of \( z \) and \( y \), compute \( x \) as \( e - z^3 - y^2 \). The sum \( x + y + z \) is then checked to see if it is the minimum found so far.

### Solution Code
```python
import sys

def compute_min_m(e):
    min_m = float('inf')
    z = 0
    while True:
        z_cubed = z ** 3
        if z_cubed > e:
            break
        remaining_e = e - z_cubed
        y = 0
        while True:
            y_squared = y ** 2
            if y_squared > remaining_e:
                break
            x = remaining_e - y_squared
            current_sum = x + y + z
            if current_sum < min_m:
                min_m = current_sum
            y += 1
        z += 1
    return min_m

for line in sys.stdin:
    line = line.strip()
    if not line:
        continue
    e = int(line)
    if e == 0:
        break
    print(compute_min_m(e))
```

1. **Reading Input**: The input is read line by line until a line with `0` is encountered, indicating the end of input.
2. **Cube Root Iteration**: For each value of \( e \), iterate over possible values of \( z \) starting from 0. For each \( z \), compute \( z^3 \) and check if it exceeds \( e \). If it does, break the loop as further values of \( z \) will not be valid.
3. **Square Root Iteration**: For each valid \( z \), compute the remaining value after subtracting \( z^3 \) from \( e \). Iterate over possible values of \( y \) starting from 0. For each \( y \), compute \( y^2 \) and check if it exceeds the remaining value. If it does, break the loop.
4. **Compute x and Check Minimum**: For each valid pair of \( z \) and \( y \), compute \( x \) and check if the sum \( x + y + z \) is the minimum found so far. Update the minimum value accordingly.

This approach efficiently narrows down the search space using mathematical constraints, ensuring that we find the optimal solution without unnecessary computations.
