To solve this problem, we need to determine the number of buildings that remain undestroyed after all bombs explode simultaneously. Each bomb destroys its own building and adjacent buildings. The solution involves tracking which buildings are destroyed and then counting the remaining ones.

### Approach
1. **Input Reading**: Read the number of test cases. For each test case, read the number of buildings and the string representing bomb placements.
2. **Tracking Destroyed Buildings**: Use a set to keep track of all destroyed buildings. For each bomb found in the string, mark its position and its adjacent positions as destroyed.
3. **Boundary Checks**: Ensure that when processing adjacent buildings, we do not go out of bounds (i.e., indices are within the valid range of building numbers).
4. **Count Remaining Buildings**: Subtract the number of destroyed buildings from the total number of buildings to get the count of undestroyed buildings.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        S = input[ptr]
        ptr += 1
        destroyed = set()
        for i in range(N):
            if S[i] == '1':
                destroyed.add(i)
                if i - 1 >= 0:
                    destroyed.add(i - 1)
                if i + 1 < N:
                    destroyed.add(i + 1)
        print(N - len(destroyed))

main()
```

### Explanation
- **Reading Input**: The input is read in one go and split into a list for efficient processing. The number of test cases is read first.
- **Processing Each Test Case**: For each test case, the number of buildings and the bomb placement string are read.
- **Marking Destroyed Buildings**: For each bomb found in the string, the corresponding building and its adjacent buildings are marked as destroyed using a set to avoid duplicate entries.
- **Boundary Handling**: When marking adjacent buildings, checks are performed to ensure indices are within valid bounds.
- **Calculating Result**: The number of undestroyed buildings is calculated by subtracting the size of the destroyed set from the total number of buildings.

This approach efficiently tracks destroyed buildings using a set, ensuring each building is only counted once even if multiple bombs affect it. The solution handles edge cases such as bombs at the start or end of the building row correctly.
