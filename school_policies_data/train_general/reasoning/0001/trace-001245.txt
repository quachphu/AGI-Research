To solve this problem, we need to calculate the score earned by Dhoni based on the results of a series of coin tosses. Each 'H' (heads) in the string increases Dhoni's score based on the number of consecutive 'H's since the last 'T' (tails). The goal is to efficiently compute this score for multiple test cases.

### Approach
1. **Input Reading**: Read the number of test cases and the subsequent strings representing the toss results for each test case.
2. **Iterate Through Each Toss**: For each test case string, iterate through each character to determine the score.
3. **Track Consecutive Heads**: Maintain a counter to track the number of consecutive 'H's. Each 'H' increases this counter and adds its current value to the total score. A 'T' resets this counter to zero.
4. **Efficiency**: The solution efficiently processes each character in linear time, making it suitable for large input sizes up to 10^6 characters.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        s = sys.stdin.readline().strip()
        current_streak = 0
        total_score = 0
        for c in s:
            if c == 'H':
                current_streak += 1
                total_score += current_streak
            else:
                current_streak = 0
        print(total_score)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The number of test cases is read first. Each subsequent line contains the toss results for a test case.
- **Processing Each Toss**: For each toss result string, we initialize `current_streak` to track consecutive 'H's and `total_score` to accumulate the score.
- **Updating Score**: For each 'H', `current_streak` is incremented and its value is added to `total_score`. For each 'T', `current_streak` is reset to zero.
- **Output**: After processing each string, the total score for that test case is printed.

This approach ensures that each character is processed in constant time, leading to an overall time complexity of O(n) per test case, where n is the length of the string. This efficiency makes the solution suitable even for the upper constraint limits.
