To solve this problem, we need to efficiently handle a string of lowercase letters and dots, and process multiple queries that modify the string. After each modification, we need to count the number of consecutive dots ('..') in the string. The challenge is to perform these operations efficiently to handle large input sizes.

### Approach
1. **Initial Count Calculation**: First, we compute the initial count of consecutive dots in the given string. This is done by iterating through the string once and checking each pair of adjacent characters.
2. **Efficient Query Processing**: For each query, we update the character at the specified position and adjust the count of consecutive dots. This adjustment is done by:
   - Checking the neighbors of the updated position before the change to subtract any existing consecutive dots involving the original character.
   - Updating the character and then checking the neighbors again to add any new consecutive dots formed by the new character.

This approach ensures that each query is processed in constant time, O(1), making the solution efficient even for large inputs.

### Solution Code
```python
import sys

def main():
    L, N = map(int, sys.stdin.readline().split())
    s = list(sys.stdin.readline().strip())
    
    # Calculate initial count of consecutive dots
    count = 0
    for i in range(L - 1):
        if s[i] == '.' and s[i+1] == '.':
            count += 1
    
    for _ in range(N):
        parts = sys.stdin.readline().split()
        k = int(parts[0])
        p = parts[1]
        i = k - 1  # Convert to 0-based index
        
        original = s[i]
        # Remove contributions from the original character
        if original == '.':
            # Check left neighbor
            if i > 0 and s[i-1] == '.':
                count -= 1
            # Check right neighbor
            if i < L - 1 and s[i+1] == '.':
                count -= 1
        
        # Update the character
        s[i] = p
        
        # Add contributions from the new character
        if p == '.':
            # Check left neighbor
            if i > 0 and s[i-1] == '.':
                count += 1
            # Check right neighbor
            if i < L - 1 and s[i+1] == '.':
                count += 1
        
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using standard input functions. The first line contains the length of the string and the number of queries. The second line is the string itself, which is converted into a list for easy modification.
2. **Initial Count Calculation**: We iterate through the string once to count the initial number of consecutive dots.
3. **Processing Queries**: For each query:
   - Convert the 1-based index to a 0-based index.
   - Check and adjust the count based on the original character before changing it.
   - Update the character in the string.
   - Check and adjust the count based on the new character after the change.
   - Print the updated count after each query.

This method ensures that each query is processed efficiently in constant time, making the solution suitable for large inputs.
