### Approach
1. **Understand the Inputs**: The inputs include the number of test cases, followed by each test case containing three integers: overs completed (O), current run rate (R), and runs scored in the next over (S).
2. **Calculate Total Runs**: Using the current run rate and overs completed, compute the total runs scored before the next over. This is done by multiplying the overs (O) by the run rate (R).
3. **Update Runs and Overs**: Add the runs scored in the next over (S) to the total runs. Increment the overs by 1 to account for the new over.
4. **Compute New Run Rate**: The new run rate is obtained by dividing the updated total runs by the new total overs.
5. **Format the Output**: Ensure the result is formatted to two decimal places for precision.

### Solution Code
```python
def calculate_run_rate():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        O = int(input[idx])
        R = int(input[idx+1])
        S = int(input[idx+2])
        idx += 3
        total_runs = O * R + S
        new_overs = O + 1
        new_rr = total_runs / new_overs
        print("{0:.2f}".format(new_rr))
        
calculate_run_rate()
```

### Explanation
- **Reading Input**: The input is read all at once for efficiency, especially given the constraints. This helps in handling up to 1000 test cases efficiently.
- **Loop Through Test Cases**: For each test case, extract the values of O, R, and S.
- **Calculate Total Runs**: The total runs before the next over are calculated as `O * R`. Adding the runs from the next over (S) gives the updated total runs.
- **Compute New Overs**: The total overs are incremented by 1.
- **Calculate and Format Run Rate**: The new run rate is the total runs divided by the new overs, formatted to two decimal places using Python's string formatting.

This approach ensures that the solution is both efficient and precise, adhering to the problem constraints and requirements.
