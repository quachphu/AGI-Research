2. The population at year \( N \) can be derived from the populations of previous years using the recurrence relation: 
   \[
   \text{pop}(N) = \text{pop}(N-1) + \text{pop}(N-2) - \text{pop}(N-4)
   \]

def bacteria_population():
    import sys
    n = int(sys.stdin.readline())
    if n == 0:
        print(1)
    elif n == 1:

    elif n == 3:
