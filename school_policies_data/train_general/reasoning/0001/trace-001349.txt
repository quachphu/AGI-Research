To solve this problem, we need to form groups of students based on their shared fields of interest and determine the number of ways to pick students from each group for submitting progress reports. The solution involves using a Disjoint Set Union (DSU) to efficiently manage the groups and calculate the required combinations.

### Approach
1. **Union-Find Data Structure (DSU)**: We use this data structure to dynamically keep track of connected components (groups) as we process the input pairs. This helps in efficiently merging sets and finding the root of any element.
2. **Component Size Calculation**: After processing all pairs, we determine the size of each connected component. This is done by iterating through each node and checking if it is a root node (indicating the start of a component).
3. **Combination Calculation**: For each component, if the size is 1, there is only 1 way to pick a student. If the size is 2 or more, the number of ways to pick 2 students is calculated using the combination formula \( C(n, 2) = \frac{n(n-1)}{2} \).
4. **Modulo Arithmetic**: Since the result can be large, we take modulo \( 10^9 + 7 \) at each step to prevent overflow and ensure the result fits within standard integer limits.

### Solution Code
```python
class DSU:
    def __init__(self, size_limit):
        self.parent = list(range(size_limit + 1))  # 1-based indexing
        self.size = [1] * (size_limit + 1)
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # Path compression
        return self.parent[x]
    
    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return
        # Union by size: attach smaller tree to larger tree
        if self.size[x_root] < self.size[y_root]:
            x_root, y_root = y_root, x_root
        self.parent[y_root] = x_root
        self.size[x_root] += self.size[y_root]

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    MOD = 10**9 + 7
    for _ in range(t):
        n = int(input[ptr])
        k = int(input[ptr + 1])
        ptr += 2
        dsu = DSU(n)
        for __ in range(k):
            x = int(input[ptr])
            y = int(input[ptr + 1])
            ptr += 2
            dsu.union(x, y)
        # Collect component sizes
        component_sizes = []
        for i in range(1, n + 1):
            if dsu.parent[i] == i:
                component_sizes.append(dsu.size[i])
        # Calculate the product
        result = 1
        for s in component_sizes:
            if s >= 2:
                result = (result * (s * (s - 1) // 2)) % MOD
        print(result)

if __name__ == "__main__":
    main()
```

3. **Component Size Collection**: After processing all pairs, we iterate through each node to find root nodes, which represent the start of each component. The size of each component is stored in the DSU's size array.
4. **Result Calculation**: For each component size, we compute the number of ways to pick students and multiply these values together, taking modulo \( 10^9 + 7 \) at each step to ensure the result remains manageable.
