n, k = map(int, input().split())

A = list(map(int, input().split()))

prefix = [0]

for num in A:

    prefix.append(prefix[-1] + num)

heap = []

visited = set()

initial_l = 0

initial_r = n-1

initial_sum = prefix[initial_r + 1] - prefix[initial_l]

heapq.heappush(heap, (-initial_sum, initial_l, initial_r))

visited.add((initial_l, initial_r))

result = []

for _ in range(k):

    current = heapq.heappop(heap)

    sum_neg = current[0]

    l = current[1]

    r = current[2]

    current_sum = -sum_neg

    result.append(current_sum)

    # Generate left child: l+1, r

    if l + 1 <= r:

        new_l = l + 1

        new_r = r

        if (new_l, new_r) not in visited:

            new_sum = prefix[new_r +1] - prefix[new_l]

            heapq.heappush(heap, (-new_sum, new_l, new_r))

            visited.add((new_l, new_r))

    # Generate right child: l, r-1

    if l <= r-1:

        new_l = l

        new_r = r-1

        if (new_l, new_r) not in visited:

            new_sum = prefix[new_r +1] - prefix[new_l]

            heapq.heappush(heap, (-new_sum, new_l, new_r))

            visited.add((new_l, new_r))

print(' '.join(map(str, result)))

To solve this problem, we need to find the first K largest sums of all possible contiguous subarrays of a given array. Given the constraints, a brute-force approach is infeasible due to the high time and space complexity. Instead, we use a max-heap (priority queue) combined with a set to efficiently track and generate the required sums.

### Approach
1. **Prefix Sum Calculation**: Compute the prefix sum array to quickly calculate the sum of any subarray.
2. **Max-Heap Initialization**: Use a max-heap to keep track of the largest sums. Since Python's `heapq` module is a min-heap, we store negative values to simulate a max-heap.
3. **Visited Set**: Track visited subarrays using a set to avoid processing the same subarray multiple times.
4. **Heap Processing**: Extract the maximum sum subarray from the heap, then generate and push the next possible subarrays (by adjusting the start or end indices) into the heap if they haven't been visited.

### Solution Code
```python
import heapq

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    k = int(input[idx])
    idx += 1
    A = list(map(int, input[idx:idx + n]))
    
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i + 1] = prefix[i] + A[i]
    
    heap = []
    visited = set()
    
    initial_l = 0
    initial_r = n - 1
    initial_sum = prefix[initial_r + 1] - prefix[initial_l]
    heapq.heappush(heap, (-initial_sum, initial_l, initial_r))
    visited.add((initial_l, initial_r))
    
    result = []
    for _ in range(k):
        current = heapq.heappop(heap)
        sum_neg, l, r = current
        current_sum = -sum_neg
        result.append(current_sum)
        
        # Generate left child: l+1, r
        new_l = l + 1
        new_r = r
        if new_l <= new_r:
            if (new_l, new_r) not in visited:
                new_sum = prefix[new_r + 1] - prefix[new_l]
                heapq.heappush(heap, (-new_sum, new_l, new_r))
                visited.add((new_l, new_r))
        
        # Generate right child: l, r-1
        new_l = l
        new_r = r - 1
        if new_l <= new_r:
            if (new_l, new_r) not in visited:
                new_sum = prefix[new_r + 1] - prefix[new_l]
                heapq.heappush(heap, (-new_sum, new_l, new_r))
                visited.add((new_l, new_r))
    
    print(' '.join(map(str, result)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prefix Sum Array**: This array helps in quickly calculating the sum of any subarray using the formula `prefix[r+1] - prefix[l]`.
2. **Max-Heap Usage**: By storing negative values of sums, we utilize Python's `heapq` as a max-heap to efficiently retrieve the largest sum in each iteration.
3. **Visited Set**: Ensures each subarray is processed only once, preventing redundant calculations and entries in the heap.
4. **Subarray Generation**: For each extracted subarray, generate new subarrays by adjusting the start or end indices, ensuring valid indices and checking against the visited set before adding to the heap.

This approach efficiently processes the largest sums using a heap, ensuring we only generate necessary subarrays, leading to an optimal solution within acceptable time and space complexity for large inputs.
