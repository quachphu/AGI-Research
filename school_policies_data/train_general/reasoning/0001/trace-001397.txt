The swaps follow a specific pattern: odd-numbered moves swap the left and middle shells, while even-numbered moves swap the middle and right shells. 

### Approach
1. **Understand the Swapping Pattern**: The swaps alternate between odd and even moves. Odd moves swap the left and middle shells, while even moves swap the middle and right shells.
2. **Cycle Detection**: After analyzing the swaps, we notice that the permutation of shell positions repeats every 6 steps. This allows us to reduce the problem size using modulo arithmetic.
3. **Reverse Simulation**: Instead of simulating all swaps from the start, we reverse the process starting from the final position and apply the swaps in reverse order. This approach is efficient given the cyclical nature of the swaps.

### Solution Code
```python
n = int(input())
x = int(input())

m = n % 6
current = x
for i in range(m, 0, -1):
    if i % 2 == 1:  # odd step, swap 0 and 1
        if current == 0:
            current = 1
        elif current == 1:
            current = 0
    else:  # even step, swap 1 and 2
        if current == 1:
            current = 2
        elif current == 2:
            current = 1
print(current)
```

### Explanation
1. **Modulo Operation**: By taking `n % 6`, we reduce the problem to a maximum of 6 steps, leveraging the cyclical nature of the swaps.
2. **Reverse Simulation**: Starting from the final position `x`, we simulate the reverse of each swap for the reduced number of steps. This is done by iterating from `m` down to 1 and applying the appropriate swap for each step (odd or even).
3. **Efficiency**: This approach runs in constant time O(1) since it processes at most 6 steps, making it suitable for very large values of `n` up to 2 billion.
