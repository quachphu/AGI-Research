To solve this problem, we need to determine which team, if any, can guarantee a win in a game of Kicker (table football) when both teams play optimally. The first team chooses their attack and defense roles first, followed by the second team, who then choose their roles based on the first team's setup. 

### Approach
1. **Input Reading**: Read the defense and attack skills of the four players.
2. **Generate Team Arrangements**: For each team, generate possible attack and defense arrangements. The first team has two possible setups, and the second team also has two possible setups for each of the first team's choices.
3. **Evaluate Outcomes**: For each possible arrangement of the first team, evaluate the outcomes of all possible responses from the second team. Determine if the first team can win, the second team can win, or if the result is a draw for each combination.
4. **Optimal Response**: The second team will choose the arrangement that maximizes their chances of winning. Based on this optimal response, determine the outcome for each of the first team's arrangements.
5. **Determine Final Result**: Check if there exists any arrangement for the first team that guarantees a win. If not, check if the second team can guarantee a win. If neither can guarantee a win, the result is a draw.

### Solution Code
```python
players = [tuple(map(int, input().split())) for _ in range(4)]

# Generate all possible team1 arrangements (attack, defense)
t1_options = [
    (players[0][1], players[1][0]),  # Player 0 attacks, Player 1 defends
    (players[1][1], players[0][0])   # Player 1 attacks, Player 0 defends
]

possible_outcomes = []

for t1_attack, t1_defense in t1_options:
    # Generate all possible team2 arrangements (attack, defense)
    t2_options = [
        (players[2][1], players[3][0]),  # Player 2 attacks, Player 3 defends
        (players[3][1], players[2][0])   # Player 3 attacks, Player 2 defends
    ]
    
    outcomes = []
    for t2_attack, t2_defense in t2_options:
        if t1_attack > t2_defense and t1_defense > t2_attack:
            outcomes.append("team1")
        elif t2_attack > t1_defense and t2_defense > t1_attack:
            outcomes.append("team2")
        else:
            outcomes.append("draw")
    
    # Determine the best outcome for team2
    if "team2" in outcomes:
        current_outcome = "team2"
    else:
        all_team1 = all(outcome == "team1" for outcome in outcomes)
        if all_team1:
            current_outcome = "team1"
        else:
            current_outcome = "draw"
    possible_outcomes.append(current_outcome)

# Determine the final result based on possible outcomes of team1's options
if "team1" in possible_outcomes:
    print("Team 1")
elif all(outcome == "team2" for outcome in possible_outcomes):
    print("Team 2")
else:
    print("Draw")
```

### Explanation
1. **Input Reading**: The code reads the input values for the four players, storing their defense and attack skills.
2. **Team Arrangements**: The first team's possible arrangements are generated, considering both players in attack and defense roles.
3. **Outcome Evaluation**: For each arrangement of the first team, the second team's possible responses are evaluated. The outcomes (win, lose, draw) are determined based on the given conditions.
4. **Optimal Response Handling**: The second team's optimal response is determined by checking if they can win, otherwise checking for a draw or a loss.
5. **Final Result Determination**: The code checks if the first team can guarantee a win with any arrangement. If not, it checks for the second team's guaranteed win. If neither can guarantee a win, the result is a draw.

This approach ensures that all possible scenarios are considered, and the optimal strategies for both teams are evaluated to determine the final result.
