To solve this problem, we need to divide the sequence of integers from 1 to n into two subsets such that the absolute difference between their sums is minimized. The solution leverages mathematical insights to determine the minimum possible difference efficiently.

### Approach
1. **Sum Calculation Insight**: The sum of the first n integers is given by \( \text{sum\_total} = \frac{n(n+1)}{2} \).
2. **Even-Odd Check**: The minimum possible difference between the sums of the two subsets depends on whether the total sum is even or odd:
   - If the total sum is even, the minimum difference is 0 because the sequence can be split into two subsets with equal sums.
   - If the total sum is odd, the minimum difference is 1 because the best possible split will have sums differing by 1.

3. **Modulo Operation Insight**: The parity (even or odd nature) of the total sum can be determined using modulo 4:
   - If \( n \mod 4 \) is 0 or 3, the total sum is even.
   - Otherwise, the total sum is odd.

### Solution Code
```python
n = int(input())
print(0 if n % 4 == 0 or n % 4 == 3 else 1)
```

### Explanation
1. **Reading Input**: The code reads the integer n from standard input.
2. **Modulo Check**: The code checks if \( n \mod 4 \) is either 0 or 3. If true, it prints 0 (indicating an even total sum and thus a minimal difference of 0). Otherwise, it prints 1 (indicating an odd total sum and thus a minimal difference of 1).

This approach ensures the solution is computed in constant time \( O(1) \), making it highly efficient even for the upper constraint limit of \( n \leq 2 \times 10^9 \).
