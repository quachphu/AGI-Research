To solve this problem, we need to calculate the probability that Utkarsh reaches exactly position X = N on the number line by making jumps of either 2 or 3 steps. Each jump of 2 steps has a probability of P/100, and each jump of 3 steps has a probability of (100-P)/100. The solution involves using dynamic programming to efficiently compute the probability for large values of N.

### Approach
1. **Dynamic Programming (DP) Setup**: We use a DP array `dp` where `dp[i]` represents the probability of reaching position `i`.
2. **Initialization**: Start with `dp[0] = 1.0` since Utkarsh starts at position 0.
3. **Transition**: For each position `i` from 1 to N, compute the probability of reaching `i` by considering the probabilities of jumping from `i-2` (if possible) and `i-3` (if possible).
4. **Edge Cases**: Handle cases where N is not reachable by ensuring the transitions only occur if the previous positions are valid.

### Solution Code
```python
n, p_percent = map(int, input().split())

p = p_percent / 100.0
q = (100 - p_percent) / 100.0

dp = [0.0] * (n + 1)
dp[0] = 1.0

for i in range(1, n + 1):
    current = 0.0
    if i >= 2:
        current += dp[i - 2] * p
    if i >= 3:
        current += dp[i - 3] * q
    dp[i] = current

print("{0:.6f}".format(dp[n]))
```

### Explanation
1. **Initialization**: The array `dp` is initialized with zeros except for `dp[0]`, which is set to 1.0 because Utkarsh starts at position 0.
2. **Probability Calculation**: For each position `i` from 1 to N:
   - If `i` can be reached by a 2-step jump from `i-2`, add the probability of reaching `i-2` multiplied by the probability of jumping 2 steps.
   - If `i` can be reached by a 3-step jump from `i-3`, add the probability of reaching `i-3` multiplied by the probability of jumping 3 steps.
3. **Result**: The value `dp[n]` gives the probability of reaching exactly position N, formatted to six decimal places.

This approach efficiently computes the required probability using dynamic programming in O(N) time and space, making it suitable for large values of N up to 1,000,000.
