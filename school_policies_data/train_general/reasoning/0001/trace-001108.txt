To solve this problem, we need to determine the minimal number of moves Dreamoon needs to climb a staircase with `n` steps such that the number of moves is a multiple of `m`. If it's not possible, we should return `-1`.

### Approach
1. **Understand the Problem**: Dreamoon can climb 1 or 2 steps per move. The goal is to find the smallest number of moves that is a multiple of `m` and allows him to reach exactly `n` steps.
2. **Key Insight**: The minimal number of moves required without considering the multiple of `m` is given by `ceil(n/2)`. This is because the optimal strategy is to take as many 2-step moves as possible.
3. **Check Validity**: For a number of moves `k` to be valid, `k` must be a multiple of `m`, and `k` must lie in the range `[ceil(n/2), n]`. This ensures that `k` moves can sum to exactly `n` steps using combinations of 1 and 2 steps.
4. **Calculate the Smallest Valid Multiple**: Compute the smallest multiple of `m` that is at least `ceil(n/2)` and check if it is within the valid range.

### Solution Code
```python
n, m = map(int, input().split())
min_k = (n + 1) // 2
start_k = ((min_k + m - 1) // m) * m
print(start_k if start_k <= n else -1)
```

### Explanation
1. **Calculate Minimum Moves**: The minimum number of moves required to reach `n` steps is `ceil(n/2)`, computed as `(n + 1) // 2` using integer arithmetic.
2. **Find the Smallest Valid Multiple**: The smallest multiple of `m` that is at least `ceil(n/2)` is calculated using the formula `((min_k + m - 1) // m) * m`.
3. **Check Range**: If this multiple is within the range `[ceil(n/2), n]`, it is valid and printed. Otherwise, `-1` is printed indicating no valid solution exists.

This approach efficiently narrows down the valid candidates and ensures we find the minimal number of moves that meets the problem's constraints.
