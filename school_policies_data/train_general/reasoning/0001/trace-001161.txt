To solve this problem, we need to determine how many times Vasya manually adjusts his clock's day number throughout a year. The key insight is to calculate the adjustments required at the transition between each month, as the clock automatically increments the day but may not match the actual first day of the next month.

### Approach
1. **Understanding the Transition**: When moving from the last day of a month to the first day of the next month, the clock automatically increments the day by 1. If this new value does not match the actual first day of the next month (which is always 1), Vasya will manually adjust the clock until it matches.
2. **Manual Adjustments Calculation**: For each transition between months, the number of manual adjustments required can be calculated using the formula `(1 - (a[i] + 1)) % d`, where `a[i]` is the number of days in the current month and `d` is the maximum day the clock can display. This formula accounts for the wrap-around behavior of the clock.

### Solution Code
```python
d = int(input())
n = int(input())
a = list(map(int, input().split()))
total = 0
for i in range(n - 1):
    x = a[i] + 1
    presses = (1 - x) % d
    total += presses
print(total)
```

### Explanation
1. **Reading Input**: The input consists of the maximum day `d`, the number of months `n`, and a list of days in each month.
2. **Loop Through Transitions**: For each month transition (from month `i` to `i+1`), calculate the number of manual adjustments needed. This is done by checking how many increments are required to adjust the clock from the day after the last day of the current month to the first day of the next month.
3. **Summing Adjustments**: Accumulate the total number of adjustments required across all transitions and print the result.

This approach efficiently computes the required adjustments in linear time, making it suitable even for the upper input constraints.
