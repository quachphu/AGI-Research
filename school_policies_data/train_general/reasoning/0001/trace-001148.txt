To solve this problem, we need to determine the longest common pattern length between two strings for multiple test cases. The longest common pattern length is defined as the maximum number of characters that both strings have in common, considering the frequency of each character.

### Approach
1. **Count Character Frequencies**: For each string, count the frequency of each character using a dictionary or a specialized data structure like `Counter` from the `collections` module in Python.
2. **Compute Common Characters**: For each character present in both strings, take the minimum of its counts from both strings. This minimum count represents the maximum number of times the character can be considered common between the two strings.
3. **Sum the Minimum Counts**: Sum all the minimum counts obtained in the previous step to get the longest common pattern length for each test case.

### Solution Code
```python
import sys
from collections import Counter

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        a = sys.stdin.readline().strip()
        b = sys.stdin.readline().strip()
        count_a = Counter(a)
        count_b = Counter(b)
        common_counts = count_a & count_b
        print(sum(common_counts.values()))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline()` to efficiently handle multiple test cases. Each test case consists of two strings read consecutively.
2. **Character Counting**: Using `Counter` from the `collections` module, we count the occurrences of each character in both strings. This operation is efficient with a time complexity of O(n), where n is the length of the string.
3. **Intersection of Counters**: The `&` operator between two `Counter` objects computes the intersection, which results in a new `Counter` where each character's count is the minimum of its counts in the two original `Counter` objects.
4. **Summing Values**: The values of the intersected `Counter` are summed to get the total number of common characters, which is then printed as the result for each test case.

This approach efficiently handles the constraints and ensures that we compute the longest common pattern length accurately and efficiently.
