To solve this problem, we need to organize an electronic queue in an embassy such that the maximum time any person spends in the embassy is minimized. Each person must go through three stages in sequence: showing ID, paying money, and fingerprinting. Each stage has multiple windows, and the goal is to schedule the queue optimally.

### Approach
1. **Model Each Stage Separately**: Each stage (showing ID, paying money, fingerprinting) is modeled separately with its own set of windows and service times.
2. **Track Start Times**: For each person, track the start time at each stage. The start time at a stage is determined by the maximum of their arrival time at that stage and the earliest available time of a window in that stage.
3. **Earliest Available Time Calculation**: For each stage, if there are enough windows (k >= number of people), each person starts immediately. Otherwise, the start time is determined by the earliest available time of the window, which can be derived from the previous usage of the same window.

### Solution Code
```python
import sys

def main():
    k1, k2, k3 = map(int, sys.stdin.readline().split())
    t1, t2, t3 = map(int, sys.stdin.readline().split())
    n = int(sys.stdin.readline())
    c = list(map(int, sys.stdin.readline().split()))
    
    # Process stage 1: showing ID
    s1 = [0] * n
    for i in range(n):
        if i >= k1:
            prev = i - k1
            s1[i] = max(c[i], s1[prev] + t1)
        else:
            s1[i] = c[i]
    
    # Process stage 2: paying money
    arrival2 = [s1[i] + t1 for i in range(n)]
    s2 = [0] * n
    for i in range(n):
        if i >= k2:
            prev = i - k2
            s2[i] = max(arrival2[i], s2[prev] + t2)
        else:
            s2[i] = arrival2[i]
    
    # Process stage 3: fingerprinting
    arrival3 = [s2[i] + t2 for i in range(n)]
    s3 = [0] * n
    for i in range(n):
        if i >= k3:
            prev = i - k3
            s3[i] = max(arrival3[i], s3[prev] + t3)
        else:
            s3[i] = arrival3[i]
    
    # Calculate the maximum time spent
    max_time = 0
    for i in range(n):
        current_time = (s3[i] + t3) - c[i]
        if current_time > max_time:
            max_time = current_time
    
    print(max_time)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Stage 1 Processing**: For each person, if there are enough windows (k1), they start immediately. Otherwise, they wait for the earliest available window, which is determined by the previous usage of the window.
2. **Stage 2 Processing**: The arrival time for stage 2 is the end time of stage 1. The same logic as stage 1 applies for determining start times based on the number of windows (k2).
3. **Stage 3 Processing**: The arrival time for stage 3 is the end time of stage 2. Start times are again determined based on the number of windows (k3).
4. **Calculate Maximum Time**: After processing all stages, the maximum time spent by any person is computed as the difference between their end time at stage 3 and their arrival time at the embassy.

This approach ensures that we efficiently model each stage's window usage and compute the maximum time spent optimally.
