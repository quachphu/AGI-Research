To solve this problem, we need to determine how many pieces of sausage lie completely within the crust of a pizza. The pizza is defined as a circle with radius `r` and a crust of width `d`, forming an annulus between the inner radius `r-d` and the outer radius `r`.

### Approach
1. **Understand the Problem Requirements**: A sausage piece is considered to be on the crust if it lies entirely within the annulus defined by the inner radius `r-d` and the outer radius `r`.
2. **Conditions for Sausage Placement**:
   - The sausage must be entirely outside the inner circle (radius `r-d`).
   - The sausage must be entirely inside the outer circle (radius `r`).
3. **Mathematical Formulation**:
   - For a sausage with center `(xi, yi)` and radius `ri`, calculate the distance from the origin to the center of the sausage using the Euclidean distance formula.
   - Check if the entire sausage lies within the crust using two conditions:
     1. The minimum distance from the origin to the sausage (center distance minus radius) must be at least `r-d`.
     2. The maximum distance from the origin to the sausage (center distance plus radius) must be at most `r`.

### Solution Code
```python
r, d = map(int, input().split())
n = int(input())
count = 0

for _ in range(n):
    x, y, ri = map(int, input().split())
    s = x * x + y * y
    inner = (r - d) + ri
    cond1 = s >= inner * inner
    if ri > r:
        cond2 = False
    else:
        outer = r - ri
        cond2 = s <= outer * outer
    if cond1 and cond2:
        count += 1

print(count)
```

### Explanation
1. **Reading Input**: The first line contains the pizza radius `r` and crust width `d`. The second line gives the number of sausages `n`.
2. **Processing Each Sausage**:
   - For each sausage, compute the squared distance from the origin to its center (`s`).
   - Calculate the squared inner boundary (`inner`) which is the sum of the inner radius `r-d` and the sausage radius `ri`.
   - Check if the squared distance `s` is at least `inner^2` to ensure the sausage is outside the inner circle.
   - Check if the squared distance `s` is at most `(r - ri)^2` to ensure the sausage is inside the outer circle. If the sausage radius exceeds the pizza radius, it cannot fit and is automatically excluded.
3. **Counting Valid Sausages**: Increment the count for each sausage that meets both conditions.

This approach efficiently checks each sausage in constant time, making the solution scalable even for the upper limit of input constraints.
