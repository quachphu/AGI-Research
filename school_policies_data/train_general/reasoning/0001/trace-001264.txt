To solve this problem, we need to rotate an NxN matrix by specified angles, each of which is a multiple of 90 degrees, and print the resulting matrix for each angle. Each rotation is applied to the original matrix independently, ensuring that each subsequent rotation starts from the initial matrix configuration.

### Approach
1. **Input Reading**: Read the matrix dimensions (N and M), the matrix itself, and the list of angles.
2. **Rotation Function**: Implement a function to rotate a matrix 90 degrees clockwise. This can be achieved by transposing the matrix and then reversing each row.
3. **Processing Each Angle**: For each angle, determine the number of 90-degree rotations required (which is the angle divided by 90 modulo 4). Create a copy of the original matrix and apply the necessary rotations.
4. **Output**: Print each rotated matrix, ensuring each matrix is separated by a new line.

### Solution Code
```python
def rotate_90(matrix):
    transposed = list(zip(*matrix))
    rotated = [list(row[::-1]) for row in transposed]
    return rotated

n, m = map(int, input().split())
original = [list(map(int, input().split())) for _ in range(n)]
angles = [int(input()) for _ in range(m)]

for i in range(m):
    angle = angles[i]
    k = (angle // 90) % 4
    current = [row.copy() for row in original]
    for _ in range(k):
        current = rotate_90(current)
    for row in current:
        print(' '.join(map(str, row)))
    if i != m - 1:
        print()
```

### Explanation
1. **Reading Input**: The matrix dimensions (N and M) are read first, followed by the matrix elements and the list of angles.
2. **Rotation Function**: The `rotate_90` function transposes the matrix (rows become columns) and then reverses each row to achieve a 90-degree clockwise rotation.
3. **Processing Each Angle**: For each angle, calculate how many 90-degree rotations are needed. Create a copy of the original matrix and apply the rotations. This ensures each rotation starts from the original matrix.
4. **Output**: After rotating the matrix for each angle, print the resulting matrix. A new line is printed between each matrix to separate them, except after the last matrix.

This approach efficiently handles each rotation independently, ensuring clarity and correctness by always starting from the original matrix configuration for each angle.
