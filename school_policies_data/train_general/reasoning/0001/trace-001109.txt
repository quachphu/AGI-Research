To solve this problem, we need to determine the maximum length of the sum of two numbers when interpreted in different bases. The key challenge is to find the base in which the sum yields the longest possible number.

### Approach
1. **Extract Digits**: Convert the given numbers into their individual digits to determine the valid base range.
2. **Determine Minimum Base**: The minimum valid base is one more than the maximum digit found in both numbers. This ensures all digits are valid in the chosen base.
3. **Calculate Values in Minimum Base**: Convert both numbers to their respective values in the minimum valid base.
4. **Sum and Convert**: Compute the sum of these values and convert the result back to the minimum base to determine the length of the sum in that base.

### Solution Code
```python
a, b = input().split()

# Extract digits of a and b
digits_a = [int(c) for c in a]
digits_b = [int(c) for c in b]

# Find the maximum digit across all digits
max_digit = max(max(digits_a), max(digits_b))
p = max_digit + 1

# Compute a_val in base p
a_val = 0
for d in digits_a:
    a_val = a_val * p + d

# Compute b_val in base p
b_val = 0
for d in digits_b:
    b_val = b_val * p + d

sum_val = a_val + b_val

# Compute the number of digits of sum_val in base p
if sum_val == 0:
    print(1)
else:
    digits = 0
    n = sum_val
    while n > 0:
        digits += 1
        n = n // p
    print(digits)
```

### Explanation
1. **Extract Digits**: Convert each number into a list of its digits. For example, the number 78 becomes [7, 8].
2. **Determine Minimum Base**: The minimum base is determined by the highest digit in either number plus one. For instance, if the highest digit is 8, the minimum base is 9.
3. **Convert to Base**: Each number is converted to its value in the minimum base. For example, 78 in base 9 is calculated as \(7*9 + 8 = 71\).
4. **Sum and Convert**: The sum of these values is then converted back to the minimum base to determine its length. This is done by repeatedly dividing the sum by the base and counting the divisions until the quotient is zero.

This approach ensures that we find the longest possible length of the sum by using the smallest valid base, which typically results in the largest number of digits due to the nature of positional numeral systems.
