To solve this problem, we need to determine the largest minimum distance between two patty-cakes with the same filling when eaten in an optimal order. The solution involves analyzing the frequency distribution of the patty-cake fillings and using this information to compute the desired distance.

### Approach
1. **Frequency Analysis**: For each bag of patty-cakes, compute the frequency of each filling using a counter.
2. **Determine Maximum Frequency**: Identify the maximum frequency of any filling in the bag.
3. **Count Maximum Frequency Elements**: Determine how many different fillings have this maximum frequency.
4. **Calculate Minimum Distance**: Use the formula derived from the problem's constraints to compute the largest minimum distance. The formula is based on the maximum frequency and the number of elements with this frequency.

The formula used is:
\[ \text{answer} = \left\lfloor \frac{n - k}{m - 1} \right\rfloor - 1 \]
where \( m \) is the maximum frequency, \( k \) is the number of fillings with this frequency, and \( n \) is the total number of patty-cakes in the bag.

### Solution Code
```python
import sys
from collections import Counter

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        a = list(map(int, sys.stdin.readline().split()))
        freq = Counter(a)
        max_freq = max(freq.values())
        k = sum(1 for v in freq.values() if v == max_freq)
        d = ( (n - k) // (max_freq - 1) ) - 1
        print(d)

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The code reads the number of test cases and processes each bag of patty-cakes.
2. **Frequency Calculation**: Using the `Counter` from the `collections` module, the code calculates the frequency of each filling.
3. **Maximum Frequency and Count**: The maximum frequency of any filling is determined, along with how many fillings have this maximum frequency.
4. **Distance Calculation**: The formula is applied to compute the largest possible minimum distance between patty-cakes with the same filling. This formula efficiently leverages the frequency distribution to derive the solution.

This approach ensures that the solution is computed in linear time relative to the number of patty-cakes, making it efficient and suitable for large inputs.
