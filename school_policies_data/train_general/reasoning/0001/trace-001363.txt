The solution involves calculating the cost for all possible combinations of bag purchases from the three shops and selecting the combination with the lowest cost.

### Approach
1. **Understand the Problem**: Each shop sells bags of specific weights and offers discounts when purchasing a certain number of bags. The goal is to buy exactly the required amount of flour at the lowest possible cost.
2. **Formulate the Equation**: The total weight of flour bought must be exactly the given amount. This translates to solving the equation \(200x + 300y + 500z = a\), where \(x\), \(y\), and \(z\) are the number of bags bought from shops A, B, and C respectively.
3. **Iterate Over Possible Combinations**: For each possible number of bags from shop C (z), iterate over possible numbers of bags from shop B (y). Calculate the remaining weight and determine the number of bags from shop A (x) needed to meet the exact weight requirement.
4. **Calculate Costs with Discounts**: For each valid combination of bags, compute the cost considering the discounts. Sum the costs from all shops and keep track of the minimum cost encountered.

### Solution Code
```python
import sys

def calculate_min_cost(a):
    k = a // 100  # Convert grams to 100g units
    min_cost = float('inf')
    max_z = k // 5  # Maximum possible bags from shop C (500g each)
    
    for z in range(0, max_z + 1):
        remaining_after_z = k - 5 * z
        max_y = remaining_after_z // 3  # Maximum possible bags from shop B (300g each)
        
        for y in range(0, max_y + 1):
            remaining_after_y = remaining_after_z - 3 * y
            if remaining_after_y < 0:
                continue
            if remaining_after_y % 2 == 0:
                x = remaining_after_y // 2  # Calculate bags from shop A (200g each)
                
                # Calculate cost for shop A
                a_groups = x // 5
                a_remainder = x % 5
                cost_a = a_groups * 1520 + a_remainder * 380
                
                # Calculate cost for shop B
                b_groups = y // 4
                b_remainder = y % 4
                cost_b = b_groups * 1870 + b_remainder * 550
                
                # Calculate cost for shop C
                c_groups = z // 3
                c_remainder = z % 3
                cost_c = c_groups * 2244 + c_remainder * 850
                
                total_cost = cost_a + cost_b + cost_c
                if total_cost < min_cost:
                    min_cost = total_cost
    return min_cost

for line in sys.stdin:
    a = int(line.strip())
    if a == 0:
        break
    print(calculate_min_cost(a))
```

4. **Calculate Remaining Weight for Shop A**: For each valid combination of y and z, compute the remaining weight and check if it can be met with bags from shop A (x).
5. **Compute Costs with Discounts**: For each valid combination, compute the cost from each shop considering their respective discounts and sum them up. Track the minimum cost encountered during the iterations.
6. **Output the Result**: Print the minimum cost for each input value.

This approach efficiently explores all possible combinations of purchases from the three shops while applying the respective discounts, ensuring the solution is both optimal and correct.
