To solve this problem, we need to calculate the total calories Jury wastes by touching specific strips on his phone during a game. Each strip has a corresponding calorie cost, and the game's process is described by a string indicating which strips are active each second.

### Approach
1. **Read Input Values**: First, we read the four integers representing the calorie costs for each of the four strips.
2. **Read Process String**: Next, we read the string that describes which strips are active each second.
3. **Calculate Total Calories**: For each character in the string, convert it to the corresponding strip index, then accumulate the calorie cost for that strip. Summing these values gives the total calories wasted.

### Solution Code
```python
a = list(map(int, input().split()))
s = input().strip()

total = 0
for c in s:
    index = int(c) - 1
    total += a[index]

print(total)
```

### Explanation
1. **Reading Input**: The first line of input contains four integers which are stored in a list `a`, where each index corresponds to a strip (index 0 for strip 1, index 1 for strip 2, etc.).
2. **Processing the String**: The string `s` is processed character by character. Each character (representing a strip number) is converted to an integer and adjusted to zero-based indexing by subtracting 1.
3. **Summing Calories**: For each character in the string, the corresponding calorie value from the list `a` is added to the total. This total is then printed as the result.

This approach efficiently computes the total calories by iterating through each character in the string once, resulting in a time complexity of O(n), where n is the length of the string. This ensures the solution is optimal even for the maximum input size.
