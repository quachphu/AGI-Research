To solve this problem, we need to determine if we can transform string S into string T using any number of character swap operations. Each swap operation allows us to replace every occurrence of one character with another and vice versa.

### Approach
The key insight is that the transformation is possible if and only if the frequency distribution of characters in S can be rearranged to match the frequency distribution of characters in T. This is because each swap operation only changes the characters' identities but not their frequencies. Therefore, the problem reduces to checking if both strings have the same frequency distribution of characters, regardless of which characters they are.

The steps to solve the problem are:
1. Read the input strings S and T.
2. Count the frequency of each character in both strings.
3. Compare the sorted lists of these frequencies. If they match, the transformation is possible; otherwise, it is not.

### Solution Code
```python
import sys
from collections import Counter

def main():
    S = sys.stdin.readline().strip()
    T = sys.stdin.readline().strip()

    # Count the frequency of each character in both strings
    count_S = Counter(S)
    count_T = Counter(T)

    # Extract the sorted list of frequencies (values)
    freq_S = sorted(count_S.values())
    freq_T = sorted(count_T.values())

    # Check if the sorted frequency lists are identical
    if freq_S == freq_T:
        print("Yes")
    else:
        print("No")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The input strings S and T are read from standard input.
2. **Counting Frequencies:** Using the `Counter` class from the `collections` module, we count the frequency of each character in both strings.
3. **Sorting Frequencies:** The frequency counts are sorted to facilitate comparison. This step ensures that we only check the distribution of frequencies, not the specific characters they belong to.
4. **Comparison:** If the sorted frequency lists of S and T are identical, it means we can rearrange the characters in S to match T using swaps, so we print "Yes". Otherwise, we print "No".

This approach efficiently checks the necessary condition for the transformation using frequency analysis, ensuring optimal performance even for the upper constraint limits.
