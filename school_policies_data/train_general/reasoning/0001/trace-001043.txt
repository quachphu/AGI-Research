### Approach
1. **Understanding the Geometry**: In a regular \( n \)-gon, the vertices are equally spaced on a circle. The angle \( \angle abc \) formed by three vertices \( a, b, \) and \( c \) is determined by the arc between \( a \) and \( c \) that does not pass through \( b \). This angle is half the measure of the arc's central angle.

2. **Mathematical Insight**: For an angle \( \text{ang} \), the corresponding arc measure is \( 2 \times \text{ang} \). The number of vertices \( n \) must be such that this arc measure can be divided into equal parts of \( \frac{360}{n} \) degrees each.

3. **Formulating the Solution**: 
   - Compute the greatest common divisor (GCD) of 180 and the given angle to simplify the problem.
   - Determine the minimum integer \( n \) using the derived formula \( n = \frac{180 \times k}{\text{ang}} \), where \( k \) is the number of steps between vertices \( a \) and \( c \).

4. **Efficient Calculation**: Use the GCD to reduce the problem into coprime parts, ensuring the solution is found efficiently and within constraints.

import math

def minimal_regular_polygon():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        ang = int(input[i])
        d = math.gcd(180, ang)
        a = 180 // d
        b = ang // d
        a_minus_b = a - b
        m_min = (1 + a_minus_b) // a_minus_b
        n = a * m_min
        print(n)

minimal_regular_polygon()
