To solve this problem, we need to determine the number of opposite couples in a list of integers. An opposite couple consists of two numbers where one is the negative of the other, except for zero, which is considered opposite to itself. The solution should efficiently count these pairs while avoiding double-counting and ensuring large numbers are handled correctly.

### Approach
1. **Frequency Counting**: Use a frequency counter to count occurrences of each number in the input list.
2. **Zero Handling**: For zero, calculate the number of valid pairs using combinations of zeros taken two at a time.
3. **Positive and Negative Pairs**: For each positive number, check if its negative counterpart exists in the frequency counter. Multiply the counts of these pairs and add to the total, ensuring each pair is counted only once.

### Solution Code
```python
import sys
from collections import Counter

def main():
    n = int(sys.stdin.readline())
    t = list(map(int, sys.stdin.readline().split()))
    count = Counter(t)
    
    total = 0
    
    # Handle zero case
    if 0 in count:
        c = count[0]
        total += c * (c - 1) // 2
    
    # Handle positive and their negative counterparts
    for x in count:
        if x > 0 and -x in count:
            total += count[x] * count[-x]
    
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input, with the first line giving the number of clients and the second line providing their respective values.
2. **Frequency Counter**: Using `collections.Counter`, we count how many times each number appears in the list.
3. **Zero Pairs**: For zeros, the number of valid pairs is calculated using the combination formula \(C(n, 2) = \frac{n(n-1)}{2}\), where \(n\) is the count of zeros.
4. **Positive-Negative Pairs**: For each positive number in the frequency counter, we check if its negative counterpart exists. If it does, the product of their counts gives the number of valid pairs, which is added to the total.

This approach ensures that each valid pair is counted exactly once, efficiently handling up to \(10^5\) elements with a linear pass through the frequency counter.
