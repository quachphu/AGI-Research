To solve this problem, we need to determine if two given numbers are coprime (mutually prime). Two numbers are considered coprime if their greatest common divisor (GCD) is 1. Given the constraints, we need an efficient method to compute the GCD, especially for very large numbers up to \(10^{18}\).

### Approach
1. **Understanding Coprimality**: Two numbers are coprime if their GCD is 1. This means they share no common positive integer factors other than 1.
2. **Efficient GCD Calculation**: The Euclidean algorithm is used to compute the GCD efficiently. This algorithm repeatedly replaces the larger number by its remainder when divided by the smaller number, which quickly reduces the problem size.
3. **Handling Large Inputs**: Python's built-in `math.gcd` function efficiently computes the GCD even for very large numbers, making it suitable for our needs here.
4. **Input Handling**: We read the number of test cases and each pair of numbers efficiently using standard input methods to handle up to 5000 test cases quickly.

### Solution Code
```python
import sys
import math

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        p, q = map(int, sys.stdin.readline().split())
        if math.gcd(p, q) == 1:
            print("Is a Co-Prime")
        else:
            print("Not a Co-Prime")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads the number of test cases `t` from the first line of input. For each test case, it reads the two integers `p` and `q`.
2. **Computing GCD**: Using Python's `math.gcd` function, we compute the GCD of `p` and `q`. This function is optimized for performance and handles large integers efficiently.
3. **Checking Coprimality**: If the GCD is 1, the numbers are coprime, and we print "Is a Co-Prime". Otherwise, we print "Not a Co-Prime".

This approach ensures that we efficiently handle up to 5000 test cases with very large numbers, providing the correct result for each pair in minimal time.
