To solve this problem, we need to determine the minimum cost required to make two given integers, x and y, both zero using two types of operations. The operations are: paying a dollars to change one integer by 1, or paying b dollars to change both integers by 1. The goal is to find the optimal strategy to minimize the total cost.

### Approach
1. **Understand the Operations**: 
   - The first operation allows changing either x or y by 1 at a cost of `a` dollars per change.
   - The second operation allows changing both x and y by 1 at a cost of `b` dollars per change.

2. **Key Observations**:
   - If `b` (cost of changing both integers) is less than `2a` (cost of changing each integer separately), using the second operation for the overlapping part (minimum of x and y) is more efficient.
   - If `b` is greater than or equal to `2a`, it is cheaper to use the first operation for all changes.

3. **Strategy**:
   - Calculate the cost using only the first operation for all changes.
   - Calculate the cost using the second operation for the overlapping part and the first operation for the remaining part.
   - The minimum of these two costs will be the answer.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    t = int(input[idx])
    idx += 1
    for _ in range(t):
        x = int(input[idx])
        y = int(input[idx + 1])
        idx += 2
        a = int(input[idx])
        b = int(input[idx + 1])
        idx += 2
        if x == 0 and y == 0:
            print(0)
            continue
        option1 = (x + y) * a
        min_xy = min(x, y)
        max_xy = max(x, y)
        option2 = min_xy * b + (max_xy - min_xy) * a
        print(min(option1, option2))
solve()
```

1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Handling Each Test Case**:
   - For each test case, read the integers x and y, followed by the costs a and b.
   - If both x and y are zero, the cost is immediately zero.
   - Calculate the cost using only the first operation (`option1`).
