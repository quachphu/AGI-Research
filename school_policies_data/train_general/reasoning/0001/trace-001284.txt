To solve this problem, we need to determine how many distinct photobooks Kyoya Ootori can create by inserting one extra photo (a lowercase letter) into his existing photobook string. The key is to count all unique strings that can be formed by inserting each of the 26 possible letters into every possible position in the original string.

### Approach
1. **Understand the Problem**: We need to insert each of the 26 lowercase letters into every possible position of the given string and count the number of distinct resulting strings.
2. **Generate All Possible Insertions**: For each position in the original string (including before the first character and after the last character), insert each of the 26 letters. This results in a new string for each insertion.
3. **Use a Set for Uniqueness**: By using a set data structure, we can automatically handle duplicate strings, as sets do not allow duplicate entries.
4. **Calculate the Result**: The size of the set after all insertions will give the number of distinct photobooks.

### Solution Code
```python
def main():
    s = input().strip()
    unique_books = set()
    length = len(s)
    for i in range(length + 1):
        for c in 'abcdefghijklmnopqrstuvwxyz':
            new_book = s[:i] + c + s[i:]
            unique_books.add(new_book)
    print(len(unique_books))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input string is read from standard input.
2. **Initializing a Set**: A set `unique_books` is used to store the unique photobook strings generated.
3. **Iterating Over Positions**: The loop runs from 0 to the length of the string (inclusive), covering all possible insertion positions.
4. **Inserting Each Character**: For each position, each of the 26 lowercase letters is inserted to form a new string.
5. **Storing Unique Strings**: Each newly formed string is added to the set, which ensures only unique entries are kept.
6. **Output the Result**: The size of the set, representing the number of distinct photobooks, is printed.

This approach efficiently handles the problem constraints and ensures that all possible unique photobooks are counted using the properties of sets to avoid duplicates. The complexity is manageable given the input constraints (string length up to 20), making this solution both optimal and easy to understand.
