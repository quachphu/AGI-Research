To solve this problem, we need to determine the maximum number of gold coins a participant can collect while moving from the top-left corner to the bottom-right corner of a grid, and then check if they can pay a specified number of coins to the guard. If they can, we output the remaining coins; otherwise, we output -1.

### Approach
1. **Dynamic Programming (DP) Setup**: Use a DP table where `dp[i][j]` represents the maximum coins collected when reaching cell `(i, j)`.
2. **Initialization**: Start from the top-left corner `(0, 0)` which is initialized to 0 coins as per the problem statement.
3. **First Row and Column**: Fill the first row and column by accumulating coins from the start, as movement is restricted to right or down only.
4. **DP Transition**: For each cell `(i, j)`, compute the maximum coins collected by considering the maximum of the coins from the cell above `(i-1, j)` or the cell to the left `(i, j-1)`, and add the current cell's coins.
5. **Result Calculation**: After constructing the DP table, check if the maximum coins at the bottom-right corner meet the required payment. If yes, output the remaining coins; otherwise, output -1.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        n = int(input[ptr])
        c = int(input[ptr + 1])
        ptr += 2
        grid = []
        for _ in range(n):
            row = list(map(int, input[ptr:ptr + n]))
            ptr += n
            grid.append(row)
        
        # Initialize DP table
        dp = [[0] * n for _ in range(n)]
        dp[0][0] = grid[0][0]
        
        # Fill first row
        for j in range(1, n):
            dp[0][j] = dp[0][j-1] + grid[0][j]
        
        # Fill first column
        for i in range(1, n):
            dp[i][0] = dp[i-1][0] + grid[i][0]
        
        # Fill the rest of the DP table
        for i in range(1, n):
            for j in range(1, n):
                dp[i][j] = max(dp[i-1][j], dp[i][j-1]) + grid[i][j]
        
        max_coins = dp[n-1][n-1]
        if max_coins >= c:
            print(max_coins - c)
        else:
            print(-1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints. The input is split into a list of strings for easy processing.
2. **Grid and DP Table Initialization**: The grid is constructed from the input values, and the DP table is initialized with zeros.
3. **Filling the DP Table**: The first row and column are filled by accumulating values from the start. The rest of the table is filled using the transition rule which considers the maximum coins from the top or left cells.
4. **Result Calculation**: The maximum coins collected at the bottom-right corner are checked against the required payment. The result is computed and printed accordingly.

This approach efficiently computes the maximum coins using dynamic programming in O(n²) time per test case, which is optimal for the given constraints.
