import sys

def is_leap(year):
    if year % 400 == 0:
        return True
    if year % 100 == 0:
        return False
    if year % 4 == 0:
        return True
    return False

def leap_count(y):
    if y < 0:
        return 0
    return y // 4 - y // 100 + y // 400 + 1

def total_days(y, m, d):
    # Calculate sum of days from years 0 to y-1
    sum_years = y * 365 + leap_count(y-1)
    # Calculate sum of days from months 1 to m-1 in year y
    month_days = [31,28,31,30,31,30,31,31,30,31,30,31]
    sum_months = 0
    for month in range(1, m):
        if month == 2:
            sum_months += 29 if is_leap(y) else 28
        else:
            sum_months += month_days[month - 1]
    # Total days
    return sum_years + sum_months + d

def main():
    data = list(map(int, sys.stdin.read().split()))
    idx = 0
    while True:
        if idx +6 > len(data):
            break
        nums = data[idx:idx+6]
        idx +=6
        if any(num <0 for num in nums):
            break
        y1, m1, d1, y2, m2, d2 = nums
        days1 = total_days(y1, m1, d1)
        days2 = total_days(y2, m2, d2)
        print(days2 - days1)

    main()

To solve this problem, we need to calculate the number of days between two dates, considering leap years and ensuring that the first date is included in the count while the second date is excluded. The solution must handle multiple datasets efficiently and correctly apply the leap year rules.

### Approach
1. **Leap Year Calculation**: Determine if a year is a leap year based on the given conditions.
2. **Total Days Calculation**: For each date, compute the total number of days from a fixed starting point (year 0) to the given date. This involves:
   - Summing the days contributed by each year up to the year before the given date.
   - Adding the days contributed by each month up to the month before the given date in the given year.
   - Adding the days in the given month.
3. **Difference Calculation**: Subtract the total days of the earlier date from the total days of the later date to get the number of days between them.

### Solution Code
```python
import sys

def is_leap(year):
    if year % 400 == 0:
        return True
    if year % 100 == 0:
        return False
    if year % 4 == 0:
        return True
    return False

def leap_count(y):
    if y < 0:
        return 0
    return y // 4 - y // 100 + y // 400 + 1

def total_days(y, m, d):
    sum_years = y * 365 + leap_count(y - 1)
    month_days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
    sum_months = 0
    for month in range(1, m):
        if month == 2:
            sum_months += 29 if is_leap(y) else 28
        else:
            sum_months += month_days[month - 1]
    return sum_years + sum_months + d

def main():
    data = list(map(int, sys.stdin.read().split()))
    idx = 0
    while idx + 6 <= len(data):
        nums = data[idx:idx+6]
        idx += 6

        y1, m1, d1, y2, m2, d2 = nums
```

### Explanation
1. **Leap Year Check**: The `is_leap` function checks if a year is a leap year using the specified rules.
2. **Leap Year Count**: The `leap_count` function calculates the number of leap years from year 0 up to a given year, which helps in efficiently summing the days contributed by each year.
3. **Total Days Calculation**: The `total_days` function computes the total days from year 0 to the given date by summing contributions from years, months, and days. This uses the leap year count to avoid iterating through each year.
4. **Main Function**: Reads input, processes each dataset, computes the total days for both dates, and prints the difference. The loop stops when encountering any negative number in the input.

This approach ensures efficient handling of large date ranges by leveraging mathematical calculations for leap years and avoiding iterative summation over years, thus optimizing performance.
