To solve this problem, we need to determine the number of valid unordered pairs {x, y} from a list of integers such that the Arrayland interval is completely contained within the Vectorland interval. The key insight is that the problem can be reduced to checking if twice the smaller absolute value of the pair is greater than or equal to the larger absolute value.

### Approach
1. **Compute Absolute Values**: Convert each number in the input list to its absolute value.
2. **Sort the Absolute Values**: Sorting helps in efficiently finding valid pairs using binary search.
3. **Binary Search for Valid Pairs**: For each element in the sorted list, use binary search to determine how many elements to its right can form valid pairs. Specifically, for each element, find the number of subsequent elements that are between the current element and twice the current element.

### Solution Code
```python
import bisect

n = int(input())
a = list(map(int, input().split()))
a_abs = [abs(x) for x in a]
a_abs.sort()

count = 0
for i in range(n):
    target = 2 * a_abs[i]
    # Find the first index after i where the value exceeds target
    j = bisect.bisect_right(a_abs, target, i + 1, n)
    count += (j - (i + 1))

print(count)
```

### Explanation
1. **Reading Input**: The input consists of the number of integers and the integers themselves.
2. **Absolute Values and Sorting**: Convert each integer to its absolute value and sort these values. This allows us to efficiently check pairs using binary search.
3. **Binary Search for Valid Pairs**: For each element in the sorted list, determine the range of subsequent elements that can form valid pairs. This is done by finding the rightmost position where twice the current element is still greater than or equal to the subsequent elements using binary search.
4. **Counting Valid Pairs**: For each element, the number of valid pairs is determined by the range found using binary search. Summing these counts gives the total number of valid pairs.

This approach ensures an efficient solution with a time complexity of O(n log n), which is suitable for large input sizes up to 200,000 elements.
