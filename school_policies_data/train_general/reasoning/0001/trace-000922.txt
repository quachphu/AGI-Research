To solve this problem, we need to find the longest path in a directed graph where the edge weights are strictly increasing and the edges are chosen in the order they appear in the input. The path must be valid, meaning each edge must start at the end node of the previous edge.

### Approach
1. **Dynamic Programming (DP) with Binary Search**: We use a dynamic programming approach where each entry `dp[i]` represents the maximum number of edges in a valid path ending with the i-th edge. To efficiently compute this, we maintain for each node a list of tuples sorted by weight. Each tuple contains a weight and the maximum path length (DP value) for paths ending at that node with that weight.
2. **Sorted List Maintenance**: For each node, we maintain a sorted list of weights and their corresponding maximum DP values. This allows us to quickly find the maximum DP value for weights less than a given value using binary search.
3. **Efficient Insertions and Queries**: When inserting a new edge into the list of a node, we ensure the list remains sorted and only keeps necessary entries by pruning redundant values. This helps maintain efficient query times.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    idx = 0
    n = int(data[idx])
    idx += 1
    m = int(data[idx])
    idx += 1

    edges = []
    for _ in range(m):
        a = int(data[idx]) - 1
        idx += 1
        b = int(data[idx]) - 1
        idx += 1
        w = int(data[idx])
        idx += 1
        edges.append((a, b, w))

    from collections import defaultdict
    nodes = defaultdict(list)
    max_length = 0

    for a, b, w in edges:
        # Query the start node's list for max dp with weight < current w
        current_list = nodes.get(a, [])
        pos = bisect.bisect_left(current_list, (w, 0))  # Find first >= w
        prev_max = 0
        if pos > 0:
            prev_max = current_list[pos - 1][1]
        current_dp = prev_max + 1
        if current_dp > max_length:
            max_length = current_dp

        # Insert into the end node's list
        target_list = nodes.get(b, [])
        insert_pos = bisect.bisect_left(target_list, (w, 0))

        # Calculate the previous_max for the insert position
        prev_m = 0
        if insert_pos > 0:
            prev_m = target_list[insert_pos - 1][1]
        new_m = max(current_dp, prev_m)

        # Skip if new_m is not better than the previous entry
        if insert_pos > 0 and new_m <= target_list[insert_pos - 1][1]:
            continue

        # Prune entries that are dominated by the new entry
        while insert_pos < len(target_list):
            current_w, current_m = target_list[insert_pos]
            if current_w >= w and current_m <= new_m:
                del target_list[insert_pos]
            else:
                break

        # Insert the new entry
        target_list.insert(insert_pos, (w, new_m))
        nodes[b] = target_list

    print(max_length)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into a list of edges, converting node indices to 0-based for easier handling.
2. **Dynamic Programming Setup**: For each edge, we determine the maximum path length ending at the current edge by querying the start node's list of weights.
3. **Binary Search for Efficiency**: Using binary search, we quickly find the position where the current edge's weight would fit in the sorted list, allowing us to determine the maximum valid path length from previous edges.
4. **Maintaining Sorted Lists**: Each node's list of weights is maintained in sorted order, and redundant entries are pruned to ensure efficient future queries and insertions.

This approach ensures that we efficiently compute the longest valid path with strictly increasing weights while adhering to the input order, achieving a time complexity of O(m log k) where k is the number of unique weights per node.
