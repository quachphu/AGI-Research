To solve this problem, we need to determine if two users in a social network are reachable through their connections. This can be efficiently achieved using the Disjoint Set Union (DSU) data structure, which allows us to manage and query connected components in an undirected graph.

### Approach
1. **Input Reading**: Read all input data at once for efficiency, especially given the constraints.
2. **Union-Find Data Structure (DSU)**: This structure helps in efficiently managing the connected components of the graph. It supports two main operations:
   - **Union**: Merge two sets (connected components).
   - **Find**: Determine the root of a set, with path compression to flatten the structure for faster future queries.
3. **Processing Relationships**: For each friendship relation, use the union operation to merge the sets of the two users.
4. **Query Handling**: For each query, use the find operation to check if the two users belong to the same connected component.

### Solution Code
```python
import sys

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]  # Path compression
            x = self.parent[x]
        return x

    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return
        if self.size[x_root] < self.size[y_root]:
            x_root, y_root = y_root, x_root
        self.parent[y_root] = x_root
        self.size[x_root] += self.size[y_root]

def main():
    data = list(map(int, sys.stdin.read().split()))
    ptr = 0
    n = data[ptr]
    ptr += 1
    m = data[ptr]
    ptr += 1

    dsu = DSU(n)
    for _ in range(m):
        s = data[ptr]
        ptr += 1
        t = data[ptr]
        ptr += 1
        dsu.union(s, t)

    q = data[ptr]
    ptr += 1
    result = []
    for _ in range(q):
        s = data[ptr]
        ptr += 1
        t = data[ptr]
        ptr += 1
        if dsu.find(s) == dsu.find(t):
            result.append("yes")
        else:
            result.append("no")
    print('\n'.join(result))

if __name__ == "__main__":
    main()
```
