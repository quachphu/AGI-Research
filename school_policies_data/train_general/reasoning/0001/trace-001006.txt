To solve this problem, we need to determine if AquaMoon can rearrange her friends into a non-decreasing sequence using swaps such that all friends end up facing right. Each swap flips the direction of the two involved friends, so each friend must be involved in an even number of swaps to end up facing right again. 

### Approach
1. **Split Elements by Parity of Positions**: Separate the elements into two groups based on their original positions (odd-indexed and even-indexed).
2. **Sort Each Group**: Sort the elements in both groups.
3. **Reconstruct the Array**: Merge the sorted groups back into an array where elements from the odd-indexed group are placed in odd positions and those from the even-indexed group are placed in even positions.
4. **Check Non-Decreasing Order**: Verify if the reconstructed array is non-decreasing. If it is, the answer is "YES"; otherwise, it is "NO".

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    t = int(input[idx])
    idx += 1
    for _ in range(t):
        n = int(input[idx])
        idx += 1
        a = list(map(int, input[idx:idx + n]))
        idx += n
        
        # Split into odd and even positions (1-based)
        odds = a[::2]  # 0, 2, 4... indices (1,3,5... 1-based)
        evens = a[1::2]  # 1,3,5... indices (2,4,6... 1-based)
        
        # Sort each list
        odds_sorted = sorted(odds)
        evens_sorted = sorted(evens)
        
        # Reconstruct the merged array
        merged = []
        o = e = 0
        for i in range(n):
            if i % 2 == 0:  # 0-based even index corresponds to 1-based odd position
                merged.append(odds_sorted[o])
                o += 1
            else:
                merged.append(evens_sorted[e])
                e += 1
        
        # Check if merged is non-decreasing
        possible = True
        for i in range(1, n):
            if merged[i] < merged[i-1]:
                possible = False
                break
        print("YES" if possible else "NO")

solve()
```

### Explanation
1. **Splitting by Parity**: Elements are split into two groups based on their original positions (odd or even). This ensures that each element can be moved to a position of the same parity, maintaining an even number of swaps.
2. **Sorting**: Each group is sorted independently to prepare for merging.
3. **Reconstructing the Array**: The sorted groups are merged back such that elements from the sorted odd-indexed group occupy the odd positions and those from the sorted even-indexed group occupy the even positions.
4. **Validation**: The merged array is checked to ensure it is non-decreasing. If it is, it means the rearrangement is possible under the given constraints.

This approach efficiently checks the feasibility of rearranging the friends while adhering to the constraints, ensuring the solution runs in O(n log n) time due to sorting, which is optimal for the problem constraints.
