### Approach
The problem can be solved by understanding that each new candle requires 4 burnt candles. Given the initial number of candles (M), we can determine the number of new candles by performing an integer division of M by 4. This approach works because each new candle is created from exactly 4 burnt candles, and we do not reuse the new candles once they are created.

### Solution Code
```python
def main():
    M = int(input())
    print(M // 4)

main()
```

3. **Output Result**: The result of the integer division is printed, which is the number of new candles created.

This approach efficiently computes the result in constant time, O(1), as it involves a single division operation. The solution directly addresses the problem constraints and provides the correct result based on the given sample input and output.
