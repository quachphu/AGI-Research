To solve this problem, we need to determine the number of days Pinocchio lied based on the recorded lengths of his nose. Each time he lies, his nose length increases by 1 cm. We need to count the days where his nose length increased compared to the previous day.

### Approach
1. **Input Reading**: Read the number of test cases. For each test case, read the number of days and the list of nose lengths recorded each day.
2. **Initialization**: Start with the nose length of the first day, as it is assumed to be truthful.
3. **Iterate through Days**: For each subsequent day, check if the nose length increased compared to the previous day. If it did, increment the count of days he lied.
4. **Update Previous Length**: After checking each day, update the previous length to the current day's length for the next comparison.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        L = list(map(int, input[ptr:ptr+N]))
        ptr += N
        if N <= 1:
            print(0)
            continue
        prev = L[0]
        count = 0
        for num in L[1:]:
            if num > prev:
                count += 1
            prev = num
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints. The input is split into a list of strings for easy processing.
2. **Processing Each Test Case**: For each test case, we first read the number of days and the list of nose lengths.
3. **Initial Check**: If there is only one day, there are no subsequent days to check, so the result is 0.
4. **Loop Through Days**: Starting from the second day, compare each day's nose length with the previous day's length. If there is an increase, it indicates at least one lie, so we increment the count.
5. **Update Previous Length**: After each comparison, update the previous day's length to the current day's length to ensure correct comparisons for subsequent days.

This approach efficiently processes each test case in linear time relative to the number of days, making it suitable for large input sizes as specified in the problem constraints.
