To solve this problem, we need to determine the number of white cells remaining in a grid after painting specific rows and columns. The key insight is that the remaining white cells are those not in any of the selected rows or columns.

### Approach
1. **Problem Analysis**:
   - We are given a grid with H rows and W columns.
   - We choose h rows and w columns to paint. All cells in these rows and columns will be painted.
   - The remaining white cells will be those that are not in any of the selected rows or columns.

2. **Key Insight**:
   - The number of remaining rows not painted is (H - h).
   - The number of remaining columns not painted is (W - w).
   - The total number of remaining white cells is the product of these two values, which is (H - h) * (W - w).

3. **Algorithm**:
   - Read the input values for H, W, h, and w.
   - Compute the product of the remaining rows and columns.
   - Print the result.

### Solution Code
```python
def main():
    H, W = map(int, input().split())
    h, w = map(int, input().split())
    remaining = (H - h) * (W - w)
    print(remaining)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input values are read and parsed into integers for H, W, h, and w.
- **Calculation**: The formula (H - h) * (W - w) is used to compute the number of remaining white cells. This formula works because it calculates the product of the number of rows and columns that are not painted.
- **Output**: The result is printed, which is the number of white cells remaining after the specified rows and columns are painted.

This approach efficiently computes the result in constant time, O(1), making it very efficient even for the upper limits of the input constraints.
