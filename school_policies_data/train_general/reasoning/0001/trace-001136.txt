To solve this problem, we need to determine if it is possible to generate a ball with the integer K using a series of operations where two balls are replaced by their absolute difference. The solution involves checking a few key conditions based on the properties of the given numbers.

### Approach
1. **Check Presence of K**: If K is already present in the initial array, the answer is immediately "POSSIBLE".
2. **Check Maximum Value**: If K is greater than the maximum value in the array, it is impossible to generate K, so the answer is "IMPOSSIBLE".
3. **Check Divisibility by GCD**: The greatest common divisor (GCD) of all elements in the array must divide K. If K is not divisible by this GCD, it is impossible to generate K, so the answer is "IMPOSSIBLE".
4. **Final Check**: If K is less than or equal to the maximum value and divisible by the GCD, then it is possible to generate K through the operations, so the answer is "POSSIBLE".

### Solution Code
```python
import sys
import math
from functools import reduce

def main():
    input = sys.stdin.read().split()
    N = int(input[0])
    K = int(input[1])
    A = list(map(int, input[2:2+N]))
    
    if K in A:
        print("POSSIBLE")
        return
    
    max_A = max(A)
    if K > max_A:
        print("IMPOSSIBLE")
        return
    
    current_gcd = reduce(math.gcd, A)
    if K % current_gcd == 0:
        print("POSSIBLE")
    else:
        print("IMPOSSIBLE")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Presence Check**: The first check simply verifies if K is already present in the array, which allows an immediate positive result.
2. **Maximum Value Check**: Since each operation can only generate numbers that are absolute differences of existing numbers, the maximum value in the array cannot be exceeded. Thus, if K is greater than this maximum, it is impossible to generate K.
3. **GCD Check**: The GCD of all elements in the array is a crucial factor. Any number generated through the operations must be a multiple of this GCD. If K is not a multiple of the GCD, it cannot be generated.
4. **Combined Check**: If K passes both the maximum value and GCD checks, it is possible to generate K through the described operations.

This approach efficiently combines these checks to determine the possibility of generating K, ensuring optimal performance even for large input sizes.
