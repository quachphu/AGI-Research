To solve this problem, we need to determine the optimal order to milk cows such that the total loss of milk is minimized. The key insight is to process cows facing right (R) first, followed by cows facing left (L) in reverse order. This approach minimizes the number of times a cow is scared by another cow being milked before it.

### Approach
1. **Identify Cows by Direction**: Separate cows into those facing right (R) and those facing left (L).
2. **Count R Cows Before L Cows**: For each cow facing left, count how many cows facing right are positioned before it. This count gives the total milk loss because each R cow processed before an L cow will scare that L cow once.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
r_count = 0
total = 0
for direction in a:
    if direction == 1:
        r_count += 1
    else:
        total += r_count
print(total)
```

### Explanation
1. **Reading Input**: The input consists of the number of cows and their respective directions.
2. **Counting R Cows**: As we iterate through the list of cows, we maintain a count of how many R cows we have encountered so far.
3. **Summing Loss for L Cows**: For each L cow encountered, we add the current count of R cows to the total loss. This is because each R cow encountered before an L cow will scare the L cow once when it is milked.

This approach ensures that we efficiently compute the minimum milk loss in linear time, O(n), by leveraging the positions and directions of the cows. The solution processes R cows first and counts how many times each L cow is scared by R cows processed before it.
