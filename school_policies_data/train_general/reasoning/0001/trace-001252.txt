To solve this problem, we need to determine the number of roads connected to each city given a list of cities and bidirectional roads between them. Each road contributes to the count of both cities it connects.

### Approach
1. **Input Reading**: Read the number of cities (N) and roads (M) from the input.
2. **Initialization**: Create an array to keep track of the number of roads connected to each city. This array will be initialized to zero for all cities.
3. **Processing Roads**: For each road, increment the count for both cities connected by that road.
4. **Output**: Print the count of roads for each city from 1 to N.

### Solution Code
```python
n, m = map(int, input().split())
counts = [0] * (n + 1)
for _ in range(m):
    a, b = map(int, input().split())
    counts[a] += 1
    counts[b] += 1
for i in range(1, n + 1):
    print(counts[i])
```

### Explanation
1. **Reading Input**: The first line of input contains the number of cities (N) and roads (M). The subsequent M lines each contain two integers representing the cities connected by a road.
2. **Count Array Initialization**: An array `counts` of size N+1 is initialized to zero to accommodate 1-based indexing of cities.
3. **Updating Counts**: For each road, the count for both cities involved in the road is incremented by 1.
4. **Output Results**: After processing all roads, the count for each city from 1 to N is printed in sequence.

This approach efficiently processes each road in O(1) time, resulting in an overall time complexity of O(M), which is optimal given the constraints. The space complexity is O(N) to store the counts, which is also efficient for the problem constraints.
