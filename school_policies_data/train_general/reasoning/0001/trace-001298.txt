To solve this problem, we need to determine if two given strings are anagrams of each other. An anagram is a word or phrase formed by rearranging the letters of another, using all the original letters exactly once. 

### Approach
1. **Check Lengths**: First, check if the two strings have the same length. If they do not, they cannot be anagrams, so we immediately return "No".
2. **Sort and Compare**: If the lengths are the same, sort both strings and compare the sorted results. If the sorted strings are identical, they are anagrams; otherwise, they are not.

### Solution Code
```python
def main():
    import sys
    t = int(sys.stdin.readline())
    for _ in range(t):
        # Read the two strings from the input line
        s1, s2 = sys.stdin.readline().split()
        # Check if lengths are different first
        if len(s1) != len(s2):
            print("No")
            continue
        # Compare sorted versions of the strings
        if sorted(s1) == sorted(s2):
            print("Yes")
        else:
            print("No")

main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first line contains the number of test cases.
2. **Length Check**: For each test case, the two strings are read and their lengths are compared. If they differ, the result is immediately "No".
3. **Sorting and Comparison**: If the lengths are the same, both strings are sorted. Sorting ensures that if they are anagrams, their sorted forms will be identical. This sorted comparison is efficient and works within the problem constraints (string length up to 1000).

This approach efficiently checks for anagrams by leveraging sorting and length checks, ensuring correctness and performance within the given problem constraints.
