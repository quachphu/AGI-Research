To solve this problem, we need to determine how many classes a student can attend given that some periods are blocked due to a barricade. The barricade is active from just before the start of the A-th period to just before the start of the B-th period, meaning any class during this interval is canceled.

### Approach
1. **Understanding the Blocked Periods**: The barricade is active from period A to period B-1 (inclusive). Any class scheduled during these periods will be canceled.
2. **Check Each Class Period**: For each class period, check if it falls outside the blocked interval. Specifically, if a class period is less than A or greater than or equal to B, it is not blocked.
3. **Count Valid Classes**: Iterate through all class periods and count how many of them are not in the blocked interval.

### Solution Code
```python
n, a, b = map(int, input().split())
count = 0
for _ in range(n):
    ti = int(input())
    if ti < a or ti >= b:
        count += 1
print(count)
```

### Explanation
1. **Reading Input**: The first line of input contains three integers N, A, and B. The subsequent N lines contain the class periods.
2. **Determine Blocked Interval**: The blocked periods are from A (inclusive) to B-1 (inclusive). Classes in these periods are canceled.
3. **Check Each Class Period**: For each class period, check if it is outside the blocked interval. If it is, increment the count of attendable classes.
4. **Output the Result**: Print the total count of classes that can be attended.

This approach efficiently checks each class period once, resulting in a time complexity of O(N), which is optimal given the constraints.
