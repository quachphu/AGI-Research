To solve this problem, we need to determine the number of pairs of intersecting wires formed by connecting electric poles on a Cartesian plane. Each wire is represented as a line, and we need to count pairs of lines that intersect at exactly one point.

### Approach
1. **Generate Unique Lines**: For each pair of distinct points, compute the line passing through them and normalize its representation to avoid duplicates. Normalization ensures that different representations of the same line are treated identically.
2. **Check for Intersections**: For each pair of unique lines, determine if they intersect by checking if they are neither the same line nor parallel. This is done by comparing their normalized coefficients.

### Solution Code
```python
import sys

def compute_gcd(a, b):
    while b:
        a, b = b, a % b
    return a

def normalize_line(A, B, C):
    if A == 0 and B == 0 and C == 0:
        return (0, 0, 0)
    gcd_ab = compute_gcd(abs(A), abs(B))
    g = compute_gcd(gcd_ab, abs(C))
    if g == 0:
        g = 1
    a = A // g
    b = B // g
    c = C // g
    first_non_zero = 0
    for v in (a, b, c):
        if v != 0:
            first_non_zero = v
            break
    if first_non_zero < 0:
        a = -a
        b = -b
        c = -c
    return (a, b, c)

def main():
    n = int(sys.stdin.readline())
    points = []
    for _ in range(n):
        x, y = map(int, sys.stdin.readline().split())
        points.append((x, y))
    lines = set()
    for i in range(n):
        x1, y1 = points[i]
        for j in range(i + 1, n):
            x2, y2 = points[j]
            A = y2 - y1
            B = x1 - x2
            C = x2 * y1 - x1 * y2
            line = normalize_line(A, B, C)
            lines.add(line)
    lines = list(lines)
    count = 0
    m = len(lines)
    for i in range(m):
        a1, b1, _ = lines[i]
        for j in range(i + 1, m):
            a2, b2, _ = lines[j]
            if a1 == a2 and b1 == b2:
                continue
            count += 1
    print(count)

if __name__ == "__main__":
    main()
```

2. **Unique Line Collection**: Using a set, we collect all unique lines formed by pairs of points.
3. **Intersection Check**: For each pair of lines, we check if they are parallel by comparing their coefficients. If they are not parallel, they intersect, and we count such pairs.
