To solve this problem, we need to determine the minimum time Devu needs to hypnotize all people in the haunted town using a perfume. The perfume spreads from its initial placement to all adjacent cells (including diagonally adjacent cells) every second. The goal is to find the optimal placement for the perfume to minimize the total time required.

### Approach
1. **Identify Inhabited Cells**: First, collect the coordinates of all inhabited cells (cells containing '*').
2. **Bounding Rectangle**: Determine the minimum and maximum coordinates (both row and column) of the inhabited cells. This forms a bounding rectangle around all inhabited cells.
3. **Calculate Spread Time**: The optimal placement for the perfume is at the center of this bounding rectangle. The time required for the perfume to spread from this center to the farthest inhabited cell is determined by the maximum Chebyshev distance from the center to any inhabited cell. The Chebyshev distance between two points (x1, y1) and (x2, y2) is given by max(|x1 - x2|, |y1 - y2|).
4. **Compute Result**: The total time is the spread time plus 1 second for placing the perfume initially.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        n = int(input[ptr])
        m = int(input[ptr + 1])
        ptr += 2
        stars = []
        for i in range(n):
            row = input[ptr]
            ptr += 1
            for j in range(m):
                if row[j] == '*':
                    stars.append((i, j))
        if not stars:
            print(0)
            continue
        min_x = max_x = stars[0][0]
        min_y = max_y = stars[0][1]
        for x, y in stars[1:]:
            if x < min_x:
                min_x = x
            if x > max_x:
                max_x = x
            if y < min_y:
                min_y = y
            if y > max_y:
                max_y = y
        x_span = max_x - min_x
        y_span = max_y - min_y
        x_comp = (x_span + 1) // 2
        y_comp = (y_span + 1) // 2
        max_dist = max(x_comp, y_comp)
        print(max_dist + 1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially for large input sizes.
2. **Collecting Inhabited Cells**: We traverse each row of the grid to collect the coordinates of all inhabited cells.
3. **Bounding Rectangle Calculation**: By finding the minimum and maximum row and column indices of the inhabited cells, we form a bounding rectangle.
4. **Spread Time Calculation**: The spread time from the optimal center is determined using the Chebyshev distance. The maximum distance from the center to any inhabited cell is calculated using the spans of the bounding rectangle.
5. **Result Calculation**: The result is the maximum spread time plus 1 second for the initial placement of the perfume.

This approach efficiently computes the minimum time required using geometric properties of the inhabited cells' distribution, ensuring optimal performance even for larger grids.
