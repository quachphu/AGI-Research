To solve this problem, we need to determine the maximum number of times the subsequence "CHEF" can be formed from a given string, where each character in the subsequence must appear in order. The solution involves tracking the counts of each character ('C', 'H', 'E', 'F') in a way that respects their required order.

### Approach
1. **Track Character Counts**: We maintain four counters for the characters 'C', 'H', 'E', and 'F'. Each counter is incremented only when the preceding characters in the subsequence have been encountered in the required order.
2. **Order Constraints**: Each character in the subsequence must appear after the previous one. For example, 'H' can only be counted if there is a preceding 'C', 'E' can only be counted if there is a preceding 'H', and so on.
3. **Efficient Traversal**: By iterating through the string once, we update the counters for each character while ensuring the order constraints are respected. This approach ensures an O(n) time complexity, which is efficient for large input sizes up to 100,000 characters.

### Solution Code
```python
def main():
    s = input().strip()
    c = h = e = f = 0
    for char in s:
        if char == 'C':
            c += 1
        elif char == 'H':
            if h < c:
                h += 1
        elif char == 'E':
            if e < h:
                e += 1
        elif char == 'F':
            if f < e:
                f += 1
    print(f)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Initialization**: Four counters (`c`, `h`, `e`, `f`) are initialized to zero to track the number of valid 'C', 'H', 'E', and 'F' characters encountered.
2. **Character Processing**:
   - For each 'C', increment the `c` counter as it can start a new subsequence.
   - For each 'H', increment the `h` counter only if there are more 'C's than 'H's encountered so far.
   - For each 'E', increment the `e` counter only if there are more 'H's than 'E's encountered so far.
   - For each 'F', increment the `f` counter only if there are more 'E's than 'F's encountered so far.
3. **Result**: The value of `f` after processing the entire string gives the maximum number of "CHEF" subsequences that can be formed, as it represents the number of valid 'F' characters that follow the required order.

This approach ensures that we efficiently count valid subsequences while respecting the order constraints, leading to an optimal solution.
