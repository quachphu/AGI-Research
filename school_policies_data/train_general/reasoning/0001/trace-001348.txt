To solve this problem, we need to determine the number of different combinations formed by the prime divisors of a given number \( N \). The solution involves computing the number of divisors of \( N \) and then adjusting for the problem's requirements.

### Approach
1. **Prime Factorization**: For each number \( N \), compute its prime factorization. This involves breaking down \( N \) into its prime factors and their respective exponents.
2. **Count Divisors**: Using the prime factorization, compute the total number of divisors of \( N \). This is done by taking the product of each exponent incremented by one (i.e., for a prime factor \( p \) with exponent \( e \), the term is \( e + 1 \)).
3. **Adjust for Combinations**: Since we need the number of combinations formed by prime divisors (excluding 1), subtract 1 from the total number of divisors.

### Solution Code
```python
import sys

def compute_combinations(n):
    if n == 1:
        return 0
    res = 1
    i = 2
    while i * i <= n:
        if n % i == 0:
            exponent = 0
            while n % i == 0:
                exponent += 1
                n = n // i
            res *= (exponent + 1)
        if n == 1:
            break
        i += 1
    if n > 1:
        res *= 2
    return res - 1

t = int(sys.stdin.readline())
for _ in range(t):
    n = int(sys.stdin.readline())
    print(compute_combinations(n))
```

### Explanation
1. **Prime Factorization**: The code iterates through potential divisors starting from 2. For each divisor, it counts how many times it divides \( N \) (the exponent). This process continues until \( N \) is reduced to 1 or a remaining prime factor.
2. **Count Divisors**: The product of each exponent incremented by 1 gives the total number of divisors. For example, if \( N = 36 \) (prime factors \( 2^2 \) and \( 3^2 \)), the number of divisors is \((2+1) * (2+1) = 9\).
3. **Adjust for Combinations**: Subtracting 1 from the total number of divisors excludes the trivial divisor 1, giving the count of valid combinations formed by prime divisors.

This approach efficiently handles the constraints, including large values of \( N \) up to \( 10^{12} \), by leveraging trial division up to the square root of \( N \) for prime factorization.
