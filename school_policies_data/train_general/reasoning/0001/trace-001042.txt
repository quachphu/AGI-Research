To solve this problem, we need to determine how many riders would call each taxi driver based on their proximity. Each rider will call the closest taxi driver, and in case of a tie in distance, the rider will choose the taxi driver with the smaller coordinate.

### Approach
1. **Input Reading**: Read the number of riders and taxi drivers, followed by their coordinates and types (rider or taxi driver).
2. **Separation**: Separate the coordinates into two lists: one for taxi drivers and one for riders.
3. **Closest Taxi Determination**: For each rider, use binary search to find the closest taxi driver. This involves:
   - Using binary search to determine the insertion point of the rider's coordinate in the sorted list of taxi coordinates.
   - Comparing the distances to the nearest taxi drivers on either side of the insertion point (if they exist).
   - Handling edge cases where the rider is before the first taxi driver or after the last taxi driver.
4. **Counting Calls**: Maintain a count of how many riders each taxi driver would receive based on the proximity check.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    m = int(input[ptr+1])
    ptr += 2
    
    x = list(map(int, input[ptr:ptr + n + m]))
    ptr += n + m
    
    t = list(map(int, input[ptr:ptr + n + m]))
    
    taxis = []
    riders = []
    for xi, ti in zip(x, t):
        if ti == 1:
            taxis.append(xi)
        else:
            riders.append(xi)
    
    counts = [0] * len(taxis)
    
    for rider in riders:
        i = bisect.bisect_left(taxis, rider)
        if i == 0:
            j = 0
        elif i == len(taxis):
            j = len(taxis) - 1
        else:
            left = taxis[i-1]
            right = taxis[i]
            d_left = rider - left
            d_right = right - rider
            if d_right < d_left:
                j = i
            elif d_left < d_right:
                j = i - 1
            else:
                j = i - 1  # tie-breaker to the left (smaller coordinate)
        counts[j] += 1
    
    print(' '.join(map(str, counts)))

main()
```

### Explanation
1. **Input Handling**: The input is read in one go for efficiency, especially given the potential size of the input.
2. **Separation of Taxis and Riders**: We iterate through the coordinates and separate them into taxis and riders based on their type.
3. **Binary Search for Proximity**: For each rider, we use `bisect.bisect_left` to find the position where the rider's coordinate would fit in the sorted list of taxi coordinates. This helps in efficiently determining the closest taxi driver(s).
