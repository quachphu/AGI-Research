To solve this problem, we need to determine the maximum amount of gold each spaceship can steal by attacking bases with defensive power less than or equal to the spaceship's attacking power. The solution involves efficiently processing the bases and querying the results using sorting and binary search.

### Approach
1. **Input Reading and Initialization**: Read the number of spaceships and bases, followed by the attacking power of each spaceship and the defensive power and gold of each base.
2. **Sorting Bases**: Sort the bases by their defensive power to facilitate efficient querying.
3. **Prefix Sum Calculation**: Compute a prefix sum array of the gold from the sorted bases. This allows quick summation of gold for any range of bases.
4. **Binary Search for Queries**: For each spaceship's attacking power, use binary search to find the maximum defensive power that the spaceship can overcome and then use the prefix sum array to get the total gold.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    s = int(input[ptr])
    ptr += 1
    b = int(input[ptr])
    ptr += 1
    
    a_list = list(map(int, input[ptr:ptr+s]))
    ptr += s
    
    bases = []
    for _ in range(b):
        d = int(input[ptr])
        ptr += 1
        g = int(input[ptr])
        ptr += 1
        bases.append((d, g))
    
    # Sort bases by defensive power
    bases.sort()
    sorted_d = [d for d, g in bases]
    sorted_g = [g for d, g in bases]
    
    # Compute prefix sums
    prefix = [0] * (len(sorted_g) + 1)
    for i in range(len(sorted_g)):
        prefix[i+1] = prefix[i] + sorted_g[i]
    
    # Process each spaceship
    result = []
    for a in a_list:
        pos = bisect.bisect_right(sorted_d, a)
        result.append(str(prefix[pos]))
    
    print(' '.join(result))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the large possible input size.
2. **Sorting Bases**: Bases are sorted by their defensive power to allow binary search operations.
3. **Prefix Sum Array**: This array is constructed to store cumulative sums of gold up to each base, allowing O(1) range sum queries.
4. **Binary Search**: For each spaceship's attacking power, we use binary search to quickly determine the rightmost base that can be attacked. The prefix sum array then gives the total gold from all bases up to that point.

This approach ensures that each query is handled efficiently in O(log n) time, making the solution scalable even for the upper constraint limits.
