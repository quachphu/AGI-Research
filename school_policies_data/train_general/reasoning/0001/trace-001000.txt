To solve this problem, we need to simulate the behavior of a smartphone displaying recent conversations based on incoming messages. The smartphone can show up to `k` most recent conversations, and each new message from a friend not currently on the screen will push older conversations down or off the screen.

### Approach
1. **Initialization**: Start with an empty list to represent the conversations currently displayed on the screen.
2. **Processing Messages**: For each incoming message:
   - Check if the conversation is already on the screen.
   - If it is not on the screen, add it to the front of the list. If the list is already at capacity (`k`), remove the oldest conversation (the last element) before adding the new one.
3. **Output**: After processing all messages, output the number of conversations displayed and their order.

### Solution Code
```python
n, k = map(int, input().split())
ids = list(map(int, input().split()))

screen = []
for id in ids:
    if id in screen:
        continue
    if len(screen) >= k:
        screen.pop()
    screen.insert(0, id)

print(len(screen))
print(' '.join(map(str, screen)))
```

### Explanation
- **Reading Input**: The input consists of two integers `n` (number of messages) and `k` (max displayed conversations), followed by a list of friend IDs sending the messages.
- **Maintaining the Screen**: We use a list `screen` to keep track of the displayed conversations. For each message:
  - If the friend's conversation is already on the screen, nothing changes.
  - If the friend's conversation is not on the screen, it is added to the front. If the screen is full, the oldest conversation (last element) is removed before adding the new one.
- **Output**: The final state of the screen is printed, showing the number of conversations and their order from top to bottom.

This approach ensures that we efficiently manage the list of conversations using basic list operations, maintaining the correct order and constraints as required. The solution handles all edge cases, including when the screen is empty or full, and when messages come from friends already on the screen.
