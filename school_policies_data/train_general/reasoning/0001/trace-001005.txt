To solve this problem, we need to find the sum of the cost function f(p, q) over all possible partitions of an array into two subsequences of equal length. The cost function is defined as the sum of absolute differences between elements of the sorted subsequences. Given the constraints, we need an efficient approach to compute the result modulo 998244353.

### Approach
1. **Sort the Array**: First, sort the array to simplify the calculation of the differences between elements.
2. **Combinatorial Factor**: Compute the binomial coefficient C(2n, n) modulo 998244353, which represents the number of ways to partition the array into two subsequences of length n.
3. **Sum of Differences**: For each valid partition, the sum of the differences between the i-th element of the first subsequence and the (i+n)-th element of the sorted array gives the required result. This is derived from the observation that the optimal partition will pair elements symmetrically around the middle of the sorted array.

### Solution Code
```python
MOD = 998244353

def main():
    import sys
    n, *rest = map(int, sys.stdin.read().split())
    a = rest[:2*n]
    a.sort()
    
    max_n = 2 * n
    factorial = [1] * (max_n + 1)
    for i in range(1, max_n + 1):
        factorial[i] = factorial[i-1] * i % MOD
    
    inv_fact = [1] * (max_n + 1)
    inv_fact[max_n] = pow(factorial[max_n], MOD-2, MOD)
    for i in range(max_n-1, -1, -1):
        inv_fact[i] = inv_fact[i+1] * (i+1) % MOD
    
    def comb(a, b):
        if a < 0 or b < 0 or a < b:
            return 0
        return factorial[a] * inv_fact[b] % MOD * inv_fact[a - b] % MOD
    
    c = comb(2*n, n)
    total = 0
    for i in range(n):
        total = (total + a[i + n] - a[i]) % MOD
    
    ans = total * c % MOD
    print(ans)
    
main()
```
