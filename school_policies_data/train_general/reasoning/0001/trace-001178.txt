To solve this problem, we need to determine the winner of a game played on an array where two players take turns removing subsegments with specific sum properties. The first player removes subsegments with an odd sum, and the second player removes subsegments with an even sum. The player who cannot make a move loses.

### Approach
1. **Total Sum Check**: First, compute the total sum of the array. If the total sum is odd, the first player can immediately remove the entire array and win.
2. **Odd Element Check**: If the total sum is even, check if there is at least one odd element in the array. If there is an odd element, the first player can remove a subsegment containing that odd element, leaving the remaining sum as odd, which forces the second player into a position where they cannot win. If there are no odd elements, the first player cannot make a valid move and loses.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
total = sum(a)
if total % 2 == 1:
    print("First")
else:
    has_odd = any(x % 2 == 1 for x in a)
    print("First" if has_odd else "Second")
```

### Explanation
1. **Total Sum Check**: The total sum of the array is computed. If this sum is odd, the first player wins immediately by taking the entire array.
2. **Odd Element Check**: If the total sum is even, we check for the presence of any odd elements. If there is at least one odd element, the first player can always make a move (by removing a subsegment containing that odd element), leading to a scenario where the second player is forced into a losing position. If there are no odd elements, the first player cannot make a valid move and thus loses.

This approach efficiently determines the winner in O(n) time, which is optimal for the given problem constraints.
