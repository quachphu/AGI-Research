To solve this problem, we need to determine the minimal number of moves required to convert exactly half of the piles of candies into squares of integers and the other half into non-squares of integers. The approach involves calculating the cost of converting each pile into either a square or a non-square and then selecting the optimal conversions to achieve the required balance.

### Approach
1. **Identify Squares**: For each pile, determine if it is already a perfect square.
2. **Conversion Costs**:
   - For a square pile, calculate the cost to convert it into a non-square. If the pile is 0, the cost is 2 (since converting to 2 is the nearest non-square). For other squares, the cost is 1 (since converting to the nearest non-square requires 1 move).
   - For a non-square pile, calculate the cost to convert it into the nearest perfect square.
3. **Determine Conversions**:
   - If the number of square piles is exactly half, no conversions are needed.
   - If there are more square piles than required, convert the excess square piles to non-squares using the least costly conversions.
   - If there are fewer square piles than required, convert the necessary non-square piles to squares using the least costly conversions.

### Solution Code
```python
import math

def main():
    import sys
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    k = n // 2
    a_info = []
    
    for num in a:
        s = math.isqrt(num)
        is_square = (s * s == num)
        cost_square = 0
        cost_non_square = 0
        if is_square:
            if num == 0:
                cost_non_square = 2
            else:
                cost_non_square = 1
        else:
            lower = s ** 2
            upper = (s + 1) ** 2
            cost_square = min(num - lower, upper - num)
        a_info.append((is_square, cost_square, cost_non_square))
    
    s = sum(1 for info in a_info if info[0])
    
    if s == k:
        print(0)
    elif s > k:
        squares = [info for info in a_info if info[0]]
        squares.sort(key=lambda x: x[2])
        needed = s - k
        total = sum(x[2] for x in squares[:needed])
        print(total)
    else:
        non_squares = [info for info in a_info if not info[0]]
        non_squares.sort(key=lambda x: x[1])
        needed = k - s
        total = sum(x[1] for x in non_squares[:needed])
        print(total)

if __name__ == "__main__":
    main()
```
