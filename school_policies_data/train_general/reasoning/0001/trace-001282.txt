To solve this problem, we need to determine the number of times Vasya uses portals to navigate through a maze from room 1 to room (n + 1). The solution involves dynamic programming to efficiently compute the number of steps required for each room.

### Approach
1. **Dynamic Programming (DP) Setup**: Define `dp[i]` as the number of steps required to exit room `i` and reach room `i + 1`.
2. **Prefix Sum Array**: Use a prefix sum array `s` to keep track of cumulative steps up to each room, which helps in efficiently calculating the sum of steps between any two rooms.
3. **Modulo Operation**: Since the result can be very large, use modulo `10^9 + 7` to keep the numbers manageable and prevent overflow.

### Solution Code
```python
n = int(input())
p = list(map(int, input().split()))
mod = 10**9 + 7

prefix = [0] * (n + 2)  # prefix[i] is sum of dp[1..i]
prefix[0] = 0

for i in range(1, n + 1):
    pi = p[i - 1]
    sum_part = (prefix[i - 1] - prefix[pi - 1]) % mod
    dp_i = (sum_part + 2) % mod
    prefix[i] = (prefix[i - 1] + dp_i) % mod

print(prefix[n] % mod)
```

### Explanation
1. **Initialization**: The prefix sum array `prefix` is initialized to store cumulative sums of steps up to each room.
2. **Loop Through Rooms**: For each room `i` from 1 to `n`:
   - **Portal Calculation**: Determine the sum of steps required from room `pi` to room `i-1` using the prefix sum array.
   - **Dynamic Programming Update**: Compute `dp[i]` as the sum of the steps from `pi` to `i-1` plus 2 (for the two portal uses).
   - **Update Prefix Sum**: Update the prefix sum array to include the steps from the current room.
3. **Result**: The final result is stored in `prefix[n]`, which gives the total steps modulo `10^9 + 7`.

This approach efficiently computes the required steps using dynamic programming and prefix sums, ensuring optimal performance even for the upper constraint of `n = 1000`.
