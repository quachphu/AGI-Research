To solve this problem, we need to determine the minimum distance from Zane's crush's house to the closest house that Zane can afford to buy. The houses are arranged in a straight line, and each adjacent pair of houses is 10 meters apart.

### Approach
1. **Input Reading**: Read the number of houses `n`, the position of the crush's house `m`, and the amount of money Zane has `k`.
2. **House Availability Check**: For each house, check if it is available (not occupied) and if its price is within Zane's budget.
3. **Distance Calculation**: For each valid house (available and affordable), calculate the distance from the crush's house. The distance is computed as the absolute difference between the house indices multiplied by 10 meters.
4. **Find Minimum Distance**: Track the minimum distance encountered among all valid houses.

### Solution Code
```python
n, m, k = map(int, input().split())
a = list(map(int, input().split()))

min_distance = float('inf')

for i in range(n):
    price = a[i]
    if price != 0 and price <= k:
        distance = abs((i + 1) - m) * 10
        if distance < min_distance:
            min_distance = distance

print(min_distance)
```

### Explanation
1. **Reading Input**: The first line of input contains three integers `n`, `m`, and `k`. The second line contains the list of house prices and availability.
2. **Loop Through Houses**: Iterate through each house, checking if it is available (non-zero price) and affordable (price ≤ k).
3. **Calculate Distance**: For each valid house, compute the distance from the crush's house using the formula `abs((house_number - m) * 10`, where `house_number` is the 1-based index of the house.
4. **Track Minimum Distance**: Keep updating the minimum distance encountered during the iteration.

This approach ensures that we efficiently check each house only once, resulting in a time complexity of O(n), which is optimal given the constraints. The solution correctly handles all edge cases and guarantees finding the minimum distance as required.
