To solve this problem, we need to determine the number of crimes that go untreated given a sequence of events where each event is either a crime or a recruitment of police officers. Each police officer can handle exactly one crime, and if no officer is available when a crime occurs, it goes untreated.

### Approach
1. **Initialization**: Start with zero available officers and zero untreated crimes.
2. **Iterate through Events**: For each event:
   - If the event is a recruitment (positive integer), add the number of recruited officers to the available pool.
   - If the event is a crime (-1), check if there are any available officers:
     - If there are, use one officer to handle the crime.
     - If there aren't, increment the count of untreated crimes.
3. **Output Result**: After processing all events, print the total number of untreated crimes.

### Solution Code
```python
n = int(input())
events = list(map(int, input().split()))

available = 0
untreated = 0

for event in events:
    if event == -1:
        if available > 0:
            available -= 1
        else:
            untreated += 1
    else:
        available += event

print(untreated)
```

### Explanation
- **Initialization**: `available` tracks the number of officers currently available, starting at 0. `untreated` counts the number of crimes that go untreated, starting at 0.
- **Processing Events**:
  - For each recruitment event (positive integer), increase the `available` count by the number of officers recruited.
  - For each crime event (-1), check if there are any officers available. If yes, reduce the `available` count by 1. If no, increment the `untreated` count by 1.
- **Efficiency**: This approach processes each event in constant time, resulting in an overall time complexity of O(n), which is efficient for the input size constraint (1 ≤ n ≤ 10^5).

This solution efficiently tracks the availability of police officers and counts untreated crimes by iterating through the events once, ensuring optimal performance.
