To solve this problem, we need to identify the k-th constellation of the Cross in a star map based on specific criteria. The Cross constellation is defined by a central star and four other stars positioned at a distance x in the four cardinal directions (up, down, left, right). The constellations are ordered by their radius, row, and column of the central star.

### Approach
1. **Grid Parsing**: Read the input grid and convert it into a boolean matrix where each cell indicates the presence of a star.
2. **Iterate Over Possible Radii**: For each possible radius x starting from 1, check all potential central stars to see if they form a valid Cross constellation.
3. **Check Validity**: For each central star, verify if the four required positions (up, down, left, right) at distance x are all stars.
4. **Early Termination**: Once the k-th constellation is found, terminate early to optimize performance.

### Solution Code
```python
n, m, k = map(int, input().split())

# Create a grid with 1-based indices. grid[0] is a dummy row, columns 0 and m+1 also dummy.
grid = [[False] * (m + 2)]  # Row 0 (dummy)
for _ in range(n):
    line = input().strip()
    row = [False] * (m + 2)  # Initialize all to False (dummy columns 0 and m+1)
    for j in range(len(line)):
        if line[j] == '*':
            row[j + 1] = True  # 1-based column indices
    grid.append(row)

max_x_global = min((n - 1) // 2, (m - 1) // 2)

        break
    for i in range(1, n + 1):
        if found:
            break
        for j in range(1, m + 1):
            if not grid[i][j]:
                continue
            current_max_x = min(i - 1, n - i, j - 1, m - j)
            if x > current_max_x:
                continue
            # Check all four directions
            if (grid[i - x][j] and grid[i + x][j] and
                grid[i][j - x] and grid[i][j + x]):
                crosses.append((x, i, j))
                if len(crosses) == k:
                    found = True
                    break
        # Break inner j loop if found

    print(i, j - x)
    print(i, j + x)

    print(-1)
```

### Explanation
1. **Grid Parsing**: The input is read and converted into a boolean grid where each cell is `True` if there is a star and `False` otherwise. This grid uses 1-based indexing for easier coordinate management.
2. **Radius Iteration**: We iterate over possible radii starting from 1 up to the maximum possible radius determined by the grid dimensions.
3. **Central Star Check**: For each potential central star (i, j), we determine the maximum possible radius it can have. If the current radius x is valid, we check the four required positions to confirm they are all stars.
4. **Early Termination**: Once the k-th valid constellation is found, the loops terminate early to avoid unnecessary checks, optimizing the performance.

This approach ensures that we efficiently find the k-th constellation by processing the stars in the correct order and terminating as soon as the required constellation is identified.
