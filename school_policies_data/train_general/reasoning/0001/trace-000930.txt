To solve this problem, we need to find the longest substring which is a prefix of both the given string and its reversed version. This problem can be efficiently solved using the Knuth-Morris-Pratt (KMP) algorithm's failure function, which helps in determining the longest prefix that is also a suffix.

### Approach
1. **Understanding the Problem**: The task is to find the longest substring that is a prefix of both the original string and its reversed version. This can be translated into finding the longest prefix of the original string that is also a suffix.
2. **KMP Failure Function**: The KMP algorithm's failure function (also known as the Longest Prefix Suffix array) is used to compute the longest proper prefix which is also a suffix for all substrings of the given string. This function helps in efficiently determining the required longest substring.
3. **Algorithm Steps**:
   - For each test case, read the string.
   - Compute the failure function array for the string.
   - The last value in this array gives the length of the longest prefix which is also a suffix.
   - If this value is greater than 0, output it; otherwise, output -1.

            j = lps[i-1]
            while j > 0 and s[i] != s[j]:
                j = lps[j-1]
            if s[i] == s[j]:
                j += 1
            lps[i] = j
        max_len = lps[-1]
        if max_len == 0:
            print(f"Case {case}: -1")
        else:
            print(f"Case {case}: {max_len}")

if __name__ == "__main__":
    main()

### Explanation
1. **Reading Input**: The number of test cases is read first, followed by each string input.
2. **Computing LPS Array**: For each string, the Longest Prefix Suffix (LPS) array is computed. This array is built by iterating through the string and using the previously computed values to efficiently determine the longest prefix which is also a suffix for each position.
3. **Determining Result**: The last value in the LPS array gives the length of the longest prefix which is also a suffix. If this value is zero, it means no such prefix exists, and we output -1. Otherwise, the value itself is the result.

This approach ensures that the solution is efficient with a time complexity of O(n) per string, where n is the length of the string, making it suitable for large input sizes up to 100,000 characters.
