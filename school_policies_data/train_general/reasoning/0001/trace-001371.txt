import sys
import math

def compute_probability(N):
    m = int(math.isqrt(N))
    S = 0
    # Sum for k from 1 to m
    for k in range(1, m + 1):
        S += N // k

    for q in range(1, m + 1):

        upper = N // q

To solve this problem, we need to calculate the probability that the Greatest Common Divisor (GCD) of two randomly chosen integers A and B (both within the range [1, N]) equals B. The result should be presented as an irreducible fraction.

### Approach
1. **Understanding the Problem**: The GCD of A and B equals B if and only if B is a divisor of A. This means we need to count all pairs (A, B) where B divides A.
2. **Efficient Sum Calculation**: Directly iterating over all possible values of B for large N (up to 1e9) is infeasible. Instead, we use a mathematical approach to compute the sum of divisors efficiently.
3. **Sum of Divisors**: The sum of the count of divisors (floor(N/B) for B from 1 to N) can be computed in O(sqrt(N)) time by leveraging the fact that many values of B will yield the same quotient when divided into N.
4. **Fraction Reduction**: After computing the sum, we reduce the fraction using the greatest common divisor (GCD) of the sum and N².

### Solution Code
```python
import sys
import math

def compute_probability(N):
    m = int(math.isqrt(N))
    S = 0
    # Sum for k from 1 to m
    for k in range(1, m + 1):
        S += N // k
    # Sum for q from 1 to m
    for q in range(1, m + 1):
        lower = (N // (q + 1)) + 1
        upper = N // q
        if upper <= m:
            continue
        lower_k = max(lower, m + 1)
        if lower_k > upper:
            continue
        count = upper - lower_k + 1
        S += q * count
    denominator = N * N
    g = math.gcd(S, denominator)
    return f"{S//g}/{denominator//g}"

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        N = int(input[i])
        print(compute_probability(N))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Sum Calculation**: The function `compute_probability` calculates the sum of floor(N/k) for k from 1 to N using an efficient method that splits the computation into two parts: direct summation for smaller values and grouped summation for larger values using the properties of integer division.
2. **Efficiency**: By splitting the summation into two parts (values up to sqrt(N) and values beyond), we reduce the time complexity to O(sqrt(N)), making it feasible for large N.
3. **Fraction Reduction**: The result is presented as a reduced fraction using the GCD of the sum and N², ensuring the fraction is in its simplest form.

This approach efficiently handles the constraints and provides the correct result in a manageable time frame even for the upper limits of the input values.
