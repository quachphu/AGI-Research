To solve this problem, we need to generate the Kth lexicographically smallest sequence of length N consisting of the characters 'O' and 'Z' such that no two 'Z' characters are adjacent. If K exceeds the number of valid sequences, we should return -1.

### Approach
1. **Dynamic Programming (DP) Precomputation**: 
   - We precompute the number of valid sequences for each length up to 1000 using dynamic programming. The state `dp[m][s]` represents the number of valid sequences of length `m` where the previous character was 'Z' if `s` is 1, and not 'Z' if `s` is 0.
   - The recurrence relations are:
     - `dp[m][0] = dp[m-1][0] + dp[m-1][1]` (if the previous character was not 'Z', the next can be 'O' or 'Z')
     - `dp[m][1] = dp[m-1][0]` (if the previous character was 'Z', the next must be 'O')

2. **Sequence Construction**:
   - For each test case, we determine the total number of valid sequences for the given N. If K exceeds this number, output -1.
   - Construct the sequence character by character. At each step, decide whether to place 'O' or 'Z' based on the number of valid sequences that can be formed with each choice, adjusting K accordingly.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    
    # Precompute dp up to m=1000
    max_m = 1000
    dp = [[0] * 2 for _ in range(max_m + 1)]
    dp[0][0] = 1
    dp[0][1] = 1
    for m in range(1, max_m + 1):
        dp[m][0] = dp[m-1][0] + dp[m-1][1]
        dp[m][1] = dp[m-1][0]
    
    for _ in range(T):
        N = int(input[idx])
        K = int(input[idx + 1])
        idx += 2
        
        if N == 0:
            print("")
            continue
        
        total = dp[N][0]
        if K > total:
            print(-1)
            continue
        
        res = []
        prev_z = False
        for i in range(N):
            remaining = (N - 1) - i
            if prev_z:
                res.append('O')
                prev_z = False
            else:
                cnt_o = dp[remaining][0]
                if K <= cnt_o:
                    res.append('O')
                    prev_z = False
                else:
                    K -= cnt_o
                    res.append('Z')
                    prev_z = True
        print(''.join(res))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precomputation**:
   - The DP table `dp` is precomputed up to the maximum possible value of N (1000). This allows us to quickly determine the number of valid sequences for any given N and state.

2. **Sequence Construction**:
   - For each test case, we check if K is within the bounds of valid sequences. If not, output -1.
   - Construct the sequence by iterating through each position, using the precomputed DP values to decide whether to place 'O' or 'Z' while maintaining the lexicographical order and adjacency constraints.

This approach efficiently handles the constraints and ensures that we can quickly determine the Kth sequence using precomputed values and a linear scan through the sequence length.
