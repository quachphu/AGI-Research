To solve this problem, we need to determine the number of magical subarrays in a given array. A magical subarray is defined as a subarray where all elements are the same, which implies that the minimum and maximum values within the subarray are identical.

### Approach
1. **Identify Consecutive Runs**: The key insight is that any subarray with all elements equal is a magical subarray. Therefore, we first need to identify consecutive runs of the same element in the array.
2. **Calculate Subarrays for Each Run**: For each run of consecutive elements of length `l`, the number of magical subarrays is given by the formula `l * (l + 1) / 2`. This formula is derived from the sum of the first `l` natural numbers, which counts all possible non-empty subarrays within the run.
3. **Sum the Results**: Sum the number of magical subarrays for all identified runs to get the final result.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))

if not a:
    print(0)
else:
    current_val = a[0]
    current_length = 1
    runs = []
    
    for num in a[1:]:
        if num == current_val:
            current_length += 1
        else:
            runs.append(current_length)
            current_val = num
            current_length = 1
    runs.append(current_length)
    
    total = sum(l * (l + 1) // 2 for l in runs)
    print(total)
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` followed by an array of `n` integers.
2. **Handling Edge Cases**: If the array is empty, we immediately return 0.
3. **Identifying Runs**: We iterate through the array, grouping consecutive identical elements into runs. Each time a different element is encountered, the current run length is recorded, and a new run is started.
4. **Calculating Subarrays**: For each run length `l`, the number of subarrays is calculated using the formula `l * (l + 1) // 2`, which efficiently sums the count of all possible non-empty subarrays within the run.
5. **Summing Results**: The results from all runs are summed to produce the final count of magical subarrays.

This approach ensures that we efficiently count all valid subarrays in linear time, making it suitable for large input sizes up to 100,000 elements.
