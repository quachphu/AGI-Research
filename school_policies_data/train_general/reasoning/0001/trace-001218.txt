To solve this problem, we need to find the longest strange subsequence from an array of integers. A sequence is considered strange if the absolute difference between any pair of its elements is greater than or equal to the maximum element in the sequence.

### Approach
1. **Identify Non-positive and Positive Elements**: Split the array into non-positive elements (≤ 0) and positive elements (> 0).
2. **Check for All Non-positive Elements**: If there are no positive elements, the entire array is a valid strange subsequence.
3. **Handle Positive Elements**: If there are positive elements, consider the smallest positive element (min_pos) and determine the longest subsequence that can include this element along with non-positive elements spaced at least min_pos apart.
4. **Greedy Selection of Non-positive Elements**: Sort the non-positive elements and use a greedy approach to select the maximum number of elements such that each consecutive pair is at least min_pos apart.
