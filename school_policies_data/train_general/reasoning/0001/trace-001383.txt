To solve this problem, we need to determine if it's possible to reduce an array of positive integers to a single element using a series of allowed moves. The allowed move involves removing the smaller of two elements if their absolute difference is at most 1.

### Approach
The key insight is that after sorting the array, if the maximum difference between any two consecutive elements is greater than 1, it becomes impossible to merge all elements down to a single one. This is because any gap larger than 1 between consecutive elements means there will be elements that cannot be merged together, preventing further reduction.

The steps to solve the problem are as follows:
1. For each test case, check if the array length is 1. If so, the answer is immediately "YES".
2. Sort the array.
3. Compute the maximum difference between consecutive elements in the sorted array.
4. If the maximum difference is at most 1, print "YES"; otherwise, print "NO".

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    if n == 1:
        print("YES")
    else:
        a_sorted = sorted(a)
        max_diff = 0
        for i in range(1, n):
            diff = a_sorted[i] - a_sorted[i-1]
            if diff > max_diff:
                max_diff = diff
        print("YES" if max_diff <= 1 else "NO")
```

### Explanation
1. **Input Reading**: The number of test cases is read first. For each test case, the length of the array and the array elements are read.
2. **Single Element Check**: If the array has only one element, the answer is "YES" because no moves are needed.
3. **Sorting**: The array is sorted to facilitate checking consecutive elements.
4. **Max Difference Calculation**: By iterating through the sorted array, we compute the maximum difference between consecutive elements.
5. **Result Determination**: If the maximum difference is at most 1, it means all elements can be merged down to one, otherwise, it's impossible.

This approach efficiently checks the necessary condition using sorting and a linear scan, ensuring the solution is both correct and optimal for the given constraints.
