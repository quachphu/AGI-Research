To solve this problem, we need to count the number of lifelines (paths of length 2) in a tree structure. A tree is a connected acyclic graph, and each path of length 2 consists of two edges connected through a common vertex.

### Approach
The key insight is that each node in the tree with a degree of `d` contributes `d * (d - 1) / 2` lifelines. This is because each pair of edges connected to the node forms a path of length 2. By summing this value for all nodes, we get the total number of lifelines in the tree.

1. **Read Input**: Read the number of vertices and the edges connecting them.
2. **Calculate Degrees**: Track the degree (number of edges connected) of each vertex.
3. **Compute Lifelines**: For each vertex, compute the number of lifelines contributed using the formula `d * (d - 1) / 2` where `d` is the degree of the vertex. Sum these values to get the total number of lifelines.

### Solution Code
```python
def count_lifelines():
    import sys
    n = int(sys.stdin.readline())
    degrees = [0] * (n + 1)
    for _ in range(n - 1):
        a, b = map(int, sys.stdin.readline().split())
        degrees[a] += 1
        degrees[b] += 1
    total = 0
    for i in range(1, n + 1):
        d = degrees[i]
        if d >= 2:
            total += d * (d - 1) // 2
    print(total)

count_lifelines()
```

### Explanation
1. **Reading Input**: The input is read using standard input. The first line gives the number of vertices `n`, followed by `n-1` lines each describing an edge between two vertices.
2. **Tracking Degrees**: We maintain an array `degrees` where `degrees[i]` represents the number of edges connected to vertex `i`.
3. **Calculating Contributions**: For each vertex, if it has a degree `d`, the number of paths of length 2 it contributes is given by the combination formula `C(d, 2) = d * (d - 1) / 2`. This value is summed for all vertices to get the total number of lifelines.

This approach efficiently computes the result in linear time relative to the number of vertices, making it suitable for the given problem constraints.
