To solve this problem, Patrick needs to visit both shops and return home while minimizing the total distance traveled. The solution involves considering all possible routes and selecting the shortest one.

### Approach
The problem can be broken down into evaluating four possible routes:
1. Direct route: House -> Shop1 -> Shop2 -> House.
2. Two separate round trips: House -> Shop1 -> House -> Shop2 -> House.
3. Round trip via Shop1 and the connecting road: House -> Shop1 -> Shop2 -> Shop1 -> House.
4. Round trip via Shop2 and the connecting road: House -> Shop2 -> Shop1 -> Shop2 -> House.

For each of these routes, we calculate the total distance and select the minimum among them.

### Solution Code
```python
d1, d2, d3 = map(int, input().split())
option1 = d1 + d2 + d3
option2 = 2 * (d1 + d2)
option3 = 2 * (d1 + d3)
option4 = 2 * (d2 + d3)
print(min(option1, option2, option3, option4))
```

### Explanation
1. **Direct Route (House -> Shop1 -> Shop2 -> House)**: This route's distance is the sum of all three paths: `d1 + d2 + d3`.
2. **Two Round Trips (House -> Shop1 -> House -> Shop2 -> House)**: This involves two separate round trips to each shop, resulting in `2 * (d1 + d2)`.
3. **Round Trip via Shop1 (House -> Shop1 -> Shop2 -> Shop1 -> House)**: This route uses the connecting road twice, giving `2 * (d1 + d3)`.
4. **Round Trip via Shop2 (House -> Shop2 -> Shop1 -> Shop2 -> House)**: Similarly, this uses the connecting road twice but starts with Shop2, resulting in `2 * (d2 + d3)`.

By evaluating all these possible routes, we ensure that we find the shortest path that allows Patrick to visit both shops and return home efficiently. The minimum of these four calculated values is the solution.
