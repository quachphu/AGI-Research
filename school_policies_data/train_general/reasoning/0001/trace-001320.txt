To solve this problem, we need to count the number of "good" substrings in a binary string. A substring is considered good if its length is equal to its decimal value when interpreted as a binary number. 

### Approach
1. **Understanding the Problem**: Each substring is good if its length equals its decimal value. For example, the binary substring "011" has a length of 3 and a decimal value of 3, making it a good substring.
2. **Efficient Calculation**: Directly checking all possible substrings would be computationally expensive. Instead, we leverage the fact that the decimal value of a binary substring of length `k` can be at most `2^k - 1`, which grows exponentially. Therefore, for practical purposes, we only need to check substrings of lengths from 1 to 19 (since values for longer substrings will exceed their lengths).
3. **Sliding Window Technique**: For each possible length `k` (from 1 to 19), we use a sliding window approach to efficiently compute the decimal value of each substring of length `k` in linear time. This avoids redundant calculations and ensures we process each substring in constant time after the initial setup.

### Solution Code
```python
def count_good_substrings(s):
    n = len(s)
    count = 0
    for k in range(1, 20):
        if k > n:
            continue
        current_num = 0
        for j in range(k):
            current_num <<= 1
            if s[j] == '1':
                current_num += 1
        if current_num == k:
            count += 1
        for i in range(1, n - k + 1):
            left_bit = s[i-1] == '1'
            current_num = (current_num - (left_bit << (k-1))) << 1
            new_bit = s[i + k - 1] == '1'
            current_num += new_bit
            if current_num == k:
                count += 1
    return count

t = int(input())
for _ in range(t):
    s = input().strip()
    print(count_good_substrings(s))
```

### Explanation
1. **Reading Input**: The number of test cases `t` is read first. For each test case, the binary string `s` is read.
2. **Iterating Over Possible Lengths**: For each possible length `k` from 1 to 19, we check if `k` is within the bounds of the string length.
3. **Initial Window Calculation**: The decimal value of the first window of length `k` is computed using bitwise operations.
4. **Sliding Window**: Using a sliding window technique, we efficiently update the decimal value of the current window by removing the contribution of the leftmost bit and adding the new rightmost bit. This allows us to check each subsequent substring in constant time.
5. **Counting Good Substrings**: Whenever the decimal value of a window equals its length `k`, we increment the count.

This approach ensures that we efficiently count all good substrings in linear time relative to the length of the string, making it feasible for large input sizes.
