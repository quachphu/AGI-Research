To solve this problem, we need to determine the number of unique cities the Monk has bought based on the roads he purchased. Each road connects two cities, and the Monk must own both cities connected by each road. The task is to count the distinct cities across all roads for each test case.

### Approach
1. **Input Reading**: Read all input at once and split it into a list of strings for easier processing.
2. **Processing Each Test Case**:
   - For each test case, read the number of roads.
   - For each road, read the two cities it connects and add these cities to a set to ensure uniqueness.
3. **Output the Result**: The size of the set after processing all roads in a test case gives the number of unique cities.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        E = int(input[ptr])
        ptr += 1
        cities = set()
        for _ in range(E):
            x = int(input[ptr])
            y = int(input[ptr + 1])
            cities.add(x)
            cities.add(y)
            ptr += 2
        print(len(cities))

main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and split into a list of strings. This allows us to process the input sequentially using a pointer.
2. **Using a Set for Uniqueness**: By adding each city (from each road) to a set, we automatically handle duplicates, as sets do not allow duplicate entries.
3. **Handling Multiple Test Cases**: The outer loop processes each test case individually, ensuring that each test case's data is handled in isolation from others.

This approach ensures that we efficiently count the unique cities using minimal space and time complexity, making the solution both optimal and easy to understand.
