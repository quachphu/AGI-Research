3. **Operation Handling**:
   - **Insert (0 x)**: Check if the element is already present in the set. If not, add it and print the new size.
   - **Find (1 x)**: Check if the element is present and print 1 or 0 accordingly.
   - **Delete (2 x)**: Remove the element if it exists in the set.

```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    q = int(input[ptr])
    ptr += 1

        op = input[ptr]
        x = int(input[ptr + 1])
        ptr += 2
        if op == '0':

                s.add(x)
            print(len(s))
        elif op == '1':
            print(1 if x in s else 0)
        elif op == '2':
            if x in s:
                s.remove(x)
                
if __name__ == "__main__":
    main()
```

- **Processing Queries**: Each query is processed by checking the operation type and performing the corresponding action on the set. The results for insert and find operations are printed immediately as required.
