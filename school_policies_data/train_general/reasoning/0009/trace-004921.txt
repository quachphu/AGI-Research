To solve this problem, we need to efficiently handle two types of queries on an array of 500,000 elements. The challenge is to process up to 500,000 queries efficiently, especially when summing elements that meet specific modular conditions.

### Approach
The key insight is to use a combination of direct updates and precomputed sums for small divisors, while handling larger divisors with direct computation. This approach leverages the fact that small divisors can be efficiently managed using a precomputed 2D array, whereas larger divisors will have fewer elements to sum, making direct computation feasible.

1. **Threshold Selection**: We choose a threshold (B = 707) based on the square root of the maximum array size. This allows us to balance between precomputing sums for small divisors and direct computation for larger divisors.

2. **Precomputed Sums for Small Divisors**: For each divisor (x) up to the threshold, we maintain a 2D array `sum_small` where `sum_small[x][y]` stores the sum of elements at positions congruent to `y` modulo `x`.

3. **Direct Updates**: For each update query, we update the actual array and adjust the relevant entries in the `sum_small` array for all small divisors.

4. **Efficient Query Handling**: For sum queries with small divisors, we directly use the precomputed sums. For larger divisors, we compute the sum by iterating through the relevant elements, which is feasible due to the smaller number of elements involved.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    q = int(input[ptr])
    ptr += 1

    max_size = 500000
    B = 707  # Approximately sqrt(500000)

    a = [0] * (max_size + 1)  # a[1..500000]

    # Initialize sum_small[x][y] for x from 1 to B
    sum_small = []
    for x in range(B + 1):
        sum_small.append([0] * x)  # sum_small[0] is unused

    for _ in range(q):
        t = int(input[ptr])
        x = int(input[ptr + 1])
        y = int(input[ptr + 2])
        ptr += 3

        if t == 1:
            # Update query: add y to a[x]
            a[x] += y
            # Update sum_small for all x_small <= B
            for x_small in range(1, B + 1):
                rem = x % x_small
                sum_small[x_small][rem] += y
        else:
            # Sum query: compute sum of a[i] where i ≡ y mod x
            if x <= B:
                print(sum_small[x][y])
            else:
                current = y
                if current == 0:
                    current = x
                total = 0
                while current <= max_size:
                    total += a[current]
                    current += x
                print(total)

if __name__ == "__main__":
    main()
```

### Explanation
- **Threshold Handling**: By choosing a threshold (B = 707), we precompute sums for all divisors up to this threshold. This allows us to answer sum queries for small divisors in constant time.
- **Efficient Updates**: For each update, we not only modify the array but also adjust the precomputed sums for all relevant small divisors, ensuring that future sum queries can be answered quickly.
- **Direct Computation for Large Divisors**: For divisors larger than the threshold, we compute the sum directly by iterating through the relevant indices. This is efficient because the number of such indices is limited by the size of the threshold.

This approach ensures that both update and sum queries are handled efficiently, making the solution scalable even for the upper limits of input constraints.
