To solve this problem, we need to determine the skills a character will have after transmigration in a role-playing game, along with their respective levels. The process involves reducing the levels of existing skills, removing those that fall below a threshold, and adding new class-specific skills if they are not already present.

### Approach
1. **Input Parsing**: Read the number of current skills, the number of class-specific skills, and the reduction coefficient. Convert the reduction coefficient into an integer to avoid floating-point inaccuracies.
2. **Skill Reduction**: For each existing skill, apply the reduction coefficient and floor the result. If the resulting level is less than 100, the skill is discarded.
3. **Add Class-Specific Skills**: Add each class-specific skill if it is not already present after the reduction step, setting its level to 0.
4. **Sorting and Output**: Collect all remaining skills, sort them lexicographically, and print the results.

### Solution Code
```python
n, m, k_str = input().split()
n = int(n)
m = int(m)

# Parse k into a numerator to avoid floating point inaccuracies
parts = k_str.split('.')
integer_part = parts[0]
decimal_part = parts[1] if len(parts) > 1 else '00'
k_numerator = int(integer_part) * 100 + int(decimal_part)

current_skills = {}
for _ in range(n):
    name, exp = input().split()
    current_skills[name] = int(exp)

processed_skills = {}
for name, exp in current_skills.items():
    new_exp = (exp * k_numerator) // 100
    if new_exp >= 100:
        processed_skills[name] = new_exp

class_skills = [input().strip() for _ in range(m)]

for skill in class_skills:
    if skill not in processed_skills:
        processed_skills[skill] = 0

sorted_skills = sorted(processed_skills.items())

print(len(sorted_skills))
for name, exp in sorted_skills:
    print(f"{name} {exp}")
```

### Explanation
1. **Input Parsing**: The input is read and parsed into integers and strings. The reduction coefficient is converted into an integer to handle it as a fraction (e.g., 0.75 becomes 75/100).
2. **Skill Reduction**: Each skill's level is multiplied by the reduction coefficient (handled as an integer fraction) and floored. Skills with levels below 100 after reduction are discarded.
3. **Class-Specific Skills**: Each class-specific skill is checked against the processed skills. If not present, it is added with a level of 0.
4. **Sorting and Output**: The remaining skills are sorted lexicographically and printed in the required format.

This approach ensures accuracy by avoiding floating-point arithmetic issues and efficiently handles the constraints and requirements of the problem.
