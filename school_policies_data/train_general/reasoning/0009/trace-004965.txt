To solve this problem, we need to determine how many candies each student and the teacher will receive after splitting the candies as per the given rules. The solution involves efficiently dividing the candies such that each student gets an equal share while the teacher keeps any remaining candies that can't be evenly distributed.

### Approach
1. **Problem Analysis**:
   - The teacher distributes candies to students such that each student gets an equal number of candies.
   - If the number of candies (N) is more than the number of students (K), the teacher repeatedly gives 1 candy to each student until there are fewer candies left than the number of students.
   - The remaining candies after this distribution are kept by the teacher.

2. **Key Insight**:
   - The number of candies each student gets is equivalent to the integer division of N by K.
   - The remaining candies that the teacher keeps are the remainder of this division.

3. **Handling Edge Cases**:
   - If there are no students (K = 0), all candies are kept by the teacher.
   - If the number of candies is exactly divisible by the number of students, the teacher keeps 0 candies.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        N = int(input[idx])
        K = int(input[idx + 1])
        idx += 2
        if K == 0:
            print(0, N)
        else:
            students = N // K
            teacher = N % K
            print(students, teacher)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read all at once and split into a list of strings to handle any whitespace issues.
- **Processing Each Test Case**: For each test case, we read the values of N (number of candies) and K (number of students).
- **Division and Remainder Calculation**:
  - If there are no students (K = 0), the output is `0` candies per student and `N` candies for the teacher.
  - Otherwise, the integer division `N // K` gives the number of candies each student receives, and the remainder `N % K` gives the candies the teacher keeps.

This approach efficiently computes the result using basic arithmetic operations, ensuring it handles the large values up to \(2^{33} - 1\) as specified in the problem constraints.
