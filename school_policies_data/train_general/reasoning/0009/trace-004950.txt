To solve this problem, we need to determine the number of distinct ways to select leaders for each group of friends at Vasya's party, where the leader is the member with the highest knowledge level. The solution involves finding connected components in a graph and calculating the number of potential leaders for each component.

### Approach
1. **Union-Find Data Structure (Disjoint Set Union - DSU):** This helps efficiently group friends into connected components. Each edge in the graph is processed to union the nodes it connects.
2. **Component Identification:** After processing all edges, each node's root is determined to identify its component.
3. **Max Knowledge Calculation:** For each component, find the maximum knowledge level and count how many members have this level.
4. **Result Calculation:** The total number of ways to select leaders is the product of the counts from each component, taken modulo \(10^9 + 7\).

### Solution Code
```python
import sys
MOD = 10**9 + 7

class DSU:
    def __init__(self, size):
        self.parent = list(range(size + 1))  # 1-based indexing
        self.rank = [1] * (size + 1)
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return
        if self.rank[x_root] < self.rank[y_root]:
            self.parent[x_root] = y_root
        else:
            self.parent[y_root] = x_root
            if self.rank[x_root] == self.rank[y_root]:
                self.rank[x_root] += 1

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    m = int(input[ptr])
    ptr += 1
    knowledge = list(map(int, input[ptr:ptr + n]))
    ptr += n
    
    dsu = DSU(n)
    for _ in range(m):
        u = int(input[ptr])
        ptr += 1
        v = int(input[ptr])
        ptr += 1
        dsu.union(u, v)
    
    # Group nodes by their root component
    components = {}
    for u in range(1, n + 1):
        root = dsu.find(u)
        if root not in components:
            components[root] = []
        components[root].append(u)
    
    result = 1
    for comp in components.values():
        max_k = max(knowledge[u - 1] for u in comp)
        count = sum(1 for u in comp if knowledge[u - 1] == max_k)
        result = (result * count) % MOD
    
    print(result)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Union-Find Initialization:** Each node starts as its own parent. The union operation merges two nodes' sets if they are connected by an edge.
2. **Component Grouping:** After processing all edges, nodes are grouped by their root parent, which identifies their connected component.
3. **Max Knowledge and Count:** For each component, the maximum knowledge level is found, and the count of nodes with this level is determined.
4. **Result Calculation:** The product of these counts across all components gives the number of ways to select leaders, modulo \(10^9 + 7\).

This approach efficiently handles up to \(10^5\) nodes and edges, ensuring optimal performance using path compression and union by rank in the DSU.
