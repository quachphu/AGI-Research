To solve this problem, we need to generate rectangles of specified dimensions using the '#' character. Each rectangle is defined by its height (H) and width (W), and the input consists of multiple such datasets until both H and W are zero. Each rectangle must be followed by a blank line.

### Approach
1. **Reading Input:** Continuously read input lines until encountering a line with both H and W as zero.
2. **Generating Rectangles:** For each valid dataset (H, W), generate a rectangle by printing H lines, each containing W '#' characters.
3. **Blank Line After Each Dataset:** After printing each rectangle, output a blank line to separate consecutive datasets.

### Solution Code
```python
def main():
    import sys
    while True:
        line = sys.stdin.readline()
        if not line:
            break
        H, W = map(int, line.strip().split())
        if H == 0 and W == 0:
            break
        for _ in range(H):
            print('#' * W)
        print()

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input:** The code reads each line from standard input. If the line contains "0 0", the loop terminates.
- **Generating Rectangles:** For each valid dataset, a loop runs H times, each iteration printing a string of W '#' characters.
- **Blank Line:** After generating all lines of the rectangle, an additional `print()` statement ensures a blank line follows each dataset.

This approach ensures that each rectangle is printed correctly and consistently formatted with a blank line after each dataset, as required.
