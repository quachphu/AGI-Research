To solve this problem, we need to determine the minimum number of bombs required to destroy all one-dimensional kingdoms represented as intervals on the real line. A bomb placed at a point x can destroy all intervals that include x.

### Approach
The optimal strategy to solve this problem is based on a greedy algorithm. The key insight is to sort the intervals by their right endpoints. By placing a bomb at the right endpoint of the earliest finishing interval, we can cover as many overlapping intervals as possible, thereby minimizing the number of bombs needed.

Here are the steps to follow:
1. **Sort Intervals**: Sort all intervals by their right endpoints in ascending order.
2. **Greedy Placement**: Iterate through the sorted intervals and place a bomb at the right endpoint of the current interval if it is not already covered by the last placed bomb. This ensures that each bomb covers the maximum possible subsequent intervals.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        intervals = []
        for _ in range(N):
            a = int(input[ptr])
            b = int(input[ptr + 1])
            intervals.append((a, b))
            ptr += 2
        # Sort intervals by their end points
        intervals.sort(key=lambda x: x[1])
        count = 0
        last_bomb = -float('inf')
        for a, b in intervals:
            if a > last_bomb:
                count += 1
                last_bomb = b
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints. The input is split into a list of strings for easy parsing.
2. **Sorting Intervals**: The intervals are sorted based on their right endpoints using a lambda function. This ensures that we always consider the interval that ends the earliest first.
3. **Greedy Bomb Placement**: We initialize `last_bomb` to negative infinity to handle the first interval correctly. For each interval, if its start is greater than the position of the last bomb, we place a new bomb at its end and update `last_bomb` to this new position. This ensures that each bomb covers as many subsequent intervals as possible.

This approach efficiently minimizes the number of bombs by leveraging the greedy strategy of covering the earliest finishing intervals first, ensuring optimal coverage with the least number of bombs.
