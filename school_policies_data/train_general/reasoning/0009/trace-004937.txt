The solution involves calculating the probability based on the XOR sum of the chosen values from each card, considering each card can be placed either face up or down.

### Approach
1. **Problem Analysis**: The game of Nim is won by the first player if the XOR of all pile sizes is non-zero. In Gambling Nim, each card can be either of two values, leading to different possible configurations. We need to compute the probability that the initial configuration's XOR sum is non-zero.

2. **Key Insight**: The problem reduces to determining the number of configurations where the XOR sum of the chosen values (each card's face-up or face-down value) is zero. This can be efficiently solved using linear algebra over the binary field (GF(2)).

3. **Gaussian Elimination over GF(2)**: We construct a basis for the vector space formed by the XOR differences of the card values. The rank of this basis helps determine the number of configurations leading to a zero XOR sum.

4. **Probability Calculation**: If the target XOR sum (initial XOR of face-up values) cannot be represented using the basis, the probability of Petya winning is 1. Otherwise, it is determined by the rank of the basis.

### Solution Code
```python
n = int(input())
s = 0
basis = [0] * 60  # For bits 0 to 59

for _ in range(n):
    a, b = map(int, input().split())
    s ^= a
    d = a ^ b
    if d == 0:
        continue
    current = d
    for i in reversed(range(60)):
        if (current >> i) & 1:
            if basis[i] == 0:
                basis[i] = current
                break
            else:
                current ^= basis[i]

# Check if s can be represented by the basis
copy_s = s
for i in reversed(range(60)):
    if (copy_s >> i) & 1:
        if basis[i] != 0:
            copy_s ^= basis[i]

if copy_s != 0:
    print("1/1")

    r = sum(1 for x in basis if x != 0)
    numerator = (1 << r) - 1
    denominator = 1 << r
```
