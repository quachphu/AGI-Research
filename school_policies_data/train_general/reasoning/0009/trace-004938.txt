To solve this problem, we need to find the lexicographically smallest string possible by shifting exactly one non-empty substring of the given string one step backward in the alphabet. The key is to identify the optimal substring to shift such that the resulting string is the smallest possible.

### Approach
1. **Identify All 'a's Case**: If all characters in the string are 'a', the optimal solution is to shift the last character to 'z', as this results in the lexicographically smallest possible string under the given constraints.
2. **Find the First Non-'a' Character**: Locate the first character that is not 'a'. This character and subsequent characters (until the next 'a' or the end of the string) form the optimal substring to shift.
3. **Extend the Substring**: From the first non-'a' character, extend the substring as far right as possible while all characters in the substring are non-'a'. Shifting these characters will convert each to the previous letter in the alphabet, thus minimizing the lexicographic order.

### Solution Code
```python
s = input().strip()

if all(c == 'a' for c in s):
    if len(s) == 1:
        print('z')
    else:
        print(s[:-1] + 'z')
else:
    # Find the first non-'a' character
    first = None
    for i in range(len(s)):
        if s[i] != 'a':
            first = i
            break
    
    # Find the end of the consecutive non-'a' substring starting at first
    j = first
    while j + 1 < len(s) and s[j + 1] != 'a':
        j += 1
    
    # Shift the characters from first to j
    res = list(s)
    for k in range(first, j + 1):
        if res[k] == 'a':
            res[k] = 'z'  # This case shouldn't happen due to the loop above
        else:
            res[k] = chr(ord(res[k]) - 1)
    
    print(''.join(res))
```

### Explanation
1. **Check for All 'a's**: If the string consists entirely of 'a's, we handle this special case by converting the last character to 'z', which is the least detrimental change possible.
2. **Locate the Optimal Substring**: By finding the first non-'a' character and extending the substring to include all consecutive non-'a' characters, we ensure that each character in this substring can be shifted to a smaller character (e.g., 'b' becomes 'a', 'c' becomes 'b', etc.), thereby reducing the lexicographic order.
3. **Shift the Substring**: Convert each character in the identified substring to the previous letter in the alphabet. This transformation is applied efficiently in a single pass over the substring.

This approach ensures that we make the earliest and most impactful change to minimize the string's lexicographic order, leading to an optimal solution in linear time.
