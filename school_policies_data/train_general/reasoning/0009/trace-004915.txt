### Approach

2. **Data Processing**: Convert the input data into a list of integers for easier manipulation. Use a pointer to traverse through the list and extract the necessary values.

### Solution Code
```python
import sys

def main():
    data = list(map(int, sys.stdin.read().split()))
    ptr = 0
    T = data[ptr]
    ptr += 1
    for _ in range(T):
        N = data[ptr]
        ptr += 1
        total = 0
        for __ in range(N):
            S = data[ptr]
            M = data[ptr + 1]
            total += S * M
            ptr += 2
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once using `sys.stdin.read()` and split into a list of integers. This allows efficient processing of large input sizes.
2. **Pointer Traversal**: A pointer is used to traverse the list of integers. The pointer starts at the beginning of the list and moves forward as values are read.
3. **Processing Test Cases**: For each test case, the number of intervals (N) is read first. Then, each subsequent pair of integers represents the time (S) and speed (M) for an interval. The product of S and M for each interval is accumulated to compute the total distance.
4. **Output the Result**: After processing all intervals for a test case, the total distance is printed.

This approach ensures that the solution is efficient and handles the constraints effectively, providing the correct results for each test case.
