To solve this problem, we need to determine if Bash's guess about the greatest common divisor (GCD) of a segment of an array is almost correct. This means we can change at most one element in the segment to make the GCD equal to the guessed value. Additionally, we need to handle updates to the array efficiently.

### Approach
1. **Understanding the Problem**: The key insight is that for a guess to be almost correct, there can be at most one element in the segment that is not divisible by the guessed GCD value. If there are zero such elements, the GCD of the segment is either the guessed value or a multiple of it. If there is exactly one such element, changing it to a multiple of the guessed value will make the GCD the guessed value.

2. **Efficient Queries**: For each query, we need to check how many elements in the given range are not divisible by the guessed value. If this count is more than one, the answer is "NO". Otherwise, it's "YES".

3. **Handling Updates**: We use a segment tree to efficiently handle range maximum queries and updates. This helps in quickly determining if the guessed value is larger than the maximum element in the range, which simplifies some checks.

4. **Optimization**: For each query, we check if the guessed value is 1 (all numbers are divisible by 1) or if the guessed value is larger than the maximum element in the range (only possible if the range has at most one element). Otherwise, we iterate through the elements in the range to count those not divisible by the guessed value.

def main():

    n = int(input[ptr])

    a = list(map(int, input[ptr:ptr + n]))
    ptr += n
    q = int(input[ptr])

    # Segment tree for range maximum query
    size = 1
    while size < n:
        size <<= 1
    max_tree = [0] * (2 * size)
    for i in range(n):
        max_tree[size + i] = a[i]
    for i in range(size - 1, 0, -1):
        max_tree[i] = max(max_tree[2 * i], max_tree[2 * i + 1])

    def update_max_tree(pos, value):
        pos += size
        max_tree[pos] = value
        while pos > 1:
            pos >>= 1
            new_val = max(max_tree[2 * pos], max_tree[2 * pos + 1])
            if max_tree[pos] == new_val:
                break
            max_tree[pos] = new_val

    def query_max_tree(l, r):
        res = -float('inf')
        l += size
        r += size
        while l <= r:
            if l % 2 == 1:
                res = max(res, max_tree[l])
                l += 1
            if r % 2 == 0:
                res = max(res, max_tree[r])
                r -= 1
            l >>= 1
            r >>= 1
        return res

    for _ in range(q):
