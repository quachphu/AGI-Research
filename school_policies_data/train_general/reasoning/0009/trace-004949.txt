To solve this problem, we need to count the number of valid substrings in a given string that consist only of the characters A, a, B, b, C, c. A valid substring is any contiguous sequence of characters where all characters are from the allowed set.

### Approach
1. **Identify Valid Segments**: Traverse the string to identify contiguous segments of valid characters. Whenever an invalid character is encountered, the current segment ends.
2. **Calculate Substrings for Each Segment**: For each valid segment of length L, the number of valid substrings is given by the formula \( L \times (L + 1) / 2 \). This formula accounts for all possible contiguous substrings within the segment.
3. **Summing Results**: Sum the results from all valid segments to get the total count of valid substrings for the entire string.

### Solution Code
```python
import sys

def main():
    allowed = {'A', 'a', 'B', 'b', 'C', 'c'}
    t = int(sys.stdin.readline())
    for _ in range(t):
        s = sys.stdin.readline().strip()
        total = 0
        current = 0
        for c in s:
            if c in allowed:
                current += 1
            else:
                total += current * (current + 1) // 2
                current = 0
        total += current * (current + 1) // 2
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads the number of test cases and each subsequent string from standard input.
2. **Tracking Valid Segments**: As we iterate through each character of the string, we maintain a count of the current valid segment length (`current`). If an invalid character is encountered, we compute the number of substrings for the current valid segment and reset the segment length.
3. **Final Calculation**: After processing all characters in the string, any remaining valid segment length is used to compute the final count of substrings for that segment.
4. **Efficiency**: The algorithm runs in O(n) time complexity for each string, where n is the length of the string. This ensures efficient handling of the input constraints (up to 100,000 characters per string).

This approach efficiently breaks down the problem into manageable segments and leverages mathematical formulas to quickly compute the required counts, ensuring optimal performance even for large input sizes.
