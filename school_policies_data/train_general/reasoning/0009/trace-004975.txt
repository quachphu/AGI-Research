To solve this problem, we need to determine the minimum number of characters to erase from a given string of digits so that the resulting string is 'good'. A 'good' string is defined as one where its left cyclic shift is equal to its right cyclic shift. 

### Approach
1. **Understanding Good Strings**:
   - A string is good if its left cyclic shift equals its right cyclic shift. This can happen in two scenarios:
     - All characters in the string are the same.
     - The string has an even length and alternates between two different characters.

2. **Key Insights**:
   - **Single Character Strings**: Any string where all characters are the same is automatically good.
   - **Alternating Character Strings**: For even lengths, a string that alternates between two different characters is good.

3. **Algorithm**:
   - **Case 1 (Single Character)**: Compute the maximum frequency of any single character in the string. This gives the longest possible good string where all characters are the same.
   - **Case 2 (Alternating Characters)**: For each pair of different digits, compute the longest possible even-length substring that alternates between these two digits, starting with either of the two digits. This involves checking all possible pairs of digits and determining the maximum length of such substrings.

4. **Optimization**:
   - By iterating through all possible pairs of digits and checking both possible starting characters (for each pair), we ensure that we consider all potential good strings of alternating characters.

### Solution Code
```python
import sys
from collections import Counter

def minimal_erasures():
    t = int(sys.stdin.readline())
    for _ in range(t):
        s = sys.stdin.readline().strip()
        if not s:
            continue
        freq = Counter(s)
        max_single = max(freq.values()) if freq else 0
        max_pair = 0
        digits = '0123456789'
        for a in digits:
            for b in digits:
                if a == b:
                    continue
                # Starting with a
                current_char = a
                count = 0
                for c in s:
                    if c == current_char:
                        count += 1
                        current_char = b if current_char == a else a
                even_len = count if count % 2 == 0 else count - 1
                if even_len > max_pair:
                    max_pair = even_len
                # Starting with b
                current_char = b
                count = 0
                for c in s:
                    if c == current_char:
                        count += 1
                        current_char = a if current_char == b else b
                even_len = count if count % 2 == 0 else count - 1
                if even_len > max_pair:
                    max_pair = even_len
        max_len = max(max_single, max_pair)
        print(len(s) - max_len)

minimal_erasures()
```

### Explanation
1. **Reading Input**: The function reads multiple test cases.
2. **Frequency Calculation**: For each test case, the frequency of each digit is calculated to determine the longest possible good string with all identical characters.
3. **Pair Checking**: For each pair of different digits, the code checks both possible starting characters (for each pair) to find the longest even-length alternating substring.
4. **Result Calculation**: The result for each test case is derived by subtracting the maximum length of the good string (from both cases) from the original string length.

This approach efficiently handles the constraints and ensures that we explore all possible good string configurations, providing the optimal solution.
