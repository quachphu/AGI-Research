To solve this problem, we need to determine if we can make all given strings equal by rearranging their characters. The key insight is that the total count of each character across all strings must be divisible by the number of strings, allowing each string to have an equal share of each character.

### Approach
1. **Input Reading**: Read the number of test cases.
2. **Character Aggregation**: For each test case, read all strings and aggregate all characters.
3. **Frequency Check**: Count the frequency of each character and check if each character's total count is divisible by the number of strings.
4. **Result Determination**: If all characters meet the divisibility condition, the answer is "YES"; otherwise, it is "NO".

### Solution Code
```python
import sys
from collections import Counter

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        chars = []
        for _ in range(n):
            s = sys.stdin.readline().strip()
            chars.extend(s)
        cnt = Counter(chars)
        possible = all(total % n == 0 for total in cnt.values())
        print("YES" if possible else "NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads the number of test cases and processes each test case individually.
2. **Aggregating Characters**: For each string in a test case, all characters are collected into a list to form a combined character pool.
3. **Counting Frequencies**: Using a `Counter`, the frequency of each character in the combined pool is determined.
4. **Divisibility Check**: The code checks if each character's total count is divisible by the number of strings. If all characters meet this condition, the answer is "YES"; otherwise, it is "NO".

This approach efficiently checks the necessary condition for rearranging characters to make all strings equal, ensuring optimal performance given the problem constraints.
