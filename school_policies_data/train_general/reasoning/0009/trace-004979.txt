To solve this problem, we need to determine the maximum possible points that company R2 can earn in a Jeopardy-style tournament where they can optimally choose the order of answering questions and adjust the prices of auction questions when possible. The key is to leverage the optimal order of answering questions to maximize points.

### Approach
1. **Separate Auction and Regular Questions**: Identify which questions are auction questions and which are regular questions.
2. **Sum Regular Questions First**: Calculate the sum of points from all regular questions. This provides an initial points value which is crucial for determining how much we can adjust auction question prices later.
3. **Sort Auction Questions**: Process auction questions in descending order of their original prices. This allows us to handle higher value questions first, which can potentially be adjusted to higher values if the current points allow it.
4. **Adjust Auction Prices**: For each auction question, if the current points are greater than the auction's original price, adjust the price to the current points, effectively doubling the points. Otherwise, simply add the original price to the current points.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n, m = int(input[ptr]), int(input[ptr+1])
    ptr +=2
    a = list(map(int, input[ptr:ptr+n]))
    ptr +=n
    bi = list(map(int, input[ptr:ptr+m]))
    bi_set = set(bi)
    
    sum_regular = 0
    auction_prices = []
    for idx in range(n):
        if (idx + 1) in bi_set:
            auction_prices.append(a[idx])
        else:
            sum_regular += a[idx]
    
    auction_prices.sort(reverse=True)
    current_s = sum_regular
    for price in auction_prices:
        if current_s > price:
            current_s += current_s
        else:
            current_s += price
    
    print(current_s)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of questions, the prices of each question, and the indices of auction questions.
2. **Separating Questions**: Regular questions are summed up immediately to form the initial points value. Auction questions are collected and sorted in descending order based on their original prices.
3. **Processing Auction Questions**: By processing auction questions in descending order, we maximize the potential points adjustment. If the current points are sufficient to adjust an auction question's price, we double the points. Otherwise, we simply add the question's original price to the current points.

This approach ensures that we maximize the points by leveraging the optimal order of answering questions, allowing us to adjust prices whenever possible to achieve the highest possible score.
