1. **Circle and Line Representation**: The circle is represented by its center coordinates (cx, cy) and radius r. Each line is defined by two points (x1, y1) and (x2, y2).
2. **Parametric Line Equation**: Convert the line into a parametric form using the direction vector derived from the two points. This helps in substituting into the circle's equation to find intersection points.
3. **Quadratic Equation**: By substituting the parametric equations of the line into the circle's equation, we derive a quadratic equation in terms of a parameter t. Solving this quadratic equation gives the parameter values where the line intersects the circle.
4. **Sorting Points**: After computing the intersection points, sort them based on their x-coordinates (and y-coordinates in case of ties) to meet the output requirements.

### Solution Code
```python
import math

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    cx = int(input[ptr])
    ptr += 1
    cy = int(input[ptr])
    ptr += 1
    r = int(input[ptr])
    ptr += 1
    q = int(input[ptr])
    ptr += 1
    
    for _ in range(q):
        x1 = int(input[ptr])
        ptr += 1
        y1 = int(input[ptr])
        ptr += 1
        x2 = int(input[ptr])
        ptr += 1
        y2 = int(input[ptr])
        ptr += 1
        
        dx = x2 - x1
        dy = y2 - y1
        A = x1 - cx
        B = y1 - cy
        a = dx ** 2 + dy ** 2
        b = 2 * (A * dx + B * dy)
        c = (A ** 2 + B ** 2) - r ** 2
        discriminant = b ** 2 - 4 * a * c
        sqrt_discriminant = math.sqrt(discriminant)
        
        t1 = (-b + sqrt_discriminant) / (2 * a)
        t2 = (-b - sqrt_discriminant) / (2 * a)
        
        x_p1 = x1 + dx * t1
        y_p1 = y1 + dy * t1
        x_p2 = x1 + dx * t2
        y_p2 = y1 + dy * t2
        
        points = [(x_p1, y_p1), (x_p2, y_p2)]
        points.sort()
        
        print("{0:.8f} {1:.8f} {2:.8f} {3:.8f}".format(
            points[0][0], points[0][1], points[1][0], points[1][1]))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of tokens for efficient processing.
2. **Parametric Line Equations**: For each line, compute the direction vector (dx, dy) and use it to form the parametric equations of the line.
3. **Quadratic Solution**: Substitute the parametric equations into the circle's equation to form a quadratic equation in t. Solve this equation using the quadratic formula to find the parameter values t1 and t2.
4. **Intersection Points**: Convert the parameter values back to Cartesian coordinates to get the intersection points.
5. **Sorting and Output**: Sort the intersection points lexicographically and print them with 8 decimal places precision.

This approach ensures that we efficiently compute and correctly order the intersection points, adhering to the problem constraints and requirements.
