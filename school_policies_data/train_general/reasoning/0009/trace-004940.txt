To solve this problem, we need to determine the type of crop planted in specific cells of a grid, considering that some cells are wastelands and crops are planted cyclically in the order Carrots, Kiwis, and Grapes. The solution involves efficiently determining the crop type for each query by accounting for the wasteland cells.

### Approach
1. **Input Reading and Preprocessing**: Read the grid dimensions, number of waste cells, and queries. Convert each waste cell into a position value based on its row-major order in the grid.
2. **Sort Waste Cells**: Store the positions of waste cells in a sorted list to enable efficient binary search operations.
3. **Query Processing**: For each query, convert the cell coordinates into a position value. Check if the cell is a waste using binary search. If not, determine its position in the sequence of cultivated cells and use modulo arithmetic to find the crop type.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr]); ptr += 1
    m = int(input[ptr]); ptr += 1
    k = int(input[ptr]); ptr += 1
    t = int(input[ptr]); ptr += 1

    waste = []
    for _ in range(k):
        a = int(input[ptr]); ptr += 1
        b = int(input[ptr]); ptr += 1
        pos = (a - 1) * m + b
        waste.append(pos)
    waste.sort()

    for _ in range(t):
        i = int(input[ptr]); ptr += 1
        j = int(input[ptr]); ptr += 1
        pos = (i - 1) * m + j

        # Check if the current cell is a waste
        idx = bisect.bisect_left(waste, pos)
        if idx < len(waste) and waste[idx] == pos:
            print("Waste")
        else:
            # Number of waste cells up to pos
            count = bisect.bisect_right(waste, pos)
            actual_pos = pos - count
            mod = (actual_pos - 1) % 3
            if mod == 0:
                print("Carrots")
            elif mod == 1:
                print("Kiwis")
            else:
                print("Grapes")

if __name__ == '__main__':
    main()
```

### Explanation
1. **Input Reading**: The input is read all at once and split into tokens for efficient parsing.
2. **Waste Cell Conversion**: Each waste cell's position is calculated using row-major order and stored in a list.
3. **Binary Search for Waste Cells**: The list of waste cell positions is sorted, allowing binary search operations to quickly determine if a cell is waste and to count waste cells up to a given position.
4. **Crop Determination**: For non-waste cells, the actual position in the sequence of cultivated cells is computed by subtracting the count of waste cells up to that position. The crop type is determined using modulo 3 arithmetic on this position.

This approach efficiently handles the constraints, ensuring quick query responses even for large grid sizes and numerous queries.
