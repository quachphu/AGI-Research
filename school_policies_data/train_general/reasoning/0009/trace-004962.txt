To solve this problem, we need to determine if an army is ready for battle based on the number of weapons each soldier is holding. The readiness is determined by the count of soldiers holding even numbers of weapons compared to those holding odd numbers. If the count of soldiers with even weapons is strictly greater, the army is ready; otherwise, it is not.

### Approach
1. **Read Input**: The first input line gives the number of soldiers, and the second line lists the number of weapons each soldier holds.
2. **Count Even and Odd Weapons**: Iterate through the list of weapons to count how many soldiers have even numbers of weapons and how many have odd numbers.
3. **Compare Counts**: Check if the count of soldiers with even weapons is greater than those with odd weapons. If yes, the army is ready; otherwise, it is not.

### Solution Code
```python
def main():
    n = int(input())
    weapons = list(map(int, input().split()))
    even = 0
    odd = 0
    for num in weapons:
        if num % 2 == 0:
            even += 1
        else:
            odd += 1
    print("READY FOR BATTLE" if even > odd else "NOT READY")

main()
```

### Explanation
1. **Reading Input**: The input is read using standard input functions. The first line is converted to an integer to get the number of soldiers, and the second line is split into a list of integers representing the weapons each soldier holds.
2. **Counting Even and Odd**: We initialize two counters, `even` and `odd`, to zero. We then iterate through each number in the weapons list. For each number, we check if it is even (using the modulus operator `% 2`). If it is even, we increment the `even` counter; otherwise, we increment the `odd` counter.
3. **Comparison and Output**: After counting, we compare the two counters. If the `even` count is greater than the `odd` count, we print "READY FOR BATTLE". Otherwise, we print "NOT READY".

This approach ensures that we efficiently determine the army's readiness by counting and comparing in linear time, making the solution both optimal and straightforward.
