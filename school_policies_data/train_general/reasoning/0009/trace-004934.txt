To solve this problem, we need to calculate the number of gestures Anya makes to launch a series of applications on her smartphone, considering that each launch moves the app's icon one position forward if it's not already in the first position. 

### Approach
1. **Understanding the Problem**: Anya's smartphone menu is divided into screens, each containing up to `k` icons. To launch an app on screen `t`, she makes `t-1` gestures to scroll and 1 gesture to press. After launching, the app moves one position forward if possible, which affects the positions of other apps.

2. **Efficient Tracking**: We need to efficiently track the positions of apps as they change. Using two arrays, `pos` (to store the current position of each app) and `app_at` (to store the app at each position), allows us to update positions in constant time.

3. **Algorithm**:
   - **Initialization**: Read input values and initialize the `pos` and `app_at` arrays.
   - **Processing Launches**: For each app in the launch sequence, determine its current position, compute the required gestures, and update the positions if the app is not already in the first position.

### Solution Code
```python
n, m, k = map(int, input().split())
a = list(map(int, input().split()))

pos = [0] * (n + 1)  # pos[app] gives its current position (1-based)
app_at = [0] * (n + 1)  # app_at[pos] gives the app at that position

for idx in range(n):
    app = a[idx]
    position = idx + 1
    pos[app] = position
    app_at[position] = app

b = list(map(int, input().split()))
total = 0

for app in b:
    current_pos = pos[app]
    t = (current_pos - 1) // k + 1
    total += t

    if current_pos > 1:
        prev_pos = current_pos - 1
        prev_app = app_at[prev_pos]

        # Swap the positions of the current app and the previous app
        pos[app] = prev_pos
        pos[prev_app] = current_pos

        app_at[prev_pos] = app
        app_at[current_pos] = prev_app

print(total)
```

### Explanation
1. **Initialization**: The `pos` array maps each app to its initial position, while `app_at` maps each position to the app located there. This setup allows O(1) access and updates.
2. **Gesture Calculation**: For each app in the launch sequence, determine its current screen using integer division to compute the number of gestures required. This is done in O(1) time.
3. **Position Update**: If the app is not in the first position, swap it with the previous app by updating the `pos` and `app_at` arrays. This ensures that subsequent launches reflect the new positions efficiently.

This approach efficiently handles the constraints, ensuring that each operation is performed in constant time, leading to an overall time complexity of O(m), which is optimal for the given problem constraints.
