To solve this problem, we need to determine the number of valid combinations of `n` distinct numbers from 0 to 9 that sum up to a given value `s` for each dataset. The solution involves generating all possible combinations of `n` numbers and checking if their sum matches `s`.

### Approach
1. **Input Handling**: Read multiple datasets until the termination condition (both `n` and `s` are 0) is encountered.
2. **Combination Generation**: For each dataset, generate all possible combinations of `n` distinct numbers from the range 0 to 9 using Python's `itertools.combinations`.
3. **Sum Check**: For each generated combination, check if the sum of the numbers in the combination equals `s`.
4. **Count Valid Combinations**: Maintain a count of valid combinations that meet the sum condition and output this count for each dataset.

### Solution Code
```python
import itertools
import sys

def count_combinations():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n, s = map(int, line.split())
        if n == 0 and s == 0:
            break
        count = 0
        for combo in itertools.combinations(range(10), n):
            if sum(combo) == s:
                count += 1
        print(count)

count_combinations()
```

### Explanation
1. **Reading Input**: The code reads input lines from standard input until it encounters a line with both `n` and `s` set to 0, which signals the end of input.
2. **Generating Combinations**: Using `itertools.combinations(range(10), n)`, we generate all possible combinations of `n` distinct numbers from the range 0 to 9. This function efficiently handles the generation without repetition and in lexicographic order.
3. **Summing and Counting**: For each combination generated, we compute the sum of its elements. If the sum matches the target value `s`, we increment the count of valid combinations.
4. **Output**: After processing all combinations for a given dataset, the count of valid combinations is printed.

This approach ensures that all possible combinations are checked efficiently, leveraging Python's built-in functionalities for combination generation and sum calculation. The solution is both concise and effective, handling all edge cases as specified in the problem constraints.
