To solve this problem, we need to maximize the satisfaction from selecting K pieces of sushi, which is defined as the sum of the base total deliciousness and the variety bonus. The base total deliciousness is the sum of the deliciousness of the selected pieces, and the variety bonus is the square of the number of different toppings among the selected pieces.

### Approach
1. **Group Sushi by Topping**: For each topping, collect all pieces and sort them by deliciousness in descending order.
2. **Separate into Two Groups**:
   - **Group A**: Contains the highest deliciousness piece for each topping.
   - **Group B**: Contains the remaining pieces after selecting the highest for each topping.
3. **Sort and Compute Prefix Sums**:
   - Sort Group A in descending order and compute prefix sums to quickly get the sum of the top x pieces.
   - Sort Group B in descending order and compute prefix sums to quickly get the sum of the top (K - x) pieces.
4. **Determine Valid Range for x**: The number of unique toppings (x) ranges from max(0, K - len(Group B)) to min(K, len(Group A)).
5. **Calculate Maximum Satisfaction**: For each valid x, compute the satisfaction as the sum of the top x pieces from Group A, the top (K - x) pieces from Group B, and the variety bonus x². Track the maximum satisfaction.

### Solution Code

import sys
from collections import defaultdict

def main():
    input = sys.stdin.read().split()
    idx = 0
    N, K = int(input[idx]), int(input[idx+1])
    idx += 2
    sushi = []
    for _ in range(N):
        t = int(input[idx])
        d = int(input[idx+1])
        sushi.append((t, d))
        idx += 2

    # Process into group_a and group_b
    dct = defaultdict(list)
    for t, d in sushi:
        dct[t].append(d)
    
    group_a = []
    group_b = []
    for t in dct:
        lst = sorted(dct[t], reverse=True)
        group_a.append(lst[0])
        group_b.extend(lst[1:])
    
    # Sort groups
    group_a.sort(reverse=True)
    group_b.sort(reverse=True)
    
    # Compute prefix sums for group_a and group_b
    prefix_a = [0]
    sum_ = 0
    for a in group_a:
        sum_ += a
        prefix_a.append(sum_)
    
    prefix_b = [0]
    sum_ = 0
    for b in group_b:
        sum_ += b
        prefix_b.append(sum_)
    
    len_a = len(group_a)
    len_b = len(group_b)
    x_min = max(0, K - len_b)
    x_max = min(K, len_a)
    
    max_total = 0
    for x in range(x_min, x_max + 1):
        if x >= len(prefix_a):
            continue  # Not possible since x_max is min(K, len_a)
        sum_a = prefix_a[x]
        take = K - x
        if take < 0:
            continue
        if take >= len(prefix_b):
            sum_b = prefix_b[-1] if len(prefix_b) > 0 else 0
        else:
            sum_b = prefix_b[take]
        total = sum_a + sum_b + x * x
        if total > max_total:
            max_total = total
    print(max_total)

if __name__ == '__main__':
    main()

3. **Range of x**: By considering the valid range for the number of unique toppings (x), we ensure we explore all possible combinations that maximize the satisfaction.
4. **Maximization**: For each valid x, we compute the satisfaction and track the maximum value, ensuring an optimal solution within feasible computational limits.
