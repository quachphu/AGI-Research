To solve this problem, we need to extract words from an input English sentence based on specific criteria. The words must be between 3 to 6 characters long and should be separated by spaces, commas, or periods. 

### Approach
1. **Input Handling**: Read the input sentence and strip any leading or trailing whitespace.
2. **Splitting Words**: Use regular expressions to split the sentence into words using spaces, commas, and periods as delimiters.
3. **Filtering Words**: Remove any empty strings resulting from consecutive delimiters and filter out words that do not meet the length criteria (3 to 6 characters).
4. **Output**: Join the filtered words with spaces and print the result.

### Solution Code
```python
import re

def main():
    s = input().strip()
    words = re.split(r'[ ,.]+', s)
    filtered = [word for word in words if word]
    result = [word for word in filtered if 3 <= len(word) <= 6]
    print(' '.join(result))

main()
```

### Explanation
1. **Reading Input**: The input is read using `input().strip()` to remove any leading or trailing whitespace.
2. **Splitting the Sentence**: The `re.split(r'[ ,.]+', s)` function splits the input string using spaces, commas, and periods as delimiters. This regex pattern ensures that any combination of these delimiters is treated as a single separator.
3. **Filtering Empty Strings**: The list comprehension `[word for word in words if word]` removes any empty strings that may result from leading, trailing, or consecutive delimiters.
4. **Checking Word Lengths**: Another list comprehension `[word for word in filtered if 3 <= len(word) <= 6]` filters out words that are shorter than 3 characters or longer than 6 characters.
5. **Output**: The filtered words are joined into a single string with spaces and printed.

This approach efficiently handles the splitting and filtering of words, ensuring that only valid words are included in the output. The use of regular expressions ensures accurate splitting based on the specified delimiters.
