To solve this problem, we need to determine the winner of a game where players take turns adding the absolute difference of two distinct integers from a set, earning points equal to the difference. The game ends when a player cannot make a move, and the winner is determined based on optimal play starting with Joey. The solution involves calculating the closure of the set under the absolute difference operation and using game theory principles to determine the outcome.

### Approach
1. **Understanding the Game Dynamics**: The game revolves around adding absolute differences of elements in the set. The closure of the set under this operation will include all possible absolute differences that can be formed.
2. **GCD Insight**: The closure set consists of all multiples of the greatest common divisor (GCD) of the initial set elements up to the maximum element in the initial set.
3. **Sum Calculation**: The total points accumulated by both players is the sum of all elements in the closure set minus the sum of the initial elements.
4. **Move Parity**: The number of moves required to reach the closure set determines the winner based on whether the number of moves is odd (Joey wins) or even (Chandler wins).

```python
import sys
from math import gcd

def compute_gcd(arr):
    current_gcd = arr[0]
    for num in arr[1:]:
        current_gcd = gcd(current_gcd, num)
        if current_gcd == 1:
            break
    return current_gcd

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        arr = list(map(int, sys.stdin.readline().split()))
        d = compute_gcd(arr)
        M = max(arr)
        k = M // d
        sum_closure = d * k * (k + 1) // 2
        sum_initial = sum(arr)
        total_points = sum_closure - sum_initial
        moves = k - n
        if moves == 0:
            print("Chandler 0")
        else:
            winner = "Joey" if moves % 2 == 1 else "Chandler"
            print(f"{winner} {total_points}")

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read from standard input, including the number of test cases and each test case's details.
2. **GCD Calculation**: The GCD of all elements in the initial set is computed to determine the step size for generating the closure set.
3. **Closure Set Calculation**: The closure set is determined by all multiples of the GCD up to the maximum element in the initial set. The sum of these elements is calculated using the formula for the sum of an arithmetic series.
4. **Determine Moves and Winner**: The number of moves required to reach the closure set from the initial set is calculated. The winner is determined based on the parity of the number of moves, and the total points are derived from the difference between the closure set sum and the initial set sum.
