Directly checking all possible pairs would be computationally expensive, so we use a more efficient approach based on modular arithmetic and precomputation.

### Approach
1. **Modular Arithmetic Insight**: The concatenation of two numbers x and y can be represented as \(x \times 10^m + y\), where m is the number of digits in y. For this concatenated number to be divisible by k, the expression \((x \times 10^m + y) \mod k\) must be 0. This can be transformed into checking if \((x \mod k) \times (10^m \mod k) + (y \mod k) \equiv 0 \mod k\).

2. **Precomputation**: 
   - Compute the modular values of \(10^m \mod k\) for all possible digit lengths m (from 1 to 10, since the maximum value of a number in the array is \(10^9\), which has 10 digits).
   - Precompute the remainder of each number in the array when divided by k and count the occurrences of each remainder for each possible digit length.

3. **Efficient Counting**:
   - For each number in the array, determine the required remainder that another number must have to form a valid pair. Use the precomputed values to quickly count how many such numbers exist, adjusting for cases where the same number might be counted twice (i.e., i = j).

### Solution Code
```python
from collections import defaultdict

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    k = int(input[idx+1])
    idx += 2
    a = list(map(int, input[idx:idx+n]))
    
    # Precompute 10^m mod k for m from 1 to 10
    pow_10_mod = [0] * 11  # index 0 unused
    current = 1 % k  # 10^0 mod k is 1 mod k
    for m in range(1, 11):
        current = (current * 10) % k
        pow_10_mod[m] = current
    
    # Preprocess the array to get counts of remainders for each length
    len_mod_counts = [defaultdict(int) for _ in range(11)]  # indexes 0-10
    for num in a:
        r = num % k
        m = len(str(num))
        len_mod_counts[m][r] += 1
    
    total = 0
    for num in a:
        r_i = num % k
        m_i = len(str(num))
        for m in range(1, 11):
            target = (-r_i * pow_10_mod[m]) % k
            cnt = len_mod_counts[m].get(target, 0)
            total += cnt
            # Check if current number's own entry contributed to the count
            if m == m_i and target == r_i:
                total -= 1  # subtract self-pairing
    
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into integers for the number of elements (n), the divisor (k), and the array elements.
2. **Precompute Powers of 10 Modulo k**: This step calculates \(10^m \mod k\) for m from 1 to 10, which helps in efficiently determining the required remainders for valid pairs.
3. **Count Remainders by Length**: For each number in the array, compute its remainder modulo k and its digit length. Store these counts in a dictionary for quick lookup.
4. **Calculate Valid Pairs**: For each number, determine how many valid pairs it can form by checking the required remainders for each possible digit length. Adjust the count to exclude cases where the same number is used twice (i.e., i = j).

This approach ensures that we efficiently count valid pairs without explicitly checking all possible pairs, leading to an optimal solution with a time complexity of O(n), which is feasible for large input sizes.
