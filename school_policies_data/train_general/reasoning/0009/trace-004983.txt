To solve this problem, we need to count the number of Z-patterns in a given grid. A Z-pattern is defined as a square where the anti-diagonal, the first row, and the last row are completely filled with 'z's. The solution involves efficiently checking these conditions using precomputed matrices to avoid excessive time complexity.

### Approach
1. **Precompute right_z Matrix**: This matrix helps determine the maximum number of consecutive 'z's starting from each cell and extending to the right. This allows quick checks for valid rows in the Z-pattern.
2. **Precompute ad Matrix**: This matrix helps determine the maximum length of consecutive 'z's starting from each cell and extending in the anti-diagonal (down-left) direction. This allows quick checks for valid anti-diagonal in the Z-pattern.
3. **Iterate Over Possible Squares**: For each cell in the grid, check all possible square sizes starting from that cell. Use the precomputed matrices to efficiently verify the conditions for valid Z-patterns.

### Solution Code
```python
import sys

def main():
    n, m = map(int, sys.stdin.readline().split())
    grid = [sys.stdin.readline().strip() for _ in range(n)]
    
    # Precompute right_z: maximum consecutive 'z's to the right including current cell
    right_z = [[0]*m for _ in range(n)]
    for x in range(n):
        row = grid[x]
        right_z[x][m-1] = 1 if row[m-1] == 'z' else 0
        for y in range(m-2, -1, -1):
            if row[y] == 'z':
                right_z[x][y] = right_z[x][y+1] + 1
            else:
                right_z[x][y] = 0
    
    # Precompute ad: maximum anti-diagonal length starting at (x, y)
    ad = [[0]*m for _ in range(n)]
    for x in range(n-1, -1, -1):
        for y in range(m-1, -1, -1):
            if grid[x][y] == 'z':
                if x+1 < n and y-1 >= 0:
                    ad[x][y] = ad[x+1][y-1] + 1
                else:
                    ad[x][y] = 1
            else:
                ad[x][y] = 0
    
    count = 0
    
    for x in range(n):
        for y in range(m):
            if grid[x][y] != 'z':
                continue
            max_k_ad = ad[x][y]
            max_k_y = y + 1
            max_k_n = n - x
            K_max = min(max_k_ad, max_k_y, max_k_n)
            if K_max == 0:
                continue
            
            for k in range(1, K_max + 1):
                j = y - k + 1
                # Check right_z for the first and last rows
                if right_z[x][j] >= k and right_z[x + k - 1][j] >= k:
                    count += 1
    
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and stored in a grid structure.
2. **right_z Matrix**: This matrix is computed by iterating each row from right to left. Each entry `right_z[x][y]` stores the number of consecutive 'z's starting from cell `(x, y)` and extending to the right.
3. **ad Matrix**: This matrix is computed by iterating each cell from bottom to top and right to left. Each entry `ad[x][y]` stores the length of the longest consecutive 'z's starting from cell `(x, y)` and extending in the anti-diagonal direction.
4. **Checking Valid Z-patterns**: For each cell `(x, y)`, the maximum possible square size `K_max` is determined. For each possible square size `k`, the conditions for valid rows and anti-diagonal are checked using the precomputed matrices. If valid, the count is incremented.

This approach ensures that we efficiently check each possible Z-pattern using precomputed data, significantly reducing the time complexity compared to a brute-force method.
