To solve this problem, we need to determine whether a ball struck on a billiard table will eventually fall into one of the four pockets located at the corners of the table. The ball moves in a direction that is either parallel to the axes or at a 45-degree angle, and we need to account for reflections off the table's edges.

### Approach
1. **Handle Axis-Aligned Movement**: If the ball's velocity is purely horizontal (vx=0) or vertical (vy=0), check if it can reach a pocket by moving along the respective axis.
2. **Diagonal Movement**: For diagonal movement (both vx and vy are non-zero), model the problem using the Chinese Remainder Theorem (CRT) to determine if the ball's path intersects a pocket in the extended grid of mirrored tables. This involves solving congruences to find the minimal time when the ball's coordinates align with a pocket's coordinates in the mirrored grid.

### Solution Code

import sys
import math

def extended_gcd(a, b):
    if b == 0:
        return (a, 1, 0)
    else:
        g, x1, y1 = extended_gcd(b, a % b)
        x = y1
        y = x1 - (a // b) * y1
        return (g, x, y)

def crt(a1, m1, a2, m2):
    g, x, y = extended_gcd(m1, m2)
    if (a2 - a1) % g != 0:
        return None
    lcm = m1 // g * m2
    k = ((a2 - a1) // g) * x % (m2 // g)
    solution = a1 + k * m1
    solution %= lcm
    if solution < 0:
        solution += lcm
    return solution
