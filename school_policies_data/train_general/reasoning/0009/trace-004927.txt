To solve this problem, we need to determine the number of distinct non-zero areas of triangles that can be formed using three trees, where one of the trees is fixed at (0, 1) and the other two are located along the x-axis. 

### Approach
The key observation is that the area of a triangle formed by two points on the x-axis and the fixed point (0, 1) is determined by the horizontal distance between the two points on the x-axis. This distance directly translates to the base of the triangle, while the height is always 1 (the vertical distance from (0, 1) to the x-axis). The area of such a triangle is given by \(\frac{1}{2} \times \text{base} \times \text{height}\), where the base is the absolute difference between the x-coordinates of the two points. 

To find the number of distinct areas, we need to count the number of distinct differences between the x-coordinates of all pairs of points along the x-axis. This reduces the problem to finding the number of unique differences between each pair of x-coordinates in the given list.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        x = list(map(int, input[ptr:ptr+n]))
        ptr += n
        diffs = set()
        for i in range(n):
            for j in range(i + 1, n):
                diffs.add(x[j] - x[i])
        print(len(diffs))

main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given multiple test cases.
2. **Processing Each Test Case**: For each test case, we read the number of trees and their x-coordinates.
3. **Calculating Differences**: For each pair of x-coordinates (i, j) where i < j, compute the difference and store it in a set to ensure uniqueness.
4. **Output Result**: The size of the set, which contains all unique differences, is the answer for that test case.

This approach ensures that we efficiently count all unique areas by leveraging the properties of sets to automatically handle duplicates. The time complexity is O(n^2) for each test case, which is feasible given the constraints (n ≤ 50).
