To solve this problem, we need to determine the majority color of stars in the universe based on the given data. The majority color is defined as a color that appears more than half the time in the dataset. If no such color exists, we should report "NO COLOR".

### Approach
The problem can be efficiently solved using the Boyer-Moore Majority Vote Algorithm, which allows us to find a potential majority element in linear time and constant space. Here's the step-by-step approach:

1. **Boyer-Moore Majority Vote Algorithm**: This algorithm helps identify a candidate for the majority element by maintaining a count. If the count reaches zero, the current element becomes the new candidate. This works because if there is a majority element, it will eventually be the candidate after processing all elements.
2. **Verification Step**: After identifying a candidate using the Boyer-Moore algorithm, we need to verify if this candidate indeed appears more than half the time in the dataset. This is done by counting the occurrences of the candidate element.

### Solution Code
```python
import sys

def main():
    data = list(map(int, sys.stdin.read().split()))
    ptr = 0
    while True:
        n = data[ptr]
        ptr += 1
        if n == 0:
            break
        arr = data[ptr:ptr + n]
        ptr += n
        
        # Boyer-Moore Majority Vote Algorithm
        candidate = None
        count = 0
        for num in arr:
            if count == 0:
                candidate = num
                count = 1
            else:
                if num == candidate:
                    count += 1
                else:
                    count -= 1
        
        # Verify the candidate
        actual_count = 0
        for num in arr:
            if num == candidate:
                actual_count += 1
        
        if actual_count > (n // 2):
            print(candidate)
        else:
            print("NO COLOR")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the potentially large size of the dataset. The input is split into tokens and processed sequentially.
2. **Boyer-Moore Algorithm**: This algorithm iterates through the dataset to find a candidate majority element. It uses a counter to keep track of the current candidate's lead over other elements.
3. **Verification**: After identifying a candidate, we count its actual occurrences in the dataset. If this count exceeds half the length of the dataset, the candidate is the majority element; otherwise, we output "NO COLOR".

This approach ensures that we efficiently determine the majority element in linear time with constant space complexity, making it suitable for large datasets.
