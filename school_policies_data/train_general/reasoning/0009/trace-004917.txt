To solve this problem, we need to determine the number of valid pairs (L, R) such that the sum of the occurrences of the digit 4 from L to R equals the sum of the occurrences of the digit 7 from L to R. The solution involves precomputing values to efficiently answer each query in constant time.

### Approach
1. **Precompute Digit Counts**: For each number from 1 to 100,000, compute the number of digits 4 and 7 it contains.
2. **Prefix Sums**: Compute prefix sums for the counts of digits 4 and 7 up to each number.
3. **Difference Array (D)**: Create an array where each entry at index i represents the difference between the prefix sums of 4s and 7s up to i.
4. **Frequency Map**: Use a frequency map to track occurrences of each value in the difference array. This helps in efficiently counting valid pairs.
5. **Sum Pairs Array**: Precompute the number of valid pairs for each number up to 100,000 using the frequency map.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    max_n = 100000
    f4 = [0] * (max_n + 1)
    f7 = [0] * (max_n + 1)

    for x in range(1, max_n + 1):
        count4 = 0
        count7 = 0
        temp = x
        while temp > 0:
            d = temp % 10
            if d == 4:
                count4 += 1
            elif d == 7:
                count7 += 1
            temp = temp // 10
        f4[x] = count4
        f7[x] = count7

    prefix4 = [0] * (max_n + 1)
    prefix7 = [0] * (max_n + 1)
    for i in range(1, max_n + 1):
        prefix4[i] = prefix4[i-1] + f4[i]
        prefix7[i] = prefix7[i-1] + f7[i]

    D = [0] * (max_n + 1)
    for i in range(max_n + 1):
        D[i] = prefix4[i] - prefix7[i]

    sum_pairs = [0] * (max_n + 1)
    freq = defaultdict(int)
    freq[D[0]] = 1  # Initialize with D[0] = 0

    sum_so_far = 0
    for j in range(1, max_n + 1):
        current_D = D[j]
        count = freq.get(current_D, 0)
        sum_so_far += count
        sum_pairs[j] = sum_so_far
        freq[current_D] += 1

    input_data = sys.stdin.read().split()
    T = int(input_data[0])
    for i in range(1, T + 1):
        N = int(input_data[i])
        print(sum_pairs[N])

if __name__ == '__main__':
    main()
```
