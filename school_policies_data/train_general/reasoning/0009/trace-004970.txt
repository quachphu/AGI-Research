### Approach
1. **Problem Analysis**: The corridor is divided into inner and outer sectors with walls between each adjacent sector. The key insight is that the connected regions are determined by the GCD of the number of sectors in the inner and outer areas. This GCD helps in determining the minimal angular division that can be used to check if two sectors are in the same connected region.

2. **Intuition**: The walls in the corridor divide the circle into regions. If two sectors (regardless of being inner or outer) lie within the same region, Amugae can move between them without crossing any walls. The regions are determined using the GCD of the number of sectors in the inner and outer areas.

3. **Algorithm**:
   - Compute the GCD of the number of inner and outer sectors.
   - For each query, determine the region of the start and end sectors using the GCD. If they lie within the same region, the answer is "YES"; otherwise, it is "NO".

### Solution Code
```python
import math

n, m, q = map(int, input().split())
g = math.gcd(n, m)

for _ in range(q):
    s_x, s_y, e_x, e_y = map(int, input().split())
    
    # Calculate region for start sector
    if s_x == 1:
        start_region = ( (s_y - 1) * g ) // n
    else:
        start_region = ( (s_y - 1) * g ) // m
    
    # Calculate region for end sector
    if e_x == 1:
        end_region = ( (e_y - 1) * g ) // n
    else:
        end_region = ( (e_y - 1) * g ) // m
    
    print("YES" if start_region == end_region else "NO")
```

2. **Region Calculation**: For each sector, the region is calculated based on its position and the GCD. This involves integer division to avoid floating-point precision issues.
