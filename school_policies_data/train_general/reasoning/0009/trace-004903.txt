To solve this problem, we need to determine the number of Product Days in a year according to the Takahashi Calendar. A Product Day is defined as a day where the day is a two-digit number, and the product of its tens and ones digits equals the month number, with both digits being at least 2.

### Approach
1. **Input Reading**: Read the values of M (number of months) and D (maximum number of days in a month).
2. **Iterate Over Months and Days**: For each month from 1 to M, check each possible two-digit day (from 10 up to D).
3. **Check Conditions**: For each day, split the day into its tens and ones digits. Verify if both digits are at least 2 and if their product equals the current month.
4. **Count Valid Days**: Increment the count for each valid Product Day found.

### Solution Code
```python
m, d = map(int, input().split())

count = 0

for month in range(1, m + 1):
    for day in range(10, d + 1):
        tens = day // 10
        ones = day % 10
        if tens >= 2 and ones >= 2 and tens * ones == month:
            count += 1

print(count)
```

### Explanation
1. **Reading Input**: The input values for M and D are read and stored.
2. **Loop Through Months**: For each month from 1 to M, we check each possible day from 10 to D.
3. **Check Day Validity**: For each day, we split it into its tens and ones digits. We then check if both digits are at least 2 and if their product matches the current month.
4. **Count Valid Days**: Each valid day that meets all conditions is counted. The total count is printed as the result.

This approach efficiently checks all possible days in each month, ensuring we only consider valid two-digit days and the specific product condition, leading to the correct count of Product Days.
