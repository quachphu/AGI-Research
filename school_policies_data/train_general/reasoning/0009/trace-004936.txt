To solve this problem, we need to determine the probability that Willman and Bolt tie in a race where the track length is chosen uniformly at random from 1 to t. Both athletes can only take steps of lengths w and b respectively, and they tie if their maximum distances without falling into the abyss are equal.

### Approach
1. **Understanding the Tie Condition**: Willman and Bolt tie if the maximum distance they can run (without falling into the abyss) is the same. This happens when the largest multiples of their step lengths (w and b) that are less than or equal to the track length L are equal.

2. **Initial Interval**: For very small track lengths (L < min(w, b)), both athletes can't take any steps, resulting in a tie. The count of such lengths is determined by the minimum of w and b minus 1.

3. **Common Multiples**: For larger lengths, we need to consider the least common multiple (LCM) of w and b. Track lengths that are multiples of the LCM up to t will have intervals where both athletes can run the same maximum distance.

4. **Efficient Calculation**: Calculate the number of valid intervals using the LCM and determine how many track lengths within each interval result in a tie. This involves considering full intervals and partial intervals if the upper bound t falls within an interval.

### Solution Code
```python
import math

t, w, b = map(int, input().split())

# Calculate initial count
m_initial_val = min(w, b) - 1
if m_initial_val >= 1:
    initial_count = min(m_initial_val, t)
else:
    initial_count = 0

gcd_val = math.gcd(w, b)
lcm = (w // gcd_val) * b
d = min(w, b)

M = t // lcm

total = initial_count

if M > 0:
    numerator_m_max = t - d + 1
    if numerator_m_max < 0:
        m_max_full = 0
    else:
        m_max_full = numerator_m_max // lcm
    m_max_full = min(m_max_full, M)
    count_full = m_max_full * d
    
    start_m = m_max_full + 1
    end_m = M
    
    if start_m <= end_m:
        count_m = end_m - start_m + 1
        sum_m = (start_m + end_m) * count_m // 2
        count_part = (t + 1) * count_m - lcm * sum_m
    else:
        count_part = 0
    
    total += count_full + count_part

# Reduce the fraction
gcd_total = math.gcd(total, t)
p = total // gcd_total
q = t // gcd_total

print(f"{p}/{q}")
```
