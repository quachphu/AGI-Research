To solve this problem, we need to determine the number of p-th cousins for a given person in a family tree. A p-th cousin of person v is someone who shares the same p-th ancestor as v. The solution involves efficiently navigating the family tree and counting the relevant nodes using depth-based traversal and binary lifting for ancestor queries.

### Approach
1. **Tree Representation**: Read the input to build the family tree using an adjacency list where each node points to its children.
2. **Depth Calculation**: Perform a depth-first search (DFS) to compute the depth of each node and record the entry (in_time) and exit (out_time) times for each node during the traversal.
3. **Binary Lifting**: Precompute a binary lifting table to efficiently find the p-th ancestor of any node in O(log p) time.
4. **Depth Grouping**: Group nodes by their depth and store their in_time values in sorted lists for quick range queries.
5. **Query Processing**: For each query, determine the p-th ancestor of the given node. Use the precomputed depth groups to count how many nodes share this ancestor at the required depth, adjusting for the node itself.

import sys
import bisect

def main():
    n = int(sys.stdin.readline())
    r = list(map(int, sys.stdin.readline().split()))
    children = [[] for _ in range(n+1)]  # 1-based indexing
    for i in range(1, n+1):
        parent = r[i-1]
        if parent != 0:
            children[parent].append(i)
    
    # Compute in_time, out_time, depth using iterative DFS
    in_time = [0] * (n + 1)
    out_time = [0] * (n + 1)
    depth = [0] * (n + 1)
    visited = [False] * (n + 1)
    timer = 0
    
    for node in range(1, n + 1):
        if r[node - 1] == 0 and not visited[node]:
            stack = [(node, None, False)]
            while stack:
                current, parent, is_processed = stack.pop()
                if not is_processed:
                    if visited[current]:
                        continue
                    visited[current] = True
                    in_time[current] = timer
                    timer += 1
                    depth[current] = depth[parent] + 1 if parent is not None else 0
                    stack.append((current, parent, True))
                    # Push children in reverse order to process them in order
                    for child in reversed(children[current]):
                        if not visited[child]:
                            stack.append((child, current, False))
                else:
                    out_time[current] = timer
                    timer += 1
    
    # Build binary lifting table
    max_level = 20
    up = [[0] * (n + 1) for _ in range(max_level)]
    for v in range(1, n + 1):
        up[0][v] = r[v - 1]
    for k in range(1, max_level):
        for v in range(1, n + 1):
            if up[k-1][v] != 0:
                up[k][v] = up[k-1][up[k-1][v]]
            else:
                up[k][v] = 0
    
    # Prepare depth_dict: maps depth to sorted list of in_time
    depth_dict = {}
    for v in range(1, n + 1):
        d = depth[v]
        if d not in depth_dict:
            depth_dict[d] = []
        depth_dict[d].append(in_time[v])
    # Sort each list in depth_dict
    for d in depth_dict:
        depth_dict[d].sort()
    
    # Process queries
    m = int(sys.stdin.readline())
    output = []
    for _ in range(m):
        v, p = map(int, sys.stdin.readline().split())
        if depth[v] < p:
            output.append('0')
            continue
        # Find p-th ancestor using binary lifting
        current = v
        remaining = p
        for k in reversed(range(max_level)):

                current = up[k][current]
                remaining -= (1 << k)
