To solve this problem, we need to determine the number of outcomes where the first player wins, the game ends in a draw, or the second player wins based on the numbers they chose and the result of a dice roll. The solution involves comparing the absolute differences between each player's chosen number and the dice outcome.

### Approach
1. **Input Reading**: Read the integers chosen by the two players.
2. **Initialize Counters**: Set up three counters to keep track of the number of wins for the first player, draws, and wins for the second player.
3. **Iterate Over Dice Outcomes**: For each possible outcome of the dice roll (from 1 to 6), compute the absolute differences between each player's chosen number and the dice outcome.
4. **Compare Differences**: Based on the differences, increment the respective counter:
   - If the first player's difference is smaller, increment the first player's win counter.
   - If both differences are equal, increment the draw counter.
   - Otherwise, increment the second player's win counter.
5. **Output Results**: Print the results for the first player's wins, draws, and the second player's wins.

### Solution Code
```python
def main():
    a, b = map(int, input().split())
    first = 0
    draw = 0
    second = 0
    for x in range(1, 7):
        da = abs(a - x)
        db = abs(b - x)
        if da < db:
            first += 1
        elif da == db:
            draw += 1
        else:
            second += 1
    print(first, draw, second)

main()
```

### Explanation
- **Reading Input**: The input consists of two integers, which are read and stored in variables `a` and `b`.
- **Loop Through Dice Outcomes**: The loop iterates over all possible dice outcomes (1 through 6).
- **Difference Calculation**: For each dice outcome, the absolute differences between the outcome and each player's chosen number are calculated.
- **Comparison and Counting**: Depending on the comparison of these differences, the respective counters are incremented to track wins and draws.
- **Output**: The results are printed in the required order: first player's wins, draws, and then the second player's wins.

This approach efficiently determines the result by checking each possible dice outcome once, leading to a time complexity of O(1), which is optimal for this problem given the fixed range of possible dice outcomes.
