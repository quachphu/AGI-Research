### Approach
1. **Dynamic Programming (DP) Setup**: We use a dynamic programming approach to track the number of subsets that sum up to each possible value from 0 to S. The key insight is to consider the contribution of each element in the array to these sums efficiently.
2. **Inverse Modulo Handling**: Since we need to handle large numbers and modulo operations, we use modular arithmetic. Specifically, we compute the modular inverse of 2, which helps in efficiently calculating contributions of subsets of varying sizes.
3. **DP Transition**: For each element in the array, we update the DP array in reverse order to avoid overwriting values that are yet to be processed. This ensures that each element's contribution is correctly accounted for in all possible subsets.
4. **Final Calculation**: After processing all elements, the result is derived by multiplying the count of valid subsets (summing to S) by 2^N (modulo 998244353), where N is the number of elements.

### Solution Code
```python
MOD = 998244353

n, s = map(int, input().split())
a = list(map(int, input().split()))

inv2 = pow(2, MOD - 2, MOD)
dp = [0] * (s + 1)
dp[0] = 1  # Start with the empty subset

    for i in range(s, num - 1, -1):
        dp[i] = (dp[i] + dp[i - num] * inv2) % MOD

print(ans)
```

3. **Modular Inverse of 2**: The inverse of 2 modulo 998244353 is used to adjust the contributions of subsets as they grow in size, ensuring correct modular arithmetic.
4. **Final Result Calculation**: After processing all elements, the result is obtained by multiplying the count of valid subsets (summing to S) by 2^N (modulo 998244353), which accounts for all possible supersets of these valid subsets.
