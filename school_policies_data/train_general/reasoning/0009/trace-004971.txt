2. **Dynamic Programming (DP) Approach**: We use a DP array where `dp[j]` represents the sum of products of j elements selected from the processed elements of B. For each element in B, we update the DP array from K down to 1 to avoid overwriting values that are yet to be processed.

3. **Handling Queries**: Each query modifies the array A temporarily. For each query, we create a copy of the original array, apply the modifications, compute the array B, and then use the DP approach to compute the required sum.

import sys
MOD = 998244353

def main():
