To solve this problem, we need to determine the maximum number of coins Toastman can get by selecting k cards from Appleman's collection. The coins are calculated based on the frequency of each chosen letter in the selected cards. The goal is to maximize the sum of squares of these frequencies.

### Approach
1. **Count Frequencies**: First, count the frequency of each uppercase letter in the given input string.
2. **Sort Frequencies**: Sort these frequencies in descending order to prioritize higher frequencies.
3. **Select Cards**: Iterate through the sorted frequencies, taking as many cards as possible from the highest frequencies first until exactly k cards are selected. This approach maximizes the sum of squares of the selected frequencies.

### Solution Code
```python
import sys
from collections import Counter

def main():
    n, k = map(int, sys.stdin.readline().split())
    s = sys.stdin.readline().strip()
    counts = Counter(s)
    freq = sorted(counts.values(), reverse=True)
    remaining = k
    res = 0
    for f in freq:
        if remaining <= 0:
            break
        take = min(f, remaining)
        res += take * take
        remaining -= take
    print(res)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Count Frequencies**: Using `collections.Counter`, we count how many times each letter appears in the input string.
2. **Sort Frequencies**: The frequencies are sorted in descending order to ensure we start with the most frequent letters, which contribute more to the sum of squares.
3. **Select Cards**: By iterating through the sorted frequencies, we take the maximum possible number of cards from the highest frequency letters first. This greedy approach ensures the sum of squares is maximized, as higher frequencies contribute quadratically more to the total coins.

This approach efficiently handles the constraints, ensuring optimal performance even for large input sizes up to 100,000 cards. The sorting step is efficient due to the limited number of unique uppercase letters (at most 26), making the overall complexity linear in terms of the input size.
