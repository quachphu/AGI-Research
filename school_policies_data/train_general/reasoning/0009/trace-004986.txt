To solve this problem, we need to determine how many stewards Jon Snow can support based on their strengths. A steward can be supported if there exists at least one steward with a strictly lower strength and another with a strictly higher strength.

### Approach
1. **Identify Extremes**: Compute the minimum and maximum strength values from the list of stewards.
2. **Check for Uniform Strength**: If all stewards have the same strength (i.e., minimum and maximum values are equal), no steward can be supported.
3. **Count Valid Stewards**: For each steward, check if their strength is strictly between the minimum and maximum values. Count such stewards.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    
    if n < 2:
        print(0)
        return
    
    min_val = min(a)
    max_val = max(a)
    
    if min_val == max_val:
        print(0)
        return
    
    count = 0
    for num in a:
        if min_val < num < max_val:
            count += 1
    
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read efficiently using `sys.stdin` to handle large input sizes.
2. **Edge Cases Handling**: If there is only one steward or all stewards have the same strength, the result is immediately determined to be 0.
3. **Efficiency**: The solution efficiently computes the minimum and maximum values in O(n) time and then iterates through the list once more to count valid stewards, resulting in an overall O(n) time complexity, which is optimal for the given problem constraints.

This approach ensures that we efficiently determine the number of stewards Jon can support by leveraging the properties of minimum and maximum values in the list.
