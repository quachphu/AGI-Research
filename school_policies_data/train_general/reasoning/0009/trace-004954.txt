To solve this problem, we need to determine the minimum total cost required to complete all three tasks given their respective values. The cost structure allows the first task to be completed at no cost, and each subsequent task's cost is the absolute difference between the current task's value and the previous task's value.

### Approach
1. **Generate All Permutations**: Since there are three tasks, there are 3! = 6 possible permutations of the order in which the tasks can be completed.
2. **Calculate Cost for Each Permutation**: For each permutation, compute the total cost by summing the absolute differences between consecutive tasks.
3. **Find Minimum Cost**: Among all permutations, identify the one with the minimum total cost.

### Solution Code
```python
import itertools

def main():
    A = list(map(int, input().split()))
    min_cost = float('inf')
    for perm in itertools.permutations(A):
        cost = abs(perm[1] - perm[0]) + abs(perm[2] - perm[1])
        if cost < min_cost:
            min_cost = cost
    print(min_cost)

main()
```

### Explanation
1. **Reading Input**: The input values are read and stored in a list `A`.
2. **Generating Permutations**: Using `itertools.permutations`, we generate all possible orderings of the three tasks.
3. **Calculating Costs**: For each permutation, we compute the cost by summing the absolute differences between consecutive elements. The first task is free, so the cost starts from the second task in the permutation.
4. **Finding Minimum**: We keep track of the minimum cost encountered across all permutations and print it as the result.

This approach ensures that we explore all possible task orders efficiently and correctly determine the minimum cost using a brute-force method, which is feasible given the small number of permutations (6 in total).
