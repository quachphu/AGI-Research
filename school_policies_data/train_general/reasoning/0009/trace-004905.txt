To solve this problem, we need to find the K-th lexicographically smallest unique substring of a given string. The solution involves generating all possible substrings of the string up to a certain length, removing duplicates, and then sorting them to find the required substring.

### Approach
1. **Generate Substrings**: Generate all possible substrings of the input string with lengths ranging from 1 to K. This is because the K-th smallest substring cannot be longer than K due to lexicographical ordering constraints.
2. **Remove Duplicates**: Use a set to collect these substrings to ensure all entries are unique.
3. **Sort Substrings**: Convert the set to a sorted list to arrange the substrings in lexicographical order.
4. **Select K-th Substring**: The K-th lexicographically smallest substring is the (K-1)-th element in the sorted list (since list indices start at 0).

### Solution Code
```python
s = input().strip()
K = int(input())

unique_substrings = set()
n = len(s)

for i in range(n):
    max_len = min(K, n - i)
    for l in range(1, max_len + 1):
        substr = s[i:i+l]
        unique_substrings.add(substr)

sorted_substrings = sorted(unique_substrings)
print(sorted_substrings[K-1])
```

### Explanation
1. **Generating Substrings**: For each starting index in the string, generate substrings of lengths from 1 up to K, ensuring we do not exceed the string length.
2. **Handling Duplicates**: Using a set ensures that only unique substrings are considered.
3. **Sorting**: The sorted function in Python sorts strings lexicographically by default.
4. **Selecting the K-th Element**: After sorting, the K-th smallest substring is found at index K-1 in the sorted list.

This approach efficiently narrows down the potential candidates for the K-th smallest substring by leveraging the constraint that the K-th smallest substring must be among the shortest K-length substrings, thus ensuring optimal performance even for the upper limits of input size.
