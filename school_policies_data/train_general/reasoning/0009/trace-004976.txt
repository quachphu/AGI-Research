To solve this problem, we need to determine if we can transform a binary string `a` into another binary string `b` using a series of operations. Each operation involves selecting a prefix of `a` with an equal number of 0s and 1s, then inverting all symbols in that prefix.

### Approach
1. **Check Initial Conditions**: First, verify if both strings `a` and `b` have the same number of 0s and 1s. If they don't, transformation is impossible.
2. **Prefix Sum Arrays**: Precompute prefix sums for the number of 0s and 1s in `a` to quickly evaluate any prefix's composition.
3. **Simulate Flips**: Process the string from right to left, keeping track of the current flip state (even or odd number of flips applied). For each position, determine if a flip is needed based on the current state and validate if such a flip is possible by checking the prefix's composition.

import sys

def solve():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline().strip())
        a = sys.stdin.readline().strip()
        b = sys.stdin.readline().strip()
        
        count_a0 = a.count('0')
        count_b0 = b.count('0')
        if count_a0 != count_b0:
            print("NO")
            continue
        
        # Precompute prefix counts of 0s and 1s for a
        prefix0 = [0] * (n + 1)
        prefix1 = [0] * (n + 1)
        for i in range(1, n+1):
            prefix0[i] = prefix0[i-1] + (a[i-1] == '0')
            prefix1[i] = prefix1[i-1] + (a[i-1] == '1')
        
        current_flip = 0
        possible = True
        for i in range(n, 0, -1):
            a_bit = 0 if a[i-1] == '0' else 1
            a_bit ^= current_flip
            b_bit = 0 if b[i-1] == '0' else 1
            if a_bit != b_bit:
                if i % 2 != 0:
                    possible = False
                    break
                # Check if current prefix has equal 0s and 1s when flipped
                total0 = prefix0[i] if current_flip == 0 else prefix1[i]
                total1 = prefix1[i] if current_flip == 0 else prefix0[i]
                if total0 != total1:
                    possible = False
                    break
                # Flip the prefix
                current_flip ^= 1
        print("YES" if possible else "NO")
