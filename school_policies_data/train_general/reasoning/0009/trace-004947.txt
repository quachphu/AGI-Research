To solve this problem, we need to convert a given time in hours and minutes into words. The solution involves handling various cases based on the value of the minutes and converting numerical values into their corresponding word representations.

### Approach
1. **Read Input:** Read the hours (H) and minutes (M) from standard input.
2. **Convert Numbers to Words:** Create a helper function to convert numbers (1-59) into their word equivalents.
3. **Handle Different Cases for Minutes:**
   - **0 minutes:** Directly output the hour followed by "o' clock".
   - **15 minutes:** Output "quarter past" followed by the hour.
   - **30 minutes:** Output "half past" followed by the hour.
   - **45 minutes:** Output "quarter to" followed by the next hour.
   - **1-30 minutes (excluding 15):** Convert minutes to words and output "minutes past" the hour.
   - **31-59 minutes (excluding 45):** Convert remaining minutes (60 - M) to words and output "minutes to" the next hour.

### Solution Code
```python
def number_to_words(n):
    num_words = ["", "one", "two", "three", "four", "five", "six", "seven", "eight", "nine", "ten",
                 "eleven", "twelve", "thirteen", "fourteen", "fifteen", "sixteen", "seventeen", 
                 "eighteen", "nineteen"]
    tens_words = ["twenty", "thirty", "forty", "fifty"]
    if n <= 19:
        return num_words[n]
    else:
        tens = n // 10
        units = n % 10
        res = tens_words[tens - 2]
        if units != 0:
            res += " " + num_words[units]
        return res

H = int(input())
M = int(input())

if M == 0:
    print(f"{number_to_words(H)} o' clock")
elif M == 15:
    print(f"quarter past {number_to_words(H)}")
elif M == 30:
    print(f"half past {number_to_words(H)}")
elif M == 45:
    next_h = H + 1 if H < 12 else 1
    print(f"quarter to {number_to_words(next_h)}")
elif 1 <= M < 30:
    plural = "minute" if M == 1 else "minutes"
    print(f"{number_to_words(M)} {plural} past {number_to_words(H)}")
else:
    remaining = 60 - M
    plural = "minute" if remaining == 1 else "minutes"
    next_h = H + 1 if H < 12 else 1
    print(f"{number_to_words(remaining)} {plural} to {number_to_words(next_h)}")
```

### Explanation
- **number_to_words Function:** This helper function converts numbers from 1 to 59 into their word equivalents. It handles numbers up to 19 directly using a list, and numbers 20-59 by combining tens and units.
- **Handling Different Cases:** The main logic checks the value of minutes (M) and formats the output string accordingly. Special cases for 0, 15, 30, and 45 minutes are handled separately, while other values are processed based on whether they are in the first or second half of the hour.
- **Edge Cases:** Properly handles the transition from 12 to 1 when calculating the next hour for times in the latter half of the hour.

This approach ensures that all possible time configurations are converted accurately into their word representations, providing a clear and precise solution.
