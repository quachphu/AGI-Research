To solve this problem, we need to find the shortest contiguous substring of a given string (composed of characters '1', '2', and '3') that contains all three characters. If such a substring does not exist, we should return 0.

### Approach
1. **Check Presence of All Characters**: For each test case, first check if the string contains all three characters ('1', '2', and '3'). If any of these characters are missing, the result is immediately 0.
2. **Sliding Window Technique**: Use a sliding window approach to efficiently find the shortest substring containing all three characters. Track the last positions of each character ('1', '2', and '3') as we iterate through the string. For each position, if all three characters have been encountered, compute the length of the current valid window and update the minimum length found.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    cases = input[1:t+1]
    for s in cases:
        if len(set(s)) < 3:
            print(0)
            continue
        last_1 = last_2 = last_3 = -1
        min_len = float('inf')
        for i, c in enumerate(s):
            if c == '1':
                last_1 = i
            elif c == '2':
                last_2 = i
            else:
                last_3 = i
            if last_1 != -1 and last_2 != -1 and last_3 != -1:
                current_min = min(last_1, last_2, last_3)
                current_len = i - current_min + 1
                if current_len < min_len:
                    min_len = current_len
        print(min_len if min_len != float('inf') else 0)

solve()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints. The first value is the number of test cases, followed by the strings for each test case.
2. **Check for All Characters**: For each string, check if it contains all three characters using a set. If not, output 0.
3. **Track Last Positions**: As we iterate through the string, update the last seen positions of each character ('1', '2', '3').
4. **Compute Window Length**: Whenever all three characters have been seen, compute the length of the window starting from the earliest of the three last seen positions to the current position. Keep track of the minimum window length encountered.
5. **Output Result**: After processing each string, output the minimum window length found or 0 if no valid window exists (though this case is already handled by the initial check).

This approach ensures an efficient O(n) time complexity per test case, making it suitable for large input sizes as specified in the problem constraints.
