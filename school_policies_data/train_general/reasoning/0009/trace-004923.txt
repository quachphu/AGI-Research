To solve this problem, we need to determine the minimum number of operations required to convert a given integer `a` into another integer `b` using specific operations. The allowed operations are adding a positive odd integer or subtracting a positive even integer. The solution must efficiently handle multiple test cases.

### Approach
1. **Difference Analysis**: The key insight is to analyze the difference between `a` and `b` (denoted as `d`). Depending on whether `a` is less than or greater than `b`, we can determine the minimum steps required based on the parity (odd or even) of the absolute difference.
2. **Case Handling**:
   - If `a` equals `b`, no operations are needed.
   - If `a` is less than `b`:
     - If the difference `d` is odd, we can reach `b` in one step by adding an odd number.
     - If the difference `d` is even, we need two steps, each adding an odd number.
   - If `a` is greater than `b`:
     - If the absolute difference is even, we can reach `b` in one step by subtracting an even number.
     - If the absolute difference is odd, we need two steps: first subtract an even number, then add an odd number.

### Solution Code
```python
t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    if a == b:
        print(0)
    elif a < b:
        delta = b - a
        print(1 if delta % 2 else 2)
    else:
        delta = a - b
        print(1 if delta % 2 == 0 else 2)
```

### Explanation
- **Case 1: `a == b`**: Directly output 0 since no operations are needed.
- **Case 2: `a < b`**:
  - If the difference `d` is odd, we can add an odd number once to reach `b`.
  - If `d` is even, we need two steps (adding two odd numbers whose sum is `d`).
- **Case 3: `a > b`**:
  - If the absolute difference is even, subtract an even number once.
  - If the absolute difference is odd, subtract an even number and then add an odd number, totaling two steps.

This approach ensures that we efficiently determine the minimum steps required using simple arithmetic checks, making the solution both optimal and easy to understand.
