We can precompute for each node v, the sum of 2^{size_subtree[u]} for all children u of v. Let's call this sum_children_2s[v].

This sum can be computed during the post-order traversal. Because when we process a node v (in the post-order step), all of its children have already been processed, so their size_subtree is known.

So during the post-order traversal:

for each node v:

   sum_children_2s[v] = sum( pow2[ size_subtree[u] ] for u in children[v] )

Thus, during the traversal, once the size_subtree for each child is known, we can compute sum_children_2s[v] as the sum of 2^s for each child's subtree size.

But this sum can be calculated as we process the children. So during the post-order traversal, after processing all children, compute sum_children_2s[v] by summing up the 2^{size_subtree[u]} for each child u.

This way, sum_children_2s[v] is O(1) per child.

But for a node with a lot of children (like the root of a star-shaped tree), this sum_children_2s[v] would take O(k) time, where k is the number of children, but since the total number of children across all nodes is O(N) (since it's a tree), the total time for this step is O(N).

Yes. Because each child contributes to exactly one parent's sum_children_2s. Thus, the total time for building sum_children_2s is O(N).

Then, for each node v:

sum_2s = sum_children_2s[v]

if v is not root:

   sum_2s += pow2[ N - size_subtree[v] ]

sum_2s modulo MOD.

This way, the sum_2s for each node can be computed in O(1) time (plus the time for the if condition).

Thus, this approach is feasible.

2. **Sum of Powers of Two**: Precompute powers of two modulo \(10^9 + 7\) to handle large numbers efficiently.
3. **Component Analysis**: For each vertex, determine the sizes of the components formed when the vertex is removed. This involves considering the subtree sizes of its children and the remaining part of the tree.
4. **Probability Calculation**: For each vertex, compute the probability that it contributes to the holeyness using the derived formula, which involves the sum of powers of the component sizes and the degree of the vertex.
5. **Modular Arithmetic**: Use modular inverses to handle division in modular arithmetic efficiently.

MOD = 10**9 + 7

def main():
    import sys
    sys.setrecursionlimit(1 << 25)
    N = int(sys.stdin.readline())
    edges = [[] for _ in range(N+1)]
    for _ in range(N-1):
        a, b = map(int, sys.stdin.readline().split())
        edges[a].append(b)
        edges[b].append(a)
    
    # Precompute powers of 2 modulo MOD
    pow2 = [1] * (N + 2)
    for i in range(1, N + 2):
        pow2[i] = (pow2[i-1] * 2) % MOD
    
    # BFS to build parent and children
    from collections import deque
    root = 1
    parent = [0] * (N + 1)
    children = [[] for _ in range(N + 1)]
    visited = [False] * (N + 1)
    q = deque([root])
    visited[root] = True
    parent[root] = -1
    while q:
        u = q.popleft()
        for v in edges[u]:
            if not visited[v]:
                visited[v] = True
                parent[v] = u
                children[u].append(v)
                q.append(v)
    
    # Post-order traversal to compute size_subtree and sum_children_2s
    size_subtree = [0] * (N + 1)
    sum_children_2s = [0] * (N + 1)
    stack = [(root, False)]
    while stack:
        u, processed = stack.pop()
        if not processed:
            stack.append((u, True))
            for v in reversed(children[u]):
                stack.append((v, False))
        else:
            size_subtree[u] = 1
            s = 0
            for v in children[u]:
                size_subtree[u] += size_subtree[v]
                s = (s + pow2[size_subtree[v]]) % MOD
            sum_children_2s[u] = s
    
    total = 0
    inv_2N = pow(pow2[N], MOD-2, MOD)
    pow2_Nminus1 = pow2[N-1]
    
    for v in range(1, N+1):
        sum_2s = sum_children_2s[v]
        if parent[v] != -1:  # not root
            s_parent = (N - size_subtree[v]) % (MOD-1)  # size is N - size_subtree[v]
            sum_2s = (sum_2s + pow2[s_parent]) % MOD
        d = len(edges[v])
        term = (pow2_Nminus1 - sum_2s + (d - 1)) % MOD
        total = (total + term) % MOD
    
    ans = (total * inv_2N) % MOD
    print(ans)

if __name__ == '__main__':
    main()
