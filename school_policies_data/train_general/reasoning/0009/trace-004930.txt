To solve this problem, we need to determine the minimum number of temperature changes required to ensure that the temperature sequence meets Vasya's condition. The condition is that there exists a point in the sequence such that all temperatures before this point are negative and all temperatures after this point are positive. Zero temperatures are not allowed at any point.

### Approach
1. **Prefix and Suffix Arrays**: 
   - **Prefix Array (`prefix_neg`)**: This array keeps track of the number of non-negative temperatures (>= 0) up to each day. This helps in quickly determining how many changes are needed to convert the first part of the sequence to all negative.
   - **Suffix Array (`suffix_pos`)**: This array keeps track of the number of non-positive temperatures (<= 0) from each day to the end of the sequence. This helps in quickly determining how many changes are needed to convert the second part of the sequence to all positive.

2. **Iterate Over Possible Split Points**:
   - For each possible split point `k` (from 1 to n-1), calculate the total changes required as the sum of changes needed for the first part (up to `k`) and the second part (from `k+1` to the end).
   - The minimum value of these sums across all possible split points is the answer.

### Solution Code
```python
n = int(input())
t = list(map(int, input().split()))

prefix_neg = [0] * (n + 1)
for i in range(1, n + 1):
    prefix_neg[i] = prefix_neg[i - 1] + (1 if t[i - 1] >= 0 else 0)

suffix_pos = [0] * (n + 2)
for i in range(n, 0, -1):
    suffix_pos[i] = suffix_pos[i + 1] + (1 if t[i - 1] <= 0 else 0)

min_changes = float('inf')
for k in range(1, n):
    current = prefix_neg[k] + suffix_pos[k + 1]
    if current < min_changes:
        min_changes = current

print(min_changes)
```

### Explanation
1. **Reading Input**: The input consists of the number of days `n` and the sequence of temperatures.
2. **Prefix Array Calculation**: The `prefix_neg` array is built by iterating through the temperature list and counting how many temperatures up to each day are non-negative.
3. **Suffix Array Calculation**: The `suffix_pos` array is built by iterating backwards through the temperature list and counting how many temperatures from each day to the end are non-positive.
4. **Finding Minimum Changes**: For each possible split point `k`, the total changes required are the sum of the changes needed for the first part (using `prefix_neg`) and the second part (using `suffix_pos`). The minimum of these values is the result.

This approach ensures that we efficiently compute the minimum number of changes needed in O(n) time, making it suitable for large input sizes up to 100,000 days.
