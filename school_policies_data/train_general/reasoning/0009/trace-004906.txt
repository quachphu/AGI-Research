To solve this problem, we need to determine the minimum possible total increase in fatigue level when visiting all towns starting from town 1, using either walking or teleportation. The towns are arranged in a line from west to east, and we must visit each town in order.

### Approach
The key insight is that for each consecutive pair of towns, we can choose between walking (costing A per unit distance) or teleporting (fixed cost B). The optimal strategy is to calculate the cost for each segment between consecutive towns and choose the cheaper option for each segment. Summing these minimum costs for all segments will give the minimum total fatigue.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    A = int(input[1])
    B = int(input[2])
    X = list(map(int, input[3:3+N]))
    total = 0
    for i in range(N-1):
        d = X[i+1] - X[i]
        total += min(d * A, B)
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of towns (N), the cost per unit distance for walking (A), the fixed cost for teleportation (B), and the list of town coordinates (X).
2. **Iterate Through Segments**: For each consecutive pair of towns, compute the distance between them.
3. **Calculate Minimum Cost**: For each segment, determine the minimum cost between walking (distance multiplied by A) and teleporting (fixed cost B).
4. **Sum Costs**: Accumulate the minimum costs for all segments to get the total minimum fatigue.

This approach ensures that we efficiently compute the minimum cost for each segment in linear time, O(N), which is optimal for the problem constraints.
