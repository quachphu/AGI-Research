### Approach
1. **Understanding the Water Charge Structure**: The water charge consists of a fixed basic charge and a variable charge based on usage tiers. The tiers are:
   - First 10 m³: Covered by the basic charge of 1150 yen.
   - Next 10 m³ (10-20 m³): 125 yen per m³.
   - Next 10 m³ (20-30 m³): 140 yen per m³.
   - Any usage above 30 m³: 160 yen per m³.

2. **Reading Input**: The input consists of multiple datasets, each representing the current month's water usage. The input ends with -1.

3. **Calculating Current Month's Charge**: For each water usage value, we compute the variable charge based on the tiers and add it to the basic charge.

4. **Comparing with Last Month's Charge**: For each dataset, compute the difference between last month's charge (4280 yen) and the current month's charge to determine the savings.

### Solution Code
```python
def main():
    import sys
    last_month_charge = 4280
    for line in sys.stdin:
        line = line.strip()
        if line == '-1':
            break
        w = int(line)
        volume_charge = 0
        if w > 10:
            # Calculate second stage (10 to 20 m³)
            second = min(w - 10, 10)
            volume_charge += second * 125
            remaining = w - 10 - second
            if remaining > 0:
                # Calculate third stage (20 to 30 m³)
                third = min(remaining, 10)
                volume_charge += third * 140
                remaining -= third
                if remaining > 0:
                    # Calculate fourth stage (over 30 m³)
                    volume_charge += remaining * 160
        current_charge = 1150 + volume_charge
        print(last_month_charge - current_charge)

main()
```

### Explanation
1. **Reading Input**: The code reads each line of input until it encounters -1, which signals the end of input.
2. **Volume Charge Calculation**: For each water usage value `w`, the code calculates the charge based on the tiers:
   - **Second Stage (10-20 m³)**: If usage exceeds 10 m³, the charge for the next 10 m³ is calculated at 125 yen per m³.
   - **Third Stage (20-30 m³)**: If usage exceeds 20 m³, the charge for the next 10 m³ is calculated at 140 yen per m³.
   - **Fourth Stage (30+ m³)**: If usage exceeds 30 m³, the charge for any additional usage is calculated at 160 yen per m³.
3. **Total Charge Calculation**: The total charge is the sum of the basic charge (1150 yen) and the calculated volume charge.
4. **Savings Calculation**: The savings for each month is determined by subtracting the current month's charge from last month's charge (4280 yen).

This approach ensures that each tier is handled correctly, and the savings are computed efficiently for each input value.
