To solve this problem, we need to determine if Arkady can hold a round immediately after creating each problem. A round can be held if there are exactly `n` problems in the pool, each with distinct difficulties from 1 to `n`. Once a round is held, those `n` problems are removed from the pool.

### Approach
1. **Track Problem Counts**: Maintain a count of how many times each difficulty level has been added to the pool.
2. **Frequency Tracking**: Use a frequency dictionary to keep track of how many difficulties have a specific count of problems.
3. **Current Minimum**: Track the minimum count of problems among all difficulties. This helps in quickly determining if a round can be held.
4. **Update and Check**: For each problem added, update the count and frequency, adjust the current minimum if necessary, and check if a round can be held by comparing the minimum count with the total rounds held so far.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n, m = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    
    added = [0] * (n + 1)  # 1-based indexing
    freq = defaultdict(int)
    current_min = 0
    freq[0] = n
    total_rounds = 0
    output = []
    
    for d in a:
        prev = added[d]
        freq[prev] -= 1
        if prev == current_min and freq[prev] == 0:
            current_min += 1
        added[d] += 1
        freq[prev + 1] += 1
        
        k = current_min - total_rounds
        if k >= 1:
            output.append('1')
            total_rounds += k
        else:
            output.append('0')
    
    print(''.join(output))

if __name__ == "__main__":
    main()
```

1. **Initialization**: We initialize arrays and variables to track the counts of each difficulty, the frequency of these counts, the current minimum count, and the total rounds held.
2. **Processing Each Problem**: For each problem created:
   - Update the count and frequency for the current difficulty.
   - Adjust the current minimum if the previous minimum count is exhausted.
   - Check if the current minimum count allows for new rounds to be held by comparing it with the total rounds held so far.
3. **Output**: Append '1' if a round is held immediately after the current problem, otherwise '0'.

This approach efficiently tracks the necessary metrics using O(n) space and processes each problem in O(1) time, leading to an overall time complexity of O(m), which is optimal for the given constraints.
