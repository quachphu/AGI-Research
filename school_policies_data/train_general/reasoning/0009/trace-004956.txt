To solve this problem, we need to determine the minimum price of a set menu that includes one pasta and one juice from their respective daily offerings. The price of the set menu is calculated as the sum of the chosen pasta and juice prices minus 50 yen. Our goal is to find the cheapest possible combination.

### Approach
1. **Input Reading**: Read the prices of three pastas and two juices.
2. **Find Minimum Prices**: Identify the cheapest pasta and the cheapest juice from their respective lists.
3. **Calculate Set Menu Price**: Sum the minimum prices of the selected pasta and juice, then subtract 50 yen to get the final price of the set menu.

### Solution Code
```python
def main():
    pasta = [int(input()) for _ in range(3)]
    juice = [int(input()) for _ in range(2)]
    total = min(pasta) + min(juice) - 50
    print(total)

main()
```

### Explanation
1. **Reading Inputs**: The code reads three integers representing pasta prices followed by two integers representing juice prices.
2. **Finding Minimum Prices**: Using Python's built-in `min()` function, the code efficiently finds the minimum price among the pastas and the minimum price among the juices.
3. **Calculating the Result**: The sum of these two minimum prices is reduced by 50 yen to get the set menu price, which is then printed.

This approach ensures that we always select the cheapest possible combination of pasta and juice, thereby minimizing the total cost of the set menu. The solution efficiently processes the inputs and computes the result in linear time relative to the number of pastas and juices, which is optimal for this problem.
