To solve this problem, we need to find the minimum path length between vertex 1 and vertex n in an undirected graph where the path length is defined as the bitwise XOR of all edge weights along the path. The key insight is that traversing an edge an even number of times cancels its contribution to the XOR, allowing us to use cycles in the graph to minimize the path length.

### Approach
1. **Breadth-First Search (BFS)**: Compute the XOR distance from the start node (vertex 1) to all other nodes. This helps in identifying cycles and their contributions to the XOR path.
2. **Cycle Detection**: During BFS, detect cycles by checking back edges. The XOR of the edges forming a cycle can be used to adjust the initial path's XOR value.
3. **Linear Basis (Gaussian Elimination)**: Construct a basis for the XOR values of detected cycles using Gaussian elimination over GF(2). This basis allows us to efficiently compute the minimum possible XOR value by adjusting the initial path value with cycle contributions.

### Solution Code
```python
import sys
from collections import deque

def main():
    n, m = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        x, y, w = map(int, sys.stdin.readline().split())
        adj[x].append((y, w))
        adj[y].append((x, w))
    
    xor = [-1] * (n + 1)
    xor[1] = 0
    q = deque([1])
    basis = [0] * 32  # Assuming 32-bit integers
    
    while q:
        u = q.popleft()
        for v, w in adj[u]:
            if xor[v] == -1:
                xor[v] = xor[u] ^ w
                q.append(v)
            else:
                cycle_xor = (xor[u] ^ w) ^ xor[v]
                if cycle_xor != 0:
                    # Add cycle_xor to the basis
                    x = cycle_xor
                    for i in reversed(range(32)):
                        if (x >> i) & 1:
                            if basis[i]:
                                x ^= basis[i]
                            else:
                                basis[i] = x
                                break
    
    initial_xor = xor[n]
    current = initial_xor
    for i in reversed(range(32)):
        if basis[i] and (current & (1 << i)):
            current ^= basis[i]
    
    print(current)

if __name__ == "__main__":
    main()
```

1. **BFS for XOR Calculation**: Start from vertex 1 and compute the XOR path to all reachable vertices. This helps in determining the initial XOR value from vertex 1 to vertex n.
2. **Cycle Detection and Basis Construction**: For each back edge encountered during BFS, compute the cycle's XOR contribution. Use Gaussian elimination to build a linear basis of these cycle contributions.
3. **Minimize Path XOR**: Using the linear basis, adjust the initial XOR value from vertex 1 to vertex n to find the minimum possible value. This involves XORing the initial value with combinations of basis vectors to minimize the result.

This approach efficiently leverages cycle contributions to adjust the path length using bitwise operations, ensuring an optimal solution even for large graphs.
