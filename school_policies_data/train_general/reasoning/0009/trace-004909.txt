To solve this problem, we need to calculate the distance between the positions of two red dragonflies on a wall based on their given coordinates. The solution involves computing the absolute difference between these two positions.

### Approach
1. **Reading Input**: The input consists of two integers representing the positions of the dragonflies. These integers are read from standard input.
2. **Calculating Distance**: The distance between two points on a straight line is the absolute difference of their positions. This is computed using the formula `abs(x1 - x2)` where `x1` and `x2` are the positions of the dragonflies.
3. **Output the Result**: The computed distance is then printed to the standard output.

### Solution Code
```python
def main():
    x1, x2 = map(int, input().split())
    print(abs(x1 - x2))

main()
```

### Explanation
- **Reading Input**: The input is read as a single line containing two integers separated by a space. Using `input().split()`, we split this line into two parts, which are then converted to integers using `map(int, ...)`.
- **Calculating Distance**: The absolute difference between the two integers is computed using `abs(x1 - x2)`, which ensures the result is non-negative regardless of the order of the positions.
- **Output**: The result is printed directly, providing the required distance between the two dragonflies.

This approach efficiently computes the distance with a time complexity of O(1), as it involves only a few arithmetic operations and input/output handling. The solution handles all edge cases, including when the positions are the same (resulting in zero distance).
