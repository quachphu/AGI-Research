To solve this problem, we need to maximize the beauty of a tree by assigning values to each node such that the sum of absolute differences across all edges is maximized. Each node has a range of possible values, and we need to choose values within these ranges to achieve the highest possible beauty.

### Approach
1. **Tree Structure**: The tree is represented using an adjacency list.
2. **Dynamic Programming (DP) on Trees**: For each node, we maintain two values: the maximum beauty achievable if the node is assigned its minimum value (`dp_l`) and if it is assigned its maximum value (`dp_r`).
3. **Post-order Traversal**: We traverse the tree in post-order to compute the DP values for each node. This ensures that we process all children of a node before the node itself, allowing us to accumulate contributions from all subtrees correctly.
4. **Edge Contribution**: For each edge between a parent and a child, we consider both possible assignments (min and max) for the child and choose the one that maximizes the edge contribution plus the subtree contribution.

### Solution Code
```python
import sys
from sys import stdin

def main():
    sys.setrecursionlimit(1 << 25)
    t = int(stdin.readline())
    for _ in range(t):
        n = int(stdin.readline())
        l = [0] * (n + 1)
        r = [0] * (n + 1)
        for i in range(1, n+1):
            li, ri = map(int, stdin.readline().split())
            l[i] = li
            r[i] = ri
        adj = [[] for _ in range(n+1)]
        for _ in range(n-1):
            u, v = map(int, stdin.readline().split())
            adj[u].append(v)
            adj[v].append(u)
        
        dp_l = [0] * (n + 1)
        dp_r = [0] * (n + 1)
        stack = [(1, None, False)]
        
        while stack:
            u, parent, visited = stack.pop()
            if not visited:
                stack.append((u, parent, True))
                children = []
                for v in adj[u]:
                    if v != parent:
                        children.append(v)
                for v in reversed(children):
                    stack.append((v, u, False))
            else:
                current_dp_l = 0
                current_dp_r = 0
                for v in adj[u]:
                    if v == parent:
                        continue
                    current_dp_l += max(abs(l[u] - l[v]) + dp_l[v], abs(l[u] - r[v]) + dp_r[v])
                    current_dp_r += max(abs(r[u] - l[v]) + dp_l[v], abs(r[u] - r[v]) + dp_r[v])
                dp_l[u] = current_dp_l
                dp_r[u] = current_dp_r
        
        print(max(dp_l[1], dp_r[1]))

if __name__ == "__main__":
    main()
```
