To solve this problem, we need to determine the minimum time required to recalibrate a corrupt DNA string into the original DNA string using replacements (each replacement takes 1 unit of time). Adding nucleobases to the ends of the corrupt DNA does not consume any time. The goal is to find the optimal alignment of the corrupt DNA as a substring of the original DNA to minimize the number of replacements.

### Approach
1. **Input Reading**: Read the number of test cases and the respective original and corrupt DNA strings for each test case.
2. **Sliding Window Technique**: For each test case, slide a window of the same length as the corrupt DNA over the original DNA. This window represents a potential substring of the original DNA that the corrupt DNA can be aligned to.
3. **Mismatch Counting**: For each position of the window, count the number of mismatches between the corrupt DNA and the substring of the original DNA. The minimum number of mismatches across all possible window positions gives the minimum time required for recalibration.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        original = input[idx]
        idx += 1
        corrupt = input[idx]
        idx += 1
        len_orig = len(original)
        len_corrupt = len(corrupt)
        min_time = float('inf')
        for i in range(len_orig - len_corrupt + 1):
            substr = original[i:i+len_corrupt]
            diff = sum(1 for a, b in zip(substr, corrupt) if a != b)
            if diff < min_time:
                min_time = diff
        print(min_time)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list for easier processing. The first element gives the number of test cases.
2. **Processing Each Test Case**: For each test case, the original and corrupt DNA strings are extracted.
3. **Sliding Window**: The sliding window iterates over all possible starting positions in the original DNA where a substring of the same length as the corrupt DNA can be found.
4. **Mismatch Calculation**: For each window position, the number of mismatches between the substring of the original DNA and the corrupt DNA is counted. The minimum number of mismatches across all window positions is determined and printed as the result for that test case.

This approach ensures that we efficiently find the optimal alignment with the minimum number of replacements, thus minimizing the recalibration time.
