The solution involves calculating the time taken for both options and choosing the faster one. If both times are equal, the lift is preferred.

### Approach
1. **Stairs Time Calculation**: The time taken using the stairs is straightforward. Jack takes 10 seconds per floor, so the total time is \( J \times 10 \) seconds.

2. **Lift Time Calculation**:
   - **Reaching Jack's Floor (J)**: The lift's movement depends on its initial direction (Up or Down) and its current floor (L). We need to compute the time for the lift to reach Jack's floor, considering possible stops and direction changes.
   - **Reaching Ground Floor from J**: After picking up Jack, the lift's direction (determined by its path to reach J) will affect the time taken to reach the ground floor. If moving down, it goes directly; if moving up, it must reach the top floor (n) first, then change direction.

### Solution Code

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        n = int(input[idx])
        J = int(input[idx+1])
        L = int(input[idx+2])
        D = input[idx+3].strip()
        idx += 4
        
        stairs_time = J * 10
        
        if D == 'U':
            if J >= L:

                    step1 = (n - L) * 5 + 10
                    dir_after = 'D'
                else:
                    step1 = (J - L) * 5 + 10
                    dir_after = 'U'
            else:
                step1 = (n - L + n - J) * 5 + 20
                dir_after = 'D'
        else:
            if J <= L:
                step1 = (L - J) * 5 + 10
                dir_after = 'D'
            else:
                step1 = (L + J) * 5 + 20
                dir_after = 'U'
        
        if dir_after == 'D':
            step2 = J * 5 + 10
        else:
            step2 = ((n - J) + n) * 5 + 20
        
        lift_time = step1 + step2
