To solve this problem, we need to maximize the total width of lawns demolished while ensuring that the new road widths of consecutive parts differ by at most 1. The solution involves a two-pass approach to adjust the maximum possible road widths while maintaining the required constraints.

### Approach
1. **Initial Setup**: For each part of the street, calculate the maximum possible road width after demolishing the entire lawn. This is given by `s_i + g_i`.
2. **Left-to-Right Pass**: Adjust the maximum possible road width for each part such that it does not exceed the previous part's road width by more than 1.
3. **Right-to-Left Pass**: Further adjust the road widths to ensure that each part does not exceed the next part's road width by more than 1.
4. **Validation Check**: Ensure that all adjusted road widths are at least the original road width. If any adjusted width is less than the original, output `-1` as it's impossible to meet the constraints.
5. **Result Calculation**: Sum the total demolished lawn width and print the result.

### Solution Code
```python
n = int(input())
s = []
g = []
for _ in range(n):
    a, b = map(int, input().split())
    s.append(a)
    g.append(b)

s_max = [s[i] + g[i] for i in range(n)]

# Left to right pass
for i in range(1, n):
    s_max[i] = min(s_max[i], s_max[i-1] + 1)

# Right to left pass
for i in range(n-2, -1, -1):
    s_max[i] = min(s_max[i], s_max[i+1] + 1)

# Check validity
valid = True
for i in range(n):
    if s_max[i] < s[i]:
        valid = False
        break

if not valid:
    print(-1)
else:
    total = sum(s_max[i] - s[i] for i in range(n))
    print(total)
    print(' '.join(map(str, s_max)))
```

### Explanation
1. **Initial Setup**: We start by reading the input values and initializing the maximum possible road widths as `s_i + g_i`.
2. **Left-to-Right Pass**: This pass ensures that each part's maximum road width does not exceed the previous part's width by more than 1. This is done by iterating from the first to the last part and adjusting each width based on the previous part's width.
3. **Right-to-Left Pass**: This pass ensures that each part's maximum road width does not exceed the next part's width by more than 1. We iterate from the second last part to the first, adjusting each width based on the next part's width.
4. **Validation Check**: After both passes, we check if all adjusted widths are at least the original road widths. If any part fails this check, the solution is impossible.
5. **Result Calculation**: If valid, we compute the total demolished lawn width and print the results.

This approach efficiently ensures that the constraints are met while maximizing the demolished lawn width, operating in linear time complexity O(n), making it suitable for large input sizes up to 200,000.
