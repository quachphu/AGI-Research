To solve this problem, we need to determine if there exists a multiple of a given integer K within the range [A, B]. If such a multiple exists, we print "OK"; otherwise, we print "NG".

### Approach
The key insight is to check if the largest multiple of K that is less than or equal to B is also greater than or equal to A. This can be efficiently computed using integer division and multiplication:
1. Compute the largest multiple of K that is less than or equal to B. This can be found using the formula `(B // K) * K`.
2. Check if this largest multiple is greater than or equal to A. If it is, there exists at least one multiple of K within the range [A, B], otherwise there does not.

### Solution Code
```python
k = int(input())
a, b = map(int, input().split())
max_multiple = (b // k) * k
print("OK" if max_multiple >= a else "NG")
```

### Explanation
1. **Reading Input**: The code reads the integer K from the first line and the integers A and B from the second line.
2. **Finding the Largest Multiple**: Using integer division, `(B // K) * K` computes the largest multiple of K that is less than or equal to B.
3. **Check Condition**: If this largest multiple is greater than or equal to A, it means there is at least one multiple of K within the range [A, B], so we print "OK". Otherwise, we print "NG".

This approach efficiently determines the existence of such a multiple without iterating through the entire range, making it both time and space efficient.
