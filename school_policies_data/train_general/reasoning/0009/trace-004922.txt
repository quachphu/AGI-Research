To solve this problem, we need to find the minimal possible difference between the largest and smallest numbers after rearranging the digits of each number using the same permutation rule. The solution involves generating all possible permutations of the digit positions and applying each permutation to all numbers to determine the optimal rearrangement.

### Approach
1. **Input Reading**: Read the number of integers (n) and their digit capacity (k), followed by the list of k-digit numbers.
2. **Permutation Generation**: Generate all possible permutations of the digit positions (indices from 0 to k-1).
3. **Transform Numbers**: For each permutation, rearrange each number according to the permutation and convert it to an integer.
4. **Compute Difference**: For each permutation, compute the difference between the maximum and minimum values of the transformed numbers.
5. **Track Minimum Difference**: Keep track of the smallest difference encountered across all permutations.

### Solution Code
```python
import itertools

n, k = map(int, input().split())
nums = [input().strip() for _ in range(n)]

min_diff = float('inf')

for perm in itertools.permutations(range(k)):
    transformed = []
    for num in nums:
        rearranged = ''.join(num[i] for i in perm)
        transformed.append(int(rearranged))
    current_max = max(transformed)
    current_min = min(transformed)
    diff = current_max - current_min
    if diff < min_diff:
        min_diff = diff

print(min_diff)
```

### Explanation
1. **Permutation Generation**: Using `itertools.permutations`, we generate all possible ways to reorder the digits of each number. Each permutation represents a different rule for rearranging the digits.
2. **Transforming Numbers**: For each permutation, we apply the same rearrangement rule to each number. This involves reordering the digits of each number according to the current permutation and converting the result into an integer.
3. **Difference Calculation**: For each permutation, after transforming all numbers, we compute the difference between the largest and smallest numbers. We track the minimum difference across all permutations to find the optimal solution.

This approach ensures that we explore all possible digit rearrangements systematically, guaranteeing that we find the minimal possible difference. The complexity is manageable given the constraints (k up to 8), making this brute-force approach feasible.
