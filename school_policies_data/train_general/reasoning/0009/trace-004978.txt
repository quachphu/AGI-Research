To solve this problem, we need to determine the final state of a 3x3 grid of lights after each light has been pressed a certain number of times. Each press toggles the light and its adjacent lights. The solution involves calculating the total number of toggles for each light and determining its state based on whether the total is even or odd.

### Approach
1. **Input Reading**: Read the 3x3 grid input which represents the number of times each light is pressed.
2. **Toggle Calculation**: For each light, calculate the total number of times it has been toggled by summing the presses from itself and its adjacent cells.
3. **State Determination**: Determine the state of each light based on the parity (even or odd) of the total toggles. If the total is even, the light remains on (state "1"); if odd, it turns off (state "0").

### Solution Code
```python
def calculate_light_states():
    # Read the input grid
    press = [list(map(int, input().split())) for _ in range(3)]
    
    # Initialize the result grid
    result = []
    for i in range(3):
        row = []
        for j in range(3):
            total = 0
            # Check all possible directions including the cell itself
            for dx, dy in [(-1, 0), (1, 0), (0, -1), (0, 1), (0, 0)]:
                x = i + dx
                y = j + dy
                if 0 <= x < 3 and 0 <= y < 3:
                    total += press[x][y]
            # Determine if the light is on (1) or off (0)
            row.append('1' if total % 2 == 0 else '0')
        result.append(''.join(row))
    
    # Print the result
    for line in result:
        print(line)

# Execute the function
calculate_light_states()
```

### Explanation
1. **Reading Input**: The input is read as a 3x3 grid where each element represents the number of times a specific light is pressed.
2. **Toggle Calculation**: For each light at position (i, j), the total toggles are calculated by summing the presses from the light itself and its adjacent cells (up, down, left, right). This is done by iterating over each possible direction and checking if the resulting position is within the grid bounds.
3. **State Determination**: The state of each light is determined by checking if the total number of toggles is even or odd. If even, the light remains on (1); if odd, it turns off (0).

This approach efficiently computes the final state of each light by considering all possible influences from adjacent presses, ensuring an accurate and optimal solution.
