To solve this problem, we need to determine the number of integers \( i \) in a permutation \( P \) such that \( P_i \) is the minimum value among the first \( i \) elements of the permutation. 

### Approach
The key insight here is that for each position \( i \) in the permutation, we need to check if \( P_i \) is the minimum value encountered so far up to that position. If it is, we count this position. 

The approach involves iterating through the permutation while maintaining the current minimum value. For each element, we update the current minimum and check if the current element equals this minimum. If it does, we increment our count.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    p = list(map(int, input[1:n+1]))
    current_min = float('inf')
    count = 0
    for num in p:
        current_min = min(current_min, num)
        if num == current_min:
            count += 1
    print(count)

main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first value is \( N \), the length of the permutation, followed by the permutation values.
2. **Tracking Minimum**: We initialize `current_min` to a very high value (infinity) to ensure the first element of the permutation will be the initial minimum.
3. **Iterating Through Elements**: For each element in the permutation, we update `current_min` to be the minimum of the current value and `current_min`.
4. **Counting Valid Positions**: Each time the current element equals `current_min`, it means this element is the minimum of the elements processed so far, so we increment our count.
5. **Output Result**: Finally, we print the count of such valid positions.

This approach efficiently processes each element exactly once, resulting in an \( O(N) \) time complexity, which is optimal for the given problem constraints.
