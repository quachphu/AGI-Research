To solve this problem, we need to determine two values for each test case: the number of ways Roy can cut a log of length L into pieces of 1 or 2 units (W) and the minimum number of cuts required (M).

### Approach
1. **Understanding the Minimum Cuts (M)**:
   - The minimum number of cuts is achieved by using as many 2-unit pieces as possible. This is because each 2-unit piece reduces the number of pieces (and thus cuts) needed compared to using 1-unit pieces.
   - The number of pieces when using maximum 2-unit pieces is given by \(\lceil \frac{L}{2} \rceil\). The minimum cuts required will be this number of pieces minus 1, as each cut increases the number of pieces by 1.

2. **Calculating the Number of Ways (W)**:
   - The number of ways to partition the log into 1-unit and 2-unit pieces is equivalent to the number of combinations of 2-unit pieces that can be used. This is determined by the possible counts of 2-unit pieces (from 0 up to \(\lfloor \frac{L}{2} \rfloor\)), leading to \(\lfloor \frac{L}{2} \rfloor + 1\) ways.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        l = int(sys.stdin.readline())
        w = (l // 2) + 1
        m = ((l + 1) // 2) - 1
        print(w, m)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency, especially given the constraints.
- **Calculating W**: For each length \( L \), the number of ways \( W \) is computed as \(\lfloor \frac{L}{2} \rfloor + 1\). This formula accounts for all possible counts of 2-unit pieces from 0 to the maximum possible.
- **Calculating M**: The minimum number of cuts is derived by first determining the number of pieces when using the maximum number of 2-unit pieces, which is \(\lceil \frac{L}{2} \rceil\). Subtracting 1 from this value gives the minimum cuts required.

This approach ensures that both values are computed efficiently in constant time \( O(1) \) per test case, making the solution suitable for large input sizes up to \( 10^9 \).
