To solve this problem, we need to determine the number of '1's and '0's in a magical string after Oz touches it M times. The string starts as "1", and each touch transforms all '1's to '0's and all '0's to "01".

### Approach
1. **Understanding the Transformation**:
   - Each '1' becomes '0' when touched.
   - Each '0' becomes "01" when touched.
   
2. **Recurrence Relations**:
   - Let `zeros[m]` be the number of '0's after m touches.
   - Let `ones[m]` be the number of '1's after m touches.
   - The recurrence relations derived from the transformation rules are:
     - `zeros[m] = ones[m-1] + zeros[m-1]`
     - `ones[m] = zeros[m-1]`
   
3. **Precomputation**:
   - Precompute the values of `zeros` and `ones` for all possible values of M (up to 90) using dynamic programming. This allows us to answer each query in constant time.

### Solution Code
```python
def main():
    max_m = 90
    zeros = [0] * (max_m + 1)
    ones = [0] * (max_m + 1)
    zeros[0] = 0
    ones[0] = 1
    
    for m in range(1, max_m + 1):
        zeros[m] = ones[m-1] + zeros[m-1]
        ones[m] = zeros[m-1]
    
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    ptr = 1
    for _ in range(T):
        M = int(input[ptr])
        ptr += 1
        print(f"{ones[M]} {zeros[M]}")

main()
```

### Explanation
1. **Initialization**:
   - Start with `zeros[0] = 0` and `ones[0] = 1` since the initial string is "1".

2. **Dynamic Programming**:
   - For each touch from 1 to 90, compute the number of '0's and '1's using the recurrence relations. This precomputation ensures that each query is answered in O(1) time.

3. **Processing Input**:
   - Read the number of test cases and each value of M. For each M, output the precomputed values of `ones[M]` and `zeros[M]`.

This approach efficiently handles up to 90 touches by leveraging dynamic programming to precompute results, ensuring quick responses to each query.
