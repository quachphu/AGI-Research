To solve this problem, we need to determine the number of valid substrings (contiguous sequences) of dresses such that the count of special dresses within each substring falls within a given range [L, R]. The solution involves using prefix sums and binary search to efficiently compute the valid substrings.

### Approach
1. **Prefix Sum Array**: Compute a prefix sum array where each element at index `i` represents the cumulative count of special dresses from the start up to the `i`-th dress.
2. **Binary Search**: For each starting index `A`, use binary search to determine the valid ending indices `B` such that the count of special dresses in the substring [A, B] lies within the range [L, R]. This involves:
   - Finding the first index `B_start` where the count of special dresses is at least `L`.
   - Finding the last index `B_end` where the count of special dresses is at most `R`.
3. **Efficiency**: By leveraging the non-decreasing property of the prefix sum array, binary search operations can be performed in logarithmic time, making the solution efficient even for large input sizes.

### Solution Code
```python
import bisect

def count_valid_substrings():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        K = int(input[ptr+1])
        L = int(input[ptr+2])
        R = int(input[ptr+3])

        S = input[ptr]
        ptr +=1
        special_chars = input[ptr]
        ptr +=1
        special_set = set(special_chars)
        # Compute prefix array
        prefix = [0] * (N + 1)
        for i in range(1, N+1):
            prefix[i] = prefix[i-1] + (1 if S[i-1] in special_set else 0)
        total = 0
        for A in range(1, N+1):
            prev = prefix[A-1]
            target_low = prev + L
            target_high = prev + R
            # Find B_start >= A where prefix[B] >= target_low
            B_start = bisect.bisect_left(prefix, target_low, A, N+1)
            if B_start > N:

            # Find B_end >= A where prefix[B] <= target_high
            B_end = bisect.bisect_right(prefix, target_high, A, N+1) - 1
            if B_end < A:
                continue
            if B_start > B_end:
                continue
            total += B_end - B_start + 1
        print(total)
```

3. **Binary Search for Valid Substrings**: For each starting index `A`, the target range for the prefix sum of the ending index `B` is calculated. Using binary search, we determine the valid range of `B` values efficiently.
4. **Summing Valid Substrings**: The count of valid substrings for each starting index `A` is accumulated to get the final result for each test case.

This approach ensures that we efficiently count valid substrings without checking each possible substring individually, leading to a time complexity of O(N log N) per test case, which is feasible for large input sizes.
