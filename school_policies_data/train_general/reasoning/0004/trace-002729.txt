To solve this problem, we need to determine the minimum time required to copy a PDF file from one computer to all N computers using M pendrives. The process involves copying the PDF from a computer to a pendrive or from a pendrive to a computer, each taking exactly 1 minute. The goal is to optimize the copying process to minimize the total time.

### Approach
The problem can be broken down into two main phases:
1. **Exponential Growth Phase**: In this phase, we focus on filling up the pendrives as quickly as possible. Each pendrive can be used to copy the PDF to a computer once it's filled. The number of pendrives filled each minute is limited by the number of available computers and the remaining pendrive slots. During this phase, both the number of filled pendrives and the number of computers with the PDF grow exponentially.
2. **Linear Growth Phase**: Once all M pendrives are filled, we can use all M pendrives each minute to copy the PDF to M new computers. This phase continues until all N computers have the PDF.

### Solution Code
```python
import sys

def minimal_time():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        N = int(input[idx])
        M = int(input[idx+1])
        idx += 2
        if N == 1:
            print(0)
            continue
        time = 0
        c = 1
        p = 0
        while c < N:
            if p < M:
                x = min(c, M - p)
                new_p = p + x
                new_c = c + p
                time += 1
                c, p = new_c, new_p
            else:
                remaining = N - c
                steps = (remaining + M - 1) // M
                time += steps
                break
        print(time)

minimal_time()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Handling Each Test Case**: For each test case, we initialize the number of computers (c) to 1 (since one computer already has the PDF) and the number of filled pendrives (p) to 0.
3. **Exponential Growth Phase**: Until all pendrives are filled (p < M), we calculate the maximum number of pendrives that can be filled in the current minute (x). We then update the number of filled pendrives and the number of computers. This process continues until all pendrives are filled.
4. **Linear Growth Phase**: Once all pendrives are filled, we calculate the remaining computers that need the PDF and determine the number of minutes required using all M pendrives each minute.
5. **Output the Result**: The total time for each test case is printed after processing.

This approach ensures that we minimize the time by leveraging the exponential growth of available sources (computers and pendrives) and then switching to a linear growth strategy once all pendrives are utilized. This method efficiently handles the constraints and provides the optimal solution.
