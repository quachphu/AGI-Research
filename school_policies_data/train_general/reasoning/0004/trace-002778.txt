To solve this problem, we need to efficiently handle range updates on a string of digits and compute the value of the string modulo 998244353 after each update. Given the constraints, a naive approach would be too slow, so we use a segment tree with lazy propagation to manage the range updates and efficiently compute the required values.

### Approach
1. **Precompute Powers and Prefix Sums**: 
   - Precompute powers of 10 modulo 998244353 up to the maximum needed value.
   - Precompute prefix sums of these powers to quickly calculate the sum of powers over any range.

2. **Segment Tree with Lazy Propagation**:
   - Build a segment tree where each node can handle range updates and maintain the sum of the digits in its range, each multiplied by their respective power of 10.
   - Each node tracks the sum of its range and can propagate pending updates to its children (lazy propagation) to ensure efficient updates.

3. **Handling Queries**:
   - For each query, update the segment tree to set the specified range to the given digit.
   - After each update, output the sum of the entire string modulo 998244353.

### Solution Code
```python
import sys
MOD = 998244353

def main():
    sys.setrecursionlimit(1 << 25)
    N, Q = map(int, sys.stdin.readline().split())
    queries = [tuple(map(int, sys.stdin.readline().split())) for _ in range(Q)]

    # Precompute pow10: pow10[k] = 10^k mod MOD, for 0 <= k < N
    pow10 = [1] * (N)
    for i in range(1, N):
        pow10[i] = (pow10[i-1] * 10) % MOD

    # Precompute prefix sums: prefix[i] is sum of 10^{N-j} for j=1 to i
    prefix = [0] * (N + 2)  # 1-based to N
    for i in range(1, N+1):
        exponent = N - i
        prefix[i] = (prefix[i-1] + pow10[exponent]) % MOD

    class SegmentTreeNode:
        __slots__ = ['a', 'b', 'sum_val', 'digit', 'left', 'right']
        def __init__(self, a, b):
            self.a = a
            self.b = b
            self.sum_val = 0
            self.digit = 1  # initial digit is 1
            self.left = None
            self.right = None

    def build(a, b):
        node = SegmentTreeNode(a, b)
        if a == b:
            node.sum_val = (1 * pow10[N - a]) % MOD
        else:
            mid = (a + b) // 2
            node.left = build(a, mid)
            node.right = build(mid + 1, b)
            node.sum_val = (node.left.sum_val + node.right.sum_val) % MOD
        node.digit = 1
        return node

    root = build(1, N)

    def update(node, L, R, D):
        if node.b < L or node.a > R:
            return
        if L <= node.a and node.b <= R:
            if node.digit is not None:
                sum_range = (prefix[node.b] - prefix[node.a - 1]) % MOD
                node.sum_val = (D * sum_range) % MOD
                node.digit = D
                return
            else:
                update(node.left, L, R, D)
                update(node.right, L, R, D)
                node.sum_val = (node.left.sum_val + node.right.sum_val) % MOD
                return
        if node.digit is not None:
            node.left.digit = node.digit
            sum_left = (node.digit * (prefix[node.left.b] - prefix[node.left.a - 1])) % MOD
            node.left.sum_val = sum_left
            node.right.digit = node.digit
            sum_right = (node.digit * (prefix[node.right.b] - prefix[node.right.a - 1])) % MOD
            node.right.sum_val = sum_right
            node.digit = None
        update(node.left, L, R, D)
        update(node.right, L, R, D)
        node.sum_val = (node.left.sum_val + node.right.sum_val) % MOD

    for L, R, D in queries:
        update(root, L, R, D)
        print(root.sum_val % MOD)

if __name__ == '__main__':
    main()
```

3. **Lazy Propagation**: When a range update is performed, the segment tree uses lazy propagation to efficiently update the relevant nodes and propagate changes to child nodes only when necessary.
4. **Query Handling**: Each query updates the relevant range in the segment tree and outputs the current sum of the entire string modulo 998244353.

This approach ensures that each update and query operation is handled efficiently in logarithmic time, making it suitable for large input sizes as specified in the problem constraints.
