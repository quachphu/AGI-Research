To solve this problem, we need to determine if we can capitalize certain letters in a sequence of words such that the sequence becomes lexicographically ordered according to the given rules. The key insight is that capitalizing a letter changes its order relative to other letters, and we need to find a set of letters to capitalize that satisfies all constraints derived from consecutive word pairs.

### Approach
1. **Identify Constraints**: For each consecutive pair of words, determine the first position where they differ. Based on the characters at this position, derive constraints on which letters must be capitalized (must_in) and which must not (must_not_in).
2. **Implication Graph**: Construct an implication graph where edges represent that if a letter is capitalized, another letter must also be capitalized.
3. **Closure Check**: Compute the closure of the must_in set under the implication graph to ensure all necessary letters are included. Check for conflicts between the closure and must_not_in sets.
4. **Validation**: Ensure no conflicts exist between must_in and must_not_in sets and that all derived constraints are satisfied.

```python
import sys
from collections import deque, defaultdict

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n, m = int(input[ptr]), int(input[ptr+1])
    ptr += 2
    words = []
    for _ in range(n):
        li = int(input[ptr])
        s = list(map(int, input[ptr+1:ptr+1+li]))
        words.append(s)
        ptr += 1 + li

    must_in = set()
    must_not_in = set()
    implications = defaultdict(list)
    possible = True

    for i in range(n - 1):
        a = words[i]
        b = words[i + 1]
        len_a = len(a)
        len_b = len(b)
        min_len = min(len_a, len_b)
        j = 0
        while j < min_len and a[j] == b[j]:
            j += 1
        if j == min_len:
            if len_a > len_b:
                print("No")
                return
            else:
                continue
        else:
            x = a[j]
            y = b[j]
            if x < y:
                implications[y].append(x)
            else:
                if x in must_not_in or y in must_in:
                    print("No")
                    return
                must_in.add(x)
                must_not_in.add(y)

    if must_in & must_not_in:
        print("No")
        return

    closure = set(must_in)
    queue = deque(closure)
    adj = implications
    while queue:
        node = queue.popleft()
        for neighbor in adj[node]:
            if neighbor not in closure:
                closure.add(neighbor)
                queue.append(neighbor)

    if closure & must_not_in:
        print("No")
        return

    print("Yes")
    print(len(closure))
    if closure:
        print(' '.join(map(str, sorted(closure))))
    else:
        print()

    main()
```
