To solve this problem, we need to determine the length of the longest subarray (almost constant range) where the difference between the maximum and minimum values is at most 1. Given the constraints that consecutive elements differ by at most 1, we can leverage this property to efficiently find the solution using a sliding window approach combined with dynamic programming.

### Approach
1. **Dynamic Programming Insight**: For each position in the array, we track two possible subarrays:
   - `len_high`: The longest subarray ending at the current position where the values are either the current value or one less than the current value.
   - `len_low`: The longest subarray ending at the current position where the values are either the current value or one more than the current value.

2. **Transition Logic**:
   - If the current element is the same as the previous element, both `len_high` and `len_low` are incremented by 1.
   - If the current element is one more than the previous element, `len_high` is updated to `prev_low + 1` (since the previous subarray ending with the lower value can now include this element), and `len_low` is reset to 1.
   - If the current element is one less than the previous element, `len_low` is updated to `prev_high + 1` (since the previous subarray ending with the higher value can now include this element), and `len_high` is reset to 1.

3. **Max Length Tracking**: Throughout the iteration, keep track of the maximum length of the valid subarrays encountered.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    if n == 0:
        print(0)
        return
    a = list(map(int, input[1:n+1]))
    if n <= 1:
        print(n)
        return
    max_len = 1
    prev_high = 1
    prev_low = 1
    for i in range(1, n):
        current = a[i]
        prev = a[i-1]
        if current == prev:
            new_high = prev_high + 1
            new_low = prev_low + 1
        elif current == prev + 1:
            new_high = prev_low + 1
            new_low = 1
        elif current == prev - 1:
            new_high = 1
            new_low = prev_high + 1
        else:
            new_high = 1
            new_low = 1
        current_max = max(new_high, new_low)
        if current_max > max_len:
            max_len = current_max
        prev_high, prev_low = new_high, new_low
    print(max_len)

main()
```

### Explanation
- **Reading Input**: The input is read and parsed into the number of elements `n` and the array `a`.
- **Edge Cases Handling**: Directly handle cases where `n` is 0 or 1.
- **Dynamic Programming Iteration**: For each element starting from the second one, determine the possible lengths of valid subarrays ending at the current element using the transition logic based on the previous element's values.
- **Track Maximum Length**: Continuously update the maximum length of valid subarrays encountered during the iteration.

This approach efficiently computes the solution in linear time, O(n), making it suitable for large input sizes up to 100,000 elements.
