To solve this problem, we need to determine the maximum number of roads that can exist between cities in Ancient Berland such that there are no cycles of length exactly 3 (triangles). The solution involves constructing a bipartite graph, which ensures that no triangles can form, and maximizes the number of edges.

### Approach
1. **Problem Analysis**: The goal is to find the maximum number of edges in a triangle-free graph. According to Turán's theorem, the maximum number of edges in a triangle-free graph (a bipartite graph) with `n` nodes is given by the product of the sizes of the two partitions when the nodes are split as evenly as possible. This product is `floor(n/2) * ceil(n/2)`.

2. **Graph Construction**: Split the cities into two groups such that the size difference between the groups is at most 1. Connect every city in the first group to every city in the second group. This ensures a bipartite graph with the maximum number of edges and no triangles.

3. **Edge Generation**: Generate all possible edges between the two groups. Each node in the first group is connected to every node in the second group, resulting in the maximum number of edges without forming any triangles.

### Solution Code
```python
n = int(input())
k = n // 2
m = k * (n - k)
print(m)
for i in range(1, k + 1):
    for j in range(k + 1, n + 1):
        print(i, j)
```

### Explanation
1. **Input Reading**: Read the integer `n` which represents the number of cities.
2. **Partition Calculation**: Calculate the partition sizes `k` (size of the first group) and `n - k` (size of the second group). This split ensures the groups are as equal as possible.
3. **Edge Count Calculation**: Compute the maximum number of edges as the product of the sizes of the two partitions.
4. **Edge Generation**: Iterate over each node in the first group and connect it to every node in the second group, printing each edge.

This approach ensures that the graph is bipartite, thus triangle-free, and contains the maximum possible number of edges. The solution efficiently constructs the required graph and meets the problem constraints.
