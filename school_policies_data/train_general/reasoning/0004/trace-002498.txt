To solve this problem, we need to determine the maximum profit Qwerty can achieve by buying items on one planet and selling them on another, considering the constraints of his ship's hold capacity. The solution involves evaluating all possible pairs of planets and determining the optimal items to trade between each pair.

### Approach
1. **Input Reading**: Read the number of planets, item types, and the ship's hold capacity. Then, read each planet's details, including the cost to buy, cost to sell, and the maximum available quantity for each item type.
2. **Evaluate Planet Pairs**: For each pair of planets (A, B) where A is the buying planet and B is the selling planet (A ≠ B), calculate the potential profit for each item type.
3. **Profit Calculation**: For each item type, compute the profit per item if sold from A to B. Only consider items with positive profit.
4. **Optimal Item Selection**: Sort these profitable items by descending profit per item. Select items starting from the highest profit until the ship's hold is full or all profitable items are considered.
5. **Maximize Profit**: Track the maximum profit across all planet pairs.

### Solution Code
```python
n, m, k = map(int, input().split())

planets = []
for _ in range(n):
    name = input().strip()
    items = []
    for _ in range(m):
        a, b, c = map(int, input().split())
        items.append((a, b, c))
    planets.append((name, items))

max_total = 0

for a_idx in range(n):
    for b_idx in range(n):
        if a_idx == b_idx:
            continue
        
        a_items = planets[a_idx][1]
        b_items = planets[b_idx][1]
        profit_list = []
        
        for j in range(m):
            a_ij = a_items[j][0]
            b_ij = b_items[j][1]
            profit = b_ij - a_ij
            if profit > 0:
                max_buy = a_items[j][2]
                profit_list.append((profit, max_buy))
        
        # Sort by descending profit, then descending max_buy (though order may not matter for same profit)
        profit_list.sort(key=lambda x: (-x[0], -x[1]))
        
        current_total = 0
        remaining = k
        
        for profit, max_buy in profit_list:
            if remaining <= 0:
                break
            take = min(max_buy, remaining)
            current_total += take * profit
            remaining -= take
        
        if current_total > max_total:
            max_total = current_total

print(max_total)
```

### Explanation
- **Input Reading**: The code reads the input values and stores each planet's details, including the item specifications.
- **Planet Pair Evaluation**: For each pair of planets (A, B), the code calculates the profit for each item type if bought from A and sold to B.
- **Profit Calculation**: The profit for each item is determined by the difference between the selling price on planet B and the buying price on planet A. Only positive profits are considered.
- **Optimal Item Selection**: Profitable items are sorted by descending profit. The algorithm then selects items starting from the highest profit until the ship's hold is full.
- **Maximize Profit**: The maximum profit from all possible planet pairs is tracked and printed as the result.

This approach ensures that we efficiently evaluate all possible trading routes and select the optimal items to maximize profit while respecting the ship's capacity constraints.
