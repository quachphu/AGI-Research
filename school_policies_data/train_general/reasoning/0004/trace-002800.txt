To solve this problem, we need to maximize the profit from selling hamburgers and chicken burgers given the constraints on the number of ingredients (buns, beef patties, and chicken cutlets) and the prices of each type of burger. The approach involves considering two scenarios for each test case: prioritizing the more expensive burger first and then the other, and vice versa. We then compute the profit for both scenarios and take the maximum.

### Approach
1. **Input Reading**: Read the number of test cases.
2. **Scenario Evaluation**:
   - **Scenario 1**: Prioritize making as many hamburgers as possible first, then use the remaining buns to make chicken burgers.
   - **Scenario 2**: Prioritize making as many chicken burgers as possible first, then use the remaining buns to make hamburgers.
3. **Profit Calculation**: For each scenario, calculate the profit based on the number of burgers that can be made given the ingredient constraints.
4. **Result Determination**: The maximum profit from the two scenarios is the result for each test case.

### Solution Code
```python
t = int(input())
for _ in range(t):
    b, p, f = map(int, input().split())
    h, c = map(int, input().split())
    
    # Scenario 1: hamburgers first, then chicken
    max_h1 = min(p, b // 2)
    rem_buns1 = b - max_h1 * 2
    max_c1 = min(f, rem_buns1 // 2)
    profit1 = max_h1 * h + max_c1 * c
    
    # Scenario 2: chicken first, then hamburgers
    max_c2 = min(f, b // 2)
    rem_buns2 = b - max_c2 * 2
    max_h2 = min(p, rem_buns2 // 2)
    profit2 = max_h2 * h + max_c2 * c
    
    print(max(profit1, profit2))
```
