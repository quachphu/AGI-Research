To solve this problem, we need to determine the number of message notifications each employee receives based on their participation in various chat groups and the message events logged. 

### Approach
1. **Input Parsing**: Read the number of employees, chats, and events. Then, read the matrix indicating which employees are part of which chats.
2. **Tracking Message Events**: For each message event, track the total number of messages sent to each chat and the number of messages each employee sent to each chat.
3. **Calculate Notifications**: For each employee, calculate the total notifications received by summing the messages from each chat they are part of, excluding the messages they sent themselves.

### Solution Code
```python
n, m, k = map(int, input().split())

# Initialize participants list for each employee (1-based)
participants = [[] for _ in range(n + 1)]
for i in range(1, n + 1):
    row = list(map(int, input().split()))
    for j in range(m):
        if row[j] == 1:
            participants[i].append(j + 1)  # Chats are 1-based

# Initialize count of messages per chat and sent messages per employee per chat
count = [0] * (m + 1)
sent = [[0] * (m + 1) for _ in range(n + 1)]

# Process each event
for _ in range(k):
    x, y = map(int, input().split())
    count[y] += 1
    sent[x][y] += 1

# Calculate the result for each employee
result = []
for i in range(1, n + 1):
    total = 0
    for chat in participants[i]:
        total += count[chat] - sent[i][chat]
    result.append(str(total))

print(' '.join(result))
```

### Explanation
1. **Reading Input**: The first line of input provides the number of employees (n), chats (m), and events (k). The next n lines describe which chats each employee is part of using a matrix.
2. **Tracking Messages**: For each message event, we increment the count of messages for the respective chat and track how many messages each employee sent to each chat.
3. **Calculating Notifications**: For each employee, we sum the total messages in each chat they participate in, subtracting the messages they sent themselves. This gives the total notifications each employee receives.

This approach efficiently computes the notifications using precomputed values, ensuring the solution handles the problem constraints within acceptable time limits.
