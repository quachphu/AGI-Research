To solve this problem, we need to determine if each line segment, which is either horizontal or vertical, can be added to a set such that it does not touch any existing line segments. The solution involves checking both horizontal and vertical segments for overlaps and intersections efficiently.

### Approach
1. **Data Structures**: Use dictionaries to keep track of horizontal and vertical segments. Each entry in the dictionary maps a coordinate (either y for horizontal or x for vertical) to a list of intervals. These intervals are stored in a sorted and non-overlapping manner.
2. **Binary Search**: Utilize binary search to efficiently check for overlaps when inserting new segments. This helps in maintaining the sorted order and checking adjacent intervals quickly.
3. **Cross-Check**: For each new segment, check against existing segments of the opposite orientation. This involves checking if the new segment's range intersects with any existing segments' ranges using binary search for efficiency.
