To solve this problem, we need to determine the maximum number of points Ilya can score by playing cards according to the given rules. The key challenge is to balance between playing cards that give more points and those that allow playing more cards by increasing the counter.

### Approach
1. **Separate Cards into Groups**: Divide the cards into two groups based on whether they provide additional moves (cards with `b_i >= 1`) or not (cards with `b_i = 0`).
2. **Sort Cards Strategically**:
   - For cards that provide additional moves (`b_i >= 1`), sort them by the net gain they provide (i.e., `b_i - 1` in descending order). If two cards have the same net gain, sort by their points (`a_i`) in descending order.
   - For cards that do not provide additional moves (`b_i = 0`), sort them by their points (`a_i`) in descending order to maximize the points from the remaining moves.
3. **Simulate Play**:
   - Play cards from the first group (providing additional moves) first, maintaining a cumulative sum of their net gains to ensure the counter remains valid.
   - After exhausting the first group, use the remaining counter value to play as many cards as possible from the second group, prioritizing higher points.

### Solution Code
```python
n = int(input())
group_a = []
group_b = []
for _ in range(n):
    a, b = map(int, input().split())
    if b >= 1:
        group_a.append((a, b))
    else:
        group_b.append((a, b))

# Sort group_a by (- (b-1), -a)
group_a.sort(key=lambda x: (-(x[1] - 1), -x[0]))
# Sort group_b by -a
group_b.sort(key=lambda x: -x[0])

current_sum = 0
total_a = 0

# Process group_a
for a, b in group_a:
    new_sum = current_sum + (b - 1)
    if new_sum >= -1:
        current_sum = new_sum
        total_a += a

# Process group_b
max_extra = current_sum + 1
k = min(max_extra, len(group_b))
total_a += sum(a for a, b in group_b[:k])

print(total_a)
```

3. **Simulation**: By processing the first group and then the second group, we ensure that we maximize both the number of plays and the points from each play. The counter is managed dynamically to ensure valid plays at each step.
