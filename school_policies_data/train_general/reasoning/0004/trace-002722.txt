To solve this problem, we need to reorder a list of strings such that each string in the list contains all previous strings as substrings. If such an arrangement is not possible, we should return "NO".

### Approach
1. **Group Strings by Length**: First, we group all strings by their lengths. This helps in checking if strings of the same length are identical, which is a necessary condition for valid ordering.
2. **Check Homogeneity in Groups**: For each group of strings with the same length, ensure all strings in the group are identical. If any group contains different strings, it's impossible to reorder them correctly, so we return "NO".
3. **Sort Groups by Length**: Sort the groups by the length of their strings in ascending order. This ensures that shorter strings come first, which is a prerequisite for forming a valid sequence.
4. **Check Substring Condition**: Verify that each string in the sorted list of unique strings (one from each group) contains the previous string as a substring. If any consecutive pair fails this check, return "NO".
5. **Construct Output**: If all checks pass, construct the output by concatenating all strings from each group in the sorted order of their lengths.

### Solution Code
```python
n = int(input())
strings = [input().strip() for _ in range(n)]

grouped = {}
for s in strings:
    length = len(s)
    if length not in grouped:
        grouped[length] = []
    grouped[length].append(s)

# Check if all strings in each group are the same
for length in grouped:
    group = grouped[length]
    first = group[0]
    for s in group[1:]:
        if s != first:
            print("NO")
            exit()

# Extract unique strings sorted by their length
sorted_lengths = sorted(grouped.keys())
unique = [grouped[length][0] for length in sorted_lengths]

# Check consecutive substring condition
for i in range(1, len(unique)):
    prev = unique[i-1]
    current = unique[i]
    if prev not in current:
        print("NO")
        exit()

# Prepare the output list
output = []
for length in sorted_lengths:
    output.extend(grouped[length])

print("YES")
for s in output:
    print(s)
```

### Explanation
1. **Grouping by Length**: We use a dictionary to group strings by their lengths. This helps in efficiently checking if all strings of the same length are identical.
2. **Homogeneity Check**: For each group of strings with the same length, we ensure all strings are the same. If not, we immediately return "NO".
3. **Sorting and Substring Check**: After sorting the groups by length, we check if each consecutive string in the sorted list contains the previous one as a substring. This ensures the valid ordering where each subsequent string can contain all previous ones.
4. **Constructing the Output**: Once all checks pass, we concatenate all strings from each group in the sorted order of their lengths to form the final output.

This approach ensures that we efficiently check the necessary conditions and construct the valid sequence if possible, providing an optimal solution to the problem.
