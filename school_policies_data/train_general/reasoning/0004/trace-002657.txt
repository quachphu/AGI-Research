To solve this problem, we need to determine the first insertion that causes a conflict in a hash table where each bucket can hold only one element. The hash function used is \( h(x) = x \mod p \). The goal is to find the index of the first insertion that results in a conflict, or output -1 if no conflicts occur.

### Approach
1. **Input Reading**: Read the values of \( p \) (number of buckets) and \( n \) (number of elements to insert).
2. **Tracking Buckets**: Use a set to keep track of which buckets have been occupied.
3. **Insertion Check**: For each element, compute its bucket using the hash function. If the bucket is already occupied, output the 1-based index of the current insertion. If all elements are inserted without conflicts, output -1.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    p = int(input[0])
    n = int(input[1])
    used = set()
    index = 2  # Starting index for the numbers
    for i in range(n):
        xi = int(input[index])
        index += 1
        mod = xi % p
        if mod in used:
            print(i + 1)
            return
        used.add(mod)
    print(-1)

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list for efficient processing.
2. **Set Initialization**: A set `used` is initialized to track occupied buckets.
3. **Iterating Over Elements**: For each element, compute its bucket using modulo operation. Check if the bucket is already in the set.
4. **Conflict Detection**: If a bucket is found in the set, print the 1-based index of the current insertion and exit. If no conflicts are detected after all insertions, print -1.

This approach efficiently tracks the state of each bucket using a set, ensuring that each insertion check is done in constant time, leading to an overall time complexity of \( O(n) \), which is optimal for the given problem constraints.
