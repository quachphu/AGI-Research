To solve this problem, we need to determine the minimum amount Roy should spend on fertilizing plants to maximize his total money after selling them the next day. The solution involves selecting a subset of plants such that the net profit (selling price minus fertilizing cost) is maximized while ensuring the total fertilizing cost does not exceed the available funds.

### Approach
1. **Filter Plants**: First, filter out plants where the selling price (X) is less than or equal to the fertilizing cost (Y), as these plants do not contribute positively to the profit.
2. **Dynamic Programming (DP) Approach**: Use a dynamic programming approach to solve a 0-1 knapsack problem where the goal is to maximize the net profit (X - Y) while keeping the total fertilizing cost within the available funds (P).
3. **Track Maximum Profit and Minimum Cost**: For each possible total fertilizing cost, track the maximum net profit. After processing all plants, determine the minimum fertilizing cost that achieves this maximum profit.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx +=1
    for _ in range(T):
        N, P = int(input[idx]), int(input[idx+1])
        idx +=2
        plants = []
        for _ in range(N):
            X, Y = int(input[idx]), int(input[idx+1])
            idx +=2
            if X > Y:
                plants.append((Y, X-Y))  # (Y, profit)
        if not plants:
            print("0", P)
            continue
        # Initialize DP
        prev_dp = [-float('inf')] * (P + 1)
        prev_dp[0] = 0  # sum(Y) 0, sum(profit) 0
        for y, profit in plants:
            current_dp = prev_dp.copy()
            for w in range(y, P + 1):
                if prev_dp[w - y] != -float('inf'):
                    if prev_dp[w - y] + profit > current_dp[w]:
                        current_dp[w] = prev_dp[w - y] + profit
            prev_dp = current_dp
        max_profit = max(prev_dp)
        if max_profit <=0:
            print("0", P)
            continue
        # Find minimal w with prev_dp[w] == max_profit and w <= P
        min_w = P + 1
        for w in range(P +1):
            if prev_dp[w] == max_profit and w < min_w:
                min_w = w
        A = min_w
        B = P + max_profit
        print(A, B)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of test cases, the number of plants, available funds, and the details of each plant.
2. **Filtering Plants**: Plants that do not yield a positive profit (X <= Y) are discarded.
3. **Dynamic Programming Setup**: A DP array is initialized to track the maximum profit achievable for each possible total fertilizing cost up to P.
4. **Processing Each Plant**: For each plant, update the DP array to consider including the plant, ensuring each plant is only considered once (0-1 knapsack).
5. **Determine Results**: After processing all plants, find the maximum profit and the minimum fertilizing cost that achieves this profit. The result is then printed.

This approach ensures that we efficiently determine the optimal subset of plants to maximize profit while adhering to the constraints, using dynamic programming to handle the combinatorial complexity.
