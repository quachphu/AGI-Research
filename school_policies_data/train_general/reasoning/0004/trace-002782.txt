To solve this problem, we need to determine how many divisors of N! (factorial of N) are Shichi-Go numbers. A Shichi-Go number is defined as a positive integer that has exactly 75 divisors. 

### Approach
1. **Prime Factorization of N!**: The number of divisors of a number is determined by its prime factorization. For a number to have exactly 75 divisors, the product of (exponent + 1) for each prime in its factorization must equal 75. 
2. **Factor Combinations of 75**: The number 75 can be factorized into several combinations of integers greater than 1. The valid combinations are (75), (25, 3), (15, 5), and (5, 5, 3). Each combination corresponds to different ways to select primes and their exponents in the factorization of N!.
3. **Exponent Calculation**: For each prime number up to N, compute its exponent in N! using the formula: sum of floor(N/p) + floor(N/p^2) + ... until p^k exceeds N.
4. **Count Valid Combinations**: For each factor combination of 75, count the number of valid prime selections from the prime exponents of N! that satisfy the conditions derived from the factor combinations.

def main():
    import sys
    from math import isqrt

    N = int(sys.stdin.readline())

    # Generate primes up to N using sieve of Eratosthenes
    if N < 2:
        primes = []
    else:
        sieve = [True] * (N + 1)
        sieve[0] = sieve[1] = False
        for i in range(2, isqrt(N) + 1):
            if sieve[i]:
                sieve[i*i : N+1 : i] = [False] * len(sieve[i*i : N+1 : i])
        primes = [i for i, val in enumerate(sieve) if val]

    if not primes:
        print(0)
        return

    # Compute exponents for each prime in N!
    exponents = {}
    for p in primes:
        e = 0
        power = p
        while power <= N:
            e += N // power
            power *= p
        exponents[p] = e

    # Case 1: (75)
    count1 = sum(1 for e in exponents.values() if e >= 74)

    # Case 2: (25, 3)
    A = sum(1 for e in exponents.values() if e >= 24)
    B = sum(1 for e in exponents.values() if e >= 2)
    count2 = A * (B - 1)

    # Case 3: (15, 5)
    C = sum(1 for e in exponents.values() if e >= 14)
    D = sum(1 for e in exponents.values() if e >= 4)
    count3 = C * (D - 1)

    # Case 4: (5, 5, 3)
    E = sum(1 for e in exponents.values() if e >= 4)
    F = sum(1 for e in exponents.values() if e >= 2)
    if E >= 2 and F >= 3:
        count4 = (E * (E - 1) // 2) * (F - 2)
    else:
        count4 = 0

    total = count1 + count2 + count3 + count4
