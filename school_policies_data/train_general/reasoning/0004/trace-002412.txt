To solve this problem, we need to determine which cars are "good" based on the results of their collisions as described by a given matrix. A car is considered good if it never turned over in any collision it was involved in.

### Approach
1. **Matrix Analysis**: The matrix entries describe the result of collisions between pairs of cars. Each entry can be 0, 1, 2, or 3, which indicate different outcomes of the collision.
2. **Check Row and Column**: For each car, we need to check two things:
   - **Row Check**: The car's row entries to see if it turned over in any collision where it was the first car (i-th car).
   - **Column Check**: The car's column entries to see if it turned over in any collision where it was the second car (j-th car).
3. **Determine Good Cars**: A car is good if neither the row check nor the column check indicates that it turned over in any collision.

### Solution Code
```python
n = int(input())
matrix = [list(map(int, input().split())) for _ in range(n)]
good_cars = []

for k in range(n):
    valid = True
    # Check row k (i=k collisions)
    for j in range(n):
        if j == k:
            continue
        val = matrix[k][j]
        if val in (1, 3):
            valid = False
            break
    if not valid:
        continue
    # Check column k (j=k collisions)
    for i in range(n):
        if i == k:
            continue
        val = matrix[i][k]
        if val in (2, 3):
            valid = False
            break
    if valid:
        good_cars.append(k + 1)  # Convert to 1-based index

print(len(good_cars))
if good_cars:
    print(' '.join(map(str, sorted(good_cars))))
```

### Explanation
1. **Reading Input**: The input is read as an integer `n` followed by an `n x n` matrix.
2. **Row Check**: For each car `k`, we check all entries in its row (excluding the diagonal). If any entry is 1 or 3, the car turned over in that collision and is not good.
3. **Column Check**: If the row check passes, we then check all entries in the car's column (excluding the diagonal). If any entry is 2 or 3, the car turned over in that collision and is not good.
4. **Result Collection**: Cars that pass both checks are collected, converted to 1-based indexing, sorted, and printed.

This approach ensures that we efficiently determine all good cars by examining each collision outcome from both the row and column perspectives of the matrix.
