### Approach
1. **Data Structure**: Use a doubly linked list to allow efficient insertion and deletion operations. Each node in the list will have pointers to the previous and next nodes.
2. **Operations**:
   - **Insert x**: Insert a node at the front of the list. This operation is done in constant time O(1).
   - **Delete x**: Remove the first occurrence of a node with value x. This requires traversing the list until the node is found, which is O(n) in the worst case. However, since the number of delete operations is limited, this approach remains feasible.
   - **DeleteFirst**: Remove the node at the front of the list in constant time O(1).
   - **DeleteLast**: Remove the node at the end of the list in constant time O(1).
3. **Efficiency**: By maintaining head and tail pointers, we ensure that insertions and deletions at both ends are done in constant time. The traversal for delete operations is manageable given the constraints.

### Solution Code
```python
import sys

class Node:
    __slots__ = ['key', 'prev', 'next']
    def __init__(self, key):
        self.key = key
        self.prev = None
        self.next = None

def main():
    head = None
    tail = None

    n = int(sys.stdin.readline())
    for _ in range(n):
        line = sys.stdin.readline().split()
        cmd = line[0]
        if cmd == 'insert':
            x = int(line[1])
            node = Node(x)
            if head is None:
                head = tail = node
            else:
                node.next = head
                head.prev = node
                head = node
        elif cmd == 'delete':
            x = int(line[1])
            current = head
            while current:
                if current.key == x:
                    prev_node = current.prev
                    next_node = current.next
                    if prev_node:
                        prev_node.next = next_node
                    else:
                        head = next_node
                    if next_node:
                        next_node.prev = prev_node
                    else:
                        tail = prev_node
                    break
                current = current.next
        elif cmd == 'deleteFirst':
            if head == tail:
                head = tail = None
            else:
                head = head.next
                head.prev = None
        elif cmd == 'deleteLast':
            if head == tail:
                head = tail = None
            else:
                tail = tail.prev
                tail.next = None

    result = []
    current = head
    while current:
        result.append(str(current.key))
        current = current.next
    print(' '.join(result))

if __name__ == '__main__':
    main()
```

### Explanation
1. **Node Class**: Each node contains a key, a pointer to the previous node, and a pointer to the next node.
2. **Insert Operation**: Inserts a new node at the front of the list. If the list is empty, the new node becomes both the head and tail. Otherwise, the new node is linked to the current head, which then updates to the new node.
3. **Delete Operation**: Traverses the list from the head to find the first occurrence of the specified key. Once found, the node is removed by adjusting the pointers of its previous and next nodes.
4. **DeleteFirst/DeleteLast**: Adjusts the head or tail pointers to remove the first or last node, respectively. These operations are done in constant time.
5. **Output**: After processing all commands, the list is traversed from head to tail, collecting all keys into a list which is then printed as a space-separated string.

This approach ensures that all operations are handled efficiently within the problem constraints, providing an optimal solution for large input sizes.
