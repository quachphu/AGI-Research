To solve this problem, we need to find two positive integers \(a\) and \(b\) such that \(a + b = n\) and the least common multiple (LCM) of \(a\) and \(b\) is minimized. The key insight is that the LCM of two numbers can be minimized by maximizing their greatest common divisor (GCD). 

### Approach
1. **Understanding LCM and GCD**: The LCM of two numbers \(a\) and \(b\) can be calculated using their GCD with the formula \(LCM(a, b) = \frac{a \times b}{GCD(a, b)}\). To minimize the LCM, we need to maximize the GCD.
2. **Divisors and GCD**: For \(a + b = n\), if \(d\) is the GCD of \(a\) and \(b\), then \(a = d \times x\) and \(b = d \times y\) where \(x\) and \(y\) are coprime (their GCD is 1). This implies \(d\) must be a divisor of \(n\).
3. **Optimal Divisor**: The largest proper divisor of \(n\) (other than \(n\) itself) will maximize the GCD. This divisor can be found by dividing \(n\) by its smallest prime factor. If \(n\) is a prime number, the largest proper divisor is 1.

### Solution Code
```python
import math

def smallest_prime_factor(n):
    if n % 2 == 0:
        return 2
    max_i = int(math.isqrt(n)) + 1
    i = 3
    while i <= max_i:
        if n % i == 0:
            return i
        i += 2
    return n  # n is prime

t = int(input())
for _ in range(t):
    n = int(input())
    spf = smallest_prime_factor(n)
    if spf == n:
        a = 1
        b = n - 1
    else:
        a = n // spf
        b = n - a
    print(a, b)
```

### Explanation
1. **Finding the Smallest Prime Factor**: The function `smallest_prime_factor` checks divisibility starting from 2, then odd numbers up to the square root of \(n\). The first divisor found is the smallest prime factor.
2. **Determine \(a\) and \(b\)**: If \(n\) is a prime number, the smallest prime factor is \(n\) itself, leading to \(a = 1\) and \(b = n - 1\). Otherwise, the largest proper divisor is \(n\) divided by its smallest prime factor, and \(a\) and \(b\) are set to this divisor and \(n - \text{divisor}\) respectively.

This approach efficiently finds the optimal pair by leveraging the properties of divisors and prime factors, ensuring the solution is both correct and efficient for large values of \(n\).
