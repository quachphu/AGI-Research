### Approach
1. **Reading Input:** The input consists of multiple test cases. Each test case includes four canal numbers and one motor number.
2. **Convert to Integers:** The canal numbers can be very large (up to 10^250), but Python's arbitrary-precision integers can handle this.
3. **Compute GCD of Canal Numbers:** Compute the GCD of the four canal numbers incrementally. This is done by iteratively finding the GCD of the current result with the next number.
4. **Compute GCD with Motor Number:** Once the GCD of the four canal numbers is found, compute the GCD of this result with the motor number.
5. **Output the Result:** Print the final GCD for each test case.

### Solution Code
```python
import math

t = int(input())
for _ in range(t):
    a = int(input())
    b = int(input())
    c = int(input())
    d = int(input())
    e = int(input())
    
    current_gcd = a
    current_gcd = math.gcd(current_gcd, b)
    current_gcd = math.gcd(current_gcd, c)
    current_gcd = math.gcd(current_gcd, d)
    
    final_gcd = math.gcd(current_gcd, e)
    print(final_gcd)
```

1. **Reading Input:** The code reads the number of test cases first. For each test case, it reads the four canal numbers and the motor number.
2. **Converting to Integers:** Each canal number is read as a string and converted to an integer. Python handles these large integers efficiently.
3. **Iterative GCD Calculation:** The GCD of the four canal numbers is computed step-by-step using Python's `math.gcd` function. This function is applied iteratively to reduce the problem to pairwise GCD calculations.
4. **Final GCD with Motor Number:** The GCD of the result from the canal numbers and the motor number is computed, giving the final answer.
5. **Output:** The result for each test case is printed immediately after computation.
