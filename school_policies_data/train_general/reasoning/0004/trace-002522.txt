To solve this problem, we need to determine the minimum number of bombs required to defeat all monsters standing in a row, where each bomb affects a specific range and reduces the health of monsters within that range. The goal is to use an optimal strategy to minimize the number of bombs used.

### Approach
1. **Sort the Monsters**: First, sort the monsters by their positions. This allows us to process them in a left-to-right manner, ensuring that we can efficiently apply bombs to cover as many subsequent monsters as possible.
2. **Greedy Bomb Placement**: For each monster, after accounting for the damage from previously placed bombs, determine how many additional bombs are needed to reduce its health to zero or below. Place these bombs as far to the right as possible to maximize their coverage of subsequent monsters.
3. **Track Bomb Effects**: Use a deque to track the range of each bomb's effect. As we process each monster, remove any bombs that no longer affect the current monster's position. This helps in efficiently managing the cumulative damage from active bombs.

### Solution Code
```python
import sys
from collections import deque

def main():
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    D = int(input[idx])
    idx += 1
    A = int(input[idx])
    idx += 1

    monsters = []
    for _ in range(N):
        x = int(input[idx])
        idx += 1
        h = int(input[idx])
        idx += 1
        monsters.append((x, h))
    
    monsters.sort()
    dq = deque()
    active_damage = 0
    ans = 0

    for x, h in monsters:
        while dq and dq[0][0] < x:
            r, d = dq.popleft()
            active_damage -= d
        
        remaining = h - active_damage
        if remaining <= 0:
            continue
        
        t = (remaining + A - 1) // A
        ans += t
        damage = t * A
        active_damage += damage
        R = x + 2 * D
        dq.append((R, damage))
    
    print(ans)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading and Sorting Input**: The input is read and parsed, then the monsters are sorted based on their positions. This ensures we process them from left to right.
2. **Deque for Bomb Tracking**: A deque is used to keep track of the active bomb ranges. Each entry in the deque stores the right endpoint of the bomb's range and the total damage contributed by that bomb.
3. **Processing Each Monster**: For each monster, we first remove any bombs from the deque that no longer affect the current monster's position. The remaining health of the monster is then calculated after accounting for active bomb damage. If additional bombs are needed, they are placed as far right as possible to maximize coverage, and their effect is added to the deque.
4. **Efficiency**: The algorithm efficiently manages the active bomb effects using a deque, ensuring that each bomb is processed exactly once, leading to an overall time complexity of O(N log N) due to the initial sorting step.

This approach ensures that we use the minimum number of bombs by leveraging greedy placement and efficient range tracking, making it suitable for large input sizes as specified in the problem constraints.
