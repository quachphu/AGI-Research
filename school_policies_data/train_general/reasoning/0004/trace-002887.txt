To solve this problem, we need to find the maximum possible sum of a subsequence with an odd sum from a given sequence of integers. The solution involves analyzing the sum of all positive elements and adjusting it if necessary to ensure the sum is odd.

### Approach
1. **Sum of Positive Elements**: Calculate the sum of all positive elements in the sequence. If this sum is odd, it is the answer because it represents the maximum possible sum of any subsequence.
2. **Adjusting Even Sum**: If the sum of positive elements is even, we need to adjust it to make it odd. This can be done in two ways:
   - **Subtract the Smallest Positive Odd**: Remove the smallest positive odd element from the sum of positive elements.
   - **Add the Largest Negative Odd**: Include the largest (closest to zero) negative odd element in the sum.
3. **Determine Maximum Adjusted Sum**: Compare the results of the two adjustments and choose the maximum value.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))

sum_positive = sum(x for x in a if x > 0)
positive_odds = [x for x in a if x > 0 and x % 2 != 0]
negative_odds = [x for x in a if x < 0 and x % 2 != 0]

if sum_positive % 2 == 1:
    print(sum_positive)
else:
    candidates = []
    if positive_odds:
        candidates.append(sum_positive - min(positive_odds))
    if negative_odds:
        candidates.append(sum_positive + max(negative_odds))
    print(max(candidates))
```

### Explanation
1. **Sum Calculation**: The sum of all positive elements is computed to find the maximum possible sum of a subsequence.
2. **Parity Check**: If the sum is odd, it is directly returned as the result.
3. **Adjustments for Even Sum**: If the sum is even, we adjust it by considering the smallest positive odd element (to subtract) and the largest negative odd element (to add). The adjustment that results in the highest odd sum is chosen.
4. **Efficiency**: The solution efficiently processes the input in linear time, making it suitable for large input sizes up to 100,000 elements. The approach ensures we check all necessary elements to determine the optimal subsequence sum.
