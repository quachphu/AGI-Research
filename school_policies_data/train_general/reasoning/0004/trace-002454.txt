To solve this problem, we need to count the number of valid arrays of length `n` that meet specific conditions related to their bitwise AND and sum. The solution involves understanding the constraints and leveraging modular arithmetic for efficient computation.

### Approach
1. **Understanding the Problem Constraints**:
   - The bitwise AND of all elements must be 0.
   - The sum of elements must be maximized.
   - Each element must be between 0 and \(2^k - 1\).

2. **Key Insight**:
   - For the bitwise AND of all elements to be 0, each bit position from 0 to k-1 must be 0 in at least one element of the array.
   - To maximize the sum, each bit position should be set in all but one element. This means for each bit position, exactly one element will have that bit unset, while the others have it set.

3. **Counting Valid Arrays**:
   - For each bit position, there are `n` choices (one for each element) to determine which element has the bit unset. This leads to a total of \(n^k\) valid configurations.

4. **Modulo Operation**:
   - Given the large potential values, results must be computed modulo \(10^9 + 7\) to avoid overflow and meet problem constraints.

### Solution Code
```python
MOD = 10**9 + 7

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    print(pow(n, k, MOD))
```

- **Reading Input**: The code reads the number of test cases `t` and then processes each test case by reading `n` and `k`.
- **Modular Exponentiation**: Using Python's built-in `pow` function with three arguments allows efficient computation of \(n^k \mod (10^9 + 7)\), which handles large numbers efficiently.
- **Output**: The result for each test case is printed immediately after computation.

This approach ensures that we efficiently compute the required values using modular arithmetic, adhering to the problem constraints and providing the correct results in optimal time.
