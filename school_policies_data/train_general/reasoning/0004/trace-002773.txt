To solve this problem, we need to determine the commands Ikshu should give to his machine gun to knock off boxes in such a way that the commands are in non-decreasing order. The challenge arises because each time a box is knocked off, all boxes above it shift down by one position. 

### Approach
The key insight is to process the boxes in ascending order of their original indices. By doing so, we can ensure that each subsequent command accounts for the boxes that have already been knocked off. Specifically, each command for a box at position `x` in the sorted list will be adjusted by subtracting the number of boxes knocked off before it. This adjustment ensures that the commands are in non-decreasing order.

### Solution Code
```python
s = int(input())
lst = list(map(int, input().split()))
lst.sort()
result = [str(lst[i] - i) for i in range(s)]
print(' '.join(result))
```

### Explanation
1. **Reading Input:** The first line of input is the number of boxes to knock off. The second line contains the indices of these boxes.
2. **Sorting:** The indices are sorted in ascending order to process them from the lowest to the highest.
3. **Adjusting Commands:** For each index in the sorted list, the command is calculated by subtracting the number of boxes already processed (which is the index of the current element in the sorted list). This adjustment accounts for the downward shift of boxes after each knock-off.
4. **Output:** The adjusted commands are printed in the required format.

This approach ensures that the commands are generated in non-decreasing order efficiently, even for large input sizes, by leveraging sorting and a linear pass to adjust the indices.
