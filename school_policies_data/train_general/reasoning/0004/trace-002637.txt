To solve this problem, we need to find the smallest palindrome number greater than a given positive integer \( K \) for multiple test cases. A palindrome is a number that reads the same forwards and backwards. 

### Approach
The approach involves incrementing the given number \( K \) starting from \( K + 1 \) and checking each subsequent number to see if it is a palindrome. The first palindrome encountered in this sequence is the answer. This brute-force method is efficient given the constraints (since \( K \) is at most a 5-digit number), ensuring that the number of increments needed is manageable even for the upper limits of input values.

### Solution Code
```python
def next_palindrome():
    import sys
    t = int(sys.stdin.readline())
    for _ in range(t):
        k = int(sys.stdin.readline().strip())
        candidate = k + 1
        while True:
            if str(candidate) == str(candidate)[::-1]:
                print(candidate)
                break
            candidate += 1

next_palindrome()
```

### Explanation
1. **Reading Input**: The function reads the number of test cases \( t \) and then reads each \( K \) value.
2. **Increment and Check**: For each \( K \), the algorithm starts checking from \( K + 1 \) and increments the candidate number until a palindrome is found.
3. **Palindrome Check**: A number is checked for being a palindrome by converting it to a string and comparing it with its reverse. If they match, the number is a palindrome.

This approach ensures that we find the smallest palindrome greater than \( K \) efficiently within the problem constraints.
