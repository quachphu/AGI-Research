To solve this problem, we need to count the number of natural numbers below a given \( N \) that contain the substring "51X3" in their decimal representation, where \( X \) can be any digit from 0 to 9. This problem can be efficiently solved using a digit dynamic programming (DP) approach, which allows us to count valid numbers without explicitly generating each number.

### Approach
1. **Problem Analysis**: The substring "51X3" must appear in the decimal form of the number. Here, \( X \) is any digit (0-9). The challenge is to efficiently count such numbers up to \( N-1 \).

2. **Digit Dynamic Programming (DP)**: This technique involves processing each digit of the number from left to right while keeping track of various states:
   - **Position**: The current digit being processed.
   - **Tight Constraint**: Whether the number formed so far is exactly the prefix of \( N-1 \).
   - **Mask**: The progress towards matching the substring "51X3".
   - **Has Feast**: A flag indicating if the substring "51X3" has been found.
   - **Started**: A flag indicating if the number has started (to handle leading zeros).

3. **State Transitions**: The DP transitions are designed to track the progress of matching the substring "51X3". The mask is updated based on the current digit and the previous state of the mask.
