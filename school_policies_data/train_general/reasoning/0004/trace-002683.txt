To solve this problem, we need to find the twin prime pair with the largest possible value (size) that is less than or equal to a given integer \( n \). Twin primes are pairs of primes that differ by 2. The solution involves generating primes up to \( n \) using the Sieve of Eratosthenes and then checking from \( n \) downwards to find the largest twin prime pair.

### Approach
1. **Generate Primes Efficiently**: Use the Sieve of Eratosthenes to generate all prime numbers up to \( n \). This method is efficient and works well for the given constraint \( 5 \leq n \leq 10000 \).
2. **Check for Twin Primes**: Starting from \( n \) and moving downwards, check each number to see if it and its predecessor (differing by 2) are both primes. The first such pair found will be the largest twin primes within the range.

### Solution Code
```python
def sieve(max_n):
    if max_n < 2:
        return []
    sieve_list = [True] * (max_n + 1)
    sieve_list[0] = sieve_list[1] = False
    for i in range(2, int(max_n ** 0.5) + 1):
        if sieve_list[i]:
            sieve_list[i*i : max_n+1 : i] = [False] * len(sieve_list[i*i : max_n+1 : i])
    return sieve_list

def main():
    import sys
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        if n == 0:
            break
        primes = sieve(n)
        found = False
        for q in range(n, 2, -1):
            if primes[q]:
                p = q - 2
                if p >= 2 and primes[p]:
                    print(f"{p} {q}")
                    found = True
                    break
        if not found:
            print("3 5")

main()
```

### Explanation
1. **Sieve of Eratosthenes**: This function generates a boolean list where each index \( i \) is `True` if \( i \) is a prime number and `False` otherwise. This is done by marking non-prime numbers starting from the first prime (2) and marking all multiples of each prime starting from its square.
2. **Reading Input**: The main function reads input values until a zero is encountered. For each input \( n \), it generates the list of primes up to \( n \).
3. **Finding Twin Primes**: The code then checks from \( n \) downwards to find the largest twin prime pair. For each number \( q \), it checks if both \( q \) and \( q-2 \) are primes. The first valid pair found is printed as the result.

This approach ensures that we efficiently generate primes and then quickly determine the largest twin prime pair by checking from the top of the range downwards, guaranteeing the first valid pair found is the largest possible.
