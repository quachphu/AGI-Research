If two locations have the same number of votes, they should be sorted by their location number in ascending order.

### Approach
1. **Reading Input**: The input consists of multiple datasets. Each dataset starts with a line containing two integers, `n` (number of students) and `m` (number of locations). This is followed by `n` lines each containing `m` integers (0 or 1) representing student preferences.
2. **Processing Each Dataset**: For each dataset, we:
   - Read the preferences for each student.
   - Calculate the sum of votes for each location.
   - Create a list of tuples where each tuple contains the vote count and the corresponding location number.
   - Sort this list first by the vote count in descending order and then by the location number in ascending order for tie-breaking.
3. **Output**: After sorting, we extract the location numbers from the sorted list and print them in the required format.

### Solution Code
```python
def process_input():
    import sys
    while True:
        line = sys.stdin.readline()
        if not line:
            break
        n, m = map(int, line.strip().split())
        if n == 0 and m == 0:
            break
        data = []
        for _ in range(n):
            row = list(map(int, sys.stdin.readline().strip().split()))
            data.append(row)
        sum_counts = [sum(col) for col in zip(*data)]
        locations = list(range(1, m + 1))
        pairs = list(zip(sum_counts, locations))
        sorted_pairs = sorted(pairs, key=lambda x: (-x[0], x[1]))
        result = [str(pair[1]) for pair in sorted_pairs]
        print(' '.join(result))
```

- **Sorting**: The locations are sorted based on the number of votes in descending order. If two locations have the same number of votes, they are sorted by their location number in ascending order.
- **Output**: The sorted location numbers are printed in the required space-separated format for each dataset.
