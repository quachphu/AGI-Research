To solve this problem, we need to determine the minimum number of moves required to transform a given bracket sequence into a regular bracket sequence. A regular bracket sequence is one where every opening bracket '(' has a corresponding closing bracket ')', and at no point does the number of closing brackets exceed the number of opening brackets when read from left to right.

### Approach
The key insight is to recognize that each move can either place a bracket at the beginning or the end of the string. By processing the string from both directions (left-to-right and right-to-left), we can determine the minimum number of moves required by considering both scenarios:
1. Moving closing brackets to the end when they cause a deficit in the balance of brackets when processed from left to right.
2. Moving opening brackets to the beginning when they cause a deficit in the balance of brackets when processed from right to left.

The minimum of these two values will give the required number of moves.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    t = int(input[idx])
    idx += 1
    for _ in range(t):
        n = int(input[idx])
        idx += 1
        s = input[idx]
        idx += 1
        
        # Calculate moves required when moving closing brackets to the end
        moves_left = 0
        balance = 0
        for c in s:
            if c == '(':
                balance += 1
            else:
                balance -= 1
            if balance < 0:
                moves_left += 1
                balance = 0  # Reset balance as we move this closing bracket to the end
        
        # Calculate moves required when moving opening brackets to the beginning
        moves_right = 0
        balance = 0
        for c in reversed(s):
            if c == ')':
                balance += 1
            else:
                balance -= 1
            if balance < 0:
                moves_right += 1
                balance = 0  # Reset balance as we move this opening bracket to the beginning
        
        print(min(moves_left, moves_right))

solve()
```

### Explanation
1. **Processing Left-to-Right**: We iterate through the string from left to right, maintaining a balance. Each time we encounter a closing bracket that causes a negative balance, we increment the move count (as if moving this closing bracket to the end) and reset the balance.
2. **Processing Right-to-Left**: We iterate through the string from right to left, treating closing brackets as if they were opening brackets and vice versa. Each time we encounter an opening bracket (in the reversed processing) that causes a negative balance, we increment the move count (as if moving this opening bracket to the beginning) and reset the balance.
3. **Result**: The minimum of the two move counts calculated from the two directions is the answer, as it represents the optimal number of moves required to transform the sequence into a regular bracket sequence.
