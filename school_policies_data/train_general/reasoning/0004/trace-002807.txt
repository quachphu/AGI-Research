To solve this problem, we need to determine if two given fractions are equal. The first fraction is provided in its standard form (p/q), while the second is given as a continued fraction of height n. The approach involves converting the continued fraction into its standard form and comparing it with the given fraction p/q.

### Approach
1. **Understanding Continued Fractions**: A continued fraction of the form [a1, a2, ..., an] is evaluated from the last term to the first. For example, the continued fraction [a1, a2, a3] is computed as a1 + 1/(a2 + 1/a3).

2. **Conversion to Standard Fraction**: Starting from the last term of the continued fraction, we iteratively compute the numerator and denominator. Each step involves adding the current term to the reciprocal of the previously computed fraction.

3. **Cross-Multiplication Check**: After converting the continued fraction to its standard form (num/den), we check if it equals p/q by verifying if num * q == den * p. This avoids potential issues with floating-point precision and ensures accuracy with large integers.

### Solution Code
```python
def main():
    import sys
    p, q = map(int, sys.stdin.readline().split())
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    if len(a) != n:
        print("NO")
        return
    # Compute the continued fraction
    num = a[-1]
    den = 1
    for i in reversed(range(n-1)):
        ai = a[i]
        new_num = ai * num + den
        new_den = num
        num, den = new_num, new_den
    # Check equality
    if num * q == den * p:
        print("YES")
    else:
        print("NO")

main()
```

### Explanation
1. **Reading Input**: The code reads the numerator (p) and denominator (q) of the first fraction, followed by the height (n) of the continued fraction and its elements (a1, a2, ..., an).

2. **Processing Continued Fraction**: Starting from the last element of the continued fraction, we compute the numerator and denominator iteratively. For each term from the second last to the first, we update the numerator and denominator using the formula derived from the continued fraction structure.

3. **Equality Check**: After converting the continued fraction to its standard form, we use cross-multiplication to check if it matches the given fraction p/q. This ensures the comparison is exact and avoids floating-point errors.

This approach efficiently handles the constraints and ensures accurate comparison using integer arithmetic, leveraging Python's capability to manage arbitrarily large integers.
