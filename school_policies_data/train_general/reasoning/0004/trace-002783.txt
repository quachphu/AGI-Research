To solve this problem, we need to determine the lengths of the edges in a tree based on the sum of the shortest distances from each vertex to every other vertex. The solution involves leveraging the properties of tree structures and the given sum values to compute edge lengths efficiently.

### Approach
1. **Tree Structure and Input Parsing**: Read the input values to construct the tree and the sum array.
2. **BFS for Parent Pointers**: Use BFS to determine parent-child relationships and compute the size of each subtree rooted at each node.
3. **Subtree Size Calculation**: Perform a post-order traversal (using reversed BFS order) to compute the size of each subtree.
4. **Edge Length Calculation**:
   - For edges where the subtree size is not half of the total nodes, use the formula derived from the difference in sum values of adjacent nodes.
   - For edges where the subtree size is exactly half of the total nodes (even edges), compute their lengths using the total sum of all distances and contributions from other edges.

### Solution Code
```python
import sys
from collections import deque

def main():
    sys.setrecursionlimit(1 << 25)
    n = int(sys.stdin.readline())
    edges_input = []
    adj = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        a, b = map(int, sys.stdin.readline().split())
        edges_input.append((a, b))
        adj[a].append(b)
        adj[b].append(a)
    s = list(map(int, sys.stdin.readline().split()))
    s_dict = {i + 1: s[i] for i in range(n)}
    
    # Compute parent pointers using BFS
    parent = [0] * (n + 1)
    parent[1] = -1  # root has no parent
    order_bfs = []
    q = deque([1])
    while q:
        u = q.popleft()
        order_bfs.append(u)
        for v in adj[u]:
            if parent[u] != v and parent[v] == 0:
                parent[v] = u
                q.append(v)
    
    # Compute subtree sizes using reversed BFS order
    size = [1] * (n + 1)
    for u in reversed(order_bfs):
        for v in adj[u]:
            if parent[v] == u:  # v is a child of u
                size[u] += size[v]
    
    # Calculate total sum of s_i
    total_s = sum(s)
    
    # Process each edge to compute lengths
    edge_lengths = [None] * (n - 1)
    even_edges_indices = []
    sum_contrib = 0
    
    for i in range(n - 1):
        a, b = edges_input[i]
        # Determine parent and child
        if parent[b] == a:
            child = b
        elif parent[a] == b:
            child = a
        else:
            assert False, "Edge not in parent-child relationship"
        
        k = size[child]
        if (n - 2 * k) != 0:
            s_child = s_dict[child]
            s_parent = s_dict[parent[child]]
            denominator = n - 2 * k
            l = (s_child - s_parent) // denominator
            edge_lengths[i] = l
            sum_contrib += 2 * l * k * (n - k)
        else:
            even_edges_indices.append(i)
    
    # Process even edges
    m = len(even_edges_indices)
    if m > 0:
        # Get k_e from the first even edge
        a, b = edges_input[even_edges_indices[0]]
        if parent[b] == a:
            child = b
        else:
            child = a
        k_e = size[child]
        assert 2 * k_e == n
        remaining = total_s - sum_contrib
        sum_l_e = remaining // (2 * k_e * k_e)
        l_e = sum_l_e // m
        for idx in even_edges_indices:
            edge_lengths[idx] = l_e
    
    # Output the edge lengths in order
    for l in edge_lengths:
        print(l)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Tree Construction**: The input is parsed to build an adjacency list representing the tree.
2. **BFS for Parent Pointers**: A BFS traversal from the root (node 1) determines parent-child relationships, which helps in identifying the structure of the tree.
3. **Subtree Sizes**: Using a post-order traversal (reversed BFS order), the size of each subtree rooted at each node is computed.
4. **Edge Length Calculation**:
   - For non-even edges (where the subtree size is not half the total nodes), the length is derived using the difference in sum values and subtree sizes.
   - For even edges (where the subtree size is exactly half the total nodes), the length is determined by leveraging the total sum of distances and contributions from other edges, ensuring the solution is uniquely determined as per the problem constraints.
