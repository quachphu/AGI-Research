To solve this problem, we need to determine the K-th smallest number from a set of merged intervals for multiple queries. The intervals are given as ranges, and we need to merge overlapping or contiguous intervals to avoid duplicates. Then, for each query, we efficiently find the K-th smallest number in the merged intervals.

### Approach
1. **Merge Intervals**: First, we merge overlapping or contiguous intervals. This helps in reducing the problem to dealing with non-overlapping intervals, which simplifies the computation of the K-th smallest number.
2. **Prefix Sum Calculation**: For each merged interval, compute the cumulative count of numbers up to that interval. This helps in quickly determining which interval the K-th number lies in.
3. **Query Processing**: For each query, check if the K-th number exists within the total count of numbers from the merged intervals. If it does, determine the exact number by iterating through the merged intervals and calculating the offset within the appropriate interval.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N, Q = int(input[ptr]), int(input[ptr + 1])
        ptr += 2
        intervals = []
        for _ in range(N):
            A = int(input[ptr])
            B = int(input[ptr + 1])
            ptr += 2
            intervals.append((A, B))
        # Merge intervals
        intervals.sort()
        merged = []
        for interval in intervals:
            s, e = interval
            if not merged:
                merged.append((s, e))
            else:
                last_s, last_e = merged[-1]
                if s <= last_e + 1:
                    new_s = last_s
                    new_e = max(last_e, e)
                    merged[-1] = (new_s, new_e)
                else:
                    merged.append((s, e))
        # Compute total numbers
        sum_total = 0
        for s, e in merged:
            sum_total += e - s + 1
        # Process each query
        for _ in range(Q):
            K = int(input[ptr])
            ptr += 1
            if K > sum_total:
                print(-1)
                continue
            current_sum = 0
            found = False
            for s, e in merged:
                cnt = e - s + 1
                if current_sum + cnt >= K:
                    offset = K - current_sum - 1
                    print(s + offset)
                    found = True
                    break
                else:
                    current_sum += cnt
            if not found:
                print(-1)

main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, and parsed using a pointer to track the current position in the input list.
2. **Merging Intervals**: The intervals are sorted by their start values. Then, overlapping or contiguous intervals are merged into a single interval to avoid duplication.
3. **Total Count Calculation**: The total number of elements in the merged intervals is computed to quickly determine if a query is out of bounds.
4. **Query Processing**: For each query, the appropriate interval is found by iterating through the merged intervals and checking cumulative counts. The exact number is calculated using the start of the interval and the offset derived from the cumulative count.

This approach ensures that we efficiently handle large ranges and multiple queries by leveraging interval merging and prefix sum calculations.
