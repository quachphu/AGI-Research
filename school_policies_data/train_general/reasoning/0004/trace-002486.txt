To solve this problem, we need to compute the sum of the first N terms of the series 1 - 2 + 3 - 4 + 5 - 6 ... efficiently for multiple test cases. 

### Approach
The series alternates between adding odd numbers and subtracting even numbers. By analyzing the pattern, we can derive a formula to compute the sum without iterating through each term, which is crucial for handling large values of N efficiently.

1. **Pattern Analysis**:
   - If N is even, the sum can be computed as \(-N/2\). For example, if N=4, the sum is \(1 - 2 + 3 - 4 = -2\), which is \(-4/2\).
   - If N is odd, the sum can be computed as \((N + 1)/2\). For example, if N=3, the sum is \(1 - 2 + 3 = 2\), which is \((3 + 1)/2\).

2. **Efficient Calculation**:
   - Check if N is even or odd.
   - Use the derived formula based on the parity of N to compute the sum in constant time \(O(1)\).

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        N = int(input[i])
        if N % 2 == 1:
            print((N + 1) // 2)
        else:
            print(-(N // 2))
            
main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially useful for handling large input sizes. The input is split into a list of strings.
2. **Processing Each Test Case**:
   - Convert the first element to get the number of test cases, T.
   - For each subsequent element, convert it to an integer N.
   - Check if N is odd or even and apply the respective formula to compute the sum.
3. **Output the Result**: Print the computed sum for each test case.

This approach ensures that each test case is processed in constant time, making the solution efficient even for very large values of N.
