To solve this problem, we need to generate a new table from a given input table by adding row sums and column sums. The new table will have an additional row and column to display these sums, including the total sum of all elements in the bottom-right corner.

### Approach
1. **Read Input**: First, we read the dimensions of the table (rows `r` and columns `c`), followed by the table data itself.
2. **Compute Row Sums**: For each row in the table, compute the sum of its elements and append this sum to the end of the row.
3. **Compute Column Sums**: After processing all rows, compute the sum for each column (including the newly added row sums column) and create a new row containing these sums.
4. **Output the Result**: Print the modified table, which now includes the row sums and the final column sums row.

### Solution Code
```python
import sys

def main():
    r, c = map(int, sys.stdin.readline().split())
    table = []
    for _ in range(r):
        row = list(map(int, sys.stdin.readline().split()))
        table.append(row)
    
    # Append row sums
    for row in table:
        row.append(sum(row))
    
    # Compute column sums
    column_sums = []
    for j in range(c + 1):
        total = 0
        for i in range(r):
            total += table[i][j]
        column_sums.append(total)
    table.append(column_sums)
    
    # Print the result
    for row in table:
        print(' '.join(map(str, row)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The first line of input contains the dimensions `r` and `c`. Subsequent lines contain the elements of the table, which are read into a list of lists.
2. **Row Sums Calculation**: For each row, the sum of its elements is calculated and appended to the end of the row. This modifies each row to have `c + 1` elements.
3. **Column Sums Calculation**: After all rows have been processed, we compute the sum for each column (including the new row sums column). This results in a new row where each element is the sum of the corresponding column from all rows. This new row is appended to the table.
4. **Output**: Each row of the modified table is printed, converting each element to a string and joining them with spaces for the correct format.

This approach efficiently computes the required sums and formats the output correctly, ensuring that the final table includes both row and column sums as specified.
