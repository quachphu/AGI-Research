To solve this problem, we need to determine the direction a person is facing after they have visited all squares in an N x M grid. The person starts at the top-left corner facing right and turns right whenever they encounter a boundary or a visited square. The solution involves identifying patterns based on the dimensions of the grid to determine the final direction efficiently.

### Approach
1. **Square Grid Check**: If the grid is square (N == M), the direction depends on whether the dimension is even or odd.
   - If the dimension is even, the final direction is left (L).
   - If the dimension is odd, the final direction is right (R).

2. **Non-Square Grid Check**: If the grid is not square, the direction is determined by the smaller dimension (min(N, M)) and whether it is even or odd.
   - If the smaller dimension is even:
     - If the grid has more rows than columns, the final direction is left (L).
     - If the grid has more columns than rows, the final direction is up (U).
   - If the smaller dimension is odd:
     - If the grid has more rows than columns, the final direction is down (D).
     - If the grid has more columns than rows, the final direction is right (R).

### Solution Code
```python
import sys

def determine_direction():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        N = int(input[idx])
        M = int(input[idx+1])
        idx += 2
        if N == M:
            if N % 2 == 0:
                print("L")
            else:
                print("R")
        else:
            min_val = min(N, M)
            if min_val % 2 == 0:
                if N < M:
                    print("U")
                else:
                    print("L")
            else:
                if N > M:
                    print("D")
                else:
                    print("R")

determine_direction()
```

### Explanation
- **Square Grid Handling**: For square grids, the direction is determined by checking if the dimension is even or odd. This is because the spiral traversal ends in the center, and the direction depends on the parity of the dimension.
- **Non-Square Grid Handling**: For non-square grids, the direction is determined by the smaller dimension and the relative sizes of the rows and columns. The smaller dimension's parity (even or odd) and which dimension is larger dictate the final direction after the spiral traversal completes.

This approach efficiently determines the final direction without simulating each step, making it suitable for very large grid dimensions up to 1000000000. The solution runs in O(1) time per test case after reading the input, ensuring it handles up to 10000 test cases efficiently.
