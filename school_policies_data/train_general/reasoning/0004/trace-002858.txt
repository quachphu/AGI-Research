To solve this problem, we need to find an integer \( K \) such that the absolute differences between \( K \) and two given distinct integers \( A \) and \( B \) are equal. If such an integer does not exist, we should return "IMPOSSIBLE".

### Approach
The key insight is that the equation \( |A - K| = |B - K| \) can be satisfied if and only if \( K \) is the average of \( A \) and \( B \). This average must be an integer, which requires the sum of \( A \) and \( B \) to be even. If the sum is even, then \( K \) is simply \( (A + B) // 2 \). If the sum is odd, it is impossible to find such a \( K \).

### Solution Code
```python
def find_k():
    a, b = map(int, input().split())
    total = a + b
    if total % 2 == 0:
        print(total // 2)
    else:
        print("IMPOSSIBLE")

find_k()
```

### Explanation
1. **Reading Input**: The integers \( A \) and \( B \) are read from standard input.
2. **Sum Calculation**: Compute the sum of \( A \) and \( B \).
3. **Check Even/Odd Sum**: If the sum is even, the integer \( K \) is the sum divided by 2. If the sum is odd, it is impossible to find such a \( K \), so we print "IMPOSSIBLE".

This approach efficiently determines the solution in constant time \( O(1) \) by leveraging arithmetic checks, ensuring optimal performance even for large input values.
