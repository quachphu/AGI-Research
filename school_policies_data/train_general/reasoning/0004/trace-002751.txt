To solve this problem, we need to determine the minimum and maximum possible total prices Valera might pay for his list of fruits, given the prices available at Ashot's stall. The key is to optimally assign the prices to the fruits to achieve the minimum and maximum sums.

### Approach
1. **Input Reading**: Read the number of price tags (n) and the number of fruits in Valera's list (m). Then read the list of prices and the list of fruits.
2. **Frequency Calculation**: Count the occurrences of each fruit in Valera's list.
3. **Sorting Frequencies**: Sort these frequencies in descending order to prioritize the most frequent fruits.
4. **Price Sorting**: Sort the prices in ascending order for the minimum sum and descending order for the maximum sum.
5. **Optimal Assignment**: For the minimum sum, assign the smallest prices to the most frequent fruits. For the maximum sum, assign the largest prices to the most frequent fruits.
6. **Sum Calculation**: Compute the total sum for both assignments and print the results.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n, m = map(int, sys.stdin.readline().split())
    prices = list(map(int, sys.stdin.readline().split()))
    freq = defaultdict(int)
    for _ in range(m):
        fruit = sys.stdin.readline().strip()
        freq[fruit] += 1
    frequencies = sorted(freq.values(), reverse=True)
    k = len(frequencies)
    
    # Calculate minimum sum
    sorted_min_prices = sorted(prices)[:k]
    min_sum = sum(f * p for f, p in zip(frequencies, sorted_min_prices))
    
    # Calculate maximum sum
    sorted_max_prices = sorted(prices, reverse=True)[:k]
    max_sum = sum(f * p for f, p in zip(frequencies, sorted_max_prices))
    
    print(min_sum, max_sum)

main()
```

### Explanation
1. **Reading Input**: The input is read using standard input functions. The first line gives the number of price tags and fruits, followed by the prices and the list of fruits.
2. **Frequency Calculation**: Using a dictionary, we count how many times each fruit appears in Valera's list.
3. **Sorting Frequencies**: The frequencies are sorted in descending order to handle the most frequent fruits first.
4. **Price Sorting**: Prices are sorted in ascending order to get the smallest prices for the minimum sum and descending order for the maximum sum.
5. **Optimal Assignment**: By aligning the highest frequencies with the smallest prices (for minimum sum) and largest prices (for maximum sum), we ensure the optimal total cost.
6. **Sum Calculation**: The sums are calculated by multiplying each frequency with the corresponding sorted price and summing the results.

This approach efficiently computes the required sums using sorting and alignment of frequencies with prices, ensuring the solution is both optimal and straightforward.
