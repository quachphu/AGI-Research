To solve this problem, we need to count the number of valid digit assignments for three numbers A, B, and C such that A + B = C, where some digits are missing (represented by '?'). The solution must ensure that the leading digits of each number are non-zero.

### Approach
1. **Reverse the Input Strings**: Process the digits from the least significant (rightmost) to the most significant (leftmost) to handle the carry-over efficiently.
2. **Dynamic Programming (DP)**: Use a DP array where `dp[i][carry]` represents the number of valid ways to assign digits up to position `i` with a carry value `carry`.
3. **Allowed Digits**: Precompute the allowed digits for each position in A, B, and C. If a digit is fixed, only that digit is allowed. If it's a '?', allow all digits (0-9 for non-leading positions, 1-9 for leading positions).
4. **Transition States**: For each position and possible carry value, iterate over all valid digit combinations for A and B, compute the corresponding digit for C, and update the DP array based on valid transitions.

### Solution Code
```python
MOD = 10**9 + 7

def get_allowed_digits(c, i, length):
    if c != '?':
        return [int(c)]
    else:
        if i == length - 1:
            return list(range(1, 10))
        else:
            return list(range(0, 10))

def solve():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    while True:
        A = input[idx]
        idx += 1
        if A == '0':
            break
        B = input[idx]
        idx +=1
        C = input[idx]
        idx +=1
        len_n = len(A)
        A_rev = A[::-1]
        B_rev = B[::-1]
        C_rev = C[::-1]
        
        allowed_A = []
        allowed_B = []
        allowed_C = []
        for i in range(len_n):
            allowed_A.append(get_allowed_digits(A_rev[i], i, len_n))
            allowed_B.append(get_allowed_digits(B_rev[i], i, len_n))
            c_digits = get_allowed_digits(C_rev[i], i, len_n)
            allowed_C.append(set(c_digits))
        
        # Initialize DP
        dp = [[0]*2 for _ in range(len_n + 1)]
        dp[0][0] = 1
        
        for i in range(len_n):
            for carry_in in [0, 1]:
                current = dp[i][carry_in]
                if current == 0:
                    continue
                # Iterate over possible a and b
                for a in allowed_A[i]:
                    for b in allowed_B[i]:
                        s = a + b + carry_in
                        c = s % 10
                        if c not in allowed_C[i]:
                            continue
                        carry_out = s // 10
                        # Check if it's the last digit and carry_out is non-zero
                        if i == len_n - 1 and carry_out != 0:
                            continue
                        dp[i+1][carry_out] = (dp[i+1][carry_out] + current) % MOD
        
        print(dp[len_n][0] % MOD)

if __name__ == "__main__":
    solve()
```

### Explanation
1. **Reading Input**: The input is read and split into individual datasets. Each dataset consists of three strings A, B, and C.
2. **Reversing Strings**: Each string is reversed to process digits from the least significant to the most significant.
3. **Allowed Digits Calculation**: For each position in the reversed strings, determine the allowed digits considering the constraints (non-zero leading digits).
4. **Dynamic Programming Initialization**: The DP array is initialized with `dp[0][0] = 1` to start counting from the rightmost digit with no carry.
5. **Processing Each Digit Position**: For each digit position and possible carry value, iterate over all valid combinations of digits for A and B, compute the corresponding digit for C, and update the DP array based on valid transitions considering the carry-out.
6. **Result Calculation**: The result for each dataset is the value in `dp[len_n][0]`, which gives the number of valid assignments modulo 1,000,000,007.
