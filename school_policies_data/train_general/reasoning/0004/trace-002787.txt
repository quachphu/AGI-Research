To solve this problem, we need to count the number of squares formed by roads arranged in a grid pattern based on given distances between consecutive roads in both north-south and east-west directions. The key insight is that a square is formed when the sum of consecutive distances in the north-south direction matches the sum of consecutive distances in the east-west direction.

### Approach
1. **Read Input:** Parse the input data to extract the number of roads and their respective distances in both directions.
2. **Compute Prefix Sums:** Generate prefix sums for the distances in both directions to efficiently calculate the sum of any subarray.
3. **Count Interval Sums:** For each possible interval in both directions, compute the sum and count the frequency of each sum using dictionaries.
4. **Calculate Total Squares:** For each sum that exists in both dictionaries, multiply the frequencies from both dictionaries to get the count of squares for that sum and accumulate the results.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    input = sys.stdin.read().split()
    ptr = 0
    while True:
        if ptr >= len(input):
            break
        N = int(input[ptr])
        M = int(input[ptr + 1])
        ptr += 2
        if N == 0 and M == 0:
            break
        
        h = []
        for _ in range(N):
            h.append(int(input[ptr]))
            ptr += 1
        
        w = []
        for _ in range(M):
            w.append(int(input[ptr]))
            ptr += 1
        
        # Compute prefix sums for h and w
        prefix_h = [0] * (N + 1)
        for i in range(1, N + 1):
            prefix_h[i] = prefix_h[i - 1] + h[i - 1]
        
        prefix_w = [0] * (M + 1)
        for i in range(1, M + 1):
            prefix_w[i] = prefix_w[i - 1] + w[i - 1]
        
        # Calculate frequency of each interval sum in h
        h_freq = defaultdict(int)
        for i in range(len(prefix_h)):
            for j in range(i + 1, len(prefix_h)):
                s = prefix_h[j] - prefix_h[i]
                h_freq[s] += 1
        
        # Calculate frequency of each interval sum in w
        w_freq = defaultdict(int)
        for i in range(len(prefix_w)):
            for j in range(i + 1, len(prefix_w)):
                s = prefix_w[j] - prefix_w[i]
                w_freq[s] += 1
        
        # Compute total squares
        total = 0
        for s in h_freq:
            if s in w_freq:
                total += h_freq[s] * w_freq[s]
        
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The input is read as a list of strings for efficient processing. Each dataset is parsed to extract the number of roads and their respective distances.
2. **Prefix Sums Calculation:** Prefix sums are computed for both directions to quickly determine the sum of any subarray. This allows efficient calculation of interval sums.
3. **Frequency Counting:** Using nested loops, we iterate over all possible intervals in both directions, compute their sums, and count the occurrences using dictionaries.
4. **Matching Sums:** For each sum found in both directions, the product of their frequencies gives the number of squares that can be formed with that side length. Summing these products gives the total number of squares for the dataset.

This approach ensures that we efficiently count all possible squares by leveraging prefix sums and frequency dictionaries, making the solution both optimal and easy to understand.
