To solve this problem, we need to generate the results of football matches such that each team has exactly k wins against other teams. The solution must ensure that no two teams play against each other more than once. If it's impossible to meet these conditions, we should return -1.

### Approach
1. **Check Feasibility**: The problem can be solved only if each team can have exactly k wins without exceeding the maximum number of allowed matches. This is possible if and only if \(2 \times k \leq n - 1\), where \(n\) is the number of teams. If this condition is not met, output -1.
2. **Generate Matches**: If feasible, generate matches such that each team beats the next k teams in a circular manner. This ensures that each team plays exactly k matches and no pair of teams plays more than once.

### Solution Code
```python
n, k = map(int, input().split())
if 2 * k > n - 1:
    print(-1)
else:
    print(n * k)
    for i in range(1, n + 1):
        for j in range(1, k + 1):
            next_team = (i + j - 1) % n
            next_team += 1
            print(i, next_team)
```

### Explanation
1. **Feasibility Check**: The condition \(2 \times k \leq n - 1\) ensures that each team can have exactly k wins without exceeding the maximum number of allowed matches. If this condition is not met, it is impossible to generate the required results, so we print -1.
2. **Generating Matches**: For each team, we generate matches against the next k teams in a circular order. This approach ensures that each team plays exactly k matches and no pair of teams plays more than once. The modulo operation helps in wrapping around the team indices to maintain the circular order.

This approach efficiently generates the required matches in \(O(n \times k)\) time complexity, which is optimal given the constraints.
