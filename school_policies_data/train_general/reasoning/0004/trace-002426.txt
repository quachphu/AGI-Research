To solve this problem, we need to determine the minimum number of friends Monk can invite to his birthday party while satisfying all dependency constraints. Each friend may have dependencies such that they will only attend if another specific friend is also invited. The goal is to find the smallest subset of friends that satisfies all these constraints.

### Approach
1. **Graph Representation**: Represent the dependencies as a directed graph where each edge from node `a` to node `b` indicates that friend `a` will only attend if friend `b` is invited.
2. **Closure Calculation**: For each friend, compute the closure, which is the set of all friends that must be invited if that friend is included. This closure includes all friends reachable from the starting friend via the directed edges.
3. **Breadth-First Search (BFS)**: Use BFS to traverse the graph starting from each friend and determine the closure for each friend. The size of the closure gives the number of friends that must be invited if that friend is included.
4. **Minimum Closure Size**: Track the minimum closure size across all friends to determine the smallest number of friends Monk can invite.

### Solution Code
```python
def main():
    import sys
    sys.setrecursionlimit(1 << 25)
    n, d = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n + 1)]
    for _ in range(d):
        a, b = map(int, sys.stdin.readline().split())
        adj[a].append(b)
    
    min_size = n  # maximum possible is n

    for x in range(1, n + 1):
        visited = set()
        stack = [x]
        visited.add(x)
        while stack:
            node = stack.pop()
            for neighbor in adj[node]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    stack.append(neighbor)
        current_size = len(visited)
        if current_size < min_size:
            min_size = current_size
    
    print(min_size)

main()
```

### Explanation
1. **Graph Construction**: The adjacency list `adj` is built from the input dependencies. Each entry `adj[a]` contains all friends that friend `a` depends on.
2. **Closure Calculation with BFS**: For each friend `x`, we use BFS to explore all friends that must be invited if `x` is included. This traversal starts at `x` and follows all outgoing edges, collecting all reachable friends into the closure set.
3. **Finding Minimum Closure**: After computing the closure for each friend, the size of the smallest closure is tracked and printed as the result. This ensures that Monk invites the minimum number of friends while satisfying all dependencies.

This approach efficiently computes the required closures using BFS, ensuring that we explore each friend's dependencies thoroughly. The overall complexity is manageable within the given constraints, making it suitable for the problem's input size.
