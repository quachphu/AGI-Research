To solve this problem, we need to determine which faces of a rectangular parallelepiped (box) Vasya can see from his given position in space. The solution involves checking the visibility of each face based on Vasya's coordinates relative to the box's dimensions.

### Approach
1. **Understand the Box Structure**: The box is defined with one vertex at (0, 0, 0) and the opposite vertex at (x1, y1, z1). Each face of the box is aligned with one of the coordinate planes.
2. **Face Identification**: Each face is identified based on its position and the axis it is aligned with:
   - a1 and a2 are on the Y-axis faces (Y=0 and Y=y1).
   - a3 and a4 are on the Z-axis faces (Z=0 and Z=z1).
   - a5 and a6 are on the X-axis faces (X=0 and X=x1).
3. **Visibility Check**: For each face, check if Vasya's coordinates lie outside the box in the direction perpendicular to that face. If so, he can see that face.

### Solution Code
```python
def main():
    import sys
    x, y, z = map(int, sys.stdin.readline().split())
    x1, y1, z1 = map(int, sys.stdin.readline().split())
    a1, a2, a3, a4, a5, a6 = map(int, sys.stdin.readline().split())
    total = 0
    if y < 0:
        total += a1
    if y > y1:
        total += a2
    if z < 0:
        total += a3
    if z > z1:
        total += a4
    if x < 0:
        total += a5
    if x > x1:
        total += a6
    print(total)

main()
```

### Explanation
- **Reading Input**: The input consists of Vasya's coordinates, the box's opposite vertex coordinates, and the numbers on each face.
- **Visibility Conditions**:
  - **Y-axis Faces**: Check if Vasya's Y-coordinate is less than 0 (for a1) or greater than y1 (for a2).
  - **Z-axis Faces**: Check if Vasya's Z-coordinate is less than 0 (for a3) or greater than z1 (for a4).
  - **X-axis Faces**: Check if Vasya's X-coordinate is less than 0 (for a5) or greater than x1 (for a6).
- **Summing Visible Faces**: For each face that meets the visibility condition, add the corresponding face number to the total sum.

This approach efficiently checks each face's visibility based on Vasya's position relative to the box, ensuring the solution is both correct and optimal.
