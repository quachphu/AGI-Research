To solve this problem, we need to determine the longest sequence of consecutive droids that R2-D2 can destroy using at most k shots. Each shot from a weapon affects all droids by reducing the count of a specific type of detail. The goal is to find the optimal number of shots for each weapon type to achieve the longest sequence of destroyed droids.

### Approach
1. **Sliding Window Technique**: Use a two-pointer (left and right) approach to maintain a window of droids. The window expands by moving the right pointer and contracts by moving the left pointer when the required shots exceed k.
2. **Efficient Maximum Tracking**: For each weapon type, maintain a deque to track the maximum number of details required in the current window. This allows efficient updates and lookups as the window slides.
3. **Sum Calculation**: Track the sum of the maximum details required for each weapon type in the current window. Adjust the window size (by moving the left pointer) if this sum exceeds k.

### Solution Code
```python
import sys
from collections import deque

def main():
    n, m, k = map(int, sys.stdin.readline().split())
    a = []
    for _ in range(n):
        a.append(list(map(int, sys.stdin.readline().split())))
    
    deques = [deque() for _ in range(m)]
    left = 0
    max_len = 0
    best_shots = [0] * m
    
    for right in range(n):
        # Update each deque with the current right's data
        for i in range(m):
            current_val = a[right][i]
            # Maintain deque in decreasing order
            while deques[i] and a[deques[i][-1]][i] <= current_val:
                deques[i].pop()
            deques[i].append(right)
        
        # Calculate the sum of max values for the current window
        current_sum = sum(a[deques[i][0]][i] for i in range(m))
        
        # Adjust the left pointer if the sum exceeds k
        while current_sum > k and left <= right:
            # Remove left from deques if it's the front element
            for i in range(m):
                if deques[i] and deques[i][0] == left:
                    deques[i].popleft()
            left += 1
            # Recalculate the current_sum after adjusting left
            if left <= right:
                current_sum = sum(a[deques[i][0]][i] for i in range(m) if deques[i])
            else:
                current_sum = 0
        
        # Update the best_shots if the current window is the longest found so far
        current_length = right - left + 1
        if current_length > max_len:
            max_len = current_length
            for i in range(m):
                if deques[i]:
                    best_shots[i] = a[deques[i][0]][i]
                else:
                    best_shots[i] = 0  # This case should not occur
    
    print(' '.join(map(str, best_shots)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and stored in a list of lists where each sublist represents the details of a droid.
2. **Deques for Maximum Tracking**: For each weapon type, a deque is used to maintain indices of droids in decreasing order of their detail counts. This allows efficient retrieval of the maximum detail count in the current window.
3. **Sliding Window**: The right pointer expands the window by adding new droids. If the sum of maximum details exceeds k, the left pointer contracts the window until the sum is within k.
4. **Updating Best Solution**: Whenever a longer valid window is found, the corresponding maximum details for each weapon type are recorded as the best solution.

This approach efficiently tracks the maximum details for each weapon type using deques, ensuring that the solution runs in O(n * m) time complexity, which is optimal for the given problem constraints.
