### Approach
1. **Preprocessing Substrings**: 
   - For each possible substring of `s` with lengths from 1 to 4, store their start and end indices in a dictionary. This allows quick look-up of all occurrences of any substring during query processing.

2. **Query Processing**:
   - For each query, retrieve the lists of start and end indices for the substrings `ai` and `bi`.
   - Use a two-pointer technique to traverse these lists efficiently, merging intervals to find the shortest valid substring that contains both `ai` and `bi`.

from collections import defaultdict
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    s = input[ptr]
    ptr += 1
    q = int(input[ptr])
    ptr += 1
    queries = []
    for _ in range(q):
        ai = input[ptr]
        bi = input[ptr+1]
        queries.append((ai, bi))
        ptr += 2

    substr_dict = defaultdict(list)
    n = len(s)
    for l in range(1, 5):
        for i in range(n - l + 1):
            substr = s[i:i+l]
            substr_dict[substr].append((i, i + l - 1))

    for ai, bi in queries:
        list_a = substr_dict.get(ai, [])
        list_b = substr_dict.get(bi, [])
        if not list_a or not list_b:
            print(-1)
            continue
        
        min_len = float('inf')
        i = j = 0
        len_a = len(list_a)
        len_b = len(list_b)
        
        while i < len_a and j < len_b:
            a_start, a_end = list_a[i]
            b_start, b_end = list_b[j]
            merged_start = min(a_start, b_start)
            merged_end = max(a_end, b_end)
            current_len = merged_end - merged_start + 1
            if current_len < min_len:
                min_len = current_len
            if a_end < b_end:
                i += 1
            else:
                j += 1
        
        # Check if there are remaining elements in list_a or list_b
        # that might form a valid pair with the last elements processed
        if i < len_a and len_b > 0:
            # Check the remaining a's with the last b
            b_last = list_b[-1]
            while i < len_a:
                a_start, a_end = list_a[i]
                merged_start = min(a_start, b_last[0])
                merged_end = max(a_end, b_last[1])
                current_len = merged_end - merged_start + 1
                if current_len < min_len:
                    min_len = current_len
                i += 1
        elif j < len_b and len_a > 0:
            # Check the remaining b's with the last a
            a_last = list_a[-1]
            while j < len_b:
                b_start, b_end = list_b[j]
                merged_start = min(a_last[0], b_start)
                merged_end = max(a_last[1], b_end)
                current_len = merged_end - merged_start + 1
                if current_len < min_len:
                    min_len = current_len
                j += 1
        
        print(min_len if min_len != float('inf') else -1)

if __name__ == "__main__":
    main()

2. **Two-pointer Technique**: For each query, we use two pointers to traverse the lists of occurrences of `ai` and `bi`. By merging intervals from both lists, we efficiently find the shortest valid substring that contains both substrings. The two pointers help us efficiently explore potential pairs of intervals, ensuring we consider the shortest possible merged intervals first.

3. **Handling Remaining Elements**: After the initial traversal, if there are remaining elements in either list, we check them against the last processed elements of the other list to ensure no valid pairs are missed.

This approach ensures that each query is processed efficiently, leveraging preprocessing and a two-pointer technique to minimize the length of the merged intervals considered.
