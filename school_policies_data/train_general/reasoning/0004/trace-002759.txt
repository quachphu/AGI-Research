To solve this problem, we need to determine the minimum number of distinct people Polycarpus could have seen based on a sequence of '+' and '-' characters. Each '+' represents a person entering the club, and each '-' represents a person leaving. The goal is to find the minimum number of distinct people such that the sequence of events is valid, considering that the initial and final number of people in the club are unknown.

### Approach
1. **Convert the Input String**: Convert the input sequence of '+' and '-' into a list of numerical values where '+' is represented as +1 and '-' as -1.
2. **Compute Prefix Sums**: Calculate the cumulative sum of the sequence starting from 0. This helps in tracking the number of people in the club after each event.
3. **Determine Minimum Initial People**: The minimum initial number of people required to ensure that the number of people never goes negative during the sequence is derived from the minimum prefix sum. This is calculated as the maximum of 0 and the negative of the minimum prefix sum.
4. **Calculate Maximum People**: Using the initial number of people determined in the previous step, compute the maximum number of people present in the club at any time by considering all prefix sums.

### Solution Code
```python
def main():
    s = input().strip()
    steps = [1 if c == '+' else -1 for c in s]
    prefix_sums = [0]
    current_sum = 0
    for step in steps:
        current_sum += step
        prefix_sums.append(current_sum)
    min_sum = min(prefix_sums)
    initial = max(0, -min_sum)
    max_people = max(initial + s_val for s_val in prefix_sums)
    print(max_people)

main()
```

### Explanation
1. **Input Conversion**: The input string is converted into a list of integers where each '+' is 1 and each '-' is -1. This allows us to process the events numerically.
2. **Prefix Sums Calculation**: By iterating through the converted list, we compute cumulative sums starting from 0. This helps in tracking the number of people after each event.
3. **Initial People Calculation**: The minimum initial number of people required is determined by finding the most negative value in the prefix sums. This value is negated and clamped to a minimum of 0 to ensure no negative values during the sequence.
4. **Maximum People Calculation**: By adding the initial number of people to each prefix sum, we determine the maximum number of people present at any point in time, which gives the minimum number of distinct people required.

This approach efficiently computes the required values using linear time complexity, making it suitable for the input constraints.
