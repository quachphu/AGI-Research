To solve this problem, we need to find the maximum length of a contiguous subarray where the product of all elements is non-zero. This translates to identifying the longest sequence of non-zero elements in the array, as any subarray containing a zero will have a product of zero.

### Approach
1. **Problem Analysis**: The key insight is that a subarray with a non-zero product must not contain any zeros. Therefore, we need to find the longest contiguous segment of non-zero elements in the array.
2. **Algorithm**: We can traverse the array once, keeping track of the current length of consecutive non-zero elements. Whenever we encounter a zero, we compare the current length with the maximum length found so far and reset the current length. After traversing the array, we perform a final check to ensure we account for any non-zero elements at the end of the array.
3. **Efficiency**: This approach runs in O(N) time complexity, where N is the number of elements in the array, making it efficient for large inputs up to 100,000 elements.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
max_len = 0
current = 0
for num in a:
    if num != 0:
        current += 1
        if current > max_len:
            max_len = current
    else:
        current = 0
print(max_len)
```

### Explanation
- **Initialization**: We initialize `max_len` to store the maximum length found and `current` to track the current streak of non-zero elements.
- **Traversal**: As we iterate through each element:
  - If the element is non-zero, we increment `current` and update `max_len` if the current streak is the longest found so far.
  - If a zero is encountered, we reset `current` to zero, as the streak of non-zero elements is broken.
- **Final Check**: After the loop, the maximum length of non-zero elements is already tracked, so we simply print `max_len`.

This approach efficiently finds the longest contiguous subarray of non-zero elements, ensuring optimal performance for large input sizes.
