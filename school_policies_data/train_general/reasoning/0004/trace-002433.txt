Each ball must be placed in one of the cylinders in the order they are given, and each subsequent ball in a cylinder must be larger than the previous one.

### Approach
1. **Dynamic Programming (DP) with State Tracking**: We use a dynamic programming approach where each state is represented by a tuple indicating the last ball in each cylinder. The state transitions are managed by checking if the current ball can be placed in either cylinder while maintaining the strictly increasing order.
2. **State Management**: For each ball in the sequence, we track all possible states (last ball in each cylinder) that can be achieved by placing the current ball in either cylinder. If at any point no valid states are possible, we immediately conclude that the sequence cannot be split and return "NO".
3. **Efficiency**: Given the constraints (10 balls), the number of possible states is manageable, making the approach feasible within reasonable time limits.

### Solution Code
```python
def can_divide_sequence(sequence):
    current_states = {(None, None)}
    for x in sequence:
        next_states = set()
        for (b, c) in current_states:
            if b is None or x > b:
                next_states.add((x, c))
            if c is None or x > c:
                next_states.add((b, x))
        current_states = next_states
        if not current_states:
            return False
    return bool(current_states)

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    idx = 1
    for _ in range(n):
        seq = list(map(int, input[idx:idx+10]))
        idx += 10
        if can_divide_sequence(seq):
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    main()
```
