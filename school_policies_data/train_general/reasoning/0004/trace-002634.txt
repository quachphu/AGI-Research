To solve this problem, we need to determine the minimum number of steps required to move a rover from the starting position (0, 0) with face 0 on the bottom to a specified position (x, y) with a specified face n on the bottom. The rover can move to one of three neighboring trigons based on the current position's parity (even or odd sum of coordinates), and each movement changes the bottom face according to predefined transitions.

### Approach
1. **Model the Problem as a Graph**: Each state of the rover is represented by its coordinates (x, y) and the current face on the bottom. The goal is to find the shortest path from the initial state (0, 0, 0) to the target state (x, y, n).

2. **Breadth-First Search (BFS)**: Use BFS to explore all possible states level by level, ensuring that the first time we reach the target state is with the minimum number of steps. BFS is suitable here because it guarantees the shortest path in an unweighted graph.

3. **Face Transitions**: Predefine the transitions for each face when moving west, east, or north/south (third direction). These transitions are based on the structure of an icosahedron.

4. **Movement Directions**: Depending on the parity of the sum of the current coordinates, the third direction (north/south) is determined. For even sums, move north (y+1); for odd sums, move south (y-1).

def solve():
    import sys
    from collections import deque

    # Transition table for each face: [west, east, third]
    trans = [
        [4, 1, 5],    # Face 0
        [0, 6, 2],    # Face 1
        [1, 7, 3],    # Face 2
        [2, 8, 4],    # Face 3
        [3, 9, 0],    # Face 4
        [0, 10, 6],   # Face 5
        [5, 11, 1],   # Face 6
        [6, 12, 2],   # Face 7
        [7, 13, 3],   # Face 8
        [8, 14, 4],   # Face 9
        [4, 15, 5],   # Face 10
        [10, 16, 6],  # Face 11
        [11, 17, 7],  # Face 12
        [12, 18, 8],  # Face 13
        [13, 19, 9],  # Face 14
        [9, 10, 19],  # Face 15
        [15, 17, 11], # Face 16
        [16, 18, 12], # Face 17
        [17, 19, 13], # Face 18
        [18, 14, 15], # Face 19
    ]

    while True:
        line = sys.stdin.readline()
        if not line:
            break
        x_target, y_target, n_target = map(int, line.strip().split())
        if x_target == 0 and y_target == 0 and n_target == 0:
            break

        # BFS initialization
        visited = {}
        queue = deque()
        queue.append((0, 0, 0, 0))
        visited[(0, 0, 0)] = 0
        found = False

        while queue:
            current_x, current_y, current_face, steps = queue.popleft()

            # Check if target is reached
            if current_x == x_target and current_y == y_target and current_face == n_target:
                print(steps)
                found = True
                break

            # Generate all possible moves
            # Move west (direction 0)
            new_x = current_x - 1
            new_y = current_y
            new_face = trans[current_face][0]
            if (new_x, new_y, new_face) not in visited or steps + 1 < visited.get((new_x, new_y, new_face), float('inf')):
                visited[(new_x, new_y, new_face)] = steps + 1
                queue.append((new_x, new_y, new_face, steps + 1))

            # Move east (direction 1)
            new_x = current_x + 1
            new_y = current_y
            new_face = trans[current_face][1]
            if (new_x, new_y, new_face) not in visited or steps + 1 < visited.get((new_x, new_y, new_face), float('inf')):
                visited[(new_x, new_y, new_face)] = steps + 1
                queue.append((new_x, new_y, new_face, steps + 1))

            # Move third direction (north or south based on current_x + current_y)
            sum_xy = current_x + current_y
            if sum_xy % 2 == 0:
                new_y = current_y + 1
            else:
                new_y = current_y - 1
            new_x = current_x
            new_face = trans[current_face][2]
            if (new_x, new_y, new_face) not in visited or steps + 1 < visited.get((new_x, new_y, new_face), float('inf')):
                visited[(new_x, new_y, new_face)] = steps + 1
                queue.append((new_x, new_y, new_face, steps + 1))

        if not found:
            # According to the problem statement, this case shouldn't happen within 100 steps
            print(100)
