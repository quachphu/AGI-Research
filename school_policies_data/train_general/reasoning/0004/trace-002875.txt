To solve this problem, we need to determine the number of distinct shapes formed by painting consecutive days on a calendar with a variable number of days per week. The shapes are considered the same if they can be translated (shifted) to overlap exactly.

### Approach
The key insight is that the number of distinct shapes depends on the number of days in a week (k) and the number of consecutive days (n) painted. For each k, the shape of the painted days is determined by how the days wrap around the weeks. 

1. **For k < n**: Each k from 1 to min(r, n-1) contributes a unique shape. The number of such unique shapes is given by the sum of the first (min(r, n-1)) integers.
2. **For k >= n**: All such k values contribute a single unique shape (a straight line of length n). Thus, if r >= n, we add 1 to the result.

The formula to compute the result is:
- Sum of the first m integers where m = min(r, n-1)
- Add 1 if r >= n

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, r = map(int, input().split())
    m = min(r, n - 1)
    res = m * (m + 1) // 2
    if r >= n:
        res += 1
    print(res)
```

### Explanation
1. **Reading Input**: We first read the number of test cases.
2. **Loop Through Test Cases**: For each test case, read the values of n (number of consecutive days) and r (maximum possible days in a week).
3. **Compute m**: Determine m as the minimum of r and n-1. This gives the range of k values that contribute unique shapes.
4. **Sum Calculation**: Calculate the sum of the first m integers using the formula m*(m+1)//2.
5. **Check for k >= n**: If r is greater than or equal to n, add 1 to the result to account for the single unique shape contributed by all k >= n.
6. **Output the Result**: Print the computed result for each test case.

This approach efficiently handles large values of n and r by leveraging mathematical summation formulas and ensures that the solution is computed in constant time for each test case.
