To solve this problem, we need to calculate the time penalty for a programming contest participant based on their submission time and the number of wrong attempts. The time penalty is determined by the total time taken from the start of the contest plus an additional penalty for each wrong attempt.

### Approach
1. **Understand the Input and Output**: The input consists of four integers representing the day (D), hour (H), minute (M) of submission, and the number of wrong attempts (W). The output is the total time penalty in minutes.
2. **Calculate the Time Difference**: The contest starts on 1st July 2014 at 00:00. The time difference from the start to the submission time is computed in minutes. This involves:
   - Converting the days from the start day (D-1) to minutes.
   - Converting the submission hour (H) and minute (M) to minutes.
3. **Add Penalty for Wrong Attempts**: Each wrong attempt adds 20 minutes to the penalty. This is calculated by multiplying the number of wrong attempts (W) by 20.
4. **Sum the Components**: The total time penalty is the sum of the computed time difference and the penalty from wrong attempts.

### Solution Code
```python
def calculate_penalty():
    import sys
    D, H, M, W = map(int, sys.stdin.readline().split())
    time_diff = (D - 1) * 24 * 60 + H * 60 + M
    penalty = time_diff + 20 * W
    print(penalty)

calculate_penalty()
```

### Explanation
- **Reading Input**: The input is read from standard input and split into four integers.
- **Time Difference Calculation**: 
  - The days from the start day (D-1) are converted to minutes by multiplying by 24 (hours per day) and 60 (minutes per hour).
  - The submission hour (H) and minute (M) are converted to minutes and added to the day-based minutes.
- **Penalty Calculation**: The penalty from wrong attempts is calculated by multiplying the number of wrong attempts (W) by 20.
- **Output**: The total penalty is printed, which is the sum of the time difference and the wrong attempt penalty.

This approach efficiently computes the required time penalty using straightforward arithmetic operations, ensuring accuracy and handling the constraints effectively.
