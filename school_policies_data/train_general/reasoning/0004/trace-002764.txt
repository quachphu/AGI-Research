4. **Leaf Check**: During traversal, check if a node is a leaf (has no children except its parent). If it is a leaf, verify if the maximum consecutive cats encountered on the path is within the allowed limit `m`.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    idx = 0
    n = int(data[idx])
    m = int(data[idx+1])
    idx +=2
    a = list(map(int, data[idx:idx+n]))
    idx +=n
    a = [0] + a  # 1-based indexing
    
    adj = [[] for _ in range(n+1)]
    for _ in range(n-1):
        x = int(data[idx])
        y = int(data[idx+1])
        adj[x].append(y)
        adj[y].append(x)
        idx +=2
    
    stack = [(1, -1, a[1], a[1])]
    answer = 0
    
    while stack:
        u, parent, curr, mx = stack.pop()
        children = [v for v in adj[u] if v != parent]
        if not children:
            if mx <= m:
                answer += 1
        else:
            for v in children:
                if a[v] == 1:
                    new_curr = curr + 1
                    new_mx = max(mx, new_curr)
                else:
                    new_curr = 0
                    new_mx = mx
                stack.append((v, u, new_curr, new_mx))
    
    print(answer)

main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially for large datasets. The tree structure and cat presence information are parsed into appropriate data structures.
2. **Tree Traversal**: Using a stack to simulate DFS, we start from the root node (vertex 1). Each stack element keeps track of the current node, its parent, the current streak of consecutive cats, and the maximum streak encountered so far.
3. **Updating Streaks**: For each node visited, if the node has a cat, the current streak is incremented; otherwise, it resets to zero. The maximum streak is updated accordingly.
4. **Leaf Node Check**: When a leaf node is encountered (no children except its parent), check if the maximum streak of consecutive cats is within the allowed limit `m`. If it is, the leaf is counted as a valid restaurant.

This approach ensures that we efficiently traverse the tree and check each path from the root to the leaves, adhering to the constraints provided. The use of DFS allows us to explore each path deeply while maintaining the necessary state to track consecutive cats.
