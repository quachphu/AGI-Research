To solve this problem, we need to count the number of pairs of indices (i, j) such that i < j and the product of the elements at these indices equals the sum of the indices themselves. The solution must efficiently handle large input sizes while ensuring correctness.

### Approach
1. **Observation**: The product of two elements must equal the sum of their indices. Given the constraints, the product must be relatively small, which allows us to limit our search to elements that are small enough to make the product feasible.
2. **Divide Elements**: Separate elements into "small" and "large" based on a threshold value derived from the square root of twice the array length. This threshold helps in reducing the number of pairs to check.
3. **Check Pairs**: For each small element, check all subsequent elements. For each large element, only check subsequent small elements to avoid redundant checks and reduce complexity.

### Solution Code
```python
import math
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        a = list(map(int, input[ptr:ptr + n]))
        ptr += n
        s = int(math.isqrt(2 * n))
        small = []
        large = []
        for idx in range(n):
            val = a[idx]
            if val <= s:
                small.append((val, idx + 1))  # Store (value, 1-based index)
            else:
                large.append((val, idx + 1))
        count = 0
        # Process pairs where the first element is small
        for x, i in small:
            for j in range(i + 1, n + 1):
                y = a[j - 1]
                if x * y == i + j:
                    count += 1
        # Process pairs where the first element is large and the second is small
        for x, i in large:
            for y, j in small:
                if j > i and x * y == i + j:
                    count += 1
        print(count)

if __name__ == "__main__":
    main()
```

2. **Threshold Calculation**: The threshold `s` is calculated using the square root of twice the array length to determine small and large elements.
3. **Element Classification**: Elements are classified into small and large based on the threshold. This helps in reducing the number of pairs to check.
4. **Pair Checking**:
   - For each small element, check all subsequent elements to see if they form a valid pair.
   - For each large element, check only subsequent small elements, as large elements paired with other large elements would exceed the product constraint.

This approach ensures that we efficiently check all feasible pairs while avoiding redundant checks, leading to an optimal solution that handles the problem constraints effectively.
