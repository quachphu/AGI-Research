To solve this problem, we need to determine the number of students invited to a Christmas party, which includes direct friends of the host (student 1) and friends of those direct friends. The solution involves modeling the friendships as a graph and using graph traversal techniques to identify the required students.

### Approach
1. **Input Reading**: Read multiple datasets until encountering a line with two zeros. Each dataset consists of the number of students, the number of friendship entries, and the list of friendships.
2. **Graph Construction**: Represent the friendships using an adjacency list to efficiently store and access the friends of each student.
3. **Identify Direct Friends (Level 1)**: Extract all direct friends of the host (student 1) from the adjacency list.
4. **Identify Friends of Friends (Level 2)**: For each direct friend, collect their friends, excluding the host and the direct friends themselves.
5. **Count Invitations**: Sum the number of direct friends and friends of friends to get the total number of invited students.

### Solution Code
```python
import sys
from sys import stdin

def main():
    while True:
        n_line = stdin.readline().strip()
        if not n_line:
            break
        n = int(n_line)
        m_line = stdin.readline().strip()
        if not m_line:
            break
        m = int(m_line)
        if n == 0 and m == 0:
            break
        
        adj = [[] for _ in range(n + 1)]  # 1-based indexing
        
        for _ in range(m):
            a, b = map(int, stdin.readline().strip().split())
            adj[a].append(b)
            adj[b].append(a)
        
        # Collect level 1 friends (direct friends of 1)
        level1 = set(adj[1]) if 1 <= n else set()
        
        # Collect level 2 friends (friends of level1, excluding 1 and level1)
        level2 = set()
        for friend in level1:
            for neighbor in adj[friend]:
                if neighbor != 1 and neighbor not in level1:
                    level2.add(neighbor)
        
        total = len(level1) + len(level2)
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads each dataset line by line, starting with the number of students and the number of friendships. It continues until both values are zero.
2. **Graph Construction**: An adjacency list is built where each student's index points to a list of their friends.
3. **Direct Friends Identification**: The direct friends of the host (student 1) are identified by accessing the adjacency list at index 1.
4. **Friends of Friends Identification**: For each direct friend, their friends are checked. Those who are not the host and not already direct friends are added to the friends of friends set.
5. **Result Calculation**: The total number of invited students is the sum of the sizes of the direct friends set and the friends of friends set, which is then printed for each dataset.

This approach efficiently processes each dataset using graph traversal techniques to ensure all required students are counted, adhering to the problem constraints and requirements.
