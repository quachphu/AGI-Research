   - If 3N < P, we compute the factorial modulo P and use modular inverses to handle the division.

3. **Efficient Computation**:
   - For 3N >= P, the result is 0.
   - For 3N < P, compute (3N)! modulo P by iterating from 3N+1 to P-1 and using Wilson's theorem to simplify the computation.
   - Compute the modular inverse of the denominator (6^N) using Fermat's Little Theorem.

import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        N = int(input[idx])
        P = int(input[idx + 1])
        idx += 2
        m = 3 * N
        if m >= P:
            print(0)
        else:
            product = 1
            for i in range(m + 1, P):
                product = (product * i) % P
            inv_product = pow(product, P - 2, P)
            m_fact = (-inv_product) % P
            denominator = pow(6, N, P)
            inv_denominator = pow(denominator, P - 2, P)
            res = (m_fact * inv_denominator) % P
            print(res)

if __name__ == "__main__":
    main()
