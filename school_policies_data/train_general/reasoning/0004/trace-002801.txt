To solve this problem, we need to determine the total number of steps taken during the process described in the problem statement. The key challenge is to efficiently compute this without simulating each possible initial value (init) step-by-step, which would be computationally infeasible for large strings.

### Approach
1. **Understanding the Process**: The process involves simulating steps for different initial values (init) until we find the minimum init that allows the entire string to be processed without the current value (cur) dropping below zero. Each step contributes to a result counter (res).

2. **Prefix Sum Insight**: For each character in the string, we compute the cumulative sum of the operations. This helps in determining the points where the current value might drop below zero for different initial values.

3. **Efficient Calculation**: Instead of simulating each init, we calculate the contribution of each position in the string to the result. For each position, we determine how many initial values would cause the process to fail at that position. This is done by tracking the maximum negative cumulative sum encountered so far.

4. **Contribution Calculation**: For each position, we compute the interval of initial values that would fail at that position. The number of such values multiplied by the position gives the contribution to the result. Summing these contributions and adding the length of the string (for the successful initial value) gives the final result.

### Solution Code
```python
import sys

def calculate_res(s):
    sum_s = 0
    current_max_prev = 0
    res = 0
    for i in range(len(s)):
        c = s[i]
        if c == '+':
            sum_s += 1
        else:
            sum_s -= 1
        contribution = max(0, (-sum_s) - current_max_prev) * (i + 1)
        res += contribution
        current_max_prev = max(current_max_prev, -sum_s)
    res += len(s)
    return res

t = int(sys.stdin.readline())
for _ in range(t):
    s = sys.stdin.readline().strip()
    print(calculate_res(s))
```

### Explanation
1. **Reading Input**: The number of test cases is read first, followed by each string for which the result needs to be computed.

2. **Prefix Sum Calculation**: For each character in the string, we maintain a running sum of the operations (+1 for '+', -1 for '-').

3. **Tracking Maximum Negative Sum**: We keep track of the maximum negative cumulative sum encountered so far. This helps in determining the range of initial values that would fail at each position.

4. **Contribution Calculation**: For each position, the contribution to the result is calculated based on the range of initial values that would fail at that position. This is done by comparing the current cumulative sum with the maximum negative sum encountered so far.

5. **Final Result**: After processing all characters, the result is the sum of all contributions plus the length of the string (for the successful initial value).

This approach efficiently computes the result in linear time relative to the length of the string, making it suitable for large inputs.
