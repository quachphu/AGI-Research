The goal is to minimize the maximum fuel required for any segment, which translates to the minimum tank size. The key insight is to split the journey into segments such that the maximum distance covered in any segment (when multiplied by the fuel consumption rate) is minimized.

2. **Binary Search**: For each truck, we use binary search to determine the minimum possible maximum segment length. This involves checking if the journey can be divided into the allowed number of segments (refuels + 1) such that no segment exceeds the current candidate length.

3. **Precomputation**: For efficiency, we precompute the distances between consecutive cities. For each truck's route, we use binary search to find the minimum possible maximum segment length that allows the journey to be completed within the refueling constraints.

import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n, m = int(input[ptr]), int(input[ptr+1])
    ptr += 2
    a = list(map(int, input[ptr:ptr+n]))
    ptr += n

    max_v = 0
    for _ in range(m):
        s_i = int(input[ptr]) - 1
        f_i = int(input[ptr+1]) - 1
        c_i = int(input[ptr+2])
        r_i = int(input[ptr+3])
        ptr += 4

        if s_i >= f_i:
            continue  # invalid, but input ensures s_i < f_i

        # Compute distances between consecutive cities in the path
        distances = []
        for i in range(s_i, f_i):
            distances.append(a[i+1] - a[i])
        m_dist = len(distances)
        if m_dist == 0:
            continue

        max_d = max(distances)
        sum_d = sum(distances)
        k = r_i + 1

        if k >= m_dist:
            current_max = max_d * c_i
        else:
            low = max_d
            high = sum_d
            answer = high
            while low <= high:
                mid = (low + high) // 2
                groups = 1
                current_sum = 0
                for d in distances:
                    if current_sum + d > mid:
                        groups += 1
                        current_sum = d
                        if groups > k:
                            break
                    else:
                        current_sum += d
                if groups <= k:
                    answer = mid
                    high = mid - 1
                else:
                    low = mid + 1
            current_max = answer * c_i

        if current_max > max_v:
            max_v = current_max

    print(max_v)
