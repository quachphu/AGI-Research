To solve this problem, we need to determine the minimum number of integers to remove from a list such that the greatest common divisor (GCD) of the remaining integers is greater than the GCD of the entire original list. If it's impossible, we return -1.

### Approach
1. **Compute the Original GCD**: Calculate the GCD of all integers in the list.
2. **Transform the List**: Divide each integer by the original GCD. If all resulting values are 1, output -1 since it's impossible to increase the GCD.
3. **Sieve of Eratosthenes**: Precompute the smallest prime factor (SPF) for every number up to the maximum value in the transformed list to facilitate efficient prime factorization.
4. **Prime Factorization**: For each number in the transformed list (excluding 1), determine its prime factors and count the frequency of each prime factor.
5. **Determine Result**: The maximum frequency of any prime factor indicates the largest subset of numbers that share a common divisor greater than 1. The minimum removals required are the total count minus this maximum frequency.

### Solution Code
```python
import sys
import math

def main():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    
    if n == 0:
        print(-1)
        return
    
    # Compute GCD of all elements
    g = a[0]
    for num in a[1:]:
        g = math.gcd(g, num)
    
    b = [x // g for x in a]
    if all(x == 1 for x in b):
        print(-1)
        return
    
    max_b = max(b)
    if max_b < 2:
        print(-1)
        return
    
    # Compute smallest prime factors (SPF) sieve up to max_b
    spf = list(range(max_b + 1))
    for i in range(2, int(math.isqrt(max_b)) + 1):
        if spf[i] == i:  # i is a prime
            for j in range(i * i, max_b + 1, i):
                if spf[j] == j:
                    spf[j] = i
    
    # Count frequency of each prime factor in elements of b (excluding 1)
    freq = {}
    for x in b:
        if x == 1:
            continue
        current = x
        primes = set()
        while current != 1:
            p = spf[current]
            primes.add(p)
            while current % p == 0:
                current //= p
        for p in primes:
            freq[p] = freq.get(p, 0) + 1
    
    max_freq = max(freq.values())
    print(n - max_freq)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Compute GCD**: The GCD of the entire list is calculated first. If all elements divided by this GCD are 1, the answer is -1.
2. **Transform List**: Each element is divided by the GCD, forming a new list. If all elements in this new list are 1, output -1.
3. **Sieve of Eratosthenes**: This precomputes the smallest prime factor for each number up to the maximum value in the transformed list, allowing efficient prime factorization.
4. **Prime Factor Counting**: Each number in the transformed list (excluding 1) is factorized into primes using the precomputed SPF. The frequency of each prime factor is counted.
5. **Result Calculation**: The maximum frequency of any prime factor determines the largest subset with a common divisor greater than 1. The answer is the total number of elements minus this maximum frequency, giving the minimum removals needed.
