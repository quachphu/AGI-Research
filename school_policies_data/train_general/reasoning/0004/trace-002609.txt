class FenwickTree:

    def __init__(self, size):

        self.n = size

        self.tree = [0] * (self.n +1)  # 1-based indexing

    def add(self, idx, delta):

        # idx is 1-based

        while idx <= self.n:

            self.tree[idx] += delta

            idx += idx & -idx

    def query(self, idx):

        # sum from 1 to idx (inclusive)

        res =0

        while idx >0:

            res += self.tree[idx]

            idx -= idx & -idx

        return res

To solve this problem, we need to determine the final username after applying a series of deletion operations on an initial username formed by concatenating multiple copies of a given string. Each deletion operation removes a specific occurrence of a character from the current username.

### Approach
1. **Initial Setup**: Construct the initial username by repeating the given string `s` exactly `k` times.
2. **Track Positions**: Precompute the positions of each character in the initial username to efficiently locate and delete the required occurrences.
3. **Efficient Deletions**: Use a Fenwick Tree (Binary Indexed Tree) for each character to efficiently count and update the active occurrences of the character. This allows us to perform each deletion operation in logarithmic time relative to the number of occurrences of the character.
4. **Process Operations**: For each deletion operation, use binary search on the Fenwick Tree to find the required occurrence and mark it as deleted.
5. **Construct Result**: After processing all operations, construct the final username by including only the characters that were not deleted.

2. **Track Positions**: We use a dictionary to track the positions of each character in `t`, which helps in quickly accessing all occurrences of any character.
3. **Fenwick Tree**: For each character, a Fenwick Tree is initialized to keep track of active occurrences. This allows efficient updates and queries to determine the position of the `p`-th occurrence.
4. **Binary Search**: For each deletion operation, binary search on the Fenwick Tree helps locate the `p`-th occurrence in logarithmic time, ensuring efficient processing even for large inputs.
