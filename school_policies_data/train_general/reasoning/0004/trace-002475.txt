To solve this problem, we need to determine if the sum or product of two given integers equals 15. Based on the result, we will print '+', '*', or 'x' if neither condition is met.

### Approach
1. **Input Reading**: Read two integers from the standard input.
2. **Check Conditions**: 
   - First, check if the sum of the two integers equals 15. If true, print '+'.
   - If the sum is not 15, check if the product of the two integers equals 15. If true, print '*'.
   - If neither condition is met, print 'x'.

### Solution Code
```python
def main():
    a, b = map(int, input().split())
    if a + b == 15:
        print('+')
    elif a * b == 15:
        print('*')
    else:
        print('x')

main()
```

### Explanation
1. **Reading Input**: The input is read as a single line and split into two integers using `map(int, input().split())`.
2. **Sum Check**: The sum of the integers is checked first. If it equals 15, the result is '+'.
3. **Product Check**: If the sum is not 15, the product of the integers is checked. If it equals 15, the result is '*'.
4. **Default Case**: If neither the sum nor the product equals 15, the result is 'x'.

This approach ensures that we check the conditions in the required order and efficiently determine the correct output based on the given constraints.
