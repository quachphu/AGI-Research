To solve this problem, we need to determine the number of ways to extract non-overlapping substrings from a string `s` such that each substring contains another string `t` as a substring. The solution must be efficient given the constraints where the lengths of `s` and `t` can be up to 100,000 characters.

### Approach
1. **Find Occurrences of `t` in `s`**: First, we identify all starting positions in `s` where `t` occurs. These positions are stored in a list `P` sorted in increasing order.
2. **Compute `p_max` for Each Position**: For each position `j` in `s`, compute the maximum starting position `p` of `t` such that the substring ending at `j` can include this occurrence of `t`.
3. **Dynamic Programming (DP) with Prefix Sum**: Use dynamic programming to count the number of valid ways to select non-overlapping substrings. We maintain a prefix sum array to efficiently compute the sum of previous valid configurations up to a certain point.

### Solution Code
```python
import bisect

MOD = 10**9 + 7

def main():
    s = input().strip()
    t = input().strip()
    len_s = len(s)
    len_t = len(t)
    
    # Find all occurrences of t in s (1-based)
    occurrences = []
    start = 0
    while True:
        pos = s.find(t, start)
        if pos == -1:
            break
        occurrences.append(pos + 1)  # Convert to 1-based index
        start = pos + 1
    
    if not occurrences:
        print(0)
        return
    
    P = occurrences
    P_sorted = sorted(P)
    
    # Precompute p_max for each j (1-based)
    p_max = [0] * (len_s + 2)  # j ranges from 1 to len_s
    for j in range(1, len_s + 1):
        target = j - len_t + 1
        if target < 1:
            p_max[j] = 0
        else:
            idx = bisect.bisect_right(P_sorted, target) - 1
            if idx >= 0:
                p_max[j] = P_sorted[idx]
            else:
                p_max[j] = 0
    
    # Initialize DP and prefix_sum arrays
    dp = [0] * (len_s + 2)
    prefix_sum = [0] * (len_s + 2)
    dp[0] = 1  # Base case: empty selection
    prefix_sum[0] = 1
    
    for j in range(1, len_s + 1):
        current_p_max = p_max[j]
        if current_p_max == 0:
            sum_prev = 0
        else:
            sum_prev = prefix_sum[current_p_max - 1]
        
        dp[j] = (dp[j-1] + sum_prev) % MOD
        prefix_sum[j] = (prefix_sum[j-1] + dp[j]) % MOD
    
    answer = (dp[len_s] - 1) % MOD  # Subtract the empty selection case
    print(answer)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Finding Occurrences**: The code uses a loop to find all starting positions of `t` in `s` using the `find` method, converting them to 1-based indices.
2. **Binary Search for `p_max`**: For each position `j` in `s`, the maximum valid starting position of `t` that can be covered by a substring ending at `j` is determined using binary search.
3. **Dynamic Programming**: The DP array `dp[j]` tracks the number of ways to form valid substrings up to position `j`. The prefix sum array helps efficiently compute the sum of previous valid configurations, allowing the solution to run in linear time.

This approach ensures that we efficiently count all valid configurations of non-overlapping substrings, each containing `t`, using dynamic programming and prefix sums to handle large input sizes within feasible time complexity.
