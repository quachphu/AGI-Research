To solve this problem, we need to determine the number of integers between A and B (inclusive) that are not divisible by either C or D. Given the constraints where B can be as large as \(10^{18}\), a direct iteration approach is infeasible. Instead, we use mathematical principles to efficiently compute the result.

### Approach
1. **Inclusion-Exclusion Principle**: This principle helps us count elements that satisfy at least one of several conditions. Here, we use it to count numbers divisible by C or D, and then subtract these counts from the total numbers in the range.
2. **Greatest Common Divisor (GCD) and Least Common Multiple (LCM)**: The LCM of C and D helps us count numbers divisible by both C and D. The formula for LCM using GCD is \( \text{LCM}(C, D) = \frac{C \times D}{\text{GCD}(C, D)} \).

### Solution Code
```python
import math

def main():
    A, B, C, D = map(int, input().split())
    gcd = math.gcd(C, D)
    lcm = C * D // gcd

    def count_divisors(n, divisor):
        return n // divisor

    count_C = count_divisors(B, C) - count_divisors(A - 1, C)
    count_D = count_divisors(B, D) - count_divisors(A - 1, D)
    count_both = count_divisors(B, lcm) - count_divisors(A - 1, lcm)

    total = B - A + 1
    result = total - (count_C + count_D - count_both)
    print(result)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input values A, B, C, and D are read from standard input.
2. **GCD and LCM Calculation**: Compute the GCD of C and D, then use it to find the LCM.
3. **Counting Divisors**: Calculate how many numbers in the range [A, B] are divisible by C, D, and the LCM of C and D using integer division.
4. **Inclusion-Exclusion Principle**: Subtract the counts of numbers divisible by C or D from the total numbers in the range, adjusting for double-counting using the LCM.

This approach efficiently handles the large input constraints by reducing the problem to a series of arithmetic operations, ensuring it runs in constant time \(O(1)\).
