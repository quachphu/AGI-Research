To solve this problem, we need to determine the number of beautiful matrices of size N x M. A matrix is considered beautiful if it meets two conditions: all elements are distinct natural numbers up to N*M, and the elements are ordered based on the XOR values of their cell indices.

### Approach
1. **Understanding the Problem**: The key insight is that the values in the matrix must follow the order of the XOR values of their indices. Cells with the same XOR value can have their values permuted among themselves, but they must be consecutive in the overall sequence of numbers from 1 to N*M.
2. **XOR Calculation**: For each cell (i, j), compute the XOR of the indices (i, j).
3. **Frequency Counting**: Count how many times each XOR value appears in the matrix.
4. **Factorials of Frequencies**: The number of ways to permute elements with the same XOR value is given by the factorial of their frequency. Multiply these factorials together to get the total number of beautiful matrices.

### Solution Code
```python
MOD = 10**9 + 7
max_fact = 10**6  # Since N and M can be up to 1000, their product is up to 1e6

# Precompute factorials modulo 10^9+7 up to max_fact
fact = [1] * (max_fact + 1)
for i in range(2, max_fact + 1):
    fact[i] = fact[i-1] * i % MOD

def main():
    import sys
    from collections import defaultdict
    input = sys.stdin.read().split()
    N = int(input[0])
    M = int(input[1])
    
    freq = defaultdict(int)
    for i in range(1, N + 1):
        for j in range(1, M + 1):
            xor = i ^ j
            freq[xor] += 1
    
    result = 1
    for count in freq.values():
        result = result * fact[count] % MOD
    
    print(result)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precompute Factorials**: We precompute the factorials modulo \(10^9 + 7\) up to \(10^6\) to efficiently handle large values of N and M.
2. **Frequency Calculation**: For each cell (i, j) in the matrix, we compute the XOR of the indices and count how many times each XOR value occurs.
3. **Result Calculation**: The result is the product of the factorials of these frequencies, modulo \(10^9 + 7\). This accounts for all permutations of values within each group of cells sharing the same XOR value.

This approach ensures that we efficiently compute the number of beautiful matrices by leveraging precomputation and modular arithmetic to handle large numbers.
