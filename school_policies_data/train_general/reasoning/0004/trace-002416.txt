To solve this problem, we need to determine if there exists a filename pattern using the '?' wildcard character that matches exactly the files to be deleted and no others. The solution involves constructing a candidate pattern from the selected files and verifying its validity against non-selected files.

### Approach

1. **Input Reading**: Read the number of files and the number of files to be deleted. Then, read the filenames and the indices of the files to be deleted.
2. **Check Length Consistency**: Ensure all selected files have the same length. If not, output "No".
3. **Pattern Construction**: For each character position in the filenames, if all selected files have the same character at that position, use that character in the pattern; otherwise, use '?'.
4. **Validation**: Check each non-selected file to see if it matches the constructed pattern. If any non-selected file matches, output "No"; otherwise, output "Yes" and the pattern.

### Solution Code

```python
n, m = map(int, input().split())
files = [input().strip() for _ in range(n)]
selected_indices = list(map(int, input().split()))

selected_files = [files[i-1] for i in selected_indices]

# Check if all selected files have the same length
lengths = {len(f) for f in selected_files}
if len(lengths) != 1:
    print("No")
else:
    pattern_length = lengths.pop()
    pattern = []
    for i in range(pattern_length):
        chars = [f[i] for f in selected_files]
        if all(c == chars[0] for c in chars):
            pattern.append(chars[0])
        else:
            pattern.append('?')
    pattern_str = ''.join(pattern)
    
    # Check non-selected files
    non_selected = [files[i] for i in range(n) if (i+1) not in selected_indices]
    valid = True
    for f in non_selected:
        if len(f) != pattern_length:
            continue
        match = True
        for p, c in zip(pattern_str, f):
            if p != '?' and p != c:
                match = False
                break
        if match:
            valid = False
            break
    if valid:
        print("Yes")
        print(pattern_str)
    else:
        print("No")
```

### Explanation

1. **Input Reading**: The input is read and parsed into the list of filenames and selected indices.
2. **Length Check**: The selected files are checked for consistent length. If they differ, it's impossible to form a valid pattern.
3. **Pattern Construction**: For each character position in the selected files, the pattern is built using the common character if all selected files agree, otherwise using '?'.
4. **Validation**: Each non-selected file is checked against the pattern. If any non-selected file matches the pattern, the solution is invalid. Otherwise, the pattern is valid and printed.

This approach ensures that the pattern matches exactly the selected files and excludes all others, efficiently solving the problem using systematic checks and pattern construction.
