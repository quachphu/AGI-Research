To solve this problem, we need to determine the maximum profit that can be earned by throwing a net once in a forest where beasts are positioned at specific points. The profit is calculated as the sum of the values of the captured beasts minus the cost of the net, which is the length of the interval covered by the net.

### Approach
1. **Problem Analysis**: The key challenge is to efficiently find the optimal interval [L, R] that maximizes the profit. The profit for an interval [L, R] is the sum of the values of the beasts in that interval minus the length of the interval (R - L). Given the constraints, a brute-force approach is infeasible, so we need an optimized solution.

2. **Key Insight**: For each beast at position `x_k`, we consider intervals ending at `x_k` and find the best starting point `x_j` such that the profit is maximized. This can be transformed into a problem of tracking the minimum value of a specific term as we iterate through the positions.

3. **Algorithm**:
   - **Prefix Sum Array**: Compute the cumulative sum of the values of the beasts up to each position.
   - **Tracking Minimum Value**: For each position, compute a term that allows us to track the minimum value encountered so far, which helps in determining the optimal starting point for the interval ending at the current position.

### Solution Code
```python
n = int(input())
x = []
s = []
for _ in range(n):
    xi, si = map(int, input().split())
    x.append(xi)
    s.append(si)

prefix_sum = [0] * (n + 1)
for i in range(n):
    prefix_sum[i + 1] = prefix_sum[i] + s[i]

max_profit = -float('inf')
current_min = float('inf')

for j in range(1, n + 1):
    a_j = prefix_sum[j - 1] - x[j - 1]
    current_min = min(current_min, a_j)
    current_profit = prefix_sum[j] - x[j - 1] - current_min
    if current_profit > max_profit:
        max_profit = current_profit

print(max_profit)
```

### Explanation
1. **Reading Input**: The input is read and stored in lists `x` (positions) and `s` (values of the beasts).

2. **Prefix Sum Calculation**: A prefix sum array `prefix_sum` is computed where each element at index `i` represents the sum of the values of the first `i` beasts. This helps in quickly calculating the sum of values for any interval.

3. **Tracking Minimum Value**: As we iterate through each position, we compute a term `a_j` which is the difference between the prefix sum up to the previous position and the current position. This term helps in tracking the minimum value encountered so far, which is crucial for determining the optimal starting point for the interval ending at the current position.

4. **Max Profit Calculation**: For each position, the profit is calculated using the prefix sum and the tracked minimum value. The maximum profit encountered during the iteration is updated accordingly.

This approach ensures that we efficiently compute the maximum possible profit in linear time, making it suitable for large input sizes as specified in the problem constraints.
