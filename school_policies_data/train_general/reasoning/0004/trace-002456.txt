To solve this problem, we need to determine the number of integer values \( x \) such that Petya can take exactly \( a \) chores with complexity greater than \( x \), and Vasya can take exactly \( b \) chores with complexity less than or equal to \( x \). 

### Approach
1. **Sort the Complexity List**: First, we sort the list of chore complexities in non-decreasing order. This helps us easily identify the threshold values where the split between Petya's and Vasya's chores can occur.
2. **Identify Threshold Values**: After sorting, the threshold \( x \) must be such that the first \( b \) elements (Vasya's chores) are less than or equal to \( x \), and the remaining \( a \) elements (Petya's chores) are greater than \( x \). This threshold is determined by the values at positions \( n-a-1 \) and \( n-a \) in the sorted list.
3. **Calculate Valid Range for \( x \)**: The valid integer values for \( x \) are those that lie between the maximum complexity of Vasya's chores and the minimum complexity of Petya's chores. The count of such values is given by the difference between these two values.

### Solution Code
```python
n, a, b = map(int, input().split())
h = list(map(int, input().split()))
h_sorted = sorted(h)
left = h_sorted[n - a - 1]
right = h_sorted[n - a]
print(max(0, right - left))
```

### Explanation
1. **Sorting**: By sorting the list of complexities, we can easily determine the boundary values that separate Vasya's and Petya's chores.
2. **Threshold Determination**: The threshold \( x \) must be at least the maximum value of the first \( b \) elements (Vasya's chores) and less than the minimum value of the remaining \( a \) elements (Petya's chores). These values are found at positions \( n-a-1 \) and \( n-a \) in the sorted list.
3. **Range Calculation**: The number of valid integer values for \( x \) is the difference between these two boundary values. If the boundary values are the same, there are no valid values for \( x \), hence the use of `max(0, right - left)` ensures non-negative results.

This approach efficiently determines the valid range for \( x \) using sorting and simple arithmetic, ensuring optimal performance even for the upper constraint limits.
