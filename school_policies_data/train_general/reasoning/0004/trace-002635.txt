To solve this problem, we need to determine the number of different triangles that satisfy specific conditions given a value T. The conditions are: each side of the triangle is a prime number, the sum of the three sides equals T, and the triangle must be valid (satisfy the triangle inequality). 

### Approach
1. **Prime Number Generation**: Use the Sieve of Eratosthenes to generate all prime numbers up to 30,000. This allows efficient prime checking and iteration.
2. **Precompute Valid Triangles**: For each possible triplet of primes (a, b, c) where a ≤ b ≤ c, check if they form a valid triangle (a + b > c) and their sum equals T. Precompute the count of such valid triangles for all possible values of T up to 30,000.
3. **Efficient Query Handling**: By precomputing the counts for all possible values of T, each query can be answered in constant time O(1).

### Solution Code
```python
import sys

def sieve(n):
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False
    for i in range(2, int(n ** 0.5) + 1):
        if is_prime[i]:
            for j in range(i * i, n + 1, i):
                is_prime[j] = False
    return is_prime

# Generate primes up to 30000
is_prime = sieve(30000)
primes = [i for i, prime in enumerate(is_prime) if prime]

# Precompute counts for each T from 0 to 30000
counts = [0] * 30001

for a in primes:
    a_idx = primes.index(a)
    for b in primes[a_idx:]:  # Ensure b >= a
        sum_ab = a + b
        # If sum_ab + b exceeds 30000, further b's will also do so, break
        if sum_ab > 30000 - b:
            break
        max_c1 = sum_ab - 1
        max_c2 = 30000 - sum_ab
        max_c = min(max_c1, max_c2)
        min_c = b  # since c >= b >= a
        if max_c < min_c:
            continue
        # Check all c in [min_c, max_c]
        for c in range(min_c, max_c + 1):
            if is_prime[c]:
                T = sum_ab + c
                if T <= 30000:
                    counts[T] += 1

# Process input and output
for line in sys.stdin:
    T = int(line.strip())
    if T == 0:
        break
    print(counts[T])
```

### Explanation
1. **Prime Generation**: The sieve function generates a boolean array where each index indicates whether the number is prime. This allows O(1) prime checks.
2. **Triple Iteration**: For each pair of primes (a, b) where a ≤ b, the code calculates possible values for c such that the sum a + b + c equals T. The valid range for c is determined by the triangle inequality and the maximum allowed value for T.
3. **Precomputation**: By iterating through all valid triples (a, b, c) and precomputing the count for each possible T, the solution efficiently handles each query in constant time.

This approach ensures that we efficiently count valid triangles during precomputation, allowing quick responses to each query by simply looking up the precomputed count.
