To solve this problem, we need to determine the minimum possible day Valera can take his last exam such that the recorded dates in his record book are in non-decreasing order. The key insight is that Valera can take each exam either on the scheduled day or an earlier day, and the order of exams must be such that their recorded dates (scheduled days) are non-decreasing.

### Approach
1. **Sort Exams by Scheduled Dates**: First, we sort the exams based on their scheduled dates (ai) to ensure that the recorded dates in the record book will be non-decreasing.
2. **Dynamic Programming (DP) Approach**: We use a dynamic programming approach to track the minimum possible day for the last exam. For each exam, we consider two possibilities: taking the exam on the early day (bi) or the scheduled day (ai). We maintain the minimum possible maximum day for each choice while ensuring that each subsequent exam is taken on or after the previous exam's day.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    exams = []
    for _ in range(n):
        a = int(input[idx])
        b = int(input[idx + 1])
        exams.append((a, b))
        idx += 2
    exams.sort()
    
    if n == 0:
        print(0)
        return
    
    INF = float('inf')
    prev_b_last = exams[0][1]
    prev_b_max = exams[0][1]
    prev_a_last = exams[0][0]
    prev_a_max = exams[0][0]
    
    for i in range(1, n):
        current_b = exams[i][1]
        current_a = exams[i][0]
        
        new_b_max = INF
        if prev_b_last <= current_b:
            new_b_max = max(prev_b_max, current_b)
        if prev_a_last <= current_b:
            candidate = max(prev_a_max, current_b)
            if candidate < new_b_max:
                new_b_max = candidate
        
        new_a_max = INF
        if prev_b_last <= current_a:
            candidate = max(prev_b_max, current_a)
            new_a_max = candidate
        if prev_a_last <= current_a:
            candidate = max(prev_a_max, current_a)
            if candidate < new_a_max:
                new_a_max = candidate
        
        prev_b_last = current_b
        prev_b_max = new_b_max
        prev_a_last = current_a
        prev_a_max = new_a_max
    
    result = min(prev_b_max, prev_a_max)
    print(result)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into a list of tuples representing each exam's scheduled day and early day.
2. **Sorting**: The exams are sorted by their scheduled day (ai) to ensure non-decreasing order of recorded dates.
3. **Dynamic Programming Initialization**: For the first exam, initialize the possible days (early and scheduled) and their corresponding maximum days.
4. **Iterating Through Exams**: For each subsequent exam, compute the minimum possible maximum day considering both taking the exam on its early day or scheduled day. This is done by checking valid transitions from the previous exam's choices and updating the current maximum day accordingly.
5. **Result Calculation**: The minimum possible day for the last exam is determined by taking the minimum of the two possible choices (early or scheduled) for the last exam.

This approach ensures that we efficiently track the optimal days for taking each exam while maintaining the non-decreasing order of recorded dates, leading to the minimum possible day for the last exam.
