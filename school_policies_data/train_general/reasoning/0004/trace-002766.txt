To solve this problem, we need to determine the number of valid ways to split problems into two divisions such that each division is non-empty, each problem is in exactly one division, all problems in division 1 are harder than those in division 2, and all similar problems are placed in different divisions.

### Approach
1. **Understanding the Split**: The problems are ordered by difficulty, so any valid split must have a cutoff point `k` where problems 1 to `k` go to division 2 and problems `k+1` to `n` go to division 1.
2. **Similar Pairs Constraint**: For each pair of similar problems (u, v), one must be in division 1 and the other in division 2. This means the cutoff `k` must be such that one of the pair is ≤ `k` and the other is > `k`.
3. **Interval Calculation**: For each similar pair (u, v), calculate the interval of valid `k` values. The valid interval for a pair (u, v) is from `min(u, v)` to `max(u, v) - 1`.
4. **Intersection of Intervals**: The valid `k` values must lie within the intersection of all intervals derived from the pairs. The result is the count of integers within this intersection that also lie between 1 and `n-1`.

### Solution Code
```python
n, m = map(int, input().split())
if m == 0:
    print(n - 1 if n >= 2 else 0)
else:
    max_L = 0
    min_R = float('inf')
    for _ in range(m):
        u, v = map(int, input().split())
        a = min(u, v)
        b = max(u, v)
        L_i = a
        R_i = b - 1
        if L_i > max_L:
            max_L = L_i
        if R_i < min_R:
            min_R = R_i
    if max_L > min_R:
        print(0)
    else:
        lower = max(max_L, 1)
        upper = min(min_R, n - 1)
        if lower > upper:
            print(0)
        else:
            print(upper - lower + 1)
```

### Explanation
1. **Reading Input**: The input is read, and if there are no similar pairs (`m = 0`), the number of valid splits is simply `n-1` since each possible cutoff `k` from 1 to `n-1` is valid.
2. **Processing Each Pair**: For each similar pair (u, v), compute the interval `[min(u, v), max(u, v) - 1]` which represents the valid range of `k` values for that pair.
3. **Intersection of Intervals**: The valid `k` values must lie in the intersection of all intervals. The maximum lower bound (`max_L`) and minimum upper bound (`min_R`) of these intervals are computed.
4. **Valid Range Check**: Check if the computed bounds are valid and adjust them to ensure they lie within the range [1, `n-1`]. The count of valid `k` values within this range is then calculated and printed.

This approach efficiently narrows down the valid cutoff points using interval intersections, ensuring optimal performance even for large input sizes.
