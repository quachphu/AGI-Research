To solve this problem, we need to determine if a given grid can be formed by stamping 3x3 crosses (without the center) on an initially empty grid. Each stamp covers 8 cells around its center. The solution involves checking if all '#' cells in the input grid can be covered by valid stamps and ensuring no '.' cells are covered by any stamps.

### Approach
1. **Identify Valid Stamps**: For each possible center of a 3x3 stamp, check if all 8 surrounding cells are '#'. If they are, this center is a valid candidate.
2. **Mark Covered Cells**: For each valid center, mark the 8 cells around it as covered.
3. **Validation**: Ensure every '#' cell in the input is covered by at least one valid stamp and no '.' cell is covered by any stamp.

### Solution Code
```python
n, m = map(int, input().split())
grid = [input().strip() for _ in range(n)]
covered = [[False for _ in range(m)] for _ in range(n)]

for x in range(1, n-1):
    for y in range(1, m-1):
        valid = True
        # Check all 8 surrounding cells
        for dx in (-1, 0, 1):
            for dy in (-1, 0, 1):
                if dx == 0 and dy == 0:
                    continue
                nx = x + dx
                ny = y + dy
                if nx < 0 or nx >= n or ny < 0 or ny >= m or grid[nx][ny] != '#':
                    valid = False
                    break
            if not valid:
                break
        if valid:
            # Mark the 8 cells around (x, y) as covered
            for dx in (-1, 0, 1):
                for dy in (-1, 0, 1):
                    if dx == 0 and dy == 0:
                        continue
                    nx = x + dx
                    ny = y + dy
                    covered[nx][ny] = True

# Check all cells
possible = True
for i in range(n):
    for j in range(m):
        if grid[i][j] == '#' and not covered[i][j]:
            possible = False
        if grid[i][j] == '.' and covered[i][j]:
            possible = False

print("YES" if possible else "NO")
```

### Explanation
1. **Reading Input**: The grid dimensions and the grid itself are read.
2. **Valid Stamps Check**: For each potential center (x, y), check if all 8 surrounding cells are '#'. If they are, mark these cells as covered.
3. **Validation Check**: After marking all covered cells, verify that every '#' cell is covered and no '.' cell is covered. If both conditions are met, the answer is "YES"; otherwise, "NO".

This approach efficiently checks the validity of the grid configuration by ensuring all necessary cells are covered by valid stamps and no invalid cells are touched, thus solving the problem in O(n*m) time complexity.
