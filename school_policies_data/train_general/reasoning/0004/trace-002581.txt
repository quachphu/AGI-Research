To solve this problem, we need to determine the coordinates of the remaining two vertices of a square given two adjacent vertices in counter-clockwise order. The key insight is to use vector rotation to find the direction of the next edges of the square.

### Approach
1. **Vector Calculation**: Compute the vector from the first given vertex to the second vertex.
2. **Rotation**: Rotate this vector 90 degrees counter-clockwise to find the direction of the next edge.
3. **Vertex Calculation**: Use the rotated vectors to compute the coordinates of the remaining vertices.

### Solution Code
```python
def main():
    x1, y1, x2, y2 = map(int, input().split())
    dx = x2 - x1
    dy = y2 - y1
    x3 = x2 - dy
    y3 = y2 + dx
    x4 = x3 - dx
    y4 = y3 - dy
    print(x3, y3, x4, y4)

main()
```

### Explanation
1. **Vector Calculation**: The vector from the first vertex (x1, y1) to the second vertex (x2, y2) is computed as (dx, dy) = (x2 - x1, y2 - y1).
2. **Rotation**: Rotating this vector 90 degrees counter-clockwise gives a new vector (-dy, dx). This new vector helps determine the direction from the second vertex to the third vertex.
3. **Third Vertex (x3, y3)**: Using the rotated vector, the third vertex is found by adding (-dy, dx) to the second vertex (x2, y2).
4. **Fourth Vertex (x4, y4)**: The fourth vertex is determined by moving from the third vertex in the direction opposite to the original vector (dx, dy), which is done by subtracting dx and dy from the third vertex coordinates.

This approach efficiently computes the remaining vertices using vector rotations, ensuring the solution is both optimal and easy to understand.
