2. **Track Minimum Values and Indices**: As we generate each array, we track the minimum values, their indices, and the second minimum values. This helps in efficiently determining the smallest possible sum of elements from different indices.
3. **Check Possible Pairs**: After determining the minimum and second minimum values and their indices for both arrays, we check all valid pairs to find the minimum sum where indices are different.

def main():
    MOD = 10**9 + 7
    a, b, c = map(int, sys.stdin.readline().split())
    N = int(sys.stdin.readline())

    minB_val = current
    first_minB_idx = 1
    countB = 1
    second_minB_val = float('inf')
