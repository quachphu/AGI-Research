To solve this problem, we need to determine Manny's password from a list of possible passwords. The password must be such that both the password itself and its reverse are present in the list. Additionally, we need to find the length of the password and its middle character.

### Approach
1. **Read Input**: Read the number of passwords and the passwords themselves from standard input.
2. **Store Passwords**: Use a set to store the passwords for efficient lookups.
3. **Check Each Password**: For each password in the list, check if its reverse is also present in the set.
4. **Determine Result**: Once a valid password is found (one whose reverse is in the set), compute its length and middle character. The middle character of a string with odd length is found at index `length // 2`.

### Solution Code
```python
def find_password():
    import sys
    n = int(sys.stdin.readline())
    passwords = [sys.stdin.readline().strip() for _ in range(n)]
    password_set = set(passwords)
    for word in passwords:
        reversed_word = word[::-1]
        if reversed_word in password_set:
            length = len(word)
            mid_index = length // 2
            print(f"{length} {word[mid_index]}")
            return
find_password()
```

### Explanation
1. **Reading Input**: The function reads the number of passwords and then each password into a list.
2. **Set for Lookups**: A set is used to store all passwords, allowing O(1) time complexity for checking the presence of reversed passwords.
3. **Reverse Check**: For each password, the code checks if its reverse exists in the set. If found, it immediately computes the length and middle character, prints the result, and exits the function.
4. **Efficiency**: The solution efficiently checks each password exactly once and uses a set for quick lookups, ensuring the solution is found in linear time relative to the number of passwords, O(N).

This approach ensures that we efficiently determine the correct password and its characteristics as required by the problem constraints.
