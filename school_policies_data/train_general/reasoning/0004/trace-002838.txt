To solve this problem, we need to find the nearest number greater than or equal to a given integer `a` such that the sum of its digits is divisible by 4. This number is considered "interesting" according to the problem's definition. 

### Approach
1. **Understanding the Problem**: We need to check each number starting from `a` and moving upwards to determine if the sum of its digits is divisible by 4. The first number that meets this criterion is our answer.
2. **Sum of Digits Calculation**: For each number, convert it to a string, iterate through each character (digit), convert it back to an integer, and sum these integers.
3. **Check Divisibility**: For each number starting from `a`, check if the sum of its digits is divisible by 4. If it is, this number is our answer; otherwise, move to the next number.

### Solution Code
```python
def find_interesting():
    a = int(input())
    n = a
    while True:
        s = sum(int(d) for d in str(n))
        if s % 4 == 0:
            print(n)
            return
        n += 1

find_interesting()
```

### Explanation
1. **Reading Input**: The function reads the input integer `a`.
2. **Initialization**: Start checking from `a` itself.
3. **Loop Until Found**: Use a while loop to check each subsequent number. For each number `n`:
   - Calculate the sum of its digits.
   - Check if this sum is divisible by 4.
   - If it is, print `n` and exit the loop; otherwise, increment `n` and repeat.

This approach efficiently finds the nearest interesting number by leveraging a straightforward brute-force method, which is feasible given the constraint that `a` is at most 1000. The solution ensures minimal computational overhead by checking each number sequentially until the condition is met.
