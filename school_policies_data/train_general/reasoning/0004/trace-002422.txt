To solve this problem, we need to determine the minimum number of moves required to move all stones on an N x N board to any of the four corners. Each stone can be moved up, down, left, or right, and different stones can be moved to different corners. The goal is to minimize the total number of moves.

### Approach
1. **Understanding Movement**: Each stone can move to one of the four corners of the board. The corners are (1,1), (1,N), (N,1), and (N,N).
2. **Manhattan Distance**: The number of moves required to move a stone from position (x, y) to a corner (a, b) is given by the Manhattan distance, which is |x - a| + |y - b|.
3. **Optimal Corner Selection**: For each stone, compute the Manhattan distance to each of the four corners and select the minimum distance. Sum these minimum distances for all stones to get the total minimum moves.

### Solution Code
```python
import sys

def main():
    n, k = map(int, sys.stdin.readline().split())
    x = list(map(int, sys.stdin.readline().split()))
    y = list(map(int, sys.stdin.readline().split()))
    total = 0
    for xi, yi in zip(x, y):
        d1 = (xi - 1) + (yi - 1)
        d2 = (xi - 1) + (n - yi)
        d3 = (n - xi) + (yi - 1)
        d4 = (n - xi) + (n - yi)
        min_d = min(d1, d2, d3, d4)
        total += min_d
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of the board size (N), number of stones (K), and the coordinates of each stone. These are read using efficient input handling methods.
2. **Distance Calculation**: For each stone, compute the Manhattan distance to each of the four corners. The minimum of these four distances is added to the total moves.
3. **Summing Moves**: The total moves required are the sum of the minimum distances for all stones, ensuring the solution is optimal and efficient.

This approach ensures that each stone is moved to the closest corner in terms of moves, resulting in the minimum total moves required. The algorithm runs in O(K) time, making it efficient even for the upper constraint limits.
