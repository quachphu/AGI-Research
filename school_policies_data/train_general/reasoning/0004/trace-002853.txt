To solve this problem, we need to determine if a given number is a "nearly awesome" number. A number is considered nearly awesome if the count of its awesome digits (4 and 7) forms an awesome number. An awesome number is a positive integer composed exclusively of the digits 4 and 7.

### Approach
1. **Input Handling**: Read the number of test cases and each number as a string to efficiently handle very large numbers.
2. **Counting Awesome Digits**: For each number, count how many of its digits are 4 or 7.
3. **Check for Awesome Number**: Convert the count of awesome digits to a string and check if all its digits are either 4 or 7. If they are, the count is an awesome number, making the original number nearly awesome.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        n_str = input[i]
        count = 0
        for ch in n_str:
            if ch in {'4', '7'}:
                count += 1
        if is_awesome(count):
            print("YES")
        else:
            print("NO")

def is_awesome(c):
    if c == 0:
        return False
    s = str(c)
    for ch in s:
        if ch not in {'4', '7'}:
            return False
    return True

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings. The first element is the number of test cases, followed by the numbers to check.
2. **Digit Counting**: For each number, iterate through each digit and count how many are 4 or 7.
3. **Check Awesome Number**: Convert the count to a string and check each digit to ensure they are either 4 or 7. If all digits meet this criterion, the count is an awesome number, and we print "YES"; otherwise, we print "NO".

This approach efficiently handles large numbers by treating them as strings and ensures correctness by methodically checking each digit of the count of awesome digits.
