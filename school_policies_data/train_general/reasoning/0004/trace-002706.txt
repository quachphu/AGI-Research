To solve this problem, we need to find the maximum sub-rectangle on a grid that contains a given point (x, y) and has an exact aspect ratio (a, b). The solution must also handle tie-breakers by selecting the closest rectangle to the given point and choosing the lexicographically smallest option if there are still ties.

### Approach
1. **Aspect Ratio Simplification**: Simplify the given aspect ratio (a, b) by dividing both values by their greatest common divisor (GCD). This reduces the problem to finding the largest possible dimensions that maintain the simplified ratio.
2. **Determine Maximum Dimensions**: Calculate the maximum possible dimensions (width and height) that fit within the grid while maintaining the simplified aspect ratio.
3. **Optimal Positioning**: Determine the optimal position for the rectangle such that it contains the given point (x, y) and is as close as possible to the center of (x, y). This involves checking possible positions around the point and selecting the closest one based on Euclidean distance, with tie-breakers handled by lexicographical order.

### Solution Code
```python
import math

def main():
    import sys
    n, m, x, y, a, b = map(int, sys.stdin.readline().split())
    
    # Compute the reduced form of a and b
    g = math.gcd(a, b)
    a_reduced = a // g
    b_reduced = b // g
    
    # Calculate the maximum possible k
    k = min(n // a_reduced, m // b_reduced)
    w = a_reduced * k
    h = b_reduced * k
    
    # Function to find the best position for a given coordinate and size
    def find_position(c, limit, size):
        low = max(0, c - size)
        high = min(c, limit - size)
        if low > high:
            return 0  # Should not occur as k is valid
        
        ideal = c - size / 2.0
        candidates = []
        floor_candidate = math.floor(ideal)
        ceil_candidate = math.ceil(ideal)
        candidates.extend([floor_candidate, ceil_candidate, low, high])
        
        # Filter valid candidates within the [low, high] range
        valid_candidates = [cand for cand in candidates if low <= cand <= high]
        if not valid_candidates:
            return low  # Fallback, though theoretically should not happen
        
        # Find the candidate with minimum distance, preferring smaller on tie
        best_candidate = valid_candidates[0]
        best_distance = abs((best_candidate + size / 2.0) - c)
        for cand in valid_candidates[1:]:
            current_distance = abs((cand + size / 2.0) - c)
            if current_distance < best_distance or (current_distance == best_distance and cand < best_candidate):
                best_candidate = cand
                best_distance = current_distance
        return best_candidate
    
    x1 = find_position(x, n, w)
    y1 = find_position(y, m, h)
    
    x2 = x1 + w
    y2 = y1 + h
    
    print(x1, y1, x2, y2)

if __name__ == "__main__":
    main()
```

2. **Maximizing Dimensions**: The maximum possible dimensions (width and height) are determined by finding the largest integer multiple of the simplified aspect ratio that fits within the grid boundaries.
3. **Positioning the Rectangle**: The rectangle is positioned such that it contains the point (x, y) and is centered as close as possible to (x, y). This is done by evaluating potential positions around the point and selecting the one that minimizes the Euclidean distance to the center of the rectangle. If there are ties, the lexicographically smallest position is chosen.
