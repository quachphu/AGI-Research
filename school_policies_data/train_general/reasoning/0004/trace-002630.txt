To solve this problem, we need to determine the maximum score Takahashi can achieve in the RPS Battle game, considering the constraints that he cannot use the same hand in consecutive rounds spaced K apart. The solution involves breaking down the problem into manageable parts and using dynamic programming to optimize the score calculation for each group of rounds.

### Approach
1. **Grouping Rounds**: Split the rounds into K groups based on their indices modulo K. Each group will contain rounds that are K indices apart. This ensures that the constraint of not using the same hand in consecutive rounds within the same group is handled correctly.
2. **Dynamic Programming for Each Group**: For each group, use dynamic programming to calculate the maximum score possible. Track two states for each position in the group:
   - `same`: The maximum score if the last move used is the current required winning move.
   - `diff`: The maximum score if the last move used is not the current required winning move.
3. **Transition Between States**: For each round in the group, update the states based on whether the current required move is the same as the previous move or not. This ensures that we avoid consecutive use of the same hand while maximizing the score.

### Solution Code
```python
n, k = map(int, input().split())
r, s, p = map(int, input().split())
t = input().strip()

# Mapping from machine's move to (player's winning move, points)
move_map = {
    'r': ('p', p),
    's': ('r', r),
    'p': ('s', s)
}

# Split into K groups
groups = [[] for _ in range(k)]
for i in range(n):
    group_idx = i % k
    machine_move = t[i]
    player_move, point = move_map[machine_move]
    groups[group_idx].append((player_move, point))

total_score = 0

for group in groups:
    if not group:
        continue
    # Initialize DP variables
    same = 0  # last move is current required move
    diff = 0   # last move is not current required move
    prev_move = None  # track the previous move in the group
    
    for idx, (current_move, point) in enumerate(group):
        if idx == 0:
            same = point
            diff = 0
            prev_move = current_move
        else:
            if current_move == prev_move:
                new_same = diff + point
                new_diff = max(same, diff)
            else:
                new_same = max(same, diff) + point
                new_diff = max(same, diff)
            same, diff = new_same, new_diff
            prev_move = current_move
    # Add the maximum of the two states for the group
    total_score += max(same, diff)

print(total_score)
```

### Explanation
1. **Grouping Rounds**: The rounds are divided into K groups where each group contains rounds that are K indices apart. This ensures that the constraint of not using the same hand in consecutive rounds within the same group is maintained.
2. **Dynamic Programming**: For each group, we track two states to determine the maximum score. The `same` state represents the maximum score if the last move used is the current required winning move, and the `diff` state represents the maximum score if the last move used is different. This allows us to handle transitions where consecutive moves cannot be the same.
3. **Efficient Calculation**: By iterating through each group and updating the states based on the current and previous moves, we efficiently compute the maximum score without violating the constraints. The solution ensures that we maximize the score by considering all valid transitions between states.

This approach efficiently handles the constraints and optimizes the score calculation, ensuring that the solution runs in O(N) time, which is suitable for the problem's constraints.
