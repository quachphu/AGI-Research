To solve this problem, we need to determine the minimum number of shelves required to place a set of books according to specific rules. Each shelf can hold a maximum of 10 books, and books with titles starting with different letters cannot be placed on the same shelf.

### Approach
1. **Group Books by First Letter**: First, we count the number of books starting with each letter. This helps us understand how many books need to be grouped together.
2. **Calculate Shelves per Group**: For each group of books starting with the same letter, we calculate the number of shelves required. This is done by dividing the count of books by 10 and taking the ceiling of the result. The ceiling can be efficiently computed using integer arithmetic as `(count + 9) // 10`.
3. **Sum the Shelves**: Sum the number of shelves required for each group to get the total minimum number of shelves needed.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n = int(sys.stdin.readline())
    counts = defaultdict(int)
    for _ in range(n):
        title = sys.stdin.readline().strip()
        first_char = title[0]
        counts[first_char] += 1
    
    total_shelves = 0
    for count in counts.values():
        total_shelves += (count + 9) // 10  # Equivalent to ceiling division by 10
    
    print(total_shelves)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of an integer `N` followed by `N` book titles. We read these titles and extract the first character of each title.
2. **Counting First Characters**: Using a dictionary, we count how many books start with each letter.
3. **Calculating Shelves**: For each letter group, we compute the number of shelves required by dividing the count of books by 10 and taking the ceiling of the result. This is efficiently done using integer arithmetic.
4. **Summing Shelves**: We sum the shelves required for all groups to get the total minimum number of shelves needed.

This approach ensures that we efficiently and correctly determine the minimum number of shelves required while adhering to the constraints provided.
