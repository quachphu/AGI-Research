To solve this problem, we need to determine how many songs are played before Jack reaches the end of the dance floor. Each song, Jack jumps forward a fixed number of steps and then is pushed back by a smaller number of steps. The key is to count each song started, even if Jack reaches the end during that song.

### Approach
1. **Immediate Check**: If the number of steps Jack jumps in one song (X) is greater than or equal to the length of the dance floor (L), Jack will reach the end in the first song itself. Thus, the answer is 1.
2. **Mathematical Calculation**: For cases where X is less than L, we need to compute how many full cycles (each cycle consisting of a jump and a push back) Jack can make before the next jump would take him past the end of the dance floor. This is done using integer division to determine the number of cycles (k) required. The total number of songs is then k + 1, accounting for the final jump.

### Solution Code
```python
def main():
    import sys
    L, X, Y = map(int, sys.stdin.readline().split())
    if X >= L:
        print(1)
    else:
        k = (L - Y - 1) // (X - Y)
        print(k + 1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Immediate Check**: If Jack's jump (X) is sufficient to reach or exceed the dance floor length (L) in one move, the answer is 1.
2. **Cycle Calculation**: When X is less than L, we calculate the number of cycles (k) needed such that after each cycle, Jack's position increases by (X - Y). The formula `(L - Y - 1) // (X - Y)` gives the number of full cycles before the next jump would take Jack past L. Adding 1 to this result gives the total number of songs, including the final jump that reaches or exceeds L.

This approach efficiently computes the result using integer arithmetic, ensuring it works even for very large values of L, X, and Y within the problem constraints.
