To solve this problem, we need to efficiently compute the sum of floor values for multiple test cases. Given the constraints, a brute-force approach is infeasible, so we use a mathematical approach inspired by the Euclidean algorithm to reduce the problem size iteratively.

### Approach
The key insight is to transform the problem into a recursive structure where each step reduces the parameters using properties similar to the Euclidean algorithm. This allows us to compute the sum in logarithmic time relative to the input size. The steps are as follows:

1. **Base Case Handling**: If the coefficient of the linear term (A) is zero or the number of terms (N) is zero, the sum is straightforward to compute.
2. **Recursive Transformation**: For each step, compute the quotient and remainder terms, then transform the problem into a smaller instance by swapping and reducing parameters. This transformation leverages the properties of the floor function and integer division to break down the problem.

### Solution Code
```python
import sys

def compute_sum(n, m, a, b):
    res = 0
    sign = 1
    while True:
        if a == 0 or n == 0:
            res += sign * (b // m) * n
            break
        q = (a * (n - 1) + b) // m
        term = q * n
        res += sign * term
        # Prepare for next iteration
        new_a = m
        new_m = a
        new_n = q
        new_b = new_a + new_m - b - 1
        a, m, b, n = new_a, new_m, new_b, new_n
        sign *= -1
    return res

def main():
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N = int(input[idx])
        M = int(input[idx + 1])
        A = int(input[idx + 2])
        B = int(input[idx + 3])
        idx += 4
        print(compute_sum(N, M, A, B))

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the large number of test cases.
2. **Iterative Calculation**: The `compute_sum` function iteratively processes each test case by breaking down the problem using properties of integer division and modular arithmetic. Each iteration reduces the problem size, similar to the Euclidean algorithm, ensuring logarithmic time complexity.
3. **Sign Handling**: The sign alternates with each transformation to account for the subtraction in the recursive formula, ensuring the correct cumulative result.

This approach efficiently handles the large constraints by reducing the problem size in each iteration, leading to an optimal solution suitable for the given input limits.
