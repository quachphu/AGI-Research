To solve this problem, we need to determine the minimum time required for all customers seated around a round table to finish ordering their meals, given that each customer who receives a menu starts ordering and then passes the menu to the next customer. The solution involves distributing M menus optimally to minimize the maximum time taken by any customer to finish their order.

### Approach
1. **Problem Analysis**: The problem can be translated into finding the minimum possible maximum time required for all customers to finish ordering. Each customer starts ordering when they receive a menu and passes it to the next customer once done. This can be modeled as splitting the array of customer order times into M contiguous segments such that the maximum sum of any segment is minimized.

2. **Binary Search**: We use binary search to efficiently determine the minimum possible maximum time. The search range is between the maximum order time (when each customer has their own menu) and the total sum of all order times (when only one menu is used).

3. **Greedy Check Function**: For each candidate maximum time during the binary search, we check if it's possible to split the array into M segments where each segment's sum does not exceed the candidate time. This is done using a greedy approach to count the minimum number of segments required.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    M = int(input[idx])
    idx += 1
    L = list(map(int, input[idx:idx+N]))
    
    left = max(L)
    right = sum(L)
    result = right
    
    def is_possible(T):
        count = 1
        current_sum = 0
        for num in L:
            if current_sum + num > T:
                count += 1
                current_sum = num
                if num > T:
                    return False
            else:
                current_sum += num
        return count <= M
    
    while left <= right:
        mid = (left + right) // 2
        if is_possible(mid):
            result = mid
            right = mid - 1
        else:
            left = mid + 1
    print(result)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of customers (N), the number of menus (M), and the list of order times (L).

2. **Binary Search Initialization**: The search range is initialized with `left` as the maximum order time (minimum possible time when each customer has a menu) and `right` as the total sum of all order times (maximum possible time when only one menu is used).

3. **Greedy Check Function**: The `is_possible` function checks if a given candidate maximum time (T) can be achieved by splitting the array into M or fewer segments. It iterates through the list, accumulating order times, and splits the segment when the accumulated time exceeds T.

4. **Binary Search Execution**: The binary search adjusts the candidate time (mid) based on whether the current candidate is feasible. The result is updated whenever a feasible candidate is found, narrowing down the search until the optimal solution is found.

This approach efficiently narrows down the possible maximum time using binary search combined with a greedy check, ensuring an optimal solution with a time complexity of O(N log S), where S is the sum of the order times.
