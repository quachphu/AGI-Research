To solve this problem, we need to determine the maximum frequency of names in a given list and compute the sum of all such maximum frequencies if they occur more than once. 

### Approach
1. **Read Input:** Read the number of names and the names themselves.
2. **Count Frequencies:** Use a dictionary to count the occurrences of each name.
3. **Determine Maximum Frequency:** Find the highest frequency from the counted values.
4. **Count Occurrences of Maximum Frequency:** Check how many times this maximum frequency occurs among the names.
5. **Calculate Result:** Multiply the maximum frequency by the number of times it occurs to get the required sum.

### Solution Code
```python
import sys
from collections import Counter

def main():
    t = int(sys.stdin.readline())
    names = [sys.stdin.readline().strip() for _ in range(t)]
    counts = Counter(names)
    frequencies = counts.values()
    max_freq = max(frequencies)
    count_max = sum(1 for f in frequencies if f == max_freq)
    print(max_freq * count_max)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The input is read efficiently using `sys.stdin` to handle large input sizes. The number of names `t` is read first, followed by reading each name into a list.
2. **Counting Frequencies:** Using `collections.Counter`, we count how many times each name appears. This provides a dictionary where keys are names and values are their respective counts.
3. **Finding Maximum Frequency:** The maximum value from the counts is determined using the `max` function.
4. **Counting Maximum Frequency Occurrences:** We iterate over the frequency values to count how many times the maximum frequency occurs using a generator expression for memory efficiency.
5. **Computing Result:** The result is the product of the maximum frequency and the number of times it occurs, which is printed as the final output.

This approach ensures efficient handling of up to 100,000 names with optimal memory usage and linear time complexity, making it suitable for large input sizes.
