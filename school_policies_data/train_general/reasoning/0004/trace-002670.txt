To solve this problem, we need to identify applicants who have registered more than once using different email IDs. The goal is to determine the number of such illegal applicants and list their names in the order of their first occurrence.

### Approach
1. **Read Input**: First, we read the number of applicants and their names from the input.
2. **Track Occurrences**: We use a dictionary to count the occurrences of each name and a list to maintain the order of their first appearance.
3. **Identify Illegal Applicants**: By iterating through the list of names in their first occurrence order, we check if any name appears more than once using the counts from the dictionary.
4. **Output Results**: Finally, we print the count of illegal applicants followed by their names in the order they first appeared.

### Solution Code
```python
def main():
    n = int(input())
    names = [input().strip() for _ in range(n)]
    
    counts = {}
    order = []
    
    for name in names:
        if name not in counts:
            counts[name] = 1
            order.append(name)
        else:
            counts[name] += 1
    
    illegals = [name for name in order if counts[name] >= 2]
    
    print(len(illegals))
    for name in illegals:
        print(name)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read line by line, with the first line giving the number of applicants and subsequent lines providing their names.
2. **Tracking Occurrences**: Using a dictionary (`counts`), we keep track of how many times each name appears. The `order` list ensures we remember the sequence in which names first appear.
3. **Identifying Illegal Applicants**: By iterating through the `order` list, we check which names have a count of 2 or more, indicating they are repeated.
4. **Output**: The number of illegal applicants is printed first, followed by each of their names in the order they were first encountered.

This approach efficiently tracks the necessary information in linear time, ensuring optimal performance given the constraints.
