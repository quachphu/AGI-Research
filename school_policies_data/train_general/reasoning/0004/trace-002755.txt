To solve this problem, we need to determine the maximum number of celebrities a paparazzi can photograph given their positions and times of appearance in Manhattan. The paparazzi starts at the intersection (1, 1) and can only take a photo if they are at the exact intersection at the exact time a celebrity appears.

### Approach
1. **Dynamic Programming (DP) Setup**: Use a DP array where `dp[i]` represents the maximum number of photos that can be taken up to and including the i-th celebrity.
2. **Initial Position Check**: Check if the paparazzi can reach the celebrity directly from the starting position (1, 1).
3. **Global Maximum Check**: Use a prefix maximum array to track the maximum number of photos that can be taken up to any given celebrity, allowing efficient look-up for celebrities that are far enough in time.
4. **Near Check**: For celebrities that are close in time, check each previous celebrity within a feasible time window to see if the paparazzi can move from one to the other in time.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    r = int(input[ptr])
    ptr += 1
    n = int(input[ptr])
    ptr += 1

    t_list = []
    x_list = []
    y_list = []

    for _ in range(n):
        t = int(input[ptr])
        ptr += 1
        x = int(input[ptr])
        ptr += 1
        y = int(input[ptr])
        ptr += 1
        t_list.append(t)
        x_list.append(x)
        y_list.append(y)

    D_max = 2 * (r - 1)
    dp = [0] * n
    prefix_max = [0] * n

    for i in range(n):
        current_t = t_list[i]
        current_x = x_list[i]
        current_y = y_list[i]

        max_val = 0

        # Option 1: Start from initial position
        distance_initial = (current_x - 1) + (current_y - 1)
        if current_t >= distance_initial:
            max_val = 1

        # Option 2: Use global max (prefix_max[j_max])
        threshold = current_t - D_max
        j_max = bisect.bisect_right(t_list, threshold, 0, i) - 1
        if j_max >= 0:
            candidate = prefix_max[j_max] + 1
            if candidate > max_val:
                max_val = candidate

        # Option 3: Check near j's
        lower = current_t - D_max + 1
        a = bisect.bisect_left(t_list, lower, 0, i)
        for j in range(a, i):
            if dp[j] == 0:
                continue  # Skip unreachable j
            time_diff = current_t - t_list[j]
            distance = abs(current_x - x_list[j]) + abs(current_y - y_list[j])
            if time_diff >= distance:
                if dp[j] + 1 > max_val:
                    max_val = dp[j] + 1

        dp[i] = max_val
        if i == 0:
            prefix_max[i] = max_val
        else:
            prefix_max[i] = max(prefix_max[i-1], max_val)

    print(max(dp))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and stored in lists for times, x-coordinates, and y-coordinates of each celebrity.
2. **Dynamic Programming Array**: `dp[i]` keeps track of the maximum photos taken up to the i-th celebrity.
3. **Initial Position Check**: Directly checks if the paparazzi can reach the celebrity from the starting point in time.
4. **Global Maximum Check**: Uses a prefix maximum array to quickly find the maximum number of photos possible from celebrities that are far enough in time.
5. **Near Check**: For each celebrity, checks recent previous celebrities within a feasible time window to see if moving from one to the other is possible, considering only reachable positions (where `dp[j] > 0`).

This approach ensures that we efficiently check both far and recent celebrities, optimizing the solution to handle up to 100,000 celebrities within feasible time limits.
