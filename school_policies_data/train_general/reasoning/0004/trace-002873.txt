To solve this problem, we need to minimize the total debt by consolidating debts using two specific operations. The key insight is that the optimal solution involves converting as many debts as possible into self-debts (which can then be eliminated) and restructuring the remaining debts efficiently.

### Approach
1. **Debt Calculation**: For each person, calculate their net debt, which is the difference between the total amount they owe others and the total amount others owe them.
2. **Self-Debt Conversion**: Convert as much of each person's debt into self-debts as possible. This is done by taking the minimum of the total amount they owe and the total amount owed to them.
3. **Debt Restructuring**: After eliminating self-debts, restructure the remaining debts such that each person either becomes a net borrower or a net lender. This involves pairing net borrowers with net lenders to form direct debts.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    m = int(input[ptr])
    ptr += 1

    sum_out = [0] * (n + 1)
    sum_in = [0] * (n + 1)

    for _ in range(m):
        u = int(input[ptr])
        ptr += 1
        v = int(input[ptr])
        ptr += 1
        d = int(input[ptr])
        ptr += 1
        sum_out[u] += d
        sum_in[v] += d

    positives = []
    negatives = []

    for a in range(1, n + 1):
        net = sum_out[a] - sum_in[a]
        if net > 0:
            positives.append((a, net))
        elif net < 0:
            negatives.append((a, -net))

    edges = []
    i = j = 0
    while i < len(positives) and j < len(negatives):
        a, pa = positives[i]
        b, pb = negatives[j]
        amount = min(pa, pb)
        edges.append((a, b, amount))
        pa -= amount
        pb -= amount
        if pa == 0:
            i += 1
        else:
            positives[i] = (a, pa)
        if pb == 0:
            j += 1
        else:
            negatives[j] = (b, pb)

    print(len(edges))
    for u, v, d in edges:
        print(u, v, d)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed to extract the number of people and debts.
2. **Summing Debts**: For each person, we calculate the total amount they owe (`sum_out`) and the total amount owed to them (`sum_in`).
3. **Net Debt Calculation**: For each person, compute their net debt. If the net debt is positive, they are a net borrower; if negative, they are a net lender.
4. **Pairing Borrowers and Lenders**: Using a two-pointer technique, we pair each net borrower with a net lender, transferring the maximum possible debt between them. This continues until all debts are restructured into direct obligations between individuals.
5. **Output**: The restructured debts are printed, ensuring each pair of individuals has at most one debt entry.

This approach efficiently minimizes the total debt by leveraging the operations allowed, ensuring optimal consolidation and elimination of self-debts.
