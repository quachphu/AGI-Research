To solve this problem, we need to determine the final string displayed in a text editor after a series of keystrokes. The keystrokes include inserting '0', inserting '1', and backspacing. The challenge is to simulate these operations efficiently and accurately.

### Approach
1. **Simulation of Keystrokes**: We simulate each keystroke step by step using a list to dynamically build and modify the string.
2. **Efficient Operations**: Using a list allows efficient append and pop operations (both O(1) time complexity), which is optimal given the constraints.
3. **Handling Backspaces**: When encountering a backspace ('B'), we check if the list is non-empty before removing the last character to avoid errors.

### Solution Code
```python
def main():
    s = input().strip()
    result = []
    for c in s:
        if c == 'B':
            if result:
                result.pop()
        else:
            result.append(c)
    print(''.join(result))

main()
```

### Explanation
1. **Reading Input**: The input string `s` is read from standard input.
2. **Initialization**: An empty list `result` is initialized to keep track of the current state of the text editor.
3. **Processing Each Character**:
   - For each character in `s`, if it is '0' or '1', append it to the list.
   - If the character is 'B', check if the list is non-empty. If it is, remove the last character from the list.
4. **Output the Result**: After processing all characters, the list is converted to a string and printed as the final result.

This approach efficiently handles all keystrokes and ensures the correct final string is produced, adhering to the problem constraints and requirements.
