To solve this problem, we need to determine the maximum profit that can be obtained from foreign exchange margin transactions given a sequence of currency values. The goal is to find the maximum value of \( R_j - R_i \) where \( j > i \).

### Approach
The key insight to solve this problem efficiently is to track the minimum currency value encountered so far as we iterate through the list. For each subsequent value, we calculate the potential profit by subtracting the minimum value encountered so far from the current value. This allows us to keep track of the maximum profit in a single pass through the list, resulting in an optimal time complexity of \( O(n) \).

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    R = [int(sys.stdin.readline()) for _ in range(n)]
    
    min_so_far = R[0]
    max_profit = -float('inf')
    
    for j in range(1, n):
        current_price = R[j]
        current_profit = current_price - min_so_far
        if current_profit > max_profit:
            max_profit = current_profit
        if current_price < min_so_far:
            min_so_far = current_price
    
    print(max_profit)

main()
```

### Explanation
1. **Reading Input:** The input is read using `sys.stdin.readline()` for efficiency, especially given the constraints where the number of values can be very large (up to 200,000).
2. **Initialization:** We start by initializing `min_so_far` to the first currency value and `max_profit` to negative infinity to handle cases where all potential profits are negative.
3. **Iterating Through Values:** For each subsequent value in the list:
   - Calculate the potential profit by subtracting the minimum value encountered so far (`min_so_far`) from the current value.
   - Update `max_profit` if the current profit is greater than the previously recorded maximum profit.
   - Update `min_so_far` if the current value is lower than the previously recorded minimum.
4. **Output the Result:** After processing all values, the maximum profit is printed. If all potential profits are negative, the result will be the least negative value, which is handled correctly by the initialization and update logic.

This approach ensures that we efficiently compute the maximum profit in linear time, making it suitable for large input sizes as specified in the problem constraints.
