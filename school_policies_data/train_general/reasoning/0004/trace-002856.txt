To solve this problem, we need to determine the maximum number of socks Tom must draw from his drawer in the worst-case scenario to find a matching pair. Each test case provides the number of pairs of socks in the drawer, and we need to compute the answer for each case efficiently.

### Approach
The problem can be broken down into understanding the worst-case scenario for drawing socks. If there are `N` pairs of socks, each pair being a different color, the worst-case scenario involves drawing one sock of each color before drawing a second sock of any color, which will form a pair. 

The key insight here is that if there are `N` pairs, there are `N` different colors. In the worst case, Tom will draw one sock of each color, resulting in `N` socks. The next sock drawn must match one of the previously drawn colors, thus forming a pair. Therefore, the total number of draws required in the worst case is `N + 1`.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        print(n + 1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of multiple test cases. The first line gives the number of test cases `T`.
2. **Processing Each Test Case**: For each test case, we read the integer `N`, which represents the number of pairs of socks in the drawer.
3. **Computing the Result**: For each `N`, the result is computed as `N + 1`. This is because the worst-case scenario involves drawing one sock of each of the `N` colors and then one more sock to ensure a pair.
4. **Output the Result**: The result for each test case is printed immediately after computation.

This approach ensures that each test case is processed in constant time, making the solution efficient even for the upper limits of the input constraints.
