To solve this problem, we need to determine the minimum number of coins required to make a given amount of cents using coins of denominations 1, 5, 10, and 25 cents. The optimal approach here is to use a greedy algorithm, which works efficiently because each larger coin denomination is a multiple of the smaller ones, ensuring that using as many of the largest possible coins first will yield the minimum number of coins.

### Approach
1. **Greedy Algorithm**: The greedy approach involves using the largest coin denomination first and then moving to smaller denominations. This ensures we use the fewest coins possible.
2. **Order of Coins**: We start with the largest denomination (25 cents), then proceed to 10 cents, 5 cents, and finally 1 cent. For each denomination, we use as many coins as possible without exceeding the remaining amount.
3. **Efficiency**: This method runs in constant time O(1) because it involves a fixed number of operations (checking four coin denominations) regardless of the input size, making it highly efficient even for very large values of n.

### Solution Code
```python
def main():
    n = int(input())
    coins = [25, 10, 5, 1]
    total = 0
    remaining = n
    for coin in coins:
        if remaining == 0:
            break
        count = remaining // coin
        total += count
        remaining -= count * coin
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input value `n` is read as an integer, representing the total cents we need to make.
2. **Initialization**: We initialize the list of coin denominations in descending order (25, 10, 5, 1) and set up variables to track the total number of coins used and the remaining cents to be converted.
3. **Iterating Over Coins**: For each coin denomination, we calculate how many of these coins can be used without exceeding the remaining cents. This is done using integer division. The count of these coins is added to the total, and the remaining cents are updated by subtracting the value of the coins used.
4. **Termination**: The loop breaks early if the remaining cents reach zero, optimizing the process further.
5. **Output**: Finally, the total number of coins used is printed.

This approach efficiently minimizes the number of coins by leveraging the properties of the given denominations, ensuring optimal performance even for very large values of `n` up to \(10^9\).
