To solve this problem, we need to determine the maximum score Leha can achieve when coloring all cells in an N x M grid. The score is calculated based on the number of neighboring colored cells at the time each cell is colored. The optimal strategy involves maximizing the score by considering each edge (shared side between two cells) exactly once.

### Approach
The key insight is that each edge between two adjacent cells contributes exactly once to the total score. This is because when one cell is colored after its neighbor, the score increases by 1 for that edge. Therefore, the maximum possible score is equal to the total number of edges in the grid. 

The number of edges in a grid can be calculated as follows:
- Horizontal edges: Each row has (M-1) horizontal edges, and there are N rows, resulting in N*(M-1) horizontal edges.
- Vertical edges: Each column has (N-1) vertical edges, and there are M columns, resulting in M*(N-1) vertical edges.

Summing these gives the total number of edges:
\[ \text{Total Edges} = N*(M-1) + M*(N-1) = 2*N*M - N - M \]

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        n = int(input[idx])
        m = int(input[idx + 1])
        idx += 2
        print(2 * n * m - n - m)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The code reads all input at once for efficiency, especially given the constraints.
2. **Processing Each Test Case:** For each test case, the dimensions N and M are extracted.
3. **Calculating Maximum Score:** Using the formula derived from the total number of edges, the maximum score is computed and printed immediately.

This approach ensures that we efficiently compute the result in constant time for each test case, making it suitable even for the upper constraint limits.
