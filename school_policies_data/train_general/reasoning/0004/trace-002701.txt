To solve this problem, we need to count the number of pairs of arrays (a, b) that satisfy specific conditions. The arrays must be of length m, with elements between 1 and n, and must meet constraints on their ordering and element-wise comparisons. The result should be computed modulo 10^9+7.

### Approach
1. **Problem Analysis**:
   - Array `a` must be non-decreasing.
   - Array `b` must be non-increasing.
   - For each index `i`, `a[i] <= b[i]`.
   - The key insight is that the maximum element of `a` (a_m) must be less than or equal to the minimum element of `b` (b_m).

2. **Combinatorial Counting**:
   - The number of non-decreasing sequences of length m ending with `am` can be computed using combinatorial methods.
   - Similarly, the number of non-increasing sequences of length m ending with `bm` can be computed using combinatorial methods.

3. **Summation**:
   - For each possible value of `am` (from 1 to n), compute the number of valid non-decreasing sequences ending at `am`.
   - For each possible value of `bm` (from `am` to n), compute the number of valid non-increasing sequences ending at `bm`.
   - Sum the products of these counts for all valid pairs (am, bm).

### Solution Code
```python
MOD = 10**9 + 7

n, m = map(int, input().split())

max_k = max(m, m - 1)  # Determine the maximum k needed for combinations

# Precompute factorials and inverse factorials up to max_k
fact = [1] * (max_k + 1)
for i in range(1, max_k + 1):
    fact[i] = fact[i-1] * i % MOD

inv_fact = [1] * (max_k + 1)
inv_fact[max_k] = pow(fact[max_k], MOD - 2, MOD)
for i in range(max_k - 1, -1, -1):
    inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

def comb(n_val, k_val):
    if k_val == 0:
        return 1
    if n_val < k_val:
        return 0
    numerator = 1
    for i in range(k_val):
        numerator = numerator * (n_val - i) % MOD
    return numerator * inv_fact[k_val] % MOD

total = 0
for am in range(1, n + 1):
    term1 = comb(am + m - 2, m - 1)
    term2 = comb((n - am) + m, m)
    total = (total + term1 * term2) % MOD

print(total)
```

2. **Combination Calculation**:

3. **Summation Loop**:
   - For each possible value of `am` (the last element of array `a`), compute the number of valid non-decreasing sequences ending at `am`.
   - For each corresponding `bm` (starting from `am`), compute the number of valid non-increasing sequences ending at `bm`.
