To solve this problem, we need to determine the maximum possible total length of words that Andrew can include in his article, ensuring that all selected words use at most two distinct letters. The goal is to maximize the total length of the selected words.

### Approach
1. **Problem Analysis**: The problem requires us to select words from a list such that all chosen words use no more than two distinct letters. The challenge is to find the optimal pair of letters that allows the maximum total length of words.
2. **Generate All Possible Pairs**: Since we need to check all possible pairs of letters (including pairs where both letters are the same), we iterate over all combinations of two letters from 'a' to 'z'. This results in 26 * 26 = 676 possible pairs.
3. **Check Validity of Words for Each Pair**: For each pair of letters, we check if each word can be formed using only those two letters. If a word meets this condition, we add its length to the total for that pair.
4. **Track Maximum Total**: We keep track of the maximum total length encountered across all pairs of letters.

### Solution Code
```python
n = int(input())
words = [input().strip() for _ in range(n)]

max_total = 0

for c1 in 'abcdefghijklmnopqrstuvwxyz':
    for c2 in 'abcdefghijklmnopqrstuvwxyz':
        allowed = {c1, c2}
        current_sum = 0
        for word in words:
            if all(ch in allowed for ch in word):
                current_sum += len(word)
        if current_sum > max_total:
            max_total = current_sum

print(max_total)
```

### Explanation
1. **Reading Input**: The input consists of the number of words followed by the words themselves. We read and store these words in a list.
2. **Generating Pairs**: We generate all possible pairs of letters (c1, c2) where both c1 and c2 range from 'a' to 'z'. This includes pairs where both letters are the same, which effectively checks for words using a single letter.
3. **Checking Word Validity**: For each pair of letters, we check each word to see if all its characters are within the allowed set {c1, c2}. If valid, we sum the lengths of these words.
4. **Maximizing Total Length**: We update the maximum total length whenever we find a valid pair of letters that results in a higher sum.

This approach efficiently checks all possible pairs of letters and ensures that we find the optimal solution within the given constraints. The algorithm's complexity is manageable due to the limited number of possible pairs (676) and the constraints on input size.
