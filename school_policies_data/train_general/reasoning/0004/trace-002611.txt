To solve this problem, we need to determine the minimum number of times Valera will need to wash dishes (either bowls or plates) given his eating plan over a series of days. Valera can eat two types of dishes: type 1 requires a bowl, and type 2 can use either a bowl or a plate. The goal is to use the available clean dishes optimally to minimize washing.

### Approach
1. **Understand the Constraints**: 
   - Type 1 dishes can only be eaten using a bowl.
   - Type 2 dishes can be eaten using either a bowl or a plate.
   - Once a dish is used, it becomes dirty and cannot be reused unless washed.

2. **Optimal Strategy**:
   - **Type 1 Dishes**: Use bowls exclusively. If no clean bowls are available, wash a bowl and use it.
   - **Type 2 Dishes**: Prioritize using plates first to save bowls for type 1 dishes. If no clean plates are available, use a bowl. If neither is available, wash a plate (since plates can be reused for type 2 dishes, saving bowls for potential type 1 dishes).

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    m = int(input[1])
    k = int(input[2])
    a = list(map(int, input[3:3+n]))
    
    clean_bowls = m
    clean_plates = k
    washes = 0
    
    for dish in a:
        if dish == 1:
            if clean_bowls > 0:
                clean_bowls -= 1
            else:
                washes += 1
        else:
            if clean_plates > 0:
                clean_plates -= 1
            elif clean_bowls > 0:
                clean_bowls -= 1
            else:
                washes += 1
    print(washes)

main()
```

### Explanation
1. **Initialization**: Read the input values and initialize the number of clean bowls and plates.
2. **Iterate Over Each Day**:
   - For **type 1 dishes**, check if a clean bowl is available. If not, increment the wash count and use a washed bowl.
   - For **type 2 dishes**, first try to use a clean plate. If no plates are available, use a bowl. If neither is available, wash a plate and increment the wash count.
3. **Output the Result**: After processing all days, print the total number of washes needed.

This approach ensures that we minimize the number of washes by prioritizing the use of plates for type 2 dishes, thereby reserving bowls for type 1 dishes whenever possible. This greedy strategy efficiently reduces the need for washing by optimally using available resources.
