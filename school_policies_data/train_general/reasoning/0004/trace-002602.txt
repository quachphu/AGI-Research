To solve this problem, we need to determine the minimum number of cuts required to rearrange the given palindrome string into a different palindrome. If it's impossible, we should return "Impossible".

### Approach
1. **Check Uniform Characters**: If all characters in the string are the same, it's impossible to form a different palindrome, so we return "Impossible".
2. **Check for One Cut (k=1)**: Iterate through all possible splits of the string into two parts. For each split, check if swapping the two parts results in a different palindrome.
3. **Check for Two Cuts (k=2)**: If one cut is not possible, check if the string can be split into three parts such that the first and third parts are reverses of each other, and the first part is not a palindrome. This ensures that rearranging these parts will form a different palindrome.

### Solution Code
```python
s = input().strip()

# Check if all characters are the same
if all(c == s[0] for c in s):
    print("Impossible")
    exit()

n = len(s)

# Check for k=1
for i in range(1, n):
    s1 = s[:i]
    s2 = s[i:]
    candidate = s2 + s1
    if candidate != s and candidate == candidate[::-1]:
        print(1)
        exit()

# Check for k=2
max_i = n // 2
for i in range(1, max_i + 1):
    a = s[:i]
    c = s[-i:]
    if c == a[::-1] and a != a[::-1]:
        print(2)
        exit()

print("Impossible")
```

### Explanation
1. **Uniform Characters Check**: The first check ensures that if all characters are the same, no rearrangement can produce a different string, hence "Impossible".
2. **One Cut Check**: By iterating through possible splits into two parts, we check if swapping these parts results in a valid palindrome different from the original. If found, we immediately return 1.
3. **Two Cuts Check**: If one cut isn't feasible, we check for splits into three parts where the first and third parts are reverses of each other. This ensures that rearranging these parts will form a different palindrome, leading to a solution with 2 cuts.

This approach efficiently narrows down the possible solutions by leveraging properties of palindromes and systematic checks for feasible splits, ensuring optimal performance even for the upper constraint of string length up to 5000.
