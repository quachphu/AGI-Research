To solve this problem, we need to determine if a given word translated from Berlandish to Birlandish is correct. The translation is correct if the second word is the reverse of the first word.

### Approach
1. **Input Reading**: Read the two input strings. The first string is the original word in Berlandish, and the second string is the translated word in Birlandish.
2. **Reverse Check**: Check if the second string is the reverse of the first string. This can be efficiently done using Python's string slicing feature to reverse the first string and then comparing it with the second string.
3. **Output Result**: Print "YES" if the second string is the reverse of the first string, otherwise print "NO".

### Solution Code
```python
s = input().strip()
t = input().strip()

print("YES" if t == s[::-1] else "NO")
```

### Explanation
1. **Reading Inputs**: The input strings are read using `input().strip()` to ensure there are no leading or trailing spaces, although the problem guarantees that there are no unnecessary spaces.
2. **Reversing the String**: The first string `s` is reversed using slicing `s[::-1]`, which creates a new string that is the reverse of `s`.
3. **Comparison**: The reversed string is compared with the second string `t`. If they match, the translation is correct, and we print "YES". Otherwise, we print "NO".

This approach efficiently checks the condition in linear time relative to the length of the strings, making it both optimal and straightforward.
