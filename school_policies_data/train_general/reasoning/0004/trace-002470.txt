To solve this problem, we need to determine the minimum number of integers to delete from a given list such that the remaining integers satisfy the condition where the maximum value (a) is at most three times the minimum value (b) of the remaining integers. The solution involves finding the largest valid subset of integers that meet this condition and then calculating the number of deletions required based on the size of this subset.

### Approach
1. **Sort the Array**: First, we sort the array to simplify the process of checking valid subsets.
2. **Binary Search for Valid Subsets**: For each element in the sorted array, considered as the minimum value (b), we use binary search to find the farthest element that can be included such that the maximum value (a) in the subset does not exceed 3 times the minimum value (3b).
3. **Calculate Maximum Valid Subset Size**: Track the largest valid subset size found using the above method. The minimum number of deletions is then the total number of integers minus this maximum subset size.

### Solution Code
```python
import bisect

n = int(input())
arr = list(map(int, input().split()))
arr.sort()

max_count = 0
for i in range(n):
    x = 3 * arr[i]
    j = bisect.bisect_right(arr, x) - 1
    current_count = j - i + 1
    if current_count > max_count:
        max_count = current_count

print(n - max_count)
```

### Explanation
1. **Sorting the Array**: Sorting the array allows us to efficiently use binary search to find the maximum valid subset for each potential minimum value.
2. **Binary Search for Maximum Valid Element**: For each element in the sorted array, treated as the minimum value (b), we calculate the maximum allowed value (3b). Using binary search, we find the rightmost element in the array that is less than or equal to this maximum allowed value.
3. **Determine Subset Size**: The size of the valid subset starting from the current minimum value (b) to the found maximum value (a) is calculated. The largest such subset size across all possible minimum values is determined.
4. **Calculate Deletions**: The result is the total number of integers minus the size of the largest valid subset, giving the minimum number of deletions required.

This approach efficiently narrows down the valid subsets using sorting and binary search, ensuring an optimal solution with a time complexity of O(N log N), which is feasible for the given problem constraints.
