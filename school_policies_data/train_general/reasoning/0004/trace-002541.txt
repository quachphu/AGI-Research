To solve this problem, we need to determine if Bob can travel from station 1 to station s using the metro system, which consists of two tracks. The first track goes from station 1 to n, and the second track goes from station n to 1. Stations can be closed on either track, and Bob can switch tracks at any station that is open on both tracks.

### Approach
1. **Initial Check**: If the starting station (station 1) is closed on the first track, Bob cannot start his journey, so the answer is "NO".
2. **Direct Path Check**: If the destination station (station s) is open on the first track, Bob can reach it directly, so the answer is "YES".
3. **Switch Track Check**: If the destination station is closed on the first track, check if it is open on the second track. If not, the answer is "NO".
4. **Intermediate Station Check**: If the destination station is open on the second track, check if there exists an intermediate station (k) such that:
   - Station k is reachable via the first track (open on the first track).
   - Station k allows switching to the second track (open on the second track).
   - Station k is greater than or equal to the destination station (s).

### Solution Code
```python
n, s = map(int, input().split())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

if a[0] == 0:
    print("NO")
else:
    if a[s-1] == 1:
        print("YES")
    else:
        if b[s-1] == 0:
            print("NO")
        else:
            found = False
            for k in range(s, n + 1):
                if a[k-1] == 1 and b[k-1] == 1:
                    found = True
                    break
            print("YES" if found else "NO")
```

### Explanation
1. **Initial Check**: The code first checks if Bob can start his journey by verifying if station 1 (a[0]) is open on the first track.
2. **Direct Path Check**: If the destination station (a[s-1]) is open on the first track, Bob can reach it directly.
3. **Switch Track Check**: If the destination station is closed on the first track, the code checks if it is open on the second track (b[s-1]).
4. **Intermediate Station Check**: The code then checks for any intermediate station (k) from s to n that is open on both tracks. If such a station exists, Bob can switch tracks there and reach the destination station via the second track.

This approach efficiently checks all possible ways Bob can reach his destination using the given constraints and ensures optimal performance within the problem limits.
