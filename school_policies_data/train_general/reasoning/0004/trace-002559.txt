To solve this problem, we need to determine the next petrol station where Vanya will stop based on his previous stops. The challenge is to find the next station uniquely if possible, considering the constraints on the petrol consumption and refueling strategy.

### Approach
1. **Understanding the Problem**: Vanya starts with an unknown amount of petrol (α liters) and stops at petrol stations when his remaining petrol is insufficient to reach the next station. Each time he stops, he refuels with α liters. Given a sequence of previous stops, we need to determine the next station he will stop at.

2. **Constraints Analysis**: For each segment between consecutive stops, we derive constraints on α. These constraints ensure that Vanya stops at the given stations and skips the intermediate ones. By iterating through these segments, we narrow down the possible values of α.

3. **Track Petrol Levels**: Using the derived constraints, we track the petrol levels after each refuel. This helps in determining the possible petrol levels when Vanya leaves the last known stop.

4. **Determine Next Stop**: Based on the possible range of α values, we simulate the journey from the last known stop to determine the next station. If all possible α values lead to the same next station, the answer is unique; otherwise, it is not unique.

### Solution Code
```python
import math

n = int(input())
stops = list(map(int, input().split()))

if n == 0:
    print("unique")
    print(0)
    exit()

prev_stop = stops[0]
a = 2
b = -10 * prev_stop
alpha_low = 10.0
alpha_high = 10.0 * (prev_stop + 1)

for i in range(1, n):
    curr_stop = stops[i]
    m = curr_stop - prev_stop
    
    # Calculate new alpha constraints for the current segment
    lower = (10.0 * m - b) / a
    upper = (10.0 * (m + 1) - b) / a
    alpha_low = max(alpha_low, lower)
    alpha_high = min(alpha_high, upper)
    
    # Check arriving petrol constraint at current_stop
    upper_arrival = (10.0 * m + 10.0 - b) / a
    alpha_high = min(alpha_high, upper_arrival)
    
    # Update coefficients for the next iteration
    a += 1
    b -= 10 * m
    prev_stop = curr_stop

# Calculate possible next station
P_last_low = a * alpha_low + b
P_last_high = a * (alpha_high - 1e-9) + b

val_low = (P_last_low - 10) / 10
val_high = (P_last_high - 10) / 10

d_low = math.floor(val_low) + 1
d_high = math.floor(val_high) + 1

if d_low == d_high:
    next_station = prev_stop + d_low
    print("unique")
    print(next_station)
else:
    print("not unique")
```

4. **Calculate Possible α Range**: The constraints are combined to determine the possible range of α values.
5. **Determine Next Station**: Using the possible α range, the next station is determined by simulating the journey from the last known stop. If the next station is uniquely determined, it is printed; otherwise, the result is "not unique".

This approach ensures that we efficiently narrow down the possible values of α and determine the next stop accurately based on the given constraints.
