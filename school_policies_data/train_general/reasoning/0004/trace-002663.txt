To solve this problem, we need to determine the total money Grandma Laura should have earned by selling her apples to each buyer, considering that each buyer either bought half of her apples or half plus an additional half apple as a gift. The solution involves working backwards from the end of the day when she has no apples left to determine the number of apples she had at each step and the corresponding money earned.

### Approach
1. **Reverse Process**: Start from the end of the day when Grandma has 0 apples and work backwards through each buyer.
2. **Reconstruct Apples**: For each buyer in reverse order, determine the number of apples Grandma had before that buyer's purchase.
3. **Calculate Earnings**: For each buyer, compute the money earned based on whether they took half or half plus an additional half apple.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    p = int(input[1])
    buyers = input[2:2+n]
    
    current_apples = 0
    money = 0
    
    for buyer in reversed(buyers):
        if buyer == 'halfplus':
            x = 2 * current_apples + 1
            money += (x * p) // 2
            current_apples = x
        else:
            x = 2 * current_apples
            money += current_apples * p
            current_apples = x
    
    print(money)

main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of buyers `n`, the price per apple `p`, and the list of buyers.
2. **Reverse Iteration**: We iterate over the buyers in reverse order to reconstruct the number of apples Grandma had before each sale.
3. **Handling Each Buyer**:
   - **'halfplus' Buyer**: If the buyer took half plus an additional half apple, we calculate the apples before the sale and the money earned. The apples before the sale are `2 * current_apples + 1`, and the money earned is `(x * p) // 2` where `x` is the apples before the sale.
   - **'half' Buyer**: If the buyer took half the apples, the apples before the sale are `2 * current_apples`, and the money earned is `current_apples * p`.
4. **Output the Result**: The total money earned is printed after processing all buyers.

This approach ensures that we accurately reconstruct the number of apples and calculate the earnings efficiently by working backwards, leveraging the constraints given in the problem.
