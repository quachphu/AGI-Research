To solve this problem, we need to determine the number of ways to assign distinct integers to robots based on their preferences, such that each robot's assigned number is within its specified range. The result should be computed modulo \(10^9 + 7\).

### Approach
1. **Sort the Preferences**: First, sort the list of maximum values (MAX[]) in non-decreasing order. This helps in systematically determining the number of valid choices for each robot.
2. **Calculate Available Choices**: For each robot in the sorted list, compute the number of available choices. The i-th robot (0-based index) can choose a number from 1 to MAX[i], but must exclude the numbers chosen by the previous i robots. Thus, the number of valid choices for the i-th robot is given by \( \text{MAX}[i] - i \).
3. **Check Validity**: If at any point the number of valid choices for a robot is non-positive, it means it's impossible to assign distinct numbers, and the result is 0.
4. **Compute Result**: Multiply the number of valid choices for each robot, taking modulo \(10^9 + 7\) at each step to prevent overflow.

### Solution Code
```python
MOD = 10**9 + 7

def compute_assignments():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        MAX = list(map(int, input[ptr:ptr+N]))
        ptr += N
        MAX.sort()
        result = 1
        for i in range(N):
            available = MAX[i] - i
            if available <= 0:
                result = 0
                break
            result = (result * available) % MOD
        print(result)

compute_assignments()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints. The input is split into a list for easy parsing.
2. **Sorting**: The maximum values are sorted to ensure we handle each robot in increasing order of their maximum allowed values.
3. **Iterating Over Robots**: For each robot, compute the available choices by subtracting the index (number of previous robots) from the current maximum value. If any robot's available choices are non-positive, the result is immediately set to 0 and the loop breaks.
4. **Modulo Operation**: The result is updated using modulo \(10^9 + 7\) at each step to handle large numbers and prevent overflow.

This approach ensures that we efficiently compute the number of valid assignments while adhering to the constraints and requirements of the problem.
