To solve this problem, we need to determine the optimal order of serving customers to minimize their total waiting time. The key insight is that serving customers in ascending order of their processing times (Shortest Job First) minimizes the total waiting time.

### Approach
1. **Input Handling**: Read multiple datasets until encountering a line with 0, which signifies the end of input.
2. **Sorting**: For each dataset, sort the customer processing times in ascending order.
3. **Total Waiting Time Calculation**: Calculate the total waiting time by summing the cumulative processing times of each customer except the last one. This is done efficiently by maintaining a running sum of the sorted processing times.

### Solution Code
```python
import sys

def main():
    lines = [line.strip() for line in sys.stdin if line.strip()]
    ptr = 0
    while ptr < len(lines):
        n = int(lines[ptr])
        ptr += 1
        if n == 0:
            break
        times = []
        for _ in range(n):
            times.append(int(lines[ptr]))
            ptr += 1
        sorted_times = sorted(times)
        total_waiting = 0
        current_sum = 0
        for i in range(len(sorted_times) - 1):
            current_sum += sorted_times[i]
            total_waiting += current_sum
        print(total_waiting)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and processed line by line. This helps in efficiently managing multiple datasets.
2. **Sorting Processing Times**: By sorting the processing times in ascending order, we ensure that customers with shorter processing times are served first, which minimizes the cumulative waiting time.
3. **Calculating Total Waiting Time**: For each customer (except the last one), we maintain a running total of the processing times of all previous customers. This running total is accumulated to compute the total waiting time.

This approach efficiently reduces the total waiting time by leveraging the Shortest Job First scheduling algorithm, ensuring optimal performance even for the upper constraint of 10,000 customers.
