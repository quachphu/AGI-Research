To solve this problem, we need to determine the number of elements in the modified power set of a set formed from the characters of a given string. The modified power set includes all non-empty subsets of consecutive elements from the original set, excluding the empty set.

### Approach
1. **Understanding the Modified Power Set**: The modified power set consists of all non-empty subsets formed by consecutive elements in the order they first appear in the input string. For example, the string "abc" results in the subsets {a}, {b}, {c}, {a, b}, {b, c}, and {a, b, c}.

2. **Forming the Set**: The original set is derived from the input string by removing duplicate characters while preserving the order of their first occurrence. For example, the string "abac" becomes the list ['a', 'b', 'c'].

3. **Counting Subsets**: The number of non-empty contiguous subarrays (subsets) of a list of length `n` is given by the formula `n * (n + 1) / 2`. This formula is derived from the sum of the first `n` natural numbers.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        s = sys.stdin.readline().rstrip('\n')
        seen = set()
        unique_order = []
        for c in s:
            if c not in seen:
                seen.add(c)
                unique_order.append(c)
        m = len(unique_order)
        print(m * (m + 1) // 2)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency, especially given the constraints of up to 1,000,000 characters per string. Each line is processed to remove the trailing newline character.

2. **Processing the String**: Each character in the string is checked for its first occurrence. A set is used to track seen characters, and a list maintains the order of first occurrences.

3. **Calculating the Result**: The length of the list of unique characters (preserving order) is used to compute the number of non-empty contiguous subsets using the formula `n * (n + 1) / 2`.

This approach efficiently handles large input sizes and ensures the solution is computed in linear time relative to the input string length, making it suitable for the given constraints.
