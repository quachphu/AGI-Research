### Approach
1. **Binary Structure Analysis**: A valid number with exactly one '0' in its binary representation can be written in the form of `(1^m 0 1^n)`, where `m` is the number of consecutive '1's before the '0', and `n` is the number of consecutive '1's after the '0'. This can be translated into the formula: `num = (2^m - 1) * 2^(n + 1) + (2^n - 1)`.
2. **Efficient Generation**: Instead of checking each number in the interval [a, b], generate all possible numbers using the formula for different values of `m` and `n` where `m ≥ 1` and `n ≥ 0`. This avoids checking each number individually and leverages the structure of valid numbers.
3. **Range Check**: For each generated number, check if it lies within the interval [a, b]. If it does, increment the count.

### Solution Code
```python
def count_one_zero(a, b):
    count = 0
    m = 1
    while True:
        # Calculate the minimal number for current m (with n=0)
        min_num = ((1 << m) - 1) << 1  # (2^m - 1) * 2
        if min_num > b:
            break  # Further m values will only produce larger numbers
        n = 0
        while True:
            left = ((1 << m) - 1) << (n + 1)
            right = (1 << n) - 1
            num = left + right
            if num > b:
                break
            if num >= a:
                count += 1
            n += 1
        m += 1
    return count

a, b = map(int, input().split())
print(count_one_zero(a, b))
```

### Explanation
1. **Binary Structure**: The valid numbers are generated by considering all possible positions of the single '0' in their binary form. This is done by varying the number of '1's before and after the '0'.
2. **Efficient Loops**: The outer loop iterates over possible values of `m` (starting from 1), and the inner loop iterates over possible values of `n` (starting from 0). For each pair (m, n), the number is generated using the formula and checked against the interval [a, b].
3. **Termination Conditions**: The loops terminate early if the generated numbers exceed the upper bound `b`, ensuring efficiency even for large ranges.

This approach efficiently generates all valid numbers and checks their inclusion in the interval, providing an optimal solution even for very large values of `a` and `b` up to 10^18.
