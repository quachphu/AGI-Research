To solve this problem, we need to minimize the final number left on the board after performing a series of operations. Each operation involves erasing two numbers and replacing them with the ceiling of their average. The goal is to determine the optimal sequence of operations to achieve the smallest possible final number.

### Approach
The key insight is that the minimal possible final number is always 2 for any given \( n \geq 2 \). This can be achieved by repeatedly combining the two largest numbers present on the board. Using a max-heap (priority queue) allows us to efficiently retrieve and combine the largest numbers at each step. This approach ensures that we minimize the impact of larger numbers by reducing them as quickly as possible.

### Solution Code
```python
import heapq
import sys

def main():
    input = sys.stdin.read().split()
    t = int(input[0])
    ptr = 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        # Use a max-heap by storing negative values
        heap = [-i for i in range(1, n+1)]
        heapq.heapify(heap)
        steps = []
        for _ in range(n-1):
            a = -heapq.heappop(heap)
            b = -heapq.heappop(heap)
            steps.append((a, b))
            c = (a + b + 1) // 2
            heapq.heappush(heap, -c)
        final = -heap[0]
        print(final)
        for a, b in steps:
            print(a, b)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Max-Heap Initialization**: We use a max-heap by storing negative values since Python's `heapq` module only provides a min-heap.
3. **Operations**: For each test case, we repeatedly extract the two largest numbers from the heap, combine them, and push the result back into the heap. Each combination step is recorded.
4. **Output**: After processing all operations, the final remaining number is printed, followed by the sequence of operations that led to this result.

This approach ensures that we always combine the largest available numbers first, which helps in minimizing the final result. The use of a heap allows efficient retrieval and insertion operations, making the solution suitable for large input sizes.
