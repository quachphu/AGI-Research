To solve this problem, we need to determine the number of cars that must be fined for overtaking inside a tunnel. A car is fined if it enters the tunnel after another car but exits before that car. 

### Approach
1. **Understand the Problem**: Each car enters and exits the tunnel exactly once. The entry and exit orders are given, and we need to identify cars that overtake others inside the tunnel.
2. **Key Insight**: A car `i` will be fined if there exists any car `j` such that `i` entered after `j` but exited before `j`.
3. **Efficient Check**: For each car in the entry order, track the maximum exit position encountered so far. If a car's exit position is less than this maximum, it means this car overtook at least one previous car, and thus should be fined.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

exit_pos = {car: idx for idx, car in enumerate(b)}

max_so_far = -1
count = 0

for car in a:
    pos = exit_pos[car]
    if pos < max_so_far:
        count += 1
    else:
        max_so_far = pos

print(count)
```

### Explanation
1. **Input Reading**: Read the number of cars and their entry and exit orders.
2. **Exit Position Mapping**: Create a dictionary to map each car to its exit position using the exit order list.
3. **Track Maximum Exit Position**: Iterate through each car in the entry order. For each car, check its exit position against the maximum exit position encountered so far. If the current car's exit position is less than this maximum, it means the car overtook another and is fined.
4. **Update Maximum**: If the current car's exit position is the highest encountered so far, update the maximum to this position.

This approach ensures we efficiently determine the number of fined cars in linear time, making it suitable for large input sizes up to 100,000 cars.
