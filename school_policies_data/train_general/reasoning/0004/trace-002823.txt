To solve this problem, we need to determine the number of cells in an N x N grid where the sum of the row and column indices (i + j) is a prime number. The solution must be efficient enough to handle large values of N up to 1,000,000.

### Approach
1. **Prime Number Identification**: Use the Sieve of Eratosthenes algorithm to identify all prime numbers up to 2*(N-1). This is because the maximum possible sum of indices (i + j) in an N x N grid is 2*(N-1).
2. **Count Valid Cells**: For each prime number identified, calculate the number of valid (i, j) pairs in the grid where the sum of indices equals the prime number. The count of valid pairs depends on the value of the prime number:
   - If the prime number is less than or equal to N-1, the count of pairs is (prime + 1).
   - If the prime number is greater than N-1 but less than or equal to 2*(N-1), the count of pairs is (2*N - 1 - prime).

### Solution Code
```python
import sys
import math

def count_colored_cells():
    MOD = 10**9 + 7
    n = int(sys.stdin.readline())
    if n == 0:
        print(0)
        return
    max_s = 2 * (n - 1)
    if max_s < 2:
        # Check primes up to max_s, which could be 0 or 1 (non-prime)
        print(0)
        return
    sieve = [True] * (max_s + 1)
    sieve[0] = sieve[1] = False
    for i in range(2, int(math.sqrt(max_s)) + 1):
        if sieve[i]:
            sieve[i*i : max_s+1 : i] = [False] * len(sieve[i*i : max_s+1 : i])
    total = 0
    for s in range(2, max_s + 1):
        if sieve[s]:
            if s <= n - 1:
                count = s + 1
            else:
                count = 2 * n - 1 - s
            total = (total + count) % MOD
    print(total % MOD)

count_colored_cells()
```

### Explanation
1. **Prime Number Identification**: The Sieve of Eratosthenes is used to efficiently generate a list of primes up to 2*(N-1). This algorithm marks non-prime numbers in a boolean array, allowing quick prime checks.
2. **Counting Valid Cells**: For each prime number identified, we determine the number of valid (i, j) pairs based on the range of the prime number. The sum of these counts across all primes gives the total number of cells to be colored. The result is computed modulo 1,000,000,007 to handle large numbers as required.

This approach ensures that the solution is efficient and can handle the upper constraint of N = 1,000,000 by leveraging the Sieve of Eratosthenes and mathematical insights into the distribution of valid pairs.
