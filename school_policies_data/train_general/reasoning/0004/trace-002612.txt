To solve this problem, we need to determine if we can expand a given set of temperature measurements to meet specific minimum and maximum temperature constraints after adding a certain number of additional measurements.

### Approach
1. **Input Validation**: Check if any of the existing temperatures are outside the desired minimum and maximum range. If any temperature is outside this range, the answer is immediately "Incorrect".
2. **Existing Min and Max Check**: Determine the minimum and maximum values from the existing temperatures.
3. **Required Additions Calculation**: Calculate how many additional temperatures are needed to ensure the minimum and maximum values match the desired ones. Specifically:
   - If the existing minimum is greater than the desired minimum, we need to add at least one temperature equal to the desired minimum.
   - If the existing maximum is less than the desired maximum, we need to add at least one temperature equal to the desired maximum.
4. **Feasibility Check**: Verify if the number of required additions does not exceed the number of available slots (i.e., the difference between the total required measurements and the existing measurements).

### Solution Code
```python
n, m, min_val, max_val = map(int, input().split())
temps = list(map(int, input().split()))

# Check if any temperature is out of the allowed range
valid = True
for t in temps:
    if t < min_val or t > max_val:
        valid = False
        break

if not valid:
    print("Incorrect")
else:
    existing_min = min(temps)
    existing_max = max(temps)
    required = 0
    if existing_min > min_val:
        required += 1
    if existing_max < max_val:
        required += 1
    if required <= (n - m):
        print("Correct")
    else:
        print("Incorrect")
```

### Explanation
1. **Input Validation**: We first check if all existing temperatures are within the specified range [min_val, max_val]. If any temperature is outside this range, the output is "Incorrect".
2. **Existing Min and Max**: We compute the minimum and maximum values from the existing temperatures.
3. **Required Additions**: We determine how many additional values are needed to ensure the desired minimum and maximum can be achieved. This is done by checking if the existing minimum and maximum values already meet the desired constraints.
4. **Feasibility Check**: We check if the number of required additions can be accommodated within the available slots (n - m). If yes, the answer is "Correct"; otherwise, it is "Incorrect".

This approach efficiently checks the necessary conditions and ensures that the solution is both correct and optimal.
