To solve this problem, we need to determine the coordinates of the point Mj after applying a series of symmetry operations based on given points. The key insight is to recognize the pattern in the symmetry operations and leverage it to compute the result efficiently, even for very large values of j.

### Approach
1. **Understanding Symmetry Operations**: Each point Mi is obtained by reflecting the previous point Mi-1 around one of the points A0, A1, ..., An-1 in a cyclic manner. The reflection of a point X around a point C results in a new point Y such that C is the midpoint of the segment XY. Mathematically, Y = 2*C - X.

2. **Cycle Detection**: Since the sequence of points A0, A1, ..., An-1 repeats every n steps, we can analyze the effect of one full cycle of n steps. After one full cycle, the transformation can be represented as a linear function. For an odd n, after each full cycle, the point alternates between two states due to the properties of reflections.

3. **Sum Calculation**: Compute the sum S of the points A0, A1, ..., An-1 with alternating signs. This sum helps in determining the effect of a full cycle of reflections.

4. **Handling Large j**: Given the constraints, directly simulating each step up to j is infeasible. Instead, we break down the problem into full cycles and remaining steps. Using the sum S, we can determine the state after m full cycles and then apply the remaining steps.

### Solution Code
```python
n, j = map(int, input().split())
m0_x, m0_y = map(int, input().split())
A = [tuple(map(int, input().split())) for _ in range(n)]

sx = 0
sy = 0
for k in range(n):
    sign = (-1) ** k
    ax, ay = A[k]
    sx += ax * sign
    sy += ay * sign

m = j // n
r = j % n

if m % 2 == 0:
    current_x, current_y = m0_x, m0_y
else:
    current_x = 2 * sx - m0_x
    current_y = 2 * sy - m0_y

for i in range(r):
    ax, ay = A[i]
    current_x = 2 * ax - current_x
    current_y = 2 * ay - current_y

print(current_x, current_y)
```

### Explanation
1. **Input Reading**: The code reads the input values for n, j, the initial point M0, and the list of points A.

2. **Sum Calculation**: The sum S is computed with alternating signs for each coordinate of the points in A. This sum captures the cumulative effect of one full cycle of reflections.

3. **Cycle Handling**: The number of full cycles (m) and remaining steps (r) are computed. Depending on whether the number of full cycles is even or odd, the initial point after m cycles is determined using the sum S.

4. **Remaining Steps**: The remaining steps (r) are applied to the initial point obtained after m cycles. Each remaining step involves reflecting the current point around the next point in the sequence A.

This approach efficiently handles large values of j by leveraging the periodic nature of the reflections and reducing the problem to a manageable number of operations.
