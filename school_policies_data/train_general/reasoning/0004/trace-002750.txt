To solve this problem, we need to find the lexicographically smallest binary string possible after performing at most `k` adjacent swaps. The key insight is to move '0's as far left as possible within the allowed number of swaps.

### Approach
1. **Identify Positions of Zeros**: Collect the indices of all '0's in the input string.
2. **Greedy Movement of Zeros**: For each zero, determine the maximum number of positions it can move left, considering the remaining allowed swaps and the positions of previously moved zeros.
3. **Construct Result String**: After determining the new positions of all zeros, construct the resulting string by placing '0's at their new positions and filling the rest with '1's.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    q = int(input[ptr])
    ptr += 1
    for _ in range(q):
        n, k = int(input[ptr]), int(input[ptr + 1])
        ptr += 2
        s = input[ptr]
        ptr += 1
        zeros = []
        for i, c in enumerate(s):
            if c == '0':
                zeros.append(i)
        if not zeros:
            print(s)
            continue
        res_zeros = []
        prev_target = -1
        remaining_k = k
        m = len(zeros)
        broke = False
        for i in range(m):
            z = zeros[i]
            earliest = prev_target + 1
            max_steps = z - earliest
            steps = min(remaining_k, max_steps) if max_steps >= 0 else 0
            new_target = z - steps
            res_zeros.append(new_target)
            remaining_k -= steps
            prev_target = new_target
            if remaining_k <= 0:
                # Add remaining zeros as their original positions
                for j in range(i + 1, m):
                    res_zeros.append(zeros[j])
                broke = True
                break
        if not broke:
            # All zeros processed normally
            pass
        # Construct the result string
        arr = ['1'] * n
        for pos in res_zeros:
            if pos < n:
                arr[pos] = '0'
        print(''.join(arr))

main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Collecting Zeros**: We gather the indices of all '0's in the input string.
3. **Processing Each Zero**: For each zero, calculate the earliest possible position it can move to, considering the remaining swaps and the positions of previously moved zeros. Update the remaining swaps and track the new positions.
4. **Constructing the Result**: After determining all new positions for zeros, construct the result string by placing '0's at these positions and filling the rest with '1's.

This approach ensures that each zero is moved as far left as possible within the allowed swaps, resulting in the lexicographically smallest string. The algorithm efficiently handles large inputs within the problem constraints.
