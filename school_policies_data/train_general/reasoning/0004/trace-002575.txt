To solve this problem, we need to determine the number of particles in a given chamber N, where each chamber K has K times the particles of the previous chamber K-1. The initial chamber (0) starts with X particles. The solution must handle very large input values efficiently using modular arithmetic.

### Approach
1. **Understanding the Pattern**: The number of particles in chamber N is given by \(X \times N!\). This is because each subsequent chamber multiplies the particles from the previous chamber by its chamber number, leading to a factorial growth pattern.
2. **Modulo Operation**: Since the result can be very large, we use modulo \(10^6 + 3\) (a prime number) to keep calculations manageable.
3. **Precomputation**: Precompute factorials modulo \(10^6 + 3\) up to \(10^6 + 2\). This allows efficient lookup of factorial values for any N.
4. **Efficient Handling of Large Values**: For N values greater than or equal to \(10^6 + 3\), the factorial modulo \(10^6 + 3\) is 0. For smaller N, use the precomputed factorial values.

### Solution Code
```python
import sys

MOD = 10**6 + 3

# Precompute factorials modulo MOD
fact = [1] * MOD
for i in range(1, MOD):
    fact[i] = (fact[i-1] * i) % MOD

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        N = int(input[idx])
        X = int(input[idx + 1])
        idx += 2
        if N >= MOD:
            print(0)
        else:
            x_mod = X % MOD
            res = (x_mod * fact[N]) % MOD
            print(res)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precomputation**: We precompute the factorial values modulo \(10^6 + 3\) up to \(10^6 + 2\). This allows us to quickly look up the factorial value for any N in constant time.
2. **Reading Input**: The input is read all at once for efficiency, especially given the large number of test cases (up to \(10^5\)).
3. **Handling Each Test Case**:
   - If \(N \geq 10^6 + 3\), the result is 0 because \(N! \mod 10^6 + 3\) is 0.
   - For smaller N, compute \(X \mod 10^6 + 3\) and multiply it by the precomputed factorial value of N, then take the result modulo \(10^6 + 3\).

This approach ensures that we handle very large values efficiently using modular arithmetic and precomputation, making the solution both optimal and scalable.
