To solve this problem, we need to determine the minimum possible difference between the number of red and blue blocks when a rectangular parallelepiped of dimensions A×B×C is split into two smaller rectangular parallelepipeds. The solution must ensure that both the red and blue blocks form valid rectangular shapes and that the difference between their counts is minimized.

### Approach
1. **Check for Even Dimensions**: If any of the dimensions (A, B, or C) is even, we can split the parallelepiped along that dimension into two equal parts. This results in zero difference between the number of red and blue blocks.
2. **All Odd Dimensions**: If all dimensions are odd, the minimum difference is determined by the smallest product of two dimensions. This is because splitting along any dimension will leave the other two dimensions as odd, resulting in a product of those two dimensions as the difference.

### Solution Code
```python
A, B, C = map(int, input().split())
if A % 2 == 0 or B % 2 == 0 or C % 2 == 0:
    print(0)
else:
    print(min(A * B, B * C, C * A))
```

### Explanation
1. **Even Dimension Check**: If any of the dimensions (A, B, or C) is even, we can split the parallelepiped along that dimension into two equal parts. For example, if A is even, splitting it into two equal halves along A results in two smaller boxes with equal volumes, leading to a difference of zero.
2. **All Odd Dimensions**: When all dimensions are odd, the optimal split is along the dimension that results in the smallest product of the other two dimensions. This product gives the minimum possible difference because splitting along the longest possible dimension would minimize the resulting difference.

This approach efficiently determines the minimal difference by leveraging the parity of each dimension and the properties of rectangular parallelepipeds.
