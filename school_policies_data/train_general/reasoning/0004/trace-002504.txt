To solve this problem, we need to determine how many origami ships Vasya can make from a given rectangular sheet of paper by repeatedly cutting out the largest possible square and using the remaining strip until no more strips are left. 

### Approach
The problem can be efficiently solved using a method similar to the Euclidean algorithm for finding the greatest common divisor (GCD). Here's the step-by-step approach:

1. **Understanding the Problem**: Each time Vasya cuts out the largest possible square from the current rectangular sheet, the remaining part is a smaller rectangle. This process continues until the remaining part is a square, which is then used to make the final ship.

2. **Key Insight**: The number of ships Vasya makes in each step is equivalent to the number of times the smaller dimension fits into the larger dimension. For example, if the dimensions are 10x7, the first ship uses a 7x7 square, leaving a 3x7 strip. The next step involves the 7x3 strip, where 3 fits into 7 twice, making two ships, and so on.

3. **Algorithm**: Using the Euclidean algorithm approach, repeatedly divide the larger dimension by the smaller one, add the quotient (number of ships) to the count, and update the dimensions with the remainder until the remainder becomes zero.

### Solution Code
```python
def main():
    a, b = map(int, input().split())
    count = 0
    while b != 0:
        count += a // b
        a, b = b, a % b
    print(count)

main()
```

### Explanation
1. **Reading Input**: The input consists of two integers `a` and `b` where `a > b`.
2. **Initialization**: Initialize a counter `count` to keep track of the total number of ships.
3. **Loop Until Remainder is Zero**: In each iteration:
   - Add the quotient of `a` divided by `b` to `count` (this gives the number of ships made from the current rectangle).
   - Update `a` to `b` and `b` to the remainder of `a` divided by `b`.
4. **Termination**: The loop terminates when `b` becomes zero, meaning the last piece of paper was a square.
5. **Output**: Print the total count of ships.

This approach efficiently handles large values up to \(10^{12}\) using the properties of the Euclidean algorithm, ensuring a time complexity of \(O(\log(\min(a, b)))\), which is optimal for the given problem constraints.
