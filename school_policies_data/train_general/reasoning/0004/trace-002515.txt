### Approach
1. **Understand the Problem Requirements**: We need two non-negative integers \(a\) and \(b\) such that their sum is \(s\) and their absolute difference is \(d\). The integers must be non-negative and should be output in descending order.
2. **Formulate Equations**: From the problem, we derive two equations:
   - \(a + b = s\)
   - \(|a - b| = d\)
3. **Derive Conditions**:
   - Since \(a\) and \(b\) are non-negative integers, \(s\) must be greater than or equal to \(d\) to ensure non-negative results.
   - The sum \(s + d\) and difference \(s - d\) must both be even. This ensures that \(a\) and \(b\) are integers.
4. **Check Validity**: If the conditions are met, compute \(a\) and \(b\) using the derived formulas. Otherwise, the result is "impossible".

### Solution Code
```python
n = int(input())
for _ in range(n):
    s, d = map(int, input().split())
    if s >= d and (s + d) % 2 == 0:
        a = (s + d) // 2
        b = (s - d) // 2
        print(a, b)
    else:
        print("impossible")
```

1. **Input Handling**: Read the number of test cases.
2. **Loop Through Test Cases**: For each test case, read the sum \(s\) and difference \(d\).
3. **Check Conditions**:
   - Ensure \(s \geq d\) to avoid negative values.
   - Check if \(s + d\) is even to ensure integer results for \(a\) and \(b\).
4. **Compute Results**: If valid, compute \(a\) and \(b\) using integer division and print them in descending order. If invalid, print "impossible".

This approach efficiently checks the necessary conditions and computes the results in constant time \(O(1)\) for each test case, ensuring optimal performance.
