The solution involves efficiently combining cubic and tetrahedral numbers to achieve the highest possible sum that does not exceed the given input value.

### Approach
1. **Precompute Cubic and Tetrahedral Numbers**: 
   - Generate all cubic numbers up to the maximum possible value (151200) using the formula \( n^3 \).
   - Generate all tetrahedral numbers up to the same maximum value using the formula \( \frac{n(n+1)(n+2)}{6} \).

2. **Efficient Search for Maximum Sum**:
   - For each input value, iterate through all possible cubic numbers.
   - For each cubic number, compute the remaining capacity and find the largest tetrahedral number that fits into this remaining capacity using binary search for efficiency.

### Solution Code
```python
import bisect

def hakodate_maru():
    # Precompute all tetrahedral numbers up to 151200
    tetra_list = []
    n = 0
    while True:
        t = n * (n + 1) * (n + 2) // 6
        if t > 151200:
            break
        tetra_list.append(t)
        n += 1

    # Precompute all cubic numbers up to 151200
    cubic_list = []
    n = 0
    while True:
        c = n ** 3
        if c > 151200:
            break
        cubic_list.append(c)
        n += 1

    # Read input and process each case
    import sys
    for line in sys.stdin:
        M = line.strip()
        if not M:
            continue
        M = int(M)
        if M == 0:
            break
        max_sum = 0
        for c in cubic_list:
            if c > M:
                break
            remaining = M - c
            # Find the largest tetrahedral number <= remaining
            idx = bisect.bisect_right(tetra_list, remaining) - 1
            t = tetra_list[idx] if idx >= 0 else 0
            current_sum = c + t
            if current_sum > max_sum:
                max_sum = current_sum
        print(max_sum)
```
