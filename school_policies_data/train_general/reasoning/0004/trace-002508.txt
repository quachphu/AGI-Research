To solve this problem, we need to find the k-th smallest divisor of a given integer n. If n has fewer than k divisors, we should return -1. The solution must efficiently handle large values of n up to 10^15.

### Approach
1. **Divisor Pairs**: Divisors of n come in pairs (d, n/d). For example, if d is a divisor of n, then n/d is also a divisor. This allows us to find divisors by iterating up to the square root of n.
2. **Early Termination**: While iterating up to the square root of n, we collect smaller divisors in a list. If we find the k-th smallest divisor during this iteration, we can immediately return it.
3. **Large Divisors**: For each divisor found (d), we also note its pair (n/d) unless it is a perfect square. These larger divisors are stored in a separate list and reversed to maintain order.
4. **Efficiency**: By iterating up to the square root of n and leveraging divisor pairs, we reduce the complexity to O(sqrt(n)), which is feasible even for large values of n.

### Solution Code
```python
import math

n, k = map(int, input().split())

s_count = 0
large = []

sqrt_n = math.isqrt(n)

for i in range(1, sqrt_n + 1):
    if n % i == 0:
        s_count += 1
        if s_count == k:
            print(i)
            exit()
        j = n // i
        if j != i:
            large.append(j)

total = s_count + len(large)
if k > total:
    print(-1)
else:
    remaining = k - s_count
    print(large[-remaining])
```

### Explanation
1. **Reading Input**: The input values n and k are read.
2. **Iterating Up to Square Root**: We iterate from 1 to the integer square root of n. For each i, if it is a divisor, we increment the count of small divisors. If this count reaches k, we print i and exit immediately.
3. **Storing Large Divisors**: For each divisor i, we compute its pair n/i and add it to the large divisors list if it is not a perfect square.
4. **Checking Total Divisors**: If the total number of divisors (small + large) is less than k, we print -1. Otherwise, we compute the position in the large divisors list and print the corresponding value.

This approach efficiently finds the k-th smallest divisor by leveraging divisor pairs and early termination, ensuring optimal performance even for very large values of n.
