To solve this problem, we need to split a given string into parts of specified lengths p and q. The solution involves checking if such a split is possible and then constructing the split if it is.

### Approach
1. **Check Feasibility**: First, we need to determine if there exist non-negative integers a and b such that the total length of the string can be divided into a parts of length p and b parts of length q. This is done by solving the equation \(a \times p + b \times q = n\).
2. **Iterate to Find Valid (a, b)**: We iterate through possible values of a from 0 to the maximum possible parts of p (n//p). For each a, we check if the remaining length can be divided into parts of q. If so, we compute b and check if it is non-negative.
3. **Construct the Split**: Once valid values of a and b are found, we construct the split by first taking a parts of length p followed by b parts of length q.

### Solution Code
```python
n, p, q = map(int, input().split())
s = input().strip()

found = False
for a in range(n // p + 1):
    remaining = n - a * p
    if remaining < 0:
        continue
    if remaining % q == 0:
        b = remaining // q
        if b >= 0:
            parts = []
            current = 0
            # Add a parts of length p
            for _ in range(a):
                parts.append(s[current:current + p])
                current += p
            # Add b parts of length q
            for _ in range(b):
                parts.append(s[current:current + q])
                current += q
            print(len(parts))
            for part in parts:
                print(part)
            found = True
            break
if not found:
    print(-1)
```

### Explanation
1. **Reading Input**: The input consists of two lines. The first line contains integers n, p, and q, and the second line contains the string s.
2. **Feasibility Check**: We loop through possible values of a (number of parts of length p). For each a, we calculate the remaining length of the string and check if it can be divided into parts of length q.
3. **Constructing the Split**: If valid values of a and b are found, we construct the split by first taking a parts of length p and then b parts of length q. The parts are appended to a list and printed in order.
4. **Output**: If no valid split is found, we print -1. Otherwise, we print the number of parts followed by each part in the order they appear in the string.

This approach ensures that we efficiently check all possible ways to split the string using dynamic programming principles and construct the solution if it exists.
