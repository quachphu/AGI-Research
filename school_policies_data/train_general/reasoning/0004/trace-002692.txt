To solve this problem, we need to compute the size of the power set of a given set with \( N \) elements. The size of the power set is \( 2^N \), which can be very large, so we return the result modulo \( 10^9 + 7 \). Given the constraints, we need an efficient approach to handle very large values of \( N \).

### Approach
1. **Understanding Power Set**: The power set of a set with \( N \) elements contains all possible subsets, including the empty set and the set itself. The size of the power set is \( 2^N \).
2. **Modular Arithmetic**: Since \( 2^N \) can be extremely large for large \( N \), we use modular arithmetic to keep the numbers manageable. Specifically, we compute \( 2^N \mod (10^9 + 7) \).
3. **Efficient Computation**: Direct computation of \( 2^N \) for very large \( N \) (up to \( 10^{15} \)) is infeasible. Instead, we use modular exponentiation (exponentiation by squaring) which efficiently computes \( a^b \mod m \) in \( O(\log b) \) time.

### Solution Code
```python
def main():
    import sys
    MOD = 10**9 + 7
    data = list(map(int, sys.stdin.read().split()))
    T = data[0]
    for n in data[1:T+1]:
        print(pow(2, n, MOD))
        
main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially when dealing with a large number of test cases. This is split into a list of integers.
2. **Processing Each Test Case**: The first integer \( T \) represents the number of test cases. For each subsequent integer \( N \), we compute \( 2^N \mod (10^9 + 7) \) using Python's built-in `pow` function, which efficiently handles modular exponentiation.
3. **Output the Result**: For each test case, the result is printed immediately.

This approach ensures that even for the maximum constraints (e.g., \( N = 10^{15} \)), the solution is computed efficiently and correctly using modular exponentiation. The time complexity for each test case is \( O(\log N) \), making the solution both optimal and scalable.
