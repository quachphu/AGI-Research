To solve this problem, we need to determine the number of distinct messages read when starting from each message in a chat history, considering the visibility window around each message and following any links to previous messages. The goal is to compute this efficiently for all messages.

### Approach
1. **Problem Analysis**: Each message can link to a previous message, forming a chain. When viewing a message, a visibility window of `k` messages before and after it is considered. The challenge is to count the distinct messages read when following these links, considering overlapping windows.

2. **Dynamic Programming Insight**: For each message, the visibility window can be combined with the windows of linked messages. Using dynamic programming, we can track the merged interval (leftmost and rightmost indices) and the count of distinct messages for each message.

3. **Key Steps**:
   - For each message, compute its visibility window.
   - If the message links to another message, merge its window with the linked message's interval.
   - Track the merged interval and adjust the count to account for overlaps.

### Solution Code
```python
import sys

def main():
    n, k = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    
    dp_L = [0] * (n + 1)
    dp_R = [0] * (n + 1)
    dp_count = [0] * (n + 1)
    
    for i in range(1, n + 1):
        x_lo = max(1, i - k)
        x_hi = min(n, i + k)
        ai = a[i - 1]
        if ai == 0:
            dp_L[i] = x_lo
            dp_R[i] = x_hi
            dp_count[i] = x_hi - x_lo + 1
        else:
            j = ai
            a_L = dp_L[j]
            a_R = dp_R[j]
            merged_L = min(x_lo, a_L)
            merged_R = max(x_hi, a_R)
            overlap = max(0, min(x_hi, a_R) - max(x_lo, a_L) + 1)
            dp_count[i] = (x_hi - x_lo + 1) + dp_count[j] - overlap
            dp_L[i] = merged_L
            dp_R[i] = merged_R
    
    print(' '.join(map(str, dp_count[1:])))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Initialization**: Arrays `dp_L`, `dp_R`, and `dp_count` are initialized to store the leftmost index, rightmost index, and count of distinct messages for each message, respectively.

2. **Visibility Window Calculation**: For each message `i`, compute its visibility window (`x_lo` and `x_hi`).

3. **Dynamic Programming Transition**:
   - If the message does not link to another (`ai == 0`), directly set its interval and count.
   - If it links to another message, merge the current window with the linked message's interval, adjust for overlaps, and update the count.

4. **Result Output**: The results for all messages are printed in the required format.

This approach efficiently computes the result using dynamic programming to merge intervals and adjust counts, ensuring an optimal O(n) time complexity.
