To solve this problem, we need to determine the number of valid positions to place a spotlight on a theater stage such that the spotlight cell is empty and there is at least one actor in the direction the spotlight is shining. The directions considered are left, right, up, and down.

### Approach
1. **Precompute Directions**: For each cell in the grid, precompute whether there is at least one actor in each of the four directions (left, right, up, down). This allows us to efficiently check each cell in constant time.
2. **Matrix Construction**:
   - **Left Matrix**: For each row, track if there is an actor to the left of each cell.
   - **Right Matrix**: For each row, track if there is an actor to the right of each cell.
   - **Up Matrix**: For each column, track if there is an actor above each cell.
   - **Down Matrix**: For each column, track if there is an actor below each cell.
3. **Count Valid Positions**: For each empty cell (value 0), count the number of valid directions using the precomputed matrices and sum these counts.

```python
    right.append(r_row)

# Precompute up matrix
up = [[False] * m for _ in range(n)]
for j in range(m):
    has_one = False
    for i in range(n):
        up[i][j] = has_one
        if grid[i][j] == 1:
            has_one = True

# Precompute down matrix
down = [[False] * m for _ in range(n)]
for j in range(m):
    has_one = False
    for i in range(n-1, -1, -1):
        down[i][j] = has_one
        if grid[i][j] == 1:
            has_one = True

# Calculate total good positions
total = 0
for i in range(n):
    for j in range(m):
        if grid[i][j] == 0:
            count = 0
            if left[i][j]:
                count += 1
            if right[i][j]:
                count += 1
            if up[i][j]:
                count += 1
            if down[i][j]:
                count += 1
            total += count

print(total)
```

### Explanation
1. **Matrix Construction**:
   - **Left Matrix**: Iterate each row from left to right, tracking if an actor has been seen to the left of the current cell.
   - **Right Matrix**: Iterate each row from right to left, tracking if an actor has been seen to the right of the current cell.
   - **Up Matrix**: Iterate each column from top to bottom, tracking if an actor has been seen above the current cell.
   - **Down Matrix**: Iterate each column from bottom to top, tracking if an actor has been seen below the current cell.

2. **Counting Valid Positions**: For each cell that is empty (0), check the four precomputed matrices to see how many valid directions there are. Sum these counts to get the total number of valid spotlight positions.

This approach efficiently precomputes necessary information in O(n*m) time and space, making it suitable for large grids up to 1000x1000.
