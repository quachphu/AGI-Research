To solve this problem, we need to determine if every cell in an n×n grid has an even number of adjacent cells containing the character 'o'. Adjacent cells are those that share a side (up, down, left, right).

### Approach
1. **Input Reading**: Read the integer n and the subsequent n lines representing the grid.
2. **Adjacency Check**: For each cell in the grid, check its four possible adjacent cells (up, down, left, right). Ensure these adjacent cells are within the grid boundaries.
3. **Count 'o' Cells**: For each cell, count how many of its adjacent cells contain 'o'.
4. **Even Check**: Verify if the count of adjacent 'o' cells is even for each cell. If any cell has an odd count, immediately output "NO" and terminate. If all cells pass the check, output "YES".

### Solution Code
```python
n = int(input())
grid = [input().strip() for _ in range(n)]

directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]

for i in range(n):
    for j in range(n):
        count = 0
        for di, dj in directions:
            ni, nj = i + di, j + dj
            if 0 <= ni < n and 0 <= nj < n:
                if grid[ni][nj] == 'o':
                    count += 1
        if count % 2 != 0:
            print("NO")
            exit()
print("YES")
```

### Explanation
- **Reading Input**: The grid is read as a list of strings where each string represents a row.
- **Direction Handling**: For each cell, we check its four possible adjacent cells using direction vectors (up, down, left, right).
- **Boundary Check**: Ensure the calculated adjacent cell indices are within the valid range (0 to n-1).
- **Count and Check**: For each cell, count the 'o' in valid adjacent cells. If any count is odd, print "NO" and exit immediately. If all counts are even, print "YES".

This approach efficiently checks each cell once, ensuring the solution runs in O(n²) time complexity, which is optimal for the given constraints (1 ≤ n ≤ 100).
