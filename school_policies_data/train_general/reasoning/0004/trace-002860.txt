To solve this problem, we need to determine if a 2x3 grid remains the same after a 180-degree rotation. This involves checking specific positions in the grid to see if they match the required transformations.

### Approach
A 180-degree rotation of a 2x3 grid means that each element (i, j) in the original grid will move to a new position (3-i, 4-j). For the grid to remain the same after such a rotation, the following conditions must be met:
1. The element at position (1, 1) must be equal to the element at position (2, 3).
2. The element at position (1, 2) must be equal to the element at position (2, 2).
3. The element at position (1, 3) must be equal to the element at position (2, 1).

By checking these three conditions, we can determine if the grid remains unchanged after a 180-degree rotation.

### Solution Code
```python
def main():
    s1 = input().strip()
    s2 = input().strip()
    if s1[0] == s2[2] and s1[1] == s2[1] and s1[2] == s2[0]:
        print("YES")
    else:
        print("NO")

main()
```

### Explanation
1. **Reading Input:** The input consists of two lines, each representing a row of the grid. These lines are read using `input().strip()` to ensure no leading or trailing whitespace.
2. **Checking Conditions:** The conditions checked are:
   - The first character of the first row (`s1[0]`) must match the third character of the second row (`s2[2]`).
   - The second character of the first row (`s1[1]`) must match the second character of the second row (`s2[1]`).
   - The third character of the first row (`s1[2]`) must match the first character of the second row (`s2[0]`).
3. **Output Result:** If all three conditions are satisfied, the program prints "YES"; otherwise, it prints "NO".

This approach efficiently checks the necessary transformations in constant time, ensuring an optimal solution.
