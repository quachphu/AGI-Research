To solve this problem, we need to simulate the room assignment process in a hotel with 10 rooms based on a sequence of events. The events describe customers arriving from either the left or right entrance or leaving a specific room. The goal is to determine the final state of the hotel rooms after processing all events.

### Approach
1. **Initialization**: Start with all 10 rooms empty, represented as a list of zeros.
2. **Event Processing**: For each event in the input string:
   - **Left Entrance ('L')**: Assign the closest empty room from the left (smallest index).
   - **Right Entrance ('R')**: Assign the closest empty room from the right (largest index).
   - **Room Leave (digit)**: Mark the specified room as empty.
3. **Efficiency**: Although the number of events can be large (up to 100,000), each event processing involves checking at most 10 rooms, which is feasible.

### Solution Code
```python
n = int(input())
events = input().strip()

rooms = [0] * 10

for c in events:
    if c == 'L':
        for i in range(10):
            if rooms[i] == 0:
                rooms[i] = 1
                break
    elif c == 'R':
        for i in range(9, -1, -1):
            if rooms[i] == 0:
                rooms[i] = 1
                break
    else:
        x = int(c)
        rooms[x] = 0

print(''.join(map(str, rooms)))
```

### Explanation
1. **Initialization**: The hotel rooms are initialized as a list of 10 zeros.
2. **Processing Each Event**:
   - For 'L', iterate from the left (index 0) to find the first empty room and mark it occupied.
   - For 'R', iterate from the right (index 9) to find the first empty room and mark it occupied.
   - For a digit (0-9), convert it to an integer and mark the corresponding room as empty.
3. **Output**: After processing all events, the final state of the rooms is printed as a concatenated string of 0s and 1s.

This approach efficiently handles up to 100,000 events by leveraging the fixed size of the hotel (10 rooms), ensuring each event is processed in constant time.
