To solve this problem, we need to efficiently handle two types of operations on an array: adding a value to a range of elements and querying the sum of elements in a range. Given the constraints, a naive approach would be too slow, so we use a more efficient data structure called a Binary Indexed Tree (BIT) with a technique to handle range updates and range queries efficiently.

### Approach
1. **Binary Indexed Tree (BIT)**: We use two BITs to handle range updates and range queries. This approach allows us to perform both operations in O(log n) time, which is efficient for the given constraints.
2. **Range Update**: For an update operation `add(s, t, x)`, we adjust the BITs to represent the range update by updating specific indices.
3. **Range Query**: For a query operation `getSum(s, t)`, we compute the sum of elements from the start up to `t` and subtract the sum up to `s-1` to get the result for the range `[s, t]`.

### Solution Code
```python
class BIT:
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (self.n + 2)  # 1-based indexing with extra space

    def add(self, idx, val):
        while idx <= self.n:
            self.tree[idx] += val
            idx += idx & -idx

    def query(self, idx):
        res = 0
        while idx > 0:
            res += self.tree[idx]
            idx -= idx & -idx
        return res

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    q = int(input[ptr])
    ptr += 1

    max_idx = n + 1
    b1 = BIT(max_idx)
    b2 = BIT(max_idx)

    for _ in range(q):
        cmd = int(input[ptr])
        ptr += 1
        s = int(input[ptr])
        ptr += 1
        t = int(input[ptr])
        ptr += 1

        if cmd == 0:
            x = int(input[ptr])
            ptr += 1
            b1.add(s, x)
            b1.add(t + 1, -x)
            b2.add(s, x * (s - 1))
            b2.add(t + 1, -x * t)
        else:
            sum_t = b1.query(t) * t - b2.query(t)
            if s == 1:
                sum_s_1 = 0
            else:
                sum_s_1 = (b1.query(s - 1) * (s - 1)) - b2.query(s - 1)
            print(sum_t - sum_s_1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **BIT Initialization**: Two BITs (`b1` and `b2`) are initialized to handle the range updates and queries. The size of each BIT is set to `n + 1` to accommodate the maximum possible index.
2. **Range Update Handling**: For each `add(s, t, x)` operation, we update `b1` and `b2` at indices `s` and `t + 1` to represent the range increment. This ensures that subsequent queries can efficiently compute the sum over any range.
3. **Range Query Handling**: For each `getSum(s, t)` operation, we compute the sum from the start up to `t` using both BITs and subtract the sum up to `s - 1` to get the result for the range `[s, t]`.

This approach efficiently handles up to 100,000 operations in logarithmic time, making it suitable for large input sizes.
