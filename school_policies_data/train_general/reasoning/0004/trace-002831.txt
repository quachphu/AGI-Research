To solve this problem, we need to determine the number of pairs of wizards whose combined magical power exceeds a given threshold. The solution must efficiently handle up to 20,000 wizards and multiple test cases.

### Approach
1. **Sort the Magical Powers**: Sorting the list of magical powers allows us to use a binary search technique to efficiently find valid pairs.
2. **Binary Search for Valid Pairs**: For each wizard, we use binary search to find the smallest index where the sum of the current wizard's power and the found index's power exceeds the threshold. This reduces the complexity from O(n²) to O(n log n).

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    while True:
        n = int(input[ptr])
        S = int(input[ptr+1])
        ptr += 2
        if n == 0 and S == 0:
            break
        r = []
        for _ in range(n):
            r.append(int(input[ptr]))
            ptr += 1
        r.sort()
        count = 0
        for i in range(n - 1):
            target = S - r[i]
            j = bisect.bisect_right(r, target)
            j = max(j, i + 1)
            if j < n:
                count += (n - j)
        print(count)

main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given multiple test cases.
2. **Sorting**: The list of magical powers is sorted to enable efficient pair searching.
3. **Binary Search**: For each wizard, we calculate the required power to exceed the threshold and use binary search to find the first valid partner. This is done using `bisect.bisect_right` to find the insertion point for the required power, adjusted to ensure we only consider indices greater than the current wizard.
4. **Counting Valid Pairs**: The number of valid pairs starting from the found index to the end of the list is added to the count.

This approach ensures that we efficiently count valid pairs using sorting and binary search, making the solution feasible even for large input sizes.
