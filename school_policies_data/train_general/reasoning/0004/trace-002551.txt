To solve this problem, we need to count the number of special pairs (a, b) such that 1 ≤ a ≤ x and 1 ≤ b ≤ y, where the special condition is defined as ⌊a/b⌋ = a mod b. This problem can be efficiently solved by leveraging mathematical insights and optimizing the summation process.

### Approach
1. **Mathematical Insight**: For a pair (a, b) to be special, there exists a non-negative integer q such that a = q*(b + 1) and 0 ≤ q < b. This leads to the condition that q must be in the range [1, b-1] and a must be ≤ x.
2. **Summation Split**: The summation to count valid pairs can be split into two parts:
   - **Part 1**: For values of b up to √(x + 1), we directly sum the valid q values.
   - **Part 2**: For larger values of b, we sum the integer division results using an optimized approach to avoid iterating each value individually.
3. **Efficient Summation**: Using mathematical techniques, we compute the sum of integer divisions over ranges efficiently by grouping values that yield the same result.

### Solution Code
```python
import math

def compute_sum(x, n):
    if n == 0:
        return 0
    m_val = int(math.isqrt(x))
    total = 0
    k_limit = min(m_val, n)
    for k in range(1, k_limit + 1):
        total += x // k
    for q in range(1, m_val + 1):
        low = (x // (q + 1)) + 1
        high = x // q
        low = max(low, m_val + 1)
        high = min(high, n)
        if high >= low:
            total += q * (high - low + 1)
    return total

t = int(input())
for _ in range(t):
    x, y = map(int, input().split())
    m = int(math.isqrt(x + 1))
    m = min(m, y)
    sum_part1 = m * (m - 1) // 2
    sum_part2 = 0
    if m + 1 <= y:
        upper_k = y + 1
        lower_k = m + 2  # since b starts from m+1, k = b+1 starts from m+2
        sum_upper = compute_sum(x, upper_k)
        sum_lower = compute_sum(x, lower_k - 1)  # sum up to lower_k -1
        sum_part2 = sum_upper - sum_lower
    total = sum_part1 + sum_part2
    print(total)
```

1. **Mathematical Insight**: The condition ⌊a/b⌋ = a mod b translates to a = q*(b + 1) where q is the quotient and remainder. This insight allows us to reframe the problem in terms of q and b.
2. **Summation Split**: By splitting the problem into two parts based on the value of b, we handle smaller values of b directly and larger values using an optimized summation technique.
3. **Efficient Summation**: The `compute_sum` function efficiently calculates the sum of integer divisions over a range by leveraging the fact that ranges of values yield the same quotient, thus reducing the number of computations needed.

This approach ensures that we handle large values efficiently, making the solution feasible even for the upper limits of the input constraints.
