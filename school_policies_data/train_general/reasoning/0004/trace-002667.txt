To solve this problem, we need to transform Ivan's array into a permutation of numbers from 1 to n with the minimum number of changes. Among all possible permutations with the minimum changes, we need the lexicographically smallest one.

### Approach
1. **Identify Missing Numbers**: First, determine which numbers from 1 to n are missing in the array. These missing numbers will be used to replace duplicates in the array.
2. **Track Duplicates**: Count the occurrences of each number in the array. Numbers with more than one occurrence are considered duplicates and need to be replaced.
3. **Replace Duplicates**: Iterate through the array and replace duplicates with the smallest available missing number if it results in a lexicographically smaller permutation. If the smallest missing number is larger than the current element, replace the duplicates starting from the latest occurrences to maintain the smallest possible lex order.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))

count = [0] * (n + 1)
for num in a:
    count[num] += 1

missing = []
for x in range(1, n + 1):
    if count[x] == 0:
        missing.append(x)

m_ptr = 0
used = [False] * (n + 1)
result = []

for x in a:
    if count[x] > 1:
        if m_ptr < len(missing) and missing[m_ptr] < x:
            result.append(missing[m_ptr])
            count[x] -= 1
            m_ptr += 1
        else:
            if not used[x]:
                result.append(x)
                used[x] = True
            else:
                result.append(missing[m_ptr])
                count[x] -= 1
                m_ptr += 1
    else:
        result.append(x)
        if not used[x]:
            used[x] = True

print(len(missing))
print(' '.join(map(str, result)))
```

### Explanation
1. **Identify Missing Numbers**: We iterate through numbers 1 to n and collect those that have zero occurrences in the array.
2. **Track Duplicates**: Using a count array, we track how many times each number appears in the original array.
3. **Replace Duplicates**: As we iterate through the original array, we check if the current element is a duplicate. If it is, we replace it with the smallest available missing number if that number is smaller than the current element. If the missing number is larger, we keep the first occurrence of the duplicate and replace subsequent occurrences with the smallest remaining missing numbers.

This approach ensures that we make the minimum number of changes while achieving the lexicographically smallest permutation. The solution efficiently processes the array in linear time, making it suitable for large input sizes up to 200,000 elements.
