To solve this problem, we need to find the longest possible "Lucky string" that can be formed from a given string by removing the minimum number of characters. A Lucky string is defined as a string composed of `m` consecutive 'R's followed by `m` consecutive 'K's, where `m` is a non-negative integer. The goal is to determine the maximum length of such a Lucky string for each test case.

### Approach
1. **Prefix and Suffix Arrays**: 
   - **Prefix Array (`prefix_r`)**: This array keeps track of the cumulative count of 'R's up to each position in the string.
   - **Suffix Array (`suffix_k`)**: This array keeps track of the cumulative count of 'K's from each position to the end of the string.

2. **Split Point Analysis**:
   - For each possible split point in the string (from the start to the end), calculate the number of 'R's before the split and the number of 'K's after the split. The minimum of these two values gives the maximum possible `m` for that split point.
   - The result for each split point is `2 * m`, and the maximum result across all split points is the answer for that test case.

### Solution Code
```python
import sys

def find_longest_lucky_string():
    input = sys.stdin.read().split()
    T = int(input[0])
    cases = input[1:T+1]
    
    for s in cases:
        n = len(s)
        prefix_r = [0] * (n + 1)
        for i in range(1, n + 1):
            prefix_r[i] = prefix_r[i-1] + (1 if s[i-1] == 'R' else 0)
        
        suffix_k = [0] * (n + 1)
        for i in range(n-1, -1, -1):
            suffix_k[i] = suffix_k[i+1] + (1 if s[i] == 'K' else 0)
        
        max_m = 0
        for i in range(n + 1):
            current = min(prefix_r[i], suffix_k[i])
            if current > max_m:
                max_m = current
        
        print(2 * max_m)

find_longest_lucky_string()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into individual test cases.
2. **Prefix Array Calculation**: The prefix array `prefix_r` is constructed where each element at index `i` represents the count of 'R's from the start of the string up to (but not including) index `i`.
3. **Suffix Array Calculation**: The suffix array `suffix_k` is constructed where each element at index `i` represents the count of 'K's from index `i` to the end of the string.
4. **Evaluating Split Points**: For each possible split point (from 0 to the length of the string), the maximum possible `m` is determined by taking the minimum of the 'R' count up to the split and the 'K' count after the split. The maximum value of `2 * m` across all split points is the result for that test case.

This approach efficiently computes the required values using linear time complexity for both prefix and suffix array constructions, ensuring the solution handles the upper constraint limits effectively.
