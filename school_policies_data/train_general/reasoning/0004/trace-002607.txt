To solve this problem, we need to determine if there exist two integers \( x \) and \( y \) such that \( l \leq x < y \leq r \) and the least common multiple (LCM) of \( x \) and \( y \) lies within the range \([l, r]\). If such a pair exists, we should print any valid pair; otherwise, print -1 -1.

### Approach
The key insight to solve this problem efficiently is to recognize that if \( 2 \times l \leq r \), then the pair \((l, 2 \times l)\) is always valid. This is because the LCM of \( l \) and \( 2 \times l \) is \( 2 \times l \), which is guaranteed to be within the range \([l, r]\) if \( 2 \times l \leq r \). If \( 2 \times l \) exceeds \( r \), it is impossible to find such a pair, and we should return -1 -1.

### Solution Code
```python
import sys

t = int(sys.stdin.readline())
for _ in range(t):
    l, r = map(int, sys.stdin.readline().split())
    if 2 * l <= r:
        print(l, 2 * l)
    else:
        print(-1, -1)
```

### Explanation
1. **Reading Input:** The code reads the number of test cases \( t \) and processes each test case by reading the values \( l \) and \( r \).
2. **Check Condition:** For each test case, it checks if \( 2 \times l \) is less than or equal to \( r \). If true, it prints \( l \) and \( 2 \times l \) as the valid pair. This is because the LCM of \( l \) and \( 2 \times l \) is \( 2 \times l \), which is within the required range.
3. **Handle Impossibility:** If \( 2 \times l \) exceeds \( r \), it prints -1 -1, indicating no valid pair exists.

This approach ensures that we efficiently determine the existence of a valid pair in constant time \( O(1) \) per test case, making the solution scalable even for large input sizes.
