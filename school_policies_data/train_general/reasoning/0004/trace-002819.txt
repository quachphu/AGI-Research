To solve this problem, we need to determine the minimum distance from the origin (0, 0, 0) to the center of mass of a swarm of fireflies at any time t ≥ 0. Each firefly moves with a constant velocity, and we need to compute the closest approach of the swarm's center of mass to the origin.

### Approach
1. **Understanding the Center of Mass**: The center of mass (COM) of the swarm at any time t is given by the average position of all fireflies at that time. Each firefly's position at time t is determined by its initial position and constant velocity.

2. **Formulating the Problem**: The position of the COM at time t can be expressed as a linear function of t. We need to find the time t that minimizes the distance from the COM to the origin. This involves solving a quadratic equation derived from the squared distance formula.

3. **Quadratic Minimization**: The squared distance from the origin to the COM is a quadratic function in terms of t. The minimum value of this quadratic function (if it occurs at t ≥ 0) gives the minimum distance. If the minimum occurs at a negative t, the minimum distance is at t = 0.

4. **Special Cases**: If the velocity of the COM is zero, the distance remains constant over time, and the minimum distance is simply the initial distance.

### Solution Code
```python
import math

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for case in range(1, T + 1):
        N = int(input[ptr])
        ptr += 1
        sum_x = sum_y = sum_z = 0
        sum_vx = sum_vy = sum_vz = 0
        for _ in range(N):
            x = int(input[ptr])
            y = int(input[ptr + 1])
            z = int(input[ptr + 2])
            vx = int(input[ptr + 3])
            vy = int(input[ptr + 4])
            vz = int(input[ptr + 5])
            ptr += 6
            sum_x += x
            sum_y += y
            sum_z += z
            sum_vx += vx
            sum_vy += vy
            sum_vz += vz
        sum_av = sum_x * sum_vx + sum_y * sum_vy + sum_z * sum_vz
        sum_v_squared = sum_vx ** 2 + sum_vy ** 2 + sum_vz ** 2
        if sum_v_squared == 0:
            x_center = sum_x / N
            y_center = sum_y / N
            z_center = sum_z / N
            dmin = math.hypot(x_center, y_center, z_center)
            tmin = 0.0
        else:
            t_vertex = (-sum_av) / sum_v_squared
            if t_vertex < 0:
                x_center = sum_x / N
                y_center = sum_y / N
                z_center = sum_z / N
                dmin = math.hypot(x_center, y_center, z_center)
                tmin = 0.0
            else:
                x = (sum_x + sum_vx * t_vertex) / N
                y = (sum_y + sum_vy * t_vertex) / N
                z = (sum_z + sum_vz * t_vertex) / N
                dmin = math.hypot(x, y, z)
                tmin = t_vertex
        print("Case #{}: {:.8f} {:.8f}".format(case, dmin, tmin))

if __name__ == '__main__':
    main()
```

2. **Summing Values**: The sums of positions and velocities across all fireflies are computed.

4. **Special Case Handling**: If the velocity of the COM is zero, the distance is computed directly from the initial position.
5. **Vertex Calculation**: The vertex of the quadratic function is calculated to find the minimum distance. If the vertex time is negative, the minimum distance is at t = 0.
