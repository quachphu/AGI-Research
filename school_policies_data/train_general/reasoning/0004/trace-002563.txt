To solve this problem, we need to generate an activation code based on a given five-digit number by following a specific algorithm involving shuffling digits and mathematical operations. Let's break down the approach and solution step-by-step.

### Approach
1. **Shuffle the Digits**: Rearrange the digits of the input number according to the specified order: first, third, fifth, fourth, and then the second digit.
2. **Compute the Fifth Power**: Raise the shuffled number to the fifth power.
3. **Extract Last Five Digits**: Take the last five digits of the result from the fifth power computation. This is done using modulo 100000 to handle large numbers efficiently.
4. **Format the Result**: Ensure the result is formatted as a five-digit string, padding with leading zeros if necessary.

### Solution Code
```python
s = input().strip()
shuffled = s[0] + s[2] + s[4] + s[3] + s[1]
new_num = int(shuffled)
activation = (new_num ** 5) % 100000
print(f"{activation:05}")
```

### Explanation
1. **Reading Input**: The input is read as a string to facilitate easy extraction of individual digits.
2. **Shuffling Digits**: The digits are rearranged according to the specified order (positions 0, 2, 4, 3, 1 in zero-based indexing) to form a new number.
3. **Conversion and Exponentiation**: The shuffled string is converted to an integer and then raised to the fifth power.
4. **Modulo Operation**: The result of the exponentiation is reduced modulo 100000 to get the last five digits.
5. **Formatting**: The result is formatted to ensure it is always five digits long, using leading zeros if necessary.

This approach efficiently handles the problem constraints and ensures correctness for all valid five-digit input values.
