To solve this problem, we need to distribute candies among kids such that the maximum number of candies is given while satisfying two conditions: the difference between the maximum and minimum candies any kid receives is at most 1, and the number of kids receiving the higher number of candies does not exceed half the total number of kids (rounded down).

### Approach
1. **Understanding the Constraints**: 
   - The difference between the maximum and minimum candies given to any kid must be at most 1.
   - The number of kids receiving the higher number of candies (if any) must not exceed half the total number of kids.

2. **Key Insight**:
   - To maximize the number of candies given, we first determine the base number of candies each kid can receive (denoted as `x`), which is the integer division of total candies by the number of kids.
   - The remainder from this division tells us how many extra candies we can distribute. However, we can only give these extra candies to up to half the number of kids (rounded down).

3. **Algorithm**:
   - For each test case, compute the base number of candies per kid (`x`) using integer division.
   - Calculate the remainder when total candies are divided by the number of kids.
   - Determine the maximum number of kids that can receive an extra candy, which is the minimum of the remainder and half the number of kids (rounded down).
   - The total number of candies distributed is the sum of the base candies for all kids and the extra candies distributed.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    x = n // k
    rem = n % k
    m = min(rem, k // 2)
    print(x * k + m)
```

### Explanation
- **Base Candies Calculation**: The integer division of `n` by `k` gives the maximum number of candies each kid can get such that distributing this number to all kids does not exceed the total candies.
- **Remainder Handling**: The remainder from the division tells us how many candies are left after distributing the base amount. These can be distributed as extra candies.
- **Extra Candies Distribution**: The number of kids who can receive an extra candy is limited to half the total number of kids (rounded down). This ensures the constraints are met.

This approach efficiently computes the maximum number of candies that can be distributed while adhering to the problem constraints, ensuring optimal performance even for large input sizes.
