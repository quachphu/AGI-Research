To solve this problem, we need to determine the maximum possible binary number that can be obtained by deleting exactly one digit from the given binary string. The solution involves identifying the optimal digit to remove to maximize the resulting number.

### Approach
1. **Identify the Optimal Deletion**: The key insight is that a binary number is maximized when the leftmost possible digit is 1, and subsequent digits are as large as possible. Therefore, we should look for the first occurrence where a digit is followed by a larger digit (i.e., '0' followed by '1'). Removing the '0' in this case results in a larger number.
2. **Handle Non-Increasing Sequences**: If the entire string is non-increasing (e.g., '1110'), the optimal deletion is the last digit, as this will remove the smallest value digit.

### Solution Code
```python
s = input().strip()

for i in range(len(s) - 1):
    if s[i] < s[i+1]:
        print(s[:i] + s[i+1:])
        exit()
print(s[:-1])
```

### Explanation
1. **Reading Input**: The input binary string is read and stripped of any leading/trailing whitespace.
2. **Loop Through Digits**: We iterate through each digit of the string (except the last one) to check if the current digit is smaller than the next digit.
3. **Check for Optimal Deletion**: If we find a digit that is smaller than the next digit, we remove the current digit and immediately print the resulting string. This ensures the largest possible number by promoting a higher digit to a more significant position.
4. **Handle Non-Increasing Case**: If no such pair is found, the string is non-increasing, and we remove the last digit to get the largest possible number.

This approach efficiently finds the optimal digit to remove in O(n) time, where n is the length of the binary string, ensuring it handles the maximum constraints effectively.
