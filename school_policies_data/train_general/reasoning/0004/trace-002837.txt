To solve this problem, we need to efficiently handle two types of queries on permutations of integers. The first type of query requires counting the intersection of values in specified ranges of two permutations, while the second type involves swapping elements in one of the permutations. The solution must efficiently manage dynamic updates and range queries to handle large input sizes within acceptable time limits.

### Approach
1. **Data Structures**: Use dictionaries to track the positions of elements in both permutations. This allows quick lookups and updates when elements are swapped.
2. **Handling Queries**: For each query of the first type, determine which of the two ranges (from the first permutation or the second) is smaller. Iterate through the elements of the smaller range and check if they fall within the specified range of the other permutation. This minimizes the number of checks required and leverages the efficiency of dictionary lookups.
3. **Efficiency**: By iterating through the smaller range for each query, the solution ensures that each query is processed in linear time relative to the size of the smaller range, which helps manage performance for large input sizes.

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    m = int(input[ptr])
    ptr += 1

    a = list(map(int, input[ptr:ptr + n]))
    ptr += n

    # Read permutation b
    b = list(map(int, input[ptr:ptr + n]))
    ptr += n

    # Precompute pos_a: element -> its position in a (1-based)
    pos_a = [0] * (n + 1)  # elements are 1-based
    for idx, num in enumerate(a):
        pos_a[num] = idx + 1  # positions are 1-based

    # Initialize pos_b and maintain the current b array
    pos_b = [0] * (n + 1)
    for idx, num in enumerate(b):
        pos_b[num] = idx + 1

    # Keep track of the current b array to slice elements for queries
    current_b = b.copy()

    output = []

    for _ in range(m):
        query = input[ptr]
        ptr += 1
        if query == '1':
            la = int(input[ptr])
            ptr += 1
            ra = int(input[ptr])
            ptr += 1
            lb = int(input[ptr])
            ptr += 1
            rb = int(input[ptr])
            ptr += 1

            sa = ra - la + 1
            sb = rb - lb + 1

            count = 0

            if sa <= sb:
                # Iterate through a's segment
                elements = a[la-1 : ra]
                for x in elements:
                    if lb <= pos_b[x] <= rb:
                        count += 1
            else:
                # Iterate through b's segment
                elements = current_b[lb-1 : rb]
                for x in elements:
                    if la <= pos_a[x] <= ra:
                        count += 1

            output.append(str(count))
        else:
            x = int(input[ptr]) - 1  # converting to 0-based index
            ptr += 1
            y = int(input[ptr]) - 1
            ptr += 1

            # Swap x and y in current_b (0-based)
            u = current_b[x]
            v = current_b[y]

            current_b[x], current_b[y] = v, u

            # Update pos_b for u and v
            pos_b[u] = y + 1  # positions are 1-based
            pos_b[v] = x + 1

    print('\n'.join(output))

if __name__ == '__main__':
    main()
