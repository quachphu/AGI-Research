To solve this problem, we need to determine the minimum total price of two different bells that Snuke can buy. The store offers three types of bells with prices given as three integers. Our task is to find the minimum sum of any two different bells.

### Approach
1. **Input Reading**: Read the three integers representing the prices of the three bells.
2. **Sum Calculation**: Calculate the sum of each possible pair of different bells. The possible pairs are (a, b), (a, c), and (b, c).
3. **Minimum Sum Determination**: Determine the minimum value among the three calculated sums.

This approach ensures that we check all possible combinations of two different bells and find the minimum cost efficiently.

### Solution Code
```python
a, b, c = map(int, input().split())
print(min(a + b, a + c, b + c))
```

### Explanation
1. **Reading Input**: The input is read as a single line of three space-separated integers, which are split and converted into integers using `map(int, input().split())`.
2. **Calculating Sums**: We compute the sum of each possible pair of different bells: `a + b`, `a + c`, and `b + c`.
3. **Finding Minimum**: Using Python's built-in `min` function, we find the smallest value among the three sums and print it.

This solution efficiently checks all pairs and ensures that we get the minimum possible cost for two different bells, adhering to the problem constraints and requirements.
