To solve this problem, we need to calculate the total expenses for purchasing items based on the given quantity and price per item. A discount of 10% is applied if the quantity purchased exceeds 1000. The solution involves reading multiple test cases, computing the total cost for each case, and formatting the output to six decimal places.

### Approach
1. **Read Input:** The first input is an integer T, representing the number of test cases. Each subsequent line contains two integers: quantity and price.
2. **Calculate Total Cost:** For each test case, compute the total cost by multiplying the quantity by the price. If the quantity exceeds 1000, apply a 10% discount to the total cost.
3. **Format Output:** Print the total cost for each test case formatted to six decimal places.

### Solution Code
```python
def calculate_expenses():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    idx = 1
    for _ in range(t):
        quantity = int(input[idx])
        price = int(input[idx + 1])
        idx += 2
        total = quantity * price
        if quantity > 1000:
            total *= 0.9
        print("{0:.6f}".format(total))

calculate_expenses()
```

### Explanation
1. **Reading Input:** The input is read all at once and split into a list of strings for efficient processing. The first element of this list is the number of test cases, T.
2. **Processing Each Test Case:** For each test case, we extract the quantity and price from the input list. The total cost is calculated by multiplying these two values. If the quantity is greater than 1000, a 10% discount is applied by multiplying the total cost by 0.9.
3. **Formatting and Output:** The result for each test case is formatted to ensure six decimal places using Python's string formatting method. This ensures consistent output even when the result is an integer, which will be displayed with trailing zeros.

This approach efficiently handles up to 1000 test cases and large values for quantity and price, ensuring accuracy and correct formatting of the output.
