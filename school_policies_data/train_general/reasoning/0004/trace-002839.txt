   - The goal is to move from the first column to the last, adjusting each column's height as needed to meet the height difference constraint with the next column.

2. **Key Insights**:
   - For each column, adjust its height to the minimum required to move to the next column, maximizing the blocks collected for future use.
   - If the current column's height is too high, remove excess blocks and add them to the bag.
   - If the current column's height is too low, use blocks from the bag to raise it to the required minimum.

3. **Algorithm**:
   - For each test case, iterate through each column from the first to the second last.
   - For each column, calculate the minimum and maximum allowed heights based on the next column's height.
   - Adjust the current column's height by either removing excess blocks or adding blocks from the bag, ensuring the height difference constraint is met.
   - Track the number of blocks in the bag and check feasibility at each step.

```python
def solve():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        m = int(input[ptr + 1])
        k = int(input[ptr + 2])
        ptr += 3
        h = list(map(int, input[ptr:ptr + n]))
        ptr += n
        if n == 1:
            print("YES")
            continue
        possible = True
        for i in range(n - 1):
            current_h = h[i]
            next_h = h[i + 1]
            min_allowed = max(0, next_h - k)
            max_allowed = next_h + k
            if current_h > max_allowed:
                removed = current_h - max_allowed
                m += removed
                current_h = max_allowed
            elif current_h < min_allowed:
                needed = min_allowed - current_h
                if m >= needed:
                    m -= needed
                    current_h = min_allowed
                else:
                    possible = False
                    break
            else:
                removed = current_h - min_allowed
                m += removed
                current_h = min_allowed
        print("YES" if possible else "NO")

solve()
```

- **Iterating Through Columns**: For each column, we determine the minimum and maximum allowed heights based on the next column. We adjust the current column's height by either removing excess blocks (adding to the bag) or adding blocks from the bag (if possible).
- **Feasibility Check**: If at any point we can't adjust the current column's height to meet the required constraints, we mark the test case as impossible.
