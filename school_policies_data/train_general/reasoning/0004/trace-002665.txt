To solve this problem, we need to determine the minimum distance from any non-storage city to the nearest storage city. Masha can only open her bakery in a city that does not have a storage, and she wants to minimize the delivery cost from the nearest storage.

### Approach
1. **Input Handling**: Read the number of cities, roads, and storages. If there are no storages, immediately return -1 since Masha cannot open a bakery.
2. **Graph Construction**: Build an adjacency list to represent the cities and roads.
3. **Multi-source Shortest Path**: Use a modified Dijkstra's algorithm starting from all storage cities simultaneously. This allows us to compute the shortest path from any storage city to all other cities efficiently.
4. **Distance Calculation**: After computing the shortest paths from all storages, iterate through each non-storage city to find the minimum distance to any storage city. If no valid city is found, return -1.

### Solution Code
```python
import heapq

def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    ptr = 0
    n = int(data[ptr])
    ptr += 1
    m = int(data[ptr])
    ptr += 1
    k = int(data[ptr])
    ptr += 1

    if k == 0:
        print(-1)
        return

    adj = [[] for _ in range(n + 1)]  # 1-based indexing

    for _ in range(m):
        u = int(data[ptr])
        ptr += 1
        v = int(data[ptr])
        ptr += 1
        l = int(data[ptr])
        ptr += 1
        adj[u].append((v, l))
        adj[v].append((u, l))

    storages = list(map(int, data[ptr:ptr + k]))
    ptr += k
    storage_set = set(storages)

    if len(storage_set) == n:
        print(-1)
        return

    INF = float('inf')
    dist = [INF] * (n + 1)
    heap = []

    for s in storage_set:
        dist[s] = 0
        heapq.heappush(heap, (0, s))

    while heap:
        d, u = heapq.heappop(heap)
        if d > dist[u]:
            continue
        for v, l in adj[u]:
            if dist[v] > d + l:
                dist[v] = d + l
                heapq.heappush(heap, (dist[v], v))

    min_dist = INF
    for city in range(1, n + 1):
        if city not in storage_set:
            if dist[city] < min_dist:
                min_dist = dist[city]

    print(min_dist if min_dist != INF else -1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Graph Construction**: The adjacency list `adj` is built to represent the roads between cities.
2. **Multi-source Dijkstra's Algorithm**: Initialize the priority queue with all storage cities, each having a distance of 0. This allows the algorithm to simultaneously explore the shortest paths from all storage cities, ensuring that each node's shortest path from the nearest storage is found efficiently.
3. **Distance Calculation**: After processing all nodes, check each non-storage city's shortest path to any storage. The minimum of these values is the result, or -1 if no valid path exists.

This approach efficiently handles the constraints and ensures that we find the optimal solution using Dijkstra's algorithm adapted for multiple sources.
