To solve this problem, we need to create a Python program that determines the output based on the age input provided. The program should either print "Hello World" or the sum of two integers, depending on the age specified.

### Approach
1. **Read the Input**: The first input line will determine the age, which can either be 1 or 2.
2. **Condition Check**: 
   - If the age (N) is 1, the program should immediately print "Hello World".
   - If the age (N) is 2, the program will then read two additional integers from the input and print their sum.
3. **Handling Input**: For the case where N is 2, read the next two lines as integers and compute their sum.

### Solution Code
```python
def main():
    n = int(input())
    if n == 1:
        print("Hello World")
    else:
        a = int(input())
        b = int(input())
        print(a + b)

main()
```

### Explanation
1. **Reading Input**: The program starts by reading the first line of input, which is converted to an integer to determine the age (N).
2. **Conditional Execution**: 
   - If N is 1, the program prints "Hello World" directly.
   - If N is 2, the program proceeds to read the next two lines of input as integers A and B. These integers are then summed and the result is printed.
3. **Function Call**: The `main()` function is called to execute the program, ensuring that the input is processed and the correct output is generated based on the given conditions.

This approach efficiently handles both possible cases for N with clear and concise code, ensuring the correct output is produced based on the problem's requirements.
