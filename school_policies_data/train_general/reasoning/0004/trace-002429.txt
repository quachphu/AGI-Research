To solve this problem, we need to determine the minimum possible sum of flight times for a route that involves visiting three airports in sequence using two flights. The flights can be between any pair of airports, and the goal is to find the shortest possible travel time.

### Approach
The problem can be broken down into the following steps:
1. **Understand the Flight Connections**: Each pair of airports (A-B, B-C, and C-A) has a specific flight time in both directions.
2. **Identify Possible Routes**: Since the route must involve three distinct airports, the possible routes are those that use two different flight connections. The possible sums of flight times are combinations of two different flight times.
3. **Calculate Possible Sums**: The possible sums of flight times are the sums of each pair of flight times: P+Q (A-B to B-C), Q+R (B-C to C-A), and R+P (C-A to A-B).
4. **Determine the Minimum Sum**: The minimum sum is the smallest value among the three calculated sums.

### Solution Code
```python
def main():
    P, Q, R = map(int, input().split())
    print(min(P + Q, Q + R, R + P))

main()
```

### Explanation
1. **Reading Input**: The input consists of three integers representing the flight times between the pairs of airports (P, Q, R).
2. **Calculating Sums**: We compute the sums of each pair of flight times. These sums are P+Q, Q+R, and R+P.
3. **Finding the Minimum**: The `min` function is used to determine the smallest value among the three computed sums, which gives the minimum possible travel time for the required route.

This approach efficiently computes the result in constant time, O(1), since it involves a fixed number of arithmetic operations and comparisons. The solution is optimal and handles all constraints effectively.
