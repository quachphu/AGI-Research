To solve this problem, we need to determine the maximum number of lucky tickets Vasya can restore by gluing pairs of ticket pieces. A lucky ticket is defined as a number formed by concatenating two pieces in any order, resulting in a number divisible by 3.

### Approach
1. **Digit Sum Modulo 3**: For each piece, compute the sum of its digits and take the result modulo 3. This gives us one of three possible remainders: 0, 1, or 2.
2. **Count Remainders**: Count how many pieces fall into each of the three remainder categories (0, 1, 2).
3. **Form Valid Pairs**: 
   - Pieces with remainder 0 can be paired among themselves. The number of such pairs is `count[0] // 2`.
   - Pieces with remainder 1 can be paired with pieces with remainder 2. The number of such pairs is the minimum of `count[1]` and `count[2]`.

The maximum number of valid pairs is the sum of the pairs formed from the above two steps.

### Solution Code
```python
n = int(input())
pieces = input().split()

count = [0, 0, 0]  # count for mod 0, 1, 2

for p in pieces:
    digit_sum = sum(int(c) for c in p)
    mod = digit_sum % 3
    count[mod] += 1

max_pairs = (count[0] // 2) + min(count[1], count[2])
print(max_pairs)
```

### Explanation
1. **Reading Input**: The input consists of the number of pieces and the pieces themselves. Each piece is read as a string to facilitate digit sum calculation.
2. **Digit Sum Calculation**: For each piece, convert each character to an integer, sum them, and take modulo 3 of the sum.
3. **Counting Remainders**: Track how many pieces fall into each of the three remainder categories.
4. **Forming Pairs**: 
   - Use integer division to determine how many pairs can be formed from pieces with remainder 0.
   - Use the minimum of the counts of remainders 1 and 2 to determine how many pairs can be formed between these two groups.
5. **Output Result**: The sum of the valid pairs gives the maximum number of lucky tickets Vasya can restore.

This approach efficiently categorizes the pieces and uses simple arithmetic to determine the maximum number of valid pairs, ensuring optimal performance even for the upper constraint of 10,000 pieces.
