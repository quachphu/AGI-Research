To solve this problem, we need to determine the earliest time the polar bears can reach their destination using the given wind directions. The boat can either move in the direction of the wind or stay anchored. The solution involves tracking the required movements in each direction and checking if they can be achieved using the given wind sequence.

### Approach
1. **Calculate Required Movements**: Determine the required steps needed in each cardinal direction (east, west, north, south) based on the starting and ending coordinates.
2. **Track Movements**: Iterate through each wind direction in sequence, accumulating the steps taken in each required direction.
3. **Check Completion**: After processing each wind direction, check if all required movements have been met. If so, return the current time step. If not, continue until all directions are processed.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    sx = int(input[1])
    sy = int(input[2])
    ex = int(input[3])
    ey = int(input[4])
    wind = input[5]

    dx = ex - sx
    dy = ey - sy

    req_e = max(dx, 0)
    req_w = max(-dx, 0)
    req_n = max(dy, 0)
    req_s = max(-dy, 0)

    current_e = current_w = current_n = current_s = 0

    for i in range(len(wind)):
        c = wind[i]
        if c == 'E' and current_e < req_e:
            current_e += 1
        elif c == 'W' and current_w < req_w:
            current_w += 1
        elif c == 'N' and current_n < req_n:
            current_n += 1
        elif c == 'S' and current_s < req_s:
            current_s += 1

        if (current_e >= req_e and current_w >= req_w and
            current_n >= req_n and current_s >= req_s):
            print(i + 1)
            return
    print(-1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Input Reading**: The input is read and parsed into the number of seconds, starting and ending coordinates, and the wind directions.
2. **Movement Calculation**: The differences in x (dx) and y (dy) coordinates between the start and end points are computed. Based on these differences, the required steps in each direction (east, west, north, south) are determined.
3. **Wind Direction Processing**: For each wind direction, the code checks if it contributes to any of the required movements. If so, the corresponding movement counter is incremented.
4. **Completion Check**: After each wind direction is processed, the code checks if all required movements have been met. If they have, the current time step (1-based) is printed and the program exits. If all directions are processed without meeting the requirements, -1 is printed.

This approach ensures that we efficiently track the necessary movements and determine the earliest possible time to reach the destination using the given wind sequence.
