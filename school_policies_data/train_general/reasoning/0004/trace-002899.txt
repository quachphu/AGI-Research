To solve this problem, we need to remove characters from a string whose ASCII values are prime numbers. If all characters are removed, we should output "NULL". The solution involves efficiently checking for prime ASCII values using a precomputed set of primes.

### Approach
1. **Precompute Prime Numbers**: Use the Sieve of Eratosthenes algorithm to generate all prime numbers up to 122 (the maximum ASCII value for lowercase letters). This allows for O(1) prime checks.
2. **Process Each Test Case**: For each input string, check each character's ASCII value against the precomputed primes. Collect characters that do not have prime ASCII values.
3. **Output the Result**: If the resulting string is empty, output "NULL"; otherwise, output the processed string.

### Solution Code
```python
import sys

def generate_primes():
    max_num = 122
    sieve = [True] * (max_num + 1)
    sieve[0] = sieve[1] = False
    for current in range(2, int(max_num ** 0.5) + 1):
        if sieve[current]:
            for multiple in range(current * current, max_num + 1, current):
                sieve[multiple] = False
    primes = {i for i, is_prime in enumerate(sieve) if is_prime}
    return primes

def main():
    primes = generate_primes()
    t = int(sys.stdin.readline())
    for _ in range(t):
        s = sys.stdin.readline().strip()
        res = [c for c in s if ord(c) not in primes]
        print('NULL' if not res else ''.join(res))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prime Generation**: The `generate_primes` function uses the Sieve of Eratosthenes to efficiently generate all prime numbers up to 122. This is done once at the start and stored in a set for quick lookup.
2. **Input Handling**: The `main` function reads the number of test cases and processes each string. For each character in the string, it checks if the ASCII value is a prime using the precomputed set.
3. **Result Construction**: Characters that are not prime are collected into a list. If this list is empty, "NULL" is printed; otherwise, the characters are joined into a string and printed.

This approach ensures efficient prime checking and handles large input sizes within acceptable time limits.
