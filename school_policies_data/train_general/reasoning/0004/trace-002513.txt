To solve this problem, we need to determine the maximum possible noise generated by a robot vacuum cleaner by optimally ordering a sequence of strings. The noise is defined as the number of "sh" subsequences in the concatenated string. 

### Approach
1. **Internal Noise Calculation**: Each string contributes to the noise internally based on the number of "sh" pairs within the string. This is calculated once and summed up for all strings.
2. **Cross Noise Calculation**: The cross noise between strings depends on their order. The key is to maximize the product of the number of 's' in earlier strings and 'h' in later strings.
3. **Optimal Ordering**: Strings are sorted to maximize cross noise. Strings are divided into three groups:
   - Group 1: Strings with 'h' count zero and non-zero 's' count.
   - Group 2: Strings with non-zero 'h' count.
   - Group 3: Strings with 's' count zero.
4. **Sorting Group 2**: Group 2 is sorted using a custom comparator to ensure that the product of 's' from earlier strings and 'h' from later strings is maximized.

### Solution Code
```python
import sys
import functools

def main():
    n = int(sys.stdin.readline())
    group1 = []
    group2 = []
    group3 = []
    total_internal = 0

    for _ in range(n):
        s = sys.stdin.readline().strip()
        s_count = s.count('s')
        h_count = s.count('h')
        internal = 0
        cnt_s = 0
        for c in s:
            if c == 's':
                cnt_s += 1
            else:
                internal += cnt_s
        total_internal += internal

        if h_count == 0:
            if s_count > 0:
                group1.append((s_count, h_count))
            else:
                group3.append((s_count, h_count))
        else:
            if s_count == 0:
                group3.append((s_count, h_count))
            else:
                group2.append((s_count, h_count))

    s_group1 = sum(s for s, h in group1)
    sum_group2_h = sum(h for s, h in group2)
    sum_group2_s = sum(s for s, h in group2)
    sum_group3_h = sum(h for s, h in group3)

    cross_group1 = s_group1 * (sum_group2_h + sum_group3_h)
    cross_group2_group3 = sum_group2_s * sum_group3_h

    def comparator(a, b):
        lhs = a[0] * b[1]
        rhs = b[0] * a[1]
        if lhs > rhs:
            return -1
        elif lhs < rhs:
            return 1
        else:
            return 0

    sorted_group2 = sorted(group2, key=functools.cmp_to_key(comparator))

    cross_within = 0
    cumulative_s = 0
    for s, h in sorted_group2:
        cross_within += cumulative_s * h
        cumulative_s += s

    total_cross = cross_group1 + cross_group2_group3 + cross_within
    total = total_internal + total_cross
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of strings which are processed to count 's' and 'h' characters and calculate internal "sh" pairs.
2. **Grouping Strings**: Strings are categorized into three groups based on their 's' and 'h' counts to optimize cross noise calculation.
3. **Sorting Group 2**: Strings in group 2 are sorted to maximize the product of 's' from earlier strings and 'h' from later strings using a custom comparator.
4. **Calculating Cross Noise**: Cross noise contributions from different groups are computed and summed up to get the total noise, which is then printed.

This approach ensures that both internal and cross noise are maximized efficiently, leading to the optimal solution.
