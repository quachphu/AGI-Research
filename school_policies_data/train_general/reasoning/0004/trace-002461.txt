To solve this problem, we need to parse a simplified version of HTML tables and determine the number of cells in each table, including nested tables. The results should be sorted in non-decreasing order.

### Approach
1. **Input Handling**: Read all input lines and concatenate them into a single string to handle any arbitrary line breaks.
2. **Tag Extraction**: Use a regular expression to split the concatenated string into individual HTML tags.
3. **Stack-Based Parsing**: Utilize a stack to keep track of the cell counts for each open table. Each time a `<table>` tag is encountered, push a new counter (initialized to 0) onto the stack. For each `<td>` tag, increment the counter at the top of the stack (representing the current table). When a `</table>` tag is encountered, pop the counter from the stack and store the result.
4. **Result Sorting**: After processing all tags, sort the collected results and print them in non-decreasing order.

### Solution Code
```python
import re
import sys

def main():
    # Read all lines and concatenate into a single string without spaces
    s = ''.join(line.strip() for line in sys.stdin)
    # Extract all tags using regular expression
    tags = re.findall(r'<[^>]+>', s)
    stack = []
    results = []
    
    for tag in tags:
        if tag == '<table>':
            stack.append(0)
        elif tag == '</table>':
            if stack:
                cnt = stack.pop()
                results.append(cnt)
        elif tag == '<td>':
            if stack:
                stack[-1] += 1
    
    # Sort the results and print
    results.sort()
    print(' '.join(map(str, results)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Input Handling**: The input is read line by line and concatenated into a single string to ensure any line breaks do not affect the parsing.
2. **Tag Extraction**: The regular expression `<[^>]+>` is used to identify all HTML tags in the input string. This ensures each tag is processed individually.
3. **Stack-Based Parsing**: A stack is used to track the cell count for each open table. Each `<table>` tag starts a new counter, each `<td>` increments the current table's counter, and each `</table>` finalizes the count for the current table, storing it in the results list.
4. **Result Sorting**: After processing all tags, the results are sorted and printed in non-decreasing order to meet the problem requirements.

This approach efficiently handles nested tables using a stack, ensuring each table's cell count is accurately tracked and collected. The use of regular expressions ensures robust tag extraction, and the stack-based parsing efficiently manages nested structures.
