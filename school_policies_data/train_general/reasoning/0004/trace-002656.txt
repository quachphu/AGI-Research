To solve this problem, we need to calculate the expected time required for user ainta to paint the wall such that each row and column has at least one painted cell. The solution involves dynamic programming (DP) to model the expected time based on the current state of the wall, defined by the number of rows and columns already painted.

### Approach
1. **Problem Analysis**: The wall is an n×n grid. The process stops when every row and column has at least one painted cell. Each step involves selecting a tile uniformly at random, painting it if not already painted, and waiting one minute. The challenge is to compute the expected time efficiently given the constraints.

2. **Dynamic Programming (DP) State**: Define `E(r, c)` as the expected time needed to complete the painting starting from `r` covered rows and `c` covered columns. The goal is to compute `E(r0, c0)` where `r0` and `c0` are the initial numbers of covered rows and columns from the input.

3. **DP Transition**: For each state `(r, c)`, the next state depends on the probability of selecting a cell that transitions to a new state:
   - Cells in uncovered rows or columns can transition to states `(r+1, c)`, `(r, c+1)`, or `(r+1, c+1)`.
   - Cells in already covered rows and columns do not change the state.

4. **Order of Computation**: Compute the DP table in reverse order starting from the state `(n, n)` (all rows and columns covered) down to the initial state `(r0, c0)` to ensure dependencies are resolved.

### Solution Code
```python
import sys

def main():
    n, m = map(int, sys.stdin.readline().split())
    rows = set()
    cols = set()
    for _ in range(m):
        r, c = map(int, sys.stdin.readline().split())
        rows.add(r - 1)
        cols.add(c - 1)
    r0 = len(rows)
    c0 = len(cols)
    if r0 == n and c0 == n:
        print("0.0000000000")
        return
    
    max_n = n
    dp = [[0.0] * (max_n + 1) for _ in range(max_n + 1)]

                dp[r][c] = 0.0
                continue
```
