To solve this problem, we need to determine the last moment a student becomes angry in a group of students, where each angry student can turn the next student in line angry by throwing a snowball. The students are described by a string where 'A' represents an angry student and 'P' represents a patient student. The string is given from the last student to the first student in the line.

### Approach
1. **Simulation**: For each group of students, simulate the process of students turning angry minute by minute.
2. **Simultaneous Updates**: Each minute, all angry students will attempt to turn the next student in line angry. These updates must be applied simultaneously to avoid interference between concurrent updates.
3. **Track Changes**: Keep track of the last minute when any student turned angry. This will be our result for each group.

### Solution Code
```python
t = int(input())
for _ in range(t):
    k = int(input())
    s = input().strip()
    current = list(s)
    max_time = 0
    time = 0
    while True:
        new = current.copy()
        changed = False
        for i in range(len(current)):
            if current[i] == 'A':
                if i + 1 < len(current) and current[i+1] == 'P':
                    new[i+1] = 'A'
                    changed = True
        if not changed:
            break
        time += 1
        max_time = time
        current = new
    print(max_time)
```

### Explanation
1. **Input Reading**: Read the number of test cases. For each test case, read the number of students (though not used directly) and the string representing the students.
2. **Initial Setup**: Convert the string to a list for easier manipulation and initialize variables to track the maximum time and the current time step.
3. **Simulation Loop**: For each minute, create a copy of the current state of students. Check each student to see if they are angry and if they can turn the next student angry. Update the next state accordingly.
4. **Track Changes**: If any changes occur during the minute, update the maximum time. If no changes occur, exit the loop.
5. **Output Result**: After processing all minutes for a group, print the maximum time recorded, which represents the last moment a student turned angry.

This approach ensures that we correctly simulate the simultaneous updates of students turning angry and efficiently track the last occurrence of such an event.
