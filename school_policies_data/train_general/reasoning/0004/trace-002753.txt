To solve this problem, we need to determine either an independent set of size ⌈k/2⌉ or a simple cycle of length at most k in a connected undirected graph. The approach leverages Breadth-First Search (BFS) to explore the graph and detect cycles, or alternatively, to determine an independent set based on the BFS layers.

### Approach
1. **Cycle Detection using BFS**: 
   - Perform BFS starting from an arbitrary node (node 1 in this case).
   - Track the depth and parent of each node during BFS traversal.
   - If a back edge (an edge connecting a node to a previously visited node that is not its parent) is found, calculate the cycle length formed by this edge. If the cycle length is ≤ k, output this cycle.

2. **Independent Set Determination**:
   - If no valid cycle is found, split the nodes into even and odd layers based on their BFS depth.
   - The larger of these two layers will form an independent set. Output the first ⌈k/2⌉ nodes from this larger layer.

from collections import deque

def main():
    n, m, k = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, sys.stdin.readline().split())
        adj[u].append(v)
        adj[v].append(u)
    
    parent = [0] * (n + 1)
    depth = [-1] * (n + 1)
    found_cycle = False
    cycle_path = []
    start_node = 1
    
    q = deque()
    q.append(start_node)
    depth[start_node] = 0
    parent[start_node] = -1
    
    while q and not found_cycle:
        u = q.popleft()
        for v in adj[u]:
            if v == parent[u]:
                continue
            if depth[v] == -1:
                depth[v] = depth[u] + 1
                parent[v] = u
                q.append(v)
            else:
                # Found a back edge, calculate cycle length
                cycle_len = depth[u] - depth[v] + 1
                if cycle_len <= k:

                    path = []
                    current = u

                        path.append(current)
                        current = parent[current]
                    path.append(v)
