### Approach
1. **Prime Factorization Insight**: A number with exactly eight divisors can be expressed in one of three forms:
   - \( p^7 \): A prime number raised to the seventh power.
   - \( p^3 \times q \): The product of a prime number cubed and another distinct prime number.
   - \( p \times q \times r \): The product of three distinct prime numbers.

2. **Constraints Handling**: Since we are looking for odd numbers, all primes involved in the factorization must be odd. This eliminates any number involving the prime number 2.

3. **Prime Generation**: Use the Sieve of Eratosthenes to generate all prime numbers up to N.

4. **Case Analysis**:
   - **Case 1**: Numbers of the form \( p^7 \). For N ≤ 200, this case does not contribute any valid numbers.
   - **Case 2**: Numbers of the form \( p^3 \times q \). Check all valid pairs of primes \( p \) and \( q \).
   - **Case 3**: Numbers of the form \( p \times q \times r \). Check all valid triplets of primes \( p, q, \) and \( r \).

### Solution Code
```python
def get_primes(n):
    if n < 2:
        return []
    sieve = [True] * (n + 1)
    sieve[0] = sieve[1] = False
    for i in range(2, int(n ** 0.5) + 1):
        if sieve[i]:
            sieve[i*i:n+1:i] = [False] * len(sieve[i*i:n+1:i])
    primes = [i for i, is_prime in enumerate(sieve) if is_prime]
    return primes

n = int(input())
primes = get_primes(n)

case2 = set()

# Process case2: p^3 * q where p and q are distinct odd primes
for p in primes:
    if p % 2 == 0:
        continue  # Skip even primes (only 2)
    p_cubed = p ** 3
    if p_cubed > n:
        continue
    for q in primes:
        if q == p or q % 2 == 0:
            continue
        product = p_cubed * q
        if product <= n:
            case2.add(product)

# Process case3: p*q*r where p < q < r are distinct odd primes
case3 = set()
odd_primes = [p for p in primes if p % 2 != 0]
len_op = len(odd_primes)

for i in range(len_op):
    p = odd_primes[i]
    for j in range(i + 1, len_op):
        q = odd_primes[j]
        pq = p * q
        if pq == 0:
            continue
        for k in range(j + 1, len_op):
            r = odd_primes[k]
            product = pq * r
            if product > n:
                break  # No need to check further as primes are sorted
            case3.add(product)

count = len(case2) + len(case3)
print(count)
```

3. **Case 3 Handling**: Generate all valid triplets of primes \( p, q, r \) such that their product is within bounds.
4. **Union of Results**: Combine results from both cases to get the total count of valid numbers.

This approach efficiently checks all possible numbers that meet the criteria using prime factorization properties and ensures correctness by leveraging set operations to avoid duplicates.
