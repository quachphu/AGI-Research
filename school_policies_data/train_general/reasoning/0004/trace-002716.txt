The operations include adding elements, removing elements, and querying the maximum XOR value. Given the constraints, a naive approach would be too slow, so we use a trie (prefix tree) data structure to optimize the solution.

### Approach
1. **Trie Data Structure**: We use a trie to store the binary representations of the numbers in the multiset. Each node in the trie represents a bit and tracks the count of numbers that pass through it.
2. **Insertion and Deletion**: When inserting a number, we update the trie by creating nodes as needed and incrementing the count at each node. When deleting a number, we follow the same path and decrement the count at each node.
3. **Maximum XOR Calculation**: For each query, we traverse the trie to find the maximum XOR value by choosing the opposite bit at each position if possible, starting from the most significant bit (MSB) to the least significant bit (LSB).

import sys

class TrieNode:
    __slots__ = ['children', 'count']
    def __init__(self):
        self.children = [None, None]  # 0 and 1
        self.count = 0

root = TrieNode()

def insert(x):
    current = root
    for i in range(29, -1, -1):
        bit = (x >> i) & 1
        if current.children[bit] is None:
            current.children[bit] = TrieNode()
        current = current.children[bit]
        current.count += 1

def delete(x):
    current = root
    for i in range(29, -1, -1):
        bit = (x >> i) & 1
        current = current.children[bit]
        current.count -= 1

def max_xor(x):
    current = root
    max_val = 0
    for i in range(29, -1, -1):
        bit = (x >> i) & 1
        desired_bit = 1 - bit
        if current.children[desired_bit] is not None and current.children[desired_bit].count > 0:
            max_val ^= (1 << i)
            current = current.children[desired_bit]
        else:
            current = current.children[bit]
    return max_val

# Initialize with 0

for _ in range(q):
    line = sys.stdin.readline().strip()
    if not line:
        continue
    op, x = line.split()
    x = int(x)
    if op == '+':
