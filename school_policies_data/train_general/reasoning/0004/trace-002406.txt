To solve this problem, we need to maximize the protection of an army of lemmings by optimally moving shields between them. The protection is defined as the number of pairs of lemmings without shields that have at least one shield between them. The goal is to determine the maximum protection achievable for each number of moves from 0 to the maximum possible value.

### Approach
1. **Problem Analysis**: The problem involves moving shields between lemmings such that the number of protected pairs is maximized. Each move allows transferring a shield to an adjacent lemming if it doesn't already have one.
2. **Dynamic Programming (DP) Insight**: Use dynamic programming to track the minimal sum of unprotected pairs for each possible number of moves. The key insight is to model the state transitions of shield positions and compute the cost of moving shields.
3. **Efficient Calculation**: The number of unprotected pairs can be derived from the blocks of zeros (lemmings without shields) between the shields. The optimal arrangement of shields minimizes these blocks, thus maximizing the protected pairs.
4. **Cumulative Minimum**: After computing the minimal sum of unprotected pairs for each possible number of moves, compute the cumulative minimum to ensure that each value represents the best possible result for up to that number of moves.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    shields = [i + 1 for i, x in enumerate(a) if x == 1]
    m = len(shields)
    m_z = n - m
    T = m_z * (m_z - 1) // 2
    max_k = n * (n - 1) // 2

    if m == 0:
        print(' '.join(['0'] * (max_k + 1)))
        return

    # Initialize DP
    dp = [defaultdict(lambda: float('inf')) for _ in range(m + 1)]
    dp[0][(0, 0)] = 0  # Initial state: no shields placed, sum is 0

    for i in range(1, m + 1):
        current_s = shields[i - 1]
        prev_dp = dp[i - 1]
        for (last_p_prev, cost_prev), sum_prev in prev_dp.items():
            # Determine the possible new_p for the current shield
            remaining_shields = m - i
            min_p = last_p_prev + 1
            max_p = n - remaining_shields
            for new_p in range(min_p, max_p + 1):
                delta_cost = abs(new_p - current_s)
                new_cost = cost_prev + delta_cost
                if new_cost > max_k:
                    continue
                L = new_p - last_p_prev - 1
                new_sum = sum_prev + L * (L - 1) // 2
                # Update the current DP state if a better sum is found
                if new_sum < dp[i][(new_p, new_cost)]:
                    dp[i][(new_p, new_cost)] = new_sum

    # Process the after block and compute min_sum
    min_sum = defaultdict(lambda: float('inf'))
    for (last_p, cost), sum_prev in dp[m].items():
        if cost > max_k:
            continue
        L_after = n - last_p
        sum_total = sum_prev + L_after * (L_after - 1) // 2
        if sum_total < min_sum[cost]:
            min_sum[cost] = sum_total

    # Prepare best_sum array
    best_sum = [float('inf')] * (max_k + 1)
    for cost in min_sum:
        if cost <= max_k:
            best_sum[cost] = min(best_sum[cost], min_sum[cost])

    # Compute cumulative minimum
    current_min = best_sum[0]
    for k in range(max_k + 1):
        if best_sum[k] < current_min:
            current_min = best_sum[k]
        else:
            best_sum[k] = current_min

    # Calculate the protection values
    protection = [T - best_sum[k] if best_sum[k] != float('inf') else 0 for k in range(max_k + 1)]
    print(' '.join(map(str, protection)))

if __name__ == "__main__":
    main()
```

3. **State Transitions**: For each shield and possible new position, the DP state is updated to reflect the cost of moving the shield and the resulting sum of unprotected pairs.
4. **Final Calculation**: After processing all shields, the sum of unprotected pairs is adjusted to include the block of zeros after the last shield. The cumulative minimum is computed to determine the best possible result for each number of moves.
5. **Output**: The protection values are computed and printed for each number of moves from 0 to the maximum possible value.
