To solve this problem, we need to determine the minimum number of flats where the lights need to be turned off such that no one is disturbed. A person in flat `i` is disturbed if there are lights on in flats `i-1` and `i+1` while their own light is off. Our goal is to ensure that no such triplets (1-0-1) exist in the modified array after turning off the lights in selected flats.

### Approach
1. **Identify Triplets**: Continuously check for disturbed people (1-0-1 triplets) in the array.
2. **Turn Off Lights**: For each identified triplet, turn off the light in either the left or right neighboring flat to break the triplet. This is done greedily by turning off the right neighbor to potentially cover more future triplets.
3. **Repeat Until Stable**: Keep checking and breaking triplets until no more exist in the modified array.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
modified = a.copy()
turn_off = set()

while True:
    # Find all disturbed people in the current modified array
    triplets = []
    for i in range(1, n-1):
        if modified[i] == 0 and modified[i-1] == 1 and modified[i+1] == 1:
            triplets.append(i)
    if not triplets:
        break
    # Choose the first triplet and turn off the right neighbor
    i = triplets[0]
    if modified[i+1] == 1:
        turn_off.add(i+1)
        modified[i+1] = 0
    else:
        # This case should not happen as per triplet condition
        turn_off.add(i-1)
        modified[i-1] = 0

print(len(turn_off))
```

### Explanation
1. **Initialization**: Read the input values and initialize the array `modified` to keep track of the current state of the flats after turning off lights. The set `turn_off` keeps track of the flats where lights have been turned off.
2. **Triplet Detection**: Continuously check for the presence of disturbed people (1-0-1 triplets) in the modified array.
3. **Greedy Elimination**: For each detected triplet, turn off the light in the right neighboring flat. This approach helps in potentially covering more triplets that might form in subsequent iterations.
4. **Termination**: The loop terminates when no more triplets are found, ensuring that no one is disturbed. The size of the `turn_off` set gives the minimum number of flats needed to achieve this state.

This approach ensures that we efficiently break all existing triplets and any new ones that might form due to previous actions, leading to the optimal solution.
