To solve this problem, we need to capitalize the first letter of a given word while leaving the rest of the letters unchanged. This involves converting the first character to uppercase and concatenating it with the rest of the string as it is.

### Approach
1. **Reading Input**: The input is a single non-empty word which can contain both uppercase and lowercase letters. We read this input using Python's `input()` function.
2. **Processing the Word**: The first character of the word is converted to uppercase using the `upper()` method. The rest of the word (from the second character onwards) is left unchanged.
3. **Constructing the Result**: The processed first character is concatenated with the rest of the original word to form the result.
4. **Output the Result**: The constructed result is printed as the output.

### Solution Code
```python
def capitalize_word():
    word = input().strip()
    capitalized = word[0].upper() + word[1:]
    print(capitalized)

capitalize_word()
```

### Explanation
- **Reading Input**: The function reads the input word using `input().strip()` to ensure there are no leading or trailing spaces, which aligns with the problem's constraints.
- **Processing the Word**: The first character of the word is converted to uppercase. This is done using `word[0].upper()`, which handles both cases where the first character might already be uppercase or needs conversion from lowercase.
- **Constructing the Result**: The rest of the word (from index 1 onwards) is concatenated to the uppercase first character. This ensures that all characters except the first remain unchanged.
- **Output**: The result is printed directly, which meets the problem's requirement of providing the correctly capitalized word.

This approach efficiently processes the input in linear time, O(n), where n is the length of the word, ensuring it is optimal even for the maximum input size constraint.
