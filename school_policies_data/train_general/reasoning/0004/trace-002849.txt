To solve this problem, we need to determine if a traffic light configuration at an intersection could potentially lead to an accident between a car and a pedestrian. An accident is possible if a pedestrian's crossing light (p) is green at the same time as any car lane (left, straight, or right) that can enter or exit the pedestrian's part of the intersection.

### Approach
1. **Input Reading**: Read the traffic light configurations for the four parts of the intersection.
2. **Check Each Part**: For each part of the intersection, check if the pedestrian light (p) is green.
3. **Immediate Check**: If any car lane (left, straight, or right) in the same part as the green pedestrian light is also green, an accident is possible.
4. **Incoming Lanes Check**: If no immediate accident is found, check the lanes from other parts that can lead into the current part. Specifically, check the left lane of the next part, the right lane of the previous part, and the straight lane of the part two steps away (all modulo 4 to handle the cyclic nature of the intersection).

### Solution Code
```python
parts = [list(map(int, input().split())) for _ in range(4)]

for X in range(4):
    if parts[X][3] == 1:
        # Check if any of X's own lanes (l, s, r) are green
        if any(parts[X][i] == 1 for i in range(3)):
            print("YES")
            exit()
        # Check incoming lanes: (X+1)%4's left, (X-1)%4's right, (X-2)%4's straight
        if (parts[(X+1) % 4][0] == 1 or
            parts[(X-1) % 4][2] == 1 or
            parts[(X-2) % 4][1] == 1):
            print("YES")
            exit()

print("NO")
```

### Explanation
- **Input Reading**: The input is read into a list of lists where each sublist represents the traffic lights for a part of the intersection.
- **Pedestrian Check**: For each part, if the pedestrian light (p) is green, we first check if any of the car lanes (left, straight, right) in the same part are green.
- **Incoming Lanes Check**: If no car lanes in the same part are green, we then check the lanes from adjacent parts that could lead into the current part. These are determined using modular arithmetic to handle the cyclic nature of the intersection.

This approach ensures that we efficiently check all possible scenarios where an accident could occur, leveraging the cyclic connections between parts of the intersection.
