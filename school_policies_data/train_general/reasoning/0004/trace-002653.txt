To solve this problem, we need to determine the maximum number of cake cells the cakeminator can eat from a rectangular grid, given that each row or column he eats must not contain any evil strawberries (S). The solution involves identifying rows and columns without any S and calculating the optimal combination of these rows and columns to maximize the cells eaten.

### Approach
1. **Identify Rows Without S**: Iterate through each row to check if it contains any S. If a row does not contain any S, it can be fully eaten.
2. **Identify Columns Without S**: For each column, check all rows to see if any cell in that column contains an S. If a column does not contain any S, it can be fully eaten.
3. **Calculate Maximum Cells Eaten**: Use the formula to compute the maximum cells eaten by considering the overlap between rows and columns. The formula is:
   \[
   \text{result} = (R \times c) + (C \times r) - (R \times C)
   \]
   where \(R\) is the count of rows without S, \(C\) is the count of columns without S, \(r\) is the number of rows, and \(c\) is the number of columns. This formula accounts for overlapping cells that are counted twice when both their row and column are eaten.

### Solution Code
```python
r, c = map(int, input().split())
grid = [input().strip() for _ in range(r)]

rows_without_S = 0
for row in grid:
    if 'S' not in row:
        rows_without_S += 1

cols_without_S = 0
for j in range(c):
    has_S = False
    for i in range(r):
        if grid[i][j] == 'S':
            has_S = True
            break
    if not has_S:
        cols_without_S += 1

result = rows_without_S * c + cols_without_S * r - rows_without_S * cols_without_S
print(result)
```

### Explanation
1. **Reading Input**: The input is read and stored in a list of strings representing the grid.
2. **Checking Rows**: Each row is checked for the presence of 'S'. If a row has no 'S', it is counted.
3. **Checking Columns**: Each column is checked by iterating through each cell in that column. If no 'S' is found, the column is counted.
4. **Computing Result**: The formula calculates the total cells eaten by considering all possible rows and columns that can be eaten, subtracting the overlapping cells counted twice.

This approach efficiently determines the maximum cells the cakeminator can eat by leveraging simple checks and a mathematical formula to account for overlaps, ensuring an optimal solution.
