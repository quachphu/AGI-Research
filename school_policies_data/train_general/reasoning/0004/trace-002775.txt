To solve this problem, we need to determine the total number of chocolates collected by Guri and Prary based on their individual paths, ensuring that overlapping regions are counted only once. The solution involves efficiently computing the union of their paths and summing the chocolates using a prefix sum array for quick range queries.

### Approach
1. **Prefix Sum Array**: Precompute a prefix sum array to quickly calculate the sum of chocolates in any given range. This allows us to compute the sum of any interval in constant time.
2. **Union of Intervals**: For each query, determine the union of the intervals covered by Guri and Prary. If the intervals overlap or are adjacent, they form a single continuous interval. Otherwise, they are treated as two separate intervals.
3. **Efficient Calculation**: For each query, check if the intervals can be merged into one. If they can, compute the sum using the merged interval. If not, compute the sum of the two separate intervals.

### Solution Code
```python
import sys

def main():
    data = sys.stdin.read().split()
    ptr = 0
    N = int(data[ptr])
    Q = int(data[ptr + 1])
    ptr += 2
    K = list(map(int, data[ptr:ptr + N]))
    ptr += N
    
    # Building the prefix sum array
    prefix = [0] * (N + 1)
    for i in range(N):
        prefix[i + 1] = prefix[i] + K[i]
    
    # Process each query
    output = []
    for _ in range(Q):
        G1 = int(data[ptr])
        P1 = int(data[ptr + 1])
        G2 = int(data[ptr + 2])
        P2 = int(data[ptr + 3])
        ptr += 4
        
        merged_start = min(G1, P1)
        merged_end = max(G2, P2)
        max_start = max(G1, P1)
        min_end = min(G2, P2)
        
        if max_start <= min_end + 1:
            total = prefix[merged_end + 1] - prefix[merged_start]
        else:
            sum_g = prefix[G2 + 1] - prefix[G1]
            sum_p = prefix[P2 + 1] - prefix[P1]
            total = sum_g + sum_p
        
        output.append(str(total))
    
    print('\n'.join(output))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prefix Sum Array**: The prefix sum array is constructed such that `prefix[i]` contains the sum of chocolates from the start up to the (i-1)-th container. This allows us to compute the sum of any interval [a, b] as `prefix[b+1] - prefix[a]`.
2. **Query Processing**: For each query, we determine the start and end positions of both Guri and Prary. We then compute the merged interval's start and end. By checking if the intervals overlap or are adjacent, we decide whether to treat them as a single interval or two separate intervals.
3. **Efficiency**: Using the prefix sum array ensures that each query is processed in constant time, making the solution efficient even for the upper constraint limits.

This approach ensures that we handle up to 100,000 queries efficiently, leveraging the prefix sum array for quick sum calculations and interval merging checks to avoid double-counting chocolates in overlapping regions.
