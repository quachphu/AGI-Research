To solve this problem, we need to rearrange the stones such that there are no white stones (W) immediately followed by red stones (R). The goal is to determine the minimum number of operations (swaps and flips) required to achieve this configuration.

### Approach
1. **Understand the Problem Constraints**: We need to avoid any occurrence of 'W' followed by 'R'. The optimal configuration is all 'R's followed by all 'W's.
2. **Prefix Sum Calculation**: Compute a prefix sum array to track the number of 'R's up to each position in the string. This helps in efficiently determining the number of 'R's in any segment.
3. **Evaluate All Possible Splits**: For each possible split point `k` (where the first `k` positions are 'R's and the rest are 'W's), calculate the cost to transform the stones into this configuration. This involves:
   - Counting the number of 'W's in the first `k` positions.
   - Counting the number of 'R's in the remaining positions.
   - Using swaps to minimize the number of flips needed.

### Solution Code
```python
n = int(input())
s = input().strip()

prefix_r = [0] * (n + 1)
for i in range(1, n + 1):
    prefix_r[i] = prefix_r[i - 1] + (1 if s[i - 1] == 'R' else 0)

total_r = prefix_r[n]
min_operations = float('inf')

for k in range(n + 1):
    current_r = prefix_r[k]
    w_in_r = k - current_r
    r_in_w = total_r - current_r
    swaps = min(w_in_r, r_in_w)
    operations = w_in_r + r_in_w - swaps
    if operations < min_operations:
        min_operations = operations

print(min_operations)
```

### Explanation
1. **Prefix Sum Array**: The prefix sum array `prefix_r` is constructed to count the number of 'R's up to each index. This allows quick lookup of how many 'R's are in any prefix of the string.
2. **Iterate Over Possible Splits**: For each possible split point `k`, calculate the number of 'W's in the first `k` positions (`w_in_r`) and the number of 'R's in the remaining positions (`r_in_w`).
3. **Calculate Operations**: The number of operations required to transform the string into the desired configuration is determined by considering both swaps and flips. Swaps are used to reduce the number of necessary flips, minimizing the total operations.

This approach efficiently evaluates all possible configurations and computes the minimum operations required using a combination of swaps and flips, ensuring an optimal solution within the problem constraints.
