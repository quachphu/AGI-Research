To solve this problem, we need to determine the maximum number of sets that could have been completed for each possible value of x (from 1 to n), where each set ends when one player wins x consecutive rounds. The input string may contain unknown results ('?'), which can be optimally chosen to maximize the number of sets.

### Approach
1. **Precompute Maximum Runs**: For each position in the string, compute the maximum possible consecutive wins (either for Alice or Bob) starting from that position if '?' characters are optimally replaced. This is done using two arrays, `left0` and `left1`, which track the maximum consecutive 0s and 1s (including '?') starting from each position.
2. **Calculate Maximum Runs**: For each position, determine the maximum length of consecutive wins (either 0s or 1s) starting from that position.
3. **Greedy Algorithm for Each x**: For each possible x, use a greedy approach to count the maximum number of non-overlapping intervals of length x where each interval can be filled with all 0s or all 1s. This is done by checking each multiple of x and counting valid intervals.

### Solution Code
```python
n = int(input())
s = input().strip()
n = len(s)

if n == 0:
    print()
    exit()

left0 = [0] * n
left1 = [0] * n

# Compute left0 from right to left
for i in range(n-1, -1, -1):
    if s[i] == '1':
        left0[i] = 0
    else:
        left0[i] = 1
        if i < n-1:
            left0[i] += left0[i+1]

# Compute left1 from right to left
for i in range(n-1, -1, -1):
    if s[i] == '0':
        left1[i] = 0
    else:
        left1[i] = 1
        if i < n-1:
            left1[i] += left1[i+1]

max_run = [max(left0[i], left1[i]) for i in range(n)]

ans = [0] * (n + 1)  # ans[1..n]

for x in range(1, n + 1):
    cnt = 0
    i = 0
    while i < n:
        if max_run[i] >= x:
            cnt += 1
            i += x
        else:
            i += 1
    ans[x] = cnt

print(' '.join(map(str, ans[1:])))
```

### Explanation
1. **Precompute Maximum Runs**: The arrays `left0` and `left1` are computed to determine the maximum consecutive wins possible starting from each position if '?' is replaced optimally. `left0[i]` gives the maximum consecutive 0s starting at position i, while `left1[i]` gives the maximum consecutive 1s.
2. **Determine Maximum Runs**: For each position, `max_run[i]` is the maximum of `left0[i]` and `left1[i]`, representing the longest possible consecutive wins starting from that position.
3. **Greedy Count for Each x**: For each x from 1 to n, iterate through the string in steps of x, checking if the maximum run starting at each position is at least x. If it is, count it as a valid set and skip the next x positions to avoid overlap. This ensures we count the maximum number of non-overlapping sets for each x.

This approach efficiently computes the result in O(n log n) time, making it suitable for large input sizes up to 1,000,000.
