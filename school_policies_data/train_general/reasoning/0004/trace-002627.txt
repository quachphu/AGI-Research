To solve this problem, we need to determine the color of the sock that does not have a pair when given an odd number of socks. The solution should be efficient in terms of both time and space complexity.

### Approach
The optimal approach to solve this problem is using the XOR bitwise operation. Here’s the reasoning behind using XOR:
1. **XOR Properties**: The XOR operation has two important properties that are useful here:
   - Any number XORed with itself results in 0.
   - Any number XORed with 0 results in the number itself.
2. **Canceling Pairs**: When we XOR all the sock colors together, each pair of socks will cancel each other out (resulting in 0), leaving only the color of the unpaired sock.

### Solution Code
```python
def find_missing_sock():
    import sys
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline().strip())
        socks = list(map(int, sys.stdin.readline().split()))
        result = 0
        for num in socks:
            result ^= num
        print(result)

find_missing_sock()
```

### Explanation
1. **Reading Input**: The function reads the number of test cases first. For each test case, it reads the number of socks and then the list of sock colors.
2. **XOR Operation**: By iterating through each sock color and applying the XOR operation cumulatively, pairs of socks will cancel each other out (resulting in 0), leaving the result as the color of the unpaired sock.
3. **Output**: The result of the XOR operation for each test case is printed, which is the color of the sock without a pair.

This approach ensures that we solve the problem in O(n) time complexity for each test case, where n is the number of socks, and O(1) space complexity, making it highly efficient.
