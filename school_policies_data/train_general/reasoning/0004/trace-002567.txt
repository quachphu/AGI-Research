To solve this problem, we need to determine the minimum value of \( k \) such that there exists at least one \( k \)-dominant character in a given string. A character \( c \) is \( k \)-dominant if every substring of length at least \( k \) contains \( c \).

### Approach
1. **Understanding k-dominant Character**: A character \( c \) is \( k \)-dominant if every substring of length \( k \) or more contains \( c \). The key insight is that the maximum gap between consecutive occurrences of \( c \) (including the start and end of the string) determines the minimum \( k \) for \( c \).

2. **Gap Calculation**: For each character \( c \), compute the gaps between consecutive occurrences, including the gap before the first occurrence and after the last occurrence. The maximum of these gaps plus one gives the minimum \( k \) for \( c \).

3. **Algorithm**:
   - Collect positions of each character in the string.
   - For each character, compute the maximum gap between consecutive occurrences.
   - The minimum \( k \) for each character is the maximum gap plus one.
   - The answer is the smallest \( k \) across all characters.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    s = sys.stdin.readline().strip()
    n = len(s)
    pos = defaultdict(list)
    for i, c in enumerate(s):
        pos[c].append(i)
    min_k = float('inf')
    for c in pos:
        lst = pos[c]
        gaps = []
        prev = -1
        for p in lst:
            if prev == -1:
                gaps.append(p)
            else:
                gaps.append(p - prev - 1)
            prev = p
        gaps.append(n - 1 - prev)
        current_max = max(gaps)
        k = current_max + 1
        if k < min_k:
            min_k = k
    print(min_k)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Input Reading**: The input string is read and its length is determined.
2. **Position Collection**: For each character in the string, store the indices where it appears.
3. **Gap Calculation**: For each character, compute the gaps between consecutive occurrences, including the start and end of the string.
4. **Determine k**: The maximum gap for a character plus one gives the minimum \( k \) for that character. The smallest \( k \) across all characters is the answer.

This approach efficiently computes the required \( k \) by leveraging the positions of each character and their gaps, ensuring an optimal solution with linear complexity relative to the input size.
