To solve this problem, we need to find the minimum sum of distances that mice have to travel to hide in holes, given the constraints on the number of mice each hole can accommodate. The solution involves dynamic programming with optimizations to handle large input sizes efficiently.

### Approach
1. **Sorting**: First, sort the mice and holes by their positions. This allows us to efficiently compute the distances using prefix sums and binary search.
2. **Dynamic Programming (DP) with Sliding Window Minimum**: Use a DP array to keep track of the minimum cost of assigning a certain number of mice to the first few holes. For each hole, maintain a deque to efficiently compute the minimum cost in a sliding window, which helps in reducing the time complexity.

### Solution Code
```python
import sys
import bisect
from collections import deque

def main():
    n, m = map(int, sys.stdin.readline().split())
    x = list(map(int, sys.stdin.readline().split()))
    x.sort()
    holes = []
    total_cap = 0
    for _ in range(m):
        p, c = map(int, sys.stdin.readline().split())
        holes.append((p, c))
        total_cap += c
    if total_cap < n:
        print(-1)
        return
    
    holes.sort()
    
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i+1] = prefix[i] + x[i]
    
    # DP array
    dp_prev = [float('inf')] * (n + 1)
    dp_prev[0] = 0
    
    for hole_idx in range(len(holes)):
        p_i, c_i = holes[hole_idx]
        cost_prefix = [0] * (n + 1)
        for j in range(1, n+1):
            cost_prefix[j] = cost_prefix[j-1] + abs(x[j-1] - p_i)
        
        dp_current = [float('inf')] * (n + 1)
        dq = deque()
        
        for j in range(n + 1):
            # Remove indices out of the window [j - c_i, j]
            while dq and dq[0][1] < j - c_i:
                dq.popleft()
            
            # Current value to add
            current_val = dp_prev[j] - cost_prefix[j]
            # Remove elements from the back that are >= current_val
            while dq and dq[-1][0] >= current_val:
                dq.pop()
            dq.append((current_val, j))
            
            # The minimum value is at the front
            if dq:
                min_val = dq[0][0]
                dp_current[j] = cost_prefix[j] + min_val
        
        dp_prev = dp_current
    
    print(dp_prev[n] if dp_prev[n] != float('inf') else -1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Sorting**: Mice and holes are sorted to facilitate efficient distance calculations.
