To solve this problem, we need to convert a given number of seconds into a time format of hours, minutes, and seconds (h:m:s). The solution involves breaking down the total seconds into hours, minutes, and remaining seconds using basic arithmetic operations.

### Approach
1. **Read Input**: Read the integer input which represents the total number of seconds.
2. **Calculate Hours**: Divide the total seconds by 3600 (the number of seconds in an hour) to get the number of hours.
3. **Calculate Remaining Seconds**: Use the modulus operator to find the remaining seconds after extracting the hours.
4. **Calculate Minutes**: Divide the remaining seconds by 60 (the number of seconds in a minute) to get the number of minutes.
5. **Calculate Seconds**: Use the modulus operator again on the remaining seconds to get the remaining seconds after extracting the minutes.
6. **Format and Output**: Format the hours, minutes, and seconds into the required string format and print it.

### Solution Code
```python
def convert_seconds():
    S = int(input())
    hours = S // 3600
    remaining_seconds = S % 3600
    minutes = remaining_seconds // 60
    seconds = remaining_seconds % 60
    print(f"{hours}:{minutes}:{seconds}")

convert_seconds()
```

### Explanation
1. **Reading Input**: The input is read as an integer using `input()` and converted to an integer.
2. **Calculating Hours**: By dividing the total seconds by 3600, we determine how many full hours are in the given seconds.
3. **Remaining Seconds After Hours**: The modulus operation with 3600 gives the remaining seconds after accounting for the hours.
4. **Calculating Minutes**: Dividing the remaining seconds by 60 gives the number of full minutes.
5. **Calculating Seconds**: The modulus operation with 60 on the remaining seconds gives the leftover seconds after accounting for the minutes.
6. **Formatting Output**: The formatted string ensures that each component (hours, minutes, seconds) is printed without leading zeros, directly as integers separated by colons.

This approach efficiently breaks down the problem into manageable steps using basic arithmetic operations, ensuring correctness and simplicity. The solution handles all edge cases, including the maximum input value of 86400 seconds (24 hours).
