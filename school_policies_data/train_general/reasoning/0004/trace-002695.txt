To solve this problem, we need to compute the sum of the "goodness" of all integers between L and R for multiple test cases. The goodness of a number is defined as the number itself multiplied by the number of digits in its decimal representation. Given the constraints, a direct approach of iterating through each number in the range [L, R] is infeasible. Instead, we use an optimized approach based on grouping numbers by their digit lengths.

### Approach
1. **Digit Length Grouping**: Numbers with the same digit length can be grouped together. For example, all 3-digit numbers (from 100 to 999) contribute their value multiplied by 3.
2. **Range Calculation**: For each digit length, determine the start and end of the range of numbers within [L, R] that have that digit length.
3. **Sum Calculation**: For each valid range, compute the sum of numbers using the arithmetic series formula. Multiply this sum by the digit length to get the contribution of that group to the total goodness.
4. **Modulo Operation**: Since the result can be very large, use modulo \(10^9 + 7\) to keep the numbers manageable.

### Solution Code
```python
MOD = 10**9 + 7

def calculate_goodness_sum():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        L = int(input[idx])
        R = int(input[idx+1])
        idx +=2
        total = 0
        for d in range(1, 11):  # digits from 1 to 10
            lower = 10 ** (d-1)
            upper = (10 ** d) - 1
            start = max(L, lower)
            end = min(R, upper)
            if start > end:
                continue
            count = end - start + 1
            sum_num = (start + end) * count // 2
            contribution = (sum_num % MOD) * d % MOD
            total = (total + contribution) % MOD
        print(total % MOD)

calculate_goodness_sum()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the potentially large number of test cases.
2. **Loop Through Test Cases**: For each test case, process the range [L, R].
3. **Digit Length Iteration**: For each digit length from 1 to 10 (since the maximum number is \(10^9\), which has 10 digits), compute the valid range of numbers with that digit length within [L, R].
4. **Range Validation**: Check if the computed range [start, end] is valid (i.e., start <= end).
5. **Sum Calculation**: Use the arithmetic series formula to compute the sum of numbers in the valid range, then compute the contribution of this range to the total goodness.
6. **Modulo Operation**: Apply modulo \(10^9 + 7\) to each contribution to ensure numbers remain manageable and avoid overflow.

This approach efficiently groups numbers by their digit lengths, computes contributions in bulk, and ensures results are within the required modulo constraint.
