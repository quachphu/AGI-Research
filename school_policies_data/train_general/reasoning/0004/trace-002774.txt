To solve this problem, we need to determine the number at a given coordinate (x, y) based on a specific pattern. If the coordinate does not follow the pattern, we should return "No Number".

### Approach
1. **Identify Valid Coordinates**: The valid coordinates are those where either x equals y or x is exactly 2 units more than y (i.e., x = y + 2). If neither condition is met, the coordinate is invalid.
2. **Determine the Number**:
   - For coordinates where x equals y:
     - If x is even, the number is `2 * x`.
     - If x is odd, the number is `2 * x - 1`.
   - For coordinates where x = y + 2:
     - If x is even, the number is `2 * x - 2`.
     - If x is odd, the number is `2 * x - 3`.

### Solution Code
```python
t = int(input())
for _ in range(t):
    x, y = map(int, input().split())
    if x == y:
        if x % 2 == 0:
            print(2 * x)
        else:
            print(2 * x - 1)
    elif x == y + 2:
        if x % 2 == 0:
            print(2 * x - 2)
        else:
            print(2 * x - 3)
    else:
        print("No Number")
```

### Explanation
- **Valid Coordinates Check**: The code first checks if the coordinates (x, y) are valid by verifying if x equals y or x is y + 2.
- **Number Calculation**:
  - For coordinates where x equals y, the number is calculated based on the parity of x.
  - For coordinates where x is y + 2, the number is calculated based on the parity of x.
  - If the coordinates do not meet either condition, "No Number" is printed.

This approach efficiently determines the number at each coordinate using simple arithmetic checks and ensures correctness by adhering to the observed pattern in the problem statement.
