To solve this problem, we need to generate Nikhil's favorite pattern, which is a clockwise spiral matrix starting from the top-left corner. The matrix should be filled with numbers from 1 to S^2 for a given size S. The solution involves simulating the spiral traversal and filling the matrix accordingly.

### Approach
1. **Matrix Initialization**: Create an SxS matrix initialized with zeros.
2. **Layer-wise Traversal**: The matrix is filled layer by layer, starting from the outermost layer and moving inward. Each layer is processed in four steps:
   - **Top Row**: Fill from left to right.
   - **Right Column**: Fill from top+1 to bottom.
   - **Bottom Row**: If applicable, fill from right-1 to left.
   - **Left Column**: If applicable, fill from bottom-1 to top+1.
3. **Direction Handling**: After filling each layer, adjust the boundaries to move inward and repeat the process until all layers are filled.

### Solution Code
```python
def generate_spiral(S):
    matrix = [[0] * S for _ in range(S)]
    current_num = 1
    for layer in range((S + 1) // 2):
        left = layer
        right = S - 1 - layer
        top = layer
        bottom = S - 1 - layer
        
        # Top row: left to right
        for col in range(left, right + 1):
            matrix[top][col] = current_num
            current_num += 1
        
        # Right column: top+1 to bottom
        for row in range(top + 1, bottom + 1):
            matrix[row][right] = current_num
            current_num += 1
        
        # Bottom row if needed
        if top < bottom:
            for col in range(right - 1, left - 1, -1):
                matrix[bottom][col] = current_num
                current_num += 1
            
            # Left column if needed
            if left < right:
                for row in range(bottom - 1, top, -1):
                    matrix[row][left] = current_num
                    current_num += 1
    return matrix
```
