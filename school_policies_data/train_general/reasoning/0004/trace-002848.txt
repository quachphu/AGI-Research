### Approach
1. **Understanding the Problem**: Joty paints tiles such that tiles divisible by `a` are red, and those divisible by `b` are blue. If a tile is divisible by both `a` and `b`, she can choose the color that gives more chocolates.
2. **Key Observations**:
   - Tiles divisible by both `a` and `b` (i.e., divisible by their least common multiple, LCM) can be painted either color. We choose the color with the higher chocolate value.
   - Calculate the number of tiles divisible by `a` but not `b`, and those divisible by `b` but not `a`.
3. **Mathematical Calculations**:
   - **LCM Calculation**: Use the formula `LCM(a, b) = (a * b) // GCD(a, b)` where GCD is the greatest common divisor.
   - **Count Multiples**: Calculate the number of multiples of `a`, `b`, and their LCM within the range `1` to `n`.
4. **Optimal Strategy**: Sum the chocolates from tiles painted red, blue, and the optimal choice for overlapping tiles.

### Solution Code
```python
import math

def main():
    n, a, b, p, q = map(int, input().split())
    gcd_ab = math.gcd(a, b)
    lcm_ab = a * b // gcd_ab
    count_both = n // lcm_ab
    count_a = (n // a) - count_both
    count_b = (n // b) - count_both
    total = count_a * p + count_b * q + count_both * max(p, q)
    print(total)

main()
```

### Explanation
1. **Reading Input**: The input values are read and parsed into integers.
2. **GCD and LCM Calculation**: Compute the GCD of `a` and `b`, then derive the LCM using the formula.
3. **Counting Multiples**:
   - `count_both` is the number of tiles divisible by both `a` and `b`.
   - `count_a` is the number of tiles divisible by `a` but not by `b`.
   - `count_b` is the number of tiles divisible by `b` but not by `a`.
4. **Total Chocolates Calculation**:
   - Sum chocolates from tiles painted red (`count_a * p`), blue (`count_b * q`), and the optimal choice for overlapping tiles (`count_both * max(p, q)`).

This approach ensures that we efficiently compute the maximum chocolates by leveraging mathematical properties and optimal choices for overlapping tiles.
