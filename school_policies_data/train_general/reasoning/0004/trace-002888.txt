    stack = []

To solve this problem, we need to compute the imbalance value of an array, which is the sum of the differences between the maximum and minimum values of all possible subsegments of the array. Given the constraints, a brute-force approach is infeasible, so we use an optimized method based on monotonic stacks to efficiently calculate the required sums of maximum and minimum values for all subsegments.

### Approach
1. **Sum of Maximum Values (sum_max):** For each element, determine how many subsegments it is the maximum value in. This is done using two passes with a monotonic stack to find the nearest previous and next elements that are greater than the current element.
2. **Sum of Minimum Values (sum_min):** Similarly, determine how many subsegments each element is the minimum value in using two passes with a monotonic stack to find the nearest previous and next elements that are smaller than the current element.
3. **Imbalance Calculation:** Subtract the sum of minimum values from the sum of maximum values to get the imbalance value.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    if n == 0:
        print(0)
        return

    # Calculate sum_max using left_max and right_max
    left_max = [-1] * n
    stack = []
    for i in range(n):
        while stack and a[stack[-1]] < a[i]:
            stack.pop()
        if stack:
            left_max[i] = stack[-1]
        else:
            left_max[i] = -1
        stack.append(i)
    
    right_max = [n] * n
    stack = []
    for i in range(n-1, -1, -1):
        while stack and a[stack[-1]] <= a[i]:
            stack.pop()
        if stack:
            right_max[i] = stack[-1]
        else:
            right_max[i] = n
        stack.append(i)
    
    sum_max = 0
    for i in range(n):
        sum_max += a[i] * (i - left_max[i]) * (right_max[i] - i)

    # Calculate sum_min using left_min and right_min
    left_min = [-1] * n
    stack = []
    for i in range(n):
        while stack and a[stack[-1]] >= a[i]:
            stack.pop()
        if stack:
            left_min[i] = stack[-1]
        else:
            left_min[i] = -1
        stack.append(i)
    
    right_min = [n] * n
    stack = []
    for i in range(n-1, -1, -1):
        while stack and a[stack[-1]] > a[i]:
            stack.pop()
        if stack:
            right_min[i] = stack[-1]
        else:
            right_min[i] = n
        stack.append(i)
    
    sum_min = 0
    for i in range(n):
        sum_min += a[i] * (i - left_min[i]) * (right_min[i] - i)

    print(sum_max - sum_min)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Monotonic Stacks for Bounds Calculation:**
   - **Left and Right Bounds for Maxima:** For each element, we find the nearest previous element greater than or equal to it and the nearest next element greater than it. This helps in determining the range of subsegments where the current element is the maximum.
   - **Left and Right Bounds for Minima:** Similarly, we find the nearest previous element smaller than or equal to it and the nearest next element smaller than it to determine the range where the current element is the minimum.

2. **Efficient Calculation:**
   - Using monotonic stacks allows us to compute these bounds in linear time, O(n), which is crucial for handling large input sizes up to 1,000,000 elements.

3. **Summing Contributions:**
   - Each element's contribution to the sum of maxima or minima is calculated based on the number of subsegments it influences, which is derived from the computed bounds. The total sum is then the difference between these contributions, giving the imbalance value.

This approach ensures that we efficiently compute the required sums in linear time, making it feasible for large input sizes.
