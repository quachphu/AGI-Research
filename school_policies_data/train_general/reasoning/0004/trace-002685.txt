To solve this problem, we need to determine how many times a given string Mi appears in a specific substring of a string S for multiple queries. Each query provides a range [li, ri] and a string Mi, and we need to count occurrences of Mi within that range efficiently.

### Approach
1. **Prefix Sum for Single Characters**: For single-character queries, we precompute a prefix sum array for each character in S. This allows us to quickly determine the count of any character in a given range using constant time lookups.

2. **KMP Algorithm for Longer Strings**: For strings longer than one character, we use the Knuth-Morris-Pratt (KMP) algorithm. This algorithm efficiently searches for occurrences of a pattern within a text by preprocessing the pattern to create a failure function, which helps in skipping unnecessary comparisons.

3. **Failure Function**: The failure function (also known as the partial match table) is precomputed for each pattern Mi. This helps in efficiently determining where to continue searching after a mismatch.

4. **Efficient Substring Search**: For each query, we apply the KMP algorithm directly on the relevant substring of S (defined by [li, ri]) without explicitly extracting it. This avoids the overhead of substring extraction and allows us to process the substring in place.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    S = input[ptr]
    ptr += 1
    Q = int(input[ptr])
    ptr += 1

    # Precompute prefix sums for each character
    prefix = [[0] * (len(S) + 1) for _ in range(26)]
    for i in range(len(S)):
        c = ord(S[i]) - ord('a')
        for j in range(26):
            prefix[j][i + 1] = prefix[j][i]
        prefix[c][i + 1] = prefix[c][i] + 1

    for _ in range(Q):
        l = int(input[ptr])
        ptr += 1
        r = int(input[ptr])
        ptr += 1
        Mi = input[ptr]
        ptr += 1
        m = len(Mi)
        if m > (r - l + 1):
            print(0)
            continue
        if m == 1:
            c = Mi[0]
            idx = ord(c) - ord('a')
            res = prefix[idx][r + 1] - prefix[idx][l]
            print(res)
            continue

        # Compute failure function for Mi
        len_mi = m
        failure = [-1] * (len_mi + 1)
        j = -1
        for i in range(len_mi):
            while j >= 0 and Mi[i] != Mi[j]:
                j = failure[j]
            j += 1
            if i + 1 < len_mi and Mi[i + 1] == Mi[j]:
                failure[i + 1] = failure[j]
            else:
                failure[i + 1] = j

        # KMP count
        count = 0
        j = 0
        for i in range(l, r + 1):
            current_char = S[i]
            while j >= 0 and current_char != Mi[j]:
                j = failure[j]
            j += 1
            if j == len_mi:
                start = i - len_mi + 1
                if start >= l and start <= r - len_mi + 1:
                    count += 1
                j = failure[j]
        print(count)
```

2. **KMP Algorithm**: This algorithm is used for patterns longer than one character. By preprocessing the pattern to create a failure function, the algorithm efficiently skips parts of the text where a mismatch occurs, reducing unnecessary comparisons.

3. **Efficiency**: The approach ensures that each query is processed in linear time relative to the length of the pattern and the range specified, making it feasible even for large input sizes. The use of prefix sums for single characters and KMP for longer patterns ensures that both types of queries are handled optimally.
