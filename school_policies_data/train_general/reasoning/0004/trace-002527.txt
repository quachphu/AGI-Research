To solve this problem, we need to determine the area of two rectangles and compare them to find the larger one. If both areas are equal, we simply output that value.

### Approach
1. **Reading Input**: The input consists of four integers representing the dimensions of two rectangles.
2. **Calculating Areas**: For each rectangle, the area is calculated by multiplying its vertical and horizontal side lengths.
3. **Comparison**: The areas of the two rectangles are compared, and the larger one is printed. If the areas are equal, that common value is printed.

### Solution Code
```python
def main():
    A, B, C, D = map(int, input().split())
    area1 = A * B
    area2 = C * D
    print(max(area1, area2))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read as a single line containing four integers. These integers are split and mapped to variables A, B, C, and D.
2. **Area Calculation**: The area of the first rectangle is computed as \(A \times B\) and the area of the second rectangle as \(C \times D\).
3. **Comparison and Output**: Using Python's built-in `max` function, the larger of the two areas is determined and printed. If both areas are equal, `max` will return the same value for both, thus correctly outputting the equal area.

This approach ensures that we efficiently compute and compare the areas with minimal computational overhead, making the solution both optimal and straightforward.
