To solve this problem, we need to identify and correct typos in a given word by inserting the minimum number of spaces. A typo is defined as a sequence of three or more consonants containing at least two different characters. Our goal is to split the word into segments such that each segment is free of typos.

### Approach
1. **Identify Vowels and Consonants**: Vowels are 'a', 'e', 'i', 'o', 'u'. All other letters are consonants.
2. **Segment the Word into Runs**: Split the word into consecutive runs of vowels and consonants.
3. **Check for Typos**: For each consonant run, check if it contains a typo (i.e., a sequence of three or more consonants with at least two different characters).
4. **Dynamic Programming (DP) for Splitting**: For each typo-containing consonant run, use a DP approach to determine the minimal number of splits needed to eliminate typos. The DP array will help track the minimum splits required up to each position in the consonant run.
5. **Backtrack to Find Split Points**: Once the DP array is built, backtrack to determine the exact positions where splits should occur to achieve the minimal number of splits.
6. **Insert Spaces**: Convert the split points from the consonant runs into positions in the original word and insert spaces accordingly.

    import sys
    word = sys.stdin.readline().strip()
    if not word:
        print(word)
        return
    
    # Split the word into runs of consonants and vowels
    runs = []
    current_run = []
    current_type = None  # 'consonant' or 'vowel'
    start_idx = 0
    for i, c in enumerate(word):
        type_ = 'consonant'
        if is_vowel(c):
            type_ = 'vowel'
        if i == 0:
            current_run.append(c)
            current_type = type_
            start_idx = 0
        else:
            if type_ == current_type:
                current_run.append(c)
            else:
                runs.append({'type': current_type, 'start': start_idx, 'end': i-1, 'chars': current_run})
                current_run = [c]
                current_type = type_
                start_idx = i
    # Add the last run
    if current_run:
        runs.append({'type': current_type, 'start': start_idx, 'end': len(word)-1, 'chars': current_run})
    
    split_positions = []
    
    for run in runs:
        if run['type'] == 'consonant':
            s = ''.join(run['chars'])
            n = len(s)
            if n >= 3 and not all(ch == s[0] for ch in s):
                # Need to split this run
                dp = [float('inf')] * (n + 1)
                dp[0] = 0
                for i in range(1, n + 1):
                    for j in range(i):
                        substr = s[j:i]
                        if len(substr) < 3 or (len(substr) >= 3 and all(ch == substr[0] for ch in substr)):
                            if dp[j] + 1 < dp[i]:
                                dp[i] = dp[j] + 1
                # Backtrack to find the segments
                current = n
                segments = []
                while current > 0:
                    found = False
                    for j in range(current - 1, -1, -1):
                        substr = s[j:current]
                        if len(substr) < 3 or (len(substr) >=3 and all(ch == substr[0] for ch in substr)):
                            if dp[current] == dp[j] + 1:
                                segments.insert(0, substr)
                                current = j
                                found = True
                                break
                    if not found:
                        break  # Shouldn't happen for valid splits
                # Compute split positions within the run
                split_positions_in_run = []
                current_pos = 0
                for seg in segments[:-1]:
                    current_pos += len(seg)
                    split_positions_in_run.append(current_pos - 1)
                # Convert to original word positions
                run_start = run['start']
                for pos_in_run in split_positions_in_run:
                    split_pos = run_start + pos_in_run
                    split_positions.append(split_pos)
    
    # Insert spaces into the word
    split_positions = sorted(split_positions)
    output = list(word)
    for pos in reversed(split_positions):
        output.insert(pos + 1, ' ')
    print(''.join(output))

if __name__ == "__main__":
    main()

### Explanation
1. **Segmentation into Runs**: The word is divided into consecutive runs of vowels and consonants. This helps in isolating segments that need to be checked for typos.
2. **Typo Detection**: Each consonant run is checked to see if it contains a typo by verifying if it has three or more consonants with at least two different characters.
3. **Dynamic Programming**: For each typo-containing consonant run, a DP array is used to determine the minimal number of splits needed. The DP array tracks the minimum splits required up to each position.
4. **Backtracking**: After computing the DP array, backtracking is used to find the exact split points that achieve the minimal splits.
5. **Inserting Spaces**: The identified split points are converted to positions in the original word, and spaces are inserted at these positions to eliminate typos.

This approach ensures that the word is split into the minimum number of segments required to remove all typos, adhering to the problem constraints and requirements.
