To solve this problem, we need to determine if all elements of sequence B are present in sequence A, given that both sequences are sorted in ascending order. The solution must efficiently handle large input sizes up to 200,000 elements each.

### Approach
1. **Two-Pointer Technique**: Utilize two pointers to traverse both sequences A and B. This method leverages the fact that both sequences are sorted, allowing us to check elements in a single pass through each sequence.
2. **Efficient Input Handling**: Read the entire input at once and split it into tokens for efficient processing, which is crucial for handling large inputs in Python.
3. **Comparison Logic**: For each element in B, move the pointer in A until a match is found or until it is determined that the element in B cannot be present in A.

### Solution Code
```python
import sys

def main():
    data = list(map(int, sys.stdin.read().split()))
    ptr = 0
    n = data[ptr]
    ptr += 1
    a = data[ptr:ptr + n]
    ptr += n
    m = data[ptr]
    ptr += 1
    b = data[ptr:ptr + m]
    
    i = 0  # pointer for a
    j = 0  # pointer for b
    
    while j < m and i < n:
        if a[i] == b[j]:
            j += 1
            i += 1
        elif a[i] < b[j]:
            i += 1
        else:
            print(0)
            return
    
    print(1 if j == m else 0)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and split into a list of integers. This approach is efficient for large inputs compared to line-by-line reading.
2. **Two-Pointer Traversal**: 
   - Initialize two pointers, `i` for sequence A and `j` for sequence B.
   - Traverse through both sequences:
     - If elements at both pointers match, move both pointers forward.
     - If the element in A is smaller than the current element in B, move the pointer in A forward.
     - If the element in A is larger, it indicates the element in B is not present in A, leading to an immediate output of 0.
3. **Final Check**: After traversal, if all elements of B have been matched (pointer `j` reaches the end of B), output 1. Otherwise, output 0.

This approach ensures that each element is checked in linear time, resulting in an overall time complexity of O(n + m), which is optimal for the given constraints.
