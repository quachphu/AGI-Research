To solve this problem, we need to determine how many times Lesha will restart a song while it is downloading. The key insight is that each time Lesha restarts the song, the downloaded portion of the song grows exponentially based on the given download rate.

### Approach
1. **Problem Analysis**: Lesha starts playing the song once the first part of it is downloaded. Each time he plays the downloaded portion, the remaining part of the song continues to download. The download speed is such that for every real-time second, `q-1` seconds of the song are downloaded. This means that during the time Lesha plays `S` seconds of the song, the downloaded portion increases to `S * q`.

2. **Key Insight**: The downloaded portion of the song grows exponentially each time Lesha restarts the song. Specifically, after each restart, the downloaded portion is multiplied by `q`. We need to count how many such multiplications are required until the downloaded portion is at least the total duration of the song `T`.

3. **Algorithm**: We repeatedly multiply the initial downloaded portion `S` by `q` until it meets or exceeds `T`. Each multiplication represents a restart of the song. The count of these multiplications gives the number of times Lesha restarts the song.

### Solution Code
```python
def calculate_restarts():
    import sys
    T, S, q = map(int, sys.stdin.readline().split())
    count = 0
    current = S
    while current < T:
        current *= q
        count += 1
    print(count)

calculate_restarts()
```

### Explanation
- **Reading Input**: The input values for the total song duration `T`, initial downloaded portion `S`, and download rate factor `q` are read from standard input.
- **Initialization**: We initialize `current` to the initial downloaded portion `S` and a counter `count` to zero.
- **Loop Until Full Download**: Using a loop, we repeatedly multiply `current` by `q` and increment the counter until `current` meets or exceeds `T`.
- **Output Result**: The counter, which now holds the number of restarts, is printed.

This approach efficiently computes the number of restarts by leveraging the exponential growth of the downloaded portion, ensuring an optimal solution with a time complexity of O(log(T/S)) due to the repeated multiplication by `q`.
