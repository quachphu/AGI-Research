To solve this problem, we need to determine if E869120 can pay exactly N yen using A 1-yen coins and an unlimited number of 500-yen coins. The solution involves checking if there exists a combination of 500-yen coins and 1-yen coins that sum up to exactly N yen without exceeding the available 1-yen coins.

### Approach
1. **Understanding the Problem**: We need to check if the total amount N can be formed using some number of 500-yen coins (let's denote this number as x) and some number of 1-yen coins (denoted as y). The key constraint is that y (the remaining amount after using x 500-yen coins) must be between 0 and A (inclusive).

2. **Mathematical Formulation**: For each possible number of 500-yen coins x, the remaining amount after using x coins is `N - 500 * x`. This remaining amount must be non-negative and less than or equal to A. 

3. **Efficient Check**: Instead of iterating through all possible values of x, we can use mathematical insights to determine the valid range for x. The valid values of x must satisfy:
   - `0 <= N - 500 * x <= A`
   - Rearranging gives: `(N - A) / 500 <= x <= N / 500`
   - We need to check if there exists an integer x in this range.

### Solution Code
```python
def main():
    n = int(input())
    a = int(input())
    lower_bound = max((n - a + 499) // 500, 0)
    upper_bound = n // 500
    print("Yes" if lower_bound <= upper_bound else "No")

main()
```

### Explanation
1. **Reading Input**: The input values N (total amount) and A (number of 1-yen coins) are read from standard input.
2. **Calculating Bounds**:
   - **Lower Bound**: The lower bound for x is calculated using the formula `(N - A + 499) // 500` to handle ceiling division efficiently. This ensures we start checking from the smallest possible x that could leave a valid remaining amount (<= A).
   - **Upper Bound**: The upper bound for x is simply `N // 500`, which is the maximum number of 500-yen coins that can be used without exceeding N.
3. **Check Validity**: If the calculated lower bound is less than or equal to the upper bound, it means there exists a valid x, and we print "Yes". Otherwise, we print "No".

This approach efficiently narrows down the possible values of x using mathematical operations, ensuring the solution is both optimal and easy to understand.
