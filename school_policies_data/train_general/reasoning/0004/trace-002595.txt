To solve this problem, we need to determine the minimum number of letters to remove from a word to make it K-good. A word is K-good if the absolute difference between the frequencies of any two letters is at most K. The approach involves finding the maximum possible sum of valid letter frequencies that satisfy the K-good condition, then subtracting this sum from the original word length to get the required deletions.

### Approach
1. **Frequency Calculation**: Compute the frequency of each character in the word using a counter.
2. **Range Evaluation**: For each possible maximum frequency value (from 0 to the maximum frequency in the word), calculate the valid sum of frequencies where each frequency lies within the range [max_frequency - K, max_frequency].
3. **Maximize Valid Sum**: Determine the maximum valid sum of frequencies across all possible ranges. The minimum deletions required is the original word length minus this maximum valid sum.

### Solution Code
```python
import sys
from collections import Counter

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        w = input[ptr]
        K = int(input[ptr + 1])
        ptr += 2
        counts = list(Counter(w).values())
        sum_total = len(w)
        if not counts:
            print(0)
            continue
        max_count = max(counts)
        best = 0
        for m in range(max_count + 1):
            lower = m - K
            current_sum = 0
            for c in counts:
                if c >= lower:
                    current_sum += min(c, m)
            if current_sum > best:
                best = current_sum
        print(sum_total - best)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list for efficient processing.
2. **Frequency Calculation**: Using `Counter` from the `collections` module, we count the frequency of each character in the word.
3. **Range Evaluation**: For each possible maximum frequency value `m`, compute the lower bound of the valid range as `m - K`. For each character frequency, check if it lies within this range and accumulate the valid sum.
4. **Maximize Valid Sum**: Track the maximum valid sum across all possible maximum frequency values. The result for each test case is the original word length minus this maximum valid sum, which gives the minimum deletions required.

This approach efficiently checks all possible valid ranges for the character frequencies and ensures that we find the optimal solution with minimal deletions.
