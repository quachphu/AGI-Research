To solve this problem, we need to reverse the process of creating a dubstep remix by removing the inserted "WUB" substrings and restoring the original song. The key insight is that all occurrences of "WUB" in the remix were added by Vasya and should be removed, with the remaining parts forming the original words of the song.

### Approach
1. **Input Handling**: Read the input string which represents the dubstep remix.
2. **Splitting the String**: Split the input string by the substring "WUB". This will give us parts of the original song interspersed with empty strings where "WUB" was present.
3. **Filtering Empty Strings**: Remove any empty strings from the split result. These empty strings result from consecutive or leading/trailing "WUB" substrings.
4. **Joining the Words**: Join the remaining non-empty parts with spaces to form the original song.

### Solution Code
```python
def restore_song():
    s = input().strip()
    parts = s.split('WUB')
    filtered = [p for p in parts if p]
    print(' '.join(filtered))

restore_song()
```

### Explanation
- **Splitting the String**: The `split('WUB')` method breaks the input string at every occurrence of "WUB", resulting in a list of substrings. For example, "WUBWUBABCWUB" becomes `['', '', 'ABC', '']`.
- **Filtering**: The list comprehension `[p for p in parts if p]` removes all empty strings from the list. This step is crucial because consecutive or leading/trailing "WUB" substrings create empty entries in the list.
- **Joining**: The `join` method combines the filtered list into a single string with spaces between the original words, effectively reconstructing the original song.

This approach efficiently processes the input string in linear time relative to its length, ensuring optimal performance even for the maximum input size.
