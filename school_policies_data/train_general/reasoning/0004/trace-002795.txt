To solve this problem, we need to determine the maximum number of days an expedition can last given the constraints that each participant must eat the same type of food every day, and each participant can choose a different food type. The solution involves calculating the maximum possible days based on the available food packages.

### Approach
1. **Count Food Types**: First, we count the frequency of each food type available in the warehouse.
2. **Iterate Over Possible Days**: Starting from the maximum possible days (determined by the highest frequency of any food type), we check each possible number of days in descending order.
3. **Check Feasibility**: For each number of days, we check if the total number of participants that can be supported by the available food packages meets or exceeds the number of participants. This is done by summing the quotient of each food type's count divided by the current number of days being checked.
4. **Early Termination**: If a feasible number of days is found, we immediately return it as the result.

### Solution Code
```python
from collections import Counter

n, m = map(int, input().split())
a = list(map(int, input().split()))
counts = Counter(a)

max_count = max(counts.values())

for d in range(max_count, 0, -1):
    total = 0
    for c in counts.values():
        total += c // d
        if total >= n:
            break
    if total >= n:
        print(d)
        exit()

print(0)
```

### Explanation
1. **Counting Frequencies**: Using the `Counter` from the `collections` module, we count how many times each food type appears in the input list.
2. **Maximum Possible Days**: The maximum possible days the expedition can last is initially set to the highest frequency of any food type. This is because the most frequent food type could potentially be the limiting factor.
3. **Checking Each Day**: Starting from the highest possible day count down to 1, we check each value. For each day count `d`, we compute how many participants can be supported by dividing each food type's count by `d` and summing these values. If the sum meets or exceeds the number of participants, `d` is the answer.
4. **Early Termination**: As soon as a valid day count is found, the solution is printed and the program exits, ensuring optimal performance by avoiding unnecessary checks.

This approach efficiently narrows down the maximum possible days using a greedy strategy, ensuring we find the optimal solution with minimal computational overhead.
