To solve this problem, we need to determine the maximum number of points that can be saved by placing two horizontal platforms of length \( k \) optimally on a plane. The points fall downwards, and a point is saved if it collides with any platform. The solution involves finding the optimal positions for these platforms to maximize the number of points saved.

### Approach
1. **Sorting**: First, sort the x-coordinates of the points. This helps in efficiently determining the intervals covered by the platforms.
2. **Sliding Window for Single Platform**: Use a sliding window technique to determine the maximum number of points that can be covered by a single platform of length \( k \).
3. **Suffix Maximum Array**: Precompute the maximum number of points that can be covered by any interval starting from each position to the end of the array. This helps in efficiently finding the best non-overlapping interval for the second platform.
4. **Non-overlapping Intervals**: For each possible position of the first platform, find the best possible second platform that starts after the first platform ends, using the suffix maximum array.
5. **Overlapping Intervals**: Check the maximum number of points that can be covered by a window of length \( 2k \), which can be covered by two overlapping platforms.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr +=1
    for _ in range(t):
        n, k = int(input[ptr]), int(input[ptr+1])
        ptr +=2
        x = list(map(int, input[ptr:ptr+n]))
        ptr +=n
        # Read y, but ignore
        ptr +=n
        x.sort()
        if n ==0:
            print(0)
            continue
        # Compute count for each position using sliding window
        count = []
        right =0
        for left in range(n):
            while right < n and x[right] <= x[left] +k:
                right +=1
            count.append(right - left)
        max_single = max(count) if count else 0
        
        # Compute suffix_max
        suffix_max = [0]*n
        suffix_max[-1] = count[-1]
        for i in range(n-2, -1, -1):
            suffix_max[i] = max(count[i], suffix_max[i+1])
        
        # Compute max_two_non_overlap
        max_two_non_overlap =0
        for i in range(n):
            end_i = x[i] +k
            j_start = bisect.bisect_right(x, end_i)
            if j_start >=n:
                continue
            current = count[i] + suffix_max[j_start]
            if current > max_two_non_overlap:
                max_two_non_overlap = current
        
        # Compute max_two_overlap
        max_two_overlap =0
        right_2k =0
        for left in range(n):
            while right_2k <n and x[right_2k] <= x[left] + 2*k:
                right_2k +=1
            current = right_2k - left
            if current > max_two_overlap:
                max_two_overlap = current
        
        answer = max(max_single, max_two_non_overlap, max_two_overlap)
        print(answer)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Sorting**: The x-coordinates are sorted to facilitate efficient interval calculations.
2. **Sliding Window**: For each starting position of the platform, determine the maximum number of points covered by a platform of length \( k \).
3. **Suffix Maximum Array**: This array helps in quickly finding the best possible non-overlapping interval for the second platform.
4. **Non-overlapping Intervals**: For each interval, find the best subsequent non-overlapping interval using the suffix maximum array.
5. **Overlapping Intervals**: Check intervals of length \( 2k \) to find the maximum points covered by two overlapping platforms.

This approach ensures that we efficiently consider both overlapping and non-overlapping scenarios, providing the optimal solution within the constraints.
