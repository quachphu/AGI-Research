To solve this problem, we need to determine the minimum amount Darshit needs to spend on buying gifts for his friend Diksha. The gifts can be either black or white, and each type has a different cost. Additionally, there is a conversion cost to change a gift from one color to another. The goal is to minimize the total cost by considering both direct purchase and conversion options.

### Approach
1. **Understanding Costs**: For each type of gift (black or white), calculate the effective cost considering both direct purchase and conversion from the other type. The conversion cost is added to the base cost of the other gift type.
2. **Optimal Cost Calculation**: For each test case, compute the minimum cost for black gifts by comparing the direct cost with the cost of converting white gifts to black. Similarly, compute the minimum cost for white gifts by comparing the direct cost with the cost of converting black gifts to white.
3. **Summing Costs**: Sum the costs for all black and white gifts to get the total minimum cost for each test case.

### Solution Code
```python
def calculate_min_cost():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        B = int(input[idx])
        W = int(input[idx+1])
        idx += 2
        X = int(input[idx])
        Y = int(input[idx+1])
        Z = int(input[idx+2])
        idx += 3
        
        cost_black = B * min(X, Y + Z)
        cost_white = W * min(Y, X + Z)
        total = cost_black + cost_white
        print(total)

calculate_min_cost()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints. The input is split into a list for easy access.
2. **Loop Through Test Cases**: For each test case, read the number of black (B) and white (W) gifts, followed by the costs (X for black, Y for white, and Z for conversion).
3. **Cost Calculation**:
   - **Black Gifts**: The cost for each black gift is the minimum of buying it directly (X) or converting a white gift (Y + Z).
   - **White Gifts**: The cost for each white gift is the minimum of buying it directly (Y) or converting a black gift (X + Z).
4. **Total Cost**: Sum the costs for all black and white gifts and print the result for each test case.

This approach ensures that we always choose the cheapest option for each gift type, either by direct purchase or conversion, leading to the minimum total cost efficiently.
