3. **LCM Calculation**: Calculate the Least Common Multiple (LCM) of the intervals `a` and `b` to determine positions that contribute to both programs.
4. **Contribution Calculation**: For each candidate number of tickets `m`, compute the contributions from positions that are multiples of `a`, `b`, both, or neither. This is done using inclusion-exclusion principles.
5. **Binary Search**: Use binary search to efficiently find the minimum number of tickets needed to meet the contribution target.

### Solution Code
```python
import sys
import math

def main():
    q = int(sys.stdin.readline())
    for _ in range(q):
        n = int(sys.stdin.readline())
        p = list(map(int, sys.stdin.readline().split()))
        x, a = map(int, sys.stdin.readline().split())
        y, b = map(int, sys.stdin.readline().split())
        k = int(sys.stdin.readline())
        
        p.sort(reverse=True)
        prefix_p = [0] * (n + 1)
        for i in range(1, n + 1):
            prefix_p[i] = prefix_p[i - 1] + p[i - 1]
        
        if a == 0 or b == 0:
            lcm_ab = 0
        else:
            gcd_ab = math.gcd(a, b)
            lcm_ab = a * b // gcd_ab
        
        def compute_sum(m):
            if m == 0:
                return 0
            count_both = m // lcm_ab
            count_a = (m // a) - count_both
            count_b = (m // b) - count_both
            s1 = x + y
            s2 = max(x, y)
            s3 = min(x, y)
            if x >= y:
                count_s2 = count_a
                count_s3 = count_b
            else:
                count_s2 = count_b
                count_s3 = count_a
            count_s1 = count_both
            
            take_s1 = min(count_s1, m)
            sum_s1 = (prefix_p[take_s1] * s1) // 100
            
            take_s2_start = take_s1
            take_s2_end = min(take_s2_start + count_s2, m)
            sum_s2 = ((prefix_p[take_s2_end] - prefix_p[take_s2_start]) * s2) // 100
            
            take_s3_start = take_s2_end
            take_s3_end = min(take_s3_start + count_s3, m)
            sum_s3 = ((prefix_p[take_s3_end] - prefix_p[take_s3_start]) * s3) // 100
            
            return sum_s1 + sum_s2 + sum_s3
        
        max_possible = compute_sum(n)
        if max_possible < k:
            print(-1)
            continue
        
        low = 1
        high = n
        ans = -1
        while low <= high:
            mid = (low + high) // 2
            current_sum = compute_sum(mid)
            if current_sum >= k:
                ans = mid
                high = mid - 1
            else:
                low = mid + 1
        print(ans if ans != -1 else -1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Input Parsing and Sorting**: The input is read and the ticket prices are sorted in descending order to maximize contributions from higher-priced tickets.
2. **Prefix Sum Calculation**: A prefix sum array is created to quickly compute the sum of the top `m` tickets.
3. **LCM Calculation**: The LCM of intervals `a` and `b` is calculated to identify positions contributing to both programs.
4. **Contribution Calculation**: For each candidate `m`, the number of contributions from each interval type (a, b, both, neither) is determined using inclusion-exclusion. The contributions are then computed using the sorted ticket prices and the prefix sums.
5. **Binary Search**: Binary search is used to efficiently find the minimum number of tickets needed to meet the contribution target, checking each candidate `m` using the contribution calculation function.

This approach ensures that we efficiently determine the minimum number of tickets needed while considering all possible contributions from the given intervals.
