To solve this problem, we need to find the sum of all products \( x \times y \) such that \( N \) divided by \( x \) equals \( y \) using integer division. Given the constraints, a direct approach of iterating through all possible values of \( x \) from 1 to \( N \) is infeasible for large \( N \). Instead, we use a mathematical optimization to efficiently compute the result.

### Approach
1. **Split the Problem**: Divide the problem into two parts based on the value of \( x \):
   - **Small \( x \) Values**: Directly compute the sum for \( x \) values from 1 to \( \sqrt{N} \).
   - **Large \( x \) Values**: For \( x \) values greater than \( \sqrt{N} \), compute the contributions by grouping values of \( y \) that result from integer division of \( N \) by \( x \).

2. **Mathematical Insight**: For each \( y \), determine the range of \( x \) values that yield the same \( y \) when \( N \) is divided by \( x \). This range is derived from the properties of integer division and allows us to sum contributions efficiently.

3. **Efficient Summation**: Use arithmetic series formulas to compute the sum of \( x \) values for each range, reducing the complexity from \( O(N) \) to \( O(\sqrt{N}) \).

### Solution Code
```python
import math

MOD = 10**9 + 7

def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        N = int(input[i])
        K = math.isqrt(N)
        sum1 = 0
        for x in range(1, K + 1):
            sum1 += x * (N // x)
        sum2 = 0
        y_max = N // (K + 1)
        for y in range(1, y_max + 1):
            m = (N // (y + 1)) + 1
            n = N // y
            lower = max(m, K + 1)
            upper = n
            if lower > upper:
                continue
            count = upper - lower + 1
            sum_x = (lower + upper) * count // 2
            sum2 += y * sum_x
        total = (sum1 + sum2) % MOD
        print(total)

if __name__ == "__main__":
    main()
```
