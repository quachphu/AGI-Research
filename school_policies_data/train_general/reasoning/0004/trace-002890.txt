To solve this problem, we need to determine the values at specific indices of an array after applying a series of cyclic shifts and reversals. Given the constraints, directly simulating each operation on the array would be computationally infeasible. Instead, we can efficiently track the positions of the important indices by reversing the operations from the last query to the first.

### Approach
1. **Reverse Processing of Queries**: Instead of applying each query from start to end, we reverse the order of processing the queries. This allows us to track the origin of each important index backward through each operation.
2. **Handling Cyclic Shifts**: For each cyclic shift right operation (type 1), we reverse it by treating it as a cyclic shift left. This involves adjusting the position of the important index based on its segment boundaries.
3. **Handling Reversals**: A reversal operation (type 2) is its own inverse. Reversing the same segment again will return the original configuration, so we adjust the position by mirroring it within the segment.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n, q, m = map(int, input[ptr:ptr+3])
    ptr +=3
    a = list(map(int, input[ptr:ptr+n]))
    ptr +=n
    queries = []
    for _ in range(q):
        t, l, r = map(int, input[ptr:ptr+3])
        ptr +=3
        queries.append((t, l, r))
    b = list(map(int, input[ptr:ptr+m]))
    ptr +=m
    
    result = []
    for bi in b:
        pos = bi
        for t, l, r in reversed(queries):
            if pos < l or pos > r:
                continue
            if t == 1:
                if pos == l:
                    pos = r
                else:
                    pos -=1
            else:
                pos = l + r - pos
        result.append(str(a[pos-1]))
    print(' '.join(result))
    
if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, and parsed into the array, queries, and important indices.
2. **Processing Each Important Index**: For each important index, we initialize its position and process each query in reverse order.
3. **Adjusting Positions**: For each query, if the current position of the important index is within the affected segment, we adjust the position based on the type of operation. Cyclic shifts are reversed by moving left instead of right, and reversals are handled by mirroring the position within the segment.
4. **Output the Results**: After processing all queries, the original position of each important index is determined, and the corresponding value from the initial array is retrieved and printed.

This approach efficiently tracks the positions of the important indices through all operations, ensuring that we handle up to 200,000 queries in linear time relative to the number of queries and important indices, making it feasible for large input sizes.
