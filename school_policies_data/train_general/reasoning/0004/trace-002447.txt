To solve this problem, we need to determine the minimal number of colors required to paint a sequence of integers such that each color's elements are all divisible by the minimal element of that color. The goal is to minimize the number of colors used.

### Approach
1. **Sort the Array**: First, we sort the array in ascending order. This allows us to process smaller elements first, which helps in forming groups (colors) that can include larger elements if they are divisible by the smaller elements.
2. **Greedy Grouping**: We iterate through each element in the sorted array and attempt to place it into the earliest possible group (color). If an element cannot be placed into any existing group (i.e., it is not divisible by the minimal element of any existing group), we create a new group for it.
3. **Check Divisibility**: For each element, we check all existing groups to see if it can be added. If it can be added to any group, we do so; otherwise, we create a new group.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
a.sort()

groups = []
for num in a:
    if all(num % g != 0 for g in groups):
        groups.append(num)

print(len(groups))
```

### Explanation
1. **Sorting the Array**: By sorting the array, we ensure that we start processing the smallest elements first. This helps in forming groups where the minimal element of each group is as small as possible, allowing more elements to potentially join the group later.
2. **Greedy Grouping**: The algorithm uses a greedy approach to check each element against existing groups. If an element can be added to an existing group (i.e., it is divisible by the group's minimal element), it is added there. If not, a new group is created with this element as the minimal element.
3. **Efficiency**: The algorithm efficiently checks each element against existing groups using a list comprehension and the `all` function, ensuring that each element is processed in O(k) time where k is the number of existing groups. This results in an overall time complexity of O(n log n + nk), which is efficient for the problem constraints (n ≤ 100).

This approach ensures that we use the minimal number of colors by leveraging the sorted order and checking divisibility against existing groups in a systematic manner.
