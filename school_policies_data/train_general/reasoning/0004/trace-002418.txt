To solve this problem, we need to find the greatest beautiful divisor of a given integer \( n \). A beautiful number is defined as a number whose binary representation consists of \( k+1 \) consecutive ones followed by \( k \) consecutive zeros, where \( k \) is a non-negative integer. The formula for generating such numbers is \((2^{k+1} - 1) \times 2^k\).

### Approach
1. **Generate Beautiful Numbers**: We generate all beautiful numbers up to \( n \) using the formula \((2^{k+1} - 1) \times 2^k\) starting from \( k = 0 \) and incrementing \( k \) until the generated number exceeds \( n \).
2. **Check Divisors**: We check each generated beautiful number in descending order to see if it divides \( n \). The first divisor we find in this order is the greatest beautiful divisor.

### Solution Code
```python
n = int(input())

beautiful = []
k = 0
while True:
    a = (2 ** (k + 1) - 1) * (2 ** k)
    if a > n:
        break
    beautiful.append(a)
    k += 1

beautiful.sort(reverse=True)

for num in beautiful:
    if n % num == 0:
        print(num)
        exit()

print(1)
```

### Explanation
1. **Generating Beautiful Numbers**: The loop generates beautiful numbers starting from \( k = 0 \). Each iteration computes the next beautiful number using the formula and stops once the number exceeds \( n \).
2. **Checking Divisors**: The list of beautiful numbers is sorted in descending order. We then iterate through this list to find the largest number that divides \( n \). The first such number encountered is printed as the result. If no such number is found (which is theoretically impossible as 1 is always a divisor), the code defaults to printing 1.

This approach efficiently narrows down the possible candidates and ensures we find the largest divisor quickly by leveraging the properties of beautiful numbers and their generation.
