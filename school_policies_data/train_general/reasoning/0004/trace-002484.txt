To solve this problem, we need to determine if a given number is a circular prime. A circular prime is a prime number that remains prime for all possible rotations of its digits. 

### Approach
1. **Prime Check**: First, check if the given number itself is a prime. If it is not, it cannot be a circular prime.
2. **Generate Rotations**: For each number, generate all possible rotations of its digits. For example, the rotations of 19937 are 19937, 99371, 93719, 37199, and 71993.
3. **Check Leading Zeros**: Ensure that none of the rotations start with a zero, as numbers with leading zeros are not valid primes.
4. **Prime Check for Rotations**: Verify if every rotation of the number is a prime. If all rotations are primes, the number is a circular prime.

### Solution Code
```python
import sys

def is_prime(n):
    if n <= 1:
        return False
    if n <= 3:
        return True
    if n % 2 == 0 or n % 3 == 0:
        return False
    i = 5
    w = 2
    while i * i <= n:
        if n % i == 0:
            return False
        i += w
        w = 6 - w
    return True

def check_circular_prime(n):
    if not is_prime(n):
        return False
    s = str(n)
    length = len(s)
    for i in range(1, length):
        rotated_s = s[i:] + s[:i]
        if rotated_s[0] == '0':
            return False
        rotated_num = int(rotated_s)
        if not is_prime(rotated_num):
            return False
    return True

t = int(sys.stdin.readline())
for _ in range(t):
    n = int(sys.stdin.readline().strip())
    print("Yes" if check_circular_prime(n) else "No")
```

### Explanation
1. **Prime Check Function**: The `is_prime` function efficiently checks if a number is prime by testing divisibility up to the square root of the number, using optimizations to skip even numbers and multiples of 3.
2. **Rotation Generation**: The `check_circular_prime` function converts the number to a string and generates all possible rotations by slicing and concatenating the string. Each rotation is checked for leading zeros and primality.
3. **Handling Input/Output**: The code reads input from standard input, processes each test case, and prints "Yes" or "No" based on whether the number is a circular prime.

This approach ensures that all edge cases, such as leading zeros and non-prime numbers, are handled efficiently, providing an accurate and optimal solution to the problem.
