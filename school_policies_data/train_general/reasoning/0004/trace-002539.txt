To solve this problem, we need to determine the number of valid substrings within a given range for each query. A valid substring is defined as one that contains at most K 0s and at most K 1s. 

### Approach
1. **Preprocessing**: Compute prefix sums for the counts of 0s and 1s in the string. This allows us to quickly determine the count of 0s and 1s in any substring.
2. **Query Processing**: For each query, iterate over all possible substrings within the specified range. Check each substring to see if it meets the criteria of having at most K 0s and K 1s. This is done efficiently using the precomputed prefix sums.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N, K, Q = map(int, input[ptr:ptr+3])
        ptr += 3
        S = input[ptr]
        ptr += 1
        prefix0 = [0] * (N + 1)
        prefix1 = [0] * (N + 1)
        for i in range(N):
            prefix0[i+1] = prefix0[i] + (S[i] == '0')
            prefix1[i+1] = prefix1[i] + (S[i] == '1')
        for __ in range(Q):
            L, R = map(int, input[ptr:ptr+2])
            ptr += 2
            L -= 1  # Convert to 0-based index
            R -= 1
            ans = 0
            # Iterate over all possible starting indices in [L, R]
            for i in range(L, R + 1):
                # Maximum end index is i + 2K -1 (since longer substrings can't be valid)
                max_j = min(i + 2 * K - 1, R)
                # Check all substrings starting at i with length up to 2K or remaining in R
                for j in range(i, max_j + 1):
                    count0 = prefix0[j + 1] - prefix0[i]
                    count1 = prefix1[j + 1] - prefix1[i]
                    if count0 <= K and count1 <= K:
                        ans += 1
            print(ans)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prefix Sum Arrays**: We maintain two arrays, `prefix0` and `prefix1`, where each entry at index `i` contains the count of 0s and 1s respectively from the start of the string up to index `i-1`. This allows us to compute the count of 0s and 1s in any substring in constant time.
2. **Query Handling**: For each query, we convert the 1-based indices to 0-based. For each starting index `i` in the range `[L, R]`, we check all substrings starting at `i` and ending at `j` where `j` ranges from `i` to the minimum of `i + 2K - 1` and `R`. This ensures we only check substrings of valid lengths. For each substring, we use the prefix sums to quickly determine if it meets the criteria and count it if valid.

This approach efficiently handles each query by leveraging precomputed data and limiting the number of substrings checked based on the problem's constraints.
