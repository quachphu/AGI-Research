To solve this problem, we need to determine the minimum number of students who must fail their exams so that each student, when considered independently, can complete their exam within the given total time M. The solution involves a systematic approach to efficiently compute this for each student using a greedy algorithm combined with sorting.

### Approach
1. **Problem Analysis**: Each student takes their exam in sequence, and the total time taken by all preceding students (who did not fail) plus the current student's time must not exceed M. For each student, we need to determine the minimum number of preceding students who must fail to ensure this condition.

2. **Greedy Strategy**: For each student, we consider the sum of the times of the preceding students. To minimize the number of failures, we should allow as many preceding students as possible to take their exams without exceeding the remaining time after accounting for the current student's exam time. This is achieved by sorting the times of the preceding students and selecting the smallest times first until the sum exceeds the remaining time.

3. **Dynamic Calculation**: For each student, calculate the remaining time after accounting for their exam time. Sort the times of all preceding students and use a greedy approach to count how many of these can be included without exceeding the remaining time. The difference between the total number of preceding students and this count gives the minimum number of failures required.

### Solution Code
```python
n, M = map(int, input().split())
t = list(map(int, input().split()))
result = []

for i in range(n):
    s_i = M - t[i]
    prev = t[:i]
    sorted_prev = sorted(prev)
    total = 0
    count = 0
    for num in sorted_prev:
        if total + num > s_i:
            break
        total += num
        count += 1
    result.append(str(i - count))

print(' '.join(result))
```

### Explanation
1. **Input Reading**: Read the number of students `n` and the total allowed time `M`, followed by the list of times each student takes to complete their exam.

2. **Loop Through Each Student**: For each student, compute the remaining time `s_i` after accounting for their own exam time.

3. **Sort Preceding Times**: Collect and sort the exam times of all preceding students.

4. **Greedy Selection**: Sum the sorted times starting from the smallest until adding the next time would exceed the remaining time. Track the count of how many times can be included.

5. **Compute Failures**: The number of failures required is the total number of preceding students minus the count of those that can be included without exceeding the remaining time.

This approach ensures that we efficiently determine the minimum failures needed for each student using sorting and a greedy strategy, leading to an optimal solution within the problem constraints.
