To solve this problem, we need to determine if a given state of a directed graph is reachable from the initial state and, if so, the first time it appears. The graph has vertices with outgoing arcs (red and blue) and a token that moves based on the active arc, which toggles each time the token visits a vertex.

### Approach
1. **Graph Representation**: Read the graph structure, including blue and red arcs for each vertex.
2. **Simulation of Token Movement**: Simulate the token's movement from the initial state (vertex 1 with all blue arcs active) step by step. Track each state (current vertex and active arcs configuration) and the time it first appears.
3. **State Tracking**: Use a dictionary to map each state to its earliest occurrence time.
4. **Query Processing**: For each query, check if the queried state exists in the tracked states and return the corresponding time or -1 if unreachable.

### Solution Code
```python
n = int(input())
edges = []  # edges[0] is dummy, edges[i] is for vertex i (1-based)
edges.append((0, 0))  # dummy
for _ in range(n-1):
    b, r = map(int, input().split())
    edges.append((b, r))

current_vertex = 1
current_parity = 0  # represented as an integer (bitmask)
state_map = {(current_vertex, current_parity): 0}
time = 0

while True:
    u = current_vertex
    new_parity = current_parity ^ (1 << (u-1))
    # Determine the active edge
    active_bit = (new_parity >> (u-1)) & 1
    if active_bit:
        next_v = edges[u][1]
    else:
        next_v = edges[u][0]
    if next_v == n:
        break
    current_vertex = next_v
    current_parity = new_parity
    time += 1
    # Check for loops (though problem states it's impossible)
    if (current_vertex, current_parity) in state_map:

    state_map[(current_vertex, current_parity)] = time

    v = int(parts[0])
```
