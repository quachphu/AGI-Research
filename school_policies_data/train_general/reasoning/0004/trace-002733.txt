To solve this problem, we need to determine the minimum distance required to visit all houses arranged around a circular pond when starting from any one of the houses. The solution involves calculating the largest gap between consecutive houses and avoiding this gap to minimize the travel distance.

### Approach
1. **Understand the Problem Constraints**: The houses are arranged in a circular manner, and movement is restricted to the perimeter of the pond. The goal is to find the optimal path that minimizes the travel distance.
2. **Identify Gaps**: Calculate the gaps between consecutive houses in the sorted order. Additionally, compute the circular gap between the last and the first house to account for the circular nature of the pond.
3. **Determine the Largest Gap**: The largest gap between any two consecutive houses (including the circular gap) is the key factor. By avoiding this largest gap, we can minimize the travel distance.
4. **Calculate Minimum Distance**: The minimum travel distance is the total perimeter of the pond minus the largest gap. This is because avoiding the largest gap allows us to travel the remaining segments of the pond, which sum up to the minimum required distance.

### Solution Code
```python
K, N = map(int, input().split())
A = list(map(int, input().split()))

gaps = []
for i in range(1, N):
    gaps.append(A[i] - A[i-1])

circular_gap = A[0] + (K - A[-1])
gaps.append(circular_gap)

max_gap = max(gaps)
print(K - max_gap)
```

### Explanation
1. **Reading Input**: The input consists of the perimeter of the pond (K), the number of houses (N), and their positions (A).
2. **Calculating Gaps**: For each consecutive pair of houses, compute the gap (distance) between them. This is done using a loop that iterates through the list of house positions.
3. **Circular Gap Calculation**: The gap between the last house and the first house (considering the circular nature) is calculated by adding the distance from the last house to the end of the pond and the distance from the start of the pond to the first house.
4. **Finding the Largest Gap**: Determine the maximum value among all calculated gaps.
5. **Result Calculation**: Subtract the largest gap from the total perimeter (K) to get the minimum travel distance required to visit all houses.

This approach efficiently computes the required minimum distance in linear time, making it suitable for large input sizes as specified in the problem constraints.
