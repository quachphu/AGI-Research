To solve this problem, we need to determine the edit distance between two given words. The edit distance is defined as the minimum number of single-character edits (insertions, deletions, or substitutions) required to transform one word into the other.

### Approach
The problem can be efficiently solved using dynamic programming. The idea is to construct a 2D table where each entry `dp[i][j]` represents the minimum number of edits required to convert the first `i` characters of the first word (`s1`) into the first `j` characters of the second word (`s2`).

1. **Initialization**: 
   - Create a 2D array `dp` with dimensions `(n+1) x (m+1)`, where `n` and `m` are the lengths of `s1` and `s2` respectively.
   - The first row `dp[i][0]` is initialized to `i` because converting the first `i` characters of `s1` to an empty string requires `i` deletions.
   - The first column `dp[0][j]` is initialized to `j` because converting an empty string to the first `j` characters of `s2` requires `j` insertions.

2. **Filling the DP Table**:
   - For each character in `s1` and `s2`, determine the cost of substitution (0 if characters are the same, 1 otherwise).
   - Update each entry `dp[i][j]` by considering the minimum of three possible operations:
     - **Deletion**: `dp[i-1][j] + 1`
     - **Insertion**: `dp[i][j-1] + 1`
     - **Substitution**: `dp[i-1][j-1] + cost`

### Solution Code
```python
def edit_distance():
    s1 = input().strip()
    s2 = input().strip()
    n = len(s1)
    m = len(s2)
    
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    
    for i in range(n + 1):
        dp[i][0] = i
    for j in range(m + 1):
        dp[0][j] = j
    
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if s1[i-1] == s2[j-1]:
                cost = 0
            else:
                cost = 1
            dp[i][j] = min(dp[i-1][j] + 1,      # Deletion
                           dp[i][j-1] + 1,      # Insertion
                           dp[i-1][j-1] + cost) # Substitution
    
    print(dp[n][m])

edit_distance()
```

### Explanation
- **Initialization**: The DP table is initialized such that converting any prefix of `s1` to an empty string requires deletions equal to the length of the prefix, and converting an empty string to any prefix of `s2` requires insertions equal to the length of the prefix.
- **DP Table Filling**: For each pair of characters from `s1` and `s2`, we compute the cost of substitution. If the characters are the same, the cost is 0; otherwise, it is 1. The value at `dp[i][j]` is then determined by considering the minimum cost of the three possible operations (deletion, insertion, substitution) from previously computed values.
- **Result**: The value at `dp[n][m]` gives the minimum edit distance between the entire strings `s1` and `s2`.

This approach efficiently computes the edit distance in O(n*m) time complexity and O(n*m) space complexity, which is optimal for the given problem constraints.
