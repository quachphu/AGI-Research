To solve this problem, we need to simulate a card game between two soldiers where each takes turns playing the top card from their respective stacks. The game continues until one of the players runs out of cards or the game enters an infinite loop. The goal is to determine the number of fights before the game ends and identify the winner, or detect if the game will continue indefinitely.

### Approach
1. **Input Reading**: Read the number of cards and the initial stacks for both players.
2. **Simulation**: Use a deque (double-ended queue) to efficiently manage the cards for each player, allowing easy removal from the front and addition to the back.
3. **Cycle Detection**: Track the states of the game using a set to detect cycles. If a state repeats, the game is in an infinite loop.
4. **Fight Processing**: For each fight, compare the top cards of both players. The winner takes both cards, appending the loser's card first followed by their own card to the bottom of their stack.
5. **Termination Check**: After each fight, check if either player's stack is empty to determine the winner. If a repeated state is detected, the game will loop indefinitely.

### Solution Code
```python
from collections import deque
import sys

def main():
    n = int(sys.stdin.readline())
    k1_line = list(map(int, sys.stdin.readline().split()))
    k1 = k1_line[0]
    p1 = k1_line[1:]
    k2_line = list(map(int, sys.stdin.readline().split()))
    k2 = k2_line[0]
    p2 = k2_line[1:]
    
    dq1 = deque(p1)
    dq2 = deque(p2)
    
    seen = set()
    fight_count = 0
    
    while True:
        if not dq1:
            print(fight_count, 2)
            return
        if not dq2:
            print(fight_count, 1)
            return
        
        state = (tuple(dq1), tuple(dq2))
        if state in seen:
            print(-1)
            return
        seen.add(state)
        
        c1 = dq1.popleft()
        c2 = dq2.popleft()
        
        if c1 > c2:
            dq1.append(c2)
            dq1.append(c1)
        else:
            dq2.append(c1)
            dq2.append(c2)
        
        fight_count += 1

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first line gives the total number of cards, followed by the cards each player starts with.
2. **Deques Initialization**: The cards for each player are stored in deques to allow efficient operations at both ends.
3. **Cycle Detection**: Before processing each fight, the current state (tuples of both players' deques) is checked against previously seen states. If a state repeats, the game is deemed infinite.
4. **Fight Processing**: Each fight involves comparing the top cards. The winner's deque is updated by appending the loser's card followed by their own card.
5. **Termination Check**: After each fight, the code checks if either deque is empty to determine the winner. If a cycle is detected, it outputs `-1`.

This approach ensures that the game is simulated efficiently, with cycle detection preventing infinite loops, making it both optimal and correct for the given constraints.
