To solve this problem, we need to determine the eight finalists for an athletics competition based on the given rules. The finalists are selected from three groups of runners, each group having eight participants. The top two from each group automatically qualify, and the next two fastest runners from the remaining participants across all groups also qualify.

### Approach
1. **Input Reading and Parsing**: Read the input which contains 24 lines, each representing a runner's number and their time.
2. **Group Division**: Divide the input into three groups of eight runners each.
3. **Sorting and Qualification**: For each group, sort the runners by their time in ascending order. The top two runners from each group qualify directly.
4. **Non-Qualifiers Collection**: Collect all runners who did not make the top two in their respective groups.
5. **Selecting Remaining Finalists**: Sort the non-qualifiers by their time and select the top two fastest runners.
6. **Output**: Print the finalists in the specified order.

### Solution Code
```python
import sys

def main():
    lines = [line.strip() for line in sys.stdin if line.strip()]
    
    groups = []
    for i in range(3):
        start = i * 8
        end = start + 8
        group = []
        for line in lines[start:end]:
            p, t = line.split()
            group.append((int(p), float(t)))
        groups.append(group)
    
    qualifiers = []
    non_qual = []
    
    for group in groups:
        sorted_group = sorted(group, key=lambda x: x[1])
        qualifiers.extend(sorted_group[:2])
        non_qual.extend(sorted_group[2:])
    
    sorted_non_qual = sorted(non_qual, key=lambda x: x[1])
    qualifiers.extend(sorted_non_qual[:2])
    
    for q in qualifiers[:8]:
        print(f"{q[0]} {q[1]:.2f}")

main()
```

### Explanation
1. **Reading Input**: The input is read line by line and stored in a list. Each line is stripped of any leading or trailing whitespace.
2. **Group Division**: The input lines are divided into three groups of eight runners each. Each group is parsed into a list of tuples where each tuple contains a runner's number (as an integer) and their time (as a float).
3. **Sorting and Qualification**: Each group is sorted by the runners' times. The top two runners from each sorted group are added to the qualifiers list. The remaining runners from each group are added to the non-qualifiers list.
4. **Selecting Remaining Finalists**: The non-qualifiers are sorted by their times, and the top two fastest runners are added to the qualifiers list.
5. **Output**: The qualifiers list, which now contains the top two from each group and the two fastest non-qualifiers, is printed in the required order. Each runner's number and time are formatted to ensure the time is displayed with two decimal places.

This approach efficiently processes the input, sorts the runners as needed, and ensures the correct finalists are selected and printed in the specified order.
