To solve this problem, we need to compute the temperature difference between the maximum and minimum temperatures for each day over a span of 7 days. The goal is to read input values for each day, compute the temperature difference, and output the results for each day.

### Approach
1. **Reading Input**: We will read 7 lines of input where each line contains two integers representing the maximum and minimum temperatures of a day.
2. **Processing Each Line**: For each line, we split the input into two integers, compute the difference between the maximum and minimum temperatures, and store or print the result immediately.
3. **Output the Results**: Print each computed temperature difference on a new line.

The approach is straightforward as it involves reading each line, processing it to compute the temperature difference, and outputting the result. This ensures that we handle each day's data individually and efficiently.

### Solution Code
```python
def main():
    for _ in range(7):
        a, b = map(int, input().split())
        print(a - b)

main()
```

### Explanation
1. **Reading Input**: The function `input().split()` reads a line from standard input and splits it into two parts. Using `map(int, ...)` converts these parts into integers.
2. **Computing Difference**: For each pair of integers (a, b), we compute the difference `a - b`, which gives the temperature difference for that day.
3. **Printing Result**: The result is immediately printed, ensuring that each line of input corresponds directly to a line of output.

This method efficiently processes each day's temperature data in sequence, ensuring clarity and correctness while adhering to the problem constraints.
