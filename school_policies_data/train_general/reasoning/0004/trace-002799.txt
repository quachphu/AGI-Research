To solve this problem, we need to determine the minimum capacity of a tram such that the number of passengers inside the tram never exceeds this capacity at any point during its journey through a series of stops. The tram starts empty and processes passengers by first allowing existing passengers to exit and then new passengers to enter at each stop.

### Approach
1. **Initialization**: Start with an empty tram (0 passengers) and track the maximum number of passengers encountered during the journey.
2. **Iterate Through Stops**: For each stop, update the current number of passengers by first subtracting those who exit and then adding those who enter.
3. **Track Maximum Capacity**: After processing each stop, check if the current number of passengers exceeds the previously recorded maximum and update the maximum if necessary.
4. **Output the Result**: The maximum value recorded during the iteration is the minimum required capacity of the tram.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    data = list(map(int, input[1:]))
    
    current_passengers = 0
    max_capacity = 0
    
    for i in range(n):
        a = data[2 * i]
        b = data[2 * i + 1]
        current_passengers = current_passengers - a + b
        if current_passengers > max_capacity:
            max_capacity = current_passengers
    
    print(max_capacity)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go and split into a list of integers for easier processing. The first value is the number of stops, followed by pairs of integers representing passengers exiting and entering at each stop.
2. **Processing Each Stop**: For each stop, the number of passengers is adjusted by first subtracting the passengers who exit and then adding those who enter. This adjustment is done in a single step to maintain clarity and efficiency.
3. **Updating Maximum Capacity**: After adjusting the passenger count for each stop, we check if this new count exceeds the previously recorded maximum. If it does, the maximum is updated.
4. **Output**: The maximum capacity encountered during the journey is printed as the result.

This approach ensures that we efficiently track the required capacity by processing each stop in linear time, making the solution both optimal and easy to understand.
