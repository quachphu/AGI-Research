To solve this problem, we need to determine if a triangle is valid based on its three given angles. A triangle is valid if the sum of its angles is exactly 180 degrees and each angle is a positive number.

### Approach
1. **Input Reading**: Read the number of test cases, followed by the three angles for each test case.
2. **Validation Check**: For each set of angles, check two conditions:
   - The sum of the angles must be exactly 180 degrees.
   - Each angle must be greater than 0.
3. **Output Result**: For each test case, print "YES" if both conditions are satisfied, otherwise print "NO".

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        A = int(input[idx])
        B = int(input[idx+1])
        C = int(input[idx+2])
        idx += 3
        if A + B + C == 180 and A > 0 and B > 0 and C > 0:
            print("YES")
        else:
            print("NO")

main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and split into a list for efficient processing. This is particularly useful when dealing with a large number of test cases.
2. **Loop Through Test Cases**: For each test case, we extract the three angles and check the validity conditions.
3. **Check Validity Conditions**: The sum of the angles is checked to be 180, and each angle is verified to be greater than 0. If both conditions are met, the triangle is valid; otherwise, it is not.

This approach ensures that each test case is processed efficiently and correctly, adhering to the problem constraints and requirements.
