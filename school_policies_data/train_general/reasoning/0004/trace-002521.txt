To solve this problem, we need to compute the product of two numbers A and B, where B is given with exactly two decimal places, and then truncate the fractional part of the result to output an integer. The challenge is to handle the precision correctly to avoid errors due to floating-point arithmetic.

### Approach
1. **Input Handling**: Read the input values A and B as strings to preserve the precision of B.
2. **Parse B**: Split B into its integer part and fractional part. Since B has exactly two decimal places, convert these parts into an integer representation by combining them. For example, B = 1.10 becomes 110 (1 * 100 + 10).
3. **Exact Calculation**: Multiply A (as an integer) by the integer representation of B and then divide by 100 using integer division to truncate the fractional part. This avoids any floating-point inaccuracies.

### Solution Code
```python
A, B = input().split()
integer_part, decimal_part = B.split('.')
B_integer = int(integer_part) * 100 + int(decimal_part)
result = (int(A) * B_integer) // 100
print(result)
```

### Explanation
1. **Reading Input**: The input is read as a string and split into A and B. A is directly converted to an integer.
2. **Processing B**: B is split into its integer and fractional parts. These parts are then combined into a single integer by multiplying the integer part by 100 and adding the fractional part. This effectively scales B by 100 to avoid dealing with decimals directly.
3. **Multiplication and Division**: The product of A and the scaled B is computed. Dividing this product by 100 using integer division truncates the fractional part, giving the correct result without any floating-point errors.

This approach ensures that all operations are performed using integers, thus maintaining precision and avoiding issues related to floating-point arithmetic.
