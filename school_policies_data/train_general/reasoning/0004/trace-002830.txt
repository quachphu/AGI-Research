To solve this problem, we need to maximize the total purchase price when selling K books out of N to a secondhand bookstore, where the price of each book increases based on the number of books of the same genre sold together. The goal is to determine the optimal selection of books to maximize the total price.

### Approach
1. **Group Books by Genre**: First, we categorize the books by their genre. This helps in calculating the price increments for each genre separately.
2. **Sort and Compute Prefix Sums**: For each genre, sort the books by their standard price in descending order and compute prefix sums. This allows us to quickly determine the maximum sum of prices for any number of books selected from that genre.
3. **Dynamic Programming (DP)**: Use a dynamic programming approach to keep track of the maximum total price achievable for selecting a certain number of books. For each genre, update the DP array to consider all possible numbers of books that can be selected from that genre and their corresponding price increments.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n, k = map(int, sys.stdin.readline().split())
    genres = defaultdict(list)
    for _ in range(n):
        c, g = map(int, sys.stdin.readline().split())
        genres[g].append(c)
    
    # Preprocess each genre: sort, compute prefix sums and values
    genre_data = {}
    for g in range(1, 11):
        if g not in genres:
            genre_data[g] = [0]  # Only t=0 is possible
            continue
        books = sorted(genres[g], reverse=True)
        m = len(books)
        prefix = [0] * (m + 1)
        for i in range(1, m + 1):
            prefix[i] = prefix[i-1] + books[i-1]
        # Compute values for each t in 0..m
        values = []
        for t in range(m + 1):
            val = prefix[t] + t * (t - 1)
            values.append(val)
        genre_data[g] = values
    
    # Initialize DP array
    dp = [-float('inf')] * (k + 1)
    dp[0] = 0  # Base case: 0 books selected gives 0 value
    
    for g in range(1, 11):
        values = genre_data[g]
        m = len(values) - 1  # Maximum t for this genre
        new_dp = [-float('inf')] * (k + 1)
        for j in range(k + 1):
            if dp[j] == -float('inf'):
                continue
            max_t = min(m, k - j)
            for t in range(0, max_t + 1):
                new_j = j + t
                if new_j > k:
                    continue
                candidate = dp[j] + values[t]
                if candidate > new_dp[new_j]:
                    new_dp[new_j] = candidate
        dp = new_dp
    
    print(dp[k] if dp[k] != -float('inf') else 0)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Grouping by Genre**: Books are grouped by their genre to handle each genre's pricing rules separately.
2. **Prefix Sum Calculation**: For each genre, we sort the books by their price in descending order and compute prefix sums to efficiently calculate the sum of the top t books.
3. **Dynamic Programming**: The DP array `dp[j]` keeps track of the maximum total price achievable by selecting j books. For each genre, we update the DP array by considering all possible numbers of books (t) that can be selected from that genre, updating the total price accordingly.

This approach ensures that we efficiently explore all possible combinations of book selections across genres, leading to the optimal solution. The complexity is managed through dynamic programming, making it feasible to handle the constraints effectively.
