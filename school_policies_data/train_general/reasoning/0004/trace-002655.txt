To solve this problem, we need to transform a given tree into a "beautiful" tree with the minimum number of color swap operations. A tree is considered beautiful if every vertex is within a certain distance `x` from at least one black vertex. The solution involves finding the optimal set of vertices to swap colors such that all vertices meet the distance criterion.

### Approach
1. **Precompute Distances**: Calculate the shortest path between all pairs of vertices using BFS, since the tree structure allows efficient distance computation.
2. **Coverage Sets**: For each vertex, determine which other vertices are within the distance `x` (coverage set).
3. **Initial Check**: Check if the initial set of black vertices already forms a beautiful tree. If yes, no swaps are needed.
4. **Generate Combinations**: If the initial set is not sufficient, generate combinations of vertices of size `k` (number of initial black vertices) and check if their coverage includes all vertices. Track the minimum number of swaps required.

import sys
from itertools import combinations
from collections import deque

def main():
    n, x = map(int, sys.stdin.readline().split())
    colors = list(map(int, sys.stdin.readline().split()))
    edges = [[] for _ in range(n)]
    for _ in range(n-1):
        u, v, w = map(int, sys.stdin.readline().split())
        u -= 1
        v -= 1
        edges[u].append((v, w))
        edges[v].append((u, w))
    
    # Precompute all pairwise distances using BFS for each node
    distance = [[0]*n for _ in range(n)]
    for u in range(n):
        q = deque()
        q.append(u)
        dist = [-1]*n
        dist[u] = 0
        while q:
            current = q.popleft()
            for (v, w) in edges[current]:
                if dist[v] == -1 or dist[current] + w < dist[v]:
                    dist[v] = dist[current] + w
                    q.append(v)
        for v in range(n):
            distance[u][v] = dist[v]
    
    # Compute coverage for each node
    coverage = []
    for u in range(n):
        cov = []
        for v in range(n):
            if distance[u][v] <= x:
                cov.append(v)
        coverage.append(cov)
    
    # Initial black nodes
    initial_black = [i for i in range(n) if colors[i] == 1]
    k = len(initial_black)
    if k == 0:
        # All red, can't swap
        print(-1)
        return
    
    # Check if initial blacks cover all
    covered = set()
    for u in initial_black:
        covered.update(coverage[u])
    if len(covered) == n:
        print(0)
        return
    
    # Now need to find a subset S of size k, possibly different from initial_black, with minimal red nodes in S
    # Generate all possible subsets of size k and check coverage
    min_swaps = float('inf')
    all_nodes = list(range(n))
