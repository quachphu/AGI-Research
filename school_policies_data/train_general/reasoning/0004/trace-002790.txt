To solve this problem, we need to determine the minimum and maximum number of declarations possible in a divisor game where each declared number must not be a divisor of any previously declared number. The solution involves understanding the prime factorization of the given number and using properties of divisors.

### Approach

1. **Prime Factorization**: Factorize the given number \( N \) into its prime factors. This helps in determining the structure of the divisors.
2. **Minimum Declarations**: The minimum number of declarations is determined by the number of distinct prime factors of \( N \). This is because each prime factor can cover all its higher powers and products in the divisor set.
3. **Maximum Declarations**: The maximum number of declarations is simply the total number of proper divisors of \( N \) (excluding \( N \) itself). This is derived from the count of all divisors of \( N \) and subtracting 1.

### Solution Code

```python
import sys
import math

def factorize(n):
    factors = {}
    while n % 2 == 0:
        factors[2] = factors.get(2, 0) + 1
        n //= 2
    i = 3
    max_factor = math.isqrt(n) + 1
    while i <= max_factor and n > 1:
        while n % i == 0:
            factors[i] = factors.get(i, 0) + 1
            n //= i
            max_factor = math.isqrt(n) + 1
        i += 2
    if n > 1:
        factors[n] = 1
    return factors

def main():
    N = int(sys.stdin.readline())
    if N == 1:
        print("0 0")
        return
    factors = factorize(N)
    min_val = len(factors)
    num_divisors = 1
    for exp in factors.values():
        num_divisors *= (exp + 1)
    max_val = num_divisors - 1
    print(f"{min_val} {max_val}")

if __name__ == "__main__":
    main()
```

1. **Prime Factorization**: The `factorize` function decomposes \( N \) into its prime factors and their respective exponents. This helps in understanding the structure of the divisors.
2. **Minimum Declarations**: The minimum number of declarations is the count of distinct prime factors. Each prime factor can cover all its multiples, ensuring minimal coverage of all divisors.
3. **Maximum Declarations**: The maximum number of declarations is the total number of proper divisors of \( N \). This is calculated by taking the product of each prime factor's exponent incremented by 1 (to account for all possible divisors) and then subtracting 1 to exclude \( N \) itself.
