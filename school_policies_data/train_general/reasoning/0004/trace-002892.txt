To solve this problem, we need to determine the minimum travel expenses required to gather at least `s` different types of goods for each town in Byteland. The travel expense between two towns is defined as the shortest path distance between them. 

### Approach
1. **Input Parsing and Initialization**: Read the input values and initialize data structures to store the towns producing each type of goods and the adjacency list for the roads.
2. **Multi-source BFS for Each Type**: For each type of goods, perform a multi-source BFS starting from all towns that produce that type. This BFS will compute the shortest distance from any town producing the type to all other towns.
3. **Calculate Minimum Expenses for Each Town**: For each town, collect the shortest distances to all other types of goods (excluding its own type), sort these distances, and sum the smallest `s-1` distances (since the town's own type has zero cost).

### Solution Code
```python
import sys
from collections import deque

def main():
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx]); idx +=1
    m = int(input[idx]); idx +=1
    k = int(input[idx]); idx +=1
    s = int(input[idx]); idx +=1
    
    a = list(map(int, input[idx:idx+n]))
    idx +=n
    
    # Build adjacency list (1-based)
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u = int(input[idx]); idx +=1
        v = int(input[idx]); idx +=1
        adj[u].append(v)
        adj[v].append(u)
    
    # For each type, collect the towns
    types = [[] for _ in range(k+1)]  # types[1..k]
    for town in range(1, n+1):
        typ = a[town-1]
        types[typ].append(town)
    
    # Precompute BFS for each type
    dists = [None] * (k+1)  # dists[1..k]
    for t in range(1, k+1):
        nodes = types[t]
        dist = [-1] * (n+1)
        q = deque()
        for node in nodes:
            dist[node] = 0
            q.append(node)
        while q:
            u = q.popleft()
            for v in adj[u]:
                if dist[v] == -1:
                    dist[v] = dist[u] + 1
                    q.append(v)
        dists[t] = dist
    
    # Compute the answer for each town
    output = []
    for town in range(1, n+1):
        my_type = a[town-1]
        others = []
        for t in range(1, k+1):
            if t != my_type:
                others.append(dists[t][town])
        others.sort()
        if s-1 <= 0:
            res = 0
        else:
            res = sum(others[:s-1])
        output.append(str(res))
    
    print(' '.join(output))
    
if __name__ == '__main__':
    main()
```

### Explanation
1. **Input Parsing**: The input is read and parsed into variables for the number of towns, roads, types of goods, and required types. The adjacency list for the roads is built to represent the graph.
2. **Multi-source BFS**: For each type of goods, a BFS is initiated from all towns producing that type. This BFS computes the shortest distance from any town producing the type to all other towns, which helps in determining the minimum travel cost for each type.
3. **Calculate Minimum Expenses**: For each town, the shortest distances to all other types (excluding its own) are collected, sorted, and the smallest `s-1` distances are summed to get the minimum travel expense. This approach ensures that we efficiently compute the required values using BFS, which is optimal for shortest path problems in unweighted graphs.
