class DSU:

    def __init__(self, n):

        self.parent = list(range(n))

        self.size = [1] * n

    def find(self, x):

        if self.parent[x] != x:

            self.parent[x] = self.find(self.parent[x])

        return self.parent[x]

    def union(self, x, y):

        x_root = self.find(x)

        y_root = self.find(y)

        if x_root == y_root:

            return

        if self.size[x_root] < self.size[y_root]:

            x_root, y_root = y_root, x_root

        self.parent[y_root] = x_root

        self.size[x_root] += self.size[y_root]

To solve this problem, we need to compute the sum of the differences between the maximum and minimum values on all simple paths in a tree. The tree is given with vertices each having a value, and we need to consider all pairs of vertices (x, y) and sum the differences between the maximum and minimum values on the path connecting x and y.

### Approach
1. **Problem Analysis**: The problem can be decomposed into two parts: calculating the sum of the maximum values on all paths and the sum of the minimum values on all paths. The final result is the difference between these two sums.

2. **Key Insight**: For each vertex, determine how many times it is the maximum or minimum value on any path. This can be efficiently computed using a Disjoint Set Union (DSU) data structure with Union-Find operations.

3. **Algorithm**:
   - **Sum of Maximum Values (sum_max)**: Process nodes in increasing order of their values. For each node, merge adjacent components where all nodes have values less than or equal to the current node's value. Track the number of new paths where the current node is the maximum.
   - **Sum of Minimum Values (sum_min)**: Process nodes in decreasing order of their values. Similarly, merge components and track paths where the current node is the minimum.

4. **Complexity**: Using DSU with path compression and union by size ensures that each operation is nearly constant time, leading to an efficient solution suitable for large input sizes (up to \(10^6\) nodes).

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]  # Path compression
            x = self.parent[x]
        return x

    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return
        if self.size[x_root] < self.size[y_root]:
            x_root, y_root = y_root, x_root
        self.parent[y_root] = x_root
        self.size[x_root] += self.size[y_root]
