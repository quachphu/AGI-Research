To solve this problem, we need to determine if a given string can be formed by a specific process where characters 'a', 'b', and 'c' are appended in a specific order with certain conditions on their counts. 

### Approach
1. **Order Check**: The string must be composed of a block of 'a's followed by a block of 'b's and then a block of 'c's. Any deviation from this order makes the string invalid.
2. **Count Check**: After ensuring the correct order, we need to check if the number of 'c's (appended by C) is equal to the number of 'a's or 'b's that were present after B appended the 'b's. Additionally, each block must contain at least one character.

### Solution Code
```python
s = input().strip()

split_a = 0
while split_a < len(s) and s[split_a] == 'a':
    split_a += 1

if split_a == 0:
    print("NO")
    exit()

split_b = split_a
while split_b < len(s) and s[split_b] == 'b':
    split_b += 1

if split_b == split_a:
    print("NO")
    exit()

split_c = split_b
while split_c < len(s) and s[split_c] == 'c':
    split_c += 1

if split_c != len(s) or split_c == split_b:
    print("NO")
    exit()

count_a = split_a
count_b = split_b - split_a
count_c = split_c - split_b

if count_c == count_a or count_c == count_b:
    print("YES")
else:
    print("NO")
```

### Explanation
1. **Order Check**: 
   - The string is checked to ensure it starts with 'a's, followed by 'b's, and ends with 'c's. This is done by iterating through the string and splitting it into three parts.
   - If any part is missing (e.g., no 'a's, 'b's, or 'c's), the string is invalid.

2. **Count Check**:
   - After confirming the correct order, the counts of 'a's, 'b's, and 'c's are calculated.
   - The number of 'c's must be equal to either the number of 'a's or the number of 'b's for the string to be valid.

This approach ensures that both the order and the count conditions are met efficiently, with a time complexity of O(n) where n is the length of the string.
