To solve this problem, we need to determine the minimum number of coins required to buy a binary string after optionally flipping some characters. Each flip costs a certain number of coins, and each character in the string has a specific cost. The goal is to find the optimal balance between flipping characters and paying their original costs to minimize the total expenditure.

### Approach
1. **Understand Costs**: For each character in the binary string, we can either keep it as it is or flip it. Flipping a character incurs a cost (h) plus the cost of the new character.
2. **Calculate Minimum Cost for Each Character**:
   - For each '0' in the string, the cost is the minimum of keeping it as '0' (cost c0) or flipping it to '1' (cost h + c1).
   - For each '1' in the string, the cost is the minimum of keeping it as '1' (cost c1) or flipping it to '0' (cost h + c0).
3. **Sum Costs**: Compute the total cost by summing the minimum costs for all characters in the string.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n, c0, c1, h = map(int, sys.stdin.readline().split())
        s = sys.stdin.readline().strip()
        count0 = s.count('0')
        count1 = n - count0
        total = count0 * min(c0, c1 + h) + count1 * min(c1, c0 + h)
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first line contains the number of test cases.
2. **Processing Each Test Case**:
   - For each test case, read the values of n (string length), c0 (cost of '0'), c1 (cost of '1'), and h (flip cost).
   - Read the binary string and count the number of '0's and '1's.
3. **Compute Minimum Costs**:
   - For each '0', compute the minimum cost between keeping it as '0' and flipping it to '1'.
   - For each '1', compute the minimum cost between keeping it as '1' and flipping it to '0'.
4. **Calculate Total Cost**: Sum the minimum costs for all characters and print the result for each test case.

This approach ensures that we efficiently determine the optimal strategy for each character, leading to the minimum possible total cost. The complexity is linear with respect to the length of the string, making the solution efficient even for the upper input limits.
