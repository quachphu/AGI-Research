To solve this problem, we need to determine if there exists at least one group where all members could be traitors in some scenario. A traitor in a universe is either Rick or Morty, but not both. The key insight is that a group can only be all traitors if no universe in the group has both Rick and Morty as members.

### Approach
1. **Input Reading**: Read the number of universes and groups.
2. **Group Processing**: For each group, check if there is any universe where both Rick and Morty are present.
3. **Conflict Detection**: For each member in a group, track which universes have their Rick or Morty present. If any universe in a group has both, the group cannot be all traitors.
4. **Early Termination**: If a valid group (with no conflicting members) is found, immediately output "YES". If all groups are processed without finding a valid group, output "NO".

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n, m = map(int, sys.stdin.readline().split())
    for _ in range(m):
        parts = list(map(int, sys.stdin.readline().split()))
        k = parts[0]
        vs = parts[1:]
        universe = defaultdict(set)
        conflict = False
        for v in vs:
            if v < 0:
                u = -v
                t = 'R'
            else:
                u = v
                t = 'M'
            if t in universe[u]:
                continue  # Already present, no need to check again
            universe[u].add(t)
            if len(universe[u]) >= 2:
                conflict = True
                break
        if not conflict:
            print("YES")
            return
    print("NO")

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read using standard input functions. The first line gives the number of universes and groups.
- **Processing Each Group**: For each group, we use a dictionary to track whether Rick ('R') or Morty ('M') from each universe is present in the group.
- **Conflict Check**: As we process each member of the group, we check if both Rick and Morty from the same universe are present. If they are, the group is marked as invalid.
- **Early Termination**: If any group is found to be valid (no conflicts), the answer is immediately "YES". If all groups are processed without finding a valid one, the answer is "NO".

This approach efficiently checks each group for conflicts, ensuring that we only process each member once, leading to a linear time complexity relative to the input size.
