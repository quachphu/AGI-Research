### Approach
1. **Initial Check**: Calculate the initial sums of the upper and lower halves of the dominoes. If both sums are already even, no rotations are needed.
2. **Parity Check**: If the sums of the upper and lower halves have different parities (one even and one odd), it is impossible to make both sums even, so we return -1.
3. **Odd Contribution Check**: If both sums are odd, check if there exists at least one domino where the sum of its upper and lower halves is odd. Rotating such a domino will change the parity of both sums, making them even. If such dominoes exist, the minimum rotations required is 1. If not, return -1.

### Solution Code
```python
n = int(input())
sum_upper = 0
sum_lower = 0
count_odd = 0

for _ in range(n):
    x, y = map(int, input().split())
    sum_upper += x
    sum_lower += y
    if (x + y) % 2 == 1:
        count_odd += 1

if sum_upper % 2 == 0 and sum_lower % 2 == 0:
    print(0)
elif (sum_upper % 2) != (sum_lower % 2):
    print(-1)
else:
    print(1 if count_odd > 0 else -1)
```

3. **Initial Check**: If both sums are even, the result is immediately 0.
4. **Parity Check**: If the sums have different parities, the result is -1.
5. **Odd Contribution Check**: If both sums are odd, the code checks if there are any dominoes that can change the parity of both sums when rotated. If such dominoes exist, the result is 1; otherwise, it is -1.
