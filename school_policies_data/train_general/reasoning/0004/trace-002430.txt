### Approach
1. **Initial Checks**: First, check if the sum of the minimum required readiness scores (B) exceeds the sum of Takahashi's current readiness scores (A). If it does, it's impossible to meet the requirements, so we return -1.

2. **Identify Mandatory Changes**: Identify the exams where Takahashi's current readiness is less than the minimum required (B). These exams must be adjusted, so we count these as mandatory changes.

3. **Calculate Adjustments**: For the remaining exams where Takahashi's readiness meets or exceeds the minimum required, we need to determine if we can adjust these scores to balance the total readiness. We calculate the required reduction in readiness (D) needed to offset the mandatory increases from the previous step.

4. **Optimize Adjustments**: Sort the possible reductions from the non-mandatory exams in descending order. Use the largest possible reductions first to minimize the number of changes needed. If the total possible reduction is insufficient, return -1.

### Solution Code

n = int(input())

B = list(map(int, input().split()))

sum_B = sum(B)

    print(-1)
else:
    X = []
    sum_B_X = 0
    sum_A_X = 0
    for a, b in zip(A, B):
        if a < b:
            X.append(a)
            sum_B_X += b
            sum_A_X += a
    D = sum_B_X - sum_A_X
    if D == 0:
        print(len(X))
    else:
        Y_contrib = []
        for a, b in zip(A, B):
            if a >= b:
                Y_contrib.append(a - b)
        total_Y_contrib = sum(Y_contrib)
        if D > total_Y_contrib:

        else:
            Y_contrib.sort(reverse=True)

            for contrib in Y_contrib:

                current += contrib
                count += 1
            print(len(X) + count)
