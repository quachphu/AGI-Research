To solve this problem, we need to compute the remainder when two given integers are divided for multiple test cases. The solution involves reading input values, processing each test case to determine the remainder, and printing the results.

### Approach
1. **Input Reading**: The first line of input contains an integer T, which represents the number of test cases. Each of the next T lines contains two integers, A and B.
2. **Modulo Operation**: For each pair of integers (A, B), we compute the remainder using the modulo operator `%` in Python, which directly gives the remainder when A is divided by B.
3. **Output the Result**: For each test case, we print the computed remainder immediately after processing the input values.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        A = int(input[idx])
        B = int(input[idx + 1])
        idx += 2
        print(A % B)

main()
```

### Explanation
1. **Reading Input Efficiently**: The code reads all input at once using `sys.stdin.read()`, which splits the input into a list of strings. This approach is efficient, especially for handling multiple lines of input.
2. **Processing Each Test Case**: The first element of the input list is the number of test cases, T. We then iterate T times, each time extracting the next two integers (A and B) from the input list.
3. **Computing the Remainder**: For each pair (A, B), we compute the remainder using `A % B` and print the result immediately.

This approach ensures that we handle all test cases efficiently and correctly, adhering to the problem constraints and requirements.
