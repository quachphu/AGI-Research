To solve this problem, we need to determine the number of optimal positions on a 2D plane where an exhibition can be built such that the sum of Manhattan distances from all given houses to this exhibition is minimized. 

### Approach
1. **Understanding Manhattan Distance**: The Manhattan distance between two points \((x_1, y_1)\) and \((x_2, y_2)\) is \(|x_1 - x_2| + |y_1 - y_2|\). The optimal position to minimize the sum of these distances from multiple points is determined by the median of their coordinates.

2. **Median Calculation**: 
   - For an odd number of houses, the median is the middle element in the sorted list of coordinates.
   - For an even number of houses, the optimal positions lie between the two middle elements (inclusive) in the sorted list. The number of valid positions in this range is calculated as the difference between these two middle elements plus one.

3. **Combining Results**: The total number of valid positions for the exhibition is the product of the valid ranges for the x-coordinates and y-coordinates.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        x = []
        y = []
        for _ in range(n):
            xi = int(input[ptr])
            yi = int(input[ptr + 1])
            x.append(xi)
            y.append(yi)
            ptr += 2
        x_sorted = sorted(x)
        y_sorted = sorted(y)
        
        if n % 2 == 1:
            count_x = 1
        else:
            lower_x = x_sorted[(n // 2) - 1]
            upper_x = x_sorted[n // 2]
            count_x = upper_x - lower_x + 1
        
        if n % 2 == 1:
            count_y = 1
        else:
            lower_y = y_sorted[(n // 2) - 1]
            upper_y = y_sorted[n // 2]
            count_y = upper_y - lower_y + 1
        
        print(count_x * count_y)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Sorting Coordinates**: For each test case, the x and y coordinates of the houses are sorted separately.
3. **Calculating Valid Ranges**:
   - If the number of houses \(n\) is odd, the median is a single point, leading to 1 valid position.
   - If \(n\) is even, the valid positions form a range between the two middle elements in the sorted list, and the count of valid positions is the difference between these elements plus one.
4. **Combining Results**: The product of valid x and y ranges gives the total number of optimal positions for the exhibition.

This approach ensures that we efficiently compute the optimal positions using median properties, leading to an optimal solution with a time complexity dominated by the sorting step, \(O(n \log n)\), which is efficient given the problem constraints.
