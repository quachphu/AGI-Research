To solve this problem, we need to determine the minimum time required to convert a given bracket sequence into a correct (regular) one using reorder operations. Each reorder operation allows selecting a consecutive substring, reordering its characters, and takes time equal to the length of the substring.

### Approach
1. **Check Validity**: First, check if the number of opening '(' and closing ')' brackets are equal. If they are not, it's impossible to form a correct sequence, so return -1.
2. **Track Balance**: Traverse the string while keeping track of the balance between opening and closing brackets. The balance increases by 1 for each '(' and decreases by 1 for each ')'.
3. **Identify Valleys**: Whenever the balance becomes negative, mark the start of a "valley" (a segment where the sequence is invalid). Continue until the balance returns to zero, marking the end of the valley. The length of this valley is added to the total cost.
4. **Sum Costs**: The total cost is the sum of the lengths of all identified valleys.

### Solution Code
```python
n = int(input())
s = input().strip()

count_open = s.count('(')
count_close = s.count(')')

if count_open != count_close:
    print(-1)
else:
    total_cost = 0
    current_balance = 0
    valley_start = None  # Start index of the current valley
    for i in range(n):
        if s[i] == '(':
            current_balance += 1
        else:
            current_balance -= 1
        
        if current_balance < 0 and valley_start is None:
            valley_start = i
        elif current_balance == 0 and valley_start is not None:
            # End of the valley
            total_cost += (i - valley_start + 1)
            valley_start = None
    print(total_cost)
```

### Explanation
- **Validity Check**: By counting the number of '(' and ')', we ensure the sequence can potentially be corrected. If counts differ, output -1.
- **Balance Tracking**: As we traverse the string, we maintain a balance counter. A negative balance indicates an invalid segment (valley).
- **Valley Detection**: Each valley starts when the balance becomes negative and ends when it returns to zero. The length of each valley is added to the total cost, which is the sum of the lengths of all such valleys.
- **Efficiency**: This approach efficiently processes the string in a single pass, making it suitable for large inputs up to the constraint limits (1,000,000 characters).

This method ensures that we find the minimal cost to reorder the brackets into a valid sequence by focusing on the segments where the sequence is invalid and efficiently calculating the required reorder operations.
