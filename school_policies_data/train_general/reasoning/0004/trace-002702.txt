To solve this problem, we need to determine the winner of a digit game between two agents, Raze and Breach, based on the parity of the last remaining digit after optimal play. The solution involves analyzing the positions of digits and their parity (odd or even) to decide the outcome.

### Approach
1. **Understanding the Game Mechanics**:
   - Raze starts first and can only mark digits in odd positions (1-based index).
   - Breach follows and can only mark digits in even positions (1-based index).
   - The game ends when one digit remains. If this digit is odd, Raze wins; otherwise, Breach wins.

2. **Key Insight**:
   - If the number of digits `n` is odd, the last remaining digit will be in an odd position. Raze wins if there is at least one odd digit in these positions.
   - If `n` is even, the last remaining digit will be in an even position. Breach wins if there is at least one even digit in these positions.

3. **Algorithm**:
   - For each test case, check the parity of `n`.
   - If `n` is odd, check all digits in odd positions (1-based) for any odd digit.
   - If `n` is even, check all digits in even positions (1-based) for any even digit.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    if n % 2 == 1:
        # Check if any odd position has an odd digit
        raze_win = False
        for i in range(0, n, 2):
            if int(s[i]) % 2 == 1:
                raze_win = True
                break
        print(1 if raze_win else 2)
    else:
        # Check if any even position has an even digit
        breach_win = False
        for i in range(1, n, 2):
            if int(s[i]) % 2 == 0:
                breach_win = True
                break
        print(2 if breach_win else 1)
```

### Explanation
- **Odd `n`**: The last remaining digit must be in an odd position. Raze wins if there is any odd digit in these positions because he can force the game to end with that digit.
- **Even `n`**: The last remaining digit must be in an even position. Breach wins if there is any even digit in these positions because he can force the game to end with that digit.

This approach efficiently checks the necessary conditions for each test case, ensuring optimal play by both agents and determining the winner based on the parity of the remaining digit. The solution runs in linear time relative to the number of digits, making it efficient even for the upper constraint of `n` up to 1000.
