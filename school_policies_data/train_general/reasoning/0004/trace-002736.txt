To solve this problem, we need to simulate the seating process of a ramen shop to determine the waiting time for each customer group. The goal is to compute the time each group spends waiting in line before being seated, based on their arrival time, group size, and meal duration.

### Approach
1. **Precompute Group Information**: For each group, determine their arrival time, size, and meal duration based on the given formulas.
2. **Simulate the Seating Process**: 
   - Track the seats in the shop, which groups are currently seated, and the queue of waiting groups.
   - At each minute, process departures (free seats), add new arrivals to the queue, and attempt to seat as many groups as possible from the front of the queue.
3. **Calculate Waiting Time**: For each group, record the time they start waiting (arrival time) and the time they are seated to determine their waiting time.

### Solution Code
```python
import sys
from collections import deque

def main():
    # Precompute group information
    group_info = []
    for i in range(100):
        arrival = 5 * i
        if i % 5 == 1:
            size = 5
        else:
            size = 2
        meal_time = 17 * (i % 2) + 3 * (i % 3) + 19
        group_info.append((arrival, size, meal_time))
    
    # Initialize simulation variables
    seats = [None] * 17
    queue = deque()
    active_groups = []
    waiting_time = [None] * 100
    time = 0

    def find_consecutive_seats(x):
        for start in range(17 - x + 1):
            for i in range(start, start + x):
                if seats[i] is not None:
                    break
            else:
                return start
        return -1

    # Run the simulation until all groups are seated
    while True:
        # Process departures
        new_active = []
        for group in active_groups:
            gn, dep_time, seats_occ = group
            if dep_time > time:
                new_active.append(group)
            else:
                # Free the seats
                for s in seats_occ:
                    seats[s] = None
        active_groups = new_active

        # Add new arrivals to the queue
        for i in range(100):
            if group_info[i][0] == time:
                queue.append(i)

        # Process seating from the queue
        while queue:
            current_gn = queue[0]
            arrival, size, meal = group_info[current_gn]
            start = find_consecutive_seats(size)
            if start == -1:
                break
            # Occupy the seats
            seats_occ = list(range(start, start + size))
            for s in seats_occ:
                seats[s] = current_gn
            # Record waiting time
            waiting_time[current_gn] = time - arrival
            # Schedule departure
            dep_time = time + meal
            active_groups.append((current_gn, dep_time, seats_occ))
            # Remove from queue
            queue.popleft()

        # Check if all groups have been seated
        if all(wt is not None for wt in waiting_time):
            break
        time += 1

    # Process input and output
    for line in sys.stdin:
        n = int(line.strip())
        print(waiting_time[n])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precompute Group Information**: For each group, we calculate their arrival time, size, and meal duration using the provided formulas. This information is stored in a list for quick access during the simulation.
2. **Simulate the Seating Process**:
   - **Departures**: At each time step, check if any groups are done with their meal and free their seats.
   - **New Arrivals**: Add groups arriving at the current time to the end of the queue.
   - **Seating**: Attempt to seat groups from the front of the queue by finding consecutive vacant seats. If a group can be seated, update their waiting time and schedule their departure.
3. **Output**: After simulating all groups, read the input values and print the waiting time for each requested group.

This approach ensures that we efficiently simulate the seating process, adhering to the rules and constraints provided, and accurately compute the waiting time for each group.
