To solve this problem, we need to determine if a given number is a nearly lucky number. A nearly lucky number is defined as a number where the count of its lucky digits (4 and 7) is itself a lucky number. A lucky number is a positive integer consisting only of the digits 4 and 7.

### Approach
1. **Read Input**: Read the input number as a string to handle very large numbers efficiently.
2. **Count Lucky Digits**: Iterate through each digit of the input number and count how many of them are 4 or 7.
3. **Check Lucky Count**: Convert the count of lucky digits to a string and check if all its digits are either 4 or 7. If the count is zero, it is automatically not a lucky number.

### Solution Code
```python
def is_nearly_lucky():
    n = input().strip()
    count = 0
    for c in n:
        if c in {'4', '7'}:
            count += 1
    if count == 0:
        print("NO")
        return
    count_str = str(count)
    for c in count_str:
        if c not in {'4', '7'}:
            print("NO")
            return
    print("YES")

is_nearly_lucky()
```

### Explanation
1. **Reading Input**: The input is read as a string to handle very large numbers up to \(10^{18}\) without any issues.
2. **Counting Lucky Digits**: We iterate through each character of the input string and count occurrences of '4' and '7'.
3. **Checking Lucky Count**: After counting the lucky digits, we check if this count is a lucky number. This is done by converting the count to a string and ensuring all characters are either '4' or '7'. If the count is zero or any digit in the count is not 4 or 7, the result is "NO"; otherwise, it is "YES".

This approach efficiently determines if the number is nearly lucky by leveraging string operations and simple iteration, ensuring correctness and optimal performance even for large inputs.
