To solve this problem, we need to determine how many numbers x exist in a given subarray such that x occurs exactly x times. Given the constraints, we need an efficient approach to handle up to 100,000 elements and 100,000 queries.

### Approach
1. **Frequency Calculation**: First, calculate the frequency of each number in the array. This helps identify potential candidates for x (numbers that occur at least x times in the entire array).
2. **Precompute Occurrences**: For each candidate x, store the positions where x occurs. This allows efficient range queries using binary search.
3. **Efficient Query Handling**: For each query, determine the valid candidates x that could potentially satisfy the condition x <= length of the subarray. Use binary search to count occurrences of x within the subarray and check if the count matches x.

### Solution Code
```python
import bisect
from collections import defaultdict

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    m = int(input[ptr])
    ptr += 1
    a = list(map(int, input[ptr:ptr+n]))
    ptr += n

    # Calculate frequency of each number
    freq = defaultdict(int)
    for num in a:
        freq[num] += 1

    # Determine valid x's (those with frequency >= x)
    valid_x = set()
    for num in freq:
        if freq[num] >= num:
            valid_x.add(num)

    # Precompute occurrences for each valid x
    occurrences = defaultdict(list)
    for idx, num in enumerate(a, 1):  # 1-based index
        if num in valid_x:
            occurrences[num].append(idx)

    # Sort the valid x's for efficient iteration
    sorted_x = sorted(valid_x)

    # Process each query
    for _ in range(m):
        L = int(input[ptr])
        ptr += 1
        R = int(input[ptr])
        ptr += 1
        current_len = R - L + 1
        max_x = current_len

        # Find the index in sorted_x where x <= max_x
        idx = bisect.bisect_right(sorted_x, max_x)
        ans = 0

        # Check each candidate x up to the found index
        for x in sorted_x[:idx]:
            lst = occurrences[x]
            left_pos = bisect.bisect_left(lst, L)
            right_pos = bisect.bisect_right(lst, R)
            count = right_pos - left_pos
            if count == x:
                ans += 1

        print(ans)

if __name__ == "__main__":
    main()
```
