To solve this problem, we need to determine the maximum area of a submatrix consisting entirely of 1's after rearranging the rows of the given matrix. The key insight is to leverage the concept of consecutive 1's in each row and column to form the largest possible rectangle.

### Approach
1. **Row-wise Histogram Calculation**: For each row, compute a histogram where each entry at position `j` represents the number of consecutive 1's ending at column `j` in that row. This helps in determining potential widths of rectangles ending at each column.
2. **Column-wise Processing**: For each column, collect the histogram values from all rows. Sorting these values in descending order allows us to efficiently determine the maximum possible height and width of the rectangle for each column.
3. **Max Area Calculation**: For each sorted column histogram, compute the maximum area by considering each entry as the height and its position in the sorted list as the width. The maximum area across all columns gives the solution.

### Solution Code
```python
n, m = map(int, input().split())
matrix = [input().strip() for _ in range(n)]

# Precompute row_hist for each row
all_row_hists = []
for row in matrix:
    row_hist = []
    for j in range(m):
        if row[j] == '1':
            if j == 0:
                curr = 1
            else:
                curr = row_hist[j-1] + 1
        else:
            curr = 0
        row_hist.append(curr)
    all_row_hists.append(row_hist)

max_area = 0

# Process each column to find the maximum area
for j in range(m):
    # Collect all row_hist values for column j
    column = []
    for i in range(n):
        column.append(all_row_hists[i][j])
    # Sort in descending order
    column.sort(reverse=True)
    # Calculate the maximum area for this column
    for i in range(len(column)):
        current_area = column[i] * (i + 1)
        if current_area > max_area:
            max_area = current_area

print(max_area)
```

### Explanation
1. **Row-wise Histogram Calculation**: Each row is processed to create a histogram where each entry represents the count of consecutive 1's ending at that column. This helps in understanding potential widths of rectangles for each column.
2. **Column-wise Processing**: For each column, we collect all the histogram values from every row. Sorting these values in descending order allows us to consider the largest possible heights first.
3. **Max Area Calculation**: By iterating through the sorted histogram values for each column, we compute the area as the product of the height (histogram value) and the width (position in the sorted list + 1). The maximum area across all columns is the answer.

This approach efficiently leverages sorting and dynamic programming concepts to find the optimal solution within feasible time complexity for large input sizes.
