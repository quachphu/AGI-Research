To solve this problem, we need to determine the minimum and maximum number of players that could have been sent off during a football match given the number of yellow cards shown and the rules for each team. The solution involves calculating both the minimum and maximum possible expelled players by considering different distributions of yellow cards.

### Approach

1. **Minimum Number of Expelled Players**:
   - To minimize the number of expelled players, we distribute the yellow cards such that as few players as possible reach the threshold (k1 for the first team and k2 for the second team). Each player can receive up to one less than their team's threshold without being expelled. If the total number of yellow cards exceeds the sum of these safe distributions, the excess cards will result in expulsions. The minimum number of expelled players is calculated by the excess cards divided by 1 (since each expulsion requires exactly one more card than the safe limit).

2. **Maximum Number of Expelled Players**:
   - To maximize the number of expelled players, we prioritize expelling players from the team with the lower threshold first. This approach ensures that each expulsion uses the fewest possible cards, allowing more players to be expelled overall. We iterate through possible numbers of expelled players from the first team and calculate the remaining cards that can be used to expel players from the second team.

### Solution Code

```python
a1 = int(input())
a2 = int(input())
k1 = int(input())
k2 = int(input())
n = int(input())

# Calculate minimum players expelled
safe = a1 * (k1 - 1) + a2 * (k2 - 1)
min_players = max(0, n - safe)

# Calculate maximum players expelled
max_players = 0
max_m1 = min(a1, n // k1)
for m1 in range(0, max_m1 + 1):
    remaining = n - m1 * k1

    if total > max_players:
        max_players = total

print(min_players, max_players)
```

### Explanation

- **Minimum Calculation**:
  - The `safe` variable calculates the maximum number of yellow cards that can be distributed without expelling any player. If the actual number of yellow cards `n` exceeds this safe limit, the difference gives the number of players that must be expelled.

- **Maximum Calculation**:
  - We iterate through possible numbers of expelled players from the first team (`m1`). For each `m1`, we compute the remaining cards and determine the maximum number of players that can be expelled from the second team (`m2`). The sum `m1 + m2` is tracked to find the maximum possible value.

This approach efficiently computes both the minimum and maximum number of expelled players by leveraging optimal card distribution strategies, ensuring correctness within the problem constraints.
