To solve this problem, we need to determine if Drazil can make all his friends happy by inviting pairs of boys and girls over days such that if either person in the pair is happy, the other becomes happy. The key insight is to check if the initial happy boys and girls can spread their happiness to all others through the sequence of pairings.

### Approach
1. **Understanding the Pairing Sequence**: Each day `i`, the `i % n`-th boy and `i % m`-th girl are paired. This sequence can be analyzed using modular arithmetic.
2. **Modular Congruence**: For a pair (a, b) to be formed on some day, `a ≡ b (mod gcd(n, m))` must hold. This is derived from the Chinese Remainder Theorem.
3. **Residue Groups**: Compute the greatest common divisor (gcd) of `n` and `m`, denoted as `d`. Both boys and girls can be grouped based on their indices modulo `d`.
4. **Check Coverage**: For each residue group from `0` to `d-1`, check if there is at least one initially happy boy or girl in that group. If any group lacks a happy member, it is impossible to make everyone happy.

### Solution Code
```python
import math

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n, m = int(input[ptr]), int(input[ptr+1])
    ptr += 2
    
    b = int(input[ptr])
    boys = list(map(int, input[ptr+1:ptr+1+b])) if b > 0 else []
    ptr += 1 + b
    
    g = int(input[ptr])
    girls = list(map(int, input[ptr+1:ptr+1+g])) if g > 0 else []
    ptr += 1 + g
    
    d = math.gcd(n, m)
    
    for r in range(d):
        has_boy = any(x % d == r for x in boys)
        has_girl = any(y % d == r for y in girls)
        if not (has_boy or has_girl):
            print("No")
            return
    print("Yes")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of boys (`n`), girls (`m`), the list of initially happy boys, and the list of initially happy girls.
2. **Compute GCD**: The greatest common divisor `d` of `n` and `m` is computed to determine the residue groups.
3. **Residue Group Check**: For each residue group from `0` to `d-1`, check if there is at least one happy boy or girl in that group. If any group lacks a happy member, print "No" and exit. If all groups are covered, print "Yes".

This approach efficiently checks the necessary conditions using modular arithmetic and ensures that all possible pairs are covered through their respective residue groups. This solution runs in O(b + g) time complexity, where `b` and `g` are the number of initially happy boys and girls, respectively.
