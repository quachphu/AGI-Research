To solve this problem, we need to determine the dominant index for each vertex in a rooted undirected tree. The dominant index of a vertex is the first peak in its depth array, where each element in the array represents the number of descendants at each level from the vertex.

### Approach
1. **Tree Representation**: Represent the tree using an adjacency list to efficiently traverse and process each node.
2. **Post-order Traversal**: Use an iterative post-order traversal to process each node after all its descendants have been processed. This ensures that we have all necessary information about the children before processing the parent node.
3. **Depth Array Calculation**: For each node, calculate the sum of the maximum values from its children's depth arrays. This sum helps determine the dominant index of the current node.
4. **Dominant Index Determination**: For each node, if the sum of the maximum values from its children's depth arrays exceeds 1, the dominant index is one more than the maximum dominant index among its children. Otherwise, the dominant index is 0.
