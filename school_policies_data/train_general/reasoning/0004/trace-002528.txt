To solve this problem, we need to count the number of friendly pairs among N rabbits. A friendly pair is defined as a pair of rabbits (i, j) where i < j, rabbit i likes rabbit j, and rabbit j likes rabbit i.

### Approach
1. **Understanding the Problem**: Each rabbit i has a preference a_i, which is another rabbit. A friendly pair (i, j) occurs when i < j, a_i = j, and a_j = i.
2. **Efficient Checking**: Given the constraint that N can be up to 100,000, an O(N) solution is necessary. We iterate through each rabbit and check if it forms a friendly pair with another rabbit it likes.
3. **Avoid Duplicate Checks**: For each rabbit i, we only check if the rabbit it likes (j = a_i) is greater than i. This ensures each pair is checked exactly once, avoiding duplicates.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    count = 0
    for i in range(1, n + 1):
        j = a[i - 1]
        if j > i and a[j - 1] == i:
            count += 1
    print(count)

main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first value is N, followed by N integers representing the preferences of each rabbit.
2. **Iterating Through Rabbits**: For each rabbit i (1-based index), we check the rabbit it likes (j = a[i-1]).
3. **Checking Friendly Pair Condition**: If j > i (to ensure i < j), we then check if the rabbit j likes back is i (a[j-1] == i). If true, increment the count.
4. **Output Result**: The total count of friendly pairs is printed.

This approach ensures that each pair is checked exactly once, leading to an efficient O(N) solution.
