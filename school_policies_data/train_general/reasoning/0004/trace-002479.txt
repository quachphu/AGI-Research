To solve this problem, we need to determine the minimum number of weights required to measure a specific dose using two different weights, ensuring that the total mass is minimized if there are multiple solutions with the same number of weights. The solution involves finding integer combinations of the given weights that satisfy the dose measurement equation while minimizing the total number of weights used.

### Approach
1. **Extended Euclidean Algorithm**: This algorithm helps in finding integer solutions to the equation \(a \cdot x + b \cdot y = \text{gcd}(a, b)\). We use this to find the initial solution for the given dose.
2. **General Solution**: Once an initial solution is found, the general solution to the equation can be derived using the gcd of the weights. This allows us to express all possible solutions in terms of a parameter \(k\).
3. **Range of k Values**: To find the optimal solution, we compute possible values of \(k\) around critical points where the weights might be zero. This helps in minimizing the total number of weights used.
4. **Minimization**: By iterating over a range of \(k\) values, we compute the total number of weights and the total mass for each solution, selecting the one with the smallest number of weights and the smallest mass if there are ties.

        return (a, 1, 0)
    else:
