To solve this problem, we need to determine the number of parallelograms that can be formed using a given set of distinct points on a plane, where no three points are collinear. The key insight is that a parallelogram is defined by pairs of points whose midpoints coincide. 

### Approach
1. **Midpoint Calculation**: For each pair of points, compute their midpoint. Instead of using floating-point arithmetic, we represent the midpoint as a tuple of the sum of the coordinates (x1 + x2, y1 + y2). This avoids precision issues and ensures accurate grouping.
2. **Grouping by Midpoints**: Use a dictionary to group all pairs of points that share the same midpoint.
3. **Valid Pairs Calculation**: For each group of pairs with the same midpoint, determine the number of valid parallelograms. This involves:
   - Calculating the total number of pairs of pairs (combinations of two pairs).
   - Subtracting invalid pairs where the pairs share a common point, as these cannot form a parallelogram.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n = int(sys.stdin.readline())
    points = [tuple(map(int, sys.stdin.readline().split())) for _ in range(n)]
    
    midpoints = defaultdict(list)
    
    for i in range(n):
        x1, y1 = points[i]
        for j in range(i + 1, n):
            x2, y2 = points[j]
            sum_x = x1 + x2
            sum_y = y1 + y2
            mid_key = (sum_x, sum_y)
            midpoints[mid_key].append((points[i], points[j]))
    
    answer = 0
    
    for key in midpoints:
        pairs = midpoints[key]
        k = len(pairs)
        if k < 2:
            continue
        
        total = k * (k - 1) // 2
        freq = defaultdict(int)
        
        for p1, p2 in pairs:
            freq[p1] += 1
            freq[p2] += 1
        
        sum_invalid = 0
        for p in freq:
            cnt = freq[p]
            sum_invalid += cnt * (cnt - 1) // 2
        
        answer += (total - sum_invalid)
    
    print(answer)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and stored as a list of tuples representing the points.
2. **Midpoint Grouping**: For each pair of points, their midpoint (as sums of coordinates) is calculated and stored in a dictionary where the key is the midpoint and the value is a list of point pairs that share this midpoint.
3. **Processing Each Midpoint Group**: For each group of pairs sharing the same midpoint:
   - The total number of possible pairs of pairs (k choose 2) is computed.
   - A frequency dictionary counts how many times each point appears in the pairs of the group.
   - Invalid pairs (those sharing a common point) are subtracted from the total to get the number of valid parallelograms.
4. **Output the Result**: The sum of valid parallelograms for all midpoints is printed.

This approach efficiently groups pairs by their midpoints and ensures that only valid parallelograms (with four distinct points) are counted, resulting in an optimal solution.
