To solve this problem, we need to determine the maximum amount of money Vasya's bank account can hold after T minutes, considering the value degradation of messages over time and the interest earned on unread messages.

### Approach
1. **Problem Analysis**: Each message arrives at a specific time and its value decreases by a fixed amount each minute. Vasya can read messages any time after they arrive, and each minute he earns interest based on the number of unread messages. The goal is to maximize the total amount of money after T minutes.

2. **Key Insight**:
   - If the interest rate (C) is higher than the degradation rate (B), it is optimal to read messages as late as possible (at time T) to maximize the interest earned.
   - If the interest rate is lower than or equal to the degradation rate, it is optimal to read messages immediately upon arrival to avoid value loss.

3. **Algorithm**:
   - For each message, if the interest rate (C) is greater than the degradation rate (B), calculate the value by reading the message at time T.
   - Otherwise, calculate the value by reading the message immediately upon arrival.

### Solution Code
```python
n, A, B, C, T = map(int, input().split())
ti = list(map(int, input().split()))

total = 0
if C > B:
    for t in ti:
        total += A + (C - B) * (T - t)
else:
    total = n * A

print(total)
```

### Explanation
- **Reading Messages at Time T**: When the interest rate (C) is higher than the degradation rate (B), delaying the reading of messages until time T maximizes the interest earned on each unread message. The value of each message is calculated as the initial value (A) plus the interest earned over the delay period minus the degradation loss.
- **Reading Messages Immediately**: If the interest rate is not higher than the degradation rate, reading messages immediately upon arrival avoids any degradation loss. The total value is simply the sum of the initial values of all messages.

This approach efficiently determines the optimal reading time for each message to maximize the total amount of money, ensuring all messages are read by time T.
