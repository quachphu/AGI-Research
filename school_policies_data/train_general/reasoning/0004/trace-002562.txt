To solve this problem, we need to determine the maximum number of squares Vika can paint on an infinitely long piece of paper by following a specific painting sequence. The sequence starts with an arbitrary color and continues cyclically, using each subsequent color until the paint runs out.

### Approach
1. **Identify Minimum Paint**: The minimum number of paint liters in any jar determines the maximum number of full cycles that can be completed. This is because each full cycle uses one liter from each color.
2. **Compute Remaining Paint**: After completing the full cycles determined by the minimum paint value, we compute the remaining paint in each jar.
3. **Find Consecutive Paint**: The next step is to determine the longest consecutive sequence of jars (in cyclic order) that still have paint left after the full cycles. This sequence will allow Vika to paint additional squares.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
m = min(a)
a_prime = [x - m for x in a]

# Process runs
current_run_type = None  # '>=1' or '0'
current_run_length = 0
runs = []
for x in a_prime:
    if x >= 1:
        if current_run_type != '>=1':
            if current_run_type is not None:
                runs.append((current_run_type, current_run_length))
            current_run_type = '>=1'
            current_run_length = 0
        current_run_length += 1
    else:
        if current_run_type != '0':
            if current_run_type is not None:
                runs.append((current_run_type, current_run_length))
            current_run_type = '0'
            current_run_length = 0
        current_run_length += 1
if current_run_type is not None:
    runs.append((current_run_type, current_run_length))

positive_runs = [length for typ, length in runs if typ == '>=1']

if not positive_runs:
    k = 0
else:
    max_linear = max(positive_runs)
    start_with = a_prime[0] >= 1
    end_with = a_prime[-1] >= 1
    if start_with and end_with:
        first_run_length = positive_runs[0]
        last_run_length = positive_runs[-1]
        circular_sum = first_run_length + last_run_length
    else:
        circular_sum = 0
    k = max(max_linear, circular_sum)

total = m * n + k
print(total)
```

### Explanation
1. **Identify Minimum Paint**: The minimum value `m` in the array `a` is found. This value determines the number of full cycles Vika can paint.
2. **Compute Remaining Paint**: Subtract `m` from each element in `a` to get the remaining paint after `m` full cycles.
3. **Track Consecutive Paint Runs**: Iterate through the remaining paint values to identify consecutive segments (runs) where there is still paint left. This helps in determining the longest consecutive sequence of squares that can be painted after the full cycles.
4. **Handle Cyclic Nature**: Check if the array starts and ends with non-zero paint values to handle the cyclic nature of the problem. This allows combining the first and last segments if they form a continuous sequence in the cyclic order.

By following these steps, we efficiently determine the maximum number of squares Vika can paint, considering both full cycles and the longest possible consecutive sequence after those cycles. This approach ensures optimal performance even for large input sizes.
