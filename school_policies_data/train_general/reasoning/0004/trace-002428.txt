3. **Case when D is positive**: We solve two quadratic equations derived from the conditions |A - B| = D and A * B = P. The solutions to these equations give the valid pairs (A, B).

### Solution Code
```python
import math

def solve():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        D = int(input[idx])
        P = int(input[idx + 1])
        idx += 2
        if D < 0:
            print(0)
        else:
            if D == 0:
                if P < 0:
                    print(0)
                else:
                    if P == 0:
                        print(1)
                    else:
                        s = math.isqrt(P)
                        if s * s == P:
                            print(2)
                        else:
                            print(0)
            else:
                disc = D * D + 4 * P
                if disc < 0:
                    print(0)
                else:
                    sqrt_disc = math.isqrt(disc)
                    if sqrt_disc * sqrt_disc != disc:
                        print(0)
                    else:
                        count = 0
                        # Check roots for equation A^2 - D*A - P = 0
                        for sgn in [1, -1]:
                            numerator = D + sgn * sqrt_disc
                            if numerator % 2 == 0:
                                count += 1
                        # Check roots for equation A^2 + D*A - P = 0
                        for sgn in [1, -1]:
                            numerator = -D + sgn * sqrt_disc
                            if numerator % 2 == 0:
                                count += 1
                        print(count)

solve()
```

2. **Negative D Check**: Directly return 0 if D is negative.
3. **Zero D Handling**: Check if P is a non-negative perfect square. If P is zero, there is exactly one pair (0, 0). If P is a perfect square, there are two pairs (sqrt(P), sqrt(P)) and (-sqrt(P), -sqrt(P)).
4. **Positive D Handling**: 
   - Calculate the discriminant for the quadratic equations derived from the conditions.
   - Check if the discriminant is a perfect square. If not, there are no valid pairs.
   - Solve both quadratic equations and count valid integer solutions. Each valid solution contributes to the count of ordered pairs.
