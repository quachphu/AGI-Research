To solve this problem, we need to calculate the total deliciousness of all possible cakes made by combining one type of cream and one type of sponge. The key insight is to use mathematical properties to simplify the computation and avoid iterating through all possible pairs, which would be computationally expensive for large inputs.

### Approach
1. **Sum Calculation**: The total deliciousness of all cakes can be computed by multiplying the sum of the cream tastes with the sum of the sponge tastes. This is derived from the distributive property of multiplication over addition, which states that the sum of products is equal to the product of sums when considering all pairs.
2. **Efficiency**: By summing the tastes of creams and sponges separately and then multiplying these sums, we reduce the complexity from O(N*M) to O(N + M), which is efficient even for large values of N and M (up to 100,000).

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    idx = 0
    N, M = int(input[idx]), int(input[idx+1])
    idx += 2
    A = list(map(int, input[idx:idx+N]))
    idx += N
    B = list(map(int, input[idx:idx+M]))
    sum_A = sum(A)
    sum_B = sum(B)
    print(sum_A * sum_B)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings for efficient processing.
2. **Parsing Values**: The first two values are parsed as integers N (number of creams) and M (number of sponges). The subsequent values are parsed into lists representing the tastes of creams and sponges.
3. **Summing Tastes**: The sum of the cream tastes and the sum of the sponge tastes are computed separately.
4. **Calculating Total Deliciousness**: The total deliciousness is obtained by multiplying the two sums, which gives the sum of all possible products of cream and sponge tastes.

This approach efficiently handles large inputs by leveraging mathematical properties, ensuring that the solution is both optimal and easy to understand.
