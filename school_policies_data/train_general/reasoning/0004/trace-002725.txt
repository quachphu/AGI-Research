To solve this problem, we need to determine the minimal number of egg cartons Dee Dee must buy to get exactly N eggs, using cartons that contain either 6 or 8 eggs. If it's impossible to achieve exactly N eggs with the given cartons, we should return -1.

### Approach
The key insight is to maximize the use of 8-egg cartons first, as they allow us to use fewer cartons for the same number of eggs. By iterating from the maximum possible number of 8-egg cartons down to zero, we check if the remaining eggs can be exactly divided by 6. The first valid combination found in this manner will give the minimal number of cartons.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline().strip())
        max_x = n // 8
        found = False
        for x in range(max_x, -1, -1):
            remainder = n - 8 * x
            if remainder >= 0 and remainder % 6 == 0:
                print(x + remainder // 6)
                found = True
                break
        if not found:
            print(-1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The code reads the number of test cases and each test case value.
2. **Iterating Over Possible 8-Egg Cartons:** For each test case, we determine the maximum number of 8-egg cartons (max_x) that could be used. We then iterate from this maximum down to zero.
3. **Checking Validity:** For each count of 8-egg cartons, we compute the remaining eggs after using those cartons. If the remaining eggs can be exactly divided by 6, we calculate the total number of cartons and print the result.
4. **Handling Impossibility:** If no valid combination is found after checking all possible counts of 8-egg cartons, we print -1.

This approach ensures that we efficiently find the minimal number of cartons by leveraging the larger capacity of 8-egg cartons first, thus minimizing the total number of cartons used.
