To solve this problem, we need to determine the number of pairs of points in a D-dimensional space such that the Euclidean distance between them is an integer. 

### Approach
1. **Input Reading**: Read the number of points (N) and the number of dimensions (D). Then read the coordinates of each point.
2. **Pair Generation**: Generate all possible pairs of points (i, j) where i < j.
3. **Distance Calculation**: For each pair, compute the squared Euclidean distance by summing the squares of the differences in each dimension.
4. **Perfect Square Check**: Check if the computed squared distance is a perfect square. This is done by computing the integer square root and verifying if squaring it gives back the original value.
5. **Count Valid Pairs**: Maintain a count of pairs that meet the criteria and print the result.

### Solution Code
```python
import math

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    d = int(input[idx])
    idx += 1
    points = []
    for _ in range(n):
        coords = list(map(int, input[idx:idx+d]))
        idx += d
        points.append(coords)
    
    count = 0
    for i in range(n):
        for j in range(i + 1, n):
            s = 0
            for k in range(d):
                diff = points[i][k] - points[j][k]
                s += diff * diff
            root = math.isqrt(s)
            if root * root == s:
                count += 1
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read all at once for efficiency, and then parsed into the number of points, dimensions, and their respective coordinates.
- **Generating Pairs**: We use nested loops to generate all unique pairs (i, j) where i < j to avoid redundant checks.
- **Calculating Squared Distance**: For each pair, the squared distance is computed by summing the squares of the differences in each dimension. This avoids the need for floating-point operations and potential precision issues.
- **Checking Perfect Square**: Using the integer square root function (`math.isqrt`), we check if the squared distance is a perfect square. This is efficient and avoids floating-point inaccuracies.
- **Counting Valid Pairs**: Each valid pair is counted, and the result is printed at the end.

This approach ensures that we efficiently check all pairs and accurately determine if their distances are integers, leveraging mathematical properties of perfect squares for correctness.
