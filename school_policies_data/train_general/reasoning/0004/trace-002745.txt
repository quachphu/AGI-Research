To solve this problem, we need to reverse each word in a given string while keeping the spaces, punctuation, and numbers in their original positions. The end of the string will always be marked with a period ('.').

### Approach
1. **Input Reading**: Read the input string.
2. **Tokenization**: Split the input string into tokens where each token is either a word (composed of alphanumeric characters) or a non-word (composed of spaces, punctuation, etc.). This is achieved using regular expressions.
3. **Processing Tokens**: For each token, if it is a word, reverse it. If it is a non-word (space or punctuation), leave it as is.
4. **Reconstruction**: Combine all processed tokens back into a single string to form the output.

### Solution Code
```python
import re

def reverse_words():
    s = input().strip()
    tokens = re.findall(r'([a-zA-Z0-9]+)|([^a-zA-Z0-9]+)', s)
    result = []
    for token in tokens:
        word, non_word = token
        if word:
            result.append(word[::-1])
        else:
            result.append(non_word)
    print(''.join(result))

reverse_words()
```

### Explanation
1. **Reading Input**: The input string is read using `input().strip()` to handle any leading or trailing whitespace.
2. **Tokenization**: The regular expression `r'([a-zA-Z0-9]+)|([^a-zA-Z0-9]+)'` is used to split the input into two types of tokens:
   - `[a-zA-Z0-9]+`: Matches sequences of alphanumeric characters (words).
   - `[^a-zA-Z0-9]+`: Matches sequences of non-alphanumeric characters (spaces, punctuation).
3. **Processing Tokens**: Each token is checked. If it is a word (alphanumeric), it is reversed. Non-word tokens are appended as they are.
4. **Reconstruction**: The processed tokens are joined together to form the final output string, ensuring that spaces and punctuation remain in their original positions.

This approach efficiently handles the reversal of words while preserving the structure of the input string, providing the correct output as required.
