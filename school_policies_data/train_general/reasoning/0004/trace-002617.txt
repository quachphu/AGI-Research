To solve this problem, we need to determine the next year after a given year `y` where the calendar will be exactly the same. This means the days of the week for each date must align again, and the leap year status must be consistent between the given year and the resulting year.

### Approach
1. **Leap Year Check**: Determine if the given year `y` is a leap year. A leap year is defined as a year divisible by 400, or divisible by 4 but not by 100.
2. **Day Shift Calculation**: Track the shift in days of the week each subsequent year contributes. A common year (non-leap) shifts the calendar by 1 day, while a leap year shifts it by 2 days.
3. **Incremental Check**: For each subsequent year after `y`, check if it has the same leap year status as `y` and if the cumulative day shift modulo 7 is zero. This ensures the days of the week align perfectly.

### Solution Code
```python
def is_leap(year):
    if year % 400 == 0:
        return True
    if year % 100 == 0:
        return False
    if year % 4 == 0:
        return True
    return False

def find_next_year(y):
    original_leap = is_leap(y)
    total_shift = 0
    current_year = y
    next_year = y + 1
    while True:
        # Calculate the shift of the current year and add to total_shift
        if is_leap(current_year):
            total_shift += 2
        else:
            total_shift += 1
        total_shift %= 7  # Keep it within modulo 7
        
        # Check if the next_year is a valid candidate
        if is_leap(next_year) == original_leap and total_shift == 0:
            return next_year
        
        # Move to the next year
        current_year = next_year
        next_year += 1

# Read input and print the result
y = int(input())
print(find_next_year(y))
```

### Explanation
1. **Leap Year Determination**: The function `is_leap` checks if a year is a leap year based on the given rules.
2. **Tracking Day Shifts**: Starting from the given year `y`, we calculate the day shift for each subsequent year. This shift is accumulated modulo 7 to keep track of the effective shift in days of the week.
3. **Candidate Year Check**: For each subsequent year, we check if it has the same leap year status as the original year and if the accumulated shift modulo 7 is zero. If both conditions are met, this year is the answer.

This approach efficiently tracks the necessary conditions to determine the next year with an identical calendar, ensuring both correctness and optimal performance.
