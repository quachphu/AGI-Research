### Approach

### Solution Code
```python
def main():
    a = int(input())
    
    def smallest_prime(n):
        if n % 2 == 0:
            return 2
        i = 3
        while i * i <= n:
            if n % i == 0:
                return i
            i += 2
        return n  # As per problem statement, this case won't occur for valid input
    
    p = smallest_prime(a)
    q = a // p
    print(int(str(p) + str(q)))

main()
```

### Explanation
1. **Reading Input**: The input integer is read from standard input.
2. **Finding Smallest Prime Factor**: The function `smallest_prime` checks divisibility starting from 2 (for even numbers) and then proceeds with odd numbers up to the square root of the input. This efficiently identifies the smallest prime factor.
3. **Calculating the Second Prime**: Once the smallest prime factor is found, the second prime is obtained by dividing the input by the smallest prime factor.
4. **Concatenation and Output**: The two primes are concatenated as strings and then converted to an integer, which is printed as the result.

This approach ensures that we efficiently factorize the input and generate the required output by leveraging prime properties and string manipulation.
