To solve this problem, we need to determine if there exists a pack size 'a' such that every customer buying between 'l' and 'r' cans (inclusive) ends up buying more than they intended. The solution relies on a key insight regarding the range of possible values for 'l' and 'r'.

### Approach
The key observation is that if the range of cans a customer can buy (from 'l' to 'r') is such that twice the lower bound (2 * l) is greater than the upper bound (r), then we can always find a suitable pack size 'a'. This is because if 2 * l > r, we can choose a pack size 'a' that is just greater than 'r', ensuring that the remainder when any number of cans in the range is divided by 'a' will be at least half of 'a', forcing the customer to buy an additional pack.

### Solution Code
```python
t = int(input())
for _ in range(t):
    l, r = map(int, input().split())
    if 2 * l > r:
        print("YES")
    else:
        print("NO")
```

### Explanation
1. **Input Reading**: Read the number of test cases.
2. **Range Check**: For each test case, read the values of 'l' and 'r'.
3. **Condition Check**: Check if twice the lower bound (2 * l) is greater than the upper bound (r). If true, print "YES", otherwise print "NO".

This approach efficiently determines the solution by leveraging the mathematical property that if the range is sufficiently small (specifically, when 2 * l > r), there exists a pack size that ensures customers buy more than they initially wanted. This solution runs in O(1) time per test case, making it highly efficient even for large input sizes.
