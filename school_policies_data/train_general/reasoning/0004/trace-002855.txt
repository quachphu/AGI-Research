To solve this problem, we need to determine if string S can be converted into string P by deleting some characters from S. This is equivalent to checking if P is a subsequence of S. A subsequence is a sequence derived from another sequence by deleting some elements without changing the order of the remaining elements.

### Approach
1. **Input Reading**: Read the number of test cases, T. For each test case, read the strings S and P.
2. **Subsequence Check**: For each pair of strings (S, P), check if P is a subsequence of S using a two-pointer technique:
   - Initialize two pointers, one for each string (i for S and j for P).
   - Traverse through S. For each character in S, check if it matches the current character in P. If it does, move the pointer in P forward.
   - If we reach the end of P, it means P is a subsequence of S. Otherwise, if we reach the end of S without exhausting P, it is not a subsequence.
3. **Edge Cases**: Handle cases where P is longer than S immediately by returning "NO".

### Solution Code
```python
def is_subsequence(s, p):
    len_p = len(p)
    len_s = len(s)
    if len_p > len_s:
        return False
    i = j = 0
    while i < len_s and j < len_p:
        if s[i] == p[j]:
            j += 1
        i += 1
    return j == len_p

T = int(input())
for _ in range(T):
    S = input().strip()
    P = input().strip()
    print("YES" if is_subsequence(S, P) else "NO")
```

### Explanation
1. **Reading Input**: The input is read line by line. The first line gives the number of test cases. Each subsequent pair of lines represents the strings S and P for each test case.
2. **Subsequence Check Function**: The function `is_subsequence` checks if P is a subsequence of S using two pointers. The pointer for S (i) moves forward for every character, while the pointer for P (j) moves forward only when a matching character is found in S. If all characters of P are found in order, P is a subsequence of S.
3. **Output**: For each test case, the result is printed as "YES" if P is a subsequence of S, otherwise "NO".

This approach efficiently checks for the subsequence property in linear time relative to the length of S, making it suitable for the given constraints.
