### Approach
1. **Problem Analysis**: The weight of a partition is the sum of the sizes of each subset multiplied by the sum of the weights of the elements in that subset. The key insight is that each element's contribution to the total weight can be computed independently and summed up.

2. **Combinatorial Insight**: The sum of weights for all partitions can be derived using Stirling numbers of the second kind, which count the number of ways to partition a set of n elements into k non-empty subsets. 

3. **Efficient Calculation**: Using precomputed factorials and their modular inverses, we can efficiently compute the required values using the inclusion-exclusion principle. The sum of contributions from all partitions is computed using these values.

        res = res * inv_fact[k_stir] % MOD
        return res

    stir_n_prev_k = compute_stirling(n-1, k)
    S = ((n - 1) * stir_n_prev_k + stir_n_k) % MOD
    ans = sum_w * S % MOD
