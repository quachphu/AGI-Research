To solve this problem, we need to determine if two given strings are anagrams of each other. An anagram is a word or phrase formed by rearranging the letters of another, using all the original letters exactly once.

### Approach
1. **Check Lengths**: If the two strings have different lengths, they cannot be anagrams. This check is done first to quickly eliminate non-anagram cases.
2. **Character Frequency Count**: If the lengths are the same, count the frequency of each character in both strings. Since the strings consist only of uppercase letters ('A'-'Z'), we can efficiently use two arrays of size 26 (one for each string) to count occurrences of each character.
3. **Compare Counts**: After counting the characters, compare the two arrays. If they are identical, the strings are anagrams; otherwise, they are not.

### Solution Code
```python
def main():
    s1 = input().strip()
    s2 = input().strip()
    
    if len(s1) != len(s2):
        print("WRONG")
        return
    
    count1 = [0] * 26
    count2 = [0] * 26
    
    for c in s1:
        count1[ord(c) - ord('A')] += 1
    
    for c in s2:
        count2[ord(c) - ord('A')] += 1
    
    print("CORRECT" if count1 == count2 else "WRONG")

main()
```

### Explanation
1. **Reading Input**: The input strings are read from standard input and stripped of any leading or trailing whitespace.
2. **Length Check**: The lengths of the two strings are compared. If they differ, the result is immediately "WRONG".
3. **Character Counting**: Two arrays of size 26 (one for each string) are used to count the frequency of each character. Each character is mapped to an index using `ord(c) - ord('A')`, where 'A' is mapped to 0, 'B' to 1, and so on.
4. **Comparison**: The two arrays are compared. If they are identical, the strings are anagrams, and "CORRECT" is printed; otherwise, "WRONG" is printed.

This approach ensures efficient handling of large input sizes up to 1,000,000 characters, with a time complexity of O(n) and a space complexity of O(1) (due to fixed-size arrays).
