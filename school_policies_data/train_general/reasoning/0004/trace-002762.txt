To solve this problem, we need to determine the maximum number of gems Mr. Kitayuta can collect while jumping between islands according to specified rules. The solution involves using dynamic programming to track the maximum number of gems collected at each possible position and jump length.

### Approach
1. **Problem Analysis**: Mr. Kitayuta starts at island 0 and jumps to island `d` first. Each subsequent jump can vary by ±1 from the previous jump length. The goal is to maximize the number of gems collected on visited islands.
2. **Dynamic Programming (DP) Setup**: Use a list of dictionaries where `dp[x][l]` represents the maximum gems collected when reaching position `x` with a jump length `l`.
3. **Initialization**: The first jump is from island 0 to `d`, so initialize `dp[d][d]` with the number of gems at island `d`.
4. **State Transitions**: For each position `x` and jump length `l`, compute the next possible positions and update the DP table for valid transitions.
5. **Result Calculation**: Track the maximum number of gems encountered during the DP transitions.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n, d = int(input[idx]), int(input[idx + 1])
    idx += 2

    max_x = 30000
    gems = [0] * (max_x + 1)
    for _ in range(n):
        p = int(input[idx])
        idx += 1
        gems[p] += 1

    # Initialize DP
    dp = [{} for _ in range(max_x + 1)]
    initial_x = d
    if initial_x <= max_x:
        dp[initial_x][d] = gems[initial_x]

    max_gems = 0

    for x in range(initial_x, max_x + 1):
        if not dp[x]:
            continue
        current_dict = dp[x]
        for l in list(current_dict.keys()):
            current_gem = current_dict[l]
            if current_gem > max_gems:
                max_gems = current_gem
            for delta in (-1, 0, 1):
                new_l = l + delta
                if new_l <= 0:
                    continue
                new_x = x + new_l
                if new_x > max_x:
                    continue
                new_total = current_gem + gems[new_x]
                if new_l not in dp[new_x] or new_total > dp[new_x].get(new_l, 0):
                    dp[new_x][new_l] = new_total

    # Check the last processed x's entries
    for x in range(max_x + 1):
        for val in dp[x].values():
            if val > max_gems:
                max_gems = val

    print(max_gems)

if __name__ == "__main__":
    main()
```
