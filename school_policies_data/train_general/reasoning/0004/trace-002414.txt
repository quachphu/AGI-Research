To solve this problem, we need to determine if the statues on a cycle of islands can be rearranged from their initial configuration to a desired configuration by moving the statues through adjacent bridges. The key insight is to check if the desired configuration is a rotation of the initial configuration of the statues, ignoring the empty pedestal's position.

### Approach
1. **Check Validity of Statues**: First, verify that the non-zero elements (statues) in the initial and desired configurations are the same. If they are not, it's impossible to rearrange the statues, so the answer is "NO".
2. **Generate Sequences**: Extract the sequences of non-zero elements from both the initial and desired configurations, maintaining their order as they appear on the islands.
3. **Check Rotation**: Determine if the desired sequence of statues is a rotation of the initial sequence. This can be efficiently checked using the Knuth-Morris-Pratt (KMP) algorithm to see if the desired sequence is a substring of the initial sequence concatenated with itself.

def kmp_failure_function(pattern):
    n = len(pattern)
    lps = [0] * n
    length = 0  # length of the previous longest prefix suffix

    for i in range(1, n):
        while length > 0 and pattern[i] != pattern[length]:
            length = lps[length - 1]

        if pattern[i] == pattern[length]:
            length += 1
            lps[i] = length
        else:
            lps[i] = 0
    return lps

def kmp_search(text, pattern, lps):
    m = len(pattern)
    n = len(text)
    j = 0  # index into pattern

    for i in range(n):
        while j > 0 and text[i] != pattern[j]:
            j = lps[j - 1]

        if text[i] == pattern[j]:
            j += 1
            if j == m:
                return True
    return False
