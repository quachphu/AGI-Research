To solve this problem, we need to determine the maximum number of coins that can be obtained by pressing two buttons. Each button press gives coins equal to the button's current size and then decreases the button's size by 1. We can press the same button twice or each button once. The goal is to find the optimal strategy to maximize the coins collected.

### Approach
1. **Press the same button twice**: If we press a button of size `X` twice, the total coins collected will be `X + (X - 1)`, which simplifies to `2X - 1`.
2. **Press each button once**: If we press each button once, the total coins collected will be the sum of their sizes, `A + B`.

The maximum number of coins will be the highest value among the three possible scenarios:
1. Pressing the first button twice: `2A - 1`
2. Pressing the second button twice: `2B - 1`
3. Pressing each button once: `A + B`

### Solution Code
```python
A, B = map(int, input().split())
print(max(A + B, 2 * A - 1, 2 * B - 1))
```

### Explanation
1. **Reading Input**: The input values for the button sizes `A` and `B` are read and converted to integers.
2. **Calculate Possible Values**:
   - `2 * A - 1`: Coins collected by pressing the first button twice.
   - `2 * B - 1`: Coins collected by pressing the second button twice.
   - `A + B`: Coins collected by pressing each button once.
3. **Determine Maximum**: The `max` function is used to find the highest value among the three calculated values, which gives the maximum number of coins possible.

This approach efficiently computes the result in constant time, O(1), making it optimal for the given constraints.
