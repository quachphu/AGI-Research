To solve this problem, we need to determine the number of valid ways to assign numbers 1, 2, or 3 to the vertices of an undirected graph such that the sum of the numbers on the vertices connected by each edge is odd. This problem can be reduced to checking if the graph is bipartite and then computing the number of valid assignments based on the bipartition.

### Approach

1. **Check Bipartiteness**: The graph must be bipartite for a valid assignment to exist. A bipartite graph can be divided into two disjoint sets where each edge connects a vertex from one set to the other. If the graph is not bipartite, the answer is 0.

2. **Component Contribution**: For each bipartite component of the graph, we calculate the number of valid assignments. Each bipartition (A, B) allows two configurations:
   - Vertices in set A are assigned even numbers (only 2) and vertices in set B are assigned odd numbers (1 or 3).
   - Vertices in set A are assigned odd numbers and vertices in set B are assigned even numbers.

3. **Exponential Calculation**: Precompute powers of 2 modulo 998244353 to efficiently compute the number of valid configurations for each component. The contribution of each component is \(2^{|A|} + 2^{|B|}\), where \(|A|\) and \(|B|\) are the sizes of the two partitions.

4. **Combine Results**: Multiply the contributions of all components to get the total number of valid assignments for the graph.

### Solution Code

```python
import sys
from collections import deque

MOD = 998244353

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    
    max_n = 3 * 10**5 + 10
    pow2 = [1] * (max_n)
    for i in range(1, max_n):
        pow2[i] = (pow2[i-1] * 2) % MOD
    
    results = []
    for _ in range(t):
        n = int(input[ptr])
        m = int(input[ptr + 1])
        ptr += 2
        
        adj = [[] for _ in range(n + 1)]
        for __ in range(m):
            u = int(input[ptr])
            v = int(input[ptr + 1])
            adj[u].append(v)
            adj[v].append(u)
            ptr += 2
        
        color = [-1] * (n + 1)
        is_bipartite = True
        result = 1
        
        for u in range(1, n + 1):
            if color[u] == -1:
                queue = deque()
                queue.append(u)
                color[u] = 0
                cnt = [1, 0]  # count[0] for color 0, count[1] for color 1
                valid = True
                
                while queue and valid:
                    current = queue.popleft()
                    for neighbor in adj[current]:
                        if color[neighbor] == -1:
                            color[neighbor] = 1 - color[current]
                            cnt[color[neighbor]] += 1
                            queue.append(neighbor)
                        else:
                            if color[neighbor] == color[current]:
                                valid = False
                                break
                    if not valid:
                        break
                
                if not valid:
                    is_bipartite = False
                    break
                else:
                    a, b = cnt[0], cnt[1]
                    contribution = (pow2[a] + pow2[b]) % MOD
                    result = (result * contribution) % MOD
        
        if is_bipartite:
            results.append(result)
        else:
            results.append(0)
    
    print('\n'.join(map(str, results)))

if __name__ == "__main__":
    main()
```

4. **Component Contribution Calculation**: For each bipartite component, the number of valid configurations is calculated as \(2^{|A|} + 2^{|B|}\), where \(|A|\) and \(|B|\) are the sizes of the two partitions. These contributions are multiplied together modulo 998244353 to get the final result for each test case.
