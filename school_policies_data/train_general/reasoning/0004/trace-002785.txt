To solve this problem, we need to determine the shortest time for Takayuki and Kazuyuki to meet in a grid-based department store where they move in opposite directions. If they cannot meet within 100 hours (360,000 time units), we should return "NA".

### Approach
1. **Problem Analysis**:
   - Takayuki and Kazuyuki move in opposite directions each time unit.
   - The grid contains obstacles they cannot move through.
   - We need to find the shortest time for them to meet at the same cell after moving.

2. **Breadth-First Search (BFS)**:
   - BFS is suitable for finding the shortest path in an unweighted grid.
   - Each state in the BFS queue represents the positions of both individuals and the current time.
   - For each state, explore all four possible movement directions (north, south, east, west) and their opposites for the other person.

3. **Movement Validation**:
   - Check if movements are within grid boundaries and not obstructed by obstacles.
   - If a movement is invalid, the person stays in their current position.

4. **Termination Conditions**:
   - If they meet (same cell after moving), return the current time + 1.
   - If the time exceeds 360,000 units, return "NA".

### Solution Code
```python
from collections import deque
import sys

def main():
    directions = [ (0, -1), (0, 1), (-1, 0), (1, 0) ]  # north, south, west, east

    while True:
        line = sys.stdin.readline()
        if not line:
            break
        W, H = map(int, line.strip().split())
        if W == 0 and H == 0:
            break
        
        tx, ty = map(int, sys.stdin.readline().split())
        kx, ky = map(int, sys.stdin.readline().split())
        tx -= 1
        ty -= 1
        kx -= 1
        ky -= 1
        
        grid = []
        for _ in range(H):
            row = list(map(int, sys.stdin.readline().split()))
            grid.append(row)
        
        visited = set()
        queue = deque()
        initial_state = (tx, ty, kx, ky)
        visited.add(initial_state)
        queue.append( (tx, ty, kx, ky, 0) )
        found = False
        answer = -1
        max_time = 100 * 3600  # 100 hours in seconds (assuming unit is seconds)
        
        while queue:
            t_x, t_y, k_x, k_y, time = queue.popleft()
            
            # Check if they meet
            if t_x == k_x and t_y == k_y:
                answer = time
                found = True
                break
            
            if time >= max_time:
                continue  # Exceeds time limit
            
            for dx_t, dy_t in directions:
                # Calculate new positions for Takayuki
                new_tx = t_x + dx_t
                new_ty = t_y + dy_t
                if new_tx < 0 or new_tx >= W or new_ty < 0 or new_ty >= H:
                    new_tx, new_ty = t_x, t_y
                elif grid[new_ty][new_tx] == 1:
                    new_tx, new_ty = t_x, t_y
                
                # Calculate new positions for Kazuyuki (opposite direction)
                dx_k = -dx_t
                dy_k = -dy_t
                new_kx = k_x + dx_k
                new_ky = k_y + dy_k
                if new_kx < 0 or new_kx >= W or new_ky < 0 or new_ky >= H:
                    new_kx, new_ky = k_x, k_y
                elif grid[new_ky][new_kx] == 1:
                    new_kx, new_ky = k_x, k_y
                
                # Check if new positions meet
                if new_tx == new_kx and new_ty == new_ky:
                    if time + 1 <= max_time:
                        answer = time + 1
                        found = True
                        break
                
                new_state = (new_tx, new_ty, new_kx, new_ky)
                if new_state not in visited:
                    visited.add(new_state)
                    queue.append( (new_tx, new_ty, new_kx, new_ky, time + 1) )
            
            if found:
                break
        
        if found and answer <= max_time:
            print(answer)
        else:
            print("NA")

if __name__ == "__main__":
    main()
```

- **Initialization**: Read input values and convert positions to 0-based indices.
- **BFS Setup**: Initialize the queue with the starting positions and time 0.
- **Direction Handling**: For each direction, compute new positions considering grid boundaries and obstacles.
- **Meeting Check**: After each move, check if both are in the same cell. If so, record the time and exit.
- **Termination**: Check time constraints and print results based on whether a meeting was found within the allowed time.
