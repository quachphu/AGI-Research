To solve this problem, we need to determine if a new user login is similar to any existing logins based on specific transformation rules. The transformations allowed include changing case, converting 'O' to '0' (and vice versa), and converting between '1', 'l' (lowercase L), and 'I' (uppercase I).

### Approach
The key insight is to normalize each login into a canonical form where all allowed transformations are accounted for. This normalization allows us to check for similarity by comparing the canonical forms of the logins.

The normalization steps are as follows:
1. Convert all characters to lowercase.
2. Replace 'o' with '0'.
3. Replace 'i', 'l', and '1' with '1'.

By applying these steps to each login, we can transform them into a form where similar logins become identical. If the normalized form of the new login matches any existing normalized login, the new login is considered similar and thus invalid.

### Solution Code
```python
def normalize(s):
    normalized = []
    for c in s:
        lower_c = c.lower()
        if lower_c == 'o':
            normalized.append('0')
        elif lower_c in {'i', 'l', '1'}:
            normalized.append('1')
        else:
            normalized.append(lower_c)
    return ''.join(normalized)

new_login = input().strip()
n = int(input())
existing_logins = [normalize(input().strip()) for _ in range(n)]
target = normalize(new_login)

print("No" if target in existing_logins else "Yes")
```

### Explanation
1. **Normalization Function**: The `normalize` function converts each character of the login string to a canonical form by applying the specified transformations. This ensures that any similar logins are transformed into the same string.
2. **Reading Inputs**: The new login and existing logins are read from the input.
3. **Normalization Check**: Each existing login is normalized and stored in a list. The new login is also normalized and checked against the list of normalized existing logins. If a match is found, the new login is invalid; otherwise, it is valid.

This approach efficiently checks for similarity by reducing the problem to a simple string comparison after normalization, ensuring correctness and optimal performance.
