To solve this problem, we need to determine if an N-sided polygon can be formed given the lengths of its sides. The key insight is to use the theorem that states an N-sided polygon can be drawn if and only if the longest side is strictly shorter than the sum of the lengths of the remaining sides.

### Approach
1. **Read Input**: Read the number of sides \( N \) and the list of side lengths.
2. **Calculate Total Sum**: Compute the sum of all the side lengths.
3. **Find Maximum Length**: Identify the longest side from the list of side lengths.
4. **Check Theorem Condition**: Verify if the sum of the remaining sides (total sum minus the longest side) is greater than the longest side itself. If this condition is met, the polygon can be formed; otherwise, it cannot.

### Solution Code
```python
n = int(input())
lengths = list(map(int, input().split()))
total = sum(lengths)
max_length = max(lengths)
if (total - max_length) > max_length:
    print("Yes")
else:
    print("No")
```

### Explanation
1. **Reading Input**: The input consists of an integer \( N \) followed by \( N \) integers representing the side lengths. These are read and stored in a list.
2. **Sum Calculation**: The sum of all side lengths is computed to determine the total length available.
3. **Maximum Length Identification**: The longest side is identified using the `max` function.
4. **Condition Check**: The theorem's condition is checked by comparing the sum of the remaining sides (total sum minus the longest side) with the longest side. If the remaining sum is greater, the polygon can be formed, and "Yes" is printed; otherwise, "No" is printed.

This approach efficiently checks the necessary condition using basic arithmetic operations and comparisons, ensuring it runs in linear time relative to the number of sides, which is optimal for the given constraints.
