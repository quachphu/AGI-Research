To solve this problem, we need to determine the number of matches required to conduct a knockout tennis tournament where the number of participants may not be a power of two. The key insight is that each match eliminates exactly one player, so the total number of matches required is always one less than the number of participants.

### Approach
1. **Understanding the Problem**: In a knockout tournament, each match eliminates one player. To determine the winner, all but one player must be eliminated. Therefore, the number of matches required is always `n - 1` where `n` is the number of participants.
2. **Handling Edge Cases**: If there are no participants (`n = 0`), the number of matches is 0. For any positive number of participants, the number of matches is simply `n - 1`.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    for i in range(1, t + 1):
        n = int(input[i])
        print(max(0, n - 1))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first line contains the number of test cases.
2. **Processing Each Test Case**: For each test case, we read the number of participants and compute the number of matches as `n - 1` if `n` is positive. If `n` is zero, we output 0.
3. **Output the Result**: The result for each test case is printed immediately after computation.

This approach efficiently computes the result in constant time for each test case, ensuring optimal performance even for large values of `n` up to 10^9.
