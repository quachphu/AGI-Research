To solve this problem, we need to determine if a given graph, specified by the degrees of its vertices, is a tree. A tree is a connected acyclic graph, and we can use specific properties of trees to check this efficiently.

### Approach
The key properties of a tree that we use here are:
1. A tree with \( N \) vertices has exactly \( N-1 \) edges.
2. The sum of the degrees of all vertices in a tree is \( 2 \times (N-1) \) (since each edge contributes exactly 2 to the sum of degrees).
3. All vertices in a tree (except in the case of a single node) must have a degree of at least 1.

Based on these properties, our approach involves the following steps:
1. Check if there is only one vertex. If so, it must have a degree of 0 to be a tree.
2. For more than one vertex, check if the sum of all vertex degrees is exactly \( 2 \times (N-1) \).
3. Ensure all vertices have a degree of at least 1.

### Solution Code
```python
n = int(input())
degrees = list(map(int, input().split()))

if n == 1:
    print("Yes" if degrees[0] == 0 else "No")
else:
    total = sum(degrees)
    if total != 2 * (n - 1):
        print("No")
    else:
        print("Yes" if all(d >= 1 for d in degrees) else "No")
```

### Explanation
1. **Single Vertex Check**: If there is only one vertex, it must have a degree of 0 to form a valid tree (a single node with no edges).
2. **Sum of Degrees Check**: For a graph with \( N \) vertices to be a tree, the sum of all vertex degrees must be \( 2 \times (N-1) \). This ensures there are exactly \( N-1 \) edges.
3. **Non-zero Degrees Check**: All vertices (except in the single node case) must have a degree of at least 1 to ensure the graph is connected. If any vertex has a degree of 0, the graph cannot be connected and thus cannot be a tree.

This approach efficiently checks the necessary conditions using simple arithmetic and list operations, ensuring correctness with a time complexity of \( O(N) \), which is optimal for the given problem constraints.
