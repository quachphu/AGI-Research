### Approach
1. **Case when `a` equals `b`**: No presses are needed.
2. **Case when `a < b`**: We need to increase the volume. The optimal strategy is to use the largest possible steps (5, then 2, then 1) to minimize the number of presses. The remainder when divided by 5 determines if we need additional steps for 1 or 2.
3. **Case when `a > b`**: We need to decrease the volume. Here, we must ensure each step does not make the volume negative. We use a greedy approach to subtract the largest possible steps (5, then 2, then 1) while ensuring each step is valid.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    T = int(data[0])
    index = 1
    for _ in range(T):
        a = int(data[index])
        b = int(data[index + 1])
        index += 2
        if a == b:
            print(0)
            continue
        if a < b:
            d = b - a
            q, r = divmod(d, 5)
            steps = q
            if r != 0:
                steps += 1 if r <= 2 else 2
            print(steps)
        else:
            d = a - b
            steps_5 = min(d // 5, a // 5)
            remaining = d - steps_5 * 5
            steps_2 = remaining // 2
            steps_1 = remaining % 2
            total = steps_5 + steps_2 + steps_1
            print(total)

if __name__ == "__main__":
    main()
```
