To solve this problem, we need to calculate the sum of the weights of each character in a given string, where each character's weight is determined by its position in the English alphabet (e.g., 'a' has a weight of 1, 'b' has a weight of 2, and so on up to 'z' with a weight of 26).

### Approach
1. **Understanding Character Weights**: Each lowercase character's weight can be determined by its position in the alphabet. For example, 'a' is the first character with a weight of 1, 'b' is the second with a weight of 2, etc. This position can be derived using the ASCII value of the character. The ASCII value of 'a' is 97, so subtracting 96 from the ASCII value of any lowercase character will give its weight (e.g., ord('a') - 96 = 1).

2. **Reading Input**: The input is a single string which we read from standard input.

3. **Summing Weights**: For each character in the input string, compute its weight using the derived formula and accumulate the total sum.

### Solution Code
```python
def calculate_weight():
    s = input().strip()
    total = 0
    for c in s:
        total += ord(c) - 96  # Calculate weight as 'a' -> 1, 'b' -> 2, ..., 'z' -> 26
    print(total)

calculate_weight()
```

### Explanation
1. **Reading Input**: The function `calculate_weight` reads the input string using `input().strip()` to remove any leading or trailing whitespace.
2. **Iterating Over Characters**: For each character in the string, we compute its weight by converting the character to its ASCII value using `ord(c)`, then subtracting 96 to get the correct weight.
3. **Summing Weights**: We initialize a variable `total` to 0 and increment it by the weight of each character as we iterate through the string.
4. **Output the Result**: Finally, the accumulated total is printed, which is the sum of the weights of all characters in the string.

This approach efficiently computes the required sum in linear time, O(n), where n is the length of the string, making it suitable for the given constraints.
