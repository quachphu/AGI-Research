To solve this problem, we need to determine the winner of a game where two players, T and HL, take turns removing stones from piles under specific constraints. The player who cannot make a move loses. The solution involves analyzing the initial configuration of the piles to decide the optimal strategy for each player.

### Approach
1. **Identify the Dominant Pile**: If the largest pile has more stones than the sum of all other piles combined, the first player (T) can always win by repeatedly taking stones from this pile.
2. **Check Total Stones Parity**: If no single pile is dominant, the winner is determined by the parity (odd or even) of the total number of stones. If the total is odd, T wins because he starts first; if even, HL wins.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    total = sum(a)
    max_pile = max(a)
    sum_rest = total - max_pile
    if max_pile > sum_rest:
        print("T")
    else:
        print("T" if total % 2 == 1 else "HL")
```

### Explanation
1. **Input Reading**: The code reads the number of test cases and processes each game configuration.
2. **Dominant Pile Check**: For each game, it checks if the largest pile has more stones than the sum of all other piles. If true, T wins immediately.
3. **Parity Check**: If no pile is dominant, the total number of stones is checked. An odd total means T wins (since he starts first), and an even total means HL wins.

This approach efficiently determines the winner by leveraging two key insights about the game structure, ensuring optimal performance and correctness.
