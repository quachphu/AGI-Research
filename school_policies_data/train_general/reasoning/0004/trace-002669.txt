To solve this problem, we need to determine how many ways Fafa can choose team leaders such that the remaining employees can be evenly divided among them. Each team leader must be responsible for a positive number of employees, and every non-leader must be assigned to exactly one leader.

### Approach
1. **Understanding the Problem Requirements**:
   - We need to find the number of valid team leader counts `l` such that the remaining employees `(n - l)` can be evenly divided among `l` leaders.
   - This translates to finding values of `l` where `(n - l) % l == 0` and each leader gets at least one employee.

2. **Key Insight**:
   - For `(n - l) % l == 0` to hold true, `l` must be a divisor of `n` because `n` can be expressed as `l * (k + 1)` where `k` is a positive integer.
   - Valid values of `l` are those divisors of `n` (excluding `n` itself) that are less than or equal to `n/2` to ensure each leader gets at least one employee.

3. **Algorithm**:
   - **Step 1**: Generate all divisors of `n`.
   - **Step 2**: Exclude `n` itself from the list of divisors.
   - **Step 3**: Count the divisors that are less than or equal to `n/2`.

### Solution Code
```python
n = int(input())
divisors = set()
for i in range(1, int(n**0.5) + 1):
    if n % i == 0:
        divisors.add(i)
        divisors.add(n // i)
divisors.discard(n)
count = 0
for d in divisors:
    if d <= n / 2:
        count += 1
print(count)
```

### Explanation
1. **Generating Divisors**:
   - We iterate from 1 up to the square root of `n` to find all divisors efficiently. For each divisor `i`, both `i` and `n/i` are added to a set to avoid duplicates.

2. **Excluding `n`**:
   - After generating all divisors, we remove `n` from the set since a team leader count equal to `n` would leave no employees to manage.

3. **Counting Valid Divisors**:
   - We count how many of the remaining divisors are less than or equal to `n/2`, ensuring each leader can manage at least one employee.

This approach efficiently computes the valid team leader counts using divisor properties and ensures correctness by adhering to the problem constraints.
