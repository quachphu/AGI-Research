To solve this problem, we need to calculate the length of a hypotrochoid curve given the radii of two circles and the distance from the center of the moving circle to the pinhole. The solution involves understanding the parametric equations of the hypotrochoid and using numerical integration to compute the curve's length.

### Approach
1. **Understanding the Hypotrochoid**: The hypotrochoid is generated by rolling a smaller circle (radius Q) inside a fixed larger circle (radius P). The pen's position is at a distance R from the center of the smaller circle.
2. **Parametric Equations**: The parametric equations for the hypotrochoid involve trigonometric functions based on the radii and the distance R.
3. **Period Calculation**: The curve's period is determined by the least common multiple (LCM) of the periods of the parametric equations, which simplifies to a function of the greatest common divisor (gcd) of the radii differences.
4. **Special Case Handling**: When R is 0, the path is a circle with a circumference of \(2\pi(P-Q)\).
5. **Numerical Integration**: For non-zero R, numerical integration using Simpson's rule is applied over the calculated period to compute the curve's length.

### Solution Code
```python
import math
import sys

def hypotrochoid_length(P, Q, R):
    if R == 0:
        return 2 * math.pi * (P - Q)
    a = P - Q
    d = math.gcd(a, Q)
    C = P / Q
    T_period = 2 * math.pi * Q / P
    N_periods = P // d
    A = a**2 + (R * (a / Q))**2
    B = 2 * a * R * (a / Q)
    
    # Simpson's rule integration for one period
    n = 1000000  # Number of intervals (must be even)
    h = T_period / n
    integral = 0.0
    for i in range(n + 1):
        theta = i * h
        fx = math.sqrt(A - B * math.cos(C * theta))
        if i == 0 or i == n:
            integral += fx
        elif i % 2 == 1:
            integral += 4 * fx
        else:
            integral += 2 * fx
    integral *= h / 3
    return integral * N_periods

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        parts = list(map(int, line.split()))
        if len(parts) < 3:
            continue
        P, Q, R = parts
        if P == 0 and Q == 0 and R == 0:
            break
        length = hypotrochoid_length(P, Q, R)
        print("{0:.2f}".format(round(length, 2)))

if __name__ == "__main__":
    main()
```
