To solve this problem, we need to determine whether to turn on the air conditioner based on the room temperature. The decision is straightforward: if the temperature is 30 degrees Celsius or higher, we turn it on; otherwise, we do not.

### Approach
1. **Read Input**: The input is a single integer representing the current room temperature.
2. **Condition Check**: Check if the temperature is 30 degrees Celsius or higher.
3. **Output Result**: Print "Yes" if the temperature is 30 or higher, otherwise print "No".

This approach ensures that we directly check the condition specified and provide the appropriate output based on the given temperature.

### Solution Code
```python
def main():
    x = int(input())
    print("Yes" if x >= 30 else "No")

main()
```

### Explanation
1. **Reading Input**: The function reads the input using `input()` and converts it to an integer.
2. **Condition Check**: Using a conditional expression, the code checks if the temperature `x` is 30 or higher.
3. **Output**: Based on the condition check, the code prints "Yes" if the temperature is 30 or higher, otherwise it prints "No".

This solution efficiently handles all possible input values within the given constraints and ensures the correct output is produced with minimal computation.
