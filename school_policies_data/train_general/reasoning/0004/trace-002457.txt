To solve this problem, we need to determine the minimum number of shuffling operations required for a marble to move from an initial position `s` to a target position `t` under a series of glasses, based on a given permutation. If it's impossible, we should return -1.

### Approach
1. **Initial Check**: If the initial position `s` is the same as the target position `t`, the answer is 0 since no shuffles are needed.
2. **Cycle Detection**: Use a set to track visited positions to detect cycles. If we revisit a position, it means we are in a cycle that does not include `t`, hence it's impossible to reach `t`.
3. **Simulation**: Simulate each shuffle step-by-step. For each step, update the current position based on the permutation and check if it matches the target position. If it does, return the number of steps taken. If a cycle is detected, return -1.

### Solution Code
```python
import sys

def main():
    n, s, t = map(int, sys.stdin.readline().split())
    p = list(map(int, sys.stdin.readline().split()))
    
    if s == t:
        print(0)
        return
    
    current = s
    steps = 0
    visited = set()
    
    while True:
        current = p[current - 1]
        steps += 1
        if current == t:
            print(steps)
            return
        if current in visited:
            print(-1)
            return
        visited.add(current)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of the number of glasses `n`, initial position `s`, target position `t`, and the permutation array `p`.
2. **Immediate Check**: If `s` equals `t`, immediately print 0 as no shuffles are needed.
3. **Tracking Visits**: Use a set to keep track of positions visited to detect cycles.
4. **Shuffling Simulation**: For each shuffle, update the current position using the permutation. If the current position matches the target, print the number of steps. If a cycle is detected (current position revisited), print -1 indicating it's impossible to reach `t`.

This approach efficiently handles the problem by leveraging cycle detection in permutations, ensuring we do not enter infinite loops and correctly determine the minimum steps or impossibility.
