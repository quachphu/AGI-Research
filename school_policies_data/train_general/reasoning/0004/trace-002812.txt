To solve this problem, we need to determine the winner of an election in a country with an unusual electoral system. The winner is determined in two stages: first, each city selects a local winner, and then the overall winner is determined based on the number of cities each candidate won.

### Approach
1. **Local Winners**: For each city, determine the candidate with the highest number of votes. In case of a tie, the candidate with the smaller index is chosen.
2. **Count City Wins**: Track how many cities each candidate has won.
3. **Determine Overall Winner**: The candidate who won the most cities is the overall winner. In case of a tie, the candidate with the smaller index is chosen.

### Solution Code
```python
n, m = map(int, input().split())
counts = [0] * (n + 1)

for _ in range(m):
    votes = list(map(int, input().split()))
    max_votes = -1
    winner = 0
    for j in range(n):
        current = votes[j]
        if current > max_votes:
            max_votes = current
            winner = j + 1
        elif current == max_votes:
            if (j + 1) < winner:
                winner = j + 1
    counts[winner] += 1

max_count = -1
overall = 0
for candidate in range(1, n + 1):
    if counts[candidate] > max_count:
        max_count = counts[candidate]
        overall = candidate
    elif counts[candidate] == max_count:
        if candidate < overall:
            overall = candidate

print(overall)
```

### Explanation
1. **Reading Input**: The first line of input contains the number of candidates (n) and cities (m). Each subsequent line represents the votes received by each candidate in a city.
2. **Determining Local Winners**: For each city, iterate through the votes to find the candidate with the highest votes. In case of a tie, the candidate with the smaller index is selected.
3. **Counting City Wins**: Maintain a count of how many cities each candidate has won.
4. **Determining the Overall Winner**: After processing all cities, find the candidate with the highest count of city wins. In case of a tie, the candidate with the smaller index is chosen.

This approach ensures that we efficiently determine the winner by leveraging simple loops and conditional checks, making it both intuitive and effective for the given problem constraints.
