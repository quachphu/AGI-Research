To solve this problem, we need to identify valid integers from an array that are coprime with a given integer X. Valid integers are those whose greatest common divisor (gcd) with X is 1. 

### Approach
1. **Input Reading**: Read all input at once for efficiency, especially given the constraints.
2. **Processing Each Test Case**: For each test case, extract the number of integers (N) and the integer X. Then, process the array of integers to check each element's gcd with X.
3. **Check Coprimality**: For each integer in the array, compute the gcd with X. If the gcd is 1, the integer is valid.
4. **Output**: Collect all valid integers and print them in the order they appear. If no valid integers are found, print -1.

### Solution Code
```python
import math
import sys

def main():
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N = int(input[idx])
        X = int(input[idx + 1])
        idx += 2
        A = list(map(int, input[idx:idx + N]))
        idx += N
        res = []
        for num in A:
            if math.gcd(num, X) == 1:
                res.append(str(num))
        if not res:
            print(-1)
        else:
            print(' '.join(res))

main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and split into a list of tokens for quick access. This approach is efficient for handling large inputs.
2. **Processing Each Test Case**: For each test case, we extract N (number of integers) and X (the integer to check coprimality against). We then process the next N integers from the input list.
3. **Checking Coprimality**: Using Python's `math.gcd` function, we check if each integer in the array is coprime with X. If they are, they are added to the result list.
4. **Generating Output**: The result list is checked for valid integers. If empty, -1 is printed. Otherwise, valid integers are printed in their original order.

This approach ensures that we efficiently handle the input and process each integer in linear time relative to the number of integers, making the solution both optimal and easy to understand.
