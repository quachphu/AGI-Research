To solve this problem, we need to determine if each given string contains all the characters from 'a' to 'z'. A string is considered complete if it includes every letter from the alphabet at least once.

### Approach
1. **Input Reading**: Read the number of test cases followed by each string.
2. **Character Set Check**: For each string, convert it into a set of characters to eliminate duplicates.
3. **Check Completeness**: Check if the size of the set is exactly 26, which would mean all letters from 'a' to 'z' are present.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    for _ in range(n):
        s = sys.stdin.readline().strip()
        if len(set(s)) == 26:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The function reads the number of test cases `n` and then processes each string line by line.
2. **Set Conversion**: Each string is converted into a set of characters. This helps in removing duplicate characters and allows us to efficiently check the presence of all unique characters.
3. **Completeness Check**: By checking if the size of the set is 26, we determine if all characters from 'a' to 'z' are present. If the size is 26, the string is complete and we print "YES"; otherwise, we print "NO".

This approach ensures that we efficiently determine the completeness of each string using set operations, which are optimal for membership and uniqueness checks.
