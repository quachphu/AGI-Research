To solve this problem, we need to count the number of pairs (x, y) such that 1 ≤ x ≤ n, 1 ≤ y ≤ m, and the sum (x + y) is divisible by 5. The solution leverages mathematical insights to efficiently compute the result without iterating through all possible pairs, which would be computationally infeasible for large values of n and m.

### Approach
1. **Modulo Insight**: For a pair (x, y) to have a sum divisible by 5, the remainders of x and y when divided by 5 must sum to 5 or 0. This means if x % 5 = a, then y % 5 must be (5 - a) % 5.
2. **Count Remainders**: For each number in the ranges 1 to n and 1 to m, count how many numbers give each possible remainder (0 to 4) when divided by 5.
3. **Pair Combinations**: Multiply the counts of corresponding remainders from the two ranges that sum to a multiple of 5. Sum these products to get the total number of valid pairs.

### Solution Code
```python
n, m = map(int, input().split())

def compute_counts(num):
    counts = [0] * 5
    counts[0] = num // 5
    for r in range(1, 5):
        if num >= r:
            counts[r] = (num - r) // 5 + 1
        else:
            counts[r] = 0
    return counts

count_x = compute_counts(n)
count_y = compute_counts(m)

total = 0
for a in range(5):
    b = (5 - a) % 5
    total += count_x[a] * count_y[b]

print(total)
```

### Explanation
1. **Reading Input**: The input values n and m are read from standard input.
2. **Count Remainders**: The function `compute_counts` calculates how many numbers in the range 1 to a given number (either n or m) leave each possible remainder (0 to 4) when divided by 5. This is done efficiently using integer division and modulo operations.
3. **Calculate Valid Pairs**: For each remainder `a` from 0 to 4, determine the corresponding remainder `b` such that `(a + b) % 5 == 0`. Multiply the counts of these remainders from the two ranges and sum the results to get the total number of valid pairs.

This approach ensures that we efficiently compute the result in constant time, O(1), regardless of the size of n and m, making it suitable for very large input values up to 1,000,000.
