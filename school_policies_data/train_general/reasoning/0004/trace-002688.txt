To solve this problem, we need to simulate the process where each person tries to sit in their desired chair and, if unavailable, moves to the next chair in a cyclic manner until they find an available seat. The solution involves efficiently managing the queue of people and tracking which seats are taken.

### Approach
1. **Queue Initialization**: Start by initializing a queue with each person's ID and their initial desired chair.
2. **Processing the Queue**: Process each person in the queue. If their current desired chair is available, they sit there. If not, they increment their desired chair (cyclically) and re-enter the queue at the end.
3. **Tracking Taken Seats**: Use a boolean array to keep track of which seats are taken to ensure each seat is occupied by the first person to reach it.

### Solution Code
```python
import sys
from collections import deque

def main():
    n = int(sys.stdin.readline())
    p = list(map(int, sys.stdin.readline().split()))
    
    queue = deque()
    for i in range(n):
        queue.append((i + 1, p[i]))  # (id, current_p)
    
    taken = [False] * (n + 1)  # 1-based indexing
    result = [0] * (n + 1)
    
    while queue:
        user_id, current_p = queue.popleft()
        if not taken[current_p]:
            taken[current_p] = True
            result[current_p] = user_id
        else:
            # Calculate next_p with wrap-around
            next_p = current_p % n + 1
            queue.append((user_id, next_p))
    
    for i in range(1, n + 1):
        print(result[i])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Queue Initialization**: Each person starts with their initial desired chair. The queue is initialized with tuples containing the person's ID and their initial desired chair.
2. **Processing Loop**: The loop processes each person in the queue. If their current desired chair is available, it is marked as taken, and the person is assigned to that chair. If not, they increment their desired chair (with wrap-around using modulo arithmetic) and re-enter the queue.
3. **Efficiency**: The algorithm efficiently processes each person's request in a FIFO manner, ensuring that each person eventually finds an available chair by cycling through their sequence of desired chairs. This approach ensures that the solution handles up to the maximum constraint efficiently using a queue and a boolean array to track seat availability.
