2. **Residue Counts**: Calculate how many numbers fall into each residue class modulo 9. This helps in efficiently counting numbers with specific digital roots.
3. **Valid Triples Using Digital Roots (S)**: Use precomputed residue counts to determine the number of valid triples (A, B, C) where the digital root of the product of A and B matches the digital root of C.
4. **Correct Triples (T)**: Count the number of correct triples where AB = C directly by iterating through possible values of A and B.
5. **Result Calculation**: The result is the difference between the valid triples using digital roots (S) and the correct triples (T).

def main():
    import sys
    N = int(sys.stdin.readline())
    
    # Compute residue counts for each residue 0-8 mod 9
    residue_counts = [0] * 9
    for r in range(9):
        if r == 0:
            residue_counts[r] = N // 9
        else:
            if N < r:
                residue_counts[r] = 0
            else:
                residue_counts[r] = ((N - r) // 9) + 1
    
    # Compute cnt_dr for each digital root 1-9
    cnt_dr = [0] * 10  # Using indices 1-9
    for dr in range(1, 10):
        if dr < 9:
            cnt_dr[dr] = residue_counts[dr]
        else:
            cnt_dr[dr] = residue_counts[0]
    
    # Calculate S: number of triples where digital root condition holds
    S = 0
    for a in range(1, 10):
        for b in range(1, 10):
            product = a * b
            dr_ab = (product - 1) % 9 + 1
            S += cnt_dr[a] * cnt_dr[b] * cnt_dr[dr_ab]
    
    # Calculate T: number of correct triples where AB = C
    T = 0
    for A in range(1, N + 1):
        T += N // A
    
    # The answer is S - T
    print(S - T)
