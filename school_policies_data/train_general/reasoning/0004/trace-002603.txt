    if g != 1:

def extended_gcd(a, b):
    if a == 0:
        return (b, 0, 1)
    else:
        g, y, x = extended_gcd(b % a, a)

To solve this problem, we need to find the integer \( x \) within a given range \([a, b]\) that maximizes the function \( f(x) = |\sin(\frac{p}{q} \pi x)| \). The optimal value of \( f(x) \) is 1, which occurs when \( \frac{p x \pi}{q} \) is an odd multiple of \( \frac{\pi}{2} \). However, since \( x \) must be an integer, we need to find the integer closest to these optimal points.

### Approach
1. **Identify Optimal Points**: The optimal points for \( x \) are given by \( x_{\text{opt}} = \frac{(2k+1)q}{2p} \) for integers \( k \). These points are where the sine function reaches its maximum value.
2. **Check Boundaries**: Include the boundaries \( a \) and \( b \) as potential candidates.
3. **Generate Candidates**: For each optimal point \( x_{\text{opt}} \), consider the floor and ceiling values as potential candidates.
4. **Modular Congruence**: Solve modular congruences to find values of \( x \) that are close to the optimal points modulo \( q \).
5. **Evaluate Candidates**: For each candidate \( x \), compute the residue modulo \( q \) and determine the distance from the ideal midpoint \( q/2 \). The candidate with the smallest distance is the solution.
