To solve this problem, we need to determine if two given genomes belong to the same race of dwarves. Two dwarves are considered to be of the same race if we can swap exactly two characters in the first genome to obtain the second genome. 

### Approach
1. **Check Lengths**: If the lengths of the two genomes are different, they cannot be transformed into each other by swapping two characters, so the answer is immediately "NO".
2. **Check Character Frequencies**: If the two genomes do not have the same characters with the same frequencies, they cannot be transformed into each other, so the answer is "NO".
3. **Identify Differing Positions**: Collect the indices where the characters in the two genomes differ. If there are exactly two differing positions, check if swapping the characters at these positions in the first genome results in the second genome. If so, the answer is "YES"; otherwise, it is "NO".

### Solution Code
```python
s1 = input().strip()
s2 = input().strip()

def same_race():
    if len(s1) != len(s2):
        print("NO")
        return
    
    if sorted(s1) != sorted(s2):
        print("NO")
        return
    
    diffs = [i for i in range(len(s1)) if s1[i] != s2[i]]
    
    if len(diffs) != 2:
        print("NO")
        return
    
    i, j = diffs
    if s1[i] == s2[j] and s1[j] == s2[i]:
        print("YES")
    else:
        print("NO")

same_race()
```

### Explanation
1. **Check Lengths**: The first check ensures that both genomes are of the same length. If not, it is impossible to transform one into the other by swapping characters.
2. **Check Character Frequencies**: By sorting both genomes and comparing the sorted results, we ensure that both genomes contain the same characters with the same frequencies. This step is crucial because if the characters do not match, no number of swaps can make the genomes identical.
3. **Identify Differing Positions**: By collecting the indices where the characters differ, we can determine if there are exactly two such positions. If there are exactly two differing positions, we check if swapping the characters at these positions in the first genome results in the second genome. If they do, the answer is "YES"; otherwise, it is "NO".

This approach efficiently checks all necessary conditions to determine if the genomes can be made identical with a single swap, ensuring correctness and optimal performance.
