To solve this problem, we need to determine the maximum possible rest time Anton can have between his chess and programming classes. The rest time is defined as the minimal distance between any two non-overlapping intervals from each set of classes. If the intervals overlap, the rest time is zero.

### Approach
1. **Identify Key Values**: For each set of intervals (chess and programming), we need to determine:
   - The minimum ending time of the chess intervals.
   - The maximum starting time of the chess intervals.
   - The maximum starting time of the programming intervals.
   - The minimum ending time of the programming intervals.

2. **Calculate Gaps**: Using the key values identified:
   - Compute the gap between the maximum programming start and the minimum chess end.
   - Compute the gap between the maximum chess start and the minimum programming end.

3. **Determine Maximum Rest Time**: The result is the maximum of the two gaps calculated, ensuring that non-positive values (indicating overlaps) are treated as zero.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    min_r1 = float('inf')
    max_l1 = -float('inf')
    for _ in range(n):
        l, r = map(int, sys.stdin.readline().split())
        if r < min_r1:
            min_r1 = r
        if l > max_l1:
            max_l1 = l
    
    m = int(sys.stdin.readline())
    max_l2 = -float('inf')
    min_r2 = float('inf')
    for _ in range(m):
        l, r = map(int, sys.stdin.readline().split())
        if l > max_l2:
            max_l2 = l
        if r < min_r2:
            min_r2 = r
    
    gap1 = max_l2 - min_r1
    gap2 = max_l1 - min_r2
    max_gap = max(gap1, gap2, 0)
    print(max_gap)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read efficiently using `sys.stdin` to handle large input sizes.
2. **Tracking Key Values**: While reading each interval, we keep track of the minimum ending time and maximum starting time for chess intervals, and similarly for programming intervals.
3. **Calculating Gaps**: Two potential gaps are calculated:
   - The gap between the earliest end of a chess interval and the latest start of a programming interval.
   - The gap between the latest start of a chess interval and the earliest end of a programming interval.
4. **Result Calculation**: The maximum of these gaps is taken, ensuring that any negative values (indicating overlaps) are replaced by zero, which is the correct rest time when intervals overlap.

This approach ensures that we efficiently compute the maximum possible rest time with a linear time complexity, O(n + m), making it suitable for large input sizes up to 200,000 intervals.
