To solve this problem, we need to determine the total number of ants that will be blocked by horizontal barriers as they march along their respective x-coordinates in the positive y-direction. Each barrier spans a range of x-coordinates at a specific y-coordinate, and any ant encountering a barrier will stop moving.

### Approach
1. **Problem Analysis**: Each ant moves along its x-coordinate upwards. A barrier at a lower y-coordinate will block an ant before any barrier at a higher y-coordinate for the same x-coordinate. Therefore, we need to consider all x-coordinates covered by any barrier, as the ant will be blocked by the first encountered barrier (lowest y-coordinate).

2. **Interval Merging**: Convert each barrier into an interval representing the x-coordinates it covers. Merge overlapping or adjacent intervals to avoid counting the same x-coordinate multiple times. The total number of blocked ants is the sum of the lengths of these merged intervals.

3. **Efficiency**: Sorting the intervals by their starting x-coordinate allows us to merge them in linear time, ensuring the solution is efficient even for large input sizes.

### Solution Code
```python
n = int(input())
intervals = []
for _ in range(n):
    xi, yi, di = map(int, input().split())
    end = xi + di
    intervals.append((xi, end))

# Sort intervals based on their start value
intervals.sort()

merged = []
for interval in intervals:
    if not merged:
        merged.append(interval)
    else:
        last_start, last_end = merged[-1]
        current_start, current_end = interval
        if current_start <= last_end:
            # Merge the intervals
            new_start = last_start
            new_end = max(last_end, current_end)
            merged.pop()
            merged.append((new_start, new_end))
        else:
            merged.append(interval)

total = 0
for start, end in merged:
    total += end - start + 1

print(total)
```

### Explanation
1. **Reading Input**: The input consists of the number of barriers and their respective parameters. Each barrier is converted into an interval `[xi, xi + di]` representing the x-coordinates it covers.

2. **Sorting Intervals**: Intervals are sorted by their starting x-coordinate to facilitate merging overlapping or adjacent intervals efficiently.

3. **Merging Intervals**: Traverse the sorted intervals, merging them if they overlap or are adjacent. This step ensures that each x-coordinate is counted only once.

4. **Calculating Total Blocked Ants**: The total number of blocked ants is the sum of the lengths of all merged intervals. Each interval's length is calculated as `end - start + 1`, representing the number of x-coordinates covered.

This approach efficiently handles up to 100,000 barriers, ensuring optimal performance using sorting and linear traversal for merging intervals.
