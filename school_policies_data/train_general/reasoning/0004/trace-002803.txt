To solve this problem, we need to identify the index of the unique element in an array where all other elements are the same. The solution involves determining the majority value by examining the first few elements and then finding the position of the element that differs from this majority value.

### Approach
1. **Determine the Majority Value**: 
   - Check the first three elements of the array. Since the problem guarantees that all elements except one are the same, the majority value can be identified by checking these elements:
     - If the first two elements are the same, they are the majority.
     - If the first two elements are different, the third element will match one of them, indicating the majority.
2. **Identify the Unique Element**: 
   - Once the majority value is determined, iterate through the array to find the element that differs from the majority value. The index of this element (1-based) is the result.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    arr = list(map(int, input().split()))
    # Determine the majority element
    if arr[0] == arr[1]:
        majority = arr[0]
    else:
        if arr[2] == arr[0]:
            majority = arr[0]
        else:
            majority = arr[1]
    # Find the unique element's index
    for i in range(len(arr)):
        if arr[i] != majority:
            print(i + 1)
            break
```

### Explanation
1. **Reading Input**: The input consists of multiple test cases. For each test case, we read the array length and the array elements.
2. **Majority Determination**: By examining the first three elements, we efficiently determine the majority value. This leverages the problem's constraint that exactly one element is different.
3. **Finding the Unique Element**: We iterate through the array to find the element that does not match the majority value and print its 1-based index.

This approach ensures that we efficiently determine the majority value and correctly identify the unique element in linear time, making the solution both optimal and straightforward.
