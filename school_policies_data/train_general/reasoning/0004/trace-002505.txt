To solve this problem, we need to count the number of non-degenerate triangles (triangles with non-zero area) formed by connecting given points on a plane. The key challenge is efficiently determining how many triplets of points are collinear and subtracting these from the total number of possible triangles.

### Approach
1. **Total Triplets Calculation**: The total number of triangles that can be formed by `n` points is given by the combination formula `C(n, 3)`, which is `n * (n - 1) * (n - 2) / 6` for `n >= 3`.

2. **Collinear Points Check**: For each pair of points, we determine the line they form and count how many other points lie on this line. This is done using a normalized line equation to avoid duplicate entries for the same line.

3. **Normalization of Line Equation**: To ensure each line is uniquely represented, we normalize the coefficients of the line equation by dividing by their greatest common divisor (GCD) and adjusting the signs so that the leading coefficient is non-negative.

4. **Counting Collinear Points**: Using a dictionary, we count how many times each line (represented by its normalized equation) is formed by pairs of points. For each line formed by `m` points, the number of collinear triplets is `C(m, 3)`.

5. **Result Calculation**: Subtract the number of collinear triplets from the total number of triplets to get the number of non-degenerate triangles.

import math
from collections import defaultdict

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    if n < 3:
        print(0)
        return
    points = []
    idx = 1
    for _ in range(n):
        x = int(input[idx])
        y = int(input[idx+1])
        points.append((x, y))
        idx += 2
    
    line_counts = defaultdict(int)
    
    for i in range(n):
        x1, y1 = points[i]
        for j in range(i + 1, n):
            x2, y2 = points[j]
            a = y2 - y1
            b = x1 - x2
            c = x2 * y1 - x1 * y2
            
            g = math.gcd(math.gcd(abs(a), abs(b)), abs(c))
            if g == 0:
                g = 1
            
            a_div = a // g
            b_div = b // g
            c_div = c // g
            
            # Normalize the sign
            if a_div < 0 or (a_div == 0 and b_div < 0):
                a_div = -a_div
                b_div = -b_div
                c_div = -c_div
            
            line = (a_div, b_div, c_div)
            line_counts[line] += 1
    
    total = n * (n - 1) * (n - 2) // 6
    invalid = 0
    
    for cnt in line_counts.values():
        if cnt == 0:
            continue
        sqrt_val = math.isqrt(1 + 8 * cnt)
        m = (1 + sqrt_val) // 2
        if m >= 3:
            invalid += m * (m - 1) * (m - 2) // 6
    
    print(total - invalid)

if __name__ == "__main__":
    main()
