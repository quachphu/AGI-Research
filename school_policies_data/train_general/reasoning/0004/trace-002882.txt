To solve this problem, we need to determine the minimum number of moves required to adjust a combination lock from its current state to a target state. Each move involves rotating a disk one digit forward or backward. The key is to find the optimal rotation for each disk to minimize the total number of moves.

### Approach
1. **Input Reading**: Read the number of disks, the current state of the lock, and the target state.
2. **Digit Pair Processing**: For each corresponding pair of digits in the current and target states, compute the minimum number of moves required.
3. **Move Calculation**: For each digit pair, calculate the absolute difference. The minimum moves will be the smaller of the direct difference or the wrap-around difference (10 minus the direct difference).
4. **Summing Moves**: Sum the minimum moves for all digit pairs to get the total number of moves required.

### Solution Code
```python
n = int(input())
original = input().strip()
target = input().strip()

total = 0
for o, t in zip(original, target):
    a = int(o)
    b = int(t)
    diff = abs(a - b)
    total += min(diff, 10 - diff)

print(total)
```

### Explanation
1. **Reading Input**: The input consists of three lines: the number of disks, the current state, and the target state. We read these inputs and convert them into appropriate variables.
2. **Processing Each Digit Pair**: Using a loop, we iterate over each digit in the current and target states. For each pair of digits, we convert them to integers and calculate the direct difference.
3. **Calculating Minimum Moves**: For each digit pair, the minimum moves required are determined by considering both the direct difference and the wrap-around difference (since the lock digits wrap around from 0 to 9 and vice versa). The minimum of these two values is added to the total moves.
4. **Output the Result**: After processing all digit pairs, the sum of all minimum moves is printed as the result.

This approach ensures that we efficiently compute the minimum number of moves for each disk, leading to an optimal solution for the entire lock. The time complexity is O(n), which is efficient given the problem constraints (n up to 1000).
