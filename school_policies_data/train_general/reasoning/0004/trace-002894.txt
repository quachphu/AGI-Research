To solve this problem, we need to read an array of integers from the input and print each integer decremented by 1. The input format specifies that the first line contains the number of elements, followed by the elements themselves. Each element should be processed individually to produce the desired output.

### Approach
1. **Read Input**: The first input line gives the number of elements, N. The subsequent N lines each contain an integer of the array.
2. **Process Each Element**: For each integer read from the input, subtract 1 from it.
3. **Output the Result**: Print each resulting value on a new line immediately after processing it.

This approach ensures that we process each element as it is read, which is efficient and straightforward given the constraints.

### Solution Code
```python
def main():
    n = int(input())
    for _ in range(n):
        num = int(input())
        print(num - 1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading the Number of Elements**: The first input line is converted to an integer `n`, which tells us how many subsequent integers to read.
2. **Reading and Processing Elements**: Using a loop that runs `n` times, each iteration reads an integer from the input, subtracts 1 from it, and prints the result immediately.
3. **Immediate Output**: By printing each result right after processing, we avoid the need to store the entire array in memory, which is efficient for the given problem constraints.

This solution efficiently handles the input and output requirements, ensuring correctness and simplicity.
