To solve this problem, we need to simulate a game between a stowaway and a controller on a train with `n` wagons. The goal is to determine who wins based on their optimal moves. The stowaway aims to avoid being caught as long as possible, while the controller follows a deterministic movement pattern.

### Approach
1. **Input Parsing**: Read the number of wagons, initial positions of the stowaway and controller, the controller's initial direction, and the sequence of train states (moving or idle).
2. **Simulation**: Use a recursive depth-first search (DFS) with memoization to simulate each minute of the game. The simulation considers both players' movements based on the train's state each minute.
3. **Movement Rules**:
   - **Controller**: Moves in a fixed direction, reversing direction upon reaching the head (wagon 1) or tail (wagon `n`).
   - **Stowaway**: Moves to neighboring wagons or stays if the train is moving. If the train is idle, the stowaway leaves and re-enters any wagon except the controller's current position.
4. **Optimal Play**: The stowaway chooses moves to maximize survival time, while the controller's moves are deterministic.

### Solution Code
```python
import sys
from functools import lru_cache

def main():
    n, m, k = map(int, sys.stdin.readline().split())
    c_dir = sys.stdin.readline().strip().lower()
    states = sys.stdin.readline().strip()
    assert states[-1] == '1', "Last state must be '1'"
    states = list(states)
    t = len(states)

    def move_controller(c_pos, direction):
        if direction == 'to head':
            new_c = c_pos - 1
            if new_c == 1:
                new_dir = 'to tail'
            else:
                new_dir = 'to head'
        else:  # 'to tail'
            new_c = c_pos + 1
            if new_c == n:
                new_dir = 'to head'
            else:
                new_dir = 'to tail'
        return new_c, new_dir

    @lru_cache(maxsize=None)
    def dfs(s_pos, c_pos, current_dir, step):
        if step >= t:
            return None  # Stowaway wins
        current_state = states[step]
        if current_state == '0':
            possible_moves = []
            for delta in (-1, 0, 1):
                new_s = s_pos + delta
                if 1 <= new_s <= n and new_s != c_pos:
                    possible_moves.append(new_s)
            if not possible_moves:
                return step + 1  # Capture at this step
            max_capture = -1
            for new_s in possible_moves:
                new_c, new_dir = move_controller(c_pos, current_dir)
                if new_s == new_c:
                    capture_step = step + 1
                else:
                    res = dfs(new_s, new_c, new_dir, step + 1)
                    if res is None:
                        return None
                    capture_step = res
                if capture_step > max_capture:
                    max_capture = capture_step
            return max_capture
        else:
            new_c, new_dir = move_controller(c_pos, current_dir)
            possible_s = [s for s in range(1, n + 1) if s != new_c]
            any_escape = False
            max_capture = -1
            for s in possible_s:
                res = dfs(s, new_c, new_dir, step + 1)
                if res is None:
                    any_escape = True
                else:
                    if res > max_capture:
                        max_capture = res
            if any_escape:
                return None
            else:
                return max_capture

    result = dfs(m, k, c_dir, 0)
    if result is None:
        print("Stowaway")
    else:
        print(f"Controller {result}")

if __name__ == "__main__":
    main()
```

- **Stowaway Movement**: The stowaway's moves depend on the train's state, with optimal choices to avoid capture.
- **Recursive DFS with Memoization**: The DFS explores all possible moves, using memoization to store results of previously computed states for efficiency. This ensures the solution handles up to the maximum constraints efficiently.

This approach ensures that the stowaway's optimal strategy is simulated accurately, determining the winner based on the earliest possible capture or successful escape.
