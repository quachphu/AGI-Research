To solve this problem, we need to find the maximum flow in a given flow network from a specified source to a sink. The solution uses Dinic's algorithm, which efficiently computes the maximum flow in a network by leveraging BFS for level graph construction and DFS with current edge pointers for blocking flow computation.

### Approach
1. **Graph Representation**: The graph is represented using an adjacency list where each edge maintains its capacity, reverse edge reference, and target node.
2. **BFS for Level Assignment**: This step constructs a level graph using BFS, where each node's level is the shortest path distance from the source, considering only edges with positive residual capacity.
3. **DFS for Blocking Flow**: Using the level graph, DFS is employed to find blocking flows (paths where each node is at the next level). This step uses pointers to avoid reprocessing edges and efficiently augments the flow.
4. **Iterative Process**: Repeat BFS and DFS steps until no more augmenting paths exist. The sum of all augmenting flows gives the maximum flow.

### Solution Code
```python
import sys
from collections import deque

def main():
    n, m = map(int, sys.stdin.readline().split())
    graph = [[] for _ in range(n)]
    for _ in range(m):
        u, v, c = map(int, sys.stdin.readline().split())
        rev_u = len(graph[v])
        rev_v = len(graph[u])
        graph[u].append([v, rev_u, c])
        graph[v].append([u, rev_v, 0])
    
    source = 0
    sink = n - 1

    def bfs():
        level = [-1] * n
        q = deque()
        q.append(source)
        level[source] = 0
        while q:
            u = q.popleft()
            for edge in graph[u]:
                v, rev, cap = edge
                if cap > 0 and level[v] == -1:
                    level[v] = level[u] + 1
                    q.append(v)
        return level

    def dfs(u, flow, level, ptr):
        if u == sink:
            return flow
        while ptr[u] < len(graph[u]):
            edge = graph[u][ptr[u]]
            v, rev, cap = edge
            if cap > 0 and level[u] + 1 == level[v]:
                min_flow = min(flow, cap)
                res = dfs(v, min_flow, level, ptr)
                if res > 0:
                    graph[u][ptr[u]][2] -= res
                    graph[v][rev][2] += res
                    return res
                ptr[u] += 1
            else:
                ptr[u] += 1
        return 0

    total = 0
    while True:
        level = bfs()
        if level[sink] == -1:
            break
        ptr = [0] * n
        while True:
            pushed = dfs(source, float('inf'), level, ptr)
            if pushed == 0:
                break
            total += pushed
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Graph Construction**: The input is read and the graph is constructed using adjacency lists. Each edge and its reverse edge (with zero initial capacity) are added to facilitate residual capacity updates.
2. **BFS Level Assignment**: BFS determines the shortest path levels from the source, ensuring that subsequent DFS operations follow paths with increasing node levels.
3. **DFS Blocking Flow**: DFS uses the level graph to find paths from source to sink, pushing the maximum possible flow through each path and adjusting residual capacities. Pointers optimize edge processing by avoiding redundant checks.
4. **Iterative Flow Augmentation**: The process repeats until BFS can no longer reach the sink, indicating no more augmenting paths exist. The accumulated flow from all successful augmentations gives the maximum flow.

This approach efficiently handles the problem constraints, ensuring optimal performance using Dinic's algorithm.
