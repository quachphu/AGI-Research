To solve this problem, we need to determine if Polycarp can watch all his TV shows using only two TVs, ensuring that no two shows on the same TV overlap, even if they start immediately after another show ends.

### Approach
1. **Sort the Shows**: First, we sort the shows by their start time. If two shows have the same start time, we sort them by their end time. This helps in processing the shows in a sequential manner and ensures that we handle overlapping intervals correctly.
2. **Greedy Assignment**: Using a greedy approach, we check each show in the sorted list and try to assign it to one of the two TVs. For each show, if it can be placed on the first TV (i.e., its start time is after the end time of the last show on the first TV), we assign it there. If not, we check the second TV. If neither TV is available, it's impossible to watch all shows, and we return "NO".

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    shows = []
    idx = 1
    for _ in range(n):
        l = int(input[idx])
        r = int(input[idx + 1])
        shows.append((l, r))
        idx += 2
    shows.sort()
    last1 = -1
    last2 = -1
    for l, r in shows:
        if l > last1:
            last1 = r
        elif l > last2:
            last2 = r
        else:
            print("NO")
            return
    print("YES")

solve()
```

### Explanation
1. **Reading Input**: The input is read and parsed into a list of tuples representing the start and end times of each show.
2. **Sorting**: The list of shows is sorted by start time and then by end time to ensure we process the earliest starting shows first and handle overlaps correctly.
3. **TV Assignment**: We maintain two variables, `last1` and `last2`, to track the end times of the last show assigned to each TV. For each show, we check if it can fit into either TV based on its start time relative to the end time of the last show on each TV. If it fits, we update the respective TV's end time. If it doesn't fit either, we immediately return "NO".
4. **Output**: If all shows are successfully assigned to the TVs, we print "YES".

This approach ensures that we efficiently check each show in a sorted order and greedily assign them to the earliest available TV, leading to an optimal solution with a time complexity of O(n log n) due to sorting.
