To solve this problem, we need to determine if a given decimal number has an even or odd number of 1's in its binary representation. The solution involves converting each number to its binary form and counting the number of 1's, then checking the parity of that count.

### Approach
1. **Read Input**: The first line of input contains the number of test cases, T. Each subsequent line contains a decimal number, N.
2. **Convert to Binary**: For each number N, convert it to its binary representation using Python's built-in `bin()` function, which returns a string prefixed with '0b'. We strip this prefix to get the binary digits.
3. **Count 1's**: Count the number of 1's in the binary string using the `count('1')` method.
4. **Check Parity**: Determine if the count of 1's is even or odd. If even, print "even"; otherwise, print "odd".

### Solution Code
```python
import sys

def check_parity():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline().strip())
        count = bin(n).count('1')
        print('even' if count % 2 == 0 else 'odd')

check_parity()
```

### Explanation
- **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency, especially given the constraints.
- **Binary Conversion**: The `bin()` function converts each number to a binary string. We use slicing `[2:]` to remove the '0b' prefix.
- **Counting 1's**: The `count('1')` method efficiently counts the occurrences of '1' in the binary string.
- **Parity Check**: Using a modulo operation, we check if the count of 1's is even or odd and print the corresponding result.

This approach ensures that each number is processed in linear time relative to the number of bits, making the solution efficient and suitable for the given constraints.
