To solve this problem, we need to determine if a given string can be transformed into the string "2020" by removing at most one contiguous substring. The solution involves checking all possible ways to split "2020" into a prefix and suffix and verifying if the given string can start with the prefix and end with the suffix after removing a substring.

### Approach
1. **Direct Match Check**: If the input string is exactly "2020", the answer is immediately "YES".
2. **Prefix-Suffix Check**: For each possible split of "2020" into a prefix and suffix (with lengths ranging from 0 to 4), check if the input string starts with the prefix and ends with the suffix. If such a split exists, the answer is "YES"; otherwise, it is "NO".

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    if s == "2020":
        print("YES")
        continue
    found = False
    target = "2020"
    for a in range(5):
        prefix = target[:a]
        suffix = target[a:]
        if s.startswith(prefix) and s.endswith(suffix):
            found = True
            break
    print("YES" if found else "NO")
```

### Explanation
1. **Reading Input**: The code reads the number of test cases and processes each case individually.
2. **Direct Match Check**: If the input string is exactly "2020", it immediately prints "YES".
3. **Prefix-Suffix Check**: For each possible split of "2020" into a prefix and suffix (from 0 to 4 characters), the code checks if the input string starts with the prefix and ends with the suffix. If such a split is found, it prints "YES"; otherwise, after checking all splits, it prints "NO".

This approach efficiently checks all possible ways to form "2020" by removing a single contiguous substring, ensuring the solution is both optimal and easy to understand.
