To solve this problem, we need to determine the minimum cost of a route that allows Mr. X to reach home within a specified time limit. If no such route exists, we should output "TLE".

### Approach
1. **Input Reading**: Read the number of routes (N) and the maximum allowed time (T).
2. **Filter Valid Routes**: For each route, check if its travel time is within the allowed limit (T). Collect the costs of these valid routes.
3. **Determine Minimum Cost**: If there are valid routes, find the minimum cost among them. If there are no valid routes, output "TLE".

### Solution Code
```python
n, T = map(int, input().split())
costs = []
for _ in range(n):
    c, t = map(int, input().split())
    if t <= T:
        costs.append(c)
print(min(costs) if costs else 'TLE')
```

### Explanation
1. **Reading Input**: The first line of input contains two integers, N (number of routes) and T (maximum allowed time). The subsequent N lines each contain two integers representing the cost and time of each route.
2. **Filtering Valid Routes**: We iterate through each route, checking if its time is within the allowed limit (T). If it is, we add its cost to a list of valid costs.
3. **Finding Minimum Cost**: After processing all routes, if there are valid costs, we print the minimum value from this list. If there are no valid costs, we print "TLE".

This approach efficiently filters and processes the routes in linear time, ensuring that we only consider valid routes and determine the minimum cost correctly.
