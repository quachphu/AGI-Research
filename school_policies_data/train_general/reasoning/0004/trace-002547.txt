To solve this problem, we need to determine the maximum number of haybales that can be moved to the first pile after a given number of days, considering that each haybale move from a distant pile to the first pile takes a number of days equal to the distance between the piles.

### Approach
1. **Input Reading**: Read the number of test cases. For each test case, read the number of piles and the number of days available. Then read the initial number of haybales in each pile.
2. **Greedy Strategy**: Process each pile starting from the one closest to the first pile (pile 1). The reason is that moving haybales from closer piles takes fewer days, allowing us to maximize the number of haybales moved.
3. **Calculate Maximum Movable Haybales**: For each pile, determine the maximum number of haybales that can be moved to the first pile given the remaining days. This is calculated as the minimum of the haybales available in the current pile and the remaining days divided by the distance (days required per haybale).
4. **Update Remaining Days**: After moving haybales from a pile, update the remaining days and continue to the next pile until there are no days left or all piles have been processed.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, d = map(int, input().split())
    a = list(map(int, input().split()))
    current = a[0]
    days_left = d
    for i in range(1, n):
        distance = i
        max_take = min(a[i], days_left // distance)
        current += max_take
        days_left -= max_take * distance
        if days_left <= 0:
            break
    print(current)
```

### Explanation
1. **Reading Input**: The input consists of multiple test cases. For each test case, we read the number of piles `n`, the number of days `d`, and the initial haybales in each pile.
2. **Initialization**: Start with the initial number of haybales in the first pile.
3. **Iterate Over Piles**: For each subsequent pile (from the second pile onwards), calculate the maximum number of haybales that can be moved to the first pile. This is determined by the distance from the pile to the first pile and the remaining days.
4. **Update and Check Days**: After moving haybales from each pile, update the remaining days. If there are no days left, break out of the loop early to avoid unnecessary calculations.
5. **Output Result**: After processing all relevant piles, print the maximum number of haybales in the first pile for each test case.

This approach ensures that we optimally use the available days by prioritizing closer piles first, thus maximizing the number of haybales moved to the first pile efficiently.
