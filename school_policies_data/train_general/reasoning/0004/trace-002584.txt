To solve this problem, we need to compare two very large positive integers, potentially up to 10^100 in magnitude. Given their size, we cannot rely on standard integer comparison methods and must instead compare their string representations directly.

### Approach
1. **Input Handling**: Read the two numbers as strings to handle their large size without conversion issues.
2. **Length Comparison**: First, compare the lengths of the two strings. A longer string indicates a larger number.
3. **Digit-by-Digit Comparison**: If the strings are of the same length, compare each corresponding digit from left to right. The first differing digit determines the result.
4. **Result Determination**: Based on the comparisons, output "GREATER", "LESS", or "EQUAL".

### Solution Code
```python
def compare_large_numbers():
    A = input().strip()
    B = input().strip()
    
    if len(A) > len(B):
        print("GREATER")
    elif len(A) < len(B):
        print("LESS")
    else:
        for a, b in zip(A, B):
            if a > b:
                print("GREATER")
                return
            elif a < b:
                print("LESS")
                return
        print("EQUAL")

compare_large_numbers()
```

### Explanation
1. **Reading Input**: The numbers are read as strings to avoid any issues related to their large size.
2. **Length Check**: The lengths of the strings are compared first. If they differ, the longer string is immediately identified as the larger number.
3. **Character Comparison**: When the lengths are the same, each digit (character) is compared from left to right. The first pair of digits that differ determines the result.
4. **Efficient Exit**: The function exits as soon as a difference is found, ensuring efficient comparison without unnecessary checks.

This approach ensures that we handle extremely large numbers efficiently and correctly by leveraging string operations, which are well-suited for this problem's constraints.
