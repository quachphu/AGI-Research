To solve this problem, we need to determine the minimal number of packets Anmol needs to take to ensure he has at least M gems. The approach involves sorting the packets in descending order and checking the cumulative sum to find the smallest number of packets that meet or exceed the required number of gems.

### Approach
1. **Input Reading**: Read the number of test cases. For each test case, read the values of N (number of packets) and M (required gems), followed by the list of packets.
2. **Sorting**: Sort the packets in descending order to prioritize larger packets, which helps in minimizing the number of packets needed.
3. **Cumulative Sum Check**: Iterate through the sorted list, maintaining a cumulative sum. Check at each step if the cumulative sum meets or exceeds M. The first occurrence where this condition is met gives the minimal number of packets required. If no cumulative sum meets the requirement, return -1.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n, m = map(int, sys.stdin.readline().split())
        p = list(map(int, sys.stdin.readline().split()))
        p.sort(reverse=True)
        total = 0
        result = -1
        for i in range(n):
            total += p[i]
            if total >= m:
                result = i + 1
                break
        print(result)

if __name__ == "__main__":
    main()
```

### Explanation
- **Sorting**: By sorting the packets in descending order, we ensure that we first consider the largest possible values, which helps in reaching the required sum with fewer packets.
- **Cumulative Sum Check**: Starting from the largest packet, we keep adding the next largest packet until the cumulative sum is at least M. The index at which this condition is met plus one (to convert from 0-based to 1-based index) gives the minimal number of packets needed.
- **Efficiency**: Sorting the list takes O(N log N) time, and checking the cumulative sum takes O(N) time, making the solution efficient even for the upper constraint of N = 7 and T = 5000.

This approach ensures that we efficiently determine the minimal number of packets required using a greedy strategy, leveraging sorting and cumulative sum checks.
