To solve this problem, we need to determine the maximum number of elements in an array that can be made equal by adjusting each element by +1, -1, or leaving it unchanged. The optimal approach involves analyzing the frequency of possible values after these adjustments.

### Approach
1. **Frequency Array**: Create a frequency array to count the occurrences of each integer in the input array.
2. **Range of Values**: Consider all possible values (X) that any adjusted element can take. These values range from -1 to 100000 (inclusive) because each element can be adjusted to its value ±1.
3. **Sum of Frequencies**: For each possible value X, compute the sum of frequencies of X-1, X, and X+1. This sum represents the number of elements that can be adjusted to X.
4. **Maximize Count**: Track the maximum sum obtained from the above step to determine the optimal solution.

### Solution Code
```python
import sys

def main():
    N = int(sys.stdin.readline())
    a_list = list(map(int, sys.stdin.readline().split()))
    max_a = 10**5 - 1  # 99999
    freq = [0] * (max_a + 1)  # indexes 0 to 99999
    for a in a_list:
        freq[a] += 1
    
    max_count = 0
    # X ranges from -1 to 100000 inclusive
    for X in range(-1, 10**5 + 1):
        current = 0
        # Check X-1
        if (X - 1) >= 0 and (X - 1) <= max_a:
            current += freq[X - 1]
        # Check X
        if X >= 0 and X <= max_a:
            current += freq[X]
        # Check X+1
        if (X + 1) >= 0 and (X + 1) <= max_a:
            current += freq[X + 1]
        if current > max_count:
            max_count = current
    print(max_count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Frequency Array**: The frequency array `freq` is used to count how many times each integer appears in the input array. This helps in efficiently determining how many elements can be adjusted to a specific value.
2. **Range of X**: The possible values of X are from -1 to 100000. This covers all possible adjustments of each element in the input array.
3. **Sum Calculation**: For each X, the sum of frequencies of X-1, X, and X+1 is calculated. This sum gives the count of elements that can be adjusted to X.
4. **Maximization**: By iterating over all possible values of X and keeping track of the maximum sum, we determine the optimal solution efficiently.

This approach ensures that we efficiently compute the maximum possible count of elements that can be adjusted to the same value using a frequency array and linear iteration over possible values, resulting in a time complexity of O(N + 10^5), which is feasible for the given constraints.
