To solve this problem, we need to determine how many numbers in the Nth row of Pascal's Triangle are not divisible by a given prime number M. The solution leverages mathematical insights from number theory, specifically Lucas' Theorem, to efficiently compute the result without generating the entire row of binomial coefficients.

### Approach
1. **Understanding Pascal's Triangle**: The Nth row of Pascal's Triangle contains N+1 elements, each of which is a binomial coefficient C(N, k) for k ranging from 0 to N.
2. **Lucas' Theorem**: This theorem helps determine if a binomial coefficient C(N, k) is divisible by a prime number M. According to the theorem, if any digit in the base-M representation of k is greater than the corresponding digit in the base-M representation of N, then C(N, k) is divisible by M.
3. **Base Conversion**: Convert the integer N into its base-M representation. For each digit in this representation, compute the product of (digit + 1). This product gives the count of numbers in the Nth row that are not divisible by M.

### Solution Code
```python
def count_non_divisible():
    import sys
    n, m = map(int, sys.stdin.readline().split())
    product = 1
    while n > 0:
        digit = n % m
        product *= (digit + 1)
        n = n // m
    print(product)

count_non_divisible()
```

### Explanation
1. **Reading Input**: The input values N and M are read from standard input.
2. **Base-M Conversion**: The number N is repeatedly divided by M, and the remainders (digits in base-M) are collected. Each digit is used to update the product by multiplying (digit + 1).
3. **Product Calculation**: The product of (digit + 1) for all digits in the base-M representation of N gives the count of numbers in the Nth row of Pascal's Triangle that are not divisible by M. This is because each digit in the base-M representation of N allows for (digit + 1) valid digits in k (from 0 to digit) that ensure non-divisibility by M.

This approach efficiently computes the result in O(log_M N) time, making it suitable for large values of N up to 10,000,000.
