To solve this problem, we need to determine the minimum number of character changes required in a string to ensure it contains at least `k` distinct characters. If it's impossible to achieve this, we should return "impossible".

### Approach
1. **Check for Impossibility**: 
   - If `k` exceeds the length of the string, it's impossible because each character in the string can contribute at most one unique character.
   - If `k` exceeds 26, it's impossible because there are only 26 lowercase Latin letters.

2. **Count Distinct Characters**:
   - Calculate the number of distinct characters already present in the string. Let's call this count `m`.

3. **Determine Changes**:
   - If the current number of distinct characters `m` is already greater than or equal to `k`, no changes are needed.
   - If `m` is less than `k`, the minimum number of changes required is `k - m`, provided the string length is sufficient.

### Solution Code
```python
s = input().strip()
k = int(input())

distinct = len(set(s))
str_length = len(s)

if k > 26 or k > str_length:
    print("impossible")
else:
    if distinct >= k:
        print(0)
    else:
        print(k - distinct)
```

### Explanation
1. **Impossibility Checks**:
   - If `k` is greater than 26 or the length of the string, print "impossible" since these conditions make it unachievable.

2. **Distinct Character Count**:
   - Using `set(s)` gives the unique characters in the string, and `len(set(s))` gives the count of these unique characters.

3. **Calculate Changes**:
   - If the number of distinct characters is already sufficient, no changes are needed.
   - Otherwise, the number of changes required is the difference between `k` and the current number of distinct characters, as each change can introduce a new distinct character.

This approach efficiently determines the minimum changes needed using set operations and simple arithmetic checks, ensuring optimal performance even for the upper constraint limits.
