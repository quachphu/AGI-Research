To solve this problem, we need to find the longest possible path in a ski resort where Valera can start at a mountain and follow ski tracks to a hotel. The path must be as long as possible and meet specific conditions regarding the types of objects and the structure of the ski tracks.

### Approach
1. **Understand the Structure**: The ski resort is represented as a graph where each node (object) can have at most one incoming track. Hotels cannot have outgoing tracks, so any valid path must end at a hotel.
2. **Track Predecessors**: Each object has a predecessor given by the input array. We need to determine the number of outgoing tracks (out-degree) for each node.
3. **Trace Paths from Hotels**: For each hotel, trace back through its predecessors to form the longest possible path. This path must consist of mountains with exactly one outgoing track each, leading to the next node in the path.
4. **Check Conditions**: Ensure each node in the path (except the hotel) is a mountain and has exactly one outgoing track.

### Solution Code
```python
n = int(input())
types = list(map(int, input().split()))
a = list(map(int, input().split()))

out_degree = [0] * (n + 1)  # 1-based indexing

for j in range(n):
    ai = a[j]
    if ai != 0:
        out_degree[ai] += 1

max_length = 0
best_path = []

for i in range(1, n + 1):
    if types[i - 1] == 1:  # Check if it's a hotel
        path = []
        current = i
        path.append(current)
        current = a[current - 1] if current != 0 else 0
        
        while current != 0:
            if types[current - 1] != 0:  # current is a hotel, cannot be part of path
                break
            if out_degree[current] != 1:
                break
            path.append(current)
            current = a[current - 1]
        
        # Reverse to get the correct order
        reversed_path = path[::-1]
        if len(reversed_path) > max_length:
            max_length = len(reversed_path)
            best_path = reversed_path

print(max_length)
print(' '.join(map(str, best_path)))
```

3. **Path Tracing**: For each hotel, trace back through its predecessors to form a path. Ensure each node in the path is a mountain with exactly one outgoing track.
