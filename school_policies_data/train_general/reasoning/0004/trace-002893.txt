To solve this problem, we need to encrypt a given string using the Bytecryption algorithm. The algorithm processes the string step-by-step by removing characters from the middle based on the string's length (even or odd) and appending them to the result string until the original string is empty.

### Approach
1. **Process Each Test Case**: Read the number of test cases and each string to be encrypted.
2. **Determine String Length**: For each string, check if its length is odd or even.
3. **Handle Odd Length**: If the length is odd, remove the middle character and append it to the result.
4. **Handle Even Length**: If the length is even, compare the two middle characters, append the smaller one (or either if they are equal) to the result, and remove it from the string.
5. **Repeat Until Empty**: Continue the process until the string is empty, building the encrypted result step-by-step.

### Solution Code
```python
def bytecrypt(s):
    k = []
    s_list = list(s)
    while s_list:
        n = len(s_list)
        if n % 2 == 1:
            mid = n // 2
            k.append(s_list[mid])
            del s_list[mid]
        else:
            mid_left = (n // 2) - 1
            mid_right = n // 2
            if s_list[mid_left] <= s_list[mid_right]:
                selected = mid_left
            else:
                selected = mid_right
            k.append(s_list[selected])
            del s_list[selected]
    return ''.join(k)

def main():
    import sys
    t = int(sys.stdin.readline())
    for _ in range(t):
        s = sys.stdin.readline().strip()
        print(bytecrypt(s))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The `main` function reads the number of test cases and each string from standard input.
2. **Bytecrypt Function**: This function processes each string by converting it into a list for easier manipulation.
3. **Odd Length Handling**: When the string length is odd, the middle character is removed and added to the result.
4. **Even Length Handling**: When the string length is even, the two middle characters are compared. The smaller one (or either if they are equal) is removed and added to the result.
5. **Building Result**: The process continues until the original string is empty, with each step appending the selected character to the result string, which is then returned as the encrypted output.

This approach efficiently processes each string in linear time relative to its length, ensuring the solution is optimal and meets the problem constraints.
