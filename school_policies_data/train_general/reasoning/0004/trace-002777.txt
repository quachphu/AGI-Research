To solve this problem, we need to count the number of wave subsequences in a given sequence. A wave subsequence alternates between increasing and decreasing values. The solution must efficiently handle sequences up to 100,000 elements long.

### Approach
1. **Dynamic Programming with Fenwick Trees**: We use two dynamic programming arrays, `up` and `down`, where `up[i]` represents the number of wave subsequences ending at index `i` with an increasing step, and `down[i]` represents those ending with a decreasing step.
2. **Coordinate Compression**: This helps reduce the range of values in the sequence, making it feasible to use Fenwick Trees for efficient range queries and updates.
3. **Efficient Range Queries**: Using Fenwick Trees, we efficiently compute the required sums and counts for elements smaller or larger than the current element, which allows us to update `up` and `down` arrays in linear time.

### Solution Code
```python
MOD = 10**9 + 7

class FenwickTree:
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (self.n + 1)  # 1-based indexing

    def update(self, idx, delta):
        while idx <= self.n:
            self.tree[idx] = (self.tree[idx] + delta) % MOD
            idx += idx & -idx

    def query(self, idx):
        res = 0
        while idx > 0:
            res = (res + self.tree[idx]) % MOD
            idx -= idx & -idx
        return res

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    A = list(map(int, input[ptr:ptr + N]))
    ptr += N

    # Coordinate compression
    sorted_unique = sorted(set(A))
    rank = {v: i + 1 for i, v in enumerate(sorted_unique)}  # 1-based
    max_rank = len(sorted_unique)

    # Initialize Fenwick Trees for counts and sums
    count_tree_down = FenwickTree(max_rank)
    sum_tree_down = FenwickTree(max_rank)
    count_tree_up = FenwickTree(max_rank)
    sum_tree_up = FenwickTree(max_rank)

    total = 0
    for num in A:
        r = rank[num]

        # Calculate up_j
        sum_dl = sum_tree_down.query(r - 1)
        count_l = count_tree_down.query(r - 1)
        up_j = (sum_dl + count_l) % MOD

        # Calculate down_j
        sum_ug = (sum_tree_up.query(max_rank) - sum_tree_up.query(r)) % MOD
        count_g = count_tree_up.query(max_rank) - count_tree_up.query(r)
        down_j = (sum_ug + count_g) % MOD

        # Update total
        total = (total + up_j + down_j) % MOD

        # Update Fenwick Trees
        count_tree_down.update(r, 1)
        sum_tree_down.update(r, down_j)

        count_tree_up.update(r, 1)
        sum_tree_up.update(r, up_j)

    print(total % MOD)

if __name__ == '__main__':
    main()
```

1. **Coordinate Compression**: Convert the sequence values into ranks to handle large value ranges efficiently.
2. **Fenwick Trees**: These are used to maintain counts and sums of `up` and `down` values dynamically. This allows efficient range queries and updates.
3. **Dynamic Programming**: For each element, compute the number of valid wave subsequences ending with an increasing (`up`) or decreasing (`down`) step using the values stored in the Fenwick Trees.
4. **Efficiency**: The algorithm processes each element in linear time with logarithmic time complexity for each query and update operation, resulting in an overall time complexity of O(N log N), which is suitable for large inputs up to 100,000 elements.
