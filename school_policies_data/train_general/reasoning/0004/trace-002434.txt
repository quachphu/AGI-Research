To solve this problem, we need to determine the number of ways a given positive integer \( n \) can be represented as the sum of at most four positive squares, considering that the order of addition does not matter. This problem leverages Lagrange's Four-Square Theorem, which states that every positive integer can be represented as the sum of at most four squares.

### Approach
1. **Single Term Check**: Check if \( n \) itself is a perfect square. If yes, it contributes one valid representation.
2. **Two Terms Check**: Iterate through possible values of \( a \) and check if the remaining value after subtracting \( a^2 \) from \( n \) is a perfect square and greater than or equal to \( a \).
3. **Three Terms Check**: Iterate through possible values of \( a \) and \( b \), then check if the remaining value after subtracting \( a^2 \) and \( b^2 \) from \( n \) is a perfect square and greater than or equal to \( b \).
4. **Four Terms Check**: Iterate through possible values of \( a \), \( b \), and \( c \), then check if the remaining value after subtracting \( a^2 \), \( b^2 \), and \( c^2 \) from \( n \) is a perfect square and greater than or equal to \( c \).

### Solution Code
```python
import math

def count_reps(n):
    count_1 = 0
    s = math.isqrt(n)
    if s * s == n:
        count_1 = 1

    count_2 = 0
    a_max = math.isqrt(n // 2)
    for a in range(1, a_max + 1):
        a_sq = a * a
        rem = n - a_sq
        if rem < a_sq:
            continue
        s_rem = math.isqrt(rem)
        if s_rem * s_rem == rem and s_rem >= a:
            count_2 += 1

    count_3 = 0
    a_max3 = math.isqrt(n // 3)
    for a in range(1, a_max3 + 1):
        a_sq = a * a
        rem_after_a = n - a_sq
        if rem_after_a < 0:
            continue
        max_b = math.isqrt(rem_after_a // 2)
        max_b = min(max_b, math.isqrt(rem_after_a))
        for b in range(a, max_b + 1):
            b_sq = b * b
            rem_after_ab = rem_after_a - b_sq
            if rem_after_ab < 0:
                continue
            s_c = math.isqrt(rem_after_ab)
            if s_c * s_c == rem_after_ab and s_c >= b:
                count_3 += 1

    count_4 = 0
    a_max4 = math.isqrt(n // 4)
    for a in range(1, a_max4 + 1):
        a_sq = a * a
        rem_after_a = n - a_sq
        if rem_after_a < 0:
            continue
        max_b_val = rem_after_a // 3
        max_b = math.isqrt(max_b_val)
        max_b = min(max_b, math.isqrt(rem_after_a))
        for b in range(a, max_b + 1):
            b_sq = b * b
            rem_after_ab = rem_after_a - b_sq
            if rem_after_ab < 0:
                continue
            max_c_val = rem_after_ab // 2
            max_c = math.isqrt(max_c_val)
            max_c = min(max_c, math.isqrt(rem_after_ab))
            for c in range(b, max_c + 1):
                c_sq = c * c
                rem_after_abc = rem_after_ab - c_sq
                if rem_after_abc < 0:
                    continue
                s_d = math.isqrt(rem_after_abc)
                if s_d * s_d == rem_after_abc and s_d >= c:
                    count_4 += 1

    return count_1 + count_2 + count_3 + count_4

def main():
    import sys
    for line in sys.stdin:
        n = int(line.strip())
        if n == 0:
            break
        print(count_reps(n))

if __name__ == "__main__":
    main()
```

3. **Three Terms Check**: Iterate \( a \) from 1 to \( \sqrt{n/3} \), \( b \) from \( a \) to \( \sqrt{(n - a^2)/2} \), and check if the remainder \( n - a^2 - b^2 \) is a perfect square.
