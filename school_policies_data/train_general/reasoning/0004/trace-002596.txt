### Approach
1. **Understanding the Jump Pattern**: Chef's jumps follow a repeating sequence of 1, 2, and 3. Each set of three jumps (1, 2, 3) forms a cycle where the total distance covered in each cycle is 6 (1+2+3). 
2. **Position Analysis**: After each cycle, Chef's position is a multiple of 6. Additionally, within each cycle, Chef can reach intermediate positions by stopping after the first or second jump of the cycle. These intermediate positions are 1 and 3 more than the starting position of the cycle (which is a multiple of 6).
3. **Modulo Operation Insight**: By analyzing the positions Chef can reach, we observe that any reachable position modulo 6 will result in 0, 1, or 3. If a position modulo 6 yields any other remainder, it is unreachable.

### Solution Code
```python
a = int(input())
if a == 0:
    print("yes")
else:
    remainder = a % 6
    if remainder in {0, 1, 3}:
        print("yes")
    else:
        print("no")
```

### Explanation
- **Input Handling**: The code reads the input value 'a'.
- **Special Case for 0**: Since Chef starts at point 0, if the input is 0, the answer is immediately "yes".
- **Modulo Check**: For any other value of 'a', we compute the remainder when 'a' is divided by 6. If this remainder is 0, 1, or 3, Chef can reach that point, otherwise he cannot. This check efficiently determines the reachability using the observed pattern in the jump sequence.
