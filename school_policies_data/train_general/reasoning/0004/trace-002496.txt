To solve this problem, we need to determine the minimum number of moves required to line up all sheep (represented by '*') in a given string such that there are no empty spaces between any sheep. Each move allows a sheep to move left or right by one cell if the target cell is empty.

### Approach
1. **Identify Sheep Positions**: Collect the positions of all sheep in the given string.
2. **Calculate Target Positions**: For each sheep, compute a value that represents the difference between its current position and its index in the list of sheep positions. This helps in determining the optimal target positions.
3. **Find Median**: The optimal target positions for the sheep are determined by the median of the computed values. The median minimizes the sum of absolute deviations, which is crucial for minimizing the total number of moves.
4. **Compute Moves**: Calculate the total number of moves required by summing the absolute differences between each computed value and the median.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline().strip())
        s = sys.stdin.readline().strip()
        positions = [i for i, char in enumerate(s) if char == '*']
        k = len(positions)
        if k <= 1:
            print(0)
            continue
        a = [positions[i] - i for i in range(k)]
        mid = k // 2
        median = a[mid]
        total = 0
        for num in a:
            total += abs(num - median)
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using standard input for efficiency, especially given the constraints.
2. **Sheep Positions**: We collect the indices of all sheep in the string. This helps in determining their current positions.
3. **Adjusting Positions**: For each sheep, we compute an adjusted position by subtracting the sheep's index in the list from its actual position. This adjustment helps in determining the optimal consecutive positions.
4. **Median Calculation**: The median of these adjusted positions is found to determine the optimal target positions. The median is chosen because it minimizes the sum of absolute deviations, which directly translates to the minimum number of moves.
5. **Total Moves Calculation**: The total number of moves is computed by summing the absolute differences between each adjusted position and the median. This gives the minimum number of moves required to line up all sheep consecutively.

This approach efficiently computes the result with a time complexity of O(n) per test case, making it suitable for large input sizes.
