To solve this problem, we need to find the sum of all multiples of 10 up to a given number \( N \) for multiple test cases efficiently. The solution should handle large values of \( N \) up to \( 10^9 \) without performance issues.

### Approach
The key insight is to recognize that the multiples of 10 form an arithmetic sequence. The sum of such a sequence can be computed using a mathematical formula to avoid iterating through each number, which would be inefficient for large values of \( N \).

1. **Identify the largest multiple of 10 less than or equal to \( N \)**:
   This can be calculated as \( \text{max\_multiple} = N // 10 \times 10 \).

2. **Determine the number of terms in the sequence**:
   The number of terms \( k \) is the largest multiple divided by 10, which simplifies to \( k = N // 10 \).

3. **Use the arithmetic series sum formula**:
   The sum of the first \( k \) terms of the sequence starting at 10 can be computed using the formula \( 5 \times k \times (k + 1) \). This formula is derived from the sum of the first \( k \) natural numbers multiplied by 10.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        N = int(input[i])
        k = N // 10
        total = 5 * k * (k + 1)
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints. The first value is the number of test cases \( T \).
2. **Processing Each Test Case**: For each test case, the value \( N \) is read. The largest multiple of 10 up to \( N \) is determined using integer division.
3. **Sum Calculation**: Using the derived formula, the sum is calculated in constant time \( O(1) \), ensuring efficiency even for the upper constraint of \( N = 10^9 \).
4. **Output**: The result for each test case is printed immediately.

This approach ensures that the solution is both time-efficient and easy to understand, leveraging mathematical properties to avoid unnecessary iterations.
