To solve this problem, we need to determine the minimum distance between two closest occurrences of the minimum value in an array. The solution involves identifying the positions of the minimum values and then computing the smallest distance between consecutive positions.

### Approach
1. **Identify the Minimum Value**: First, find the minimum value in the given array.
2. **Collect Indices of Minimum Values**: Traverse the array to collect all indices where the minimum value occurs.
3. **Compute Minimum Distance**: Iterate through the collected indices and compute the distance between each consecutive pair of indices. The smallest of these distances is the answer.

### Solution Code
```python
n = int(input())
arr = list(map(int, input().split()))
min_val = min(arr)
indices = [i for i, x in enumerate(arr) if x == min_val]
min_dist = min(indices[i+1] - indices[i] for i in range(len(indices)-1))
print(min_dist)
```

### Explanation
1. **Reading Input**: The first line of input is the size of the array `n`, and the second line contains the array elements.
2. **Finding Minimum Value**: The minimum value of the array is determined using the `min` function.
3. **Collecting Indices**: Using a list comprehension, we gather all indices where the array elements equal the minimum value.
4. **Calculating Distances**: By iterating through the collected indices, we compute the difference between each consecutive pair of indices. The minimum of these differences is the result, which is printed as the output.

This approach efficiently processes the array in linear time, making it suitable for large input sizes up to 100,000 elements. The solution ensures that we only traverse the array once to collect indices and once more to compute distances, resulting in an overall time complexity of O(n).
