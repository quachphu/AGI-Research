### Approach
1. **Simulate Binary Search**: Simulate the binary search process to track the positions that influence the search path. These positions will be divided into two sets: those that must be less than or equal to `x` and those that must be greater than `x`.
2. **Factorial Precomputation**: Precompute factorials and their modular inverses up to the maximum value of `n` (1000) to efficiently compute combinations and permutations.
3. **Combinatorial Calculations**: Use the results from the binary search simulation to compute the number of valid permutations by considering the constraints on the elements in the permutation.

### Solution Code
```python
MOD = 10**9 + 7

n, x, pos = map(int, input().split())

max_fact = 1000
fact = [1] * (max_fact + 1)
for i in range(1, max_fact + 1):
    fact[i] = fact[i-1] * i % MOD

# Simulate the binary search steps to find L and G
left = 0
right = n
less_positions = set()
greater_positions = set()

while left < right:
    mid = (left + right) // 2
    if mid < pos:
        less_positions.add(mid)
        left = mid + 1
    elif mid > pos:
        greater_positions.add(mid)
        right = mid
    else:
        left = mid + 1

L = len(less_positions)
G = len(greater_positions)

# Check if there are enough numbers for the required positions
if (x - 1 < L) or (n - x < G):
    print(0)
else:
    remaining = (n - 1) - L - G
    numerator = fact[x-1] * fact[n - x] % MOD
    numerator = numerator * fact[remaining] % MOD
    denominator = fact[x-1 - L] * fact[n - x - G] % MOD
    inv_denominator = pow(denominator, MOD - 2, MOD)
    result = numerator * inv_denominator % MOD
    print(result)
```
