### Approach
1. **Bitwise Sum Without Carry**: For each bit in `a` and `b`, compute the sum without carrying over. This sum can result in values 0, 1, or 2.
2. **Collapsing Consecutive Duplicates**: After forming the sum array `c`, we collapse consecutive duplicates to form `d`.
3. **Greedy Selection**: For each position, choose the highest possible value for `c` such that it does not create consecutive duplicates in `d`. This ensures that the resulting `d` is lexicographically the largest possible.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    b = input().strip()
    a = []
    prev = None
    for i in range(n):
        bi = int(b[i])
        possible = [bi, bi + 1]
        possible_sorted = sorted(list(set(possible)), reverse=True)
        chosen = None
        for c in possible_sorted:
            if prev is None or c != prev:
                chosen = c
                break
        if chosen is None:
            chosen = max(possible_sorted)
        a_i = chosen - bi
        a.append(str(a_i))
        if prev != chosen:
            prev = chosen
    print(''.join(a))
```

### Explanation
1. **Reading Input**: The input consists of multiple test cases. For each test case, we read the length `n` and the binary string `b`.
2. **Possible Values Calculation**: For each bit in `b`, determine the possible values of the sum `c` which can be either `bi` or `bi + 1` (where `bi` is the current bit of `b`).
3. **Greedy Selection**: For each bit position, select the highest possible value for `c` that does not match the previous value in `d` to avoid consecutive duplicates. If all possible values are the same as the previous value, choose the highest possible value.
4. **Constructing `a`**: Convert the chosen value of `c` back to the corresponding bit in `a` by subtracting `bi` and append it to the result.
