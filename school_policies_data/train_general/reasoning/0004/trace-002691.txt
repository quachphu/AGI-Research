To solve this problem, we need to determine the minimum number of atoms required to partition a set of integers such that each atom is either entirely contained within each given subset or completely disjoint from it. 

### Approach
The key insight is that each element can be represented by a binary vector indicating its presence or absence in each of the given subsets. Elements with identical binary vectors can be grouped into the same atom, as they share the same membership characteristics across all subsets. Thus, the minimum number of atoms required is equivalent to the number of distinct binary vectors formed by the elements.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    subsets = []
    for _ in range(m):
        parts = list(map(int, input().split()))
        s = set(parts[1:])
        subsets.append(s)
    vectors = set()
    for x in range(n):
        vec = tuple(1 if x in s else 0 for s in subsets)
        vectors.add(vec)
    print(len(vectors))
```

### Explanation
1. **Input Reading**: The input consists of multiple test cases. For each test case, we first read the size of the set `n` and the number of subsets `m`.
2. **Subset Storage**: Each subset is read and stored as a set for efficient membership checking.
3. **Binary Vector Creation**: For each element in the set `X` (from 0 to n-1), we create a binary vector where each bit indicates the presence (1) or absence (0) of the element in the corresponding subset.
4. **Unique Vectors Count**: By collecting all unique binary vectors in a set, the size of this set gives the number of distinct atoms needed, which is the solution for the test case.

This approach efficiently determines the minimum number of atoms by leveraging the properties of binary vectors, ensuring optimal performance given the problem constraints.
