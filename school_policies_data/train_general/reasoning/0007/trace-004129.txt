To solve this problem, we need to determine the minimum cost to transform a given set of alphabet blocks into a configuration that can be rearranged into a palindrome. The allowed operations are adding, deleting, or changing a block, each with a cost of 1.

### Approach
1. **Character Frequency Analysis**: First, count the frequency of each character in the input string. This helps determine how many characters have odd frequencies, which is crucial for forming a palindrome.
2. **Odd Frequency Count**: For a string to be rearranged into a palindrome, it must meet one of two conditions: all characters have even counts (for even-length palindromes) or exactly one character has an odd count (for odd-length palindromes).
3. **Cost Calculation**: Calculate the minimum cost for both possible target configurations (0 or 1 odd frequency counts) by considering the number of changes, additions, or deletions required. Adjust the total cost to ensure the resulting string length matches the required parity (even or odd).

### Solution Code
```python
s = input().strip()
from collections import Counter

counts = Counter(s)
current_odd = sum(1 for v in counts.values() if v % 2 != 0)
initial_parity = len(s) % 2

min_cost = float('inf')

for m in [0, 1]:
    if current_odd >= m:
        steps_changes = (current_odd - m) // 2
        steps_adds_deletes = (current_odd - m) % 2
    else:
        steps_changes = 0
        steps_adds_deletes = (m - current_odd)
    
    cost = steps_changes + steps_adds_deletes
    new_parity = (initial_parity + steps_adds_deletes) % 2
    required_parity = m % 2
    
    if new_parity != required_parity:
        cost += 1
    
    if cost < min_cost:
        min_cost = cost

print(min_cost)
```

### Explanation
1. **Character Frequency Count**: Using `Counter` from the `collections` module, we count the occurrences of each character in the input string.
2. **Current Odd Count**: Determine how many characters have odd frequencies.
3. **Initial Parity**: Check if the initial length of the string is even or odd.
4. **Cost Calculation for Each Target**: For each possible target configuration (0 or 1 odd frequencies), compute the number of changes and additions/deletions required. Adjust the cost to ensure the resulting string length has the correct parity (even for 0 odd frequencies, odd for 1 odd frequency).
5. **Result**: The minimum cost between the two target configurations is the answer.

This approach efficiently computes the minimal operations needed by leveraging character frequency analysis and parity checks, ensuring optimal performance even for the maximum input size.
