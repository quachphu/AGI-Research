To solve this problem, we need to determine the minimum length of the shorter side of an isosceles triangle with two sides on the coordinate axes that can cover all given points on a plane. The triangle's vertices are at (0,0), (a,0), and (0,a), where a is the length of the legs on the axes. The hypotenuse of the triangle is the line x + y = a, and a point (x, y) is covered by the triangle if x + y ≤ a.

### Approach
The key insight is that the minimum length of the shorter side of the triangle (a) is determined by the maximum sum of the x and y coordinates of any given point. This is because for a point (x_i, y_i) to be covered by the triangle, it must satisfy x_i + y_i ≤ a. Therefore, the smallest possible value of a that covers all points is the maximum value of x_i + y_i among all points.

### Solution Code
```python
n = int(input())
max_sum = 0
for _ in range(n):
    x, y = map(int, input().split())
    current_sum = x + y
    if current_sum > max_sum:
        max_sum = current_sum
print(max_sum)
```

### Explanation
1. **Reading Input**: The number of points `n` is read first.
2. **Initializing Maximum Sum**: A variable `max_sum` is initialized to keep track of the maximum sum of x and y coordinates encountered.
3. **Processing Each Point**: For each point, the sum of its x and y coordinates is computed. If this sum exceeds the current `max_sum`, the `max_sum` is updated.
4. **Output Result**: After processing all points, the `max_sum` is printed, which represents the minimum length of the shorter side of the triangle.

This approach efficiently computes the required value in O(n) time, which is optimal given the problem constraints.
