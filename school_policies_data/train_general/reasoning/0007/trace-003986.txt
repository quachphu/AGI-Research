To solve this problem, we need to determine the minimum cost for Misha to buy exactly `k` shovels from a shop, considering special offers that allow him to get some shovels for free if he buys a certain number in a single purchase. The solution involves dynamic programming and optimal use of the given offers.

### Approach
1. **Sort the Shovels by Cost**: Since the cheapest shovels are the most beneficial to get for free, we first sort the list of shovel costs in non-decreasing order and consider only the first `k` shovels.
2. **Precompute Best Offers**: For each possible number of shovels `x` that can be bought in a single purchase, determine the maximum number of free shovels `y` available through the offers. This helps in minimizing the cost for each group of shovels bought.
3. **Dynamic Programming (DP)**: Use a DP array where `dp[i]` represents the minimum cost to buy the first `i` shovels. For each `i`, consider all possible previous purchase sizes `x` and compute the cost using the best offer available for `x`.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    m = int(input[ptr])
    ptr += 1
    k = int(input[ptr])
    ptr += 1

    a = list(map(int, input[ptr:ptr + n]))
    ptr += n

    a.sort()
    a = a[:k]

    prefix_sum = [0] * (k + 1)
    for i in range(k):
        prefix_sum[i + 1] = prefix_sum[i] + a[i]

    best_y = [0] * (k + 1)  # best_y[x] is the best y for x in 1..k

    for _ in range(m):
        xj = int(input[ptr])
        ptr += 1
        yj = int(input[ptr])
        ptr += 1
        if xj > k:
            continue
        if yj > best_y[xj]:
            best_y[xj] = yj

    INF = float('inf')
    dp = [INF] * (k + 1)
    dp[0] = 0

    for i in range(1, k + 1):
        for x in range(1, i + 1):
            y = best_y[x]
            start = i - x
            if start < 0:
                continue
            if start + y > i:
                continue  # not possible since y <= x, start + y <= (i - x) + x = i
            cost = dp[start] + (prefix_sum[i] - prefix_sum[start + y])
            if cost < dp[i]:
                dp[i] = cost

    print(dp[k])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Sorting and Trimming**: The shovels are sorted to prioritize cheaper ones. Only the first `k` shovels are considered since they are the cheapest and optimal to buy.
2. **Prefix Sum Array**: This array helps in quickly calculating the sum of any subarray of shovels, which is essential for determining the cost of each group purchase.
3. **Best Offers Precomputation**: For each possible group size `x`, we determine the maximum number of free shovels `y` using the given offers. This allows us to efficiently compute the minimum cost for each group size.
4. **Dynamic Programming**: The DP array is filled by considering all possible previous group sizes and their corresponding costs. This ensures that we find the optimal way to split the purchases to minimize the total cost.

This approach efficiently combines sorting, prefix sums, and dynamic programming to solve the problem within the constraints, ensuring optimal performance even for large input sizes.
