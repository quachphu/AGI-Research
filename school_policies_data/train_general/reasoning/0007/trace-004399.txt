To solve this problem, we need to determine the Kth character in the sorted decompressed string derived from a given compressed string. The decompressed string can be extremely large (up to 10^18 characters), so direct decompression is impractical. Instead, we use a more efficient approach by leveraging cumulative sums and binary search.

### Approach
1. **Parse the Compressed String**: Convert the compressed string into a list of character-count pairs. Each character in the compressed string is followed by a number indicating its frequency.
2. **Aggregate Frequencies**: Sum the counts for each character to get the total occurrences in the decompressed string.
3. **Sort Characters**: Sort the characters alphabetically to determine their order in the decompressed string.
4. **Compute Prefix Sums**: Calculate cumulative sums of the counts for the sorted characters. This helps in quickly determining the range of indices each character occupies in the decompressed string.
5. **Handle Queries Efficiently**: For each query, use binary search on the prefix sums to find the character that contains the Kth position in the decompressed string.

### Solution Code
```python
import sys
import re
import bisect

def main():
    compressed = sys.stdin.readline().strip()
    q = int(sys.stdin.readline())
    
    # Parse the compressed string into character and count pairs
    parts = re.findall(r'([a-z])(\d+)', compressed)
    freq = {}
    for char, num_str in parts:
        count = int(num_str)
        if char in freq:
            freq[char] += count
        else:
            freq[char] = count
    
    # Sort the characters and compute prefix sums
    sorted_chars = sorted(freq.keys())
    prefix = []
    total = 0
    for char in sorted_chars:
        total += freq[char]
        prefix.append(total)
    
    # Process each query
    for _ in range(q):
        k = int(sys.stdin.readline())
        if k > total:
            print(-1)
        else:
            idx = bisect.bisect_left(prefix, k)
            print(sorted_chars[idx])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Parsing the Compressed String**: The regular expression `r'([a-z])(\d+)'` matches each character followed by its numeric count, efficiently extracting these pairs from the input string.
2. **Aggregating Frequencies**: Using a dictionary, we sum the counts for each character to handle cases where the same character appears multiple times in the compressed string.
3. **Sorting Characters**: Characters are sorted alphabetically to determine their order in the decompressed string.
4. **Prefix Sums Calculation**: Cumulative sums of character counts allow us to determine the range of indices each character occupies in the decompressed string. This enables efficient range checks using binary search.
5. **Binary Search for Queries**: For each query, binary search (via `bisect_left`) quickly locates the character whose range includes the queried index, ensuring efficient handling of up to 100,000 queries.

This approach ensures that we efficiently handle the constraints without decompressing the entire string, making the solution both time and space efficient.
