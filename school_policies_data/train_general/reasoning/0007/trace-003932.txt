To solve this problem, we need to reconstruct a permutation of integers from 1 to n based on the given differences between consecutive elements. The key challenge is to ensure that the resulting permutation is valid, i.e., it contains each number from 1 to n exactly once.

### Approach
1. **Understand the Problem**: We are given an array `q` of length `n-1` where each element `q[i]` represents the difference between consecutive elements in the permutation `p`. Our task is to reconstruct `p` such that it forms a valid permutation of integers from 1 to n.

2. **Cumulative Sum Array**: Compute a cumulative sum array `s` where `s[i]` is the sum of the first `i` elements of `q`. This helps in expressing each element of the permutation `p` in terms of the first element `p1`.

3. **Determine p1**: Calculate the first element `p1` of the permutation using the formula derived from the sum of the first `n` natural numbers. This ensures that the sum of the permutation elements matches the required sum.

4. **Check Validity**: Verify that all elements of the permutation are within the range [1, n] and are unique. This ensures the permutation is valid.

### Solution Code
```python
def restore_permutation():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    q = list(map(int, input[1:n]))
    
    s = [0] * n
    current_sum = 0
    for i in range(1, n):
        current_sum += q[i-1]
        s[i] = current_sum
    
    sum_s = sum(s)
    required_sum = n * (n + 1) // 2
    total = required_sum - sum_s
    
    if total % n != 0:
        print(-1)
        return
    
    p1 = total // n
    p = [p1 + x for x in s]
    
    # Check validity
    valid = True
    seen = set()
    for num in p:
        if num < 1 or num > n:
            valid = False
            break
        if num in seen:
            valid = False
            break
        seen.add(num)
    
    if valid:
        print(' '.join(map(str, p)))
    else:
        print(-1)

restore_permutation()
```

### Explanation
1. **Reading Input**: The input is read from standard input, which includes the integer `n` and the array `q`.

2. **Cumulative Sum Array**: The array `s` is constructed where each element `s[i]` (for i >= 1) is the cumulative sum of the first `i-1` elements of `q`. This helps in expressing each element of the permutation `p` as `p1 + s[i]`.

3. **Calculate p1**: The first element `p1` is determined using the formula derived from the sum of the first `n` natural numbers. This ensures that the sum of the permutation elements matches the required sum.

4. **Construct Permutation**: The permutation `p` is constructed by adding `p1` to each element of the cumulative sum array `s`.

5. **Validity Check**: The constructed permutation is checked to ensure all elements are within the range [1, n] and are unique. If valid, the permutation is printed; otherwise, `-1` is printed.

This approach efficiently constructs and verifies the permutation in linear time, making it suitable for large values of `n` up to 200,000.
