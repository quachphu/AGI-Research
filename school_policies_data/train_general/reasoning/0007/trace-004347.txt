To solve this problem, we need to find the length of the longest balanced substring in a given string consisting of characters '0' and '1'. A balanced substring has an equal number of '0's and '1's. 

### Approach
The key insight to efficiently solve this problem is to use a prefix sum technique combined with a hash map to track the first occurrence of each prefix sum. Here's the detailed approach:

1. **Convert Characters to Values**: Treat '0' as -1 and '1' as +1. This allows us to convert the problem of finding a balanced substring into finding a subarray with a sum of zero.
2. **Prefix Sum Array**: Compute the running sum of the converted values. If the same sum is encountered at two different indices, the subarray between these indices has a sum of zero, indicating a balanced substring.
3. **Hash Map for First Occurrence**: Use a hash map to store the first occurrence of each prefix sum. This helps in efficiently determining the maximum length of subarrays with zero sum.

### Solution Code
```python
def main():
    import sys
    n = int(sys.stdin.readline())
    s = sys.stdin.readline().strip()
    sum_map = {0: -1}
    current_sum = 0
    max_len = 0
    for i in range(n):
        current_sum += 1 if s[i] == '1' else -1
        if current_sum in sum_map:
            candidate = i - sum_map[current_sum]
            if candidate > max_len:
                max_len = candidate
        else:
            sum_map[current_sum] = i
    print(max_len)

main()
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` and a string `s` of length `n`.
2. **Initialization**: We initialize a hash map `sum_map` with the initial entry `{0: -1}` to handle the prefix sum starting from index -1 (before the first element).
3. **Iterating Through the String**: For each character in the string, we update the running sum (`current_sum`). If the sum has been seen before, we calculate the length of the subarray between the current index and the first occurrence of this sum, updating the maximum length if this subarray is longer.
4. **Updating Hash Map**: If the current sum is encountered for the first time, we store its index in the hash map to track its first occurrence.

This approach efficiently finds the longest balanced substring in linear time, O(n), making it suitable for large input sizes up to 100,000 characters.
