To solve this problem, we need to determine if it's possible to paint a fence such that there are no consecutive planks of the same color exceeding a given threshold. The planks are painted based on their divisibility by two integers, and overlapping multiples can be colored either color. The solution involves analyzing the maximum possible consecutive same-colored planks and ensuring they do not exceed the threshold.

### Approach
1. **Problem Analysis**:
   - Planes are painted based on divisibility by `r` (red) and `b` (blue).
   - Overlapping multiples (divisible by both) can be either color.
   - The goal is to avoid `k` consecutive same-colored planks in the ordered list of painted planks.

2. **Key Insight**:
   - The problem can be simplified by considering the greatest common divisor (GCD) of `r` and `b`. Dividing `r` and `b` by their GCD reduces the problem to coprime integers, simplifying the analysis.
   - For coprime integers, the maximum consecutive same-colored planks between overlapping points is determined by the formula `(max(r, b) - 1) // min(r, b)`.

3. **Algorithm**:
   - Compute the GCD of `r` and `b` and reduce `r` and `b` to coprime values.
   - Calculate the maximum possible consecutive planks using the formula and check against the threshold `k`.

### Solution Code
```python
import math

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        r = int(input[idx])
        b = int(input[idx+1])
        k = int(input[idx+2])
        idx += 3
        g = math.gcd(r, b)
        r_prime = r // g
        b_prime = b // g
        m = max(r_prime, b_prime)
        n = min(r_prime, b_prime)
        if m == n:
            max_streak = 1
        else:
            max_streak = (m + n - 2) // n
        if max_streak >= k:
            print("REBEL")
        else:
            print("OBEY")

if __name__ == "__main__":
    main()
```
