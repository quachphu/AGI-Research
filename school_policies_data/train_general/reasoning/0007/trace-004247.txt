To solve this problem, we need to determine if a given integer can be transformed into a palindrome by adding leading zeros. A number is considered quasi-palindromic if such a transformation is possible.

### Approach
1. **Understanding the Problem**: A quasi-palindromic number can have leading zeros added such that the resulting string is a palindrome. For example, the number 2010200 can become "002010200" by adding two leading zeros, which is a palindrome.
2. **Key Insight**: The number must end with trailing zeros that can be mirrored by adding leading zeros. The middle part of the number (after removing trailing zeros) must be a palindrome.
3. **Steps**:
   - Convert the input number to a string.
   - Determine the number of trailing zeros in the string.
   - For each possible count of trailing zeros (from 0 up to the total trailing zeros), check if the remaining part of the string (after removing those trailing zeros) is a palindrome.
   - If any such part is a palindrome, the number is quasi-palindromic.

### Solution Code
```python
x = input().strip()
m = len(x) - len(x.rstrip('0'))
for k in range(m + 1):
    candidate = x[:-k] if k != 0 else x
    if candidate == candidate[::-1]:
        print("YES")
        exit()
print("NO")
```

### Explanation
1. **Reading Input**: The input number is read as a string to handle leading zeros correctly.
2. **Trailing Zeros Calculation**: The number of trailing zeros is determined by comparing the length of the string with the length after stripping trailing zeros.
3. **Palindrome Check**: For each possible count of trailing zeros (from 0 to the total trailing zeros), the string is truncated by removing those zeros. The resulting substring is checked for being a palindrome.
4. **Output**: If any truncated substring is a palindrome, the answer is "YES". If none are palindromic, the answer is "NO".

This approach efficiently checks all possible ways to form a palindrome by adding leading zeros, ensuring correctness and optimal performance.
