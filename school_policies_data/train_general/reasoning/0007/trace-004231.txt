To solve this problem, we need to determine the minimal and maximal possible sums of an array under specific constraints. The array must have between `l` and `r` distinct elements, where each element is either 1 or an even number that can be repeatedly halved until reaching 1. 

### Approach
1. **Constraints Analysis**: The distinct elements in the array must form a sequence of powers of 2 starting from 1 (e.g., 1, 2, 4, 8, ...). This is because each even number must have its half present in the array, leading back to 1.
2. **Sum Calculation**:
   - **Minimal Sum**: Achieved by maximizing the count of the smallest elements (1s) and using the minimum required counts for larger elements.
   - **Maximal Sum**: Achieved by maximizing the count of the largest elements possible, given the constraints on distinct elements.
3. **Iterate Over Possible Distinct Counts**: For each possible number of distinct elements `k` between `l` and `r`, compute the minimal and maximal sums. Then, determine the overall minimum and maximum sums across all valid `k`.

### Solution Code
```python
def solve():
    import sys
    n, l, r = map(int, sys.stdin.readline().split())
    min_total = float('inf')
    max_total = -float('inf')
    for k in range(l, r + 1):
        sum_min = (n - k + 1) + (2**k - 2)
        sum_max = (2**k - 1) + (n - k) * (2**(k - 1))
        if sum_min < min_total:
            min_total = sum_min
        if sum_max > max_total:
            max_total = sum_max
    print(min_total, max_total)

solve()
```

### Explanation
1. **Reading Input**: The input consists of three integers `n`, `l`, and `r`.
2. **Iterating Over Possible Distinct Counts**: For each `k` from `l` to `r`:
   - **Minimal Sum Calculation**: The formula `(n - k + 1) + (2^k - 2)` ensures the smallest possible sum by using as many 1s as possible and the minimum required counts for each subsequent power of 2.
   - **Maximal Sum Calculation**: The formula `(2^k - 1) + (n - k) * (2^(k - 1))` ensures the largest possible sum by using the maximum possible counts of the largest elements while maintaining the required distinct elements.
3. **Updating Results**: Track the minimum and maximum sums across all valid `k` values and print the results.

This approach efficiently computes the required sums by leveraging the properties of geometric sequences and ensures correctness by considering all valid configurations of distinct elements within the given constraints.
