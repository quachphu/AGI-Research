To solve this problem, we need to find the sum of all "Lucky Numbers" up to a given number \( N \) for multiple test cases. A Lucky Number is defined as a number that contains exactly two set bits in its binary representation. Given the constraints, we need an efficient approach to handle very large values of \( N \) and a high number of test cases.

### Approach
1. **Understanding Lucky Numbers**: A Lucky Number can be represented as \( 2^i + 2^j \) where \( i > j \). This means we need to consider all pairs of distinct bits in the binary representation of numbers up to \( N \).

2. **Efficient Calculation**: Instead of generating each number and checking if it's a Lucky Number, we use mathematical properties to directly compute the sum. For each possible bit position \( i \) (starting from 1), we calculate how many valid pairs \( (i, j) \) exist such that \( 2^i + 2^j \leq N \).

3. **Bit Length Utilization**: Using the bit length of numbers helps in quickly determining the highest possible bit positions for valid pairs. This allows us to efficiently compute the maximum valid \( j \) for each \( i \).

4. **Modulo Operation**: Since the result can be very large, we use modulo \( 10^9 + 7 \) to keep the numbers manageable and prevent overflow.

### Solution Code
```python
import sys

MOD = 10**9 + 7

def solve():
    input = sys.stdin.read().split()
    T = int(input[0])
    cases = list(map(int, input[1:T+1]))
    for N in cases:
        if N < 3:
            print(0)
            continue
        max_i = (N - 1).bit_length() - 1
        total = 0
        for i in range(1, max_i + 1):
            power_i = 1 << i
            rem = N - power_i
            if rem < 1:
                continue
            max_j_val = (rem.bit_length() - 1)
            max_j = min(i - 1, max_j_val)
            if max_j < 0:
                continue
            count_j = max_j + 1
            # Calculate term1: power_i * count_j mod MOD
            term1 = (power_i % MOD) * (count_j % MOD) % MOD
            total = (total + term1) % MOD
            # Calculate term2: (2^(max_j + 1) - 1) mod MOD
            exponent = max_j + 1
            pow2 = pow(2, exponent, MOD)
            term2 = (pow2 - 1) % MOD
            total = (total + term2) % MOD
        print(total % MOD)

if __name__ == "__main__":
    solve()
```
