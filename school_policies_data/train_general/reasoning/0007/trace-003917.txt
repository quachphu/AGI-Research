To solve this problem, we need to determine the greatest number of consecutive 1s in an n×n grid in any of the vertical, horizontal, or diagonal directions. The solution involves checking each possible line (row, column, and both diagonal directions) for consecutive 1s and keeping track of the maximum count found.

### Approach
1. **Reading Input:** The input consists of multiple datasets. Each dataset starts with an integer n, followed by n lines representing the grid. The input ends with a line containing 0.
2. **Check Rows:** For each row, traverse from left to right and count consecutive 1s.
3. **Check Columns:** For each column, traverse from top to bottom and count consecutive 1s.
4. **Check Diagonals (Down-Right):** Traverse all diagonals starting from the top row and the leftmost column moving down-right.
5. **Check Diagonals (Down-Left):** Traverse all diagonals starting from the top row and the rightmost column moving down-left.

### Solution Code
```python
def process_grid(n, grid):
    max_count = 0

    # Check rows
    for row in grid:
        current = 0
        for c in row:
            if c == '1':
                current += 1
                if current > max_count:
                    max_count = current
            else:
                current = 0

    # Check columns
    for j in range(n):
        current = 0
        for i in range(n):
            if grid[i][j] == '1':
                current += 1
                if current > max_count:
                    max_count = current
            else:
                current = 0

    # Check down-right diagonals starting from the first row
    for j_start in range(n):
        i = 0
        j = j_start
        current = 0
        while i < n and j < n:
            if grid[i][j] == '1':
                current += 1
                if current > max_count:
                    max_count = current
            else:
                current = 0
            i += 1
            j += 1

    # Check down-right diagonals starting from the first column (i starts from 1)
    for i_start in range(1, n):
        i = i_start
        j = 0
        current = 0
        while i < n and j < n:
            if grid[i][j] == '1':
                current += 1
                if current > max_count:
                    max_count = current
            else:
                current = 0
            i += 1
            j += 1

    # Check down-left diagonals starting from the first row
    for j_start in range(n):
        i = 0
        j = j_start
        current = 0
        while i < n and j >= 0:
            if grid[i][j] == '1':
                current += 1
                if current > max_count:
                    max_count = current
            else:
                current = 0
            i += 1
            j -= 1

    # Check down-left diagonals starting from the last column (i starts from 1)
    for i_start in range(1, n):
        i = i_start
        j = n - 1
        current = 0
        while i < n and j >= 0:
            if grid[i][j] == '1':
                current += 1
                if current > max_count:
                    max_count = current
            else:
                current = 0
            i += 1
            j -= 1

    return max_count


def main():
    import sys
    data = sys.stdin.read().split()
    ptr = 0
    while True:
        if ptr >= len(data):
            break
        n = int(data[ptr])
        ptr += 1
        if n == 0:
            break
        grid = []
        for _ in range(n):
            row = data[ptr]
            ptr += 1
            grid.append(row)
        print(process_grid(n, grid))


if __name__ == "__main__":
    main()
```

3. **Column Check:** Similar to the row check but iterates through each column.
4. **Diagonal Checks:** We check both down-right and down-left diagonals starting from each possible position on the top row and respective columns. This ensures all possible diagonal lines are covered.

This approach efficiently checks all possible lines in the grid, ensuring that the maximum consecutive 1s are found in O(n²) time complexity for each dataset.
