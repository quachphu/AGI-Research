To solve this problem, we need to compute the sum of the weights of all possible subsegments of a given array. The weight of a subsegment is defined as the number of unordered pairs (i, j) where i < j and the elements at these indices are equal. Given the constraints, a direct approach of iterating through all subsegments is infeasible, so we need an optimized solution.

### Approach
1. **Frequency Dictionary**: For each test case, create a frequency dictionary that maps each element to the list of indices where it occurs.
2. **Contribution Calculation**: For each element value that occurs at least twice, calculate the contribution of each pair of indices (i, j) where i < j. The contribution of each pair (i, j) is the number of subsegments that include both i and j, which is given by (i+1) * (n - j).
3. **Efficient Summation**: Instead of iterating through all pairs directly, use a prefix sum approach to efficiently compute the sum of contributions for all pairs in linear time relative to the number of occurrences of each element.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        a = list(map(int, input[ptr:ptr + n]))
        ptr += n
        freq = defaultdict(list)
        for idx, num in enumerate(a):
            freq[num].append(idx)
        total = 0
        for num in freq:
            indices = freq[num]
            m = len(indices)
            if m < 2:
                continue
            prefix = 0
            contribution = 0
            for j in range(1, m):
                prefix += indices[j-1] + 1
                current_xj = indices[j]
                contribution += prefix * (n - current_xj)
            total += contribution
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the large constraints.
2. **Frequency Dictionary Construction**: For each element in the array, track the indices where it occurs using a dictionary.
3. **Contribution Calculation**: For each element value with multiple occurrences, compute the contribution of each valid pair (i, j) using a prefix sum approach. This allows us to efficiently sum the contributions of all pairs in linear time relative to the number of occurrences of the element.
4. **Summing Contributions**: For each element's list of indices, compute the prefix sum of contributions and accumulate the total contribution for all valid pairs.

This approach ensures that we handle the problem efficiently within the given constraints, avoiding the need for nested loops over all possible subsegments.
