To solve this problem, we need to determine the minimum number of operations required to sort a permutation of integers from 1 to N. The allowed operation is moving an element to either the beginning or the end of the sequence. 

### Approach
The key insight is to find the longest consecutive increasing subsequence (LCIS) within the permutation. The elements in this subsequence are already in the correct order and do not need to be moved. The minimum number of operations required will be the total number of elements minus the length of this subsequence.

1. **Identify LCIS**: For each element in the permutation, track the length of the longest consecutive sequence ending at that element. This is done by checking the length of the sequence ending at the previous element (if it exists) and incrementing it by 1.
2. **Calculate Operations**: Subtract the length of the LCIS from the total number of elements to get the minimum number of moves required.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    p = [int(sys.stdin.readline()) for _ in range(n)]
    dp = [0] * (n + 2)  # To handle x up to n and x-1 up to n-1
    max_len = 0
    for x in p:
        dp[x] = dp[x - 1] + 1
        if dp[x] > max_len:
            max_len = dp[x]
    print(n - max_len)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline` for efficiency, especially with large input sizes.
2. **Tracking Consecutive Sequences**: An array `dp` is used where `dp[x]` stores the length of the longest consecutive sequence ending at `x`. For each element `x` in the permutation, `dp[x]` is updated based on the value of `dp[x-1]`.
3. **Determine Maximum Length**: While updating `dp`, we keep track of the maximum length of any consecutive sequence found.
4. **Calculate Result**: The result is derived by subtracting the maximum length of the consecutive sequence from the total number of elements, giving the minimum number of operations required.

This approach efficiently computes the result in O(N) time and O(N) space, making it suitable for the given constraints.
