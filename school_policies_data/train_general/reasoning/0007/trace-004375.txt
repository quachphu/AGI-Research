To solve this problem, we need to compute the sum of scores for each participant in a training contest where participants form teams in such a way that their combined score is minimized. The solution must efficiently handle up to 300,000 participants and 300,000 forbidden pairs.

### Approach
1. **Problem Analysis**:
   - Each team consists of two participants where each participant solves a different problem to minimize their combined score.
   - The score for a team (i, j) is `min(x_i + y_j, x_j + y_i)`.
   - We need to compute the sum of these minimized scores for each participant over all valid pairs, excluding forbidden pairs.

2. **Key Insight**:
   - The minimized score for a pair (i, j) depends on the difference `d_i = x_i - y_i` and `d_j = x_j - y_j`. If `d_i <= d_j`, the score is `x_i + y_j`, otherwise it's `x_j + y_i`.

3. **Efficient Calculation**:
   - Sort participants based on their `d` values to efficiently compute the contributions from all possible pairs using prefix and suffix sums.
   - Use binary search to determine the count of participants with `d` values greater than or equal to the current participant's `d` value.
   - Precompute prefix sums for the sorted `x` values and suffix sums for the sorted `y` values to quickly calculate the contributions from valid pairs.

4. **Handling Forbidden Pairs**:
   - After computing the initial sums for all pairs, adjust the sums by subtracting the contributions from each forbidden pair.

### Solution Code
```python
import bisect

n, m = map(int, input().split())

x = []
y = []
d_list = []
for _ in range(n):
    xi, yi = map(int, input().split())
    x.append(xi)
    y.append(yi)
    d_list.append(xi - yi)

sorted_list = sorted([(d_list[i], x[i], y[i], i) for i in range(n)], key=lambda elem: elem[0])
sorted_d = [elem[0] for elem in sorted_list]

pos_in_sorted = [0] * n
for idx in range(n):
    original_i = sorted_list[idx][3]
    pos_in_sorted[original_i] = idx

prefix_x = [0] * (n + 1)
for i in range(n):
    prefix_x[i + 1] = prefix_x[i] + sorted_list[i][1]

suffix_y = [0] * (n + 1)
for i in range(n - 1, -1, -1):
    suffix_y[i] = suffix_y[i + 1] + sorted_list[i][2]

sum_s = [0] * n
for i in range(n):
    d_i = d_list[i]
    pos = bisect.bisect_left(sorted_d, d_i)
    cnt_ge = n - pos
    sum_y_ge_excl_i = suffix_y[pos] - sorted_list[pos_in_sorted[i]][2]
    sum_x_lt = prefix_x[pos]
    s = x[i] * (cnt_ge - 1) + sum_y_ge_excl_i + sum_x_lt + y[i] * pos
    sum_s[i] = s

for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    du = d_list[u]
    dv = d_list[v]
    if du <= dv:
        s_uv = x[u] + y[v]
    else:
        s_uv = x[v] + y[u]
    sum_s[u] -= s_uv
    sum_s[v] -= s_uv

print(' '.join(map(str, sum_s)))
```
