To solve this problem, we need to determine if there exists a positive integer \( k \) such that \( x^k \) is divisible by \( m \). This can be checked by ensuring that all prime factors of \( m \) are present in \( x \).

### Approach
1. **Prime Factorization**: For each test case, factorize \( m \) into its prime factors.
2. **Check Prime Presence**: Verify if each prime factor of \( m \) is also a prime factor of \( x \). If any prime factor of \( m \) is not present in \( x \), the answer is "NO".
3. **Special Case for m=1**: If \( m \) is 1, it trivially divides any number, so the answer is "YES".

### Solution Code
```python
def prime_factors(n):
    factors = set()
    if n % 2 == 0:
        factors.add(2)
        while n % 2 == 0:
            n //= 2
    i = 3
    while i * i <= n:
        if n % i == 0:
            factors.add(i)
            while n % i == 0:
                n //= i
        i += 2
    if n > 1:
        factors.add(n)
    return factors

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        x = int(input[idx])
        m = int(input[idx + 1])
        idx += 2
        if m == 1:
            print("YES")
            continue
        factors = prime_factors(m)
        possible = True
        for p in factors:
            if x % p != 0:
                possible = False
                break
        print("YES" if possible else "NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prime Factorization**: The `prime_factors` function decomposes a number \( n \) into its prime factors using trial division. This is efficient for numbers up to \( 10^{13} \).
2. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
3. **Check Each Test Case**: For each test case, if \( m \) is 1, immediately print "YES". Otherwise, check if all prime factors of \( m \) divide \( x \). If they do, print "YES"; otherwise, print "NO".

This approach ensures that we efficiently check the necessary conditions using prime factorization and modular arithmetic, leading to an optimal solution for the given problem constraints.
