To solve this problem, we need to efficiently compute the sum of numbers from 1 to N, where each number is taken modulo a given value. Direct computation for large values of N is infeasible, so we use a mathematical approach to optimize the calculation.

### Approach
1. **Pattern Recognition**: The modulo operation results in a repeating cycle from 0 to MOD-1. Each complete cycle sums up to the sum of the first (MOD-1) natural numbers.
2. **Cycle Decomposition**: Decompose the problem into complete cycles and a partial cycle. For example, if MOD is 5, the sequence modulo 5 will repeat every 5 numbers.
3. **Sum Calculation**:
   - **Complete Cycles**: Calculate the sum of one complete cycle and multiply by the number of complete cycles.
   - **Partial Cycle**: Compute the sum of the remaining numbers after the last complete cycle.

### Solution Code
```python
def valentine_sum():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        N = int(input[idx])
        MOD = int(input[idx + 1])
        idx += 2
        if MOD == 1:
            print(0)
            continue
        q = N // MOD
        r = N % MOD
        sum_cycles = q * (MOD * (MOD - 1) // 2)
        sum_remain = r * (r + 1) // 2
        total = sum_cycles + sum_remain
        print(total)

valentine_sum()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Handling Each Test Case**: For each test case, we read N and MOD.
3. **Special Case Handling**: If MOD is 1, every number modulo 1 is 0, so the sum is 0.
4. **Cycle Calculation**:
   - **Complete Cycles**: The number of complete cycles is `N // MOD`. The sum of one complete cycle is `MOD * (MOD - 1) // 2`, which is the sum of the first (MOD-1) natural numbers.
   - **Partial Cycle**: The remaining numbers after the last complete cycle are `N % MOD`. The sum of these remaining numbers is `r * (r + 1) // 2`.
5. **Total Sum**: The total sum is the sum of all complete cycles plus the sum of the partial cycle.

This approach ensures that we handle very large values of N efficiently, reducing the time complexity from O(N) to O(1) per test case.
