### Approach
1. **Tree Representation**: Represent the hierarchy of soldiers as a tree where each node (soldier) has a parent (immediate superior).
2. **Depth Calculation**: Compute the depth of each node from the root (commander) using BFS.
3. **Binary Lifting**: Precompute a binary lifting table to efficiently find ancestors of nodes. This allows us to check if a soldier is a superior and determine the number of steps between nodes in logarithmic time.
4. **Query Processing**: For each query, check if the target soldier is a valid superior using the precomputed depth and binary lifting table. If valid, compute the number of steps (reviews) using depth differences.
