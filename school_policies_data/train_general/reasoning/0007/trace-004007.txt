To solve this problem, we need to determine if a class will be canceled based on the arrival times of students. The class is canceled if fewer than K students arrive on time (i.e., at or before the class starts).

### Approach
1. **Input Reading**: Read the number of test cases. For each test case, read the number of students (N) and the threshold (K). Then, read the arrival times of the students.
2. **Count On-Time Students**: For each test case, count how many students have non-positive arrival times (<= 0), as these students are considered on time.
3. **Decision Making**: Compare the count of on-time students with the threshold K. If the count is less than K, the class is canceled ("YES"); otherwise, it is not canceled ("NO").

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        K = int(input[ptr + 1])
        ptr += 2
        arrival_times = list(map(int, input[ptr:ptr + N]))
        ptr += N
        on_time = sum(1 for time in arrival_times if time <= 0)
        print("YES" if on_time < K else "NO")

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings for efficient processing. This approach helps in handling multiple test cases seamlessly.
2. **Processing Each Test Case**: For each test case, we extract N (number of students) and K (threshold). We then read the arrival times of these students.
3. **Counting On-Time Students**: Using a generator expression, we count how many students arrived on time (non-positive arrival times).
4. **Decision Making**: Based on the count of on-time students, we determine if the class is canceled by comparing the count with the threshold K. If the count is less than K, the class is canceled; otherwise, it is not.

This approach ensures that we efficiently process each test case and make the decision in linear time relative to the number of students, making it optimal for the given constraints.
