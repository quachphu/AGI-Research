To solve this problem, we need to determine which Infinity Gems are missing from Thanos' Infinity Gauntlet based on the colors of the gems present. Each gem has a unique color, and the goal is to identify the absent gems by their names using the given colors.

### Approach
1. **Mapping Colors to Gem Names**: Create a dictionary that maps each color to its corresponding gem name.
2. **Reading Input**: Read the number of gems present and their respective colors.
3. **Identifying Present Gems**: Use a set to collect the colors of the present gems.
4. **Determining Absent Gems**: Check each color in the predefined dictionary against the set of present colors. If a color is not present, add the corresponding gem name to the list of missing gems.
5. **Output the Result**: Print the count of missing gems followed by their names in any order.

### Solution Code
```python
def main():
    color_to_gem = {
        'purple': 'Power',
        'green': 'Time',
        'blue': 'Space',
        'orange': 'Soul',
        'red': 'Reality',
        'yellow': 'Mind'
    }

    n = int(input())
    present_colors = set()
    for _ in range(n):
        color = input().strip()
        present_colors.add(color)

    missing = []
    for color in color_to_gem:
        if color not in present_colors:
            missing.append(color_to_gem[color])

    print(len(missing))
    for name in missing:
        print(name)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Mapping Colors to Gems**: The dictionary `color_to_gem` is used to map each color to its respective gem name.
2. **Reading Input**: The input is read, starting with the number of gems, followed by their colors. These colors are stored in a set for quick lookup.
3. **Checking for Absent Gems**: For each color in the dictionary, we check if it is in the set of present colors. If not, the corresponding gem name is added to the list of missing gems.
4. **Output**: The number of missing gems is printed first, followed by their names. The order of names does not matter as per the problem statement.

This approach efficiently determines the missing gems using set operations for quick lookups and ensures the solution is both clear and concise.
