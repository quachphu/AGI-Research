To solve this problem, we need to determine the number of valid floor heights for a condominium such that the total height of the building is exactly H, with each floor's height adjustable within a given range [A, B]. Each floor must have the same height, and the number of floors must be an integer.

### Approach
1. **Understand the Problem Requirements**: We need to find all possible floor heights within the range [A, B] such that when the building is divided into these floor heights, the total height H is exactly achieved with an integer number of floors.
2. **Key Insight**: For a floor height h to be valid, H must be exactly divisible by h. This means H % h should be 0.
3. **Iterate Over the Range**: Check each integer h in the range [A, B] to see if H is divisible by h. Count how many such valid heights exist.

### Solution Code
```python
def main():
    import sys
    H, A, B = map(int, sys.stdin.readline().split())
    count = 0
    for h in range(A, B + 1):
        if H % h == 0:
            count += 1
    print(count)

main()
```

### Explanation
1. **Reading Input**: The input values H (total height), A (minimum floor height), and B (maximum floor height) are read from standard input.
2. **Initialize Count**: A counter is initialized to keep track of the number of valid floor heights.
3. **Check Each Height**: For each height h in the range from A to B (inclusive), check if H is divisible by h. If it is, increment the count.
4. **Output Result**: Print the total count of valid floor heights.

This approach efficiently checks each possible floor height within the given range, ensuring that the solution is both correct and optimal given the problem constraints. The time complexity is O(B - A + 1), which is efficient given the constraints.
