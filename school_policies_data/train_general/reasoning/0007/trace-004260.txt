To solve this problem, we need to determine the amount of rain each mountain received based on the water accumulated in the dams located between them. The problem is structured such that the solution can be derived using a systematic approach involving cyclic equations and alternating sums.

### Approach
1. **Understanding the Problem**: Each mountain contributes water to two adjacent dams. Given the accumulated water in each dam, we need to reverse-engineer the rain received by each mountain. The key insight is that the problem can be modeled using a system of linear equations with cyclic dependencies.

2. **Cyclic Equations**: For each dam, the sum of the contributions from the adjacent mountains equals twice the water accumulated in the dam. This forms a system of cyclic equations which can be solved efficiently due to the problem constraints (N is odd).

3. **Alternating Sum Calculation**: The unique solution for the cyclic system can be derived using an alternating sum of the accumulated water values. This sum helps in determining the rain received by the first mountain, which can then be used to compute the rain for subsequent mountains iteratively.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
sum_r1 = 0
for j in range(n):
    if j % 2 == 0:
        sum_r1 += a[j]
    else:
        sum_r1 -= a[j]
r = [0] * n
r[0] = sum_r1
for i in range(n - 1):
    r[i + 1] = 2 * a[i] - r[i]
print(' '.join(map(str, r)))
```

### Explanation
1. **Reading Input**: The input consists of the number of mountains (N) and the list of water accumulated in each dam (A).

2. **Alternating Sum Calculation**: We compute the sum of the accumulated water values with alternating signs. This sum gives the rain received by the first mountain (R₁).

3. **Iterative Calculation**: Using the value of R₁, we iteratively compute the rain received by each subsequent mountain. Each subsequent value is derived using the formula derived from the cyclic equations, ensuring that the solution satisfies all constraints.

This approach efficiently computes the solution in O(N) time, making it suitable for large input sizes up to 100,000 elements. The alternating sum ensures that we correctly handle the cyclic nature of the problem, leveraging the constraint that N is odd to guarantee a unique solution.
