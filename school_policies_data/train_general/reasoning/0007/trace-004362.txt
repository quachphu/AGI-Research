To solve this problem, we need to calculate the temperature at Mr. JOI's house (Spot N) after each tectonic movement. The temperature changes based on the altitude differences between consecutive spots. The challenge is to efficiently compute these temperature changes after each update, given the constraints of large input sizes.

### Approach
1. **Understanding Temperature Changes**: The temperature change between consecutive spots depends on whether the altitude increases or decreases. If moving to a higher altitude (A[i] < A[i+1]), the temperature decreases by S degrees per unit altitude. Otherwise, it increases by T degrees per unit altitude.

2. **Efficient Updates**: Instead of recalculating the entire temperature from scratch after each update, we track the effect of each update on specific pairs of spots. Each update affects the altitude of a range of spots, which in turn affects the temperature change between adjacent spots in a predictable manner.

3. **Delta Contributions**: Each update affects the altitude differences (D[i] = A[i+1] - A[i]) for pairs of spots at the boundaries of the update range. Specifically, updating altitudes from L to R affects the pairs (L-1, L) and (R, R+1). This allows us to compute the temperature change efficiently by only considering these boundary pairs.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    N, Q, S, T = map(int, input[ptr:ptr+4])
    ptr += 4
    
    A = []
    for _ in range(N + 1):
        A.append(int(input[ptr]))
        ptr += 1
    
    # Compute initial D array
    D = [A[i+1] - A[i] for i in range(N)]
    
    # Calculate initial sum of contributions
    sum_contrib = 0
    for d in D:
        if d > 0:
            sum_contrib += -S * d
        else:
            sum_contrib += T * (-d)
    
    for _ in range(Q):
        L = int(input[ptr])
        R = int(input[ptr+1])
        X = int(input[ptr+2])
        ptr += 3
        
        # Process i = L-1
        i = L - 1
        if 0 <= i < N:
            old = -S * D[i] if D[i] > 0 else T * (-D[i])
            D[i] += X
            new = -S * D[i] if D[i] > 0 else T * (-D[i])
            sum_contrib += new - old
        
        # Process i = R
        i = R
        if i < N:
            old = -S * D[i] if D[i] > 0 else T * (-D[i])
            D[i] -= X
            new = -S * D[i] if D[i] > 0 else T * (-D[i])
            sum_contrib += new - old
        
        print(sum_contrib)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the large constraints. We parse the initial altitudes and the queries.

2. **Initial Setup**: We compute the initial altitude differences (D array) and the initial temperature sum based on these differences.

3. **Processing Queries**: For each query, we adjust the altitude differences at the boundaries of the affected range (L-1 and R). We update the temperature sum by computing the contribution changes for these boundary pairs, allowing us to efficiently maintain the current temperature without recalculating all pairs.

This approach ensures that each query is processed in constant time, making the solution efficient and scalable for large input sizes.
