To solve this problem, we need to convert all lowercase letters in a given text to uppercase while leaving other characters (such as spaces and periods) unchanged. The solution should read a line of text from standard input, process it, and print the converted text.

### Approach
The approach involves the following steps:
1. **Reading Input**: Read a single line of text from standard input.
2. **Converting to Uppercase**: Use Python's built-in string method `upper()` to convert all lowercase letters in the input string to uppercase. This method leaves non-alphabetic characters unchanged, which is exactly what we need.
3. **Output the Result**: Print the converted string.

The solution leverages Python's efficient string manipulation capabilities to achieve the desired result in a straightforward and concise manner.

### Solution Code
```python
def main():
    text = input()
    print(text.upper())

main()
```

### Explanation
- **Reading Input**: The `input()` function reads a line of text from standard input.
- **Converting to Uppercase**: The `upper()` method is called on the input string, converting all lowercase letters to uppercase. This method does not affect spaces, periods, or any other non-alphabetic characters.
- **Output the Result**: The converted string is printed using the `print()` function.

This approach ensures that the solution is both efficient and easy to understand, handling all specified input constraints and edge cases effectively.
