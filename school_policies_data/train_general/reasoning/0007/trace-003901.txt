To solve this problem, we need to determine how many silver coins Fafa needs to pay when moving through gates between two neighboring kingdoms separated by a wall along the line x=y. The payment is required only when Fafa moves from one kingdom to another through a gate.

### Approach
1. **Track Fafa's Position**: Start from the initial position (0, 0) and update his position based on each move in the sequence.
2. **Check for Gates**: After each move, check if Fafa's current position is on a gate (x == y).
3. **Determine Kingdom Transitions**: For each gate encountered, check if the move into the gate was from one kingdom and the move out of the gate is into the other kingdom. This involves checking the previous position (before the move) and the next position (after the next move).
4. **Count Payments**: Increment the count of silver coins whenever a valid transition through a gate (excluding the initial gate at (0, 0)) is detected.

### Solution Code
```python
n = int(input())
s = input().strip()

x, y = 0, 0
count = 0

for i in range(n):
    x_prev, y_prev = x, y
    move = s[i]
    if move == 'U':
        y += 1
    else:
        x += 1
    if x == y:
        if i == n - 1:
            continue
        # Check if previous position was also a gate
        if x_prev == y_prev:
            continue
        prev_k = 'first' if x_prev > y_prev else 'second'
        next_move = s[i+1]
        next_x = x + (1 if next_move == 'R' else 0)
        next_y = y + (1 if next_move == 'U' else 0)
        next_k = 'first' if next_x > next_y else 'second'
        if prev_k != next_k:
            # Check if it's not the initial gate (0,0)
            if x != 0 or y != 0:
                count += 1
```
