To solve this problem, we need to compute the sum of binomial coefficients from k=0 to P for each test case, where N is the size of the set and P is the upper limit of the subset size. The result should be printed modulo 1000000007.

### Approach
1. **Precompute Binomial Coefficients**: Using Pascal's Triangle, precompute all binomial coefficients C(n, k) for 0 ≤ n ≤ 1000 and 0 ≤ k ≤ n. This allows efficient lookup of values during test case processing.
2. **Precompute Prefix Sums**: For each n, compute the prefix sums of binomial coefficients up to each possible k. This allows us to quickly answer each query by summing up the required range of binomial coefficients in constant time.
3. **Efficient Query Handling**: For each test case, simply retrieve the precomputed prefix sum for the given N and P, ensuring the result is modulo 1000000007.

### Solution Code
```python
MOD = 10**9 + 7
max_n = 1000

# Precompute binomial coefficients using Pascal's triangle
comb = []
for n in range(max_n + 1):
    current = [0] * (n + 1)
    current[0] = 1
    if n >= 1:
        current[n] = 1
    for k in range(1, n):
        current[k] = (comb[n-1][k-1] + comb[n-1][k]) % MOD
    comb.append(current)

# Precompute prefix sums for each n
sum_prefix = []
for n in range(max_n + 1):
    prefix = []
    total = 0
    for k in range(n + 1):
        total = (total + comb[n][k]) % MOD
        prefix.append(total)
    sum_prefix.append(prefix)

# Read input and output results
import sys

def main():
    input = sys.stdin.read().split()
    idx = 0
    t = int(input[idx])
    idx += 1
    for _ in range(t):
        n = int(input[idx])
        p = int(input[idx + 1])
        idx += 2
        print(sum_prefix[n][p] % MOD)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precompute Binomial Coefficients**: The binomial coefficients are calculated using Pascal's Triangle, which builds each row based on the previous row. This ensures that each coefficient is computed in O(1) time per element, leading to an overall O(n^2) time complexity for precomputing all values up to n=1000.
2. **Prefix Sums**: For each n, we compute the cumulative sum of binomial coefficients from k=0 to k=n. This allows each query to be answered in O(1) time by directly accessing the precomputed sum.
3. **Efficiency**: The precomputation steps ensure that each test case is processed in constant time, making the solution efficient even for the upper constraint limits (T=1000 and N=1000).

This approach ensures that we handle up to 1000 test cases efficiently by leveraging precomputation and prefix sums, providing quick answers to each query.
