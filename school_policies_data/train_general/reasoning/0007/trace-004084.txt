To solve this problem, we need to determine the maximum length of a k-beautiful necklace that can be assembled from a given set of beads. A k-beautiful necklace remains unchanged when rotated clockwise by k positions.

### Approach
1. **Understanding k-beautiful Necklace**: A necklace of length m is k-beautiful if rotating it by k positions (mod m) leaves it unchanged. This implies that the necklace can be partitioned into cycles where each cycle's beads must be identical.
2. **Cycle Analysis**: For a necklace of length m, the number of cycles is given by the greatest common divisor (gcd) of m and k (mod m). Each cycle's length is m divided by this gcd.
3. **Frequency Check**: For each possible length m (from n down to 1), we check if we can form cycles using the available bead counts. Each cycle requires a certain number of beads of the same color, determined by the cycle length.

### Solution Code
```python
import math

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    s = input().strip()
    counts = [0] * 26
    for c in s:
        counts[ord(c) - ord('a')] += 1
    counts_sorted = sorted(counts, reverse=True)
    max_m = 0
    for m in range(n, 0, -1):
        k_mod = k % m
        d = math.gcd(m, k_mod)
        L = m // d
        quotients = [cnt // L for cnt in counts_sorted]
        sum_top = sum(quotients[:d])
        if sum_top >= d:
            max_m = m
            break
    print(max_m)
```

### Explanation
1. **Input Reading**: Read the number of test cases. For each test case, read the values of n (number of beads), k (rotation steps), and the string of beads.
2. **Frequency Count**: Calculate the frequency of each bead in the string and sort these frequencies in descending order.
3. **Cycle Calculation**: For each possible necklace length m (from n down to 1):
   - Compute the effective rotation steps (k mod m).
   - Determine the number of cycles (gcd of m and k mod m) and the length of each cycle (m divided by the gcd).
   - Check if the available beads can form the required cycles by summing the top possible cycle contributions from the sorted frequencies.
4. **Result Determination**: The maximum valid length m found is printed as the result for each test case.

This approach efficiently checks each possible necklace length and uses mathematical properties to determine the feasibility of forming a k-beautiful necklace, ensuring optimal performance given the problem constraints.
