To solve this problem, we need to determine the number of foods that are liked by all people surveyed. This involves finding the intersection of all the sets of foods each person likes and counting the elements in this intersection.

### Approach
1. **Read Input**: The first line contains two integers, N (number of people) and M (number of foods). The subsequent N lines each contain a list of integers where the first integer is the count of foods liked by a person, followed by the indices of those foods.
2. **Store Likes as Sets**: For each person, store their liked foods in a set. Using a set allows efficient computation of intersections.
3. **Compute Intersection**: Start with the first person's set of liked foods and iteratively compute the intersection with each subsequent person's set. The result will be the set of foods liked by all people.
4. **Output Result**: The size of the resulting intersection set is the number of foods liked by everyone, which is our answer.

### Solution Code
```python
def main():
    import sys
    data = sys.stdin.read().splitlines()
    N, M = map(int, data[0].split())
    sets = []
    for line in data[1:N+1]:
        parts = list(map(int, line.split()))
        foods = parts[1:]
        sets.append(set(foods))
    if not sets:
        print(0)
        return
    common = sets[0]
    for s in sets[1:]:
        common &= s
    print(len(common))

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into lines for easier processing. The first line gives N and M.
2. **Processing Each Person's Likes**: For each subsequent line, we convert the list of liked foods into a set, which allows efficient intersection operations.
3. **Intersection Calculation**: We start with the first person's set of liked foods. For each subsequent person's set, we compute the intersection with the current common set. This progressively narrows down the common foods to those liked by all.
4. **Result**: The size of the final intersection set is printed, representing the number of foods liked by all surveyed people.

This approach efficiently handles the constraints and ensures that we correctly identify the common foods using set operations, which are optimal for this type of problem.
