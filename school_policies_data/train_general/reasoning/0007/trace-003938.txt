To solve this problem, we need to determine the minimum number of swaps required to make an array "good," where each element's parity (even or odd) matches the parity of its index. If it's not possible, we should return -1.

### Approach
1. **Check Feasibility**: For each test case, first check if the number of even elements in the array matches the number of even indices and the number of odd elements matches the number of odd indices. This is a necessary condition for the array to be transformed into a good array.
2. **Count Mismatches**: If the array can be transformed, count the number of even indices that contain odd elements. Each such mismatch can be resolved by swapping with an odd index that contains an even element. The number of such swaps required is equal to the number of mismatched elements in even indices.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    required_even = (n + 1) // 2
    count_even = sum(1 for num in a if num % 2 == 0)
    if count_even != required_even:
        print(-1)
    else:
        x = 0
        for i in range(n):
            if i % 2 == 0 and a[i] % 2 != 0:
                x += 1
        print(x)
```

### Explanation
1. **Feasibility Check**: The number of even elements in the array must exactly match the number of even indices (calculated as `(n + 1) // 2`). If this condition is not met, it is impossible to make the array good, and we return -1.
2. **Mismatch Counting**: If the feasibility condition is met, we count how many even indices contain odd elements. Each such mismatch can be paired with a corresponding mismatch in an odd index (containing an even element). Each pair of mismatches can be resolved with a single swap, so the total number of swaps needed is equal to the count of mismatched elements in even indices.

This approach efficiently determines the minimum number of swaps required, or identifies if it is impossible, using linear time complexity for each test case.
