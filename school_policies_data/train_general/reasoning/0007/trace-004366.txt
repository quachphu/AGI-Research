To solve this problem, we need to minimize the time required to scan all given papers using three scanners working in parallel. The goal is to distribute the papers among the three scanners such that the maximum time taken by any scanner is minimized.

### Approach
The problem can be approached using a dynamic programming (DP) technique. The key idea is to track all possible sums of times for the first two scanners and derive the sum for the third scanner based on the total sum of all papers. By iteratively considering each paper and updating possible sums for the first two scanners, we can efficiently determine the optimal distribution.

1. **Dynamic Programming Initialization**: Start with an initial state where both scanners have a sum of 0.
2. **Iterative Update**: For each paper, update the possible sums for the first two scanners by considering three scenarios: adding the current paper's time to the first scanner, the second scanner, or the third scanner.
3. **Track Minimum Maximum Time**: After processing all papers, compute the maximum time taken by any of the three scanners for each possible state and track the minimum of these maximum values.

### Solution Code
```python
n = int(input())
times = [int(input()) for _ in range(n)]

current_dp = {(0, 0)}
sum_prev = 0

for t in times:
    sum_prev += t
    new_dp = set()
    for (a, b) in current_dp:
        # Assign to scanner 1
        new_a = a + t
        new_b = b
        new_dp.add((new_a, new_b))
        # Assign to scanner 2
        new_a2 = a
        new_b2 = b + t
        new_dp.add((new_a2, new_b2))
        # Assign to scanner 3
        new_dp.add((a, b))
    current_dp = new_dp

sum_total = sum_prev
min_max = float('inf')

for a, b in current_dp:
    s3 = sum_total - a - b
    current_max = max(a, b, s3)
    if current_max < min_max:
        min_max = current_max

print(min_max)
```

### Explanation
1. **Reading Input**: The input consists of the number of papers and their respective scanning times.
2. **Dynamic Programming Set Initialization**: We start with a set containing the initial state (0, 0), representing the sums of the first two scanners.
3. **Processing Each Paper**: For each paper's scanning time, generate new possible sums for the first two scanners by adding the current time to either scanner or leaving them unchanged (implying the time is added to the third scanner).
4. **Tracking Possible States**: Use a set to track all unique possible sums for the first two scanners after each paper is processed.
5. **Calculating Minimum Maximum Time**: After processing all papers, compute the sum for the third scanner and determine the maximum time among all three scanners for each state. Track the minimum of these maximum values to get the optimal result.

This approach efficiently explores all possible distributions of scanning times using dynamic programming, ensuring we find the optimal solution within feasible computational limits.
