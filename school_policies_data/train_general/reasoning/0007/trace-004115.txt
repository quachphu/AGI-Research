To solve this problem, we need to filter out duplicate email subjects from multiple test cases while preserving the order of their first occurrence. Each test case consists of a list of subjects, and our goal is to return a list where each subject appears only once, in the order they first appeared.

### Approach
1. **Reading Input**: The first line of input contains an integer T, indicating the number of test cases. Each subsequent line represents a test case with subjects separated by spaces.
2. **Tracking Seen Subjects**: For each test case, we use a set to keep track of subjects that have already been encountered. This allows for efficient O(1) average-time complexity for membership checks.
3. **Building the Result List**: As we iterate through each subject in the test case, we add the subject to the result list if it has not been seen before and mark it in the set. If it has been seen, we skip it.
4. **Output the Result**: After processing all subjects in a test case, we join the result list into a space-separated string and print it.

### Solution Code
```python
def process_emails():
    import sys
    t = int(sys.stdin.readline())
    for _ in range(t):
        subjects = sys.stdin.readline().strip().split()
        seen = set()
        result = []
        for sub in subjects:
            if sub not in seen:
                seen.add(sub)
                result.append(sub)
        print(' '.join(result))

process_emails()
```

### Explanation
- **Reading Input Efficiently**: Using `sys.stdin.readline()` ensures that we read each line efficiently, which is crucial for handling large input sizes.
- **Set for Tracking**: The use of a set (`seen`) allows us to check if a subject has already been encountered in constant time, ensuring the solution is efficient even for large datasets.
- **Maintaining Order**: By iterating through the subjects and appending to the result list only when encountering a subject for the first time, we maintain the order of first occurrences as required.

This approach ensures that each test case is processed in linear time relative to the number of subjects, making the solution both efficient and scalable.
