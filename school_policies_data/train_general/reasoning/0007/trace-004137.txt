The conditions require that the number of blue ornaments is exactly one more than the yellow ones, and the number of red ornaments is exactly one more than the blue ones.

### Approach
1. **Understand the Constraints**: The problem requires that the number of blue ornaments (B) is exactly one more than the yellow ones (Y), and the number of red ornaments (R) is exactly one more than the blue ones. This translates to:
   - B = Y + 1
   - R = B + 1 = Y + 2

2. **Formulate the Problem**: Let the number of yellow ornaments used be \( x \). Then, blue ornaments used will be \( x + 1 \) and red ornaments used will be \( x + 2 \).

3. **Constraints on Available Ornaments**: We need to ensure that:
   - \( x \leq y \) (available yellow ornaments)
   - \( x + 1 \leq b \) (available blue ornaments)
   - \( x + 2 \leq r \) (available red ornaments)

4. **Determine Maximum x**: The maximum value of \( x \) that satisfies all constraints is the minimum of \( y \), \( b - 1 \), and \( r - 2 \). This is derived from the inequalities above.

5. **Calculate Total Ornaments**: Once \( x \) is determined, the total number of ornaments is \( 3x + 3 \).

### Solution Code
```python
def main():

```

- **Calculate Maximum x**: The maximum possible value of \( x \) is determined by taking the minimum of the available yellow ornaments, one less than the available blue ornaments, and two less than the available red ornaments. This ensures all constraints are satisfied.
- **Compute Total Ornaments**: Using the calculated \( x \), the total number of ornaments is computed as \( 3x + 3 \), which is the sum of \( x \) yellow, \( x + 1 \) blue, and \( x + 2 \) red ornaments.
