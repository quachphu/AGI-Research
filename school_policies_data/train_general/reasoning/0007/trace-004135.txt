class DSU:
    def __init__(self, size):
        self.parent = list(range(size+1))  # 1-based indexing
        self.rank = [1]*(size+1)
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return
        if self.rank[x_root] < self.rank[y_root]:
            self.parent[x_root] = y_root
        else:
            self.parent[y_root] = x_root
            if self.rank[x_root] == self.rank[y_root]:
                self.rank[x_root] +=1

                            low[u] = min(low[u], low[v])
                            if low[v] > disc[u]:
                                bridges.add(frozenset({u, v}))
                        else:  # back edge or forward edge
                            low[u] = min(low[u], disc[v])
                    continue
                if visited[u]:
                    continue
                visited[u] = True
                disc[u] = low[u] = time
                time +=1
                # Push u back with processed=True
                stack.append( (u, parent_u, True) )
                # Push children
                for v in adj[u]:
                    if v == parent_u:
                        continue
                    if not visited[v]:
                        stack.append( (v, u, False) )
                    else:
                        # back edge, update low[u]
                        low[u] = min(low[u], disc[v])
    return bridges

This code is based on the approach of processing nodes in two steps: first, discovering the node and pushing it back with a processed flag, then processing its children. Then, when the node is popped again with processed=True, the low values are updated based on children.

To solve this problem, we need to determine the maximum number of passages (edges) that can be guarded by bosses such that it is impossible to travel from a starting location `s` to an ending location `t` without passing through these passages. The key insight is that these passages are bridges in the graph, and the problem reduces to finding the longest path (diameter) in the bridge tree of the graph.

### Approach
1. **Identify Bridges**: Use Tarjan's algorithm to find all bridges in the graph. A bridge is an edge that, if removed, would increase the number of connected components.
2. **Construct 2-Edge-Connected Components**: Using a Disjoint Set Union (DSU), merge nodes connected by non-bridge edges to form 2-edge-connected components.
3. **Build Bridge Tree**: Each 2-edge-connected component becomes a node in the bridge tree, and bridges connect these nodes.
4. **Compute Diameter**: The maximum number of bridges (boss passages) is the diameter of the bridge tree, which can be found using two Breadth-First Searches (BFS).

4. **Diameter Calculation**: The diameter of the bridge tree, found using two BFS traversals, gives the longest path between any two nodes, representing the maximum number of bridges (boss passages) possible.
