To solve this problem, we need to determine the minimum number of seats required for a scenic railroad service under two different policies. Policy 1 allows passengers to choose any available seat when booking, while Policy 2 allows the railroad to optimally assign seats after all reservations are made. 

### Approach

**Policy 1 (Worst-case Scenario):**
1. **Problem Analysis:** The goal is to find the maximum number of seats required in the worst-case scenario where passengers choose seats in a way that maximizes seat usage. This is determined by the maximum number of overlapping intervals for any passenger's travel section.
2. **Algorithm:** For each passenger's interval, count how many other intervals overlap with it. The maximum count of overlapping intervals across all passengers gives the required number of seats.
3. **Efficiency:** Using sorting and binary search, we efficiently count overlaps for each interval in O(n log n) time.

**Policy 2 (Optimal Assignment):**
1. **Problem Analysis:** Here, we need to find the maximum number of passengers on the train at any point in time, which is the classic interval scheduling problem.
2. **Algorithm:** Use a timeline of events (start and end of intervals) to track the number of passengers on the train. The maximum value during this tracking gives the required number of seats.
3. **Efficiency:** Sorting events and processing them in linear time ensures O(n log n) complexity.

### Solution Code

```python
import bisect

n = int(input())
intervals = []
for _ in range(n):
    a, b = map(int, input().split())
    intervals.append((a, b))

# Calculate s1 for policy 1
sorted_a = sorted(a for a, b in intervals)
sorted_b = sorted(b for a, b in intervals)

max_s1 = 0
for a_i, b_i in intervals:
    x = bisect.bisect_left(sorted_a, b_i)
    y = bisect.bisect_right(sorted_b, a_i)
    current_count = x - y
    if current_count > max_s1:
        max_s1 = current_count
s1 = max_s1

# Calculate s2 for policy 2
events = []
for a, b in intervals:
    events.append((a, 1))
    events.append((b, -1))

# Sort events by position, end events come before start events at the same position
events.sort(key=lambda x: (x[0], x[1]))

current = 0
max_s2 = 0
for pos, typ in events:
    current += typ
    if typ == 1 and current > max_s2:
        max_s2 = current

s2 = max_s2

print(s1, s2)
```

### Explanation

**Policy 1:**
- **Sorting Intervals:** We sort intervals by their start and end times.
- **Binary Search:** For each interval, we use binary search to count how many intervals start before the current interval's end and end after the current interval's start. This gives the number of overlapping intervals.
- **Maximum Overlap:** The maximum overlap count across all intervals determines the required seats under Policy 1.

**Policy 2:**
- **Event Timeline:** We create events for the start and end of each interval and sort them. End events are processed before start events at the same time to avoid overlap.
- **Tracking Passengers:** By iterating through these events, we track the number of passengers on the train. The peak value during this iteration gives the required seats under Policy 2.

This approach efficiently handles up to 200,000 intervals, ensuring optimal performance and correctness for both policies.
