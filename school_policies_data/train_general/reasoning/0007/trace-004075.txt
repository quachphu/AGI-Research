To solve this problem, we need to determine the absolute difference between the count of even numbers and the count of odd numbers in a given sequence. The solution involves reading the input, processing the numbers, and then computing the required difference.

### Approach
1. **Reading Input**: The first line contains an integer representing the number of elements in the sequence. The second line contains the sequence of integers separated by spaces.
2. **Counting Even and Odd Numbers**: Iterate through each number in the sequence, checking if each number is even or odd. Increment the respective counters for even and odd numbers.
3. **Calculating Absolute Difference**: Compute the absolute difference between the count of even numbers and the count of odd numbers.
4. **Output the Result**: Print the computed absolute difference.

### Solution Code
```python
def main():
    n = int(input())
    numbers = list(map(int, input().split()))
    even = 0
    odd = 0
    for num in numbers:
        if num % 2 == 0:
            even += 1
        else:
            odd += 1
    print(abs(even - odd))

main()
```

### Explanation
1. **Reading Input**: The function reads the first line to get the number of elements `n`, then reads the second line to get the sequence of integers.
2. **Counting Even and Odd Numbers**: Initialize two counters, `even` and `odd`, both starting at zero. For each number in the sequence, check if it is even (using `num % 2 == 0`). If it is even, increment the `even` counter; otherwise, increment the `odd` counter.
3. **Calculating Absolute Difference**: After counting, compute the absolute difference using `abs(even - odd)` to ensure the result is non-negative.
4. **Output the Result**: Print the computed absolute difference.

This approach efficiently processes the input in linear time, O(n), where n is the number of elements in the sequence, making it optimal for large inputs.
