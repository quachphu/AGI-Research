To solve this problem, we need to determine the total number of stickers Karan will need to distribute to the attendees based on their entry order. The last person to enter the hall receives 1 sticker, the second last receives 2 stickers, and so on. This pattern continues until the first person, who receives N stickers where N is the number of attendees.

### Approach
The key observation here is that the total number of stickers required is the sum of the first N natural numbers. This sum can be efficiently calculated using the formula for the sum of an arithmetic series:
\[ \text{Sum} = \frac{N \times (N + 1)}{2} \]
This formula allows us to compute the result in constant time O(1) for each test case, making the solution very efficient even for large values of N.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        N = int(input[i])
        print(N * (N + 1) // 2)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The input is read all at once and split into a list of strings. The first element of this list is the number of test cases, T.
2. **Processing Each Test Case:** For each test case, we convert the input string to an integer N and compute the sum using the formula \( \frac{N \times (N + 1)}{2} \). We use integer division (//) to ensure the result is an integer.
3. **Output the Result:** The result for each test case is printed immediately after computation.

This approach ensures that we handle up to 10 test cases efficiently, even for the maximum constraint where N is \(10^8\), by leveraging the arithmetic series sum formula for constant time computation.
