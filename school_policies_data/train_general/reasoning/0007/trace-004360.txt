To solve this problem, we need to determine the result of a Tic-Tac-Toe game based on the given board configuration. The result can be a win for 'o', a win for 'x', or a draw if the board is full with no winner.

### Approach
1. **Input Reading**: Read multiple lines of input, each representing a 3x3 Tic-Tac-Toe board.
2. **Check Winning Conditions**: For each board, check if 'o' or 'x' has a winning line. A winning line can be a row, column, or diagonal where all three cells are occupied by the same player.
3. **Determine Result**: 
   - If 'o' wins, output 'o'.
   - If 'x' wins, output 'x'.
   - If neither wins, check if the board is full (no empty cells 's'). If it is full, output 'd' (draw).

### Solution Code
```python
import sys

def check_board(board):
    lines = [
        [0, 1, 2], [3, 4, 5], [6, 7, 8],  # Rows
        [0, 3, 6], [1, 4, 7], [2, 5, 8],  # Columns
        [0, 4, 8], [2, 4, 6]              # Diagonals
    ]
    
    o_win = any(all(board[i] == 'o' for i in line) for line in lines)
    x_win = any(all(board[i] == 'x' for i in line) for line in lines)
    
    if o_win:
        return 'o'
    elif x_win:
        return 'x'
    else:
        return 'd' if 's' not in board else 'd'

def main():
    for line in sys.stdin:
        line = line.strip()
        if len(line) == 9:
            print(check_board(line))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The `main` function reads each line from standard input, strips any extraneous whitespace, and processes it if it is exactly 9 characters long.
2. **Checking for Wins**: The `check_board` function uses predefined lines (rows, columns, diagonals) to check if either 'o' or 'x' has filled all three cells in any of these lines.
3. **Result Determination**: If 'o' or 'x' is found to have a winning line, the corresponding result is returned. If neither has a winning line, the function checks if the board is full (no 's' remaining) and returns 'd' for a draw.

This approach efficiently checks all possible winning conditions and handles valid input as specified, ensuring correct results for each game state.
