To solve this problem, we need to decompress a string that has been compressed using a specific rule. The compressed string uses '@' followed by a count and a character to represent consecutive occurrences of that character. Our task is to restore the original string by expanding these compressed sequences.

### Approach
1. **Input Reading**: Read multiple lines of input strings.
2. **Iterate Through Each Line**: For each line, process each character sequentially.
3. **Handle Compression Markers**: When encountering an '@', the next two characters represent the count (a single digit) and the character to be repeated. Expand this sequence into the corresponding repeated characters.
4. **Construct Result**: Build the result string by either expanding the compressed sequences or directly appending other characters.

### Solution Code
```python
def decompress():
    import sys
    for line in sys.stdin:
        line = line.strip()
        result = []
        i = 0
        while i < len(line):
            if line[i] == '@' and i + 2 < len(line):
                count = int(line[i+1])
                char = line[i+2]
                result.append(char * count)
                i += 3
            else:
                result.append(line[i])
                i += 1
        print(''.join(result))
        
decompress()
```

### Explanation
1. **Reading Input**: The function reads each line from the standard input.
2. **Processing Each Character**: For each character in the line, check if it is an '@'. If it is, the next two characters are the count (as a digit) and the character to repeat. Append the repeated character to the result list and skip ahead by three positions (to move past the '@', count, and character).
3. **Handling Normal Characters**: If the current character is not an '@', simply append it to the result list and move to the next character.
4. **Output the Result**: After processing all characters in the line, join the result list into a string and print it.

This approach ensures that we efficiently decompress the string by expanding each '@' sequence correctly, while maintaining the order and structure of the original uncompressed string.
