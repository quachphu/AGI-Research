To solve this problem, we need to determine the maximum number of cookies Apollinaria can bake using her ingredients and a magic powder. The solution involves using binary search to efficiently find the maximum number of cookies that can be baked given the constraints.

### Approach
1. **Problem Analysis**: Each cookie requires a specific amount of each ingredient. Apollinaria has a certain amount of each ingredient and can use a magic powder to make up for any deficiencies. The goal is to maximize the number of cookies baked.

2. **Binary Search**: The number of cookies that can be baked is a monotonic function. If `x` cookies can be baked, then any number less than `x` can also be baked. Binary search is used to efficiently determine the maximum `x`.

3. **Upper Bound Calculation**: The upper bound for the binary search is determined by the minimum value of `(b_i + k) // a_i` for all ingredients. This ensures that we do not consider impossible values of `x` where the magic powder required for a single ingredient exceeds the available amount.

4. **Magic Powder Calculation**: For each midpoint in the binary search, calculate the total magic powder required to bake that number of cookies. If the required magic powder is within the available amount, update the maximum number of cookies.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n, k = int(input[ptr]), int(input[ptr+1])
    ptr += 2
    a = list(map(int, input[ptr:ptr+n]))
    ptr += n
    b = list(map(int, input[ptr:ptr+n]))
    
    # Compute the initial high value
    high = float('inf')
    for i in range(n):
        current = (b[i] + k) // a[i]
        if current < high:
            high = current
    
    low = 0
    max_x = 0
    while low <= high:
        mid = (low + high) // 2
        required = 0
        for i in range(n):
            need = mid * a[i]
            if need > b[i]:
                required += (need - b[i])
                if required > k:
                    break
        if required <= k:
            max_x = mid
            low = mid + 1
        else:
            high = mid - 1
    print(max_x)

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read and parsed into the number of ingredients, the amount of magic powder, the required amounts for each ingredient per cookie, and the available amounts of each ingredient.

2. **Upper Bound Calculation**: For each ingredient, compute the maximum number of cookies that can be baked using the available ingredient and magic powder. The minimum of these values across all ingredients is used as the upper bound for the binary search.

3. **Binary Search Execution**: The binary search iterates over possible values of cookies. For each midpoint value, the required magic powder is calculated. If the required powder is within the available amount, the midpoint is a valid solution, and the search continues for higher values.

4. **Result**: The maximum valid number of cookies found during the binary search is printed as the result.

This approach efficiently narrows down the possible number of cookies using binary search, ensuring the solution is optimal and runs in a reasonable time frame even for large input sizes.
