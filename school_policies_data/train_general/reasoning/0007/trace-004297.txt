To solve this problem, we need to determine if two cells in a grid are connected, considering dynamic barriers placed around rectangular regions. The solution involves efficiently managing these barriers and checking connectivity using a breadth-first search (BFS).

### Approach
1. **Grid Representation**: Use two 2D arrays to track horizontal and vertical edges that are blocked by barriers.
2. **Barrier Management**: For each barrier placement or removal, update the corresponding edges in the grid.
3. **Connectivity Check**: For each query, perform a BFS to check if there is a path between the two cells that does not cross any blocked edges. Use a visited array with a timestamp to efficiently reuse memory across queries.

### Solution Code
```python
import sys
from collections import deque

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    m = int(input[ptr])
    ptr += 1
    q = int(input[ptr])
    ptr += 1

    # Initialize edge arrays. We'll use 1-based indexing for rows and columns.
    # horizontal[r][c] represents the horizontal edge between (r,c) and (r,c+1)
    horizontal = [[False] * (m + 2) for _ in range(n + 2)]  # rows 0..n, cols 0..m
    vertical = [[False] * (m + 2) for _ in range(n + 2)]    # vertical edges between (r,c) and (r+1,c)

    visited = [[0] * (m + 2) for _ in range(n + 2)]
    current_visit = 0

    for _ in range(q):
        t = int(input[ptr])
        ptr += 1
        r1 = int(input[ptr])
        ptr += 1
        c1 = int(input[ptr])
        ptr += 1
        r2 = int(input[ptr])
        ptr += 1
        c2 = int(input[ptr])
        ptr += 1

        if t == 1 or t == 2:
            # Add or remove barrier edges
            # Top horizontal edge: row r1-1, columns c1-1 to c2-1
            row = r1 - 1
            c_start = c1 - 1
            c_end = c2 - 1
            for c in range(c_start, c_end + 1):
                horizontal[row][c] = (t == 1)

            # Bottom horizontal edge: row r2, columns c1-1 to c2-1
            row = r2
            for c in range(c_start, c_end + 1):
                horizontal[row][c] = (t == 1)

            # Left vertical edge: column c1-1, rows r1-1 to r2-1
            col = c1 - 1
            r_start = r1 - 1
            r_end = r2 - 1
            for r in range(r_start, r_end + 1):
                vertical[r][col] = (t == 1)

            # Right vertical edge: column c2, rows r1-1 to r2-1
            col = c2
            for r in range(r_start, r_end + 1):
                vertical[r][col] = (t == 1)

        elif t == 3:
            # Check connectivity
            if (r1, c1) == (r2, c2):
                print("Yes")
                continue

            current_visit += 1
            queue = deque()
            queue.append((r1, c1))
            visited[r1][c1] = current_visit
            found = False

            while queue and not found:
                r, c = queue.popleft()
                for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                    nr = r + dr
                    nc = c + dc
                    if 1 <= nr <= n and 1 <= nc <= m:
                        if visited[nr][nc] == current_visit:
                            continue
                        # Check if the edge is blocked
                        edge_blocked = False
                        if dr == -1:  # moving up, check vertical[r-1][c]
                            edge_blocked = vertical[r-1][c]
                        elif dr == 1:  # moving down, check vertical[r][c]
                            edge_blocked = vertical[r][c]
                        elif dc == -1:  # moving left, check horizontal[r][c-1]
                            edge_blocked = horizontal[r][c-1]
                        elif dc == 1:  # moving right, check horizontal[r][c]
                            edge_blocked = horizontal[r][c]
                        if edge_blocked:
                            continue
                        if nr == r2 and nc == c2:
                            found = True
                            break
                        visited[nr][nc] = current_visit
                        queue.append((nr, nc))
                if found:
                    break

            print("Yes" if found else "No")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Grid Representation**: The grid uses two 2D arrays to track horizontal and vertical edges. These arrays are updated dynamically as barriers are added or removed.
2. **Barrier Management**: When a barrier is added (type 1) or removed (type 2), the corresponding edges in the horizontal and vertical arrays are updated to reflect their blocked status.
3. **Connectivity Check**: For each type 3 query, a BFS is performed starting from the first cell. The BFS checks if there is a path to the second cell that avoids blocked edges. A visited array with a timestamp is used to avoid reinitializing the array for each query, improving efficiency. The BFS terminates early if the destination cell is found.
