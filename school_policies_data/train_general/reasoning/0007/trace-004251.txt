### Approach
1. **Identify the Battle Number**: For a given day D, determine which battle (N) is ongoing. This is done by finding the smallest N such that the sum of the first N natural numbers (triangular number) is greater than or equal to D. This sum is given by the formula \( T(N) = N(N+1)/2 \).

2. **Triangular Number Calculation**: Using the quadratic formula, we approximate N by solving \( N^2 + N - 2D \geq 0 \). This gives us \( N \approx (\sqrt{8D + 1} - 1) / 2 \). We then adjust this approximation to ensure accuracy.

3. **Determine Participants**: Once the battle number N is found, use modulo 3 arithmetic to determine the participating houses:
   - If \( N \mod 3 = 0 \), the participants are Starks (S) and Lannisters (L).
   - If \( N \mod 3 = 1 \), the participants are Lannisters (L) and Baratheons (B).
   - If \( N \mod 3 = 2 \), the participants are Baratheons (B) and Starks (S).

import math
import sys
