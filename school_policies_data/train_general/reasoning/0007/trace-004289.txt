To solve this problem, we need to determine the minimum number of button presses required to transform a number `n` into a number `m` using two operations: multiplying by 2 (red button) and subtracting 1 (blue button). The solution involves working backwards from `m` to `n` to minimize the number of steps efficiently.

### Approach
1. **Reverse Operations**: Instead of starting from `n` and trying to reach `m`, we reverse the operations. This means:
   - If `m` is even, the reverse operation is dividing by 2.
   - If `m` is odd, the reverse operation is adding 1 (since subtracting 1 in the original process would make it even, allowing division by 2 in the next step).

2. **Handle Cases Where `m` is Less Than `n`**: If `m` is less than `n`, the only valid operation is subtracting 1 repeatedly, which takes `n - m` steps.

3. **Iterative Process**: While `m` is greater than `n`, adjust `m` by adding 1 if it is odd and then divide by 2. Count each adjustment and division as steps. Once `m` is less than or equal to `n`, add the remaining steps needed to reach `n`.

### Solution Code
```python
n, m = map(int, input().split())

if m < n:
    print(n - m)
else:
    steps = 0
    while m > n:
        if m % 2 == 1:
            m += 1
            steps += 1
        m //= 2
        steps += 1
    steps += n - m
    print(steps)
```

### Explanation
- **Reverse Operations**: By working backwards from `m`, we can efficiently reduce `m` to a value less than or equal to `n` using the reverse of the allowed operations. This approach ensures that we minimize the number of steps by making optimal choices (e.g., avoiding unnecessary subtractions).
- **Handling Odd Numbers**: When `m` is odd, we increment it to make it even, which allows us to divide by 2 in the next step. This step is crucial to avoid getting stuck in an infinite loop of odd numbers.
- **Final Adjustment**: Once `m` is reduced to a value less than or equal to `n`, the remaining steps are simply the difference between `n` and the current value of `m`.

This approach efficiently reduces the problem to a series of straightforward operations, ensuring the minimum number of steps are taken to reach the target value `m` from `n`.
