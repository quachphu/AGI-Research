  * ...

  * all the described edges of a cycle are distinct.

To solve this problem, we need to determine the number of connected components in an undirected graph that form cycles. A connected component is considered a cycle if each vertex in the component has exactly two neighbors, and the component contains at least three vertices.

### Approach
1. **Graph Representation**: Use an adjacency list to represent the graph and track the degree of each vertex.
2. **Connected Components**: Use BFS (Breadth-First Search) to explore each connected component in the graph.
3. **Cycle Check**: For each connected component, check if all vertices have a degree of 2 and if the component contains at least three vertices. If both conditions are met, the component is a cycle.

### Solution Code
```python
import sys
from collections import deque

def main():
    n, m = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n + 1)]
    degrees = [0] * (n + 1)
    for _ in range(m):
        u, v = map(int, sys.stdin.readline().split())
        adj[u].append(v)
        adj[v].append(u)
        degrees[u] += 1
        degrees[v] += 1
    visited = [False] * (n + 1)
    count = 0
    for v in range(1, n + 1):
        if not visited[v]:
            q = deque()
            q.append(v)
            visited[v] = True
            component = []
            while q:
                node = q.popleft()
                component.append(node)
                for neighbor in adj[node]:
                    if not visited[neighbor]:
                        visited[neighbor] = True
                        q.append(neighbor)
            valid = True
            for node in component:
                if degrees[node] != 2:
                    valid = False
                    break
            if valid and len(component) >= 3:
                count += 1
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Graph Representation**: The graph is represented using an adjacency list where each vertex points to its neighbors. Additionally, an array `degrees` is used to track the degree of each vertex.
2. **Finding Connected Components**: BFS is used to traverse the graph starting from each unvisited vertex. This helps in identifying all vertices in the connected component.
3. **Cycle Validation**: For each connected component found, we check two conditions:
   - All vertices in the component must have a degree of exactly 2.
   - The component must contain at least three vertices.
   If both conditions are satisfied, the component is counted as a cycle.

This approach efficiently checks each component in O(n + m) time complexity, making it suitable for large graphs up to the given constraints.
