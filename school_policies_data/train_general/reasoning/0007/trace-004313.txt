To solve this problem, we need to identify and count the duplicate surface information in a polygon model composed of triangles. Each surface is defined by three vertices, and different permutations of these vertices are considered duplicates. The goal is to determine how many such duplicates exist and need to be removed.

### Approach
1. **Reading Input**: First, we read the number of surface information entries and then each entry itself.
2. **Standardizing Surface Information**: For each set of three vertices, we sort them. This standardized form ensures that different permutations of the same vertices are treated identically.
3. **Tracking Unique Entries**: Using a set data structure, we track each unique standardized surface entry. The set automatically handles duplicates by only storing unique elements.
4. **Calculating Duplicates**: The number of duplicates is the total number of entries minus the number of unique entries stored in the set.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    idx = 1
    seen = set()
    for _ in range(n):
        a, b, c = input[idx], input[idx+1], input[idx+2]
        idx += 3
        key = tuple(sorted((int(a), int(b), int(c))))
        seen.add(key)
    print(n - len(seen))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and split into a list for efficient processing. This helps in handling large inputs smoothly.
2. **Standardization with Sorting**: By sorting each triplet of vertices, we convert any permutation of the same three vertices into a consistent form. For example, both (1, 3, 2) and (3, 2, 1) become (1, 2, 3) after sorting.
3. **Using Set for Uniqueness**: The set data structure is used to store each unique standardized triplet. Since sets do not allow duplicate values, each unique triplet is stored exactly once.
4. **Result Calculation**: The difference between the total number of entries (N) and the size of the set (number of unique entries) gives the count of duplicates, which is the required result.

This approach ensures that we efficiently identify and count duplicates in O(N) time complexity, where N is the number of surface information entries, making it suitable for large inputs up to the constraint limits.
