To solve this problem, we need to determine the number of seats Mr. A can sit in a classroom based on specific conditions. The conditions include avoiding the first row, seats adjacent to other students, and seats near noisy students. 

### Approach
1. **Input Reading**: Read the dimensions of the classroom (M rows and N columns) and the seating arrangement.
2. **Check First Row**: Exclude all seats in the first row (index 0).
3. **Check Adjacent Seats**: Ensure there are no students ('o' or 'x') in the immediately adjacent left or right seats.
4. **Check Noisy Neighbors**: Ensure there are no noisy students ('x') in any of the 8 surrounding cells (including diagonally adjacent cells).
5. **Valid Seat Check**: Count the seats that meet all the conditions.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().splitlines()
    M, N = map(int, input[0].split())
    grid = []
    for line in input[1:M+1]:
        grid.append(list(line.strip()))
    
    count = 0
    for i in range(M):
        for j in range(N):
            if grid[i][j] != '-':
                continue
            if i == 0:
                continue
            # Check left and right for 'o' or 'x'
            left_invalid = (j > 0 and grid[i][j-1] in {'o', 'x'})
            right_invalid = (j < N-1 and grid[i][j+1] in {'o', 'x'})
            if left_invalid or right_invalid:
                continue
            # Check 8 surrounding cells for 'x'
            has_x = False
            for di in (-1, 0, 1):
                for dj in (-1, 0, 1):
                    if di == 0 and dj == 0:
                        continue
                    ni, nj = i + di, j + dj
                    if 0 <= ni < M and 0 <= nj < N:
                        if grid[ni][nj] == 'x':
                            has_x = True
                            break
                if has_x:
                    break
            if not has_x:
                count += 1
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into a grid representing the classroom seats.
2. **Iterating Over Seats**: Each seat is checked to see if it is vacant ('-').
3. **First Row Exclusion**: Seats in the first row (index 0) are immediately excluded.
4. **Adjacent Seat Check**: For each valid seat, the left and right seats are checked for the presence of any students ('o' or 'x').
5. **Noisy Neighbor Check**: The 8 surrounding cells of each valid seat are checked for noisy students ('x').
6. **Counting Valid Seats**: Seats that pass all checks are counted and the total is printed.

This approach ensures that all conditions are systematically checked for each seat, resulting in an efficient and accurate solution.
