To solve this problem, we need to determine two values for Vasya the Hipster: the maximum number of days he can wear different colored socks and the maximum number of days he can wear the same colored socks afterward.

### Approach
1. **Different Colored Socks (First Value):** The maximum number of days Vasya can wear different colored socks is determined by the smaller count of the two sock colors. This is because each day he uses one sock of each color, so once the smaller count is exhausted, he can no longer form a pair of different colors.
2. **Same Colored Socks (Second Value):** After using up the smaller count of socks, the remaining socks will all be of one color. The number of days he can wear these remaining socks is determined by how many pairs (each pair consisting of two socks) can be formed from the remaining count. This is calculated by taking the absolute difference between the two counts, dividing by 2, and taking the floor of the result.

### Solution Code
```python
def main():
    a, b = map(int, input().split())
    diff_days = min(a, b)
    same_days = (abs(a - b) // 2)
    print(diff_days, same_days)

main()
```

### Explanation
1. **Reading Input:** The input consists of two integers representing the number of red and blue socks.
2. **Calculating Days for Different Socks:** The first value is the minimum of the two input integers, as this represents the number of days Vasya can wear one sock of each color.
3. **Calculating Days for Same Socks:** After using up the smaller count of socks, the remaining socks are all of one color. The number of days he can wear these is the integer division of the absolute difference between the two counts by 2, as each day requires two socks of the same color.

This approach efficiently computes the required values using simple arithmetic operations, ensuring optimal performance and correctness.
