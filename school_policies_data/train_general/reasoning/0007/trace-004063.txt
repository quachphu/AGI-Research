To solve this problem, we need to determine the minimum possible depth of a tournament tree given the parent array where each node (contestant) except the root (champion) has a parent that it lost to. The depth of the tournament is defined as the maximum number of matches that any contestant must play to win the championship.

### Approach
1. **Tree Structure**: The given parent array forms a tree where each node's parent is the contestant that defeated it. The root of this tree is the champion (node 1).
2. **Post-order Traversal**: We process each node in post-order to compute the depth contribution of each subtree. This ensures that we process all children of a node before processing the node itself.
3. **Depth Calculation**: For each node, we collect the depths of its children, sort them in descending order, and compute the maximum depth contribution considering the order of matches. The depth contribution of a node is determined by the formula `d + (i + 1)` where `d` is the depth of a child and `i` is the index in the sorted list of child depths.

### Solution Code
```python
import sys

def main():
    sys.setrecursionlimit(1 << 25)
    N = int(sys.stdin.readline())
    if N == 1:
        print(0)
        return
    children = [[] for _ in range(N + 1)]
    for i in range(2, N + 1):
        a = int(sys.stdin.readline())
        children[a].append(i)
    
    stack = [(1, False)]
    depth = [0] * (N + 1)
    max_depth = 0
    
    while stack:
        node, visited = stack.pop()
        if not visited:
            stack.append((node, True))
            for child in reversed(children[node]):
                stack.append((child, False))
        else:
            child_depths = [depth[child] for child in children[node]]
            child_depths.sort(reverse=True)
            current_max = 0
            for i in range(len(child_depths)):
                temp = child_depths[i] + (i + 1)
                if temp > current_max:
                    current_max = temp
            depth[node] = current_max
            if node == 1:
                max_depth = current_max
    print(max_depth)

if __name__ == "__main__":
    main()
```

3. **Depth Calculation**: For each node, we compute the depth contribution by considering the sorted depths of its children. The sorted depths allow us to minimize the maximum depth by processing deeper subtrees first.
4. **Result**: The depth of the root node (champion) gives the minimum possible depth of the tournament, which is printed as the result.
