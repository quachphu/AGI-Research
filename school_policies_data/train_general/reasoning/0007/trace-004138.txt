To solve this problem, we need to determine if a given sequence of words forms a valid sentence in Petya's language. A valid sentence is either a single valid word or a sequence of words that follow specific grammatical rules regarding parts of speech and gender.

### Approach
1. **Check Validity of Each Word**: Each word must end with one of the valid suffixes for adjectives, nouns, or verbs, each with specific gender endings.
2. **Check Sentence Structure**: If there are multiple valid words, they must form a valid statement. This means:
   - All words must have the same gender.
   - The sequence must follow the order: zero or more adjectives, exactly one noun, and zero or more verbs.

```python
def main():
    import sys
    words = sys.stdin.read().split()
    if not words:
        print("NO")
        return
    
    suffixes = [
        ('initis', 'verb', 'masculine'),
        ('inites', 'verb', 'feminine'),
        ('liala', 'adjective', 'feminine'),
        ('lios', 'adjective', 'masculine'),
        ('etra', 'noun', 'feminine'),
        ('etr', 'noun', 'masculine'),
    ]
    
    parts = []
    genders = []
    valid = True
    
    for word in words:
        found = False
        for suffix, part, gender in suffixes:
            if word.endswith(suffix):
                parts.append(part)
                genders.append(gender)
                found = True
                break
        if not found:
            valid = False
            break
    
    if not valid:
        print("NO")
        return
    
    if len(words) == 1:
        print("YES")
        return
    
    if len(set(genders)) != 1:
        print("NO")
        return
    
    noun_count = parts.count('noun')
    if noun_count != 1:
        print("NO")
        return
    
    noun_index = parts.index('noun')
    
    for part in parts[:noun_index]:
        if part != 'adjective':
            print("NO")
            return
    
    for part in parts[noun_index + 1:]:
        if part != 'verb':
            print("NO")
            return
    
    print("YES")

main()
```

4. **Single Word Check**: If there's only one valid word, the result is "YES".
5. **Gender Consistency**: All words must share the same gender.
6. **Noun Check**: There must be exactly one noun in the sequence.
7. **Order Check**: The sequence must follow the order of adjectives, one noun, and then verbs.

This approach ensures that all conditions for a valid sentence in Petya's language are met efficiently and correctly.
