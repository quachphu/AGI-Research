To solve this problem, we need to determine the sum of the values of all subsets of a given set, modulo \(10^9 + 7\). The key insight is to recognize that each element's contribution to the total sum can be efficiently computed using properties of subsets.

### Approach
1. **Understanding Subset Contributions**: Each element in the set appears in exactly half of all possible subsets. For a set of size \(n\), each element appears in \(2^{n-1}\) subsets.
2. **Sum Calculation**: The total sum of all subset sums is the sum of all elements multiplied by \(2^{n-1}\). This is because each element's contribution to the total sum is its value multiplied by the number of subsets it appears in.
3. **Modular Arithmetic**: Since the result can be very large, we use modular arithmetic with \(10^9 + 7\) to keep numbers manageable and prevent overflow.

### Solution Code
```python
MOD = 10**9 + 7

def main():
    import sys
    input = sys.stdin.read().splitlines()
    T = int(input[0])
    ptr = 1
    for _ in range(T):
        n = int(input[ptr])
        ptr += 1
        arr = list(map(int, input[ptr].split()))
        ptr += 1
        total = sum(arr)
        exponent = n - 1
        power = pow(2, exponent, MOD)
        result = (total * power) % MOD
        print(result)

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read all at once and split into lines for efficient processing.
2. **Processing Each Test Case**: For each test case, we read the size of the set and the elements.
3. **Sum Calculation**: The sum of the elements is computed, and the number of subsets each element appears in is determined using \(2^{n-1}\).
4. **Modular Exponentiation**: The power of 2 is computed using Python's built-in `pow` function with three arguments to handle large exponents efficiently under modulo \(10^9 + 7\).
5. **Result Calculation**: The final result is the product of the sum of elements and the computed power, taken modulo \(10^9 + 7\).

This approach ensures that we efficiently compute the required result even for large values of \(n\) and large element values, adhering to the problem constraints.
