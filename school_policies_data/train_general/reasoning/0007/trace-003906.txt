To solve this problem, we need to compute the product of the three largest distinct elements in the range [1, i] for each index i in a given array. If there are fewer than three elements up to a certain index, the result for that index should be -1.

### Approach
1. **Initialization**: Start with an empty list to keep track of the top three elements as we iterate through the array.
2. **Iteration**: For each element in the array:
   - Add the current element to the list.
   - Sort the list in descending order to maintain the largest elements at the front.
   - Truncate the list to keep only the top three elements if it exceeds three elements.
3. **Check and Output**: After processing each element, if the list has fewer than three elements, output -1. Otherwise, compute the product of the top three elements and output the result.

This approach ensures that we efficiently track the top three elements using a list and sorting, which allows us to maintain a time complexity of O(N * 4 log 4), where N is the number of elements in the array. This is efficient enough given the problem constraints.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    top3 = []
    for num in a:
        top3.append(num)
        top3.sort(reverse=True)
        if len(top3) > 3:
            top3 = top3[:3]
        if len(top3) < 3:
            print(-1)
        else:
            print(top3[0] * top3[1] * top3[2])

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
- **Tracking Top Elements**: For each element in the array, we add it to our list of top elements, sort the list to maintain order, and truncate it to keep only the top three elements.
- **Output**: After processing each element, we check if we have at least three elements. If not, we output -1. Otherwise, we compute the product of the top three elements and print it.

This approach ensures that we efficiently maintain and update the top three elements as we iterate through the array, providing the correct results in an optimal manner.
