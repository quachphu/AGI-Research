To solve this problem, we need to determine the smallest rectangular region on a grid that contains all the shaded squares (marked with '*'). The goal is to minimize the area of this rectangle to reduce the cost of sending it by post.

### Approach
1. **Identify Shaded Squares**: First, we iterate through the entire grid to collect the coordinates of all shaded squares ('*').
2. **Determine Bounds**: Using the collected coordinates, we find the minimum and maximum row and column indices that bound all the shaded squares. This gives us the smallest rectangle that encloses all the shaded areas.
3. **Extract Subgrid**: Using the identified bounds, we extract the subgrid from the original grid, which forms the smallest rectangle containing all the shaded squares.

### Solution Code
```python
def main():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]
    
    stars = []
    for i in range(n):
        for j in range(m):
            if grid[i][j] == '*':
                stars.append((i, j))
    
    min_row = min(i for i, j in stars)
    max_row = max(i for i, j in stars)
    min_col = min(j for i, j in stars)
    max_col = max(j for i, j in stars)
    
    for i in range(min_row, max_row + 1):
        print(grid[i][min_col : max_col + 1])

main()
```

### Explanation
1. **Reading Input**: The grid dimensions and the grid itself are read from standard input.
2. **Collecting Shaded Coordinates**: We traverse each cell in the grid to collect the coordinates of all cells containing a '*'.
3. **Calculating Bounds**: The minimum and maximum row and column indices from the collected coordinates are determined. These indices define the smallest rectangle that includes all shaded cells.
4. **Extracting the Subgrid**: Using the calculated bounds, we extract the relevant portion of the grid and print it row by row, ensuring the output is the minimal rectangle containing all shaded cells.

This approach efficiently narrows down the relevant portion of the grid by focusing on the extreme positions of the shaded cells, ensuring optimal performance even for the maximum grid size constraints.
