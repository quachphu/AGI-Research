To solve this problem, we need to determine which student will receive the second hole in their badge when the teacher starts with each student in turn. The process involves following the chain of accusations until a student is revisited, indicating the second hole.

### Approach
1. **Understanding the Process**: The teacher starts with a student, follows their accusation to another student, and continues this process until a student is revisited. The first student revisited is the one who gets the second hole.
2. **Simulation for Each Student**: For each student from 1 to n, simulate the process of following accusations. Track visited students using a set to detect the first revisit efficiently.
3. **Efficient Tracking**: Using a set allows O(1) average time complexity for insertions and lookups, making the process efficient even for the upper constraint of n=1000.

### Solution Code
```python
def main():
    import sys
    n = int(sys.stdin.readline())
    p = list(map(int, sys.stdin.readline().split()))
    res = []
    for a in range(1, n + 1):
        visited = set()
        current = a
        visited.add(current)
        while True:
            current = p[current - 1]
            if current in visited:
                res.append(str(current))
                break
            visited.add(current)
    print(' '.join(res))

main()
```

### Explanation
1. **Reading Input**: The number of students `n` and their respective accusations `p` are read from standard input.
2. **Simulating Each Start Point**: For each student `a` from 1 to n:
   - Initialize a set to track visited students.
   - Follow the chain of accusations starting from `a`, adding each student to the visited set.
   - When a student is encountered again (already in the set), this student is the one who gets the second hole, and their number is recorded.
3. **Output the Results**: After processing all students, the results are printed as a space-separated string.

This approach ensures that each student's scenario is handled independently, efficiently tracking the first revisit using a set, leading to an overall time complexity of O(n^2), which is feasible for the given constraints.
