To solve this problem, we need to generate a chessboard configuration where each good cell ('.') is colored such that no two adjacent cells have the same color. The bad cells ('-') remain unchanged. 

### Approach
The problem can be efficiently solved using a checkerboard pattern. The key insight is that each cell's color can be determined based on the sum of its row and column indices. If the sum is even, the cell is colored 'B'; if odd, it is colored 'W'. This ensures that adjacent cells (which will have sums differing by 1) will always have different colors. 

### Solution Code
```python
n, m = map(int, input().split())
for i in range(n):
    row = input().strip()
    new_row = []
    for j in range(m):
        c = row[j]
        if c == '.':
            if (i + j) % 2 == 0:
                new_row.append('B')
            else:
                new_row.append('W')
        else:
            new_row.append('-')
    print(''.join(new_row))
```

### Explanation
1. **Reading Input**: The first line reads the dimensions of the chessboard. Subsequent lines read the chessboard configuration.
2. **Processing Each Cell**: For each cell in the chessboard:
   - If the cell is bad ('-'), it remains unchanged.
   - If the cell is good ('.'), its color is determined by the parity (even or odd) of the sum of its row and column indices. Even sums result in 'B', and odd sums result in 'W'.
3. **Output the Result**: After processing all cells, the modified chessboard is printed row by row.

This approach ensures that all adjacent good cells have different colors, meeting the problem's requirements efficiently. The solution runs in O(n*m) time complexity, which is optimal for the given constraints.
