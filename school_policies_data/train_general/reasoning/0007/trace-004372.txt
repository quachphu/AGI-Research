To solve this problem, we need to determine the maximum sum possible by selecting exactly `k` elements from a sorted array to be multiplied by 1 and the remaining elements to be multiplied by -1. The array is given in non-decreasing order, which allows us to make optimal choices efficiently.

### Approach
1. **Understand the Problem Requirements**: We need to maximize the sum of the product of each element with either 1 or -1, such that exactly `k` elements are multiplied by 1 and the rest by -1.
2. **Leverage the Sorted Array**: Since the array is sorted in non-decreasing order, the optimal choice is to select the largest `k` elements (the last `k` elements in the array) to be multiplied by 1. This is because larger elements contribute more when added and smaller elements (which could be negative) contribute less negatively when subtracted.
3. **Calculate the Sum**: Compute the sum of the largest `k` elements and subtract the sum of the remaining elements. This gives the maximum possible sum under the given constraints.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))

sum_last_k = sum(a[-k:]) if k != 0 else 0
sum_first_part = sum(a[:n - k]) if (n - k) != 0 else 0

print(sum_last_k - sum_first_part)
```

### Explanation
1. **Reading Input**: The first line of input contains two integers `n` (number of elements) and `k` (number of elements to be multiplied by 1). The second line contains the sorted array elements.
2. **Sum Calculation**:
   - **Sum of Last `k` Elements**: This is the sum of the largest `k` elements in the array, which are the last `k` elements due to the array being sorted.
   - **Sum of First `n - k` Elements**: This is the sum of the remaining elements which will be multiplied by -1. Subtracting this sum from the sum of the largest `k` elements gives the desired maximum sum.
3. **Edge Cases**: Handling cases where `k` is 0 (all elements are multiplied by -1) or `k` equals `n` (all elements are multiplied by 1) is straightforward with the given approach.

This approach efficiently computes the maximum sum by leveraging the sorted nature of the array, ensuring optimal element selection in linear time.
