To solve this problem, we need to efficiently handle two types of queries on an array: range updates and finding the maximum difference between the first and last occurrence of a specific value. The challenge is to manage these operations efficiently given the constraints of large input sizes.

### Approach
1. **Range Updates with Fenwick Tree**: Use a Fenwick Tree (Binary Indexed Tree) to efficiently handle range updates. This allows us to increment all elements in a given range by a specific value in logarithmic time.
2. **Tracking Current Values**: For each element in the array, the current value after all updates can be computed as the original value plus the sum of all increments applied to its position. This sum is efficiently queried using the Fenwick Tree.
3. **Handling Queries**: For each query of type 2, iterate through the array to find the first and last occurrence of the target value using the current values computed on-the-fly. This approach, while linear in the worst case, is necessary given the problem constraints and ensures correctness.

import sys

class FenwickTree:
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (self.n + 2)
    
    def _update(self, idx, delta):
        while idx <= self.n:
            self.tree[idx] += delta
            idx += idx & -idx
    
    def range_add(self, l, r, x):
        self._update(l, x)
        self._update(r + 1, -x)
    
    def point_query(self, idx):
        res = 0
        while idx > 0:
            res += self.tree[idx]
            idx -= idx & -idx
        return res

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    q = int(input[ptr])
    ptr += 1
    a = list(map(int, input[ptr:ptr+n]))
    ptr += n
    ft = FenwickTree(n)
    for _ in range(q):
        query_type = input[ptr]
        ptr += 1
        if query_type == '1':
            l = int(input[ptr])
            ptr +=1
            r = int(input[ptr])
            ptr +=1
            x = int(input[ptr])
            ptr +=1
            ft.range_add(l, r, x)
        else:
            y = int(input[ptr])
            ptr +=1
            first = -1
            last = -1
            for i in range(1, n+1):

                if current == y:

            if first == -1:
