To solve this problem, we need to determine if a given sheet of size \( w \times h \) can be cut into at least \( n \) pieces using specific cutting rules. The rules allow cutting a sheet into two equal parts if either the width or height is even. The goal is to check if it's possible to achieve the required number of pieces through these cuts.

### Approach
1. **Understand the Cutting Rules**: Each sheet can be cut along its width if it's even, resulting in two sheets of half the original width. Similarly, cutting along the height if it's even results in two sheets of half the original height. This process can be repeated until both dimensions become odd.
2. **Maximize the Number of Pieces**: The maximum number of pieces achievable from a sheet of size \( w \times h \) is determined by how many times each dimension can be halved. This is equivalent to finding the number of times each dimension is divisible by 2.
3. **Calculate Possible Pieces**: For each dimension \( w \) and \( h \), compute how many times they can be divided by 2. Let these counts be \( a \) and \( b \). The maximum number of pieces is \( 2^{(a + b)} \).
4. **Comparison**: Check if the maximum number of pieces is at least \( n \).

### Solution Code
```python
def count_factors_of_two(x):
    count = 0
    while x % 2 == 0:
        count += 1
        x = x // 2
    return count

t = int(input())
for _ in range(t):
    w, h, n = map(int, input().split())
    a = count_factors_of_two(w)
    b = count_factors_of_two(h)
    total = 1 << (a + b)
    print("YES" if total >= n else "NO")
```

### Explanation
1. **Counting Factors of Two**: The function `count_factors_of_two` calculates how many times a number can be divided by 2. This helps determine the number of times a dimension can be halved.
2. **Iterate Through Test Cases**: For each test case, read the dimensions \( w \) and \( h \), and the required number of pieces \( n \).
3. **Calculate Maximum Pieces**: Using the counts of divisions by 2 for both dimensions, compute the maximum possible pieces using bit shifting for efficiency.
4. **Determine Result**: Compare the maximum possible pieces with \( n \) and print "YES" if achievable, otherwise "NO".

This approach efficiently computes the maximum number of pieces using bitwise operations, ensuring the solution handles the upper constraints effectively.
