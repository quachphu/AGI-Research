To solve this problem, we need to determine the number of special items present in a list of ornaments. A special item is defined as a character that appears at least once in every ornament.

### Approach
1. **Input Reading**: Read the number of ornaments and their compositions from standard input.
2. **Character Check**: For each character from 'a' to 'z', check if it exists in every ornament.
3. **Count Special Items**: Increment the count for each character that is found in all ornaments.
4. **Output Result**: Print the total count of special items.

### Solution Code
```python
def count_special_items():
    import sys
    n = int(sys.stdin.readline())
    ornaments = [sys.stdin.readline().strip() for _ in range(n)]
    count = 0
    for c in 'abcdefghijklmnopqrstuvwxyz':
        all_have = True
        for o in ornaments:
            if c not in o:
                all_have = False
                break
        if all_have:
            count += 1
    print(count)

count_special_items()
```

### Explanation
1. **Reading Input**: The function reads the number of ornaments `n` and then reads each ornament's composition into a list.
2. **Checking Each Character**: For each character from 'a' to 'z', the function checks if the character is present in every ornament. This is done by iterating through each ornament and verifying the presence of the character.
3. **Counting Special Items**: If a character is found in all ornaments, it is counted as a special item.
4. **Output**: The total count of special items is printed.

This approach efficiently checks each character against all ornaments, ensuring that we only count characters that meet the criteria of appearing in every ornament. The solution handles all edge cases and constraints as specified.
