To solve this problem, we need to calculate the expected value of Vasya's final score after moving a chip on a matrix according to specific rules. The solution involves dynamic programming and modular arithmetic to efficiently compute the expected value using properties of Markov chains and Euclidean distances.

### Approach
1. **Sorting Cells by Value**: We start by sorting all cells in the matrix based on their values. This allows us to process cells in increasing order of their values, ensuring that when we compute the expected value for a cell, all cells with smaller values have already been processed.

2. **Dynamic Programming (DP) Setup**: We maintain a DP array `E` where `E[i][j]` represents the expected score starting from cell `(i, j)`. The value of `E[i][j]` is computed using the contributions from all cells with smaller values.

3. **Cumulative Sums**: To efficiently compute the contributions from all smaller cells, we maintain cumulative sums of their coordinates, squared coordinates, and their expected values. These sums help in quickly calculating the required distances and expected values using precomputed values.

4. **Modular Arithmetic**: Since the result needs to be modulo `998244353`, all operations, including divisions (using modular inverses), are performed under this modulus to prevent overflow and ensure correctness.
