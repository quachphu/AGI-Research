To solve this problem, we need to determine the number of cells in a maze that can be reached from a given starting position, considering constraints on the number of left and right movements allowed. The solution involves a breadth-first search (BFS) approach that tracks the maximum remaining left and right steps for each cell to efficiently explore all reachable cells.

### Approach
1. **Input Parsing and Initialization**: Read the maze dimensions, starting position, and movement constraints. Convert the starting position to 0-based indices for easier array manipulation.
2. **BFS Setup**: Initialize two 2D arrays to track the maximum remaining left and right steps for each cell. Start the BFS from the starting position with the initial remaining left and right steps.
3. **BFS Exploration**: For each cell, explore all four possible directions (up, down, left, right). Update the remaining steps based on the movement direction and check if the new state (remaining steps) is better than the previously recorded state for the target cell.
4. **Reachability Check**: After processing all possible movements, count the cells where both remaining left and right steps are non-negative, indicating that the cell is reachable under the given constraints.

import sys
from collections import deque

def main():
    n, m = map(int, sys.stdin.readline().split())
    r, c = map(int, sys.stdin.readline().split())
    r -= 1
    c -= 1
    x, y = map(int, sys.stdin.readline().split())
    maze = []
    for _ in range(n):
        maze.append(sys.stdin.readline().strip())
    
    max_left = [[-1 for _ in range(m)] for __ in range(n)]
    max_right = [[-1 for _ in range(m)] for __ in range(n)]
    
    q = deque()
    max_left[r][c] = x
    max_right[r][c] = y
    q.append((r, c))
    
    directions = [(-1, 0, 'up'), (1, 0, 'down'), (0, -1, 'left'), (0, 1, 'right')]
    
    while q:
        i, j = q.popleft()
        for (di, dj, dir) in directions:
            ni, nj = i + di, j + dj
            if 0 <= ni < n and 0 <= nj < m:
                if maze[ni][nj] == '.':
                    new_left = max_left[i][j]
                    new_right = max_right[i][j]
                    if dir == 'left':
                        new_left = max_left[i][j] - 1
                        if new_left < 0:
                            continue
                    elif dir == 'right':
                        new_right = max_right[i][j] - 1
                        if new_right < 0:
                            continue
                    if (max_left[ni][nj] < new_left) or (max_right[ni][nj] < new_right):
                        if max_left[ni][nj] < new_left:
                            max_left[ni][nj] = new_left
                        if max_right[ni][nj] < new_right:
                            max_right[ni][nj] = new_right
                        q.append((ni, nj))
    
    count = 0
    for i in range(n):
        for j in range(m):
            if max_left[i][j] >= 0 and max_right[i][j] >= 0:
                count += 1
