To solve this problem, we need to find the maximum possible beauty of painting given non-negative integers into two non-empty subsets (red and blue). The beauty is defined as the sum of the XOR of the integers in the red subset and the XOR of the integers in the blue subset. 

### Approach
1. **Total XOR Calculation**: Compute the XOR of all integers in the array. This total XOR (denoted as `total_xor`) is crucial because it helps determine the optimal split into two subsets.
2. **Case Handling**:
   - **Non-zero Total XOR**: If `total_xor` is non-zero, the maximum beauty is derived by considering the bits that can be set in both subsets. We mask each element to ignore bits set in `total_xor`, then find the maximum XOR of these masked elements.
   - **Zero Total XOR**: If `total_xor` is zero, the problem reduces to finding the maximum XOR of any non-empty proper subset of the array, which is then doubled to get the beauty.
