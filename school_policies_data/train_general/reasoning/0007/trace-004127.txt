To solve this problem, we need to count the number of consecutive subsequences (substrings) in a given number that form multiples of 11, without leading zeros and ensuring they are positive numbers. 

### Approach
1. **Divisibility Rule for 11**: A number is divisible by 11 if the alternating sum of its digits (sum of digits at odd positions minus sum of digits at even positions) is a multiple of 11.
2. **Prefix Sum Array**: Compute a prefix sum array where each element is the alternating sum of digits up to that point. This helps in efficiently checking the divisibility of any substring.
3. **Modulo Handling**: Use modulo 11 to track the remainders of these prefix sums. This helps in quickly determining if a substring is divisible by 11 by checking if two prefix sums have the same remainder when divided by 11.
4. **Efficient Counting**: Use a hash map to count occurrences of each remainder, allowing us to efficiently determine how many valid substrings end at each position.
5. **Edge Cases Handling**: Exclude substrings that start with a zero (for lengths >1) and single zero digits.

### Solution Code

import bisect
from collections import defaultdict

def count_11_sequences(s):
    N = len(s)
    if N == 0:
        return 0
    
    # Compute the prefix sums with alternating signs
    S = []
    current_sum = 0
    for i in range(N):
        digit = int(s[i])
        if i % 2 == 0:
            current_sum += digit
        else:
            current_sum -= digit
        S.append(current_sum)
    
    # Include the virtual S[-1] = 0 at the beginning
    S_with_virtual = [0] + S
    
    # Calculate total_count using the prefix sums and mod 11
    total_count = 0
    mod_counts = defaultdict(int)
    mod_counts[0] = 1  # Initialize with S[-1] = 0
    
    for y in range(1, len(S_with_virtual)):
        current_mod = S_with_virtual[y] % 11
        total_count += mod_counts.get(current_mod, 0)
        mod_counts[current_mod] += 1
    
    # Calculate A (number of single '0's)
    A = s.count('0')
    
    # Precompute mod_lists for each modulo value
    mod_lists = defaultdict(list)
    for idx, val in enumerate(S_with_virtual):
        mod = val % 11
        mod_lists[mod].append(idx)
    
    # Calculate B (substrings starting with '0' and length >=2)
    B = 0
    for i in range(N):
        if s[i] != '0':
            continue
        
        # Find m = S[i-1] mod 11, which is S_with_virtual[i]
        m = S_with_virtual[i] % 11
        lst = mod_lists.get(m, [])
        if not lst:
            continue
        
        # The required j in S_with_virtual must be >= i+2
        target = i + 2
        pos = bisect.bisect_left(lst, target)
        B += len(lst) - pos
    
    valid_count = total_count - A - B
    return valid_count

def main():
    import sys
    for line in sys.stdin:
        line = line.strip()
        if line == '0':
            break
        print(count_11_sequences(line))

    main()
