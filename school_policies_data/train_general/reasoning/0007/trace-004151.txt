To solve this problem, we need to determine the k-th element in a sequence where all odd numbers from 1 to n are listed first in ascending order, followed by all even numbers from 1 to n in ascending order.

### Approach
1. **Understand the Sequence Structure**: The sequence is divided into two parts: odd numbers followed by even numbers.
2. **Count the Odds**: Calculate the number of odd numbers up to n. This can be done using the formula `(n + 1) // 2`.
3. **Determine Position**: Check if the k-th position falls within the odd part or the even part:
   - If k is less than or equal to the count of odd numbers, the result is the k-th odd number, which can be computed as `2 * k - 1`.
   - If k is greater than the count of odd numbers, adjust k to find the position within the even part and compute the result as `2 * (k - count_of_odds)`.

### Solution Code
```python
n, k = map(int, input().split())
m = (n + 1) // 2
if k <= m:
    print(2 * k - 1)
else:
    print(2 * (k - m))
```

### Explanation
1. **Reading Input**: The input consists of two integers, n and k.
2. **Calculate Number of Odds**: Using `(n + 1) // 2`, we determine how many odd numbers exist up to n.
3. **Check Position**:
   - If k is within the range of odd numbers (i.e., k ≤ m), the k-th odd number is calculated as `2 * k - 1`.
   - If k is beyond the odd numbers, adjust k by subtracting the count of odds (m) and compute the corresponding even number as `2 * (k - m)`.

This approach efficiently handles very large values of n (up to 10^12) by using direct mathematical calculations without iterating through the sequence, ensuring optimal performance.
