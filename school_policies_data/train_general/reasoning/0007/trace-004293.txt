To solve this problem, we need to calculate the total time taken by Ayush to process all customer orders in a store where each item's position is dynamically updated whenever it is accessed. Each time an item is accessed, it is moved to the front of the row, and the time taken for each access is determined by its current position before the move.

### Approach
1. **Input Reading**: Read the number of customers, items per customer, and total items in the store. Then read the initial arrangement of the items.
2. **Processing Orders**: For each customer, process their order one item at a time:
   - Find the current position of the item.
   - Add this position to the total time.
   - Move the item to the front of the row.
3. **Dynamic List Update**: Maintain the current arrangement of items as a list. Each time an item is accessed, update the list by moving the item to the front.

### Solution Code
```python
n, m, k = map(int, input().split())
current = list(map(int, input().split()))
total_time = 0

for _ in range(n):
    order = list(map(int, input().split()))
    for item in order:
        idx = current.index(item)
        total_time += idx + 1
        # Remove the item and insert at the front
        current.pop(idx)
        current.insert(0, item)

print(total_time)
```

### Explanation
1. **Reading Input**: The first line of input gives the number of customers, items per customer, and total items. The second line provides the initial arrangement of items in the store.
2. **Processing Each Customer**: For each customer's order:
   - For each item in the order, determine its current position using the list's `index` method.
   - Add the position (1-based index) to the total time.
   - Update the list by removing the item from its current position and inserting it at the front.
3. **Efficiency**: The approach efficiently tracks and updates the positions of items using list operations. Each access and update operation is handled in linear time relative to the number of items, which is feasible given the problem constraints.

This solution ensures that each item's position is dynamically updated and correctly accounted for in the total processing time, providing an accurate and efficient result.
