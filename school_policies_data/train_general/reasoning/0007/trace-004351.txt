To solve this problem, we need to generate a min-heap from a list of given integers and determine the root element of the heap. A min-heap is a complete binary tree where each parent node is less than or equal to its children, ensuring the smallest element is at the root.

### Approach
1. **Read Input:** Read the input from standard input, which consists of space-separated integers.
2. **Convert to List:** Split the input string into individual integers and convert them into a list.
3. **Heapify:** Use the `heapq` module's `heapify` function to transform the list into a min-heap. This function rearranges the elements in-place to satisfy the min-heap property.
4. **Extract Root:** The root of the min-heap is the first element of the heapified list. Print this element as the result.

### Solution Code
```python
import heapq

def main():
    import sys
    input_list = list(map(int, sys.stdin.read().split()))
    heapq.heapify(input_list)
    print(input_list[0])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The input is read from standard input using `sys.stdin.read().split()`, which splits the input string into a list of strings. These strings are then converted to integers using `map(int, ...)`.
2. **Heap Conversion:** The `heapq.heapify` function is called on the list of integers. This function rearranges the elements such that the smallest element is at the root (index 0 of the list), maintaining the min-heap structure.
3. **Output Root Element:** After heapifying, the root element (the smallest element) is located at the first position of the list, which is printed as the result.

This approach efficiently converts the input list into a min-heap using built-in functions, ensuring optimal performance and correctness. The time complexity of heapifying the list is O(n), where n is the number of elements, making this approach both efficient and straightforward.
