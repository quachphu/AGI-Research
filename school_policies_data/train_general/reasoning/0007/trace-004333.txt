### Approach

2. **Constraints**: We need \( c \) to be the smallest number greater than \( a \) such that its mask matches \( b \).

### Solution Code
```python
import sys
import itertools

def find_min_c():
    a, b = map(int, sys.stdin.readline().split())
    target = str(b)
    target_len = len(target)
    
    for c in itertools.count(a + 1):
        s = str(c)
        mask = []
        count = 0
        for ch in s:
            if ch in {'4', '7'}:
                count += 1
                mask.append(ch)
                if count > target_len:
                    break  # Early exit if count exceeds target
        if count != target_len:
            continue  # Skip if the count of 4/7 digits doesn't match target length
        if ''.join(mask) == target:
            print(c)
            return
```

### Explanation
1. **Reading Input**: The input values \( a \) and \( b \) are read and converted to integers.
2. **Target Preparation**: The target mask \( b \) is converted to a string to facilitate comparison.
3. **Iterative Check**: Starting from \( a + 1 \), each number is converted to a string. For each number, we build its mask by collecting all '4' and '7' digits.
4. **Early Termination**: If the count of '4' and '7' digits exceeds the length of \( b \) early, we break out of the loop to save time.
5. **Comparison**: If the constructed mask matches \( b \), the number is printed as the result and the function exits.

This approach ensures that we efficiently check each number starting from \( a + 1 \) and find the smallest valid \( c \) using a straightforward iterative method, optimized with early termination checks.
