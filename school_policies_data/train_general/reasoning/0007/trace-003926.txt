To solve this problem, we need to compute the number of ways to pick a certain number of students out of a total class, which is a combinatorial problem. The solution involves calculating combinations efficiently using the mathematical formula for combinations, C(a, b) = a! / (b! * (a-b)!).

### Approach
1. **Input Handling**: Read the number of test cases and then process each test case to get the integers a (total students) and b (students to pick).
2. **Edge Case Handling**: If the number of students to pick (b) is 0, the result is 1 since there's exactly one way to pick zero students.
3. **Optimization**: Use the property C(a, b) = C(a, a-b) to minimize the number of multiplications and divisions. This is done by choosing the smaller value between b and a-b.
4. **Efficient Calculation**: Compute the product of the first k terms of a in descending order (numerator) and the product of the first k terms in ascending order (denominator). The result is the integer division of the numerator by the denominator.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    t = int(input[idx])
    idx += 1
    for _ in range(t):
        a = int(input[idx])
        b = int(input[idx + 1])
        idx += 2
        if b == 0:
            print(1)
            continue
        k = min(b, a - b)
        numerator = 1
        denominator = 1
        for i in range(k):
            numerator *= (a - i)
            denominator *= (i + 1)
        print(numerator // denominator)

main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially with large input sizes. The input is split into a list of strings which are then processed sequentially.
2. **Edge Case Handling**: If b is 0, the output is immediately 1.
3. **Combination Calculation**: By using the smaller of b and a-b, we reduce the number of iterations needed. The numerator is the product of a down to (a - k + 1), and the denominator is the product of 1 up to k. The result is obtained by integer division of the numerator by the denominator, ensuring precision and avoiding floating-point inaccuracies.

This approach efficiently computes combinations using properties of combinatorial mathematics, ensuring optimal performance and correctness for the given problem constraints.
