The solution involves efficiently handling both zero and non-zero substrings to avoid generating all possible substrings explicitly, which would be computationally infeasible for large inputs.

### Approach
1. **Count Zero Substrings**: First, count all substrings that consist entirely of zeros. If the H-th value falls within these zeros, the result is zero.
2. **Generate Non-Zero Substrings**: For non-zero values, generate all possible substrings starting from each non-zero digit in the string. Convert these substrings to their numeric values and sort them to find the H-th smallest value.

### Solution Code
```python
import sys

def main():
    N, H = map(int, sys.stdin.readline().split())
    S = sys.stdin.readline().strip()

    # Calculate count_zero
    count_zero = 0
    current_zero = 0
    for c in S:
        if c == '0':
            current_zero += 1
        else:
            count_zero += current_zero * (current_zero + 1) // 2
            current_zero = 0
    count_zero += current_zero * (current_zero + 1) // 2

    if H <= count_zero:
        print(0)
        return

    # Adjust H for non-zero substrings
    H -= count_zero

    # Collect all non-zero substrings (after stripping leading zeros)
    non_zero_substrings = []
    for i in range(N):
        # Find the first non-zero position starting from i
        j = i
        while j < N and S[j] == '0':
            j += 1
        if j >= N:
            continue  # No non-zero digit from i onwards
        # j is the first non-zero position, add all substrings starting at j
        for k in range(j, N):
            non_zero_substrings.append(S[j:k+1])

    # Sort the non-zero substrings by their numeric value (as strings)
    non_zero_substrings.sort(key=lambda x: (len(x), x))

    # Get the H-1 index (0-based)
    result = non_zero_substrings[H-1].lstrip('0')
    print(result if result != '' else '0')

if __name__ == "__main__":
    main()
```
