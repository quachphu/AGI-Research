To solve this problem, we need to determine the minimum enlightenment value required for K monks to cover all N temples positioned along a straight line. Each monk can spread their enlightenment in both directions from their position, and we aim to minimize this range.

### Approach
1. **Sort the Temple Positions**: The temples are given in a list, which we first sort to facilitate the coverage check.
2. **Binary Search on Enlightenment Value**: We use binary search to efficiently determine the minimum enlightenment value. The search range is between 0 and the maximum distance between the first and last temple.
3. **Check Feasibility Function**: For a given mid value in the binary search, this function checks if K monks can cover all temples with that enlightenment value. The function works by iterating through the sorted temple positions and placing monks optimally to cover as many temples as possible.

### Solution Code
```python
n, k = map(int, input().split())
positions = list(map(int, input().split()))
positions.sort()

def is_possible(d):
    count = 1
    current_end = positions[0] + 2 * d
    for pos in positions[1:]:
        if pos > current_end:
            count += 1
            current_end = pos + 2 * d
            if count > k:
                return False
    return count <= k

low, high = 0, (positions[-1] - positions[0])
answer = high

while low <= high:
    mid = (low + high) // 2
    if is_possible(mid):
        answer = mid
        high = mid - 1
    else:
        low = mid + 1

print(answer)
```

### Explanation
1. **Sorting the Positions**: By sorting the temple positions, we can sequentially check coverage from the leftmost to the rightmost temple.
2. **Binary Search**: The binary search helps narrow down the minimum enlightenment value efficiently. The search space is between 0 and the distance between the farthest temples.
3. **Feasibility Check**: For each mid value in the binary search, the `is_possible` function checks if K monks can cover all temples with an enlightenment value of `d`. This is done by placing each monk as far right as possible to cover the maximum number of subsequent temples. If a temple is beyond the current coverage, a new monk is placed, and the coverage is extended accordingly.

This approach ensures that we efficiently determine the minimum enlightenment value using a combination of sorting and binary search, leading to an optimal solution with a time complexity of O(N log D), where D is the maximum distance between the temples.
