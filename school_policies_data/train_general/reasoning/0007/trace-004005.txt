To solve this problem, we need to determine the number of magic fractions for each number from 1 to N, and then sum these counts. A magic fraction for a number K is a proper fraction a/b where gcd(a, b) = 1 and a * b = K!.

### Approach
1. **Prime Sieve (Sieve of Eratosthenes)**: Generate a list of primes up to N using the Sieve of Eratosthenes. This helps in efficiently determining the number of primes up to any given number K.
2. **Prime Count Array**: Create an array where each entry at index K contains the count of primes less than or equal to K. This helps in quickly determining the number of primes for any K.
3. **Magic Fraction Calculation**: For each K from 1 to N, compute the number of magic fractions. For K >= 2, the number of magic fractions is determined by the formula \(2^{(m-1)}\), where m is the number of primes less than or equal to K. This is derived from the fact that each prime factor of K! can be assigned to either the numerator or the denominator of the fraction, leading to coprime pairs (a, b).

### Solution Code
```python
def main():
    import sys
    n = int(sys.stdin.readline())
    
    if n < 1:
        print(0)
        return
    
    # Sieve of Eratosthenes to find primes up to n
    sieve = [True] * (n + 1)
    sieve[0] = sieve[1] = False
    for i in range(2, int(n ** 0.5) + 1):
        if sieve[i]:
            sieve[i*i : n+1 : i] = [False] * len(sieve[i*i : n+1 : i])
    
    # Compute primes_count where primes_count[k] is the number of primes <= k
    primes_count = [0] * (n + 1)
    count = 0
    for k in range(n + 1):
        if sieve[k]:
            if k >= 2:
                count += 1
        primes_count[k] = count
    
    total = 0
    for K in range(1, n + 1):
        if K == 1:
            continue
        m = primes_count[K]
        if m > 0:
            total += (1 << (m - 1))  # Efficiently compute 2^(m-1)
    
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prime Sieve**: The Sieve of Eratosthenes is used to mark non-prime numbers up to N. This allows efficient prime checking and counting.
2. **Prime Count Array**: This array is built by iterating through the sieve and maintaining a count of primes encountered. Each entry at index K in this array gives the number of primes less than or equal to K.
3. **Magic Fraction Calculation**: For each K from 1 to N, if K is 1, there are no magic fractions. For K >= 2, the number of magic fractions is \(2^{(m-1)}\) where m is the number of primes up to K. This is calculated using bit shifting for efficiency, as \(2^{(m-1)}\) is equivalent to `1 << (m - 1)`.

This approach efficiently computes the required values using precomputed prime information, ensuring optimal performance even for the upper constraint of N = 500.
