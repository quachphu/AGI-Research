To solve this problem, we need to determine the sum of all even numbers in a specific sequence up to a given number \( N \). The sequence starts with 1 and 2, with each subsequent number being the sum of the two preceding numbers. The challenge is to efficiently compute this sum for very large values of \( N \), up to \( 4 \times 10^{16} \), and for up to \( 10^5 \) test cases.

### Approach
1. **Sequence Analysis**: The sequence given is similar to the Fibonacci sequence starting with 1 and 2. The even numbers in this sequence appear at positions 2, 5, 8, 11, etc., which can be modeled by a subsequence with a recurrence relation.
2. **Recurrence Relation**: The even terms form a subsequence where each term \( E(k) \) can be defined as \( E(k) = 4 \times E(k-1) + E(k-2) \), starting with \( E(0) = 2 \) and \( E(1) = 8 \).
3. **Precomputation**: Precompute all even terms and their cumulative sums up to the maximum possible \( N \) (4e16). This allows efficient querying using binary search.
4. **Binary Search**: For each test case, use binary search to quickly find the largest even term less than or equal to \( N \) and retrieve the precomputed cumulative sum.

### Solution Code
```python
import bisect
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    cases = list(map(int, input[1:T+1]))
    
    # Precompute the even terms and their cumulative sums
    max_limit = 4 * 10**16
    even_terms = [2, 8]
    cumulative_sums = [2, 10]  # Sums up to the first and second even terms
    
    while True:
        next_term = 4 * even_terms[-1] + even_terms[-2]
        if next_term > max_limit:
            break
        even_terms.append(next_term)
        cumulative_sums.append(cumulative_sums[-1] + next_term)
    
    # Process each test case
    for N in cases:
        idx = bisect.bisect_right(even_terms, N) - 1
        if idx >= 0:
            print(cumulative_sums[idx])
        else:
            print(0)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precomputation**: We generate all even terms in the sequence up to \( 4 \times 10^{16} \) using the recurrence relation \( E(k) = 4 \times E(k-1) + E(k-2) \). Alongside, we maintain cumulative sums of these terms to avoid recalculating sums for each query.
2. **Efficient Query Handling**: For each test case, we use binary search to find the largest even term that is less than or equal to \( N \). The corresponding cumulative sum from the precomputed list gives the result in constant time.

This approach ensures that even for the upper limits of input constraints, the solution remains efficient and responsive, leveraging precomputation and binary search to handle up to \( 10^5 \) queries efficiently.
