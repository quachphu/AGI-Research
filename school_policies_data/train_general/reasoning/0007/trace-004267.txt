### Approach
1. **Understand the Input**: The input consists of multiple days, each with specific prices for bathing and pool tickets, and the number of tickets needed for each.
2. **Calculate Costs Without Discount**: Compute the cost by purchasing exactly the required number of tickets for each day.
3. **Calculate Costs With Discount**: Determine the minimum number of tickets needed to qualify for the discount (at least 5 bathing tickets and 2 pool tickets). Compute the cost after applying the 20% discount.
4. **Compare Costs**: For each day, compare the cost without discount and the cost with discount, then choose the cheaper option.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    for _ in range(N):
        x = int(input[idx])
        y = int(input[idx+1])
        b = int(input[idx+2])
        p = int(input[idx+3])
        idx += 4
        cost_no_discount = x * b + y * p
        req_b = max(b, 5)
        req_p = max(p, 2)
        cost_with_discount = (x * req_b + y * req_p) * 0.8
        total_cost = min(cost_no_discount, cost_with_discount)
        print(int(total_cost))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list for easier processing. The first value is the number of days, followed by the details for each day.
2. **Cost Without Discount**: For each day, calculate the total cost by multiplying the number of required tickets by their respective prices.
3. **Cost With Discount**: Calculate the number of tickets needed to qualify for the discount (at least 5 bathing and 2 pool tickets). Compute the total cost for these tickets and apply the 20% discount.
4. **Determine Minimum Cost**: Compare the two computed costs (with and without discount) and print the minimum value for each day.
