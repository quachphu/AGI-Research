To solve this problem, we need to determine the minimum number of heaters required to warm up Vova's entire house, which is represented as an array. Each heater has a specific range and can only be placed where the array has a value of 1. The goal is to cover all positions in the array with the fewest heaters possible.

### Approach
1. **Identify Heater Positions**: First, collect all positions in the array where heaters are present (i.e., where the value is 1).
2. **Check for Impossibility**: If there are no heaters, it's impossible to warm the house, so return -1 immediately.
3. **Greedy Algorithm**: Use a greedy approach to select the optimal heaters:
   - Start from the first position of the house.
   - For each current position, find the farthest heater that can cover this position and extend coverage as far as possible.
   - Move to the next position that needs coverage (just after the current heater's coverage ends).
   - Repeat until the entire house is covered or determine if it's impossible.

### Solution Code
```python
def main():
    import sys
    n, r = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    heaters = []
    for i in range(n):
        if a[i] == 1:
            heaters.append(i + 1)  # Convert to 1-based index
    heaters.sort()
    current = 1
    count = 0
    i = 0
    len_heaters = len(heaters)
    
    if len_heaters == 0:
        print(-1)
        return
    
    while current <= n:
        max_reach = -1
        best_heater = -1
        while i < len_heaters and heaters[i] - r + 1 <= current:
            end = heaters[i] + r - 1
            if end >= current:
                if end > max_reach:
                    max_reach = end
                    best_heater = i
            i += 1
        if best_heater == -1:
            print(-1)
            return
        count += 1
        current = max_reach + 1
    print(count)

main()
```

### Explanation
1. **Reading Input**: The code reads the input values for the house size `n`, heater range `r`, and the house array `a`.
2. **Heater Positions**: It collects the positions of all heaters (1-based index) and sorts them.
3. **Greedy Coverage Check**: Starting from the first position, the code iterates through the heater positions to find the farthest heater that can cover the current position. This is done by checking each heater's coverage range and selecting the one that extends coverage the furthest.
4. **Update Coverage**: After selecting the optimal heater, the current position is updated to the end of this heater's coverage range plus one, ensuring the next iteration starts from the next uncovered position.
5. **Check Completion**: If all positions are covered, the count of heaters used is printed. If it's impossible to cover all positions, -1 is printed.

This approach efficiently ensures that we use the minimum number of heaters by always extending coverage as far as possible with each selected heater, adhering to the greedy algorithm's optimal substructure property.
