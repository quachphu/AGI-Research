To solve this problem, we need to help Chef Po select non-overlapping events such that his total compensation is maximized. This problem can be efficiently solved using dynamic programming combined with a binary search approach to find the optimal subset of events.

### Approach
1. **Sort Events by End Time**: First, we sort all the events based on their end times. This allows us to efficiently find the latest non-overlapping event using binary search.
2. **Dynamic Programming (DP) Setup**: We use a DP array where `dp[i]` represents the maximum compensation achievable considering the first `i` events after sorting.
3. **Binary Search for Non-Overlapping Events**: For each event, we use binary search to find the latest event that ends before the current event starts. This helps in efficiently determining the optimal previous event to consider.
4. **DP Transition**: For each event, we have two choices: either include the event (and add its compensation to the maximum compensation of non-overlapping previous events) or exclude it. The DP transition captures the maximum of these two choices.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        events = []
        for _ in range(N):
            S = int(input[ptr])
            E = int(input[ptr+1])
            C = int(input[ptr+2])
            ptr += 3
            events.append((S, E, C))
        
        # Sort events by end time (E)
        events.sort(key=lambda x: x[1])
        ends = [e[1] for e in events]
        dp = [0] * N
        dp[0] = events[0][2]
        
        for i in range(1, N):
            S_i = events[i][0]
            # Find the rightmost event ending <= S_i using bisect_right
            j = bisect.bisect_right(ends, S_i, 0, i) - 1
            current = events[i][2]
            if j >= 0:
                current += dp[j]
            dp[i] = max(dp[i-1], current)
        
        print(dp[-1])

if __name__ == "__main__":
    main()
```
