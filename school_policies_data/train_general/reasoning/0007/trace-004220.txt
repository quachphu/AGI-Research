To solve this problem, we need to analyze a rooted binary tree and provide detailed information about each node, including its parent, sibling, degree, depth, height, and type. The solution involves several steps to compute these properties efficiently.

### Approach
1. **Data Structure Setup**: Read the input and store each node's left and right children in a list of dictionaries.
2. **Parent Identification**: For each node, determine its parent by checking which nodes reference it as a child.
3. **Sibling Identification**: For each node, determine its sibling by checking the other child of its parent.
4. **Degree Calculation**: Compute the number of children each node has.
5. **Depth Calculation**: Use a Breadth-First Search (BFS) starting from the root to determine the depth of each node.
6. **Height Calculation**: Use a post-order traversal to compute the height of each node, which is the longest path from the node to a leaf.
7. **Node Type Determination**: Classify each node as a root, internal node, or leaf based on its parent and degree.

### Solution Code
```python
import sys
from collections import deque

def main():
    n = int(sys.stdin.readline())
    nodes = [{'left': -1, 'right': -1} for _ in range(n)]
    for _ in range(n):
        id, l, r = map(int, sys.stdin.readline().split())
        nodes[id]['left'] = l
        nodes[id]['right'] = r

    parent = [-1] * n
    for id in range(n):
        left = nodes[id]['left']
        right = nodes[id]['right']
        if left != -1:
            parent[left] = id
        if right != -1:
            parent[right] = id

    root = parent.index(-1)

    sibling = [-1] * n
    for id in range(n):
        if parent[id] == -1:
            continue
        p = parent[id]
        if nodes[p]['left'] == id:
            sib = nodes[p]['right']
        else:
            sib = nodes[p]['left']
        sibling[id] = sib

    degree = [0] * n
    for id in range(n):
        cnt = 0
        if nodes[id]['left'] != -1:
            cnt += 1
        if nodes[id]['right'] != -1:
            cnt += 1
        degree[id] = cnt

    depth = [0] * n
    visited = [False] * n
    q = deque([root])
    visited[root] = True
    depth[root] = 0
    while q:
        u = q.popleft()
        left = nodes[u]['left']
        right = nodes[u]['right']
        for child in [left, right]:
            if child != -1 and not visited[child]:
                depth[child] = depth[u] + 1
                visited[child] = True
                q.append(child)

    height = [0] * n
    def compute_height(node):
        if node == -1:
            return -1
        left = nodes[node]['left']
        right = nodes[node]['right']
        left_h = compute_height(left) if left != -1 else -1
        right_h = compute_height(right) if right != -1 else -1
        h = 1 + max(left_h, right_h)
        height[node] = h
        return h
    compute_height(root)

    type_str = []
    for id in range(n):
        if parent[id] == -1:
            type_str.append('root')
        elif degree[id] == 0:
            type_str.append('leaf')
        else:
            type_str.append('internal node')

    for id in range(n):
        print(f"node {id}: parent = {parent[id]}, sibling = {sibling[id]}, degree = {degree[id]}, depth = {depth[id]}, height = {height[id]}, {type_str[id]}")

if __name__ == '__main__':
    main()
```

6. **Height Calculation**: Using a post-order traversal, we recursively compute the height of each node as the maximum height of its children plus one.
7. **Node Type Determination**: Based on the presence of a parent and the degree of the node, we classify each node as root, leaf, or internal node.

This approach efficiently computes all required properties using standard tree traversal techniques and ensures accurate results within the problem constraints.
