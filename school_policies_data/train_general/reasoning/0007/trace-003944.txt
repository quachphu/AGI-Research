To solve this problem, we need to efficiently determine the number of distinct elements in subarrays starting from various positions in an array. Given the constraints, a direct approach would be too slow, so we use a preprocessing step to compute the results for all possible starting positions in linear time.

### Approach
1. **Preprocessing with Dynamic Programming**: We traverse the array from the end to the beginning while maintaining a set of seen elements and a count of distinct elements encountered so far. This allows us to build an array `dp` where `dp[i]` holds the number of distinct elements from position `i` to the end of the array.
2. **Efficient Query Handling**: After preprocessing, each query can be answered in constant time by simply looking up the precomputed value in the `dp` array.

### Solution Code
```python
import sys

def main():
    n, m = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    dp = [0] * (n + 2)  # 1-based indexing up to n
    seen = set()
    current_count = 0
    
    for i in range(n, 0, -1):
        idx = i - 1  # convert to 0-based index
        if a[idx] not in seen:
            seen.add(a[idx])
            current_count += 1
        dp[i] = current_count
    
    for _ in range(m):
        l = int(sys.stdin.readline())
        print(dp[l])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline` for efficiency, especially given the large possible input size.
2. **Preprocessing the Array**: We iterate from the end of the array to the beginning. For each position `i`, we check if the element has been seen before. If not, we add it to the set and increment the count of distinct elements. The result for each position `i` is stored in `dp[i]`.
3. **Answering Queries**: Each query is answered by directly accessing the precomputed value in the `dp` array, ensuring constant time complexity per query.

This approach ensures that we handle up to 100,000 elements and 100,000 queries efficiently, with an overall time complexity of O(n + m).
