To solve this problem, we need to determine the strings that appear most frequently on the voting papers and output them in lexicographical order. 

### Approach
1. **Reading Input:** First, we read the number of votes, followed by each vote string.
2. **Counting Frequencies:** Using a dictionary (or `Counter` from the `collections` module), we count the occurrences of each string.
3. **Finding Maximum Frequency:** Identify the highest frequency of any string from the counts.
4. **Filtering Candidates:** Collect all strings that have this maximum frequency.
5. **Sorting and Outputting:** Sort the collected strings lexicographically and print each one.

### Solution Code
```python
import sys
from collections import Counter

def main():
    n = int(sys.stdin.readline())
    strings = [sys.stdin.readline().strip() for _ in range(n)]
    counts = Counter(strings)
    max_count = max(counts.values())
    candidates = [s for s, cnt in counts.items() if cnt == max_count]
    candidates.sort()
    for s in candidates:
        print(s)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The input is read using `sys.stdin.readline()` for efficiency, especially given the constraint of up to 200,000 votes. Each vote string is stripped of any leading/trailing whitespace to ensure clean data.
2. **Counting Frequencies:** The `Counter` from the `collections` module efficiently counts occurrences of each string.
3. **Finding Maximum Frequency:** The maximum value from the counts is determined using `max(counts.values())`.
4. **Filtering Candidates:** Strings with the maximum frequency are filtered into a list.
5. **Sorting and Outputting:** The list of most frequent strings is sorted lexicographically and each string is printed on a new line.

This approach ensures that we efficiently handle the input size constraints and produce the required results in the correct order.
