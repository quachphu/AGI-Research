To solve this problem, we need to select students from two rows such that no two consecutive students are from the same row and the indices of the selected students form a strictly increasing sequence. The goal is to maximize the total height of the selected students.

### Approach
The problem can be efficiently solved using dynamic programming. The key insight is to track the maximum possible height sum for sequences ending at each index in both rows. By iterating through each student index, we maintain two variables, `max0` and `max1`, which represent the maximum height sum achievable if the last selected student was from the first or second row, respectively. 

1. **Dynamic Programming Initialization**: Start with `max0` and `max1` initialized to 0, representing the maximum height sum starting from no students selected.
2. **Iterate Through Indices**: For each index from 1 to n (0-based in code), compute the maximum height sum for ending at the current index in each row by considering the best possible previous selection from the opposite row.
3. **Update Maximum Values**: After processing each index, update the maximum values for the current row based on the computed values.

This approach ensures that we efficiently compute the maximum possible height sum in linear time, O(n), by leveraging the previous computations optimally.

### Solution Code
```python
n = int(input())
h1 = list(map(int, input().split()))
h2 = list(map(int, input().split()))

max0 = 0
max1 = 0

for i in range(n):
    current0 = h1[i] + max1
    current1 = h2[i] + max0
    new_max0 = max(max0, current0)
    new_max1 = max(max1, current1)
    max0, max1 = new_max0, new_max1

print(max(max0, max1))
```

### Explanation
1. **Initialization**: `max0` and `max1` start at 0, representing the initial state where no students have been selected.
2. **Iteration**: For each student index `i` (0-based), compute the maximum height sum if the sequence ends at `i` in the first row (`current0`) and the second row (`current1`). These values are derived by adding the current student's height to the maximum sum from the opposite row up to the previous index.
3. **Update Maximums**: After computing the values for the current index, update `max0` and `max1` to reflect the best possible sums ending at the current index for each row.
4. **Result**: The maximum possible height sum is the larger of `max0` and `max1` after processing all indices.

This approach efficiently tracks the optimal selections using dynamic programming, ensuring that each step builds on the best possible previous choices, leading to an optimal solution in linear time.
