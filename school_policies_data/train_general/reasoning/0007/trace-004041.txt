To solve this problem, we need to determine if there exist two laptops such that one has a lower price but higher quality than the other. This can be efficiently checked by sorting the laptops by price and then verifying if the quality values form a strictly increasing sequence.

### Approach
1. **Input Reading**: Read the number of laptops and their respective prices and qualities.
2. **Sorting**: Sort the laptops by their price in ascending order.
3. **Quality Check**: After sorting by price, check if the quality values form a strictly increasing sequence. If they do not, it means there exists at least one pair of laptops where the cheaper one has higher quality, confirming Alex's claim.

### Solution Code
```python
n = int(input())
laptops = [tuple(map(int, input().split())) for _ in range(n)]
laptops.sort()

for i in range(1, n):
    if laptops[i][1] < laptops[i-1][1]:
        print("Happy Alex")
        exit()
print("Poor Alex")
```

### Explanation
1. **Reading Input**: The input is read and stored as a list of tuples where each tuple represents a laptop's price and quality.
2. **Sorting**: The list of laptops is sorted by their price. This ensures that we can check the quality values in the order of increasing prices.
3. **Checking Quality Sequence**: By iterating through the sorted list, we check if each subsequent quality value is less than the previous one. If we find such a case, it immediately confirms Alex's claim, and we print "Happy Alex". If the loop completes without finding such a case, we print "Poor Alex".

This approach efficiently checks the condition using sorting and a single linear pass through the sorted list, resulting in an overall time complexity of O(n log n), which is suitable for the given problem constraints.
