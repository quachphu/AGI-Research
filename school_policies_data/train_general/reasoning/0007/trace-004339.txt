### Approach
1. **Dynamic Programming Setup**: Define a function `compute` that calculates the number of paths in a tree where each edge weight is between 1 and a given maximum value. This function uses dynamic programming to efficiently count the number of paths that sum to each possible weight up to n.
2. **Total Paths Calculation**: Calculate the total number of paths in a k-tree that sum to n using the `compute` function with the maximum edge weight set to k.
3. **Subtract Invalid Paths**: Calculate the number of paths that only use edges with weights less than d. This is done using the same `compute` function but with the maximum edge weight set to d-1.
4. **Result Adjustment**: Subtract the number of invalid paths from the total paths to get the result. Use modulo arithmetic to handle large numbers and ensure the result is within the required range.

### Solution Code
```python
MOD = 10**9 + 7

n, k, d = map(int, input().split())

def compute(target, max_step):
    if max_step == 0:
        return 0
    dp = [0] * (target + 1)
    dp[0] = 1
    for i in range(1, target + 1):
        for j in range(1, max_step + 1):
            if i >= j:
                dp[i] = (dp[i] + dp[i - j]) % MOD
    return dp[target]

total = compute(n, k)
subtract = compute(n, d - 1)
answer = (total - subtract) % MOD
print(answer)
```

### Explanation
1. **Dynamic Programming Function (`compute`)**:
   - This function initializes a DP array where `dp[i]` represents the number of ways to reach the sum `i` using edges with weights from 1 to `max_step`.
   - The base case `dp[0] = 1` indicates there is exactly one way to achieve a sum of 0 (using an empty path).
   - For each possible sum `i`, iterate through all possible edge weights up to `max_step` and update the DP array by adding the number of ways to reach the sum `i - j` (if valid).

2. **Total Paths Calculation**:
   - Use `compute(n, k)` to get the total number of paths in a k-tree that sum to n.

3. **Invalid Paths Calculation**:
   - Use `compute(n, d-1)` to get the number of paths that only use edges with weights less than d. These paths are invalid as they do not meet the requirement of having at least one edge with weight >= d.

4. **Result Adjustment**:
   - Subtract the number of invalid paths from the total paths and take modulo 10^9 + 7 to ensure the result is non-negative and within the required range.

This approach efficiently calculates the required values using dynamic programming, ensuring the solution is both optimal and correct for the given constraints.
