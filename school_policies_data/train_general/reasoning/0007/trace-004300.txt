The wardrobe doubles the number of dresses each month, and in the first \( k \) months, there is a 50% chance that a dress is eaten after doubling. ### Approach
1. **Understanding the Problem**: The key operations are doubling the dresses each month and the probabilistic dress reduction in the first \( k \) months. The last month only doubles the dresses without any reduction.
2. **Mathematical Insight**: The expected number of dresses after each month can be modeled using a recurrence relation. After analyzing the problem, we derive that the expected number of dresses after \( k \) months can be represented by the formula \( x \cdot 2^{k+1} - 2^k + 1 \).
3. **Modulo Arithmetic**: Given the constraints, direct computation is infeasible. We use modular arithmetic to handle large numbers efficiently, leveraging properties of exponentiation under modulo.

### Solution Code
```python
x, k = map(int, input().split())
mod = 10**9 + 7

if x == 0:
    print(0)
else:
    a = pow(2, k + 1, mod)
    b = pow(2, k, mod)
    res = ( (x % mod) * a % mod - b + 1 ) % mod
    res = (res + mod) % mod  # Ensure non-negative result
    print(res)
```

3. **Formula Application**: Using the derived formula \( x \cdot 2^{k+1} - 2^k + 1 \), we compute each term modulo \( 10^9 + 7 \) to handle large numbers and ensure the result is within the required range.
4. **Adjustment for Negative Results**: The result is adjusted to ensure it is non-negative by adding the modulus before taking the modulo again if necessary.
