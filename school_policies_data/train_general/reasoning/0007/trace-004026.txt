To solve this problem, we need to determine the minimum travel time between different locations in a building with multiple towers and floors, considering specific constraints on where horizontal movement between towers is allowed.

### Approach
1. **Same Tower Check**: If the start and end locations are in the same tower, the travel time is simply the vertical difference between the floors.
2. **Different Towers**: If the start and end locations are in different towers, we need to consider both vertical and horizontal movements:
   - **Horizontal Movement**: This is allowed only on floors between `a` and `b`. The number of horizontal steps is the absolute difference between the tower numbers.
   - **Vertical Movement**: The optimal vertical path involves moving to a floor within the range `[a, b]` in both the start and end towers. The minimal vertical steps are determined by the closest valid floor in the range `[a, b]` to the start and end floors.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    h = int(input[ptr])
    ptr += 1
    a = int(input[ptr])
    ptr += 1
    b = int(input[ptr])
    ptr += 1
    k = int(input[ptr])
    ptr += 1
    for _ in range(k):
        ta = int(input[ptr])
        ptr += 1
        fa = int(input[ptr])
        ptr += 1
        tb = int(input[ptr])
        ptr += 1
        fb = int(input[ptr])
        ptr += 1
        if ta == tb:
            print(abs(fa - fb))
        else:
            horizontal = abs(ta - tb)
            min_f = min(fa, fb)
            max_f = max(fa, fb)
            lower = max(a, min_f)
            upper = min(b, max_f)
            if lower <= upper:
                s = max_f - min_f
            else:
                if max_f < a:
                    s = (a - fa) + (a - fb)
                else:
                    s = (fa - b) + (fb - b)
            total = horizontal + s
            print(total)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and processed using a pointer for efficiency, especially given the constraints.
2. **Same Tower Handling**: If the start and end towers are the same, the result is the absolute difference between the floors.
3. **Different Towers Handling**:
   - **Horizontal Steps**: Calculated as the absolute difference between the tower numbers.
   - **Vertical Steps**: The optimal vertical path is determined by checking if there is an overlap between the valid horizontal movement floors `[a, b]` and the floors of the start and end points. If there is an overlap, the vertical steps are the difference between the floors. If not, the closest valid floor (either `a` or `b`) is used to compute the vertical steps.

This approach ensures that we efficiently compute the minimal travel time by considering both vertical and horizontal constraints, leading to an optimal solution for each query.
