To solve this problem, we need to determine the maximum number of characters that can be removed from a string following specific rules. Each character can be removed if at least one of its adjacent characters is the previous letter in the Latin alphabet. The goal is to find the optimal sequence of removals to maximize the count of removed characters.

### Approach
1. **Identify Candidates**: For each character in the current string, check if it can be removed by verifying if either of its adjacent characters is the previous letter in the alphabet.
2. **Select Optimal Candidate**: Among the characters that can be removed, select the one with the highest ASCII value. If there are multiple candidates with the same highest value, choose the leftmost one.
3. **Iterate Until No More Removals**: Repeat the process of identifying and removing characters until no more valid removals are possible.

This approach ensures that we always remove the highest possible character first, which helps in enabling more subsequent removals, thus maximizing the total count.

### Solution Code
```python
def max_removals():
    import sys
    n = int(sys.stdin.readline())
    s = list(sys.stdin.readline().strip())
    count = 0

    while True:
        candidates = []
        for i in range(len(s)):
            c = s[i]
            if c == 'a':
                continue
            prev_char = chr(ord(c) - 1)
            left_ok = i > 0 and s[i-1] == prev_char
            right_ok = i < len(s) - 1 and s[i+1] == prev_char
            if left_ok or right_ok:
                candidates.append(i)
        if not candidates:
            break
        # Find the best candidate: max char, leftmost if tie
        max_char = None
        best_i = -1
        for i in candidates:
            current_char = s[i]
            if (max_char is None) or (current_char > max_char) or (current_char == max_char and i < best_i):
                max_char = current_char
                best_i = i
        del s[best_i]
        count += 1
    print(count)

max_removals()
```

### Explanation
1. **Reading Input**: The input is read from standard input, where the first line gives the length of the string, and the second line is the string itself.
2. **Candidate Identification**: For each character in the string, check if it can be removed by verifying if its left or right neighbor is the previous letter in the alphabet.
3. **Optimal Selection**: From the list of valid candidates, select the character with the highest ASCII value. In case of ties, the leftmost character is chosen to ensure deterministic behavior.
4. **Removal Process**: The selected character is removed from the string, and the count of removed characters is incremented. This process repeats until no more valid characters can be removed.

This approach efficiently narrows down the possible removals by prioritizing higher characters, which often leads to more subsequent removals, thus maximizing the total count. The algorithm runs in O(n^3) time complexity in the worst case, which is feasible for the given constraint (n ≤ 100).
