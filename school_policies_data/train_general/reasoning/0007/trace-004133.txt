To solve this problem, we need to determine the minimal cost to make all elements of an array non-negative using two types of operations: one that increases all elements by 1 at a cost of X coins per operation, and another that increases a single element by 1 at a cost of 1 coin per operation. The goal is to find the optimal combination of these operations to minimize the total cost.

### Approach
1. **Identify Negative Elements**: Extract all negative elements from the array, as these are the only elements that require operations to become non-negative.
2. **Sort and Preprocess**: Sort the negative elements and compute a prefix sum array of their absolute values. This helps in efficiently calculating the sum of required individual operations for any given number of global operations.
3. **Ternary Search**: Use ternary search on the number of global operations (k) to find the optimal value that minimizes the total cost. The cost function for a given k is derived from the cost of k global operations plus the cost of any remaining individual operations needed after applying k global operations.
4. **Evaluate Cost Function**: For each candidate value of k during the ternary search, compute the total cost using the prefix sum array to quickly determine the sum of individual operations required.

import bisect

def compute_minimal_cost():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr +=1
    A = list(map(int, input[ptr:ptr+N]))
    ptr +=N
    X = int(input[ptr])
    ptr +=1
    
    B = [x for x in A if x < 0]
    if not B:
        print(0)
        return
    
    B.sort()
    abs_B = [-x for x in B]
    prefix_abs = [0] * (len(abs_B) + 1)
    for i in range(len(abs_B)):
        prefix_abs[i+1] = prefix_abs[i] + abs_B[i]
    max_k = max(abs_B)
    
    low = 0
    high = max_k
    
    # Perform ternary search with a fixed number of iterations
    for _ in range(100):
        if high - low <= 3:
            break
        mid1 = low + (high - low) // 3
        mid2 = high - (high - low) // 3
        cost1 = compute_cost(mid1, X, B, prefix_abs)
        cost2 = compute_cost(mid2, X, B, prefix_abs)
        if cost1 < cost2:
            high = mid2
        else:
            low = mid1
    
    # Check all possible k in the narrowed range
    min_cost = float('inf')
    for k in range(low, high + 1):
        current_cost = compute_cost(k, X, B, prefix_abs)
        if current_cost < min_cost:
            min_cost = current_cost
    print(min_cost)

def compute_cost(k, X, B_sorted, prefix_abs):
    target = -k
    count = bisect.bisect_left(B_sorted, target)
    sum_abs = prefix_abs[count]
    cost = X * k + (sum_abs - k * count)
