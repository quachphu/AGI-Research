To solve this problem, we need to generate a permutation of numbers from 1 to n such that the absolute differences between consecutive elements are all distinct. The key insight here is to construct the permutation by alternating between the smallest and largest remaining numbers, ensuring each jump's length is unique.

### Approach
1. **Alternating Pattern**: Start with the smallest number (1) and then alternately take the largest remaining number, followed by the next smallest, and so on. This approach ensures that each consecutive difference decreases by 1 each time, resulting in all unique differences.
2. **Two Pointers Technique**: Use two pointers, `left` starting at 1 and `right` starting at n. Alternately add the values at these pointers to the permutation, incrementing `left` and decrementing `right` each time they are used. This continues until all numbers from 1 to n are included in the permutation.

### Solution Code
```python
import sys

n = int(sys.stdin.readline())

perm = []
left = 1
right = n
turn_left = True

while len(perm) < n:
    if turn_left:
        perm.append(left)
        left += 1
    else:
        perm.append(right)
        right -= 1
    turn_left = not turn_left

print(' '.join(map(str, perm)))
```

### Explanation
- **Initialization**: We start with `left` at 1 and `right` at n. The boolean `turn_left` determines whether we take the next number from the left (smallest remaining) or the right (largest remaining).
- **Loop Until Permutation Complete**: Continue adding numbers until the permutation contains all n elements.
- **Alternate Directions**: Each iteration alternates between adding the current `left` value and the current `right` value, adjusting the pointers accordingly. This alternation ensures that each consecutive jump length decreases by 1, guaranteeing all differences are unique.

This approach efficiently constructs the required permutation in O(n) time complexity, ensuring optimal performance even for the upper constraint of n = 10,000.
