To solve this problem, we need to determine if two semiknights on a chessboard can meet on a good square (not marked as '#') through a series of simultaneous moves. The solution involves leveraging graph traversal techniques and understanding the movement constraints of the semiknights.

### Approach
1. **Input Handling**: Read multiple test cases, each consisting of an 8x8 chessboard. Each test case is separated by empty lines.
2. **Initial Check**: Calculate the sum of the coordinates of both semiknights modulo 4. If these sums are different, the semiknights can never meet, and we immediately return "NO".
3. **Breadth-First Search (BFS)**: Use BFS to explore all possible positions both semiknights can reach simultaneously. Track their positions and check if they meet on a good square.

### Solution Code
```python
import sys
from collections import deque

def read_board():
    board = []
    while len(board) < 8:
        line = sys.stdin.readline().strip()
        if not line:
            continue
        board.append(line)
    return board

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        board = read_board()
        # Find the two K positions
        positions = []
        for i in range(8):
            for j in range(8):
                if board[i][j] == 'K':
                    positions.append((i, j))
        k1, k2 = positions
        # Check sum mod4 condition
        sum1 = k1[0] + k1[1]
        sum2 = k2[0] + k2[1]
        if (sum1 % 4) != (sum2 % 4):
            print("NO")
            continue
        # BFS setup
        directions = [(-2, -2), (-2, 2), (2, -2), (2, 2)]
        visited = set()
        q = deque()
        start = (k1, k2)
        visited.add(start)
        q.append(start)
        found = False
        while q and not found:
            pos1, pos2 = q.popleft()
            # Check if current positions are the same and valid
            if pos1 == pos2:
                r, c = pos1
                if board[r][c] != '#':
                    found = True
                    break
            # Generate all possible moves for each knight
            next_pos1 = []
            for dr, dc in directions:
                nr = pos1[0] + dr
                nc = pos1[1] + dc
                if 0 <= nr < 8 and 0 <= nc < 8:
                    next_pos1.append((nr, nc))
            next_pos2 = []
            for dr, dc in directions:
                nr = pos2[0] + dr
                nc = pos2[1] + dc
                if 0 <= nr < 8 and 0 <= nc < 8:
                    next_pos2.append((nr, nc))
            # Check all combinations of next moves
            for np1 in next_pos1:
                for np2 in next_pos2:
                    if np1 == np2:
                        r, c = np1
                        if board[r][c] != '#':
                            found = True
                            break
                    state = (np1, np2)
                    if state not in visited:
                        visited.add(state)
                        q.append(state)
                if found:
                    break
            if found:
                break
        print("YES" if found else "NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The `read_board` function reads 8 lines per test case, skipping any empty lines between test cases.
2. **Initial Check**: The sum of the coordinates of each semiknight modulo 4 is checked. If different, meeting is impossible.
3. **BFS Implementation**: The BFS explores all possible moves for both semiknights simultaneously. Each state in the queue represents their positions. If they meet on a good square, the answer is "YES"; otherwise, it continues until all possibilities are exhausted.

This approach efficiently checks all possible meeting points using BFS, ensuring correctness and optimality given the constraints.
