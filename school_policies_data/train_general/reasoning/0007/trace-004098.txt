To solve this problem, we need to determine the number of ways to distribute coins to 3n gnomes arranged in a circle such that Tanya is satisfied. Tanya is satisfied if there exists at least one triplet of gnomes forming an equilateral triangle whose sum of coins is not equal to 6. The solution involves calculating the total valid distributions modulo \(10^9 + 7\).

### Approach
1. **Total Possible Distributions**: Each of the 3n gnomes can have 1, 2, or 3 coins. The total number of possible distributions is \(3^{3n}\) modulo \(10^9 + 7\).
2. **Invalid Distributions**: These are distributions where every triplet sums to exactly 6. For each triplet, there are 7 valid combinations (as calculated). Thus, the number of invalid distributions is \(7^n\) modulo \(10^9 + 7\).
3. **Result Calculation**: Subtract the number of invalid distributions from the total possible distributions and take the result modulo \(10^9 + 7\) to ensure non-negative values.

### Solution Code
```python
MOD = 10**9 + 7
n = int(input())
result = (pow(3, 3 * n, MOD) - pow(7, n, MOD)) % MOD
print(result)
```

### Explanation
- **Total Distributions**: Using modular exponentiation, we compute \(3^{3n} \mod (10^9 + 7)\). This gives the total number of ways to distribute coins without any restrictions.
- **Invalid Distributions**: Similarly, compute \(7^n \mod (10^9 + 7)\), which counts the distributions where every triplet sums to 6.
- **Final Result**: Subtract the invalid count from the total count and take modulo \(10^9 + 7\) to handle negative values. This gives the number of valid distributions where Tanya is satisfied.

This approach efficiently handles large values of n up to \(10^5\) using modular arithmetic to ensure computations remain feasible.
