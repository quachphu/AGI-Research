To solve this problem, we need to determine which lunch menu Kawabayashi should endure to minimize his total calorie intake. The goal is to find the lunch menu with the highest calories, as excluding this menu will result in the minimum possible total calories from the remaining two menus.

### Approach
1. **Understand the Problem**: Kawabayashi wants to eat two different lunch menus while enduring one, such that the total calories consumed are minimized. This means we need to exclude the lunch with the highest calories.
2. **Key Insight**: The sum of the calories from the two lunches he eats will be minimized when the lunch with the highest calories is excluded. This is because the highest calorie lunch contributes the most to the total when included.
3. **Algorithm**: 
   - Read the calorie values for the three lunch menus.
   - Identify the maximum calorie value among the three.
   - Output the corresponding menu (A, B, or C) that has the highest calorie value.

### Solution Code
```python
a, b, c = map(int, input().split())
max_cal = max(a, b, c)
if a == max_cal:
    print("A")
elif b == max_cal:
    print("B")
else:
    print("C")
```

### Explanation
1. **Reading Input**: The input consists of three integers representing the calories of lunches A, B, and C.
2. **Finding the Maximum**: Using the `max` function, we determine the highest calorie value among the three inputs.
3. **Output the Result**: Based on which of the three values is the highest, we print the corresponding menu identifier (A, B, or C).

This approach efficiently determines the menu to endure by leveraging the properties of maximum value comparison, ensuring an optimal solution with a time complexity of O(1).
