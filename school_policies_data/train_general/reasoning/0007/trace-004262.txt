To solve this problem, we need to count the number of triples (a, b, c) of positive integers not greater than N such that a + b, b + c, and c + a are all multiples of K. The solution involves understanding the modular arithmetic constraints and efficiently counting valid residues.

### Approach

1. **Understanding Modular Constraints**:
   - For a + b, b + c, and c + a to be multiples of K, we derive that a ≡ -b (mod K), b ≡ -c (mod K), and c ≡ -a (mod K). This leads to the conclusion that 2b ≡ 0 (mod K), meaning b must be a multiple of K / gcd(2, K).

2. **Residue Calculation**:
   - Compute the greatest common divisor (gcd) of 2 and K, denoted as d. This helps in determining the valid residues for b.
   - Valid residues for b are those that are multiples of K / d. These residues form the set S.

3. **Counting Valid Numbers**:
   - For each residue r in S, count how many numbers up to N have the residue r (for b) and the residues -r (mod K) (for a and c).

4. **Summing Contributions**:
   - For each valid residue r, compute the contribution to the total count of valid triples using the counts of valid residues for a, b, and c.

### Solution Code

```python
import math

n, k = map(int, input().split())

d = math.gcd(2, k)
t = k // d
s_residues = [m * t for m in range(d)]

def count_residue(r):
    if r == 0:
        return n // k
    if r > n:
        return 0
    return (n - r) // k + 1

total = 0
for r in s_residues:
    cnt_r = count_residue(r)
    s = (-r) % k
    cnt_s = count_residue(s)
    total += cnt_s * cnt_s * cnt_r

print(total)
```

### Explanation

1. **Residue Set Calculation**:
   - Compute `d` as the gcd of 2 and K. This determines the number of valid residues for b.
   - Compute `t` as K divided by d. The valid residues for b are 0, t, 2t, ..., (d-1)t.

2. **Counting Numbers with Specific Residues**:
   - For each residue r, determine how many numbers up to N have that residue using integer division and modulo operations.

3. **Summing Contributions**:
   - For each valid residue r in the set S, compute the contribution of valid triples (a, b, c) where b ≡ r (mod K) and a, c ≡ -r (mod K).

This approach efficiently counts the valid triples by leveraging modular arithmetic and precomputing necessary counts, ensuring the solution handles the upper constraints effectively.
