The operations involve selecting two integers \( x \) and \( y \) from the board and writing \( 2x - y \) on the board. The solution requires checking if \( k \) can be generated through these operations.

### Approach
1. **Immediate Check**: If \( k \) is already present in the initial list of numbers, the answer is immediately "YES".
2. **GCD Calculation**: Compute the greatest common divisor (GCD) of the differences between all numbers in the list and the first number. This GCD (denoted as \( d \)) helps determine the possible values that can be generated.
3. **Divisibility Check**: Check if the difference between \( k \) and the first number in the list is divisible by \( d \). If it is, then \( k \) can be generated through the operations; otherwise, it cannot.

### Solution Code
```python
import sys
import math

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n, k = map(int, input[ptr:ptr+2])
        ptr += 2
        x = list(map(int, input[ptr:ptr+n]))
        ptr += n
        if k in x:
            print("YES")
            continue
        x0 = x[0]
        diffs = [num - x0 for num in x[1:]]
        d = 0
        for diff in diffs:
            d = math.gcd(d, abs(diff))
        delta = k - x0
        if delta % d == 0:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Immediate Check**: If \( k \) is found in the initial list, we print "YES" immediately.
2. **GCD Calculation**: The differences between each number in the list and the first number are computed. The GCD of these differences is calculated to determine the common divisor \( d \).
3. **Divisibility Check**: The difference between \( k \) and the first number in the list (\( \text{delta} = k - x_0 \)) is checked for divisibility by \( d \). If \( \text{delta} \) is divisible by \( d \), then \( k \) can be generated using the operations, and we print "YES". Otherwise, we print "NO".

This approach efficiently determines the possibility of generating \( k \) using the given operations by leveraging the properties of GCD and modular arithmetic.
