To solve this problem, we need to determine the sum of all values in a 100x100 grid after each cell has been incremented by the number of rectangles that cover it. Each rectangle is defined by its lower-left and upper-right corners, and we need to count how many times each cell is covered by these rectangles.

### Approach
1. **Grid Initialization**: Create a 101x101 grid (using 1-based indexing for both rows and columns) initialized to zero. This grid will be used to count the number of rectangles covering each cell.
2. **Reading Input**: Read the number of rectangles and their respective coordinates.
3. **Updating the Grid**: For each rectangle, increment the count of each cell within the bounds of the rectangle.
4. **Summing the Values**: After processing all rectangles, sum the values of all cells in the grid to get the final result.

### Solution Code
```python
n = int(input())
grid = [[0] * 101 for _ in range(101)]

for _ in range(n):
    x1, y1, x2, y2 = map(int, input().split())
    for x in range(x1, x2 + 1):
        for y in range(y1, y2 + 1):
            grid[y][x] += 1

total = 0
for x in range(1, 101):
    for y in range(1, 101):
        total += grid[y][x]

print(total)
```

### Explanation
1. **Grid Initialization**: The grid is initialized to a size of 101x101 to simplify 1-based indexing, which aligns with the problem's row and column numbering.
2. **Reading Input**: The input is read and parsed to extract the coordinates of each rectangle.
3. **Updating the Grid**: For each rectangle, iterate over all cells within its bounds (from the lower-left to the upper-right corner) and increment each cell's count by 1.
4. **Summing the Values**: After processing all rectangles, iterate over the entire grid (from 1 to 100 in both dimensions) to sum up all cell values, which gives the total number of times cells were covered by rectangles.

This approach efficiently handles the problem constraints by directly simulating the coverage of each rectangle and summing the results, ensuring correctness and performance within acceptable limits.
