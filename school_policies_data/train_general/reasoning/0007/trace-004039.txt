To solve this problem, we need to determine the number of pairs of secretaries that are talking to each other using the Spyke VoIP system based on their session IDs. If the data provided is inconsistent (i.e., any session ID appears more than twice), we should return -1.

### Approach
1. **Input Reading**: Read the number of secretaries and their respective session IDs.
2. **Frequency Counting**: Use a counter to track the frequency of each session ID, ignoring zeros since they indicate secretaries not on a call.
3. **Validation Check**: Check if any session ID appears more than twice. If so, output -1 as this is invalid.
4. **Pair Counting**: Count how many session IDs appear exactly twice. Each such session ID represents a valid pair of secretaries talking to each other.

### Solution Code
```python
from collections import Counter
import sys

def main():
    n = int(sys.stdin.readline())
    ids = list(map(int, sys.stdin.readline().split()))
    cnt = Counter(ids)
    pairs = 0
    for key, val in cnt.items():
        if key == 0:
            continue
        if val > 2:
            print(-1)
            return
        if val == 2:
            pairs += 1
    print(pairs)

main()
```

### Explanation
1. **Reading Input**: The code reads the number of secretaries and their session IDs from standard input.
2. **Counting Frequencies**: Using the `Counter` from the `collections` module, we count how many times each session ID appears, excluding zeros.
3. **Checking Validity**: For each session ID, if it appears more than twice, the code immediately outputs -1 and exits, as this indicates an invalid scenario.
4. **Counting Valid Pairs**: For each session ID that appears exactly twice, it is counted as a valid pair. The total number of such pairs is then printed.

This approach efficiently checks for invalid scenarios and counts valid pairs using a frequency counter, ensuring both correctness and optimal performance.
