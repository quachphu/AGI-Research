To solve this problem, we need to find the longest directed path in a directed acyclic graph (DAG). The approach involves using topological sorting combined with dynamic programming (DP) to efficiently compute the longest path.

### Approach
1. **Topological Sorting**: Since the graph is a DAG, we can use Kahn's algorithm to generate a topological order. This order ensures that all edges go from earlier nodes to later nodes in the sequence.
2. **Dynamic Programming**: Using the topological order, we maintain a DP array where `dp[v]` represents the length of the longest path ending at node `v`. For each node in the topological order, we update its neighbors' DP values to reflect the longest path possible through the current node.

### Solution Code
```python
import sys
from collections import deque

def main():
    N, M = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(N + 1)]
    in_degree = [0] * (N + 1)
    
    for _ in range(M):
        x, y = map(int, sys.stdin.readline().split())
        adj[x].append(y)
        in_degree[y] += 1
    
    # Kahn's algorithm for topological sort
    q = deque()
    for i in range(1, N + 1):
        if in_degree[i] == 0:
            q.append(i)
    
    topo_order = []
    while q:
        u = q.popleft()
        topo_order.append(u)
        for v in adj[u]:
            in_degree[v] -= 1
            if in_degree[v] == 0:
                q.append(v)
    
    # Compute longest path using DP
    dp = [0] * (N + 1)
    for u in topo_order:
        for v in adj[u]:
            if dp[v] < dp[u] + 1:
                dp[v] = dp[u] + 1
    
    print(max(dp))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and stored in an adjacency list format along with the in-degrees of each node.
2. **Topological Sort Using Kahn's Algorithm**: Nodes with zero in-degree are processed first, and their edges are removed by decrementing the in-degree of their neighbors. This continues until all nodes are processed, resulting in a topological order.
3. **Dynamic Programming for Longest Path**: For each node in the topological order, we update the DP values of its neighbors to reflect the longest path found so far. The maximum value in the DP array at the end gives the length of the longest path.

This approach ensures that we efficiently compute the longest path in O(N + M) time, which is optimal for the given constraints.
