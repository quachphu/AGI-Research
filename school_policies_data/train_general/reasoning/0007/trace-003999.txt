To solve this problem, we need to determine if we can replace the question marks in a given string such that there exists a substring of length 26 containing all 26 letters of the English alphabet exactly once. If possible, we must also provide an example of such a string.

### Approach
1. **Check Each Window**: Iterate through each possible window of length 26 in the input string.
2. **Check Validity**: For each window, check if the non-question mark characters are unique and if the number of question marks allows filling in the missing letters.
3. **Generate Missing Letters**: If a valid window is found, generate the missing letters required to complete the alphabet.
4. **Construct Result**: Replace the question marks in the valid window with the missing letters and replace any remaining question marks outside the window with a default letter (e.g., 'A').

### Solution Code
```python
s = input().strip()
n = len(s)
found = False

for i in range(n - 25):
    window = s[i:i+26]
    non_question = []
    for c in window:
        if c != '?':
            non_question.append(c)
    unique = set(non_question)
    if len(unique) != len(non_question):
        continue  # Duplicate characters in non-'?' part
    m = len(unique)
    k = window.count('?')
    if m + k != 26:
        continue  # Not enough or too many '?' to fill all missing
    
    # Collect missing letters
    missing = []
    for c in 'ABCDEFGHIJKLMNOPQRSTUVWXYZ':
        if c not in unique:
            missing.append(c)
    
    # Build the answer
    ans = list(s)
    ptr = 0
    for j in range(i, i + 26):
        if ans[j] == '?':
            ans[j] = missing[ptr]
            ptr += 1
    # Replace remaining '?' with 'A'
    for j in range(n):
        if ans[j] == '?':
            ans[j] = 'A'
    print(''.join(ans))
    found = True
    break

if not found:
    print(-1)
```

1. **Window Iteration**: The code iterates through each possible starting index of a 26-character window in the input string.
2. **Validation Check**: For each window, it checks if the non-question mark characters are unique and if the number of question marks plus the unique characters equals 26.
3. **Missing Letters Collection**: If a valid window is found, the missing letters needed to complete the alphabet are determined.
4. **Result Construction**: The valid window's question marks are replaced with the missing letters, and any remaining question marks in the string are replaced with 'A' to form the final result. If no valid window is found, the output is -1.

This approach ensures that we efficiently check each possible window and construct a valid solution if one exists.
