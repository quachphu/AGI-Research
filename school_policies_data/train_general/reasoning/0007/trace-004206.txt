To solve this problem, we need to determine how many friends Max can make based on the numbers each child has. Two children can be friends if their numbers share a common factor greater than 1.

### Approach
1. **Understand the Problem Requirements**: Max can be friends with another child if their numbers are not coprime, i.e., their greatest common divisor (GCD) is greater than 1.
2. **Input Handling**: Read Max's number, the count of other children, and their respective numbers.
3. **Compute GCD**: For each child's number, compute the GCD with Max's number. If the GCD is greater than 1, count that child as a friend.
4. **Edge Cases**: Handle cases where Max's number is 1, as 1 is coprime with every other number, resulting in 0 friends.

### Solution Code
```python
import sys
import math

def main():
    a = int(sys.stdin.readline())
    n = int(sys.stdin.readline())
    nums = list(map(int, sys.stdin.readline().split()))
    count = 0
    for num in nums:
        if math.gcd(a, num) > 1:
            count += 1
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The function reads three lines of input: Max's number, the number of children, and the list of numbers each child has.
2. **GCD Calculation**: For each number in the list, the GCD with Max's number is calculated using Python's `math.gcd` function. This function efficiently computes the GCD of two integers.
3. **Count Friends**: If the GCD of Max's number and another child's number is greater than 1, it indicates they can be friends, so the count is incremented.
4. **Output Result**: Finally, the total count of friends is printed.

This approach ensures that we efficiently check each number in linear time, making the solution both optimal and easy to understand.
