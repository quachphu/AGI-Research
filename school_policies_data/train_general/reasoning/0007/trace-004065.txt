To solve this problem, we need to compute the sum of pairs of integers provided in the input. The input consists of multiple lines, each containing two integers separated by a space, and the program should process each line until the end of the input (EOF) is reached.

### Approach
1. **Reading Input**: The input is read line by line from standard input (stdin) until EOF is encountered.
2. **Processing Each Line**: For each line read, split the line into two integer values.
3. **Computing the Sum**: Convert the split string values to integers, compute their sum, and print the result immediately.

This approach ensures that each line is processed individually and efficiently, handling all specified constraints and input conditions correctly.

### Solution Code
```python
import sys

def main():
    for line in sys.stdin:
        a, b = map(int, line.split())
        print(a + b)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code uses `sys.stdin` to read all lines from the input. This is efficient and handles EOF automatically.
2. **Splitting and Converting Values**: Each line is split into parts using the `split()` method, which handles any whitespace separation. The resulting parts are converted to integers using `map(int, ...)`.
3. **Summing and Printing**: The sum of the two integers is computed and printed immediately, ensuring that each result is output as soon as the corresponding input line is processed.

This solution is efficient and straightforward, adhering to the problem constraints and ensuring correct handling of all valid input cases.
