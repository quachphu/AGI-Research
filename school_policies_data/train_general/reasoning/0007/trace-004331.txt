To solve this problem, we need to determine if a given matrix of 0s and 1s could be the result of a sequence of cannon shots as described. The key insight is that each cell containing a 1 must be placed in such a way that it could have been the result of a cannon shot from either the left (row cannon) or above (column cannon).

### Approach
1. **Row and Column Conditions**: For each cell (i, j) containing a 1, check if it could have been placed by a row cannon or a column cannon:
   - **Row Cannon Check**: The cell must be the rightmost cell in its row (j == n-1) or the cell immediately to its right (j+1) must be 1.
   - **Column Cannon Check**: The cell must be the bottommost cell in its column (i == n-1) or the cell immediately below it (i+1) must be 1.

2. **Validation**: If every cell containing a 1 satisfies either the row or column condition, the matrix is valid; otherwise, it is not.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    grid = [input().strip() for _ in range(n)]
    valid = True
    for i in range(n):
        for j in range(n):
            if grid[i][j] == '1':
                row_ok = (j == n-1) or (j + 1 < n and grid[i][j+1] == '1')
                col_ok = (i == n-1) or (i + 1 < n and grid[i+1][j] == '1')
                if not (row_ok or col_ok):
                    valid = False
                    break
        if not valid:
            break
    print("YES" if valid else "NO")
```

### Explanation
- **Row Check**: For each cell (i, j), if it is the rightmost cell (j == n-1) or the cell immediately to the right (j+1) is 1, then it could have been placed by a row cannon.
- **Column Check**: Similarly, if the cell is the bottommost cell (i == n-1) or the cell immediately below (i+1) is 1, then it could have been placed by a column cannon.
- If every cell containing a 1 passes either check, the matrix is valid (output "YES"), otherwise it is invalid (output "NO").

This approach ensures that we efficiently check the necessary conditions for each cell in the matrix, leading to an optimal solution.
