To solve this problem, we need to maximize the beauty of an array after optionally multiplying a consecutive subarray by a given integer \( x \). The beauty of an array is defined as the maximum sum of any consecutive subarray, which can also be empty (summing to zero). 

### Approach
The approach involves using dynamic programming to track the maximum subarray sums under three different states:
1. **No multiplication applied**: This is the standard Kadane's algorithm to find the maximum subarray sum.
2. **Multiplication ongoing**: Track the maximum subarray sum where the multiplication is currently being applied.
3. **Multiplication ended**: Track the maximum subarray sum after the multiplication has been applied and ended.

We iterate through each element of the array and update these three states dynamically. The maximum value among these states at each step gives the current maximum beauty, which is then compared with the overall maximum beauty found so far.

### Solution Code
```python
n, x = map(int, input().split())
a = list(map(int, input().split()))

prev_max0 = 0
prev_max1 = float('-inf')
prev_max2 = float('-inf')
max_beauty = 0

for num in a:
    # Compute current_max0: state0 (no multiplication)
    current_max0 = max(prev_max0 + num, num)
    
    # Compute current_max1: state1 (ongoing multiplication)
    if prev_max1 == float('-inf'):
        temp = prev_max0
    else:
        temp = max(prev_max0, prev_max1)
    current_max1 = max(num * x, temp + num * x)
    
    # Compute current_max2: state2 (after multiplication)
    current_max2_candidates = []
    if prev_max2 != float('-inf'):
        current_max2_candidates.append(prev_max2 + num)
    if prev_max1 != float('-inf'):
        current_max2_candidates.append(prev_max1 + num)
    current_max2 = max(current_max2_candidates) if current_max2_candidates else float('-inf')
    
    # Update the maximum beauty considering all states and the option of choosing an empty subarray
    current_max = max(current_max0, current_max1, current_max2, 0)
    if current_max > max_beauty:
        max_beauty = current_max
    
    # Prepare for next iteration
    prev_max0, prev_max1, prev_max2 = current_max0, current_max1, current_max2

print(max_beauty)
```

### Explanation
1. **Initialization**: Start with initializing three states (`prev_max0`, `prev_max1`, `prev_max2`) to track the maximum subarray sums under different conditions. `prev_max0` starts at 0 (no elements processed), while `prev_max1` and `prev_max2` start at negative infinity (since they are not yet applicable).

2. **Iterate through each element**: For each element in the array:
   - **State 0 (No multiplication)**: Update the maximum subarray sum using the standard Kadane's algorithm.
   - **State 1 (Multiplication ongoing)**: Compute the maximum sum considering the current element is part of the multiplied subarray. This can either start at the current element or extend a previous multiplied subarray.
   - **State 2 (Multiplication ended)**: Compute the maximum sum after the multiplied subarray has ended. This can either extend a previous subarray that ended earlier or end the current multiplied subarray.

3. **Update maximum beauty**: After processing each element, update the overall maximum beauty by considering the maximum value from all three states and the possibility of choosing an empty subarray (sum zero).

This approach ensures that we efficiently compute the maximum possible beauty in linear time, \( O(n) \), making it suitable for large input sizes up to \( 3 \times 10^5 \).
