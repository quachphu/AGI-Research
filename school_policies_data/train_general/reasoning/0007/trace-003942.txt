To solve this problem, we need to determine if there exists a sequence of weights for fish species such that the total weight of fish caught by Alice is strictly larger than that caught by Bob. The fish species are given in non-decreasing order of their weights.

### Approach
1. **Problem Analysis**: The key insight is to check if there exists a suffix (a contiguous segment from some species to the largest species) where the cumulative count of Alice's fish exceeds Bob's. If such a suffix exists, we can assign weights such that the total weight of Alice's fish is greater.

2. **Algorithm**:
   - **Count Frequencies**: Count the number of fish each species caught by Alice and Bob.
   - **Collect Unique Species**: Gather all unique species from both Alice's and Bob's catches.
   - **Check Suffix Sums**: Process the species in reverse order (from largest to smallest) and compute the cumulative difference between Alice's and Bob's counts. If at any point this cumulative difference is positive, it indicates a possible valid weight assignment.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n, m, k = map(int, sys.stdin.readline().split())
    a_list = list(map(int, sys.stdin.readline().split()))
    b_list = list(map(int, sys.stdin.readline().split()))
    
    a_counts = defaultdict(int)
    for x in a_list:
        a_counts[x] += 1
    
    b_counts = defaultdict(int)
    for x in b_list:
        b_counts[x] += 1
    
    species = set(a_counts.keys()).union(b_counts.keys())
    sorted_species = sorted(species)
    
    current_sum = 0
    for s in reversed(sorted_species):
        current_sum += (a_counts[s] - b_counts[s])
        if current_sum > 0:
            print("YES")
            return
    print("NO")

main()
```

### Explanation
1. **Reading Input**: The input is read and parsed to get the counts of fish caught by Alice and Bob.
2. **Counting Frequencies**: Using dictionaries, we count how many times each species appears in Alice's and Bob's catches.
3. **Unique Species**: We gather all unique species from both lists to consider all relevant species.
4. **Suffix Sum Check**: By processing species in reverse order (from largest to smallest), we accumulate the difference in counts. If at any point this cumulative difference becomes positive, it means there's a valid weight assignment where Alice's total weight exceeds Bob's, and we print "YES". If the loop completes without finding such a suffix, we print "NO".

This approach efficiently checks the necessary condition using a linear scan of the species, ensuring optimal performance even for large inputs.
