### Approach
1. **Initial Check**: First, we check if the minimum element of `a` is already greater than or equal to the maximum element of `b`. If so, no operations are needed.
2. **Sorting and Preprocessing**: If the initial check fails, we sort both arrays and compute prefix sums for `a` and suffix sums for `b` to efficiently calculate the cost of operations for any given value.
3. **Generate Candidates**: We generate candidate values for the threshold `x` which will be the minimum value of `a` and the maximum value of `b` after operations. These candidates are derived from elements of both arrays.
4. **Cost Calculation**: For each candidate value `x`, we compute the cost to make all elements of `a` at least `x` and all elements of `b` at most `x` using binary search and precomputed sums.
5. **Find Minimum Cost**: We iterate through all candidate values to find the one that results in the minimum number of operations.

import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    m = int(input[ptr])
    ptr += 1
    a = list(map(int, input[ptr:ptr+n]))
    ptr += n
    b = list(map(int, input[ptr:ptr+m]))
    ptr += m
    
    min_a = min(a)
    max_b = max(b)
    
    if min_a >= max_b:
        print(0)
        return
    
    a_sorted = sorted(a)
    b_sorted = sorted(b)
    
    # Compute prefix sums for a
    prefix_a = [0] * (n + 1)
    for i in range(n):
        prefix_a[i+1] = prefix_a[i] + a_sorted[i]
    
    # Compute suffix sums for b
    suffix_b = [0] * (m + 1)
    for i in range(m-1, -1, -1):
        suffix_b[i] = suffix_b[i+1] + b_sorted[i]
    
    # Generate unique candidates and include min_a and max_b
    candidates = a_sorted + b_sorted
    candidates.append(min_a)
    candidates.append(max_b)
    candidates = sorted(list(set(candidates)))
    
    min_ops = float('inf')
    
    for x in candidates:
        if x < min_a or x > max_b:
            continue
        
        # Calculate cost for array a
        count_a_less = bisect.bisect_left(a_sorted, x)
        sum_a_less = prefix_a[count_a_less]
        a_cost = x * count_a_less - sum_a_less
        
        # Calculate cost for array b
        idx = bisect.bisect_right(b_sorted, x)
        count_b_more = m - idx
        sum_b_more = suffix_b[idx]
        b_cost = sum_b_more - x * count_b_more
        
        total = a_cost + b_cost
        if total < min_ops:
            min_ops = total
    
    print(min_ops)

4. **Binary Search for Cost Calculation**: Using binary search, we efficiently determine how many elements need adjustment in each array and compute the associated costs using precomputed sums.
5. **Optimal Threshold**: By iterating through all candidates and calculating the total cost, we find the threshold `x` that results in the minimum number of operations, ensuring the solution is both optimal and efficient.
