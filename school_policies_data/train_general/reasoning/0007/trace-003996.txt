To solve this problem, we need to determine if we can travel from cell 1 to cell t using a series of one-way portals. Each portal allows movement from cell i to cell i + a_i, where a_i is a given value for each cell i.

### Approach
1. **Problem Analysis**: The problem involves moving through cells using portals that only allow forward movement. The key insight is that once we move past cell t, we cannot go back, so we need to check if we land exactly on cell t during our traversal.
2. **Simulation**: Starting from cell 1, we simulate the movement through each portal. For each cell i, we move to cell i + a_i. We continue this process until we either reach cell t, pass it, or reach the end of the cells (cell n).
3. **Termination Conditions**: The loop stops if we reach cell t (output "YES") or if we exceed cell t (output "NO").

### Solution Code
```python
n, t = map(int, input().split())
a = list(map(int, input().split()))

current = 1
while current < t:
    current += a[current - 1]

print("YES" if current == t else "NO")
```

### Explanation
1. **Reading Input**: The input consists of two integers n (number of cells) and t (target cell), followed by a list of integers representing the portals.
2. **Simulating Movement**: Starting from cell 1, we use each portal to move forward according to the value of a_i. This continues until we either reach or exceed the target cell t.
3. **Check Result**: After exiting the loop, we check if the current cell is exactly t. If it is, we print "YES"; otherwise, we print "NO".

This approach efficiently determines if the target cell is reachable by simulating the exact path taken using the portals, ensuring we do not miss any possible path while adhering to the constraints.
