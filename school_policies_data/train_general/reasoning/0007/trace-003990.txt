To solve this problem, we need to determine the maximum number of toasts each friend can make given the constraints on the amount of drink, lime slices, and salt available. Each friend must make the same number of toasts, and we need to ensure that all resources are considered.

### Approach
1. **Understand the Inputs**: The problem provides several inputs including the number of friends, the number of bottles of drink, the volume of each bottle, the number of limes, slices per lime, the amount of salt, and the required amounts per toast for drink and salt.

2. **Calculate Resource Constraints**:
   - **Drink**: The total amount of drink available is the product of the number of bottles and the volume per bottle. Each toast per friend requires a certain amount of drink, so we need to determine how many rounds of toasts can be made with the available drink.
   - **Lime Slices**: Each toast requires one lime slice per friend. The total number of slices is the product of the number of limes and slices per lime. We need to determine how many rounds of toasts these slices can support.
   - **Salt**: Each toast requires a certain amount of salt per friend. We need to determine how many rounds of toasts the available salt can support.

3. **Determine the Limiting Factor**: The maximum number of toasts each friend can make is constrained by the smallest number of rounds determined by the drink, lime slices, and salt.

### Solution Code
```python
def main():
    n, k, l, c, d, p, nl, np = map(int, input().split())
    drink = (k * l) // (n * nl)
    limes = (c * d) // n
    salt = p // (n * np)
    print(min(drink, limes, salt))

main()
```

### Explanation
1. **Reading Inputs**: The input values are read and parsed into integers representing the number of friends, bottles, volume per bottle, limes, slices per lime, salt, and the required amounts per toast for drink and salt.

2. **Calculating Constraints**:
   - **Drink Constraint**: The total drink available is `k * l`. Each toast round (all friends making a toast) requires `n * nl` milliliters. The number of rounds possible is `(k * l) // (n * nl)`.
   - **Lime Constraint**: The total lime slices available is `c * d`. Each toast round requires `n` slices. The number of rounds possible is `(c * d) // n`.
   - **Salt Constraint**: The total salt available is `p`. Each toast round requires `n * np` grams. The number of rounds possible is `p // (n * np)`.

3. **Determine the Result**: The result is the minimum of the three calculated constraints, as this represents the limiting factor for the number of toasts each friend can make.

This approach efficiently computes the maximum number of toasts each friend can make by considering all resource constraints and ensuring the solution is optimal.
