To solve this problem, we need to determine the number of friendship suggestions that should be sent between users of a social network based on their existing friendships. A suggestion is made between two users if they are not already friends and there exists at least one common friend between them.

### Approach
1. **Input Reading and Initialization**: Read the number of users and their friendship matrix.
2. **Bitmask Conversion**: Convert each user's friendship list into a bitmask for efficient bitwise operations. Each bit in the bitmask represents whether a user is friends with another user.
3. **Check Suggestions**: For each pair of users (u, v), check if they are not already friends. If they are not friends, check if there is any common friend by performing a bitwise AND operation on their respective friend bitmasks. If the result is non-zero, it indicates there is at least one common friend, and a suggestion should be counted.

### Solution Code
```python
n = int(input())
friends_masks = []
for _ in range(n):
    s = input().strip()
    rev = s[::-1]
    mask = int(rev, 2)
    friends_masks.append(mask)

count = 0
for u in range(n):
    for v in range(n):
        if u == v:
            continue
        # Check if u and v are already friends
        if (friends_masks[u] & (1 << v)) != 0:
            continue
        # Check if there's at least one common friend
        if (friends_masks[u] & friends_masks[v]) != 0:
            count += 1

print(count)
```

### Explanation
1. **Bitmask Conversion**: Each user's friendship list is converted into a bitmask by reversing the input string and converting it to an integer. This allows efficient bitwise operations to check for common friends.
2. **Check Friendships**: For each pair of users (u, v), we first check if they are already friends using bitwise operations. If not, we use a bitwise AND operation on their friend bitmasks to determine if there is any common friend. If the result is non-zero, it means there is at least one common friend, and a suggestion is counted.
3. **Efficiency**: The use of bitwise operations ensures that the solution runs efficiently even for the upper constraint of 2000 users, with a time complexity of O(N^2), which is feasible given the constraints.

This approach efficiently leverages bitwise operations to handle the problem constraints and provides an optimal solution for determining the number of friendship suggestions.
