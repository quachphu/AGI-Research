To solve this problem, we need to count the number of ordinary numbers from 1 to a given number \( n \). An ordinary number is defined as a positive integer where all digits are the same, such as 1, 22, 333, etc.

### Approach
1. **Understanding Ordinary Numbers**: Ordinary numbers can be generated by repeating a single digit (from 1 to 9) for different lengths. For example, numbers like 1, 11, 111, etc., are ordinary.
2. **Digit Length Analysis**: For a number \( n \) with \( m \) digits, ordinary numbers with fewer than \( m \) digits are all valid because their maximum value (e.g., 999 for 3 digits) is less than the minimum value of an \( m \)-digit number (e.g., 1000 for 4 digits).
3. **Efficient Counting**: For each test case, we first count all ordinary numbers with fewer digits than \( n \). Then, we check each possible ordinary number with the same number of digits as \( n \) to see if it is less than or equal to \( n \).

### Solution Code
```python
def count_ordinary_numbers():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    for i in range(1, t + 1):
        n = int(input[i])
        s = str(n)
        m = len(s)
        res = 9 * (m - 1) if m > 1 else 0
        for k in range(1, 10):
            num = int(str(k) * m)
            if num <= n:
                res += 1
        print(res)

count_ordinary_numbers()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Digit Length Calculation**: Convert the number \( n \) to a string to determine its length \( m \).
3. **Counting Ordinary Numbers**:
   - For numbers with fewer digits than \( m \), there are \( 9 \times (m - 1) \) ordinary numbers (since each digit length from 1 to \( m-1 \) contributes 9 numbers).
   - For numbers with exactly \( m \) digits, generate each possible ordinary number by repeating digits from 1 to 9 and check if they are less than or equal to \( n \).
4. **Output the Result**: For each test case, the result is computed and printed immediately.

This approach efficiently counts the ordinary numbers by leveraging the structure of these numbers and avoids unnecessary computations, ensuring it handles the upper constraint limits effectively.
