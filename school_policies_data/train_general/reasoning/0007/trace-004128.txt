To solve this problem, we need to determine the optimal accommodation plan for Mr. Takatsuki over D nights across N hotels, minimizing the total cost, followed by the number of hotel changes, and finally ensuring the lexicographically smallest path if there are still ties.

### Approach
1. **Dynamic Programming (DP) Setup**: We use a DP table where each entry `dp[j][i]` keeps track of the minimum cost, the number of hotel changes, and the path taken to stay at hotel `i` on night `j+1` (0-based index).
2. **Initialization**: For the first night, initialize the DP table with the prices of each hotel for the first night, zero changes, and the hotel itself as the starting path.
3. **DP Transition**: For each subsequent night, compute the cost, number of changes, and path for staying at each hotel by considering all possible previous hotels. Update the DP table with the optimal values based on the minimum cost, then the least changes, and finally the lexicographically smallest path.
4. **Result Extraction**: After processing all nights, determine the optimal path from the DP table entries of the last night by considering the minimum cost, least changes, and lexicographical order.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    D = int(input[ptr])
    ptr += 1

    prices = []
    for _ in range(N):
        row = list(map(int, input[ptr:ptr+D]))
        ptr += D
        prices.append(row)

    INF = float('inf')
    dp = [[(INF, INF, []) for _ in range(N)] for _ in range(D)]

    # Initialize day 0
    for i in range(N):
        cost = prices[i][0]
        dp[0][i] = (cost, 0, [i + 1])

    # Fill DP table
    for j in range(1, D):
        for i in range(N):
            min_cost = INF
            min_changes = INF
            min_path = []
            for k in range(N):
                prev_cost, prev_changes, prev_path = dp[j-1][k]
                if prev_cost == INF:
                    continue
                current_cost = prev_cost + prices[i][j]
                current_changes = prev_changes + (0 if k == i else 1)
                current_path = prev_path.copy()
                current_path.append(i + 1)
                # Update if better
                if current_cost < min_cost:
                    min_cost = current_cost
                    min_changes = current_changes
                    min_path = current_path
                elif current_cost == min_cost:
                    if current_changes < min_changes:
                        min_changes = current_changes
                        min_path = current_path
                    elif current_changes == min_changes:
                        # Lex order comparison
                        is_smaller = False
                        for pos in range(len(current_path)):
                            if current_path[pos] < min_path[pos]:
                                is_smaller = True
                                break
                            elif current_path[pos] > min_path[pos]:
                                break
                        if is_smaller:
                            min_path = current_path
            # Assign the best state to dp[j][i]
            if min_cost != INF:
                dp[j][i] = (min_cost, min_changes, min_path)

    # Find the best path in the last day
    best_cost = INF
    best_changes = INF
    best_path = []
    for i in range(N):
        cost, changes, path = dp[D-1][i]
        if cost < best_cost:
            best_cost = cost
            best_changes = changes
            best_path = path
        elif cost == best_cost:
            if changes < best_changes:
                best_changes = changes
                best_path = path
            elif changes == best_changes:
                # Lex order comparison
                is_smaller = False
                for pos in range(len(path)):
                    if pos >= len(best_path):
                        break
                    if path[pos] < best_path[pos]:
                        is_smaller = True
                        break
                    elif path[pos] > best_path[pos]:
                        break
                if is_smaller:
                    best_path = path
                elif len(path) < len(best_path):
                    best_path = path

    print(f"{best_cost} {best_changes}")
    for hotel in best_path:
        print(hotel)

if __name__ == "__main__":
    main()
```

3. **DP Transition**: For each subsequent night, the DP table is updated by considering all possible previous hotels, calculating the cost, changes, and path, and choosing the optimal values based on the problem's criteria.
4. **Result Extraction**: After processing all nights, the optimal path is determined by evaluating the minimum cost, least changes, and lexicographical order from the DP table entries of the last night.
