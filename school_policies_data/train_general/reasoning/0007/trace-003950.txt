To solve this problem, we need to determine the maximum number of apples Amr can collect from apple trees located on a coordinate line. Amr starts at position 0 and alternates directions after collecting apples from each tree. The challenge is to simulate his movement and calculate the optimal path to maximize the apples collected.

### Approach
1. **Split Trees by Direction**: Separate the apple trees into two groups: those on the left (negative positions) and those on the right (positive positions).
2. **Sort Trees**: Sort the left trees in descending order (closest to 0 first) and the right trees in ascending order (closest to 0 first).
3. **Simulate Collection**: Simulate Amr's movement starting both directions (left and right). For each simulation, track the apples collected as he alternates directions until no more trees can be collected in the current direction.
4. **Calculate Maximum Apples**: Compare the results from both simulations (starting left and starting right) and return the maximum value.

### Solution Code
```python
n = int(input())
left = []   # Trees with negative x, sorted in descending order (closest to zero first)
right = []  # Trees with positive x, sorted in ascending order (closest to zero first)

for _ in range(n):
    x, a = map(int, input().split())
    if x < 0:
        left.append((x, a))
    else:
        right.append((x, a))

left.sort(reverse=True, key=lambda t: t[0])  # Sort negative x in descending order
right.sort(key=lambda t: t[0])               # Sort positive x in ascending order

def simulate(start_left):
    total = 0
    l_ptr = 0
    r_ptr = 0
    current_dir = 'left' if start_left else 'right'
    
    while True:
        collected = False
        if current_dir == 'left':
            if l_ptr < len(left):
                total += left[l_ptr][1]
                l_ptr += 1
                collected = True
                current_dir = 'right'
        else:
            if r_ptr < len(right):
                total += right[r_ptr][1]
                r_ptr += 1
                collected = True
                current_dir = 'left'
        if not collected:
            break
    return total

max_apples = max(simulate(True), simulate(False))
print(max_apples)
```

### Explanation
1. **Input Handling and Tree Separation**: The input is read and split into two lists based on the tree positions (left for negative values, right for positive values).
2. **Sorting**: Left trees are sorted in descending order to prioritize those closest to 0, while right trees are sorted in ascending order for the same reason.
3. **Simulation Function**: The `simulate` function starts in either the left or right direction, collects apples from the closest tree in the current direction, then switches directions. This process continues until no more trees can be collected in the current direction.
4. **Result Calculation**: The maximum apples collected from both starting directions (left and right) are compared, and the highest value is printed as the result.

This approach efficiently handles the problem constraints and ensures that Amr's optimal path is considered by simulating both possible starting directions and choosing the best outcome.
