To solve this problem, we need to determine the shortest path from cell A to cell B on an infinite 2D grid, avoiding a forbidden cell F. The solution involves calculating the Manhattan distance between A and B and checking if F lies on any direct path between them, which would require a detour.

### Approach
1. **Manhattan Distance Calculation**: The shortest path between two points on a grid (without obstacles) is given by the Manhattan distance, which is the sum of the absolute differences of their coordinates.
2. **Check for Obstruction**: Determine if the forbidden cell F lies on the direct path between A and B. This is true if:
   - A and B are in the same row, and F is in the same row and between their columns.
   - A and B are in the same column, and F is in the same column and between their rows.
3. **Adjust Path for Obstruction**: If F obstructs the direct path, the shortest path length is increased by 2 to account for the necessary detour.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        xA = int(input[ptr])
        yA = int(input[ptr + 1])
        ptr += 2
        xB = int(input[ptr])
        yB = int(input[ptr + 1])
        ptr += 2
        xF = int(input[ptr])
        yF = int(input[ptr + 1])
        ptr += 2
        
        d = abs(xA - xB) + abs(yA - yB)
        same_row = (yA == yB)
        same_col = (xA == xB)
        
        if same_row:
            if yF == yA:
                min_x = min(xA, xB)
                max_x = max(xA, xB)
                if min_x <= xF <= max_x:
                    d += 2
        elif same_col:
            if xF == xA:
                min_y = min(yA, yB)
                max_y = max(yA, yB)
                if min_y <= yF <= max_y:
                    d += 2
        print(d)

if __name__ == "__main__":
    main()
```
