To solve this problem, we need to maximize the points Vasya can get by destroying geometric figures in an optimal order. The points depend on the current factor, which increases as more figures are destroyed. The challenge is to determine the optimal order of destruction to maximize the total points.

### Approach
1. **Understand Factor Changes**: The factor starts at 1 and increases after destroying a certain number of figures. The factor changes at specific thresholds provided in the input.
2. **Calculate Capacities for Each Factor**: Determine the number of figures that can be destroyed under each factor. This involves computing the range of positions for each factor based on the given thresholds.
3. **Sort Figures by Cost**: To maximize points, figures with higher costs should be destroyed under higher factors. Thus, we sort the figures by their cost in descending order.
4. **Assign Figures to Factors**: Distribute the figures to the highest possible factors first, utilizing the computed capacities for each factor. This ensures that higher cost figures contribute more points by being destroyed under higher factors.

### Solution Code
```python
n = int(input())
types = []
for _ in range(n):
    ki, ci = map(int, input().split())
    types.append((ki, ci))
sum_k = sum(ki for ki, ci in types)

    if i >= len(p):
        break
    p_i = p[i]
    start = current_pos + 1
    end = p_i
    if start > sum_k:
        break
    actual_end = min(end, sum_k)
    available = actual_end - start + 1
    if available > 0:
        capacities.append((i + 1, available))
        current_pos = end
        if current_pos >= sum_k:
            break

remaining = sum_k - current_pos
if remaining > 0:
    capacities.append((t + 1, remaining))

capacities.sort(reverse=True, key=lambda x: x[0])
figure_types = sorted([(ci, ki) for ki, ci in types], reverse=True)

for f, cap in capacities:

    for i in range(len(figure_types)):

            break

        figure_types[i] = (ci, ki - take)
        remaining_cap -= take
```
