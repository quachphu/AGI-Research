To solve this problem, we need to determine the new parent representation of cities in Berland after moving the capital from city r1 to city r2. The original tree structure is rooted at r1, and we need to re-root it at r2 while maintaining the same tree structure.

### Approach
1. **Input Reading**: Read the number of cities (n), the old capital (r1), the new capital (r2), and the parent list for the original tree rooted at r1.
2. **Build the Adjacency List**: Construct the adjacency list of the tree using the given parent list. This list will help us traverse the tree efficiently.
3. **Breadth-First Search (BFS)**: Perform BFS starting from the new capital (r2) to determine the new parent relationships. This traversal will give us the parent of each node in the tree rooted at r2.
4. **Output the Result**: Collect the parent information for all nodes except the new capital (r2) and print them in increasing order of their indices.

### Solution Code
```python
import sys
from collections import deque

def main():
    n, r1, r2 = map(int, sys.stdin.readline().split())
    p_list = list(map(int, sys.stdin.readline().split()))
    
    # Build adjacency list
    adj = [[] for _ in range(n + 1)]
    sorted_nodes = [i for i in range(1, n+1) if i != r1]
    
    for i in range(n-1):
        node = sorted_nodes[i]
        parent = p_list[i]
        adj[node].append(parent)
        adj[parent].append(node)
    
    # BFS to find new parents
    parent_new = [0] * (n + 1)
    visited = [False] * (n + 1)
    q = deque([r2])
    visited[r2] = True
    
    while q:
        u = q.popleft()
        for v in adj[u]:
            if not visited[v]:
                visited[v] = True
                parent_new[v] = u
                q.append(v)
    
    # Collect and output the result
    output_nodes = sorted([i for i in range(1, n+1) if i != r2])
    result = [str(parent_new[node]) for node in output_nodes]
    print(' '.join(result))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Input Reading**: The input is read and parsed to get the number of cities, old capital, new capital, and the parent list.
2. **Adjacency List Construction**: The adjacency list is built by iterating over each node (excluding the old capital r1) and connecting it to its parent as given in the input list.
3. **BFS Traversal**: Starting from the new capital (r2), we traverse the tree using BFS. During traversal, we keep track of the parent of each node in the new tree structure.
4. **Result Collection and Output**: After BFS traversal, we collect the parent information for all nodes except the new capital (r2), sort them by their indices, and print the results.

This approach ensures that we efficiently re-root the tree and determine the new parent relationships using BFS, which runs in O(n) time complexity, making it suitable for large input sizes.
