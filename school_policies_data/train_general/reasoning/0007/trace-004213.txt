To solve this problem, we need to determine the optimal gestures for AtCoDeer to maximize his score in a game of Rock-paper-scissors against TopCoDeer, while adhering to the constraint that the number of Paper plays must never exceed the number of Rock plays after each turn.

### Approach
1. **Understanding the Game Dynamics**:
   - Rock ('g') beats Scissors, Paper ('p') beats Rock.
   - The score is calculated as the number of wins minus the number of losses.
   - The constraint is that after each turn, the number of Paper plays by AtCoDeer must not exceed the number of Rock plays.

2. **Optimal Strategy**:
   - For each turn, based on TopCoDeer's move, determine the best possible move for AtCoDeer:
     - If TopCoDeer plays Rock ('g'), AtCoDeer should play Paper ('p') if it doesn't violate the constraint, otherwise play Rock ('g').
     - If TopCoDeer plays Paper ('p'), AtCoDeer should play Paper ('p') if possible to avoid a loss, otherwise play Rock ('g').

3. **Track Counts and Score**:
   - Maintain counts of Rock and Paper plays by AtCoDeer.
   - Adjust the score based on the outcome of each turn.

### Solution Code
```python
s = input().strip()
current_g = 0
current_p = 0
score = 0

for c in s:
    if c == 'g':
        if current_p + 1 <= current_g:
            current_p += 1
            score += 1
        else:
            current_g += 1
    else:
        if current_p + 1 <= current_g:
            current_p += 1
        else:
            current_g += 1
            score -= 1

print(score)
```

### Explanation
1. **Initialization**:
   - `current_g` and `current_p` track the number of Rock and Paper plays by AtCoDeer respectively.
   - `score` keeps track of the current score.

2. **Iterate Through Each Turn**:
   - For each character in the input string (TopCoDeer's moves):
     - **TopCoDeer plays Rock ('g')**:
       - Check if AtCoDeer can play Paper without violating the constraint. If yes, play Paper and increase the score.
       - If not, play Rock.
     - **TopCoDeer plays Paper ('p')**:
       - Check if AtCoDeer can play Paper. If yes, play Paper to avoid a loss.
       - If not, play Rock, which results in a loss and decreases the score.

3. **Output the Result**:
   - After processing all turns, print the final score.

This approach ensures that AtCoDeer's moves are optimal under the given constraints, leading to the maximum possible score. The algorithm efficiently processes each turn in linear time, making it suitable for large input sizes up to 100,000 turns.
