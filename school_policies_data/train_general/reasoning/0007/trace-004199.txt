2. **Check for Right-Angled Triangle**: For each modified point, check if the triplet formed by replacing the original point with the modified point forms a right-angled triangle with non-zero area. This involves:
   - **Non-Zero Area Check**: Using the cross product to ensure the points are not collinear.

def is_rat(p1, p2, p3):
    # Calculate twice the area to check for collinearity
    area_x2 = (p2[0] - p1[0]) * (p3[1] - p1[1]) - (p2[1] - p1[1]) * (p3[0] - p1[0])
    if area_x2 == 0:

    # Check Pythagorean theorem conditions
    return (d1_sq + d2_sq == d3_sq) or (d1_sq + d3_sq == d2_sq) or (d2_sq + d3_sq == d1_sq)
