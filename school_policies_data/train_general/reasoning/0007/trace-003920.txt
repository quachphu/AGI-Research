To solve this problem, we need to determine the number of black tiles after each day's operation. Each day, Taro checks a rectangular area and paints it black if all tiles in the area are white. ### Approach
1. **Track Existing Rectangles**: Maintain a list of non-overlapping rectangles that have been painted black. Each rectangle is represented by its coordinates.
2. **Binary Search for Efficiency**: Use binary search to quickly find potential overlapping rectangles by sorting the existing rectangles based on their starting x-coordinate.
3. **Overlap Check**: For each new rectangle, check if it overlaps with any existing rectangles by comparing their x and y intervals. If no overlap is found, the new rectangle is added to the list of existing rectangles.

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    W = int(input[ptr])
    ptr += 1
    H = int(input[ptr])
    ptr += 1
    N = int(input[ptr])
    ptr += 1

    existing = []
    total = 0

    for _ in range(N):
        ax = int(input[ptr])
        ptr += 1
        ay = int(input[ptr])
        ptr += 1
        bx = int(input[ptr])
        ptr += 1
        by = int(input[ptr])
        ptr += 1

        current_area = (bx - ax + 1) * (by - ay + 1)
        overlap = False

        index = bisect.bisect_right(existing, (bx + 1,))  # Find first index where ax > new_bx

        for i in range(index):
            ex_ax, ex_ay, ex_bx, ex_by = existing[i]
            if ex_bx >= ax:
                if not (ex_ay > by or ex_by < ay):
                    overlap = True
                    break

        if not overlap:
            total += current_area
            bisect.insort(existing, (ax, ay, bx, by))

        print(total)
