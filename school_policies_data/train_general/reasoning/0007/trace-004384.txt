To solve this problem, we need to determine the number of particles that exit a series of planes after a particle of decay age \( k \) is shot through them. Each plane can create a copy of the particle moving in the opposite direction with a decay age reduced by 1. The solution involves dynamic programming (DP) to efficiently compute the number of particles that exit the planes.

### Approach
1. **Dynamic Programming (DP) Setup**: Use two DP tables to track the number of particles exiting when moving left (L) and right (R) from each plane with a given decay age.
2. **Base Cases**: For decay age 1, particles do not create copies and exit immediately.
3. **Prefix and Suffix Sums**: Optimize the computation of sums using prefix sums for right-moving particles and suffix sums for left-moving particles to reduce the time complexity.
4. **Iterative Calculation**: Fill the DP tables iteratively for each decay age from 2 to \( k-1 \) using the precomputed sums.

### Solution Code
```python
MOD = 10**9 + 7

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    if k == 1:
        print(1)
        continue
    max_d = k - 1
    # Initialize L and R arrays with dimensions (n+2) x (max_d+1) to handle 1-based indexing
    L = [[0] * (max_d + 1) for _ in range(n + 2)]
    R = [[0] * (max_d + 1) for _ in range(n + 2)]
    
    # Base case: d = 1
    for i in range(1, n + 1):
        L[i][1] = 1
        R[i][1] = 1
    
    # Fill the DP tables for d from 2 to max_d
    for d in range(2, max_d + 1):
        # Compute prefix sums for R[j][d-1]
        prefix_R = [0] * (n + 1)
        for j in range(1, n + 1):
            prefix_R[j] = (prefix_R[j-1] + R[j][d-1]) % MOD
        
        # Update L[i][d] for all i
        for i in range(1, n + 1):
            L[i][d] = (1 + prefix_R[i-1]) % MOD
        
        # Compute suffix sums for L[i][d-1]
        suffix_L = [0] * (n + 2)
        for i in range(n, 0, -1):
            suffix_L[i] = (suffix_L[i+1] + L[i][d-1]) % MOD
        
        # Update R[j][d] for all j
        for j in range(1, n + 1):
            R[j][d] = (1 + suffix_L[j+1]) % MOD
    
    # Calculate the total sum of L[i][max_d] for i=1 to n
    total = 0
    for i in range(1, n + 1):
        total = (total + L[i][max_d]) % MOD
    
    ans = (1 + total) % MOD
    print(ans)
```

4. **DP Table Updates**: Using the precomputed sums, we update the DP tables for each plane and decay age.
5. **Result Calculation**: Sum the results from the `L` table for decay age \( k-1 \) and add the initial particle to get the final count.
