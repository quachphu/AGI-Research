To solve this problem, we need to determine if each given number in a series of test cases is a power of two. A number is considered a power of two if it can be expressed as \(2^n\) where \(n\) is a non-negative integer. 

### Approach
The key insight here is recognizing that a power of two in binary representation has exactly one '1' bit followed by zeros. For example, 2 (10), 4 (100), 8 (1000), etc. 

To check if a number is a power of two efficiently:
1. Ensure the number is greater than zero (since 0 is not a power of two).
2. Use a bitwise operation to check if there is exactly one '1' bit. This can be done using the property that for a number \(X\) which is a power of two, \(X \& (X - 1)\) will be zero. This works because subtracting 1 from a power of two flips all the bits after the single '1' bit, making the bitwise AND operation result in zero.

### Solution Code
```python
import sys

def is_power_of_two():
    T = int(sys.stdin.readline())
    for _ in range(T):
        X = int(sys.stdin.readline().strip())
        if X != 0 and (X & (X - 1)) == 0:
            print(1)
        else:
            print(0)

is_power_of_two()
```

### Explanation
1. **Reading Input:** The function reads the number of test cases \(T\) from standard input.
2. **Loop Through Test Cases:** For each test case, the number \(X\) is read and checked.
3. **Check Power of Two:** For each number \(X\), the function checks if \(X\) is non-zero and if \(X \& (X - 1)\) equals zero. If both conditions are met, \(X\) is a power of two, and the function prints 1; otherwise, it prints 0.

This approach efficiently determines if a number is a power of two using bitwise operations, which runs in constant time \(O(1)\) for each test case, making the solution both optimal and easy to understand.
