To solve this problem, we need to determine if among five people there exists either a trio of mutual acquaintances or a trio of mutual strangers. This problem can be efficiently solved by modeling the relationships as a graph and checking all possible triplets of people for the required conditions.

### Approach
1. **Graph Representation**: Use an adjacency matrix to represent the acquaintances among the five people. The matrix will be symmetric since the acquaintance relationship is mutual.
2. **Triplet Check**: Generate all possible triplets of people (combinations of three distinct individuals) and check each triplet for two conditions:
   - All three pairs in the triplet are acquainted.
   - None of the three pairs in the triplet are acquainted.
3. **Immediate Termination**: If any triplet satisfies either condition, immediately output "WIN" and terminate. If no such triplet is found after checking all possibilities, output "FAIL".

### Solution Code
```python
import itertools

def check_ramsey():
    m = int(input())
    acquainted = [[False] * 6 for _ in range(6)]  # Using 1-based indexing

    for _ in range(m):
        a, b = map(int, input().split())
        acquainted[a][b] = True
        acquainted[b][a] = True

    for trio in itertools.combinations(range(1, 6), 3):
        x, y, z = trio
        # Check for all acquainted
        if acquainted[x][y] and acquainted[y][z] and acquainted[x][z]:
            print("WIN")
            return
        # Check for all unacquainted
        if not acquainted[x][y] and not acquainted[y][z] and not acquainted[x][z]:
            print("WIN")
            return

    print("FAIL")

check_ramsey()
```

### Explanation
1. **Graph Representation**: The adjacency matrix `acquainted` is initialized to handle 1-based indexing for the five people. Each input pair updates both entries in the matrix to maintain symmetry.
2. **Triplet Generation**: Using `itertools.combinations`, we generate all possible groups of three people from the five. For each triplet, we check if all three pairs are either acquainted or unacquainted.
3. **Efficiency**: The algorithm efficiently checks each triplet and terminates early if a valid trio is found, ensuring optimal performance given the small problem size (only 10 triplets to check).

This approach ensures that we thoroughly check all possible configurations of triplets, adhering to the problem constraints and efficiently determining the result.
