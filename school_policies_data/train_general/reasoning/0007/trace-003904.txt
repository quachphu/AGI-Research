To solve this problem, we need to determine the ID of the student who receives the last candy when the teacher distributes M candies starting from a given student S in a circular manner among N students.

### Approach
The key insight here is to recognize that the distribution of candies can be modeled using modular arithmetic. Given that the students are arranged in a circle, after each full cycle through all students, the distribution continues from the start. The problem can be broken down into the following steps:

1. **Calculate the Effective Position**: Starting from student S, the position of the last candy can be determined by considering the total number of candies M. This is done by calculating the effective position using modular arithmetic.
2. **Modular Arithmetic**: The effective position is computed using the formula `(S - 1 + M) % N`. This formula adjusts the starting position (S) by converting it to a zero-based index, adds the number of candies (M), and then takes the modulus with N to handle the circular nature.
3. **Adjust for Zero-Based Index**: If the result of the modulus operation is zero, it means the last candy falls exactly at the last student (N), otherwise, it is the result of the modulus operation converted back to a 1-based index.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        N = int(input[idx])
        M = int(input[idx+1])
        S = int(input[idx+2])
        idx += 3
        mod = (S - 1 + M) % N
        print(mod if mod != 0 else N)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints where input size can be large.
2. **Loop Through Test Cases**: For each test case, we extract the values of N (number of students), M (number of candies), and S (starting student ID).
3. **Effective Position Calculation**: Using the formula `(S - 1 + M) % N`, we compute the position of the last candy. This formula converts the starting position to a zero-based index, adds the number of candies, and then applies the modulus operation to handle the circular distribution.
4. **Adjust for Zero-Based Index**: If the result of the modulus operation is zero, it means the last candy falls on the last student (ID N). Otherwise, the result is directly the student ID.

This approach efficiently handles the constraints and ensures that the solution is computed in constant time O(1) for each test case, making it suitable for large input sizes.
