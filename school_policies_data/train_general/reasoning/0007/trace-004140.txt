To solve this problem, we need to determine the winner of a game where Monocarp and Bicarp take turns replacing erased digits (denoted by '?') in a bus ticket. The ticket is considered happy if the sum of the first half of the digits equals the sum of the second half. Monocarp aims to prevent this, while Bicarp aims to achieve it.

### Approach
1. **Split the Ticket**: Divide the ticket into two halves.
2. **Calculate Known Sums**: Compute the sum of known digits in both halves.
3. **Count Erased Digits**: Count the number of '?' in each half.
4. **Compute Difference**: Calculate the initial difference (D) between the sums of the known digits in the two halves.
5. **Determine Contribution**: Calculate the contribution (C) from the erased digits based on their positions (left or right half).
6. **Check Winning Condition**: Determine if Bicarp can balance the sums to make the ticket happy.

### Solution Code
```python
n = int(input())
ticket = input().strip()

half = n // 2
left = ticket[:half]
right = ticket[half:]

def process_half(s):
    total = 0
    cnt = 0
    for c in s:
        if c == '?':
            cnt += 1
        else:
            total += int(c)
    return total, cnt

left_sum, left_q = process_half(left)
right_sum, right_q = process_half(right)

D = left_sum - right_sum
diff_q = left_q - right_q
C = (diff_q * 9) // 2

if D + C == 0:
    print("Bicarp")
else:
    print("Monocarp")
```

### Explanation
1. **Split the Ticket**: The ticket is divided into two halves to handle each part separately.
2. **Calculate Known Sums and Erased Counts**: For each half, compute the sum of the known digits and count the number of '?'.
3. **Initial Difference (D)**: The difference between the sums of the known digits in the left and right halves.
4. **Contribution from Erased Digits (C)**: The contribution is calculated based on the difference in the number of '?' between the two halves. Each '?' in the left half can contribute up to 9, while each '?' in the right half can subtract up to 9. The optimal play results in an average contribution of 4.5 per '?' difference.
5. **Check Balance**: If the initial difference (D) combined with the contribution (C) results in zero, Bicarp wins; otherwise, Monocarp wins.

This approach efficiently determines the winner by leveraging the properties of optimal play and the structure of the problem, ensuring a solution in linear time.
