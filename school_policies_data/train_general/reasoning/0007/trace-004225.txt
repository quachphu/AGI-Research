Strings A and B are called anagrams if it's possible to rearrange the letters of string A using all the original letters exactly once and achieve string B; in other words A and B are permutations of each other. For example, remote and meteor are anagrams, race and race are anagrams as well, while seat and tease aren't anagrams as tease contains an extra 'e'.

String A is called a subsequence of string B if A can be obtained from B by removing some (possibly none) characters. For example, cat is a subsequence of scratch, rage is a subsequence of rage, and tame is not a subsequence of steam.

String A is lexicographically smaller than string B of the same length if at the first position where A and B differ A contains a letter which is earlier in the alphabet than the corresponding letter in B.

To solve this problem, we need to find the longest string that is an anagram of a subsequence of every string in a given set. If there are multiple such strings of maximum length, we choose the lexicographically smallest one. If no such string exists, we return "no such string".

### Approach
1. **Character Frequency Analysis**: For each character from 'a' to 'z', determine the minimum frequency across all input strings. This is because a valid anagram must not have more occurrences of any character than the minimum present in each string.
2. **Construct Result**: Using the minimum frequencies, construct the result string by iterating through characters from 'a' to 'z'. This ensures the lexicographically smallest order.
3. **Check Validity**: If the constructed result is empty, output "no such string". Otherwise, output the constructed string.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    strings = [sys.stdin.readline().strip() for _ in range(n)]
    
    # Initialize min_counts for each character
    min_counts = {}
    for c in 'abcdefghijklmnopqrstuvwxyz':
        min_counts[c] = float('inf')
    
    for s in strings:
        count = {}
        for c in s:
            count[c] = count.get(c, 0) + 1
        for c in 'abcdefghijklmnopqrstuvwxyz':
            current = count.get(c, 0)
            if current < min_counts[c]:
                min_counts[c] = current
    
    result = []
    for c in 'abcdefghijklmnopqrstuvwxyz':
        if min_counts[c] > 0:
            result.append(c * min_counts[c])
    
    final = ''.join(result)
    print(final if final else 'no such string')

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read, including the number of strings and the strings themselves.
2. **Character Frequency Calculation**: For each character from 'a' to 'z', compute the minimum frequency across all strings. This ensures that the resulting string can be an anagram of a subsequence of each input string.
3. **Constructing the Result**: By iterating through characters in alphabetical order, we append each character the number of times equal to its minimum frequency. This guarantees the lexicographically smallest result.
4. **Output**: If the constructed string is empty, it means no valid string exists, so we print "no such string". Otherwise, the constructed string is printed.

This approach efficiently computes the required result by leveraging character frequency analysis and ensures correctness by adhering to the problem constraints and requirements.
