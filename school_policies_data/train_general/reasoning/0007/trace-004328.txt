To solve this problem, we need to determine the maximum number of points you can gain by optimally using a secret technique that allows you to skip your opponent's turn up to `k` times. The goal is to maximize the points by strategically using skips to ensure you land the killing blow on as many monsters as possible.

### Approach
1. **Understanding the Fight Dynamics**:
   - Each monster is attacked alternately by you and your opponent until it is dead.
   - You gain a point if your attack kills the monster, while your opponent's kill does not give you any points.

2. **Base Points Calculation**:
   - For each monster, calculate the remainder of its health when divided by the sum of your and your opponent's attack powers (`a + b`).
   - If this remainder is within your attack power (`a`), you will kill the monster in the normal scenario without any skips, earning a base point.

3. **Optimal Skip Usage**:
   - For monsters not killed by you in the normal scenario, calculate the minimum number of skips needed to ensure you land the killing blow. This is derived from the remainder health after accounting for the combined attack power cycles.
   - Sort these required skips in ascending order and use them greedily to maximize the number of points within the allowed `k` skips.

### Solution Code
```python
n, a, b, k = map(int, input().split())
h_list = list(map(int, input().split()))
a_plus_b = a + b
base = 0
required_skips = []

for hi in h_list:
    rem = hi % a_plus_b
    if rem == 0:
        rem = a_plus_b
    if rem <= a:
        base += 1
    else:
        s = (rem + a - 1) // a - 1
        required_skips.append(s)

required_skips.sort()
sum_skips = 0
count = 0

for s in required_skips:
    if sum_skips + s <= k:
        sum_skips += s
        count += 1
    else:
        break

print(base + count)
```

### Explanation
1. **Base Points Calculation**:
   - For each monster, if the remainder of its health modulo (`a + b`) is within your attack power `a`, you get a point without any skips.

2. **Skip Calculation**:
   - For monsters not killed by you initially, calculate the minimum skips needed. This is derived by determining how many additional attacks (skips) are needed to reduce the remainder health to zero using your attack power alone.

3. **Greedy Skip Usage**:
   - Sort the required skips and use the smallest values first to maximize the number of monsters you can kill with the given `k` skips.

This approach ensures that we maximize the points by efficiently using the allowed skips on monsters where they provide the highest benefit.
