### Approach
1. **Understanding the Problem**: Each permutation represents the order in which clients visited the doctor. We need to find common contiguous subarrays in all permutations after trimming some prefix and suffix.

2. **Key Insight**: A common contiguous subarray across all permutations must appear in the same order in each permutation. This means that the next element for any given element in the subarray must be consistent across all permutations.

3. **Building Next Arrays**: For each permutation, create a dictionary that maps each element to its next element in the sequence. This helps in determining the order of elements.

4. **Merged Next Array**: Construct a merged next array where each element's next element is the same across all permutations. If there is any discrepancy, the next element is set to `None`.

5. **Dynamic Programming (DP)**: Use a DP approach to count all possible valid subarrays. For each element, calculate the number of valid subarrays starting from that element by following the merged next array.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n, m = int(input[ptr]), int(input[ptr+1])
    ptr += 2

    next_perms = []
    for _ in range(m):
        perm = list(map(int, input[ptr:ptr+n]))
        ptr += n
        next_dict = {}
        for j in range(n):
            if j < n-1:
                next_dict[perm[j]] = perm[j+1]
            else:
                next_dict[perm[j]] = None
        next_perms.append(next_dict)

    merged_next = {}
    for u in range(1, n+1):
        first = next_perms[0].get(u)
        all_same = True
        for i in range(1, m):
            if next_perms[i].get(u) != first:
                all_same = False
                break
        if all_same:
            merged_next[u] = first
        else:
            merged_next[u] = None

    visited = [False] * (n + 1)
    dp = [0] * (n + 1)

    for u in range(1, n + 1):
        if not visited[u]:
            chain = []
            current = u
            while current is not None and not visited[current]:
                visited[current] = True
                chain.append(current)
                current = merged_next.get(current)
            # Process the chain in reverse order
            for node in reversed(chain):
                next_node = merged_next.get(node)
                if next_node is not None:
                    dp[node] = 1 + dp[next_node]
                else:
                    dp[node] = 1

    print(sum(dp[1:n+1]))

if __name__ == "__main__":
    main()
```

2. **Building Next Arrays**: For each permutation, a dictionary is created to map each element to its next element in the sequence.

3. **Merged Next Array**: For each element, check if the next element is the same across all permutations. If so, it is added to the merged next array; otherwise, it is set to `None`.

4. **Dynamic Programming (DP)**: Using a DP array, the number of valid subarrays starting from each element is calculated. This is done by processing elements in reverse order of their chains in the merged next array, ensuring that each element's count includes all valid subarrays starting from it.

5. **Summing Results**: The results from the DP array are summed to get the total number of valid subarrays, which is printed as the result.

This approach efficiently determines the common contiguous subarrays across all permutations, leveraging the merged next array and dynamic programming to ensure optimal performance.
