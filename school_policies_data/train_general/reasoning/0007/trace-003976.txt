To solve this problem, we need to efficiently determine which points lie within a given rectangular range for multiple queries. Given the constraints, a brute-force approach would be too slow, so we need an optimized solution using sorting and binary search.

### Approach
1. **Data Preprocessing**:
   - Read all points and store them with their original indices.
   - Sort the points by their x-coordinate, and then by their y-coordinate. This allows us to efficiently group points by their x-coordinate.

2. **Grouping Points by X-Coordinate**:
   - Group the sorted points by their x-coordinate. For each group (points with the same x-coordinate), store their y-coordinates and original indices sorted by y-coordinate. This helps in efficiently querying the y-range for each x-group.

3. **Query Processing**:
   - For each query, determine the range of x-values that fall within the query's x-range using binary search.
   - For each x-value in this range, use binary search again to find the y-values that fall within the query's y-range and collect their indices.
   - Sort the collected indices and output them.

### Solution Code
```python
import bisect
import sys
from itertools import groupby

def main():
    input = sys.stdin.read().split()
    ptr = 0

    n = int(input[ptr])
    ptr += 1

    points = []
    for i in range(n):
        x = int(input[ptr])
        y = int(input[ptr + 1])
        ptr += 2
        points.append((x, y, i))

    points.sort(key=lambda p: (p[0], p[1]))

    sorted_x = []
    x_to_ys = []
    for key, group in groupby(points, key=lambda p: p[0]):
        ys_ids = [(p[1], p[2]) for p in group]
        sorted_x.append(key)
        x_to_ys.append(ys_ids)

    q = int(input[ptr])
    ptr += 1

    for _ in range(q):
        sx = int(input[ptr])
        tx = int(input[ptr + 1])
        sy = int(input[ptr + 2])
        ty = int(input[ptr + 3])
        ptr += 4

        left = bisect.bisect_left(sorted_x, sx)
        right = bisect.bisect_right(sorted_x, tx)

        res = []
        for i in range(left, right):
            ys_list = x_to_ys[i]
            low = (sy, -10**18)
            high = (ty, 10**18)
            start = bisect.bisect_left(ys_list, low)
            end = bisect.bisect_right(ys_list, high)
            for j in range(start, end):
                res.append(ys_list[j][1])

        res.sort()
        for point_id in res:
            print(point_id)
        print()

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the large possible input size.
2. **Sorting and Grouping**: Points are sorted by x and y coordinates. They are then grouped by x-coordinate, with each group's y-coordinates and indices stored in sorted order.
3. **Processing Queries**:
   - For each query, binary search is used to quickly find the valid x-range.
   - For each valid x-coordinate, another binary search determines the valid y-range within that x-group.
   - The results are collected, sorted, and printed as required.

This approach efficiently narrows down the points to check using binary search, ensuring that each query is processed in logarithmic time relative to the number of points, making it suitable for large input sizes.
