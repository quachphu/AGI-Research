To solve this problem, we need to determine if we can distribute red and blue beans into packets such that each packet meets specific constraints. Each packet must contain at least one red and one blue bean, and the difference between the number of red and blue beans in each packet must not exceed a given value \( d \).

### Approach
The key insight is to check if the larger quantity of beans (either red or blue) can be distributed such that the maximum difference constraint is satisfied. Specifically, we need to ensure that the larger quantity does not exceed the smaller quantity multiplied by \( (d + 1) \). This is because each packet can have at most \( d \) more beans of one color than the other, and we can form as many packets as the smaller quantity allows.

1. For each test case, read the values of red beans (\( r \)), blue beans (\( b \)), and the maximum allowed difference (\( d \)).
2. Determine the maximum and minimum values between \( r \) and \( b \).
3. Check if the maximum value is less than or equal to the minimum value multiplied by \( (d + 1) \). If true, print "YES"; otherwise, print "NO".

### Solution Code
```python
t = int(input())
for _ in range(t):
    r, b, d = map(int, input().split())
    max_val = max(r, b)
    min_val = min(r, b)
    if max_val <= min_val * (d + 1):
        print("YES")
    else:
        print("NO")
```

### Explanation
1. **Reading Input:** We start by reading the number of test cases.
2. **Processing Each Test Case:** For each test case, we read the values of \( r \), \( b \), and \( d \).
3. **Determine Maximum and Minimum Values:** We find the maximum and minimum values between \( r \) and \( b \).
4. **Check Condition:** We check if the maximum value can be distributed such that each packet (formed using the minimum value as the base) does not exceed the allowed difference \( d \). This is done by checking if the maximum value is within \( min_val \times (d + 1) \).
5. **Output Result:** Based on the condition check, we print "YES" or "NO".

This approach ensures that we efficiently determine the possibility of distributing the beans according to the given constraints using a straightforward mathematical check, making the solution both optimal and easy to understand.
