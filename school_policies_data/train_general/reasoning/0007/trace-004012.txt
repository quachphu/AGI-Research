To solve this problem, we need to find all favorite numbers \( m \) for a given positive integer \( N \) such that the quotient and remainder of \( N \) divided by \( m \) are equal. We then sum all these favorite numbers and print the result.

### Approach
1. **Understanding the Condition**: The condition \(\lfloor \frac{N}{m} \rfloor = N \bmod m\) implies that the quotient \( q \) and remainder \( r \) when \( N \) is divided by \( m \) must be equal. This leads to the equation \( N = q \times (m + 1) \) where \( q < m \).

2. **Divisors of \( N \)**: For \( N = q \times (m + 1) \) to hold, \( q \) must be a divisor of \( N \). We need to check all divisors \( q \) of \( N \) and determine if \( q < (N/q - 1) \).

3. **Efficient Calculation**: We generate all divisors of \( N \) by iterating up to the square root of \( N \). For each divisor \( q \), we compute the corresponding \( m \) as \( (N/q - 1) \) and check if \( q < m \). If true, we add \( m \) to the sum.

### Solution Code
```python
n = int(input())
divisors = set()
for i in range(1, int(n**0.5) + 1):
    if n % i == 0:
        divisors.add(i)
        divisors.add(n // i)
sum_ans = 0
for q in divisors:
    m = (n // q) - 1
    if q < m:
        sum_ans += m
print(sum_ans)
```

### Explanation
1. **Generating Divisors**: We use a set to collect all divisors of \( N \) by iterating from 1 up to \(\sqrt{N}\). For each divisor \( i \), both \( i \) and \( N/i \) are added to the set, ensuring we avoid duplicates.

2. **Checking Conditions**: For each divisor \( q \), we compute \( m \) as \( (N // q) - 1 \). We check if \( q \) is less than \( m \). If true, \( m \) is a valid favorite number and is added to the sum.

3. **Summing Valid \( m \)**: The sum of all valid \( m \) values is computed and printed as the result.

This approach efficiently generates and checks all possible divisors, ensuring the solution works within acceptable time limits even for large values of \( N \) up to \( 10^{12} \).
