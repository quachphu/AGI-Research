To solve this problem, we need to determine the maximum number of large bouquets that can be formed from given initial bouquets, where each large bouquet must consist of two or more initial bouquets and have an odd total number of flowers. Each initial bouquet can be part of at most one large bouquet.

### Approach
1. **Identify Even and Odd Bouquets**: First, count the number of initial bouquets with even and odd numbers of flowers.
2. **Form Pairs**: The maximum number of pairs (one even and one odd bouquet) is determined by the minimum of the counts of even and odd bouquets. Each valid pair forms a large bouquet with an odd sum.
3. **Form Trios from Remaining Odd Bouquets**: After forming pairs, any remaining odd bouquets can be grouped into trios. Each trio of three odd bouquets will also have an odd sum.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
even = 0
odd = 0
for num in a:
    if num % 2 == 0:
        even += 1
    else:
        odd += 1

pairs = min(even, odd)
remaining_odd = odd - pairs
trios = remaining_odd // 3
print(pairs + trios)
```

### Explanation
1. **Counting Even and Odd Bouquets**: We iterate through the list of initial bouquets to count how many have even and odd numbers of flowers.
2. **Forming Pairs**: By taking the minimum of the counts of even and odd bouquets, we determine the maximum number of valid pairs. Each pair consists of one even and one odd bouquet, ensuring the sum is odd.
3. **Forming Trios**: After forming pairs, any remaining odd bouquets are checked to see how many trios of three can be formed. Each trio of three odd bouquets will have an odd sum.

This approach efficiently maximizes the number of large bouquets by first using pairs of even and odd bouquets and then utilizing any remaining odd bouquets in trios. The solution ensures optimal use of available bouquets with a time complexity of O(n), which is efficient given the problem constraints.
