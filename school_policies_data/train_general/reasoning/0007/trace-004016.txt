To solve this problem, we need to find the lexicographically smallest string that can be formed by swapping any adjacent pair of characters up to `k` times. The solution involves a greedy approach where we move the smallest possible character as far left as possible within the allowed number of swaps.

### Approach
1. **Inversion Count Check**: First, we check if the number of swaps allowed (`k`) is sufficient to sort the string. This is determined by counting the number of inversions in the string. If `k` is greater than or equal to the number of inversions, the sorted string is the answer.
2. **Greedy Selection**: If `k` is not sufficient to sort the string, we process each position from left to right. For each position, we find the smallest character in the range that can be moved to the current position within the remaining swaps. This character is then moved to the current position, and the remaining swaps are adjusted accordingly.

### Solution Code
```python
import sys

def count_inversions(s):
    res = 0
    fenwick = [0] * 26
    for c in reversed(s):
        idx = ord(c) - ord('a')
        # Query the sum of elements less than idx
        sum_ = 0
        i = idx - 1
        while i >= 0:
            sum_ += fenwick[i]
            i = (i & (i + 1)) - 1
        res += sum_
        # Update Fenwick Tree
        i = idx
        while i < 26:
            fenwick[i] += 1
            i |= i + 1
    return res

def main():
    s = sys.stdin.readline().strip()
    k = int(sys.stdin.readline())
    sorted_s = sorted(s)
    inv_count = count_inversions(s)
    if inv_count <= k:
        print(''.join(sorted_s))
        return
    s_list = list(s)
    n = len(s_list)
    for i in range(n):
        if k <= 0:
            break
        j_max = i + k
        if j_max >= n:
            j_max = n - 1
        # Find the minimum character in s_list[i..j_max]
        min_char = s_list[i]
        min_pos = i
        for j in range(i + 1, j_max + 1):
            if s_list[j] < min_char:
                min_char = s_list[j]
                min_pos = j
        # Move the character from min_pos to i
        cost = min_pos - i
        if cost == 0:
            continue
        k -= cost
        # Remove and insert
        char = s_list.pop(min_pos)
        s_list.insert(i, char)
    print(''.join(s_list))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Inversion Count Check**: The `count_inversions` function uses a Fenwick Tree (Binary Indexed Tree) to count the number of inversions in the string. This helps determine if the string can be sorted with the given `k` swaps.
2. **Greedy Selection**: For each position in the string, we determine the smallest character that can be moved to the current position within the remaining swaps. This character is moved by popping it from its current position and inserting it at the current position, adjusting the remaining swaps accordingly.

This approach ensures that we make the lexicographically smallest possible string by greedily moving the smallest available character to the leftmost possible position within the allowed swaps. The solution efficiently handles both small and large values of `k` by first checking if the string can be sorted and then using a greedy method for the remaining cases.
