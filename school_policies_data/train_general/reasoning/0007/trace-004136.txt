To solve this problem, we need to determine which laptop Vasya will choose based on specific criteria. The chosen laptop should not be outdated by any other laptop and should be the cheapest among all non-outdated laptops.

### Approach
1. **Identify Outdated Laptops**: A laptop is considered outdated if there exists another laptop with strictly higher values in all three properties: processor speed, RAM, and HDD.
2. **Filter Non-Outdated Laptops**: Collect all laptops that are not outdated based on the above criteria.
3. **Select the Cheapest Laptop**: Among the non-outdated laptops, select the one with the lowest cost. Since all laptops have unique prices, there will be a single cheapest laptop.

### Solution Code
```python
n = int(input())
laptops = []
for i in range(n):
    parts = list(map(int, input().split()))
    speed, ram, hdd, cost = parts
    laptops.append((speed, ram, hdd, cost, i + 1))

non_outdated = []
for laptop in laptops:
    s, r, h, c, idx = laptop
    outdated = False
    for other in laptops:
        if other[0] > s and other[1] > r and other[2] > h:
            outdated = True
            break
    if not outdated:
        non_outdated.append(laptop)

min_cost = float('inf')
selected = None
for laptop in non_outdated:
    if laptop[3] < min_cost:
        min_cost = laptop[3]
        selected = laptop

print(selected[4])
```

### Explanation
1. **Reading Input**: The input is read and stored in a list of tuples, each representing a laptop's properties along with its original index.
2. **Check for Outdated Laptops**: For each laptop, we check if there exists another laptop with higher values in all three properties (speed, RAM, HDD). If such a laptop exists, the current laptop is marked as outdated.
3. **Filter Non-Outdated Laptops**: Laptops that are not marked as outdated are added to the `non_outdated` list.
4. **Select the Cheapest**: From the non-outdated list, the laptop with the minimum cost is selected, and its original index is printed.

This approach ensures that we efficiently determine the best laptop for Vasya by checking each laptop against others and then selecting the cheapest from the valid candidates. The solution runs in O(n^2) time complexity, which is feasible given the constraint \( n \leq 100 \).
