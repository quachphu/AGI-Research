To solve this problem, we need to identify the deepest nested substring within balanced parentheses in a given string. The solution involves tracking the depth of parentheses and determining the substring enclosed by the deepest pair of parentheses.

### Approach
1. **Track Parentheses Depth**: Use a stack to keep track of the indices of opening parentheses. Each time a closing parenthesis is encountered, the depth of the current pair is determined by the size of the stack before popping the corresponding opening parenthesis.
2. **Update Maximum Depth**: For each closing parenthesis, calculate the depth of the current pair. If this depth is greater than the previously recorded maximum depth, update the maximum depth and store the substring enclosed by these parentheses.
3. **Result Extraction**: After processing the entire string, the substring enclosed by the deepest pair of parentheses is the result.

### Solution Code
```python
def find_message():
    import sys
    s = sys.stdin.readline().strip()
    stack = []
    max_depth = 0
    result = ""
    for i, c in enumerate(s):
        if c == '(':
            stack.append(i)
        elif c == ')':
            if stack:
                start = stack.pop()
                current_depth = len(stack) + 1
                substring = s[start+1:i]
                if current_depth > max_depth:
                    max_depth = current_depth
                    result = substring
    print(result)

find_message()
```

### Explanation
- **Stack Usage**: The stack is used to track the indices of opening parentheses. Each time an opening parenthesis `(` is encountered, its index is pushed onto the stack.
- **Depth Calculation**: When a closing parenthesis `)` is encountered, the stack is popped to get the index of the corresponding opening parenthesis. The depth of the current pair is calculated as the length of the stack after popping plus one (since the stack size before popping gives the depth of the current pair).
- **Substring Extraction**: The substring between the indices of the opening and closing parentheses is extracted. If this substring is enclosed in a deeper pair of parentheses than previously found, it becomes the new result.

This approach efficiently tracks the deepest nested substring in linear time, making it suitable for large input sizes up to 100,000 characters.
