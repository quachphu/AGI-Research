To solve this problem, we need to construct a string `s` of minimum possible length that contains exactly `k` occurrences of a given substring `t`. The key insight is to maximize the overlap between consecutive occurrences of `t` to minimize the length of `s`.

### Approach
1. **Identify Overlap**: Determine the maximum overlap `d` where the prefix of length `d` of `t` matches its suffix of the same length. This helps in minimizing the number of new characters added for each subsequent occurrence of `t`.
2. **Construct String**: Start with the initial string `t` and append the suffix of `t` (starting from index `d`) `k-1` times. This suffix is the part of `t` that does not overlap with the previous occurrence, ensuring each new occurrence adds the minimum number of characters.

### Solution Code
```python
n, k = map(int, input().split())
t = input().strip()

d = 0
for possible_d in range(n-1, 0, -1):
    if t[:possible_d] == t[-possible_d:]:
        d = possible_d
        break

result = t + (k-1) * t[d:]
print(result)
```

### Explanation
1. **Overlap Calculation**: The loop checks from the largest possible overlap down to the smallest. The maximum overlap `d` is found when the prefix of length `d` matches the suffix of the same length.
2. **String Construction**: By using the overlap `d`, we construct the result string by appending the non-overlapping part of `t` (from index `d` onwards) `k-1` times after the initial occurrence of `t`. This ensures each new occurrence adds the minimum number of characters, thus minimizing the total length of `s`.

This approach efficiently computes the minimal length string by leveraging the maximum possible overlap between consecutive occurrences of `t`, ensuring the solution is both optimal and correct.
