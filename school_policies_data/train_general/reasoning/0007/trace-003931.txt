To solve this problem, we need to determine the maximum possible cost of a tree when choosing an optimal root vertex. The cost is defined as the sum of the product of the distance from the root to each vertex and the value assigned to each vertex. 

### Approach
1. **Tree Structure Analysis**: We first build the tree using an adjacency list.
2. **Subtree Sum Calculation**: Using a post-order traversal, we compute the sum of values for each subtree rooted at each node.
3. **Initial Cost Calculation**: We compute the initial cost when the tree is rooted at an arbitrary node (node 1) using a BFS to calculate distances from the root.
4. **Cost Propagation**: Using another BFS, we propagate the cost from the initial root to all other nodes. For each node, we adjust the cost based on whether we are moving to a child or parent in the original tree structure, using the precomputed subtree sums.

### Solution Code
```python
import sys
from collections import deque

def main():
    sys.setrecursionlimit(1 << 25)
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    edges = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v = map(int, sys.stdin.readline().split())
        edges[u].append(v)
        edges[v].append(u)
    
    # Compute sum_a_subtree using iterative post-order traversal
    sum_a_subtree = [0] * (n + 1)
    stack = [(1, 0, False)]  # (node, parent, visited)
    while stack:
        u, parent, visited = stack.pop()
        if not visited:
            stack.append((u, parent, True))
            for v in edges[u]:
                if v != parent:
                    stack.append((v, u, False))
        else:
            sum_a_subtree[u] = a[u - 1]
            for v in edges[u]:
                if v != parent:
                    sum_a_subtree[u] += sum_a_subtree[v]
    
    # Compute initial cost and parent array using BFS
    initial_cost = 0
    parent_arr = [0] * (n + 1)
    distance = [0] * (n + 1)
    visited = [False] * (n + 1)
    q = deque()
    q.append(1)
    visited[1] = True
    parent_arr[1] = 0
    while q:
        u = q.popleft()
        initial_cost += distance[u] * a[u - 1]
        for v in edges[u]:
            if not visited[v]:
                visited[v] = True
                parent_arr[v] = u
                distance[v] = distance[u] + 1
                q.append(v)
    
    total_a = sum(a)
    max_cost = initial_cost
    cost = [0] * (n + 1)
    cost[1] = initial_cost
    visited = [False] * (n + 1)
    q = deque()
    q.append(1)
    visited[1] = True
    
    while q:
        u = q.popleft()
        for v in edges[u]:
            if not visited[v]:
                if parent_arr[v] == u:  # v is a child of u in original tree
                    delta = total_a - 2 * sum_a_subtree[v]
                else:  # u is a child of v in original tree
                    delta = - (total_a - 2 * sum_a_subtree[u])
                cost[v] = cost[u] + delta
                if cost[v] > max_cost:
                    max_cost = cost[v]
                visited[v] = True
                q.append(v)
    
    print(max_cost)

if __name__ == "__main__":
    main()
```

2. **Subtree Sum Calculation**: Using an iterative post-order traversal, we compute the sum of values for each subtree. This helps in efficiently calculating the cost adjustments when moving the root.
3. **Initial Cost Calculation**: Starting from an arbitrary root (node 1), we use BFS to compute the initial cost based on the distances from this root.
4. **Cost Propagation**: Using another BFS, we propagate the cost from the initial root to all other nodes. The cost adjustment (delta) is computed based on whether the node is moving to a child or parent in the original tree structure, ensuring optimal cost calculation in linear time.

This approach efficiently computes the maximum possible cost in O(n) time, making it suitable for large trees up to 200,000 nodes.
