To solve this problem, we need to determine all possible valid outcomes of a coin-tossing game between Vasya and Petya based on the given constraints. The goal is to find all pairs of scores where Vasya's score is strictly higher than Petya's score, while adhering to the minimum heads each player must have achieved.

### Approach
1. **Input Reading**: Read the input values which include the number of tosses each player made and the minimum heads each must have achieved.
2. **Generate Valid Outcomes**: Iterate through all possible valid scores for both Vasya and Petya. For Vasya, the valid scores range from the minimum heads he must have achieved to his total tosses. Similarly, for Petya, the valid scores range from his minimum heads to his total tosses.
3. **Filter Valid Outcomes**: Check each pair of scores to ensure Vasya's score is strictly greater than Petya's.
4. **Sorting**: Sort the valid outcomes first by Vasya's score in ascending order and then by Petya's score in ascending order if Vasya's scores are the same.
5. **Output**: Print the number of valid outcomes followed by each valid pair.

### Solution Code
```python
def main():
    x, y, a, b = map(int, input().split())
    valid = []
    for c in range(a, x + 1):
        for d in range(b, y + 1):
            if c > d:
                valid.append((c, d))
    valid.sort()
    print(len(valid))
    for pair in valid:
        print(pair[0], pair[1])

main()
```

### Explanation
1. **Reading Input**: The input values are read and parsed into integers representing the number of tosses and minimum heads required for both players.
2. **Generating Scores**: Using nested loops, we generate all possible scores for Vasya (from `a` to `x`) and Petya (from `b` to `y`).
3. **Filtering Valid Pairs**: Each pair of scores is checked to ensure Vasya's score is strictly greater than Petya's. Valid pairs are collected into a list.
4. **Sorting**: The list of valid pairs is sorted to meet the problem's requirement of strictly increasing order by Vasya's score first, then Petya's score.
5. **Output**: The number of valid outcomes is printed followed by each valid pair in the required format.

This approach ensures that all constraints are met efficiently and the results are presented in the correct order. The solution efficiently iterates through possible scores and filters them based on the given conditions, ensuring correctness and optimal performance given the problem constraints.
