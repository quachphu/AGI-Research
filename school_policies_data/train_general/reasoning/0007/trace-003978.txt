To solve this problem, we need to determine the number of ways to sell exactly X tickets to a group of friends such that all tickets are in the same compartment of a train car. Each compartment must have enough free seats to accommodate all X friends.

### Approach
1. **Understanding Compartment Structure**: Each train car has 9 compartments, each consisting of 6 seats. The first four seats of each compartment are consecutive, while the last two seats are positioned towards the end of the car and follow a specific numbering pattern.
2. **Reading Input**: The input consists of two integers X and N, followed by N strings representing the seats in each car. Each string has 54 characters where '0' indicates a free seat and '1' indicates a booked seat.
3. **Compartment Seat Calculation**: For each compartment, determine the seat numbers. The first four seats of the i-th compartment are calculated as `1 + (i-1)*4` to `4 + (i-1)*4`. The last two seats are calculated as `55 - 2*i` and `56 - 2*i`.
4. **Counting Free Seats**: For each compartment, count the number of free seats. If the number of free seats (k) is at least X, compute the number of ways to choose X seats from k using combinations (C(k, X)).
5. **Summing Up**: Sum the combinations for all valid compartments across all cars to get the total number of ways to sell the tickets.

### Solution Code
```python
import math

x, n = map(int, input().split())
cars = [input().strip() for _ in range(n)]

total = 0

for car in cars:
    for i in range(1, 10):  # i from 1 to 9 inclusive
        # Calculate the first four seats of the compartment
        start_seat = 1 + (i - 1) * 4
        four_seats = list(range(start_seat, start_seat + 4))
        # Calculate the two higher seats
        higher1 = 55 - 2 * i
        higher2 = 56 - 2 * i
        # Collect all six seats in the compartment
        compartment_seats = four_seats + [higher1, higher2]
        # Count the number of free seats
        free = 0
        for seat in compartment_seats:
            if car[seat - 1] == '0':
                free += 1
        # Add the combination if possible
        if free >= x:
            total += math.comb(free, x)

print(total)
```

### Explanation
1. **Reading Input**: The code reads the values of X and N, followed by N strings representing each car's seat status.
2. **Compartment Calculation**: For each car and each of its 9 compartments, the code calculates the seat numbers for both the first four seats and the last two seats using the given pattern.
3. **Free Seats Count**: For each compartment, the code checks each seat to count how many are free.
4. **Combination Calculation**: If the number of free seats in a compartment is at least X, the code calculates the number of ways to choose X seats from the free ones using the combination formula and adds this to the total count.
5. **Output**: The total number of valid ways to sell the tickets is printed.

This approach efficiently processes each car and compartment, ensuring that all possible valid combinations are considered, leading to the correct solution.
