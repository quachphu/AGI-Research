To solve this problem, we need to determine which row each passenger will take when they enter the bus, based on their personality type (introvert or extrovert). The solution involves efficiently managing the selection of seats using priority queues to handle the constraints and requirements of each passenger type.

### Approach
1. **Sort Rows by Width**: First, sort the rows by their seat widths in ascending order. This allows introverts to always select the smallest available width efficiently.
2. **Track Available Rows for Introverts**: Use a pointer to track the next available row for introverts, which will be the next smallest width in the sorted list.
3. **Max-Heap for Extroverts**: Use a max-heap (implemented using a min-heap with negative values) to track rows that have exactly one occupied seat. Extroverts will select the row with the largest width from this heap.

### Solution Code
```python
import heapq

n = int(input())
w = list(map(int, input().split()))
# Sort rows by width, and keep track of original 1-based index
rows = sorted((w[i], i + 1) for i in range(n))
next_available = 0
max_heap = []
result = []

for c in input().strip():
    if c == '0':
        # Introvert: take the next smallest available row
        row = rows[next_available]
        result.append(row[1])
        # Push to max_heap as negative width for max-heap behavior
        heapq.heappush(max_heap, (-row[0], row[1]))
        next_available += 1
    else:
        # Extrovert: take the largest available from the max-heap
        w_val, row_idx = heapq.heappop(max_heap)
        result.append(row_idx)

print(' '.join(map(str, result)))
```

### Explanation
1. **Sorting Rows**: The rows are sorted by their seat widths. This allows introverts to pick the smallest available width efficiently by simply iterating through the sorted list.
2. **Handling Introverts**: Each introvert takes the next available row from the sorted list, which is tracked using a pointer. After selecting a row, it is added to the max-heap for potential use by extroverts.
3. **Handling Extroverts**: Each extrovert picks the row with the largest width from the max-heap. This heap is maintained using negative values to simulate a max-heap with Python's `heapq` module, which inherently provides a min-heap.
4. **Efficiency**: The sorting step runs in O(n log n) time, and each heap operation (push/pop) runs in O(log n) time. With n operations for both introverts and extroverts, the overall complexity is O(n log n), which is efficient for the problem constraints.

This approach ensures that both introverts and extroverts select their seats according to the problem's rules efficiently and correctly.
