To solve this problem, we need to determine the maximum number of points Petya can score in a math exam by solving problems within a given time frame, considering both easy and hard problems that become mandatory at specific times.

### Approach
1. **Sort Problems by Mandatory Time**: First, we sort the problems based on their mandatory times (t_i) to efficiently determine which problems become mandatory as time progresses.
2. **Prefix Sums for Easy and Hard Problems**: We precompute prefix sums for the number of easy and hard problems up to each index. This helps in quickly calculating the total time required to solve all mandatory problems up to any given time.
3. **Generate Candidate Times**: We generate candidate times to check for the maximum points. These candidates include all mandatory times (t_i), the total exam time (T), and the sum of times required to solve the first k problems for each k. Additionally, we consider the maximum of the mandatory time and the sum of solving times for the first k problems.
4. **Evaluate Each Candidate Time**: For each candidate time, we determine how many mandatory problems can be solved within that time and then use the remaining time to solve as many optional problems (those not mandatory by the candidate time) as possible.

import bisect

def solve():
    import sys
    input = sys.stdin.read
    data = input().split()
    idx = 0
    m = int(data[idx])
    idx += 1
    for _ in range(m):
        n, T, a, b = map(int, data[idx:idx+4])
        idx +=4
        types = list(map(int, data[idx:idx+n]))
        idx +=n
        t_list = list(map(int, data[idx:idx+n]))
        idx +=n
        
        problems = list(zip(t_list, types))
        problems.sort()
        sorted_ts = [t for t, _ in problems]
        sum_easy = [0]*(n+1)
        sum_hard = [0]*(n+1)
        for i in range(n):
            t, typ = problems[i]
            sum_easy[i+1] = sum_easy[i] + (1 if typ ==0 else 0)
            sum_hard[i+1] = sum_hard[i] + (1 if typ ==1 else 0)
        
        total_easy = sum_easy[n]
        total_hard = sum_hard[n]
        
        candidates = set()
        for t in sorted_ts:
            candidates.add(t)
        candidates.add(T)
        
        for k in range(n+1):
            sum_time_k = sum_easy[k] * a + sum_hard[k] * b
            if sum_time_k <= T:
                candidates.add(sum_time_k)
        
        for k in range(n+1):
            if k ==0:
                max_t_k = 0
            else:
                max_t_k = problems[k-1][0]
            sum_time_k = sum_easy[k] * a + sum_hard[k] * b
            s_candidate = max(max_t_k, sum_time_k)
            if s_candidate <= T:
                candidates.add(s_candidate)
        
        candidates.add(0)
        max_points = 0
        for s in candidates:
            if s <0 or s > T:
                continue
            k = bisect.bisect_right(sorted_ts, s)
            sum_easy_mandatory = sum_easy[k]
            sum_hard_mandatory = sum_hard[k]
            sum_mandatory_time = sum_easy_mandatory * a + sum_hard_mandatory * b
            if sum_mandatory_time > s:
                continue
            remaining_time = s - sum_mandatory_time
            optional_easy = total_easy - sum_easy_mandatory
            optional_hard = total_hard - sum_hard_mandatory
            take_easy = min(optional_easy, remaining_time // a)
            rem = remaining_time - take_easy * a
            take_hard = min(optional_hard, rem // b)
            total = k + take_easy + take_hard
            if total > max_points:
                max_points = total
        print(max_points)
        
solve()
