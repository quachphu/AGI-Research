To solve this problem, we need to simulate the operations on a correct bracket sequence (CBS) using an efficient data structure to handle deletions and cursor movements. The key challenge is to efficiently manage deletions of contiguous bracket ranges and adjust the cursor position accordingly.

### Approach
1. **Precompute Pairs**: Use a stack to determine the matching pair for each bracket. This helps in quickly identifying the range to delete when the 'D' operation is performed.
2. **Linked List Representation**: Maintain two arrays, `prev` and `next`, to represent the previous and next indices in the current active sequence. This allows efficient deletion of ranges and cursor movements.
3. **Process Operations**: For each operation, update the cursor position or delete the specified range. Adjust the linked list pointers (`prev` and `next`) to skip the deleted range and update the cursor position as required.
4. **Reconstruct Result**: After processing all operations, traverse the remaining elements using the linked list pointers to collect the resulting bracket sequence.

### Solution Code
```python
n, m, p = map(int, input().split())
s = input().strip()
operations = input().strip()

# Precompute the pair for each bracket
stack = []
pair = [0] * (n + 1)  # 1-based indices
for i in range(1, n + 1):
    if s[i - 1] == '(':
        stack.append(i)
    else:
        j = stack.pop()
        pair[i] = j
        pair[j] = i

# Initialize prev and next arrays
prev = [0] * (n + 2)  # prev[0] is unused
next_ = [0] * (n + 2)  # next_ to avoid conflict with next keyword

for i in range(1, n + 1):
    prev[i] = i - 1
    next_[i] = i + 1
next_[n] = 0  # Correct the last element's next to 0

current_p = p

for op in operations:
    if op == 'L':
        current_p = prev[current_p]
    elif op == 'R':
        current_p = next_[current_p]
    else:  # 'D' operation
        q = pair[current_p]
        start = min(current_p, q)
        end = max(current_p, q)
        left = prev[start]
        right = next_[end]

        # Update the links to bypass the deleted segment
        if left != 0:
            next_[left] = right
        if right != 0:
            prev[right] = left

        # Determine the new cursor position
        current_p = right if right != 0 else left

# Find the head of the remaining sequence
head = current_p
while prev[head] != 0:
    head = prev[head]

# Collect the remaining characters
result = []
current = head
while current != 0:
    result.append(s[current - 1])
    current = next_[current]

print(''.join(result))
```

### Explanation
1. **Pair Calculation**: Using a stack, we determine the matching pair for each bracket in O(n) time. This allows us to quickly find the range to delete when the 'D' operation is executed.
2. **Linked List Management**: Arrays `prev` and `next_` keep track of the active elements in the sequence. When a range is deleted, we adjust these pointers to skip the deleted range, ensuring efficient O(1) updates.
3. **Cursor Movement**: The cursor is moved left or right by following the `prev` and `next_` pointers. After a deletion, the cursor is repositioned to the nearest valid bracket.
4. **Result Construction**: Starting from the leftmost active element, we traverse the linked list using the `next_` pointers to collect the remaining brackets and form the resulting sequence.
