To solve this problem, we need to determine if a given n x n grid can be completely covered by non-overlapping crosses. Each cross consists of exactly 5 cells arranged in a specific pattern, and every '#' in the grid must be part of exactly one cross.

### Approach
1. **Check Divisibility by 5**: First, check if the total number of '#' cells is divisible by 5. If not, it's impossible to cover them with crosses, so we immediately return "NO".
2. **Greedy Cross Placement**: Iterate through each cell in the grid. For each cell that can be the center of a cross (i.e., it's within valid bounds and not on the edge), check if it and its four adjacent cells (up, down, left, right) are all '#'. If they are, mark these cells as part of a cross.
3. **Validation**: After attempting to place all possible crosses, check if every '#' cell has been covered. If any '#' cell is not covered, return "NO"; otherwise, return "YES".
