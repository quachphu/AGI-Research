The robot processes each element in the array, and if an element is divisible by a given integer `x`, it appends `x` copies of the quotient of the element divided by `x` to the end of the array. The robot stops when it encounters an element that is not divisible by `x`.

### Approach
The approach involves simulating the robot's processing steps using a queue. The robot processes each element in the order they appear in the array. If an element is divisible by `x`, the quotient is added to the queue `x` times. The sum of all elements processed until the robot stops is accumulated and added to the original sum of the array to get the final result.

```python
import sys
from collections import deque

def main():
    input = sys.stdin.read().split()
    idx = 0
    t = int(input[idx])
    idx += 1
    for _ in range(t):
        n, x = int(input[idx]), int(input[idx+1])
        idx +=2
        a = list(map(int, input[idx:idx+n]))

        original_sum = sum(a)
        sum_processed = 0
        q = deque(a)

        while q:
            current = q.popleft()
            if current % x == 0:
                sum_processed += current
                for _ in range(x):

            else:
                break
        print(original_sum + sum_processed)

    main()
```
