To solve this problem, we need to determine the number of pairs (i, j) in an array where 1 ≤ i < j ≤ N and the XOR of the elements at these indices is odd. 

### Approach
The key insight here is that the XOR of two numbers is odd if and only if one of the numbers is even and the other is odd. This is because the least significant bit (LSB) of an odd number is 1, and the LSB of an even number is 0. The XOR of 1 and 0 is 1, which makes the result odd. Conversely, if both numbers are even or both are odd, their XOR will be even.

Thus, the problem reduces to counting the number of even and odd elements in the array. Let the count of even elements be E and the count of odd elements be O. The number of valid pairs (i, j) where one element is even and the other is odd is simply the product E * O.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        arr = list(map(int, input[ptr:ptr+N]))
        ptr += N
        even = 0
        for num in arr:
            if num % 2 == 0:
                even += 1
        odd = N - even
        print(even * odd)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once for efficiency, especially given the constraints where the array can be large (up to 100,000 elements). This is handled using `sys.stdin.read()` which reads all input at once and splits it into a list of strings.
2. **Counting Even and Odd Elements**: For each test case, we count the number of even elements by iterating through the array and checking each element's parity (even or odd). The count of odd elements is derived by subtracting the count of even elements from the total number of elements.
3. **Calculating Valid Pairs**: The number of valid pairs is computed as the product of the counts of even and odd elements, which gives the result in constant time after counting.

This approach ensures that we efficiently handle the input size constraints and compute the result in linear time for each test case, making the solution both optimal and easy to understand.
