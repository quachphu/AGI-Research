To solve this problem, we need to find a non-negative integer \( k \) such that the least common multiple (LCM) of \( a + k \) and \( b + k \) is minimized. If there are multiple values of \( k \) that yield the same minimal LCM, we should choose the smallest \( k \).

### Approach
1. **Problem Analysis**:
   - The difference \( d \) between \( a \) and \( b \) is crucial. Let \( d = |a - b| \). If \( d = 0 \), the LCM is simply \( a \) (or \( b \)), so \( k = 0 \).
   - For \( d \neq 0 \), we need to find \( k \) such that \( \text{LCM}(a + k, b + k) \) is minimized. The key insight is that the LCM of two numbers can be minimized by considering their greatest common divisor (GCD).

2. **Divisors of \( d \)**:
   - The optimal \( k \) often corresponds to divisors of \( d \). For each divisor \( g \) of \( d \), we compute the smallest integer \( m \) such that \( m \geq \lceil \text{min}(a, b) / g \rceil \) and \( \text{GCD}(m, d/g) = 1 \).

3. **LCM Calculation**:
   - For each divisor \( g \), calculate the corresponding \( k \) and LCM. Track the minimal LCM and the smallest \( k \) if there are ties.

### Solution Code
```python
import math

def find_min_k():
    a, b = map(int, input().split())
    d = abs(a - b)
    if d == 0:
        print(0)
        return
    
    s = min(a, b)
    divisors = set()
    for i in range(1, int(math.isqrt(d)) + 1):
        if d % i == 0:
            divisors.add(i)
            divisors.add(d // i)
    divisors = sorted(divisors)
    
    candidates = []
    for g in divisors:
        k_prime = d // g
        m_min = (s + g - 1) // g  # Equivalent to ceil(s/g)
        m = m_min
        while True:
            if math.gcd(m, k_prime) == 1:
                break
            m += 1
        x = g * m
        lcm_val = g * m * (m + k_prime)
        k_candidate = x - s
        candidates.append((lcm_val, k_candidate))
    
    # Find the best candidate
    min_lcm = None
    best_k = None
    for lcm, k in candidates:
        if min_lcm is None or lcm < min_lcm:
            min_lcm = lcm
            best_k = k
        elif lcm == min_lcm and k < best_k:
            best_k = k
    print(best_k)

find_min_k()
```
