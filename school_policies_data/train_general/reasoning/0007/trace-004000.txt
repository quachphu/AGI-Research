To solve this problem, we need to determine if the number of valid permutations remains odd after removing each valid pair from the list. The solution involves using Gaussian elimination over GF(2) (binary field) to efficiently compute the parity of permutations involving each pair.

### Approach
1. **Matrix Representation**: Represent the valid permutation pairs as a binary matrix where each entry (i, j) is 1 if the pair (i+1, j+1) is allowed.
2. **Augmented Matrix**: Construct an augmented matrix that combines the original matrix with an identity matrix. This helps in performing row operations to compute the inverse matrix.
3. **Gaussian Elimination**: Perform Gaussian elimination on the augmented matrix over GF(2) to transform the original matrix into the identity matrix. The right part of the augmented matrix will then be the inverse of the original matrix.
4. **Inverse Matrix Analysis**: Use the inverse matrix to determine the parity of permutations involving each pair. If the parity is even, removing the pair will leave an odd count of permutations, otherwise, it will not.

### Solution Code
```python
import sys

def main():
    n, m = map(int, sys.stdin.readline().split())
    adj = [[0] * n for _ in range(n)]
    edges = []
    for _ in range(m):
        a, b = map(int, sys.stdin.readline().split())
        a -= 1
        b -= 1
        adj[a][b] = 1
        edges.append((a, b))
    
    # Build augmented matrix as integers where each bit represents a column
    aug = []
    for i in range(n):
        row = 0
        # Original part (columns 0 to n-1)
        for j in range(n):
            if adj[i][j]:
                bit_pos = (2 * n - 1) - j
                row |= (1 << bit_pos)
        # Augmented identity part (columns n to 2n-1)
        # For row i, set column n + i
        bit_pos_aug = (2 * n - 1) - (n + i)
        row |= (1 << bit_pos_aug)
        aug.append(row)
    
    # Perform Gaussian elimination over GF(2)
    for c in range(n):
        # Find the pivot row
        pivot = None
        for r in range(c, n):
            if (aug[r] >> ((2 * n - 1) - c)) & 1:
                pivot = r
                break
        if pivot is None:
            print("No pivot found for column", c)
            exit()
        aug[c], aug[pivot] = aug[pivot], aug[c]
        
        # Eliminate all other rows
        for r in range(n):
            if r != c and (aug[r] >> ((2 * n - 1) - c)) & 1:
                aug[r] ^= aug[c]
    
    # Process each edge to determine the answer
    for a, b in edges:
        bit_pos = (n - 1) - a
        bit = (aug[b] >> bit_pos) & 1
        print("YES" if bit == 0 else "NO")

if __name__ == "__main__":
    main()
```

3. **Gaussian Elimination**: This step transforms the original matrix into the identity matrix while applying the same operations to the identity part, resulting in the inverse matrix.
4. **Checking Parity**: For each valid pair, the corresponding entry in the inverse matrix is checked to determine if removing the pair results in an odd number of permutations, which is printed as "YES" or "NO".
