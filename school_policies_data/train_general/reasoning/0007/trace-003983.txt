n, k = map(int, input().split())

To solve this problem, we need to repeatedly find the minimum non-zero element in an array, subtract it from all non-zero elements, and print the result for each of the given k operations. If all elements are zero, we print zero for the remaining operations.

### Approach
1. **Sort the Array**: First, we sort the array to efficiently find the minimum non-zero elements in subsequent operations.
2. **Track Cumulative Subtraction**: Maintain a cumulative subtraction value that keeps track of the total amount subtracted from the elements so far.
3. **Binary Search for Efficiency**: Use binary search to quickly locate the next minimum non-zero element after each subtraction. This avoids the need to scan the entire array repeatedly, which would be inefficient for large arrays.
