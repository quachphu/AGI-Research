To solve this problem, we need to determine the number of coprime subsequences in a given array. A subsequence is coprime if the greatest common divisor (GCD) of all its elements is 1. Given the constraints, a brute force approach is infeasible, so we use a more efficient method involving the inclusion-exclusion principle and the Möbius function.

### Approach
1. **Frequency Array**: Count the frequency of each element in the array.
2. **Divisibility Count**: For each integer `d`, compute the count of elements in the array that are divisible by `d`.
3. **Möbius Function**: Precompute the Möbius function values for all integers up to the maximum element in the array. The Möbius function helps in applying the inclusion-exclusion principle efficiently.
4. **Power of 2 Precomputation**: Precompute powers of 2 modulo \(10^9 + 7\) to efficiently calculate the number of non-empty subsequences.
5. **Sum Calculation**: Use the precomputed values and the Möbius function to sum up the contributions of each integer `d` to the number of coprime subsequences.

### Solution Code
```python
MOD = 10**9 + 7

n = int(input())
a = list(map(int, input().split()))

if not a:
    print(0)
    exit()

max_a = max(a)

# Frequency array
freq = [0] * (max_a + 1)
for x in a:
    freq[x] += 1

# Compute c[d]: number of elements divisible by d
c = [0] * (max_a + 1)
for d in range(1, max_a + 1):
    for k in range(d, max_a + 1, d):
        c[d] += freq[k]

# Smallest prime factor (SPF) sieve
max_spf = max_a
spf = list(range(max_spf + 1))
for i in range(2, int(max_spf**0.5) + 1):
    if spf[i] == i:  # i is prime
        for j in range(i * i, max_spf + 1, i):
            if spf[j] == j:
                spf[j] = i

# Compute Möbius function
mu = [0] * (max_a + 1)
mu[1] = 1
for d in range(2, max_a + 1):
    temp = d
    is_square_free = True
    last_p = -1
    count_primes = 0
    while temp > 1 and is_square_free:
        p = spf[temp]
        if p == last_p:
            is_square_free = False
            break
        last_p = p
        count_primes += 1
        temp //= p
        if temp % p == 0:
            is_square_free = False
    if is_square_free:
        mu[d] = (-1) ** count_primes
    else:
        mu[d] = 0

# Precompute powers of 2 up to n
max_pow = n
pow2 = [1] * (max_pow + 1)
for i in range(1, max_pow + 1):
    pow2[i] = (pow2[i-1] * 2) % MOD

# Calculate the result
result = 0
for d in range(1, max_a + 1):
    if c[d] == 0:
        continue
    term = mu[d] * (pow2[c[d]] - 1)
    result += term
    result %= MOD

print(result % MOD)
```

1. **Frequency Array**: We first count how many times each number appears in the array.
2. **Divisibility Count**: For each integer `d`, we calculate how many elements in the array are divisible by `d` by summing up the frequencies of all multiples of `d`.
3. **Möbius Function**: Using a sieve-like approach, we compute the Möbius function values. The Möbius function helps in efficiently applying the inclusion-exclusion principle to count coprime subsequences.
4. **Power of 2**: Precompute powers of 2 modulo \(10^9 + 7\) to quickly determine the number of non-empty subsequences for each divisor.
5. **Result Calculation**: Using the precomputed values and the Möbius function, we sum the contributions of each integer `d` to the total number of coprime subsequences. The result is adjusted using modulo \(10^9 + 7\) to handle large numbers.

This approach efficiently handles the constraints and provides the correct result using mathematical principles and precomputation techniques.
