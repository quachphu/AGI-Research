The solution involves iterating over possible values of x and checking the constraints to find the optimal solution efficiently.

### Approach
1. **Understanding Distribution**: Candies are distributed in batches of size x to each of k people in a cyclic manner. The leftover candies after each full cycle are discarded.
2. **Constraints on x**: 
   - x must be ≤ M.
   - The number of times any person receives candies must be ≤ D.
3. **Iterate Over Possible Times (t)**: For each possible number of times t (from 1 to D), calculate the minimum and maximum possible values of x that would allow Arkady to receive candies exactly t times.
4. **Calculate Candidate x Values**: For each t, compute the minimum and maximum possible values of x and check if they fit within the constraints. Track the maximum number of candies Arkady can receive.

### Solution Code
```python
n, k, M, D = map(int, input().split())
max_total = 0

for t in range(1, D + 1):
    s_min = k * (t - 1) + 1
    if s_min > n:
        continue
    x_candidate = n // s_min
    x_candidate = min(x_candidate, M)
    if x_candidate == 0:
        continue
    s = n // x_candidate
    if s < s_min or s > k * t:
        continue
    current = x_candidate * t
    if current > max_total:
        max_total = current

print(max_total)
```

1. **Loop Over Possible Times (t)**: The loop iterates over each possible number of times t (from 1 to D) that Arkady could receive candies.
2. **Calculate Minimum Batch Size (s_min)**: For each t, compute the minimum number of batches required to ensure Arkady receives candies exactly t times.
3. **Determine Candidate x**: Calculate the candidate x value based on s_min, ensuring it does not exceed M.
4. **Check Validity of x**: Check if the calculated x value results in a valid number of batches within the allowed range (s_min to k*t).
5. **Update Maximum Candies**: Track the maximum number of candies Arkady can receive based on valid x values.

This approach efficiently narrows down the possible values of x by leveraging mathematical constraints and iterating over a manageable range of possible values, ensuring an optimal solution within the problem's constraints.
