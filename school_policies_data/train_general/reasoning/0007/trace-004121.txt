To solve this problem, we need to determine the maximum amount of yen we can earn by strategically smashing gemstones. The key is to decide which gemstones to smash such that the sum of the values of the unsmashed gemstones is maximized. 

### Approach
1. **Problem Analysis**: We can smash gemstones by selecting a positive integer x and smashing all multiples of x. The goal is to maximize the sum of the values of the remaining unsmashed gemstones. 
2. **Intuition**: If the sum of the values of all gemstones that are multiples of a certain x is negative, smashing those gemstones will increase the total sum (since we avoid the negative values). Conversely, if the sum is positive, we should not smash those gemstones.
3. **Algorithm**: 
   - Process each integer from N down to 1.
   - For each integer x, calculate the sum of the values of the gemstones that are multiples of x and not yet smashed.
   - If this sum is negative, smash all multiples of x to avoid the negative values, thus increasing the total sum.
4. **Complexity**: The algorithm runs in O(N log N) time due to the nested loops for checking multiples, which is efficient for the given constraint (N ≤ 100).

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
smashed = [False] * (n + 1)
total = sum(a)
for x in range(n, 0, -1):
    current_sum = 0
    for i in range(x, n + 1, x):
        if not smashed[i]:
            current_sum += a[i - 1]
    if current_sum < 0:
        total += -current_sum
        for i in range(x, n + 1, x):
            if not smashed[i]:
                smashed[i] = True
print(total)
```

### Explanation
1. **Reading Input**: The input consists of an integer N followed by N integers representing the values of the gemstones.
2. **Initialization**: We initialize an array `smashed` to keep track of which gemstones have been smashed and calculate the initial total sum of all gemstone values.
3. **Processing Integers**: We iterate from N down to 1. For each integer x, we calculate the sum of the values of all unsmashed multiples of x.
4. **Decision Making**: If the calculated sum is negative, we smash all multiples of x to avoid the negative contribution, updating the total sum accordingly.
5. **Output**: Finally, we print the maximum total sum after optimally smashing gemstones.

This approach ensures that we maximize the sum by avoiding negative contributions while retaining positive ones, efficiently determining the optimal strategy using a greedy approach.
