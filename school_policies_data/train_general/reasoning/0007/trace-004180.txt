To solve this problem, we need to calculate the total overhead of typing a given string based on the number of button presses required for each character. Each lowercase letter 'a' to 'z' corresponds to 1 to 26 presses, respectively. 

### Approach
1. **Input Reading**: Read the number of test cases, followed by each test case string.
2. **Character Processing**: For each character in the string, compute its corresponding button presses using its position in the alphabet (e.g., 'a' is 1, 'b' is 2, etc.).
3. **Sum Calculation**: Sum the button presses for all characters in each string and print the result for each test case.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        s = sys.stdin.readline().strip()
        total = sum(ord(c) - ord('a') + 1 for c in s)
        print(total)

main()
```

### Explanation
1. **Reading Input Efficiently**: The code reads all input at once using `sys.stdin.readline()` for efficiency, which is crucial given the constraints of up to 10,000 test cases.
2. **Processing Each Test Case**: Each string is processed by iterating over its characters. For each character, the position in the alphabet is determined using `ord(c) - ord('a') + 1`, where `ord` gives the ASCII value of the character.
3. **Summing and Printing**: The sum of these values is computed and printed for each test case, ensuring the solution is both efficient and straightforward.

This approach ensures that the solution handles the maximum constraints efficiently, providing results in linear time relative to the input size.
