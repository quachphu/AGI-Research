To solve this problem, we need to calculate the number of points scored when squares are added to columns on a platform. Points are scored each time all columns have at least one square, causing the bottom row to be removed.

### Approach
1. **Track Column Heights**: Maintain an array to keep track of the number of squares in each column.
2. **Check for Full Rows**: After each square is added, check if all columns have at least one square.
3. **Remove Rows and Update Points**: If all columns have at least one square, calculate the minimum number of rows that can be removed (which is the minimum number of squares in any column). Subtract this minimum from each column and add the minimum to the points.

### Solution Code
```python
n, m = map(int, input().split())
columns = list(map(int, input().split()))
counts = [0] * n
points = 0

for c in columns:
    counts[c-1] += 1
    min_count = min(counts)
    if min_count > 0:
        points += min_count
        for i in range(n):
            counts[i] -= min_count

print(points)
```

### Explanation
1. **Reading Input**: The input consists of two integers `n` (number of columns) and `m` (number of squares), followed by a list of integers representing the columns where each square is added.
2. **Tracking Column Heights**: We use an array `counts` to track the number of squares in each column.
3. **Adding Squares**: For each square added to a column, increment the corresponding entry in the `counts` array.
4. **Checking Full Rows**: After each addition, check if all columns have at least one square by finding the minimum value in the `counts` array.
5. **Updating Points and Counts**: If the minimum value is greater than zero, add this value to the points and subtract it from each column's count. This effectively removes the bottom row(s) and updates the counts accordingly.

This approach efficiently tracks the state of the platform and ensures that we only process each square once, leading to an optimal solution with a time complexity of O(n*m), which is manageable given the problem constraints.
