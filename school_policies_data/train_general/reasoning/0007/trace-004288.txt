To solve this problem, we need to determine if a given distance matrix corresponds to a weighted tree with positive integer weights. The tree must satisfy the properties of being connected, acyclic, and having edges with positive weights.

### Approach
1. **Initial Checks**:
   - **Symmetry and Zero Diagonals**: Ensure the matrix is symmetric and all diagonal elements are zero.
   - **Positive Distances**: For non-diagonal elements (i ≠ j), ensure all distances are positive.

2. **Special Case for Single Node**:
   - If the matrix has only one node (n=1), it trivially forms a valid tree.

3. **Root Selection and Sorting**:
   - Choose the first node (node 0) as the root and sort all nodes based on their distance from the root.

4. **Parent Identification**:
   - For each node, identify a parent node such that the distance from the root to the node is the sum of the distance from the root to the parent and the edge weight between the parent and the node.

5. **Validation**:
   - Ensure that the identified parent and edge weight satisfy the distance constraints for all previously processed nodes.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    matrix = []
    for _ in range(n):
        row = list(map(int, sys.stdin.readline().split()))
        matrix.append(row)
    
    # Check diagonal elements and symmetry
    valid = True
    for i in range(n):
        if matrix[i][i] != 0:
            valid = False
            break
        for j in range(n):
            if matrix[i][j] != matrix[j][i]:
                valid = False
                break
        if not valid:
            break
    if not valid:
        print("NO")
        return
    
    if n == 1:
        print("YES")
        return
    
    # Check all i != j have positive distances
    for i in range(n):
        for j in range(n):
            if i != j and matrix[i][j] <= 0:
                print("NO")
                return
    
    d0 = matrix[0]
    sorted_nodes = sorted(range(n), key=lambda x: (d0[x], x))
    
    if sorted_nodes[0] != 0:
        print("NO")
        return
    
    for idx in range(1, n):
        u = sorted_nodes[idx]
        found_p = False
        selected_p = None
        
        # Iterate in reverse to find the parent with maximum d0[p]
        for p in reversed(sorted_nodes[:idx]):
            if matrix[u][p] == d0[u] - d0[p]:
                selected_p = p
                found_p = True
                break
        
        if not found_p:
            print("NO")
            return
        
        w = d0[u] - d0[selected_p]
        if w <= 0:
            print("NO")
            return
        
        # Check all previously added nodes
        for v in sorted_nodes[:idx]:
            expected = w + matrix[selected_p][v]
            if matrix[u][v] != expected:
                print("NO")
                return
    
    print("YES")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Initial Checks**: The code first verifies the matrix is symmetric and has zero diagonal elements. It also ensures non-diagonal elements are positive for non-trivial cases (n ≥ 2).
2. **Root and Sorting**: The root node (node 0) is used to sort all other nodes based on their distance from the root.
3. **Parent Identification**: For each node, the algorithm finds a parent node such that the distance constraints are satisfied. This is done by iterating in reverse order to quickly find the most likely parent.
4. **Validation**: For each node, the algorithm checks if the distances to all previously processed nodes match the expected values based on the identified parent and edge weight.

This approach efficiently verifies the tree structure using O(n²) operations, making it feasible for large matrices up to 2000x2000.
