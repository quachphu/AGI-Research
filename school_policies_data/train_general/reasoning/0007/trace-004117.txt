To solve this problem, we need to find the minimum prime number that is greater than or equal to a given integer \( X \). A prime number is a number greater than 1 that has no divisors other than 1 and itself. The approach involves checking each number starting from \( X \) upwards until we find a prime number.

### Approach
1. **Check for Primality**: For each number starting from \( X \), we check if it is a prime number. This is done by checking divisibility from 2 up to the square root of the number. If any number in this range divides the number, it is not a prime.
2. **Efficient Divisibility Check**: To optimize the primality check, we first handle even numbers and then check divisibility by odd numbers only, reducing the number of checks needed.
3. **Iterate from \( X \) Upwards**: Starting from \( X \), we incrementally check each subsequent number until we find the first prime number.

### Solution Code
```python
def is_prime(n):
    if n <= 1:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False
    max_divisor = int(n ** 0.5) + 1
    for d in range(3, max_divisor, 2):
        if n % d == 0:
            return False
    return True

def find_min_prime():
    X = int(input())
    n = X
    while True:
        if is_prime(n):
            print(n)
            return
        n += 1

find_min_prime()
```

### Explanation
1. **Prime Check Function (`is_prime`)**:
   - **Handle Small Values**: Numbers less than 2 are not prime. The number 2 is the smallest prime.
   - **Check Even Numbers**: Any even number greater than 2 is not prime.
   - **Check Odd Divisors**: For numbers greater than 2 and odd, check divisibility from 3 up to the square root of the number, stepping by 2 to skip even numbers.

2. **Main Function (`find_min_prime`)**:
   - **Read Input**: The input value \( X \) is read.
   - **Iterate from \( X \)**: Starting from \( X \), check each number for primality using `is_prime`. The first prime number found is printed and the function exits.

This approach efficiently checks each number starting from \( X \) upwards, ensuring we find the smallest prime number efficiently even for larger values of \( X \). The use of square root for divisibility checks and skipping even numbers optimizes the primality test, making the solution both time and space efficient.
