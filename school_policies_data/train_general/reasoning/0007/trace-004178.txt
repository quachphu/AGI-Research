To solve this problem, we need to determine the minimum number of balls to add to each bucket such that the sequence of balls in the buckets becomes non-decreasing and their greatest common divisor (GCD) is strictly greater than 1.

### Approach
1. **Prime Factorization Insight**: The GCD of the adjusted sequence must be a prime number. This is because any composite GCD will have a prime factor that can serve as a valid GCD with a potentially lower number of additions.
2. **Candidate Primes**: For each bucket, consider the number of balls and its next two increments (i.e., the bucket's count and the count after adding 1 and 2 balls). Factorize these values to gather potential prime candidates.
3. **Small Primes**: Additionally, include all primes up to 200 to ensure coverage of small primes that might not be factors of the bucket values but could still be optimal.
4. **Non-Decreasing Check**: For each candidate prime, adjust the bucket values to form a non-decreasing sequence where each value is a multiple of the prime, and track the minimum number of additions required.

### Solution Code
```python
import sys
import math

def generate_primes(max_limit):
    sieve = [True] * (max_limit + 1)
    sieve[0] = sieve[1] = False
    for i in range(2, int(math.sqrt(max_limit)) + 1):
        if sieve[i]:
            sieve[i*i : max_limit+1 : i] = [False] * len(sieve[i*i : max_limit+1 : i])
    primes = [i for i, is_prime in enumerate(sieve) if is_prime]
    return primes

# Precompute primes up to 20000
max_prime_limit = 20000
primes_list = generate_primes(max_prime_limit)

def get_prime_factors(n, primes):
    factors = set()
    if n < 2:
        return factors
    temp = n
    for p in primes:
        if p * p > temp:
            break
        if temp % p == 0:
            factors.add(p)
            while temp % p == 0:
                temp //= p
        if temp == 1:
            break
    if temp > 1:
        factors.add(temp)
    return factors

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr +=1
    for _ in range(T):
        N = int(input[ptr])
        ptr +=1
        arr = list(map(int, input[ptr:ptr+N]))
        ptr +=N
        
        candidates = set()
        for a in arr:
            for delta in [0, 1, 2]:
                num = a + delta
                factors = get_prime_factors(num, primes_list)
                candidates.update(factors)
        # Add primes up to 200
        for p in primes_list:
            if p > 200:
                break
            candidates.add(p)
        # Filter primes >=2 and convert to list
        candidate_primes = [p for p in candidates if p >=2]
        
        min_sum = float('inf')
        for p in candidate_primes:
            current_sum = 0
            prev = 0
            for a in arr:
                current_min = max(prev, a)
                remainder = current_min % p
                if remainder == 0:
                    x = current_min
                else:
                    x = current_min + (p - remainder)
                current_sum += x - a
                prev = x
            if current_sum < min_sum:
                min_sum = current_sum
        print(min_sum)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prime Generation**: We generate all primes up to 20000 using the Sieve of Eratosthenes. This helps in quickly factorizing numbers and checking primes.
2. **Candidate Primes Collection**: For each bucket value and its next two increments, we determine their prime factors to form a set of candidate primes.
3. **Small Primes Inclusion**: We also include primes up to 200 to ensure we don't miss small primes that might offer the optimal solution.
4. **Optimal Adjustments**: For each candidate prime, we adjust the bucket values to form a non-decreasing sequence of multiples of the prime, calculating the required additions. The minimum of these values across all primes is the solution.

This approach efficiently narrows down the primes to check, ensuring both correctness and performance.
