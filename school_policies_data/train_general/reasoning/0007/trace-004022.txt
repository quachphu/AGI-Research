To solve this problem, we need to determine if there exists a KxK submatrix in a given LxR matrix that consists entirely of either 'M' (males) or 'F' (females) for each query. The solution involves precomputing the largest possible square submatrices for each character using dynamic programming, which allows us to efficiently answer each query.

### Approach
1. **Dynamic Programming (DP) Setup**: We create two DP tables, `dp_m` for males and `dp_f` for females. Each cell in these tables will store the size of the largest square submatrix ending at that cell which consists entirely of the respective character.
2. **Max Size Calculation**: While filling the DP tables, we keep track of the maximum size of squares found for both 'M' and 'F'.
3. **Query Handling**: For each query, we check if the requested KxK submatrix size is possible by comparing it against the precomputed maximum sizes. Additionally, we ensure that K does not exceed the dimensions of the matrix.

### Solution Code
```python
l, r, q = map(int, input().split())
matrix = [input().strip() for _ in range(l)]

# Initialize DP tables for 'M' and 'F'
dp_m = [[0] * r for _ in range(l)]
dp_f = [[0] * r for _ in range(l)]
max_m = 0
max_f = 0

for i in range(l):
    for j in range(r):
        # Process 'M' DP
        if matrix[i][j] == 'M':
            if i == 0 or j == 0:
                dp_m[i][j] = 1
            else:
                dp_m[i][j] = min(dp_m[i-1][j], dp_m[i][j-1], dp_m[i-1][j-1]) + 1
            if dp_m[i][j] > max_m:
                max_m = dp_m[i][j]
        else:
            dp_m[i][j] = 0
        
        # Process 'F' DP
        if matrix[i][j] == 'F':
            if i == 0 or j == 0:
                dp_f[i][j] = 1
            else:
                dp_f[i][j] = min(dp_f[i-1][j], dp_f[i][j-1], dp_f[i-1][j-1]) + 1
            if dp_f[i][j] > max_f:
                max_f = dp_f[i][j]
        else:
            dp_f[i][j] = 0

for _ in range(q):
    k_str, c = input().split()
    k = int(k_str)
    min_dim = min(l, r)
    if k > min_dim:
        print("no")
    else:
        if c == 'M' and max_m >= k:
            print("yes")
        elif c == 'F' and max_f >= k:
            print("yes")
        else:
            print("no")
```

### Explanation
1. **Dynamic Programming Tables**: The DP tables `dp_m` and `dp_f` are used to store the size of the largest square submatrix ending at each cell for 'M' and 'F' respectively. This is computed using the minimum value from the top, left, and top-left cells, incremented by 1 if the current cell matches the character.
2. **Max Size Tracking**: As we populate the DP tables, we keep track of the maximum size encountered for each character. This allows us to quickly determine the largest possible K for any query.
3. **Query Processing**: For each query, we check if the requested K is feasible based on the matrix dimensions and the precomputed maximum sizes. This ensures that each query is answered in constant time after preprocessing.

This approach efficiently preprocesses the matrix in O(L*R) time and handles each query in O(1) time, making it suitable for large input sizes.
