To solve this problem, we need to compute the Nth term of a modified Fibonacci series efficiently using matrix exponentiation, which allows us to achieve a time complexity of O(log n). The series starts with given initial terms A and B, and each subsequent term is the sum of the previous two terms.

### Approach
1. **Matrix Exponentiation**: The Fibonacci sequence can be represented using matrix multiplication. The transformation matrix [[1, 1], [1, 0]] raised to the power of (N-2) (for 1-based indexing) helps us compute the Nth term efficiently.
2. **Exponentiation by Squaring**: This technique allows us to compute the power of a matrix in O(log n) time, which is crucial for handling large values of N efficiently.
3. **Base Cases Handling**: Directly return the initial terms A and B for N=1 and N=2 respectively, as they are the starting points of the series.

### Solution Code
```python
def multiply(m1, m2):
    a = m1[0][0] * m2[0][0] + m1[0][1] * m2[1][0]
    b = m1[0][0] * m2[0][1] + m1[0][1] * m2[1][1]
    c = m1[1][0] * m2[0][0] + m1[1][1] * m2[1][0]
    d = m1[1][0] * m2[0][1] + m1[1][1] * m2[1][1]
    return ((a, b), (c, d))

def matrix_power(mat, power):
    result = ((1, 0), (0, 1))  # Identity matrix
    while power > 0:
        if power % 2 == 1:
            result = multiply(result, mat)
        mat = multiply(mat, mat)
        power = power // 2
    return result

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        A = int(input[idx])
        B = int(input[idx+1])
        N = int(input[idx+2])
        idx +=3
        if N == 1:
            print(A)
        elif N == 2:
            print(B)
        else:
            mat = matrix_power(((1, 1), (1, 0)), N-2)
            a, b = mat[0][0], mat[0][1]
            res = a * B + b * A
            print(res)

if __name__ == "__main__":
    main()
```
