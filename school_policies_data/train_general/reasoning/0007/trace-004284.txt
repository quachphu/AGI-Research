The successive shortest augmenting path algorithm with potentials can be implemented as follows:

Initialize potential array (h) to 0 for all nodes.

While the flow is less than required:

   Compute the shortest path from source to sink in the residual graph, using the modified cost (cost + h[u] - h[v]).

   If no path exists, return -1.

   Update the potential h[v] = h[v] + distance[v]

   Augment along the path found.

The code would look something like this:

import heapq

def min_cost_flow(source, sink, required_flow, graph):
    n = len(graph)
    h = [0] * n  # Potential
    prevv = [0] * n
    preve = [0] * n
    INF = float('inf')
    res = 0
    current_flow = 0
    while current_flow < required_flow:
        # Dijkstra to find shortest path in residual graph with modified cost
        dist = [INF] * n
        dist[source] = 0
        heap = []
        heapq.heappush(heap, (0, source))
        while heap:
            d, u = heapq.heappop(heap)
            if d > dist[u]:
                continue
            for i, e in enumerate(graph[u]):
                if e.cap > 0 and dist[e.to] > d + e.cost + h[u] - h[e.to]:
                    dist[e.to] = d + e.cost + h[u] - h[e.to]
                    prevv[e.to] = u
                    preve[e.to] = i
                    heapq.heappush(heap, (dist[e.to], e.to))
        if dist[sink] == INF:
            return -1  # No possible flow
        # Update potential
        for v in range(n):
            h[v] += dist[v] if dist[v] < INF else 0
        # Find the maximum possible flow along the path
        d = required_flow - current_flow
        v = sink
        while v != source:
            d = min(d, graph[prevv[v]][preve[v]].cap)
            v = prevv[v]
        current_flow += d
        res += d * h[sink]
        # Update the residual graph
        v = sink
        while v != source:
            e = graph[prevv[v]][preve[v]]
            e.cap -= d
            graph[v][e.rev].cap += d
            v = prevv[v]
    return res if current_flow == required_flow else -1

This is an implementation of the Dijkstra's algorithm with potentials for finding the shortest paths in each iteration. The potential h is used to adjust the edge costs to be non-negative, allowing Dijkstra to work even with the possible negative costs in the residual graph.
