To solve this problem, we need to determine the number of connected components of black segments after each segment is added to a white line. A connected component is defined as a set of segments that either overlap or touch each other at the endpoints.

### Approach
1. **Maintain Sorted Intervals**: Keep track of the intervals in a sorted manner by their start and end points. This helps in efficiently finding overlapping intervals using binary search.
2. **Binary Search for Overlapping Intervals**: For each new segment, use binary search to find the first interval that ends at or after the new segment's start and the last interval that starts at or before the new segment's end. These intervals form a contiguous block that overlaps with the new segment.
3. **Merge Intervals**: Merge the overlapping intervals into a single interval and update the list of intervals. This ensures that we maintain non-overlapping intervals efficiently.
4. **Count Connected Components**: Track the number of connected components by adjusting the count based on the number of intervals merged with each new segment.
