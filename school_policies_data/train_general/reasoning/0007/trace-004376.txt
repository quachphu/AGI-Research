To solve this problem, we need to efficiently manage the placement of books on a shelf based on given queries and determine the minimum number of books to remove to make a specific book either the leftmost or rightmost. 

### Approach
1. **Data Structure**: Use a dictionary to keep track of the position of each book on the shelf. This allows O(1) time complexity for both insertion and lookup operations.
2. **Position Tracking**: Maintain two variables, `leftmost` and `rightmost`, to track the current extreme positions on the shelf. These variables help in determining the position of new books added to either end.
3. **Query Handling**:
   - **L id**: Place the book to the left of the current leftmost book, updating the position to `leftmost - 1`.
   - **R id**: Place the book to the right of the current rightmost book, updating the position to `rightmost + 1`.
   - **? id**: Calculate the minimum number of books to remove by comparing the distance of the book's position from the current leftmost and rightmost positions.

### Solution Code
```python
import sys

def main():
    q = int(sys.stdin.readline())
    pos = {}
    leftmost = None
    rightmost = None
    for _ in range(q):
        parts = sys.stdin.readline().split()
        if parts[0] in ['L', 'R']:
            id = int(parts[1])
            if not pos:
                pos[id] = 0
                leftmost = 0
                rightmost = 0
            else:
                if parts[0] == 'L':
                    new_pos = leftmost - 1
                    leftmost = new_pos
                else:
                    new_pos = rightmost + 1
                    rightmost = new_pos
                pos[id] = new_pos
        else:
            id = int(parts[1])
            p = pos[id]
            left = p - leftmost
            right = rightmost - p
            print(min(left, right))

if __name__ == "__main__":
    main()
```

### Explanation
- **Initialization**: The first book is placed at position 0, initializing both `leftmost` and `rightmost` to 0.
- **Adding Books**: For each subsequent L or R query, the new book's position is calculated relative to the current `leftmost` or `rightmost` value, which is then updated.
- **Query Resolution**: For each query of type '?', the position of the specified book is retrieved from the dictionary. The minimum number of removals required is determined by the shorter distance to either end of the shelf, computed using the current `leftmost` and `rightmost` values.

This approach ensures efficient handling of up to 200,000 queries with O(1) operations for each insertion, lookup, and query resolution, making it suitable for large input sizes.
