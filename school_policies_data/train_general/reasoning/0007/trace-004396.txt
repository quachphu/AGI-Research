To solve this problem, we need to determine if Imp can use a cloning machine to achieve exactly `x` copied toys and `y` original toys, starting from 1 original toy and 0 copied toys. The cloning machine works differently when applied to an original toy versus a copied toy, and we need to check if the desired configuration is achievable under these constraints.

### Approach
1. **Initial Check for Valid `y`**: 
   - If `y` is 0, it's impossible to achieve because we start with 1 original toy. Thus, the answer is "No".
   - If `y` is 1, check if `x` is 0 (since no operations are needed to maintain 1 original toy and 0 copies). If `x` is 0, the answer is "Yes"; otherwise, "No".

2. **Check for `y` ≥ 2**:
   - The number of original toys increases by 1 each time the machine is applied to an original toy. Therefore, the number of times the machine is applied to original toys is `y - 1`.
   - Each application to an original toy also increases the number of copied toys by 1. After these applications, the remaining copied toys needed must be achievable by applying the machine to copied toys, which increases the count by 2 each time. Thus, the remaining copied toys after accounting for the original applications must be non-negative and even.

### Solution Code
```python
x, y = map(int, input().split())

if y == 0:
    print("No")
elif y == 1:
    print("Yes" if x == 0 else "No")
else:
    required_a = y - 1
    if x < required_a:
        print("No")
    else:
        remaining = x - required_a
        print("Yes" if remaining % 2 == 0 else "No")
```

### Explanation
- **Initial Check for `y`**: The problem starts with 1 original toy, so `y` must be at least 1. If `y` is 0, it's impossible. If `y` is 1, we check if `x` is 0 (the initial state).
- **Applications to Original Toys**: For `y` ≥ 2, we need `y - 1` applications to original toys. Each such application increases both original and copied toys by 1.
- **Remaining Copied Toys**: After accounting for the applications to original toys, the remaining copied toys must be even (since each application to a copied toy adds 2). If the remaining count is non-negative and even, the answer is "Yes"; otherwise, "No".

This approach efficiently checks the necessary conditions using simple arithmetic and modular checks, ensuring optimal performance even for large values up to \(10^9\).
