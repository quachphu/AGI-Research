To solve this problem, we need to determine the number of hits and blows between two 4-digit numbers, where hits are digits that are correct in both value and position, and blows are digits that are correct in value but not in position. The solution involves reading multiple datasets until a termination condition is met and then computing the hits and blows for each dataset.

### Approach
1. **Reading Input**: Read input lines until a line with two zeros is encountered.
2. **Calculate Hits**: For each pair of digits in the same position of the two numbers, count how many are the same (hits).
3. **Determine Non-hit Digits**: Collect digits from both numbers that are not part of the hits.
4. **Calculate Blows**: Using the non-hit digits from the correct answer, count how many digits from the guess exist in these non-hit positions, considering each digit only once even if it appears multiple times in the guess.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        parts = line.split()
        if len(parts) != 2:
            continue
        r, a = parts
        if r == '0' and a == '0':
            break
        hits = sum(1 for i in range(4) if r[i] == a[i])
        
        r_non_hit = []
        a_non_hit = []
        for i in range(4):
            if r[i] != a[i]:
                r_non_hit.append(r[i])
                a_non_hit.append(a[i])
        
        counter = defaultdict(int)
        for d in r_non_hit:
            counter[d] += 1
        
        blow = 0
        for d in a_non_hit:
            if counter[d] > 0:
                blow += 1
                counter[d] -= 1
        
        print(f"{hits} {blow}")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads each line from standard input, processes it, and stops when encountering a line with two zeros.
2. **Hits Calculation**: By iterating through each position of the two numbers, we count how many digits are the same in both value and position.
3. **Non-hit Digits Collection**: For digits that are not hits, we collect them from both the correct answer and the guess.
4. **Blows Calculation**: Using a frequency counter for the non-hit digits of the correct answer, we count how many digits from the guess (non-hit positions) match these non-hit digits, ensuring each digit is counted only once.

This approach efficiently computes the required hits and blows by leveraging direct comparisons and frequency counting, ensuring correctness and optimal performance even for the maximum input size.
