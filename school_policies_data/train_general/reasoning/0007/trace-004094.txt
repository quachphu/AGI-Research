To solve this problem, we need to count the number of valid email substrings in a given string according to specific criteria. The valid email format is defined as follows: a local part starting with a letter followed by letters, numbers, or underscores, followed by an '@', a domain part of letters or numbers, a '.', and ending with a top-level domain (TLD) of letters only.

### Approach
1. **Precompute Arrays**:
   - **alnum_start_b**: Track the start of alphanumeric (letters/digits) runs for the domain part.
   - **letter_run_lengths**: Track the maximum length of consecutive letters starting from each position for the TLD.
   - **earliest_start**: Track the earliest start of valid local parts.
   - **letter_counts**: Prefix sum of letters to count valid starts for local parts.
   - **local_counts**: Count valid local parts ending at each '@' position.
   - **prefix_local**: Prefix sum of local counts for efficient range queries.
   - **prefix_at**: Prefix sum of '@' occurrences.

2. **Iterate Over Dots**:
   For each '.' in the string, check if it can be part of a valid TLD and domain part. Calculate contributions from valid local parts and TLDs.

### Solution Code
```python
import sys

def main():
    s = sys.stdin.readline().strip()
    n = len(s)
    if n == 0:
        print(0)
        return

    # Precompute alnum_start_b for B part (letters/digits)
    alnum_start_b = [-1] * n
    current_start = -1
    for i in range(n):
        c = s[i]
        if c.isalpha() or c.isdigit():
            if current_start == -1:
                current_start = i
            alnum_start_b[i] = current_start
        else:
            current_start = -1
            alnum_start_b[i] = -1

    # Precompute letter_run_lengths for TLD
    letter_run_lengths = [0] * n
    if n > 0:
        letter_run_lengths[-1] = 1 if s[-1].isalpha() else 0
    for i in range(n-2, -1, -1):
        if s[i].isalpha():
            letter_run_lengths[i] = letter_run_lengths[i+1] + 1
        else:
            letter_run_lengths[i] = 0

    # Precompute earliest_start and letter_counts for local parts
    earliest_start = [-1] * n
    current_start = -1
    for i in range(n):
        c = s[i]
        allowed = c.isalpha() or c.isdigit() or c == '_'
        if allowed:
            if current_start == -1:
                if c.isalpha():
                    current_start = i
                else:
                    current_start = -1
            earliest_start[i] = current_start
        else:
            current_start = -1
            earliest_start[i] = -1

    # Compute letter_counts
    letter_counts = [0] * (n + 1)  # 1-based for easier calculation
    count = 0
    for i in range(n):
        if s[i].isalpha():
            count += 1
        letter_counts[i+1] = count  # letter_counts[1] is count up to index 0

    # Compute local_counts and prefix_local
    local_counts = [0] * n
    for i in range(n):
        if s[i] == '@':
            end = i - 1
            if end < 0:
                local_counts[i] = 0
                continue
            es = earliest_start[end]
            if es == -1:
                local_counts[i] = 0
                continue
            a = es
            b = end
            if a > b:
                local_counts[i] = 0
                continue
            # Calculate the number of letters from a to b (inclusive)
            # letter_counts is 1-based
            total_letters = letter_counts[b + 1] - letter_counts[a]
            local_counts[i] = total_letters
        else:
            local_counts[i] = 0

    prefix_local = [0] * (n + 1)
    for i in range(n):
        prefix_local[i+1] = prefix_local[i] + local_counts[i]

    # Precompute prefix_at
    prefix_at = [0] * (n + 1)
    for i in range(n):
        prefix_at[i+1] = prefix_at[i] + (1 if s[i] == '@' else 0)

    total = 0

    for j in range(n):
        if s[j] != '.':
            continue
        # Check TLD
        tld_start = j + 1
        if tld_start >= n:
            continue
        if not s[tld_start].isalpha():
            continue
        tld_length = letter_run_lengths[tld_start]
        if tld_length < 1:
            continue
        # Check B part
        b_end = j - 1
        if b_end < 0:
            continue
        if not (s[b_end].isalpha() or s[b_end].isdigit()):
            continue
        a_start_b = alnum_start_b[b_end]
        if a_start_b == -1:
            continue
        i_min = a_start_b - 1
        i_max = j - 2
        if i_min < 0:
            i_min = 0
        if i_max < i_min:
            continue
        # Check if i_min <= i_max and there's any '@' in this range
        # Calculate the sum of local_counts[i] for i in [i_min, i_max] inclusive
        sum_local = prefix_local[i_max + 1] - prefix_local[i_min]
        total += sum_local * tld_length

    print(total)

if __name__ == "__main__":
    main()
```

### Explanation

   - **letter_run_lengths**: Helps determine valid TLD lengths.
   - **earliest_start**: Tracks valid local part starts.
   - **letter_counts**: Counts valid letters for local parts.
   - **local_counts and prefix_local**: Efficiently count valid local parts for '@' positions.
   - **prefix_at**: Counts '@' occurrences for range queries.

2. **Main Loop**:
   - For each '.' in the string, check if it can be part of a valid TLD.
   - Check the domain part (B part) for valid alphanumeric runs.
   - Sum valid local parts and TLD contributions using precomputed arrays for efficiency.

This approach ensures that we efficiently count valid email substrings by leveraging precomputed data and prefix sums, reducing the complexity from O(n^2) to manageable levels for large inputs.
