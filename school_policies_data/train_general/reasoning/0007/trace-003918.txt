To solve this problem, we need to calculate the total distance traveled by a traveler moving along a highway with post towns over a series of days. The traveler starts at the first post town and moves according to a given sequence of steps each day. The goal is to compute the total distance traveled modulo 100000.

### Approach
1. **Input Reading**: Read the number of post towns (n) and the number of travel days (m).
2. **Prefix Sum Array**: Construct a prefix sum array to quickly compute the distance between any two post towns. This array helps in efficiently calculating the sum of distances between consecutive towns from any starting point to an ending point.
3. **Simulate Each Day's Travel**: For each day, determine the starting and ending post towns, compute the distance using the prefix sum array, and accumulate the total distance traveled.
4. **Modulo Operation**: Since the result can be very large, take the result modulo 100000 at the end to ensure it fits within the required constraints.

### Solution Code
```python
import sys

def main():
    n, m = map(int, sys.stdin.readline().split())
    s = [int(sys.stdin.readline()) for _ in range(n - 1)]
    
    prefix_sum = [0] * n
    for i in range(1, n):
        prefix_sum[i] = prefix_sum[i - 1] + s[i - 1]
    
    current = 1
    total = 0
    
    for _ in range(m):
        a = int(sys.stdin.readline())
        next_town = current + a
        start_idx = current - 1
        end_idx = next_town - 1
        distance = abs(prefix_sum[end_idx] - prefix_sum[start_idx])
        total += distance
        current = next_town
    
    print(total % 100000)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prefix Sum Array**: This array is constructed such that `prefix_sum[i]` represents the cumulative distance from the first post town to the (i+1)-th post town. This allows us to compute the distance between any two post towns in constant time by taking the difference of their corresponding prefix sums.
2. **Daily Travel Calculation**: For each day, the traveler moves from their current post town to another post town. The distance for this movement is calculated using the absolute difference of the prefix sums of the starting and ending post towns. This ensures that we correctly handle both eastward and westward movements.
3. **Efficiency**: The use of the prefix sum array reduces the time complexity of calculating each day's distance to O(1), making the overall complexity O(n + m), which is efficient for the given problem constraints.

This approach ensures that we efficiently compute the total distance traveled while adhering to the problem constraints, providing an optimal solution.
