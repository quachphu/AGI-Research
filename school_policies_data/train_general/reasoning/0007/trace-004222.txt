### Approach
1. **Check Start and End Tiles**: If the first tile (1) or the last tile (N) is unlucky, output "NO".
2. **Sort Unlucky Tiles**: Sort the list of unlucky tiles to check for consecutive sequences.
3. **Check for Three Consecutive Unlucky Tiles**: Iterate through the sorted list and check if there are any three consecutive numbers. If found, output "NO".
4. **Determine Result**: If none of the checks fail, output "YES".

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N = int(input[idx])
        M = int(input[idx+1])
        idx +=2
        unlucky = list(map(int, input[idx:idx+M]))
        idx += M
        if 1 in unlucky or N in unlucky:
            print("NO")
            continue
        unlucky.sort()
        found = False
        for i in range(len(unlucky)-2):
            if unlucky[i+2] == unlucky[i] + 2:
                found = True
                break
        print("NO" if found else "YES")

solve()
```

3. **Sorting**: The unlucky tiles are sorted to facilitate checking for consecutive sequences.
4. **Consecutive Check**: By iterating through the sorted list, we check if any three consecutive tiles are unlucky. The presence of such a sequence means Chahak cannot jump over them, resulting in "NO".
5. **Result Determination**: If no invalid conditions are found, the result is "YES", indicating a valid path exists.
