To solve this problem, we need to determine the number of distinct values obtained from the bitwise OR operation on all possible subarrays of a given array. The challenge is to do this efficiently given the constraints.

### Approach
The key insight is that the bitwise OR operation is cumulative, meaning once a bit is set to 1, it remains 1 for all subsequent subarrays that include the element. This allows us to efficiently track possible OR values for subarrays ending at each position.

1. **Track OR Values**: For each element in the array, maintain a set of possible OR values for subarrays ending at the current position. This set is built by OR-ing the current element with each value from the previous set (for subarrays ending at the previous position) and including the current element itself.
2. **Global Set**: Maintain a global set to collect all unique OR values encountered during the process.
3. **Efficiency**: Since each OR operation can only add bits, the number of distinct OR values for each position is limited by the number of bits in the maximum possible value (e.g., 20 bits for values up to \(10^6\)), making the approach efficient with a time complexity of \(O(n \times b)\), where \(b\) is the number of bits.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))

prev = set()
result = set()

for num in a:
    current = {num}
    for x in prev:
        current.add(x | num)
    prev = current
    result.update(current)

print(len(result))
```

### Explanation
1. **Initialization**: Start with empty sets `prev` (to track OR values for subarrays ending at the previous position) and `result` (to collect all unique OR values).
2. **Iterate Through Elements**: For each element in the array:
   - Create a new set `current` starting with the element itself.
   - Update `current` by OR-ing the element with each value from `prev`.
   - Update `prev` to `current` for the next iteration.
   - Add all values in `current` to the global set `result`.
3. **Result**: The size of `result` gives the number of distinct OR values from all possible subarrays.

This approach efficiently tracks possible OR values using sets, ensuring that each step processes a manageable number of values, leading to an optimal solution for large input sizes.
