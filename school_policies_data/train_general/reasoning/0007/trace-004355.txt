Each step involves donating money to people sitting in a specific range, and the ranges for subsequent steps are generated using a given formula. The solution must efficiently compute the maximum donation received at any position and the smallest index if there are multiple positions with the maximum donation.

### Approach
1. **Difference Array Technique**: Instead of updating each position in the range for every donation step, we use a difference array to efficiently apply range updates. This allows us to handle each donation step in constant time.
2. **Prefix Sum Calculation**: After processing all donation steps, we compute the prefix sum from the difference array to determine the total donation received at each position.
3. **Iterative Query Generation**: Generate each subsequent donation step using the provided recurrence relations, ensuring the ranges are correctly ordered (i.e., swapping if necessary).
4. **Track Maximum Donation**: While computing the prefix sum, keep track of the maximum donation value and the smallest index where this maximum occurs.
