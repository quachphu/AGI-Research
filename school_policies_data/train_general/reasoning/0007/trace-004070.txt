To solve this problem, we need to count the number of even integers in a given list of integers. The solution involves reading input from standard input, processing the data, and then outputting the result. 

### Approach
1. **Reading Input**: The first line of input contains an integer \( N \), which represents the number of integers in the list. The second line contains \( N \) integers separated by spaces.
2. **Processing Data**: For each integer in the list, check if it is even. An integer is even if it is divisible by 2 (i.e., the remainder when divided by 2 is zero).
3. **Counting Evens**: Maintain a counter to keep track of how many even numbers are encountered in the list.
4. **Output the Result**: Print the count of even numbers.

### Solution Code
```python
def count_evens():
    n = int(input())
    numbers = list(map(int, input().split()))
    count = 0
    for num in numbers:
        if num % 2 == 0:
            count += 1
    print(count)

count_evens()
```

### Explanation
1. **Reading Input**: The function reads the integer \( N \) from the first line using `input()` and converts it to an integer. The second line is read and split into a list of integers using `map` and `split`.
2. **Checking Even Numbers**: A loop iterates through each integer in the list. For each integer, it checks if the integer modulo 2 equals zero. If true, the counter is incremented.
3. **Output**: After processing all integers, the count of even numbers is printed.

This approach efficiently processes the input in linear time \( O(N) \), where \( N \) is the number of integers, making it suitable for the given constraints.
