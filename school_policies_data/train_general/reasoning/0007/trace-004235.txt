### Approach
1. **Understanding Requirements**: Each torch requires 1 stick and 1 coal. To craft `k` torches, we need `k` sticks and `k` coals. The initial stick count is 1.
2. **Trades**: 
   - **Stick Trade**: Exchange 1 stick for `x` sticks (net gain of `x-1` sticks per trade).
   - **Coal Trade**: Exchange `y` sticks for 1 coal.
3. **Strategy**:
   - Calculate the total sticks needed for `k` coals and `k` torches: `k * (y + 1)`.
   - Determine the minimum number of stick trades needed to accumulate enough sticks using the formula for the ceiling of a division.
   - Sum the stick trades and coal trades to get the total number of trades.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        x, y, k = map(int, sys.stdin.readline().split())
        s = k * (y + 1)
        numerator = s - 1 + x - 2
        denominator = x - 1
        m1 = numerator // denominator
        print(m1 + k)

if __name__ == "__main__":
    main()
```

2. **Total Sticks Calculation**: The total number of sticks required (`s`) is calculated as `k * (y + 1)`, accounting for both the sticks needed for torches and coal conversion.
3. **Stick Trades Calculation**: Using the formula `(s - 1 + x - 2) // (x - 1)`, we determine the minimum number of stick trades required to accumulate at least `s` sticks.
4. **Total Trades**: The result is the sum of stick trades and coal trades, which is printed for each test case.
