To solve this problem, we need to determine how many unique triangles exist from a given list of triangles. A triangle is considered unique if no other triangle has the same set of sides, regardless of the order of the sides.

### Approach
1. **Reading Input Efficiently**: We read the input efficiently using `sys.stdin` to handle large input sizes.
2. **Normalizing Triangle Sides**: For each triangle, we sort its sides to ensure that triangles with sides in different orders are treated as identical.
3. **Counting Occurrences**: We use a dictionary to count the occurrences of each normalized triangle (sorted tuple of sides).
4. **Identifying Unique Triangles**: After processing all triangles, we count how many triangles have exactly one occurrence in the dictionary.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n = int(sys.stdin.readline())
    count = defaultdict(int)
    for _ in range(n):
        a, b, c = map(int, sys.stdin.readline().split())
        triplet = tuple(sorted((a, b, c)))
        count[triplet] += 1
    unique = sum(1 for v in count.values() if v == 1)
    print(unique)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: We read the number of triangles and then each triangle's sides using `sys.stdin.readline()` for efficiency.
2. **Sorting Sides**: Each triangle's sides are sorted to form a tuple, which allows us to compare triangles regardless of the order of their sides.
3. **Counting with Dictionary**: A dictionary (defaultdict) is used to keep track of how many times each normalized triangle appears.
4. **Counting Unique Triangles**: We iterate through the dictionary values to count how many triangles appeared exactly once, which gives us the number of unique triangles.

This approach ensures that we efficiently handle up to 100,000 triangles with side lengths up to \(10^{15}\), providing an optimal solution both in time and space complexity.
