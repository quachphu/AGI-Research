To solve this problem, we need to determine if there exists a map where the robot's recorded path is the shortest possible path from the starting point to the end point. The robot's path is considered valid if it can be the shortest path in some map with obstructions.

### Approach
1. **Simulate the Path**: Track the robot's movements starting from the origin (0, 0) and record each position visited.
2. **Check for Duplicates**: Ensure all positions in the path are unique. If any position is visited more than once, the path cannot be the shortest.
3. **Validate Adjacent Positions**: For each position in the path, check that none of its adjacent positions (except the previous and next positions in the path) were visited earlier than the step before the current step. This ensures no shorter path exists in any valid map.

### Solution Code
```python
def main():
    moves = input().strip()
    directions = {
        'U': (0, 1),
        'D': (0, -1),
        'R': (1, 0),
        'L': (-1, 0)
    }
    
    x, y = 0, 0
    positions = [(x, y)]
    for move in moves:
        dx, dy = directions[move]
        x += dx
        y += dy
        positions.append((x, y))
    
    # Check for duplicate positions
    if len(positions) != len(set(positions)):
        print("BUG")
        return
    
    # Check each position's adjacent cells
    for i in range(len(positions)):
        current = positions[i]
        for d in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
            neighbor = (current[0] + d[0], current[1] + d[1])
            # Skip previous and next positions
            if i > 0 and neighbor == positions[i-1]:
                continue
            if i < len(positions)-1 and neighbor == positions[i+1]:
                continue
            # Check if this neighbor exists in the positions list
            if neighbor in positions:
                idx = positions.index(neighbor)
                if idx < i - 1:
                    print("BUG")
                    return
    
    print("OK")

main()
```

### Explanation
1. **Simulate the Path**: The robot starts at (0, 0) and moves according to the input string, recording each position visited.
2. **Check for Duplicates**: Convert the list of positions into a set and compare lengths. If they differ, a duplicate exists, making the path invalid.
3. **Validate Adjacent Positions**: For each position, check its adjacent cells. If any adjacent cell (other than the previous and next positions in the path) was visited earlier than the step before the current position, the path is invalid.

This approach ensures that the robot's path is the shortest possible by verifying that no shorter alternative routes exist in any valid map configuration.
