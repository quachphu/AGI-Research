To solve this problem, we need to determine the number of pairs of soldiers whose combined power is a multiple of 3. This can be efficiently calculated by leveraging the properties of modulo arithmetic.

### Approach
1. **Modulo Classification**: Each soldier's power value can be classified based on its remainder when divided by 3. The possible remainders are 0, 1, or 2.
2. **Count Pairs**: 
   - Pairs of soldiers with both powers having a remainder of 0 when divided by 3 will always sum to a multiple of 3.
   - Pairs consisting of one soldier with a remainder of 1 and another with a remainder of 2 will also sum to a multiple of 3.
3. **Mathematical Combinations**:
   - The number of valid pairs from soldiers with remainder 0 is calculated using the combination formula \( C(n, 2) = \frac{n(n-1)}{2} \).
   - The number of valid pairs between soldiers with remainder 1 and those with remainder 2 is simply the product of their counts.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    powers = list(map(int, input().split()))
    count0 = count1 = count2 = 0
    for p in powers:
        mod = p % 3
        if mod == 0:
            count0 += 1
        elif mod == 1:
            count1 += 1
        else:
            count2 += 1
    pairs = (count0 * (count0 - 1) // 2) + (count1 * count2)
    print(pairs)
```

### Explanation
1. **Reading Input**: The input is read in a structured manner where the first value is the number of test cases. For each test case, we first read the number of soldiers and then their respective power values.
2. **Modulo Classification**: Each power value is classified into one of three categories based on its remainder when divided by 3.
3. **Calculating Pairs**: Using the counts from the classification, we compute the valid pairs using the combination formula for remainder 0 values and the product of counts for remainder 1 and 2 values.
4. **Output**: The result for each test case is printed immediately after computation.

This approach ensures that we efficiently count the valid pairs in linear time relative to the number of soldiers, making it optimal for the given problem constraints.
