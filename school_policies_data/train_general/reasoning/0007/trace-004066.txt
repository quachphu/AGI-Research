To solve this problem, we need to determine the number of distinct configurations a freight train can form after being split into two parts, possibly reversed, and then reconnected in either order. The solution involves generating all possible configurations and counting the unique ones.

### Approach
1. **Input Reading**: Read the number of datasets and the subsequent strings representing the train configurations.
2. **Generate Configurations**: For each string, generate all possible configurations by splitting the string at every possible position, reversing each part (if needed), and combining the parts in both possible orders.
3. **Use a Set for Uniqueness**: Utilize a set to collect all generated configurations, ensuring that duplicates are automatically removed.
4. **Count Unique Configurations**: The size of the set after processing all splits gives the number of distinct configurations.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    m = int(input[0])
    for s in input[1:m+1]:
        unique_configs = set()
        n = len(s)
        for k in range(1, n):
            left = s[:k]
            right = s[k:]
            left_rev = left[::-1]
            right_rev = right[::-1]
            for l in (left, left_rev):
                for r in (right, right_rev):
                    combined = l + r
                    unique_configs.add(combined)
                    combined_rev = r + l
                    unique_configs.add(combined_rev)
        print(len(unique_configs))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings. The first element is the number of datasets, followed by the dataset strings.
2. **Processing Each Dataset**: For each dataset string, we initialize a set to keep track of unique configurations.
3. **Splitting the String**: For each possible split position (from 1 to the length of the string minus 1), we divide the string into left and right parts.
4. **Generating Variants**: For each split, we generate the reversed versions of both the left and right parts. We then consider all combinations of the original and reversed parts, concatenating them in both possible orders (left+right and right+left).
5. **Storing Unique Configurations**: Each generated configuration is added to a set, which automatically handles duplicates.
6. **Output**: After processing all splits for a dataset, the size of the set (number of unique configurations) is printed.

This approach efficiently handles all possible transformations and ensures that only unique configurations are counted, providing the correct result for each dataset.
