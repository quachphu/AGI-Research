To solve this problem, we need to determine if there exists a pair of participants whose heights sum up to a given number \( K \). The solution must efficiently check all possible pairs of participants to find such a pair.

### Approach
1. **Problem Analysis**: The problem requires checking if any two distinct participants have heights that add up to \( K \). The key challenge is to do this efficiently given the constraints.
2. **Intuition**: For each participant's height \( h \), we can compute the complement \( K - h \). If this complement exists in the list of heights, we can form a valid pair. However, we need to handle cases where the complement is the same as \( h \) (i.e., \( K \) is twice the height of some participant) by ensuring there are at least two such participants.
3. **Algorithm Selection**: Using a hash map (or a frequency counter) allows us to check the existence of the complement in constant time. This approach reduces the time complexity from \( O(N^2) \) (brute force) to \( O(N) \), which is efficient for the given constraints.
4. **Complexity Analysis**: The solution involves iterating through the list once to build the frequency counter and once more to check each element, resulting in an overall linear time complexity \( O(N) \).

### Solution Code
```python
import sys
from collections import Counter

def main():
    n, k = map(int, sys.stdin.readline().split())
    h = list(map(int, sys.stdin.readline().split()))
    count = Counter(h)
    for num in h:
        comp = k - num
        if comp in count:
            if comp == num:
                if count[comp] >= 2:
                    print("Yes")
                    return
            else:
                print("Yes")
                return
    print("No")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first line contains \( N \) (number of participants) and \( K \) (required sum). The second line contains the heights of the participants.
2. **Frequency Counter**: A `Counter` from the `collections` module is used to count occurrences of each height. This helps in quickly checking the existence and count of any height.
3. **Checking Complements**: For each height in the list, we compute the complement \( K - \text{height} \). If the complement exists in the frequency counter:
   - If the complement is the same as the current height, we check if there are at least two occurrences of this height.
   - If the complement is different, we check if it exists in the counter.
4. **Early Exit**: The solution returns "Yes" as soon as a valid pair is found, ensuring optimal performance. If no valid pair is found after checking all elements, it returns "No".

This approach efficiently handles all edge cases and constraints, providing a robust solution to the problem.
