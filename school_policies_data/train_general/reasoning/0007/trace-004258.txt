To solve this problem, we need to determine if we can select M popular items from N items based on their votes, such that each selected item has at least 1/(4M) of the total votes.

### Approach
1. **Calculate Total Votes**: Sum all the votes received by the N items.
2. **Determine Threshold**: Compute the threshold value as the total votes divided by (4 * M).
3. **Count Eligible Items**: Check how many items have votes greater than or equal to the threshold.
4. **Check Eligibility**: If the number of eligible items is at least M, print "Yes"; otherwise, print "No".

### Solution Code
```python
n, m = map(int, input().split())
a = list(map(int, input().split()))
total = sum(a)
threshold = total / (4 * m)
count = sum(1 for x in a if x >= threshold)
print("Yes" if count >= m else "No")
```

### Explanation
1. **Input Reading**: The code reads the input values for N (number of items), M (number of popular items to select), and the list of votes received by each item.
2. **Total Votes Calculation**: The sum of all votes is computed to determine the total number of votes.
3. **Threshold Calculation**: The threshold is calculated as the total votes divided by (4 * M). This threshold ensures each selected item has at least 1/(4M) of the total votes.
4. **Eligibility Check**: The code counts how many items meet or exceed the threshold. If this count is at least M, it means we can select M popular items, and the answer is "Yes". Otherwise, the answer is "No".

This approach efficiently checks the eligibility of items using straightforward arithmetic operations and a single pass through the list of votes, ensuring an optimal solution.
