2. **Mathematical Insight**: The key insight is to count valid pairs (x, y) where x*y < A*B and x ≠ A and y ≠ B. This can be split into regions based on the integer square root of the product of ranks, which helps in efficiently counting valid pairs.

3. **Efficient Calculation**: Using the integer square root of (A*B - 1), we can split the problem into manageable regions and compute the valid pairs in these regions. This avoids iterating through all possible values up to A*B.

import math
import sys

def main():
    input = sys.stdin.read().split()
    Q = int(input[0])
    idx = 1
    for _ in range(Q):
        A = int(input[idx])
        B = int(input[idx+1])
        idx += 2
        K = A * B
        s = int(math.isqrt(K - 1))
        
        # Calculate total pairs x*y < K
        total = 0
        for x in range(1, s + 1):
            total += (K - 1) // x
        total = 2 * total - s * s
        
        # Subtract pairs where x = A or y = B
        # Pairs with x = A and y < K//A (which is B)
        cx = B - 1 if A != 0 else 0
        # Pairs with y = B and x < K//B (which is A)
        cy = A - 1 if B != 0 else 0
        res = total - cx - cy
        
        # Handle overlapping cases where x < s and y < s
        # Now find the number of pairs where x <= s and y <= s and x*y < K
        # but subtract those where x = A or y = B
        overlap = 0
        if A <= s and B <= s:
            overlap += 1
        if B <= s:
            overlap += min(A-1, s) - (A <= s)
        if A <= s:
            overlap += min(B-1, s) - (B <= s)
        res += overlap
        
        print(res)
