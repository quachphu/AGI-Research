To solve this problem, we need to determine the probability of finding numbers within a given range that are divisible by either of two prime numbers, P1 or P2. The solution must efficiently handle large ranges and multiple test cases.

### Approach
1. **Understanding the Problem**: We need to count numbers in a range [L, R] that are divisible by either P1 or P2. Using the inclusion-exclusion principle, the count of such numbers can be computed as:
   - Count of numbers divisible by P1
   - Plus count of numbers divisible by P2
   - Minus count of numbers divisible by both P1 and P2 (to avoid double-counting).

2. **Mathematical Insight**:
   - The count of numbers divisible by a prime P in a range [L, R] is calculated as `floor(R/P) - floor((L-1)/P)`.
   - The least common multiple (LCM) of P1 and P2 is used to find numbers divisible by both. For primes, LCM(P1, P2) is P1*P2 if they are distinct, and P1 if they are the same.

3. **Efficiency Considerations**:
   - Direct iteration over the range is infeasible for large values. Instead, we use mathematical operations to compute counts in constant time for each query.

### Solution Code
```python
import math

p1, p2 = map(int, input().split())
gcd = math.gcd(p1, p2)
lcm = (p1 * p2) // gcd

t = int(input())
for _ in range(t):
    l, r = map(int, input().split())
    count_p1 = (r // p1) - ((l - 1) // p1)
    count_p2 = (r // p2) - ((l - 1) // p2)
    count_lcm = (r // lcm) - ((l - 1) // lcm)
    total = count_p1 + count_p2 - count_lcm
    probability = total / (r - l + 1)
    print("{0:.6f}".format(probability))
```

### Explanation
1. **Reading Input**: The primes P1 and P2 are read first. The number of test cases T is read next, followed by T pairs of integers L and R representing the ranges.
2. **Computing LCM**: Using the greatest common divisor (GCD), we compute the LCM of P1 and P2 to handle numbers divisible by both.
3. **Count Calculation**:
   - For each range [L, R], we calculate how many numbers are divisible by P1, P2, and their LCM using integer division.
   - The inclusion-exclusion principle is applied to get the total count of valid numbers.
4. **Probability Calculation**: The probability is the ratio of valid numbers to the total numbers in the range, formatted to six decimal places.

This approach ensures that each query is processed in constant time, making the solution efficient even for the upper limits of input constraints.
