To solve this problem, we need to efficiently handle two types of queries on a string: updating a character and counting distinct characters in a substring. Given the constraints, a brute force approach is infeasible, so we use a segment tree to achieve efficient updates and queries.

### Approach
1. **Segment Tree Structure**: Each node in the segment tree stores a bitmask representing the presence of characters in its range. Each bit in the bitmask corresponds to a character from 'a' to 'z'.
2. **Building the Tree**: The tree is built such that each leaf node represents a single character, and internal nodes combine their children's bitmasks using the OR operation.
3. **Update Operation**: When a character is updated, the corresponding leaf node's bitmask is updated, and changes are propagated up the tree.
4. **Query Operation**: To count distinct characters in a range, the OR of the bitmasks for the relevant segments is computed, and the number of set bits in the result is counted.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0

    N = int(input[ptr])
    ptr += 1
    S = input[ptr]
    ptr += 1
    s_list = list(S)
    Q = int(input[ptr])
    ptr += 1

    # Compute next power of two for N
    n = 1
    while n < N:
        n <<= 1
    # Initialize segment tree
    tree = [0] * (2 * n)
    for i in range(N):
        tree[n + i] = 1 << (ord(s_list[i]) - ord('a'))
    # Build the tree
    for i in range(n - 1, 0, -1):
        tree[i] = tree[2 * i] | tree[2 * i + 1]

    for _ in range(Q):
        query_type = input[ptr]
        ptr += 1
        if query_type == '1':
            i_q = int(input[ptr]) - 1
            ptr += 1
            c_q = input[ptr]
            ptr += 1
            if s_list[i_q] == c_q:
                continue
            s_list[i_q] = c_q
            new_mask = 1 << (ord(c_q) - ord('a'))
            pos = i_q
            # Update the tree
            pos_in_tree = n + pos
            tree[pos_in_tree] = new_mask
            pos_in_tree >>= 1
            while pos_in_tree >= 1:
                left = pos_in_tree << 1
                right = left + 1
                tree[pos_in_tree] = tree[left] | tree[right]
                pos_in_tree >>= 1
        else:
            l = int(input[ptr]) - 1
            ptr += 1
            r = int(input[ptr]) - 1
            ptr += 1
            a = l + n
            b = r + n
            res = 0
            while a <= b:
                if a % 2 == 1:
                    res |= tree[a]
                    a += 1
                if b % 2 == 0:
                    res |= tree[b]
                    b -= 1
                a >>= 1
                b >>= 1
            print(bin(res).count('1'))

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the string `S` and the list of queries.
2. **Segment Tree Initialization**: The segment tree is initialized to a size that is the next power of two greater than or equal to `N`. Each leaf node corresponds to a character in the string.
3. **Building the Tree**: The tree is built from the leaves up, combining nodes using the OR operation to form internal nodes.
4. **Handling Updates**: For an update query, the corresponding leaf node's bitmask is updated, and the changes are propagated up the tree.
5. **Handling Range Queries**: For a range query, the OR of all relevant segments is computed, and the number of distinct characters is determined by counting the set bits in the resulting bitmask.

This approach ensures efficient handling of both update and query operations in logarithmic time, making it suitable for large input sizes as specified in the problem constraints.
