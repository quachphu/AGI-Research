To solve this problem, we need to determine the maximum number of blocks into which an array of sand castle heights can be divided such that each block, when sorted individually, results in the entire array being sorted in non-decreasing order.

### Approach
The key insight is to identify split points where the maximum height of all elements up to a certain index is less than or equal to the minimum height of all elements from the next index onwards. This ensures that after sorting each block, the entire array remains sorted.

1. **Precompute Maximums:** Calculate the maximum height from the start up to each index.
2. **Precompute Minimums:** Calculate the minimum height from each index to the end.
3. **Identify Splits:** For each index, check if the maximum height up to that index is less than or equal to the minimum height starting from the next index. Count such valid splits.
4. **Result:** The number of valid splits plus one (since each split adds a block) gives the maximum number of blocks.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    h = list(map(int, input[1:n+1]))
    
    if n == 0:
        print(0)
        return
    
    left_max = [0] * n
    left_max[0] = h[0]
    for i in range(1, n):
        left_max[i] = max(left_max[i-1], h[i])
    
    right_min = [0] * n
    right_min[-1] = h[-1]
    for i in range(n-2, -1, -1):
        right_min[i] = min(h[i], right_min[i+1])
    
    count = 0
    for i in range(n-1):
        if left_max[i] <= right_min[i+1]:
            count += 1
    
    print(count + 1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precompute Maximums:** The `left_max` array stores the maximum height from the start up to each index. This helps in determining the highest castle in any potential block ending at that index.
2. **Precompute Minimums:** The `right_min` array stores the minimum height from each index to the end. This helps in determining the lowest castle in any potential block starting from the next index.
3. **Check Splits:** For each index, if the maximum height up to that index is less than or equal to the minimum height starting from the next index, it means we can split the array at that point. Each valid split is counted.
4. **Result:** The total number of valid splits plus one gives the maximum number of blocks, as each split increases the block count by one.

This approach efficiently computes the required values in linear time, making it suitable for large input sizes up to 100,000 elements.
