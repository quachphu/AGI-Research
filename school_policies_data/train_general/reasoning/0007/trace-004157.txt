To solve this problem, we need to reschedule flights after a delay such that the total cost of delays is minimized. Each flight has a cost per minute of delay, and flights must depart in a new time window starting from the earliest possible time after the delay.

### Approach
1. **Problem Analysis**: Flights are initially scheduled to depart at 1-minute intervals starting from minute 1. Due to a delay, no flights can depart in the first `k` minutes. We need to reschedule all flights between `k+1` and `k+n` minutes such that each flight departs at a unique time and no earlier than its original scheduled time.

2. **Key Insight**: To minimize the total delay cost, flights with higher delay costs should be rescheduled as early as possible within their permissible window. This is because higher cost flights contribute more to the total cost if delayed longer.

3. **Algorithm Selection**: Use a greedy approach combined with a Union-Find (Disjoint Set Union, DSU) data structure. The Union-Find helps efficiently find the earliest available time slot for each flight, ensuring no overlaps.

4. **Sorting**: Sort flights in descending order of their delay cost. For flights with the same cost, sort by their original departure time in descending order to handle ties correctly.

5. **Union-Find**: This data structure helps track the next available time slot efficiently. For each flight, find the earliest available slot starting from its earliest permissible time and update the next available slot.

### Solution Code
```python
import sys

def main():
    n, k = map(int, sys.stdin.readline().split())
    c = list(map(int, sys.stdin.readline().split()))
    
    flights = []
    for i in range(n):
        original_i = i + 1
        flights.append((-c[i], -original_i, original_i))
    flights.sort()
    
    max_time = k + n
    parent = list(range(max_time + 2))  # 0 to max_time +1
    
    def find(t):
        while parent[t] != t:
            parent[t] = parent[parent[t]]
            t = parent[t]
        return t
    
    result = [0] * (n + 1)  # 1-based indexing
    
    for flight in flights:
        _, _, i = flight
        s_i = max(i, k + 1)
        t = find(s_i)
        result[i] = t
        if t + 1 <= max_time + 1:
            parent[t] = find(t + 1)
        else:
            parent[t] = t + 1
    
    total_cost = 0
    for i in range(1, n + 1):
        original_time = i
        new_time = result[i]
        delay = new_time - original_time
        total_cost += delay * c[i - 1]
    
    print(total_cost)
    print(' '.join(map(str, result[1:])))
    
if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of the number of flights `n`, the delay `k`, and the cost per minute of delay for each flight.

2. **Sorting Flights**: Flights are sorted by descending delay cost and, for ties, by descending original departure time. This ensures that higher cost flights and those with later original times (which have later permissible slots) are processed first.

3. **Union-Find Initialization**: A parent array is initialized to track the next available time slot. Each element starts pointing to itself.

4. **Finding and Updating Slots**: For each flight, the earliest available slot starting from `max(i, k+1)` is found using the Union-Find structure. The slot is then marked as used by updating the parent to the next available slot.

5. **Calculating Total Cost**: After assigning all flights, the total delay cost is computed based on the rescheduled times and printed along with the new schedule.

This approach efficiently ensures that higher cost flights are rescheduled first with minimal delays, leading to the optimal total cost. The Union-Find structure allows for efficient slot management, ensuring the solution scales well even for large inputs.
