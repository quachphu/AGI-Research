```python
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        s = input[ptr]
        ptr += 1
        count_b = 0
        count_g = 0
        for i in range(0, 2 * N, 2):
            c = s[i]
            if c == 'B':
                count_b += 1
            else:
                count_g += 1
        swaps_b = N - count_b
        swaps_g = N - count_g
        print(min(swaps_b, swaps_g))

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
- **Counting Correct Positions**: For each test case, we iterate over even indices to count how many boys (for B starting case) and girls (for G starting case) are already in the correct positions.
- **Calculating Swaps**: The number of swaps required for each case is derived from the number of incorrect placements. Each swap fixes two mismatches, so the number of swaps is simply the count of mismatched positions divided by 2.
- **Output**: The minimum number of swaps required from both starting cases is printed for each test case.

This approach ensures that we efficiently compute the result in linear time relative to the input size, making it suitable for large inputs as specified in the problem constraints.
