The solution involves efficiently tracking the plank lengths and their frequencies to check the required conditions after each event.

### Approach
1. **Track Frequencies**: Maintain a frequency map to keep track of the count of each plank length.
2. **Key Metrics**: Track the total number of planks (`sum_total`), the number of planks that can form pairs (`sum_pairs`), and counts of lengths with at least 4 and 8 planks (`count_4` and `count_8` respectively).
3. **Event Handling**: For each event (addition or removal of a plank), update the frequency map and the key metrics.
4. **Condition Checks**: After each event, check if the current set of planks can form the required storages using the following conditions:
   - There exists a length with at least 8 planks.
   - There are at least two different lengths each with at least 4 planks.
   - There exists a length with at least 4 planks and enough pairs of other lengths to form a rectangle.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    freq = defaultdict(int)
    sum_total = 0
    count_4 = 0
    count_8 = 0
    sum_pairs = 0

    # Read initial planks
    n = int(sys.stdin.readline())
    sum_total = n
    a = list(map(int, sys.stdin.readline().split()))
    for x in a:
        old = freq[x]
        freq[x] += 1
        new = old + 1

        # Update count_4 and count_8
        if old < 4 and new >= 4:
            count_4 += 1
        if old < 8 and new >= 8:
            count_8 += 1
        # Update sum_pairs
        sum_pairs += (new // 2) - (old // 2)

    q = int(sys.stdin.readline())
    for _ in range(q):
        line = sys.stdin.readline().strip()
        if not line:
            continue
        op, x = line.split()
        x = int(x)
        old = freq[x]
        if op == '+':
            freq[x] += 1
            new = old + 1
            sum_total += 1
            # Update counts and sum_pairs
            sum_pairs += (new // 2 - old // 2)
            if old < 4 and new >= 4:
                count_4 += 1
            if old < 8 and new >= 8:
                count_8 += 1
        else:
            freq[x] -= 1
            new = old - 1
            sum_total -= 1
            # Update counts and sum_pairs
            sum_pairs += (new // 2 - old // 2)
            if old >= 4 and new < 4:
                count_4 -= 1
            if old >= 8 and new < 8:
                count_8 -= 1

        # Check conditions
        if sum_total < 8:
            print("NO")

            # Check the three conditions

            elif count_4 >= 2:

            else:

if __name__ == "__main__":
```

### Explanation
- **Frequency Tracking**: The frequency map (`freq`) keeps track of how many planks exist for each length.
- **Key Metrics Update**: After each event, we update `sum_total`, `count_4`, `count_8`, and `sum_pairs` based on the change in the plank count for the affected length.
- **Conditions Check**: After each event, we check if the current set of planks can form the required storages using the precomputed metrics. This ensures efficient checking in constant time for each event, making the solution scalable even for large input sizes.
