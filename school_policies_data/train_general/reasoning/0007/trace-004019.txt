To solve this problem, we need to determine if we can unlock a door with a given lock configuration. The lock has N lights arranged in a circle and M buttons, each moving the hand by a certain number of positions. The goal is to check if we can turn on all N lights by pressing the buttons exactly N times.

### Approach
The key insight is to determine if the sequence of button presses can generate all possible positions (mod N) exactly once. This can be checked using the greatest common divisor (GCD) of the button values and N. Specifically, if the GCD of all button values and N is 1, then it is possible to generate all positions; otherwise, it is not.

### Solution Code
```python
import math

def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    n = int(data[0])
    m = int(data[1])
    li = list(map(int, data[2:2+m]))
    
    g = 0
    for num in li:
        g = math.gcd(g, num)
    
    d = math.gcd(g, n)
    print("Yes" if d == 1 else "No")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into integers N (number of lights) and M (number of buttons), followed by the list of button values.
2. **Compute GCD of Button Values**: We compute the GCD of all button values. This GCD determines the common divisor of all possible moves.
3. **Check GCD with N**: The GCD of the computed button GCD and N is checked. If this result is 1, it means the button values can generate all positions modulo N, allowing all lights to be turned on. Otherwise, it is impossible to turn on all lights.

This approach efficiently checks the necessary mathematical condition using GCD, ensuring the solution is both optimal and correct for large values of N and M.
