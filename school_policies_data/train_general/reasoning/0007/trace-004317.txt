### Approach
1. **Merge Sort Algorithm**: This is a divide-and-conquer algorithm that splits the array into two halves, recursively sorts each half, and then merges the sorted halves. The key operation here is the merge step, which combines two sorted subarrays into one sorted array.
2. **Counting Comparisons**: During the merge step, each time we compare elements from the two subarrays, we increment a counter. This counter is maintained across all recursive calls to accurately track the total number of comparisons.

def merge_sort(A, left, right, count):
    if left + 1 < right:
        mid = (left + right) // 2
        merge_sort(A, left, mid, count)
        merge_sort(A, mid, right, count)
        merge(A, left, mid, right, count)

def merge(A, left, mid, right, count):

    n2 = right - mid

    sentinel = float('inf')
    L.append(sentinel)

        if L[i] <= R[j]:
            A[k] = L[i]
            i += 1
        else:
            A[k] = R[j]
            j += 1
        count[0] += 1
