This involves pooling all stakes, deducting a certain percentage, and distributing the remaining amount to the winners proportionally. The solution must handle multiple datasets and output the payout for each.

### Approach
1. **Input Handling**: Read all input tokens at once to efficiently process multiple datasets.
2. **Pool Calculation**: Sum all the stakes (each stake is 100 gold) to form the total pool.
3. **Deduction**: Subtract the specified percentage from the total pool.
4. **Winning Tickets Check**: Determine the number of tickets for the winning player. If there are no winning tickets, the payout is zero.
5. **Payout Calculation**: Distribute the remaining pool to the winning tickets, ensuring the result is floored to an integer if necessary.

### Solution Code
```python
def main():
    import sys
    tokens = list(map(int, sys.stdin.read().split()))
    idx = 0
    while idx < len(tokens):
        n = tokens[idx]
        m = tokens[idx + 1]
        p = tokens[idx + 2]
        idx += 3
        if n == 0 and m == 0 and p == 0:
            break
        xi = tokens[idx: idx + n]
        idx += n
        sum_xi = sum(xi)
        if m < 1 or m > n:
            xm = 0
        else:
            xm = xi[m - 1]
        if xm == 0:
            print(0)
        else:
            remaining = sum_xi * (100 - p)
            payout = remaining // xm
            print(payout)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into tokens for easy processing. This handles any extraneous whitespace or newlines.
2. **Dataset Processing**: Each dataset starts with three integers (N, M, P). Subsequent integers are the number of tickets for each player.
3. **Pool and Deduction**: The total pool is calculated by summing all tickets and multiplying by 100. A percentage (P) is deducted, leaving the remaining pool.
4. **Winning Check**: The number of winning tickets (for player M) is checked. If zero, the payout is zero.
5. **Payout Calculation**: The remaining pool is divided by the number of winning tickets, with the result floored to ensure an integer value.

This approach efficiently processes each dataset, ensuring correct handling of all edge cases and constraints.
