To solve this problem, we need to determine the average sum of the digits of a number \( A \) when written in all bases from 2 to \( A-1 \). The result should be presented as an irreducible fraction.

### Approach
1. **Sum of Digits in Different Bases**: For each base \( b \) from 2 to \( A-1 \), convert the number \( A \) into base \( b \) and compute the sum of its digits. This is done by repeatedly dividing \( A \) by \( b \) and summing the remainders.
2. **Summing the Totals**: Accumulate the sum of the digit sums from all bases.
3. **Fraction Reduction**: Compute the average by dividing the total sum by the number of bases (which is \( A-2 \)). Simplify the resulting fraction using the greatest common divisor (GCD).

### Solution Code
```python
import math

def main():
    A = int(input())
    sum_total = 0
    for b in range(2, A):
        n = A
        s = 0
        while n > 0:
            s += n % b
            n = n // b
        sum_total += s
    denominator = A - 2
    gcd_val = math.gcd(sum_total, denominator)
    x = sum_total // gcd_val
    y = denominator // gcd_val
    print(f"{x}/{y}")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input integer \( A \) is read.
2. **Iterating Over Bases**: For each base from 2 to \( A-1 \), the number \( A \) is converted to that base. The conversion is done by repeatedly dividing \( A \) by the base and summing the remainders, which gives the sum of the digits in that base.
3. **Summing Digit Sums**: The sum of digits for each base is accumulated into `sum_total`.
4. **Computing the Average**: The average is calculated as the total sum divided by the number of bases (\( A-2 \)).
5. **Simplifying the Fraction**: The fraction representing the average is simplified by dividing both the numerator and denominator by their GCD, ensuring the result is in its simplest form.

This approach efficiently computes the required average by leveraging mathematical operations to convert numbers to different bases and sum their digits, ensuring correctness and performance for the given constraints.
