To solve this problem, we need to determine the minimum day on which Borya can finish visiting all doctors in the prescribed order, considering each doctor's specific working schedule. Each doctor works on a starting day and then periodically every specified number of days. Borya can only visit one doctor per day, so each subsequent visit must be scheduled after the previous one.

### Approach
1. **Initialization**: Start with the current day set to 0.
2. **Iterate through each doctor**: For each doctor, calculate the earliest possible day Borya can visit them after the previous visit.
3. **Determine the earliest day for each doctor**:
   - If the doctor's starting day is after the day following the last visit, use the doctor's starting day.
   - If not, compute the earliest day using the formula to find the next valid day in the doctor's schedule that is after the last visit day.
4. **Update the current day**: After determining the earliest possible day for each doctor, update the current day to this day and proceed to the next doctor.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    current_day = 0
    for _ in range(n):
        s = int(input[idx])
        d = int(input[idx + 1])
        idx += 2
        desired = current_day + 1
        if s >= desired:
            current_day = s
        else:
            delta = desired - s
            k = (delta + d - 1) // d
            current_day = s + k * d
    print(current_day)

main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially with larger input sizes. The number of doctors `n` is read first.
2. **Processing Each Doctor**: For each doctor, their starting day `s` and interval `d` are read.
3. **Calculating the Earliest Visit Day**:
   - **Desired Day**: The day after the last visit (`current_day + 1`).
   - **Check Starting Day**: If the doctor's starting day is on or after the desired day, use it directly.
   - **Calculate Next Valid Day**: If the starting day is before the desired day, compute the next valid day using integer arithmetic to avoid floating-point operations. This ensures the solution is efficient and accurate.
4. **Update Current Day**: After determining the earliest valid day for the current doctor, update `current_day` to this day.

This approach efficiently calculates the minimum day required for Borya to visit all doctors in order, ensuring each visit is on a valid working day and adhering to the constraint of one visit per day.
