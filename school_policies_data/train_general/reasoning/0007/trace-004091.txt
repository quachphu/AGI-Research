To solve this problem, we need to determine the Formula One champion based on two different scoring systems. The first system prioritizes total points, while the second system prioritizes the number of wins (first places). We need to process race results to compute scores and positions for each driver and then determine the champions using both systems.

### Approach
1. **Data Collection**: For each driver, track their total points and the count of each position they achieved in every race.
2. **Original Scoring System**: The champion is determined by total points. In case of a tie, the driver with the most wins (first places) is chosen, followed by the most second places, and so on.
3. **Alternative Scoring System**: The champion is determined by the most wins. In case of a tie, total points are considered. If still tied, the driver with the most second places is chosen, followed by third places, and so on.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    t = int(sys.stdin.readline())
    points = [25, 18, 15, 12, 10, 8, 6, 4, 2, 1]
    drivers = defaultdict(lambda: {'points': 0, 'positions': [0] * 50})

    for _ in range(t):
        n = int(sys.stdin.readline().strip())
        race_drivers = [sys.stdin.readline().strip() for _ in range(n)]
        for i in range(n):
            name = race_drivers[i]
            driver = drivers[name]
            pos_in_race = i + 1
            if pos_in_race <= 50:
                driver['positions'][pos_in_race - 1] += 1
            if i < 10:
                driver['points'] += points[i] if i < len(points) else 0

    drivers_list = list(drivers.items())

    # Sort for original system
    def original_key(item):
        return (-item[1]['points'],) + tuple(-cnt for cnt in item[1]['positions'])

    sorted_original = sorted(drivers_list, key=original_key)
    original_champion = sorted_original[0][0]

    # Sort for alternative system
    def alternative_key(item):
        return (-item[1]['positions'][0], -item[1]['points']) + tuple(-cnt for cnt in item[1]['positions'][1:])

    sorted_alternative = sorted(drivers_list, key=alternative_key)
    alternative_champion = sorted_alternative[0][0]

    print(original_champion)
    print(alternative_champion)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read line by line, starting with the number of races. Each race's results are processed to update the drivers' points and positions.
2. **Points Calculation**: For each race, points are awarded to the top 10 drivers based on their positions. The points array `[25, 18, 15, 12, 10, 8, 6, 4, 2, 1]` is used for this calculation.
3. **Position Tracking**: Each driver's positions are tracked in an array where the index represents the position (1st, 2nd, etc.) and the value at that index represents the count of times the driver finished in that position.
4. **Sorting Drivers**: For the original system, drivers are sorted by points, then by the count of positions starting from first place. For the alternative system, drivers are sorted by the number of wins, then by points, and finally by the count of positions starting from second place.

This approach ensures that we efficiently determine the champions for both scoring systems by leveraging sorting with custom keys based on the problem's requirements.
