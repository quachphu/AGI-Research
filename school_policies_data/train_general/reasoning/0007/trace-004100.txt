To solve this problem, we need to determine the number of substrings of a given string of digits that form a number divisible by 4. The solution involves checking both single-digit and two-digit substrings efficiently.

### Approach
1. **Single-digit Substrings**: A single-digit number is divisible by 4 if it is 0, 4, or 8. We count each occurrence of these digits in the string.
2. **Two-digit Substrings**: A number is divisible by 4 if its last two digits form a number that is divisible by 4. For each pair of consecutive digits in the string, if the pair forms a number divisible by 4, all substrings ending at the second digit of the pair are valid. The number of such substrings is determined by the starting position of the pair.

### Solution Code
```python
s = input().strip()
count = 0
n = len(s)

# Count single-digit substrings
for c in s:
    if c in {'0', '4', '8'}:
        count += 1

# Count two-digit substrings and their contributions
for i in range(n - 1):
    two_digit = int(s[i]) * 10 + int(s[i + 1])
    if two_digit % 4 == 0:
        count += (i + 1)

print(count)
```

### Explanation
1. **Single-digit Check**: Iterate through each character in the string. For each character, check if it is '0', '4', or '8'. Each valid character contributes 1 to the count.
2. **Two-digit Check**: Iterate through each consecutive pair of digits in the string. Convert each pair into an integer and check if it is divisible by 4. If it is, the number of valid substrings ending at this pair is equal to the starting index of the pair plus 1 (since substrings can start from any position from the beginning of the string up to the start of the pair).

This approach ensures that we efficiently count all valid substrings in linear time, O(n), where n is the length of the string, making it suitable for large input sizes.
