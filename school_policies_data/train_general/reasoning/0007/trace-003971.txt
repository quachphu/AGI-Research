To solve this problem, we need to process multiple datasets to find words that start with a given character, count their occurrences, and output the top 5 words sorted by frequency and lexicographic order. If no words match, we output "NA".

### Approach
1. **Input Handling**: Read all input lines at once and process them as datasets. Each dataset starts with an integer `n` followed by `n` lines of text and a character `k`.
2. **Word Extraction**: For each dataset, split the text lines into individual words.
3. **Filtering Words**: Filter words that start with the given character `k`.
4. **Frequency Counting**: Count the occurrences of each filtered word.
5. **Sorting**: Sort the words primarily by their frequency in descending order and secondarily by lexicographic order in ascending order.
6. **Output**: Print up to 5 top words or "NA" if no words match.

### Solution Code
```python
import sys

def main():
    lines = [line.rstrip('\n') for line in sys.stdin]
    while True:
        if not lines:
            break
        n_str = lines.pop(0)
        n = int(n_str)
        if n == 0:
            break
        text_lines = []
        for _ in range(n):
            text_lines.append(lines.pop(0))
        k = lines.pop(0)
        words = []
        for line in text_lines:
            words.extend(line.split())
        filtered = [word for word in words if word.startswith(k)]
        if not filtered:
            print("NA")
            continue
        freq = {}
        for word in filtered:
            freq[word] = freq.get(word, 0) + 1
        sorted_words = sorted(freq.keys(), key=lambda x: (-freq[x], x))
        top = sorted_words[:5]
        print(' '.join(top))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and processed line by line. Each dataset is identified by the integer `n`, followed by `n` text lines and a character `k`.
2. **Extracting and Filtering Words**: Each line of text is split into words. Words starting with the character `k` are filtered out.
3. **Counting Frequencies**: A dictionary is used to count the occurrences of each filtered word.
4. **Sorting**: The words are sorted by their frequency in descending order. If frequencies are the same, words are sorted lexicographically in ascending order.
5. **Output**: The top 5 words are printed. If no words match the criteria, "NA" is printed.

This approach ensures efficient handling of input and processing, adhering to the problem constraints and requirements.
