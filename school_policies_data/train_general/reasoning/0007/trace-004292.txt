To solve this problem, we need to determine the order of Polycarp's chat list after processing all his messages. The chat list moves a friend's chat to the top whenever a message is sent to them. The goal is to efficiently track the order of chats based on the most recent messages.

### Approach
1. **Track Last Occurrences**: For each friend, keep track of the last time they received a message. This can be efficiently done using a dictionary where the key is the friend's name and the value is the index of the last message sent to them.
2. **Sort by Last Occurrence**: After processing all messages, sort the friends based on their last occurrence in descending order. This ensures that the most recently messaged friend appears first in the output.

### Solution Code
```python
n = int(input())
messages = [input().strip() for _ in range(n)]
last_occurrence = {}

for idx, friend in enumerate(messages):
    last_occurrence[friend] = idx

sorted_friends = sorted(last_occurrence.keys(), key=lambda x: -last_occurrence[x])

for friend in sorted_friends:
    print(friend)
```

### Explanation
1. **Reading Input**: We first read the number of messages and then the messages themselves.
2. **Tracking Last Occurrences**: Using a dictionary, we update the last occurrence index for each friend every time they receive a message.
3. **Sorting and Output**: We sort the friends based on their last occurrence indices in descending order and print them. This ensures the most recently messaged friends appear first, maintaining the correct order of the chat list as per the problem's requirements.

This approach efficiently handles up to 200,000 messages with a time complexity of O(n log n) due to the sorting step, which is feasible given the problem constraints.
