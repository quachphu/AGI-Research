To solve this problem, we need to distribute candy bags such that each of Gerald's brothers receives an equal number of candies. The key is to form groups of candy bags such that each group sums to the same total.

### Approach
1. **Understand the Total Candies**: The sum of all candies from 1 to \( n^2 \) is \( \frac{n^2(n^2 + 1)}{2} \). Since each of the \( n \) brothers must receive an equal share, each brother's total is \( \frac{n(n^2 + 1)}{2} \).

2. **Pair Formation**: Create pairs of numbers that sum to \( n^2 + 1 \). For example, if \( n = 2 \), pairs are (1, 4) and (2, 3), each summing to 5.

3. **Group Formation**: Each brother will receive \( n/2 \) such pairs. This ensures the sum of each group is the required total. For \( n = 4 \), each group of two pairs (e.g., (1, 16) and (2, 15)) sums to 34.

### Solution Code
```python
n = int(input())
n_squared = n * n
pairs = []
for i in range(1, (n_squared // 2) + 1):
    pairs.append((i, n_squared + 1 - i))

group_size = n // 2
groups = [pairs[i:i + group_size] for i in range(0, len(pairs), group_size)]

for group in groups:
    elements = []
    for p in group:
        elements.extend(map(str, p))
    print(' '.join(elements))
```

### Explanation
1. **Pair Generation**: Generate pairs of numbers such that each pair sums to \( n^2 + 1 \). For example, if \( n = 4 \), pairs are (1, 16), (2, 15), (3, 14), etc.

2. **Group Formation**: Split these pairs into groups of \( n/2 \) pairs each. Each group will contain \( n \) elements (since each pair contributes 2 elements and \( n/2 \) pairs contribute \( n \) elements).

3. **Output**: For each group, flatten the pairs into a list of numbers and print them. This ensures each brother gets exactly \( n \) bags with the correct sum.

This approach efficiently partitions the candy bags using mathematical properties, ensuring each brother receives an equal share with minimal computation.
