To solve this problem, we need to determine the minimum number of moves required for Petya to repaint a stripe of squares such that no two adjacent squares have the same color. Each move allows Petya to repaint any two adjacent squares of the same color to any other colors (black or white).

### Approach
1. **Understand Target Patterns**: The valid target patterns are alternating colors starting with either '0' or '1'. For example, for a stripe of length 6, the valid patterns are '010101' and '101010'.

2. **Identify Errors**: For each target pattern, identify the positions where the initial stripe does not match the target pattern. These positions are called errors.

3. **Count Adjacent Error Pairs**: For each target pattern, count the number of adjacent error pairs (consecutive positions where the initial stripe has the same color). These pairs can be fixed in one move.

4. **Calculate Moves**: The minimum number of moves required for each target pattern is determined by subtracting the number of adjacent error pairs from the total number of errors. This is because each adjacent error pair can be fixed in one move.

5. **Determine the Result**: The result is the minimum number of moves required between the two target patterns. If both target patterns are impossible to achieve, return -1.
