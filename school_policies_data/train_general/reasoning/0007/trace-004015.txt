To solve this problem, we need to determine the minimum number of lanterns required along the streets connecting historic sites such that all sites are connected via streets with lanterns. The key is to minimize the number of lanterns while ensuring all sites are reachable.

### Approach
1. **Problem Analysis**:
   - The problem requires connecting all historic sites with the minimum number of lanterns. Each lantern must be placed 100 meters apart, but not at the sites themselves.
   - The distance between any two sites is a multiple of 100 meters and at least 200 meters. For a road of length `d` meters, the number of lanterns needed is `(d // 100) - 1`.

2. **Graph Representation**:
   - The historic sites and roads form a graph where sites are nodes and roads are edges with weights equal to their lengths.

3. **Minimum Spanning Tree (MST)**:
   - The goal is to find an MST that connects all nodes (historic sites) with the minimum total road length. Using Kruskal's algorithm, we can efficiently find the MST.

4. **Calculate Lanterns**:
   - Once the MST is found, the total number of lanterns is calculated by summing the lanterns required for each road in the MST, which is `(total length of MST edges // 100) - (number of edges in MST)`.

### Solution Code
```python
import sys

def main():
    lines = sys.stdin.read().splitlines()
    ptr = 0
    while True:
        if ptr >= len(lines):
            break
        n = int(lines[ptr])
        ptr += 1
        if n == 0:
            break
        m = int(lines[ptr])
        ptr += 1
        edges = []
        for _ in range(m):
            parts = lines[ptr].split(',')
            a = int(parts[0])
            b = int(parts[1])
            d = int(parts[2])
            edges.append((d, a, b))
            ptr += 1
        edges.sort()
        parent = list(range(n))
        
        def find(u):
            while parent[u] != u:
                parent[u] = parent[parent[u]]  # Path compression
                u = parent[u]
            return u
        
        sum_d = 0
        edges_used = 0
        for d, a, b in edges:
            root_a = find(a)
            root_b = find(b)
            if root_a != root_b:
                parent[root_b] = root_a
                sum_d += d
                edges_used += 1
                if edges_used == n - 1:
                    break
        total_lanterns = (sum_d // 100) - (n - 1)
        print(total_lanterns)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**:
   - The input is read line by line, parsing the number of sites and roads for each dataset.

2. **Kruskal's Algorithm**:
   - Edges are sorted by length. Using a union-find data structure with path compression, we efficiently add edges to the MST while avoiding cycles.

3. **Calculating Lanterns**:
   - The total length of the MST edges is used to compute the number of lanterns. Each edge contributes `(d // 100 - 1)` lanterns, and the sum is adjusted by subtracting the number of edges in the MST (since each edge has one fewer lantern than the division result).

This approach ensures we find the optimal number of lanterns efficiently using graph theory principles, specifically the MST to minimize total road length.
