To solve this problem, we need to determine the minimum time after which all dishes ordered by Petya can be at his home. Each dish can either be delivered by a courier or picked up by Petya himself. The goal is to minimize the maximum time between the sum of times for self-picked dishes and the maximum delivery time of the couriers.

### Approach
1. **Problem Analysis**: 
   - For each dish, we have two options: courier delivery (time `a_i`) or self-pickup (time `b_i`).
   - The total time required is the maximum of the sum of self-pickup times and the maximum courier delivery time.
   - The challenge is to determine the optimal subset of dishes to self-pickup such that the maximum time is minimized.

2. **Key Insight**:
   - We need to balance the sum of self-pickup times (`sum_b`) and the maximum courier delivery time (`max_a`).
   - Use binary search to find the minimum possible maximum time `M` such that the sum of self-pickup times for dishes with delivery times exceeding `M` is within `M`.

3. **Algorithm**:
   - **Sorting**: Sort dishes by their courier delivery times.
   - **Suffix Sum Array**: Compute suffix sums of self-pickup times to efficiently calculate sums for subsets.
   - **Binary Search**: Determine the smallest `M` where the sum of self-pickup times for dishes with `a_i > M` is within `M`.

### Solution Code
```python
import bisect
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        a = list(map(int, input[ptr:ptr+n]))
        ptr += n
        b = list(map(int, input[ptr:ptr+n]))
        ptr += n
        
        sorted_ab = sorted(zip(a, b), key=lambda x: x[0])
        sorted_a = [x[0] for x in sorted_ab]
        sorted_b = [x[1] for x in sorted_ab]
        
        # Compute suffix sums of sorted_b
        suffix_sums = [0] * (n + 1)
        for i in range(n-1, -1, -1):
            suffix_sums[i] = suffix_sums[i+1] + sorted_b[i]
        
        sum_all_b = sum(b)
        max_a = max(a) if n > 0 else 0
        low = 0
        high = max(sum_all_b, max_a)
        answer = high
        
        while low <= high:
            mid = (low + high) // 2
            idx = bisect.bisect_right(sorted_a, mid)
            sum_mandatory = suffix_sums[idx]
            if sum_mandatory <= mid:
                answer = mid
                high = mid - 1
            else:
                low = mid + 1
        
        print(answer)

if __name__ == "__main__":
    main()
```

2. **Sorting**: Dishes are sorted by their courier delivery times to facilitate efficient range queries.
3. **Suffix Sum Array**: This array helps quickly compute the sum of self-pickup times for any suffix of the sorted list.
4. **Binary Search**: The binary search is performed on possible values of `M` to find the minimum valid maximum time. For each `M`, we check if the sum of self-pickup times for dishes with delivery times exceeding `M` is within `M`, adjusting the search range based on the result.

This approach efficiently balances the trade-off between self-pickup times and courier delivery times, ensuring the optimal solution is found within acceptable time complexity.
