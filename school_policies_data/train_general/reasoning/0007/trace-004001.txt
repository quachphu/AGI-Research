To solve this problem, we need to determine the optimal fare charges for each trip made by a passenger using a public transport ticketing system. The system automatically selects the cheapest combination of tickets (single trip, 90-minute, or daily) to cover all trips up to the current one, and charges the passenger the difference between the current optimal fare and the total charges made so far.

### Approach
1. **Dynamic Programming (DP) Setup**: We use a dynamic programming array `dp` where `dp[i]` represents the minimum cost to cover all trips from the first up to the i-th trip.
2. **Binary Search for Ticket Coverage**: For each trip, we determine the earliest trip that can be covered by a 90-minute or daily ticket starting from the current trip time. This is efficiently done using binary search.
3. **Cost Calculation**: For each trip, compute the cost using three possible ticket options:
   - A single ticket for the current trip.
   - A 90-minute ticket covering the current and previous relevant trips.
   - A daily ticket covering the current and previous relevant trips.
4. **Charge Calculation**: The charge for each trip is the difference between the current optimal fare and the total charges up to the previous trip.

### Solution Code
```python
import bisect

n = int(input())
times = [int(input()) for _ in range(n)]

if n == 0:
    exit()

dp = [0] * n
dp[0] = 20  # The first trip's minimum cost is 20 (single ticket)

charges = [20]

for i in range(1, n):
    ti = times[i]
    
    # Calculate the 90-minute ticket option
    target_90 = ti - 89
    j_90 = bisect.bisect_left(times, target_90, 0, i + 1)
    cost_90 = 50
    if j_90 > 0:
        cost_90 += dp[j_90 - 1]
    
    # Calculate the day ticket option
    target_day = ti - 1439
    j_day = bisect.bisect_left(times, target_day, 0, i + 1)
    cost_day = 120
    if j_day > 0:
        cost_day += dp[j_day - 1]
    
    # Calculate the single ticket option
    cost_single = dp[i - 1] + 20
    
    # Determine the minimum cost
    min_cost = min(cost_single, cost_90, cost_day)
    dp[i] = min_cost
    
    # Calculate the charge for this trip
    charge = dp[i] - dp[i - 1]
    charges.append(charge)

for c in charges:
    print(c)
```

### Explanation
1. **Reading Input**: The input consists of the number of trips followed by the start times of each trip in ascending order.
2. **Dynamic Programming Array Initialization**: The `dp` array is initialized where `dp[0]` is set to 20 since the first trip can only be covered by a single ticket.
3. **Binary Search for Optimal Coverage**: For each subsequent trip, we use binary search to find the earliest trip that can be covered by a 90-minute or daily ticket starting from the current trip time.
4. **Cost Calculation**: For each ticket type, the cost is calculated considering the optimal coverage of previous trips. The minimum cost among the three options is stored in the `dp` array.
5. **Charge Calculation**: The charge for each trip is computed as the difference between the current optimal fare and the cumulative charges up to the previous trip, which is then printed as the result.

This approach ensures that we efficiently compute the minimal charges using dynamic programming and binary search, resulting in an optimal solution with a time complexity of O(n log n).
