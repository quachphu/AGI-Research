To solve this problem, we need to determine how many days remain until the next Sunday given a specific day of the week. The solution involves leveraging the order of days in a week and calculating the difference between the given day and Sunday.

### Approach
1. **Understand the Order of Days**: The days of the week are ordered from Sunday to Saturday. We can represent this order using a list where each day is positioned according to its occurrence in the week.
2. **Index Calculation**: By finding the index of the given day in the list, we can determine its position relative to Sunday.
3. **Days Until Next Sunday**: The next Sunday can be found by calculating the difference between 7 (total days in a week) and the index of the given day. This difference gives the number of days from the given day to the next Sunday.

### Solution Code
```python
def main():
    days = ['SUN', 'MON', 'TUE', 'WED', 'THU', 'FRI', 'SAT']
    s = input().strip()
    idx = days.index(s)
    print(7 - idx)

main()
```

### Explanation
1. **List of Days**: The list `days` is created to represent the order of the days starting from Sunday.
2. **Input Handling**: The input day `s` is read and stripped of any extra whitespace.
3. **Index Determination**: The index of the input day `s` is found using the `index` method of the list.
4. **Calculate Days Until Sunday**: The number of days until the next Sunday is computed by subtracting the index of the input day from 7. This works because the index of Sunday is 0, so subtracting the index of the given day from 7 directly gives the number of days remaining until the next Sunday.

This approach efficiently computes the result in constant time, O(1), by leveraging list indexing and simple arithmetic operations.
