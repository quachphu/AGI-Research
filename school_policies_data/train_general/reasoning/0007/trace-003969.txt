To solve this problem, we need to determine the maximum number of people that can sit on a seat of given width, considering that each person occupies a specific length and requires a minimum gap between themselves and others, as well as from the ends of the seat.

### Approach
The key insight is to model the problem mathematically. Each person requires a segment of the seat for themselves and the necessary gaps. Specifically, each person needs:
1. A gap of at least Z centimeters before they start sitting.
2. Their own length Y centimeters.
3. A gap of Z centimeters after they end, except for the last person, who only needs the gap before the next person or the end of the seat.

By observing the pattern, we can derive that the total length required for k people is given by the formula:
\[ k \times Y + (k + 1) \times Z \]

However, to simplify calculations, we can rearrange this formula to find the maximum number of people (k) that can fit into the seat length X. This reduces to solving:
\[ k \leq \frac{X - Z}{Y + Z} \]

This formula accounts for the space each person and their subsequent gap requires, ensuring the constraints are met.

### Solution Code
```python
X, Y, Z = map(int, input().split())
print((X - Z) // (Y + Z))
```

### Explanation
1. **Reading Input:** The input values for X (seat width), Y (person's length), and Z (minimum gap) are read.
2. **Formula Application:** Using the derived formula, we compute the maximum number of people by integer division of (X - Z) by (Y + Z). This calculation ensures that we account for the necessary gaps and the space each person occupies.
3. **Output Result:** The result is printed, which is the maximum number of people that can be seated under the given constraints.

This approach efficiently computes the result in constant time, O(1), making it suitable for large input values up to \(10^5\).
