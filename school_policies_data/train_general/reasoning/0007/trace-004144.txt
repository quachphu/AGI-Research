To solve this problem, we need to determine if a given array contains a subsequence of length at least 3 that forms a palindrome. A palindrome reads the same forwards and backwards, and a subsequence can be formed by removing elements from the array without changing the order of the remaining elements.

### Approach
The key insight is that a palindrome of length 3 can be formed if there exists a pair of identical elements in the array with at least one element between them. This is because the first and third elements of such a subsequence must be the same, with any element in between. 

To efficiently check for this condition:
1. Track the first and last occurrence of each element in the array.
2. For each element, check if the distance between its first and last occurrence is at least 2. If this condition is met, a valid palindrome subsequence of length 3 can be formed.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    first_last = {}
    for idx in range(n):
        num = a[idx]
        if num not in first_last:
            first_last[num] = [idx, idx]
        else:
            first_last[num][1] = idx
    found = False
    for num in first_last:
        fl = first_last[num]
        if fl[1] - fl[0] >= 2:
            found = True
            break
    print("YES" if found else "NO")
```

### Explanation
1. **Reading Input:** The input consists of multiple test cases. For each test case, we read the array length and the array elements.
2. **Tracking Occurrences:** Using a dictionary, we track the first and last occurrence indices of each element in the array.
3. **Checking Conditions:** For each element, we check if the distance between its first and last occurrence is at least 2. If such an element exists, it means we can form a valid palindrome subsequence of length 3.
4. **Output Result:** Based on the check, we print "YES" if a valid subsequence exists, otherwise "NO".

This approach ensures we efficiently determine the presence of a valid subsequence with a linear scan of the array, making the solution both optimal and easy to understand.
