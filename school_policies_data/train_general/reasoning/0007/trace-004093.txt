To solve this problem, we need to determine the minimum number of insertions required to ensure that all maximal sequences of consecutive identical nucleotides in a given DNA string have odd lengths. This is crucial because a protein encoded by a DNA string with any even-length sequence is nonfunctional.

### Approach
1. **Identify Maximal Sequences**: Split the input DNA string into consecutive sequences (runs) of identical characters.
2. **Check Sequence Lengths**: For each identified sequence, check if its length is even.
3. **Count Even-Length Sequences**: The minimum number of insertions required is equal to the number of even-length sequences. Each even-length sequence can be converted to an odd-length sequence with exactly one insertion.

### Solution Code
```python
s = input().strip()
if not s:
    print(0)
else:
    current_char = s[0]
    count = 1
    total = 0
    for c in s[1:]:
        if c == current_char:
            count += 1
        else:
            if count % 2 == 0:
                total += 1
            current_char = c
            count = 1
    if count % 2 == 0:
        total += 1
    print(total)
```

### Explanation
1. **Reading Input**: The input DNA string is read from standard input.
2. **Tracking Runs**: The code iterates through each character of the string, tracking the current run of identical characters.
3. **Checking Even Lengths**: Whenever a new character is encountered, the length of the current run is checked. If it is even, a counter is incremented.
4. **Final Check**: After the loop, the length of the last run is checked to ensure no even-length sequences are missed.

This approach efficiently processes the DNA string in linear time, making it optimal for the given problem constraints. Each even-length sequence is addressed with exactly one insertion, ensuring the solution is both correct and minimal.
