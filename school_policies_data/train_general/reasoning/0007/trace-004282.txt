To solve this problem, we need to determine the maximum number of matches a burglar can steal by selecting matchboxes from various containers, given a constraint on the number of matchboxes he can carry. The solution involves a greedy approach to maximize the matches by prioritizing containers with the highest number of matches per box.

### Approach
1. **Input Reading**: Read the number of matchboxes the burglar can carry (n) and the number of containers (m).
2. **Data Collection**: For each container, read the number of matchboxes it contains and the number of matches per box.
3. **Sorting**: Sort the containers in descending order based on the number of matches per box. This ensures we prioritize containers with more matches per box.
4. **Greedy Selection**: Iterate through the sorted containers, taking as many matchboxes as possible from each container until the burglar's capacity is reached. Sum the matches taken from each container to get the maximum total.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    m = int(input[idx+1])
    idx += 2
    containers = []
    for _ in range(m):
        a = int(input[idx])
        b = int(input[idx+1])
        containers.append((a, b))
        idx += 2
    # Sort containers by descending order of matches per box (b)
    containers.sort(key=lambda x: -x[1])
    total = 0
    remaining = n
    for a, b in containers:
        if remaining <= 0:
            break
        take = min(a, remaining)
        total += take * b
        remaining -= take
    print(total)

main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints. The first line provides the capacity (n) and the number of containers (m). Subsequent lines provide the number of matchboxes and matches per box for each container.
2. **Sorting Containers**: Containers are sorted in descending order based on the number of matches per box. This ensures that we always consider the most valuable containers first.
3. **Greedy Selection**: For each container, we take as many matchboxes as possible (up to the container's available quantity or the remaining capacity). This continues until the burglar's capacity is exhausted or all containers have been considered.
4. **Output**: The total number of matches collected is printed as the result.

This approach efficiently ensures that the maximum possible matches are collected by leveraging a greedy strategy, which is optimal for this problem structure. The sorting step ensures we prioritize higher value containers, leading to an optimal solution.
