To solve this problem, we need to determine the maximum area that two different seals can occupy on a given piece of paper without overlapping. Each seal can be rotated by 90 degrees, and the goal is to find the optimal arrangement of two seals to maximize the total area covered.

### Approach
1. **Input Reading**: Read the number of seals and the dimensions of the paper.
2. **Generate All Pairs**: Consider all possible pairs of different seals.
3. **Check Rotations**: For each pair of seals, consider all possible rotations (0° and 90°).
4. **Check Valid Arrangements**: For each combination of rotated seals, check if they can be placed on the paper in any of the following valid configurations:
   - Side by side horizontally (sum of widths ≤ paper width and max height ≤ paper height).
   - Stacked vertically (sum of heights ≤ paper height and max width ≤ paper width).
   - Side by side horizontally rotated (sum of widths ≤ paper height and max height ≤ paper width).
   - Stacked vertically rotated (sum of heights ≤ paper width and max width ≤ paper height).
5. **Calculate Maximum Area**: Track the maximum area covered by valid arrangements of any pair of seals.

### Solution Code
```python
n, a, b = map(int, input().split())
seals = [tuple(map(int, input().split())) for _ in range(n)]

max_area = 0

for i in range(n):
    for j in range(i + 1, n):
        xi, yi = seals[i]
        xj, yj = seals[j]
        # Iterate through all possible rotations for both seals
        for w1, h1 in [(xi, yi), (yi, xi)]:
            for w2, h2 in [(xj, yj), (yj, xj)]:
                # Check all four possible conditions
                cond1 = (w1 + w2 <= a) and (max(h1, h2) <= b)
                cond2 = (h1 + h2 <= b) and (max(w1, w2) <= a)
                cond3 = (w1 + w2 <= b) and (max(h1, h2) <= a)
                cond4 = (h1 + h2 <= a) and (max(w1, w2) <= b)
                if cond1 or cond2 or cond3 or cond4:
                    current_area = w1 * h1 + w2 * h2
                    if current_area > max_area:
                        max_area = current_area

print(max_area)
```

### Explanation
1. **Reading Input**: The input is read and stored in variables for the number of seals and the dimensions of the paper. Each seal's dimensions are stored in a list.
2. **Generating Pairs**: We iterate over all pairs of seals using nested loops to ensure each pair is considered exactly once.
3. **Checking Rotations**: For each seal in a pair, we consider both possible orientations (original and rotated 90 degrees).
4. **Validating Configurations**: For each combination of orientations, we check four possible configurations to see if the seals can fit on the paper without overlapping.
5. **Calculating Area**: If any configuration is valid, we compute the area covered by the two seals and update the maximum area if this is the largest found so far.

This approach ensures that we efficiently explore all possible valid arrangements of the seals to find the optimal solution.
