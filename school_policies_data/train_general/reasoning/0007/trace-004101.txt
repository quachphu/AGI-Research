To solve this problem, we need to count the number of valid intervals in a permutation that do not contain any given foe pairs. The solution involves efficiently determining the intervals that are invalid due to containing foe pairs and subtracting these from the total number of possible intervals.

### Approach
1. **Understanding the Problem**: Each interval (x, y) is valid if it does not contain any foe pair (ai, bi). The challenge is to efficiently count these valid intervals given the constraints where n and m can be as large as 300,000.

2. **Transforming Foe Pairs**: Convert each foe pair (ai, bi) into their positions in the permutation. For each pair, determine the minimum (a) and maximum (b) positions.

3. **Tracking Maximum a for Each b**: For each maximum position (b) encountered, track the maximum minimum position (a) from all foe pairs. This helps in determining the leftmost position that invalidates intervals ending at or after b.

4. **Cumulative Maximum Calculation**: Sort the maximum positions (b) and compute cumulative maximum values of a. This allows quick lookup of the maximum a for any given b.

5. **Summing Forbidden Intervals**: For each possible end position y, determine the maximum a using binary search on the sorted list of b's. Sum the forbidden intervals for each y by considering the valid x positions up to the maximum a.

6. **Final Calculation**: Subtract the sum of forbidden intervals from the total number of possible intervals to get the count of valid intervals.

### Solution Code
```python
import sys
from bisect import bisect_right

def main():
    n, m = map(int, sys.stdin.readline().split())
    p = list(map(int, sys.stdin.readline().split()))
    pos = {num: i+1 for i, num in enumerate(p)}
    max_a_for_b = {}

    for _ in range(m):
        a_el, b_el = map(int, sys.stdin.readline().split())
        a = pos[a_el]
        b_pos = pos[b_el]
        a_pair = min(a, b_pos)
        b_pair = max(a, b_pos)
        if b_pair in max_a_for_b:
            if a_pair > max_a_for_b[b_pair]:
                max_a_for_b[b_pair] = a_pair
        else:
            max_a_for_b[b_pair] = a_pair

    sorted_bs = sorted(max_a_for_b.keys())
    cumulative_max = []
    current_max = 0
    for b in sorted_bs:
        current_max = max(current_max, max_a_for_b[b])
        cumulative_max.append(current_max)
    
    sum_forbidden = 0
    for y in range(1, n+1):
        idx = bisect_right(sorted_bs, y) - 1
        current_a = cumulative_max[idx] if idx >= 0 else 0
        sum_forbidden += min(current_a, y)
    
    total = n * (n + 1) // 2
    print(total - sum_forbidden)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The permutation and foe pairs are read, and each element's position in the permutation is stored in a dictionary for quick lookup.

2. **Processing Foe Pairs**: Each foe pair is converted into their respective positions in the permutation. The minimum and maximum positions (a, b) are determined and stored, keeping track of the maximum a for each b.

3. **Sorting and Cumulative Maxima**: The maximum positions (b) are sorted, and a cumulative maximum array is built to quickly determine the maximum a for any given b.

4. **Binary Search for Forbidden Intervals**: For each possible end position y, binary search is used to find the largest b that is less than or equal to y. The corresponding maximum a is used to determine the number of forbidden intervals starting at any x up to this maximum a.

5. **Result Calculation**: The total number of intervals is calculated, and the sum of forbidden intervals is subtracted to get the number of valid intervals.

This approach efficiently handles the constraints and ensures that the solution is computed in O(n log m) time complexity, making it suitable for large input sizes.
