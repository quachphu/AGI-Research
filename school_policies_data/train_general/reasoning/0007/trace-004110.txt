To solve this problem, we need to generate a transition table for a Deterministic Finite Automaton (DFA) such that the final state after processing a binary string is equivalent to the decimal value of the string modulo the number of states, N. The transitions for each state should be determined based on the current state and the input bit (0 or 1).

### Approach
1. **Understanding the Transition Function**: For each state `a` and input bit `b`, the next state is computed as `(2 * a + b) % N`. This formula arises from the fact that processing a binary string from left to right involves multiplying the current value by 2 (shift left) and adding the new bit (0 or 1), followed by taking modulo N to ensure the state remains within valid bounds.
2. **Iterate Over States**: For each state from 0 to N-1, compute the next states for both input bits 0 and 1 using the transition function.
3. **Generate Output**: Format the transitions for each state into the required output format.

### Solution Code
```python
def main():
    import sys
    n = int(sys.stdin.readline())
    for a in range(n):
        transition_0 = (a * 2) % n
        transition_1 = (a * 2 + 1) % n
        print(a, transition_0, transition_1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The number of states, `N`, is read from standard input.
2. **Loop Through States**: For each state `a` from 0 to N-1:
   - **Transition for 0**: Compute `(a * 2) % N` which simulates appending a 0 bit to the current binary string.
   - **Transition for 1**: Compute `(a * 2 + 1) % N` which simulates appending a 1 bit to the current binary string.
3. **Output the Transitions**: Print each state followed by its transitions for input bits 0 and 1 in the specified format.

This approach ensures that each transition correctly models the effect of processing each bit in the binary string, leading to the correct final state as the decimal value of the string modulo N. The algorithm efficiently computes transitions in linear time relative to the number of states, making it suitable for the given constraints.
