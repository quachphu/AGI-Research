To solve this problem, we need to determine the maximum number of operations Takahashi can perform for each possible value of K (from 1 to N), where each operation involves selecting exactly K distinct cards and removing them. The solution must efficiently handle the constraints where N can be as large as 300,000.

### Approach
1. **Frequency Calculation**: Count the frequency of each integer on the cards.
2. **Sorting Frequencies**: Sort these frequencies in non-decreasing order to facilitate efficient range queries.
3. **Prefix Sum Array**: Construct a prefix sum array of the sorted frequencies to quickly compute the sum of frequencies up to any index.
4. **Binary Search for Each K**: For each K, determine the maximum number of operations (m) using binary search. The key insight is to find the largest m such that the sum of the minimum of each frequency and m is at least K * m, while also ensuring m does not exceed the maximum possible value given by the total number of cards divided by K.

### Solution Code
```python
from collections import Counter
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    A = list(map(int, input[1:N+1]))
    
    freq = Counter(A)
    F = sorted(freq.values())
    D = len(F)
    
    prefix = [0] * (D + 1)
    for i in range(D):
        prefix[i + 1] = prefix[i] + F[i]
    
    S = N  # Total number of cards
    answers = []
    
    for K in range(1, N + 1):
        m_upper = S // K
        if m_upper == 0:
            answers.append(0)
            continue
        
        low, high = 0, m_upper
        best_m = 0
        while low <= high:
            mid = (low + high) // 2
            j = bisect.bisect_left(F, mid)
            sum_mid = prefix[j] + (D - j) * mid
            if sum_mid >= K * mid:
                best_m = mid
                low = mid + 1
            else:
                high = mid - 1
        answers.append(best_m)
    
    print(' '.join(map(str, answers)))

if __name__ == '__main__':
    main()
```

### Explanation
1. **Frequency Calculation**: Using a counter, we determine how many times each integer appears on the cards.
2. **Sorting and Prefix Sum**: Sorting the frequencies allows us to efficiently compute the sum of the smallest frequencies using a prefix sum array. This helps in quickly determining the sum of frequencies up to any given index.
3. **Binary Search for Each K**: For each K, we use binary search to find the maximum number of operations (m) that can be performed. The binary search checks if the sum of the minimum of each frequency and the current mid value (potential m) is sufficient to allow m operations with K distinct cards each.

This approach ensures that we efficiently compute the result for each K in O(log N) time per K, leading to an overall time complexity of O(N log N), which is feasible for large values of N up to 300,000.
