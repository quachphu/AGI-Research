To solve this problem, we need to determine the exact floor of a specific flat in a building where each floor has the same number of flats. The challenge is to use the given information about some flats and their respective floors to determine if the floor of the given flat can be uniquely identified.

### Approach
1. **Input Handling**: Read the number of the flat to determine and the number of remembered flats along with their respective floors.
2. **Special Case Handling**: If there are no remembered flats, check if the flat number is 1 (which is the only case where the floor can be uniquely determined).
3. **Calculate Constraints**: For each remembered flat, calculate the possible range of flats per floor (k) that would place the remembered flat on its respective floor.
4. **Determine Valid Ranges**: Compute the global lower and upper bounds for k by intersecting the valid ranges from all remembered flats.
5. **Check Uniqueness**: For each valid k, compute the floor of the given flat and check if all computed floors are the same. If they are, output the floor; otherwise, output -1.

### Solution Code
```python
n, m = map(int, input().split())

if m == 0:
    print(1 if n == 1 else -1)
else:
    memory = [tuple(map(int, input().split())) for _ in range(m)]
    global_lower = 0
    global_upper = 10**9
    has_fi_greater_1 = False

    for ki, fi in memory:
        if fi == 1:
            this_lower = ki
            this_upper = 10**9
        else:
            has_fi_greater_1 = True
            this_lower = (ki - 1) // fi + 1
            this_upper = (ki - 1) // (fi - 1)
        
        if this_lower > global_lower:
            global_lower = this_lower
        
        if fi > 1:
            if this_upper < global_upper:
                global_upper = this_upper

    if not has_fi_greater_1:
        if global_lower > (n - 1):
            print(1)
        else:
            print(-1)
    else:
        if global_lower > global_upper:
            print(-1)
        else:
            floors = set()
            for k in range(global_lower, global_upper + 1):
                floor = (n - 1) // k + 1
                floors.add(floor)
            if len(floors) == 1:
                print(floors.pop())
            else:
                print(-1)
```

### Explanation
1. **Input Handling**: The code reads the input values for the number of the flat to determine (n) and the number of remembered flats (m).
2. **Special Case Handling**: If there are no remembered flats (m=0), the floor can only be determined uniquely if n=1.
3. **Calculate Constraints**: For each remembered flat, the code calculates the possible range of values for the number of flats per floor (k) that would place the remembered flat on its specified floor.
4. **Determine Valid Ranges**: By intersecting all valid ranges from the remembered flats, the code computes the global lower and upper bounds for k.
5. **Check Uniqueness**: The code checks each valid k within the computed range to determine the floor of the given flat. If all valid k values result in the same floor, that floor is printed; otherwise, -1 is printed indicating the floor cannot be uniquely determined.

This approach ensures that we efficiently narrow down the possible values for the number of flats per floor and check for the uniqueness of the floor determination using the given constraints.
