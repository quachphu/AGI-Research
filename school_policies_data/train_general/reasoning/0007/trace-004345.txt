To solve this problem, we need to determine the greatest common divisor (GCD) of two numbers that lies within a specified range for each query. The solution involves efficiently computing the GCD of the two numbers and then checking the divisors of this GCD against the given ranges.

### Approach
1. **Compute GCD**: First, compute the GCD of the two given numbers, which helps us identify all possible common divisors.
2. **Find Divisors**: Generate all divisors of the computed GCD. This is done by iterating up to the square root of the GCD to efficiently find all divisors.
3. **Handle Queries**: For each query, determine the largest divisor of the GCD that falls within the specified range using binary search for efficiency.

### Solution Code
```python
import math
from bisect import bisect_right

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    a = int(input[ptr])
    ptr += 1
    b = int(input[ptr])
    ptr += 1
    g = math.gcd(a, b)
    
    divisors = []
    if g != 0:
        temp = set()
        sqrt_g = int(math.isqrt(g))  # More accurate than g**0.5 for integer sqrt
        for i in range(1, sqrt_g + 1):
            if g % i == 0:
                temp.add(i)
                temp.add(g // i)
        divisors = sorted(temp)
    
    n = int(input[ptr])
    ptr += 1
    for _ in range(n):
        low = int(input[ptr])
        ptr += 1
        high = int(input[ptr])
        ptr += 1
        idx = bisect_right(divisors, high) - 1
        if idx >= 0 and divisors[idx] >= low:
            print(divisors[idx])
        else:
            print(-1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Compute GCD**: The GCD of the two numbers `a` and `b` is computed using Python's `math.gcd` function. This GCD is the largest number that divides both `a` and `b`.
2. **Generate Divisors**: Using a set to avoid duplicates, we iterate from 1 to the integer square root of the GCD. For each divisor found, both the divisor and its complement (i.e., `GCD // divisor`) are added to the set. This ensures all divisors are captured efficiently.
3. **Query Handling**: For each query, we use binary search (`bisect_right`) to quickly find the largest divisor of the GCD that is less than or equal to the upper bound of the query range. We then check if this divisor is within the specified range. If it is, we return it; otherwise, we return -1.

This approach ensures that we efficiently handle up to 10,000 queries by leveraging precomputed divisors and binary search, resulting in a time complexity that is manageable even for large input sizes.
