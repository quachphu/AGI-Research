To solve this problem, we need to compute the factorial of given numbers for multiple test cases. The factorial of a number \( T \) (denoted as \( T! \)) is the product of all positive integers up to \( T \). Given the constraints where \( T \) can be as large as 200, we need an efficient approach to handle very large numbers, which Python can manage natively.

### Approach
1. **Input Handling**: Read the number of test cases, \( N \), followed by \( N \) integers.
2. **Factorial Calculation**: For each integer \( T \), compute its factorial using an iterative approach. This involves multiplying all integers from 1 up to \( T \).
3. **Output the Result**: Print each computed factorial on a new line.

### Solution Code
```python
def factorial(n):
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result

n = int(input())
for _ in range(n):
    t = int(input())
    print(factorial(t))
```

### Explanation
1. **Factorial Function**: The `factorial` function initializes a result variable to 1. It then iterates from 1 to \( n \) (inclusive), multiplying the result by each integer in this range. This effectively computes \( n! \).
2. **Reading Input**: The code reads the number of test cases \( N \) and then reads each integer \( T \) in a loop.
3. **Processing Each Test Case**: For each integer \( T \), the factorial is computed using the `factorial` function, and the result is printed immediately.

This approach ensures that we efficiently compute the factorial for each input value, even for the upper constraint of \( T = 200 \), leveraging Python's ability to handle arbitrarily large integers.
