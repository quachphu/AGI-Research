To solve this problem, we need to determine if it's possible to find two n x n matrices such that their element-wise combination yields all possible pairs of {1, 2, ..., n} x {1, 2, ..., n}. This problem is equivalent to determining whether orthogonal Latin squares exist for a given order n. The solution leverages the known result that orthogonal Latin squares exist for all orders except 2 and 6.

### Approach
1. **Understanding the Problem**: The problem requires checking if there exist two Latin squares of order n that are orthogonal. Orthogonal Latin squares (Graeco-Latin squares) are pairs of Latin squares such that each pair of elements occurs exactly once when the squares are superimposed.
2. **Key Insight**: From mathematical theory, it is known that orthogonal Latin squares exist for all orders except 2 and 6. Therefore, the solution reduces to checking if the given order n is 2 or 6.
3. **Efficient Input Handling**: Given the constraints (up to 1,000,000 test cases), we read all input at once for efficiency, process each test case, and generate the results in a single output operation.

### Solution Code
```python
import sys

def main():
    data = sys.stdin.read().split()
    t = int(data[0])
    answers = []
    for n_str in data[1:t+1]:
        n = int(n_str)
        answers.append("No" if n in (2, 6) else "Yes")
    print('\n'.join(answers))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The code reads all input at once using `sys.stdin.read()` and splits it into a list of strings for efficient processing.
2. **Processing Each Test Case**: For each test case, the code checks if the order n is either 2 or 6. If so, it appends "No" to the result list; otherwise, it appends "Yes".
3. **Output the Results**: The results are collected in a list and printed all at once using `'\n'.join(answers)`, which is efficient for handling a large number of results.

This approach ensures that the solution is both time-efficient and space-efficient, handling up to the maximum constraints smoothly.
