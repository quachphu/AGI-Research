To solve this problem, we need to determine the maximum number of petals in a bouquet such that Little Jhool ends on "She loves me!" when plucking the petals. This requires the total number of petals in the bouquet to be odd. If all petals are even, it's impossible to form such a bouquet, and we should return ":(".

### Approach
1. **Sum Calculation**: First, calculate the total sum of petals from all roses.
2. **Check Odd Sum**: If the total sum is odd, this sum is the answer since it directly results in "She loves me!".
3. **Handle Even Sum**: If the total sum is even, we need to adjust it to make it odd by removing the smallest odd petal. If there are no odd petals, return ":(" as it's impossible to form an odd sum.

### Solution Code
```python
n = int(input())
petals = list(map(int, input().split()))
total = sum(petals)
if total % 2 == 1:
    print(total)
else:
    odds = [x for x in petals if x % 2 == 1]
    if not odds:
        print(':(')
    else:
        min_odd = min(odds)
        print(total - min_odd)
```

### Explanation
1. **Input Reading**: Read the number of roses and their respective petals.
2. **Total Sum Calculation**: Compute the sum of all petals.
3. **Odd Sum Check**: If the total sum is odd, print it directly.
4. **Adjust Even Sum**: If the total sum is even, check for the presence of odd petals. If none exist, print ":(". Otherwise, subtract the smallest odd petal from the total sum to make it odd and print the result.

This approach ensures that we efficiently determine the maximum possible odd sum by leveraging the properties of odd and even numbers, thus providing an optimal solution.
