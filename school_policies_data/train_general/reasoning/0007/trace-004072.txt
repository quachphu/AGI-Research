To solve this problem, we need to determine the number of triangles that can be formed from given points, considering that some of these points are collinear. The key is to subtract the invalid triangles formed by collinear points from the total possible triangles.

### Approach
1. **Understanding Triangle Formation**: A triangle is formed by three non-collinear points. The total number of triangles that can be formed from `n` points (assuming no three are collinear) is given by the combination formula \( C(n, 3) = \frac{n(n-1)(n-2)}{6} \).
2. **Adjusting for Collinear Points**: If `k` points are collinear, they cannot form a triangle. The number of invalid triangles formed by these collinear points is \( C(k, 3) = \frac{k(k-1)(k-2)}{6} \).
3. **Final Formula**: Subtract the invalid triangles from the total possible triangles to get the valid triangles. The formula becomes:
   \[
   \text{valid\_triangles} = \frac{n(n-1)(n-2) - k(k-1)(k-2)}{6}
   \]

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    idx = 1
    for _ in range(t):
        n = int(input[idx])
        k = int(input[idx + 1])
        idx += 2
        total = (n * (n - 1) * (n - 2) - k * (k - 1) * (k - 2)) // 6
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
- **Loop Through Test Cases**: For each test case, read `n` and `k`.
- **Calculate Valid Triangles**: Use the derived formula to compute the number of valid triangles by subtracting the invalid collinear triangles from the total possible triangles.
- **Output the Result**: Print the result for each test case.

This approach efficiently handles the constraints and ensures that the solution is computed in constant time for each test case, making it suitable for large inputs.
