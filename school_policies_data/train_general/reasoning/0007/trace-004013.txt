To solve this problem, we need to determine the maximum number of distinct characters that are present in both parts of a string when it is split at an optimal position. The solution involves evaluating all possible split positions and computing the intersection of distinct characters from both parts at each position.

### Approach
1. **Input Reading**: Read the input values for the string length `N` and the string `S`.
2. **Iterate Through Split Positions**: For each possible split position (from 0 to N-2), split the string into two parts, `X` and `Y`.
3. **Compute Distinct Characters**: For each split, compute the set of distinct characters in both parts `X` and `Y`.
4. **Find Common Characters**: Determine the intersection of these two sets to find the common distinct characters.
5. **Track Maximum Count**: Keep track of the maximum number of common distinct characters found across all splits.

### Solution Code
```python
n = int(input())
s = input().strip()

max_count = 0

for i in range(n - 1):
    x = s[:i+1]
    y = s[i+1:]
    common = set(x) & set(y)
    max_count = max(max_count, len(common))

print(max_count)
```

### Explanation
1. **Reading Input**: The input consists of an integer `N` and a string `S` of length `N`. These are read from standard input.
2. **Loop Through Splits**: The loop runs from 0 to N-2, representing all valid split positions where both parts of the string are non-empty.
3. **Split the String**: For each split position `i`, the string is divided into two parts: `X` (from the start to `i`) and `Y` (from `i+1` to the end).
4. **Set Operations**: Convert both parts into sets of characters to find the distinct characters in each part. The intersection of these sets gives the common characters.
5. **Track Maximum**: Update the maximum count of common characters found after evaluating each split position.

This approach efficiently checks all possible splits using set operations to determine the optimal solution, ensuring that we maximize the number of common distinct characters between the two parts of the string. The complexity of this approach is O(N^2), which is efficient given the constraint \(N \leq 100\).
