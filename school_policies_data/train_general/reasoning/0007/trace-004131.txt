To solve this problem, we need to determine the optimal locations for the chef's house such that the sum of Manhattan distances from the house to all his restaurants is minimized. The solution involves finding the median coordinates of the restaurants and counting the number of valid integer grid points around these medians.

### Approach
1. **Understanding Manhattan Distance**: The Manhattan distance between two points (A, B) and (C, D) is |A - C| + |B - D|. The sum of these distances is minimized when the house is located at a median point of the restaurants' coordinates.
2. **Median Calculation**: 
   - For an odd number of restaurants, the median is the middle element in the sorted list of coordinates.
   - For an even number of restaurants, the median can be any integer between the two middle elements in the sorted list.
3. **Count Valid Coordinates**: The number of valid integer coordinates around the median(s) is determined by the range between the two middle elements for even counts, and exactly one element for odd counts.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        x = []
        y = []
        for _ in range(N):
            xi = int(input[ptr])
            yi = int(input[ptr + 1])
            ptr += 2
            x.append(xi)
            y.append(yi)
        x_sorted = sorted(x)
        y_sorted = sorted(y)
        
        def count_options(arr):
            n = len(arr)
            if n % 2 == 1:
                return 1
            else:
                left = arr[(n // 2) - 1]
                right = arr[n // 2]
                return right - left + 1
        
        cx = count_options(x_sorted)
        cy = count_options(y_sorted)
        print(cx * cy)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Sorting Coordinates**: The x and y coordinates of the restaurants are sorted separately.
3. **Median Calculation**: 
   - For odd numbers of restaurants, the median is the middle element, resulting in exactly one valid coordinate.
   - For even numbers, the valid coordinates are the integers between the two middle elements, inclusive.
4. **Counting Valid Points**: The number of valid x and y coordinates are calculated separately and multiplied to get the total number of optimal house locations.

This approach ensures that we efficiently determine the optimal locations using median properties and handle both odd and even cases appropriately, leading to an optimal and correct solution.
