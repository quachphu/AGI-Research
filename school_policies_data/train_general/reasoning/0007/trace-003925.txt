To solve this problem, we need to compute the sum of all proper divisors for a given number efficiently. Given the constraints, a direct approach for each test case would be too slow. Instead, we precompute the sum of proper divisors for all numbers up to the maximum possible value using a sieve-like approach, allowing each query to be answered in constant time.

### Approach
1. **Precomputation**: Use a sieve method to precompute the sum of proper divisors for all numbers up to 500,000. This involves iterating through each number and adding it to the sum of its multiples.
2. **Efficient Query Handling**: After precomputing, each test case can be answered in O(1) time by simply looking up the precomputed value.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    max_n = 500000
    sum_div = [0] * (max_n + 1)
    
    for i in range(1, max_n + 1):
        for j in range(2 * i, max_n + 1, i):
            sum_div[j] += i
    
    T = int(input[0])
    results = []
    for num_str in input[1:T + 1]:
        n = int(num_str)
        results.append(sum_div[n])
    
    print('\n'.join(map(str, results)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precomputation with Sieve Method**:
   - We initialize an array `sum_div` of size 500,001 (indexed from 0 to 500,000) to store the sum of proper divisors for each number.
   - For each number `i` starting from 1, we iterate through all its multiples (starting from `2*i` up to 500,000) and add `i` to their sum. This ensures that each multiple of `i` accumulates `i` as one of its proper divisors.

2. **Handling Input/Output Efficiently**:
   - Read all input at once to handle large input sizes efficiently.
   - Use the precomputed `sum_div` array to answer each test case in constant time by directly accessing the precomputed value.

This approach ensures that the solution is efficient even for the upper limits of the input constraints, providing quick responses to each query after an initial preprocessing step.
