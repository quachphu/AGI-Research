To solve this problem, we need to determine the minimum distance from each station to the ringroad (cycle) in a subway scheme represented as a unicyclic graph. The solution involves identifying the cycle and then computing the shortest path from each node to the cycle using BFS.

### Approach
1. **Identify the Cycle**: Use a modified BFS to iteratively remove leaf nodes (nodes with degree 1) until only the cycle nodes remain. Nodes in the cycle will have a degree of 2 after all leaves and their attached trees are removed.
2. **Compute Distances**: Perform a BFS starting from all cycle nodes (distance 0) to compute the shortest distance from each node to the nearest cycle node.

### Solution Code
```python
import sys
from collections import deque

def main():
    n = int(sys.stdin.readline())
    adj = [[] for _ in range(n + 1)]
    degrees = [0] * (n + 1)
    for _ in range(n):
        x, y = map(int, sys.stdin.readline().split())
        adj[x].append(y)
        adj[y].append(x)
        degrees[x] += 1
        degrees[y] += 1

    in_cycle = [True] * (n + 1)
    q = deque()
    for i in range(1, n + 1):
        if degrees[i] == 1:
            q.append(i)
            in_cycle[i] = False

    while q:
        u = q.popleft()
        for v in adj[u]:
            if in_cycle[v]:
                degrees[v] -= 1
                if degrees[v] == 1:
                    in_cycle[v] = False
                    q.append(v)

    distance = [-1] * (n + 1)
    q = deque()
    for i in range(1, n + 1):
        if in_cycle[i]:
            distance[i] = 0
            q.append(i)

    while q:
        u = q.popleft()
        for v in adj[u]:
            if distance[v] == -1:
                distance[v] = distance[u] + 1
                q.append(v)

    print(' '.join(map(str, distance[1:n+1])))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input and Building the Graph**: The input is read to construct the adjacency list and degree array for each node.
2. **Identifying Cycle Nodes**: Nodes with degree 1 are repeatedly removed (as they are part of trees, not the cycle). This process continues until only nodes with degree 2 remain, which form the cycle.
3. **BFS for Distance Calculation**: Starting from all cycle nodes (distance 0), BFS is used to propagate the minimum distances to all other nodes. Each node's distance is the shortest path to any cycle node.

This approach efficiently identifies the cycle and computes distances using BFS, ensuring optimal performance even for the upper constraint of 3000 nodes.
