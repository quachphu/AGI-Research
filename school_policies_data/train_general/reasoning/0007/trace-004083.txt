To solve this problem, we need to determine the number of minutes remaining until the New Year, which occurs at 0:00 (midnight). Given the current time in hours and minutes, we can compute the remaining minutes by calculating the difference between the total minutes in a day and the minutes passed since midnight.

### Approach
1. **Understanding the Problem**: The New Year starts at 0:00. For each given time (h hours and m minutes), we need to find how many minutes are left until midnight. 
2. **Formulating the Solution**: 
   - A day has 24 hours, which is equivalent to 24 * 60 = 1440 minutes.
   - Convert the current time into total minutes passed since midnight: `total_minutes_passed = h * 60 + m`.
   - Subtract the total minutes passed from 1440 to get the remaining minutes: `remaining_minutes = 1440 - total_minutes_passed`.
3. **Handling Input**: Read the number of test cases and each subsequent time, then apply the formula to compute the result for each case.

### Solution Code
```python
t = int(input())
for _ in range(t):
    h, m = map(int, input().split())
    current = h * 60 + m
    print(1440 - current)
```

### Explanation
1. **Reading Input**: The first input line gives the number of test cases. Each subsequent line contains two integers representing hours and minutes.
2. **Conversion to Minutes**: For each test case, convert the given hours and minutes into total minutes since midnight.
3. **Calculate Remaining Minutes**: Subtract the total minutes passed from the total minutes in a day (1440) to get the remaining minutes until midnight.
4. **Output the Result**: Print the computed remaining minutes for each test case.

This approach efficiently computes the required result in constant time for each test case, ensuring optimal performance even for the upper limit of input constraints.
