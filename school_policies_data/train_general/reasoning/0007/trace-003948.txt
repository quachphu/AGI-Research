To solve this problem, we need to determine the maximum possible score that Toastman and Appleman can achieve by optimally splitting groups of numbers. The key insight is to maximize the sum of all groups processed during the game, which can be efficiently computed using a sorted array and suffix sums.

### Approach
1. **Sort the Array**: By sorting the array in non-decreasing order, we can efficiently compute the contributions of each element in subsequent splits.
2. **Compute Suffix Sums**: Suffix sums help in quickly determining the sum of elements from any index to the end of the array. This allows us to efficiently calculate the sum of all possible groups formed during the splitting process.
3. **Sum Contributions**: The total score is the sum of the initial group and all groups formed by splitting off the smallest element iteratively. This is computed using the suffix sums.

### Solution Code
```python
n, *rest = map(int, open(0).read().split())
a = rest[:n]

if n == 1:
    print(a[0])
else:
    a.sort()
    suffix = [0] * n
    suffix[-1] = a[-1]
    for i in range(n-2, -1, -1):
        suffix[i] = suffix[i+1] + a[i]
    sum_split = sum(suffix[:n-1])  # sum from 0 to n-2 inclusive
    total = sum(a) + sum_split
    print(total)
```

### Explanation
1. **Sorting**: The array is sorted to facilitate the optimal splitting strategy, where the smallest elements are split off first, allowing the remaining elements to contribute to more groups.
2. **Suffix Sums**: By computing suffix sums, we can quickly determine the sum of any subarray starting from a given index to the end. This helps in efficiently calculating the sum of all groups formed during each split.
3. **Summing Contributions**: The total score is the sum of the initial group and all groups formed by splitting. This is computed by summing the initial array and the relevant suffix sums, which account for all possible splits.

This approach ensures that we maximize the score by leveraging the optimal splitting strategy, leading to an efficient solution with a time complexity of O(n log n) due to sorting and O(n) for suffix sum computation.
