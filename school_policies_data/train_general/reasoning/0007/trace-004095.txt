To solve this problem, we need to reconstruct a strictly increasing sequence of positive integers from a given sequence of their digit sums. The goal is to find the sequence with the smallest possible last number, ensuring each number's digit sum matches the given sequence.

### Approach
1. **Problem Analysis**: Given a sequence of digit sums, we need to generate the smallest possible strictly increasing sequence of numbers such that each number's digit sum matches the given sequence. The challenge is to ensure each subsequent number is larger than the previous one while maintaining the required digit sum.

2. **Key Insight**: The smallest number with a specific digit sum can be constructed by placing the highest possible digits (9) to the right, starting with the smallest possible non-zero digit. For example, the smallest number with a digit sum of 10 is 19 (1 followed by 9).

3. **Algorithm**:
   - **Minimal Number Construction**: For each digit sum, construct the smallest possible number by using the formula: the first digit is the remainder when the sum is divided by 9 (adjusted to ensure non-zero), followed by as many 9s as needed.
   - **Increment and Check**: If the minimal number for a given digit sum is not larger than the previous number, increment the previous number and check each subsequent number until a valid number (with the correct digit sum) is found.

def minimal_number(s):
    if s == 0:
        return "0"
    digits = (s + 8) // 9
    first_digit = s - 9 * (digits - 1)
    if first_digit <= 0:
        first_digit = 1
    return str(first_digit) + '9' * (digits - 1)

def increment_string(s):
    s_list = list(s)
    i = len(s_list) - 1
    while i >= 0 and s_list[i] == '9':
        s_list[i] = '0'
        i -= 1
    if i >= 0:
        s_list[i] = str(int(s_list[i]) + 1)
        return ''.join(s_list)
    else:
        return '1' + '0' * len(s_list)

def compare(a_str, b_str):
    if len(a_str) > len(b_str):
        return 1
    elif len(a_str) < len(b_str):
        return -1
    else:
        for a, b in zip(a_str, b_str):
            a_digit = int(a)
            b_digit = int(b)
            if a_digit > b_digit:
                return 1
            elif a_digit < b_digit:
                return -1
        return 0

def sum_digits(s):
    return sum(int(c) for c in s)

def find_next_number(s, lower_bound_str):
    min_num = minimal_number(s)
    if compare(min_num, lower_bound_str) >= 0:
        return min_num
    current = lower_bound_str
    while True:
        current_sum = sum_digits(current)
        if current_sum == s:
            return current
        elif current_sum > s:
            current = increment_string(current)
        else:
            min_num = minimal_number(s)
            cmp_res = compare(min_num, current)
            if cmp_res >= 0:
                return min_num
            else:
                current = increment_string(current)

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    b_list = list(map(int, input[1:n+1]))
    previous_a = '0'
    for b in b_list:
        lower_bound = increment_string(previous_a)
        a_i = find_next_number(b, lower_bound)
        print(a_i)
        previous_a = a_i
