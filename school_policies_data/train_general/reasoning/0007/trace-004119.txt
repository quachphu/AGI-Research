To solve this problem, we need to determine if a given connected undirected graph can be decomposed into three edge-disjoint cycles such that each edge is used exactly once. The solution involves checking specific graph properties to ensure such a decomposition is possible.

### Approach
1. **Check Number of Edges**: The number of edges \( M \) must be at least 9. This is because each cycle must have at least 3 edges, and three cycles would require a minimum of 9 edges.
2. **Even Degrees**: All vertices must have even degrees. This is a necessary condition for any graph to be decomposed into cycles, as each vertex must have an equal number of incoming and outgoing edges.
3. **Single Cycle Check**: The graph must not be a single cycle. If the graph is a single cycle (i.e., \( M = N \) and all vertices have degree 2), it cannot be decomposed into three cycles.

### Solution Code
```python
n, m = map(int, input().split())

if m < 9:
    print("No")
    exit()

degrees = [0] * (n + 1)

for _ in range(m):
    a, b = map(int, input().split())
    degrees[a] += 1
    degrees[b] += 1

# Check all vertices have even degrees
for i in range(1, n + 1):
    if degrees[i] % 2 != 0:
        print("No")
        exit()

# Check if the graph is a single cycle
if m == n:
    all_two = True
    for i in range(1, n + 1):
        if degrees[i] != 2:
            all_two = False
            break
    if all_two:
        print("No")
        exit()

print("Yes")
```

### Explanation
1. **Input Reading**: The code reads the number of vertices \( N \) and edges \( M \), followed by the edges themselves.
2. **Edge Count Check**: If \( M \) is less than 9, the answer is immediately "No".
3. **Degree Calculation**: The code calculates the degree of each vertex.
4. **Even Degree Check**: It verifies that all vertices have even degrees. If any vertex has an odd degree, the answer is "No".
5. **Single Cycle Check**: If the number of edges \( M \) equals the number of vertices \( N \) and all vertices have exactly degree 2, the graph is a single cycle, and the answer is "No".
6. **Final Check**: If all conditions are met, the answer is "Yes".

This approach efficiently checks the necessary conditions using linear time complexity relative to the number of vertices and edges, making it suitable for large input sizes.
