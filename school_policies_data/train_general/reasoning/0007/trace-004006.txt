To solve this problem, we need to determine the probability that Maga will enjoy his contest, which happens when at least K of his favorite students are among the top N awarded students. This problem can be efficiently solved using combinatorial probability, specifically the hypergeometric distribution.

### Approach
1. **Problem Analysis**:
   - **Input**: We have T test cases, each with values S (total students), N (awarded students), M (favorite students), and K (minimum favorite students needed in the awarded group).
   - **Output**: The probability that at least K favorite students are in the awarded group, formatted to six decimal places.

2. **Key Insight**:
   - The problem can be modeled using the hypergeometric distribution, which calculates the probability of k successes (favorite students being awarded) in n draws (awarded positions) without replacement from a finite population.

3. **Algorithm**:
   - For each test case, compute the sum of probabilities for all valid values of k (from K to the minimum of M and N).
   - Use combinatorial mathematics to calculate the number of ways to choose k favorite students and (N-k) non-favorite students, divided by the total number of ways to choose N students from S.

4. **Complexity Consideration**:
   - The use of Python's `math.comb` function allows efficient computation of combinations, which is crucial given the constraints (S up to 1000).

### Solution Code
```python
import sys
import math

def compute_probability(S, N, M, K):
    if M == 0:
        return 1.0 if K == 0 else 0.0
    s_minus_m = S - M
    lower = max(K, max(0, N - s_minus_m))
    upper = min(M, N)
    if lower > upper:
        return 0.0
    total_ways = math.comb(S, N)
    sum_num = 0
    for k in range(lower, upper + 1):
        try:
            c_m_k = math.comb(M, k)
            c_sm_nk = math.comb(s_minus_m, N - k)
            sum_num += c_m_k * c_sm_nk
        except ValueError:
            continue  # Skip invalid combinations, though theoretically shouldn't happen
    return sum_num / total_ways if total_ways != 0 else 0.0

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        S = int(input[idx])
        N = int(input[idx+1])
        M = int(input[idx+2])
        K = int(input[idx+3])
        idx += 4
        prob = compute_probability(S, N, M, K)
        print("{0:.6f}".format(prob))

if __name__ == "__main__":
    main()
```
