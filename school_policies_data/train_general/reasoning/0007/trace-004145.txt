To solve this problem, we need to determine a positive integer \( x \) such that the sum of a geometric series \( x + 2x + 4x + \ldots + 2^{k-1}x \) equals a given number \( n \). The key insight is that the sum of this series can be represented as \( x \times (2^k - 1) \), where \( k > 1 \). Therefore, our task reduces to finding a divisor of \( n \) that is of the form \( 2^k - 1 \).

### Approach
1. **Geometric Series Sum**: The sum of the series \( x + 2x + 4x + \ldots + 2^{k-1}x \) can be simplified to \( x \times (2^k - 1) \).
2. **Divisor Check**: For each given \( n \), we need to find a divisor of \( n \) that fits the form \( 2^k - 1 \) where \( k > 1 \).
3. **Iterate Over Possible Values of \( k \)**: Since \( 2^k \) grows exponentially, we only need to check values of \( k \) up to 30 (as \( 2^{30} \) is slightly over \( 10^9 \), which is the upper limit for \( n \)).
4. **Check Divisibility**: For each \( k \), compute \( s = 2^k - 1 \) and check if \( s \) divides \( n \). The first valid \( s \) found will give us \( x \) as \( n / s \).

### Solution Code
```python
import sys

def find_x(n):
    for k in range(2, 31):
        s = (1 << k) - 1
        if s > n:
            break
        if n % s == 0:
            return n // s
    return -1  # The problem states a solution exists, so this line is theoretically unreachable

t = int(sys.stdin.readline())
for _ in range(t):
    n = int(sys.stdin.readline())
    print(find_x(n))
```

### Explanation
1. **Reading Input**: The number of test cases \( t \) is read first, followed by each test case value \( n \).
2. **Loop Through Possible \( k \) Values**: For each \( n \), iterate \( k \) from 2 up to 30. For each \( k \), compute \( s = 2^k - 1 \).
3. **Check Divisibility**: If \( s \) exceeds \( n \), break the loop early. Otherwise, check if \( s \) divides \( n \). If it does, compute \( x \) as \( n // s \) and return it.
4. **Output**: The result for each test case is printed immediately after computation.

This approach efficiently narrows down the possible values of \( k \) and ensures that we find a valid \( x \) quickly due to the exponential growth of \( 2^k \), making the solution both optimal and easy to understand.
