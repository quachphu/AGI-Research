To solve this problem, we need to determine the minimal number of intervals required to cover each query range [x, y]. If it's impossible to cover the range, we should return -1 for that query. The solution involves preprocessing the intervals to optimize the query handling using a greedy algorithm combined with binary lifting for efficient jumps.

### Approach
1. **Preprocessing Intervals**:
   - Sort intervals by their starting point. If multiple intervals start at the same point, keep the one with the largest end.
   - Further process the intervals to retain only those that extend the coverage further than the previous intervals. This helps in reducing redundant intervals and ensures that the intervals are sorted by their start and end points.

2. **Binary Lifting Table**:
   - For each interval, precompute the farthest interval that can be reached in one step using binary search.
   - Build a binary lifting table to allow efficient jumps of powers of two steps. This table helps in quickly determining the farthest point reachable in logarithmic time.

3. **Query Handling**:
   - For each query, use binary search to find the initial interval that covers the start point. If no such interval exists, return -1.
   - Use the binary lifting table to jump through intervals efficiently and count the minimal number of steps required to cover the query range.

import sys
import bisect

def main():
    n, m = map(int, sys.stdin.readline().split())
    intervals = []
    for _ in range(n):
        l, r = map(int, sys.stdin.readline().split())
        intervals.append((l, r))
    
    # Preprocess intervals to keep only the necessary ones
    intervals.sort(key=lambda x: (x[0], -x[1]))
    processed = []
    prev_l = None
    for l, r in intervals:
        if prev_l is None or l != prev_l:
            processed.append((l, r))
            prev_l = l
    
    new_processed = []
    max_r = -1
    for l, r in processed:
        if r > max_r:
            new_processed.append((l, r))
            max_r = r
    processed = new_processed
    
    if not processed:
        for _ in range(m):
            x, y = map(int, sys.stdin.readline().split())
            print(-1)
        return
    
    sorted_l = [l for l, r in processed]
    sorted_r = [r for l, r in processed]
    len_processed = len(processed)
    next_intervals = [-1] * len_processed
    
    for i in range(len_processed):
        l_i, r_i = processed[i]
        left, right = 0, len_processed - 1
        best_j = -1
        while left <= right:
            mid = (left + right) // 2
            if processed[mid][0] <= r_i:
                best_j = mid
                left = mid + 1
            else:
                right = mid - 1
        next_intervals[i] = best_j if best_j > i else -1
    
    log_max = 20
    up = [[-1] * (log_max + 1) for _ in range(len_processed)]
    for i in range(len_processed):
        up[i][0] = next_intervals[i]
    
    for j in range(1, log_max + 1):
        for i in range(len_processed):
            if up[i][j-1] != -1:
                up[i][j] = up[up[i][j-1]][j-1]
    
    for _ in range(m):
        x, y = map(int, sys.stdin.readline().split())
        if x >= y:
            print(0)
            continue
        
        idx = bisect.bisect_right(sorted_l, x) - 1
        if idx < 0 or processed[idx][1] <= x:
            print(-1)
            continue
        
        current = idx
        current_r = processed[current][1]
        if current_r >= y:
            print(1)
            continue
        
        steps = 1
        for j in reversed(range(log_max + 1)):
            if up[current][j] != -1:
                jump_r = processed[up[current][j]][1]
                if jump_r < y:
                    steps += (1 << j)
                    current = up[current][j]
                    current_r = jump_r
        
        if up[current][0] != -1:
            final_jump_r = processed[up[current][0]][1]
            if final_jump_r >= y:
                print(steps + 1)
            else:
                print(-1)
        else:
            print(-1)
