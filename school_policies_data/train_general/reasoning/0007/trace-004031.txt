To solve this problem, we need to efficiently compute the sum of the last digits of pages divisible by a given number for multiple queries. Given the constraints, a direct approach of iterating through all possible pages is infeasible, so we use a mathematical approach based on the cyclical nature of last digits.

### Approach
1. **Identify Cycles**: The last digits of multiples of any number form a repeating cycle. For example, multiples of 3 (3, 6, 9, 12, 15, ...) have last digits that cycle through 3, 6, 9, 2, 5, 8, 1, 4, 7, 0.
2. **Precompute Cycles**: For each possible last digit (0-9), precompute the cycle of last digits, the sum of each cycle, and the prefix sums of the cycle elements.
3. **Efficient Calculation**: For each query, determine how many full cycles fit into the range and the sum of any remaining elements using the precomputed data.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    q = int(input[idx])
    idx += 1

    # Precompute cycles for each d (0-9)
    cycles = []
    for d in range(10):
        elements = []
        seen = set()
        i = 1
        while True:
            current = (d * i) % 10
            if current in seen:
                break
            elements.append(current)
            seen.add(current)
            i += 1
        cycle_sum = sum(elements)
        cycle_length = len(elements)
        prefix_sums = [0]
        s = 0
        for num in elements:
            s += num
            prefix_sums.append(s)
        cycles.append({
            'sum': cycle_sum,
            'length': cycle_length,
            'prefix_sums': prefix_sums
        })

    # Process queries
    for _ in range(q):
        n = int(input[idx])
        m = int(input[idx + 1])
        idx += 2
        k = n // m
        if k == 0:
            print(0)
            continue
        d = m % 10
        if d == 0:
            print(0)
            continue
        data = cycles[d]
        cycle_sum = data['sum']
        cycle_length = data['length']
        prefix_sums = data['prefix_sums']
        full_cycles = k // cycle_length
        remaining = k % cycle_length
        total = full_cycles * cycle_sum + prefix_sums[remaining]
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precompute Cycles**: For each digit from 0 to 9, we generate the cycle of last digits formed by multiplying the digit with consecutive integers. We also compute the sum of each cycle and prefix sums for efficient range sum queries.
2. **Query Processing**: For each query, determine the number of pages (k) that are multiples of m. Using the last digit of m, we find the corresponding precomputed cycle. We then calculate the sum using the number of full cycles and any remaining elements, leveraging the precomputed prefix sums for efficiency.

This approach ensures that we handle large values efficiently by exploiting the cyclical nature of last digits, reducing the complexity from O(k) to O(1) per query after precomputation.
