To solve this problem, we need to determine the maximum possible number of consecutive people standing on hands (represented by '1's) after flipping up to K intervals of people standing on feet (represented by '0's). Each flip operation can convert a range of consecutive '0's to '1's and vice versa.

### Approach
1. **Group Consecutive Characters**: First, we split the input string into groups of consecutive '0's and '1's. This helps in efficiently managing the flipping operations.
2. **Sliding Window Technique**: We use a sliding window approach over these groups to find the maximum length of consecutive '1's that can be achieved by flipping up to K groups of '0's. The window expands to include more groups until the number of '0' groups exceeds K, at which point the window is shrunk from the left until the count of '0' groups is within K.

### Solution Code
```python
n, k = map(int, input().split())
s = input().strip()

if n == 0:
    print(0)
    exit()

# Split into groups of consecutive characters
groups = []
current_char = s[0]
current_count = 1
for c in s[1:]:
    if c == current_char:
        current_count += 1
    else:
        groups.append((current_char, current_count))
        current_char = c
        current_count = 1
groups.append((current_char, current_count))

max_length = 0
current_sum = 0
zero_count = 0
left = 0

for right in range(len(groups)):
    char, cnt = groups[right]
    if char == '0':
        zero_count += 1
    current_sum += cnt
    
    # If the number of zero groups exceeds K, move left pointer
    while zero_count > k:
        left_char, left_cnt = groups[left]
        if left_char == '0':
            zero_count -= 1
        current_sum -= left_cnt
        left += 1
    
    # Update the maximum length found
    if current_sum > max_length:
        max_length = current_sum

print(max_length)
```

### Explanation
1. **Grouping Consecutive Characters**: The input string is split into groups where each group consists of consecutive '0's or '1's. For example, the string "00010" is split into groups [(0, 3), (1, 1), (0, 1)].
2. **Sliding Window**: Using two pointers (left and right), we maintain a window of groups. The right pointer expands the window by including more groups, while the left pointer contracts the window if the number of '0' groups exceeds K. The sum of the lengths of groups within the window gives the length of consecutive '1's after flipping the '0' groups within the window.
3. **Efficiency**: This approach ensures that each group is processed at most twice (once when included and once when excluded), leading to an O(N) time complexity, which is efficient for large input sizes up to 100,000.

This method efficiently tracks the maximum length of consecutive '1's achievable by flipping up to K groups of '0's, ensuring optimal performance and correctness.
