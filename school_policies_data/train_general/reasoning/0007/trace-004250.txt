To solve this problem, we need to determine the nth term of a specific sequence where each term is generated based on a recurrence relation that alternates between addition and multiplication depending on whether the term's position is even or odd.

### Approach
1. **Problem Analysis**: The sequence starts with 1, 2, and each subsequent term is determined by the following rules:
   - If the term's position (n) is even, the term is the sum of the two preceding terms.
   - If the term's position (n) is odd, the term is the product of the two preceding terms.
   
2. **Precomputation**: Since the maximum value of n can be 20, we precompute the terms up to n=20 using the recurrence relation. This allows us to efficiently answer each query in constant time.

3. **Efficiency**: Precomputing the terms once and storing them in an array ensures that each query is answered in O(1) time. The precomputation itself runs in O(n) time, which is feasible given the constraint n ≤ 20.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    cases = list(map(int, input[1:T+1]))
    
    # Precompute the sequence up to n=20
    dp = [0] * 20
    dp[0] = 1  # n=1
    if len(dp) > 1:
        dp[1] = 2  # n=2
    for i in range(2, 20):
        n = i + 1  # Current term's position (1-based)
        if n % 2 == 0:
            # Even n: sum of previous two terms
            dp[i] = dp[i-1] + dp[i-2]
        else:
            # Odd n: product of previous two terms
            dp[i] = dp[i-1] * dp[i-2]
    
    # Output results for each test case
    for case in cases:
        print(dp[case - 1])

if __name__ == "__main__":
    main()
```
