To solve this problem, we need to determine how many of Takahashi's friends can ride a roller coaster based on their height. The roller coaster requires a minimum height of K centimeters. We will read the input values, check each friend's height against this threshold, and count how many meet or exceed it.

### Approach
1. **Read Input:** First, we read the number of friends (N) and the minimum height (K) from the input.
2. **Read Heights:** Next, we read the list of heights of each friend.
3. **Count Eligible Friends:** We iterate through the list of heights and count how many of them are greater than or equal to K.
4. **Output the Result:** Finally, we print the count of friends who meet the height requirement.

This approach ensures that we efficiently check each friend's height in linear time, O(N), which is optimal given the problem constraints.

### Solution Code
```python
def main():
    import sys
    n, k = map(int, sys.stdin.readline().split())
    heights = list(map(int, sys.stdin.readline().split()))
    count = 0
    for h in heights:
        if h >= k:
            count += 1
    print(count)

main()
```

### Explanation
1. **Reading Input:** The input is read using `sys.stdin.readline()` for efficiency. The first line is split into two integers, N (number of friends) and K (minimum height required). The second line is split into a list of integers representing the heights of each friend.
2. **Counting Eligible Friends:** We initialize a counter to zero. For each height in the list, we check if it is at least K. If it is, we increment the counter.
3. **Output:** The result is printed, which is the count of friends who meet the height requirement.

This solution efficiently processes the input and checks each height in linear time, making it suitable even for the upper constraint limits.
