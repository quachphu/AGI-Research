To solve this problem, we need to determine the maximum number of candies Alice and Bob can each have after optimally dividing three piles of candies. The division process involves Alice and Bob each taking one pile, then splitting the third pile such that the difference between their total candies is minimized. The goal is to maximize the minimum number of candies each can have after possible discards.

### Approach
1. **Understanding the Problem**: Alice and Bob each take one pile, and the third pile is split optimally. The key is to maximize the minimum number of candies each can have after splitting the third pile.
2. **Optimal Split Calculation**: For each possible way of splitting the third pile, we calculate the maximum possible minimum candies each can have. This is derived by considering the sum of all candies and ensuring the split is as fair as possible.
3. **Three Scenarios**: We consider three scenarios where each pile is the one being split. For each scenario, we compute the maximum possible minimum candies using the formula `min(total // 2, total - max of the other two piles)`.
4. **Maximize Over All Scenarios**: The result for each query is the maximum value obtained from the three scenarios.

### Solution Code
```python
q = int(input())
for _ in range(q):
    a, b, c = map(int, input().split())
    s = a + b + c
    # Split a (so initial piles are b and c)
    candidate1 = min(s // 2, s - max(b, c))
    # Split b (initial piles are a and c)
    candidate2 = min(s // 2, s - max(a, c))
    # Split c (initial piles are a and b)
    candidate3 = min(s // 2, s - max(a, b))
    print(max(candidate1, candidate2, candidate3))
```

### Explanation
1. **Reading Input**: The number of queries `q` is read first. For each query, the values of the three piles `a`, `b`, and `c` are read.
2. **Total Candies Calculation**: The total number of candies `s` is computed as the sum of `a`, `b`, and `c`.
3. **Scenario Evaluations**:
   - **Split Pile a**: Calculate the maximum possible minimum candies when splitting pile `a`, considering the other two piles `b` and `c`.
   - **Split Pile b**: Similarly, calculate when splitting pile `b`, considering the other two piles `a` and `c`.
   - **Split Pile c**: Calculate when splitting pile `c`, considering the other two piles `a` and `b`.
4. **Result Calculation**: The maximum value from the three scenarios is printed as the result for each query.

This approach ensures that all possible ways of splitting the third pile are considered, and the optimal solution is derived efficiently. The use of integer division and maximum functions ensures correctness and efficiency even for very large values.
