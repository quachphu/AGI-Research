To solve this problem, we need to count the number of pairs of bishops that attack each other on a 1000x1000 grid. Bishops attack each other if they are on the same diagonal. There are two types of diagonals: main diagonals (top-left to bottom-right) and anti-diagonals (top-right to bottom-left). We will determine the number of attacking pairs by considering both types of diagonals.

### Approach
1. **Identify Diagonals**: For each bishop at position (x, y), compute two values:
   - `sum_diag = x + y` for anti-diagonals.
   - `diff_diag = x - y` for main diagonals.
2. **Count Bishops on Each Diagonal**: Use dictionaries to count how many bishops are on each diagonal (both main and anti).
3. **Calculate Pairs**: For each diagonal, the number of attacking pairs is given by the combination formula `k * (k - 1) / 2`, where `k` is the number of bishops on that diagonal. Sum these values for all diagonals.

### Solution Code
```python
import sys

def count_attacking_pairs():
    n = int(sys.stdin.readline())
    sum_counts = {}
    diff_counts = {}
    for _ in range(n):
        x, y = map(int, sys.stdin.readline().split())
        s = x + y
        d = x - y
        sum_counts[s] = sum_counts.get(s, 0) + 1
        diff_counts[d] = diff_counts.get(d, 0) + 1
    total = 0
    for count in sum_counts.values():
        total += count * (count - 1) // 2
    for count in diff_counts.values():
        total += count * (count - 1) // 2
    print(total)

count_attacking_pairs()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency, especially with large input sizes.
2. **Tracking Diagonals**: Two dictionaries, `sum_counts` and `diff_counts`, are used to track the number of bishops on each anti-diagonal (sum of coordinates) and main diagonal (difference of coordinates), respectively.
3. **Calculating Pairs**: For each diagonal type, we compute the number of attacking pairs using the combination formula. The results from both diagonal types are summed to get the total number of attacking pairs.

This approach ensures that we efficiently count the pairs in linear time relative to the number of bishops, making it suitable for large input sizes up to 200,000 bishops.
