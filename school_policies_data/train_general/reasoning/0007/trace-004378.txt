To solve this problem, we need to compute the 'wow' factor of a given string. The 'wow' factor is defined as the number of subsequences equal to "wow", where each 'w' is represented by two consecutive 'v's. This means we need to count the number of valid subsequences that match the pattern "vvovv" (two 'v's followed by an 'o' and then two more 'v's).

### Approach
1. **Split the String into Runs**: First, we split the input string into runs of consecutive characters. For example, the string "vvvovvv" would be split into runs of 'v's and 'o's.
2. **Compute Prefix and Suffix Sums**: We compute two arrays:
   - **Prefix Sum**: This array keeps track of the cumulative count of consecutive 'v' pairs up to each position.
   - **Suffix Sum**: This array keeps track of the cumulative count of consecutive 'v' pairs from each position to the end of the string.
3. **Calculate Contributions from Each 'o' Run**: For each run of 'o's, we determine the number of valid consecutive 'v' pairs before and after the 'o' run using the prefix and suffix sums. The contribution of each 'o' run to the total 'wow' factor is the product of these counts multiplied by the length of the 'o' run.

### Solution Code
```python
def main():
    import sys
    s = sys.stdin.readline().strip()
    if not s:
        print(0)
        return

    # Split the string into runs of consecutive characters
    runs = []
    n = len(s)
    current_char = s[0]
    start = 0
    for i in range(1, n):
        if s[i] != current_char:
            runs.append((current_char, start, i-1))
            current_char = s[i]
            start = i
    runs.append((current_char, start, n-1))

    # Compute prefix sums of consecutive 'v' pairs
    prefix = [0] * len(runs)
    current_sum = 0
    for i in range(len(runs)):
        char, st, end = runs[i]
        if char == 'v':
            current_sum += (end - st + 1) - 1  # number of pairs in this run
        prefix[i] = current_sum

    # Compute suffix sums of consecutive 'v' pairs
    suffix = [0] * len(runs)
    current_sum = 0
    for i in range(len(runs)-1, -1, -1):
        char, st, end = runs[i]
        if char == 'v':
            current_sum += (end - st + 1) - 1  # number of pairs in this run
        suffix[i] = current_sum

    total = 0
    for i in range(len(runs)):
        char, st, end = runs[i]
        if char == 'o':
            # Calculate left pairs (from prefix) and right pairs (from suffix)
            left_pairs = prefix[i-1] if i > 0 else 0
            right_pairs = suffix[i+1] if i+1 < len(runs) else 0
            # Number of 'o's in this run contributes multiplicatively
            total += (end - st + 1) * left_pairs * right_pairs

    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Splitting into Runs**: The input string is divided into segments (runs) of consecutive 'v's and 'o's. This helps in efficiently counting consecutive 'v' pairs.
2. **Prefix and Suffix Sums**: These arrays help in quickly determining the number of consecutive 'v' pairs before and after each 'o' run. The prefix sum accumulates the count of 'v' pairs from the start up to each position, while the suffix sum accumulates from the end backwards.
3. **Calculating Contributions**: For each 'o' run, the contribution to the 'wow' factor is calculated by multiplying the number of 'v' pairs before and after the 'o' run, scaled by the number of 'o's in the run. This approach ensures that we efficiently count all valid subsequences without redundant checks.

This method ensures that we handle even large input sizes efficiently, adhering to the problem constraints.
