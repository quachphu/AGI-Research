To solve this problem, we need to determine the minimum distance Winnie-the-Pooh must travel to have his meals exactly `n` times, starting from Rabbit's house and moving between friends' houses in such a way that minimizes the total travel distance.

### Approach
1. **Dynamic Programming (DP) Setup**: We use a DP table where `dp[i][current_house]` represents the minimum distance required to have `i` meals ending at `current_house`.
2. **Initialization**: The first meal is at Rabbit's house (R) with zero distance. Thus, `dp[1][R] = 0` and other initial values are set to infinity (unreachable).
3. **Transition Between Houses**: For each subsequent meal (from 2 to `n`), compute the minimum distance to reach each house from any other possible previous house, considering the distances between Rabbit (R), Owl (O), and Eeyore (E).
4. **Result Extraction**: The result for `n` meals is the minimum value among the distances stored in `dp[n][R]`, `dp[n][O]`, and `dp[n][E]`.

### Solution Code
```python
def main():
    n = int(input())
    a = int(input())
    b = int(input())
    c = int(input())

    INF = float('inf')
    # Representing the houses as 0 (Rabbit), 1 (Owl), 2 (Eeyore)
    dist = [
        [0, a, b],
        [a, 0, c],
        [b, c, 0]
    ]

    dp = [[INF] * 3 for _ in range(n + 1)]
    dp[1][0] = 0  # First meal at Rabbit's house

    for i in range(2, n + 1):
        for current in range(3):
            min_dist = INF
            for prev in range(3):
                if prev != current:
                    if dp[i-1][prev] + dist[prev][current] < min_dist:
                        min_dist = dp[i-1][prev] + dist[prev][current]
            dp[i][current] = min_dist

    print(min(dp[n][0], dp[n][1], dp[n][2]))

main()
```

### Explanation
1. **Input Handling**: Read the number of meals `n` and the distances between the houses.
2. **Distance Matrix**: A matrix `dist` is used to store the distances between each pair of houses.
3. **DP Table Initialization**: The DP table `dp` is initialized with infinity values except for the starting position (Rabbit's house) after the first meal.
4. **DP Transitions**: For each meal count from 2 to `n`, compute the minimum distance to each house by considering all possible transitions from the previous house, excluding the current house to avoid staying in the same place.
5. **Result Calculation**: After filling the DP table, the minimum distance for `n` meals is found by taking the minimum value from the last row of the DP table.

This approach efficiently computes the minimum travel distance using dynamic programming, ensuring that each transition between houses is considered optimally.
