To solve this problem, we need to determine the size of the largest subsequence of a given string such that all characters in the subsequence are distinct. The solution involves counting the number of unique characters in each string, as the largest distinct subsequence can be formed by including each unique character exactly once.

### Approach
1. **Understanding the Problem**: A subsequence can be formed by deleting some characters from the string without changing the order of the remaining characters. The largest subsequence with all distinct characters will simply be the number of unique characters in the string.
2. **Key Insight**: The maximum possible size of such a subsequence is equal to the number of unique characters in the string. This is because each unique character can appear exactly once in the subsequence.
3. **Algorithm**: For each input string, convert it into a set of characters (which automatically removes duplicates) and compute the size of this set. This size gives the number of unique characters, which is the answer for that string.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        s = sys.stdin.readline().strip()
        print(len(set(s)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads the number of test cases `t` from the input.
2. **Processing Each Test Case**: For each test case, the string is read and any leading/trailing whitespace (like newline characters) is removed using `strip()`.
3. **Counting Unique Characters**: The string is converted into a set of characters, which removes duplicates. The length of this set, which represents the number of unique characters, is printed as the result for each test case.

This approach efficiently computes the required result with a time complexity of O(N) per string, where N is the length of the string, due to the operations involved in converting the string to a set and determining its length. This ensures the solution is both optimal and straightforward.
