To solve this problem, we need to determine the maximum possible area of the smallest piece of chocolate after making exactly k cuts, either horizontally or vertically. The solution involves checking the feasibility of the cuts and then optimizing the distribution of cuts to maximize the minimum area.

### Approach
1. **Feasibility Check**: First, check if it is possible to make k cuts. If k exceeds the maximum possible cuts (n-1 vertical cuts plus m-1 horizontal cuts), output -1.
2. **Generate Candidate Cuts**: If feasible, generate candidate values for the number of horizontal cuts (h) around the optimal real number derived from k/2. This includes checking boundaries and nearby values to ensure we cover potential optimal solutions.
3. **Evaluate Candidates**: For each candidate value of h, compute the corresponding vertical cuts (v = k - h). Check if these cuts are within valid ranges and calculate the resulting area. Track the maximum area obtained from these valid configurations.

### Solution Code
```python
n, m, k = map(int, input().split())

if k > (n - 1) + (m - 1):
    print(-1)
else:
    h_min = max(0, k - (m - 1))
    h_max = min(n - 1, k)
    
    optimal_h_floor = (k - 1) // 2
    optimal_h_ceil = optimal_h_floor + 1
    
    candidates = {
        h_min,
        h_max,
        optimal_h_floor,
        optimal_h_floor - 1,
        optimal_h_floor + 1,
        optimal_h_ceil,
        optimal_h_ceil - 1,
        optimal_h_ceil + 1
    }
    
    max_area = 0
    
    for h in candidates:
        if h < h_min or h > h_max:
            continue
        v = k - h
        if v < 0 or v > (m - 1):
            continue
        
        a = n // (h + 1)
        b = m // (v + 1)
        current_area = a * b
        if current_area > max_area:
            max_area = current_area

```

3. **Area Calculation**: For each valid candidate h, the corresponding vertical cuts (v) are computed. The area of the smallest piece is determined by dividing the chocolate into (h+1) rows and (v+1) columns, then calculating the product of the minimum dimensions of these divisions.
