To solve this problem, we need to determine who between Vladik and Valera will be the first to run out of candies when they take turns giving each other an increasing number of candies. Vladik starts with giving 1 candy, followed by Valera giving 2 candies, then Vladik giving 3 candies, and so on. Each person uses their original stash of candies, and the candies received from each other are not considered part of their own stash.

### Approach
1. **Initialization**: Start with the initial counts of candies for Vladik and Valera.
2. **Turn Simulation**: Alternate turns between Vladik and Valera, incrementing the number of candies given each turn.
3. **Check Availability**: For each turn, check if the current person has enough candies to give the required amount. If not, that person is the first to fail.
4. **Termination**: The loop continues until one of them cannot give the required number of candies, at which point we print the name of the person who failed.

### Solution Code
```python
a, b = map(int, input().split())
sum_v = 0
sum_va = 0
current_step = 1

while True:
    if current_step % 2 == 1:
        if sum_v + current_step > a:
            print("Vladik")
            break
        sum_v += current_step
    else:
        if sum_va + current_step > b:
            print("Valera")
            break
        sum_va += current_step
    current_step += 1
```

### Explanation
1. **Initialization**: Read the initial number of candies for Vladik (`a`) and Valera (`b`).
2. **Turn Simulation**: Use a loop where `current_step` starts at 1 and increments by 1 each iteration. The step number determines whose turn it is (odd steps for Vladik, even steps for Valera).
3. **Check Availability**: For each step, check if the current person's total given candies (summing up their previous contributions plus the current step's requirement) exceeds their initial stash. If it does, print the person's name and exit the loop.
4. **Termination**: The loop stops as soon as one person cannot meet the required number of candies, ensuring the correct result is printed immediately.

This approach efficiently simulates the turns and checks for the failure condition in each iteration, ensuring that we handle up to the maximum possible values of `a` and `b` within the problem constraints. The complexity is O(sqrt(n)), which is efficient for the given problem limits.
