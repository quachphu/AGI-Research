To solve this problem, we need to determine the number of seats in a grid that remain in a standing state after a series of instructions. This will help us determine the latest arrival time required to ensure entry into the venue in the worst-case scenario where all participants except the user choose seats optimally.

### Approach
1. **Process Instructions**: Track the last step and order (sit or stand) for each row and column based on the given instructions.
2. **Sort Steps**: Collect and sort the last steps for rows and columns to facilitate efficient binary search operations.
3. **Count Valid Seats**:
   - For each row that ends in a standing order, count the number of columns whose last step is before the row's last step.
   - For each column that ends in a standing order, count the number of rows whose last step is before or equal to the column's last step.

### Solution Code
```python
import bisect
import sys

def main():
    for line in sys.stdin:
        r, c, q = map(int, line.strip().split())
        if r == 0 and c == 0 and q == 0:
            break
        
        # Initialize row and column data
        row_last_step = [0] * r
        row_last_order = [0] * r
        col_last_step = [0] * c
        col_last_order = [0] * c
        
        for step in range(1, q + 1):
            parts = sys.stdin.readline().split()
            Ai = int(parts[0])
            Bi = int(parts[1])
            order = int(parts[2])
            
            if Ai == 0:
                row = Bi
                row_last_step[row] = step
                row_last_order[row] = order
            else:
                col = Bi
                col_last_step[col] = step
                col_last_order[col] = order
        
        # Collect all column steps and sort
        sorted_col_steps = sorted(col_last_step)
        # Collect all row steps and sort
        sorted_row_steps = sorted(row_last_step)
        
        count = 0
        
        # Process rows with order 1
        for i in range(r):
            if row_last_order[i] == 1:
                target = row_last_step[i]
                cnt = bisect.bisect_left(sorted_col_steps, target)
                count += cnt
        
        # Process columns with order 1
        for j in range(c):
            if col_last_order[j] == 1:
                target = col_last_step[j]
                cnt = bisect.bisect_right(sorted_row_steps, target)
                count += cnt
        
        print(count)

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read line by line, processing each test case until the termination condition (0 0 0) is encountered.
2. **Tracking Instructions**: For each instruction, we update the last step and order for the specified row or column.
3. **Sorting Steps**: The last steps for rows and columns are sorted to allow efficient binary search operations.
4. **Counting Valid Seats**:
   - For each row that ends in a standing order, we use binary search to count how many columns have a last step before the row's last step.
   - For each column that ends in a standing order, we use binary search to count how many rows have a last step before or equal to the column's last step.
5. **Output**: The total count of valid seats is printed for each test case.

This approach efficiently computes the required result using sorting and binary search, ensuring that the solution is optimal even for large grid sizes and numerous instructions.
