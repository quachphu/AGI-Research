To solve this problem, we need to determine if all elements in a given sequence of integers are pairwise distinct. If there are any duplicates, we should print "NO"; otherwise, we print "YES".

### Approach
1. **Read Input Efficiently**: The input consists of an integer \( N \) followed by \( N \) integers. We can read all input at once and split it into individual elements for efficient processing.
2. **Use a Set for Tracking Elements**: A set data structure is used to keep track of elements we have seen so far. Checking for membership in a set is an average O(1) operation, which allows us to efficiently determine if an element has already been encountered.
3. **Early Termination**: As soon as we find a duplicate element, we can immediately print "NO" and terminate the program to save unnecessary computations.
4. **Edge Cases Handling**: The approach naturally handles edge cases such as all elements being the same or having exactly two identical elements.

### Solution Code
```python
def main():
    import sys
    data = list(map(int, sys.stdin.read().split()))
    n = data[0]
    a = data[1:n+1]
    seen = set()
    for num in a:
        if num in seen:
            print("NO")
            return
        seen.add(num)
    print("YES")

main()
```

### Explanation
1. **Reading Input**: The input is read in one go using `sys.stdin.read()` which is split into a list of integers. The first integer is \( N \), the number of elements, and the subsequent integers are the elements of the sequence.
2. **Set Initialization**: A set `seen` is initialized to keep track of elements we have encountered.
3. **Element Check and Insertion**: For each element in the sequence, we check if it exists in the set. If it does, we print "NO" and exit immediately. If not, the element is added to the set.
4. **Output Result**: If the loop completes without finding any duplicates, "YES" is printed.

This approach ensures that we efficiently check for duplicates in linear time, O(N), making it suitable for large input sizes up to 200,000 elements.
