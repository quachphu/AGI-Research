To solve this problem, we need to adjust the heights of trees in a row such that each consecutive tree's height differs by a given constant \( k \). The goal is to achieve this with the minimum number of operations, where each operation can either increase or decrease a tree's height to any positive integer.

### Approach
1. **Identify Potential Bases**: For each tree \( i \), calculate the potential starting height (base) of the arithmetic sequence that would allow the tree's current height to fit into the sequence. This is done using the formula \( \text{base}_i = a_i - (i-1) \times k \).
2. **Validate Bases**: Check if each calculated base is valid (i.e., positive). For each valid base, determine how many trees already fit into the arithmetic sequence starting with that base.
3. **Select Optimal Base**: Choose the base that maximizes the number of trees fitting into its sequence. If no valid base exists, default to a base of 1.
4. **Generate Operations**: For the chosen base, generate the required operations to adjust the heights of the trees that do not fit into the sequence.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))

best_base = None
max_count = 0

# Check all possible bases derived from each tree
for i in range(n):
    current_base = a[i] - i * k  # since (i+1-1) = i (0-based)
    if current_base < 1:
        continue
    cnt = 0
    for j in range(n):
        required = current_base + j * k
        if a[j] == required:
            cnt += 1
    # Update best_base if current count is higher or same but base is smaller
    if cnt > max_count or (cnt == max_count and (best_base is None or current_base < best_base)):
        max_count = cnt
        best_base = current_base

# Handle case where all bases are invalid
if best_base is None:
    best_base = 1

# Generate the operations
operations = []
for j in range(n):
    required = best_base + j * k
    if a[j] != required:
        delta = required - a[j]
        if delta > 0:
            operations.append(f"+ {j + 1} {delta}")
        else:
            operations.append(f"- {j + 1} {-delta}")

print(len(operations))
for op in operations:
    print(op)
```

### Explanation
1. **Identify Potential Bases**: For each tree, compute the base that would make the tree's height fit into the arithmetic sequence starting at that base.
2. **Validate and Count**: For each valid base (positive), count how many trees already fit into the sequence starting at that base.
3. **Select Optimal Base**: Choose the base with the highest count of fitting trees. If there's a tie, select the smallest base to minimize the required adjustments.
4. **Generate Adjustments**: For the selected base, determine the necessary operations to adjust each tree's height to fit into the sequence, either increasing or decreasing as needed.

This approach ensures that we minimize the number of operations by leveraging the optimal starting height derived from the existing tree heights, thus efficiently achieving the desired arithmetic sequence.
