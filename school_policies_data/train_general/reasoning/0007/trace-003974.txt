To solve this problem, we need to find the cheapest route for Kita_masa's world trip that visits every city exactly once and returns to the starting city. The solution involves a combination of domestic and international flights, with the constraint that international flights can only be taken between international airports.

### Approach
1. **Precompute Internal Costs**: For each country, compute the minimal cost to traverse all cities starting from one international airport and ending at another. This is done using a dynamic programming (DP) approach to solve the Hamiltonian path problem within each country.
2. **Model as a Traveling Salesman Problem (TSP)**: Use a DP approach to model the problem as a TSP on international airports. The state tracks the current airport, the set of visited countries, and the starting airport.
3. **Check for Valid Cycles**: After processing all possible paths, check if there is a valid cycle that returns to the starting airport, ensuring all cities are visited exactly once.

            exit_idx = index_map.get((s_country, exit_city), -1)
            if exit_idx is None:
                continue
            a = s_city - 1
            b = exit_city - 1
            ic = internal_cost[s_country][a][b]
            if ic == float('inf'):
                continue
            mask = 1 << s_country
            if ic < dp[exit_idx][mask]:
                dp[exit_idx][mask] = ic
        
        for mask in range(1 << N):
            for u_idx in range(num_airports):
                if dp[u_idx][mask] == float('inf'):
                    continue
                current_cost = dp[u_idx][mask]
                for (v_idx, flight_cost) in international_adj[u_idx]:
                    v_country, v_city = airports[v_idx]
                    if (mask & (1 << v_country)):
                        continue
                    for exit_city in range(1, F[v_country]+1):
                        exit_idx = index_map.get((v_country, exit_city), -1)
                        if exit_idx is None:
                            continue
                        a = v_city - 1
                        b = exit_city - 1
                        ic = internal_cost[v_country][a][b]
                        if ic == float('inf'):
                            continue
                        new_mask = mask | (1 << v_country)
                        new_cost = current_cost + flight_cost + ic
                        if new_cost < dp[exit_idx][new_mask]:
                            dp[exit_idx][new_mask] = new_cost
        
        full_mask = (1 << N) -1
        for u_idx in range(num_airports):
            if dp[u_idx][full_mask] == float('inf'):
                continue
            for (v_idx, flight_cost) in international_adj[u_idx]:
                if v_idx == s_idx:
                    total_cost = dp[u_idx][full_mask] + flight_cost
                    if total_cost < min_total:
                        min_total = total_cost
    
    print(-1 if min_total == float('inf') else min_total)

if __name__ == "__main__":
