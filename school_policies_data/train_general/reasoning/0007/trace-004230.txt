To solve this problem, we need to determine if a given string can be transformed into a valid telephone number by deleting some characters. A valid telephone number is exactly 11 digits long and starts with the digit '8'.

### Approach
1. **Check Length Constraint**: First, check if the length of the string is at least 11. If not, it's impossible to form a valid telephone number, so the answer is "NO".
2. **Identify Valid Starting Position**: For strings with length ≥ 11, we need to check if there's a digit '8' within the first (n - 10) characters. This is because the earliest valid starting position for '8' must leave enough characters (exactly 10) after it to form the remaining part of the telephone number.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    if n < 11:
        print("NO")
        continue
    required_length = n - 10
    found = any(c == '8' for c in s[:required_length])
    print("YES" if found else "NO")
```

### Explanation
1. **Input Reading**: The code reads the number of test cases `t`.
2. **Loop Through Test Cases**: For each test case, it reads the length of the string `n` and the string `s`.
3. **Length Check**: If the string length is less than 11, it immediately outputs "NO".
4. **Check for Valid '8' Position**: If the string length is sufficient, it checks the first (n - 10) characters for the presence of '8'. If found, it prints "YES"; otherwise, it prints "NO".

This approach ensures that we efficiently determine the possibility of forming a valid telephone number by leveraging the position of '8' and ensuring there are enough subsequent characters to complete the 11-digit requirement.
