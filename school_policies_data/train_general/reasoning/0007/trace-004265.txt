To solve this problem, we need to determine the number of valid combinations of four digits (a, b, c, d) where each digit ranges from 0 to 9, such that their sum equals a given integer n. The solution must handle multiple test cases efficiently.

### Approach
1. **Precomputation**: Since the maximum possible sum of four digits (each ranging from 0 to 9) is 36, we precompute the number of valid combinations for each possible sum from 0 to 36. This allows us to answer each query in constant time.
2. **Brute-force Generation**: We generate all possible combinations of four digits (a, b, c, d) using four nested loops. For each combination, we compute the sum and increment the corresponding count in our precomputed list.
3. **Efficient Query Handling**: For each input value n, we check if it falls within the valid range (0 to 36). If it does, we use the precomputed count; otherwise, the result is 0.

### Solution Code
```python
def main():
    # Precompute the number of combinations for each possible sum (0 to 36)
    counts = [0] * 37  # Index 0 to 36
    for a in range(10):
        for b in range(10):
            for c in range(10):
                for d in range(10):
                    s = a + b + c + d
                    if s <= 36:
                        counts[s] += 1
    
    # Read each line from stdin and process
    import sys
    for line in sys.stdin:
        n = int(line.strip())
        if 0 <= n <= 36:
            print(counts[n])
        else:
            print(0)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precomputation**: The nested loops iterate through all possible values of a, b, c, and d (each from 0 to 9). For each combination, the sum is calculated. If the sum is within the valid range (0 to 36), the corresponding index in the `counts` list is incremented. This precomputation step ensures that we efficiently count all valid combinations once.
2. **Query Handling**: For each input value, we check if it lies within the valid range. If it does, we directly use the precomputed count; otherwise, the result is 0. This approach ensures that each query is answered in constant time, making the solution highly efficient even for the maximum input size.

This method efficiently handles up to 50 test cases, each with a sum up to 50, by leveraging precomputation to minimize repeated calculations.
