To solve this problem, we need to determine the cost of painting the remaining logs after certain ranges of logs have been painted. The solution involves efficiently calculating the sum of the remaining logs for each query using prefix sums.

### Approach
1. **Read Input:** Read the number of logs (N) and the number of queries (Q), followed by the cost array of the logs.
2. **Compute Total Sum:** Calculate the total sum of the cost array to determine the sum of all logs.
3. **Prefix Sum Array:** Construct a prefix sum array where each element at index `i` represents the sum of the first `i` elements of the cost array. This allows for quick range sum queries.
4. **Process Queries:** For each query, compute the sum of the logs in the given range using the prefix sum array. Subtract this sum from the total sum to get the cost of the remaining logs.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    N, Q = int(input[ptr]), int(input[ptr + 1])
    ptr += 2
    arr = list(map(int, input[ptr:ptr + N]))
    ptr += N
    total_sum = sum(arr)
    prefix = [0] * (N + 1)
    for i in range(1, N + 1):
        prefix[i] = prefix[i - 1] + arr[i - 1]
    results = []
    for _ in range(Q):
        L = int(input[ptr])
        R = int(input[ptr + 1])
        ptr += 2
        sum_lr = prefix[R] - prefix[L - 1]
        results.append(total_sum - sum_lr)
    print('\n'.join(map(str, results)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently:** The input is read all at once and split into tokens for efficient processing.
2. **Total Sum Calculation:** The total sum of the cost array is computed once, which is used to determine the remaining cost after each query.
3. **Prefix Sum Array:** This array allows for O(1) range sum queries. Each element `prefix[i]` is the sum of the first `i` elements of the cost array.
4. **Query Processing:** For each query, the sum of the specified range is computed using the prefix sum array. The result for each query is the total sum minus the sum of the specified range, which is then collected and printed.

This approach ensures that each query is processed in constant time after an initial linear time preprocessing step, making the solution efficient even for large inputs.
