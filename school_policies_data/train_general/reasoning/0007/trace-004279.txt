To solve this problem, we need to find the maximum number of hugs you can get by spending exactly `x` consecutive days with Coronavirus-chan, considering that the days can wrap around the end of the year. The solution involves efficiently calculating the optimal sequence of days using prefix sums and binary search.

### Approach
1. **Doubling the Array**: To handle the circular nature of the year, we double the array of month lengths. This allows us to consider sequences that wrap around the end of the year as linear sequences in the doubled array.
2. **Prefix Sums**: Compute prefix sums for both the number of days and the cumulative hugs. These prefix sums help in quickly calculating the total days and hugs for any segment of the array.
3. **Binary Search**: For each starting month, use binary search to find the earliest month where the cumulative days reach or exceed `x`. This helps in efficiently determining the optimal sequence of days.
4. **Excess Days Calculation**: Adjust the sum by removing the excess days from the end of the identified segment to ensure exactly `x` days are considered.

### Solution Code
```python
def main():
    import sys
    n, x = map(int, sys.stdin.readline().split())
    d = list(map(int, sys.stdin.readline().split()))
    extended_d = d + d
    m = len(extended_d)
    days_prefix = [0] * (m + 1)
    hugs_prefix = [0] * (m + 1)
    
    for i in range(m):
        days_prefix[i+1] = days_prefix[i] + extended_d[i]
        hugs_prefix[i+1] = hugs_prefix[i] + (extended_d[i] * (extended_d[i] + 1)) // 2
    
    max_hugs = 0
    
    for i in range(n):
        left = i
        right = 2 * n - 1
        best_j = i
        
        # Binary search for the smallest j >= i such that days_prefix[j+1] - days_prefix[i] >= x
        while left <= right:
            mid = (left + right) // 2
            if mid + 1 > len(days_prefix) - 1:
                total = days_prefix[-1] - days_prefix[i]
            else:
                total = days_prefix[mid + 1] - days_prefix[i]
            if total >= x:
                best_j = mid
                right = mid - 1
            else:
                left = mid + 1
        
        j = best_j
        if j + 1 > len(days_prefix) - 1:
            total_days = days_prefix[-1] - days_prefix[i]
        else:
            total_days = days_prefix[j + 1] - days_prefix[i]
        
        if total_days < x:
            continue
        
        excess = total_days - x
        sum_excess = excess * (excess + 1) // 2
        current_hugs = hugs_prefix[j + 1] - hugs_prefix[i] - sum_excess
        
        if current_hugs > max_hugs:
            max_hugs = current_hugs
    
    print(max_hugs)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Doubling the Array**: This allows us to treat the circular year as a linear array, making it easier to handle sequences that wrap around the end of the year.
2. **Prefix Sums**: The `days_prefix` array helps quickly determine the total number of days between any two months. The `hugs_prefix` array helps in quickly calculating the total hugs for the same range.
3. **Binary Search**: For each starting month, we use binary search to find the smallest segment of months that contains at least `x` days. This ensures we efficiently narrow down the optimal sequence.
4. **Excess Days Adjustment**: After identifying the segment, we adjust the sum by removing the excess days from the end of the segment to ensure exactly `x` days are considered, thus maximizing the hugs.

This approach efficiently handles the constraints and ensures we find the optimal solution in O(n log n) time, making it suitable for large input sizes.
