To solve this problem, we need to determine if we can sort an array using specific allowed adjacent swaps. Each integer from 1 to n appears exactly once in the array, and we can swap elements at positions i and i+1 if the corresponding character in the given string is '1'.

### Approach
1. **Identify Allowed Regions**: Determine the contiguous regions in the array where swaps are allowed. Each element in these regions can be freely rearranged within their region.
2. **Left and Right Boundaries**: For each position in the array, compute the leftmost (l) and rightmost (r) positions it can reach using allowed swaps. This helps in defining the boundaries of each region.
3. **Check Sorted Positions**: After sorting the array, check if each element's target position in the sorted array lies within the boundaries of its original region. If all elements meet this condition, the array can be sorted; otherwise, it cannot.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
swap_str = input().strip()

# Initialize l and r arrays (1-based indices)
l = [0] * (n + 1)
r = [0] * (n + 1)

l[1] = 1
for i in range(2, n + 1):
    if swap_str[i-2] == '1':
        l[i] = l[i-1]
    else:
        l[i] = i

r[n] = n
for i in range(n-1, 0, -1):
    if i <= len(swap_str) and swap_str[i-1] == '1':
        r[i] = r[i+1]
    else:
        r[i] = i

sorted_a = sorted(a)
pos_map = {num: i+1 for i, num in enumerate(sorted_a)}

possible = True
for i in range(1, n + 1):
    original_num = a[i-1]
    target_pos = pos_map[original_num]
    if not (l[i] <= target_pos <= r[i]):
        possible = False
        break

print("YES" if possible else "NO")
```

3. **Computing Right Boundaries (r)**: Similarly, compute the rightmost position reachable using allowed swaps by iterating from right to left.
4. **Mapping Positions**: After sorting the array, create a mapping from each element to its position in the sorted array.
5. **Validation**: Check if each element's target position in the sorted array falls within the boundaries of its original region. If all elements satisfy this condition, print "YES"; otherwise, print "NO".

This approach efficiently determines if the array can be sorted using the allowed swaps by leveraging contiguous regions and boundary checks, ensuring an optimal solution with a time complexity of O(n).
