To solve this problem, we need to determine the maximum possible state of Ilya's bank account after he uses his gift to delete either the last digit or the second last digit of his account balance once, or chooses not to delete any digit at all.

### Approach
1. **Input Handling**: Read the input as a string to facilitate digit manipulation.
2. **Generate Candidates**: Create three potential account states:
   - The original account state.
   - The account state after deleting the last digit.
   - The account state after deleting the second last digit.
3. **Convert and Compare**: Convert these string candidates back to integers and determine the maximum value among them.

### Solution Code
```python
s = input().strip()
original = int(s)
c2 = int(s[:-1])
c3 = int(s[:-2] + s[-1])
print(max(original, c2, c3))
```

### Explanation
1. **Reading Input**: The input is read as a string to easily manipulate individual digits.
2. **Generating Candidates**:
   - **Original Value**: Directly convert the input string to an integer.
   - **Delete Last Digit**: Remove the last character from the string and convert the result to an integer.
   - **Delete Second Last Digit**: Remove the second last character from the string, combine the remaining parts, and convert the result to an integer.
3. **Finding Maximum**: Compare the three generated values and print the maximum.

This approach ensures that we efficiently consider all possible outcomes of the allowed digit deletions and select the optimal one, providing the correct solution in constant time.
