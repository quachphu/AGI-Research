To solve this problem, we need to determine the maximum possible data transfer speed that can be uniformly set for at least `k` computers out of `n` available computers, such that each of the `k` participants gets a computer with the same speed. The goal is to maximize this speed.

### Approach
1. **Sort the Data Transfer Speeds**: First, we sort the list of data transfer speeds in descending order. This allows us to easily access the largest possible values.
2. **Select the k-th Largest Element**: After sorting, the k-th largest element in the list (considering 0-based indexing) will be the maximum speed that can be uniformly set for `k` computers. This is because we can take the top `k` largest values and set each of them to the smallest value among these top `k` values, ensuring uniformity and maximizing the speed.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))
a.sort(reverse=True)
print(a[k-1])
```

### Explanation
1. **Reading Input**: The input consists of two integers `n` (number of computers) and `k` (number of participants), followed by a list of integers representing the maximum data transfer speeds of each computer.
2. **Sorting**: By sorting the list of speeds in descending order, we ensure that the first `k` elements are the largest values available.
3. **Selecting the Maximum Speed**: The k-th element in this sorted list (at index `k-1` due to 0-based indexing) is the highest speed that can be uniformly applied to `k` computers. This value is the answer because it represents the largest possible speed that can be achieved for `k` computers after potentially reducing some of their speeds.

This approach efficiently finds the solution by leveraging sorting and direct index access, ensuring an optimal time complexity of O(n log n) due to the sorting step.
