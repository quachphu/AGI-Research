To solve this problem, we need to determine the minimum number of steps required to make both the sum and the product of all elements in an array non-zero. Each step allows incrementing any element of the array by 1.

### Approach
1. **Eliminate Zeros**: First, we need to ensure that there are no zeros in the array. If any element is zero, we increment it to 1, as a zero would make the product zero. This step also counts the number of increments needed.
2. **Check Sum**: After eliminating zeros, if the sum of the array is zero, we need an additional step. We check if there exists an element that is not -1 (since incrementing -1 would make it zero, which is not allowed). If such an element exists, we increment it by 1 to make the sum non-zero.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    arr = list(map(int, input().split()))
    steps = 0
    for i in range(n):
        if arr[i] == 0:
            arr[i] += 1
            steps += 1
    current_sum = sum(arr)
    if current_sum == 0:
        has_non_neg_one = False
        for num in arr:
            if num != -1:
                has_non_neg_one = True
                break
        if has_non_neg_one:
            steps += 1
    print(steps)
```

### Explanation
1. **Eliminate Zeros**: We iterate through each element of the array. If an element is zero, we increment it by 1 and count this step.
2. **Check Sum**: After processing all zeros, we compute the sum of the array. If the sum is zero, we check if there exists an element that is not -1. If such an element exists, we increment it by 1 to ensure the sum becomes non-zero, thus adding an extra step.

This approach efficiently ensures that both the sum and product of the array are non-zero with the minimum number of steps.
