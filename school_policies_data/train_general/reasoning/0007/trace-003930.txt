To solve this problem, we need to split an array of video durations into exactly k consecutive non-empty segments (posts) such that the sum of each segment is the same. The solution must either output the sizes of these segments or determine that it's impossible.

### Approach
1. **Check Divisibility**: First, check if the total sum of the video durations is divisible by k. If not, it's impossible to split the array into k segments with equal sums, and we immediately return "No".
2. **Calculate Target Sum**: If the total sum is divisible by k, compute the target sum for each segment as the total sum divided by k.
3. **Iterate and Accumulate**: Traverse the array while accumulating the sum of elements. Each time the accumulated sum matches the target, split the array at that point, reset the accumulator, and record the segment size.
4. **Check Validity**: After processing all elements, ensure that exactly k segments were formed and that all elements were used. If both conditions are met, output the segment sizes; otherwise, output "No".

### Solution Code
```python
import sys

def main():
    n, k = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    total = sum(a)
    if total % k != 0:
        print("No")
        return
    target = total // k
    current_sum = 0
    count = 0
    splits = []
    current_group_size = 0
    for num in a:
        current_sum += num
        current_group_size += 1
        if current_sum == target:
            splits.append(current_group_size)
            count += 1
            current_sum = 0
            current_group_size = 0
        elif current_sum > target:
            print("No")
            return
    if count == k and current_sum == 0:
        print("Yes")
        print(' '.join(map(str, splits)))
    else:
        print("No")

if __name__ == "__main__":
    main()
```

### Explanation
- **Divisibility Check**: The first step ensures that the problem can only be solved if the total duration can be evenly divided into k parts.
- **Target Sum Calculation**: This gives the required sum for each segment.
- **Accumulation and Splitting**: By iterating through the array, we accumulate the sum of elements until it matches the target sum, then split the array and reset the accumulator. This ensures each segment meets the target sum.
- **Final Validation**: After processing all elements, we check if exactly k segments were formed and all elements were used. This ensures the solution is valid and complete.

This approach efficiently checks for the possibility of the solution and constructs the segments in linear time, making it suitable for large input sizes up to the problem constraints.
