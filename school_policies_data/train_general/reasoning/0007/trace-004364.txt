To solve this problem, we need to count the number of valid arithmetic substrings of a given expression that evaluate to a specified target value. The valid arithmetic expressions must conform to a specific grammar with operator precedence and parentheses.

### Approach
The approach involves using dynamic programming to track possible values of substrings that form valid arithmetic expressions. We use three dictionaries to keep track of possible values for different parts of the grammar (F, T, E) at each position in the string. Here's a detailed breakdown:

1. **F (Factor)**: Represents numbers or parenthesized expressions. For each position, if the character is a digit, it forms a factor. If it's a closing parenthesis, we check for valid expressions inside the parentheses.
2. **T (Term)**: Represents multiplication operations. A term can be a factor or a product of a previous term and a factor.
3. **E (Expression)**: Represents addition operations. An expression can be a term or the sum of a previous expression and a term.

By iterating through each character in the string and updating these dictionaries, we can efficiently track all valid substrings and their values. Finally, we count how many of these substrings evaluate to the target value.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    while n != 0:
        s = sys.stdin.readline().strip()
        count = 0

        # Initialize lists to hold dictionaries for F, T, E at each position j
        F = []
        T = []
        E = []

        for j in range(len(s)):
            current_F = {}

            # Process F for current j
            if s[j].isdigit():
                current_F[j] = int(s[j])
            elif s[j] == ')':
                # Look for E entries ending at j-1, which are inside parentheses
                if j - 1 >= 0 and j - 1 < len(E):
                    e_prev = E[j-1]
                    for start in e_prev:
                        i_candidate = start - 1
                        if i_candidate >= 0 and s[i_candidate] == '(':
                            current_F[i_candidate] = e_prev[start]

            F.append(current_F)

            # Process T for current j
            current_T = current_F.copy()
            # Check for T_prev * F_current
            for start in current_F:
                if start > 0 and s[start - 1] == '*':
                    m = start - 2  # T_prev ends at m = start-2
                    if m >= 0 and m < len(T) and T[m]:
                        t_prev = T[m]
                        for t_start in t_prev:
                            product = t_prev[t_start] * current_F[start]
                            # Update current_T with new start and product
                            if t_start in current_T:
                                # Ensure we don't overwrite with same value
                                if current_T[t_start] != product:
                                    current_T[t_start] = product  # This case shouldn't happen as per grammar
                            else:
                                current_T[t_start] = product
            T.append(current_T)

            # Process E for current j
            current_E = current_T.copy()
            # Check for E_prev + T_current
            for start in current_T:
                if start > 0 and s[start - 1] == '+':
                    m = start - 2  # E_prev ends at m = start-2
                    if m >= 0 and m < len(E) and E[m]:
                        e_prev = E[m]
                        for e_start in e_prev:
                            summation = e_prev[e_start] + current_T[start]
                            if e_start in current_E:
                                if current_E[e_start] != summation:
                                    current_E[e_start] = summation  # Again, shouldn't happen
                            else:
                                current_E[e_start] = summation
            E.append(current_E)

            # Count how many current_E entries have value n
            current_count = sum(1 for val in current_E.values() if val == n)
            count += current_count

        print(count)
        n = int(sys.stdin.readline())

if __name__ == "__main__":
    main()
```

3. **Term (T) Handling**: Track multiplication operations by combining previous terms with current factors.
4. **Expression (E) Handling**: Track addition operations by combining previous expressions with current terms.
5. **Counting Valid Substrings**: After processing each character, count how many valid substrings evaluate to the target value.

This approach efficiently tracks valid substrings and their values using dynamic programming, ensuring that we only consider valid arithmetic expressions according to the given grammar.
