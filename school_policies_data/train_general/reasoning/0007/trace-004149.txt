To solve this problem, we need to find the smallest year greater than a given year where all the digits are distinct. The solution involves checking each subsequent year starting from the given year until we find one that meets the criteria of having all unique digits.

### Approach
1. **Input Reading**: Read the input year.
2. **Iterative Check**: Starting from the next year after the given year, check each subsequent year.
3. **Distinct Digit Check**: For each year, convert it to a string and check if all characters (digits) are unique by using a set. A set automatically removes duplicates, so if the length of the set is 4, all digits are distinct.
4. **Output the Result**: Once a valid year is found, print it and exit the loop.

### Solution Code
```python
y = int(input())
while True:
    y += 1
    if len(set(str(y))) == 4:
        print(y)
        break
```

### Explanation
1. **Reading Input**: The input year is read as an integer.
2. **Increment and Check**: Starting from the next year (`y + 1`), each subsequent year is checked. The loop continues indefinitely until a valid year is found.
3. **Set for Uniqueness**: Converting the year to a string and then to a set allows us to check if all digits are unique. If the set length is 4, all digits are unique.
4. **Termination**: The loop breaks immediately upon finding the first valid year, ensuring the minimum year is found efficiently.

This approach ensures that we check each subsequent year systematically and efficiently, leveraging the properties of sets to quickly determine digit uniqueness. The solution is guaranteed to terminate due to the problem constraints ensuring a valid answer exists.
