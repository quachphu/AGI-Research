To solve this problem, we need to determine the most frequently occurring hidden message in a given string. A hidden message is defined as a subsequence whose indices form an arithmetic progression. The solution involves efficiently calculating the occurrences of such hidden messages and identifying the maximum count.

### Approach
1. **Single Character Count**: The simplest hidden messages are single characters. The maximum occurrence of any single character in the string is a candidate for the result.
2. **Character Pair Count**: For pairs of characters, we need to count how many times each character (c1) appears before another character (c2) in the string. This is done using a 2D array to track these occurrences efficiently.

The approach leverages dynamic programming to maintain counts of characters seen so far and uses these counts to compute the occurrences of pairs in linear time. The final result is the maximum value between the most frequent single character and the most frequent pair.

### Solution Code
```python
s = input().strip()

count = [0] * 26
pair_counts = [[0 for _ in range(26)] for _ in range(26)]

for c in s:
    idx = ord(c) - ord('a')
    for i in range(26):
        pair_counts[i][idx] += count[i]
    count[idx] += 1

max_single = max(count)
max_pair = max(max(row) for row in pair_counts)

print(max(max_single, max_pair))
```

### Explanation
1. **Initialization**: We initialize two arrays: `count` to keep track of the frequency of each character encountered so far, and `pair_counts` to track the occurrences of each character pair (c1, c2) where c1 appears before c2.
2. **Processing Each Character**: For each character in the string, we update the `pair_counts` array by adding the current counts of all previous characters to the corresponding entries. This step ensures that all valid pairs (c1, c2) are counted as we iterate through the string.
3. **Compute Maximums**: After processing the entire string, we determine the maximum frequency of any single character (`max_single`) and the maximum occurrence of any character pair (`max_pair`). The result is the maximum of these two values.

This approach efficiently handles the problem within O(n) time complexity for iterating through the string and O(1) space complexity for the fixed-size arrays, making it suitable for large input sizes up to 100,000 characters.
