To solve this problem, we need to determine if a given number is a V-number. A V-number is defined as a number where the sum of the digits in the upper half of the number is equal to the sum of the digits in the lower half of the number. 

### Approach
1. **Input Handling**: Read the number of test cases and the subsequent numbers.
2. **Check Even Length**: For each number, first check if it has an even number of digits. If not, it cannot be a V-number.
3. **Split and Sum**: If the number has an even number of digits, split it into two equal halves. Calculate the sum of the digits in each half.
4. **Comparison**: Compare the sums of the two halves. If they are equal, the number is a V-number; otherwise, it is not.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        s = input[i].strip()
        if len(s) % 2 != 0:
            print("NO")
            continue
        mid = len(s) // 2
        sum_upper = sum(int(c) for c in s[:mid])
        sum_lower = sum(int(c) for c in s[mid:])
        print("YES" if sum_upper == sum_lower else "NO")

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings for easier processing.
2. **Check Digit Length**: For each number, converted to a string, we check if its length is even. If not, we immediately print "NO".
3. **Splitting the Number**: If the length is even, we split the string into two halves. The midpoint is calculated as the length divided by 2.
4. **Summing Halves**: We compute the sum of the digits in the first half (upper) and the second half (lower).
5. **Result Determination**: The sums of the two halves are compared. If they are equal, "YES" is printed; otherwise, "NO" is printed.

This approach efficiently checks each number and ensures correctness by handling edge cases such as odd-length numbers and ensuring accurate summation of the digits in each half.
