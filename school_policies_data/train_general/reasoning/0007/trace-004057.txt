To solve this problem, we need to determine how many words from a given list are "bubbly." A word is considered bubbly if pairs of identical letters (A with A, B with B) can be connected with non-intersecting arches.

### Approach
1. **Check Even Counts**: Each letter (A and B) must appear an even number of times. If either letter appears an odd number of times, the word cannot be bubbly.
2. **Stack-Based Validation**: Use a stack to simulate the process of forming non-intersecting pairs. As we iterate through each character in the word:
   - If the top of the stack is the same as the current character, pop the stack (indicating a valid pair).
   - If the top of the stack is different, push the current character onto the stack.
   - If the stack is empty after processing all characters, the word is bubbly.

### Solution Code
```python
def count_bubbly():
    import sys
    input = sys.stdin.read().split()
    M = int(input[0])
    words = input[1:M+1]
    result = 0
    for word in words:
        count_a = word.count('A')
        count_b = len(word) - count_a
        if count_a % 2 != 0 or count_b % 2 != 0:
            continue
        stack = []
        for c in word:
            if stack and stack[-1] == c:
                stack.pop()
            else:
                stack.append(c)
        if not stack:
            result += 1
    print(result)

count_bubbly()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Even Count Check**: For each word, we first check if both A and B counts are even. If not, the word is immediately discarded.
3. **Stack Processing**: Using a stack, we ensure that pairs are formed in a non-intersecting manner. By popping the stack when consecutive characters are the same, we simulate the removal of valid pairs.
4. **Result Calculation**: If the stack is empty after processing all characters, it means all pairs were formed without intersections, and the word is counted as bubbly.

This approach efficiently checks each word in linear time relative to its length, ensuring the solution handles the upper constraint limits effectively.
