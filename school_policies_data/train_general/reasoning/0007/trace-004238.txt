To solve this problem, we need to determine the smallest positive integer that is not present in a given list of test indexes. This integer will be the default index for the next test to be added.

### Approach
1. **Input Reading**: Read the number of existing test indexes and the indexes themselves.
2. **Set Conversion**: Convert the list of indexes into a set for efficient lookup operations.
3. **Finding the Smallest Missing Index**: Starting from 1, check each integer sequentially to see if it is present in the set. The first integer that is not found in the set is the answer.

### Solution Code
```python
def find_smallest_missing():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    existing = set(a)
    i = 1
    while True:
        if i not in existing:
            print(i)
            return
        i += 1

find_smallest_missing()
```

### Explanation
1. **Reading Input**: The input is read in one go and split into a list of strings. The first element is the number of test indexes, and the subsequent elements are the indexes themselves.
2. **Set Conversion**: Converting the list of indexes to a set allows for O(1) average-time complexity for membership checks, which is efficient for this problem.
3. **Sequential Check**: Starting from 1, we check each integer in sequence. The first integer not found in the set is the smallest missing positive integer and is printed as the result. This ensures we find the correct default index efficiently, even for the maximum constraints.

This approach ensures that we efficiently determine the smallest missing index with a time complexity of O(n) in the worst case, where n is the maximum possible value in the list (up to 3001). This is optimal for the given problem constraints.
