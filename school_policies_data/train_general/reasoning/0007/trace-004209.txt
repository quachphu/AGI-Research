To solve this problem, we need to determine the distance each person will walk before encountering a blocked point on an infinitely long street. The challenge is to efficiently process a large number of roadworks and queries while considering the constraints.

### Approach
1. **Event Modeling**: Convert each roadwork into two events: an "add" event when the roadwork starts blocking and a "remove" event when it stops blocking. These events are processed in chronological order.
2. **Sorting Events**: Sort the events by their occurrence time. If two events occur at the same time, process "remove" events before "add" events to ensure correct state transitions.
3. **Priority Queue (Min-Heap)**: Use a min-heap to keep track of the active roadworks. This allows efficient retrieval of the smallest blocked point.
4. **Lazy Removal**: Track removed roadworks using a counter. When querying the heap, lazily remove elements that are no longer active to maintain the correct state.

### Solution Code
```python
import heapq
from collections import defaultdict

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    N, Q = int(input[ptr]), int(input[ptr+1])
    ptr += 2
    events = []
    for _ in range(N):
        S = int(input[ptr])
        T = int(input[ptr+1])
        X = int(input[ptr+2])
        ptr += 3
        event_add = 2 * S - 1 - 2 * X
        event_remove = 2 * T - 1 - 2 * X
        events.append((event_add, 1, X))
        events.append((event_remove, 0, X))
    events.sort()
    Ds = []
    for _ in range(Q):
        Ds.append(int(input[ptr]))
        ptr += 1
    current_times = [d * 2 for d in Ds]
    heap = []
    removal_counter = defaultdict(int)
    answers = []
    event_ptr = 0
    for ct in current_times:
        while event_ptr < len(events) and events[event_ptr][0] <= ct:
            time, typ, x = events[event_ptr]
            if typ == 1:
                heapq.heappush(heap, x)
            else:
                removal_counter[x] += 1
            event_ptr += 1
        while heap:
            current_x = heap[0]
            if removal_counter.get(current_x, 0) > 0:
                removal_counter[current_x] -= 1
                heapq.heappop(heap)
            else:
                break
        if heap:
            answers.append(heap[0])
        else:
            answers.append(-1)
    for ans in answers:
        print(ans)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Event Creation**: Each roadwork is converted into two events: one when it starts blocking (add) and one when it stops blocking (remove). These events are stored with their respective times.
2. **Event Processing**: Events are sorted by time, with "remove" events processed before "add" events if they occur at the same time. This ensures the correct state of active roadworks.
3. **Heap Management**: As events are processed, roadworks are added to or removed from a min-heap. The heap always contains the currently active roadworks, allowing efficient retrieval of the smallest blocked point.
4. **Lazy Removal**: A counter tracks removed roadworks. When querying the heap, inactive roadworks are lazily removed, ensuring the heap's top element is always valid.

This approach efficiently handles up to 200,000 roadworks and queries, ensuring optimal performance with sorting, heap operations, and lazy removal.
