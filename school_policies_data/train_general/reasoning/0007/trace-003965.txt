To solve this problem, we need to determine the maximum possible Manhattan distance between any two distinct points on a 2D plane. The Manhattan distance between two points (x1, y1) and (x2, y2) is defined as |x1 - x2| + |y1 - y2|. Given the constraints, an efficient approach is necessary to handle up to 200,000 points.

### Approach
The key insight is to recognize that the Manhattan distance can be transformed into expressions involving the sums and differences of the coordinates. Specifically, the Manhattan distance between two points can be expressed as the maximum of two values:
1. The difference between the maximum and minimum values of (x + y) for all points.
2. The difference between the maximum and minimum values of (x - y) for all points.

By computing these values for all points, we can efficiently determine the maximum Manhattan distance in linear time, O(N), which is optimal for the given constraints.

### Solution Code
```python
n = int(input())
max_s = -float('inf')
min_s = float('inf')
max_d = -float('inf')
min_d = float('inf')

for _ in range(n):
    x, y = map(int, input().split())
    s = x + y
    d = x - y
    if s > max_s:
        max_s = s
    if s < min_s:
        min_s = s
    if d > max_d:
        max_d = d
    if d < min_d:
        min_d = d

candidate1 = max_s - min_s
candidate2 = max_d - min_d
print(max(candidate1, candidate2))
```

### Explanation
1. **Reading Input:** The input is read, starting with the number of points, followed by the coordinates of each point.
2. **Transforming Coordinates:** For each point, compute two values: `s = x + y` and `d = x - y`.
3. **Tracking Extremes:** Track the maximum and minimum values of `s` and `d` as we iterate through each point.
4. **Calculating Candidates:** After processing all points, compute two candidates for the maximum Manhattan distance: the difference between the maximum and minimum values of `s`, and the difference between the maximum and minimum values of `d`.
5. **Result:** The result is the maximum of these two candidates, which gives the maximum possible Manhattan distance.

This approach ensures that we efficiently compute the result in linear time, making it suitable for large input sizes.
