To solve this problem, we need to determine if Kizahashi can complete all his jobs before their respective deadlines. The key insight is to schedule the jobs in an optimal order to meet all deadlines.

### Approach
1. **Sort Jobs by Deadline**: The optimal strategy is to sort the jobs based on their deadlines in ascending order. This ensures that we handle the jobs with the earliest deadlines first, minimizing the risk of missing any deadline.
2. **Check Cumulative Time**: After sorting, we process each job sequentially. For each job, we maintain a cumulative time that represents the total time spent up to that point. If at any point this cumulative time exceeds the job's deadline, we immediately determine that it's impossible to complete all jobs on time.

### Solution Code
```python
n = int(input())
jobs = []
for _ in range(n):
    a, b = map(int, input().split())
    jobs.append((b, a))

jobs.sort()

current_time = 0
for b, a in jobs:
    current_time += a
    if current_time > b:
        print("No")
        exit()
print("Yes")
```

### Explanation
1. **Reading Input**: The input is read and stored as a list of tuples where each tuple contains the deadline and the time required for each job.
2. **Sorting**: The jobs are sorted based on their deadlines. This ensures that we process the job with the earliest deadline first.
3. **Processing Jobs**: We iterate through the sorted jobs, accumulating the time taken for each job. After each job, we check if the cumulative time exceeds the job's deadline. If it does, we print "No" and exit. If all jobs are processed without exceeding any deadlines, we print "Yes".

This approach ensures that we efficiently check the feasibility of completing all jobs by leveraging sorting and a linear scan, making the solution both optimal and easy to understand. The time complexity is dominated by the sorting step, which is \(O(N \log N)\), where \(N\) is the number of jobs. This is efficient enough given the problem constraints.
