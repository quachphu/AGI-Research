To solve this problem, we need to sort an array of integers in non-descending order and print the sorted result. The input consists of the size of the array followed by the elements of the array. The output should be the sorted elements separated by spaces.

### Approach
1. **Reading Input**: The input is read as a single line of space-separated integers. The first integer represents the size of the array, and the subsequent integers are the elements of the array.
2. **Parsing Input**: Convert the input string into a list of integers. The first element of this list is the size of the array, and the rest are the elements to be sorted.
3. **Sorting**: Use Python's built-in sort function to sort the array elements in non-descending order.
4. **Output**: Print the sorted elements as a space-separated string.

### Solution Code
```python
def main():
    nums = list(map(int, input().split()))
    arr = nums[1:]
    print(*sorted(arr))

main()
```

### Explanation
1. **Reading and Parsing Input**: The input is read as a single line and split into individual string elements. These elements are then converted into integers. The first integer is the size of the array, which we can ignore since we directly use the rest of the elements as the array.
2. **Sorting**: The array elements (excluding the first element which is the size) are sorted using Python's `sorted()` function, which sorts the elements in ascending order.
3. **Printing the Result**: The sorted elements are printed using the `print(*sorted(arr))` syntax, which unpacks the sorted list into individual arguments for the `print` function. This results in the elements being printed space-separated, which meets the problem's requirements.

This approach efficiently handles the input and sorting, ensuring the solution is both correct and optimal for the given constraints.
