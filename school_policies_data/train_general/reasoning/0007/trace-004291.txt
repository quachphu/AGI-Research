To solve this problem, we need to determine the minimum number of steps an elephant needs to take to reach his friend's house located at position x on a coordinate line. The elephant can move 1, 2, 3, 4, or 5 positions forward in each step.

### Approach
The key insight is to maximize the distance covered in each step to minimize the number of steps. The optimal strategy is to use as many steps of 5 units as possible, then handle the remaining distance with one additional step if necessary. 

Mathematically, the minimum number of steps can be calculated by dividing the target position x by 5 and rounding up to the nearest integer. This can be efficiently computed using integer arithmetic as `(x + 4) // 5`, which effectively rounds up the division result without using floating-point operations.

### Solution Code
```python
x = int(input())
print((x + 4) // 5)
```

### Explanation
1. **Reading Input**: The input value x is read from standard input.
2. **Calculating Steps**: The formula `(x + 4) // 5` is used to compute the minimum number of steps. This formula works by adding 4 to x before performing integer division by 5, which ensures that any remainder results in an additional step. For example, if x is 12, `(12 + 4) // 5` equals 16 // 5 = 3, which is the correct number of steps (5 + 5 + 2).

This approach efficiently computes the result in constant time O(1), making it suitable for very large values of x up to 1,000,000.
