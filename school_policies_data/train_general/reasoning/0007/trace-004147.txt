### Approach
1. **Generate Fibonacci Numbers**: Generate all Fibonacci numbers up to \( n \). This sequence is generated starting from \( F_0 = 0 \) and \( F_1 = 1 \), with each subsequent number being the sum of the previous two.
2. **Check Triplets**: Using nested loops, check all possible combinations of three Fibonacci numbers from the generated list to see if their sum equals \( n \). The first valid triplet found is printed immediately.
3. **Edge Case Handling**: Special handling for \( n = 0 \) to directly return the triplet (0, 0, 0) as it is the only valid solution for this case.

### Solution Code
```python
def main():
    n = int(input())
    if n == 0:
        print("0 0 0")
        return
    
    fibs = [0, 1]
    while True:
        next_fib = fibs[-1] + fibs[-2]
        if next_fib > n:
            break
        fibs.append(next_fib)
    # Ensure we include all elements <=n
    fibs = [x for x in fibs if x <= n]
    
    # Check all possible triplets
    for a in fibs:
        for b in fibs:
            for c in fibs:
                if a + b + c == n:
                    print(f"{a} {b} {c}")
                    return
    
    # If no triplet found
    print("I'm too stupid to solve this problem")

main()
```
