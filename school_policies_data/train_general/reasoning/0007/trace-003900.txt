To solve this problem, we need to count the number of non-empty sets of cells in an n x m grid where all cells in a set are the same color and every two cells in the set share either the same row or column. The solution involves calculating valid sets in rows and columns separately and adjusting for overlapping counts of single-cell sets.

### Approach
1. **Row and Column Analysis**: For each row and column, count the number of cells of each color (0 and 1).
2. **Subset Calculation**: For each row and column, compute the number of non-empty subsets of cells of the same color. This is done using the formula \(2^k - 1\) for k cells of the same color.
3. **Sum Adjustment**: Sum the valid subsets from rows and columns. Subtract the total number of cells to avoid double-counting single-cell subsets.

### Solution Code
```python
n, m = map(int, input().split())
grid = [list(map(int, input().split())) for _ in range(n)]

sum_rows = 0
for row in grid:
    count0 = row.count(0)
    count1 = m - count0
    sum_rows += (2 ** count0 - 1) if count0 > 0 else 0
    sum_rows += (2 ** count1 - 1) if count1 > 0 else 0

sum_cols = 0
for j in range(m):
    count0 = 0
    count1 = 0
    for i in range(n):
        if grid[i][j] == 0:
            count0 += 1
        else:
            count1 += 1
    sum_cols += (2 ** count0 - 1) if count0 > 0 else 0
    sum_cols += (2 ** count1 - 1) if count1 > 0 else 0

total = sum_rows + sum_cols - n * m
print(total)
```

### Explanation
1. **Reading Input**: The grid dimensions and cell values are read from standard input.
2. **Row Contribution Calculation**: For each row, the number of white (0) and black (1) cells are counted. The number of non-empty subsets for each color is calculated using \(2^k - 1\), where k is the count of cells of that color.
3. **Column Contribution Calculation**: Similar to rows, each column is analyzed to count cells of each color and compute the valid subsets.
4. **Adjustment for Overlaps**: The total number of single-cell subsets (which are counted in both rows and columns) is subtracted to avoid double-counting. This adjustment is done by subtracting \(n \times m\) from the sum of row and column contributions.

This approach efficiently computes the required sets by leveraging mathematical properties of subsets and ensures accurate results by adjusting for overlaps.
