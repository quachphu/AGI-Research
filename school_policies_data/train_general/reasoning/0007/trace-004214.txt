To solve this problem, we need to determine how many combinations of a given integer \( n \) can be represented as the sum of two prime numbers, following Goldbach's conjecture. The solution must handle both even and odd integers efficiently, even for large values up to 50,000.

### Approach
1. **Prime Number Generation**: Use the Sieve of Eratosthenes to generate all prime numbers up to 50,000. This allows quick prime checks.
2. **Precompute Goldbach Counts**: For even numbers, precompute the number of valid prime pairs that sum to each even number up to 50,000. This is done using pairs of odd primes and handling the special case of 4 (2+2) separately.
3. **Handle Odd Numbers**: For odd numbers, check if \( n-2 \) is a prime (since 2 is the only even prime, the other number must be \( n-2 \) and prime).

### Solution Code
```python
def sieve_eratosthenes(max_limit):
    sieve = [True] * (max_limit + 1)
    sieve[0] = sieve[1] = False
    for i in range(2, int(max_limit ** 0.5) + 1):
        if sieve[i]:
            sieve[i*i : max_limit+1 : i] = [False] * len(sieve[i*i : max_limit+1 : i])
    return sieve

def main():
    import bisect
    max_limit = 50000
    sieve = sieve_eratosthenes(max_limit)
    primes_list = [i for i, is_prime in enumerate(sieve) if is_prime]
    
    # Initialize Goldbach counts
    goldbach = [0] * (max_limit + 1)
    goldbach[4] = 1  # Handle the case 2 + 2 = 4
    
    primes_odd = primes_list[1:]  # Exclude 2
    
    # Precompute Goldbach counts for even numbers
    for i in range(len(primes_odd)):
        p = primes_odd[i]
        max_q = max_limit - p
        j_max = bisect.bisect_right(primes_odd, max_q) - 1
        if j_max < i:
            continue
        for j in range(i, j_max + 1):
            q = primes_odd[j]
            s = p + q
            goldbach[s] += 1
    
    # Process input
    import sys
    for line in sys.stdin:
        n = int(line.strip())
        if n == 0:
            break
        if n < 4 or n > 50000:
            print(0)
        elif n % 2 == 0:
            print(goldbach[n])
        else:
            if (n - 2) >= 2 and sieve[n - 2]:
                print(1)
            else:
                print(0)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prime Generation**: The Sieve of Eratosthenes efficiently generates all primes up to 50,000. This allows O(1) prime checks.
2. **Goldbach Precomputation**: For each even number, we precompute the count of prime pairs (p, q) such that \( p + q = n \). This is done by iterating over pairs of odd primes and using binary search to limit the range of valid primes.
3. **Efficiency**: Precomputing the counts for even numbers ensures that each query is answered in O(1) time. For odd numbers, we check if \( n-2 \) is prime, which is an O(1) operation using the sieve.

This approach ensures that the solution handles up to 10,000 queries efficiently, even for large values of \( n \).
