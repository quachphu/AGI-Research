To solve this problem, we need to determine the k-th positive number whose digital root is x for multiple test cases. The digital root of a number can be computed using a mathematical formula, which allows us to derive a direct solution without iterating through numbers.

### Approach
The digital root of a number n can be computed as `1 + (n - 1) % 9`. For a given digital root x, the numbers that have this digital root form a sequence where each number is 9 units apart. Specifically, the sequence starts at x and increments by 9 for each subsequent number. Therefore, the k-th number in this sequence can be calculated using the formula:
- For any x (1 to 9), the k-th number is given by `x + 9 * (k - 1)`.

This formula works because each subsequent number in the sequence is 9 units apart, starting from x. For example, if x is 5 and k is 1, the result is 5. For k=2, the result is 14, and so on.

### Solution Code
```python
n = int(input())
for _ in range(n):
    k, x = map(int, input().split())
    print(x + 9 * (k - 1))
```

### Explanation
1. **Reading Input**: The first line contains the number of test cases, n. Each subsequent line contains two integers, k (the position in the sequence) and x (the desired digital root).
2. **Formula Application**: For each test case, we compute the k-th number in the sequence using the formula `x + 9 * (k - 1)`. This formula directly gives the k-th number with the desired digital root by leveraging the arithmetic progression formed by the sequence of numbers with the same digital root.
3. **Output**: The result for each test case is printed immediately after computation.

This approach ensures that the solution is efficient and handles the upper constraint of k up to 10^12 without any performance issues, as it operates in constant time for each test case.
