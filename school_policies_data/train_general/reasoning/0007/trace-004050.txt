To solve this problem, we need to decrypt an 80-character binary string into an 8-digit password. Each digit of the password is represented by a unique 10-character binary code provided in the input.

### Approach
1. **Read Input:** The first line is the encrypted binary password. The next 10 lines are the binary codes corresponding to digits 0 through 9.
2. **Create Mapping:** Construct a dictionary that maps each 10-character binary code to its corresponding digit (0-9).
3. **Decrypt Password:** Split the 80-character binary string into 8 segments of 10 characters each. For each segment, look up the corresponding digit using the mapping and concatenate these digits to form the password.

### Solution Code
```python
def main():
    encrypted = input().strip()
    mappings = {}
    for i in range(10):
        code = input().strip()
        mappings[code] = str(i)
    password = []
    for i in range(8):
        start = i * 10
        chunk = encrypted[start:start+10]
        password.append(mappings[chunk])
    print(''.join(password))

main()
```

### Explanation
1. **Reading Input:** The first line is read as the encrypted binary string. The next 10 lines are read into a dictionary where each key is a binary string and the value is the corresponding digit (0-9).
2. **Mapping Creation:** The dictionary `mappings` is built by iterating over the 10 input lines, assigning each line to its respective digit based on its position (0 for the first line, 1 for the second, etc.).
3. **Decrypting the Password:** The encrypted binary string is divided into 8 segments of 10 characters each. Each segment is looked up in the dictionary to find the corresponding digit, which is then concatenated to form the final password.

This approach ensures that each part of the binary string is correctly mapped to its digit, efficiently reconstructing the original password.
