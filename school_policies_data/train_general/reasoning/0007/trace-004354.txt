To solve this problem, we need to generate the Fibonacci sequence up to the nth term, where each term is printed on a new line. The Fibonacci sequence starts with two 1s, and each subsequent term is the sum of the two preceding terms.

### Approach
1. **Input Handling**: Read an integer `n` from standard input, which represents the number of terms in the Fibonacci sequence to generate.
2. **Initial Terms**: The first two terms of the sequence are both 1. If `n` is 1, we print the first term. If `n` is 2, we print both initial terms.
3. **Subsequent Terms**: For `n` greater than 2, we start from the third term and compute each subsequent term by summing the previous two terms. Each term is printed immediately after computation to save memory.

### Solution Code
```python
def fibonacci():
    n = int(input())
    a, b = 1, 1
    if n >= 1:
        print(a)
    if n >= 2:
        print(b)
    for i in range(3, n + 1):
        c = a + b
        print(c)
        a, b = b, c

fibonacci()
```

### Explanation
1. **Reading Input**: The input integer `n` is read using `input()` and converted to an integer.
2. **Handling Initial Terms**: The first two terms (both 1) are printed directly if `n` is 1 or 2. This handles the base cases of the Fibonacci sequence.
3. **Generating Subsequent Terms**: For `n` greater than 2, we use a loop starting from the third term. In each iteration, the next term is computed as the sum of the previous two terms. After printing the new term, we update the variables to shift the window of the last two terms forward.
4. **Efficiency**: This approach efficiently uses variables to keep track of the last two terms, avoiding the need to store the entire sequence in memory, which is optimal for large values of `n`.

This method ensures that each term is computed in constant time and printed immediately, making the solution both time and space efficient.
