To solve this problem, we need to find two distinct integer points such that one point lies within the first segment and the other lies within the second segment. The solution must handle multiple queries efficiently.

### Approach
The key insight is to leverage the endpoints of the segments to quickly determine valid points. Here's the step-by-step approach:

1. **Check Left Endpoints**: If the left endpoints of the two segments are different, we can directly use these endpoints as our two points since they are guaranteed to be different.
2. **Use Right Endpoint of Second Segment**: If the left endpoints are the same, we use the left endpoint of the first segment and the right endpoint of the second segment. Since the segments are valid (i.e., their right endpoints are strictly greater than their left endpoints), these points will always be different.

This approach ensures that we can determine valid points in constant time for each query, making the solution efficient and straightforward.

### Solution Code
```python
import sys

q = int(sys.stdin.readline())
for _ in range(q):
    l1, r1, l2, r2 = map(int, sys.stdin.readline().split())
    if l1 != l2:
        a, b = l1, l2
    else:
        a, b = l1, r2
    print(a, b)
```

### Explanation
1. **Reading Input**: The input is read from standard input, starting with the number of queries.
2. **Processing Each Query**: For each query, the endpoints of the two segments are read.
3. **Determine Points**:
   - If the left endpoints of the two segments are different, use these left endpoints directly.
   - If the left endpoints are the same, use the left endpoint of the first segment and the right endpoint of the second segment, ensuring they are different.

This approach efficiently handles all possible segment configurations (disjoint, overlapping, or nested) and guarantees valid points by construction. The solution runs in O(1) time per query, making it highly efficient even for the upper constraint of 500 queries.
