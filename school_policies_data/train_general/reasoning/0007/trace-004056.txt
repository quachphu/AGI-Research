To solve this problem, we need to determine the highest points earned by any team during the league stage of the World Cup based on their match results. Each team earns points from wins, ties, and losses, and we need to compute the maximum points among all teams.

### Approach
1. **Input Reading**: Read the number of teams, followed by the match results (wins, ties, losses) for each team.
2. **Points Calculation**: For each team, calculate their total points using the formula: \(3 \times \text{wins} + 1 \times \text{ties} - 1 \times \text{losses}\).
3. **Track Maximum Points**: Keep track of the highest points encountered while iterating through each team's results.
4. **Output the Result**: After processing all teams, print the highest points.

### Solution Code
```python
def main():
    import sys
    n = int(sys.stdin.readline())
    max_points = -float('inf')
    for _ in range(n):
        w, t, l = map(int, sys.stdin.readline().split())
        current = 3 * w + t - l
        if current > max_points:
            max_points = current
    print(max_points)

main()
```

### Explanation
1. **Reading Input**: The first line of input is the number of teams. Subsequent lines contain three integers each, representing wins, ties, and losses for each team.
2. **Calculating Points**: For each team, the points are calculated using the formula provided. This formula accounts for 3 points per win, 1 point per tie, and -1 point per loss.
3. **Tracking Maximum**: As we process each team's results, we compare their calculated points with the current maximum and update the maximum if the current team's points are higher.
4. **Output**: After all teams have been processed, the highest points value is printed.

This approach efficiently processes each team's results in linear time, making it suitable for the given constraints. The solution ensures that we handle all edge cases, including teams with negative points, by initializing the maximum points to negative infinity.
