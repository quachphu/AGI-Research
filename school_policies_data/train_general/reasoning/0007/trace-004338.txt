To solve this problem, we need to determine the number of soda bottles that cannot be opened using any other bottle in the collection. Each bottle can be used to open other bottles of a specific brand, even if it is closed. The key insight is that a bottle can only be opened if there exists another bottle (different from itself) that can open it.

### Approach
1. **Input Reading**: Read the number of bottles and their respective brands (a_i) and the brands they can open (b_i).
2. **Check Openability**: For each bottle, check if there exists another bottle (different from the current one) that can open it. This is determined by checking if another bottle's b value matches the current bottle's a value.
3. **Count Unopenable Bottles**: Count how many bottles do not have any other bottle that can open them.

### Solution Code
```python
n = int(input())
bottles = [tuple(map(int, input().split())) for _ in range(n)]

count = 0
for i in range(n):
    ai, bi = bottles[i]
    found = False
    for j in range(n):
        if i != j and bottles[j][1] == ai:
            found = True
            break
    if not found:
        count += 1
print(count)
```

### Explanation
1. **Reading Input**: The input is read and stored in a list of tuples where each tuple represents a bottle's brand and the brand it can open.
2. **Check Each Bottle**: For each bottle, iterate through all other bottles to see if there exists one that can open it. This is checked by comparing the current bottle's a value with other bottles' b values.
3. **Count Unopenable Bottles**: If no other bottle can open the current bottle, increment the count of unopenable bottles.
4. **Output Result**: The count of unopenable bottles is printed.

This approach efficiently checks each bottle against all others to determine if it can be opened, resulting in a time complexity of O(n^2), which is feasible given the constraint n ≤ 100.
