To solve this problem, we need to minimize the number of operations required to ensure that any two neighboring boxes contain at most `x` candies in total. The operations allowed are eating one candy from a chosen box any number of times.

### Approach
1. **Left to Right Pass**: Adjust each box starting from the first to the last. For each box, ensure that the sum of the current box and the previous box does not exceed `x`. If it does, reduce the current box's candies to the maximum possible value that keeps the sum within the limit.
2. **Right to Left Pass**: Adjust each box starting from the last to the first. This ensures that after the left to right pass, the sum of each box with its next neighbor is also within the limit. This step further reduces the candies in the current box if necessary.

By performing these two passes, we ensure that all neighboring pairs of boxes meet the constraint, and the total number of operations (candies eaten) is minimized.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    x = int(input[1])
    a = list(map(int, input[2:2+N]))
    
    new_a = a.copy()
    
    # Left to right pass
    for i in range(1, N):
        prev = new_a[i-1]
        max_allowed = max(0, x - prev)
        new_a[i] = min(a[i], max_allowed)
    
    # Right to left pass
    for i in range(N-2, -1, -1):
        next_val = new_a[i+1]
        max_allowed = max(0, x - next_val)
        new_a[i] = min(new_a[i], max_allowed)
    
    total = sum(orig - new for orig, new in zip(a, new_a))
    print(total)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input, parsed into the number of boxes `N`, the maximum allowed sum `x`, and the list of candies in each box `a`.
2. **Left to Right Pass**: For each box starting from the second one, adjust the number of candies to ensure that the sum with the previous box does not exceed `x`. This is done by reducing the current box's candies to the maximum allowed value, which is `max(0, x - previous box's candies)`.
3. **Right to Left Pass**: For each box starting from the second last one, adjust the number of candies again to ensure that the sum with the next box does not exceed `x`. This step ensures that any adjustments made in the left to right pass are further refined to meet the constraints from both directions.
4. **Calculate Operations**: The total number of operations is the sum of the differences between the original and adjusted values of each box, which gives the minimum number of candies eaten to meet the constraints.

This approach efficiently ensures that all neighboring pairs meet the constraint with a time complexity of O(N), making it suitable for large inputs up to the given constraints.
