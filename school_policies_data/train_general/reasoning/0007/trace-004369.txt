To solve this problem, we need to efficiently manage multiple priority queues (max-heaps) and perform insert, get maximum, and delete maximum operations on them. The challenge is to handle up to 200,000 operations efficiently using appropriate data structures.

### Approach
1. **Data Structure Selection**: Use a list of min-heaps (from Python's `heapq` module) to simulate max-heaps. This is achieved by storing negative values in the min-heap, which allows us to efficiently retrieve and remove the maximum value.
2. **Operations Handling**:
   - **Insert**: Insert the negative of the value into the appropriate heap to maintain the max-heap property.
   - **Get Maximum**: Check if the heap is non-empty and return the maximum value by negating the smallest element in the min-heap.
   - **Delete Maximum**: Remove the smallest element from the min-heap (which corresponds to the maximum value in the original data) if the heap is non-empty.

### Solution Code
```python
import sys
import heapq

def main():
    n, q = map(int, sys.stdin.readline().split())
    queues = [[] for _ in range(n)]
    
    for _ in range(q):
        parts = sys.stdin.readline().split()
        if not parts:
            continue
        if parts[0] == '0':
            t = int(parts[1])
            x = int(parts[2])
            heapq.heappush(queues[t], -x)
        elif parts[0] == '1':
            t = int(parts[1])
            if queues[t]:
                print(-queues[t][0])
        elif parts[0] == '2':
            t = int(parts[1])
            if queues[t]:
                heapq.heappop(queues[t])

if __name__ == "__main__":
    main()
```

### Explanation
- **Initialization**: We initialize `n` empty heaps (lists) to represent each priority queue.
- **Insert Operation**: Convert the value to its negative and push it into the corresponding heap using `heapq.heappush`.
- **Get Maximum Operation**: If the heap is non-empty, the maximum value is the negative of the smallest element in the min-heap (accessed via the first element).
- **Delete Maximum Operation**: If the heap is non-empty, remove the smallest element (which is the negative of the maximum value) using `heapq.heappop`.

This approach ensures that each operation (insert, get maximum, delete maximum) is handled in logarithmic time relative to the size of the heap, making the solution efficient even for the upper constraint limits.
