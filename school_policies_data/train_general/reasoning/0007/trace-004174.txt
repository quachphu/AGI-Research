To solve this problem, we need to count the number of valid seating arrangements for ambassadors from two countries around a round table such that no more than `k` ambassadors from the same country sit consecutively. Rotations of the same arrangement are considered identical.

### Approach
1. **Dynamic Programming (DP) for Linear Arrangements**: We first compute the number of valid linear arrangements using a DP approach. This DP tracks the number of ways to arrange `n` seats where each run of the same country does not exceed `k`.

2. **Adjust for Circular Constraints**: After computing the valid linear arrangements, we adjust for circular constraints by considering the first and last runs in the linear arrangement. If the first and last runs are of the same country, their combined length must not exceed `k`.

3. **Special Case for Monochromatic Arrangements**: If all ambassadors are from the same country and `k >= n`, these arrangements are valid and counted separately.

MOD = 1000003

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    while True:
        n = int(input[idx])
        k = int(input[idx + 1])
        idx += 2
        if n == 0 and k == 0:
            break
        if n == 0:
            print(0)
            continue
        
        # Compute F_linear: number of valid linear arrangements
        # dp[i][c][l] = number of ways to arrange i seats, ending with country c (0 or 1), with current run length l
        dp = [[[0] * (k + 2) for _ in range(2)] for __ in range(n + 1)]
        dp[1][0][1] = 1
        dp[1][1][1] = 1
        
        for i in range(2, n + 1):
            for c in [0, 1]:
                for l in range(1, k + 1):
                    if dp[i-1][c][l] == 0:
                        continue
                    # Add same country
                    if l + 1 <= k:
                        dp[i][c][l + 1] = (dp[i][c][l + 1] + dp[i-1][c][l]) % MOD
                    # Add other country
                    other = 1 - c
                    dp[i][other][1] = (dp[i][other][1] + dp[i-1][c][l]) % MOD
        
        F_linear = 0
        for c in [0, 1]:
            for l in range(1, k + 1):
                F_linear = (F_linear + dp[n][c][l]) % MOD
        
        # Compute S: number of valid linear arrangements where first and last runs are the same country, and sum of their lengths exceeds k
        # To compute S, need to track the first run's length and last run's length
        # This requires a more detailed DP
        # We'll use a helper function to compute the middle part
        def compute_f(m, start_c, end_c):
            if m == 0:
                return 1 if start_c == end_c else 0
            dp_f = [[[0] * (k + 2) for _ in range(2)] for __ in range(m + 1)]
            if start_c == end_c and m == 0:
                return 1
            if start_c != end_c and m == 0:
                return 0
            # Initialize
            dp_f[1][start_c][1] = 1
            for i in range(2, m + 1):
                for curr_c in [0, 1]:
                    for curr_l in range(1, k + 1):

                            continue

                        if curr_l + 1 <= k:
                            dp_f[i][curr_c][curr_l + 1] = (dp_f[i][curr_c][curr_l + 1] + dp_f[i-1][curr_c][curr_l]) % MOD
                        # Add other country
                        other = 1 - curr_c
                        dp_f[i][other][1] = (dp_f[i][other][1] + dp_f[i-1][curr_c][curr_l]) % MOD
            total = 0
            for l in range(1, k + 1):
                total = (total + dp_f[m][end_c][l]) % MOD
            return total
        
        S = 0
        for c in [0, 1]:
            for l1 in range(1, k + 1):

        case2 = (numerator * inv_denominator) % MOD
        
        total = (case1 + case2) % MOD
