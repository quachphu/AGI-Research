To solve this problem, we need to count the occurrences of a specific word (case-insensitive) within a given text. The text is provided line by line, and the end of the text is marked by the line "END_OF_TEXT". 

### Approach
1. **Reading Input**: The first input line is the target word (W), which we convert to lowercase to ensure case-insensitive comparison.
2. **Processing Text**: Subsequent lines are read until the line "END_OF_TEXT" is encountered. Each line is split into individual words, and each word is converted to lowercase to compare with the target word.
3. **Counting Matches**: For each word in the text, if it matches the target word (case-insensitively), we increment our count.
4. **Output Result**: After processing all lines, the count of matches is printed.

### Solution Code
```python
w = input().strip().lower()
count = 0
while True:
    line = input().strip()
    if line == "END_OF_TEXT":
        break
    words = line.split()
    for word in words:
        if word.lower() == w:
            count += 1
print(count)
```

### Explanation
1. **Reading the Target Word**: The first line is read and converted to lowercase to handle case insensitivity.
2. **Loop Through Lines**: We continuously read lines from the input. Each line is stripped of leading/trailing whitespace to accurately detect the "END_OF_TEXT" marker.
3. **Splitting Lines into Words**: Each line (except the termination line) is split into words using the default `split()` method, which handles any whitespace.
4. **Case-Insensitive Comparison**: Each word from the text is converted to lowercase and compared with the target word. If they match, the count is incremented.
5. **Termination and Output**: The loop terminates when "END_OF_TEXT" is encountered, and the total count of matches is printed.

This approach ensures that we efficiently count case-insensitive matches of the target word within the given text, adhering to the constraints and requirements specified.
