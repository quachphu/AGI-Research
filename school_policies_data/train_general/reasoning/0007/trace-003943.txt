To solve this problem, we need to determine the optimal sequence of moves for Homer and Marge such that their combined total prize is maximized. Each player takes exactly `n` turns, and the goal is to distribute the digits of the given number `A` to maximize the sum of their respective numbers.

### Approach
The problem can be efficiently solved using dynamic programming (DP) with memoization. The key idea is to explore all possible sequences of moves (H for Homer and M for Marge) while keeping track of the maximum possible sum that can be achieved from each state. The state is defined by the current position in the string and the number of moves Homer has made so far. By recursively evaluating each possible move and memoizing the results, we can efficiently determine the optimal sequence of moves.

### Solution Code
```python
import sys
from functools import lru_cache

def main():
    n = int(sys.stdin.readline())
    a = sys.stdin.readline().strip()
    digits = [int(c) for c in a]
    length = 2 * n

    @lru_cache(maxsize=None)
    def dp(pos, h_used):
        if pos == length:
            if h_used == n and (length - h_used) == n:
                return (0, "")
            else:
                return (-1, "")  # Invalid state
        
        max_sum = -1
        best_path = ""

        # Try choosing H
        if h_used < n:
            contribution = digits[pos] * (10 ** (n - 1 - h_used))
            sum_h, path_h = dp(pos + 1, h_used + 1)
            if sum_h != -1:
                total = contribution + sum_h
                if total > max_sum or (total == max_sum and best_path > ('H' + path_h)):
                    max_sum = total
                    best_path = 'H' + path_h

        # Try choosing M
        m_used = pos - h_used
        if m_used < n:
            contribution = digits[pos] * (10 ** (n - 1 - m_used))
            sum_m, path_m = dp(pos + 1, h_used)
            if sum_m != -1:
                total = contribution + sum_m
                if total > max_sum or (total == max_sum and best_path > ('M' + path_m)):
                    max_sum = total
                    best_path = 'M' + path_m

        return (max_sum, best_path) if max_sum != -1 else (-1, "")

    _, path = dp(0, 0)
    print(path)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The input consists of an integer `n` and a string `A` of length `2n`. The digits of `A` are converted into a list of integers for easier manipulation.
2. **Dynamic Programming with Memoization:** The `dp` function is defined to compute the maximum sum and optimal path starting from a given position `pos` with `h_used` moves by Homer. The function uses memoization to store results of previously computed states for efficiency.
3. **Base Case:** When `pos` reaches `2n`, we check if both players have taken exactly `n` moves. If so, return a sum of 0 and an empty path; otherwise, return an invalid state.
4. **Recursive Case:** For each state, we consider two possible moves:
   - **Choosing Homer (H):** Calculate the contribution of the current digit to Homer's number and recursively compute the result for the next state.
   - **Choosing Marge (M):** Similarly, calculate the contribution for Marge's number and compute the next state.
5. **Comparison and Path Selection:** For each move, if the resulting sum is greater than the current maximum, update the maximum sum and path. In case of ties, the lexicographically smaller path (earlier occurrence of 'H') is chosen to ensure consistency.

This approach ensures that we explore all possible sequences of moves efficiently using memoization, leading to an optimal solution in polynomial time.
