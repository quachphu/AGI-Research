To solve this problem, we need to determine if a string constructed by sequentially adding parentheses is well-balanced. A well-balanced string of parentheses is defined as one where every opening parenthesis has a corresponding closing parenthesis in the correct order, and at no point do the closing parentheses exceed the number of opening ones.

### Approach
1. **Track Balance**: As we process each operation, we maintain a balance counter. Each opening parenthesis `(` increases the balance, while each closing parenthesis `)` decreases it.
2. **Check Minimum Balance**: For each operation, we also track the minimum balance encountered. If at any point the balance becomes negative, the string is immediately invalid.
3. **Early Termination**: If during processing any operation the balance becomes negative, we can immediately conclude the string is not balanced and terminate early.
4. **Final Check**: After processing all operations, the final balance must be zero, and the minimum balance encountered during processing must be non-negative.

### Solution Code
```python
def check_balanced():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    balance = 0
    min_balance = 0
    for _ in range(n):
        p = input[idx]
        x = int(input[idx + 1])
        idx += 2
        if p == '(':
            new_balance = balance + x
            step_min = balance
        else:
            new_balance = balance - x
            step_min = new_balance
        new_min = min(min_balance, step_min)
        if new_min < 0:
            print("NO")
            return
        balance = new_balance
        min_balance = new_min
    print("YES" if balance == 0 and min_balance >= 0 else "NO")

check_balanced()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into tokens for efficient processing.
2. **Balance Tracking**: For each operation, we update the balance based on whether we are adding opening or closing parentheses.
3. **Minimum Balance Check**: During each operation, we compute the minimum balance encountered. If this value becomes negative at any point, we print "NO" and exit immediately.
4. **Final Validation**: After processing all operations, we check if the final balance is zero and the minimum balance encountered is non-negative. If both conditions are met, the string is balanced, and we print "YES"; otherwise, we print "NO".

This approach ensures that we efficiently check the balance without constructing the entire string, which is crucial given the constraints on input size.
