To solve this problem, we need to efficiently assign taxis to users based on their request times and travel durations. The goal is to determine which taxi each user gets or if their request is rejected when all taxis are busy.

### Approach
1. **Input Reading and Sorting**: Read the number of users (N) and taxis (M). Then, read each user's request time and travel duration. Store each user's data along with their original index to maintain the order of results as per the input.
2. **Sort Users**: Sort the users based on their request times to process them in chronological order.
3. **Taxi Availability Tracking**: Maintain an array to track the next available time for each taxi, initialized to zero (all taxis start as available).
4. **Processing Each User**: For each user in the sorted list, check each taxi in order (from 1 to M) to find the first available taxi. Assign the taxi if available and update its next available time. If no taxi is available, mark the user's request as rejected.
5. **Result Compilation**: Store the result for each user in the original input order and print the results.

### Solution Code
```python
import sys

def main():
    n, m = map(int, sys.stdin.readline().split())
    users = []
    for idx in range(n):
        s, j = map(int, sys.stdin.readline().split())
        users.append((s, j, idx))
    
    # Sort users by their request time
    users.sort()
    
    taxis = [0] * m  # Track the next available time for each taxi
    result = [-1] * n  # Initialize result list with -1
    
    for s, j, original_idx in users:
        assigned = -1
        for taxi_idx in range(m):
            if taxis[taxi_idx] <= s:
                taxis[taxi_idx] = s + j
                assigned = taxi_idx + 1  # Convert to 1-based index
                break
        result[original_idx] = assigned
    
    # Print the results in the original order
    print(' '.join(map(str, result)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline` for efficiency, especially given the constraints. Each user's request time and travel duration are stored along with their original index.
2. **Sorting**: Users are sorted by their request time to ensure we process each request in chronological order.
3. **Taxi Assignment**: For each user, check each taxi's availability starting from the lowest index. The first available taxi is assigned, and its next available time is updated. If no taxi is available, the user's request is marked as rejected.
4. **Result Handling**: The results are stored in the order of the original input using the stored indices and printed at the end.

This approach efficiently handles up to 100,000 users and 100 taxis by leveraging a linear check through the taxis for each user, ensuring optimal performance within the problem constraints.
