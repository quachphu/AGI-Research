To solve this problem, we need to calculate the total Manhattan distance between all pairs of cities efficiently. Given the constraints, a brute-force approach is infeasible, so we use a more optimized method based on sorting and prefix sums.

### Approach
1. **Separate Coordinates**: Split the input coordinates into two separate lists for x and y coordinates.
2. **Sort Coordinates**: Sort both lists of coordinates individually. Sorting helps in efficiently calculating the sum of absolute differences using prefix sums.
3. **Prefix Sum Calculation**: Compute prefix sums for both sorted lists. The prefix sum array helps in quickly calculating the sum of elements up to any given index.
4. **Sum of Absolute Differences**: For each element in the sorted list, compute its contribution to the total sum of absolute differences using the formula `element * index - prefix_sum[index]`. This formula leverages the sorted order to efficiently compute the sum of differences between the current element and all previous elements.
5. **Modulo Operation**: Since the result can be very large, take the result modulo \(10^9 + 7\).

### Solution Code
```python
MOD = 10**9 + 7

n = int(input())
x_coords = []
y_coords = []
for _ in range(n):
    x, y = map(int, input().split())
    x_coords.append(x)
    y_coords.append(y)

def calculate_sum(sorted_coords):
    prefix = [0]
    current = 0
    for num in sorted_coords:
        current += num
        prefix.append(current)
    total = 0
    for i in range(len(sorted_coords)):
        total += sorted_coords[i] * i - prefix[i]
    return total

sorted_x = sorted(x_coords)
sorted_y = sorted(y_coords)

sum_x = calculate_sum(sorted_x)
sum_y = calculate_sum(sorted_y)

total = (sum_x + sum_y) % MOD
print(total)
```

### Explanation
1. **Reading Input**: The input is read and coordinates are split into x and y lists.
2. **Sorting**: The x and y coordinate lists are sorted to facilitate the efficient calculation of absolute differences.
3. **Prefix Sum Calculation**: A prefix sum array is built for each sorted list. This array helps in quickly accessing the sum of all elements up to any given index.
4. **Sum Calculation**: For each element in the sorted list, compute the contribution to the total sum using the formula `element * index - prefix_sum[index]`. This effectively calculates the sum of differences between the current element and all previous elements.
5. **Modulo Operation**: The final result is taken modulo \(10^9 + 7\) to handle large numbers, as required by the problem constraints.

This approach ensures that we efficiently compute the total Manhattan distance in \(O(N \log N)\) time due to sorting, making it suitable for large input sizes up to 200,000.
