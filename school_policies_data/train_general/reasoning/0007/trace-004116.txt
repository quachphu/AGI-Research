To solve this problem, we need to efficiently handle two types of queries on an array: point updates and range sum queries. Given the constraints of up to 500,000 elements and 500,000 queries, a naive approach would be too slow. Instead, we use a Fenwick Tree (Binary Indexed Tree) to achieve efficient point updates and range sum queries in logarithmic time.

### Approach
1. **Data Structure Selection**: A Fenwick Tree (Binary Indexed Tree) is chosen due to its efficiency in handling both point updates and prefix sum queries in O(log N) time, which is crucial given the problem constraints.
2. **Initialization**: Convert the 0-based array indices to 1-based for the Fenwick Tree. Initialize the tree with the given array elements.
3. **Query Handling**:
   - **Update Query (0 p x)**: Update the Fenwick Tree at position p+1 (converted to 1-based) by adding x.
   - **Range Sum Query (1 l r)**: Compute the sum from index l to r-1 (0-based) using the Fenwick Tree's prefix sums. This is done by querying the prefix sum up to r (1-based) and subtracting the prefix sum up to l (1-based).

### Solution Code
```python
import sys

class FenwickTree:
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (self.n + 1)  # 1-based indexing
    
    def update(self, idx, delta):
        while idx <= self.n:
            self.tree[idx] += delta
            idx += idx & -idx
    
    def query(self, idx):
        res = 0
        while idx > 0:
            res += self.tree[idx]
            idx -= idx & -idx
        return res

def main():
    data = list(map(int, sys.stdin.read().split()))
    ptr = 0
    N = data[ptr]
    ptr += 1
    Q = data[ptr]
    ptr += 1
    a = data[ptr:ptr+N]
    ptr += N
    
    ft = FenwickTree(N)
    for i in range(N):
        ft.update(i + 1, a[i])
    
    output = []
    for _ in range(Q):
        cmd = data[ptr]
        ptr += 1
        if cmd == 0:
            p = data[ptr]
            ptr += 1
            x = data[ptr]
            ptr += 1
            ft.update(p + 1, x)
        else:
            l = data[ptr]
            ptr += 1
            r = data[ptr]
            ptr += 1
            sum_r = ft.query(r)
            sum_l = ft.query(l)
            output.append(str(sum_r - sum_l))
    
    print('\n'.join(output))

if __name__ == "__main__":
    main()
```

### Explanation
- **Fenwick Tree Initialization**: The tree is initialized with a size equal to the array length. Each element of the array is added to the corresponding 1-based index in the tree.
- **Update Operation**: When an element at index `p` (0-based) is updated, the Fenwick Tree is updated at index `p+1` (1-based).
- **Range Sum Query**: The sum from index `l` to `r-1` (0-based) is computed by querying the prefix sum up to `r` (1-based) and subtracting the prefix sum up to `l` (1-based).

This approach ensures that both update and query operations are handled efficiently in O(log N) time, making the solution suitable for large input sizes as specified in the problem constraints.
