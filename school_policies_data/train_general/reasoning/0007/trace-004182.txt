To solve this problem, we need to determine which player will win a game where two players take turns removing consecutive equal characters from a string. The player who cannot make a move loses. Both players play optimally.

### Approach
The key insight is that each move removes a pair of consecutive equal characters. The outcome of the game depends on the number of such pairs that can be removed, and specifically, whether this number is odd or even. If the number of pairs is odd, the first player wins; if even, the second player wins.

We can efficiently determine the number of removable pairs using a stack-based approach:
1. Traverse the string character by character.
2. Use a stack to keep track of characters. If the current character matches the top of the stack, pop the stack and count the pair. Otherwise, push the character onto the stack.
3. The parity (odd/even) of the count of pairs will determine the winner.

### Solution Code
```python
def game_winner():
    s = input().strip()
    stack = []
    count = 0
    for c in s:
        if stack and stack[-1] == c:
            stack.pop()
            count += 1
        else:
            stack.append(c)
    print("Yes" if count % 2 == 1 else "No")

game_winner()
```

### Explanation
1. **Stack Initialization**: We use a stack to keep track of characters as we iterate through the string.
2. **Character Processing**: For each character in the string:
   - If the stack is not empty and the top element is the same as the current character, pop the top element and increment the count of pairs.
   - Otherwise, push the current character onto the stack.
3. **Determine Winner**: After processing all characters, check the parity of the count of pairs. If the count is odd, the first player wins ("Yes"). If even, the second player wins ("No").

This approach efficiently processes the string in O(n) time, where n is the length of the string, making it suitable for large inputs up to 100,000 characters.
