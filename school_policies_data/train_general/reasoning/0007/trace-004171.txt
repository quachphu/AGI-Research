To solve this problem, we need to determine the minimal possible penalty Peter can achieve by solving all the problems in an optimal order. The penalty is calculated based on the time taken to solve each problem and the order in which they are solved. The optimal order minimizes the sum of submission times, which is influenced by the sequence in which problems are solved.

### Approach
1. **Understanding Penalty Calculation**: The penalty for each problem is the time at which it is solved, which is the sum of the solving times of all previously solved problems plus its own solving time. The goal is to minimize the total penalty, which is the sum of these times for all problems.
2. **Optimal Order Insight**: The optimal order to minimize the total penalty is to solve the problems in non-decreasing order of their solving times. This is because solving shorter problems first reduces the cumulative penalty contribution of each subsequent problem.
3. **Sorting and Summing**: By sorting the problem solving times in ascending order and summing each time multiplied by its position in the sequence (starting from the number of problems down to 1), we can compute the minimal penalty efficiently.

### Solution Code
```python
import sys

def main():
    data = list(map(int, sys.stdin.read().split()))
    ptr = 0
    while ptr < len(data):
        n = data[ptr]
        ptr += 1
        if n == 0:
            print(0)
            continue
        p = data[ptr:ptr + n]
        ptr += n
        p_sorted = sorted(p)
        total = 0
        for i in range(n):
            total += p_sorted[i] * (n - i)
        print(total)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read as a list of integers. This allows us to process each dataset sequentially without worrying about line breaks.
2. **Processing Each Dataset**: For each dataset, we first read the number of problems. If there are no problems (n=0), the penalty is zero. Otherwise, we read the solving times of the problems.
3. **Sorting and Calculating Penalty**: The solving times are sorted in ascending order. Each problem's contribution to the total penalty is calculated by multiplying its solving time by its position in the sorted sequence (starting from the number of problems down to 1). This sum gives the minimal possible penalty.

This approach ensures that we efficiently compute the minimal penalty by leveraging sorting and a straightforward summation, resulting in an optimal solution with a time complexity of O(N log N) per dataset due to the sorting step.
