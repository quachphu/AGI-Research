To solve this problem, we need to simulate the process of shooting birds on horizontal electricity wires and track the movement of the remaining birds after each shot. The goal is to determine the final number of birds on each wire after all shots have been fired.

### Approach
1. **Problem Analysis**: Each time a bird is shot on a specific wire, the birds to the left of the shot position move to the wire above (if it exists) and the birds to the right move to the wire below (if it exists). The shot bird is removed entirely.
2. **Simulation**: For each shot, we need to:
   - Remove the shot bird.
   - Move the left birds to the wire above.
   - Move the right birds to the wire below.
3. **Data Structures**: Use a list to represent the number of birds on each wire, adjusting indices to handle 1-based input wire numbers.
4. **Edge Cases**: Handle cases where there is no wire above or below the shot wire by allowing birds to fly away.

### Solution Code
```python
n = int(input())
wires = list(map(int, input().split()))
m = int(input())

for _ in range(m):
    xi, yi = map(int, input().split())
    index = xi - 1  # convert to 0-based index
    current = wires[index]
    left = yi - 1
    right = current - yi
    wires[index] = 0
    if index > 0:
        wires[index - 1] += left
    if index < n - 1:
        wires[index + 1] += right

for num in wires:
    print(num)
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of wires, the initial number of birds on each wire, the number of shots, and each shot's coordinates.
2. **Processing Shots**: For each shot, the code converts the wire number to a 0-based index. It calculates the number of birds moving left and right from the shot position, updates the current wire to zero, and adjusts the adjacent wires accordingly.
3. **Output**: After processing all shots, the final number of birds on each wire is printed.

This approach efficiently handles each shot in sequence, ensuring that all movements are correctly simulated and the final state of each wire is accurately determined.
