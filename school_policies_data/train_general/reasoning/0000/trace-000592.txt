To solve this problem, we need to determine the original message typed by Mole on a keyboard where his hands were shifted either left or right. The solution involves mapping each character to its neighboring characters and then using this mapping to decode the shifted input.

### Approach
1. **Keyboard Layout**: The keyboard is arranged in three rows as given. We need to create a mapping of each character to its left and right neighbors.
2. **Shift Direction**: Depending on the shift direction ('L' or 'R'), each character in the input corresponds to a different original character:
   - If the shift is to the right ('R'), the original character is the left neighbor of the input character.
   - If the shift is to the left ('L'), the original character is the right neighbor of the input character.
3. **Mapping Creation**: Create a dictionary where each key is a character from the keyboard, and its value is another dictionary containing its left and right neighbors.
4. **Decoding the Input**: For each character in the input string, use the shift direction to determine the original character using the precomputed neighbor mappings.

### Solution Code
```python
def main():
    rows = ["qwertyuiop", "asdfghjkl;", "zxcvbnm,./"]
    key_map = {}
    for row in rows:
        for i in range(len(row)):
            current = row[i]
            left = row[i-1] if i > 0 else None
            right = row[i+1] if i < len(row) - 1 else None
            key_map[current] = {'left': left, 'right': right}
    
    direction = input().strip()
    s = input().strip()
    
    result = []
    for c in s:
        if direction == 'R':
            result.append(key_map[c]['left'])
        else:
            result.append(key_map[c]['right'])
    
    print(''.join(result))

main()
```

### Explanation
1. **Keyboard Mapping**: The keyboard rows are defined, and a dictionary (`key_map`) is created where each character maps to its left and right neighbors. This is done by iterating over each character in each row and storing the neighbors.
2. **Input Handling**: The direction of the shift and the input string are read from standard input.
3. **Decoding Process**: For each character in the input string, the corresponding original character is determined based on the shift direction. If the shift is to the right, the left neighbor is used; if the shift is to the left, the right neighbor is used.
4. **Result Construction**: The decoded characters are collected into a list and joined into a final string, which is printed as the result.

This approach efficiently decodes the input string using a precomputed neighbor mapping, ensuring that the solution is both optimal and easy to understand.
