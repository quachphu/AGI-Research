To solve this problem, we need to determine how many cars are moving at their maximum speed on a straight segment of a race track where overtaking is impossible. Each car must adjust its speed to match the speed of the car in front if it is slower. 

### Approach
1. **Observation**: Each car's speed is constrained by the slowest car ahead of it. Thus, the speed of each car is determined by the minimum speed among all cars that entered the segment before it, including itself.
2. **Key Insight**: For a car to be moving at its maximum speed, it must be the slowest car encountered so far. This is because if there was a slower car before it, it would have to slow down to match that car's speed.
3. **Algorithm**: 
   - Iterate through each car's maximum speed while maintaining the minimum speed encountered so far.
   - Count how many times a car's maximum speed is the slowest encountered up to that point.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        speeds = list(map(int, input[ptr:ptr+N]))
        ptr += N
        current_min = float('inf')
        count = 0
        for s in speeds:
            current_min = min(current_min, s)
            if s == current_min:
                count += 1
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and split into tokens for efficient processing, which is crucial for handling large input sizes.
2. **Tracking Minimum Speed**: As we process each car's maximum speed, we keep track of the minimum speed encountered so far using `current_min`.
3. **Counting Valid Cars**: Each time a car's maximum speed matches the current minimum speed, it indicates that this car is moving at its maximum speed (since it is the slowest encountered so far), so we increment the count.

This approach ensures we efficiently determine the number of cars moving at their maximum speed with a linear scan through each test case's data, resulting in an optimal time complexity of O(N) per test case.
