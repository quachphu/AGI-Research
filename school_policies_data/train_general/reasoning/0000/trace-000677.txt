To solve this problem, we need to find the shortest closed cycle in a directed weighted graph that visits each vertex exactly once and returns to the starting vertex. This problem can be approached using dynamic programming (DP) similar to the Traveling Salesman Problem (TSP) but adapted for directed graphs.

### Approach
1. **Graph Representation**: Use an adjacency matrix to store the weights of the directed edges. If there is no edge between two vertices, the weight is set to infinity.
2. **Dynamic Programming Setup**: Use a DP table where `dp[mask][u]` represents the minimum cost to reach vertex `u` having visited the set of vertices represented by `mask`. The `mask` is a bitmask where each bit indicates whether a vertex has been visited.
3. **Initialization**: For each possible starting vertex `s`, initialize the DP table such that the starting vertex `s` is visited with a cost of 0.
4. **State Transitions**: For each state `(mask, u)`, iterate through all possible outgoing edges from `u` to other vertices `v` that haven't been visited yet. Update the DP table for the new state `(new_mask, v)` where `new_mask` includes `v`.
5. **Check for Cycles**: After processing all possible states, check if a valid cycle exists from each vertex `u` back to the starting vertex `s`. The shortest cycle for each starting vertex is computed and the minimum among all starting vertices is the result.

### Solution Code
