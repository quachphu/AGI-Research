To solve this problem, we need to determine the height at which each box lands on the staircase. The boxes are thrown sequentially, and each box covers a certain width of the staircase. The landing height of each box depends on the maximum height encountered in the covered width, either from the staircase itself or previous boxes.

### Approach
1. **Track Maximum Height Efficiently**: Instead of updating each stair's height individually, we track the maximum height using two variables: `current_max_value` and `current_max_k`. The `current_max_value` represents the highest height encountered so far, and `current_max_k` represents the farthest stair covered by this height.
2. **Determine Landing Height**: For each box, if the width of the box is within the range covered by `current_max_k`, the maximum height is `current_max_value`. Otherwise, we consider the maximum height between `current_max_value` and the stair's height at the given width (since the staircase is non-decreasing).
3. **Update State**: After determining the landing height, update `current_max_value` to the new height (landing height + box height) and adjust `current_max_k` to cover the new width if necessary.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
a = [0] + a  # Convert to 1-based indexing
m = int(input())

current_max_value = 0
current_max_k = 0

for _ in range(m):
    w, h = map(int, input().split())
    if w <= current_max_k:
        current_max = current_max_value
    else:
        current_max = max(current_max_value, a[w])
    print(current_max)
    new_value = current_max + h
    current_max_value = new_value
    current_max_k = max(current_max_k, w)
```

### Explanation
- **Reading Input**: The input is read and adjusted for 1-based indexing to simplify the logic.
- **Tracking Maximum Values**: The variables `current_max_value` and `current_max_k` keep track of the highest height encountered and the farthest stair it covers.
- **Processing Each Box**: For each box, determine the maximum height in the covered width. If the width is within the previously covered range, use the tracked maximum. Otherwise, consider the staircase's height at that width.
- **Updating State**: After processing each box, update the tracked maximum values to reflect the new height and coverage.

This approach efficiently handles up to 100,000 boxes and stairs, ensuring optimal performance by avoiding repeated updates to individual stairs.
