To solve this problem, we need to determine the minimum number of non-decreasing arrays (each with at most k distinct elements) that sum up to the given array a. The solution involves analyzing the differences between consecutive elements in the array and leveraging these differences to compute the required result efficiently.

### Approach
1. **Difference Array Calculation**: Compute the differences between consecutive elements in the array a. This helps in understanding the points where the array increases.
2. **Count Increases**: For each position from the second element onwards, count how many times the array increases. This count is crucial to determine the minimum number of arrays needed.
3. **Special Case Handling (k=1)**: If k is 1, each array must be constant. Check if all elements in a are the same. If they are, the answer is 1; otherwise, it's impossible.
4. **General Case (k>1)**: Calculate the minimum number of arrays required based on the count of increases. Each array can handle up to k-1 increases, so the minimum number of arrays is the ceiling of the count of increases divided by (k-1).

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    # Compute the differences
    d = []
    prev = 0
    for num in a:
        d.append(num - prev)
        prev = num
    
    # Calculate s: number of j >= 2 (1-based) where d[j] > 0
    s = sum(1 for delta in d[1:] if delta > 0)
    
    if k == 1:
        # Check if all elements are the same
        all_equal = all(x == a[0] for x in a)
        print(1 if all_equal else -1)
    else:
        if s == 0:
            print(1)
        else:
            required = (s + (k-1) - 1) // (k-1)
            print(required)
```

### Explanation
1. **Difference Array Calculation**: The differences array `d` is computed by subtracting each element from its predecessor. This helps identify where the array increases.
2. **Count Increases (s)**: We count how many times the array increases from the second element onwards. This count is stored in `s`.
3. **Handling k=1**: If k is 1, each array must be constant. We check if all elements in the given array are the same. If they are, one array suffices; otherwise, it's impossible.
4. **General Case**: For k > 1, the minimum number of arrays required is determined by the formula `ceil(s / (k-1))`, which is efficiently computed using integer arithmetic.

This approach ensures that we efficiently determine the minimum number of arrays required, leveraging mathematical insights to avoid unnecessary complexity.
