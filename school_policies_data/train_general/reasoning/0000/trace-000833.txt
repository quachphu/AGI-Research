To solve this problem, we need to determine the minimal cost required to adjust the number of commentary boxes such that it becomes divisible by the number of delegations. The adjustment can be done either by building new boxes or demolishing existing ones, each with a specific cost per box.

### Approach
1. **Problem Analysis**:
   - The goal is to make the number of commentary boxes (n) divisible by the number of delegations (m).
   - If `n` is already divisible by `m`, the cost is zero.
   - If not, we need to calculate the cost of either building enough boxes to reach the next multiple of `m` or demolishing enough boxes to reach the previous multiple of `m`.

2. **Key Insight**:
   - Calculate the remainder when `n` is divided by `m` (denoted as `rem`).
   - If `rem` is zero, no adjustment is needed.
   - Otherwise, compute two possible costs:
     - **Demolishing**: Cost to remove `rem` boxes to make `n` a multiple of `m`.
     - **Building**: Cost to add `(m - rem)` boxes to reach the next multiple of `m`.

3. **Algorithm**:
   - Calculate the remainder `rem = n % m`.
   - If `rem` is zero, print `0`.
   - Otherwise, compute the costs for both demolishing and building, then print the minimum of these two costs.

### Solution Code
```python
n, m, a, b = map(int, input().split())
rem = n % m
if rem == 0:
    print(0)
else:
    demolish_cost = rem * b
    build_cost = (m - rem) * a
    print(min(demolish_cost, build_cost))
```

### Explanation
- **Input Handling**: Read the input values for `n`, `m`, `a`, and `b`.
- **Remainder Calculation**: Compute the remainder `rem` of `n` divided by `m`.
- **Check Divisibility**: If `n` is already divisible by `m`, the remainder is zero, and no cost is incurred.
- **Cost Calculation**:
  - **Demolishing Cost**: Calculate the cost to remove `rem` boxes, which is `rem * b`.
  - **Building Cost**: Calculate the cost to add `(m - rem)` boxes, which is `(m - rem) * a`.
- **Result**: Print the minimum of the demolishing and building costs.

This approach ensures that we efficiently determine the minimal cost by considering both possible adjustments (building or demolishing) based on the given costs per box. The solution runs in constant time, O(1), as it involves simple arithmetic operations.
