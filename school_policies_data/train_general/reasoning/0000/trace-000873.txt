To solve this problem, we need to determine the maximum number of cookies Apollinaria can bake using the given ingredients and magic powder. Each cookie requires a specific amount of each ingredient, and the magic powder can be converted into any ingredient to cover deficits.

### Approach
1. **Initial Calculation**: Compute the initial maximum number of cookies that can be baked without using any magic powder. This is determined by the minimum ratio of available ingredients to required ingredients for each cookie.
2. **Binary Search**: Use binary search to find the maximum number of cookies that can be baked by efficiently using the magic powder. The search range starts from the initial maximum cookies (without magic powder) and extends up to the sum of the initial maximum and the magic powder quantity.
3. **Deficit Calculation**: For each midpoint value in the binary search, calculate the total deficit of ingredients needed to bake that number of cookies. If the total deficit can be covered by the magic powder, update the maximum number of cookies and adjust the search range.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    k = int(input[idx + 1])
    idx += 2
    a = list(map(int, input[idx:idx + n]))
    idx += n
    b = list(map(int, input[idx:idx + n]))
    
    x0 = min(b[i] // a[i] for i in range(n))
    low = x0
    high = x0 + k
    max_cookies = x0
    
    while low <= high:
        mid = (low + high) // 2
        required = 0
        for i in range(n):
            needed = a[i] * mid
            if needed > b[i]:
                required += needed - b[i]
            if required > k:
                break
        if required <= k:
            max_cookies = mid
            low = mid + 1
        else:
            high = mid - 1
    
    print(max_cookies)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of ingredients, magic powder quantity, required amounts for each ingredient, and available amounts of each ingredient.
2. **Initial Maximum Cookies (x0)**: Calculate the initial maximum number of cookies without using magic powder by finding the minimum ratio of available ingredients to required ingredients.
3. **Binary Search Setup**: Set the initial search range from `x0` to `x0 + k` to account for potential additional cookies using magic powder.
4. **Midpoint Check**: For each midpoint value in the binary search, compute the total deficit of ingredients needed. If the total deficit is within the magic powder quantity, update the maximum number of cookies and adjust the search range upwards. Otherwise, adjust the range downwards.
5. **Result**: The maximum number of cookies found through binary search is printed as the result.

This approach efficiently narrows down the possible number of cookies using binary search, ensuring optimal use of the magic powder and ingredients.
