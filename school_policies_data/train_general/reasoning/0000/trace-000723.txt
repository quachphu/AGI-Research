To solve this problem, we need to determine the number of valid Amidakuji patterns that, when starting from the top of the leftmost vertical line, end at the K-th vertical line at the bottom. The solution involves dynamic programming (DP) to track permutations of vertical lines as horizontal lines are added row by row.

### Approach
1. **Generate Valid Masks**: For each row, generate all valid configurations of horizontal lines that do not share endpoints. This is done using bitmasks where each bit represents a possible horizontal line between two vertical lines.
2. **Row Permutations**: Convert each valid mask into a permutation of vertical lines. Each permutation represents the effect of horizontal lines in a row.
3. **Dynamic Programming**: Use a DP approach to track the number of ways to reach each permutation of vertical lines after each row. The DP state transitions are computed by applying each row's permutations to the current state.
4. **Result Calculation**: After processing all rows, sum the counts of permutations where the starting position (leftmost vertical line) maps to the K-th vertical line.

### Solution Code
```python
MOD = 10**9 + 7

def main():
    import sys
    from collections import defaultdict

    H, W, K = map(int, sys.stdin.readline().split())
    K -= 1  # Adjusting K to 0-based index (since permutations are 0-based in the code)

    if W == 1:
        print(1)
        return

    # Generate all valid masks for horizontal lines in a single row
    def generate_valid_masks(W):
        masks = []
        for m in range(0, 1 << (W - 1)):
            valid = True
            for i in range(W - 2):
                if (m >> i) & 3 == 3:  # Check two consecutive bits
                    valid = False
                    break
            if valid:
                masks.append(m)
        return masks

    masks = generate_valid_masks(W)

    # Generate row permutations for each valid mask
    row_perms = []
    for mask in masks:
        perm = list(range(1, W + 1))
        for i in range(W - 1):
            if (mask >> i) & 1:
                perm[i], perm[i + 1] = perm[i + 1], perm[i]
        row_perms.append(tuple(perm))

    # Initialize DP with the identity permutation
    current_dp = defaultdict(int)
    identity = tuple(range(1, W + 1))
    current_dp[identity] = 1

    for _ in range(H):
        new_dp = defaultdict(int)
        for perm, cnt in current_dp.items():
            for r_perm in row_perms:
                # Compute the composition of r_perm and perm (r_perm ∘ perm)
                composed = list(perm)
                for i in range(W):
                    composed[i] = r_perm[composed[i] - 1]
                composed_tuple = tuple(composed)
                new_dp[composed_tuple] = (new_dp[composed_tuple] + cnt) % MOD
        current_dp = new_dp

    # Calculate the answer by checking the image of the first position (1-based K is 0-based here)
    ans = 0
    target = K + 1  # Adjust back to 1-based for the permutation check
    for perm, cnt in current_dp.items():
        if perm[0] == target:
            ans = (ans + cnt) % MOD
    print(ans)

if __name__ == "__main__":
    main()
```

1. **Valid Masks Generation**: The function `generate_valid_masks` generates all valid configurations of horizontal lines using bitmasks. Each configuration must ensure no two horizontal lines are adjacent.
2. **Row Permutations**: For each valid mask, generate the corresponding permutation of vertical lines. This permutation represents the swaps caused by the horizontal lines in that row.
3. **Dynamic Programming**: The DP table tracks the number of ways to reach each permutation of vertical lines after each row. Each entry in the DP table is updated by applying all possible row permutations to the current permutations.
4. **Result Calculation**: After processing all rows, the result is the sum of counts of permutations where the starting position (leftmost vertical line) maps to the K-th vertical line.

This approach efficiently handles the constraints and computes the result using dynamic programming and permutation composition, ensuring correctness and optimal performance.
