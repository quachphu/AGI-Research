### Approach
1. **Pisano Period**: The Fibonacci sequence modulo 10000 (for the last four digits) repeats every 15000 terms. This period allows us to reduce the problem of computing very large Fibonacci numbers to a manageable range.
2. **Precomputation**: Precompute the Fibonacci numbers modulo 10000 for the first 15000 terms. This array helps in quickly retrieving the required Fibonacci numbers.
3. **Prefix Sum Array**: Compute a prefix sum array of the precomputed Fibonacci values modulo \(10^9 + 7\). This array allows efficient range sum queries.
4. **Efficient Query Handling**: For each query, determine the number of complete cycles of the Pisano period and the remaining elements. Use the prefix sum array to compute the sum of these elements efficiently.

                wrap_end = end % PERIOD
                sum_part = ( (prefix[PERIOD] - prefix[s]) + (prefix[wrap_end + 1] - prefix[0]) ) % MOD
            sum_part = sum_part % MOD  # Ensure non-negative
        
        total = (sum_full + sum_part) % MOD
        print(total)

2. **Prefix Sum Array**: The prefix sum array (`prefix`) stores cumulative sums of the precomputed Fibonacci values modulo \(10^9 + 7\). This array helps in efficiently calculating the sum of any subarray.

The sum of complete cycles is computed using the total sum of the precomputed array. The sum of the remaining elements is computed using the prefix sum array, considering wrap-around if necessary.

This approach ensures that each query is processed in constant time, making the solution efficient even for the upper constraint limits.
