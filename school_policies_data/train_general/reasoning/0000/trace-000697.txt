To solve this problem, we need to calculate the complexity of a dance pair assignment, which is defined as the number of pairs (i, j) where i < j but the assigned values of i and j (after applying an XOR operation) result in an inversion. The solution involves efficiently computing this complexity using bitwise operations and modular arithmetic.

### Approach
1. **Understanding the XOR Permutation**: Each member i of MDC is paired with a member of NFC using the XOR operation with a given binary number x. This results in a permutation of numbers from 0 to 2^n - 1, where n is the length of the binary string x.
2. **Inversion Count Insight**: The complexity of the permutation is equivalent to the number of inversions in the array formed by i XOR x for each i. An inversion occurs when a pair (i, j) with i < j has a higher value after applying the XOR operation.
3. **Bitwise Contribution**: For each bit position k where the bit in x is 1, flipping this bit affects the order of numbers. The number of inversions contributed by each such bit can be computed using the formula 2^(n + k - 1) modulo 1000000007.

### Solution Code
```python
s = input().strip()
n = len(s)
x = int(s, 2)
MOD = 10**9 + 7
ans = 0

for k in range(n):
    if (x >> k) & 1:
        exponent = n + k - 1
        ans = (ans + pow(2, exponent, MOD)) % MOD

print(ans)
```

### Explanation
1. **Reading Input**: The binary string x is read and converted to its decimal equivalent.
2. **Iterating Over Bits**: For each bit position k (from 0 to n-1), check if the bit is set in x.
3. **Calculating Contribution**: If the k-th bit is set, compute the number of inversions contributed by this bit using the formula 2^(n + k - 1) modulo 1000000007.
4. **Summing Contributions**: Sum all contributions from each bit position where the bit is set in x and print the result modulo 1000000007.

This approach efficiently computes the inversion count by leveraging bitwise operations and modular exponentiation, ensuring it handles the large values involved within the constraints.
