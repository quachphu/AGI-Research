To solve this problem, we need to determine the minimum number of changes required to transform a given string into an 'a'-good string. An 'a'-good string is defined recursively, where either the first half or the second half of the string consists entirely of 'a's and the other half is a 'b'-good string, and so on for subsequent characters.

### Approach
1. **Recursive Definition**: The problem can be broken down recursively. For a string to be 'a'-good, it can either:
   - Have the first half as all 'a's and the second half as a 'b'-good string.
   - Have the second half as all 'a's and the first half as a 'b'-good string.

2. **Prefix Sum Arrays**: To efficiently count the number of characters in a substring that match a given character, we use prefix sum arrays for each character from 'a' to 'z'. This allows us to compute the count in O(1) time for any substring.

3. **Recursive Function with Memoization**: We use a recursive function to explore both possible transformations (first half or second half being the current target character) and compute the minimum changes required. The function is optimized using prefix sums to avoid redundant calculations.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    for _ in range(t):
        n = int(data[idx])
        idx += 1
        s = data[idx]
        idx += 1
        
        # Precompute prefix sums for each character
        prefix = {chr(c): [0] * (n + 1) for c in range(ord('a'), ord('z') + 1)}
        for i in range(n):
            current_char = s[i]
            for c in prefix:
                prefix[c][i+1] = prefix[c][i] + (1 if c == current_char else 0)
        
        # Define the recursive function
        def dfs(left, right, current_c):
            if left == right:
                return 0 if s[left] == current_c else 1
            mid = (left + right) // 2
            # Option 1: first half current_c, second half (current_c+1)-good
            length_first = mid - left + 1
            count_first = prefix[current_c][mid+1] - prefix[current_c][left]
            cost1a = length_first - count_first
            next_c = chr(ord(current_c) + 1)
            cost1b = dfs(mid + 1, right, next_c)
            option1 = cost1a + cost1b
            
            # Option 2: second half current_c, first half (current_c+1)-good
            length_second = right - mid
            count_second = prefix[current_c][right+1] - prefix[current_c][mid+1]
            cost2a = length_second - count_second
            cost2b = dfs(left, mid, next_c)
            option2 = cost2a + cost2b
            
            return min(option1, option2)
        
        print(dfs(0, n-1, 'a'))

if __name__ == "__main__":
    main()
```
