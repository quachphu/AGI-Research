To solve this problem, we need to determine the sum of the number of ways to choose K students from N students to sit on chairs for all values of K from 1 to N, modulo \(10^9 + 7\). This problem can be efficiently solved using modular arithmetic and exponentiation.

### Approach
1. **Understanding the Problem**: The sum of combinations \(C(N, K)\) for K from 1 to N is equivalent to \(2^N - 1\). This is because the sum of all subsets of N elements (including the empty set) is \(2^N\), and subtracting 1 removes the empty subset.
2. **Modulo Operation**: Since the result can be very large, we need to compute the result modulo \(10^9 + 7\).
3. **Efficient Computation**: Use modular exponentiation to compute \(2^N \mod (10^9 + 7)\) efficiently. Python's built-in `pow` function with three arguments (base, exponent, modulus) is optimized for this purpose.

### Solution Code
```python
import sys

MOD = 10**9 + 7

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        N = int(input[i])
        result = (pow(2, N, MOD) - 1) % MOD
        print(result)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
- **Modular Exponentiation**: The `pow(2, N, MOD)` function efficiently computes \(2^N \mod (10^9 + 7)\) using exponentiation by squaring, which runs in \(O(\log N)\) time.
- **Adjusting Result**: Subtract 1 from the result of the modular exponentiation to exclude the empty subset and take modulo \(10^9 + 7\) again to ensure the result is non-negative.

This approach ensures that we handle large values of N efficiently and correctly compute the result within the constraints.
