To solve this problem, we need to determine if there was any moment during the entry of guests into Jelly Castle when more than `k` doors were open simultaneously. Each guest uses a specific entrance, and each entrance door opens just before the first guest arrives and closes just after the last guest using that entrance arrives. Guards are assigned to open doors, and if more than `k` doors are open at any time, it indicates a security breach.

### Approach
1. **Track First and Last Occurrences**: For each entrance (denoted by a character), track the first and last occurrence of guests using that entrance.
2. **Generate Events**: For each entrance, generate two events: one when the door opens (at the first occurrence) and one when it closes (immediately after the last occurrence).
3. **Sort Events**: Sort these events by time. If two events occur at the same time, process door closings before openings to avoid overcounting.
4. **Simulate Door Openings**: Traverse through the sorted events, maintaining a count of currently open doors. If at any point this count exceeds `k`, output "YES". If the traversal completes without exceeding `k`, output "NO".

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    k = int(input[1])
    s = input[2] if len(input) > 2 else ''
    
    first = {}
    last = {}
    for i in range(n):
        c = s[i]
        if c not in first:
            first[c] = i
        last[c] = i
    
    events = []
    for c in first:
        start = first[c]
        end = last[c]
        events.append((start, 1))
        events.append((end + 1, -1))
    
    events.sort()
    current = 0
    for x, delta in events:
        current += delta
        if current > k:
            print("YES")
            return
    print("NO")

main()
```
