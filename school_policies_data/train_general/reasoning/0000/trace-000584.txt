To solve this problem, we need to determine the minimal index \( i \) from which Petya can start his journey using public transport such that the total cost does not exceed his remaining money \( p \). The solution involves analyzing the segments of consecutive bus or tram stations and calculating the cumulative cost from each segment to the end.

### Approach
1. **Segment Identification**: Split the input string into segments of consecutive 'A's or 'B's. Each segment represents a continuous stretch of either bus or tram stations.
2. **Cost Calculation**: For each segment, determine the cost based on whether it is a bus ('A') or tram ('B') segment.
3. **Suffix Sum Calculation**: Compute the cumulative cost from each segment to the end of the journey using suffix sums. This helps in quickly determining if starting from a particular segment is feasible with the given money \( p \).
4. **Determine Minimal Index**: Iterate through the segments to find the earliest segment where the cumulative cost is within \( p \). The start index of this segment is the answer.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        a = int(input[ptr])
        b = int(input[ptr + 1])
        p = int(input[ptr + 2])
        ptr += 3
        s = input[ptr]
        ptr += 1
        n = len(s)
        effective = s[:-1]  # Process up to the second last character
        if not effective:
            print(n)
            continue
        
        # Split into segments
        segments = []
        current_char = effective[0]
        start = 0
        for i in range(1, len(effective)):
            if effective[i] != current_char:
                segments.append((current_char, start, i - 1))
                current_char = effective[i]
                start = i
        segments.append((current_char, start, len(effective) - 1))
        
        # Calculate costs for each segment
        costs = []
        for seg in segments:
            cost = a if seg[0] == 'A' else b
            costs.append(cost)
        
        # Compute suffix sums
        m = len(costs)
        suffix_sums = [0] * m
        if m == 0:
            print(1)
            continue
        suffix_sums[-1] = costs[-1]
        for i in range(m - 2, -1, -1):
            suffix_sums[i] = suffix_sums[i + 1] + costs[i]
        
        # Find the earliest possible segment
        answer = n  # Default to walking all the way
        for i in range(m):
            if suffix_sums[i] <= p:
                answer = segments[i][1] + 1  # Convert to 1-based index
                break
        print(answer)

solve()
```

### Explanation
1. **Segment Identification**: The input string is processed to identify segments of consecutive 'A's or 'B's. Each segment is stored with its type and start/end indices.
2. **Cost Calculation**: Each segment's cost is determined by its type ('A' for bus cost \( a \), 'B' for tram cost \( b \)).
3. **Suffix Sum Calculation**: We compute the suffix sums for the costs array to quickly determine the cumulative cost from any segment to the end.
4. **Determine Minimal Index**: By iterating through the suffix sums, we find the earliest segment where the cumulative cost is within \( p \). The start index of this segment is the answer, ensuring Petya starts as close to the beginning as possible while staying within his budget. If no valid segment is found, the answer defaults to the last crossroad, meaning Petya must walk the entire way.
