To solve this problem, we need to determine the maximum number of days Takahashi can hang out during his summer vacation if he completes all his assignments. If he cannot finish all assignments within the vacation period, we should return `-1`.

### Approach
1. **Understand the Problem**: Takahashi has `N` days of vacation and `M` assignments. Each assignment takes a specific number of days to complete. He can only work on one assignment per day, and he cannot hang out on days he is working. The goal is to maximize his free days.
2. **Sum of Assignment Days**: Calculate the total number of days required to complete all assignments. This is simply the sum of all the days required for each individual assignment.
3. **Check Feasibility**: If the total days required for assignments exceed the vacation days (`N`), output `-1` as it's impossible to complete all assignments. Otherwise, the remaining days after completing all assignments are his free days, which is `N` minus the total assignment days.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    M = int(input[1])
    A = list(map(int, input[2:2+M]))
    total = sum(A)
    if total > N:
        print(-1)
    else:
        print(N - total)

main()
```

### Explanation
1. **Reading Input**: The input is read from standard input, which includes the number of vacation days `N`, the number of assignments `M`, and the list of days required for each assignment.
2. **Calculate Total Assignment Days**: The sum of all elements in the list `A` gives the total number of days needed to complete all assignments.
3. **Determine Feasibility and Result**: Compare the total assignment days with `N`. If the total exceeds `N`, print `-1`. Otherwise, subtract the total assignment days from `N` to get the maximum free days and print the result.

This approach efficiently computes the result with a time complexity of O(M), which is suitable given the problem constraints. The solution ensures we handle edge cases where assignments cannot be completed within the vacation period.
