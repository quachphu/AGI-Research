To solve this problem, we need to determine if a robot vehicle can capture all falling balloons at their respective positions and times, while minimizing the total distance traveled. The vehicle can carry up to three balloons, and its speed decreases as it carries more balloons. The solution must also identify the first balloon that cannot be captured if it's impossible to capture all.

### Approach
1. **Problem Analysis**:
   - The vehicle starts at the house (position 0) and must be at the exact position of each balloon when it lands.
   - The vehicle's speed depends on the number of balloons it carries. The time to move one unit distance is `k + 1` where `k` is the number of balloons carried.
   - After capturing a balloon, if the vehicle is carrying three balloons, it must return to the house to unload before capturing the next balloon.

2. **Dynamic Programming (DP) Approach**:
   - Track possible states of the vehicle after each balloon capture using a dictionary where keys are tuples `(position, load)` and values are the minimal distance traveled to reach that state.
   - For each balloon, compute possible transitions from the previous states to reach the current balloon's position in time, considering both direct movement and movement via the house.

3. **Transition Logic**:
   - **Direct Move**: Check if the vehicle can move directly from its current position to the next balloon's position within the available time.
   - **Move via Home**: Check if the vehicle can return to the house first, then move to the next balloon's position within the available time.

4. **Final Check**:
   - After processing all balloons, compute the minimal total distance by considering the return trip to the house from the final position.

import sys

def main():
    for line in sys.stdin:
        n = int(line.strip())
        if n == 0:
            break
        balloons = []
        for _ in range(n):
            p, t = map(int, sys.stdin.readline().split())
            balloons.append((p, t))
        
        if balloons[0][0] > balloons[0][1]:
            print("NG 1")
            continue
        
        dp = {}
        first_p, first_t = balloons[0]
        dp[(first_p, 1)] = first_p
        
        possible = True
        for i in range(1, n):
            current_p, current_t = balloons[i]
            prev_t = balloons[i-1][1]
            delta_t = current_t - prev_t
            new_dp = {}
            for (prev_pos, prev_load) in dp:
                prev_dist = dp[(prev_pos, prev_load)]
                
                # Option 1: Direct move
                if prev_load <= 2:
                    distance_move = abs(current_p - prev_pos)
                    time_move = distance_move * (prev_load + 1)
                    if time_move <= delta_t:
                        new_load = prev_load + 1
                        new_pos = current_p
                        total_dist = prev_dist + distance_move
                        key = (new_pos, new_load)
                        if key not in new_dp or total_dist < new_dp[key]:
                            new_dp[key] = total_dist
                
                # Option 2: Move via home
                time_to_home = prev_pos * (prev_load + 1)
                time_from_home = current_p * 1
                total_time = time_to_home + time_from_home
                if total_time <= delta_t:
                    new_load = 1
                    new_pos = current_p
                    total_dist = prev_dist + prev_pos + current_p
                    key = (new_pos, new_load)
                    if key not in new_dp or total_dist < new_dp[key]:
                        new_dp[key] = total_dist
            
            if not new_dp:
                print(f"NG {i+1}")
                possible = False
                break
            else:
                dp = new_dp
        
        if possible:
            min_total = min([dist + pos for (pos, load), dist in dp.items()])
            print(f"OK {min_total}")

if __name__ == "__main__":
