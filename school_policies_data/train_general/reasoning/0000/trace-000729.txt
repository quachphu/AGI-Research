To solve this problem, we need to determine if a bridge will break based on the weights of people crossing it over time. The bridge can withstand a maximum weight of 150 kg at any given time. The solution involves checking if the total weight of people on the bridge exceeds this limit at any moment.

### Approach
1. **Event Collection**: For each person, create two events: a start event (when they step onto the bridge) and an end event (when they leave the bridge).
2. **Event Sorting**: Sort these events by time. If multiple events occur at the same time, process end events before start events to ensure the bridge's weight is updated correctly.
3. **Weight Tracking**: As we process each event, update the current weight on the bridge. Check if the weight exceeds 150 kg after handling each start event. If it does, the bridge breaks.
