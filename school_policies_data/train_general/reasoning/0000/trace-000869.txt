To solve this problem, we need to determine the maximum number of tables that can be decorated using red, green, and blue balloons such that each table has exactly three balloons, and no table has all three balloons of the same color.

### Approach
The key insight is to recognize that each table can either use one balloon of each color or a combination of two colors. The solution involves two main considerations:
1. The sum of all balloons divided by 3 (since each table needs 3 balloons).
2. The sum of the two smaller quantities of balloons, which limits the number of tables when one color is significantly more abundant than the others.

The maximum number of tables is the minimum of these two values:
1. The total number of balloons divided by 3.
2. The sum of the two smaller quantities of balloons.

### Solution Code
```python
r, g, b = map(int, input().split())
total = r + g + b
max_val = max(r, g, b)
sum_two = total - max_val
print(min(total // 3, sum_two))
```

### Explanation
1. **Reading Input:** The input consists of three integers representing the number of red, green, and blue balloons.
2. **Total Balloons:** Calculate the total number of balloons.
3. **Maximum Balloons:** Determine the maximum count among the three colors.
4. **Sum of Two Smaller Quantities:** Subtract the maximum count from the total to get the sum of the two smaller quantities.
5. **Compute Result:** The result is the minimum of the total divided by 3 and the sum of the two smaller quantities. This ensures we account for both the total number of balloons and the limiting factor when one color is dominant.

This approach efficiently computes the maximum number of tables using basic arithmetic operations and comparisons, ensuring optimal performance even for large input values.
