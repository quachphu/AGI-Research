To solve this problem, we need to determine the number of ways Tak can move from Cell 1 to Cell N using steps defined by given non-overlapping segments. The solution involves dynamic programming (DP) with prefix sums to efficiently compute the number of ways to reach each cell.

### Approach
1. **Dynamic Programming (DP) Setup**: Define `dp[i]` as the number of ways to reach cell `i`. Initialize `dp[1]` to 1 since Tak starts at Cell 1.
2. **Prefix Sum Array**: Use a prefix sum array to quickly compute the sum of DP values over any range. This helps in efficiently calculating the contributions from each segment.
3. **Segment Processing**: For each cell `i` from 2 to N, compute the contribution from each segment by determining the valid range of previous cells that can reach `i` using steps from the segment. Use the prefix sum array to get the sum of contributions in constant time.
4. **Modulo Operations**: Ensure all operations are performed modulo 998244353 to handle large numbers and prevent overflow.

### Solution Code
```python
mod = 998244353

n, k = map(int, input().split())
intervals = [tuple(map(int, input().split())) for _ in range(k)]

dp = [0] * (n + 2)
prefix = [0] * (n + 2)

dp[1] = 1
prefix[1] = dp[1]

for i in range(2, n + 1):
    current = 0
    for (l, r) in intervals:
        upper = i - l
        lower = i - r
        lower = max(1, lower)
        if upper < 1:
            continue
        if lower > upper:
            continue
        sum_c = (prefix[upper] - prefix[lower - 1]) % mod
        current = (current + sum_c) % mod
    dp[i] = current
    prefix[i] = (prefix[i - 1] + dp[i]) % mod

print(dp[n] % mod)
```

### Explanation
1. **Dynamic Programming Array**: `dp[i]` stores the number of ways to reach cell `i`. We start with `dp[1] = 1` since Tak is initially at Cell 1.
2. **Prefix Sum Array**: The prefix array `prefix[i]` stores the cumulative sum of `dp` values up to cell `i`, allowing efficient range sum queries.
3. **Segment Contribution Calculation**: For each cell `i`, iterate through each segment to determine the valid range of previous cells that can reach `i` using steps from the segment. The valid range is adjusted to ensure it stays within bounds, and the prefix sum array is used to get the sum of contributions in constant time.
4. **Modulo Operations**: All operations are performed modulo 998244353 to handle large numbers and ensure results fit within standard integer limits.

This approach efficiently computes the number of ways to reach each cell using dynamic programming and prefix sums, ensuring the solution is optimal and runs in O(N*K) time complexity, which is feasible for the given constraints.
