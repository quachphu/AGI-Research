To solve this problem, we need to determine if a given sequence of gears can be rotated such that their active teeth form the sequence 0, 1, 2, ..., n-1 after a certain number of button presses. Each gear alternates rotation direction (clockwise for odd-indexed gears, counter-clockwise for even-indexed gears) with each button press.

### Approach
1. **Understand the Rotation Mechanics**: 
   - Odd-indexed gears rotate clockwise, incrementing their active tooth by 1 each press.
   - Even-indexed gears rotate counter-clockwise, decrementing their active tooth by 1 each press.

2. **Formulate Equations**:
   - For an odd-indexed gear i, after k presses, the active tooth is `(a_i + k) % n`.
   - For an even-indexed gear i, after k presses, the active tooth is `(a_i - k) % n`.

3. **Determine Validity**:
   - For each gear, derive the required number of presses k modulo n to achieve the target sequence.
   - Check if all gears agree on the same value of k modulo n. If they do, the answer is "Yes"; otherwise, it's "No".

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
x = None
valid = True

for i in range(1, n + 1):
    ai = a[i - 1]
    if i % 2 == 1:
        current = (i - 1 - ai) % n
    else:
        current = (ai - (i - 1)) % n
    if x is None:
        x = current
    elif current != x:
        valid = False
        break

print("Yes" if valid else "No")
```

### Explanation
- **Input Handling**: Read the number of gears `n` and the list of active teeth positions.
- **Iterate Over Gears**: For each gear, compute the required number of presses modulo n based on its index (odd or even).
- **Check Consistency**: Ensure all gears compute the same required number of presses modulo n. If they do, print "Yes"; otherwise, print "No".

This approach efficiently checks the consistency of the required presses across all gears using modular arithmetic, ensuring a solution in O(n) time complexity.
