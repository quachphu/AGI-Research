To solve this problem, we need to represent the product of two numbers, N and M, using left shift operations. The goal is to form an equation using the left shift operator such that the result is equivalent to N*M, with the minimum number of terms and in non-increasing order of shift positions.

### Approach
1. **Understanding Left Shift and Multiplication**: The left shift operation `(N << p)` is equivalent to multiplying N by 2^p. Thus, multiplying N by M can be broken down into a sum of left shifts of N, corresponding to the binary representation of M.
2. **Binary Representation of M**: Each bit set in the binary representation of M corresponds to a term in the sum. For example, if M is 3 (binary 11), it can be represented as 2^1 + 2^0, leading to the terms `(N << 1) + (N << 0)`.
3. **Efficient Extraction of Set Bits**: For each number M, determine the positions of all set bits in its binary representation. These positions indicate the required left shifts.
4. **Ordering of Terms**: The terms must be ordered in non-increasing order of their shift positions. This is naturally achieved by checking bits from the most significant to the least significant.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    results = []
    for _ in range(T):
        N = int(input[idx])
        M = int(input[idx + 1])
        idx += 2
        exponents = []
        for i in range(60, -1, -1):
            if M & (1 << i):
                exponents.append(i)
        terms = ["(%d<<%d)" % (N, p) for p in exponents]
        results.append(" + ".join(terms))
    print('\n'.join(results))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once for efficiency, especially given the constraints where the number of test cases can be very large.
2. **Binary Decomposition of M**: For each M, we check each bit from the 60th position down to 0. This ensures we capture all set bits in descending order.
3. **Constructing Terms**: Each set bit in M corresponds to a term `(N << p)`, where p is the bit position. These terms are collected in a list and joined into a string formatted as required.
4. **Output**: The results for all test cases are collected in a list and printed at once to minimize I/O operations, which is crucial for handling large input sizes efficiently.

This approach ensures that the solution is both optimal in terms of the number of operations and efficient in handling large input sizes.
