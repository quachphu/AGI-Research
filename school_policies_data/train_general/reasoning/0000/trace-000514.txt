We need a Union-Find data structure.

Implement the Union-Find with path compression and union by rank.

class UnionFind:

    def __init__(self, size):

        self.parent = list(range(size))

        self.rank = [0] * size

    def find(self, x):

        if self.parent[x] != x:

            self.parent[x] = self.find(self.parent[x])

        return self.parent[x]

    def union(self, x, y):

        xroot = self.find(x)

        yroot = self.find(y)

        if xroot == yroot:

            return False

        if self.rank[xroot] < self.rank[yroot]:

            self.parent[xroot] = yroot

        else:

            self.parent[yroot] = xroot

            if self.rank[xroot] == self.rank[yroot]:

                self.rank[xroot] +=1

        return True

To solve this problem, we need to connect all towns on a plane with the minimum possible cost using roads. The cost of building a road between two towns is determined by the minimum of the absolute differences in their x-coordinates and y-coordinates. This problem can be efficiently solved using a Minimum Spanning Tree (MST) approach with a Union-Find data structure to ensure optimal connectivity.

### Approach
1. **Problem Analysis**: The goal is to connect all towns such that the total cost is minimized. The cost between two towns is given by the minimum of the x and y coordinate differences. This problem can be transformed into finding an MST in a graph where each node represents a town and edges are weighted by the aforementioned cost.

2. **Key Insight**: Instead of considering all possible edges (which is computationally infeasible for large N), we can generate edges by sorting the towns by their x and y coordinates. For each sorted list, we consider edges between consecutive towns. This reduces the number of edges to O(N), making the problem tractable.

3. **Algorithm Selection**: Kruskal's algorithm is used to find the MST. This algorithm sorts all edges by weight and uses a Union-Find data structure to efficiently manage and merge components.

4. **Complexity Analysis**: Sorting the towns by x and y coordinates takes O(N log N) time. Generating edges and sorting them also takes O(N log N) time. The Union-Find operations with path compression and union by rank ensure near-linear time complexity, making the solution efficient even for large N.

### Solution Code

class UnionFind:
    def __init__(self, size):
        self.parent = list(range(size))
        self.rank = [0] * size

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        xroot = self.find(x)
        yroot = self.find(y)
        if xroot == yroot:
            return False
        if self.rank[xroot] < self.rank[yroot]:
            self.parent[xroot] = yroot
        else:
            self.parent[yroot] = xroot
            if self.rank[xroot] == self.rank[yroot]:
                self.rank[xroot] += 1
        return True

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    coords = []
    for _ in range(N):
        x = int(input[idx])
        y = int(input[idx + 1])
        coords.append((x, y))
        idx += 2

    # Generate edges from x-sorted indices
    sorted_x = sorted(range(N), key=lambda i: (coords[i][0], coords[i][1]))
    edges = []
    for i in range(N - 1):
        u = sorted_x[i]
        v = sorted_x[i + 1]
        dx = coords[v][0] - coords[u][0]
        dy = abs(coords[v][1] - coords[u][1])
        edges.append((min(dx, dy), u, v))

    # Generate edges from y-sorted indices
    sorted_y = sorted(range(N), key=lambda i: (coords[i][1], coords[i][0]))
    for i in range(N - 1):
        u = sorted_y[i]
        v = sorted_y[i + 1]
        dy = coords[v][1] - coords[u][1]
        dx = abs(coords[v][0] - coords[u][0])
        edges.append((min(dx, dy), u, v))

    # Sort edges by cost
    edges.sort()

    # Kruskal's algorithm
    uf = UnionFind(N)
    total = 0
    for cost, u, v in edges:
        if uf.find(u) != uf.find(v):
            uf.union(u, v)
            total += cost

    print(total)

if __name__ == '__main__':
    main()

3. **Generating Edges**: Edges are created between consecutive towns in both x-sorted and y-sorted lists, with their respective costs calculated.
4. **Kruskal's Algorithm**: The edges are sorted by cost, and the Union-Find data structure is used to efficiently build the MST, ensuring all towns are connected with minimal cost.

This approach efficiently reduces the problem size and leverages sorting and Union-Find operations to achieve the optimal solution.
