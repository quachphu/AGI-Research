To solve this problem, we need to determine the language of a given sentence based on its suffix. The suffixes and their corresponding languages are as follows:
- "po" indicates Filipino.
- "desu" or "masu" indicates Japanese.
- "mnida" indicates Korean.

### Approach
1. **Input Reading**: Read the number of test cases followed by each sentence.
2. **Suffix Checking**: For each sentence, check the suffix in descending order of length to ensure we catch the longest suffixes first. This avoids any potential partial matches and ensures correctness.
3. **Determine Language**: Based on the suffix, classify the sentence into the appropriate language.

### Solution Code
```python
def main():
    import sys
    t = int(sys.stdin.readline())
    for _ in range(t):
        s = sys.stdin.readline().strip()
        if s.endswith('mnida'):
            print("KOREAN")
        elif s.endswith('desu') or s.endswith('masu'):
            print("JAPANESE")
        else:
            print("FILIPINO")

main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency, especially given the constraints. The first line contains the number of test cases.
2. **Checking Suffixes**: Each sentence is checked for the longest suffix first ("mnida" for Korean), followed by "desu" and "masu" (Japanese), and finally "po" (Filipino). This order ensures that longer suffixes are checked before shorter ones to avoid incorrect partial matches.
3. **Output**: Based on the suffix check, the corresponding language is printed for each test case.

This approach efficiently determines the language of each sentence by leveraging string suffix checks, ensuring correctness and simplicity.
