To solve this problem, we need to determine the number of positive divisors of a given integer \( x \) that share at least one common digit with \( x \). The solution involves generating all divisors of \( x \) and checking each divisor for common digits with \( x \).

### Approach
1. **Factorize the Number**: First, we factorize \( x \) into its prime factors. This helps in efficiently generating all possible divisors.
2. **Generate Divisors**: Using the prime factors, generate all divisors by considering all possible combinations of the prime factors' exponents.
3. **Check Common Digits**: For each divisor, check if it shares any digit with \( x \) by converting both numbers to strings and comparing their characters.

### Solution Code
```python
def get_factors(x):
    factors = {}
    while x % 2 == 0:
        factors[2] = factors.get(2, 0) + 1
        x = x // 2
    i = 3
    while i * i <= x:
        while x % i == 0:
            factors[i] = factors.get(i, 0) + 1
            x = x // i
        i += 2
    if x > 1:
        factors[x] = 1
    return factors

def generate_divisors(factors):
    divisors = [1]
    for p, exp in factors.items():
        temp = []
        for d in divisors:
            for e in range(exp + 1):
                temp.append(d * (p ** e))
        divisors = temp
    return divisors

def solve():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        x = int(input[i])
        x_str = str(x)
        digits_x = set(x_str)
        factors = get_factors(x)
        divisors = generate_divisors(factors)
        count = 0
        for d in divisors:
            if any(c in digits_x for c in str(d)):
                count += 1
        print(count)

solve()
```

1. **Factorization**: The `get_factors` function uses trial division to factorize \( x \). It checks divisibility starting from 2, then proceeds with odd numbers up to the square root of \( x \).
2. **Divisor Generation**: The `generate_divisors` function generates all divisors by iterating over each prime factor and its possible exponents, combining them with existing divisors.
3. **Digit Check**: For each divisor, convert it to a string and check if any character is present in the string representation of \( x \). This is done using set operations for efficiency.

This approach ensures that we efficiently generate divisors and check for common digits, handling the constraints effectively.
