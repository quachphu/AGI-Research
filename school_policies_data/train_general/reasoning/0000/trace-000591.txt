To solve this problem, we need to determine if we can sort an array by reversing exactly one segment. If possible, we must also identify the segment's start and end indices (1-based).

### Approach
1. **Sort the Array**: First, sort the given array to get the target sorted version.
2. **Identify Mismatched Segments**: Find the leftmost and rightmost indices where the original array differs from the sorted array.
3. **Check Reversal**: Reverse the segment between these indices in the original array and check if it matches the sorted array. If it does, the segment can be reversed to sort the array; otherwise, it cannot.

### Solution Code
```python
def solve():
    import sys
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    sorted_a = sorted(a)
    
    if a == sorted_a:
        print("yes")
        print(1, 1)
        return
    
    left = None
    for i in range(n):
        if a[i] != sorted_a[i]:
            left = i
            break
    
    right = None
    for i in range(n-1, -1, -1):
        if a[i] != sorted_a[i]:
            right = i
            break
    
    # Reverse the segment from left to right
    reversed_segment = a[left:right+1][::-1]
    new_a = a[:left] + reversed_segment + a[right+1:]
    
    if new_a == sorted_a:
        print("yes")
        print(left + 1, right + 1)
    else:
        print("no")

solve()
```

### Explanation
1. **Sorting the Array**: The sorted version of the array is necessary to compare against the original array and identify discrepancies.
2. **Finding Mismatches**: By iterating from the start and end of the array, we locate the first and last positions where the original array deviates from the sorted array. These positions define the segment that needs to be checked.
3. **Reversing the Segment**: The identified segment is reversed, and the resulting array is compared to the sorted version. If they match, the reversal of that segment sorts the array; otherwise, it is not possible.

This approach efficiently identifies the segment and checks its reversal in linear time relative to the array size, making it suitable for large input sizes up to 100,000 elements.
