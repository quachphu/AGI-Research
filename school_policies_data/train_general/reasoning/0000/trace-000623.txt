To solve this problem, we need to implement the partition step of the QuickSort algorithm. The goal is to read an input array, partition it around the last element (pivot), and then print the modified array with the pivot element enclosed in square brackets.

### Approach
1. **Reading Input**: The input consists of an integer `n` (number of elements) followed by `n` integers.
2. **Partition Process**: The partition process is performed as described in the problem statement. The pivot element is always the last element of the array. The array is rearranged such that elements less than or equal to the pivot are on the left, and elements greater than the pivot are on the right. The pivot is then placed in its correct position.
3. **Output Formatting**: After partitioning, the array is printed with the pivot element enclosed in square brackets.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    A = list(map(int, input[1:n+1]))
    
    def partition(arr, p, r):
        x = arr[r]
        i = p - 1
        for j in range(p, r):
            if arr[j] <= x:
                i += 1
                arr[i], arr[j] = arr[j], arr[i]
        arr[i+1], arr[r] = arr[r], arr[i+1]
        return i + 1
    
    q = partition(A, 0, n-1)
    
    output = []
    for i in range(n):
        if i == q:
            output.append(f"[{A[i]}]")
        else:
            output.append(str(A[i]))
    print(' '.join(output))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go using `sys.stdin.read()` for efficiency, especially with large input sizes. The input is split into a list of strings, with the first element being `n` and the rest being the elements of the array.
2. **Partition Function**: The partition function takes the array and indices `p` (start) and `r` (end). The pivot is the element at index `r`. The array is iterated from `p` to `r-1`, and elements less than or equal to the pivot are moved to the left. The pivot is then swapped with the element immediately after the last element found to be less than or equal to it, placing the pivot in its correct position.
3. **Output Formatting**: After partitioning, each element of the array is converted to a string. The pivot element (at the index returned by the partition function) is enclosed in square brackets. The elements are then joined into a single string separated by spaces and printed.

This approach ensures that the array is partitioned efficiently in O(n) time, making it suitable for large input sizes up to 100,000 elements.
