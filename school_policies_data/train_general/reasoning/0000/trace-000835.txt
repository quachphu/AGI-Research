To solve this problem, we need to convert a given string into a "Good String" by removing consecutive duplicate characters. A Good String is defined as one where no two consecutive characters are the same.

### Approach
The approach to solve this problem involves iterating through each character of the string and constructing the result by checking each character against the last character added to the result. If the current character is the same as the last character in the result, it is skipped. Otherwise, it is added to the result. This method ensures that consecutive duplicates are removed in a single pass through the string, which is efficient and straightforward.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        s = sys.stdin.readline().strip()
        if not s:
            print('')
            continue
        res = [s[0]]
        for c in s[1:]:
            if c != res[-1]:
                res.append(c)
        print(''.join(res))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The number of test cases `T` is read first. For each test case, the string `S` is read.
2. **Processing Each String:** For each string, we initialize the result with the first character. Then, we iterate through the remaining characters of the string.
3. **Building the Result:** For each character, if it is different from the last character in the result list, it is added to the result. This ensures that consecutive duplicates are removed.
4. **Output:** The processed result for each test case is printed.

This approach efficiently processes the string in a single pass, resulting in an optimal solution with a time complexity of O(n) for each string, where n is the length of the string. This ensures the solution is both efficient and easy to understand.
