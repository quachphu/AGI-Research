To solve this problem, we need to determine the number of trailing zeros in the factorial of a given number \( N \) for multiple test cases. The trailing zeros in a factorial are produced by the factors 10, which are the product of 2 and 5. Since there are usually more factors of 2 than 5, the number of trailing zeros is determined by the number of times 5 is a factor in the numbers from 1 to \( N \).

### Approach
1. **Understanding Trailing Zeros**: The number of trailing zeros in \( N! \) is determined by the number of times 10 is a factor in \( N! \). Since 10 is the product of 2 and 5, and there are more factors of 2 than 5, the count of trailing zeros is determined by the number of times 5 is a factor in the sequence from 1 to \( N \).

2. **Counting Factors of 5**: For each number \( N \), we count the multiples of 5, 25, 125, etc. This is because numbers like 25 contribute two factors of 5, numbers like 125 contribute three factors of 5, and so on. The formula to compute the number of trailing zeros is given by the sum of integer divisions of \( N \) by 5, 25, 125, etc., until the divisor exceeds \( N \).

3. **Efficient Calculation**: For each test case, we repeatedly divide \( N \) by powers of 5 and sum the quotients. This approach ensures that we efficiently count the number of factors of 5 in \( N! \).

### Solution Code
```python
import sys

def count_trailing_zeros(n):
    count = 0
    divisor = 5
    while divisor <= n:
        count += n // divisor
        divisor *= 5
    return count

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        print(count_trailing_zeros(n))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads the number of test cases \( t \) and then processes each test case by reading the integer \( N \).

2. **Counting Trailing Zeros**: For each \( N \), the function `count_trailing_zeros` calculates the number of trailing zeros in \( N! \) by summing the integer divisions of \( N \) by increasing powers of 5 (5, 25, 125, etc.) until the divisor exceeds \( N \).

3. **Output**: The result for each test case is printed immediately after calculation, ensuring efficient handling of up to 10,000 test cases with large values of \( N \).

This approach efficiently computes the number of trailing zeros in \( N! \) using mathematical insights into factorial factors, ensuring optimal performance even for large values of \( N \).
