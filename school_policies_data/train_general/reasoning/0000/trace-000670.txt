To solve this problem, we need to find the greatest common divisor (GCD) of the sums of the beauty values of all permutations of chickens forming different numbers of cycles, modulo 998244353. The beauty value of a permutation is defined as the product of the smallest chicken size in each cycle of the permutation.

### Approach
1. **Sort the Chicken Sizes**: First, we sort the array of chicken sizes in non-decreasing order. This helps in systematically processing each chicken size in increasing order, which is crucial for determining the contribution of each size to the GCD.

2. **Compute GCD Contributions**: For each chicken size in the sorted list, compute the GCD of the chicken size and its 0-based index. This is because the contribution of each chicken size to the GCD of the sums of beauty values can be derived from the GCD of the chicken size and its position in the sorted list.

3. **Product of GCDs**: The final result is the product of all these individual GCD values, taken modulo 998244353. This product gives the GCD of all the sums of beauty values for permutations forming different numbers of cycles.

### Solution Code
```python
import math

n = int(input())
a = list(map(int, input().split()))
a.sort()
mod = 998244353
result = 1
for i in range(n):
    current_gcd = math.gcd(a[i], i)
    result = (result * current_gcd) % mod
print(result)
```

### Explanation
1. **Sorting**: Sorting the chicken sizes allows us to process each size in increasing order. This ensures that when we compute the GCD for each position, we correctly account for the contribution of each size relative to its position.

2. **GCD Calculation**: For each chicken size at position `i` (0-based index), we compute the GCD of the size and `i`. This GCD represents the contribution of the chicken size to the overall product that determines the GCD of the sums of beauty values.

3. **Modulo Operation**: Since the result can be very large, we take the product modulo 998244353 at each step to ensure the values remain manageable and fit within standard integer limits.

This approach efficiently computes the required GCD in O(N log N) time due to the sorting step, which is optimal for the problem constraints (N up to 100,000).
