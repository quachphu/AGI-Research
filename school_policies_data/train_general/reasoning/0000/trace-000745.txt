To solve this problem, we need to determine the maximum number of days Polycarp can train by solving exactly k problems on the k-th day using contests from a given list. Each contest can be used exactly once, and Polycarp must use a contest with at least k problems on the k-th day.

### Approach
1. **Sort the Contests**: First, sort the list of contests in non-decreasing order. This allows us to efficiently check the smallest contests first, ensuring we use the minimal required contests for each day.
2. **Greedy Selection**: Iterate through the sorted list and check each contest to see if it can be used for the current day. If a contest has enough problems for the current day, increment the day counter. This greedy approach ensures we maximize the number of days by using the smallest possible contests first.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
a.sort()
day = 1
for num in a:
    if num >= day:
        day += 1
print(day - 1)
```

### Explanation
1. **Sorting**: By sorting the contests in non-decreasing order, we can efficiently check each contest in sequence to see if it meets the requirement for the current day.
2. **Greedy Iteration**: We iterate through the sorted list, and for each contest, we check if it has enough problems for the current day. If it does, we move to the next day. This ensures that we use the smallest possible contests first, maximizing the number of days we can train.

This approach ensures that we efficiently determine the maximum number of days Polycarp can train with a time complexity of O(n log n) due to the sorting step, which is optimal for the given problem constraints.
