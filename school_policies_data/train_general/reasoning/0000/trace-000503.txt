To solve this problem, we need to extract the price of each order from a given string. The price is indicated by an integer following a '$' character, which may include spaces between the digits. Our task is to process each string to remove the spaces, form the integer, and then output it without leading zeros, except when the integer is zero.

### Approach
1. **Input Reading**: Read the number of orders and each order string.
2. **Splitting on '$'**: For each order string, split it into parts before and after the '$' character.
3. **Tokenizing the Price Part**: Split the part after the '$' into tokens based on spaces.
4. **Filtering Valid Tokens**: Collect tokens that are composed entirely of digits.
5. **Forming the Integer**: Concatenate the valid tokens to form the integer string.
6. **Removing Leading Zeros**: Strip leading zeros from the integer string. If the result is empty (all zeros), output '0'; otherwise, output the stripped string.

### Solution Code
```python
import sys

def process_orders():
    n = int(sys.stdin.readline())
    for _ in range(n):
        s = sys.stdin.readline().strip()
        _, after = s.split('$', 1)
        tokens = after.split()
        digits_tokens = [t for t in tokens if t.isdigit()]
        c_str = ''.join(digits_tokens)
        stripped = c_str.lstrip('0')
        print(f'${stripped}' if stripped else '$0')

process_orders()
```

### Explanation
1. **Reading Input**: The function starts by reading the number of orders and each subsequent order string.
2. **Splitting on '$'**: Each string is split into two parts using the '$' character. The part after '$' is processed further.
3. **Tokenizing**: The part after '$' is split into tokens based on spaces to handle spaces between digits.
4. **Filtering Tokens**: Only tokens that are entirely digits are kept to form the price string.
5. **Forming the Price String**: Valid tokens are concatenated to form the price string, ensuring all spaces are removed.
6. **Handling Leading Zeros**: Leading zeros are stripped from the price string. If the result is empty (indicating all zeros), '0' is printed; otherwise, the stripped string is printed.

This approach efficiently processes each string to extract the price, ensuring correct handling of spaces and leading zeros, providing the required output in the specified format.
