To solve this problem, we need to determine the index of a character whose removal will make a given string a palindrome. If the string is already a palindrome, we return -1. The solution involves checking for the first discrepancy from both ends of the string and then verifying which character's removal will result in a valid palindrome.

### Approach
1. **Check for Palindrome**: First, check if the given string is already a palindrome. If it is, return -1.
2. **Find Discrepancy**: Use two pointers starting from both ends of the string to find the first pair of characters that do not match.
3. **Check Removal Possibilities**: Once a discrepancy is found, check two possibilities:
   - Removing the character at the left pointer and checking if the resulting substring is a palindrome.
   - Removing the character at the right pointer and checking if the resulting substring is a palindrome.
4. **Return Result**: Based on the checks, return the index of the character whose removal results in a valid palindrome.

### Solution Code
```python
import sys

def is_palindrome(s, l, r):
    while l < r:
        if s[l] != s[r]:
            return False
        l += 1
        r -= 1
    return True

def find_palindrome_index(s):
    left = 0
    right = len(s) - 1
    while left < right:
        if s[left] != s[right]:
            if is_palindrome(s, left + 1, right):
                return left
            if is_palindrome(s, left, right - 1):
                return right
            return -2  # This line should theoretically never be reached per problem constraints
        left += 1
        right -= 1
    return -1

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        s = input[i]
        print(find_palindrome_index(s))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Palindrome Check**: The helper function `is_palindrome` checks if a substring (from index `l` to `r`) is a palindrome.
3. **Finding the Discrepancy**: Using two pointers, we move towards the center of the string until a mismatch is found.
4. **Checking Possibilities**: After finding a mismatch, we check both possibilities (removing the left or right character) to see which results in a valid palindrome.
5. **Output**: The result for each test case is printed immediately after processing.

This approach ensures that we efficiently determine the correct index with a time complexity of O(n) per test case, where n is the length of the string, making it suitable for large inputs up to the given constraints.
