To solve this problem, we need to determine the minimum total height of stools required such that each person in a row is at least as tall as everyone in front of them when standing on their respective stools. The solution involves iterating through the list of people's heights and dynamically adjusting the required stool heights to meet the given condition efficiently.

### Approach
1. **Initialization**: Start by reading the input values, which include the number of people and their respective heights.
2. **Track Maximum Height**: Maintain a variable to keep track of the maximum adjusted height (person's height + stool height) encountered so far.
3. **Calculate Required Stool Height**: For each subsequent person, calculate the minimum stool height required to ensure they are at least as tall as the tallest person in front of them. This is done by comparing their current height with the maximum adjusted height encountered so far.
4. **Update Maximum Height**: After determining the stool height for the current person, update the maximum adjusted height to include this person's new height (original height + stool height).

This approach ensures that we traverse the list of heights exactly once, resulting in an efficient O(N) time complexity, which is suitable given the problem constraints.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    sum_stools = 0
    if n == 0:
        print(0)
        return
    current_max = a[0]
    for num in a[1:]:
        req = max(current_max - num, 0)
        sum_stools += req
        current_max = num + req
    print(sum_stools)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go and split into a list of integers. The first integer is the number of people, and the subsequent integers are their respective heights.
2. **Initial Check**: If there are no people (though constraints ensure this won't happen), the function handles it gracefully by printing 0.
3. **Iterating Through Heights**: Starting from the second person, the code calculates the required stool height by comparing each person's height with the maximum adjusted height encountered so far. If the person's height is less than this maximum, the difference is added to the total stool height.
4. **Updating Maximum Height**: After determining the stool height for each person, their new height (original height + stool height) is used to update the maximum adjusted height for subsequent comparisons.

This method ensures that we efficiently compute the minimum total stool height required while adhering to the problem constraints, providing an optimal solution in linear time.
