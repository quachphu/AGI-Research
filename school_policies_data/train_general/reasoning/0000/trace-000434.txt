The encryption process involves repeatedly applying the key to overlapping windows of the message, which can be computationally intensive if done naively. Instead, we use a difference array technique to optimize the range updates, ensuring the solution runs efficiently even for large input sizes.

### Approach
1. **Problem Analysis**: The encryption process involves adding the key to each window of the message. Directly simulating each step would be too slow for large inputs, so we need an optimized approach.
2. **Key Insight**: Each element in the key affects a specific range of elements in the message. By determining these ranges, we can use a difference array to efficiently compute the cumulative effect of all key applications.
3. **Difference Array Technique**: This technique allows us to perform range updates in constant time. We maintain an array `delta` where we mark the start and end of each range affected by the key elements. After processing all key elements, we compute the prefix sum of the `delta` array to get the total effect on each message element.
4. **Modulo Operation**: Since all operations are performed modulo `c`, we apply the modulo after computing the cumulative sums to ensure the results are within the required range.
