To solve this problem, we need to determine the maximum number of games Hideo Kojima can leave in his CV such that no unsuccessful game (0) comes right after a successful game (1). The solution involves finding the optimal way to split the sequence of games into two parts: all unsuccessful games (0s) on the left and all successful games (1s) on the right.

### Approach
1. **Prefix and Suffix Arrays**: We will use two auxiliary arrays to precompute the number of 0s up to each index (prefix) and the number of 1s from each index to the end (suffix).
2. **Prefix Array (prefix_0)**: This array will store the cumulative count of 0s from the start up to each position.
3. **Suffix Array (suffix_1)**: This array will store the cumulative count of 1s from each position to the end.
4. **Maximize the Sum**: For each possible split point between 0 and the end of the array, compute the sum of 0s in the prefix and 1s in the suffix. The maximum sum across all split points will be the answer.

### Solution Code
```python
n = int(input())
s = list(map(int, input().split()))

prefix_0 = [0] * (n + 1)
for i in range(1, n + 1):
    prefix_0[i] = prefix_0[i-1] + (1 if s[i-1] == 0 else 0)

suffix_1 = [0] * (n + 1)
for i in range(n-1, -1, -1):
    suffix_1[i] = suffix_1[i+1] + (1 if s[i] == 1 else 0)

max_total = 0
for k in range(n + 1):
    current = prefix_0[k] + suffix_1[k]
    if current > max_total:
        max_total = current

print(max_total)
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` (number of games) followed by a list of integers representing the success (1) or failure (0) of each game.
2. **Prefix Array Calculation**: The `prefix_0` array is built such that each entry at index `i` represents the number of 0s from the start up to but not including index `i`.
3. **Suffix Array Calculation**: The `suffix_1` array is built such that each entry at index `i` represents the number of 1s from index `i` to the end of the list.
4. **Finding the Optimal Split**: By iterating over all possible split points (from 0 to `n`), we compute the sum of 0s in the prefix and 1s in the suffix for each split. The maximum value of these sums gives the solution.

This approach ensures that we efficiently compute the maximum number of games that can be left in the CV while adhering to the given constraints, using precomputed prefix and suffix sums for optimal performance.
