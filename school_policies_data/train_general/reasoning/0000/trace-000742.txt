To solve this problem, we need to determine if a given word adheres to the Berlanese language rules. Specifically, every consonant (except 'n') must be followed by a vowel, and the last character cannot be a consonant unless it is 'n'.

### Approach
1. **Identify Vowels**: Define the set of vowels which includes 'a', 'e', 'i', 'o', and 'u'.
2. **Check Each Character**: Iterate through each character of the input string.
   - If the current character is a consonant (not a vowel and not 'n'), check if the next character is a vowel.
   - If the current character is the last character and is a consonant (not a vowel and not 'n'), the word is invalid.
3. **Immediate Termination**: If any check fails, immediately print "NO" and exit. If all checks pass, print "YES".

### Solution Code
```python
def check_berlanese():
    s = input().strip()
    vowels = {'a', 'e', 'i', 'o', 'u'}
    for i in range(len(s)):
        current = s[i]
        if current not in vowels and current != 'n':
            if i == len(s) - 1:
                print("NO")
                return
            next_char = s[i + 1]
            if next_char not in vowels:
                print("NO")
                return
    print("YES")

check_berlanese()
```

### Explanation
- **Vowel Set**: The set of vowels is used to quickly check if a character is a vowel.
- **Loop Through Characters**: For each character in the string, we check if it is a consonant (not a vowel and not 'n').
  - If it is a consonant and the last character, the word is invalid.
  - If it is a consonant followed by another consonant, the word is invalid.
- **Immediate Checks**: The function exits immediately upon finding an invalid condition to avoid unnecessary checks.

This approach ensures that all characters are checked efficiently, adhering to the constraints and rules of the Berlanese language.
