      class DSU:
          def __init__(self, size):
              self.parent = list(range(size+1))  # 1-based indexing

          def find(self, x):
              if self.parent[x] != x:
                  self.parent[x] = self.find(self.parent[x])
              return self.parent[x]

          def union(self, x, y):
              x_root = self.find(x)
              y_root = self.find(y)
              if x_root != y_root:
                  self.parent[y_root] = x_root

To solve this problem, we need to determine if an array can be sorted using a specific set of allowed adjacent swaps. The approach involves analyzing the connected components formed by these allowed swaps and verifying if each component can be rearranged to match the sorted array.

### Approach
1. **Union-Find Data Structure**: We use a union-find (disjoint set union) data structure to identify connected components of positions that can be swapped. Each allowed swap connects two positions, forming edges in a graph.
2. **Connected Components**: After processing all allowed swaps, we determine the connected components of the positions. These components represent groups of positions that can be freely rearranged among themselves.
3. **Component Comparison**: For each connected component, we check if the elements in the original array can be rearranged to match the corresponding elements in the sorted array. This is done by comparing the sorted list of elements in each component from both the original and sorted arrays.

### Solution Code
```python
import sys
from collections import defaultdict

class DSU:
    def __init__(self, size):
        self.parent = list(range(size + 1))  # 1-based indexing

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root != y_root:
            self.parent[y_root] = x_root

def can_sort(n, m, a, p):
    dsu = DSU(n)
    for pos in p:
        dsu.union(pos, pos + 1)
    components = defaultdict(list)
    for i in range(1, n + 1):
        root = dsu.find(i)
        components[root].append(i)
    sorted_a = sorted(a)
    for comp in components.values():
        original = [a[i-1] for i in comp]
        sorted_part = [sorted_a[i-1] for i in comp]
        if sorted(original) != sorted(sorted_part):
            return False
    return True

t = int(sys.stdin.readline())
for _ in range(t):
    n, m = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    p = list(map(int, sys.stdin.readline().split()))
    if can_sort(n, m, a, p):
        print("YES")
    else:
        print("NO")
```
