To solve this problem, we need to count the number of subarrays within given ranges whose XOR equals a specific value. The solution leverages prefix XOR and efficient range queries using binary search to handle large input sizes efficiently.

### Approach
1. **Prefix XOR Array**: Compute a prefix XOR array where each element at index `i` represents the XOR of all elements from the start of the array up to index `i-1`.
2. **Frequency Dictionary**: Maintain a dictionary to track the indices where each prefix XOR value occurs. This helps in quickly determining the count of specific values in any range.
3. **Precompute Valid Subarrays**: For each position, precompute the count of valid subarrays ending at that position using a frequency map.
4. **Prefix Sum Array**: Use a prefix sum array to quickly compute the sum of valid subarray counts over any range.
5. **Efficient Range Queries**: For each query, use binary search on the precomputed indices to determine the count of valid subarrays within the specified range.

### Solution Code
```python
import bisect
from collections import defaultdict

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    m = int(input[ptr])
    ptr += 1
    k = int(input[ptr])
    ptr += 1
    a = list(map(int, input[ptr:ptr+n]))
    ptr += n
    
    # Compute prefix_xor array
    prefix_xor = [0] * (n + 1)
    for i in range(1, n + 1):
        prefix_xor[i] = prefix_xor[i - 1] ^ a[i - 1]
    
    # Build a dictionary mapping each value in prefix_xor to its list of indices
    prefix_xor_indices = defaultdict(list)
    for idx in range(n + 1):
        prefix_xor_indices[prefix_xor[idx]].append(idx)
    
    # Precompute y_x for each x
    y_x_array = [0] * (n + 1)
    for x in range(n + 1):
        y_x_array[x] = prefix_xor[x] ^ k
    
    # Compute S and pre_sum
    freq = defaultdict(int)
    freq[prefix_xor[0]] = 1  # Initialize with prefix_xor[0] = 0
    S = [0] * (n + 1)  # S[0] is unused since x starts from 1
    for x in range(1, n + 1):
        y_x = y_x_array[x]
        S[x] = freq.get(y_x, 0)
        current_v = prefix_xor[x]
        freq[current_v] += 1
    
    # Compute prefix sum of S
    pre_sum = [0] * (n + 1)
    for x in range(1, n + 1):
        pre_sum[x] = pre_sum[x - 1] + S[x]
    
    # Process each query
    output = []
    for _ in range(m):
        L = int(input[ptr])
        ptr += 1
        R = int(input[ptr])
        ptr += 1
        sum_first = pre_sum[R] - pre_sum[L - 1]
        sum_second = 0
        # Precompute L-2 to avoid repeated computation
        L_minus_2 = L - 2
        # Iterate over each x in [L, R]
        for x in range(L, R + 1):
            y_x = y_x_array[x]
            indices = prefix_xor_indices.get(y_x, [])
            cnt = bisect.bisect_right(indices, L_minus_2)
            sum_second += cnt
        ans = sum_first - sum_second
        output.append(str(ans))
    
    print('\n'.join(output))
    
if __name__ == '__main__':
    main()
```

### Explanation
1. **Prefix XOR Array**: This array helps in quickly computing the XOR of any subarray using the property that the XOR of elements from index `i` to `j` is `prefix_xor[j+1] ^ prefix_xor[i]`.
2. **Frequency Dictionary**: This dictionary maps each XOR value to the list of indices where it occurs, allowing efficient range queries using binary search.
3. **Precompute Valid Subarrays**: By maintaining a frequency map, we can track how many times each XOR value has been seen up to each index, enabling quick count lookups.
4. **Prefix Sum Array**: This array allows us to compute the sum of valid subarray counts over any range in constant time.
5. **Efficient Range Queries**: For each query, we use binary search on the precomputed indices to determine the count of valid subarrays within the specified range, ensuring efficient handling of large input sizes.
