import sys
from collections import deque

def main():
    N = int(sys.stdin.readline())
    if N % 2 != 0:
        print("First")
        return

    # Build adjacency list
    adj = [[] for _ in range(N+1)]
    for _ in range(N-1):
        a, b = map(int, sys.stdin.readline().split())
        adj[a].append(b)
        adj[b].append(a)

    # Track degrees
    degrees = [0] * (N+1)
    for i in range(1, N+1):
        degrees[i] = len(adj[i])

    q = deque()
    for i in range(1, N+1):
        if degrees[i] == 1:
            q.append(i)

    matched = [False] * (N+1)
    matched_pairs = 0

    while q:
        leaf = q.popleft()
        if matched[leaf]:
            continue
        # Find parent (the only neighbor not matched)
        for parent in adj[leaf]:
            if not matched[parent]:
                break
        else:
            # No parent available, can't pair
            print("First")
            return
        # Check if parent is already matched
        if matched[parent]:
            print("First")
            return
        # Match leaf and parent
        matched[leaf] = True
        matched[parent] = True
        matched_pairs += 1
        # Update degrees of parent's neighbors
        for neighbor in adj[parent]:
            degrees[neighbor] -= 1
            if degrees[neighbor] == 1 and not matched[neighbor]:
                q.append(neighbor)

    if matched_pairs == N // 2:
        print("Second")
    else:
        print("First")

if __name__ == "__main__":
    main()

To solve this problem, we need to determine the winner of a game played on a tree where two players, Takahashi and Aoki, alternately paint vertices white and black, respectively. The winner is determined by whether any white vertices remain after repainting all white vertices adjacent to black vertices.

### Approach
The key insight is to determine if the tree has a perfect matching. If it does, Aoki (the second player) can win by mirroring Takahashi's moves. Otherwise, Takahashi (the first player) will win. A perfect matching in a tree means every vertex can be paired such that each pair is connected by an edge and all vertices are included in the pairs.

1. **Check Tree Parity**: If the number of vertices (N) is odd, Takahashi wins immediately because a perfect matching is impossible.
2. **Greedy Matching Algorithm**: For even N, use a greedy algorithm to check for a perfect matching by pairing leaves with their parents. If all vertices can be paired, Aoki wins; otherwise, Takahashi wins.

### Solution Code
```python
import sys
from collections import deque

def main():
    N = int(sys.stdin.readline())
    if N % 2 != 0:
        print("First")
        return

    # Build adjacency list
    adj = [[] for _ in range(N+1)]
    for _ in range(N-1):
        a, b = map(int, sys.stdin.readline().split())
        adj[a].append(b)
        adj[b].append(a)

    # Track degrees
    degrees = [0] * (N+1)
    for i in range(1, N+1):
        degrees[i] = len(adj[i])

    q = deque()
    for i in range(1, N+1):
        if degrees[i] == 1:
            q.append(i)

    matched = [False] * (N+1)
    matched_pairs = 0

    while q:
        leaf = q.popleft()
        if matched[leaf]:
            continue
        # Find parent (the only neighbor not matched)
        parent = None
        for p in adj[leaf]:
            if not matched[p]:
                parent = p
                break
        if parent is None:
            print("First")
            return
        if matched[parent]:
            print("First")
            return
        # Match leaf and parent
        matched[leaf] = True
        matched[parent] = True
        matched_pairs += 1
        # Update degrees of parent's neighbors
        for neighbor in adj[parent]:
            degrees[neighbor] -= 1
            if degrees[neighbor] == 1 and not matched[neighbor]:
                q.append(neighbor)

    if matched_pairs == N // 2:
        print("Second")
    else:
        print("First")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Tree Parity Check**: If the number of vertices is odd, a perfect matching is impossible, so Takahashi wins.
2. **Greedy Matching**: For even N, we use a queue to process leaves (vertices with degree 1). Each leaf is paired with its parent. If any step cannot pair a leaf with its parent, it indicates no perfect matching exists, so Takahashi wins. If all vertices are paired successfully, Aoki wins.

This approach efficiently checks for a perfect matching using a breadth-first search (BFS) strategy, ensuring the solution runs in linear time, which is optimal for large trees up to 100,000 vertices.
