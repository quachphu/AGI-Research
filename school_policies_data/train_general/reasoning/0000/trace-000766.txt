To solve this problem, we need to determine the minimum possible sum of the remaining cards after Limak potentially discards two or three cards with the same number. The solution involves analyzing the frequency of each number and calculating the optimal deduction to minimize the sum.

### Approach
1. **Calculate Total Sum**: Start by computing the total sum of all five cards.
2. **Frequency Count**: Use a frequency counter to determine how many times each number appears on the cards.
3. **Determine Maximum Deduction**: For each unique number, check how many times it appears. If it appears at least twice, compute the maximum possible deduction by considering both two and three cards (if applicable). The maximum deduction is the higher value between removing two or three cards.
4. **Compute Minimum Sum**: Subtract the maximum deduction from the total sum to get the minimum possible sum of the remaining cards.

### Solution Code
```python
import sys
from collections import Counter

def main():
    cards = list(map(int, sys.stdin.readline().split()))
    total = sum(cards)
    counts = Counter(cards)
    max_deduction = 0
    for num, cnt in counts.items():
        possible = 0
        if cnt >= 2:
            possible = 2 * num
        if cnt >= 3:
            possible = max(possible, 3 * num)
        if possible > max_deduction:
            max_deduction = possible
    print(total - max_deduction)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read as a list of integers.
2. **Total Sum Calculation**: The total sum of all cards is computed initially.
3. **Frequency Analysis**: Using `Counter` from the `collections` module, we count the occurrences of each number.
4. **Deduction Calculation**: For each number, based on its frequency, we determine the best possible deduction by considering both two and three cards if applicable. The maximum valid deduction is tracked.
5. **Result Calculation**: The maximum deduction is subtracted from the total sum to get the minimum possible sum, which is then printed.

This approach efficiently determines the optimal cards to discard by leveraging frequency counts and maximizing the deduction, ensuring the solution is both optimal and runs in linear time relative to the input size.
