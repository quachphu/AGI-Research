To solve this problem, we need to determine the maximum value of the function \( f(s) \) for a binary string \( s \) of length \( n \) containing exactly \( m \) '1's. The function \( f(s) \) counts the number of substrings that contain at least one '1'. 

### Approach
1. **Understanding the Problem**: The function \( f(s) \) can be derived by subtracting the number of substrings consisting entirely of '0's from the total number of substrings of \( s \). The total number of substrings of a string of length \( n \) is \( \frac{n(n+1)}{2} \).

2. **Key Insight**: To maximize \( f(s) \), we need to minimize the number of substrings of '0's. This is achieved by distributing the '0's as evenly as possible between the '1's. If there are \( m \) '1's, they split the string into \( m+1 \) blocks of '0's. 

3. **Mathematical Formulation**:
   - Calculate the total number of substrings.
   - Determine the number of zeros and how they are distributed into blocks.
   - Compute the number of substrings in each block of zeros and sum these values.
   - Subtract the sum of zero substrings from the total substrings to get \( f(s) \).

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    t = int(input[0])
    idx = 1
    for _ in range(t):
        n = int(input[idx])
        m = int(input[idx+1])
        idx += 2
        if m == 0:
            print(0)
            continue
        zeros = n - m
        if zeros == 0:
            total = n * (n + 1) // 2
            print(total)
            continue
        num_blocks = m + 1
        a = zeros // num_blocks
        r = zeros % num_blocks
        sum_zero = r * (a + 1) * (a + 2) // 2 + (num_blocks - r) * a * (a + 1) // 2
        total_substrings = n * (n + 1) // 2
        print(total_substrings - sum_zero)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
- **Handling Edge Cases**: If there are no '1's (m=0), the result is 0 since all substrings are '0's.
- **Total Substrings Calculation**: The total number of substrings of length \( n \) is computed using \( \frac{n(n+1)}{2} \).
- **Zero Distribution**: The zeros are divided into \( m+1 \) blocks. Using integer division and modulo operations, we determine the size of each block to ensure even distribution.
- **Summing Zero Substrings**: For each block of zeros, the number of substrings is calculated using the formula \( \frac{k(k+1)}{2} \) where \( k \) is the length of the block. The sum of these values is subtracted from the total substrings to get the maximum \( f(s) \).

This approach ensures that the solution is efficient and handles up to the maximum constraints effectively.
