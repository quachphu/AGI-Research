To solve this problem, we need to find the maximum subset of points such that the distance between any two points is non-integer. The key insight is to use the properties of integer coordinates and the distances between points to construct a valid solution.

### Approach
The solution is based on the observation that if we select points along the line \( x + y = k \), where \( k \) is the minimum of the given dimensions \( n \) and \( m \), we can ensure that the distance between any two points in this subset is non-integer. This is because the differences in coordinates between any two points on this line will result in a sum of squares that is not a perfect square.

### Solution Code
```python
n, m = map(int, input().split())
k = min(n, m)
points = [(x, k - x) for x in range(k + 1)]
print(len(points))
for p in points:
    print(p[0], p[1])
```

1. **Input Handling**: Read the integers \( n \) and \( m \).

3. **Generate Points**: Create points along the line \( x + y = k \) by iterating \( x \) from 0 to \( k \) and setting \( y \) to \( k - x \).
4. **Output**: Print the number of points and each point's coordinates.
