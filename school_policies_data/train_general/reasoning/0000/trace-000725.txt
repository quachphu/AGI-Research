To solve this problem, we need to determine if a three-digit integer formed by three given digits (red, green, and blue) is a multiple of 4. The key insight here is that a number is divisible by 4 if its last two digits form a number that is divisible by 4.

### Approach
1. **Read Input**: The input consists of three integers representing the digits on the red, green, and blue cards.
2. **Form the Last Two Digits**: Combine the digits from the green and blue cards to form a two-digit number.
3. **Check Divisibility**: Check if this two-digit number is divisible by 4. If it is, the three-digit number formed by all three digits is also divisible by 4.

### Solution Code
```python
def main():
    r, g, b = map(int, input().split())
    two_digit = 10 * g + b
    print("YES" if two_digit % 4 == 0 else "NO")

main()
```

### Explanation
1. **Reading Input**: The input is read as three integers separated by spaces. These integers represent the digits on the red, green, and blue cards.
2. **Forming the Two-Digit Number**: The green digit is multiplied by 10 and added to the blue digit to form the last two digits of the three-digit number.
3. **Checking Divisibility**: Using modulo operation, we check if the two-digit number formed is divisible by 4. If it is, the three-digit number is a multiple of 4, and we print "YES"; otherwise, we print "NO".

This approach efficiently checks the divisibility by focusing on the last two digits, leveraging the mathematical property that a number is divisible by 4 if and only if its last two digits form a number that is divisible by 4. This reduces the problem to a simple check on the last two digits, making the solution both optimal and easy to implement.
