To solve this problem, we need to connect spaceships to bases such that the line segments between them do not intersect. The solution involves using a geometric approach to ensure non-crossing segments by sorting the points based on their polar angles around a common reference point.

### Approach
1. **Identify the Reference Point (O):** Find the point with the smallest y-coordinate (and leftmost in case of ties) among all spaceships and bases. This point serves as the reference for calculating polar angles.
2. **Calculate Polar Angles:** For each spaceship and base, compute the polar angle around the reference point O. The polar angle helps in determining the order of points around O.
3. **Sort Points by Polar Angles:** Sort both the spaceships and bases based on their polar angles around O. This ensures that when paired in the same order, the resulting segments do not intersect.
4. **Pair Spaceships and Bases:** Pair the i-th spaceship in the sorted list with the i-th base in the sorted list. This pairing ensures non-crossing segments due to the angular ordering.

import sys
import math

def main():

    ptr = 0
    N = int(input[ptr])

        x = int(input[ptr])
        y = int(input[ptr + 1])
        ptr += 2

    bases = []

        x = int(input[ptr])
        y = int(input[ptr + 1])
        ptr += 2

    # Find O: the point with the smallest y, then smallest x among all points
    all_points = ships + bases
    min_y = min(p[1] for p in all_points)

        x, y, idx = point

    ships_sorted = sorted(ships, key=compute_angle)
    bases_sorted = sorted(bases, key=compute_angle)

    pairs = {}
    for s, b in zip(ships_sorted, bases_sorted):
