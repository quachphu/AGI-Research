To solve this problem, we need to determine the minimum number of attacks required to defeat a monster using a combination of wielding and throwing katanas. The goal is to minimize the total number of attacks while ensuring the total damage inflicted meets or exceeds a given threshold, H.

### Approach
1. **Identify Key Variables**: The maximum damage from wielding any katana once (max_a) is crucial. This value helps determine the optimal strategy between throwing and wielding.
2. **Sort and Filter Katanas**: Collect all katanas that deal more damage when thrown than the maximum damage from wielding (max_a). These katanas are sorted in descending order of their throwing damage (b_i).
3. **Prefix Sum Calculation**: Compute prefix sums of the sorted throwing damages to efficiently evaluate the cumulative damage from throwing multiple katanas.
4. **Evaluate All Scenarios**: For each possible number of thrown katanas (from 0 to all), calculate the remaining damage needed and determine the minimum number of wielding attacks required using the highest possible wield damage (max_a).

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    H = int(input[idx])
    idx += 1

    a = []
    b = []
    for _ in range(N):
        ai = int(input[idx])
        bi = int(input[idx + 1])
        a.append(ai)
        b.append(bi)
        idx += 2

    max_a = max(a)
    B = [bi for bi in b if bi > max_a]
    B.sort(reverse=True)

    # Compute prefix sums
    prefix = [0] * (len(B) + 1)
    for i in range(len(B)):
        prefix[i + 1] = prefix[i] + B[i]

    min_attacks = float('inf')

    for k in range(0, len(B) + 1):
        current_sum = prefix[k]
        if current_sum >= H:
            attacks = k
        else:
            remaining = H - current_sum
            attacks = k + (remaining + max_a - 1) // max_a

        if attacks < min_attacks:
            min_attacks = attacks

    print(min_attacks)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed to extract the number of katanas (N), the damage threshold (H), and the respective wield and throw damages for each katana.
2. **Determine Max Wield Damage**: The maximum damage from wielding any katana once (max_a) is calculated.
3. **Filter and Sort**: Katanas that deal more damage when thrown than max_a are filtered and sorted in descending order based on their throw damage.
4. **Prefix Sums**: A prefix sum array is created to quickly compute the cumulative damage from throwing the top k katanas.
5. **Evaluate Each Scenario**: For each possible number of thrown katanas (from 0 to all), the total damage and remaining required damage are calculated. The remaining damage is then covered using the maximum wield damage, and the total number of attacks is minimized.

This approach efficiently balances between using high-damage throws and the best possible wielding strategy, ensuring the solution is optimal and runs in a reasonable time complexity for large inputs.
