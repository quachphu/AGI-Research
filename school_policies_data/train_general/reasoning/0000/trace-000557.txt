To solve this problem, we need to find the substring that appears in the maximum number of input strings. If there are multiple such substrings, we choose the shortest one, and if there are still ties, we select the lexicographically smallest one.

### Approach
1. **Read Input**: Read the number of test cases and the input strings for each test case.
2. **Generate Substrings**: For each input string, generate all possible substrings and track the count of how many input strings each substring appears in.
3. **Track Counts**: Use a dictionary to count the occurrences of each substring across all input strings.
4. **Determine the Optimal Substring**: Sort the substrings based on their count (descending), length (ascending), and lexicographical order (ascending) to find the optimal substring.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        strings = []
        for _ in range(N):
            s = input[ptr].strip()
            ptr += 1
            strings.append(s)
        
        substring_counts = defaultdict(int)
        
        for s in strings:
            substrings = set()
            n = len(s)
            for i in range(n):
                for j in range(i, n):
                    substrings.add(s[i:j+1])
            for substr in substrings:
                substring_counts[substr] += 1
        
        if not substring_counts:
            print('')
            continue
        
        # Convert to list of tuples (substring, count)
        candidates = list(substring_counts.items())
        # Sort by: -count, len(substring), substring
        candidates.sort(key=lambda x: (-x[1], len(x[0]), x[0]))
        
        print(candidates[0][0])

if __name__ == "__main__":
    main()
```

2. **Generating Substrings**: For each input string, all possible substrings are generated and stored in a set to avoid duplicates within the same string.
3. **Counting Occurrences**: A dictionary is used to count how many input strings each substring appears in. This is done by iterating over each substring of each input string and incrementing the corresponding count in the dictionary.
4. **Sorting and Selecting the Optimal Substring**: The substrings are sorted based on their count (highest first), length (shortest first), and lexicographical order (smallest first). The first element after sorting is the desired result.
