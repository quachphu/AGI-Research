To solve this problem, we need to determine the number of trailing zeros in the factorial of a given integer \( n \) for multiple inputs until the input is 0. The trailing zeros in a factorial result from the product of factors 2 and 5, with the number of 5s being the limiting factor. Thus, the solution involves counting the number of times 5 appears in the prime factors of the numbers from 1 to \( n \).

### Approach
1. **Understanding Trailing Zeros**: The number of trailing zeros in \( n! \) is determined by the number of times 10 is a factor in the product sequence. Since 10 is the product of 2 and 5, and there are typically more 2s than 5s in the factorial's prime factors, the count of trailing zeros is determined by the count of 5s.
2. **Counting Factors of 5**: For each number \( n \), we count the multiples of 5, 25, 125, etc., because each contributes at least one 5. For example, 25 (which is \( 5^2 \)) contributes two 5s.
3. **Summing the Counts**: Sum the counts of 5s from all these multiples to get the total number of trailing zeros.

### Solution Code
```python
import sys

def count_trailing_zeros(n):
    count = 0
    divisor = 5
    while divisor <= n:
        count += n // divisor
        divisor *= 5
    return count

for line in sys.stdin:
    n = int(line.strip())
    if n == 0:
        break
    print(count_trailing_zeros(n))
```

### Explanation
1. **Reading Input**: The code reads each line from standard input until it encounters a 0, which signals the end of input.
2. **Counting Trailing Zeros**: For each input \( n \), the function `count_trailing_zeros` calculates the number of trailing zeros by iteratively dividing \( n \) by increasing powers of 5 (5, 25, 125, etc.) and summing the quotients.
3. **Output**: For each valid input (non-zero), the computed number of trailing zeros is printed.

This approach efficiently computes the trailing zeros by focusing on the factors of 5, ensuring optimal performance even for the upper limit of \( n = 20000 \). The complexity is \( O(\log_5 n) \) per input, which is very efficient.
