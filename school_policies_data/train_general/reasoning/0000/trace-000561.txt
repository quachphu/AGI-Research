To solve this problem, we need to determine the minimum and maximum possible numbers of different colors among users based on their ratings. Users with a rating of 3200 or higher can choose any color, while others have their color determined by specific rating ranges.

### Approach
1. **Categorize Users**: Separate users into two groups: those with ratings below 3200 (fixed colors) and those with ratings 3200 or higher (free to choose any color).
2. **Determine Fixed Colors**: For users with ratings below 3200, determine their color based on predefined ranges and collect these colors in a set to avoid duplicates.
3. **Count Free Users**: Count the number of users who can freely choose their color (rating 3200 or higher).
4. **Calculate Minimum Colors**: The minimum number of colors is determined by the fixed colors if there are no free users. If there are free users, they can choose existing fixed colors, or if there are no fixed colors, they can all choose the same color.
5. **Calculate Maximum Colors**: The maximum number of colors is the sum of the number of fixed colors and the number of free users, as each free user can choose a unique color.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))

fixed_colors = set()
free_count = 0

for num in a:
    if num >= 3200:
        free_count += 1
    else:
        if num < 400:
            color = 'gray'
        elif num < 800:
            color = 'brown'
        elif num < 1200:
            color = 'green'
        elif num < 1600:
            color = 'cyan'
        elif num < 2000:
            color = 'blue'
        elif num < 2400:
            color = 'yellow'
        elif num < 2800:
            color = 'orange'
        else:  # num < 3200
            color = 'red'
        fixed_colors.add(color)

k = len(fixed_colors)
m = free_count

if m == 0:
    min_val = k
    max_val = k
else:
    min_val = k if k != 0 else 1
    max_val = k + m

print(min_val, max_val)
```

### Explanation
1. **Input Handling**: Read the number of users and their ratings.
2. **Categorization**: For each rating, determine if it's a fixed color or a free user. Collect fixed colors in a set to ensure uniqueness.
3. **Color Determination**: Fixed colors are determined based on specific ranges. Free users are counted separately.
4. **Minimum Calculation**: If there are no free users, the minimum is the number of unique fixed colors. If there are free users, the minimum is the number of fixed colors unless there are none, in which case it's 1.
5. **Maximum Calculation**: The maximum is the number of fixed colors plus the number of free users, as each free user can contribute a unique color.

This approach efficiently categorizes users and calculates the required values using set operations and simple arithmetic, ensuring optimal performance given the problem constraints.
