To solve this problem, we need to compute the sum of the greatest odd divisors (GOD) for all integers from 1 to a given number X for multiple test cases efficiently. Given the constraints where X can be as large as 1 billion, a brute force approach is infeasible, so we use a mathematical approach and recursion with memoization to optimize the solution.

### Approach
1. **Understanding GOD**: For any even number, the GOD is the same as the GOD of that number divided by 2. For any odd number, the GOD is the number itself.
2. **Recursive Formula**: The sum of GODs from 1 to X can be broken down using a recursive approach:
   - If X is even, the sum is the sum of the squares of the first X/2 odd numbers plus the sum of GODs of the numbers from 1 to X/2.
   - If X is odd, the sum is the sum of the squares of the first (X+1)/2 odd numbers plus the sum of GODs of the numbers from 1 to (X-1)/2.
3. **Memoization**: Use memoization to store intermediate results and avoid redundant calculations, which significantly speeds up the recursive solution.

### Solution Code
```python
import sys
from functools import lru_cache

@lru_cache(maxsize=None)
def compute_sum(X):
    if X == 0:
        return 0
    if X % 2 == 0:
        k = X // 2
        return k * k + compute_sum(k)
    else:
        k = (X + 1) // 2
        return k * k + compute_sum(k - 1)

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    for x in input[1:T+1]:
        X = int(x)
        print(compute_sum(X))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings for efficient processing.
2. **Recursive Function with Memoization**: The `compute_sum` function uses memoization to store results of previously computed sums, reducing redundant calculations. For each X, it checks if X is even or odd and applies the respective recursive formula to compute the sum.
3. **Handling Even and Odd Cases**: 
   - For even X, the sum of the first X/2 odd numbers is (X/2)² and the sum of GODs of numbers up to X/2 is computed recursively.
   - For odd X, the sum of the first (X+1)/2 odd numbers is ((X+1)/2)² and the sum of GODs of numbers up to (X-1)/2 is computed recursively.

This approach ensures that each number is processed in logarithmic time relative to its value, making the solution efficient even for the upper constraint limits.
