To solve this problem, we need to determine the minimum number of holes Arkady should block in a watering system to ensure that at least B liters of water flow out of the first hole when A liters of water are poured into the system. The solution involves calculating the required sum of the sizes of the unblocked holes to achieve the desired water flow and blocking the largest holes if necessary.

### Approach
1. **Understand the Water Flow Formula**: The water flow from the first hole is given by \((s_1 \cdot A) / S\), where \(s_1\) is the size of the first hole and \(S\) is the sum of the sizes of all unblocked holes. We need this value to be at least B.
2. **Calculate Required Sum**: Rearrange the formula to find the maximum allowable sum \(S\) of the unblocked holes, which is \((s_1 \cdot A) / B\). The sum of the other unblocked holes must be at most \(S - s_1\).
3. **Check Initial Condition**: If the initial sum of the other holes is already within the allowable limit, no holes need to be blocked.
4. **Block Largest Holes**: If the initial sum exceeds the allowable limit, sort the other holes in descending order and iteratively block the largest holes until the sum of the remaining holes meets the requirement.

### Solution Code
```python
n, A, B = map(int, input().split())
s = list(map(int, input().split()))
s1 = s[0]
others = s[1:]
sum_rest = sum(others)
required = (s1 * A) / B - s1

if sum_rest <= required + 1e-9:
    print(0)
else:
    others_sorted = sorted(others, reverse=True)
    current_sum = sum_rest
    blocked = 0
    for num in others_sorted:
        current_sum -= num
        blocked += 1
        if current_sum <= required + 1e-9:
            break
    print(blocked)
```

### Explanation
1. **Reading Input**: The input consists of the number of holes, the volume of water, the desired volume from the first hole, and the sizes of the holes.
2. **Initial Calculations**: Calculate the sum of the sizes of the holes excluding the first one. Determine the maximum allowable sum of these holes to ensure the first hole meets the required water flow.
3. **Check Condition**: If the initial sum of the other holes is within the allowable limit, immediately output 0 as no holes need to be blocked.
4. **Blocking Holes**: If blocking is necessary, sort the other holes by size in descending order. Iteratively subtract the largest holes from the sum until the remaining sum meets the requirement, counting the number of blocked holes.

This approach efficiently determines the minimum number of holes to block by leveraging sorting and a greedy algorithm to maximize the reduction in the sum of the hole sizes, ensuring optimal performance even for large inputs.
