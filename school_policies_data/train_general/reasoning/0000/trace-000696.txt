To solve this problem, we need to determine how many ways Dima can show fingers such that he does not end up being the one to clean the apartment. The solution involves calculating the total number of fingers shown by all participants and using modular arithmetic to determine if Dima is selected.

### Approach
1. **Input Reading**: Read the number of friends and the fingers they show.
2. **Sum Calculation**: Compute the sum of the fingers shown by Dima's friends.
3. **Modular Arithmetic Check**: For each possible number of fingers Dima can show (from 1 to 5), calculate the total fingers and use modular arithmetic to check if Dima is selected. If not, count this as a valid way.

### Solution Code
```python
n = int(input())
friends = list(map(int, input().split()))
s = sum(friends)
m = n + 1
count = 0
for x in range(1, 6):
    total = s + x
    if (total - 1) % m != 0:
        count += 1
print(count)
```

### Explanation
1. **Input Reading**: The first line of input is the number of friends, and the second line contains the fingers shown by each friend.
2. **Sum Calculation**: We sum the fingers shown by all friends to get the initial sum `s`.
3. **Modular Check**: For each possible value of fingers Dima can show (1 to 5), we compute the total fingers and check if the result of `(total - 1) % (n + 1)` is zero. If it is zero, Dima is selected to clean; otherwise, he is not. We count the valid values where Dima is not selected.

This approach efficiently checks each possibility using modular arithmetic, ensuring we correctly determine the valid ways Dima can avoid cleaning. The solution runs in constant time, O(1), since the loop iterates exactly 5 times regardless of input size.
