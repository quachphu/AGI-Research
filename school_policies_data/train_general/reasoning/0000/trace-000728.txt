### Approach
The approach involves using a max-heap to keep track of the highest counts efficiently. Each time a participant's count changes, we push the new count into the heap. When querying the maximum count, we validate the entries in the heap to ensure they reflect the current counts. This "lazy" validation ensures that we efficiently find the current maximum without needing to update the heap for every change.

import heapq

def main():
    import sys

    index += 1
    q = int(data[index])
    index += 1

    heap = []

        ai = int(data[index])
        index += 1
        vi = int(data[index])
        index += 1
        
        counts[ai] += vi
        heapq.heappush(heap, (-counts[ai], ai))
        
        current_ai = None
        current_count = None
        
        while True:
            if not heap:
                # This case should theoretically not happen since we push after each event
                current_count = 0
                current_ai = 1
                for i in range(1, n + 1):
                    if counts[i] > current_count or (counts[i] == current_count and i < current_ai):
                        current_count = counts[i]
                        current_ai = i
                break

            candidate_count = -current_neg_count
