To solve this problem, we need to help Kefa invite an optimal group of friends to a restaurant such that none of them feels poor, while maximizing the total friendship factor. A friend feels poor if there is someone in the group who has at least `d` units of money more than them. 

### Approach
1. **Sort the Friends**: First, we sort the friends based on their money. This allows us to efficiently determine valid groups using a sliding window technique.
2. **Sliding Window Technique**: We use a two-pointer approach to maintain a window of friends where the difference between the maximum and minimum money in the window is less than `d`. This ensures no one feels poor.
3. **Maximize Friendship Factor**: As we adjust the window using the two pointers, we maintain a running sum of the friendship factors within the window and update the maximum sum encountered.

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    d = int(input[idx + 1])
    idx += 2

    for _ in range(n):
        m = int(input[idx])
