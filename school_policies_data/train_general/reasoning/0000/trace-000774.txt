To solve this problem, we need to determine the number of valid strings of length N using the characters 'A', 'B', and 'C' such that each character appears at least once. The solution must be efficient enough to handle very large values of N (up to 1e9) and a large number of test cases (up to 1e5).

### Approach
1. **Inclusion-Exclusion Principle**: The total number of valid strings can be derived using the inclusion-exclusion principle. The formula to compute the valid count is:
   \[
   \text{Valid} = 3^N - 3 \times 2^N + 3
   \]
   where:
   - \(3^N\) is the total number of strings without any restrictions.
   - \(3 \times 2^N\) accounts for the cases where one of the three characters is missing.
   - \(3\) corrects for over-subtraction by adding back the cases where two characters are missing (each such case contributes \(1^N\), and there are 3 such combinations).

2. **Modulo Operations**: Since the result can be very large, we use modulo \(10^9 + 7\) to keep the numbers manageable. Efficient computation of powers modulo a number is done using Python's built-in `pow` function with three arguments, which allows modular exponentiation in logarithmic time.

3. **Handling Large Inputs**: Reading input efficiently using `sys.stdin.read()` to handle up to 100,000 test cases quickly.

### Solution Code
```python
import sys

MOD = 10**9 + 7

def main():
    data = sys.stdin.read().split()
    T = int(data[0])
    results = []
    for i in range(1, T + 1):
        N = int(data[i])
        pow3 = pow(3, N, MOD)
        pow2 = pow(2, N, MOD)
        res = (pow3 - 3 * pow2 + 3) % MOD
        results.append(res)
    print('\n'.join(map(str, results)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the large number of test cases.
2. **Modular Exponentiation**: Using `pow(3, N, MOD)` and `pow(2, N, MOD)` to compute \(3^N \mod (10^9 + 7)\) and \(2^N \mod (10^9 + 7)\) efficiently.
3. **Formula Application**: The result for each test case is computed using the derived formula and stored in a list to avoid repeated I/O operations, which can be slow.
4. **Output**: The results are printed in one go to minimize I/O overhead.

This approach ensures that the solution is both time-efficient and handles the constraints effectively.
