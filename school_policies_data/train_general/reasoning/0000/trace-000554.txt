To solve this problem, we need to process a list of integers and remove any duplicates such that only the first occurrence of each integer remains. The solution must be efficient to handle the upper constraint of up to 100,000 integers.

### Approach
1. **Reading Input:** First, read the integer N which denotes the number of elements. Then, read the next line containing N space-separated integers.
2. **Tracking Seen Elements:** Use a set to keep track of the integers that have already been encountered. This allows for O(1) average time complexity for membership checks.
3. **Building the Result List:** Iterate through the list of integers. For each integer, if it has not been seen before, add it to the result list and mark it as seen. If it has been seen, skip it.
4. **Output the Result:** Convert the result list to a space-separated string and print it.

This approach ensures that each element is processed in O(1) time on average, leading to an overall time complexity of O(N), which is efficient for the given constraints.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    nums = list(map(int, input[1:n+1]))
    seen = set()
    result = []
    for num in nums:
        if num not in seen:
            seen.add(num)
            result.append(str(num))
    print(' '.join(result))

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input:** The input is read all at once and split into a list of strings. The first element is converted to an integer (N), and the subsequent elements are converted to integers representing the list of numbers.
- **Tracking Seen Elements:** A set `seen` is used to track which numbers have already been encountered. This allows for efficient membership checks.
- **Building the Result List:** As we iterate through the list of numbers, each number is checked against the `seen` set. If it is not present, it is added to both the `seen` set and the result list. This ensures that only the first occurrence of each number is retained.
- **Output:** The result list, which contains the numbers in the order of their first occurrence, is converted to a space-separated string and printed.

This solution efficiently handles the constraints and ensures that the output is correct and formatted as required.
