To solve this problem, we need to determine which teams qualify for the knockout stage of a World Cup based on their performance in the tournament. The teams are ranked using specific criteria, and the top half of the teams (sorted lexicographically) qualify for the next stage.

### Approach
1. **Input Reading**: Read the number of teams and their names.
2. **Match Processing**: For each match, update the points, goals scored, and goals conceded for the respective teams.
3. **Sorting Criteria**: Teams are sorted based on:
   - Points (descending)
   - Goal difference (descending)
   - Goals scored (descending)
4. **Select Top Teams**: The top half of the sorted teams are selected.
5. **Lexicographical Sort**: The selected teams are sorted lexicographically and printed.

### Solution Code
```python
n = int(input())
teams = [input().strip() for _ in range(n)]
stats = {team: [0, 0, 0] for team in teams}  # Points, Goals Scored, Goals Conceded

for _ in range(n * (n - 1) // 2):
    match_info = input().strip().split()
    teams_part, scores_part = match_info[0], match_info[1]
    team1, team2 = teams_part.split('-')
    score1, score2 = map(int, scores_part.split(':'))
    
    # Update points based on the match outcome
    if score1 > score2:
        stats[team1][0] += 3
    elif score1 == score2:
        stats[team1][0] += 1
        stats[team2][0] += 1
    else:
        stats[team2][0] += 3
    
    # Update goals scored and conceded for both teams
    stats[team1][1] += score1
    stats[team1][2] += score2
    stats[team2][1] += score2
    stats[team2][2] += score1

# Sort teams by the criteria
sorted_teams = sorted(teams, key=lambda name: (
    -stats[name][0],
    -(stats[name][1] - stats[name][2]),
    -stats[name][1],
    name
))

# Select top n/2 teams and sort lexicographically
selected = sorted_teams[:n // 2]
selected_sorted = sorted(selected)

# Output the result
for team in selected_sorted:
    print(team)
```

### Explanation
1. **Reading Input**: The number of teams and their names are read first. Each team's initial stats (points, goals scored, goals conceded) are initialized to zero.
2. **Processing Matches**: Each match result is parsed to update the respective teams' stats. Points are awarded based on match outcomes (3 for a win, 1 each for a draw).
3. **Sorting Teams**: Teams are sorted using a custom key that prioritizes points, goal difference, and goals scored in descending order.
4. **Selecting and Outputting**: The top half of the sorted teams are selected, sorted lexicographically, and printed.

This approach ensures that the teams are evaluated and sorted correctly according to the given criteria, and the final output is presented in the required lexicographical order.
