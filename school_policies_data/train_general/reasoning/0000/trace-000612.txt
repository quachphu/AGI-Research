To solve this problem, we need to determine the maximum number of apple pies that can be made given a certain number of whole apples (A) and existing pieces of apple (P). Each whole apple can be cut into three pieces, and each pie requires two pieces. 

### Approach
1. **Convert Apples to Pieces**: Each whole apple can be converted into three pieces. Therefore, the total number of pieces obtained from all whole apples is \(3 \times A\).
2. **Total Pieces Calculation**: The total number of pieces available after converting all apples is the sum of the pieces obtained from the apples and the existing pieces (P).
3. **Compute Maximum Pies**: Each pie requires two pieces, so the maximum number of pies is the integer division of the total pieces by 2.

### Solution Code
```python
def main():
    A, P = map(int, input().split())
    total_pieces = 3 * A + P
    print(total_pieces // 2)

main()
```

### Explanation
1. **Reading Input**: The input values A (apples) and P (pieces) are read from standard input.
2. **Conversion of Apples**: Each apple is converted into three pieces, contributing \(3 \times A\) pieces.
3. **Total Pieces**: The total number of pieces is the sum of the converted apple pieces and the existing pieces (P).
4. **Calculate Pies**: The maximum number of pies is obtained by dividing the total pieces by 2 (since each pie requires two pieces) using integer division to ensure we get a whole number of pies.

This approach efficiently computes the maximum number of pies by utilizing all available resources optimally, ensuring no unnecessary waste of pieces. The solution runs in constant time \(O(1)\), making it very efficient for the given constraints.
