To solve this problem, we need to repeatedly sum the digits of a given number until we obtain a single digit. This result is known as the digital root of the number. The digital root can be efficiently computed using a mathematical formula involving modulo 9, which allows us to determine the result in constant time without repeatedly summing the digits.

### Approach
The digital root of a number can be computed using the formula:
- If the number is 0, the digital root is 0.
- Otherwise, the digital root is given by \((n - 1) \% 9 + 1\). This formula works because the digital root of a number is equivalent to its value modulo 9, with the exception that a number divisible by 9 has a digital root of 9 instead of 0.

Given the constraints, we can safely assume that the input values are always greater than 1, so we do not need to handle the case where the input is 0.

### Solution Code
```python
def main():
    import sys
    data = sys.stdin.read().split()
    T = int(data[0])
    for i in range(1, T + 1):
        n = int(data[i])
        print((n - 1) % 9 + 1)

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings. The first element of this list is the number of test cases, \( T \).
2. **Processing Each Test Case**: For each test case, we convert the input string to an integer and compute its digital root using the formula \((n - 1) \% 9 + 1\).
3. **Output the Result**: The result for each test case is printed immediately after computation.

This approach efficiently computes the digital root in constant time for each input value, ensuring optimal performance even for the upper constraint limits.
