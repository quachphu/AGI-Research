To solve this problem, we need to determine the minimum time Roy takes to reach city B by choosing the optimal train from city A. The solution involves calculating the time for each available train, considering Roy's arrival time at the station and the trains' departure times and speeds.

### Approach
1. **Input Reading**: Read the number of test cases and the parameters for each test case.
2. **Check Feasibility for Each Train**: For each train, check if Roy can catch it based on his arrival time at the station.
3. **Calculate Travel Time**: For each train Roy can catch, compute the total travel time, which includes the time until the train departs and the train's travel time to city B.
4. **Handle Non-integer Times**: Convert the total travel time to minutes and round up to the nearest integer if necessary.
5. **Determine Optimal Time**: Select the minimum travel time from the feasible options. If no train can be caught, return -1.

### Solution Code
```python
import sys
import math

def main():
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        T0 = int(input[idx])
        T1 = int(input[idx+1])
        T2 = int(input[idx+2])
        V1 = int(input[idx+3])
        V2 = int(input[idx+4])
        D = int(input[idx+5])
        idx += 6
        
        possible = []
        # Check first train
        if T0 <= T1:
            total_time = T1 + (D * 60.0) / V1
            possible.append(math.ceil(total_time))
        # Check second train
        if T0 <= T2:
            total_time = T2 + (D * 60.0) / V2
            possible.append(math.ceil(total_time))
        
        if possible:
            print(min(possible))
        else:
            print(-1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Input Handling**: The input is read all at once and split into a list of strings for efficient processing, especially with large input sizes.
2. **Feasibility Check**: For each train, we check if Roy's arrival time at the station (T0) is less than or equal to the train's departure time (T1 or T2). If true, the train is considered feasible.
3. **Travel Time Calculation**: For each feasible train, the total travel time is calculated as the sum of the train's departure time and the time taken by the train to travel the distance D. This time is converted from hours to minutes.
4. **Rounding**: The total travel time is rounded up to the nearest integer using `math.ceil` to handle non-integer values.
5. **Optimal Time Selection**: The minimum travel time from the feasible options is selected and printed. If no trains are feasible, -1 is printed.

This approach ensures that we efficiently determine the optimal train for Roy while handling all edge cases and constraints specified in the problem.
