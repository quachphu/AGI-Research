Each flower's contribution to happiness is its mood multiplied by the number of chosen subarrays it appears in. The goal is to select subarrays such that the total happiness is maximized.

### Approach
1. **Problem Analysis**: Each subarray contributes to the happiness based on the sum of the moods of the flowers within its range. The optimal solution involves selecting subarrays with positive sums, as these will increase the total happiness. Subarrays with non-positive sums should be ignored as they do not contribute positively.

2. **Key Insight**: The contribution of each subarray can be computed independently. Therefore, we can sum the contributions of all subarrays with positive values to get the maximum possible happiness.

3. **Efficient Sum Calculation**: Using a prefix sum array allows us to quickly compute the sum of any subarray in constant time. This helps in efficiently evaluating each suggested subarray.

4. **Algorithm**:
   - Compute a prefix sum array to quickly determine the sum of any subarray.
   - For each suggested subarray, calculate its sum using the prefix sum array.
   - Accumulate the sums of subarrays with positive values to get the maximum happiness.

### Solution Code
```python
n, m = map(int, input().split())
a = list(map(int, input().split()))
prefix = [0] * (n + 1)
for i in range(n):
    prefix[i+1] = prefix[i] + a[i]
total = 0
for _ in range(m):
    l, r = map(int, input().split())
    s = prefix[r] - prefix[l-1]
    if s > 0:
        total += s
print(total)
```

### Explanation
1. **Reading Input**: The first line reads the number of flowers `n` and the number of suggested subarrays `m`. The second line reads the moods of the flowers into an array `a`.

2. **Prefix Sum Array**: The prefix sum array is constructed where `prefix[i]` holds the sum of the first `i` elements of the mood array. This allows quick calculation of the sum of any subarray using the formula `prefix[r] - prefix[l-1]`.

3. **Evaluating Subarrays**: For each suggested subarray (given by indices `l` and `r`), compute its sum using the prefix array. If the sum is positive, it is added to the total happiness.

4. **Output the Result**: The total accumulated happiness from all positive contributing subarrays is printed as the result.

This approach ensures that we efficiently compute the maximum possible happiness by considering only the subarrays that contribute positively, leveraging the prefix sum array for quick sum calculations.
