To solve this problem, we need to determine if it's possible to fill the empty squares between the leftmost (A) and rightmost (B) squares such that the absolute difference between any two adjacent squares is between C and D (inclusive).

### Approach
1. **Special Case Handling for Zero Differences**: If both C and D are zero, the only way to fill the squares is if A equals B.
2. **General Case Handling**: For non-zero C and D, we use a mathematical approach to determine if there exists a valid sequence of steps (differences) that can take us from A to B within N-1 steps, considering the constraints on the differences.

Key Steps:
1. **Calculate the Target Difference (S)**: Compute the difference between B and A.
2. **Sum of Constraints (M)**: Calculate the sum of C and D, which helps in determining the possible range of valid steps.
3. **Range of Valid Steps (K)**: Determine the range of valid steps (K) using the constraints derived from C and D. Check if there exists an integer K within this range that allows us to reach B from A in the given number of steps.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    A = int(input[1])
    B = int(input[2])
    C = int(input[3])
    D = int(input[4])
    S = B - A

    if C == 0 and D == 0:
        print("YES" if S == 0 else "NO")
        return

    M = C + D
    numerator_low = S + (N-1)*C
    numerator_high = S + (N-1)*D

    lower_K = (numerator_low + M - 1) // M
    upper_K = numerator_high // M

    possible_low = max(lower_K, 0)
    possible_high = min(upper_K, N-1)

    if possible_low <= possible_high:
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Special Case Handling**: If both C and D are zero, we check if A equals B. If they do, it's possible to fill the squares; otherwise, it's not.
2. **General Case Calculation**:
   - **Target Difference (S)**: The difference between B and A.
   - **Sum of Constraints (M)**: The sum of C and D helps in determining the valid range of steps.
   - **Valid Steps Calculation**: Using the derived formulas, compute the lower and upper bounds for possible steps (K). Check if there exists an integer K within these bounds that also lies within the valid range of steps (0 to N-1).

This approach efficiently checks the feasibility of filling the squares by leveraging mathematical constraints and integer arithmetic, ensuring it works within the problem's constraints.
