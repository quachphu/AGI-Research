To solve this problem, we need to determine the winner of a game where two players take turns removing stones from a pile, given that both play optimally. The solution involves using dynamic programming to model each possible state of the game and determine if it is a winning or losing position.

### Approach
1. **Dynamic Programming (DP) Setup**: We use a boolean array `dp` where `dp[i]` indicates whether the current player can force a win with `i` stones left.
2. **Base Case**: If there are 0 stones left (`dp[0]`), the current player cannot make a move and thus loses.
3. **Transition**: For each number of stones `i` from 1 to `K`, check all possible moves (elements in set `A`). If any move leads to a losing position for the opponent, mark the current position as a winning position.
4. **Optimal Play**: The players will always choose the move that forces the opponent into a losing position if possible.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))

dp = [False] * (k + 1)

for i in range(1, k + 1):
    for x in a:
        if x > i:
            break
        if not dp[i - x]:
            dp[i] = True
            break

print("First" if dp[k] else "Second")
```

### Explanation
1. **Reading Input**: The input values are read, including the number of elements in set `A`, the initial number of stones `K`, and the elements of `A`.
2. **DP Initialization**: The `dp` array is initialized with `False` values, indicating losing positions initially. The base case `dp[0] = False` is set since having 0 stones means the current player loses.
3. **Filling DP Array**: For each number of stones `i` from 1 to `K`, iterate through each possible move in set `A`. If a move leads to a position where the opponent cannot win (`dp[i - x]` is `False`), mark the current position `i` as a winning position (`dp[i] = True`).
4. **Result Determination**: After filling the DP array, check the value of `dp[K]`. If `dp[K]` is `True`, Taro (First) wins; otherwise, Jiro (Second) wins.

This approach efficiently determines the winner by leveraging dynamic programming to explore all possible game states, ensuring optimal play from both players. The time complexity is O(K*N), which is feasible given the constraints.
