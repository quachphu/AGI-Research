To solve this problem, we need to determine the maximum possible total cost of souvenirs that Petya can carry to the market without exceeding the weight limit. The souvenirs have weights of 1, 2, or 3, and we need an efficient approach to handle the constraints where the number of souvenirs (n) can be up to 100,000 and the maximum weight (m) can be up to 300,000.

### Approach
1. **Grouping by Weight**: Split the souvenirs into three groups based on their weights (1, 2, or 3).
2. **Sorting and Prefix Sums**: Sort each group in descending order of their costs and compute prefix sums for each group. The prefix sums allow us to quickly determine the maximum cost for taking a certain number of items from each group.
3. **Iterate Over Weight 3 Items**: For each possible number of weight 3 items taken, calculate the remaining weight capacity and determine the optimal combination of weight 1 and weight 2 items using a ternary search approach to maximize the total cost efficiently.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    m = int(input[idx + 1])
    idx += 2

    items = []
    for _ in range(n):
        w = int(input[idx])
        c = int(input[idx + 1])
        items.append((w, c))
        idx += 2

    # Group by weight and sort each group in descending order of cost
    w1 = sorted([c for w, c in items if w == 1], reverse=True)
    w2 = sorted([c for w, c in items if w == 2], reverse=True)
    w3 = sorted([c for w, c in items if w == 3], reverse=True)

    # Compute prefix sums for each group
    sum1 = [0]
    for c in w1:
        sum1.append(sum1[-1] + c)
    sum2 = [0]
    for c in w2:
        sum2.append(sum2[-1] + c)
    sum3 = [0]
    for c in w3:
        sum3.append(sum3[-1] + c)

    max_total = 0
    max_c = min(len(sum3) - 1, m // 3)

    for c in range(max_c + 1):
        current_m_rem = m - 3 * c
        if current_m_rem < 0:
            continue

        k1 = len(sum1) - 1
        k2 = len(sum2) - 1
        b_max = min(k2, current_m_rem // 2)
        low = 0
        high = b_max
        current_max_12 = 0

        while low <= high:
            if high - low < 3:
                for b in range(low, high + 1):
                    a = current_m_rem - 2 * b
                    if a < 0:
                        a = 0
                    a = min(a, k1)
                    current_sum = sum2[b] + sum1[a]
                    if current_sum > current_max_12:
                        current_max_12 = current_sum
                break

            mid1 = low + (high - low) // 3
            mid2 = high - (high - low) // 3

            a1 = current_m_rem - 2 * mid1
            a1 = max(0, a1)
            a1 = min(a1, k1)
            s1 = sum2[mid1] + sum1[a1]

            a2 = current_m_rem - 2 * mid2
            a2 = max(0, a2)
            a2 = min(a2, k1)
            s2 = sum2[mid2] + sum1[a2]

            if s1 < s2:
                if s2 > current_max_12:
                    current_max_12 = s2
                low = mid1 + 1
            else:
                if s1 > current_max_12:
                    current_max_12 = s1
                high = mid2 - 1

        total = sum3[c] + current_max_12
        if total > max_total:
            max_total = total

    print(max_total)

if __name__ == "__main__":
    main()
```

3. **Iterating Over Weight 3 Items**: For each possible number of weight 3 items taken, the remaining weight capacity is calculated. Using ternary search, we determine the optimal combination of weight 1 and weight 2 items to maximize the total cost within the remaining weight capacity.
4. **Ternary Search**: This search is used to efficiently find the optimal number of weight 2 items to take, considering the trade-off between increasing the number of weight 2 items (which increases their total cost but reduces the remaining capacity for weight 1 items).
