To solve this problem, we need to determine the number of binary sequences of length \( N \) that contain at least \( M \) consecutive 1s as a substring. The result should be computed modulo \( 10^9 + 7 \).

### Approach
1. **Problem Analysis**:
   - The problem requires counting binary sequences (0s and 1s) of length \( N \) that include at least one substring of \( M \) consecutive 1s.
   - Instead of directly counting valid sequences, we count the invalid sequences (those without any substring of \( M \) consecutive 1s) and subtract this count from the total number of possible sequences.

2. **Dynamic Programming (DP) Approach**:
   - Define \( F(n) \) as the number of invalid sequences of length \( n \) (those without any \( M \) consecutive 1s).
   - For \( n < M \), all possible sequences of length \( n \) are valid (since they can't contain \( M \) consecutive 1s), so \( F(n) = 2^n \).
   - For \( n \geq M \), use a sliding window technique to maintain the sum of the last \( M \) values of \( F \) to efficiently compute the next value.

3. **Efficient Calculation**:
   - Use modular arithmetic to handle large numbers and prevent overflow.
   - Compute the total number of sequences as \( 2^N \) and subtract the number of invalid sequences \( F(N) \).

### Solution Code
```python
MOD = 10**9 + 7

N, M = map(int, input().split())

F = [1]  # F[0] is 1 (base case)

# Compute F[1] to F[M-1], each as 2^i mod MOD
for i in range(1, M):
    F.append((F[-1] * 2) % MOD)

if M <= N:
    sum_prev = sum(F) % MOD  # Initial sum of F[0] to F[M-1]
    for i in range(M, N + 1):
        current = sum_prev % MOD
        F.append(current)
        # Update sum_prev by subtracting the element leaving the window and adding the new current
        sum_prev = (sum_prev - F[i - M] + current) % MOD
        # Ensure non-negative result
        if sum_prev < 0:
            sum_prev += MOD
    forbidden = F[N]
else:
    # When M > N, all sequences are invalid (since they can't have M consecutive 1s)
    forbidden = pow(2, N, MOD)

total = pow(2, N, MOD)
ans = (total - forbidden) % MOD
print(ans)
```

### Explanation
- **Initialization**: Start with \( F(0) = 1 \) (empty sequence).
- **Precompute for \( n < M \)**:
  - For \( n \) from 1 to \( M-1 \), each \( F(n) \) is \( 2^n \mod 10^9 + 7 \).
- **Sliding Window Sum**:
  - For \( n \geq M \), compute \( F(n) \) as the sum of the previous \( M \) values of \( F \), maintaining this sum efficiently using a sliding window technique.
- **Result Calculation**:
  - The total number of sequences is \( 2^N \mod 10^9 + 7 \).
  - Subtract the count of invalid sequences \( F(N) \) from the total and take the result modulo \( 10^9 + 7 \).

This approach efficiently computes the result using dynamic programming and modular arithmetic, ensuring it handles large values of \( N \) and \( M \) within feasible time complexity.
