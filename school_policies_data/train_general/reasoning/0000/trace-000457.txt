To solve this problem, we need to decrypt a message encrypted using the Caesar cipher by finding the shift value that results in the lexicographically smallest possible decrypted message. The Caesar cipher encrypts a character by shifting it by a certain number of positions, and our task is to determine the optimal shift value for decryption.

### Approach
1. **Understanding the Problem**: The Caesar cipher shifts each character by a certain number of positions. To decrypt, we need to reverse this process by trying all possible shifts (0 to 25) and selecting the one that produces the lexicographically smallest string.
2. **Efficient Comparison**: Instead of generating all 26 possible decrypted strings, we can determine the optimal shift by iteratively reducing the number of candidate shifts. For each character position in the string, we compute the minimum possible decrypted value and retain only those shifts that achieve this value. This process continues until we find a single optimal shift or exhaust all characters.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    cases = input[1:T+1]
    for S in cases:
        pre = [ord(c) - 97 for c in S]
        candidates = set(range(26))
        for c in pre:
            min_val = 26
            for s in candidates:
                current = (c - s) % 26
                if current < min_val:
                    min_val = current
            new_candidates = set()
            for s in candidates:
                if (c - s) % 26 == min_val:
                    new_candidates.add(s)
            candidates = new_candidates
            if len(candidates) == 1:
                break
        best_shift = min(candidates)
        decrypted = ''.join([chr(((v - best_shift) % 26) + 97) for v in pre])
        print(decrypted)

if __name__ == '__main__':
    main()
```
