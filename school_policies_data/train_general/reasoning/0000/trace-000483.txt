2. **Single Digit Check**: If both parts of the time are single digits, they can be valid in infinitely many bases if their values are within the valid ranges.
3. **General Case**: For other cases, compute the minimum possible base (k_min) based on the maximum digits in a and b. Then, check each base starting from k_min to determine if the time is valid. If the values of a and b in a base exceed the valid ranges, stop checking further bases.
