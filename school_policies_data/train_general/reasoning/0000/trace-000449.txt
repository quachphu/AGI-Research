To solve this problem, we need to determine if Pig can reach his friend's house located at point m using only teleports. Each teleport allows Pig to move from its location ai to any point up to its limit bi. The key is to check if there exists a sequence of teleport uses that can take Pig from his starting point (0) to his friend's house (m).

### Approach
1. **Problem Analysis**: Pig starts at point 0 and needs to reach point m. Each teleport at position ai can move Pig to any point between ai and bi (inclusive). The teleports are given in non-decreasing order of their positions ai.
2. **Greedy Strategy**: The optimal approach is to use a greedy algorithm to track the farthest point Pig can reach using the teleports processed so far. By iterating through each teleport in order, we update the maximum reachable point if the current teleport's position ai is within the current reachable range. If at any point the maximum reachable point exceeds or equals m, Pig can reach his friend's house.
3. **Algorithm**:
   - Initialize `max_reach` to 0 (starting point).
   - For each teleport (ai, bi):
     - If ai is beyond the current `max_reach`, break the loop as Pig cannot reach this teleport.
     - Update `max_reach` to the maximum of its current value and bi.
   - After processing all relevant teleports, check if `max_reach` is at least m.

### Solution Code
```python
n, m = map(int, input().split())
teleports = [tuple(map(int, input().split())) for _ in range(n)]
max_reach = 0

for a, b in teleports:
    if a > max_reach:
        break
    max_reach = max(max_reach, b)

print("YES" if max_reach >= m else "NO")
```

### Explanation
- **Initialization**: Start with `max_reach` set to 0, representing the farthest point Pig can reach initially.
- **Iterate Through Teleports**: For each teleport, check if its position ai is reachable (i.e., ai ≤ `max_reach`). If it is, update `max_reach` to the maximum of its current value and the teleport's limit bi.
- **Check Reachability**: After processing all teleports that can be reached, check if `max_reach` is at least m. If yes, Pig can reach his friend's house; otherwise, he cannot.

This approach efficiently determines the solution using a linear scan of the teleports, ensuring optimal performance given the problem constraints.
