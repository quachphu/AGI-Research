To solve this problem, we need to determine the maximum number of Pokemon Bash can take such that their strengths do not fight among each other. The key insight is that a group of Pokemon will fight if their greatest common divisor (GCD) is 1. Therefore, we need to find the largest subset of Pokemon whose strengths have a GCD greater than 1.

### Approach
1. **Prime Factorization**: For each Pokemon's strength, compute its prime factors. This helps in identifying common factors among different strengths.
2. **Count Prime Factors**: Track the frequency of each prime factor across all Pokemon strengths. The prime factor with the highest frequency indicates the maximum number of Pokemon that can be grouped together without their GCD being 1.
3. **Edge Cases**: Handle cases where all strengths are 1 separately, as any group of more than one Pokemon with strength 1 will have a GCD of 1.

### Solution Code
```python
import sys
from collections import defaultdict

def prime_factors(x):
    factors = set()
    if x < 2:
        return factors
    while x % 2 == 0:
        factors.add(2)
        x //= 2
    i = 3
    while i * i <= x:
        while x % i == 0:
            factors.add(i)
            x //= i
        i += 2
    if x > 1:
        factors.add(x)
    return factors

def main():
    n = int(sys.stdin.readline())
    s = list(map(int, sys.stdin.readline().split()))
    counts = defaultdict(int)
    has_non_one = False
    
    for num in s:
        if num == 1:
            continue
        has_non_one = True
        factors = prime_factors(num)
        for p in factors:
            counts[p] += 1
    
    if not has_non_one:
        print(1)
    else:
        print(max(counts.values()))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of the number of Pokemon and their respective strengths.
2. **Prime Factorization**: For each strength greater than 1, compute its prime factors. This helps in identifying common prime factors among different strengths.
3. **Tracking Prime Frequencies**: Use a dictionary to count how many times each prime factor appears across all strengths.
4. **Determine Result**: If there are no strengths greater than 1, the answer is 1. Otherwise, the result is the maximum count of any prime factor, as this indicates the largest group of Pokemon that can be taken without their GCD being 1.

This approach efficiently computes the required result by leveraging prime factorization and frequency counting, ensuring optimal performance even for large input sizes.
