To solve this problem, we need to count the number of "good" sequences of vertices in a tree where each edge is colored either black or red. A sequence is considered good if at least one black edge is traversed during the entire journey from the first to the last vertex in the sequence. 

### Approach
1. **Problem Analysis**:
   - A sequence is bad if all paths between consecutive vertices in the sequence use only red edges.
   - The total number of sequences is \( n^k \), where \( n \) is the number of vertices and \( k \) is the length of the sequence.
   - The goal is to subtract the number of bad sequences from the total sequences to get the number of good sequences.

2. **Key Insight**:
   - Bad sequences can only be formed if all consecutive vertices in the sequence lie within the same connected component of the subgraph formed by red edges. This is because moving between different components requires traversing a black edge.

3. **Algorithm**:
   - **Step 1**: Construct the adjacency list for the subgraph formed by red edges.
   - **Step 2**: Use BFS to find all connected components in this subgraph.
   - **Step 3**: For each component of size \( s \), compute \( s^k \) (modulo \( 10^9 + 7 \)).
   - **Step 4**: Sum these values for all components to get the total number of bad sequences.
   - **Step 5**: Subtract the number of bad sequences from \( n^k \) to get the result.

### Solution Code
```python
from collections import deque

MOD = 10**9 + 7

n, k = map(int, input().split())
adj = [[] for _ in range(n + 1)]

for _ in range(n - 1):
    u, v, x = map(int, input().split())
    if x == 0:
        adj[u].append(v)
        adj[v].append(u)

visited = [False] * (n + 1)
sum_bad = 0

for u in range(1, n + 1):
    if not visited[u]:
        q = deque()
        q.append(u)
        visited[u] = True
        cnt = 0
        while q:
            node = q.popleft()
            cnt += 1
            for neighbor in adj[node]:
                if not visited[neighbor]:
                    visited[neighbor] = True
                    q.append(neighbor)
        sum_bad = (sum_bad + pow(cnt, k, MOD)) % MOD

total = (pow(n, k, MOD) - sum_bad) % MOD
print(total)
```

### Explanation
1. **Reading Input and Building the Red-edge Subgraph**:
   - We read the input values and construct an adjacency list for the subgraph formed by red edges (edges where the color is 0).

2. **Finding Connected Components**:
   - Using BFS, we traverse each unvisited node to find all connected components in the red-edge subgraph. Each component's size is counted during traversal.

3. **Calculating Bad Sequences**:
   - For each component of size \( s \), the number of bad sequences within that component is \( s^k \). These values are summed up modulo \( 10^9 + 7 \).

4. **Computing the Result**:
   - The total number of sequences is \( n^k \). Subtracting the number of bad sequences from this total gives the number of good sequences, which is then printed modulo \( 10^9 + 7 \).

This approach efficiently handles the constraints by leveraging BFS for component detection and modular arithmetic for large number computations.
