To solve this problem, we need to determine the final string after Alice and Bob play their game optimally. Alice aims to make the string lexicographically smallest, while Bob aims to make it largest. They take turns choosing indices to modify, starting with Alice.

### Approach
1. **Turn-Based Strategy**: Alice and Bob take turns modifying the string. Alice starts first, and they alternate turns.
2. **Lexicographical Priority**: The leftmost characters have a higher impact on the lexicographical order. Thus, both players will prioritize modifying the leftmost available indices first.
3. **Optimal Moves**:
   - **Alice's Move**: On her turn, Alice will change the current character to the smallest possible character that is different from the original.
   - **Bob's Move**: On his turn, Bob will change the current character to the largest possible character that is different from the original.
4. **Character Selection**:
   - For Alice, the smallest possible character is 'a' if it's not the original, otherwise 'b'.
   - For Bob, the largest possible character is 'z' if it's not the original, otherwise 'y'.

### Solution Code
```python
def solve():
    import sys
    t = int(sys.stdin.readline())
    for _ in range(t):
        s = sys.stdin.readline().strip()
        res = []
        for i in range(len(s)):
            original = s[i]
            if i % 2 == 0:
                # Alice's turn: choose smallest possible
                if original != 'a':
                    res.append('a')
                else:
                    res.append('b')
            else:
                # Bob's turn: choose largest possible
                if original != 'z':
                    res.append('z')
                else:
                    res.append('y')
        print(''.join(res))

solve()
```

### Explanation
1. **Reading Input**: The number of test cases is read first. For each test case, the input string is processed.
2. **Processing Each Character**: Each character in the string is processed from left to right. The index determines whose turn it is (Alice for even indices, Bob for odd indices).
3. **Character Modification**:
   - **Alice's Turn**: She changes the character to 'a' if possible, otherwise to 'b'.
   - **Bob's Turn**: He changes the character to 'z' if possible, otherwise to 'y'.
4. **Output**: The modified string after all characters have been processed is printed for each test case.

This approach ensures that both players play optimally, with Alice minimizing the lexicographical order and Bob maximizing it, resulting in the correct final string after all moves.
