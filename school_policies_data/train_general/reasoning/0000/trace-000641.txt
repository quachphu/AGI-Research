class FenwickTree:
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (self.n + 1)  # 1-based

    def update(self, idx, delta):
        while idx <= self.n:
            self.tree[idx] += delta
            idx += idx & -idx

    def query(self, idx):
        res = 0
        while idx > 0:
            res += self.tree[idx]
            idx -= idx & -idx
        return res

To solve this problem, we need to determine the number of pairs of topics (i, j) where i < j and the sum of their interestingness for the teacher is greater than the sum for the students. This can be efficiently solved using a combination of sorting, binary search, and a Fenwick Tree (Binary Indexed Tree) to count valid pairs.

### Approach
1. **Transform the Problem**: Convert the problem into finding pairs (i, j) where the sum of the differences (a_i - b_i) and (a_j - b_j) is positive. This simplifies the problem to finding pairs (i, j) where (a_i - b_i) + (a_j - b_j) > 0.
2. **Compress Values**: Since the values can be very large, we compress the values of the differences (a_i - b_i) and their negatives to a smaller range using sorting and deduplication.
3. **Fenwick Tree**: Use a Fenwick Tree to efficiently count the number of valid pairs. For each element, we query how many previous elements are greater than the negative of the current element, which gives the number of valid pairs ending at the current element.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    a = list(map(int, input[idx:idx+n]))
    idx += n
    b = list(map(int, input[idx:idx+n]))
    idx += n
    
    c = [a[i] - b[i] for i in range(n)]
    
    # Collect all possible values for compression
    all_values = []
    for num in c:
        all_values.append(num)
        all_values.append(-num)
    sorted_unique = sorted(list(set(all_values)))
    
    class FenwickTree:
        def __init__(self, size):
            self.n = size
            self.tree = [0] * (self.n + 1)  # 1-based indexing
        
        def update(self, idx, delta):
            while idx <= self.n:
                self.tree[idx] += delta
                idx += idx & -idx
        
        def query(self, idx):
            res = 0
            while idx > 0:
                res += self.tree[idx]
                idx -= idx & -idx
            return res
    
    ft = FenwickTree(len(sorted_unique))
    res = 0
    
    for num in c:
        x = -num
        # Find the first index in sorted_unique where value > x
        k = bisect.bisect_right(sorted_unique, x)
        # Count elements > x: sum from k to end
        count = ft.query(len(sorted_unique)) - ft.query(k)
        res += count
        
        # Insert current num into Fenwick Tree
        pos = bisect.bisect_left(sorted_unique, num)
        ft.update(pos + 1, 1)  # Fenwick Tree is 1-based
    
    print(res)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Input Reading and Transformation**: Read input values and compute the array `c` where each element is the difference between the teacher's and students' interestingness values.
2. **Value Compression**: Collect all values from `c` and their negatives, sort them, and deduplicate to create a compressed list of values. This helps in efficiently querying and updating the Fenwick Tree.
3. **Fenwick Tree Operations**: For each element in `c`, determine how many previous elements are greater than the negative of the current element using binary search on the compressed values. Update the Fenwick Tree with the current element to include it in future queries.

This approach efficiently reduces the problem to manageable operations with a time complexity of O(n log n), making it suitable for large input sizes up to 200,000 elements.
