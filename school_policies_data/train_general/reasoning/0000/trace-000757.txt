To solve this problem, we need to determine the number of ways to choose three distinct points such that the maximum distance between any two points in the trio does not exceed a given value \( d \). The points are provided in strictly increasing order, which allows us to use an efficient approach to solve the problem.

### Approach
1. **Problem Analysis**:
   - The key observation is that for any triplet of points (i, j, k) where \( i < j < k \), the maximum distance between the farthest points is \( x[k] - x[i] \). This distance must be less than or equal to \( d \).
   - Given the points are sorted, we can use binary search to efficiently find the range of points that can form valid triplets with each starting point.

2. **Algorithm**:
   - For each point \( x[i] \), determine the farthest point \( x[j] \) such that \( x[j] - x[i] \leq d \) using binary search.
   - Calculate the number of valid triplets that can be formed starting from \( x[i] \) using combinations of the points within this valid range.

3. **Complexity**:
   - The binary search operation for each point \( x[i] \) takes \( O(\log n) \), leading to an overall time complexity of \( O(n \log n) \), which is efficient for \( n \leq 10^5 \).

### Solution Code
```python
import bisect

n, d = map(int, input().split())
x = list(map(int, input().split()))
total = 0

for i in range(n):
    target = x[i] + d
    j = bisect.bisect_right(x, target) - 1
    count = j - i
    if count >= 2:
        total += count * (count - 1) // 2

print(total)
```

### Explanation
1. **Reading Input**: The input values for \( n \) (number of points) and \( d \) (maximum allowed distance) are read first, followed by the coordinates of the points.
2. **Binary Search**: For each point \( x[i] \), we use binary search to find the rightmost point \( x[j] \) such that \( x[j] - x[i] \leq d \). This is done using `bisect_right` to find the insertion point of \( x[i] + d \) and adjusting to get the largest valid index \( j \).
3. **Counting Triplets**: For each valid range from \( i \) to \( j \), the number of valid triplets is calculated using the combination formula \( C(\text{count}, 2) \), where \( \text{count} = j - i \). This formula gives the number of ways to choose 2 points from \( \text{count} \) points, which forms valid triplets with \( x[i] \).
4. **Summing Results**: The results for each starting point \( i \) are accumulated to get the total number of valid triplets, which is then printed.

This approach efficiently leverages sorting and binary search to ensure the solution is both optimal and easy to understand.
