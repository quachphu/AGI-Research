To solve this problem, we need to determine all possible fun values for a given number of people sitting in a circle, where each person passes a ball to their k-th neighbor in a clockwise direction until the ball returns to the starting person. The fun value is the sum of the unique IDs of all people who touched the ball.

### Approach
1. **Understanding the Problem**: The ball starts at person 1 and is passed to the k-th neighbor each time. The process stops when the ball returns to person 1. The fun value is the sum of all unique IDs encountered during this process.
2. **Mathematical Insight**: The key insight is that the movement of the ball can be modeled using modular arithmetic. The sequence of positions forms a cycle, which depends on the greatest common divisor (GCD) of k and the number of people, n.
3. **Divisors and GCD**: For each divisor d of n, the possible values of k can be grouped by their GCD with n. Each group will result in a unique fun value.
4. **Formula for Fun Value**: For each divisor d of n, the fun value can be computed using the formula \( S = \frac{n \times (n - d + 2)}{2d} \).

### Solution Code
```python
n = int(input())

def factorize(n):
    factors = {}
    while n % 2 == 0:
        factors[2] = factors.get(2, 0) + 1
        n = n // 2
    i = 3
    while i * i <= n:
        while n % i == 0:
            factors[i] = factors.get(i, 0) + 1
            n = n // i
        i += 2
    if n > 1:
        factors[n] = 1
    return factors

def generate_divisors(factors):
    divisors = [1]
    for p in factors:
        current_exponents = [p**e for e in range(1, factors[p] + 1)]
        temp = []
        for d in divisors:
            for exp in current_exponents:
                temp.append(d * exp)
        divisors += temp
    return divisors

factors = factorize(n)
divisors = generate_divisors(factors)

s_values = []
for d in divisors:
    s = (n * (n - d + 2)) // (2 * d)
    s_values.append(s)

s_values = sorted(set(s_values))
print(' '.join(map(str, s_values)))
```
