To solve this problem, we need to compare two numbers, X and Y, which are represented in different bases. The goal is to determine if X is less than, greater than, or equal to Y by converting both numbers to a common base (decimal) and then comparing them.

### Approach
1. **Read Input**: The input consists of two numbers each represented in their respective bases. The first part describes number X with its base, and the second part describes number Y with its base.
2. **Convert to Decimal**: Convert each number from its given base to a decimal (base 10) value. This is done by iterating through each digit of the number and applying the formula: `value = value * base + digit`, which effectively shifts the current value left (multiplying by the base) and adds the new digit.
3. **Compare Values**: Once both numbers are converted to decimal, compare them directly to determine the result.

### Solution Code
```python
def compare_numbers():
    import sys

    # Read X's data
    n, bx = map(int, sys.stdin.readline().split())
    x_digits = list(map(int, sys.stdin.readline().split()))

    # Read Y's data
    m, by = map(int, sys.stdin.readline().split())
    y_digits = list(map(int, sys.stdin.readline().split()))

    # Convert X to decimal value
    x_val = 0
    for d in x_digits:
        x_val = x_val * bx + d

    # Convert Y to decimal value
    y_val = 0
    for d in y_digits:
        y_val = y_val * by + d

    # Compare and output result
    if x_val < y_val:
        print('<')
    elif x_val > y_val:
        print('>')
    else:
        print('=')

compare_numbers()
```

### Explanation
1. **Reading Input**: The input is read line by line. The first two lines describe the number X, and the next two lines describe the number Y.
2. **Conversion Process**: Each digit of the number is processed in order, starting from the most significant digit. For each digit, the current value is multiplied by the base and the digit is added. This effectively builds the number in base 10.
3. **Comparison**: After converting both numbers to base 10, a simple comparison between the two values gives the result, which is then printed as '<', '>', or '='.

This approach efficiently handles the conversion and comparison within the constraints provided, ensuring accurate results using Python's ability to manage large integers.
