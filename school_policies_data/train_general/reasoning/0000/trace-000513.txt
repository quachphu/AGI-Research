To solve this problem, we need to count the numbers between 1 and N (inclusive) that are Shichi-Go-San numbers. A Shichi-Go-San number is defined as a number that contains each of the digits 3, 5, and 7 at least once, and no other digits are present.

### Approach
1. **Generate Possible Numbers**: Generate all numbers composed exclusively of the digits 3, 5, and 7. These numbers can vary in length from 1 digit up to the number of digits in N.
2. **Check Validity**: For each generated number, check if it is less than or equal to N and contains all three digits (3, 5, and 7) at least once.
3. **Count Valid Numbers**: Count how many of these generated numbers meet both criteria.

### Solution Code
```python
import itertools

def count_shichigosan():
    N = int(input().strip())
    count = 0
    max_length = len(str(N))
    for length in range(3, max_length + 1):
        for digits in itertools.product('357', repeat=length):
            num = int(''.join(digits))
            if num > N:
                continue
            if '3' in digits and '5' in digits and '7' in digits:
                count += 1
    print(count)

count_shichigosan()
```
