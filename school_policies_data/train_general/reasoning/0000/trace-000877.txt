To solve this problem, we need to determine the minimum cost required to transform a list of numbers such that the greatest common divisor (gcd) of the remaining elements is greater than 1, making the list "good." The allowed operations are deleting an element with cost `x` or incrementing an element by 1 with cost `y`.

### Approach
1. **Problem Analysis**: The list is considered "bad" if it is non-empty and the gcd of its elements is 1. Our goal is to make the list "good" by ensuring the gcd is greater than 1 or by deleting all elements.

2. **Key Insight**: The optimal solution involves finding a divisor `g` such that modifying elements to be divisible by `g` results in the minimum cost. This divisor can be efficiently found by considering the prime factors of the elements and their increments.

3. **Algorithm**:
   - **Prime Factorization**: Generate candidate divisors by considering the prime factors of each element and its increment (element + 1).
   - **Cost Calculation**: For each candidate divisor, compute the total cost of either modifying elements to be divisible by the divisor or deleting them.
   - **Comparison**: Compare the computed costs for all candidate divisors and choose the minimum.

### Solution Code
```python
import sys

def input():
    return sys.stdin.read()

def factors(n):
    if n < 2:
        return set()
    factors = set()
    while n % 2 == 0:
        factors.add(2)
        n = n // 2
    i = 3
    while i * i <= n:
        while n % i == 0:
            factors.add(i)
            n = n // i
        i += 2
    if n > 2:
        factors.add(n)
    return factors

def main():
    data = input().split()
    n = int(data[0])
    x = int(data[1])
    y = int(data[2])
    a = list(map(int, data[3:3+n]))
    
    candidates = set()
    for num in a:
        if num > 1:
            candidates.update(factors(num))
        num_plus = num + 1
        candidates.update(factors(num_plus))
    
    min_cost = x * n  # Cost to delete all elements
    
    for g in candidates:
        if g == 1:
            continue
        total = 0
        count_modified = 0
        for ai in a:
            remainder = ai % g
            delta = (g - remainder) % g
            cost_modify = delta * y
            if cost_modify < x:
                total += cost_modify
                count_modified += 1
            else:
                total += x
        if count_modified == 0:
            # All elements would be deleted, which is invalid
            continue
        if total < min_cost:
            min_cost = total
    
    print(min(min_cost, x * n))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prime Factorization**: The `factors` function generates all prime factors of a number, which helps in identifying potential divisors for the gcd.
2. **Candidate Divisors**: For each element and its increment, we collect all prime factors to form candidate divisors.
3. **Cost Calculation**: For each candidate divisor `g`, compute the cost of modifying elements to be divisible by `g` or deleting them. Track the minimum cost.
4. **Edge Case Handling**: Ensure that at least one element remains non-deleted to form a valid list.

This approach efficiently narrows down potential divisors and computes the minimal cost using a combination of prime factorization and greedy cost comparison, ensuring optimal performance even for large inputs.
