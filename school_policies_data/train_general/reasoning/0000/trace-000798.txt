To solve this problem, we need to determine the minimum number of operations required to transform an array such that there exists exactly K elements with the same value. The operations allowed are changing an element to any other value.

### Approach
1. **Problem Analysis**: The goal is to find the minimum number of operations to transform the array such that exactly K elements are the same. The key insight is to either use an existing element in the array or introduce a new element not present in the array.
2. **Frequency Counting**: Use a frequency counter to determine how many times each element appears in the array.
3. **Cost Calculation**:
   - For each existing element, calculate the cost to make exactly K elements. If the element's current count is greater than or equal to K, the cost is the difference between the count and K. If the count is less than K, the cost is the difference needed to reach K.
   - Compare this cost with the cost of introducing a new element, which is K operations (changing K elements to the new value).
4. **Optimal Solution**: The minimum of the costs calculated from existing elements and the cost of introducing a new element gives the answer.

### Solution Code
```python
import sys
from collections import Counter

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N, K = int(input[ptr]), int(input[ptr + 1])
        ptr += 2
        A = list(map(int, input[ptr:ptr + N]))
        ptr += N
        counts = Counter(A)
        min_ops = float('inf')
        for x in counts:
            m = counts[x]
            if m >= K:
                ops = m - K
            else:
                ops = K - m
            if ops < min_ops:
                min_ops = ops
        ans = min(min_ops, K)
        print(ans)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Frequency Count**: Using the `Counter` from the `collections` module, we count the occurrences of each element in the array.
3. **Cost Calculation for Existing Elements**: For each element in the frequency counter, calculate the cost to adjust its count to exactly K. This involves either reducing the count if it's more than K or increasing it if it's less than K.
4. **Comparison with New Element Cost**: The cost of introducing a new element is always K operations. The minimum between this value and the minimum cost from existing elements is the result for each test case.

This approach ensures we efficiently determine the optimal solution by leveraging frequency counts and simple arithmetic operations, resulting in a time complexity of O(N) per test case.
