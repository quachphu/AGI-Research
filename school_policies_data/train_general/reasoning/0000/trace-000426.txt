To solve this problem, we need to determine if we can construct a binary search tree (BST) from a given sorted list of nodes such that every parent-child pair in the tree has a greatest common divisor (GCD) greater than 1. 

### Approach
1. **Factorization**: Precompute the prime factors for each node value. This helps in efficiently checking if two nodes can be connected by an edge (i.e., their GCD is greater than 1).
2. **Dynamic Programming (DP)**: Use a DP table to track if a valid BST can be formed for each subarray of nodes. The DP state `dp[l][r]` indicates whether the subarray from index `l` to `r` can form a valid BST.
3. **Prime Union Tracking**: For each subarray, track the union of prime factors of all valid roots. This helps in quickly checking if a node can be connected to any valid root of a subarray.

### Solution Code

def main():
    import sys
    from sys import stdin

    def get_factors(x):
        factors = set()
        if x % 2 == 0:
            factors.add(2)
            while x % 2 == 0:
                x //= 2
        i = 3
        while i * i <= x:
            while x % i == 0:
                factors.add(i)
                x //= i
            i += 2
        if x > 1:
            factors.add(x)
        return factors

    n = int(stdin.readline())
    a = list(map(int, stdin.readline().split()))
    a.sort()
    factors = [get_factors(num) for num in a]
    dp = [[False] * n for _ in range(n)]
    root_primes = [[set() for _ in range(n)] for _ in range(n)]

    # Initialize for single node intervals
    for i in range(n):
        dp[i][i] = True
        root_primes[i][i] = factors[i]

    # Process intervals of increasing length
    for length in range(1, n):
        for l in range(n - length):
            r = l + length
            valid_roots = []
            for k in range(l, r + 1):
                left_ok = True
                if k > l:
                    if not dp[l][k - 1]:
                        left_ok = False
                    else:
                        if factors[k].intersection(root_primes[l][k - 1]):
                            left_ok = True
                        else:
                            left_ok = False
                right_ok = True
                if k < r:
                    if not dp[k + 1][r]:
                        right_ok = False
                    else:
                        if factors[k].intersection(root_primes[k + 1][r]):
                            right_ok = True
                        else:
                            right_ok = False
                if left_ok and right_ok:
                    valid_roots.append(k)
            if valid_roots:
                dp[l][r] = True
                current_primes = set()
                for k_valid in valid_roots:
                    current_primes.update(factors[k_valid])
                root_primes[l][r] = current_primes
            else:
                dp[l][r] = False

    print("Yes" if dp[0][n - 1] else "No")

3. **DP Processing**: For each interval length starting from 1, check all possible roots. For each root, check if the left and right sub-intervals can form valid BSTs with roots that have a GCD greater than 1 with the current root.
4. **Prime Union Tracking**: Track the union of prime factors of all valid roots for each interval. This allows efficient checks for valid connections between nodes.
