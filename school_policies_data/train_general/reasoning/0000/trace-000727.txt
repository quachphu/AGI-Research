To solve this problem, we need to determine the smallest base \( b \) (where \( b \geq 2 \)) such that the sum of the digits of \( n \) when represented in base \( b \) equals \( s \). If no such base exists, we should return -1.

### Approach
1. **Immediate Checks**:
   - If \( s \) is greater than \( n \), output -1 because the sum of digits in any base greater than \( n \) is exactly \( n \), which cannot be greater than \( n \).
   - If \( s \) equals \( n \), the smallest base is \( n + 1 \) because any base greater than \( n \) will represent \( n \) as a single digit, which is \( n \).

2. **Divisors of \( d \)**:
   - Compute \( d = n - s \). The sum of digits in base \( b \) must be congruent to \( n \) modulo \( (b-1) \). This implies \( d \) must be divisible by \( (b-1) \).
   - Generate all divisors of \( d \) and check each divisor \( m \) to see if \( b = m + 1 \) results in the sum of digits of \( n \) in base \( b \) being exactly \( s \).

3. **Check Each Divisor**:
   - For each divisor \( m \), compute \( b = m + 1 \).
   - Calculate the sum of digits of \( n \) in base \( b \). If the sum matches \( s \), return \( b \).

### Solution Code

import math

def find_min_base():
    n = int(input())
    s = int(input())
    
    if s > n:
        print(-1)
        return
    if s == n:
        print(n + 1)
        return
    
    d = n - s
    divisors = set()
    for i in range(1, int(math.isqrt(d)) + 1):
        if d % i == 0:
            divisors.add(i)
            divisors.add(d // i)
    sorted_divisors = sorted(divisors)
    
    for m in sorted_divisors:
        b = m + 1
        current = n
        total = 0
        while current > 0:
            remainder = current % b
            total += remainder
            if total > s:
                break
            current = current // b
        if total == s:
            print(b)
            return
    print(-1)
