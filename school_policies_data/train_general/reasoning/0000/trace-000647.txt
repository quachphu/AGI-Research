To solve this problem, we need to determine the maximum number of equal elements that can be obtained in an array after performing a series of operations. Each operation allows increasing one element by 1 and decreasing another element by 1, which keeps the sum of the array constant.

### Approach
1. **Sum Analysis**: The sum of the array remains constant regardless of the number of operations performed. This is because each operation increases one element by 1 and decreases another by 1, thus maintaining the overall sum.
2. **Divisibility Check**: If the sum of the array elements is divisible by the number of elements (n), then all elements can be made equal, resulting in n equal elements.
3. **Non-Divisibility Case**: If the sum is not divisible by n, then it's impossible to make all elements equal. However, we can always make at least (n-1) elements equal by redistributing the values appropriately.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
total = sum(a)
print(n if total % n == 0 else n - 1)
```

### Explanation
- **Input Reading**: The code reads the input values for the array size and the array elements.
- **Sum Calculation**: The sum of the array elements is computed.
- **Divisibility Check**: The code checks if the sum is divisible by the array size. If it is, the maximum number of equal elements is n. Otherwise, it is n-1.

This approach efficiently determines the result in O(n) time complexity, which is optimal for the problem constraints.
