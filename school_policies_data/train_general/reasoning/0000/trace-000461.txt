To solve this problem, we need to find the number of non-empty contiguous subarrays in a given array whose sums are zero. Given the constraints, an efficient approach is necessary to handle large input sizes up to 200,000 elements.

### Approach
The key insight is to use prefix sums and a hash map (dictionary) to efficiently count the number of valid subarrays. Here's the detailed approach:

1. **Prefix Sum Array**: Compute the prefix sum array where each element at index `i` represents the sum of the array elements from the start up to index `i-1`.
2. **Hash Map Tracking**: Use a hash map to keep track of the frequency of each prefix sum encountered. This allows us to determine how many times a particular prefix sum has been seen before, which helps in counting subarrays that sum to zero.
3. **Efficient Counting**: For each element in the array, update the current prefix sum and check how many times this sum has been seen before. Each occurrence of a repeated prefix sum indicates a subarray that sums to zero, starting just after the previous occurrence of that sum to the current index.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    current_sum = 0
    prefix_counts = defaultdict(int)
    prefix_counts[0] = 1
    total = 0
    for num in a:
        current_sum += num
        total += prefix_counts[current_sum]
        prefix_counts[current_sum] += 1
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially for large inputs. The first value is the length of the array, followed by the array elements.
2. **Prefix Sum Calculation**: As we iterate through each element, we maintain a running sum (`current_sum`) which represents the prefix sum up to the current element.
3. **Hash Map Usage**: The hash map (`prefix_counts`) keeps track of how many times each prefix sum has been encountered. Initially, the sum of 0 is set with a count of 1 to handle cases where the subarray starts from the beginning.
4. **Counting Valid Subarrays**: For each element, after updating the current prefix sum, we check how many times this sum has been seen before. Each occurrence contributes to the count of valid subarrays. The count is then updated in the hash map.

This approach efficiently counts the valid subarrays in linear time, O(N), making it suitable for large input sizes as specified in the problem constraints.
