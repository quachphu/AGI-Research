To solve this problem, we need to determine how many terms of a geometric progression Masha will write on the board, considering that she skips terms that are in a given list of bad integers. If the terms can be written infinitely, we should return "inf".

### Approach
1. **Initial Setup**: Read the input values, including the initial term (b1), common ratio (q), maximum absolute value (l), and the list of bad integers.
2. **Term Generation**: Generate terms of the geometric progression one by one until the absolute value of the term exceeds l.
3. **Cycle Detection**: Check for conditions that could lead to an infinite number of terms being written:
   - If the common ratio (q) is 1, the terms will be constant. If such a term is allowed (absolute value ≤ l) and not in the bad list, it leads to an infinite count.
   - If the common ratio (q) is -1, the terms will alternate between two values. If both values are allowed and not in the bad list, it leads to an infinite count.
   - If a term becomes zero and is allowed and not in the bad list, all subsequent terms will be zero, leading to an infinite count.
4. **Term Tracking**: Use a set to track seen terms to avoid infinite loops caused by cycles not covered by the three specific cases mentioned.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    b1 = int(input[0])
    q = int(input[1])
    l = int(input[2])
    m = int(input[3])
    bad_set = set(map(int, input[4:4+m]))
    
    current = b1
    count = 0
    seen = set()
    
    while True:
        if abs(current) > l:
            break
        if current in seen:
            break
        seen.add(current)
        if current not in bad_set:
            count += 1
        
        next_term = current * q
        
        # Check if next_term leads to infinite condition
        if abs(next_term) <= l and next_term not in bad_set:
            if next_term == current or (q == -1 and next_term == -current) or next_term == 0:
                print("inf")
                return
        
        current = next_term
    
    print(count)

main()
```

### Explanation
- **Reading Input**: The input values are read and parsed into the respective variables. The bad integers are stored in a set for O(1) lookups.
- **Loop Through Terms**: The loop continues generating terms of the geometric progression until the absolute value exceeds l or a cycle is detected.
- **Cycle Detection**: After generating each term, the code checks if the next term could lead to an infinite loop by evaluating the three specific cases (constant terms, alternating terms, and zero terms).
- **Tracking Seen Terms**: A set is used to track terms that have already been processed to avoid infinite loops due to unexpected cycles.

This approach efficiently handles all edge cases and ensures that both finite and infinite scenarios are correctly identified and processed.
