To solve this problem, we need to count the number of non-empty substrings in a given string where all characters in the substring are the same. Each occurrence of such a substring, even at different positions, is considered distinct.

### Approach
1. **Identify Consecutive Character Groups**: The key insight is that substrings with identical characters must be consecutive. For example, in the string "xxxyx", the consecutive groups are "xxx", "y", and "x".
2. **Calculate Substrings for Each Group**: For a group of length `l`, the number of substrings is given by the formula `l * (l + 1) / 2`. This formula accounts for all possible lengths of substrings starting from 1 up to `l`.
3. **Sum Up Contributions**: Sum the contributions from each group to get the total number of valid substrings.

### Solution Code
```python
def count_substrings():
    s = input().strip()
    if not s:
        print(0)
        return
    groups = []
    current_char = s[0]
    count = 1
    for c in s[1:]:
        if c == current_char:
            count += 1
        else:
            groups.append((current_char, count))
            current_char = c
            count = 1
    groups.append((current_char, count))
    total = 0
    for _, l in groups:
        total += l * (l + 1) // 2
    print(total)

count_substrings()
```

### Explanation
1. **Reading Input**: The input string is read and stripped of any leading or trailing whitespace.
2. **Grouping Consecutive Characters**: We iterate through the string, grouping consecutive identical characters. Each time a different character is encountered, the current group is stored, and a new group is started.
3. **Calculating Substrings**: For each group of consecutive characters, we use the formula `l * (l + 1) // 2` to compute the number of valid substrings and accumulate the total.
4. **Output the Result**: The total count is printed as the result.

This approach efficiently processes the string in linear time, making it suitable for the given constraints.
