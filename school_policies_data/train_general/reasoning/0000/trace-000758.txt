To solve this problem, we need to determine the winner of a card game based on the highest points accumulated by players over several rounds. If multiple players have the same highest score, the winner is the one who first reached or exceeded that score during the game.

### Approach
1. **Read Input and Track Scores**: First, we read the number of rounds and each round's details. We then compute the final scores for each player after all rounds.
2. **Identify Candidates**: Determine the maximum score achieved by any player and identify all players (candidates) who have this maximum score.
3. **Simulate Rounds to Find Earliest Achievement**: Re-simulate the rounds step-by-step, tracking the cumulative scores of each candidate. For each candidate, record the earliest round in which their cumulative score first reaches or exceeds the maximum score.
4. **Determine the Winner**: Among the candidates, the winner is the one who first achieved the maximum score in the earliest round.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n = int(sys.stdin.readline())
    rounds = []
    for _ in range(n):
        parts = sys.stdin.readline().split()
        name = parts[0]
        score = int(parts[1])
        rounds.append((name, score))
    
    # Compute final scores
    final_scores = defaultdict(int)
    for name, score in rounds:
        final_scores[name] += score
    
    m = max(final_scores.values())
    candidates = [name for name, sc in final_scores.items() if sc == m]
    
    if len(candidates) == 1:
        print(candidates[0])
        return
    
    # Simulate rounds to find first occurrence of >= m
    current_scores = defaultdict(int)
    first_reached = {name: None for name in candidates}
    
    for step in range(n):
        name, delta = rounds[step]
        current_scores[name] += delta
        
        for candidate in candidates:
            if first_reached[candidate] is None and current_scores[candidate] >= m:
                first_reached[candidate] = step
    
    # Find the candidate with the smallest step
    min_step = n
    winner = None
    for name in candidates:
        if first_reached[name] < min_step:
            min_step = first_reached[name]
            winner = name
    print(winner)

if __name__ == "__main__":
    main()
```
