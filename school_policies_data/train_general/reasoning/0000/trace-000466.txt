To solve this problem, we need to determine the maximum total value of items that can be placed into a knapsack without exceeding its weight capacity. Given the constraints, a dynamic programming approach based on values rather than weights is optimal.

### Approach
1. **Problem Analysis**: The knapsack problem is a classic optimization problem. Given the constraints where the weight capacity can be extremely large, a traditional dynamic programming approach based on weight is infeasible. Instead, we use an approach based on the total value of items.
2. **Dynamic Programming Insight**: We use a dynamic programming array `dp` where `dp[v]` represents the minimum weight required to achieve a total value `v`. This approach leverages the fact that the maximum possible total value of items is manageable (up to 10,000 for 100 items each with a maximum value of 100).
3. **Algorithm**:
   - Initialize the `dp` array with infinity (a large number) to represent impossible values, except `dp[0]` which is 0 (no value requires no weight).
   - For each item, update the `dp` array from the highest possible value down to the item's value to ensure each item is only considered once.
   - After processing all items, the maximum value achievable with a weight within the knapsack's capacity is found by iterating from the highest possible value downwards.

### Solution Code
```python
import sys

def main():
    N, W = map(int, sys.stdin.readline().split())
    items = []
    total_value = 0
    for _ in range(N):
        v, w = map(int, sys.stdin.readline().split())
        items.append((v, w))
        total_value += v
    
    dp = [float('inf')] * (total_value + 1)
    dp[0] = 0
    
    for v_i, w_i in items:
        for v in range(total_value, v_i - 1, -1):
            if dp[v - v_i] + w_i < dp[v]:
                dp[v] = dp[v - v_i] + w_i
    
    max_value = 0
    for v in range(total_value, -1, -1):
        if dp[v] <= W:
            max_value = v
            break
    
    print(max_value)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of items `N`, the weight capacity `W`, and a list of items with their respective values and weights.
2. **Dynamic Programming Initialization**: The `dp` array is initialized to store the minimum weight required to achieve each possible value. Initially, all values except `dp[0]` are set to infinity.
3. **Updating DP Array**: For each item, iterate backwards through possible values to update the `dp` array. This ensures each item is only considered once per value, maintaining the 0-1 knapsack constraint.
4. **Finding the Result**: After processing all items, the maximum value achievable within the weight capacity is found by checking from the highest possible value downwards.

This approach efficiently handles large weight capacities by focusing on achievable values, making it feasible even for the upper constraint limits.
