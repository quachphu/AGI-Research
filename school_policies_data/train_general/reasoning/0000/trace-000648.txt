To solve this problem, we need to determine the minimum number of operations required to transform a pair of integers into an m-perfect pair, where at least one number in the pair is greater than or equal to m. The allowed operation is to replace one of the numbers with their sum.

### Approach
1. **Immediate Check**: If either of the initial numbers is already greater than or equal to m, no operations are needed, so we return 0.
2. **Simulation of Operations**: If neither number meets the requirement initially, we simulate the operations by always replacing the smaller of the two numbers with their sum. This strategy helps in maximizing the growth of the numbers.
3. **Impossibility Check**: During each iteration, we check if the sum of the current pair is less than or equal to both the maximum and minimum of the current pair. If this condition is met, it means further operations will not help in reaching the target m, and we return -1.

### Solution Code
```python
def compute_steps(x, y, m):
    a, b = x, y
    if a >= m or b >= m:
        return 0
    steps = 0
    while True:
        if a >= m or b >= m:
            return steps
        s = a + b
        if s <= max(a, b) and s <= min(a, b):
            return -1
        if a < b:
            a = s
        else:
            b = s
        steps += 1

# Read input
x, y, m = map(int, input().split())
result = compute_steps(x, y, m)
print(result if result != -1 else -1)
```

### Explanation
1. **Immediate Check**: The function first checks if either number in the initial pair (x, y) is already greater than or equal to m. If so, it returns 0 immediately.
2. **Simulation Loop**: The loop continues to replace the smaller number with the sum of both numbers. This ensures that we maximize the growth of the numbers towards the target m.
3. **Impossibility Condition**: During each iteration, we check if the sum of the current pair is not helping to increase the maximum value. If the sum is less than or equal to both the maximum and minimum values of the current pair, it means further operations will not help, and we return -1.

This approach efficiently handles both the growth of numbers and checks for impossibility, ensuring optimal performance even for large values.
