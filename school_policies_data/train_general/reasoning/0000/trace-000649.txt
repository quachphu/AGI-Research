To solve this problem, we need to count the number of right-angled triangles in a grid where the vertices are '*' characters and the right angle is formed by two sides parallel to the grid's axes. 

### Approach
1. **Grid Analysis**: For each '*' in the grid, determine how many '*' characters exist in its row and column. This helps in calculating potential right-angled triangles with the current '*' as the right-angle vertex.
2. **Row and Column Preprocessing**: Precompute the number of '*' characters in each row and each column. This allows efficient lookup during the main calculation phase.
3. **Triangle Counting**: For each '*' in the grid, use the precomputed row and column counts to determine how many right-angled triangles can be formed with that '*' as the right-angle vertex. The number of such triangles is the product of the number of other '*' characters in the same row and the number of other '*' characters in the same column.

### Solution Code
```python
n, m = map(int, input().split())
grid = [input().strip() for _ in range(n)]

row_counts = [row.count('*') for row in grid]

col_counts = [0] * m
for j in range(m):
    cnt = 0
    for i in range(n):
        if grid[i][j] == '*':
            cnt += 1
    col_counts[j] = cnt

total = 0
for i in range(n):
    for j in range(m):
        if grid[i][j] == '*':
            rc = row_counts[i] - 1
            cc = col_counts[j] - 1
            total += rc * cc

print(total)
```

### Explanation
1. **Reading Input**: The grid dimensions and the grid itself are read from the input.
2. **Row Count Calculation**: For each row, count the number of '*' characters and store these counts in `row_counts`.
3. **Column Count Calculation**: For each column, count the number of '*' characters by iterating through each row and store these counts in `col_counts`.
4. **Triangle Calculation**: For each '*' in the grid, compute the number of other '*' characters in its row and column. The product of these two values gives the number of right-angled triangles that can be formed with the current '*' as the right-angle vertex. Sum these products to get the total count.

This approach efficiently preprocesses row and column counts, allowing each '*' to be processed in constant time, leading to an overall time complexity of O(n*m), which is optimal for the given problem constraints.
