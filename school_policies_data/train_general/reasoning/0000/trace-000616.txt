To solve this problem, we need to determine the shortest path between two vertices in a tree that must pass through a specific vertex K. The solution involves efficiently computing the distances from vertex K to all other vertices and then using these precomputed distances to answer each query in constant time.

### Approach
1. **Tree Representation**: Represent the tree using an adjacency list where each node points to its neighbors along with the edge weights.
2. **Distance Calculation**: Use a Breadth-First Search (BFS) starting from vertex K to compute the shortest distance from K to all other vertices. This is feasible because the tree structure guarantees a unique path between any two vertices.
3. **Query Processing**: For each query, the result is the sum of the precomputed distances from the two query vertices to vertex K.

### Solution Code
```python
import sys
from collections import deque

def main():
    data = sys.stdin.read().split()
    ptr = 0
    N = int(data[ptr])
    ptr += 1
    
    adjacency = [[] for _ in range(N)]
    for _ in range(N - 1):
        a = int(data[ptr]) - 1
        b = int(data[ptr + 1]) - 1
        c = int(data[ptr + 2])
        adjacency[a].append((b, c))
        adjacency[b].append((a, c))
        ptr += 3
    
    Q = int(data[ptr])
    K = int(data[ptr + 1]) - 1
    ptr += 2
    
    queries = []
    for _ in range(Q):
        x = int(data[ptr]) - 1
        y = int(data[ptr + 1]) - 1
        queries.append((x, y))
        ptr += 2
    
    # Compute distances from K using BFS
    dist = [-1] * N
    dist[K] = 0
    q = deque([K])
    
    while q:
        u = q.popleft()
        for v, c in adjacency[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + c
                q.append(v)
    
    # Process queries and print results
    for x, y in queries:
        print(dist[x] + dist[y])

if __name__ == '__main__':
    main()
```

### Explanation
1. **Tree Representation**: The tree is read and stored as an adjacency list where each node maintains a list of tuples representing its neighbors and the corresponding edge weights.
2. **BFS for Distance Calculation**: Starting from vertex K, we use BFS to traverse the tree. For each node visited, we update its distance from K using the edge weights. This ensures that each node is processed exactly once, leading to an O(N) time complexity.
3. **Query Processing**: Each query is answered in constant time by summing the precomputed distances from the two query vertices to K. This leverages the fact that the shortest path through K is the sum of the paths from each query vertex to K.

This approach efficiently handles the constraints, ensuring optimal performance even for large input sizes up to 100,000 nodes and queries.
