To solve this problem, we need to count the number of non-empty palindromic substrings in a given string. A substring is considered palindromic if it reads the same forwards and backwards. 

### Approach
1. **Generate All Substrings**: For each possible start and end index in the string, generate the corresponding substring. This involves checking all substrings starting from each character and extending to the end of the string.
2. **Check for Palindrome**: For each generated substring, check if it is a palindrome by comparing the substring with its reverse.
3. **Count Palindromic Substrings**: Maintain a count of all substrings that are found to be palindromic.

Given the constraints (maximum string length of 50), a brute-force approach is feasible. This approach involves checking all possible substrings, which is manageable due to the limited input size.

### Solution Code
```python
def count_palindromic_substrings():
    s = input().strip()
    count = 0
    n = len(s)
    for i in range(n):
        for j in range(i, n):
            substr = s[i:j+1]
            if substr == substr[::-1]:
                count += 1
    print(count)

count_palindromic_substrings()
```

### Explanation
1. **Reading Input**: The input string is read from standard input.
2. **Nested Loops for Substrings**: The outer loop iterates over each possible starting index of a substring. The inner loop extends the substring from the current starting index to each possible ending index.
3. **Palindrome Check**: For each substring generated by the indices from the loops, check if the substring is equal to its reverse. If it is, increment the count.
4. **Output the Result**: After processing all possible substrings, print the total count of palindromic substrings.

This approach ensures that all possible substrings are checked efficiently within the given constraints, providing an accurate count of palindromic substrings.
