To solve this problem, we need to find the maximum sum of the longest alternating subsequence from a given sequence of integers. An alternating subsequence is defined as a sequence where each consecutive element has the opposite sign. The goal is to maximize the sum of such a subsequence while ensuring it is the longest possible.

### Approach
1. **Group Consecutive Elements**: Iterate through the sequence and group consecutive elements with the same sign. For each group, track the maximum element as it contributes the most to the sum.
2. **Sum Maximum Elements**: For each group of consecutive elements with the same sign, add the maximum element of that group to the total sum. This ensures the subsequence is the longest possible and the sum is maximized.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        a = list(map(int, input[ptr:ptr + n]))
        ptr += n
        if not a:
            print(0)
            continue
        current_max = a[0]
        current_sign = 1 if current_max > 0 else -1
        total = 0
        for num in a[1:]:
            sign = 1 if num > 0 else -1
            if sign == current_sign:
                if num > current_max:
                    current_max = num
            else:
                total += current_max
                current_sign = sign
                current_max = num
        total += current_max
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Processing Each Test Case**: For each test case, we read the sequence and process it.
3. **Grouping Elements**: As we iterate through the sequence, we group consecutive elements by their sign. For each group, we keep track of the maximum element.
4. **Updating Sum**: When the sign changes, we add the maximum element of the current group to the total sum and start a new group with the current element.
5. **Final Sum Calculation**: After processing all elements, the maximum element of the last group is added to the total sum to complete the calculation.

This approach ensures that we efficiently compute the longest alternating subsequence with the maximum possible sum in linear time, making it suitable for large input sizes.
