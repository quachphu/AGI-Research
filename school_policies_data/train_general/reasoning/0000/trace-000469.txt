To solve this problem, we need to determine the minimal number of jumps Chef needs to move from the first digit to the last digit in a sequence. Chef can jump to adjacent digits or any digit with the same value. The solution involves using Breadth-First Search (BFS) to efficiently explore the shortest path, leveraging a dictionary to handle same-digit jumps optimally.

### Approach
1. **Preprocessing**: Create a dictionary where each key is a digit and the value is a list of indices where that digit occurs. This helps in quickly accessing all positions of the same digit.
2. **BFS Initialization**: Use a queue to manage the BFS process starting from the first index (0). Track visited indices and their distances from the start.
3. **Processing Each Node**:
   - Check adjacent indices (left and right).
   - For the current digit, check all indices from the preprocessed list, enqueue them if unvisited, and then clear the list to avoid reprocessing.
4. **Termination**: The BFS ensures that the first time we reach the last index, it is via the shortest path.

### Solution Code
```python
from collections import deque
from sys import stdin

def minimal_jumps(s):
    n = len(s)
    if n == 1:
        return 0
    digit_indices = {}
    for idx, c in enumerate(s):
        if c not in digit_indices:
            digit_indices[c] = []
        digit_indices[c].append(idx)
    visited = [False] * n
    distance = [0] * n
    q = deque()
    q.append(0)
    visited[0] = True
    while q:
        current = q.popleft()
        current_dist = distance[current]
        if current == n - 1:
            return current_dist
        # Check left neighbor
        left = current - 1
        if left >= 0 and not visited[left]:
            visited[left] = True
            distance[left] = current_dist + 1
            q.append(left)
        # Check right neighbor
        right = current + 1
        if right < n and not visited[right]:
            visited[right] = True
            distance[right] = current_dist + 1
            q.append(right)
        # Check same digits
        current_char = s[current]
        if current_char in digit_indices:
            same_indices = digit_indices[current_char]
            for idx in same_indices:
                if not visited[idx]:
                    visited[idx] = True
                    distance[idx] = current_dist + 1
                    q.append(idx)
            # Clear to prevent future processing
            del digit_indices[current_char]
    return -1  # This line is theoretically unreachable as per problem constraints

s = stdin.read().strip()
print(minimal_jumps(s))
```

### Explanation
- **Preprocessing**: The dictionary `digit_indices` maps each digit to its positions, allowing efficient same-digit jumps.
- **BFS Queue**: Starts at the first index, exploring adjacent and same-digit indices. Each index is processed once to ensure efficiency.
- **Distance Tracking**: The `distance` array keeps track of the minimal jumps required to reach each index, ensuring the shortest path is found.
- **Same-Digit Optimization**: By clearing the list of indices for a digit after processing, we avoid redundant checks, ensuring the algorithm runs in linear time, O(N), where N is the length of the input string.

This approach efficiently combines BFS with preprocessing to handle same-digit jumps optimally, ensuring minimal computational complexity and correct results.
