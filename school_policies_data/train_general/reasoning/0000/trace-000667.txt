To solve this problem, we need to determine the maximum possible number of moves Aoki has to make when traveling between any two road squares in a maze, following the shortest path. The solution involves using a breadth-first search (BFS) algorithm to compute the shortest path from each road square to all other road squares and then finding the maximum value among these shortest paths.

### Approach
1. **Input Reading and Road Collection**: Read the maze dimensions and grid. Collect all coordinates of road squares (denoted by '.').
2. **BFS for Each Road Square**: For each road square, perform a BFS to compute the shortest path to all other road squares. Track the maximum distance encountered during each BFS.
3. **Determine Maximum Distance**: After performing BFS from each road square, the overall maximum distance found across all BFS runs is the answer.

### Solution Code
```python
import sys
from collections import deque

def main():
    H, W = map(int, sys.stdin.readline().split())
    grid = [sys.stdin.readline().strip() for _ in range(H)]
    
    roads = []
    for i in range(H):
        for j in range(W):
            if grid[i][j] == '.':
                roads.append((i, j))
    
    max_dist = 0
    for start in roads:
        i, j = start
        dist = [[-1] * W for _ in range(H)]
        q = deque()
        dist[i][j] = 0
        q.append((i, j))
        
        while q:
            x, y = q.popleft()
            for dx, dy in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                nx = x + dx
                ny = y + dy
                if 0 <= nx < H and 0 <= ny < W:
                    if grid[nx][ny] == '.' and dist[nx][ny] == -1:
                        dist[nx][ny] = dist[x][y] + 1
                        q.append((nx, ny))
        
        current_max = max(dist[x][y] for x, y in roads)
        if current_max > max_dist:
            max_dist = current_max
    
    print(max_dist)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input and Collecting Roads**: The input is read and stored in a grid. Each cell is checked to see if it is a road ('.'), and these coordinates are stored in a list.
2. **BFS Execution**: For each road square, a BFS is initiated. The BFS computes the shortest path from the starting road square to all other road squares, updating a distance matrix.
3. **Tracking Maximum Distance**: After each BFS completes, the maximum distance from the starting road square to any other road square is determined and compared with the global maximum distance.
4. **Output the Result**: The global maximum distance is printed as the result, representing the longest shortest path between any two road squares in the maze.

This approach efficiently computes the required maximum shortest path by leveraging BFS, ensuring that each road square is processed, and the shortest paths are computed optimally. The complexity is manageable given the constraints, making this solution both effective and efficient.
