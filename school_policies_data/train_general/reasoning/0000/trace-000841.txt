To solve this problem, we need to determine the number of "Very Cool" integers between 1 and R for each test case. A number is considered "Very Cool" if its "Coolness" (the number of times the substring "101" appears in its binary representation) is greater than or equal to K.

### Approach
1. **Precompute Coolness Values**: For each integer from 1 to 100,000, compute its Coolness value. This is done by converting the number to its binary string representation and counting occurrences of the substring "101".
2. **Prefix Sum Arrays for Efficient Querying**: Precompute prefix sum arrays for each possible K value (from 1 to 15) to quickly answer how many numbers up to a given R have a Coolness value of at least K. For K values greater than 15, the result is always 0 because the maximum possible Coolness value for numbers up to 100,000 is 15.

### Solution Code
```python
max_R = 10**5
coolness = [0] * (max_R + 1)

for n in range(1, max_R + 1):
    s = bin(n)[2:]
    cnt = 0
    for i in range(len(s) - 2):
        if s[i:i+3] == '101':
            cnt += 1
    coolness[n] = cnt

max_K_precompute = 15
prefix = [[0] * (max_R + 1) for _ in range(max_K_precompute + 1)]

for K in range(1, max_K_precompute + 1):
    current = 0
    for r in range(1, max_R + 1):
        if coolness[r] >= K:
            current += 1
        prefix[K][r] = current

import sys

def main():
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        R = int(input[idx])
        K = int(input[idx+1])
        idx += 2
        if K > max_K_precompute:
            print(0)
        else:
            print(prefix[K][R])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precompute Coolness Values**: For each number from 1 to 100,000, convert it to its binary string and count the occurrences of "101". This is stored in an array `coolness` where `coolness[n]` gives the Coolness of number `n`.
2. **Prefix Sum Arrays**: For each K from 1 to 15, create a prefix sum array `prefix[K]` where `prefix[K][r]` stores the count of numbers from 1 to `r` with Coolness at least K. This allows each query to be answered in constant time.
3. **Efficient Query Handling**: For each test case, if K is greater than 15, the result is 0. Otherwise, use the precomputed prefix sum array to quickly get the result for the given R and K.

This approach ensures that we efficiently handle up to 100 test cases with the constraints given, providing results in optimal time after an initial preprocessing step.
