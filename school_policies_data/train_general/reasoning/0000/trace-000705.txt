To solve this problem, we need to determine the number of pairs of watchmen where the Manhattan distance (calculated by Doctor Manhattan) is equal to the Euclidean distance (calculated by Daniel). The key insight is that these distances are equal if and only if either the x-coordinates or y-coordinates of the pair are the same.

### Approach
1. **Count Frequencies**: Use dictionaries to count the occurrences of each x-coordinate, y-coordinate, and (x, y) pair among the watchmen.
2. **Calculate Pairs**: For each unique x-coordinate, y-coordinate, and (x, y) pair, compute the number of valid pairs using the combination formula \( \binom{n}{2} = \frac{n(n-1)}{2} \).
3. **Adjust for Overlaps**: Subtract the number of pairs where both x and y coordinates are the same to avoid double-counting these pairs.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n = int(sys.stdin.readline())
    x_counts = defaultdict(int)
    y_counts = defaultdict(int)
    xy_counts = defaultdict(int)
    for _ in range(n):
        x, y = map(int, sys.stdin.readline().split())
        x_counts[x] += 1
        y_counts[y] += 1
        xy_counts[(x, y)] += 1
    
    total_x = sum(k * (k - 1) // 2 for k in x_counts.values())
    total_y = sum(k * (k - 1) // 2 for k in y_counts.values())
    total_xy = sum(k * (k - 1) // 2 for k in xy_counts.values())
    
    print(total_x + total_y - total_xy)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed to extract the number of watchmen and their coordinates.
2. **Counting Occurrences**: Three dictionaries (`x_counts`, `y_counts`, `xy_counts`) are used to track how many times each x-coordinate, y-coordinate, and (x, y) pair appears.
3. **Calculating Pairs**: For each unique x-coordinate and y-coordinate, the number of valid pairs is calculated using the combination formula. Similarly, the number of pairs with the same (x, y) coordinates is calculated.
4. **Adjusting for Overlaps**: The total number of valid pairs is computed by summing the pairs from x and y coordinates and subtracting the overlapping pairs counted twice.

This approach efficiently counts the required pairs using linear time complexity relative to the number of watchmen, ensuring it handles the upper constraint of 200,000 watchmen effectively.
