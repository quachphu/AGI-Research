To solve this problem, we need to determine how many numbers in a given array are k-good. A k-good number is defined as a number that contains all digits from 0 to k inclusive. 

### Approach
1. **Understanding the Problem**: We need to check each number in the array to see if it contains every digit from 0 up to k. If a number meets this criterion, it is counted as k-good.
2. **Reading Input**: The input consists of two integers, n (number of elements) and k, followed by n numbers.
3. **Required Digits**: For a given k, generate the set of digits that must be present in a number for it to be k-good. This set includes all digits from 0 to k.
4. **Check Each Number**: For each number in the array, convert it to a string and check if all required digits are present using set operations.
5. **Count Valid Numbers**: Increment the count for each number that meets the criteria and print the result.

### Solution Code
```python
n, k = map(int, input().split())
required = set(str(d) for d in range(k + 1))
count = 0
for _ in range(n):
    s = input().strip()
    if required.issubset(set(s)):
        count += 1
print(count)
```

### Explanation
1. **Reading Input**: The first line of input is read to get the values of n and k.
2. **Generating Required Digits**: Using a set comprehension, we generate the set of digits from 0 to k. This set will be used to check each number.
3. **Processing Each Number**: For each number in the input, convert it to a string and then to a set of characters (digits). This allows us to efficiently check if all required digits are present using the `issubset` method.
4. **Counting Valid Numbers**: If a number contains all required digits, it is counted. The total count is printed at the end.

This approach efficiently checks each number using set operations, ensuring that the solution is both clear and optimal.
