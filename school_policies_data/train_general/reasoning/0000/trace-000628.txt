To solve this problem, we need to determine the number of ways 2n people sitting around a round table can shake hands without any pairs crossing each other. The solution involves using Catalan numbers, which are a sequence of natural numbers with applications in combinatorial mathematics, particularly in problems involving non-crossing partitions.

### Approach
1. **Catalan Numbers**: The problem of non-crossing handshakes around a round table is equivalent to finding the nth Catalan number. Catalan numbers count the number of ways to correctly match parentheses, the number of non-crossing partitions, and more.
2. **Dynamic Programming**: We precompute the Catalan numbers up to the maximum possible value of N (999) using dynamic programming. This allows us to answer each query in constant time after the precomputation.
3. **Modulo Operation**: Since the result can be very large, we take modulo 100003 at each step to ensure the numbers remain manageable and fit within standard integer limits.

### Solution Code
```python
def main():
    MOD = 100003
    MAX_N = 999

    catalan = [0] * (MAX_N + 1)
    catalan[0] = 1

    for n in range(1, MAX_N + 1):
        for i in range(n):
            catalan[n] += catalan[i] * catalan[n - 1 - i]
            catalan[n] %= MOD

    t = int(input())
    for _ in range(t):
        n = int(input())
        print(catalan[n])

main()
```

### Explanation
1. **Catalan Number Calculation**: We use a dynamic programming approach to compute the nth Catalan number. The nth Catalan number is given by the sum of the products of the ith and (n-1-i)th Catalan numbers for i from 0 to n-1.
2. **Precomputation**: We precompute the Catalan numbers up to the maximum value of N (999) to efficiently answer each query. This precomputation is done once and stored in an array.
3. **Modulo Operation**: Each step of the computation uses modulo 100003 to keep the numbers within bounds and ensure we can handle large values efficiently.

This approach ensures that we efficiently compute the result for each test case in constant time after an initial O(N^2) precomputation, which is feasible given the constraints.
