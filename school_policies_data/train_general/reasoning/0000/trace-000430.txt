To solve this problem, we need to determine the number of subarrays (contiguous subsequences) of a given sequence of non-zero integers that have a negative product and those that have a positive product. The solution efficiently tracks the count of such subarrays using dynamic programming principles to avoid an O(n^2) brute-force approach.

### Approach
1. **Key Insight**: The product of a subarray is negative if it contains an odd number of negative integers and positive if it contains an even number of negative integers (including zero negatives).
2. **Dynamic Tracking**: As we iterate through each element of the array, we maintain counts of subarrays ending at the current position that have an even or odd number of negative integers.
3. **Update Rules**:
   - For each positive number, the count of subarrays with even negative integers increases by extending previous even subarrays and starting a new subarray with the current element.
   - For each negative number, the parity (even/odd) of the count of negatives in subarrays is flipped. Thus, the counts of even and odd subarrays are swapped and updated accordingly.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    
    current_even = 0
    current_odd = 0
    total_even = 0
    total_odd = 0
    
    for num in a:
        if num > 0:
            new_even = current_even + 1
            new_odd = current_odd
        else:
            new_even = current_odd
            new_odd = current_even + 1
        
        total_even += new_even
        total_odd += new_odd
        current_even, current_odd = new_even, new_odd
    
    print(total_odd, total_even)

main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Initialization**: We initialize counters to keep track of subarrays ending at the current position with even (`current_even`) and odd (`current_odd`) counts of negative numbers.
3. **Iterate Through Elements**: For each element, based on whether it is positive or negative, we update the counts of even and odd subarrays ending at that position.
4. **Update Totals**: The total counts of even and odd subarrays are updated by adding the current counts for each position.
5. **Output**: Finally, the counts of subarrays with negative (odd count) and positive (even count) products are printed.

This approach ensures that we efficiently compute the result in O(n) time, making it suitable for large input sizes up to 200,000 elements.
