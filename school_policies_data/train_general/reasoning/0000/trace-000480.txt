To solve this problem, we need to determine the outcome of a game where Koa and her friend take turns removing elements from an array, each time XOR-ing their current score with the chosen element. The goal is to determine if Koa will win, lose, or draw if both play optimally.

### Approach
1. **Total XOR Calculation**: Compute the XOR of all elements in the array. If the total XOR is zero, the game ends in a draw because both players will end up with the same score.
2. **Highest Bit Determination**: If the total XOR is non-zero, determine the highest bit set in the total XOR. This bit is crucial as it influences the maximum possible score.
3. **Count Elements with Highest Bit**: Count how many elements in the array have this highest bit set. The parity of this count (modulo 4) determines the outcome:
   - If the count modulo 4 is 1, Koa wins.
   - Otherwise, Koa loses.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        a = list(map(int, sys.stdin.readline().split()))
        total_xor = 0
        for num in a:
            total_xor ^= num
        if total_xor == 0:
            print("DRAW")
            continue
        highest_bit = total_xor.bit_length() - 1
        c = 0
        mask = 1 << highest_bit
        for num in a:
            if num & mask:
                c += 1
        if c % 4 == 1:
            print("WIN")
        else:
            print("LOSE")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Total XOR Calculation**: The XOR of all elements is computed. If this value is zero, both players end up with the same score, resulting in a draw.
2. **Highest Bit Determination**: The highest bit set in the total XOR is found using `bit_length() - 1`. This bit is critical as it determines the maximum possible score.
3. **Count Elements with Highest Bit**: Elements having this highest bit set are counted. The count's parity (modulo 4) determines if Koa can secure a win:
   - If the count modulo 4 is 1, Koa can always ensure she ends up with an odd number of elements contributing to this highest bit, leading to a win.
   - Otherwise, the friend can force Koa into an even count, resulting in a loss.

This approach efficiently determines the game's outcome in linear time, making it suitable for large input sizes.
