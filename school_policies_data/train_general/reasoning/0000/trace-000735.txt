To solve this problem, we need to find the maximum sum of the longest increasing subsequence (LIS) in a given sequence. The solution involves dynamic programming to track both the length and the maximum sum of the LIS ending at each position.

### Approach
1. **Dynamic Programming Arrays**: We use two arrays, `dp_length` and `dp_sum`. `dp_length[i]` stores the length of the longest increasing subsequence ending at index `i`, while `dp_sum[i]` stores the maximum sum of such a subsequence.
2. **Initialization**: Initialize `dp_length` to 1 for all elements (each element itself is a subsequence of length 1) and `dp_sum` to the value of each element.
3. **Iterate and Compare**: For each element, compare it with all previous elements. If a previous element is smaller, update the current element's `dp_length` and `dp_sum` based on the longest subsequence found so far. If multiple subsequences of the same length exist, choose the one with the highest sum.
4. **Determine Result**: After processing all elements, find the maximum length of the LIS and then determine the maximum sum among all subsequences of that length.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
if n == 0:
    print(0)
    exit()

dp_length = [1] * n
dp_sum = [0] * n

for i in range(n):
    dp_sum[i] = a[i]
    for j in range(i):
        if a[j] < a[i]:
            if dp_length[j] + 1 > dp_length[i]:
                dp_length[i] = dp_length[j] + 1
                dp_sum[i] = dp_sum[j] + a[i]
            elif dp_length[j] + 1 == dp_length[i]:
                current_sum = dp_sum[j] + a[i]
                if current_sum > dp_sum[i]:
                    dp_sum[i] = current_sum

max_len = max(dp_length)
max_sum = 0

for i in range(n):
    if dp_length[i] == max_len and dp_sum[i] > max_sum:
        max_sum = dp_sum[i]

print(max_sum)
```

### Explanation
1. **Dynamic Programming Setup**: We initialize `dp_length` and `dp_sum` arrays to track the length and sum of the longest increasing subsequence ending at each index.
2. **Nested Loop Comparison**: For each element, we compare it with all previous elements. If a previous element is smaller, we check if extending that subsequence results in a longer subsequence or a higher sum for the same length.
3. **Result Calculation**: After processing all elements, we find the maximum length of the LIS and then determine the maximum sum among all subsequences of that length.

This approach ensures we efficiently compute both the length and the maximum sum of the longest increasing subsequence using dynamic programming, with a time complexity of O(n^2), which is feasible for moderately sized inputs.
