To solve this problem, we need to determine if a directed graph contains any cycles. This can be efficiently done using Depth-First Search (DFS) to track the recursion stack and detect back edges, which indicate the presence of a cycle.

### Approach
1. **Graph Representation**: Read the input and construct the graph using an adjacency list.
2. **DFS Traversal**: Perform a DFS traversal from each unvisited node. Track the nodes in the current recursion stack to detect cycles.
3. **Cycle Detection**: If during the DFS traversal, we encounter a node that is already in the current recursion stack, a cycle is detected. Otherwise, continue the traversal until all nodes are visited.

### Solution Code
```python
import sys

def main():
    sys.setrecursionlimit(10000)
    n, m = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        s, t = map(int, sys.stdin.readline().split())
        adj[s].append(t)
    
    visited = [False] * n
    rec_stack = [False] * n
    
    def dfs(node):
        visited[node] = True
        rec_stack[node] = True
        for neighbor in adj[node]:
            if not visited[neighbor]:
                if dfs(neighbor):
                    return True
            elif rec_stack[neighbor]:
                return True
        rec_stack[node] = False
        return False
    
    for node in range(n):
        if not visited[node]:
            if dfs(node):
                print(1)
                return
    print(0)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Graph Construction**: The graph is represented using an adjacency list where each node points to its neighbors.
2. **DFS with Recursion Stack**: For each node, if it hasn't been visited, start a DFS. During the DFS, mark nodes as visited and keep track of the recursion stack. If we encounter a neighbor that is already in the recursion stack, a cycle is detected.
3. **Cycle Check**: If any DFS traversal detects a cycle, immediately print `1` and exit. If all nodes are processed without detecting a cycle, print `0`.

This approach ensures that each node and edge is processed efficiently, leveraging the properties of DFS to detect cycles in linear time relative to the number of nodes and edges (O(V + E)).
