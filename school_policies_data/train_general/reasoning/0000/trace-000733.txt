To solve this problem, we need to determine if string B can be a fragment of string A, considering that underscores in B act as wildcards that can match any character in A. The solution involves checking all possible substrings of A of the same length as B to see if they match B, with underscores in B allowing any character in the corresponding position of A.

### Approach
1. **Input Reading**: Read the input strings A and B.
2. **Length Check**: If B is empty, immediately return "Yes" (though constraints ensure B is non-empty).
3. **Substring Generation**: Iterate through all possible starting positions in A where a substring of length equal to B can be found.
4. **Substring Comparison**: For each substring of A, check if it matches B. A match occurs if every character in B (excluding underscores) matches the corresponding character in the substring of A. Underscores in B are considered wildcards and match any character in A.
5. **Result Determination**: If any valid substring matches B, print "Yes" and exit. If no matches are found after checking all substrings, print "No".

### Solution Code
```python
def main():
    import sys
    A = sys.stdin.readline().strip()
    B = sys.stdin.readline().strip()
    lenA = len(A)
    lenB = len(B)
    
    for i in range(lenA - lenB + 1):
        substr = A[i:i+lenB]
        match = True
        for j in range(lenB):
            if B[j] != '_' and substr[j] != B[j]:
                match = False
                break
        if match:
            print("Yes")
            return
    print("No")

main()
```

### Explanation
- **Input Reading**: The function reads two lines from standard input, stripping any leading or trailing whitespace to get strings A and B.
- **Substring Generation**: The loop iterates over all possible starting positions in A where a substring of length equal to B can start. This is done using `range(lenA - lenB + 1)`.
- **Substring Comparison**: For each starting position, the substring of A is extracted. Each character of this substring is compared with the corresponding character in B. If B has an underscore, it is considered a wildcard and matches any character. If any character in B (excluding underscores) does not match the corresponding character in the substring, the comparison stops early.
- **Result Determination**: If a valid match is found, "Yes" is printed and the function exits. If all possible substrings are checked and none match, "No" is printed.

This approach efficiently checks all possible substrings of A, ensuring that we correctly identify if B can be a fragment of A with the given wildcard rules. The solution handles all edge cases and constraints effectively.
