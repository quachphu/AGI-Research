def lcm(a, b):

def compute_lcm(numbers):

    if not numbers:

    current = numbers[0]

    return current

To solve this problem, we need to determine the smallest integer \( t \) such that for each person \( x \) in Arpa's land, if \( x \) starts a round of the game, the Joon-Joon of that round is \( y \), and starting a round from \( y \) results in \( x \) becoming the Joon-Joon. The solution involves checking if all people are part of cycles in their crush relationships and then computing the minimal \( t \) based on these cycles.

### Approach
1. **Check for Cycles**: Each person must be part of a cycle in their crush relationships. If any person is not part of a cycle, it is impossible to find such \( t \), and we return -1.
2. **Identify Cycles**: Once all nodes are confirmed to be in cycles, identify each cycle's length.
3. **Compute Required Values for Each Cycle**: For each cycle length \( L \):
   - If \( L \) is odd, the required value is \( L \).
   - If \( L \) is even, the required value is \( L/2 \).
4. **Find Least Common Multiple (LCM)**: The smallest \( t \) that satisfies all cycles is the LCM of the required values computed for each cycle.

### Solution Code
```python
from math import gcd

def main():
    n = int(input())
    crush = list(map(int, input().split()))
    
    # Check if all nodes are part of a cycle
    for x in range(1, n + 1):
        visited = set()
        current = x
        while current not in visited:
            visited.add(current)
            current = crush[current - 1]
        if current != x:
            print(-1)
            return
    
    # Find all cycles
    visited = set()
    cycles = []
    for x in range(1, n + 1):
        if x not in visited:
            path = []
            current = x
            while current not in path:
                path.append(current)
                current = crush[current - 1]
            idx = path.index(current)
            cycle = path[idx:]
            cycles.append(cycle)
            for node in cycle:
                visited.add(node)
    
    # Calculate the required components for each cycle
    components = []
    for cycle in cycles:
        L = len(cycle)
        if L % 2 == 0:
            components.append(L // 2)
        else:
            components.append(L)
    
    # Compute LCM of components
    def lcm(a, b):
        return a * b // gcd(a, b)
    
    t = 1
    for c in components:
        t = lcm(t, c)
    
    print(t)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Cycle Check**: For each person, we traverse their crush relationships until we find a cycle. If a person does not lead back to themselves in this traversal, they are not part of a valid cycle, and we return -1.
2. **Cycle Identification**: We collect all cycles in the crush graph. Each cycle is identified by following the crush relationships until we encounter a node already visited in the current path.
3. **Component Calculation**: For each identified cycle, we compute the required value based on whether the cycle length is odd or even.
4. **LCM Calculation**: The smallest \( t \) that works for all cycles is found by computing the LCM of all the required values from each cycle. This ensures that \( t \) is the minimal value satisfying the problem's conditions for all cycles.
