To solve this problem, we need to determine the last digit of the number \(1378^n\). The key insight is that the last digit of a number raised to a power follows a repeating cycle, which allows us to compute the result efficiently even for very large exponents.

### Approach
1. **Identify the Last Digit Cycle**: The last digit of \(1378\) is \(8\). Therefore, the problem reduces to finding the last digit of \(8^n\).
2. **Determine the Cycle**: The last digits of powers of \(8\) follow a cycle: 8, 4, 2, 6. This cycle repeats every 4 numbers.
3. **Handle Special Case for Zero**: Any number raised to the power of 0 is 1, so when \(n = 0\), the result is 1.
4. **Use Modulo Operation**: For \(n \geq 1\), the position within the cycle can be determined using \((n - 1) \% 4\), which gives the correct index in the cycle array.

### Solution Code
```python
n = int(input())
if n == 0:

else:

    print(cycle[(n - 1) % 4])
```

1. **Reading Input**: The code reads an integer \(n\) from standard input.
2. **Check for Zero**: If \(n\) is 0, the output is directly 1.
3. **Cycle Calculation**: For \(n \geq 1\), the code uses the modulo operation to find the position within the cycle array. The cycle array [8, 4, 2, 6] is indexed using \((n - 1) \% 4\) to get the correct last digit.

This approach efficiently computes the result in constant time \(O(1)\) by leveraging the repeating cycle of the last digits, making it suitable even for very large values of \(n\) up to \(10^9\).
