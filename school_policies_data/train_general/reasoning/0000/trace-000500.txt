To solve this problem, we need to determine the minimum amount of cash Michael has to spend on charging his electric car over a series of days, considering he can use a bonus card to offset some costs. The bonus card allows him to either save cash immediately or accumulate more bonus points for future use. The challenge is to balance between using the bonus points optimally and accumulating them for future savings.

### Approach
1. **Dynamic Programming with State Pruning**: We use a dynamic programming approach where each state represents the current bonus balance and the total cash spent. For each day, we consider two options: using the maximum possible bonus points or paying the full amount to accumulate more bonus points.
2. **State Pruning**: To efficiently manage the states, we prune dominated states. A state is dominated if there exists another state with a higher bonus balance and lower cash spent. This ensures we only keep the most beneficial states.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    
    # Each state is a tuple (bonus, cash_spent)
    states = [(0, 0)]
    
    for x in a:
        new_states = []
        for (b, c) in states:
            # Option 1: Use maximum possible bonus
            y = min(b, x)
            new_b1 = b - y
            new_c1 = c + (x - y)
            new_states.append((new_b1, new_c1))
            
            # Option 2: Pay full to gain bonus
            new_b2 = b + x // 10
            new_c2 = c + x
            new_states.append((new_b2, new_c2))
        
        # Prune dominated states
        # Sort by bonus in ascending order
        sorted_states = sorted(new_states, key=lambda p: p[0])
        pruned = []
        min_c = float('inf')
        # Iterate in reverse to keep the lowest cash for each bonus level
        for p in reversed(sorted_states):
            if p[1] < min_c:
                pruned.append(p)
                min_c = p[1]
        # Reverse to maintain order by bonus
        pruned.reverse()
        states = pruned
    
    # Find the minimum cash spent
    min_cash = min(c for _, c in states)
    print(min_cash)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of the number of days and the daily charging costs.
2. **State Initialization**: Start with an initial state of zero bonus and zero cash spent.
3. **Processing Each Day**: For each day, generate new states based on the two possible actions (using maximum bonus or paying full to accumulate more bonus).
4. **Pruning States**: After generating new states for each day, we sort them by bonus balance and prune dominated states to keep the number of states manageable.
5. **Finding Minimum Cash**: After processing all days, the minimum cash spent is determined from the remaining states.

This approach ensures that we efficiently explore the optimal balance between using bonus points and accumulating them, leading to the minimum possible cash expenditure.
