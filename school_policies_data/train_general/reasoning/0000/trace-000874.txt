2. **Two-pointer Technique for Sum1**: For each element \( a_i \), find the maximum index \( j \) such that \( a_i \times a_j < p \). The number of valid pairs for each \( a_i \) is \( j + 1 \) (since indices start from 0).

import bisect
import math
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
