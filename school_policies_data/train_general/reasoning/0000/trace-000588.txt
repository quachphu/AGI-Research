### Approach
1. **Problem Analysis**: The problem requires counting subarrays where at least one number appears at least `k` times. Directly checking all possible subarrays is infeasible due to the large input size, so we need an optimized approach.

2. **Key Insight**: Instead of counting valid subarrays directly, we compute the total number of subarrays and subtract the number of invalid subarrays (those where all elements appear fewer than `k` times).

3. **Sliding Window Technique**: We maintain a sliding window with two pointers (left and right) to track the longest valid window where all elements have counts less than `k`. For each right pointer, we adjust the left pointer to ensure the window remains valid, and count the number of valid subarrays ending at each right position.

4. **Frequency Counting**: We use dictionaries to keep track of the frequency of each element within the current window and the number of elements at each frequency. This helps efficiently determine the maximum frequency in the current window and adjust the window size accordingly.

import sys
from collections import defaultdict

def main():
    n, k = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))

    frequency_count = defaultdict(int)

        frequency_count[prev_count] -= 1
        count[x] += 1
        new_count = count[x]
        frequency_count[new_count] += 1
        if new_count > max_freq:
            max_freq = new_count
        # Adjust the left pointer if current max_freq >= k
        while max_freq >= k:
            left_x = a[left]
            prev_left = count[left_x]
            frequency_count[prev_left] -= 1
            count[left_x] -= 1
            new_left = count[left_x]
            frequency_count[new_left] += 1
            if prev_left == max_freq and frequency_count[prev_left] == 0:
                max_freq -= 1
            left += 1
        invalid += (right - left + 1)
    print(total_subarrays - invalid)
