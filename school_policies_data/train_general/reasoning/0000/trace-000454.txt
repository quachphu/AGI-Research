To solve this problem, we need to efficiently compute the average number of marbles in each box after performing a series of operations. Each operation adds a certain number of marbles to a range of boxes. Given the constraints, a direct approach of updating each box for every operation is infeasible. Instead, we use a mathematical approach to optimize the solution.

### Approach
1. **Problem Analysis**: Each operation updates a range of boxes by adding a certain number of marbles. Instead of updating each box individually, we track the contributions of each operation using two sums, `S1` and `S2`.
2. **Key Insight**: The total number of marbles can be computed using the formula derived from the contributions of each operation. The sum of marbles added by each operation can be represented using two sums:
   - `S1` tracks the sum of all additions and subtractions to the boxes.
   - `S2` tracks the weighted sum of these additions and subtractions based on their positions.
3. **Mathematical Formulation**: Using `S1` and `S2`, the total number of marbles can be computed as `(N + 1) * S1 - S2`, which avoids iterating over all boxes and directly computes the result in linear time relative to the number of operations.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    M = int(input[ptr])
    ptr += 1
    
    S1 = 0
    S2 = 0
    
    for _ in range(M):
        a = int(input[ptr])
        ptr += 1
        b = int(input[ptr])
        ptr += 1
        k = int(input[ptr])
        ptr += 1
        
        # Apply the a part
        if a <= N:
            S1 += k
            S2 += a * k
        
        # Apply the b+1 part if within N
        b_plus_1 = b + 1
        if b_plus_1 <= N:
            S1 -= k
            S2 -= b_plus_1 * k
    
    total = (N + 1) * S1 - S2
    average = total // N
    print(average)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the potentially large input size.
2. **Tracking Contributions**: For each operation, we update `S1` and `S2` based on the range specified. This allows us to accumulate the total contributions without iterating over each box in the range.
3. **Computing Total Marbles**: Using the formula derived from `S1` and `S2`, we compute the total number of marbles efficiently.
4. **Output the Result**: The average is computed by dividing the total marbles by the number of boxes and rounding down to the nearest integer.

This approach ensures that we handle the constraints efficiently, operating in O(M) time complexity and O(1) space complexity, making it suitable for large values of N and M.
