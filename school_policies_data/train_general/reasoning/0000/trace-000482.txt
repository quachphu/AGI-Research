2. **Increasing Phases**: For each row in an increasing phase, each tile can transition to two tiles in the next row. The DP array is expanded and updated accordingly.
3. **Decreasing Phases**: For each row in a decreasing phase, each tile in the next row can be reached from two tiles in the previous row. The DP array is contracted and updated accordingly.
