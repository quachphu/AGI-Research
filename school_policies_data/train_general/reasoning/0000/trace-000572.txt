To solve this problem, we need to determine the minimal number of clicks required for a miner to pass a test in the worst-case scenario. The test consists of answering a series of questions, each with multiple choice answers, where each wrong answer forces the miner to restart from the first question. The miner remembers all previous answers, so he does not repeat wrong choices.

### Approach
The key insight is to calculate the number of clicks required for each question individually, considering both the correct and incorrect answers. For each question, the worst-case scenario involves trying all incorrect answers before selecting the correct one. Each incorrect attempt forces the miner to restart from the first question, but he will not repeat previous incorrect choices.

1. **Incorrect Attempts**: For each question, if there are `a[i]` possible answers, there are `a[i] - 1` incorrect attempts. Each incorrect attempt requires the miner to click through all previous questions (now answered correctly) and the current incorrect answer.
2. **Correct Attempt**: After all incorrect attempts, the correct answer is selected once. This correct attempt also requires clicking through all previous questions and the current correct answer.

The total number of clicks for each question `i` (1-based index) is calculated as:
- Incorrect attempts: `(a[i] - 1) * i` clicks (where `i` is the number of clicks per incorrect attempt).
- Correct attempt: `1` click (as previous correct answers are already accounted for).

Summing these values for all questions gives the total number of clicks required.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
total = 0
for i in range(n):
    total += (a[i] - 1) * (i + 1) + 1
print(total)
```

### Explanation
1. **Input Reading**: The number of questions `n` and the list of possible answers for each question are read from the input.
2. **Total Clicks Calculation**: For each question, the total clicks are computed by considering both incorrect and correct attempts. The loop iterates through each question, summing the clicks required for each question based on the formula derived.
3. **Output**: The total number of clicks is printed.

This approach efficiently computes the worst-case scenario by leveraging the structure of the problem and ensuring that each question's contribution to the total clicks is accurately calculated. The complexity is linear with respect to the number of questions, making it efficient even for the upper constraint of `n = 100`.
