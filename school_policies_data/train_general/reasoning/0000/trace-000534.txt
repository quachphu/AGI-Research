To solve this problem, we need to split carrots into k pieces such that the sum of the squares of each piece's length is minimized. The approach involves using a greedy algorithm with a priority queue (max-heap) to efficiently determine the optimal splits.

### Approach
1. **Initial Setup**: Calculate the initial sum of squares of the carrot lengths.
2. **Priority Queue (Max-Heap)**: Use a max-heap to keep track of the potential gains (reduction in the sum of squares) from splitting each carrot into more pieces.
3. **Greedy Splitting**: For each split, choose the carrot that provides the maximum reduction in the sum of squares. Update the sum and push the next possible gain for that carrot into the heap.
4. **Validation Check**: Ensure that each entry in the heap is still valid by checking the current number of pieces for the carrot against the entry's stored value.

### Solution Code
```python
import heapq

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    k = int(input[idx])
    idx += 1
    a = list(map(int, input[idx:idx + n]))
    
    def compute_sum(L, m):
        q, r = divmod(L, m)
        return (m - r) * q * q + r * (q + 1) ** 2
    
    sum_squares = sum(x * x for x in a)
    current_m = [1] * n
    need = k - n
    
    if need <= 0:
        print(sum_squares)
        return
    
    heap = []
    for i in range(n):
        x = a[i]
        m = current_m[i]
        next_m = m + 1
        if next_m > x:
            continue
        current = compute_sum(x, m)
        next_sum = compute_sum(x, next_m)
        gain = current - next_sum
        if gain > 0:
            heapq.heappush(heap, (-gain, i, m))
    
    while need > 0 and heap:
        neg_gain, i, m = heapq.heappop(heap)
        gain = -neg_gain
        if current_m[i] != m:
            continue
        sum_squares -= gain
        current_m[i] += 1
        need -= 1
        new_m = current_m[i]
        new_next_m = new_m + 1
        if new_next_m > a[i]:
            continue
        current = compute_sum(a[i], new_m)
        next_sum = compute_sum(a[i], new_next_m)
        new_gain = current - next_sum
        if new_gain > 0:
            heapq.heappush(heap, (-new_gain, i, new_m))
    
    print(sum_squares)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Initial Sum Calculation**: The initial sum of squares is computed directly from the given carrot lengths.
2. **Heap Initialization**: For each carrot, calculate the potential gain from splitting it into two pieces and push this gain into the heap.
3. **Processing Splits**: Repeatedly extract the maximum gain from the heap, apply it to the sum, and update the heap with the next potential gain for that carrot. This ensures that each split provides the maximum possible reduction in the sum of squares.
4. **Validity Check**: Each heap entry includes the current number of pieces for the carrot. If the actual number of pieces has changed since the entry was added, the entry is ignored.

This approach efficiently minimizes the sum of squares using a greedy strategy, ensuring optimal performance with a time complexity of O(k log n), where k is the number of splits needed.
