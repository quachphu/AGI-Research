The solution involves efficiently using binary search to find the minimal maximum height that satisfies the constraints.

### Approach
1. **Problem Analysis**:
   - Students using two-block pieces can form towers with heights that are multiples of 2 but not 6 (since multiples of 6 can be used by either group).
   - Students using three-block pieces can form towers with heights that are multiples of 3 but not 6.
   - Multiples of 6 (common multiples) can be used by either group but not both.

2. **Key Insight**:
   - Use binary search to find the minimum height `x` such that all students can build their towers without conflicts.
   - For each candidate height `x`, calculate the maximum number of valid towers each group can build without overlapping and check if the remaining towers can be constructed using multiples of 6.

3. **Binary Search**:
   - For each midpoint `x` in the binary search, compute the number of valid towers each group can build using their non-overlapping multiples and check if the remaining towers can be constructed using common multiples of 6.

### Solution Code
```python
n, m = map(int, input().split())

def is_possible(x):
    a = (x // 2) - (x // 6)
    b = (x // 3) - (x // 6)
    c = x // 6
    need_2 = max(0, n - a)
    need_3 = max(0, m - b)
    return need_2 + need_3 <= c

low = 0
high = 10**18

while low < high:
    mid = (low + high) // 2
    if is_possible(mid):
        high = mid
    else:
        low = mid + 1

print(low)
```

### Explanation
1. **Binary Search Setup**:
   - Initialize `low` to 0 and `high` to a large value (10^18) to cover all possible heights.

2. **Check Feasibility Function**:
   - For a given height `x`, calculate the number of valid towers for each group (using non-overlapping multiples) and the remaining capacity using multiples of 6.
   - Determine if the remaining towers can be accommodated using the common multiples of 6 without conflicts.

3. **Binary Search Execution**:
   - Adjust the search range based on whether the current midpoint can accommodate all towers. If feasible, reduce the upper bound; otherwise, increase the lower bound.

This approach efficiently narrows down the minimum possible height using binary search, ensuring optimal performance even for large input sizes.
