To solve this problem, we need to reorder a given sequence of numbers such that each subsequent number is either divided by 3 (if divisible) or multiplied by 2. The sequence must start with an initial number that cannot be derived from any other number in the sequence using these operations. 

### Approach
1. **Identify the Starting Element**: The initial number (starting element) is the one that cannot be derived from any other number in the sequence using either multiplication by 2 or division by 3. This is determined by checking each number in the list to see if there exists another number that could be its predecessor.
2. **Construct the Sequence**: Once the starting element is identified, construct the sequence by iteratively checking if the next number can be obtained by multiplying the current number by 2 or dividing it by 3 (if divisible). This ensures each subsequent number follows the rules defined by the problem.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))

# Find the starting element which has no predecessor
start = None
for x in a:
    has_predecessor = False
    for y in a:
        if x == y * 2 or y == x * 3:
            has_predecessor = True
            break
    if not has_predecessor:
        start = x
        break

# Build the sequence
result = [start]
available = set(a)
available.remove(start)
current = start

for _ in range(n-1):
    next_mult = current * 2
    if next_mult in available:
        result.append(next_mult)
        available.remove(next_mult)
        current = next_mult
    else:
        next_div = current // 3
        result.append(next_div)
        available.remove(next_div)
        current = next_div

print(' '.join(map(str, result)))
```

### Explanation
1. **Finding the Starting Element**: We iterate through each number in the list to check if it can be derived from any other number using the allowed operations. The number that cannot be derived from any other number is chosen as the starting element.
2. **Constructing the Sequence**: Starting with the identified initial number, we build the sequence by checking if the next number can be obtained by multiplying the current number by 2. If not, we check if it can be obtained by dividing the current number by 3 (if divisible). This process continues until all numbers are placed in the correct order.

This approach ensures that we correctly reorder the sequence according to the problem's constraints, leveraging set operations for efficient membership checks and ensuring the solution is both optimal and correct.
