To solve this problem, we need to determine which girlfriend Vasya visits more frequently based on the train schedules. The trains to Dasha and Masha run every `a` and `b` minutes respectively, and we need to compare the total time intervals during which Vasya would take each train.

### Approach
1. **Understanding the Schedule**: The trains run periodically, and the schedule repeats every `LCM(a, b)` minutes, where `LCM` is the Least Common Multiple. This periodicity allows us to analyze the schedule within a single period to determine the overall frequency of visits.
2. **Generating Events**: We generate all arrival times for both trains within one period (from `0` to `LCM(a, b)`).
3. **Sorting Events**: Merge and sort these arrival times to process them in chronological order.
4. **Calculating Intervals**: For each interval between consecutive events, determine which train Vasya would take. If two trains arrive simultaneously, Vasya chooses the direction with the lower frequency (higher interval value).

### Solution Code
```python
import sys
from math import gcd
from collections import defaultdict

def main():
    a, b = map(int, sys.stdin.readline().split())

    def compute_lcm(x, y):
        return x * y // gcd(x, y)
    
    T = compute_lcm(a, b)
    
    # Generate all Dasha and Masha event times up to T
    dasha_times = [i * a for i in range(1, T // a + 1)]
    masha_times = [i * b for i in range(1, T // b + 1)]
    
    events = defaultdict(set)
    for t in dasha_times:
        events[t].add('D')
    for t in masha_times:
        events[t].add('M')
    
    sorted_events = sorted(events.items())
    
    t_prev = 0
    d_time = 0
    m_time = 0
    
    for time, directions in sorted_events:
        interval = time - t_prev
        if len(directions) == 1:
            if 'D' in directions:
                d_time += interval
            else:
                m_time += interval
        else:
            # Both directions, choose based on a and b comparison
            if a < b:
                m_time += interval
            elif a > b:
                d_time += interval
        t_prev = time
    
    if d_time > m_time:
        print("Dasha")
    elif m_time > d_time:
        print("Masha")
    else:
        print("Equal")

if __name__ == "__main__":
    main()
```

### Explanation
1. **LCM Calculation**: The period after which the train schedule repeats is determined by the LCM of `a` and `b`.
2. **Event Generation**: We generate all arrival times for both trains up to this period.
3. **Event Processing**: By sorting these times, we process each interval between consecutive events. The length of each interval determines the time contribution to each girlfriend based on the next arriving train.
4. **Tie-Breaking**: When both trains arrive simultaneously, the direction with the lower frequency (higher interval value) is chosen.

This approach efficiently computes the total time intervals using the periodic nature of the train schedules, ensuring accuracy and optimal performance.
