To solve this problem, we need to find the lexicographically smallest string possible by performing at most one operation of removing a character from any position and inserting it back at another position. 

### Approach
1. **Problem Analysis**: The goal is to determine the smallest lexicographical string achievable by moving any single character to another position. The solution involves generating all possible strings resulting from each valid move and selecting the smallest one.
2. **Generate Candidates**: For each character in the string, remove it and reinsert it at every possible position. This generates all potential candidate strings.
3. **Comparison**: Compare each candidate string with the current minimum string to keep track of the smallest one.

### Solution Code
```python
def find_lex_smallest_string():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N = int(input[idx])
        idx += 1
        S = input[idx]
        idx += 1
        best = S
        for i in range(N):
            s_list = list(S)
            char = s_list.pop(i)
            for k in range(N):
                new_str = s_list[:k] + [char] + s_list[k:]
                candidate = ''.join(new_str)
                if candidate < best:
                    best = candidate
        print(best)

find_lex_smallest_string()
```

### Explanation
1. **Reading Input**: The input is read in one go and split into a list for easier processing.
2. **Iterating Through Test Cases**: For each test case, read the string and initialize the best possible string as the original string.
3. **Generating Candidates**: For each character in the string, remove it and insert it at every possible position in the resulting shorter string. This generates all possible candidate strings.
4. **Updating the Best String**: Each candidate string is compared with the current best string. If it is lexicographically smaller, it becomes the new best string.
5. **Output**: After processing all possible moves for a test case, the best string is printed.

This approach ensures that all possible moves are considered efficiently, leveraging the constraints to generate and compare all possible candidates within feasible limits.
