To solve this problem, we need to find the longest contiguous substring of a given string `s` that does not contain any of the specified boring substrings. The solution should also provide the starting position of this longest valid substring.

### Approach
The approach involves using a sliding window technique to efficiently check for valid substrings. The key steps are as follows:

1. **Preprocess Forbidden Substrings**: Store all boring substrings in a set for quick lookup and determine the maximum length among these substrings.
2. **Sliding Window Technique**: Use two pointers, `left` and `right`, to represent the current window of the string being checked. As we expand the window by moving `right` from left to right, we check all possible substrings ending at `right` that could be boring. If a boring substring is found, adjust the `left` pointer to exclude this substring from the window.
3. **Track Maximum Length**: Keep track of the longest valid substring found and its starting position. If multiple valid substrings of the same maximum length exist, any starting position is acceptable.

### Solution Code
```python
def find_longest_substring():
    import sys
    s = sys.stdin.readline().strip()
    n = int(sys.stdin.readline())
    forbidden = set()
    max_len = 0
    for _ in range(n):
        bi = sys.stdin.readline().strip()
        forbidden.add(bi)
        if len(bi) > max_len:
            max_len = len(bi)
    
    left = 0
    max_length = 0
    best_start = 0
    len_s = len(s)
    
    for right in range(len_s):
        # Check all possible substrings ending at 'right' with length up to max_len
        for i in range(max(0, right - max_len + 1), right + 1):
            substr = s[i:right+1]
            if substr in forbidden:
                if i + 1 > left:
                    left = i + 1
        
        current_length = right - left + 1
        if current_length > max_length:
            max_length = current_length
            best_start = left
        elif current_length == max_length and left < best_start:
            # This line is optional as any position is acceptable. 
            # Keeping it as it prefers the first occurrence, but the problem allows any.
            # To prefer the last possible occurrence, change to left > best_start.
            pass
    
    print(max_length, best_start)
```
