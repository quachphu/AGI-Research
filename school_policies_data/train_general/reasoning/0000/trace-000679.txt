To solve this problem, we need to determine the optimal arrangement of a new row of balls, Z, that maximizes the sum of the Hamming distances between Z and two given rows X and Y. Additionally, if there are multiple optimal arrangements, we must choose the lexicographically smallest one.

### Approach
1. **Understanding Hamming Distance Contribution**: For each position in the strings X and Y, the contribution to the sum of Hamming distances depends on whether the characters at that position in X and Y are the same or different.
   - If the characters at a position in X and Y are the same, the maximum contribution (2) is achieved by choosing the opposite character for Z.
   - If the characters at a position in X and Y are different, each choice (either 'B' or 'W') contributes 1 to the sum. Here, we choose 'B' to ensure lexicographical order is minimized.

2. **Constructing Z**: For each position:
   - If characters in X and Y are the same, append the opposite character to Z.
   - If characters in X and Y are different, append 'B' to ensure the lexicographically smallest result.

### Solution Code
```python
t = int(input())
for _ in range(t):
    x = input().strip()
    y = input().strip()
    z = []
    for a, b in zip(x, y):
        if a == b:
            z.append('B' if a == 'W' else 'W')
        else:
            z.append('B')
    print(''.join(z))
```

### Explanation
- **Reading Input**: We first read the number of test cases.
- **Processing Each Test Case**: For each test case, read the strings X and Y.
- **Building Z**: Iterate through each character position in X and Y:
  - If characters are the same, append the opposite character to Z.
  - If characters are different, append 'B' to ensure the smallest lexicographical order.
- **Output Result**: After constructing Z for each test case, print the result.

This approach ensures that we maximize the sum of Hamming distances while maintaining the smallest lexicographical order for Z when multiple optimal solutions exist.
