To solve this problem, we need to determine the color of a point (x, y) on a Cartesian plane based on the magic clock's coloring pattern. The clock's coloring alternates between black and white in concentric rings, with points on the borders (where the distance from the origin is an integer) being black. 

### Approach
1. **Calculate the Distance Squared**: Compute the squared distance from the origin to the point (x, y) to avoid floating-point inaccuracies.
2. **Check for Perfect Square**: Determine if the squared distance is a perfect square. If it is, the point lies on a border and is black.
3. **Determine the Ring**: Calculate the integer part of the square root of the squared distance to identify which ring the point is in.
4. **Determine the Quadrant**: Identify the quadrant of the point based on the signs of x and y.
5. **Color Determination**: Check the parity (even or odd) of the sum of the ring number and the quadrant number. If the sum is even, the point is white; otherwise, it is black.

### Solution Code
```python
import math

def determine_color():
    x, y = map(int, input().split())
    d_sq = x ** 2 + y ** 2
    n = int(math.sqrt(d_sq))
    if n * n == d_sq:
        print("black")
        return
    # Determine the quadrant
    if x >= 0 and y >= 0:
        quadrant = 1
    elif x < 0 and y >= 0:
        quadrant = 2
    elif x < 0 and y < 0:
        quadrant = 3
    else:
        quadrant = 4
    total = n + quadrant
    print("white" if total % 2 == 0 else "black")

determine_color()
```

### Explanation
1. **Distance Squared Calculation**: The squared distance from the origin to the point (x, y) is computed using integer arithmetic to avoid precision issues.
2. **Perfect Square Check**: By comparing the integer square root with the original squared distance, we determine if the point lies on a border (perfect square), which is always black.
3. **Ring Calculation**: The integer part of the square root of the squared distance gives the ring number, which helps in determining the color alternation.
4. **Quadrant Determination**: The quadrant is determined based on the signs of the coordinates, which helps in alternating colors within each ring.
5. **Parity Check**: The sum of the ring number and quadrant number determines the color. An even sum results in white, while an odd sum results in black.

This approach efficiently combines geometric calculations with parity checks to determine the color of the point accurately.
