To solve this problem, we need to determine the number of valid ways to select two pairs of boys and girls such that no person is included in more than one pair. The solution involves efficiently counting the valid pairs while considering constraints on the number of boys, girls, and pairs.

### Approach
1. **Understanding the Problem**: We need to count pairs of boy-girl pairs where each person appears in at most one pair. The key insight is to subtract the invalid pairs (those sharing a boy or a girl) from the total possible pairs.

2. **Total Possible Pairs**: The total number of ways to choose 2 pairs from `k` pairs is given by the combination formula `C(k, 2) = k * (k - 1) / 2`.

3. **Invalid Pairs**: 
   - **Shared Boys**: For each boy, count how many pairs he is in. The number of invalid pairs for a boy appearing in `c` pairs is `C(c, 2)`.
   - **Shared Girls**: Similarly, for each girl, count how many pairs she is in. The number of invalid pairs for a girl appearing in `d` pairs is `C(d, 2)`.

4. **Efficient Calculation**: Using frequency dictionaries to count occurrences of each boy and girl in the pairs allows us to compute the invalid pairs efficiently.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        a = int(input[ptr])
        b = int(input[ptr+1])
        k = int(input[ptr+2])
        ptr +=3
        boys = list(map(int, input[ptr:ptr+k]))
        ptr +=k
        girls = list(map(int, input[ptr:ptr+k]))
        ptr +=k
        
        cnt_boys = defaultdict(int)
        for boy in boys:
            cnt_boys[boy] +=1
        
        cnt_girls = defaultdict(int)
        for girl in girls:
            cnt_girls[girl] +=1
        
        sum_b = sum(c * (c-1) // 2 for c in cnt_boys.values())
        sum_g = sum(c * (c-1) // 2 for c in cnt_girls.values())
        
        total = k * (k-1) // 2
        ans = total - sum_b - sum_g
        print(ans)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Frequency Counting**: Using `defaultdict` from the `collections` module, we count how many times each boy and girl appears in the pairs.
3. **Calculating Invalid Pairs**: For each boy and girl, compute the number of invalid pairs using the combination formula `C(n, 2)` which is `n * (n - 1) / 2`.
4. **Computing the Result**: Subtract the invalid pairs (both shared boys and shared girls) from the total possible pairs to get the valid pairs.

This approach ensures that we efficiently handle the constraints, providing the solution in O(k) time per test case, which is optimal given the problem constraints.
