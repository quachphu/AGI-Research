To solve this problem, we need to determine if an even number can be expressed as the sum of two prime numbers. If it can, Deepa wins; otherwise, Arjit wins. The solution involves checking each even number for possible prime pairs using the Sieve of Eratosthenes for efficient prime number generation.

### Approach
1. **Prime Number Generation**: Use the Sieve of Eratosthenes algorithm to generate all prime numbers up to the maximum possible value (100,000). This allows O(1) prime checks.
2. **Check Prime Pair Sum**: For each even number, check if there exists a pair of prime numbers that sum up to the given number. This is done by iterating through possible primes up to half the number and checking if both the prime and the remainder (number - prime) are primes.

### Solution Code
```python
import sys

def generate_sieve(max_limit):
    sieve = [True] * (max_limit + 1)
    sieve[0] = sieve[1] = False
    for num in range(2, int(max_limit**0.5) + 1):
        if sieve[num]:
            sieve[num*num : max_limit+1 : num] = [False] * len(sieve[num*num : max_limit+1 : num])
    return sieve

max_limit = 100000
sieve = generate_sieve(max_limit)

def determine_winner(n):
    if n == 2:
        return "Arjit"
    for p in range(2, (n // 2) + 1):
        if sieve[p] and sieve[n - p]:
            return "Deepa"
    return "Arjit"

def main():
    input = sys.stdin.read().split()
    tc = int(input[0])
    for i in range(1, tc + 1):
        n = int(input[i])
        print(determine_winner(n))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Sieve of Eratosthenes**: This algorithm efficiently generates all prime numbers up to a given limit (100,000 in this case). It marks non-prime numbers by iterating through each number starting from 2 and marking its multiples.
2. **Prime Pair Check**: For each test case (even number), the solution checks each number from 2 up to half of the given number. For each number, it checks if both the number and its complement (with respect to the given even number) are primes using the precomputed sieve array. If such a pair is found, Deepa wins; otherwise, Arjit wins.

This approach ensures that we efficiently check for prime pairs using precomputed data, making the solution both optimal and easy to understand.
