Each match can result in a win (100 points), a loss (0 points), or a draw (50 points each). The goal is to find the maximum possible score for the Finance team by optimally pairing their players with the Marketing team's players.

### Approach
1. **Problem Analysis**: The problem can be modeled as a bipartite graph where each node represents a player from either team, and edges represent the points the Finance team would earn if those two players are matched. The challenge is to find the maximum weight matching in this bipartite graph.

2. **Dynamic Programming with Bitmasking**: Given the constraints (up to 20 players per team), a brute-force approach is infeasible. Instead, we use dynamic programming (DP) with bitmasking to efficiently explore all possible pairings. The bitmask tracks which Marketing team players have been used, and the DP state stores the maximum score achievable with that subset of players.

3. **Points Matrix**: Precompute the points matrix where each entry (i, j) represents the points the Finance team gets if their i-th player is matched with the j-th player from the Marketing team.

4. **DP State Transition**: For each possible subset of Marketing players (represented by a bitmask), calculate the maximum score by considering each possible next player to pair with the next available Finance player.

### Solution Code
```python
import itertools

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    finance = list(map(int, input[1:n+1]))
    marketing = list(map(int, input[n+1:2*n+1]))
    
    # Precompute the points matrix
    points = []
    for i in range(n):
        row = []
        for j in range(n):
            fi = finance[i]
            ma = marketing[j]
            if fi > ma:
                row.append(100)
            elif fi < ma:
                row.append(0)
            else:
                row.append(50)
        points.append(row)
    
    # Initialize DP array with -1 (unreachable), except dp[0] = 0
    size = 1 << n
    dp = [-1] * size
    dp[0] = 0
    
    # Iterate over each possible number of set bits (m) from 0 to n-1
    for m in range(n):
        # Generate all possible masks with exactly m bits set
        for bits in itertools.combinations(range(n), m):
            mask = sum(1 << j for j in bits)
            if dp[mask] == -1:
                continue  # Skip unreachable states
            # Current Finance player to assign is m (0-based)
            # Try all Marketing players not in the current mask
            for j in range(n):
                if not (mask & (1 << j)):
                    new_mask = mask | (1 << j)
                    new_score = dp[mask] + points[m][j]
                    if dp[new_mask] < new_score:
                        dp[new_mask] = new_score
    
    print(dp[(1 << n) - 1])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of players and their respective skill levels for both teams.
2. **Points Matrix Calculation**: A matrix is created where each entry (i, j) represents the points the Finance team earns if their i-th player is matched with the j-th player from the Marketing team.
3. **DP Initialization**: A DP array is initialized to track the maximum score achievable with each subset of Marketing players. The initial state (no players matched) has a score of 0.
4. **DP State Transition**: For each possible number of matched players (from 0 to n-1), generate all possible subsets of Marketing players and update the DP array by considering all possible next pairings.
5. **Result**: The maximum score for the Finance team, when all players are matched, is found in the DP state where all Marketing players are used (all bits set).

This approach efficiently explores all possible pairings using dynamic programming and bitmasking, ensuring optimal performance even for the upper constraint of 20 players per team.
