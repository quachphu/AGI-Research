To solve this problem, we need to determine how many lanterns Vova can see on his way to the conference, considering that some lanterns might be blocked by a standing train. The solution involves calculating the total number of lanterns and subtracting those that are blocked.

### Approach
1. **Total Lanterns Calculation**: The total number of lanterns up to point \( L \) is given by the integer division \( L // v \), as lanterns are placed at every \( v \)-th unit.
2. **Blocked Lanterns Calculation**: The number of lanterns blocked by the standing train from \( l \) to \( r \) is determined by the formula \( (r // v) - ((l - 1) // v) \). This formula calculates the count of multiples of \( v \) within the range \([l, r]\).

By subtracting the blocked lanterns from the total lanterns, we get the number of visible lanterns for each query.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    idx = 1
    for _ in range(t):
        L = int(input[idx])
        v = int(input[idx+1])
        l = int(input[idx+2])
        r = int(input[idx+3])
        idx += 4
        total = L // v
        blocked = (r // v) - ((l - 1) // v)
        print(total - blocked)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints. Each query is processed sequentially.
2. **Total Lanterns**: For each query, the total number of lanterns is calculated as \( L // v \).
3. **Blocked Lanterns**: The blocked lanterns are calculated using the formula that finds the count of multiples of \( v \) within the interval \([l, r]\).
4. **Result Calculation**: The result for each query is obtained by subtracting the blocked lanterns from the total lanterns, ensuring the correct count of visible lanterns is output.

This approach efficiently handles up to \( 10^4 \) queries with large values up to \( 10^9 \) by leveraging mathematical properties of integer division and ranges, ensuring optimal performance and correctness.
