To solve this problem, we need to count the number of substrings in a given ABC-string that contain an equal number of 'A', 'B', and 'C' characters. The solution must efficiently handle strings up to 1,000,000 characters long.

### Approach
The key insight is that for a substring to have equal counts of 'A', 'B', and 'C', its length must be a multiple of 3. Additionally, we can use prefix sums and differences between these sums to track the counts of each character efficiently.

1. **Prefix Sums and Differences**: For each position in the string, we compute the cumulative counts of 'A', 'B', and 'C'. We then calculate the differences between these counts (delta_ab = A - B, delta_bc = B - C) to form a key that helps identify potential valid substrings.

2. **Modulo Operation**: Since the length of valid substrings must be a multiple of 3, we use modulo 3 on the indices to group potential start and end points of valid substrings.

3. **Hash Map with Count Tracking**: We use a hash map (dictionary) to track the occurrence of each (delta_ab, delta_bc) pair along with their modulo 3 indices. This allows us to quickly determine how many valid substrings end at the current position.

### Solution Code
```python
from collections import defaultdict

def count_abc_substrings():
    s = input().strip()
    count_a = 0
    count_b = 0
    count_c = 0
    counter = defaultdict(lambda: [0, 0, 0])
    result = 0

    # Handle the initial state (i=0)
    key = (0, 0)
    current_mod = 0 % 3
    result += counter[key][current_mod]
    counter[key][current_mod] += 1

    for i in range(1, len(s) + 1):
        char = s[i-1]
        if char == 'A':
            count_a += 1
        elif char == 'B':
            count_b += 1
        else:
            count_c += 1

        delta_ab = count_a - count_b
        delta_bc = count_b - count_c
        key = (delta_ab, delta_bc)
        current_mod = i % 3

        # Add to the result the count of occurrences with the same key and mod
        result += counter.get(key, [0, 0, 0])[current_mod]

        # Update the counter for this key and mod
        counter[key][current_mod] += 1

    print(result)

count_abc_substrings()
```

### Explanation
1. **Initialization**: We start by initializing counters for 'A', 'B', and 'C' to zero. We also initialize a hash map to track the occurrences of each (delta_ab, delta_bc) pair along with their modulo 3 indices.

2. **Processing Initial State**: The initial state (i=0) corresponds to an empty prefix, where all counts are zero. This is added to the hash map with modulo 0.

3. **Iterating Through the String**: For each character in the string, we update the cumulative counts of 'A', 'B', and 'C'. We then compute the current delta_ab and delta_bc values, and the current index modulo 3.

4. **Checking Valid Substrings**: For each position, we check how many times the current (delta_ab, delta_bc) pair has been seen with the same modulo 3 index. This count is added to the result as these represent valid substrings ending at the current position.

5. **Updating the Hash Map**: After checking, we update the hash map to include the current (delta_ab, delta_bc) pair and its modulo 3 index.

This approach efficiently tracks potential valid substrings using prefix sums and differences, ensuring an O(n) time complexity and O(n) space complexity, making it suitable for large input sizes.
