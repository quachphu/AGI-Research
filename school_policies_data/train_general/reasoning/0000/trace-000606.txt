To solve this problem, we need to determine the minimum possible length of a binary string after repeatedly removing adjacent pairs of '0' and '1'. The solution involves counting the occurrences of '0's and '1's and using these counts to compute the result efficiently.

### Approach
1. **Count Occurrences**: For each test case, count the number of '0's and '1's in the string.
2. **Calculate Minimum Length**: The minimum length of the string after all possible removals can be determined by the formula:
   \[
   \text{min\_length} = \text{original\_length} - 2 \times \min(\text{count\_0}, \text{count\_1})
   \]
   This formula works because each removal of an adjacent '0' and '1' pair reduces the string length by 2, and the maximum number of such pairs we can remove is the minimum of the counts of '0's and '1's.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        s = sys.stdin.readline().strip()
        c0 = s.count('0')
        c1 = len(s) - c0
        print(len(s) - 2 * min(c0, c1))

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read from standard input. The number of test cases `T` is read first.
- **Processing Each Test Case**: For each test case, the binary string is read, and the counts of '0's and '1's are determined.
- **Computing Result**: Using the counts of '0's and '1's, the minimum possible length of the string after all valid removals is computed using the formula mentioned in the approach.
- **Output**: The result for each test case is printed immediately after computation.

This approach ensures that we efficiently compute the result in linear time relative to the length of the string, making it suitable for large input sizes up to the constraints given.
