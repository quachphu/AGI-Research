To solve this problem, we need to determine the number of intervals (subarrays) where each color is the dominant color. A dominant color is defined as the color that occurs most frequently in the interval, and in case of a tie, the smallest color number is chosen.

### Approach
1. **Problem Analysis**: We need to consider all possible non-empty intervals of the given array of colors. For each interval, we determine the dominant color and count how many times each color becomes dominant across all intervals.
2. **Optimization Insight**: Directly checking each interval in a brute-force manner would be computationally expensive (O(n^3)), so we use a more efficient approach by iterating over each possible starting point and expanding the interval to the right while maintaining the count of each color.
3. **Efficient Counting**: For each starting point, we maintain a frequency array to count occurrences of each color as we expand the interval. We also keep track of the current maximum frequency and the dominant color, updating these as we expand the interval.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    t = list(map(int, sys.stdin.readline().split()))
    ans = [0] * (n + 1)  # 1-based indexing for colors
    
    for i in range(n):
        counts = [0] * (n + 1)
        current_max = 0
        dominant = 0
        for j in range(i, n):
            color = t[j]
            counts[color] += 1
            if counts[color] > current_max:
                current_max = counts[color]
                dominant = color
            elif counts[color] == current_max:
                if color < dominant:
                    dominant = color
            ans[dominant] += 1
    
    print(' '.join(map(str, ans[1:n+1])))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency.
2. **Initialization**: We initialize an array `ans` to keep track of the count of intervals where each color is dominant.
3. **Iterating Over Starting Points**: For each starting point `i`, we initialize a frequency array `counts` to keep track of color occurrences, and variables `current_max` and `dominant` to track the current maximum frequency and the dominant color.
4. **Expanding Intervals**: For each ending point `j` starting from `i`, we update the frequency of the current color, adjust `current_max` and `dominant` as necessary, and increment the count for the dominant color in the interval `[i, j]`.
5. **Output**: Finally, we print the results for each color from 1 to n.

This approach efficiently processes each interval in O(n^2) time, which is feasible for the given constraints (n ≤ 5000).
