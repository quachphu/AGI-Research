```python
def compute_phi(max_limit):
    phi = list(range(max_limit + 1))
    for i in range(2, max_limit + 1):
        if phi[i] == i:  # i is a prime number
            for j in range(i, max_limit + 1, i):
                phi[j] = phi[j] // i * (i - 1)
    return phi

max_limit = 10**6 - 1  # since n < 10^6
phi = compute_phi(max_limit)

import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        print(phi[n])

if __name__ == "__main__":
    main()
```

1. **Precomputation of φ(n)**:
   - We initialize an array `phi` where each element `phi[i]` is initially set to `i`.
   - For each integer `i` starting from 2, if `i` is a prime (indicated by `phi[i]` still being equal to `i`), we update all multiples of `i` to adjust their φ values using the formula: `phi[j] = phi[j] // i * (i - 1)`.
   - This sieve-based approach efficiently computes the Totient values for all numbers up to the given maximum limit.

2. **Handling Queries**:
   - After precomputing the φ values, each query is answered in constant time by simply looking up the precomputed value.

This approach ensures that we efficiently handle up to 2000 queries with values up to 999,999, providing results in optimal time after an initial preprocessing step.
