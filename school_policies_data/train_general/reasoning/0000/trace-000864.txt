These operations allow multiplying or dividing by 2, 4, or 8, with division only allowed if the number is exactly divisible by the chosen divisor.

### Approach
1. **Check Equality**: If `a` and `b` are already equal, no operations are needed.
2. **Odd Part Check**: The transformation is only possible if `a` and `b` have the same odd part. This is because the allowed operations only affect the power of 2 in the number's factorization. If the odd parts differ, the transformation is impossible.
3. **Exponent Calculation**: Calculate the exponents of 2 in the prime factorization of `a` and `b`. This tells us how many times each number can be divided by 2 until it becomes odd.
4. **Delta Calculation**: Compute the difference (delta) between the exponents of `b` and `a`. The minimum number of operations required to adjust this exponent difference is given by the formula `(abs(delta) + 2) // 3`, which effectively uses the largest possible steps (3, then 2, then 1) to minimize the number of operations.

### Solution Code
```python
def count_operations():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    idx = 1
    for _ in range(t):
        a = int(input[idx])
        b = int(input[idx + 1])
        idx += 2
        if a == b:
            print(0)
            continue
        # Calculate a's odd part
        a_lsb = a & -a
        a_odd = a // a_lsb
        # Calculate b's odd part
        b_lsb = b & -b
        b_odd = b // b_lsb
        if a_odd != b_odd:
            print(-1)
            continue
        # Calculate exponents
        s = a_lsb.bit_length() - 1
        t_val = b_lsb.bit_length() - 1
        delta = t_val - s
        if delta == 0:
            print(0)
        else:
            steps = (abs(delta) + 2) // 3
            print(steps)
```
