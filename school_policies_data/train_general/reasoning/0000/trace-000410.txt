To solve this problem, we need to maximize the total happiness points earned by rearranging children in a line. The happiness points for each child are calculated based on their activeness and the distance they move from their original position. 

### Approach
The key insight is that children with higher activeness should be moved as far as possible from their original positions to maximize their contribution to the total happiness. We use dynamic programming (DP) to efficiently compute the optimal arrangement.

1. **Sort by Activeness**: First, we sort the children in descending order of their activeness. This allows us to consider the most impactful moves first.
2. **Dynamic Programming (DP) Setup**: We use a 2D DP array `dp[l][r]` where `dp[l][r]` represents the maximum happiness achievable using the subarray of positions from `l` to `r`.
3. **DP Transition**: For each segment of positions `[l, r]`, we decide whether to place the current child (from the sorted list) at position `l` or `r`, whichever yields a higher happiness value. This decision is propagated through the DP array.

### Solution Code
```python
n = int(input())
A = list(map(int, input().split()))
sorted_A = sorted([(A[i], i + 1) for i in range(n)], key=lambda x: (-x[0], x[1]))

# Initialize DP table
dp = [[0] * (n + 2) for _ in range(n + 2)]

for length in range(1, n + 1):
    for l in range(1, n - length + 2):
        r = l + length - 1
        k = n - length
        a, x = sorted_A[k]
        if l == r:
            dp[l][r] = a * abs(x - l)
        else:
            option1 = a * abs(x - l) + dp[l + 1][r]
            option2 = a * abs(x - r) + dp[l][r - 1]
            dp[l][r] = max(option1, option2)

print(dp[1][n])
```

### Explanation
1. **Sorting**: We first sort the children by their activeness in descending order. This ensures that we handle the most impactful moves (those contributing the most to happiness) first.
2. **DP Initialization**: The DP array `dp[l][r]` is initialized to store the maximum happiness for the segment `[l, r]`.
3. **Filling DP Table**: For each possible segment length from 1 to `n`, we compute the maximum happiness by considering placing the current child (from the sorted list) at either end of the segment. The decision is based on which placement (left or right) yields a higher happiness value, considering subsequent placements.
4. **Result Extraction**: The result for the entire line (from position 1 to `n`) is stored in `dp[1][n]`, which we print as the final answer.

This approach efficiently computes the optimal rearrangement using dynamic programming, ensuring we consider all possible moves while keeping the complexity manageable.
