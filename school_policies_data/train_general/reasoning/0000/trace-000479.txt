To solve this problem, we need to compute the XOR of all pairwise sums of elements in an array efficiently. Given the constraints, a direct O(n^2) approach is infeasible, so we use a bitwise optimization technique to determine each bit of the result independently.

### Approach
1. **Bitwise Analysis**: For each bit position from 0 to 30 (since the maximum sum of two elements can be up to 2 * 10^7, which is less than 2^25), determine if the k-th bit in the result is set. This is done by counting the number of pairs whose sum has the k-th bit set. If this count is odd, the k-th bit in the result is 1.

2. **Modulo and Sorting**: For each bit k, compute the modulo of each element with 2^(k+1) to focus on the relevant bits for the current position. Sort these modulo values to facilitate efficient range queries.

3. **Range Queries with Binary Search**: For each element, determine the valid ranges of other elements that would result in the k-th bit being set when summed. Use binary search to count these pairs efficiently.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    result = 0
    for k in range(31):  # Cover up to 30 bits
        M = 1 << (k + 1)
        b = [x % M for x in a]
        b.sort()
        cnt = 0
        for i in range(n - 1):
            bi = b[i]
            # First interval [2^k, M-1]
            lower_sum1 = (1 << k)
            upper_sum1 = M - 1
            low1 = lower_sum1 - bi
            high1 = upper_sum1 - bi
            low1_adj = max(0, low1)
            high1_adj = min(high1, M - 1)
            if high1_adj < 0:
                count1 = 0
            else:
                left = bisect.bisect_left(b, low1_adj, i + 1, n)
                right = bisect.bisect_right(b, high1_adj, i + 1, n)
                count1 = right - left
            # Second interval [M + 2^k, 2*M - 2]
            lower_sum2 = M + (1 << k)
            upper_sum2 = 2 * M - 2
            low2 = lower_sum2 - bi
            high2 = upper_sum2 - bi
            low2_adj = max(0, low2)
            high2_adj = min(high2, M - 1)
            if low2_adj > high2_adj:
                count2 = 0
            else:
                left2 = bisect.bisect_left(b, low2_adj, i + 1, n)
                right2 = bisect.bisect_right(b, high2_adj, i + 1, n)
                count2 = right2 - left2
            cnt += count1 + count2
        if cnt % 2 == 1:
            result ^= (1 << k)
    print(result)

main()
```

### Explanation
1. **Bitwise Analysis**: Each bit in the final result is determined by the parity (odd/even count) of pairs whose sum has that bit set. This is computed for each bit position independently.

2. **Modulo and Sorting**: By taking modulo 2^(k+1) for each element, we reduce the problem to considering only the relevant bits for the current position. Sorting these values allows efficient range queries using binary search.

3. **Range Queries**: For each element, we determine the valid ranges of other elements that would result in the k-th bit being set when summed. Binary search (via `bisect` module) is used to count elements within these ranges efficiently, ensuring an overall time complexity of O(n log n) per bit, which is feasible for large n.

This approach efficiently computes the XOR of all pairwise sums by leveraging bitwise properties and efficient range queries, ensuring it handles the upper constraint of n ≤ 400,000 effectively.
