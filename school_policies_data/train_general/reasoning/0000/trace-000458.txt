### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        a, b = sys.stdin.readline().split()
        rev_a = int(a[::-1])
        rev_b = int(b[::-1])
        total = rev_a + rev_b
        rev_total = int(str(total)[::-1])
        print(rev_total)

if __name__ == "__main__":
    main()
```

4. **Reversing the Sum**: The sum is converted to a string, reversed, and then converted back to an integer to ensure any leading zeros are removed.
