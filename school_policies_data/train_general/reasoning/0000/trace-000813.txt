To solve this problem, we need to determine the maximum diversity of a musical composition after each note can either be left as is or increased by 1. The diversity is defined as the number of distinct notes in the final sequence. 

### Approach
The key insight is to process the sorted array of notes and decide for each note whether to keep it or increment it by 1, ensuring that each choice contributes to the maximum number of distinct values. The approach is greedy and leverages the fact that the input array is sorted in non-decreasing order.

1. **Initialization**: Start with the smallest possible value for the previous note (negative infinity).
2. **Iterate through each note**: For each note, check if it can be kept as is. If not, check if incrementing it by 1 results in a new distinct value.
3. **Track the previous value**: This ensures that each new value chosen is the smallest possible that maintains the order and uniqueness.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        x = list(map(int, input[ptr:ptr+n]))
        ptr += n
        prev = -float('inf')
        count = 0
        for num in x:
            if num > prev:
                count += 1
                prev = num
            else:
                if num + 1 > prev:
                    count += 1
                    prev = num + 1
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Processing Each Test Case**: For each test case, we read the number of notes and the notes themselves.
3. **Greedy Selection**: For each note in the sorted list:
   - If the current note is greater than the previous value, we keep it as is.
   - If not, we check if incrementing the note by 1 results in a value greater than the previous value. If so, we use the incremented value.
   - This ensures that each choice is optimal for maximizing the number of distinct values up to that point.

This approach efficiently processes each note in linear time, ensuring that the solution handles the upper constraints effectively. The greedy strategy works because the input is sorted, allowing us to make locally optimal choices that lead to a globally optimal solution.
