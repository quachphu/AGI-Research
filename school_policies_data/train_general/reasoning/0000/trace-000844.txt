To solve this problem, we need to determine if string S can be transformed into string T by performing a series of rotations. A rotation is defined as moving the last character of the string to the front. 

### Approach
1. **Understand Rotation Mechanics**: Each rotation moves the last character of the string to the front. For example, rotating "abc" once results in "cab".
2. **Generate All Possible Rotations**: For a string of length N, there are N possible rotations (including the original string). Each rotation can be generated by taking the last k characters and placing them at the front, followed by the remaining characters.
3. **Check for Match**: For each possible rotation of S, check if it matches T. If any rotation matches, output "Yes"; otherwise, output "No".

### Solution Code
```python
def main():
    S = input().strip()
    T = input().strip()
    for k in range(len(S)):
        rotated = S[-k:] + S[:-k] if k != 0 else S
        if rotated == T:
            print("Yes")
            return
    print("No")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of two strings, S and T, which are read from standard input.
2. **Loop Through Rotations**: For each possible rotation count from 0 to the length of S minus 1, generate the rotated string.
3. **Generate Rotated String**: For each rotation count k, the rotated string is formed by concatenating the last k characters of S with the first (length of S - k) characters of S.
4. **Check for Equality**: If any generated rotated string matches T, print "Yes" and exit. If none match after all rotations, print "No".

This approach efficiently checks all possible rotations in linear time relative to the length of S, making it suitable for the given constraints.
