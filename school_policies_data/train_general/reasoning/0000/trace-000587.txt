def kosaraju(n, adj):
    visited = [False] * (n + 1)  # nodes are 1-based
    order = []
    # First pass: process nodes in original graph
    for i in range(1, n+1):
        if not visited[i]:
            stack = [(i, False)]
            while stack:
                node, processed = stack.pop()
                if processed:
                    order.append(node)
                    continue
                if visited[node]:
                    continue
                visited[node] = True
                stack.append( (node, True) )
                for neighbor, _ in reversed(adj[node]):  # to simulate the order of recursive DFS
                    if not visited[neighbor]:
                        stack.append( (neighbor, False) )
    # Reverse the graph
    reverse_adj = [[] for _ in range(n+1)]
    for u in range(1, n+1):
        for v, l in adj[u]:
            reverse_adj[v].append( (u, l) )
    # Second pass: find SCCs
    visited = [False] * (n + 1)
    components = []
    for node in reversed(order):
        if not visited[node]:
            stack = [node]
            visited[node] = True
            component = []
            while stack:
                u = stack.pop()
                component.append(u)
                for v, _ in reverse_adj[u]:
                    if not visited[v]:
                        visited[v] = True
                        stack.append(v)
            components.append(component)
    # Assign component id to each node
    comp_id = [0]*(n+1)
    for i, comp in enumerate(components):
        for node in comp:
            comp_id[node] = i
    return components, comp_id

To solve this problem, we need to determine if each car can return to its starting intersection with the odometer showing zero after driving through some roads. The solution involves analyzing the graph structure and leveraging properties of cycles within strongly connected components (SCCs).

### Approach
1. **Identify Strongly Connected Components (SCCs)**: Using Kosaraju's algorithm, we decompose the graph into SCCs. Each SCC is a subgraph where every node is reachable from every other node within the same SCC.

2. **Compute Cycle Length GCD for Each SCC**: For each SCC, we compute the greatest common divisor (GCD) of all cycle lengths within that SCC. This is done using a BFS traversal to assign potentials (distances) to each node and then calculating discrepancies in these potentials to determine the GCD.

3. **Query Processing**: For each query, check if the car can return to its starting node with the odometer showing zero. This involves checking if the required distance (to reset the odometer) is a multiple of the GCD of the cycle lengths in the car's SCC, adjusted by the car's parameters.

                    q.append(v)
                else:
                    discrepancy = (potentials[u] + l) - potentials[v]
                    if discrepancy != 0:
                        g = math.gcd(g, abs(discrepancy))
        component_gcd[i] = g

    for _ in range(q):
        v_i, s_i, t_i = map(int, stdin.readline().split())
        if s_i == 0:

        if len(components[cid]) == 1:

        g = component_gcd[cid]
        if g == 0:
            print("NO")
            continue
        required = (-s_i) % t_i
        d = math.gcd(g, t_i)
        if required % d == 0:
            print("YES")
        else:
            print("NO")
