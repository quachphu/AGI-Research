To solve this problem, we need to determine if a given set of integers meets specific conditions that are considered unlucky. The conditions are that both the product of two integers (H and W) and the sum of two other integers (X and Y) must be odd. If both conditions are met, the result is "No"; otherwise, it is "Yes".

### Approach
1. **Input Reading**: Read four integers H, W, X, and Y from the input.
2. **Product Check**: Calculate the product of H and W and check if it is odd.
3. **Sum Check**: Calculate the sum of X and Y and check if it is odd.
4. **Condition Evaluation**: If both the product and sum are odd, print "No". Otherwise, print "Yes".

### Solution Code
```python
def main():
    H, W, X, Y = map(int, input().split())
    product = H * W
    sum_xy = X + Y
    if product % 2 == 1 and sum_xy % 2 == 1:
        print("No")
    else:
        print("Yes")

main()
```

### Explanation
1. **Reading Input**: The input is read as a single line and split into four integers H, W, X, and Y.
2. **Product Calculation**: The product of H and W is computed. If this product is odd (i.e., when the product modulo 2 equals 1), it meets one of the unlucky conditions.
3. **Sum Calculation**: The sum of X and Y is computed. If this sum is odd, it meets the other unlucky condition.
4. **Condition Check**: Both conditions (product and sum being odd) are checked. If both are true, the output is "No". If either or both are not true, the output is "Yes".

This approach efficiently checks the required conditions using basic arithmetic operations and modular checks, ensuring optimal performance even for the upper constraint limits.
