To solve this problem, we need to determine if two flies sitting on different vertices of a cube can see each other. The flies can see each other if their vertices lie on the same face of the cube. 

### Approach
The key observation is that two vertices lie on the same face of a cube if and only if they share at least one coordinate (x, y, or z). This is because each face of the cube is defined by fixing one of the coordinates (x, y, or z) to either 0 or 1. Therefore, if two vertices share any coordinate, they must lie on the face corresponding to that fixed coordinate.

### Solution Code
```python
def main():
    p1 = list(map(int, input().split()))
    p2 = list(map(int, input().split()))
    if p1[0] == p2[0] or p1[1] == p2[1] or p1[2] == p2[2]:
        print("YES")
    else:
        print("NO")

main()
```

### Explanation
1. **Reading Input:** The code reads two lines of input, each representing the coordinates of a vertex where a fly is sitting.
2. **Coordinate Check:** The code checks if the two vertices share any coordinate (x, y, or z). If they do, the vertices lie on the same face of the cube, and the output is "YES". Otherwise, the output is "NO".

This approach efficiently determines the visibility between the two flies by leveraging the geometric properties of the cube's faces, ensuring a solution with constant time complexity O(1).
