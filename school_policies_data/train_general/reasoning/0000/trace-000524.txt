The solution involves analyzing the game using combinatorial game theory principles, specifically the Sprague-Grundy theorem, which allows us to break the problem into independent subgames and determine the winner based on the XOR of their Grundy numbers.

### Approach
1. **Generate Primes and Semi-Primes**: We first generate all prime numbers up to the maximum possible value (200,000) using the Sieve of Eratosthenes. We then generate semi-primes (products of two primes) up to the same limit.
2. **Identify Forbidden Moves**: We exclude the given forbidden move `f` from the set of valid moves.
3. **Compute Grundy Numbers**: Using dynamic programming, we compute the Grundy numbers for each possible value up to the maximum possible distance between tokens on the grid. The Grundy number for a value `n` is the minimum excludant (mex) of the Grundy numbers of all values reachable by subtracting valid moves from `n`.
4. **Determine Game Outcome**: For each row, compute the XOR of the Grundy numbers of the distances between the blue and white tokens and between the white and red tokens. The total XOR of these values across all rows determines the winner. If the total XOR is non-zero, the first player wins; otherwise, the second player wins.

import sys

def main():
    import sys
    sys.setrecursionlimit(1 << 25)
    n, f = map(int, sys.stdin.readline().split())
    rows = [tuple(map(int, sys.stdin.readline().split())) for _ in range(n)]

    max_possible = 2 * 10**5 * 2  # To cover all possible x and y

    # Step 1: Generate primes using sieve of Eratosthenes
    sieve = [True] * (max_possible + 1)
    sieve[0] = sieve[1] = False
    for i in range(2, int(max_possible**0.5) + 1):
        if sieve[i]:
            sieve[i*i : max_possible+1 : i] = [False]*len(sieve[i*i : max_possible+1 : i])
    primes = [i for i, is_prime in enumerate(sieve) if is_prime]

    # Step 2: Generate semi-primes (products of two primes)
    semi_primes = set()
    for p in primes:
        if p > max_possible // p:
            break
        for q in primes:
            if q < p:
                continue  # to avoid duplicates, considering p <= q
            product = p * q
            if product > max_possible:
                break
            semi_primes.add(product)
    semi_primes = list(semi_primes)

    # Combine primes and semi_primes into S, then remove f
    S = set(primes)
    S.update(semi_primes)
    if f in S:
        S.remove(f)
    S = sorted(S)

    # Precompute grundy numbers for all possible n up to max_possible
    max_grundy = max_possible
    grundy = [0] * (max_grundy + 1)
    for n in range(1, max_grundy + 1):
        reachable = set()
        for k in S:
            if k > n:
                break
            reachable.add(grundy[n - k])
        mex = 0
        while mex in reachable:
            mex += 1
        grundy[n] = mex

    # Process each row
    total_xor = 0
    for b, w, r in rows:
        x = w - b
        y = r - w
        gx = grundy[x] if x <= max_grundy else 0
        gy = grundy[y] if y <= max_grundy else 0
        total_xor ^= (gx ^ gy)

    # Determine the winners
    alice_wins = total_xor != 0
    print("Alice" if alice_wins else "Bob")
    print("Bob" if total_xor !=0 else "Alice")

if __name__ == "__main__":
    main()
