To solve this problem, we need to determine the maximum possible number of points you can score by deleting up to k cubes such that the remaining cubes form the longest consecutive sequence of the same color. 

### Approach
The solution involves using a sliding window technique combined with frequency counting to efficiently find the optimal sequence. Here's the detailed approach:

1. **Frequency Calculation**: First, compute the frequency of each color in the array. This helps in prioritizing colors with higher frequencies as they are more likely to form longer sequences.
2. **Sort Colors by Frequency**: Sort the colors in descending order based on their frequencies. This allows us to process colors with higher frequencies first, potentially reducing the number of colors we need to check.
3. **Sliding Window Technique**: For each color, use a sliding window approach to find the longest window where the number of non-current-color elements (which need to be deleted) is within the allowed limit k. This helps in efficiently determining the maximum possible consecutive sequence for each color.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n, m, k = map(int, sys.stdin.readline().split())
    arr = list(map(int, sys.stdin.readline().split()))
    
    freq = defaultdict(int)
    for num in arr:
        freq[num] += 1
    
    # Sort colors in descending order of frequency
    colors = sorted(freq.keys(), key=lambda x: -freq[x])
    
    ans = 0
    
    for c in colors:
        # Early termination if current color's frequency can't exceed current answer
        if freq[c] <= ans:
            break
        
        current_max = 0
        cnt_non = 0
        left = 0
        
        for right in range(n):
            if arr[right] != c:
                cnt_non += 1
            
            # Ensure the window is valid by moving left pointer if needed
            while cnt_non > k:
                if arr[left] != c:
                    cnt_non -= 1
                left += 1
            
            # Calculate current number of c's in the window
            current_c = (right - left + 1) - cnt_non
            if current_c > current_max:
                current_max = current_c
        
        if current_max > ans:
            ans = current_max
    
    print(ans)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Frequency Calculation**: We use a dictionary to count how many times each color appears in the array.
2. **Sorting Colors**: By sorting colors based on their frequency in descending order, we prioritize processing colors that have the potential to form longer sequences.
3. **Sliding Window for Each Color**: For each color, we use a sliding window to maintain a valid window where the number of deletions (non-current-color elements) is within the allowed limit k. We adjust the window size dynamically by moving the left pointer whenever the number of deletions exceeds k. This helps in efficiently finding the longest valid sequence for each color.

This approach ensures that we efficiently explore all possible sequences while leveraging the frequency of colors to minimize unnecessary computations, leading to an optimal solution.
