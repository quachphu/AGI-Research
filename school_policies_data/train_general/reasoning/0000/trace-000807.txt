   - If there are any 1s (x ≥ 1), follow the initial 2 with a 1 to get the next prefix sum as 3 (another prime).
   - Append all remaining 2s to maintain the sum as odd, which increases the chances of forming primes.
   - Finally, append all remaining 1s. These will turn the sum into even numbers, which (except for 2) are not primes, but by this point, we have already maximized the number of primes.

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    x = a.count(1)
    y = a.count(2)
    
    res = []
    if y > 0:
        res.append(2)
        y -= 1
        if x > 0:
            res.append(1)
            x -= 1
        res += [2] * y
        res += [1] * x
    else:
        res = [1] * x
    
    print(' '.join(map(str, res)))

main()
