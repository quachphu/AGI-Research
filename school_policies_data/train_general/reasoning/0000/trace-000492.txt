2. **Dynamic Programming with Factorials**: Precompute factorials and their modular inverses up to a sufficient maximum value to efficiently compute combinations using the formula \( C(n, k) = \frac{n!}{k!(n-k)!} \mod 10^9 + 7 \).
3. **Prefix Sums and Combinations**: For each color, compute the number of ways to place its balls such that the last ball is positioned correctly relative to previous colors. This is done using prefix sums and combinations.

### Solution Code

MOD = 10**9 + 7

max_n = 1000  # Maximum possible sum of c_i is 1000, so n can be up to 999

# Precompute factorial and inverse factorial modulo MOD
fact = [1] * (max_n + 1)
for i in range(1, max_n + 1):
    fact[i] = fact[i-1] * i % MOD

inv_fact = [1] * (max_n + 1)
inv_fact[max_n] = pow(fact[max_n], MOD-2, MOD)
for i in range(max_n - 1, -1, -1):
    inv_fact[i] = inv_fact[i+1] * (i+1) % MOD

def comb(n, k):
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % MOD * inv_fact[n - k] % MOD

k = int(input())
c = [int(input()) for _ in range(k)]

result = 1
current_sum = 0
for ci in c:
    current_sum += ci
    n = current_sum - 1
    k_comb = ci - 1

print(result)
