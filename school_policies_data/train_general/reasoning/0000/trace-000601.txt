To solve this problem, we need to calculate the "power" of several subarrays of a given array. The power of a subarray is defined as the sum of the product of the square of the frequency of each element in the subarray and the element itself. Given the constraints, a direct approach would be too slow, so we use Mo's algorithm to efficiently process the queries.

### Approach
1. **Mo's Algorithm**: This algorithm is used to process range queries efficiently by sorting them in a way that minimizes the number of element additions and removals when moving from one query to the next. This reduces the time complexity from O(n^2) to O(n * sqrt(n)).

2. **Sorting Queries**: Queries are sorted based on the block of their left endpoint and then by their right endpoint, with a slight optimization to alternate the order of right endpoints for consecutive blocks to reduce movement.

3. **Efficient Updates**: As we adjust the current window to match each query, we maintain a count of each element's frequency and update the power sum incrementally. Each addition or removal of an element adjusts the sum based on the change in frequency.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n, t = int(input[ptr]), int(input[ptr+1])
    ptr += 2
    a = list(map(int, input[ptr:ptr+n]))
    ptr += n
    queries = []
    for i in range(t):
        l = int(input[ptr]) - 1  # Convert to 0-based
        r = int(input[ptr+1]) - 1
        ptr += 2
        queries.append((l, r, i))
    
    block_size = int(n**0.5) + 1  # Determine block size for Mo's algorithm

    # Custom comparator for Mo's algorithm
    def mo_cmp(query):
        l, r, idx = query
        block = l // block_size
        return (block, r if (block % 2 == 0) else -r)
    
    queries.sort(key=mo_cmp)
    
    max_a = 10**6 + 2
    count = [0] * max_a  # Frequency count of each element
    current_l = 0
    current_r = 0
    sum_power = 0
    ans = [0] * t
    
    for l, r, idx in queries:
        target_r = r + 1  # Convert to [current_l, current_r) format
        
        # Expand to the left
        while current_l > l:
            current_l -= 1
            x = a[current_l]
            sum_power += (count[x] * 2 + 1) * x
            count[x] += 1
        
        # Expand to the right
        while current_r < target_r:
            x = a[current_r]
            sum_power += (count[x] * 2 + 1) * x
            count[x] += 1
            current_r += 1
        
        # Shrink from the left
        while current_l < l:
            x = a[current_l]
            sum_power -= (count[x] * 2 - 1) * x
            count[x] -= 1
            current_l += 1
        
        # Shrink from the right
        while current_r > target_r:
            current_r -= 1
            x = a[current_r]
            sum_power -= (count[x] * 2 - 1) * x
            count[x] -= 1
        
        ans[idx] = sum_power
    
    for a_val in ans:
        print(a_val)

if __name__ == "__main__":
    main()
```

4. **Processing Queries**: Adjust the current window (current_l, current_r) to match each query, updating the sum incrementally based on the frequency of elements added or removed.
5. **Efficient Updates**: Each element addition or removal updates the sum using the change in frequency, ensuring each update is done in constant time.
