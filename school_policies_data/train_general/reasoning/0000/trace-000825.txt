To solve this problem, we need to compute the product of the number of tanks contributed by each country, where each number is either a "beautiful" number or a modified version of a beautiful number. A beautiful number is defined as a number consisting only of the digits '0' and '1', with at most one '1'. The challenge is to efficiently compute the product, considering the constraints on the input.

### Approach
1. **Check for Zero**: If any country contributed zero tanks, the product will be zero.
2. **Identify Beautiful Numbers**: For each number, check if it is beautiful. Beautiful numbers contribute to the product in a specific way (as powers of 10).
3. **Sum Exponents**: For each beautiful number, compute the exponent (number of zeros in its decimal representation) and sum these exponents.
4. **Handle Non-beautiful Numbers**: If there is exactly one non-beautiful number, the product is this number followed by zeros corresponding to the sum of exponents from beautiful numbers. If all numbers are beautiful, the product is 1 followed by the sum of exponents as zeros.

### Solution Code
```python
def is_beautiful(s):
    if s == '0':
        return True
    if s[0] != '1':
        return False
    count_ones = 0
    for c in s:
        if c not in {'0', '1'}:
            return False
        if c == '1':
            count_ones += 1
            if count_ones > 1:
                return False
    return count_ones == 1

n = int(input())
a = input().split()

if '0' in a:
    print(0)
else:
    non_beautiful = []
    m = 0
    for s in a:
        if is_beautiful(s):
            if s != '1':
                m += len(s) - 1
        else:
            non_beautiful.append(s)
    if len(non_beautiful) == 0:
        print('1' + '0' * m)
    else:
        print(non_beautiful[0] + '0' * m)
```

### Explanation
1. **Check for Zero**: The presence of '0' in the input list immediately results in a product of 0.
2. **Identify Beautiful Numbers**: The function `is_beautiful` checks if a number is beautiful by ensuring it consists of '0's and at most one '1'.
3. **Sum Exponents**: For each beautiful number (excluding '1'), the exponent is determined by the length of the string minus one (since it starts with '1' followed by zeros).
4. **Construct Result**: If all numbers are beautiful, the result is '1' followed by zeros equal to the sum of exponents. If there's one non-beautiful number, it is concatenated with the sum of exponents as trailing zeros.

This approach efficiently handles large numbers by leveraging string operations, avoiding direct computation of extremely large products.
