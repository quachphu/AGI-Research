To solve this problem, we need to determine the number of integer points covered by exactly k segments for each k from 1 to n. Given the constraints, we need an efficient approach that avoids iterating over each possible integer point.

### Approach
1. **Event Points**: For each segment [l, r], create two events: a start event at l (increment coverage) and an end event at r+1 (decrement coverage).
2. **Sort Events**: Sort all events by their coordinate. If two events have the same coordinate, process end events before start events to ensure correct coverage calculation.
3. **Process Intervals**: Traverse the sorted events to maintain the current coverage count. For each interval between consecutive events, calculate the number of integer points covered and update the count for the respective coverage value.

### Solution Code
```python
n = int(input())
events = []
for _ in range(n):
    l, r = map(int, input().split())
    events.append((l, 1))
    events.append((r + 1, -1))

events.sort()
current_coverage = 0
prev_x = None
ans = [0] * (n + 2)  # ans[1..n]

for x, delta in events:
    if prev_x is not None and x > prev_x:
        length = x - prev_x
        if 1 <= current_coverage <= n:
            ans[current_coverage] += length
    current_coverage += delta
    prev_x = x

print(' '.join(map(str, ans[1:n+1])))
```
