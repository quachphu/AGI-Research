To solve this problem, we need to determine how many minutes Limak will watch a game before turning it off due to 15 consecutive boring minutes. The game lasts 90 minutes, and we are given the specific minutes that are interesting. If any 15-minute stretch of boring minutes occurs, Limak stops watching immediately after the 15th minute.

### Approach
1. **Identify Boring Intervals**: The game timeline is divided into intervals of boring minutes. These intervals occur before the first interesting minute, between consecutive interesting minutes, and after the last interesting minute.
2. **Check for 15-Minute Boring Stretch**: For each interval, check if its length is at least 15 minutes. If so, determine the earliest possible end time where Limak would stop watching.
3. **Determine the Result**: The result is the minimum of all possible end times where a 15-minute boring stretch starts. If no such interval exists, Limak watches the entire 90 minutes.

### Solution Code
```python
n = int(input())
t = list(map(int, input().split()))

end_times = []

# Check the interval before the first interesting minute
if t and t[0] > 1:
    start = 1
    end = t[0] - 1
    if end - start + 1 >= 15:
        end_times.append(start + 14)

# Check intervals between consecutive interesting minutes
for i in range(n - 1):
    current = t[i]
    next_ = t[i + 1]
    start = current + 1
    end = next_ - 1
    if start <= end:
        if end - start + 1 >= 15:
            end_times.append(start + 14)

# Check the interval after the last interesting minute
if t:
    start = t[-1] + 1
    end = 90
    if start <= end and end - start + 1 >= 15:
        end_times.append(start + 14)

# Determine the answer
if end_times:
    print(min(end_times))
else:
    print(90)
```

### Explanation
1. **Reading Input**: The input consists of the number of interesting minutes and the list of those minutes.
2. **First Interval Check**: Before the first interesting minute, check if there's a boring interval long enough to cause Limak to stop watching.
3. **Middle Intervals Check**: For each pair of consecutive interesting minutes, check the interval in between for a 15-minute boring stretch.
4. **Last Interval Check**: After the last interesting minute, check the remaining time up to 90 minutes.
5. **Result Calculation**: The smallest end time from any valid interval is the result. If no valid interval is found, the result is 90 minutes.

This approach efficiently checks all possible intervals and ensures we find the earliest point where Limak would stop watching, if any.
