### Approach
1. **Extended Euclidean Algorithm**: This algorithm not only computes the greatest common divisor (gcd) of two integers a and b but also finds coefficients x and y such that ax + by = gcd(a, b). The algorithm works by iteratively applying the Euclidean division and updating coefficients.
2. **Generating Candidates**: After obtaining the initial coefficients (x0, y0) from the Extended Euclidean Algorithm, we generate candidate solutions by adjusting these coefficients using integer multiples of b/gcd(a, b) for x and a/gcd(a, b) for y. This adjustment is based on the general solution of the linear Diophantine equation.
3. **Selecting Optimal Solution**: Among all candidate solutions, we select the one with the minimal sum of absolute values. If there are multiple candidates with the same minimal sum, we choose the one where x ≤ y.

import math

    old_x, x = 1, 0
    old_y, y = 0, 1

        candidates.add(math.ceil(k_yzero) + delta)

    # Include k=0 and some additional around to cover possible minima
    candidates.add(0)
    candidates.add(1)
    candidates.add(-1)

    best_sum = None
    best_x = None
    best_y = None

    for k in candidates:

        y = y0 - n * k
        current_sum = abs(x) + abs(y)

        if best_sum is None:
            best_sum = current_sum
            best_x = x
            best_y = y
        else:
            if current_sum < best_sum:
                best_sum = current_sum
                best_x = x
                best_y = y

                best_x_leq_y = (best_x <= best_y)

                if current_x_leq_y:
