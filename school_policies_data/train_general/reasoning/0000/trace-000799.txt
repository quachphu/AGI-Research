To solve this problem, we need to determine the maximum amount of American dollars we can get by exchanging a Bytelandian gold coin, either by splitting it into smaller coins or by selling it directly. The optimal solution involves using dynamic programming with memoization to efficiently compute the maximum value for each coin.

### Approach
1. **Problem Analysis**: Each Bytelandian gold coin can be split into three smaller coins (n//2, n//3, n//4) or sold directly. The goal is to maximize the value obtained by either splitting or selling the coin.
2. **Recursive Insight**: The maximum value for a coin `n` is the maximum of `n` itself or the sum of the maximum values of the three smaller coins obtained by splitting.
3. **Memoization**: To avoid redundant calculations, we use memoization to store the results of previously computed values. This ensures each value is computed only once, significantly improving efficiency.
4. **Base Case Handling**: For values of `n` less than 12, the maximum value is `n` itself because splitting these values does not yield a higher amount.

### Solution Code
```python
import sys
from functools import lru_cache

@lru_cache(maxsize=None)
def max_dollars(n):
    if n < 12:
        return n
    split_sum = max_dollars(n // 2) + max_dollars(n // 3) + max_dollars(n // 4)
    return max(n, split_sum)

for line in sys.stdin:
    n = int(line.strip())
    print(max_dollars(n))
```

### Explanation
- **Memoization with LRU Cache**: The `lru_cache` decorator is used to store the results of the `max_dollars` function for each input value, ensuring that each value is computed only once.
- **Base Case Handling**: For values of `n` less than 12, the function directly returns `n` as splitting these values does not yield a higher amount.
- **Recursive Calculation**: For values of `n` 12 or greater, the function recursively calculates the maximum value obtainable by splitting the coin into three parts and comparing it with the value of the coin itself.

This approach efficiently handles large values up to 1,000,000,000 and multiple test cases, ensuring optimal performance using dynamic programming and memoization.
