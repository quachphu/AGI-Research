To solve this problem, we need to determine the total number of distinct gift exchanges possible among groups of students connected by ropes. Each group forms a connected component, and the number of distinct exchanges for a group of size `m` is given by `m!` (m factorial). The result is the product of these factorials for all connected components, modulo \(10^9 + 7\).

### Approach
1. **Precompute Factorials**: Since the maximum number of students can be up to 100,000, precompute factorials modulo \(10^9 + 7\) up to this value for efficient look-up.
2. **Union-Find Data Structure**: Use a Disjoint Set Union (DSU) to efficiently find and union connected components. This helps in determining the size of each connected component.
3. **Calculate Component Sizes**: After processing all connections, determine the size of each connected component using the DSU.
4. **Compute Result**: Multiply the factorials of the sizes of all connected components, taking modulo \(10^9 + 7\) at each step to prevent overflow.

### Solution Code
```python
MOD = 10**9 + 7
max_n = 10**5

# Precompute factorials modulo MOD
fact = [1] * (max_n + 1)
for i in range(1, max_n + 1):
    fact[i] = fact[i-1] * i % MOD

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return
        if self.size[x_root] < self.size[y_root]:
            x_root, y_root = y_root, x_root
        self.parent[y_root] = x_root
        self.size[x_root] += self.size[y_root]

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    K = int(input[ptr])
    ptr += 1

    dsu = DSU(N)
    for _ in range(K):
        u = int(input[ptr])
        ptr += 1
        v = int(input[ptr])
        ptr += 1
        dsu.union(u, v)

    seen = set()
    result = 1
    for i in range(N):
        root = dsu.find(i)
        if root not in seen:
            seen.add(root)
            result = (result * fact[dsu.size[root]]) % MOD

    print(result % MOD)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precompute Factorials**: We precompute the factorials up to \(10^5\) to quickly access the factorial of any component size during the result calculation.
2. **Union-Find (DSU)**: This data structure helps efficiently manage and merge connected components. Each union operation ensures that the size of the resulting component is tracked correctly.
3. **Component Size Calculation**: After processing all edges, each node's root is found, and the size of the component rooted at that node is recorded if it hasn't been processed before.
4. **Result Calculation**: The product of the factorials of all component sizes is computed modulo \(10^9 + 7\) to get the final result.

This approach ensures that we efficiently handle the constraints and compute the required result in a time complexity that is nearly linear with respect to the number of students and connections.
