To solve this problem, we need to determine if we can connect two boxes in a circular arrangement such that the connecting rod does not intersect with any previously placed rods. Each box can be connected to at most one other box, and no box can be connected to itself.

### Approach
1. **Check for Self-Connection**: If a query asks to connect a box to itself, it is immediately rejected.
2. **Check for Existing Connections**: If either box in the query is already connected to another box, the connection is rejected.
3. **Check for Intersections**: For each new connection request, check if the new rod would intersect with any existing rods. This is done by verifying if the endpoints of the new rod and any existing rod are interleaved in a way that causes intersection.

### Solution Code
```python
def between(x, y, p):
    if x < y:
        return x < p < y
    else:
        return p > x or p < y

def main():
    import sys
    data = sys.stdin.read().split()
    ptr = 0
    N = int(data[ptr])
    Q = int(data[ptr + 1])
    ptr += 2
    rods = []
    connections = {}
    for _ in range(Q):
        i = int(data[ptr])
        j = int(data[ptr + 1])
        ptr += 2
        if i == j:
            print("NO")
            continue
        if i in connections or j in connections:
            print("NO")
            continue
        crosses = False
        for (a, b) in rods:
            cross1 = between(a, b, i) != between(a, b, j)
            cross2 = between(i, j, a) != between(i, j, b)
            if cross1 or cross2:
                crosses = True
                break
        if crosses:
            print("NO")
        else:
            rods.append((i, j))
            connections[i] = j
            connections[j] = i
            print("YES")

main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Self-Connection Check**: If the two boxes in the query are the same, the answer is immediately "NO".
3. **Existing Connections Check**: Using a dictionary to track connections, we check if either box is already connected.
4. **Intersection Check**: For each existing rod, we check if the new rod would intersect using the `between` function. This function determines if a point lies within the interval defined by two other points on a circular arrangement.
5. **Updating Connections**: If all checks pass, the new connection is recorded, and the result is "YES".

The algorithm efficiently checks each new query against existing connections in O(Q) time per query, resulting in an overall time complexity of O(Q^2), which is feasible given the problem constraints.
