To solve this problem, we need to determine how many valid 32x32 checkerboard patterns exist within a given N x M grid. A valid checkerboard alternates between '_' and '#' starting with '_' in even rows and '#' in odd rows.

### Approach
1. **Pattern Analysis**: The valid checkerboard alternates characters such that each cell (i, j) in the grid should be '_' if the sum of its row and column indices (i + j) is even, and '#' if the sum is odd. This pattern alternates every row.
2. **Precomputation**: We precompute two matrices, `valid_p0` and `valid_p1`, where each cell indicates whether the character matches the expected pattern for even and odd parity respectively.
3. **Prefix Sums**: Using these matrices, we compute prefix sums to quickly check the sum of any submatrix. This allows us to efficiently determine if a 32x32 subgrid matches the expected pattern.
4. **Efficient Checking**: For each possible top-left corner of a 32x32 subgrid, we use the precomputed prefix sums to check if the entire subgrid matches the expected pattern in constant time.

### Solution Code
```python
import sys

def main():
    n, m = map(int, sys.stdin.readline().split())
    grid = [sys.stdin.readline().strip() for _ in range(n)]
    
    valid_p0 = [[0] * m for _ in range(n)]
    valid_p1 = [[0] * m for _ in range(n)]
    
    for i in range(n):
        for j in range(m):
            cell_parity = (i + j) % 2
            c = grid[i][j]
            valid_p0[i][j] = 1 if ((cell_parity == 0 and c == '_') or (cell_parity == 1 and c == '#')) else 0
            valid_p1[i][j] = 1 if ((cell_parity == 1 and c == '_') or (cell_parity == 0 and c == '#')) else 0
    
    # Compute prefix sums for valid_p0 and valid_p1
    prefix_p0 = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            prefix_p0[i][j] = prefix_p0[i-1][j] + prefix_p0[i][j-1] - prefix_p0[i-1][j-1] + valid_p0[i-1][j-1]
    
    prefix_p1 = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            prefix_p1[i][j] = prefix_p1[i-1][j] + prefix_p1[i][j-1] - prefix_p1[i-1][j-1] + valid_p1[i-1][j-1]
    
    count = 0
    required = 32 * 32
    
    for x in range(n - 31):
        for y in range(m - 31):
            p = (x + y) % 2
            if p == 0:
                total = prefix_p0[x+32][y+32] - prefix_p0[x][y+32] - prefix_p0[x+32][y] + prefix_p0[x][y]
            else:
                total = prefix_p1[x+32][y+32] - prefix_p1[x][y+32] - prefix_p1[x+32][y] + prefix_p1[x][y]
            if total == required:
                count += 1
    
    print(count)

if __name__ == "__main__":
    main()
```

2. **Prefix Sum Calculation**: Prefix sums for these matrices allow us to quickly compute the sum of any submatrix in constant time.
3. **Efficient Validation**: By iterating over all possible top-left corners of 32x32 subgrids and using the prefix sums, we efficiently check each subgrid in constant time, leading to an overall time complexity of O(N*M), which is feasible for large grids up to 2000x2000.
