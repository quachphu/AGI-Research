To solve this problem, we need to identify the missing numbers from list A that were originally present in list B. The key observation is that B was a permutation of the original A, so any discrepancies in the frequency of numbers between the current A and B indicate missing numbers from A.

### Approach
1. **Read Input:** Read the sizes and elements of lists A and B.
2. **Count Frequencies:** Use a frequency counter to count occurrences of each number in both lists.
3. **Identify Missing Numbers:** For each number in B, check if its frequency in B is greater than its frequency in A. If so, add it to the list of missing numbers.
4. **Sort and Output:** Sort the missing numbers in ascending order and print them.

### Solution Code
```python
from collections import Counter
import sys

def main():
    # Read the input
    n = int(sys.stdin.readline())
    A = list(map(int, sys.stdin.readline().split()))
    m = int(sys.stdin.readline())
    B = list(map(int, sys.stdin.readline().split()))
    
    # Count occurrences of each number in both lists
    count_A = Counter(A)
    count_B = Counter(B)
    
    # Determine missing numbers
    missing = []
    for num in count_B:
        if count_B[num] > count_A.get(num, 0):
            missing.append(num)
    
    # Sort and print the result
    missing.sort()
    print(' '.join(map(str, missing)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The input is read from standard input using `sys.stdin.readline()` for efficiency, especially with large input sizes.
2. **Counting Frequencies:** Using `collections.Counter`, we efficiently count the occurrences of each number in both lists A and B.
3. **Identifying Missing Numbers:** By iterating over the elements in B's frequency counter, we check if each element's count in B exceeds its count in A. This difference indicates missing elements from A.
4. **Sorting and Outputting:** The missing numbers are sorted to ensure ascending order and printed as a space-separated string.

This approach ensures that we efficiently handle large input sizes within the problem constraints, providing an optimal solution with linear time complexity relative to the input size.
