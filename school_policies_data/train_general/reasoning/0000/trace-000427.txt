### Approach
The key insight is to use a repeating pattern of the characters 'a', 'b', 'c', and 'd'. This pattern ensures that each character is reused every 4 positions, which satisfies the condition of having adjacent differences of 4 (a lucky number). By cycling through these four characters, we can construct the lexicographically smallest string efficiently.

### Solution Code
```python
n = int(input())
result = 'abcd' * (n // 4) + 'abcd'[:n % 4]
print(result)
```

### Explanation
1. **Pattern Selection**: The characters 'a', 'b', 'c', and 'd' are chosen because they are the lexicographically smallest and form a cycle that meets the lucky number condition (difference of 4 between consecutive positions).
2. **Cycle Repetition**: The string is constructed by repeating the "abcd" pattern. For a given length `n`, we repeat the pattern `n // 4` times to cover the bulk of the length.
3. **Remainder Handling**: Any remaining characters needed to reach the exact length `n` are taken from the start of the "abcd" pattern, ensuring the lexicographically smallest continuation.

This approach efficiently constructs the required string in O(n) time, ensuring it is both lucky and lexicographically minimal.
