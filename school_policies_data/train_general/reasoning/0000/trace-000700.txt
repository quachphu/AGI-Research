To solve this problem, we need to determine the number of valid positions on a chessboard where a new knight can be placed such that none of the three pieces (rook, existing knight, and new knight) attack each other. The solution involves checking each possible position on the board against several conditions to ensure mutual non-aggression.

### Approach
1. **Convert Input Positions**: Convert the given positions of the rook and the existing knight from chess notation (like 'a1') into numerical coordinates for easier manipulation.
2. **Check All Positions**: Iterate over all possible positions on the chessboard (8x8 grid).
3. **Validate Each Position**: For each position, check the following conditions:
   - The position is not occupied by the rook or the existing knight.
   - The position is not in the same row or column as the rook (to avoid rook's line of attack).
   - The position is not a knight's move away from the rook (to avoid new knight attacking the rook).
   - The position is not a knight's move away from the existing knight (to avoid mutual attack between knights).

### Solution Code
```python
def main():
    rook_pos = input().strip()
    knight_pos = input().strip()
    
    def to_coords(pos):
        x = ord(pos[0]) - ord('a')
        y = int(pos[1]) - 1
        return (x, y)
    
    rx, ry = to_coords(rook_pos)
    kx, ky = to_coords(knight_pos)
    
    count = 0
    
    for x in range(8):
        for y in range(8):
            if (x == rx and y == ry) or (x == kx and y == ky):
                continue
            if x == rx or y == ry:
                continue
            dx_rook = abs(x - rx)
            dy_rook = abs(y - ry)
            if (dx_rook == 1 and dy_rook == 2) or (dx_rook == 2 and dy_rook == 1):
                continue
            dx_knight = abs(x - kx)
            dy_knight = abs(y - ky)
            if (dx_knight == 1 and dy_knight == 2) or (dx_knight == 2 and dy_knight == 1):
                continue
            count += 1
    
    print(count)

main()
```

### Explanation
- **Input Conversion**: The positions of the rook and knight are converted from chess notation to zero-based coordinates. For example, 'a1' becomes (0, 0) and 'h8' becomes (7, 7).
- **Position Validation**: Each position on the board is checked to ensure it is not occupied and does not fall into any of the attack lines or moves of the existing pieces.
  - **Rook's Line of Attack**: Check if the position shares the same row or column as the rook.
  - **Knight's Move Check**: Verify if the position is a valid knight's move away from both the rook and the existing knight using the difference in coordinates.
- **Count Valid Positions**: Increment the count for each valid position that passes all checks and print the result.

This approach ensures that all mutual attack conditions are checked efficiently, resulting in the correct count of valid positions for placing the new knight.
