To solve this problem, we need to determine how many spiders Om Nom will encounter during his walk for each possible starting cell in the first row of the park. The park is represented as a grid with spiders moving in specific directions, and Om Nom moves straight down from the first row to the last row, one row per time unit.

### Approach
1. **Problem Analysis**:
   - Om Nom starts at the first row and moves down one row each time unit.
   - Spiders move continuously in one of four directions (left, right, up, down) and leave the park if they go out of bounds.
   - We need to count how many spiders Om Nom will see for each starting column in the first row.

2. **Key Insights**:
   - For each spider, determine if it will be present in a cell that Om Nom visits at the corresponding time.
   - Spiders moving up (U) can only be encountered if their starting row is odd.
   - Spiders moving left (L) and right (R) will be encountered if their movement aligns with Om Nom's path at the correct time.

3. **Algorithm**:
   - Iterate through each cell in the park grid (excluding the first row).
   - For each spider, calculate the column where Om Nom would encounter it based on its movement direction and starting position.
   - Update the count of encounters for the respective starting columns.

### Solution Code
```python
n, m, k = map(int, input().split())
grid = [input().strip() for _ in range(n)]
res = [0] * m

for x in range(2, n + 1):
    row = grid[x - 1]
    for col_idx, c in enumerate(row):
        if c == '.':
            continue
        y = col_idx + 1
        if c == 'U':
            if x % 2 == 1:
                res[y - 1] += 1
        elif c == 'L':
            j = y - (x - 1)
            if 1 <= j <= m:
                res[j - 1] += 1
        elif c == 'R':
            j = y + (x - 1)
            if j <= m:
                res[j - 1] += 1

print(' '.join(map(str, res)))
```

### Explanation
- **Reading Input**: The grid dimensions and the grid itself are read from input.
- **Initialization**: An array `res` is initialized to keep track of the number of encounters for each starting column.
- **Iterating Through Grid**: For each row starting from the second row (since the first row has no spiders), check each cell for spiders.
- **Direction Handling**:
  - **Up (U)**: Check if the row index is odd. If so, the spider will be encountered in the same column at the calculated time.
  - **Left (L)**: Calculate the column where the spider will be encountered and update the count if within bounds.
  - **Right (R)**: Similarly, calculate the column and update the count if within bounds.
- **Output**: Print the results for each starting column in the first row.

This approach efficiently computes the encounters by leveraging the movement patterns of spiders and the predictable path of Om Nom, ensuring optimal performance even for large grid sizes.
