### Approach
1. **Catalan Numbers**: The total number of BSTs with `n` nodes is given by the `n`-th Catalan number. This can be computed using dynamic programming.
2. **Count BSTs with Height Constraints**: We need to count the number of BSTs with height less than `h`. This is done using a recursive approach with memoization to avoid redundant calculations.

### Solution Code
```python
import sys
from functools import lru_cache

def catalan(n):
    if n == 0:
        return 1
    c = [0] * (n + 1)
    c[0] = 1
    for i in range(1, n + 1):
        for j in range(i):
            c[i] += c[j] * c[i - j - 1]
    return c[n]

@lru_cache(maxsize=None)
def count_le_height(n, H):
    if n == 0:
        return 1
    if H == 0:
        return 0
    if n == 1:
        return 1
    total = 0
    for k in range(1, n + 1):
        left = count_le_height(k - 1, H - 1)
        right = count_le_height(n - k, H - 1)
        total += left * right
    return total

def main():
    n, h = map(int, sys.stdin.readline().split())
    total = catalan(n)
    required_h = h - 1
    sub = count_le_height(n, required_h)
    print(total - sub)

if __name__ == "__main__":
    main()
```

3. **Main Function**: The main function reads the input values `n` and `h`, computes the total number of BSTs, subtracts the number of BSTs with height less than `h`, and prints the result.
