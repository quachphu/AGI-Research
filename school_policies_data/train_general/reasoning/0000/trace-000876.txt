2. **Intuition**: For each possible shift value (from 0 to L-1), we apply the shift to one sequence and check if the sorted result matches the other sequence. If any shift results in a match, the answer is "YES"; otherwise, it is "NO".

3. **Algorithm**:
   - Read input values.
   - For each possible shift (delta) from 0 to L-1:
     - Apply the shift to each element of Kefa's sequence modulo L.
     - Sort the shifted sequence and compare it with Sasha's sequence.
   - If any shift results in a match, print "YES" and exit. If no match is found after all shifts, print "NO".

### Solution Code
```python
n, L = map(int, input().split())
kefa = list(map(int, input().split()))
sasha = list(map(int, input().split()))

for delta in range(L):
    shifted = [(x + delta) % L for x in kefa]
    shifted_sorted = sorted(shifted)
    if shifted_sorted == sasha:
        print("YES")
        exit()
print("NO")
```
