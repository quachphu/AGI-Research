To solve this problem, we need to determine if three given strings form a word chain based on their first and last characters. Specifically, the last character of the first string must match the first character of the second string, and the last character of the second string must match the first character of the third string.

### Approach
1. **Input Reading**: Read the input line containing three strings separated by spaces.
2. **Check Conditions**:
   - The last character of the first string (A) should be the same as the first character of the second string (B).
   - The last character of the second string (B) should be the same as the first character of the third string (C).
3. **Output Result**: If both conditions are satisfied, print "YES". Otherwise, print "NO".

### Solution Code
```python
def check_word_chain():
    A, B, C = input().split()
    if A[-1] == B[0] and B[-1] == C[0]:
        print("YES")
    else:
        print("NO")

check_word_chain()
```

### Explanation
1. **Reading Input**: The input is read as a single line and split into three strings A, B, and C.
2. **Condition Checks**:
   - `A[-1] == B[0]` checks if the last character of A matches the first character of B.
   - `B[-1] == C[0]` checks if the last character of B matches the first character of C.
3. **Output**: Based on the results of the two checks, the function prints "YES" if both conditions are met, otherwise it prints "NO".

This approach efficiently checks the required conditions in constant time, ensuring the solution is optimal and handles all edge cases within the problem constraints.
