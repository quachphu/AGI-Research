To solve this problem, we need to determine if a given positive integer \( x \) can be expressed as the sum of the cubes of two positive integers. This involves checking each test case efficiently to handle large values up to \( 10^{12} \).

### Approach
1. **Cube Root Limitation**: For a given \( x \), the maximum possible value for the first integer \( a \) is the cube root of \( x \). This is because \( a^3 \) must be less than or equal to \( x \).
2. **Iterative Check**: For each integer \( a \) starting from 1 up to the cube root of \( x \), compute \( a^3 \) and check if the remaining value \( x - a^3 \) is a perfect cube.
3. **Binary Search for Perfect Cube**: To efficiently check if the remaining value is a perfect cube, use binary search within a range derived from the cube root of the remaining value. This ensures we handle large numbers accurately.

### Solution Code
```python
def check(x):
    max_a = int(x ** (1/3)) + 2  # Adding 2 to handle floating point inaccuracies
    for a in range(1, max_a + 1):
        a_cubed = a ** 3
        if a_cubed > x:
            break
        remaining = x - a_cubed
        if remaining < 1:
            continue
        # Binary search to check if remaining is a perfect cube
        low = 1
        high = int(remaining ** (1/3)) + 2
        found = False
        while low <= high:
            mid = (low + high) // 2
            mid_cubed = mid ** 3
            if mid_cubed == remaining:
                found = True
                break
            elif mid_cubed < remaining:
                low = mid + 1
            else:
                high = mid - 1
        if found:
            return True
    return False

t = int(input())
for _ in range(t):
    x = int(input())
    print("YES" if check(x) else "NO")
```

### Explanation
1. **Reading Input**: The number of test cases \( t \) is read first, followed by each test case value \( x \).
2. **Cube Root Calculation**: For each \( x \), the maximum value of \( a \) is determined using the cube root of \( x \), adjusted for floating-point inaccuracies.
3. **Iterating Over Possible Values of \( a \)**: For each \( a \), compute \( a^3 \). If \( a^3 \) exceeds \( x \), break the loop early to save computation time.
4. **Binary Search for Perfect Cube**: For the remaining value after subtracting \( a^3 \) from \( x \), use binary search to check if this remaining value is a perfect cube. This ensures efficient and accurate checking even for very large numbers.

This approach efficiently handles the constraints and ensures that each test case is processed in a time complexity of \( O(\sqrt[3]{x} \cdot \log \sqrt[3]{x}) \), which is feasible given the problem constraints.
