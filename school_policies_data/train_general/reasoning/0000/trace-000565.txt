To solve this problem, we need to compute the difference between two very large integers, A and B, which can be up to 100,000 digits long. Python's inherent ability to handle arbitrarily large integers makes this problem straightforward, as we can directly convert the input strings to integers and perform the subtraction.

### Approach
1. **Reading Input**: The input consists of two integers separated by a space. We will read the input line and split it into two parts.
2. **Conversion to Integers**: Convert the split string parts into Python integers. Python handles large integers natively, so there is no issue with the size of the numbers.
3. **Subtraction**: Compute the difference between the two integers by subtracting the second integer from the first.
4. **Output the Result**: Print the result of the subtraction.

### Solution Code
```python

print(int(a) - int(b))
```

1. **Reading Input**: The `input().split()` method reads the input line and splits it into two parts based on spaces. This handles leading and trailing spaces automatically.
2. **Conversion to Integers**: The `int()` function converts the string representations of the numbers into integers. Python's `int` type can handle very large numbers, so there is no risk of overflow.
3. **Subtraction**: The subtraction operation `int(a) - int(b)` is performed directly using Python's arithmetic capabilities.
4. **Output**: The result of the subtraction is printed, which is the required output.

This approach efficiently handles the problem constraints and edge cases, leveraging Python's ability to manage large integers seamlessly.
