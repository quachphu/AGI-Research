To solve this problem, we need to calculate the sum of all possible XOR values (s) for interesting triples (u, v, s) in an undirected graph. An interesting triple is defined as a pair of nodes (u, v) such that there exists a path between them where the XOR of all edge values along the path equals s. The solution must efficiently handle large graphs with up to 100,000 nodes and 200,000 edges.

### Approach
1. **Graph Traversal**: Use BFS to traverse each connected component of the graph. Track the XOR value from the root node to each node during traversal.
2. **Cycle Basis Detection**: While traversing, detect cycles using back edges. For each cycle, compute the XOR value and maintain a basis for the cycle space using Gaussian elimination over GF(2).
3. **Basis Handling**: Maintain a basis for the cycle space to determine which bits can be varied independently. This basis helps in determining the possible XOR values for paths between nodes.
4. **Contribution Calculation**: For each connected component, calculate the contribution of each bit position to the total sum. This involves considering both fixed bits (determined by the path from the root) and free bits (which can be varied using cycles).

### Solution Code
```python
import sys
from collections import deque

MOD = 10**9 + 7

def main():
    n, m = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n + 1)]  # 1-based indexing
    for _ in range(m):
        u, v, t = map(int, sys.stdin.readline().split())
        adj[u].append((v, t))
        adj[v].append((u, t))
    
    visited = [False] * (n + 1)
    total = 0
    
    for u in range(1, n + 1):
        if not visited[u]:
            component = []
            xor = [0] * (n + 1)
            visited_u = [False] * (n + 1)
            q = deque()
            q.append(u)
            visited_u[u] = True
            visited[u] = True
            component.append(u)
            xor[u] = 0
            parent = {u: None}
            basis = []
            free_bits = [False] * 61
            
            # BFS to compute XOR and find cycles
            while q:
                current = q.popleft()
                for (neigh, t) in adj[current]:
                    if neigh == parent.get(current, None):
                        continue
                    if not visited_u[neigh]:
                        visited_u[neigh] = True
                        visited[neigh] = True
                        parent[neigh] = current
                        xor[neigh] = xor[current] ^ t
                        component.append(neigh)
                        q.append(neigh)
                    else:
                        # Found a back edge, compute cycle_xor
                        cycle_xor = xor[current] ^ t ^ xor[neigh]
                        x = cycle_xor
                        # Add x to the basis using Gaussian elimination
                        while x != 0:
                            highest = x.bit_length() - 1
                            found = False
                            for i in range(len(basis)):
                                if (basis[i] >> highest) & 1:
                                    x ^= basis[i]
                                    found = True
                                    break
                            if not found:
                                # Insert into basis and sort
                                basis.append(x)
                                basis.sort(reverse=True)
                                # Update free_bits
                                for i in range(61):
                                    if (x >> i) & 1:
                                        free_bits[i] = True
                                break
            
            # Recompute free_bits based on final basis
            free_bits = [False] * 61
            for b in basis:
                for i in range(61):
                    if (b >> i) & 1:
                        free_bits[i] = True
            
            # Count 0s and 1s for non-free bits
            count_0 = [0] * 61
            count_1 = [0] * 61
            for node in component:
                x = xor[node]
                for i in range(61):
                    if not free_bits[i]:
                        if (x >> i) & 1:
                            count_1[i] += 1
                        else:
                            count_0[i] += 1
            
            # Calculate contribution for this component
            C = len(component)
            k = len(basis)
            for i in range(61):
                if free_bits[i]:
                    # Contribution is (C choose 2) * 2^{k-1} * 2^i
                    pow_term = pow(2, k - 1 + i, MOD)
                    pairs = (C * (C - 1) // 2) % MOD
                    term = (pairs * pow_term) % MOD
                    total = (total + term) % MOD
                else:
                    # Contribution is count_0[i] * count_1[i] * 2^{k} * 2^i
                    c0 = count_0[i]
                    c1 = count_1[i]
                    pow_term = pow(2, k + i, MOD)
                    term = (c0 * c1) % MOD
                    term = (term * pow_term) % MOD
                    total = (total + term) % MOD
    
    print(total % MOD)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Graph Traversal**: The BFS traversal ensures we visit each node in the connected component, computing the XOR value from the root to each node.
2. **Cycle Detection**: Back edges are used to detect cycles. The XOR value of each cycle is processed to form a basis for the cycle space using Gaussian elimination.
3. **Basis Handling**: The basis vectors are maintained to determine which bits can be varied. This helps in calculating possible XOR values efficiently.
4. **Contribution Calculation**: For each bit position, contributions are calculated based on whether the bit is fixed or free. Fixed bits depend on the path XOR values, while free bits use the cycle basis to determine possible variations.

This approach ensures efficient computation even for large graphs by leveraging properties of XOR and linear algebra over GF(2).
