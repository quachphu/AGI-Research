To solve this problem, we need to compute the sum of all elements of all subsets in the power set of a set S, where S consists of numbers from 1 to N. The solution involves understanding the contribution of each element in the set to the total sum.

### Approach
1. **Understanding Subset Contributions**: Each element from 1 to N appears in exactly half of the subsets of the power set. For a set of size N, each element appears in \(2^{(N-1)}\) subsets.
2. **Sum of Elements**: The sum of all elements from 1 to N can be computed using the formula for the sum of the first N natural numbers: \( \text{sum} = \frac{N(N+1)}{2} \).
3. **Total Contribution**: Each element's total contribution to the sum is the element value multiplied by the number of subsets it appears in. Summing this for all elements gives the total sum, which is \( \text{sum} \times 2^{(N-1)} \).

### Solution Code
```python
def calculate_sum():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for n in map(int, input[1:T+1]):
        total = (n * (n + 1) // 2) * (2 ** (n - 1))
        print(total)

calculate_sum()
```

1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Processing Each Test Case**: For each test case, compute the sum of the first N natural numbers using the formula \( \frac{N(N+1)}{2} \).
3. **Calculating Total Sum**: Multiply the sum of the first N natural numbers by \(2^{(N-1)}\) to account for the number of subsets each element appears in.
4. **Output**: Print the result for each test case.
