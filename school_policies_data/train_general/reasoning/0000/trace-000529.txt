import sys

def compute_total_digits(m):
    total = 0
    d = 1
    while True:
        a = 10 ** (d -1)
        if a > m:
            break
        b = 10**d -1
        actual_b = min(b, m)
        start = m - actual_b +1
        end = m - a +1
        num_terms = actual_b - a +1
        sum_contribution = (start + end) * num_terms // 2
        total += d * sum_contribution
        d +=1
    return total

def compute_sum_s(n):
    sum_s =0
    d =1
    while True:
        a = 10**(d-1)
        if a >n:
            break
        b = 10**d -1
        actual_b = min(b, n)
        count = actual_b - a +1
        sum_s += count *d
        d +=1
    return sum_s

def find_m(k):
    low =1
    high =1
    while compute_total_digits(high) <k:
        high *=2
    while low < high:
        mid = (low + high)//2
        td = compute_total_digits(mid)
        if td <k:
            low = mid +1
        else:
            high = mid
    return low

def find_n(m, k_prime):
    low =1
    high =m
    while low <= high:
        mid = (low +high)//2
        s = compute_sum_s(mid)
        if s <k_prime:
            low = mid +1
        else:
            high = mid -1
    return low

def main():
    import sys
    input = sys.stdin.read().split()
    q = int(input[0])
    for i in range(1, q+1):
        k = int(input[i])
        # Find m
        m = find_m(k)
        # Compute k_prime
        if m ==0:
            k_prime =k
        else:
            prev_total = compute_total_digits(m-1)
            k_prime = k - prev_total
        # Now find n in 1..m
        n = find_n(m, k_prime)
        # Compute sum_s(n-1)
        s_prev = compute_sum_s(n-1)
        pos = k_prime - s_prev -1
        digit = str(n)[pos]
        print(digit)

To solve this problem, we need to determine the k-th digit in an infinite sequence formed by concatenating blocks of consecutive positive integers. Each block i consists of the numbers from 1 to i. Given the constraints, a direct approach of generating the sequence is infeasible, so we use a combination of binary search and mathematical analysis to efficiently determine the required digit.

### Approach

1. **Understanding the Sequence Structure**:
   - The sequence is built by concatenating blocks where each block i contains numbers from 1 to i.
   - Each block contributes a certain number of digits, which can be computed by summing the number of digits of each number in the block.

2. **Efficient Calculation of Digit Counts**:
   - For each block i, compute the total number of digits contributed by the block using the sum of digits of numbers from 1 to i.
   - Use binary search to determine the block that contains the k-th digit by summing the digits contributed by each block up to a certain point.

3. **Finding the Exact Digit**:
   - Once the block is identified, determine the exact position within the block.
   - Use another binary search within the identified block to find the specific number and digit position.

### Solution Code

```python
import sys

def compute_total_digits(m):
    total = 0
    d = 1
    while True:
        a = 10 ** (d - 1)
        if a > m:
            break
        b = 10 ** d - 1
        actual_b = min(b, m)
        start = m - actual_b + 1
        end = m - a + 1
        num_terms = actual_b - a + 1
        sum_contribution = (start + end) * num_terms // 2
        total += d * sum_contribution
        d += 1
    return total

def compute_sum_s(n):
    sum_s = 0
    d = 1
    while True:
        a = 10 ** (d - 1)
        if a > n:
            break
        b = 10 ** d - 1
        actual_b = min(b, n)
        count = actual_b - a + 1
        sum_s += count * d
        d += 1
    return sum_s

def find_m(k):
    low = 1
    high = 1
    while compute_total_digits(high) < k:
        high *= 2
    while low < high:
        mid = (low + high) // 2
        td = compute_total_digits(mid)
        if td < k:
            low = mid + 1
        else:
            high = mid
    return low

def find_n(m, k_prime):
    low = 1
    high = m
    while low <= high:
        mid = (low + high) // 2
        s = compute_sum_s(mid)
        if s < k_prime:
            low = mid + 1
        else:
            high = mid - 1
    return low

def main():
    input = sys.stdin.read().split()
    q = int(input[0])
    for i in range(1, q + 1):
        k = int(input[i])
        m = find_m(k)
        prev_total = compute_total_digits(m - 1) if m != 0 else 0
        k_prime = k - prev_total
        n = find_n(m, k_prime)
        s_prev = compute_sum_s(n - 1) if n != 0 else 0
        pos = k_prime - s_prev - 1
        digit = str(n)[pos]
        print(digit)

if __name__ == "__main__":
    main()
```

### Explanation

1. **compute_total_digits(m)**:
   - Computes the total number of digits contributed by all blocks up to block m using a digit-based approach for efficiency.

2. **compute_sum_s(n)**:
   - Computes the total number of digits in the concatenation of numbers from 1 to n.

3. **find_m(k)**:
   - Uses binary search to find the smallest block m such that the cumulative number of digits up to block m is at least k.

4. **find_n(m, k_prime)**:
   - Uses binary search within the identified block m to find the specific number containing the k-th digit.

5. **main()**:
   - Reads input queries, processes each query to find the required digit using the above functions, and prints the results.

This approach efficiently narrows down the search space using binary search and mathematical analysis, ensuring that even for large values of k (up to 10^9), the solution remains feasible.
