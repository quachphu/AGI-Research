To solve this problem, we need to determine which player from a fixed batting lineup will bat on the K-th ball, considering that each time a player bats, they are duplicated and both copies are added back to the end of the lineup. This creates a sequence where each player's appearances grow exponentially.

### Approach
1. **Initial Setup**: The initial lineup consists of 7 players. Each time a player bats, they are duplicated and both copies are added to the end of the lineup.
2. **Pattern Recognition**: The sequence of batting follows a pattern where each player's appearances double every time they complete a round. This forms a geometric progression.
3. **Mathematical Insight**: For large values of K, we can determine the player by identifying the level of the geometric progression in which K falls. Each level corresponds to a power of 2, and the number of balls in each level grows exponentially.
4. **Efficient Calculation**: Instead of simulating each ball, we use mathematical properties to determine the level and position within that level, allowing us to directly compute the player without iterating through each ball.

### Solution Code
```python
players = ["Rohit", "Dhawan", "Kohli", "Yuvraj", "Raina", "Dhoni", "Sir Jadeja"]

def find_kth_player(K):
    if K <= 7:
        return players[K-1]
    m = 0
    current_sum = 7  # Represents 7*(2^(m+1) - 1) where m starts at 0
    while current_sum < K:
        m += 1
        current_sum = 7 * ((1 << (m + 1)) - 1)
    previous_sum = 7 * ((1 << m) - 1)
    pos_in_level = K - previous_sum - 1
    player_index = pos_in_level // (1 << m)
    return players[player_index]

import sys
def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T+1):
        K = int(input[i])
        print(find_kth_player(K))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input, with the number of test cases followed by each test case value K.
2. **Handling Small K**: For K values up to 7, the result is directly obtained from the initial lineup.
3. **Determining Level**: For larger K values, we determine the level (m) by finding the smallest m such that the cumulative sum of balls up to that level exceeds K.
4. **Position Calculation**: Once the level is determined, we compute the position within that level and map it back to the original player using division by the number of balls per player in that level.

This approach efficiently handles very large values of K by leveraging geometric progression properties, ensuring the solution is computed in logarithmic time relative to K.
