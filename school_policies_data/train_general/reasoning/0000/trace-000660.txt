To solve this problem, we need to determine if Sam is present in a meeting of gangsters and, if he is, how many gangsters are more powerful than him. The solution involves checking for Sam's presence based on his power and counting the number of gangsters with higher power.

### Approach
1. **Input Reading**: Read the number of test cases. For each test case, read the total number of gangsters (including Sam) and Sam's power. Then read the list of powers of all gangsters present.
2. **Check Presence**: Determine if Sam is present by checking if his power exists in the list of gangsters' powers.
3. **Count More Powerful Gangsters**: If Sam is present, count how many gangsters have a power greater than Sam's. If he is not present, the count is zero.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        P = int(input[ptr + 1])
        ptr += 2
        powers = list(map(int, input[ptr:ptr + N]))
        ptr += N
        if P in powers:
            count = sum(1 for x in powers if x > P)
            print(f"YES {count}")
        else:
            print("NO 0")

main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and split into a list for efficient processing. This helps in handling multiple test cases seamlessly.
2. **Check for Sam's Presence**: By checking if Sam's power (P) exists in the list of gangsters' powers, we determine his presence.
3. **Count Calculation**: If Sam is present, we count how many elements in the list are greater than his power using a generator expression for efficiency. If Sam is not present, we directly output "NO 0".

This approach ensures that we efficiently handle the input and compute the required results in linear time relative to the number of gangsters, making the solution both optimal and easy to understand.
