To solve this problem, we need to determine the maximum number of doughnuts Akaki can make, ensuring at least one of each type is made, using the given amount of "Okashi no Moto" (Moto). 

### Approach
1. **Initial Requirement Calculation**: Calculate the minimum amount of Moto required to make one of each type of doughnut. This is the sum of the Moto required for each type.
2. **Remaining Moto Calculation**: Subtract the initial required Moto from the total available Moto to get the remaining Moto that can be used to make additional doughnuts.
3. **Maximize Additional Doughnuts**: Use the remaining Moto to make as many additional doughnuts as possible, focusing on the type that requires the least amount of Moto per doughnut. This is efficient because using the smallest Moto requirement allows for the maximum number of additional doughnuts.

### Solution Code
```python
n, x = map(int, input().split())
m = [int(input()) for _ in range(n)]
sum_m = sum(m)
remaining = x - sum_m
min_m = min(m)
additional = remaining // min_m
print(n + additional)
```

### Explanation
1. **Reading Input**: The first line of input contains the number of doughnut types (N) and the total Moto available (X). The subsequent lines contain the Moto required for each doughnut type.
2. **Sum Calculation**: Compute the sum of Moto required to make one of each doughnut type. This ensures we meet the requirement of making at least one of each type.
3. **Remaining Moto**: Subtract the initial required Moto from the total available Moto to determine how much Moto is left for additional doughnuts.
4. **Determine Efficient Additional Doughnuts**: Find the doughnut type with the smallest Moto requirement. Use all remaining Moto to make as many of this type as possible, which maximizes the total number of additional doughnuts.
5. **Output Result**: The total number of doughnuts is the sum of the initial one per type and the additional doughnuts made from the remaining Moto.

This approach efficiently ensures the maximum number of doughnuts by prioritizing the most economical use of the remaining Moto.
