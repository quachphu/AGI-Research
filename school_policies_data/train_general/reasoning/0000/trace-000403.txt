### Approach
The key insight to solve this problem is to check if the rectangular cutter can fit within the circular cake. The cutter can fit if the diagonal of the rectangle (calculated using the Pythagorean theorem) is less than or equal to the diameter of the cake (which is twice the radius, R). 

- If the diagonal of the rectangle (with dimensions A and B) is greater than the diameter of the cake, the cutter cannot fit, and both Alice and Bob will end up with equal portions (EQUAL).
- If the diagonal of the rectangle is within the diameter, Alice will always make the first cut, and since the problem constraints and optimal play strategy imply that only one optimal cut is possible, Alice will end up with more cake.

### Solution Code
```python
import math
import sys

def determine_winner():
    T = int(sys.stdin.readline())
    for _ in range(T):
        R, A, B = map(int, sys.stdin.readline().split())
        diagonal = math.sqrt(A**2 + B**2)
        if diagonal <= 2 * R:
            print("ALICE")
        else:
            print("EQUAL")

determine_winner()
```

- **Comparison with Diameter**: The diagonal is compared against the diameter of the cake (2 * R).
