To solve this problem, we need to identify the single point that is not on the boundary of an axis-aligned square, given that all other points lie on the boundary. The solution involves determining the square's boundaries and checking each point against these boundaries.

### Approach
1. **Identify Potential Boundaries**: The square's boundaries are determined by the minimum and maximum x and y coordinates from the given points. We consider all possible combinations of these coordinates to form the edges of the square.
2. **Check Each Candidate Square**: For each candidate square, check if the points on its edges meet the required conditions:
   - Each edge (left, right, bottom, top) must have at least `n` points.
   - The total number of distinct points on all edges must be exactly `4n`.
3. **Identify the Outlier**: The point that does not lie on any of the square's edges is the solution.

### Solution Code
```python
n = int(input())
points = [tuple(map(int, input().split())) for _ in range(4 * n + 1)]

xs = sorted(list({x for x, y in points}))
ys = sorted(list({y for x, y in points}))

for a in xs:
    for b in xs:
        if a >= b:
            continue
        side_length = b - a
        for c in ys:
            d = c + side_length
            if d > 50:
                continue
            
            edge_points = set()
            left_count = right_count = bottom_count = top_count = 0
            
            for (x, y) in points:
                on_left = (x == a) and (c <= y <= d)
                on_right = (x == b) and (c <= y <= d)
                on_bottom = (y == c) and (a <= x <= b)
                on_top = (y == d) and (a <= x <= b)
                
                if on_left:
                    left_count += 1
                if on_right:
                    right_count += 1
                if on_bottom:
                    bottom_count += 1
                if on_top:
                    top_count += 1
                
                if on_left or on_right or on_bottom or on_top:
                    edge_points.add((x, y))
            
            if len(edge_points) != 4 * n:
                continue
            
            if (left_count >= n and right_count >= n and
                bottom_count >= n and top_count >= n):
                for (x, y) in points:
                    if (x, y) not in edge_points:
                        print(x, y)
                        exit()
```
