To solve this problem, we need to determine the number of strings \( t \) that maximize the Vasya distance \( \rho(s, t) \) for a given string \( s \). The solution involves understanding the structure of the Vasya distance and leveraging character frequency counts to efficiently compute the result.

### Approach
1. **Character Frequency Count**: First, we count the occurrences of each character ('A', 'C', 'G', 'T') in the given string \( s \).
2. **Determine Maximum Frequency**: Identify the maximum frequency of any character in \( s \).
3. **Count Maximum Frequency Characters**: Count how many characters have this maximum frequency.
4. **Compute Result**: The number of strings \( t \) that maximize the Vasya distance is given by raising the count of maximum frequency characters to the power of \( n \) (the length of \( s \)), modulo \( 10^9 + 7 \).

### Solution Code
```python
MOD = 10**9 + 7

n = int(input())
s = input().strip()

from collections import defaultdict

counts = defaultdict(int)
for c in s:
    counts[c] += 1

max_count = max(counts.values())
k = sum(1 for cnt in counts.values() if cnt == max_count)

print(pow(k, n, MOD))
```

### Explanation
1. **Character Frequency Count**: We use a dictionary to count occurrences of each character in \( s \).
2. **Determine Maximum Frequency**: The maximum value in the frequency dictionary gives the highest occurrence of any character.
3. **Count Maximum Frequency Characters**: We count how many characters have this maximum frequency. This count determines the number of choices we have for each character in the optimal string \( t \).
4. **Compute Result**: Using modular exponentiation, we compute \( k^n \mod (10^9 + 7) \), where \( k \) is the number of characters with maximum frequency. This gives the number of valid strings \( t \) efficiently even for large \( n \).

This approach ensures that we efficiently compute the result using simple loops and modular arithmetic, making it suitable for large input sizes up to \( 10^5 \).
