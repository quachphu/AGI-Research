To solve this problem, we need to maximize the number of rice crackers that can be shipped after an earthquake disrupted the normal baking process. The key is to determine the optimal way to flip rows and columns of the grid to ensure each cracker is baked correctly on both sides.

### Approach
1. **Problem Analysis**: The problem requires flipping rows and columns such that each rice cracker is baked exactly once on both sides. The machine can flip entire rows or columns, and we need to find the optimal combination of these flips to maximize the number of correctly baked crackers.

2. **Key Insight**: For each rice cracker, the total number of flips (from the earthquake and machine operations) must be exactly 1. This translates to ensuring that the sum of row and column flips for each cracker matches its initial state (1 for unflipped, 0 for flipped by the earthquake).

3. **Algorithm**: 
   - Enumerate all possible row flip combinations (using bit masks).
   - For each row flip combination, determine the optimal column flips for each column to maximize the number of correctly baked crackers.
   - For each column, check if all rows agree on the required flip. If they do, use that flip; otherwise, choose the flip that maximizes the correct count for that column.

### Solution Code
```python
import sys

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        R, C = map(int, line.split())
        if R == 0 and C == 0:
            break
        grid = []
        for _ in range(R):
            row = list(map(int, sys.stdin.readline().split()))
            grid.append(row)
        max_total = 0
        for mask in range(0, 1 << R):
            row_flips = [(mask >> i) & 1 for i in range(R)]
            total = 0
            for j in range(C):
                desired_c = None
                possible = True
                for i in range(R):
                    target = (grid[i][j] - row_flips[i]) % 2
                    if i == 0:
                        desired_c = target
                    else:
                        if target != desired_c:
                            possible = False
                            break
                if possible:
                    total += R
                else:
                    count0 = 0
                    count1 = 0
                    for i in range(R):
                        if (row_flips[i] + 0) % 2 == grid[i][j]:
                            count0 += 1
                        if (row_flips[i] + 1) % 2 == grid[i][j]:
                            count1 += 1
                    total += max(count0, count1)
            if total > max_total:
                max_total = total
        print(max_total)

if __name__ == "__main__":
    main()
```
