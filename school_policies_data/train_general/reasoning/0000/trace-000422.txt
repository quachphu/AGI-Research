To solve this problem, we need to determine the minimum number of symbol replacements required to convert a given sequence of '+' and '-' into a valid "Chain" sequence. A valid Chain sequence alternates between '+' and '-', starting with either '+' or '-'. 

### Approach
1. **Problem Analysis**:
   - The sequence must alternate between '+' and '-'.
   - There are two possible valid sequences for any input: one starting with '+' and alternating, and another starting with '-' and alternating.
   - The task is to compute the minimum number of changes needed to convert the input sequence into either of these two valid sequences.

2. **Key Insight**:
   - For each input string, generate the two possible valid sequences (one starting with '+' and the other starting with '-').
   - Compare the input string with both generated sequences and count the number of mismatches for each.
   - The result for each test case is the minimum of these two mismatch counts.

3. **Algorithm**:
   - For each character in the input string, check if it matches the expected character in both possible valid sequences.
   - Count the mismatches for both sequences and return the minimum count.

### Solution Code
```python
import sys

def minimal_replacements(s):
    count_start_plus = 0
    count_start_minus = 0
    for i in range(len(s)):
        expected_plus = '+' if i % 2 == 0 else '-'
        if s[i] != expected_plus:
            count_start_plus += 1
        expected_minus = '-' if i % 2 == 0 else '+'
        if s[i] != expected_minus:
            count_start_minus += 1
    return min(count_start_plus, count_start_minus)

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        s = input[i]
        print(minimal_replacements(s))

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
- **Generating Expected Sequences**:
  - **Starting with '+'**: The sequence alternates starting with '+', so even indices (0, 2, 4, ...) are '+', and odd indices (1, 3, 5, ...) are '-'.
  - **Starting with '-'**: The sequence alternates starting with '-', so even indices are '-', and odd indices are '+'.
- **Counting Mismatches**: For each character in the input string, we check against both expected sequences and count mismatches.
- **Result Calculation**: The minimum of the two mismatch counts is the answer for each test case.

This approach ensures that we efficiently compute the result with a linear pass through the string, making the solution both optimal and easy to understand.
