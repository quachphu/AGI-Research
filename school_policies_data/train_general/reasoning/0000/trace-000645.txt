To solve this problem, we need to determine which suspects are telling the truth, lying, or if their status is undefined based on the given number of truthful statements and the statements made by each suspect. 

### Approach
1. **Parse Input**: Read the number of suspects and the number of truthful statements, followed by each suspect's statement.
2. **Preprocess Statements**: Track the number of times each suspect is accused by others and the number of times each suspect is defended by others.
3. **Identify Candidates**: Determine which suspects could be the criminal such that exactly the given number of truthful statements are made.
4. **Determine Truthfulness**: For each suspect's statement, check if it must be true, false, or if it's undefined based on the possible criminals.

### Solution Code
```python
n, m = map(int, input().split())

statements = []
count_plus = [0] * (n + 1)
count_minus_a = [0] * (n + 1)
total_minus = 0

for _ in range(n):
    s = input().strip()
    type_ = s[0]
    a = int(s[1:])
    statements.append((type_, a))
    if type_ == '+':
        count_plus[a] += 1
    else:
        count_minus_a[a] += 1
        total_minus += 1

candidates = set()
for x in range(1, n + 1):
    truthful = count_plus[x] + (total_minus - count_minus_a[x])
    if truthful == m:
        candidates.add(x)

for type_, a in statements:
    if type_ == '+':
        if a in candidates:
            if len(candidates) == 1:
                print("Truth")
            else:
                print("Not defined")
        else:
            print("Lie")
    else:
        if a not in candidates:
            print("Truth")
        else:
            if len(candidates) == 1:
                print("Lie")
            else:
                print("Not defined")
```

### Explanation
1. **Input Parsing**: The input is read and parsed into the number of suspects and the number of truthful statements. Each suspect's statement is stored along with whether they accused or defended another suspect.
2. **Preprocessing**: Arrays `count_plus` and `count_minus_a` are used to track how many times each suspect is accused or defended. `total_minus` counts the total number of defensive statements.
3. **Candidate Identification**: For each suspect, we calculate the number of truthful statements if they were the criminal. If this number matches the given number of truthful statements, the suspect is added to the list of candidates.
4. **Determine Truthfulness**: For each statement, we check if the accused or defended suspect is in the list of candidates. Based on the presence and number of candidates, we determine if the statement must be true, false, or is undefined.

This approach efficiently narrows down possible criminals and evaluates each statement's validity, ensuring optimal performance even for large inputs.
