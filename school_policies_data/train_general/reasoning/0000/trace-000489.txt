The key insight is that the graph's edges correspond to inversion pairs in the input permutation. The maximum independent set in this graph is equivalent to the length of the longest non-decreasing subsequence (LNDS) of the input permutation.

### Approach
1. **Understanding the Graph Construction**: The graph is built by adding edges between elements that are swapped during Bubble Sort. Each swap corresponds to an inversion in the input permutation.
2. **Independent Set and LNDS**: The maximum independent set in this graph is a set of vertices where no two elements are adjacent. This translates to finding the longest subsequence of elements that are non-decreasing, as such a subsequence avoids inversions.
3. **Efficient Calculation of LNDS**: Using a method similar to the one used for finding the Longest Increasing Subsequence (LIS), we can efficiently compute the LNDS in O(n log n) time using binary search.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    
    tails = []
    for x in a:
        idx = bisect.bisect_right(tails, x)
        if idx == len(tails):
            tails.append(x)
        else:
            tails[idx] = x
    print(len(tails))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input, which includes the number of elements and the permutation itself.
2. **Tracking the Longest Non-Decreasing Subsequence**: Using a list `tails`, we maintain the smallest possible tail values for all increasing subsequences encountered. For each element in the permutation, we determine its position in `tails` using binary search (bisect_right), ensuring the list remains sorted.
3. **Updating the List**: If the current element can extend the longest subsequence, it is appended. Otherwise, it replaces the first element in `tails` that is larger than the current element, maintaining the smallest possible tail values for future elements.

This approach efficiently computes the length of the longest non-decreasing subsequence, which directly gives the size of the maximum independent set in the constructed graph.
