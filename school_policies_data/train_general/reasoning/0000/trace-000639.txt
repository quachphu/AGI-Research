To solve this problem, we need to find the shortest dominated subarray in a given array. A dominated subarray is defined as a contiguous part of the array where one value occurs more frequently than any other value. The solution involves checking for adjacent duplicates and tracking the minimal distance between consecutive occurrences of each element.

### Approach
1. **Check for Adjacent Duplicates**: If any two consecutive elements in the array are the same, the shortest dominated subarray is of length 2.
2. **Track Consecutive Occurrences**: If no adjacent duplicates are found, track the indices of each element's occurrences. For each element, compute the minimal distance between consecutive occurrences and determine the shortest subarray length where the element dominates.

### Solution Code
```python
import sys

def solve():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        n = int(input[ptr])
        ptr += 1
        a = list(map(int, input[ptr:ptr+n]))
        ptr += n
        
        # Check for adjacent duplicates
        found = False
        for i in range(n - 1):
            if a[i] == a[i + 1]:
                found = True
                break
        if found:
            print(2)
            continue
        
        # Track previous occurrences and find minimal distance
        prev_indices = {}
        min_length = float('inf')
        for i in range(n):
            num = a[i]
            if num in prev_indices:
                current_diff = i - prev_indices[num]
                candidate = current_diff + 1
                if candidate < min_length:
                    min_length = candidate
                # Update previous index to current for next comparisons
                prev_indices[num] = i
            else:
                prev_indices[num] = i
        
        print(min_length if min_length != float('inf') else -1)

solve()
```

### Explanation
1. **Adjacent Duplicates Check**: The code first checks if there are any adjacent elements that are the same. If found, the shortest dominated subarray is immediately determined to be 2.
2. **Tracking Occurrences**: For each element, the code tracks the last occurrence index. For subsequent occurrences, it calculates the distance from the previous occurrence and updates the minimal subarray length required for the element to dominate.
3. **Result Determination**: If no valid subarray is found (all elements are unique), the result is -1. Otherwise, the minimal length of the dominated subarray is printed.

This approach efficiently handles the problem constraints and ensures optimal performance by leveraging linear traversal and dictionary-based tracking of element indices.
