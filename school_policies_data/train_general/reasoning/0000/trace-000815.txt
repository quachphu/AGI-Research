To solve this problem, we need to determine the minimum number of days Polycarp requires to save enough money to buy a new computer. Polycarp can either work in his current position to earn money or spend money to move to a higher position, which offers a higher daily wage. The goal is to find the optimal balance between earning money and moving to higher positions to minimize the total days needed.

### Approach
1. **Initialization**: Start from the first position with zero money and track the number of days and accumulated money.
2. **Earning Calculation**: For each position, calculate the minimum days required to accumulate the needed amount if Polycarp stops at that position.
3. **Upgrading Positions**: If possible, calculate the days required to move to the next higher position. This involves working enough days to afford the upgrade cost and then spending a day to move.
4. **Optimal Check**: For each position, compute the total days required if Polycarp stops there and updates the minimum days accordingly.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n, c = int(input[ptr]), int(input[ptr+1])
        ptr += 2
        a = list(map(int, input[ptr:ptr+n]))
        ptr += n
        b = list(map(int, input[ptr:ptr+n-1]))
        ptr += n-1
        
        current_days = 0
        current_money = 0
        best = float('inf')
        
        for i in range(n):
            # Calculate days needed if staying at current position (i+1)
            required = max(0, c - current_money)
            if required == 0:
                days_needed = current_days
            else:
                days_needed = current_days + (required + a[i] - 1) // a[i]
            if days_needed < best:
                best = days_needed
            
            # Check if can move to next position
            if i < n - 1:
                needed = b[i] - current_money
                if needed <= 0:
                    current_days += 1
                    current_money -= b[i]
                else:
                    k = (needed + a[i] - 1) // a[i]
                    current_days += k + 1
                    current_money += k * a[i] - b[i]
        
        print(best)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Loop Through Test Cases**: Each test case is processed individually.
3. **Iterate Through Positions**: For each position, compute the days required to accumulate the needed money if Polycarp stops there.
4. **Check for Upgrades**: If moving to the next position is feasible, compute the days required to earn the necessary upgrade cost and update the current days and money accordingly.
5. **Update Minimum Days**: Track the minimum days required across all possible stopping positions.

This approach ensures that we efficiently explore all possible paths, balancing between earning money in the current position and upgrading to higher positions to leverage higher wages, thus minimizing the total days required.
