To solve this problem, we need to count the number of amazing performances by a coder in a series of contests. An amazing performance is defined as either breaking the previous highest score or the previous lowest score in the contests participated in so far.

### Approach
1. **Initialization**: Start by reading the number of contests and the points scored in each contest.
2. **Edge Case Handling**: If there is only one contest, there are no previous contests to compare with, so the result is zero.
3. **Tracking Records**: For each contest starting from the second one, check if the current score breaks the previous highest or lowest score.
4. **Update Records**: If a new highest or lowest score is encountered, update the respective record and increment the count of amazing performances.
5. **Output Result**: Print the total count of amazing performances after processing all contests.

### Solution Code
```python
def count_amazing_performances():
    import sys
    n = int(sys.stdin.readline())
    points = list(map(int, sys.stdin.readline().split()))
    if n <= 1:
        print(0)
        return
    current_max = points[0]
    current_min = points[0]
    count = 0
    for num in points[1:]:
        if num > current_max:
            count += 1
            current_max = num
        elif num < current_min:
            count += 1
            current_min = num
    print(count)

count_amazing_performances()
```

### Explanation
1. **Reading Input**: The input is read from standard input, where the first line is the number of contests `n`, and the second line contains the scores in chronological order.
2. **Edge Case Handling**: If there is only one contest, immediately return 0 as there are no previous scores to compare with.
3. **Tracking Records**: Initialize `current_max` and `current_min` with the score from the first contest. For each subsequent score, check if it is strictly greater than `current_max` or strictly less than `current_min`.
4. **Updating Records**: Each time a new maximum or minimum score is found, update the respective record and increment the count of amazing performances.
5. **Output**: After processing all scores, the total count of amazing performances is printed.

This approach efficiently tracks the highest and lowest scores encountered so far in a single pass through the list of scores, resulting in a time complexity of O(n), which is optimal for the given constraints.
