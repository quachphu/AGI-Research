To solve this problem, we need to determine the number of contiguous subarrays of a given array that can be divided into exactly `k` groups such that the product of any pair of integers in the same group is a perfect square. The solution involves preprocessing each element to determine its square-free part and then efficiently counting the valid subarrays for each possible `k`.

### Approach
1. **Square-Free Part Calculation**: For each element in the array, compute its square-free part. This involves removing all square factors from the element, considering both the magnitude and the sign.
2. **Track Zero Elements**: Identify elements that are zero, as they can be grouped with any other elements provided all non-zero elements in the group have the same square-free part.
3. **Sliding Window Technique**: For each starting index of a subarray, expand the window to the right while maintaining a count of distinct square-free parts and checking for the presence of zeros. This allows us to efficiently determine the number of groups required for each subarray.
