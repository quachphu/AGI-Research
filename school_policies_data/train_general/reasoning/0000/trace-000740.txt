To solve this problem, we need to determine the amount Mrs. Verma will get by selling her car to the Kth lowest bidder. The solution involves sorting the list of bids and selecting the appropriate bid based on the sorted order.

### Approach
1. **Read Input**: First, we read the input values which include the number of bidders (N) and the position (K) of the bidder we are interested in. Following this, we read the list of bids.
2. **Sort Bids**: The next step is to sort the list of bids in ascending order. This allows us to easily determine the Kth lowest bid by accessing the (K-1)th element in the sorted list (since list indices in Python are zero-based).
3. **Output Result**: Finally, we print the value of the Kth lowest bid from the sorted list.

### Solution Code
```python
def main():
    n, k = map(int, input().split())
    bids = list(map(int, input().split()))
    bids.sort()
    print(bids[k-1])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The first line of input is split into two integers, N and K. The second line is split into a list of integers representing the bids.
2. **Sorting Bids**: The list of bids is sorted in ascending order. Sorting ensures that the smallest bid is first and the largest is last, making it easy to find the Kth lowest bid.
3. **Selecting the Kth Lowest Bid**: By accessing the (K-1)th element in the sorted list (due to zero-based indexing), we directly obtain the Kth lowest bid, which is then printed as the result.

This approach efficiently handles the problem constraints and ensures the correct result is obtained with minimal computational overhead. The sorting operation has a time complexity of O(N log N), which is efficient for the given constraint limits (N ≤ 1000).
