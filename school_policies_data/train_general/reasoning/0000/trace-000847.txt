To solve this problem, we need to determine the combination of weights to place on the right plate of a balance scale such that it balances with a given weight on the left plate. The weights available are powers of two, from 1 gram to 512 grams. The solution involves converting the given weight into its binary representation to identify which weights to use.

### Approach
1. **Binary Representation Insight**: Each weight is a power of two, which means each weight corresponds to a bit in the binary representation of the given number. For example, the number 5 in binary is `101`, which corresponds to the weights 1 gram (2^0) and 4 grams (2^2).

2. **Iterate Through Powers of Two**: For each weight from 1 gram (2^0) up to 512 grams (2^9), check if the bit corresponding to that weight is set in the binary representation of the given number. If it is, include that weight in the result.

3. **Output in Ascending Order**: Since we check the weights starting from the smallest (1 gram) to the largest (512 grams), the collected weights will naturally be in ascending order.

### Solution Code
```python
def main():
    import sys
    for line in sys.stdin:
        n = int(line.strip())
        weights = []
        for i in range(10):
            w = 2 ** i
            if n & w:
                weights.append(str(w))
        print(' '.join(weights))

main()
```

### Explanation
1. **Reading Input**: The code reads multiple lines of input until the end of the file is reached. Each line represents a different weight to be balanced.

2. **Binary Check**: For each weight value from 1 (2^0) to 512 (2^9), the code checks if the corresponding bit in the binary representation of the input number is set using a bitwise AND operation (`n & w`). If the result is non-zero, that weight is included in the result list.

3. **Output**: The collected weights are joined into a string separated by spaces and printed. This ensures the weights are listed in ascending order, from the lightest to the heaviest.

This approach efficiently determines the correct weights using bitwise operations, ensuring optimal performance and correctness.
