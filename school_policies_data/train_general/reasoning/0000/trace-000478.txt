To solve this problem, we need to determine if Bob's answer to Alice's problem is correct. The task is to shuffle the digits of a given number `n` to form the smallest possible number without leading zeros and check if Bob's answer matches this number.

### Approach
1. **Input Handling**: Read the input values `n` and `m` as strings to preserve leading zeros in `m`.
2. **Edge Case Handling**: If `n` is "0", the correct answer must be "0".
3. **Digit Sorting and Rearrangement**:
   - Convert the digits of `n` into a list and sort them in ascending order.
   - Find the first non-zero digit in the sorted list and swap it with the first position to avoid leading zeros.
   - The remaining digits are already sorted, so combining them will give the smallest possible number.
4. **Comparison**: Compare the generated smallest number with Bob's answer (`m`) to determine if it is correct.

### Solution Code
```python
n = input().strip()
m = input().strip()

if n == '0':
    correct = '0'
else:
    digits = sorted(n)
    # Find the first non-zero digit
    first_non_zero = next(i for i, d in enumerate(digits) if d != '0')
    # Swap with the first position
    digits[0], digits[first_non_zero] = digits[first_non_zero], digits[0]
    correct = ''.join(digits)

print("OK" if m == correct else "WRONG_ANSWER")
```

### Explanation
1. **Reading Input**: The input values are read as strings to handle `m` correctly, which may contain leading zeros.
2. **Edge Case for Zero**: If `n` is "0", the correct answer is immediately "0".
3. **Sorting Digits**: The digits of `n` are sorted to form the smallest possible number. However, leading zeros are not allowed, so the first non-zero digit is identified and moved to the front.
4. **Generating Correct Answer**: After rearranging the digits, the correct smallest number is formed and compared with Bob's answer. If they match, the result is "OK"; otherwise, it is "WRONG_ANSWER".

This approach ensures that the smallest possible number is generated efficiently and correctly, adhering to the constraints and requirements of the problem.
