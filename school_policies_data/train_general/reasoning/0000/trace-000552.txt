To solve this problem, we need to determine the number of times a specific character appears in a given string for multiple test cases. The solution involves reading input, parsing each test case, and counting the occurrences of the specified character in the string.

### Approach
1. **Input Reading**: Read the number of test cases, T.
2. **Parsing Each Test Case**: For each test case, read the line containing the string and the character. Split the line into parts where the last part is the character and the remaining parts form the string.
3. **Count Occurrences**: Use the string's `count` method to determine how many times the character appears in the string.
4. **Output the Result**: Print the count for each test case.

### Solution Code
```python
def main():
    import sys
    t = int(sys.stdin.readline())
    for _ in range(t):
        line = sys.stdin.readline().strip()
        parts = line.split()
        c = parts[-1]
        s = ' '.join(parts[:-1])
        print(s.count(c))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The number of test cases, T, is read first. Each subsequent line contains a string and a character separated by spaces.
2. **Splitting the Line**: Each line is split into parts using the `split()` method. The last element of the split result is the character to count, while the rest form the string. This handles cases where the string might contain spaces by rejoining the parts except the last one.
3. **Counting Characters**: The `count` method of the string is used to efficiently count occurrences of the specified character.
4. **Output**: The result for each test case is printed immediately after processing.

This approach ensures that each test case is processed efficiently and correctly, adhering to the problem constraints and requirements.
