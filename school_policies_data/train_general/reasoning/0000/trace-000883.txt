To solve this problem, we need to find the smallest triangular number that has more divisors than a given number \( n \). A triangular number is formed by the sum of the first \( k \) natural numbers, and the \( k \)-th triangular number can be represented as \( T_k = \frac{k(k+1)}{2} \).

### Approach
1. **Triangular Number Generation**: Generate triangular numbers sequentially starting from \( k = 1 \).
2. **Divisors Calculation**: For each triangular number, split it into two coprime factors. This split depends on whether \( k \) is even or odd:
   - If \( k \) is even, the triangular number \( T_k \) can be split into \( \frac{k}{2} \) and \( k+1 \).
   - If \( k \) is odd, the triangular number \( T_k \) can be split into \( k \) and \( \frac{k+1}{2} \).
3. **Divisors Count**: Calculate the number of divisors for each of the two factors. The product of the divisors count of these two factors gives the total number of divisors for the triangular number.
4. **Comparison**: Check if the total number of divisors exceeds \( n \). If it does, this triangular number is the answer.

### Solution Code
```python
import math
from functools import lru_cache

@lru_cache(maxsize=None)
def count_divisors(x):
    if x == 0:
        return 0
    cnt = 0
    sqrt_x = int(math.sqrt(x))
    for i in range(1, sqrt_x + 1):
        if x % i == 0:
            if i * i == x:
                cnt += 1
            else:
                cnt += 2
    return cnt

def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    cases = list(map(int, input[1:T+1]))
    for n in cases:
        k = 1
        while True:
            if k % 2 == 0:
                a = k // 2
                b = k + 1
            else:
                a = k
                b = (k + 1) // 2
            d_a = count_divisors(a)
            d_b = count_divisors(b)
            if d_a * d_b > n:
                print(a * b)
                break
            else:
                k += 1

if __name__ == "__main__":
    main()
```

### Explanation
- **Divisors Calculation**: The function `count_divisors` uses trial division up to the square root of a number to efficiently count its divisors. This method is optimized using memoization to cache results and avoid redundant calculations.
- **Triangular Number Splitting**: By splitting the triangular number into two coprime factors, we leverage the property that the product of the divisors of coprime numbers gives the total number of divisors of their product.
- **Efficiency**: The algorithm sequentially checks each triangular number until the required condition is met. Memoization ensures that divisor counts for numbers encountered in previous iterations are reused, significantly speeding up the process.

This approach ensures that we efficiently find the smallest triangular number with more divisors than \( n \) for each test case.
