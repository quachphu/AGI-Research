To solve this problem, we need to find the longest subsequence from a given sequence such that the absolute difference between any two adjacent elements in the subsequence is at most K. The solution involves using a segment tree to efficiently compute the maximum length of such a subsequence.

### Approach
1. **Dynamic Programming with Segment Tree**: We use dynamic programming (DP) where `dp[i]` represents the maximum length of a valid subsequence ending at element `A[i]`. For each element `A[i]`, we need to find the maximum length of subsequences ending at previous elements that are within the range `[A[i] - K, A[i] + K]`. This range query and update operation can be efficiently handled using a segment tree.

2. **Segment Tree for Range Queries**: The segment tree is used to maintain the maximum length of valid subsequences ending at each possible value. For each element `A[i]`, we query the segment tree to find the maximum value in the range `[A[i] - K, A[i] + K]`, then update the segment tree with the new value at `A[i]`.

3. **Efficient Updates and Queries**: The segment tree allows us to perform both range maximum queries and point updates in logarithmic time, making the solution efficient even for large input sizes.

### Solution Code
```python
import sys

class SegmentTree:
    def __init__(self, max_val):
        self.n = 1
        while self.n < max_val + 1:
            self.n <<= 1
        self.tree = [0] * (2 * self.n)
    
    def update(self, idx, value):
        idx += self.n
        if self.tree[idx] >= value:
            return
        self.tree[idx] = value
        while idx > 1:
            idx >>= 1
            new_val = max(self.tree[idx * 2], self.tree[idx * 2 + 1])
            if self.tree[idx] == new_val:
                break
            self.tree[idx] = new_val
    
    def query(self, l, r):
        res = 0
        l += self.n
        r += self.n
        while l <= r:
            if l % 2 == 1:
                res = max(res, self.tree[l])
                l += 1
            if r % 2 == 0:
                res = max(res, self.tree[r])
                r -= 1
            l >>= 1
            r >>= 1
        return res

def main():
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    K = int(input[ptr])
    ptr += 1
    A = []
    for _ in range(N):
        A.append(int(input[ptr]))
        ptr += 1
    max_x = 600000  # Since K and A_i can each be up to 3e5, x+K can be up to 6e5
    st = SegmentTree(max_x)
    max_len = 0
    for x in A:
        low = max(0, x - K)
        high = x + K
        current_max = st.query(low, high)
        new_val = current_max + 1
        if new_val > max_len:
            max_len = new_val
        st.update(x, new_val)
    print(max_len)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input, parsed into integers for N (number of elements), K (maximum allowed difference), and the sequence A.

2. **Segment Tree Initialization**: The segment tree is initialized to handle values up to 600,000, which is the maximum possible value after considering the constraints (3e5 for elements and 3e5 for K).

3. **Processing Each Element**: For each element in the sequence, compute the valid range `[A[i] - K, A[i] + K]`, query the segment tree for the maximum subsequence length in this range, update the current element's subsequence length, and update the segment tree.

4. **Updating Result**: Track the maximum length of valid subsequences found during the process and print it as the result.

This approach efficiently handles the constraints using a segment tree, ensuring logarithmic time complexity for both updates and queries, leading to an overall time complexity of O(N log M), where M is the maximum possible value in the range.
