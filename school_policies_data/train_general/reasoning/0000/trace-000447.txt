To solve this problem, we need to find the maximum possible proper irreducible fraction such that the sum of its numerator and denominator equals a given integer \( n \). A proper fraction has a numerator smaller than its denominator, and an irreducible fraction means the numerator and denominator are coprime (their greatest common divisor is 1).

### Approach
1. **Understanding the Problem**: We need to maximize the fraction \( \frac{a}{b} \) where \( a + b = n \), \( a < b \), and \( \text{gcd}(a, b) = 1 \).
2. **Maximizing the Fraction**: The fraction \( \frac{a}{b} \) is maximized when \( a \) is as large as possible. Given \( a < b \) and \( a + b = n \), the largest possible \( a \) is \( \lfloor \frac{n-1}{2} \rfloor \).
3. **Iterative Check**: Starting from the largest possible \( a \), check each value downwards until we find an \( a \) such that \( a \) and \( b = n - a \) are coprime.

### Solution Code
```python
import math

n = int(input())
for a in range((n - 1) // 2, 0, -1):
    b = n - a
    if math.gcd(a, b) == 1:
        print(a, b)
        break
```

### Explanation
1. **Reading Input**: The input integer \( n \) is read.
2. **Iterating Over Possible Numerators**: We iterate from the largest possible \( a \) (i.e., \( \lfloor \frac{n-1}{2} \rfloor \)) down to 1.
3. **Checking Coprimality**: For each \( a \), compute \( b = n - a \) and check if \( \text{gcd}(a, b) = 1 \). The first valid pair encountered (starting from the largest \( a \)) is printed and the loop exits.

This approach ensures that we efficiently find the maximum possible proper irreducible fraction by leveraging the properties of coprime numbers and the constraints given. The use of the greatest common divisor (gcd) check ensures the fraction is irreducible, while iterating from the largest possible \( a \) ensures the fraction is maximized.
