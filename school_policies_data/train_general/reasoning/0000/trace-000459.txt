To solve this problem, we need to determine how many mountain inns allow you to see the ocean. The visibility from each inn is determined by the heights of the mountains relative to each other from west to east.

### Approach
1. **Understanding Visibility**: The westernmost mountain (first mountain) always allows visibility to the ocean. For subsequent mountains, an inn can see the ocean if and only if it is taller than all previous mountains from west to east.
2. **Tracking Maximum Height**: As we iterate through the list of mountain heights from west to east, we keep track of the maximum height encountered so far. Each time we encounter a mountain that is taller than or equal to the current maximum height, it means this mountain can see the ocean, and we update our maximum height to this new value.
3. **Iterative Check**: Starting from the second mountain, we check each mountain's height against the current maximum. If it meets the condition, we increment our count of visible inns.

### Solution Code
```python
def main():
    n = int(input())
    h_list = list(map(int, input().split()))
    count = 1
    current_max = h_list[0]
    for i in range(1, n):
        if h_list[i] >= current_max:
            count += 1
            current_max = h_list[i]
    print(count)

main()
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` (number of mountains) followed by a list of integers representing the heights of the mountains from west to east.
2. **Initialization**: We start by assuming the first mountain can always see the ocean, so we initialize our count to 1 and set the current maximum height to the height of the first mountain.
3. **Iterate Through Heights**: For each subsequent mountain (from the second to the nth), we check if its height is greater than or equal to the current maximum height. If it is, we increment our count and update the current maximum height to this mountain's height.
4. **Output Result**: Finally, we print the count of mountains from which the ocean is visible.

This approach efficiently checks each mountain in a single pass, ensuring an optimal time complexity of O(n), where n is the number of mountains. This is efficient given the problem constraints (n ≤ 20).
