To solve this problem, we need to determine the maximum number of candies that can be collected when traveling from the top-left corner to the bottom-right corner of a 2xN grid, moving only right or down. The key insight is that the optimal path will involve moving right in the top row, then down once, and then moving right in the bottom row. The challenge is to find the column where switching from the top row to the bottom row maximizes the total candies collected.

### Approach
1. **Prefix Sum Calculation**: Compute the cumulative sum of candies collected as we move right in the top row up to each column.
2. **Suffix Sum Calculation**: Compute the cumulative sum of candies collected from each column to the end in the bottom row.
3. **Maximize Total Candies**: For each possible column where we switch from the top row to the bottom row, calculate the total candies collected by combining the prefix sum up to that column in the top row and the suffix sum from that column in the bottom row. Track the maximum value obtained from these combinations.

### Solution Code
```python
n = int(input())
a1 = list(map(int, input().split()))
a2 = list(map(int, input().split()))

prefix1 = [0] * (n + 1)
for j in range(1, n + 1):
    prefix1[j] = prefix1[j - 1] + a1[j - 1]

suffix_sum = [0] * n
suffix_sum[-1] = a2[-1]
for i in range(n - 2, -1, -1):
    suffix_sum[i] = a2[i] + suffix_sum[i + 1]

max_candies = 0
for j in range(1, n + 1):
    current = prefix1[j] + suffix_sum[j - 1]
    if current > max_candies:
        max_candies = current

print(max_candies)
```

### Explanation
1. **Reading Input**: The input consists of the grid size `n`, followed by two rows of integers representing the candies in each cell.
2. **Prefix Sum Array**: The `prefix1` array stores the cumulative sum of candies collected in the top row up to each column. This helps in quickly determining the total candies collected if we switch to the bottom row at any given column.
3. **Suffix Sum Array**: The `suffix_sum` array stores the cumulative sum of candies collected from each column to the end in the bottom row. This helps in determining the total candies collected from the switch column to the end of the grid in the bottom row.
4. **Combining Prefix and Suffix Sums**: For each possible switch column, compute the total candies collected by summing the corresponding prefix and suffix values. Track the maximum value encountered during this process.

This approach efficiently computes the maximum candies using prefix and suffix sums, ensuring an optimal solution with a time complexity of O(N), which is well-suited for the problem constraints.
