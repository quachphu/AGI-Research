To solve this problem, we need to determine how many days Ivan will take to read a book where each page introduces a mystery that is explained on a later page. Ivan reads consecutively from the first unread page each day and stops when all mysteries introduced in the pages he read that day are explained within those same pages.

### Approach
1. **Initialization**: Start from the first page and initialize the count of days.
2. **Daily Reading**: For each day, determine the range of pages Ivan will read:
   - Begin from the first unread page.
   - Expand the range until the maximum page number that explains any mystery in the current range is reached.
3. **Update Next Start**: After determining the range for the day, update the start page for the next day to the page immediately following the last page read on the current day.
4. **Repeat**: Continue the process until all pages are read.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
a = [0] + a  # Convert to 1-based indexing
days = 0
start = 1

while start <= n:
    days += 1
    current_max = a[start]
    end = start
    while end < current_max:
        end += 1
        if a[end] > current_max:
            current_max = a[end]
    start = end + 1

print(days)
```

### Explanation
- **Initialization**: Convert the input list to 1-based indexing for easier page number management.
- **Daily Reading Loop**: For each day, start from the first unread page (`start`). Track the maximum page number needed to explain all mysteries introduced from `start` to the current end (`end`). Expand `end` until it reaches this maximum page number.
- **Update Start**: Once the end of the day's reading is determined, set the next starting page to `end + 1`.
- **Efficiency**: Each page is processed exactly once, leading to an O(n) time complexity, which is efficient even for the upper constraint of \( n = 10^4 \).

This approach ensures that Ivan reads the minimum number of pages each day while meeting the condition that all mysteries introduced on a given day are explained by the end of that day.
