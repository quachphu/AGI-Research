To solve this problem, we need to determine the number of integers between 1 and a given integer \( n \) that have exactly four positive divisors. These integers can be of two forms: either the cube of a prime number (e.g., \( p^3 \)) or the product of two distinct prime numbers (e.g., \( p \times q \)). 

### Approach
1. **Cube of Prime Numbers**: For a number to have exactly four divisors and be a cube of a prime \( p \), \( p^3 \) must be less than or equal to \( n \). We generate all primes up to the cube root of \( n \) and check this condition.
2. **Product of Two Distinct Primes**: For a number to be the product of two distinct primes \( p \) and \( q \) (where \( p < q \)), \( p \times q \) must be less than or equal to \( n \). We generate all primes up to the square root of \( n \) and count valid pairs \( (p, q) \) using prime counting functions.

### Solution Code
```python
import sympy

def D(n):
    if n < 6:
        return 0
    # Calculate the cube part
    cube_count = 0
    cube_root = int(n ** (1/3)) + 1
    cube_primes = list(sympy.sieve.primerange(1, cube_root + 1))
    for p in cube_primes:
        if p ** 3 <= n:
            cube_count += 1
        else:
            break  # Since primes are in order, we can break early
    
    # Calculate the product part
    product_count = 0
    sqrt_n = int(n ** 0.5)
    primes = list(sympy.sieve.primerange(1, sqrt_n + 1))
    for p in primes:
        max_q = n // p
        if max_q <= p:
            continue  # q must be > p
        # Compute the number of primes q where p < q <= max_q
        count = sympy.primepi(max_q) - sympy.primepi(p)
        product_count += count
    
    return cube_count + product_count

n = int(input())
```
