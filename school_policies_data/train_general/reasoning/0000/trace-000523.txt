To solve this problem, we need to determine the number of user submissions from students of Graphic Era University on the Nth day following the formation of the GEU_Coders chapter. The sequence of submissions follows a specific pattern, and we need an iterative approach to compute the value efficiently.

### Approach
The sequence of submissions is given as 2, 3, 7, 13, 27, 53, 107, etc. Observing the pattern, we notice that each term is derived from the previous term based on whether the current day index (N) is even or odd:
- If the day index (N) is even, the number of submissions is calculated as `previous * 2 - 1`.
- If the day index (N) is odd, the number of submissions is calculated as `previous * 2 + 1`.

Using this observation, we can iteratively compute the number of submissions for any given day starting from day 1 up to the required day N.

### Solution Code
```python
def compute_submissions():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    cases = list(map(int, input[1:t+1]))
    for n in cases:
        if n == 1:
            print(2)
            continue
        current = 2
        for i in range(2, n + 1):
            if i % 2 == 0:
                current = current * 2 - 1
            else:
                current = current * 2 + 1
        print(current)

compute_submissions()
```

### Explanation
1. **Reading Input:** The input is read all at once for efficiency, especially given the constraints. The first value is the number of test cases, followed by the respective day indices for each test case.
2. **Edge Case Handling:** If the day index (N) is 1, the result is directly 2 as given in the problem statement.
3. **Iterative Calculation:** For each day from 2 to N, we determine the number of submissions based on whether the current day index is even or odd. This is done using a loop that updates the current value according to the derived formula.
4. **Output:** After computing the value for the given day index, the result is printed immediately.

This approach ensures that we efficiently compute the required values using an iterative method, adhering to the problem constraints and requirements.
