To solve this problem, we need to split a given multiset of integers into two subsets such that the sum of their minimum excluded values (mex) is maximized. The mex of a set is the smallest non-negative integer not present in the set. 

### Approach
1. **Understanding mex**: The mex of a set is determined by the smallest non-negative integer not present. For example, mex of {0, 1, 2} is 3, and mex of an empty set is 0.
2. **Splitting Strategy**: The goal is to split the given set into two subsets A and B such that the sum of their mex values is maximized. This requires ensuring that each subset contains the necessary elements to achieve the highest possible mex.
3. **Frequency Analysis**: For each number in the input set, count its occurrences. This helps determine how to distribute elements between subsets A and B.
4. **Check Validity**: For each possible pair of mex values (x for A and y for B), check if the distribution of elements allows these mex values. Specifically, ensure that each number from 0 to x-1 is present in A and each number from 0 to y-1 is present in B, considering the available frequencies.

```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        a = list(map(int, input[ptr:ptr + n]))
        ptr += n
        freq = [0] * 300
        for num in a:
            freq[num] += 1
        max_sum = 0
        for x in range(201):
            for y in range(201):
                current_max = max(x, y)
                valid = True
                for k in range(current_max):
                    req = 0
                    if k < x and k < y:
                        req = 2
                    elif k < x or k < y:
                        req = 1
                    if freq[k] < req:
                        valid = False
                        break
                if valid:
                    current = x + y
                    if current > max_sum:
                        max_sum = current
        print(max_sum)

main()
```

1. **Reading Input**: The input is read in one go for efficiency, especially given multiple test cases.
2. **Frequency Count**: An array `freq` is used to count occurrences of each number in the input set.
3. **Iterating Possible mex Values**: For each possible mex value pair (x, y), check if the required elements for these mex values can be satisfied with the given frequencies.
4. **Validation Check**: For each k from 0 to max(x, y)-1, determine the required occurrences in the subsets and check against the available frequencies.
5. **Maximizing Sum**: Track the maximum sum of valid mex pairs (x, y) and print the result for each test case.

This approach ensures that we efficiently explore all possible splits and validate them against the constraints, leading to the optimal solution.
