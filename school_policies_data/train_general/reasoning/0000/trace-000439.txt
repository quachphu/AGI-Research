To solve this problem, we need to maximize Kefa's satisfaction by selecting exactly `m` distinct dishes from a menu of `n` dishes, considering both individual dish satisfaction and pairwise rules that provide additional satisfaction when specific dishes are eaten consecutively.

### Approach
1. **Dynamic Programming (DP) with Bitmasking**: 
   - Use a bitmask to represent the set of dishes selected so far. Each bit in the mask indicates whether a dish is included.
   - Define a DP state `dp[mask][last]` where `mask` is the current set of dishes and `last` is the last dish eaten. The value stored is the maximum satisfaction achievable with that configuration.
   
2. **Initialization**:
   - Start with each individual dish, initializing the satisfaction value for each dish when it is the only one selected.

3. **Transition**:
   - For each possible state (mask and last dish), consider adding each possible next dish that hasn't been selected yet. Update the DP state to include the new dish and calculate the new satisfaction by adding the dish's value and any applicable pairwise rule.

4. **Result Extraction**:
   - After processing all possible transitions, the result is the maximum value among all states where exactly `m` dishes have been selected.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    idx = 0
    n = int(data[idx])
    m = int(data[idx+1])
    k = int(data[idx+2])
    idx +=3
    a = list(map(int, data[idx:idx+n]))
    idx +=n
    rules = [[0]*n for _ in range(n)]
    for _ in range(k):
        x = int(data[idx])-1
        y = int(data[idx+1])-1
        c = int(data[idx+2])
        rules[x][y] = c
        idx +=3
    
    size = 1 << n
    INF = -10**18
    dp = [[INF]*n for _ in range(size)]
    
    for i in range(n):
        mask = 1 << i
        dp[mask][i] = a[i]
    
    for mask in range(size):
        s = bin(mask).count('1')
        if s >= m:
            continue
        for last in range(n):
            if not (mask & (1 << last)):
                continue
            current = dp[mask][last]
            if current == INF:
                continue
            for next_dish in range(n):
                if mask & (1 << next_dish):
                    continue
                new_mask = mask | (1 << next_dish)
                added = a[next_dish] + rules[last][next_dish]
                if current + added > dp[new_mask][next_dish]:
                    dp[new_mask][next_dish] = current + added
    
    max_sat = 0
    for mask in range(size):
        if bin(mask).count('1') == m:
            current_max = max(dp[mask])
            if current_max > max_sat:
                max_sat = current_max
    
    print(max_sat)

main()
```
