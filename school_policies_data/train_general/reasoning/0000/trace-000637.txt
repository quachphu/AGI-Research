To solve this problem, we need to determine the earliest day in summer that is "not-so-rainy" based on the given constraints. A day is considered not-so-rainy if the amount of rain on that day is less than the rain on each of the preceding `x` days and the following `y` days.

### Approach
1. **Iterate through each day**: Check each day from 1 to `n` to determine if it meets the not-so-rainy criteria.
2. **Check preceding days**: For each day `d`, check the preceding `x` days (if they exist) to ensure all have more rain than day `d`.
3. **Check following days**: Similarly, check the following `y` days (if they exist) to ensure all have more rain than day `d`.
4. **Return the earliest valid day**: The first day that satisfies both conditions is the answer.

### Solution Code
```python
n, x, y = map(int, input().split())
a = list(map(int, input().split()))

for d in range(1, n + 1):
    # Check left x days
    left_start = max(1, d - x)
    left_end = d - 1
    valid = True
    for j in range(left_start, left_end + 1):
        if a[j-1] <= a[d-1]:
            valid = False
            break
    if not valid:
        continue
    
    # Check right y days
    right_start = d + 1
    right_end = min(n, d + y)
    for j in range(right_start, right_end + 1):
        if a[j-1] <= a[d-1]:
            valid = False
            break
    if valid:
        print(d)
        exit()
```

### Explanation
1. **Reading Input**: The input values for the number of days `n`, preceding days `x`, and following days `y` are read. The list of rain amounts for each day is also read.
2. **Loop Through Days**: For each day `d` from 1 to `n`, we check if it is a valid not-so-rainy day.
3. **Check Preceding Days**: The preceding days are checked starting from the maximum of 1 and `d - x` to `d - 1`. If any of these days have rain less than or equal to day `d`, the day is invalid.
4. **Check Following Days**: The following days are checked from `d + 1` to the minimum of `n` and `d + y`. Similarly, if any of these days have rain less than or equal to day `d`, the day is invalid.
5. **Early Exit**: The first valid day found is printed and the program exits immediately to ensure the earliest day is returned.

This approach efficiently checks each day within the constraints, ensuring the solution is optimal and runs in a reasonable time even for the upper limits of input values.
