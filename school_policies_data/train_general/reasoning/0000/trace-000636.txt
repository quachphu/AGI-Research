### Approach
The key insight is to observe that each order of the rhombus builds upon the previous one by adding a layer of cells. The pattern observed from the examples shows that the number of cells added at each step follows a specific arithmetic sequence. 

For a given n-th order rhombus:
1. The first order (n=1) has 1 cell.
2. Each subsequent order (n ≥ 2) adds a layer of cells around the previous rhombus. The number of cells added at each step forms an arithmetic sequence where each term is a multiple of 4. Specifically, the number of cells added when moving from order (n-1) to order n is 4*(n-1).

Summing these contributions from order 1 up to order n gives the total number of cells. This sum can be simplified to a closed-form formula: \(2n^2 - 2n + 1\), which directly computes the number of cells for any given n.
