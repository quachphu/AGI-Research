To solve this problem, we need to determine if there are three consecutive doublets in a sequence of dice rolls. A doublet occurs when both dice in a roll show the same number. The task is to check if there exists at least one instance where three consecutive doublets occur.

### Approach
1. **Input Reading**: Read the number of dice rolls, followed by the results of each roll.
2. **Doublet Identification**: For each roll, check if both dice show the same number and store these results in a boolean list.
3. **Consecutive Check**: Iterate through the boolean list to check if there are three consecutive `True` values, indicating three consecutive doublets.

### Solution Code
```python
def main():
    n = int(input())
    doublets = []
    for _ in range(n):
        a, b = map(int, input().split())
        doublets.append(a == b)
    
    for i in range(len(doublets) - 2):
        if all(doublets[i:i+3]):
            print("Yes")
            return
    print("No")

main()
```

### Explanation
1. **Reading Input**: The first input line gives the number of rolls, `n`. The subsequent `n` lines each contain two integers representing the results of each roll.
2. **Identifying Doublets**: For each roll, we check if the two numbers are equal. This result (True or False) is stored in a list called `doublets`.
3. **Checking Consecutive Doublets**: We iterate through the `doublets` list, checking each possible triplet of consecutive entries. If any triplet consists of three `True` values, we immediately print "Yes" and exit. If no such triplet is found after checking all possibilities, we print "No".

This approach efficiently checks for the required condition with a time complexity of O(n), where n is the number of rolls, ensuring optimal performance given the problem constraints.
