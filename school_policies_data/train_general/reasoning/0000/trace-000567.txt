To solve this problem, we need to determine the maximum amount of money that can be earned by selling broomsticks given a sequence of events where brooms are found and customers demand brooms of specific lengths. The challenge is to optimize the selection of brooms to keep and sell to maximize profit, considering that only one broom can be held at a time.

### Approach
1. **Dynamic Programming (DP) State Tracking**: Use a dictionary to keep track of the maximum profit achievable for each possible broom length (state) at each day.
2. **Handling Found Events**: When a broom is found, decide whether to take it (replacing the current broom if any) or ignore it. The decision is based on maximizing the profit from previous states.
3. **Handling Demand Events**: When a customer demands a broom, check if the current broom matches the demand. If it does, decide whether to sell it (increasing the profit) or keep it for potential future sales.

### Solution Code
```python
n = int(input())
events = [input().split() for _ in range(n)]

dp = {0: 0}  # The initial state: no broom, 0 rupees

for event in events:
    if event[0] == 'found':
        L = int(event[1])
        current_max = max(dp.values()) if dp else 0
        new_dp = {L: current_max}
        for s, val in dp.items():
            if s in new_dp:
                new_dp[s] = max(new_dp[s], val)
            else:
                new_dp[s] = val
        dp = new_dp
    else:
        L = int(event[1])
        new_dp = {}
        for s, val in dp.items():
            if s == L:
                # Option to sell
                new_dp[0] = max(new_dp.get(0, 0), val + L)
                # Option to not sell
                new_dp[L] = max(new_dp.get(L, 0), val)
            else:
                new_dp[s] = max(new_dp.get(s, 0), val)
        dp = new_dp

print(max(dp.values()) if dp else 0)
```

### Explanation
1. **Initialization**: Start with an initial state where no broom is held and the profit is 0.
2. **Processing Found Events**: For each found event, compute the maximum profit achievable by either taking the new broom (replacing the current one) or ignoring it. Update the DP state accordingly.
3. **Processing Demand Events**: For each demand event, check if the current broom matches the demand. If it does, compute the profit from selling it and update the state to reflect no broom being held. If the broom is not sold, retain the current state.
4. **Maximizing Profit**: After processing all events, the maximum value in the DP dictionary represents the highest profit achievable.

This approach efficiently tracks possible states and transitions using dynamic programming, ensuring optimal decisions are made at each step to maximize the total profit.
