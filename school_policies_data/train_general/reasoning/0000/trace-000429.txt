### Approach
1. **Problem Analysis**:
   - The first player writes a number `s1` (≤ a), and the second player writes a number `s2` (≤ b).
   - The second player wins if the concatenated number `s1s2` is divisible by `mod`. Otherwise, the first player wins.
   - We need to check if there exists any `s1` such that no valid `s2` can make the concatenated number divisible by `mod`.

2. **Key Insight**:
   - The concatenated number can be expressed as `s1 * 10^9 + s2`.
   - For the second player to win, `(s1 * 10^9 + s2) % mod == 0` must hold. This simplifies to checking if `s2 ≡ (-s1 * 10^9) % mod` and `s2 ≤ b`.

3. **Mathematical Formulation**:
   - For each possible `s1`, compute `r = (-s1 * 10^9) % mod`.
   - Check if there exists an `s2 ≤ b` such that `s2 % mod == r`.

4. **Efficient Check**:
   - Instead of iterating through all possible values of `s1`, use modular arithmetic to determine feasible values of `s1` efficiently.

5. **Lexicographical Order**:
   - If the first player can win, find the smallest `s1` in lexicographical order by checking the smallest feasible values.

### Solution Code
```python
import math

def main():
    import sys
    a, b, mod = map(int, sys.stdin.readline().split())
    threshold = mod - b
    X = []
    for x in range(1, mod):
        if x < threshold:
            X.append(x)
    
    d = math.gcd(10**9, mod)
    candidates = []
    for x in X:
        if x % d != 0:
            continue
        m = mod // d
        a_part = 10**9 // d
        try:
            inv = pow(a_part, -1, m)
        except ValueError:
            continue
        s0 = ((x // d) * inv) % m
        if s0 <= a:
            candidates.append(s0)
    
    if not candidates:
        print(2)
    else:
        min_s = min(candidates)
        print(f"1 {min_s:09d}")

if __name__ == "__main__":
    main()
```
