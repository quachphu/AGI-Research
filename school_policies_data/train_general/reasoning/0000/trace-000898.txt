To solve this problem, we need to sort a list of points on a plane based on their coordinates. The primary sorting criterion is the x-coordinate, and in case of a tie, the y-coordinate is used. The solution must efficiently handle up to 100,000 points, ensuring optimal performance.

### Approach
1. **Reading Input Efficiently**: The input is read all at once using `sys.stdin.read()` for efficiency, especially with large input sizes. This method reduces the overhead of multiple I/O operations.
2. **Parsing Data**: The input data is split into a list of integers. The first integer is the number of points, followed by pairs of integers representing the x and y coordinates of each point.
3. **Sorting Points**: Using Python's built-in sort function, which is efficient and handles large datasets well. The points are sorted by their x-coordinate first and y-coordinate second using a tuple key for the sort function.
4. **Output the Result**: After sorting, each point is printed in the required format.

### Solution Code
```python
import sys

def main():
    data = list(map(int, sys.stdin.read().split()))
    n = data[0]
    x_coords = data[1::2]
    y_coords = data[2::2]
    points = list(zip(x_coords, y_coords))
    points.sort(key=lambda p: (p[0], p[1]))
    for x, y in points:
        print(f"{x} {y}")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go using `sys.stdin.read().split()`, which splits the input into a list of strings. These strings are then converted to integers.
2. **Data Parsing**: The list of integers is processed to extract the number of points and their coordinates. The x-coordinates are extracted from the odd indices starting from 1, and the y-coordinates from the even indices starting from 2.
3. **Sorting**: The points are sorted using a lambda function that returns a tuple (x, y), ensuring the sort is done first by x and then by y.
4. **Output**: The sorted points are printed in the required format using an f-string for each point.

This approach ensures that the solution is efficient both in terms of time and space complexity, making it suitable for handling the upper constraint of 100,000 points.
