To solve this problem, we need to convert a binary number to its octal equivalent and then map each octal digit to a corresponding letter or space. The solution involves several steps, including processing the integer and fractional parts of the binary number separately, converting them to octal, and then mapping the octal digits to letters.

### Approach
1. **Input Handling**: Read the binary input and split it into integer and fractional parts if a decimal point is present.
2. **Integer Part Conversion**:
   - Pad the integer part with leading zeros to make its length a multiple of 3.
   - Split the padded binary string into groups of 3 bits and convert each group to its octal equivalent.
3. **Fractional Part Conversion**:
   - If present, pad the fractional part with trailing zeros to make its length a multiple of 3.
   - Split the padded binary string into groups of 3 bits and convert each group to its octal equivalent.
4. **Octal to Letter Mapping**:
   - Map each octal digit of the integer part to its corresponding letter (A for 1, B for 2, ..., G for 7, and space for 0).
   - For the fractional part, map each octal digit similarly but join the resulting letters with spaces.
5. **Output Construction**: Combine the octal string and the mapped letters into the final output format.

### Solution Code
```python
def binary_to_octal_converter():
    binary_input = input().strip()
    
    # Split into integer and fractional parts
    if '.' in binary_input:
        int_part, frac_part = binary_input.split('.')
    else:
        int_part = binary_input
        frac_part = None
    
    # Process integer part
    if len(int_part) == 0:
        octal_int = '0'
    else:
        pad_length = (3 - len(int_part) % 3) % 3
        padded = '0' * pad_length + int_part
        octal_digits = []
        for i in range(0, len(padded), 3):
            group = padded[i:i+3]
            octal_digit = str(int(group, 2))
            octal_digits.append(octal_digit)
        octal_int = ''.join(octal_digits)
    
    # Process fractional part
    octal_frac = []
    if frac_part is not None:
        pad_length = (3 - len(frac_part) % 3) % 3
        padded = frac_part + '0' * pad_length
        for i in range(0, len(padded), 3):
            group = padded[i:i+3]
            octal_digit = str(int(group, 2))
            octal_frac.append(octal_digit)
    
    # Build octal string
    octal_str = octal_int
    if frac_part is not None:
        octal_str += '.' + ''.join(octal_frac)
    
    # Function to map octal digits to letters
    def map_digit(c):
        if c == '0':
            return ' '
        else:
            return chr(ord('A') + int(c) - 1)
    
    # Build letters part
    int_letters = ''.join([map_digit(d) for d in octal_int])
    frac_letters = ''
    if octal_frac:
        frac_letters = ' '.join([map_digit(d) for d in octal_frac])
    
    # Combine letters
    if frac_letters:
        letters = f"{int_letters} {frac_letters}"
    else:
        letters = int_letters
    
    # Print the output
    print(f"{octal_str} {letters}")
```

1. **Input Handling**: The input is read and split into integer and fractional parts using the decimal point as a delimiter.
2. **Integer Conversion**: The integer part is padded with leading zeros to ensure its length is a multiple of 3. Each group of 3 bits is converted to an octal digit.
3. **Fractional Conversion**: The fractional part, if present, is padded with trailing zeros. Each group of 3 bits is converted to an octal digit.
4. **Mapping to Letters**: Each octal digit is mapped to a letter (A-G) or a space (for 0). The fractional part's letters are joined with spaces.
5. **Output**: The octal string and the mapped letters are combined and printed in the required format.

This approach ensures that both integer and fractional parts are processed correctly, and the resulting output meets the specified format.
