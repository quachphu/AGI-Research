The goal is to determine the optimal distribution of pizza slices to maximize happiness while using the minimum number of pizzas.

### Approach

1. **Calculate Total Slices and Minimum Pizzas**: Compute the total number of slices required by all contestants and determine the minimum number of pizzas needed (T) using the ceiling of the division of total slices by the number of slices per pizza (S).

2. **Classify Contestants**: Separate contestants into three groups based on their preference:
   - Group A: Prefers type 1 pizza (higher happiness from type 1).
   - Group B: Indifferent between both pizza types (same happiness).
   - Group C: Prefers type 2 pizza (higher happiness from type 2).

3. **Prefix Sums for Optimization**: Compute prefix sums for Group A (sorted by ascending preference for type 1) and Group C (sorted by descending preference for type 2). These prefix sums help in quickly calculating the maximum possible happiness when adjusting the number of slices allocated to each group.

4. **Iterate Over Possible Pizza Distributions**: For each possible distribution of pizzas between type 1 and type 2 (from 0 to T type 1 pizzas), calculate the valid range of type 1 slices and determine the optimal allocation within this range.
