To solve this problem, we need to select up to `k` songs from a playlist to maximize the pleasure, which is defined as the sum of the lengths of the selected songs multiplied by the minimum beauty among them. 

### Approach
1. **Sort by Beauty**: First, sort the songs in descending order of their beauty values. This allows us to consider each song as a potential candidate for the minimum beauty in the subset of songs we select.
2. **Maintain a Heap**: Use a min-heap to keep track of the largest `k-1` song lengths encountered so far. This helps efficiently compute the sum of the top `k-1` lengths when combined with the current song's length.
3. **Calculate Maximum Pleasure**: For each song in the sorted list, compute the potential pleasure using the current song's beauty as the minimum and the sum of the top `k-1` lengths from previous songs plus the current song's length. Update the maximum pleasure encountered during this process.

### Solution Code
```python
import heapq

n, k = map(int, input().split())
songs = []
for _ in range(n):
    t, b = map(int, input().split())
    songs.append((-b, t))  # Sort by descending beauty

songs.sort()

max_pleasure = 0
heap = []
sum_heap = 0

for song in songs:
    b = -song[0]
    t = song[1]
    current_pleasure = (sum_heap + t) * b
    if current_pleasure > max_pleasure:
        max_pleasure = current_pleasure
    heapq.heappush(heap, t)
    sum_heap += t
    if len(heap) > k - 1:
        popped = heapq.heappop(heap)
        sum_heap -= popped

print(max_pleasure)
```

### Explanation
1. **Sorting**: By sorting the songs in descending order of beauty, we ensure that when we consider each song, all previously processed songs have a beauty value greater than or equal to the current song's beauty. This allows us to use the current song's beauty as the minimum for the subset being considered.
2. **Heap Usage**: A min-heap is used to maintain the largest `k-1` song lengths encountered so far. This helps efficiently track the sum of the top `k-1` lengths, which, when combined with the current song's length, gives the total length for the subset.
3. **Updating Maximum Pleasure**: For each song, compute the potential pleasure using the current song's beauty and the sum of the top lengths from the heap. Update the maximum pleasure if the current value is higher.

This approach ensures that we efficiently compute the maximum possible pleasure by leveraging sorting and heap data structures to handle large input sizes within acceptable time complexity.
