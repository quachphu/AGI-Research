To solve this problem, we need to find the longest path in a directed graph where each edge's weight is strictly increasing. The solution involves dynamic programming combined with sorting edges by their weights and processing them in groups to ensure strictly increasing order.

### Approach
1. **Sort Edges by Weight**: First, we sort all edges based on their weights in non-decreasing order. This allows us to process edges in increasing weight order, ensuring that we can build paths with strictly increasing weights.
2. **Dynamic Programming (DP)**: Use a DP array where `dp[v]` represents the maximum number of edges in a path ending at vertex `v`.
3. **Group Processing**: Process edges in groups of the same weight. For each group, compute potential updates to the DP array using a temporary dictionary to avoid interference within the same weight group.
4. **Update DP Array**: After processing each group, update the DP array with the maximum values obtained from the temporary dictionary to ensure paths are built correctly with strictly increasing weights.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    m = int(input[ptr])
    ptr += 1
    edges = []
    for _ in range(m):
        u = int(input[ptr])
        ptr += 1
        v = int(input[ptr])
        ptr += 1
        w = int(input[ptr])
        ptr += 1
        edges.append((u, v, w))
    
    edges.sort(key=lambda x: x[2])
    
    dp = [0] * (n + 1)  # 1-based indexing
    max_len = 0
    i = 0
    
    while i < m:
        current_w = edges[i][2]
        temp = {}
        j = i
        while j < m and edges[j][2] == current_w:
            u, v, w = edges[j]
            new_val = dp[u] + 1
            if new_val > temp.get(v, 0):
                temp[v] = new_val
            j += 1
        # Update dp and track maximum length
        for v in temp:
            if temp[v] > dp[v]:
                dp[v] = temp[v]
            if dp[v] > max_len:
                max_len = dp[v]
        i = j
    
    print(max_len)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into a list of edges.
2. **Sorting Edges**: The edges are sorted by their weights to ensure we process them in increasing order.
3. **Dynamic Programming Initialization**: The DP array is initialized to zero for all vertices since initially, no edges are traversed.
4. **Processing Groups**: For each group of edges with the same weight, a temporary dictionary is used to track the maximum path length ending at each vertex. This ensures that all updates within the same weight group do not interfere with each other.
5. **Updating DP Array**: After processing each group, the DP array is updated with the values from the temporary dictionary, and the maximum path length is tracked.

This approach efficiently processes each edge in O(m log m) time due to sorting and linear processing, making it suitable for large input sizes up to 300,000 edges.
