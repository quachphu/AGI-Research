To solve this problem, we need to determine if there exists a good set of choices for placing balls in boxes such that for each integer \( i \) from 1 to \( N \), the total number of balls in boxes with indices that are multiples of \( i \) is congruent to \( a_i \) modulo 2. If such a configuration exists, we need to find one such configuration.

### Approach
The key insight is to use a greedy algorithm that processes the boxes from right to left (i.e., from \( N \) down to 1). This approach ensures that when we decide whether to place a ball in the \( i \)-th box, we have already considered all larger multiples of \( i \), which simplifies the computation.

1. **Initialization**: Create an array `x` where `x[i]` will be 1 if we place a ball in the \( i \)-th box and 0 otherwise.
2. **Processing from Right to Left**: For each \( i \) from \( N \) down to 1:
   - Calculate the sum of balls in boxes that are multiples of \( i \) and greater than \( i \).
   - Determine if a ball should be placed in the \( i \)-th box by checking if the current sum modulo 2 matches the required value \( a[i-1] \).
3. **Result Collection**: Collect all indices where a ball is placed and print the result.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
x = [0] * (n + 1)

for i in range(n, 0, -1):
    sum_multiples = 0
    j = 2 * i
    while j <= n:
        sum_multiples += x[j]
        j += i
    sum_multiples %= 2
    x[i] = (a[i-1] - sum_multiples) % 2

result = [i for i in range(1, n+1) if x[i] == 1]
print(len(result))
if result:
    print(' '.join(map(str, result)))
```

### Explanation
1. **Reading Input**: The input is read and parsed into `n` and the list `a`.
2. **Processing Each Box**: Starting from the largest index \( N \) down to 1, we compute the sum of balls in all boxes that are multiples of the current index and greater than the current index. This sum is used to determine if a ball should be placed in the current box to satisfy the condition modulo 2.
3. **Result Construction**: After processing all indices, we collect all indices where a ball is placed and print the count followed by the indices.

This approach ensures that each condition for the sum of balls in multiples of each index is checked and satisfied in an efficient manner, leveraging the properties of modular arithmetic and greedy decision-making. The algorithm runs in \( O(N \log N) \) time, which is efficient for the given constraints.
