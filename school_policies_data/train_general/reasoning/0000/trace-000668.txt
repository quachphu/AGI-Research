The approach involves a greedy strategy where we try to split the string into the smallest possible segments while ensuring each new segment is different from the previous one.

### Approach
1. **Greedy Strategy**: We iterate through the string and attempt to split it into the smallest possible segments (1 or 2 characters long) that are different from the previous segment.
2. **Handling Merges**: If the remaining part of the string cannot be split into a valid segment (i.e., it is the same as the previous segment), we merge it with the previous segment. This ensures we maximize the number of valid partitions.

def main():
    s = input().strip()
    if not s:
        print(0)
        return
    
    prev = ''
    count = 0
    i = 0
    n = len(s)
    
    while i < n:
        # Try to take 1 character first
        if i + 1 <= n:
            candidate = s[i:i+1]
            if candidate != prev:
                prev = candidate
                count += 1
                i += 1
                continue
        # If 1 character is not possible, try 2 characters
        if i + 2 <= n:
            candidate = s[i:i+2]
            if candidate != prev:
                prev = candidate
                count += 1
                i += 2
                continue
        # If both 1 and 2 are not possible, take remaining characters
        remaining = s[i:]
        if remaining != prev:
            prev = remaining
            count += 1
            i = n
        else:
            # Merge with the previous segment if possible
            if count > 0:
                count -= 1  # undo previous segment
                i -= len(prev)  # backtrack to the start of the previous segment
                # Now take the merged segment and proceed
                merged = s[i:i+len(prev)+len(remaining)]
                prev = merged
                count += 1
                i += len(prev)
            else:
                # Entire string is one segment
                count = 1
                i = n
    print(count)
