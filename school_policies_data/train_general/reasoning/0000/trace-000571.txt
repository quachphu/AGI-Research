To solve this problem, we need to determine how many times the page is turned each day when writing names in a notebook according to specific rules. The notebook has pages that can hold a fixed number of names, and we need to track page turns as we fill each page during each day.

### Approach
1. **Problem Analysis**: The key insight is that each page turn occurs when the cumulative number of names written reaches a multiple of the page capacity. For each day, the number of page turns is determined by the difference in the number of full pages before and after writing the names for that day.

2. **Efficient Calculation**: Instead of simulating the writing process day by day, we use cumulative sums to track the total number of names written up to each day. By comparing the number of full pages before and after each day, we can efficiently determine the number of page turns for that day.

3. **Algorithm**:
   - Track the cumulative sum of names written up to the previous day.
   - For each day, update the cumulative sum by adding the names written on the current day.
   - Calculate the number of full pages before and after the current day using integer division.
   - The difference between these two values gives the number of page turns for the current day.

### Solution Code
```python
n, m = map(int, input().split())
a = list(map(int, input().split()))

prev_total = 0
result = []
for names in a:
    prev_total += names
    result.append(str(prev_total // m - (prev_total - names) // m))

print(' '.join(result))
```

### Explanation
- **Reading Input**: The input consists of the number of days `n` and the page capacity `m`, followed by a list of names written each day.
- **Cumulative Sum Calculation**: We maintain a running total of names written (`prev_total`). For each day, we add the names written that day to `prev_total`.
- **Page Turn Calculation**: By dividing the cumulative sum by the page capacity `m` before and after adding the current day's names, we determine how many full pages exist before and after the day. The difference between these values gives the number of page turns for that day.
- **Output**: The results for each day are collected in a list and printed as space-separated values.

This approach efficiently computes the required result in linear time, making it suitable for large input sizes as specified in the problem constraints.
