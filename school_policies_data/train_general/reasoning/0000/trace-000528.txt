To solve this problem, we need to find the minimum total cost to paint all black cells (denoted by '#') in an n×n grid white using rectangle operations. Each operation's cost is determined by the maximum of the rectangle's height and width. The goal is to cover all black cells with the least possible cost.

### Approach
1. **Dynamic Programming (DP) with Memoization**: We use a DP approach to compute the minimal cost for each sub-rectangle of the grid. The state of our DP function is defined by the coordinates of the top-left and bottom-right corners of a rectangle.
2. **Prefix Sum Array**: To efficiently check if a sub-rectangle contains any black cells, we use a prefix sum array. This allows us to determine the presence of black cells in constant time.
3. **Splitting Strategy**: For each rectangle, we consider both covering it with a single operation and splitting it into smaller sub-rectangles (either vertically or horizontally) to find the minimum cost.

### Solution Code
```python
from functools import lru_cache

n = int(input())
grid = []
for _ in range(n):
    line = input().strip()
    grid.append([1 if c == '#' else 0 for c in line])

# Compute the 2D prefix sum array
prefix = [[0] * (n + 1) for _ in range(n + 1)]
for i in range(n):
    row_sum = 0
    for j in range(n):
        row_sum += grid[i][j]
        prefix[i + 1][j + 1] = prefix[i][j + 1] + row_sum

def has_black(i1, j1, i2, j2):
    if i1 > i2 or j1 > j2:
        return False
    return (prefix[i2 + 1][j2 + 1] - prefix[i1][j2 + 1] - prefix[i2 + 1][j1] + prefix[i1][j1]) > 0

@lru_cache(maxsize=None)
def dp(i1, j1, i2, j2):
    if not has_black(i1, j1, i2, j2):
        return 0
    h = i2 - i1 + 1
    w = j2 - j1 + 1
    min_cost = max(h, w)
    # Try all vertical splits
    for k in range(j1, j2):
        cost = dp(i1, j1, i2, k) + dp(i1, k + 1, i2, j2)
        if cost < min_cost:
            min_cost = cost
    # Try all horizontal splits
    for k in range(i1, i2):
        cost = dp(i1, j1, k, j2) + dp(k + 1, j1, i2, j2)
        if cost < min_cost:
            min_cost = cost
    return min_cost

print(dp(0, 0, n - 1, n - 1))
```

### Explanation
1. **Prefix Sum Array**: The prefix sum array helps quickly determine if any sub-rectangle contains black cells. This is done by calculating the sum of the sub-rectangle using the prefix sums.
2. **Dynamic Programming Function (dp)**: The function `dp(i1, j1, i2, j2)` computes the minimum cost to clear all black cells in the rectangle defined by the coordinates (i1, j1) to (i2, j2). It checks if the rectangle is empty using the prefix sum array. If not, it considers both covering the entire rectangle in one operation and splitting it into smaller sub-rectangles to find the minimum cost.
3. **Splitting Strategy**: For each rectangle, we explore all possible vertical and horizontal splits. The cost of each split is the sum of the costs of the resulting sub-rectangles. The minimum of these costs and the cost of covering the entire rectangle in one operation is taken as the result.

This approach ensures that we efficiently explore all possible ways to clear the grid with minimal cost using dynamic programming and memoization.
