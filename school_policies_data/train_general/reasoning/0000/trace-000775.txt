To solve this problem, we need to read an array of integers from standard input, sort them in non-decreasing order (ascending order), and then print each integer on a separate line in the sorted order.

### Approach
1. **Reading Input**: The first line of input contains an integer \( N \), which is the number of elements in the array. The subsequent \( N \) lines each contain an integer.
2. **Storing Integers**: Read these \( N \) integers and store them in a list.
3. **Sorting**: Sort the list of integers in ascending order.
4. **Output**: Print each integer from the sorted list on a separate line.

This approach ensures that we efficiently handle the input size constraints (up to 10,000 elements) and correctly sort the integers using Python's built-in sort function, which is optimal for this problem size.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    numbers = [int(sys.stdin.readline().strip()) for _ in range(n)]
    numbers.sort()
    for num in numbers:
        print(num)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The function starts by reading the integer \( N \) from the first line of input. Then, it reads the next \( N \) lines, converting each line to an integer and storing them in a list.
2. **Sorting**: The list of integers is sorted in ascending order using Python's built-in `sort()` method, which is efficient and handles all edge cases.
3. **Printing Output**: Each integer from the sorted list is printed on a new line, ensuring the output matches the required format.

This approach efficiently processes the input and ensures the correct sorted order is outputted, adhering to the problem constraints and requirements.
