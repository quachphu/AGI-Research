To solve this problem, we need to determine the minimum cost of wallpapering all rooms in Boris's apartment using the available types of wallpaper. Each room must be covered using exactly one type of wallpaper, and each type of wallpaper has specific dimensions and costs. The goal is to minimize the total cost while ensuring all rooms are covered.

### Approach
1. **Calculate Room Perimeter and Height**: For each room, compute the perimeter of the walls and the height. The perimeter is calculated as \(2 \times (length + width)\), and the height is directly taken from the input.
2. **Evaluate Each Wallpaper Type**: For each room, check each type of wallpaper to see if it can be used (i.e., the length of the wallpaper roll is at least the height of the room).
3. **Determine Strips and Rolls Needed**: For valid wallpaper types, calculate the number of vertical strips each roll can provide and the number of strips needed to cover the room's perimeter. From these values, compute the number of rolls required and the associated cost.
4. **Minimize Cost per Room**: For each room, find the wallpaper type that results in the lowest cost and sum these minimum costs across all rooms.

### Solution Code
```python
n = int(input())
rooms = []
for _ in range(n):
    l, w, h = map(int, input().split())
    perimeter = 2 * (l + w)
    rooms.append((perimeter, h))

m = int(input())
wallpapers = []
for _ in range(m):
    lj, wj, pj = map(int, input().split())
    wallpapers.append((lj, wj, pj))

total_cost = 0
for perimeter, h_room in rooms:
    min_cost = float('inf')
    for lj, wj, pj in wallpapers:
        if lj < h_room:
            continue
        strips_per_roll = lj // h_room
        strips_needed = (perimeter + wj - 1) // wj
        rolls_needed = (strips_needed + strips_per_roll - 1) // strips_per_roll
        cost = rolls_needed * pj
        if cost < min_cost:
            min_cost = cost
    total_cost += min_cost

print(total_cost)
```

### Explanation
1. **Reading Input**: The input is read and parsed into rooms and wallpapers. Each room's perimeter and height are stored, and each wallpaper's dimensions and price are stored.
2. **Iterating Over Rooms**: For each room, we initialize the minimum cost to a large value and then check each wallpaper type.
3. **Checking Validity**: If a wallpaper's length is less than the room's height, it is skipped.
4. **Calculating Requirements**: For valid wallpapers, the number of strips per roll, strips needed, and rolls needed are computed. The cost is determined and compared to find the minimum cost for the room.
5. **Summing Costs**: The minimum cost for each room is added to the total cost, which is printed as the final result.

This approach ensures that we efficiently compute the minimum cost for each room and sum these costs to get the optimal solution for wallpapering all rooms. The complexity is manageable due to the constraints, making it feasible to solve within reasonable time limits.
