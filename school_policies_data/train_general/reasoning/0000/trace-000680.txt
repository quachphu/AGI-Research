To solve this problem, we need to determine if Chef can find a magical path in a given N x M maze. A magical path is defined as a path that starts and ends at adjacent cells, traversing all cells exactly once. 

### Approach
1. **Check for 1x2 or 2x1 Grids**: If either dimension is 1, the only way to have a magical path is if the other dimension is 2. This is because a 1x2 or 2x1 grid allows a straight path from one end to the other, which are adjacent.
2. **Check for Even Dimensions**: For grids where both dimensions are greater than 1, a magical path exists if at least one of the dimensions is even. This is because an even dimension allows for a snake-like traversal that covers all cells and ends adjacent to the start.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        n = int(input[idx])
        m = int(input[idx + 1])
        idx += 2
        if n == 1 or m == 1:
            if n * m == 2:
                print("Yes")
            else:
                print("No")
        else:
            if n % 2 == 0 or m % 2 == 0:
                print("Yes")
            else:
                print("No")

if __name__ == "__main__":
    main()
```

### Explanation
- **1x2 or 2x1 Grids**: These grids have exactly 2 cells, which are adjacent. Thus, a valid path exists.
- **Even Dimension Check**: For grids where both dimensions are greater than 1, if either dimension is even, the grid can be traversed in a snake-like manner. This ensures that the start and end points are adjacent after visiting all cells exactly once. If both dimensions are odd, such traversal is impossible, hence no valid path exists.

This approach efficiently checks the necessary conditions in constant time for each test case, making it suitable for large input sizes up to 100,000 test cases.
