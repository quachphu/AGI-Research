To solve this problem, we need to determine the minimum amount of magic points (MP) required to transform a given set of bamboos into three specific lengths (A, B, and C) using a combination of extension, shortening, and composition magic. The solution involves systematically exploring all possible ways to group the bamboos into three groups, each targeting one of the required lengths, and calculating the associated costs.

### Approach
1. **Group Assignment**: Each bamboo can be assigned to one of four groups: A, B, C, or unused. We generate all possible assignments of bamboos to these groups using itertools.product.
2. **Validation**: For each assignment, check if all three target groups (A, B, C) have at least one bamboo each.
3. **Cost Calculation**: For each valid assignment, compute the cost for each group:
   - **Composition Magic Cost**: Each group with `k` bamboos requires `(k-1)*10` MP due to combining them into a single bamboo.
   - **Adjustment Cost**: The cost to adjust the combined length of each group to the target length (A, B, or C) using extension or shortening magic, which is the absolute difference between the combined length and the target length.
4. **Minimize Total Cost**: Track the minimum total cost across all valid assignments.

### Solution Code
```python
import itertools

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx +=1
    A = int(input[idx])
    idx +=1
    B = int(input[idx])
    idx +=1
    C = int(input[idx])
    idx +=1
    l = []
    for _ in range(N):
        l.append(int(input[idx]))
        idx +=1
    
    min_mp = float('inf')
    
    for assign in itertools.product([0,1,2,3], repeat=N):
        a_count = assign.count(0)
        b_count = assign.count(1)
        c_count = assign.count(2)
        
        if a_count ==0 or b_count ==0 or c_count ==0:
            continue
        
        sum_a = sum(l[i] for i in range(N) if assign[i] ==0)
        sum_b = sum(l[i] for i in range(N) if assign[i] ==1)
        sum_c = sum(l[i] for i in range(N) if assign[i] ==2)
        
        cost_a = (a_count -1)*10 + abs(sum_a - A)
        cost_b = (b_count -1)*10 + abs(sum_b - B)
        cost_c = (c_count -1)*10 + abs(sum_c - C)
        
        total = cost_a + cost_b + cost_c
        
        if total < min_mp:
            min_mp = total
    
    print(min_mp)

if __name__ == '__main__':
    main()
```

### Explanation
- **Group Assignment**: Using itertools.product, we generate all possible ways to assign each of the N bamboos to one of the four groups (A, B, C, or unused).
- **Validation**: We ensure that each of the target groups (A, B, C) has at least one bamboo. If not, the assignment is skipped.
- **Cost Calculation**: For each valid assignment, we compute the total cost by summing the composition magic costs and the adjustment costs for each group.
- **Optimization**: We keep track of the minimum total cost encountered and print it as the result.

This approach efficiently explores all possible groupings and computes the minimum MP required, ensuring an optimal solution given the problem constraints.
