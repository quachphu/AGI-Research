To solve this problem, we need to determine the minimum number of changes required to convert a given binary matrix into a "good" matrix, where every even-length square sub-matrix has an odd number of 1s. If it's impossible to achieve this, we should return -1.

### Approach
1. **Check for Impossibility**: If the matrix has 4 or more rows, it's impossible to make it good because larger even-length squares (4x4 or bigger) introduce conflicting constraints. Thus, we immediately return -1 for matrices with 4 or more rows.

2. **Handle Single Row**: If the matrix has only one row, there are no even-length squares, so no changes are needed.

3. **Handle Two Rows**: For a matrix with two rows, we need to ensure all 2x2 sub-matrices have an odd sum. This can be achieved by alternating the parity of column sums. We compute the minimum changes needed for two possible alternating patterns and choose the minimum.

4. **Handle Three Rows**: For a matrix with three rows, we need to ensure all 2x2 sub-matrices in both the top two rows and bottom two rows have odd sums. We explore four possible patterns for the parity sequences of columns, compute the minimum changes for each, and select the minimum.

### Solution Code
```python
import sys

def main():
    n, m = map(int, sys.stdin.readline().split())
    if n >= 4:
        print(-1)
        return
    if n == 1:
        print(0)
        return
    if n == 2:
        row0 = sys.stdin.readline().strip()
        row1 = sys.stdin.readline().strip()
        costA = 0
        costB = 0
        for j in range(m):
            # s_j is (row0[j] + row1[j]) mod 2
            s_j = (int(row0[j]) + int(row1[j])) % 2
            # Pattern A: starts with 0, alternates (j is 0-based, so (j) %2 for pattern)
            expectedA = j % 2
            if s_j != expectedA:
                costA += 1
            # Pattern B: starts with 1, so expected is (j+1) %2
            expectedB = (j + 1) % 2
            if s_j != expectedB:
                costB += 1
        print(min(costA, costB))
        return
    if n == 3:
        row0 = sys.stdin.readline().strip()
        row1 = sys.stdin.readline().strip()
        row2 = sys.stdin.readline().strip()
        original = []
        for j in range(m):
            a0 = int(row0[j])
            a1 = int(row1[j])
            a2 = int(row2[j])
            original.append((a0, a1, a2))
        min_total = float('inf')
        # Iterate all four combinations of x_start and y_start
        for x_start in [0, 1]:
            for y_start in [0, 1]:
                total = 0
                for j in range(m):
                    x_j = (x_start + j) % 2
                    y_j = (y_start + j) % 2
                    a0_orig, a1_orig, a2_orig = original[j]
                    # Option 0: a1j = 0
                    cost0 = ( (a0_orig != x_j) + (a1_orig != 0) + (a2_orig != y_j) )
                    # Option 1: a1j = 1
                    a0_new = (x_j + 1) % 2
                    a2_new = (y_j + 1) % 2
                    cost1 = ( (a0_orig != a0_new) + (a1_orig != 1) + (a2_orig != a2_new) )
                    total += min(cost0, cost1)
                if total < min_total:
                    min_total = total
        print(min_total if min_total != float('inf') else -1)
        return

if __name__ == "__main__":
    main()
```

2. **Single Row Handling**: No changes needed as there are no even-length squares.
3. **Two Rows Handling**: We check two possible alternating patterns for column sums and compute the minimum changes needed.
4. **Three Rows Handling**: We explore four possible patterns for parity sequences in columns, compute the cost for each, and select the minimum cost.
