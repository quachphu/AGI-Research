To solve this problem, we need to determine the maximum number of happy people in a queue after performing up to K operations. Each operation can reverse a substring and flip the directions of the people in it. A person is happy if the person in front of them is facing the same direction.

### Approach
1. **Understanding Happy People**: A person is happy if the next person in the queue is facing the same direction. Thus, the number of happy people is determined by the number of consecutive pairs of people facing the same direction.

2. **Transitions Between Directions**: The key insight is that each time the direction changes from 'L' to 'R' or vice versa, it creates a transition. The number of transitions directly affects the number of happy people. Fewer transitions mean more happy people.

3. **Effect of Operations**: Each operation can potentially reduce the number of transitions. The optimal use of up to K operations can reduce the number of transitions by up to 2 per operation. Thus, the maximum reduction in transitions is min(2*K, T), where T is the initial number of transitions.

4. **Formula for Maximum Happy People**: The maximum number of happy people can be calculated as (N-1) - max(0, T - 2*K), where N is the number of people, T is the initial number of transitions, and K is the maximum number of operations allowed.

### Solution Code
```python
n, k = map(int, input().split())
s = input().strip()

transitions = 0
for i in range(n-1):
    if s[i] != s[i+1]:
        transitions += 1

max_happy = (n - 1) - max(0, transitions - 2 * k)
print(max_happy)
```

### Explanation
1. **Reading Input**: The input consists of the number of people (N), the number of operations allowed (K), and the string (S) representing the directions of the people.

2. **Counting Transitions**: We iterate through the string to count the number of transitions between 'L' and 'R'. Each transition is where consecutive characters differ.

3. **Calculating Maximum Happy People**: Using the formula derived, we compute the maximum possible number of happy people by considering the reduction in transitions due to the allowed operations.

This approach efficiently computes the result in O(N) time complexity, which is optimal given the constraints.
