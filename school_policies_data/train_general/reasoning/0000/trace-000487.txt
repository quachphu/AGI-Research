To solve this problem, we need to determine if a given array can be sorted by swapping at most one pair of elements. The solution involves comparing the given array with its sorted version and checking the positions where they differ. 

### Approach
1. **Sort the Array**: First, sort the given array to get the target sorted version.
2. **Identify Differences**: Find all indices where the elements of the original array and the sorted array differ.
3. **Check Conditions**:
   - If there are no differences, the array is already sorted, so the answer is "YES".
   - If there are exactly two differences, check if swapping the elements at these two indices in the original array makes it match the sorted array.
   - If there are more than two differences, it's impossible to sort the array with a single swap, so the answer is "NO".

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
sorted_a = sorted(a)
diff = [i for i in range(n) if a[i] != sorted_a[i]]

if len(diff) == 0:
    print("YES")
elif len(diff) == 2:
    i, j = diff
    if a[i] == sorted_a[j] and a[j] == sorted_a[i]:
        print("YES")
    else:
        print("NO")
else:
    print("NO")
```

### Explanation
1. **Reading Input**: The input consists of the array size `n` and the array elements.
2. **Sorting**: The array is sorted to determine the target configuration.
3. **Finding Differences**: By comparing each element of the original array with the sorted array, we collect the indices where discrepancies occur.
4. **Decision Making**:
   - If there are no discrepancies, the array is already sorted.
   - If there are exactly two discrepancies, we check if swapping those two elements in the original array results in the sorted array.
   - More than two discrepancies mean sorting with a single swap is impossible.

This approach efficiently checks the necessary conditions with a time complexity of O(n log n) due to sorting, which is optimal for the given problem constraints.
