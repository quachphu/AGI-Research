To solve this problem, we need to find the longest valid parentheses substring in a given string of brackets and count how many such substrings exist. A valid parentheses substring is defined as a sequence that can form a correct mathematical expression with the insertion of numbers and operators.

### Approach
1. **Stack-Based Tracking**: Use a stack to keep track of indices of unmatched parentheses. This helps in determining the length of valid substrings whenever a closing bracket is encountered.
2. **Dynamic Updates**: Maintain variables to track the maximum length of valid substrings found (`max_len`) and the count of such substrings (`count`).
3. **Edge Case Handling**: If no valid substrings are found, output "0 1" as specified.

s = input().strip()

max_len = 0

        stack.pop()
        if not stack:
            stack.append(i)
