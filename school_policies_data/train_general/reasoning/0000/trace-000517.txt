To solve this problem, we need to determine the maximum number of friends we can invite to the sea such that each friend's condition on the number of attendees (including ourselves) is satisfied. Each friend specifies a range [ai, bi] within which the total number of attendees must fall for them to agree to come.

### Approach
1. **Problem Analysis**:
   - Each friend will only attend if the total number of people (including ourselves) is within their specified range [ai, bi].
   - We need to find the maximum number of friends such that there exists a number K (total attendees) that falls within each of their ranges.

2. **Key Insight**:
   - For a given number of friends `m` that we can invite, the total attendees `K` will be `m + 1` (including ourselves). We need to find the largest `m` such that there are at least `m` friends whose ranges include `K`.

3. **Efficient Calculation**:
   - Use a delta array to efficiently compute the number of friends whose ranges include each possible value of K. This allows us to quickly determine how many friends can be invited for any potential K.

4. **Algorithm**:
   - **Delta Array**: Track the start and end of each friend's range using a delta array to increment and decrement counts.
   - **Prefix Sum**: Compute the prefix sum of the delta array to get the count of friends for each possible K.
   - **Iterate from Max K**: Check each possible K from the maximum possible value down to 1 to find the largest valid K where the count of friends including K is sufficient.
