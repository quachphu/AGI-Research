To solve this problem, we need to determine the number of valid N-digit binary numbers where no two zeros are adjacent. This problem can be efficiently solved using dynamic programming by recognizing the pattern in the valid sequences, which corresponds to the Fibonacci sequence.

### Approach
1. **Problem Analysis**: The problem can be translated into finding the number of valid binary sequences of length N where no two zeros are adjacent. This can be broken down using dynamic programming:
   - Let `a(n)` be the number of valid sequences of length `n` ending with 0.
   - Let `b(n)` be the number of valid sequences of length `n` ending with 1.
   - The recurrence relations are:
     - `a(n) = b(n-1)` (since a sequence ending in 0 must be preceded by a 1)
     - `b(n) = a(n-1) + b(n-1)` (since a sequence ending in 1 can be preceded by either 0 or 1)
   - The total number of valid sequences of length `n` is `a(n) + b(n)`, which follows the Fibonacci sequence shifted by two positions.

2. **Fibonacci Sequence Insight**: The number of valid sequences for length `n` is equivalent to the (n+2)th Fibonacci number. This is derived from the recurrence relations and initial conditions.

3. **Precomputation**: To handle multiple test cases efficiently, we precompute Fibonacci numbers up to the maximum required value using dynamic programming. This allows each query to be answered in constant time.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    test_cases = list(map(int, input[1:T+1]))
    if not test_cases:
        return
    max_n = max(test_cases)
    max_fib = max_n + 2
    fib = [0] * (max_fib + 1)
    if max_fib >= 1:
        fib[1] = 1
    if max_fib >= 2:
        fib[2] = 1
    for i in range(3, max_fib + 1):
        fib[i] = fib[i-1] + fib[i-2]
    for n in test_cases:
        print(fib[n + 2])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Precomputation**: We precompute the Fibonacci numbers up to the maximum required value (determined by the largest test case) to ensure each query can be answered in constant time.
3. **Dynamic Programming**: The Fibonacci sequence is computed iteratively to avoid recursion and handle large values efficiently.
4. **Output**: For each test case, we simply look up the precomputed Fibonacci value at the appropriate position and print it.

This approach ensures that we handle up to the maximum constraint (N = 10^4) efficiently, leveraging the properties of the Fibonacci sequence to solve the problem optimally.
