To solve this problem, we need to determine how closely two words resemble each other by comparing their characters at corresponding positions and counting the number of matches. The solution involves reading multiple test cases and processing each pair of strings to compute their similarity score.

### Approach
1. **Input Reading**: Read the number of test cases, followed by pairs of strings for each test case.
2. **Determine Minimum Length**: For each pair of strings, determine the minimum length between the two strings to limit the comparison to the shortest string.
3. **Character Comparison**: Compare each character at the same position in both strings up to the minimum length, counting the number of matches.
4. **Output the Result**: For each test case, output the count of matching characters.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        A = input[idx].strip()
        B = input[idx+1].strip()
        idx +=2
        min_len = min(len(A), len(B))
        count = 0
        for i in range(min_len):
            if A[i] == B[i]:
                count +=1
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and split into a list for efficient processing. This helps in handling multiple test cases seamlessly.
2. **Processing Each Test Case**: For each test case, we extract the two strings, determine the minimum length to avoid index errors, and compare each character up to that length.
3. **Counting Matches**: For each position in the strings up to the minimum length, we check if the characters match and increment the count accordingly.
4. **Output**: The count of matching characters for each test case is printed immediately after processing the pair.

This approach ensures that we efficiently handle the input and correctly compute the similarity score for each pair of strings, adhering to the problem constraints and requirements.
