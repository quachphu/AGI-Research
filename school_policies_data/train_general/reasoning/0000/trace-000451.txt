To solve this problem, we need to determine if the volumes of juice in the cups could have resulted from either no pouring, exactly one pouring, or neither. The initial state of the cups is that they all contained the same amount of juice, and any pouring must involve transferring an integer amount of juice from one cup to another.

### Approach
1. **Check Sum Divisibility**: First, check if the sum of all the volumes is divisible by the number of cups. If not, it's impossible to have an initial state where all cups had the same amount, so we output "Unrecoverable configuration."
2. **Calculate Initial Volume**: If the sum is divisible, compute the initial volume each cup should have had (sum divided by the number of cups).
3. **Compute Differences**: For each cup, compute the difference between its current volume and the initial volume.
4. **Check Non-zero Differences**: Collect all non-zero differences. The valid scenarios are:
   - **No Non-zero Differences**: All cups are as initially poured, so output "Exemplary pages."
   - **Exactly Two Non-zero Differences**: These must be equal in magnitude but opposite in sign (one positive, one negative). This indicates a single transfer of juice from one cup to another. Check if these differences sum to zero and form a valid transfer, then output the result.
   - **Other Cases**: Output "Unrecoverable configuration."

### Solution Code
```python
n = int(input())
volumes = [int(input()) for _ in range(n)]
sum_vol = sum(volumes)

if sum_vol % n != 0:
    print("Unrecoverable configuration.")
else:
    x = sum_vol // n
    diffs = [v - x for v in volumes]
    non_zero = [d for d in diffs if d != 0]
    
    if not non_zero:
        print("Exemplary pages.")
    elif len(non_zero) == 2:
        a, b = non_zero
        if a + b == 0:
            v = abs(a)
            sources = [i + 1 for i, d in enumerate(diffs) if d == -v]
            dests = [i + 1 for i, d in enumerate(diffs) if d == v]
            if len(sources) == 1 and len(dests) == 1:
                print(f"{v} ml. from cup #{sources[0]} to cup #{dests[0]}.")
            else:
                print("Unrecoverable configuration.")
        else:
            print("Unrecoverable configuration.")
    else:
        print("Unrecoverable configuration.")
```

### Explanation
- **Sum Divisibility Check**: Ensures the initial state is possible.
- **Initial Volume Calculation**: Determines the expected volume each cup should have.
- **Difference Calculation**: Identifies deviations from the initial volume.
- **Non-zero Differences Handling**: Validates the scenario based on the number and nature of deviations, ensuring exactly one valid transfer if possible.

This approach efficiently checks for valid configurations using basic arithmetic and list operations, ensuring correctness and optimal performance given the problem constraints.
