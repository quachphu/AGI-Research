To solve this problem, we need to split an array into contiguous subarrays such that the sum of each subarray is non-zero. If it's impossible to split the array under these constraints, we should output "NO". Otherwise, we need to provide the split points.

### Approach
1. **Check for All Zeros**: If all elements in the array are zero, it's impossible to split the array into non-zero sum subarrays, so we immediately output "NO".
2. **Check Total Sum**: If the total sum of the array is non-zero, we can simply take the entire array as a single valid subarray.
3. **Handle Zero Total Sum**: If the total sum is zero, we need to find the first point where the prefix sum is non-zero. This allows us to split the array into two parts where each part has a non-zero sum.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))

if all(x == 0 for x in a):
    print("NO")
else:
    total = sum(a)
    if total != 0:
        print("YES")
        print(1)
        print(1, n)
    else:
        split_i = 0
        for i in range(1, n + 1):
            current_sum = sum(a[:i])
            if current_sum != 0:
                split_i = i
                break
        print("YES")
        print(2)
        print(1, split_i)
        print(split_i + 1, n)
```

### Explanation
1. **Check All Zeros**: The code first checks if all elements are zero. If true, it prints "NO".
2. **Total Sum Check**: If the sum of the array is non-zero, the entire array is a valid subarray, so we print it as a single segment.
3. **Finding Split Point**: When the total sum is zero, we iterate through the array to find the first prefix sum that is non-zero. This index allows us to split the array into two parts, ensuring each part has a non-zero sum.

This approach efficiently handles all edge cases and ensures the solution is both correct and optimal.
