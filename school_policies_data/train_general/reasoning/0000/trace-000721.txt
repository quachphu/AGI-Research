To solve this problem, we need to determine the total duration of songs played after Niwango fell asleep at the end of a specific song. The solution involves identifying the position of the song after which Niwango fell asleep and summing the durations of all subsequent songs.

### Approach
1. **Read Input**: Read the number of songs, their titles and durations, and the title of the song after which Niwango fell asleep.
2. **Identify the Target Song**: Find the position (index) of the song titled X in the playlist.
3. **Calculate Sleep Duration**: Sum the durations of all songs that come after the identified song in the playlist.

### Solution Code
```python
n = int(input())
songs = []
for _ in range(n):
    s, t = input().split()
    songs.append((s, int(t)))
x = input().strip()

index = next(i for i, (s, _) in enumerate(songs) if s == x)
total = sum(t for s, t in songs[index + 1:])

print(total)
```

### Explanation
1. **Reading Input**: The input is read and stored in a list of tuples where each tuple contains a song title and its duration.
2. **Finding the Target Song**: Using a generator expression with `next`, we efficiently find the index of the song titled X.
3. **Summing Durations**: We sum the durations of all songs starting from the index immediately after the target song to the end of the list. This sum represents the total time Niwango was asleep while songs were playing.

This approach ensures that we efficiently locate the target song and compute the required sum in linear time, which is optimal for the given problem constraints.
