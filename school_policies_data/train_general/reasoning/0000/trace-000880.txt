To solve this problem, we need to determine the outcome of a "Battle of Words" between Alice and Bob. The solution involves analyzing the frequency of each alphabet in their sentences and determining the result based on the remaining alphabets after mutual cancellations.

### Approach
1. **Input Reading**: Read the number of test cases and then read each pair of sentences spoken by Alice and Bob.
2. **Frequency Counting**: For each sentence, count the frequency of each lowercase alphabet (ignoring non-alphabet characters).
3. **Mutual Cancellation**: For each alphabet, compute the remaining counts after mutual cancellations. This is done by subtracting the minimum count of each alphabet in Alice's and Bob's sentences from both.
4. **Result Determination**: Sum the remaining counts for both Alice and Bob. Determine the result based on the remaining counts:
   - Alice wins if she has remaining alphabets and Bob has none.
   - Bob wins if he has remaining alphabets and Alice has none.
   - It's a draw if both have remaining alphabets or both have none.

### Solution Code
```python
import sys
from collections import Counter

def determine_battle_result():
    T = int(sys.stdin.readline())
    for _ in range(T):
        alice_str = sys.stdin.readline().strip()
        bob_str = sys.stdin.readline().strip()
        
        # Count only lowercase letters
        alice_counts = Counter(c for c in alice_str if 'a' <= c <= 'z')
        bob_counts = Counter(c for c in bob_str if 'a' <= c <= 'z')
        
        alice_total = 0
        bob_total = 0
        
        for c in 'abcdefghijklmnopqrstuvwxyz':
            a = alice_counts.get(c, 0)
            b = bob_counts.get(c, 0)
            min_ab = min(a, b)
            alice_total += a - min_ab
            bob_total += b - min_ab
        
        if alice_total > 0 and bob_total == 0:
            print("You win some.")
        elif bob_total > 0 and alice_total == 0:
            print("You lose some.")
        else:
            print("You draw some.")

# Execute the function
determine_battle_result()
```

1. **Reading Input**: The input is read line by line, handling multiple test cases efficiently.
2. **Counting Frequencies**: Using Python's `Counter` from the `collections` module, we count the occurrences of each lowercase letter in both Alice's and Bob's sentences.
3. **Processing Each Alphabet**: For each alphabet (from 'a' to 'z'), we determine the remaining counts after mutual cancellations. This is done by subtracting the minimum count of the alphabet in both sentences from each.
4. **Determining the Result**: After summing the remaining counts for both Alice and Bob, we check the conditions to determine if Alice wins, loses, or the result is a draw.

This approach ensures that we efficiently handle large inputs up to the constraints given, providing the correct result for each test case.
