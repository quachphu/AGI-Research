To solve this problem, we need to determine the minimum number of times JOI must log in to accumulate at least a given number of coins (C) in a social game. Each login grants a certain number of coins (A), and logging in consecutively for a full week (Monday to Sunday) grants an additional bonus (B).

### Approach
The key insight is to recognize that the optimal strategy involves maximizing the number of full consecutive weeks logged in, as each full week provides a significant bonus. The problem can be efficiently solved using binary search to find the minimum number of days (X) such that the total coins accumulated from X logins and the bonuses from full weeks meet or exceed the target coins (C).

1. **Binary Search**: We use binary search to efficiently find the minimum number of days required. The search range is from 0 to a very large upper bound (10^18) to ensure coverage of all possible cases.
2. **Coin Calculation**: For each midpoint in the binary search, calculate the total coins accumulated, considering both the daily coins and the weekly bonuses.

### Solution Code
```python
def main():
    import sys
    A, B, C = map(int, sys.stdin.readline().split())
    
    left = 0
    right = 10**18  # A sufficiently large upper bound
    
    while left < right:
        mid = (left + right) // 2
        total = mid * A + (mid // 7) * B
        if total >= C:
            right = mid
        else:
            left = mid + 1
    print(left)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input values for A (coins per login), B (weekly bonus), and C (target coins) are read from standard input.
2. **Binary Search Setup**: The search range is initialized from 0 to a large number (10^18) to cover all potential cases.
3. **Midpoint Calculation**: For each midpoint value during the binary search, compute the total coins accumulated by considering both the daily login coins and the weekly bonuses.
4. **Adjust Search Range**: Adjust the search range based on whether the current midpoint's total coins meet or exceed the target (C). If it does, narrow the search to find a smaller valid value; otherwise, increase the lower bound.
5. **Result**: The left bound of the search range will eventually converge to the minimum number of days required, which is printed as the result.

This approach efficiently narrows down the possible number of days using binary search, ensuring optimal performance even for large values of C.
