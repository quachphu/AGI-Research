To solve this problem, we need to determine the maximum number of overlapping circular stickers on a square origami paper. Each sticker has a radius of 1 and is placed such that their centers are within the bounds of the paper. The solution involves checking potential points where overlaps could occur, including the centers of the stickers and the intersection points of pairs of stickers.

### Approach
1. **Input Handling**: Read multiple datasets until encountering a dataset with 0 stickers. Each dataset includes the number of stickers followed by their coordinates.
2. **Generate Candidate Points**: For each dataset, generate candidate points which include:
   - Centers of all stickers.
   - Intersection points of every pair of stickers whose centers are within 2 units of each other (since their circles might overlap).
3. **Count Overlaps**: For each candidate point, count how many stickers (circles) include this point within their radius. The maximum count across all candidate points is the result for that dataset.

### Solution Code
```python
import math
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    while True:
        if ptr >= len(input):
            break
        n = int(input[ptr])
        ptr += 1
        if n == 0:
            break
        centers = []
        for _ in range(n):
            line = input[ptr]
            x_str, y_str = line.split(',')
            x = float(x_str)
            y = float(y_str.strip())
            centers.append((x, y))
            ptr += 1
        # Generate all candidate points
        candidates = list(centers)  # Start with all centers
        # Add intersection points of all pairs with distance <= 2
        for i in range(n):
            x1, y1 = centers[i]
            for j in range(i + 1, n):
                x2, y2 = centers[j]
                dx = x2 - x1
                dy = y2 - y1
                d_sq = dx ** 2 + dy ** 2
                if d_sq > 4.0:
                    continue
                d = math.sqrt(d_sq)
                if d == 0:
                    continue  # Impossible per problem statement
                h_sq = 1.0 - (d / 2.0) ** 2
                h = math.sqrt(h_sq)
                mid_x = (x1 + x2) / 2.0
                mid_y = (y1 + y2) / 2.0
                # Compute delta_x and delta_y components
                delta_x = (-dy * h) / d
                delta_y = (dx * h) / d
                # First intersection point
                p1x = mid_x + delta_x
                p1y = mid_y + delta_y
                candidates.append((p1x, p1y))
                # Second intersection point
                p2x = mid_x - delta_x
                p2y = mid_y - delta_y
                candidates.append((p2x, p2y))
        max_count = 0
        epsilon = 1e-8
        for (x, y) in candidates:
            count = 0
            for (cx, cy) in centers:
                dx = x - cx
                dy = y - cy
                dist_sq = dx ** 2 + dy ** 2
                if dist_sq <= 1.0 + epsilon:
                    count += 1
            if count > max_count:
                max_count = count
        print(max_count)

if __name__ == "__main__":
    main()
```

3. **Counting Overlaps**: Each candidate point is checked against all sticker centers to count how many stickers include this point within their radius. The maximum count is tracked and printed for each dataset.

This approach efficiently checks potential overlap points, ensuring that we consider both the centers of the stickers and their intersections, leading to an accurate solution.
