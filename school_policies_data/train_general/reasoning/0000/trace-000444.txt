To solve this problem, we need to determine the minimum number of artists that should be killed to ensure that no artists are present in the room when Ilia-alpinist calls. The key insight is to identify the overlapping times when both Ilia's calls and artists' visits occur simultaneously.

### Approach
1. **Understanding Overlapping Times**: The problem can be reduced to finding the times that are multiples of both Ilia's call interval (n) and the artists' visit interval (m). These overlapping times are the least common multiples (LCM) of n and m.
2. **Calculate LCM**: The LCM of two numbers can be efficiently calculated using their greatest common divisor (GCD). The formula for LCM is \( \text{LCM}(n, m) = \frac{n \times m}{\text{GCD}(n, m)} \).
3. **Count Multiples**: Once we have the LCM, we need to count how many multiples of this LCM exist within the duration of the day (z minutes). This count gives the number of times artists need to be killed.

### Solution Code
```python
import math

def main():
    n, m, z = map(int, input().split())
    gcd = math.gcd(n, m)
    lcm = (n * m) // gcd
    print(z // lcm)

main()
```

### Explanation
1. **Reading Input**: The input consists of three integers: n (Ilia's call interval), m (artists' visit interval), and z (duration of the day).
2. **Calculate GCD and LCM**: Using Python's `math.gcd` function, we compute the greatest common divisor (GCD) of n and m. The LCM is then derived using the formula involving GCD.
3. **Determine Overlapping Count**: The number of overlapping times within the day duration z is found by integer division of z by the LCM. This gives the count of times when both events coincide, which is the number of artists that need to be killed.

This approach efficiently computes the required result using mathematical properties of GCD and LCM, ensuring optimal performance even for the upper constraint values.
