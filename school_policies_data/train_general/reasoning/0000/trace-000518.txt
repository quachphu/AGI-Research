To solve this problem, we need to determine if a given permutation corresponds to a valid parentheses string. If it does, we generate the string; otherwise, we output `:(`.

### Approach
The key insight is to treat the permutation as a sequence of indices indicating which opening parenthesis each closing parenthesis matches. We simulate the process of building the parentheses string using a stack to ensure that each closing parenthesis correctly matches the most recent unmatched opening parenthesis. Here's the detailed approach:

1. **Simulate Stack Operations**: Use a stack to keep track of the indices of opening parentheses. For each closing parenthesis in the given permutation, check if it matches the top of the stack (i.e., the most recent opening parenthesis that hasn't been closed yet).
2. **Check Validity**: If at any point the required closing parenthesis does not match the top of the stack, the permutation is invalid. Additionally, ensure that all opening parentheses are properly closed by the end of the permutation.

### Solution Code

def main():

    input = sys.stdin.read().split()
    n = int(input[0])
    p = list(map(int, input[1:n+1]))

                break
            stack.append(current)

            current += 1

### Explanation
1. **Reading Input**: The input consists of an integer `n` followed by a permutation of integers from 1 to `n`.
2. **Stack Simulation**: We use a stack to simulate the process of opening and closing parentheses. For each element in the permutation (representing a closing parenthesis), we check if it can be matched with the most recent opening parenthesis (top of the stack). If not, we push more opening parentheses onto the stack until we can match the current closing parenthesis.
3. **Validity Check**: If we exhaust all possible opening parentheses without matching the current closing parenthesis, the permutation is invalid. After processing all elements, if the stack is empty, the permutation is valid, and we output the constructed string; otherwise, we output `:(`.
