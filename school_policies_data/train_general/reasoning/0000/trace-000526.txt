To solve this problem, we need to determine the minimal possible number of stones in Vasya's pile after he performs a series of operations, ensuring that the pile is never empty before any '-' operation. 

### Approach
1. **Prefix Sum Calculation**: Compute the prefix sum of operations to track the cumulative effect of each operation step-by-step.
2. **Constraints Handling**: For each '-' operation, determine the minimum initial stones required to ensure the pile is non-empty before that operation.
3. **Determine Minimum Initial Stones**: Calculate the maximum value of the required initial stones from the constraints, ensuring it is non-negative.
4. **Final Calculation**: Compute the final number of stones by adding the initial stones to the total sum of all operations.

### Solution Code
```python
n = int(input())
s = input().strip()

sum_up_to = [0] * (n + 1)
for i in range(1, n + 1):
    op = s[i - 1]
    sum_up_to[i] = sum_up_to[i - 1] + (1 if op == '+' else -1)

required_x = []
for i in range(n):
    if s[i] == '-':
        required_x.append(1 - sum_up_to[i])

max_required = max(required_x) if required_x else 0
x = max(max_required, 0)
print(x + sum_up_to[n])
```

### Explanation
1. **Prefix Sum Calculation**: The `sum_up_to` array is built to keep track of the cumulative sum of operations up to each step. This helps in determining the state of the pile before each operation.
2. **Constraints Handling**: For each '-' operation, we calculate the minimum initial stones required to keep the pile non-empty before that operation. This is done by checking the prefix sum up to the previous step and ensuring the initial stones plus this sum is at least 1.
3. **Determine Minimum Initial Stones**: The maximum value from the constraints gives the minimum initial stones required. If there are no '-' operations, the initial stones can be zero.
4. **Final Calculation**: The final number of stones is computed by adding the determined initial stones to the total sum of all operations, which gives the minimal possible stones after all operations.

This approach efficiently tracks the necessary constraints and ensures the solution is both optimal and correct.
