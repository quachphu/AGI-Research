To solve this problem, we need to determine if a ninja can escape a canyon by moving up, down, or jumping between two walls while avoiding dangerous areas and rising water levels. The solution involves using a breadth-first search (BFS) approach to explore all possible moves the ninja can make while keeping track of the earliest time each position is reached to ensure efficiency.

### Approach
1. **Problem Analysis**: The canyon consists of two vertical walls with safe and dangerous areas. The ninja starts at the bottom of the left wall and must escape by moving up, down, or jumping to the opposite wall. The water level rises each second, and the ninja cannot be submerged. The goal is to check if the ninja can escape before being trapped by the rising water.

2. **BFS Approach**: Use BFS to explore all possible moves the ninja can make. Each state in the BFS is represented by the current wall, position, and time. The BFS ensures that we explore the shortest path (earliest time) to each position, which helps in efficiently determining if an escape is possible.

3. **State Tracking**: Track the earliest time each position on either wall is visited. This helps in avoiding redundant checks and ensures that we only process each state once with the minimum time required.

4. **Move Validation**: For each move, check if the new position is safe, not submerged, and hasn't been visited earlier. If the new position exceeds the canyon height, the ninja escapes.

import sys
from collections import deque

def main():
    n, k = map(int, sys.stdin.readline().split())
    left_wall = sys.stdin.readline().strip()
    right_wall = sys.stdin.readline().strip()

    left_safe = [False] * (n + 2)
    right_safe = [False] * (n + 2)
    for i in range(n):
        left_safe[i+1] = (left_wall[i] == '-')
        right_safe[i+1] = (right_wall[i] == '-')

    left_time = [n + 2] * (n + 2)
    right_time = [n + 2] * (n + 2)
    left_time[1] = 0
    q = deque()
    q.append((0, 1, 0))  # (left_wall (0), position 1, time 0)

    found = False

    while q:
        wall, x, t = q.popleft()

        # Check if current position is out of bounds (escape)
        if x > n:
            print("YES")
            return

        # Validate current state if within bounds
        if x <= n:
            # Check if current position is safe and not submerged
            if (wall == 0 and not left_safe[x]) or (wall == 1 and not right_safe[x]):
                continue
            if x <= t:
                continue

        # Generate all possible moves
        # Move up
        new_x = x + 1
        new_t = t + 1
        new_wall = wall
        if new_x > n:
            print("YES")
            return
        if new_x <= n:
            if (new_wall == 0 and left_safe[new_x]) or (new_wall == 1 and right_safe[new_x]):
                if new_x > new_t:
                    if new_wall == 0:
                        if left_time[new_x] > new_t:
                            left_time[new_x] = new_t
                            q.append((new_wall, new_x, new_t))
                    else:
                        if right_time[new_x] > new_t:
                            right_time[new_x] = new_t
                            q.append((new_wall, new_x, new_t))

        # Move down
        new_x = x - 1
        if new_x >= 1:
            new_t = t + 1
            new_wall = wall
            if (new_wall == 0 and left_safe[new_x]) or (new_wall == 1 and right_safe[new_x]):
                if new_x > new_t:
                    if new_wall == 0:
                        if left_time[new_x] > new_t:
                            left_time[new_x] = new_t
                            q.append((new_wall, new_x, new_t))
                    else:
                        if right_time[new_x] > new_t:
                            right_time[new_x] = new_t
                            q.append((new_wall, new_x, new_t))

        # Jump to the other wall
        new_x = x + k
        new_t = t + 1
        new_wall = 1 - wall  # switch walls
        if new_x > n:
            print("YES")
            return
        if new_x <= n:
            if (new_wall == 0 and left_safe[new_x]) or (new_wall == 1 and right_safe[new_x]):
                if new_x > new_t:
                    if new_wall == 0:
                        if left_time[new_x] > new_t:

                    else:
                        if right_time[new_x] > new_t:
                            right_time[new_x] = new_t
                            q.append((new_wall, new_x, new_t))

    print("NO")

if __name__ == "__main__":
