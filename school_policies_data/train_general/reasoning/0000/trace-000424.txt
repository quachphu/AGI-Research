### Approach
1. **Problem Analysis**: The task is to find the highest and second highest scores from a list. The key challenge is to handle cases where multiple students might have the same highest score, which means the second highest score could be the same as the highest.
2. **Algorithm Selection**: We will use a single-pass approach to iterate through the list of scores while maintaining two variables to track the highest and second highest scores. This ensures an O(n) time complexity, which is efficient for large input sizes.
3. **Handling Duplicates**: By updating the second highest score whenever we encounter a score equal to the current highest, we correctly handle cases where multiple students have the same top score.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    scores = list(map(int, input[1:n+1]))
    
    first = second = -float('inf')
    for num in scores:
        if num > first:
            second = first
            first = num
        elif num == first:
            second = first
        elif num > second:
            second = num
    print(first, second)

main()
```

### Explanation
1. **Reading Input**: The input is read in one go using `sys.stdin.read()` for efficiency, especially with large input sizes. The input is split into a list of strings, which is then converted into integers.
2. **Initialization**: Two variables, `first` and `second`, are initialized to negative infinity to handle any possible score values.
3. **Iterating Through Scores**: For each score:
   - If the score is higher than the current highest (`first`), update `second` to be the old `first` and set `first` to the new score.
   - If the score is equal to `first`, update `second` to `first` to handle duplicates.
   - If the score is between `second` and `first`, update `second` to this score.
4. **Output**: Finally, print the highest and second highest scores.

This approach ensures that we efficiently determine the top two scores in a single pass through the list, making it both time and space efficient.
