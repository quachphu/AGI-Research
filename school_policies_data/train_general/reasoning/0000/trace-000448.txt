To solve this problem, we need to efficiently determine the characteristics of creatures created through a series of operations involving maximum and minimum values of existing creatures' characteristics. The solution involves recursively computing the required characteristic for each query based on the creation history of the creatures.

### Approach
1. **Data Structures**: Store the initial creatures' characteristics and track the operations used to create new creatures.
2. **Recursive Calculation with Memoization**: For each query requesting a specific characteristic of a creature, recursively compute the value by traversing the creature's creation history. Use memoization to cache intermediate results and avoid redundant computations.

### Solution Code
```python
import sys
from sys import stdin

def main():
    sys.setrecursionlimit(1 << 25)
    n, k, q = map(int, stdin.readline().split())
    original = []
    for _ in range(k):
        original.append(list(map(int, stdin.readline().split())))
    
    creatures = []
    output = []
    
    for _ in range(q):
        parts = stdin.readline().split()
        t = int(parts[0])
        if t == 1 or t == 2:
            x = int(parts[1]) - 1  # convert to 0-based
            y = int(parts[2]) - 1
            creatures.append((t, x, y))
        elif t == 3:
            xi = int(parts[1]) - 1  # 0-based creature index
            yi = int(parts[2]) - 1  # 0-based characteristic index
            memo = {}
            def get_value(x, j):
                if (x, j) in memo:
                    return memo[(x, j)]
                if x < k:
                    val = original[x][j]
                    memo[(x, j)] = val
                    return val
                else:
                    # x is a new creature, index in creatures is x - k
                    op, a, b = creatures[x - k]
                    a_val = get_value(a, j)
                    b_val = get_value(b, j)
                    if op == 1:
                        res = max(a_val, b_val)
                    else:
                        res = min(a_val, b_val)
                    memo[(x, j)] = res
                    return res
            result = get_value(xi, yi)
            output.append(str(result))
    
    print('\n'.join(output))

if __name__ == "__main__":
    main()
```
