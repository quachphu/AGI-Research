To solve this problem, we need to compute the sum of XOR values between all pairs of integers in an array efficiently. Given the constraints, a brute-force approach is infeasible, so we use a bitwise optimization technique.

### Approach
1. **Bitwise Contribution Analysis**: For each bit position (0 to 59), determine how many pairs of numbers have different bits at that position. The XOR of two numbers at a bit position is 1 if the bits are different, contributing \(2^{\text{bit position}}\) to the sum for each such pair.
2. **Count Set Bits**: For each bit position, count how many numbers have that bit set. Let this count be \(m\). The number of pairs with differing bits at this position is \(m \times (N - m)\).
3. **Modular Arithmetic**: Since the result can be very large, compute all values modulo \(10^9 + 7\). Precompute powers of 2 modulo \(10^9 + 7\) for efficiency.

### Solution Code
```python
MOD = 10**9 + 7

def main():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    A = list(map(int, input[1:N+1]))
    
    bits_count = [0] * 60
    for a in A:
        for k in range(60):
            if (a >> k) & 1:
                bits_count[k] += 1
    
    pow2 = [1] * 60
    for k in range(1, 60):
        pow2[k] = (pow2[k-1] * 2) % MOD
    
    total = 0
    for k in range(60):
        m = bits_count[k]
        term = m * (N - m)
        term %= MOD
        term = term * pow2[k] % MOD
        total = (total + term) % MOD
    
    print(total % MOD)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into an integer \(N\) and a list of integers \(A\).
2. **Counting Bits**: For each number in the array, check each bit position (0 to 59) and count how many numbers have each bit set.
3. **Precompute Powers of 2**: Precompute \(2^k \mod (10^9 + 7)\) for all relevant bit positions to avoid repeated calculations.
4. **Calculate Contributions**: For each bit position, compute the number of pairs with differing bits, multiply by the corresponding power of 2, and accumulate the result modulo \(10^9 + 7\).
5. **Output Result**: Print the total sum modulo \(10^9 + 7\).

This approach efficiently reduces the problem complexity from \(O(N^2)\) to \(O(N \log \text{MAX_VALUE})\), making it feasible for large input sizes.
