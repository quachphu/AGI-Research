To solve this problem, we need to determine how many people are currently in the library based on the log entries of names. Each entry in the log represents a person either entering or leaving the library. The solution involves tracking the presence of each person using a set data structure to efficiently toggle their presence status.

### Approach
1. **Read Input Efficiently**: Read all input at once and split it into tokens for efficient processing.
2. **Track Presence with a Set**: Use a set to keep track of people currently in the library. For each name encountered:
   - If the name is already in the set, remove it (indicating the person has left).
   - If the name is not in the set, add it (indicating the person has entered).
3. **Process Each Test Case**: For each test case, process all names and use the set to determine the number of people remaining in the library after all entries.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        n = int(input[ptr])
        ptr += 1
        present = set()
        for _ in range(n):
            name = input[ptr]
            ptr += 1
            if name in present:
                present.remove(name)
            else:
                present.add(name)
        print(len(present))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of tokens. This allows efficient processing, especially for large input sizes.
2. **Tracking Presence**: A set is used to track people currently in the library. Each time a name is encountered, the set is checked. If the name is present, it is removed (indicating the person left), otherwise, it is added (indicating the person entered).
3. **Efficiency**: The use of a set ensures that each insertion and deletion operation is average O(1), making the solution efficient even for the upper constraint of 50,000 names per test case.

This approach ensures that we efficiently determine the number of people in the library by the end of each test case using optimal data structures and methods.
