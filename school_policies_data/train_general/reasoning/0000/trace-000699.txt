To solve this problem, we need to select a subset of fruits such that the ratio of their total taste to total calories equals a given value \( k \). Our goal is to maximize the total taste of the selected fruits while ensuring the ratio constraint is met.

### Approach
1. **Problem Analysis**:
   - The ratio constraint can be rewritten as the sum of taste values minus \( k \) times the sum of calories equals zero. This transformation simplifies the problem into finding a subset where this adjusted sum is zero.
   - Each fruit contributes an adjusted value \( c_i = a_i - k \times b_i \), where \( a_i \) is the taste and \( b_i \) is the calorie count of the fruit. We need the sum of these adjusted values for the selected subset to be zero.

2. **Dynamic Programming (DP) Approach**:
   - Use a dictionary to track the maximum possible taste sum for each possible adjusted sum value.
   - Initialize the DP with the sum of an empty subset (0 taste sum).
   - For each fruit, update the DP by considering both including and excluding the fruit, ensuring we keep the maximum taste sum for each adjusted sum.

3. **Complexity Consideration**:
   - The number of possible adjusted sums is manageable due to the constraints (n ≤ 100, each \( c_i \) ranges between -999 and 90), allowing efficient use of a dictionary-based DP approach.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))
b = list(map(int, input().split()))
c = [a[i] - k * b[i] for i in range(n)]

dp = {0: 0}

for i in range(n):
    current_c = c[i]
    current_a = a[i]
    temp_dp = {}
    for s in dp:
        # Option 1: not take the current fruit
        if s in temp_dp:
            if dp[s] > temp_dp[s]:
                temp_dp[s] = dp[s]
        else:
            temp_dp[s] = dp[s]
        # Option 2: take the current fruit
        new_s = s + current_c
        new_a = dp[s] + current_a
        if new_s in temp_dp:
            if new_a > temp_dp[new_s]:
                temp_dp[new_s] = new_a
        else:
            temp_dp[new_s] = new_a
    dp = temp_dp

if 0 in dp and dp[0] > 0:
    print(dp[0])
else:
    print(-1)
```

1. **Reading Input**:
   - Read the number of fruits \( n \) and the ratio \( k \).
   - Read the taste values and calorie values of each fruit.

2. **Adjusted Value Calculation**:
   - Compute the adjusted value \( c_i \) for each fruit, which simplifies the ratio constraint into a sum problem.

3. **Dynamic Programming Initialization**:
   - Start with a dictionary `dp` where the key is the adjusted sum and the value is the maximum taste sum. Initialize with the empty subset (sum 0, taste 0).

4. **Processing Each Fruit**:
   - For each fruit, update the DP dictionary by considering both including and excluding the fruit. Track the maximum taste sum for each possible adjusted sum.

5. **Result Check**:
   - After processing all fruits, check if there's a valid subset (non-empty) that meets the ratio constraint. If found, print the maximum taste sum; otherwise, print -1.

This approach efficiently explores all possible subsets using dynamic programming, ensuring we maximize the taste sum while adhering to the given constraint.
