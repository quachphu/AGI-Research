To solve this problem, we need to determine the minimum cost to cover all white squares (.) in a grid using 1x1 or 1x2 tiles. The solution involves evaluating each row of the grid to find the optimal combination of tiles that minimizes the total cost.

### Approach
1. **Input Reading**: Read the number of test cases. For each test case, read the grid dimensions, costs of the tiles, and the grid itself.
2. **Segmentation**: For each row in the grid, identify contiguous segments of white squares separated by black squares (*).
3. **Cost Calculation**: For each segment of white squares:
   - If using a 1x2 tile is cheaper than two 1x1 tiles, calculate the cost using as many 1x2 tiles as possible, plus a 1x1 tile if there's an odd number of squares.
   - Otherwise, use only 1x1 tiles.
4. **Summing Costs**: Sum the costs for all segments across all rows to get the total minimum cost for each test case.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n, m, x, y = map(int, sys.stdin.readline().split())
        total = 0
        for _ in range(n):
            row = sys.stdin.readline().strip()
            segments = []
            current = 0
            for c in row:
                if c == '.':
                    current += 1
                else:
                    if current > 0:
                        segments.append(current)
                        current = 0
            if current > 0:
                segments.append(current)
            for k in segments:
                if y < 2 * x:
                    cost = (k // 2) * y + (k % 2) * x
                else:
                    cost = k * x
                total += cost
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
- **Segmentation**: Each row is processed to identify contiguous white square segments. This is done by iterating through each character and counting consecutive '.' characters.
- **Cost Calculation**: For each segment, the cost is determined based on whether using 1x2 tiles is more economical than using 1x1 tiles. If a 1x2 tile is cheaper than two 1x1 tiles, we use as many 1x2 tiles as possible and handle any remaining square with a 1x1 tile. Otherwise, we use only 1x1 tiles.
- **Efficiency**: The solution efficiently processes each row and segment, ensuring that the total operations remain within acceptable limits given the problem constraints.

This approach ensures that we minimize the cost by optimally choosing between 1x1 and 1x2 tiles for each segment of white squares, leading to an optimal solution.
