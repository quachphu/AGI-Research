To solve this problem, we need to determine the width and height of an artwork made up of squares placed according to specific instructions. Each square is placed adjacent to a previously placed square in one of four directions (left, down, right, up). The goal is to compute the minimum bounding box that contains all the squares.

### Approach
1. **Model the Positions**: Track the coordinates of each square as they are placed. The first square is placed at the origin (0, 0).
2. **Process Each Instruction**: For each subsequent square, determine its position based on the direction relative to the referenced square (ni). Update the coordinates accordingly.
3. **Determine Bounds**: After placing all squares, find the minimum and maximum x and y coordinates across all squares.
4. **Calculate Dimensions**: The width and height are derived from the difference between the maximum and minimum coordinates plus one (since each square is 1x1).

### Solution Code
```python
import sys

def calculate_dimensions():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        N = int(line)
        if N == 0:
            break
        positions = [(0, 0)]  # Position of square 0 is (0, 0)
        if N == 1:
            print("1 1")
            continue
        for _ in range(N - 1):
            parts = sys.stdin.readline().split()
            ni = int(parts[0])
            di = int(parts[1])
            x_ni, y_ni = positions[ni]
            if di == 0:
                new_x, new_y = x_ni - 1, y_ni
            elif di == 1:
                new_x, new_y = x_ni, y_ni - 1
            elif di == 2:
                new_x, new_y = x_ni + 1, y_ni
            else:  # di == 3
                new_x, new_y = x_ni, y_ni + 1
            positions.append((new_x, new_y))
        x_coords = [x for x, y in positions]
        y_coords = [y for x, y in positions]
        min_x, max_x = min(x_coords), max(x_coords)
        min_y, max_y = min(y_coords), max(y_coords)
        width = max_x - min_x + 1
        height = max_y - min_y + 1
        print(f"{width} {height}")

calculate_dimensions()
```

### Explanation
- **Reading Input**: The input is read line by line. Each dataset starts with an integer N, followed by N-1 placement instructions.
- **Tracking Positions**: The first square is placed at (0, 0). Each subsequent square's position is determined based on the direction relative to a previously placed square.
- **Direction Handling**: Directions are mapped to coordinate changes (left decreases x, right increases x, down decreases y, up increases y).
- **Bounds Calculation**: After processing all instructions, the minimum and maximum x and y coordinates are found. The width and height are computed from these bounds.

This approach efficiently tracks the positions of each square and calculates the required dimensions using straightforward arithmetic, ensuring correctness and optimal performance for the given constraints.
