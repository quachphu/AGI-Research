To solve this problem, we need to determine if the input string contains the subsequence 'heidi'. A subsequence means that the characters of 'heidi' must appear in order, but not necessarily consecutively. 

### Approach
The approach involves iterating through the input string and checking if we can sequentially find each character of the target string 'heidi'. Here are the steps:

1. **Initialize a pointer** for the target string 'heidi' starting at 0.
2. **Iterate through each character** in the input string.
   - If the current character matches the current target character (as indicated by the pointer), move the pointer to the next character in the target string.
   - If the pointer reaches the end of the target string, break out of the loop early as we've found all characters in order.
3. After processing all characters, check if the pointer has reached the end of the target string. If yes, print "YES"; otherwise, print "NO".

This method ensures we efficiently check for the subsequence in a single pass through the input string.

### Solution Code
```python
def main():
    s = input().strip()
    target = 'heidi'
    current = 0
    for c in s:
        if current < len(target) and c == target[current]:
            current += 1
            if current == len(target):
                break
    print("YES" if current == len(target) else "NO")

main()
```

### Explanation
- **Reading Input**: The input string is read from standard input.
- **Target Initialization**: The target subsequence 'heidi' is defined, and a pointer `current` is initialized to track progress through this target.
- **Iterating Through Characters**: For each character in the input string, we check if it matches the current character in the target. If it does, we move the pointer to the next character in the target.
- **Early Termination**: If at any point the pointer reaches the end of the target string, we break out of the loop early to avoid unnecessary checks.
- **Result Determination**: After processing all characters, we check if the pointer has reached the end of the target string. If it has, the input string contains 'heidi' as a subsequence, and we print "YES"; otherwise, we print "NO".

This approach efficiently checks for the subsequence with a time complexity of O(n), where n is the length of the input string, ensuring optimal performance even for the maximum input size.
