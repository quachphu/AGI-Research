To solve this problem, we need to find the intersection of two sorted sets efficiently. The intersection elements should be printed in ascending order. Given the constraints, we need an optimal approach to ensure the solution is efficient even for large input sizes.

### Approach
The optimal approach to solve this problem is using the two-pointer technique. This method leverages the fact that both input arrays are sorted. By maintaining two pointers, one for each array, we can traverse both arrays simultaneously and compare elements to find the intersection efficiently.

1. **Initialize Pointers**: Start two pointers, one at the beginning of each array.
2. **Compare Elements**: 
   - If the elements at both pointers are equal, add the element to the result and move both pointers forward.
   - If the element in the first array is smaller, move the pointer in the first array forward.
   - If the element in the second array is smaller, move the pointer in the second array forward.
3. **Termination**: The process continues until one of the pointers reaches the end of its respective array.

This approach ensures that each element is checked at most once, leading to a time complexity of O(n + m), where n and m are the lengths of the two arrays.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    a = list(map(int, input[ptr:ptr + n]))
    ptr += n
    m = int(input[ptr])
    ptr += 1
    b = list(map(int, input[ptr:ptr + m]))
    
    res = []
    i = j = 0
    while i < n and j < m:
        if a[i] == b[j]:
            res.append(a[i])
            i += 1
            j += 1
        elif a[i] < b[j]:
            i += 1
        else:
            j += 1
    for num in res:
        print(num)

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into tokens for efficient processing. This helps in quickly accessing the elements of both arrays.
2. **Two-Pointer Technique**: By initializing two pointers, `i` for the first array and `j` for the second, we compare elements and move the pointers based on the comparison results. This ensures we only traverse each array once.
3. **Result Collection**: Common elements are collected in a list and printed line by line after processing both arrays.

This method efficiently finds the intersection of two sorted arrays with a linear time complexity, making it suitable for large input sizes up to 200,000 elements.
