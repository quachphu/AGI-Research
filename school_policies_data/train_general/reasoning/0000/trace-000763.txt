### Approach
1. **Combinatorial Paths Calculation**: The number of paths from (1,1) to (h,w) without any obstacles is given by the binomial coefficient C(h+w-2, h-1) modulo 10^9 + 7.
2. **Inclusion-Exclusion Principle**: Subtract paths that pass through any black cell. For each black cell, compute the number of valid paths to that cell and from there to the end, then subtract these from the total.
3. **Dynamic Programming on Black Cells**: Sort black cells by their coordinates to ensure we process them in an order where each cell is only processed after all cells that could precede it in any valid path. Compute the number of paths to each black cell that avoid other black cells using dynamic programming.

### Solution Code
```python
MOD = 10**9 + 7

h, w, n = map(int, input().split())
black = [tuple(map(int, input().split())) for _ in range(n)]

# Sort the blocked cells by (r + c), then by r
black.sort(key=lambda x: (x[0] + x[1], x[0]))

# Precompute factorial and inverse factorial modulo MOD up to 2e5
max_n = 2 * 10**5 + 10
fact = [1] * (max_n + 1)
for i in range(1, max_n + 1):
    fact[i] = fact[i-1] * i % MOD

inv_fact = [1] * (max_n + 1)
inv_fact[max_n] = pow(fact[max_n], MOD - 2, MOD)
for i in range(max_n - 1, -1, -1):
    inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

def comb(n, k):
    if n < 0 or k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % MOD * inv_fact[n - k] % MOD

total = comb(h + w - 2, h - 1)
sum_contributions = 0
dp = []

for i in range(len(black)):
    r, c = black[i]
    ways = comb(r + c - 2, r - 1)
    for j in range(i):
        pr, pc = black[j]
        if pr <= r and pc <= c:
            dr = r - pr
            dc = c - pc
            ways = (ways - dp[j] * comb(dr + dc, dr)) % MOD
    # Contribution of this cell to the total
    cont = ways * comb((h - r) + (w - c), h - r) % MOD
    sum_contributions = (sum_contributions + cont) % MOD
    dp.append(ways)

ans = (total - sum_contributions) % MOD
print(ans)
```

2. **Sort Black Cells**: Black cells are sorted to ensure we process them in the order they would appear in any valid path from the start to the end.
3. **Dynamic Programming on Black Cells**: For each black cell, compute the number of paths to it that avoid other black cells. This is done by subtracting paths that pass through previously processed black cells.
4. **Subtract Invalid Paths**: For each black cell, compute the number of paths that pass through it and subtract these from the total valid paths.

This approach efficiently handles the constraints and ensures we correctly account for all valid paths while avoiding blocked cells.
