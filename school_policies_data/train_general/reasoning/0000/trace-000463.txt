To solve this problem, we need to determine the largest square composed entirely of unmarked squares (represented by '.') in a given grid. The solution involves using dynamic programming (DP) to efficiently compute the maximum size of such a square.

### Approach
1. **Input Reading**: Read the grid dimensions and the grid itself. The grid is read as a binary matrix where '.' is converted to 1 (unmarked) and '*' is converted to 0 (marked).
2. **Dynamic Programming Setup**: Create a DP table where each entry `dp[i][j]` represents the side length of the largest square ending at cell `(i, j)`.
3. **DP Table Computation**:
   - For each cell `(i, j)`, if the cell is unmarked (1), compute the value of `dp[i][j]` based on the minimum value of its neighboring cells (top, left, and top-left) plus 1. This ensures that the current cell can form a square with the neighboring cells.
   - Track the maximum value encountered in the DP table, which gives the side length of the largest square of unmarked cells.

### Solution Code
```python
import sys

def main():
    while True:
        line = sys.stdin.readline()
        if not line:
            break
        n = int(line.strip())
        if n == 0:
            break
        grid = []
        for _ in range(n):
            row_line = sys.stdin.readline().strip()
            grid_row = [1 if c == '.' else 0 for c in row_line]
            grid.append(grid_row)
        
        max_side = 0
        dp = [[0] * n for _ in range(n)]
        
        for i in range(n):
            for j in range(n):
                if grid[i][j] == 1:
                    if i == 0 or j == 0:
                        dp[i][j] = 1
                    else:
                        dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
                    if dp[i][j] > max_side:
                        max_side = dp[i][j]
                else:
                    dp[i][j] = 0
        print(max_side)

if __name__ == "__main__":
    main()
```

### Explanation
- **Input Handling**: The code reads multiple datasets until it encounters a line with `n = 0`. Each dataset starts with an integer `n` followed by `n` lines of the grid.
- **Binary Grid Conversion**: Each grid line is converted into a list of integers where '.' becomes 1 and '*' becomes 0.
- **Dynamic Programming Table**: The DP table is filled by iterating over each cell. For each cell `(i, j)`, if the cell is unmarked, the DP value is determined based on the minimum of the three neighboring cells (top, left, top-left) plus 1. This ensures that the current cell can form the largest possible square with the cells around it.
- **Result Calculation**: The maximum value in the DP table is tracked and printed as the result for each dataset, representing the side length of the largest square of unmarked cells.

This approach efficiently computes the solution in O(n^2) time and space complexity, making it suitable for the given constraints.
