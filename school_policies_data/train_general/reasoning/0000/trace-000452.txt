To solve this problem, we need to determine the actual distance Benny traveled based on the broken odometer readings, which skip any number containing the digit 3. The solution involves converting the displayed number into a base-9 number, adjusting each digit to account for the skipped numbers.

### Approach
1. **Understanding the Odometer**: The odometer skips any number containing the digit 3. Therefore, each digit in the displayed number can be thought of as a digit in a base-9 system, where digits 4-9 are adjusted to 3-8 respectively.
2. **Conversion Process**: For each digit in the displayed number:
   - If the digit is greater than 3, subtract 1 to adjust for the skipped digit 3.
   - Convert the adjusted digits from base-9 to base-10 to get the actual distance.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    cases = input[1:T+1]
    for n_str in cases:
        res = 0
        for c in n_str:
            d = int(c)
            if d > 3:
                d -= 1
            res = res * 9 + d
        print(res)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints where the number of test cases can be very large (up to 100,000).
2. **Processing Each Test Case**: For each test case:
   - Convert the number to a string to process each digit individually.
   - Adjust each digit by subtracting 1 if it is greater than 3.
   - Convert the adjusted digits from base-9 to base-10 by iterating through each digit and accumulating the result.
3. **Output**: The result for each test case is printed immediately after processing.

This approach efficiently converts each displayed number to the actual distance using arithmetic operations that run in linear time relative to the number of digits, ensuring optimal performance even for large inputs.
