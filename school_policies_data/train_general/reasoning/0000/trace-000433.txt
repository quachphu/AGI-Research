To solve this problem, we need to determine the minimum number of characters to remove from a given string such that no forbidden adjacent pairs of characters remain. Each forbidden pair is unordered and each character can only be part of at most one forbidden pair.

### Approach
The solution uses dynamic programming (DP) to efficiently track the minimum number of deletions required up to each character in the string. The key idea is to maintain a DP state where each state represents the minimum deletions needed up to the current character, considering the last character kept in the processed string.

1. **Forbidden Pairs Setup**: We first parse the forbidden pairs into a dictionary for quick lookup. This helps in checking if two adjacent characters form a forbidden pair in constant time.

2. **Dynamic Programming Initialization**: We initialize a DP dictionary where the key is the last character kept (or `None` if no character is kept) and the value is the minimum deletions required to reach that state.

3. **Processing Each Character**: For each character in the string, we consider two options:
   - **Delete the current character**: This increments the deletion count but keeps the previous state unchanged.
   - **Keep the current character**: This checks if the current character and the previous character (from the DP state) form a forbidden pair. If they do, this transition is invalid. Otherwise, we update the DP state with the current character as the new last character.

4. **Update DP States**: After processing each character, we update the DP states to reflect the minimum deletions required for each possible new state.

5. **Result Extraction**: The minimum value in the final DP states gives the answer, as it represents the smallest number of deletions required to process the entire string without any forbidden adjacent pairs.

### Solution Code
```python
s = input().strip()
k = int(input())

forbidden = {}
for _ in range(k):
    pair = input().strip()
    a, b = pair[0], pair[1]
    forbidden[a] = b
    forbidden[b] = a

prev_dp = {None: 0}

for c in s:
    curr_dp = {}
    for prev_char in prev_dp:
        cost = prev_dp[prev_char]
        
        # Option 1: Delete current character
        key = prev_char
        if key in curr_dp:
            if cost + 1 < curr_dp[key]:
                curr_dp[key] = cost + 1
        else:
            curr_dp[key] = cost + 1
        
        # Option 2: Keep current character
        if prev_char is None:
            new_char = c
            if new_char in curr_dp:
                if cost < curr_dp[new_char]:
                    curr_dp[new_char] = cost
            else:
                curr_dp[new_char] = cost
        else:
            if forbidden.get(prev_char) == c:
                continue  # Forbidden pair, cannot keep
            else:
                new_char = c
                if new_char in curr_dp:
                    if cost < curr_dp[new_char]:
                        curr_dp[new_char] = cost
                else:
                    curr_dp[new_char] = cost
    prev_dp = curr_dp

print(min(prev_dp.values()))
```

### Explanation
- **Forbidden Pairs Setup**: The forbidden pairs are stored in a dictionary where each character points to its forbidden partner. This allows O(1) time complexity checks for forbidden pairs.
- **Dynamic Programming**: The DP dictionary `prev_dp` tracks the minimum deletions required to reach each possible state (last character kept). For each character in the string, we update the DP states by considering both deletion and keeping the character.
- **Efficiency**: The algorithm processes each character in O(1) time per state, leading to an overall time complexity of O(N * 27) where N is the length of the string and 27 represents the possible states (26 letters + None). This ensures the solution is efficient even for the upper constraint of N = 100,000.

This approach ensures that we efficiently compute the minimum deletions required to transform the input string into a valid N-ish language string without any forbidden adjacent pairs.
