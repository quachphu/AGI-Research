To solve this problem, we need to find two positive integers \(a\) and \(b\) such that their Greatest Common Divisor (GCD) plus their Least Common Multiple (LCM) equals a given integer \(x\). The solution must work for multiple test cases efficiently.

### Approach
The key insight is that if we choose \(a = 1\) and \(b = x - 1\), the GCD of \(a\) and \(b\) will always be 1 (since 1 is coprime with any integer), and the LCM of \(a\) and \(b\) will be \(x - 1\) (since the LCM of 1 and any integer \(n\) is \(n\)). Thus, the sum of GCD(1, \(x-1\)) and LCM(1, \(x-1\)) will be \(1 + (x - 1) = x\), which satisfies the problem's requirement.

This approach is efficient because it directly computes the required pair in constant time \(O(1)\) for each test case, making the overall time complexity \(O(t)\) where \(t\) is the number of test cases.

### Solution Code
```python
t = int(input())
for _ in range(t):
    x = int(input())
    print(1, x - 1)
```

### Explanation
- **Input Handling**: Read the number of test cases \(t\).
- **Loop Through Test Cases**: For each test case, read the integer \(x\).
- **Generate Solution**: For each \(x\), output the pair (1, \(x - 1\)). This pair ensures that the GCD is 1 and the LCM is \(x - 1\), which sum to \(x\).

This approach is optimal and straightforward, leveraging the properties of GCD and LCM with minimal computation, ensuring it handles the upper constraints efficiently.
