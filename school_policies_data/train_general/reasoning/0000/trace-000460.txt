To solve this problem, we need to find the index of the frame in a video whose representation is closest to the average of all frame representations. If there are multiple such frames, we select the one with the smallest index.

### Approach
1. **Read Input**: First, we read the number of frames \( N \) and the list of frame representations.
2. **Compute Average**: Calculate the average of all frame representations.
3. **Find Closest Frame**: Iterate through each frame to compute the absolute difference between the frame's representation and the average. Track the minimum difference and the corresponding index. If multiple frames have the same minimum difference, the first occurrence (smallest index) is retained.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
average = sum(a) / n

min_diff = float('inf')
best_idx = 0

for i in range(n):
    diff = abs(a[i] - average)
    if diff < min_diff:
        min_diff = diff
        best_idx = i

print(best_idx)
```

### Explanation
1. **Reading Input**: The input is read in two parts: the number of frames \( N \) and the list of integers representing each frame.
2. **Calculating Average**: The average of the frame representations is computed by summing all elements and dividing by \( N \).
3. **Finding the Closest Frame**: By iterating through each frame, we compute the absolute difference between the frame's value and the average. We keep track of the smallest difference and update the best index whenever a smaller difference is found. If the same minimum difference is encountered again, the index is not updated, ensuring the smallest index is retained.

This approach efficiently determines the required frame index in linear time, ensuring optimal performance even for the upper constraint of \( N = 100 \).
