To solve this problem, we need to determine the final integer value in Takahashi's mind after he processes four symbols, each of which is either '+' or '-'. The initial value starts at 0, and each '+' increases the value by 1, while each '-' decreases it by 1.

### Approach
1. **Input Reading**: Read the input string which consists of exactly four characters.
2. **Initialization**: Start with an initial value of 0.
3. **Processing Each Symbol**: Iterate through each character in the input string. For each '+', increment the value by 1, and for each '-', decrement the value by 1.
4. **Output the Result**: After processing all four symbols, print the final value.

This approach ensures that each symbol is processed exactly once, resulting in an efficient solution with a time complexity of O(1) since the input length is fixed at 4 characters.

### Solution Code
```python
def main():
    s = input().strip()
    total = 0
    for c in s:
        if c == '+':
            total += 1
        else:
            total -= 1
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input string is read using `input().strip()` to remove any leading or trailing whitespace.
- **Initial Value**: The variable `total` is initialized to 0.
- **Processing Symbols**: A loop iterates over each character in the input string. For each character, if it is '+', the total is incremented by 1; if it is '-', the total is decremented by 1.
- **Output**: The final value of `total` is printed after processing all characters in the input string.

This method efficiently computes the result by directly iterating over the input string and adjusting the total value based on each character, ensuring a straightforward and optimal solution.
