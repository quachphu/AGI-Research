To solve this problem, we need to determine the probability that at least two numbers in an array of k randomly generated numbers (each between 1 and n inclusive) are the same. This problem can be approached using principles similar to the birthday problem, where we calculate the probability of all elements being unique and then subtract this from 1.

### Approach
1. **Understanding the Problem**: The key insight is that if k exceeds n, the probability of duplicates is 1 due to the pigeonhole principle. Otherwise, we compute the probability of all elements being unique and subtract this from 1.
2. **Probability Calculation**: For each element in the array, the probability that it is unique relative to the previous elements is calculated and multiplied iteratively. This product gives the probability that all elements are unique. Subtracting this product from 1 gives the desired probability.
3. **Edge Cases**: If k is 0, the probability is 0 as there are no elements. If k exceeds n, the probability is 1 as duplicates are inevitable.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        k = int(input[idx])
        n = int(input[idx + 1])
        idx += 2
        if k == 0:
            print("0.000000000")
        elif k > n:
            print("1.000000000")
        else:
            product = 1.0
            for i in range(k):
                product *= (n - i) / n
            prob = 1 - product
            print("{0:.9f}".format(prob))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given multiple test cases.
2. **Handling Edge Cases**: Direct checks for k being 0 or greater than n immediately return the respective probabilities (0 or 1).
3. **Probability Calculation**: For valid cases where 1 ≤ k ≤ n, the product of probabilities for each subsequent element being unique is computed. This product is then subtracted from 1 to get the probability of having at least one duplicate.
4. **Formatting Output**: The result is formatted to 9 decimal places using Python's string formatting to ensure the correct precision and trailing zeros.

This approach efficiently handles the constraints and ensures accurate results using straightforward mathematical principles and careful handling of edge cases.
