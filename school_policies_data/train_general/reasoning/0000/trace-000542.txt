Instead, we use an optimized approach that leverages the periodicity of the array and dynamic programming.

### Approach
1. **Small T Handling**: If T is small (specifically, T ≤ 2n), generate the sequence up to T copies and compute the LNDS using an efficient algorithm.
2. **Large T Handling**: For larger T, compute the LNDS for 2n and (2n-1) copies. The difference between these two values gives the increment per copy once the sequence stabilizes. Use this increment to extrapolate the result for the remaining copies.

### Solution Code
```python
import bisect

def compute_lnds(arr):
    tails = []
    for num in arr:
        idx = bisect.bisect_right(tails, num)
        if idx == len(tails):
            tails.append(num)
        else:
            tails[idx] = num
    return len(tails)

n, T = map(int, input().split())
```
