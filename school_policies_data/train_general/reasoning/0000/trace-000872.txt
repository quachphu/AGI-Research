To solve this problem, we need to determine the number at the n-th position in a specific sequence where each group of numbers increases by one each time. The sequence is structured such that the first group contains 1, the second group contains 1 and 2, the third group contains 1, 2, and 3, and so on. The challenge is to efficiently find the number at the given position, even for very large values of n (up to \(10^{14}\)).

### Approach
1. **Identify the Group**: The sequence is built in groups where each group k contains numbers from 1 to k. The total number of elements up to and including group k is given by the sum of the first k natural numbers, which is \(k(k+1)/2\). We need to determine the largest group m such that the sum of the first m groups is less than n. This can be efficiently found using binary search.
2. **Determine Position within Group**: Once the correct group is identified, compute the position within that group by subtracting the total number of elements in all previous groups from n.

### Solution Code
```python
n = int(input())

low = 0
high = 2 * 10**18
best = 0

while low <= high:
    mid = (low + high) // 2
    s = mid * (mid + 1) // 2
    if s < n:
        best = mid
        low = mid + 1
    else:
        high = mid - 1

ans = n - best * (best + 1) // 2
print(ans)
```

### Explanation
1. **Binary Search for Group Identification**: The binary search helps efficiently find the largest group m such that the sum of the first m groups (i.e., \(m(m+1)/2\)) is less than n. This avoids the inefficiency of iterating through each possible group.
2. **Calculate Position within Group**: Once the correct group is identified, the position within the group is calculated by subtracting the sum of all previous groups from n. This gives the exact position within the identified group, which directly corresponds to the number at that position.

This approach ensures that we handle very large values of n efficiently, leveraging the logarithmic time complexity of binary search to quickly narrow down the correct group and position.
