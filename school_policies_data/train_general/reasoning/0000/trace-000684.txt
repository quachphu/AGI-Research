Alternatively, find the longest prefix where the subnet covers start and the entire subnet is within the range.

This is a known problem and there are algorithms to find the minimal number of CIDR blocks to cover a range.

An efficient way to generate the minimal subnets for a given start and end is to use the following approach:

Initialize the current position as start.

While current <= end:

   Find the maximum number of trailing zeros in the binary representation of (current). Let's call this shift. The maximum possible prefix is 32 - shift. But also, the subnet must not exceed the end.

   For example, if current is 0x0000 (binary ...0000), then the maximum possible prefix is 32 (subnet of size 1), but if the end is larger, then we can take a smaller prefix (larger subnet).

   So, the maximum possible subnet is the largest possible (smallest x) where the subnet starts at current and covers as many addresses as possible without exceeding end.

   The algorithm for this is:

   - Compute the maximum mask length such that the subnet covers current and the entire subnet is within [current, end].

   - The mask length is the maximum x where (current | ( (1 << (32 - x)) -1 )) <= end.

   - To find x, we can iterate from the smallest possible mask (0) upwards, but that's slow.

   Alternative approach: compute the number of trailing 1 bits in (current ^ end). The maximum possible x is 32 - the number of leading zeros of (end - current + 1).

   Or, find the largest block size (2^k) that fits into the remaining range.

   This is similar to the method described here: https://stackoverflow.com/questions/33443914/how-to-convert-ip-address-range-to-cidr-in-java.

   The steps are:

   a. The mask is 32 - the number of trailing zeros in (current & -current). This gives the maximum possible mask where the block size is a power of two, starting at current.

   b. The block size is 2^(32 - x). We need the largest possible block size that is <= (end - current + 1).

   c. Once the maximum block size is determined, calculate x.

   d. Add the subnet current/x.

   e. current += block_size.

This way, each step reduces the remaining range until current exceeds end.

def compute_complement(merged_w_ranges):
    all_start = 0
    all_end = (1 << 32) -1

    complement = []

    prev_end = all_start -1

    for (start, end) in merged_w_ranges:
        if start > prev_end +1:
            complement.append( (prev_end +1, start -1) )
        prev_end = max(prev_end, end)

    if prev_end < all_end:
        complement.append( (prev_end +1, all_end) )

    return complement

If any address is found in both the original blacklist and whitelist, the solution should return -1.

### Approach
1. **Parse Input**: Read and parse the input to separate blacklist and whitelist subnets.
2. **Check Overlaps**: Merge the ranges of both blacklist and whitelist subnets and check for any overlaps. If there is an overlap, return -1.
3. **Generate CIDR Subnets**: 
   - **Option 1**: Generate CIDR subnets that cover the merged ranges of the original blacklist.
   - **Option 2**: Generate CIDR subnets that cover the entire address space except the merged ranges of the original whitelist.
4. **Choose Optimal Solution**: Compare the number of subnets required for both options and choose the one with the minimal count. If counts are equal, prefer the option covering more addresses (whitelist complement).

def ip_to_int(ip_str):
    parts = list(map(int, ip_str.split('.')))
    res = 0
    for p in parts:
        res = (res << 8) | p
    return res

def parse_subnet(subnet_str):
    if '/' in subnet_str:
        ip_part, x_str = subnet_str.split('/')
        x = int(x_str)
    else:
        ip_part = subnet_str
        x = 32
    ip = ip_to_int(ip_part)
    mask = (0xFFFFFFFF << (32 - x)) & 0xFFFFFFFF if x != 0 else 0
    start = ip & mask
    end = start | ((1 << (32 - x)) - 1)
    return start, end

def merge_ranges(ranges):
    if not ranges:
        return []
    sorted_ranges = sorted(ranges)
    merged = [sorted_ranges[0]]
    for current in sorted_ranges[1:]:
        last = merged[-1]
        if current[0] <= last[1] + 1:
            merged[-1] = (last[0], max(last[1], current[1]))
        else:
            merged.append(current)
    return merged

def has_overlap(merged_b, merged_w):
    i = j = 0
    while i < len(merged_b) and j < len(merged_w):
        b_start, b_end = merged_b[i]
        w_start, w_end = merged_w[j]
        if b_end < w_start:
            i += 1
        elif w_end < b_start:
            j += 1
        else:
            return True
    return False

def range_to_cidrs(start, end):
    cidrs = []
    while start <= end:
        max_mask = 32
        while True:
            block = 1 << (32 - max_mask)
            current_end = start + block - 1
            if current_end > end:
                max_mask -= 1
            else:
                break
            if max_mask == 0:
                break
        cidrs.append((start, max_mask))
        start += (1 << (32 - max_mask))
    return cidrs

def compute_complement(merged_w):
    all_start = 0
    all_end = (1 << 32) - 1
    complement = []
    prev_end = all_start - 1
    for (s, e) in merged_w:
        if s > prev_end + 1:
            complement.append((prev_end + 1, s - 1))
        prev_end = max(prev_end, e)
    if prev_end < all_end:
        complement.append((prev_end + 1, all_end))
    return complement

def int_to_ip(n):
    return '.'.join(str((n >> (24 - i * 8)) & 0xFF) for i in range(4))

def cidr_to_string(start, mask):
    ip_str = int_to_ip(start)
    if mask == 32:
        return ip_str
    else:
        return f"{ip_str}/{mask}"

def main():
    import sys
    input = sys.stdin.read().splitlines()
    n = int(input[0])
    black = []
    white = []
    for line in input[1:n+1]:
        line = line.strip()
        if not line:
            continue
        type_sub = line[0]
        subnet_str = line[1:]
        start, end = parse_subnet(subnet_str)
        if type_sub == '-':
            black.append((start, end))
        else:
            white.append((start, end))
    
    merged_black = merge_ranges(black)
    merged_white = merge_ranges(white)
    
    if has_overlap(merged_black, merged_white):
        print(-1)
        return
    
    cidrs_b = []
    for s, e in merged_black:
        cidrs_b.extend(range_to_cidrs(s, e))
    
    if not white:
        complement_ranges = [ (0, (1 << 32) -1) ]
    else:
        complement_ranges = compute_complement(merged_white)
    
    cidrs_w = []
    for s, e in complement_ranges:
        cidrs_w.extend(range_to_cidrs(s, e))
    
    if len(cidrs_w) <= len(cidrs_b):
        output_cidrs = cidrs_w
    else:
        output_cidrs = cidrs_b
    
    print(len(output_cidrs))
    for start, mask in output_cidrs:
        print(cidr_to_string(start, mask))

if __name__ == "__main__":
    main()
