To solve this problem, we need to determine the maximum amount of yen Takahashi can earn by announcing a string that maximizes his balance. The balance is calculated by the number of blue cards with the announced string minus the number of red cards with the same string. 

### Approach
1. **Count Occurrences**: First, we count the occurrences of each string in the blue cards and red cards using a counter data structure.
2. **Calculate Profit**: For each unique string in the blue cards, compute the profit as the number of times it appears in the blue cards minus the number of times it appears in the red cards.
3. **Determine Maximum Profit**: Track the maximum profit across all strings in the blue cards. If all possible profits from the blue cards are negative, the maximum profit is zero (since Takahashi can choose a string not present on any card).

### Solution Code
```python
import sys
from collections import Counter

def main():
    n = int(sys.stdin.readline())
    blue_strings = [sys.stdin.readline().strip() for _ in range(n)]
    m = int(sys.stdin.readline())
    red_strings = [sys.stdin.readline().strip() for _ in range(m)]
    
    blue_count = Counter(blue_strings)
    red_count = Counter(red_strings)
    
    max_profit = 0
    for s, cnt in blue_count.items():
        current_profit = cnt - red_count.get(s, 0)
        if current_profit > max_profit:
            max_profit = current_profit
    print(max_profit)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first integer `n` gives the number of blue cards, followed by `n` strings. Similarly, the next integer `m` gives the number of red cards, followed by `m` strings.
2. **Counting Strings**: Using `Counter` from the `collections` module, we count how many times each string appears in the blue cards and red cards.
3. **Calculating Profit**: For each unique string in the blue cards, compute the profit by subtracting the count of that string in red cards from its count in blue cards.
4. **Finding Maximum Profit**: Track the highest profit encountered. If all possible profits are negative, the result defaults to zero, as Takahashi can choose a string not present on any card to avoid losing money.

This approach efficiently computes the maximum possible profit using counting and iteration, ensuring optimal performance given the problem constraints.
