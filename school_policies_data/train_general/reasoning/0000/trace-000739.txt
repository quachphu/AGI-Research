To solve this problem, we need to generate a wrong answer for the subtraction of two integers, A and B, such that the wrong answer has exactly one digit different from the correct result, maintains the same number of digits, and does not have leading zeros. The solution involves systematically modifying each digit of the correct result to find a valid wrong answer.

### Approach
1. **Calculate the Correct Result**: Compute the correct result by subtracting B from A.
2. **Convert to String**: Convert the correct result into a string to easily manipulate individual digits.
3. **Generate Candidates**: For each digit in the correct result, generate possible candidates by altering each digit to any other digit (0-9 except the original digit). Ensure the first digit is not changed to zero to avoid leading zeros.
4. **Output the First Valid Candidate**: Check each candidate and print the first valid one that meets the criteria.

### Solution Code
```python
a, b = map(int, input().split())
correct = a - b
s = str(correct)
for i in range(len(s)):
    original = s[i]
    for d in '0123456789':
        if d == original:
            continue
        if i == 0 and d == '0':
            continue
        new_s = s[:i] + d + s[i+1:]
        print(int(new_s))
        exit()
```

### Explanation
1. **Input Handling**: Read integers A and B from the input.
2. **Correct Result Calculation**: Compute the correct result of A - B.
3. **String Conversion**: Convert the correct result into a string to facilitate digit manipulation.
4. **Digit Replacement Loop**: Iterate over each digit position. For each position, generate all possible digits (0-9) except the original digit. For the first digit, also exclude zero to avoid leading zeros.
5. **Generate and Check Candidates**: Form a new number by replacing the current digit with the new digit. Print the first valid candidate and exit immediately, ensuring efficiency.

This approach efficiently generates valid candidates by checking each digit position from left to right and altering each digit to the smallest possible valid value first, ensuring a quick solution.
