To solve this problem, we need to determine the number of colors that connect two given vertices in an undirected graph either directly or indirectly for each query. Each edge in the graph has a specific color, and we need to check connectivity for each color separately.

### Approach
1. **Input Parsing**: Read the number of vertices and edges, followed by the edges themselves, which include their connecting vertices and color.
2. **Color-Specific Subgraphs**: For each color, construct a subgraph using edges of that color. Use the Union-Find (Disjoint Set Union, DSU) data structure to determine the connected components within each color's subgraph.
3. **Path Compression**: After constructing the DSU for each color, apply path compression to ensure each node's parent points directly to the root of its component, allowing O(1) time complexity for connectivity checks.
4. **Query Processing**: For each query, check all colors to count how many colors have the queried vertices within the same connected component.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    def find(parent, x):
        if parent[x] != x:
            parent[x] = find(parent, parent[x])
        return parent[x]

    # Read input
    n, m = map(int, sys.stdin.readline().split())
    color_edges = defaultdict(list)
    for _ in range(m):
        a, b, c = map(int, sys.stdin.readline().split())
        color_edges[c].append((a, b))
    
    # Prepare DSU for each color
    color_dsu = {}
    for c in color_edges:
        parent = list(range(n + 1))
        rank = [1] * (n + 1)
        for a, b in color_edges[c]:
            root_a = find(parent, a)
            root_b = find(parent, b)
            if root_a != root_b:
                if rank[root_a] > rank[root_b]:
                    parent[root_b] = root_a
                    rank[root_a] += rank[root_b]
                else:
                    parent[root_a] = root_b
                    rank[root_b] += rank[root_a]
        # Compress all paths
        for node in range(1, n + 1):
            find(parent, node)
        color_dsu[c] = parent
    
    # Process queries
    q = int(sys.stdin.readline())
    for _ in range(q):
        u, v = map(int, sys.stdin.readline().split())
        count = 0
        for c in color_dsu:
            if color_dsu[c][u] == color_dsu[c][v]:
                count += 1
        print(count)

if __name__ == "__main__":
    main()
```

1. **Input Parsing**: The input is read using standard input methods. The edges are stored in a dictionary where the key is the color, and the value is a list of edges of that color.
2. **DSU Construction**: For each color, we initialize a Union-Find structure. Each edge of the color is processed to union the vertices it connects. After processing all edges, path compression is applied to ensure each node's parent points directly to the root of its component.
3. **Query Handling**: For each query, we check each color's DSU to see if the two vertices are in the same connected component. The count of such colors is the result for that query.

This approach efficiently handles the constraints and ensures that each query is processed in linear time relative to the number of colors, making it suitable for the given problem constraints.
