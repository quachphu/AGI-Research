### Approach

2. **Key Insights**:
   - The sum of points from all sets must be at least `k` times the number of sets, but less than `2 * k` times the number of sets.
   - We need to check all possible numbers of sets (from the maximum possible down to the minimum) to find the valid configuration where the scores are possible.
3. **Algorithm**:
   - Calculate the possible range for the number of sets (`s_total`) based on the total points scored.
   - For each possible number of sets, check if there exists a valid distribution of wins (s1 for Misha and s2 for Vanya) that satisfies the conditions for valid scores in each set.

k, a, b = map(int, input().split())

    max_s1 = min(a // k, s_total)
    min_s1 = max(0, s_total - (b // k))
    if min_s1 > max_s1:

    for s1 in range(min_s1, max_s1 + 1):
        s2 = s_total - s1
        if s2 < 0 or s2 > (b // k):

        m = a - s1 * k
        v = b - s2 * k
        if m < 0 or v < 0:

        valid = True
        if s1 > 0:

        if s2 > 0:
