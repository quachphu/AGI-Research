To solve this problem, we need to find the smallest child number for a given father number such that the child number plus the sum of its digits equals the father number. If no such child number exists, we should return "NONE".

### Approach
1. **Understanding the Problem**: The child number (X) and the sum of its digits must add up to the given father number (N). Thus, we need to find the smallest X such that X + sum_digits(X) = N.
2. **Key Insight**: The sum of the digits of X (sum_digits(X)) is non-negative and at most 45 (for a 5-digit number with all 9s). Therefore, X must be in the range [N - 45, N - 1] to ensure sum_digits(X) is positive and meaningful.
3. **Efficient Search**: Iterate over possible values of sum_digits(X) from 45 down to 1. For each possible sum (s), compute X as N - s and check if the sum of X's digits equals s. The first valid X found in this manner is the smallest possible child number.

### Solution Code
```python
def sum_digits(x):
    s = 0
    while x > 0:
        s += x % 10
        x = x // 10
    return s

def find_child(N):
    for s in range(45, 0, -1):
        X = N - s
        if X < 1:
            continue
        if sum_digits(X) == s:
            return X
    return None

def main():
    import sys
    lines = [line.strip() for line in sys.stdin if line.strip()]
    K = int(lines[0])
    idx = 1
    for _ in range(K):
        if idx >= len(lines):
            break
        N = int(lines[idx])
        idx += 1
        child = find_child(N)
        print(child if child is not None else "NONE")

if __name__ == "__main__":
    main()
```

### Explanation
1. **sum_digits Function**: This helper function calculates the sum of the digits of a given number.
2. **find_child Function**: This function iterates over possible sums of digits from 45 down to 1. For each sum (s), it computes the potential child number X as N - s. If X is positive and the sum of its digits equals s, X is returned as the valid child number.
3. **Main Function**: Reads input, processes each test case, and prints the result. It handles input reading by stripping whitespace and filtering out empty lines to correctly parse the input format.

This approach ensures that we efficiently check the possible range for X, leveraging the constraint on the maximum possible sum of digits, leading to an optimal solution.
