To solve this problem, we need to ensure that a mouse, which moves deterministically through rooms according to a given sequence, will eventually be caught by a trap regardless of its starting position. The goal is to determine the minimal cost to set these traps such that every possible path the mouse can take will lead it to a trapped room.

### Approach
1. **Graph Structure Analysis**: The movement of the mouse can be modeled as a directed graph where each node (room) has exactly one outgoing edge. This structure consists of cycles and trees directed towards these cycles.
2. **Cycle Detection**: For each node, we need to determine if it is part of a cycle. If a node is part of a cycle, placing a trap in that cycle is necessary to ensure the mouse is caught.
3. **Cost Minimization**: For each detected cycle, the minimal cost to place a trap in that cycle is the minimum cost among all nodes in the cycle. The solution is the sum of these minimal costs for all detected cycles.

### Solution Code
```python
n = int(input())
c = list(map(int, input().split()))
a = list(map(lambda x: int(x)-1, input().split()))
visited = [0] * n
total = 0

for i in range(n):
    if visited[i] != 0:
        continue
    path = []
    current = i
    while True:
        if visited[current] == 1:
            idx = path.index(current)
            cycle = path[idx:]
            total += min(c[j] for j in cycle)
            for node in path:
                visited[node] = 2
            break
        if visited[current] == 2:
            for node in path:
                visited[node] = 2
            break
        visited[current] = 1
        path.append(current)
        current = a[current]

print(total)
```

### Explanation
1. **Input Reading**: The input consists of the number of rooms, the cost array for each room, and the movement array adjusted to 0-based indices.
2. **Cycle Detection**: Using a depth-first search (DFS) approach, we traverse each node. Nodes are marked as unvisited (0), being visited (1), or visited (2). As we traverse, we keep track of the current path. If we encounter a node that is already being visited, we have found a cycle.
3. **Cycle Processing**: Once a cycle is detected, we compute the minimum cost for that cycle and add it to the total cost. All nodes in the current path are marked as visited to avoid reprocessing.
4. **Result Calculation**: The sum of the minimum costs from all detected cycles gives the minimal total cost required to guarantee the mouse will be caught regardless of its starting position.

This approach efficiently processes each node exactly once, ensuring an optimal solution with a time complexity of O(n), making it suitable for large input sizes up to 200,000 rooms.
