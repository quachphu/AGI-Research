To solve this problem, we need to find the maximum integer \( k \) such that \( 0 \leq k \leq n \) and \( k \mod x = y \) for multiple test cases. The solution must efficiently handle up to \( 5 \times 10^4 \) test cases with values up to \( 10^9 \).

### Approach
1. **Understanding the Modulo Condition**: For \( k \mod x = y \), \( k \) can be expressed as \( x \cdot m + y \), where \( m \) is a non-negative integer. The goal is to find the largest \( m \) such that \( x \cdot m + y \leq n \).
2. **Rearranging the Inequality**: Rearrange \( x \cdot m + y \leq n \) to \( m \leq (n - y) / x \). The largest integer \( m \) is the floor value of \( (n - y) / x \).
3. **Compute \( k \)**: Using the largest \( m \), compute \( k \) as \( k = x \cdot ((n - y) // x) + y \).

### Solution Code
```python
import sys

def solve():
    t = int(sys.stdin.readline())
    for _ in range(t):
        x, y, n = map(int, sys.stdin.readline().split())
        k = ((n - y) // x) * x + y
        print(k)

solve()
```

3. **Guaranteed Existence**: The problem constraints ensure that \( y \leq n \), so \( n - y \) is non-negative, making the formula safe to use.

This approach ensures that each test case is processed in constant time, leading to an overall time complexity of \( O(t) \), which is optimal for the given constraints.
