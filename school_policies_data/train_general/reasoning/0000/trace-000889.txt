To solve this problem, we need to determine the minimum number of button presses required to make each element of an integer sequence a multiple of another corresponding integer sequence. Each button press affects all elements from the start up to the button's position.

### Approach
1. **Problem Analysis**: When pressing the i-th button, all elements from the first to the i-th are incremented by 1. The goal is to ensure each element \(A_i\) becomes a multiple of \(B_i\) with the minimum number of button presses.

2. **Key Insight**: The number of increments each element \(A_i\) receives is the sum of presses from the i-th button onwards. We need to determine the minimal sum of increments for each element such that \(A_i + \text{increments}\) is a multiple of \(B_i\).

3. **Algorithm**:
   - Process elements from right to left (N down to 1).
   - For each element, compute the minimum increments needed to make \(A_i\) a multiple of \(B_i\) while ensuring the increments are non-negative and meet the constraints from previous elements.
   - Use modular arithmetic to determine the required increments and propagate constraints from right to left efficiently.

### Solution Code
```python
n = int(input())
ab = [tuple(map(int, input().split())) for _ in range(n)]
s_prev = 0
for a, b in reversed(ab):
    rem = (-a) % b
    r = s_prev % b
    delta = (rem - r) % b
    s_prev += delta
print(s_prev)
```
