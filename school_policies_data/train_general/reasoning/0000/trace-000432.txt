To solve this problem, we need to find the smallest positive integer \( a \) for each test case such that \( a \) has at least 4 divisors and the difference between any two of its divisors is at least \( d \). The solution involves identifying two primes that meet specific criteria to form \( a \) as their product.

### Approach
1. **Prime Identification**: For each given \( d \), the smallest integer \( a \) can be formed by multiplying two primes \( p \) and \( q \). Here, \( p \) is the smallest prime greater than or equal to \( d + 1 \), and \( q \) is the smallest prime greater than or equal to \( p + d \).
2. **Prime Check Function**: A helper function to check if a number is prime using trial division up to its square root.
3. **Next Prime Function**: Another helper function to find the next prime number greater than or equal to a given number.

### Solution Code
```python
def is_prime(n):
    if n <= 1:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False
    for i in range(3, int(n**0.5) + 1, 2):
        if n % i == 0:
            return False
    return True

def next_prime(n):
    if n <= 2:
        return 2
    if n % 2 == 0:
        candidate = n + 1
    else:
        candidate = n
    while True:
        if is_prime(candidate):
            return candidate
        candidate += 2

t = int(input())
for _ in range(t):
    d = int(input())
    p = next_prime(d + 1)
    q = next_prime(p + d)
    print(p * q)
```

### Explanation
1. **Prime Check Function (`is_prime`)**:
   - Checks if a number \( n \) is prime by testing divisibility up to \( \sqrt{n} \). This ensures efficiency even for larger numbers.

2. **Next Prime Function (`next_prime`)**:
   - Finds the smallest prime number greater than or equal to \( n \). It starts checking from \( n \) if \( n \) is odd, or \( n + 1 \) if \( n \) is even, incrementing by 2 to skip even numbers.

3. **Main Logic**:
   - For each test case, read \( d \).
   - Compute \( p \) as the next prime after \( d + 1 \).
   - Compute \( q \) as the next prime after \( p + d \).
   - The result \( a \) is the product of \( p \) and \( q \).

This approach ensures that the divisors of \( a \) (1, \( p \), \( q \), \( pq \)) have differences of at least \( d \), meeting the problem's requirements efficiently.
