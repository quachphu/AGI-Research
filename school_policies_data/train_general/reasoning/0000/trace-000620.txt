To solve this problem, we need to help Taro select two distinct items from a list such that their combined price is the highest possible without exceeding a given budget. The solution must efficiently determine the optimal pair for each dataset provided.

### Approach
1. **Sorting the Prices**: First, we sort the list of item prices. Sorting helps us efficiently find the largest possible pairs using binary search.
2. **Binary Search for Optimal Pair**: For each item price, we calculate the maximum allowable price for the second item (target) such that their sum does not exceed the budget. Using binary search, we find the largest price that is less than or equal to this target.
3. **Handling Duplicates**: If the optimal pair found includes the same item (due to duplicates), we check if there are multiple occurrences of that item to ensure we can form a valid pair.
4. **Edge Cases**: If no valid pairs are found for a dataset, we output "NONE".

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    while True:
        n = int(input[ptr])
        m = int(input[ptr+1])
        ptr += 2
        if n == 0 and m == 0:
            break
        a = list(map(int, input[ptr:ptr+n]))
        ptr += n
        a.sort()
        max_sum = -1
        for i in range(n):
            ai = a[i]
            if ai > m:
                continue
            target = m - ai
            idx = bisect.bisect_right(a, target) - 1
            if idx < 0:
                continue
            if a[idx] > target:
                continue
            if idx != i:
                current_sum = ai + a[idx]
                if current_sum <= m and current_sum > max_sum:
                    max_sum = current_sum
            else:
                if (i > 0 and a[i-1] == ai) or (i < n-1 and a[i+1] == ai):
                    current_sum = ai * 2
                    if current_sum <= m and current_sum > max_sum:
                        max_sum = current_sum
        print(max_sum if max_sum != -1 else "NONE")

main()
```

1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints. We process each dataset iteratively.
2. **Sorting**: Each list of prices is sorted to facilitate binary search operations.
3. **Binary Search**: For each price in the sorted list, we use binary search to find the largest valid complementary price. This helps in efficiently narrowing down potential pairs.
4. **Duplicate Check**: If the optimal complementary price is the same as the current item, we check for duplicates to ensure a valid pair can be formed.
5. **Edge Case Handling**: If no valid pairs are found, "NONE" is returned. Otherwise, the maximum valid sum is printed.

This approach ensures that we efficiently find the optimal pairs using sorting and binary search, making the solution both effective and performant within the problem constraints.
