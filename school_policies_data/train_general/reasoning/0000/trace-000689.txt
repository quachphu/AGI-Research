To solve this problem, we need to determine if we can make two strings, `a` and `b`, identical by swapping each character of a third string `c` with the corresponding character in either `a` or `b`. The key insight is that for each position, after the swap, the characters in `a` and `b` at that position must be equal.

### Approach
1. **Input Reading**: Read the number of test cases and then read the strings `a`, `b`, and `c` for each test case.
2. **Character Check**: For each position in the strings, check if either of the following conditions is met:
   - The character in `a` at the current position matches the character in `c` at the same position.
   - The character in `b` at the current position matches the character in `c` at the same position.
3. **Validation**: If all positions satisfy at least one of the conditions, it is possible to make `a` and `b` identical; otherwise, it is not.

### Solution Code
```python
t = int(input())
for _ in range(t):
    a = input().strip()
    b = input().strip()
    c = input().strip()
    possible = True
    for ai, bi, ci in zip(a, b, c):
        if ai != ci and bi != ci:
            possible = False
            break
    print("YES" if possible else "NO")
```

### Explanation
- **Reading Input**: The code reads the number of test cases and then iterates through each test case, reading the strings `a`, `b`, and `c`.
- **Character Check**: For each position in the strings, the code checks if either `a[i]` matches `c[i]` or `b[i]` matches `c[i]`. If neither condition is met for any position, it is impossible to make `a` and `b` identical, and the result for that test case is "NO".
- **Result Determination**: If all positions pass the check, the result is "YES"; otherwise, it is "NO".

This approach efficiently checks each position in linear time, making it optimal for the given constraints.
