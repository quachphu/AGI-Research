def survivor(n):

        return 0
    m = n.bit_length() - 1

    if largest == n:
        return n
    else:

    input = sys.stdin.read().split()

3. **Determining Survivor**:

   - Otherwise, compute the survivor using the formula 2 * (N - largest_power).
