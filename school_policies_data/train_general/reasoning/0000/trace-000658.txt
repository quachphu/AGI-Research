To solve this problem, we need to determine the probability that Dot will win the game based on the die rolls of Yakko and Wakko. The probability should be presented as an irreducible fraction.

### Approach
1. **Identify the Maximum Roll**: The maximum value between Yakko's and Wakko's rolls determines the threshold Dot needs to meet or exceed to win.
2. **Calculate Favorable Outcomes**: Dot's favorable outcomes are the die faces that are greater than or equal to the maximum of Yakko's and Wakko's rolls. This is calculated as \(7 - \text{max}(Y, W)\) since the die has faces from 1 to 6.
3. **Simplify the Fraction**: The probability is the ratio of favorable outcomes to the total possible outcomes (6). We use the greatest common divisor (GCD) to simplify this fraction to its lowest terms.

### Solution Code
```python
import math

def calculate_probability():
    import sys
    Y, W = map(int, sys.stdin.readline().split())
    max_roll = max(Y, W)
    favorable = 7 - max_roll
    gcd_val = math.gcd(favorable, 6)
    numerator = favorable // gcd_val
    denominator = 6 // gcd_val
    print(f"{numerator}/{denominator}")

calculate_probability()
```

### Explanation
1. **Reading Input**: The input consists of two integers, Y and W, which are the results of Yakko's and Wakko's die rolls.
2. **Determine Threshold**: The maximum value of Y and W is computed to find the minimum value Dot needs to roll to win.
3. **Favorable Outcomes Calculation**: The number of favorable outcomes for Dot is derived using \(7 - \text{max}(Y, W)\). For example, if the maximum roll is 4, Dot needs to roll 4, 5, or 6, which gives 3 favorable outcomes.
4. **Fraction Simplification**: The probability fraction is simplified by dividing both the numerator (favorable outcomes) and the denominator (total outcomes, which is 6) by their GCD. This ensures the fraction is in its simplest form.

This approach efficiently computes the required probability using basic arithmetic operations and the GCD function, ensuring optimal performance and correctness.
