To solve this problem, we need to determine which participants from two semifinals have a chance to advance to the finals based on their performance. The selection process involves two possible paths: being in the top k of their semifinal or being among the best of the remaining participants from both semifinals. 

### Approach
1. **Understanding the Problem**: Each semifinal has `n` participants. The top k participants from each semifinal automatically qualify. The remaining spots are filled by the best performers from the non-top k participants of both semifinals. We need to determine for each participant if there exists any k such that they can qualify through either path.

2. **Key Observations**:
   - **Case A**: A participant can qualify if their rank in their semifinal (1-based) is within the top half of the participants (i.e., rank ≤ `n//2`).
   - **Case B**: A participant can qualify if their time is among the best remaining participants after excluding the top k from each semifinal. This is determined by checking if their combined rank in both semifinals is within the top `n` participants when k=0.

3. **Efficient Checks**:
   - Use binary search to determine how many participants from the opposite semifinal have better times.
   - Check if the sum of their rank in their own semifinal and the count of better performers from the opposite semifinal is within the required range.

### Solution Code
```python
import bisect

n = int(input())
a = []
b = []
for _ in range(n):
    x, y = map(int, input().split())
    a.append(x)
    b.append(y)

res1 = []
res2 = []

# Process first semifinal
for i in range(n):
    # Check case A: rank is <= floor(n/2)
    case_a = (i + 1) <= (n // 2)
    # Find total_b: number of elements in b less than a[i]
    total_b = bisect.bisect_left(b, a[i])
    # Check case B: i + total_b <= n-1
    case_b = (i + total_b) <= (n - 1)
    res1.append('1' if (case_a or case_b) else '0')

# Process second semifinal
for j in range(n):
    # Check case A: rank is <= floor(n/2)
    case_a = (j + 1) <= (n // 2)
    # Find total_a: number of elements in a less than b[j]
    total_a = bisect.bisect_left(a, b[j])
    # Check case B: j + total_a <= n-1
    case_b = (j + total_a) <= (n - 1)
    res2.append('1' if (case_a or case_b) else '0')

print(''.join(res1))
print(''.join(res2))
```

### Explanation
1. **Reading Input**: The input is read and stored in two lists `a` and `b`, which represent the times of participants in the first and second semifinals, respectively. Both lists are already sorted in ascending order.

2. **Case A Check**: For each participant, we check if their 1-based rank is within the top half of the participants. This determines if they can qualify by being in the top k of their semifinal.

3. **Case B Check**: Using binary search, we determine how many participants from the opposite semifinal have better times. If the sum of the participant's rank and this count is within the top `n` participants when k=0, they can qualify through the remaining spots.

4. **Result Construction**: For each participant, we construct a result string indicating if they have any chance of qualifying based on either case.

This approach efficiently checks both qualification paths using binary search and simple arithmetic checks, ensuring optimal performance even for large input sizes.
