To solve this problem, we need to maximize the total rating of a character's skills by optimally distributing improvement units. The total rating is calculated as the sum of the floor division of each skill's value by 10. The goal is to use up to `k` improvement units to increase the skills such that the total rating is maximized.

### Approach
1. **Initial Calculation**: Compute the initial total rating based on the given skill values without any improvements.
2. **Delta Initial Steps**: For each skill, calculate the number of units required to reach the next multiple of 10. These steps are prioritized as they provide the most gain per unit spent.
3. **Sort and Process**: Sort these delta initial steps by their cost in ascending order to use the least units first.
4. **Remaining Units for 10-Unit Steps**: After processing all possible delta initial steps, use the remaining units to improve skills in increments of 10, which are the next most efficient steps.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))

initial_sum = sum(x // 10 for x in a)

delta_steps = []
for x in a:
    if x == 100:
        continue
    remainder = x % 10
    if remainder == 0:
        delta = min(10, 100 - x)
    else:
        delta = min(10 - remainder, 100 - x)
    if delta < 10:
        delta_steps.append(delta)

delta_steps.sort()

gain = 0
remaining_k = k
for delta in delta_steps:
    if delta > remaining_k:
        break
    gain += 1
    remaining_k -= delta

sum_t2 = sum((100 - x) // 10 for x in a)
t2_steps = min(remaining_k // 10, sum_t2)
gain += t2_steps

print(initial_sum + gain)
```

### Explanation
1. **Initial Calculation**: The initial total rating is computed by summing the floor division of each skill value by 10.
2. **Delta Initial Steps**: For each skill, determine the units needed to reach the next multiple of 10 (or 100 if the skill is already close to 100). These steps are collected and sorted by their cost.
3. **Process Delta Steps**: Use the sorted delta steps to maximize the number of increments by using the least units first.
4. **10-Unit Steps**: After using all possible delta steps, the remaining units are converted into 10-unit steps. The maximum number of such steps is determined by the remaining units and the total possible 10-unit steps across all skills.

This approach ensures that we efficiently use the improvement units to maximize the total rating by prioritizing smaller, more impactful increments first, followed by bulk increments of 10 units.
