The solution involves leveraging dynamic programming to efficiently compute Fibonacci numbers and derive the result based on the properties of valid configurations.

### Approach
1. **Understanding Valid Configurations**: A valid configuration is one where no cell has more than one adjacent cell of the same color. This can be broken down into row-based and column-based valid patterns.
2. **Fibonacci Sequence Insight**: The number of valid configurations for a single row or column of length `k` can be derived using the Fibonacci sequence. Specifically, the number of valid configurations for a row of length `k` is `2 * fib(k+1)`, where `fib` is the Fibonacci sequence.
3. **Combining Row and Column Configurations**: The total number of valid configurations for an `n x m` grid is the sum of valid row-based configurations and valid column-based configurations, minus the overlapping configurations (chessboard patterns counted twice).

### Solution Code
```python
n, m = map(int, input().split())
MOD = 10**9 + 7

max_k = max(n, m) + 2
fib = [0] * (max_k + 1)
fib[0] = 0
fib[1] = 1
for i in range(2, max_k + 1):
    fib[i] = (fib[i-1] + fib[i-2]) % MOD

f_m = (2 * fib[m + 1]) % MOD
f_n = (2 * fib[n + 1]) % MOD
ans = (f_m + f_n - 2 + MOD) % MOD
print(ans)
```

### Explanation
1. **Fibonacci Computation**: We precompute Fibonacci numbers up to `max(n, m) + 2` using dynamic programming. This allows us to efficiently determine the number of valid configurations for any row or column length.
2. **Row and Column Configurations**: Using the precomputed Fibonacci numbers, we calculate the number of valid row-based configurations (`f_m`) for columns of length `m` and valid column-based configurations (`f_n`) for rows of length `n`.
3. **Adjust for Overlaps**: We subtract 2 to account for the two overlapping chessboard patterns (starting with black or white) that are counted in both row-based and column-based configurations.
