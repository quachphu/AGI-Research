   # Total nodes: 2*N

   adj = [[] for _ in range(size)]

   rev_adj = [[] for _ in range(size)]

           a_j = D[j]

           b_j = 24 - a_j

To solve this problem, we need to determine the maximum possible value of the smallest time gap between any pair of participants in a global event. The participants include Takahashi, who is in a city with a local time of 0 o'clock, and N other participants whose cities have time gaps relative to Takahashi's city. The goal is to maximize the minimum time gap between any pair of participants.

### Approach
1. **Understanding Time Gaps**: Each participant's city has a time gap defined as the minimum of the direct difference and the circular difference (24-hour format). For example, if a city is 7 hours ahead, the gap is 7, but if it is 17 hours ahead, the gap is also 7 (since 24-17=7).

2. **Binary Search for Maximum Gap**: We use binary search to determine the maximum possible value of the smallest time gap (s). The search range is from 0 to 12 (the maximum possible gap in a 24-hour format).

3. **2-SAT Problem for Feasibility Check**: For each candidate gap (s), we check if it's feasible to arrange the cities such that all pairwise gaps are at least s. This is modeled as a 2-SAT problem where each city's time can be either the given gap or its complement (24 - gap).

4. **Kosaraju's Algorithm**: To solve the 2-SAT problem efficiently, we use Kosaraju's algorithm to find strongly connected components (SCCs) in the implication graph. If any variable and its negation are in the same SCC, the arrangement is not feasible.

        for u in range(size):
            if not visited[u]:
                dfs(u)

        visited = [False] * size
        component = [0] * size
        current = 0

        for u in reversed(order):
            if not visited[u]:
                current += 1
                stack = [u]
                visited[u] = True
                component[u] = current
                while stack:
                    node = stack.pop()
                    for v in rev_adj[node]:
                        if not visited[v]:
                            visited[v] = True
                            component[v] = current
                            stack.append(v)

        for i in range(N):
            if component[2 * i] == component[2 * i + 1]:
                return False
        return True

        if is_possible(mid):

            low = mid + 1
