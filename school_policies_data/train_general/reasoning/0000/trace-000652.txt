To solve this problem, we need to simulate the movement of frogs on a cyclic gameboard where each frog jumps a certain number of cells and knocks out other frogs in its path. The goal is to determine which frogs remain on the board at the end of the game.

### Approach
1. **Initialization**: Read the input values and initialize each frog's position, jump length, and active status.
2. **Active Frogs Tracking**: Maintain a sorted list of active frogs' positions and their indices to efficiently query and update their positions.
3. **Simulation Loop**: Process each frog's turn in their original order. For each active frog with a positive jump length:
   - **Path Calculation**: Determine the cells the frog will jump through.
   - **Knockout Check**: Identify any frogs in the path and mark them as inactive.
   - **Update Jump Length**: Adjust the frog's jump length based on the number of frogs knocked out.
   - **Position Update**: Move the frog to its new position if it can still jump.
4. **Survivor Collection**: After processing all frogs, collect and print the indices of the remaining active frogs.

import bisect

n, m = map(int, input().split())

class Frog:
    def __init__(self, pos, ai, idx):

        self.ai = ai
        self.idx = idx
        self.active = True  # True means not knocked out

frogs = []
for i in range(n):
    p, a = map(int, input().split())
    frogs.append(Frog(p, a, i + 1))

sorted_pos = []
sorted_idx = []
# Initial setup
for i, f in enumerate(frogs):
    if f.active:

        sorted_pos.insert(insert_pos, f.pos)
        sorted_idx.insert(insert_pos, i)

    changed = False
    for i in range(n):
        current_frog = frogs[i]
        if not current_frog.active or current_frog.ai <= 0:
            continue
        
        current_pos = current_frog.pos
        ai_initial = current_frog.ai
        start = (current_pos + 1) % m
        end = (start + ai_initial - 1) % m
        
        # Determine the ranges
        if start <= end:
            ranges = [(start, end)]
        else:
            ranges = [(start, m), (1, end)]
        
        # Collect indices of frogs in the path
        frogs_in_path = []
        temp_remove = []
        for a, b in ranges:
            left = bisect.bisect_left(sorted_pos, a)
            right = bisect.bisect_right(sorted_pos, b)
            for j in range(left, right):
                idx = sorted_idx[j]
                if idx != i:
                    frogs_in_path.append(idx)
        
        # Remove duplicates
        frogs_in_path = list(set(frogs_in_path))
        # Mark frogs as inactive and remove from the sorted lists
        for idx in frogs_in_path:
            f = frogs[idx]
            if f.active:
                f.active = False
                # Find and remove from sorted_pos and sorted_idx
                pos = f.pos
                pos_left = bisect.bisect_left(sorted_pos, pos)
                while pos_left < len(sorted_pos) and sorted_pos[pos_left] == pos:
                    if sorted_idx[pos_left] == idx:

                    pos_left += 1

        k = len(frogs_in_path)
