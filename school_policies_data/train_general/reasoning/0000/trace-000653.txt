To solve this problem, we need to determine if a given number \( b \) appears in an arithmetic sequence that starts with \( a \) and has a common difference \( c \). The sequence is defined such that each subsequent element is obtained by adding \( c \) to the previous element. 

### Approach
1. **Immediate Check for Equality**: If \( a \) is equal to \( b \), \( b \) is trivially present in the sequence.
2. **Zero Common Difference**: If \( c \) is zero, the sequence does not progress, so \( b \) can only be in the sequence if \( a \) equals \( b \).
3. **Non-zero Common Difference**: For non-zero \( c \):
   - Calculate the difference \( \text{delta} = b - a \).
   - Check if \( \text{delta} \) is divisible by \( c \). If not, \( b \) cannot be in the sequence.
   - If divisible, check if the quotient (when \( \text{delta} \) is divided by \( c \)) is non-negative. This ensures that the sequence reaches \( b \) after starting from \( a \).

### Solution Code
```python
def check_sequence():
    a, b, c = map(int, input().split())
    if a == b:
        print("YES")
    elif c == 0:
        print("NO")
    else:
        delta = b - a
        if delta % c != 0:
            print("NO")
        else:
            k = delta // c
            print("YES" if k >= 0 else "NO")

check_sequence()
```

### Explanation
1. **Immediate Check for Equality**: If \( a \) and \( b \) are the same, the answer is immediately "YES".
2. **Handling Zero Common Difference**: If \( c \) is zero, the sequence remains \( a \) indefinitely. Thus, if \( a \) is not \( b \), the answer is "NO".
3. **Non-zero Common Difference**: For non-zero \( c \):
   - Compute the difference \( \text{delta} \) between \( b \) and \( a \).
   - Check divisibility of \( \text{delta} \) by \( c \). If not divisible, \( b \) cannot be in the sequence.
   - Check if the quotient \( k \) (from the division) is non-negative. A non-negative \( k \) indicates that \( b \) can be reached by adding \( c \) exactly \( k \) times to \( a \).

This approach efficiently covers all edge cases and ensures correctness through careful checks of divisibility and sequence progression constraints.
