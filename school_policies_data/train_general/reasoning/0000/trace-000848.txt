To solve this problem, we need to determine the number of Hamming numbers within a given range [m, n] for multiple datasets. Hamming numbers are numbers that can be formed by multiplying 1 by 2, 3, and 5 any number of times (including zero times). 

### Approach
1. **Generate Hamming Numbers**: Precompute all Hamming numbers up to the maximum possible value (1,000,000) using nested loops to generate all possible products of 2, 3, and 5.
2. **Sort the Hamming Numbers**: Once generated, sort these numbers to facilitate efficient range queries using binary search.
3. **Process Queries Efficiently**: For each input range [m, n], use binary search to quickly count how many Hamming numbers fall within the range.

### Solution Code
```python
import bisect
import sys

def generate_hamming():
    max_limit = 10**6
    hamming = set()
    current_2 = 1
    # Generate all 2^a * 3^b * 5^c <= max_limit
    for a in range(100):
        if current_2 > max_limit:
            break
        current_23 = current_2
        for b in range(100):
            if current_23 > max_limit:
                break
            current_235 = current_23
            for c in range(100):
                if current_235 > max_limit:
                    break
                hamming.add(current_235)
                current_235 *= 5
            current_23 *= 3
        current_2 *= 2
    return sorted(hamming)

sorted_hamming = generate_hamming()

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        parts = line.split()
        if not parts:
            continue
        if parts[0] == '0':
            break
        if len(parts) < 2:
            continue
        m = int(parts[0])
        n = int(parts[1])
        left = bisect.bisect_left(sorted_hamming, m)
        right = bisect.bisect_right(sorted_hamming, n)
        print(right - left)

if __name__ == "__main__":
    main()
```

1. **Generating Hamming Numbers**: The function `generate_hamming` uses nested loops to generate all possible products of 2^a, 3^b, and 5^c up to 1,000,000. These values are stored in a set to avoid duplicates and then sorted.
2. **Efficient Query Processing**: For each input range [m, n], the sorted list of Hamming numbers allows us to use binary search (via `bisect_left` and `bisect_right`) to quickly find the count of numbers within the range. This reduces the time complexity for each query to O(log N), where N is the number of Hamming numbers generated.
