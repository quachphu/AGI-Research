To solve this problem, we need to determine if there exists a switch that can be ignored such that pressing all remaining switches will still turn on all the lamps. 

### Approach
1. **Problem Analysis**: Each switch can turn on a subset of lamps. We need to check if there's a switch that, when ignored, all lamps can still be turned on by the remaining switches. This means for every lamp, there must be at least one switch (other than the ignored one) that can turn it on.

2. **Key Insight**: For each lamp, we collect all switches that can turn it on. If there exists a switch such that no lamp is exclusively dependent on it (i.e., every lamp can be turned on by at least one other switch), then that switch can be safely ignored.

3. **Algorithm**:
   - **Step 1**: Read the input and construct a list for each lamp indicating which switches can turn it on.
   - **Step 2**: For each switch, check if there exists any lamp that is exclusively turned on by that switch. If no such lamp exists for a switch, that switch can be ignored.

### Solution Code
```python
n, m = map(int, input().split())
a = [input().strip() for _ in range(n)]

lamp_switches = []
for j in range(m):
    switches = []
    for i in range(n):
        if a[i][j] == '1':
            switches.append(i)
    lamp_switches.append(switches)

found = False
for i in range(n):
    possible = True
    for j in range(m):
        sw = lamp_switches[j]
        if len(sw) == 1 and sw[0] == i:
            possible = False
            break
    if possible:
        found = True
        break

print("YES" if found else "NO")
```

### Explanation
- **Reading Input**: The input is read and stored in a matrix where each row represents a switch and each column represents a lamp.
- **Constructing Lamp Switch Lists**: For each lamp, we create a list of switches that can turn it on.
- **Checking Switches**: For each switch, we check if there is any lamp that is exclusively turned on by this switch. If no such lamp exists, this switch can be ignored, and we print "YES". If all switches are essential for at least one lamp, we print "NO".

This approach efficiently checks the dependency of each lamp on the switches, ensuring that we determine the possibility of ignoring a switch in linear time relative to the number of switches and lamps, making it suitable for large inputs.
