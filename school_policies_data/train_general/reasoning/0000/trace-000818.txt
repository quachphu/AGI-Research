To solve this problem, we need to determine the sum of the shortest distances between all pairs of cities in Berland after each new road is added. The solution involves updating the shortest path matrix incrementally as each new road is considered.

### Approach
1. **Input Reading**: Read the number of cities and the initial shortest distance matrix.
2. **Process Each New Road**: For each new road, check if it provides a shorter path between its two cities than the current shortest path.
3. **Update Distance Matrix**: If the new road provides a shorter path, update the distance matrix by considering paths that use this new road.
4. **Sum Calculation**: After processing each new road, compute the sum of the shortest distances between all pairs of cities.

### Solution Code
```python
n = int(input())
d = []
for _ in range(n):
    row = list(map(int, input().split()))
    d.append(row.copy())

k = int(input())
roads = []
for _ in range(k):
    a, b, c = map(int, input().split())
    a -= 1  # convert to 0-based index
    b -= 1
    roads.append((a, b, c))

sums = []

for a, b, c in roads:
    if c < d[a][b]:
        # Update the distance between a and b
        d[a][b] = c
        d[b][a] = c
        # Iterate over all pairs to update via a and via b
        for i in range(n):
            for j in range(n):
                via_a = d[i][a] + c + d[b][j]
                via_b = d[i][b] + c + d[a][j]
                new_dist = min(d[i][j], via_a, via_b)
                if new_dist < d[i][j]:
                    d[i][j] = new_dist
                    d[j][i] = new_dist  # since it's undirected

    # Calculate the sum of all pairs i < j
    total = 0
    for i in range(n):
        for j in range(i + 1, n):
            total += d[i][j]
    sums.append(str(total))

print(' '.join(sums))
```

1. **Reading Input**: The input includes the number of cities, the initial shortest distance matrix, and the details of each planned road.
2. **Processing Each Road**: For each new road, check if it shortens the distance between its two cities. If it does, update the shortest distance matrix.
3. **Updating Distances**: For each pair of cities, check if using the new road provides a shorter path. This involves checking paths through both endpoints of the new road.
4. **Sum Calculation**: After processing each road, compute the sum of the shortest distances between all pairs of cities and store the result.

This approach ensures that each new road is efficiently considered, and the shortest paths are updated incrementally, leading to the correct sum after each addition. The algorithm efficiently handles up to 300 cities and 300 new roads, ensuring optimal performance.
