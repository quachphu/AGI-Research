2. **Basket Formation**: Divide the sorted teams into four baskets. Each basket will contain `m` teams, where `m` is the number of groups (calculated as `n // 4`).
3. **Random Number Generator (RNG)**: Implement the RNG to generate indices for selecting teams from the baskets. The RNG updates its state each time it is called.
4. **Group Formation**: For each group (except the last one), select one team from each basket using the RNG indices. The last group is formed from the remaining teams in each basket.
5. **Sorting and Output**: For each group, sort the teams by their ratings in descending order and print them.

### Solution Code
```python
n = int(input())
x, a, b, c = map(int, input().split())
teams = []
for _ in range(n):
    name, rating = input().split()
    teams.append((name, int(rating)))

# Sort teams by descending rating
teams.sort(key=lambda t: -t[1])

m = n // 4
baskets = [[] for _ in range(4)]

    basket_idx = i // m
    baskets[basket_idx].append(teams[i])

current_x = x

def get_random():
    global current_x
    current_x = (a * current_x + b) % c
    return current_x

groups = []

# Form the first m-1 groups
for _ in range(m - 1):
    group = []
    for j in range(4):
        s = len(baskets[j])
        k = get_random()
        idx = k % s
        selected_team = baskets[j].pop(idx)
        group.append(selected_team)
    groups.append(group)

# Form the last group from the remaining teams
last_group = []
for j in range(4):
    last_group.append(baskets[j][0])

    # Sort the group in descending order of rating
    sorted_group = sorted(group, key=lambda t: -t[1])
    print(f"Group {chr(ord('A') + i)}:")
    for team in sorted_group:
```
