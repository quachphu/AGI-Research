To solve this problem, we need to determine the maximum sum of elements that can be selected from an array following specific rules. The rules state that the first element chosen must not be the first element in the array, and each subsequent element must be at an index that is a multiple of any previously chosen index. The goal is to maximize the sum of these selected elements.

### Approach
1. **Understanding the Problem**: The key insight is that once an index is chosen, all its multiples can be included in the sum. This means that for each starting index (from 2 to N), we can compute the sum of all elements at indices that are multiples of the starting index.
2. **Efficient Calculation**: For each possible starting index, compute the sum of all elements at its multiples. This can be done efficiently by iterating through each index and summing its multiples.
3. **Maximization**: Track the maximum sum obtained from all possible starting indices.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        A = list(map(int, input[ptr:ptr + N]))
        ptr += N
        max_sum = 0
        for i in range(2, N + 1):
            current_sum = 0
            for j in range(i, N + 1, i):
                current_sum += A[j - 1]
            if current_sum > max_sum:
                max_sum = current_sum
        print(max_sum)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Iterating Over Test Cases**: For each test case, read the array size and the array elements.
3. **Calculating Maximum Sum**: For each possible starting index (from 2 to N), calculate the sum of elements at all multiples of that index. This is done using nested loops where the outer loop iterates over possible starting indices and the inner loop sums elements at their multiples.
4. **Tracking Maximum Sum**: Keep track of the highest sum encountered during these calculations and print it for each test case.

This approach ensures that we efficiently compute the required sums using properties of multiples, leading to an optimal solution within acceptable time complexity.
