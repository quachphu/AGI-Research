To solve this problem, we need to determine if a body in space, subjected to multiple force vectors, remains in equilibrium. The body is in equilibrium if the sum of all the force vectors acting on it is zero. This means the sum of the x-components, y-components, and z-components of all the vectors must each be zero.

### Approach
1. **Read Input:** First, read the number of force vectors, `n`.
2. **Initialize Sums:** Initialize three variables to keep track of the sum of the x, y, and z components of the vectors.
3. **Sum Components:** For each vector, read its components, convert them to integers, and add each component to the respective sum.
4. **Check Equilibrium:** After processing all vectors, check if all three sums (x, y, z) are zero. If they are, the body is in equilibrium; otherwise, it is not.

### Solution Code
```python
n = int(input())
sum_x = sum_y = sum_z = 0

for _ in range(n):
    x, y, z = map(int, input().split())
    sum_x += x
    sum_y += y
    sum_z += z

print("YES" if sum_x == sum_y == sum_z == 0 else "NO")
```

### Explanation
1. **Reading Input:** The first input line gives the number of vectors. Subsequent lines each provide the components of a vector.
2. **Summing Components:** For each vector, the x, y, and z components are added to cumulative sums.
3. **Equilibrium Check:** After all vectors are processed, we check if the cumulative sums of all components are zero. If they are, the body is in equilibrium (output "YES"), otherwise it is not (output "NO").

This approach ensures that we efficiently compute the necessary sums and check the equilibrium condition in linear time, O(n), where n is the number of vectors, making it optimal for the given constraints.
