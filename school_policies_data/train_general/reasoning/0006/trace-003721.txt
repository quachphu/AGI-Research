To solve this problem, we need to determine the minimum cost to buy at least the required quantity of water, considering both 1-liter and 500-milliliter bottles. The solution must account for the possibility that buying more than the required quantity might be cheaper if the exact quantity cannot be met with a lower cost combination.

### Approach
1. **Understand the Input**: The input consists of three integers: the price of a 1-liter bottle (A), the price of a 500-milliliter bottle (B), and the required quantity of water in milliliters (X).
2. **Iterate Over Possible Quantities of 1-liter Bottles**: We consider all possible quantities of 1-liter bottles (a) from 0 up to a calculated maximum. This maximum is determined by the formula `(X + 1000) // 1000`, ensuring we cover all feasible quantities that could potentially minimize the cost.
3. **Calculate Remaining Water Requirement**: For each quantity of 1-liter bottles (a), compute the remaining water needed to meet or exceed the requirement X.
4. **Determine 500-milliliter Bottles Needed**: Calculate the minimum number of 500-milliliter bottles (b) required to cover any remaining water need after accounting for the 1-liter bottles.
5. **Compute Total Cost**: For each combination of a and b, compute the total cost and track the minimum cost encountered.

### Solution Code
```python
A, B, X = map(int, input().split())
min_cost = float('inf')
max_a = (X + 1000) // 1000
for a in range(max_a + 1):
    rem = X - a * 1000
    if rem <= 0:
        b = 0
    else:
        b = (rem + 499) // 500
    cost = a * A + b * B
    if cost < min_cost:
        min_cost = cost
print(min_cost)
```

### Explanation
1. **Reading Input**: The input values for A, B, and X are read and parsed.
2. **Initialization**: The minimum cost is initialized to a very large number to ensure any valid cost will be lower.
3. **Iterating Over 1-liter Bottles**: The loop runs from 0 to the calculated maximum number of 1-liter bottles needed to cover the requirement X.
4. **Calculating Remaining Water**: For each quantity of 1-liter bottles (a), the remaining water needed (rem) is computed. If the remaining water is non-positive, no 500-milliliter bottles are needed. Otherwise, the number of 500-milliliter bottles required is calculated using integer division to ensure rounding up.
5. **Updating Minimum Cost**: For each combination of 1-liter and 500-milliliter bottles, the total cost is computed and compared with the current minimum cost, updating it if a lower cost is found.

This approach ensures that all possible combinations of bottle quantities are considered efficiently, leading to the optimal solution.
