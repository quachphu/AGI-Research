To solve this problem, we need to calculate the weight of a word based on specific rules where some characters are skipped. The weight of each character from 'a' to 'z' is their position in the alphabet (e.g., 'a' is 1, 'b' is 2, etc.). Skipped characters contribute 0 to the total weight.

### Approach
1. **Input Reading**: Read all input lines at once for efficiency, especially given the constraints.
2. **Processing Each Test Case**:
   - For each test case, read the word, the number of skipped characters, and the skipped characters themselves.
   - Convert the list of skipped characters into a set for O(1) look-up time.
3. **Calculate Weight**: Iterate over each character in the word. If the character is in the skipped set, add 0 to the total weight; otherwise, add its corresponding alphabet position value.
4. **Output the Result**: After processing each word, print the computed weight.

### Solution Code
```python
import sys

def main():
    input_lines = sys.stdin.read().splitlines()
    idx = 0
    T = int(input_lines[idx].strip())
    idx += 1
    for _ in range(T):
        word = input_lines[idx].strip()
        idx += 1
        N = int(input_lines[idx].strip())
        idx += 1
        skipped_chars = input_lines[idx].strip().split()
        idx += 1
        skipped_set = set(skipped_chars)
        total = 0
        for c in word:
            if c not in skipped_set:
                total += ord(c) - ord('a') + 1
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input Efficiently**: Using `sys.stdin.read().splitlines()` allows us to read all input at once, which is more efficient for large input sizes.
- **Set for Skipped Characters**: Converting the skipped characters into a set ensures that checking if a character is skipped is done in constant time, O(1).
- **Weight Calculation**: For each character in the word, we check if it is in the skipped set. If not, we compute its weight using its position in the alphabet (calculated using `ord(c) - ord('a') + 1`).

This approach efficiently handles the constraints and ensures that each test case is processed in linear time relative to the length of the word, making the solution both optimal and easy to understand.
