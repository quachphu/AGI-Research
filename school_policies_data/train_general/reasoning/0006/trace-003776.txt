The solution should provide the starting floor and the number of floors in the sequence. If there are multiple solutions with the same length, the one with the smallest starting floor should be chosen.

### Approach
1. **Problem Analysis**: The problem requires finding the longest sequence of consecutive integers (floors) that sum up to a given budget. The sum of consecutive integers starting from `s` for `k` terms can be represented using the formula for the sum of an arithmetic series. Rearranging this formula helps in efficiently determining possible values of `s` and `k`.

2. **Mathematical Insight**: The sum of `k` consecutive integers starting from `s` is given by:
   \[
   \text{Sum} = \frac{k}{2} \times (2s + (k - 1))
   \]
   Rearranging this formula, we get:
   \[
   2b = k(2s + k - 1)
   \]
   where `b` is the budget. This equation helps in checking possible values of `k` efficiently.

3. **Efficient Search**: Instead of iterating through all possible values of `k`, we use the insight that the maximum possible value of `k` can be derived from the quadratic formula. This reduces the search space significantly, allowing us to check values of `k` from the maximum possible down to 1.

4. **Validation**: For each `k`, we check if it can divide `2b` and if the resulting value for `s` is a positive integer. The first valid `k` found from the maximum downwards is the solution.

### Solution Code
```python
import math
import sys

def find_skyscraper_plan():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        b = int(line)
        if b == 0:
            break
        max_k = (math.isqrt(8 * b + 1) - 1) // 2
        ans_s, ans_k = b, 1
        for k in range(max_k, 0, -1):
            if (2 * b) % k != 0:
                continue
            temp = (2 * b // k) - k + 1
            if temp <= 0 or temp % 2 != 0:
                continue
            s = temp // 2
            if s >= 1:
                ans_s, ans_k = s, k
                break
        print(f"{ans_s} {ans_k}")

find_skyscraper_plan()
```

3. **Iterating k Values**: The code iterates from the maximum possible `k` down to 1, checking each value for validity.
4. **Validation Check**: For each `k`, the code checks if it divides `2b` and if the resulting value for `s` is a positive integer.
5. **Output**: The first valid `k` found (starting from the largest possible) determines the solution, which is printed as the starting floor and the number of floors.

This approach ensures that we efficiently find the longest sequence of floors that meet the budget requirement, adhering to the constraints and providing optimal performance.
