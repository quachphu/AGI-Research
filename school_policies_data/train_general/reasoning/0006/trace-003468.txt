To solve this problem, we need to determine if the string "CF" can be obtained as a subsequence from a given input string by deleting some characters. A subsequence means that the characters 'C' and 'F' must appear in order, but not necessarily consecutively.

### Approach
1. **Identify the First 'C'**: Traverse the input string to find the first occurrence of the character 'C'. This marks the starting point for our subsequence search.
2. **Check for Subsequent 'F'**: After locating the first 'C', continue traversing the string to check if there is a subsequent 'F'. If such an 'F' is found, print "Yes" and exit immediately. If the end of the string is reached without finding an 'F' after the first 'C', print "No".

This approach ensures that we efficiently check for the required subsequence in a single pass through the string, making the solution both optimal and straightforward.

### Solution Code
```python
def check_cf():
    s = input().strip()
    found_c = False
    for c in s:
        if not found_c:
            if c == 'C':
                found_c = True
        else:
            if c == 'F':
                print("Yes")
                return
    print("No")

check_cf()
```

### Explanation
- **Reading Input**: The input string is read and stripped of any leading or trailing whitespace.
- **Tracking 'C'**: We use a boolean flag `found_c` to track whether we have encountered the first 'C'. Once 'C' is found, we set this flag to `True`.
- **Checking for 'F'**: After finding the first 'C', we look for the next occurrence of 'F'. If found, we immediately print "Yes" and exit the function. If we reach the end of the string without finding an 'F' after the first 'C', we print "No".

This solution efficiently checks for the subsequence "CF" in linear time, O(n), where n is the length of the input string, ensuring optimal performance.
