To solve this problem, we need to determine the number of remote planets in a solar system structured as a tree. A remote planet is defined as a planet connected to the rest via only one tunnel, which corresponds to a leaf node in a tree structure.

### Approach
1. **Understanding the Tree Structure**: The solar system is represented as a tree, where each node (planet) is connected such that there is exactly one path between any two nodes. In a tree, leaf nodes are those with exactly one connection (degree of 1).
2. **Degree Counting**: For each planet, we count the number of connections (edges) it has. A planet with a degree of 1 is a leaf node and thus a remote planet.
3. **Input Processing**: Read the number of planets and the edges connecting them, then compute the degree for each planet.
4. **Count Leaf Nodes**: Sum the number of planets with a degree of 1 to get the count of remote planets.

### Solution Code
```python
n = int(input())
degrees = [0] * (n + 1)
for _ in range(n - 1):
    u, v = map(int, input().split())
    degrees[u] += 1
    degrees[v] += 1

count = sum(1 for d in degrees[1:] if d == 1)
print(count)
```

### Explanation
1. **Reading Input**: The first line gives the number of planets, `n`. The subsequent `n-1` lines describe the bidirectional tunnels between planets.
2. **Degree Calculation**: For each tunnel, increment the degree count of the connected planets.
3. **Leaf Node Count**: After processing all edges, count how many planets have a degree of 1. This count is the number of remote planets.

This approach efficiently computes the result by leveraging the properties of tree structures, ensuring an optimal solution with a time complexity of O(n), where n is the number of planets.
