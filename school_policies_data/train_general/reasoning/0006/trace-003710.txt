To solve this problem, we need to determine the last coordinate Karan can reach in a long jump event given his maximum jump capacity. The coordinates where he can step are provided, and he can only jump to the next coordinate if it is within his maximum jump capacity from his current position.

### Approach
1. **Input Reading and Sorting**: Read the input values, including the number of coordinates and the maximum jump capacity. The coordinates are then sorted to ensure they are in ascending order, which is necessary to check consecutive jumps.
2. **Iterative Check**: Starting from the first coordinate, iterate through each subsequent coordinate. For each coordinate, check if it is within the maximum jump capacity from the current position. If it is, update the current position to this coordinate. If it is not, stop the iteration as further coordinates will also be out of reach due to the sorted order.
3. **Output the Result**: The last reachable coordinate is printed as the result.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    k = int(input[1])
    coords = list(map(int, input[2:2+n]))
    coords.sort()
    current = coords[0]
    for x in coords[1:]:
        if x <= current + k:
            current = x
        else:
            break
    print(current)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints where the number of coordinates can be very large. The input is split into a list of integers.
2. **Sorting Coordinates**: The coordinates are sorted to ensure they are in ascending order, which allows us to check each subsequent coordinate sequentially.
3. **Iterating Through Coordinates**: Starting from the first coordinate, each subsequent coordinate is checked to see if it is within the maximum jump distance from the current position. If it is, the current position is updated. If a coordinate is found that is out of reach, the loop breaks early as further coordinates will also be out of reach.
4. **Output**: The last reachable coordinate is printed as the result.

This approach efficiently determines the farthest coordinate Karan can reach by leveraging sorting and a single linear pass through the coordinates, ensuring optimal performance even for large input sizes.
