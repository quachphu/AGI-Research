To solve this problem, we need to determine the area of the white region remaining in a rectangle after applying a series of painting operations. Each operation paints a specific region of the rectangle black, and the goal is to compute the area of the region that remains white after all operations are applied.

### Approach
1. **Initialization**: Start with the entire rectangle defined by its lower-left corner (0, 0) and upper-right corner (W, H).
2. **Boundary Adjustment**: For each painting operation, adjust the boundaries of the remaining white region based on the type of operation:
   - **Type 1 (x < x_i)**: Adjust the left boundary to be the maximum of the current left boundary and x_i.
   - **Type 2 (x > x_i)**: Adjust the right boundary to be the minimum of the current right boundary and x_i.
   - **Type 3 (y < y_i)**: Adjust the bottom boundary to be the maximum of the current bottom boundary and y_i.
   - **Type 4 (y > y_i)**: Adjust the top boundary to be the minimum of the current top boundary and y_i.
3. **Area Calculation**: After processing all operations, compute the width and height of the remaining white region. If the adjusted boundaries result in invalid dimensions (negative width or height), the area is zero. Otherwise, the area is the product of the valid width and height.

### Solution Code
```python
import sys

def main():
    W, H, N = map(int, sys.stdin.readline().split())
    left, right = 0, W
    bottom, top = 0, H

    for _ in range(N):
        x, y, a = map(int, sys.stdin.readline().split())
        if a == 1:
            left = max(left, x)
        elif a == 2:
            right = min(right, x)
        elif a == 3:
            bottom = max(bottom, y)
        elif a == 4:
            top = min(top, y)

    width = max(0, right - left)
    height = max(0, top - bottom)
    print(width * height)

if __name__ == "__main__":
    main()
```

### Explanation
- **Initialization**: The initial boundaries of the white region are set to the entire rectangle (0 to W for x-axis and 0 to H for y-axis).
- **Boundary Adjustments**: Each operation modifies one of the boundaries to exclude the painted region. For example, a type 1 operation (x < x_i) increases the left boundary, effectively excluding all regions to the left of x_i from the white area.
- **Final Calculation**: After all operations, the remaining white region is a rectangle defined by the adjusted boundaries. The area is computed as the product of the width and height of this rectangle, ensuring non-negative values by using the `max` function.

This approach efficiently processes each operation in constant time, resulting in an overall time complexity of O(N), which is optimal for the given constraints.
