To solve this problem, we need to determine if there exist three adjacent faces on a cube that are all painted the same color. The cube's faces are given in a specific order, and we need to check all possible triplets of adjacent faces (corners) to see if any of them meet the criteria.

### Approach
1. **Understanding Cube Structure**: Each corner of a cube is formed by three adjacent faces. These faces are one from each pair of opposite faces (front/back, left/right, top/bottom).
2. **Predefined Triplets**: There are 8 possible corners on a cube, each represented by a triplet of indices corresponding to the cube's faces. These triplets are derived from the given order of the cube's faces.
3. **Check Triplets**: For each test case, check all 8 predefined triplets. If any triplet has all three faces of the same color, the answer is "YES"; otherwise, it is "NO".

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    # Predefined triplets representing the corners (indices of the faces)
    triplets = [
        (0, 2, 4),  # front, left, top
        (0, 2, 5),  # front, left, bottom
        (0, 3, 4),  # front, right, top
        (0, 3, 5),  # front, right, bottom
        (1, 2, 4),  # back, left, top
        (1, 2, 5),  # back, left, bottom
        (1, 3, 4),  # back, right, top
        (1, 3, 5)   # back, right, bottom
    ]
    for _ in range(T):
        # Read the six colors for the current test case
        colors = input[idx:idx+6]
        idx += 6
        found = False
        # Check each triplet to see if all three colors are the same
        for a, b, c in triplets:
            if colors[a] == colors[b] == colors[c]:
                found = True
                break
        print("YES" if found else "NO")

solve()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and split into a list for efficient processing, especially given the large possible number of test cases.
2. **Predefined Triplets**: The 8 triplets represent all possible corners of the cube. Each triplet consists of indices corresponding to the front/back, left/right, and top/bottom faces.
3. **Checking Each Test Case**: For each test case, the cube's face colors are checked against each triplet. If any triplet has all three faces of the same color, the result is immediately "YES"; otherwise, after checking all triplets, the result is "NO".

This approach ensures that each test case is processed in constant time, making the solution efficient and suitable for the given constraints.
