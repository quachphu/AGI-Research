To solve this problem, we need to determine the maximum possible total after-tax price of two items after a VAT rate change, given their total after-tax price before the change. The approach involves systematically exploring all possible pairs of before-tax prices that could have resulted in the given sum under the old VAT rate and then calculating the maximum sum under the new VAT rate.

### Approach
1. **Understanding the Problem**: The task is to find the maximum possible sum of after-tax prices of two items under a new VAT rate, given their sum under the old VAT rate. The key challenge is to consider all valid pairs of before-tax prices that meet the original sum constraint and then compute the maximum sum under the new rate.

2. **Formulating the Solution**:
   - **Iterate Over Possible Before-Tax Prices**: For each possible before-tax price of the first item (a), compute its after-tax price under the old VAT rate.
   - **Determine Valid Pairs**: For each possible value of a, determine the range of valid before-tax prices for the second item (b) such that their combined after-tax sum under the old rate equals the given sum (s).
   - **Adjust for New VAT Rate**: For each valid pair (a, b), compute the after-tax prices under the new VAT rate and track the maximum sum.

3. **Efficient Calculation**:
   - Use mathematical bounds to determine valid ranges for b efficiently, avoiding brute-force enumeration of all possible pairs.
   - Compute the maximum possible sum under the new VAT rate by considering the upper bounds of valid ranges for b to minimize redundant calculations.

import sys

def compute_max(x, y, s):
    max_sum = 0
    for a in range(1, s):  # a ranges from 1 to s-1 inclusive
        fa = (a * (100 + x)) // 100
        k = s - fa
        if k < 0:
            continue
        denominator = 100 + x
        # Calculate min_b using ceiling division
        min_b = (100 * k + denominator - 1) // denominator
        # Calculate max_b
        max_b = (100 * (k + 1) - 1) // denominator
        # Clamp to valid b range [1, s-1]
        min_b = max(min_b, 1)
        max_b = min(max_b, s - 1)
        if min_b > max_b:
            continue
        # Compute new prices
        new_a = (a * (100 + y)) // 100
        new_b_max = (max_b * (100 + y)) // 100
        current_sum = new_a + new_b_max
        if current_sum > max_sum:
            max_sum = current_sum
    return max_sum

def main():
    for line in sys.stdin:
        x, y, s = map(int, line.strip().split())
        if x == 0 and y == 0 and s == 0:
            break
        print(compute_max(x, y, s))

if __name__ == "__main__":
    main()
