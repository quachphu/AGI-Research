To solve this problem, we need to determine the number of supercentral points in a given set of points. A supercentral point is defined as a point that has at least one neighbor in each of the four cardinal directions: up, down, left, and right.

### Approach
1. **Data Structures**: Use dictionaries to group points by their x-coordinates and y-coordinates. This helps efficiently check for neighbors in each direction.
2. **Preprocessing**: For each x-coordinate, store the sorted list of y-coordinates. Similarly, for each y-coordinate, store the sorted list of x-coordinates.
3. **Check Neighbors**: For each point, check if there exists at least one neighbor in each direction using the preprocessed data. Specifically:
   - **Upper Neighbor**: Check if the maximum y-coordinate for the same x is greater than the current y.
   - **Lower Neighbor**: Check if the minimum y-coordinate for the same x is less than the current y.
   - **Right Neighbor**: Check if the maximum x-coordinate for the same y is greater than the current x.
   - **Left Neighbor**: Check if the minimum x-coordinate for the same y is less than the current x.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n = int(sys.stdin.readline())
    points = []
    x_to_ys = defaultdict(list)
    y_to_xs = defaultdict(list)
    for _ in range(n):
        x, y = map(int, sys.stdin.readline().split())
        points.append((x, y))
        x_to_ys[x].append(y)
        y_to_xs[y].append(x)
    
    # Sort the lists
    for x in x_to_ys:
        x_to_ys[x].sort()
    for y in y_to_xs:
        y_to_xs[y].sort()
    
    count = 0
    for x, y in points:
        # Check upper and lower neighbors
        ys = x_to_ys[x]
        upper = ys[-1] > y if ys else False
        lower = ys[0] < y if ys else False
        
        # Check left and right neighbors
        xs = y_to_xs[y]
        right = xs[-1] > x if xs else False
        left = xs[0] < x if xs else False
        
        if upper and lower and left and right:
            count += 1
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and stored in a list of points. Two dictionaries are created to map each x-coordinate to its y-coordinates and each y-coordinate to its x-coordinates.
2. **Sorting**: The lists of y-coordinates for each x and x-coordinates for each y are sorted to facilitate efficient neighbor checks.
3. **Checking Conditions**: For each point, the existence of upper, lower, left, and right neighbors is checked by comparing against the maximum and minimum values in the sorted lists from the dictionaries.
4. **Counting Supercentral Points**: If all four conditions are satisfied for a point, it is counted as a supercentral point.

This approach efficiently groups and sorts coordinates, allowing for quick neighbor checks and ensuring the solution is optimal even for the upper constraint of 200 points.
