To solve this problem, we need to determine the minimum number of character replacements required to ensure that no two adjacent characters are the same in a string T, which is formed by concatenating K copies of a given string S.

### Approach
1. **Uniform String Check**: If all characters in S are the same, the solution is straightforward. The minimum replacements needed for a string of length L repeated K times is `(L * K) // 2`.
2. **Non-Uniform String Handling**:
   - **Runs Identification**: Split the string S into runs of consecutive identical characters. For example, "issii" becomes runs [('i', 1), ('s', 2), ('i', 2)].
   - **Base Changes Calculation**: Calculate the minimum replacements required within a single copy of S by summing `(run_length // 2)` for each run.
   - **Junction Handling**: If the first and last characters of S are the same, calculate additional replacements needed at the junctions between consecutive copies of S. This is done by considering the combined run formed by the suffix of one copy and the prefix of the next.

### Solution Code
```python
def get_runs(s):
    if not s:
        return []
    runs = []
    current_char = s[0]
    count = 1
    for c in s[1:]:
        if c == current_char:
            count += 1
        else:
            runs.append((current_char, count))
            current_char = c
            count = 1
    runs.append((current_char, count))
    return runs

S = input().strip()
K = int(input())

if len(S) == 0:
    print(0)
else:
    if all(c == S[0] for c in S):
        total = (len(S) * K) // 2
    else:
        runs = get_runs(S)
        base_changes = sum((length // 2) for char, length in runs)
        if S[0] != S[-1]:
            total = base_changes * K
        else:
            prefix_len = runs[0][1]
            suffix_len = runs[-1][1]
            combined = prefix_len + suffix_len
            additional = (combined // 2) - (prefix_len // 2 + suffix_len // 2)
            total = base_changes * K + additional * (K - 1)
    print(total)
```

### Explanation
1. **Uniform String Check**: If all characters in S are the same, the result is derived directly from the formula for a single long run.
2. **Runs Identification**: The string S is broken down into segments (runs) of consecutive identical characters. This helps in calculating the necessary changes within each segment.
3. **Base Changes Calculation**: For each run, the minimum replacements needed are determined by the formula `run_length // 2`.
4. **Junction Handling**: When the first and last characters of S are the same, additional replacements are calculated for the combined run formed at the junction of consecutive copies. This is done by considering the combined length of the prefix and suffix runs and adjusting for the changes already accounted for in individual copies.

This approach efficiently handles both small and large values of K by focusing on the structural properties of the string S and leveraging mathematical properties to minimize redundant calculations.
