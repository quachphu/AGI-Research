The cells can already be connected if they are touching or overlapping, and the goal is to find the minimal additional corridors needed.

### Approach
1. **Problem Analysis**:
   - Each cell is a sphere with given coordinates and radius.
   - Cells are connected if they overlap or touch, requiring no additional corridors.
   - If cells are not connected, we need to build the shortest possible corridors to connect all cells.

2. **Graph Representation**:
   - Represent each cell as a node in a graph.
   - Calculate the edge weights between each pair of nodes (cells) as the Euclidean distance between their centers minus the sum of their radii. If this value is negative (overlapping or touching), the edge weight is zero.

3. **Minimum Spanning Tree (MST)**:
   - Use Kruskal's algorithm to find the MST of the graph. The MST will connect all nodes with the minimum total edge weight, which corresponds to the minimal total length of corridors needed.

```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0

    while True:
        n = int(input[ptr])
        ptr += 1
        if n == 0:
            break

        cells = []
        for _ in range(n):
            x = float(input[ptr])
            y = float(input[ptr + 1])
            z = float(input[ptr + 2])
            r = float(input[ptr + 3])
            cells.append((x, y, z, r))
            ptr += 4

        edges = []
        for i in range(n):
            for j in range(i + 1, n):
                xi, yi, zi, ri = cells[i]
                xj, yj, zj, rj = cells[j]
                dx = xi - xj
                dy = yi - yj
                dz = zi - zj
                dist = (dx**2 + dy**2 + dz**2) ** 0.5
                sum_r = ri + rj
                weight = max(0.0, dist - sum_r)
                edges.append((weight, i, j))

        edges.sort()

        class DSU:
            def __init__(self, size):
                self.parent = list(range(size))
                self.rank = [0] * size

            def find(self, x):
                if self.parent[x] != x:
                    self.parent[x] = self.find(self.parent[x])
                return self.parent[x]

            def union(self, x, y):
                xroot = self.find(x)
                yroot = self.find(y)
                if xroot != yroot:
                    if self.rank[xroot] < self.rank[yroot]:
                        self.parent[xroot] = yroot
                    else:
                        self.parent[yroot] = xroot
                        if self.rank[xroot] == self.rank[yroot]:
                            self.rank[xroot] += 1

        dsu = DSU(n)
        total = 0.0

        for edge in edges:
            w, u, v = edge
            if dsu.find(u) != dsu.find(v):
                dsu.union(u, v)
                total += w

        print("{0:.3f}".format(total))

main()
```
