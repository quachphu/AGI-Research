To solve this problem, we need to determine the numerical rank of a given number among all permutations of its digits when sorted in lexicographical order. The rank is 1-based, meaning the smallest permutation has rank 1.

### Approach
1. **Precompute Factorials**: Since the maximum number of digits in the input is 18, we precompute factorials from 0! to 18! to efficiently calculate permutations later.
2. **Count Digit Frequencies**: For each input number, count the frequency of each digit (0-9).
3. **Calculate Rank**: For each digit in the input number, starting from the leftmost digit:
   - For each digit smaller than the current digit, calculate how many valid permutations can be formed by placing that smaller digit in the current position.
   - Adjust the count of the current digit and move to the next position.
4. **Sum Permutations**: Sum the number of permutations that can be formed with smaller digits at each position to determine the rank.

def precompute_factorials(max_n):
    fact = [1] * (max_n + 1)
    for i in range(1, max_n + 1):
        fact[i] = fact[i-1] * i
    return fact

            count[e] -= 1
            remaining_length = len(digits) - i - 1
            denominator = 1
            for d in range(10):
                denominator *= fact[count[d]]
            permutations = fact[remaining_length] // denominator
            sum_rank += permutations
            count[e] += 1
        count[current_digit] -= 1
    return sum_rank + 1
