To solve this problem, we need to determine the largest possible number divisible by 90 that Jeff can create using cards with digits 5 and 0. The solution involves leveraging the properties of numbers divisible by 90, which require the number to be divisible by both 9 and 10. 

### Approach
1. **Divisibility by 10**: The number must end in 0. Thus, there must be at least one 0 in the input cards.
2. **Divisibility by 9**: The sum of the digits must be a multiple of 9. Since each 5 contributes 5 to the sum, the number of 5s used must be such that their total sum is a multiple of 9. 

The steps to solve the problem are:
1. Count the number of 5s (`count5`) and 0s (`count0`) from the input.
2. If there are no 0s, output -1 as it's impossible to form a valid number.
3. Determine the maximum number of 5s that can be used such that their count is a multiple of 9.
4. If no valid multiple of 9 is found for the 5s, check if there are any 0s. If there are, output 0 (since 0 is a valid number).
5. If valid 5s and 0s are available, construct the number using the maximum valid 5s followed by all available 0s.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
count5 = a.count(5)
count0 = a.count(0)

if count0 == 0:
    print(-1)
else:
    max5 = (count5 // 9) * 9
    if max5 == 0:
        print(0)
    else:
        print('5' * max5 + '0' * count0)
```

### Explanation
1. **Input Handling**: Read the number of cards and their values.
2. **Count Calculation**: Count the occurrences of 5s and 0s.
3. **Check for 0s**: If there are no 0s, print -1 immediately as no valid number can be formed.
4. **Determine Valid 5s**: Calculate the largest multiple of 9 that is less than or equal to the count of 5s. This ensures the sum of the 5s used is a multiple of 9.
5. **Construct Result**: If valid 5s are found, use them followed by all available 0s to form the largest possible number. If no valid 5s are found but 0s exist, print 0.

This approach efficiently checks the necessary conditions and constructs the maximum valid number using simple arithmetic and string operations.
