To solve this problem, we need to determine the number of ways to partition N people into groups such that each group has at least K people. This problem can be efficiently solved using dynamic programming.

### Approach
1. **Dynamic Programming (DP) Setup**: We use a 2D DP table `dp` where `dp[n][k]` represents the number of ways to partition `n` people into groups where each group has at least `k` people.
2. **Recurrence Relation**:
   - If `k > n`, there are no valid partitions, so `dp[n][k] = 0`.
   - If `k == n`, there is exactly one valid partition (a single group of `n` people), so `dp[n][k] = 1`.
   - Otherwise, the number of partitions can be derived by considering two scenarios:
     1. Including a group of size `k` and partitioning the remaining `n-k` people into groups of at least `k` people.
     2. Excluding groups of size `k` and partitioning `n` people into groups of at least `k+1` people.
3. **Precomputation**: We precompute the DP table for all values of `n` (up to 200) and `k` (up to 200) to efficiently answer multiple queries.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    
    max_n = 200
    max_k = 200
    dp = [[0] * (max_k + 2) for _ in range(max_n + 1)]
    
    for n in range(0, max_n + 1):
        for k in range(max_k, 0, -1):
            if k > n:
                dp[n][k] = 0
            elif k == n:
                dp[n][k] = 1
            else:
                a = dp[n - k][k] if (n - k >= 0) else 0
                b = dp[n][k + 1] if (k + 1 <= max_k) else 0
                dp[n][k] = a + b
    
    results = []
    for _ in range(T):
        N = int(input[idx])
        K = int(input[idx + 1])
        idx += 2
        results.append(dp[N][K])
    
    for result in results:
        print(result)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially with multiple test cases.
2. **DP Table Initialization**: A 2D list `dp` is initialized to store the number of partitions for each `n` and `k`.
3. **Filling the DP Table**: The table is filled by iterating over possible values of `n` from 0 to 200 and `k` from 200 down to 1. This ensures that when computing `dp[n][k]`, the necessary values for `k+1` and `n-k` are already computed.
4. **Handling Queries**: After precomputing the DP table, each query is answered in constant time by directly accessing the precomputed value in the table.

This approach efficiently handles the constraints and provides quick responses to each query after an initial precomputation step.
