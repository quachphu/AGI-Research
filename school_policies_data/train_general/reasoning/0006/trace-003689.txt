To solve this problem, we need to determine the number of substrings of a given string `s` that can be transformed into an anagram of another string `p` by replacing '?' characters with any lowercase Latin letters. 

### Approach
1. **Check Length Validity**: If the length of `p` is greater than the length of `s`, there are no valid substrings, so the result is immediately 0.
2. **Frequency Count of `p`**: Compute the frequency count of each character in `p` to determine the required counts for any valid substring.
3. **Sliding Window Technique**: Use a sliding window of length equal to `p` to traverse through `s`, maintaining the frequency count of characters in the current window and the number of '?' characters.
4. **Validation Check**: For each window, check if the frequency counts of characters (excluding '?') do not exceed the corresponding counts in `p`. If they do, the window is invalid. If valid, increment the count of good substrings.

### Solution Code
```python
def main():
    import sys
    s = sys.stdin.readline().strip()
    p = sys.stdin.readline().strip()

    len_p = len(p)
    len_s = len(s)

    if len_p > len_s:
        print(0)
        return

    count_p = [0] * 26
    for c in p:
        count_p[ord(c) - ord('a')] += 1

    window_counts = [0] * 26
    num_q = 0
    answer = 0

    # Initialize the first window
    for i in range(len_p):
        c = s[i]
        if c == '?':
            num_q += 1
        else:
            idx = ord(c) - ord('a')
            window_counts[idx] += 1

    # Check the first window
    valid = True
    for i in range(26):
        if window_counts[i] > count_p[i]:
            valid = False
            break
    if valid:
        answer += 1

    # Slide the window through the rest of s
    for i in range(len_p, len_s):
        # Remove the leftmost character of the previous window
        left_char = s[i - len_p]
        if left_char == '?':
            num_q -= 1
        else:
            idx = ord(left_char) - ord('a')
            window_counts[idx] -= 1

        # Add the new rightmost character
        right_char = s[i]
        if right_char == '?':
            num_q += 1
        else:
            idx = ord(right_char) - ord('a')
            window_counts[idx] += 1

        # Check validity of the current window
        valid = True
        for j in range(26):
            if window_counts[j] > count_p[j]:
                valid = False
                break
        if valid:
            answer += 1

    print(answer)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Sliding Window Initialization**: The initial window is set to the first `len(p)` characters of `s`. We count the occurrences of each character and the number of '?' characters in this window.
2. **Validation of Initial Window**: Check if the initial window can be transformed into an anagram of `p` by comparing character counts and ensuring no character exceeds the count in `p`.
3. **Sliding the Window**: For each subsequent window, adjust the counts by removing the character that slides out of the window and adding the new character that slides in. Check validity similarly to the initial window.
4. **Efficiency**: This approach efficiently checks each possible window in linear time relative to the length of `s`, making it suitable for large input sizes. Each window check is done in constant time (O(26)), ensuring the solution is optimal.
