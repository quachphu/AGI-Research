To solve this problem, we need to determine if a given room can be exactly tiled with specified tiles without cutting any tiles. The tiles can be placed in either their original orientation or rotated by 90 degrees, but all tiles in a room must be oriented the same way.

### Approach
1. **Understand the Problem Constraints**: The room and tiles have integer dimensions, and the goal is to check if the room can be completely covered by tiles either in their original orientation or rotated.
2. **Check Both Orientations**: For each room and tile combination, check two possible orientations:
   - Original tile dimensions (width x height).
   - Rotated tile dimensions (height x width).
3. **Divisibility Check**: For each orientation, check if both the room's width and height are exactly divisible by the tile's width and height respectively. If either orientation fits perfectly, the answer is "yes"; otherwise, it is "no".

### Solution Code
```python
t = int(input())
for _ in range(t):
    a, b, c, d = map(int, input().split())
    option1 = (a % c == 0) and (b % d == 0)
    option2 = (a % d == 0) and (b % c == 0)
    print("yes" if option1 or option2 else "no")
```

### Explanation
1. **Reading Input**: The first line contains the number of test cases. Each subsequent line contains four integers representing the room dimensions and tile dimensions.
2. **Checking Orientations**: For each test case, we check two conditions:
   - **Original Orientation**: Check if the room's width is divisible by the tile's width and the room's height is divisible by the tile's height.
   - **Rotated Orientation**: Check if the room's width is divisible by the tile's height and the room's height is divisible by the tile's width.
3. **Output Result**: If either orientation fits perfectly, print "yes"; otherwise, print "no".

This approach efficiently checks both possible tile orientations in constant time for each test case, ensuring the solution is both optimal and easy to understand.
