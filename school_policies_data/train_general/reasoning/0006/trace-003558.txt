To solve this problem, we need to determine if Alice can win the 5-in-a-row game by placing a single 'X' in an empty cell (denoted by '.') on a 10x10 grid. Alice wins if she forms a line of at least 5 consecutive 'X's either horizontally, vertically, or diagonally.

### Approach
1. **Grid Traversal**: Iterate through each cell in the 10x10 grid.
2. **Check Empty Cells**: For each empty cell ('.'), simulate placing an 'X' and check if this creates a line of 5 or more consecutive 'X's.
3. **Direction Checks**: For each empty cell, check four possible directions for consecutive 'X's:
   - **Horizontal**: Check left and right from the cell.
   - **Vertical**: Check up and down from the cell.
   - **Diagonal Down-Right**: Check top-left to bottom-right direction.
   - **Diagonal Down-Left**: Check top-right to bottom-left direction.
4. **Count Consecutive 'X's**: For each direction, count consecutive 'X's in both directions from the cell. If the sum of consecutive 'X's in any direction is 5 or more, Alice can win immediately.

### Solution Code
```python
grid = [input().strip() for _ in range(10)]

def check_win():
    for i in range(10):
        for j in range(10):
            if grid[i][j] != '.':
                continue
            # Check horizontal
            left = 0
            y = j - 1
            while y >= 0 and grid[i][y] == 'X':
                left += 1
                y -= 1
            right = 0
            y = j + 1
            while y < 10 and grid[i][y] == 'X':
                right += 1
                y += 1
            if left + right + 1 >= 5:
                return True
            
            # Check vertical
            up = 0
            x = i - 1
            while x >= 0 and grid[x][j] == 'X':
                up += 1
                x -= 1
            down = 0
            x = i + 1
            while x < 10 and grid[x][j] == 'X':
                down += 1
                x += 1
            if up + down + 1 >= 5:
                return True
            
            # Check diagonal 1 (top-left to bottom-right)
            ul = 0
            x, y = i - 1, j - 1
            while x >= 0 and y >= 0 and grid[x][y] == 'X':
                ul += 1
                x -= 1
                y -= 1
            lr = 0
            x, y = i + 1, j + 1
            while x < 10 and y < 10 and grid[x][y] == 'X':
                lr += 1
                x += 1
                y += 1
            if ul + lr + 1 >= 5:
                return True
            
            # Check diagonal 2 (top-right to bottom-left)
            ur = 0
            x, y = i - 1, j + 1
            while x >= 0 and y < 10 and grid[x][y] == 'X':
                ur += 1
                x -= 1
                y += 1
            ll = 0
            x, y = i + 1, j - 1
            while x < 10 and y >= 0 and grid[x][y] == 'X':
                ll += 1
                x += 1
                y -= 1
            if ur + ll + 1 >= 5:
                return True
    return False

print('YES' if check_win() else 'NO')
```

### Explanation
- **Grid Traversal**: The code iterates over each cell in the 10x10 grid to check if it's an empty cell ('.').
- **Direction Checks**: For each empty cell, the code checks four possible directions (horizontal, vertical, and two diagonals) to count consecutive 'X's. This is done by moving step-by-step in both directions from the cell and summing the counts.
- **Immediate Win Check**: If any direction yields a sum of 5 or more consecutive 'X's (including the current cell), the function returns 'YES', indicating Alice can win. If no such cell exists, it returns 'NO'.

This approach efficiently checks all possible winning lines for Alice by simulating each possible move and leveraging directional checks to count consecutive 'X's.
