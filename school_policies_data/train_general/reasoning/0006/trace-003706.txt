To solve this problem, we need to determine how many times Benny slips and falls on icy points while following a set of movement instructions. A point becomes icy once Benny visits it, and she slips if she steps on an icy point again.

### Approach
1. **Track Visited Positions**: Use a set to keep track of all positions Benny has visited. Initially, the starting position (0, 0) is marked as visited.
2. **Simulate Movements**: For each movement instruction in the input string, compute the new position based on the current position and the direction of movement.
3. **Check for Slips**: Before moving to the new position, check if it has already been visited. If it has, increment the slip count.
4. **Update Visited Positions**: After checking for slips, add the new position to the set of visited positions to mark it as icy for future steps.

### Solution Code
```python
def count_falls():
    s = input().strip()
    current_x, current_y = 0, 0
    visited = {(current_x, current_y)}
    count = 0
    for c in s:
        if c == 'L':
            new_x, new_y = current_x, current_y - 1
        elif c == 'R':
            new_x, new_y = current_x, current_y + 1
        elif c == 'U':
            new_x, new_y = current_x - 1, current_y
        elif c == 'D':
            new_x, new_y = current_x + 1, current_y
        if (new_x, new_y) in visited:
            count += 1
        visited.add((new_x, new_y))
        current_x, current_y = new_x, new_y
    print(count)

count_falls()
```

### Explanation
- **Initialization**: Start at position (0, 0) and mark it as visited.
- **Movement Simulation**: For each character in the input string, compute the new position based on the direction ('L', 'R', 'U', 'D').
- **Slip Check**: Before moving to the new position, check if it is already in the visited set. If it is, increment the slip count.
- **Update Visited Set**: Add the new position to the visited set to ensure future visits to this position are counted as slips.

This approach efficiently tracks visited positions using a set, ensuring each check and insertion operation is done in average O(1) time, leading to an overall time complexity of O(n) where n is the length of the input string. This makes the solution suitable even for the upper constraint of 100,000 characters.
