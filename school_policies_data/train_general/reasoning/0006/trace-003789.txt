To solve this problem, we need to determine the maximum possible side length of a square that can be formed using some of the given wooden planks. The planks are placed side by side, and the square is cut from the resulting rectangle. The side length of the square is determined by the minimum of the number of planks used and the height of the shortest plank in the selected set.

### Approach
1. **Sort the Planks**: First, sort the planks in descending order of their heights. This allows us to efficiently consider the tallest planks first.
2. **Iterate and Evaluate**: For each possible number of planks (from 1 to n), calculate the minimum height of the selected planks (which is the height of the shortest plank in the sorted list up to that point) and the number of planks used. The maximum possible side length of the square at each step is the minimum of these two values.
3. **Track Maximum Value**: Keep track of the maximum side length encountered during the iteration over all possible numbers of planks.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    k = int(input[ptr])
    ptr += 1
    for _ in range(k):
        n = int(input[ptr])
        ptr += 1
        a = list(map(int, input[ptr:ptr + n]))
        ptr += n
        a.sort(reverse=True)
        max_s = 0
        for i in range(1, n + 1):
            current_a = a[i - 1]
            current_s = min(i, current_a)
            if current_s > max_s:
                max_s = current_s
        print(max_s)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given multiple test cases.
2. **Sorting**: The planks are sorted in descending order to facilitate easy access to the tallest available planks at each step.
3. **Iterating Through Planks**: For each possible number of planks (from 1 to n), compute the minimum height of the first `i` planks (which is the height of the `i`-th plank in the sorted list) and compare it with `i` (the number of planks used). The minimum of these two values gives the side length of the largest possible square that can be formed using those `i` planks.
4. **Tracking Maximum**: The maximum side length encountered during the iteration is recorded and printed for each test case.

This approach ensures that we efficiently determine the optimal solution by leveraging sorting and a single pass through the sorted list, resulting in a time complexity of O(n log n) per test case due to the sorting step.
