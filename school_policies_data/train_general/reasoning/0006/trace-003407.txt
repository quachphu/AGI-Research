To solve this problem, we need to determine if the concatenation of two positive integers, a and b, forms a perfect square number. 

### Approach
1. **Input Reading**: Read the integers a and b from the input.
2. **Concatenation**: Convert the integers to strings, concatenate them, and then convert the result back to an integer.
3. **Perfect Square Check**: Check if the resulting integer is a perfect square by comparing the square of the integer part of its square root with the number itself.

### Solution Code
```python
import math

a, b = map(int, input().split())
concatenated = str(a) + str(b)
n = int(concatenated)

sqrt_n = int(math.sqrt(n))
if sqrt_n * sqrt_n == n:
    print("Yes")
else:
    print("No")
```

### Explanation
1. **Reading Input**: The input is read as two integers, a and b, which are split and converted from the input string.
2. **Concatenation**: The integers a and b are converted to strings and concatenated to form a new string. This string is then converted back to an integer to form the concatenated number.
3. **Perfect Square Check**: The square root of the concatenated number is computed and converted to an integer. Squaring this integer and comparing it with the original number determines if the number is a perfect square. If they match, the output is "Yes"; otherwise, it is "No".

This approach efficiently checks for perfect square properties using mathematical operations, ensuring correctness and optimal performance given the problem constraints.
