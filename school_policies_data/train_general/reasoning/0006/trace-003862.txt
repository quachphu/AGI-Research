To solve this problem, we need to determine the maximum number of robots that can be kept such that their movable ranges do not intersect. The movable range of each robot is defined as an open interval (X_i - L_i, X_i + L_i), where the endpoints are excluded. 

### Approach
The problem can be efficiently solved using a greedy algorithm, which is a common strategy for interval scheduling problems. The key steps are:

1. **Interval Calculation**: For each robot, compute the start and end of its movable range.
2. **Sorting**: Sort the robots based on the end of their movable ranges.
3. **Greedy Selection**: Iterate through the sorted list and select the maximum number of non-overlapping intervals by always choosing the interval that ends the earliest and does not overlap with the previously selected interval.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    robots = []
    for _ in range(n):
        x, l = map(int, sys.stdin.readline().split())
        start = x - l
        end = x + l
        robots.append((end, start))  # Storing as (end, start) for sorting by end

    robots.sort()  # Sort by the end of the interval

    count = 0
    last_end = -float('inf')
    for end, start in robots:
        if start >= last_end:
            count += 1
            last_end = end

    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read efficiently using standard input functions to handle up to 100,000 robots.
2. **Interval Calculation**: For each robot, the start and end of its movable range are calculated as (X_i - L_i) and (X_i + L_i), respectively.
3. **Sorting**: The robots are sorted by the end of their intervals to facilitate the greedy selection process.
4. **Greedy Selection**: We iterate through the sorted intervals, keeping track of the end of the last selected interval. If the current interval's start is greater than or equal to the last selected interval's end, it is selected, and the count is incremented.

This approach ensures that we maximize the number of non-overlapping intervals by always selecting the interval that ends the earliest, thus leaving more room for subsequent intervals. The time complexity is dominated by the sorting step, making it O(N log N), which is efficient for the given constraints.
