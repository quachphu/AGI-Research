        tmp = [0] * n

class SparseTable:
    def __init__(self, data):
        self.n = len(data)
        self.log_table = [0] * (self.n +1)
        for i in range(2, self.n +1):
            self.log_table[i] = self.log_table[i//2] +1
        self.size = self.log_table[self.n] +1
        self.table = [[0]*self.n for _ in range(self.size)]
        self.table[0] = data[:]
        for j in range(1, self.size):
            for i in range(self.n - (1<<j) +1):
                self.table[j][i] = min(self.table[j-1][i], self.table[j-1][i + (1<<(j-1))])
    def query_min(self, l, r):
        length = r - l +1
        k = self.log_table[length]
        return min(self.table[k][l], self.table[k][r - (1<<k) +1])

1. **Heap Initialization**: Start by pushing all single-character substrings into the heap. Each entry in the heap is a tuple containing the substring, its starting index, and its length.
2. **Heap Processing**: Extract the smallest substring from the heap k times. After each extraction, if possible, push the next longer substring starting from the same index into the heap.
3. **Termination Check**: If the total number of substrings is less than k, output an appropriate message.

This approach ensures that we generate substrings in lexicographical order without explicitly storing all substrings, leveraging the efficiency of the heap structure to maintain order and manage the extraction and insertion operations.

### Solution Code
```python
import heapq

def main():
    import sys
    input = sys.stdin.read().split()
    s = input[0]
    k = int(input[1])
    n = len(s)
    total = n * (n + 1) // 2
    if k > total:
        print("No such line.")
        return
    
    heap = []
    for i in range(n):
        heapq.heappush(heap, (s[i], i, 1))
    
    result = ""
    for _ in range(k):
        current, i, length = heapq.heappop(heap)
        result = current
        if i + length < n:
            new_sub = s[i:i+length+1]
            heapq.heappush(heap, (new_sub, i, length + 1))
    
    print(result)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Heap Initialization**: We start by pushing all single-character substrings into the heap. Each entry is a tuple `(substring, starting index, length)`.
2. **Heap Processing**: For each of the k iterations, we extract the smallest substring from the heap. If there are more characters remaining from the starting index of the extracted substring, we generate the next longer substring and push it into the heap.
3. **Efficiency**: By using a heap, we ensure that each extraction and insertion operation is efficient (O(log n)), making the overall complexity manageable even for large inputs.

This approach efficiently generates the k-th smallest substring without generating all possible substrings upfront, leveraging the properties of the heap to maintain order dynamically.
