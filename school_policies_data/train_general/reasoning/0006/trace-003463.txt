To solve this problem, we need to efficiently handle a series of operations on a string that can reverse it or add characters to either end. The challenge is to perform these operations in an optimal manner given the constraints.

### Approach
1. **Use a Deque**: A deque (double-ended queue) allows O(1) time complexity for both appending and prepending characters, which is crucial given the large number of operations.
2. **Track Reversed State**: Instead of actually reversing the string each time a reverse operation is called, we use a boolean flag to track whether the string is currently reversed. This allows us to toggle the flag in O(1) time.
3. **Adjust Add Operations Based on Reversed State**: Depending on whether the string is currently reversed, adding a character to the front or end of the string translates to appending or prepending to the deque accordingly.

### Solution Code
```python
import sys
from collections import deque

def main():
    s = sys.stdin.readline().strip()
    q = int(sys.stdin.readline())
    dq = deque(s)
    reversed_flag = False

    for _ in range(q):
        query = sys.stdin.readline().split()
        if query[0] == '1':
            reversed_flag = not reversed_flag
        else:
            f = query[1]
            c = query[2]
            if f == '1':
                if reversed_flag:
                    dq.append(c)
                else:
                    dq.appendleft(c)
            else:
                if reversed_flag:
                    dq.appendleft(c)
                else:
                    dq.append(c)

    if reversed_flag:
        dq = deque(reversed(dq))

    print(''.join(dq))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The initial string and the number of operations are read from standard input.
2. **Deque Initialization**: The initial string is stored in a deque to allow efficient operations on both ends.
3. **Processing Queries**: Each query is processed to either reverse the string (by toggling the reversed flag) or add a character to the front or end of the string. The actual operation on the deque is adjusted based on the current reversed state.
4. **Final Adjustment**: After processing all queries, if the reversed flag is set, the deque is reversed once to produce the final string, which is then printed.

This approach ensures that each operation is handled in O(1) time, making the solution efficient even for the upper constraint limits. The final reversal, if needed, is done in O(n) time, which is manageable given the problem constraints.
