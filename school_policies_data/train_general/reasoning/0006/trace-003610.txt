To solve this problem, we need to determine if Raju can draw specific angles using the angles he knows and their combinations through addition and subtraction. The solution involves understanding the greatest common divisor (GCD) of the known angles and their relationship with 360 degrees, which is a full circle.

### Approach
1. **Compute the GCD of Known Angles**: The key insight is that any combination of the known angles (through addition and subtraction) will be a multiple of their GCD. This GCD determines the smallest step Raju can take.
2. **Modulo 360 Consideration**: Since angles wrap around every 360 degrees, we need to consider the GCD of the previously computed GCD and 360. This gives the smallest step size modulo 360.
3. **Check Each Target Angle**: For each target angle, check if it can be formed by multiples of the computed step size modulo 360.

### Solution Code
```python
def solve():
    import math

    # Read input values
    n, k = map(int, input().split())
    known_angles = list(map(int, input().split()))
    target_angles = list(map(int, input().split()))

    # Calculate the GCD of all known angles
    current_gcd = 0
    for angle in known_angles:
        if current_gcd == 0 and angle == 0:
            continue  # Skip to avoid gcd(0, 0)
        current_gcd = math.gcd(current_gcd, angle)

    # Determine the effective GCD considering 360 degrees
    if current_gcd == 0:
        d = 360  # All known angles are zero, only 0 degrees is possible
    else:
        d = math.gcd(current_gcd, 360)

    # Check each target angle
    for target in target_angles:
        mod_angle = target % 360
        if mod_angle % d == 0:
            print("YES")
        else:
            print("NO")

# Call the function to execute
solve()
```

### Explanation
1. **Reading Input**: The input consists of the number of known angles, the number of target angles, the known angles, and the target angles.
2. **Computing GCD**: The GCD of all known angles is computed. If all known angles are zero, the GCD is zero, which is handled separately.
3. **Effective GCD**: The effective step size modulo 360 is determined by computing the GCD of the known angles' GCD and 360.
4. **Checking Targets**: For each target angle, we check if it modulo 360 is a multiple of the effective step size. If it is, the answer is "YES"; otherwise, it is "NO".

This approach efficiently determines the feasibility of each target angle using mathematical properties of GCD and modular arithmetic, ensuring correctness and optimal performance.
