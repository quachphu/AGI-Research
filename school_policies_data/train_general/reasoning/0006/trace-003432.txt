To solve this problem, we need to find the maximum width of a beautiful sequence between two given strings. A beautiful sequence is defined as a sequence of positions in the first string where each character matches the corresponding character in the second string in order, and the width is the maximum difference between consecutive positions in this sequence.

### Approach
1. **Identify Positions**: We need to determine the earliest possible positions (left array) and the latest possible positions (right array) for each character in the second string within the first string.
2. **Compute Maximum Width**: Using the left and right arrays, compute the maximum width by considering the largest gap between consecutive positions in these arrays.

### Solution Code
```python
n, m = map(int, input().split())
s = input().strip()
t = input().strip()

left = []
j = 0
for c in t:
    while j < len(s) and s[j] != c:
        j += 1
    left.append(j + 1)  # Convert to 1-based index
    j += 1

right = [0] * m
j = len(s) - 1
for i in range(m-1, -1, -1):
    c = t[i]
    while j >= 0 and s[j] != c:
        j -= 1
    right[i] = j + 1  # Convert to 1-based index
    j -= 1

max_width = 0
for i in range(m-1):
    current = right[i+1] - left[i]
    if current > max_width:
        max_width = current

print(max_width)
```

### Explanation
1. **Reading Input**: The input consists of the lengths of the two strings and the strings themselves.
2. **Constructing Left Array**: This array stores the earliest positions in the first string where each character of the second string can be found in order. We iterate through the first string and track the positions of each character in the second string sequentially.
3. **Constructing Right Array**: This array stores the latest positions in the first string where each character of the second string can be found, starting from the end of the first string. This ensures we get the farthest valid positions for each character.
4. **Calculating Maximum Width**: By iterating through the left and right arrays, we compute the maximum gap between consecutive positions. The largest gap found is the answer, representing the maximum width of a beautiful sequence.

This approach efficiently computes the required positions in linear time, making it suitable for large input sizes up to the given constraints.
