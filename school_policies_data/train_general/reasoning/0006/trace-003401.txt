To solve this problem, we need to determine the number of distinct possible sums that can be obtained by selecting any subset of elements from a given array, including the empty subset which yields a sum of 0.

### Approach
The key insight here is to use a dynamic programming approach to efficiently track all possible sums that can be formed by the elements of the array. Instead of generating all subsets (which is infeasible for large arrays), we use a set to keep track of all possible sums as we iterate through each element of the array.

1. **Initialization**: Start with a set containing only the sum 0 (from the empty subset).
2. **Iterate through each element**: For each element in the array, generate new sums by adding the element to each of the sums already present in the set.
3. **Update the set**: Merge these new sums into the existing set to ensure all possible sums are tracked without duplicates.
4. **Result**: The size of the set after processing all elements gives the number of distinct possible sums.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline().strip())
        arr = list(map(int, sys.stdin.readline().strip().split()))
        possible_sums = {0}
        for num in arr:
            new_sums = set()
            for s in possible_sums:
                new_sums.add(s + num)
            possible_sums.update(new_sums)
        print(len(possible_sums))

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read using standard input functions. The first line contains the number of test cases. For each test case, the array size and elements are read.
- **Tracking Possible Sums**: A set `possible_sums` is initialized with 0. For each element in the array, a new set of sums is generated by adding the element to each existing sum in `possible_sums`.
- **Updating the Set**: The new sums are merged into the existing set using `update`, which ensures all sums are unique.
- **Output**: After processing all elements of the array, the size of the set is printed, representing the number of distinct sums.

This approach efficiently tracks possible sums using a set, ensuring that each sum is only counted once, and avoids the exponential complexity of generating all subsets directly. The algorithm runs in O(N * S) time where S is the number of distinct sums possible, which is feasible given the problem constraints.
