To solve this problem, we need to determine the minimum number of currency denominations required to make an exact payment using given standard denominations. The denominations available are 1, 2, 5, 10, 20, 50, 100, 500, and 1000. The optimal approach is to use a greedy algorithm to minimize the number of notes used.

### Approach
The greedy algorithm works by always selecting the largest possible denomination that does not exceed the remaining amount. This approach is efficient and guarantees the minimum number of denominations for the given set. Here's the step-by-step approach:

1. **Sort Denominations in Descending Order**: Start with the largest denomination (1000) and proceed to the smallest (1).
2. **Iterate Through Denominations**: For each denomination, use as many of it as possible without exceeding the remaining amount.
3. **Update Remaining Amount**: Subtract the total value of the used denominations from the remaining amount and continue with the next smaller denomination.
4. **Count Denominations**: Keep a count of how many denominations are used until the remaining amount becomes zero.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    denominations = [1000, 500, 100, 50, 20, 10, 5, 2, 1]
    for i in range(1, T + 1):
        x = int(input[i])
        count = 0
        remaining = x
        for d in denominations:
            if remaining == 0:
                break
            if d > remaining:
                continue
            count += remaining // d
            remaining %= d
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints. The first value is the number of test cases, followed by each amount to be processed.
2. **Denomination Processing**: For each test case, the algorithm processes the amount by iterating through the denominations from largest to smallest. For each denomination, it calculates how many times it can be used, updates the count, and reduces the remaining amount accordingly.
3. **Output**: After processing all denominations, the count for each test case is printed.

This approach ensures that we use the minimum number of denominations by always taking the largest possible note first, which is optimal for the given set of denominations. The algorithm efficiently handles the maximum constraints, ensuring quick processing even for the largest values.
