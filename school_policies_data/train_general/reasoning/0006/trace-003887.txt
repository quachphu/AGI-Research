To solve this problem, we need to calculate the total number of changed digits when incrementing a number from `l` to `r` by 1 each time. The challenge is to do this efficiently given the constraints where `l` and `r` can be as large as 10^9 and there can be up to 10^4 test cases.

### Approach
1. **Understanding Digit Changes**: When incrementing a number, the number of digits changed is determined by the number of trailing 9s in the current number. For example, incrementing 999 to 1000 changes all three trailing 9s to 0s and increments the next digit, resulting in 4 changes.

2. **Efficient Calculation**: Instead of iterating through each number from `l` to `r-1`, we use a mathematical approach to count the numbers with a specific number of trailing 9s. For each possible number of trailing 9s (from 1 to 18, as numbers up to 10^9 can have at most 9 trailing 9s), we determine how many numbers in the range `[l, r-1]` have exactly that many trailing 9s.

3. **Arithmetic Sequence**: For each number of trailing 9s `i`, numbers that end with `i` 9s form an arithmetic sequence. We compute the first number in this sequence within the range and then count how many such numbers exist in the range.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    idx = 1
    for _ in range(t):
        l = int(input[idx])
        r = int(input[idx + 1])
        idx += 2
        res = r - l  # Initial count is the number of increments
        for i in range(1, 19):  # Check up to 10^18 (18 digits)
            m = 10 ** i
            remainder = l % m
            diff = ((m - 1) - remainder) % m
            x = l + diff
            if x > r - 1:
                continue
            count = ((r - 1 - x) // m) + 1
            res += count
        print(res)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the large number of test cases.
2. **Initial Count**: The initial count `res` is set to `r - l`, which is the number of increments needed to reach `r` from `l`.
3. **Trailing 9s Check**: For each possible number of trailing 9s `i` (from 1 to 18), we compute the modulus `m` (10^i). The first number in the range `[l, r-1]` that ends with `i` 9s is found using modular arithmetic.
4. **Counting Valid Numbers**: If such a number exists within the range, we calculate how many numbers in the arithmetic sequence (formed by numbers ending with `i` 9s) fall within the range and add this count to the result.

This approach efficiently reduces the problem from a potential O(r-l) complexity per test case to O(1) per test case by leveraging mathematical properties of numbers and arithmetic sequences.
