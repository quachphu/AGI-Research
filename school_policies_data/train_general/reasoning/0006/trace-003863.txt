To solve this problem, we need to replace every character in a given string that differs from the K-th character with an asterisk (`*`). The solution involves reading the input values, determining the target character based on the given index, and constructing the resulting string by replacing non-matching characters.

### Approach
1. **Read Inputs**: First, we read the integer values for the length of the string (N), the string itself (S), and the index (K).
2. **Determine Target Character**: Convert the 1-based index K to a 0-based index to find the target character in the string.
3. **Construct Result String**: Iterate over each character in the string, replacing characters that do not match the target character with `*`.
4. **Output the Result**: Combine the processed characters into a single string and print it.

### Solution Code
```python
def main():
    n = int(input())
    s = input().strip()
    k = int(input())
    target = s[k-1]
    result = ''.join(['*' if c != target else c for c in s])
    print(result)

main()
```

### Explanation
1. **Reading Inputs**: The code reads three lines of input: the length of the string, the string itself, and the index K. These values are stored in variables `n`, `s`, and `k` respectively.
2. **Target Character Calculation**: The target character is determined by accessing the (K-1)-th index of the string, adjusting for Python's 0-based indexing.
3. **String Transformation**: Using a list comprehension, each character in the string is checked against the target character. If a character does not match, it is replaced with `*`; otherwise, it remains unchanged.
4. **Result Construction and Output**: The transformed characters are joined into a single string and printed as the final result.

This approach ensures that we efficiently process each character in the string exactly once, leading to a time complexity of O(N), which is optimal for the given constraints.
