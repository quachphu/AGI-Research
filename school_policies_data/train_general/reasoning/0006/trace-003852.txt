To solve this problem, we need to determine if we can move exactly one element in an array such that the array can be split into two non-empty consecutive parts with equal sums. 

### Approach
1. **Check Sum Parity**: If the total sum of the array is odd, it's impossible to split it into two equal parts, so the answer is immediately "NO".
2. **Check for Existing Split**: If the sum of the array is even, check if there's already a valid split point where the sum of the first part equals half of the total sum. If such a split exists, the answer is "YES".
3. **Prefix Sum Analysis**: If no existing split is found, compute the prefix sums and use them to determine if moving one element can create a valid split. This involves checking two conditions for each element:
   - **Condition 1**: Moving an element from the left part to the right part to adjust the sum.
   - **Condition 2**: Moving an element from the right part to the left part to adjust the sum.

### Solution Code
```python
import bisect

n = int(input())
a = list(map(int, input().split()))
sum_total = sum(a)

if sum_total % 2 != 0:
    print("NO")
    exit()

t = sum_total // 2

current_sum = 0
has_valid_split = False

for num in a:
    current_sum += num
    prefix_sums.append(current_sum)
    if current_sum == t and len(prefix_sums) < n:
        has_valid_split = True
        break

if has_valid_split:
    print("YES")

from collections import defaultdict
sum_map = defaultdict(list)
for idx, s in enumerate(prefix_sums):
    sum_map[s].append(idx)

for i in range(len(a)):
    ai = a[i]
    target1 = t + ai
    if target1 in sum_map:
        sum_list = sum_map[target1]
        pos = bisect.bisect_left(sum_list, i)
        if pos < len(sum_list):

            exit()
    target2 = t - ai
    if target2 in sum_map:
        sum_list = sum_map[target2]

        if pos > 0:

print("NO")
```

### Explanation
1. **Sum Parity Check**: The total sum of the array is checked for parity. If it's odd, splitting into two equal parts is impossible.
2. **Existing Split Check**: While computing the prefix sums, we check if any prefix sum equals half the total sum (excluding the full array sum). If found, the answer is "YES".
3. **Prefix Sum Analysis**:
   - **Prefix Sum Map**: A dictionary maps each prefix sum to the indices where it occurs.
   - **Condition Checks**: For each element, check if moving it can create a valid split by adjusting the prefix sums. This is done by checking if the required target sums (either adding or subtracting the element) exist in the prefix sum map at valid positions.

This approach efficiently checks all possible ways to split the array by moving one element, ensuring an optimal solution even for large input sizes.
