To solve this problem, we need to determine if a binary string B (of length 5) is a substring of another binary string A (of length 10) for multiple test cases. The solution involves checking each pair of strings efficiently.

### Approach
1. **Input Handling**: Read the number of test cases, followed by each test case which consists of two binary strings A and B separated by a space.
2. **Substring Check**: For each test case, check if the string B is a substring of A. This can be efficiently done using Python's built-in substring check operator `in`.
3. **Output Result**: For each test case, print 1 if B is a substring of A, otherwise print 0.

### Solution Code
```python
def check_substring():
    import sys
    input = sys.stdin.read().splitlines()
    n = int(input[0])
    for line in input[1:n+1]:
        a, b = line.strip().split()
        print(1 if b in a else 0)

check_substring()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into lines for efficient processing. The first line gives the number of test cases.
2. **Processing Each Test Case**: For each subsequent line, the strings A and B are extracted. Using the `in` operator, we check if B is a substring of A.
3. **Output**: The result for each test case is printed immediately after checking, ensuring that the solution is both efficient and straightforward.

This approach ensures that we handle each test case in constant time, making the solution efficient with a time complexity of O(n) where n is the number of test cases. The substring check operation itself is optimized in Python, ensuring that each check is done in linear time relative to the length of the strings, which is fixed here (10 for A and 5 for B), thus maintaining overall efficiency.
