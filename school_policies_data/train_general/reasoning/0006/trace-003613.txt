To solve this problem, we need to distribute T-shirts to students such that each student receives a different color than their friends while minimizing the number of inversions (students wearing a color that does not match their gender). The solution involves checking if the graph of friendships is bipartite and then determining the optimal color assignment to minimize inversions.

### Approach
1. **Check Bipartiteness**: Use BFS to determine if the graph can be colored using two colors such that no two adjacent nodes (friends) have the same color. If the graph is not bipartite, it is impossible to distribute the T-shirts as required.
2. **Calculate Inversions**: If the graph is bipartite, compute the number of inversions for two possible color assignments (blue for one group and pink for the other, and vice versa). The minimum of these two values is the answer.

import sys
from collections import deque

def main():
    N, M = map(int, sys.stdin.readline().split())
    gender = sys.stdin.readline().split()
    adj = [[] for _ in range(N + 1)]  # Using 1-based indexing

    for _ in range(M):
        u, v = map(int, sys.stdin.readline().split())
        adj[u].append(v)
        adj[v].append(u)

    # Check bipartition using BFS starting from node 1 (graph is connected)
    color = [-1] * (N + 1)
    is_bipartite = True
    queue = deque()

    color[1] = 0
    queue.append(1)

    while queue and is_bipartite:
        u = queue.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                queue.append(v)
            elif color[v] == color[u]:
                is_bipartite = False
                break
        if not is_bipartite:
            break

    if not is_bipartite:
        print("Not possible")
        return

    # Calculate inversions for both possible color assignments
    count1 = 0  # Group 0: B, Group 1: P
    count2 = 0  # Group 0: P, Group 1: B

    for u in range(1, N + 1):
        g = gender[u - 1]
        desired = 'B' if g == 'B' else 'P'

        # For count1 (Group 0: B, Group 1: P)
        if color[u] == 0:
            assigned = 'B'
        else:
            assigned = 'P'
        if assigned != desired:
            count1 += 1

        # For count2 (Group 0: P, Group 1: B)
        if color[u] == 0:
            assigned = 'P'
        else:
            assigned = 'B'
        if assigned != desired:
