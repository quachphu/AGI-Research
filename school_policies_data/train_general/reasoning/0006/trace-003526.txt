To solve this problem, we need to calculate the bowling scores for multiple participants based on their sequence of throws, then output the results sorted by score in descending order and by student ID in ascending order for ties.

### Approach
1. **Reading Input**: The input consists of multiple datasets. Each dataset starts with the number of participants, followed by their respective throw sequences. The input ends with a zero.
2. **Score Calculation**: For each participant, we calculate their score based on the rules of bowling:
   - **Strike**: A strike (10 pins in the first throw) adds 10 points plus the next two throws as bonuses.
   - **Spare**: A spare (10 pins in two throws) adds 10 points plus the next throw as a bonus.
   - **Regular Frames**: If neither a strike nor a spare, the sum of the two throws is added.
   - **10th Frame**: The score is the sum of all remaining throws in the 10th frame, which can be 1, 2, or 3 throws depending on strikes or spares.
3. **Sorting**: After calculating scores, participants are sorted by descending scores. In case of ties, they are sorted by ascending student IDs.

def calculate_score(throws):
    total = 0
    current = 0
    for _ in range(9):  # Process frames 1-9
        if current >= len(throws):
            break
        if throws[current] == 10:  # Strike
            total += 10
            if current + 1 < len(throws):
                total += throws[current + 1]
            if current + 2 < len(throws):
                total += throws[current + 2]
            current += 1
        else:
            # Check if there's a second throw
            if current + 1 >= len(throws):
                total += throws[current]
                current += 1
                continue
            first = throws[current]
            second = throws[current + 1]
            total += first + second
            if (first + second) == 10:  # Spare
                if current + 2 < len(throws):
                    total += throws[current + 2]
            current += 2
    # Handle the 10th frame
    if current < len(throws):
        total += sum(throws[current:])
    return total
