To solve this problem, we need to determine the minimum number of contiguous flats Sergei B. must visit to collect all types of Pokemons present in the house. The solution involves finding the smallest contiguous subarray (window) that contains all unique Pokemon types.

### Approach
1. **Identify Unique Characters**: First, determine all unique Pokemon types in the given string. Let the number of unique types be `k`.
2. **Sliding Window Technique**: Use a sliding window approach to find the smallest window that contains exactly `k` unique characters. This technique efficiently expands and contracts a window over the string to check for the smallest valid window.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n = int(sys.stdin.readline())
    s = sys.stdin.readline().strip()
    
    unique_chars = set(s)
    k = len(unique_chars)
    
    if k == 0:
        print(0)
        return
    
    count = defaultdict(int)
    left = 0
    min_length = float('inf')
    current_unique = 0
    
    for right in range(n):
        char = s[right]
        count[char] += 1
        if count[char] == 1:
            current_unique += 1
        
        while current_unique == k:
            window_length = right - left + 1
            if window_length < min_length:
                min_length = window_length
            
            left_char = s[left]
            count[left_char] -= 1
            if count[left_char] == 0:
                current_unique -= 1
            left += 1
    
    print(min_length)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first line gives the number of flats `n`, and the second line gives the string `s` representing Pokemon types in each flat.
2. **Unique Characters**: Convert the string `s` into a set to determine the unique Pokemon types, which gives the count `k`.
3. **Sliding Window Initialization**: Initialize a dictionary `count` to keep track of character frequencies within the current window. Use `left` and `right` pointers to represent the current window boundaries.
4. **Expanding the Window**: Move the `right` pointer to expand the window. For each new character added to the window, update its frequency. If this character is new to the current window, increment the count of unique characters in the window.
5. **Contracting the Window**: Once the window contains all `k` unique characters, attempt to contract it from the left to find the smallest valid window. Adjust the `left` pointer and update frequencies and unique character count accordingly.
6. **Result**: Track the minimum window length found during the process and print it as the result.

This approach ensures that we efficiently find the smallest window containing all unique Pokemon types in linear time, making it suitable for large input sizes up to 100,000 flats.
