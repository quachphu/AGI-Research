To solve this problem, we need to determine the minimum number of insertions required to ensure that no subsegment of the resulting array sums to zero. The key insight is to track prefix sums and use a set to detect when a duplicate prefix sum occurs, which indicates a zero-sum subsegment. When a duplicate is detected, we insert a split and reset the tracking for the next segment.

### Approach
1. **Track Prefix Sums**: As we iterate through the array, maintain a running sum (prefix sum) of the elements encountered.
2. **Detect Zero-Sum Subsegments**: Use a set to keep track of all prefix sums encountered. If a prefix sum repeats, it indicates a zero-sum subsegment.
3. **Insert Splits**: When a duplicate prefix sum is detected, increment the insertion count, reset the prefix sum tracking, and start a new segment from the current element.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))

current_sum = 0
seen = {0}
result = 0

for num in a:
    current_sum += num
    if current_sum in seen:
        result += 1
        seen = {0, num}
        current_sum = num
    else:
        seen.add(current_sum)

print(result)
```

### Explanation
1. **Initialization**: Start with an initial prefix sum of 0 (empty subarray) and a set containing this sum.
2. **Iterate Through Elements**: For each element, update the running sum (current_sum).
3. **Check for Duplicates**: If the current_sum is found in the set, it means a zero-sum subsegment exists. Insert a split, reset the set to track the new segment starting from the current element, and update the current_sum to the current element.
4. **Update Set**: If no duplicate is found, add the current_sum to the set.

This approach ensures that each segment of the array processed has unique prefix sums, thus avoiding any zero-sum subsegments with the minimum number of insertions. The algorithm efficiently handles the constraints with a time complexity of O(n), where n is the number of elements in the input array.
