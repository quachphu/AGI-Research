### Approach
1. **Problem Analysis**: The problem is a direct application of the ballot theorem. The theorem states that if candidate A scores `a` votes and candidate B scores `b` votes (where `a > b`), the probability that A is always ahead of B in the count is given by the formula `(a - b) / (a + b)`.
2. **Algorithm**: 
   - Read the number of test cases.

   - Compute the probability using the formula derived from the ballot theorem.
   - Print the result formatted to 12 decimal places to ensure precision as required.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        a = int(input[idx])
        b = int(input[idx + 1])
        idx += 2
        prob = (a - b) / (a + b)
        print("{0:.12f}".format(prob))

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read all at once and split into a list of strings for efficient processing. The first element of this list is the number of test cases.
- **Processing Each Test Case**: For each test case, we extract the integers `a` and `b`, compute the probability using the formula `(a - b) / (a + b)`, and print the result formatted to 12 decimal places.
- **Precision Handling**: The result is formatted to 12 decimal places to meet the problem's precision requirements, ensuring that both absolute and relative errors do not exceed \(10^{-6}\).

This approach efficiently computes the required probability using direct mathematical insights, ensuring optimal performance even for large input sizes.
