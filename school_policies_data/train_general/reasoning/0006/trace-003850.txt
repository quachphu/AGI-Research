To solve this problem, we need to determine the minimum number of rest days Vasya must take during his vacation, given that he cannot perform the same activity (sport or contest) on consecutive days. The solution involves dynamic programming to track the minimum rest days required for each possible activity on each day.

### Approach
1. **Dynamic Programming (DP) Setup**: Use a DP array where each entry tracks the minimum rest days required up to that day for each possible last activity (rest, sport, contest).
2. **Initialization**: For the first day, initialize the DP array based on the allowed activities for that day.
3. **Transition**: For each subsequent day, compute the minimum rest days for each possible activity by considering valid transitions from the previous day's activities. Valid transitions ensure no consecutive sport or contest activities.
4. **Result Extraction**: After processing all days, the result is the minimum value in the DP array for the last day.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
INF = float('inf')

prev_dp = [INF] * 3

# Initialize for the first day
ai = a[0]
allowed = []
if ai == 0:
    allowed = [0]
elif ai == 1:
    allowed = [0, 2]
elif ai == 2:
    allowed = [0, 1]
elif ai == 3:
    allowed = [0, 1, 2]
for act in allowed:
    if act == 0:
        prev_dp[0] = 1
    else:
        prev_dp[act] = 0

for i in range(1, n):
    curr_dp = [INF] * 3
    ai = a[i]
    allowed = []
    if ai == 0:
        allowed = [0]
    elif ai == 1:
        allowed = [0, 2]
    elif ai == 2:
        allowed = [0, 1]
    elif ai == 3:
        allowed = [0, 1, 2]
    for prev_act in range(3):
        if prev_dp[prev_act] == INF:
            continue
        for curr_act in allowed:
            # Check if current activity is sport or contest and same as previous
            if curr_act in (1, 2) and prev_act == curr_act:
                continue
            new_rest = prev_dp[prev_act] + (1 if curr_act == 0 else 0)
            if new_rest < curr_dp[curr_act]:
                curr_dp[curr_act] = new_rest
    prev_dp = curr_dp

print(min(prev_dp))
```

### Explanation
1. **Initialization**: The first day's possible activities are determined, and the DP array is initialized to track the rest days required if Vasya starts with each allowed activity.
2. **Transition Loop**: For each subsequent day, iterate over all possible previous activities and compute valid transitions to current activities. Update the DP array to keep track of the minimum rest days required.
3. **Result Calculation**: After processing all days, the minimum value in the DP array for the last day gives the minimum rest days required.

This approach efficiently tracks the state transitions using dynamic programming, ensuring optimal computation of the minimum rest days while adhering to the constraints.
