To solve this problem, we need to reorder a sequence of integers such that the "strength" of the sequence is maximized. The strength is defined as the sum of absolute differences between consecutive elements, including the wrap-around between the last and first elements. 

### Approach
The key insight to maximize the strength is to arrange the elements in such a way that consecutive elements (including the wrap-around) are as far apart as possible. This can be achieved by sorting the elements and then interleaving the smallest and largest remaining elements. 

1. **Sort the Array**: First, sort the array in non-decreasing order.
2. **Split the Array**: Split the sorted array into two halves. For even-sized arrays, split into two equal halves. For odd-sized arrays, split into two halves with the middle element kept aside.
3. **Interleave Halves**: Create a new array by interleaving the lower half and the reversed upper half of the sorted array. This ensures that each element is as far apart as possible from its neighbors.
4. **Compute the Strength**: Calculate the sum of absolute differences between consecutive elements in the new array, including the wrap-around between the last and first elements.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    a.sort()
    
    if n % 2 == 0:
        mid = n // 2
        lower = a[:mid]
        upper = a[mid:]
        upper_reversed = upper[::-1]
        arranged = []
        for i in range(mid):
            arranged.append(lower[i])
            arranged.append(upper_reversed[i])
    else:
        mid = (n - 1) // 2
        lower = a[:mid]
        upper = a[mid + 1:]
        upper_reversed = upper[::-1]
        arranged = []
        for i in range(mid):
            arranged.append(lower[i])
            arranged.append(upper_reversed[i])
        arranged.append(a[mid])
    
    total = 0
    for i in range(n):
        total += abs(arranged[i] - arranged[(i + 1) % n])
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Sorting**: The array is sorted to facilitate splitting into lower and upper halves.
2. **Splitting and Interleaving**: For even-sized arrays, the lower half is the first half of the sorted array, and the upper half is the second half, reversed. For odd-sized arrays, the middle element is placed at the end after interleaving the lower and reversed upper halves.
3. **Strength Calculation**: The sum of absolute differences is computed by iterating through the interleaved array and considering the wrap-around between the last and first elements.

This approach ensures that each consecutive pair of elements (including the wrap-around) contributes maximally to the strength, resulting in the optimal solution. The complexity of this approach is O(n log n) due to sorting, which is efficient for large values of n up to 100,000.
