To solve this problem, we need to determine the number of positive integers \( M \) within a given range that satisfy specific conditions related to the product of their divisors. The solution involves precomputing necessary values to efficiently handle up to \( 10^5 \) queries.

### Approach
1. **Understanding the Problem**: For each integer \( M \) between 2 and \( N \), we need to check if the product of its proper divisors (excluding \( M \) itself) is more than twice \( M \). This can be mathematically transformed using logarithms to avoid direct computation of large products.

2. **Precompute Divisors Count**: Using a sieve-like approach, compute the number of divisors for each integer up to \( 10^5 \). This helps in determining the divisor count efficiently.

3. **Check Validity Using Logarithms**: For each integer \( M \), use the divisor count to check if the product of its proper divisors exceeds twice \( M \). This is done using logarithms to avoid numerical overflow and to simplify comparisons.

4. **Prefix Sum Array**: Construct a prefix sum array to quickly answer the number of valid integers up to any given \( N \).

### Solution Code
```python
import sys
import math

def main():
    input = sys.stdin.read().split()
    Q = int(input[0])
    queries = list(map(int, input[1:Q+1]))
    max_N = 100000  # Maximum possible N as per constraints

    # Precompute the number of divisors for each number up to max_N
    divisors_count = [0] * (max_N + 1)
    for i in range(1, max_N + 1):
        for j in range(i, max_N + 1, i):
            divisors_count[j] += 1

    # Precompute valid numbers and prefix sums
    valid = [False] * (max_N + 1)
    threshold = 2 * math.log(2)
    for M in range(2, max_N + 1):
        t = divisors_count[M]
        if t < 4:
            continue
        if (t - 4) * math.log(M) > threshold:
            valid[M] = True

    # Compute prefix sum array
    prefix = [0] * (max_N + 1)
    count = 0
    for M in range(2, max_N + 1):
        if valid[M]:
            count += 1
        prefix[M] = count

    # Process each query
    for N in queries:
        print(prefix[N])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Divisors Count Calculation**: Using a sieve method, we count the divisors for each number efficiently. This is done by iterating through each number and marking its multiples, incrementing their divisor count.

2. **Validity Check**: For each number \( M \), we check if the product of its proper divisors exceeds twice \( M \) using logarithms. This avoids direct computation of large products and allows us to work with manageable values.

3. **Prefix Sum Array**: This array allows us to quickly answer the count of valid numbers up to any \( N \) in constant time. By precomputing the cumulative count of valid numbers, we can efficiently handle multiple queries.

This approach ensures that we preprocess all necessary data once, allowing each query to be answered in \( O(1) \) time, making the solution efficient even for large input sizes.
