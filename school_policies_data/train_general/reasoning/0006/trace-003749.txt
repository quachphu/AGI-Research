To solve this problem, we need to determine the minimum total cost of breaking a rectangular chocolate bar into exactly `k` squares. The cost of breaking the chocolate is the square of the length of the break. The solution involves using dynamic programming (DP) to precompute the minimum costs for all possible dimensions and values of `k`.

### Approach
1. **Dynamic Programming (DP) Table Initialization**: We initialize a 3D DP table where `dp[a][b][c]` represents the minimum cost to break an `a x b` chocolate bar into exactly `c` squares. Here, `a` and `b` are the dimensions of the chocolate bar, and `c` is the number of squares we want to obtain.

2. **Base Cases**: 
   - If `c` is 0, the cost is 0 because we don't need to break the chocolate.
   - If `c` equals the area of the chocolate (i.e., `a * b`), the cost is 0 because no breaks are needed.

3. **Splitting the Chocolate**: For each possible split (vertical or horizontal), we consider all ways to divide `c` into two parts `c1` and `c2` such that `c1 + c2 = c`. We compute the cost for each split and update the DP table with the minimum cost.

4. **Precomputation**: We precompute the DP table for all possible dimensions up to `30x30` and `k` up to 50 to efficiently answer each query in constant time.

### Solution Code
```python
import sys

def main():
    max_a = 30
    max_b = 30
    max_c = 50
    INF = float('inf')

    # Initialize DP table
    dp = [[[INF] * (max_c + 1) for _ in range(max_b + 1)] for __ in range(max_a + 1)]

    for a in range(1, max_a + 1):
        for b in range(a, max_b + 1):
            area = a * b
            max_c_val = min(area, max_c)
            dp[a][b][0] = 0  # c=0, cost is 0
            for c in range(0, max_c_val + 1):
                if c == area:
                    dp[a][b][c] = 0  # no breaks needed
                elif c == 0:
                    dp[a][b][c] = 0  # already handled
                else:
                    min_val = INF
                    # Vertical splits
                    for a1 in range(1, a):
                        a2 = a - a1
                        split_cost = b * b
                        lower_c1 = max(0, c - a2 * b)
                        upper_c1 = min(c, a1 * b)
                        if lower_c1 > upper_c1:
                            continue
                        for c1 in range(lower_c1, upper_c1 + 1):
                            c2 = c - c1
                            # Normalize first part
                            na1, nb1 = (a1, b) if a1 <= b else (b, a1)
                            na1 = min(na1, nb1)
                            nb1 = max(na1, nb1)
                            # Normalize second part
                            na2, nb2 = (a2, b) if a2 <= b else (b, a2)
                            na2 = min(na2, nb2)
                            nb2 = max(na2, nb2)
                            if na1 > max_a or nb1 > max_b or na2 > max_a or nb2 > max_b:
                                continue
                            cost = split_cost + dp[na1][nb1][c1] + dp[na2][nb2][c2]
                            if cost < min_val:
                                min_val = cost
                    # Horizontal splits
                    for b1 in range(1, b):
                        b2 = b - b1
                        split_cost = a * a
                        lower_c1 = max(0, c - a * b2)
                        upper_c1 = min(c, a * b1)
                        if lower_c1 > upper_c1:
                            continue
                        for c1 in range(lower_c1, upper_c1 + 1):
                            c2 = c - c1
                            # Normalize first part
                            na1, nb1 = (a, b1) if a <= b1 else (b1, a)
                            na1 = min(na1, nb1)
                            nb1 = max(na1, nb1)
                            # Normalize second part
                            na2, nb2 = (a, b2) if a <= b2 else (b2, a)
                            na2 = min(na2, nb2)
                            nb2 = max(na2, nb2)
                            if na1 > max_a or nb1 > max_b or na2 > max_a or nb2 > max_b:
                                continue
                            cost = split_cost + dp[na1][nb1][c1] + dp[na2][nb2][c2]
                            if cost < min_val:
                                min_val = cost
                    if min_val < dp[a][b][c]:
                        dp[a][b][c] = min_val

    t = int(sys.stdin.readline())
    for _ in range(t):
        n, m, k = map(int, sys.stdin.readline().split())
        a, b = sorted([n, m])
        print(dp[a][b][k])

if __name__ == "__main__":
    main()
```

1. **Initialization**: The DP table is initialized with infinity (INF) to represent impossible states. The base cases for `c = 0` and `c = a * b` are set to 0.

2. **Vertical and Horizontal Splits**: For each possible vertical and horizontal split, we compute the cost of the split and recursively compute the minimum cost for the resulting pieces. The valid ranges for `c1` and `c2` are computed to ensure they are within the bounds of the chocolate pieces.

3. **Precomputation**: The DP table is precomputed for all possible dimensions and values of `k`, allowing each query to be answered in constant time by looking up the precomputed value.

This approach efficiently computes the minimum cost using dynamic programming, ensuring optimal performance even for the upper constraint limits.
