Let the sum of elements of the first part be sum_1, the sum of elements of the second part be sum_2 and the sum of elements of the third part be sum_3. Among all possible ways to split the array you have to choose a way such that sum_1 = sum_3 and sum_1 is maximum possible.

More formally, if the first part of the array contains a elements, the second part of the array contains b elements and the third part contains c elements, then:

$$$sum_1 = ∑_{1 ≤ i ≤ a}d_i, sum_2 = ∑_{a + 1 ≤ i ≤ a + b}d_i, sum_3 = ∑_{a + b + 1 ≤ i ≤ a + b + c}d_i.$$$

The sum of an empty array is 0.

Your task is to find a way to split the array such that sum_1 = sum_3 and sum_1 is maximum possible.

Input

The first line of the input contains one integer n (1 ≤ n ≤ 2 ⋅ 10^5) — the number of elements in the array d.

The second line of the input contains n integers d_1, d_2, ..., d_n (1 ≤ d_i ≤ 10^9) — the elements of the array d.

Output

Print a single integer — the maximum possible value of sum_1, considering that the condition sum_1 = sum_3 must be met.

Obviously, at least one valid way to split the array exists (use a=c=0 and b=n).

To solve this problem, we need to split an array into three contiguous subsegments such that the sum of the first and third segments are equal, and this sum is maximized. The segments must be non-overlapping and contiguous.

### Approach
1. **Two Pointers Technique**: Use two pointers to track the elements taken from the start (prefix) and the end (suffix) of the array.
2. **Sum Tracking**: Maintain two sums, one for the prefix (`sum1`) and one for the suffix (`sum3`).
3. **Maximization**: Continuously adjust the prefix and suffix sums to find the maximum possible sum where they are equal, ensuring that the total elements considered from both ends do not exceed the array length.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    d = list(map(int, input[1:n+1]))
    
    sum1 = 0
    sum3 = 0
    left = 0
    right = 0
    max_sum = 0
    
    while left + right <= n:
        if sum1 == sum3:
            if sum1 > max_sum:
                max_sum = sum1
            if left + right < n:
                # Try to add to left first if possible
                if left < n:
                    sum1 += d[left]
                    left += 1
                else:
                    # Can't add left, add to right
                    sum3 += d[n - 1 - right]
                    right += 1
            else:
                break
        elif sum1 < sum3:
            if left < n - right:
                sum1 += d[left]
                left += 1
            else:
                break
        else:
            if right < n - left:
                sum3 += d[n - 1 - right]
                right += 1
            else:
                break
    print(max_sum)

main()
```

### Explanation
1. **Initialization**: Start with `sum1` and `sum3` both set to 0, representing the sums of the prefix and suffix respectively. `left` and `right` pointers track the number of elements considered from the start and end.
2. **Loop Until Valid**: Continue adjusting the sums while the total elements from both ends do not exceed the array length.
3. **Adjust Sums**: If the sums are equal, check if this sum is the maximum found so far. Then, try to add elements to either the prefix or suffix to find a larger possible sum.
4. **Break Conditions**: If one sum is smaller, adjust by adding elements from the respective side until the sums can be balanced again or the valid range is exceeded.

This approach ensures that we efficiently find the maximum sum by leveraging the two pointers technique, maintaining an O(n) time complexity, which is optimal for the given problem constraints.
