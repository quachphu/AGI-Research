To solve this problem, we need to determine the number of training sessions (golden coins) required to raise all soldiers' ranks to the maximum possible rank in the strategic computer game "Settlers II". Each training session allows one soldier from each non-maximal rank group to be promoted, and we need to compute the minimum number of such sessions required.

### Approach
1. **Problem Analysis**: Each training session allows one promotion per group of soldiers with the same rank (excluding those already at the maximum rank). The goal is to compute the number of sessions needed until all soldiers reach the maximum rank.
2. **Group Formation**: Soldiers are grouped by their ranks. For each session, we count the number of groups that can promote a soldier (i.e., groups not at the maximum rank).
3. **Simulation**: For each session, we process each eligible group, promote one soldier from each group, and update the counts of soldiers in each rank. This process continues until no more promotions are possible.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))

counts = [0] * (k + 2)  # Using k+2 to avoid index issues

for num in a:
    counts[num] += 1

sessions = 0

while True:
    current_groups = []
    for r in range(1, k):
        if counts[r] > 0:
            current_groups.append(r)
    if not current_groups:
        break
    for r in current_groups:
        counts[r] -= 1
        counts[r + 1] += 1
    sessions += 1

print(sessions)
```

### Explanation
1. **Reading Input**: The input consists of the number of soldiers `n`, the maximum rank `k`, and the list of current ranks of the soldiers.
2. **Initialization**: We initialize an array `counts` to keep track of the number of soldiers at each rank.
3. **Training Sessions**: For each session, we determine the current groups of soldiers that can promote (ranks less than `k`). For each group, we promote one soldier and update the counts. This continues until no more groups can promote.
4. **Termination**: The loop terminates when there are no more groups eligible for promotion, and the total number of sessions is printed.

This approach efficiently simulates each training session and ensures that we only process necessary groups, leading to an optimal solution. The complexity is manageable given the constraints, making the solution both efficient and easy to understand.
