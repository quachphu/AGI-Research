To solve this problem, we need to determine the winner of a game played on a grid made of horizontal and vertical sticks. The players take turns removing intersection points, and the player who cannot make a move loses. The solution involves analyzing the optimal moves for both players based on the dimensions of the grid.

### Approach
The key insight is that each move reduces both the number of horizontal and vertical sticks by 1. The game continues until there are no intersection points left. The outcome of the game depends on the parity (odd or even) of the minimum of the two dimensions (n and m). If the minimum dimension is even, the second player (Malvika) wins; if odd, the first player (Akshat) wins.

### Solution Code
```python
n, m = map(int, input().split())
k = min(n, m)
print("Malvika" if k % 2 == 0 else "Akshat")
```

### Explanation
1. **Input Reading**: The code reads the dimensions of the grid (n and m).
2. **Determine Minimum Dimension**: The minimum of n and m is calculated to determine the number of optimal moves possible.
3. **Check Parity**: The parity (even or odd) of the minimum dimension determines the winner. If even, Malvika wins; if odd, Akshat wins.

This approach efficiently determines the winner in constant time O(1), making it highly optimal for the given problem constraints.
