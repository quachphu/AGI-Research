To solve this problem, we need to determine the minimum number of problems Takahashi needs to solve to achieve a total score of at least G points, considering both the base score from solved problems and the perfect bonuses for solving all problems of a certain type.

### Approach
1. **Subset Enumeration**: Since the number of problem types (D) is up to 10, we can use a bitmask to enumerate all possible subsets of problem types where all problems in the subset are solved (thereby earning their perfect bonuses).
2. **Score Calculation**: For each subset, calculate the base score and the sum of perfect bonuses. If this total meets or exceeds G, record the number of problems solved.
3. **Handling Remaining Points**: If the total score from the subset is insufficient, compute the remaining points needed and greedily solve problems from the highest point categories not in the subset to minimize the number of problems solved.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    D = int(input[idx])
    idx += 1
    G = int(input[idx])
    idx += 1
    
    p = []
    c = []
    for _ in range(D):
        pi = int(input[idx])
        ci = int(input[idx+1])
        p.append(pi)
        c.append(ci)
        idx += 2
    
    candidates = []
    
    for mask in range(1 << D):
        base = 0
        bonus = 0
        total_p = 0
        for j in range(D):
            if (mask >> j) & 1:
                base += 100 * (j + 1) * p[j]
                bonus += c[j]
                total_p += p[j]
        current_score = base + bonus
        if current_score >= G:
            candidates.append(total_p)
            continue
        rem = G - current_score
        non_selected = []
        for j in range(D):
            if not (mask & (1 << j)):
                non_selected.append(j)
        non_selected.sort(key=lambda x: -(x + 1))
        temp_p = total_p
        temp_rem = rem
        for j in non_selected:
            if temp_rem <= 0:
                break
            pt = 100 * (j + 1)
            max_need = (temp_rem + pt - 1) // pt
            max_take = min(max_need, p[j] - 1)
            if max_take <= 0:
                continue
            temp_p += max_take
            temp_rem -= max_take * pt
        if temp_rem <= 0:
            candidates.append(temp_p)
    
    print(min(candidates))

if __name__ == '__main__':
    main()
```
