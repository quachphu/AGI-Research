To solve this problem, we need to determine the number of substrings in a given string that contain exactly K distinct characters. The solution involves efficiently counting substrings using a sliding window technique to handle the constraints effectively.

### Approach
The key insight is to use a sliding window approach to count substrings with at most K distinct characters and then use this result to find the count of substrings with exactly K distinct characters. Here's the detailed approach:

1. **Sliding Window for At Most K Distinct Characters**: 
   - We use a sliding window to maintain the count of distinct characters within the current window. If the number of distinct characters exceeds K, we adjust the window from the left until it contains at most K distinct characters.
   - For each valid window, the number of substrings ending at the current right pointer is calculated and accumulated.

2. **Exact K Distinct Characters**:
   - The number of substrings with exactly K distinct characters can be derived by subtracting the count of substrings with at most K-1 distinct characters from the count of substrings with at most K distinct characters.

### Solution Code
```python
import sys
from collections import defaultdict

def at_most_k(s, k):
    count = defaultdict(int)
    left = 0
    distinct = 0
    result = 0
    for right in range(len(s)):
        char = s[right]
        if count[char] == 0:
            distinct += 1
        count[char] += 1
        while distinct > k:
            left_char = s[left]
            count[left_char] -= 1
            if count[left_char] == 0:
                distinct -= 1
            left += 1
        result += right - left + 1
    return result

def main():
    K = int(sys.stdin.readline())
    S = sys.stdin.readline().strip()
    a = at_most_k(S, K)
    b = at_most_k(S, K-1)
    print(a - b)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of an integer K and a string S. We read these values from standard input.
2. **Sliding Window Function (`at_most_k`)**:
   - This function uses a sliding window approach to count the number of substrings with at most K distinct characters.
   - A frequency dictionary (`count`) keeps track of character counts within the current window.
   - The window is adjusted by moving the left pointer whenever the number of distinct characters exceeds K.
   - For each valid window, the number of substrings ending at the current right pointer is added to the result.
3. **Calculating Exact K Distinct Substrings**: By computing the difference between the counts of substrings with at most K and K-1 distinct characters, we get the number of substrings with exactly K distinct characters.

This approach efficiently handles the problem constraints with a time complexity of O(n) for each call to `at_most_k`, leading to an overall time complexity of O(n). This ensures the solution is optimal and handles the upper constraint limits effectively.
