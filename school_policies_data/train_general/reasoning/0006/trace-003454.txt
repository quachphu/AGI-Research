To solve this problem, we need to determine the ASCII value of a given character. The input will be a single character from the ASCII character set, and we need to output its corresponding ASCII value.

### Approach
1. **Reading Input**: The input is a single character provided via standard input. In Python, the `input()` function reads a line from standard input. Since the problem guarantees that the input will be exactly one ASCII character, we can directly use the result of `input()` without any additional processing.
2. **Convert to ASCII**: The `ord()` function in Python returns the ASCII value (or Unicode code point) of a given character. This function is well-suited for our needs as it directly converts the input character to its corresponding ASCII value.
3. **Output the Result**: Once we have the ASCII value, we simply print it to the standard output.

### Solution Code
```python
def main():
    c = input()
    print(ord(c))

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The `input()` function reads the input line from the user. Given the problem constraints, this input will be exactly one character long.
- **Conversion to ASCII**: The `ord()` function takes a single character string and returns its ASCII value. This is efficient and straightforward for our needs.
- **Output**: The result from `ord()` is printed directly, ensuring the correct ASCII value is displayed.

This approach ensures that we handle the input correctly and efficiently convert it to the desired output with minimal overhead. The solution is optimal with a time complexity of O(1) since reading the input and converting it to ASCII are constant-time operations.
