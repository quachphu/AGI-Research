To solve this problem, we need to determine the original sequence of integers \( b_1, b_2, \ldots, b_n \) from the given sequence \( a_1, a_2, \ldots, a_n \). The sequence \( a \) is constructed such that each \( a_i \) is formed by starting at \( b_i \) and alternately subtracting and adding subsequent elements of \( b \). 

### Approach
The key insight is recognizing the relationship between the sequences \( a \) and \( b \). Specifically, each element \( a_i \) can be expressed in terms of \( b \) and subsequent elements of \( a \). By analyzing the problem, we derive the following relationships:
1. For each \( i \) from 1 to \( n-1 \), \( b_i = a_i + a_{i+1} \).
2. For the last element, \( b_n = a_n \).

This allows us to efficiently compute each \( b_i \) using the given sequence \( a \).

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
b = []
for i in range(n-1):
    b.append(a[i] + a[i+1])
b.append(a[-1])
print(' '.join(map(str, b)))
```

### Explanation
1. **Reading Input:** We first read the integer \( n \) which denotes the number of elements in the sequence. Then, we read the sequence \( a \) from the input.
2. **Constructing Sequence \( b \):** We iterate through the elements of \( a \) from the first to the second-to-last element. For each element \( a_i \), we compute \( b_i \) as \( a_i + a_{i+1} \). The last element of \( b \) is directly taken as the last element of \( a \).
3. **Output:** Finally, we print the sequence \( b \) as space-separated integers.

This approach efficiently constructs the sequence \( b \) in \( O(n) \) time complexity, which is optimal for the given problem constraints.
