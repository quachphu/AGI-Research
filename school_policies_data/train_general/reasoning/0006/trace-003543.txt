To solve this problem, we need to determine the day of the week when Petr will finish reading a book with `n` pages, given his daily reading schedule. Petr starts reading on Monday and follows the same weekly schedule each subsequent week. The goal is to simulate the reading process day by day until the book is finished.

### Approach
1. **Input Reading**: Read the number of pages `n` and the weekly reading schedule which consists of 7 integers representing the pages Petr can read each day from Monday to Sunday.
2. **Simulation**: Simulate the reading process day by day. Each day, subtract the number of pages Petr reads from the remaining pages. If the remaining pages drop to zero or below, the day on which this happens is the answer.
3. **Cycling Through Days**: Since Petr reads according to the same weekly schedule, we cycle through the days of the week repeatedly until the book is finished.

### Solution Code
```python
n = int(input())
days = list(map(int, input().split()))
remaining = n

while True:
    for i in range(7):
        pages = days[i]
        if pages == 0:
            continue
        remaining -= pages
        if remaining <= 0:
            print(i + 1)
            exit()
```

### Explanation
1. **Reading Input**: The first input line is the number of pages `n`, and the second line contains seven integers representing the pages Petr can read each day from Monday to Sunday.
2. **Simulating the Reading Process**: We start with the total number of pages `n` and iterate through each day of the week in order. For each day, we check how many pages Petr can read. If he reads pages (non-zero), we subtract those pages from the remaining count. If the remaining pages become zero or less, we immediately print the current day (1-based index) and exit the program.
3. **Handling Zero Pages**: If Petr cannot read any pages on a particular day (i.e., the value is zero), we skip that day and continue to the next day. This ensures we only process days where actual reading occurs.

This approach efficiently simulates the reading process day by day, ensuring we correctly determine the exact day Petr finishes the book. The solution efficiently handles the constraints and guarantees termination due to the problem constraints ensuring at least one day of reading per week.
