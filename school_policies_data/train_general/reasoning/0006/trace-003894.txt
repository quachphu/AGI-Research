One of the problems of HDD hard drives is the following: the magnetic head should move from one sector to another to read some file.

Find the time need to read file split to n fragments. The i-th sector contains the fi-th fragment of the file (1 ≤ fi ≤ n). Note different sectors contains the different fragments. At the start the magnetic head is in the position that contains the first fragment. The fragments are read in the order from the first to the n-th.

It takes |a - b| time units to move the magnetic head from the sector a to the sector b. Reading a fragment takes no time.

Input

The first line contains a positive integer n (1 ≤ n ≤ 2·105) — the number of fragments.

The second line contains n different integers fi (1 ≤ fi ≤ n) — the number of the fragment written in the i-th sector.

Output

Examples

Input

Input

  * 3->4 means movement from the sector 2 to the sector 4, i.e. it takes 2 time units

To solve this problem, we need to determine the total time required for a magnetic head to read all fragments of a file stored in different sectors of an HDD. The magnetic head moves from the sector containing the first fragment to the sector containing the second fragment, and so on until all fragments are read. The time taken to move between sectors is the absolute difference between their sector numbers.

### Approach
1. **Input Reading**: Read the number of fragments and the list of integers representing which fragment is stored in each sector.
2. **Position Mapping**: Create a mapping from each fragment number to its corresponding sector. This helps in quickly determining the sector of any fragment.
3. **Calculate Movement Time**: Starting from the sector of the first fragment, sequentially move to each subsequent fragment's sector, accumulating the time taken for each move using the absolute difference between sector numbers.

### Solution Code
```python
n = int(input())
fragments = list(map(int, input().split()))

position = [0] * (n + 1)
for idx, frag in enumerate(fragments):
    position[frag] = idx + 1  # sectors are 1-based

total_time = 0
current = position[1]
for frag in range(2, n + 1):
    next_pos = position[frag]
    total_time += abs(next_pos - current)
    current = next_pos

print(total_time)
```

### Explanation
1. **Input Reading**: The first line of input is the number of fragments `n`. The second line contains the list of integers where each integer represents the fragment number stored in the corresponding sector.
2. **Position Mapping**: Using an array `position`, we map each fragment number to its sector. For example, if fragment `3` is stored in the first sector, `position[3]` will be `1`.
3. **Movement Calculation**: Starting from the sector of the first fragment, we iterate through each subsequent fragment (from the second to the nth), compute the absolute difference between the current sector and the next sector, and accumulate this time. The total accumulated time is printed as the result.

This approach ensures that we efficiently compute the total movement time with a time complexity of O(n), which is optimal for the given problem constraints.
