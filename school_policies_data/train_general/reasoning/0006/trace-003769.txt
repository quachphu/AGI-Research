### Approach
1. **Bulk Operations**: Instead of simulating each operation individually, which is inefficient for large values, we compute how many operations can be performed in bulk on the same largest element.
2. **Mathematical Insight**: For each bulk operation, we calculate the maximum number of steps \(t\) that can be performed on the current largest element before it is no longer the largest. This is derived using the difference between the largest and second-largest elements and the structure of the problem.
3. **Edge Cases Handling**: When multiple elements share the maximum value, we handle each operation individually to avoid complications in bulk calculations.
