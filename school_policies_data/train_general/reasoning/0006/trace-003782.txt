To solve this problem, we need to determine how many times Gerald can apply a spell to a number until it becomes a single-digit number. Each application of the spell replaces the number with the sum of its digits.

### Approach
1. **Input Handling**: Read the input number as a string to handle very large numbers efficiently.
2. **Initial Check**: If the input number is already a single digit, output 0 immediately.
3. **Summing Digits**: For each iteration, compute the sum of the digits of the current number.
4. **Count Iterations**: Keep track of how many times the spell is applied until the resulting sum is a single digit.
5. **Termination Condition**: Stop the process once the sum of digits is a single digit and output the count of iterations.

### Solution Code
```python
def main():
    n = input().strip()
    count = 0
    if len(n) == 1:
        print(0)
        return
    current = n
    while True:
        sum_digits = sum(int(c) for c in current)
        count += 1
        if sum_digits < 10:
            break
        current = str(sum_digits)
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read as a string to handle extremely large numbers that cannot be stored in standard integer types.
2. **Immediate Check for Single Digit**: If the input number is already a single digit, the result is 0 as no spell is needed.
3. **Iterative Summing**: Convert each digit of the current number to an integer, sum them, and check if the result is a single digit.
4. **Count Updates**: Each iteration increments the count, and the loop continues until the sum of digits is a single digit.
5. **Efficiency**: The algorithm efficiently processes even very large numbers by working with strings for the initial steps and converting to integers for subsequent sums, ensuring manageable computation times.
