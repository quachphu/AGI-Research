To solve this problem, we need to determine the minimum number of teams required to group students such that no two students with consecutive programming skills are in the same team. The solution involves analyzing consecutive sequences of skills and determining the optimal team distribution.

### Approach
1. **Sort the Skills**: Start by sorting the list of programming skills. This helps in easily identifying consecutive sequences.
2. **Group Consecutive Skills**: Iterate through the sorted list and group consecutive skills. Each group of consecutive skills will be considered separately.
3. **Determine Teams for Each Group**: For each group, if the group has only one student, it requires 1 team. If the group has two or more consecutive students, they can be optimally divided into 2 teams (as each consecutive student alternates between teams).
4. **Compute the Result**: The result for each query is the maximum number of teams required by any group of consecutive skills. This is because different non-consecutive groups can share the same set of teams.

### Solution Code
```python
q = int(input())
for _ in range(q):
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()
    if n == 0:
        print(0)
        continue
    groups = []
    current_group = [a[0]]
    for num in a[1:]:
        if num == current_group[-1] + 1:
            current_group.append(num)
        else:
            groups.append(current_group)
            current_group = [num]
    groups.append(current_group)
    max_teams = 1
    for group in groups:
        if len(group) >= 2:
            max_teams = 2
    print(max_teams)
```

### Explanation
1. **Sorting the Skills**: By sorting the skills, we can easily identify consecutive sequences.
2. **Grouping Consecutive Skills**: We iterate through the sorted list and create groups where each group contains consecutive skills. For example, sorting the list [2, 10, 1, 20] becomes [1, 2, 10, 20], resulting in groups [1, 2], [10], and [20].
3. **Team Calculation**: Each group of consecutive skills requires at least 2 teams if there are two or more students. For isolated skills (groups of size 1), only 1 team is needed. The maximum number of teams required by any group determines the result for the query.
4. **Result Calculation**: The result is determined by checking the maximum teams required across all groups. If any group requires 2 teams, the answer is 2; otherwise, it is 1.

This approach efficiently groups students and calculates the minimum number of teams required, ensuring optimal performance given the problem constraints.
