To solve this problem, we need to determine the maximum possible difference in weight between the items carried by Chef and his son. The son will carry exactly K items, and Chef will carry the remaining items. The goal is to maximize the weight difference, with Chef carrying the heavier group.

### Approach
1. **Input Reading**: Read the number of test cases. For each test case, read the number of items (N) and the number of items the son will carry (K), followed by the weights of the items.
2. **Total Weight Calculation**: Compute the total weight of all items.
3. **Sorting and Summing**:
   - Sort the items in ascending order to find the minimum possible weight of K items (son's minimum load).
   - Sort the items in descending order to find the maximum possible weight of K items (son's maximum load).
4. **Difference Calculation**:
   - Calculate the difference when the son carries the minimum possible weight.
   - Calculate the difference when the son carries the maximum possible weight.
5. **Result Determination**: The maximum possible difference is the highest value obtained from the two calculated differences.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N, K = int(input[idx]), int(input[idx+1])
        idx +=2
        W = list(map(int, input[idx:idx+N]))
        idx +=N
        total = sum(W)
        sorted_asc = sorted(W)
        min_sum = sum(sorted_asc[:K])
        sorted_desc = sorted(W, reverse=True)
        max_sum = sum(sorted_desc[:K])
        diff1 = total - 2 * min_sum
        diff2 = 2 * max_sum - total
        print(max(diff1, diff2))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given multiple test cases.
2. **Total Weight Calculation**: The sum of all item weights is computed once to avoid repeated calculations.
3. **Sorting**:
   - Ascending sort helps in quickly determining the minimum sum of K items (lightest K items).
   - Descending sort helps in determining the maximum sum of K items (heaviest K items).
4. **Difference Calculation**:
   - **diff1**: Represents the difference when the son carries the lightest K items. This is calculated as `total - 2 * min_sum`.
   - **diff2**: Represents the difference when the son carries the heaviest K items. This is calculated as `2 * max_sum - total`.
5. **Result**: The maximum of the two differences is printed for each test case, ensuring the optimal solution is chosen.

This approach efficiently leverages sorting and summation operations to determine the optimal weight distribution, ensuring the solution is both optimal and efficient within the problem constraints.
