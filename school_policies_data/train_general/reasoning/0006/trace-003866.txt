To solve this problem, we need to determine the number of valid ways to arrange N dogs and M monkeys in a row such that no two adjacent animals are of the same type. The solution must be computed modulo \(10^9 + 7\).

### Approach
1. **Check Validity**: If the absolute difference between N and M is greater than 1, it is impossible to arrange them without having two adjacent animals of the same type. In such cases, the result is 0.
2. **Factorial Precomputation**: Precompute the factorials of numbers up to the maximum of N and M modulo \(10^9 + 7\). This helps in efficiently computing the permutations of dogs and monkeys.
3. **Calculate Permutations**:
   - If N and M are equal, the valid arrangements can start with either a dog or a monkey, leading to twice the product of the permutations of dogs and monkeys.
   - If the counts differ by 1, the valid arrangements can only start with the type that has the higher count, leading to the product of the permutations of dogs and monkeys.

### Solution Code
```python
MOD = 10**9 + 7

n, m = map(int, input().split())

if abs(n - m) > 1:
    print(0)
else:
    max_fact = max(n, m)
    fact = [1] * (max_fact + 1)
    for i in range(2, max_fact + 1):
        fact[i] = fact[i-1] * i % MOD
    res = fact[n] * fact[m] % MOD
    if n == m:
        res = res * 2 % MOD
    print(res)
```

### Explanation
1. **Validity Check**: The first check ensures that the counts of dogs and monkeys are feasible for an alternating arrangement. If the counts differ by more than 1, the answer is immediately 0.
2. **Factorial Precomputation**: Using dynamic programming, we precompute the factorials of all numbers up to the maximum of N and M. This allows efficient lookup of factorial values modulo \(10^9 + 7\).
3. **Permutation Calculation**: Depending on whether the counts are equal or differ by 1, we compute the product of the permutations of dogs and monkeys, adjusting for the starting type if counts are equal.

This approach ensures that we efficiently compute the result using precomputed values, adhering to the constraints and modulo requirements.
