To solve this problem, we need to calculate the niceness for each vertex in a tree when it is chosen as the headquarters. The niceness is defined as the sum of the smallest joyfulness values of the edges on the paths from the headquarters to every other vertex. 

### Approach
The key insight is to use a Union-Find (Disjoint Set Union, DSU) data structure with path compression and lazy propagation to efficiently compute the contributions of each edge to the niceness values. Here's the detailed approach:

1. **Sort Edges by Joyfulness**: Process edges in decreasing order of their joyfulness values. This ensures that when we merge components using Union-Find, the current edge is the smallest in the path between any two nodes in the merged components.

2. **Union-Find Data Structure**: Track the size of each component and the accumulated contributions (niceness) for each node. When merging two components, the contribution of the current edge to the niceness of each node in the merged components is calculated and stored.

3. **Lazy Propagation**: During the union operations, contributions from the edges are propagated to the root nodes of the components. When querying the niceness of a node, we ensure that all accumulated contributions from the root down to the node are considered.

import sys
sys.setrecursionlimit(1 << 25)

class DSU:
    def __init__(self, n):
        self.parent = list(range(n+1))  # 1-based indexing
        self.size = [1] * (n+1)
        self.contribution = [0] * (n+1)  # Contribution stored per node
    
    def find(self, u):
        while self.parent[u] != u:
            orig_parent = self.parent[u]
            self.parent[u] = self.parent[self.parent[u]]  # Path compression
            self.contribution[u] += self.contribution[orig_parent]
        return self.parent[u]
    
    def union(self, u, v, c):
        u_root = self.find(u)
        v_root = self.find(v)
        if u_root == v_root:
            return
        if self.size[u_root] < self.size[v_root]:
            u_root, v_root = v_root, u_root
        # Add contributions
        self.contribution[u_root] += c * self.size[v_root]
        self.contribution[v_root] += c * self.size[u_root]
        # Merge the smaller tree into the larger tree
        self.parent[v_root] = u_root
        self.size[u_root] += self.size[v_root]

def main():
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    edges = []
    for _ in range(N-1):
        a = int(input[idx])
        b = int(input[idx+1])
        c = int(input[idx+2])
        edges.append((c, a, b))
        idx +=3
    # Sort edges in decreasing order of c
    edges.sort(reverse=True, key=lambda x: x[0])
    dsu = DSU(N)
    for c, a, b in edges:
        dsu.union(a, b, c)
    # Now, compute the contribution for each node
    result = [0] * (N+1)
    for i in range(1, N+1):
        dsu.find(i)  # Ensure path compression and contribution propagation
        result[i] = dsu.contribution[i]
    for i in range(1, N+1):
        print(result[i])

2. **Union-Find with Contributions**: The Union-Find data structure is augmented to track the size of each component and the contributions of each edge. When merging two components, the contribution of the current edge is added to the root nodes of both components.
