To solve this problem, we need to process a series of commands on a given string. The commands can be to print a substring, reverse a substring, or replace a substring with another string. The solution involves efficiently handling these operations using Python's list manipulation capabilities.

### Approach
1. **Read Input:** First, read the initial string and the number of commands.
2. **Convert String to List:** Since strings in Python are immutable, convert the initial string to a list of characters for easier manipulation.
3. **Process Commands:** For each command:
   - **Print Command:** Extract the substring from indices `a` to `b` (inclusive) and print it.
   - **Reverse Command:** Reverse the substring from indices `a` to `b` (inclusive).
   - **Replace Command:** Replace the substring from indices `a` to `b` (inclusive) with the given string `p`.

### Solution Code
```python
def main():
    s = input().strip()
    q = int(input())
    lst = list(s)
    for _ in range(q):
        parts = input().strip().split()
        command = parts[0]
        if command == 'print':
            a = int(parts[1])
            b = int(parts[2])
            print(''.join(lst[a:b+1]))
        elif command == 'reverse':
            a = int(parts[1])
            b = int(parts[2])
            reversed_sub = lst[a:b+1][::-1]
            lst[a:b+1] = reversed_sub
        elif command == 'replace':
            a = int(parts[1])
            b = int(parts[2])
            p = parts[3]
            lst[a:b+1] = list(p)

main()
```

### Explanation
1. **Reading Input:** The initial string is read and converted into a list of characters to allow in-place modifications.
2. **Processing Each Command:**
   - **Print Command:** Convert the relevant slice of the list back to a string and print it.
   - **Reverse Command:** Reverse the specified sublist using slicing and assign it back to the original list.
   - **Replace Command:** Replace the specified sublist with the characters of the given replacement string.

This approach ensures that each operation is performed efficiently, leveraging Python's list slicing and manipulation capabilities to handle substrings in linear time relative to their length. This solution efficiently handles the constraints and provides the correct output for each command.
