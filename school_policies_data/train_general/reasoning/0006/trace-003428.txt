To solve this problem, we need to determine the minimum number of changes required to transform a given sequence of integers into a "nice" sequence. A sequence is considered nice if all occurrences of the same value are contiguous. The solution must handle updates to the sequence, but since the problem specifies that the number of updates (q) is 0, we only need to compute the initial difficulty.

### Approach
1. **Identify Key Properties**: A sequence is nice if each value appears in contiguous blocks. To achieve this, we need to merge values such that their occurrences form contiguous intervals.
2. **Track Occurrences**: For each value in the sequence, track its first and last occurrence positions and its count.
3. **Form Merged Groups**: Values whose intervals (from first to last occurrence) overlap must be merged into the same group. These groups will form contiguous blocks in the resulting sequence.
4. **Calculate Cost**: For each merged group, the minimal changes required are calculated by considering the most frequent value in the group (which minimizes the number of changes needed).

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n, q = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    
    first_occurrence = dict()
    last_occurrence = dict()
    count = defaultdict(int)
    
    for idx, val in enumerate(a):
        if val not in first_occurrence:
            first_occurrence[val] = idx
        last_occurrence[val] = idx
        count[val] += 1
    
    sorted_values = sorted(count.keys(), key=lambda x: first_occurrence[x])
    
    components = []
    if sorted_values:
        current_start = first_occurrence[sorted_values[0]]
        current_end = last_occurrence[sorted_values[0]]
        current_vals = [sorted_values[0]]
        
        for val in sorted_values[1:]:
            f = first_occurrence[val]
            l = last_occurrence[val]
            if f <= current_end:
                current_end = max(current_end, l)
                current_vals.append(val)
            else:
                components.append(current_vals)
                current_vals = [val]
                current_start = f
                current_end = l
        components.append(current_vals)
    
    total_max = 0
    total_elements = sum(count.values())
    
    for comp in components:
        max_c = 0
        for val in comp:
            if count[val] > max_c:
                max_c = count[val]
        total_max += max_c
    
    difficulty = total_elements - total_max
    print(difficulty)

if __name__ == "__main__":
    main()
```

5. **Calculating Cost**: For each merged group, the cost is minimized by keeping the most frequent value and changing all other values in the group to this value. The total difficulty is computed by summing these minimal costs across all groups.

This approach efficiently determines the minimum changes required by leveraging interval merging and frequency analysis, ensuring optimal performance even for large sequences.
