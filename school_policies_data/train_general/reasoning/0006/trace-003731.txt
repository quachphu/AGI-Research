To solve this problem, we need to determine the most balanced team based on the price difference between the most expensive and least expensive players in each team. The goal is to identify the team with the smallest balance (price difference) and, in case of ties, select the team with the highest index.

### Approach
1. **Input Reading**: Read the number of test cases. For each test case, read the player prices for 10 teams.
2. **Balance Calculation**: For each team, compute the balance as the difference between the maximum and minimum player prices.
3. **Determine the Most Balanced Team**: Track the smallest balance encountered and the corresponding team index. If multiple teams have the same smallest balance, select the team with the highest index.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().splitlines()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        teams = []
        for _ in range(10):
            line = input[ptr].strip()
            ptr += 1
            prices = list(map(int, line.split()))
            teams.append(prices)
        min_balance = float('inf')
        best_team = 0
        for i in range(10):
            mn = min(teams[i])
            mx = max(teams[i])
            balance = mx - mn
            if balance < min_balance:
                min_balance = balance
                best_team = i + 1
            elif balance == min_balance:
                if (i + 1) > best_team:
                    best_team = i + 1
        print(best_team, min_balance)

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into lines for efficient processing. The first line gives the number of test cases.
2. **Processing Each Test Case**: For each test case, we read 10 lines representing the 10 teams. Each line contains 15 integers representing player prices.
3. **Calculating Balance**: For each team, the minimum and maximum prices are found using Python's built-in `min` and `max` functions. The balance is the difference between these values.
4. **Tracking the Best Team**: We keep track of the smallest balance and update the best team index whenever a smaller balance is found or the same balance is found in a higher-indexed team.

This approach ensures that we efficiently determine the most balanced team using linear scans through the player prices and straightforward comparisons, resulting in an optimal solution for the given problem constraints.
