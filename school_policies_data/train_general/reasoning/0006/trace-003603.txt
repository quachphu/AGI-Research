To solve this problem, we need to determine the winner of a chess-like game where two players, A (with white pawns) and B (with black pawns), take turns moving their pawns towards opposite ends of the board. Player A moves first, and the goal is to determine who wins if both play optimally.

### Approach
1. **Problem Analysis**: The game is played on an 8x8 board. Player A (white pawns) aims to move any pawn to the top row (row 1), while Player B (black pawns) aims to move any pawn to the bottom row (row 8). Each player moves their pawns one step at a time towards their respective goal rows. The key is to find the minimum steps each player needs to reach their target row, considering optimal play.

2. **Intuition**: For each white pawn, check if there is a clear path upward to row 1. Similarly, for each black pawn, check if there is a clear path downward to row 8. The player with the shortest path to their goal row will win, considering they take turns starting with Player A.

3. **Algorithm**:
   - **Check Path for White Pawns**: For each white pawn, determine if the path upward (from its current row to row 1) is unobstructed. If so, calculate the steps required.
   - **Check Path for Black Pawns**: For each black pawn, determine if the path downward (from its current row to row 8) is unobstructed. If so, calculate the steps required.
   - **Compare Steps**: The player with the minimum steps wins. If both have the same minimum steps, Player A wins because they move first.

### Solution Code
```python
board = [input().strip() for _ in range(8)]
a_min = float('inf')
b_min = float('inf')

for row in range(8):
    for col in range(8):
        cell = board[row][col]
        if cell == 'W':
            # Check upward path
            clear = True
            for i in range(row - 1, -1, -1):
                if board[i][col] != '.':
                    clear = False
                    break
            if clear:
                steps = row  # steps = (row + 1) - 1 (since problem rows are 1-based)
                if steps < a_min:
                    a_min = steps
        elif cell == 'B':
            # Check downward path
            clear = True
            for i in range(row + 1, 8):
                if board[i][col] != '.':
                    clear = False
                    break
            if clear:
                steps = 7 - row  # steps = 8 - (row + 1) (since problem rows are 1-based)
                if steps < b_min:
                    b_min = steps

print('A' if a_min <= b_min else 'B')
```

### Explanation
1. **Reading Input**: The board is read as a list of strings, each representing a row.
2. **Initialization**: Variables `a_min` and `b_min` are initialized to infinity to track the minimum steps for players A and B, respectively.
3. **Path Checking**:
   - **White Pawns**: For each white pawn ('W'), check if all cells from its current row up to row 1 (top row) are empty. If so, calculate the steps as the current row index (0-based) and update `a_min` if this is the shortest path found.
   - **Black Pawns**: For each black pawn ('B'), check if all cells from its current row down to row 8 (bottom row) are empty. If so, calculate the steps as `7 - current_row` (since rows are 0-based) and update `b_min` if this is the shortest path found.
4. **Determine Winner**: Compare the minimum steps for both players. If `a_min` is less than or equal to `b_min`, Player A wins; otherwise, Player B wins.

This approach ensures optimal play by both players, considering all possible unobstructed paths and selecting the shortest one for each player. The solution efficiently checks each pawn's path and determines the winner based on the shortest path lengths.
