To solve this problem, we need to determine the value of the element at position k (1-based) in a sequence generated through a specific process after (n-1) steps. The sequence starts with [1] and grows by appending itself and inserting the next smallest unused integer in the middle at each step.

### Approach
The key insight is to recognize the recursive structure of the sequence. Each step generates a new sequence by appending the previous sequence to itself and inserting the next smallest integer in the middle. The length of the sequence after (n-1) steps is \(2^n - 1\), which makes direct construction infeasible for large n. Instead, we use a recursive approach to efficiently determine the k-th element without generating the entire sequence.

1. **Base Case**: If n is 1, the sequence is [1], so the answer is 1.
2. **Recursive Case**: For n > 1, compute the middle position of the current sequence. If k is at this middle position, return n. If k is in the left half, recurse on the left half. If k is in the right half, adjust k to the corresponding position in the left half and recurse.

### Solution Code
```python
n, k = map(int, input().split())

def find_kth(n, k):
    if n == 1:
        return 1
    L = (1 << (n-1)) - 1  # Equivalent to 2^(n-1) - 1
    if k == L + 1:
        return n
    elif k <= L:
        return find_kth(n-1, k)
    else:
        return find_kth(n-1, k - (L + 1))

print(find_kth(n, k))
```

### Explanation
1. **Recursive Structure**: The sequence after each step is formed by appending the previous sequence to itself and inserting the next integer in the middle. This structure allows us to break down the problem into smaller subproblems.
2. **Middle Position Calculation**: For each step, the middle position is at \(2^{(n-1)}\). If k matches this position, the value is n.
3. **Left and Right Halves**: If k is in the left half, we recursively check the left half. If k is in the right half, we adjust k to the corresponding position in the left half and recurse.

This approach efficiently narrows down the position of k by leveraging the recursive structure, ensuring we do not need to construct the entire sequence, thus handling very large n efficiently.
