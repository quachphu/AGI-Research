To solve this problem, we need to determine the minimum number of groups required to divide all employees such that no employee in a group is a superior of another. The key insight is that the minimum number of groups is determined by the longest chain of command (or hierarchy depth) within the company.

### Approach
1. **Model the Hierarchy**: Each employee can be represented as a node in a tree, where the root node has no immediate manager. The depth of an employee in this tree is the number of superiors in the chain up to the root.
2. **Compute Depth for Each Employee**: For each employee, compute their depth in the hierarchy tree. The depth of an employee is 1 more than the depth of their immediate manager. If an employee has no immediate manager (root), their depth is 1.
3. **Find Maximum Depth**: The minimum number of groups required is equal to the maximum depth found across all employees. This is because each group can consist of employees from the same depth level, ensuring no superior-subordinate relationship within the group.

### Solution Code
```python
n = int(input())
managers = [0] * (n + 1)
for i in range(1, n + 1):
    pi = int(input())
    managers[i] = pi

depth = [0] * (n + 1)

for i in range(1, n + 1):
    if depth[i] == 0:
        path = []
        current = i
        while current != -1 and depth[current] == 0:
            path.append(current)
            current = managers[current]
        if current == -1:
            current_depth = 1
        else:
            current_depth = depth[current] + 1
        for node in reversed(path):
            depth[node] = current_depth
            current_depth += 1

print(max(depth))
```

### Explanation
1. **Reading Input**: The number of employees and their respective immediate managers are read. Each manager entry is stored in an array where the index represents the employee.
2. **Depth Calculation**: For each employee, if their depth hasn't been computed, we traverse up their hierarchy to find the root or a previously computed depth. This traversal helps in building the path from the employee to the root or a known depth node.
3. **Path Processing**: Once the path is determined, we backtrack from the root or known depth node to compute the depth for each employee in the path. This ensures that each depth is computed in linear time relative to the path length.
4. **Result**: The maximum depth value from the computed depths is the answer, representing the minimum number of groups required.

This approach efficiently computes the depth for each employee using memoization and ensures that each node is processed only once, leading to an optimal solution with a time complexity of O(n).
