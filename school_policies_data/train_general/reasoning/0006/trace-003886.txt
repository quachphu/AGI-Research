To solve this problem, we need to maximize the total number of upvotes by strategically directing each reviewer to one of two servers. The decision of where to send each reviewer depends on their type and the current state of the servers. The solution involves using dynamic programming to efficiently track the possible states of each server and determine the optimal server assignment for each reviewer.

### Approach
1. **Dynamic Programming (DP) State Tracking**: We use a DP approach where each state is represented by the balance (upvotes minus downvotes) of each server and the total upvotes accumulated so far. The balance of a server determines how a type 3 reviewer will vote.
2. **State Transitions**: For each reviewer, we consider sending them to either server and compute the resulting new state and total upvotes. We update the DP table to keep track of the maximum upvotes achievable for each possible state.
3. **Efficient State Management**: Using dictionaries, we efficiently manage the possible states and transitions, ensuring that we only keep track of the maximum upvotes for each state.

import sys
from collections import defaultdict

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        r = list(map(int, input[ptr:ptr + n]))
        ptr += n
        
        current_dp = defaultdict(int)
        current_dp[(0, 0)] = 0
        for reviewer in r:
            next_dp = defaultdict(int)
            for (b1, b2), up in current_dp.items():
                # Process sending to server 1
                if reviewer == 1:
                    new_b1, new_b2 = b1 + 1, b2
                    new_up = up + 1
                elif reviewer == 2:
                    new_b1, new_b2 = b1 - 1, b2
                    new_up = up
                else:
                    if b1 >= 0:
                        new_b1, add = b1 + 1, 1
                    else:
                        new_b1, add = b1 - 1, 0
                    new_up = up + add
                    new_b2 = b2
                if next_dp[(new_b1, new_b2)] < new_up:
                    next_dp[(new_b1, new_b2)] = new_up
                
                # Process sending to server 2
                if reviewer == 1:
                    new_b1_s2, new_b2_s2 = b1, b2 + 1
                    new_up_s2 = up + 1
                elif reviewer == 2:
                    new_b1_s2, new_b2_s2 = b1, b2 - 1
                    new_up_s2 = up

                    if b2 >= 0:
                        new_b2_s2, add_s2 = b2 + 1, 1
                    else:
                        new_b2_s2, add_s2 = b2 - 1, 0
                    new_up_s2 = up + add_s2
                    new_b1_s2 = b1
                if next_dp[(new_b1_s2, new_b2_s2)] < new_up_s2:
                    next_dp[(new_b1_s2, new_b2_s2)] = new_up_s2
