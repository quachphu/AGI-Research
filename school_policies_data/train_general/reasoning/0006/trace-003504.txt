To solve this problem, we need to determine the minimal number of people Vasya should check in a bar to ensure that no one under the age of 18 is consuming alcoholic drinks. The solution involves checking each person's provided information (either age or drink) and determining if further checks are necessary based on the given constraints.

### Approach
1. **Identify Alcoholic Drinks**: First, we define a list of alcoholic drinks as specified in the problem.
2. **Parse Input**: For each person, we check if the provided information is their age or their drink.
3. **Check Conditions**: 
   - If the person's age is provided and it is less than 18, they must be checked because they might be consuming an alcoholic drink.
   - If the person's drink is provided and it is an alcoholic drink, they must be checked because they might be under 18.
4. **Count Checks**: Sum up all the cases where a check is necessary based on the above conditions.

### Solution Code
```python
alcohol_drinks = {
    'ABSINTH', 'BEER', 'BRANDY', 'CHAMPAGNE', 'GIN', 'RUM', 'SAKE',
    'TEQUILA', 'VODKA', 'WHISKEY', 'WINE'
}

n = int(input())
count = 0

for _ in range(n):
    entry = input().strip()
    if entry.isdigit():
        age = int(entry)
        if age < 18:
            count += 1
    else:
        if entry in alcohol_drinks:
            count += 1

print(count)
```

### Explanation
1. **Input Reading**: The first line of input is read to determine the number of people in the bar.
2. **Loop Through Each Person**: For each subsequent line, we check if the entry is a digit (indicating age) or a string (indicating a drink).
3. **Age Check**: If the entry is a digit and the age is less than 18, increment the check count.
4. **Drink Check**: If the entry is a drink and it is in the predefined list of alcoholic drinks, increment the check count.
5. **Output Result**: Finally, the total count of necessary checks is printed.

This approach ensures that we efficiently determine the minimal number of checks required by focusing only on the necessary conditions, leading to an optimal solution with a time complexity of O(n), where n is the number of people in the bar.
