To solve this problem, we need to determine the minimum number of moves required to make all elements of a matrix equal by either adding or subtracting a given value `d` to each element. If it's impossible to achieve this, we should return `-1`.

### Approach
1. **Check Feasibility**: First, we check if it's possible to make all elements equal. This is possible only if all elements have the same remainder when divided by `d`. If any element has a different remainder, it's impossible to equalize all elements, and we return `-1`.

2. **Transform Elements**: If all elements have the same remainder when divided by `d`, we transform each element by subtracting the common remainder and then dividing by `d`. This transformation converts the problem into finding the minimum number of steps to make all transformed values equal, where each step is now a difference of 1.

3. **Find Median**: The optimal target value to minimize the total number of steps (sum of absolute differences) is the median of the transformed values. This is because the median minimizes the sum of absolute deviations.

4. **Calculate Steps**: Compute the total number of steps required to adjust all transformed values to the median.

### Solution Code
```python
n, m, d = map(int, input().split())
elements = []
for _ in range(n):
    elements += list(map(int, input().split()))

# Check if all elements have the same remainder mod d
remainder = elements[0] % d
for a in elements:
    if a % d != remainder:
        print(-1)
        exit()

# Transform elements
r = remainder
vals = [(a - r) // d for a in elements]
vals.sort()

# Calculate median
median = vals[len(vals) // 2]

# Compute total steps
total = sum(abs(v - median) for v in vals)
print(total)
```

### Explanation
1. **Feasibility Check**: By checking the remainder of each element modulo `d`, we ensure that all elements can be adjusted to the same value using steps of `d`.

2. **Transformation**: Converting each element using `(element - remainder) // d` simplifies the problem to finding the minimum steps to equalize integers, which is efficiently solved using the median.

3. **Median Calculation**: Sorting the transformed values and selecting the median ensures that the sum of absolute differences is minimized, leading to the optimal number of moves.

This approach efficiently handles the problem constraints and ensures the solution is both correct and optimal.
