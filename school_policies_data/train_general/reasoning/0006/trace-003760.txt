To solve this problem, we need to determine if all computers from 1 to n are turned on after k button presses. The computers toggle their state based on specific conditions, and we need an efficient way to check the state without simulating each button press.

### Approach
1. **Understanding the Toggle Pattern**: Each computer can only be toggled if all previous computers are on. This creates a specific pattern where each computer's state toggles in a binary counter-like manner.
2. **Mathematical Insight**: For n computers, the minimum number of button presses required to turn all n computers on is \(2^n - 1\). After this, the state repeats every \(2^n\) presses.
3. **Check Conditions**: For a given number of presses k, check if k is at least \(2^n - 1\) and if the remaining presses after the minimum required form a multiple of \(2^n\).

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n, k = map(int, sys.stdin.readline().split())
        if n == 0:
            print("YES" if k == 0 else "NO")
            continue
        required = (1 << n) - 1
        if k < required:
            print("NO")
        else:
            cycle = 1 << n
            if (k - required) % cycle == 0:
                print("YES")
            else:
                print("NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads the number of test cases and each pair of n and k values.
2. **Calculate Minimum Required Presses**: Using bit shifting, we compute \(2^n - 1\) as the minimum presses needed to turn all n computers on.
3. **Check Validity**: If k is less than the minimum required, output "NO". Otherwise, check if the remaining presses after the minimum form a valid cycle using modulo operation.

This approach efficiently determines the state of the computers without simulating each button press, making it feasible even for large values of k up to \(10^8\).
