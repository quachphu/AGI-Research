To solve this problem, we need to determine if we can select exactly one integer from each row of a matrix such that the bitwise exclusive OR (XOR) of all selected integers is strictly greater than zero. If possible, we should also provide the indices of the selected integers.

### Approach
1. **Initial XOR Calculation**: Compute the XOR of the first element from each row. If this initial XOR is non-zero, we can directly use these elements as our solution.
2. **Check for Varying Elements**: If the initial XOR is zero, check each row to see if there are any rows with varying elements (i.e., not all elements in the row are the same). If such a row exists, changing one element in this row can potentially result in a non-zero XOR.
3. **Adjust Selection**: If a row with varying elements is found, adjust the selection in this row to change the XOR from zero to a non-zero value. If no such row exists, it is impossible to achieve a non-zero XOR, and we output "NIE".

### Solution Code
```python
n, m = map(int, input().split())
matrix = []
for _ in range(n):
    row = list(map(int, input().split()))
    matrix.append(row)

initial_xor = 0
selection = [1] * n

for i in range(n):
    initial_xor ^= matrix[i][0]

if initial_xor != 0:
    print("TAK")
    print(' '.join(map(str, selection)))
else:
    found_row = -1
    diff_col = -1
    for i in range(n):
        first_val = matrix[i][0]
        for j in range(1, m):
            if matrix[i][j] != first_val:
                found_row = i
                diff_col = j
                break
        if found_row != -1:
            break
    if found_row != -1:
        selection[found_row] = diff_col + 1  # Convert to 1-based index
        print("TAK")
        print(' '.join(map(str, selection)))
    else:
        print("NIE")
```

### Explanation
1. **Initial XOR Calculation**: We start by selecting the first element from each row and computing their XOR. If this XOR is non-zero, we immediately output "TAK" along with the indices of the first elements.
2. **Row Check for Varying Elements**: If the initial XOR is zero, we check each row to see if there are any elements different from the first element of that row. This helps us determine if we can adjust our selection to achieve a non-zero XOR.
3. **Adjusting Selection**: If we find a row with varying elements, we adjust our selection in that row to change the XOR result. This adjustment is done by selecting a different element in that row, which changes the overall XOR to a non-zero value. If no such row exists, we output "NIE" as it is impossible to achieve a non-zero XOR.

This approach efficiently checks the necessary conditions and adjusts the selection to ensure the XOR result is non-zero if possible, providing an optimal solution with linear complexity relative to the matrix dimensions.
