To solve this problem, we need to determine the minimum possible difference between the tallest and shortest tree when selecting K trees out of N, such that the difference between the tallest and shortest selected trees is minimized.

### Approach
1. **Sort the Heights**: First, we sort the list of tree heights. This allows us to efficiently find the minimum difference between consecutive elements in groups of K trees.
2. **Sliding Window Technique**: Using a sliding window of size K on the sorted list, we check the difference between the maximum and minimum heights in each window. Since the list is sorted, the maximum in any window is the last element, and the minimum is the first element of the window.
3. **Calculate Minimum Difference**: Iterate through all possible windows of size K in the sorted list and keep track of the minimum difference encountered.

### Solution Code
```python
import sys

def main():
    n, k = map(int, sys.stdin.readline().split())
    h = [int(sys.stdin.readline()) for _ in range(n)]
    h.sort()
    min_diff = float('inf')
    for i in range(n - k + 1):
        current_diff = h[i + k - 1] - h[i]
        if current_diff < min_diff:
            min_diff = current_diff
    print(min_diff)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin` for efficiency, especially given the constraints.
2. **Sorting**: The list of tree heights is sorted to allow the sliding window technique to work effectively.
3. **Sliding Window**: By iterating over each possible starting position of the window (from 0 to N-K), we compute the difference between the first and last element of each window (since the list is sorted, the first element is the minimum and the last is the maximum in the window).
4. **Finding Minimum Difference**: We maintain the minimum difference found across all windows and print it as the result.

This approach ensures that we efficiently find the optimal solution with a time complexity of O(N log N) due to sorting, followed by an O(N) pass to check all possible windows, making it suitable for large input sizes up to 100,000.
