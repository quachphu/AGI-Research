To solve this problem, we need to determine the number of subarrays in an array where the sum of elements is equal to the product of those elements. The solution involves checking all possible subarrays efficiently to ensure optimal performance.

### Approach
1. **Understanding Subarrays**: A subarray is a contiguous part of an array. For an array of size \( N \), there are \( \frac{N(N+1)}{2} \) possible subarrays.
2. **Constraints Handling**: Given the constraints, a brute-force approach checking each subarray directly is feasible. However, we optimize by incrementally calculating the sum and product for each subarray starting from each index.
3. **Incremental Calculation**: For each starting index \( i \), we compute the sum and product for subarrays ending at index \( j \) (where \( j \geq i \)) incrementally. This reduces the time complexity from \( O(N^3) \) to \( O(N^2) \).

### Solution Code
```python
T = int(input())
for _ in range(T):
    N = int(input())
    A = list(map(int, input().split()))
    count = 0
    for i in range(N):
        current_sum = 0
        current_product = 1
        for j in range(i, N):
            current_sum += A[j]
            current_product *= A[j]
            if current_sum == current_product:
                count += 1
    print(count)
```

### Explanation
1. **Reading Input**: The input is read in a standard way where the first line contains the number of test cases \( T \). For each test case, we read the array size \( N \) and the array elements.
2. **Iterating Over Subarrays**: For each starting index \( i \), we initialize the sum and product. As we extend the subarray ending at index \( j \), we update the sum and product incrementally.
3. **Checking Conditions**: For each subarray from \( i \) to \( j \), we check if the sum equals the product. If they match, we increment the count.
4. **Efficiency**: This approach ensures that each subarray is checked in constant time after the initial setup, leading to an efficient solution with \( O(N^2) \) complexity per test case, which is optimal given the constraints.

This method efficiently handles all possible subarrays and checks the required condition in an optimal manner, ensuring correctness and performance within the problem constraints.
