To solve this problem, we need to determine the total time during which two tourists, starting from points (-1, 0) and (1, 0) at a given time, cannot see each other due to walls appearing on the line x=0. The solution involves checking intersections between the tourists' line of sight and the walls, considering the time each wall appears.

### Approach
1. **Input Reading and Preprocessing**: Read the number of tourist pairs and walls, followed by the wall details and query times.
2. **Interval Calculation**: For each query time, calculate the intervals during which each wall blocks the tourists' view. This involves determining the valid intervals based on the wall's appearance time and the query time.
3. **Interval Merging**: Merge overlapping intervals to avoid double-counting the blocked time.
4. **Summing Valid Intervals**: Calculate the total blocked time by summing the lengths of the merged intervals.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n, m = int(input[ptr]), int(input[ptr+1])
    ptr += 2
    walls = []
    for _ in range(m):
        l = int(input[ptr])
        r = int(input[ptr+1])
        t = int(input[ptr+2])
        ptr += 3
        walls.append((l, r, t))
    queries = list(map(int, input[ptr:ptr+n]))
    
    for qi in queries:
        intervals = []
        for l, r, t_wall in walls:
            a = max(t_wall - qi, l)
            if a <= r:
                intervals.append((a, r))
        # Merge intervals
        if not intervals:
            print(0)
            continue
        # Sort intervals by start time
        intervals.sort()
        merged = []
        current_start, current_end = intervals[0]
        for start, end in intervals[1:]:
            if start > current_end:
                merged.append((current_start, current_end))
                current_start, current_end = start, end
            else:
                current_end = max(current_end, end)
        merged.append((current_start, current_end))
        total = 0
        for s, e in merged:
            total += e - s
        print(total)

if __name__ == "__main__":
    main()
```
