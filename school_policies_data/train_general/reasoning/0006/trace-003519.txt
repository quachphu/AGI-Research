To solve this problem, we need to determine if a given string \( S \) of odd length is a strong palindrome. A strong palindrome must satisfy three conditions related to its structure and the structure of its substrings.

### Approach
1. **Check if the entire string is a palindrome**: A string is a palindrome if it reads the same forwards and backwards.
2. **Check the first half substring**: The substring formed by the first \((N-1)/2\) characters (where \( N \) is the length of \( S \)) must also be a palindrome.
3. **Check the second half substring**: The substring starting from the \((N+3)/2\)-th character to the end of the string must be a palindrome.

### Solution Code
```python
def main():
    S = input().strip()
    # Check if S is a palindrome
    if S != S[::-1]:
        print("No")
        return
    N = len(S)
    # Check first part
    first_part = S[0 : (N - 1) // 2]
    if first_part != first_part[::-1]:
        print("No")
        return
    # Check third part
    third_part_start = (N + 3) // 2 - 1
    third_part = S[third_part_start:]
    if third_part != third_part[::-1]:
        print("No")
        return
    # All conditions met
    print("Yes")

main()
```

### Explanation
1. **Palindrome Check for the Entire String**: The string \( S \) is checked against its reverse to determine if it is a palindrome.
2. **First Half Substring Check**: The substring from the start of \( S \) to the \((N-1)/2\)-th character (converted to 0-based indexing) is checked for being a palindrome.
3. **Second Half Substring Check**: The substring starting from the \((N+3)/2\)-th character (converted to 0-based indexing) to the end of \( S \) is checked for being a palindrome.

By systematically breaking down the problem into these three checks, we ensure that all conditions for a strong palindrome are met efficiently. The solution leverages Python's string slicing and reversal capabilities to simplify each check.
