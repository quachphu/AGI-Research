### Approach
1. **Input Handling**: Read multiple datasets until encountering a line with a single zero. Each dataset starts with the number of students followed by their scores in three subjects.
2. **Classification Conditions**: Check each student's scores against the conditions in order of class priority (A, B, C):
   - **Class A**: If any subject score is 100, or the average of Mathematics and English is at least 90, or the average of all three subjects is at least 80.
   - **Class B**: If the average of all three subjects is at least 70, or the average is at least 50 with either Mathematics or English score being at least 80.
   - **Class C**: If none of the above conditions are met.
3. **Efficiency**: Use integer arithmetic to avoid floating-point operations, ensuring efficient and accurate comparisons.

### Solution Code
```python
def determine_class(pm, pe, pj):
    if pm == 100 or pe == 100 or pj == 100:
        return 'A'
    if pm + pe >= 180:
        return 'A'
    total = pm + pe + pj
    if total >= 240:
        return 'A'
    if total >= 210:
        return 'B'
    if total >= 150 and (pm >= 80 or pe >= 80):
        return 'B'
    return 'C'

def main():
    import sys
    data = list(map(int, sys.stdin.read().split()))
    ptr = 0
    while ptr < len(data):
        n = data[ptr]
        ptr += 1
        if n == 0:
            break
        for _ in range(n):
            pm = data[ptr]
            pe = data[ptr + 1]
            pj = data[ptr + 2]
            ptr += 3
            print(determine_class(pm, pe, pj))

if __name__ == "__main__":
    main()
```
