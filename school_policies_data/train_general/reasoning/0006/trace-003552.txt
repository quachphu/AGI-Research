To solve this problem, we need to determine the minimum number of steps required to transform an initial array of zeros into a target array using specific operations. Each operation allows adding or subtracting 1 from all elements starting from a chosen index to the end of the array.

### Approach
The key insight is that each element in the target array can be viewed as a series of incremental changes from the previous element. The minimum number of steps required is determined by summing the absolute differences between consecutive elements in the target array, starting from the initial zero value. This approach works because each difference between consecutive elements in the target array corresponds to a set of operations starting at a specific index, ensuring that previous elements remain unchanged once set.

### Solution Code
```python
n = int(input())
b = list(map(int, input().split()))
res = 0
prev = 0
for num in b:
    res += abs(num - prev)
    prev = num
print(res)
```

### Explanation
1. **Reading Input**: The code reads the length of the array `n` and the target array `b`.
2. **Initialization**: We initialize `res` to accumulate the total steps and `prev` to track the previous element's value, starting from 0 (the initial array value).
3. **Iterating Through Target Array**: For each element in the target array, compute the absolute difference from the previous element. This difference represents the number of steps needed to transition from the previous element's value to the current element's value.
4. **Summing Steps**: Accumulate these absolute differences in `res` to get the total number of steps required.
5. **Output Result**: Finally, print the total number of steps.

This approach efficiently computes the result in linear time, O(n), which is optimal for the given problem constraints.
