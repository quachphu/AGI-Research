To solve this problem, we need to determine if there exist three distinct elements in an array whose sum equals a given value \( K \). The solution must be efficient given the constraints, where the array can have up to 3000 elements.

### Approach
1. **Sort the Array**: Sorting helps in efficiently finding the triplet using the two-pointer technique.
2. **Iterate with Two Pointers**: For each element in the array (considered as the first element of the triplet), use two pointers to find the remaining two elements such that their sum with the first element equals \( K \).
   - The left pointer starts just after the current element.
   - The right pointer starts at the end of the array.
   - Adjust the pointers based on whether the current sum is less than or greater than the target sum.

### Solution Code
```python
n = int(input())
arr = list(map(int, input().split()))
k = int(input())

if n < 3:
    print("NO")
else:
    arr.sort()
    found = False
    for i in range(n - 2):
        left = i + 1
        right = n - 1
        target = k - arr[i]
        while left < right:
            current_sum = arr[left] + arr[right]
            if current_sum == target:
                found = True
                break
            elif current_sum < target:
                left += 1
            else:
                right -= 1
        if found:
            break
    print("YES" if found else "NO")
```

### Explanation
1. **Sorting**: The array is sorted to facilitate the two-pointer technique, which reduces the time complexity significantly.
2. **Triplet Search**: For each element in the array (up to the third last element), we fix it as the first element and then use two pointers to check the remaining elements for the required sum.
   - **Left Pointer**: Starts right after the current element to avoid reuse.
   - **Right Pointer**: Starts at the end of the array.
   - **Adjust Pointers**: If the sum of the two pointers is less than the target, move the left pointer right to increase the sum. If the sum is greater, move the right pointer left to decrease the sum.
3. **Early Termination**: If a valid triplet is found, the search terminates early to optimize performance.

This approach ensures an efficient solution with a time complexity of \( O(n^2) \), which is feasible for the given constraints.
