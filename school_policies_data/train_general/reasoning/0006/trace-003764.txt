```python
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    arr = list(map(int, input[1:n+1]))
    m = int(input[n+1])
    
    original = arr.copy()
    current_pos = 0
    
    while len(arr) > 1:
        index = (current_pos + m - 1) % len(arr)
        del arr[index]
        current_pos = index % len(arr)  # Update current position
    
    last = arr[0]
    if last % 2 == 1:
        result = sorted(x for x in original if x % 2 == 1)
    else:
        result = sorted(x for x in original if x % 2 == 0)
    
    print(' '.join(map(str, result)))

main()
```

### Explanation
1. **Reading Input**: The input is read in one go and split into individual components. The first value is the size of the array, followed by the array elements, and finally the integer m.
2. **Copy Original Array**: A copy of the original array is made to preserve it for later use after the deletion process.
3. **Simulate Deletions**: Using a loop, we repeatedly compute the index of the element to remove, delete it, and update the current position to the next starting point. This continues until only one element remains.
4. **Check Parity and Collect Results**: The parity of the last remaining element determines whether we collect all odd or even numbers from the original array. These numbers are then sorted and printed.

This approach efficiently simulates the circular deletion process and ensures the final result is derived from the original array elements, maintaining correctness and clarity.
