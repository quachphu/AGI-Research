To solve this problem, we need to modify a grid such that exactly `k` lakes remain by filling the minimum number of water cells. A lake is defined as a maximal region of water cells not connected to the ocean, which surrounds the grid.

### Approach
1. **Identify Ocean Regions**: Use BFS to mark all water cells connected to the grid's borders (ocean) as visited.
2. **Identify Lakes**: After marking ocean regions, the remaining unvisited water cells form lakes. Collect these lakes using BFS.
3. **Sort Lakes by Size**: Sort the collected lakes by their size in ascending order to determine which lakes to fill.
4. **Fill Smallest Lakes**: Fill the smallest lakes until exactly `k` lakes remain. The number of lakes to fill is determined by the difference between the initial number of lakes and `k`.
5. **Output the Result**: Print the number of cells filled and the modified grid.

```python
    directions = [ (-1,0), (1,0), (0,-1), (0,1) ]
    
    visited = [ [False for _ in range(m)] for __ in range(n) ]
    
    # Mark all ocean-connected cells
    border_cells = []
    for i in range(n):
        for j in range(m):
            if i == 0 or i == n-1 or j == 0 or j == m-1:
                border_cells.append( (i, j) )
    
    for i, j in border_cells:
        if grid[i][j] == '.' and not visited[i][j]:
            queue = deque()
            queue.append((i, j))
            visited[i][j] = True
            while queue:
                x, y = queue.popleft()
                for dx, dy in directions:
                    nx, ny = x + dx, y + dy
                    if 0 <= nx < n and 0 <= ny < m:
                        if grid[nx][ny] == '.' and not visited[nx][ny]:
                            visited[nx][ny] = True
                            queue.append((nx, ny))
    
    # Collect lakes
    lakes = []
    for i in range(n):
        for j in range(m):
            if grid[i][j] == '.' and not visited[i][j]:
                queue = deque()
                queue.append((i, j))
                visited[i][j] = True
                lake_cells = []
                while queue:
                    x, y = queue.popleft()
                    lake_cells.append((x, y))
                    for dx, dy in directions:
                        nx, ny = x + dx, y + dy
                        if 0 <= nx < n and 0 <= ny < m and grid[nx][ny] == '.' and not visited[nx][ny]:
                            visited[nx][ny] = True
                            queue.append((nx, ny))
                lakes.append((len(lake_cells), lake_cells))
    
    # Sort lakes by size to remove the smallest ones
    lakes.sort()
    
    total_lakes = len(lakes)
    remove = total_lakes - k
    total_filled = 0
    cells_to_fill = []
    
    for i in range(remove):
        total_filled += lakes[i][0]
        cells_to_fill.extend(lakes[i][1])
    
    # Fill the cells in the grid
    for x, y in cells_to_fill:
        grid[x][y] = '*'
    
    # Output the results
    print(total_filled)
    for row in grid:
        print(''.join(row))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Marking Ocean Regions**: The code first identifies all water cells connected to the grid's borders using BFS. These cells are part of the ocean and marked as visited.
2. **Collecting Lakes**: After marking ocean regions, the remaining unvisited water cells form lakes. Each lake is collected using BFS to determine its size and cells.
3. **Sorting and Filling Lakes**: The lakes are sorted by size. The smallest lakes are filled until exactly `k` lakes remain, ensuring the minimum number of cells are filled.
4. **Output**: The modified grid is printed after filling the necessary cells, showing the required changes.

This approach efficiently identifies and processes the necessary regions to meet the problem's constraints, ensuring optimal performance for grid sizes up to 50x50.
