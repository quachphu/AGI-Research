To solve this problem, we need to count the number of pairs (i, j) such that the product of the elements at these indices forms a perfect k-th power. This involves analyzing the prime factorization of each element and determining how they can combine to form such a power.

### Approach
1. **Prime Factorization**: Decompose each number into its prime factors.
2. **Modulo Operation**: For each prime factor, compute the exponent modulo k. If the result is zero, the prime factor can be ignored as it already contributes to a perfect k-th power.
3. **Signature Creation**: Create a "signature" for each number using the remaining prime factors and their exponents after the modulo operation.
4. **Complement Signature**: For each signature, compute its complement, which is the required signature to form a perfect k-th power when multiplied.
5. **Frequency Map**: Use a frequency map to count occurrences of each signature. For each number, check how many previous numbers have the complement signature and update the count of valid pairs accordingly.

### Solution Code
```python
import sys
from collections import defaultdict

# Precompute smallest prime factors (SPF) for numbers up to 10^5
max_spf = 10**5
spf = list(range(max_spf + 1))
for i in range(2, int(max_spf**0.5) + 1):
    if spf[i] == i:
        for j in range(i * i, max_spf + 1, i):
            if spf[j] == j:
                spf[j] = i

def factor(n):
    factors = {}
    while n > 1:
        p = spf[n]
        while n % p == 0:
            factors[p] = factors.get(p, 0) + 1
            n = n // p
    return factors

def main():
    input = sys.stdin.read().split()
    n, k = map(int, input[0:2])
    a = list(map(int, input[2:2+n]))
    
    freq = defaultdict(int)
    total = 0
    
    for num in a:
        factors = factor(num)
        signature = []
        for p, e in factors.items():
            rem = e % k
            if rem != 0:
                signature.append((p, rem))
        signature.sort()
        sig_key = tuple(signature)
        
        complement = []
        for (p, e) in signature:
            req_e = (k - e) % k
            if req_e != 0:
                complement.append((p, req_e))
        complement.sort()
        comp_key = tuple(complement)
        
        total += freq.get(comp_key, 0)
        freq[sig_key] += 1
    
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prime Factorization**: Using a precomputed smallest prime factor (SPF) array, each number is factorized into its prime components efficiently.
2. **Modulo Operation**: For each prime factor, the exponent is reduced modulo k. If the result is zero, the prime factor is excluded from the signature.
3. **Signature and Complement**: Each number's signature is a sorted list of tuples (prime, remainder). The complement signature is derived by adjusting each remainder to form a perfect k-th power when combined with another number's signature.
4. **Frequency Counting**: A dictionary keeps track of how many times each signature has been encountered. For each number, the count of valid pairs is updated by checking how many previous numbers have the required complement signature.

This approach ensures that we efficiently count valid pairs by leveraging prime factorization and modular arithmetic, leading to an optimal solution even for large input sizes.
