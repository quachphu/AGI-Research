To solve this problem, we need to determine the minimum number of operations required to delete an entire string where each operation allows us to delete a contiguous substring of the same characters. The solution involves using dynamic programming to efficiently compute the minimum operations for all possible substrings of the given string.

### Approach
1. **Dynamic Programming (DP) Setup**: Define a 2D DP array `dp[i][j]` where `dp[i][j]` represents the minimum number of operations needed to delete the substring starting at index `i` and ending at index `j`.
2. **Base Case**: If the substring length is 1 (i.e., `i == j`), then `dp[i][j]` is 1 because a single character can be deleted in one operation.
3. **Recurrence Relation**:
   - **Default Case**: Initialize `dp[i][j]` with the value `1 + dp[i+1][j]`, which represents deleting the character at `i` first and then the remaining substring.
   - **Optimization Check**: For each position `k` from `i+1` to `j`, if the characters at positions `i` and `k` are the same, consider the possibility of merging the deletions. Update `dp[i][j]` to the minimum of its current value and the sum of `dp[i+1][k-1]` (deleting the substring between `i` and `k`) and `dp[k][j]` (deleting the substring starting from `k`).

### Solution Code
```python

s = input().strip()

if n == 0:
    print(0)
    exit()

        if i == j:
            dp[i][j] = 1
        else:
            dp[i][j] = 1 + dp[i+1][j]
            for k in range(i+1, j+1):

                    temp = dp[i+1][k-1]
```

4. **Result**: The final result is stored in `dp[0][n-1]`, which gives the minimum operations to delete the entire string starting from index 0 to `n-1`.
