To solve this problem, we need to split a given positive integer \( n \) into three positive integers \( a, b, c \) such that \( a + b + c = n \) and none of the integers \( a, b, \) or \( c \) is a multiple of 3. The solution can be derived by considering the remainder when \( n \) is divided by 3.

### Approach
1. **Identify the Remainder**: Compute the remainder of \( n \) when divided by 3. This helps in determining how to split \( n \) appropriately.
2. **Case Analysis**:
   - **Case 1 (Remainder 0)**: If \( n \mod 3 = 0 \), split \( n \) into \( 1, 1, \) and \( n - 2 \). This works because \( n - 2 \) will not be a multiple of 3.
   - **Case 2 (Remainder 1)**: If \( n \mod 3 = 1 \), split \( n \) into \( 1, 1, \) and \( n - 2 \). Here, \( n - 2 \) will again not be a multiple of 3.
   - **Case 3 (Remainder 2)**: If \( n \mod 3 = 2 \), split \( n \) into \( 1, 2, \) and \( n - 3 \). This ensures all parts are non-multiples of 3.

### Solution Code
```python
n = int(input())
remainder = n % 3
if remainder == 0 or remainder == 1:
    a, b = 1, 1
else:
    a, b = 1, 2
c = n - a - b
print(a, b, c)
```

### Explanation
- **Reading Input**: The input integer \( n \) is read from standard input.
- **Determine Remainder**: The remainder when \( n \) is divided by 3 is calculated to decide the split strategy.
- **Splitting Strategy**:
  - For remainders 0 or 1, split \( n \) into \( 1, 1, \) and \( n - 2 \). This ensures the sum is \( n \) and no part is a multiple of 3.
  - For remainder 2, split \( n \) into \( 1, 2, \) and \( n - 3 \). This adjustment ensures all parts are valid non-multiples of 3.
- **Output**: The three integers are printed in the required format.

This approach efficiently handles all possible values of \( n \) within the given constraints and guarantees a valid solution as required.
