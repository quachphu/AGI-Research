To solve this problem, we need to determine the number of days it takes for each kid's book to return to them for the first time after being passed according to a fixed permutation. The solution involves identifying cycles in the permutation, as each cycle's length determines the number of days for the books within that cycle to return to their respective owners.

### Approach
1. **Cycle Detection in Permutations**: Each permutation can be decomposed into cycles. For each kid, the number of days required for their book to return is the length of the cycle they belong to.
2. **Traversal and Marking Visited Nodes**: For each kid, if they haven't been visited, traverse through the permutation starting from that kid until we return to the starting point, marking all visited kids in the process. This traversal forms a cycle.
3. **Cycle Length Assignment**: The length of each detected cycle is assigned as the result for all kids in that cycle.

### Solution Code
```python
q = int(input())
for _ in range(q):
    n = int(input())
    p = list(map(int, input().split()))
    visited = [False] * (n + 1)
    res = [0] * (n + 1)
    for i in range(1, n + 1):
        if not visited[i]:
            cycle = []
            current = i
            while not visited[current]:
                visited[current] = True
                cycle.append(current)
                current = p[current - 1]
            cycle_len = len(cycle)
            for kid in cycle:
                res[kid] = cycle_len
    print(' '.join(map(str, res[1:n+1])))
```

### Explanation
1. **Input Reading**: The number of queries is read first. For each query, the number of kids and the permutation array are read.
2. **Cycle Detection**: For each kid starting from 1 to n, if the kid hasn't been visited, a cycle detection process starts. This process follows the permutation until it loops back to the starting kid, marking all visited kids in the cycle.
3. **Result Calculation**: The length of each detected cycle is stored in the result array for each kid in that cycle.
4. **Output**: The result for each query is printed as space-separated values corresponding to each kid from 1 to n.

This approach efficiently finds cycles in the permutation using a linear scan with a time complexity of O(n) per query, making it suitable for the given constraints.
