To solve this problem, we need to maximize the number of 1's in an array after performing exactly K inversions. Each inversion changes a 0 to 1 or a 1 to 0. The goal is to determine the optimal strategy for these inversions to achieve the maximum number of 1's.

### Approach
1. **Count Initial 0s and 1s**: First, count the number of 0s (C0) and 1s (C1) in the initial array.
2. **Check Inversion Limits**:
   - If K is less than or equal to the number of 0s (C0), convert all possible 0s to 1s. The maximum number of 1s will be C1 + K.
   - If K exceeds the number of 0s (C0), convert all 0s to 1s first. The remaining inversions (K - C0) must be applied to 1s. The result depends on whether the remaining inversions are even or odd:
     - **Even Remaining Inversions**: No net change as flipping 1s even times leaves them as 1s.
     - **Odd Remaining Inversions**: One 1 will be turned to 0, resulting in N - 1 1s (where N is the total number of elements).

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N, K = int(input[idx]), int(input[idx+1])
        idx += 2
        arr = list(map(int, input[idx:idx+N]))
        idx += N
        c0 = arr.count(0)
        if K <= c0:
            res = (N - c0) + K
        else:
            remaining = K - c0
            res = N - (remaining % 2)
        print(res)

main()
```

### Explanation
- **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
- **Counting Zeros**: The number of zeros (C0) is counted to determine how many can be flipped to 1s.
- **Handling Inversions**:
  - If K is within the number of zeros, convert up to K zeros to 1s.
  - If K exceeds the number of zeros, convert all zeros to 1s and adjust based on the parity of remaining inversions. Even remaining inversions keep all elements as 1s, while odd inversions reduce one 1 to 0.

This approach ensures that we efficiently determine the maximum possible 1's using optimal inversion strategy, considering both the initial configuration of the array and the parity of remaining inversions.
