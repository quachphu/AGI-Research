To solve this problem, we need to find the longest contiguous subarray in a list of integers where the sum of the elements is zero. This can be efficiently achieved using prefix sums and a hash map to track the first occurrence of each prefix sum.

### Approach
1. **Prefix Sum Calculation**: Compute the prefix sum as we iterate through the list. The prefix sum at any index `i` is the sum of all elements from the start of the list up to `i`.
2. **Hash Map Tracking**: Use a hash map to store the first occurrence of each prefix sum. This helps in determining the longest subarray that sums to zero by checking if the same prefix sum has been encountered before.
3. **Max Length Calculation**: For each index, if the current prefix sum has been seen before, the subarray between the first occurrence of this prefix sum and the current index sums to zero. The length of this subarray is the difference between these indices. Track the maximum length of such subarrays.

### Solution Code
```python
import sys

def main():
    data = list(map(int, sys.stdin.read().split()))
    n = data[0]
    d = data[1:n+1]
    
    prefix_sums = {0: -1}
    current_sum = 0
    max_len = 0
    
    for i in range(n):
        current_sum += d[i]
        if current_sum in prefix_sums:
            length = i - prefix_sums[current_sum]
            if length > max_len:
                max_len = length
        else:
            prefix_sums[current_sum] = i
    
    print(max_len)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints, and then split into individual integers.
2. **Prefix Sum Initialization**: We initialize a hash map with `{0: -1}` to handle cases where a prefix sum of zero is encountered starting from the beginning of the list.
3. **Iterating Through Elements**: For each element, we update the current prefix sum. If this sum has been seen before, we calculate the length of the subarray between the first occurrence of this sum and the current index. If this length is greater than the previously recorded maximum, we update the maximum length.
4. **Updating Hash Map**: If the current prefix sum is not in the hash map, we add it with the current index as its value. This ensures we always track the first occurrence of each prefix sum.

This approach efficiently finds the longest subarray with a sum of zero in O(N) time complexity, where N is the number of elements, making it suitable for large input sizes up to 200,000 elements.
