x, y = map(int, input().split())

orig_x, orig_y = 0, 0
for c in s:
    if c == 'U':
        orig_y += 1
    elif c == 'D':
        orig_y -= 1
    elif c == 'R':
        orig_x += 1
    else:
        orig_x -= 1

if orig_x == x and orig_y == y:
    print(0)
    exit()

delta_x = x - orig_x
delta_y = y - orig_y

prefix_x = [0] * (n + 1)
prefix_y = [0] * (n + 1)

for i in range(n):
    c = s[i]
    dx, dy = 0, 0
    if c == 'U':
        dy = 1
    elif c == 'D':
        dy = -1
    elif c == 'R':
        dx = 1
    else:
        dx = -1
    prefix_x[i+1] = prefix_x[i] + dx
    prefix_y[i+1] = prefix_y[i] + dy

min_length = -1
for L in range(1, n+1):
    for i in range(n - L + 1):
        j = i + L
        owx = prefix_x[j] - prefix_x[i]
        owy = prefix_y[j] - prefix_y[i]
        if abs(owx + delta_x) + abs(owy + delta_y) == L:
            print(L)
            exit()

print(-1)

### Explanation
1. **Original Displacement Calculation**: The robot's final position after following the initial sequence is computed by iterating through each movement.
2. **Immediate Check**: If the robot is already at the target position, we immediately return 0.
3. **Delta Calculation**: The difference between the target position and the original position is calculated to determine the necessary adjustment.
4. **Prefix Sums**: These arrays store cumulative displacements, allowing efficient calculation of the displacement of any subsegment.
5. **Sliding Window**: For each possible subsegment length, we check all subsegments of that length. If adjusting a subsegment's movements can result in the required displacement, we return the length of that subsegment.

This approach ensures we efficiently check all possible subsegments, leveraging prefix sums for quick displacement calculations. The solution iterates through possible subsegment lengths and checks each subsegment, ensuring we find the minimum length required to adjust the robot's path to the target.
