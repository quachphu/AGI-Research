n = int(input())
nums = [int(input()) for _ in range(n)]

lo = [] # max-heap (store as negatives)
hi = [] # min-heap

sum_med = 0

for num in nums:
    if len(lo) ==0 or num <= -lo[0]:
        heapq.heappush(lo, -num)
    else:
        heapq.heappush(hi, num)
    
    # balance
    if len(lo) > len(hi) +1:

        val = -heapq.heappop(lo)

        val = heapq.heappop(hi)

To solve this problem, we need to efficiently compute the median of the first k numbers for each k from 1 to N and then sum these medians, taking the result modulo 100000. The challenge lies in maintaining the median efficiently as elements are added one by one, which can be achieved using two heaps to keep track of the lower and upper halves of the numbers.

### Approach
1. **Two Heaps Technique**: Use a max-heap (`lo`) to store the lower half of the numbers and a min-heap (`hi`) to store the upper half. The max-heap allows us to quickly access the largest element in the lower half, while the min-heap allows quick access to the smallest element in the upper half.
2. **Balancing Heaps**: After each insertion, ensure the heaps are balanced such that the size of `lo` is either equal to or one more than the size of `hi`. This ensures the median is always the top element of `lo`.
3. **Efficient Insertions**: For each new number, add it to the appropriate heap based on the current median. Adjust the heaps as needed to maintain balance, moving elements between heaps if necessary.

### Solution Code
```python
import heapq

def calculate_medians_sum():
    MOD = 100000
    n = int(input())
    nums = [int(input()) for _ in range(n)]
    
    lo = []  # max heap (stored as negatives)
    hi = []  # min heap
    sum_med = 0
    
    for num in nums:
        if not lo or num <= -lo[0]:
            heapq.heappush(lo, -num)
        else:
            heapq.heappush(hi, num)
        
        # Balance the heaps
        if len(lo) > len(hi) + 1:
            val = -heapq.heappop(lo)
            heapq.heappush(hi, val)
        elif len(hi) > len(lo):
            val = heapq.heappop(hi)
            heapq.heappush(lo, -val)
        
        sum_med += (-lo[0])
    
    print(sum_med % MOD)

calculate_medians_sum()
```

### Explanation
1. **Reading Input**: The input is read and stored in a list.
2. **Heap Initialization**: Two heaps are initialized, `lo` (max-heap implemented using negative values) and `hi` (min-heap).
3. **Processing Each Number**: For each number, determine which heap to add it to based on the current median. If the number is less than or equal to the current median (top of `lo`), it goes into `lo`; otherwise, it goes into `hi`.
4. **Balancing Heaps**: After each insertion, check if the heaps need balancing. If `lo` has more than one element than `hi`, move the largest element from `lo` to `hi`. If `hi` has more elements than `lo`, move the smallest element from `hi` to `lo`.
5. **Summing Medians**: The median after each insertion is the top element of `lo`, which is added to the cumulative sum. Finally, the result is printed modulo 100000.

This approach ensures that each insertion and balancing operation runs in logarithmic time, making the solution efficient and suitable for large input sizes up to 100,000.
