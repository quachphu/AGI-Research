To solve this problem, we need to determine the number of "beautiful" arrays of length \( n \) as defined by Chris the Rabbit. A beautiful array is either non-decreasing or non-increasing. We must account for overlapping cases (constant arrays) to avoid double-counting.

### Approach
1. **Combinatorial Counting**: 
   - The number of non-decreasing arrays of length \( n \) with elements from 1 to \( n \) can be computed using the combinatorial formula \( C(2n-1, n-1) \). This is derived from the stars and bars theorem in combinatorics.
   - Similarly, the number of non-increasing arrays is the same as non-decreasing arrays.
   - Subtract the overlap (constant arrays) which are counted twice. There are exactly \( n \) constant arrays.

2. **Modular Arithmetic**:
   - Given the constraints, we need to compute results modulo \( 10^9 + 7 \).
   - Precompute factorials and inverse factorials up to \( 2n-1 \) using efficient modular arithmetic to handle large numbers.

3. **Efficient Computation**:
   - Use precomputed factorials and inverse factorials to quickly compute combinations using modular inverses.

### Solution Code
```python
MOD = 10**9 + 7

n = int(input())

if n == 0:
    print(0)
else:
    a = 2 * n - 1
    max_fact = a
    # Precompute factorials modulo MOD
    fact = [1] * (max_fact + 1)
    for i in range(1, max_fact + 1):
        fact[i] = fact[i-1] * i % MOD
    
    # Precompute inverse factorials modulo MOD
    inv_fact = [1] * (max_fact + 1)
    inv_fact[max_fact] = pow(fact[max_fact], MOD - 2, MOD)
    for i in range(max_fact - 1, -1, -1):
        inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD
    
    # Calculate combination C(2n-1, n-1)
    c = fact[a] * inv_fact[n-1] % MOD
    c = c * inv_fact[a - (n-1)] % MOD  # a - (n-1) = n
    
    # Compute the result
    ans = (2 * c - n) % MOD
    print(ans)
```

### Explanation
1. **Combinatorial Calculation**:
   - The number of non-decreasing arrays is computed using the combination formula \( C(2n-1, n-1) \), which is derived from the stars and bars theorem.
   - The same count applies to non-increasing arrays, so we multiply by 2.

2. **Overlap Subtraction**:
   - Constant arrays (where all elements are the same) are counted in both non-decreasing and non-increasing counts. Subtract \( n \) to correct for this double-counting.

3. **Modular Precomputation**:
   - Factorials and their modular inverses are precomputed up to \( 2n-1 \) to efficiently compute combinations using modular arithmetic, ensuring the solution works within the constraints.

This approach efficiently handles large values of \( n \) up to \( 10^5 \) using precomputation and modular arithmetic, ensuring the solution is both optimal and correct.
