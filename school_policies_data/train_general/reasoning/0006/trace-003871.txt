        answer = -1

            current_str, steps = queue.popleft()

            if current_str == delta:

                answer = steps

                found = True

To solve this problem, we need to determine the minimum number of substitutions required to transform an initial string γ into a final string δ using given substitution pairs. Each substitution replaces all non-overlapping occurrences of a substring α with another substring β, following specific rules.

### Approach
1. **Breadth-First Search (BFS)**: We use BFS to explore all possible strings reachable from γ by applying the substitution pairs. BFS is suitable here because it guarantees the shortest path (minimum steps) to reach the target string δ.
2. **Substitution Function**: For each substitution pair (α, β), we generate the next possible string by replacing all non-overlapping occurrences of α with β. The substitution is done in a leftmost, non-overlapping manner.
3. **Pruning**: Since each substitution increases the length of the string, we prune any paths where the current string's length exceeds that of δ, as these cannot lead to the solution.
4. **Visited Set**: To avoid revisiting the same string multiple times and getting stuck in cycles, we maintain a set of visited strings.

from collections import deque

def substitute(s, alpha, beta):
    res = []
    current = 0
    len_alpha = len(alpha)
    len_s = len(s)
    while current <= len_s - len_alpha:
        if s[current:current+len_alpha] == alpha:
            res.append(beta)
            current += len_alpha
        else:
            res.append(s[current])
            current += 1
    res.append(s[current:])
    return ''.join(res)
