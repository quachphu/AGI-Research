1. **Validation of Existing Non-zero Elements**: First, we check if the existing non-zero elements in the matrix already violate the strictly increasing constraints in their rows and columns. If any violation is found, the matrix is impossible to fix, and we return -1 immediately.

2. **Compute Lower Bounds**: Using a forward pass (top to bottom, left to right), we compute the minimum possible value each zero cell can take based on the maximum of the values from the top and left neighbors plus one.

3. **Compute Upper Bounds**: Using a backward pass (bottom to top, right to left), we compute the maximum possible value each zero cell can take based on the minimum of the values from the bottom and right neighbors minus one.

4. **Check Feasibility**: For each cell, we ensure that the computed lower bound is not greater than the upper bound. If any cell violates this condition, the matrix is impossible to fix.

5. **Replace Zeros and Validate**: Replace each zero with its computed upper bound value and then validate the entire matrix to ensure all rows and columns are strictly increasing. If valid, compute the sum; otherwise, return -1.

### Solution Code
```python
n, m = map(int, input().split())
matrix = []
for _ in range(n):
    row = list(map(int, input().split()))
    matrix.append(row)

# Step 1: Validate existing non-zero cells
valid = True
for i in range(n):
    for j in range(m):
        if matrix[i][j] == 0:
            continue
        # Check left neighbor
        if j > 0 and matrix[i][j-1] != 0 and matrix[i][j-1] >= matrix[i][j]:
            valid = False
        # Check upper neighbor
        if i > 0 and matrix[i-1][j] != 0 and matrix[i-1][j] >= matrix[i][j]:
            valid = False
        # Check right neighbor
        if j < m-1 and matrix[i][j+1] != 0 and matrix[i][j] >= matrix[i][j+1]:
            valid = False
        # Check lower neighbor
        if i < n-1 and matrix[i+1][j] != 0 and matrix[i][j] >= matrix[i+1][j]:
            valid = False
if not valid:
    print(-1)
    exit()

# Step 2: Compute lower bounds with forward pass
lower = [[0]*m for _ in range(n)]
for i in range(n):
    for j in range(m):
        if matrix[i][j] != 0:
            lower[i][j] = matrix[i][j]
        else:
            lower_val = 1
            if i > 0:
                lower_val = max(lower_val, lower[i-1][j] + 1)
            if j > 0:
                lower_val = max(lower_val, lower[i][j-1] + 1)
            lower[i][j] = lower_val

# Step 3: Compute upper bounds with backward pass
upper = [[0]*m for _ in range(n)]
for i in range(n):
    for j in range(m):
        if matrix[i][j] != 0:
            upper[i][j] = matrix[i][j]
        else:
            upper[i][j] = float('inf')

# Backward pass processing
for i in range(n-1, -1, -1):
    for j in range(m-1, -1, -1):
        upper_val = float('inf')
        if i < n-1:
            upper_val = min(upper_val, upper[i+1][j] - 1)
        if j < m-1:
            upper_val = min(upper_val, upper[i][j+1] - 1)
        if matrix[i][j] == 0:
            upper[i][j] = upper_val
        else:
            # Check if the current cell's value is within the upper_val constraint
            if upper_val < matrix[i][j]:
                print(-1)
                exit()

# Check if any cell has lower > upper or non-zero cells' bounds mismatch
possible = True
for i in range(n):
    for j in range(m):
        if lower[i][j] > upper[i][j]:
            possible = False
        if matrix[i][j] != 0:
            if lower[i][j] != matrix[i][j] or upper[i][j] != matrix[i][j]:
                possible = False
if not possible:
    print(-1)
    exit()

# Replace zeros with upper values and create new_matrix
new_matrix = []
for i in range(n):
    new_row = []
    for j in range(m):
        if matrix[i][j] == 0:
            new_row.append(upper[i][j])
        else:
            new_row.append(matrix[i][j])
    new_matrix.append(new_row)

# Final check for strictly increasing rows and columns
# Check rows
for i in range(n):
    for j in range(m-1):
        if new_matrix[i][j] >= new_matrix[i][j+1]:
            print(-1)
            exit()

# Check columns
for j in range(m):
    for i in range(n-1):
        if new_matrix[i][j] >= new_matrix[i+1][j]:
            print(-1)
            exit()

# Calculate total sum
total = sum(sum(row) for row in new_matrix)
print(total)
```

### Explanation
1. **Validation**: We first check if the existing non-zero elements already violate the strictly increasing order in rows and columns.
2. **Lower Bounds**: We compute the minimum value each zero cell can take based on its top and left neighbors.
3. **Upper Bounds**: We compute the maximum value each zero cell can take based on its bottom and right neighbors.
4. **Feasibility Check**: We ensure that each cell's lower bound is not greater than its upper bound.
5. **Replacement and Final Check**: Replace zeros with their upper bounds and validate the entire matrix again to ensure strict increasing order in all rows and columns. If valid, compute the sum of the matrix elements.
