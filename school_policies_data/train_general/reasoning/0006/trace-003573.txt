To solve this problem, we need to determine the number of possible height sequences of mountains that satisfy both Takahashi's and Aoki's recorded maximum heights. The solution involves checking constraints from both records and ensuring they are compatible.

### Approach
1. **Initial Check**: Verify if the maximum height recorded by Takahashi (T_N) matches the maximum recorded by Aoki (A_1). If not, output 0 immediately.
2. **Iterate Through Each Mountain**: For each mountain, determine the constraints imposed by Takahashi's and Aoki's records:
   - **Takahashi's Constraint**: If the current maximum height (T_i) is greater than the previous maximum (T_{i-1}), then the height of the current mountain (h_i) must be exactly T_i.
   - **Aoki's Constraint**: If the current maximum height (A_i) is greater than the next maximum (A_{i+1}), then the height of the current mountain (h_i) must be exactly A_i.
3. **Combine Constraints**: If both constraints require a specific height, they must agree. Otherwise, calculate the number of valid heights based on the remaining possibilities.
4. **Multiply Possibilities**: For each valid configuration, multiply the number of possible heights for each mountain, taking the result modulo 10^9 + 7.
