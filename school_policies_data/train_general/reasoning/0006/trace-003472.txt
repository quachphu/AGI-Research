To solve this problem, we need to simulate a firewall system that processes network packets based on a set of filtering rules. The firewall determines whether each packet should be permitted or denied according to the rules, which are prioritized based on their order of appearance.

### Approach
1. **Reading Input**: The input consists of multiple datasets. Each dataset starts with two integers, `n` (number of rules) and `m` (number of packets), followed by `n` filtering rules and `m` packets.
2. **Filtering Rules**: Each rule specifies whether packets matching certain source and destination patterns should be permitted or denied. The rules are processed in reverse order (from last to first) to ensure higher priority for later rules.
3. **Pattern Matching**: For each packet, check if it matches the source and destination patterns of each rule. A pattern can include wildcard characters ('?') that match any digit.
4. **Decision Making**: The first matching rule (in reverse order) determines whether the packet is permitted or denied. If no rules match, the packet is denied by default.
5. **Output**: For each dataset, output the number of permitted packets followed by the permitted packets in their original order.

### Solution Code
```python
import sys

def main():
    while True:
        # Read n and m
        line = sys.stdin.readline()
        if not line:
            break
        line = line.strip()
        while line == '':
            line = sys.stdin.readline().strip()
        if not line:
            break
        n, m = map(int, line.split())
        if n == 0 and m == 0:
            break
        
        # Read rules
        rules = []
        for _ in range(n):
            parts = sys.stdin.readline().strip().split()
            action = parts[0]
            src_pat = parts[1]
            dst_pat = parts[2]
            rules.append((action, src_pat, dst_pat))
        
        # Read packets
        packets = []
        for _ in range(m):
            line = sys.stdin.readline().strip()
            parts = line.split(' ', 2)
            src = parts[0]
            dst = parts[1]
            msg = parts[2]
            packets.append((src, dst, msg, line))
        
        # Process packets
        allowed = []
        for pkt in packets:
            src, dst, msg, original = pkt
            permitted = False
            for rule in reversed(rules):
                action, s_pat, d_pat = rule
                # Check source pattern
                match_s = True
                for i in range(8):
                    sc = s_pat[i]
                    if sc != '?' and sc != src[i]:
                        match_s = False
                        break
                if not match_s:
                    continue
                # Check destination pattern
                match_d = True
                for i in range(8):
                    dc = d_pat[i]
                    if dc != '?' and dc != dst[i]:
                        match_d = False
                        break
                if not match_d:
                    continue
                # Both match, apply action
                if action == 'permit':
                    allowed.append(original)
                permitted = True
                break
            # No else needed; default deny
        
        # Output
        print(len(allowed))
        for line in allowed:
            print(line)

if __name__ == "__main__":
    main()
```

3. **Matching Process**: For each packet, the rules are checked in reverse order. The packet's source and destination addresses are compared against each rule's patterns using wildcard matching.
4. **Decision Making**: The first matching rule determines the packet's fate. If a rule permits the packet, it is added to the allowed list; otherwise, it is denied. If no rules match, the packet is denied by default.
5. **Output**: The count of permitted packets is printed, followed by the permitted packets in their original order.
