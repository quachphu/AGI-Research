To solve this problem, we need to determine the number of distinct substrings in a given string. The solution must efficiently handle strings up to a length of 500,000 characters. We use a Suffix Automaton (SAM) to achieve this efficiently in linear time and space.

### Approach
1. **Suffix Automaton (SAM)**: A SAM is a powerful data structure that compactly represents all substrings of a given string. It allows us to efficiently count the number of distinct substrings by leveraging the properties of its states and transitions.
2. **Construction of SAM**: The SAM is built incrementally by processing each character of the string. Each state in the SAM represents a set of substrings ending at a certain position, and transitions between states represent adding a new character.
3. **Counting Substrings**: The number of distinct substrings can be computed by summing the contributions of each state in the SAM. Each state's contribution is the difference between its length and the length of its suffix link, which gives the number of new substrings introduced by that state.

### Solution Code
```python
class State:
    __slots__ = ['len', 'link', 'trans']
    def __init__(self):
        self.len = 0
        self.link = -1
        self.trans = [-1] * 26

def main():
    import sys
    S = sys.stdin.readline().strip()
    if not S:
        print(0)
        return
    sa = [State()]
    sa[0].len = 0
    sa[0].link = -1
    last = 0
    for c in S:
        ci = ord(c) - 97
        curr = State()
        curr.len = sa[last].len + 1
        curr.link = -1
        curr.trans = [-1] * 26
        sa.append(curr)
        curr_idx = len(sa) - 1
        p = last
        while p != -1 and sa[p].trans[ci] == -1:
            sa[p].trans[ci] = curr_idx
            p = sa[p].link
        if p == -1:
            sa[curr_idx].link = 0
        else:
            q = sa[p].trans[ci]
            if sa[p].len + 1 == sa[q].len:
                sa[curr_idx].link = q
            else:
                clone = State()
                clone.len = sa[p].len + 1
                clone.trans = list(sa[q].trans)
                clone.link = sa[q].link
                sa.append(clone)
                clone_idx = len(sa) - 1
                sa[q].link = clone_idx
                sa[curr_idx].link = clone_idx
                while p != -1 and sa[p].trans[ci] == q:
                    sa[p].trans[ci] = clone_idx
                    p = sa[p].link
        last = curr_idx
    ans = 0
    for i in range(1, len(sa)):
        ans += sa[i].len - sa[sa[i].link].len
    print(ans)

main()
```

### Explanation
1. **State Class**: Each state in the SAM has a length (`len`), a suffix link (`link`), and transitions (`trans`) to other states based on characters.
2. **Building the SAM**: For each character in the input string, we create a new state and update transitions and suffix links. If necessary, we clone states to maintain the properties of the SAM.
3. **Counting Distinct Substrings**: After constructing the SAM, we sum the contributions of each state (excluding the initial state) by calculating the difference between the length of the state and the length of its suffix link. This sum gives the total number of distinct substrings.

This approach efficiently handles the problem constraints, ensuring linear time and space complexity relative to the input size.
