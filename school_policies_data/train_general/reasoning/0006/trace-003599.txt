To solve this problem, we need to determine the winner of a wrestling match based on the points awarded for each technique used by the wrestlers. The winner is determined by the total points, lexicographical order of their sequences of points, and the last technique performed if the previous criteria are tied.

### Approach
1. **Sum Calculation**: Calculate the total points for each wrestler. The first wrestler's points are the sum of all positive values, and the second wrestler's points are the sum of the absolute values of all negative numbers.
2. **Sequence Construction**: Construct sequences of points for each wrestler in the order the techniques were performed.
3. **Comparison by Total Points**: If the total points of the wrestlers are different, the wrestler with the higher total points wins.
4. **Lexicographical Comparison**: If the total points are equal, compare the sequences lexicographically. The sequence that is lexicographically larger determines the winner.
5. **Last Technique Check**: If the sequences are lexicographically equal, the wrestler who performed the last technique wins.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    a = [int(sys.stdin.readline()) for _ in range(n)]
    
    sum_first = 0
    sum_second = 0
    first_seq = []
    second_seq = []
    
    for num in a:
        if num > 0:
            sum_first += num
            first_seq.append(num)
        else:
            sum_second += (-num)
            second_seq.append(-num)
    
    if sum_first > sum_second:
        print("first")
    elif sum_second > sum_first:
        print("second")
    else:
        if first_seq > second_seq:
            print("first")
        elif second_seq > first_seq:
            print("second")
        else:
            print("first" if a[-1] > 0 else "second")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin` for efficiency, especially given the potential size of the input.
2. **Sum and Sequence Construction**: As we read each value, we update the respective wrestler's total points and construct their sequence of points.
3. **Total Points Check**: If one wrestler's total points are higher, they are declared the winner immediately.
4. **Lexicographical Comparison**: If the total points are equal, we compare the sequences lexicographically using Python's built-in list comparison, which directly supports lexicographical ordering.
5. **Last Technique Decision**: If both sequences are identical, the last technique performed (determined by the sign of the last input value) breaks the tie.

This approach ensures that we efficiently determine the winner while adhering to the problem constraints and requirements.
