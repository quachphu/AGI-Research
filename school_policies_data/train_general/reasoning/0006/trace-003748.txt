To solve this problem, we need to determine the minimal set of questions Petya should ask to uniquely identify the number Vasya thought of between 1 and n. Each question is about whether the number is divisible by a specific value. The goal is to find the smallest set of such values (divisors) that ensures each number in the range has a unique combination of answers.

### Approach
1. **Prime Numbers and Prime Powers**: The key insight is that each number can be uniquely identified by its prime factors and their highest powers. For example, numbers 2 and 4 can be distinguished by checking divisibility by 4 (since 4 is a prime power of 2).
2. **Generate Primes**: Use the Sieve of Eratosthenes to generate all prime numbers up to n.
3. **Generate Prime Powers**: For each prime number, generate all its prime powers (e.g., 2, 4, 8 for prime 2) up to n. These prime powers are necessary to distinguish numbers that share the same prime factors but have different exponents.

### Solution Code
```python
def sieve(n):
    if n < 2:
        return []
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False
    for i in range(2, int(n ** 0.5) + 1):
        if is_prime[i]:
            for j in range(i * i, n + 1, i):
                is_prime[j] = False
    primes = [i for i, val in enumerate(is_prime) if val]
    return primes

n = int(input())
if n == 1:
    print(0)
else:
    primes = sieve(n)
    prime_powers = []
    for p in primes:
        e = 1
        current = p
        while current <= n:
            prime_powers.append(current)
            e += 1
            current = p ** e
    print(len(prime_powers))
    print(' '.join(map(str, prime_powers)))
```

### Explanation
1. **Prime Generation**: The Sieve of Eratosthenes efficiently generates all primes up to n. This helps in identifying the base factors for all numbers in the range.
2. **Prime Powers**: For each prime, we compute all its powers (e.g., 2^1, 2^2, etc.) up to n. These powers help in distinguishing numbers that have the same prime factors but different multiplicities.
3. **Uniqueness**: By including all prime powers, each number in the range 1 to n will have a unique set of divisors from the generated list, ensuring that Petya can uniquely determine the number based on the answers.

This approach ensures that the minimal set of questions is asked, leveraging the properties of prime numbers and their powers to achieve uniqueness in responses.
