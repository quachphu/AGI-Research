To solve this problem, we need to determine the maximum number of sweets Caisa can receive as change when buying a type of sugar from the supermarket. The key is to find the optimal sugar type that maximizes the sweets while considering the constraints of the given money.

### Approach
1. **Input Reading**: Read the number of sugar types and the amount of money Caisa has.
2. **Cost Conversion**: Convert the cost of each sugar type from dollars and cents into total cents to facilitate comparison.
3. **Affordability Check**: For each sugar type, check if Caisa can afford it using his available money.
4. **Change Calculation**: If a sugar type is affordable, compute the change in cents and determine the number of sweets (which is the remainder when the change is divided by 100).
5. **Max Sweets Tracking**: Track the maximum number of sweets obtained from all affordable sugar types. If no sugar type is affordable, return -1.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    s = int(input[idx])
    idx += 1
    max_sweets = -1
    for _ in range(n):
        xi = int(input[idx])
        yi = int(input[idx + 1])
        idx += 2
        cost = xi * 100 + yi
        if cost > s * 100:
            continue
        change = s * 100 - cost
        sweets = change % 100
        if sweets > max_sweets:
            max_sweets = sweets
    print(max_sweets if max_sweets != -1 else -1)

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list for efficient processing. The first two values are the number of sugar types and the money Caisa has.
2. **Iterating Through Sugars**: For each sugar type, the cost in dollars and cents is converted to total cents.
3. **Checking Affordability**: Each sugar's total cost is compared against Caisa's money (converted to cents). If affordable, the change is calculated.
4. **Calculating Sweets**: The change modulo 100 gives the number of sweets, as the remainder represents the cents part after converting as much as possible to dollars.
5. **Tracking Maximum Sweets**: The maximum number of sweets is tracked, and the result is printed. If no sugar is affordable, -1 is returned.

This approach ensures we efficiently check each sugar type and compute the maximum possible sweets in linear time, making it optimal for the given constraints.
