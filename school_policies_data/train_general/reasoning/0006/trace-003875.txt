To solve this problem, we need to efficiently compute the results of AND and OR searches on two sorted lists of document IDs. The AND search returns documents present in both lists, while the OR search returns all documents from either list, sorted and without duplicates.

### Approach

1. **AND Search**: This requires finding the intersection of two sorted lists. We use a two-pointer technique to traverse both lists simultaneously, comparing elements and moving pointers based on the comparison results. This approach ensures we efficiently find common elements in O(n + m) time complexity.

2. **OR Search**: This requires finding the union of two sorted lists. Using a similar two-pointer technique, we merge the two lists while skipping duplicates. This approach ensures the union is sorted and free of duplicates, also in O(n + m) time complexity.

### Solution Code

```python
import sys

def main():
    # Read input
    n, m = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    b = list(map(int, sys.stdin.readline().split()))
    
    # Compute AND results (intersection)
    and_list = []
    i = j = 0
    while i < n and j < m:
        if a[i] == b[j]:
            and_list.append(a[i])
            i += 1
            j += 1
        elif a[i] < b[j]:
            i += 1
        else:
            j += 1
    
    # Compute OR results (union, sorted and deduplicated)
    or_list = []
    current = None
    i = j = 0
    while i < n or j < m:
        if j >= m or (i < n and a[i] <= b[j]):
            candidate = a[i]
            i += 1
        else:
            candidate = b[j]
            j += 1
        if candidate != current:
            or_list.append(candidate)
            current = candidate
    
    # Output the results
    print(len(and_list), len(or_list))
    for num in and_list:
        print(num)
    for num in or_list:
        print(num)

if __name__ == "__main__":
    main()
```

### Explanation

1. **Reading Input**: The input is read using `sys.stdin.readline` for efficiency, especially with large input sizes. The first line provides the lengths of the two lists, followed by the elements of each list.

2. **AND Search Calculation**: Using two pointers, we traverse both lists. When elements at both pointers are equal, it's added to the result. If not, the pointer pointing to the smaller element is advanced. This efficiently finds the intersection.

3. **OR Search Calculation**: Again using two pointers, we merge the two lists. We ensure each element is added only once by tracking the last added element. This merges the lists into a sorted union without duplicates.

4. **Output**: The results are printed in the required format, first the counts of AND and OR results, followed by the elements of each list on separate lines.

This approach ensures optimal performance and correctness for the given problem constraints.
