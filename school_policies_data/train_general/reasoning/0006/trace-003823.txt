To solve this problem, we need to determine which of two given integers has a larger key number. The key number is calculated by subtracting the sum of all other prime factors from the largest prime factor of the integer. The solution involves efficiently computing the prime factors of each integer and then determining their key numbers.

### Approach
1. **Prime Factorization**: For each integer, compute its unique prime factors. This is done using trial division, checking divisibility starting from 2 upwards, followed by checking odd numbers up to the square root of the integer.
2. **Key Calculation**: Once the prime factors are obtained, sort them. The largest prime factor is the last element in the sorted list. The key number is calculated as the largest prime factor minus the sum of the remaining prime factors.
3. **Comparison**: For each pair of integers, compute their respective key numbers and compare them to determine which integer has the larger key number.

### Solution Code
```python
import sys

def get_prime_factors(n):
    factors = set()
    if n % 2 == 0:
        factors.add(2)
        while n % 2 == 0:
            n = n // 2
    i = 3
    while i * i <= n:
        if n % i == 0:
            factors.add(i)
            while n % i == 0:
                n = n // i
        i += 2
    if n > 1:
        factors.add(n)
    return sorted(factors)

def compute_key(n):
    factors = get_prime_factors(n)
    largest = factors[-1]
    sum_others = sum(factors) - largest
    return largest - sum_others

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        a, b = map(int, line.split())
        if a == 0 and b == 0:
            break
        key_a = compute_key(a)
        key_b = compute_key(b)
        print('a' if key_a > key_b else 'b')

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prime Factorization**: The `get_prime_factors` function efficiently computes the unique prime factors of a given integer. It handles even numbers separately and then checks for odd factors up to the square root of the number.
2. **Key Calculation**: The `compute_key` function uses the prime factors to determine the key number by sorting the factors and using the largest element to compute the result.
3. **Comparison and Output**: The `main` function reads input values, computes the key numbers for each pair of integers, and prints the result based on which integer has the larger key number.

This approach ensures that we efficiently determine the prime factors and compute the key numbers, allowing us to solve the problem within acceptable time limits even for large input values.
