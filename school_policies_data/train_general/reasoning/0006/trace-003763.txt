To solve this problem, we need to determine the last digit of \(a^b\) for very large values of \(a\) and \(b\). Direct computation is infeasible due to the size constraints, so we use mathematical properties of the last digits of powers to find an efficient solution.

### Approach
1. **Identify Last Digit of Base**: The last digit of \(a^b\) depends only on the last digit of \(a\). Thus, we first extract the last digit of \(a\).
2. **Handle Special Cases**:
   - If \(b = 0\), the result is 1 (since any number to the power of 0 is 1).
   - If the last digit of \(a\) is 0 and \(b > 0\), the result is 0.
3. **Cyclic Patterns**: The last digits of powers follow cyclic patterns. For example, the last digit of powers of 2 cycles through [2, 4, 8, 6]. Using these cycles, we can determine the last digit without full computation.
4. **Modulo Operation**: Using the cycle length, compute the effective exponent modulo the cycle length to find the position in the cycle and thus the result.

### Solution Code
```python
t = int(input())
for _ in range(t):
    a, b = input().split()
    last_digit = int(a[-1])
    b_val = int(b)
    
    if b_val == 0:
        print(1)
        continue
    if last_digit == 0:
        print(0)
        continue
    
    cycles = {
        1: [1],
        2: [2, 4, 8, 6],
        3: [3, 9, 7, 1],
        4: [4, 6],
        5: [5],
        6: [6],
        7: [7, 9, 3, 1],
        8: [8, 4, 2, 6],
        9: [9, 1]
    }
    cycle = cycles[last_digit]
    cycle_length = len(cycle)
    exponent_mod = (b_val - 1) % cycle_length
    print(cycle[exponent_mod])
```

### Explanation
1. **Reading Input**: The input is read as strings to handle very large numbers.
2. **Extracting Last Digit**: The last digit of \(a\) is obtained using string indexing.
3. **Special Cases Handling**: Directly handle cases where \(b = 0\) or the last digit of \(a\) is 0.
4. **Cycle Utilization**: Each digit (1-9) has a predefined cycle of last digits when raised to successive powers. The effective exponent is computed using modulo arithmetic on the cycle length to find the position in the cycle, which gives the result.

This approach efficiently reduces the problem size using mathematical properties, ensuring it handles very large inputs within feasible computational limits.
