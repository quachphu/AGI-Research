To solve this problem, we need to determine the maximum possible total score for a class of students based on their answers to a multiple-choice test. The key is to choose the correct answers for each question such that the total score is maximized.

### Approach
1. **Understand the Problem**: Each question has a fixed point value, and the goal is to choose the correct answer for each question such that the maximum number of students answer correctly. This will maximize the score for each question, contributing to the overall maximum total score.
2. **Input Handling**: Read the number of students and questions, followed by each student's answers and the point values for each question.
3. **Frequency Counting**: For each question, count how many students chose each possible answer (A-E). The answer with the highest frequency will be chosen as the correct answer for that question.
4. **Score Calculation**: Multiply the highest frequency count of each question by its respective point value and sum these products to get the maximum possible total score.

### Solution Code
```python
from collections import defaultdict

n, m = map(int, input().split())
students = [input().strip() for _ in range(n)]
a = list(map(int, input().split()))

total = 0
for j in range(m):
    counts = defaultdict(int)
    for i in range(n):
        c = students[i][j]
        counts[c] += 1
    max_count = max(counts.values())
    total += max_count * a[j]

print(total)
```

### Explanation
1. **Reading Input**: The first line of input contains the number of students (n) and questions (m). The next n lines contain the answers of each student, and the last line contains the point values for each question.
2. **Processing Each Question**: For each question (column), we count the occurrences of each answer choice (A-E) across all students.
3. **Maximizing Score**: For each question, the answer choice with the highest frequency is selected as the correct answer. The score for that question is calculated by multiplying the highest frequency by the question's point value.
4. **Summing Scores**: The scores for all questions are summed to get the maximum possible total score, which is then printed.

This approach ensures that we efficiently compute the maximum possible score by leveraging the frequency of answers for each question, leading to an optimal solution in O(n*m) time complexity, which is feasible given the problem constraints.
