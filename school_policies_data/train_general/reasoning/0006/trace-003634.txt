To solve this problem, we need to determine the maximum number of consecutive hours Polycarp rests, considering his schedule repeats daily. The key challenge is to account for the possibility that the longest rest period might wrap around from the end of one day to the start of the next.

### Approach
1. **Identify Linear Maximum Rest Period**: First, compute the longest consecutive rest period within a single day. This is done by iterating through the schedule and tracking the current and maximum streaks of rest hours (1s).

2. **Identify Wrap-around Rest Period**: Since the schedule repeats daily, the longest rest period might wrap around from the end of one day to the start of the next. To handle this, compute the number of rest hours at the beginning (leading rest hours) and end (trailing rest hours) of the schedule. The sum of these two values gives the maximum rest period if it wraps around.

3. **Determine the Result**: The result is the maximum value between the longest linear rest period and the wrap-around rest period.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))

max_streak = 0
current = 0
for num in a:
    if num == 1:
        current += 1
        max_streak = max(max_streak, current)
    else:
        current = 0

# Calculate leading and trailing 1s
leading = 0
i = 0
while i < n and a[i] == 1:
    leading += 1
    i += 1

trailing = 0
j = n - 1
while j >= 0 and a[j] == 1:
    trailing += 1
    j -= 1

wrap_around = leading + trailing
result = max(max_streak, wrap_around)
print(result)
```

### Explanation
1. **Linear Maximum Rest Period**: The code iterates through the schedule to find the longest sequence of consecutive 1s. This is stored in `max_streak`.

2. **Leading and Trailing Rest Hours**: The code calculates how many rest hours are at the start (leading) and end (trailing) of the schedule. This is done by iterating from the start until a working hour (0) is found for leading rest hours, and from the end until a working hour is found for trailing rest hours.

3. **Wrap-around Calculation**: The sum of leading and trailing rest hours gives the maximum rest period if it wraps around from the end of one day to the start of the next.

4. **Result Calculation**: The final result is the maximum of the linear maximum rest period and the wrap-around rest period, ensuring we consider both possibilities.

This approach efficiently handles all cases in O(n) time complexity, which is optimal given the constraints.
