To solve this problem, we need to determine the positions of molecules in a chemical structure after applying a sequence of swap operations. The problem involves two types of queries: finding the original position of a molecule that ends up in a specific position after the swaps and finding the new position of a molecule that starts in a specific position.

### Approach
The approach involves simulating the swap operations for each query. Each query specifies a range of swaps to apply to the initial state of the molecule structure. For each query, we process the swaps in the specified range and track the position changes of the molecule in question.

1. **Type 1 Query**: For each query of this type, we need to determine the original position of the molecule that ends up in position `x` after applying the swaps from `s` to `t`. This is done by reversing the swaps from `t` back to `s` and tracking the position changes in reverse order.
2. **Type 2 Query**: For each query of this type, we need to determine the new position of the molecule that starts in position `x` after applying the swaps from `s` to `t` in the given order.

```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    N, K, Q = map(int, input[ptr:ptr+3])
    ptr +=3
    swaps = []
    for _ in range(K):
        a, b = map(int, input[ptr:ptr+2])
        swaps.append((a, b))
        ptr +=2
    for _ in range(Q):
        parts = input[ptr:ptr+4]
        ptr +=4
        query_type = int(parts[0])
        s = int(parts[1])
        t = int(parts[2])
        x = int(parts[3])
        if query_type == 1:
            current = x
            for i in range(t-1, s-2, -1):
                a, b = swaps[i]
                if current == a:
                    current = b
                elif current == b:
                    current = a
            print(current)
        else:
            current = x
            for i in range(s-1, t):
                a, b = swaps[i]
                if current == a:
                    current = b
                elif current == b:
                    current = a
            print(current)

if __name__ == '__main__':
    main()
```

3. **Tracking Position**: For each query, the position of the molecule is tracked through each relevant swap. If the current position matches one of the positions in the swap, it is updated to the other position in the swap.
