To solve this problem, we need to determine if each set within a given range contains at least one segment that lies entirely within a specified query segment. The solution must efficiently handle multiple online queries due to the large input constraints.

### Approach
1. **Preprocessing Segments**: For each set, sort the segments by their right endpoint and compute the maximum left endpoint for all segments up to each position. This allows quick determination of the maximum left endpoint for any given right endpoint threshold.
2. **Segment Tree Construction**: Build a segment tree where each node represents a range of sets. Each leaf node (individual set) can quickly determine the maximum left endpoint for segments up to a given right endpoint using binary search. Internal nodes combine results from their children to provide the minimum value across their range.
3. **Query Handling**: For each query, use the segment tree to find the minimum maximum left endpoint across the specified range of sets. If this minimum meets the query's left endpoint requirement, the answer is "yes"; otherwise, it's "no".

### Solution Code
```python
import sys

def main():
    n, m, k = map(int, sys.stdin.readline().split())
    segments = [[] for _ in range(n + 1)]  # 1-based indexing

    for _ in range(k):
        l, r, p = map(int, sys.stdin.readline().split())
        segments[p].append((r, l))  # stored as (r, l)

    # Preprocess each set
    sorted_r = [[] for _ in range(n + 1)]
    prefix_max_l = [[] for _ in range(n + 1)]

    for p in range(1, n + 1):
        # Sort the segments by r ascending
        sorted_segments = sorted(segments[p], key=lambda x: x[0])
        rs = [seg[0] for seg in sorted_segments]
        ls = [seg[1] for seg in sorted_segments]
        sorted_r[p] = rs

        # Compute prefix_max_l
        current_max = -float('inf')
        pmax = []
        for l_val in ls:
            current_max = max(current_max, l_val)
            pmax.append(current_max)
        prefix_max_l[p] = pmax

    # Define the query function with corrected logic
    def query_segment(y, a, b, node_start, node_end):
        if node_end < a or node_start > b:
            return float('inf')  # No overlap
        if a <= node_start and node_end <= b:
            if node_start == node_end:
                p = node_start
                rs = sorted_r[p]
                pmax = prefix_max_l[p]
                if not rs:
                    return -float('inf')
                # Binary search for largest r <= y
                left, right = 0, len(rs) - 1
                j = -1
                while left <= right:
                    mid = (left + right) // 2
                    if rs[mid] <= y:
                        j = mid
                        left = mid + 1
                    else:
                        right = mid - 1
                if j == -1:
                    return -float('inf')
                else:
                    return pmax[j]
            else:
                mid = (node_start + node_end) // 2
                left_min = query_segment(y, node_start, mid, node_start, mid)
                right_min = query_segment(y, mid + 1, node_end, mid + 1, node_end)
                return min(left_min, right_min)
        mid = (node_start + node_end) // 2
        left_min = query_segment(y, a, b, node_start, mid)
        right_min = query_segment(y, a, b, mid + 1, node_end)
        return min(left_min, right_min)

    # Process each query
    for _ in range(m):
        a, b, x, y = map(int, sys.stdin.readline().split())
        min_val = query_segment(y, a, b, 1, n)
        if min_val >= x and min_val != -float('inf'):
            print("yes")
        else:
            print("no")
        sys.stdout.flush()

if __name__ == "__main__":
    main()
```

### Explanation
1. **Preprocessing**: Each set's segments are sorted by their right endpoint. A prefix maximum array of left endpoints is created for efficient range queries.
2. **Segment Tree**: The tree is constructed such that each node can quickly determine the minimum valid left endpoint for segments within a range of sets. This allows efficient range minimum queries.
3. **Query Handling**: For each query, the segment tree is queried to find the minimum valid left endpoint across the specified range. This minimum is compared to the query's left endpoint to determine the result.

This approach ensures that each query is handled in logarithmic time relative to the number of sets and segments, making it efficient for large input sizes.
