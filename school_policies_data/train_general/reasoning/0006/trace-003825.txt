To solve this problem, we need to select exactly one problem for each difficulty level from 1 to M such that the sum of their recommendation levels is maximized. Each difficulty level is guaranteed to have at least one problem.

### Approach
1. **Input Reading**: Read multiple datasets until encountering a line with two zeros.
2. **Processing Each Dataset**:
   - For each difficulty level (from 1 to M), track the maximum recommendation level.
   - Use a list to store the maximum recommendation level for each difficulty level.
3. **Sum Calculation**: After processing all problems in a dataset, sum the maximum recommendation levels for all difficulty levels from 1 to M.

### Solution Code
```python
def main():
    import sys
    while True:
        line = sys.stdin.readline()
        if not line:
            break
        line = line.strip()
        if not line:
            continue
        parts = list(map(int, line.split()))
        if parts[0] == 0 and parts[1] == 0:
            break
        N, M = parts[0], parts[1]
        max_v = [0] * (M + 1)
        for _ in range(N):
            d, v = map(int, sys.stdin.readline().split())
            if v > max_v[d]:
                max_v[d] = v
        print(sum(max_v[1:M+1]))
main()
```

### Explanation
1. **Reading Input**: The code reads input line by line. The first line of each dataset contains the number of problems (N) and the maximum difficulty level (M).
2. **Tracking Maximum Recommendations**: For each problem, the code checks its difficulty level and updates the maximum recommendation level for that difficulty if the current problem's recommendation level is higher.
3. **Summing Values**: After processing all problems in the dataset, the code sums the maximum recommendation values for each difficulty level from 1 to M and prints the result.

This approach ensures that we efficiently compute the maximum possible sum of recommendation levels by leveraging a list to track the highest recommendation value for each difficulty level. The complexity is linear with respect to the number of problems, making it efficient given the problem constraints.
