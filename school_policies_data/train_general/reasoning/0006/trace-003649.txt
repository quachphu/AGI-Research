To solve this problem, we need to maximize the total sociability of groups formed from a line of children, where each child has a specific charisma value. The sociability of a group is defined as the difference between the maximum and minimum charisma values in that group. 

### Approach
The approach involves using dynamic programming (DP) combined with a dictionary to track the maximum and minimum values of potential groups ending at each position. This allows us to efficiently compute the optimal grouping strategy by extending previous groups or starting new ones as needed.

1. **Dynamic Programming Array (dp)**: This array stores the maximum total sociability up to each position.
2. **Dictionary (max_min_dict)**: This tracks the maximum and minimum values of potential groups ending at each position, along with the best sum of sociabilities up to the start of the group.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    if n == 0:
        print(0)
        return
    a = list(map(int, input[1:n+1]))
    
    dp = [0] * n
    max_min_dict = {}

    current_max = a[0]
    current_min = a[0]
    key = (current_max, current_min)
    max_min_dict[key] = 0  # best_sum_prev is 0 (dp[j] where j is -1)
    dp[0] = current_max - current_min  # contribution of the first group
    
    for i in range(1, n):
        new_dict = {}
        x = a[i]
        # Process previous entries
        for (cm, cmin), best_prev in max_min_dict.items():
            new_max = max(cm, x)
            new_min = min(cmin, x)
            new_key = (new_max, new_min)
            if new_key in new_dict:
                if best_prev > new_dict[new_key]:
                    new_dict[new_key] = best_prev
            else:
                new_dict[new_key] = best_prev
        # Add the new group starting at i
        new_key = (x, x)
        best_prev_new = dp[i-1]
        if new_key in new_dict:
            if best_prev_new > new_dict[new_key]:
                new_dict[new_key] = best_prev_new
        else:
            new_dict[new_key] = best_prev_new
        
        # Compute the current dp[i]
        max_sum = 0
        for (cm, cmin), best_prev in new_dict.items():
            current_sum = best_prev + (cm - cmin)
            if current_sum > max_sum:
                max_sum = current_sum

        max_min_dict = new_dict
    
    print(dp[-1])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Initialization**: We start by initializing the DP array and the dictionary for the first element. The initial group is just the first child, so the sociability is 0 (since there's only one element).

2. **Iterating through each child**: For each subsequent child, we consider two possibilities:
   - Extending previous groups to include the current child, updating the maximum and minimum values of these groups.
   - Starting a new group with the current child.

3. **Updating the dictionary**: For each group ending at the current child, we update the dictionary to keep track of the best possible sum of sociabilities. This ensures that we only keep the most beneficial groups for future calculations.

4. **Computing the DP value**: The maximum sociability up to the current child is computed by considering all possible groups ending at that child, either by extending previous groups or starting a new one.

This approach efficiently tracks potential groups and their contributions, ensuring we maximize the total sociability in linear time, making it suitable for large input sizes.
