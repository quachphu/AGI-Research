To solve this problem, we need to determine if we can insert exactly one lowercase English letter into a given string such that the resulting string becomes a palindrome. If possible, we should output the resulting palindrome; otherwise, we output "NA".

### Approach
1. **Understand the Problem**: A palindrome reads the same forwards and backwards. We need to check all possible insertions of one character into the given string to see if any result in a palindrome.
2. **Generate All Possible Insertions**: For each possible position in the string (from the start to the end), and for each lowercase letter (a-z), generate a new string by inserting the letter at that position.
3. **Check for Palindrome**: For each generated string, check if it is a palindrome.
4. **Output the Result**: If any valid palindrome is found, print it and exit. If no valid palindrome is found after checking all possibilities, print "NA".

### Solution Code
```python
def main():
    s = input().strip()
    for i in range(len(s) + 1):
        for c in 'abcdefghijklmnopqrstuvwxyz':
            new_s = s[:i] + c + s[i:]
            if new_s == new_s[::-1]:
                print(new_s)
                return
    print("NA")

main()
```

### Explanation
1. **Reading Input**: The input string is read and stripped of any leading or trailing whitespace.
2. **Iterate Over Positions**: We loop through each possible insertion position from 0 to the length of the string (inclusive).
3. **Iterate Over Characters**: For each position, we check every lowercase letter (a-z).
4. **Generate New String**: For each combination of position and character, a new string is created by inserting the character at the specified position.
5. **Check Palindrome**: The new string is checked to see if it is a palindrome by comparing it to its reverse.
6. **Output**: The first valid palindrome found is printed, and the function exits. If no valid palindrome is found after all checks, "NA" is printed.

This approach ensures that we efficiently check all possible insertions and determine the result in a straightforward manner. The complexity is manageable given the constraints, making it feasible even for the maximum input size.
