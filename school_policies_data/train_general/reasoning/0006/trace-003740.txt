To solve this problem, we need to assign weights to the edges of a tree such that the XOR of the weights on the path between any two leaves is zero. We aim to determine the minimum and maximum possible number of distinct edge weights (f) that can be used.

### Approach
1. **Minimum Possible f**:
   - **Bipartite Coloring**: Check if all leaves can be placed in the same bipartition (color) using a BFS or DFS. If all leaves are in the same color, the minimum f is 1. Otherwise, the minimum f is 3. This is because if all leaves are in the same bipartition, all paths between leaves will have even lengths, allowing the use of a single weight. If leaves are in different bipartitions, paths between them will have odd lengths, requiring at least three distinct weights.

2. **Maximum Possible f**:
   - **Parent Node Analysis**: Calculate the maximum possible f by considering the number of leaves connected to each parent node. Subtract the number of redundant edges (those connected to the same parent) from the total number of edges. This gives the maximum distinct weights possible.

### Solution Code
```python
import sys
from collections import deque

def main():
    sys.setrecursionlimit(1 << 25)
    n = int(sys.stdin.readline())
    edges = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        a, b = map(int, sys.stdin.readline().split())
        edges[a].append(b)
        edges[b].append(a)
    
    # Find leaves (nodes with degree 1)
    leaves = [i for i in range(1, n+1) if len(edges[i]) == 1]
    
    # Calculate maximum possible f
    parent_count = {}
    for leaf in leaves:
        parent = edges[leaf][0]
        parent_count[parent] = parent_count.get(parent, 0) + 1
    sum_val = sum((v - 1) for v in parent_count.values())
    max_f = (n - 1) - sum_val
    
    # Calculate minimum possible f using bipartition check
    color = [-1] * (n + 1)
    q = deque()
    root = 1
    color[root] = 0
    q.append(root)
    while q:
        u = q.popleft()
        for v in edges[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                q.append(v)
    
    leaf_colors = [color[leaf] for leaf in leaves]
    if all(c == leaf_colors[0] for c in leaf_colors):
        min_f = 1
    else:
        min_f = 3
    
    print(min_f, max_f)

if __name__ == "__main__":
    main()
```
