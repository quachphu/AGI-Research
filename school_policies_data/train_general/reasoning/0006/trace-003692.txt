To solve this problem, we need to compute the sum of specific elements in an odd-sized square matrix that are considered "good". The good elements are those on the main diagonal, secondary diagonal, middle row, and middle column of the matrix.

### Approach
1. **Identify Good Elements**: The good elements are defined as follows:
   - **Main Diagonal**: Elements where the row index equals the column index (i.e., `i == j`).
   - **Secondary Diagonal**: Elements where the sum of the row index and column index equals `n-1` (i.e., `i + j == n - 1`).
   - **Middle Row**: The row at index `n // 2`.
   - **Middle Column**: The column at index `n // 2`.

2. **Sum Calculation**: Iterate through each element of the matrix and check if it satisfies any of the conditions for being a good element. Sum all such elements.

### Solution Code
```python
n = int(input())
matrix = [list(map(int, input().split())) for _ in range(n)]
mid = n // 2
total = 0
for i in range(n):
    for j in range(n):
        if i == j or i + j == n - 1 or i == mid or j == mid:
            total += matrix[i][j]
print(total)
```

### Explanation
1. **Reading Input**: The first input line gives the size of the matrix `n`. The next `n` lines each contain `n` integers representing the matrix elements.
2. **Mid Calculation**: The middle index `mid` is calculated as `n // 2` since `n` is odd.
3. **Checking Conditions**: For each element in the matrix, we check if it lies on the main diagonal, secondary diagonal, middle row, or middle column. If it does, we add its value to the total sum.
4. **Output**: The final sum of all good elements is printed.

This approach efficiently checks each element exactly once, resulting in a time complexity of O(n²), which is optimal for the given problem constraints.
