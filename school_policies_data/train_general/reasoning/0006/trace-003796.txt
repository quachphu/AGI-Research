To solve this problem, we need to determine the optimal points on the west and east banks of a river to build a bridge such that the total distance between the two villages is minimized. The total distance includes the sum of the distance from the west village to the bridge point on the west bank, the straight-line distance of the bridge, and the length of the path from the bridge point on the east bank to the east village.

### Approach
1. **Problem Analysis**:
   - The river is represented by vertical lines at x = a (west bank) and x = b (east bank).
   - We need to find points Ai on the west bank and Bj on the east bank such that the sum of distances OAi (from the west village to Ai), AiBj (the bridge), and lj (path from Bj to the east village) is minimized.

2. **Key Insights**:
   - For each point Bj on the east bank, calculate a potential optimal point on the west bank using a derived formula based on minimizing the continuous function of distances.
   - Use binary search to efficiently find the closest points on the west bank to the calculated optimal point, and check adjacent points to ensure the minimum distance.

3. **Algorithm**:
   - For each point Bj on the east bank, compute the optimal y-coordinate on the west bank using the formula y_opt = (a * yj) / b.
   - Use binary search to find the insertion point of y_opt in the sorted list of west bank y-coordinates.
   - Check the insertion point and its adjacent points to find the minimum distance for each Bj.
   - Track the minimum total distance across all points Bj and their corresponding optimal points Ai.

### Solution Code
```python
import bisect
import math

n, m, a, b = map(int, input().split())
y_west = list(map(int, input().split()))
y_east = list(map(int, input().split()))
l_list = list(map(int, input().split()))

min_total = float('inf')
best_west = -1
best_east = -1

for j_idx in range(m):
    yj = y_east[j_idx]
    lj = l_list[j_idx]
    y_opt = (a * yj) / b
    pos = bisect.bisect_left(y_west, y_opt)
    candidates = []
    for delta in (-1, 0, 1):
        k = pos + delta
        if 0 <= k < n:
            candidates.append(k)
    candidates = list(sorted(set(candidates)))  # Remove duplicates and sort
    
    current_min = None
    current_i = -1
    for i in candidates:
        yi = y_west[i]
        oa = math.hypot(a, yi)
        aibj = math.hypot(b - a, yj - yi)
        total = oa + aibj + lj
        if current_min is None or total < current_min:
            current_min = total
            current_i = i
    if current_min < min_total:
        min_total = current_min
        best_west = current_i + 1  # Convert to 1-based index
        best_east = j_idx + 1

print(best_west, best_east)
```

### Explanation
- **Reading Input**: The input values are read and parsed into appropriate variables.
- **Optimal Point Calculation**: For each point Bj on the east bank, compute the optimal y-coordinate on the west bank using the formula derived from minimizing the continuous distance function.
- **Binary Search**: Use binary search to find the closest points on the west bank to the calculated optimal y-coordinate.
- **Adjacent Points Check**: Check the insertion point and its adjacent points to ensure the minimum distance is found considering discrete points.
- **Tracking Minimum**: Keep track of the minimum total distance and corresponding points across all Bj points.

This approach efficiently narrows down the potential points using mathematical insights and binary search, ensuring the solution is optimal and runs in O(m log n) time complexity, which is feasible for large input sizes.
