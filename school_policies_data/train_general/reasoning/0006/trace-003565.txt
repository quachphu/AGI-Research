To solve this problem, we need to determine if a given number is a dual prime. A dual prime is defined as a number that is prime and whose sum of digits is also a prime number. 

### Approach
The solution involves two main steps:
1. **Prime Check**: Verify if the given number is a prime number.
2. **Sum of Digits Check**: Calculate the sum of the digits of the number and check if this sum is also a prime number.

The approach can be broken down into the following steps:
1. **Input Reading**: Read the number of test cases and the respective numbers.
2. **Prime Check Function**: Implement a function to check if a number is prime.
3. **Sum of Digits Calculation**: Convert the number to a string, iterate through each character to sum the digits.
4. **Dual Prime Check**: For each number, check if both the number and the sum of its digits are prime.

### Solution Code
```python
def is_prime(n):
    if n <= 1:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False
    for i in range(3, int(n**0.5) + 1, 2):
        if n % i == 0:
            return False
    return True

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        if not is_prime(n):
            print("NO")
            continue
        digit_sum = sum(int(d) for d in str(n))
        if is_prime(digit_sum):
            print("YES")
        else:
            print("NO")

solve()
```

### Explanation
1. **Prime Check Function (`is_prime`)**:
   - This function checks if a number `n` is prime by testing divisibility from 2 up to the square root of `n`. If any divisor is found, the number is not prime. This method ensures efficiency by reducing the number of checks needed.

2. **Main Function (`solve`)**:
   - Reads the number of test cases.
   - For each test case, reads the number and checks if it is prime using `is_prime`.
   - If the number is not prime, it immediately prints "NO".
   - If the number is prime, it calculates the sum of its digits and checks if this sum is also prime.
   - Prints "YES" if both the number and the sum of its digits are prime, otherwise prints "NO".

This approach efficiently checks the required conditions using optimal prime checking and straightforward digit sum calculation, ensuring correctness and performance for typical input sizes.
