To solve this problem, we need to determine the maximum number of times a draw (where both teams have the same score) could appear on the scoreboard during a football match, given some known score moments in chronological order. The initial score of 0:0 is counted as a draw.

### Approach
1. **Initialization**: Start by considering the initial score of 0:0, which is a draw. This is counted once.
2. **Iterate through Checkpoints**: For each pair of consecutive checkpoints, compute the maximum number of possible draws between them.
3. **Calculate Draws Between Checkpoints**:
   - For each interval between two consecutive checkpoints (prev_a, prev_b) and (curr_a, curr_b), determine the range of possible draws.
   - The start of the range is the maximum of the previous scores plus one if the previous checkpoint was a draw.
   - The end of the range is the minimum of the current scores.
   - If the start of the range is less than or equal to the end, the number of draws in this interval is the difference between the end and start plus one.

### Solution Code
```python
n = int(input())
checkpoints = [tuple(map(int, input().split())) for _ in range(n)]

prev_a, prev_b = 0, 0
total = 1  # Initial 0:0 counts as one draw

for a, b in checkpoints:
    # Calculate the start and end of possible draws in this interval
    start_k = max(prev_a, prev_b)
    if prev_a == prev_b:
        start_k += 1
    end_k = min(a, b)
    
    if end_k >= start_k:
        total += end_k - start_k + 1
    
    prev_a, prev_b = a, b

print(total)
```

### Explanation
1. **Initialization**: The initial score (0:0) is counted as one draw.
2. **Iterate through Checkpoints**: For each checkpoint, compute the possible draws between the previous checkpoint and the current one.
3. **Range Calculation**:
   - **start_k**: The starting point of possible draws in the interval. If the previous checkpoint was a draw, increment by one to avoid counting it again.
   - **end_k**: The ending point of possible draws, which is the minimum of the current scores.
   - If the range is valid (start_k ≤ end_k), add the number of draws in this range to the total.

This approach efficiently calculates the maximum possible draws by considering each interval between consecutive checkpoints and summing the valid draws within each interval. The solution ensures that all possible draws are counted without overlapping or missing any valid intervals.
