To solve this problem, we need to determine the minimum and maximum possible total bus fare given the number of adults (n) and children (m) in a bus. The fare structure allows each adult to take up to one child for free, with additional children requiring payment.

### Approach
1. **Check for Validity**: 
   - If there are children (m > 0) but no adults (n = 0), the situation is impossible as children cannot ride alone.
   - If there are no children (m = 0), the fare is simply the number of adults as each adult pays 1 ruble.

2. **Calculate Minimum Fare**:
   - The minimum fare occurs when each adult takes as many children as possible, utilizing the free ride for one child per adult. This results in the minimum fare being the maximum of the number of adults and children, i.e., `max(n, m)`.

3. **Calculate Maximum Fare**:
   - The maximum fare occurs when one adult takes all the children (paying for all but one child), and the remaining adults pay individually. This results in the maximum fare being `m + n - 1`.

### Solution Code
```python
n, m = map(int, input().split())

if m == 0:
    print(f"{n} {n}")
elif n == 0:
    print("Impossible")
else:
    min_fare = max(n, m)
    max_fare = m + n - 1
    print(f"{min_fare} {max_fare}")
```

### Explanation
- **Validity Check**: If there are children but no adults, it's impossible. If there are no children, the fare is determined by the number of adults.
- **Minimum Fare Calculation**: By optimally using each adult to take one child for free, the fare is minimized to the greater value between the number of adults and children.
- **Maximum Fare Calculation**: By having one adult take all children (paying for all but one) and others paying individually, the fare is maximized to the sum of children and adults minus one.

This approach efficiently computes the required values with a constant time complexity, ensuring it handles all edge cases within the problem constraints.
