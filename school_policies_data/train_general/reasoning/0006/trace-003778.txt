To solve this problem, we need to determine if two input strings are anagrams of each other. An anagram is a word formed by rearranging the letters of another word, using all the original letters exactly once.

### Approach
The approach to solve this problem involves the following steps:
1. **Reading Inputs**: Read two input strings from standard input.
2. **Check Anagrams**: Check if the two strings are anagrams by sorting both strings and comparing the sorted results. If the sorted strings are identical, they are anagrams; otherwise, they are not.

### Solution Code
```python
s1 = input().strip()
s2 = input().strip()

if sorted(s1) == sorted(s2):
    print("Yes")
else:
    print("No")
```

### Explanation
1. **Reading Inputs**: The code reads two input strings using `input().strip()`, which ensures that any leading or trailing whitespace is removed from each input line.
2. **Check Anagrams**: The strings are sorted using the `sorted()` function, which returns a list of characters in ascending order. By comparing these sorted lists, we can determine if the original strings contain the same characters in any order. If the sorted lists are identical, the function prints "Yes"; otherwise, it prints "No".

This approach efficiently checks for anagrams with a time complexity of O(n log n) due to the sorting step, where n is the length of the strings. This is optimal for typical string lengths encountered in such problems.
