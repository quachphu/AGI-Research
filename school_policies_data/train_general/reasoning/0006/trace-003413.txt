### Approach
1. **Reading the Atomic Table**: First, we read the atomic symbols and their corresponding weights from the input until we encounter the line "END_OF_FIRST_PART". These values are stored in a dictionary for quick lookup.

2. **Parsing Molecular Formulas**: For each molecular formula provided in the input, we need to parse it to compute the total molecular weight. The parsing process involves handling nested groups and multipliers correctly using a stack-based approach.

3. **Stack-Based Parsing**: 
   - **Parentheses Handling**: When encountering an opening parenthesis '(', we push a new context (dictionary) onto the stack to handle nested groups.
   - **Closing Parentheses Handling**: When encountering a closing parenthesis ')', we parse the subsequent number (multiplier), pop the current context, multiply the counts by the multiplier, and merge the result back into the parent context.
   - **Atomic Symbols and Multipliers**: For each atomic symbol, we check if it exists in the atomic table. If it does, we parse any subsequent number to determine the count of that atom in the current context.

4. **Weight Calculation**: After parsing the entire formula, we sum the weighted counts of all atoms in the base context to get the total molecular weight. If any atomic symbol in the formula is not found in the atomic table, the result is "UNKNOWN".

def main():
    import sys

    for line in sys.stdin:

        symbol = parts[0]

    for line in sys.stdin:

            break

            else:

                symbol = line[i]
                i += 1
                if i < len(line) and line[i].islower():
