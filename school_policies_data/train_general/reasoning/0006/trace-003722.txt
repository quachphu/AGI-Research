To solve this problem, we need to determine if a given subset of dominoes can be arranged in a straight line such that adjacent dominoes have matching numbers. This problem can be approached by modeling it as a graph problem where we check for the existence of an Eulerian trail, which requires specific conditions regarding node degrees and graph connectivity.

### Approach

1. **Graph Representation**: Represent each domino as an undirected edge between two nodes (numbers on the domino). Each node's degree is calculated based on how many times it appears in the dominoes.

2. **Degree Check**: For an Eulerian trail to exist, the graph must have either 0 or 2 nodes with an odd degree. This is because an Eulerian trail starts and ends at nodes with odd degrees (if they exist), or forms a cycle if all nodes have even degrees.

3. **Connectivity Check**: All edges (dominoes) must form a single connected component. This ensures that there is a path connecting all dominoes, allowing them to be arranged in a single line.

import sys
from collections import defaultdict, deque

def solve():
    lines = [line.strip() for line in sys.stdin if line.strip()]
    idx = 0
    while idx < len(lines):
        n = int(lines[idx])
        idx += 1
        dominoes = []
        parts = lines[idx].split()
        idx += 1
        for s in parts:
            a = int(s[0])
            b = int(s[1])
            dominoes.append((a, b))
        
        adj = defaultdict(list)
        degrees = defaultdict(int)
        for a, b in dominoes:
            adj[a].append(b)
            adj[b].append(a)
            degrees[a] += 1
            degrees[b] += 1
        
        odd_count = 0
        for node in degrees:
            if degrees[node] % 2 != 0:
                odd_count += 1
        
        if odd_count not in (0, 2):
            print("No")
            continue
        
        non_zero_nodes = [node for node in degrees if degrees[node] > 0]
        if not non_zero_nodes:
            print("Yes")
            continue
        
        start = non_zero_nodes[0]
        visited = set()
        queue = deque([start])
        visited.add(start)
        
        while queue:
            u = queue.popleft()
            for v in adj[u]:
                if v not in visited:
                    visited.add(v)
                    queue.append(v)
        
        connected = True
        for node in non_zero_nodes:
            if node not in visited:
                connected = False
                break
        
        if connected:
            print("Yes")
        else:
            print("No")

if __name__ == "__main__":
    solve()
