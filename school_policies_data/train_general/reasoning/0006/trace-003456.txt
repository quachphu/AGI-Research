To solve this problem, we need to determine the number of KxK submatrices in an NxN grid whose sum is a perfect cube. The solution involves efficiently computing the sum of each possible KxK submatrix using a prefix sum array and checking if the sum is a perfect cube.

### Approach
1. **Prefix Sum Array**: Construct a prefix sum array to efficiently compute the sum of any submatrix in O(1) time. The prefix sum array helps in reducing the time complexity of sum calculation from O(K^2) per submatrix to O(1).
2. **Check Perfect Cube**: For each KxK submatrix sum, determine if the sum is a perfect cube using a binary search approach. This ensures accuracy and efficiency in checking cube roots even for very large numbers.

### Solution Code
```python
def is_perfect_cube(s):
    if s < 1:
        return False
    low = 1
    high = 10**5  # since (1e5)^3 is 1e15
    while low <= high:
        mid = (low + high) // 2
        cube = mid ** 3
        if cube == s:
            return True
        elif cube < s:
            low = mid + 1
        else:
            high = mid - 1
    return False

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    k = int(input[ptr])
    ptr += 1
    matrix = []
    for _ in range(n):
        row = list(map(int, input[ptr:ptr+n]))
        ptr += n
        matrix.append(row)
    
    # Compute prefix sum matrix
    prefix = [[0]*(n+1) for _ in range(n+1)]
    for i in range(1, n+1):
        for j in range(1, n+1):
            prefix[i][j] = matrix[i-1][j-1] + prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1]
    
    count = 0
```
