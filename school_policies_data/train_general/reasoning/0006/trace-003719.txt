To solve this problem, we need to simulate a card game between Alice, Bob, and Charlie where each player takes turns based on the cards they draw. The goal is to determine the winner of the game when one of the players runs out of cards during their turn.

### Approach
1. **Input Reading**: Read the initial decks of Alice, Bob, and Charlie from standard input.
2. **Deck Representation**: Use deque (double-ended queue) data structures to efficiently manage the decks, allowing us to pop cards from the front efficiently.
3. **Turn Simulation**: Start with Alice and simulate each turn according to the rules:
   - Check if the current player's deck is empty. If it is, the current player wins.
   - If not, pop the top card from the current player's deck and determine the next player based on the card's letter.
4. **Termination**: The game continues until a player's deck is empty when it's their turn, at which point that player is declared the winner.

### Solution Code
```python
from collections import deque
import sys

def main():
    sa = sys.stdin.readline().strip()
    sb = sys.stdin.readline().strip()
    sc = sys.stdin.readline().strip()
    
    deck_a = deque(sa)
    deck_b = deque(sb)
    deck_c = deque(sc)
    
    current_player = 'A'
    
    while True:
        if current_player == 'A':
            if not deck_a:
                print('A')
                return
            card = deck_a.popleft()
        elif current_player == 'B':
            if not deck_b:
                print('B')
                return
            card = deck_b.popleft()
        else:
            if not deck_c:
                print('C')
                return
            card = deck_c.popleft()
        current_player = card.upper()

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of three strings representing the decks of Alice, Bob, and Charlie. These strings are read and stored in deques to allow efficient popping from the front.
2. **Simulating Turns**: The game starts with Alice. On each player's turn, we check if their deck is empty. If it is, they win. Otherwise, they draw the top card from their deck, and the next player is determined by the letter on this card.
3. **Efficient Deck Management**: Using deques ensures that popping the front element is done in constant time, which is crucial for efficient simulation of the game turns.

This approach ensures that we correctly simulate the game according to the rules and efficiently determine the winner when a player's deck is exhausted.
