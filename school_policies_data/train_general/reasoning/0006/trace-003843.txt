To solve this problem, we need to determine the maximum number of candies Om Nom can eat while alternating between two types of candies (fruit drops and caramel drops) and increasing his jump height each time he eats a candy. The solution involves simulating the process starting with each type of candy and selecting the optimal sequence of candies to maximize the count.

### Approach
1. **Problem Analysis**: Om Nom can start with either type of candy (0 or 1). Each time he eats a candy, his jump height increases by the mass of the candy. The key constraints are that he cannot eat the same type of candy consecutively and must reach the candy's height with his current jump height.
2. **Greedy Strategy**: For each starting type, we use a greedy approach to always select the available candy of the required type with the highest mass. This maximizes the increase in jump height, allowing access to more candies in subsequent steps.
3. **Simulation**: We simulate the process twice, once starting with type 0 and once starting with type 1. For each simulation, we keep track of the current jump height, the count of candies eaten, and the available candies. The maximum count from both simulations is the result.

### Solution Code
```python
n, x = map(int, input().split())
candies = [tuple(map(int, input().split())) for _ in range(n)]

max_count = 0

for start_type in [0, 1]:
    available = list(candies)
    current_jump = x
    count = 0
    current_type = start_type
    
    while True:
        # Filter candidates of the current type and within jump height
        candidates = [c for c in available if c[0] == current_type and c[1] <= current_jump]
        if not candidates:
            break
        # Select the candidate with the highest mass
        best = max(candidates, key=lambda c: c[2])
        available.remove(best)
        count += 1
        current_jump += best[2]
        current_type = 1 - current_type  # Toggle type for next step
    
    if count > max_count:
        max_count = count

print(max_count)
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of candies `n`, initial jump height `x`, and a list of tuples representing each candy's type, height, and mass.
2. **Simulation for Each Starting Type**: For both starting types (0 and 1), we simulate the process:
   - **Initialization**: Start with the initial jump height and the list of all candies.
   - **Candy Selection**: At each step, filter available candies by the current required type and height. Select the candy with the highest mass, update the jump height, and toggle the required type for the next step.
   - **Termination**: The simulation stops when no valid candy can be selected. The count of candies eaten is recorded.
3. **Result Calculation**: The maximum count from both simulations (starting with type 0 and type 1) is printed as the result.

This approach ensures that we explore both possible starting points and use a greedy strategy to maximize the number of candies eaten, leading to an optimal solution.
