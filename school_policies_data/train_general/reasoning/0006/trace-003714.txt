To solve this problem, we need to determine the number of ways to make all squares white after performing exactly N operations, where each operation inverts the colors of two chosen squares and the squares between them. Each square must be chosen exactly once. The solution involves understanding the parity of flips required and using combinatorial methods to count valid sequences of operations.

### Approach
1. **Delta Array Calculation**: Compute the parity changes between consecutive squares. This helps in determining how many times each square must be flipped.
2. **Ends Array Calculation**: Using the delta array, compute an array that tracks where intervals (pairs of squares) must end. This helps in forming valid pairs of operations.
3. **Validation Check**: Ensure the computed ends array forms a valid sequence of intervals that can cover all squares.
4. **Combination Counting**: Calculate the number of valid ways to pair starts and ends using a stack-based approach, then multiply by the factorial of N to account for the order of operations.

### Solution Code
```python
MOD = 10**9 + 7

n = int(input())
s = input().strip()

m = 2 * n

s_arr = [0] * (m + 1)
for i in range(m):
    s_arr[i + 1] = 1 if s[i] == 'B' else 0

delta = [0] * (m + 1)
for x in range(1, m + 1):
    delta[x] = (s_arr[x] - s_arr[x - 1]) % 2

ends = [0] * (m + 1)
ends[0] = 0
for x in range(1, m + 1):
    ends[x] = (1 - delta[x] - ends[x - 1]) % 2

if ends[m] != 1:
    print(0)
else:
    available = 0
    product = 1
    valid = True
    for x in range(1, m + 1):
        if ends[x] == 0:
            available += 1
        else:
            if available <= 0:
                valid = False
                break
            product = (product * available) % MOD
            available -= 1
    if not valid or available != 0:
        print(0)
    else:
        # Compute factorial of n
        fact = 1
        for i in range(1, n + 1):
            fact = fact * i % MOD
        print((product * fact) % MOD)
```
