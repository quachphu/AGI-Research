To solve this problem, we need to count the number of Hamiltonian paths in an undirected graph that start from vertex 1 and visit all vertices exactly once. A Hamiltonian path is a path that visits each vertex exactly once without any repetitions.

### Approach
1. **Graph Representation**: Represent the graph using an adjacency list where each node points to its neighbors.
2. **Permutations Generation**: Generate all permutations of the vertices starting from vertex 1. This is because the path must start at vertex 1 and visit all other vertices exactly once.
3. **Path Validation**: For each generated permutation, check if every consecutive pair of vertices in the permutation is connected by an edge in the graph. If all consecutive pairs are connected, the permutation forms a valid Hamiltonian path.

### Solution Code
```python
import sys
from itertools import permutations

def count_hamiltonian_paths():
    # Read input
    n, m = map(int, sys.stdin.readline().split())
    adj = [set() for _ in range(n + 1)]  # Using 1-based indexing

    for _ in range(m):
        a, b = map(int, sys.stdin.readline().split())
        adj[a].add(b)
        adj[b].add(a)

    # Generate all permutations starting with 1 and check each
    remaining = [i for i in range(1, n+1) if i != 1]
    count = 0

    for perm in permutations(remaining):
        path = [1] + list(perm)
        valid = True
        for i in range(len(path) - 1):
            current = path[i]
            next_node = path[i+1]
            if next_node not in adj[current]:
                valid = False
                break
        if valid:
            count += 1

    print(count)

# Execute the function
count_hamiltonian_paths()
```

### Explanation
1. **Graph Representation**: The adjacency list `adj` is built using sets to efficiently check for the existence of edges. Each node's neighbors are stored in a set to allow O(1) average-time complexity for membership checks.
2. **Permutations Generation**: Using `itertools.permutations`, we generate all possible permutations of the remaining vertices (excluding vertex 1). This ensures that each permutation starts with vertex 1.
3. **Path Validation**: For each permutation, we construct a path starting with vertex 1 followed by the permutation of the remaining vertices. We then check if each consecutive pair in the path is connected by an edge in the graph. If all consecutive pairs are connected, the permutation is valid, and we increment our count.

This approach efficiently checks all possible paths starting from vertex 1, ensuring we count all valid Hamiltonian paths in the graph. The complexity is manageable given the constraint \(2 \leq N \leq 8\), making the brute-force approach feasible.
