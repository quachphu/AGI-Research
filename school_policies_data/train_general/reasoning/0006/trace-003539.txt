To solve this problem, we need to rearrange students in a queue such that their total dissatisfaction is minimized. Each student's dissatisfaction is determined by their position in the queue and their individual characteristics. The goal is to find the optimal order of students that minimizes the total dissatisfaction.

### Approach
1. **Understanding Dissatisfaction Calculation**: Each student's dissatisfaction is given by the formula \(a_i \cdot (j-1) + b_i \cdot (n-j)\), where \(j\) is the student's position in the queue. This can be rewritten as \((a_i - b_i) \cdot j + (b_i \cdot n - a_i)\), highlighting that the key factor is the term \((a_i - b_i) \cdot j\).

2. **Optimizing the Sum**: To minimize the total dissatisfaction, we need to minimize the sum of \((a_i - b_i) \cdot j\) for all students. This is achieved by sorting the students in descending order of their \((a_i - b_i)\) values. This way, students with higher values of \((a_i - b_i)\) are placed in earlier positions, reducing the overall sum.

3. **Efficient Calculation**: After sorting, we compute the total dissatisfaction by iterating through the sorted list and calculating each student's contribution based on their position.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    idx = 1
    students = []
    for _ in range(n):
        a = int(input[idx])
        b = int(input[idx+1])
        students.append((a, b))
        idx += 2
    students.sort(key=lambda x: (x[0] - x[1]), reverse=True)
    total = 0
    for i in range(n):
        a, b = students[i]
        total += a * i + b * (n - i - 1)
    print(total)

main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints. The first value is the number of students, followed by pairs of integers representing each student's characteristics.

2. **Sorting Students**: Students are sorted in descending order based on the difference \(a_i - b_i\). This ensures that students contributing more to the dissatisfaction when placed later are positioned earlier.

3. **Calculating Total Dissatisfaction**: For each student in the sorted list, their contribution to the total dissatisfaction is calculated based on their position. The position is determined by their index in the sorted list, which allows for an efficient linear pass to compute the total.

This approach ensures that the solution is both optimal and efficient, handling up to \(10^5\) students within acceptable time limits.
