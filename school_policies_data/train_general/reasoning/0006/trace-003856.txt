To solve this problem, we need to determine if there exists a common substring between two given strings for each test case. The solution can be efficiently derived by checking if there is at least one common character between the two strings, as even a single common character implies a common substring of length 1.

### Approach
1. **Input Reading**: Read the number of test cases.
2. **Character Set Conversion**: For each test case, convert both strings into sets of characters. This helps in efficiently checking for common characters.
3. **Intersection Check**: Check if the intersection of the two character sets is non-empty. If it is, there exists at least one common substring, otherwise there does not.

This approach leverages the properties of sets in Python, which allow for efficient membership testing and intersection operations. Converting the strings to sets ensures that we only check for unique characters, making the intersection check very efficient.

### Solution Code
```python
import sys

def check_common_substring():
    t = int(sys.stdin.readline())
    for _ in range(t):
        a = sys.stdin.readline().strip()
        b = sys.stdin.readline().strip()
        set_a = set(a)
        set_b = set(b)
        if set_a & set_b:
            print("YES")
        else:
            print("NO")

check_common_substring()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency, especially given the potentially large size of the input strings.
2. **Set Conversion**: Each string is converted into a set of its characters. This step ensures that each character is considered only once, which simplifies checking for common characters.
3. **Intersection Check**: The intersection of the two sets is computed. If the intersection is non-empty, it means there is at least one common character between the two strings, resulting in "YES". Otherwise, the result is "NO".

This method efficiently handles the constraints, ensuring that even for large strings up to 100,000 characters, the solution remains optimal with a time complexity of O(n) per string for set conversion and O(1) average time for set intersection checks.
