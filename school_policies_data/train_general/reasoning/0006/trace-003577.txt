    is_prime = [True] * (n+1)

    is_prime[0] = is_prime[1] = False

    for i in range(2, int(n**0.5)+1):

        if is_prime[i]:

            for j in range(i*i, n+1, i):

                is_prime[j] = False

    primes = [i for i, val in enumerate(is_prime) if val]

    return primes

To solve this problem, we need to determine how many ways a given positive integer can be expressed as the sum of one or more consecutive prime numbers. 

### Approach
1. **Generate Primes**: Use the Sieve of Eratosthenes to generate all prime numbers up to 10,000. This is efficient and ensures we have all necessary primes for our calculations.
2. **Prefix Sum Array**: Construct a prefix sum array from the list of primes. This helps in efficiently calculating the sum of any consecutive subsequence of primes.
3. **Sliding Window with Binary Search**: For each input number, use the prefix sum array and binary search to determine how many times the number can be represented as the sum of consecutive primes. This involves checking each possible starting index and using binary search to find a valid ending index where the sum matches the target.

### Solution Code
```python
import sys
import bisect

def sieve(n):
    sieve = [True] * (n + 1)
    sieve[0] = sieve[1] = False
    for i in range(2, int(n ** 0.5) + 1):
        if sieve[i]:
            sieve[i*i : n+1 : i] = [False] * len(sieve[i*i : n+1 : i])
    primes = [i for i, is_p in enumerate(sieve) if is_p]
    return primes

def main():
    primes = sieve(10000)
    prefix = [0]
    current_sum = 0
    for p in primes:
        current_sum += p
        prefix.append(current_sum)
    
    for line in sys.stdin:
        n = int(line.strip())
        if n == 0:
            break
        count = 0
        for i in range(len(prefix)):
            target = prefix[i] + n
            j = bisect.bisect_left(prefix, target, i + 1)
            if j < len(prefix) and prefix[j] == target:
                count += 1
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prime Generation**: The Sieve of Eratosthenes efficiently generates all primes up to 10,000. This is done once at the start.
2. **Prefix Sum Array**: The prefix sum array allows us to quickly compute the sum of any subarray of primes. For example, the sum of primes from index `i` to `j` is simply `prefix[j+1] - prefix[i]`.
3. **Binary Search for Efficient Lookup**: For each starting index `i`, we compute the target sum needed to reach the input number `n` and use binary search to find if this target exists in the prefix sum array starting from `i+1`. This reduces the complexity from O(n^2) to O(n log n), making the solution efficient even for the upper constraint.

This approach ensures that we efficiently and accurately count the number of valid representations for each input number by leveraging mathematical properties and efficient algorithms.
