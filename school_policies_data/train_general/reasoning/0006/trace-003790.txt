To solve this problem, we need to determine the number of pairs of sequences whose concatenation contains an ascent. An ascent in a sequence is defined as the existence of two indices \(i\) and \(j\) such that \(i < j\) and \(a_i < a_j\).

### Approach
1. **Identify Sequences with Ascent**: For each sequence, check if it has an ascent. If it does, any concatenation involving this sequence will have an ascent.
2. **Non-Increasing Sequences**: For sequences without an ascent, they must be non-increasing. For these sequences, we need their first and last elements to determine if their concatenation with another non-increasing sequence forms an ascent.
3. **Efficient Pair Counting**: Use binary search to efficiently count valid pairs of non-increasing sequences where the last element of one sequence is less than the first element of another.

### Solution Code
```python
import bisect

def count_ascent_pairs():
    n = int(input())
    count_A = 0  # Number of sequences with ascent
    group2 = []  # Stores tuples of (first_element, last_element) for non-increasing sequences

    for _ in range(n):
        parts = list(map(int, input().split()))
        l_i = parts[0]
        s = parts[1:]
        
        if l_i == 1:
            group2.append((s[0], s[0]))
            continue
        
        is_non_increasing = True
        for i in range(l_i - 1):
            if s[i] < s[i + 1]:
                is_non_increasing = False
                break
        
        if is_non_increasing:
            group2.append((s[0], s[-1]))
        else:
            count_A += 1
    
    sorted_first = sorted([x[0] for x in group2])
    sum_third = 0
    
    for (_, last) in group2:
        pos = bisect.bisect_right(sorted_first, last)
        sum_third += len(sorted_first) - pos
    
    total = count_A * (2 * n - count_A) + sum_third
    print(total)

count_ascent_pairs()
```

### Explanation
1. **Reading Input**: The input is read and parsed into sequences. Each sequence is checked to determine if it has an ascent.
2. **Check for Ascent**: A sequence is checked for being non-increasing. If any element is found to be less than the next, it is marked as having an ascent.
3. **Handling Non-Increasing Sequences**: For sequences without an ascent, their first and last elements are stored. These elements help in determining if their concatenation with another non-increasing sequence forms an ascent.
4. **Binary Search for Efficient Counting**: The first elements of non-increasing sequences are sorted. For each sequence's last element, binary search is used to count how many other sequences' first elements are larger, ensuring efficient counting of valid pairs.

This approach efficiently handles the constraints and ensures that we count valid pairs in \(O(N \log N)\) time, where \(N\) is the number of sequences, making it suitable for large input sizes.
