To solve this problem, we need to determine if each query string matches a given glob pattern with specific rules for wildcard characters. The pattern can include '?' which matches any good letter and '*' which matches any sequence of bad letters (including an empty sequence). The solution involves checking each query string against the pattern efficiently.

### Approach
1. **Input Reading**: Read the good letters, the pattern, and the query strings.
2. **Pattern Analysis**: Split the pattern into prefix and suffix if it contains a '*'. The prefix is the part before '*' and the suffix is the part after.
3. **Query Check**:
   - **Without '*'**: Directly compare each character of the query string with the pattern. '?' must match a good letter, and other characters must match exactly.
   - **With '*'**: Ensure the query string can be divided into three parts: prefix, middle (replaced by '*'), and suffix. The prefix and suffix must match their respective parts in the pattern, and the middle part must consist only of bad letters.

                    valid = False
                    break

                    valid = False
                    break

            print("NO")

                if c != p:
                    valid = False
                    break

            continue

                    valid = False
                    break

                if c != p:
                    valid = False
                    break

            print("NO")
            continue
        # Check middle part

            if c in good:
                valid = False
                break
        print("YES" if valid else "NO")

   - For patterns with '*', the query must be long enough to accommodate both prefix and suffix. The prefix and suffix parts of the query are checked against the pattern, and the middle part (between prefix and suffix) must consist entirely of bad letters.
