To solve this problem, we need to determine if an n × m grid can be uniquely tiled with 1 × 2 dominoes such that all empty cells are covered, and no two tiles overlap. If the solution is not unique or impossible, we should output "Not unique". Otherwise, we should print the unique tiling.

### Approach
1. **Check Parity of Empty Cells**: If the number of empty cells is odd, it's impossible to tile the grid, so we immediately output "Not unique".
2. **Compute Initial Degrees**: For each empty cell, compute the number of adjacent empty cells (degree). If any cell has a degree of 0, output "Not unique" as it can't be paired.
3. **Breadth-First Search (BFS) for Forced Pairings**: Use a queue to process cells with exactly one possible neighbor (degree 1). These cells must be paired with their only neighbor, and this pairing is forced. Update the grid and adjust the degrees of neighboring cells as we process each cell.
4. **Check for Remaining Empty Cells**: If any empty cells remain after processing the queue, output "Not unique".

### Solution Code
```python
import sys
from collections import deque

def main():
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    m = int(input[idx])
    idx += 1
    grid = []
    for _ in range(n):
        row = input[idx]
        idx += 1
        grid.append(list(row))
    
    count_empty = sum(row.count('.') for row in grid)
    if count_empty % 2 != 0:
        print("Not unique")
        return
    
    # Initialize degrees matrix
    degrees = [[0]*m for _ in range(n)]
    for i in range(n):
        for j in range(m):
            if grid[i][j] == '.':
                cnt = 0
                for dx, dy in [(-1,0), (1,0), (0,-1), (0,1)]:
                    ni, nj = i + dx, j + dy
                    if 0 <= ni < n and 0 <= nj < m and grid[ni][nj] == '.':
                        cnt += 1
                degrees[i][j] = cnt
                if cnt == 0:
                    print("Not unique")
                    return
    
    q = deque()
    for i in range(n):
        for j in range(m):
            if grid[i][j] == '.' and degrees[i][j] == 1:
                q.append((i, j))
    
    while q:
        i, j = q.popleft()
        if grid[i][j] != '.':
            continue
        
        # Find the only neighbor
        neighbors = []
        for dx, dy in [(-1,0), (1,0), (0,-1), (0,1)]:
            ni, nj = i + dx, j + dy
            if 0 <= ni < n and 0 <= nj < m and grid[ni][nj] == '.':
                neighbors.append((ni, nj))
        
        if len(neighbors) != 1:
            print("Not unique")
            return
        x, y = neighbors[0]
        
        dx_dir = x - i
        dy_dir = y - j
        
        # Determine direction and update grid
        if dx_dir == 0 and dy_dir == 1:
            grid[i][j] = '<'
            grid[x][y] = '>'
        elif dx_dir == 0 and dy_dir == -1:
            grid[i][j] = '>'
            grid[x][y] = '<'
        elif dx_dir == 1 and dy_dir == 0:
            grid[i][j] = '^'
            grid[x][y] = 'v'
        elif dx_dir == -1 and dy_dir == 0:
            grid[i][j] = 'v'
            grid[x][y] = '^'
        else:
            print("Not unique")
            return
        
        # Update degrees for neighbors of (i,j) and (x,y) except each other
        processed = set()
        for a, b in [(i, j), (x, y)]:
            for dx, dy in [(-1,0), (1,0), (0,-1), (0,1)]:
                ni, nj = a + dx, b + dy
                if 0 <= ni < n and 0 <= nj < m and grid[ni][nj] == '.':
                    if (ni, nj) == (i, j) or (ni, nj) == (x, y):
                        continue
                    if (ni, nj) not in processed:
                        degrees[ni][nj] -= 1
                        processed.add((ni, nj))
                        if degrees[ni][nj] == 1:
                            q.append((ni, nj))
    
    # Check if all cells are filled
    for row in grid:
        if '.' in row:
            print("Not unique")
            return
    
    for row in grid:
        print(''.join(row))

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read and parsed into a grid structure.
2. **Initial Checks**: We check if the number of empty cells is even. If not, output "Not unique".
3. **Degree Calculation**: For each cell, compute the number of adjacent empty cells. If any cell has a degree of 0, output "Not unique".
4. **BFS Processing**: Cells with exactly one neighbor are processed first. Each such cell is paired with its only neighbor, and the grid is updated. The degrees of neighboring cells are adjusted, and any new cells with degree 1 are added to the queue.
5. **Final Check**: After processing all possible cells, if any empty cells remain, output "Not unique". Otherwise, print the tiled grid.
