To solve this problem, we need to determine the minimal possible maximum load that any mover must carry when transporting packages. The packages are split into consecutive groups, and each mover takes a group starting from the front of the remaining packages. The goal is to minimize the maximum load carried by any mover.

### Approach
The problem can be efficiently solved using dynamic programming (DP). The approach involves precomputing prefix sums to quickly calculate the sum of any subarray. We then use a DP table to keep track of the minimal maximum load for splitting the first `i` packages into `m` groups.

1. **Prefix Sum Calculation**: Compute the prefix sums of the package weights to quickly determine the sum of any subarray.
2. **Dynamic Programming Table Initialization**: Initialize a DP table where `dp[m][i]` represents the minimal maximum load when splitting the first `i` packages into `m` groups.
3. **Filling the DP Table**: For each number of movers `m` from 1 to M, and each possible number of packages `i`, compute the minimal maximum load by considering all possible splits into `m-1` groups and the remaining packages.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    M = int(input[ptr])
    ptr += 1
    P = int(input[ptr])
    ptr += 1
    weights = list(map(int, input[ptr:ptr+P]))
    ptr += P
    
    # Compute prefix sums
    prefix = [0] * (P + 1)
    for i in range(P):
        prefix[i+1] = prefix[i] + weights[i]
    
    # Initialize DP table
    dp = [[float('inf')] * (P + 1) for _ in range(M + 1)]
    for i in range(P + 1):
        dp[1][i] = prefix[i]
    
    # Fill DP table
    for m in range(2, M + 1):
        for i in range(1, P + 1):
            min_max = float('inf')
            for k in range(i):
                current_max = max(dp[m-1][k], prefix[i] - prefix[k])
                if current_max < min_max:
                    min_max = current_max
            dp[m][i] = min_max
    
    print(dp[M][P])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prefix Sum Calculation**: The prefix sum array allows us to compute the sum of any subarray in constant time. For example, the sum of packages from index `k` to `i` can be found using `prefix[i] - prefix[k]`.
2. **Dynamic Programming Table**: The DP table `dp[m][i]` is filled such that each entry represents the minimal maximum load when splitting the first `i` packages into `m` groups. For each `m` and `i`, we consider all possible previous splits (up to `i-1` packages) and compute the maximum load for the current split. The minimum of these maximum values is stored in the DP table.
3. **Iterating Over Movers and Packages**: For each number of movers `m` from 2 to M, and each possible number of packages `i`, the algorithm iterates over all possible previous splits to find the optimal split that minimizes the maximum load.

This approach ensures that we efficiently compute the minimal maximum load using dynamic programming, leveraging prefix sums for quick sum calculations and iterating through possible splits to find the optimal solution.
