To solve this problem, we need to determine the minimum number of straight cuts required to divide a pizza into exactly `n + 1` equal slices, where `n` is the number of Shiro's friends. The solution involves analyzing the structure of the problem and leveraging mathematical insights to derive the answer efficiently.

### Approach
1. **Problem Analysis**:
   - If there are no friends (n = 0), Shiro alone needs the whole pizza, which requires 0 cuts.
   - For `n` friends, we need `n + 1` slices. The key insight is that the number of cuts required depends on whether `n + 1` (let's call it `m`) is even or odd.
   - If `m` is even, we can achieve the required slices by making `m / 2` cuts through the center, each pair of cuts being diametrically opposite and spaced evenly.
   - If `m` is odd, each slice must be created by a separate cut from the center, resulting in `m` cuts.

2. **Algorithm**:
   - Read the input value `n`.
   - Compute `m` as `n + 1`.
   - Check if `m` is 1 (no cuts needed).
   - If `m` is even, the minimum cuts required are `m // 2`.
   - If `m` is odd, the minimum cuts required are `m`.

### Solution Code
```python
n = int(input())
m = n + 1
if m == 1:
    print(0)
elif m % 2 == 0:
    print(m // 2)
else:
    print(m)
```

### Explanation
- **Case 1 (m = 1)**: When there are no friends (n = 0), `m` is 1. No cuts are needed, so the output is 0.
- **Case 2 (m is even)**: When `m` is even, each cut through the center can create two slices. Thus, the number of cuts required is `m // 2`.
- **Case 3 (m is odd)**: When `m` is odd, each cut must create a single slice. Thus, the number of cuts required is `m`.

This approach efficiently determines the minimum number of cuts by leveraging the properties of even and odd numbers, ensuring optimal performance even for very large values of `n` up to \(10^{18}\).
