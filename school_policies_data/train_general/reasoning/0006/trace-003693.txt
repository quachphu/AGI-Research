To solve this problem, we need to efficiently handle two types of queries on two arrays: copying a subsegment from one array to another and querying a value in the second array. The challenge is to perform these operations efficiently given the constraints.

### Approach
1. **Segment Tree with Lazy Propagation**: We use a segment tree to keep track of the latest timestamp when each position in the second array (b) was updated by a copy operation. This allows us to quickly determine the most recent copy operation affecting a specific position.
2. **Timestamps for Copy Operations**: Each copy operation is assigned a unique timestamp. This helps in determining the order of operations and which one is the most recent.
3. **Efficient Query Handling**: For each query, we check the segment tree to find the latest timestamp affecting the queried position. If there is a copy operation, we compute the value from the source array (a) based on the parameters of that operation.

import sys

class SegmentTree:
    def __init__(self, size):
        self.n = size
        self.size = 1
        while self.size < self.n:
            self.size <<= 1
        self.max_t = [0] * (2 * self.size)
        self.lazy = [0] * (2 * self.size)
    
    def push(self, node, l, r):
        if self.lazy[node] != 0 and node < self.size:
            left = 2 * node
            right = 2 * node + 1
            self.max_t[left] = max(self.max_t[left], self.lazy[node])
            self.lazy[left] = max(self.lazy[left], self.lazy[node])
            self.max_t[right] = max(self.max_t[right], self.lazy[node])
            self.lazy[right] = max(self.lazy[right], self.lazy[node])
            self.lazy[node] = 0
    
    def range_update_max(self, a, b, val, node=1, l=0, r=None):
        if r is None:
            r = self.size - 1
        if a > r or b < l:
            return
        if a <= l and r <= b:
            if self.max_t[node] >= val:
                return
            self.max_t[node] = val
            if node < self.size:
                self.lazy[node] = max(self.lazy[node], val)
            return
        self.push(node, l, r)
        mid = (l + r) // 2
        self.range_update_max(a, b, val, 2 * node, l, mid)
        self.range_update_max(a, b, val, 2 * node + 1, mid + 1, r)
        self.max_t[node] = max(self.max_t[2 * node], self.max_t[2 * node + 1])
    
    def point_query_max(self, idx):
        node = 1
        l = 0
        r = self.size - 1
        while l < r:
            self.push(node, l, r)
            mid = (l + r) // 2
            if idx <= mid:
                node = 2 * node
                r = mid
            else:
                node = 2 * node + 1
                l = mid + 1
        return self.max_t[node]

1. **Segment Tree Initialization**: The segment tree is initialized to track the latest timestamp for each position in array b.
2. **Range Update**: Each copy operation updates the segment tree to mark the affected positions with the current timestamp.
3. **Point Query**: For each query, the segment tree is queried to find the latest timestamp affecting the queried position. The corresponding value is then computed from array a if there is a copy operation, otherwise from the original array b.

This approach ensures efficient handling of both copy and query operations, achieving the desired time complexity of O(log n) per operation.
