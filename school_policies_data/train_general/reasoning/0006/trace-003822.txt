To solve this problem, we need to determine the contiguous painted sections on a circular wall after multiple children have painted their chosen sections. The goal is to output the lengths of these contiguous sections in descending order along with their counts.

### Approach
1. **Model the Wall**: Represent the wall as a list of boolean values where each element indicates whether a section is painted.
2. **Mark Painted Sections**: For each child's painting instruction, mark the corresponding sections on the wall.
3. **Check for Fully Painted Wall**: If all sections are painted, directly return the result for a fully painted wall.
4. **Identify Contiguous Regions**: For each section, determine if it starts a new contiguous region. A new region starts if the current section is painted and the previous section is not.
5. **Calculate Region Lengths**: For each identified starting section, calculate the length of the contiguous painted region.
6. **Count and Sort**: Count the occurrences of each region length and sort them in descending order of length.

### Solution Code
```python
n, m = map(int, input().split())
painted = [False] * n

for _ in range(m):
    a, l = map(int, input().split())
    a %= n  # Ensure a is within the valid range
    for k in range(l):
        section = (a + k) % n
        painted[section] = True

if all(painted):
    print(f"{n} 1")
else:
    regions = []
    for i in range(n):
        prev = (i - 1) % n
        if painted[i] and not painted[prev]:
            current = i
            length = 0
            while painted[current]:
                length += 1
                current = (current + 1) % n
                if length >= n:
                    break
            regions.append(length)
    
    # Count frequencies
    freq = {}
    for length in regions:
        if length in freq:
            freq[length] += 1
        else:
            freq[length] = 1
    
    # Sort and output
    for length in sorted(freq.keys(), reverse=True):
        print(f"{length} {freq[length]}")
```

1. **Modeling the Wall**: The wall is represented using a list of boolean values where each index corresponds to a section. This allows efficient marking of painted sections.
2. **Marking Painted Sections**: Each child's painting instruction is processed to mark the sections they paint. This is done using modular arithmetic to handle the circular nature of the wall.
3. **Checking Fully Painted Wall**: If every section is painted, the result is immediately returned as the entire wall being a single region.
4. **Identifying Regions**: By iterating through each section and checking if it starts a new region (current section painted and previous not), we can identify all contiguous regions.
5. **Calculating Lengths**: For each region start, the length is calculated by moving forward until an unpainted section is encountered, using modular arithmetic to wrap around the wall.
