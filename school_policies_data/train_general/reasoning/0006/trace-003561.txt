To solve this problem, we need to determine the earliest time Arkady can schedule a takeoff such that there is a minimum gap of `s` minutes before and after the takeoff, without conflicting with any existing landing schedules. 

### Approach
1. **Input Parsing**: Read the number of landings `n` and the safety gap `s`. Then, read each landing time and convert it into minutes from the start of the day.
2. **Check Possible Time Slots**:
   - **Before the First Landing**: Check if there is enough time before the first landing to fit the takeoff and the required safety gap.
   - **Between Landings**: For each pair of consecutive landings, check if the gap between the end of the previous landing and the start of the next landing is sufficient to accommodate the takeoff and the safety gaps on both sides.
   - **After the Last Landing**: Determine the earliest possible time after the last landing, considering the safety gap.
3. **Determine the Earliest Time**: Among all valid candidate times, select the earliest one and convert it back to hours and minutes.

### Solution Code
```python
n, s = map(int, input().split())
landings = []
for _ in range(n):
    h, m = map(int, input().split())
    start = h * 60 + m
    end = start + 1
    landings.append((start, end))

candidates = []

# Check before the first landing
first_start = landings[0][0]
if first_start >= s + 1:
    candidates.append(0)

# Check between consecutive landings
for i in range(n - 1):
    prev_end = landings[i][1]
    next_start = landings[i+1][0]
    required_gap = 2 * s + 1
    if next_start - prev_end >= required_gap:
        candidates.append(prev_end + s)

# Check after the last landing
last_end = landings[-1][1]
candidates.append(last_end + s)

earliest = min(candidates)
h = earliest // 60
m = earliest % 60
print(h, m)
```

### Explanation
1. **Input Parsing**: The input is read and converted into a list of tuples where each tuple represents the start and end time (in minutes) of each landing.
2. **Before the First Landing**: If the first landing starts after `s + 1` minutes, the takeoff can be scheduled at time 0.
3. **Between Landings**: For each consecutive pair of landings, we check if the gap between them can accommodate the takeoff and the required safety gaps. The required gap is `2 * s + 1` minutes (s minutes before, 1 minute for the takeoff, and s minutes after).
4. **After the Last Landing**: The takeoff can be scheduled immediately after the last landing ends, considering the safety gap.
5. **Determine the Earliest Time**: The minimum time from all valid candidates is converted back to hours and minutes for the final result.

This approach ensures that we efficiently check all possible valid slots for the takeoff and select the earliest possible time while adhering to the safety constraints.
