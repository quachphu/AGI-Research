To solve this problem, we need to generate a list of numbers between two given input numbers, excluding those divisible by either 3 or 5 unless they are divisible by both. The solution involves filtering numbers based on specific divisibility conditions and formatting the output appropriately.

### Approach
1. **Input Handling**: Read two integers from standard input. These integers define the range of numbers to consider.
2. **Range Determination**: Determine the start and end of the range by sorting the input integers. This ensures the range is correctly ordered regardless of the input order.
3. **Generate Numbers**: Create a list of numbers between the start and end (exclusive of the endpoints).
4. **Filtering**: For each number in the generated list, check if it should be included. A number is included if it is either not divisible by 3 and not divisible by 5, or if it is divisible by both 3 and 5.
5. **Output Formatting**: Collect the valid numbers, convert them to strings, and join them with commas to produce the final output.

### Solution Code
```python
def main():
    a, b = map(int, input().split())
    start = min(a, b)
    end = max(a, b)
    numbers = range(start + 1, end)
    result = []
    for num in numbers:
        if (num % 3 != 0 and num % 5 != 0) or (num % 15 == 0):
            result.append(str(num))
    print(','.join(result))

main()
```

### Explanation
1. **Reading Input**: The input is read as two integers which are split and converted into the start and end of the range.
2. **Range Calculation**: Using `min` and `max`, we ensure the range is correctly ordered. The actual numbers considered are from `start + 1` to `end - 1`.
3. **Filtering Logic**: Each number is checked for inclusion. The condition `(num % 3 != 0 and num % 5 != 0)` checks if the number is not divisible by either 3 or 5. The condition `(num % 15 == 0)` checks if the number is divisible by both 3 and 5 (since 15 is the least common multiple of 3 and 5).
4. **Output**: The valid numbers are collected into a list, converted to strings, and joined with commas to form the final output string, which is then printed.

This approach efficiently filters and formats the numbers according to the given conditions, ensuring the solution is both correct and optimal.
