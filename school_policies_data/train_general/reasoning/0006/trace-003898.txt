To solve this problem, we need to determine the maximum number of problems Limak can solve during a contest before he has to leave for a New Year's Eve party. The contest starts at 20:00 and ends at midnight, giving Limak a total of 240 minutes. However, he needs to leave his house early enough to reach the party by midnight, which requires `k` minutes of travel time. 

### Approach
1. **Calculate Available Time**: Determine the total time Limak can spend solving problems by subtracting his travel time `k` from the total contest duration (240 minutes). This gives `available_time = 240 - k`.
2. **Sum Problem Solving Times**: Each problem `i` takes `5 * i` minutes to solve. We need to find the maximum number of consecutive problems starting from the first problem such that the total time spent solving these problems does not exceed `available_time`.
3. **Iterate and Accumulate**: Iterate through each problem, accumulating the time spent. If at any point the accumulated time exceeds `available_time`, stop and return the count of problems solved up to that point.

### Solution Code
```python
n, k = map(int, input().split())
total_time = 240 - k
if total_time < 0:
    print(0)
else:
    sum_time = 0
    count = 0
    for i in range(1, n + 1):
        sum_time += 5 * i
        if sum_time > total_time:
            break
        count += 1
    print(count)
```

### Explanation
1. **Input Handling**: Read the input values `n` (number of problems) and `k` (travel time in minutes).
2. **Available Time Calculation**: Compute the time available for solving problems as `total_time = 240 - k`.
3. **Edge Case Check**: If `total_time` is negative (i.e., `k` exceeds 240), Limak cannot solve any problems, so output `0`.
4. **Iterate Through Problems**: For each problem from 1 to `n`, accumulate the time spent solving each problem. If the accumulated time exceeds `total_time`, break the loop. Otherwise, increment the count of problems solved.
5. **Output Result**: Print the count of problems solved within the available time.

This approach ensures that we efficiently determine the maximum number of problems Limak can solve while still making it to the party on time. The complexity is linear, O(n), which is efficient given the problem constraints (n ≤ 10).
