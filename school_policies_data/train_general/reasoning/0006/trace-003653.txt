To solve this problem, we need to determine the number of deputies working adjacent to the President's desk in an office room. Each deputy's desk is identified by a unique color and must be adjacent to the President's desk. 

### Approach
1. **Identify the President's Desk**: The President's desk is represented by a unique color and forms a contiguous rectangular block in the office grid. We first locate all cells that belong to the President's desk.
2. **Determine the Bounding Rectangle**: Calculate the minimum and maximum row and column indices of the President's desk to form a bounding rectangle.
3. **Check Adjacent Cells**: Examine all cells surrounding the bounding rectangle (top, bottom, left, and right edges) to identify adjacent desks. Collect unique colors from these cells, excluding the President's desk color and empty cells.
4. **Count Unique Colors**: The number of unique colors found in the adjacent cells represents the number of deputies.

### Solution Code
```python
n, m, c = input().split()
n = int(n)
m = int(m)
grid = [input().strip() for _ in range(n)]

cells = []
for i in range(n):
    for j in range(m):
        if grid[i][j] == c:
            cells.append((i, j))

r1 = min(i for i, j in cells)
r2 = max(i for i, j in cells)
c1 = min(j for i, j in cells)
c2 = max(j for i, j in cells)

adjacent = set()

# Check top edge
if r1 > 0:
    row = r1 - 1
    for col in range(c1, c2 + 1):
        cell = grid[row][col]
        if cell != '.' and cell != c:
            adjacent.add(cell)

# Check bottom edge
if r2 + 1 < n:
    row = r2 + 1
    for col in range(c1, c2 + 1):
        cell = grid[row][col]
        if cell != '.' and cell != c:
            adjacent.add(cell)

# Check left edge
if c1 - 1 >= 0:
    col = c1 - 1
    for row in range(r1, r2 + 1):
        cell = grid[row][col]
        if cell != '.' and cell != c:
            adjacent.add(cell)

# Check right edge
if c2 + 1 < m:
    col = c2 + 1
    for row in range(r1, r2 + 1):
        cell = grid[row][col]
        if cell != '.' and cell != c:
            adjacent.add(cell)

print(len(adjacent))
```

### Explanation
1. **Reading Input**: The input is read and parsed into the grid dimensions, the President's desk color, and the office layout.
2. **Locating the President's Desk**: All cells matching the President's desk color are identified, and their positions are stored.
3. **Bounding Rectangle Calculation**: The minimum and maximum row and column indices of the President's desk are determined to form the bounding rectangle.
4. **Edge Checking**: The code checks cells adjacent to the top, bottom, left, and right edges of the bounding rectangle. Each valid adjacent cell's color is added to a set to ensure uniqueness.
5. **Result Calculation**: The size of the set of unique colors from adjacent cells is printed, representing the number of deputies.

This approach efficiently narrows down the cells to check by focusing on the perimeter of the President's desk, ensuring optimal performance even for larger grids.
