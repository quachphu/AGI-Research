To solve this problem, we need to efficiently handle two types of operations on a sequence of elements: adding a value to a specific element and calculating the sum of elements over a range. Given the constraints, a naive approach would be too slow, so we use a Fenwick Tree (Binary Indexed Tree) to achieve efficient point updates and range sum queries.

### Approach
1. **Fenwick Tree (BIT)**: This data structure allows us to perform point updates and prefix sum queries in O(log n) time, which is efficient enough for the given constraints (up to 100,000 elements and 100,000 queries).
2. **Point Update**: For each "add" operation, we update the Fenwick Tree at the specified index by adding the given value.
3. **Range Sum Query**: For each "getSum" operation, we compute the sum of elements from the start index to the end index using the prefix sums provided by the Fenwick Tree.

### Solution Code
```python
import sys

class FenwickTree:
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (self.n + 1)  # 1-based indexing

    def update(self, index, delta):
        while index <= self.n:
            self.tree[index] += delta
            index += index & -index

    def query(self, index):
        res = 0
        while index > 0:
            res += self.tree[index]
            index -= index & -index
        return res

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    q = int(input[ptr])
    ptr += 1
    ft = FenwickTree(n)
    for _ in range(q):
        com = int(input[ptr])
        x = int(input[ptr + 1])
        y = int(input[ptr + 2])
        ptr += 3
        if com == 0:
            ft.update(x, y)
        else:
            total = ft.query(y) - ft.query(x - 1)
            print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Fenwick Tree Initialization**: The tree is initialized with a size of `n` elements, using 1-based indexing to match the problem's element indices.
2. **Update Operation**: The `update` method adds a value to a specific index, adjusting the tree structure to maintain efficient prefix sum calculations.
3. **Query Operation**: The `query` method computes the prefix sum up to a given index. For a range sum query, we compute the difference between the prefix sum up to the end index and the prefix sum just before the start index.
4. **Input Handling**: The input is read in one go for efficiency, and each query is processed sequentially to determine the operation type (add or getSum) and execute the corresponding action using the Fenwick Tree.

This approach ensures that both update and query operations are handled in logarithmic time, making the solution efficient and scalable for large input sizes.
