To solve this problem, we need to sort a list of students based on their marks in descending order. If two students have the same marks, they should be sorted lexicographically by their names in ascending order. 

### Approach
1. **Reading Input**: Read the number of students and their respective details from the standard input.
2. **Storing Data**: Store each student's name and marks in a list of tuples.
3. **Sorting**: Sort the list of tuples using a custom key that first sorts by marks in descending order and then by names in ascending order for students with the same marks.
4. **Output**: Print the sorted list of students.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    students = []
    for _ in range(n):
        parts = sys.stdin.readline().split()
        name = parts[0]
        mark = int(parts[1])
        students.append((name, mark))
    students.sort(key=lambda x: (-x[1], x[0]))
    for student in students:
        print(f"{student[0]} {student[1]}")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency, especially with large input sizes. The first line gives the number of students, and subsequent lines provide each student's name and marks.
2. **Storing Data**: Each student's details are stored as a tuple `(name, mark)` in a list. This allows easy sorting based on multiple keys.
3. **Sorting**: The list is sorted using Python's built-in `sort` method with a custom key. The key `(-x[1], x[0])` ensures that the primary sort is by marks in descending order (achieved by negating the marks) and the secondary sort is by names in ascending order.
4. **Output**: After sorting, each student's details are printed in the required format.

This approach efficiently handles the constraints and ensures the solution is both optimal and easy to understand.
