To solve this problem, we need to determine if a given grid represents a valid Berland flag. The flag must consist of three equal-sized horizontal or vertical stripes, each of a different color (R, G, B), and each color must be used exactly once.

### Approach
1. **Check Valid Dimensions**: The grid can be divided into three equal horizontal stripes if the number of rows (n) is divisible by 3, or three equal vertical stripes if the number of columns (m) is divisible by 3. If neither dimension is divisible by 3, the flag cannot be valid.
2. **Check Horizontal Stripes**: If n is divisible by 3, divide the grid into three horizontal stripes. Each stripe must be uniformly colored, and together they must use all three colors exactly once.
3. **Check Vertical Stripes**: If m is divisible by 3, divide the grid into three vertical stripes. Similarly, each stripe must be uniformly colored, and together they must use all three colors exactly once.
4. **Validation**: For each valid division (horizontal or vertical), check if all cells in each stripe are the same color and if all three colors are used exactly once.

### Solution Code
```python
n, m = map(int, input().split())
grid = [input().strip() for _ in range(n)]

valid = False

# Check horizontal stripes
if n % 3 == 0:
    h = n // 3
    colors = []
    ok = True
    for i in range(3):
        start = i * h
        end = start + h
        color = grid[start][0]
        for row in range(start, end):
            for col in range(m):
                if grid[row][col] != color:
                    ok = False
                    break
            if not ok:
                break
        if not ok:
            break
        colors.append(color)
    if ok and set(colors) == {'R', 'G', 'B'}:
        valid = True

# Check vertical stripes if not valid yet
if not valid and m % 3 == 0:
    w = m // 3
    colors = []
    ok = True
    for i in range(3):
        start = i * w
        end = start + w
        color = grid[0][start]
        for row in range(n):
            for col in range(start, end):
                if grid[row][col] != color:
                    ok = False
                    break
            if not ok:
                break
        if not ok:
            break
        colors.append(color)
    if ok and set(colors) == {'R', 'G', 'B'}:
        valid = True

print("YES" if valid else "NO")
```

### Explanation
1. **Reading Input**: The grid dimensions and the grid itself are read from standard input.
2. **Horizontal Check**: If the number of rows (n) is divisible by 3, the grid is divided into three horizontal stripes. Each stripe is checked for uniform color, and the colors are collected. If all three colors (R, G, B) are present exactly once, the flag is valid.
3. **Vertical Check**: If the number of columns (m) is divisible by 3, the grid is divided into three vertical stripes. Similar checks for uniform color and presence of all three colors are performed.
4. **Output Result**: If either the horizontal or vertical check passes, "YES" is printed; otherwise, "NO" is printed.

This approach efficiently checks both possible orientations (horizontal and vertical) and ensures the flag meets the specified criteria using systematic checks for uniformity and color usage.
