To solve this problem, we need to compute the sum of the total costs of removing blocks in all possible orders, modulo \(10^9 + 7\). The key insight is to determine how each block contributes to the total cost across all permutations of removals.

### Approach
1. **Modular Arithmetic**: Since the result can be extremely large, all calculations are done modulo \(10^9 + 7\).
2. **Precompute Inverses**: Use modular inverses to efficiently compute harmonic numbers.
3. **Harmonic Numbers**: Compute harmonic numbers to determine the contribution of each block in the sum.
4. **Factorials**: Precompute factorials to handle permutations efficiently.
5. **Sum Contributions**: For each block, compute its contribution based on its position and the harmonic numbers.

### Solution Code
```python
MOD = 10**9 + 7

def main():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    A = list(map(int, input[1:N+1]))
    
    max_inv = N + 1
    inv = [0] * (max_inv + 2)
    inv[1] = 1
    for i in range(2, max_inv + 1):
        inv[i] = pow(i, MOD - 2, MOD)
    
    H = [0] * (max_inv + 2)
    for i in range(1, max_inv + 1):
        H[i] = (H[i-1] + inv[i]) % MOD
    
    fact = 1
    for i in range(1, N+1):
        fact = (fact * i) % MOD
    
    ans = 0
    for j in range(N):
        j_1 = j + 1
        left = H[j_1]
        m = N - j_1 + 1
        right = (H[m] - 1) % MOD
        total = (left + right) % MOD
        total = (total * fact) % MOD
        ans = (ans + A[j] * total) % MOD
    
    print(ans % MOD)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Modular Inverses**: Precompute the modular inverses of numbers up to \(N+1\) using Fermat's Little Theorem.
2. **Harmonic Numbers**: Compute the harmonic numbers using the precomputed inverses. These harmonic numbers help in determining the contribution of each block efficiently.
3. **Factorials**: Compute \(N!\) modulo \(10^9 + 7\) to handle permutations.
4. **Contribution Calculation**: For each block, compute its contribution based on its position using the precomputed harmonic numbers and factorials. Sum these contributions modulo \(10^9 + 7\).

This approach ensures that we efficiently compute the required sum without explicitly iterating through all permutations, which is infeasible for large \(N\). The use of harmonic numbers and modular arithmetic allows us to handle the large values within the constraints.
