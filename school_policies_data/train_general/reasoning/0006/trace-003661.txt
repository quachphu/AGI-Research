1. **Generate Divisors**: For each value of Z, generate all possible divisors. This is done efficiently by iterating up to the square root of Z and checking for divisibility. For each divisor found, both the divisor and its complement (Z divided by the divisor) are added to the list of divisors.
2. **Check Valid Pairs**: For each divisor, check if it can be a valid X (i.e., within [1, M]) and its corresponding Y (i.e., Z divided by the divisor) is within [1, N]. Count such valid pairs.

### Solution Code
```python
import math

def get_divisors(z):
    divisors = set()
    sqrt_z = math.isqrt(z)
    for i in range(1, sqrt_z + 1):
        if z % i == 0:
            divisors.add(i)
            divisors.add(z // i)
    return divisors

def count_valid_pairs(z, m, n):
    divisors = get_divisors(z)
    count = 0
    for d in divisors:
        if d <= m and (z // d) <= n:
            count += 1
    return count

t = int(input())
for _ in range(t):
    z, m, n = map(int, input().split())
    print(count_valid_pairs(z, m, n))
```

### Explanation
1. **Generating Divisors**: The function `get_divisors` efficiently generates all divisors of Z by iterating up to the integer square root of Z. For each number `i` that divides Z, both `i` and `Z//i` are added to the set of divisors. This ensures we capture all divisors without duplicates.
2. **Counting Valid Pairs**: For each divisor `d`, we check if `d` (as X) is within the range [1, M] and `Z//d` (as Y) is within [1, N]. If both conditions are met, the pair is counted.

This approach ensures we efficiently check all possible pairs that multiply to Z, leveraging the properties of divisors to avoid redundant checks and ensuring correctness within the problem constraints.
