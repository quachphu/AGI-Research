To solve this problem, we need to determine the number of years Ichiro would need to try all possible ways of climbing stairs, given that he tries 10 different ways each day. Each year is counted as 365 days, and even a single day over counts as a whole year.

### Approach
1. **Understanding the Problem**: Ichiro can climb up to 3 steps at a time. The number of ways to climb `n` steps can be computed using a dynamic programming approach where each step `i` can be reached from steps `i-1`, `i-2`, or `i-3`.

2. **Dynamic Programming Setup**: We precompute the number of ways to climb up to 30 steps using a dynamic programming array. The recurrence relation is:
   \[
   dp[i] = dp[i-1] + dp[i-2] + dp[i-3]
   \]
   with base cases `dp[0] = 1`, `dp[1] = 1`, and `dp[2] = 2`.

3. **Calculate Days and Years**: For each input `n`, compute the total number of ways to climb `n` steps. Convert this number into the required days (considering 10 ways per day) and then into years (considering 365 days per year).

### Solution Code
```python
def main():
    # Precompute the number of ways for each step from 0 to 30
    dp = [0] * 31
    dp[0] = 1
    for i in range(1, 31):
        dp[i] = dp[i-1]
        if i >= 2:
            dp[i] += dp[i-2]
        if i >= 3:
            dp[i] += dp[i-3]
    
    import sys
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        if n == 0:
            break
        total_ways = dp[n]
        days = (total_ways + 9) // 10  # Ceiling division for days
        years = (days + 364) // 365    # Ceiling division for years
        print(years)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Dynamic Programming Array**: We initialize an array `dp` where `dp[i]` represents the number of ways to climb `i` steps. Using the recurrence relation, we fill this array up to 30 steps.

2. **Reading Input**: The input consists of multiple integers `n` until a 0 is encountered. For each `n`, we use the precomputed `dp` array to quickly get the number of ways to climb `n` steps.

3. **Days Calculation**: Convert the total number of ways into days using ceiling division by 10. This ensures that any remaining ways (even just one) are counted as an additional day.

4. **Years Calculation**: Convert the total days into years using ceiling division by 365. This ensures that any remaining days (even just one) are counted as an additional year.

This approach efficiently computes the required values using dynamic programming and handles input processing to provide the solution in an optimal manner.
