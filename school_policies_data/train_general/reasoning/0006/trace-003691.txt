To solve this problem, we need to determine the number of good subarrays in a given array. A subarray is considered good if it does not contain any bad triples, where a bad triple is defined by three points forming a Manhattan distance condition that makes the middle point redundant.

### Approach
1. **Initial Count of Good Subarrays**: Any subarray of length 1 or 2 is automatically good. Therefore, the initial count of good subarrays is `2n - 1` where `n` is the length of the array.
2. **Check Subarrays of Length 3**: For each subarray of length 3, check if the middle element is between the first and third elements. If not, the subarray is good.
3. **Check Subarrays of Length 4**: For each subarray of length 4, check all possible triples (there are 4 such triples). If none of these triples form a bad triple, the subarray is good.

### Solution Code
```python
import sys

def count_good_subarrays():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        a = list(map(int, sys.stdin.readline().split()))
        ans = 2 * n - 1  # All subarrays of length 1 and 2
        # Check subarrays of length 3
        for i in range(n - 2):
            x, y, z = a[i], a[i+1], a[i+2]
            if not (min(x, z) <= y <= max(x, z)):
                ans += 1
        # Check subarrays of length 4
        for i in range(n - 3):
            x, y, z, w = a[i], a[i+1], a[i+2], a[i+3]
            cond1 = (min(x, z) <= y <= max(x, z))
            cond2 = (min(x, w) <= y <= max(x, w))
            cond3 = (min(x, w) <= z <= max(x, w))
            cond4 = (min(y, w) <= z <= max(y, w))
            if not (cond1 or cond2 or cond3 or cond4):
                ans += 1
        print(ans)

count_good_subarrays()
```

### Explanation
1. **Initial Count**: The initial count of good subarrays is derived from all possible subarrays of length 1 and 2, which are `n` and `n-1` respectively, summing up to `2n - 1`.
2. **Length 3 Subarrays**: For each subarray of length 3, check if the middle element lies between the first and third elements. If not, increment the count.
3. **Length 4 Subarrays**: For each subarray of length 4, check all four possible triples. If none of these triples form a bad triple, increment the count.

This approach efficiently checks all possible subarrays of lengths 3 and 4, ensuring that the solution runs in linear time relative to the input size, making it suitable for large inputs.
