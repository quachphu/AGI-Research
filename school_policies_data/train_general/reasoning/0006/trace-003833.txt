To solve this problem, we need to maximize the number of chocolates bought under the constraint that for any type `i`, if chocolates of type `j` (where `j < i`) are bought, they must be fewer than those bought of type `i`. 

### Approach
The key insight is to process the array from right to left, ensuring that each type's chocolate count is as high as possible while respecting the constraints imposed by the subsequent types. The strategy involves:
1. Starting from the last type and moving leftwards.
2. For each type, determining the maximum number of chocolates that can be bought without violating the constraints set by the subsequent types.
3. Maintaining a running total of the chocolates bought.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
prev_max = float('inf')
total = 0
for num in reversed(a):
    current = min(num, prev_max - 1)
    if current > 0:
        total += current
        prev_max = current
    else:
        prev_max = 0
print(total)
```

### Explanation
1. **Reading Input:** The input consists of the number of chocolate types and the stock of each type.
2. **Processing from Right to Left:** By starting from the last type, we ensure that each subsequent type's constraints are respected. This allows us to adjust the current type's maximum allowable chocolates based on the next type's value.
3. **Dynamic Adjustment:** For each type, we calculate the maximum chocolates that can be bought as the minimum of the current stock and one less than the previous maximum. This ensures the strictly increasing order constraint is met.
4. **Summing Up:** We accumulate the total chocolates bought, adjusting the previous maximum value as we move left through the types.

This approach efficiently processes each type in constant time, resulting in an overall time complexity of O(n), which is optimal for the given problem constraints.
