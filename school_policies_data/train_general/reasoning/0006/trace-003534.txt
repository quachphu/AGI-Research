To solve this problem, we need to determine the number of axis-aligned rectangular frames that can be placed within a triangular wall defined by the vertices (0, 0), (N, 0), and (N, N*A/B). The solution involves iterating through possible positions and calculating valid rectangles based on the constraints imposed by the triangle's hypotenuse.

### Approach
1. **Understanding the Triangle's Hypotenuse**: The hypotenuse of the triangle is defined by the line y = (A/B)x. Any rectangle placed within the triangle must have all its corners below this line.
2. **Iterate Over Possible Positions**: For each possible lower-left x-coordinate (x1) and upper-right x-coordinate (x2), calculate the maximum allowable height for rectangles starting at x1 and ending at x2.
3. **Calculate Valid Rectangles**: For each valid pair of x1 and x2, compute the maximum height (K) using integer division. The number of valid rectangles for each pair is derived from the sum of the first K natural numbers, which simplifies to K*(K+1)/2.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N = int(input[idx])
        A = int(input[idx + 1])
        B = int(input[idx + 2])
        idx += 3
        total = 0
        for x1 in range(N):
            for x2 in range(x1 + 1, N + 1):
                K = (A * x1) // B
                if K > 0:
                    total += K * (K + 1) // 2
        print(total)

main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Loop Through Test Cases**: For each test case, read the values of N, A, and B.
3. **Nested Loops for x1 and x2**: For each possible starting x-coordinate (x1), iterate through all possible ending x-coordinates (x2) greater than x1.
4. **Calculate Maximum Height (K)**: Using integer division, compute the maximum height K allowed for the current x1. This ensures the rectangle stays within the triangle.
5. **Sum Valid Rectangles**: For each valid (x1, x2) pair, if K is positive, calculate the number of valid rectangles using the formula K*(K+1)/2 and accumulate the total.

This approach efficiently checks all possible positions and sizes of rectangles, ensuring that all constraints are respected while minimizing redundant calculations.
