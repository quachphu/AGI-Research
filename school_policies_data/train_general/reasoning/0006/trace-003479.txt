To solve this problem, we need to determine the day of the week for January 1st of a given year, given that January 1, 2001 was a Monday. The solution involves calculating the number of days between the given year and the reference year (2001), adjusting for leap years, and then determining the day of the week using modular arithmetic.

### Approach
1. **Leap Year Calculation**: A year is a leap year if it is divisible by 4, but not by 100 unless it is also divisible by 400.
2. **Day Calculation**:
   - For years before 2001, calculate the total number of days from the given year up to 2000.
   - For years after 2001, calculate the total number of days from 2001 up to the year before the given year.
3. **Modulo Operation**: Use modulo 7 to determine the offset from the reference day (Monday, January 1, 2001). This offset helps in determining the day of the week for the given year.

### Solution Code
```python
import sys

def main():
    def is_leap(year):
        if year % 4 != 0:
            return False
        elif year % 100 != 0:
            return True
        else:
            return year % 400 == 0

    days = ['monday', 'tuesday', 'wednesday', 'thursday', 'friday', 'saturday', 'sunday']
    
    T = int(sys.stdin.readline())
    for _ in range(T):
        Y = int(sys.stdin.readline().strip())
        if Y == 2001:
            print("monday")
            continue
        
        if Y < 2001:
            start, end = Y, 2000
        else:
            start, end = 2001, Y - 1
        
        total_days = 0
        for year in range(start, end + 1):
            total_days += 366 if is_leap(year) else 365
        
        mod = total_days % 7
        if Y < 2001:
            day_index = (0 - mod) % 7
        else:
            day_index = mod % 7
        
        print(days[day_index])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Leap Year Check**: The function `is_leap` determines if a year is a leap year using the rules of the Gregorian calendar.
2. **Reading Input**: The number of test cases `T` is read first, followed by each year.
3. **Day Calculation**:
   - For years before 2001, the total days from the given year to 2000 are summed, considering leap years.
   - For years after 2001, the total days from 2001 to the year before the given year are summed.
4. **Modulo 7**: The total days modulo 7 gives the offset from the reference day (Monday). Adjusting this offset for direction (before or after 2001) gives the correct day of the week.

This approach efficiently computes the day of the week for any given year within the specified constraints using modular arithmetic and leap year checks.
