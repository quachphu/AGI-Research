To solve this problem, we need to determine the minimum and maximum number of times Walter could have entered the school building based on the counts provided by two guards. The guards never sleep at the same time, meaning each entry is counted by at least one guard.

### Approach
1. **Understanding the Problem**: 
   - The guards' counts (A and B) are the number of times each guard saw Walter enter. Since they never sleep simultaneously, each entry is counted by at least one guard.
   - The minimum number of entries is determined by the maximum of the two guards' counts. This is because the actual number of entries must be at least as large as the higher count (since the higher count must be entirely included in the actual entries).
   - The maximum number of entries is the sum of both counts. This occurs when the guards' counts do not overlap, meaning each entry was counted by only one guard.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        A = int(input[idx])
        B = int(input[idx + 1])
        idx += 2
        min_val = max(A, B)
        max_val = A + B
        print(f"{min_val} {max_val}")

main()
```

### Explanation
- **Reading Input**: The input is read all at once and split into tokens for efficient processing.
- **Processing Each Test Case**: For each test case, we read the counts A and B.
- **Calculating Minimum and Maximum Entries**:
  - **Minimum Entries**: The maximum of A and B. This is because the actual entries must cover the higher count entirely.
  - **Maximum Entries**: The sum of A and B. This is the scenario where the counts do not overlap, meaning each entry was counted by only one guard.

This approach efficiently computes the required values using simple arithmetic operations, ensuring optimal performance even for the upper constraint limits.
