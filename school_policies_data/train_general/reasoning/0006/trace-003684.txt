To solve this problem, we need to divide a sorted array into k non-empty consecutive subarrays such that the sum of the differences between the maximum and minimum values of each subarray is minimized. 

### Approach
1. **Initial Cost Calculation**: The initial cost when the array is considered as a single subarray is the difference between the last and the first element of the array.
2. **Consecutive Differences**: Calculate the differences between each consecutive pair of elements in the array. These differences represent the potential reduction in cost if a split is made between those elements.
3. **Optimal Splits**: To minimize the total cost, we should make splits at the largest consecutive differences. This is because each split reduces the total cost by the value of the consecutive difference at the split point.
4. **Sum of Largest Differences**: Sum the largest (k-1) consecutive differences and subtract this sum from the initial cost to get the minimum possible cost.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))

initial = a[-1] - a[0]

if k == 1:
    print(initial)
else:
    diffs = [a[i+1] - a[i] for i in range(n-1)]
    diffs.sort(reverse=True)
    sum_sub = sum(diffs[:k-1])
    print(initial - sum_sub)
```

### Explanation
1. **Initial Cost**: The initial cost is calculated as the difference between the maximum and minimum values of the entire array, which is `a[-1] - a[0]`.
2. **Consecutive Differences**: By computing the differences between each consecutive element in the sorted array, we identify potential points where splits can reduce the total cost.
3. **Sorting and Summing Differences**: Sorting these differences in descending order allows us to select the largest (k-1) differences. Summing these values gives the maximum possible reduction in cost.
4. **Final Cost Calculation**: Subtracting the sum of the largest (k-1) differences from the initial cost yields the minimum possible cost after optimal splits.

This approach efficiently leverages the sorted nature of the array and the properties of consecutive differences to find the optimal solution in O(n log n) time complexity, which is suitable for large input sizes up to 300,000 elements.
