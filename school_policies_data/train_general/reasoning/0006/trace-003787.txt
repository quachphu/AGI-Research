To solve this problem, we need to select up to three problems from a given list such that their cumulative "prettiness" is maximized, while ensuring that no problem's prettiness divides another's. The solution involves efficiently checking combinations of the top elements after deduplication and sorting.

### Approach
1. **Deduplication and Sorting**: For each query, first deduplicate the list of prettiness values and sort them in descending order. This helps in focusing on the largest values which are more likely to contribute to the maximum sum.
2. **Candidate Selection**: Limit the candidates to the top 100 elements after deduplication and sorting. This is based on the intuition that the maximum sum is likely to be found among the largest values.
3. **Combination Checks**: Check all possible combinations of 1, 2, and 3 elements from these candidates. For each combination, verify the divisibility constraints to ensure no element divides another.
4. **Max Sum Calculation**: Track the maximum sum from valid combinations and output the result for each query.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    q = int(input[ptr])
    ptr += 1
    results = []
    for _ in range(q):
        n = int(input[ptr])
        ptr += 1
        a = list(map(int, input[ptr:ptr + n]))
        ptr += n
        # Deduplicate and sort descending
        a = sorted(list(set(a)), reverse=True)
        # Take up to 100 elements
        candidates = a[:100]
        max_sum = 0
        # Check single element
        if candidates:
            max_sum = candidates[0]
        # Check pairs
        len_cand = len(candidates)
        for i in range(len_cand):
            for j in range(i + 1, len_cand):
                if candidates[i] % candidates[j] != 0:
                    current = candidates[i] + candidates[j]
                    if current > max_sum:
                        max_sum = current
        # Check triplets
        for i in range(len_cand):
            for j in range(i + 1, len_cand):
                if candidates[i] % candidates[j] == 0:
                    continue
                for k in range(j + 1, len_cand):
                    if candidates[j] % candidates[k] != 0 and candidates[i] % candidates[k] != 0:
                        current = candidates[i] + candidates[j] + candidates[k]
                        if current > max_sum:
                            max_sum = current
        results.append(max_sum)
    
    sys.stdout.write('\n'.join(map(str, results)) + '\n')

if __name__ == "__main__":
    main()
```

2. **Candidate Selection**: Limiting to the top 100 elements reduces the number of combinations to check, making the solution feasible even for large input sizes.
3. **Combination Checks**: For each possible combination of 1, 2, or 3 elements, we check the divisibility constraints. This ensures that no element in the combination divides another, which is crucial for meeting the problem's requirements.
4. **Efficiency**: By focusing on the top candidates and limiting the number of combinations checked, the solution efficiently narrows down potential maximum sums while adhering to constraints.

This approach balances thoroughness with efficiency, ensuring that the solution handles large input sizes within acceptable time limits.
