To solve this problem, we need to efficiently convert a ternary number (base 3) into its decimal equivalent and repeatedly sum its digits until a single digit is obtained. This single digit is known as the digital root. Given the constraints, directly converting large ternary numbers to decimal is impractical, so we use mathematical properties to optimize the solution.

### Approach
1. **Digital Root Insight**: The digital root of a number can be found using modulo 9 operations. Specifically, the digital root of a non-zero number `n` is `n % 9` if `n % 9 != 0`, otherwise it is 9. If `n` is zero, the digital root is 0.
2. **Efficient Conversion**: Instead of converting the entire ternary number to decimal, we compute its value modulo 9. This is feasible because each digit's contribution to the modulo result can be computed incrementally.
3. **Handling Zeros**: If the input ternary number consists entirely of zeros, the result is 0. Otherwise, we compute the modulo 9 of the ternary number's decimal value and apply the digital root rules.

### Solution Code
```python
t = int(input())
for _ in range(t):
    s = input().strip()
    if all(c == '0' for c in s):
        print(0)
    else:
        mod = 0
        for c in s:
            mod = (mod * 3 + int(c)) % 9
        print(9 if mod == 0 else mod)
```

### Explanation
1. **Reading Input**: The number of test cases `t` is read first. Each subsequent line contains a ternary number.
2. **Check for Zero**: If the ternary number is composed entirely of zeros, the result is immediately 0.
3. **Modulo Calculation**: For non-zero ternary numbers, each digit is processed from left to right. The current modulo value is updated by multiplying by 3 (to shift left in base 3) and adding the current digit, then taking modulo 9.
4. **Digital Root Determination**: If the resulting modulo value is 0 (and the number is non-zero), the digital root is 9. Otherwise, the modulo value itself is the digital root.

This approach efficiently handles very large numbers by leveraging modular arithmetic, ensuring the solution is both optimal and scalable.
