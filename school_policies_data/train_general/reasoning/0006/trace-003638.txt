To solve this problem, we need to determine if it is possible to reduce two integers \(a\) and \(b\) to zero simultaneously using a series of operations where each operation allows subtracting \(x\) from one integer and \(2x\) from the other. 

### Approach
The solution involves checking two key conditions for each pair of integers \(a\) and \(b\):
1. The sum of \(a\) and \(b\) must be divisible by 3. This is because each operation reduces the sum of \(a\) and \(b\) by \(3x\), so their initial sum must be a multiple of 3.
2. Neither \(a\) nor \(b\) should be more than twice the other. This ensures that the integers can be reduced to zero without one becoming negative before the other.

### Solution Code
```python
t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    if (a + b) % 3 != 0:
        print("NO")
    else:
        if a > 2 * b or b > 2 * a:
            print("NO")
        else:
            print("YES")
```

### Explanation
1. **Divisibility Check**: The sum of \(a\) and \(b\) must be divisible by 3. This ensures that we can distribute the reductions evenly over the operations.
2. **Proportional Check**: Each integer must not exceed twice the other. This ensures that we can always find valid operations to reduce both integers to zero without one becoming negative prematurely.

By verifying these two conditions for each test case, we can efficiently determine if it is possible to reduce both integers to zero. The solution runs in \(O(1)\) time per test case, making it very efficient even for large input sizes.
