To solve this problem, we need to find a non-empty subset of integers from each test case such that their sum is zero. The constraints given ensure that such a subset always exists. 

### Approach
1. **Understanding the Constraints**: Each integer \( a_i \) in the input array is constrained such that \( i - n \leq a_i \leq i - 1 \). This can be transformed into another array \( d \) where \( d_i = i - a_i \). Each element in \( d \) will be between 1 and \( n \), inclusive.
2. **Cycle Detection**: The array \( d \) can be treated as a directed graph where each node points to another node. By finding a cycle in this graph, we can ensure that the sum of the corresponding elements in the original array is zero. This is because the sum of the elements in a cycle in the transformed array \( d \) will always be zero.
