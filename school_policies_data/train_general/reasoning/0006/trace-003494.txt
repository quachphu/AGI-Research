To solve this problem, we need to determine the maximum number of gift sets Polycarp can create using his red and blue candies. Each gift set can be of two types: either `a` red candies and `b` blue candies, or `b` red candies and `a` blue candies. The solution involves a systematic approach to explore all possible numbers of gift sets efficiently using binary search.

### Approach
1. **Special Case Handling**: If `a` equals `b`, each gift set uses exactly `a` red and `a` blue candies. The maximum number of such gift sets is simply the minimum of the red and blue candies divided by `a`.
2. **Binary Search**: For cases where `a` is not equal to `b`, we use binary search to determine the maximum number of gift sets. The upper bound for the binary search is derived from the total number of candies divided by the sum of `a` and `b`.
3. **Feasibility Check**: For each candidate number of gift sets `k` during the binary search, we check if there exists a valid distribution of `k` gift sets into two types such that the constraints on red and blue candies are satisfied. This involves calculating feasible ranges for the number of gift sets of each type and ensuring these ranges overlap.
