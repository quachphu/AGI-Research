To solve this problem, we need to determine the number of valid integer pairs (a, b) such that both a and b are non-negative and satisfy the given system of equations:

1. \( a^2 + b = n \)
2. \( a + b^2 = m \)

### Approach
The approach involves iterating through possible values of `a` and computing the corresponding `b` from the first equation. We then check if this pair (a, b) satisfies the second equation. 

1. **Iterate through possible values of `a`:** Since `a` must be non-negative and \( a^2 \) must be less than or equal to `n`, the maximum value for `a` is the integer part of the square root of `n`.
2. **Compute `b` for each `a`:** Using the first equation \( b = n - a^2 \), we compute `b` and check if it is non-negative.
3. **Check the second equation:** For each valid pair (a, b), check if \( a + b^2 = m \). If it holds, increment the count.

This approach ensures that we efficiently check all possible pairs within the constraints.

### Solution Code
```python
n, m = map(int, input().split())
count = 0
max_a = int(n**0.5)
for a in range(max_a + 1):
    b = n - a * a
    if b < 0:
        continue
    if a + b * b == m:
        count += 1
print(count)
```

### Explanation
1. **Reading Input:** The input values `n` and `m` are read from standard input.
2. **Initialization:** We initialize a counter `count` to zero to keep track of valid pairs.
3. **Iterate Over Possible Values of `a`:** The loop runs from 0 to the integer part of the square root of `n` (inclusive), ensuring we cover all possible non-negative values of `a` that could satisfy the first equation.
4. **Compute `b`:** For each `a`, compute `b` using the first equation. If `b` is negative, skip to the next iteration.
5. **Check Validity:** Check if the computed pair (a, b) satisfies the second equation. If it does, increment the counter.
6. **Output Result:** Print the count of valid pairs.

This method efficiently narrows down the possible values of `a` and `b` using the constraints given by the equations, ensuring we only check feasible pairs and thus optimizing the solution.
