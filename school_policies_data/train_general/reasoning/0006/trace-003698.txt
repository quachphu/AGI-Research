To solve this problem, we need to determine the minimum number of initial rap battles that uniquely define the order of robots by their skill levels. The solution involves checking after each rap battle if the order can be uniquely determined using a directed acyclic graph (DAG) and topological sorting.

### Approach
1. **Problem Analysis**: The problem requires us to find the earliest point where the results of rap battles form a DAG that has a unique topological order. This is equivalent to checking if at every step of the topological sort, there is exactly one node with zero in-degree.

2. **Key Insight**: A DAG has a unique topological order if and only if at each step of the topological sort, there is exactly one node with zero in-degree. This can be efficiently checked using a modified version of Kahn's algorithm.

3. **Binary Search**: To efficiently find the minimum number of initial rap battles, we use binary search on the number of battles. For each midpoint in the binary search, we check if the first `mid` battles form a DAG with a unique topological order.

4. **Modified Kahn's Algorithm**: This algorithm checks for the uniqueness of the topological order by ensuring that at each step, there is exactly one node with zero in-degree.

### Solution Code
```python
import sys
from collections import deque

def main():
    n, m = map(int, sys.stdin.readline().split())
    edges = [tuple(map(int, sys.stdin.readline().split())) for _ in range(m)]
    
    def is_valid(k):
        adj = [[] for _ in range(n + 1)]
        in_degree = [0] * (n + 1)
        for i in range(k):
            u, v = edges[i]
            adj[u].append(v)
            in_degree[v] += 1
        
        q = deque()
        for node in range(1, n + 1):
            if in_degree[node] == 0:
                q.append(node)
        
        if len(q) != 1:
            return False
        
        count = 0
        while q:
            if len(q) != 1:
                return False
            u = q.popleft()
            count += 1
            for v in adj[u]:
                in_degree[v] -= 1
                if in_degree[v] == 0:
                    q.append(v)
        
        return count == n
    
    low = 1
    high = m
    ans = -1
    while low <= high:
        mid = (low + high) // 2
        if is_valid(mid):
            ans = mid
            high = mid - 1
        else:
            low = mid + 1
    
    print(ans if ans != -1 else -1)

if __name__ == "__main__":
    main()
```
