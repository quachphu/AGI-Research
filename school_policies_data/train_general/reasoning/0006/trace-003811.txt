To solve this problem, we need to minimize the total cost of buying marbles when distributing the purchases among K friends. Each friend's cost for a marble increases with each subsequent purchase they make. The key insight is to strategically assign the marbles to minimize the total cost by leveraging the multiplier effect efficiently.

### Approach
1. **Sort the Marbles by Cost**: The marbles should be sorted in descending order of their cost. This ensures that the most expensive marbles are considered first, which helps in minimizing the impact of the increasing multiplier.
2. **Distribute Marbles in Batches**: Assign the marbles to K friends in batches. The first K marbles (sorted in descending order) are each assigned to a different friend as their first purchase. The next K marbles are assigned as their second purchase, and so on. This way, each friend's multiplier increases in a controlled manner.
3. **Calculate the Multiplier**: For each marble, the multiplier is determined by the batch it belongs to. The first batch (first K marbles) has a multiplier of 1, the next batch (next K marbles) has a multiplier of 2, etc. This can be computed using integer division of the marble's index by K, then adding 1.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    k = int(input[1])
    c = list(map(int, input[2:2+n]))
    c.sort(reverse=True)
    total = 0
    for i in range(n):
        total += c[i] * (i // k + 1)
    print(total)

main()
```

### Explanation
1. **Reading Input**: The input is read and parsed to extract the number of marbles (N), the number of friends (K), and the list of marble costs.
2. **Sorting**: The list of marble costs is sorted in descending order to prioritize the most expensive marbles.
3. **Calculating Total Cost**: Iterate through each marble, compute its multiplier based on its position (index divided by K), and accumulate the total cost by multiplying each marble's cost with its respective multiplier.
4. **Output the Result**: The accumulated total cost is printed as the result.

This approach ensures that the most expensive marbles are assigned the smallest possible multipliers, thereby minimizing the total cost efficiently. The complexity is dominated by the sorting step, making it O(N log N), which is efficient given the problem constraints.
