class FenwickTree:

    def __init__(self, size):

        self.size = size

        self.tree = [0]*(size + 1)

    def update(self, index, delta):

        # index is 1-based

        while index <= self.size:

            self.tree[index] += delta

            index += index & -index

    def query(self, index):

        # returns sum from 1 to index (inclusive)

        res = 0

        while index > 0:

            res += self.tree[index]

            index -= index & -index

        return res

To solve this problem, we need to determine the number of contiguous subarrays in a given sequence whose arithmetic mean is at least a specified integer \( K \). The solution involves transforming the problem into a sum-based problem using prefix sums and efficiently counting valid subarrays using a Fenwick Tree (Binary Indexed Tree) for coordinate compression.

### Approach
1. **Transform the Problem**: Convert each element \( a_i \) in the input array to \( b_i = a_i - K \). This transforms the problem into finding subarrays where the sum of \( b_i \) values is non-negative.
2. **Prefix Sum Calculation**: Compute the prefix sums of the transformed array. The sum of a subarray from index \( l \) to \( r \) can be derived from the prefix sums.
3. **Coordinate Compression**: Since the prefix sums can be very large, compress these values into a smaller range using sorting and deduplication.
4. **Efficient Counting with Fenwick Tree**: Use a Fenwick Tree to efficiently count the number of valid subarrays by maintaining and querying prefix sums dynamically.

### Solution Code
```python
import bisect

class FenwickTree:
    def __init__(self, size):
        self.size = size
        self.tree = [0] * (self.size + 1)  # 1-based indexing

    def update(self, index, delta):
        # Update the frequency at 'index' by delta
        while index <= self.size:
            self.tree[index] += delta
            index += index & -index

    def query(self, index):
        # Return the sum from 1 to 'index'
        res = 0
        while index > 0:
            res += self.tree[index]
            index -= index & -index
        return res

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    K = int(input[ptr])
    ptr += 1
    a = []
    for _ in range(N):
        a.append(int(input[ptr]))
        ptr += 1

    # Compute transformed array b
    b = [num - K for num in a]

    # Compute prefix sums
    prefix_sum = [0] * (N + 1)
    for i in range(1, N + 1):
        prefix_sum[i] = prefix_sum[i - 1] + b[i - 1]

    # Collect all prefix sums for coordinate compression
    s_list = prefix_sum
    sorted_unique = sorted(list(set(s_list)))
    sorted_unique.sort()

    # Initialize Fenwick Tree
    size_ft = len(sorted_unique)
    ft = FenwickTree(size_ft)

    total = 0

    # Insert prefix_sum[0] into Fenwick Tree
    x = prefix_sum[0]
    idx = bisect.bisect_left(sorted_unique, x)
    rank = idx + 1
    ft.update(rank, 1)

    for r in range(1, N + 1):
        x = prefix_sum[r]
        # Find how many elements <= x in the current Fenwick Tree (prefix_sum[0..r-1])
        idx = bisect.bisect_left(sorted_unique, x)
        cnt = ft.query(idx + 1)
        total += cnt

        # Insert current x (prefix_sum[r]) into Fenwick Tree
        idx_insert = bisect.bisect_left(sorted_unique, x)
        rank_insert = idx_insert + 1
        ft.update(rank_insert, 1)

    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Transformation**: By converting each element \( a_i \) to \( b_i = a_i - K \), we transform the problem into finding subarrays where the sum of \( b_i \) values is non-negative.
2. **Prefix Sums**: The prefix sums array helps in quickly calculating the sum of any subarray. For a subarray from index \( l \) to \( r \), the sum is given by \( \text{prefix_sum}[r] - \text{prefix_sum}[l-1] \).
3. **Coordinate Compression**: This step reduces the range of prefix sums to a manageable size, allowing efficient use of the Fenwick Tree.
4. **Fenwick Tree Operations**: The Fenwick Tree is used to maintain the counts of prefix sums dynamically. For each new prefix sum, we query the tree to count how many previous sums are less than or equal to the current sum, which gives the number of valid subarrays ending at the current index.

This approach efficiently handles the constraints, ensuring the solution runs in \( O(N \log N) \) time complexity.
