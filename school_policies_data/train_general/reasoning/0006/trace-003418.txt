To solve this problem, we need to sort a given set of cards using both Bubble Sort and Selection Sort algorithms and determine the stability of each sorting method. Stability here means that cards with the same value maintain their relative order from the input.

### Approach
1. **Reading Input**: The input consists of the number of cards and the cards themselves.
2. **Bubble Sort**: This algorithm sorts by repeatedly swapping adjacent elements if they are in the wrong order. It is inherently stable because it does not change the relative order of equal elements.
3. **Selection Sort**: This algorithm sorts by repeatedly finding the minimum element and swapping it with the current element. It is generally unstable because it can change the relative order of equal elements.
4. **Stability Check**: After sorting, we check if the sorted list maintains the relative order of cards with the same value as they appeared in the input. This is done by tracking the original indices of each card and ensuring they are in non-decreasing order for each group of cards with the same value.

### Solution Code
```python
n = int(input())
cards = input().split()

original = [(card, idx) for idx, card in enumerate(cards)]

# Bubble Sort
bubble = original.copy()
for i in range(n):
    for j in range(n-1, i, -1):
        current_val = int(bubble[j][0][1:])
        prev_val = int(bubble[j-1][0][1:])
        if current_val < prev_val:
            bubble[j], bubble[j-1] = bubble[j-1], bubble[j]

# Selection Sort
selection = original.copy()
for i in range(n):
    mini = i
    for j in range(i, n):
        current_val = int(selection[j][0][1:])
        min_val = int(selection[mini][0][1:])
        if current_val < min_val:
            mini = j
    selection[i], selection[mini] = selection[mini], selection[i]

def is_stable(sorted_tuples):
    groups = {}
    for card, original_idx in sorted_tuples:
        val = int(card[1:])
        if val not in groups:
            groups[val] = []
        groups[val].append(original_idx)
    for val in groups:
        indices = groups[val]
        for i in range(len(indices)-1):
            if indices[i] > indices[i+1]:
                return False
    return True

bubble_sorted = [t[0] for t in bubble]
selection_sorted = [t[0] for t in selection]
bubble_stable = is_stable(bubble)
selection_stable = is_stable(selection)

print(' '.join(bubble_sorted))
print('Stable' if bubble_stable else 'Not stable')
print(' '.join(selection_sorted))
print('Stable' if selection_stable else 'Not stable')
```

### Explanation
1. **Reading Input**: The input is read and stored as a list of cards along with their original indices.
2. **Bubble Sort Implementation**: The algorithm iterates through the list, comparing adjacent elements and swapping them if they are in the wrong order. This process is repeated until the list is sorted.
3. **Selection Sort Implementation**: The algorithm repeatedly selects the minimum element from the unsorted portion and swaps it with the first unsorted element. This process continues until the entire list is sorted.
4. **Stability Check**: After sorting, we check the stability by grouping elements by their values and ensuring that the original indices of each group are in non-decreasing order. If any group fails this check, the sort is deemed unstable.

This approach ensures that we correctly implement both sorting algorithms and accurately determine their stability based on the original input order.
