To solve this problem, we need to determine the minimum number of sticks required to form a given length, where each stick's length is a power of 2. The key insight here is that the binary representation of the target length directly gives us the solution.

### Approach
1. **Problem Analysis**: The problem can be reduced to finding the number of distinct powers of 2 that sum up to the given target length. Each power of 2 corresponds to a bit in the binary representation of the target length. For example, the binary representation of 5 is `101`, which has two 1s, corresponding to the powers 4 (2^2) and 1 (2^0), thus requiring two sticks.
2. **Key Insight**: The number of 1s in the binary representation of the target length directly gives the minimum number of sticks needed. This is because each 1 in the binary string represents a distinct power of 2 that must be used to sum up to the target length.
3. **Algorithm**: Convert the input number to its binary representation and count the number of 1s in this binary string.

### Solution Code
```python
n = int(input())
print(bin(n).count('1'))
```

### Explanation
1. **Reading Input**: The input is read as an integer.
2. **Binary Conversion**: The integer is converted to its binary string representation using `bin()`, which includes a prefix `0b`.
3. **Counting 1s**: The `count('1')` method is used on the binary string to count the number of 1s, which corresponds to the number of sticks needed.

This approach efficiently computes the result with a time complexity of O(log n), as converting a number to its binary representation and counting characters both operate in linear time relative to the number of bits. This is optimal for the given problem constraints.
