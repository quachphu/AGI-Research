To solve this problem, we need to determine the maximum points a player can achieve in the game of Berland poker by optimally distributing jokers among players. The points are calculated as the difference between the number of jokers the winner has and the maximum number of jokers any other player has.

### Approach
1. **Understand the Distribution**: Each player gets exactly `n/k` cards. The goal is to maximize the points by distributing jokers such that one player has the maximum possible jokers, and the remaining jokers are distributed in a way that minimizes the maximum jokers among other players.
2. **Constraints Check**: For each test case, compute the maximum possible jokers a player can have (`max_x`) as the minimum of `m` (total jokers) and `n/k` (cards per player).
3. **Iterate and Validate**: Check each possible value of `max_x` from the highest possible down to 1. For each value, ensure the remaining jokers can be distributed among other players such that their maximum jokers do not exceed `max_x - 1`.
4. **Calculate Points**: If a valid distribution is found, compute the points as the difference between the winner's jokers and the maximum jokers among other players.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, m, k = map(int, input().split())
    per = n // k
    max_x = min(m, per)
    best = 0
    for x in range(max_x, 0, -1):
        rem = m - x
        if rem < 0:
            continue
        if rem <= (k - 1) * (x - 1):
            # Calculate y as ceil(rem / (k-1))
            if k - 1 == 0:
                y = 0
            else:
                y = (rem + (k - 2)) // (k - 1)
            best = x - y
            break
    print(best)
```

### Explanation
1. **Reading Input**: The input consists of multiple test cases. For each test case, we read the values of `n`, `m`, and `k`.
2. **Calculate Cards per Player**: Each player gets `n/k` cards, denoted as `per`.
3. **Determine Maximum Jokers**: The maximum jokers a player can have (`max_x`) is the minimum of `m` and `per`.
4. **Check Valid Distributions**: For each possible value of `max_x` from the highest down to 1, check if the remaining jokers can be distributed such that no other player exceeds `max_x - 1` jokers.
5. **Calculate Points**: If a valid distribution is found, compute the points using the difference between the winner's jokers and the maximum jokers among others. If no valid distribution is found, the result is 0.

This approach efficiently checks all possible distributions to determine the optimal points a player can achieve, ensuring correctness and optimality within the constraints.
