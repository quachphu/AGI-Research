To solve this problem, we need to find the maximum weight of numbers in a given range [l, r], where the weight of a number n is defined as the product of n and its reflection. The reflection of a number n is obtained by replacing each digit a in n with (9 - a), ensuring that leading zeros are omitted.

### Approach
1. **Understanding Reflection**: The reflection of a number n can be computed as (10^d - 1 - n), where d is the number of digits in n. This is because the reflection of a d-digit number n is the difference between the largest d-digit number (all 9s) and n itself.
2. **Optimal Number Insight**: The product of a number and its reflection (n * (10^d - 1 - n)) is a quadratic function that reaches its maximum when n is close to half of the largest d-digit number. For a d-digit number, this midpoint is around (10^d - 1) / 2.
3. **Candidates Generation**: To efficiently find the maximum weight without iterating through all numbers in the range, generate potential candidates:
   - The boundaries of the range (l and r).
   - Midpoints around (10^d - 1) / 2 for each relevant digit length d within the range [l, r].

```python
l, r = map(int, input().split())

candidates = {l, r}

for d in range(1, 11):
    start = 10 ** (d - 1)
    end = (10 ** d) - 1
    if start > r or end < l:
        continue
    M = end
    c1 = (M - 1) // 2
    c2 = (M + 1) // 2
    if l <= c1 <= r:
        candidates.add(c1)
    if l <= c2 <= r:
        candidates.add(c2)

max_product = 0
for n in candidates:
    d = len(str(n))
    M = (10 ** d) - 1
    reflection = M - n
    product = n * reflection
    if product > max_product:
        max_product = product

print(max_product)
```

### Explanation
1. **Reading Input**: The input consists of two integers l and r, representing the range boundaries.
2. **Generating Candidates**: We consider numbers at the boundaries (l and r) and midpoints for each digit length d. For each d, the midpoints are calculated as (10^d - 1) / 2 and (10^d + 1) / 2, which are potential candidates for maximum weight.
3. **Computing Maximum Weight**: For each candidate, compute its reflection and the corresponding weight. The maximum weight among all candidates is determined and printed.

This approach efficiently narrows down the potential candidates, ensuring we check a manageable number of points while still guaranteeing that we find the maximum weight within the given range.
