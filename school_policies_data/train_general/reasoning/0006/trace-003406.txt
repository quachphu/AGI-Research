To solve this problem, we need to determine if a given integer \( N \) can be represented as the product of two integers, each between 1 and 9 inclusive. If such a pair exists, we print "Yes"; otherwise, we print "No".

### Approach
The approach involves checking all possible pairs of integers between 1 and 9 to see if their product equals \( N \). Since the range of possible values is small (1 to 9 for both integers), we can efficiently check each pair using nested loops. This brute-force method is feasible due to the limited range and ensures that we cover all possible products.

### Solution Code
```python
n = int(input())
if any(i * j == n for i in range(1, 10) for j in range(1, 10)):
    print("Yes")
else:
    print("No")
```

### Explanation
1. **Reading Input**: The input integer \( N \) is read from standard input.
2. **Checking Pairs**: Using a generator expression with the `any` function, we check all pairs (i, j) where both i and j range from 1 to 9. The `any` function efficiently stops checking as soon as it finds a pair whose product equals \( N \).
3. **Output Result**: If such a pair is found, "Yes" is printed; otherwise, "No" is printed.

This method ensures that we check all possible products efficiently and correctly, leveraging Python's concise syntax and built-in functions for clarity and brevity.
