def grundy(s):

### Approach
1. **Grundy Numbers**: In combinatorial game theory, the Grundy number (or nimber) of a game state determines the winning strategy. For each pile of stones, the Grundy number is calculated based on the maximum number of distinct moves possible, where each move removes a unique number of stones from the pile.
2. **Grundy Number Calculation**: For a pile with `s` stones, the Grundy number is the largest integer `k` such that the sum of the first `k` natural numbers (i.e., `k*(k+1)/2`) is less than or equal to `s`. This is derived from the quadratic formula and verified using a loop to ensure accuracy.
3. **XOR Sum**: The result of XORing all Grundy numbers of the piles determines the winner. If the XOR sum is zero, Jon (the second player) wins; otherwise, Sam (the first player) wins.

### Solution Code

```python
import sys
import math

def grundy(s):
    k = int((math.sqrt(8 * s + 1) - 1) // 2)
    # Verify and adjust for potential floating-point inaccuracies
    while (k + 1) * (k + 2) // 2 <= s:
        k += 1
    return k

n = int(sys.stdin.readline())
xor_sum = 0
for _ in range(n):
    s = int(sys.stdin.readline())
    xor_sum ^= grundy(s)
print("YES" if xor_sum == 0 else "NO")
```
