To solve this problem, we need to determine the last remaining node in a circular linked list after repeatedly removing every K-th node. The solution involves simulating the process of node removal using a linked list structure to adhere to the problem constraints.

### Approach
1. **Linked List Construction**: Create a circular linked list with nodes numbered from 1 to N. Each node points to the next node, and the last node points back to the first node.
2. **Efficient Step Calculation**: For each step, compute the effective steps needed to reach the K-th node using modulo arithmetic to handle large values of K efficiently.
3. **Node Removal**: Traverse the linked list by the computed effective steps, remove the K-th node, and adjust the pointers to maintain the circular structure.
4. **Iteration**: Repeat the traversal and removal process until only one node remains.

### Solution Code
```python
class Node:
    def __init__(self, value):
        self.value = value
        self.next = None

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N = int(input[idx])
        K = int(input[idx + 1])
        idx += 2
        
        if N == 0:
            print(0)
            continue
        
        nodes = [Node(i + 1) for i in range(N)]
        for i in range(N):
            if i == N - 1:
                nodes[i].next = nodes[0]
            else:
                nodes[i].next = nodes[i + 1]
        
        current = nodes[0]
        current_length = N
        
        while current_length > 1:
            eff = (K - 1) % current_length
            for _ in range(eff):
                current = current.next
            current.next = current.next.next
            current = current.next
            current_length -= 1
        
        print(current.value)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Linked List Construction**: Nodes are created in a list where each node points to the next node. The last node points back to the first node, forming a circular structure.
2. **Effective Step Calculation**: The effective steps to reach the K-th node are computed using `(K - 1) % current_length` to handle large values of K efficiently. This ensures we only traverse the necessary nodes each iteration.
3. **Node Removal**: After moving the computed effective steps, the next node is removed, and the current pointer is adjusted to the node following the removed node. This maintains the circular structure of the linked list.
4. **Iteration**: The process repeats until only one node remains, which is then printed as the result for each test case.

This approach efficiently handles the constraints and ensures the solution is computed in a feasible time frame even for large values of K.
