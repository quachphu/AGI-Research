To solve this problem, we need to pair all integers from `l` to `r` inclusive such that each pair's greatest common divisor (GCD) is 1. The problem guarantees that the number of integers in the range is even, which allows us to form pairs efficiently.

### Approach
The key insight is that consecutive integers are always coprime (their GCD is 1). This allows us to pair each integer `i` with `i+1` for all even `i` in the range. This approach ensures that each pair meets the GCD requirement and covers all numbers exactly once.

### Solution Code
```python
l, r = map(int, input().split())
print("YES")
for i in range(l, r, 2):
    print(i, i+1)
```

### Explanation
1. **Reading Input**: The input consists of two integers `l` and `r`.
2. **Output "YES"**: Since consecutive integers are always coprime, a valid solution is guaranteed, so we immediately print "YES".
3. **Generate Pairs**: We iterate through the range from `l` to `r` in steps of 2. For each step, we form a pair of consecutive integers `(i, i+1)`, ensuring all numbers are included exactly once and each pair's GCD is 1.

This approach efficiently constructs the required pairs in linear time relative to the number of integers in the range, which is optimal given the constraints.
