To solve this problem, we need to determine the grade of steel based on three specific conditions related to its hardness, carbon content, and tensile strength. The solution involves checking these conditions in a specific order to assign the correct grade according to the given criteria.

### Approach
1. **Input Reading**: Read the number of test cases and the respective values for hardness, carbon content, and tensile strength for each test case.
2. **Condition Checking**: For each test case, check the three conditions:
   - Hardness greater than 50.
   - Carbon content less than 0.7.
   - Tensile strength greater than 5600.
3. **Grade Assignment**: Based on the conditions met, assign the grade using a priority order:
   - Grade 10 if all three conditions are met.
   - Grade 9 if the first two conditions (hardness and carbon content) are met.
   - Grade 8 if the last two conditions (carbon content and tensile strength) are met.
   - Grade 7 if the first and third conditions (hardness and tensile strength) are met.
   - If none of the above, check how many conditions are met. Assign Grade 6 if exactly one condition is met, otherwise assign Grade 5.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        h = float(input[idx])
        c = float(input[idx + 1])
        ts = float(input[idx + 2])
        idx += 3
        
        cond_i = h > 50
        cond_ii = c < 0.7
        cond_iii = ts > 5600
        
        if cond_i and cond_ii and cond_iii:
            print(10)
        elif cond_i and cond_ii:
            print(9)
        elif cond_ii and cond_iii:
            print(8)
        elif cond_i and cond_iii:
            print(7)
        else:
            count = sum([cond_i, cond_ii, cond_iii])
            print(6 if count == 1 else 5)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read all at once and split into a list for efficient processing. The first element gives the number of test cases.
- **Condition Checks**: Each test case is processed by converting the input values to floats and checking the three conditions.
- **Priority-Based Grading**: The conditions are checked in a specific order to ensure the highest possible grade is assigned first. If none of the higher grades apply, the number of met conditions is counted to determine if the grade should be 6 (one condition met) or 5 (no conditions met).

This approach ensures that all possible cases are covered efficiently and correctly, adhering to the problem constraints and requirements.
