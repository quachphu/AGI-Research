To solve this problem, we need to determine two things: the maximum possible beauty difference between any two flowers and the number of ways to pick such pairs of flowers. 

### Approach
1. **Identify Extremes**: The maximum beauty difference is determined by the difference between the maximum and minimum beauty values in the list of flowers.
2. **Count Occurrences**: If all flowers have the same beauty value, every pair of flowers is valid, and the number of pairs is given by the combination formula \( C(n, 2) = \frac{n(n-1)}{2} \).
3. **Handle Distinct Extremes**: If there are distinct maximum and minimum beauty values, count how many times each of these values appears. The number of valid pairs is the product of these counts.

### Solution Code
```python
n = int(input())
b = list(map(int, input().split()))
min_b = min(b)
max_b = max(b)
if min_b == max_b:
    print(0, n * (n - 1) // 2)
else:
    count_min = b.count(min_b)
    count_max = b.count(max_b)
    print(max_b - min_b, count_min * count_max)
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` followed by `n` integers representing the beauty values of the flowers.
2. **Finding Extremes**: Using Python's built-in `min` and `max` functions, we determine the minimum and maximum beauty values in the list.
3. **Special Case Handling**: If all flowers have the same beauty value, the maximum difference is 0, and the number of valid pairs is calculated using the combination formula.
4. **Counting Valid Pairs**: For distinct maximum and minimum values, we count their occurrences using `list.count()`. The product of these counts gives the number of valid pairs with the maximum beauty difference.

This approach efficiently handles the constraints and ensures optimal performance even for the upper limit of input size.
