To solve this problem, we need to read a stream of words from standard input (stdin) and print each word until we encounter the word "pragyan" (case-insensitive). Once "pragyan" is found, we print it and stop processing further input.

### Approach
1. **Reading Input**: Read each line from stdin one by one.
2. **Case-Insensitive Check**: Convert each read word to lowercase and check if it matches "pragyan".
3. **Print and Exit**: If the word matches "pragyan" (case-insensitive), print the original word and terminate the processing. Otherwise, print the word and continue processing the next input line.

### Solution Code
```python
import sys

def process_input():
    for line in sys.stdin:
        word = line.strip()
        print(word)
        if word.lower() == 'pragyan':
            break

process_input()
```

### Explanation
1. **Reading Input**: The code uses a loop to read each line from `sys.stdin`, which efficiently handles the input stream.
2. **Stripping Whitespace**: Each line is stripped of leading and trailing whitespace using `strip()` to ensure clean processing.
3. **Case-Insensitive Check**: The word is converted to lowercase using `word.lower()` and compared to "pragyan" to handle any case variations.
4. **Termination**: Upon finding the target word, the loop breaks, stopping further input processing immediately after printing the word.

This approach ensures that we process each input line exactly once, making the solution both efficient and straightforward.
