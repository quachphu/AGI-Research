To solve this problem, we need to determine the maximum number of valid triples (i, j, k) in a sequence of non-negative integers. Each triple must meet specific conditions regarding the values and indices of the elements involved. The solution involves efficiently checking for valid triples and using a greedy approach to maximize the count.

### Approach
1. **Count Zeros**: The number of zeros in the sequence determines the potential pairs of indices (i, k) that can form triples. Each valid triple requires two zeros (i and k) and one non-zero element (j).
2. **Prefix and Suffix Checks**: For each non-zero element, check if there is at least one zero before it (prefix) and one zero after it (suffix). This helps identify valid candidates for j in the triples.
3. **Unique Values**: Ensure that each non-zero element used in the triples has a unique value.
4. **Calculate Result**: The result is the minimum of the number of valid unique non-zero values and the number of possible zero pairs (floor of half the number of zeros).

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        a = list(map(int, input[ptr:ptr + n]))
        ptr += n
        m = a.count(0)
        if m < 2:
            print(0)
            continue
        # Compute prefix and suffix
        prefix = [False] * n
        has_zero = False
        for j in range(n):
            prefix[j] = has_zero
            if a[j] == 0:
                has_zero = True
        suffix = [False] * n
        has_zero = False
        for j in range(n-1, -1, -1):
            suffix[j] = has_zero
            if a[j] == 0:
                has_zero = True
        # Collect unique a_j's
        unique_aj = set()
        for j in range(n):
            if a[j] != 0 and prefix[j] and suffix[j]:
                unique_aj.add(a[j])
        u = len(unique_aj)
        print(min(u, m // 2))

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Zero Count**: The number of zeros (m) is counted. If there are fewer than two zeros, no valid triples can be formed.
3. **Prefix and Suffix Arrays**: These arrays track whether there is a zero before and after each position, respectively.
4. **Unique Values Check**: For each non-zero element, check if it can be part of a valid triple using the prefix and suffix arrays. Collect unique values of these valid elements.
5. **Result Calculation**: The result is the minimum of the number of unique valid elements and half the number of zeros, as each triple requires two zeros.

This approach ensures that we efficiently determine the maximum number of valid triples while adhering to the constraints, using linear time complexity for each test case.
