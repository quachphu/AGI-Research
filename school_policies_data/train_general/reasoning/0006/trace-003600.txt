To solve this problem, we need to determine if there exists a string that is lexicographically larger than a given string `s` and smaller than another given string `t`, both of which have the same length. If such a string exists, we should output it; otherwise, we should output "No such string".

### Approach
1. **Generate the Next Lexicographical String**: The key insight is to generate the smallest possible string that is lexicographically greater than `s`. This can be done by incrementing the characters of `s` from right to left, similar to how we increment numbers. If a character is 'z', it wraps around to 'a', and we carry over the increment to the next character on the left.
2. **Check Validity**: After generating the next string, check if it is lexicographically smaller than `t`. If it is, this string is our answer. If not, output "No such string".

### Solution Code
```python
def get_next(s):
    s_list = list(s)
    i = len(s_list) - 1
    while i >= 0:
        if s_list[i] == 'z':
            s_list[i] = 'a'
            i -= 1
        else:
            s_list[i] = chr(ord(s_list[i]) + 1)
            break
    return ''.join(s_list)

s = input().strip()
t = input().strip()

next_str = get_next(s)
if next_str < t:
    print(next_str)
else:
    print("No such string")
```

### Explanation
1. **Generating the Next String**: The function `get_next` converts the string `s` into a list of characters for easier manipulation. Starting from the end of the list, it increments the character. If the character is 'z', it wraps around to 'a' and moves left to carry over the increment. This process continues until a character that is not 'z' is found and incremented.
2. **Comparison with `t`**: After generating the next string, we compare it with `t`. If the next string is lexicographically smaller than `t`, it is printed. Otherwise, we print "No such string".

This approach efficiently generates the next possible string and checks its validity, ensuring that we either find a valid string or determine that none exists in linear time relative to the length of the strings.
