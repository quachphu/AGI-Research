To solve this problem, we need to determine if Ksusha the Squirrel can jump from the first sector to the last sector of a road without landing on any rocks. Ksusha can jump up to `k` sectors forward from her current position, but she cannot land on sectors marked with a rock (`#`).

### Approach
1. **Dynamic Programming with Sliding Window Sum**: We use a dynamic programming (DP) array `dp` where `dp[i]` indicates whether sector `i` is reachable. We also use a prefix sum array to efficiently compute the sum of reachable sectors within a sliding window of up to `k` elements.
2. **Prefix Sum Array**: This array helps in quickly determining if there is any reachable sector within the last `k` positions from the current sector. This allows us to check in constant time if Ksusha can jump to the current sector from any valid previous position.
3. **Sliding Window Check**: For each sector, we check if there is any reachable sector within the previous `k` sectors using the prefix sum array. If such a sector exists and the current sector is not a rock, we mark the current sector as reachable.

### Solution Code
```python
n, k = map(int, input().split())
s = input().strip()

dp = [0] * (n + 1)
dp[1] = 1  # Starting position is sector 1, which is guaranteed to be '.'

prefix = [0] * (n + 1)
prefix[1] = dp[1]

for i in range(2, n + 1):
    if s[i-1] == '#':
        dp[i] = 0
        prefix[i] = prefix[i-1]
    else:
        a = max(1, i - k)
        b = i - 1
        if a > b:
            sum_prev = 0
        else:
            sum_prev = prefix[b] - (prefix[a-1] if a > 1 else 0)
        dp[i] = 1 if sum_prev > 0 else 0
        prefix[i] = prefix[i-1] + dp[i]

print("YES" if dp[n] else "NO")
```

### Explanation
1. **Initialization**: We start by initializing the `dp` array where `dp[1]` is set to 1 because Ksusha starts at the first sector, which is guaranteed to be safe (`.`). The prefix sum array `prefix` is initialized to keep track of cumulative reachable sectors.
2. **Iterate Through Sectors**: For each sector from 2 to `n`, we check if the current sector is a rock. If it is, it is marked as unreachable. If it is not a rock, we check the previous `k` sectors using the prefix sum array to determine if there is any reachable sector.
3. **Sliding Window Check**: Using the prefix sum array, we compute the sum of reachable sectors in the valid range `[max(1, i - k), i - 1]`. If this sum is positive, the current sector is reachable.
4. **Result Check**: After processing all sectors, we check if the last sector is reachable and print "YES" if it is, otherwise "NO".

This approach efficiently checks reachability using dynamic programming combined with a sliding window sum technique, ensuring the solution runs in linear time, which is optimal for large input sizes.
