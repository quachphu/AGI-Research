To solve this problem, we need to construct the minimum number of roads between cities such that any two cities can be reached by traversing at most two roads. Additionally, certain pairs of cities are forbidden from having a direct road. 

### Approach
1. **Select a Hub City**: Choose a city (hub) that can be connected to the maximum number of other cities directly. This minimizes the number of cities that need indirect connections.
2. **Direct Connections**: Connect the hub city to all cities that are allowed (not forbidden).
3. **Indirect Connections**: For cities that cannot be directly connected to the hub (due to forbidden pairs), connect each to a city that is directly connected to the hub. This ensures that all cities can reach the hub within two steps.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n, m = map(int, sys.stdin.readline().split())
    forbidden = defaultdict(set)
    for _ in range(m):
        a, b = map(int, sys.stdin.readline().split())
        forbidden[a].add(b)
        forbidden[b].add(a)
    
    # Compute allowed_count for each city
    allowed_count = [0] * (n + 1)  # index 0 unused
    for c in range(1, n + 1):
        cnt = len(forbidden.get(c, set()))
        allowed_count[c] = (n - 1) - cnt
    
    # Find the city with maximum allowed_count
    c = 1
    max_allowed = allowed_count[1]
    for i in range(2, n + 1):
        if allowed_count[i] > max_allowed:
            max_allowed = allowed_count[i]
            c = i
    
    # Collect allowed and forbidden cities for c
    allowed_c = []
    for v in range(1, n + 1):
        if v != c and v not in forbidden.get(c, set()):
            allowed_c.append(v)
    
    forbidden_for_c = []
    for u in forbidden.get(c, set()):
        if u != c:
            forbidden_for_c.append(u)
    
    edges = []
    # Add all edges from c to allowed_c
    for v in allowed_c:
        edges.append((c, v))
    
    # Handle forbidden_for_c by connecting to allowed_c
    if allowed_c:
        secondary_hub = allowed_c[0]
        for u in forbidden_for_c:
            if secondary_hub not in forbidden[u]:
                edges.append((u, secondary_hub))
            else:
                found = False
                for v in allowed_c:
                    if v not in forbidden.get(u, set()):
                        edges.append((u, v))
                        found = True
                        break
                if not found:
                    pass  # According to problem constraints, this won't happen
    
    print(len(edges))
    for a, b in edges:
        print(a, b)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and stored in a dictionary to track forbidden city pairs.
2. **Hub Selection**: The city with the maximum allowed connections (minimum forbidden pairs) is selected as the hub.
3. **Direct Connections**: The hub is directly connected to all cities that are allowed.
4. **Indirect Connections**: Cities that cannot connect directly to the hub are connected to another city that is directly connected to the hub, ensuring all cities can reach each other within two steps.

This approach ensures that we use the minimum number of roads while adhering to the constraints, providing an efficient and optimal solution.
