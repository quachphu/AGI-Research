To solve this problem, we need to determine the optimal restaurant location such that the maximum Manhattan distance traveled by any friend from their hotel to the restaurant is minimized. The Manhattan distance between two points \((x1, y1)\) and \((x2, y2)\) is given by \(|x1 - x2| + |y1 - y2|\).

### Approach
1. **Preprocessing Hotels**: For each hotel, compute two values:
   - \(s_i = x_i + y_i\)
   - \(d_i = x_i - y_i\)
   Track the minimum and maximum values of \(s_i\) and \(d_i\) across all hotels. These values will be used to efficiently compute the maximum distance for any given restaurant.

2. **Evaluating Restaurants**: For each restaurant, compute the Manhattan distances to all hotels using the preprocessed values. The key insight is that the maximum Manhattan distance from a restaurant to any hotel can be derived from four precomputed values:
   - \( \text{max1} = (a + b) - \text{min}(s_i) \)
   - \( \text{max2} = \text{max}(s_i) - (a + b) \)
   - \( \text{max3} = (a - b) - \text{min}(d_i) \)
   - \( \text{max4} = \text{max}(d_i) - (a - b) \)
   The maximum of these four values gives the maximum distance for that restaurant.

3. **Select Optimal Restaurant**: Track the restaurant that results in the minimum of these maximum distances. If multiple restaurants yield the same minimum, select the first one encountered.

def main():
    data = sys.stdin.read().split()
    ptr = 0
    N = int(data[ptr])
    ptr += 1

        ptr += 1

        d = x - y

        if s > max_s:
            max_s = s
        if d < min_d:
            min_d = d
        if d > max_d:
            max_d = d

    ptr += 1

    best_dist = float('inf')
    best_idx = -1

1. **Reading Input**: The input is read in one go for efficiency, especially given the large constraints.
2. **Preprocessing Hotels**: For each hotel, compute \(s_i\) and \(d_i\), and update the minimum and maximum values for these metrics.
3. **Evaluating Restaurants**: For each restaurant, compute the four possible maximum distances using the preprocessed values. The maximum of these four values determines the worst-case travel distance for that restaurant.
4. **Tracking the Best Option**: Maintain the best (smallest maximum distance) found and update it as each restaurant is evaluated.

This approach ensures that we efficiently compute the optimal restaurant using preprocessed values, reducing the complexity from \(O(C \times H)\) to \(O(C + H)\), which is feasible for large input sizes.
