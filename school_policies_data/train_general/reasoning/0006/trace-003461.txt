To solve this problem, we need to determine how many words from a given list match a specific pattern. Each pattern can include fixed characters or groups of possible characters for each position in the word.

### Approach
1. **Input Parsing**: Read the input values for the word length (L), the number of known words (D), and the number of test cases (N). Then, read the known words and the test cases.
2. **Pattern Parsing**: For each test case, parse the pattern into a list of sets. Each set contains the allowed characters for a specific position in the word.
3. **Matching Words**: For each word in the list of known words, check if it matches the parsed pattern by ensuring every character in the word is present in the corresponding set of allowed characters for that position.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().splitlines()
    idx = 0
    L, D, N = map(int, input[idx].split())
    idx += 1
    words = [input[i].strip() for i in range(idx, idx + D)]
    idx += D
    for _ in range(N):
        pattern = input[idx].strip()
        idx += 1
        allowed = []
        i = 0
        n = len(pattern)
        while i < n:
            if pattern[i] == '(':
                i += 1
                j = i
                while j < n and pattern[j] != ')':
                    j += 1
                allowed.append(set(pattern[i:j]))
                i = j + 1
            else:
                allowed.append({pattern[i]})
                i += 1
        count = 0
        for word in words:
            match = True
            for pos in range(L):
                if word[pos] not in allowed[pos]:
                    match = False
                    break
            if match:
                count += 1
        print(count)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into lines for easier processing. The first line contains the values of L, D, and N.
2. **Storing Words**: The next D lines are the known words, stored in a list for later processing.
3. **Processing Each Test Case**:
   - **Pattern Parsing**: Each pattern is parsed into a list of sets. If a token is enclosed in parentheses, each character within the parentheses is added to a set. If the token is a single character, it is directly added as a set containing that character.
   - **Matching Words**: For each word, check if every character matches the allowed characters in the corresponding position of the parsed pattern. If all characters match, the word is counted as a valid match.
4. **Output**: The count of valid matches for each test case is printed.

This approach efficiently checks each word against the parsed pattern, ensuring that we only consider valid characters for each position, leading to an optimal solution given the constraints.
