To solve this problem, we need to determine the number of sequences consisting of integers each at least 3 that sum up to a given integer S. The result should be provided modulo \(10^9 + 7\).

### Approach
The problem can be efficiently solved using dynamic programming (DP) combined with prefix sums to optimize the computation. Here's the detailed approach:

1. **Dynamic Programming (DP) Setup**:
   - Define `dp[s]` as the number of valid sequences that sum up to `s`.
   - Initialize `dp[0]` to 1, representing the base case of an empty sequence.

2. **Prefix Sum Optimization**:
   - Use a prefix sum array to efficiently compute the sum of previous `dp` values. This helps in reducing the time complexity from \(O(S^2)\) to \(O(S)\).

3. **Iterative Calculation**:
   - For each sum `s` from 1 to S, compute `dp[s]` using the prefix sum array. If `s` is less than 3, `dp[s]` is 0 because each term in the sequence must be at least 3. For `s` greater than or equal to 3, `dp[s]` is derived from the prefix sum of values up to `s-3`.

### Solution Code
```python
MOD = 10**9 + 7

S = int(input())

if S < 3:
    print(0)
else:
    dp = [0] * (S + 1)
    dp[0] = 1  # Base case: empty sequence
    prefix = [0] * (S + 1)
    prefix[0] = 1  # prefix[0] corresponds to sum up to 0
    
    for s in range(1, S + 1):
        if s >= 3:
            dp[s] = prefix[s - 3] % MOD
        else:
            dp[s] = 0
        prefix[s] = (prefix[s - 1] + dp[s]) % MOD
    
    print(dp[S] % MOD)
```

### Explanation
- **Dynamic Programming Array (`dp`)**: This array keeps track of the number of valid sequences for each sum from 0 to S. The value `dp[s]` is computed based on the sum of previous valid sequences using prefix sums.
- **Prefix Sum Array (`prefix`)**: This array helps in efficiently computing the sum of `dp` values up to a certain index. It is updated iteratively to include the current `dp` value, ensuring that each computation is done in constant time.
- **Modulo Operation**: To handle large numbers and prevent overflow, all operations are performed modulo \(10^9 + 7\).

This approach ensures that we efficiently compute the result in linear time, making it feasible even for the upper constraint of \(S = 2000\).
