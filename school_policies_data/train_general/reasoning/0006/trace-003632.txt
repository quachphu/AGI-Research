To solve this problem, we need to determine the number of proxies in a class based on the attendance record. A proxy is represented by a '.' in the attendance string, while a present student is represented by a '#'. The task is to count the number of '.' characters in the given string.

### Approach
1. **Input Reading**: Read the number of attendance records (N) and the attendance string.
2. **Count Proxies**: Simply count the occurrences of the '.' character in the attendance string.
3. **Output the Result**: Print the count of '.' characters, which represents the number of proxies.

### Solution Code
```python
n = int(input())
attendance = input().strip()
print(attendance.count('.'))
```

### Explanation
1. **Reading Input**: The first line of input is read to get the number of attendance records (N), which is not directly used but ensures the input format is correct. The second line is the attendance string.
2. **Counting Proxies**: Using the `count('.')` method on the attendance string efficiently counts the number of '.' characters, each representing a proxy.
3. **Output**: The result is printed directly, which is the count of proxies.

This approach ensures that we efficiently and correctly determine the number of proxies with a time complexity of O(N), where N is the length of the attendance string, due to the linear scan involved in the `count` method. This is optimal for the problem constraints.
