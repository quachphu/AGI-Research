To solve this problem, we need to determine if Lesha's problem is brand new or if it resembles any problem in the Torcoder.com archive based on a similarity metric. The similarity metric is calculated by finding the permutation of Lesha's problem that appears as a subsequence in an archive problem with the minimum number of inversions.

### Approach
1. **Input Reading**: Read the number of words in Lesha's problem and the words themselves. Then read the number of archive problems and their descriptions.
2. **Generate Permutations**: For each archive problem, generate all permutations of Lesha's problem words.
3. **Subsequence Check**: For each permutation, check if it is a subsequence of the archive problem's words.
4. **Inversion Count Calculation**: For valid permutations (those that are subsequences), calculate the inversion count relative to the original order of Lesha's words.
5. **Similarity Calculation**: Compute the similarity metric using the minimum inversion count found for valid permutations. The similarity is given by \( p = \frac{n(n-1)}{2} - x + 1 \), where \( x \) is the minimum inversion count.
6. **Determine Result**: Track the highest similarity and the corresponding archive problem. If no valid permutation is found in any archive problem, output "Brand new problem!".

### Solution Code
```python
import itertools

def main():
    n = int(input())
    lesha_words = input().split()
    m = int(input())
    archives = []
    for _ in range(m):
        parts = input().split()
        words = parts[1:]
        archives.append(words)
    
    best_p = -1
    best_index = -1

    def is_subsequence(needle, haystack):
        current_pos = 0
        for word in needle:
            found = False
            while current_pos < len(haystack):
                if haystack[current_pos] == word:
                    current_pos += 1
                    found = True
                    break
                current_pos += 1
            if not found:
                return False
        return True

    def count_inversion(perm):
        indices = [lesha_words.index(word) for word in perm]
        inv_count = 0
        for i in range(len(indices)):
            for j in range(i + 1, len(indices)):
                if indices[i] > indices[j]:
                    inv_count += 1
        return inv_count

    for idx, words in enumerate(archives, 1):
        min_x = None
        for perm in itertools.permutations(lesha_words):
            if is_subsequence(perm, words):
                x = count_inversion(perm)
                if min_x is None or x < min_x:
                    min_x = x
        if min_x is not None:
            max_inversion = n * (n - 1) // 2
            p = max_inversion - min_x + 1
            if (p > best_p) or (p == best_p and idx < best_index):
                best_p = p
                best_index = idx

    if best_index == -1:
        print("Brand new problem!")
    else:
        print(best_index)
        bar = '|' * best_p
        print(f"[:{bar}:]")

main()
```

2. **Generating Permutations**: Using `itertools.permutations`, all permutations of Lesha's problem words are generated for each archive problem.
3. **Checking Subsequence**: For each permutation, the `is_subsequence` function checks if the permutation appears in order within the archive problem's words.
4. **Calculating Inversions**: The `count_inversion` function calculates the number of inversions by comparing each permutation to the original order of Lesha's words.
5. **Computing Similarity**: The similarity metric \( p \) is computed using the minimum inversion count found. The highest similarity and corresponding archive problem index are tracked.
6. **Output**: The result is printed based on the highest similarity found or if no valid permutations are found.

This approach efficiently checks all permutations and computes the required metrics to determine the most similar problem or confirm the problem is new.
