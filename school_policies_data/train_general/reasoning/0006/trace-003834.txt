To solve this problem, we need to determine if it is possible to reduce a number \( x \) to another number \( y \) (where \( x > y \)) by subtracting a prime number \( p \) any number of times. 

### Approach
The key insight here is that the difference \( D = x - y \) must be a multiple of some prime number \( p \). For any \( D \geq 2 \), there will always be a prime number that can divide \( D \), allowing us to reduce \( x \) to \( y \) by subtracting \( p \) exactly \( D/p \) times. However, if \( D = 1 \), it is impossible because the smallest prime number is 2, and subtracting 2 from 1 would result in a negative number. 

Thus, the solution simplifies to checking if \( D = x - y \) is greater than 1. If it is, the answer is "YES"; otherwise, the answer is "NO".

### Solution Code
```python
t = int(input())
for _ in range(t):
    x, y = map(int, input().split())
    d = x - y
    print("YES" if d > 1 else "NO")
```

### Explanation
1. **Input Reading**: Read the number of test cases \( t \).
2. **Loop Through Test Cases**: For each test case, read the integers \( x \) and \( y \).
3. **Compute Difference**: Calculate the difference \( D = x - y \).
4. **Check Condition**: If \( D > 1 \), print "YES" because there exists a prime number that can divide \( D \). Otherwise, print "NO" since \( D = 1 \) cannot be achieved by subtracting any prime number.

This approach efficiently solves the problem in constant time \( O(1) \) per test case, making it suitable even for large values up to \( 10^{18} \).
