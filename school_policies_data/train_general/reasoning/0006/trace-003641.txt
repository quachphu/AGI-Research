To solve this problem, we need to reconstruct the original string `a` from the given string `b`, which is formed by concatenating all substrings of length 2 from `a` in order. The key insight is that the original string can be reconstructed by taking the first character from each substring of `b` and appending the last character of the last substring.

### Approach
1. **Understanding the Structure of `b`**: The string `b` is formed by concatenating all length-2 substrings of `a`. For example, if `a` is "abac", then `b` is formed by concatenating "ab", "ba", and "ac" resulting in "abbaac".
2. **Splitting `b` into Pairs**: Since each substring in `b` is of length 2, we can split `b` into consecutive pairs of characters.
3. **Reconstructing `a`**: The original string `a` can be reconstructed by taking the first character from each pair in `b` and appending the second character of the last pair. This works because each pair overlaps by one character with the next pair in the original string `a`.

### Solution Code
```python
t = int(input())
for _ in range(t):
    b = input().strip()
    pairs = [b[i:i+2] for i in range(0, len(b), 2)]
    a = ''.join(p[0] for p in pairs) + pairs[-1][1]
    print(a)
```

### Explanation
1. **Reading Input**: We start by reading the number of test cases `t`.
2. **Processing Each Test Case**: For each test case, we read the string `b`.
3. **Splitting into Pairs**: We split `b` into pairs of consecutive characters. For example, "abbaac" becomes ["ab", "ba", "ac"].
4. **Constructing `a`**: We construct `a` by concatenating the first character of each pair and then appending the second character of the last pair. This gives us the original string `a`.

This approach efficiently reconstructs the original string by leveraging the structure of how `b` is formed from `a`, ensuring correctness and optimal performance.
