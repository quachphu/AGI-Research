To solve this problem, we need to determine the minimum number of roads that must be built to connect all cities in a given graph. The solution involves identifying the number of connected components in the graph and using this information to compute the result.

### Approach
1. **Problem Analysis**: The goal is to ensure all cities are connected, either directly or indirectly through other cities. If the graph is already connected, no new roads are needed. If it is divided into multiple connected components, the minimum number of roads required to connect all components is the number of components minus one.
2. **Graph Representation**: Use a Disjoint Set Union (DSU) data structure to efficiently manage and query the connected components of the graph.
3. **Union-Find Algorithm**: This algorithm helps in dynamically connecting components and finding the root of any component in nearly constant time due to path compression and union by rank optimizations.
4. **Counting Components**: After processing all existing roads, count the number of distinct connected components by finding the unique roots in the DSU structure.

### Solution Code
```python
import sys

class DSU:
    def __init__(self, size):
        self.parent = list(range(size + 1))  # 1-based indexing
        self.rank = [0] * (size + 1)
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return
        if self.rank[x_root] < self.rank[y_root]:
            self.parent[x_root] = y_root
        else:
            self.parent[y_root] = x_root
            if self.rank[x_root] == self.rank[y_root]:
                self.rank[x_root] += 1

def main():
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    M = int(input[ptr])
    ptr += 1
    dsu = DSU(N)
    for _ in range(M):
        a = int(input[ptr])
        ptr += 1
        b = int(input[ptr])
        ptr += 1
        dsu.union(a, b)
    # Find the number of connected components
    roots = set()
    for i in range(1, N+1):
        roots.add(dsu.find(i))
    print(len(roots) - 1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **DSU Initialization**: The DSU class is initialized with each city as its own parent and rank 0.
2. **Union Operations**: For each road, the union operation merges the two cities into a single component.
3. **Component Counting**: After processing all roads, each city's root is found and stored in a set to count unique components.
4. **Result Calculation**: The minimum number of roads needed is the number of components minus one, which is printed as the result.

This approach efficiently handles the constraints using union-find with path compression and union by rank, ensuring optimal performance even for large input sizes.
