To solve this problem, we need to count the occurrences of the digit '4' in each number from a given list of integers. The solution should efficiently handle up to 100,000 integers, each potentially having a large number of digits.

### Approach
1. **Reading Input Efficiently**: We use Python's `sys.stdin` to read input efficiently, which is crucial given the large potential input size.
2. **Processing Each Number**: For each number, instead of converting it to an integer, we treat it as a string. This allows us to directly count the occurrences of the digit '4' using the string method `count('4')`.
3. **Output the Results**: After counting the occurrences for each number, we immediately print the result to avoid storing large intermediate results.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        num = sys.stdin.readline().strip()
        print(num.count('4'))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The first line of input is the number of test cases, `T`. We read this using `sys.stdin.readline()` for efficiency.
2. **Processing Each Test Case**: For each of the next `T` lines, we read the number as a string and strip any extraneous whitespace (though the problem guarantees well-formed input, this is a precaution).
3. **Counting '4's**: Using the string method `count('4')`, we efficiently determine how many times '4' appears in the string representation of the number.
4. **Output**: Each count is printed immediately after processing the corresponding number to ensure minimal memory usage and efficient output handling.

This approach ensures that we handle up to 100,000 numbers efficiently, with each number processed in linear time relative to its length, making the solution both time and space efficient.
