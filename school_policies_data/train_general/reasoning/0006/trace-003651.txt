### Approach
1. **Understanding DFS Traversal**: The DFS traversal starts at the root and visits each node's children in a specific order. By rearranging the children's order, we can influence the traversal path.
2. **Key Insight**: The first `k` nodes in the DFS traversal form a connected subtree. The challenge is to select a subtree of size at least `k` such that the minimum value in this subtree is maximized.
3. **Union-Find Data Structure**: We use a union-find (disjoint set union, DSU) structure to efficiently manage and merge connected components as we process nodes in descending order of their values.
4. **Binary Search on Values**: By sorting nodes in descending order of their values and processing them one by one, we can check if a connected component of size at least `k` exists using the union-find structure. The first valid value encountered is our answer.

import sys
from sys import stdin
sys.setrecursionlimit(1 << 25)

def main():
    n, k = map(int, stdin.readline().split())
    a = list(map(int, stdin.readline().split()))
    adj = [[] for _ in range(n + 1)]  # Using 1-based indexing

    for _ in range(n - 1):
        u, v = map(int, stdin.readline().split())
        adj[u].append(v)
        adj[v].append(u)

    # Sort nodes in descending order of a's value
    sorted_nodes = sorted([(a[i], i + 1) for i in range(n)], key=lambda x: (-x[0], x[1]))

    parent = list(range(n + 1))
    size = [1] * (n + 1)
    processed = [False] * (n + 1)
    max_size = 0

    def find(u):
        while parent[u] != u:
            parent[u] = parent[parent[u]]  # Path compression
            u = parent[u]
        return u

    def union(u, v):
        u_root = find(u)
        v_root = find(v)
        if u_root == v_root:
            return
        # Union by size
        if size[u_root] < size[v_root]:
            u_root, v_root = v_root, u_root
        parent[v_root] = u_root
        size[u_root] += size[v_root]

    for val, u in sorted_nodes:
        processed[u] = True
        for v in adj[u]:
            if processed[v]:
                union(u, v)
        root = find(u)
        current_size = size[root]
        if current_size > max_size:
            max_size = current_size
        if max_size >= k:
            print(val)
            return

    print(min(a))  # This line is theoretically unreachable given the constraints

    main()
