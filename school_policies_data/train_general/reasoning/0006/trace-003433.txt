To solve this problem, we need to determine the minimum cost for Phoenix to pair all his socks into matching pairs. Each pair must consist of one left sock and one right sock of the same color. The operations allowed are recoloring a sock, turning a left sock into a right sock, or turning a right sock into a left sock, each costing 1 dollar.

### Approach
1. **Balance Left and Right Socks**: First, ensure that the number of left and right socks are equal. If there are more left socks, flip some to right socks and vice versa. The cost for this step is the absolute difference between the current number of left/right socks and half the total number of socks.
2. **Optimize Pairing**: After balancing the counts of left and right socks, we need to minimize the number of recoloring operations. This is done by using a max-heap to greedily flip socks from colors with the highest discrepancy between left and right counts, thereby minimizing the number of recoloring operations needed.

### Solution Code
```python
from heapq import heappush, heappop

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n, l, r = map(int, input[ptr:ptr+3])
        ptr +=3
        c = list(map(int, input[ptr:ptr+n]))
        ptr +=n
        left = c[:l]
        right = c[l:]
        
        left_count = {}
        for color in left:
            left_count[color] = left_count.get(color, 0) + 1
        right_count = {}
        for color in right:
            right_count[color] = right_count.get(color, 0) + 1
        
        flip_cost = abs(l - n//2)
        K = flip_cost
        
        if l > n//2:
            heap = []
            for color in left_count:
                current_d = left_count[color] - right_count.get(color, 0)
                heappush(heap, (-current_d, color))
            while K > 0 and heap:
                current_d_neg, color = heappop(heap)
                current_d = -current_d_neg
                if left_count[color] == 0:
                    continue
                left_count[color] -= 1
                right_count[color] = right_count.get(color, 0) + 1
                new_d = left_count[color] - right_count[color]
                if left_count[color] > 0:
                    heappush(heap, (-new_d, color))
                K -= 1
        elif l < n//2:
            heap = []
            for color in right_count:
                current_d = right_count[color] - left_count.get(color, 0)
                heappush(heap, (-current_d, color))
            while K > 0 and heap:
                current_d_neg, color = heappop(heap)
                current_d = -current_d_neg
                if right_count[color] == 0:
                    continue
                right_count[color] -= 1
                left_count[color] = left_count.get(color, 0) + 1
                new_d = right_count[color] - left_count[color]
                if right_count[color] > 0:
                    heappush(heap, (-new_d, color))
                K -= 1
        
        sum_abs = 0
        all_colors = set(left_count.keys()).union(right_count.keys())
        for color in all_colors:
            lc = left_count.get(color, 0)
            rc = right_count.get(color, 0)
            sum_abs += abs(lc - rc)
        E = sum_abs // 2
        print(flip_cost + E)

if __name__ == "__main__":
    main()
```

4. **Calculating Recolor Cost**: After balancing, the sum of absolute differences between left and right counts for each color is computed. This sum divided by 2 gives the number of recoloring operations needed, as each pair of excess socks requires one recolor.

This approach ensures that we minimize the number of operations needed to pair all socks efficiently.
