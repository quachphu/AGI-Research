To solve this problem, we need to determine if any two contests' timings overlap. If they do, Kuldeep will need a moderator; otherwise, he won't. The solution involves checking intervals of time for overlaps efficiently.

### Approach
1. **Parse Input**: Read the number of contests and their respective start and end times.
2. **Convert Time to Minutes**: Convert the start and end times from HH:MM format to minutes since midnight for easier comparison.
3. **Sort Intervals**: Sort the intervals based on their start times.
4. **Check Overlaps**: Traverse the sorted intervals while keeping track of the maximum end time encountered so far. If any interval starts before the maximum end time of previous intervals, there is an overlap.

### Solution Code
```python
def check_overlap():
    import sys
    t = int(sys.stdin.readline())
    intervals = []
    for _ in range(t):
        line = sys.stdin.readline().strip()
        start_str, end_str = line.split('-')
        # Parse start time
        hh, mm = map(int, start_str.split(':'))
        start = hh * 60 + mm
        # Parse end time
        hh_end, mm_end = map(int, end_str.split(':'))
        end = hh_end * 60 + mm_end
        intervals.append((start, end))
    # Sort intervals by their start time
    intervals.sort()
    max_end = 0
    for s, e in intervals:
        if s < max_end:
            print("Will need a moderator!")
            return
        max_end = max(max_end, e)
    print("Who needs a moderator?")

check_overlap()
```

### Explanation
1. **Reading Input**: The input is read using standard input functions. The first line gives the number of contests. Each subsequent line contains the start and end times of a contest in HH:MM-HH:MM format.
2. **Time Conversion**: Each time is converted into minutes since midnight to simplify comparison. For example, 09:30 becomes 570 minutes (9*60 + 30).
3. **Sorting**: The intervals are sorted by their start times to ensure we process them in chronological order.
4. **Overlap Check**: As we iterate through the sorted intervals, we maintain the maximum end time encountered. If an interval starts before this maximum end time, it indicates an overlap, and we immediately determine that a moderator is needed. If no overlaps are found after checking all intervals, we confirm that no moderator is needed.

This approach efficiently checks for overlaps in O(n log n) time due to sorting, which is optimal for the problem constraints.
