To solve this problem, we need to assign seats to people in a queue based on their preferred seats. If a preferred seat is taken, the person should be assigned the closest available seat according to specific criteria: minimum Manhattan distance, smallest row number, and smallest column number in case of ties.

### Approach
1. **Initialization**: Create a grid to track taken seats.
2. **Processing Each Person**: For each person in the queue:
   - Check if their preferred seat is available. If yes, assign it.
   - If the preferred seat is taken, search for the next best seat by expanding the search in concentric layers (Manhattan distance) around the preferred seat.
3. **Search Layers**: For each distance layer:
   - Generate potential seats in the order of increasing row number and, within the same row, increasing column number.
   - Check these seats in order until an available seat is found.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    m = int(input[ptr])
    ptr += 1
    k = int(input[ptr])
    ptr += 1

    taken = [[False] * (m + 2) for _ in range(n + 2)]  # 1-based indexing

    for _ in range(k):
        x = int(input[ptr])
        ptr += 1
        y = int(input[ptr])
        ptr += 1

        if not taken[x][y]:
            print(x, y)
            taken[x][y] = True
            continue

        # Need to find the next best seat
        found = False
        max_d = (n - 1) + (m - 1)
        for d in range(1, max_d + 1):
            start_x = max(1, x - d)
            end_x = min(n, x + d)
            for x2 in range(start_x, end_x + 1):
                dx = abs(x2 - x)
                dy_remaining = d - dx
                if dy_remaining < 0:
                    continue
                # Check y_minus first
                y_minus = y - dy_remaining
                if 1 <= y_minus <= m:
                    if not taken[x2][y_minus]:
                        print(x2, y_minus)
                        taken[x2][y_minus] = True
                        found = True
                        break
                if found:
                    break
                # Check y_plus if not found and it's different
                y_plus = y + dy_remaining
                if y_plus != y_minus and 1 <= y_plus <= m:
                    if not taken[x2][y_plus]:
                        print(x2, y_plus)
                        taken[x2][y_plus] = True
                        found = True
                        break
                if found:
                    break
            if found:
                break
        # According to problem statement, k <= n*m, so a seat will always be found

if __name__ == "__main__":
    main()
```

### Explanation
- **Grid Initialization**: A 2D list `taken` tracks which seats are occupied.
- **Preferred Seat Check**: For each person, check if their preferred seat is available. If yes, assign it immediately.
- **Expanding Search**: If the preferred seat is taken, search in expanding layers (Manhattan distance). For each layer:
  - Calculate the range of rows to check.
  - For each row in the range, compute valid columns based on the remaining distance.
  - Check columns in order (smallest first) and assign the first available seat found.
- **Efficiency**: The search for each person stops as soon as an available seat is found, minimizing unnecessary checks.

This approach ensures that each person is assigned the closest available seat according to the problem's criteria efficiently.
