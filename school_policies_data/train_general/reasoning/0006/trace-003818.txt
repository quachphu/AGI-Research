To solve this problem, we need to determine the status of each part (power supply, motor, and cable) in a factory based on test results. Each part can be classified as definitely normal, definitely faulty, or undetermined. The solution involves analyzing the test results to infer the status of each part.

### Approach
1. **Input Reading**: Read the input datasets until a line with three zeros is encountered. Each dataset includes the number of power supplies, motors, cables, and a list of test results.
2. **Initialization**: Initialize an array to track the status of each part (0 for faulty, 1 for normal, 2 for undetermined).
3. **Process Pass Tests**: For each test that passed (result = 1), mark all three involved parts as normal.
4. **Process Fail Tests Iteratively**: For each failed test (result = 0), check if exactly two parts are known to be normal. If so, the third part must be faulty. Repeat this process until no more changes can be made.
5. **Output Results**: After processing all tests, output the status of each part in the order of their part numbers.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().splitlines()
    ptr = 0
    while ptr < len(input):
        line = input[ptr].strip()
        ptr += 1
        if not line:
            continue
        a, b, c = map(int, line.split())
        if a == 0 and b == 0 and c == 0:
            break
        N = int(input[ptr].strip())
        ptr += 1
        tests = []
        for _ in range(N):
            if ptr >= len(input):
                break  # Handle unexpected EOF
            parts_line = input[ptr].strip()
            ptr += 1
            if not parts_line:
                continue
            i, j, k, r = map(int, parts_line.split())
            tests.append((i, j, k, r))
        pass_tests = [t for t in tests if t[3] == 1]
        fail_tests = [t for t in tests if t[3] == 0]
        total_parts = a + b + c
        parts = [2] * total_parts  # 0-based index for parts 1..total_parts
        # Process pass tests
        for test in pass_tests:
            i, j, k, _ = test
            for p in [i, j, k]:
                idx = p - 1
                if parts[idx] == 2:
                    parts[idx] = 1
        # Process fail tests iteratively
        changed = True
        while changed:
            changed = False
            for test in fail_tests:
                i, j, k, _ = test
                parts_in_test = [i, j, k]
                statuses = [parts[p - 1] for p in parts_in_test]
                count_1 = sum(1 for s in statuses if s == 1)
                if count_1 == 2:
                    for p in parts_in_test:
                        idx = p - 1
                        if parts[idx] == 2:
                            parts[idx] = 0
                            changed = True
                            break  # Only one can be 2 in this case
        # Output the results
        for part in range(1, total_parts + 1):
            print(parts[part - 1])

solve()
```

### Explanation
1. **Reading Input**: The input is read line by line, handling multiple datasets until the termination line (0 0 0) is encountered.
2. **Initialization**: An array `parts` is used to track the status of each part, initialized to 2 (undetermined).
3. **Processing Pass Tests**: For each pass test, the involved parts are marked as normal (1) if they were previously undetermined.
4. **Processing Fail Tests**: For each fail test, if exactly two parts are known to be normal, the third part is marked as faulty (0). This process is repeated until no more changes are detected.
5. **Output**: The status of each part is printed in the order of their part numbers, from 1 to the total number of parts.

This approach efficiently infers the status of parts using logical deductions from the test results, ensuring that all constraints are respected.
