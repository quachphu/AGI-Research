To solve this problem, we need to determine if a given rectangle with specified vertices lies entirely inside a circle defined by its radius and center. The solution involves checking if all vertices of the rectangle are within or on the circumference of the circle.

### Approach
1. **Input Reading**: Read the number of test cases. For each test case, read the circle's radius and center coordinates, followed by the coordinates of the four vertices of the rectangle.
2. **Distance Calculation**: For each vertex of the rectangle, compute the squared distance from the circle's center. This avoids floating-point operations and potential precision errors.
3. **Check Condition**: Verify if the squared distance of each vertex from the center is less than or equal to the square of the circle's radius. If all vertices satisfy this condition, the rectangle is inside the circle; otherwise, it is not.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        r = int(input[ptr])
        xc = int(input[ptr + 1])
        yc = int(input[ptr + 2])
        ptr += 3
        vs = []
        for _ in range(4):
            x = int(input[ptr])
            y = int(input[ptr + 1])
            vs.append((x, y))
            ptr += 2
        all_inside = True
        max_r_sq = r * r
        for (x, y) in vs:
            dx = x - xc
            dy = y - yc
            dist_sq = dx * dx + dy * dy
            if dist_sq > max_r_sq:
                all_inside = False
                break
        print("Yes" if all_inside else "No")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once using `sys.stdin.read()` for efficiency, especially with large input sizes. This splits the input into a list of strings for easy processing.
2. **Processing Each Test Case**: For each test case, the circle's radius and center coordinates are read first, followed by the four vertices of the rectangle.
3. **Distance Calculation**: For each vertex, the squared distance from the circle's center is computed. This avoids the computational cost and precision issues of square root operations.
4. **Checking All Vertices**: Each vertex is checked to ensure it lies within or on the circumference of the circle. If any vertex is outside, the result for that test case is "No"; otherwise, it is "Yes".

This approach ensures that the solution is both efficient and accurate, handling up to the maximum constraints effectively.
