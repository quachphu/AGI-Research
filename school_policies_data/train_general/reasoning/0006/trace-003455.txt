To solve this problem, we need to determine the winner of a knockout tournament based on given match results. The tournament structure ensures that each driver, except the final winner, loses exactly once. Our task is to identify the driver who never lost any match.

### Approach
1. **Input Reading**: Read the number of rounds (N) and the results of each match.
2. **Participant Collection**: Collect all drivers mentioned in the matches, either as winners or losers.
3. **Loser Tracking**: Track all drivers who lost at least one match.
4. **Determine Winner**: The winner is the driver who is present in the list of participants but not in the list of losers.

### Solution Code
```python
n = int(input())
matches = [input().split() for _ in range((1 << n) - 1)]

participants = set()
losers = set()

for winner, loser in matches:
    participants.add(winner)
    participants.add(loser)
    losers.add(loser)

winner = (participants - losers).pop()
print(winner)
```

### Explanation
1. **Reading Input**: The number of rounds (N) is read first. The number of matches is calculated as \(2^N - 1\), which is read next.
2. **Collecting Participants**: For each match, both the winner and loser are added to a set of participants to ensure we have all drivers.
3. **Tracking Losers**: Each loser from the matches is added to a separate set to track all drivers who lost at least once.
4. **Finding the Winner**: The winner is identified by finding the driver who is a participant but not in the set of losers. This is done using set difference, which gives the driver who never lost any match.

This approach efficiently narrows down the winner by leveraging set operations, ensuring optimal performance even for the upper constraint limits.
