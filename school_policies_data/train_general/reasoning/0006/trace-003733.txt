To solve this problem, we need to determine the minimum number of keyboards that were stolen from an electronics store after a heist. The remaining keyboards are given as input, and we need to calculate the smallest possible number of stolen keyboards based on the indices of the remaining ones.

### Approach
1. **Understanding the Problem**: The original sequence of keyboards in the store was consecutive and started from some integer `x`. After the heist, some keyboards are missing, and we need to find the minimum number of missing keyboards.
2. **Key Insight**: The minimum number of stolen keyboards occurs when the original sequence of keyboards is as tight as possible around the remaining keyboards. This means the original sequence starts at the minimum index of the remaining keyboards and ends at the maximum index of the remaining keyboards.
3. **Formula Derivation**: The total number of keyboards in the original sequence, if it starts at the minimum index and ends at the maximum index, would be `max_index - min_index + 1`. The number of stolen keyboards is then the difference between this total and the number of remaining keyboards.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
print(max(a) - min(a) + 1 - n)
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` (number of remaining keyboards) followed by `n` distinct integers representing the indices of the remaining keyboards.
2. **Calculating Min and Max**: We compute the minimum and maximum values from the list of remaining keyboard indices.
3. **Computing the Result**: The formula `max(a) - min(a) + 1 - n` gives the total number of keyboards that should have been present in the original sequence (from min to max) minus the number of remaining keyboards, which gives the minimum number of stolen keyboards.

This approach efficiently computes the result in linear time, O(n), where n is the number of remaining keyboards, making it suitable for large input sizes up to 1000.
