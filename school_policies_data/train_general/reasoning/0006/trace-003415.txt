To solve this problem, we need to determine the maximum steps one has to climb and descend when moving through a series of blocks arranged in a row. Each block has a specific height, and the goal is to calculate the maximum climb and descent required between consecutive blocks for each dataset provided.

### Approach
1. **Input Reading**: Read the number of datasets. For each dataset, read the number of blocks and their respective heights.
2. **Initialize Variables**: For each dataset, initialize two variables to keep track of the maximum climb and maximum descent.
3. **Iterate Through Blocks**: For each consecutive pair of blocks, compute the height difference. Update the maximum climb if the next block is higher, and update the maximum descent if the next block is lower.
4. **Output Results**: After processing all pairs of blocks in a dataset, output the maximum climb and maximum descent values.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    t = int(input[idx])
    idx += 1
    for _ in range(t):
        n = int(input[idx])
        idx += 1
        heights = list(map(int, input[idx:idx + n]))
        idx += n
        max_climb = 0
        max_descent = 0
        for i in range(n - 1):
            current = heights[i]
            next_h = heights[i + 1]
            diff = next_h - current
            if diff > 0:
                max_climb = max(max_climb, diff)
            else:
                descent = current - next_h
                max_descent = max(max_descent, descent)
        print(f"{max_climb} {max_descent}")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and split into a list of strings for efficient processing. This avoids the overhead of multiple read operations.
2. **Processing Each Dataset**: For each dataset, the number of blocks and their heights are extracted. The heights are processed in pairs to determine the height differences.
3. **Updating Climb and Descent Values**: For each pair of consecutive blocks, the difference in height is calculated. If the next block is higher, the climb value is updated. If the next block is lower, the descent value is updated.
4. **Output**: After processing all pairs in a dataset, the maximum climb and descent values are printed.

This approach ensures that each dataset is processed in linear time relative to the number of blocks, making the solution efficient and scalable for the given constraints.
