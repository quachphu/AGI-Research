To solve this problem, we need to determine the mode(s) of a sequence of integers. The mode is the number that appears most frequently. If there are multiple numbers with the same highest frequency, they should be printed in ascending order.

### Approach
1. **Read Input**: Read the sequence of integers from standard input.
2. **Count Frequencies**: Use a dictionary to count the occurrences of each integer in the sequence.
3. **Determine Maximum Frequency**: Identify the highest frequency of occurrence from the dictionary.
4. **Collect Modes**: Gather all integers that have the highest frequency.
5. **Sort and Output**: Sort the collected modes in ascending order and print each on a new line.

### Solution Code
```python
import sys

def main():
    numbers = list(map(int, sys.stdin.read().splitlines()))
    frequency = {}
    for num in numbers:
        frequency[num] = frequency.get(num, 0) + 1
    max_count = max(frequency.values()) if numbers else 0
    modes = [k for k, v in frequency.items() if v == max_count]
    modes.sort()
    for mode in modes:
        print(mode)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.read().splitlines()` which captures all lines of input and converts them into a list of integers.
2. **Counting Frequencies**: A dictionary (`frequency`) is used to keep track of how many times each integer appears in the input list.
3. **Finding Maximum Frequency**: The maximum value from the dictionary's values (frequencies) is determined using `max(frequency.values())`.
4. **Collecting Modes**: All keys (integers) in the dictionary that have the maximum frequency are collected into a list called `modes`.
5. **Sorting and Printing**: The modes are sorted in ascending order using `sort()` and each mode is printed on a new line.

This approach efficiently handles the input processing, frequency counting, and sorting to ensure the correct modes are identified and displayed in the required order.
