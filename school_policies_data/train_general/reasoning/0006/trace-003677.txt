To solve this problem, we need to determine the minimum amount of time AOR Ika gets wet while traveling from bus stop S to bus stop G using available bus routes. The goal is to minimize the time spent waiting for buses, as waiting time is when AOR Ika gets wet.

### Approach
1. **Problem Analysis**: The problem can be modeled as a shortest path problem where the edge weights represent the waiting time before catching a bus. Each bus route is a directed edge with a specific departure time and travel time. The key is to find the path from S to G that minimizes the total waiting time.

2. **Graph Representation**: Represent the bus stops and routes using an adjacency list. Each entry in the list contains the destination bus stop, departure time, and travel time for each route.

3. **Dijkstra's Algorithm**: Use a modified Dijkstra's algorithm to find the shortest path in terms of waiting time. The priority queue (min-heap) will store tuples of (total waiting time, current bus stop, arrival time at current stop). This helps in exploring the shortest waiting time paths first.

4. **Tracking Arrival Times**: Maintain a dictionary for each bus stop to track the minimum waiting time required to reach that stop at each possible arrival time. This helps in avoiding redundant processing of states with higher waiting times.

import heapq

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx]); idx +=1
    m = int(input[idx]); idx +=1
    s = int(input[idx]); idx +=1
    g = int(input[idx]); idx +=1

    if s == g:
        print(0)
        return

    adj = [[] for _ in range(n+1)]  # 1-based indexing
    for _ in range(m):
        u = int(input[idx]); idx +=1
        v = int(input[idx]); idx +=1
        t = int(input[idx]); idx +=1
        c = int(input[idx]); idx +=1
        adj[u].append( (v, t, c) )

    # Dijkstra's setup
    heap = []
    heapq.heappush(heap, (0, s, 0))
    arrival = [{} for _ in range(n+1)]  # arrival[u] maps arrival time to min cost
    arrival[s][0] = 0

    found = False
    while heap:
        cost, u, a = heapq.heappop(heap)
        if u == g:
            print(cost)
            found = True
            break
        # Skip if this state is outdated
        if a not in arrival[u] or arrival[u][a] < cost:
            continue
        # Explore all edges from u
        for edge in adj[u]:
            v, t_depart, c_travel = edge
            if t_depart < a:
                continue  # Can't catch this bus
            new_cost = cost + (t_depart - a)
            new_a = t_depart + c_travel
            # Check if this new state is better than existing ones for v
            if new_a in arrival[v]:
                if arrival[v][new_a] <= new_cost:
                    continue
            # Check if there's any a_prev in arrival[v] <= new_a with cost <= new_cost
            # This part is omitted for efficiency, relying on Dijkstra's property
            if new_a not in arrival[v] or new_cost < arrival[v].get(new_a, float('inf')):
                arrival[v][new_a] = new_cost
                heapq.heappush(heap, (new_cost, v, new_a))
    if not found:
        print(0)  # According to problem constraints, this case shouldn't occur

if __name__ == '__main__':
    main()
