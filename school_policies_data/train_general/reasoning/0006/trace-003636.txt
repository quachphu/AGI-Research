To solve this problem, we need to determine the minimal number of moves required to make a given sequence strictly increasing. Each move allows us to add a fixed value `d` to any element of the sequence.

### Approach
1. **Initialization**: Start by reading the input values for the sequence length `n`, the fixed increment value `d`, and the sequence itself.
2. **Iterate through the sequence**: For each element starting from the second one, check if it is greater than the previous element. If it is, move to the next element without any changes.
3. **Calculate required increments**: If the current element is not greater than the previous element, compute the minimum number of increments needed using the formula `(delta + d) // d`, where `delta` is the difference between the previous element and the current element. This formula ensures that the current element after increments is strictly greater than the previous element.
4. **Update the sequence**: Adjust the current element by adding the required increments and update the total number of moves.

### Solution Code
```python
n, d = map(int, input().split())
b = list(map(int, input().split()))

total = 0
prev = b[0]
for i in range(1, n):
    current = b[i]
    if current > prev:
        prev = current
        continue
    delta = prev - current
    required_k = (delta + d) // d
    total += required_k
    new_current = current + required_k * d
    prev = new_current

print(total)
```

### Explanation
- **Initialization**: The input values are read and stored in appropriate variables.
- **Iteration**: Starting from the second element, each element is compared with the previous element. If it is not greater, the required number of increments is calculated to make it greater.
- **Formula**: The formula `(delta + d) // d` efficiently computes the minimum number of increments needed by leveraging integer division to ensure the result is the ceiling value of the division.
- **Update**: After calculating the required increments, the current element is adjusted, and the total moves are updated accordingly.

This approach ensures that each element is processed in linear time, leading to an efficient solution with a time complexity of O(n), which is optimal for the given constraints.
