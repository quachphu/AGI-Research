To solve this problem, we need to determine the minimum possible width of a bookshelf that can accommodate all volumes of a novel in exactly `m` columns, with each column containing consecutive volumes ordered by their sequence. The goal is to minimize the maximum width of any column.

### Approach
1. **Problem Analysis**: The problem can be broken down into finding the optimal way to partition the sequence of book thicknesses into `m` columns such that the maximum sum of the thicknesses in any column is minimized. This is a classic optimization problem that can be efficiently solved using binary search combined with a greedy approach.

2. **Key Insight**: If we can determine the minimum possible maximum width (let's call it `mid`) for which it is feasible to split the books into `m` columns, we can use binary search to efficiently narrow down the optimal value of `mid`.

3. **Feasibility Check**: For a given `mid`, we check if we can partition the books into `m` columns such that the sum of the thicknesses in each column does not exceed `mid`. This is done using a greedy approach where we accumulate books into a column until adding the next book would exceed `mid`, at which point we start a new column.

4. **Edge Cases Handling**: If the number of columns `m` is greater than the number of books `n`, it is impossible to form `m` columns each with at least one book. In such cases, the solution is the maximum thickness of any single book since each book must be placed in its own column and the remaining columns will be empty (though the problem constraints ensure this case is handled correctly).

### Solution Code
```python
import sys

def main():
    while True:
        line = sys.stdin.readline()
        if not line:
            break
        m, n = map(int, line.strip().split())
        if m == 0 and n == 0:
            break
        w = []
        for _ in range(n):
            w.append(int(sys.stdin.readline()))
        if m > n:
            print(max(w))
            continue
        # Binary search between max(w) and sum(w)
        low = max(w)
        high = sum(w)
        answer = high
        while low <= high:
            mid = (low + high) // 2
            current_sum = 0
            groups = 1
            valid = True
            for num in w:
                if current_sum + num > mid:
                    groups += 1
                    current_sum = num
                    if current_sum > mid:
                        valid = False
                        break
                else:
                    current_sum += num
            if valid and groups <= m:
                answer = mid
                high = mid - 1
            else:
                low = mid + 1
        print(answer)

if __name__ == "__main__":
    main()
```

3. **Binary Search Setup**: The search range is initialized between the maximum book thickness (lower bound) and the sum of all book thicknesses (upper bound).
4. **Feasibility Check**: For each midpoint value in the binary search, the algorithm checks if the books can be partitioned into `m` columns such that each column's sum does not exceed the midpoint. This check is done using a greedy approach to accumulate books into columns.
5. **Adjusting Search Range**: Depending on whether the midpoint is feasible (i.e., the books can be partitioned into `m` columns), the search range is adjusted to narrow down the optimal solution.
