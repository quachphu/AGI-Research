To solve this problem, we need to determine the maximum number of children Santa can distribute candies to such that each child gets a distinct positive integer number of candies, and the total number of candies given out is exactly the number Santa has. 

### Approach
1. **Identify Maximum Number of Children**: The key insight is that the maximum number of children, \( k \), is the largest integer for which the sum of the first \( k \) natural numbers (1 + 2 + ... + k) does not exceed the total number of candies \( n \). This sum is given by the formula \( k(k + 1) / 2 \).

2. **Adjust for Exact Sum**: If the sum of the first \( k \) numbers equals \( n \), then those numbers are the solution. If the sum is less than \( n \), adjust the largest number (k) by the difference between \( n \) and the sum of the first \( k \) numbers to ensure the total sum is exactly \( n \).

### Solution Code
```python
n = int(input())

k = 0
total = 0

while True:
    next_k = k + 1
    next_total = total + next_k
    if next_total > n:
        break
    k = next_k
    total = next_total

sum_k = k * (k + 1) // 2

if sum_k == n:
    res = list(range(1, k + 1))
else:
    d = n - sum_k
    res = list(range(1, k)) + [k + d]

print(len(res))
print(' '.join(map(str, res)))
```

### Explanation
1. **Finding Maximum \( k \)**: We start with \( k = 0 \) and incrementally compute the sum of the first \( k \) numbers until the sum exceeds \( n \). This gives the maximum \( k \) for which the sum of the first \( k \) numbers is less than or equal to \( n \).

2. **Adjusting the Last Element**: If the sum of the first \( k \) numbers is exactly \( n \), the solution is the list of numbers from 1 to \( k \). If the sum is less than \( n \), the difference (denoted as \( d \)) is added to the largest number (k) to form the last element of the result list, ensuring the total sum is \( n \).

This approach efficiently determines the optimal distribution of candies while ensuring all numbers are distinct and the sum matches the given input exactly.
