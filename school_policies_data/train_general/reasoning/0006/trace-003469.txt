### Approach
1. **Reading Input**: The input consists of multiple lines where each line contains a student's attendance number and their blood type separated by a comma. We will read each line from standard input.
2. **Initializing Counters**: We use a dictionary to keep track of the counts for each blood type (A, B, AB, O), initializing each count to zero.
3. **Processing Each Line**: For each line read, we split the line by the comma to separate the attendance number from the blood type. We then increment the count for the corresponding blood type in our dictionary.
4. **Output Results**: After processing all input lines, we print the counts for each blood type in the order A, B, AB, O.

### Solution Code
```python
import sys

def count_blood_types():
    counts = {'A': 0, 'B': 0, 'AB': 0, 'O': 0}
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        _, blood_type = line.split(',')
        counts[blood_type] += 1
    print(counts['A'])
    print(counts['B'])
    print(counts['AB'])
    print(counts['O'])

count_blood_types()
```

### Explanation
1. **Reading Input**: The code reads each line from standard input using a loop over `sys.stdin`.
2. **Stripping and Splitting Lines**: Each line is stripped of leading/trailing whitespace and then split by the comma to separate the attendance number (which is ignored) from the blood type.
3. **Updating Counts**: The blood type extracted from each line is used to update the corresponding count in the dictionary.
4. **Output**: After processing all lines, the counts for each blood type are printed in the specified order (A, B, AB, O).

This approach efficiently processes each input line in linear time, ensuring that we handle up to the maximum number of students (50) without performance issues. The solution is straightforward and leverages Python's built-in capabilities for input handling and string manipulation.
