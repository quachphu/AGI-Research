To solve this problem, we need to simulate the behavior of the 'cd' and 'pwd' commands in a shell. The shell starts at the root directory, and each 'cd' command changes the current directory based on either an absolute or relative path. The 'pwd' command outputs the absolute path of the current directory.

### Approach
1. **Representation of Directories**: The current directory is represented as a list of directory names. The root directory is an empty list.
2. **Handling Commands**:
   - **pwd**: Outputs the absolute path by joining the directory names with slashes and appending a trailing slash.
   - **cd**: Processes the path to update the current directory. The path can be absolute (starting with '/') or relative. Absolute paths reset the current directory, while relative paths modify it.
3. **Path Processing**:
   - **Absolute Paths**: Split the path into components and process each component from the root.
   - **Relative Paths**: Split the path into components and process each component relative to the current directory. Components can be directory names or '..' to move up one directory.

### Solution Code
```python
import sys

def process_commands():
    n = int(sys.stdin.readline())
    current_dir = []
    for _ in range(n):
        line = sys.stdin.readline().strip()
        parts = line.split()
        if parts[0] == 'pwd':
            if not current_dir:
                print('/')
            else:
                print('/' + '/'.join(current_dir) + '/')
        else:
            path = parts[1]
            if path.startswith('/'):
                dir_parts = [p for p in path.split('/')[1:] if p]
                new_dir = []
                for part in dir_parts:
                    if part == '..':
                        if new_dir:
                            new_dir.pop()
                    else:
                        new_dir.append(part)
                current_dir = new_dir
            else:
                dir_parts = path.split('/')
                for part in dir_parts:
                    if part == '..':
                        if current_dir:
                            current_dir.pop()
                    else:
                        current_dir.append(part)

process_commands()
```

### Explanation
1. **Reading Input**: The number of commands is read first, followed by each command line.
2. **Current Directory Management**:
   - **pwd Command**: Constructs the path by joining directory names with slashes and ensuring it starts and ends with a slash.
   - **cd Command**:
     - **Absolute Path**: Splits the path, ignoring the leading slash, and processes each component from the root.
     - **Relative Path**: Splits the path and processes each component relative to the current directory. '..' moves up one directory, while other names move down into the specified directory.
3. **Efficiency**: The operations (appending, popping) on the list representing the current directory are efficient, ensuring the solution handles the maximum constraints smoothly.

This approach ensures that all commands are processed correctly, maintaining the correct directory structure and handling both absolute and relative paths as specified.
