To solve this problem, we need to determine if a given string contains all the vowels (a, e, i, o, u). The solution involves checking the presence of each vowel in the input string and outputting "YES" if all are present, otherwise "NO".

### Approach
1. **Input Reading**: Read the size of the string (though not directly necessary for the check) and the string itself.
2. **Vowel Set Check**: Convert the input string into a set of characters to efficiently check for the presence of each vowel. Using a set allows for O(1) average-time complexity for membership checks.
3. **Subset Verification**: Check if the set of vowels is a subset of the characters in the input string. If it is, print "YES"; otherwise, print "NO".

### Solution Code
```python
def main():
    n = int(input())
    s = input().strip()
    vowels = {'a', 'e', 'i', 'o', 'u'}
    if vowels.issubset(set(s)):
        print("YES")
    else:
        print("NO")

main()
```

### Explanation
1. **Reading Input**: The first input line gives the size of the string, which is read but not used further since we directly process the string. The second line is the string itself.
2. **Set Conversion**: Convert the input string into a set of characters to eliminate duplicates and allow efficient membership checks.
3. **Subset Check**: Use the `issubset` method to check if all vowels are present in the set of characters from the input string. This method efficiently checks if every element of the vowels set is present in the input set.

This approach ensures that we efficiently determine the presence of all vowels with an average time complexity of O(1) for each membership check, leading to an overall time complexity of O(n) where n is the length of the string. This is optimal for the given problem constraints.
