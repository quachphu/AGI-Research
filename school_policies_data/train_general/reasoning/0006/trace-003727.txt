To solve this problem, we need to determine if a player in COUNTER STRIKE is a Terrorist or a Counter Terrorist based on the number of distinct characters in their username. If the number of distinct characters is odd, the player is a Counter Terrorist; otherwise, they are a Terrorist.

### Approach
1. **Input Reading**: Read the number of test cases, followed by each username.
2. **Distinct Character Count**: For each username, convert the string into a set to automatically handle duplicate characters, then compute the length of the set.
3. **Odd/Even Check**: Check if the length of the set (number of distinct characters) is odd or even.
4. **Output Result**: Print "Counter Terrorist" if the count is odd, otherwise print "Terrorist".

### Solution Code
```python
import sys

def recognize_player():
    T = int(sys.stdin.readline())
    for _ in range(T):
        username = sys.stdin.readline().strip()
        distinct_count = len(set(username))
        if distinct_count % 2 == 1:
            print("Counter Terrorist")
        else:
            print("Terrorist")

recognize_player()
```

### Explanation
- **Reading Input**: The function reads the number of test cases `T` using `sys.stdin.readline()` for efficient input handling. Each subsequent line is processed as a username.
- **Set Conversion**: Converting the username string into a set removes any duplicate characters, allowing us to directly determine the number of unique characters using `len(set(username))`.
- **Odd/Even Check**: By checking if the count of distinct characters modulo 2 is 1 (odd) or 0 (even), we determine the player's role efficiently.
- **Output**: Based on the check, the appropriate result is printed for each test case.

This approach ensures that we handle even the maximum constraints efficiently, with a time complexity of O(n) per username, where n is the length of the username, due to the set conversion. This is optimal for the given problem constraints.
