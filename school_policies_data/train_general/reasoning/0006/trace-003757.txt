To solve this problem, we need to determine the number of greetings that are both palindromes and have a prime length. A palindrome reads the same forwards and backwards, and a prime number is a number greater than 1 that has no divisors other than 1 and itself.

### Approach
1. **Input Reading**: Read the number of greetings and the greetings themselves.
2. **Palindrome Check**: For each greeting, check if it is a palindrome by comparing the string with its reverse.
3. **Prime Length Check**: Check if the length of the greeting is a prime number.
4. **Count Valid Greetings**: Increment the count for each greeting that satisfies both conditions and print the result.

### Solution Code
```python
def is_prime(n):
    if n <= 1:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False
    max_divisor = int(n ** 0.5) + 1
    for i in range(3, max_divisor, 2):
        if n % i == 0:
            return False
    return True

def main():
    n = int(input())
    count = 0
    for _ in range(n):
        s = input().strip()
        if s == s[::-1] and is_prime(len(s)):
            count += 1
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prime Check Function**: The `is_prime` function checks if a number is prime by testing divisibility up to the square root of the number, which optimizes the check.
2. **Palindrome Check**: Each string is checked for being a palindrome by comparing it to its reverse using slicing (`s[::-1]`).
3. **Main Function**: The `main` function reads the input, processes each string to check the conditions, and counts how many strings meet both criteria. The result is printed at the end.

This approach efficiently combines checking for palindromes and prime lengths to solve the problem as required.
