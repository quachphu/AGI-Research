To solve this problem, we need to transform string A into string B using the minimum number of moves. Each move allows changing a subset of positions with the same character to a higher character. If it's impossible to transform A into B, we return -1.

### Approach
1. **Check for Impossibility**: If any character in A is greater than the corresponding character in B, it's impossible to transform A into B, so we return -1 immediately.
2. **Iterate Over Characters**: Process each character from 'a' to 't' (0 to 19 in ordinal values). For each character, determine the positions in A that need to be changed to reach the target character in B.
3. **Determine Minimum Steps**: For each character, find the minimum target character in B that the current positions need to be transformed into. This ensures that we can group as many positions as possible into a single move, minimizing the number of steps.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline().strip())
        A = list(sys.stdin.readline().strip())
        B = list(sys.stdin.readline().strip())
        
        possible = True
        for a, b in zip(A, B):
            if a > b:
                possible = False
                break
        if not possible:
            print(-1)
            continue
        
        # Convert to ordinal values (a=0, t=19)
        current_A = [ord(c) - ord('a') for c in A]
        B_ord = [ord(c) - ord('a') for c in B]
        steps = 0
        
        for x in range(20):  # Process from 'a' to 't'
            # Collect positions where current_A[i] == x and B_ord[i] > x
            indices = []
            for i in range(n):
                if current_A[i] == x and B_ord[i] > x:
                    indices.append(i)
            if not indices:
                continue
            
            # Find the minimal B_ord[i] among these positions
            min_b = min(B_ord[i] for i in indices)
            if min_b <= x:
                print(-1)
                possible = False
                break
            
            # Change all these positions to min_b
            for i in indices:
                current_A[i] = min_b
            steps += 1
        
        if not possible:
            continue
        
        # Verify if current_A matches B_ord
        if current_A == B_ord:
            print(steps)
        else:
            print(-1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Impossibility Check**: We first check if any character in A is greater than the corresponding character in B. If so, it's impossible to transform A into B, and we return -1.
2. **Character Processing**: We process each character from 'a' to 't'. For each character, we collect all positions in A that need to be changed to a higher character as per B.
3. **Transform Steps**: For each collected set of positions, we determine the minimum target character in B. We then transform all these positions to this target character in a single move. This ensures we use the minimum number of steps by grouping transformations efficiently.
4. **Verification**: After processing all characters, we verify if the transformed A matches B. If not, we return -1, otherwise, we return the number of steps taken.

This approach ensures that we efficiently group transformations to minimize the number of moves, adhering to the problem constraints and requirements.
