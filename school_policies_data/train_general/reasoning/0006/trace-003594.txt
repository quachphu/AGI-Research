To solve this problem, we need to determine the maximum total value of items the princess can smash during her tantrum, given that she can only take items from the leftmost or rightmost positions of each shelf. The solution involves dynamic programming to efficiently compute the optimal selection of items from the shelves.

### Approach

1. **Precompute Maximum Values for Each Shelf**: For each shelf, precompute the maximum possible value sum for taking exactly `k` items, where `k` ranges from 0 to the number of items on the shelf. This is done by considering all possible combinations of taking items from the left and right ends of the shelf.

2. **Dynamic Programming (Knapsack Problem)**: Use a dynamic programming approach to select the optimal number of items from each shelf such that the total number of items taken is exactly `m` and the total value is maximized. This is modeled as a knapsack problem where each shelf contributes a set of possible values for different numbers of items taken.

### Solution Code

```python
import sys

def main():
    n, m = map(int, sys.stdin.readline().split())
    shelves = []
    for _ in range(n):
        parts = list(map(int, sys.stdin.readline().split()))
        s = parts[1:]
        shelves.append(s)
    
    max_sums_list = []
    for s in shelves:
        l = len(s)
        prefix = [0] * (l + 1)
        for i in range(l):
            prefix[i+1] = prefix[i] + s[i]
        suffix = [0] * (l + 1)
        for i in range(l):
            suffix[i+1] = suffix[i] + s[l-1 - i]
        max_sum = [0] * (l + 1)
        for k in range(l + 1):
            current_max = 0
            for i in range(k + 1):
                j = k - i
                if j < 0 or i + j > l:
                    continue
                current = prefix[i] + suffix[j]
                if current > current_max:
                    current_max = current
            max_sum[k] = current_max
        max_sums_list.append(max_sum)
    
    dp = [-float('inf')] * (m + 1)
    dp[0] = 0
    for max_sum in max_sums_list:
        temp = [-float('inf')] * (m + 1)
        for j in range(m + 1):
            if dp[j] == -float('inf'):
                continue
            for k in range(len(max_sum)):
                if j + k > m:
                    continue
                if temp[j + k] < dp[j] + max_sum[k]:
                    temp[j + k] = dp[j] + max_sum[k]
        dp = temp
    
    print(dp[m])

if __name__ == "__main__":
    main()
```

### Explanation

1. **Precompute Maximum Values for Each Shelf**:
   - For each shelf, compute the prefix sums (sum of items from the left) and suffix sums (sum of items from the right).
   - For each possible number of items `k` (from 0 to the length of the shelf), determine the maximum value by considering all possible splits of taking `i` items from the left and `k-i` items from the right.

2. **Dynamic Programming**:
   - Initialize a DP array where `dp[j]` represents the maximum value achievable by taking exactly `j` items.
   - For each shelf, update the DP array by considering all possible numbers of items that can be taken from the current shelf and updating the DP values accordingly.
   - The final result is the value in `dp[m]`, which represents the maximum value of taking exactly `m` items from all shelves.

This approach efficiently combines the precomputed maximum values from each shelf with dynamic programming to solve the problem within feasible time complexity.
