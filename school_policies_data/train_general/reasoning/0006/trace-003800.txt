To solve this problem, we need to determine if a flea, starting at one of the hassocks arranged in a circle, will eventually visit all hassocks given its specific jumping pattern. The key insight is to recognize that the flea's movement forms a sequence that covers all positions if and only if the number of hassocks is a power of two.

### Approach
The flea's position after `k` minutes is given by the sum of the first `k` jumps modulo `n`. This sum can be represented as `k(k-1)/2` modulo `n`. The problem reduces to checking whether this sequence covers all residues modulo `n`. Through analysis, we find that this happens if and only if `n` is a power of two. This is because the sequence of sums modulo a power of two will eventually cover all residues, while for other numbers, there will be gaps.

### Solution Code
```python
n = int(input())
if (n & (n - 1)) == 0:
    print("YES")
else:
    print("NO")
```

1. **Check for Power of Two**: The function checks if `n` is a power of two using a bitwise operation. A number `n` is a power of two if and only if it has exactly one bit set in its binary representation. This can be checked using the expression `(n & (n - 1)) == 0`.
2. **Output Result**: If `n` is a power of two, the flea will visit all hassocks, so we print "YES". Otherwise, we print "NO".

This approach efficiently determines the result in constant time, O(1), making it very fast even for the upper limit of the input constraint.
