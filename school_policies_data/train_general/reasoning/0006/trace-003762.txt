To solve this problem, we need to determine the number of ways to select at least one city from a list of `n` cities for multiple test cases. The solution must be efficient given the constraints.

### Approach
The problem can be translated into a mathematical formula. For each city, there are two choices: either it is selected or not. Thus, the total number of subsets of cities is \(2^n\). Since we need at least one city, we subtract 1 to exclude the empty subset. The result is \(2^n - 1\). 

Given the constraints where \(n\) can be as large as \(10^{12}\) and there can be up to \(10^5\) test cases, we need an efficient way to compute \(2^n \mod (10^9 + 7)\). Python's built-in `pow` function with three arguments (base, exponent, modulus) efficiently handles large exponents using modular exponentiation, which runs in \(O(\log n)\) time.

### Solution Code
```python
import sys

MOD = 10**9 + 7

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        result = (pow(2, n, MOD) - 1) % MOD
        print(result)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The code reads all input at once using `sys.stdin.readline()` to handle up to \(10^5\) test cases efficiently.
2. **Modular Exponentiation**: For each test case, the code computes \(2^n \mod (10^9 + 7)\) using Python's `pow` function, which efficiently handles large exponents.
3. **Adjusting the Result**: After computing \(2^n \mod (10^9 + 7)\), we subtract 1 and take the modulus again to ensure the result is non-negative.

This approach ensures that each test case is processed in \(O(\log n)\) time, making the solution efficient and scalable for the given constraints.
