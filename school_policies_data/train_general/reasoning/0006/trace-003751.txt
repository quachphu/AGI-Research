To solve this problem, we need to determine if it's possible to make all elements of an array equal by adding an integer x to some elements, subtracting x from others, or leaving some elements unchanged. The key insight is that the distinct elements in the array must form a specific pattern that allows them to be adjusted to a common value using a single x.

### Approach
1. **Identify Unique Elements**: First, we collect all unique elements from the array.
2. **Check Element Count**: If there are more than three unique elements, it's impossible to adjust them using a single x, so the answer is "NO".
3. **Handle Cases with Fewer Elements**:
   - If there is only one unique element, all elements are already equal, so the answer is "YES".
   - If there are two unique elements, they can always be adjusted to a common value using an appropriate x, so the answer is "YES".
4. **Check Arithmetic Progression for Three Elements**: If there are exactly three unique elements, they must form an arithmetic progression (i.e., the middle element is the average of the other two). If they do, the answer is "YES"; otherwise, it's "NO".

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    unique = sorted(list(set(a)))
    if len(unique) > 3:
        print("NO")
    else:
        if len(unique) <= 2:
            print("YES")
        else:
            if unique[2] - unique[1] == unique[1] - unique[0]:
                print("YES")
            else:
                print("NO")

solve()
```

### Explanation
- **Reading Input**: The input is read all at once and split into a list of integers. The first integer is the number of elements, followed by the elements themselves.
- **Unique Elements**: The unique elements are extracted and sorted.
- **Decision Logic**:
  - If there are more than three unique elements, print "NO".
  - If there are one or two unique elements, print "YES".
  - For three unique elements, check if they form an arithmetic progression. If they do, print "YES"; otherwise, print "NO".

This approach efficiently handles the problem constraints and ensures that we check the necessary conditions to determine if the array can be adjusted to have all elements equal using a single integer x.
