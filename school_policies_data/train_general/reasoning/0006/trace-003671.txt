To solve this problem, we need to determine if Jerry can trail a piece of cheese shaped like a rectangular prism through various circular holes in his house. The solution involves checking if the smallest possible cross-section of the cheese can fit through each hole without touching the edges.

### Approach
1. **Understanding the Problem**: The cheese has dimensions A, B, and C. Each hole has a radius R. The cheese can fit through a hole if the smallest diagonal of any face of the cheese is less than the diameter of the hole (2R). The smallest diagonal of any face of the cheese is determined by the two smallest dimensions of the cheese.

2. **Sorting Dimensions**: First, we sort the dimensions of the cheese in non-decreasing order. This helps in easily identifying the two smallest dimensions, which form the face with the smallest diagonal.

3. **Calculate the Minimal Diagonal**: Using the two smallest dimensions, compute the diagonal of the face they form. This is done using the Pythagorean theorem: \( \text{diagonal} = \sqrt{x^2 + y^2} \), where x and y are the two smallest dimensions.

4. **Check Each Hole**: For each hole's radius R, check if the diameter (2R) is strictly greater than the computed diagonal. If it is, the cheese can pass through the hole without touching it; otherwise, it cannot.

### Solution Code
```python
import math
import sys

def main():
    for line in sys.stdin:
        A, B, C = map(int, line.strip().split())
        if A == 0 and B == 0 and C == 0:
            break
        x, y, z = sorted([A, B, C])
        diag = math.hypot(x, y)
        n = int(sys.stdin.readline())
        for _ in range(n):
            R = float(sys.stdin.readline().strip())
            if 2 * R > diag:
                print("OK")
            else:
                print("NA")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read line by line from standard input. Each dataset starts with three integers A, B, and C, followed by the number of holes and their respective radii.
2. **Sorting Dimensions**: The dimensions of the cheese are sorted to easily find the two smallest dimensions.
3. **Computing the Diagonal**: The diagonal of the face formed by the two smallest dimensions is computed using `math.hypot`, which calculates the Euclidean norm (sqrt(x² + y²)).
4. **Checking Each Hole**: For each radius, the code checks if twice the radius (diameter) is greater than the computed diagonal. The result for each hole is printed immediately.

This approach ensures that we efficiently determine if each hole is suitable for the cheese to pass through, adhering to the problem constraints and requirements.
