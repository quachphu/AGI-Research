To solve this problem, we need to determine the average total distance Iahub would walk when visiting all destinations in any possible order. The solution involves calculating the average distance efficiently using mathematical insights and avoiding brute force enumeration of all permutations.

### Approach
1. **Understanding the Problem**: The total distance Iahub walks is the sum of the distances from the starting point to the first destination and the distances between consecutive destinations in the chosen order. The average distance is computed over all possible permutations of the destinations.

2. **Mathematical Insight**:
   - **First Term**: The average distance from the starting point (0) to the first destination in any permutation is the average of all destination distances.
   - **Consecutive Pairs**: For each pair of destinations, the average contribution of their absolute difference over all permutations can be computed using combinatorial analysis.

3. **Efficient Calculation**:
   - **Sum of Absolute Differences**: By sorting the destinations, we can efficiently compute the sum of absolute differences for all pairs using prefix sums, which reduces the complexity from O(n^2) to O(n log n).

### Solution Code
```python
import sys
import math

def main():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    a.sort()
    
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i+1] = prefix[i] + a[i]
    
    sum_pairs = 0
    for i in range(n):
        sum_pairs += a[i] * i - prefix[i]
    
    sum_a = sum(a)
    numerator = sum_a + 2 * sum_pairs
    denominator = n
    
    g = math.gcd(numerator, denominator)
    print(f"{numerator // g} {denominator // g}")

main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of destinations `n` and the list of destination distances `a`.

2. **Sorting**: The destinations are sorted to facilitate efficient calculation of the sum of absolute differences between all pairs.

3. **Prefix Sum Calculation**: A prefix sum array is built to quickly compute the sum of distances up to any point, which helps in calculating the sum of absolute differences efficiently.

4. **Sum of Absolute Differences**: Using the sorted list and prefix sums, the sum of absolute differences for all pairs is computed in linear time.

5. **Final Calculation**: The average distance is derived by combining the average of the first term (sum of all distances divided by `n`) and twice the sum of absolute differences divided by `n`.

6. **Reducing the Fraction**: The result is presented as a reduced fraction by dividing the numerator and denominator by their greatest common divisor (GCD).

This approach ensures the solution is efficient and handles the constraints effectively.
