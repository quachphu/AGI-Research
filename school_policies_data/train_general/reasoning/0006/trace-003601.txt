To solve this problem, we need to split a given string into exactly `k` parts such that each part starts with a distinct character. If such a split is possible, we should output the parts; otherwise, we should indicate that it's impossible.

### Approach
1. **Check Length Constraint**: If the length of the string is less than `k`, it's impossible to split the string into `k` parts, each of at least one character. Hence, we immediately return "NO".
2. **Track Split Points**: We need to identify the starting indices of each part such that each part starts with a unique character. We start by initializing the first split point at index 0 (the beginning of the string).
3. **Collect Unique Characters**: As we iterate through the string, we collect indices where new unique characters start. These indices form our split points.
4. **Validate Split Points**: If we collect exactly `k` split points, we can split the string accordingly. If not, it's impossible to form the required parts, and we return "NO".
