To solve this problem, we need to determine the result of a vote based on the number of upvotes, downvotes, and unknown votes. The result can be certain (either "+", "-", or "0") or uncertain ("?"), depending on how the unknown votes might be split between upvotes and downvotes.

### Approach
1. **Understand the Problem**: We need to determine the result of the vote considering all possible splits of the unknown votes between upvotes and downvotes.
2. **Key Insight**: The unknown votes can affect the outcome by changing the difference between upvotes and downvotes. We need to check the extreme cases where all unknown votes are either upvotes or downvotes to determine the possible range of outcomes.
3. **Calculate Extremes**:
   - **Minimum Difference**: When all unknown votes are downvotes.
   - **Maximum Difference**: When all unknown votes are upvotes.
4. **Determine Result**:
   - If all possible splits result in a positive difference, the result is "+".
   - If all possible splits result in a negative difference, the result is "-".
   - If all possible splits result in a zero difference, the result is "0".
   - If the range of possible differences includes both positive and negative values (or zero and non-zero), the result is uncertain ("?").

### Solution Code
```python
x, y, z = map(int, input().split())
min_diff = x - y - z
max_diff = x - y + z

if min_diff > 0:
    print('+')
elif max_diff < 0:
    print('-')
elif min_diff == 0 and max_diff == 0:
    print('0')
else:
    print('?')
```

### Explanation
1. **Input Reading**: The code reads three integers representing the number of upvotes, downvotes, and unknown votes.
2. **Calculate Extremes**:
   - `min_diff` is the difference if all unknown votes are downvotes.
   - `max_diff` is the difference if all unknown votes are upvotes.
3. **Result Determination**:
   - If `min_diff` is positive, all splits result in more upvotes.
   - If `max_diff` is negative, all splits result in more downvotes.
   - If both `min_diff` and `max_diff` are zero, the result is a tie.
   - Otherwise, the result is uncertain as there are multiple possible outcomes.

This approach efficiently checks the extreme cases to determine the result without explicitly iterating through all possible splits of the unknown votes, ensuring optimal performance.
