To solve this problem, we need to determine the number of divisors of a given integer \( x \) that share at least one common digit with \( x \). 

### Approach
1. **Generate Divisors**: Efficiently generate all divisors of \( x \) by iterating up to the square root of \( x \). For each divisor \( i \), both \( i \) and \( x/i \) are added to the list of divisors.
2. **Check Common Digits**: For each divisor, check if it shares any digit with \( x \) by converting both numbers to strings and comparing their digit sets.

### Solution Code
```python
import math

x = int(input())
s_x = set(str(x))

divisors = set()
for i in range(1, int(math.sqrt(x)) + 1):
    if x % i == 0:
        divisors.add(i)
        divisors.add(x // i)

count = 0
for d in divisors:
    if set(str(d)) & s_x:
        count += 1

print(count)
```

### Explanation
1. **Input Handling**: The input integer \( x \) is read and converted into a set of its digits for quick lookup.
2. **Divisor Generation**: By iterating from 1 to the square root of \( x \), we efficiently find all divisors. Each divisor \( i \) and \( x/i \) are added to a set to avoid duplicates.
3. **Digit Comparison**: For each divisor, convert it to a string and check if its digit set intersects with the digit set of \( x \). If there is an intersection, the divisor is counted.

This approach ensures that we efficiently generate divisors and check for common digits using set operations, leading to an optimal solution for the given problem constraints.
