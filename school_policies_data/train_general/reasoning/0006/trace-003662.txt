To solve this problem, we need to count the number of integers in a given interval [L, R] that are divisible by at least one of the provided prime numbers. Given the constraints, a direct approach of checking each number in the interval is infeasible due to the potential size of the interval (up to 10^18). Instead, we use the inclusion-exclusion principle to efficiently compute the result.

### Approach
1. **Inclusion-Exclusion Principle**: This principle allows us to count the union of multiple sets by adding the sizes of individual sets, subtracting the sizes of all pairwise intersections, adding back the sizes of all triple intersections, and so on. This alternates signs based on the subset size.
2. **Subset Generation**: For each test case, generate all non-empty subsets of the given primes. For each subset, compute the product of the primes (since primes are distinct, the product is their LCM).
3. **Divisibility Check**: For each subset's product, determine how many numbers in the interval [L, R] are divisible by this product. This is done using integer division.
4. **Early Termination**: If the product of a subset exceeds R, further multiplication is unnecessary as it won't contribute to the count.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        L = int(input[ptr + 1])
        R = int(input[ptr + 2])
        ptr += 3
        primes = list(map(int, input[ptr:ptr + N]))
        ptr += N
        total = 0
        # Generate all non-empty subsets using bitmask
        for mask in range(1, 1 << N):
            # Collect primes in the subset
            product = 1
            subset_size = 0
            overflow = False
            for i in range(N):
                if mask & (1 << i):
                    subset_size += 1
                    p = primes[i]
                    product *= p
                    if product > R:
                        overflow = True
                        break
            if overflow:
                continue
            # Calculate count of numbers divisible by 'product' in [L, R]
            cnt = R // product - (L - 1) // product
            # Apply inclusion-exclusion
            if subset_size % 2 == 1:
                total += cnt
            else:
                total -= cnt
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Bitmasking for Subsets**: Each bitmask represents a subset of primes. For example, a bitmask `0b101` represents the subset containing the first and third primes.
3. **Product Calculation**: For each subset, compute the product of its primes. If the product exceeds R during calculation, the subset is skipped early to save computation.
4. **Divisibility Count**: Using integer division, the count of numbers in [L, R] divisible by the product is calculated. This is adjusted by the inclusion-exclusion principle based on subset size.
5. **Efficiency**: The approach efficiently handles large intervals by leveraging mathematical properties and early termination of irrelevant subsets.

This method ensures we handle up to the maximum constraints efficiently, avoiding the need to iterate through each number in potentially enormous intervals.
