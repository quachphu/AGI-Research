To solve this problem, we need to determine if a given angle can form the internal angle of a regular polygon. The solution involves checking if the angle can be derived from the formula for the internal angles of regular polygons.

### Approach
1. **Understanding the Formula**: The internal angle of a regular polygon with \( n \) sides is given by \( \frac{(n-2) \times 180}{n} \) degrees. Rearranging this formula, we find that \( n = \frac{360}{180 - a} \), where \( a \) is the given angle.
2. **Check Divisibility**: For \( n \) to be a valid number of sides, it must be an integer. This means \( 360 \) must be divisible by \( 180 - a \).
3. **Minimum Sides Check**: A polygon must have at least 3 sides, so \( n \) must be at least 3.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    for a_str in input[1:t+1]:
        a = int(a_str)
        denominator = 180 - a
        if denominator > 0 and 360 % denominator == 0:
            n = 360 // denominator
            if n >= 3:
                print("YES")
            else:
                print("NO")
        else:
            print("NO")

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings for easier processing.
2. **Loop Through Test Cases**: For each test case, convert the angle to an integer and compute the denominator \( 180 - a \).
3. **Divisibility Check**: Check if \( 360 \) is divisible by the computed denominator. If it is, compute \( n \) and ensure it is at least 3.
4. **Output Result**: Print "YES" if both conditions are met, otherwise print "NO".

This approach efficiently checks each angle using mathematical properties of regular polygons, ensuring correctness and optimal performance.
