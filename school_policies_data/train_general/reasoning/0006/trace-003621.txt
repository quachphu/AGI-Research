To solve this problem, we need to form N teams from 3N participants such that the sum of the second largest strengths of each team is maximized. The solution involves sorting the strengths and strategically selecting the elements to form the optimal teams.

### Approach
1. **Sort the Strengths**: First, sort the list of participant strengths in ascending order.
2. **Select Optimal Elements**: After sorting, the optimal second largest elements for the teams can be found at specific positions. These positions are determined by starting from the second last element in the sorted list and selecting every second element moving backwards. Specifically, we select elements from indices `3N-2`, `3N-4`, ..., down to `N` (0-based indexing).

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
a.sort()
total = 0
for i in range(n):
    idx = (3 * n - 2) - 2 * i
    total += a[idx]
print(total)
```

### Explanation
1. **Sorting**: By sorting the strengths in ascending order, we can easily access the largest elements from the end of the list.
2. **Optimal Selection**: The key insight is that the second largest element in each team can be maximized by selecting every second element starting from the second last element in the sorted list. This ensures that each selected element is the second largest in its respective team, formed with two larger elements from the sorted list.
3. **Summation**: Summing these selected elements gives the maximum possible sum of the second largest strengths of the teams.

This approach efficiently computes the solution in O(N log N) time due to sorting, which is optimal given the constraints.
