To solve this problem, we need to determine the minimum number of new one-way roads required to make all cities reachable from the capital city in a directed graph. The solution involves analyzing the graph's structure using strongly connected components (SCCs) and then determining the optimal edges to add.

### Approach
1. **Identify SCCs**: Use Kosaraju's algorithm to decompose the graph into SCCs. Each SCC is a maximal subgraph where every node is reachable from every other node within the SCC.
2. **Condense the Graph**: Convert the original graph into a Directed Acyclic Graph (DAG) of SCCs. Each node in this DAG represents an SCC from the original graph.
3. **Determine Reachability**: Identify which SCCs are reachable from the SCC containing the capital city using BFS/DFS.
4. **Analyze Unreachable Components**: For the SCCs that are not reachable from the capital's SCC, form a sub-DAG and calculate the in-degrees of each node in this sub-DAG.
5. **Count Sources in Sub-DAG**: The minimum number of new roads required is equal to the number of source nodes (nodes with zero in-degree) in the sub-DAG of unreachable SCCs. Each source node needs one new road from the reachable part of the graph.

### Solution Code
```python
from collections import defaultdict, deque

def kosaraju(n, adj):
    visited = [False] * (n + 1)
    order = []

    def dfs(u):
        stack = [(u, False)]
        while stack:
            node, processed = stack.pop()
            if processed:
                order.append(node)
                continue
            if visited[node]:
                continue
            visited[node] = True
            stack.append((node, True))
            for v in adj[node]:
                if not visited[v]:
                    stack.append((v, False))

    for u in range(1, n + 1):
        if not visited[u]:
            dfs(u)

    order.reverse()

    reversed_adj = [[] for _ in range(n + 1)]
    for u in range(1, n + 1):
        for v in adj[u]:
            reversed_adj[v].append(u)

    visited = [False] * (n + 1)
    components = [0] * (n + 1)
    current_component = 0

    def reverse_dfs(u, label):
        stack = [u]
        visited[u] = True
        components[u] = label
        while stack:
            node = stack.pop()
            for v in reversed_adj[node]:
                if not visited[v]:
                    visited[v] = True
                    components[v] = label
                    stack.append(v)

    for u in order:
        if not visited[u]:
            current_component += 1
            reverse_dfs(u, current_component)

    return components, current_component

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    m = int(input[idx])
    idx += 1
    s = int(input[idx])
    idx += 1

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(input[idx])
        idx += 1
        v = int(input[idx])
        idx += 1
        adj[u].append(v)

    components, num_components = kosaraju(n, adj)
    s_comp = components[s]

    condensed_adj = defaultdict(set)
    for u in range(1, n + 1):
        for v in adj[u]:
            cu = components[u]
            cv = components[v]
            if cu != cv:
                condensed_adj[cu].add(cv)

    reachable_components = set()
    q = deque()
    q.append(s_comp)
    reachable_components.add(s_comp)

    while q:
        u = q.popleft()
        for v in condensed_adj.get(u, set()):
            if v not in reachable_components:
                reachable_components.add(v)
                q.append(v)

    unreachable = [c for c in range(1, num_components + 1) if c not in reachable_components]
    if not unreachable:
        print(0)
        return

    sub_dag_in_degree = {c: 0 for c in unreachable}
    unreachable_set = set(unreachable)
    for u in unreachable:
        for v in condensed_adj.get(u, set()):
            if v in unreachable_set:
                sub_dag_in_degree[v] += 1

    count = sum(1 for c in unreachable if sub_dag_in_degree[c] == 0)
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Kosaraju's Algorithm**: This algorithm is used to find SCCs by performing two passes of DFS. The first pass records nodes in the order of their completion, and the second pass processes nodes in reverse order on the reversed graph to identify SCCs.
2. **Condensed DAG**: After identifying SCCs, the original graph is condensed into a DAG where each node represents an SCC. This helps in analyzing reachability and dependencies between components.
3. **Reachability Check**: Using BFS/DFS from the SCC containing the capital, we determine which SCCs are reachable.
4. **Sub-DAG Analysis**: For unreachable SCCs, we form a sub-DAG and count the in-degrees of each node. The number of sources (nodes with zero in-degree) in this sub-DAG gives the minimum number of new roads needed, as each source requires one road to connect it to the reachable part of the graph.
