To solve this problem, we need to determine if two lines, defined by points AB and CD, are parallel. This involves checking if their direction vectors are scalar multiples of each other, which can be efficiently determined using the cross product of the vectors. 

### Approach
1. **Input Reading**: Read the number of datasets and each dataset's coordinates.
2. **Direction Vectors**: Compute the direction vectors for lines AB and CD.
3. **Zero Vectors Check**: Check if either direction vector is a zero vector (i.e., both points defining the line are the same). If both are zero vectors, the lines are considered parallel. If only one is a zero vector, they are not parallel.
4. **Cross Product Calculation**: If neither direction vector is a zero vector, compute the cross product. If the cross product is close to zero (within a small tolerance to handle floating-point precision issues), the lines are parallel.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().splitlines()
    n = int(input[0])
    epsilon = 1e-9
    for line in input[1:n+1]:
        parts = list(map(float, line.strip().split()))
        x1, y1, x2, y2, x3, y3, x4, y4 = parts
        dx1 = x2 - x1
        dy1 = y2 - y1
        dx2 = x4 - x3
        dy2 = y4 - y3
        ab_zero = abs(dx1) <= epsilon and abs(dy1) <= epsilon
        cd_zero = abs(dx2) <= epsilon and abs(dy2) <= epsilon
        if ab_zero:
            print("YES" if cd_zero else "NO")
        elif cd_zero:
            print("NO")
        else:
            cross = dx1 * dy2 - dy1 * dx2
            print("YES" if abs(cross) < epsilon else "NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into lines for processing. The first line gives the number of datasets.
2. **Processing Each Dataset**: For each dataset, extract the coordinates of points A, B, C, and D.
3. **Direction Vectors**: Calculate the direction vectors for lines AB and CD by subtracting the coordinates of their respective points.
4. **Zero Vector Check**: Check if either direction vector is a zero vector using a small tolerance (epsilon) to handle floating-point precision.
5. **Cross Product Calculation**: If both vectors are non-zero, compute their cross product. If the absolute value of the cross product is below the tolerance, the vectors are parallel, and we print "YES"; otherwise, we print "NO".

This approach efficiently handles all edge cases, including when the lines are defined by identical points, ensuring accurate results even with floating-point arithmetic.
