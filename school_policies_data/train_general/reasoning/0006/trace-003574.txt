To solve this problem, we need to determine the difference between the largest and smallest integers that can be formed by rearranging 8 given digits for each dataset. The solution involves sorting the digits to form the smallest and largest possible numbers and then computing their difference.

### Approach
1. **Reading Input:** The input consists of multiple datasets. The first line specifies the number of datasets. Each subsequent line contains 8 digits.
2. **Forming the Smallest Number:** Sort the digits in ascending order and concatenate them to form the smallest possible integer. Leading zeros are allowed but will be ignored when converting to an integer, which is handled correctly by converting the sorted string to an integer.
3. **Forming the Largest Number:** Sort the digits in descending order and concatenate them to form the largest possible integer.
4. **Computing the Difference:** Subtract the smallest integer from the largest integer and print the result for each dataset.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    for data in input[1:n+1]:
        digits = list(data)
        min_num = int(''.join(sorted(digits)))
        max_num = int(''.join(sorted(digits, reverse=True)))
        print(max_num - min_num)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input:** The input is read all at once and split into a list of strings. The first element is the number of datasets, and the subsequent elements are the datasets themselves.
2. **Sorting for Smallest Number:** Each dataset is converted into a list of characters (digits), sorted in ascending order, joined into a string, and converted to an integer. This effectively forms the smallest possible number, ignoring leading zeros in the integer conversion.
3. **Sorting for Largest Number:** Similarly, the digits are sorted in descending order, joined into a string, and converted to an integer to form the largest possible number.
4. **Difference Calculation:** The difference between the largest and smallest numbers is computed and printed for each dataset.

This approach efficiently handles all edge cases, including leading zeros and all zeros, by leveraging string sorting and integer conversion to correctly compute the required values.
