To solve this problem, we need to determine the maximum number of edges that can be added to a graph while ensuring it remains stable. A stable graph is defined as one where government nodes (k specified nodes) are in separate connected components with no path between them.

### Approach
1. **Identify Connected Components**: First, we identify all connected components in the given graph. Each component is either a government component (contains at least one government node) or a non-government component (contains no government nodes).

2. **Merge Non-Government Components**: To maximize the number of edges, we merge all non-government components into the largest existing government component. This is because merging into the largest component maximizes the number of possible edges due to the combinatorial nature of edge formation.

3. **Calculate Maximum Edges**: After merging, calculate the maximum possible edges for each government component using the formula \( \frac{s(s-1)}{2} \) where \( s \) is the size of the component. Subtract the original number of edges \( m \) from the total possible edges to get the answer.

### Solution Code
```python
import sys
from collections import deque

def main():
    n, m, k = map(int, sys.stdin.readline().split())
    c = list(map(int, sys.stdin.readline().split()))
    edges = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, sys.stdin.readline().split())
        edges[u].append(v)
        edges[v].append(u)
    
    visited = [False] * (n + 1)
    components = []
    for i in range(1, n + 1):
        if not visited[i]:
            q = deque()
            q.append(i)
            visited[i] = True
            component = []
            while q:
                u = q.popleft()
                component.append(u)
                for v in edges[u]:
                    if not visited[v]:
                        visited[v] = True
                        q.append(v)
            components.append(component)
    
    gov_components = []
    non_gov_components = []
    c_set = set(c)
    for comp in components:
        is_gov = False
        for node in comp:
            if node in c_set:
                is_gov = True
                break
        if is_gov:
            gov_components.append(comp)
        else:
            non_gov_components.append(comp)
    
    gov_sizes = [len(comp) for comp in gov_components]
    non_gov_total = sum(len(comp) for comp in non_gov_components)
    
    if gov_sizes:
        max_size = max(gov_sizes)
        gov_sizes.remove(max_size)
        gov_sizes.append(max_size + non_gov_total)
    
    total = sum(s * (s - 1) // 2 for s in gov_sizes)
    print(total - m)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed to get the number of nodes, edges, and government nodes. The edges are stored in an adjacency list.

2. **Finding Connected Components**: Using BFS, we traverse the graph to find all connected components. Each component is checked to see if it contains a government node.

3. **Separating Components**: Components are classified into government and non-government components based on the presence of government nodes.

4. **Merging Components**: Non-government components are merged into the largest government component to maximize the possible edges.

5. **Calculating Maximum Edges**: The maximum number of edges each component can have is calculated and summed up. The original number of edges is subtracted to get the result, which is printed.

This approach ensures that the graph remains stable while maximizing the number of edges added.
