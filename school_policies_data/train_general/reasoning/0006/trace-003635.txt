2. **Pattern Recognition**: For even values of n, the number of ways to fill the grid follows a pattern where each even increment of n doubles the number of ways. This can be expressed using powers of 2.
3. **Mathematical Insight**: The number of ways to fill a 3×n grid for even n is given by \(2^{(n/2)}\). This is derived from the observation that each increment of 2 in n (i.e., each additional pair of columns) doubles the number of valid configurations.

def main():
