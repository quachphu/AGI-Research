### Approach
1. **Special Case for \( k = 0 \)**:
   - When \( k = 0 \), the problem reduces to finding the smallest number with a digit sum of \( n \). This can be constructed by using as many 9s as possible followed by the remainder (if any).

2. **Precomputation for \( k > 0 \)**:
   - Precompute the sum of digits for all numbers up to \( 10^6 + 10 \) to efficiently calculate the sum of digits for any range of numbers.
   - Use prefix sums to quickly compute the sum of digits for the range \( x \) to \( x + k \).

3. **Brute Force Search**:
   - For \( k > 0 \), iterate through possible values of \( x \) up to \( 10^6 \) and use the precomputed values to check if the sum of digits from \( x \) to \( x + k \) equals \( n \).

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    t = int(input[idx])
    idx += 1

    max_limit = 10**6 + 10
    digit_sums = [0] * (max_limit + 1)
    for i in range(max_limit + 1):
        x = i
        s = 0
        while x > 0:
            s += x % 10
            x = x // 10
        digit_sums[i] = s

    prefix = [0] * (max_limit + 2)
    for i in range(1, max_limit + 2):
        prefix[i] = prefix[i-1] + digit_sums[i-1]

    results = []
    for _ in range(t):
        n = int(input[idx])
        k_val = int(input[idx + 1])
        idx += 2

        if k_val == 0:
            if n == 0:
                results.append(0)
            else:
                remainder = n % 9
                if remainder == 0:
                    s = '9' * (n // 9)
                else:
                    s = str(remainder) + '9' * (n // 9)
                results.append(s)
        else:
            found = False
            for x in range(0, 10**6 + 1):
                if x + k_val >= max_limit + 1:
                    continue
                total = prefix[x + k_val + 1] - prefix[x]
                if total == n:
                    results.append(str(x))
                    found = True
                    break
            if not found:
                results.append("-1")

    print('\n'.join(map(str, results)))

if __name__ == "__main__":
    main()

2. **Handling \( k = 0 \)**:
