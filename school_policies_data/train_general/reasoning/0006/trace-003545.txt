To solve this problem, we need to determine the number of pairs of people who make eye contact at least once during their synchronized rotation on a plane. The key insight is that two people will make eye contact if their initial directions are exactly opposite, and this condition can be checked efficiently using geometric properties.

### Approach
1. **Direction Vectors**: For each person, compute the direction vector from their position to the point they are initially looking at.
2. **Normalization**: Normalize each direction vector by dividing it by its greatest common divisor (GCD) to handle different magnitudes but same directions.
3. **Opposite Directions**: For each normalized direction vector, check if there exists another person whose direction vector is the exact opposite (i.e., negative of the normalized vector).
4. **Count Pairs**: Use a dictionary to count occurrences of each normalized direction vector. For each direction vector, check the count of its opposite vector and sum up the valid pairs.

### Solution Code

import sys
import math

def main():

            a = dx // g
            b = dy // g

            dir_counts[key] = dir_counts.get(key, 0) + 1

2. **Direction Vector Calculation**: For each person, compute the direction vector from their position to their initial look point.
3. **Normalization**: Each direction vector is normalized by dividing by the GCD of its components, ensuring that vectors with the same direction but different magnitudes are treated identically.
4. **Dictionary for Counting**: A dictionary is used to count occurrences of each normalized direction vector.
5. **Opposite Check**: For each direction vector in the dictionary, check if its opposite vector exists. The count of valid pairs is computed by multiplying the counts of each direction vector and its opposite, then dividing by 2 to avoid double-counting.

This approach efficiently checks for opposite directions using normalized vectors and ensures that the solution runs in linear time relative to the number of people, making it suitable for large input sizes.
