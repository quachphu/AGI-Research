To solve this problem, we need to count the number of binary strings of length N that contain exactly one occurrence of two consecutive zeros. The solution involves dynamic programming and combinatorial analysis to efficiently compute the result for large values of N up to 100,000.

### Approach
1. **Dynamic Programming Precomputation**:
   - **a[L]**: This array stores the number of valid binary strings of length L that end with '1' and contain no two consecutive zeros.
   - **f[k]**: This array stores the number of valid binary strings of length k with no two consecutive zeros.

2. **Summation for Each Test Case**:
   - For each N, compute the sum over all possible positions where the pair "00" can be placed, ensuring that it is isolated by '1's or the string boundaries. This involves summing contributions from valid left and right parts of the string around the "00" block.

### Solution Code
```python
MOD = 10**9 + 7
max_n = 10**5

# Precompute array a where a[L] is the number of valid left parts of length L
a = [0] * (max_n + 2)
a[0] = 1
if max_n >= 1:
    a[1] = 1
    dp_end0_prev = 1  # dp_end0 for L=1
    dp_end1_prev = 1  # dp_end1 for L=1
    for L in range(2, max_n + 1):
        dp_end0 = dp_end1_prev  # dp_end0[L] = dp_end1[L-1]
        dp_end1 = (dp_end0_prev + dp_end1_prev) % MOD  # dp_end1[L] = dp_end0[L-1] + dp_end1[L-1]
        a[L] = dp_end1
        dp_end0_prev, dp_end1_prev = dp_end0, dp_end1

# Precompute array f where f[k] is the number of valid strings of length k with no two consecutive zeros
f = [0] * (max_n + 2)
f[0] = 1
if max_n >= 1:
    f[1] = 2
    for k in range(2, max_n + 1):
        f[k] = (f[k-1] + f[k-2]) % MOD

        total = 0

        for L in range(0, N-1):  # since range is exclusive on upper end, N-1 is N-2+1
```
