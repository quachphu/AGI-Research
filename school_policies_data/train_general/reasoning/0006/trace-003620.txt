To solve this problem, we need to determine the total number of people sitting in a theater based on the consecutive seat ranges occupied by different groups. Each group's seat range is given as input, and we need to ensure that no seat is occupied by more than one person.

### Approach
The problem can be efficiently solved by summing the number of seats each group occupies. Each group's seat range is given as a pair of integers (l_i, r_i), representing the starting and ending seats of the group. The number of seats occupied by a group is calculated as (r_i - l_i + 1). By summing this value for all groups, we obtain the total number of people in the theater. The constraints guarantee that there are no overlapping seat ranges, so we can directly sum these values without additional checks.

### Solution Code
```python
n = int(input())
total = 0
for _ in range(n):
    l, r = map(int, input().split())
    total += r - l + 1
print(total)
```

### Explanation
1. **Reading Input:** The first input line contains the number of groups, `n`.
2. **Initialization:** We initialize a variable `total` to accumulate the total number of people.
3. **Processing Each Group:** For each group, we read the starting seat `l` and ending seat `r`, compute the number of seats occupied by this group as `r - l + 1`, and add this value to `total`.
4. **Output the Result:** Finally, we print the accumulated total, which represents the total number of people in the theater.

This approach efficiently computes the result in O(N) time complexity, where N is the number of groups, making it suitable for the given constraints.
