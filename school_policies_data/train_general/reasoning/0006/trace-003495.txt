To solve this problem, we need to determine the minimum value of `v` such that Vasya can write at least `n` lines of code before falling asleep. The number of lines he writes decreases by a factor of `k` each time he drinks a cup of tea. 

### Approach
1. **Problem Analysis**: The task is to find the smallest `v` where the sum of lines written in each iteration (starting with `v` and then decreasing by integer division by `k` each time) meets or exceeds `n`.
2. **Binary Search**: Since the sum of lines written is a non-decreasing function of `v`, we can use binary search to efficiently find the minimum `v`.
3. **Sum Calculation**: For each candidate `v` during the binary search, we calculate the total lines written by iteratively dividing `v` by `k` until it becomes zero. We also include an optimization to break early if the sum exceeds `n` during this calculation.

### Solution Code
```python
n, k = map(int, input().split())

def is_enough(v):
    total = 0
    current = v
    while current > 0:
        total += current
        if total >= n:
            return True
        current = current // k
    return total >= n

low = 1
high = n

while low < high:
    mid = (low + high) // 2
    if is_enough(mid):
        high = mid
    else:
        low = mid + 1

print(low)
```

### Explanation
1. **Binary Search Setup**: We initialize the search range with `low` set to 1 and `high` set to `n` because the maximum possible value for `v` is `n` (as writing `n` lines in the first iteration alone would suffice).
2. **Check Function**: The `is_enough` function calculates the total lines written starting with `v` and repeatedly dividing by `k` until the quotient becomes zero. If at any point the total meets or exceeds `n`, the function returns early to optimize performance.
3. **Binary Search Execution**: The binary search narrows down the minimum `v` by checking if the middle value in the current range meets the requirement. If it does, the upper bound is adjusted; otherwise, the lower bound is increased.

This approach ensures that we efficiently find the minimum `v` using binary search, which operates in O(log n) time, making the solution both optimal and scalable for large values of `n`.
