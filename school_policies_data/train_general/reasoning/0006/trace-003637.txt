To solve this problem, we need to determine the minimum number of colors required to color the edges of a directed graph such that no cycle is monochromatic. The solution involves checking if the graph is a Directed Acyclic Graph (DAG) and using a feedback edge set approach if it is not.

### Approach
1. **Check if the Graph is a DAG**: If the graph is a DAG, we can color all edges with a single color since there are no cycles.
2. **Identify Feedback Edges**: If the graph is not a DAG, we need to identify feedback edges (edges that form cycles). These edges are then colored differently to ensure that every cycle contains edges of at least two colors.

### Solution Code
```python
import sys
from sys import stdin
sys.setrecursionlimit(1 << 25)

def main():
    n, m = map(int, stdin.readline().split())
    edges = []
    adj = [[] for _ in range(n+1)]  # nodes are 1-based
    for i in range(m):
        u, v = map(int, stdin.readline().split())
        edges.append((u, v))
        adj[u].append((v, i))
    
    # Check if the graph is a DAG using Kahn's algorithm for topological sort
    in_degree = [0]*(n+1)
    for u, v in edges:
        in_degree[v] += 1
    from collections import deque
    q = deque()
    for i in range(1, n+1):
        if in_degree[i] == 0:
            q.append(i)
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v, _ in adj[u]:
            in_degree[v] -= 1
            if in_degree[v] == 0:
                q.append(v)
    if len(order) == n:
        # It's a DAG
        print(1)
        print(' '.join(['1']*m))
        return
    
    # Otherwise, find back edges using DFS
    visited = [False] * (n + 1)
    in_stack = [False] * (n + 1)
    is_back_edge = [False] * m
    
    def dfs(u):
        visited[u] = True
        in_stack[u] = True
        for (v, idx) in adj[u]:
            if not visited[v]:
                dfs(v)
            elif in_stack[v]:
                is_back_edge[idx] = True
        in_stack[u] = False
    
    for u in range(1, n+1):
        if not visited[u]:
            dfs(u)
    
    colors = [1 if not is_back else 2 for is_back in is_back_edge]
    k = 2 if any(is_back_edge) else 1
    print(k)
    print(' '.join(map(str, colors)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **DAG Check**: The code first checks if the graph is a DAG using Kahn's algorithm for topological sorting. If it is a DAG, all edges are colored with 1.
2. **DFS for Feedback Edges**: If the graph is not a DAG, a Depth-First Search (DFS) is used to identify back edges. These back edges are part of cycles and are colored with 2, while the remaining edges are colored with 1. This ensures that any cycle in the graph includes edges of both colors, thus meeting the problem's requirements.

This approach efficiently determines the minimum number of colors required and ensures the solution meets the problem constraints.
