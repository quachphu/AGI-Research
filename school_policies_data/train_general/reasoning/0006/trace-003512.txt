To solve this problem, we need to help Amit buy the maximum number of cookies possible within his budget. The key strategy is to prioritize buying the cheapest cookies first, as this approach maximizes the number of cookies he can afford.

### Approach
1. **Sort the Prices**: First, we sort the list of cookie prices in ascending order. This allows us to consider the cheapest cookies first.
2. **Iterate and Accumulate**: We then iterate through the sorted list, accumulating the total cost of the cookies. For each cookie price, we check if adding it to the current total would exceed the budget. If it does, we stop and return the count of cookies bought so far. If it doesn't, we add the price to the total and increment the count.

### Solution Code
```python
import sys

def max_cookies():
    n, k = map(int, sys.stdin.readline().split())
    prices = list(map(int, sys.stdin.readline().split()))
    prices.sort()
    total = 0
    count = 0
    for price in prices:
        if total + price > k:
            break
        total += price
        count += 1
    print(count)

max_cookies()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin` for efficiency, especially given the constraints.
2. **Sorting**: The prices are sorted in ascending order to ensure we start with the cheapest cookies.
3. **Accumulating Costs**: We iterate through the sorted prices, accumulating the total cost while counting how many cookies we can buy without exceeding the budget. If adding the next cookie would exceed the budget, we stop immediately.
4. **Output**: Finally, we print the count of cookies that can be bought within the budget.

This approach ensures that we efficiently determine the maximum number of cookies Amit can buy by leveraging sorting and a linear scan, resulting in an overall time complexity of O(N log N) due to the sorting step, which is optimal for the given constraints.
