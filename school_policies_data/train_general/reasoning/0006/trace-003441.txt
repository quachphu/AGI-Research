To solve this problem, we need to determine the elements of a sequence built through a series of operations. Directly simulating the sequence is infeasible due to potential exponential growth from copy operations. Instead, we use a backtracking approach to efficiently determine the value at any given position without constructing the entire sequence.

### Approach
1. **Track Operations**: Maintain a list of operations (history) that records each step taken to build the sequence. Each entry in the history tracks the operation type and the resulting length of the sequence after the operation.
2. **Binary Search for Efficient Lookup**: For each query, use binary search to determine which operation affects the queried position. This helps in quickly narrowing down the relevant operation without iterating through all operations.
3. **Backtracking**: If the operation is a copy (type 2), compute the original position within the copied prefix by adjusting the query index and recursively resolving it until a direct value (type 1 operation) is found.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    m = int(input[ptr])
    ptr +=1
    
    history = []
    current_len = 0
    
    for _ in range(m):
        type_op = int(input[ptr])
        ptr +=1
        if type_op == 1:
            x = int(input[ptr])
            ptr +=1
            current_len +=1
            history.append( (1, x, current_len) )
        else:
            l = int(input[ptr])
            c = int(input[ptr+1])
            ptr +=2
            len_before = current_len
            added = l * c
            current_len += added
            history.append( (2, (l, c, len_before), current_len) )
    
    n = int(input[ptr])
    ptr +=1
    queries = list(map(int, input[ptr:ptr+n]))
    
    len_afters = [event[2] for event in history]
    output = []
    
    for k in queries:
        current_k = k
        while True:
            pos = bisect.bisect_left(len_afters, current_k)
            event = history[pos]
            if event[0] == 1:
                output.append(str(event[1]))
                break
            else:
                l, c, len_before = event[1]
                offset = current_k - len_before
                pos_in_block = (offset -1) % l +1
                current_k = pos_in_block
    
    print(' '.join(output))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, and parsed using a pointer to track the current position.
2. **Building History**: Each operation (either adding a number or copying a prefix) is recorded in the `history` list along with the resulting sequence length.
3. **Processing Queries**: For each query, binary search (`bisect_left`) is used to find the earliest operation affecting the queried position. If the operation is a copy, the position is adjusted to reference the original prefix, and the process repeats until a direct value is found.
4. **Efficiency**: The use of binary search and backtracking ensures that each query is resolved in logarithmic time relative to the number of operations, making the solution efficient even for large inputs.
