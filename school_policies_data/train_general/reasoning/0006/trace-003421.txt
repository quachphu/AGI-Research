To solve this problem, we need to determine the number of consecutive days Sahil can drink juice before running out, given that he starts with a certain number of bottles and his mother buys an additional bottle every 'm' days in the evening.

### Approach
1. **Initial Setup**: Sahil starts with 'n' bottles of juice.
2. **Daily Consumption**: Each morning, Sahil drinks one bottle of juice.
3. **Bottle Replenishment**: Every 'm' days (i.e., on days m, 2m, 3m, etc.), his mother buys an additional bottle of juice in the evening, which becomes available the next day.
4. **Simulation**: We simulate each day step-by-step, decrementing the juice count each morning and checking if an additional bottle should be added in the evening if the day is a multiple of 'm'.

### Solution Code
```python
n, m = map(int, input().split())
current = n
days = 0
while current > 0:
    days += 1
    current -= 1
    if days % m == 0:
        current += 1
print(days)
```

### Explanation
1. **Reading Input**: The input consists of two integers, 'n' (initial number of bottles) and 'm' (the interval at which new bottles are bought).
2. **Initialization**: We start with the given number of bottles and initialize the day counter.
3. **Daily Loop**: For each day:
   - Increment the day counter.
   - Decrease the bottle count by 1 (Sahil drinks a bottle each morning).
   - Check if the current day is a multiple of 'm'. If it is, add a bottle to the count (this happens in the evening, so the new bottle is available the next day).
4. **Termination**: The loop continues until Sahil runs out of bottles. The day counter then gives the number of consecutive days he can drink juice.

This approach efficiently simulates each day's events and correctly accounts for the replenishment of bottles every 'm' days, ensuring accurate results.
