To solve this problem, we need to determine if three given integers are in strictly increasing order. Specifically, we need to check if the first integer is less than the second, and the second is less than the third. If this condition is met, we print "Yes"; otherwise, we print "No".

### Approach
1. **Reading Input**: The input consists of three integers separated by spaces. We will read this input and split it into three separate integer values.
2. **Condition Check**: Using Python's ability to chain comparison operators, we check if the integers satisfy the condition \(a < b < c\).
3. **Output Result**: Based on the condition check, we print "Yes" if the integers are in strictly increasing order, otherwise "No".

### Solution Code
```python
def main():
    a, b, c = map(int, input().split())
    print("Yes" if a < b < c else "No")

main()
```

### Explanation
1. **Reading Input**: The `input().split()` method reads a line of input, splits it into a list of strings based on whitespace, and `map(int, ...)` converts these strings into integers. The three integers are then assigned to variables `a`, `b`, and `c`.
2. **Condition Check**: The expression `a < b < c` is a chained comparison which checks if `a` is less than `b` and `b` is less than `c` in a concise manner.
3. **Output Result**: Using a ternary conditional operator, we print "Yes" if the condition is true, otherwise "No".

This approach efficiently checks the required condition and ensures the solution is both concise and easy to understand.
