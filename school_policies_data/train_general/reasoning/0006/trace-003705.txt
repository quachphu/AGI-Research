To solve this problem, we need to reverse the encryption process described. The encryption process involves reversing substrings based on the divisors of the string length in decreasing order. To decrypt, we need to reverse these operations in the reverse order.

### Approach
1. **Identify Divisors**: Find all divisors of the given length `n` and sort them in decreasing order.
2. **Reverse Order**: Reverse the order of these divisors to get the order in which we need to apply the reverse operations for decryption.
3. **Apply Reverses**: For each divisor in the reversed list, reverse the substring from the start to the divisor's position. This undoes the encryption steps in reverse order.

### Solution Code
```python
n = int(input())
t = input().strip()

# Find all divisors of n
divisors = []
for i in range(1, n + 1):
    if n % i == 0:
        divisors.append(i)

# Sort divisors in decreasing order and reverse to get decryption order
decryption_order = sorted(divisors, reverse=True)[::-1]

current = t
for d in decryption_order:
    # Reverse the first d characters
    reversed_part = current[:d][::-1]
    current = reversed_part + current[d:]

print(current)
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` and the encrypted string `t`.
2. **Finding Divisors**: We iterate through all numbers from 1 to `n` to find the divisors of `n`.
3. **Sorting and Reversing Divisors**: The divisors are sorted in decreasing order and then reversed to get the order in which we need to apply the reverse operations for decryption.
4. **Reversing Substrings**: For each divisor in the reversed list, we reverse the substring from the start to the divisor's position. This step-by-step reversal undoes the encryption process in reverse order, leading us back to the original string.

This approach ensures that we correctly reverse each step of the encryption process, resulting in the original string. The complexity is manageable given the constraints (n ≤ 100), making this solution efficient and straightforward.
