To solve this problem, we need to determine the winner of a game played by Alice and Bob, where they take turns subtracting a proper divisor from a number N. Alice plays first, and the player who cannot make a move loses. The solution must be efficient given the constraints.

### Approach
The key insight here is to recognize the pattern based on the parity (even or odd) of the number N. The solution can be derived as follows:

1. **Even N**: If N is even, Alice can always subtract 1 (a proper divisor) to turn N into an odd number. This forces Bob into a position where he must subtract an odd divisor (since all divisors of an odd number are odd), resulting in an even number again. This cycle continues, ensuring Alice always has a move until N becomes 1, where Bob loses.
2. **Odd N**: If N is odd, any proper divisor subtracted from N will result in an even number. This allows Bob to follow the same strategy as Alice, ensuring he can always force Alice into a losing position.

Thus, the winner is determined by the parity of N:
- If N is even, Alice wins.
- If N is odd, Bob wins.

### Solution Code
```python
import sys

def determine_winner():
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        N = int(input[i])
        if N % 2 == 0:
            print("ALICE")
        else:
            print("BOB")

determine_winner()
```

### Explanation
- **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
- **Loop Through Test Cases**: For each test case, we check if the number N is even or odd.
- **Determine Winner**: Based on the parity check, we print "ALICE" if N is even and "BOB" if N is odd.

This approach ensures that we handle up to 10,000 test cases efficiently, even for large values of N up to 1 billion, with a constant time check for each number.
