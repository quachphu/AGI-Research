To solve this problem, we need to determine the maximum number of rows that can be made completely clean by sweeping over columns of a grid. Each sweep toggles the state of all cells in the column (clean to dirty and vice versa). The goal is to find the optimal set of columns to sweep such that the maximum number of rows become entirely clean (all cells as '1').

### Approach
1. **Understand Flip Patterns**: For each row, determine the columns that need to be toggled (swept) to convert all cells in that row to '1'. This forms a flip pattern specific to that row.
2. **Count Flip Patterns**: Track the frequency of each flip pattern across all rows. The flip pattern that occurs most frequently indicates the maximum number of rows that can be made clean by applying the corresponding column toggles.

### Solution Code
```python
n = int(input())
rows = [input().strip() for _ in range(n)]

from collections import defaultdict

pattern_counts = defaultdict(int)

for row in rows:
    # Generate the flip pattern required to make this row all '1's
    flip_pattern = ''.join('1' if c == '0' else '0' for c in row)
    pattern_counts[flip_pattern] += 1

max_rows = max(pattern_counts.values(), default=0)
print(max_rows)
```

### Explanation
1. **Reading Input**: The first line reads the grid size `n`, followed by reading the grid rows.
2. **Generating Flip Patterns**: For each row, generate a flip pattern where each character is '1' if the corresponding column needs to be toggled (original cell is '0'), and '0' otherwise. This pattern represents the columns that need to be toggled to make that row entirely clean.
3. **Counting Patterns**: Use a dictionary to count occurrences of each flip pattern. The maximum value in this dictionary gives the number of rows that can be made clean by toggling the columns specified by the most frequent flip pattern.

This approach efficiently determines the optimal columns to toggle by leveraging the frequency of required flip patterns, ensuring an optimal solution in O(n^2) time complexity, which is efficient for the given constraints (n ≤ 100).
