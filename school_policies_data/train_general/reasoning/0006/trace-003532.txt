To solve this problem, we need to determine the minimum number of days required for a rumor to spread from a strategically chosen starting house to all other houses in an M x N grid. The optimal starting point minimizes the maximum time taken for the rumor to reach the farthest house.

### Approach
1. **Problem Analysis**:
   - The rumor spreads from the starting house to adjacent houses (up, down, left, right) one day at a time.
   - The goal is to find the starting point that minimizes the maximum time taken to reach all houses.
   - The optimal starting point is the center of the grid, as it minimizes the maximum distance to any edge.

2. **Key Insight**:
   - The time taken for the rumor to spread to a house is determined by its Manhattan distance from the starting point. The Manhattan distance from (x1, y1) to (x2, y2) is |x1 - x2| + |y1 - y2|.
   - The optimal starting point's maximum Manhattan distance to any edge is determined by the grid's dimensions. For a grid with M rows and N columns, the maximum distance from the center to any edge is given by the formula: (M // 2) + (N // 2).

3. **Algorithm**:
   - For each test case, read the grid dimensions M and N.
   - If either dimension is zero, the result is zero (no houses).
   - Otherwise, compute the minimum days using the formula: (M // 2 + N // 2) + 1.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        m = int(input[idx])
        n = int(input[idx + 1])
        idx += 2
        if m == 0 or n == 0:
            print(0)
        else:
            res = (m // 2 + n // 2) + 1
            print(res)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read all at once for efficiency, especially given the constraints with up to 1000 test cases.
- **Handling Zero Dimensions**: If either dimension (M or N) is zero, the output is zero as there are no houses.
- **Optimal Days Calculation**: For valid grid dimensions, the formula (M // 2 + N // 2) + 1 computes the minimum days required by considering the center of the grid as the optimal starting point. This formula efficiently calculates the maximum Manhattan distance from the center to any edge and adds one to account for the initial day when the rumor starts.

This approach ensures that the solution is both optimal and efficient, handling up to the maximum constraints smoothly.
