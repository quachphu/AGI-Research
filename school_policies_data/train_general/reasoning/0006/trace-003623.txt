To solve this problem, we need to determine the person closest to the ideal Body Mass Index (BMI) of 22 from multiple datasets. Each dataset contains the number of people followed by their respective details. The solution involves calculating the BMI for each person and identifying the one with the smallest deviation from 22, breaking ties by selecting the person with the smallest reception number.

### Approach
1. **Read Input Data**: Read all input data at once and split it into a list of integers for efficient processing.
2. **Process Each Dataset**: For each dataset, extract the number of people and their details.
3. **Calculate BMI and Deviation**: For each person, convert height from centimeters to meters, compute BMI, and determine the absolute deviation from the ideal BMI of 22.
4. **Sort and Select**: Sort the people based on their deviation from the ideal BMI and their reception number. The person with the smallest deviation (and smallest reception number in case of ties) is selected as the result for each dataset.

### Solution Code
```python
import sys

def main():
    data = list(map(int, sys.stdin.read().split()))
    ptr = 0
    while True:
        if ptr >= len(data):
            break
        n = data[ptr]
        ptr += 1
        if n == 0:
            break
        people = []
        for _ in range(n):
            pi = data[ptr]
            hi = data[ptr + 1]
            wi = data[ptr + 2]
            ptr += 3
            height_m = hi / 100.0
            bmi = wi / (height_m ** 2)
            diff = abs(bmi - 22)
            people.append((diff, pi))
        people.sort()
        print(people[0][1])

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and converted into a list of integers for easy traversal.
2. **Dataset Processing**: Each dataset starts with an integer `n` (number of people). If `n` is 0, processing stops.
3. **BMI Calculation**: For each person, height is converted from centimeters to meters. BMI is calculated using the formula `weight / (height_in_meters^2)`, and the deviation from the ideal BMI of 22 is computed.
4. **Sorting**: Each person's deviation and reception number are stored in a list. The list is sorted first by deviation and then by reception number to handle ties.
5. **Output**: The reception number of the person with the smallest deviation (and smallest reception number in case of ties) is printed for each dataset.

This approach ensures efficient processing of input data and correctly identifies the closest person to the ideal BMI using sorting and tie-breaking rules.
