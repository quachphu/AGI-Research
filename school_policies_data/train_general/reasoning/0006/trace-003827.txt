To solve this problem, we need to determine the minimum and maximum possible number of items sold in an auction based on a given sequence of prices. The auction rules dictate that each item's prices must form a strictly increasing sequence. 

### Approach
1. **Minimum Number of Items**:
   - The minimum number of items is determined by the number of times the price sequence decreases or remains the same. Each time a price is not higher than the previous price, a new item must start. Thus, the minimum number of items is the count of such decreases plus one.

2. **Maximum Number of Items**:
   - The maximum number of items is simply the total number of prices recorded. This is because each price can be considered the initial bid of a new item, provided it is followed by a lower or equal price. Since each price can be an individual item's initial bid, the maximum number of items is the length of the price sequence.

### Solution Code
```python
n, *rest = map(int, open(0).read().split())
a = rest[:n]

if n == 0:
    print(0)
    print(0)
else:
    cnt = 0
    for i in range(1, n):
        if a[i] <= a[i-1]:
            cnt += 1
    print(cnt + 1)
    print(n)
```

### Explanation
- **Reading Input**: The input is read and parsed into a list of integers.
- **Counting Decreases**: We iterate through the list of prices, counting each time a price is not higher than the previous one. This count gives the number of times a new item must start.
- **Calculating Minimum**: The minimum number of items is the count of decreases plus one (to account for the initial item).
- **Calculating Maximum**: The maximum number of items is simply the number of prices recorded, as each price can be the start of a new item.

This approach efficiently computes the required values in linear time, making it suitable for large input sizes up to the given constraints.
