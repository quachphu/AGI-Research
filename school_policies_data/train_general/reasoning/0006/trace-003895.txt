To solve this problem, we need to determine the optimal strategy for Bob to maximize his strength after flipping either a prefix or a suffix of Alice's initial team assignment. The solution involves calculating the potential gain from flipping each possible prefix or suffix and choosing the maximum gain.

### Approach
1. **Initial Strength Calculation**: Compute the initial strength of Bob based on Alice's assignment.
2. **Delta Calculation**: For each element, compute the change in Bob's strength (delta) if that element is flipped. If the element is assigned to Alice (A), flipping it to B increases Bob's strength by its value. If the element is assigned to Bob (B), flipping it to A decreases Bob's strength by its value.
3. **Prefix and Suffix Analysis**: Calculate the maximum possible gain from flipping any prefix and any suffix by iterating through the elements and maintaining cumulative sums of deltas.
4. **Result Calculation**: Determine the maximum gain from all possible flips (prefix, suffix, or doing nothing) and add this gain to the initial strength to get the final result.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    p = list(map(int, sys.stdin.readline().split()))
    s = sys.stdin.readline().strip()
    
    initial_sum = 0
    for i in range(n):
        if s[i] == 'B':
            initial_sum += p[i]
    
    max_prefix = 0
    current_prefix = 0
    for i in range(n):
        delta = p[i] if s[i] == 'A' else -p[i]
        current_prefix += delta
        if current_prefix > max_prefix:
            max_prefix = current_prefix
    
    max_suffix = 0
    current_suffix = 0
    for i in range(n-1, -1, -1):
        delta = p[i] if s[i] == 'A' else -p[i]
        current_suffix += delta
        if current_suffix > max_suffix:
            max_suffix = current_suffix
    
    max_delta = max(max_prefix, max_suffix, 0)
    print(initial_sum + max_delta)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The number of pieces, their strengths, and the initial assignment are parsed.
2. **Initial Strength Calculation**: The initial strength of Bob is calculated by summing the strengths of pieces assigned to him (marked 'B').
3. **Delta Calculation for Prefix**: By iterating through the elements from left to right, we maintain a cumulative sum of deltas. The maximum value of this cumulative sum gives the maximum gain from flipping any prefix.
4. **Delta Calculation for Suffix**: Similarly, by iterating from right to left, we compute the cumulative sum of deltas for suffixes and track the maximum gain.
5. **Result Calculation**: The maximum possible gain from flipping any prefix, suffix, or doing nothing is determined. This maximum gain is added to the initial strength to get the final result, which is printed.

This approach efficiently computes the optimal strategy in linear time, ensuring it handles the upper constraint of up to 500,000 elements efficiently.
