To solve this problem, we need to find the minimum absolute difference between any three consecutive digits in a given string and the number 753. The solution involves iterating through all possible triplets of consecutive digits in the string, converting each triplet to an integer, and calculating the absolute difference from 753. The smallest difference encountered is the answer.

### Approach
1. **Read Input**: The input string is read from standard input.
2. **Initialize Minimum Difference**: Start with a large initial value for the minimum difference.
3. **Iterate Through Triplets**: Loop through each possible triplet of consecutive digits in the string.
4. **Calculate Differences**: For each triplet, convert it to an integer and compute the absolute difference from 753.
5. **Track Minimum Difference**: Keep track of the smallest difference encountered during the iteration.
6. **Output Result**: Print the smallest difference found.

### Solution Code
```python
def main():
    s = input().strip()
    min_diff = float('inf')
    for i in range(len(s) - 2):
        x = int(s[i:i+3])
        diff = abs(x - 753)
        if diff < min_diff:
            min_diff = diff
    print(min_diff)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input string is read using `input().strip()` to ensure no leading or trailing whitespace.
2. **Initialization**: `min_diff` is initialized to `float('inf')` to represent a very large number, ensuring any valid difference will be smaller initially.
3. **Loop Through Triplets**: The loop runs from the start of the string to the position where a triplet can still be formed, which is `len(s) - 2` (since each triplet is 3 characters long).
4. **Convert and Compare**: Each triplet is converted to an integer, and the absolute difference from 753 is computed. This difference is compared to the current minimum difference, updating it if a smaller difference is found.
5. **Output**: After processing all possible triplets, the smallest difference is printed.

This approach efficiently checks all possible triplets in linear time relative to the length of the string, making it optimal for the given problem constraints.
