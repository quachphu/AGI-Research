To solve this problem, we need to efficiently compute the minimum number of replacement operations required to eliminate all consecutive periods in a string after each update. Each update changes a character at a specific position, and we need to determine the effect of this change on the string's structure.

### Approach
1. **Key Insight**: The number of replacement operations required (denoted as `f(s)`) is determined by the number of periods (`.`) and the number of contiguous runs of periods. Specifically, `f(s) = count_of_periods - number_of_runs`.

2. **Initial Setup**: Calculate the initial count of periods and the number of contiguous runs of periods in the string.

3. **Handling Queries**:
   - For each query, check if the character at the specified position is changing.
   - Update the count of periods and the number of runs based on whether the character is being changed to or from a period.
   - Adjust the number of runs by checking neighboring characters to see if merging or splitting runs is necessary.

### Solution Code
```python
n, m = map(int, input().split())
s = list(input().strip())
count = sum(1 for c in s if c == '.')
runs = 0

for i in range(n):
    if s[i] == '.' and (i == 0 or s[i-1] != '.'):
        runs += 1

for _ in range(m):
    xi, ci = input().split()
    xi = int(xi) - 1  # convert to 0-based index

    if s[xi] == ci:
        print(count - runs)
        continue

    old_char = s[xi]
    new_char = ci

    if old_char == '.':
        count -= 1
        left_exists = 0
        if xi > 0 and s[xi-1] == '.':
            left_exists = 1
        right_exists = 0
        if xi < n-1 and s[xi+1] == '.':
            right_exists = 1
        delta = (left_exists + right_exists) - 1
        runs += delta
    else:
        if new_char == '.':
            count += 1
            left_exists = 0
            if xi > 0 and s[xi-1] == '.':
                left_exists = 1
            right_exists = 0
            if xi < n-1 and s[xi+1] == '.':
                right_exists = 1
            delta = 1 - (left_exists + right_exists)
            runs += delta

    s[xi] = new_char
    print(count - runs)
```

3. **Updating Values**: If the character changes from a period to a non-period, we decrement the count and adjust the number of runs based on the neighboring characters. Conversely, if the character changes to a period, we increment the count and adjust the runs by checking neighbors.
