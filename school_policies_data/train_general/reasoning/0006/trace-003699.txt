To solve this problem, we need to determine the minimum number of changes required to make all substrings of a given string distinct. If it is impossible to achieve this, we should return -1.

### Approach
1. **Impossibility Check**: If the length of the string \( n \) is greater than 26, it is impossible to make all substrings distinct. This is because there are only 26 lowercase English letters, and any string longer than 26 characters will necessarily have repeated characters in its substrings of length 1.
2. **Character Uniqueness**: For strings with \( n \leq 26 \), the key insight is that all substrings of any length will be unique if and only if all characters in the string are unique. This is because if all characters are unique, every substring of the same length will start with a different character, ensuring uniqueness.

### Solution Code
```python
n = int(input())
s = input().strip()

if n > 26:
    print(-1)
else:
    unique_chars = len(set(s))
    print(n - unique_chars)
```

### Explanation
1. **Impossibility Check**: The first check determines if the string length exceeds 26. If it does, we immediately return -1 as it's impossible to have all unique substrings.
2. **Unique Characters Calculation**: For valid string lengths (≤ 26), we count the number of unique characters using a set. The minimum number of changes required is the difference between the string length and the number of unique characters. This ensures that each character in the string is unique, thereby guaranteeing all substrings will be unique.

This approach efficiently determines the solution by leveraging the properties of sets and character uniqueness, ensuring optimal performance even for the upper constraint of \( n = 100,000 \).
