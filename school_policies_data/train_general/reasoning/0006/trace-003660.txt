To solve this problem, we need to determine the number of special letters that appear in every friend's name. A letter is considered special if it occurs at least once in each of the given names.

### Approach
1. **Input Reading**: Read the number of names, followed by the names themselves.
2. **Set Creation**: Convert each name into a set of unique characters. This helps in efficiently determining the common characters across all names.
3. **Intersection Calculation**: Compute the intersection of all the sets derived from the names. The intersection of multiple sets gives the elements (characters, in this case) that are common to all sets.
4. **Result Calculation**: The size of the intersection set gives the number of special letters.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    names = input[1:n+1]
    if n == 0:
        print(0)
        return
    # Convert each name to a set of characters
    sets_list = [set(name) for name in names]
    # Compute the intersection of all sets
    common_chars = sets_list[0].intersection(*sets_list[1:])
    print(len(common_chars))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings for easier processing. The first element is the number of names, and the subsequent elements are the names themselves.
2. **Set Conversion**: Each name is converted into a set of its characters. This helps in efficiently finding common characters using set operations.
3. **Intersection Calculation**: The intersection of all sets is computed using the `intersection` method. Starting with the first set, we iteratively intersect it with the rest of the sets to find common characters.
4. **Output**: The size of the resulting intersection set is printed, which represents the number of special letters present in all names.

This approach efficiently handles the problem constraints and ensures that we find the solution in an optimal manner using set operations, which are average O(1) for membership checks and intersections.
