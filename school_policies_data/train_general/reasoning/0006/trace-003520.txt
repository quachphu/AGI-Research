To solve this problem, we need to maximize Takahashi's happiness by selecting dishes from an all-you-can-eat restaurant under specific time constraints. The key challenge is to determine the optimal subset of dishes to maximize the sum of their deliciousness while adhering to the time restrictions.

### Approach
1. **Understand the Time Constraints**: The last order must be placed by T - 0.5 minutes, which translates to a maximum allowed time of T - 1 minutes for the sum of the eating times of all dishes except the last one.
2. **Dynamic Programming (DP) Approach**: We use a combination of prefix and suffix DP arrays to efficiently compute the maximum deliciousness sum for subsets of dishes excluding each dish individually.
3. **Prefix and Suffix DP Arrays**: 
   - **Prefix DP**: Tracks the maximum deliciousness for subsets of the first i dishes.
   - **Suffix DP**: Tracks the maximum deliciousness for subsets of the last i dishes.
4. **Combining Results**: For each dish considered as the last dish, compute the maximum deliciousness sum by combining the prefix and suffix DP arrays, ensuring the sum of eating times for the prefix dishes is within the allowed time.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    T = int(input[idx])
    idx += 1
    dishes = []
    for _ in range(N):
        a = int(input[idx])
        idx += 1
        b = int(input[idx])
        idx += 1
        dishes.append((a, b))
    
    T_half = T - 1
    if T_half < 0:
        print(0)
        return
    
    # Compute prefix DP
    prefix = [[-float('inf')] * (T_half + 1) for _ in range(N + 1)]
    prefix[0][0] = 0
    for j in range(1, N + 1):
        a, b = dishes[j - 1]
        prev_dp = prefix[j - 1]
        new_dp = prev_dp.copy()
        for w in range(T_half, a - 1, -1):
            if new_dp[w - a] != -float('inf'):
                new_dp[w] = max(new_dp[w], new_dp[w - a] + b)
        prefix[j] = new_dp
    
    # Compute suffix DP
    suffix = [[-float('inf')] * (T_half + 1) for _ in range(N + 2)]
    suffix[N + 1][0] = 0
    for j in range(N, 0, -1):
        a, b = dishes[j - 1]
        next_dp = suffix[j + 1].copy()
        for w in range(T_half, a - 1, -1):
            if next_dp[w - a] != -float('inf'):
                next_dp[w] = max(next_dp[w], next_dp[w - a] + b)
        suffix[j] = next_dp
    
    max_happiness = 0
    for j in range(1, N + 1):
        a_j, b_j = dishes[j - 1]
        pre_dp = prefix[j - 1]
        suf_dp = suffix[j + 1]
        
        # Compute max_s for suffix[j+1]
        max_s = [-float('inf')] * (T_half + 1)
        max_s[0] = suf_dp[0]
        for w in range(1, T_half + 1):
            max_s[w] = max(max_s[w - 1], suf_dp[w])
        
        current_max = -float('inf')
        for w1 in range(T_half + 1):
            if pre_dp[w1] == -float('inf'):
                continue
            rem = T_half - w1
            if rem < 0:
                continue
            rem = min(rem, T_half)
            current_total = pre_dp[w1] + max_s[rem]
            if current_total > current_max:
                current_max = current_total
        
        candidate = current_max + b_j
        if candidate > max_happiness:
            max_happiness = candidate
    
    print(max_happiness)

if __name__ == "__main__":
    main()
```

3. **Combining Results**: For each dish considered as the last dish, the prefix and suffix arrays are combined to find the maximum possible deliciousness sum, ensuring the sum of eating times for the prefix dishes does not exceed T - 1 minutes.
