To solve this problem, we need to adjust a list of integers such that their product becomes 1 with the minimum cost. Each adjustment (adding or subtracting 1 from a number) costs one coin. 

### Approach
1. **Understanding the Product Requirement**: The product of integers can only be 1 if all numbers are either 1 or -1, and there is an even number of -1s. This is because any other integers would require fractions to achieve a product of 1, which are not allowed here.

2. **Cost Calculation**: For each number, calculate the cost to convert it to 1 and to -1. The cost to convert a number `a` to 1 is `abs(a - 1)`, and to convert it to -1 is `abs(a + 1)`.

3. **Initial Adjustment**: Convert each number to the nearest of 1 or -1 (whichever is cheaper), and keep track of the total cost and the count of -1s.

4. **Parity Check**: If the count of -1s is even, the product is already valid. If odd, adjust the numbers to make the count even by finding the minimal cost increment needed to flip one number from 1 to -1 or vice versa.

### Solution Code
```python
import sys

def main():
    n, *rest = map(int, sys.stdin.read().split())
    a = rest[:n]
    
    sum_cost = 0
    cnt_neg1 = 0
    min_delta = float('inf')
    
    for num in a:
        cost1 = abs(num - 1)
        cost_neg1 = abs(num + 1)
        
        if cost_neg1 < cost1:
            sum_cost += cost_neg1
            cnt_neg1 += 1
            delta = cost1 - cost_neg1
        elif cost1 < cost_neg1:
            sum_cost += cost1
            delta = cost_neg1 - cost1
        else:
            sum_cost += cost1
            delta = 0
        
        if delta < min_delta:
            min_delta = delta
    
    if cnt_neg1 % 2 != 0:
        sum_cost += min_delta
    
    print(sum_cost)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into a list of integers.
2. **Cost Calculation**: For each number, compute the cost to convert it to 1 and -1. Track the total cost and the number of -1s.
3. **Adjustment for Parity**: If the count of -1s is odd, find the minimal cost increment (delta) needed to flip one number to make the count even. This delta is the minimum difference in cost between converting a number to 1 instead of -1 or vice versa.
4. **Output Result**: Print the total minimum cost after adjusting for parity if necessary.

This approach ensures that we efficiently compute the minimal cost while adhering to the constraints, ensuring optimal performance even for large input sizes.
