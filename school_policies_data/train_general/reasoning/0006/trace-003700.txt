To solve this problem, we need to determine the next "lucky year" after a given current year in Berland. A lucky year is defined as a year that has at most one non-zero digit (e.g., 5, 10, 300). The goal is to compute how many years until the next lucky year.

### Approach
1. **Identify the Structure of Lucky Years**: A lucky year can be represented as `d * 10^k`, where `d` is a non-zero digit (1-9) and `k` is the number of zeros following `d`.
2. **Determine Current Year's Length**: Calculate the number of digits in the current year to understand the possible candidates for the next lucky year.
3. **Generate Candidates**:
   - **Same Length Candidates**: Check if there is a valid lucky year with the same number of digits as the current year but starting with a higher non-zero digit.
   - **Next Length Candidate**: If no valid same-length candidate exists, consider the smallest lucky year with one more digit than the current year (i.e., `10^length` where `length` is the number of digits in the current year).

### Solution Code
```python
n = int(input())
s = str(n)
l = len(s)
first_d = int(s[0])

possible_min = None
if first_d < 9:
    possible_min = (first_d + 1) * (10 ** (l - 1))

next_length_candidate = 10 ** l

candidates = []
if possible_min is not None and possible_min > n:
    candidates.append(possible_min)
if next_length_candidate > n:
    candidates.append(next_length_candidate)

min_candidate = min(candidates)
print(min_candidate - n)
```

### Explanation
1. **Input Handling**: Read the current year `n`.
2. **Digit Analysis**: Convert the year to a string to determine its length and the first digit.
3. **Generate Same-Length Candidate**: If the first digit is less than 9, compute the smallest possible candidate with the same number of digits by incrementing the first digit and setting the remaining digits to zero.
4. **Next Length Candidate**: Compute the smallest candidate with one more digit than the current year (e.g., if the current year is 4000, the next length candidate is 10000).
5. **Determine the Minimum Candidate**: Collect all valid candidates (those greater than the current year) and find the smallest one. The result is the difference between this minimum candidate and the current year.

This approach efficiently narrows down the possible candidates to the smallest valid lucky year, ensuring an optimal solution with minimal computational overhead.
