To solve this problem, we need to determine the depth of the snow cover based on the uncovered parts of two adjacent towers. The towers are arranged in such a way that each subsequent tower's height increases by the next integer, forming triangular numbers. The key insight is to leverage the relationship between the heights of these towers and the given uncovered parts to compute the snow depth.

### Approach
1. **Understand the Tower Heights**: The height of the nth tower is given by the sum of the first n natural numbers, which is a triangular number. The height of the nth tower can be calculated using the formula \( T_n = \frac{n(n+1)}{2} \).

2. **Adjacent Tower Difference**: The difference in height between two adjacent towers (n and n+1) is \( (n+1) \). This difference can be derived from the given uncovered parts of the towers (a and b), where \( b - a \) gives the difference in their heights.

3. **Determine Tower Index**: Using the difference \( b - a \), we can find the index of the west tower (i) as \( i = (b - a) - 1 \).

4. **Calculate Snow Depth**: The snow depth (x) can be found by subtracting the uncovered part (a) from the height of the west tower (i).

### Solution Code
```python
a, b = map(int, input().split())
delta = b - a
i = delta - 1
t_i = i * (i + 1) // 2
x = t_i - a
print(x)
```

1. **Input Reading**: The input values a and b are read from standard input.
2. **Compute Difference (delta)**: The difference between the uncovered parts of the east and west towers (b - a) is calculated.
3. **Determine Tower Index (i)**: The index of the west tower is derived from the difference (delta) as \( i = delta - 1 \).
4. **Calculate Tower Height (t_i)**: The height of the west tower (i) is computed using the triangular number formula.
5. **Compute Snow Depth (x)**: The snow depth is found by subtracting the uncovered part (a) from the height of the west tower.

This approach efficiently computes the snow depth using the properties of triangular numbers and the relationship between adjacent towers, ensuring an optimal and correct solution.
