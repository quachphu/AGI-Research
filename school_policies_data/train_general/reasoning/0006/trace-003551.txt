To solve this problem, we need to determine the maximum number of consecutive bears with their hands on their eyes (represented by 1) in any row of a grid after each round of state changes. Each round involves flipping the state of a specific bear and then recalculating the maximum consecutive 1s for the entire grid.

### Approach
1. **Grid Initialization**: Read the grid dimensions and the initial state of each bear.
2. **Precompute Row Maxima**: For each row, compute the maximum number of consecutive 1s and store these values in an array.
3. **Global Maximum Calculation**: Compute the initial global maximum from the row maxima.
4. **Process Queries**: For each query, flip the state of the specified bear, recompute the maximum consecutive 1s for the affected row, update the row maxima, and then determine the new global maximum.

### Solution Code
```python
n, m, q = map(int, input().split())

grid = []
for _ in range(n):
    row = list(map(int, input().split()))
    grid.append(row)

def compute_max(row):
    max_so_far = 0
    current = 0
    for num in row:
        if num == 1:
            current += 1
            if current > max_so_far:
                max_so_far = current
        else:
            current = 0
    return max_so_far

row_max = []
for i in range(n):
    row_max.append(compute_max(grid[i]))

global_max = max(row_max)

for _ in range(q):
    i, j = map(int, input().split())
    i -= 1
    j -= 1
    # Flip the cell
    grid[i][j] ^= 1
    # Recompute the max for the affected row
    row_max[i] = compute_max(grid[i])
    # Update the global maximum
    current_global = max(row_max)
    print(current_global)
```

### Explanation
1. **Grid Initialization**: The grid is read from the input and stored as a list of lists, where each sublist represents a row of bears.
2. **Row Maxima Calculation**: The `compute_max` function iterates through each row to determine the longest sequence of consecutive 1s. This value is stored in `row_max` for each row.
3. **Global Maximum**: The initial global maximum is derived from the maximum value in `row_max`.
4. **Query Processing**: For each query, the specified cell's state is flipped. The row containing this cell is then re-evaluated to update its maximum consecutive 1s. The global maximum is recalculated by taking the maximum of all row maxima and printed.

This approach ensures that each query is processed efficiently by only recalculating the necessary row and updating the global maximum, leading to an optimal solution within the problem constraints.
