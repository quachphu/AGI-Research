To solve this problem, we need to shuffle a deck of cards represented by a string according to a sequence of specified shuffle operations. Each shuffle operation involves moving a certain number of cards from the bottom of the deck to the top. The goal is to determine the final state of the deck after applying all the shuffle operations.

### Approach
1. **Input Reading**: Read the input datasets until a line containing a single '-' is encountered.
2. **Shuffle Operations**: For each dataset, read the initial deck string, the number of shuffles, and the sequence of shuffle values.
3. **Apply Shuffles**: For each shuffle value, split the deck into two parts: the first part of length `h` (cards from the bottom) and the remaining part. The new deck is formed by appending the first part to the end of the remaining part.
4. **Output the Result**: After applying all shuffles for a dataset, print the resulting deck.

### Solution Code
```python
import sys

def process_decks():
    while True:
        deck = sys.stdin.readline().strip()
        if deck == '-':
            break
        m = int(sys.stdin.readline().strip())
        hs = [int(sys.stdin.readline().strip()) for _ in range(m)]
        for h in hs:
            deck = deck[h:] + deck[:h]
        print(deck)

process_decks()
```

### Explanation
1. **Reading Input**: The input is read line by line. Each dataset starts with a deck string followed by the number of shuffles and the shuffle values.
2. **Processing Each Dataset**: For each dataset, the initial deck is processed by applying each shuffle operation in sequence. Each shuffle operation rearranges the deck by moving the specified number of cards from the bottom to the top.
3. **Shuffle Mechanism**: For a given shuffle value `h`, the deck is split into two parts: the first `h` characters and the remaining characters. The new deck is formed by concatenating the remaining characters followed by the first `h` characters.
4. **Termination Condition**: The loop terminates when a deck string consisting of a single '-' is encountered.

This approach ensures that each shuffle operation is applied efficiently, and the final state of the deck is printed correctly for each dataset. The solution handles multiple datasets and efficiently processes each shuffle operation in linear time relative to the length of the deck string.
