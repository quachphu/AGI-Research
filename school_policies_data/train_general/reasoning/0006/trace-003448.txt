To solve this problem, we need to determine the number of ways to flip some subset of directed roads in a graph such that the resulting graph has no directed cycles. The solution involves decomposing the graph into cycles and trees leading into those cycles, then calculating the valid configurations for each component.

### Approach
1. **Cycle Detection**: Identify all cycles in the directed graph using a traversal method. Each node in a functional graph (where each node has exactly one outgoing edge) belongs to exactly one cycle or a tree leading into a cycle.
2. **Component Size Calculation**: For each cycle, determine the size of the component it forms, which includes the cycle itself and all nodes in trees leading into it.
3. **Valid Configurations**: For each cycle component, the number of valid configurations is given by \((2^m - 2) \times 2^k\), where \(m\) is the length of the cycle and \(k\) is the number of tree edges in the component. This formula accounts for breaking the cycle and allowing any configuration for the tree edges.
4. **Modulo Arithmetic**: Use modulo \(10^9 + 7\) to handle large numbers efficiently.

### Solution Code
```python
import sys
from collections import deque

MOD = 10**9 + 7

def main():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))  # a is 1-based in the problem's input
    
    # Adjust a to 1-based indices
    a = [0] + a  # Now a[1] is the first town's road
    
    # Build reverse graph: adj_rev[v] contains u where original road is u -> v
    adj_rev = [[] for _ in range(n + 1)]
    for u in range(1, n + 1):
        v = a[u]
        adj_rev[v].append(u)
    
    # Find all cycles in the functional graph
    visited = [False] * (n + 1)
    cycles = []
    for u in range(1, n + 1):
        if not visited[u]:
            path = []
            current = u
            while True:
                if visited[current]:
                    if current in path:
                        idx = path.index(current)
                        cycles.append(path[idx:])
                    break
                else:
                    visited[current] = True
                    path.append(current)
                    current = a[current]
    
    # Compute component sizes for each cycle using BFS on the reverse graph
    component_visited = [False] * (n + 1)
    component_sizes = []
    for cycle in cycles:
        queue = deque()
        component_size = 0
        for node in cycle:
            if not component_visited[node]:
                component_visited[node] = True
                queue.append(node)
                component_size += 1
        while queue:
            u = queue.popleft()
            for v in adj_rev[u]:
                if not component_visited[v]:
                    component_visited[v] = True
                    component_size += 1
                    queue.append(v)
        component_sizes.append((len(cycle), component_size))
    
    # Precompute powers of 2 up to the maximum component size needed
    max_power = max((cs for m, cs in component_sizes), default=0)
    pow2 = [1] * (max_power + 1)
    for i in range(1, max_power + 1):
        pow2[i] = (pow2[i-1] * 2) % MOD
    
    # Calculate the result as the product of terms for each cycle
    result = 1
    for m, cs in component_sizes:
        term = (pow2[m] - 2) % MOD
        term = term * pow2[cs - m] % MOD
        result = (result * term) % MOD
    
    print(result)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Cycle Detection**: The code traverses each node to detect cycles. Each cycle is stored once detected.
2. **Reverse Graph Construction**: The reverse graph helps in determining all nodes that can reach a cycle, which forms the component of that cycle.
3. **Component Size Calculation**: Using BFS on the reverse graph starting from cycle nodes, we determine the component size for each cycle.
4. **Precompute Powers of 2**: Efficiently compute powers of 2 up to the maximum component size to avoid repeated calculations.
5. **Result Calculation**: For each cycle, compute the valid configurations and multiply them together, taking modulo \(10^9 + 7\) to handle large numbers.

This approach efficiently decomposes the problem into manageable parts, ensuring correctness and performance even for large input sizes.
