To solve this problem, we need to determine the minimal time required for Liss to eat all the nuts on top of trees, starting from the root of the first tree. Liss can walk up or down trees, eat nuts, and jump to the next tree if the height allows. The goal is to minimize the time taken by optimizing the movements between trees.

### Approach
1. **Climb to the Top**: For each tree, Liss needs to climb from her current height to the top of the tree to eat the nut.
2. **Eat the Nut**: Once at the top, eating the nut takes 1 second.
3. **Prepare for Jump**: After eating, Liss must climb down to a height that allows her to jump to the next tree. The optimal height to climb down to is the minimum of the current tree's height and the next tree's height.
4. **Jump to Next Tree**: Jumping takes 1 second and requires the height to be within the next tree's height.

By iterating through each tree and calculating the necessary movements step-by-step, we can accumulate the total time required.

### Solution Code
```python
n = int(input())
h = [int(input()) for _ in range(n)]
total = 0
current = 0
for i in range(n):
    climb = h[i] - current
    total += climb
    total += 1  # eat the nut
    if i < n - 1:
        next_h = h[i + 1]
        desired = min(h[i], next_h)
        total += (h[i] - desired)
        total += 1  # jump to next tree
        current = desired
print(total)
```

### Explanation
1. **Reading Input**: The number of trees and their respective heights are read from the input.
2. **Initialization**: `total` time starts at 0, and `current` height starts at 0 (root of the first tree).
3. **Loop Through Trees**: For each tree:
   - **Climb Up**: Calculate the time to climb from the current height to the top of the current tree.
   - **Eat Nut**: Add 1 second for eating the nut.
   - **Prepare for Jump**: If not the last tree, calculate the optimal height to climb down to (minimum of current tree's height and next tree's height), add the time to climb down, and add 1 second for the jump.
4. **Update Current Height**: After jumping, update the current height to the height prepared for the next tree.

This approach ensures that Liss takes the minimal necessary steps by always preparing optimally for the next jump, thus minimizing the total time required.
