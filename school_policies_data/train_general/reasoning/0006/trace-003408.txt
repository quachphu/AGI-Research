To solve this problem, we need to determine the minimum cost to buy exactly N liters of ice tea from a store that sells bottles of different volumes and costs. The key is to find the most cost-effective combination of bottle sizes to minimize the total expenditure.

### Approach
1. **Understand the Bottle Costs**: The store sells ice tea in bottles of 0.25 liters (Q yen), 0.5 liters (H yen), 1 liter (S yen), and 2 liters (D yen). 
2. **Cost per Liter**: Calculate the minimum cost to buy 1 liter by comparing the costs of using smaller bottles:
   - Four 0.25-liter bottles (4Q yen)
   - Two 0.5-liter bottles (2H yen)
   - One 1-liter bottle (S yen)
3. **Cost for 2 Liters**: Determine the minimum cost for 2 liters by comparing:
   - The cost of two 1-liter bottles (twice the minimum 1-liter cost)
   - One 2-liter bottle (D yen)
4. **Calculate Total Cost**: For N liters, use the optimal 2-liter cost as much as possible and handle any remaining 1 liter with the optimal 1-liter cost.

### Solution Code
```python
q, h, s, d = map(int, input().split())
n = int(input())

per_liter = min(4 * q, 2 * h, s)
two_liter = min(per_liter * 2, d)

k = n // 2
rem = n % 2

total = k * two_liter + rem * per_liter

print(total)
```

### Explanation
1. **Cost per Liter Calculation**: We first determine the cheapest way to buy 1 liter by considering all possible combinations of smaller bottles. This is stored in `per_liter`.
2. **Cost for 2 Liters**: Next, we check if buying a 2-liter bottle is cheaper than buying two 1-liter bottles. This is stored in `two_liter`.
3. **Total Cost Calculation**: For the given N liters, we use as many 2-liter bottles as possible (handled by integer division `n // 2`) and then use the optimal 1-liter cost for any remaining liter (handled by `n % 2`).

This approach ensures that we efficiently minimize the cost by leveraging bulk purchases (2-liter bottles) where beneficial and using the most economical 1-liter option for any remaining volume. The solution efficiently handles very large values of N due to its O(1) complexity.
