To solve this problem, we need to determine the minimum number of operations required to change the ratio of even and odd numbers to 2:3. If it's impossible, we should return -1.

### Approach
1. **Check Divisibility by 5**: The sum of even and odd numbers must be divisible by 5 for the ratio 2:3 to be possible. If not, output -1.
2. **Calculate Target Values**: If the sum is divisible by 5, compute the target number of even and odd numbers required to achieve the ratio 2:3.
3. **Determine Adjustments**: Calculate the difference (delta) between the current number of even numbers and the target. Use this delta to determine the range of possible operations.
4. **Check Feasibility**: Check if the required adjustments are within the bounds of the current counts of even and odd numbers. If not, output -1.
5. **Compute Minimum Operations**: Calculate the minimum operations needed using the feasible range of adjustments.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        e = int(input[idx])
        o = int(input[idx + 1])
        idx += 2
        total = e + o
        if total % 5 != 0:
            print(-1)
            continue
        e_target = (2 * total) // 5
        delta = e_target - e
        x_low = max(0, -delta)
        x_high = min(e, o - delta)
        if x_low > x_high:
            print(-1)
        else:
            res = 2 * x_low + delta
            print(res)

if __name__ == "__main__":
    main()
```
