To solve this problem, we need to determine the two faded digits of a 5-digit price tag and the maximum possible price per nail, given the number of nails and the three visible middle digits of the price. The solution must ensure the price is a valid 5-digit number, divisible by the number of nails, and if multiple valid prices exist, select the highest possible price.

### Approach
1. **Input Reading**: Read the number of test cases. For each test case, read the number of nails (N) and the three middle digits (X, Y, Z) of the price.
2. **Generate Candidates**: For each possible combination of the first digit (D1, 1-9) and the last digit (D5, 0-9), construct the 5-digit number and check if it is divisible by N.
3. **Select Maximum Valid Price**: Track the highest valid price. If no valid price is found, output 0. Otherwise, output the first and last digits of the highest valid price and the price per nail.

### Solution Code
```python
def find_price():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N = int(input[idx])
        idx += 1
        X = int(input[idx])
        Y = int(input[idx+1])
        Z = int(input[idx+2])
        idx += 3
        
        max_total = -1
        best_d1 = best_d5 = -1
        
        for d1 in range(1, 10):
            for d5 in range(0, 10):
                total = d1 * 10000 + X * 1000 + Y * 100 + Z * 10 + d5
                if total % N == 0:
                    if total > max_total:
                        max_total = total
                        best_d1 = d1
                        best_d5 = d5
        
        if max_total == -1:
            print(0)
        else:
            per_nail = max_total // N
            print(f"{best_d1} {best_d5} {per_nail}")

find_price()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, then parsed sequentially. The number of test cases (T) is read first.
2. **Loop Through Test Cases**: For each test case, read N (number of nails) and the middle three digits (X, Y, Z).
3. **Generate Possible Prices**: Construct all possible 5-digit numbers by iterating over all valid first (1-9) and last (0-9) digits. Each number is checked for divisibility by N.
4. **Track Maximum Valid Price**: Keep track of the highest valid price. If valid prices exist, the highest one is used to compute the price per nail. If no valid price is found, output 0.

This approach ensures that we efficiently check all possible valid prices, select the highest one, and compute the required results accurately.
