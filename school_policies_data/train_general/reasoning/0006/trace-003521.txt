To solve this problem, we need to determine the maximum number of operations that can be performed on a set of points in a 2D plane. Each operation involves adding a new point to form a rectangle when exactly three of the four corners are present.

### Approach
1. **Model as Bipartite Graph**: Represent the points as a bipartite graph where one set of nodes represents x-coordinates and the other set represents y-coordinates. Each point (x, y) is an edge connecting node x to node y.
2. **Union-Find Data Structure**: Use a Disjoint Set Union (DSU) to manage the connected components of the bipartite graph. This helps efficiently merge components and track their sizes.
3. **Component Analysis**: For each connected component in the bipartite graph, calculate the number of x-coordinates (m) and y-coordinates (n). The maximum number of edges (points) in a component is m * n.
4. **Edge Count Calculation**: Subtract the initial number of edges (points) in each component from the maximum possible edges to determine the number of operations that can be performed for that component.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    points = []
    for _ in range(N):
        x = int(input[idx])
        y = int(input[idx+1])
        points.append((x, y))
        idx += 2

    parent = {}
    rank = {}
    x_count = {}
    y_count = {}

    def find(u):
        while parent[u] != u:
            parent[u] = parent[parent[u]]
            u = parent[u]
        return u

    for x, y in points:
        y_node = y + 10**5
        for node in [x, y_node]:
            if node not in parent:
                parent[node] = node
                rank[node] = 1
                if node == x:
                    x_count[node] = 1
                    y_count[node] = 0
                else:
                    x_count[node] = 0
                    y_count[node] = 1
        root_x = find(x)
        root_ynode = find(y_node)
        if root_x != root_ynode:
            if rank[root_x] > rank[root_ynode]:
                parent[root_ynode] = root_x
                x_count[root_x] += x_count[root_ynode]
                y_count[root_x] += y_count[root_ynode]
            else:
                parent[root_x] = root_ynode
                x_count[root_ynode] += x_count[root_x]
                y_count[root_ynode] += y_count[root_x]
                if rank[root_x] == rank[root_ynode]:
                    rank[root_ynode] += 1

    edge_count = defaultdict(int)
    for x, y in points:
        root = find(x)
        edge_count[root] += 1

    ans = 0
    for root in edge_count:
        m = x_count[root]
        n = y_count[root]
        ans += m * n - edge_count[root]
    print(ans)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into a list of points.
2. **Union-Find Initialization**: The DSU structures (parent, rank, x_count, y_count) are initialized to manage the nodes and their connections.
3. **Union Operations**: For each point, the corresponding x and y nodes are merged in the DSU. This helps track connected components.
4. **Component Analysis**: After processing all points, each component's root node is identified, and the number of x and y nodes in the component is determined.
5. **Edge Count and Result Calculation**: For each component, the maximum possible edges (m * n) are computed, and the difference from the initial edges gives the number of operations possible for that component. The sum of these values across all components gives the final result.

This approach efficiently handles the constraints and ensures optimal performance using union-find with path compression and union by rank.
