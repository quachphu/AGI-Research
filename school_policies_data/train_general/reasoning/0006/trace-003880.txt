To solve this problem, we need to determine if each given integer is a prime number. A prime number is a natural number greater than 1 that has no positive divisors other than 1 and itself. The solution involves efficiently checking the primality of each number provided in the input.

### Approach
1. **Input Handling**: Read the number of test cases, followed by the integers to be tested.
2. **Prime Check Function**: For each integer, check if it is a prime number using an optimized approach:
   - **Immediate Checks**: If the number is less than 2, it is not prime. If the number is 2, it is prime. If the number is even and greater than 2, it is not prime.
   - **Divisor Check**: For numbers greater than 2 and odd, check divisibility from 3 up to the square root of the number. If any divisor is found, the number is not prime.
3. **Output**: For each number, print "yes" if it is prime and "no" otherwise.

### Solution Code
```python
import sys
import math

def is_prime(n):
    if n <= 1:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False
    sqrt_n = int(math.sqrt(n))
    for i in range(3, sqrt_n + 1, 2):
        if n % i == 0:
            return False
    return True

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline().strip())
        print("yes" if is_prime(n) else "no")

if __name__ == "__main__":
    main()
```

### Explanation
- **Prime Check Optimization**: By checking divisibility up to the square root of the number, we reduce the number of checks significantly. For example, if a number `n` is not a prime, it can be factored into two factors `a` and `b` such that `a * b = n`. If both factors were greater than the square root of `n`, their product would exceed `n`, so at least one factor must be less than or equal to the square root of `n`.
- **Handling Even Numbers**: After checking for 2, all even numbers are immediately identified as non-prime, reducing unnecessary checks.
- **Efficiency**: The algorithm efficiently checks for prime by iterating only through necessary potential divisors, ensuring optimal performance even for the upper constraint values.

This approach ensures that we efficiently and accurately determine the primality of each number in the input, adhering to the problem constraints and requirements.
