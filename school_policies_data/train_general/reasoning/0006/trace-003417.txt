To solve this problem, we need to determine if the given function \( f \) on set \( S \) is such that any two functions \( g \) and \( h \) that agree on the image of \( f \) must agree everywhere on \( S \). If not, we need to provide a counterexample.

### Approach
1. **Understanding the Problem**: The problem boils down to checking if the function \( f \) is surjective (i.e., every element of \( S \) is mapped to by some element of \( S \)). If \( f \) is surjective, then any functions \( g \) and \( h \) that agree on the image of \( f \) must agree everywhere. If \( f \) is not surjective, we can construct such \( g \) and \( h \) that agree on the image of \( f \) but differ elsewhere.

2. **Check Surjectivity**: To check if \( f \) is surjective, we verify if the image of \( f \) (the set of all values \( f(a_i) \)) is equal to \( S \).

3. **Construct Counterexample**: If \( f \) is not surjective, we construct two functions \( g \) and \( h \) such that they agree on the image of \( f \) but differ on at least one element not in the image.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

image = set(b)
s_set = set(a)

if image == s_set:
    print("Yes")
else:
    print("No")
    s = a[0]
    t = a[1]
    g = []
    h = []
    for x in a:
        if x in image:
            g_val = s
            h_val = s
        else:
            g_val = s
            h_val = t
        g.append(g_val)
        h.append(h_val)
    print(' '.join(map(str, g)))
    print(' '.join(map(str, h)))
```

### Explanation
1. **Reading Input**: The input consists of the size of the set \( N \), the elements of the set \( S \), and the list of values \( f(a_i) \).

2. **Check Surjectivity**: Convert the list of \( f(a_i) \) values into a set (image) and compare it with the set \( S \). If they are equal, \( f \) is surjective, and we print "Yes".

3. **Construct Counterexample**: If \( f \) is not surjective, we construct two functions \( g \) and \( h \). Both functions map elements in the image of \( f \) to the same value (the first element of \( S \)). For elements not in the image, \( g \) maps them to the first element of \( S \), while \( h \) maps them to the second element of \( S \). This ensures \( g \) and \( h \) agree on the image of \( f \) but differ elsewhere, providing the required counterexample.
