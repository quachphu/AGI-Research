To solve this problem, we need to determine how many times Kolya will need to empty the waste section of his juicer when processing a sequence of oranges. The waste section overflows when the total size of the processed oranges exceeds a given threshold. 

### Approach
1. **Input Reading**: Read the number of oranges, the maximum size of an orange that can be juiced, and the overflow threshold for the waste section.
2. **Processing Each Orange**: Iterate through each orange's size. If an orange's size exceeds the maximum allowable size, it is skipped.
3. **Waste Accumulation**: For each valid orange (size within the limit), accumulate its size into the current waste total.
4. **Check Overflow**: After adding each valid orange, check if the accumulated waste exceeds the threshold. If it does, increment the count of times the waste section is emptied and reset the accumulator.

### Solution Code
```python
n, b, d = map(int, input().split())
oranges = list(map(int, input().split()))

count = 0
current = 0

for a in oranges:
    if a > b:
        continue
    current += a
    if current > d:
        count += 1
        current = 0

print(count)
```

### Explanation
1. **Reading Input**: The first line of input is parsed into three integers `n`, `b`, and `d`, representing the number of oranges, the maximum size of an orange that can be processed, and the overflow threshold respectively. The second line contains the sizes of the oranges.
2. **Initialization**: Two variables are initialized: `count` to keep track of how many times the waste section is emptied, and `current` to accumulate the total size of processed oranges.
3. **Processing Oranges**: For each orange, if its size exceeds `b`, it is skipped. Otherwise, its size is added to `current`.
4. **Overflow Check**: After each addition to `current`, check if it exceeds `d`. If it does, increment `count` and reset `current` to 0.
5. **Output**: Finally, the count of how many times the waste section was emptied is printed.

This approach efficiently processes each orange in linear time, ensuring optimal performance even for the upper limits of input constraints.
