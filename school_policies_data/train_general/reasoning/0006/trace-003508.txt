To solve this problem, we need to efficiently manage the state of a bookcase through a series of operations, including reverting to previous states. The solution must track the number of books after each operation, even when operations revert to a previous state.

### Approach
1. **Persistent Data Structure**: Each version of the bookcase is stored as a list of tuples, where each tuple represents the state of a shelf. This allows us to efficiently revert to any previous state.
2. **Efficient State Tracking**: Each shelf's state is tracked using three variables: the flip count (indicating if the shelf has been inverted), a bitmask for modified positions, and another bitmask for stored values of those positions.
3. **Handling Operations**:
   - **Type 1 (Place Book)**: Adjust the state of the specified position considering the current flip count.
   - **Type 2 (Remove Book)**: Adjust the state similarly, ensuring the position's effective value is updated.
   - **Type 3 (Invert Shelf)**: Toggle the flip count and adjust the effective values of all positions on the shelf.
   - **Type 4 (Revert State)**: Directly copy the state from a previous version.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx]); idx += 1
    m = int(input[idx]); idx += 1
    q = int(input[idx]); idx += 1

    # Initialize version 0: all shelves (f=0, modified_mask=0, stored_mask=0)
    initial_shelves = [ (0, 0, 0) for _ in range(n) ]
    versions = [ initial_shelves ]

    for _ in range(q):
        parts = input[idx:idx+4]
        op = parts[0]
        if op == '1' or op == '2':
            # Type 1 or 2: i, j
            i = int(parts[1]) - 1  # convert to 0-based shelf index
            j = int(parts[2])
            idx += 3
            j_bit = 1 << (j-1)
            prev_shelves = versions[-1]
            new_shelves = list(prev_shelves)
            f, modified_mask, stored_mask = prev_shelves[i]

            if op == '1':
                # Place a book if effective is 0
                is_modified = (modified_mask & j_bit) != 0
                if is_modified:
                    current_stored = (stored_mask & j_bit) != 0
                    effective_value = current_stored ^ f
                    if effective_value == 0:
                        new_stored = 1 ^ f
                        if new_stored:
                            new_stored_mask = stored_mask | j_bit
                        else:
                            new_stored_mask = stored_mask & ~j_bit
                        new_shelves[i] = (f, modified_mask, new_stored_mask)
                else:
                    effective_value = f
                    if effective_value == 0:
                        new_modified_mask = modified_mask | j_bit
                        new_stored = 1 ^ f
                        new_stored_mask = stored_mask | (new_stored << (j-1))
                        new_shelves[i] = (f, new_modified_mask, new_stored_mask)
            else:  # op == '2'
                # Remove the book if effective is 1
                is_modified = (modified_mask & j_bit) != 0
                if is_modified:
                    current_stored = (stored_mask & j_bit) != 0
                    effective_value = current_stored ^ f
                    if effective_value == 1:
                        new_stored = 0 ^ f
                        if new_stored:
                            new_stored_mask = stored_mask | j_bit
                        else:
                            new_stored_mask = stored_mask & ~j_bit
                        new_shelves[i] = (f, modified_mask, new_stored_mask)
                else:
                    effective_value = f
                    if effective_value == 1:
                        new_modified_mask = modified_mask | j_bit
                        new_stored = 0 ^ f
                        new_stored_mask = stored_mask | (new_stored << (j-1))
                        new_shelves[i] = (f, new_modified_mask, new_stored_mask)
            versions.append(new_shelves)
        elif op == '3':
            # Type 3: invert shelf i
            i = int(parts[1]) - 1
            idx += 2
            prev_shelves = versions[-1]
            new_shelves = list(prev_shelves)
            f, modified_mask, stored_mask = prev_shelves[i]
            new_f = 1 - f
            new_shelves[i] = (new_f, modified_mask, stored_mask)
            versions.append(new_shelves)
        else:  # op == '4'
            # Type 4: revert to version k
            k = int(parts[1])
            idx += 2
            new_shelves = list(versions[k])
            versions.append(new_shelves)
        
        # Compute the total books for the new version
        current_shelves = versions[-1]
        total = 0
        for (f, modified_mask, stored_mask) in current_shelves:
            common = modified_mask & stored_mask
            sum_modified = bin(common).count('1')
            if f == 0:
                total += sum_modified
            else:
                total += m - sum_modified
        print(total)

if __name__ == "__main__":
    main()
```

- **Efficiency**: Using bitmasks allows efficient updates and queries, while storing each version's state ensures quick reverts.
