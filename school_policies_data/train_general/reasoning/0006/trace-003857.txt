### Approach

5. **Result Collection**: Collect all unique step counts that reach the Queen. If no valid paths are found, return -1. Otherwise, return the shortest step count and the sorted list of all unique steps.

    T = int(input[idx])
    idx += 1
    for case in range(1, T + 1):
        while idx < len(input) and input[idx].strip() == '':
            idx += 1
        if idx >= len(input):
            break
        N = int(input[idx])
        idx += 1
        matrix = []
        for _ in range(N):
            while idx < len(input) and input[idx].strip() == '':
                idx += 1
            if idx >= len(input):
                row = []
            else:
                row = input[idx].strip().split()
                idx += 1
            matrix.append(row)
        # Find positions of M and Q
        m_pos = None
        q_pos = None
        for i in range(N):
            for j in range(N):
                if matrix[i][j] == 'M':
                    m_pos = (i, j)
                elif matrix[i][j] == 'Q':
                    q_pos = (i, j)
        if not m_pos or not q_pos:
            print(f"Case {case}: -1")
            continue
        if m_pos == q_pos:
            print(f"Case {case}: 0 <0>")
            continue
        # BFS setup
        visited = [[set() for _ in range(N)] for _ in range(N)]
        q = deque()
        q.append((m_pos[0], m_pos[1], 0))
        visited[m_pos[0]][m_pos[1]].add(0)
        result = set()
        # Directions: up, down, left, right
        dirs = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        while q:
            i, j, s = q.popleft()
            if (i, j) == q_pos:
                result.add(s)
                continue
            for di, dj in dirs:
                ni, nj = i + di, j + dj
                if 0 <= ni < N and 0 <= nj < N:
                    cell = matrix[ni][nj]
                    if cell == '$':
                        continue
                    new_steps = s + 1
                    if new_steps not in visited[ni][nj]:
                        visited[ni][nj].add(new_steps)
                        q.append((ni, nj, new_steps))
        if not result:
            print(f"Case {case}: -1")
        else:
            sorted_steps = sorted(result)
            min_step = sorted_steps[0]
            steps_str = ' '.join(map(str, sorted_steps))
            print(f"Case {case}: {min_step} <{steps_str}>")

if __name__ == "__main__":
    main()

### Explanation
1. **Input Parsing**: The input is read and split into lines. Each test case is processed to extract the matrix and identify the positions of Mario and the Queen.
2. **BFS Initialization**: The BFS queue starts from Mario's position with 0 steps. Each cell visited is tracked with the number of steps taken to reach it.
3. **Path Exploration**: For each cell, the algorithm explores all four possible directions. If a direction leads to the Queen, the step count is recorded. Dragons ($) are avoided.
4. **Result Collection**: After BFS completes, the unique step counts to reach the Queen are sorted. The shortest step is the optimized move. If no valid paths are found, the result is -1.

This approach ensures that all possible paths are explored efficiently, and the shortest path is found using BFS, which is optimal for finding the shortest path in an unweighted grid.
