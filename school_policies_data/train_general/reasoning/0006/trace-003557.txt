To solve this problem, we need to determine how many times the word "Bulbasaur" can be formed from a given string, considering case sensitivity and that each character can be used exactly once per formation of the word.

### Approach
1. **Character Requirements**: The word "Bulbasaur" consists of specific characters with exact counts:
   - 'B' (1 time)
   - 'u' (2 times)
   - 'l' (1 time)
   - 'b' (1 time)
   - 'a' (2 times)
   - 's' (1 time)
   - 'r' (1 time)

2. **Frequency Count**: Count the occurrences of each character in the input string.

3. **Determine Feasibility**: For each character required to form "Bulbasaur", calculate how many times it can contribute to forming the word by dividing the available count by the required count. The minimum value across all required characters gives the maximum number of times "Bulbasaur" can be formed.

### Solution Code
```python
def count_bulbasaur():
    from collections import Counter
    s = input().strip()
    counts = Counter(s)
    required = {'B': 1, 'u': 2, 'l': 1, 'b': 1, 'a': 2, 's': 1, 'r': 1}
    min_count = float('inf')
    for char, req in required.items():
        available = counts.get(char, 0)
        possible = available // req
        if possible < min_count:
            min_count = possible
    print(min_count)

count_bulbasaur()
```

### Explanation
1. **Input Handling**: The input string is read and stripped of any leading/trailing whitespace.
2. **Character Counting**: Using the `Counter` from the `collections` module, we count the frequency of each character in the input string.
3. **Required Characters Check**: For each character required to form "Bulbasaur", we check how many times it appears in the input string and determine how many full contributions it can make towards forming the word.
4. **Minimum Calculation**: The minimum number of contributions across all required characters determines the maximum number of times "Bulbasaur" can be formed, which is then printed as the result.

This approach efficiently checks the feasibility of forming the word multiple times by leveraging character frequency counts and ensures optimal performance even for the upper constraint of the input string length.
