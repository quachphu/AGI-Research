To solve this problem, we need to determine the number of distinct objects mentioned in an ancient Aramic script based on the roots of the words. Each word's root is defined by its unique set of characters, and permutations of these roots are considered the same object.

### Approach
1. **Understanding Roots**: Each word's root is derived by taking the unique characters in the word, sorting them, and forming a string. This ensures that permutations of the same set of characters are treated identically.
2. **Set for Uniqueness**: By converting each word to its root and storing these roots in a set, we can efficiently track unique objects, as sets automatically handle duplicates.

### Solution Code
```python
n = int(input())
words = input().split()

roots = set()
for word in words:
    unique_chars = set(word)
    sorted_chars = sorted(unique_chars)
    root = ''.join(sorted_chars)
    roots.add(root)

print(len(roots))
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` (number of words) followed by the words themselves.
2. **Processing Each Word**: For each word, we:
   - Extract its unique characters using a set.
   - Sort these characters to form a consistent root string.
3. **Tracking Unique Roots**: Using a set to store these roots ensures that only unique roots are counted.
4. **Output the Result**: The size of the set gives the number of distinct objects.

This approach efficiently handles up to the maximum constraints, ensuring correctness and optimal performance.
