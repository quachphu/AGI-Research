### Approach
1. **Count Occurrences**: First, count the occurrences of each color in both the available sheets and the required garland pieces.
2. **Check Feasibility**: Ensure that every color required in the garland is present in the available sheets. If any color is missing, it's impossible to make the garland, and we return -1.
3. **Calculate Maximum Area**: For each color required in the garland, the maximum contribution to the total area is the minimum of the number of available sheets of that color and the number of required pieces of that color. Sum these minimum values to get the maximum possible total area.

### Solution Code
```python
import sys
from collections import Counter

def compute_max_area():
    available = sys.stdin.readline().strip()
    garland = sys.stdin.readline().strip()

    available_counter = Counter(available)
    garland_counter = Counter(garland)

    total = 0
    for color, count in garland_counter.items():
        if color not in available_counter:
            print(-1)
            return
        total += min(count, available_counter[color])
    print(total)

compute_max_area()
```

1. **Reading Input**: The input consists of two lines. The first line represents the colors of the available sheets, and the second line represents the colors required for the garland.
2. **Counting Colors**: Using the `Counter` class from the `collections` module, we count the occurrences of each color in both the available sheets and the garland requirements.
3. **Feasibility Check**: For each color required in the garland, we check if it exists in the available sheets. If any required color is missing, we immediately return -1.
4. **Summing Contributions**: For each color that is present in both the available sheets and the garland requirements, we add the minimum of the required count and available count to the total area. This minimum ensures we use the maximum possible area from the available sheets without exceeding the required number of pieces for each color.
