To solve this problem, we need to determine how Alice and Bob can optimally divide slices of pie such that each of them maximizes their total amount of pie consumed. The decision-making process alternates based on who holds the "decider" token, starting with Bob. The solution involves dynamic programming to simulate each possible decision and its subsequent outcomes.

### Approach
1. **Dynamic Programming (DP) Setup**: We use a DP table where `dp[i][d]` represents the maximum amounts of pie Alice and Bob can eat starting from the i-th slice, with `d` indicating who holds the decider token (0 for Alice, 1 for Bob).

2. **State Transitions**:
   - **Alice's Turn (d=0)**: Alice can either take the current slice and pass the token to Bob, or give the slice to Bob and keep the token.
   - **Bob's Turn (d=1)**: Bob can either take the current slice and pass the token to Alice, or give the slice to Alice and keep the token.

3. **Optimal Decision**: At each step, the current decider chooses the option that maximizes their total pie, considering future decisions. This is computed by comparing the outcomes of taking the current slice versus giving it away.

4. **Base Case**: When all slices have been considered (`i == N`), both Alice and Bob have 0 pie.

### Solution Code
```python
n = int(input())
slices = list(map(int, input().split()))
dp = [[(0, 0) for _ in range(2)] for __ in range(n + 1)]

for i in range(n - 1, -1, -1):
    for d in [0, 1]:
        if d == 0:
            # Alice's turn to decide
            a1 = slices[i] + dp[i + 1][1][0]
            b1 = dp[i + 1][1][1]
            a2 = dp[i + 1][0][0]
            b2 = slices[i] + dp[i + 1][0][1]
            if a1 > a2:
                dp[i][d] = (a1, b1)
            else:
                dp[i][d] = (a2, b2)
        else:
            # Bob's turn to decide
            a1 = dp[i + 1][0][0]
            b1 = slices[i] + dp[i + 1][0][1]
            a2 = slices[i] + dp[i + 1][1][0]
            b2 = dp[i + 1][1][1]
            if b1 > b2:
                dp[i][d] = (a1, b1)
            else:
                dp[i][d] = (a2, b2)

result = dp[0][1]
print(result[0], result[1])
```

### Explanation
1. **Initialization**: The DP table `dp` is initialized with dimensions `(n+1) x 2`, where each entry holds a tuple representing the maximum pies Alice and Bob can eat from the current slice onward.

2. **Reverse Iteration**: We iterate from the last slice to the first. For each slice and each possible decider (Alice or Bob), we compute the optimal decision by considering both taking the slice or giving it away.

3. **Decision Making**:
   - **Alice's Decision**: She chooses between taking the slice (adding to her total and passing the token) or giving it to Bob (keeping the token).
   - **Bob's Decision**: He chooses between taking the slice (adding to his total and passing the token) or giving it to Alice (keeping the token).

4. **Result Extraction**: The result is derived from `dp[0][1]`, which represents the optimal outcome starting from the first slice with Bob as the initial decider.

This approach ensures that both players make optimal decisions at each step, leading to the maximum possible pie consumption for each.
