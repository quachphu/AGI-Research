To solve this problem, we need to determine the largest possible screen dimensions for a monitor that maintains a given aspect ratio and does not exceed the original dimensions. If it's impossible to achieve the desired ratio within the original dimensions, we should return 0 0.

### Approach
1. **Simplify the Aspect Ratio**: The given aspect ratio (x:y) should be simplified to its lowest terms by dividing both x and y by their greatest common divisor (gcd). This gives us the simplest form of the ratio, which we will use to compute potential screen dimensions.
2. **Determine Maximum Scaling Factor**: Calculate the maximum integer scaling factor (k) such that the scaled dimensions (k * simplified_x, k * simplified_y) do not exceed the original dimensions (a, b). This scaling factor is determined by taking the minimum of the maximum possible values derived from each dimension.
3. **Check Feasibility**: If the maximum scaling factor is zero, it means the desired ratio cannot be achieved within the original dimensions, and we return 0 0. Otherwise, compute and return the scaled dimensions.

### Solution Code
```python
import math

a, b, x, y = map(int, input().split())

g = math.gcd(x, y)
x_red = x // g
y_red = y // g

k1 = a // x_red
k2 = b // y_red
k = min(k1, k2)

if k == 0:
    print(0, 0)
else:
    print(x_red * k, y_red * k)
```

### Explanation
1. **Simplify the Aspect Ratio**: By dividing x and y by their gcd, we reduce the ratio to its simplest form, which helps in determining the possible dimensions more efficiently.
2. **Calculate Scaling Factor**: The maximum scaling factor (k) is determined by the minimum of the integer divisions of the original dimensions by the simplified ratio components. This ensures that both dimensions (height and width) do not exceed the original values.
3. **Output Result**: If the scaling factor is zero, output 0 0. Otherwise, compute the dimensions using the scaling factor and the simplified ratio components and print them.

This approach efficiently narrows down the possible dimensions using mathematical properties, ensuring the solution is both optimal and correct.
