To solve this problem, we need to calculate the number of days between two given dates in the Gregorian calendar, considering the leap year rules. The solution involves converting each date into a total number of days from a fixed starting point and then finding the absolute difference between these two counts.

### Approach
1. **Leap Year Check**: Determine if a year is a leap year using the Gregorian calendar rules: a year is a leap year if it is divisible by 4, but not by 100 unless it is also divisible by 400.
2. **Date to Days Conversion**: Convert each date into the total number of days from a fixed starting point (year 0). This involves:
   - Summing the days contributed by all years before the given year.
   - Adding the days contributed by each month in the given year up to the current month.
   - Adding the days in the current month.
3. **Calculate Difference**: Compute the absolute difference between the total days for the two dates.

### Solution Code
```python
import sys

def is_leap(y):
    if y % 4 != 0:
        return False
    elif y % 100 != 0:
        return True
    else:
        return y % 400 == 0

def date_to_days(y, m, d):
    # Calculate days contributed by full years before y
    leap_years = (y - 1) // 4 - (y - 1) // 100 + (y - 1) // 400
    total_days = (y - 1) * 365 + leap_years
    
    # Add days from the current year's months and days
    month_days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
    if is_leap(y):
        month_days[1] = 29
    
    # Sum days from all preceding months in the current year
    for month in range(m - 1):
        total_days += month_days[month]
    
    # Add the days in the current month
    total_days += d
    return total_days

def main():
    date1 = sys.stdin.readline().strip()
    date2 = sys.stdin.readline().strip()
    
    y1, m1, d1 = map(int, date1.split(':'))
    y2, m2, d2 = map(int, date2.split(':'))
    
    days1 = date_to_days(y1, m1, d1)
    days2 = date_to_days(y2, m2, d2)
    
    print(abs(days1 - days2))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Leap Year Check**: The function `is_leap` checks if a year is a leap year by applying the Gregorian rules.
2. **Date Conversion**: The function `date_to_days` converts a date into the total number of days since year 0. It calculates the days contributed by all previous years, including leap years, and then adds the days from the current year's months and days.
3. **Main Function**: The `main` function reads the input dates, converts each date to the total number of days, and prints the absolute difference between these two values, which is the number of days between the two dates.

This approach efficiently handles the conversion of dates to a day count and accurately computes the difference, considering all edge cases related to leap years and varying month lengths.
