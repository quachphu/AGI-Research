To solve this problem, we need to determine how many seconds each color combination (Red, Green, Blue, Yellow, Cyan, Magenta, White, Black) is visible based on the cycles of three LEDs (Red, Green, Blue) over a given time period T. Each LED alternates between being ON and OFF for specific durations, and the initial state for all LEDs is OFF.

### Approach
1. **Understand LED Cycles**: Each LED (Red, Green, Blue) has a cycle where it stays ON for R, G, and B seconds respectively, followed by the same duration in the OFF state. This means each LED's cycle length is twice its ON/OFF duration.
2. **Determine LED State at Each Second**: For each second from 0 to T-1, check if each LED is ON or OFF. This is determined by checking if the current second modulo twice the LED's cycle duration is within the ON period.
3. **Count Color Combinations**: Based on the ON/OFF states of the three LEDs at each second, determine the corresponding color combination and increment the respective counter.

### Solution Code
```python
def main():
    import sys
    T, R, G, B = map(int, sys.stdin.readline().split())
    red = green = blue = yellow = cyan = magenta = white = black = 0
    for t in range(T):
        r = (t % (2 * R)) >= R
        g = (t % (2 * G)) >= G
        b = (t % (2 * B)) >= B
        if r and not g and not b:
            red += 1
        elif not r and g and not b:
            green += 1
        elif not r and not g and b:
            blue += 1
        elif r and g and not b:
            yellow += 1
        elif not r and g and b:
            cyan += 1
        elif r and not g and b:
            magenta += 1
        elif r and g and b:
            white += 1
        else:
            black += 1
    print(red, green, blue, yellow, cyan, magenta, white, black)

main()
```

### Explanation
1. **Reading Input**: The input consists of four integers T, R, G, and B, representing the total time and the ON durations for each LED.
2. **Initializing Counters**: Eight counters are initialized to zero, each corresponding to a color combination.
3. **Loop Through Each Second**: For each second from 0 to T-1, the state (ON/OFF) of each LED is determined using modulo operations.
4. **Determine Color Combination**: Based on the combination of ON/OFF states of the LEDs, the corresponding color counter is incremented.
5. **Output Results**: The counts for each color combination are printed in the specified order.

This approach efficiently iterates through each second and checks the state of each LED, ensuring accurate counting of each color combination within the given constraints. The solution is optimized to handle the maximum constraints efficiently.
