To solve this problem, we need to determine the minimum number of trains required to operate on the Yamanote Line based on a given timetable. Each train departs from Osaki Station, completes a loop, and returns to Osaki Station. The goal is to find the maximum number of trains that are in use simultaneously at any point in time, which gives the minimum number of trains needed.

### Approach
1. **Convert Times to Seconds**: Convert the departure and arrival times from "hh:mm:ss" format to seconds since midnight for easier comparison and sorting.
2. **Event Creation**: For each train, create two events: a departure event and an arrival event.
3. **Sort Events**: Sort the events by time. If two events have the same time, arrival events are processed before departure events to allow immediate reuse of trains.
4. **Track Trains in Use**: Iterate through the sorted events, maintaining a count of current trains in use. Update the maximum number of trains required whenever a departure event is encountered.

### Solution Code
```python
import sys

def time_to_seconds(time_str):
    hh, mm, ss = map(int, time_str.split(':'))
    return hh * 3600 + mm * 60 + ss

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        if n == 0:
            break
        events = []
        for _ in range(n):
            depart, arrive = sys.stdin.readline().strip().split()
            d_sec = time_to_seconds(depart)
            a_sec = time_to_seconds(arrive)
            events.append((d_sec, 1))  # Departure event
            events.append((a_sec, 0))  # Arrival event
        # Sort events: first by time, then arrival before departure
        events.sort(key=lambda x: (x[0], x[1]))
        current_trains = 0
        max_trains = 0
        for t, typ in events:
            if typ == 1:
                current_trains += 1
                if current_trains > max_trains:
                    max_trains = current_trains
            else:
                current_trains -= 1
        print(max_trains)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Time Conversion**: The `time_to_seconds` function converts a time string into the total number of seconds since midnight. This simplifies time comparisons.
2. **Event Creation**: For each train's departure and arrival times, two events are created. Departure events are marked with `1` and arrival events with `0`.
3. **Sorting Events**: Events are sorted by time. If two events occur at the same time, arrival events (0) are processed before departure events (1) to allow immediate reuse of trains.
4. **Tracking Usage**: As we process each event, we adjust the count of current trains in use. The maximum count observed during this process gives the minimum number of trains required.

This approach efficiently determines the peak number of trains needed by leveraging event sorting and linear traversal, ensuring optimal performance even for large datasets.
