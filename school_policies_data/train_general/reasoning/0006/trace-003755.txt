To solve this problem, we need to determine if we can transform a given string into another string that contains the entire alphabet "abcdefghijklmnopqrstuvwxyz" as a subsequence by incrementing some of its characters. If possible, we should output the transformed string; otherwise, we should output -1.

### Approach
1. **Problem Analysis**: The goal is to check if we can increment characters of the input string such that the resulting string contains each letter of the alphabet in order as a subsequence. Each character can be incremented any number of times but cannot exceed 'z'.
2. **Greedy Strategy**: We will use a greedy approach to sequentially find each character of the alphabet ('a' to 'z') in the input string. For each character in the input string, if it can be incremented to the current target character (from 'a' to 'z'), we modify it to the target and move to the next target character.
3. **Efficiency**: By iterating through the string once and checking each character against the current target, we ensure an efficient O(n) solution where n is the length of the input string.

### Solution Code
```python
s = input().strip()
modified = list(s)
target = ord('a')

for i in range(len(s)):
    if target > ord('z'):
        break
    current_char = ord(s[i])
    if current_char <= target:
        modified[i] = chr(target)
        target += 1

print(''.join(modified) if target > ord('z') else -1)
```

### Explanation
1. **Initialization**: Convert the input string into a list for easy modification and initialize the target character to 'a'.
2. **Iterate through the Input String**: For each character in the input string:
   - If the current target character has been found beyond 'z', break out of the loop as we have successfully formed the alphabet subsequence.
   - Check if the current character can be incremented to the target character. If yes, update the character in the modified list to the target character and move to the next target character.
3. **Check Completion**: After processing all characters, check if we have reached the end of the alphabet ('z'). If yes, print the modified string; otherwise, print -1.

This approach ensures that we efficiently check each character once, making the solution optimal and suitable for large input sizes up to 100,000 characters.
