To solve this problem, we need to determine the maximum and minimum possible number of respondents who subscribe to both Newspaper X and Newspaper Y based on the given survey results. The solution involves understanding the constraints and applying logical reasoning to derive the answers.

### Approach
1. **Maximum Possible Subscribers**: The maximum number of respondents subscribing to both newspapers is determined by the smaller of the two counts (A or B). This is because the maximum overlap cannot exceed the smaller group of subscribers.
2. **Minimum Possible Subscribers**: The minimum number of respondents subscribing to both newspapers is determined by the overlap required when the sum of individual subscribers (A + B) exceeds the total number of respondents (N). If the sum of A and B is greater than N, the minimum overlap is calculated as (A + B - N). If not, the minimum overlap is zero.

### Solution Code
```python
n, a, b = map(int, input().split())
max_both = min(a, b)
min_both = max(a + b - n, 0)
print(max_both, min_both)
```

### Explanation
1. **Reading Input**: The input values for N (total respondents), A (subscribers of Newspaper X), and B (subscribers of Newspaper Y) are read and parsed.
2. **Calculating Maximum Overlap**: The maximum number of respondents who could subscribe to both newspapers is the minimum of A and B. This is because the overlap cannot exceed the smaller group.
3. **Calculating Minimum Overlap**: The minimum number of respondents subscribing to both is derived by checking if the combined subscriptions (A + B) exceed the total respondents. If they do, the minimum overlap is (A + B - N); otherwise, it is zero.
4. **Output**: The results for maximum and minimum overlap are printed.

This approach efficiently computes the required values using basic arithmetic operations and logical checks, ensuring optimal performance even for the upper constraint limits.
