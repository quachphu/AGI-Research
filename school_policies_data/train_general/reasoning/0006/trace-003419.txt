To solve this problem, we need to manage tenant movements across multiple buildings, floors, and rooms based on given notices. The goal is to track the number of tenants in each room and output the final state of each building after processing all notices.

### Approach
1. **Data Structure Initialization**: We start by initializing a 4-dimensional list to represent 4 buildings, each with 3 floors and 10 rooms per floor, all initialized to zero occupants.
2. **Processing Notices**: For each notice, we adjust the tenant count in the specified room by the given value. The building, floor, and room indices are converted from 1-based to 0-based for proper indexing.
3. **Output Formatting**: After processing all notices, we print the current tenant count for each room in each building. Each building's floors are printed sequentially, followed by a separator line between consecutive buildings.

### Solution Code
```python
def main():
    n = int(input())
    buildings = [[[0 for _ in range(10)] for _ in range(3)] for _ in range(4)]
    
    for _ in range(n):
        b, f, r, v = map(int, input().split())
        buildings[b-1][f-1][r-1] += v
    
    for i in range(4):
        for floor in buildings[i]:
            print(' ' + ' '.join(map(str, floor)))
        if i < 3:
            print('####################')

if __name__ == "__main__":
    main()
```

### Explanation
1. **Initialization**: The `buildings` list is structured as a 4x3x10 grid initialized with zeros to represent each room's initial state.
2. **Reading Input**: The number of notices `n` is read first. Each subsequent line contains the building, floor, room, and the change in tenant count, which are used to update the corresponding room's occupancy.
3. **Updating Tenants**: For each notice, the indices are adjusted to 0-based and the tenant count is updated by adding the given value (which can be negative for departures).
4. **Printing Results**: Each building's floors are printed in sequence. Each floor's tenant counts are formatted with a leading space and separated by spaces. The separator line `####################` is printed between buildings to distinguish them.

This approach efficiently processes the input and formats the output as required, ensuring clarity and correctness in tracking tenant movements.
