To solve this problem, we need to determine the maximum number of groups of cats that can be formed in a circle after some cats have left. The groups are defined by consecutive remaining cats, and each empty spot (where a cat has left) can split the circle into smaller groups.

### Approach
The key insight to solve this problem is to recognize that the maximum number of groups is determined by the arrangement of the remaining and removed cats. The optimal arrangement occurs when each removed cat is placed such that they split the circle into as many groups as possible. 

The solution can be derived using the following observations:
1. If no cats have left (m = 0), all cats form a single group.
2. If all cats have left (m = n), there are no groups.
3. Otherwise, the maximum number of groups is determined by the minimum of the number of removed cats (m) and the number of remaining cats (n - m). This is because each removed cat can potentially split the circle into a new group, but the number of groups cannot exceed the number of remaining cats.

### Solution Code
```python
n, m = map(int, input().split())
if m == 0:
    print(1)
elif m == n:
    print(0)
else:
    print(min(m, n - m))
```

### Explanation
- **Case 1: No cats have left (m = 0)**. All cats are still in the circle, forming a single group. Thus, the output is 1.
- **Case 2: All cats have left (m = n)**. There are no cats remaining, so there are no groups. Thus, the output is 0.
- **Case 3: Some cats have left (0 < m < n)**. The maximum number of groups is the minimum of the number of removed cats (m) and the number of remaining cats (n - m). This is because each removed cat can split the circle into a new group, but the number of groups cannot exceed the number of remaining cats, as each group must have at least one cat.

This approach efficiently computes the result in constant time, making it optimal for the given problem constraints.
