To solve this problem, we need to determine the maximum number of frames Nicholas can make using his sticks. Each frame requires two pairs of sticks, which can either form a square or a rectangle. The key insight is to count how many pairs of each stick length we can form and then determine how many frames can be made from these pairs.

### Approach
1. **Count Frequencies**: First, count the frequency of each stick length using a frequency dictionary.
2. **Calculate Pairs**: For each stick length, determine how many pairs can be formed. This is done by integer division of the frequency by 2.
3. **Sum Pairs**: Sum all the pairs obtained from each stick length.
4. **Determine Frames**: Each frame requires exactly two pairs of sticks. Therefore, the maximum number of frames is the total number of pairs divided by 2, using integer division.

### Solution Code
```python
import sys
from collections import Counter

def main():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    counts = Counter(a)
    total_pairs = sum(v // 2 for v in counts.values())
    print(total_pairs // 2)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first line gives the number of sticks, and the second line lists the lengths of these sticks.
2. **Frequency Count**: Using `collections.Counter`, we count how many times each stick length appears.
3. **Pairs Calculation**: For each stick length, we determine how many pairs can be formed (each pair requires two sticks, so we use integer division by 2).
4. **Total Frames**: The total number of pairs is summed up. Since each frame requires two pairs, the result is the total pairs divided by 2, again using integer division.

This approach efficiently computes the maximum number of frames by leveraging counting and simple arithmetic operations, ensuring an optimal solution.
