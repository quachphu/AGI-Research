To solve this problem, we need to determine the minimum number of operations required to make all elements of an array equal. Each operation involves merging an element into one of its neighbors. The key insight is that the sum of the array remains constant through these operations, so we need to check if the array can be partitioned into contiguous subarrays whose sum is a divisor of the total sum.

### Approach
1. **Sum Calculation**: Compute the sum of the array. This sum must be divisible by the number of remaining elements after some operations.
2. **Divisors Identification**: Identify all divisors of the sum. These divisors represent possible counts of remaining elements (each count must be a divisor of the sum).
3. **Partition Check**: For each divisor (in descending order), check if the array can be partitioned into contiguous subarrays each summing to the total sum divided by the divisor. The largest valid divisor gives the minimum number of operations.

### Solution Code
```python
import math

def get_divisors(s):
    divisors = set()
    for i in range(1, int(math.isqrt(s)) + 1):
        if s % i == 0:
            divisors.add(i)
            divisors.add(s // i)
    return sorted(divisors, reverse=True)

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    if all(x == a[0] for x in a):
        print(0)
        continue
    total = sum(a)
    divisors = get_divisors(total)
    possible_ds = [d for d in divisors if d <= n]
    found = False
    for d in possible_ds:
        target = total // d
        current_sum = 0
        count = 0
        valid = True
        for num in a:
            current_sum += num
            if current_sum == target:
                count += 1
                current_sum = 0
            elif current_sum > target:
                valid = False
                break
        if valid and count == d and current_sum == 0:
            print(n - d)
            found = True
            break
    if not found:
        print(n - 1)
```

### Explanation
1. **Sum Calculation**: The sum of the array is computed to determine potential target values for the contiguous subarrays.
2. **Divisors Identification**: By finding all divisors of the sum, we identify possible counts of remaining elements (each count must divide the sum).
3. **Partition Check**: For each divisor, check if the array can be split into contiguous subarrays each summing to the required target. The largest valid divisor minimizes the number of operations needed (n - divisor).

This approach efficiently narrows down the possible solutions by leveraging mathematical properties of divisors and ensures the solution is both optimal and correct.
