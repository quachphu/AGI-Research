To solve this problem, we need to determine the minimum number of columns to remove from a given n x m table of lowercase letters such that the rows are ordered lexicographically from top to bottom.

### Approach
The key insight is to process each column from left to right while keeping track of which pairs of consecutive rows are already in lexicographical order based on the columns kept so far. For each new column, we check if it can be kept without violating the order for any pairs of rows that are not yet determined. If a column can be kept, we update our tracking to note which pairs of rows are now fixed in order due to this column.

### Solution Code
```python
n, m = map(int, input().split())
rows = [input().strip() for _ in range(n)]
fixed = [False] * (n - 1)
kept = 0

for col in range(m):
    valid = True
    for i in range(n - 1):
        if not fixed[i] and rows[i][col] > rows[i+1][col]:
            valid = False
            break
    if valid:
        kept += 1
        for i in range(n - 1):
            if not fixed[i] and rows[i][col] < rows[i+1][col]:
                fixed[i] = True

print(m - kept)
```

### Explanation
1. **Initialization**: Read the input values and initialize a list `fixed` to track which pairs of consecutive rows are already ordered.
2. **Column Processing**: For each column, check if it can be kept by ensuring all currently unfixed row pairs are in non-decreasing order.
3. **Update Tracking**: If a column is kept, update the `fixed` list to mark pairs of rows that become ordered due to this column.
4. **Result Calculation**: The result is the total number of columns minus the number of columns kept, giving the minimum columns to remove.

This approach efficiently checks each column once and updates the tracking of ordered pairs, ensuring an optimal solution with a time complexity of O(n*m), which is efficient given the problem constraints.
