To solve this problem, we need to determine the minimum number of coins required to make all elements of an array zero using specific operations. The operations allow moving a unit from one element to another, with a cost incurred only when moving from a higher index to a lower index.

### Approach
The key insight is to track the cumulative surplus or deficit as we process the array from left to right. Here's the detailed approach:

1. **Track Carry**: As we iterate through each element, maintain a carry that accumulates the sum of elements processed so far.
2. **Handle Deficits**: If the carry becomes negative at any point, it indicates a deficit that must be covered by surpluses from the right. This deficit is converted into coins (since moving from higher to lower indices incurs a cost). Reset the carry to zero after accounting for the deficit.
3. **Sum Deficits**: The total number of coins required is the sum of all the deficits encountered during the iteration.

This approach ensures that we only count the necessary movements from higher indices to lower indices, thus minimizing the cost.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        a = list(map(int, input[ptr:ptr+n]))
        ptr += n
        carry = 0
        coins = 0
        for num in a:
            carry += num
            if carry < 0:
                coins += -carry
                carry = 0
        print(coins)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
- **Processing Each Test Case**: For each test case, we initialize the carry and coins. As we iterate through each element:
  - **Update Carry**: Add the current element to the carry.
  - **Check for Deficit**: If the carry is negative, this indicates a deficit. Convert this deficit to coins and reset the carry to zero.
- **Output Result**: After processing all elements of the array, the accumulated coins give the minimum number of coins required.

This method efficiently processes each element in linear time, ensuring the solution handles large input sizes within the problem constraints.
