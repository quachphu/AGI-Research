To solve this problem, we need to calculate the total amount of money Anshu receives from his father over a given number of days. The amount given each day increases by 1 Rupee each day, starting from 1 Rupee on the first day. The challenge is to efficiently compute the sum for very large values of days, which can have up to 20001 digits.

### Approach
The key insight here is to recognize that the sum of the first n natural numbers can be computed using the formula \( S = \frac{n(n+1)}{2} \). This formula allows us to compute the sum in constant time, \( O(1) \), which is efficient even for very large values of n. Python's ability to handle arbitrarily large integers ensures that we can process even the largest values of n without overflow issues.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    for i in range(1, t + 1):
        n_str = input[i]
        n = int(n_str)
        total = n * (n + 1) // 2
        print(total)

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings. The first element of this list is the number of test cases, `t`.
2. **Processing Each Test Case**: For each test case, we convert the string representation of the day number `n` to an integer. Python's `int` type can handle very large numbers, which is essential given the problem constraints.
3. **Computing the Sum**: Using the formula \( S = \frac{n(n+1)}{2} \), we compute the total money received up to day `n`. The division by 2 is performed using integer division to ensure the result remains an integer.
4. **Output the Result**: The result for each test case is printed immediately after computation.

This approach efficiently handles the constraints, ensuring that even the largest values of n are processed correctly and quickly.
