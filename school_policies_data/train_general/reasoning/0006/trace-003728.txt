To solve this problem, we need to determine the number of "holes" in a given text based on specific letters that form regions when written. The letters A, B, D, O, P, Q, and R each contribute to the hole count in different ways. Our task is to count these holes for each test case.

### Approach
1. **Identify Hole Contributions**: The letters A, D, O, P, Q, and R each contribute 1 hole, while B contributes 2 holes. All other letters contribute 0 holes.
2. **Read Input**: Read the number of test cases followed by the text for each test case.
3. **Calculate Holes**: For each test case, iterate through each character in the text, sum the hole contributions using a predefined dictionary that maps each letter to its respective hole count.
4. **Output Results**: Print the total hole count for each test case.

### Solution Code
```python
def main():
    import sys
    data = sys.stdin.read().splitlines()
    T = int(data[0])
    hole_counts = {'A': 1, 'B': 2, 'D': 1, 'O': 1, 'P': 1, 'Q': 1, 'R': 1}
    for i in range(1, T + 1):
        text = data[i]
        total = sum(hole_counts.get(c, 0) for c in text)
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read all at once and split into lines to handle multiple test cases efficiently.
- **Hole Dictionary**: A dictionary `hole_counts` is used to map each letter to its corresponding hole count.
- **Summing Holes**: For each test case, the total number of holes is calculated using a generator expression that sums the hole contributions of each character in the text.
- **Efficiency**: The solution efficiently processes each character in linear time relative to the length of the text, ensuring optimal performance even for the upper input limits.

This approach ensures that we accurately count the holes for each test case based on the predefined rules, providing a clear and efficient solution.
