To solve this problem, we need to determine the total time taken to execute all processes based on their calling order and ideal order. Each process either requires moving the front element to the end of the queue (taking 1 unit of time) or executing the process (taking 1 unit of time). 

### Approach
1. **Input Reading**: Read the number of processes and the calling and ideal orders from standard input.
2. **Queue Initialization**: Convert the calling order into a deque (double-ended queue) for efficient operations at both ends.
3. **Simulation**: For each process in the ideal order:
   - Continuously move the front element of the queue to the end until the front element matches the current target process from the ideal order.
   - Each move operation takes 1 unit of time.
   - Once the front element matches the target, remove it from the queue, which takes 1 unit of time.
4. **Time Calculation**: Sum up all the time units from both move and execute operations to get the total time.

### Solution Code
```python
import sys
from collections import deque

def main():
    n = int(sys.stdin.readline())
    calling_order = list(map(int, sys.stdin.readline().split()))
    ideal_order = list(map(int, sys.stdin.readline().split()))
    
    queue = deque(calling_order)
    time = 0
    
    for target in ideal_order:
        while queue[0] != target:
            queue.append(queue.popleft())
            time += 1
        queue.popleft()
        time += 1
    
    print(time)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency. The first line gives the number of processes, the second line the calling order, and the third line the ideal order.
- **Queue Operations**: Using a deque allows efficient popping from the front and appending to the end. This is crucial for simulating the rotation of processes.
- **Processing Each Target**: For each process in the ideal order, the algorithm repeatedly moves the front of the queue to the end until the front matches the target process. Each rotation increments the time. Once matched, the process is removed (executed), which also increments the time.
- **Time Calculation**: The total time is accumulated through each rotation and execution step, providing the final result.

This approach efficiently simulates the process execution and rotation, ensuring the solution is both optimal and easy to understand.
