To solve this problem, we need to sort an array of integers using the counting sort algorithm. Counting sort is efficient when the range of input values (k) is known and not excessively large. Given the constraints (0 ≤ A[i] ≤ 10,000), counting sort is an optimal choice here.

### Approach
1. **Count Frequencies**: First, we count the occurrences of each integer in the input array using a count array `C` of size `k+1` (where k is 10,000).
2. **Cumulative Counts**: Convert the count array into a cumulative count array where each element at index `i` represents the number of elements less than or equal to `i`.
3. **Build Output Array**: Using the cumulative count array, place each element from the input array into its correct position in the output array, starting from the end of the input array to maintain stability.

### Solution Code
```python
def counting_sort():
    import sys
    n = int(sys.stdin.readline())
    A = list(map(int, sys.stdin.readline().split()))
    max_k = 10000
    C = [0] * (max_k + 1)
    
    for x in A:
        C[x] += 1
    
    for i in range(1, max_k + 1):
        C[i] += C[i - 1]
    
    B = [0] * n
    for x in reversed(A):
        pos = C[x] - 1
        B[pos] = x
        C[x] -= 1
    
    print(' '.join(map(str, B)))

counting_sort()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin` for efficiency, especially with large input sizes.
2. **Count Array Initialization**: We initialize a count array `C` of size 10,001 (since the maximum value allowed is 10,000) to count occurrences of each integer.
3. **Frequency Counting**: We iterate over the input array and update the count array to reflect the frequency of each integer.
4. **Cumulative Counts**: Convert the count array into a cumulative sum array. This helps in determining the correct position of each element in the sorted output array.
5. **Building the Output Array**: By iterating over the input array in reverse order, we use the cumulative count array to place each element in its correct position in the output array, ensuring stability. After placing an element, we decrement its count in the cumulative array.
6. **Output**: The sorted array is printed as a space-separated string.

This approach ensures that the sorting is done in linear time O(n + k), making it highly efficient for the given constraints.
