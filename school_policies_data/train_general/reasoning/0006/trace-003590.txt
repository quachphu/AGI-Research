To solve this problem, we need to determine the number of good subarrays in a given array. A good subarray is defined as a subarray where every non-empty subarray has a non-zero sum. 

### Approach
1. **Prefix Sum Array**: Compute the prefix sum array to efficiently check the sums of subarrays.
2. **Non-Zero Runs**: Split the array into contiguous segments (runs) of non-zero elements since any subarray containing zero cannot be good.
3. **Sliding Window Technique**: For each non-zero run, use a sliding window approach to count valid subarrays where all prefix sums are unique. This ensures that no subarray within the window has a sum of zero.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))

prefix = [0] * (n + 1)
for i in range(n):
    prefix[i + 1] = prefix[i] + a[i]

runs = []
current_start = None
for i in range(n):
    if a[i] != 0:
        if current_start is None:
            current_start = i
    else:
        if current_start is not None:
            runs.append((current_start, i - 1))
            current_start = None
if current_start is not None:
    runs.append((current_start, n - 1))

def count_good(s, e, prefix):
    left = s
    right = s
    seen = set()
    count = 0
    while left <= e:
        while right <= e + 1 and prefix[right] not in seen:
            seen.add(prefix[right])
            right += 1
        count += (right - left - 1)
        if left < right:
            seen.discard(prefix[left])
        left += 1
    return count

total = 0
for s, e in runs:
    total += count_good(s, e, prefix)

print(total)
```

### Explanation
1. **Prefix Sum Calculation**: The prefix sum array helps in quickly determining the sum of any subarray. The sum of elements from index `i` to `j` can be found using `prefix[j+1] - prefix[i]`.
2. **Identify Non-Zero Runs**: The array is divided into segments of consecutive non-zero elements. This is because any subarray containing a zero cannot be good.
3. **Sliding Window for Unique Prefix Sums**: For each non-zero run, we use a sliding window technique to check all possible subarrays. We maintain a set of seen prefix sums to ensure uniqueness. The window expands as long as all prefix sums are unique and contracts from the left when a duplicate is found. The count of valid subarrays is adjusted to exclude empty subarrays by subtracting 1 for each window position.

This approach efficiently counts all valid good subarrays in O(n) time complexity per non-zero run, leading to an overall linear time complexity for the solution.
