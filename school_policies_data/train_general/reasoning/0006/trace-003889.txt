To solve this problem, we need to count the number of right-angled triangles with integer side lengths \(a, b, c\) such that \(1 \leq a \leq b \leq c \leq n\). The solution involves generating all possible Pythagorean triples using Euclid's formula and then checking how many of these triples (and their multiples) fit within the given constraints.

### Approach
1. **Generate Primitive Triples**: Using Euclid's formula, generate all primitive Pythagorean triples (triples where \(a, b, c\) are coprime). Euclid's formula states that for integers \(m > n > 0\), where \(m\) and \(n\) are coprime and not both odd, the triple can be generated as:
   - \(a = m^2 - n^2\)
   - \(b = 2mn\)
   - \(c = m^2 + n^2\)

2. **Check Multiples**: For each primitive triple, compute the maximum integer \(k\) such that \(k \times c \leq n\). Each \(k\) represents a valid multiple of the primitive triple that fits within the constraints.

3. **Count Valid Triples**: Sum the valid multiples for all generated primitive triples to get the total count of valid right-angled triangles.
