To solve this problem, we need to determine whether the automatic ticket gate at a Shinkansen (bullet train) station opens or closes based on the combination of tickets inserted. The solution involves checking specific valid combinations of ticket states to decide the gate's operation.

### Approach
The problem specifies that the gate opens if either of the following two conditions is met:
1. Both a "ticket" (b1) and a "limited express ticket" (b2) are inserted.
2. A single "boarding/limited express ticket" (b3) is inserted.

For all other valid input combinations, the gate remains closed. The valid input states are limited to the cases provided, so we can directly check for the two conditions that open the gate and handle all other cases as closed.

### Solution Code
```python
def main():
    b1, b2, b3 = map(int, input().split())
    if (b1 == 1 and b2 == 1 and b3 == 0) or (b1 == 0 and b2 == 0 and b3 == 1):
        print("Open")
    else:
        print("Close")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of three integers (b1, b2, b3) representing the states of the tickets.
2. **Check Opening Conditions**: The gate opens if:
   - Both "ticket" (b1) and "limited express ticket" (b2) are inserted (i.e., b1=1, b2=1, b3=0).
   - A single "boarding/limited express ticket" (b3) is inserted (i.e., b1=0, b2=0, b3=1).
3. **Handle Other Cases**: All other valid input combinations result in the gate closing.

This approach efficiently checks the two valid conditions for opening the gate and defaults to closing the gate for all other cases, ensuring correctness and simplicity.
