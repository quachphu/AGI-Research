To solve this problem, we need to efficiently compute the XOR of elements in specified intervals for multiple queries. Given the constraints, a direct approach would be too slow, so we use a prefix XOR array to allow each query to be answered in constant time.

### Approach
1. **Prefix XOR Array**: We precompute a prefix XOR array where each element at index `i` represents the XOR of all elements from the start of the array up to index `i-1`. This allows us to compute the XOR for any interval in constant time.
2. **Query Processing**: For each query, we use the prefix XOR array to quickly determine the XOR of the interval by leveraging the properties of XOR. Specifically, the XOR of elements from index `a` to `b` can be found using `prefix[b+1] ^ prefix[a]`.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    arr = list(map(int, input[ptr:ptr+N]))
    ptr += N
    Q = int(input[ptr])
    ptr += 1
    
    # Compute prefix XOR array
    prefix = [0] * (N + 1)
    for i in range(1, N + 1):
        prefix[i] = prefix[i-1] ^ arr[i-1]
    
    # Process each query
    results = []
    for _ in range(Q):
        a = int(input[ptr])
        b = int(input[ptr + 1])
        ptr += 2
        res = prefix[b + 1] ^ prefix[a]
        results.append(res)
    
    print('\n'.join(map(str, results)))

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the large constraints. The input is split into a list of strings for easy processing.
2. **Prefix XOR Calculation**: The prefix array is constructed such that each element at index `i` (starting from 1) is the XOR of all elements from the start of the array up to index `i-1`. This allows us to compute the XOR of any subarray in constant time.
3. **Query Handling**: For each query, we determine the XOR of the interval using the precomputed prefix array. The result for each query is obtained by XORing `prefix[b+1]` with `prefix[a]`, which effectively cancels out the elements before index `a`.

This approach ensures that preprocessing takes O(N) time and each query is answered in O(1) time, making the solution efficient and scalable for large inputs.
