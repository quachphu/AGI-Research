### Approach
1. **Check for Unique Points**: Ensure all eight input points are distinct.
2. **Extract Coordinates**: Collect the x and y coordinates from the points.
3. **Validate Coordinate Counts**: Check if there are exactly three unique x-coordinates and three unique y-coordinates.
4. **Generate Expected Points**: Create all possible points from the three unique x and y coordinates, then remove the middle point (x2, y2).

### Solution Code
```python
def main():
    points = [tuple(map(int, input().split())) for _ in range(8)]
    unique = set(points)
    if len(unique) != 8:
        print("ugly")
        return

    x_values = {p[0] for p in unique}
    y_values = {p[1] for p in unique}

    if len(x_values) != 3 or len(y_values) != 3:
        print("ugly")
        return

    xs = sorted(x_values)
    ys = sorted(y_values)

    expected = set()
    for x in xs:
        for y in ys:
            expected.add((x, y))
    expected.remove((xs[1], ys[1]))

    print("respectable" if unique == expected else "ugly")

main()
```

### Explanation
1. **Reading Input**: The input points are read and stored as tuples in a list.
2. **Uniqueness Check**: Convert the list of points into a set to check for duplicates. If duplicates exist, print "ugly".
3. **Coordinate Extraction**: Extract x and y values into separate sets to check their uniqueness.
4. **Coordinate Validation**: Ensure there are exactly three unique x and y values. If not, print "ugly".
5. **Generate and Compare Points**: Generate all possible points from the three x and y values, remove the middle point, and check if the input points match this generated set. If they do, print "respectable"; otherwise, print "ugly".

This approach efficiently checks the required conditions using set operations and list comprehensions, ensuring correctness and optimal performance.
