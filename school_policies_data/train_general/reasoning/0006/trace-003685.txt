To solve this problem, we need to determine if Maria can reach Anna's position on an 8x8 chessboard while avoiding moving statues. Maria moves first, and statues move down one row each turn. If Maria reaches Anna's position, she wins. If a statue moves into Maria's position, the statues win.

### Approach
1. **Model the Problem as BFS**: Use Breadth-First Search (BFS) to explore all possible moves Maria can make. Each state in the BFS will track Maria's current position and the number of steps taken.
2. **Track Statue Positions**: Statues move down one row each turn. Their positions after `t` steps can be determined by their initial positions and the number of steps `t`.
3. **Collision Detection**: For each move Maria makes, check if the new position is valid (not occupied by a statue) and if moving there will result in a collision with a statue after the statues move down.

### Solution Code
```python
from collections import deque

def main():
    import sys
    grid = [line.strip() for line in sys.stdin]
    
    # Collect initial positions of statues
    statues = []
    for i in range(8):
        for j in range(8):
            if grid[i][j] == 'S':
                statues.append((i, j))
    
    # BFS initialization
    visited = set()
    q = deque()
    start = (7, 0, 0)  # Maria's starting position (row 7, column 0) at step 0
    q.append(start)
    visited.add(start)
    
    # Directions: 8 possible moves plus staying in place
    directions = [(dx, dy) for dx in (-1, 0, 1) for dy in (-1, 0, 1)]
    
    while q:
        x, y, t = q.popleft()
        
        # Check if Maria has reached Anna's position
        if x == 0 and y == 7:
            print("WIN")
            return
        
        # Generate all possible next moves
        for dx, dy in directions:
            nx, ny = x + dx, y + dy
            if 0 <= nx < 8 and 0 <= ny < 8:
                # Check if the next cell is blocked by any statue at current step t
                blocked = False
                for (r, c) in statues:
                    if (r + t) < 8 and (r + t) == nx and c == ny:
                        blocked = True
                        break
                if not blocked:
                    # Check if next move reaches Anna's position
                    if nx == 0 and ny == 7:
                        print("WIN")
                        return
                    # Check collision after statues move (t+1 steps)
                    collision = False
                    for (r, c) in statues:
                        new_row = r + t + 1
                        if new_row < 8 and new_row == nx and c == ny:
                            collision = True
                            break
                    if not collision:
                        next_state = (nx, ny, t + 1)
                        if next_state not in visited:
                            visited.add(next_state)
                            q.append(next_state)
    
    # If queue is exhausted without finding a path
    print("LOSE")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Input Parsing**: Read the grid and collect initial positions of statues.
2. **BFS Initialization**: Start BFS from Maria's initial position (7, 0) at step 0.
3. **Direction Handling**: Consider all 8 possible moves (including diagonals and staying in place).
4. **Blocked Cells Check**: For each potential move, check if the cell is blocked by statues at the current step.
5. **Collision Check**: After moving, check if any statue will move into Maria's new position in the next step.
6. **Termination Conditions**: If Maria reaches Anna's position, print "WIN". If all possible moves are exhausted, print "LOSE".

This approach efficiently explores all possible paths Maria can take while accounting for the dynamic movement of statues, ensuring accurate determination of the game's outcome.
