To solve this problem, we need to determine if two toads, Daniel and Vlad, will ever be at the same subway station at the same time while traveling on two different circular routes. Daniel travels in a clockwise direction, and Vlad travels in a counter-clockwise direction. Both start moving simultaneously and exit the subway once they reach their respective destinations.

### Approach
1. **Problem Analysis**:
   - Daniel's route is 1 → 2 → ... → n → 1 → 2 → ...
   - Vlad's route is n → (n-1) → ... → 1 → n → (n-1) → ...
   - We need to check if there exists any time `t` such that both Daniel and Vlad are at the same station.

2. **Key Insight**:
   - Calculate the number of steps each toad takes to reach their destination.
   - Simulate their movements step-by-step up to the minimum number of steps required by either toad to reach their destination. This is because once either toad reaches their destination, they exit the subway, and we no longer need to check further.

3. **Algorithm**:
   - Compute the time `t_d` Daniel takes to reach his destination and `t_v` Vlad takes to reach his.
   - Determine the maximum time `t_max` to simulate, which is the minimum of `t_d` and `t_v`.
   - For each time step from 0 to `t_max`, compute their positions and check if they coincide.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = int(input[1])
    x = int(input[2])
    b = int(input[3])
    y = int(input[4])
    
    t_d = (x - a) % n
    t_v = (b - y) % n
    t_max = min(t_d, t_v)
    
    for t in range(t_max + 1):
        d_pos = ((a - 1 + t) % n) + 1
        v_pos = ((b - 1 - t) % n) + 1
        if d_pos == v_pos:
            print("YES")
            return
    print("NO")

main()
```

### Explanation
1. **Reading Input**: The input values are read and parsed into integers.
2. **Calculate Steps**:
   - `t_d` is the number of steps Daniel needs to reach his destination, calculated using modulo arithmetic to handle the circular route.
   - `t_v` is similarly calculated for Vlad's counter-clockwise route.
3. **Simulate Movements**:
   - For each time step from 0 to `t_max`, compute Daniel's and Vlad's positions using modular arithmetic to handle the circular nature of their routes.
   - If at any step their positions match, print "YES" and exit. If no match is found after all steps, print "NO".

This approach efficiently checks for any overlap in their paths within the necessary time frame, ensuring optimal performance given the constraints.
