To solve this problem, we need to efficiently count the occurrences of the substring "AC" within specified ranges of a given string. Given the constraints, a direct approach for each query would be too slow, so we use a preprocessing step with prefix sums to allow constant-time query responses.

### Approach
1. **Preprocessing**: 
   - Construct an array `ac` where each element at index `i` is 1 if the substring starting at `i` in the original string is "AC", otherwise 0.
   - Build a prefix sum array `sum_ac` from the `ac` array. This allows us to quickly compute the sum of any subarray in `ac`.

2. **Query Handling**:
   - For each query, use the prefix sum array to compute the number of "AC" substrings in constant time by subtracting the prefix sum at the start of the range from the prefix sum at the end of the range.

### Solution Code
```python
n, q = map(int, input().split())
s = input().strip()

# Precompute the AC occurrences
ac = []
for i in range(n - 1):
    if s[i] == 'A' and s[i + 1] == 'C':
        ac.append(1)
    else:
        ac.append(0)

# Build prefix sum array
sum_ac = [0] * (len(ac) + 1)
current = 0
for i in range(len(ac)):
    current += ac[i]
    sum_ac[i + 1] = current

# Process each query
for _ in range(q):
    l, r = map(int, input().split())
    res = sum_ac[r - 1] - sum_ac[l - 1]
    print(res)
```

### Explanation
1. **Preprocessing**:
   - The `ac` array is constructed by iterating through the string and checking each pair of consecutive characters. If a pair is "AC", the corresponding position in `ac` is marked as 1.
   - The prefix sum array `sum_ac` is built from the `ac` array. Each entry `sum_ac[i]` holds the cumulative count of "AC" substrings from the start of the string up to the `i-1` position in the `ac` array.

2. **Query Handling**:
   - For each query with indices `l` and `r` (1-based), the number of "AC" substrings in the range from `l` to `r` is determined by the difference `sum_ac[r-1] - sum_ac[l-1]`. This efficiently computes the sum of the `ac` array between the adjusted indices, providing the result in constant time.

This approach ensures that we handle up to the maximum constraints efficiently, with preprocessing in linear time and each query in constant time.
