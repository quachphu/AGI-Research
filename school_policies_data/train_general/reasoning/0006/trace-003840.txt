To solve this problem, we need to simulate the evolution of a cellular automaton based on specific rules. The goal is to determine the state of the array after a given number of iterations, considering that the number of iterations can be extremely large.

### Approach
1. **Problem Analysis**:
   - Each cell can either be alive (1) or dead (0).
   - A dead cell becomes alive if exactly one of its neighbors (left or right) is alive.
   - Alive cells remain alive forever.

2. **Key Insight**:
   - Since alive cells remain alive, once a cell becomes alive, it will stay alive. This means the number of alive cells can only increase over time.
   - The state of the array can stabilize after a certain number of steps, meaning no further changes occur regardless of additional iterations. This allows us to stop early once stabilization is detected.

3. **Algorithm**:
   - For each test case, simulate the evolution step by step.
   - In each iteration, compute the next state based on the current state. If no changes occur during an iteration, the state has stabilized, and we can terminate early.
   - Use a loop to simulate up to the given number of iterations or until stabilization, whichever comes first.

def main():
