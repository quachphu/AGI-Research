To solve this problem, we need to determine the previous state of Conway's Game of Life in a one-dimensional grid given the current state. The cells in the grid follow specific rules based on the number of living neighbors, and we need to reverse these rules to find the possible previous states.

### Approach
1. **Problem Analysis**: Each cell's state in the next step is determined by the number of living neighbors in the current step. If a cell has exactly one living neighbor, it flips its state; otherwise, it remains the same. We need to reverse this process to find the previous state given the current state.

2. **Linear System of Equations**: The problem can be modeled as a system of linear equations over GF(2) (binary field). Each equation represents the condition that the previous state must satisfy to transition to the given current state. Specifically, each cell's state in the previous state is determined by its neighbors and the current state.

3. **Gaussian Elimination**: We use Gaussian elimination over GF(2) to solve the system of linear equations. This helps in determining if there are no solutions, a unique solution, or multiple solutions.

4. **Verification**: After solving the system, we verify the solution to ensure it correctly transitions to the given current state using the game's rules.

def gauss(matrix, n_vars):
    rank = 0
    n = len(matrix)
    for col in range(n_vars):
        pivot = None
        for row in range(rank, n):
            if matrix[row][col]:
                pivot = row
                break
        if pivot is None:
            continue
        matrix[rank], matrix[pivot] = matrix[pivot], matrix[rank]
        for row in range(n):
            if row != rank and matrix[row][col]:
                matrix[row] = [(a ^ b) for a, b in zip(matrix[row], matrix[rank])]
        rank += 1
    for row in matrix:
        if all(v == 0 for v in row[:-1]) and row[-1] == 1:
            return (None, 0)
    free_vars = n_vars - rank
    return (matrix, free_vars)

def solve(matrix, n_vars):
    assignment = [0] * n_vars
    used = [False] * n_vars
    for row in matrix:
        leading = -1
        for col in range(n_vars):
            if row[col]:
                leading = col
                break
        if leading == -1:
            continue
        used[leading] = True
        s = row[-1]
        for col in range(leading + 1, n_vars):
            s ^= assignment[col] & row[col]
        assignment[leading] = s
    return assignment

def verify(prev, c):
    n = len(prev)
    for i in range(n):
        left = prev[(i-1) % n]
        right = prev[(i+1) % n]
        sum_neighbors = left + right
        if sum_neighbors == 1:
            expected = 1 - prev[i]
        else:
            expected = prev[i]
        if expected != c[i]:
            return False
    return True

def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    cases = input[1:T+1]
    for case in cases:
        c_str = case.strip()
        n = len(c_str)
        c = [int(ch) for ch in c_str]
        matrix = []
        for i in range(n):
            row = [0] * (n + 1)
            prev = (i - 1) % n
            next_ = (i + 1) % n
            row[prev] = 1
            row[i] = 1
            row[next_] = 1
            row[-1] = c[i]
            matrix.append(row)
        reduced, free_vars = gauss(matrix, n)
        if reduced is None:
            print("No solution")
            continue
        if free_vars > 0:
            print("Multiple solutions")
            continue
        assignment = solve(reduced, n)
        if verify(assignment, c):
            print(''.join(map(str, assignment)))
        else:
            print("No solution")
