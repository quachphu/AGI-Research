To solve this problem, we need to generate a number pattern from a given sequence of 10 integers. The pattern follows a specific rule where each subsequent number is derived from the ones digit of the sum of adjacent pairs in the previous sequence. This process continues until only one number remains, which is the output for each dataset.

### Approach
1. **Input Reading**: Read multiple datasets, each consisting of a single line of 10 digits.
2. **Pattern Generation**: For each dataset, iteratively generate a new sequence by replacing each adjacent pair of numbers with the ones digit of their sum. This process reduces the length of the sequence by one each iteration.
3. **Termination**: Continue the pattern generation until the sequence is reduced to a single number, which is then printed as the result for that dataset.

### Solution Code
```python
def main():
    import sys
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        digits = [int(c) for c in line]
        while len(digits) > 1:
            new_digits = []
            for i in range(len(digits) - 1):
                new_digits.append((digits[i] + digits[i+1]) % 10)
            digits = new_digits
        print(digits[0])

main()
```

### Explanation
1. **Reading Input**: The function reads each line from standard input. Each line is expected to be a string of 10 digits.
2. **Processing Each Dataset**: For each line, convert the string into a list of integers.
3. **Generating the Pattern**: Using a loop, repeatedly generate a new list where each element is the ones digit of the sum of adjacent elements from the current list. This reduces the list length by one each iteration.
4. **Output**: Once the list is reduced to a single element, print that element as the result for the corresponding dataset.

This approach efficiently processes each dataset by iteratively reducing the sequence length until the final result is obtained, ensuring correctness and adherence to the problem constraints.
