Given the constraints where \( N \) can be as large as 4,000,000, an efficient approach is necessary. The Sieve of Eratosthenes algorithm is well-suited for this task due to its time efficiency in generating all primes up to a given limit.

### Approach
1. **Sieve of Eratosthenes**: This algorithm efficiently marks non-prime numbers in a boolean array (or bytearray in this case for memory efficiency). The steps are:
   - Initialize a bytearray where each element represents whether the index is a prime number.
   - Mark the first two elements (0 and 1) as non-prime.
   - For each number starting from 2 up to the square root of \( N \), mark all its multiples as non-prime.
2. **Sum Calculation**: After generating the sieve, sum all indices that are marked as prime.

### Solution Code
```python
def sum_primes():
    import sys
    import math

    n = int(sys.stdin.readline())
    if n < 2:
        print(0)
        return

    sieve = bytearray(n)
    sieve[:] = b'\x01' * n  # Initialize all to 1 (True)
    sieve[0] = sieve[1] = 0  # 0 and 1 are not primes

    for i in range(2, int(math.sqrt(n)) + 1):
        if sieve[i]:
            # Mark multiples of i starting from i*i as non-prime
            sieve[i*i : n : i] = b'\x00' * len(sieve[i*i : n : i])

    total = sum(i for i in range(n) if sieve[i])
    print(total)

sum_primes()
```

### Explanation
1. **Reading Input**: The input integer \( N \) is read from standard input.
2. **Edge Case Handling**: If \( N \) is less than 2, the sum of primes is immediately 0 since there are no primes less than 2.
3. **Sieve Initialization**: A bytearray is used to efficiently manage memory. All elements are initially set to 1 (True), indicating they are prime candidates.
4. **Marking Non-Primes**: Using the Sieve of Eratosthenes, non-prime numbers are marked starting from the square of each prime number. This ensures that each non-prime is marked only once, improving efficiency.
5. **Summing Primes**: Finally, all indices that remain marked as primes (value 1) are summed to get the result.

This approach ensures that the solution is both time and memory efficient, handling the upper constraint of \( N = 4,000,000 \) effectively.
