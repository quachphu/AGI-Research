To solve this problem, we need to determine the c-th term of a sequence generated using two initial values, a and b, where each subsequent term is the sum of the previous two terms. This sequence is similar to the Fibonacci sequence but starts with the given values a and b.

### Approach
1. **Problem Analysis**: The sequence starts with the given values a and b. Each subsequent term is the sum of the previous two terms. The task is to find the c-th term (0-based index) in this sequence.
2. **Intuition**: For each test case, we can generate the sequence up to the c-th term using iterative steps. This approach efficiently computes the required term without generating the entire sequence up to c, thus optimizing both time and space complexity.
3. **Algorithm**:
   - Read the number of test cases.
   - For each test case, read the values of a, b, and c.
   - If c is 0, the result is a.
   - If c is 1, the result is b.
   - For c greater than 1, iterate from 2 to c, updating the terms using the sum of the previous two terms.
   - Print the result for each test case.

### Solution Code
```python
import sys

def solve():
    T = int(sys.stdin.readline())
    for _ in range(T):
        a, b, c = map(int, sys.stdin.readline().split())
        if c == 0:
            print(a)
        elif c == 1:
            print(b)
        else:
            for _ in range(2, c + 1):
                a, b = b, a + b
            print(b)

solve()
```

### Explanation
- **Reading Input**: The input is read using standard input functions. The number of test cases is read first, followed by each test case's parameters.
- **Handling Edge Cases**: Directly return a for c=0 and b for c=1 as these are the initial terms.
- **Iterative Calculation**: For c greater than 1, iterate from 2 to c, updating the current term as the sum of the previous two terms. This is done by shifting the values of a and b in each iteration to avoid using extra space for storing the entire sequence.
- **Efficiency**: The algorithm runs in O(c) time for each test case, which is efficient given the constraints (1 ≤ c ≤ 100). The space complexity is O(1) as only the last two terms are stored at any time.

This approach ensures that we efficiently compute the required term for each test case with minimal time and space complexity.
