To solve this problem, we need to determine the minimal total increase in salaries required to merge all companies into one while adhering to the anti-monopoly service's regulations. The key insight is that all companies must have the same maximum salary before merging, and we can only increase salaries.

### Approach
1. **Identify the Target Maximum Salary**: The minimum possible maximum salary (S0) that all companies can be adjusted to is the highest maximum salary among all companies. This is because setting a higher target would only increase the total salary increment unnecessarily.
2. **Calculate Total Increment**: For each company, compute the difference between the target maximum salary (S0) and the company's current maximum salary. Multiply this difference by the number of employees in the company to get the total increment required for that company. Sum these values for all companies to get the total minimal increment.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    companies = []
    max_s = 0
    for _ in range(n):
        parts = list(map(int, sys.stdin.readline().split()))
        m_i = parts[0]
        salaries = parts[1:]
        current_max = max(salaries)
        companies.append((current_max, m_i))
        if current_max > max_s:
            max_s = current_max
    total = 0
    for current_max, m in companies:
        delta = max_s - current_max
        total += delta * m
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first line gives the number of companies. Each subsequent line contains the number of employees in a company followed by their respective salaries.
2. **Determine Target Maximum Salary**: While reading each company's data, we compute the maximum salary for that company and track the overall maximum salary (S0) across all companies.
3. **Calculate Total Increment**: For each company, we calculate the required increase to match the target maximum salary (S0) and sum these values to get the total minimal increment.

This approach ensures that we efficiently determine the minimal total increment required by focusing on the necessary adjustments to align all companies' maximum salaries, thus enabling legal mergers while minimizing costs.
