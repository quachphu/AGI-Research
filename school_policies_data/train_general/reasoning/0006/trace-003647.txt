To solve this problem, we need to determine the profit Sereja will make from his restaurant's coat rack considering the cost of each hook and any fines incurred due to unavailable hooks. 

### Approach
1. **Input Reading**: Read the number of hooks `n`, the fine amount `d`, the list of hook costs, and the number of guests `m`.
2. **Sorting Hooks by Cost**: Sort the list of hook costs in ascending order to ensure that each guest uses the cheapest available hook first.
3. **Calculate Revenue from Hooks**: Sum the costs of the first `min(n, m)` hooks, as each guest will use the cheapest available hook until all hooks are occupied.
4. **Calculate Fines**: If the number of guests exceeds the number of hooks, calculate the total fines for the excess guests.
5. **Compute Profit**: Subtract the total fines from the revenue generated by the hooks to get the final profit.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    d = int(input[idx])
    idx += 1
    a = list(map(int, input[idx:idx + n]))
    idx += n
    m = int(input[idx])
    
    a_sorted = sorted(a)
    k = min(n, m)
    sum_hooks = sum(a_sorted[:k])
    fines = max(0, m - n) * d
    profit = sum_hooks - fines
    print(profit)

main()
```

### Explanation
- **Reading Inputs**: The input is read all at once and split into a list for easier processing. This approach ensures that we handle all input correctly even if it is provided in a non-interactive environment.
- **Sorting Hooks**: By sorting the hook costs, we can efficiently determine the minimum cost for each guest sequentially.
- **Revenue Calculation**: Summing the first `k` elements (where `k` is the minimum of `n` and `m`) gives the total revenue from the hooks used by the guests.
- **Fines Calculation**: If there are more guests than hooks, each additional guest incurs a fine. The total fines are calculated by multiplying the number of excess guests by the fine amount `d`.
- **Profit Calculation**: The final profit is the revenue from hooks minus the total fines, which is printed as the result.

This approach efficiently computes the profit with a time complexity dominated by the sorting step, which is O(n log n), making it suitable for the given problem constraints.
