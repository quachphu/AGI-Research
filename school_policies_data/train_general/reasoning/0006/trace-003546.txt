To solve this problem, we need to determine the minimum number of moves required to move the single '1' in a 5x5 matrix to the center position (3, 3) using row and column swaps. Each adjacent row or column swap counts as one move.

### Approach
1. **Identify the Position of '1'**: First, we need to locate the position of the '1' in the matrix. This can be done by iterating through each element of the matrix.
2. **Calculate Moves**: Once the position of '1' is found, calculate the number of row moves and column moves required to bring it to the center (3, 3). The number of moves for rows is the absolute difference between the current row and 3, and similarly for columns.
3. **Sum the Moves**: The total number of moves is the sum of the row moves and column moves.

### Solution Code
```python
matrix = [list(map(int, input().split())) for _ in range(5)]

# Find the position of the 1
row, col = 0, 0
for i in range(5):
    for j in range(5):
        if matrix[i][j] == 1:
            row = i + 1  # convert to 1-based index
            col = j + 1  # convert to 1-based index
            break
    else:
        continue
    break

# Calculate the required moves
moves = abs(row - 3) + abs(col - 3)
print(moves)
```

### Explanation
1. **Reading Input**: The matrix is read as a list of lists where each sublist represents a row.
2. **Finding '1'**: We iterate through each element of the matrix to find the position of '1'. The indices are converted to 1-based indexing as per the problem statement.
3. **Calculating Moves**: The number of moves required to center the '1' is computed by summing the absolute differences of the row and column indices from 3 (the center position). This works because each move shifts the '1' by one position towards the center, either vertically or horizontally.

This approach efficiently determines the minimum moves by leveraging the grid's structure and simple arithmetic, ensuring an optimal solution with a time complexity of O(1) given the fixed size of the matrix.
