To solve this problem, we need to determine the minimum number of moves required to reach a position with an opposite parity (even or odd) from each position in an array. Each position allows jumping to either the left or right based on the value at that position.

### Approach
1. **Graph Representation**: Treat each position as a node in a graph where directed edges exist from node `i` to `i + a[i]` and `i - a[i]` if those positions are valid.
2. **Reverse Graph**: Construct a reverse graph where edges point from the destination back to the source nodes. This helps in efficiently computing the shortest path using BFS from multiple sources.
3. **Multi-source BFS**: Use BFS starting from all nodes of the opposite parity (even or odd) to compute the shortest path for each node to reach any node of the opposite parity. This approach ensures we efficiently compute the shortest paths in linear time.

### Solution Code
```python
import sys
from collections import deque

def main():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))

    # Precompute predecessors for each node (1-based)
    predecessors = [[] for _ in range(n + 2)]  # +2 to avoid index issues
    for i in range(1, n + 1):
        ai = a[i-1]
        s_right = i + ai
        if s_right <= n:
            predecessors[s_right].append(i)
        s_left = i - ai
        if s_left >= 1:
            predecessors[s_left].append(i)

    # Separate even and odd nodes
    even_nodes = []
    odd_nodes = []
    for i in range(1, n + 1):
        if a[i-1] % 2 == 0:
            even_nodes.append(i)
        else:
            odd_nodes.append(i)

    # Compute even_dist: minimal steps to reach an even node (for odd a[i])
    even_dist = [-1] * (n + 1)
    q = deque()
    for node in even_nodes:
        even_dist[node] = 0
        q.append(node)
    while q:
        j = q.popleft()
        for i in predecessors[j]:
            if even_dist[i] == -1:
                even_dist[i] = even_dist[j] + 1
                q.append(i)

    # Compute odd_dist: minimal steps to reach an odd node (for even a[i])
    odd_dist = [-1] * (n + 1)
    q = deque()
    for node in odd_nodes:
        odd_dist[node] = 0
        q.append(node)
    while q:
        j = q.popleft()
        for i in predecessors[j]:
            if odd_dist[i] == -1:
                odd_dist[i] = odd_dist[j] + 1
                q.append(i)

    # Generate the result
    result = []
    for i in range(1, n + 1):
        if a[i-1] % 2 == 0:
            res = odd_dist[i]
        else:
            res = even_dist[i]
        result.append(str(res))
    
    print(' '.join(result))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reverse Graph Construction**: For each node `i`, we determine the nodes that can jump to `i` by checking `i + a[i]` and `i - a[i]`. This helps in building the reverse adjacency list.
2. **BFS for Even and Odd Nodes**: We perform two BFS traversals. The first starts from all even nodes to compute the shortest path to any odd node, and the second starts from all odd nodes to compute the shortest path to any even node.
3. **Result Calculation**: For each node, based on its parity, we use the precomputed shortest paths from the BFS results to determine the minimum number of moves required to reach a node of the opposite parity.

This approach efficiently computes the required minimum moves using BFS, ensuring linear time complexity and handling the constraints effectively.
