To solve this problem, we need to determine the number of squares that will be painted black in an N×N grid when exactly A squares are painted white. The solution involves a straightforward arithmetic calculation based on the total number of squares in the grid.

### Approach
1. **Understanding the Grid**: The grid consists of N×N squares. Each square can be either black or white.
2. **Total Squares Calculation**: The total number of squares in the grid is given by \(N^2\).
3. **Black Squares Calculation**: If A squares are painted white, the remaining squares will be black. This is simply the total number of squares minus A, i.e., \(N^2 - A\).

### Solution Code
```python
def main():
    n = int(input())
    a = int(input())
    print(n * n - a)

main()
```

### Explanation
1. **Reading Input**: The function reads two integers from standard input. The first integer is N, representing the grid size, and the second integer is A, the number of squares painted white.
2. **Calculating Total Squares**: The total number of squares in the grid is calculated as \(N \times N\).
3. **Calculating Black Squares**: The number of black squares is obtained by subtracting the number of white squares (A) from the total squares. The result is printed directly.

This approach efficiently computes the result in constant time, O(1), as it involves only basic arithmetic operations. The constraints ensure that the input values are within valid ranges, making the solution both optimal and correct for all possible cases.
