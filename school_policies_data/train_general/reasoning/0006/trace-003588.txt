To solve this problem, we need to find the number of pairs of indices (i, j) such that the expression \((a_i + a_j)(a_i^2 + a_j^2) \equiv k \mod p\) holds true, where \(1 \leq i < j \leq n\). Given the constraints, an efficient approach is necessary to avoid an O(n²) solution.

### Approach
1. **Simplify the Expression**: The given expression can be transformed using algebraic manipulation. By recognizing that \((a + b)(a^2 + b^2) = a^4 - b^4 / (a - b)\) when \(a \neq b\), we can rewrite the condition as \((a_i^4 - k \cdot a_i) \equiv (a_j^4 - k \cdot a_j) \mod p\). This allows us to reduce the problem to counting pairs with equivalent values under this transformation.

2. **Modular Arithmetic**: For each element \(a_i\), compute \(x_i = (a_i^4 - k \cdot a_i) \mod p\). This transforms the problem into finding pairs of elements with the same \(x_i\) value.

3. **Frequency Counting**: Use a dictionary to count the frequency of each \(x_i\). The number of valid pairs for each unique \(x_i\) is given by the combination formula \(m \choose 2\), which is \(m(m-1)/2\) for frequency \(m\).

### Solution Code
```python
def main():
    import sys
    from collections import defaultdict

    input = sys.stdin.read().split()
    n = int(input[0])
    p = int(input[1])
    k = int(input[2])
    a = list(map(int, input[3:3+n]))

    counts = defaultdict(int)
    for num in a:
        term = (pow(num, 4, p) - (k * num) % p) % p
        counts[term] += 1

    ans = 0
    for m in counts.values():
        ans += m * (m - 1) // 2
    print(ans)

main()
```

### Explanation
1. **Reading Input**: The input is read in one go and split into individual components for processing.
2. **Transformation Calculation**: For each element in the array, compute the transformed value using modular arithmetic to ensure efficiency.
3. **Frequency Dictionary**: Maintain a count of how many times each transformed value appears.
4. **Pair Calculation**: For each unique transformed value, compute the number of valid pairs using the combination formula and sum these values to get the final result.

This approach ensures that we efficiently count the required pairs in O(n) time, making it suitable for large input sizes up to \(3 \times 10^5\).
