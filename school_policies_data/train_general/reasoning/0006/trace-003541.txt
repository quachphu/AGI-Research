To solve this problem, we need to determine the maximum area of a rectangular window on a screen that does not include a dead pixel. The screen's resolution and the dead pixel's coordinates are given for each test case. The solution involves calculating the maximum possible area by considering regions around the dead pixel.

### Approach
1. **Problem Analysis**: The dead pixel divides the screen into four potential regions where the largest valid rectangle can be located:
   - To the left of the dead pixel.
   - To the right of the dead pixel.
   - Above the dead pixel.
   - Below the dead pixel.

2. **Key Insight**: The maximum area of a valid rectangle will be the largest of the areas of these four regions. Each region's dimensions can be calculated based on the dead pixel's coordinates.

3. **Algorithm**:
   - For each test case, compute the area of each of the four regions.
   - The maximum area among these four regions is the answer for that test case.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    t = int(input[idx])
    idx += 1
    for _ in range(t):
        a = int(input[idx])
        b = int(input[idx+1])
        x = int(input[idx+2])
        y = int(input[idx+3])
        idx += 4
        
        left = x * b
        right = (a - x - 1) * b
        top = a * y
        bottom = a * (b - y - 1)
        
        print(max(left, right, top, bottom))

main()
```

### Explanation
- **Reading Input**: The input is read all at once for efficiency, especially given the constraints where the number of test cases can be as high as 10,000.
- **Calculating Areas**:
  - **Left Area**: The width is the x-coordinate of the dead pixel, and the height is the full screen height (b).
  - **Right Area**: The width is the remaining columns to the right of the dead pixel, calculated as `(a - x - 1)`, and the height is the full screen height (b).
  - **Top Area**: The height is the y-coordinate of the dead pixel, and the width is the full screen width (a).
  - **Bottom Area**: The height is the remaining rows below the dead pixel, calculated as `(b - y - 1)`, and the width is the full screen width (a).
- **Output**: For each test case, the maximum of the four computed areas is printed as the result.

This approach ensures that we efficiently determine the largest possible valid rectangle by considering all potential regions around the dead pixel, leading to an optimal solution with a time complexity of O(1) per test case.
