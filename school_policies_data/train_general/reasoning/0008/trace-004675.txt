### Approach

2. **Required Sleep Calculation**: If `b` is not sufficient, calculate the remaining sleep required as `required = a - b`.

4. **Cycle Calculation**: If each cycle can contribute positively, compute the number of cycles needed using integer division to round up the required sleep divided by the effective sleep gained per cycle. The effective sleep per cycle is `c - d`.
5. **Total Time Calculation**: The total time is the initial alarm time plus the product of the number of cycles and the alarm time `c`.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    idx = 1
    for _ in range(t):
        a = int(input[idx])
        b = int(input[idx + 1])
        c = int(input[idx + 2])
        d = int(input[idx + 3])
        idx += 4
        if b >= a:
            print(b)
        else:
            required = a - b
            if c <= d:
                print(-1)
            else:
                gain = c - d
                k = (required + gain - 1) // gain
                print(b + k * c)

solve()
```

3. **Cycle Contribution Check**: If each subsequent cycle does not contribute positively to sleep (i.e., `c <= d`), print `-1` as Polycarp will never meet the required sleep.
4. **Effective Sleep Calculation**: Calculate the number of cycles needed using ceiling division to ensure we round up any fractional cycles. This is done using integer arithmetic to avoid floating-point operations.
5. **Output Result**: The total time is computed as the initial alarm time plus the product of the number of cycles and the alarm interval `c`.

This approach efficiently handles the constraints and edge cases, ensuring the solution is both optimal and correct.
