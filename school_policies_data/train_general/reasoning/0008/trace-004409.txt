To solve this problem, we need to determine the position of the K-th flower planted in an infinitely long flowerbed where each flower type is planted at specific intervals. The challenge is to efficiently find this position given the constraints.

### Approach
The problem can be efficiently solved using binary search. The key idea is to determine the smallest position such that the total number of flowers planted up to that position is at least K. This approach leverages the following steps:

1. **Binary Search Setup**: We initialize the search range (low and high) for the position. The high value is determined based on the maximum possible position any single flower type could occupy for the K-th position.
2. **Count Calculation**: For a given mid-point in the binary search, we calculate the total number of flowers planted up to that position by summing contributions from each flower type.
3. **Early Exit Optimization**: During the count calculation, if the cumulative count exceeds K early, we can break out of the loop to save computation time.
