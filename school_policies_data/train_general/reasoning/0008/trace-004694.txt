To solve this problem, we need to determine the minimum number of deletions required to transform a given integer into a perfect square. If it's impossible, we should return -1.

### Approach
1. **Understanding the Problem**: The goal is to delete digits from the given integer such that the remaining number is a perfect square. The key is to find the longest subsequence of the given number that forms a perfect square, as this will minimize the number of deletions.

2. **Generating Possible Squares**: For a given integer `n` with `L` digits, the maximum possible perfect square that can be formed will have at most `L` digits. We generate all possible perfect squares up to the length of `n` by iterating through all integers from 1 up to the integer square root of the maximum `L`-digit number.

3. **Checking Subsequence**: For each generated perfect square, check if it can be a subsequence of the given number. A subsequence maintains the order of characters but not necessarily their continuity.

4. **Result Calculation**: The minimum deletions required will be the difference between the length of the original number and the length of the longest valid perfect square subsequence found.

### Solution Code
```python
import math

def is_subsequence(a, s):
    it = iter(s)
    return all(c in it for c in a)

def main():
    s = input().strip()
    original_length = len(s)
    if original_length == 0:
        print(-1)
        return
    max_num = 10 ** original_length - 1
    max_y = math.isqrt(max_num)
    max_len = -1
    for y in range(1, max_y + 1):
        square_str = str(y * y)
        if len(square_str) > original_length:
            continue
        if is_subsequence(square_str, s):
            current_len = len(square_str)
            if current_len > max_len:
                max_len = current_len
    print(original_length - max_len if max_len != -1 else -1)

main()
```

### Explanation
1. **Subsequence Check**: The `is_subsequence` function checks if a string `a` (a perfect square) can be formed as a subsequence of the input string `s`. This is done using an iterator to efficiently traverse the input string while checking each character of the perfect square.

2. **Generating Perfect Squares**: By iterating through all integers from 1 up to the integer square root of the maximum `L`-digit number, we generate all possible perfect squares that could be subsequences of the input.

3. **Finding the Longest Valid Subsequence**: For each perfect square generated, we check if it is a valid subsequence of the input. The longest valid subsequence found determines the minimum deletions required, calculated as the difference between the original length and the length of this subsequence.

This approach efficiently narrows down the possible candidates and checks each one, ensuring we find the optimal solution with minimal computational overhead.
