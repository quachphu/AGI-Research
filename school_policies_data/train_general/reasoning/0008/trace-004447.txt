To solve this problem, we need to determine the duration during which both Alice and Bob were holding down their buttons simultaneously. This involves finding the overlapping time interval between the periods when each of them pressed their buttons.

### Approach
1. **Understanding the Input**: The input consists of four integers A, B, C, D. Here, Alice presses her button from time A to B, and Bob presses his button from time C to D.
2. **Finding the Overlap**: The overlapping period between the two intervals can be determined by taking the maximum of the start times (A and C) and the minimum of the end times (B and D). The duration of the overlap is the difference between these two values.
3. **Handling Non-overlapping Intervals**: If the calculated start time is greater than or equal to the end time, it means there is no overlap, and the duration should be zero.

### Solution Code
```python
def main():
    A, B, C, D = map(int, input().split())
    start = max(A, C)
    end = min(B, D)
    print(max(end - start, 0))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input values are read and split into four integers A, B, C, D.
2. **Calculating Overlap Start and End**: 
   - The start of the overlap is the maximum of the times when Alice and Bob start pressing their buttons (`max(A, C)`).
   - The end of the overlap is the minimum of the times when either Alice or Bob releases their button (`min(B, D)`).
3. **Computing Duration**: The duration of the overlap is calculated as the difference between the end and start times. If the start time is greater than or equal to the end time, the overlap duration is zero, which is ensured using `max(end - start, 0)`.

This approach efficiently computes the overlapping time using basic mathematical operations, ensuring correctness and optimal performance.
