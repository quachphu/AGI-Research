To solve this problem, we need to determine if each person in a list of names has appeared before in the list up to their current position. The solution involves tracking each name as we process the list and checking if it has been encountered previously.

### Approach
1. **Read Input**: First, we read the integer `n` which indicates the number of names.
2. **Track Names**: Use a set data structure to keep track of names we have seen so far. A set is chosen because it allows O(1) average time complexity for both membership checks and insertions.
3. **Process Each Name**: For each name in the list:
   - Check if the name is already in the set.
   - Print "YES" if the name is found in the set, otherwise print "NO".
   - Add the name to the set to track future occurrences.

### Solution Code
```python
def main():
    n = int(input())
    seen = set()
    for _ in range(n):
        name = input().strip()
        if name in seen:
            print("YES")
        else:
            print("NO")
        seen.add(name)

main()
```

### Explanation
1. **Reading Input**: The first input line is the integer `n`, which tells us how many names to process.
2. **Set Initialization**: A set named `seen` is initialized to keep track of the names encountered so far.
3. **Processing Each Name**:
   - For each name, we check if it exists in the `seen` set.
   - If the name exists, we print "YES"; otherwise, we print "NO".
   - Regardless of whether the name was seen before, we add it to the `seen` set to ensure subsequent checks include this name.

This approach efficiently checks for previous occurrences using a set, ensuring that each check and insertion operation is done in constant average time, leading to an overall time complexity of O(n). This is optimal for the given constraints (n ≤ 100), ensuring quick and efficient processing.
