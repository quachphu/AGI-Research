To solve this problem, we need to determine the number of pairs (i, j) such that i < j and the bitwise AND of the elements at these positions is greater than or equal to the bitwise XOR of the elements. The key insight is that pairs of numbers sharing the same highest set bit will satisfy the condition, as their AND operation will dominate their XOR operation.

### Approach
1. **Identify Highest Set Bit**: For each number in the array, determine the position of the highest set bit. This can be efficiently found using the `bit_length()` method in Python, which returns the number of bits required to represent the number in binary, excluding leading zeros.
2. **Group by Highest Set Bit**: Group numbers by their highest set bit position. This allows us to count how many numbers fall into each group.
3. **Count Valid Pairs**: For each group of numbers sharing the same highest set bit, the number of valid pairs is given by the combination formula C(n, 2) = n * (n - 1) / 2, where n is the size of the group.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        a = list(map(int, sys.stdin.readline().split()))
        freq = defaultdict(int)
        for x in a:
            h = x.bit_length() - 1
            freq[h] += 1
        ans = 0
        for cnt in freq.values():
            ans += cnt * (cnt - 1) // 2
        print(ans)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using standard input for efficiency, especially given the constraints.
2. **Frequency Calculation**: For each number, compute its highest set bit position using `bit_length() - 1` and maintain a frequency count of these positions.
3. **Pair Calculation**: For each group of numbers with the same highest set bit, compute the number of valid pairs using the combination formula. Sum these values across all groups to get the final result.

This approach efficiently groups numbers by their highest set bit, allowing us to count valid pairs in linear time relative to the input size, ensuring it handles the upper constraint limits effectively.
