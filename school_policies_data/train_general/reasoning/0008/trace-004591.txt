To solve this problem, we need to compute the sum of all integers between two given integers \(i\) and \(j\) (both inclusive). Given the constraints where \(i\) and \(j\) can be as large as \(10^{18}\), using a loop to iterate through each number would be computationally infeasible. Instead, we can use a mathematical formula to efficiently compute the sum.

### Approach
The sum of all integers from \(i\) to \(j\) can be calculated using the formula for the sum of an arithmetic series. The formula is:

\[
\text{Sum} = \frac{(j - i + 1) \times (i + j)}{2}
\]

Here, \(j - i + 1\) represents the number of terms in the series, and \(i + j\) is the sum of the first and last terms of the series. Dividing by 2 gives the sum of the entire series. This formula allows us to compute the result in constant time, \(O(1)\), which is efficient even for very large values of \(i\) and \(j\).

### Solution Code
```python
i, j = map(int, input().split())
total = (j - i + 1) * (i + j) // 2
print(total)
```

### Explanation
1. **Reading Input**: The input consists of two space-separated integers \(i\) and \(j\). These are read and converted to integers using `map(int, input().split())`.
2. **Applying the Formula**: Using the formula for the sum of an arithmetic series, we compute the number of terms \((j - i + 1)\) and the sum of the first and last terms \((i + j)\). Multiplying these values and dividing by 2 gives the total sum.
3. **Output the Result**: The computed sum is printed as the result.

This approach ensures that we handle very large numbers efficiently without any performance issues, leveraging Python's capability to manage arbitrarily large integers.
