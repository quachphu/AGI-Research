To solve this problem, we need to determine the total sales quantity of all cakes from a jumbled list of pairwise sums of sales quantities. The key insight is that the sum of all pairwise sums can be used to derive the total sales quantity of all cakes.

### Approach
1. **Understanding the Problem**: The problem involves reversing a vandalized sales record where each entry is the sum of sales of two different cakes. The task is to compute the total sales of all cakes combined.
2. **Key Insight**: The sum of all pairwise sums of sales quantities can be expressed as the product of the total sales quantity and (K-1), where K is the number of cake types. This is because each cake's sales quantity appears in (K-1) pairs.
3. **Algorithm**:
   - For each test case, read the number of cake types (K).
   - Read the next line containing the jumbled pairwise sums.
   - Compute the sum of these pairwise sums.
   - Divide this sum by (K-1) to get the total sales quantity of all cakes.

### Solution Code
```python
import sys

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        K = int(line)
        if K == 0:
            break
        # Read the next non-empty line for the ci values
        while True:
            ci_line = sys.stdin.readline().strip()
            if ci_line:
                break
        ci = list(map(int, ci_line.split()))
        sum_ci = sum(ci)
        total = sum_ci // (K - 1)
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The code reads input lines until it encounters a line with K=0, which signifies the end of input.
- **Processing Each Test Case**: For each valid K, the code reads the next line containing the jumbled pairwise sums.
- **Summing Pairwise Sums**: The sum of all pairwise sums is computed.
- **Calculating Total Sales**: The total sales quantity is derived by dividing the computed sum by (K-1), which gives the original total sales of all cakes combined.

This approach efficiently computes the required total sales using mathematical insights, ensuring correctness and optimal performance given the problem constraints.
