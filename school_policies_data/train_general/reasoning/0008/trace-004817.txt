To solve this problem, we need to reconstruct a binary tree from its preorder and inorder traversals and then output the postorder traversal. The key insight is that the root of the tree can be identified from the preorder traversal, and the inorder traversal helps us split the tree into left and right subtrees.

### Approach
1. **Identify the Root**: The first element in the preorder traversal is always the root of the tree.
2. **Split Inorder Traversal**: Using the root identified from the preorder traversal, split the inorder traversal into left and right subtrees. The elements to the left of the root in the inorder traversal form the left subtree, and the elements to the right form the right subtree.
3. **Recursive Construction**: Recursively apply the same process to construct the left and right subtrees. The postorder traversal is obtained by combining the results of the left and right subtree traversals followed by the root.

### Solution Code
```python
def build_post(pre, ino):
    if not pre:
        return []
    root = pre[0]
    idx = ino.index(root)
    left_ino = ino[:idx]
    right_ino = ino[idx+1:]
    left_size = len(left_ino)
    left_pre = pre[1:1+left_size]
    right_pre = pre[1+left_size:]
    left_post = build_post(left_pre, left_ino)
    right_post = build_post(right_pre, right_ino)
    return left_post + right_post + [root]

n = int(input())
preorder = list(map(int, input().split()))
inorder = list(map(int, input().split()))
post_order = build_post(preorder, inorder)
print(' '.join(map(str, post_order)))
```

### Explanation
1. **Reading Input**: The input consists of the number of nodes and the preorder and inorder traversal sequences.
2. **Root Identification**: The root of the tree is the first element in the preorder list.
3. **Splitting Inorder List**: The root's position in the inorder list splits it into left and right subtrees.
4. **Recursive Processing**: The left and right subtrees are processed recursively to generate their postorder traversals.
5. **Combining Results**: The postorder traversal is formed by concatenating the left subtree's postorder traversal, the right subtree's postorder traversal, and the root.

This approach efficiently constructs the postorder traversal by leveraging the properties of preorder and inorder traversals, ensuring that each node is processed in constant time relative to its position in the tree. The overall time complexity is O(n), where n is the number of nodes, due to the linear processing of each node and the index lookups.
