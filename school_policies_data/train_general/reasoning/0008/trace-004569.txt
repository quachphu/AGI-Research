To solve this problem, we need to determine the arrival time at the last station for Alexey's train journey, considering both the scheduled times and additional delays. The train's departure from each station is constrained by both a minimum required waiting time and the scheduled departure time.

### Approach
1. **Input Reading**: Read the number of test cases. For each test case, read the number of stations, followed by the arrival and departure times for each station, and the additional travel times between consecutive stations.
2. **Initialization**: Start from the terminal with an initial departure time of 0.
3. **Iterate Through Stations**: For each station, calculate the arrival time considering the previous departure time and additional delays. Compute the minimum required waiting time and determine the earliest possible departure time from the current station, which is the maximum of the earliest departure time based on the waiting time and the scheduled departure time.
4. **Update Departure Time**: Update the departure time for the next station based on the current station's departure time.
5. **Output the Result**: For the last station, directly output the arrival time as it is the destination.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    stations = [tuple(map(int, input().split())) for _ in range(n)]
    tm = list(map(int, input().split()))
    
    current_departure = 0
    previous_b_scheduled = 0
    
    for i in range(n):
        a_i, b_i = stations[i]
        tm_i = tm[i]
        arrival = current_departure + (a_i - previous_b_scheduled) + tm_i
        
        if i == n - 1:
            print(arrival)
            break
        
        required_wait = (b_i - a_i + 1) // 2
        earliest_departure = arrival + required_wait
        departure = max(earliest_departure, b_i)
        
        current_departure = departure
        previous_b_scheduled = b_i
```

### Explanation
- **Reading Input**: The input is read and parsed into the number of test cases, stations, their respective arrival and departure times, and the additional delays.
- **Arrival Time Calculation**: For each station, the arrival time is computed based on the previous station's departure time, the scheduled arrival time, and the additional delay.
- **Required Waiting Time**: The minimum waiting time at each station is calculated using ceiling division, ensuring the train meets the required waiting period.
- **Departure Time Calculation**: The departure time from each station is determined by taking the maximum of the earliest possible departure time (considering the waiting period) and the scheduled departure time.
- **Final Output**: The arrival time at the last station is printed as the result for each test case.

This approach ensures that all constraints are respected, and the solution efficiently computes the arrival time at the destination station considering all given delays and waiting periods.
