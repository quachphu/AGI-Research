To solve this problem, we need to determine the possible tram lines Arkady could have been on based on the stops he saw. Each stop he observed must be served by the tram line he was on. The solution involves finding the intersection of the sets of lines from each stop he saw, as the valid tram lines must be present in all these sets.

### Approach
1. **Read Input**: Read the number of stops `n` and the lines that stop at each of these `n` stops.
2. **Collect Line Sets**: For each stop, collect the set of tram lines that stop there.
3. **Compute Intersection**: Find the intersection of all these sets. The intersection will give the lines that are common to all stops, which are the possible tram lines Arkady could have been on.
4. **Output Result**: Print the lines in the intersection in sorted order for consistency.

### Solution Code
```python
def find_possible_lines():
    import sys
    n = int(sys.stdin.readline())
    sets = []
    for _ in range(n):
        parts = list(map(int, sys.stdin.readline().split()))
        lines = parts[1:]
        sets.append(set(lines))
    if not sets:
        return
    result = sets[0]
    for s in sets[1:]:
        result &= s
    sorted_result = sorted(result)
    print(' '.join(map(str, sorted_result)))

find_possible_lines()
```

### Explanation
1. **Reading Input**: The input is read using standard input functions. The first line gives the number of stops `n`. Each subsequent line provides the number of lines at that stop followed by the line numbers.
2. **Storing Line Sets**: Each stop's lines are stored as a set to facilitate efficient intersection operations.
3. **Intersection Calculation**: Starting with the first set of lines, we iteratively compute the intersection with each subsequent set. This ensures that we only keep lines that are present in all stops.
4. **Sorting and Output**: The resulting lines are sorted and printed in a space-separated format to ensure a consistent and readable output.

This approach efficiently narrows down the possible tram lines by leveraging set operations, ensuring correctness and optimal performance given the problem constraints.
