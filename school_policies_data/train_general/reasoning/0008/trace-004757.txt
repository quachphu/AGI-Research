To solve this problem, we need to determine if a given lowercase English letter is a vowel or a consonant. The vowels are 'a', 'e', 'i', 'o', and 'u', and any other lowercase letter is considered a consonant.

### Approach
1. **Read Input**: The input is a single lowercase letter provided via standard input.
2. **Check for Vowel**: Check if the input character is one of the vowels ('a', 'e', 'i', 'o', 'u').
3. **Output Result**: Print "vowel" if the character is a vowel, otherwise print "consonant".

This approach efficiently checks the input character against a set of vowels, which allows for O(1) average time complexity for membership checks. The solution is straightforward and handles all possible valid inputs as specified by the problem constraints.

### Solution Code
```python
c = input().strip()
if c in {'a', 'e', 'i', 'o', 'u'}:
    print("vowel")
else:
    print("consonant")
```

### Explanation
1. **Reading Input**: The input is read using `input().strip()` to ensure any leading or trailing whitespace is removed, though the problem guarantees a single lowercase letter.
2. **Vowel Check**: The character is checked against a set of vowels. Using a set for membership testing is efficient in Python.
3. **Output**: Based on the check, the appropriate result ("vowel" or "consonant") is printed.

This solution is optimal for the given problem constraints and handles all edge cases correctly.
