To solve this problem, we need to compute the sum of the difference between the maximum and minimum values of all possible subsets of size K from a given list of integers. Given the constraints, a direct approach of enumerating all subsets is infeasible, so we use combinatorial mathematics to efficiently compute the result.

### Approach
1. **Sorting**: First, sort the array to simplify the calculation of contributions of each element as either the maximum or minimum in subsets.
2. **Combinatorial Precomputation**: Precompute factorials and inverse factorials modulo \(10^9 + 7\) to efficiently compute combinations using modular arithmetic.
3. **Contribution Calculation**: For each element in the sorted array, determine how many times it contributes as the maximum and how many times as the minimum in all valid subsets. The difference between these contributions, multiplied by the element's value, gives its net contribution to the final sum.

### Solution Code
```python
MOD = 10**9 + 7

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    K = int(input[idx])
    idx += 1
    A = list(map(int, input[idx:idx+N]))
    A.sort()
    
    max_n = N
    fact = [1] * (max_n + 1)
    for i in range(1, max_n + 1):
        fact[i] = fact[i-1] * i % MOD
    
    inv_fact = [1] * (max_n + 1)
    inv_fact[max_n] = pow(fact[max_n], MOD-2, MOD)
    for i in range(max_n - 1, -1, -1):
        inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD
    
    sum_total = 0
    for i in range(N):
        # Calculate max contribution
        if K-1 <= i:
            n_max = i
            k_max = K-1
            c_max = fact[n_max] * inv_fact[k_max] % MOD
            c_max = c_max * inv_fact[n_max - k_max] % MOD
        else:
            c_max = 0
        
        # Calculate min contribution
        remaining = (N - 1 - i)
        if remaining >= K-1:
            n_min = remaining
            k_min = K-1
            c_min = fact[n_min] * inv_fact[k_min] % MOD
            c_min = c_min * inv_fact[n_min - k_min] % MOD
        else:
            c_min = 0
        
        # Compute contribution and add to sum
        contribution = (c_max - c_min) * A[i]
        contribution %= MOD
        sum_total = (sum_total + contribution) % MOD
    
    print(sum_total % MOD)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Sorting**: The array is sorted to facilitate the calculation of contributions. In a sorted array, the maximum element of any subset will be the rightmost element, and the minimum will be the leftmost element.
2. **Factorials and Inverse Factorials**: These are precomputed to efficiently calculate combinations using modular arithmetic. This allows us to compute combinations in constant time after an initial preprocessing step.
3. **Contribution Calculation**:
   - **Maximum Contribution**: For an element at position `i` in the sorted array, the number of subsets where it is the maximum is given by the combination \(C(i, K-1)\), which is the number of ways to choose the remaining \(K-1\) elements from the first `i` elements.
   - **Minimum Contribution**: Similarly, the number of subsets where an element is the minimum is given by \(C(N-1-i, K-1)\), the number of ways to choose the remaining \(K-1` elements from the elements to the right of `i`.
   - **Net Contribution**: The difference between the maximum and minimum contributions for each element, multiplied by the element's value, is accumulated to form the final result.

This approach efficiently computes the required sum using combinatorial mathematics and modular arithmetic, ensuring it handles large inputs within the problem constraints.
