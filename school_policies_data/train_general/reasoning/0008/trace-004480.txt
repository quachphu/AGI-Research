To solve this problem, we need to determine the optimal bus stop for Poor Student to alight so he can reach the University as soon as possible. The solution involves calculating the time taken to reach each bus stop and then running to the University, considering both the bus's speed and the student's running speed. 

### Approach
1. **Input Reading**: Read the number of stops, bus speed, student's running speed, bus stop coordinates, and University coordinates.
2. **Time Calculation**: For each bus stop (starting from the second stop), calculate the total time taken to reach the University if the student alights at that stop. This includes the time taken by the bus to reach the stop and the time taken by the student to run from the stop to the University.
3. **Optimal Stop Selection**: Track the stop with the minimum total time. If multiple stops have the same minimum time, select the one closest to the University. If there's a tie in distance, choose the stop with the smallest index.

### Solution Code
```python
import math

def find_optimal_stop():
    n, vb, vs = map(int, input().split())
    xi = list(map(int, input().split()))
    xu, yu = map(int, input().split())
    
    best_j = 1  # 0-based index, starting from the second stop (j=1)
    x = xi[best_j]
    time_bus = x / vb
    dx = xu - x
    distance = math.hypot(dx, yu)
    best_time = time_bus + (distance / vs)
    best_distance = distance
    
    for j in range(2, n):
        x = xi[j]
        current_time_bus = x / vb
        dx = xu - x
        current_distance = math.hypot(dx, yu)
        current_time_run = current_distance / vs
        total_time = current_time_bus + current_time_run
        
        if total_time < best_time:
            best_j = j
            best_time = total_time
            best_distance = current_distance
        elif total_time == best_time:
            if current_distance < best_distance:
                best_j = j
                best_distance = current_distance
            elif current_distance == best_distance:
                if j < best_j:
                    best_j = j
    
    print(best_j + 1)

find_optimal_stop()
```

### Explanation
1. **Reading Inputs**: The inputs are read and parsed into variables for the number of stops, speeds, bus stop coordinates, and University coordinates.
2. **Initial Setup**: The first valid stop (second bus stop) is initially set as the best stop. The time and distance from this stop to the University are calculated.
3. **Iterating Through Stops**: For each subsequent stop, the total time to reach the University is calculated. This time is compared with the current best time. If the new time is better, or if it ties but has a shorter distance or smaller index, the best stop is updated.
4. **Output**: The index of the best stop (converted to 1-based indexing) is printed.

This approach ensures that we efficiently determine the optimal stop by considering both time and distance, and it handles ties by selecting the closest and earliest stop.
