To solve this problem, we need to determine the minimum cost for Mahmoud to send a message by potentially replacing some words with others from the same group that have a lower cost. Each group of words has the same meaning, and we can replace any word in the message with another word from its group to minimize the total cost.

### Approach
1. **Input Reading**: Read the number of words, groups, and the number of words in the message.
2. **Word and Cost Lists**: Read the list of words and their corresponding costs.
3. **Group Processing**: For each group, determine the minimum cost among all words in that group. Map each word in the group to this minimum cost.
4. **Message Cost Calculation**: For each word in the message, sum the minimum cost of the group it belongs to.

### Solution Code
```python
import sys

def main():
    # Read the first line of input
    n, k, m = map(int, sys.stdin.readline().split())
    
    # Read the list of words
    words = sys.stdin.readline().split()
    
    # Read the list of costs
    costs = list(map(int, sys.stdin.readline().split()))
    
    # Initialize a dictionary to hold the minimum cost for each word
    min_cost = {}
    
    # Process each group
    for _ in range(k):
        parts = list(map(int, sys.stdin.readline().split()))
        x = parts[0]
        indices = [i - 1 for i in parts[1:]]  # Convert to 0-based indices
        # Find the minimum cost in the current group
        group_min = min(costs[i] for i in indices)
        # Update the minimum cost for each word in the group
        for i in indices:
            word = words[i]
            min_cost[word] = group_min
    
    # Read the message words
    message = sys.stdin.readline().split()
    
    # Calculate the total minimum cost
    total = sum(min_cost[word] for word in message)
    
    # Output the result
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency, especially with large input sizes.
2. **Word and Cost Lists**: The words and their costs are stored in lists for easy access.
3. **Group Processing**: Each group is processed to find the minimum cost within the group. This minimum cost is then associated with each word in the group using a dictionary.
4. **Message Cost Calculation**: For each word in the message, the dictionary is used to find the minimum cost for that word's group, and these costs are summed to get the total minimum cost.

This approach ensures that each word in the message is replaced with the cheapest possible alternative from its group, leading to the optimal solution. The time complexity is linear with respect to the number of words and groups, making it efficient even for large input sizes.
