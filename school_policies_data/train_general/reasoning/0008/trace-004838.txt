To solve this problem, we need to determine if a given problem name contains exactly one occurrence of any of Alex's friends' names. The friends' names are "Danil", "Olya", "Slava", "Ann", and "Nikita", and the check is case-sensitive.

### Approach
1. **Problem Analysis**: The task is to check if the input string contains exactly one occurrence of any of the specified names. Each name must be checked exactly as given, considering case sensitivity.
2. **Intuition**: We need to iterate through each possible substring of the input string that matches the length of each friend's name and check for exact matches.
3. **Algorithm**:
   - For each friend's name, generate all possible substrings of the same length from the input string.
   - Count the total number of exact matches across all friend's names.
   - If the total count is exactly one, print "YES"; otherwise, print "NO".
4. **Complexity**: The algorithm efficiently checks each substring, leading to a time complexity of O(n * m), where n is the length of the input string and m is the number of friends (5 in this case). This is efficient given the input constraints (string length up to 100).

### Solution Code
```python
def check_contest():
    friends = ["Danil", "Olya", "Slava", "Ann", "Nikita"]
    s = input().strip()
    count = 0
    for name in friends:
        name_len = len(name)
        for i in range(len(s) - name_len + 1):
            if s[i:i+name_len] == name:
                count += 1
    print("YES" if count == 1 else "NO")

check_contest()
```

### Explanation
- **Reading Input**: The input string is read and stripped of any leading/trailing whitespace.
- **Iterating Over Friends' Names**: For each friend's name, we determine its length and generate all possible substrings of that length from the input string.
- **Checking Matches**: Each substring is compared to the friend's name. If a match is found, the count is incremented.
- **Result Determination**: After checking all possible substrings for all friends' names, if the total count of matches is exactly one, "YES" is printed; otherwise, "NO" is printed.

This approach ensures that we accurately count occurrences of each friend's name and determine if the problem name meets the contest criteria.
