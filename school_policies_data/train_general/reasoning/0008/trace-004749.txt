To solve this problem, we need to determine if we can fill a huge grid such that each pair of neighboring cells has values with different parities. The grid is initially populated with some cells containing non-negative integers, and we need to check if the existing cells allow for a valid filling of the remaining cells.

### Approach
The key insight is that the grid must follow a checkerboard pattern where each cell's parity (even or odd) alternates with its neighbors. This pattern can be determined by the sum of the row and column indices of each cell. Specifically, each cell (r, c) must have a parity that matches either (r + c) % 2 or (r + c + 1) % 2. We need to check if all existing cells can conform to one of these two patterns.

1. **Parity Calculation**: For each existing cell (r, c, x), compute the parity of the sum of its row and column indices, and the parity of the value x.
2. **Consistency Check**: Determine if all existing cells agree on the same parity pattern. This is done by checking if the computed parity offset (p) for each cell is consistent across all cells.

### Solution Code
```python
import sys

def solve():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        n = int(input[ptr])
        ptr += 1
        first_p = None
        valid = True
        for __ in range(n):
            r = int(input[ptr])
            c = int(input[ptr+1])
            x = int(input[ptr+2])
            ptr += 3
            sum_rc = r + c
            sum_p = sum_rc % 2
            x_p = x % 2
            current_p = (x_p - sum_p) % 2
            if first_p is None:
                first_p = current_p
            else:
                if current_p != first_p:
                    valid = False
        print("Yes" if valid else "No")

solve()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the large potential size of the input.
2. **Processing Each Test Case**: For each test case, we read the number of non-empty cells and then process each cell to check its parity consistency.
3. **Parity Check**: For each cell, compute the sum of its row and column indices, then determine the required parity based on this sum and the cell's value. The difference (mod 2) between the value's parity and the sum's parity gives the parity offset (p).
4. **Validation**: Ensure all cells have the same parity offset. If they do, the answer is "Yes"; otherwise, it is "No".

This approach efficiently checks the consistency of the existing cells with a possible checkerboard pattern, ensuring the solution is both optimal and correct.
