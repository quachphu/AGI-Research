2. **Generate Divisors List**: Create a list of prime factors where each prime is repeated according to its exponent. For example, if \( n = 36 \) (which factors into \( 2^2 \times 3^2 \)), the list will be \([2, 2, 3, 3]\).
3. **Construct the Sequence**: Start with \( n \) and iteratively divide by each prime in the generated list to form the sequence. This ensures that each subsequent value is a divisor of the previous one, maximizing the length of the sequence.

### Solution Code
```python
def factorize(n):
    factors = {}
    while n % 2 == 0:
        factors[2] = factors.get(2, 0) + 1
        n = n // 2
    i = 3
    max_i = int(n ** 0.5) + 1
    while i <= max_i and n > 1:
        while n % i == 0:
            factors[i] = factors.get(i, 0) + 1
            n = n // i
            max_i = int(n ** 0.5) + 1
        i += 2
    if n > 1:
        factors[n] = 1
    return factors

def main():
    import sys
    n = int(sys.stdin.readline())
    if n == 1:
        print(1)
        return
    factors = factorize(n)
    primes = sorted(factors.keys())
    prime_list = []
    for p in primes:
        prime_list.extend([p] * factors[p])
    sequence = [n]
    current = n
    for p in prime_list:
        current = current // p
        sequence.append(current)
    print(' '.join(map(str, sequence)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prime Factorization**: The `factorize` function decomposes \( n \) into its prime factors and their respective exponents. For example, \( n = 10 \) is decomposed into \( \{2: 1, 5: 1\} \).
2. **Generate Divisors List**: Using the prime factors, we generate a list where each prime is repeated according to its exponent. For \( n = 10 \), this list is \([2, 5]\).
3. **Construct the Sequence**: Starting with \( n \), each subsequent value is obtained by dividing the current value by the next prime in the list. This ensures that each value is a divisor of the previous one, forming a valid sequence. For \( n = 10 \), the sequence is \([10, 5, 1]\).

This approach ensures that the sequence is the longest possible by leveraging the prime factorization and systematically reducing the value by each prime factor, thus adhering to the problem constraints and requirements.
