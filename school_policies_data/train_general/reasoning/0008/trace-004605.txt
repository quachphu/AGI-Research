To solve this problem, we need to determine if a given string is balanced with respect to round and square brackets. A string is balanced if every opening bracket has a corresponding closing bracket in the correct order, and vice versa.

### Approach
1. **Input Handling**: Read each line from the input until a line consisting solely of a period (.) is encountered. Each line represents a dataset terminated by a period, which should be excluded from the check.
2. **Stack-Based Validation**: Use a stack data structure to keep track of opening brackets. For each closing bracket encountered, check if it matches the most recent opening bracket (i.e., the top of the stack).
3. **Termination Condition**: The process stops when a line with only a period is read.

### Solution Code
```python
import sys

def is_balanced(s):
    stack = []
    for c in s:
        if c in '([':
            stack.append(c)
        elif c in ')]':
            if not stack:
                return False
            top = stack.pop()
            if (c == ')' and top != '(') or (c == ']' and top != '['):
                return False
    return len(stack) == 0

for line in sys.stdin:
    line = line.rstrip('\n')
    if line == '.':
        break
    if line.endswith('.'):
        dataset = line[:-1]
    else:
        dataset = line
    if is_balanced(dataset):
        print("yes")
    else:
        print("no")
```

### Explanation
1. **Reading Input**: The input is read line by line. Each line is stripped of the newline character.
2. **Termination Check**: If a line is exactly '.', the loop terminates.
3. **Dataset Extraction**: For each valid dataset line, the period at the end is removed to form the dataset string.
4. **Balanced Check**: The `is_balanced` function uses a stack to ensure all brackets are properly nested and matched. If a closing bracket does not match the corresponding opening bracket, or if there are unmatched brackets left in the stack, the string is unbalanced.

This approach efficiently checks each dataset in linear time, making it suitable for the input constraints.
