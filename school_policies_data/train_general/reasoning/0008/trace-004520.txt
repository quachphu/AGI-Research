To solve this problem, we need to determine if Alexey can pay the exact donation amount required by each university using coins of denominations within a specified range. The solution involves checking if there exists a combination of coins such that their sum equals the donation amount.

### Approach
The key insight is to determine if there exists a number of coins \( k \) such that the sum of \( k \) coins (each with a denomination between \( l_i \) and \( r_i \)) equals the donation amount \( n_i \). This can be efficiently checked using the following steps:

1. **Calculate the Minimum Number of Coins (k_min):** This is the smallest number of coins required if we use the largest denomination \( r_i \). It is computed as the ceiling of \( n_i / r_i \), which can be efficiently calculated using integer arithmetic.
2. **Calculate the Maximum Number of Coins (k_max):** This is the largest number of coins required if we use the smallest denomination \( l_i \). It is computed as the floor of \( n_i / l_i \).
3. **Check Feasibility:** If there exists a \( k \) in the range \([k_{min}, k_{max}]\), then it is possible to form the donation amount \( n_i \) using the given denominations. This is because the range \([k_{min} \times l_i, k_{max} \times r_i]\) will cover \( n_i \) if \( k_{min} \leq k_{max} \).

### Solution Code
```python
t = int(input())
for _ in range(t):
    ni, li, ri = map(int, input().split())
    k_min = (ni + ri - 1) // ri
    k_max = ni // li
    print("Yes" if k_min <= k_max else "No")
```

1. **Reading Input:** The number of test cases \( t \) is read first. For each test case, the donation amount \( n_i \), minimum denomination \( l_i \), and maximum denomination \( r_i \) are read.
2. **Calculate k_min:** This is the minimum number of coins needed if using the largest denomination. It is calculated as \(\lceil \frac{n_i}{r_i} \rceil\), which is computed using integer arithmetic as \((n_i + r_i - 1) // r_i\).
3. **Calculate k_max:** This is the maximum number of coins needed if using the smallest denomination. It is calculated as \(\lfloor \frac{n_i}{l_i} \rfloor\), which is \(n_i // l_i\).
4. **Check Condition:** If \( k_{min} \leq k_{max} \), print "Yes" indicating that it is possible to form the donation amount using the given denominations. Otherwise, print "No".

This approach efficiently checks the feasibility using arithmetic operations, ensuring it runs in constant time for each test case, making it suitable for large input sizes.
