To solve this problem, we need to determine the maximum and minimum product of any non-empty subset of elements from an array. The solution involves generating all possible subsets and their products, then finding the maximum and minimum values among these products.

### Approach
1. **Input Reading**: Read the number of test cases and the arrays for each test case.
2. **Generate Subset Products**: For each element in the array, generate all possible products of subsets that include the current element. This is done using a dynamic programming approach where we maintain a set of products formed by including each element one by one.
3. **Track Maximum and Minimum Products**: After generating all possible products, determine the maximum and minimum values from the set of products.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N = int(input[idx])
        idx += 1
        arr = list(map(int, input[idx:idx+N]))
        idx += N
        
        current_products = set()
        for num in arr:
            new_products = {num}
            for p in current_products:
                new_products.add(p * num)
            current_products.update(new_products)
        
        max_p = max(current_products)
        min_p = min(current_products)
        print(max_p, min_p)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints. The input is split into a list of strings for easy processing.
2. **Dynamic Programming with Sets**: For each element in the array, we generate new products by multiplying the element with all previously generated products (stored in a set to avoid duplicates). This ensures that we consider all possible subsets efficiently.
3. **Updating Products Set**: The set `current_products` is updated iteratively for each element in the array, ensuring that all possible subset products are considered.
4. **Finding Results**: After processing all elements, the maximum and minimum values from the set of products are determined and printed.

This approach efficiently handles the constraints and ensures that all possible non-empty subsets are considered, providing the correct maximum and minimum products in a time-efficient manner.
