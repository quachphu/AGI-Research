To solve this problem, we need to determine the winner of a string game where two players take turns cutting the string into three parts based on specific conditions. The solution involves using dynamic programming and game theory concepts, specifically Grundy numbers, to determine the optimal moves.

### Approach
1. **Identify Valid Cuts**: A valid cut at position `i` is determined by checking if the characters at positions `i-1` and `i+1` are the same. This is because a valid cut requires symmetry around the chosen position.
2. **Dynamic Programming Setup**: Use a 2D array `grundy` where `grundy[l][r]` represents the Grundy number for the substring from index `l` to `r`.
3. **Grundy Number Calculation**: For each substring, compute the Grundy number by considering all valid cuts. The Grundy number is the minimum excludant (mex) of the XOR of the Grundy numbers of the left and right parts resulting from each valid cut.
4. **Determine Winner**: If the Grundy number of the entire string is non-zero, the first player wins. Otherwise, the second player wins. If the first player wins, find the minimal position for the winning move.

s = input().strip()
n = len(s)
if n == 0:
    print("Second")
    exit()

# Convert s to 0-based
s = list(s)

valid = [0] * (n + 2)  # 1-based indices from 1 to n
for i in range(1, n - 1):  # 1-based i ranges from 2 to n-1 (0-based 1 to n-2)
    if s[i - 1] == s[i + 1]:
        valid[i + 1] = 1  # since i+1 is 1-based

# Precompute prefix sum for valid
pre_sum = [0] * (n + 2)
for i in range(1, n + 1):
    pre_sum[i] = pre_sum[i - 1] + valid[i]

# Function to check if substring l..r (1-based) has any valid cuts
def can_cut(l, r):
    if r - l < 2:
        return False
    return pre_sum[r - 1] - pre_sum[l] > 0

# Initialize grundy table
grundy = [[0] * (n + 2) for _ in range(n + 2)]

# Compute grundy for all substrings in increasing order of length
for length in range(2, n + 1):
    for l in range(1, n - length + 2):
        r = l + length - 1
        if can_cut(l, r):
            mex_set = set()
            # Iterate through all possible i in l+1 to r-1 where valid[i] is 1
            # To find these i's efficiently, we can loop through the valid array
            # but this is still O(r - l -1) per substring
            for i in range(l + 1, r):
                if valid[i]:
                    left = grundy[l][i - 1]
                    right = grundy[i + 1][r]
                    mex_set.add(left ^ right)
            mex = 0
            while mex in mex_set:
                mex += 1
            grundy[l][r] = mex
        else:
            grundy[l][r] = 0

            left_g = grundy[1][i - 1]

                print(i)
