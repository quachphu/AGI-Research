To solve this problem, we need to find the lexicographically largest permutation of an array using at most K swaps. The approach involves greedily placing the largest possible element at each position from left to right, using the minimum number of swaps necessary.

### Approach
1. **Understand the Goal**: The goal is to rearrange the array such that each position from left to right holds the largest possible remaining value. This means for the first position, we want the largest element, for the second position the next largest, and so on.
2. **Track Positions Efficiently**: Use an array to track the current index of each value. This allows us to quickly find where each desired value is located.
3. **Greedy Swaps**: For each position from left to right, determine the largest value that should be placed at that position. If it is not already there, swap it into place and update the tracked positions. Continue until we run out of swaps.

### Solution Code
```python
import sys

def main():
    N, K = map(int, sys.stdin.readline().split())
    arr = list(map(int, sys.stdin.readline().split()))
    pos = [0] * (N + 1)  # pos[value] = index
    
    for idx, val in enumerate(arr):
        pos[val] = idx
    
    for i in range(N):
        if K <= 0:
            break
        desired = N - i
        if arr[i] == desired:
            continue
        # Find the current position of the desired value
        j = pos[desired]
        # Swap the elements in the array
        arr[i], arr[j] = arr[j], arr[i]
        # Update the positions in the pos array
        pos[arr[j]] = j  # The value that was at i is now at j
        pos[desired] = i  # The desired value is now at i
        K -= 1
    
    print(' '.join(map(str, arr)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of the size of the array (N), the maximum number of swaps (K), and the array itself.
2. **Position Tracking**: We use an array `pos` where `pos[value]` gives the current index of `value` in the array. This allows us to quickly locate where each value is.
3. **Greedy Swapping**: For each position `i` from 0 to N-1:
   - Determine the largest possible value that should be at position `i` (which is `N - i`).
   - If this value is not already at `i`, find its current index using the `pos` array.
   - Swap the value at `i` with the desired value. Update the `pos` array to reflect the new positions of the swapped values.
   - Decrement the swap counter `K` and stop if no swaps remain.
4. **Output**: Print the modified array after performing the swaps.

This approach ensures that we use each swap to place the largest possible remaining value at each position, leading to the lexicographically largest permutation possible within the given constraints. The time complexity is O(N), which is efficient for large values of N up to 100,000.
