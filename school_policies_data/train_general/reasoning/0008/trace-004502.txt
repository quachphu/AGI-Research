To solve this problem, we need to find the shortest closed cycle in a weighted undirected graph that traverses every edge at least once. This problem is known as the Chinese Postman Problem (CPP). The solution involves determining if the graph is Eulerian (all vertices have even degrees) and, if not, finding the minimal paths to make it Eulerian by pairing vertices with odd degrees optimally.

### Approach
1. **Check for Eulerian Circuit**: If all vertices have even degrees, the graph is Eulerian, and the answer is simply the sum of all edge weights.
2. **Identify Odd-Degree Vertices**: If there are vertices with odd degrees, we need to pair them optimally using the shortest paths between each pair.
3. **Compute All-Pairs Shortest Paths (APSP)**: Use the Floyd-Warshall algorithm to compute the shortest paths between all pairs of vertices.
4. **Dynamic Programming for Optimal Pairing**: Use dynamic programming to find the minimal sum of shortest paths required to pair all odd-degree vertices, making the graph Eulerian.

```python
import sys
from functools import lru_cache

def main():
    input = sys.stdin.read().split()
    ptr = 0
    v = int(input[ptr])
    ptr += 1
    e = int(input[ptr])
    ptr += 1

    degrees = [0] * v
    sum_d = 0
    INF = float('inf')
    dist = [[INF] * v for _ in range(v)]
    for i in range(v):
        dist[i][i] = 0

    for _ in range(e):
        s = int(input[ptr])
        ptr += 1
        t = int(input[ptr])
        ptr += 1
        d = int(input[ptr])
        ptr += 1
        sum_d += d
        degrees[s] += 1
        degrees[t] += 1
        if d < dist[s][t]:
            dist[s][t] = d
            dist[t][s] = d

    # Floyd-Warshall algorithm to compute all-pairs shortest paths
    for k in range(v):
        for i in range(v):
            for j in range(v):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    odd_nodes = [i for i in range(v) if degrees[i] % 2 != 0]
    if not odd_nodes:
        print(sum_d)
        return

    n = len(odd_nodes)
    assert n % 2 == 0

    @lru_cache(maxsize=None)
    def dp(mask):
        if mask == 0:
            return 0
        # Find the first set bit
        first = None
        for i in range(n):
            if mask & (1 << i):
                first = i
                break
        min_cost = INF
        for j in range(first + 1, n):
            if mask & (1 << j):
                new_mask = mask ^ ((1 << first) | (1 << j))
                cost = dist[odd_nodes[first]][odd_nodes[j]]
                current = cost + dp(new_mask)
                if current < min_cost:
                    min_cost = current
        return min_cost

    minimal_sum = dp((1 << n) - 1)
    print(sum_d + minimal_sum)

if __name__ == "__main__":
    main()
```

3. **Dynamic Programming for Pairing**: The dynamic programming approach uses a bitmask to represent the set of remaining vertices to pair. The `dp` function recursively finds the minimal cost to pair all vertices, using memoization to optimize repeated calculations.
4. **Result Calculation**: The total distance is the sum of all edge weights plus the minimal cost of pairing odd-degree vertices, which is printed as the result.

This approach efficiently handles the constraints and ensures the shortest closed cycle is found by transforming the graph into an Eulerian one through optimal edge additions.
