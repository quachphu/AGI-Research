### Approach
1. **Monotonic Stacks for Bounds Calculation**: We use monotonic stacks to efficiently determine the nearest greater elements to the left and right for each element in the permutation. This helps in identifying the valid ranges where each element is the maximum.
2. **Value to Position Mapping**: Create a mapping from each value in the permutation to its index for quick lookup.
3. **Iterate Over Each Element as Maximum**: For each element considered as the maximum value (s), determine the valid left and right subsegments where this element is the maximum.
4. **Check Valid Pairs**: For each element in the left subsegment, check if the corresponding pair (s - element) exists in the right subsegment and increment the count if valid.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    p = list(map(int, input[1:n+1]))
    pos_map = {v: i for i, v in enumerate(p)}
    
    # Compute left_bound using monotonic stack (next greater to the left)
    left_bound = [-1] * n
    stack = []
    for i in range(n):
        while stack and p[stack[-1]] < p[i]:
            stack.pop()
        if stack:
            left_bound[i] = stack[-1]
        else:
            left_bound[i] = -1
        stack.append(i)
    
    # Compute right_bound using monotonic stack (next greater to the right)
    right_bound = [n] * n
    stack = []
    for i in range(n-1, -1, -1):
        while stack and p[stack[-1]] < p[i]:
            stack.pop()
        if stack:
            right_bound[i] = stack[-1]
        else:
            right_bound[i] = n
        stack.append(i)
    
    total = 0
    for s_val in p:
        pos_s = pos_map[s_val]
        lb = left_bound[pos_s]
        rb = right_bound[pos_s]
        
        # Indices for left_part: [lb + 1, pos_s]
        left_start = lb + 1
        left_end = pos_s
        
        # Indices for right_part: [pos_s, rb - 1]
        right_start = pos_s
        right_end = rb - 1
        
        # Collect elements in right_part and create a set for quick lookups
        right_values = set()
        if right_start <= right_end:
            for i in range(right_start, right_end + 1):
                right_values.add(p[i])
        
        # Check each a in left_part
        count = 0
        if left_start <= left_end:
            for i in range(left_start, left_end + 1):
                a = p[i]
                b = s_val - a
                if b in pos_map:
                    b_pos = pos_map[b]
                    if right_start <= b_pos <= right_end:
                        count += 1
        total += count
    
    print(total)

if __name__ == "__main__":
    main()
```
