To solve this problem, we need to ensure that all k jobs in the kingdom of Lazyland are assigned to idlers such that each job is done by exactly one idler. The goal is to minimize the total persuasion time required to reassign idlers to jobs that are initially not chosen by anyone.

### Approach
1. **Collect Job Preferences**: For each job from 1 to k, collect the list of idlers who initially chose that job.
2. **Identify Unassigned Jobs**: Determine the number of jobs (referred to as `required`) that have no idlers initially choosing them.
3. **Prepare Persuasion Pool**: For each job that has more than one idler, keep the idler with the highest persuasion time (to minimize the cost of persuading others) and add the remaining idlers to a pool of candidates who can be persuaded to switch jobs.
4. **Calculate Minimum Persuasion Time**: Sort the pool of candidates by their persuasion time and sum the smallest `required` values from this pool to get the minimum total persuasion time.

```python
def solve():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    k = int(input[ptr])
    ptr += 1

    a = list(map(int, input[ptr:ptr + n]))
    ptr += n
    b = list(map(int, input[ptr:ptr + n]))
    ptr += n

    jobs = [[] for _ in range(k + 1)]  # 1-based indexing for jobs 1..k
    for i in range(n):
        job = a[i]
        if job <= k:
            jobs[job].append(b[i])

    required = 0
    for j in range(1, k + 1):
        if not jobs[j]:
            required += 1

    pool = []
    for j in range(1, k + 1):
        lst = jobs[j]
        if not lst:
            continue
        lst.sort()
        take = len(lst) - 1
        pool.extend(lst[:take])

    if required == 0:
        print(0)
        return

    pool.sort()
    print(sum(pool[:required]))

solve()
```

4. **Build Persuasion Pool**: For each job with multiple idlers, sort the persuasion times and keep the highest value (to minimize future persuasion costs), adding the rest to a pool.
5. **Calculate Minimum Cost**: Sort the pool of persuasion times and sum the smallest values needed to cover all required jobs, ensuring the minimum total persuasion time.
