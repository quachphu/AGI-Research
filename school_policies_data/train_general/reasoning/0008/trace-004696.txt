To solve this problem, we need to efficiently compute the result of multiple queries on an array of integers. Each query involves calculating a specific sum based on given parameters. Given the constraints, a direct approach would be too slow, so we use prefix sums to optimize the solution.

### Approach
1. **Understanding the Query Formula**: Each query requires computing the sum of elements in a specific range, adjusted by a weight and indices. The formula for each query is derived as the sum of elements multiplied by their respective weights and indices.
2. **Prefix Sum Arrays**: We precompute two prefix sum arrays:
   - `S1` for the cumulative sum of the array elements.
   - `S2` for the cumulative sum of each element multiplied by its index.
3. **Efficient Query Calculation**: For each query, determine the range of indices and use the prefix sums to compute the result in constant time by breaking down the problem into manageable parts using the precomputed sums.

### Solution Code
```python
import sys

MOD = 10**9 + 7

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        n, q = map(int, input[ptr:ptr+2])
        ptr += 2
        a = list(map(int, input[ptr:ptr+n]))
        ptr += n
        # Convert to 1-based index
        a = [0] + a
        # Precompute prefix sums S1 and S2
        S1 = [0] * (n + 1)
        S2 = [0] * (n + 1)
        for i in range(1, n + 1):
            S1[i] = S1[i-1] + a[i]
            S2[i] = S2[i-1] + a[i] * i
        # Process each query
        for _ in range(q):
            w, x, y, z = map(int, input[ptr:ptr+4])
            ptr += 4
            L = x + y
            R = x + z
            sum1 = S1[R] - S1[L-1]
            sum2 = S2[R] - S2[L-1]
            res = (w - x) * sum1 + sum2
            print(res % MOD)

if __name__ == "__main__":
    main()
```

3. **Query Processing**: For each query, the range is determined using the provided parameters. The result is computed using the precomputed prefix sums, ensuring each query is processed in constant time.
