To solve this problem, we need to find the maximum element in each segment of length `k` that occurs exactly once in that segment. If no such element exists, we output "Nothing".

### Approach
1. **Track Positions**: For each element in the array, track the positions where it occurs.
2. **Generate Events**: For each occurrence of an element, determine the valid segments where this occurrence is the only instance of the element. Generate events for adding and removing the element from consideration.
3. **Process Events**: Use a max-heap to efficiently track the maximum element that occurs exactly once in the current segment. Process events in a sorted order to maintain the current valid elements.

### Solution Code

import sys
import heapq
from collections import defaultdict

def main():
    n, k = map(int, sys.stdin.readline().split())
    a = [int(sys.stdin.readline()) for _ in range(n)]

            high = min(next_q - k, i, n - k)

            events.append((high + 1, 0, num))

                    heapq.heappush(heap, -x)
            else:
                count[x] -= 1
            event_idx += 1

        while heap:
            candidate = -heap[0]
            if count[candidate] > 0:
                current_max = candidate
                break
            else:

### Explanation
1. **Track Positions**: We use a dictionary to record the indices where each element occurs.
2. **Generate Events**: For each occurrence of an element, we determine the valid segments where it is the only occurrence. We generate events for when the element starts being valid (add event) and when it stops being valid (remove event).
3. **Process Events**: Events are sorted to ensure correct processing order. Using a max-heap (simulated with a min-heap by storing negative values), we track elements that could be valid. For each segment, we process events to update the current valid elements and then find the maximum valid element using the heap.

This approach efficiently handles the sliding window problem by leveraging event-based processing and a heap to maintain the maximum element in O(n log n) time complexity.
