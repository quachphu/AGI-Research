To solve this problem, we need to determine if Ivan can buy exactly the number of chicken chunks he wants using a combination of small (3 chunks) and large (7 chunks) portions. The solution involves checking all possible combinations of these portions to see if they sum up to the desired number of chunks.

### Approach
1. **Problem Analysis**: For each test case, we need to check if there exist non-negative integers \(a\) and \(b\) such that \(3a + 7b = x\), where \(x\) is the number of chunks Ivan wants to eat.
2. **Intuition**: By iterating over possible values of \(b\) (the number of large portions), we can compute the remaining chunks needed and check if this remainder can be exactly divided by 3 (the size of a small portion). This reduces the problem to checking if the remainder is a non-negative multiple of 3.
3. **Algorithm**:
   - For each test case, iterate over possible values of \(b\) from 0 up to the maximum possible value (i.e., \(x // 7\)).
   - For each \(b\), compute the remainder when \(x - 7b\) is divided by 3.
   - If the remainder is zero and non-negative, then it is possible to form exactly \(x\) chunks using the current combination of portions.

### Solution Code
```python
n = int(input())
for _ in range(n):
    x = int(input())
    possible = False
    max_b = x // 7
    for b in range(max_b, -1, -1):
        remainder = x - 7 * b
        if remainder >= 0 and remainder % 3 == 0:
            possible = True
            break
    print("YES" if possible else "NO")
```

### Explanation
1. **Reading Input**: The code reads the number of test cases and then processes each test case individually.
2. **Iterating Over Large Portions**: For each test case, the maximum number of large portions (7 chunks) that could be used is calculated as \(x // 7\). The loop checks all possible values of \(b\) from this maximum down to 0.
3. **Checking Remainder**: For each value of \(b\), the remaining chunks after accounting for the large portions are calculated. If this remainder is non-negative and divisible by 3, then the exact number of chunks can be achieved using some number of small portions (3 chunks).
4. **Output Result**: For each test case, the result is printed as "YES" if a valid combination is found, otherwise "NO".

This approach efficiently checks all possible combinations using a linear scan over possible values of \(b\), ensuring correctness with a time complexity of \(O(n \cdot x)\), which is feasible given the problem constraints.
