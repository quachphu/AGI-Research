To solve this problem, we need to determine the minimum number of badge decks Vasya should take to ensure that there is a suitable deck for any possible combination of boys and girls participating in the tournament. 

### Approach
1. **Understanding the Problem Constraints**: The number of boys (b), girls (g), and tournament participants (n) are given. Each deck i contains i blue badges and (n-i) red badges. We need to find the minimum number of decks such that any valid distribution of boys and girls among the participants can be covered by at least one deck.

2. **Range of Possible Boys**: The number of boys (x) in the participants must satisfy two conditions:
   - It cannot exceed the total number of boys available, i.e., \( x \leq \min(b, n) \).
   - It must be at least the number of participants minus the number of girls available (since all other participants would have to be girls), i.e., \( x \geq \max(0, n - g) \).

3. **Calculate the Range**: The valid values of x range from \( \max(0, n - g) \) to \( \min(b, n) \). The number of valid values in this range gives the minimum number of decks needed.

### Solution Code
```python
b = int(input())
g = int(input())
n = int(input())

lower = max(0, n - g)
upper = min(b, n)
print(upper - lower + 1)
```

### Explanation
- **Reading Inputs**: The code reads the number of boys, girls, and participants.
- **Determine Valid Range**: The lower bound of boys (x) is calculated as \( \max(0, n - g) \) and the upper bound as \( \min(b, n) \).
- **Calculate Result**: The number of valid values between the lower and upper bounds (inclusive) is computed as \( \text{upper} - \text{lower} + 1 \), which gives the minimum number of decks required.

This approach efficiently narrows down the possible values of x using mathematical constraints, ensuring we cover all valid scenarios with the minimum number of decks.
