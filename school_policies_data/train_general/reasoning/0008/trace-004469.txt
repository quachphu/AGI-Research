To solve this problem, we need to determine if a given integer \( n \) has an odd divisor greater than one. This can be efficiently checked by removing all factors of 2 from \( n \) and checking if the remaining number is greater than 1.

### Approach
1. **Understanding the Problem**: A number \( n \) can be expressed as \( n = 2^k \times m \), where \( m \) is an odd integer. If \( m \) is greater than 1, then \( m \) itself is an odd divisor of \( n \). If \( m \) is 1, then \( n \) is a power of two and does not have any odd divisors other than 1.
2. **Algorithm**:
   - For each test case, repeatedly divide \( n \) by 2 until it is no longer even.
   - If the resulting number is 1, the original number was a power of two, so the answer is "NO".
   - Otherwise, the answer is "YES" because the remaining number is an odd divisor greater than 1.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    for i in range(1, t + 1):
        n = int(input[i])
        while n % 2 == 0:
            n //= 2
        print("NO" if n == 1 else "YES")

solve()
```

### Explanation
- **Reading Input**: The input is read all at once for efficiency, especially given the large number of test cases.
- **Processing Each Test Case**: For each number \( n \):
  - Divide \( n \) by 2 until it becomes odd.
  - Check if the resulting number is 1. If it is, print "NO" (indicating \( n \) was a power of two). Otherwise, print "YES" (indicating an odd divisor exists).

This approach ensures that each test case is processed in \( O(\log n) \) time due to the division by 2, which is efficient even for the upper constraint of \( n \leq 10^{14} \).
