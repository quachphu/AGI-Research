### Approach
1. **Generate Permutations**: Use the `itertools.permutations` function to generate all possible permutations of the input string. This function returns tuples of characters representing each permutation.
2. **Remove Duplicates**: Convert each permutation tuple into a string and collect these strings into a set to automatically eliminate duplicates.
3. **Sort Lexicographically**: Convert the set of unique permutations into a sorted list to ensure lexicographical order.
4. **Output Results**: Print each permutation from the sorted list on a new line.

This approach leverages Python's built-in libraries for permutation generation and set operations to ensure efficiency and correctness, even when handling strings with duplicate characters.

### Solution Code
```python
import itertools

def generate_permutations():
    s = input().strip()
    perms = itertools.permutations(s)
    unique_perms = set()
    for p in perms:
        unique_perms.add(''.join(p))
    for perm in sorted(unique_perms):
        print(perm)

generate_permutations()
```

### Explanation
1. **Input Handling**: The input string is read and stripped of any extraneous whitespace.
2. **Permutation Generation**: Using `itertools.permutations`, all possible permutations of the input string are generated. Each permutation is a tuple of characters.
3. **Deduplication**: Each permutation tuple is converted to a string and added to a set, which inherently removes duplicates.
4. **Sorting**: The set of unique permutation strings is converted to a sorted list to ensure lexicographical order.
5. **Output**: Each permutation from the sorted list is printed on a new line.

This method efficiently handles the constraints and ensures that all permutations are unique and presented in the required order.
