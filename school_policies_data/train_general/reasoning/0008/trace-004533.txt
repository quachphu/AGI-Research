To solve this problem, we need to calculate the Overall Power of a set of boxes, which is defined as the sum of absolute differences between each pair of box strengths multiplied by the maximum strength among the boxes. The result should be returned modulo \(10^9 + 7\).

### Approach
1. **Sorting the Array**: First, sort the array of strengths. Sorting helps in efficiently computing the sum of absolute differences using a prefix sum approach.
2. **Prefix Sum Calculation**: Use a running sum to keep track of the cumulative sum of elements up to the current index. This helps in calculating the sum of absolute differences in linear time.
3. **Sum of Absolute Differences**: For each element in the sorted array, compute the contribution to the sum of absolute differences using the running prefix sum.
4. **Multiplication by Maximum Strength**: After computing the sum of absolute differences, multiply it by the maximum element (which is the last element in the sorted array) and take the result modulo \(10^9 + 7\).

### Solution Code
```python
import sys

MOD = 10**9 + 7

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        A = list(map(int, input[ptr:ptr+N]))
        ptr += N
        A.sort()
        max_val = A[-1]
        current_sum = 0
        sum_abs = 0
        for i in range(N):
            if i > 0:
                sum_abs = (sum_abs + A[i] * i - current_sum) % MOD
            current_sum = (current_sum + A[i]) % MOD
        result = (sum_abs * max_val) % MOD
        print(result)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially for large inputs. The input is split into a list of strings for easy processing.
2. **Sorting**: The array of strengths is sorted to facilitate the calculation of absolute differences using a prefix sum approach.
3. **Prefix Sum and Absolute Differences**: As we iterate through the sorted array, we maintain a running sum of elements. For each element (starting from the second element), we calculate its contribution to the sum of absolute differences using the formula \(A[i] * i - \text{current_sum}\), where `current_sum` is the sum of all previous elements.
4. **Modulo Operations**: To handle large numbers and prevent overflow, we take modulo \(10^9 + 7\) at each step where intermediate results might become large.
5. **Result Calculation**: The sum of absolute differences is multiplied by the maximum strength (the last element in the sorted array) and the result is taken modulo \(10^9 + 7\) before being printed.

This approach ensures that the solution runs efficiently in \(O(N \log N)\) time per test case due to the sorting step, which is optimal for the given constraints.
