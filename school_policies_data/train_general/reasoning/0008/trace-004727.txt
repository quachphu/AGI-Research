To solve this problem, we need to determine the minimum and maximum sums of the distances between pairs of soulmates when assigned to houses in a tree structure. The tree structure ensures that there is exactly one path between any two houses. The goal is to minimize the sum of distances for the Good Place (G) and maximize it for the Bad Place (B).

### Approach
1. **Tree Structure Analysis**: The problem involves a tree with 2k nodes. Each edge in the tree has a weight representing the time to traverse it. We need to compute the contribution of each edge to the total sum of distances for both G and B.

2. **Subtree Size Calculation**: For each edge, determine the size of the subtree formed when that edge is removed. This helps in determining how many pairs of soulmates will have their path pass through that edge.

3. **Contribution Calculation**:
   - **Minimum Sum (G)**: The goal is to minimize the number of pairs crossing each edge. This is achieved by pairing nodes within subtrees as much as possible.
   - **Maximum Sum (B)**: The goal is to maximize the number of pairs crossing each edge. This is done by maximizing the pairs that use the edge, which is determined by the minimum size of the two subtrees formed by removing the edge.

4. **Efficient Traversal**: Use a depth-first search (DFS) to compute the subtree sizes and parent-child relationships, which helps in determining the contribution of each edge efficiently.

### Solution Code
```python
import sys
from sys import stdin

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        k = int(input[ptr])
        ptr +=1
        n = 2 * k
        edges = []
        for __ in range(2*k -1):
            a = int(input[ptr])
            b = int(input[ptr+1])
            t_val = int(input[ptr+2])
            ptr +=3
            edges.append( (a, b, t_val) )
        # Build adjacency list
        adj = [[] for _ in range(n+1)]
        for a, b, t_val in edges:
            adj[a].append( (b, t_val) )
            adj[b].append( (a, t_val) )
        # Compute parent and size
        parent = [0]*(n+1)
        size = [0]*(n+1)
        stack = [(1, False)]
        parent[1] = -1  # mark root's parent as non-existent
        while stack:
            node, processed = stack.pop()
            if not processed:
                stack.append( (node, True) )
                # Collect children (excluding parent)
                children = []
                for neighbor, _ in adj[node]:
                    if neighbor != parent[node]:
                        children.append(neighbor)
                # Push children in reverse order to process them in order
                for child in reversed(children):
                    parent[child] = node
                    stack.append( (child, False) )
            else:
                size[node] = 1
                for neighbor, _ in adj[node]:
                    if neighbor != parent[node] and parent[neighbor] == node:
                        size[node] += size[neighbor]
        # Process each edge
        G = 0
        B = 0
        for a, b, t_val in edges:
            if parent[b] == a:
                s = size[b]
            elif parent[a] == b:
                s = size[a]
            else:
                assert False, "Edge not in parent-child hierarchy"
            other = 2 * k - s
            # Compute G contribution
            g_pairs = k - ( (s // 2) + (other // 2) )
            G += g_pairs * t_val
            # Compute B contribution
            b_pairs = min(s, other)
            B += b_pairs * t_val
        print(G, B)

if __name__ == "__main__":
```
