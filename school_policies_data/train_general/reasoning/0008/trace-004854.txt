To solve this problem, we need to determine the number of distinct subsequences of each possible length from 1 to n+1 for a given sequence of length n+1. The sequence contains each integer from 1 to n exactly once, except for one integer that appears twice. The solution must efficiently compute these counts modulo \(10^9 + 7\).

### Approach
1. **Identify the Duplicate Element**: The sequence contains exactly one duplicate element. Identify this element using a frequency array.
2. **Dynamic Programming (DP) Array**: Use a DP array where `dp[k]` represents the number of distinct subsequences of length `k`.
3. **Handling Elements**: For each element in the sequence:
   - If the element is not the duplicate, update the DP array to include new subsequences formed by appending this element to existing subsequences.
   - For the first occurrence of the duplicate element, save the current state of the DP array.
   - For the second occurrence of the duplicate element, compute the contribution to the DP array by considering the difference between the current state and the saved state from the first occurrence.

### Solution Code
```python
MOD = 10**9 + 7

n, *rest = map(int, open(0).read().split())
a = rest[:n+1]

# Find the duplicated element x
freq = [0] * (n + 2)
x = -1
for num in a:
    freq[num] += 1
    if freq[num] == 2:
        x = num
        break

dp = [0] * (n + 2)
dp[0] = 1
prev_x_dp = None
count_x = 0

for num in a:
    if num != x:
        # Process normally: add dp[k-1] to dp[k] for all k from n+1 down to 1
        for k in range(n+1, 0, -1):
            dp[k] = (dp[k] + dp[k-1]) % MOD
    else:
        count_x += 1
        if count_x == 1:
            # Save the current dp state
            prev_x_dp = dp.copy()
            # Process normally: add dp[k-1] to dp[k]
            for k in range(n+1, 0, -1):
                dp[k] = (dp[k] + dp[k-1]) % MOD
        else:
            # Compute contribution based on the difference between current dp and prev_x_dp
            temp_dp = dp.copy()
            for k in range(n+1, 0, -1):
                prev = prev_x_dp[k-1] if k-1 < len(prev_x_dp) else 0
                contribution = (temp_dp[k-1] - prev) % MOD
                dp[k] = (dp[k] + contribution) % MOD

for k in range(1, n+2):
    print(dp[k] % MOD)
```

1. **Identify Duplicate Element**: The duplicate element is found using a frequency array. This element appears exactly twice in the sequence.
2. **DP Initialization**: The DP array is initialized with `dp[0] = 1` (representing the empty subsequence) and all other values set to 0.
3. **Processing Elements**:
   - For non-duplicate elements, the DP array is updated in reverse order to avoid overwriting values prematurely.
   - For the first occurrence of the duplicate element, the current state of the DP array is saved.
   - For the second occurrence, the contribution to each subsequence length is computed by considering the difference between the current state and the saved state from the first occurrence, ensuring no overcounting of subsequences that include the duplicate element.

This approach efficiently computes the number of distinct subsequences for each length, leveraging the properties of the sequence and dynamic programming to handle the constraints effectively.
