To solve this problem, we need to find the diameter of a tree, which is defined as the longest path between any two nodes in the tree. The approach involves using two breadth-first search (BFS) traversals to efficiently determine this maximum distance.

### Approach
1. **Understanding the Problem**: The diameter of a tree is the longest path between any two nodes. This can be found by:
   - First, selecting an arbitrary node and finding the farthest node from it using BFS.
   - Then, using the farthest node found in the first step as the new starting point to find the farthest node from it. The distance between these two farthest nodes is the diameter of the tree.

2. **Algorithm Selection**: The BFS traversal is chosen because it efficiently explores all nodes level by level, which helps in calculating the maximum distance in linear time. This approach ensures that we handle the constraints efficiently even for large trees.

3. **Complexity Analysis**: The algorithm involves two BFS traversals, each taking O(n) time, resulting in an overall time complexity of O(n), which is optimal for the given constraints.

### Solution Code
```python
import sys
from sys import stdin

def main():
    n = int(sys.stdin.readline())
    if n == 1:
        print(0)
        return
    adj = [[] for _ in range(n)]
    for _ in range(n-1):
        s, t, w = map(int, sys.stdin.readline().split())
        adj[s].append((t, w))
        adj[t].append((s, w))
    
    def get_farthest(start):
        max_dist = 0
        far_node = start
        stack = [(start, -1, 0)]
        while stack:
            node, parent, dist = stack.pop()
            if dist > max_dist:
                max_dist = dist
                far_node = node
            for neighbor, weight in adj[node]:
                if neighbor != parent:
                    stack.append((neighbor, node, dist + weight))
        return (far_node, max_dist)
    
    u, _ = get_farthest(0)
    v, diameter = get_farthest(u)
    print(diameter)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency, especially given the large possible input size. The tree is represented as an adjacency list where each node points to its connected nodes along with the edge weights.

2. **Finding the Farthest Node**: The `get_farthest` function uses a stack-based BFS to traverse the tree starting from a given node. It keeps track of the maximum distance encountered and the corresponding farthest node.

3. **Two BFS Traversals**: The first BFS from an arbitrary node (node 0) finds one end of the longest path (node `u`). The second BFS from node `u` finds the other end (node `v`), and the distance between `u` and `v` is the diameter of the tree.

This approach efficiently computes the diameter in linear time, ensuring it handles the upper constraint of 100,000 nodes effectively.
