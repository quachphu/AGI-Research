To solve this problem, we need to read a sequence of integers, compute their minimum value, maximum value, and sum, and then print these results. The solution involves straightforward input handling and utilizing Python's built-in functions for efficient computation.

### Approach
1. **Reading Input**: First, we read the integer `n` which denotes the number of elements in the sequence. Then, we read the next line containing `n` integers separated by spaces.
2. **Conversion to List**: Convert the input string of integers into a list of integers for easy manipulation.
3. **Compute Values**: Use Python's built-in functions `min()`, `max()`, and `sum()` to compute the minimum value, maximum value, and sum of the list respectively.
4. **Output Results**: Print the computed values in the required format.

### Solution Code
```python
def main():
    n = int(input())
    numbers = list(map(int, input().split()))
    print(min(numbers), max(numbers), sum(numbers))

main()
```

### Explanation
1. **Reading Input**: The first line of input is converted to an integer `n` using `int(input())`. The second line is split into individual string elements using `input().split()`, which are then converted to integers using `map(int, ...)` and stored in a list.
2. **Computing Values**: The `min()` and `max()` functions efficiently find the smallest and largest elements in the list, while `sum()` calculates the total sum of all elements. These operations are optimized in Python and handle even large lists efficiently.
3. **Output**: The results are printed in a single line with spaces separating the minimum, maximum, and sum values, meeting the problem's output requirements.

This approach ensures that the solution is both efficient and easy to understand, leveraging Python's built-in functions for optimal performance.
