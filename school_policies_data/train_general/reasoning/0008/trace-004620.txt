To solve this problem, we need to determine the minimum number of days Polycarp needs to complete his coursework given the caffeine levels in his coffee cups. Each day, the effectiveness of the coffee decreases based on the order in which he drinks them. The goal is to find the optimal way to distribute the coffee consumption over the fewest days possible.

### Approach
1. **Sort the Coffee Cups**: First, we sort the coffee cups in descending order of caffeine levels. This allows us to maximize the effectiveness of the coffee consumed each day by using the strongest coffees first.
2. **Binary Search for Minimum Days**: We use binary search to determine the minimum number of days required. For each candidate number of days (mid), we check if it's possible to achieve the required number of pages (m) by distributing the coffee consumption optimally.
3. **Check Feasibility for Each Day Count**: For each candidate day count (mid), we calculate the total number of pages Polycarp can write. This is done by iterating through the sorted coffee cups and applying the penalty based on their position within the days. We break early if the coffee's effectiveness becomes non-positive to optimize the check.

### Solution Code
```python
n, m = map(int, input().split())
a = list(map(int, input().split()))
a.sort(reverse=True)

low = 1
high = n
ans = -1

while low <= high:
    mid = (low + high) // 2
    total = 0
    for i in range(n):
        q = i // mid
        if a[i] > q:
            total += a[i] - q
        else:
            break
    if total >= m:
        ans = mid
        high = mid - 1
    else:
        low = mid + 1

print(ans if ans != -1 else -1)
```

### Explanation
1. **Sorting**: The coffee cups are sorted in descending order to ensure we start with the most potent coffee each day, minimizing the penalty effect.
2. **Binary Search**: We perform a binary search over the possible number of days (from 1 to n). For each midpoint (mid), we check if distributing the coffee consumption over mid days can achieve the required pages (m).
3. **Feasibility Check**: For each candidate day count (mid), we calculate the total pages by iterating through the sorted list. Each coffee's contribution is adjusted by the penalty based on its position when divided into mid days. If the total pages meet or exceed m, mid is a feasible solution, and we search for a smaller number of days. If not, we increase the number of days.

This approach efficiently narrows down the minimum number of days using binary search combined with an optimized feasibility check, ensuring the solution is both optimal and efficient.
