To solve this problem, we need to determine if a given three-digit integer contains the digit 7. If it does, we print "Yes"; otherwise, we print "No". The solution involves checking each digit of the number efficiently.

### Approach
The key insight here is to treat the input as a string rather than a numerical value. This allows us to directly check each character (digit) in the string for the presence of the digit '7'. This approach simplifies the problem significantly because string operations are straightforward and efficient for this use case.

### Solution Code
```python
def main():
    n = input().strip()
    print("Yes" if '7' in n else "No")

main()
```

### Explanation
1. **Reading Input**: The input is read as a string using `input().strip()`, which removes any leading or trailing whitespace (though not necessary here due to the problem constraints, it's a good practice).
2. **Checking for Digit 7**: We check if the string contains the character '7' using the `in` keyword. This is a concise and efficient way to determine if any of the digits in the number is 7.
3. **Output Result**: Based on the presence of '7' in the string, we print "Yes" if found, otherwise "No".

This approach ensures that we efficiently check each digit in constant time, making the solution both optimal and easy to understand.
