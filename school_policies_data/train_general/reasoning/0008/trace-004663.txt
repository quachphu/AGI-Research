To solve this problem, we need to determine the total winnings from lottery tickets based on given winning patterns. Each winning pattern consists of 8 characters (digits and/or asterisks) and a corresponding prize amount. A lottery ticket matches a winning pattern if all the digits in the pattern (non-asterisk characters) match the corresponding digits in the ticket. Each ticket can match at most one winning pattern, as ensured by the input constraints.

### Approach
1. **Input Handling**: Read multiple datasets until encountering a line with two zeros. Each dataset starts with the number of winning patterns and lottery tickets.
2. **Pattern Storage**: For each winning pattern, store both the pattern and its associated prize amount.
3. **Matching Check**: For each lottery ticket, check against all winning patterns. If a match is found, add the prize amount to the total and stop checking further patterns for that ticket (due to input constraints ensuring no multiple matches).
4. **Output**: After processing all tickets for a dataset, output the total winnings.

### Solution Code
```python
import sys

def main():
    lines = [line.strip() for line in sys.stdin if line.strip()]
    ptr = 0
    while ptr < len(lines):
        n, m = map(int, lines[ptr].split())
        ptr += 1
        if n == 0 and m == 0:
            break
        patterns = []
        for _ in range(n):
            parts = lines[ptr].split()
            ptr += 1
            ni = parts[0]
            mi = int(parts[1])
            patterns.append((ni, mi))
        total = 0
        for _ in range(m):
            bj = lines[ptr]
            ptr += 1
            for ni, mi in patterns:
                match = True
                for i in range(8):
                    if ni[i] != '*' and ni[i] != bj[i]:
                        match = False
                        break
                if match:
                    total += mi
                    break
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once into a list of lines for efficient processing. This avoids issues with mixing different input methods.
2. **Processing Each Dataset**: For each dataset, the number of winning patterns and lottery tickets are read first. Winning patterns are stored along with their prize amounts.
3. **Checking Matches**: Each lottery ticket is checked against each winning pattern. If all non-asterisk characters in the pattern match the corresponding characters in the ticket, the prize amount is added to the total, and further checks for that ticket are skipped.
4. **Output**: After processing all tickets in a dataset, the total winnings are printed.

This approach ensures efficient processing of each dataset, leveraging the input constraints to optimize the matching check by stopping early when a match is found.
