To solve this problem, we need to determine if Snuke can return to his starting point after N days of travel in specified directions, with each day's travel distance being a positive value he can choose. The solution involves checking if the directions allow for cancellation in such a way that the total displacement is zero.

### Approach
The key insight is that for Snuke to return home, the movements in opposite directions (North-South and East-West) must cancel each other out. This means:
1. If there are any North (N) movements, there must be corresponding South (S) movements to cancel them, and vice versa.
2. Similarly, if there are any East (E) movements, there must be corresponding West (W) movements to cancel them, and vice versa.

The solution involves:
1. Counting the occurrences of each direction (N, S, E, W) in the input string.
2. Checking if both North and South directions are either both present (at least one each) or both absent.
3. Checking if both East and West directions are either both present (at least one each) or both absent.

If both conditions are satisfied, Snuke can return home, otherwise, he cannot.

### Solution Code
```python
s = input().strip()
count_n = s.count('N')
count_s = s.count('S')
count_e = s.count('E')
count_w = s.count('W')

valid_ns = (count_n == 0 and count_s == 0) or (count_n >= 1 and count_s >= 1)
valid_ew = (count_e == 0 and count_w == 0) or (count_e >= 1 and count_w >= 1)

print("Yes" if valid_ns and valid_ew else "No")
```

### Explanation
1. **Count Directions**: We first count how many times each direction (N, S, E, W) appears in the input string.
2. **Check Validity for North-South**: We check if both North and South directions are either both present (each appearing at least once) or both absent. This ensures their movements can cancel each other out.
3. **Check Validity for East-West**: Similarly, we check if both East and West directions are either both present or both absent.
4. **Determine Result**: If both North-South and East-West pairs are valid, print "Yes". Otherwise, print "No".

This approach efficiently checks the necessary conditions using simple counts and logical checks, ensuring the solution is both optimal and easy to understand.
