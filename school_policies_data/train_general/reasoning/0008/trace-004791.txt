To solve this problem, we need to determine the minimum amount of money the king must distribute to ensure all citizens have equal welfare. The solution involves calculating the difference between the maximum welfare value and each citizen's welfare, then summing these differences.

### Approach
1. **Identify the Maximum Welfare**: The target welfare for all citizens is the maximum value in the given list since we can only add money and not take it away.
2. **Calculate Required Amount**: For each citizen, compute the difference between the maximum welfare and their current welfare. Sum these differences to get the total amount needed.

### Solution Code
```python
def main():
    n = int(input())
    a = list(map(int, input().split()))
    max_val = max(a)
    total = sum(max_val - x for x in a)
    print(total)

main()
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` (number of citizens) followed by a list of integers representing each citizen's welfare.
2. **Finding Maximum Welfare**: The maximum value in the list is identified as the target welfare for all citizens.
3. **Summing Differences**: For each citizen's welfare, the difference between the target welfare and their current welfare is calculated and summed up. This sum gives the minimum amount of money needed to equalize all citizens' welfare.

This approach ensures that we efficiently compute the required total by leveraging the maximum value and iterating through the list once, resulting in a time complexity of O(n), which is optimal for the given problem constraints.
