To solve this problem, we need to convert a given date in the Christian era to the corresponding Japanese era name. The input consists of multiple dates, each provided as three integers representing the year, month, and day. The output should be the era name followed by the year in that era, the month, and the day. If the date falls before the Meiji era, we should output "pre-meiji".

### Approach
1. **Understand the Era Periods**: The problem defines four eras with specific start and end dates:
   - Meiji: 1868-09-08 to 1912-07-29
   - Taisho: 1912-07-30 to 1926-12-24
   - Showa: 1926-12-25 to 1989-01-07
   - Heisei: 1989-01-08 onwards

2. **Check Order of Eras**: To efficiently determine the era for a given date, check the eras in reverse chronological order (from latest to earliest). This ensures that we check the most recent eras first.

3. **Date Comparison**: Convert each date into a tuple (year, month, day) for easy comparison. Check if the date falls within the start and end dates of each era.

4. **Calculate Era Year**: Once the era is determined, calculate the year within that era by subtracting the start year of the era from the input year and adding 1 (since the first year is considered "1 year").

5. **Handle Pre-Meiji Dates**: If the date does not fall into any of the defined eras and is before the start of the Meiji era, output "pre-meiji".

### Solution Code
```python
import sys

def convert_date(y, m, d):
    eras = [
        ('heisei', (1989, 1, 8), None),
        ('showa', (1926, 12, 25), (1989, 1, 7)),
        ('taisho', (1912, 7, 30), (1926, 12, 24)),
        ('meiji', (1868, 9, 8), (1912, 7, 29)),
    ]
    date = (y, m, d)
    for era in eras:
        name, start, end = era
        if end is None:
            if date >= start:
                era_year = y - start[0] + 1
                return f"{name} {era_year} {m} {d}"
        else:
            if start <= date <= end:
                era_year = y - start[0] + 1
                return f"{name} {era_year} {m} {d}"
    # Check if the date is before Meiji
    if date < (1868, 9, 8):
        return "pre-meiji"
    else:
        return "pre-meiji"

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        parts = line.split()
        if len(parts) != 3:
            continue
        try:
            y = int(parts[0])
            m = int(parts[1])
            d = int(parts[2])
        except ValueError:
            continue
        result = convert_date(y, m, d)
        print(result)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The `main` function reads each line from standard input, processes it, and prints the result for each date.
2. **Era Conversion**: The `convert_date` function checks each era in reverse chronological order. It uses tuple comparison to determine if the input date falls within the start and end dates of each era.
3. **Era Year Calculation**: For valid dates within an era, the year within that era is calculated by subtracting the start year of the era from the input year and adding 1.
4. **Pre-Meiji Check**: If the date does not match any era, it checks if the date is before the start of the Meiji era and returns "pre-meiji" if true.

This approach ensures efficient and accurate conversion of dates to the corresponding Japanese era names, handling all edge cases as specified.
