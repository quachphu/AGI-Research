To solve this problem, we need to determine the minimum total maintenance cost of bridges such that all cities in Water Deven remain connected. This is a classic problem that can be efficiently solved using the Minimum Spanning Tree (MST) algorithm. The MST connects all nodes (cities) with the minimum possible total edge weight (maintenance cost).

### Approach
1. **Input Handling**: Read multiple datasets until encountering two zeros. Each dataset starts with the number of cities (n) and the number of bridges (m), followed by m lines describing the bridges.
2. **Kruskal's Algorithm**: This algorithm is used to find the MST. It involves:
   - Sorting all bridges by their maintenance cost.
   - Using a Union-Find (Disjoint Set Union, DSU) data structure to efficiently manage and merge sets of connected cities.
3. **Union-Find Operations**: To keep track of connected components and ensure no cycles are formed while constructing the MST.
4. **Summing Costs**: Accumulate the maintenance costs of the bridges included in the MST, which ensures all cities are connected with the minimum cost.

### Solution Code
```python
class DSU:
    def __init__(self, size):
        self.parent = list(range(size))
        self.rank = [0] * size

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return False
        if self.rank[x_root] < self.rank[y_root]:
            self.parent[x_root] = y_root
        else:
            self.parent[y_root] = x_root
            if self.rank[x_root] == self.rank[y_root]:
                self.rank[x_root] += 1
        return True

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    while True:
        if ptr + 1 >= len(input):
            break
        n = int(input[ptr])
        m = int(input[ptr + 1])
        ptr += 2
        if n == 0 and m == 0:
            break
        edges = []
        for _ in range(m):
            a = int(input[ptr])
            b = int(input[ptr + 1])
            cost = int(input[ptr + 2])
            edges.append((cost, a, b))
            ptr += 3
        edges.sort()
        dsu = DSU(n)
        total = 0
        count = 0
        for cost, a, b in edges:
            if dsu.find(a) != dsu.find(b):
                dsu.union(a, b)
                total += cost
                count += 1
                if count == n - 1:
                    break
        print(total)

if __name__ == "__main__":
    main()
```

4. **Constructing MST**: Using the sorted edges, we iteratively add the cheapest bridge that connects two previously disconnected components until all cities are connected (n-1 edges).
5. **Output**: The total maintenance cost of the MST is printed for each dataset.

This approach ensures that the solution is both optimal and efficient, handling the constraints and providing the correct results for each dataset.
