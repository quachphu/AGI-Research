To solve this problem, we need to determine two specific words from a given text: the most frequently occurring word and the longest word. The solution must read a line of input, process it, and output the two words in the required format.

### Approach
1. **Reading Input**: The input text is read from standard input and stripped of any leading or trailing whitespace.
2. **Splitting Words**: The text is split into individual words using spaces as delimiters.
3. **Counting Frequencies**: A frequency dictionary is created to count how many times each word appears in the text.
4. **Finding the Most Frequent Word**: The word with the highest frequency is identified using the frequency dictionary.
5. **Finding the Longest Word**: The longest word is determined by comparing the lengths of all words in the text.
6. **Output**: The results are printed in the specified format.

### Solution Code
```python
from collections import Counter

def main():
    text = input().strip()
    words = text.split()
    freq = Counter(words)
    most_frequent = max(freq, key=lambda k: freq[k])
    longest_word = max(words, key=lambda x: len(x))
    print(f"{most_frequent} {longest_word}")

main()
```

### Explanation
1. **Reading Input**: The `input().strip()` method reads the input line and removes any leading/trailing spaces.
2. **Splitting Words**: The `split()` method splits the text into a list of words based on spaces.
3. **Counting Frequencies**: The `Counter` from the `collections` module efficiently counts the occurrences of each word.
4. **Most Frequent Word**: Using `max` with a key function that references the frequency count, we determine the word with the highest occurrence.
5. **Longest Word**: Again using `max` with a key function that checks the length of each word, we find the longest word in the list.
6. **Output**: The results are formatted into a string and printed as required.

This approach ensures that we efficiently and correctly identify the required words while adhering to the problem constraints. The use of built-in functions and data structures from Python's standard library helps keep the solution concise and efficient.
