To solve this problem, we need to count how many times the substring "ABC" appears in a given string S as contiguous subsequences. The solution involves iterating through the string and checking each triplet of consecutive characters to determine if they form the substring "ABC".

### Approach
1. **Input Reading**: Read the input values, which include the length of the string (N) and the string itself (S).
2. **Iterate Through Triplets**: Loop through the string from the start to the position where the triplet can still be formed (i.e., up to the third last character).
3. **Check for Substring**: For each position in the loop, check if the substring starting at that position and spanning the next three characters is "ABC".
4. **Count Occurrences**: Maintain a counter to keep track of how many times the substring "ABC" is found.

### Solution Code
```python
def count_abc():
    n = int(input())
    s = input().strip()
    count = 0
    for i in range(len(s) - 2):
        if s[i:i+3] == 'ABC':
            count += 1
    print(count)

count_abc()
```

### Explanation
1. **Reading Input**: The first input line is the integer N, which is the length of the string. The second line is the string S itself.
2. **Loop Through Triplets**: By iterating from the start of the string to the third last character (i.e., `len(s) - 2`), we ensure that we can form a triplet of characters each time.
3. **Check Substring**: For each index `i`, the substring `s[i:i+3]` is checked against "ABC". If it matches, the counter is incremented.
4. **Output Result**: Finally, the count of occurrences of "ABC" is printed.

This approach efficiently checks each possible contiguous triplet in the string, ensuring that all occurrences of "ABC" are counted accurately. The time complexity is O(N), where N is the length of the string, making it efficient for the given constraints.
