To solve this problem, we need to determine if countries can dispose of their missiles in such a way that the difference between the maximum and minimum war potential of any country never exceeds a given threshold, d, at any point during the disposal process. Each country must dispose of missiles in the order from oldest to newest.

### Approach
1. **Input Parsing and Initial Setup**: Read the number of countries and the threshold value, d. For each country, read the missile capabilities and reverse the order to get the disposal sequence from oldest to newest.
2. **Potential Calculation**: Precompute the potential (sum of remaining missiles) for each country after each disposal step.
3. **Breadth-First Search (BFS)**: Use BFS to explore all possible sequences of missile disposals. Each state in the BFS represents the number of missiles disposed by each country. Track visited states to avoid redundant processing.
4. **Validity Check**: For each state, check if the difference between the maximum and minimum potential across all countries is within the threshold d. If all missiles are disposed successfully while maintaining this condition, the answer is "Yes"; otherwise, it's "No".

### Solution Code
```python
import sys
from collections import deque

def main():
    input = sys.stdin.read().split()
    ptr = 0
    while True:
        n, d = int(input[ptr]), int(input[ptr+1])
        ptr +=2
        if n ==0 and d ==0:
            break
        countries = []
        for _ in range(n):
            m = int(input[ptr])
            ptr +=1
            missiles = list(map(int, input[ptr:ptr+m]))
            ptr +=m
            # Reverse the missiles to get disposal order (oldest first)
            missiles_reversed = missiles[::-1]
            # Compute potential after each step (0, 1, ..., m)
            potentials = [0]*(m+1)
            potentials[0] = sum(missiles)
            for i in range(m):
                potentials[i+1] = potentials[i] - missiles_reversed[i]
            countries.append(potentials)
        # BFS
        initial = tuple([0]*n)
        visited = set()
        q = deque()
        q.append(initial)
        visited.add(initial)
        found = False
        while q:
            state = q.popleft()
            # Compute current potentials
            potentials = [countries[i][state[i]] for i in range(n)]
            max_p = max(potentials)
            min_p = min(potentials)
            if max_p - min_p > d:
                continue
            # Check if all are at the end
            all_done = True
            for i in range(n):
                if state[i] < len(countries[i])-1:
                    all_done = False
                    break
            if all_done:
                found = True
                break
            # Generate next states
            for i in range(n):
                if state[i] < len(countries[i])-1:
                    next_state = list(state)
                    next_state[i] +=1
                    next_state_tuple = tuple(next_state)
                    if next_state_tuple not in visited:
                        visited.add(next_state_tuple)
                        q.append(next_state_tuple)
        print("Yes" if found else "No")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Input Parsing**: The input is read and parsed to extract the number of countries, the threshold d, and the missile capabilities for each country. The missile list is reversed to get the correct disposal order from oldest to newest.
2. **Potential Calculation**: For each country, we precompute the potential after each disposal step. This helps in quickly determining the war potential during the BFS.
3. **BFS Exploration**: Using BFS, we explore all possible sequences of missile disposals. Each state in the BFS represents the number of missiles disposed by each country. We check if moving to the next state (disposing the next missile) maintains the potential difference within d. If we reach a state where all missiles are disposed, we return "Yes".
4. **Validity Check**: For each state, we compute the current potentials and check if the maximum and minimum potentials are within the allowed difference. If any state violates this condition, it is skipped.

This approach ensures that we explore all valid paths efficiently using BFS, checking each state only once to avoid redundant computations.
