To solve this problem, we need to determine the palindromic characteristics of a given string. The k-th number in the characteristics represents the count of non-empty substrings that are k-palindromes. A k-palindrome is defined recursively, where a string is a k-palindrome if it is a palindrome (1-palindrome) and its left and right halves are (k-1)-palindromes.

### Approach
1. **Palindrome Table**: Precompute a 2D array to check if each substring is a palindrome.
2. **Hash Tables**: Use rolling hash techniques to efficiently compare substrings for equality.
3. **Dynamic Programming for k-palindromes**: Compute the maximum k for each substring using dynamic programming, leveraging the precomputed palindrome and hash tables.
4. **Count Accumulation**: For each substring, determine the maximum k it can achieve and update the counts for all k from 1 to this maximum value.

### Solution Code
```python
import sys

def main():
    s = sys.stdin.readline().strip()
    n = len(s)
    if n == 0:
        return
    
    # Precompute palindrome table
    pal = [[False] * n for _ in range(n)]
    for i in range(n-1, -1, -1):
        pal[i][i] = True
        if i < n-1:
            pal[i][i+1] = (s[i] == s[i+1])
        for j in range(i+2, n):
            pal[i][j] = (s[i] == s[j] and pal[i+1][j-1])
    
    # Precompute hash tables for quick substring equality checks
    base1 = 911382629
    mod1 = 10**18 + 3
    base2 = 3571428571
    mod2 = 10**18 + 7
    hash1 = [[0] * n for _ in range(n)]
    hash2 = [[0] * n for _ in range(n)]
    
    for i in range(n):
        current_hash1 = 0
        current_hash2 = 0
        for j in range(i, n):
            current_hash1 = (current_hash1 * base1 + (ord(s[j]) - ord('a') + 1)) % mod1
            current_hash2 = (current_hash2 * base2 + (ord(s[j]) - ord('a') + 1)) % mod2
            hash1[i][j] = current_hash1
            hash2[i][j] = current_hash2
    
    # Compute max_k for all substrings
    max_k = [[0] * n for _ in range(n)]
    for length in range(1, n+1):
        for i in range(n - length + 1):
            j = i + length - 1
            if not pal[i][j]:
                max_k[i][j] = 0
            else:
                if length == 1:
                    max_k[i][j] = 1
                else:
                    h = length // 2
                    left_i = i
                    left_j = i + h - 1
                    right_i = j - h + 1
                    right_j = j
                    # Check if left and right substrings are equal using both hash tables
                    if (hash1[left_i][left_j] == hash1[right_i][right_j] and
                        hash2[left_i][left_j] == hash2[right_i][right_j]):
                        min_val = min(max_k[left_i][left_j], max_k[right_i][right_j])
                        max_k[i][j] = 1 + min_val
                    else:
                        max_k[i][j] = 1
    
    # Accumulate counts for each k
    counts = [0] * (n + 1)  # counts[1..n]
    for i in range(n):
        for j in range(i, n):
            mk = max_k[i][j]
            if mk >= 1:
                for k in range(1, mk + 1):
                    counts[k] += 1
    
    # Prepare and print the output
    output = [str(counts[k]) for k in range(1, n+1)]
    print(' '.join(output))
```
