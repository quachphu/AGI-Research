To solve this problem, we need to compute the factorial of a given integer \( N \) where \( 1 \leq N \leq 100 \). The factorial of a number \( N \) is the product of all positive integers from 1 to \( N \). 

### Approach
The approach to solve this problem involves using an iterative method to compute the factorial. This method is efficient and straightforward, especially given the constraint that \( N \) can be as large as 100. Here's the step-by-step breakdown of the approach:

1. **Read Input**: Read the integer \( N \) from standard input.
2. **Initialize Result**: Start with a result initialized to 1, as the factorial of 1 is 1 and serves as the multiplicative identity.
3. **Iterate and Multiply**: Loop through each integer from 1 to \( N \) (inclusive), multiplying the current result by each integer in this range.
4. **Output Result**: Print the computed factorial result.

### Solution Code

```python
def factorial():
    n = int(input())
    result = 1
    for i in range(1, n + 1):
        result *= i
    print(result)

factorial()
```

### Explanation
1. **Reading Input**: The function reads an integer \( N \) from standard input using `input()` and converts it to an integer.
2. **Result Initialization**: The variable `result` is initialized to 1. This serves as the starting point for our multiplicative operations.
3. **Iterative Multiplication**: A loop runs from 1 to \( N \) (inclusive). In each iteration, the current value of `result` is multiplied by the loop variable `i`, effectively computing the product of all integers from 1 to \( N \).
4. **Printing the Result**: After the loop completes, the computed factorial value stored in `result` is printed.

This approach ensures that we efficiently compute the factorial using a simple loop, which is both time and space efficient for the given constraints.
