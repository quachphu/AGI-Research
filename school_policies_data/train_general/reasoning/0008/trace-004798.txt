To solve this problem, we need to find the minimum path sum from any cell in the leftmost column to any cell in the rightmost column of an n x n grid. The path can move in any direction (up, down, left, right) but must start in the leftmost column and end in the rightmost column.

### Approach
The problem can be efficiently solved using Dijkstra's algorithm, which is well-suited for finding the shortest path in a graph with non-negative weights. Here, each cell in the grid is treated as a node, and edges exist between adjacent cells (up, down, left, right). The weight of moving to a cell is the value of that cell. 

Key steps in the approach:
1. **Initialization**: Start by initializing the minimum path sum (distance) to all cells as infinity, except for the cells in the leftmost column, which are initialized to their own values.
2. **Priority Queue**: Use a priority queue (min-heap) to process cells in order of their current minimum path sum. This ensures that we always expand the shortest known path first.
3. **Processing Cells**: For each cell processed, check its neighbors. If moving to a neighbor results in a shorter path, update the neighbor's path sum and push it into the priority queue.
4. **Early Termination**: As soon as a cell in the rightmost column is processed, we can immediately return the minimum path sum found, as Dijkstra's algorithm guarantees the shortest path once a node is processed.

### Solution Code
```python
import heapq

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    grid = []
    for _ in range(n):
        row = list(map(int, input[idx:idx + n]))
        grid.append(row)
        idx += n
    
    INF = float('inf')
    dist = [[INF] * n for _ in range(n)]
    heap = []
    
    # Initialize the first column
    for i in range(n):
        dist[i][0] = grid[i][0]
        heapq.heappush(heap, (dist[i][0], i, 0))
    
    # Directions: up, down, left, right
    dirs = [(-1, 0), (1, 0), (0, -1), (0, 1)]
    
    while heap:
        current_sum, i, j = heapq.heappop(heap)
        # Check if we've reached the last column
        if j == n - 1:
            print(current_sum)
            return
        # Skip if a shorter path to this cell was already found
        if current_sum > dist[i][j]:
            continue
        # Explore all four directions
        for dx, dy in dirs:
            x = i + dx
            y = j + dy
            if 0 <= x < n and 0 <= y < n:
                new_sum = current_sum + grid[x][y]
                if new_sum < dist[x][y]:
                    dist[x][y] = new_sum
                    heapq.heappush(heap, (new_sum, x, y))
    
    # If all paths are processed and no last column found (shouldn't happen per problem statement)
    min_result = min(dist[i][n-1] for i in range(n))
    print(min_result)

if __name__ == "__main__":
    main()
```

3. **Priority Queue Initialization**: The priority queue is initialized with all cells from the first column.
4. **Processing with Dijkstra's Algorithm**: The algorithm processes each cell by popping the cell with the smallest current path sum from the heap. 5. **Early Termination**: The algorithm checks if the current cell is in the rightmost column and immediately returns the path sum if it is, ensuring the shortest path is found efficiently.

This approach ensures that we efficiently find the shortest path using Dijkstra's algorithm, which is optimal for this problem due to its ability to handle grids with non-negative weights and provide the shortest path in logarithmic time relative to the number of cells processed.
