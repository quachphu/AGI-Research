To solve this problem, we need to determine the number of shuffle sequences that result in the original sorted permutation after applying a series of moves where each move consists of selecting a number and moving it to the front. The solution involves understanding the combinatorial structure of these sequences and efficiently computing the result using modular arithmetic to handle large numbers.

### Approach
The key insight is that the number of valid shuffle sequences for a permutation of length `n` is equivalent to `n!` (n factorial). This is because each element must be moved to the front in a specific order such that the cumulative effect of all moves restores the original permutation. 

To handle large values of `n` efficiently and avoid overflow, we precompute the factorials modulo `10^9 + 7` up to the maximum possible value of `n` (which is 1000 in this problem). This precomputation allows us to answer each test case in constant time.

### Solution Code
```python
MOD = 10**9 + 7
MAX_N = 1000

# Precompute factorials modulo MOD up to MAX_N
factorial = [1] * (MAX_N + 1)
for i in range(1, MAX_N + 1):
    factorial[i] = (factorial[i-1] * i) % MOD

t = int(input())
for _ in range(t):
    n = int(input())
    print(factorial[n])
```

### Explanation
1. **Precomputation**: We precompute the factorial values modulo `10^9 + 7` for all values from 0 to 1000. This allows us to quickly answer each test case in constant time.
2. **Modular Arithmetic**: Using modular arithmetic ensures that we handle large numbers efficiently and prevent overflow.
3. **Efficient Query Handling**: For each test case, we simply look up the precomputed factorial value for the given `n` and return it.

This approach leverages precomputation and modular arithmetic to efficiently solve the problem within the constraints, ensuring optimal performance even for the upper limits of input size.
