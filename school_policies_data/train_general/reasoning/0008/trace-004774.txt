To solve this problem, we need to determine the minimum total pairwise distance between three friends after each friend has moved optimally for one minute. Each friend can move at most one unit left, right, or stay in place. The goal is to minimize the sum of the distances between each pair of friends after their movements.

### Approach
1. **Problem Analysis**:
   - Each friend can move to positions within ±1 of their current position.
   - The total pairwise distance can be simplified to twice the range (difference between the maximum and minimum positions of the three friends) after their movements.
   - The key insight is that the minimum possible range after optimal movements can be determined by analyzing the intervals each friend can move into.

2. **Key Insight**:
   - For each friend, define their possible movement interval as [current position - 1, current position + 1].
   - Calculate the maximum of the lower bounds (max_low) of these intervals and the minimum of the upper bounds (min_high).
   - If these intervals overlap (i.e., max_low ≤ min_high), the minimum range is 0. Otherwise, the minimum range is the difference between max_low and min_high.

3. **Algorithm**:
   - For each test case, compute the intervals for each friend.
   - Determine max_low and min_high from these intervals.
   - Calculate the result as twice the maximum of 0 or the difference between max_low and min_high.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    q = int(input[0])
    idx = 1
    for _ in range(q):
        a = int(input[idx])
        b = int(input[idx + 1])
        c = int(input[idx + 2])
        idx += 3
        a_low = a - 1
        a_high = a + 1
        b_low = b - 1
        b_high = b + 1
        c_low = c - 1
        c_high = c + 1
        max_low = max(a_low, b_low, c_low)
        min_high = min(a_high, b_high, c_high)
        range_val = max(0, max_low - min_high)
        print(2 * range_val)

solve()
```

### Explanation
- **Reading Input**: The input is read all at once and split into a list of strings for efficient processing.
- **Processing Each Test Case**:
  - For each friend, compute their possible movement interval.
  - Determine the maximum lower bound (max_low) and the minimum upper bound (min_high) of these intervals.
  - Calculate the range as the difference between max_low and min_high. If max_low is greater than min_high, the range is their difference; otherwise, the range is 0.
  - The result is twice this range, as the total pairwise distance is twice the range of the positions.

This approach efficiently computes the minimum total pairwise distance in constant time for each test case, ensuring optimal performance even for the upper constraint limits.
