To solve this problem, we need to determine if Sherlock Holmes can partition the given items into two subsets such that the sum of the costs in each subset is equal. This is a classic partition problem which can be efficiently solved using dynamic programming.

### Approach
1. **Sum Check**: First, check if the total sum of the item costs is even. If it is odd, partitioning into two equal subsets is impossible, so we immediately return "NO".
2. **Dynamic Programming (DP)**: If the sum is even, we use a DP array to track achievable sums. The goal is to determine if a subset of the items can sum up to half of the total sum (target sum).

### Solution Code
```python
def can_partition(costs):
    total = sum(costs)
    if total % 2 != 0:
        return False
    target = total // 2
    dp = [False] * (target + 1)
    dp[0] = True
    for cost in costs:
        for j in range(target, cost - 1, -1):
            if dp[j - cost]:
                dp[j] = True
    return dp[target]

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        costs = list(map(int, input[ptr:ptr + N]))
        ptr += N
        print("YES" if can_partition(costs) else "NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings for easier processing.
2. **Sum Check**: For each test case, we first check if the total sum of the costs is even. If not, output "NO".
3. **Dynamic Programming Setup**: We initialize a boolean array `dp` where `dp[i]` indicates if a subset of the items can sum up to `i`.
4. **Updating DP Array**: For each cost, we update the DP array from the back (from the target sum down to the cost) to avoid reusing the same item multiple times.
5. **Result Check**: After processing all items, if the target sum (half of the total sum) is achievable, output "YES"; otherwise, output "NO".

This approach efficiently checks for the possibility of partitioning using dynamic programming, ensuring optimal performance even for the upper constraint limits.
