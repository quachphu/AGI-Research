To solve this problem, we need to translate sentences from Bytelandian to English using a given permutation of the English alphabet. The translation involves converting each Bytelandian character to its corresponding English character, handling uppercase and lowercase letters appropriately, converting underscores to spaces, and leaving punctuation unchanged.

### Approach
1. **Input Reading**: Read the first line to get the number of sentences (T) and the permutation string (M) which maps Bytelandian characters to English.
2. **Mapping Creation**: Construct a dictionary that maps each Bytelandian character (a-z) to its corresponding English character using the permutation string M.
3. **Translation Process**:
   - For each character in the input sentence:
     - Replace underscores with spaces.
     - Leave punctuation marks (.,!?) unchanged.
     - Convert lowercase Bytelandian letters using the mapping.
     - Convert uppercase Bytelandian letters by first converting them to lowercase, mapping them, and then converting the result back to uppercase.
4. **Output the Result**: Print each translated sentence line by line.

### Solution Code
```python
def main():
    import sys
    input_lines = sys.stdin.read().splitlines()
    first_line = input_lines[0].strip().split()
    T = int(first_line[0])
    M = first_line[1]
    
    # Create the mapping from Bytelandian to English
    mapping = {chr(ord('a') + i): M[i] for i in range(26)}
    punctuation = {'.', ',', '!', '?'}
    
    # Process each of the next T lines
    for line in input_lines[1:T+1]:
        translated = []
        for c in line.strip():
            if c == '_':
                translated.append(' ')
            elif c in punctuation:
                translated.append(c)
            else:
                if c.islower():
                    translated.append(mapping[c])
                else:
                    lower_c = c.lower()
                    translated_char = mapping[lower_c]
                    translated.append(translated_char.upper())
        print(''.join(translated))
        
if __name__ == "__main__":
    main()
```

### Explanation
- **Input Handling**: The first line is split into T and M. The subsequent lines are the sentences to be translated.
- **Mapping Creation**: The permutation string M is used to create a dictionary that maps each Bytelandian character to its English counterpart.
- **Character Translation**: Each character in the input sentences is checked and translated based on its type (underscore, punctuation, lowercase, uppercase).
- **Efficiency**: The solution efficiently processes each character in linear time relative to the length of the input sentences, ensuring it meets the problem constraints effectively.

This approach ensures that each character is translated correctly while maintaining the required case and punctuation handling.
