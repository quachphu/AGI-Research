To solve this problem, we need to determine the maximum possible score that can be displayed by the examination system, considering the constraint that if the total score is a multiple of 10, the system displays 0. 

### Approach
1. **Calculate Total Score**: First, compute the sum of all given scores.
2. **Check Divisibility by 10**: If the total score is not a multiple of 10, it is the answer.
3. **Handle Multiples of 10**: If the total score is a multiple of 10, we need to adjust it to the next possible maximum value that is not a multiple of 10. This is done by finding the smallest score that is not a multiple of 10 and subtracting it from the total. If all scores are multiples of 10, the result will be 0.

### Solution Code
```python
n = int(input())
scores = [int(input()) for _ in range(n)]
total = sum(scores)

if total % 10 != 0:
    print(total)
else:
    non_divisible = [s for s in scores if s % 10 != 0]
    if not non_divisible:
        print(0)
    else:
        min_non_div = min(non_divisible)
        print(total - min_non_div)
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` followed by `n` integers representing the scores of each question.
2. **Total Score Calculation**: The total score is computed by summing all the given scores.
3. **Check for Non-divisibility by 10**: If the total score is not divisible by 10, it is printed directly.
4. **Adjusting for Divisibility**: If the total score is divisible by 10, we check for the smallest score that is not a multiple of 10. Subtracting this smallest non-divisible score from the total gives the maximum possible score that is not a multiple of 10. If all scores are multiples of 10, the result is 0.

This approach ensures that we efficiently find the optimal solution by leveraging the properties of divisibility and minimal subtraction to adjust the total score appropriately.
