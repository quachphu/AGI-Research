To solve this problem, we need to determine the frequency of each query value in the multiset C, which is formed by summing each element from set A (1 to N) with each element from set B (N+1 to 2N). The solution involves calculating the valid range of elements from set A that can form the query value when summed with elements from set B.

### Approach
1. **Understanding the Range of Sums**: The possible sums of elements from sets A and B range from N+2 (1 + (N+1)) to 3N (N + 2N). Any query outside this range will have a count of zero.
2. **Valid Element Range in Set A**: For each valid query value q, determine the valid range of elements in set A that can form q when summed with elements from set B. This range is derived from the constraints that the elements in set B must be between N+1 and 2N.
3. **Mathematical Formulation**: For each query q, compute the minimum and maximum values of a (from set A) that satisfy the equation a + b = q, where b is in set B. This gives the valid range for a as [max(1, q - 2N), min(N, q - (N+1))].
4. **Count Calculation**: The count of valid elements in set A is the number of integers in the valid range. If the range is invalid (min > max), the count is zero.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    M = int(input[idx])
    idx += 1
    for _ in range(M):
        q = int(input[idx])
        idx += 1
        if q < (N + 2) or q > 3 * N:
            print(0)
        else:
            a_min = max(1, q - 2 * N)
            a_max = min(N, q - (N + 1))
            if a_max < a_min:
                print(0)
            else:
                print(a_max - a_min + 1)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
- **Range Check**: For each query, we first check if it falls within the valid range of sums (N+2 to 3N). If not, the count is zero.
- **Range Calculation**: For valid queries, compute the minimum (a_min) and maximum (a_max) valid indices in set A that can form the query value when summed with elements from set B.
- **Count Calculation**: The count is derived from the valid range [a_min, a_max]. If the range is valid (a_min ≤ a_max), the count is the number of integers in this range, otherwise, it is zero.

This approach ensures that each query is processed in constant time, making the solution efficient even for large values of N and M.
