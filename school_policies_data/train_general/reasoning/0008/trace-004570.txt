To solve this problem, we need to maximize the number of potions we can drink while ensuring that our health never drops below zero. The solution involves a greedy approach combined with a priority queue (min-heap) to efficiently manage the potions we have consumed, allowing us to replace the worst choices when beneficial.

### Approach
1. **Greedy Strategy**: Always take positive potions as they increase health, making it easier to take more potions later.
2. **Handling Negative Potions**: For negative potions, check if taking them directly keeps health non-negative. If not, consider replacing the most negative potion taken so far (using a min-heap) with the current one if it is less detrimental. This ensures we maintain the highest possible health to maximize future potion intake.

### Solution Code
```python
import heapq

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    
    heap = []
    current_sum = 0
    
    for num in a:
        if num >= 0:
            current_sum += num
            heapq.heappush(heap, num)
        else:
            if current_sum + num >= 0:
                current_sum += num
                heapq.heappush(heap, num)
            else:
                if heap and num > heap[0]:
                    removed = heapq.heappop(heap)
                    current_sum += (num - removed)
                    heapq.heappush(heap, num)
    print(len(heap))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of potions `n` and the list of health changes `a`.
2. **Initialization**: A min-heap is used to track the potions taken, and `current_sum` keeps track of the current health.
3. **Processing Each Potion**:
   - **Positive Potions**: Directly add to health and push into the heap.
   - **Negative Potions**: Check if taking the potion keeps health non-negative. If yes, add to health and heap. If not, check if replacing the most negative potion (heap's top) with the current one improves health. If so, replace and adjust health accordingly.
4. **Result**: The size of the heap gives the maximum number of potions that can be taken without health dropping below zero.

This approach efficiently balances between taking beneficial potions and replacing detrimental ones using a min-heap, ensuring an optimal solution in O(n log n) time complexity.
