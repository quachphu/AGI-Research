To solve this problem, we need to determine if a given 6-character string meets specific conditions that classify it as "coffee-like". The string must have its 3rd and 4th characters equal, and its 5th and 6th characters equal.

### Approach
1. **Input Handling**: Read the input string from standard input.
2. **Character Comparison**: Check the equality of the 3rd and 4th characters (indices 2 and 3 in Python) and the 5th and 6th characters (indices 4 and 5 in Python).
3. **Output Result**: Print "Yes" if both conditions are satisfied, otherwise print "No".

### Solution Code
```python
def main():
    S = input().strip()
    if S[2] == S[3] and S[4] == S[5]:
        print("Yes")
    else:
        print("No")

main()
```

### Explanation
1. **Reading Input**: The input string is read and any leading/trailing whitespace is removed using `strip()`, though the problem guarantees a valid 6-character input.
2. **Checking Conditions**: The code checks if the 3rd and 4th characters (indices 2 and 3) are the same, and if the 5th and 6th characters (indices 4 and 5) are the same.
3. **Output**: Based on the checks, the appropriate result ("Yes" or "No") is printed.

This approach efficiently checks the required conditions in constant time, ensuring optimal performance.
