To solve this problem, we need to simulate Maxim's process of buying games using the bills in his wallet. The goal is to determine how many games he can successfully purchase given the constraints.

### Approach
1. **Input Reading**: Read the number of games and bills, followed by the costs of the games and the values of the bills.
2. **Queue Initialization**: Use a deque to represent Maxim's wallet, allowing efficient removal of the first element (bill).
3. **Simulate the Purchase Process**: For each game in order, check the first bill in the wallet. If the bill's value is sufficient to buy the game, remove the bill from the wallet and increment the count of purchased games. If not, proceed to the next game without removing the bill.
4. **Output the Result**: After processing all games, print the total number of games purchased.

### Solution Code
```python
import sys
from collections import deque

def main():
    n, m = map(int, sys.stdin.readline().split())
    c = list(map(int, sys.stdin.readline().split()))
    a = list(map(int, sys.stdin.readline().split()))
    
    q = deque(a)
    count = 0
    for cost in c:
        if q and q[0] >= cost:
            q.popleft()
            count += 1
    print(count)

main()
```

### Explanation
1. **Reading Input**: The input is read using standard input functions. The first line contains the number of games `n` and bills `m`. The next two lines contain the costs of the games and the values of the bills respectively.
2. **Queue for Bills**: The bills are stored in a deque to efficiently manage the order of bills and remove the front element when a purchase is made.
3. **Processing Each Game**: For each game's cost, check if the first bill in the deque is sufficient. If yes, the bill is removed (purchased), and the count is incremented. If not, the bill remains, and the next game is checked.
4. **Result**: After iterating through all games, the count of successfully purchased games is printed.

This approach ensures that we efficiently check each game in order and manage the bills using a deque, which allows O(1) time complexity for both checking the front element and removing it. This results in an overall time complexity of O(n), where n is the number of games, making the solution efficient and suitable for the problem constraints.
