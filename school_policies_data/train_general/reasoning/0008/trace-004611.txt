To solve this problem, we need to determine the number of distinct values in a given sequence of integers. The solution involves efficiently reading the input, processing the data to identify unique values, and then outputting the count of these unique values.

### Approach
1. **Reading Input**: The input consists of two lines. The first line contains an integer \( N \), which is the number of elements in the sequence. The second line contains \( N \) integers separated by spaces.
2. **Processing Data**: Convert the list of integers into a set to automatically remove duplicates, as sets in Python do not allow duplicate values.
3. **Counting Unique Values**: The length of the set, which now contains only unique values, gives the number of distinct values in the sequence.

This approach leverages Python's built-in data structures for efficient duplicate removal and counting. The time complexity of converting a list to a set is \( O(N) \), which is optimal for the given constraints.

### Solution Code
```python
def count_unique():
    n = int(input())
    nums = list(map(int, input().split()))
    print(len(set(nums)))

count_unique()
```

### Explanation
1. **Reading Input**: The function reads the integer \( N \) from the first line and then reads the sequence of integers from the second line.
2. **Removing Duplicates**: By converting the list of integers to a set, all duplicate values are removed, leaving only unique values.
3. **Output the Result**: The length of the set, which is the number of unique values, is printed as the result.

This method efficiently handles the constraints, ensuring that even for the upper limit of \( N = 10^5 \), the solution runs in linear time, making it both optimal and straightforward.
