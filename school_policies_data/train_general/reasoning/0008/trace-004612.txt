To solve this problem, we need to multiply two very large integers given as strings. The integers can be up to 200,000 digits long, which makes direct conversion to standard integer types impractical. However, Python's native support for arbitrary-precision integers allows us to handle such large numbers efficiently.

### Approach
1. **Check for Zero**: If either input number is zero, the product is zero.
2. **Determine the Sign**: The product's sign is negative if one number is negative and the other is positive; otherwise, it is positive.
3. **Convert to Absolute Values**: Remove any leading signs to handle the numbers as their absolute values.
4. **Multiply Using Python's Arbitrary-Precision**: Convert the cleaned string representations to Python integers and multiply them.
5. **Adjust the Sign**: Apply the determined sign to the product and print the result.

### Solution Code
```python
a, b = input().split()

if a == '0' or b == '0':
    print(0)
else:
    # Determine the sign of the product
    sign = -1 if (a[0] == '-') ^ (b[0] == '-') else 1
    
    # Remove signs and leading zeros (though input has no leading zeros per problem statement)
    a_abs = a.lstrip('-')
    b_abs = b.lstrip('-')
    
    # Convert to integers and multiply
    num_a = int(a_abs)
    num_b = int(b_abs)
    product = num_a * num_b
    
    # Apply the sign
    if sign == -1:
        product = -product
    
    print(product)
```

### Explanation
1. **Handling Zero**: The code first checks if either input is zero, immediately returning zero in such cases.
2. **Sign Determination**: Using XOR on the presence of a negative sign in the inputs, the code determines if the product should be negative.
3. **String Cleaning**: The input strings are stripped of any leading negative signs to work with their absolute values.
4. **Conversion and Multiplication**: Python's native integer conversion and multiplication handle the large numbers efficiently, leveraging Python's optimized arbitrary-precision arithmetic.
5. **Sign Adjustment**: The product is adjusted to the correct sign based on the earlier determination and printed.

This approach efficiently handles the constraints using Python's built-in capabilities, ensuring correct results even for extremely large numbers.
