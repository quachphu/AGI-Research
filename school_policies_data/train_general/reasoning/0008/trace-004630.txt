To solve this problem, the Little Elephant needs to find the town with the minimum travel time from Rozdil. If there are multiple towns with the same minimum travel time, he will stay in Rozdil instead.

### Approach
1. **Read Input**: First, read the number of towns and their respective travel times.
2. **Find Minimum Time**: Determine the minimum travel time from the list of times.
3. **Check Uniqueness**: Count how many times this minimum travel time occurs in the list.
4. **Determine Result**: If the minimum time occurs exactly once, output the 1-based index of this town. If it occurs more than once, output "Still Rozdil".

### Solution Code
```python
def main():
    import sys
    n = int(sys.stdin.readline())
    times = list(map(int, sys.stdin.readline().split()))
    min_time = min(times)
    count = times.count(min_time)
    if count == 1:
        print(times.index(min_time) + 1)
    else:
        print("Still Rozdil")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using standard input functions. The first line gives the number of towns, and the second line provides the travel times for each town.
2. **Finding Minimum Time**: The minimum travel time is found using the `min` function.
3. **Checking Uniqueness**: The `count` method is used to determine how many times the minimum time appears in the list.
4. **Result Determination**: If the minimum time appears exactly once, the index of this time (converted to 1-based indexing) is printed. If it appears multiple times, "Still Rozdil" is printed instead.

This approach ensures that the solution efficiently handles the constraints with a time complexity of O(n), making it suitable even for the upper limit of input size.
