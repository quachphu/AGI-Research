To solve this problem, we need to determine the maximum points Harry can collect from judges such that no two adjacent judges are selected. This problem is analogous to the classic House Robber problem, where dynamic programming is used to efficiently compute the solution.

### Approach
1. **Problem Analysis**: The problem requires us to select judges in such a way that no two consecutive judges are chosen. The goal is to maximize the sum of points from the selected judges.
2. **Dynamic Programming Insight**: We can use a dynamic programming approach where we maintain two variables to keep track of the maximum points that can be collected up to the previous and the previous-to-previous judge. This allows us to compute the maximum points for the current judge efficiently.
3. **Optimal Substructure**: For each judge, the maximum points that can be collected up to that judge is the maximum of either including the current judge's points plus the maximum points up to two judges before, or excluding the current judge and taking the maximum points up to the previous judge.
4. **Edge Cases**: Handle cases where there are no judges or only one judge separately.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split('\n')
    idx = 0
    T = int(input[idx])
    idx += 1
    for case in range(1, T + 1):
        N = int(input[idx])
        idx += 1
        points = list(map(int, input[idx].split()))
        idx += 1
        prev_prev = 0
        prev = 0
        for num in points:
            new_prev = max(prev, prev_prev + num)
            prev_prev, prev = prev, new_prev
        print(f"Case {case}: {prev}")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into lines for efficient processing.
2. **Initialization**: For each test case, we initialize two variables, `prev_prev` and `prev`, to keep track of the maximum points collected up to two judges before and the previous judge, respectively.
3. **Dynamic Programming Loop**: For each judge's points, we compute the new maximum points considering either including the current judge (adding their points to `prev_prev`) or excluding them (taking `prev`). We then update our tracking variables.
4. **Output**: After processing all judges for a test case, we print the result in the required format.

This approach ensures that we efficiently compute the maximum points using constant space, making it suitable for large inputs up to the constraint limits.
