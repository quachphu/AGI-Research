To solve this problem, we need to determine the number of ways an ant can return to its starting vertex D of a tetrahedron after exactly n steps. Each step must move to a different vertex along an edge. The result should be computed modulo \(10^9 + 7\).

### Approach
The problem can be efficiently solved using dynamic programming with a focus on optimizing space and time complexity. The key insight is to recognize the symmetry in the tetrahedron structure, which allows us to reduce the problem to tracking two states:
1. `a_n`: The number of ways to be at vertex D after `n` steps.
2. `c_n`: The number of ways to be at any of the other three vertices (A, B, C) after `n` steps.

The recurrence relations derived from the problem's symmetry are:
- `a_n = 3 * c_{n-1}` (since from each of the three vertices A, B, or C, there is exactly one way to move to D)
- `c_n = a_{n-1} + 2 * c_{n-1}` (since from D, there is one way to each of the three other vertices, and from any other vertex, there are two ways to move to another non-D vertex)

Using these relations, we can compute the result iteratively in O(n) time with O(1) space complexity.

### Solution Code
```python
MOD = 10**9 + 7

n = int(input())

if n == 0:
    print(1)
else:
    a_prev, c_prev = 1, 0
    for _ in range(n):
        a_current = (3 * c_prev) % MOD
        c_current = (a_prev + 2 * c_prev) % MOD
        a_prev, c_prev = a_current, c_current
    print(a_prev % MOD)
```

### Explanation
1. **Initialization**: Start with `a_prev = 1` (the ant starts at D) and `c_prev = 0` (no steps taken yet, so no other vertices are visited).
2. **Iteration**: For each step from 1 to `n`, update `a_current` and `c_current` using the recurrence relations. This ensures we track the number of ways to be at D or any other vertex after each step.
3. **Modulo Operation**: Use modulo \(10^9 + 7\) to prevent integer overflow and keep the numbers manageable.

This approach efficiently computes the result in linear time, making it feasible even for the upper constraint of \(n = 10^7\).
