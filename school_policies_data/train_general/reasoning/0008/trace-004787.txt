To solve this problem, we need to determine the minimum number of minutes of a movie you have to watch in order to cover all the best moments, given that you can either watch the current minute or skip a fixed number of minutes using two buttons on your player.

### Approach
1. **Understand the Problem**: The movie player starts at minute 1, and you need to watch all specified intervals of best moments. You can either watch each minute sequentially or skip a fixed number of minutes. The goal is to minimize the total watched minutes by using skips optimally between the intervals.

2. **Gaps Between Intervals**: The intervals are non-overlapping and ordered. The gaps between the end of one interval and the start of the next (or from the start of the movie to the first interval) can be navigated using skips and watches. The optimal strategy is to skip as much as possible using the fixed skip value and then watch the remaining minutes if necessary.

3. **Mathematical Insight**: For each gap, compute the number of minutes you can skip using the fixed skip value. The remaining minutes after maximum skips are the minutes you must watch. This is calculated using the modulus operation.

4. **Algorithm**:
   - Initialize the current time to 1 and the total watched minutes to 0.
   - For each interval, calculate the gap from the current time to the start of the interval.
   - Use skips as much as possible and add the remaining minutes (if any) to the total watched minutes.
   - Add the duration of the current interval to the total watched minutes and update the current time to the end of the interval plus one.

### Solution Code
```python
n, x = map(int, input().split())
intervals = [tuple(map(int, input().split())) for _ in range(n)]

current_time = 1
total = 0

for li, ri in intervals:
    gap = li - current_time
    if gap > 0:
        total += gap % x
    total += ri - li + 1
    current_time = ri + 1

print(total)
```

### Explanation
- **Reading Input**: The first line reads the number of intervals and the skip value. Subsequent lines read the start and end of each interval.
- **Processing Each Interval**: For each interval, compute the gap from the current time to the start of the interval. Use the modulus operation to determine the remaining minutes after maximum skips. Add these remaining minutes and the duration of the interval to the total watched minutes.
- **Update Current Time**: After processing each interval, update the current time to the end of the interval plus one to start processing the next interval from the correct position.

This approach ensures that we minimize the watched minutes by efficiently using skips between intervals and only watching necessary minutes within the intervals.
