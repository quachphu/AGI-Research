To solve this problem, we need to determine if a given number is part of the Fibonacci sequence. The solution involves precomputing all Fibonacci numbers up to the maximum possible value (100,000) and then efficiently checking each input number against this precomputed set.

### Approach
1. **Precompute Fibonacci Numbers**: Generate all Fibonacci numbers up to 100,000 and store them in a set for O(1) lookups.
2. **Read Input Efficiently**: Read all input at once to handle up to 10,000 test cases efficiently.
3. **Check Each Number**: For each test case, check if the number is in the precomputed set of Fibonacci numbers and print the result accordingly.

### Solution Code
```python
import sys

def main():
    max_limit = 100000
    fib_set = set()
    a, b = 0, 1
    fib_set.add(a)
    fib_set.add(b)
    while True:
        c = a + b
        if c > max_limit:
            break
        fib_set.add(c)
        a, b = b, c
    
    input_data = sys.stdin.read().split()
    T = int(input_data[0])
    for n_str in input_data[1:T+1]:
        n = int(n_str)
        print("Yes" if n in fib_set else "No")

main()
```

### Explanation
1. **Precompute Fibonacci Numbers**: We start with the first two Fibonacci numbers (0 and 1). Using a loop, we generate subsequent Fibonacci numbers until the next number exceeds 100,000. Each generated number is added to a set for quick lookup.
2. **Efficient Input Handling**: The input is read all at once and split into a list of strings. This approach minimizes I/O operations, which is crucial for handling a large number of test cases efficiently.
3. **Check Membership**: For each test case, we convert the input string to an integer and check if it exists in the precomputed set of Fibonacci numbers. The result is printed immediately, ensuring minimal overhead.

This approach ensures that each test case is processed in constant time after the initial precomputation, making the solution both efficient and scalable for large inputs.
