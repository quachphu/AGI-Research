### Approach
1. **Understanding the Criteria**: Anton's performance is good if he outscored any participant who:
   - Had a red handle before the contest (rating >= 2400).
   - Increased their rating after the contest (after rating > before rating).

2. **Input Handling**: Read the number of participants Anton outscored and then process each participant's data to check the criteria.

3. **Check Conditions**: For each participant, check if their rating before the contest was at least 2400 (red handle) and if their rating after the contest is higher than before.

4. **Result Determination**: If any participant meets both conditions, print "YES". Otherwise, print "NO".

### Solution Code
```python
n = int(input())
found = False

    parts = input().split()
    name = parts[0]

    if before >= 2400 and after > before:
```

- **Reading Input**: The first input line gives the number of participants Anton outscored. Each subsequent line provides a participant's handle, their rating before the contest, and their rating after the contest.
- **Condition Check**: For each participant, we check if their pre-contest rating was 2400 or higher (indicating a red handle) and if their post-contest rating is higher than their pre-contest rating.
- **Result**: If any participant meets both conditions, we immediately determine Anton's performance as good ("YES"). If none meet the criteria, the result is "NO".
