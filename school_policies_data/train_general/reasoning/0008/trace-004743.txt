To solve this problem, we need to determine the smallest number of points to add on a straight line so that the distances between all neighboring points are equal. 

### Approach
1. **Sort the Points**: First, we sort the given points to arrange them in ascending order. This helps in calculating the gaps between consecutive points.
2. **Compute Differences**: Calculate the differences between each consecutive pair of points after sorting.
3. **Find the Greatest Common Divisor (GCD)**: The GCD of all these differences will determine the maximum possible interval that can evenly divide all gaps. This ensures that the minimal number of points are added.
4. **Calculate Points to Add**: For each gap, the number of points needed to make the interval equal to the GCD is computed. Sum these values to get the total points required.

### Solution Code
```python
import math

def main():
    n = int(input())
    x = list(map(int, input().split()))
    x.sort()
    
    if n < 2:
        print(0)
        return
    
    differences = []
    for i in range(1, n):
        differences.append(x[i] - x[i-1])
    
    current_gcd = differences[0]
    for d in differences[1:]:
        current_gcd = math.gcd(current_gcd, d)
        if current_gcd == 1:
            break
    
    total = 0
    for d in differences:
        total += (d // current_gcd) - 1
    
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Sorting the Points**: Sorting ensures that we can compute consecutive gaps in a straightforward manner.
2. **Calculating Differences**: The differences between consecutive sorted points give us the gaps that need to be adjusted.
3. **Finding GCD**: The GCD of all gaps is the largest interval that can divide each gap. This interval minimizes the number of points added.
4. **Summing Required Points**: For each gap, the number of points needed is the gap divided by the GCD minus one (since the interval itself counts as a segment, not a point).

This approach efficiently computes the minimal points needed using sorting and GCD calculation, ensuring optimal performance even for large input sizes.
