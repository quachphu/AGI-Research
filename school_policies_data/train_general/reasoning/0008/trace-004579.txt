To solve this problem, we need to determine on which days road works will be in progress based on the given schedule. The workers will only asphalt both roads at an intersection if neither of the roads forming the intersection has been asphalted before. 

### Approach
1. **Initialization**: We start by reading the input values, which include the number of roads (n) and the schedule of intersections to be processed.
2. **Tracking Asphalted Roads**: We use two sets to keep track of the horizontal and vertical roads that have been asphalted.
3. **Processing Each Day**: For each day in the schedule, we check if both the horizontal and vertical roads at the given intersection are un-asphalted. If they are, we mark the day as a working day and add both roads to their respective sets.
4. **Output the Result**: After processing all days, we print the days on which road works were conducted.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    idx = 1
    schedule = []
    for _ in range(n * n):
        h = int(input[idx])
        v = int(input[idx + 1])
        schedule.append((h, v))
        idx += 2
    
    horizontal = set()
    vertical = set()
    result = []
    
    for day in range(len(schedule)):
        h, v = schedule[day]
        if h not in horizontal and v not in vertical:
            result.append(day + 1)
            horizontal.add(h)
            vertical.add(v)
    
    print(' '.join(map(str, result)))

main()
```

### Explanation
- **Reading Input**: The input is read all at once for efficiency, especially given the constraints. The first value is the number of roads (n), followed by the schedule of intersections.
- **Processing Each Intersection**: For each intersection in the schedule, we check if both the horizontal and vertical roads are unmarked. If they are, we record the day and mark both roads as asphalted.
- **Efficiency**: Using sets to track asphalted roads allows for O(1) average time complexity for membership checks and insertions, making the solution efficient even for the upper limit of n=50.

This approach ensures that we correctly identify all days on which road works occur by systematically checking each intersection and updating our tracking sets accordingly. The solution efficiently handles the constraints and provides the correct output in ascending order.
