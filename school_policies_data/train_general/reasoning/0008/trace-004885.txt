To solve this problem, we need to determine the shortest distance between two points on the perimeter of a square. The path must be along the edges of the square. The approach involves converting the coordinates of the points into their positions along the perimeter of the square and then finding the minimal path between these positions.

### Approach
1. **Model the Square's Perimeter**: Treat the square's perimeter as a continuous path starting from the bottom edge, moving to the right, then to the top, and finally to the left edge.
2. **Convert Coordinates to Perimeter Positions**: For each point, determine its position along the perimeter by checking which edge it lies on and calculating the distance from the starting point (0,0) along that edge.
3. **Calculate Minimal Distance**: Once the positions of both points on the perimeter are known, compute the shortest path by considering both clockwise and counter-clockwise directions around the perimeter.

### Solution Code
```python
n, x1, y1, x2, y2 = map(int, input().split())

def perimeter_position(n, x, y):
    if y == 0:
        return x
    elif x == n:
        return n + y
    elif y == n:
        return 3 * n - x
    else:  # x == 0
        return 4 * n - y

a = perimeter_position(n, x1, y1)
b = perimeter_position(n, x2, y2)

distance = abs(a - b)
print(min(distance, 4 * n - distance))
```

### Explanation
1. **Perimeter Position Calculation**:
   - **Bottom Edge (y=0)**: The position is the x-coordinate.
   - **Right Edge (x=n)**: The position is `n + y` (n units for the bottom edge plus y units up the right edge).
   - **Top Edge (y=n)**: The position is `3n - x` (2n units for the bottom and right edges, plus (n - x) units left along the top edge).
   - **Left Edge (x=0)**: The position is `4n - y` (3n units for the bottom, right, and top edges, plus (n - y) units down the left edge).

2. **Distance Calculation**:
   - Compute the absolute difference between the two perimeter positions.
   - The shortest path is the minimum of the clockwise and counter-clockwise distances around the perimeter, which is `min(distance, 4n - distance)` where `4n` is the total perimeter length.

This approach efficiently converts the problem into a linear distance calculation on a circular path, ensuring the solution is both optimal and straightforward.
