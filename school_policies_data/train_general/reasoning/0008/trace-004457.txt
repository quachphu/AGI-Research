To solve this problem, we need to determine the final scores of Taro and Hanako after playing a card game where each card has an animal name written on it. The winner of each turn is determined by lexicographical order, and points are awarded accordingly.

### Approach
1. **Reading Input:** The first input line gives the number of turns (n). The next n lines each contain two strings separated by a space, representing Taro's and Hanako's cards for each turn.
2. **Comparing Cards:** For each turn, compare the two cards lexicographically:
   - If Taro's card is lexicographically larger, he gets 3 points.
   - If Hanako's card is larger, she gets 3 points.
   - If both cards are the same, each player gets 1 point.
3. **Accumulating Scores:** Keep track of the scores for both players across all turns.
4. **Output the Result:** After processing all turns, print the final scores of Taro and Hanako.

### Solution Code
```python
n = int(input())
taro_score = 0
hanako_score = 0
for _ in range(n):
    taro_card, hanako_card = input().split()
    if taro_card > hanako_card:
        taro_score += 3
    elif taro_card < hanako_card:
        hanako_score += 3
    else:
        taro_score += 1
        hanako_score += 1
print(f"{taro_score} {hanako_score}")
```

### Explanation
- **Reading Input:** The first line is read to get the number of turns. Each subsequent line is split into two parts: Taro's card and Hanako's card.
- **Comparison:** Using lexicographical comparison (which is case-sensitive in Python), we determine the winner of each turn. The comparison directly uses Python's string comparison operators.
- **Scoring:** Points are updated based on the comparison results. If there's a tie, both players get 1 point. Otherwise, the winner gets 3 points.
- **Output:** After processing all turns, the accumulated scores are printed in the required format.

This approach efficiently processes each turn in constant time, leading to an overall time complexity of O(n), which is optimal given the constraints.
