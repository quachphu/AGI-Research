To solve this problem, we need to divide two numbers and present the result truncated to a specified number of decimal places. The solution involves handling multiple test cases and ensuring precise division results without rounding.

### Approach
1. **Reading Input:** Read the number of test cases and then process each test case which consists of three integers: a (dividend), b (divisor), and c (number of decimal places).
2. **Integer Division:** Compute the integer part of the division using integer division.
3. **Decimal Part Calculation:** For the decimal part, use the remainder from the integer division and repeatedly multiply it by 10, extracting the next digit each time until the required number of decimal places (c) is reached.
4. **Constructing the Result:** Combine the integer part and the computed decimal digits to form the final result. If no decimal places are required, only the integer part is printed.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        a = int(input[idx])
        b = int(input[idx+1])
        c = int(input[idx+2])
        idx += 3
        
        integer_part = a // b
        remainder = a % b
        decimal_digits = []
        for _ in range(c):
            remainder *= 10
            digit = remainder // b
            decimal_digits.append(str(digit))
            remainder = remainder % b
        
        if c == 0:
            print(integer_part)
        else:
            print(f"{integer_part}.{''.join(decimal_digits)}")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The input is read all at once and split into a list of strings for efficient processing. The first element gives the number of test cases.
2. **Integer Part Calculation:** The integer part of the division is obtained using `a // b`.
3. **Decimal Digits Calculation:** For each decimal place, the remainder from the previous step is multiplied by 10. The quotient of this value divided by `b` gives the next decimal digit. The remainder is updated for the next iteration.
4. **Result Construction:** Depending on the number of decimal places required (c), the result is formatted either as an integer (if c=0) or as a floating-point number with exactly `c` decimal places.

This approach ensures that the division result is precise and truncated to the specified number of decimal places without any rounding, adhering to the problem requirements efficiently.
