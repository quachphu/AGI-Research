To solve this problem, we need to determine if Masha can construct a symmetric square matrix of size m x m using 2x2 tiles. The matrix must be symmetric with respect to its main diagonal, and tiles cannot be rotated.

### Approach
1. **Check if m is Even**: Since each tile is 2x2, the size of the matrix (m) must be even. If m is odd, it's impossible to cover the matrix with 2x2 tiles, so the answer is immediately "NO".

2. **Check Diagonal Tiles**: For the matrix to be symmetric, any tile placed on the main diagonal (where row index equals column index) must be symmetric itself. This means the top-right element of the tile must equal the bottom-left element.

3. **Check for Mirror Tiles**: For even m greater than 2, non-diagonal tiles must come in pairs such that each tile has a corresponding mirror tile. This mirror tile is formed by swapping the top-right and bottom-left elements of the original tile.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    tiles = []
    for _ in range(n):
        a, b = map(int, input().split())
        c, d = map(int, input().split())
        tiles.append((a, b, c, d))
    
    if m % 2 != 0:
        print("NO")
        continue
    
    # Check condition a: exists a tile with b == c (for diagonal)
    has_diagonal = any(b == c for (a, b, c, d) in tiles)
    if not has_diagonal:
        print("NO")
        continue
    
    if m == 2:
        print("YES")
        continue
    
    # Check condition b: exists at least one tile whose mirror is present
    tile_set = set(tiles)
    has_mirror = False
    for tile in tiles:
        a, b, c, d = tile
        mirror = (a, c, b, d)
        if mirror in tile_set:
            has_mirror = True
            break
    
    print("YES" if has_mirror else "NO")
```

4. **Mirror Tile Check**: For matrices larger than 2x2, check if there exists at least one pair of tiles where one is the mirror of the other. This ensures that non-diagonal blocks can be mirrored to maintain symmetry.

This approach efficiently checks the necessary conditions to determine if a symmetric matrix can be constructed using the given tiles.
