To solve this problem, we need to determine the number of days for which the weather forecast was correct. Given two strings representing the forecasted and actual weather for three consecutive days, we compare each day's forecast with the actual weather and count the matches.

### Approach
1. **Input Reading**: Read the two input strings representing the forecasted and actual weather.
2. **Comparison**: For each day (i.e., each character position in the strings), compare the forecasted weather with the actual weather.
3. **Count Matches**: Count how many times the forecasted weather matches the actual weather for the three days.
4. **Output Result**: Print the count of matching days.

### Solution Code
```python
def main():
    s = input().strip()
    t = input().strip()
    count = sum(a == b for a, b in zip(s, t))
    print(count)

main()
```

### Explanation
1. **Reading Input**: The function reads two lines of input. The first line is the forecast string `S`, and the second line is the actual weather string `T`.
2. **Comparing Characters**: Using the `zip` function, we pair each character from the forecast string with the corresponding character from the actual weather string.
3. **Counting Matches**: The `sum` function is used to count the number of `True` values generated by the comparison `a == b` for each character pair. In Python, `True` is equivalent to `1` and `False` to `0`, so summing these values gives the total number of correct forecasts.
4. **Output**: The result is printed, which is the count of days where the forecast matched the actual weather.

This approach efficiently processes the input in linear time, O(n), where n is the length of the strings (3 in this case), making it optimal for the problem constraints.
