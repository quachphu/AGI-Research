To solve this problem, we need to determine the minimum size of a photo for each friend when they are excluded from the group photo. The size of the photo is determined by the sum of the widths of the remaining friends and the maximum height among them.

### Approach
1. **Sum of Widths**: Compute the total sum of all widths once. For each friend, subtract their width from this total to get the sum of widths when they are excluded.
2. **Maximum Height Handling**: Efficiently compute the maximum height and the second maximum height. This allows us to quickly determine the maximum height when any given friend is excluded.
3. **Edge Cases Handling**: If the maximum height occurs more than once, the maximum height remains the same even if one instance is excluded. If it occurs only once, the second maximum height becomes the new maximum when that friend is excluded.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    friends = []
    sum_w = 0
    h_list = []
    for _ in range(n):
        w, h = map(int, sys.stdin.readline().split())
        friends.append((w, h))
        sum_w += w
        h_list.append(h)
    
    if n == 0:
        print()
        return
    
    max_h = h_list[0]
    count_max = 1
    second_max = -float('inf')
    
    for h in h_list[1:]:
        if h > max_h:
            second_max = max_h
            max_h = h
            count_max = 1
        elif h == max_h:
            count_max += 1
        else:
            if h > second_max:
                second_max = h
    
    results = []
    for w, h in friends:
        sum_wi = sum_w - w
        if h == max_h:
            if count_max > 1:
                current_max = max_h
            else:
                current_max = second_max
        else:
            current_max = max_h
        results.append(sum_wi * current_max)
    
    print(' '.join(map(str, results)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read efficiently using `sys.stdin` to handle large input sizes.
2. **Sum of Widths**: We compute the total width of all friends once, which allows us to quickly determine the sum for each friend's exclusion by subtracting their width.
3. **Max and Second Max Heights**: We iterate through the heights to determine the maximum height and the second maximum height. This helps in quickly determining the new maximum height when a friend is excluded.
4. **Result Calculation**: For each friend, we compute the photo size by using the precomputed total width (excluding their width) and the appropriate maximum height based on whether the excluded friend was contributing to the original maximum height.

This approach ensures that we efficiently handle up to 200,000 friends with an O(n) time complexity, making it suitable for large input sizes.
