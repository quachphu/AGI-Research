To solve this problem, we need to determine the maximum possible even number that can be obtained by swapping exactly two distinct digits in a given odd positive integer. The solution must ensure that the resulting number is even and the largest possible value under the given constraints.

### Approach
1. **Identify Even Digits**: First, identify all even digits in the given number except the last digit (since the original number is odd, the last digit is odd).
2. **Check Feasibility**: If there are no even digits, output `-1` as it's impossible to form an even number.
3. **Optimal Swap**:
   - **Leftmost Smaller Even Digit**: Find the leftmost even digit that is smaller than the last digit. Swapping this digit with the last digit will yield the largest possible number.
   - **Rightmost Even Digit**: If no even digit smaller than the last digit is found, swap the rightmost even digit with the last digit to ensure the number is even while minimizing the reduction in value.
4. **Avoid Leading Zeros**: Ensure the resulting number does not have leading zeros, which would make it invalid.

### Solution Code
```python
n = input().strip()
digits = list(n)
last_digit = digits[-1]
even_indices = [i for i, c in enumerate(digits[:-1]) if int(c) % 2 == 0]

if not even_indices:
    print(-1)
else:
    selected_index = -1
    for i in even_indices:
        if digits[i] < last_digit:
            selected_index = i
            break
    if selected_index != -1:
        digits[selected_index], digits[-1] = digits[-1], digits[selected_index]
        if digits[0] == '0':
            print(-1)
        else:
            print(''.join(digits))

        rightmost = even_indices[-1]
        digits[rightmost], digits[-1] = digits[-1], digits[rightmost]
        if digits[0] == '0':

        else:
            print(''.join(digits))
```

2. **Feasibility Check**: If there are no even digits, the result is `-1`.
3. **Leftmost Smaller Even Digit**: The code iterates through the even digits from left to right to find the first even digit smaller than the last digit. Swapping this digit with the last digit ensures the highest possible value.
4. **Rightmost Even Digit**: If no smaller even digit is found, the code swaps the rightmost even digit with the last digit to ensure the number is even, albeit the largest possible under the circumstances.
5. **Leading Zero Check**: After any swap, the code checks if the resulting number starts with a zero, which would be invalid, and outputs `-1` in such cases.
