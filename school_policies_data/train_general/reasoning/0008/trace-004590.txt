To solve this problem, we need to determine the maximum possible sum of absolute differences between consecutive elements in a permutation of the first N natural numbers. The goal is to find the optimal permutation that maximizes this sum.

### Approach
The key insight is that the optimal permutation can be derived using a mathematical formula based on whether N is even or odd:

1. **For even N**: The maximum sum is calculated as \((N^2 // 2) - 1\). This formula is derived from the observation that alternating high and low values in the permutation maximizes the absolute differences.
2. **For odd N**: The maximum sum is calculated as \(((N^2 - 1) // 2) - 1\). This formula accounts for the middle element in the permutation and adjusts the sum accordingly.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        N = int(input[i])
        if N == 1:
            print(0)
        else:
            if N % 2 == 0:
                res = (N * N) // 2 - 1
            else:
                res = (N * N - 1) // 2 - 1
            print(res)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Handling Each Test Case**: For each test case, we check if N is 1, which directly returns 0 since there are no consecutive elements. For other values of N, we determine if it is even or odd and apply the respective formula.
3. **Formulas**:
   - **Even N**: The formula \((N^2 // 2) - 1\) efficiently computes the maximum sum by leveraging the properties of even-numbered permutations.
   - **Odd N**: The formula \(((N^2 - 1) // 2) - 1\) adjusts for the middle element in the permutation, ensuring the sum is maximized.

This approach ensures that the solution is computed in constant time \(O(1)\) per test case, making it highly efficient even for large values of N up to \(2 \times 10^5\).
