To solve this problem, we need to determine the winner of a game played by Jack and Jenny based on the distance to their school, `n`, where they take turns riding a cycle in increments of 1, 3, or 5 units. The winner is the one who reaches exactly `n` units. Jenny starts first, and both play optimally.

### Approach
The key insight to solve this problem is recognizing the parity (odd or even nature) of the distance `n`. Since each move (1, 3, or 5 units) is an odd number, each move changes the parity of the total distance covered. Jenny starts first, so if `n` is odd, she can always reach `n` first by making optimal moves. Conversely, if `n` is even, Jack will be the one to reach `n` first by playing optimally. This is because the parity alternates with each move, and the player starting first (Jenny) will always end up on an odd total, while the second player (Jack) will end up on an even total.

### Solution Code
```python
def determine_winner():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T+1):
        n = int(input[i])
        if n % 2 == 1:
            print("JENNY")
        else:
            print("JACK")

determine_winner()
```

### Explanation
1. **Reading Input:** The input is read in one go for efficiency, especially given the constraints.
2. **Iterating Through Test Cases:** For each test case, we check the parity of the distance `n`.
3. **Determining the Winner:** If `n` is odd, Jenny wins because she can always reach an odd total first. If `n` is even, Jack wins because he will be the one to reach the even total after Jenny's initial move.

This approach ensures that we efficiently determine the winner in constant time for each test case, making the solution both optimal and straightforward.
