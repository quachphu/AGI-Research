To solve this problem, we need to create a function that reads two integers from standard input, computes their sum, and prints the result. This is a straightforward problem that involves basic input handling and arithmetic operations.

### Approach
1. **Reading Input**: The input consists of two integers separated by a space. We will read the input line, split it into two parts, and convert these parts into integers.
2. **Summing the Integers**: Once we have the two integers, we simply add them together.
3. **Outputting the Result**: Finally, we print the result of the addition.

### Solution Code
```python
def add_numbers():
    a, b = map(int, input().split())
    print(a + b)

add_numbers()
```

### Explanation
1. **Reading Input**: The function `input().split()` reads a line from standard input and splits it into a list of strings based on whitespace. Using `map(int, ...)`, we convert these string values into integers.
2. **Summing the Integers**: The integers `a` and `b` are added together using the `+` operator.
3. **Outputting the Result**: The result of the addition is printed using the `print` function.

This approach ensures that we handle the input correctly, perform the required arithmetic operation efficiently, and output the result as specified. The solution is optimal with a time complexity of O(1) since all operations (reading input, converting types, arithmetic addition, and printing) are performed in constant time.
