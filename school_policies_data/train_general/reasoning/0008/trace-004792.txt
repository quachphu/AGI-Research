To solve this problem, we need to determine the sum of the k smallest elements from a given list of integers. 

### Approach
The approach involves the following steps:
1. **Input Reading**: Read the integers n and k from the input, followed by the list of n integers.
2. **Sorting**: Sort the list of integers in ascending order.
3. **Summing**: Sum the first k elements of the sorted list, which are the k smallest elements.

This approach works efficiently given the constraints (n ≤ 2200) and ensures that we correctly identify and sum the smallest k elements using sorting.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))
a.sort()
print(sum(a[:k]))
```

### Explanation
1. **Reading Input**: The first line of input is split into two integers, n (number of elements) and k (number of smallest elements to sum). The second line is split into a list of integers.
2. **Sorting**: The list of integers is sorted in ascending order. Sorting ensures that the smallest elements are at the beginning of the list.
3. **Summing the Smallest Elements**: By taking the first k elements of the sorted list and summing them, we obtain the required result. This method efficiently leverages sorting to quickly access the smallest elements and compute their sum.

This solution is optimal for the given problem constraints and ensures correctness by directly addressing the problem's requirements.
