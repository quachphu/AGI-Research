To solve this problem, we need to determine how many bricks between two given numbers, a and b, are painted both red and pink by Iahub and Floyd, respectively. The solution involves finding the common multiples of their painting intervals using mathematical concepts of greatest common divisor (GCD) and least common multiple (LCM).

### Approach
1. **Understanding the Problem**: Iahub paints every x-th brick red, and Floyd paints every y-th brick pink. We need to find the bricks that are painted both colors, which are the common multiples of x and y within the range [a, b].

2. **Mathematical Insight**: The common multiples of x and y are the multiples of their least common multiple (LCM). The LCM of two numbers can be calculated using their greatest common divisor (GCD) with the formula: \( \text{LCM}(x, y) = \frac{x \times y}{\text{GCD}(x, y)} \).

3. **Finding Multiples in Range**: Once we have the LCM, we need to determine how many multiples of this LCM lie within the range [a, b]. This involves:
   - Finding the smallest multiple of LCM that is greater than or equal to a.
   - Finding the largest multiple of LCM that is less than or equal to b.
   - Calculating the count of these multiples within the range.

### Solution Code
```python
import math

def count_common_painted():
    x, y, a, b = map(int, input().split())
    gcd = math.gcd(x, y)
    lcm = (x * y) // gcd
    k_first = (a + lcm - 1) // lcm
    k_last = b // lcm
    print(max(0, k_last - k_first + 1) if k_last >= k_first else 0)

count_common_painted()
```

### Explanation
1. **Reading Input**: The input values x, y, a, and b are read from standard input.
2. **Calculating GCD and LCM**: Using the built-in `math.gcd` function, we compute the GCD of x and y. The LCM is then derived using the formula mentioned.
3. **Finding Multiples**:
   - **k_first**: The smallest integer k such that \( k \times \text{LCM} \geq a \). This is calculated using integer division to avoid floating-point operations.
   - **k_last**: The largest integer k such that \( k \times \text{LCM} \leq b \). This is simply the integer division of b by LCM.
4. **Counting Valid Multiples**: If `k_last` is less than `k_first`, there are no valid multiples in the range, and the result is 0. Otherwise, the count of multiples is `k_last - k_first + 1`.

This approach efficiently narrows down the problem to mathematical operations on integers, ensuring optimal performance even for large input ranges.
