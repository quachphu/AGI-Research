To solve this problem, we need to determine the maximum possible dimension of a sub-square matrix consisting entirely of 1's for each given test case. The solution involves using dynamic programming (DP) to efficiently compute the largest square of 1's ending at each cell in the matrix.

### Approach
1. **Dynamic Programming (DP) Table**: We create a DP table where each cell `dp[i][j]` represents the size of the largest square ending at cell `(i, j)` in the input matrix.
2. **Initialization**: For cells in the first row or first column, the value in the DP table is the same as the input matrix because the largest possible square at these positions can only be 1x1 if the value is 1.
3. **DP Transition**: For other cells, if the input matrix value is 1, the value in the DP table is determined by the minimum value among the top, left, and top-left diagonal cells plus 1. This is because a square ending at `(i, j)` can only be as large as the smallest square ending at its neighboring cells plus one.
4. **Track Maximum**: Keep track of the maximum value in the DP table, which represents the dimension of the largest square of 1's found.

### Solution Code
```python
import sys

def main():
    data = list(map(int, sys.stdin.read().split()))
    ptr = 0
    T = data[ptr]
    ptr += 1
    for _ in range(T):
        m = data[ptr]
        n = data[ptr + 1]
        ptr += 2
        matrix = []
        for i in range(m):
            row = data[ptr:ptr + n]
            matrix.append(row)
            ptr += n
        
        max_size = 0
        dp = [[0] * n for _ in range(m)]
        for i in range(m):
            for j in range(n):
                if matrix[i][j] == 1:
                    if i == 0 or j == 0:
                        current = 1
                    else:
                        current = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
                    dp[i][j] = current
                    if current > max_size:
                        max_size = current
                else:
                    dp[i][j] = 0
        print(max_size)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and split into a list of integers for efficient processing, which is crucial given the potentially large number of test cases.
2. **Dynamic Programming Table Construction**: The DP table is constructed by iterating through each cell of the input matrix. For each cell, the value in the DP table is computed based on the values of its neighboring cells.
3. **Handling Edge Cases**: The first row and first column are handled separately to initialize the DP table correctly.
4. **Tracking Maximum Size**: During the construction of the DP table, the maximum value is continuously updated to keep track of the largest square found.

This approach ensures that each test case is processed in O(m*n) time complexity, where m and n are the dimensions of the matrix, making the solution efficient and scalable for the given constraints.
