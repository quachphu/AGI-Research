To solve this problem, we need to ensure that no matter which box the nephew chooses, he can redistribute the blocks such that the remaining boxes have the same number of blocks. The goal is to determine the minimum number of extra blocks required to achieve this.

### Approach
1. **Understanding the Problem**: The key insight is that for any chosen box, the total number of blocks in all boxes (after redistribution) must be divisible by the number of remaining boxes. This means we need to adjust the number of blocks in each box such that the sum of blocks in all boxes is a multiple of the number of remaining boxes, and each box's block count does not exceed a certain threshold.

2. **Key Observations**:
   - The sum of blocks in all boxes must be divisible by \( n-1 \), where \( n \) is the number of boxes.
   - The maximum block count in any box (after adding extra blocks) must not exceed the threshold \( T \), which is the sum of all blocks divided by \( n-1 \).

3. **Algorithm**:
   - Compute the sum of the existing blocks.
   - Determine the maximum number of blocks in any box.
   - Calculate the required threshold \( T \) as the maximum between the current maximum block count and the ceiling of the sum of blocks divided by \( n-1 \).
   - The minimum number of extra blocks required is the difference between \( T \times (n-1) \) and the sum of the existing blocks.

import sys

def main():
    input = sys.stdin.read().split()
    idx = 0
    t = int(input[idx])
    idx += 1
    for _ in range(t):
        n = int(input[idx])
        idx += 1
        a = list(map(int, input[idx:idx+n]))
        idx += n
        sum_a = sum(a)
        max_a = max(a)
        denominator = n - 1
        required_T1 = (sum_a + denominator - 1) // denominator
        T = max(max_a, required_T1)
        result = T * denominator - sum_a
        print(result)

if __name__ == "__main__":
