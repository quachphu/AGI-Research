To solve this problem, we need to determine the size of the maximum clique in a graph formed by points on a line, where edges exist between points if their distance is at least the sum of their weights. The problem can be transformed into an interval scheduling problem, where the goal is to select the maximum number of non-overlapping intervals.

### Approach
1. **Transform Points to Intervals**: Each point (xi, wi) is transformed into an interval [xi - wi, xi + wi].
2. **Sort Intervals by End Points**: Sorting the intervals by their end points allows us to use a greedy algorithm to select the maximum number of non-overlapping intervals.
3. **Greedy Selection**: Iterate through the sorted intervals, selecting each interval if it starts after the end of the previously selected interval. This ensures that we maximize the number of non-overlapping intervals.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    intervals = []
    for _ in range(n):
        x, w = map(int, sys.stdin.readline().split())
        start = x - w
        end = x + w
        intervals.append((end, start))  # Storing as (end, start) to sort by end
    
    # Sort by end (first element of the tuple)
    intervals.sort()
    
    count = 0
    last_end = -float('inf')
    for end, start in intervals:
        if start >= last_end:
            count += 1
            last_end = end
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read efficiently using `sys.stdin` to handle large input sizes.
2. **Interval Transformation**: Each point is converted into an interval [xi - wi, xi + wi].
3. **Sorting**: Intervals are sorted by their end points to facilitate the greedy selection process.
4. **Greedy Algorithm**: By iterating through the sorted intervals and selecting each interval that starts after the previous interval's end, we ensure the maximum number of non-overlapping intervals, which corresponds to the maximum clique size in the graph.

This approach ensures an optimal solution with a time complexity of O(n log n) due to sorting, which is efficient for the given problem constraints.
