To solve this problem, we need to determine the parity (even or odd) of a given 7-digit hexadecimal number. The solution hinges on the observation that the parity of a hexadecimal number is determined by its last digit, similar to how the parity of a decimal number is determined by its last digit. This allows us to directly check the last digit of the input string to determine the result.

### Approach
1. **Input Reading**: Read the input string which is a 7-digit hexadecimal number starting with 'A' followed by six decimal digits.
2. **Check Last Digit**: Extract the last character of the input string, which is a digit between 0 and 9.
3. **Determine Parity**: Check if the last digit is even or odd. If it is even, output 0; if it is odd, output 1.

### Solution Code
```python
def main():
    s = input().strip()
    last_digit = s[-1]
    print(1 if int(last_digit) % 2 else 0)

main()
```

### Explanation
- **Reading Input**: The input is read as a string, which is stripped of any leading or trailing whitespace.
- **Extracting Last Digit**: The last character of the string is accessed using `s[-1]`.
- **Checking Parity**: Convert the last character to an integer and check its parity using the modulus operator. If the result of `int(last_digit) % 2` is 0, the number is even, so we print 0. Otherwise, we print 1.

This approach efficiently determines the parity by focusing solely on the last digit, avoiding the need to convert the entire hexadecimal number to an integer. This makes the solution both optimal and straightforward.
