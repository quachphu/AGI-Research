To solve this problem, we need to count the number of squares that meet two specific conditions: the square's assigned number (position) is odd, and the integer written on that square is also odd. 

### Approach
1. **Read Input**: First, we read the integer N which represents the number of squares, followed by the list of integers written on each square.
2. **Iterate Through Positions**: For each position from 1 to N, check if both the position and the integer at that position are odd.
3. **Count Valid Squares**: Maintain a counter to keep track of how many squares satisfy both conditions.
4. **Output the Result**: Print the count of valid squares.

### Solution Code
```python
def main():
    n = int(input())
    a = list(map(int, input().split()))
    count = 0
    for i in range(n):
        position = i + 1
        if position % 2 == 1 and a[i] % 2 == 1:
            count += 1
    print(count)

main()
```

### Explanation
1. **Reading Input**: The input is read in two parts. The first part is the integer N, and the second part is a list of N integers.
2. **Loop Through Positions**: Using a loop, we check each position from 1 to N. For each position, we determine if the position is odd and if the corresponding integer in the list is also odd.
3. **Check Conditions**: For each position, we use modulo operations to check if both the position and the integer are odd. If both conditions are met, we increment our counter.
4. **Output the Result**: Finally, we print the count of valid squares that meet both conditions.

This approach efficiently checks each position and its corresponding integer in a single pass through the list, ensuring an optimal time complexity of O(N), where N is the number of squares. This solution is both straightforward and efficient for the given problem constraints.
