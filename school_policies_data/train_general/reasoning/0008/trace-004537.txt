To solve this problem, we need to determine the length of each string provided in the input for multiple test cases. The solution involves reading the input, processing each string to compute its length, and then outputting the results.

### Approach
1. **Read Input:** The first line of input is an integer `t` representing the number of test cases. Each subsequent line contains a string of lowercase alphabets.
2. **Process Each Test Case:** For each test case, read the string and compute its length using Python's built-in `len()` function.
3. **Output the Results:** Print the length of each string immediately after processing it.

This approach ensures that we efficiently process each string in linear time relative to the number of test cases, making the solution both optimal and straightforward.

### Solution Code
```python
def main():
    t = int(input())
    for _ in range(t):
        s = input()
        print(len(s))

main()
```

### Explanation
1. **Reading Input:** The function starts by reading the integer `t` which denotes the number of test cases.
2. **Loop Through Test Cases:** Using a loop, each subsequent line (string) is read. The `input()` function captures each line excluding the trailing newline character.
3. **Compute and Print Length:** For each string, the length is computed using `len(s)` where `s` is the input string. This length is then printed immediately.

This solution efficiently handles the input constraints and ensures that each string is processed in constant time, resulting in an overall time complexity of O(t), where t is the number of test cases. This is optimal given the problem constraints.
