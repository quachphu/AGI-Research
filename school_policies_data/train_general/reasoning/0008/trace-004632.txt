To solve this problem, we need to determine the number of excellent numbers of exactly length `n` where each digit is either `a` or `b`. An excellent number is defined as a good number whose sum of digits is also a good number. A good number contains only the digits `a` and `b`.

### Approach
1. **Combinatorics and Modular Arithmetic**: 
   - Use combinatorial mathematics to count the number of valid combinations of digits `a` and `b` in an `n`-digit number.
   - Precompute factorials and inverse factorials modulo `10^9 + 7` to efficiently compute combinations using modular arithmetic.

2. **Sum Check**:
   - For each possible count of digit `a` (from 0 to `n`), compute the sum of digits and check if this sum is a good number (all digits are `a` or `b`).

3. **Efficient Validation**:
   - Instead of converting the sum to a string, use arithmetic operations to check each digit of the sum directly.

### Solution Code
```python
def main():
    MOD = 10**9 + 7
    a, b, n = map(int, input().split())
    
    # Precompute factorial and inverse factorial modulo MOD up to n
    max_n = n
    fact = [1] * (max_n + 1)
    for i in range(1, max_n + 1):
        fact[i] = fact[i-1] * i % MOD
    
    inv_fact = [1] * (max_n + 1)
    inv_fact[max_n] = pow(fact[max_n], MOD - 2, MOD)
    for i in range(max_n - 1, -1, -1):
        inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD
    
    ans = 0
    for k in range(n + 1):
        total = a * k + b * (n - k)
        # Check if total is a good number
        valid = True
        if total == 0:
            valid = False
        else:
            temp = total
            while temp > 0:
                digit = temp % 10
                if digit != a and digit != b:
                    valid = False
                    break
                temp = temp // 10
        if valid:
            # Compute combination C(n, k)
            comb = fact[n] * inv_fact[k] % MOD
            comb = comb * inv_fact[n - k] % MOD
            ans = (ans + comb) % MOD
    print(ans)

main()
```

### Explanation
1. **Precomputation**:
   - We precompute the factorial and inverse factorial arrays up to `n` using modular arithmetic. This allows us to compute combinations efficiently using the formula `C(n, k) = n! / (k! * (n-k)!) % MOD`.

2. **Loop Through Possible Counts**:
   - For each possible count `k` of digit `a`, compute the sum of digits as `a*k + b*(n-k)`.

3. **Check Sum Validity**:
   - For each sum, check if all its digits are either `a` or `b` using arithmetic operations to avoid string conversion overhead.

4. **Combination Calculation**:
   - If the sum is valid, compute the combination `C(n, k)` using the precomputed factorials and add it to the result modulo `10^9 + 7`.

This approach efficiently handles the constraints and ensures the solution is computed in a feasible time even for large values of `n` up to `10^6`.
