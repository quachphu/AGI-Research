To solve this problem, we need to determine if Mahmoud can use exactly three line segments to form a non-degenerate triangle. A non-degenerate triangle is defined as a triangle with a positive area, which means that the sum of any two sides must be greater than the third side.

### Approach
1. **Sort the Array**: The key insight is that if there exists a valid triplet of line segments forming a non-degenerate triangle, then after sorting the array in non-decreasing order, there must be at least one triplet of consecutive elements where the sum of the two smaller elements is greater than the largest element. This is because sorting helps us efficiently check the closest possible candidates for forming a valid triangle.
2. **Check Consecutive Triplets**: After sorting, we iterate through the array and check each triplet of consecutive elements. For each triplet (a[i-2], a[i-1], a[i]), we verify if a[i-2] + a[i-1] > a[i]. If this condition holds for any triplet, we can immediately conclude that a valid triangle can be formed.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
a.sort()
for i in range(2, n):
    if a[i-2] + a[i-1] > a[i]:
        print("YES")
        exit()
print("NO")
```

### Explanation
1. **Input Reading and Sorting**: We first read the input values, including the number of line segments and their lengths. The lengths are then sorted in non-decreasing order.
2. **Consecutive Triplet Check**: By iterating through the sorted array starting from the third element (index 2), we check each triplet of consecutive elements. For each triplet, we verify if the sum of the first two elements is greater than the third element. If such a triplet is found, we print "YES" and exit the program immediately.
3. **Result Determination**: If no valid triplet is found after checking all possible consecutive triplets, we print "NO".

This approach ensures that we efficiently check for the possibility of forming a non-degenerate triangle using a sorting step followed by a linear scan, resulting in an overall time complexity of O(n log n) due to the sorting step. This is optimal for the given problem constraints.
