The solution involves reading multiple datasets, processing each to identify valid sweets, and outputting the results accordingly.

### Approach
1. **Input Handling**: Read multiple datasets until a line with 0 is encountered. Each dataset starts with the number of sweets, followed by their nutritional information and the respective limits.
2. **Caloric Calculation**: For each sweet, compute the calories using the formula: \(4 \times \text{protein} + 9 \times \text{fat} + 4 \times \text{carbohydrate}\).
3. **Validation Check**: Check if each sweet's protein, fat, carbohydrate, and computed calories are within the given limits.
4. **Result Compilation**: Collect all valid sweets in the order they were input and output their numbers. If no valid sweets exist, output "NA".

### Solution Code
```python
def main():
    import sys
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        if n == 0:
            break
        sweets = []
        for _ in range(n):
            parts = sys.stdin.readline().strip().split()
            s = int(parts[0])
            p = int(parts[1])
            q = int(parts[2])
            r = int(parts[3])
            sweets.append((s, p, q, r))
        parts = sys.stdin.readline().strip().split()
        P = int(parts[0])
        Q = int(parts[1])
        R = int(parts[2])
        C = int(parts[3])
        valid = []
        for s, p, q, r in sweets:
            calories = 4 * p + 9 * q + 4 * r
            if p <= P and q <= Q and r <= R and calories <= C:
                valid.append(s)
        if valid:
            for num in valid:
                print(num)
        else:
            print("NA")

main()
```

- **Processing Each Sweet**: For each sweet, the calories are calculated using the given formula. The sweet is checked against the nutritional and caloric limits.
- **Output**: Valid sweets are collected in the order they were read and printed. If no valid sweets are found, "NA" is printed.

This approach ensures that each dataset is processed efficiently, and the solution adheres to the problem constraints and requirements.
