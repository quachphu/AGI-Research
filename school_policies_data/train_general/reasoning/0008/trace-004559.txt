To solve this problem, we need to determine the winner of a game where players choose natural numbers, and the winner is the player who chose the smallest unique number. If no unique number exists, the result is a draw.

### Approach
1. **Input Reading**: Read the number of test cases. For each test case, read the number of players and their respective names and chosen numbers.
2. **Frequency Counting**: Use a dictionary to count the frequency of each number chosen by the players.
3. **Identify Unique Numbers**: Extract all numbers that appear exactly once (unique numbers).
4. **Determine the Winner**: If there are no unique numbers, the result is a draw. Otherwise, find the smallest unique number and determine the first player who chose this number, as they are the winner.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        players = []
        freq = defaultdict(int)
        for _ in range(N):
            name = input[ptr]
            ai = int(input[ptr + 1])
            players.append((name, ai))
            ptr += 2
            freq[ai] += 1
        unique_numbers = [num for num, count in freq.items() if count == 1]
        if not unique_numbers:
            print("Nobody wins.")
            continue
        min_unique = min(unique_numbers)
        for name, num in players:
            if num == min_unique:
                print(name)
                break

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and split into a list of strings for efficient processing. This helps in quickly accessing each token as needed.
2. **Frequency Dictionary**: A dictionary is used to count occurrences of each number, which allows O(1) average time complexity for updates and lookups.
3. **Unique Numbers Identification**: By filtering the frequency dictionary, we collect all numbers that appear exactly once.
4. **Finding the Minimum Unique Number**: The smallest unique number is determined using the `min` function.
5. **First Occurrence Check**: The list of players is iterated in order to find the first player who chose the smallest unique number, ensuring we respect the input order for tie-breaking.

This approach ensures that we efficiently handle the constraints, providing an optimal solution with linear time complexity relative to the input size.
