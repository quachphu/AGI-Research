To solve this problem, we need to determine if a drunk person moving in a systematic pattern between two manholes will fall into either manhole, and if so, which one and how long it takes. The person alternates directions starting with a given initial direction (forward or backward) and moves a fixed number of meters each time. The challenge is to simulate this movement and detect if the person falls into a manhole or enters an infinite loop.

### Approach
1. **Input Parsing**: Read the number of test cases and the parameters for each test case, including initial direction, distances to manholes, step distances, and time per meter.
2. **Simulation of Movement**: For each test case, simulate the person's movement step-by-step, alternating directions after each step.
3. **Manhole Detection**: Check after each step if the person has crossed either manhole. If a manhole is crossed, compute the exact time taken and output the result.
4. **Loop Detection**: Track the person's position and direction at each step. If a state (position and direction) repeats, it indicates an infinite loop, and the person survives.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    results = []
    for _ in range(N):
        direction = input[idx]
        F = int(input[idx+1])
        B = int(input[idx+2])
        f = int(input[idx+3])
        b = int(input[idx+4])
        t = int(input[idx+5])
        idx += 6
        
        current_pos = 0
        total_time = 0
        next_dir = direction
        seen = set()
        result = 'SURVIVED'
        
        while True:
            current_dir = next_dir
            next_dir = 'B' if current_dir == 'F' else 'F'
            
            # Check for repeating state to detect loops
            state = (current_pos, current_dir)
            if state in seen:
                break
            seen.add(state)
            
            step = f if current_dir == 'F' else b
            new_pos = current_pos + (step if current_dir == 'F' else -step)
            
            # Check if this step crosses a manhole
            if current_dir == 'F':
                if current_pos < F and new_pos >= F:
                    required = F - current_pos
                    total_time += required * t
                    result = f'F{total_time}'
                    break
            else:
                if current_pos > -B and new_pos <= -B:
                    required = current_pos + B
                    total_time += required * t
                    result = f'B{total_time}'
                    break
            
            # Update position and time if no manhole was hit
            current_pos = new_pos
            total_time += step * t
        
        results.append(result)
    
    print('\n'.join(results))

if __name__ == "__main__":
    main()
```
