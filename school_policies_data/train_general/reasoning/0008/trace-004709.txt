To solve this problem, we need to determine the color of each vertex in a graph after a series of painting operations. Each operation repaints all vertices within a certain distance from a given vertex. The challenge is to efficiently process these operations, considering the constraints where the number of vertices, edges, and operations can be very large.

### Approach
1. **Reverse Processing of Queries**: Process the queries in reverse order (from last to first). This ensures that once a vertex is painted by a later query, it will not be repainted by any earlier queries.
2. **Breadth-First Search (BFS) for Each Query**: For each query, perform a BFS starting from the given vertex and up to the specified distance. This allows us to efficiently find all vertices within the required distance.
3. **Tracking Processed Vertices**: Use a boolean array to track which vertices have been painted to avoid redundant updates. Additionally, use a timestamp-based visited array to efficiently manage the BFS traversal for each query without resetting the array each time.

### Solution Code
```python
import sys
from collections import deque

def main():
    input = sys.stdin.read().split()
    ptr = 0

    N = int(input[ptr])
    ptr += 1
    M = int(input[ptr])
    ptr += 1

    adj = [[] for _ in range(N + 1)]
    for _ in range(M):
        a = int(input[ptr])
        ptr += 1
        b = int(input[ptr])
        ptr += 1
        adj[a].append(b)
        adj[b].append(a)

    Q = int(input[ptr])
    ptr += 1

    queries = []
    for _ in range(Q):
        v = int(input[ptr])
        ptr += 1
        d = int(input[ptr])
        ptr += 1
        c = int(input[ptr])
        ptr += 1
        queries.append((v, d, c))

    queries.reverse()

    color = [0] * (N + 1)
    marked = [False] * (N + 1)
    visited_time = [0] * (N + 1)
    timestamp = 0

    for (v, d, c) in queries:
        if d == 0:
            if not marked[v]:
                color[v] = c
                marked[v] = True
            continue
        timestamp += 1
        queue = deque()
        queue.append((v, 0))
        visited_time[v] = timestamp
        while queue:
            u, current_d = queue.popleft()
            if current_d > d:
                continue
            if not marked[u]:
                color[u] = c
                marked[u] = True
            for neighbor in adj[u]:
                new_d = current_d + 1
                if new_d > d:
                    continue
                if visited_time[neighbor] < timestamp:
                    visited_time[neighbor] = timestamp
                    queue.append((neighbor, new_d))

    for i in range(1, N + 1):
        print(color[i])

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read and parsed into vertices, edges, and queries.
2. **Adjacency List Construction**: The graph is represented using an adjacency list for efficient traversal.
3. **Reverse Query Processing**: Queries are processed in reverse order to ensure that the last operation affecting a vertex is applied last.
4. **BFS with Timestamp Tracking**: For each query, a BFS is performed up to the specified distance. A timestamp-based visited array ensures that each vertex is enqueued once per BFS, avoiding redundant processing.
5. **Marking and Coloring**: Vertices are marked as painted once they are processed, ensuring each vertex is only painted once by the last relevant query.

This approach efficiently handles the constraints by leveraging reverse processing and BFS with optimal tracking mechanisms, ensuring the solution is both time and space efficient.
