To solve this problem, we need to determine the maximum number of times a visitor can become happy by passing from a less beautiful painting to a more beautiful one when the paintings are arranged in an optimal order. The key insight here is to leverage the frequency of each beauty value to determine the optimal arrangement.

### Approach
1. **Frequency Analysis**: The maximum number of increasing steps we can achieve is constrained by the most frequent beauty value. If a particular beauty value appears very frequently, it limits the number of transitions we can create between different values.
2. **Optimal Arrangement**: The optimal arrangement is determined by the maximum frequency of any beauty value. The formula to compute the maximum number of increasing steps is `n - max_freq`, where `n` is the total number of paintings and `max_freq` is the highest frequency of any beauty value.

### Solution Code
```python
from collections import Counter

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    freq = Counter(a)
    max_freq = max(freq.values())
    print(n - max_freq)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of the number of paintings and their respective beauty values.
2. **Frequency Calculation**: Using a `Counter` from the `collections` module, we count the frequency of each beauty value.
3. **Determine Maximum Frequency**: The maximum frequency of any beauty value is found using the `max` function on the frequency values.
4. **Compute Result**: The result is calculated as `n - max_freq`, which gives the maximum number of increasing steps possible by optimally arranging the paintings.

This approach efficiently determines the solution by focusing on the frequency distribution of the beauty values, ensuring we handle both unique and repeated values optimally.
