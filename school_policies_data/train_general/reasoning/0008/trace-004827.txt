def compute_min_flips(s):
    n = len(s)
    prefix_0 = [0]*(n+1)
    prefix_1 = [0]*(n+1)
    for i in range(1, n+1):
        c = s[i-1]
        prefix_0[i] = prefix_0[i-1] + (1 if c == '0' else 0)
        prefix_1[i] = prefix_1[i-1] + (1 if c == '1' else 0)
    total_0 = prefix_0[n]
    total_1 = prefix_1[n]
    all_0 = total_1
    all_1 = total_0
    min_01 = float('inf')
    for i in range(n+1):
        cost = prefix_1[i] + (total_0 - prefix_0[i])
        if cost < min_01:
            min_01 = cost
    min_10 = float('inf')
    for i in range(n+1):
        cost = prefix_0[i] + (total_1 - prefix_1[i])
        if cost < min_10:
            min_10 = cost
    return min(all_0, all_1, min_01, min_10)

To solve this problem, we need to determine the minimum number of operations required to convert a binary string into a "good" string. A good string is defined as one that does not contain "010" or "101" as a subsequence. 

### Approach
The key insight is that a binary string is good if it can be transformed into a string with at most two contiguous segments (either all 0s followed by all 1s, all 1s followed by all 0s, or entirely one character). The approach involves considering four possible target configurations and calculating the minimum flips required for each configuration:

1. **All 0s**: Count the number of 1s to be flipped.
2. **All 1s**: Count the number of 0s to be flipped.
3. **Segmented 0s followed by 1s**: Find the optimal split point where the first part is all 0s and the second part is all 1s.
4. **Segmented 1s followed by 0s**: Find the optimal split point where the first part is all 1s and the second part is all 0s.

### Solution Code
```python
t = int(input())
for _ in range(t):
    s = input().strip()
    n = len(s)
    prefix_0 = [0] * (n + 1)
    prefix_1 = [0] * (n + 1)
    for i in range(1, n + 1):
        c = s[i-1]
        prefix_0[i] = prefix_0[i-1] + (1 if c == '0' else 0)
        prefix_1[i] = prefix_1[i-1] + (1 if c == '1' else 0)
    total_0 = prefix_0[n]
    total_1 = prefix_1[n]
    all_0 = total_1
    all_1 = total_0
    min_01 = float('inf')
    for i in range(n + 1):
        cost = prefix_1[i] + (total_0 - prefix_0[i])
        if cost < min_01:
            min_01 = cost
    min_10 = float('inf')
    for i in range(n + 1):
        cost = prefix_0[i] + (total_1 - prefix_1[i])
        if cost < min_10:
            min_10 = cost
    res = min(all_0, all_1, min_01, min_10)
    print(res)
```

### Explanation
1. **Prefix Arrays**: Compute prefix sums for 0s and 1s to efficiently calculate the number of flips required for any segment of the string.
2. **Total Counts**: Determine the total number of 0s and 1s in the string to handle the cases where the entire string is converted to all 0s or all 1s.
3. **Segmented Conversions**: For each possible split point, compute the cost to convert the string into two segments (0s followed by 1s or 1s followed by 0s) and track the minimum cost.
4. **Result Calculation**: The minimum number of flips required is the smallest value among all considered configurations.

This approach ensures that we efficiently explore all possible valid configurations and find the optimal solution with minimal computational overhead.
