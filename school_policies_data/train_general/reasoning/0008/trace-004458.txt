To solve this problem, we need to determine the winner between Shanky and Anku based on the first unique characters they encounter while traversing a string from opposite directions. If their characters are the same or neither finds a unique character, Pandey is declared the winner.

### Approach
1. **Count Character Frequencies**: For each test case, we first count the frequency of each character in the string using an array of size 26 (for each lowercase alphabet).
2. **Find Shanky's Character**: Traverse the string from left to right and find the first character that appears exactly once.
3. **Find Anku's Character**: Traverse the string from right to left and find the first character that appears exactly once.
4. **Determine the Winner**: Compare the characters found by Shanky and Anku. If Shanky's character has a higher ASCII value, he wins. If Anku's character has a higher ASCII value, she wins. If both characters are the same or neither found a unique character, Pandey wins.

### Solution Code
```python
import sys

def determine_winner():
    T = int(sys.stdin.readline())
    for _ in range(T):
        S = sys.stdin.readline().strip()
        counts = [0] * 26
        for c in S:
            counts[ord(c) - 97] += 1
        
        # Find Shanky's character
        shanky_char = None
        for c in S:
            if counts[ord(c) - 97] == 1:
                shanky_char = c
                break
        
        # Find Anku's character
        anku_char = None
        for c in reversed(S):
            if counts[ord(c) - 97] == 1:
                anku_char = c
                break
        
        # Determine the result
        if shanky_char is None and anku_char is None:
            print("PANDEY")
        elif shanky_char is None:
            print("ANKU")
        elif anku_char is None:
            print("SHANKY")
        else:
            if shanky_char > anku_char:
                print("SHANKY")
            elif anku_char > shanky_char:
                print("ANKU")
            else:
                print("PANDEY")

determine_winner()
```

### Explanation
- **Character Frequency Counting**: We use an array of size 26 to store the frequency of each character in the string. This allows efficient lookup of character counts.
- **Traversal for Unique Characters**: By traversing the string once from each direction (left to right for Shanky and right to left for Anku), we efficiently determine the first unique character each player encounters.
- **Comparison and Result Determination**: After identifying the unique characters (or lack thereof), we compare their ASCII values to decide the winner or declare Pandey as the winner if there's a tie or no unique characters.

This approach ensures that we handle each test case efficiently, even for the upper constraint limits, by maintaining linear time complexity O(n) per test case.
