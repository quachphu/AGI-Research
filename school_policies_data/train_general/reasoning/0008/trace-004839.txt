To solve this problem, we need to determine the position of the first occurrence of a specific digit in the decimal expansion of a fraction after the decimal point. The solution involves simulating the long division process to track the digits generated and detect cycles or termination points.

### Approach
1. **Long Division Simulation**: Perform long division manually to generate each digit of the decimal expansion. This involves repeatedly multiplying the remainder by 10, dividing by the denominator to get the next digit, and updating the remainder.
2. **Cycle Detection**: Use a dictionary to track remainders encountered during the division process. If a remainder repeats, it indicates a repeating cycle, and we can conclude that the digit does not appear in the expansion.
3. **Termination Check**: If the remainder becomes zero, the decimal expansion terminates. If the target digit is zero, the next position after termination will be the first occurrence of zero. Otherwise, the digit does not appear.

### Solution Code
```python
def find_first_occurrence():
    import sys
    a, b, c = map(int, sys.stdin.readline().split())
    remainder = a
    seen = {}
    pos = 0
    target = c
    while True:
        pos += 1
        remainder *= 10
        digit = remainder // b
        remainder = remainder % b
        if digit == target:
            print(pos)
            return
        if remainder == 0:
            if target == 0:
                print(pos + 1)
            else:
                print(-1)
            return
        if remainder in seen:
            print(-1)
            return
        seen[remainder] = pos

find_first_occurrence()
```

1. **Reading Input**: The function reads three integers `a`, `b`, and `c` from standard input.
2. **Initial Setup**: The initial remainder is set to `a` (since `a < b`, the integer part of the division is zero).
3. **Digit Generation Loop**:
   - For each iteration, the remainder is multiplied by 10 to shift to the next decimal position.
   - The digit is determined by integer division of the scaled remainder by `b`.
   - The new remainder is updated using modulus operation.
4. **Check for Target Digit**: If the generated digit matches `c`, the current position is printed.
5. **Termination Check**: If the remainder becomes zero, check if the target digit is zero to determine the next position or return -1.
6. **Cycle Detection**: If a remainder repeats, it indicates a cycle, and the function returns -1 as the digit is not found in the expansion.

This approach efficiently tracks the decimal expansion digits, handles termination, and detects cycles to ensure accurate results.
