To solve this problem, we need to determine if a given integer \( n \) can be expressed as the sum of two positive integers such that when added digit by digit, there are no carries. This means each digit of \( n \) must be split into two non-negative integers whose sum equals the digit and does not exceed 9.

### Approach
1. **Check for Valid Digits**: Each digit of \( n \) must be between 0 and 9. However, since \( n \) is given as an integer, this check is implicitly satisfied.
2. **Check for Presence of Digit >= 2**: If any digit in \( n \) is 2 or higher, we can always split \( n \) into two valid positive integers.
3. **Check for Multiple 1s**: If all digits are 0 or 1, we need at least two 1s to form valid positive integers by splitting digits.

### Solution Code
```python
t = int(input())
for _ in range(t):
    s = input().strip()
    if any(c >= '2' for c in s):
        print("YES")
    else:
        ones = s.count('1')
        print("YES" if ones >= 2 else "NO")
```

### Explanation
- **Check for Digits >= 2**: If any digit in \( n \) is 2 or higher, we can split that digit into 1 and the remaining part (e.g., 2 can be split into 1 and 1), ensuring both parts are positive.
- **Check for Multiple 1s**: If there are at least two 1s, we can split them such that one part takes a 1 from one position and the other part takes a 1 from another position, ensuring both resulting numbers are positive.

This approach efficiently checks the necessary conditions in linear time relative to the number of digits in \( n \), ensuring optimal performance even for large values of \( n \).
