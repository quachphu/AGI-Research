To solve this problem, we need to determine how much of a message Raju can type on a T9 keypad within a given time limit, considering the time taken to move his thumb between keys and press the keys.

### Approach
1. **Keypad Mapping**: First, we create a mapping of each character to its corresponding key and the number of presses required to type it. This includes special characters on keys 0 and 1, and lowercase letters on keys 2 to 9.
2. **Time Calculation**: For each character in the message, calculate the time taken to move the thumb to the required key (if different from the current key) and the time taken to press the key the required number of times.
3. **Iterative Check**: For each test case, iterate through each character of the message, accumulating the total time spent. If adding the next character exceeds the time limit, stop and output the part of the message that can be typed within the limit.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1

    # Precompute the character to key and press count mapping
    key_to_chars = {
        '0': ['_', '0'],
        '1': ['.', ',', '?', '!', '1'],
        '2': ['a', 'b', 'c'],
        '3': ['d', 'e', 'f'],
        '4': ['g', 'h', 'i'],
        '5': ['j', 'k', 'l'],
        '6': ['m', 'n', 'o'],
        '7': ['p', 'q', 'r', 's'],
        '8': ['t', 'u', 'v'],
        '9': ['w', 'x', 'y', 'z'],
    }

    char_map = {}
    for key in key_to_chars:
        for pos, char in enumerate(key_to_chars[key]):
            char_map[char] = (key, pos + 1)

    for _ in range(T):
        X = int(input[idx])
        Y = int(input[idx+1])
        Z = int(input[idx+2])
        idx += 3
        M = input[idx]
        idx += 1

        current_key = '1'
        total_time = 0
        result = []

        for c in M:
            key, presses = char_map[c]
            movement = X if key != current_key else 0
            time_needed = movement + Y * presses
            if total_time + time_needed > Z:
                break
            total_time += time_needed
            current_key = key
            result.append(c)

        print(''.join(result))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Keypad Mapping**: The `key_to_chars` dictionary maps each key to its characters. The `char_map` dictionary is then built to map each character to its corresponding key and the number of presses required.
2. **Reading Input**: The input is read and split into tokens for processing. Each test case is processed by reading the values of X, Y, Z, and the message M.
3. **Time Calculation**: For each character in the message, the time required to move the thumb (if necessary) and press the key is calculated. The total time is accumulated, and if it exceeds the allowed time Z, the loop breaks, and the result is printed up to the last valid character.
4. **Output**: The result for each test case is the longest substring of the message that can be typed within the given time limit.

This approach efficiently calculates the time for each character and ensures that the solution is both optimal and easy to understand.
