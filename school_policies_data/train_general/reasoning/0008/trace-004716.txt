We can obtain "Huffman codes" (the third row of the table) using Huffman's algorithm.

The algorithm finds a full binary tree called "Huffman tree" as shown in the following figure.

<image>

To obtain a Huffman tree, for each alphabet character, we first prepare a node which has no parents and a frequency (weight) of the alphabet character. Then, we repeat the following steps:

1. Choose two nodes, $x$ and $y$, which has no parents and the smallest weights.
2. Create a new node $z$ whose weight is the sum of $x$'s and $y$'s.
3. Add edge linking $z$ to $x$ with label $0$ and to $y$ with label $1$. Then $z$ become their parent.
4. If there is only one node without a parent, which is the root, finish the algorithm. Otherwise, go to step 1.



Finally, we can find a "Huffman code" in a path from the root to leaves.

To solve this problem, we need to determine the length of a binary string obtained by encoding a given string using Huffman coding. Huffman coding assigns variable-length codes to characters such that more frequent characters have shorter codes, and no code is a prefix of another. The goal is to compute the total length of the encoded string efficiently.

### Approach
1. **Frequency Count**: First, count the frequency of each character in the input string.
2. **Special Case Handling**: If all characters in the string are the same, the encoded length is simply the length of the string since each character will be represented by a single bit.
3. **Min-Heap Construction**: Use a min-heap (priority queue) to repeatedly combine the two smallest frequencies. This process simulates the construction of a Huffman tree.
4. **Merge Process**: Extract the two smallest frequencies from the heap, merge them, and push the merged result back into the heap. Keep track of the sum of these merges, which directly gives the total encoded length.

### Solution Code
```python
import heapq
from collections import Counter

def main():
    S = input().strip()
    freq = Counter(S)
    
    if len(freq) == 1:
        print(len(S))
        return
    
    heap = list(freq.values())
    heapq.heapify(heap)
    
    total = 0
    while len(heap) > 1:
        x = heapq.heappop(heap)
        y = heapq.heappop(heap)
        merged = x + y
        total += merged
        heapq.heappush(heap, merged)
    
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Frequency Count**: The `Counter` from the `collections` module is used to count the frequency of each character in the input string.
2. **Special Case Handling**: If all characters are the same, the length of the string is returned directly since each character is encoded as a single bit.
3. **Min-Heap Construction**: The frequencies are pushed into a min-heap to always access the two smallest elements efficiently.
4. **Merge Process**: The two smallest frequencies are repeatedly merged, and their sum is accumulated. This sum represents the total encoded length as each merge corresponds to the depth of nodes in the Huffman tree, which directly contributes to the code length of each character.

This approach efficiently computes the total encoded length using Huffman coding by leveraging a priority queue to simulate the tree construction process, ensuring optimal performance even for large input sizes.
