To solve this problem, we need to calculate the sum of the digits of a given integer for multiple test cases. The approach involves reading the input values, processing each integer by summing its digits, and then printing the result for each test case.

### Approach
1. **Read Input**: The first input line contains the number of test cases, T. Each of the next T lines contains an integer N.
2. **Process Each Integer**: For each integer N, convert it to a string to iterate over each character (digit), convert each character back to an integer, and sum these integers.
3. **Output Results**: Print the sum of the digits for each test case.

### Solution Code
```python
def sum_digits():
    t = int(input())
    for _ in range(t):
        n = input().strip()
        print(sum(int(c) for c in n))

sum_digits()
```

### Explanation
1. **Reading Input**: The function starts by reading the number of test cases, T, using `input()`. This value determines how many subsequent lines need to be processed.
2. **Processing Each Integer**: For each test case, the integer N is read as a string. This allows us to iterate over each character in the string, which represents each digit of the integer. Each character is converted to an integer, and the sum of these integers is computed using a generator expression.
3. **Output**: The sum for each test case is printed immediately after processing the corresponding integer, ensuring efficient memory usage and straightforward logic.

This approach efficiently handles the constraints and ensures that each digit is processed in linear time relative to the number of digits in each integer, making it both time and space efficient.
