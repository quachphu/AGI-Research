To solve this problem, we need to determine the number of digits in both base-10 and base-2 representations of the values in Pascal's triangle given their row and column indices. This involves calculating binomial coefficients and converting them to their respective digit counts efficiently.

### Approach
1. **Understanding Pascal's Triangle Entries**: Each entry in Pascal's triangle at row `n` and column `r` corresponds to the binomial coefficient C(n, r), which can be computed using the multiplicative formula to avoid large intermediate values.
2. **Efficient Calculation of Binomial Coefficients**: Using a multiplicative approach to compute C(n, r) step-by-step ensures we handle large numbers efficiently without overflow.
3. **Digit Count Calculation**: 
   - For base-10 digits, convert the number to a string and measure its length.
   - For base-2 digits, use Python's `bit_length()` method to get the number of bits directly.

### Solution Code
```python
def comb(n, r):
    if r > n or r < 0:
        return 0
    if r == 0 or r == n:
        return 1
    r = min(r, n - r)
    result = 1
    for i in range(1, r + 1):
        result = result * (n - r + i) // i
    return result

t = int(input())
for _ in range(t):
    n, r = map(int, input().split())
    c = comb(n, r)
    digits10 = len(str(c))
    digits2 = c.bit_length()
    print(digits10, digits2)
```

### Explanation
1. **Reading Input**: The number of test cases `t` is read first, followed by `t` pairs of integers representing row `n` and column `r`.
2. **Binomial Coefficient Calculation**: The function `comb(n, r)` computes the binomial coefficient using a multiplicative approach to minimize computational overhead and avoid large intermediate values.
3. **Digit Counts**:
   - **Base-10 Digits**: Convert the binomial coefficient to a string and measure its length.
   - **Base-2 Digits**: Use the `bit_length()` method of Python integers to directly get the number of bits required, which is efficient and avoids string conversion.

This approach ensures that the solution is both efficient and accurate, handling large values gracefully using Python's arbitrary-precision integers.
