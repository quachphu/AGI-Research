To solve this problem, we need to determine the number of pairs of strings that are anagrams of each other from a given list of distinct strings. An anagram is a string formed by rearranging the characters of another string. 

### Approach
1. **Canonical Form Representation**: Convert each string into a canonical form by sorting its characters. This allows us to group all anagrams together, as anagrams will have the same sorted character sequence.
2. **Count Frequencies**: Use a hash map (dictionary) to count the occurrences of each canonical form. Each entry in the hash map will represent a group of anagrams.
3. **Calculate Pairs**: For each group of anagrams with `k` elements, the number of valid pairs is given by the combination formula `k * (k - 1) / 2`. Sum these values for all groups to get the total number of anagram pairs.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n = int(sys.stdin.readline())
    counts = defaultdict(int)
    for _ in range(n):
        s = sys.stdin.readline().strip()
        sorted_s = ''.join(sorted(s))
        counts[sorted_s] += 1
    total = 0
    for v in counts.values():
        if v >= 2:
            total += v * (v - 1) // 2
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first line gives the number of strings `N`, followed by `N` strings.
2. **Canonical Form Conversion**: Each string is converted to its sorted character sequence, which serves as the canonical form. This ensures that all anagrams of a string map to the same canonical form.
3. **Frequency Counting**: A dictionary is used to count how many times each canonical form appears.
4. **Pair Calculation**: For each canonical form with `k` occurrences, the number of pairs is calculated using the combination formula and summed up to get the total number of valid anagram pairs.

This approach efficiently groups anagrams and calculates pairs using hash maps and combinatorial counting, ensuring optimal performance even for large input sizes up to 100,000 strings.
