To solve this problem, we need to determine the mode(s) of a given list of integers for multiple test cases. The mode is the number that appears most frequently. If there are multiple modes, they should be printed in non-increasing order.

### Approach
1. **Input Handling**: Read the number of test cases. For each test case, read the number of integers in the list and then the list itself.
2. **Frequency Counting**: Use a dictionary (or `Counter` from the `collections` module) to count the frequency of each integer in the list.
3. **Determine Modes**: Identify the maximum frequency from the frequency counts. Collect all integers that have this maximum frequency.
4. **Sorting Modes**: Sort the collected modes in non-increasing order.
5. **Output**: Print the sorted modes for each test case.

### Solution Code
```python
import sys
from collections import Counter

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        numbers = list(map(int, sys.stdin.readline().split()))
        freq = Counter(numbers)
        max_count = max(freq.values())
        modes = [num for num, cnt in freq.items() if cnt == max_count]
        modes.sort(reverse=True)
        print(' '.join(map(str, modes)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency, especially with large input sizes. The first line gives the number of test cases. For each test case, the number of elements and the elements themselves are read.
2. **Frequency Counting**: The `Counter` class from the `collections` module efficiently counts the occurrences of each integer in the list.
3. **Finding Maximum Frequency**: The maximum value among the frequency counts is determined using `max()`.
4. **Collecting and Sorting Modes**: All integers that have the maximum frequency are collected into a list, which is then sorted in descending order.
5. **Output**: The modes are printed in the required format, space-separated and in non-increasing order.

This approach ensures that we efficiently handle the input size constraints and correctly determine the modes while maintaining optimal performance.
