To solve this problem, we need to determine the knight that each participant was conquered by in a tournament. The tournament consists of multiple fights where each fight eliminates all knights in a specific range except the winner. The goal is to efficiently track the conqueror of each knight using the given fight details.

### Approach
1. **Data Structure**: Use a Disjoint Set Union (DSU) with path compression to efficiently track active knights and mark eliminated knights.
2. **Range Processing**: For each fight, process the range in two parts: left of the winner and right of the winner. This ensures that the winner remains active for future fights.
3. **Elimination Tracking**: For each knight in the fight range (except the winner), mark their conqueror and update the DSU to skip them in subsequent fights.

### Solution Code
```python
import sys

def main():
    sys.setrecursionlimit(1 << 25)
    n, m = map(int, sys.stdin.readline().split())
    parent = list(range(n + 2))  # parent[0] unused, indices 0 to n+1
    conqueror = [0] * (n + 2)  # 1-based to n

    def find(u):
        while parent[u] != u:
            parent[u] = parent[parent[u]]
            u = parent[u]
        return u

    for _ in range(m):
        l, r, x = map(int, sys.stdin.readline().split())
        # Process left part [l, x-1]
        if l <= x - 1:
            current = find(l)
            while current <= x - 1:
                conqueror[current] = x
                parent[current] = find(current + 1)
                current = find(current)
        # Process right part [x+1, r]
        if x + 1 <= r:
            current = find(x + 1)
            while current <= r:
                conqueror[current] = x
                parent[current] = find(current + 1)
                current = find(current)
    
    print(' '.join(map(str, conqueror[1:n+1])))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Initialization**: The DSU (`parent`) is initialized such that each knight points to themselves, indicating they are active. The `conqueror` array is initialized to store the result.
2. **Find Function**: This function uses path compression to quickly find the next active knight.
3. **Processing Fights**: For each fight, the range is split into two parts around the winner. Each part is processed to mark the conqueror of active knights and update the DSU to skip eliminated knights.
4. **Output**: After processing all fights, the `conqueror` array is printed, showing the conqueror of each knight or 0 if they won the tournament.

This approach efficiently handles the constraints using DSU with path compression, ensuring each knight is processed exactly once, leading to an optimal time complexity of O(m α(n)) where α is the inverse Ackermann function.
