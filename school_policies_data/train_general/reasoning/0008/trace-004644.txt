    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr +=1
    for _ in range(T):
        N = int(input[ptr])
        K = int(input[ptr+1])
        ptr +=2
        arr = list(map(int, input[ptr:ptr+N]))
        ptr += N
        min_cost = float('inf')
        # Iterate possible T from 0 to 200 (or higher)
        for T_val in range(0, 201):
            costs = []
            for num in arr:
                if T_val >= num:
                    cost = (T_val - num) *3
                else:
                    cost = (num - T_val)*5
                costs.append(cost)
            costs.sort()
            current_sum = sum(costs[:K])
            if current_sum < min_cost:
                min_cost = current_sum
        print(min_cost)

if __name__ == "__main__":

To solve this problem, we need to determine the minimum cost required to convert at least K elements of an array into equal elements using increment and decrement operations, each with different costs. The solution involves systematically exploring possible target values and calculating the associated costs to find the optimal solution.

### Approach
1. **Problem Analysis**: We need to convert K elements of the array into the same value (target) with the minimum cost. Increment operations cost 3 units each, while decrement operations cost 5 units each.
2. **Key Insight**: For each possible target value, we compute the cost to convert each element of the array to that target. The optimal target value will be the one that results in the minimum sum of the K smallest conversion costs.
3. **Range of Target Values**: Since the elements of the array are integers between 1 and 100, we consider all possible target values from 0 to 200. This range is chosen to cover all feasible values around the minimum and maximum elements of the array, ensuring we don't miss any potential optimal target.
4. **Algorithm**:
   - For each test case, read the array and parameters.
   - For each possible target value (from 0 to 200), compute the conversion costs for all elements.
   - Sort these costs and sum the K smallest costs to determine the minimum cost for that target.
   - Track the minimum cost across all target values and output the result.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        K = int(input[ptr + 1])
        ptr += 2
        arr = list(map(int, input[ptr:ptr + N]))
        ptr += N
        min_cost = float('inf')
        # Check all possible target values from 0 to 200
        for target in range(201):
            costs = []
            for num in arr:
                if target >= num:
                    cost = (target - num) * 3
                else:
                    cost = (num - target) * 5
                costs.append(cost)
            costs.sort()
            current_sum = sum(costs[:K])
            if current_sum < min_cost:
                min_cost = current_sum
        print(min_cost)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
- **Iterating Over Target Values**: We consider each integer target value from 0 to 200. This range is chosen to ensure we cover all potential optimal values around the array's elements.
- **Cost Calculation**: For each target value, compute the conversion cost for each element in the array. The cost depends on whether the target is greater than or less than the element.
- **Sorting and Summing Costs**: After computing the costs for each target, we sort them and sum the K smallest costs to find the minimum cost for that target.
- **Tracking Minimum Cost**: The minimum cost across all target values is tracked and printed for each test case.

This approach efficiently explores all possible target values within a reasonable range, ensuring that the optimal solution is found with minimal computational overhead.
