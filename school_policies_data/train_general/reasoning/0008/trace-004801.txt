To solve this problem, we need to determine the output of a function based on two given integers, a and b. The solution involves a straightforward computation using the modulus operator, which yields the remainder of the division of a by b.

### Approach
The problem requires us to compute the remainder when the integer a is divided by the integer b for each test case. This can be efficiently achieved using the modulus operator (%). Given the constraints that a is non-negative and b is positive, the modulus operation in Python directly gives the correct remainder. The approach involves reading the number of test cases and then processing each pair of integers to compute and print the result of a % b.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    index = 1
    for _ in range(t):
        a = int(input[index])
        b = int(input[index + 1])
        index += 2
        print(a % b)

solve()
```

### Explanation
1. **Reading Input:** The input is read all at once and split into a list of strings for efficient processing. The first element of this list is the number of test cases, t.
2. **Processing Each Test Case:** For each test case, the integers a and b are extracted from the input list. The modulus operation a % b is computed to find the remainder when a is divided by b.
3. **Output the Result:** The result of the modulus operation is printed for each test case, ensuring each result is on a separate line.

This approach efficiently handles the constraints and provides the correct results by leveraging Python's built-in modulus operator, which is well-suited for the given problem constraints.
