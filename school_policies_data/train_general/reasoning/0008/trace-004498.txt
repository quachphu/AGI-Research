To solve this problem, we need to find the Shortest Secret String (SSS) that contains all given words as substrings. The solution should be efficient given the constraints and should also handle lexicographical order in case of ties.

### Approach
1. **Preprocessing**: Remove any words that are substrings of other words. This reduces the number of words we need to consider, making the problem more manageable.
2. **Generate Permutations**: For the remaining words, generate all possible permutations. Each permutation represents a potential order in which words can be merged.
3. **Merge Words**: For each permutation, merge the words by finding the maximum overlap between consecutive words. The goal is to minimize the length of the merged string.
4. **Select Optimal Solution**: Track the shortest merged string. In case of ties, select the lexicographically smallest string.

### Solution Code
```python
import sys
import itertools

def remove_substrings(words):
    filtered = []
    for word in words:
        found = False
        for other in words:
            if word != other and word in other:
                found = True
                break
        if not found:
            filtered.append(word)
    return filtered

def max_merge(a, b):
    max_k = min(len(a), len(b))
    for k in range(max_k, -1, -1):
        if k == 0:
            return a + b
        if a.endswith(b[:k]):
            return a + b[k:]
    return a + b

def get_merged_string(permutation):
    merged = permutation[0]
    for word in permutation[1:]:
        merged = max_merge(merged, word)
    return merged

def solve_case(words):

    best = None
    min_len = float('inf')
    for perm in itertools.permutations(filtered):
        current = get_merged_string(perm)
        if len(current) < min_len or (len(current) == min_len and (best is None or current < best)):
            min_len = len(current)
            best = current
    return best

def main():
    lines = [line.strip() for line in sys.stdin if line.strip()]
    ptr = 0
    while ptr < len(lines):

            words.append(lines[ptr])
            ptr += 1

        print(result)
```

3. **Permutations and Merging**: For each permutation of the filtered words, the `get_merged_string` function merges all words in the permutation order, using the maximum overlap possible between consecutive words.
4. **Optimal Solution**: The `solve_case` function evaluates all permutations, keeping track of the shortest merged string. If multiple strings have the same length, the lexicographically smallest one is chosen.

This approach ensures that we efficiently explore all possible ways to merge the words, leading to the shortest possible string that contains all input words as substrings.
