To solve this problem, we need to determine the optimal lantern for Tommy to hide such that the maximum product of the remaining lanterns (chosen by Banban) is minimized. Tommy and Banban act strategically, with Tommy aiming to minimize the maximum product Banban can achieve, and Banban aiming to maximize it.

### Approach
1. **Problem Analysis**:
   - Tommy hides one lantern from his list.
   - Banban then selects one lantern from Tommy's remaining list and one from his own to maximize the product.
   - The goal is to find the minimum possible value of the maximum product Banban can achieve after Tommy hides one lantern optimally.

2. **Key Insight**:
   - For each lantern Tommy could potentially hide, compute the maximum product Banban can achieve with the remaining lanterns.
   - The solution is the minimum value among all these maximum products.

3. **Algorithm**:
   - Iterate over each lantern in Tommy's list, considering each as the hidden lantern.
   - For each hidden lantern, compute the maximum product Banban can form with the remaining lanterns.
   - Track the minimum of these maximum products to get the final answer.

4. **Complexity**:
   - The algorithm involves iterating over each lantern in Tommy's list (O(n)), and for each, checking all combinations of the remaining lanterns with Banban's lanterns (O((n-1) * m)). This results in a time complexity of O(n^2 * m), which is feasible given the problem constraints (n, m ≤ 50).

### Solution Code
```python
n, m = map(int, input().split())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

min_result = float('inf')

for i in range(n):
    new_a = a[:i] + a[i+1:]
    current_max = -float('inf')
    for x in new_a:
        for y in b:
            product = x * y
            if product > current_max:
                current_max = product
    if current_max < min_result:
        min_result = current_max

print(min_result)
```

### Explanation
- **Reading Input**: The input consists of the number of lanterns Tommy and Banban have, followed by their respective brightness values.
- **Iterating Over Possible Hidden Lanterns**: For each lantern in Tommy's list, we create a new list excluding the current lantern.
- **Computing Maximum Product**: For each remaining lantern in Tommy's list and each lantern in Banban's list, compute the product and track the maximum product.
- **Determining the Result**: Track the minimum value of these maximum products across all possible hidden lanterns, which gives the optimal solution where Tommy's choice minimizes the maximum product Banban can achieve.

This approach ensures that both players act optimally, with Tommy minimizing the worst-case scenario and Banban maximizing the product given the remaining lanterns.
