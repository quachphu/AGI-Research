To solve this problem, we need to determine the state of an array after applying a specific transformation K times. Each transformation involves finding the maximum value in the array and replacing each element with the difference between this maximum value and the element itself. 

### Approach
The key insight here is that after the first two transformations, the array starts to alternate between two states. This observation allows us to optimize the solution by avoiding unnecessary repeated transformations. Here's the step-by-step approach:

1. **Initial Check for K=0**: If no transformations are needed (K=0), return the original array.
2. **First Transformation (K=1)**: Compute the array after one transformation.
3. **Second Transformation (K=2)**: Compute the array after a second transformation.
4. **Determine Result for K>2**: If K is even, the result will be the same as after two transformations. If K is odd, the result will be the same as after one transformation.

This approach ensures that we only perform up to two transformations regardless of the value of K, making the solution efficient even for very large K.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))

if k == 0:
    print(' '.join(map(str, a)))
else:
    max1 = max(a)
    a1 = [max1 - x for x in a]
    if k == 1:
        print(' '.join(map(str, a1)))
    else:
        max2 = max(a1)
        a2 = [max2 - x for x in a1]
        if k % 2 == 0:
            print(' '.join(map(str, a2)))
        else:
            print(' '.join(map(str, a1)))
```

### Explanation
1. **Reading Input**: The input consists of the array size (N), the number of transformations (K), and the array elements.
2. **Handling K=0**: Directly output the original array if no transformations are needed.
3. **First Transformation**: Compute the maximum value of the original array and transform each element to `max - element`.
4. **Second Transformation**: Compute the maximum value of the transformed array from the first step and transform each element again.
5. **Determine Output Based on K**: For K=1, output the first transformed array. For K=2 or any even K, output the second transformed array. For any odd K greater than 1, output the first transformed array.

This method efficiently reduces the problem to a constant number of transformations, ensuring optimal performance even for large values of N and K.
