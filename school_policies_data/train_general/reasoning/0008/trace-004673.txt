To solve this problem, we need to determine the number of valid positions Petr can occupy in a line of `n` people, given that there are at least `a` people in front of him and at most `b` people behind him.

### Approach
1. **Understanding the Constraints**:
   - If Petr is in position `k` (1-based index), there are `k-1` people in front of him and `n-k` people behind him.
   - The constraints are:
     - `k-1 >= a` which simplifies to `k >= a + 1`
     - `n - k <= b` which simplifies to `k >= n - b`

2. **Determine Valid Range**:
   - The valid starting position `start` is the maximum of `a + 1` and `n - b`.
   - The valid ending position is `n` (the last position in the line).

3. **Count Valid Positions**:
   - If the starting position exceeds the ending position, there are no valid positions.
   - Otherwise, the number of valid positions is `end - start + 1`.

### Solution Code
```python
n, a, b = map(int, input().split())
start = max(a + 1, n - b)
end = n
print(end - start + 1 if start <= end else 0)
```

### Explanation
1. **Reading Input**: The input consists of three integers `n`, `a`, and `b`.
2. **Calculating Start Position**: The valid starting position is determined by the maximum of `a + 1` (minimum front people constraint) and `n - b` (maximum behind people constraint).
3. **Calculating End Position**: The end position is always `n` since it's the last possible position in the line.
4. **Counting Valid Positions**: If the start position is within the valid range (<= end), the count is `end - start + 1`, otherwise, it is 0.

This approach efficiently narrows down the valid positions using the given constraints and calculates the result in constant time, ensuring optimal performance.
