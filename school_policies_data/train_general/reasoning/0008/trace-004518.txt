To solve this problem, we need to determine the number of valid pairs of soldiers that can form a reconnaissance unit such that their height difference does not exceed a given value. The pairs (i, j) and (j, i) are considered different and both need to be counted if they meet the condition.

### Approach
1. **Input Reading**: Read the number of soldiers and the maximum allowed height difference from the input.
2. **Check All Pairs**: For each pair of soldiers (i, j) where i ≠ j, check if their height difference is within the allowed limit. Count such valid pairs.
3. **Efficiency**: Given the constraints (n ≤ 1000), a brute-force approach checking all possible pairs (O(n²)) is feasible and efficient enough.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    d = int(input[1])
    a = list(map(int, input[2:2+n]))
    count = 0
    for i in range(n):
        for j in range(n):
            if i != j and abs(a[i] - a[j]) <= d:
                count += 1
    print(count)

main()
```

### Explanation
1. **Reading Input**: The input is read as a single string split into a list of strings. The first two elements are parsed as integers n (number of soldiers) and d (maximum allowed height difference). The subsequent elements are parsed into a list of integers representing the heights of the soldiers.
2. **Nested Loops**: We use nested loops to iterate over all possible pairs of soldiers. For each pair (i, j), we check if they are distinct and if their height difference is within the allowed limit.
3. **Counting Valid Pairs**: Each valid pair (i, j) is counted, and the total count is printed as the result.

This approach ensures that all possible pairs are checked efficiently within the constraints, providing the correct result in O(n²) time complexity.
