To solve this problem, we need to determine the maximum number of valid problem tags that Aniruddha may like, which are strings composed of 'H' and 'E' with no consecutive 'E's. The solution involves dynamic programming to precompute results for all possible values up to the maximum constraint efficiently.

### Approach
1. **Dynamic Programming Setup**: We define two states for each string length `L`:
   - `a[L]`: Number of valid strings of length `L` ending with 'H'.
   - `b[L]`: Number of valid strings of length `L` ending with 'E'.

2. **Transitions**:
   - `a[L]` can be formed by appending 'H' or 'E' to valid strings of length `L-1` ending with either 'H' or 'E'.
   - `b[L]` can only be formed by appending 'E' to valid strings of length `L-1` ending with 'H'.

3. **Precomputation**: Precompute the number of valid strings for each length up to the maximum constraint (1,000,000) and store cumulative sums to allow O(1) query responses.

4. **Efficient Input Handling**: Read all input at once to handle up to 1,000,000 test cases efficiently.

### Solution Code
```python
import sys

MOD = 10**9 + 7
max_n = 10**6

# Precompute the required arrays
a = [0] * (max_n + 2)
b = [0] * (max_n + 2)
sum_dp = [0] * (max_n + 2)

a[1] = 1
b[1] = 1
sum_dp[1] = 2  # Sum for length 1: 1 (H) + 1 (E) = 2

for i in range(2, max_n + 1):
    a[i] = (a[i-1] + b[i-1]) % MOD
    b[i] = a[i-1] % MOD
    current = (a[i] + b[i]) % MOD
    sum_dp[i] = (sum_dp[i-1] + current) % MOD

def main():
    input_data = sys.stdin.read().split()
    T = int(input_data[0])
    results = []
    for n_str in input_data[1:T+1]:
        N = int(n_str)
        results.append(sum_dp[N] % MOD)
    print('\n'.join(map(str, results)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Dynamic Programming Arrays**: `a` and `b` track valid strings ending with 'H' and 'E' respectively. `sum_dp` stores cumulative counts up to each length.
2. **Precomputation**: For each length from 2 to 1,000,000, compute the valid strings using transitions derived from the problem constraints.
3. **Efficient Query Handling**: By precomputing results, each query is answered in constant time, ensuring the solution handles up to 1,000,000 test cases efficiently.

This approach ensures that we handle large inputs efficiently by leveraging precomputation and efficient input/output operations.
