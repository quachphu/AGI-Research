To solve this problem, we need to determine the minimum number of pockets required to distribute coins such that no two coins with the same value are placed in the same pocket. The key insight is that the number of pockets needed is determined by the maximum frequency of any coin value in the list.

### Approach
1. **Problem Analysis**: The problem requires that each coin value can only appear once in each pocket. Therefore, if a coin value appears `k` times, it needs `k` separate pockets. The solution must find the maximum frequency of any coin value, as this will dictate the minimum number of pockets required.
2. **Algorithm Selection**: We will use a frequency counter to count the occurrences of each coin value. The maximum value in this frequency counter will be our answer.
3. **Complexity Analysis**: Counting the frequency of each element takes linear time, O(n), where n is the number of coins. Finding the maximum frequency also takes linear time, O(m), where m is the number of unique coin values. Thus, the overall time complexity is O(n), which is efficient for the given constraints (n ≤ 100).

### Solution Code
```python
def main():
    import sys
    from collections import Counter
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    counts = Counter(a)
    print(max(counts.values()))

main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first line contains the number of coins, `n`. The second line contains the list of coin values.
2. **Counting Frequencies**: Using `collections.Counter`, we count the occurrences of each coin value efficiently.
3. **Finding Maximum Frequency**: The maximum value from the frequency counter is determined, which gives the minimum number of pockets required. This is printed as the result.

This approach ensures that we efficiently determine the minimum number of pockets needed by leveraging the properties of frequency counting and maximum value extraction.
