To solve this problem, we need to determine the maximum number of days the hobbits can celebrate their party such that every two days share at least one hobbit, but no three days share a common hobbit. 

### Approach
1. **Determine Maximum Days (k):** The maximum number of days, k, is the largest integer such that \( k \times (k-1) / 2 \leq n \). This is derived from the combinatorial requirement that each pair of days must share a unique hobbit.
2. **Generate Guest Lists:** Using a combinatorial design approach, each pair of days is assigned a unique hobbit. This ensures that every pair of days shares exactly one hobbit and no three days share a common hobbit.

### Solution Code
```python
n = int(input())

# Calculate the maximum possible k
k = 0
while True:
    next_k = k + 1
    if next_k * (next_k - 1) // 2 <= n:
        k = next_k
    else:
        break

# Generate the guest lists based on pairs of days
guest_lists = [[] for _ in range(k)]
current_hobbit = 1
for i in range(1, k + 1):
    for j in range(i + 1, k + 1):
        guest_lists[i - 1].append(current_hobbit)
        guest_lists[j - 1].append(current_hobbit)
        current_hobbit += 1

# Output the results
print(k)
for guests in guest_lists:
    print(' '.join(map(str, guests)), end=' \n')
```

### Explanation
1. **Determine k:** The value of k is found by incrementing until the next value exceeds the constraint \( k \times (k-1) / 2 \leq n \). This ensures the maximum number of days while adhering to the problem constraints.
2. **Construct Guest Lists:** For each pair of days, a unique hobbit is assigned. This hobbit is added to the guest lists of both days in the pair. This ensures that every pair of days shares exactly one hobbit and no hobbit is present in three different days, thus meeting the problem's requirements.

This approach efficiently constructs the solution using combinatorial principles, ensuring optimality and correctness.
