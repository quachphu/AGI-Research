To solve this problem, we need to convert a number given in scientific notation into its usual decimal representation with the minimal number of digits after the decimal point. The goal is to ensure that the output is formatted correctly, removing any unnecessary trailing zeros and leading zeros.

### Approach
1. **Input Parsing**: Split the input string into the base part (before 'e') and the exponent part (after 'e').
2. **Construct Digits**: Combine the integer part (a) and the fractional part (d) from the base part into a single string of digits.
3. **Determine Decimal Position**: Calculate the new position of the decimal point after applying the exponent.
4. **Split Integer and Fractional Parts**: Based on the new decimal position, split the digits into the integer part and the fractional part.
5. **Format Output**: Remove leading zeros from the integer part and trailing zeros from the fractional part (if any) to ensure the correct format.

def convert_scientific_to_decimal():
    s = input().strip()
    before_e, exponent_str = s.split('e')
    exponent = int(exponent_str)
    a_part, d_part = before_e.split('.')
    digits = a_part + d_part
    new_decimal_pos = 1 + exponent  # a_part is 1 digit
    len_digits = len(digits)
    
    if new_decimal_pos <= len_digits:
        integer_part = digits[:new_decimal_pos]
        fractional_part = digits[new_decimal_pos:]
    else:
        integer_part = digits + '0' * (new_decimal_pos - len_digits)
        fractional_part = ''
    
    # Process integer part to remove leading zeros
    stripped_integer = integer_part.lstrip('0')
    if not stripped_integer:
        stripped_integer = '0'
    
    # Process fractional part
    if fractional_part:
        if all(c == '0' for c in fractional_part):
            print(stripped_integer)
        else:
            print(f"{stripped_integer}.{fractional_part}")
