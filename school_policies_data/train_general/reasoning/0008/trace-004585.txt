To solve this problem, we need to maximize the bitwise AND of the sums of k consecutive shelves of books. The approach involves using a greedy algorithm combined with dynamic programming to check each bit from the highest possible down to the lowest, ensuring each bit can be set in the result while maintaining valid splits into k shelves.

### Approach
1. **Bitwise Maximization**: Start with a result initialized to 0. For each bit from the highest possible (60 bits due to constraints) down to 0, tentatively set the bit and check if it's possible to split the books into k shelves such that each shelf's sum has all the bits set in the current result.
2. **Dynamic Programming (DP) Check**: For each candidate bit, use a DP approach to determine if the books can be split into k shelves where each shelf's sum, when ANDed with the current candidate mask, equals the candidate mask. This ensures all bits in the candidate mask are set in each shelf's sum.
3. **Prefix Sums**: Precompute prefix sums to efficiently calculate the sum of any subarray, which helps in quickly checking the sums for each potential shelf.

### Solution Code
```python
def main():
    import sys
    n, k = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i + 1] = prefix[i] + a[i]
    
    ans = 0
    for bit in reversed(range(60)):  # Check from highest bit down to 0
        candidate = ans | (1 << bit)
        # DP table to track possible splits
        dp = [[False] * (n + 1) for _ in range(k + 1)]
        dp[0][0] = True  # Base case: 0 shelves, 0 books
        
        for j in range(1, k + 1):
            for i in range(j, n + 1):
                # Check all possible previous splits for j-1 shelves
                for m in range(j-1, i):
                    if dp[j-1][m]:
                        current_sum = prefix[i] - prefix[m]
                        if (current_sum & candidate) == candidate:
                            dp[j][i] = True
                            break  # No need to check further m
        if dp[k][n]:
            ans = candidate
    print(ans)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prefix Sums Calculation**: The prefix sums array is computed to quickly determine the sum of any subarray, which is essential for efficiently checking each potential shelf's sum during the DP checks.
2. **Bitwise Maximization Loop**: Iterate over each bit from the highest (59) down to 0. For each bit, tentatively set it in the candidate mask and check if the books can be split into k shelves with sums that include all bits in the candidate mask.
3. **Dynamic Programming Check**: The DP table `dp[j][i]` tracks whether the first `i` books can be split into `j` shelves. For each shelf count `j` and book count `i`, check all possible previous splits to see if the current subarray sum meets the candidate mask condition. If valid, update the DP table and break early for efficiency.
4. **Result Update**: If the candidate mask is valid (as determined by the DP check), update the result to include the current bit.

This approach ensures that we greedily set the highest possible bits while maintaining valid splits, leading to the maximum possible bitwise AND of the shelf sums.
