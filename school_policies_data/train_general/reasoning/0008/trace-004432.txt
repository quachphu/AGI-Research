To solve this problem, we need to determine the probability that at least two out of k people interviewed by ZS the Coder share the same birthday in a year with 2n days. The result should be presented as an irreducible fraction A/B, where A and B are coprime, and their values modulo 10^6 + 3 are required.

### Approach
1. **Check for Trivial Case**: If the number of people k exceeds the number of days 2n, the probability is 1, so the answer is (1, 1).
2. **Precompute Factorials and Inverses**: Compute factorials and their modular inverses up to 10^6 + 3 using Fermat's Little Theorem for efficient calculations.
3. **Modular Arithmetic**: Use modular arithmetic to handle large numbers efficiently. Compute the numerator and denominator modulo 10^6 + 3.
4. **Euclidean Algorithm**: Compute the greatest common divisor (GCD) of the numerator and denominator modulo 10^6 + 3 to simplify the fraction.

### Solution Code
```python
import sys
import math

MOD = 10**6 + 3

# Precompute factorial and inverse factorial modulo MOD
max_fact = MOD - 1
fact = [1] * (max_fact + 1)
for i in range(1, max_fact + 1):
    fact[i] = fact[i-1] * i % MOD

inv_fact = [1] * (max_fact + 1)
inv_fact[max_fact] = pow(fact[max_fact], MOD-2, MOD)
for i in range(max_fact - 1, -1, -1):
    inv_fact[i] = inv_fact[i+1] * (i+1) % MOD

def main():
    n, k = map(int, sys.stdin.readline().split())
    D = 2 * n
    if k > D:
        print(1, 1)
        return
    x = D % MOD
    if k > x:
        product_mod = 0
    else:
        product_mod = fact[x] * inv_fact[x - k] % MOD
    Dk_mod = pow(x, k, MOD)
    numerator_mod = (Dk_mod - product_mod) % MOD
    denominator_mod = Dk_mod
    g = math.gcd(numerator_mod, denominator_mod)
    A = (numerator_mod // g) % MOD
    B = (denominator_mod // g) % MOD
    print(A, B)

if __name__ == "__main__":
    main()
```

3. **Modular Arithmetic**: The values of the numerator and denominator are computed modulo 10^6 + 3 to manage large numbers. The product of the first k terms modulo 10^6 + 3 is derived using precomputed factorials and their inverses.
