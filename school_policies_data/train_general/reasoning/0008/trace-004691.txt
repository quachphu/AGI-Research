To solve this problem, we need to determine whether the number of flights from Seattle to San Francisco (denoted by transitions from 'S' to 'F') is greater than the number of flights in the opposite direction (from 'F' to 'S') based on a given sequence of daily office locations.

### Approach
1. **Input Reading**: Read the number of days and the sequence of locations.
2. **Transition Counting**: Iterate through the sequence to count transitions between consecutive days:
   - Count transitions from 'S' to 'F'.
   - Count transitions from 'F' to 'S'.
3. **Comparison**: Compare the counts of the two types of transitions. If transitions from 'S' to 'F' are more frequent, output "YES"; otherwise, output "NO".

### Solution Code
```python
n = int(input())
s = input().strip()

s_to_f = 0
f_to_s = 0

for i in range(len(s) - 1):
    current = s[i]
    next_char = s[i + 1]
    if current == 'S' and next_char == 'F':
        s_to_f += 1
    elif current == 'F' and next_char == 'S':
        f_to_s += 1

print("YES" if s_to_f > f_to_s else "NO")
```

### Explanation
- **Input Reading**: The first line of input is read as an integer `n` representing the number of days. The second line is read as a string `s` which denotes the daily office locations.
- **Transition Counting**: We iterate through each consecutive pair of characters in the string. For each pair, we check if the transition is from 'S' to 'F' or from 'F' to 'S', and update the respective counters.
- **Comparison**: After counting all transitions, we compare the two counters. If the count of 'S' to 'F' transitions is greater, we print "YES"; otherwise, we print "NO".

This approach efficiently processes the input in linear time relative to the number of days, ensuring optimal performance even for the upper constraint of 100 days.
