    # Step 1: find largest k where arr[k] < arr[k+1]

    k = len(arr) - 2

To solve this problem, we need to generate the previous and next permutations of a given sequence in lexicographic order. The solution involves using well-known algorithms to find the previous and next permutations efficiently.

### Approach
1. **Understanding Lexicographic Order**: Permutations in lexicographic order are arranged similarly to dictionary order. For example, for the sequence [1, 2, 3], the permutations are ordered as [1, 2, 3], [1, 3, 2], [2, 1, 3], etc.

2. **Next Permutation Algorithm**:
   - Find the largest index `k` such that `a[k] < a[k + 1]`. If no such index exists, the permutation is the last permutation.
   - Find the largest index `l` greater than `k` such that `a[k] < a[l]`.
   - Swap the values of `a[k]` and `a[l]`.
   - Reverse the sequence from `a[k + 1]` to the end.

3. **Previous Permutation Algorithm**:
   - Find the largest index `k` such that `a[k] > a[k + 1]`. If no such index exists, the permutation is the first permutation.
   - Find the largest index `l` greater than `k` such that `a[l] < a[k]`.
   - Swap the values of `a[k]` and `a[l]`.
   - Reverse the sequence from `a[k + 1]` to the end.
