To solve this problem, we need to find the largest perfect power that is at most a given integer X. A perfect power is defined as an integer that can be represented as \( b^p \) where \( b \) is an integer greater than or equal to 1 and \( p \) is an integer greater than or equal to 2.

### Approach
1. **Initialization**: Start by considering the smallest perfect power, which is 1 (since \( 1 = 1^2 \)).
2. **Determine Maximum Exponent**: Calculate the maximum possible exponent \( p \) such that \( 2^p \leq X \). This is derived from the fact that the smallest base (2) raised to the highest possible exponent gives the upper bound for \( p \).
3. **Generate Perfect Powers**: For each exponent from 2 up to the calculated maximum, generate all possible values of \( b^p \) where \( b \) starts from 2 and increments until \( b^p \) exceeds X. Collect all these values in a set to avoid duplicates.
4. **Find the Maximum**: The maximum value in the set of generated perfect powers is the result.

### Solution Code
```python
X = int(input())
perfect_powers = {1}

if X == 1:
    print(1)
else:
    # Determine the maximum exponent p where 2^p <= X
    p_max = 1
    current_p = 2
    while True:
        if (2 ** current_p) > X:
            break
        p_max = current_p
        current_p += 1
    
    # Generate all possible perfect powers for exponents from 2 to p_max
    for p in range(2, p_max + 1):
        b = 2
        while True:
            current = b ** p
            if current > X:
                break
            perfect_powers.add(current)
            b += 1
    
    print(max(perfect_powers))
```

### Explanation
- **Initialization**: We start with the set `{1}` because 1 is always a valid perfect power for any \( X \geq 1 \).
- **Max Exponent Calculation**: We determine the highest exponent \( p \) such that \( 2^p \) does not exceed X. This gives us the range of exponents to check.
- **Generating Powers**: For each exponent \( p \) from 2 up to the calculated maximum, we compute all possible values \( b^p \) starting from \( b = 2 \) until \( b^p \) exceeds X. Each valid value is added to the set.
- **Result Extraction**: The maximum value in the set of generated perfect powers is printed as the result.

This approach efficiently generates all possible perfect powers up to X and ensures we find the largest one using a combination of mathematical bounds and iterative checks.
