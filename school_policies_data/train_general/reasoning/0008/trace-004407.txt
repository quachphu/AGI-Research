To solve this problem, we need to determine the minimum number of attack actions Fennec must perform to defeat all monsters, given that she can use a special move at most K times. The special move instantly reduces a monster's health to zero, so we should use it on the monsters with the highest health to minimize the number of attacks needed.

### Approach
1. **Sort the Health Values**: First, we sort the list of monsters' health values in descending order. This allows us to efficiently identify the K monsters with the highest health values.
2. **Apply Special Moves**: Use the special move on the K monsters with the highest health. This effectively removes these monsters from consideration for attacks.
3. **Sum Remaining Health**: The remaining monsters (after the top K) will need to be defeated using attacks. Sum their health values to get the total number of attacks required.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    K = int(input[1])
    H = list(map(int, input[2:2+N]))
    H.sort(reverse=True)
    total = sum(H[K:])
    print(total)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of monsters (N), the maximum number of special moves (K), and the list of health values (H).
2. **Sorting Health Values**: The health values are sorted in descending order to prioritize the monsters with the highest health for the special moves.
3. **Summing Remaining Health**: After excluding the top K health values (which are eliminated using special moves), the sum of the remaining health values gives the total number of attacks needed. This sum is printed as the result.

This approach ensures that we use the special moves optimally to minimize the number of attacks required, resulting in an efficient solution with a time complexity of O(N log N) due to sorting.
