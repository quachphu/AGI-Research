3. **Track Balance**: Use two counters to track the number of unmatched opening (`open_count`) and closing (`close_count`) brackets as we iterate through the string.
4. **Calculate Flips**: If the number of brackets is even, use the formula derived from the standard problem of minimum bracket flips to balance the string. The formula is `(open_count + 1) // 2 + (close_count + 1) // 2`.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().splitlines()
    T = int(input[0])
    for case in input[1:T+1]:
        line = case.strip()
        n = 0
        open_count = 0
        close_count = 0
        pos = 0
        length = len(line)
        while pos < length:
            # Skip leading spaces
            while pos < length and line[pos] == ' ':
                pos += 1
            if pos >= length:
                break
            # Extract the next token
            start = pos
            while pos < length and line[pos] != ' ':
                pos += 1
            token = line[start:pos]
            if token == '.':
                break
            n += 1
            if token == '{':
                open_count += 1
            else:
                if open_count > 0:
                    open_count -= 1
                else:
                    close_count += 1
        if n % 2 != 0:
            print(-1)
        else:
            total = (open_count + 1) // 2 + (close_count + 1) // 2
            print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read line by line. The first line gives the number of test cases.
2. **Processing Each Test Case**: For each test case, we strip leading and trailing spaces and process each token (bracket) individually.
3. **Tracking Unmatched Brackets**: As we process each bracket, we adjust `open_count` and `close_count` to track unmatched brackets.
4. **Check for Balance**: If the total number of brackets is odd, output -1. Otherwise, compute the minimum flips using the formula derived from the counts of unmatched brackets.

This approach ensures that we efficiently handle even very long input strings without excessive memory usage, processing each token on-the-fly. The solution leverages a well-known formula to determine the minimum flips required, ensuring correctness and optimal performance.
