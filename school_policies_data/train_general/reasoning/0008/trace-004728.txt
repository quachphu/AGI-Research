To solve this problem, we need to determine two divisors greater than 1 for each number in an array such that the sum of these divisors is coprime with the number itself. If no such pair exists, we should return -1 for both divisors.

### Approach
1. **Prime Factorization Check**: For each number, check if it is a prime power (i.e., it can be written as \( p^k \) where \( p \) is a prime and \( k \geq 1 \)). If it is a prime power, it is impossible to find such divisors, so we return -1 for both divisors.
2. **Smallest Prime Factor**: For numbers that are not prime powers, find the smallest prime factor. This factor will be one of the divisors.
3. **Second Divisor Calculation**: Compute the second divisor by dividing the number by the highest power of the smallest prime factor. This ensures the second divisor is coprime with the smallest prime factor, making their sum coprime with the original number.

### Solution Code
```python
import sys

def main():
    max_a = 10**7
    spf = list(range(max_a + 1))
    for i in range(2, int(max_a**0.5) + 1):
        if spf[i] == i:
            for j in range(i*i, max_a + 1, i):
                if spf[j] == j:
                    spf[j] = i

    input = sys.stdin.read().split()
    n = int(input[0])
    a_list = list(map(int, input[1:n+1]))

    result_d1 = []
    result_d2 = []

    for a in a_list:
        if a < 2:
            result_d1.append(-1)
            result_d2.append(-1)
            continue
        factors = {}
        x = a
        while x != 1:
            p = spf[x]
            factors[p] = factors.get(p, 0) + 1
            while x % p == 0:
                x //= p
        primes = list(factors.keys())
        if len(primes) == 1:
            result_d1.append(-1)
            result_d2.append(-1)
        else:
            primes.sort()
            p = primes[0]
            e = factors[p]
            p_power = p ** e
            d1 = p
            d2 = a // p_power
            result_d1.append(d1)
            result_d2.append(d2)

    print(' '.join(map(str, result_d1)))
    print(' '.join(map(str, result_d2)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precompute Smallest Prime Factors (SPF)**: Using a sieve method, we precompute the smallest prime factor for every number up to \( 10^7 \). This allows efficient factorization of any number within this range.
2. **Factorize Each Number**: For each number in the input array, we factorize it using the precomputed SPF array. This helps determine if the number is a prime power.
3. **Check for Prime Power**: If the number is a prime power (only one distinct prime factor), we immediately return -1 for both divisors.
4. **Determine Divisors**: For non-prime power numbers, we find the smallest prime factor and use it to compute the second divisor by dividing the number by the highest power of the smallest prime factor. This ensures the sum of the divisors is coprime with the original number.

This approach efficiently handles the constraints and ensures the solution is computed in a timely manner even for large input sizes.
