    n, s = map(int, input().split())

To solve this problem, we need to determine which part of the verse Vasya should skip to maximize the number of presents he receives. The presents are given based on the number of consecutive parts he can recite within a given time limit, allowing him to skip at most one part.

### Approach
1. **Prefix Sum Calculation**: Compute the prefix sums of the verse parts to efficiently calculate the sum of any subarray.
2. **Binary Search**: Use binary search to determine the maximum number of parts Vasya can recite if he skips a particular part. This involves checking the sum of parts before and after the skipped part.
3. **Iterate Over Possible Skips**: For each possible part to skip, compute the maximum number of parts he can recite using the prefix sums and binary search. Compare this with the maximum parts he can recite without skipping any part to determine the optimal solution.

### Solution Code
```python
import bisect

def solve():
    import sys
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx +=1
    for _ in range(t):
        n, s = int(data[idx]), int(data[idx+1])
        idx +=2
        a = list(map(int, data[idx:idx+n]))
        idx +=n
        
        pre_sum = [0]*(n+1)
        for i in range(n):
            pre_sum[i+1] = pre_sum[i] + a[i]
        
        best = bisect.bisect_right(pre_sum, s) -1
        best_k = 0
        
        for k in range(n):
            ak = a[k]
            s_plus = s + ak
            
            left_l = bisect.bisect_right(pre_sum, s, 0, k+1) -1
            
            p = bisect.bisect_right(pre_sum, s_plus) -1
            if p >= k + 2:
                right_l = p -1
            else:
                right_l = 0
            
            current_max = max(left_l, right_l)
            
            if current_max > best:
                best = current_max
                best_k = k + 1  # 1-based
            elif current_max == best and (best_k == 0 or (k +1) < best_k):
                best_k = k +1
        
        print(best_k)
        
solve()
```

### Explanation
1. **Prefix Sum Calculation**: We compute the prefix sums array `pre_sum` where `pre_sum[i]` is the sum of the first `i` parts. This helps in quickly calculating the sum of any subarray.
2. **Initial Check Without Skipping**: Determine the maximum number of parts Vasya can recite without skipping any part using binary search on the prefix sums.
3. **Iterate Over Each Part**: For each part, calculate the maximum parts he can recite if he skips that part. This involves:
   - **Left Part Check**: Using binary search to find the maximum parts he can recite before the skipped part.
   - **Right Part Check**: Using binary search to find the maximum parts he can recite after the skipped part, adjusting for the skipped part's time.
4. **Update Best Solution**: Track the maximum parts and the corresponding part to skip, ensuring to handle ties by choosing the smallest index if multiple solutions exist.

This approach efficiently handles the constraints and ensures optimal performance using prefix sums and binary search, making the solution both effective and efficient.
