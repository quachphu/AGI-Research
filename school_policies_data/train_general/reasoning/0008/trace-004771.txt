To solve this problem, we need to determine the maximum height of a triangle that Chef can form using a given number of gold coins. The triangle is structured such that each row contains an increasing number of coins, starting from 1 coin in the first row, 2 in the second, and so on. The goal is to find the maximum height for which the sum of the first h natural numbers (triangular number) does not exceed the given number of coins.

### Approach
1. **Problem Analysis**: The sum of the first h natural numbers is given by the formula \( \frac{h(h+1)}{2} \). We need to find the largest h such that this sum is less than or equal to N.
2. **Binary Search**: Instead of iterating through each possible value of h (which would be inefficient for large N), we use binary search to efficiently find the maximum h. This reduces the time complexity to O(log h), where h is the maximum possible height.
3. **Initial Bounds**: The upper bound for h can be approximated using the quadratic formula derived from the sum equation. This gives an initial estimate, which is then refined using binary search.

### Solution Code
```python
import math

def max_triangle_height():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        N = int(input[i])
        low = 0
        high = int(math.sqrt(2 * N)) + 1
        while low <= high:
            mid = (low + high) // 2
            current = mid * (mid + 1) // 2
            if current <= N:
                low = mid + 1
            else:
                high = mid - 1
        print(high)

max_triangle_height()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints. The first value is the number of test cases, followed by the number of coins for each test case.
2. **Binary Search Setup**: For each test case, we initialize the binary search with `low` set to 0 and `high` set to an upper bound derived from the quadratic formula. This upper bound is calculated as \( \sqrt{2N} + 1 \), which ensures we start with a value higher than the possible maximum height.
3. **Binary Search Execution**: The binary search iterates by checking the midpoint value. If the sum of coins required for this midpoint height is within the allowed number of coins, we adjust the lower bound to search for a higher possible height. Otherwise, we adjust the upper bound downward.
4. **Result**: After the loop completes, the upper bound (`high`) gives the maximum height of the triangle that can be formed with the given coins.

This approach efficiently narrows down the possible heights using binary search, ensuring that we quickly find the solution even for large values of N.
