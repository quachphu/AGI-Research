To solve this problem, we need to determine the difference between the maximum and minimum average values of all possible sub-sequences of a given array of integers. The result should be the greatest integer (floor value) of this difference.

### Approach
The key insight to solve this problem efficiently is recognizing that the maximum average value of any sub-sequence is simply the maximum element in the array, and the minimum average value is the minimum element in the array. This is because:
1. The maximum average of any sub-sequence cannot exceed the maximum element in the array, as any sub-sequence including the maximum element alone will have this average.
2. Similarly, the minimum average of any sub-sequence cannot be lower than the minimum element in the array, as any sub-sequence including the minimum element alone will have this average.

Thus, the problem reduces to finding the difference between the maximum and minimum elements of the array and returning the floor value of this difference, which is simply the integer part of the difference.

### Solution Code
```python
n = int(input())
arr = list(map(int, input().split()))
max_val = max(arr)
min_val = min(arr)
print(max_val - min_val)
```

### Explanation
1. **Reading Input**: The code reads the input values, where the first value is the number of elements in the array, followed by the array elements themselves.
2. **Finding Extremes**: Using built-in functions `max` and `min`, the code determines the maximum and minimum values in the array.
3. **Calculating Difference**: The difference between these maximum and minimum values is computed.
4. **Output the Result**: The result is printed directly, which is the integer difference between the maximum and minimum values.

This approach ensures that we efficiently solve the problem in linear time, O(n), where n is the number of elements in the array, making it suitable for large input sizes up to the constraint limit of 500 elements.
