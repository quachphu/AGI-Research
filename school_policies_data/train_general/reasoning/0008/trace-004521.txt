To solve this problem, we need to determine the minimum number of shots Han Solo needs to destroy all stormtroopers on a plane using a laser gun positioned at a specific point. Each shot can destroy all stormtroopers lying on a straight line that passes through the gun's position.

### Approach
1. **Problem Analysis**: The key observation is that each shot can destroy all stormtroopers along a line passing through the gun's position. Thus, the problem reduces to determining how many unique lines pass through the gun's position and at least one stormtrooper.

2. **Direction Vectors**: For each stormtrooper, compute the direction vector from the gun's position to the stormtrooper. Two points lie on the same line through the gun if their direction vectors are scalar multiples of each other. 

3. **Normalization**: To handle direction vectors efficiently, we normalize them by dividing by their greatest common divisor (GCD) and adjusting signs to ensure consistent representation. This ensures that vectors that are scalar multiples are considered the same.

### Solution Code
```python
import math

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    x0 = int(input[idx])
    idx += 1
    y0 = int(input[idx])
    idx += 1
    
    directions = set()
    
    for _ in range(n):
        xi = int(input[idx])
        idx += 1
        yi = int(input[idx])
        idx += 1
        dx = xi - x0
        dy = yi - y0
        
        g = math.gcd(abs(dx), abs(dy))
        a = dx // g
        b = dy // g
        
        if a != 0:
            if a < 0:
                a = -a
                b = -b
        else:
            if b < 0:
                b = -b
        
        directions.add((a, b))
    
    print(len(directions))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints. The first line contains the number of stormtroopers and the gun's coordinates. Subsequent lines contain the coordinates of each stormtrooper.

2. **Direction Calculation**: For each stormtrooper, compute the differences `dx` and `dy` from the gun's position. These differences form the direction vector.

3. **Normalization**: The direction vector is normalized by dividing by the GCD of the absolute values of `dx` and `dy`. The sign of the direction vector is adjusted to ensure a consistent representation (non-negative first component, or non-negative second component if the first is zero).

4. **Unique Directions**: Using a set to store these normalized direction vectors ensures that each unique direction is counted only once. The size of this set gives the minimum number of shots required.

This approach efficiently groups stormtroopers lying on the same line through the gun's position, ensuring the solution is both optimal and correct.
