To solve this problem, we need to determine the shortest time required to transport all boats from one island to another using an optimal strategy. The approach is inspired by the classic bridge-crossing problem, where we aim to minimize the total time by efficiently utilizing the fastest boats to shuttle others.

### Approach
1. **Sort the Boats by Time**: Start by sorting the list of boat times in ascending order. This helps in efficiently selecting the fastest boats for shuttling.
2. **Iterative Pair Processing**: While there are more than three boats left, repeatedly process the two slowest boats using two possible strategies:
   - **Strategy 1**: Use the two fastest boats to shuttle the two slowest. This involves sending the two fastest boats, then the two slowest, and bringing back the fastest boat each time.
   - **Strategy 2**: Use the fastest boat to shuttle each of the two slowest boats individually.
3. **Handle Remaining Boats**: Once three or fewer boats remain, handle them directly:
   - If three boats are left, the total time is the sum of their times.
   - If two boats are left, the time is the maximum of their times.
   - If one boat is left, the time is simply its own time.

### Solution Code
```python
n = int(input())
T = list(map(int, input().split()))
T.sort()
total = 0

while len(T) > 3:
    x = T[0]
    y = T[1]
    a = T[-1]
    b = T[-2]
    option1 = y + x + a + y
    option2 = x * 2 + a + b
    if option1 < option2:
        total += option1
    else:
        total += option2
    T.pop()
    T.pop()

if len(T) == 3:
    total += sum(T)
elif len(T) == 2:
    total += max(T)
else:
    total += T[0]

print(total)
```

### Explanation
1. **Sorting**: By sorting the boat times, we can efficiently access the fastest and slowest boats.
2. **Processing Pairs**: For each pair of the slowest boats, we compute the time required using both strategies and choose the minimum. This ensures that we are always using the optimal method for transporting the slowest boats.
3. **Handling Remaining Boats**: When three or fewer boats remain, we handle them directly as there are no more pairs to process, and the remaining times can be summed or taken as the maximum directly.

This approach ensures that we minimize the total time by leveraging the fastest boats to shuttle the slower ones efficiently, following an optimal strategy derived from the classic bridge-crossing problem.
