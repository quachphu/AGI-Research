To solve this problem, we need to determine which element to remove from a permutation such that the number of records (elements larger than all previous elements) is maximized. If there are multiple such elements, we should return the smallest one.

### Approach
1. **Identify Records**: First, identify the records in the original permutation. A record is an element that is larger than all previous elements.
2. **Prefix and Suffix Arrays**: Use prefix arrays to track the maximum element up to each position and suffix arrays to count the number of records from each position to the end.
3. **Monotonic Stack**: Use a monotonic stack to determine the last position where an element greater than or equal to the current element exists.
4. **Binary Search**: For each element that is not a record, use binary search to find the furthest position where removing an element would still allow the current element to become a record.
5. **Delta Array**: Use a delta array to efficiently compute the number of elements that would become records if each element is removed.

### Solution Code
```python
n = int(input())
p = list(map(int, input().split()))

if n == 1:
    print(p[0])
    exit()

# Compute left_max array
left_max = []
current_max = 0
for num in p:
    current_max = max(current_max, num)
    left_max.append(current_max)

# Compute is_record and record_count
is_record = [False] * n
record_count = [0] * n
current_max = 0
count = 0
for i in range(n):
    if p[i] > current_max:
        is_record[i] = True
        current_max = p[i]
        count += 1
    record_count[i] = count

# Compute L[j] using a monotonic stack
L = [-1] * n
stack = []
for j in range(n):
    while stack and p[stack[-1]] < p[j]:
        stack.pop()
    if stack:
        L[j] = stack[-1]
    else:
        L[j] = -1
    stack.append(j)

# Compute suffix_records
suffix_records = [0] * (n + 1)
for i in range(n-1, -1, -1):
    suffix_records[i] = suffix_records[i+1] + (1 if is_record[i] else 0)

# Initialize delta array for count2
delta = [0] * (n + 2)

for j in range(n):
    if not is_record[j]:
        if j == 0:
            continue
        a = L[j]
        # Binary search to find i0_j
        low = 0
        high = j - 1
        best = -1
        target = p[j]
        while low <= high:
            mid = (low + high) // 2
            if mid == 0:
                prev_max = 0
            else:
                prev_max = left_max[mid - 1]
            if prev_max < target:
                best = mid
                low = mid + 1
            else:
                high = mid - 1
        if best == -1:
            continue
        i0_j = best
        b = min(i0_j, j-1)
        if a > b:
            continue
        delta[a] += 1
        if b + 1 < n:
            delta[b + 1] -= 1

# Compute count2 using prefix sum of delta
count2 = [0] * n
current_delta = 0
for i in range(n):
    current_delta += delta[i]
    count2[i] = current_delta

# Compute the total for each i and find the answer
max_total = -1
result = None

for i in range(n):
    if i == 0:
        pre = 0
    else:
        pre = record_count[i-1]
    count1 = suffix_records[i+1]
    c2 = count2[i]
    total = pre + count1 + c2
    if total > max_total or (total == max_total and (result is None or p[i] < result)):
        max_total = total
        result = p[i]

print(result)
```

### Explanation
1. **Identify Records**: We iterate through the permutation to determine which elements are records.
2. **Prefix and Suffix Arrays**: The `left_max` array keeps track of the maximum element up to each position. The `suffix_records` array counts the number of records from each position to the end.
3. **Monotonic Stack**: This helps efficiently find the last position where an element greater than or equal to the current element exists.
4. **Binary Search**: For each non-record element, binary search determines the furthest position where removing an element allows the current element to become a record.
5. **Delta Array**: This efficiently tracks the number of elements that would become records if each element is removed, using prefix sums to compute the final counts.

This approach ensures that we efficiently compute the result in O(n log n) time, making it suitable for large input sizes.
