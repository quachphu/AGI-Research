To solve this problem, we need to assign each mark in Polycarp's journal to either Safety Studies (subject 1) or Physical Education (subject 2) such that the total average score in both subjects is maximized. Additionally, if there are multiple optimal solutions, we need to choose the lexicographically smallest sequence.

### Approach
1. **Case Handling**:
   - **Equal Marks (a = b)**: Since both subjects have the same number of marks, any assignment will yield the same total average. The lexicographically smallest sequence is obtained by assigning the first `a` marks to subject 1 and the rest to subject 2.
   - **More Safety Studies Marks (a < b)**: To maximize the sum of averages, we assign the largest `a` marks to subject 1. If there are ties in marks, the earliest occurring marks are chosen to ensure lexicographical order.
   - **More PE Marks (a > b)**: To maximize the sum of averages, we assign the largest `b` marks to subject 2. If there are ties in marks, the latest occurring marks are chosen to ensure lexicographical order.

### Solution Code
```python
n = int(input())
a, b = map(int, input().split())
t = list(map(int, input().split()))

output = [2] * n

if a == b:
    output = [1 if i < a else 2 for i in range(n)]
else:
    if a < b:
        # Sort by descending value, then ascending index
        arr = sorted(enumerate(t), key=lambda x: (-x[1], x[0]))
        selected_indices = [x[0] for x in arr[:a]]
        output = [2] * n
        for idx in selected_indices:
            output[idx] = 1
    else:
        # Sort by descending value, then descending index
        arr = sorted(enumerate(t), key=lambda x: (-x[1], -x[0]))
        selected_indices = [x[0] for x in arr[:b]]
        output = [1] * n
        for idx in selected_indices:
            output[idx] = 2

print(' '.join(map(str, output)))
```

### Explanation
- **Input Reading**: The input is read and parsed into the number of marks `n`, the counts `a` and `b`, and the list of marks `t`.
- **Case Handling**:
  - **a = b**: Directly assign the first `a` marks to subject 1 and the rest to subject 2.
  - **a < b**: Sort the marks in descending order of their values and ascending order of their indices. Select the first `a` marks for subject 1.
  - **a > b**: Sort the marks in descending order of their values and descending order of their indices. Select the first `b` marks for subject 2.
- **Output**: The output list is constructed based on the selected indices and printed as a space-separated string.

This approach ensures that the solution is both optimal in terms of maximizing the sum of averages and lexicographically smallest when there are multiple optimal solutions.
