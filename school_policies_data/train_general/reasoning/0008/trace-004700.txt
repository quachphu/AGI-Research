To solve this problem, we need to determine the maximum amount of money Roy can collect by serving sweets to guest families under specific conditions. The key challenge is to efficiently determine the optimal sweet for each guest family based on their size and the constraints provided.

### Approach
1. **Sort Sweets by Sweetness**: First, we sort the sweets in descending order based on their sweetness level. This allows us to efficiently query sweets that meet or exceed a given sweetness requirement using binary search.

2. **Prefix Maximum Array**: We precompute a prefix maximum array where each entry represents the maximum quantity of sweets available up to that point in the sorted list. This helps in quickly determining the maximum quantity of sweets available for any given sweetness level.

3. **Efficient Query Handling**: For each guest family, we use binary search to find the maximum sweetness level that meets or exceeds the family's size. Using the prefix maximum array, we then determine the maximum quantity of sweets that can be evenly distributed to the family members, ensuring optimal resource utilization.

import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    
    n = int(input[ptr])
    ptr += 1
    
    sweets = []
    for _ in range(n):
        s = int(input[ptr])
        q = int(input[ptr+1])
        ptr += 2
        sweets.append((s, q))
    
    # Sort sweets in descending order of sweetness (s), ascending order of q (not necessary)
    sweets.sort(key=lambda x: (-x[0], x[1]))
    sorted_s_desc = [s for s, q in sweets]
    sorted_q = [q for s, q in sweets]
    
    # Compute prefix max array for quantities
    prefix_max = [0] * n
    if n > 0:
        prefix_max[0] = sorted_q[0]
        for i in range(1, n):
            prefix_max[i] = max(prefix_max[i-1], sorted_q[i])
    
    # Prepare sorted_neg for bisect operations (list of -s in ascending order)
    sorted_neg = [-s for s in sorted_s_desc]
    
    g = int(input[ptr])
    ptr += 1
    
    total = 0
    for _ in range(g):
        m = int(input[ptr])
        ptr += 1
        target = -m
        
        # Find the number of elements in sorted_neg <= target
        count = bisect.bisect_right(sorted_neg, target)
        if count == 0:
            continue  # No sweets available for this M
        else:
            max_q = prefix_max[count - 1]
            r = (max_q // m) * 100
            total += r
    
    print(total)

if __name__ == "__main__":
    main()
