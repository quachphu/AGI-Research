To solve this problem, we need to determine the minimum number of additional cards Vanya needs to find to make the sum of all his cards equal to zero. Each card can have a value between -x and x (inclusive), where x is given.

### Approach
1. **Calculate the Sum of Found Cards**: First, compute the sum of the values on the cards Vanya has already found.
2. **Check for Zero Sum**: If the sum is already zero, no additional cards are needed.
3. **Determine Minimum Cards Needed**: If the sum is non-zero, compute the absolute value of the sum. The minimum number of cards required is determined by dividing this absolute value by x and taking the ceiling of the result. This can be efficiently computed using integer arithmetic as \((\text{abs(sum)} + x - 1) // x\), which effectively rounds up the division.

### Solution Code
```python
n, x = map(int, input().split())
cards = list(map(int, input().split()))
s = sum(cards)
if s == 0:
    print(0)
else:
    target = abs(s)
    print((target + x - 1) // x)
```

### Explanation
1. **Reading Input**: The input consists of two integers, n (number of found cards) and x (maximum absolute value), followed by n integers representing the values on the found cards.
2. **Sum Calculation**: Compute the sum of the found cards.
3. **Zero Check**: If the sum is zero, immediately print 0 as no additional cards are needed.
4. **Ceiling Calculation**: For a non-zero sum, compute the minimum number of cards needed by dividing the absolute value of the sum by x, rounding up using integer arithmetic to avoid floating-point operations.

This approach efficiently determines the solution with a time complexity of O(n), which is optimal given the constraints.
