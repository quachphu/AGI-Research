To solve this problem, we need to determine the minimum number of coins Little Chef needs to spend to buy an air ticket costing \( N \) using coins that are powers of \( K \), with each power available up to \( K \) times. 

### Approach
1. **Understanding the Coin System**: The coins available are \( K^0, K^1, K^2, \ldots \). Each coin can be used up to \( K \) times.
2. **Greedy Algorithm**: The optimal strategy is to use the highest denomination coins as much as possible, then move to lower denominations. This approach ensures minimal coin usage.
3. **Special Case Handling**: If \( K = 1 \), the only coin available is 1, so the answer is simply \( N \).
4. **Iterative Calculation**: For \( K > 1 \), iteratively compute the highest power of \( K \) that fits into the remaining value of \( N \), use as many of those coins as allowed (up to \( K \)), and reduce \( N \) accordingly until it reaches zero.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        N = int(input[idx])
        K = int(input[idx + 1])
        idx += 2
        if K == 1:
            print(N)
            continue
        count = 0
        current = 1
        # Find the highest power of K that is <= N
        while current * K <= N:
            current *= K
        # Process each power from highest to lowest
        while current >= 1:
            if N >= current:
                max_coins = min(N // current, K)
                count += max_coins
                N -= max_coins * current
                if N == 0:
                    break
            current //= K
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and split into tokens for efficient processing, especially given the constraints.
2. **Handling \( K = 1 \)**: Directly output \( N \) since each coin is 1 and we need exactly \( N \) coins.
3. **Finding the Highest Power**: Calculate the highest power of \( K \) that is less than or equal to \( N \).
4. **Greedy Coin Usage**: For each power from highest to lowest, use as many coins as possible (up to \( K \) times) and reduce \( N \) accordingly. This ensures the minimum number of coins are used by leveraging higher denominations first.

This approach efficiently handles the constraints and ensures the solution is optimal, even for very large values of \( N \) and \( K \).
