To solve this problem, we need to determine the maximum number of layers in a kagami mochi (rice cake stack) using given mochi diameters, where each layer must be smaller than the one below it.

### Approach
1. **Understanding the Problem**: The key insight is that each layer in the stack must have a strictly smaller diameter than the layer below it. Therefore, the maximum number of layers is determined by the number of unique diameters when sorted in descending order.
2. **Removing Duplicates**: Since duplicate diameters cannot be used in consecutive layers, we first eliminate duplicates by converting the list of diameters into a set.
3. **Sorting**: Convert the set of unique diameters back into a list and sort it in descending order. The length of this sorted list gives the maximum number of layers possible.

### Solution Code
```python
n = int(input())
diameters = [int(input()) for _ in range(n)]
unique_diameters = sorted(set(diameters), reverse=True)
print(len(unique_diameters))
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` followed by `n` integers representing the diameters of the mochi.
2. **Removing Duplicates**: By converting the list of diameters into a set, we remove any duplicate values.
3. **Sorting**: The unique diameters are sorted in descending order to form the layers of the kagami mochi. The length of this sorted list of unique diameters is the maximum number of layers possible.

This approach efficiently computes the solution by leveraging set operations and sorting, ensuring that we only consider each diameter once and in the correct order. The time complexity is dominated by the sorting step, making it O(n log n), which is efficient given the problem constraints.
