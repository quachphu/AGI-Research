To solve this problem, we need to convert the adjacency list representation of a directed graph into an adjacency matrix representation. The adjacency matrix will be an \( n \times n \) matrix where each element \( a_{ij} \) is 1 if there is an edge from vertex \( i \) to vertex \( j \), and 0 otherwise.

### Approach
1. **Read Input**: First, read the number of vertices \( n \).
2. **Initialize Matrix**: Create an \( n \times n \) matrix initialized with zeros.
3. **Populate Matrix**: For each vertex entry in the adjacency list, update the matrix to reflect the edges. Specifically, for each vertex \( u \) and its adjacent vertices, set the corresponding entries in the matrix to 1.
4. **Output Matrix**: Print the matrix row by row, with each element separated by a space.

### Solution Code
```python
def main():
    n = int(input())
    matrix = [[0] * n for _ in range(n)]
    for _ in range(n):
        parts = list(map(int, input().split()))
        u = parts[0]
        vs = parts[2:]  # since parts[1] is the degree, the rest are adjacent vertices
        for v in vs:
            matrix[u-1][v-1] = 1
    for row in matrix:
        print(' '.join(map(str, row)))

main()
```

### Explanation
1. **Reading Input**: The input starts with an integer \( n \) representing the number of vertices. Each subsequent line describes the adjacency list for a vertex \( u \), including its degree and the adjacent vertices.
2. **Matrix Initialization**: An \( n \times n \) matrix is created using a list comprehension, initialized with zeros.
3. **Updating the Matrix**: For each vertex \( u \), the adjacency list is parsed. The matrix entry at position \([u-1][v-1]\) is set to 1 for each adjacent vertex \( v \) (adjusting for 0-based indexing in Python).
4. **Printing the Matrix**: Each row of the matrix is converted to a string of space-separated values and printed.

This approach efficiently constructs the adjacency matrix by directly mapping the edges from the adjacency list, ensuring an accurate representation of the graph. The time complexity is \( O(n + m) \), where \( m \) is the number of edges, making it efficient for the given constraints.
