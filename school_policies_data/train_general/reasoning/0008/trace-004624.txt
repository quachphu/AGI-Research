To solve this problem, we need to determine the number of positive integers that can divide all elements of a given array. This can be efficiently achieved by leveraging the greatest common divisor (GCD) of the array and finding the number of divisors of this GCD.

### Approach
1. **Compute the GCD of the Array**: The common divisors of all elements in the array must be divisors of the GCD of the entire array. This is because any number that divides every element of the array must also divide their GCD.
2. **Factorize the GCD**: Once we have the GCD, we factorize it into its prime factors. The number of divisors of a number is determined by its prime factorization. For a number \( n \) with prime factorization \( p_1^{e1} \times p_2^{e2} \times \ldots \times p_k^{ek} \), the number of divisors is \( (e1 + 1) \times (e2 + 1) \times \ldots \times (ek + 1) \).

### Solution Code
```python
import sys
import math
from functools import reduce

def main():
    n = int(sys.stdin.readline())
    arr = list(map(int, sys.stdin.readline().split()))
    
    # Compute the GCD of all elements in the array
    gcd_all = reduce(math.gcd, arr)
    
    # Function to factorize a number into its prime factors
    def factorize(x):
        factors = {}
        if x == 1:
            return factors  # 1 has no prime factors
        # Handle divisibility by 2
        while x % 2 == 0:
            factors[2] = factors.get(2, 0) + 1
            x = x // 2
        # Check odd divisors starting from 3
        i = 3
        max_factor = math.isqrt(x) + 1
        while i <= max_factor and x > 1:
            while x % i == 0:
                factors[i] = factors.get(i, 0) + 1
                x = x // i
                max_factor = math.isqrt(x) + 1  # Update max_factor after division
            i += 2
        # If remaining x is a prime number greater than 2
        if x > 1:
            factors[x] = 1
        return factors
    
    # Handle the case where GCD is 1
    if gcd_all == 1:
        print(1)
        return
    
    # Factorize the GCD and compute the number of divisors
    factors = factorize(gcd_all)
    count = 1
    for exp in factors.values():
        count *= (exp + 1)
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of the number of elements and the array itself.
2. **Computing GCD**: Using Python's `reduce` and `math.gcd`, we compute the GCD of the entire array.
3. **Factorizing the GCD**: The GCD is factorized into its prime factors using trial division up to the square root of the GCD, which is efficient for large numbers.
4. **Counting Divisors**: The number of divisors is calculated by multiplying the increments of each exponent in the prime factorization. This gives the total number of positive integers that can divide all elements of the array.

This approach ensures that we efficiently compute the result even for large input sizes and values, adhering to the problem constraints.
