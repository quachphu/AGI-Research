To solve this problem, we need to convert a given temperature in Fahrenheit to Celsius using a simplified method. The conversion formula provided is \( C = \frac{F - 30}{2} \), where \( F \) is the temperature in Fahrenheit and \( C \) is the temperature in Celsius. The input will be an even integer between 30 and 100, ensuring the result of the conversion is an integer.

### Approach
1. **Reading Input**: The input is a single integer read from standard input.
2. **Conversion Formula**: Apply the formula \( C = \frac{F - 30}{2} \) to convert the Fahrenheit temperature to Celsius. Since the input \( F \) is guaranteed to be an even integer, the result of \( F - 30 \) will also be even, ensuring that dividing by 2 will yield an integer.
3. **Output the Result**: Print the converted Celsius temperature.

### Solution Code
```python
def convert_f_to_c():
    f = int(input())
    c = (f - 30) // 2
    print(c)

convert_f_to_c()
```

### Explanation
1. **Reading Input**: The function `convert_f_to_c` reads the input using `int(input())`, which converts the input string to an integer.
2. **Conversion Calculation**: The formula `(f - 30) // 2` is used to compute the Celsius temperature. Here, integer division (`//`) is used to ensure the result is an integer, which is safe because the input constraints guarantee that \( F - 30 \) is even.
3. **Output**: The result is printed directly using `print(c)`.

This approach efficiently and accurately converts the given Fahrenheit temperature to Celsius using the specified simplified method, ensuring the result is an integer as required.
