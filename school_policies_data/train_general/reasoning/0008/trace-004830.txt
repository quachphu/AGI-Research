To solve this problem, we need to determine the minimum time for Dima to travel from the top-left corner to the bottom-right corner of a grid, considering both direct paths and paths using portals. Portals allow instantaneous travel between any two portals, but the time cost is the sum of their values.

### Approach
1. **Breadth-First Search (BFS) for Direct Paths**: Compute the shortest path from the start (0,0) to all other cells using BFS. Similarly, compute the shortest path from the end (n-1, m-1) to all other cells. This helps us determine the shortest path without using portals.
2. **Portal Utilization**: Identify portals reachable from the start and end. For each portal, calculate the minimum time to reach the portal from the start and from the portal to the end, considering the portal's cost.
3. **Combining Paths**: Compute the minimum time using portals by finding the optimal combination of a portal from the start and a portal to the end. This involves summing the time to reach the start portal, the portal costs, and the time from the end portal to the destination.

### Solution Code
```python
import sys
from collections import deque

def main():
    n, m, w = map(int, sys.stdin.readline().split())
    grid = []
    for _ in range(n):
        row = list(map(int, sys.stdin.readline().split()))
        grid.append(row)
    
    # BFS for start distances (from (0,0))
    s_dist = [[-1] * m for _ in range(n)]
    q = deque()
    q.append((0, 0))
    s_dist[0][0] = 0
    dirs = [(-1, 0), (1, 0), (0, -1), (0, 1)]
    while q:
        x, y = q.popleft()
        for dx, dy in dirs:
            nx, ny = x + dx, y + dy
            if 0 <= nx < n and 0 <= ny < m:
                if grid[nx][ny] != -1 and s_dist[nx][ny] == -1:
                    s_dist[nx][ny] = s_dist[x][y] + 1
                    q.append((nx, ny))
    
    # BFS for end distances (from (n-1, m-1))
    e_dist = [[-1] * m for _ in range(n)]
    q = deque()
    q.append((n-1, m-1))
    e_dist[n-1][m-1] = 0
    while q:
        x, y = q.popleft()
        for dx, dy in dirs:
            nx, ny = x + dx, y + dy
            if 0 <= nx < n and 0 <= ny < m:
                if grid[nx][ny] != -1 and e_dist[nx][ny] == -1:
                    e_dist[nx][ny] = e_dist[x][y] + 1
                    q.append((nx, ny))
    
    # Calculate direct path time
    direct_time = s_dist[n-1][m-1] * w if s_dist[n-1][m-1] != -1 else float('inf')
    
    # Find all reachable portals from start and end
    portals_start = []
    for i in range(n):
        for j in range(m):
            if grid[i][j] > 0 and s_dist[i][j] != -1:
                portals_start.append((i, j))
    
    portals_end = []
    for i in range(n):
        for j in range(m):
            if grid[i][j] > 0 and e_dist[i][j] != -1:
                portals_end.append((i, j))
    
    # Calculate minimal start and end portal costs
    min_start_cost = float('inf')
    for i, j in portals_start:
        cost = s_dist[i][j] * w + grid[i][j]
        if cost < min_start_cost:
            min_start_cost = cost
    
    min_end_cost = float('inf')
    for i, j in portals_end:
        cost = e_dist[i][j] * w + grid[i][j]
        if cost < min_end_cost:
            min_end_cost = cost
    
    portal_time = min_start_cost + min_end_cost if (min_start_cost != float('inf') and min_end_cost != float('inf')) else float('inf')
    
    answer = min(direct_time, portal_time)
    print(-1 if answer == float('inf') else answer)

if __name__ == "__main__":
    main()
```

1. **BFS for Direct Paths**: We use BFS to compute the shortest path from the start and end points to all other cells. This helps in determining the shortest path without using portals and identifying reachable portals.
2. **Portal Handling**: We collect all portals reachable from the start and end. For each portal, we compute the minimum time to reach it from the start and from the portal to the end, considering the portal's cost.
3. **Optimal Portal Combination**: The minimum time using portals is determined by combining the minimal costs from the start and end portals. This is compared with the direct path time to determine the final answer.

This approach efficiently handles large grids and ensures that both direct and portal-based paths are considered, providing the optimal solution.
