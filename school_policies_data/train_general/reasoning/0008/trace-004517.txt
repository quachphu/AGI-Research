To solve this problem, we need to determine the minimum number of supply-line filters Vasya needs to plug all his devices into electricity. The solution involves calculating the net gain in available sockets after using each filter and ensuring that all devices can be accommodated.

### Approach
1. **Sort Filters by Efficiency**: First, sort the supply-line filters in descending order based on the number of sockets they provide. This allows us to use the most efficient filters first, maximizing the net gain in available sockets.
2. **Simulate Filter Usage**: For each possible number of filters (from 0 up to the total number available), simulate the process of plugging in the filters and calculate the resulting available sockets. This simulation checks if each step of plugging in a filter is feasible and ensures that there are enough sockets available at each step.
3. **Check Feasibility**: For each number of filters used, check if the total available sockets after using those filters can accommodate all devices. If it can, record the number of filters used and exit early to find the minimum solution.

### Solution Code
```python
n, m, k = map(int, input().split())
a = list(map(int, input().split()))
a.sort(reverse=True)

for t in range(0, n + 1):
    if t == 0:
        if k >= m:
            print(0)
            exit()
        else:
            continue
    else:
        if t > len(a):
            continue
        sum_a = sum(a[:t])
        available = k + sum_a - t
        if available < m:
            continue
        current_available = k
        valid = True
        for ai in a[:t]:
            if current_available < 1:
                valid = False
                break
            current_available = current_available - 1 + ai
        if valid and current_available >= m:
            print(t)
            exit()

print(-1)
```

4. **Simulate Filter Plugging**: For each number of filters, calculate the total available sockets after using those filters. Simulate plugging each filter step-by-step to ensure each step is feasible (i.e., there is always at least one socket available to plug the next filter).
5. **Check Final Availability**: After simulating the use of the filters, check if the final available sockets can accommodate all devices. If yes, print the number of filters used and exit. If no valid configuration is found, print -1.
