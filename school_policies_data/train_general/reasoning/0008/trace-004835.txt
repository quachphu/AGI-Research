To solve this problem, we need to determine the time George went to bed based on the current time and the duration he slept. The solution involves converting the given times into total minutes, performing the necessary arithmetic operations, and then converting the result back into the required time format.

### Approach
1. **Parse Input Times**: Convert the given current time `s` and sleep duration `t` from "hh:mm" format into total minutes since midnight.
2. **Calculate Bedtime in Minutes**: Subtract the total minutes of sleep duration from the total minutes of the current time. Use modulo 1440 to handle cases where the result might be negative, effectively wrapping around the 24-hour clock.
3. **Convert Back to Time Format**: Convert the resulting total minutes back into "hh:mm" format, ensuring leading zeros for both hours and minutes.

### Solution Code
```python
def bedtime():
    s = input().strip()
    t = input().strip()
    
    s_hh, s_mm = map(int, s.split(':'))
    s_total = s_hh * 60 + s_mm
    
    t_hh, t_mm = map(int, t.split(':'))
    t_total = t_hh * 60 + t_mm
    
    p_total = (s_total - t_total) % 1440
    p_hh = p_total // 60
    p_mm = p_total % 60
    
    print(f"{p_hh:02d}:{p_mm:02d}")

bedtime()
```

### Explanation
1. **Parsing Input**: The input times `s` and `t` are split into hours and minutes, which are then converted into total minutes since midnight. This conversion simplifies arithmetic operations.
2. **Calculating Bedtime**: By converting both times into total minutes, we can directly subtract the sleep duration from the current time. Using modulo 1440 ensures that any negative result (indicating the previous day) is correctly wrapped around to a valid time within the 24-hour period.
3. **Formatting Output**: The result in total minutes is converted back into hours and minutes. The `f"{p_hh:02d}:{p_mm:02d}"` format string ensures that both hours and minutes are displayed as two-digit numbers, maintaining the correct time format.

This approach efficiently handles all edge cases, including times that roll over to the previous day, by leveraging modular arithmetic and proper string formatting.
