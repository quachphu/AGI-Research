To solve this problem, we need to determine if two lines AB and CD are orthogonal (perpendicular) given four points on a plane. The solution involves using vector mathematics to check the orthogonality of the lines.

### Approach
1. **Vector Representation**: For each line defined by two points, compute the direction vector. For line AB, the direction vector is obtained by subtracting the coordinates of point A from point B. Similarly, for line CD, subtract the coordinates of point C from point D.
2. **Dot Product Calculation**: The dot product of two vectors is a scalar value that can be used to determine if the vectors are perpendicular. If the dot product of the direction vectors of AB and CD is zero, the lines are orthogonal.
3. **Floating-Point Precision Handling**: Due to potential floating-point precision issues, we check if the absolute value of the dot product is within a small threshold (1e-8) to determine if it is effectively zero.

### Solution Code
```python
import sys

def main():
    epsilon = 1e-8
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        coords = list(map(float, line.split()))
        xA, yA, xB, yB, xC, yC, xD, yD = coords
        ab_x = xB - xA
        ab_y = yB - yA
        cd_x = xD - xC
        cd_y = yD - yC
        dot_product = ab_x * cd_x + ab_y * cd_y
        if abs(dot_product) < epsilon:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads multiple datasets from standard input, each containing the coordinates of four points.
2. **Vector Calculation**: For each dataset, the direction vectors of lines AB and CD are computed.
3. **Dot Product Check**: The dot product of these vectors is calculated. If the absolute value of the dot product is below the threshold (1e-8), the lines are considered orthogonal, and "YES" is printed; otherwise, "NO" is printed.

This approach efficiently checks for orthogonality using vector mathematics and handles potential floating-point precision issues, ensuring accurate results.
