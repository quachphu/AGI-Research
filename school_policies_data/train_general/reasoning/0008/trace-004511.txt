To solve this problem, we need to determine the optimal way to arrange wooden sticks such that the end of the resulting polyline is as far as possible from the origin (0, 0). The key constraint is that consecutive sticks must alternate between horizontal and vertical directions. The solution involves maximizing the squared distance from the origin by strategically grouping the sticks.

### Approach
1. **Sort the Sticks**: First, sort the sticks in descending order of their lengths. This allows us to use the longest sticks first, which contributes more significantly to the distance.
2. **Determine Group Sizes**: Based on the number of sticks (n), determine the sizes of two groups:
   - If n is even, split the sticks into two equal groups.
   - If n is odd, split the sticks into two groups where one group has one more stick than the other.
3. **Sum the Groups**: Calculate the sum of the lengths of the sticks in each group. The first group will consist of the largest sticks, and the second group will consist of the remaining sticks.
4. **Compute the Result**: The maximum squared distance is the sum of the squares of the sums of the two groups.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
a.sort(reverse=True)

if n % 2 == 0:
    m = n // 2
    sum1 = sum(a[:m])
    sum2 = sum(a[m:])
else:
    m1 = (n + 1) // 2
    sum1 = sum(a[:m1])
    sum2 = sum(a[m1:])

print(sum1 ** 2 + sum2 ** 2)
```

### Explanation
1. **Sorting**: By sorting the sticks in descending order, we ensure that the longest sticks are considered first, maximizing their contribution to the distance.
2. **Grouping Strategy**:
   - For an even number of sticks, splitting them into two equal groups ensures that each group contributes optimally to the horizontal and vertical directions alternately.
   - For an odd number of sticks, the larger group (by one stick) is assigned to the direction that will be used one more time, maximizing the contribution from the additional stick.
3. **Sum Calculation**: The sums of the groups are computed directly from the sorted list, ensuring the largest possible values for both groups.
4. **Result Calculation**: The squared distance is computed as the sum of the squares of the two group sums, which gives the maximum possible value due to the optimal grouping strategy.

This approach efficiently handles up to 100,000 sticks with a time complexity dominated by the sorting step, O(n log n), which is feasible for large inputs.
