To solve this problem, we need to determine the maximum absolute difference between the number of remaining test tabs and social network tabs after closing every k-th tab starting from a chosen position. The goal is to find the optimal starting position that maximizes this difference.

### Approach
1. **Understand Tab Closing Mechanism**: Roman closes tabs in an arithmetic sequence starting from a chosen position `b` with a step size `k`. This means closing all tabs that are congruent to `b` modulo `k`.
2. **Residue Classes**: For each possible residue class modulo `k` (from 0 to k-1), calculate the effect of closing all tabs in that class. Each residue class corresponds to a set of positions that, when closed, will affect the remaining tabs.
3. **Sum Calculation**: Compute the sum of the values of the tabs in each residue class. The sum of the values (where test tabs are +1 and social tabs are -1) directly gives the difference between the number of test and social tabs.
4. **Maximize Difference**: For each residue class, compute the remaining sum after closing those tabs and track the maximum absolute difference.

### Solution Code
```python
def main():
    import sys
    n, k = map(int, sys.stdin.readline().split())
    tabs = list(map(int, sys.stdin.readline().split()))
    total = sum(tabs)
    max_diff = 0

    for r in range(k):
        closed_sum = 0
        count = 0
        for i in range(n):
            if (i + 1) % k == r:
                closed_sum += tabs[i]
                count += 1
        if count == 0:
            continue
        current_diff = abs(total - closed_sum)
        if current_diff > max_diff:
            max_diff = current_diff
    print(max_diff)

main()
```

### Explanation
1. **Reading Input**: The input consists of two integers `n` (number of tabs) and `k` (step size), followed by a list of integers representing the type of each tab.
2. **Total Sum Calculation**: Compute the total sum of the tab values. This sum represents the initial difference between test and social tabs.
3. **Residue Class Evaluation**: For each residue class modulo `k`, determine the sum of the values of the tabs in that class. If no tabs exist in a class, skip it.
4. **Difference Calculation**: For each valid residue class, compute the absolute difference between the total sum and the sum of the closed tabs. Track the maximum difference encountered.
5. **Output the Result**: Print the maximum absolute difference found.

This approach efficiently evaluates all possible ways Roman can close tabs using modular arithmetic and ensures the solution is optimal with a time complexity of O(n * k), which is efficient given the constraints.
