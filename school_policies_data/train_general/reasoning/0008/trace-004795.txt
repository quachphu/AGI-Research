To solve this problem, we need to determine the maximum number of coins each knight can accumulate if they kill other knights, given that each knight can kill up to `k` other knights with lower power. The solution involves sorting the knights by their power and efficiently maintaining the top `k` coins from the weaker knights using a min-heap.

### Approach
1. **Sort Knights by Power**: First, we sort the knights by their power in ascending order. This allows us to process each knight in the order of increasing power, ensuring that each knight can only kill those who come before them in the sorted list.
2. **Maintain a Min-Heap**: As we process each knight, we maintain a min-heap to keep track of the top `k` coins from the knights processed so far. This heap helps efficiently determine the maximum coins a knight can collect from up to `k` victims.
3. **Sum Tracking**: Alongside the heap, we maintain a running sum of the elements in the heap to quickly compute the maximum coins each knight can accumulate without recalculating the sum each time.

### Solution Code
```python
import heapq

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    k = int(input[ptr])
    ptr += 1
    
    p = list(map(int, input[ptr:ptr+n]))
    ptr += n
    c = list(map(int, input[ptr:ptr+n]))
    ptr += n
    
    knights = sorted([(p[i], c[i], i) for i in range(n)], key=lambda x: x[0])
    
    ans = [0] * n
    heap = []
    sum_heap = 0
    
    for power, coins, idx in knights:
        ans[idx] = coins + sum_heap
        
        if k > 0:
            if len(heap) < k:
                heapq.heappush(heap, coins)
                sum_heap += coins
            else:
                if coins > heap[0]:
                    sum_heap -= heapq.heappop(heap)
                    heapq.heappush(heap, coins)
                    sum_heap += coins
    
    print(' '.join(map(str, ans)))

main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of knights `n`, the maximum kills allowed `k`, the power list `p`, and the coins list `c`.
2. **Sorting Knights**: Knights are sorted by their power to ensure we process each knight in the order of increasing power.
3. **Processing Each Knight**: For each knight in the sorted list:
   - The maximum coins they can accumulate is their own coins plus the sum of the top `k` coins from the knights processed before them (maintained in the min-heap).
   - The current knight's coins are added to the heap if they are among the top `k` coins encountered so far, ensuring the heap size does not exceed `k`.
4. **Output**: The results are printed in the original order of the knights.

This approach efficiently tracks the top `k` coins using a min-heap and maintains a running sum, resulting in an optimal solution with a time complexity of O(n log k), which is suitable for large input sizes.
