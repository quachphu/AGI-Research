To solve this problem, we need to determine the topology of a given connected undirected graph. The possible topologies are bus, ring, star, or unknown. Each topology has specific structural characteristics which we can leverage to classify the graph.

### Approach
1. **Bus Topology**: A path graph where exactly two nodes have degree 1 (the endpoints), and all other nodes have degree 2. The number of edges `m` should be `n-1`.
2. **Ring Topology**: A cycle graph where all nodes have degree 2. The number of edges `m` should be equal to the number of nodes `n`.
3. **Star Topology**: A central node connected to all other nodes, resulting in the central node having degree `n-1` and all other nodes having degree 1. The number of edges `m` should be `n-1`.

The solution involves:
1. Reading the input and constructing the degree list for each node.
2. Checking the conditions for each topology in sequence based on the number of edges and node degrees.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    m = int(input[ptr])
    ptr += 1

    degrees = [0] * (n + 1)
    for _ in range(m):
        x = int(input[ptr])
        ptr += 1
        y = int(input[ptr])
        ptr += 1
        degrees[x] += 1
        degrees[y] += 1

    if m == n - 1:
        # Check for star topology
        count_center = 0
        count_leaves = 0
        for d in degrees[1:]:
            if d == n - 1:
                count_center += 1
            elif d == 1:
                count_leaves += 1
        if count_center == 1 and count_leaves == n - 1:
            print("star topology")
            return

        # Check for bus topology
        valid_bus = True
        count_ones = 0
        for d in degrees[1:]:
            if d == 1:
                count_ones += 1
            elif d != 2:
                valid_bus = False
        if valid_bus and count_ones == 2:
            print("bus topology")
            return

        print("unknown topology")
    elif m == n:
        # Check for ring topology
        valid_ring = all(d == 2 for d in degrees[1:])
        if valid_ring:
            print("ring topology")
        else:
            print("unknown topology")
    else:
        print("unknown topology")

main()
```

### Explanation
1. **Reading Input**: The input is read and parsed to extract the number of nodes `n` and edges `m`, followed by constructing the degree list for each node.
2. **Star Topology Check**: If `m == n-1`, check if there is exactly one node with degree `n-1` (central node) and all other nodes have degree 1.
3. **Bus Topology Check**: If not a star, check if there are exactly two nodes with degree 1 and all other nodes have degree 2.
4. **Ring Topology Check**: If `m == n`, verify if all nodes have degree 2.
5. **Unknown Topology**: If none of the above conditions are met, the topology is classified as unknown.

This approach efficiently checks each possible topology in sequence based on the number of edges and node degrees, ensuring the solution is both correct and optimal for the given constraints.
