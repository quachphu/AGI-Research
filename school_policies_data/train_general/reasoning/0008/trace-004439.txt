To solve this problem, we need to generate a Fibonacci-like sequence starting with two given numbers A and B, and then find the Nth term in this sequence. The approach involves iteratively computing each term based on the sum of the two preceding terms until we reach the Nth term.

### Approach
1. **Input Handling**: Read three integers A, B, and N from the input.
2. **Base Cases**: Directly return A if N is 1, and B if N is 2, as these are the first two terms of the sequence.
3. **Iterative Calculation**: For N greater than 2, use an iterative approach to compute each subsequent term by summing the previous two terms. This is done using a loop that starts from the third term and continues up to the Nth term.

### Solution Code
```python
def main():
    A, B, N = map(int, input().split())
    if N == 1:
        print(A)
    elif N == 2:
        print(B)
    else:
        prev_prev, prev = A, B
        for _ in range(3, N + 1):
            current = prev_prev + prev
            prev_prev, prev = prev, current
        print(current)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read as a single line containing three integers A, B, and N.
2. **Base Cases Handling**: If N is 1 or 2, the output is simply A or B respectively, as these are the first two terms of the sequence.
3. **Iterative Calculation**: For N greater than 2, we initialize two variables to keep track of the previous two terms (prev_prev and prev). We then iterate from the 3rd term up to the Nth term, updating these variables to the next terms in the sequence by summing them. This loop efficiently computes each subsequent term until the desired Nth term is reached.

This approach ensures that we efficiently compute the Nth term using an iterative method with a time complexity of O(N), which is optimal given the constraints (N ≤ 10).
