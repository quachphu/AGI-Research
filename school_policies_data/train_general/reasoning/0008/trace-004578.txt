To solve this problem, we need to make a table stable by removing some legs such that the remaining legs meet the stability condition with the minimum energy spent. The table is stable if more than half of the legs are of the maximum length present.

### Approach
1. **Sort Legs by Length**: First, we sort the legs by their length in ascending order to facilitate efficient range queries.
2. **Precompute Suffix Sums**: We precompute the suffix sums of the energy costs to quickly determine the cost of removing all legs longer than a given length.
3. **Group Legs by Length**: We group legs by their length and precompute the sorted list of energy costs along with their prefix sums for each group.
4. **Prefix Frequency Array**: We maintain a prefix frequency array to efficiently compute the sum of the top energy costs for any prefix of legs sorted by length.
5. **Iterate Over Possible Lengths**: For each possible maximum length (from the unique lengths present), compute the minimum energy required to make the table stable by considering all valid configurations of legs.

import bisect

n = int(input())
l = list(map(int, input().split()))
d = list(map(int, input().split()))

sorted_legs = sorted(zip(l, d), key=lambda x: x[0])
sorted_l = [x[0] for x in sorted_legs]

# Compute suffix_sum array
suffix_sum = [0] * (n + 1)
for i in range(n-1, -1, -1):
    suffix_sum[i] = suffix_sum[i+1] + sorted_legs[i][1]

total_sum = sum(d)

# Preprocess group_info for each unique length
from collections import defaultdict
groups = defaultdict(list)
for leg in sorted_legs:
    li, di = leg
    groups[li].append(di)

group_info = {}
for li in groups:
    di_list = sorted(groups[li], reverse=True)
    prefix = [0]
    current = 0
    for di in di_list:
        current += di
        prefix.append(current)
    group_info[li] = (di_list, prefix)

# Precompute prefix_freq array
prefix_freq = [[0] * 201]
for i in range(n):
    current_di = sorted_legs[i][1]
    new_freq = prefix_freq[-1].copy()
    new_freq[current_di] += 1
    prefix_freq.append(new_freq)

min_cost = float('inf')

for L in group_info:
    # Find the first index where leg's length > L
    pos = bisect.bisect_right(sorted_l, L)
    cost1 = suffix_sum[pos]
    
    # Find start and end for legs of length L
    start = bisect.bisect_left(sorted_l, L)
    end = bisect.bisect_right(sorted_l, L)
    L_count = end - start
    
    if L_count == 0:
        continue  # Should not happen as L is in group_info
    
    di_list, di_prefix = group_info[L]
    max_sum = 0
    
    for x in range(1, L_count + 1):
        if x >= len(di_prefix):
            sum_L = di_prefix[-1]
        else:
            sum_L = di_prefix[x]
        
        y_max = x - 1
        sum_S = 0
        remaining = y_max
        
        if remaining > 0 and start > 0:
            freq = prefix_freq[start]
