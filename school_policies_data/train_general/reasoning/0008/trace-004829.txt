To solve this problem, we need to determine if we can remove some non-adjacent characters from a binary string such that the remaining string is sorted in non-decreasing order (i.e., all '0's followed by all '1's). 

### Approach
1. **Check if the string is already sorted**: If the given string is already sorted, the answer is immediately "YES".
2. **Evaluate possible splits**: For each possible split point in the string, check if we can remove characters such that the left part of the split contains only '0's and the right part contains only '1's. The positions of the characters to be removed (non-adjacent) must be such that no two positions are consecutive.

### Solution Code
```python
def is_sorted(s):
    for i in range(len(s) - 1):
        if s[i] > s[i + 1]:
            return False
    return True

t = int(input())
for _ in range(t):
    s = input().strip()
    if is_sorted(s):
        print("YES")
        continue
    n = len(s)
    found = False
    for split_i in range(-1, n):
        deletions = []
        for j in range(n):
            if j <= split_i:
                if s[j] == '1':
                    deletions.append(j)
            else:
                if s[j] == '0':
                    deletions.append(j)
        if not deletions:
            continue  # No deletions needed, but original isn't sorted
        valid = True
        for i in range(1, len(deletions)):
            if deletions[i] - deletions[i-1] == 1:
                valid = False
                break
        if valid:
            found = True
            break
    print("YES" if found else "NO")
```

### Explanation
1. **Check Sorted String**: The function `is_sorted` checks if the string is already non-decreasing. If it is, we print "YES".
2. **Evaluate Splits**: For each possible split point in the string, we determine the positions of characters that need to be removed to make the left part all '0's and the right part all '1's. We then check if these positions can be removed without any two being consecutive.
3. **Validation**: For each split, if the positions to be removed are non-consecutive and non-empty, the answer is "YES". If no valid split is found after checking all possibilities, the answer is "NO".

This approach ensures that we efficiently check all possible ways to split the string and remove characters to achieve a sorted result, adhering to the constraints of non-adjacent removals.
