To solve this problem, we need to determine the number of palindromic numbers between two given integers A and B (inclusive). A palindromic number reads the same forwards and backwards. Given the constraints that both A and B are 5-digit numbers, we can efficiently generate all possible 5-digit palindromes and count how many fall within the specified range.

### Approach
1. **Understanding Palindromic Structure**: A 5-digit palindromic number has the form `d1d2d3d2d1`, where `d1`, `d2`, and `d3` are digits. Here, `d1` ranges from 1 to 9 (no leading zero), and `d2` and `d3` range from 0 to 9.
2. **Generate Palindromes**: Generate all possible 5-digit palindromic numbers by iterating through all valid combinations of `d1`, `d2`, and `d3`.
3. **Check Range**: For each generated palindrome, check if it lies within the range [A, B]. Count how many such palindromes meet this condition.

### Solution Code
```python
a, b = map(int, input().split())

count = 0

for d1 in range(1, 10):
    for d2 in range(0, 10):
        for d3 in range(0, 10):
            num = d1 * 10000 + d2 * 1000 + d3 * 100 + d2 * 10 + d1
            if a <= num <= b:
                count += 1

print(count)
```

### Explanation
- **Generating Palindromes**: The nested loops iterate through all possible values of `d1`, `d2`, and `d3` to form each palindrome. For example, `d1=1`, `d2=2`, `d3=3` forms the palindrome 12321.
- **Range Check**: Each generated palindrome is converted to an integer and checked if it lies within the given range [A, B]. If it does, the count is incremented.
- **Efficiency**: This approach efficiently generates all 900 possible 5-digit palindromes (9 choices for `d1`, 10 each for `d2` and `d3`), making the solution both optimal and easy to understand.

This method ensures that we only generate valid 5-digit palindromes and efficiently check their inclusion in the specified range, leading to an optimal solution.
