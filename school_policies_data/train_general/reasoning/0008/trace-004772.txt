To solve this problem, we need to decrypt a string that has been encrypted using the Right-Left cipher. The encryption process involves alternately appending and prepending characters to build the encrypted string. Our task is to reverse this process to retrieve the original string.

### Approach
1. **Understand the Encryption Process**: The encryption starts with the first character, then alternately appends and prepends subsequent characters. For example, the second character is appended, the third is prepended, the fourth is appended, and so on.
2. **Reverse the Process**: To decrypt, we reverse each step of the encryption process starting from the last character added. This means we need to determine whether each character in the encrypted string was appended or prepended during encryption and remove it accordingly.
3. **Character Removal**: For each character in the encrypted string starting from the end:
   - If the position (in the original string) is even, the character was appended and should be removed from the end.
   - If the position is odd, the character was prepended and should be removed from the beginning.
4. **Reconstruct the Original String**: Collect the removed characters in reverse order and combine them with the remaining character (from the initial step) to form the original string.

### Solution Code
```python
def decrypt():
    t = input().strip()
    m = len(t)
    current = list(t)
    chars = []
    
    for i in range(m, 1, -1):
        if i % 2 == 0:
            # Appended, remove from end
            c = current.pop()
        else:
            # Prepended, remove from start
            c = current.pop(0)
        chars.append(c)
    
    # Add the remaining first character
    chars.append(''.join(current))
    # Reverse to get the original order
    s = ''.join(reversed(chars))
    print(s)
```
