To solve this problem, we need to determine the number of valid pairs (p, q) such that two robots, starting from opposite ends of an array, stop at different positions without meeting. The left robot stops at the first occurrence of p, and the right robot stops at the last occurrence of q. The valid pairs are those where the first occurrence of p is strictly to the left of the last occurrence of q.

### Approach
1. **Identify First and Last Occurrences**: For each unique element in the array, determine the first occurrence (from the left) and the last occurrence (from the right).
2. **Sort First Occurrences**: Collect all first occurrences and sort them to facilitate efficient binary search operations.
3. **Count Valid Pairs**: For each unique element q, determine how many elements p exist such that the first occurrence of p is less than the last occurrence of q. This is efficiently done using binary search on the sorted list of first occurrences.

### Solution Code
```python
import bisect

n = int(input())
a = list(map(int, input().split()))

# Calculate first occurrence of each element
first_occurrence = {}
for i in range(n):
    if a[i] not in first_occurrence:
        first_occurrence[a[i]] = i

# Calculate last occurrence of each element
last_occurrence = {}
for i in range(n - 1, -1, -1):
    if a[i] not in last_occurrence:
        last_occurrence[a[i]] = i

# Sort the first occurrences
sorted_first = sorted(first_occurrence.values())

result = 0
# For each element's last occurrence, count valid first occurrences
for q in last_occurrence:
    L = last_occurrence[q]
    count = bisect.bisect_left(sorted_first, L)
    result += count

print(result)
```

### Explanation
1. **First and Last Occurrences**: We traverse the array once from the left to record the first occurrence of each element and once from the right to record the last occurrence. This helps us quickly determine the stopping positions for each robot given any element.
2. **Binary Search for Efficiency**: By sorting the first occurrences, we can use binary search to efficiently count how many first occurrences are less than a given last occurrence. This reduces the complexity from O(n^2) to O(n log n), making the solution feasible for large input sizes.
3. **Summing Valid Pairs**: For each element's last occurrence, we use binary search to find how many first occurrences are to the left of it. Summing these counts gives the total number of valid pairs, ensuring the robots do not meet.

This approach efficiently handles the constraints and provides the correct result by leveraging sorting and binary search, ensuring optimal performance even for large arrays.
