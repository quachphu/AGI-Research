To solve this problem, we need to count the number of "damn rhombi" in a directed graph. A rhombus consists of four distinct nodes a, b, c, d such that there are two paths from a to c: a→b→c and a→d→c. The order of b and d does not matter when counting.

### Approach
1. **Graph Representation**: Use adjacency sets to represent outgoing edges from each node and incoming edges to each node.
2. **Intersection Calculation**: For each pair of nodes (a, c) where a ≠ c, compute the intersection of nodes that can be reached from a in one step (adj_out[a]) and nodes that can reach c in one step (in_edges[c]). This intersection gives the intermediate nodes through which there are two-step paths from a to c.
3. **Combination Calculation**: For each valid pair (a, c), if the number of intermediate nodes (k) is at least 2, the number of rhombi contributed by this pair is given by the combination formula k choose 2, which is k*(k-1)/2.

### Solution Code
```python
n, m = map(int, input().split())

adj_out = {}
in_edges = {}

for node in range(1, n+1):
    adj_out[node] = set()
    in_edges[node] = set()

for _ in range(m):
    a, b = map(int, input().split())
    adj_out[a].add(b)
    in_edges[b].add(a)

total = 0

for a in range(1, n+1):
    a_adj = adj_out[a]
    if not a_adj:
        continue
    for c in range(1, n+1):
        if a == c:
            continue
        in_c = in_edges[c]
        if not in_c:
            continue
        # Compute the intersection size between a_adj and in_c
        # Iterate through the smaller set for efficiency
        if len(a_adj) < len(in_c):
            count = sum(1 for x in a_adj if x in in_c)
        else:
            count = sum(1 for x in in_c if x in a_adj)
        if count >= 2:
            total += count * (count - 1) // 2

print(total)
```

3. **Combination Calculation**: If the number of intermediate nodes (k) is 2 or more, the number of rhombi formed by choosing any two distinct intermediates is given by the combination formula k choose 2. This value is accumulated to get the total number of rhombi.
