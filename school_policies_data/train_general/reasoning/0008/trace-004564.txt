To solve this problem, we need to determine the minimum number of blows required to defeat Zmei Gorynich, a dragon-like monster with multiple heads. Each blow reduces the number of heads, and if the monster is not defeated, it regenerates some heads. The goal is to find the optimal sequence of blows to defeat the monster in the fewest steps possible.

### Approach
1. **Check for Immediate Kill**: If any blow can immediately reduce the heads to zero (i.e., its damage is at least the initial number of heads), the answer is 1.
2. **Check Feasibility**: If no blow can kill the monster immediately, check if there exists a blow that reduces the number of heads more than the monster can regenerate. If no such blow exists, it is impossible to defeat the monster.
3. **Optimal Blows Calculation**: Use the blow that maximizes the net reduction in heads (damage minus regeneration) repeatedly to reduce the monster's heads to a point where a final blow can finish it off. The number of required blows is calculated based on the maximum net reduction and the most damaging single blow.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, x = map(int, input().split())
    blows = [tuple(map(int, input().split())) for _ in range(n)]
    max_d = max(d for d, h in blows)
    # Check if any blow can kill immediately
    if any(d >= x for d, h in blows):
        print(1)
        continue
    # Check if there's any blow with d > h
    has_valid = any(d > h for d, h in blows)
    if not has_valid:
        print(-1)
        continue
    # Compute the maximum delta (d - h) among valid blows
    delta = max(d - h for d, h in blows if d > h)
    required_k = (x - max_d + delta - 1) // delta
    print(required_k + 1)
```

### Explanation
1. **Immediate Kill Check**: The code first checks if any blow can reduce the monster's heads to zero in one hit. If so, it immediately outputs 1.
2. **Feasibility Check**: If no immediate kill is possible, the code checks if there exists a blow where the damage exceeds the regeneration. If not, the monster cannot be defeated, and the code outputs -1.
3. **Optimal Blows Calculation**: The code calculates the maximum net reduction (damage minus regeneration) and uses this to determine how many times this blow must be used to reduce the heads sufficiently. Finally, the most damaging blow is used once more to finish the monster, resulting in the total number of blows.

This approach ensures that we minimize the number of blows by leveraging the optimal net reduction and the most powerful single strike efficiently.
