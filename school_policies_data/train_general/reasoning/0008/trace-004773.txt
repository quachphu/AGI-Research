To solve this problem, we need to determine the minimum total amount of money required to buy all chocolate bars using one of the given coupons optimally. Each coupon allows us to buy a certain number of bars, with the cheapest one among them being free. Our goal is to find the optimal coupon to minimize the total cost.

### Approach
1. **Sort the Prices**: First, sort the prices of the chocolate bars in descending order. This allows us to efficiently determine the most expensive bars to maximize the discount from the coupon.
2. **Sum Calculation**: Calculate the total sum of all chocolate bar prices. This helps in quickly determining the total cost after applying the coupon.
3. **Coupon Application**: For each coupon, which specifies the number of bars to buy (q_i), the optimal strategy is to select the q_i most expensive bars. The discount will be the price of the cheapest bar among these q_i bars (which is the q_i-th element in the sorted list). The total cost using this coupon is the total sum minus the price of this cheapest bar.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    a = list(map(int, input[ptr:ptr + n]))
    ptr += n
    m = int(input[ptr])
    ptr += 1
    qs = list(map(int, input[ptr:ptr + m]))
    
    sum_total = sum(a)
    a_sorted = sorted(a, reverse=True)
    
    res = []
    for q in qs:
        res.append(str(sum_total - a_sorted[q - 1]))
    
    print('\n'.join(res))

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings for efficient processing.
2. **Sorting**: The prices are sorted in descending order to easily access the most expensive bars.
3. **Total Sum Calculation**: The total sum of all prices is computed once, which helps in quickly determining the total cost after applying each coupon.
4. **Processing Coupons**: For each coupon, the discount is calculated by subtracting the price of the q_i-th most expensive bar (which is the cheapest in the selected group) from the total sum. This value is stored and printed in the required format.

This approach ensures that we efficiently compute the minimum cost for each coupon using sorting and summation, resulting in an optimal solution with a time complexity of O(n log n) due to sorting, which is suitable for the problem constraints.
