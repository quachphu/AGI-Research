To solve this problem, we need to determine if Barney's pineapple is barking at the exact time he wants to eat it. The pineapple barks at specific intervals, and we need to check if the given time falls into one of these intervals.

### Approach
1. **Initial Check**: If the time Barney wants to eat (x) is exactly the first bark time (t), the answer is "YES".
2. **Before First Bark**: If x is before the first bark time (t), the answer is "NO".
3. **Subsequent Barks**: After the first bark, the pineapple barks in pairs every `s` seconds. For each interval `s` after the first bark, the pineapple barks at `t + s` and `t + s + 1`, then `t + 2s` and `t + 2s + 1`, and so on.
4. **Check Subsequent Intervals**: For the time `x` after the first bark, compute the difference `x_prime = x - t`. Check if this difference can be expressed as either `k*s` or `k*s + 1` where `k` is a positive integer. This translates to checking if `x_prime` is a multiple of `s` or if `x_prime - 1` is a multiple of `s`, while ensuring these values are within valid bounds.

### Solution Code
```python
t, s, x = map(int, input().split())

if x == t:
    print("YES")
elif x < t:
    print("NO")
else:
    x_prime = x - t
    if (x_prime >= s and x_prime % s == 0) or (x_prime - 1 >= s and (x_prime - 1) % s == 0):
        print("YES")
    else:
        print("NO")
```

### Explanation
1. **Initial Check**: Directly check if `x` is equal to `t`.
2. **Before First Bark**: If `x` is less than `t`, immediately return "NO".
3. **Subsequent Barks Calculation**: Calculate `x_prime` as the difference between `x` and `t`.
4. **Check Valid Intervals**: 
   - Check if `x_prime` is a non-negative multiple of `s` and at least `s`.
   - Check if `x_prime - 1` is a non-negative multiple of `s` and at least `s` (to ensure valid intervals after the first pair).

This approach efficiently checks the conditions using arithmetic operations, ensuring the solution is both optimal and easy to understand.
