To solve this problem, we need to determine how many unique ways two given matrices can be multiplied. The solution involves checking the conditions for matrix multiplication for both possible orders of the matrices (A*B and B*A).

### Approach
1. **Matrix Multiplication Conditions**: For two matrices A (with dimensions x1 rows and y1 columns) and B (with dimensions x2 rows and y2 columns), matrix multiplication A*B is possible if the number of columns of A (y1) is equal to the number of rows of B (x2). Similarly, matrix multiplication B*A is possible if the number of columns of B (y2) is equal to the number of rows of A (x1).
2. **Count Valid Multiplications**: For each test case, we check both possible orders (A*B and B*A). If the conditions for multiplication are met for an order, we increment our count. The result for each test case is the sum of valid multiplications.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        x1 = int(input[idx])
        y1 = int(input[idx+1])
        x2 = int(input[idx+2])
        y2 = int(input[idx+3])
        idx += 4
        cnt = 0
        if y1 == x2:
            cnt += 1
        if y2 == x1:
            cnt += 1
        print(cnt)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings for easier processing. The first value is the number of test cases, T.
2. **Processing Each Test Case**: For each test case, we extract the dimensions of the two matrices (x1, y1, x2, y2).
3. **Check Multiplication Feasibility**: We check if matrix multiplication is possible in both orders (A*B and B*A) by comparing the columns of the first matrix with the rows of the second matrix for each order.
4. **Count and Output**: For each valid multiplication possibility, we increment the count and print the result for each test case.

This approach efficiently checks the necessary conditions for matrix multiplication in both possible orders and counts the valid possibilities, ensuring an optimal solution with a time complexity of O(T) where T is the number of test cases.
