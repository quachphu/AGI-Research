To solve this problem, we need to determine the maximum length of a substring consisting of equal characters ('a' or 'b') that can be achieved by changing no more than `k` characters in the given string. This can be efficiently solved using a sliding window technique to explore both possibilities of converting characters to 'a' or 'b'.

### Approach
1. **Sliding Window Technique**: The sliding window technique is used to find the longest substring where the number of differing characters (either 'a' or 'b') can be converted within the allowed limit `k`.
2. **Two Passes**: We perform two separate passes over the string:
   - One pass considering the maximum substring of 'a's by converting up to `k` 'b's.
   - Another pass considering the maximum substring of 'b's by converting up to `k` 'a's.
3. **Helper Function**: A helper function `max_beauty` is used to compute the maximum length of the substring for a given target character ('a' or 'b') by allowing up to `k` conversions of the other character.

### Solution Code
```python
def max_beauty(s, k, target_char):
    left = 0
    max_len = 0
    count = 0  # count of characters different from target_char
    for right in range(len(s)):
        if s[right] != target_char:
            count += 1
        # Shrink the window until the count is within k
        while count > k:
            if s[left] != target_char:
                count -= 1
            left += 1
        current_len = right - left + 1
        if current_len > max_len:
            max_len = current_len
    return max_len

n, k = map(int, input().split())
s = input().strip()

max_a = max_beauty(s, k, 'a')
max_b = max_beauty(s, k, 'b')
print(max(max_a, max_b))
```

### Explanation
1. **Reading Input**: The input consists of the string length `n`, the maximum allowed conversions `k`, and the string `s`.
2. **Helper Function `max_beauty`**:
   - This function uses a sliding window approach to maintain a window where the count of characters different from the target character (`target_char`) does not exceed `k`.
   - For each character in the string, expand the window to the right. If the count of differing characters exceeds `k`, shrink the window from the left until the count is within the limit.
   - Track the maximum length of valid windows encountered during this process.
3. **Two Passes**: The helper function is called twice, once for 'a' and once for 'b', to determine the maximum possible lengths for converting to each character.
4. **Result**: The maximum value from the two passes is printed as the result.

This approach efficiently computes the solution in linear time, making it suitable for large input sizes up to 100,000 characters.
