To solve this problem, we need to determine the frequency of "Best numbers" (even numbers) in a list of integers for multiple test cases. Each test case consists of a list of integers, and we need to count how many of these integers are even.

### Approach
1. **Read Input:** The input starts with the number of test cases. For each test case, the first line contains the number of elements in the list, and the second line contains the elements themselves.
2. **Process Each Test Case:** For each test case, read the list of integers and count how many of them are even.
3. **Output the Result:** For each test case, output the count of even numbers.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    nums = list(map(int, input().split()))
    print(sum(1 for num in nums if num % 2 == 0))
```

### Explanation
1. **Reading Input:** The code first reads the number of test cases. For each test case, it reads the number of elements and then the list of elements.
2. **Counting Even Numbers:** Using a generator expression, the code counts how many numbers in the list are even by checking if each number modulo 2 equals 0.
3. **Efficiency:** The approach efficiently processes each test case in linear time relative to the number of elements, making it suitable for large inputs as well.

This solution ensures that each test case is handled independently and efficiently, providing the correct count of even numbers for each list.
