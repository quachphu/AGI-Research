To solve this problem, we need to determine the number of valid combinations of K different coins such that their total value falls within a given range [L, R]. Given the constraints, a brute force approach is infeasible, so we use a meet-in-the-middle technique to efficiently explore possible combinations.

### Approach
1. **Split the Array**: Divide the array of coin values into two halves. This allows us to handle each half independently, reducing the problem size significantly.
2. **Generate Subsets**: For each half, generate all possible subsets along with their sums and sizes. This is done using bit manipulation to iterate through all possible combinations.
3. **Preprocess Subsets**: For each subset size in the second half, sort the sums to facilitate efficient range queries using binary search.
4. **Combine Results**: For each possible combination of subset sizes from both halves that sum to K, check if their combined sums fall within the range [L, R]. Use binary search to count valid combinations efficiently.

### Solution Code
```python
import sys
import bisect
from collections import defaultdict

def generate_subsets(arr):
    n = len(arr)
    subsets = defaultdict(list)
    for mask in range(1 << n):
        cnt = bin(mask).count('1')
        s = 0
        for i in range(n):
            if mask & (1 << i):
                s += arr[i]
        subsets[cnt].append(s)
    return subsets

def main():
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx]); idx += 1
    K = int(input[idx]); idx += 1
    L = int(input[idx]); idx += 1
    R = int(input[idx]); idx += 1
    a = list(map(int, input[idx:idx+N]))
    idx += N

    mid = N // 2
    A = a[:mid]
    B = a[mid:]

    subsets_A = generate_subsets(A)
    subsets_B = generate_subsets(B)

    # Pre-sort subsets_B's lists for efficient binary search
    for key in subsets_B:
        subsets_B[key].sort()

    total = 0

    for k1 in subsets_A:
        k2 = K - k1
        if k2 < 0 or k2 not in subsets_B:
            continue
        list1 = subsets_A[k1]
        list2 = subsets_B[k2]
        for s in list1:
            target_low = L - s
            target_high = R - s
            left = bisect.bisect_left(list2, target_low)
            right_idx = bisect.bisect_right(list2, target_high)
            total += (right_idx - left)
    print(total)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Splitting the Array**: The array is divided into two halves to handle each part separately, reducing the problem size from 2^40 to manageable 2^20 subsets per half.
2. **Subset Generation**: Using bit manipulation, we generate all possible subsets for each half, storing their sums grouped by subset size. This allows us to quickly access sums of any required size.
3. **Binary Search for Range Queries**: By sorting the sums of subsets from the second half, we efficiently count how many values fall within the required range using binary search. This reduces the complexity of each range query from O(n) to O(log n).
4. **Combining Results**: For each valid combination of subset sizes from both halves, we check all possible sums and count valid combinations using the preprocessed data and binary search, ensuring efficiency even for large input sizes.

This approach effectively balances the computational load, making it feasible to solve the problem within the given constraints.
