To solve this problem, we need to determine if a given 4-digit integer has three or more consecutive same digits. If it does, we classify it as "good" and print "Yes"; otherwise, we print "No".

### Approach
The approach to solve this problem involves the following steps:
1. Convert the input number into a string to easily access individual digits.
2. Check two possible consecutive triplets in the 4-digit number:
   - The first three digits (positions 0, 1, 2).
   - The last three digits (positions 1, 2, 3).
3. If either of these triplets consists of the same digit, the number is classified as "good".

### Solution Code
```python
def main():
    n = input().strip()
    if (n[0] == n[1] == n[2]) or (n[1] == n[2] == n[3]):
        print("Yes")
    else:
        print("No")

main()
```

### Explanation
1. **Reading Input**: The input is read as a string to facilitate easy access to each digit.
2. **Checking Consecutive Digits**: 
   - The first check `n[0] == n[1] == n[2]` verifies if the first three digits are the same.
   - The second check `n[1] == n[2] == n[3]` verifies if the last three digits are the same.
3. **Output Result**: Based on the checks, the result is printed as "Yes" if either check is true, otherwise "No".

This approach efficiently determines the presence of three consecutive same digits in constant time, ensuring optimal performance.
