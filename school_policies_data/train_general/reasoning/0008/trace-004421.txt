To solve this problem, we need to determine which buttons on Polycarp's keyboard are definitely working correctly. Each button can either work normally (adding one character when pressed) or be malfunctioning (adding two characters when pressed). The solution involves analyzing the given string to identify characters that must be added by a working button.

### Approach
1. **Total Count Check**: If a character appears an odd number of times in the string, it must be added by a working button because a malfunctioning button would only add characters in pairs (even counts).
2. **Run Length Check**: For characters with even counts, check if all consecutive runs of that character are of even length. If any run is odd, the character must be added by a working button.

### Solution Code
```python
def determine_working_buttons():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    cases = input[1:t+1]
    
    for s in cases:
        res = set()
        # Check each character from a to z
        for c in 'abcdefghijklmnopqrstuvwxyz':
            count = s.count(c)
            if count % 2 == 1:
                res.add(c)
            else:
                # Check runs of c
                current_run = 0
                has_odd_run = False
                for char in s:
                    if char == c:
                        current_run += 1
                    else:
                        if current_run > 0:
                            if current_run % 2 != 0:
                                has_odd_run = True
                                break  # Early exit if found
                            current_run = 0
                # Check the last run after loop ends
                if current_run > 0:
                    if current_run % 2 != 0:
                        has_odd_run = True
                if has_odd_run:
                    res.add(c)
        # Prepare the result string
        sorted_res = sorted(res)
        print(''.join(sorted_res))
        
determine_working_buttons()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into individual test cases.
2. **Character Analysis**: For each character from 'a' to 'z':
   - **Total Count Check**: If the total count of the character is odd, it is added to the result set.
   - **Run Length Check**: If the count is even, check each consecutive run of the character. If any run has an odd length, the character is added to the result set.
3. **Result Preparation**: The result set is sorted alphabetically and printed as a concatenated string for each test case.

This approach efficiently determines which characters must be added by working buttons by leveraging both total counts and run-length analysis, ensuring correctness and optimal performance.
