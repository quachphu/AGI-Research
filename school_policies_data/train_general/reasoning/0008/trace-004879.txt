To solve this problem, we need to determine the number of almost prime numbers between 1 and a given integer \( n \). An almost prime is defined as a number that has exactly two distinct prime divisors. 

### Approach
1. **Generate Primes**: Use the Sieve of Eratosthenes algorithm to generate all prime numbers up to 3000 (the maximum possible value for \( n \)).
2. **Check Each Number**: For each number from 2 to \( n \), determine its prime divisors using the list of primes generated in the first step.
3. **Count Almost Primes**: If a number has exactly two distinct prime divisors, increment the count of almost primes.

### Solution Code
```python
def sieve(n):
    sieve = [True] * (n + 1)
    sieve[0] = sieve[1] = False
    for i in range(2, int(n**0.5) + 1):
        if sieve[i]:
            sieve[i*i : n+1 : i] = [False] * len(sieve[i*i : n+1 : i])
    primes = [i for i, is_p in enumerate(sieve) if is_p]
    return primes

primes_list = sieve(3000)

n = int(input())
count = 0

for m in range(2, n + 1):
    factors = set()
    temp = m
    for p in primes_list:
        if p > temp:
            break
        if temp % p == 0:
            factors.add(p)
            while temp % p == 0:
                temp //= p
            if temp == 1:
                break
    if len(factors) == 2:
        count += 1

print(count)
```

### Explanation
1. **Sieve of Eratosthenes**: This algorithm efficiently generates all prime numbers up to 3000. The sieve array is initialized to `True`, and non-prime indices are marked `False` iteratively.
2. **Prime Factorization**: For each number from 2 to \( n \), we check divisibility by primes generated from the sieve. We use a set to keep track of distinct prime divisors.
3. **Check Almost Prime Condition**: After factorizing each number, if the set of prime divisors has exactly two elements, the number is counted as an almost prime.

This approach ensures that we efficiently determine the prime factors of each number using precomputed primes, making the solution both optimal and easy to understand.
