Implement a Fenwick Tree that supports range updates and point queries.

The standard way to do this is to use a Fenwick Tree that represents a prefix sum array. To support range updates (add d to l to r), we can perform two point updates: add d to position l, subtract d from position r+1. Then, the prefix sum up to position i gives the sum added to i.

Here's the implementation:

class FenwickTree:
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (self.n + 1)

    def update(self, idx, delta):
        while idx <= self.n:
            self.tree[idx] += delta
            idx += idx & -idx

    def query(self, idx):
        res = 0
        while idx > 0:
            res += self.tree[idx]
            idx -= idx & -idx
        return res

    def range_add(self, l, r, delta):
        self.update(l, delta)
        self.update(r + 1, -delta)

To solve this problem, we need to efficiently handle two types of operations on an array: adding a value to a range of elements and counting the number of "lucky numbers" in a range. Lucky numbers are defined as numbers that only contain the digits 4 and 7.

### Approach
1. **Precompute Lucky Numbers**: Generate all lucky numbers up to 10,000. These numbers will be stored in a set for O(1) lookups.
2. **Fenwick Tree (Binary Indexed Tree)**: Use a Fenwick Tree to efficiently manage range updates (add operations) and point queries to retrieve the sum of updates applied to each element.
3. **Process Operations**: For each add operation, update the Fenwick Tree. For each count operation, iterate through the specified range, compute the current value of each element using the Fenwick Tree, and check if it is a lucky number.

### Solution Code
```python
import sys
from itertools import product

def generate_lucky_numbers():
    lucky = set()
    for length in range(1, 5):  # Check 1 to 4 digit numbers
        for bits in product('47', repeat=length):
            num = int(''.join(bits))
            if num <= 10000:
                lucky.add(num)
    return lucky

lucky_set = generate_lucky_numbers()

class FenwickTree:
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (self.n + 2)  # 1-based indexing

    def update(self, idx, delta):
        while idx <= self.n:
            self.tree[idx] += delta
            idx += idx & -idx

    def query_point(self, idx):
        res = 0
        while idx > 0:
            res += self.tree[idx]
            idx -= idx & -idx
        return res

    def range_add(self, l, r, delta):
        self.update(l, delta)
        self.update(r + 1, -delta)

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    m = int(input[ptr])
    ptr += 1
    a = list(map(int, input[ptr:ptr + n]))
    ptr += n
    ft = FenwickTree(n)
    for _ in range(m):
        cmd = input[ptr]
        ptr += 1
        l = int(input[ptr])
        ptr += 1
        r = int(input[ptr])
        ptr += 1
        if cmd == 'add':
            d = int(input[ptr])
            ptr += 1
            ft.range_add(l, r, d)
        elif cmd == 'count':
            count = 0
            for i in range(l, r + 1):
                current = a[i - 1] + ft.query_point(i)
                if current in lucky_set:
                    count += 1
            print(count)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Precompute Lucky Numbers**: The `generate_lucky_numbers` function generates all possible numbers consisting of the digits 4 and 7 up to 10,000 and stores them in a set for quick lookups.
2. **Fenwick Tree**: This data structure efficiently handles range additions and point queries. The `range_add` method updates the range [l, r] by adding a value, and `query_point` retrieves the cumulative sum at a specific index.
3. **Processing Operations**: For each add operation, the Fenwick Tree is updated. For each count operation, the current value of each element in the range is computed by adding the initial value to the cumulative sum from the Fenwick Tree. If the result is a lucky number, it is counted.

This approach ensures that each add operation is handled in O(log n) time and each count operation in O((r-l+1) log n) time, making it efficient for large input sizes.
