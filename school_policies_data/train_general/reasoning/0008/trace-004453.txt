To solve this problem, we need to decrypt a message that was encrypted using a specific swap encryption method. The encryption process involves swapping characters at specific positions and then shifting them in a reversed alphabetical order. Our task is to reverse these operations to retrieve the original message.

### Approach
1. **Reverse the Order of Operations**: Since the encryption steps are applied in a specific order, we need to reverse these steps to decrypt the message. This means processing the steps from the last one to the first.
2. **Shift Characters Back**: Each character involved in the swap during encryption was shifted backward in a reversed alphabetical order. To reverse this, we shift the characters forward by the same amount.
3. **Swap Characters Again**: After shifting the characters back to their original values, we swap them again to revert their positions to what they were before the encryption step.

### Solution Code
```python
def decrypt():
    import sys
    lines = [line.strip() for line in sys.stdin if line.strip()]
    ptr = 0
    while ptr < len(lines):
        line = lines[ptr]
        ptr += 1
        if line == '0':
            break
        n = int(line)
        message = lines[ptr]
        ptr += 1
        steps = []
        for _ in range(n):
            a, b = map(int, lines[ptr].split())
            steps.append((a, b))
            ptr += 1
        current = list(message)
        for a, b in reversed(steps):
            i = a - 1
            j = b - 1
            k = b - a
            # Shift the characters at positions i and j by +k
            ci = current[i]
            new_ci = chr((ord(ci) - ord('a') + k) % 26 + ord('a'))
            current[i] = new_ci
            cj = current[j]
            new_cj = chr((ord(cj) - ord('a') + k) % 26 + ord('a'))
            current[j] = new_cj
            # Swap the characters
            current[i], current[j] = current[j], current[i]
        print(''.join(current))
```
