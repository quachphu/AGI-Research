To solve this problem, we need to evaluate a simple arithmetic expression given in the form of "A op B", where A and B are integers, and op is either '+' or '-'. The goal is to read the input, parse the values and operator, compute the result, and print it.

### Approach
1. **Reading Input**: The input is read as a single line from standard input.
2. **Splitting the Input**: The input line is split into three components: the first integer (A), the operator (op), and the second integer (B).
3. **Conversion to Integers**: The first and third components (A and B) are converted from strings to integers.
4. **Performing the Operation**: Depending on the operator, either addition or subtraction is performed on the integers A and B.
5. **Output the Result**: The result of the operation is printed.

### Solution Code
```python
def main():
    line = input().strip()
    parts = line.split()
    a = int(parts[0])
    op = parts[1]
    b = int(parts[2])
    if op == '+':
        print(a + b)
    else:
        print(a - b)

main()
```

### Explanation
1. **Reading Input**: The `input().strip()` function reads the entire line of input and removes any leading or trailing whitespace.
2. **Splitting the Input**: The `split()` method is used to split the input string into a list of substrings based on whitespace. This ensures that we correctly separate the two integers and the operator.
3. **Conversion to Integers**: The first and third elements of the split list are converted from strings to integers using `int()`.
4. **Performing the Operation**: A conditional check determines the operator. If the operator is '+', the integers are added; otherwise, they are subtracted.
5. **Output the Result**: The result of the arithmetic operation is printed using `print()`.

This approach efficiently handles the input parsing and arithmetic operations, ensuring correct results for all valid inputs as specified by the problem constraints.
