To solve this problem, we need to generate the abbreviation for the N-th round of the AtCoder Beginner Contest (ABC). The abbreviation is formed by appending the three-digit number N to the string "ABC".

### Approach
The problem is straightforward. Given an integer N (where 100 ≤ N ≤ 999), we need to output the string "ABC" followed by the integer N. The key steps are:
1. Read the input value N.
2. Concatenate the string "ABC" with the input value N.
3. Print the resulting string.

Since the input is guaranteed to be a valid three-digit integer, we can directly use the input string without any additional formatting or validation.

### Solution Code
```python
n = input().strip()
print(f"ABC{n}")
```

### Explanation
1. **Reading Input**: The input is read as a string using `input().strip()`, which ensures any leading or trailing whitespace is removed.
2. **Concatenation**: The string "ABC" is concatenated with the input string using an f-string for clarity and efficiency.
3. **Output**: The resulting string is printed directly.

This approach ensures that we efficiently and correctly generate the required abbreviation by leveraging Python's string manipulation capabilities. The solution handles all valid input cases within the specified constraints.
