To solve this problem, we need to find the minimum cost path from (0, 0) to (n, n) on a grid, where each segment alternates between horizontal and vertical directions. The cost of each segment is determined by its length multiplied by a given cost factor. The goal is to minimize the total cost while ensuring the path alternates directions and does not exceed n segments.

### Approach
1. **Precompute Costs**: For each test case, precompute the sum and minimum values for odd and even indexed segments. This helps in efficiently calculating the costs for different paths.
2. **Iterate Over Possible Paths**: For each possible number of segments (from 2 to n), compute the cost for paths starting both horizontally and vertically. This involves checking both even and odd segment counts to ensure all possible paths are considered.
3. **Calculate Minimum Cost**: For each valid combination of horizontal and vertical segments, compute the total cost using the precomputed values and track the minimum cost encountered.

import sys

def solve():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        c = list(map(int, input[ptr:ptr + n]))
        ptr += n
        
        # Precompute sums and mins for odd and even indices
        m_odd = (n + 1) // 2
        sum_odd = [0] * (m_odd + 1)
        min_odd = [float('inf')] * (m_odd + 1)
        current_sum = 0
        current_min = float('inf')
        for i in range(m_odd):
            idx = 2 * i
            if idx >= n:
                sum_odd[i+1] = current_sum
                min_odd[i+1] = current_min
                continue
            current_sum += c[idx]
            current_min = min(current_min, c[idx])
            sum_odd[i+1] = current_sum
            min_odd[i+1] = current_min
        
        m_even = n // 2
        sum_even = [0] * (m_even + 1)
        min_even = [float('inf')] * (m_even + 1)
        current_sum = 0
        current_min = float('inf')
        for i in range(m_even):
            idx = 2 * i + 1
            if idx >= n:
                sum_even[i+1] = current_sum
                min_even[i+1] = current_min
                continue
            current_sum += c[idx]
            current_min = min(current_min, c[idx])
            sum_even[i+1] = current_sum
            min_even[i+1] = current_min
        
        min_total = float('inf')
        
        # Check paths starting with horizontal (H)
        for h_count in range(1, m_odd + 1):
            # Even k case: k = 2 * h_count
            v_count_even = h_count
            if v_count_even <= m_even:
                cost_h = sum_odd[h_count] + (n - h_count) * min_odd[h_count]
                cost_v = sum_even[v_count_even] + (n - v_count_even) * min_even[v_count_even]
                total = cost_h + cost_v
                if total < min_total:
                    min_total = total
            
            # Odd k case: k = 2 * h_count - 1
            v_count_odd = h_count - 1
            if v_count_odd >= 0 and v_count_odd <= m_even:
                cost_h = sum_odd[h_count] + (n - h_count) * min_odd[h_count]
                cost_v = sum_even[v_count_odd] + (n - v_count_odd) * min_even[v_count_odd]
