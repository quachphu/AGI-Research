To solve this problem, we need to determine the center of a square with an odd side length that has been painted black on a white grid. The solution involves identifying the boundaries of the black square and calculating its center based on these boundaries.

### Approach
1. **Input Reading**: Read the grid dimensions (n rows and m columns) and the grid itself.
2. **Identify Black Cells**: Collect the positions of all black cells ('B') in the grid.
3. **Determine Boundaries**: Find the minimum and maximum row and column indices of the black cells. These indices define the boundaries of the square.
4. **Calculate Center**: The center of the square is the midpoint of the boundaries. Since the grid is 1-indexed, adjust the 0-based indices to 1-based indices for the final result.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    m = int(input[idx+1])
    idx += 2
    grid = []
    for _ in range(n):
        grid.append(input[idx])
        idx += 1
    b_positions = []
    for i in range(n):
        for j in range(m):
            if grid[i][j] == 'B':
                b_positions.append((i, j))
    min_r = min(p[0] for p in b_positions)
    max_r = max(p[0] for p in b_positions)
    min_c = min(p[1] for p in b_positions)
    max_c = max(p[1] for p in b_positions)
    center_r = (min_r + max_r) // 2 + 1
    center_c = (min_c + max_c) // 2 + 1
    print(center_r, center_c)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read as a list of strings split by whitespace. The first two elements are the grid dimensions, followed by the rows of the grid.
2. **Collecting Black Cells**: We iterate through each cell in the grid to collect the positions of all 'B' cells.
3. **Finding Boundaries**: The minimum and maximum row and column indices of the black cells are determined. These values define the smallest square that encloses all black cells.
4. **Calculating the Center**: The center of the square is found by taking the midpoint of the minimum and maximum indices for both rows and columns. These midpoints are adjusted from 0-based to 1-based indexing before being printed as the result.

This approach efficiently narrows down the problem to identifying the boundaries of the black cells and using those boundaries to compute the center, ensuring correctness and optimal performance.
