To solve this problem, we need to determine the minimum day Ivan can purchase all required microtransactions, considering both regular and sale prices. The key challenge is to optimize the use of sale days to minimize the total cost, thus allowing Ivan to start playing as soon as possible.

### Approach
1. **Binary Search**: We use binary search to efficiently determine the minimum day `D` by checking feasibility for each candidate day.
2. **Sale Day Utilization**: For each candidate day `D`, we determine the latest sale day for each type of microtransaction up to `D`.
3. **Greedy Strategy**: To maximize the use of sale days, we process transactions in increasing order of their latest sale days. This allows us to utilize accumulated burles optimally and maximize the number of items bought at the sale price.

from bisect import bisect_right

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n, m = int(input[ptr]), int(input[ptr+1])
    ptr += 2
    k = list(map(int, input[ptr:ptr+n]))
    ptr += n
    sales = [[] for _ in range(n)]
    for _ in range(m):
        d = int(input[ptr])
        t = int(input[ptr+1]) - 1  # convert to 0-based
        sales[t].append(d)
        ptr += 2
    # Preprocess sales for each type
    for t in range(n):
        sales[t].sort()
    # Calculate sum of 2*k_i
    total_two_k = sum(2 * ki for ki in k)
    # Binary search
    low = 1
    high = total_two_k  # upper bound is worst case
    while low < high:
        mid = (low + high) // 2
        s_list = []
        for t in range(n):
            if k[t] == 0:
                continue
            lst = sales[t]
            if not lst:
                s_t = 0
            else:
                idx = bisect_right(lst, mid) - 1
                s_t = lst[idx] if idx >= 0 else 0
            if s_t > 0:
                s_list.append( (s_t, t) )
        # Sort by s_t in increasing order
        s_list.sort(key=lambda x: x[0])
