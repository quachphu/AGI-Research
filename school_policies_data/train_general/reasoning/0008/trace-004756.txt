To solve this problem, we need to read two integers from standard input, compute their sum, and check if the sum meets a specific condition. If the sum is 10 or greater, we output "error"; otherwise, we output the sum itself.

### Approach
1. **Reading Input**: The input consists of two integers separated by a space. We will read this input and convert it into integers.
2. **Sum Calculation**: Compute the sum of the two integers.
3. **Condition Check**: Check if the sum is 10 or greater. If it is, print "error". Otherwise, print the sum.

### Solution Code
```python
def main():
    A, B = map(int, input().split())
    if A + B >= 10:
        print("error")
    else:
        print(A + B)

main()
```

### Explanation
1. **Reading Input**: The function `input().split()` reads the input line and splits it into two strings, which are then converted to integers using `map(int, ...)`.
2. **Sum Calculation**: The sum of the integers `A` and `B` is computed directly in the conditional check.
3. **Condition Check**: Using an `if` statement, we check if the sum is 10 or greater. If true, "error" is printed; otherwise, the sum is printed.

This approach ensures that we efficiently check the condition and produce the correct output based on the problem constraints. The solution handles all valid input ranges as specified by the problem constraints.
