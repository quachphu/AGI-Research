To solve this problem, we need to efficiently calculate the number of inversions in a permutation after each swap operation. The initial permutation is sorted, and each swap operation can significantly change the inversion count. The challenge is to compute the inversion count after each swap in an efficient manner.

### Approach
1. **Understanding Inversions**: An inversion in a permutation is a pair of indices (i, j) such that i < j and the element at i is greater than the element at j. The goal is to maintain and update the inversion count dynamically after each swap.

2. **Efficient Data Structure**: Use a segment tree where each node stores a sorted list of elements in its range. This allows efficient range queries to count elements within a specific value range, which is crucial for determining the inversion count changes after each swap.

3. **Delta Calculation**: For each swap, compute the change in inversion count (delta) by considering:
   - The direct effect of swapping the two elements.
   - The effect of elements between the swapped positions, which can be efficiently queried using the segment tree.

### Solution Code

import bisect

class SegmentTreeNode:
    def __init__(self, l, r):
        self.l = l
        self.r = r
        self.left = None
        self.right = None
        self.sorted_list = []

def build_segment_tree(arr, l, r):
    node = SegmentTreeNode(l, r)
    if l == r:
        node.sorted_list = [arr[l]]
    else:
        mid = (l + r) // 2
        node.left = build_segment_tree(arr, l, mid)
        node.right = build_segment_tree(arr, mid+1, r)
        # Merge the sorted lists of left and right children
        node.sorted_list = []
        i = j = 0
        while i < len(node.left.sorted_list) and j < len(node.right.sorted_list):
            if node.left.sorted_list[i] < node.right.sorted_list[j]:
                node.sorted_list.append(node.left.sorted_list[i])
                i += 1
            else:
                node.sorted_list.append(node.right.sorted_list[j])
                j += 1
        node.sorted_list.extend(node.left.sorted_list[i:])
        node.sorted_list.extend(node.right.sorted_list[j:])
    return node

def query_range(node, L, R, x):
    if node.r < L or node.l > R:
        return 0
    if L <= node.l and node.r <= R:
        return bisect.bisect_left(node.sorted_list, x)
    return query_range(node.left, L, R, x) + query_range(node.right, L, R, x)

def update_node(node, idx, old_val, new_val):
    # Remove old_val and insert new_val in the node's sorted_list
    pos = bisect.bisect_left(node.sorted_list, old_val)
    if pos < len(node.sorted_list) and node.sorted_list[pos] == old_val:
        del node.sorted_list[pos]
    bisect.insort(node.sorted_list, new_val)
    if node.l == node.r:
        return
    if idx <= node.left.r:
        update_node(node.left, idx, old_val, new_val)
    else:
        update_node(node.right, idx, old_val, new_val)

def main():

    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    q = int(input[ptr])
    ptr += 1
    arr = list(range(1, n + 1))
    # Build the segment tree
    root = build_segment_tree(arr, 0, n - 1)
    current_inversion = 0
    for _ in range(q):
        l = int(input[ptr]) - 1  # convert to 0-based
        ptr += 1
        r = int(input[ptr]) - 1
        ptr += 1
        if l == r:
            print(current_inversion)
            continue
        if l > r:
            l, r = r, l
        u = arr[l]
        v = arr[r]
        # Compute delta from the pair (u, v)
        delta_pair = 1 if v > u else -1
        # Compute the count of elements in [l+1, r-1] between min(u, v) and max(u, v)
        a = min(u, v)
        b = max(u, v)
        L = l + 1
        R = r - 1
        cnt = 0
        if L <= R:
            count_less_b = query_range(root, L, R, b)
            count_less_a_plus_1 = query_range(root, L, R, a + 1)
            cnt = count_less_b - count_less_a_plus_1
        delta_middle = 2 * cnt if (v > u) else -2 * cnt
        delta = delta_pair + delta_middle
        current_inversion += delta
        # Swap the elements in the array
        arr[l], arr[r] = arr[r], arr[l]
        # Update the segment tree for both positions
        update_node(root, l, u, arr[l])
        update_node(root, r, v, arr[r])
        print(current_inversion)

### Explanation
1. **Segment Tree Construction**: The segment tree is built such that each node contains a sorted list of elements in its range. This allows efficient range queries and updates.

2. **Range Queries**: For each swap, we query the segment tree to count elements within a specific range and value interval. This helps determine how many elements contribute to the inversion count change.

3. **Updates**: After each swap, the segment tree is updated to reflect the new positions of the swapped elements. This ensures subsequent queries are accurate.

By maintaining the segment tree and efficiently querying/updating it, we can dynamically compute the inversion count after each swap in logarithmic time, making the solution feasible for large input sizes.
