To solve this problem, we need to determine the minimum number of elements to remove from an array to make it "beautiful" according to Polycarp's criteria. An array is considered beautiful if for every pair of distinct elements, one element divides the other.

### Approach
1. **Sort the Array**: Sorting helps in efficiently checking divisibility conditions as we can process elements in non-decreasing order.
2. **Dynamic Programming with Divisors**: Use a dynamic programming approach where we maintain a dictionary `dp` to track the maximum length of a beautiful subset ending at each element. For each element, generate all its divisors and update the maximum subset length based on previously seen elements.
3. **Divisor Generation**: For each element, generate all possible divisors. This helps in efficiently checking all possible previous elements that could form a valid subset with the current element.

### Solution Code
```python
import sys
import math

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        a = list(map(int, input[ptr:ptr + n]))
        ptr += n
        a.sort()
        dp = {}
        max_len = 0
        for x in a:
            divisors = set()
            for i in range(1, int(math.isqrt(x)) + 1):
                if x % i == 0:
                    divisors.add(i)
                    divisors.add(x // i)
            current_max = 0
            for d in divisors:
                if d in dp and dp[d] > current_max:
                    current_max = dp[d]
            dp[x] = current_max + 1
            if dp[x] > max_len:
                max_len = dp[x]
        print(n - max_len)

if __name__ == '__main__':
    main()
```

4. **Divisor Generation**: For each element `x`, all divisors are generated by iterating up to the square root of `x`, ensuring efficiency.
