To solve this problem, we need to determine the maximum length of a "beautiful" string that can be formed by removing some characters from the given input string. A string is considered beautiful if it can be divided into three parts (possibly empty) such that the first and third parts contain only 'a's and the second part contains only 'b's, while maintaining the order of characters from the original string.

### Approach
The approach involves using dynamic programming to track three states as we iterate through the input string:
1. **a**: The maximum length of the string considering only the first part (all 'a's).
2. **ab**: The maximum length of the string considering the first part and the second part (all 'b's).
3. **aba**: The maximum length of the string considering all three parts (first part 'a's, second part 'b's, and third part 'a's).

For each character in the input string, we update these states based on whether the character is 'a' or 'b':
- If the character is 'a', it can be added to the first part (state `a`) or the third part (state `aba`).
- If the character is 'b`, it can be added to the second part (state `ab`).

### Solution Code
```python
def max_beautiful_string_length():
    s = input().strip()
    a = 0
    ab = 0
    aba = 0
    for c in s:
        if c == 'a':
            new_a = a + 1
            new_ab = ab  # Can't add 'a' to ab
            new_aba = max(aba + 1, ab + 1)
        else:
            new_a = a
            new_ab = max(ab + 1, a + 1)
            new_aba = aba
        a, ab, aba = new_a, new_ab, new_aba
    print(max(a, ab, aba))

max_beautiful_string_length()
```

### Explanation
1. **Initialization**: Start with all states (`a`, `ab`, `aba`) set to 0.
2. **Iterate through each character** in the input string:
   - **For 'a'**:
     - Update `a` by adding 1 (extending the first part).
     - Update `aba` by considering the maximum of extending the third part from either the current `aba` state or transitioning from the `ab` state.
   - **For 'b'**:
     - Update `ab` by considering the maximum of extending the second part from either the current `ab` state or transitioning from the `a` state.
3. **After processing all characters**, the result is the maximum value among the three states, which represents the longest beautiful string achievable.

This approach efficiently computes the solution in O(n) time complexity, where n is the length of the input string, making it suitable for the given constraints.
