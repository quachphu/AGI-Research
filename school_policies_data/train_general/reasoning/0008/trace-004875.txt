To solve this problem, we need to determine how many ways Olga can steal exactly one bag of cookies such that the remaining total number of cookies is even. This will allow Anna and Maria to divide the remaining cookies evenly without any disputes.

### Approach
1. **Understand the Parity Requirement**: The total number of cookies left after stealing one bag must be even. This means that the parity (even or odd nature) of the remaining cookies must be even.
2. **Calculate Total Sum**: Compute the sum of all cookies in the bags.
3. **Determine Parity Check**: Check the parity of the total sum. If the total sum is even, Olga can steal a bag with an even number of cookies. If the total sum is odd, she must steal a bag with an odd number of cookies.
4. **Count Valid Bags**: Iterate through each bag and count how many bags have the same parity as the total sum. This count will give the number of valid ways Olga can steal a bag.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
total = sum(a)
parity = total % 2
count = 0
for num in a:
    if num % 2 == parity:
        count += 1
print(count)
```

### Explanation
1. **Reading Input**: The first input line gives the number of bags, `n`. The second line contains the list of integers representing the number of cookies in each bag.
2. **Total Sum Calculation**: Compute the sum of all cookies to determine the overall parity.
3. **Parity Check**: By calculating `total % 2`, we determine if the total number of cookies is even or odd.
4. **Counting Valid Bags**: For each bag, check if its parity matches the total's parity. If it does, increment the count.
5. **Output Result**: The count of valid bags is printed, which represents the number of ways Olga can steal a bag to leave an even number of cookies.

This approach efficiently checks each bag in linear time, making it optimal for the given constraints.
