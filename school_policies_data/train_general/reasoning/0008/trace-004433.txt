To solve this problem, we need to determine the optimal m-bit number Peter should choose to minimize and maximize the sum of values of n variables computed using bitwise operations. The solution involves analyzing the impact of each bit of Peter's number on the total sum and choosing the bits accordingly.

### Approach
1. **Bitwise Analysis**: Each bit in Peter's number (denoted as X) can independently affect the sum of the variables. We analyze each bit position from the least significant bit (LSB) to the most significant bit (MSB).
2. **Variable Computation**: For each bit position, compute the value of each variable when the corresponding bit in X is 0 or 1. Track the sum contributions for both cases.
3. **Decision Making**: For each bit position, determine whether setting it to 0 or 1 minimizes or maximizes the sum. In case of ties, choose 0 to ensure the smallest possible X.

### Solution Code
```python
n, m = map(int, input().split())
variables = []
for _ in range(n):
    line = input().strip()
    name, expr = line.split(' := ')
    variables.append((name, expr))

min_bits = []
max_bits = []

for j in range(m):
    var_dict = {}
    count0 = 0
    count1 = 0
    for (name, expr) in variables:
        if expr[0] in '01':  # constant
            binary_str = expr
            idx = m - 1 - j
            bit = 1 if binary_str[idx] == '1' else 0
            var_dict[name] = (bit, bit)
            count0 += bit
            count1 += bit
        else:
            parts = expr.split()
            op1, op, op2 = parts[0], parts[1], parts[2]
            
            def get_bits(operand):
                if operand == '?':
                    return (0, 1)
                else:
                    return var_dict[operand]
            
            op1_0, op1_1 = get_bits(op1)
            op2_0, op2_1 = get_bits(op2)
            
            if op == 'AND':
                res0 = op1_0 & op2_0
                res1 = op1_1 & op2_1
            elif op == 'OR':
                res0 = op1_0 | op2_0
                res1 = op1_1 | op2_1
            elif op == 'XOR':
                res0 = op1_0 ^ op2_0
                res1 = op1_1 ^ op2_1
            var_dict[name] = (res0, res1)
            count0 += res0
            count1 += res1
    
    if count0 <= count1:
        min_bit = 0
    else:
        min_bit = 1
    
    if count1 > count0:
        max_bit = 1
    else:
        max_bit = 0
    
    min_bits.append(min_bit)
    max_bits.append(max_bit)

def bits_to_binary(bits):
    return ''.join(str(bit) for bit in reversed(bits))
```
