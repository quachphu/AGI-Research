To solve this problem, we need to determine how many consecutive days Vasya can use his socks before running out, considering that his mom buys him a new pair every m-th day in the evening. 

### Approach
1. **Initial Setup**: Start with `n` pairs of socks and track the current number of socks.
2. **Daily Usage**: Each day, Vasya uses one pair of socks, decreasing the count by 1.
3. **Replenishment Check**: After using a pair, check if the day is a multiple of `m`. If it is, add a new pair of socks in the evening, which will be available from the next day.
4. **Termination Condition**: Continue this process until Vasya runs out of socks. Count each day until the socks are exhausted.

### Solution Code
```python
def main():
    import sys
    n, m = map(int, sys.stdin.readline().split())
    current = n
    day = 0
    while current > 0:
        day += 1
        current -= 1
        if day % m == 0:
            current += 1
    print(day)

main()
```

### Explanation
- **Initialization**: Read the input values `n` (initial pairs of socks) and `m` (every m-th day a new pair is bought).
- **Daily Loop**: For each day, increment the day counter and reduce the current sock count by 1.
- **Replenishment**: If the day is a multiple of `m`, add a new pair of socks to the current count after the day's usage.
- **Termination**: The loop continues until there are no socks left. The total number of days counted is printed as the result.

This approach efficiently tracks the daily usage and replenishment of socks, ensuring we accurately count the days until Vasya runs out of socks.
