3. **Mathematical Insight**: For each even integer N, the minimum number of remaining soldiers after three turns is N/2. ### Solution Code
```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    T = int(data[0])
    for i in range(1, T + 1):
        N = int(data[i])
        print(N // 2)

if __name__ == "__main__":
    main()
```
