To solve this problem, we need to determine the total duration the shower emits water when multiple people press the switch at different times. Each press resets the shower's timer to emit water for a fixed duration T seconds. The challenge is to compute the cumulative time efficiently, considering overlapping intervals when the shower is already running.

### Approach
1. **Initialization**: Start by reading the input values for N (number of people) and T (duration of water emission per press). Also, read the list of times at which each person presses the switch.
2. **Tracking Intervals**: Use two variables to track the current interval during which the shower is running: `current_start` and `current_end`. These variables denote the start and end times of the current water emission period.
3. **Iterate Through Press Times**: For each subsequent press time:
   - If the press time is after the current interval's end time, add the duration of the current interval to the total and start a new interval.
   - If the press time is within the current interval, extend the current interval's end time by T seconds from the press time.
4. **Final Calculation**: After processing all presses, add the duration of the last interval to the total.

### Solution Code
```python
import sys

def main():
    N_T = sys.stdin.readline().split()
    while len(N_T) < 2:
        line = sys.stdin.readline()
        if not line:
            break
        N_T += line.split()
    N, T = map(int, N_T)
    t = list(map(int, sys.stdin.readline().split()))
    current_start = t[0]
    current_end = current_start + T
    total = 0
    for i in range(1, N):
        ti = t[i]
        if ti >= current_end:
            total += current_end - current_start
            current_start = ti
            current_end = ti + T
        else:
            current_end = ti + T
    total += current_end - current_start
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline` for efficiency, especially with large input sizes.
2. **Initial Setup**: The first person's press time initializes the start and end of the first interval.
3. **Loop Through Press Times**: For each subsequent press time:
   - If the press time is outside the current interval, the current interval's duration is added to the total, and a new interval starts.
   - If the press time is within the current interval, the interval's end time is extended from the press time.
4. **Final Interval**: After processing all presses, the last interval's duration is added to the total, ensuring all time periods are accounted for.

This approach efficiently processes each press in O(N) time, making it suitable for large input sizes up to 200,000 presses.
