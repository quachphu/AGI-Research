The sunscreen lasts for T minutes once applied and can only be applied once. The goal is to find the optimal time to apply the sunscreen to maximize its effectiveness during the live concerts.

### Approach
1. **Understanding the Problem**: Aizu Nyan attends multiple live concerts, each with a start and end time. She is outdoors only during these concerts. We need to find the optimal time to apply sunscreen such that the duration of its effect (T minutes) overlaps as much as possible with the live concert times.

2. **Key Insight**: The optimal time to apply sunscreen can either be at the start of a live concert or during a gap between two consecutive concerts. By considering these two scenarios, we can efficiently determine the maximum coverage.

3. **Efficient Calculation**:
   - **Prefix Sums**: Precompute prefix sums of the durations of live concerts and their end times to quickly calculate overlaps.
   - **Binary Search**: Use binary search to determine the range of live concerts that can be covered by the sunscreen's effect starting at a given time.

4. **Candidates for Application Time**: Generate candidate times for applying sunscreen, including the start times of each live concert and the optimal times during gaps between concerts.

5. **Calculate Overlap**: For each candidate time, compute the overlap of the sunscreen's duration with the live concerts using prefix sums and binary search for efficient range queries.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    N = int(input[ptr])
    ptr += 1
    lives = []
    for _ in range(N):
        s = int(input[ptr])
        t = int(input[ptr + 1])
        ptr += 2
        lives.append((s, t))
    
    # Precompute s_list and t_list
    s_list = [s for s, t in lives]
    t_list = [t for s, t in lives]
    
    # Precompute prefix sums for durations and t
    prefix_duration = [0]
    current_sum = 0
    for s, t in lives:
        current_sum += t - s
        prefix_duration.append(current_sum)
    
    prefix_t = [0]
    current_sum = 0
    for t in t_list:
        current_sum += t
        prefix_t.append(current_sum)
    
    # Generate all candidates
    candidates = s_list.copy()
    # Gap candidates: before first live, between lives
    gap_candidates = []
    if lives:
        gap_candidates.append(s_list[0] - T)
    for i in range(len(lives) - 1):
        prev_t = lives[i][1]
        next_s = lives[i+1][0]
        candidate = max(prev_t, next_s - T)
        gap_candidates.append(candidate)
    all_candidates = candidates + gap_candidates
    
    max_overlap = 0
    for X in all_candidates:
        end = X + T
        j = bisect.bisect_left(s_list, X)
        m = bisect.bisect_left(s_list, end)
        sum_duration_part = prefix_duration[m] - prefix_duration[j]
        sum_max = 0
        if j < m:
            # Find p in j..m-1 where t_list[p] > end
            # Using bisect_right on t_list[j:m]
            p = bisect.bisect_right(t_list, end, j, m)
            sum_max = (prefix_t[m] - prefix_t[p]) - end * (m - p)
        current_overlap = sum_duration_part - sum_max
        if current_overlap > max_overlap:
            max_overlap = current_overlap
    print(max_overlap)

if __name__ == '__main__':
    main()
```

4. **Binary Search**: For each candidate time, use binary search to determine the range of live concerts that can be covered by the sunscreen's effect and compute the overlap using prefix sums.
