To solve this problem, we need to count how many positive integers up to a given number \( n \) are "undoubtedly lucky". A number is undoubtedly lucky if it can be formed using at most two distinct digits. 

### Approach
1. **Understanding Undoubtedly Lucky Numbers**: A number is undoubtedly lucky if it can be composed using one or two distinct digits. For example, numbers like 1, 22, 121, and 1232 (using digits 1 and 2) are all considered undoubtedly lucky.

2. **Breaking Down the Problem**:
   - **Part 1**: Count all numbers with fewer digits than \( n \). These numbers are automatically less than \( n \) and can be formed using one or two distinct digits.
   - **Part 2**: Count all numbers with the same number of digits as \( n \) that are less than or equal to \( n \) and can be formed using one or two distinct digits.

3. **Efficient Calculation**:
   - **Part 1**: For numbers with fewer digits than \( n \), compute the count of numbers formed using one digit and two distinct digits.
   - **Part 2**: For numbers with the same number of digits as \( n \), generate all possible numbers using one digit and two distinct digits, and check if they are less than or equal to \( n \).

### Solution Code
```python
import itertools

def count_undoubtedly_lucky():
    n = int(input())
    str_n = str(n)
    m = len(str_n)
    
    part1 = 0
    for l in range(1, m):
        # Numbers with exactly one distinct digit for length l
        single = 9
        # Numbers with exactly two distinct digits for length l
        two = 81 * ((2 ** (l - 1)) - 1)
        part1 += single + two
    
    # Part 2a: Numbers with exactly one distinct digit and m digits
    part2a = 0
    for d in range(1, 10):
        num_str = str(d) * m
        if int(num_str) <= n:
            part2a += 1
    
    # Part 2b: Numbers with exactly two distinct digits and m digits
    part2_set = set()
    for a in range(10):
        for b in range(10):
            if a == b:
                continue
            # Determine allowed first digits
            allowed_first = []
            if a == 0:
                allowed_first = [b]
            elif b == 0:
                allowed_first = [a]
            else:
                allowed_first = [a, b]
            for first in allowed_first:
                # Generate all combinations of a and b for remaining digits
                for rest in itertools.product([a, b], repeat=m-1):
                    digits = [first] + list(rest)
                    num_str = ''.join(map(str, digits))
                    if len(num_str) != m:
                        continue  # This should not happen
                    num = int(num_str)
                    if num > n:
                        continue
                    # Check if both a and b are present in the number
                    has_a = str(a) in num_str
                    has_b = str(b) in num_str
                    if has_a and has_b:
                        part2_set.add(num_str)
    
    part2b = len(part2_set)
    total = part1 + part2a + part2b
```
