To solve this problem, we need to count the total number of multiples of each Fibonacci number within the first N Fibonacci numbers for each test case. The solution involves leveraging the properties of Fibonacci numbers and efficient summation to avoid excessive computations.

### Approach
1. **Understanding Multiples**: Each Fibonacci number at position k (where k ≥ 3) will have multiples at positions that are integer multiples of k. For example, the Fibonacci number at position 3 will have multiples at positions 6, 9, etc.
2. **Special Cases**: The first two Fibonacci numbers are both 1, and every number is a multiple of 1. Thus, for positions 1 and 2, the count of multiples is simply N (the number of elements considered).
3. **Summation Strategy**: For each test case, sum the contributions from the first two positions (each contributing N) and then add the contributions from positions 3 to N. The contribution from position k (k ≥ 3) is the number of multiples of k within the first N elements, which is calculated as floor(N/k).

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        N = int(input[i])
        if N == 1:
            print(1)
        else:
            res = 2 * N
            for k in range(3, N + 1):
                res += N // k
            print(res)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Handling Each Test Case**: For each test case, we determine the number of Fibonacci numbers (N) and compute the result based on the following:
   - If N is 1, the result is simply 1 because the only Fibonacci number is 1, and it is a multiple of itself.
   - For N ≥ 2, we start with a base result of 2 * N (accounting for the first two positions, both being 1).
   - For each position from 3 to N, we add the count of multiples, which is computed as the integer division of N by the position (k). This efficiently counts how many times k fits into N, representing the number of multiples.

This approach ensures that we efficiently compute the required sum with a time complexity of O(N) per test case, which is feasible given the constraints.
