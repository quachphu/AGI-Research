To solve this problem, we need to determine the correct combination of '+' and '-' operators between four given digits such that the resulting expression evaluates to 7. The solution involves checking all possible combinations of these operators and finding the one that satisfies the condition.

### Approach
1. **Input Handling**: Read the input as a string and split it into individual digits.
2. **Generate Combinations**: Use itertools.product to generate all possible combinations of the three operators ('+' and '-').
3. **Evaluate Each Combination**: For each combination of operators, compute the result of the expression step by step.
4. **Check Result**: If the computed result equals 7, format the expression as a string and print it.

### Solution Code
```python
from itertools import product

def find_formula():
    s = input().strip()
    A = int(s[0])
    B = int(s[1])
    C = int(s[2])
    D = int(s[3])
    
    for ops in product(['+', '-'], repeat=3):
        op1, op2, op3 = ops
        current = A
        current = current + B if op1 == '+' else current - B
        current = current + C if op2 == '+' else current - C
        current = current + D if op3 == '+' else current - D
        if current == 7:
            formula = f"{A}{op1}{B}{op2}{C}{op3}{D}=7"
            print(formula)
            return

find_formula()
```

### Explanation
1. **Input Handling**: The input is read as a string and split into four individual digits, which are converted to integers.
2. **Generate Combinations**: Using itertools.product, we generate all possible combinations of the three operators. Since each operator can be either '+' or '-', there are 2^3 = 8 possible combinations.
3. **Evaluate Each Combination**: For each combination of operators, the expression is evaluated step by step. Starting with the first digit, each subsequent digit is either added or subtracted based on the current operator in the combination.
4. **Check Result**: If the evaluated result equals 7, the corresponding expression is formatted into the required string format and printed. The function exits immediately after finding the correct combination to ensure efficiency.

This approach ensures that we check all possible combinations efficiently and correctly, leveraging Python's itertools.product for generating combinations and straightforward arithmetic evaluation.
