To solve this problem, we need to find the largest positive integer that does not exceed a given integer \( x \) and has the maximum possible sum of its digits. If there are multiple such integers, we choose the largest one among them.

### Approach
1. **Generate Candidates**: The key insight is that the optimal number is likely formed by reducing a digit in \( x \) and setting all subsequent digits to 9. This approach ensures that the resulting number is as large as possible while maintaining a lower value than \( x \).
2. **Check All Possibilities**: We generate candidates by iterating over each digit of \( x \). For each digit, if it is not zero, we decrease it by 1 and set all subsequent digits to 9. This generates a number that is smaller than \( x \) but potentially has a higher digit sum.
3. **Evaluate Candidates**: For each candidate, compute the sum of its digits. Track the candidate with the highest digit sum. In case of ties, the largest candidate is chosen.

### Solution Code
```python
def main():
    x_str = input().strip()
    x = int(x_str)
    candidates = [x_str]
    
    for i in range(len(x_str)):
        if x_str[i] == '0':
            continue
        new_candidate = list(x_str)
        new_candidate[i] = str(int(new_candidate[i]) - 1)
        for j in range(i + 1, len(new_candidate)):
            new_candidate[j] = '9'
        candidate_str = ''.join(new_candidate).lstrip('0')
        if not candidate_str:
            candidate_str = '0'
        candidates.append(candidate_str)
    
    max_sum = -1
    best_num = 0
    
    for c in candidates:
        num = int(c)
        if num == 0 or num > x:
            continue
        current_sum = sum(int(d) for d in str(num))
        if current_sum > max_sum or (current_sum == max_sum and num > best_num):
            max_sum = current_sum
            best_num = num
    
    print(best_num)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read as a string to handle large numbers efficiently.
2. **Generating Candidates**: For each digit in \( x \), if the digit is not zero, we create a new candidate by decreasing the digit by 1 and setting all subsequent digits to 9. This candidate is added to the list after removing leading zeros.
3. **Evaluating Candidates**: Each candidate is converted to an integer, checked to ensure it is positive and does not exceed \( x \), and its digit sum is computed. The candidate with the highest digit sum is selected, with ties broken by choosing the larger number.
4. **Output**: The best candidate found is printed as the result.

This approach efficiently narrows down potential candidates and ensures we find the optimal solution without checking every number up to \( x \), making it suitable for very large values of \( x \).
