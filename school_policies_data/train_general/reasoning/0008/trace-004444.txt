To solve this problem, we need to determine if we can partition the vertices of a connected undirected graph into non-empty sets such that every edge connects vertices from adjacent sets. If possible, we also need to find the maximum number of such sets.

### Approach
1. **Check Bipartiteness**: The graph must be bipartite. If it is not, we output -1 immediately. A bipartite graph can be divided into two sets where edges only go between the sets, not within them.
2. **Compute Diameter**: If the graph is bipartite, the maximum number of sets (k) is determined by the longest shortest path (diameter) between any two nodes in the graph. The maximum k is the diameter plus one.

### Solution Code
```python
import sys
from collections import deque

def main():
    n = int(sys.stdin.readline())
    graph = [[] for _ in range(n)]
    for i in range(n):
        s = sys.stdin.readline().strip()
        for j in range(n):
            if s[j] == '1':
                graph[i].append(j)
    
    # Check if the graph is bipartite
    color = [-1] * n
    is_bipartite = True
    queue = deque([0])
    color[0] = 0
    
    while queue and is_bipartite:
        u = queue.popleft()
        for v in graph[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                queue.append(v)
            elif color[v] == color[u]:
                is_bipartite = False
                break
    
    if not is_bipartite:
        print(-1)
        return
    
    # Compute the diameter of the graph
    max_diameter = 0
    for u in range(n):
        visited = [False] * n
        distance = [0] * n
        current_max = 0
        queue = deque([u])
        visited[u] = True
        
        while queue:
            current = queue.popleft()
            for v in graph[current]:
                if not visited[v]:
                    visited[v] = True
                    distance[v] = distance[current] + 1
                    current_max = max(current_max, distance[v])
                    queue.append(v)
        
        max_diameter = max(max_diameter, current_max)
    
    print(max_diameter + 1)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Bipartite Check**: We use a BFS to check if the graph can be colored using two colors. If any conflict in coloring is found (an edge connecting two nodes of the same color), the graph is not bipartite.
2. **Diameter Calculation**: For each node, we perform a BFS to determine the longest shortest path starting from that node. The maximum value obtained from all such BFS operations gives the diameter of the graph. The maximum number of sets (k) is the diameter plus one, as each step in the longest path corresponds to a new set.

This approach ensures that we efficiently determine the solution using BFS for both bipartiteness checking and diameter calculation, leading to an optimal solution.
