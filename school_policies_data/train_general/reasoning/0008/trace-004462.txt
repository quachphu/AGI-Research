To solve this problem, we need to determine the number written in specific cells of a chessboard filled in a particular pattern. The chessboard is filled such that cells with even sum of coordinates are filled first, followed by cells with odd sum of coordinates. The challenge is to efficiently answer multiple queries about the number in a specific cell, given the constraints of very large board sizes and a high number of queries.

### Approach
1. **Understanding the Filling Pattern**:
   - The chessboard is filled in two phases. The first half of the numbers (rounded up) are placed in cells where the sum of the coordinates (row + column) is even. The remaining numbers are placed in cells where the sum is odd.
   - The numbers are filled row-wise (left to right, top to bottom) in each category.

2. **Key Observations**:
   - For each cell (x, y), determine if the sum (x + y) is even or odd.
   - Calculate the number of cells filled before the given cell in the same category (even or odd) using row-major order.

3. **Efficient Calculation**:
   - Precompute the number of even-sum cells in previous rows and the current row up to the given column.
   - Use these precomputed values to determine the position of the number in the given cell.

### Solution Code
```python
import sys

def main():
    n, q = map(int, sys.stdin.readline().split())
    half = (n * n + 1) // 2
    for _ in range(q):
        x, y = map(int, sys.stdin.readline().split())
        total = x + y
        parity = total % 2
        
        # Calculate sum_even_before_x (sum of even cells in rows 1..x-1)
        even_rows = (x - 1) // 2
        odd_rows = x // 2
        sum_even_before = even_rows * (n // 2) + odd_rows * ((n + 1) // 2)
        
        # Calculate sum_even_current (even cells in row x up to column y)
        x_mod = x % 2
        if x_mod == 0:
            sum_even_current = y // 2
        else:
            sum_even_current = (y + 1) // 2
        
        sum_even = sum_even_before + sum_even_current
        
        if parity == 0:
            print(sum_even)
        else:
            sum_odd = (x - 1) * n + y - sum_even
            print(half + sum_odd)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin` for efficiency, especially given the large number of queries.
2. **Precompute Half Value**: The midpoint of the numbers (ceil(n²/2)) is precomputed once to avoid repeated calculations.
3. **Determine Parity**: For each query, the parity (even or odd) of the sum of coordinates (x + y) is determined.
4. **Calculate Even Cells Before Current Row**: Compute the number of even-sum cells in all rows before the current row using integer division to handle large values efficiently.
5. **Calculate Even Cells in Current Row**: Depending on whether the current row is even or odd, compute the number of even-sum cells up to the given column.
6. **Determine Result**: Based on the parity, compute the result either directly from the count of even-sum cells or adjust using the precomputed midpoint and count of odd-sum cells.

This approach ensures that each query is processed in constant time, making the solution efficient even for the upper constraint limits.
