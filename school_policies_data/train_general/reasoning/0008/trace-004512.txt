### Approach
1. **Immediate Check**: If the program's runtime `d` is already less than or equal to the deadline `n`, the answer is immediately "YES".
2. **Optimal Calculation**: For cases where `d` exceeds `n`, we need to find the optimal number of days to spend optimizing. This involves checking values around the integer square root of `d` to find the minimal total days spent. The function `x + ceil(d/(x+1)` is minimized around the integer square root of `d`, so we check a range around this value to ensure we find the minimum.

### Solution Code
```python
import math

def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        n = int(input[idx])
        d = int(input[idx+1])
        idx += 2
        if d <= n:
            print("YES")
            continue
        k_candidate = int(math.sqrt(d))
        max_k = 2 * k_candidate + 2
        min_sum = float('inf')
        for k in range(1, max_k + 1):
            ceil_val = (d + k - 1) // k
            current = (k - 1) + ceil_val
            if current < min_sum:
                min_sum = current
        print("YES" if min_sum <= n else "NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Immediate Check**: If the program's runtime `d` is already within the deadline `n`, we print "YES".
3. **Optimal Calculation**: For cases where `d` exceeds `n`, we calculate the integer square root of `d` to determine a candidate value for optimization. We then check a range around this candidate value to find the minimal total days spent, ensuring we cover all potential optimal points.
4. **Range Check**: We check values from 1 up to twice the candidate value plus two to ensure we capture the optimal point. This range is chosen based on the mathematical properties of the function we are minimizing.

This approach efficiently narrows down the potential optimal values to check, ensuring we find the minimal total days spent without resorting to brute force over a large range.
