To solve this problem, we need to determine the minimum number of steps required to brew a potion with exactly k% magic essence and (100 - k)% water. Each step involves adding either one liter of magic essence or one liter of water. The solution must ensure the ratio of essence to water is exact and uses the fewest steps possible.

### Approach
1. **Problem Analysis**:
   - The ratio of magic essence to water must be exactly k% to (100 - k)%.
   - The goal is to find the minimum number of steps (each step being adding one liter) to achieve this ratio.

2. **Key Insight**:
   - The problem can be reduced to finding the smallest integers e (essence) and w (water) such that the ratio e/w = k/(100 - k). The minimum steps required will be the sum of these integers e and w.
   - Using the greatest common divisor (GCD) of k and (100 - k), we can determine the smallest integers that maintain the required ratio. The minimum steps are then given by 100 divided by the GCD of k and (100 - k).

3. **Special Cases**:
   - If k is 100% or 0%, the solution is trivial: 1 step (either all essence or all water). However, according to the problem constraints, k will always be between 1 and 100, so we only need to handle k = 100.

### Solution Code
```python
import math

t = int(input())
for _ in range(t):
    k = int(input().strip())
    if k == 100:
        print(1)
    else:
        g = math.gcd(k, 100 - k)
        print(100 // g)
```

### Explanation
- **Reading Input**: The number of test cases `t` is read first. For each test case, the desired percentage `k` is read.
- **Handling Special Case**: If `k` is 100, the answer is immediately 1 step since only magic essence is needed.
- **General Case**: For other values of `k`, compute the GCD of `k` and `(100 - k)`. The minimum steps required are calculated as `100 // GCD`, which gives the sum of the smallest integers maintaining the required ratio.

This approach efficiently computes the result using mathematical properties of GCD, ensuring optimal performance and correctness for all valid inputs.
