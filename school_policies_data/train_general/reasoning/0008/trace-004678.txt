To solve this problem, we need to determine the minimum number of elements to insert into an array to make it "dense." An array is considered dense if the ratio of the maximum to the minimum of any two adjacent elements is at most 2.

### Approach
1. **Problem Analysis**: For each pair of consecutive elements in the array, we need to check if their ratio exceeds 2. If it does, we need to insert elements between them such that all adjacent pairs in the resulting subarray meet the density condition.
2. **Key Insight**: For a pair of elements (a, b) where a ≤ b, if b > 2a, we need to find the minimum number of insertions such that each adjacent pair in the resulting sequence has a ratio ≤ 2. This can be done by repeatedly doubling the smaller element until it reaches or exceeds the larger element.
3. **Algorithm**:
   - For each test case, iterate through each consecutive pair of elements in the array.
   - For each pair, compute the minimum number of insertions required to make the subarray dense.
   - Sum the insertions for all pairs to get the total number of insertions required for the array.

### Solution Code
```python
def compute_insertions(x, y):
    a = min(x, y)
    b = max(x, y)
    if b <= 2 * a:
        return 0
    current = a
    count = 0
    while current < b:
        current *= 2
        count += 1
    return count - 1

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    res = 0
    for i in range(n - 1):
        res += compute_insertions(a[i], a[i + 1])
    print(res)
```

### Explanation
1. **Reading Input**: The input consists of multiple test cases. For each test case, we read the length of the array and the array elements.
2. **Processing Each Pair**: For each consecutive pair of elements in the array, we determine the minimum number of insertions required using the `compute_insertions` function.
3. **Insertion Calculation**: The `compute_insertions` function calculates the number of insertions by repeatedly doubling the smaller element until it meets or exceeds the larger element, ensuring each step maintains the ratio constraint.
4. **Summing Insertions**: The total number of insertions for each test case is the sum of insertions required for all consecutive pairs in the array.

This approach efficiently determines the minimum insertions required by leveraging the properties of doubling to maintain the density condition, ensuring optimal performance even for the upper constraint limits.
