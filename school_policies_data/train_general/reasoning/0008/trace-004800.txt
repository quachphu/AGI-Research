To solve this problem, we need to determine the longest path in a 2D matrix starting from the top-left cell (1,1) and moving only right or down, with each subsequent cell having a higher value than the current cell. 

### Approach
The approach involves using dynamic programming (DP) to keep track of the longest path from the starting cell to each cell in the matrix. The key idea is to use a DP table where each entry `dp[i][j]` represents the length of the longest path ending at cell (i, j). 

1. **Initialization**: Start by initializing the DP table with zeros, except for the starting cell (0,0) which is initialized to 1, as the path length starting here is 1.
2. **DP Table Update**: For each cell (i, j), check the cells above (i-1, j) and to the left (i, j-1). If the current cell's value is greater than these neighboring cells, update the DP value for the current cell based on the maximum value from these neighbors.
3. **Result Extraction**: The maximum value in the DP table after processing all cells will be the length of the longest path starting from (1,1).

### Solution Code
```python
def longest_path():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        M = int(input[ptr + 1])
        ptr += 2
        matrix = []
        for i in range(N):
            row = list(map(int, input[ptr:ptr + M]))
            ptr += M
            matrix.append(row)
        dp = [[0 for _ in range(M)] for __ in range(N)]
        dp[0][0] = 1
        max_length = 1
        for i in range(N):
            for j in range(M):
                if i == 0 and j == 0:
                    continue
                max_prev = 0
                # Check top cell
                if i > 0 and matrix[i][j] > matrix[i-1][j]:
                    if dp[i-1][j] > max_prev:
                        max_prev = dp[i-1][j]
                # Check left cell
                if j > 0 and matrix[i][j] > matrix[i][j-1]:
                    if dp[i][j-1] > max_prev:
                        max_prev = dp[i][j-1]
                if max_prev != 0:
                    dp[i][j] = max_prev + 1
                else:
                    dp[i][j] = 0  # Not reachable from (0,0)
                if dp[i][j] > max_length:
                    max_length = dp[i][j]
        print(max_length)

longest_path()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints. The input is split into a list for easier processing.
2. **Matrix and DP Table Setup**: For each test case, the matrix is constructed from the input values. The DP table is initialized with zeros, except for the starting cell.
3. **DP Table Population**: Each cell (i, j) is processed in row-major order (left to right, top to bottom). For each cell, the maximum path length from the top or left cell (if valid) is determined and used to update the current cell's DP value.
4. **Result Calculation**: The maximum value in the DP table is tracked as the cells are processed, ensuring the longest path length is found efficiently.

This approach ensures that each cell is processed in constant time, leading to an overall time complexity of O(N*M) per test case, which is efficient given the problem constraints.
