To solve this problem, we need to determine Sumit's final direction relative to his starting position based on his movements in a 2D world. The movements are given as a string of directions ('N', 'S', 'E', 'W'), and we need to compute the net displacement to determine the final direction from the starting point.

### Approach
1. **Input Reading**: Read the number of test cases and each string of movements.
2. **Net Displacement Calculation**: Track the cumulative movement in the North-South (y-axis) and East-West (x-axis) directions.
3. **Direction Determination**:
   - If the net displacement is purely along one axis (either x or y), the direction is straightforward (North, South, East, or West).
   - For combined displacements, compute the angle relative to the North direction using trigonometric functions and determine the compass direction based on predefined sectors.

### Solution Code
```python
import math

def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        S = input[i]
        dx = 0
        dy = 0
        for c in S:
            if c == 'N':
                dy += 1
            elif c == 'S':
                dy -= 1
            elif c == 'E':
                dx += 1
            elif c == 'W':
                dx -= 1
        
        if dx == 0:
            print('NORTH' if dy > 0 else 'SOUTH')
        elif dy == 0:
            print('EAST' if dx > 0 else 'WEST')
        else:
            angle_rad = math.atan2(dy, dx)
            angle_deg = math.degrees(angle_rad)
            adjusted_angle = (90 - angle_deg) % 360
            
            if adjusted_angle < 22.5 or adjusted_angle >= 337.5:
                print('NORTH')
            elif 22.5 <= adjusted_angle < 67.5:
                print('NORTHEAST')
            elif 67.5 <= adjusted_angle < 112.5:
                print('EAST')
            elif 112.5 <= adjusted_angle < 157.5:
                print('SOUTHEAST')
            elif 157.5 <= adjusted_angle < 202.5:
                print('SOUTH')
            elif 202.5 <= adjusted_angle < 247.5:
                print('SOUTHWEST')
            elif 247.5 <= adjusted_angle < 292.5:
                print('WEST')
            else:
                print('NORTHWEST')

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Calculating Displacement**: For each movement in the string, update the net displacement in the x (East-West) and y (North-South) directions.
3. **Handling Pure Directions**: If the displacement is purely along one axis, the direction is directly determined (e.g., North if only moving North).
4. **Combined Directions**: For combined movements, the angle from the North direction is computed using `math.atan2` to handle the quadrant correctly. The angle is adjusted to be measured clockwise from North, and then checked against predefined sectors to determine the compass direction.

This approach efficiently computes the direction using trigonometric functions and ensures accuracy by considering all possible sectors for the 8 compass directions.
