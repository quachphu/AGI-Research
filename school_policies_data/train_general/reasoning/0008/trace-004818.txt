To solve this problem, we need to determine if a given integer A contains all the prime divisors of another integer B for multiple test cases. The solution must efficiently handle very large values of A and B (up to \(10^{18}\)) and a large number of test cases (up to \(10^4\)).

### Approach
The key insight is that if A has all the prime divisors of B, then repeatedly dividing B by the greatest common divisor (GCD) of A and B should eventually reduce B to 1. If at any point the GCD becomes 1 while B is still greater than 1, it means B has a prime divisor that A does not.

Steps:
1. For each test case, read integers A and B.
2. If B is 1, immediately return "Yes" since 1 has no prime divisors.
3. Otherwise, repeatedly compute the GCD of A and B, divide B by this GCD, and check if B reduces to 1. If the GCD becomes 1 while B is still greater than 1, return "No".

### Solution Code
```python
import sys
import math

def solve():
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        A = int(input[idx])
        B = int(input[idx + 1])
        idx += 2
        if B == 1:
            print("Yes")
            continue
        current_B = B
        while True:
            g = math.gcd(A, current_B)
            if g == 1:
                print("No")
                break
            current_B = current_B // g
            if current_B == 1:
                print("Yes")
                break

solve()
```

### Explanation
1. **Reading Input:** The input is read all at once for efficiency, especially given the large number of test cases.
2. **Handling B = 1:** If B is 1, it has no prime divisors, so the answer is immediately "Yes".
3. **Iterative GCD Reduction:** For each B, we iteratively compute the GCD of A and B, then divide B by this GCD. This process removes all prime factors of B that are also in A. If B reduces to 1, all its prime factors were in A. If the GCD becomes 1 while B is still greater than 1, B has a prime factor not in A.

This approach efficiently handles large values by leveraging the properties of GCD and ensures that each test case is processed in logarithmic time relative to the size of B, making it suitable for the given constraints.
