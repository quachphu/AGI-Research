To solve this problem, we need to simulate a game where two players, Ciel and Hanako, take turns removing exactly 220 yen from a pile of coins. The winner is determined by who cannot make a valid move first. The strategies for each player differ: Ciel maximizes the number of 100-yen coins she takes, while Hanako maximizes the number of 10-yen coins she takes.

### Approach
1. **Game Simulation**: The game proceeds in turns, alternating between Ciel and Hanako.
2. **Ciel's Strategy**: On her turn, Ciel will try to take the maximum number of 100-yen coins possible. This means checking for the highest possible number of 100-yen coins (starting from 2 down to 0) and then the necessary 10-yen coins to sum up to 220 yen.
3. **Hanako's Strategy**: On her turn, Hanako will try to take the maximum number of 10-yen coins possible. This means checking for the lowest possible number of 100-yen coins (starting from 0 up to 2) and then the necessary 10-yen coins to sum up to 220 yen.
4. **Termination**: The game continues until one player cannot make a valid move, at which point the other player is declared the winner.

### Solution Code
```python
x, y = map(int, input().split())

turn = 'Ciel'

while True:
    if turn == 'Ciel':
        found = False
        for a in [2, 1, 0]:
            b = 22 - 10 * a
            if x >= a and y >= b:
                x -= a
                y -= b
                found = True
                turn = 'Hanako'
                break
        if not found:
            print("Hanako")
            exit()
    else:
        found = False
        for a in [0, 1, 2]:
            b = 22 - 10 * a
            if x >= a and y >= b:
                x -= a
                y -= b
                found = True
                turn = 'Ciel'
                break
        if not found:
            print("Ciel")
            exit()
```

### Explanation
1. **Initialization**: Read the initial counts of 100-yen coins (x) and 10-yen coins (y).
2. **Turn Handling**: Alternate turns between Ciel and Hanako.
3. **Ciel's Turn**: Check from the highest possible 100-yen coins (2) down to 0. If a valid move is found, adjust the coin counts and switch turns.
4. **Hanako's Turn**: Check from the lowest possible 100-yen coins (0) up to 2. If a valid move is found, adjust the coin counts and switch turns.
5. **Termination Check**: If a player cannot make a valid move, print the winner and exit.

This approach ensures that each player's strategy is followed precisely, and the game is simulated efficiently until a winner is determined.
