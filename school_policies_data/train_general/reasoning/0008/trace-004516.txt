The system must efficiently handle adding, removing members, and querying the politicization of a text.

### Approach
The key challenge is efficiently counting the occurrences of multiple dynamically changing patterns (active surnames) in a given text. The solution involves using the Aho-Corasick algorithm, which is designed for multiple pattern matching. This algorithm allows us to preprocess all potential surnames into a trie structure with failure links, enabling efficient substring searches in linear time relative to the text length.

1. **Trie Construction**: Build a trie for all potential surnames. Each node in the trie represents a prefix of a surname.
2. **Failure Links**: Compute failure links for each node to handle substring searches that might span multiple nodes, allowing efficient transitions when a substring match fails.
3. **Output Lists**: Maintain output lists at each node to keep track of which surnames end at that node or any of its suffix nodes.
4. **Dynamic Activation**: Track active surnames using a boolean array. For each query, update the active status as needed.
5. **Text Processing**: For each text query, traverse the trie using the Aho-Corasick algorithm, summing occurrences of active surnames using their precomputed output lists.

                    break

                    fail_node = fail_node.fail
            child.output += child.fail.output
            queue.append(child)

    active = [True] * k

    for _ in range(n):

        ptr += 1
