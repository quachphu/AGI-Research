To solve this problem, we need to find the minimum possible sum of a sequence of non-negative integers that satisfies given inequalities based on a string of '<' and '>' characters. The key insight is to determine the minimum values for each position by considering both the increasing and decreasing constraints from both directions.

### Approach
1. **Left Pass**: Calculate the number of consecutive '<' characters ending at each position. This helps determine the minimum value required at each position to satisfy increasing constraints from the left.
2. **Right Pass**: Calculate the number of consecutive '>' characters starting from each position. This helps determine the minimum value required at each position to satisfy decreasing constraints from the right.
3. **Determine Values**: For each position, the value is the maximum of the results from the left and right passes, ensuring both constraints are satisfied.

### Solution Code
```python
s = input().strip()
n = len(s) + 1

left = [0] * n
for i in range(1, n):
    if s[i-1] == '<':
        left[i] = left[i-1] + 1
    else:
        left[i] = 0

right = [0] * n
for i in range(n-2, -1, -1):
    if s[i] == '>':
        right[i] = right[i+1] + 1
    else:
        right[i] = 0

total = sum(max(left[i], right[i]) for i in range(n))
print(total)
```

### Explanation
1. **Left Pass**: We traverse the string from left to right. For each position `i`, if the character before it is '<', we increment the count from the previous position; otherwise, we reset the count to 0. This gives the number of consecutive '<' characters ending at each position.
2. **Right Pass**: We traverse the string from right to left. For each position `i`, if the character at `i` is '>', we increment the count from the next position; otherwise, we reset the count to 0. This gives the number of consecutive '>' characters starting at each position.
3. **Summing Values**: For each position, the value is the maximum of the results from the left and right passes. Summing these values gives the minimum possible sum of the sequence that satisfies all constraints.

This approach efficiently computes the required values in linear time, making it suitable for large input sizes up to 500,000 characters.
