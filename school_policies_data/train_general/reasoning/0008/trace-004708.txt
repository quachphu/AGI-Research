To solve this problem, we need to determine how many numbers remain on a sheet after a series of operations where each number is either added or removed based on its previous presence. The key insight is that a number will remain on the sheet if it appears an odd number of times, as each occurrence toggles its presence.

### Approach
1. **Read Input Efficiently**: Read all input at once and split it into a list of strings for faster processing.
2. **Track Frequencies**: Use a dictionary to count the occurrences of each number.
3. **Determine Result**: Check the parity (odd/even) of the count for each number. If a number's count is odd, it remains on the sheet.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    input = sys.stdin.read().split()
    n = int(input[0])
    counts = defaultdict(int)
    for a in input[1:n+1]:
        num = int(a)
        counts[num] += 1
    res = 0
    for cnt in counts.values():
        res += cnt % 2
    print(res)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings. The first element is the number of operations, `n`.
2. **Frequency Tracking**: Using a dictionary, we count how many times each number appears in the input.
3. **Result Calculation**: For each number, if its count is odd, it means the number remains on the sheet. We sum up all such occurrences to get the final result.

This approach efficiently handles the constraints, ensuring that even for large inputs (up to 100,000 numbers), the solution remains optimal and runs in linear time.
