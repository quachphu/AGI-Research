To solve this problem, we need to determine if each given string can be transformed into a double string by removing at most one character. A double string is defined as a string that can be split into two identical non-empty substrings.

### Approach
1. **Check Even Length Strings**: If a string has an even length, check if it can be split directly into two equal halves. If the two halves are identical, the string is a double string.
2. **Check Odd Length Strings**: If a string has an odd length, we need to check if removing one character can result in a double string. This involves two possible scenarios:
   - **First Half Check**: Compare the first half (allowing one deletion) with the second half.
   - **Second Half Check**: Compare the second half (allowing one deletion) with the first half.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    D = int(input[0])
    cases = input[1:D+1]
    for s in cases:
        m = len(s)
        if m % 2 == 0:
            half = m // 2
            if s[:half] == s[half:]:
                print("YES")
            else:
                print("NO")
        else:
            k = (m - 1) // 2
            # Check possibility 1: first k+1 vs second k, allowing one deletion in first
            i1, j1, del1 = 0, 0, 0
            success1 = False
            while i1 < (k + 1) and j1 < k:
                if s[i1] == s[k + 1 + j1]:
                    i1 += 1
                    j1 += 1
                else:
                    i1 += 1
                    del1 += 1
                    if del1 > 1:
                        break
            success1 = (j1 == k and del1 <= 1)
            
            # Check possibility 2: first k vs second k+1, allowing one deletion in second
            i2, j2, del2 = 0, 0, 0
            success2 = False
            while i2 < k and j2 < (k + 1):
                if s[i2] == s[k + j2]:
                    i2 += 1
                    j2 += 1
                else:
                    j2 += 1
                    del2 += 1
                    if del2 > 1:
                        break
            success2 = (i2 == k and del2 <= 1)
            
            print("YES" if (success1 or success2) else "NO")

if __name__ == "__main__":
    main()
```

### Explanation
- **Even Length Strings**: For strings with even length, the solution checks if the first half is identical to the second half. If they are, the string is a double string.
- **Odd Length Strings**: For strings with odd length, the solution checks two possibilities by allowing one deletion in either the first half or the second half. This is done using a two-pointer approach to efficiently compare the respective parts while accounting for the allowed deletion.

This approach ensures that each string is processed in linear time, making the solution efficient even for large inputs.
