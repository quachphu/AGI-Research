To solve this problem, we need to count the number of distinct substrings of a given string that contain at most `k` bad characters. A character is considered bad if it is specified as such in the input.

### Approach
1. **Identify Bad Characters**: First, we determine which characters in the string are bad using the provided binary string.
2. **Rolling Hash for Efficient Substring Hashing**: Use a rolling hash technique to efficiently compute the hash of any substring. This allows us to check the uniqueness of substrings in constant time.
3. **Sliding Window Technique**: For each starting index in the string, expand the window to the right while keeping track of the number of bad characters. If the count of bad characters exceeds `k`, stop expanding and move to the next starting index.
4. **Hash Set for Uniqueness**: Use a set to store the hashes of valid substrings. This ensures that we only count each unique substring once.

### Solution Code
```python
s = input().strip()
good = input().strip()
k = int(input())

# Determine which characters in the string are bad
bad = [0] * len(s)
for i in range(len(s)):
    c = s[i]
    idx = ord(c) - ord('a')
    if good[idx] == '0':
        bad[i] = 1
    else:
        bad[i] = 0

# Parameters for rolling hash to minimize collisions
base1 = 911382629
mod1 = 10**18 + 3
base2 = 3571428571
mod2 = 10**18 + 7

n = len(s)

# Precompute prefix hashes and power arrays for both hashing methods
prefix_hash1 = [0] * (n + 1)
prefix_hash2 = [0] * (n + 1)
power1 = [1] * (n + 1)
power2 = [1] * (n + 1)

for i in range(n):
    prefix_hash1[i+1] = (prefix_hash1[i] * base1 + ord(s[i])) % mod1
    prefix_hash2[i+1] = (prefix_hash2[i] * base2 + ord(s[i])) % mod2
    power1[i+1] = (power1[i] * base1) % mod1
    power2[i+1] = (power2[i] * base2) % mod2

seen = set()

for l in range(n):
    current_bad = 0
    for r in range(l, n):
        current_bad += bad[r]
        if current_bad > k:
            break
        length = r - l + 1
        # Compute hash for the substring s[l..r] using both methods
        h1 = (prefix_hash1[r+1] - (prefix_hash1[l] * power1[length]) % mod1) % mod1
        h2 = (prefix_hash2[r+1] - (prefix_hash2[l] * power2[length]) % mod2) % mod2
        seen.add((h1, h2))

print(len(seen))
```

### Explanation
1. **Identify Bad Characters**: Convert the input string into an array where each entry indicates whether the corresponding character in the string is bad (1) or good (0).
2. **Rolling Hash Preparation**: Precompute prefix hashes and power values for two different hash functions to reduce collision probability. This allows us to compute the hash of any substring in constant time.
3. **Sliding Window Technique**: For each starting index `l`, expand the window to the right (increasing `r`). Keep a running count of bad characters. If the count exceeds `k`, stop expanding and move to the next starting index.
4. **Hash Set for Uniqueness**: For each valid substring (with at most `k` bad characters), compute its hash using both hash functions and store the tuple of hashes in a set. The size of the set gives the number of distinct valid substrings.

This approach efficiently counts unique substrings using hashing and handles large input sizes within acceptable time complexity.
