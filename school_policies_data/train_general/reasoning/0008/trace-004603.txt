To solve this problem, we need to read a list of pairs consisting of a word and a page number, then output each word in alphabetical order along with its corresponding page numbers sorted in ascending order. 

### Approach
1. **Reading Input**: We read all input lines from standard input (stdin). Each line contains a word followed by a page number.
2. **Storing Data**: Use a dictionary to accumulate page numbers for each word. The keys of the dictionary are words, and the values are lists of page numbers.
3. **Sorting**: 
   - **Words**: Sort the dictionary keys (words) alphabetically.
   - **Page Numbers**: For each word, sort its list of page numbers in ascending order.
4. **Output**: Print each word followed by its sorted list of page numbers.

### Solution Code
```python
def process_books():
    import sys
    from collections import defaultdict

    pages = defaultdict(list)
    for line in sys.stdin:
        line = line.strip()
        if line:
            word, page = line.split()
            pages[word].append(int(page))
    
    for word in sorted(pages):
        sorted_pages = sorted(pages[word])
        print(word)
        print(' '.join(map(str, sorted_pages)))

process_books()
```

### Explanation
1. **Reading Input**: The code reads each line from stdin, strips any leading/trailing whitespace, and splits the line into a word and a page number.
2. **Storing Data**: Using a `defaultdict` from the `collections` module, the code appends each page number to the list corresponding to its word. This ensures that all page numbers for a word are collected in one place.
3. **Sorting**: 
   - **Words**: The keys (words) of the dictionary are sorted alphabetically using Python's built-in `sorted()` function.
   - **Page Numbers**: For each word, the list of page numbers is sorted in ascending order using `sorted()`.
4. **Output**: The sorted words and their corresponding sorted page numbers are printed in the required format. Each word is printed on a new line followed by its page numbers separated by spaces.

This approach efficiently handles the input data and ensures the output is formatted correctly as specified.
