To solve this problem, we need to find the sum of integers between 1 and N (inclusive) whose sum of digits, when written in base 10, falls within a given range [A, B]. The solution involves iterating through each number in the range, calculating the sum of its digits, and checking if this sum lies within the specified range.

### Approach
1. **Input Reading**: Read the values of N, A, and B from the standard input.
2. **Digit Sum Calculation**: For each number from 1 to N, compute the sum of its digits. This can be done by repeatedly extracting the last digit using modulo 10 and then removing the last digit using integer division by 10.
3. **Range Check**: Check if the computed digit sum for each number lies within the range [A, B]. If it does, add the number to a running total.
4. **Output the Result**: After processing all numbers, print the total sum.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    A = int(input[1])
    B = int(input[2])
    
    total = 0
    for num in range(1, N + 1):
        current = num
        digit_sum = 0
        while current > 0:
            digit_sum += current % 10
            current = current // 10
        if A <= digit_sum <= B:
            total += num
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input values are read from standard input and parsed into integers N, A, and B.
2. **Iterating Through Numbers**: We loop through each number from 1 to N inclusive.
3. **Digit Sum Calculation**: For each number, we calculate the sum of its digits by repeatedly taking the last digit (using modulo 10) and then discarding it (using integer division by 10).
4. **Range Check and Accumulation**: For each number, if its digit sum is within the range [A, B], the number is added to the total sum.
5. **Output**: Finally, the accumulated total sum is printed.

This approach efficiently processes each number in the range, ensuring that we only consider those numbers whose digit sums fall within the specified bounds. The algorithm runs in O(N * D) time, where D is the average number of digits in the numbers from 1 to N, which is efficient given the problem constraints.
