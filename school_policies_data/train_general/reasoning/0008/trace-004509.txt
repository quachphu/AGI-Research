To solve this problem, we need to determine the minimum number of segments Sofia has to draw using a ruler when drawing n squares in the snow. The key insight is to arrange the squares in a grid-like structure to minimize the number of new ruler segments required for each new square.

### Approach
1. **Problem Analysis**: Each square requires vertical and horizontal segments. Sofia can reuse segments if they are already present in the same row or column. The goal is to minimize the number of unique rows and columns she needs to draw segments for.
2. **Optimal Arrangement**: The optimal arrangement of n squares is to form a rectangle (or as close to a square as possible) because this minimizes the number of unique rows and columns. The sum of the number of rows and columns in this rectangle will give the minimum number of ruler segments.
3. **Mathematical Insight**: For a given n, the minimum number of ruler segments is equivalent to finding two integers a and b such that their product is at least n and their sum (a + b) is minimized. This is achieved by checking integers around the square root of n.

### Solution Code
```python
import math

n = int(input())
s = math.isqrt(n)
min_total = float('inf')

for a in range(max(1, s - 2), s + 3):
    b = (n + a - 1) // a  # Equivalent to ceil(n / a)
    if a * b >= n:
        min_total = min(min_total, a + b)

print(min_total)
```

### Explanation
1. **Square Root Calculation**: Compute the integer part of the square root of n (`s`). This helps in finding the closest integers around the square root which are potential candidates for the optimal rows and columns.
2. **Range Check**: Check integers around the computed square root (from `s-2` to `s+2`) to ensure we consider all possible candidates that might yield the minimal sum of rows and columns.
3. **Ceiling Division**: For each candidate integer `a`, compute the corresponding `b` using ceiling division to ensure the product `a * b` is at least n.
4. **Minimization**: Track the minimum sum of `a + b` which represents the minimum number of unique rows and columns needed, thus giving the minimum number of ruler segments.

This approach efficiently narrows down the possible candidates for rows and columns, ensuring the solution is optimal even for very large values of n (up to 10^9).
