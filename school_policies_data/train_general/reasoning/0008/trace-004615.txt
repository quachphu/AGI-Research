To solve this problem, we need to determine if a given permutation of integers is ambiguous. An ambiguous permutation is one that is identical to its inverse permutation. The inverse permutation is derived such that the i-th element in the inverse permutation is the position of the integer i in the original permutation.

### Approach
1. **Input Handling**: Read the input values which include multiple test cases. Each test case consists of an integer `n` followed by a permutation of integers from 1 to `n`.
2. **Inverse Permutation Calculation**: For each permutation, compute its inverse permutation. This is done by iterating through the original permutation and setting the position of each integer in the original permutation as the value in the inverse permutation.
3. **Comparison**: Check if the original permutation is the same as its inverse permutation. If they are the same, the permutation is ambiguous; otherwise, it is not.

### Solution Code
```python
import sys

def is_ambiguous(n, permutation):
    if n == 0:
        return False  # Not a valid case as per input specs
    inverse = [0] * n
    for idx in range(n):
        val = permutation[idx]
        inverse[val - 1] = idx + 1  # Positions are 1-based
    for i in range(n):
        if permutation[i] != inverse[i]:
            return False
    return True

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        if n == 0:
            break
        # Read the permutation line
        perm_line = ''
        while True:
            perm_line = sys.stdin.readline()
            if perm_line.strip() == '':
                continue
            break
        permutation = list(map(int, perm_line.strip().split()))
        if len(permutation) != n:
            # Handle possible line breaks in permutation input
            while len(permutation) < n:
                next_part = sys.stdin.readline().strip().split()
                permutation += list(map(int, next_part))
        if is_ambiguous(n, permutation):
            print("ambiguous")
        else:
            print("not ambiguous")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read line by line from standard input. Each test case starts with an integer `n`, followed by a permutation of `n` integers.
2. **Inverse Calculation**: For each integer in the permutation, determine its position and store it in the inverse permutation array. This is done in O(n) time.
3. **Comparison**: Compare the original permutation with its inverse. If they match, the permutation is ambiguous. This comparison is also done in O(n) time, ensuring efficient handling even for large values of `n` (up to 100,000).

This approach ensures that each test case is processed efficiently, adhering to the problem constraints and providing the correct result for each permutation.
