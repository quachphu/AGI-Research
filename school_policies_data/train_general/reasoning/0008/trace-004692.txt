To solve this problem, we need to determine the minimum number of operations required to turn all elements of an array into 1 using a specific operation. The operation allows replacing one of two adjacent elements with their greatest common divisor (GCD).

### Approach
1. **Check for Existing 1s**: If the array already contains any 1s, the minimum number of operations required is simply the number of elements minus the count of 1s, as each non-1 element can be converted to 1 in one step adjacent to an existing 1.
2. **Check Overall GCD**: If there are no 1s, compute the GCD of the entire array. If the overall GCD is not 1, it is impossible to turn all elements into 1, so we return -1.
3. **Find Minimum Subarray with GCD 1**: If the overall GCD is 1, find the smallest contiguous subarray whose GCD is 1. The length of this subarray determines the number of operations needed to create the first 1. The total operations are then calculated as the sum of operations needed to create the first 1 and the operations needed to convert the remaining elements.

### Solution Code
```python
import math
from functools import reduce

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    
    count_1 = a.count(1)
    if count_1 > 0:
        print(n - count_1)
        return
    
    overall_gcd = reduce(math.gcd, a)
    if overall_gcd != 1:
        print(-1)
        return
    
    min_len = float('inf')
    for i in range(n):
        current_gcd = a[i]
        if current_gcd == 1:
            min_len = 1
            break
        for j in range(i + 1, n):
            current_gcd = math.gcd(current_gcd, a[j])
            if current_gcd == 1:
                current_window_len = j - i + 1
                if current_window_len < min_len:
                    min_len = current_window_len
                break  # No need to check further for this i
    
    ans = (min_len - 1) + (n - 1)
    print(ans)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Check for Existing 1s**: If there are any 1s in the array, each non-1 element can be converted to 1 in one operation adjacent to the existing 1, resulting in `n - count_1` operations.
2. **Overall GCD Check**: If no 1s exist, the overall GCD of the array must be 1 to proceed. If not, output -1.
3. **Finding Minimum Subarray**: For each starting index, compute the GCD of the subarray starting at that index and expanding until the GCD becomes 1. Track the minimum length of such subarrays. The operations needed to create the first 1 are `(min_len - 1)`, and converting the rest of the elements takes `(n - 1)` operations, leading to the total minimum operations.

This approach efficiently finds the solution by leveraging the properties of GCD and contiguous subarrays, ensuring optimal performance even for larger arrays.
