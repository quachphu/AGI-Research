Each operation involves selecting a good cell and a corner, forming a rectangle that covers all cells between them. The goal is to find the optimal way to cover the entire grid with the fewest operations.

### Approach
1. **Identify Good Cells and Corners**: First, we identify all good cells (non-corner cells with a value of 1) and the four corners of the grid.
2. **Check for Single Operation Coverage**: Check if there exists a single operation that covers the entire grid. This happens when the rectangle formed by a good cell and a corner spans all rows and columns.
3. **Check for Two Operations Coverage**: 
   - **Column Coverage**: Check if there are two operations that together cover all columns, and their combined row ranges cover all rows.
   - **Row Coverage**: Check if there are two operations that together cover all rows, and their combined column ranges cover all columns.
4. **Default to Four Operations**: If none of the above checks are satisfied, default to four operations as a fallback, which is the maximum required in cases where each corner must be individually covered.
