def find_lucky_substring(s):
    valid_substrings = set()

    for i in range(len(s)):
        if s[i] not in {'4', '7'}:

To solve this problem, we need to find the substring of a given string that represents a lucky number (composed only of the digits 4 and 7) which appears the maximum number of times. If there are multiple such substrings, we choose the lexicographically smallest one. If no valid lucky number substring exists, we return -1.

### Approach
1. **Generate Valid Substrings**: Iterate through the input string to generate all possible substrings that are valid lucky numbers. A valid lucky number must start with 4 or 7 and consist only of these digits.
2. **Count Occurrences**: For each valid substring, count how many times it appears in the input string, including overlapping occurrences.
3. **Determine Maximum Frequency**: Identify the maximum occurrence count among all valid substrings.
4. **Select Lexicographically Smallest**: From the substrings with the maximum occurrence count, select the lexicographically smallest one.

### Solution Code
```python
def find_lucky_substring(s):
    valid_substrings = set()

    # Generate all valid lucky substrings
    for i in range(len(s)):
        if s[i] not in {'4', '7'}:
            continue
        current = []
        for j in range(i, len(s)):
            if s[j] not in {'4', '7'}:
                break
            current.append(s[j])
            valid_substrings.add(''.join(current))
    
    if not valid_substrings:
        return "-1"
    
    # Count occurrences of each valid substring
    counts = {}
    for t in valid_substrings:
        L = len(t)
        cnt = 0
        for i in range(len(s) - L + 1):
            if s[i:i+L] == t:
                cnt += 1
        counts[t] = cnt
    
    max_count = max(counts.values())
    candidates = [t for t in counts if counts[t] == max_count]
    candidates.sort()  # Lexicographical order
    
    return candidates[0]

# Read input and execute the function
import sys
s = sys.stdin.readline().strip()
print(find_lucky_substring(s))
```

### Explanation
1. **Generating Valid Substrings**: The code iterates through each character of the string. If the character is 4 or 7, it generates all possible substrings starting from that character and checks if they consist only of 4 and 7. These valid substrings are stored in a set to avoid duplicates.
2. **Counting Occurrences**: For each valid substring, the code counts how many times it appears in the original string using nested loops. This includes overlapping occurrences.
3. **Finding Maximum Frequency**: The maximum occurrence count is determined using the `max` function on the count values.
4. **Selecting Lexicographically Smallest**: The valid substrings with the maximum count are sorted lexicographically, and the smallest one is returned as the result.

This approach ensures that we efficiently generate and check all possible valid substrings, count their occurrences accurately, and select the required result based on the problem constraints.
