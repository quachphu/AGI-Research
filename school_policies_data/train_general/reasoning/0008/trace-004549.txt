### Approach
The problem can be reduced to checking if the product of the number of rows (r) and columns (c) is even. This is because a valid rearrangement where each student moves to an adjacent seat is only possible if the total number of seats (r * c) is even. When the product is even, the grid can be tiled with dominoes (2x1 or 1x2 tiles), ensuring each student can move to an adjacent seat. If the product is odd, such a rearrangement is impossible.

def solve():
    import sys
    for line in sys.stdin:
        r, c = map(int, line.strip().split())
        if r == 0 and c == 0:
            break
        print("yes" if (r * c) % 2 == 0 else "no")

solve()
