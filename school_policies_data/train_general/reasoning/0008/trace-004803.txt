To solve this problem, we need to implement an efficient autocomplete feature that, given an incomplete search query, returns the maximum weight of any database entry that starts with the given query string. The solution must handle large input sizes efficiently.

### Approach
1. **Trie Data Structure**: We use a trie (prefix tree) to store the database entries. Each node in the trie represents a prefix and stores the maximum weight of all entries that start with that prefix.
2. **Global Maximum Weight**: Track the maximum weight of all entries to handle empty queries efficiently.
3. **Efficient Insertion**: For each entry, insert it into the trie and update the maximum weight for each node along the insertion path.
4. **Query Processing**: For each query, traverse the trie to find the node corresponding to the query. If the traversal is successful, return the maximum weight stored in that node; otherwise, return -1.

### Solution Code
```python
import sys

def main():
    root = {'children': {}, 'max_weight': -1}
    global_max = -1

    data = sys.stdin.read().split()
    ptr = 0
    n = int(data[ptr])
    q = int(data[ptr+1])
    ptr += 2

    for _ in range(n):
        s = data[ptr]
        w = int(data[ptr+1])
        ptr += 2
        if w > global_max:
            global_max = w
        current = root
        for c in s:
            if c not in current['children']:
                current['children'][c] = {'children': {}, 'max_weight': -1}
            current = current['children'][c]
            if w > current['max_weight']:
                current['max_weight'] = w

    output = []
    for _ in range(q):
        t = data[ptr]
        ptr += 1
        if not t:
            output.append(str(global_max) if global_max != -1 else '-1')
        else:
            current = root
            found = True
            for c in t:
                if c not in current['children']:
                    found = False
                    break
                current = current['children'][c]
            if found:
                res = current['max_weight']
                output.append(str(res) if res != -1 else '-1')
            else:
                output.append('-1')
    
    print('\n'.join(output))

if __name__ == '__main__':
    main()
```

### Explanation
1. **Trie Construction**: Each node in the trie is a dictionary with children nodes and a max_weight. As we insert each string into the trie, we update the max_weight for each node along the path to be the maximum of its current value and the new weight.
2. **Global Maximum**: This is maintained to handle empty queries quickly, as all entries start with an empty string.
3. **Query Handling**: For each query, we traverse the trie. If we successfully traverse all characters of the query, the max_weight at the final node is the result. If any character is missing during traversal, the result is -1.

This approach ensures efficient insertion and query operations, making it suitable for large input sizes as specified in the problem constraints.
