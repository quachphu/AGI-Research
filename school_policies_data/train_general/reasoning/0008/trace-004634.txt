### Approach
1. **Identify the Minimum Paint Requirement**: Determine the minimum amount of paint required to write any digit from 1 to 9. This helps in calculating the maximum possible length of the number Igor can write.
2. **Check Feasibility**: If the minimum paint required is more than the available paint, Igor cannot write any number, and we return -1.
3. **Determine Maximum Length**: Calculate the maximum number of digits (length) Igor can write using the available paint and the minimum paint required per digit.
4. **Construct the Initial Number**: Use the digit that requires the minimum paint and has the highest value to form the initial number of maximum length.
5. **Optimize the Number**: Use any remaining paint to replace digits in the initial number with higher-value digits wherever possible, starting from the most significant digit to the least significant digit.
