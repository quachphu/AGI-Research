To solve this problem, we need to efficiently handle a sequence of insert and find operations on a set of integers. The goal is to ensure that each insert operation adds a unique element and reports the size of the set after the insertion, while each find operation checks the presence of an element and reports the result.

### Approach
1. **Data Structure**: Use a Python `set` to store the elements. This data structure provides average O(1) time complexity for both insertion and membership checking, which is optimal given the problem constraints.
2. **Input Handling**: Read all input at once using `sys.stdin.read()` for efficiency, especially with large input sizes. This minimizes the overhead of repeated input calls.
3. **Operations**:
   - **Insert (0 x)**: Add the element to the set and print the current size of the set. The `add` method of the set ensures no duplicates.
   - **Find (1 x)**: Check if the element is present in the set and print 1 if found, otherwise 0.

### Solution Code
```python
import sys

def main():
    s = set()
    data = sys.stdin.read().split()
    q = int(data[0])
    index = 1
    for _ in range(q):
        op = data[index]
        x = int(data[index + 1])
        index += 2
        if op == '0':
            s.add(x)
            print(len(s))
        else:
            print(1 if x in s else 0)

if __name__ == "__main__":
    main()
```

### Explanation
- **Data Structure**: The use of a Python `set` ensures that all elements are unique and provides efficient insertion and membership checks.
- **Efficient Input Handling**: Reading all input at once and processing it in memory reduces the overhead of reading from standard input line by line, which is crucial for handling up to 200,000 operations efficiently.
- **Operations**:
  - **Insert Operation**: The `add` method is used to insert elements into the set. Since sets automatically handle duplicates, inserting an existing element has no effect. The size of the set is then printed immediately after each insertion.
  - **Find Operation**: The membership check using `in` operator on the set is efficient and directly returns the required result (1 or 0).

This approach ensures that each operation is handled in average O(1) time, making the solution efficient and scalable for large input sizes.
