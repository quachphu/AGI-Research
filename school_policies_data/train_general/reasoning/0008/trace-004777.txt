To solve this problem, we need to determine the number of historical events that are fully contained within another event. An event \( j \) includes event \( i \) if the start of \( j \) is before the start of \( i \) and the end of \( j \) is after the end of \( i \).

### Approach
1. **Sort Events**: First, we sort the events based on their start times. This allows us to process events in chronological order.
2. **Track Maximum End Time**: As we iterate through the sorted events, we maintain the maximum end time encountered so far. For each event, if its end time is less than this maximum, it means this event is contained within a previous event. Otherwise, we update the maximum end time.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    events = []
    index = 1
    for _ in range(n):
        a = int(input[index])
        b = int(input[index + 1])
        events.append((a, b))
        index += 2
    
    events.sort()
    max_b = 0
    count = 0
    for a, b in events:
        if b < max_b:
            count += 1
        else:
            max_b = b
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into a list of tuples representing the start and end times of each event.
2. **Sorting Events**: The events are sorted based on their start times. This ensures that any event processed later in the list starts after the previously processed events.
3. **Tracking Maximum End Time**: As we iterate through the sorted events, we keep track of the maximum end time encountered. For each event, if its end time is less than this maximum, it is counted as contained. Otherwise, the maximum end time is updated to the current event's end time.

This approach efficiently determines the number of contained events in \( O(n \log n) \) time due to sorting, which is optimal for the given problem constraints.
