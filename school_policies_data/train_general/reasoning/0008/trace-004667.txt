To solve this problem, we need to compute the integer part of the square root of given integers using Python's built-in functions. The solution involves reading multiple test cases, computing the square root for each, and printing the result.

### Approach
1. **Reading Input**: The first line of input specifies the number of test cases. Each subsequent line contains an integer for which we need to compute the square root.
2. **Compute Square Root**: For each integer, we use Python's `math.sqrt` function to compute the square root. Since the problem requires the integer part (floor value) of the square root, we convert the result of `math.sqrt` to an integer using `int()`.
3. **Output the Result**: Print the computed integer square root for each test case.

### Solution Code
```python
import math
import sys

def compute_square_roots():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        print(int(math.sqrt(n)))

compute_square_roots()
```

### Explanation
1. **Reading Input**: The function reads the number of test cases `t` using `sys.stdin.readline()`. Then, for each test case, it reads the integer `n`.
2. **Computing Square Root**: The `math.sqrt` function computes the square root of `n` as a floating-point number. Converting this result to an integer using `int()` truncates the decimal part, effectively giving the floor value of the square root.
3. **Output**: The result for each test case is printed immediately after computation.

This approach efficiently handles the constraints and ensures accurate results using Python's built-in functions, adhering to the problem requirements.
