To solve this problem, we need to count the number of Pythagorean triplets (a, b, c) such that \(1 \leq a \leq b \leq c \leq N\) for given values of N. The solution involves precomputing values to efficiently answer multiple queries.

### Approach
1. **Generate Primitive Triplets**: Using Euclid's formula, generate all primitive Pythagorean triplets (a, b, c) where \(c \leq 10^6\). A triplet is primitive if m and n are coprime and not both odd.
2. **Precompute Contributions**: For each primitive triplet's hypotenuse c, calculate how many times each multiple of c (up to \(10^6\)) contributes to the count of valid triplets.
3. **Prefix Sum Array**: Build a prefix sum array to quickly answer each query in constant time by summing up the contributions up to the given N.

### Solution Code
```python
import sys
import math
from math import gcd

def generate_primitive_c(max_n):
    primitive_c = []
    max_m = int(math.isqrt(max_n)) + 1
    for m in range(2, max_m + 1):
        for n in range(1, m):
            if gcd(m, n) == 1 and (m % 2 + n % 2) != 2:
                c = m * m + n * n
                if c <= max_n:
                    primitive_c.append(c)
    return primitive_c

def main():
    max_N = 10**6
    primitive_c = generate_primitive_c(max_N)

    # Build ans array where ans[i] is the number of primitive c's that divide i
    ans = [0] * (max_N + 1)
    for c in primitive_c:
        ans[c::c] = [x + 1 for x in ans[c::c]]

    # Compute prefix sums to get the total count up to each N
    prefix_sum = [0] * (max_N + 1)
    current_sum = 0
    for i in range(1, max_N + 1):
        current_sum += ans[i]
        prefix_sum[i] = current_sum

    # Read input and output results
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        N = int(input[i])
        print(prefix_sum[N])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Generating Primitive Triplets**: Using Euclid's formula, we generate all possible values of c (hypotenuse) for primitive triplets up to \(10^6\). This ensures we consider all possible bases for forming valid triplets.
2. **Precomputing Contributions**: For each primitive triplet's hypotenuse c, we mark all multiples of c up to \(10^6\). Each multiple k*c contributes one valid triplet (k*a, k*b, k*c).
3. **Efficient Query Handling**: Using a prefix sum array, we precompute the cumulative count of valid triplets up to each possible value of N. This allows each query to be answered in constant time by simply looking up the precomputed value.

This approach ensures that we efficiently handle up to the maximum constraint of \(N = 10^6\) and answer each query in O(1) time after preprocessing.
