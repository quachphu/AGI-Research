To solve this problem, we need to determine the floor number where Petya's apartment is located based on the given apartment number and the number of apartments per floor (excluding the first floor, which has 2 apartments). 

### Approach
1. **Understanding the Problem Structure**:
   - The first floor has 2 apartments.
   - Each subsequent floor (starting from the second) has `x` apartments.
   - Apartment numbers are sequential starting from 1 on the first floor.

2. **Key Insight**:
   - For apartment numbers 1 and 2, the answer is straightforward: they are on the first floor.
   - For apartment numbers greater than 2, we need to calculate how many floors are required after the first floor. This can be done by subtracting the first two apartments and then using ceiling division to determine the number of additional floors needed.

3. **Mathematical Formulation**:
   - If `n` is the apartment number, subtract the first two apartments: `remaining = n - 2`.
   - Use ceiling division to determine the number of additional floors: `ceil(remaining / x)`, which can be computed as `(remaining + x - 1) // x`.
   - Add 1 to account for the first floor.

### Solution Code
```python
def main():
    import sys
    t = int(sys.stdin.readline())
    for _ in range(t):
        n, x = map(int, sys.stdin.readline().split())
        if n <= 2:
            print(1)
        else:
            print(1 + (n - 2 + x - 1) // x)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The number of test cases `t` is read first. For each test case, the values of `n` (apartment number) and `x` (apartments per floor starting from the second) are read.
- **First Floor Check**: If the apartment number `n` is 1 or 2, the result is immediately 1 since these are on the first floor.
- **Calculation for Higher Floors**: For apartment numbers greater than 2, the remaining apartments after the first floor are calculated. Using ceiling division, we determine how many additional floors are needed and add 1 to include the first floor.

This approach efficiently computes the floor number using arithmetic operations, ensuring optimal performance even for the upper input limits.
