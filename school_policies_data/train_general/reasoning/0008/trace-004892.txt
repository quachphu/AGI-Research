To solve this problem, we need to determine how many programmers each programmer can mentor, considering their skill levels and quarrels. A programmer can mentor another if their skill is strictly higher and they are not in a quarrel.

### Approach
1. **Sort the Skills**: First, we sort the list of programmers' skills. This allows us to efficiently determine the number of programmers with lower skills using binary search.
2. **Calculate Potential Mentees**: For each programmer, use binary search to find how many programmers have lower skills. This gives the initial count of potential mentees.
3. **Adjust for Quarrels**: For each quarrel pair, check the skill levels of the involved programmers. If one programmer has a higher skill than the other, reduce the potential mentee count of the higher-skilled programmer by 1, as they cannot mentor each other due to the quarrel.

### Solution Code
```python
import bisect

n, k = map(int, input().split())
r = list(map(int, input().split()))
sorted_r = sorted(r)
mentees = [bisect.bisect_left(sorted_r, x) for x in r]

for _ in range(k):
    x, y = map(int, input().split())
    a = x - 1
    b = y - 1
    if r[a] > r[b]:
        mentees[a] -= 1
    elif r[b] > r[a]:
        mentees[b] -= 1

print(' '.join(map(str, mentees)))
```

### Explanation
1. **Sorting Skills**: By sorting the skills, we can efficiently use binary search to determine the number of programmers with lower skills for each programmer.
2. **Binary Search for Initial Count**: Using `bisect.bisect_left`, we find the position where each programmer's skill would fit in the sorted list, which gives the count of programmers with lower skills.
3. **Adjusting for Quarrels**: For each quarrel pair, we check which programmer has a higher skill and decrement their potential mentee count, as they cannot mentor each other due to the quarrel.

This approach efficiently handles the constraints, ensuring the solution runs in O(n log n + k) time, which is suitable for large inputs.
