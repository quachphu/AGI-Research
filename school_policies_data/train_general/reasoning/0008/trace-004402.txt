To solve this problem, we need to determine the sum of a Nice-P sequence given an initial element \(a1\), a modulus \(p\), and the length of the sequence \(n\). The sequence is defined such that each consecutive pair of elements multiplies to 1 modulo \(p\). If any element in the sequence does not have a valid inverse modulo \(p\), we should return -1.

### Approach
1. **Check Coprimality**: First, check if \(a1\) and \(p\) are coprime using the greatest common divisor (GCD). If they are not coprime, \(a1\) does not have an inverse modulo \(p\), and we return -1.
2. **Compute Modular Inverse**: If \(a1\) and \(p\) are coprime, compute the modular inverse of \(a1\) modulo \(p\) using Python's built-in `pow` function.
3. **Check Self-Inverse**: Determine if \(a1\) is its own inverse modulo \(p\). If \(a1^2 \equiv 1 \mod p\), the sequence will consist of \(a1\) repeated \(n\) times.
4. **Sum Calculation**: If \(a1\) is not its own inverse, the sequence alternates between \(a1\) and its modular inverse. The sum is calculated based on whether \(n\) is even or odd.

### Solution Code
```python
import sys
import math

def main():
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    results = []
    for _ in range(T):
        a1 = int(input[idx])
        p = int(input[idx + 1])
        n = int(input[idx + 2])
        idx += 3
        
        if math.gcd(a1, p) != 1:
            results.append(-1)
            continue
        
        try:
            a2 = pow(a1, -1, p)
        except ValueError:
            results.append(-1)
            continue
        
        if (a1 * a1) % p == 1:
            total = a1 * n
        else:
            pairs = n // 2
            remainder = n % 2
            total = pairs * (a1 + a2) + remainder * a1
        
        results.append(total)
    
    sys.stdout.write('\n'.join(map(str, results)) + '\n')

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once for efficiency, especially given the large constraints.
2. **Coprimality Check**: Using the GCD, we determine if \(a1\) and \(p\) are coprime. If not, the result is immediately -1.
3. **Modular Inverse Calculation**: Using Python's `pow` function with three arguments, we efficiently compute the modular inverse.
4. **Self-Inverse Check**: If \(a1\) is its own inverse, the sequence is simply \(a1\) repeated \(n\) times.
5. **Alternating Sequence Sum**: For non-self-inverse \(a1\), the sum is calculated by considering pairs of \(a1\) and its inverse, adjusting for odd lengths by adding the initial element if necessary.

This approach ensures that we handle up to \(10^5\) test cases efficiently, even with the maximum constraints, by leveraging mathematical properties and efficient modular arithmetic.
