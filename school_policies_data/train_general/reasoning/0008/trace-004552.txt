To solve this problem, we need to compute the points each participant earns in a round-robin tournament based on their GPA values. The points are awarded such that a win gives 3 points, a draw gives 1 point, and a loss gives 0 points. The challenge is to efficiently compute these points given the constraints.

### Approach
1. **Convert GPA Values**: Convert each GPA value from a string to an integer by considering the three decimal places. This avoids floating-point precision issues.
2. **Sort the Values**: Sorting the converted integer values allows us to use binary search for efficient counting.
3. **Binary Search for Counts**: For each GPA value, use binary search to determine the number of participants with a lower GPA (count_less) and the number of participants with the same GPA (count_equal).
4. **Calculate Points**: For each participant, calculate points using the counts obtained from the binary search. The formula used is `3 * count_less + 1 * (count_equal - 1)`.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    original = []
    idx = 1
    for _ in range(n):
        s = input[idx].strip()
        idx += 1
        integer_part, fractional_part = s.split('.')
        fractional = fractional_part.ljust(3, '0')[:3]
        val = int(integer_part) * 1000 + int(fractional)
        original.append(val)
    
    sorted_original = sorted(original)
    
    points = []
    for val in original:
        less = bisect.bisect_left(sorted_original, val)
        equal_left = less
        equal_right = bisect.bisect_right(sorted_original, val)
        equal = equal_right - equal_left
        p = 3 * less + (equal - 1) * 1
        points.append(p)
    
    for point in points:
        print(point)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and split into lines. The first line gives the number of participants, and subsequent lines provide their GPA values.
2. **Conversion to Integer**: Each GPA string is split into integer and fractional parts. These parts are combined into an integer by multiplying the integer part by 1000 and adding the fractional part as an integer.
3. **Sorting**: The converted integer values are sorted to facilitate efficient counting using binary search.
4. **Binary Search Counts**: For each GPA value, `bisect_left` finds the number of values less than the current value, and `bisect_right` helps determine the number of equal values.
5. **Points Calculation**: Using the counts from the binary search, points are calculated for each participant based on the rules provided.

This approach ensures an efficient solution with a time complexity of O(N log N), which is suitable for large input sizes up to 100,000 participants.
