To solve this problem, we need to determine the maximum score achievable in a directed graph game where coins are collected on edges and a payment is made based on the time taken to reach the end vertex. The solution involves detecting cycles that allow infinite score gains and finding the longest path if such cycles do not exist.

### Approach
1. **Graph Transformation**: Convert each edge's coin value to a weight of (coins - payment per minute), which represents the net gain or loss per edge traversal.
2. **Reachability Check**: Identify nodes that can reach the end vertex (N) using a reversed graph traversal from N.
3. **Bellman-Ford Algorithm**: Use this algorithm to find the longest path from the start vertex (1) to the end vertex (N). This helps in detecting any positive cycles that can be exploited for infinite score gains.
4. **Cycle Detection**: After running Bellman-Ford, check for any edges that can still be relaxed (indicating a positive cycle) and ensure they are part of a path leading to the end vertex.

### Solution Code
```python
import sys
from collections import deque

def main():
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx]); idx +=1
    M = int(input[idx]); idx +=1
    P = int(input[idx]); idx +=1

    edges = []
    reversed_adj = [[] for _ in range(N+1)]  # For BFS to find reachable to N
    for _ in range(M):
        a = int(input[idx]); idx +=1
        b = int(input[idx]); idx +=1
        c = int(input[idx]); idx +=1
        edges.append( (a, b, c) )
        reversed_adj[b].append(a)  # Reverse the edge for BFS

    # Step 1: Find all nodes that can reach N in the original graph (using BFS on reversed edges)
    can_reach_n = [False]*(N+1)
    q = deque()
    q.append(N)
    can_reach_n[N] = True
    while q:
        u = q.popleft()
        for v in reversed_adj[u]:
            if not can_reach_n[v]:
                can_reach_n[v] = True
                q.append(v)

    # Transform edges to (C_i - P)
    transformed_edges = [ (a, b, c - P) for a, b, c in edges ]

    # Bellman-Ford for longest path
    max_dist = [ -float('inf') ] * (N+1)
    max_dist[1] = 0

    for i in range(N-1):
        updated = False
        for a, b, w in transformed_edges:
            if max_dist[a] != -float('inf') and max_dist[b] < max_dist[a] + w:
                max_dist[b] = max_dist[a] + w
                updated = True
        if not updated:
            break

    # Check for possible relaxation indicating positive cycle that can reach N
    has_cycle = False
    for a, b, w in transformed_edges:
        if max_dist[a] != -float('inf') and max_dist[b] < max_dist[a] + w:
            if can_reach_n[b]:
                has_cycle = True
                break

    if has_cycle:
        print(-1)
    else:
        ans = max( max_dist[N], 0 )
        print(ans)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Graph Transformation**: Each edge's weight is adjusted by subtracting the payment per minute (P) from its coin value. This helps in evaluating the net gain per edge traversal.
2. **Reachability Check**: Using a reversed graph, we determine which nodes can reach the end vertex (N). This is crucial for detecting cycles that can influence the score.
3. **Bellman-Ford Algorithm**: This algorithm is used to find the longest path in the transformed graph. It also helps in detecting positive cycles that can lead to an unbounded score.
4. **Cycle Detection**: After processing all edges for N-1 iterations, any remaining relaxable edges that can reach N indicate a positive cycle, leading to an infinite score. If such cycles exist, the result is -1; otherwise, the maximum score is computed and adjusted to be non-negative.

This approach efficiently handles the constraints and ensures optimal performance using graph traversal and dynamic programming techniques.
