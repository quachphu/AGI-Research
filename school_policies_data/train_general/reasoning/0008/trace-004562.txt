To solve this problem, we need to implement a file suggestion feature that efficiently processes multiple queries to count how many file names contain a given substring and return any of those file names. The solution must handle up to 10,000 files and 50,000 queries efficiently.

### Approach
1. **Preprocessing Files**: 
   - For each file, generate all possible substrings and store these substrings in a dictionary. This dictionary maps each substring to a tuple containing the count of files that include this substring and an example file name.
   - When generating substrings for a file, iterate over all possible start and end indices to ensure every contiguous substring is considered. Use a set to avoid duplicate substrings within the same file.

2. **Handling Queries**:
   - For each query, check the preprocessed dictionary to quickly retrieve the count of files containing the substring and an example file name. This ensures each query is processed in constant time, O(1).

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1

    substr_info = {}

    for _ in range(n):
        filename = input[ptr]
        ptr += 1
        subs = set()
        length = len(filename)
        for i in range(length):
            for j in range(i, length):
                subs.add(filename[i:j+1])
        for s in subs:
            if s in substr_info:
                substr_info[s] = (substr_info[s][0] + 1, filename)
            else:
                substr_info[s] = (1, filename)

    q = int(input[ptr])
    ptr += 1

    output = []
    for _ in range(q):
        s = input[ptr]
        ptr += 1
        if s in substr_info:
            count, example = substr_info[s]
            output.append(f"{count} {example}")
        else:
            output.append("0 -")
    
    print('\n'.join(output))

if __name__ == "__main__":
    main()
```

### Explanation
- **Preprocessing**: For each file, all possible substrings are generated and stored in a set to avoid duplicates. Each substring is then added to a dictionary where the value is a tuple consisting of the count of files containing the substring and an example file name (the last file that contributed to the substring).
- **Query Handling**: Each query is checked against the preprocessed dictionary. If the substring exists, the count and example file name are retrieved in constant time. If not, the result indicates no matches.

This approach ensures efficient preprocessing and query handling, making the solution scalable even for the upper limits of the problem constraints.
