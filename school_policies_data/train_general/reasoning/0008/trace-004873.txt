To solve this problem, we need to determine the maximum number of steps (k) in a ladder that can be constructed from a given set of planks. The ladder requires two base planks of length at least k+1 and k step planks each of length at least 1. 

### Approach
1. **Sort the Planks**: First, sort the planks in descending order. This helps in efficiently determining the longest possible base planks.
2. **Determine Base Constraints**: The two longest planks will form the base of the ladder. The minimum of these two lengths determines the maximum possible value for k+1.
3. **Check Plank Availability**: The total number of planks needed for a k-step ladder is k+2 (2 bases + k steps). Ensure that there are enough planks available to form the ladder.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        n = int(input[idx])
        idx += 1
        a = list(map(int, input[idx:idx + n]))
        idx += n
        a.sort(reverse=True)
        if len(a) < 2:
            print(0)
            continue
        possible_k = min(a[0], a[1]) - 1
        possible_k2 = n - 2
        ans = min(possible_k, possible_k2)
        print(max(ans, 0))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Sorting**: The planks are sorted in descending order to easily access the two longest planks.
3. **Base Planks Check**: The maximum possible k+1 is determined by the shorter of the two longest planks. Subtracting 1 from this value gives the maximum possible k.
4. **Plank Availability Check**: The number of available planks (n) must be at least k+2. This translates to ensuring that k does not exceed (n-2).
5. **Result Calculation**: The result for each test case is the minimum of the two constraints mentioned above, ensuring it is non-negative.

This approach efficiently combines sorting and constraint checks to determine the maximum possible k for each test case, ensuring optimal performance even for large input sizes.
