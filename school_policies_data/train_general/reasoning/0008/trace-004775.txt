To solve this problem, we need to determine the number of prefixes of an infinite binary string (formed by repeating a given string `s`) that have a specific balance. The balance of a string is defined as the number of '0's minus the number of '1's. If there are infinitely many such prefixes, we return -1.

### Approach
1. **Balance Calculation**: For each prefix of the string `s`, compute the balance and store these values in an array. The balance after each full repetition of `s` (denoted as `delta`) is crucial because it determines how the balance changes with each subsequent repetition of `s`.

2. **Delta Check**: If the balance change (`delta`) after one full repetition of `s` is zero, check if the target balance `x` is present in any prefix of `s`. If it is, there are infinitely many prefixes; otherwise, there are none.

3. **Non-zero Delta Handling**: If `delta` is non-zero, for each prefix of `s`, determine how many full repetitions of `s` (if any) would result in the target balance `x`. This is done by solving the equation `delta * k + balance[m] = x` for non-negative integer `k`.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        n, x = int(input[idx]), int(input[idx+1])
        idx += 2
        s = input[idx]
        idx += 1
        balance = [0] * (n + 1)
        for i in range(n):
            if s[i] == '0':
                balance[i+1] = balance[i] + 1
            else:
                balance[i+1] = balance[i] - 1
        delta = balance[-1]
        if delta == 0:
            found = x in balance[:n]
            print(-1 if found else 0)
        else:
            count = 0
            for m in range(n):
                target = x - balance[m]
                if target % delta != 0:
                    continue
                k = target // delta
                if k >= 0:
                    count += 1
            print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Balance Array Construction**: The balance array is constructed to store the balance after each character in `s`, starting from the empty prefix (balance 0).
3. **Delta Calculation**: The balance after one full repetition of `s` (delta) is calculated. This helps determine if the balance can be achieved infinitely.
4. **Infinite Check (Delta Zero)**: If `delta` is zero, check if the target balance `x` exists in any prefix of `s`. If it does, print -1; otherwise, print 0.
5. **Finite Check (Non-zero Delta)**: For each prefix of `s`, solve the linear equation to check if valid non-negative integer solutions exist. Count valid solutions and print the result.

This approach efficiently handles both finite and infinite cases, ensuring optimal performance even for large input sizes.
