To solve this problem, we need to determine the number of cells in a grid that are centers of Prime-Cross (CPC). A cell is considered a CPC if it meets specific criteria related to contiguous cells in all four directions (left, right, top, bottom).

### Approach
1. **Problem Analysis**: A cell is a CPC if it is not a wall (`#`) and the minimum number of contiguous non-wall cells in all four directions (left, right, top, bottom) is at least 2. This is because the smallest prime number is 2, and any minimum value greater than or equal to 2 will have at least one prime number (e.g., 2) that satisfies the condition.

2. **Algorithm**:
   - For each test case, read the grid dimensions and the grid itself.
   - For each cell in the grid, check if it is a non-wall cell (`^`).
   - For each valid cell, compute the number of contiguous non-wall cells in all four directions (left, right, top, bottom).
   - Determine the minimum value among these four directions. If this minimum value is at least 2, increment the count of CPC cells.

3. **Complexity Consideration**: Given the constraints (grid size up to 50x50), the algorithm efficiently checks each cell and computes the contiguous cells in linear time for each direction, resulting in a manageable time complexity.

### Solution Code
```python
def count_monsters():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        R = int(input[idx])
        C = int(input[idx+1])
        idx +=2
        grid = []
        for _ in range(R):
            grid.append(input[idx])
            idx +=1
        count = 0
        for i in range(R):
            for j in range(C):
                if grid[i][j] != '^':
                    continue
                # Compute L
                l = 0
                x = j - 1
                while x >= 0 and grid[i][x] == '^':
                    l += 1
                    x -= 1
                # Compute R
                r = 0
                x = j + 1
                while x < C and grid[i][x] == '^':
                    r += 1
                    x += 1
                # Compute T
                t = 0
                y = i - 1
                while y >= 0 and grid[y][j] == '^':
                    t += 1
                    y -= 1
                # Compute B
                b = 0
                y = i + 1
                while y < R and grid[y][j] == '^':
                    b += 1
                    y += 1
                min_val = min(l, r, t, b)
                if min_val >= 2:
                    count += 1
        print(count)

count_monsters()
```

### Explanation
- **Reading Input**: The input is read in one go for efficiency, especially given multiple test cases.
- **Grid Processing**: For each cell in the grid, we check if it is a non-wall cell. If it is, we compute the contiguous non-wall cells in all four directions.
- **Direction Calculation**: For each direction (left, right, top, bottom), we count the number of contiguous non-wall cells starting from the current cell and moving outward until a wall or the grid boundary is encountered.
- **Prime Check**: The minimum value of the four directions is checked against the smallest prime number (2). If the minimum value is at least 2, the cell is counted as a CPC.

This approach ensures that we efficiently and correctly determine the number of CPC cells in each grid, adhering to the problem constraints and requirements.
