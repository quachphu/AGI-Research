To solve this problem, we need to determine the minimum number of 2050-numbers required to sum up to a given number \( n \). A 2050-number is defined as \( 2050 \times 10^k \) for any non-negative integer \( k \). If it's impossible to represent \( n \) using such numbers, we should return -1.

### Approach
1. **Check Divisibility**: First, check if \( n \) is divisible by 2050. If not, it's impossible to represent \( n \) using 2050-numbers, so the result is -1.
2. **Reduce the Problem**: If \( n \) is divisible by 2050, divide \( n \) by 2050 to get a new number \( m \). The problem then reduces to finding the minimum number of terms required to sum up to \( m \) using powers of 10 (e.g., 1, 10, 100, etc.).
3. **Sum of Digits**: The minimum number of terms required to sum up to \( m \) using powers of 10 is equivalent to the sum of the digits of \( m \). This is because each digit in \( m \) represents how many times a particular power of 10 is used.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        n = int(input[i])
        if n % 2050 != 0:
            print(-1)
        else:
            m = n // 2050
            digit_sum = sum(int(d) for d in str(m))
            print(digit_sum)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints. The first value is the number of test cases \( T \).
2. **Processing Each Test Case**: For each test case, we check if \( n \) is divisible by 2050. If not, we immediately output -1.
3. **Reduction and Digit Sum**: If \( n \) is divisible by 2050, we compute \( m \) by dividing \( n \) by 2050. The sum of the digits of \( m \) gives the minimum number of 2050-numbers needed, as each digit represents how many times a particular power of 10 (and thus a 2050-number) is used.

This approach efficiently handles the constraints and ensures that we quickly determine the result using simple arithmetic operations and string manipulation to sum the digits.
