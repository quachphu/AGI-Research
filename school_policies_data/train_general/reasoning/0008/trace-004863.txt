To solve this problem, we need to determine the minimum number of balloons Chef must draw from a bag to ensure that there are at least K balloons of the same color, even in the worst-case scenario. 

### Approach
The key insight here is to consider the worst-case scenario where Chef draws the maximum number of balloons without having K balloons of any single color. This can be achieved by calculating the sum of the minimum number of balloons that can be taken from each color without reaching K. Adding one more balloon to this sum ensures that Chef will have at least K balloons of one color.

1. **Understanding the Worst-Case Scenario**: The worst-case scenario occurs when Chef draws (K-1) balloons from each of the two colors with the highest counts and as many as possible from the third color without reaching K.
2. **Summing Minimums**: For each color, calculate the minimum of the number of balloons of that color and (K-1). This gives the maximum number of balloons that can be drawn without reaching K in any color.
3. **Adding One More Balloon**: The result is the sum of these minimum values plus one additional balloon, which ensures that at least one color will have K balloons.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        r, g, b = map(int, sys.stdin.readline().split())
        k = int(sys.stdin.readline())
        sum_min = min(r, k-1) + min(g, k-1) + min(b, k-1)
        print(sum_min + 1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads the number of test cases, then for each test case, it reads the number of red, green, and blue balloons followed by the value K.
2. **Calculating Minimum Balloons**: For each color (red, green, blue), the code calculates how many balloons can be drawn without exceeding K-1. This is done using `min(color_count, K-1)`.
3. **Summing and Adding One**: The sum of these minimum values gives the maximum number of balloons that can be drawn without having K of any color. Adding one ensures that the next balloon drawn will result in at least K balloons of one color, thus saving the passengers.

This approach efficiently handles the constraints and ensures correctness by leveraging the pigeonhole principle to determine the worst-case scenario. The solution runs in O(T) time complexity where T is the number of test cases, making it efficient even for the upper constraint limits.
