To solve this problem, we need to determine the minimum number of steps required to obtain exactly `c` liters of water in one of two vessels, given their capacities `a` and `b`. The operations allowed are filling, emptying, and pouring water between the vessels. 

### Approach
1. **Check Trivial Cases**: If `c` is 0, the answer is 0. If `c` is greater than both `a` and `b`, it's impossible, so return -1.
2. **Check Divisibility**: Use the greatest common divisor (GCD) of `a` and `b` to determine if `c` can be measured. If `c` is not a multiple of the GCD, return -1.
3. **Simulate Pouring**: Use a simulation approach to model the process of filling, emptying, and pouring water between the two vessels in two scenarios:
   - Pouring from the first vessel to the second.
   - Pouring from the second vessel to the first.
4. **Breadth-First Search (BFS)**: Track visited states to avoid cycles and compute the minimum steps required for each scenario. Return the minimum steps from both scenarios.

### Solution Code
```python
import sys
import math

def simulate(from_cap, to_cap, target):
    from_current = 0
    to_current = 0
    steps = 0
    visited = set()
    
    while True:
        if from_current == target or to_current == target:
            return steps
        state = (from_current, to_current)
        if state in visited:
            return -1
        visited.add(state)
        
        if from_current == 0:
            from_current = from_cap
            steps += 1
        else:
            pour = min(from_current, to_cap - to_current)
            from_current -= pour
            to_current += pour
            steps += 1
            if from_current == target or to_current == target:
                return steps
            if to_current == to_cap:
                to_current = 0
                steps += 1

def solve():
    t = int(sys.stdin.readline())
    for _ in range(t):
        a = int(sys.stdin.readline().strip())
        b = int(sys.stdin.readline().strip())
        c = int(sys.stdin.readline().strip())
        
        if c == 0:
            print(0)
            continue
        if c > max(a, b):
            print(-1)
            continue
        gcd_val = math.gcd(a, b)
        if c % gcd_val != 0:
            print(-1)
            continue
        
        steps1 = simulate(a, b, c)
        steps2 = simulate(b, a, c)
        
        results = []
        if steps1 != -1:
            results.append(steps1)
        if steps2 != -1:
            results.append(steps2)
        
        if not results:
            print(-1)
        else:
            print(min(results))

solve()
```

3. **Simulation**: The `simulate` function models the process of pouring water between vessels, tracking visited states to avoid cycles. It alternates between filling the source vessel and pouring water to the target, emptying the target when full.
4. **BFS Approach**: By simulating both possible pouring directions (from `a` to `b` and from `b` to `a`), we ensure that we explore all possible minimal paths to reach the target `c` liters. The minimum steps from both simulations are considered to determine the final result.
