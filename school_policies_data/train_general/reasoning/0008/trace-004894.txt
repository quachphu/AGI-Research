To solve this problem, we need to sort a given string based on a custom order defined by another string. The custom order string specifies the priority of each character from highest to lowest. The goal is to rearrange the characters of the input string according to this custom order.

### Approach
1. **Read Input:** Read the number of test cases. For each test case, read the pattern string (P) and the string to be sorted (F).
2. **Create Order Mapping:** Construct a dictionary that maps each character in the pattern string to its index. This index represents the priority of the character, with lower indices indicating higher priority.
3. **Sort Using Custom Order:** Use the dictionary to sort the characters of the input string (F) based on their priority defined by the pattern string (P).
4. **Output the Result:** Join the sorted characters into a string and print the result for each test case.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        p = sys.stdin.readline().strip()
        f = sys.stdin.readline().strip()
        order = {c: i for i, c in enumerate(p)}
        sorted_f = sorted(f, key=lambda x: order[x])
        print(''.join(sorted_f))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The input is read using `sys.stdin.readline()` to efficiently handle potentially large input sizes. Each test case consists of two lines: the pattern string (P) and the string to be sorted (F).
2. **Order Mapping:** A dictionary `order` is created where each character in P is mapped to its index. This allows for O(1) lookup time when determining the priority of each character during sorting.
3. **Sorting:** The characters of F are sorted using Python's built-in `sorted()` function with a custom key that uses the priority from the `order` dictionary. This ensures that characters are sorted according to the custom order specified by P.
4. **Output:** The sorted characters are joined into a single string and printed as the result for each test case.

This approach efficiently handles the constraints, ensuring that even for the maximum input size of 100,000 characters, the sorting operation remains efficient with a time complexity of O(n log n) due to Python's optimized sorting algorithm.
