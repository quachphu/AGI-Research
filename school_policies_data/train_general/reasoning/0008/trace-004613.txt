### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        N = input[i].strip()
        digit_sum = sum(int(c) for c in N)
        num = int(N)
        print(num % digit_sum)

main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first line contains the number of test cases, T. The subsequent T lines each contain a number N.
2. **Sum of Digits**: For each number N, convert it to a string to iterate over each character (digit), convert each character back to an integer, and compute the sum of these integers.
3. **Modulo Operation**: Convert the string representation of N back to an integer and compute the modulo of this integer with the sum of its digits. The result of this operation is printed as the output for each test case.

This approach efficiently computes the required result by leveraging string manipulation to handle individual digits and simple arithmetic operations to compute the modulo.
