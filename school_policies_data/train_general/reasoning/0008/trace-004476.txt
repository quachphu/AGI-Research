To solve this problem, we need to determine the number of non-empty contiguous substrings of commands that return Calvin the robot to his starting position. This means that the net movement in both the horizontal (x) and vertical (y) directions must be zero.

### Approach
1. **Prefix Sum Arrays**: We will use prefix sum arrays to efficiently compute the cumulative displacement in both the x and y directions up to each command. This allows us to quickly determine the net movement for any substring.
2. **Check All Substrings**: For each possible starting and ending index of a substring, we check if the net displacement from the starting index to the ending index is zero in both directions. This is done by comparing the prefix sums at the respective indices.

### Solution Code
```python
n = int(input())
s = input().strip()

prefix_x = [0]
prefix_y = [0]

for c in s:
    dx, dy = 0, 0
    if c == 'U':
        dy = 1
    elif c == 'D':
        dy = -1
    elif c == 'R':
        dx = 1
    elif c == 'L':
        dx = -1
    prefix_x.append(prefix_x[-1] + dx)
    prefix_y.append(prefix_y[-1] + dy)

count = 0
for a in range(n):
    for b in range(a, n):
        dx = prefix_x[b + 1] - prefix_x[a]
        dy = prefix_y[b + 1] - prefix_y[a]
        if dx == 0 and dy == 0:
            count += 1

print(count)
```
