To solve this problem, we need to determine if a given substring can be rearranged into a double palindrome. A double palindrome is defined as a string that can be split into two non-empty palindromic substrings. 

### Approach
1. **Understanding Double Palindromes**: A double palindrome is formed by concatenating two palindromes. Each palindrome can have at most one character with an odd frequency count. Thus, the entire substring must allow for two such partitions.
2. **Key Insight**: For a substring to be rearranged into a double palindrome, the number of characters with odd frequencies (total_odds) must be 0, 1, or 2. This is because each part of the split can have at most one character with an odd frequency.
3. **Efficient Frequency Calculation**: Using prefix sums, we can efficiently compute the frequency of each character in any given substring. This allows us to quickly determine the number of characters with odd frequencies for each query.

### Solution Code
```python
import sys

def main():
    # Read input
    N = int(sys.stdin.readline())
    s = sys.stdin.readline().strip()
    Q = int(sys.stdin.readline())
    queries = [tuple(map(int, sys.stdin.readline().split())) for _ in range(Q)]
    
    # Precompute prefix sums for each character
    prefix = [[0]*(N+1) for _ in range(26)]  # 26 letters a-z, each has a prefix array of size N+1
    for i in range(1, N+1):
        current_char = s[i-1]
        c_idx = ord(current_char) - ord('a')
        for c in range(26):
            prefix[c][i] = prefix[c][i-1]
        prefix[c_idx][i] += 1
    
    # Process each query
    for l, r in queries:
        length = r - l + 1
        if length < 2:
            print("NO")
            continue
        total_odds = 0
        for c in range(26):
            cnt = prefix[c][r] - prefix[c][l-1]
            if cnt % 2 == 1:
                total_odds += 1
        if total_odds <= 2:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prefix Sum Arrays**: We precompute prefix sums for each character in the string. This allows us to quickly determine the frequency of each character in any substring using simple arithmetic.
2. **Query Processing**: For each query, we check the length of the substring. If it's less than 2, the answer is immediately "NO". Otherwise, we compute the number of characters with odd frequencies using the prefix sums and check if this number is 0, 1, or 2. If so, the answer is "YES"; otherwise, it's "NO".

This approach ensures that we efficiently handle up to 100,000 queries on a string of up to 100,000 characters, adhering to the problem constraints.
