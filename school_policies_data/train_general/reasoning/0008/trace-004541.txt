To solve this problem, we need to determine the number of ways to arrange N balls such that exactly K of them are blue, and the blue balls can be collected in exactly i moves, where each move collects a consecutive group of blue balls. The solution involves combinatorial mathematics to efficiently compute the required values modulo \(10^9 + 7\).

### Approach
1. **Combinatorial Analysis**:
   - **Splitting Blue Balls**: The number of ways to split K blue balls into i groups is given by the binomial coefficient \(C(K-1, i-1)\). This is derived from the stars and bars theorem.
   - **Distributing Red Balls**: After placing the i groups of blue balls, we need to ensure they are separated by at least one red ball. The remaining red balls can be distributed around these groups. This is computed using the binomial coefficient \(C(N-K+1, i)\).

2. **Precomputation**:
   - Precompute factorials and their modular inverses up to the maximum possible value (2000) to efficiently compute binomial coefficients.

3. **Modulo Operations**:
   - Use modular arithmetic to handle large numbers and ensure results fit within standard integer limits.

### Solution Code
```python
MOD = 10**9 + 7
max_n = 2000  # Since N can be up to 2000

# Precompute factorial and inverse factorial arrays
fact = [1] * (max_n + 1)
for i in range(1, max_n + 1):
    fact[i] = fact[i-1] * i % MOD

inv_fact = [1] * (max_n + 1)
inv_fact[max_n] = pow(fact[max_n], MOD-2, MOD)
for i in range(max_n - 1, -1, -1):
    inv_fact[i] = inv_fact[i+1] * (i+1) % MOD

def comb(n, k):
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % MOD * inv_fact[n - k] % MOD

def main():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    K = int(input[1])
    M = N - K + 1
    for i in range(1, K+1):
        c1 = comb(K-1, i-1)
        c2 = comb(M, i)
        print((c1 * c2) % MOD)

if __name__ == "__main__":
    main()
```
