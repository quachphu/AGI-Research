To solve this problem, we need to determine the maximum number of trees that lie on one side of a given partition line. The line is defined by the equation Ax + By + C = 0, and each tree's coordinates are provided. The goal is to count how many trees are on either side of the line and return the maximum count.

### Approach
1. **Input Reading**: Efficiently read the input using `sys.stdin.read()` to handle large input sizes quickly.
2. **Line Equation Evaluation**: For each tree, compute the value of the line equation at the tree's coordinates. This value determines which side of the line the tree is on.
3. **Count Calculation**: Track the number of trees on the positive and negative sides of the line. Trees exactly on the line are ignored.
4. **Result Determination**: The result for each test case is the maximum of the positive and negative counts.

### Solution Code
```python
import sys

def main():
    input_data = sys.stdin.read().split()
    ptr = 0
    T = int(input_data[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input_data[ptr])
        ptr += 1
        A = int(input_data[ptr])
        B = int(input_data[ptr + 1])
        C = int(input_data[ptr + 2])
        ptr += 3
        pos = 0
        neg = 0
        for __ in range(N):
            x = int(input_data[ptr])
            y = int(input_data[ptr + 1])
            ptr += 2
            val = A * x + B * y + C
            if val > 0:
                pos += 1
            elif val < 0:
                neg += 1
        print(max(pos, neg))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and split into a list of strings for efficient processing, which is crucial for handling large inputs up to 100,000 trees per test case.
2. **Line Equation Evaluation**: For each tree's coordinates (x, y), compute the value of the line equation Ax + By + C. This value determines whether the tree is on the positive side (value > 0), negative side (value < 0), or exactly on the line (value = 0).
3. **Counting Trees on Each Side**: Maintain two counters, `pos` and `neg`, to keep track of trees on the positive and negative sides of the line, respectively. Trees on the line are ignored.
4. **Result Calculation**: For each test case, the result is the maximum of the positive and negative counts, which is printed as the output.

This approach ensures that we efficiently process each tree in linear time relative to the number of trees, making the solution both optimal and scalable for large input sizes.
