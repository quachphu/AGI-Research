To solve this problem, we need to determine the minimum number of minutes Kevin needs to distribute all his bananas such that each lemur gets the same number of bananas. Kevin can adjust both the number of bananas (N) and the number of lemurs (K) using specific operations, each taking one minute.

### Approach
1. **Problem Analysis**: Kevin can either add or discard bananas, and increase or decrease the number of lemurs. The goal is to make the total number of bananas divisible by the number of lemurs with the minimum number of operations.
2. **Key Insight**: For each possible number of lemurs (K'), we need to calculate the total steps required to adjust both the number of lemurs to K' and the number of bananas to be divisible by K'. The optimal K' is likely to be near the original K or a divisor of N.
3. **Algorithm**: Iterate over all possible values of K' from 1 to K + N. For each K', compute the steps to adjust the number of lemurs to K' and the steps to adjust the bananas to be divisible by K'. Track the minimum total steps across all K'.

### Solution Code
```python
n, k = map(int, input().split())

min_steps = float('inf')
max_k_prime = k + n

for k_prime in range(1, max_k_prime + 1):
    steps_k = abs(k_prime - k)
    remainder = n % k_prime
    if remainder == 0:
        steps_n = 0
    else:
        steps_n = min(remainder, k_prime - remainder)
    total = steps_k + steps_n
    if total < min_steps:
        min_steps = total

print(min_steps)
```

### Explanation
1. **Reading Input**: The input consists of two integers, N (number of bananas) and K (number of lemurs).
2. **Iterating Over Possible K' Values**: For each possible number of lemurs (K') from 1 to K + N:
   - **Adjusting Lemurs (K')**: Calculate the steps needed to change the number of lemurs from K to K'.
   - **Adjusting Bananas (N)**: Calculate the steps needed to make the number of bananas divisible by K'. This is done by finding the remainder when N is divided by K' and determining the minimum steps to adjust N to the nearest multiple of K'.
3. **Tracking Minimum Steps**: Keep track of the minimum total steps required across all possible values of K'.

This approach ensures that we explore all feasible values of K' efficiently, leading to an optimal solution in O(K + N) time complexity, which is manageable given the problem constraints.
