To solve this problem, we need to swap every occurrence of the substring "apple" with "peach" and vice versa in a given input string. The challenge is to ensure that replacing one substring does not interfere with the replacement of the other, which requires a simultaneous substitution approach.

### Approach
1. **Simultaneous Replacement**: Use a regular expression to match both "apple" and "peach" substrings in a single pass. This avoids the problem of one replacement interfering with the other.
2. **Lambda Function for Replacement**: For each match found by the regular expression, use a lambda function to determine which substring was matched and replace it with the corresponding counterpart. If "apple" is found, it is replaced with "peach"; if "peach" is found, it is replaced with "apple".

### Solution Code
```python
import re

def main():
    s = input().strip()
    replaced = re.sub(r'apple|peach', lambda x: 'peach' if x.group() == 'apple' else 'apple', s)
    print(replaced)

main()
```

### Explanation
- **Regular Expression**: The regex pattern `r'apple|peach'` is used to find both "apple" and "peach" substrings in the input string.
- **Lambda Function**: The lambda function checks each matched substring. If the match is "apple", it returns "peach"; otherwise, it returns "apple".
- **Simultaneous Processing**: By using `re.sub` with the regex and lambda function, all occurrences of "apple" and "peach" are replaced in a single pass through the input string, ensuring correct substitution without interference.

This approach efficiently handles the replacement in linear time relative to the length of the input string, making it both optimal and easy to understand.
