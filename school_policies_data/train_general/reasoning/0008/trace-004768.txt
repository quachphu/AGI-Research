To solve this problem, we need to determine the best add-on plan for Chef based on his last month's mobile usage. The goal is to identify the plan that maximizes his savings compared to his default rate. If no plan offers savings, we should indicate that as well.

### Approach
1. **Input Parsing**: Read the number of test cases. For each test case, read the default rate (D), the number of minutes Chef talked (U), and the number of available plans (N).
2. **Calculate Savings for Each Plan**: For each plan, compute the savings using the formula:
   \[
   \text{savings} = (D - R) \times U - \frac{C}{M}
   \]
   where \(R\) is the plan's rate, \(C\) is the activation cost, and \(M\) is the validity period in months.
3. **Determine the Best Plan**: Track the plan that provides the maximum savings. If the maximum savings is positive, output the 1-based index of that plan. Otherwise, output 0.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        D = float(input[ptr])
        U = int(input[ptr + 1])
        N = int(input[ptr + 2])
        ptr += 3
        max_saving = -float('inf')
        best = 0
        for i in range(N):
            M = int(input[ptr])
            R = float(input[ptr + 1])
            C = int(input[ptr + 2])
            ptr += 3
            saving = (D - R) * U - (C / M)
            if saving > max_saving:
                max_saving = saving
                best = i + 1  # 1-based index
        print(best if max_saving > 0 else 0)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints. The input is split into a list of strings for easy processing.
2. **Processing Each Test Case**: For each test case, the default rate (D), usage (U), and number of plans (N) are read. Each plan's details (validity period M, rate R, and cost C) are processed next.
3. **Calculating Savings**: For each plan, the savings are calculated by comparing the cost using the plan against the default cost. The formula accounts for the per-month activation cost spread over the plan's validity period.
4. **Selecting the Best Plan**: The plan with the highest positive savings is selected. If no plan offers positive savings, the result is 0.

This approach ensures that we efficiently determine the optimal plan for Chef based on his previous usage, considering both the reduced call rates and the periodic activation costs.
