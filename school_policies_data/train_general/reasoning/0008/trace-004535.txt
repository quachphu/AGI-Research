To solve this problem, we need to convert each uppercase letter in a given string to lowercase and each lowercase letter to uppercase. The solution should read the input string from standard input, process it, and print the transformed string.

### Approach
The approach to solve this problem is straightforward by utilizing Python's built-in string method `swapcase()`. This method directly converts each uppercase character to lowercase and each lowercase character to uppercase in the string. The steps involved are:
1. Read the input string from standard input.
2. Use the `swapcase()` method to transform the string.
3. Print the transformed string.

This approach is efficient and leverages Python's built-in functionality to handle the case conversion, ensuring simplicity and readability.

### Solution Code
```python
def main():
    s = input().strip()
    print(s.swapcase())

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The function reads the input string using `input().strip()`, which removes any leading or trailing whitespace (though the problem constraints ensure that the input is a valid string with only alphabetic characters).
2. **Transforming Case**: The `swapcase()` method is called on the input string, which automatically converts each uppercase letter to lowercase and each lowercase letter to uppercase.
3. **Output**: The transformed string is printed to the standard output.

This solution efficiently handles the problem requirements with minimal code, ensuring clarity and correctness.
