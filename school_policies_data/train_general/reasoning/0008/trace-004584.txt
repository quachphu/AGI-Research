To solve this problem, we need to determine if a given poem qualifies as a haiku based on specific syllable counts in each of its three lines. The syllable count is determined by the number of vowels (a, e, i, o, u) in each line, with the requirement that the first and third lines must each have exactly 5 syllables, and the second line must have exactly 7 syllables.

### Approach
1. **Input Handling**: Read three lines of input, each representing a phrase of the poem.
2. **Preprocessing**: For each line, strip leading and trailing spaces to handle any extraneous whitespace.
3. **Word Splitting**: Split each line into words using spaces as delimiters.
4. **Vowel Counting**: For each word in a line, count the number of vowels. Sum these counts for all words in the line to get the total syllables for that line.
5. **Validation**: Check if the syllable counts for the three lines are exactly 5, 7, and 5 respectively. If they match, the poem is a haiku; otherwise, it is not.

### Solution Code
```python
def check_haiku():
    counts = []
    for _ in range(3):
        line = input().strip()
        words = line.split()
        total = 0
        for word in words:
            total += sum(1 for c in word if c in 'aeiou')
        counts.append(total)
    print("YES" if counts == [5, 7, 5] else "NO")

check_haiku()
```

### Explanation
1. **Reading Input**: The function reads three lines from standard input.
2. **Stripping Whitespace**: Each line is stripped of leading and trailing spaces to ensure accurate word splitting.
3. **Splitting Words**: Each line is split into words using the default `split()` method, which handles multiple spaces between words.
4. **Counting Vowels**: For each word, the number of vowels is counted using a generator expression that checks each character against the set of vowels.
5. **Validation Check**: The total vowel counts for each line are compared against the required haiku structure (5, 7, 5). If they match, "YES" is printed; otherwise, "NO" is printed.

This approach efficiently processes each line to determine if the poem meets the haiku criteria, ensuring accurate and efficient validation.
