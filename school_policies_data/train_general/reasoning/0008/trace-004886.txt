To solve this problem, we need to determine the maximum messiness (number of inversions) that can be achieved by performing at most `k` swaps on an array of `n` cows initially arranged in ascending order. The goal is to find the optimal way to perform these swaps to maximize the number of inversions.

### Approach
1. **Understanding Inversions**: An inversion in an array is a pair of indices `(i, j)` such that `i < j` and `arr[i] > arr[j]`. The maximum number of inversions in an array of size `n` is `n*(n-1)/2`, which occurs when the array is in reverse order.
2. **Optimal Swaps**: The optimal strategy to maximize inversions is to reverse the array. Reversing an array of size `n` requires `floor(n/2)` swaps. Each swap involves exchanging the i-th element from the start with the i-th element from the end.
3. **Handling Limited Swaps**: If `k` is greater than or equal to `floor(n/2)`, we can fully reverse the array. If `k` is less than `floor(n/2)`, we perform `k` such swaps. Each swap contributes a specific number of inversions, which can be calculated using a derived formula.

### Solution Code
```python
n, k = map(int, input().split())
m = min(k, n // 2)
print(m * (2 * (n - m) - 1))
```

### Explanation
1. **Formula Derivation**: The number of inversions contributed by each swap can be derived as follows. For the i-th swap (starting from the outermost elements), the number of inversions added is `2*(n - 2*i + 1) - 1`.
