To solve this problem, we need to determine the greatest common divisor (GCD) of a given number \( S \) and a series of query numbers \( A_i \). The challenge is to ensure that once a GCD value is returned for a query, any subsequent queries resulting in the same GCD value return -1 instead.

### Approach
1. **Understanding the Problem**: The problem requires finding the GCD of \( S \) and each query number \( A_i \). The key constraint is that each GCD value can only be returned once. If the same GCD value is encountered again, the result should be -1.

2. **Key Insight**: The GCD of \( S \) and any \( A_i \) must be a divisor of \( S \). Therefore, we can precompute all divisors of \( S \), but in practice, we compute the GCD directly for each query and track used GCD values using a set for efficient lookups.

3. **Algorithm**:
   - **Compute GCD**: For each query, compute the GCD of \( S \) and \( A_i \).
   - **Track Used GCDs**: Use a set to keep track of GCD values that have already been returned. If a GCD value is found in the set, return -1; otherwise, return the GCD value and add it to the set.

### Solution Code
```python
import sys
import math

def main():
    s, q = map(int, sys.stdin.readline().split())
    used = set()
    for _ in range(q):
        ai = int(sys.stdin.readline())
        current_gcd = math.gcd(s, ai)
        if current_gcd in used:
            print(-1)
        else:
            used.add(current_gcd)
            print(current_gcd)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input values \( S \) and \( Q \) are read first, followed by \( Q \) lines each containing an integer \( A_i \).
- **Computing GCD**: For each \( A_i \), the GCD with \( S \) is computed using Python's `math.gcd` function.
- **Tracking Used GCDs**: A set `used` is maintained to track GCD values that have already been returned. If the computed GCD is found in this set, the result is -1; otherwise, the GCD is added to the set and returned.

This approach ensures efficient computation and tracking of GCD values, adhering to the problem constraints and providing the correct results in optimal time.
