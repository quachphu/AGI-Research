To solve this problem, we need to compute the sum of the function f(l, r) for all possible subsegments [l, r] of an array, where each element in the array is distinct. The function f(l, r) is defined as the sum of the elements in the sorted subsegment multiplied by their respective 1-based indices. The result should be computed modulo \(10^9 + 7\).

### Approach
1. **Understanding the Contribution of Each Element**: Each element's contribution to the total sum depends on its position in the sorted order of each subsegment that includes it. For each element, we need to determine how many times it appears in a specific position across all valid subsegments.

2. **Efficient Calculation Using Fenwick Trees**: Instead of iterating through all possible subsegments (which is infeasible for large n), we use Fenwick Trees (Binary Indexed Trees) to efficiently compute the contributions of each element. This allows us to maintain and query prefix sums efficiently.

3. **Sorting and Processing Elements**: By sorting the elements and processing them in increasing order, we can leverage the properties of sorted arrays to efficiently determine the contributions of each element using the Fenwick Trees.

### Solution Code
```python
MOD = 10**9 + 7

n = int(input())
a = list(map(int, input().split()))
elements = sorted((val, i + 1) for i, val in enumerate(a))  # 1-based index

class FenwickTree:
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (self.n + 2)  # 1-based indexing

    def add(self, idx, delta):
        while idx <= self.n:
            self.tree[idx] += delta
            idx += idx & -idx

    def query(self, idx):
        res = 0
        while idx > 0:
            res += self.tree[idx]
            idx -= idx & -idx
        return res

count_tree = FenwickTree(n)
sum_tree = FenwickTree(n)
total_count = 0
total_sum = 0
ans = 0

for val, pos in elements:
    # Compute sum_left: sum of positions < pos
    sum_left = sum_tree.query(pos - 1)
    # Compute sum_right components
    cnt_right = total_count - count_tree.query(pos)
    sum_pos_right = total_sum - sum_tree.query(pos)
    sum_right = ( (n + 1) * cnt_right ) - sum_pos_right
    # Calculate the contribution of the current element
    term = val * ( sum_left * (n - pos + 1) + sum_right * pos + pos * (n - pos + 1) )
    ans = (ans + term) % MOD
    # Update the Fenwick Trees and totals
    count_tree.add(pos, 1)
    sum_tree.add(pos, pos)
    total_count += 1
    total_sum += pos

print(ans % MOD)
```

### Explanation
1. **Sorting Elements**: The elements are sorted along with their original positions to process them in increasing order of their values.
2. **Fenwick Tree Operations**: Two Fenwick Trees are used to track the count of elements and the sum of their positions. This allows efficient range queries and updates.
3. **Contribution Calculation**: For each element, we compute its contribution based on how many elements are smaller and located to the left or right of it. This is done using prefix sums from the Fenwick Trees.
4. **Modulo Operation**: The result is continuously updated modulo \(10^9 + 7\) to handle large numbers and prevent overflow.

This approach efficiently computes the required sum in \(O(n \log n)\) time, making it suitable for large input sizes up to \(5 \times 10^5\).
