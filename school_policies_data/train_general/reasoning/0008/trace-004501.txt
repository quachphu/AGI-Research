To solve this problem, we need to determine the final result of applying a mysterious device operation \( M \) sequentially on a list of animals (Tanuki 'T' and Fox 'F'). The operation is applied left-associatively, meaning the result of each step is used as the input for the next step.

### Approach
1. **Understanding the Device Operation \( M \)**:
   - The device operation \( M \) has specific rules based on the inputs:
     - \( M(T, T) = T \)
     - \( M(T, F) = F \)
     - \( M(F, T) = T \)
     - \( M(F, F) = T \)
   - From these rules, we observe that if the first input is 'T', the result is the second input. If the first input is 'F', the result is always 'T'.

2. **Iterative Application**:
   - Start with the first element as the initial result.
   - Iterate through the remaining elements, applying the device operation \( M \) step-by-step using the current result and the next element.

3. **Efficiency**:
   - The algorithm processes each element exactly once, resulting in an O(N) time complexity, which is efficient even for large input sizes.

### Solution Code
```python
def main():
    n = int(input())
    elements = input().split()
    current = elements[0]
    for next_animal in elements[1:]:
        if current == 'T':
            current = next_animal
        else:
            current = 'T'
    print(current)

main()
```

### Explanation
1. **Reading Input**:
   - The input consists of an integer \( n \) followed by \( n \) strings ('T' or 'F').

2. **Initialization**:
   - The first element is taken as the initial result.

3. **Iterative Processing**:
   - For each subsequent element, the device operation \( M \) is applied. If the current result is 'T', the result becomes the next element. If the current result is 'F', the result becomes 'T' regardless of the next element.

4. **Output**:
   - The final result after processing all elements is printed.

This approach efficiently computes the result by leveraging the observed rules of the device operation \( M \), ensuring each step is processed in constant time.
