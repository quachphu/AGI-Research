To solve this problem, we need to determine the number of ways to split `n` people into two round dances, each consisting of exactly `n/2` people. The solution involves combinatorial mathematics to account for the different ways to partition the group and the circular permutations within each group.

### Approach
1. **Splitting the Group**: The number of ways to split `n` people into two groups of size `n/2` each is given by the combination formula `C(n, n/2)`. However, since the order of the groups does not matter, we divide by 2 to avoid double-counting.
2. **Circular Permutations**: For each group of size `m = n/2`, the number of distinct circular permutations is `(m-1)!` because rotations of the same group are considered identical.
3. **Combining Both Groups**: The total number of ways for both groups is the product of the permutations of each group. This results in `((m-1)!^2)` permutations for both groups combined.
4. **Final Formula**: Combining the above steps, the formula simplifies to `(n! / (2 * (n/2)^2))`.

### Solution Code
```python
import math

n = int(input())
m = n // 2
result = math.factorial(n) // (2 * m * m)
print(result)
```

### Explanation
1. **Reading Input**: The input integer `n` is read, which is the total number of people.
2. **Calculate m**: Compute `m` as `n // 2`, which is the size of each group.
3. **Factorial Calculation**: Compute the factorial of `n` using `math.factorial(n)`.
4. **Apply Formula**: The result is calculated by dividing the factorial of `n` by `2 * m * m`, which accounts for the number of ways to split the group and the circular permutations within each group.
5. **Output Result**: The result is printed, which gives the number of ways to form the two round dances.

This approach efficiently computes the required number using combinatorial mathematics, ensuring that all constraints and edge cases are handled correctly.
