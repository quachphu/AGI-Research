To solve this problem, we need to determine the winner for each starting position on a game board where Alice and Bob move a token according to specific rules. The solution involves analyzing each position to determine if the current player can force a win using optimal strategies.

### Approach
1. **Game Theory and Dynamic Programming**: The problem can be approached using dynamic programming (DP) where we determine if a position is a winning or losing state. A position is a winning state if the current player can move to a losing state for the opponent.

2. **Optimal Moves**: For each position, the valid moves are determined by the rules: moving to a cell with a higher number and a distance that is a multiple of the current cell's number. We need to check all possible valid moves efficiently.

3. **Efficient Traversal**: By processing positions in decreasing order of their values, we ensure that all valid moves (to higher values) have already been evaluated. This allows us to use previously computed results to determine the current state efficiently.

4. **Direction Checks**: For each position, we check both positive and negative directions for valid moves, ensuring we stay within bounds and meet the game's constraints.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))

# Sort the positions in decreasing order of their a values
sorted_indices = sorted(range(1, n + 1), key=lambda x: -a[x - 1])

dp = [False] * (n + 1)  # Using 1-based indexing

for i in sorted_indices:
    x = a[i - 1]
    possible = False
    
    # Check positive direction (i + k*x)
    j = i + x
    while j <= n:
        if a[j - 1] > x and not dp[j]:
            possible = True
            break
        j += x
    
    if not possible:
        # Check negative direction (i - k*x)
        j = i - x
        while j >= 1:
            if a[j - 1] > x and not dp[j]:
                possible = True
                break
            j -= x
    
    dp[i] = possible

# Generate the result string
result = ''.join('A' if dp[i] else 'B' for i in range(1, n + 1))
print(result)
```

1. **Input Handling**: Read the number of cells and the values in each cell.
2. **Sorting**: Positions are sorted in descending order based on their values to ensure that when processing a position, all valid moves (to higher values) have already been evaluated.
3. **Dynamic Programming Array**: The `dp` array tracks whether each position is a winning (True) or losing (False) state.
4. **Direction Checks**: For each position, check valid moves in both positive and negative directions. If any move leads to a losing state for the opponent, mark the current position as a winning state.
5. **Result Generation**: Construct the result string based on the DP array, indicating the winner for each starting position.

This approach efficiently determines the winner for each starting position by leveraging dynamic programming and optimal move checks, ensuring the solution runs in acceptable time complexity for large inputs.
