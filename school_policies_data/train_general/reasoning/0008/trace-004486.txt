To solve this problem, we need to assign letters to keys on a keyboard in a way that minimizes the total number of keystrokes required to type a given text. The key insight is that more frequent letters should be assigned to positions requiring fewer keystrokes. 

### Approach
1. **Check Feasibility**: First, ensure that the total number of available key positions across all keys is at least equal to the number of letters (N). If not, output -1.
2. **Generate Positions**: For each key, generate possible positions (keystrokes) based on its size. For example, a key with size 3 has positions 1, 2, and 3.
3. **Sort Positions**: Collect all possible positions from all keys and sort them in ascending order of their keystroke count.
4. **Assign Letters**: Sort the letter frequencies in descending order and assign the highest frequencies to the smallest keystroke positions.
5. **Calculate Total Keystrokes**: Multiply each frequency by its corresponding keystroke count and sum the results to get the minimum total keystrokes.

### Solution Code
```python
n = int(input())
frequencies = list(map(int, input().split()))
k = int(input())
key_sizes = list(map(int, input().split()))

sum_keys = sum(key_sizes)
if sum_keys < n:
    print(-1)
else:
    positions = []
    for size in key_sizes:
        positions.extend(range(1, size + 1))
    positions.sort()
    selected_positions = positions[:n]
    frequencies_sorted = sorted(frequencies, reverse=True)
    total = 0
    for f, p in zip(frequencies_sorted, selected_positions):
        total += f * p
    print(total)
```

### Explanation
1. **Feasibility Check**: The sum of all key sizes is checked against the number of letters. If insufficient, output -1.
2. **Position Generation**: Each key's size determines the possible positions (keystrokes) it can offer. For example, a key of size 2 offers positions 1 and 2.
3. **Sorting Positions**: All positions are sorted to prioritize lower keystroke counts.
4. **Optimal Assignment**: By sorting frequencies in descending order and assigning them to the smallest available positions, we ensure that higher frequency letters use fewer keystrokes, minimizing the total effort.

This approach efficiently combines sorting and greedy assignment to achieve the optimal solution with a time complexity dominated by the sorting steps, making it O(M log M) where M is the total number of key positions.
