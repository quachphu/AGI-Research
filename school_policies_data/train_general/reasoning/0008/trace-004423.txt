### Approach
1. **Understand the Equation**: The given equation \(m = n \cdot a + b - c\) can be rearranged to \(m - n \cdot a = b - c\). Here, \(b - c\) must lie within the range \(-(r - l)\) to \(r - l\) because \(b\) and \(c\) are within \([l, r]\).
2. **Range of \(n \cdot a\)**: For each \(a\) in \([l, r]\), we need to find an \(n\) such that \(n \cdot a\) is within the interval \([m - (r - l), m + (r - l)]\). This ensures \(b - c\) falls within the required range.
3. **Check Validity of \(a\)**: For each \(a\), compute the possible values of \(n\) using the interval bounds. If a valid \(n\) exists, compute \(b\) and \(c\) based on the resulting delta (\(m - n \cdot a\)).

    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    idx = 1

                n = lower_n
                delta = m - a * n
                if delta >= 0:

                    c = l
                else:

                    c = l - delta

                found = True
                break
        assert found
