To solve this problem, we need to find the minimum possible area of a rectangle that contains at least K points from a given set of N points in a 2D plane. The rectangle's sides must be parallel to the coordinate axes, and points on the edges are considered inside the rectangle.

### Approach
1. **Sort Points by X-Coordinates**: First, we sort all the points based on their x-coordinates. This helps in efficiently determining the range of x-values for potential rectangles.
2. **Iterate Over Possible X-Ranges**: For each possible range of x-values (from the i-th smallest x to the j-th smallest x), we check if the number of points in this range is at least K.
3. **Extract and Sort Y-Coordinates**: For each valid x-range, extract the y-coordinates of the points within this range and sort them.
4. **Determine Minimum Y-Interval**: Using the sorted y-coordinates, compute the minimum interval that includes at least K points. This is done by sliding a window of size K over the sorted y-values and finding the smallest interval.
5. **Calculate Area and Track Minimum**: For each valid x-range and corresponding y-interval, compute the area of the rectangle and keep track of the minimum area encountered.

### Solution Code
```python
n, k = map(int, input().split())
points = [tuple(map(int, input().split())) for _ in range(n)]
points.sort(key=lambda p: p[0])  # Sort points by x-coordinate

min_area = float('inf')

for i in range(n):
    for j in range(i, n):
        # Check if the number of points in x range [i..j] is >=k
        m = j - i + 1
        if m < k:
            continue
        # Extract y-coordinates and sort them
        ys = [points[idx][1] for idx in range(i, j + 1)]
        ys.sort()
        # Find the minimal y span covering at least k points
        min_span = None
        for p in range(len(ys) - k + 1):
            span = ys[p + k - 1] - ys[p]
            if min_span is None or span < min_span:
                min_span = span
        if min_span is None:
            continue  # This case should not occur as m >=k
        # Calculate the area
        width = points[j][0] - points[i][0]
        area = width * min_span
        if area < min_area:
            min_area = area

print(min_area)
```

### Explanation
1. **Sorting Points**: By sorting the points based on their x-coordinates, we can efficiently consider all possible x-ranges by iterating through pairs of points.
2. **Sliding Window for Y-Intervals**: For each valid x-range, the y-coordinates are sorted, and a sliding window of size K is used to determine the smallest interval that includes at least K points. This ensures we efficiently find the minimal y-interval.
3. **Efficiency**: The algorithm runs in O(N^3) time complexity due to iterating over all possible x-ranges (O(N^2)) and sliding the window over sorted y-coordinates (O(N)). This is feasible given the constraint N ≤ 50.

This approach ensures that we explore all potential rectangles efficiently and find the minimum area that meets the problem's requirements.
