To solve this problem, we need to determine the optimal radii for two fountains such that all flowers in a garden are watered, while minimizing the sum of the squares of these radii. The solution involves calculating the squared distances from each flower to both fountains and using these distances to efficiently determine the optimal radii.

### Approach
1. **Calculate Squared Distances**: For each flower, compute the squared distance to both fountains. This avoids dealing with floating-point precision issues and keeps all operations in the integer domain.
2. **Sort Flowers**: Sort the flowers based on their squared distances to each fountain. This allows us to efficiently determine the maximum distance required for coverage when considering different partitions of flowers between the two fountains.
3. **Suffix Maximum Arrays**: Compute suffix maximum arrays for the squared distances. These arrays help in quickly determining the maximum distance required for the remaining flowers when considering a partition point.
4. **Evaluate Partitions**: For each possible partition point in the sorted lists (sorted by each fountain's distances), calculate the required radii and their sum of squares. Track the minimum sum across all partitions.

### Solution Code
```python
n, x1, y1, x2, y2 = map(int, input().split())
flowers = []
for _ in range(n):
    xi, yi = map(int, input().split())
    s1 = (xi - x1) ** 2 + (yi - y1) ** 2
    s2 = (xi - x2) ** 2 + (yi - y2) ** 2
    flowers.append((s1, s2))

min_sum = float('inf')

# Sort by s1 and compute suffix max of s2
sorted_s1 = sorted(flowers, key=lambda x: x[0])
suffix_max_s2 = [0] * (len(sorted_s1) + 1)
for i in range(len(sorted_s1) - 1, -1, -1):
    suffix_max_s2[i] = max(sorted_s1[i][1], suffix_max_s2[i + 1])

for k in range(len(sorted_s1) + 1):
    current_r1 = sorted_s1[k-1][0] if k > 0 else 0
    current_r2 = suffix_max_s2[k]
    total = current_r1 + current_r2
    if total < min_sum:
        min_sum = total

# Sort by s2 and compute suffix max of s1
sorted_s2 = sorted(flowers, key=lambda x: x[1])
suffix_max_s1 = [0] * (len(sorted_s2) + 1)
for i in range(len(sorted_s2) - 1, -1, -1):
    suffix_max_s1[i] = max(sorted_s2[i][0], suffix_max_s1[i + 1])

for k in range(len(sorted_s2) + 1):
    current_r2 = sorted_s2[k-1][1] if k > 0 else 0
    current_r1 = suffix_max_s1[k]
    total = current_r1 + current_r2
    if total < min_sum:
        min_sum = total

print(min_sum)
```

3. **Suffix Maximum Arrays**: These arrays allow quick determination of the maximum distance required for the remaining flowers, ensuring that all flowers beyond a partition point are covered by the other fountain.
4. **Partition Evaluation**: By evaluating all possible partition points in both sorted orders (by distance to each fountain), we ensure that the optimal solution is found, covering all flowers with the minimum sum of squared radii.

This approach efficiently narrows down the optimal solution by leveraging sorting and suffix maximum arrays, ensuring that we explore all potential partitions while maintaining a manageable computational complexity.
