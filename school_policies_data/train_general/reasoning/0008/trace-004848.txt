To solve this problem, we need to determine the total number of handshakes that occur at a party hosted by Raman, given the number of people who joined the party and including Raman himself. 

### Approach
1. **Understanding the Problem**: 
   - Raman is always present at the party.
   - Each person at the party shakes hands with every other person exactly once.
   - The number of people who joined the party (K) and Raman's presence means there are K + 1 people in total at the party.

2. **Handshake Calculation**:
   - The total number of handshakes when there are `n` people is given by the combination formula `C(n, 2)`, which is `n * (n - 1) / 2`.
   - Here, the total number of people is `K + 1` (including Raman), so the formula becomes `(K + 1) * K / 2`.

3. **Implementation**:
   - Read the number of test cases.
   - For each test case, read the values of N (number of invites) and K (number of people who joined).
   - Compute the number of handshakes using the formula derived above.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n, k = map(int, sys.stdin.readline().split())
        print(k * (k + 1) // 2)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read from standard input. The first line contains the number of test cases `T`.
- **Processing Each Test Case**: For each test case, read the values of `N` and `K`. Although `N` is provided, it is not used in the calculation since the number of handshakes depends only on the number of people who actually attended (K) plus Raman.
- **Handshake Calculation**: Using the formula `(K * (K + 1)) // 2`, we compute the total number of handshakes efficiently. This formula is derived from the combination formula for choosing 2 people out of `K + 1` to shake hands.

This approach ensures that the solution is both efficient and straightforward, handling up to the maximum constraints with ease.
