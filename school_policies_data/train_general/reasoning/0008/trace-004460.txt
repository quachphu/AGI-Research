To solve this problem, we need to reverse the digits of given integers and print them without leading zeros. The solution must efficiently handle up to 100,000 integers, each potentially as large as \(10^{18}\).

### Approach
1. **Input Handling**: Read all input at once using `sys.stdin.read()` to efficiently handle large input sizes. This method reads all input data in one system call, which is faster for large inputs compared to reading line by line.
2. **String Reversal**: For each integer, convert it to a string, reverse the string, and then convert it back to an integer to remove any leading zeros.
3. **Output**: Print each reversed integer on a new line.

### Solution Code
```python
import sys

def main():
    data = sys.stdin.read().split()
    T = int(data[0])
    for num_str in data[1:T+1]:
        reversed_num = int(num_str[::-1])
        print(reversed_num)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: Using `sys.stdin.read().split()` reads all input at once and splits it into a list of strings, which is efficient for large inputs.
2. **Reversing the Number**: Each number is treated as a string, reversed using slicing (`[::-1]`), and converted back to an integer to strip any leading zeros.
3. **Handling Large Numbers**: Python's ability to handle arbitrarily large integers ensures that even the largest numbers (up to \(10^{18}\)) are processed correctly without overflow issues.

This approach ensures that the solution is both efficient and straightforward, handling the constraints effectively.
