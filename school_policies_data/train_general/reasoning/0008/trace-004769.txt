To solve this problem, we need to determine the media type of files based on their extensions using a predefined table of associations. The solution involves reading input values, processing the associations, and efficiently checking each file's extension against the known associations.

### Approach
1. **Read Input Values**: The input starts with two integers, N (number of media type associations) and Q (number of file names to check).
2. **Store Media Type Associations**: Use a dictionary to store the media type associations where the key is the file extension and the value is the corresponding media type.
3. **Process Each File Name**: For each file name, determine its extension by finding the last occurrence of the period ('.'). If there is no period, the file has no extension. If the extension exists and is found in the dictionary, output the corresponding media type; otherwise, output "unknown".

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().splitlines()
    idx = 0
    n, q = map(int, input[idx].split())
    idx += 1
    media = {}
    for _ in range(n):
        if idx >= len(input):
            break
        ext, mt = input[idx].strip().split()
        media[ext] = mt
        idx += 1
    for _ in range(q):
        if idx >= len(input):
            break
        filename = input[idx].strip()
        idx += 1
        dot_pos = filename.rfind('.')
        if dot_pos == -1:
            print("unknown")
        else:
            ext = filename[dot_pos+1:]
            print(media.get(ext, "unknown"))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into lines for efficient processing. This helps in managing the input correctly, especially when dealing with multiple lines of data.
2. **Storing Associations**: The media type associations are stored in a dictionary for O(1) average-time complexity lookups. This ensures that checking each file's extension against the known associations is efficient.
3. **Processing File Names**: Each file name is checked for the presence of an extension by finding the last period. If an extension exists, it is looked up in the dictionary. The result is either the corresponding media type or "unknown" if the extension is not found or there is no extension.

This approach efficiently handles the problem constraints and ensures that each file name is processed in linear time relative to its length, making the solution both optimal and easy to understand.
