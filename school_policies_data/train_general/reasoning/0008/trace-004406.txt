To solve this problem, we need to determine if a given string can be converted into a "double string" by removing some characters. A double string is defined as a string that can be split into two equal parts where both parts are identical.

### Approach
The key insight to solve this problem is to recognize that a valid double string must have at least two identical characters. This is because the smallest possible double string is of length 2 (e.g., "aa"), which can be formed by selecting two identical characters from the original string. Therefore, the solution reduces to checking if the input string contains at least two identical characters. If it does, we can always form a valid double string by removing other characters. If not, it's impossible to form a double string.

### Solution Code
```python
def is_double_string_possible(s):
    if len(s) < 2:
        return False
    seen = set()
    for char in s:
        if char in seen:
            return True
        seen.add(char)
    return False

T = int(input())
for _ in range(T):
    S = input().strip()
    if is_double_string_possible(S):
        print("Yes")
    else:
        print("No")
```

### Explanation
1. **Reading Input**: The code reads the number of test cases and each string input.
2. **Check for Valid Double String**: For each string, the function `is_double_string_possible` checks if there are at least two identical characters.
3. **Using a Set**: The function uses a set to track characters that have been seen. If a character is encountered again, it means there are at least two identical characters, and the function returns `True`.
4. **Output Result**: Based on the result of the check, the code prints "Yes" if a double string can be formed, otherwise "No".

This approach efficiently checks the presence of duplicate characters in linear time, making it both optimal and easy to understand.
