To solve this problem, we need to determine the minimum possible number of seconds the Separatists' message could represent. The message uses symbols (letters and digits), where each symbol represents a unique digit in some base. The goal is to convert the message into the smallest possible number in base 10.

### Approach
1. **Identify Unique Symbols**: For each message, identify the unique symbols and their order of first occurrence.
2. **Determine Base**: The base is determined by the number of unique symbols. If there is only one unique symbol, the base is 2 (since base 1 is invalid). Otherwise, the base is the number of unique symbols.
3. **Assign Digits**: Assign digits to the symbols such that the first symbol gets 1 (to avoid leading zero), the next symbols get the smallest possible digits starting from 0, then 2, 3, etc., in the order of their first occurrence.
4. **Convert to Base 10**: Convert the message using the assigned digits and the determined base to get the minimum possible number in base 10.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().splitlines()
    T = int(input[0])
    for case in input[1:T+1]:
        S = case.strip()
        order_list = []
        seen = set()
        for c in S:
            if c not in seen:
                order_list.append(c)
                seen.add(c)
        m = len(order_list)
        base = m if m > 1 else 2
        # Assign digits
        digits = [0] * m
        digits[0] = 1
        if m >= 2:
            digits[1] = 0
            for i in range(2, m):
                digits[i] = i
        # Create mapping
        char_map = {c: digits[i] for i, c in enumerate(order_list)}
        # Compute value
        val = 0
        for c in S:
            val = val * base + char_map[c]
        print(val)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and split into lines. The first line gives the number of test cases.
2. **Processing Each Test Case**:
   - **Unique Symbols Order**: For each message, we determine the order of unique symbols as they first appear.
   - **Determine Base**: The base is set to the number of unique symbols unless there's only one symbol, in which case the base is 2.
   - **Digit Assignment**: The first symbol is assigned 1, the next symbol 0, and subsequent symbols are assigned 2, 3, etc., in the order of their appearance.
   - **Conversion to Base 10**: Using the assigned digits and the determined base, the message is converted to a base 10 number by iterating through each character and computing the value step-by-step.

This approach ensures that the smallest possible number is generated by using the smallest base possible and assigning digits in a way that minimizes the overall value.
