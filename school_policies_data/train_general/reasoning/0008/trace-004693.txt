To solve this problem, we need to determine the number of valid ways to award participants with diplomas based on their scores, adhering to specific criteria. The key insight is that each valid subset of awardees is determined by a threshold score, which must be a non-zero value present in the list of scores.

### Approach
1. **Filter Non-zero Scores**: First, we filter out all participants with a score of zero since they cannot be awarded.
2. **Identify Unique Scores**: The valid subsets of awardees are determined by the distinct non-zero scores. Each distinct score acts as a potential threshold, where all participants with scores greater than or equal to this threshold are awarded.
3. **Count Unique Scores**: The number of valid subsets is equal to the number of distinct non-zero scores in the list. This is because each distinct non-zero score represents a unique threshold, leading to a unique subset of awardees.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
non_zero = {x for x in a if x != 0}
print(len(non_zero))
```

### Explanation
- **Reading Input**: The input consists of the number of participants and their respective scores.
- **Filtering Zeros**: We create a set of non-zero scores to automatically handle duplicates and ignore zeros.
- **Counting Unique Scores**: The size of the set of non-zero scores gives the number of valid ways to choose subsets of participants, as each unique score represents a valid threshold for awarding diplomas.

This approach efficiently computes the result by leveraging set operations to handle duplicates and ensure we only consider valid non-zero scores. The complexity is linear, making it suitable for the given constraints.
