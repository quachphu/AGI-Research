To solve this problem, we need to determine the optimal path for Walter William to escape from city 1 to city n in the shortest possible distance while minimizing the number of roads that need to be repaired or blown up. The solution involves finding the shortest path and then selecting the one that requires the least modifications to the roads.

### Approach
1. **Breadth-First Search (BFS)**: Compute the shortest distance from city 1 to all other cities using BFS. This helps in identifying the shortest path length from city 1 to city n.
2. **Dynamic Programming (DP)**: Use BFS again to determine the maximum sum of working roads (z values) along the shortest path. This helps in selecting the path that minimizes the number of modifications needed.
3. **Path Reconstruction**: Using parent pointers, reconstruct the path from city n back to city 1 based on the maximum sum of working roads.
4. **Edge Classification**: Identify which edges are part of the chosen shortest path and determine the necessary modifications (repairing or blowing up roads) based on their current state.

### Solution Code
```python
import sys
from collections import deque

def main():
    n, m = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n)]
    edges = []
    for _ in range(m):
        x, y, z = map(int, sys.stdin.readline().split())
        x -= 1
        y -= 1
        adj[x].append((y, z))
        adj[y].append((x, z))
        edges.append((x, y, z))
    
    # Compute shortest distances using BFS
    d = [-1] * n
    d[0] = 0
    q = deque([0])
    while q:
        u = q.popleft()
        for v, z in adj[u]:
            if d[v] == -1:
                d[v] = d[u] + 1
                q.append(v)
    
    max_dist = d[n-1]
    if max_dist == -1:
        print(0)
        return
    
    # Group nodes by their distance
    levels = [[] for _ in range(max_dist + 1)]
    for i in range(n):
        if d[i] != -1 and d[i] <= max_dist:
            levels[d[i]].append(i)
    
    # Compute max_z_sum and parent pointers
    max_z_sum = [-float('inf')] * n
    max_z_sum[0] = 0
    parent = [-1] * n
    
    for dist in range(max_dist + 1):
        for u in levels[dist]:
            for (v, z) in adj[u]:
                if d[v] == d[u] + 1:
                    if max_z_sum[v] < max_z_sum[u] + z:
                        max_z_sum[v] = max_z_sum[u] + z
                        parent[v] = u
    
    # Reconstruct the path
    path = []
    current = n - 1
    while current != -1:
        path.append(current)
        current = parent[current]
    path.reverse()
    
    if not path or path[0] != 0:
        print(0)
        return
    
    # Collect edges in the path as sorted tuples
    path_edges = set()
    for i in range(len(path) - 1):
        u = path[i]
        v = path[i+1]
        sorted_edge = tuple(sorted((u, v)))
        path_edges.add(sorted_edge)
    
    # Process all edges to determine modifications
    result = []
    for x, y, z in edges:
        sorted_pair = tuple(sorted((x, y)))
        if sorted_pair in path_edges:
            if z == 0:
                result.append((x+1, y+1, 1))
        else:
            if z == 1:
                result.append((x+1, y+1, 0))
    
    print(len(result))
    for line in result:
        print(line[0], line[1], line[2])

if __name__ == "__main__":
    main()
```

### Explanation
1. **BFS for Shortest Path**: The BFS computes the shortest distance from city 1 to all other cities, ensuring we know the minimum number of steps required to reach each city.
2. **Dynamic Programming for Maximum Working Roads**: Using BFS levels, we compute the maximum sum of working roads (z values) along the shortest paths. This helps in selecting the path that requires the least modifications.
3. **Path Reconstruction**: Using parent pointers from the DP step, we reconstruct the optimal path from city n back to city 1.
4. **Edge Classification and Modifications**: For each edge, check if it is part of the optimal path. If it is, repair it if necessary. If it is not, blow it up if it is currently working. This ensures the remaining roads form the optimal shortest path with minimal modifications.
