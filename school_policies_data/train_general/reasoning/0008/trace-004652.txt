To solve this problem, we need to determine the optimal placement of a bomb on a grid such that it destroys the maximum number of targets. The bomb destroys all targets in the same row and column as its placement. The solution involves efficiently calculating the maximum possible targets destroyed by considering rows and columns with the highest target counts and checking their intersections.

### Approach
1. **Count Targets in Rows and Columns**: Track the number of targets in each row and each column.
2. **Identify Maximum Counts**: Determine the rows and columns with the highest target counts.
3. **Check Intersections**: Verify if there exists any intersection between the rows and columns with maximum counts that does not contain a target. If such an intersection exists, the maximum targets destroyed will be the sum of the maximum row and column counts. Otherwise, subtract one from this sum to account for the overlapping target at the intersection.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    H = int(input[idx]); idx +=1
    W = int(input[idx]); idx +=1
    M = int(input[idx]); idx +=1
    
    row_counts = [0] * (H + 1)
    col_counts = [0] * (W + 1)
    targets = set()
    
    for _ in range(M):
        h = int(input[idx]); idx +=1
        w = int(input[idx]); idx +=1
        row_counts[h] += 1
        col_counts[w] += 1
        targets.add((h, w))
    
    row_max = max(row_counts)
    max_rows = [h for h in range(1, H+1) if row_counts[h] == row_max]
    R = len(max_rows)
    
    col_max = max(col_counts)
    max_cols = [w for w in range(1, W+1) if col_counts[w] == col_max]
    C = len(max_cols)
    
    max_rows_set = set(max_rows)
    max_cols_set = set(max_cols)
    cross_count = 0
    
    for h, w in targets:
        if h in max_rows_set and w in max_cols_set:
            cross_count += 1
    
    if cross_count < R * C:
        print(row_max + col_max)
    else:
        print(row_max + col_max - 1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed to extract grid dimensions and target positions.
2. **Counting Targets**: Two arrays, `row_counts` and `col_counts`, are used to count the number of targets in each row and column, respectively.
3. **Finding Maximum Counts**: The maximum values in `row_counts` and `col_counts` are identified, along with the rows and columns that achieve these maximums.
4. **Checking Intersections**: For each target, check if it lies at the intersection of a maximum row and column. If the number of such intersections is less than the product of the number of maximum rows and columns, the result is the sum of the maximum counts. Otherwise, the result is adjusted by subtracting one to account for the overlap.

This approach efficiently narrows down the potential optimal positions using the highest target density rows and columns, ensuring the solution is computed in linear time relative to the number of targets, making it suitable for large input sizes.
