To solve this problem, we need to determine the number of distinct subsequences of a given bracket sequence that form a Regular Simple Bracket Sequence (RSBS). An RSBS is a sequence of even length where the first half consists of '(' characters and the second half consists of ')' characters.

### Approach
1. **Precompute Factorials and Inverse Factorials**: To efficiently compute combinations modulo \(10^9 + 7\), we precompute factorials and inverse factorials up to the maximum possible length of the input string.
2. **Suffix Counts of Closing Brackets**: Calculate the number of closing brackets (')') from each position to the end of the string. This helps in determining how many closing brackets are available after each opening bracket ('(').
3. **Iterate Over Opening Brackets**: For each opening bracket, compute the number of valid RSBS subsequences where this bracket is the last opening bracket in the subsequence. This involves:
   - Counting the number of closing brackets available after the current opening bracket.
   - Using combinatorial mathematics to determine the number of ways to choose the required opening and closing brackets.

### Solution Code
```python
MOD = 10**9 + 7

def main():
    import sys
    s = sys.stdin.readline().strip()
    n = len(s)
    
    # Precompute factorial and inverse factorial mod MOD
    max_n = 4 * 10**5 + 10  # Sufficient size based on problem constraints
    factorial = [1] * (max_n + 1)
    for i in range(1, max_n + 1):
        factorial[i] = factorial[i-1] * i % MOD
    
    inv_fact = [1] * (max_n + 1)
    inv_fact[max_n] = pow(factorial[max_n], MOD-2, MOD)
    for i in range(max_n-1, -1, -1):
        inv_fact[i] = inv_fact[i+1] * (i+1) % MOD
    
    def comb(a, b):
        if a < 0 or b < 0 or a < b:
            return 0
        return factorial[a] * inv_fact[b] % MOD * inv_fact[a - b] % MOD
    
    # Compute suffix counts of ')'
    suffix_counts = [0] * (n + 1)
    for i in range(n-1, -1, -1):
        suffix_counts[i] = suffix_counts[i+1] + (1 if s[i] == ')' else 0)
    
    # Collect positions of '('
    left_pos = []
    for i in range(n):
        if s[i] == '(':
            left_pos.append(i)
    
    total = 0
    for idx, pos in enumerate(left_pos):
        # Number of '(' up to and including this one is idx + 1
        a = idx  # i-1 = idx
        # Number of ')' after this '('
        r = suffix_counts[pos + 1]
        if r == 0:
            continue
        # Compute sum for k=1 to min(a+1, r)
        max_k = min(a + 1, r)
        for k in range(1, max_k + 1):
            c = comb(a, k-1) * comb(r, k) % MOD
            total = (total + c) % MOD
    
    print(total % MOD)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precomputation of Factorials**: This allows us to compute combinations efficiently using modular arithmetic.
2. **Suffix Counts**: This helps in determining how many closing brackets are available after each position in the string.
3. **Combination Calculation**: For each opening bracket, we calculate the number of valid RSBS subsequences by considering all possible valid lengths (k) and summing the combinations of choosing k-1 opening brackets before the current one and k closing brackets after it.

This approach ensures we efficiently count all valid RSBS subsequences by leveraging combinatorial mathematics and modular arithmetic to handle large numbers.
