To solve this problem, we need to schedule Devu's songs and Churu's jokes such that all songs are performed within the given time limit, and the number of jokes is maximized. 

### Approach
1. **Calculate Minimum Required Time**: First, compute the minimum time required for Devu to sing all his songs, including the mandatory rest periods after each song except the last one. This is given by the sum of the song durations plus 10 minutes of rest for each song except the last one.
2. **Check Feasibility**: If the minimum required time exceeds the event duration `d`, output `-1` as it's impossible to fit all songs.
3. **Calculate Remaining Time**: If feasible, compute the remaining time after accounting for Devu's songs and rest periods.
4. **Maximize Jokes**: Use the remaining time to fit as many 5-minute jokes as possible. Additionally, each rest period between songs can exactly fit 2 jokes. The maximum number of jokes is the sum of jokes during rest periods and the remaining time divided by 5.

### Solution Code
```python
n, d = map(int, input().split())
t = list(map(int, input().split()))
sum_t = sum(t)
required = sum_t + 10 * (n - 1)

if required > d:
    print(-1)
else:
    remaining = d - required
    jokes = 2 * (n - 1) + remaining // 5
    print(jokes)
```

### Explanation
1. **Input Reading**: Read the number of songs `n` and the event duration `d`, followed by the list of song durations.
2. **Minimum Required Time Calculation**: Sum the song durations and add the rest periods (10 minutes for each song except the last one).
3. **Feasibility Check**: If the minimum required time exceeds `d`, print `-1`.
4. **Remaining Time and Jokes Calculation**: If feasible, calculate the remaining time after accounting for Devu's schedule. Each rest period allows exactly 2 jokes. The remaining time is converted into the maximum possible 5-minute jokes and added to the rest period jokes to get the total number of jokes.

This approach ensures that we maximize the number of jokes while adhering to the constraints, providing an efficient and optimal solution.
