To solve this problem, we need to determine if three atoms with given valence numbers can form a molecule such that each atom's valence is satisfied through bonds with the other two atoms. The solution involves checking if the sum of the valence numbers is even and then solving a system of equations to find the number of bonds between each pair of atoms.

### Approach
1. **Check Sum Parity**: The sum of the valence numbers of the three atoms must be even. If it is odd, forming a molecule is impossible because the sum of bonds must be even.
2. **Solve Equations**: Using the valence numbers (a, b, c), derive the number of bonds between each pair of atoms (x, y, z) using the following formulas:
   - \( x = (a + b - c) / 2 \)
   - \( y = (b + c - a) / 2 \)
   - \( z = (a + c - b) / 2 \)
3. **Non-negative Check**: Ensure that the derived bond counts (x, y, z) are non-negative integers. If any of them are negative, forming the molecule is impossible.

### Solution Code
```python
a, b, c = map(int, input().split())

total = a + b + c
if total % 2 != 0:
    print("Impossible")
else:
    x = (a + b - c) // 2
    y = (b + c - a) // 2
    z = (a + c - b) // 2
    if x >= 0 and y >= 0 and z >= 0:
        print(x, y, z)
    else:
        print("Impossible")
```

### Explanation
1. **Sum Parity Check**: The sum of the valence numbers (a + b + c) must be even. This is because each bond is counted twice (once for each atom it connects). If the sum is odd, it's impossible to form valid bonds.
2. **Deriving Bonds**: Using the derived formulas, we calculate the number of bonds between each pair of atoms. These formulas ensure that each atom's valence is met by the sum of its bonds.
3. **Non-negative Validation**: The calculated bonds must be non-negative integers. If any bond count is negative, it indicates an impossible configuration.

This approach efficiently checks the feasibility of forming the molecule and computes the bond counts if possible, ensuring correctness and optimal performance.
