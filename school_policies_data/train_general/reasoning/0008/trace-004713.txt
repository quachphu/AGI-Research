To solve this problem, we need to determine the shortest number of steps required to visit all vertices starting from each vertex in a given tree. The tree is an acyclic connected graph with N vertices and N-1 edges.

### Approach
1. **Understanding the Problem**: The goal is to find the minimal steps required to visit all nodes starting from each vertex. The key insight is that the minimal steps required can be derived using the tree's diameter (the longest path between any two nodes) and the distances from each node to the endpoints of this diameter.

2. **Finding the Diameter**: The diameter of the tree is found using two BFS traversals. The first BFS from an arbitrary node finds the farthest node (u). The second BFS from node u finds the farthest node (v), which is the other endpoint of the diameter.

3. **Distance Calculation**: Using BFS, compute the distances from both endpoints (u and v) of the diameter to all other nodes. For each node, the maximum distance to either u or v is used to determine the minimal steps required.

4. **Formula for Steps**: The minimal steps for each node is given by \(2 \times (N - 1) - \text{max\_distance}\), where max_distance is the maximum distance from the node to either of the diameter endpoints.

### Solution Code
```python
import sys
from collections import deque

def main():
    n = int(sys.stdin.readline())
    adj = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v = map(int, sys.stdin.readline().split())
        adj[u].append(v)
        adj[v].append(u)
    
    def bfs(start):
        visited = [-1] * (n + 1)
        q = deque([start])
        visited[start] = 0
        while q:
            u = q.popleft()
            for v in adj[u]:
                if visited[v] == -1:
                    visited[v] = visited[u] + 1
                    q.append(v)
        max_dist = max(visited)
        far_node = [i for i, d in enumerate(visited) if d == max_dist]
        return far_node[0], visited
    
    # Find the first endpoint of the diameter
    u, _ = bfs(1)
    # Find the second endpoint and get distances from u
    v, dist_u = bfs(u)
    # Get distances from v
    _, dist_v = bfs(v)
    
    # Calculate results
    result = []
    for i in range(1, n + 1):
        max_d = max(dist_u[i], dist_v[i])
        result.append(str(2 * (n - 1) - max_d))
    
    print('\n'.join(result))

if __name__ == "__main__":
    main()
```

### Explanation
1. **BFS for Diameter Endpoints**: The BFS function is used to find the farthest node from a given start node. This helps in determining the endpoints of the tree's diameter.
2. **Distance Arrays**: Using BFS from each endpoint of the diameter, we compute the distance of all nodes from these endpoints. This helps in determining the maximum distance any node has from the farthest endpoints.
3. **Result Calculation**: For each node, the maximum distance to either endpoint is subtracted from \(2 \times (N - 1)\) to get the minimal steps required. This formula accounts for the fact that each edge is traversed twice except for those on the longest path from the starting node, which are traversed once.

This approach efficiently computes the required steps using BFS, which runs in linear time, making it suitable for large input sizes up to \(10^5\) nodes.
