### Solution Code
```python
import itertools

n, m = map(int, input().split())

def get_digits(x):
    if x == 0:
        return 1
    cnt = 0
    while x > 0:
        x = x // 7
        cnt += 1
    return cnt

hd = get_digits(n - 1)
md = get_digits(m - 1)

total_digits = hd + md

if total_digits > 7:
    print(0)
    exit()

count = 0

for digits in itertools.permutations(range(7), total_digits):
    h_part = digits[:hd]
    m_part = digits[hd:]
    
    # Compute hour value
    h_val = 0
    for d in h_part:
        h_val = h_val * 7 + d
    if h_val >= n:
        continue
    
    # Compute minute value
    m_val = 0
    for d in m_part:
        m_val = m_val * 7 + d
    if m_val >= m:
        continue
    
    count += 1

print(count)
```

3. **Permutations Generation**: Using `itertools.permutations`, we generate all possible permutations of the required total digits. Each permutation is split into hours and minutes parts.
4. **Validation**: Each permutation is converted to its decimal form for hours and minutes. If both values are within their respective valid ranges, the permutation is counted.
