To solve this problem, we need to determine who won more games between Anton and Danik based on a string of game outcomes. The solution involves counting the occurrences of each player's wins and comparing the counts to determine the result.

### Approach
1. **Input Reading**: Read the number of games played and the string representing the outcomes of each game.
2. **Count Occurrences**: Count the number of times Anton ('A') and Danik ('D') won using the string's `count` method.
3. **Comparison**: Compare the counts of Anton's and Danik's wins to determine the result:
   - If Anton's wins are more than Danik's, print "Anton".
   - If Danik's wins are more than Anton's, print "Danik".
   - If both have the same number of wins, print "Friendship".

### Solution Code
```python
def main():
    n = int(input())
    s = input().strip()
    count_a = s.count('A')
    count_d = s.count('D')
    if count_a > count_d:
        print("Anton")
    elif count_d > count_a:
        print("Danik")
    else:
        print("Friendship")

main()
```

### Explanation
- **Reading Input**: The first line of input is read to get the number of games, `n`. The second line is read to get the string `s` of length `n` containing the game outcomes.
- **Counting Wins**: Using the `count` method on the string `s`, we efficiently count the occurrences of 'A' (Anton's wins) and 'D' (Danik's wins).
- **Determining the Result**: By comparing the counts of 'A' and 'D', we determine who won more games or if they tied, and print the corresponding result.

This approach ensures that we efficiently handle the input size constraints (up to 100,000 games) with an O(n) time complexity, making it suitable for large inputs.
