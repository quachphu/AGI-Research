To solve this problem, we need to determine if a given string can be split into exactly `k` substrings, each of which is a palindrome and has the same length. 

### Approach
1. **Check Divisibility**: The length of the string `s` must be divisible by `k` to ensure it can be split into `k` equal parts. If not, the answer is immediately "NO".
2. **Split into Chunks**: If the length is divisible, calculate the length of each chunk as `len(s) // k`.
3. **Check Palindromes**: Split the string into `k` chunks of the calculated length and check if each chunk is a palindrome. If any chunk is not a palindrome, the answer is "NO". If all chunks are palindromes, the answer is "YES".

### Solution Code
```python
def check():
    s = input().strip()
    k = int(input())
    n = len(s)
    if n % k != 0:
        print("NO")
        return
    chunk_length = n // k
    for i in range(0, n, chunk_length):
        chunk = s[i:i+chunk_length]
        if chunk != chunk[::-1]:
            print("NO")
            return
    print("YES")

check()
```

### Explanation
1. **Divisibility Check**: The first step is to check if the length of the string `s` is divisible by `k`. This is because if `k` equal parts are required, the total length must be a multiple of `k`.
2. **Chunk Length Calculation**: If divisible, each chunk's length is determined by dividing the total length of `s` by `k`.
3. **Palindrome Check**: The string is split into chunks of the calculated length. Each chunk is checked to see if it reads the same forwards and backwards (a palindrome). If all chunks pass this check, the function returns "YES"; otherwise, it returns "NO".

This approach efficiently checks the necessary conditions and ensures correctness by leveraging string slicing and palindrome checks in Python.
