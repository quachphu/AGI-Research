To solve this problem, we need to identify the position of the number that differs in evenness from the rest of the given numbers. The problem guarantees that exactly one number will be different in terms of being even or odd.

### Approach
1. **Read Input:** First, we read the input values which include the number of elements and the list of numbers.
2. **Classify Numbers:** We iterate through the list of numbers and classify each number as even or odd, while keeping track of their positions.
3. **Identify the Odd One Out:** Determine which group (evens or odds) contains exactly one number. The position of the number in this group is our answer.

### Solution Code
```python
def find_unique_evenness():
    n = int(input())
    numbers = list(map(int, input().split()))
    evens = []
    odds = []
    for idx, num in enumerate(numbers, 1):
        if num % 2 == 0:
            evens.append(idx)
        else:
            odds.append(idx)
    print(evens[0] if len(evens) == 1 else odds[0])

find_unique_evenness()
```

### Explanation
1. **Reading Input:** The input is read using standard input functions. The first value is the number of elements, and the second line contains the list of numbers.
2. **Classifying Numbers:** We use two lists, `evens` and `odds`, to store the positions of even and odd numbers respectively. By iterating through the numbers with their indices (starting from 1), we populate these lists.
3. **Determining the Result:** After classifying all numbers, we check the length of the `evens` list. If it contains exactly one element, that position is printed. Otherwise, the position from the `odds` list is printed. This works because the problem guarantees that exactly one number will be different in evenness, ensuring one of the lists will have exactly one element.

This approach efficiently determines the differing number's position in linear time, making it both optimal and straightforward.
