To solve this problem, we need to determine the maximum possible sum of integers written on cards when selecting K cards from three groups: A cards with 1, B cards with 0, and C cards with -1. The strategy is to maximize the sum by prioritizing cards with the highest value first.

### Approach
1. **Prioritize Higher Value Cards**: The optimal strategy is to take as many cards with 1 as possible first, followed by cards with 0, and finally cards with -1 if needed.
2. **Step-by-Selection**:
   - First, take the maximum possible number of cards with 1 (up to the limit of available cards or K).
   - If there are still cards left to pick after using all available 1s, take the remaining cards from the 0s.
   - If more cards are still needed, take the remaining required cards from the -1s.

This approach ensures that we maximize the sum by using the highest value cards first and only using lower or negative value cards when necessary.

### Solution Code
```python
def main():
    import sys
    A, B, C, K = map(int, sys.stdin.readline().split())
    total = 0
    remaining = K
    
    # Take as many 1s as possible
    take_1 = min(A, remaining)
    total += take_1
    remaining -= take_1
    
    if remaining > 0:
        # Take as many 0s as possible
        take_0 = min(B, remaining)
        remaining -= take_0
    
    if remaining > 0:
        # Take remaining from -1s
        total -= remaining
    
    print(total)

main()
```

### Explanation
1. **Reading Input**: The input values for A, B, C, and K are read from standard input.
2. **Taking 1s**: The maximum possible number of 1s (up to the minimum of A or K) is taken first, contributing directly to the total sum.
3. **Taking 0s**: If there are still cards left to pick after using all available 1s, the next step is to take 0s, which do not affect the sum but fill the required count of K.
4. **Taking -1s**: If there are still cards needed after using all available 1s and 0s, the remaining cards are taken from the -1s, which reduce the sum by the number of -1s taken.

This method ensures that the sum is maximized efficiently by leveraging the highest value cards first and only using lower value cards when necessary, all within the constraints provided.
