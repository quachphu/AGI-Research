To solve this problem, we need to determine the maximum length of a sorted subarray that can be obtained using the Thanos sorting algorithm. This algorithm repeatedly removes either the first or the second half of the array until the remaining elements are sorted in non-decreasing order.

### Approach
1. **Check Sorted Subarray**: For a given subarray, check if it is already sorted in non-decreasing order. If it is, the length of this subarray is the result.
2. **Recursive Splitting**: If the subarray is not sorted, split it into two equal halves. Recursively apply the same process to both halves and return the maximum length obtained from either half.
3. **Base Case Handling**: If the subarray length is 1, it is trivially sorted, so return 1.

This approach ensures that we explore all possible paths of splitting the array and determine the maximum length of a sorted subarray that can be achieved.

### Solution Code
```python
n = int(input())
arr = list(map(int, input().split()))

def max_sorted_length(arr, start, end):
    # Check if the current subarray is sorted
    is_sorted = True
    for i in range(start, end):
        if arr[i] > arr[i + 1]:
            is_sorted = False
            break
    if is_sorted:
        return end - start + 1
    
    # If not sorted, split into two halves and recurse
    length = end - start + 1
    mid = start + (length // 2) - 1
    left_max = max_sorted_length(arr, start, mid)
    right_max = max_sorted_length(arr, mid + 1, end)
    return max(left_max, right_max)

print(max_sorted_length(arr, 0, n - 1))
```

### Explanation
1. **Reading Input**: The input consists of the size of the array and the array elements.
2. **Recursive Function**: The `max_sorted_length` function checks if the current subarray (defined by `start` and `end` indices) is sorted. If it is, it returns the length of this subarray.
3. **Splitting the Array**: If the subarray is not sorted, the function splits it into two halves and recursively processes each half. The result is the maximum length obtained from either half.
4. **Base Case**: The recursion terminates when the subarray length is 1, ensuring each element is considered as a potential sorted subarray.

This solution efficiently explores all possible splits using recursion, ensuring that we find the longest sorted subarray achievable through the Thanos sorting algorithm. The time complexity is O(n log n) due to the recursive splitting and checking of subarrays.
