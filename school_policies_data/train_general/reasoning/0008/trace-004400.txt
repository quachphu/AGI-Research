To solve this problem, we need to determine the maximum XOR value between any two distinct cities numbered from 1 to N. Given the constraints, a direct computation of all pairs is infeasible, so we need an efficient mathematical approach.

### Approach
1. **Problem Analysis**: The maximum XOR value between two numbers within a range can be determined by finding the highest bit set in the binary representation of the largest number (N). This is because the maximum XOR value is achieved when two numbers have the highest possible differing bit.
2. **Key Insight**: For a given number N, the highest possible XOR value is determined by the next power of two greater than N minus 1. This is because the highest differing bit between two numbers will be at the position of the next power of two.
3. **Efficient Calculation**: 
   - Compute the highest power of two less than or equal to N using bit manipulation.
   - The result is then derived by doubling this highest power and subtracting 1, which gives the maximum XOR value.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    results = []
    for i in range(1, T + 1):
        N = int(input[i])
        if N == 1:
            results.append(0)
        else:
            m = 1 << (N.bit_length() - 1)
            results.append((m << 1) - 1)
    print('\n'.join(map(str, results)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the large possible number of test cases (up to 100,000).
2. **Handling Each Test Case**: For each test case:
   - If N is 1, there are no roads, so the result is 0.
   - Otherwise, compute the highest power of two less than or equal to N using bit length. This is done using `N.bit_length() - 1` to find the position of the highest bit, then shifting 1 to this position.
   - The maximum XOR value is calculated by doubling this highest power (using a left shift) and subtracting 1.
3. **Output**: Results for all test cases are collected in a list and printed at once to minimize I/O operations, which is crucial for handling large input sizes efficiently.

This approach ensures that we efficiently compute the result in constant time for each test case, making the solution scalable even for the upper limits of the input constraints.
