To solve this problem, we need to simulate the process of alternating cookie exchanges between Takahashi and Aoki over a given number of operations. Each operation involves checking if the current player's cookie count is odd (and eating one if it is), then giving half of the remaining cookies to the other player. 

### Approach
1. **Initialization**: Read the initial number of cookies for Takahashi and Aoki, and the number of operations to perform.
2. **Alternating Operations**: For each operation, determine whose turn it is (Takahashi starts first, then alternates with Aoki).
3. **Cookie Adjustment**: For the current player, check if their cookie count is odd. If so, subtract one. Then, give half of the remaining cookies to the other player.
4. **Update Counts**: After each operation, update the cookie counts for both players accordingly.
5. **Output Result**: After all operations are completed, print the final counts of cookies for Takahashi and Aoki.

### Solution Code
```python
a, b, k = map(int, input().split())

takahashi = a
aoki = b

for step in range(k):
    if step % 2 == 0:
        # Takahashi's turn
        if takahashi % 2 == 1:
            takahashi -= 1
        give = takahashi // 2
        aoki += give
        takahashi = takahashi // 2
    else:
        # Aoki's turn
        if aoki % 2 == 1:
            aoki -= 1
        give = aoki // 2
        takahashi += give
        aoki = aoki // 2

print(takahashi, aoki)
```

### Explanation
- **Reading Input**: The initial values of cookies for Takahashi and Aoki, along with the number of operations, are read from the input.
- **Loop Through Operations**: For each operation, check if it's Takahashi's turn (even-indexed steps) or Aoki's turn (odd-indexed steps).
- **Adjust Cookies**: If the current player's cookies are odd, reduce by one. Then, split the remaining cookies evenly, giving half to the other player.
- **Update Counts**: Adjust the counts for both players after each operation based on the cookies given.
- **Output**: After all operations, print the final counts of cookies for both players.

This approach efficiently handles up to 100 operations, ensuring that each operation is processed in constant time, making the solution both optimal and straightforward.
