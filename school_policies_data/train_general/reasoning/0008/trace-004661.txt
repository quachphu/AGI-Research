To solve this problem, we need to determine the top three highest mountain heights from a list of ten given heights and print them in descending order. The solution involves reading input values, sorting them, and selecting the highest three values.

### Approach
1. **Reading Input:** We read ten lines of input, each representing the height of a mountain.
2. **Storing Heights:** Store these heights in a list for further processing.
3. **Sorting:** Sort the list of heights in descending order to easily access the largest values.
4. **Selecting Top Three:** Extract the first three elements from the sorted list, which will be the highest three values.
5. **Output:** Print each of these top three values on separate lines.

### Solution Code
```python
def main():
    heights = []
    for _ in range(10):
        heights.append(int(input()))
    sorted_heights = sorted(heights, reverse=True)
    for height in sorted_heights[:3]:
        print(height)

main()
```

### Explanation
1. **Reading Input:** The loop reads ten integer values from the standard input and appends them to the list `heights`.
2. **Sorting:** The list `heights` is sorted in descending order using Python's built-in `sorted` function with the `reverse=True` parameter.
3. **Selecting Top Three:** The sorted list is sliced to take the first three elements, which are the highest values.
4. **Printing Output:** Each of the top three values is printed on a new line, ensuring the output format matches the requirement.

This approach efficiently handles the input constraints and ensures that the solution is both clear and concise, leveraging Python's built-in functionalities for sorting and list manipulation.
