To solve this problem, we need to determine if the total number of stamps collected by all members of the Stamp Collecting Community (SCC) can be redistributed such that the i-th member gets exactly i stamps. 

### Approach
1. **Sum Check**: The key insight here is that the sum of stamps after redistribution must exactly match the sum of the first N natural numbers. This is because each member i should end up with exactly i stamps, and the sum of the first N natural numbers is given by the formula \( \frac{N(N+1)}{2} \).
2. **Comparison**: If the total number of stamps collected by all members (sum of the given array) equals the target sum \( \frac{N(N+1)}{2} \), then redistribution is possible. Otherwise, it is not.

### Solution Code
```python
n = int(input())
ci = list(map(int, input().split()))
total = sum(ci)
target = n * (n + 1) // 2
print("YES" if total == target else "NO")
```

### Explanation
1. **Input Reading**: The code reads the number of members \( N \) and the list of integers representing the number of stamps each member currently has.
2. **Sum Calculation**: It calculates the total number of stamps collected by all members.
3. **Target Sum Calculation**: It computes the target sum using the formula \( \frac{N(N+1)}{2} \), which is the sum required for each member to have exactly i stamps.
4. **Comparison and Output**: The code checks if the total number of stamps matches the target sum and prints "YES" if they match, otherwise "NO".

This approach efficiently determines the possibility of redistribution by leveraging a simple mathematical sum check, ensuring it runs in linear time relative to the number of members, which is optimal for the given constraints.
