To solve this problem, we need to split a rooted tree into the minimum number of vertical paths such that each path does not exceed a given length (L) and sum (S). Each node must belong to exactly one path. A vertical path is a sequence of nodes where each node (except the first) is the parent of the previous node.

### Approach
1. **Check for Impossibility**: If any node's weight exceeds the maximum allowed sum (S), it is impossible to split the tree, so we immediately return -1.
2. **Depth Calculation**: Calculate the depth of each node to process nodes starting from the deepest levels upwards. This ensures that deeper nodes are processed first, allowing us to form the longest possible paths from the bottom up.
3. **Greedy Path Formation**: Process nodes in reverse order of their depth (deepest first). For each node, form the longest possible path starting from that node and moving upwards, ensuring the path constraints (sum and length) are not violated. Mark nodes as they are included in paths to avoid reuse.

### Solution Code
```python
def main():
    import sys
    sys.setrecursionlimit(1 << 25)
    n, L, S = map(int, sys.stdin.readline().split())
    w = list(map(int, sys.stdin.readline().split()))
    if any(wi > S for wi in w):
        print(-1)
        return
    if n == 1:
        print(1 if w[0] <= S and 1 <= L else -1)
        return
    p = list(map(int, sys.stdin.readline().split()))
    
    # parents[i] is the parent of node i (1-based)
    parents = [0] * (n + 1)  # parents[1] = 0 (root has no parent)
    for i in range(2, n + 1):
        parents[i] = p[i - 2]
    
    # Compute depth for each node (root is 1)
    depth = [0] * (n + 1)
    for i in range(2, n + 1):
        depth[i] = depth[parents[i]] + 1
    
    # Sort nodes in reverse order of depth
    nodes = sorted(range(1, n + 1), key=lambda x: -depth[x])
    
    covered = [False] * (n + 1)
    ans = 0
    
    for u in nodes:
        if not covered[u]:
            ans += 1
            current_sum = 0
            current_length = 0
            current_node = u
            while current_node != 0 and not covered[current_node]:
                if current_sum + w[current_node - 1] > S or current_length + 1 > L:
                    break
                current_sum += w[current_node - 1]
                current_length += 1
                covered[current_node] = True
                current_node = parents[current_node]
    
    print(ans)

main()
```

2. **Depth Calculation**: The depth of each node is calculated using a simple traversal, starting from the root (node 1) and propagating the depth to its children.
3. **Node Processing Order**: Nodes are sorted in reverse order of their depth to ensure deeper nodes are processed first. This allows us to form the longest possible paths starting from the deepest nodes.
4. **Greedy Path Formation**: For each node, starting from the deepest, we form the longest possible path upwards, ensuring the sum and length constraints are respected. Nodes are marked as covered once included in a path to avoid reuse.

This approach ensures that we form the minimum number of paths by always extending each path as much as possible from the deepest nodes upwards, leveraging the constraints effectively.
