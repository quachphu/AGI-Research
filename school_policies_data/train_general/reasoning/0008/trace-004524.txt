To solve this problem, we need to determine how many shops Vasiliy can buy his favorite drink from each day, given his daily budget. The solution must efficiently handle up to 100,000 shops and 100,000 daily queries.

### Approach
1. **Sort the Prices**: First, we sort the list of drink prices from all shops. Sorting helps us efficiently determine the number of shops with prices within a certain budget using binary search.
2. **Binary Search for Each Query**: For each daily budget, we use binary search to quickly find the number of shops where the price is less than or equal to the budget. This is done using the `bisect_right` function from Python's `bisect` module, which gives the insertion point just after the last element that is less than or equal to the budget.

### Solution Code
```python
import bisect
import sys

def main():
    n = int(sys.stdin.readline())
    prices = list(map(int, sys.stdin.readline().split()))
    prices.sort()
    q = int(sys.stdin.readline())
    mi_list = [int(line) for line in sys.stdin.read().splitlines()[:q]]
    for mi in mi_list:
        print(bisect.bisect_right(prices, mi))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read using `sys.stdin` functions to handle large input sizes efficiently. This avoids the overhead of repeated input calls.
2. **Sorting Prices**: The prices are sorted once, which takes O(n log n) time. This allows us to use binary search for each query.
3. **Binary Search with `bisect_right`**: For each daily budget, `bisect_right` finds the position where the budget would fit in the sorted list, which corresponds to the number of shops with prices less than or equal to the budget. This operation takes O(log n) time per query.

This approach ensures that the solution efficiently handles the upper constraints with a time complexity of O(n log n + q log n), making it suitable for large input sizes.
