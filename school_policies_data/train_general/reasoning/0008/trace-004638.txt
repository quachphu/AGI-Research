The solution involves using combinatorial mathematics to compute the number of ways to distribute the pennants, considering that pennants of the same type are indistinct.

### Approach
1. **Understanding the Problem**: Each table can hold any number of pennants. We need to compute the number of ways to distribute 5 bug pennants and 3 feature pennants across `n` tables. This is a combinatorial problem where we need to count the number of non-negative integer solutions to the equations for distributing the pennants.

2. **Combinatorial Mathematics**: The number of ways to distribute `k` indistinct items into `n` distinct bins is given by the combination formula with repetition, which is computed as `C(n + k - 1, k)`. Here, `C` denotes combinations.

3. **Formulas**:
   - For 5 bug pennants: The number of ways is `C(n + 4, 5)` because we need to distribute 5 items into `n` bins, which is equivalent to choosing 5 positions out of `n + 4`.
   - For 3 feature pennants: The number of ways is `C(n + 2, 3)` for similar reasons.

4. **Multiplication Principle**: The total number of ways to distribute both types of pennants is the product of the two combinations calculated above.

### Solution Code
```python
import math

n = int(input())
a = math.comb(n + 4, 5)
b = math.comb(n + 2, 3)
print(a * b)
```

1. **Reading Input**: The code reads the integer `n` from the standard input, representing the number of tables.
2. **Calculating Combinations**:
   - `math.comb(n + 4, 5)` computes the number of ways to distribute 5 bug pennants across `n` tables.
   - `math.comb(n + 2, 3)` computes the number of ways to distribute 3 feature pennants across `n` tables.
3. **Result Calculation**: The product of the two computed values gives the total number of ways to distribute all pennants, which is then printed.

This approach efficiently computes the required values using combinatorial mathematics, ensuring that the solution is both optimal and correct for the given constraints.
