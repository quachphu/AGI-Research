To solve this problem, we need to determine the answer for each step Chef played, which involves calculating the sum of absolute differences between the digit at a given index and all previous digits. This problem can be efficiently solved using a frequency count approach to avoid redundant calculations.

### Approach
1. **Understand the Problem**: For each query index `x`, compute the sum of absolute differences between the digit at `x` and all digits before it. This sum can be derived by considering the frequency of each digit encountered before `x`.
2. **Precomputation Strategy**: Use an array to keep track of the frequency of each digit (0-9) encountered up to each index. For each digit at index `i`, compute the sum of absolute differences using the frequency counts of digits from previous indices.
3. **Efficient Calculation**: By maintaining the frequency of each digit, we can compute the required sum in constant time for each index, leading to an overall time complexity of O(n * 10), which is efficient for large inputs.

### Solution Code
```python
n, m = map(int, input().split())
digits = input().strip()
counts = [0] * 10
sums = [0] * n

for i in range(n):
    current = int(digits[i])
    total = 0
    for d in range(10):
        total += counts[d] * abs(current - d)
    sums[i] = total
    counts[current] += 1

for _ in range(m):
    x = int(input())
    print(sums[x - 1])
```

### Explanation
1. **Reading Input**: The input consists of the number of digits `n`, the number of queries `m`, the sequence of digits, and the queries themselves.
2. **Frequency Count Array**: An array `counts` of size 10 (one for each digit) is used to track how many times each digit has appeared up to the current index.
3. **Precompute Sums**: For each digit in the sequence, compute the sum of absolute differences with all previous digits using the frequency counts. This precomputed sum is stored in the `sums` array.
4. **Query Processing**: For each query, directly retrieve the precomputed sum from the `sums` array using the 1-based index provided in the query.

This approach efficiently reduces the problem complexity by leveraging the limited range of digit values (0-9) and precomputing results to answer each query in constant time.
