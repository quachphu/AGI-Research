To solve this problem, we need to determine which characters 'o' (criminals) in a string can be terminated by characters 'x' (terminators) based on the presence of '*' (savers) between them. The goal is to process each string such that any 'o' that can be terminated by an 'x' (without a '*' blocking the path) is removed from the result.

### Approach
1. **Input Reading**: Read the number of test cases and the subsequent strings.
2. **String Processing**: For each string, check each 'o' to see if it can be terminated by any 'x' either to its left or right without a '*' in between.
3. **Termination Check**:
   - **Left Check**: Move left from the 'o' to find the nearest 'x' or '*'. If an 'x' is found first, the 'o' is terminated.
   - **Right Check**: Move right from the 'o' to find the nearest 'x' or '*'. If an 'x' is found first, the 'o' is terminated.
4. **Result Construction**: Construct the result string by including only those characters that are not terminated 'o's, along with all 'x' and '*' characters.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for i in range(1, T + 1):
        s = input[i]
        print(process_string(s))

def process_string(s):
    result = []
    for i in range(len(s)):
        c = s[i]
        if c != 'o':
            result.append(c)
            continue
        # Check left
        left = False
        j = i - 1
        while j >= 0:
            if s[j] == 'x':
                left = True
                break
            elif s[j] == '*':
                break
            j -= 1
        # Check right
        right = False
        j = i + 1
        while j < len(s):
            if s[j] == 'x':
                right = True
                break
            elif s[j] == '*':
                break
            j += 1
        if left or right:
            continue
        result.append('o')
    return ''.join(result)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read all at once and split into a list of strings. The first element is the number of test cases.
- **Processing Each String**: For each string, iterate through each character. If the character is 'o', check its left and right for the nearest 'x' or '*'.
- **Left and Right Checks**: These checks determine if an 'x' can terminate the 'o' without being blocked by a '*'. If either check finds a valid 'x', the 'o' is excluded from the result.
- **Constructing the Result**: Characters that are not terminated 'o's (including 'x' and '*') are added to the result string, which is then printed.

This approach ensures that each 'o' is checked efficiently in linear time relative to the string length, making the solution both optimal and easy to understand.
