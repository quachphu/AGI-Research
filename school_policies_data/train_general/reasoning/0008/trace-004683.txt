To solve this problem, we need to determine the optimal value of `d` such that the points scored by the first team minus the points scored by the second team is maximized. The points for each team are calculated based on the distance of their throws relative to `d`, where throws ≤ `d` are worth 2 points and throws > `d` are worth 3 points.

### Approach
1. **Sort the Distances**: First, we sort the distances of the throws for both teams to facilitate efficient binary search operations.
2. **Generate Candidates for `d`**: We consider all unique distances from both teams, along with `-1` (representing the minimum possible value) and a value greater than the maximum distance (to cover the case where all throws are worth 3 points).
3. **Evaluate Each Candidate**: For each candidate value of `d`, we compute the number of throws for each team that are ≤ `d` using binary search. This helps determine the points for each team and the difference in points.
4. **Track Maximum Difference**: We track the maximum difference in points and the corresponding counts of throws ≤ `d` for both teams. In case of ties, we prioritize the scenario where the first team's points are maximized.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    a = list(map(int, input[ptr:ptr + n]))
    ptr += n
    m = int(input[ptr])
    ptr += 1
    b = list(map(int, input[ptr:ptr + m]))
    ptr += m
    
    a.sort()
    b.sort()
    
    max_val = max(a[-1], b[-1]) if a and b else (a[-1] if a else b[-1])
    
    merged = set(a) | set(b)
    candidates = sorted(merged)
    candidates = [-1] + candidates + [max_val + 1]
    
    max_diff = float('-inf')
    best_count_a = best_count_b = 0
    
    for d in candidates:
        count_a = bisect.bisect_right(a, d)
        count_b = bisect.bisect_right(b, d)
        current_diff = count_b - count_a
        if current_diff > max_diff:
            max_diff = current_diff
            best_count_a = count_a
            best_count_b = count_b
        elif current_diff == max_diff:
            if count_a < best_count_a:
                best_count_a = count_a
                best_count_b = count_b
    
    a_points = 3 * n - best_count_a
    b_points = 3 * m - best_count_b
    print(f"{a_points}:{b_points}")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Sorting**: The distances of throws for both teams are sorted to enable efficient binary search operations.
2. **Candidate Generation**: We generate candidate values for `d` by considering all unique distances from both teams, plus `-1` and a value greater than the maximum distance to cover edge cases.
3. **Binary Search**: For each candidate `d`, we use binary search to quickly determine the number of throws ≤ `d` for both teams.
4. **Maximizing Difference**: We track the maximum difference in points and adjust for ties by prioritizing higher points for the first team.

This approach ensures that we efficiently evaluate all potential values of `d` and determine the optimal solution in O((n + m) log (n + m)) time complexity, which is suitable given the problem constraints.
