To solve this problem, we need to determine which of two constructed strings is lexicographically smaller. The strings are formed by repeating two given digits a and b a specific number of times each. The solution involves generating these strings and comparing them using lexicographical order.

### Approach
1. **Input Reading**: Read the two integers a and b from the input.
2. **String Construction**:
   - Construct the first string by repeating the digit a exactly b times.
   - Construct the second string by repeating the digit b exactly a times.
3. **Comparison**: Compare the two strings lexicographically. If they are equal, either can be printed. Otherwise, print the smaller one.

### Solution Code
```python
a, b = map(int, input().split())
s1 = str(a) * b
s2 = str(b) * a
print(s1 if s1 < s2 else s2)
```

### Explanation
1. **Reading Input**: The input is read as a single line containing two integers, a and b.
2. **String Construction**:
   - The first string `s1` is created by converting the integer `a` to a string and repeating it `b` times.
   - The second string `s2` is created by converting the integer `b` to a string and repeating it `a` times.
3. **Lexicographical Comparison**: The strings are compared using Python's string comparison, which inherently checks lexicographical order. The result of the comparison determines which string is printed.

This approach efficiently constructs the necessary strings and leverages Python's built-in string comparison to ensure correctness and simplicity. The solution handles all edge cases, including when the strings are of different lengths or when the digits are the same.
