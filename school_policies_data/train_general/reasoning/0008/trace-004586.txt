To solve this problem, we need to determine the minimum and maximum possible sums that Big P could get by potentially miswriting the digits '5' as '6' and vice versa. The approach involves transforming the digits of each number to achieve the smallest and largest possible values, then calculating the sums of these transformed values.

### Approach
1. **Understanding the Problem**: Big P might write '5' as '6' and '6' as '5'. We need to find the minimum and maximum sums by considering these transformations.
2. **Transformations**:
   - **Minimum Transformation**: Replace all '6' digits in both numbers with '5' to get the smallest possible values.
   - **Maximum Transformation**: Replace all '5' digits in both numbers with '6' to get the largest possible values.
3. **Sum Calculation**: Compute the sum of the minimum transformed values and the sum of the maximum transformed values.

### Solution Code
```python
a, b = map(int, input().split())

def get_min(n):
    return int(str(n).replace('6', '5'))

def get_max(n):
    return int(str(n).replace('5', '6'))

min_sum = get_min(a) + get_min(b)
max_sum = get_max(a) + get_max(b)

print(min_sum, max_sum)
```

### Explanation
1. **Reading Input**: The input consists of two positive integers A and B.
2. **Transformation Functions**:
   - `get_min(n)`: Converts a number to its minimum possible value by replacing all '6's with '5's.
   - `get_max(n)`: Converts a number to its maximum possible value by replacing all '5's with '6's.
3. **Calculating Sums**:
   - Compute the minimum sum by applying `get_min` to both A and B and adding the results.
   - Compute the maximum sum by applying `get_max` to both A and B and adding the results.
4. **Output**: Print the minimum and maximum sums.

This approach efficiently transforms each number and computes the required sums, ensuring optimal performance even for large values within the given constraints.
