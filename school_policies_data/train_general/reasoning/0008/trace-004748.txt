To solve this problem, we need to count the number of even digits from each index to the end of the given string. The solution should efficiently compute this for each position using a reverse traversal approach to ensure optimal performance.

### Approach
1. **Reverse Traversal**: Start from the end of the string and move backwards. This allows us to keep a cumulative count of even digits encountered so far.
2. **Cumulative Count**: As we traverse the string from right to left, maintain a running total of even digits. For each character, if it is even, increment the cumulative count.
3. **Store Results**: Append the cumulative count to a list during the reverse traversal. After processing all characters, reverse this list to get the results in the correct order corresponding to the original string indices.

This approach ensures that each character is processed exactly once, leading to an O(n) time complexity, where n is the length of the string, making it efficient for large input sizes up to 10^4 characters.

### Solution Code
```python
s = input().strip()
result = []
count = 0
for c in reversed(s):
    if int(c) % 2 == 0:
        count += 1
    result.append(count)
result = result[::-1]  # Reverse to get the correct order
print(' '.join(map(str, result)))
```

### Explanation
1. **Reading Input**: The input string is read and stripped of any leading/trailing whitespace.
2. **Reverse Traversal**: The string is processed from the last character to the first. For each character, check if it is even.
3. **Cumulative Count Update**: If the character is even, increment the cumulative count. This count is stored in a list as we traverse.
4. **Reversing Results**: After processing all characters, the list of counts is reversed to align with the original string indices.
5. **Output**: The reversed list is printed as space-separated integers, providing the required result for each index.

This method efficiently computes the required counts using a single pass through the string, ensuring optimal performance even for the maximum input size.
