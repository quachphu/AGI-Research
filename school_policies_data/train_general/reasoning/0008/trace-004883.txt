To solve this problem, we need to determine the number of buses required to transport all groups of people from a bus stop to their destination, given that each bus can carry a maximum of `m` people. The groups must be transported in the order they are standing in the queue, and each group must be entirely placed on a bus. If a group cannot fit into the current bus, it waits for the next one along with subsequent groups.

### Approach
1. **Input Reading**: Read the number of groups `n` and the maximum capacity `m` of each bus. Then read the list of groups where each element represents the number of people in that group.
2. **Bus Allocation**: Initialize a counter for the number of buses and a pointer to track the current group being processed.
3. **Iterative Group Processing**: For each bus, start from the current group and keep adding groups until the bus reaches its capacity. If a group cannot fit, increment the bus count and reset the capacity for the next bus.
4. **Termination Check**: Continue the process until all groups have been allocated to buses.

### Solution Code
```python
def calculate_buses():
    import sys
    n, m = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    
    buses = 0
    start = 0
    
    while start < n:
        current_sum = 0
        i = start
        while i < n and current_sum + a[i] <= m:
            current_sum += a[i]
            i += 1
        buses += 1
        start = i
    
    print(buses)

calculate_buses()
```

### Explanation
1. **Reading Input**: The first line of input is split into `n` (number of groups) and `m` (bus capacity). The second line is read as a list of integers representing the number of people in each group.
2. **Bus Counter Initialization**: We initialize `buses` to 0 and `start` to 0 to track the current group being processed.
3. **Processing Groups**: For each bus, we start from the current group (`start`) and sum the number of people in subsequent groups until adding another group would exceed the bus capacity `m`. Each time we fill a bus, we increment the bus counter and update `start` to the next group that couldn't fit.
4. **Output Result**: Once all groups are processed, the total number of buses used is printed.

This approach ensures that we efficiently allocate each group to buses in the required order, adhering to the constraints and ensuring optimal use of each bus's capacity.
