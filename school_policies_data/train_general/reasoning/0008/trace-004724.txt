To solve this problem, we need to form teams of two students each such that each team has the same programming skill. The goal is to determine the minimum number of problems students need to solve to achieve this, where solving a problem increases a student's skill by 1.

### Approach
1. **Sort the Skills**: By sorting the list of students' skills, we can pair consecutive students. This minimizes the difference in skills between each pair, thereby minimizing the number of problems needed to equalize their skills.
2. **Sum the Differences**: For each consecutive pair of students in the sorted list, compute the difference in their skills. The sum of these differences gives the minimum number of problems required.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
a.sort()
total = 0
for i in range(0, n, 2):
    total += a[i + 1] - a[i]
print(total)
```

### Explanation
1. **Input Reading**: The number of students `n` and their respective skills are read from the input.
2. **Sorting**: The skills array is sorted to ensure that consecutive elements are closest to each other, which helps in minimizing the required increments.
3. **Pairing and Summing Differences**: By iterating through the sorted list in steps of 2, we form pairs of consecutive students. The difference between each pair's skills is accumulated to get the total number of problems needed.

This approach ensures that we efficiently form teams with the minimum total number of problems solved, leveraging sorting to simplify the problem into a straightforward summation of differences.
