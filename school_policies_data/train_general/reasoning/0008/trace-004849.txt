### Approach

2. **Even N**: When N is even, the median is the average of the two middle elements. The number of distinct medians is determined by the range of sums of these two middle elements. The smallest sum is derived from the lower bounds, and the largest sum is derived from the upper bounds.

```python
n = int(input())
A = []
B = []
for _ in range(n):
    a, b = map(int, input().split())
    A.append(a)
    B.append(b)

A.sort()
B.sort()

if n % 2 == 1:
    k = (n + 1) // 2
    a_median = A[k - 1]
    b_median = B[-k]
    print(b_median - a_median + 1)
else:
    k = n // 2 - 1
    a_sum = A[k] + A[k + 1]
    # For B, take the (k+1)-th and (k+2)-th elements from the end
    # which corresponds to B_sorted[len(B) - (k+2)] and B_sorted[len(B) - (k+1) - 1]
    b1 = B[- (k + 2)]
    b2 = B[- (k + 1)]
    b_sum = b1 + b2
    print(b_sum - a_sum + 1)
```
