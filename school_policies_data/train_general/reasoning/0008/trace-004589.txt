To solve this problem, we need to determine the maximum prize money Ram can win by playing up to a given number of games. Each game can be played at most once, and the goal is to select the games with the highest prize money to maximize the total sum.

### Approach
1. **Problem Analysis**: The problem requires us to select the top `k` games (or all games if there are fewer than `k` games) with the highest prize money. This can be efficiently achieved by sorting the prize money in descending order and summing the top `k` values.
2. **Sorting**: Sorting the prize money in descending order allows us to easily pick the top `k` values. This operation has a time complexity of O(n log n), which is efficient for the given constraints.
3. **Summing Top Values**: After sorting, we sum the first `min(k, n)` elements, where `n` is the number of games. This ensures we handle cases where `k` might be larger than the number of available games.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n, k = map(int, sys.stdin.readline().split())
        a = list(map(int, sys.stdin.readline().split()))
        if k == 0:
            print(0)
            continue
        a.sort(reverse=True)
        m = min(k, n)
        total = sum(a[:m])
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency, especially with large input sizes.
2. **Handling Test Cases**: For each test case, we read the number of games `n` and the maximum number of games `k` Ram can play.
3. **Sorting**: The prize money array is sorted in descending order to prioritize the highest values.
4. **Summing Top Values**: We compute the sum of the top `min(k, n)` elements from the sorted array, ensuring we handle cases where `k` exceeds the number of available games.

This approach efficiently handles the constraints and ensures we maximize the prize money by leveraging sorting and summation of the highest values.
