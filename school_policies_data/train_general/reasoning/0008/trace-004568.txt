To solve this problem, we need to ensure that the inflation coefficients for each month do not exceed a given percentage \( k \). The goal is to determine the minimum total sum of changes required to adjust the prices such that all inflation coefficients remain within the allowed limit.

### Approach
1. **Understanding the Inflation Coefficient**: The inflation coefficient for the \( i \)-th month is given by the ratio of the price increase \( p_i \) to the cumulative sum of all previous prices up to month \( i-1 \). This ratio must not exceed \( k \% \).

2. **Adjusting Prices**: For each month \( i \), we need to ensure that the price increase \( p_i \) does not exceed \( k \% \) of the cumulative sum of all previous prices. If the cumulative sum is insufficient, we need to adjust previous prices to meet the requirement.

3. **Mathematical Formulation**: For each month \( i \), the required cumulative sum of previous prices must be at least \( \text{ceil}((100 \times p_i) / k) \). If the current cumulative sum is less than this required value, we adjust the cumulative sum to meet this requirement and track the total adjustments made.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    t = int(input[idx])
    idx += 1
    for _ in range(t):
        n, k = int(input[idx]), int(input[idx+1])
        idx += 2
        p = list(map(int, input[idx:idx+n]))
        idx += n
        sum_prev = p[0]
        total = 0
        for i in range(1, n):
            current_p = p[i]
            required_sum = (100 * current_p + k - 1) // k
            if sum_prev < required_sum:
                total += required_sum - sum_prev
                sum_prev = required_sum
            sum_prev += current_p
        print(total)

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints. The number of test cases \( t \) is read first, followed by each test case's parameters and price array.

2. **Processing Each Test Case**: For each test case, initialize the cumulative sum of prices with the initial price \( p_0 \). Iterate through each subsequent month's price increase.

3. **Calculating Required Sum**: For each month \( i \), compute the minimum required cumulative sum of previous prices using the formula \( \text{ceil}((100 \times p_i) / k) \). This ensures the current price increase does not exceed \( k \% \) of the cumulative sum.

4. **Adjusting Cumulative Sum**: If the current cumulative sum is less than the required value, adjust it by the necessary amount and track the total adjustments made. Update the cumulative sum by adding the current month's price increase.

5. **Output the Result**: After processing all months for a test case, output the total adjustments required.
