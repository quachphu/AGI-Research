To solve this problem, we need to generate a "Hall of Fame" from log entries of friends using an app, sorted by the number of times each friend used the app in descending order. In case of a tie, the friend who used the app first (earlier in the log) should come first.

### Approach
1. **Read Input**: First, we read the number of entries and the list of names from the input.
2. **Track Counts and First Occurrence**: Using a dictionary, we track each friend's usage count and their first occurrence index in the log.
3. **Sort Entries**: We sort the entries first by count in descending order. If counts are equal, we sort by the first occurrence index in ascending order.
4. **Output Results**: Finally, we print the sorted results in the required format.

### Solution Code
```python
def hall_of_fame():
    import sys
    n = int(sys.stdin.readline())
    names = sys.stdin.readline().split()
    
    counts = {}
    for index, name in enumerate(names):
        if name not in counts:
            counts[name] = [1, index]
        else:
            counts[name][0] += 1
    
    sorted_counts = sorted(counts.items(), key=lambda x: (-x[1][0], x[1][1]))
    
    for name, data in sorted_counts:
        print(f"{name} {data[0]}")

hall_of_fame()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin` for efficiency. The first line gives the number of entries, and the second line contains the names.
2. **Tracking Data**: We use a dictionary where each key is a friend's name and the value is a list containing their usage count and the index of their first occurrence.
3. **Sorting**: The dictionary items are sorted using a custom key. The primary sort key is the negative of the count (to sort descending), and the secondary key is the first occurrence index (to sort ascending in case of ties).
4. **Output**: The sorted results are printed in the required "name count" format.

This approach efficiently processes the input and ensures the correct ordering as specified, handling ties by the time of first occurrence.
