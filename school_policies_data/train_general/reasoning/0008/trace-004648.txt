To solve this problem, we need to determine the minimum number of insertions required to transform a given string into a palindrome. A palindrome reads the same forwards and backwards. The key insight is that the minimum insertions required can be found by subtracting the length of the longest palindromic subsequence (LPS) from the length of the original string.

### Approach
1. **Longest Palindromic Subsequence (LPS)**: The LPS of a string is the longest sequence of characters that reads the same forwards and backwards. The minimum number of insertions required to make a string a palindrome is the difference between the string's length and its LPS length.
2. **Dynamic Programming (DP)**: We use a DP table to compute the LPS. The table `dp[i][j]` represents the length of the LPS in the substring from index `i` to `j`. The solution fills this table in a bottom-up manner, considering all possible substrings of increasing lengths.

### Solution Code
```python
def min_insertions(s):
    n = len(s)
    dp = [[0] * n for _ in range(n)]
    
    for i in range(n):
        dp[i][i] = 1
    
    for cl in range(2, n + 1):
        for i in range(n - cl + 1):
            j = i + cl - 1
            if s[i] == s[j]:
                if cl == 2:
                    dp[i][j] = 2
                else:
                    dp[i][j] = 2 + dp[i + 1][j - 1]
            else:
                dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
    
    return len(s) - dp[0][n - 1]

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        n = int(input[idx])
        idx += 1
        s = input[idx]
        idx += 1
        print(min_insertions(s))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list for easier processing. The first value is the number of test cases.
2. **Processing Each Test Case**: For each test case, read the string length (though it is not used directly) and the string itself.
3. **DP Table Initialization**: A 2D DP table is initialized where `dp[i][i]` is set to 1 because a single character is a palindrome of length 1.
4. **Filling the DP Table**: For each possible substring length from 2 to `n`, the table is filled by comparing characters at the ends of the substring. If they match, the LPS length is increased by 2 plus the LPS of the inner substring. If they do not match, the maximum LPS length from either excluding the first or last character is taken.
5. **Result Calculation**: The result for each string is the difference between its length and the LPS length, which is printed as the output.

This approach efficiently computes the minimum insertions required using dynamic programming, ensuring optimal performance even for the upper constraint of string length 20.
