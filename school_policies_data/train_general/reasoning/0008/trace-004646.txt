To solve this problem, we need to determine if a given password string (P) can be formed by inserting a copy of a given word (S) into itself exactly once. The solution involves checking all possible ways to split the original word and insert its copy to form the password.

### Approach
1. **Check Length Constraint**: The password (P) must be exactly twice the length of the word (S). If not, it's immediately impossible to form P from S.
2. **Check Possible Splits**: For each possible way to split S into a prefix and suffix, concatenate the prefix, the entire word S, and the suffix to form a candidate password. If any candidate matches P, then P is possible.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        s, p = sys.stdin.readline().strip().split()
        if len(p) != 2 * len(s):
            print("Impossible")
            continue
        possible = False
        n = len(s)
        for i in range(n + 1):
            prefix = s[:i]
            suffix = s[i:]
            candidate = prefix + s + suffix
            if candidate == p:
                possible = True
                break
        print("Possible" if possible else "Impossible")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads the number of test cases and then processes each test case by reading the word (S) and password (P).
2. **Length Check**: If the length of P is not exactly twice the length of S, the result is immediately "Impossible".
3. **Generating Candidates**: For each possible split point in S (from 0 to the length of S), the code generates a candidate password by inserting S between the prefix and suffix of the split. If any candidate matches P, the result is "Possible".
4. **Output Result**: After checking all possible splits, the result is printed based on whether a valid candidate was found.

This approach efficiently checks all possible ways to form the password by leveraging string splitting and concatenation, ensuring correctness and optimal performance within given constraints.
