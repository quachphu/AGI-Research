To solve this problem, we need to determine the minimum distance Vasya has to travel to visit at least \( n-1 \) checkpoints starting from a given position \( a \). The checkpoints are located along a line, and we can visit them in any order. The goal is to minimize the total distance traveled.

### Approach
1. **Sorting Checkpoints**: First, we sort the checkpoints to simplify the process of determining the leftmost and rightmost points.
2. **Handling Edge Case**: If there is only one checkpoint, the answer is 0 since Vasya can choose not to visit any checkpoints.
3. **Three Scenarios**: For \( n \geq 2 \), we consider three scenarios to find the minimum distance:
   - **Excluding the First Checkpoint**: Compute the distance when the leftmost checkpoint is excluded.
   - **Excluding the Last Checkpoint**: Compute the distance when the rightmost checkpoint is excluded.
   - **Excluding a Middle Checkpoint**: Compute the distance when any middle checkpoint is excluded (the leftmost and rightmost checkpoints remain unchanged).
4. **Distance Calculation**: For each scenario, calculate the distance based on Vasya's starting position relative to the remaining checkpoints.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = int(input[1])
    x = list(map(int, input[2:2 + n]))
    x.sort()
    
    if n == 1:
        print(0)
        return
    
    def calculate_distance(l, r):
        if a <= l:
            return r - a
        elif a >= r:
            return a - l
        else:
            return (r - l) + min(a - l, r - a)
    
    # Case 1: Exclude the first element
    l1 = x[1]
    r1 = x[-1]
    d1 = calculate_distance(l1, r1)
    
    # Case 2: Exclude the last element
    l2 = x[0]
    r2 = x[-2]
    d2 = calculate_distance(l2, r2)
    
    # Case 3: Exclude a middle element (l and r remain the same)
    l3 = x[0]
    r3 = x[-1]
    d3 = calculate_distance(l3, r3)
    
    print(min(d1, d2, d3))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Sorting Checkpoints**: By sorting the checkpoints, we can easily determine the leftmost and rightmost points, which are crucial for calculating distances.
2. **Distance Calculation Function**: The function `calculate_distance` computes the minimum distance based on Vasya's starting position relative to the leftmost (l) and rightmost (r) checkpoints. It handles three cases:
   - If Vasya starts left of all checkpoints, the distance is from his starting position to the rightmost checkpoint.
   - If Vasya starts right of all checkpoints, the distance is from his starting position to the leftmost checkpoint.
   - If Vasya starts between the checkpoints, the distance is the span of the checkpoints plus the shorter distance from his starting position to either end.
3. **Three Scenarios**: By evaluating the three scenarios (excluding the first, last, or a middle checkpoint), we ensure that all possible configurations are considered to find the minimal travel distance.

This approach efficiently narrows down the problem to three key scenarios, ensuring an optimal solution with a time complexity of \( O(n \log n) \) due to sorting, which is suitable for large input sizes up to \( 100,000 \).
