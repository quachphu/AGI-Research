To solve this problem, we need to determine if Alice can win at least half of the rounds in a rock-paper-scissors game against Bob, given that Alice must use a specific number of each move (rock, paper, scissors) and knows Bob's sequence of moves in advance. If she can win, we also need to provide a valid sequence of moves for her.

### Approach
1. **Problem Analysis**:
   - Alice wins a round if she plays a move that beats Bob's move.
   - The goal is to determine if Alice can win at least ⌈n/2⌉ rounds, where n is the total number of rounds.
   - We need to construct a sequence of moves for Alice that uses exactly the specified number of each move and maximizes her wins.

2. **Key Insights**:
   - For each of Bob's moves, determine the optimal move Alice should use to win that round.
   - Calculate the maximum possible wins Alice can achieve using her available moves.
   - If the maximum possible wins are at least ⌈n/2⌉, construct the sequence of moves by first using the optimal moves and then filling the remaining rounds with the leftover moves.

3. **Algorithm**:
   - Count the occurrences of each move (rock, paper, scissors) in Bob's sequence.
   - Calculate the maximum possible wins using the optimal moves against Bob's moves.
   - If the total possible wins are less than required, output "NO".
   - Otherwise, construct the sequence by first placing the optimal moves and then filling the remaining positions with leftover moves.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    a, b, c = map(int, input().split())
    s = input().strip()
    
    count_r = s.count('R')
    count_p = s.count('P')
    count_s = s.count('S')
    
    possible_win_r = min(count_r, b)
    possible_win_p = min(count_p, c)
    possible_win_s = min(count_s, a)
    
    total = possible_win_r + possible_win_p + possible_win_s
    required = (n + 1) // 2
    
    if total < required:
        print("NO")
    else:
        alice = [None] * n
        pr, pp, ps = possible_win_r, possible_win_p, possible_win_s
        
        for i in range(n):
            char = s[i]
            if char == 'R' and pr > 0:
                alice[i] = 'P'
                pr -= 1
            elif char == 'P' and pp > 0:
                alice[i] = 'S'
                pp -= 1
            elif char == 'S' and ps > 0:
                alice[i] = 'R'
                ps -= 1
        
        a_rem = a - possible_win_s
        b_rem = b - possible_win_r
        c_rem = c - possible_win_p
        
        for i in range(n):
            if alice[i] is None:
                if a_rem > 0:
                    alice[i] = 'R'
                    a_rem -= 1
                elif b_rem > 0:
                    alice[i] = 'P'
                    b_rem -= 1
                elif c_rem > 0:
                    alice[i] = 'S'
                    c_rem -= 1
        
        print("YES")
        print(''.join(alice))
```

4. **Checking Feasibility**: If the total possible wins are less than the required number, output "NO".
