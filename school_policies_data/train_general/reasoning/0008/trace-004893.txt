### Approach

2. **Process Each Test Case**:
   - For each test case, read the integer N, which indicates the number of integers to follow.
   - Read the next N integers and compute their sum.
   - Calculate the mean by performing integer division of the sum by N. This automatically truncates the fractional part.
3. **Output the Result**: Print the truncated mean for each test case.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        n = int(input[ptr])
        ptr += 1
        total = 0
        for _ in range(n):
            total += int(input[ptr])
            ptr += 1
        print(total // n)

main()
```

### Explanation
- **Reading Input Efficiently**: The code reads all input at once using `sys.stdin.read().split()`, which splits the input into a list of strings. This approach is efficient for handling multiple lines of input.
- **Pointer Management**: A pointer `ptr` is used to traverse the list of input values sequentially.
- **Summing Integers**: For each test case, the integers are summed as they are read.
- **Integer Division**: The sum is divided by the count of integers using integer division `//`, which truncates any fractional part, giving the required result.

This approach ensures that the solution is both efficient and straightforward, handling all edge cases within the given constraints.
