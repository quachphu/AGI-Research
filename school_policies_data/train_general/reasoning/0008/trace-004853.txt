To solve this problem, we need to determine the maximum value in an infinite sequence after performing a series of operations. Each operation adds a value to all multiples of a given integer. The challenge is to efficiently compute the maximum value without explicitly iterating through the infinite sequence.

### Approach
1. **Dynamic Programming with LCM Tracking**: We use a dynamic programming approach to track the Least Common Multiples (LCMs) of subsets of the given integers. For each LCM, we compute the sum of contributions from all integers that divide it.
2. **Efficient Sum Calculation**: For each new LCM generated by combining an existing LCM with the current integer, we compute the sum of contributions from all integers that divide this new LCM. This ensures we consider all relevant contributions efficiently.
3. **Maximization**: By maintaining a dictionary of LCMs and their corresponding sums, we can efficiently track and update the maximum sum encountered during the process.

### Solution Code
```python
import sys
import math

def main():
    q = int(sys.stdin.readline())
    operations = []
    for _ in range(q):
        m, x = map(int, sys.stdin.readline().split())
        operations.append((m, x))
    
    dp = {1: 0}  # Start with LCM 1 and sum 0 (no operations applied)
    
    for m, x in operations:
        tmp = {}
        # Process each current LCM in the dp
        for current_lcm in list(dp.keys()):
            # Compute the new LCM
            gcd_val = math.gcd(current_lcm, m)
            new_lcm = current_lcm * m // gcd_val
            
            # Calculate the sum for the new LCM by checking all mj's
            sum_new = 0
            for mj, xj in operations:
                if new_lcm % mj == 0:
                    sum_new += xj
            
            # Update the temporary dictionary
            if new_lcm in tmp:
                if sum_new > tmp[new_lcm]:
                    tmp[new_lcm] = sum_new
            else:
                tmp[new_lcm] = sum_new
        
        # Merge the temporary results into the main dp
        for lcm, s in tmp.items():
            if lcm in dp:
                if s > dp[lcm]:
                    dp[lcm] = s
            else:
                dp[lcm] = s
    
    # Find the maximum sum across all possible LCMs
    max_sum = max(dp.values())
    print(max_sum)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read and stored as a list of tuples, each containing an integer and its corresponding value to add.
2. **Dynamic Programming Initialization**: We initialize a dictionary `dp` with the LCM of 1 (representing no operations applied) and a sum of 0.
3. **Processing Each Operation**: For each integer and value pair, we generate new LCMs by combining the current integer with existing LCMs in the dictionary. For each new LCM, we compute the sum of contributions from all integers that divide it.
4. **Updating the Dictionary**: We merge the temporary results into the main dictionary, ensuring we keep the maximum sum for each LCM.
5. **Finding the Maximum Sum**: After processing all operations, the maximum value in the dictionary is the answer, which is printed as the result.

This approach efficiently tracks potential maximum values by leveraging the properties of LCMs and ensuring that each sum is computed based on all relevant contributions, thus avoiding the need to explicitly iterate through an infinite sequence.
