To solve this problem, we need to find the k-th smallest shortest path in a connected undirected weighted graph. The solution involves efficiently computing the shortest paths between all pairs of vertices and then determining the k-th smallest value among these paths.

### Approach
The key insight is that the k-th smallest shortest path can be found by considering the shortest paths from each vertex to all other vertices and collecting the k smallest values. Given the constraints, we use a modified Dijkstra's algorithm for each vertex to compute the shortest paths and collect the k smallest distances efficiently.

1. **Modified Dijkstra's Algorithm**: For each vertex, we run Dijkstra's algorithm but stop early once we have collected the k smallest distances to vertices with higher indices (to avoid duplicates and ensure each pair is considered only once).
2. **Priority Queue for k-th Smallest**: We use a max-heap (priority queue) to keep track of the k smallest distances encountered across all vertices. This allows us to efficiently maintain the k smallest values without storing all possible pairs.

### Solution Code
```python
import sys
import heapq

def main():
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx]); idx +=1
    m = int(input[idx]); idx +=1
    k = int(input[idx]); idx +=1

    adj = [[] for _ in range(n+1)]  # 1-based

    for _ in range(m):
        x = int(input[idx]); idx +=1
        y = int(input[idx]); idx +=1
        w = int(input[idx]); idx +=1
        adj[x].append((y, w))
        adj[y].append((x, w))

    # Collect all possible candidates
    candidates = []

    for u in range(1, n+1):
        dist = [float('inf')] * (n+1)
        dist[u] = 0
        visited = [False] * (n+1)
        heap = []
        heapq.heappush(heap, (0, u))
        collected = []
        count = 0
        while heap and count < k:
            d, v = heapq.heappop(heap)
            if visited[v]:
                continue
            visited[v] = True
            if v > u:
                collected.append(d)
                count +=1
            for neighbor, weight in adj[v]:
                if not visited[neighbor] and dist[neighbor] > d + weight:
                    dist[neighbor] = d + weight
                    heapq.heappush(heap, (dist[neighbor], neighbor))
        # Add the collected distances to the global list
        if collected:
            candidates.extend(collected)

    # Now find the k-th smallest in candidates
    candidates.sort()
    print(candidates[k-1])

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read and parsed to extract the number of vertices, edges, and k value. The adjacency list of the graph is constructed.
2. **Dijkstra's Algorithm for Each Vertex**: For each vertex, we run a modified Dijkstra's algorithm to compute the shortest paths to all other vertices. We stop early once we have collected the k smallest distances to vertices with higher indices (i.e., pairs (u, v) where v > u).
3. **Collecting Distances**: The collected distances for each vertex are added to a global list.
4. **Finding k-th Smallest**: The global list of distances is sorted, and the k-th smallest element is printed.

This approach efficiently computes the required shortest paths and uses a priority queue to manage the k smallest values, ensuring the solution is both time and space efficient given the problem constraints.
