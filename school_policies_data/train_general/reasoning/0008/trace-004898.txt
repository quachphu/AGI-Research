To solve this problem, we need to determine the number of beautiful pairs (a, b) where a < b, such that Shil can see the peak of the b-th hill from the peak of the a-th hill. The line of sight from a to b must not be blocked by any intermediate hills.

### Approach
1. **Problem Analysis**: For a pair (a, b) to be beautiful, the line connecting the peaks of hills a and b must not be obstructed by any hill between them. This means the slope of the line from a to b must be greater than or equal to the slope from a to any intermediate hill k (where a < k < b).

2. **Key Insight**: By iterating through each hill a and checking subsequent hills b in order, we can track the maximum slope encountered so far. If the slope from a to b is greater than or equal to this maximum slope, the pair (a, b) is valid.

3. **Efficient Slope Comparison**: To avoid floating-point precision issues, we compare slopes using cross-multiplication. This allows us to maintain precision even with large values.

### Solution Code
```python
def count_beautiful_pairs():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    x = []
    y = []
    for _ in range(N):
        xi = int(input[idx])
        yi = int(input[idx + 1])
        x.append(xi)
        y.append(yi)
        idx += 2
    
    count = 0
    for a in range(N - 1):
        max_num = -10**18
        max_den = 1
        for b in range(a + 1, N):
            dx = x[b] - x[a]
            dy = y[b] - y[a]
            if dy * max_den >= max_num * dx:
                count += 1
            if dy * max_den > max_num * dx:
                max_num = dy
                max_den = dx
    print(count)

count_beautiful_pairs()
```

1. **Reading Input**: The input is read and parsed into lists of x and y coordinates for each hill.
2. **Iterating Over Pairs**: For each hill a, we iterate over all subsequent hills b. For each pair (a, b), we calculate the slope from a to b using integer arithmetic to avoid precision issues.
3. **Tracking Maximum Slope**: We maintain the maximum slope encountered so far using cross-multiplication. If the current slope is greater than or equal to this maximum, the pair (a, b) is counted as beautiful.
4. **Efficiency**: By tracking the maximum slope dynamically as we iterate, we ensure the solution runs in O(N^2) time, which is efficient for the given constraints.

This approach efficiently checks each potential pair while maintaining precision, ensuring correctness even with large input values.
