To solve this problem, we need to convert between two spreadsheet cell notation systems: the Excel-like format (e.g., BC23) and the RXCY format (e.g., R23C55). The task involves reading input coordinates and converting each to the other format.

### Approach
1. **Input Detection**: Determine if the input line is in the RXCY format or the Excel-like format using regular expressions.
2. **Conversion Logic**:
   - **RXCY to Excel-like**: Extract the row and column numbers from the RXCY format, convert the column number to letters using a base-26 system (adjusted for 1-based indexing), and combine with the row number.
   - **Excel-like to RXCY**: Split the input into letters (column) and digits (row), convert the column letters to a number, and format as RXCY.

### Solution Code
```python
import re

def main():
    import sys
    input = sys.stdin.read().splitlines()
    n = int(input[0])
    for line in input[1:n+1]:
        line = line.strip()
        # Check if it's in RXCY format
        rx_match = re.fullmatch(r'R(\d+)C(\d+)', line)
        if rx_match:
            row = rx_match.group(1)
            col_num = int(rx_match.group(2))
            # Convert column number to letters
            letters = []
            n_col = col_num
            while n_col > 0:
                n_col -= 1
                remainder = n_col % 26
                letters.append(chr(65 + remainder))
                n_col = n_col // 26
            letters_str = ''.join(reversed(letters))
            print(f"{letters_str}{row}")
        else:
            # Split into letters and digits
            ex_match = re.fullmatch(r'([A-Za-z]+)(\d+)', line)
            letters_part = ex_match.group(1).upper()
            row_part = ex_match.group(2)
            # Convert letters to column number
            col_num = 0
            for c in letters_part:
                col_num = col_num * 26 + (ord(c) - ord('A') + 1)
            print(f"R{row_part}C{col_num}")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Input Detection**: The code uses regular expressions to check if the input matches the RXCY pattern (`R\d+C\d+`). If it does, the line is processed as RXCY format; otherwise, it is treated as Excel-like.
2. **RXCY to Excel Conversion**:
   - Extract the row and column numbers.
   - Convert the column number to letters using a base-26 system with adjustments for 1-based indexing (by decrementing the column number before each division).
3. **Excel to RXCY Conversion**:
   - Split the input into letters (column) and digits (row).
   - Convert the column letters to a number by iterating through each character and applying base-26 conversion.
4. **Efficiency**: The solution efficiently processes each line using regular expressions and arithmetic operations, ensuring it handles the maximum input size constraints effectively.
