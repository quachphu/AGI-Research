To solve this problem, we need to determine the minimum number of seconds required to rearrange a line of soldiers such that the first soldier is the tallest and the last soldier is the shortest. Each swap of neighboring soldiers takes one second.

### Approach
1. **Identify Key Positions**: 
   - Find the position of the leftmost occurrence of the maximum height (to minimize the number of swaps needed to bring it to the front).
   - Find the position of the rightmost occurrence of the minimum height (to minimize the number of swaps needed to bring it to the end).

2. **Calculate Swaps**:
   - The number of swaps required to move the tallest soldier to the front is the position of the leftmost maximum.
   - The number of swaps required to move the shortest soldier to the end is calculated from the rightmost minimum's position. If the shortest soldier is initially positioned before the tallest soldier, we need to adjust its position by one because moving the tallest soldier affects the shortest soldier's position.

### Solution Code
```python
n = int(input())
a = list(map(int, input().split()))
max_val = max(a)
min_val = min(a)

max_pos = a.index(max_val)
# Find the last occurrence of min_val
min_pos = len(a) - 1 - a[::-1].index(min_val)

if min_pos < max_pos:
    total = max_pos + (n - 1 - min_pos) - 1
else:
    total = max_pos + (n - 1 - min_pos)

print(total)
```

### Explanation
1. **Reading Input**: The code reads the number of soldiers and their respective heights.
2. **Finding Extremes**: The maximum and minimum values in the list of heights are identified.
3. **Determining Positions**:
   - The leftmost occurrence of the maximum value is found using `a.index(max_val)`.
   - The rightmost occurrence of the minimum value is found by reversing the list and using index calculation.
4. **Calculating Swaps**: 
   - If the rightmost minimum is initially positioned before the leftmost maximum, moving the maximum to the front shifts the minimum's position by one, thus requiring an adjustment in the calculation.
   - The total number of swaps is the sum of swaps needed to move the maximum to the front and the minimum to the end, adjusted if necessary.

This approach efficiently calculates the minimum swaps required by focusing on the critical positions of the tallest and shortest soldiers, ensuring optimal performance with a linear scan of the list.
