1. **Problem Analysis**: The problem can be modeled as a state transition problem where each state represents the number of players with consecutive wins from 0 up to M-1. The goal is to transition through these states until at least one player achieves M consecutive wins.

2. **State Representation**: Each state is represented as a tuple where each element indicates the number of players with a specific number of consecutive wins. For example, a state (a0, a1, ..., aM-1) means there are `a0` players with 0 consecutive wins, `a1` players with 1 consecutive win, etc.

3. **Breadth-First Search (BFS)**: We use BFS to explore all possible states starting from the initial state where all players have 0 consecutive wins. Each state transition corresponds to one turn of the game, where players are paired, and their consecutive wins are updated based on the game outcomes.

4. **Transition Logic**: For each state, we compute the next possible state by:
   - Pairing players within each group (players with the same consecutive wins).
   - Updating the counts of consecutive wins for winners and losers of each pair.
   - Checking if the next state leads to a player achieving M consecutive wins.

### Solution Code
```python
import sys
from collections import deque

def main():
    case = 1
    while True:
        line = sys.stdin.readline()
        if not line:
            break
        line = line.strip()
        if not line:
            continue
        N, M = map(int, line.split())
        if N == 0 and M == 0:
            break
        if M == 0:
            print(f"Case {case}: 0")
            case += 1
            continue
        
        target = M
        initial = [0] * target
        initial[0] = N
        initial = tuple(initial)
        visited = set()
        queue = deque([(initial, 0)])
        visited.add(initial)
        answer = -1
        
        while queue:
            state, steps = queue.popleft()
            
            # Check if current state can reach M consecutive wins in the next step
            if state[target - 1] >= 2:
                answer = steps + 1
                break
            
            # Compute the next state
            p = [cnt // 2 for cnt in state]
            sum_p = sum(p)
            new_state = [0] * target
            
            # Calculate new_a0
            new_state[0] = (state[0] - 2 * p[0]) + sum_p
            
            # Calculate new_a for k >= 1
            for k in range(1, target):
                new_state[k] = (state[k] - 2 * p[k]) + p[k - 1]
            
            new_state = tuple(new_state)
            
            if new_state not in visited:
                visited.add(new_state)
                queue.append((new_state, steps + 1))
        
        print(f"Case {case}: {answer}")
        case += 1

if __name__ == "__main__":
    main()
```

### Explanation
- **State Initialization**: The initial state is set with all players having 0 consecutive wins.
- **BFS Exploration**: Using BFS, we explore each possible state transition by pairing players in each group and updating their consecutive wins.
- **Transition Calculation**: For each state, we compute the next state by pairing players and updating their consecutive wins. Winners move to the next consecutive win group, while losers reset to 0 wins.
- **Termination Check**: The BFS terminates when we find a state where the highest consecutive win group (M-1) has at least 2 players, which allows us to transition to M consecutive wins in the next turn.

This approach ensures that we efficiently explore all possible states and find the minimum number of turns required using BFS, which is optimal for this problem's constraints.
