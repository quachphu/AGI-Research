To solve this problem, we need to determine how many times a specific day occurs in the year 2016 based on two possible input formats: a day of the week or a day of the month. The solution involves different calculations for each format.

### Approach

1. **Day of the Week**:
   - The year 2016 starts on a Friday (January 1, 2016) and is a leap year with 366 days.
   - Each week has 7 days, so 366 days result in 52 full weeks and 2 extra days. These extra days are Friday and Saturday, meaning they occur 53 times each, while all other days occur 52 times.

2. **Day of the Month**:
   - We need to count how many months in 2016 have a specific day. For example, the 30th day exists in all months except February (which had 29 days in 2016).
   - We check each month to see if the given day is valid (i.e., less than or equal to the number of days in that month).

### Solution Code

```python
def main():
    import sys
    line = sys.stdin.readline().strip()
    parts = line.split()
    x = int(parts[0])
    if parts[2] == 'week':
        if x == 5 or x == 6:
            print(53)
        else:
            print(52)
    else:
        months_days = [31, 29, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
        count = sum(1 for days in months_days if x <= days)
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation

1. **Reading Input**:
   - The input is read from standard input and split into parts to determine the type (week or month) and the specific day.

2. **Handling Day of the Week**:
   - If the input specifies a day of the week, check if the day is Friday (5) or Saturday (6). These days occur 53 times in 2016, while all other days occur 52 times.

3. **Handling Day of the Month**:
   - For a day of the month, we check each month's number of days in 2016. The valid months are those where the given day is less than or equal to the number of days in that month. The count of such valid months is the result.

This approach efficiently computes the required counts using direct checks and summation, ensuring optimal performance and correctness.
