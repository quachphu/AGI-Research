To solve this problem, we need to find the palindrome number closest to a given integer \( n \). If there are two palindrome numbers equally close to \( n \), we return the smaller one.

### Approach
1. **Check if \( n \) is a Palindrome**: If \( n \) itself is a palindrome, we directly return \( n \) as the result.
2. **Find the Closest Palindromes**:
   - **Previous Palindrome**: Starting from \( n-1 \), decrement until we find the largest palindrome smaller than \( n \).
   - **Next Palindrome**: Starting from \( n+1 \), increment until we find the smallest palindrome larger than \( n \).
3. **Compare Distances**: Calculate the distances from \( n \) to both the previous and next palindromes. Return the one with the smaller distance. If distances are equal, return the smaller palindrome.

### Solution Code
```python
def is_palindrome(x):
    s = str(x)
    return s == s[::-1]

n = int(input())

if is_palindrome(n):
    print(n)
else:
    # Find previous palindrome
    prev_pali = None
    for i in range(n-1, -1, -1):
        if is_palindrome(i):
            prev_pali = i
            break
    # Find next palindrome
    next_pali = None
    i = n + 1
    while True:
        if is_palindrome(i):
            next_pali = i
            break
        i += 1
    # Compare distances
    d_prev = n - prev_pali
    d_next = next_pali - n
    if d_prev < d_next:
        print(prev_pali)
    elif d_next < d_prev:
        print(next_pali)
    else:
        print(min(prev_pali, next_pali))
```

### Explanation
1. **Palindrome Check**: The helper function `is_palindrome` checks if a number reads the same forwards and backwards by converting it to a string and comparing it with its reverse.
2. **Finding Previous Palindrome**: Starting from \( n-1 \) and moving downwards, the first palindrome encountered is the largest one smaller than \( n \).
3. **Finding Next Palindrome**: Starting from \( n+1 \) and moving upwards, the first palindrome encountered is the smallest one larger than \( n \).
4. **Distance Comparison**: The distances from \( n \) to the previous and next palindromes are compared. The closest one is returned, with ties resolved by choosing the smaller palindrome.

This approach efficiently narrows down the search to the immediate vicinity of \( n \), ensuring optimal performance even for the upper constraint of \( n = 10,000 \).
