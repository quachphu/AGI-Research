The valid bus number must be a permutation of a subset of the digits he saw, must not start with a zero, and must include all unique digits from the original number.

### Approach
1. **Count Digit Frequencies**: First, count the frequency of each digit in the input number.
2. **Generate Possible Combinations**: For each unique digit in the input, generate all possible counts (from 1 to the original count) to form valid combinations.
3. **Calculate Permutations**: For each valid combination, compute the number of permutations, adjusting for invalid permutations that start with zero.
4. **Sum Valid Permutations**: Sum the valid permutations for all combinations to get the total number of possible valid bus numbers.

### Solution Code
```python
import sys
from itertools import product

def main():
    n = sys.stdin.read().strip()
    count_digits = {}
    for c in n:
        count_digits[c] = count_digits.get(c, 0) + 1
    
    max_fact = sum(count_digits.values())
    fact = [1] * (max_fact + 1)
    for i in range(1, max_fact + 1):
        fact[i] = fact[i-1] * i
    
    digits = list(count_digits.keys())
    possible_counts = []
    for d in digits:
        original_count = count_digits[d]
        possible_counts.append(list(range(1, original_count + 1)))
    
    total = 0
    
    for counts in product(*possible_counts):
        sum_counts = sum(counts)
        denominator = 1
        count_zero = 0
        for i in range(len(counts)):
            cnt = counts[i]
            denominator *= fact[cnt]
            if digits[i] == '0':
                count_zero = cnt
        total_perm = fact[sum_counts] // denominator
        if count_zero > 0:
            invalid = (total_perm * count_zero) // sum_counts
            valid_perm = total_perm - invalid
        else:
            valid_perm = total_perm
        total += valid_perm
    
    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Digit Frequency Count**: The input number is read, and the frequency of each digit is counted using a dictionary.
2. **Factorial Precomputation**: Factorials up to the maximum possible length of the input number (18 digits) are precomputed to efficiently calculate permutations later.
3. **Generate Valid Combinations**: Using itertools.product, generate all valid combinations of digit counts where each digit appears at least once but no more than its original count.
4. **Permutation Calculation**: For each combination, calculate the total permutations of the digits and subtract those permutations that start with zero (if zero is part of the combination).
5. **Sum Valid Permutations**: The valid permutations for each combination are summed to get the final result, which is printed.

This approach ensures that all valid permutations are considered efficiently, even for large input sizes, by leveraging combinatorial mathematics and precomputation.
