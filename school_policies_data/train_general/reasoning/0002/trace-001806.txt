To solve this problem, we need to determine the number of operations required to reduce a given positive integer to 1 using the Collatz conjecture rules. The solution involves reading multiple input values until a zero is encountered, processing each non-zero value to compute the number of steps, and outputting the results.

### Approach
1. **Reading Input**: The input consists of multiple integers, each on a separate line. The end of the input is indicated by a zero.
2. **Collatz Conjecture Rules**: For each integer:
   - If the integer is even, divide it by 2.
   - If the integer is odd, multiply it by 3 and add 1.
3. **Counting Steps**: For each input integer, repeatedly apply the Collatz rules until the integer becomes 1, counting each operation.
4. **Output Results**: After processing each integer, output the count of operations required to reach 1.

### Solution Code
```python
def main():
    import sys
    for line in sys.stdin:
        n = int(line.strip())
        if n == 0:
            break
        count = 0
        current = n
        while current != 1:
            if current % 2 == 0:
                current //= 2
            else:
                current = current * 3 + 1
            count += 1
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads lines from standard input until it encounters a zero. Each line is stripped of whitespace and converted to an integer.
2. **Processing Each Integer**: For each non-zero integer, the code initializes a counter and processes the integer using the Collatz rules until the integer becomes 1. The counter is incremented for each operation.
3. **Applying Collatz Rules**: The loop continues until the integer is reduced to 1. For each iteration, the integer is either halved (if even) or transformed using the 3n + 1 rule (if odd).
4. **Output**: After processing each integer, the count of operations is printed.

This approach ensures that each input is processed efficiently, and the solution adheres to the problem constraints, providing the correct number of operations for each input integer.
