To solve this problem, we need to determine the maximum points a player can achieve in their current turn by placing a stone on an empty vertex of a triangular board. The points are calculated based on the number of stones removed from other players minus the number of the player's own stones removed.

### Approach
1. **Input Parsing**: Read the input values to construct the board and identify the player's current turn.
2. **Simulate Moves**: For each empty vertex on the board, simulate placing the player's stone and check the resulting groups of stones.
3. **Group Identification**: Use BFS to identify connected components (groups) of stones with the same number.
4. **Check Adjacency**: For each identified group, check if any cell in the group is adjacent to an empty vertex. If not, the group is removed.
5. **Calculate Points**: Compute the points for each valid move by considering the number of stones removed from others and the player's own stones removed. Track the maximum points across all possible moves.

### Solution Code
```python
import sys
from collections import deque
import copy

def get_adjacent_problem_coords(i, j, N):
    adjacent = []
    # Left
    if j > 1:
        adjacent.append((i, j-1))
    # Right
    if j < i:
        adjacent.append((i, j+1))
    # Top-left
    if i > 1 and j > 1:
        adjacent.append((i-1, j-1))
    # Top-right
    if i > 1 and j <= (i-1):
        adjacent.append((i-1, j))
    # Bottom-left and bottom-right
    if i < N:
        adjacent.append((i+1, j))
        adjacent.append((i+1, j+1))
    return adjacent

def main():
    while True:
        line = sys.stdin.readline()
        if not line:
            break
        line = line.strip()
        if not line:
            continue
        parts = line.split()
        N, C = map(int, parts)
        if N == 0 and C == 0:
            break
        
        board = [[] for _ in range(N+1)]  # 1-based rows
        for i in range(1, N+1):
            while True:
                line = sys.stdin.readline().strip()
                if line:
                    break
            elements = list(map(int, line.split()))
            board[i] = elements.copy()
        
        max_points = -float('inf')
        empty_cells = []
        for i in range(1, N+1):
            for j_code in range(len(board[i])):
                if board[i][j_code] == 0:
                    empty_cells.append((i, j_code))
        
        for (i, j_code) in empty_cells:
            new_board = copy.deepcopy(board)
            new_board[i][j_code] = C
            
            visited = [[False for _ in row] for row in new_board]
            groups = []
            for x in range(1, N+1):
                x_row = new_board[x]
                for y_code in range(len(x_row)):
                    if x_row[y_code] == 0 or visited[x][y_code]:
                        continue
                    value = x_row[y_code]
                    queue = deque()
                    queue.append((x, y_code))
                    visited[x][y_code] = True
                    group = [(x, y_code)]
                    while queue:
                        xi, yj_code = queue.popleft()
                        problem_j = yj_code + 1
                        adj_problem = get_adjacent_problem_coords(xi, problem_j, N)
                        adj_code = []
                        for (a, b) in adj_problem:
                            if 1 <= a <= N and 1 <= b <= a:
                                adj_code.append((a, b-1))
                        for (a, b_code) in adj_code:
                            if a < 1 or a > N or b_code >= len(new_board[a]):
                                continue
                            if new_board[a][b_code] == value and not visited[a][b_code]:
                                visited[a][b_code] = True
                                queue.append((a, b_code))
                                group.append((a, b_code))
                    groups.append((value, group))
            
            total_C = 0
            total_others = 0
            for (val, group) in groups:
                has_empty = False
                for (x, y_code) in group:
                    x_problem = x
                    y_problem = y_code + 1
                    adj_problem = get_adjacent_problem_coords(x_problem, y_problem, N)
                    for (a, b) in adj_problem:
                        if 1 <= a <= N and 1 <= b <= a:
                            if new_board[a][b-1] == 0:
                                has_empty = True
                                break
                    if has_empty:
                        break
                if not has_empty:
                    if val == C:
                        total_C += len(group)
                    else:
                        total_others += len(group)
            current_points = total_others - total_C
            if current_points > max_points:
                max_points = current_points
        
        print(max_points if max_points != -float('inf') else 0)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Input Parsing**: The input is read and parsed into a board structure where each row is stored as a list of integers.
2. **Empty Cells Identification**: All empty cells (vertices with value 0) are identified as potential moves for the player.
3. **Simulate Moves**: For each empty cell, a deep copy of the board is created, and the player's stone is placed at the empty cell.
4. **Group Identification**: Using BFS, all connected components (groups) of stones with the same number are identified.
5. **Adjacency Check**: Each group is checked to determine if any of its cells are adjacent to an empty cell. If not, the group is marked for removal.
6. **Points Calculation**: The points for each move are calculated based on the removed stones, and the maximum points across all moves are tracked and printed.

This approach ensures that all possible moves are evaluated efficiently, and the maximum points are determined accurately.
