To solve this problem, we need to categorize the visual acuity test results of individuals into four categories (A, B, C, D) based on predefined ranges for both left and right eyes. The goal is to count how many people fall into each category for each eye and then output these counts in a specific format.

### Approach
1. **Reading Input**: The input consists of multiple lines, each containing two real numbers representing the visual acuity of the left and right eyes respectively.
2. **Categorization**: Each visual acuity value is converted to an integer by multiplying by 10 to avoid floating-point precision issues. This integer is then categorized into A, B, C, or D based on the given ranges.
3. **Counting**: Maintain counts for each category for both left and right eyes.
4. **Output**: Print the counts for each category in the specified order.

### Solution Code
```python
import sys

def main():
    left_counts = {'A': 0, 'B': 0, 'C': 0, 'D': 0}
    right_counts = {'A': 0, 'B': 0, 'C': 0, 'D': 0}

    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        l_str, r_str = line.split()
        l_float = float(l_str)
        r_float = float(r_str)
        l_x = int(l_float * 10)
        r_x = int(r_float * 10)

        # Determine left category
        if l_x >= 11:
            left_counts['A'] += 1
        elif l_x >= 6:
            left_counts['B'] += 1
        elif l_x >= 2:
            left_counts['C'] += 1
        else:
            left_counts['D'] += 1

        # Determine right category
        if r_x >= 11:
            right_counts['A'] += 1
        elif r_x >= 6:
            right_counts['B'] += 1
        elif r_x >= 2:
            right_counts['C'] += 1
        else:
            right_counts['D'] += 1

    print(left_counts['A'], right_counts['A'])
    print(left_counts['B'], right_counts['B'])
    print(left_counts['C'], right_counts['C'])
    print(left_counts['D'], right_counts['D'])

main()
```

### Explanation
1. **Reading Input**: The code reads each line from standard input, strips any leading/trailing whitespace, and splits the line into left and right eye values.
2. **Conversion and Categorization**: Each value is converted to a float, multiplied by 10, and converted to an integer. This integer is checked against the ranges for each category (A, B, C, D) using simple conditional checks.
3. **Counting**: Separate counters for left and right eyes are maintained in dictionaries. Each time a value falls into a category, the corresponding counter is incremented.
4. **Output**: After processing all input lines, the counts for each category are printed in the specified order, ensuring the output format matches the problem requirements.

This approach efficiently handles the input and categorization using integer arithmetic to avoid floating-point precision issues, ensuring accurate counts and correct output.
