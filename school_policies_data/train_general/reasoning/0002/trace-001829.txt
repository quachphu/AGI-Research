The operation allows selecting a subarray (contiguous elements) and rearranging its elements in any order, but it cannot be applied to the entire array.

### Approach
1. **Check if Already Sorted**: If the permutation is already sorted, no operations are needed.
2. **Identify Mismatched Segments**: Find the leftmost and rightmost indices where the permutation deviates from the sorted array.
3. **Check Contiguous Mismatch**: Determine if the elements between these indices form a contiguous block that, when rearranged, can sort the entire permutation in one operation.
4. **Determine Operations**: If the contiguous block can be rearranged and it is not the entire array, one operation suffices. Otherwise, check if it can be sorted in two operations by considering edge cases where the entire array is mismatched but cannot be directly operated on.
