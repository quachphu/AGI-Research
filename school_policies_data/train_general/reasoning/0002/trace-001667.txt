To solve this problem, we need to determine if Snuke can distribute cookies from two tins such that each of his three goats receives the same number of cookies. The possible distributions are either using one tin or both tins combined. 

### Approach
The key insight is that the total number of cookies given (either from one tin or both) must be divisible by 3 for the cookies to be evenly divided among the three goats. We need to check three possibilities:
1. The number of cookies in the first tin (A) is divisible by 3.
2. The number of cookies in the second tin (B) is divisible by 3.
3. The sum of cookies from both tins (A+B) is divisible by 3.

If any of these conditions are met, it is possible to distribute the cookies evenly; otherwise, it is impossible.

### Solution Code
```python
A, B = map(int, input().split())
if A % 3 == 0 or B % 3 == 0 or (A + B) % 3 == 0:
    print("Possible")
else:
    print("Impossible")
```

### Explanation
1. **Input Reading**: The code reads two integers, A and B, representing the number of cookies in each tin.
2. **Divisibility Check**: The code checks if either A, B, or their sum (A+B) is divisible by 3 using the modulus operator.
3. **Output Decision**: If any of the checks pass, the code prints "Possible", indicating that an even distribution is feasible. Otherwise, it prints "Impossible".

This approach efficiently checks all possible valid distributions in constant time, ensuring optimal performance given the problem constraints.
