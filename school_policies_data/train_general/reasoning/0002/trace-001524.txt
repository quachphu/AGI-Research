To solve this problem, we need to calculate the radius of a sphere inscribed in a tetrahedron given the lengths of its edges. The solution involves using the Cayley-Menger determinant to compute the volume of the tetrahedron and Heron's formula to compute the surface areas of its faces. The inradius is then derived from these values.

### Approach
1. **Cayley-Menger Determinant**: This determinant helps compute the volume of a tetrahedron using the squares of its edge lengths. The determinant of a 5x5 matrix constructed from the edge lengths is used to find the volume.
2. **Heron's Formula**: This formula calculates the area of a triangle given its three sides. Each face of the tetrahedron is a triangle, and we use Heron's formula to compute the area of each face.
3. **Volume and Surface Area**: The volume derived from the Cayley-Menger determinant and the sum of the surface areas of the four faces are used to compute the inradius using the formula \( r = \frac{3 \times \text{Volume}}{\text{Total Surface Area}} \).

### Solution Code
```python
import sys
import math
import numpy as np

def compute_inradius():
    t = int(sys.stdin.readline())
    for _ in range(t):
        edges = list(map(int, sys.stdin.readline().split()))
        a, b, c, d, e, f = edges
        
        # Build Cayley-Menger matrix
        cm = np.array([
            [0, 1, 1, 1, 1],
            [1, 0, a**2, b**2, c**2],
            [1, a**2, 0, d**2, e**2],
            [1, b**2, d**2, 0, f**2],
            [1, c**2, e**2, f**2, 0]
        ], dtype=np.float64)
        
        det = np.linalg.det(cm)
        volume = math.sqrt(abs(det) / 288)
        
        # Compute surface areas using Heron's formula
        def heron(x, y, z):
            s = (x + y + z) / 2.0
            return math.sqrt(max(0, s * (s - x) * (s - y) * (s - z)))
        
        area1 = heron(a, b, d)
        area2 = heron(a, c, e)
        area3 = heron(b, c, f)
        area4 = heron(d, e, f)
        
        total_area = area1 + area2 + area3 + area4
        if total_area == 0:
            print("0.0000")
        else:
            r = (3 * volume) / total_area
            print("{0:.4f}".format(r))

compute_inradius()
```

3. **Volume Calculation**: The determinant is computed using numpy's linear algebra module, and the volume is derived from this determinant.
4. **Surface Area Calculation**: Each face of the tetrahedron is treated as a triangle, and Heron's formula is applied to compute the area of each face. The total surface area is the sum of these areas.
5. **Inradius Calculation**: The inradius is computed using the formula involving the volume and total surface area, and the result is formatted to four decimal places for output.
