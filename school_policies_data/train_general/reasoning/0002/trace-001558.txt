To solve this problem, we need to split a list of weights into two groups such that the absolute difference between their sums is minimized. The split is determined by an index T, where the first group contains elements up to T and the second group contains the remaining elements. 

### Approach
1. **Prefix Sum Calculation**: Compute a prefix sum array to efficiently calculate the sum of the first T elements for any possible T.
2. **Total Sum Calculation**: Determine the total sum of all weights, which helps in quickly calculating the sum of the second group.
3. **Iterate Over Possible Splits**: For each possible split point T (from 1 to N-1), compute the sum of the first group and use the total sum to find the sum of the second group. Calculate the absolute difference and track the minimum difference encountered.

### Solution Code
```python
n = int(input())
weights = list(map(int, input().split()))

prefix = [0] * (n + 1)
for i in range(1, n + 1):
    prefix[i] = prefix[i-1] + weights[i-1]

total = prefix[n]
min_diff = float('inf')

for t in range(1, n):
    current_sum = prefix[t]
    diff = abs(2 * current_sum - total)
    if diff < min_diff:
        min_diff = diff

print(min_diff)
```

### Explanation
1. **Reading Input**: The input consists of an integer N followed by N integers representing the weights.
2. **Prefix Sum Array**: The prefix sum array is constructed where each element at index i represents the sum of the first i weights. This allows for O(1) sum calculation for any range up to i.
3. **Total Sum**: The total sum of all weights is derived from the last element of the prefix sum array.
4. **Finding Minimum Difference**: For each possible split point T, compute the sum of the first group and use the total sum to find the sum of the second group. The absolute difference between these sums is calculated and the minimum value is tracked.

This approach ensures that we efficiently compute the required sums using prefix sums, leading to an optimal solution with a time complexity of O(N), which is efficient given the problem constraints.
