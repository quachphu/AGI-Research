To solve this problem, we need to determine if any three distinct drinks from a given list of drink quantities can sum up to a specified target quantity. The solution involves checking all possible combinations of three distinct drinks to see if their sum matches the target quantity.

### Approach
1. **Input Reading**: Read the number of drinks, their quantities, and the target sum from the standard input.
2. **Combination Generation**: Generate all possible combinations of three distinct drinks from the list of quantities.
3. **Sum Check**: For each combination of three drinks, check if their sum equals the target quantity. If any combination meets the target, print "True" and exit. If none do, print "False".

### Solution Code
```python
from itertools import combinations
import sys

def main():
    input = sys.stdin.read().splitlines()
    n = int(input[0])
    arr = list(map(int, input[1].split()))
    x = int(input[2])
    for combo in combinations(arr, 3):
        if sum(combo) == x:
            print("True")
            return
    print("False")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first line gives the number of drinks, the second line provides the quantities of these drinks as a space-separated string, and the third line is the target sum.
2. **Generating Combinations**: Using the `combinations` function from the `itertools` module, we generate all possible triplets of drink quantities. This function ensures that each combination consists of three distinct elements from the list, considering their positions (even if the values are the same).
3. **Checking Sums**: For each triplet generated, we check if their sum equals the target quantity. If a valid triplet is found, we immediately print "True" and exit. If no valid triplet is found after checking all combinations, we print "False".

This approach efficiently checks all possible triplets using a straightforward combinatorial method, ensuring correctness by considering each drink's quantity as a distinct element regardless of its value.
