To solve this problem, we need to determine the optimal combination of treasures that maximizes the total value without exceeding the weight capacity of the furoshiki. If there are multiple combinations with the same maximum value, we choose the one with the smallest total weight.

### Approach
1. **Dynamic Programming (DP) Setup**: We use a DP array where each entry `dp[j]` stores a tuple `(max_value, min_weight)`. Here, `max_value` is the maximum value achievable with a total weight less than or equal to `j`, and `min_weight` is the smallest weight required to achieve that value.
2. **Iterate Over Items**: For each item, update the DP array from the highest weight down to the item's weight to ensure each item is only considered once.
3. **Update DP Entries**: For each weight capacity, check if including the current item results in a higher value or the same value with a smaller weight, updating the DP entry accordingly.
4. **Determine Result**: After processing all items, iterate through the DP array to find the maximum value and the corresponding smallest weight.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().splitlines()
    idx = 0
    case_num = 1
    while True:
        if idx >= len(input):
            break
        line = input[idx].strip()
        while line == '':
            idx += 1
            line = input[idx].strip()
        W = int(line)
        idx += 1
        if W == 0:
            break
        line = input[idx].strip()
        while line == '':
            idx += 1
            line = input[idx].strip()
        N = int(line)
        idx += 1
        items = []
        for _ in range(N):
            while True:
                if idx >= len(input):
                    break
                line = input[idx].strip()
                idx += 1
                if line != '':
                    break
            v, w = map(int, line.split(','))
            items.append((v, w))
        # Initialize DP
        dp = [(0, 0) for _ in range(W + 1)]
        for v, w in items:
            for j in range(W, w - 1, -1):
                prev_j = j - w
                new_val = dp[prev_j][0] + v
                new_weight = dp[prev_j][1] + w
                current_val, current_weight = dp[j]
                if new_val > current_val:
                    dp[j] = (new_val, new_weight)
                elif new_val == current_val and new_weight < current_weight:
                    dp[j] = (new_val, new_weight)
        max_val = 0
        min_weight = 0
        for j in range(W + 1):
            current_val, current_weight = dp[j]
            if current_val > max_val:
                max_val = current_val
                min_weight = current_weight
            elif current_val == max_val and current_weight < min_weight:
                min_weight = current_weight
        print(f"Case {case_num}:")
        print(max_val)
        print(min_weight)
        case_num += 1

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read line by line, handling multiple datasets until a weight of 0 is encountered.
2. **Dynamic Programming Array Initialization**: The DP array is initialized with tuples representing zero value and weight for all capacities.
3. **Processing Each Item**: For each item, update the DP array from the highest possible weight down to the item's weight to avoid reprocessing items.
4. **Updating DP Entries**: For each weight capacity, check if including the current item improves the value or reduces the weight for the same value.
5. **Finding the Result**: After processing all items, the maximum value and the corresponding minimum weight are determined by iterating through the DP array.

This approach efficiently solves the 0-1 knapsack problem with the added constraint of minimizing weight when multiple solutions yield the same maximum value, ensuring optimal performance within the given constraints.
