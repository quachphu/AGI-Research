To solve this problem, we need to determine how many times each football team uses their home and away kits during a tournament where each team plays every other team twice (once at home and once away). The key challenge is to account for situations where the away team's kit color clashes with the home team's home kit color, forcing the away team to switch to their home kit.

### Approach
1. **Input Reading**: Read the number of teams and their respective home and away kit colors.
2. **Frequency Calculation**: Compute the frequency of each home kit color across all teams. This helps in quickly determining how many times a particular color is used as a home kit by other teams.
3. **Kit Usage Calculation**: For each team, calculate the number of times they use their home kit and away kit:
   - **Home Kit Usage**: The team uses their home kit in all their home games (n-1 games) plus the number of times their away kit color matches another team's home kit color.
   - **Away Kit Usage**: The team uses their away kit in all their away games minus the number of times they had to switch to their home kit due to color clashes.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n = int(sys.stdin.readline())
    teams = []
    x_freq = defaultdict(int)
    for _ in range(n):
        x, y = map(int, sys.stdin.readline().split())
        teams.append((x, y))
        x_freq[x] += 1
    for x, y in teams:
        count = x_freq.get(y, 0)
        home = (n - 1) + count
        away = (n - 1) - count
        print(home, away)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline` for efficiency, especially given the constraints.
2. **Frequency Dictionary**: A dictionary `x_freq` is used to count occurrences of each home kit color.
3. **Processing Each Team**: For each team, we check how many other teams have a home kit color matching the current team's away kit color. This count is obtained from the frequency dictionary.
4. **Calculating Kits**: 
   - **Home Kit Usage**: The team plays `n-1` home games plus the number of times their away kit color matches another team's home kit color.
   - **Away Kit Usage**: The team plays `n-1` away games minus the count of clashes (since those instances require switching to the home kit).

This approach ensures that we efficiently compute the required values in linear time, making it suitable for large input sizes up to 100,000 teams.
