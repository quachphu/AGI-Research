To solve this problem, we need to find the maximum value of the expression \( p \cdot a_i + q \cdot a_j + r \cdot a_k \) where \( 1 \leq i \leq j \leq k \leq n \). The solution must efficiently handle large input sizes up to \( 10^5 \) elements.

### Approach
1. **Precompute Maximum Values**:
   - **Left Maximum Array (max_p_left)**: This array stores the maximum value of \( p \cdot a_i \) for all indices from 0 up to each position \( j \). This helps in efficiently determining the best \( i \) for any given \( j \).
   - **Right Maximum Array (max_r_right)**: This array stores the maximum value of \( r \cdot a_k \) for all indices from each position \( j \) to the end of the array. This helps in efficiently determining the best \( k \) for any given \( j \).

2. **Calculate Maximum Sum**:
   - For each position \( j \), compute the sum of the corresponding values from the left maximum array, the current value scaled by \( q \), and the right maximum array. Track the maximum sum encountered.

### Solution Code
```python
n, p, q, r = map(int, input().split())
a = list(map(int, input().split()))

if n == 0:
    print(0)
    exit()

max_p_left = [0] * n
max_p_left[0] = p * a[0]
for j in range(1, n):
    max_p_left[j] = max(max_p_left[j-1], p * a[j])

max_r_right = [0] * n
max_r_right[-1] = r * a[-1]
for j in range(n-2, -1, -1):
    max_r_right[j] = max(r * a[j], max_r_right[j+1])

max_sum = -float('inf')
for j in range(n):
    current = max_p_left[j] + q * a[j] + max_r_right[j]
    if current > max_sum:
        max_sum = current

print(max_sum)
```

### Explanation
1. **Input Handling**: Read the input values and the array.
2. **Edge Case Handling**: If the array is empty, immediately output 0 (though constraints ensure \( n \geq 1 \)).
3. **Left Maximum Array**: Constructed by iterating from the start to the end, maintaining the maximum value of \( p \cdot a_i \) up to each index.
4. **Right Maximum Array**: Constructed by iterating from the end to the start, maintaining the maximum value of \( r \cdot a_k \) from each index to the end.
5. **Compute Maximum Sum**: For each index \( j \), compute the sum using the precomputed arrays and track the maximum sum encountered.

This approach ensures that we efficiently compute the required values in linear time, making the solution suitable for large input sizes.
