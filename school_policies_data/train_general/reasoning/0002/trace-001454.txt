To solve this problem, we need to abbreviate words that are longer than 10 characters by using a specific format: the first letter, followed by the number of characters between the first and last letters, and then the last letter. Words that are 10 characters or shorter should remain unchanged.

### Approach
1. **Input Reading**: First, read the integer `n` which indicates the number of words to process.
2. **Processing Each Word**: For each word, check its length:
   - If the length is greater than 10, convert it to the abbreviation format.
   - If the length is 10 or less, keep the word as it is.
3. **Abbreviation Formation**: For words longer than 10 characters, form the abbreviation by concatenating the first character, the length of the word minus 2 (to exclude the first and last characters), and the last character.

### Solution Code
```python
def abbreviate_long_words():
    n = int(input())
    for _ in range(n):
        word = input().strip()
        if len(word) > 10:
            print(f"{word[0]}{len(word)-2}{word[-1]}")
        else:
            print(word)

abbreviate_long_words()
```

### Explanation
1. **Reading Input**: The function starts by reading the number of words `n`.
2. **Loop Through Words**: For each word, it checks the length.
3. **Abbreviation Check**: If the word length exceeds 10, it constructs the abbreviation using the first character, the length of the word minus 2 (to account for the first and last characters), and the last character.
4. **Output**: The result for each word is printed immediately, ensuring efficient handling of input and output without storing all words in memory.

This approach ensures that each word is processed in constant time, making the solution efficient with a time complexity of O(n), where n is the number of words. The space complexity is O(1) since we process each word individually without additional storage.
