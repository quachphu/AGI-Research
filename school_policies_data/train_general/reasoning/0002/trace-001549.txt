### Approach
1. **Input Handling**: Read the number of test cases, T. For each test case, read the size of the array, N, followed by the array elements.
2. **Sorting**: Use Python's built-in sort function with the `reverse=True` parameter to sort each array in non-increasing order.
3. **Output**: Print each sorted array as a space-separated string.

### Solution Code
```python
import sys

def sort_arrays():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline().strip())
        arr = list(map(int, sys.stdin.readline().strip().split()))
        arr.sort(reverse=True)
        print(' '.join(map(str, arr)))

sort_arrays()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency, especially with large inputs. This method is faster than the standard `input()` function for handling large data.
2. **Sorting**: The arrays are sorted in-place using Python's efficient Timsort algorithm, which has an average time complexity of O(N log N). By setting `reverse=True`, the array is sorted in non-increasing order.
3. **Output Formatting**: The sorted array is converted to a space-separated string using `join` for efficient output formatting, which is faster than using `print(*arr)` for large arrays.

This approach ensures that each array is processed efficiently, even up to the maximum constraints, making it suitable for competitive programming environments.
