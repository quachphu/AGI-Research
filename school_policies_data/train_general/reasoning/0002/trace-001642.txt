To solve this problem, we need to determine the number of crosses John will draw on the perimeter of a square with side length `n` meters before he returns to the lower left corner for the second time. 

### Approach
1. **Understanding Movement**: John starts at the lower left corner and moves clockwise along the perimeter, drawing a cross every `(n+1)` meters. The perimeter of the square is `4n` meters.
2. **Key Insight**: The problem reduces to finding the minimal number of steps `m` such that John returns to the starting point (0 meters) after `m` steps. Each step covers `(n+1)` meters.
3. **Mathematical Formulation**: We need to find the smallest `m` such that `m*(n+1) % 4n == 0`. This can be simplified using the greatest common divisor (GCD) of `n+1` and 4, leading to the formula:
   \[
   m = \frac{4n}{\text{GCD}(n+1, 4)}
   \]
   The total number of crosses is then `m + 1`.

### Solution Code
```python
import math

def main():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    ns = list(map(int, input[1:t+1]))
    for n in ns:
        d = math.gcd(n + 1, 4)
        ans = (4 * n // d) + 1
        print(ans)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of multiple test cases. The first value is the number of test cases `t`, followed by `t` integers representing the side lengths of the squares.
2. **Computing GCD**: For each side length `n`, compute the GCD of `n+1` and 4. This helps in determining the minimal steps needed to return to the starting point.
3. **Calculating Result**: Using the formula derived, compute the result for each test case and print it.

This approach efficiently handles large values of `n` (up to \(10^9\)) by leveraging mathematical properties, ensuring the solution is both optimal and scalable.
