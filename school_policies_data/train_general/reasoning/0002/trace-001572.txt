To solve this problem, we need to decrypt a message that was encrypted using a columnar transposition method with alternating row directions. The encrypted message is read row by row, alternating between left-to-right and right-to-left. Our task is to reverse this process and retrieve the original message.

### Approach
1. **Input Reading**: Read the number of test cases. For each test case, read the number of columns and the encrypted string.
2. **Row Splitting**: Split the encrypted string into rows of length equal to the number of columns.
3. **Row Reversal**: Reverse the rows that were read in right-to-left direction during encryption. Specifically, reverse every alternate row starting from the second row (index 1, 3, 5, etc.).
4. **Column-wise Reading**: Reconstruct the original message by reading the characters column-wise from the processed rows.

### Solution Code
```python
def decrypt_message():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        c = int(input[idx])
        idx += 1
        s = input[idx]
        idx += 1
        r = len(s) // c
        rows = [s[i*c:(i+1)*c] for i in range(r)]
        processed = []
        for i in range(r):
            row = rows[i]
            if i % 2 == 1:
                row = row[::-1]
            processed.append(row)
        res = []
        for col in range(c):
            for row in processed:
                res.append(row[col])
        print(''.join(res))
        
decrypt_message()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings for easier processing.
2. **Row Splitting**: The encrypted string is divided into rows where each row's length is equal to the number of columns specified.
3. **Row Reversal**: Each row at an odd index is reversed to undo the encryption process where alternate rows were reversed.
4. **Column-wise Reconstruction**: The original message is reconstructed by reading characters column by column from top to bottom for each column from left to right.

This approach efficiently reverses the encryption process and retrieves the original message by systematically handling row reversal and column-wise reading.
