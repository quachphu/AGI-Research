To solve this problem, we need to sort a list of batsmen based on their country codes and their runs in a specific order. The country codes should be sorted in ascending order, and within each country, the runs should be sorted in descending order. This approach ensures that the data is organized as per the mutual agreement between Virat and Maxwell.

### Approach
1. **Input Reading**: Efficiently read the input data using `sys.stdin` to handle large input sizes.
2. **Grouping by Country**: Use a dictionary to group batsmen by their country codes. This helps in efficiently collecting all runs associated with each country.
3. **Sorting Runs**: For each country, sort the collected runs in descending order.
4. **Sorting Countries**: Sort the country codes in ascending order to meet the requirement of ascending country code order.
5. **Output**: Print the sorted results by iterating through the sorted country codes and their corresponding sorted runs.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n = int(sys.stdin.readline())
    country_data = defaultdict(list)
    for _ in range(n):
        c, r = map(int, sys.stdin.readline().split())
        country_data[c].append(r)
    
    for c in sorted(country_data.keys()):
        runs = sorted(country_data[c], reverse=True)
        for r in runs:
            sys.stdout.write(f"{c} {r}\n")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency, especially with large input sizes. This ensures that reading the input is handled quickly even for the upper constraint of 1,000,006 entries.
2. **Grouping by Country**: A `defaultdict` from the `collections` module is used to group the runs by their respective country codes. This allows efficient aggregation of runs under each country.
3. **Sorting Runs**: For each country, the runs are sorted in descending order using Python's built-in `sorted` function with `reverse=True`.
4. **Sorting Countries**: The country codes are sorted in ascending order using the `sorted` function on the dictionary keys.
5. **Output**: The sorted results are printed using `sys.stdout.write` for efficient output handling, ensuring that even large outputs are processed quickly.

This approach ensures that the solution is both efficient and easy to understand, adhering to the problem constraints and requirements.
