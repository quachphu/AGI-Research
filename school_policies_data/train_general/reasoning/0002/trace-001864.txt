To solve this problem, we need to determine the country with the most votes based on the chefs' votes and the chef who received the most votes. If there are ties, we select the lexicographically smaller name.

### Approach
1. **Input Reading**: Read the number of chefs and emails. Then, read each chef's name and their respective country into a dictionary.
2. **Vote Counting**: Use two dictionaries to track votes for each chef and their respective countries.
3. **Determine Winners**:
   - **Chef of the Year**: Find the chef with the highest votes. In case of a tie, select the lexicographically smaller name.
   - **Winning Country**: Find the country with the highest votes. In case of a tie, select the lexicographically smaller country name.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n, m = map(int, sys.stdin.readline().split())

    chef_to_country = {}
    country_votes = defaultdict(int)
    chef_votes = defaultdict(int)

    for _ in range(n):
        name, country = sys.stdin.readline().split()
        chef_to_country[name] = country

    for _ in range(m):
        chef = sys.stdin.readline().strip()
        chef_votes[chef] += 1
        country = chef_to_country[chef]
        country_votes[country] += 1

    # Find best country
    max_country_count = max(country_votes.values()) if country_votes else 0
    best_countries = [country for country, count in country_votes.items() if count == max_country_count]
    best_country = min(best_countries) if best_countries else ''

    # Find best chef
    max_chef_count = max(chef_votes.values()) if chef_votes else 0
    best_chefs = [chef for chef, count in chef_votes.items() if count == max_chef_count]
    best_chef = min(best_chefs) if best_chefs else ''

    print(best_country)
    print(best_chef)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The first line contains the number of chefs and emails. Subsequent lines list each chef and their country. The following lines list the votes for each chef.
2. **Mapping Chefs to Countries**: A dictionary maps each chef's name to their country.
3. **Counting Votes**: Two dictionaries track the number of votes each chef and their country receive.
4. **Finding the Winners**:
   - **Chef of the Year**: The chef with the highest votes is determined. If there's a tie, the lexicographically smaller name is chosen.
   - **Winning Country**: The country with the highest votes is determined. If there's a tie, the lexicographically smaller country name is chosen.

This approach efficiently handles up to the maximum constraints using dictionaries for quick lookups and updates, ensuring the solution is both optimal and easy to understand.
