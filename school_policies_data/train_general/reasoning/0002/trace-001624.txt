    if len(cw) != len(pw):

        return None

    mapping = {}

    for c, p in zip(cw, pw):

        if c in mapping:

            if mapping[c] != p:

                return None

        else:

            if p in mapping:

                if mapping[p] != c:

                    return None

            else:

                mapping[c] = p

                mapping[p] = c

    return mapping

The substitution rule consists of pairs of letters that can be swapped, and each letter can appear in at most one pair. The goal is to determine the original plaintext from the ciphertext, given a list of candidate words. If there are multiple valid plaintexts, we should output a hyphen followed by a period.

### Approach
1. **Input Parsing**: Read the input dataset, which includes the number of candidate words, the candidate words themselves, and the ciphertext sequence.
2. **Generate Possible Candidates**: For each word in the ciphertext sequence, collect all candidate words of the same length.
3. **Backtracking to Find Valid Substitutions**: Use a backtracking approach to generate all valid substitution rules that can map the ciphertext words to the candidate words. This involves checking each possible candidate for each ciphertext word and ensuring the substitution rules are consistent across all words.
4. **Generate Plaintexts**: For each valid substitution rule, generate the corresponding plaintext by applying the substitution to each word in the ciphertext sequence.
5. **Check Uniqueness**: If all generated plaintexts are the same, output the plaintext. Otherwise, output a hyphen followed by a period.

def generate_mappings(cw, pw):
    if len(cw) != len(pw):
        return None
    mapping = {}
    for c, p in zip(cw, pw):
        if c in mapping:
            if mapping[c] != p:
                return None
        else:
            if p in mapping:
                if mapping[p] != c:
                    return None
            else:
                mapping[c] = p
                mapping[p] = c
    return mapping

def apply_substitution(word, substitution):
    return ''.join([substitution.get(c, c) for c in word])

def main():
