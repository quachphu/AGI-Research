To solve this problem, we need to determine the optimal apple to remove such that the sum of the remaining apples' flavors is as close as possible to the original sum when using all apples. The solution involves calculating the sum of all apple flavors and identifying the apple with the flavor closest to zero (smallest absolute value), as removing this apple will minimize the difference from the original sum.

### Approach
1. **Calculate the Original Sum**: Compute the sum of all apple flavors. The flavor of each apple is given by the sequence starting from `L` and incrementing by 1 for each subsequent apple.
2. **Identify the Optimal Apple to Remove**: Determine which apple has the flavor closest to zero. This is done by iterating through each apple's flavor and tracking the minimum absolute value.
3. **Compute the Result**: Subtract the flavor of the identified apple from the original sum to get the new sum, which is the desired output.

### Solution Code
```python
n, l = map(int, input().split())

flavors = [l + i - 1 for i in range(1, n + 1)]
total_sum = sum(flavors)

min_abs = float('inf')
selected_flavor = 0

for flavor in flavors:
    current_abs = abs(flavor)
    if current_abs < min_abs:
        min_abs = current_abs
        selected_flavor = flavor

print(total_sum - selected_flavor)
```

### Explanation
1. **Input Reading**: The input values `N` (number of apples) and `L` (starting flavor) are read.
2. **Flavor Calculation**: Each apple's flavor is computed using the formula `L + i - 1` where `i` ranges from 1 to `N`.
3. **Sum Calculation**: The sum of all apple flavors is computed directly by iterating through the list of flavors.
4. **Optimal Apple Selection**: The apple with the flavor closest to zero is identified by comparing the absolute values of each flavor.
5. **Result Calculation**: The flavor of the optimal apple is subtracted from the original sum to get the result, which is then printed.

This approach ensures that we efficiently determine the optimal apple to remove, leading to the smallest possible change in the sum of flavors, thus solving the problem in linear time complexity, O(N), which is optimal for the given constraints.
