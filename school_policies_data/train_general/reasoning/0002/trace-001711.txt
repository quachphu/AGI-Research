1. **Dynamic Programming (DP) Setup**: Use a 4-dimensional DP array `dp[i][j][d][k]` where:
   - `i` and `j` are the current coordinates.
   - `d` represents the direction (0 for east, 1 for north) from which the current intersection was reached.
   - `k` indicates whether the next move must be straight (1) or if a turn is allowed (0).

3. **Transitions**:
   - **East Transition**: For each cell (i, j) that can be reached from (i-1, j), update the DP values based on whether the move is straight or a turn.
   - **North Transition**: Similarly, update the DP values for cells reachable from (i, j-1).

4. **Result Calculation**: Sum the values from all possible states at the destination (w, h) and return the result modulo 100000.

### Solution Code
```python
import sys

MOD = 100000

def compute(w, h):
    if w == 0 and h == 0:
        return 0
    # Initialize DP table: dp[i][j][d][k]
    dp = [[[[0] * 2 for _ in range(2)] for __ in range(h + 1)] for ___ in range(w + 1)]
    
    # Base cases
    if w >= 2:
        dp[2][1][0][0] = 1
    if h >= 2:
        dp[1][2][1][0] = 1
    
    for i in range(1, w + 1):
        for j in range(1, h + 1):
            if i == 1 and j == 1:
                continue  # Skip the starting point
            
            # Process east transitions (from i-1, j)
            if i > 1:
                for d_prev in [0, 1]:
                    for k_prev in [0, 1]:
                        current = dp[i-1][j][d_prev][k_prev]
                        if current == 0:
                            continue
                        if d_prev == 0:
                            # Straight move east
                            new_d, new_k = 0, 0
                            dp[i][j][new_d][new_k] = (dp[i][j][new_d][new_k] + current) % MOD
                        else:
                            # Turn east from north direction if allowed
                            if k_prev == 0:
                                new_d, new_k = 0, 1
                                dp[i][j][new_d][new_k] = (dp[i][j][new_d][new_k] + current) % MOD
            
            # Process north transitions (from i, j-1)
            if j > 1:
                for d_prev in [0, 1]:
                    for k_prev in [0, 1]:
                        current = dp[i][j-1][d_prev][k_prev]
                        if current == 0:
                            continue
                        if d_prev == 1:
                            # Straight move north
                            new_d, new_k = 1, 0
                            dp[i][j][new_d][new_k] = (dp[i][j][new_d][new_k] + current) % MOD
                        else:
                            # Turn north from east direction if allowed
                            if k_prev == 0:
                                new_d, new_k = 1, 1
                                dp[i][j][new_d][new_k] = (dp[i][j][new_d][new_k] + current) % MOD
    
    total = 0
    for d in [0, 1]:
        for k in [0, 1]:
            total = (total + dp[w][h][d][k]) % MOD
    return total

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        w, h = map(int, line.split())
        if w == 0 and h == 0:
            break
        res = compute(w, h)
        print(res % MOD)

if __name__ == '__main__':
    main()
```

### Explanation
- **Dynamic Programming Table**: The 4-dimensional DP array `dp[i][j][d][k]` keeps track of the number of ways to reach each intersection (i, j) considering the direction of arrival and whether a turn is allowed next.
- **Base Cases**: Initialize the first possible moves from (1, 1) to (2, 1) and (1, 2).
- **Transitions**: For each cell, update the DP values based on transitions from the previous cells, considering both straight moves and turns where allowed.
- **Result Calculation**: Sum all possible ways to reach the destination (w, h) and return the result modulo 100000.

This approach efficiently computes the number of valid routes using dynamic programming, ensuring adherence to the traffic rules and constraints.
