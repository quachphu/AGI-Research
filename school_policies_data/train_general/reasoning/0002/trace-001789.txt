To solve this problem, we need to track the number of ice cream packs Kay and Gerda have and determine how many children leave distressed because they couldn't get the ice cream they wanted. The solution involves processing each person in the queue sequentially, updating the ice cream count accordingly, and counting the number of distressed children.

### Approach
1. **Initialization**: Read the initial number of people in the queue and the starting number of ice cream packs.
2. **Processing Each Person**: For each person in the queue:
   - If the person is a carrier, add the ice cream packs they bring to the current stock.
   - If the person is a child wanting ice cream, check if there are enough packs. If there are, subtract the requested amount. If not, increment the count of distressed children.
3. **Output**: After processing all people in the queue, print the remaining ice cream packs and the number of distressed children.

### Solution Code
```python
import sys

def main():
    n, x = map(int, sys.stdin.readline().split())
    current = x
    distressed = 0
    for _ in range(n):
        op, di = sys.stdin.readline().split()
        di = int(di)
        if op == '+':
            current += di
        else:
            if current >= di:
                current -= di
            else:
                distressed += 1
    print(current, distressed)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The first line of input is read to get the number of people `n` and the initial ice cream packs `x`.
2. **Loop Through Queue**: For each of the next `n` lines, we determine if the person is a carrier or a child. Carriers increase the ice cream count, while children decrease it if possible or are counted as distressed if not.
3. **Updating Counts**: The ice cream count is updated in real-time, and the number of distressed children is tracked separately.
4. **Output Results**: Finally, the remaining ice cream packs and the number of distressed children are printed.

This approach ensures that each operation is handled in constant time, leading to an efficient solution with a time complexity of O(n), which is optimal given the constraints.
