To solve this problem, we need to calculate the area of a farm excluding two intersecting roads (one vertical and one horizontal) that each span the entire length and width of the farm respectively. 

### Approach
1. **Understand the Problem**: The farm is a rectangle with dimensions A (length) and B (width). The roads are 1 yard wide and span the entire length and width of the farm. The vertical road covers the entire width (B yards) and the horizontal road covers the entire length (A yards). The overlapping area where the roads intersect is counted twice, so we need to subtract this overlap once.
2. **Formulate the Solution**: The total area of the roads is the sum of the areas of the vertical and horizontal roads minus the overlapping area. This can be simplified to (A + B - 1). The remaining area of the farm excluding the roads is then calculated as the total area of the farm minus the area of the roads. This simplifies to (A-1) * (B-1).
3. **Algorithm**: Read the input values for A and B, compute the result using the formula (A-1)*(B-1), and print the result.

### Solution Code
```python
def main():
    import sys
    a, b = map(int, sys.stdin.readline().split())
    print((a - 1) * (b - 1))

main()
```

### Explanation
1. **Reading Input**: The input values A and B are read from standard input.
2. **Calculation**: Using the formula (A-1)*(B-1), we compute the area of the farm excluding the roads. This formula accounts for the 1-yard width of each road and their intersection.
3. **Output**: The result is printed as the final output.

This approach efficiently computes the desired area in constant time O(1), making it very efficient even for the upper limits of the input constraints.
