To solve this problem, we need to determine the minimum number of seconds required to water all garden beds using the given water taps. Each tap, when turned on, waters an expanding segment of the garden over time. The goal is to find the earliest time when all beds are covered by the union of all taps' coverage areas.

### Approach
1. **Understanding Tap Coverage**: Each tap at position `xi` will water an expanding segment of the garden. After `j` seconds, the segment covered is `[xi - (j - 1), xi + (j - 1)]`.
2. **Coverage Calculation**: For each garden bed position `p` from 1 to `n`, determine the minimum time required for it to be covered by any tap. This time is derived from the closest tap to `p`.
3. **Max Time Calculation**: The overall minimum time required to water the entire garden is the maximum of the minimum times calculated for each garden bed.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    taps = list(map(int, input().split()))
    max_time = 0
    for p in range(1, n + 1):
        min_dist = min(abs(p - x) for x in taps)
        current_time = min_dist + 1
        if current_time > max_time:
            max_time = current_time
    print(max_time)
```

### Explanation
1. **Input Reading**: Read the number of test cases. For each test case, read the number of garden beds `n` and the number of taps `k`, followed by the positions of the taps.
2. **Iterate Over Each Bed**: For each garden bed position `p`, calculate the minimum distance to any tap. This distance determines the earliest time `p` will be watered by the closest tap.
3. **Determine Maximum Time**: The maximum value of these minimum times across all positions gives the earliest time when the entire garden is watered.

This approach efficiently computes the required time by leveraging the closest tap distance for each position, ensuring an optimal solution with a time complexity of O(n*k) per test case, which is feasible given the problem constraints.
