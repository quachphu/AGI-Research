To solve this problem, we need to perform a series of operations on a string where each operation replaces specific characters within a given range. The goal is to determine the final state of the string after all operations have been applied.

### Approach
1. **Input Reading**: Read the initial values for the string length and the number of operations. Then read the initial string and convert it into a list for easier manipulation since strings in Python are immutable.
2. **Processing Operations**: For each operation, read the parameters which define the range and the characters to be replaced. Adjust the range from 1-based indexing (as given in the problem) to 0-based indexing (used in Python lists).
3. **Character Replacement**: Iterate over the specified range in the string and replace each occurrence of the target character with the new character.
4. **Output the Result**: After processing all operations, convert the list back to a string and print the result.

### Solution Code
```python
def main():
    n, m = map(int, input().split())
    s = list(input().strip())
    for _ in range(m):
        l, r, c1, c2 = input().split()
        l = int(l)
        r = int(r)
        start = l - 1
        end = r - 1
        for i in range(start, end + 1):
            if s[i] == c1:
                s[i] = c2
    print(''.join(s))

main()
```

### Explanation
1. **Reading Input**: The first line of input contains the length of the string and the number of operations. The second line is the initial string. Each subsequent line describes an operation with parameters specifying the range and characters to replace.
2. **String Conversion**: Convert the string to a list to allow in-place modifications.
3. **Adjusting Indices**: Convert the given 1-based indices to 0-based indices for Python list operations.
4. **Applying Operations**: For each operation, iterate over the specified range and replace the target character with the new character if it matches.
5. **Output**: After all operations are applied, the modified list is converted back to a string and printed.

This approach efficiently handles the constraints and ensures that each operation is applied correctly, resulting in the desired final string.
