To solve this problem, we need to determine the K-th digit in the string S(n) generated by Lala's recursive formula up to n = 10^100. The string is built using the formula S(n) = S(n-1) + "0" + switch(reverse(S(n-1))), where "switch" inverts each bit (0 becomes 1 and vice versa) and "reverse" reverses the string. Given the constraints, directly generating the string is infeasible, so we use a recursive approach to determine the K-th digit efficiently.

### Approach
1. **Recursive Structure**: The string S(n) is constructed by appending "0" and the switched reverse of S(n-1) to S(n-1). This structure allows us to decompose the problem into smaller subproblems.
2. **Binary Decomposition**: For a given K, we determine which part of the string (first part, middle "0", or second part) K lies in. This is done by iteratively checking the length of the string at each level until we find the correct segment.
3. **Flip Handling**: When K is in the second part (switched reverse part), we adjust the position and toggle a flip flag to account for the inversion of bits.
