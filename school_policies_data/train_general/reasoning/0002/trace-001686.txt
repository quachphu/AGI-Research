2. **Existing Infection Check**: If any account already has the same rating as Killjoy's account, all other accounts can be infected in one contest (1 contest).
3. **Sum Check**: If none of the accounts initially have the same rating as Killjoy's, check if the sum of all account ratings equals `n * x` (where `n` is the number of accounts and `x` is Killjoy's rating). If true, all accounts can be set to `x` in one contest (1 contest).
4. **Default Case**: If none of the above conditions are met, it will take at least two contests to infect all accounts (2 contests).

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, x = map(int, input().split())
    a = list(map(int, input().split()))
    all_x = True
    any_x = False
    sum_a = 0
    for num in a:
        if num != x:
            all_x = False
        else:
            any_x = True
        sum_a += num
    if all_x:
        print(0)
    elif any_x:
        print(1)
    else:
        if sum_a == n * x:
            print(1)
        else:
            print(2)
```

### Explanation
- **Immediate Infection Check**: If every account's rating is already `x`, no contests are needed.
- **Existing Infection Check**: If any account is already infected (rating `x`), we can adjust the remaining accounts in one contest by leveraging the sum of changes to zero.
- **Sum Check**: If the sum of all account ratings equals `n * x`, we can adjust all accounts to `x` in one contest.
- **Default Case**: If none of the above conditions are met, it will take two contests to adjust the ratings such that all accounts become infected, using intermediate steps to balance the sum of changes.

This approach efficiently covers all possible scenarios with minimal checks, ensuring optimal performance even for the upper constraint limits.
