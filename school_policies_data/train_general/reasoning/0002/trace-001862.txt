To solve this problem, we need to count the totatives of a given integer \( n \), which are the positive integers less than or equal to \( n \) that are relatively prime to \( n \). This can be efficiently computed using Euler's Totient function, \( \phi(n) \), which is based on the prime factorization of \( n \).

### Approach
1. **Prime Factorization**: The key insight is that the value of Euler's Totient function can be derived from the distinct prime factors of \( n \). The formula for \( \phi(n) \) is:
   \[
   \phi(n) = n \times \left(1 - \frac{1}{p_1}\right) \times \left(1 - \frac{1}{p_2}\right) \times \ldots \times \left(1 - \frac{1}{p_k}\right)
   \]
   where \( p_1, p_2, \ldots, p_k \) are the distinct prime factors of \( n \).

2. **Efficient Calculation**: We use trial division to factorize \( n \). For each prime factor found, we adjust the result by multiplying it by \( (1 - 1/p) \). This is done by iterating through possible divisors up to the square root of \( n \) and adjusting the result as we find each prime factor.

3. **Edge Cases**: Handle the case where \( n \) is 1 separately, as its only totative is itself.

### Solution Code
```python
def euler_totient(n):
    if n == 1:
        return 1
    result = n
    i = 2
    while i * i <= n:
        if n % i == 0:
            result -= result // i
            while n % i == 0:
                n //= i
        i += 1
    if n > 1:
        result -= result // n
    return result

n = int(input())
print(euler_totient(n))
```

### Explanation
1. **Initialization**: Start with the result initialized to \( n \).
2. **Prime Factorization Loop**: Iterate through potential divisors starting from 2 up to the square root of \( n \). For each divisor \( i \):
   - If \( i \) is a divisor of \( n \), adjust the result by multiplying it by \( (1 - 1/i) \).
   - Remove all occurrences of \( i \) from \( n \) to ensure we only process each prime factor once.
3. **Remaining Prime Factor**: After the loop, if \( n \) is greater than 1, it means \( n \) itself is a prime number. Adjust the result accordingly.
4. **Edge Case Handling**: Directly return 1 if \( n \) is 1, as 1 is coprime with itself.

This approach efficiently computes the number of totatives using trial division for prime factorization, which is sufficient for the given problem constraints.
