To solve this problem, we need to determine the winning team from a list of goals scored during a football match. The input consists of a number of goals followed by the names of the teams that scored each goal. The solution requires counting the goals for each team and identifying the team with the highest count.

### Approach
1. **Read Input**: First, read the number of goals, `n`.
2. **Count Goals**: Use a dictionary to keep track of the number of goals scored by each team. For each goal entry, update the count in the dictionary.
3. **Determine Winner**: Find the team with the maximum goals using the dictionary counts. Since the problem guarantees no tie, there will always be a clear winner.

### Solution Code
```python
def main():
    n = int(input())
    counts = {}
    for _ in range(n):
        team = input().strip()
        counts[team] = counts.get(team, 0) + 1
    winner = max(counts, key=lambda k: counts[k])
    print(winner)

main()
```

### Explanation
1. **Reading Input**: The first input line is converted to an integer `n`, representing the number of goals. The subsequent lines are read and processed one by one.
2. **Counting Goals**: A dictionary `counts` is used where keys are team names and values are the counts of goals. For each team name read, the dictionary is updated to increment the count for that team.
3. **Finding the Winner**: The `max` function is used with a custom key to find the team with the highest goal count. The key function uses the dictionary values (goal counts) to determine the maximum, ensuring the correct team is selected as the winner.

This approach efficiently counts the goals and determines the winner in linear time relative to the number of goals, making it optimal for the given constraints.
