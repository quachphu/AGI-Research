### Approach
1. **Understand the Problem Requirements**: Each tube must be centrifuged twice, and each cycle can hold up to M tubes. The goal is to find the minimum time required to complete all centrifugations.
2. **Key Insight**: Each tube needs two cycles, so the total number of "slots" required is 2*N. Each cycle can provide up to M slots. The minimum number of cycles (K) required is the ceiling of (2*N)/M. However, since each tube must be in two distinct cycles, if N is at least 1, the minimum number of cycles must be at least 2.
3. **Formula**: The formula to compute the minimum number of cycles is derived using ceiling division and ensuring the result is at least 2 if there are any tubes to process.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        M = int(input[idx])
        N = int(input[idx + 1])
        idx += 2
        if N == 0:
            print(0)
            continue
        required = (2 * N + M - 1) // M
        required = max(required, 2)
        print(required * 5)

main()
```
