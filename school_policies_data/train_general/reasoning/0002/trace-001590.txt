To solve this problem, we need to manage a set of intervals and determine if there's a path between two intervals based on specific movement rules. The solution involves maintaining a directed graph where nodes represent intervals and edges represent possible moves between intervals. Each query is processed to either add a new interval or check connectivity between two intervals.

### Approach
1. **Data Structures**: Use a list to store intervals and an adjacency list to represent the directed graph where edges indicate possible moves between intervals.
2. **Adding Intervals**: For each new interval added, check against all existing intervals to determine if there are edges in either direction (from existing to new and from new to existing) based on the movement rules.
3. **Connectivity Check**: For each connectivity query, use Breadth-First Search (BFS) to determine if there's a path from the start interval to the target interval in the directed graph.

### Solution Code
```python
import sys
from collections import deque

def main():
    n = int(sys.stdin.readline())
    intervals = []
    adj = []
    
    for _ in range(n):
        parts = sys.stdin.readline().split()
        if parts[0] == '1':
            x, y = int(parts[1]), int(parts[2])
            intervals.append((x, y))
            i = len(intervals) - 1
            adj.append([])
            for j in range(i):
                c, d = intervals[j]
                if (x < c < y) or (x < d < y):
                    adj[j].append(i)
                if (c < x < d) or (c < y < d):
                    adj[i].append(j)
        else:
            a, b = int(parts[1]), int(parts[2])
            start = a - 1
            end = b - 1
            if start == end:
                print("YES")
                continue
            visited = set()
            queue = deque([start])
            found = False
            while queue:
                node = queue.popleft()
                if node == end:
                    found = True
                    break
                if node in visited:
                    continue
                visited.add(node)
                for neighbor in adj[node]:
                    if neighbor not in visited:
                        queue.append(neighbor)
            print("YES" if found else "NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read line by line. Each line is split into parts to determine the query type.
2. **Handling Type 1 Queries**: When adding a new interval, check all existing intervals to see if there are edges in both directions based on the movement rules. Update the adjacency list accordingly.
3. **Handling Type 2 Queries**: For connectivity checks, use BFS starting from the specified interval to see if the target interval is reachable. BFS efficiently explores all reachable nodes from the start node, marking visited nodes to avoid cycles.

This approach ensures that each interval addition correctly updates the graph, and each connectivity check efficiently determines the path existence using BFS, which is suitable given the problem constraints.
