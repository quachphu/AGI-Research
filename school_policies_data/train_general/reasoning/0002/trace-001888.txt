To solve this problem, we need to determine which points in a 5-dimensional space are considered "good." A point is good if there are no two other distinct points such that the angle between the vectors formed by these points is acute. The angle is acute if the dot product of the vectors is positive.

### Approach
1. **Understanding the Problem**: A point is bad if there exist two other points such that the dot product of the vectors from the point to these two other points is positive. This is because a positive dot product indicates an acute angle.
2. **Key Insight**: In 5-dimensional space, if there are 11 or more points, any point will automatically be bad due to the pigeonhole principle, which states that in 5D space, more than 10 vectors will necessarily have at least two with a positive dot product.
3. **Efficient Check**: For each point, if there are fewer than 11 points, check all pairs of vectors formed by the other points relative to the current point. If any pair has a positive dot product, the point is bad; otherwise, it is good.

### Solution Code
```python
n = int(input())
points = [list(map(int, input().split())) for _ in range(n)]

good_points = []

for idx in range(n):
    a = points[idx]
    m = n - 1  # number of other points
    
    if m < 2:
        # If there are less than 2 other points, no pairs to form an angle.
        good_points.append(idx + 1)
    elif m >= 11:
        # According to the theorem, in 5D space, any 11 vectors must have at least two with positive dot product.
        continue
    else:
        # Collect all vectors (b - a) where b != a
        vectors = []
        for j in range(n):
            if j == idx:
                continue
            b = points[j]
            vector = [b[0] - a[0], b[1] - a[1], b[2] - a[2], b[3] - a[3], b[4] - a[4]]
            vectors.append(vector)
        
        # Check all pairs of vectors
        is_good = True
        for i in range(len(vectors)):
            for j in range(i + 1, len(vectors)):
                dot_product = sum(vectors[i][k] * vectors[j][k] for k in range(5))
                if dot_product > 0:
                    is_good = False
                    break
            if not is_good:
                break
        
        if is_good:
            good_points.append(idx + 1)

print(len(good_points))
for point in sorted(good_points):
    print(point)
```

1. **Reading Input**: The input is read and stored in a list of points.
2. **Checking Each Point**: For each point, we check if it is good by evaluating the vectors formed with all other points.
3. **Handling Cases with Few Points**: If there are fewer than 2 other points, the point is automatically good since no pairs can form an angle.
4. **Handling Cases with Many Points**: If there are 11 or more other points, the point is automatically bad due to the pigeonhole principle.
5. **Checking Pairs**: For points with 2 to 10 other points, we check all pairs of vectors to see if any have a positive dot product, indicating an acute angle.
