To solve this problem, we need to determine the number of unique employees in the first group specified in each dataset, considering nested group memberships. The goal is to expand all nested groups recursively and count the unique employees.

### Approach
1. **Input Parsing**: Read the input datasets, each starting with an integer `n` indicating the number of groups. For each group, parse the group name and its members.
2. **Recursive Expansion with Memoization**: For the first group in each dataset, recursively expand its members. If a member is a group, expand it further until all members are employees. Use memoization to avoid redundant computations and improve efficiency.
3. **Set Operations**: Use a set to collect all unique employee names during the expansion process. The size of this set gives the required count of unique employees.

### Solution Code
```python
import sys

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        n = int(line)
        if n == 0:
            break
        groups = {}
        group1 = None
        for i in range(n):
            current_line = sys.stdin.readline().strip()
            while not current_line:
                current_line = sys.stdin.readline().strip()
            group_part, members_part = current_line.split(':', 1)
            group_name = group_part
            members = members_part.rstrip('.').split(',')
            groups[group_name] = members
            if i == 0:
                group1 = group_name
        memo = {}
        def get_employees(g):
            if g in memo:
                return memo[g]
            employees = set()
            for member in groups[g]:
                if member in groups:
                    employees.update(get_employees(member))
                else:
                    employees.add(member)
            memo[g] = employees
            return employees
        employees = get_employees(group1)
        print(len(employees))

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The code reads each dataset line by line. The first line gives the number of groups `n`, followed by `n` lines each describing a group.
2. **Storing Groups**: Groups are stored in a dictionary where each key is a group name and the value is a list of its members.
3. **Recursive Expansion**: The `get_employees` function recursively expands each group. If a member is a group, it recursively processes that group. Employees are collected in a set to ensure uniqueness.
4. **Memoization**: A memoization dictionary (`memo`) caches the result for each group to avoid redundant calculations when a group is referenced multiple times.
5. **Output**: For each dataset, the number of unique employees in the first group is printed.

This approach efficiently handles nested group structures and ensures that each group is expanded only once, leading to optimal performance even for the upper constraint limits.
