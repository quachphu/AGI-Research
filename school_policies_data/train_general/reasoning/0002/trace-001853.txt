To solve this problem, we need to generate 12-digit ID numbers for cities based on their prefecture and the order of their establishment within that prefecture. The solution involves efficiently grouping cities by their prefecture, determining their establishment order, and formatting the results correctly.

### Approach
1. **Input Reading**: Read the number of prefectures (N) and cities (M), followed by the details of each city, including its prefecture and the year it was established.
2. **Grouping by Prefecture**: Use a dictionary to group cities by their prefecture. Each entry in the dictionary will hold the cities belonging to a specific prefecture.
3. **Sorting by Year**: For each prefecture group, sort the cities based on the year they were established. This allows us to determine the chronological order of cities within each prefecture.
4. **Assigning Order Numbers**: After sorting, assign an order number (x-value) to each city within its prefecture. This x-value is used to construct the latter part of the 12-digit ID.
5. **Formatting and Output**: For each city, format its prefecture number and x-value into the required 12-digit ID and print the results in the original input order.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    N, M = map(int, sys.stdin.readline().split())
    cities = []
    groups = defaultdict(list)
    for orig_idx in range(M):
        P, Y = map(int, sys.stdin.readline().split())
        cities.append((P, Y))
        groups[P].append((Y, orig_idx))
    
    x_values = [0] * M
    for P in groups:
        sorted_list = sorted(groups[P], key=lambda x: x[0])
        for pos, (y, orig_idx) in enumerate(sorted_list, 1):
            x_values[orig_idx] = pos
    
    for orig_idx in range(M):
        P, Y = cities[orig_idx]
        p_part = f"{P:06d}"
        x_part = f"{x_values[orig_idx]:06d}"
        print(p_part + x_part)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and stored in a list of cities, each represented by a tuple of its prefecture and year. Simultaneously, cities are grouped by their prefecture using a dictionary.
2. **Sorting Cities**: Each group of cities (by prefecture) is sorted based on the year of establishment. This sorting allows us to determine the chronological order of cities within each prefecture.
3. **Determining Order Numbers**: As we iterate through the sorted list of cities in each prefecture, we assign an order number (x-value) starting from 1. This x-value is stored in an array where the index corresponds to the original input order of the city.
4. **Formatting IDs**: Finally, each city's prefecture number and x-value are formatted into two 6-digit strings (with leading zeros as necessary) and concatenated to form the 12-digit ID. The results are printed in the original input order.

This approach ensures that we efficiently handle the constraints, sorting cities within each prefecture and formatting the results correctly, leading to an optimal and correct solution.
