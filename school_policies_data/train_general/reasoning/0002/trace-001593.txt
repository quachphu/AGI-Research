### Approach
1. **Identify Boundaries**: The first step is to determine the minimum and maximum x and y coordinates among all the given mine points. These values will define the smallest rectangle that can contain all the points.
2. **Calculate Span**: Compute the horizontal span (difference between the maximum and minimum x coordinates) and the vertical span (difference between the maximum and minimum y coordinates).
3. **Determine Side Length**: The side length of the square must be the maximum of the horizontal and vertical spans to ensure all points are enclosed.
4. **Compute Area**: The area of the square is the square of the side length determined in the previous step.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    x = []
    y = []
    idx = 1
    for _ in range(n):
        xi = int(input[idx])
        yi = int(input[idx + 1])
        x.append(xi)
        y.append(yi)
        idx += 2
    min_x = min(x)
    max_x = max(x)
    min_y = min(y)
    max_y = max(y)
    delta_x = max_x - min_x
    delta_y = max_y - min_y
    side = max(delta_x, delta_y)
    print(side * side)

main()
```

### Explanation
1. **Reading Input**: The input is read as a single string and split into a list of values for easier processing. The first value is the number of mine points, followed by pairs of x and y coordinates.
2. **Storing Coordinates**: The x and y coordinates are stored in separate lists to facilitate finding their minimum and maximum values.
3. **Calculating Spans**: By finding the minimum and maximum values for both x and y coordinates, we determine the horizontal and vertical spans.
4. **Determining Side Length**: The side length of the square is the maximum of the horizontal and vertical spans to ensure all points are enclosed within the square.
5. **Computing Area**: The area is the square of the determined side length, which is then printed as the result.

This approach efficiently computes the required minimum area by leveraging basic arithmetic operations and comparisons, ensuring optimal performance even for the upper limit of input constraints.
