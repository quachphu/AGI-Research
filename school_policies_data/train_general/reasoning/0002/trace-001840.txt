To solve this problem, we need to determine the optimal strategy for Vova to defeat the Modcrab in the minimum number of phases while ensuring he never dies during the battle. The strategy involves deciding when to attack and when to heal based on the current health and attack power of both Vova and the Modcrab.

### Approach
1. **Understand the Phases**: Each phase consists of Vova's action (either attack or heal) followed by the Modcrab's attack if it is still alive.
2. **Greedy Strategy**: The goal is to minimize the number of phases. Therefore, Vova should attack whenever possible unless it would result in his death before the next phase.
3. **Healing Decision**: If attacking would leave Vova with health less than or equal to zero after the Modcrab's subsequent attack, he must heal instead. This ensures he survives to continue the battle.

### Solution Code
```python
def main():
    import sys
    h1, a1, c1 = map(int, sys.stdin.readline().split())
    h2, a2 = map(int, sys.stdin.readline().split())
    
    v_h = h1
    m_h = h2
    actions = []
    
    while True:
        if m_h <= a1:
            actions.append("STRIKE")
            break
        # Check if attacking is possible without dying
        after_attack_v = v_h - a2
        if after_attack_v > 0:
            # Attack
            actions.append("STRIKE")
            m_h -= a1
            v_h = after_attack_v
        else:
            # Heal
            actions.append("HEAL")
            v_h += (c1 - a2)
    # Output the results
    print(len(actions))
    for action in actions:
        print(action)

if __name__ == "__main__":
    main()
```
