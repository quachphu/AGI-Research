To solve this problem, we need to determine the minimum number of times Jamie needs to press the snooze button on his alarm clock so that he wakes up at a specific time, given that the alarm must start at a "lucky" time (containing the digit '7'). The solution involves checking each possible snooze interval starting from the desired wake-up time and moving backward in time until we find the first occurrence of a lucky time.

### Approach
1. **Convert Time to Minutes**: Convert the given wake-up time (hh:mm) into total minutes since midnight. This simplifies the arithmetic operations needed to adjust the time backward.
2. **Iterate Over Possible Snooze Counts**: Starting from 0 snooze presses, incrementally check each possible snooze count (y) by moving backward in time in steps of x minutes each.
3. **Check for Lucky Time**: For each adjusted time (wake-up time minus y snooze intervals), check if any digit in the hours or minutes (formatted as two-digit strings) contains the digit '7'.
4. **Return the Minimum Snooze Count**: The first y that results in a lucky time is the answer.

### Solution Code
```python
x = int(input())
hh, mm = map(int, input().split())
total = hh * 60 + mm

for y in range(0, 1440 + 1):
    adjusted = (total - x * y) % 1440
    hh_adj = adjusted // 60
    mm_adj = adjusted % 60
    time_str = f"{hh_adj:02d}{mm_adj:02d}"
    if '7' in time_str:
        print(y)
        break
```

### Explanation
1. **Convert Time to Minutes**: The wake-up time (hh:mm) is converted into total minutes since midnight. For example, 11:23 becomes 683 minutes.
2. **Adjust Time Backward**: For each snooze count y, compute the adjusted time by subtracting x*y minutes from the total minutes. Use modulo 1440 to handle the wrap-around of the 24-hour clock.
3. **Check Digits for '7'**: Convert the adjusted time back into hours and minutes, format them as two-digit strings, and check if either string contains the digit '7'.
4. **Output Result**: The loop breaks as soon as a valid lucky time is found, ensuring the minimum y is printed.

This approach efficiently checks each possible start time within a 24-hour period, ensuring the solution is both correct and optimal.
