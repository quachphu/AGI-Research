To solve this problem, we need to determine the number of years Vasya needs to serve in the army to rise from his current rank `a` to his desired rank `b`. The solution involves calculating the sum of the years required for each consecutive rank promotion from `a` to `b`.

### Approach
1. **Input Reading**: Read the number of ranks `n`, the list of years required for each promotion, and the current and desired ranks `a` and `b`.
2. **Sum Calculation**: Calculate the sum of the years required for promotions starting from rank `a` up to rank `b-1`. This is done by summing the elements in the list from index `a-1` to `b-2` (inclusive), which corresponds to the promotions needed to move from rank `a` to `b`.

### Solution Code
```python
def main():
    import sys
    n = int(sys.stdin.readline())
    d = list(map(int, sys.stdin.readline().split()))
    a, b = map(int, sys.stdin.readline().split())
    print(sum(d[a-1 : b-1]))

main()
```

### Explanation
1. **Reading Input**: The input is read from standard input. The first line gives the number of ranks `n`. The second line provides a list of `n-1` integers, each representing the years needed to move from rank `i` to `i+1`. The third line contains two integers `a` and `b`, the current and desired ranks.
2. **Summing Years**: The years required to move from rank `a` to `b` are found by summing the elements in the list from index `a-1` to `b-2`. This is because the list indices start from 0, and each element at index `i` represents the years needed to move from rank `i+1` to `i+2`.

This approach efficiently computes the required sum using list slicing and the built-in `sum` function, ensuring the solution is both concise and optimal.
