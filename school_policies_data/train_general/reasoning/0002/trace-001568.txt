To solve this problem, we need to implement the Bubble Sort algorithm based on the provided pseudocode, which sorts a sequence in ascending order and counts the number of swap operations performed during the sorting process.

### Approach
1. **Understanding Bubble Sort**: Bubble Sort works by repeatedly swapping adjacent elements if they are in the wrong order. This process is repeated until the entire sequence is sorted.
2. **Pseudocode Translation**: The given pseudocode specifies two nested loops. The outer loop runs from the start to the end of the array, and the inner loop runs from the end of the array down to the current position of the outer loop. This setup ensures that each element "bubbles up" to its correct position.
3. **Counting Swaps**: Each time two elements are swapped, a counter is incremented to keep track of the total number of swaps performed.

### Solution Code
```python
def bubble_sort():
    n = int(input())
    a = list(map(int, input().split()))
    swap_count = 0
    for i in range(n):
        for j in range(n-1, i, -1):
            if a[j] < a[j-1]:
                a[j], a[j-1] = a[j-1], a[j]
                swap_count += 1
    print(' '.join(map(str, a)))
    print(swap_count)

bubble_sort()
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` (number of elements) followed by the sequence of `n` integers.
2. **Outer Loop**: The outer loop runs from `0` to `n-1`, iterating through each element of the array.
3. **Inner Loop**: The inner loop starts from the end of the array and moves towards the current position of the outer loop. This ensures that each element is compared with its previous neighbor.
4. **Swapping Elements**: If an element is found to be smaller than its previous neighbor, they are swapped, and the swap counter is incremented.
5. **Output**: After sorting the array, the sorted sequence and the total number of swaps are printed.

This approach efficiently sorts the array using the Bubble Sort algorithm and accurately counts the number of swaps, adhering to the problem constraints and requirements.
