To solve this problem, we need to identify pairs of houses in a network of water pipes where a water tank should be installed at the starting house (tank) and a water tap at the ending house (tap). Each tank should convey water to the corresponding tap through a series of pipes, and the maximum safe water volume is determined by the minimum diameter of the pipes in the path.

### Approach
1. **Model the Network**: Represent the network using dictionaries to track outgoing and incoming pipes for each house.
2. **Identify Tanks and Taps**: A tank is a house with an outgoing pipe but no incoming pipe. A tap is a house with an incoming pipe but no outgoing pipe.
3. **Traverse Paths**: For each identified tank, follow the outgoing pipes to determine the path to the corresponding tap. Track the minimum pipe diameter along this path to determine the safe water volume.
4. **Collect Results**: Gather all valid tank-tap pairs along with the minimum diameter and sort them by the tank's house number.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    p = int(input[ptr])
    ptr += 1

    outgoing = {}
    incoming = {}
    for _ in range(p):
        ai = int(input[ptr])
        ptr += 1
        bi = int(input[ptr])
        ptr += 1
        di = int(input[ptr])
        ptr += 1
        outgoing[ai] = (bi, di)
        incoming[bi] = (ai, di)

    result = []
    for tank in range(1, n + 1):
        if tank not in incoming and tank in outgoing:
            current = tank
            min_d = float('inf')
            while current in outgoing:
                next_node, d = outgoing[current]
                min_d = min(min_d, d)
                current = next_node
            result.append((tank, current, min_d))

    result.sort()
    print(len(result))
    for line in result:
        print(f"{line[0]} {line[1]} {line[2]}")


if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into integers representing the number of houses and pipes. Each pipe's details are stored in dictionaries for outgoing and incoming pipes.
2. **Identifying Tanks**: For each house, check if it has an outgoing pipe but no incoming pipe, marking it as a tank.
3. **Traversing Paths**: For each tank, follow the outgoing pipes to the end of the path, keeping track of the minimum pipe diameter encountered.
4. **Collecting Results**: Each valid tank-tap pair is collected, sorted by the tank's house number, and printed in the required format.

This approach efficiently traverses the network to find all valid paths from tanks to taps, ensuring the solution is both correct and optimal.
