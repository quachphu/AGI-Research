To solve this problem, we need to add two reversed numbers and output their reversed sum. The key steps involve reversing the input numbers to get their original form, summing these original numbers, and then reversing the sum to produce the final result while omitting any leading zeros.

### Approach
1. **Read Input:** Read the number of test cases and each pair of reversed numbers.
2. **Reverse Numbers:** For each input number, reverse its digits to get the original number. This is done by converting the number to a string, reversing the string, and converting it back to an integer to strip any leading zeros.
3. **Sum Original Numbers:** Add the two original numbers obtained from reversing the input numbers.
4. **Reverse the Sum:** Convert the sum to a string, reverse it, and convert it back to an integer to strip any leading zeros.
5. **Output the Result:** Print the reversed sum for each test case.

### Solution Code
```python
n = int(input())
for _ in range(n):
    a, b = input().split()
    a_rev = int(a[::-1])
    b_rev = int(b[::-1])
    total = a_rev + b_rev
    reversed_total = str(total)[::-1]
    print(int(reversed_total))
```

### Explanation
1. **Reading Input:** The input consists of multiple test cases. The first line specifies the number of test cases, and each subsequent line contains two reversed numbers.
2. **Reversing Input Numbers:** Each number is reversed by converting it to a string, slicing the string in reverse order, and converting it back to an integer. This process ensures that any leading zeros from the reversed string are removed.
3. **Summing Original Numbers:** The original numbers (obtained by reversing the input numbers) are summed up.
4. **Reversing the Sum:** The sum of the original numbers is converted to a string, reversed, and converted back to an integer to remove any leading zeros, ensuring the result is in the correct format.
5. **Output:** The final reversed sum is printed for each test case.

This approach efficiently handles the requirements by leveraging string manipulation and integer conversion to ensure correctness and simplicity.
