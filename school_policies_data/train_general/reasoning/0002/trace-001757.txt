To solve this problem, we need to determine the minimum possible total number of votes obtained by two candidates, Takahashi and Aoki, after each report of vote ratios. The key challenge is to ensure that the number of votes never decreases between reports while maintaining the given ratios.

### Approach
1. **Initialization**: Start with the first reported ratio as the initial votes for Takahashi and Aoki.
2. **Iterative Update**: For each subsequent report, compute the minimum multiplier needed to scale the current ratio such that the votes for both candidates do not decrease. This multiplier is determined by ensuring the scaled votes are at least as much as the previous counts.
3. **Ceiling Division**: Use ceiling division to find the smallest integer multiplier that satisfies the non-decreasing condition for both candidates' votes.
4. **Update Votes**: Adjust the votes for both candidates using the computed multiplier and proceed to the next report.

### Solution Code
```python
n = int(input())
ratios = [tuple(map(int, input().split())) for _ in range(n)]

current_t, current_a = ratios[0]
for t, a in ratios[1:]:
    m1 = (current_t + t - 1) // t
    m2 = (current_a + a - 1) // a
    m = max(m1, m2)
    current_t = m * t
    current_a = m * a

print(current_t + current_a)
```

### Explanation
1. **Reading Input**: The input is read and parsed into a list of tuples representing the vote ratios.
2. **Initial Votes**: The initial votes are set to the first ratio values.
3. **Iterating Through Reports**: For each subsequent report, compute the minimum multiplier using ceiling division to ensure the votes do not decrease. The multiplier is the maximum of the required multipliers for both candidates.
4. **Updating Votes**: Adjust the votes using the computed multiplier and continue to the next report.
5. **Output the Result**: After processing all reports, the sum of the final votes for both candidates is printed.

This approach efficiently ensures that the votes are scaled appropriately at each step while maintaining the constraints, leading to the correct minimum total votes after the last report.
