To solve this problem, we need to determine the minimum number of minutes required for Pasha to adjust the positions of his hamsters such that exactly half of them are standing up (denoted by 'X') and the other half are sitting down (denoted by 'x'). Additionally, we need to provide one of the possible optimal configurations.

### Approach
1. **Count Current Standing Hamsters**: First, count how many hamsters are currently standing ('X').
2. **Determine Required Adjustments**: Calculate the number of standing hamsters required, which is half of the total number of hamsters (since n is even).
3. **Calculate Changes Needed**: Compute the difference between the current number of standing hamsters and the required number. This difference determines the number of changes needed.
4. **Adjust Positions**: Depending on whether we need more or fewer standing hamsters:
   - If there are more standing hamsters than needed, convert the excess 'X' to 'x'.
   - If there are fewer standing hamsters than needed, convert the deficit 'x' to 'X'.
5. **Output the Result**: Print the minimum number of changes and the resulting configuration.

### Solution Code
```python
n = int(input())
s = list(input().strip())
current_x = s.count('X')
required = n // 2
delta = current_x - required

if delta == 0:
    print(0)
    print(''.join(s))
else:
    steps = abs(delta)
    if delta > 0:
        # Need to change 'X's to 'x's
        for i in range(n):
            if s[i] == 'X':
                s[i] = 'x'
                delta -= 1
                if delta == 0:
                    break
    else:
        # Need to change 'x's to 'X's
        delta = -delta
        for i in range(n):
            if s[i] == 'x':
                s[i] = 'X'
                delta -= 1
                if delta == 0:
                    break
    print(steps)
    print(''.join(s))
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` (number of hamsters) followed by a string representing their current positions.
2. **Counting Standing Hamsters**: We count the occurrences of 'X' to determine how many hamsters are standing.
3. **Determine Required Adjustments**: Calculate how many hamsters need to be standing (`n // 2`).
4. **Adjust Positions**:
   - If there are more standing hamsters than needed, convert the excess 'X' to 'x' starting from the left.
   - If there are fewer standing hamsters than needed, convert the necessary 'x' to 'X' starting from the left.
5. **Output**: Print the minimum number of changes and the resulting configuration. This approach ensures we make the minimum number of changes efficiently by processing the string from left to right, ensuring optimal performance.
