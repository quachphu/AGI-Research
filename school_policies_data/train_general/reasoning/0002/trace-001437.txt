To solve this problem, we need to determine if two given strings `s` and `t` can be made equal through a series of moves where each move involves reversing contiguous substrings of the same length in both strings. The solution involves checking the feasibility based on character counts and permutation parity.

### Approach
1. **Immediate Check**: If `s` and `t` are already equal, the answer is "YES".
2. **Character Count Check**: If the sorted versions of `s` and `t` are different, they cannot be made equal, so the answer is "NO".
3. **Duplicate Characters Check**: If there are duplicate characters in `s`, we can always rearrange the characters to make `s` and `t` equal, so the answer is "YES".
4. **Permutation Parity Check**: For strings with all unique characters, we need to check if the permutation required to transform `s` into `t` has an even parity. This is determined by counting the number of inversions in the permutation using a Fenwick Tree (Binary Indexed Tree).

### Solution Code
```python
q = int(input())

class FenwickTree:
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (self.n + 2)  # +2 to avoid overflow issues

    def update(self, idx, delta=1):
        while idx <= self.n:
            self.tree[idx] += delta
            idx += idx & -idx

    def query(self, idx):
        res = 0
        while idx > 0:
            res += self.tree[idx]
            idx -= idx & -idx
        return res

for _ in range(q):
    n = int(input())
    s = input().strip()
    t = input().strip()

        continue

        continue

    char_to_pos = {c: i for i, c in enumerate(t)}
```
