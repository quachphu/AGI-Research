To solve this problem, we need to determine the maximum total price of items Navi can sell each day to his friend, given constraints on the maximum weight and number of items his friend can carry. The solution involves generating all possible subsets of items and checking which subsets meet the given constraints while maximizing the total price.

### Approach
1. **Input Reading**: Read the number of days and for each day, read the number of items, their prices and weights, and the constraints (maximum weight and item count).
2. **Subset Generation**: For each day, generate all possible non-empty subsets of items using bitmasking. This allows us to efficiently iterate through all combinations of items.
3. **Constraint Checking**: For each subset, calculate the total price, total weight, and count of items. Check if the subset meets the constraints (total weight ≤ maximum weight and count ≤ maximum item count).
4. **Maximize Total Price**: Track the maximum total price of valid subsets. If no valid subset is found, return -1 for that day.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    D = int(input[ptr])
    ptr += 1
    for day in range(D):
        N = int(input[ptr])
        ptr += 1
        items = []
        for _ in range(N):
            p = int(input[ptr])
            w = int(input[ptr + 1])
            items.append((p, w))
            ptr += 2
        Wmax = int(input[ptr])
        C = int(input[ptr + 1])
        ptr += 2
        max_total = -1
        for mask in range(1, 1 << N):
            count = bin(mask).count('1')
            if count > C:
                continue
            sum_p = 0
            sum_w = 0
            for i in range(N):
                if mask & (1 << i):
                    sum_p += items[i][0]
                    sum_w += items[i][1]
            if sum_w <= Wmax and sum_p > max_total:
                max_total = sum_p
        print(f"For Day #{day + 1}:")
        print(max_total if max_total != -1 else -1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, and then parsed using a pointer to track the current position in the input list.
2. **Bitmasking**: Each possible subset of items is represented by a bitmask. For example, a bitmask `0b101` represents selecting the first and third items.
3. **Subset Evaluation**: For each bitmask, the number of items (count) is determined by counting the set bits. The total price and weight are computed by summing the corresponding values of the selected items.
4. **Constraints Check**: Each subset is checked against the constraints. If valid, the total price is compared with the current maximum to update it if higher.
5. **Output**: After processing all subsets for a day, the maximum total price is printed, or -1 if no valid subset was found.

This approach efficiently explores all possible item combinations using bitmasking, ensuring we find the optimal solution within the given constraints.
