To solve this problem, we need to identify all modified Kaprekar numbers (KP numbers) within a given range [p, q]. A modified KP number is a number whose square can be split into two parts such that the sum of these parts equals the original number. 

### Approach
1. **Understanding the Problem**: A modified KP number `n` with `d` digits has a square that can be split into two parts. The right part must have exactly `d` digits, and the left part must have the remaining digits (either `d` or `d-1` digits). The sum of these two parts should equal `n`.

2. **Key Observations**:
   - For a number `n` with `d` digits, its square will have either `2d` or `2d-1` digits.
   - The right part of the square (last `d` digits) and the left part (remaining digits) must sum to `n`.

3. **Algorithm**:
   - For each number `n` in the range [p, q], calculate its square.
   - Convert the square to a string to handle leading zeros.
   - Check if the length of the square string is either `2d` or `2d-1` (where `d` is the number of digits in `n`).
   - Split the square string into left and right parts, convert them to integers, and check if their sum equals `n`.

### Solution Code
```python
def is_kp(n):
    d = len(str(n))
    square = n ** 2
    square_str = str(square)
    len_sq = len(square_str)
    
    if len_sq not in (2 * d - 1, 2 * d):
        return False
    
    right_str = square_str[-d:]
    left_str = square_str[:-d]
    
    left = int(left_str) if left_str else 0
    right = int(right_str)
    
    return left + right == n

p = int(input())
q = int(input())

kp_numbers = []
for num in range(p, q + 1):
    if is_kp(num):
        kp_numbers.append(str(num))

if kp_numbers:
    print(' '.join(kp_numbers))
else:
    print("INVALID RANGE")
```

### Explanation
1. **Reading Input**: The input consists of two integers `p` and `q`, which define the range of numbers to check.
2. **Checking KP Numbers**: For each number `n` in the range [p, q], the function `is_kp` checks if it is a modified KP number.
   - **Digit Count**: Calculate the number of digits `d` in `n`.
   - **Square Calculation**: Compute the square of `n` and convert it to a string.
   - **Length Check**: Ensure the square string's length is either `2d` or `2d-1`.
   - **Splitting and Summing**: Split the square string into left and right parts, convert them to integers, and check if their sum equals `n`.
3. **Output Results**: Collect all valid KP numbers and print them. If no KP numbers are found, print "INVALID RANGE".

This approach efficiently checks each number in the given range using string manipulation and arithmetic checks, ensuring correctness and handling edge cases such as leading zeros in the right part of the square.
