   - Each row or column selection contributes to the total discomfort based on the current values of the cells in that row or column.
   - After each selection, the discomfort of all cells in the chosen row or column increases by 1, affecting future selections.

2. **Key Insights**:
   - The optimal strategy involves minimizing the sum of discomforts by considering both row and column selections.
   - The discomfort contribution from each row or column selection can be modeled using a greedy approach, where each selection is made to minimize the incremental discomfort.

3. **Algorithm**:
   - **Precompute Row and Column Sums**: Calculate the initial discomfort sums for each row and column.
   - **Dynamic Programming with Min-Heap**: Use a min-heap to efficiently compute the minimum possible discomfort for selecting rows and columns up to K times. This involves distributing the K selections between rows and columns optimally.
   - **Combine Results**: For each possible split of K selections between rows (s) and columns (K-s), compute the total discomfort and find the minimum.

import heapq
import sys

def main():
    input = sys.stdin.read().split()

    T = int(input[ptr])

        ptr += 2

            ptr += N
            matrix.append(row)

        S = [sum(row) for row in matrix]
        # Compute column sums C_j
        C = [0] * N
        for j in range(N):
            for i in range(N):
                C[j] += matrix[i][j]
        
        # Precompute rows_sum
        rows_sum = [0] * (K + 1)
        if K >= 1:

            sum_r = 0

                sum_r += current
                rows_sum[s] = sum_r
                heapq.heappush(heap, current + N)
        
        # Precompute columns_sum
        columns_sum = [0] * (K + 1)

            heap = C.copy()
            heapq.heapify(heap)
            sum_c = 0

                columns_sum[t] = sum_c
