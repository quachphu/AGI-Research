To solve this problem, we need to compute the sum of activity levels of a kindergarten for all possible distributions of candies and excitement levels of children, modulo \(10^9 + 7\). The activity level is determined by the product of the happiness of each child, which in turn depends on the number of candies they receive and their excitement level.

### Approach
1. **Precomputation of Powers and Prefix Sums**:
   - Precompute the values of \(x^k \mod (10^9 + 7)\) for all \(x\) in the range [1, 400] and \(k\) in the range [0, 400].
   - Use these precomputed values to compute prefix sums for each \(k\), allowing efficient range sum queries for \(x\) values from \(A_i\) to \(B_i\).

2. **Dynamic Programming (DP) Setup**:
   - Use a DP array to keep track of the sum of activity levels for distributing a certain number of candies up to the given number of children.
   - For each child, compute the contribution of their possible excitement levels using the precomputed prefix sums and update the DP array accordingly.

### Solution Code
```python
MOD = 10**9 + 7

max_x = 400
max_k = 400

# Precompute x^k for x in [1, 400] and k in [0, 400]
pow_xk = [[0] * (max_k + 1) for _ in range(max_x + 1)]
for x in range(1, max_x + 1):
    pow_xk[x][0] = 1
    for k in range(1, max_k + 1):
        pow_xk[x][k] = (pow_xk[x][k-1] * x) % MOD

# Precompute prefix sums for each k
prefix_sum = [[0] * (max_x + 1) for _ in range(max_k + 1)]
for k in range(max_k + 1):
    current = 0
    for x in range(1, max_x + 1):
        current = (current + pow_xk[x][k]) % MOD
        prefix_sum[k][x] = current

# Read input
N, C = map(int, input().split())
A = list(map(int, input().split()))
B = list(map(int, input().split()))

# Precompute S[i][k] for each child i and k up to C
S = []
for i in range(N):
    a = A[i]
    b = B[i]
    s_i = [0] * (C + 1)
    for k in range(C + 1):
        if a > 1:
            total = (prefix_sum[k][b] - prefix_sum[k][a - 1]) % MOD
        else:
            total = prefix_sum[k][b] % MOD
        s_i[k] = (total + MOD) % MOD  # Ensure non-negative
    S.append(s_i)

# Dynamic programming
dp_prev = [0] * (C + 1)
dp_prev[0] = 1  # Base case: 0 candies, 0 children

for i in range(N):
    dp_current = [0] * (C + 1)
    for c in range(C + 1):
        for k in range(c + 1):
            dp_current[c] = (dp_current[c] + S[i][k] * dp_prev[c - k]) % MOD
    dp_prev = dp_current
```

   - The DP array `dp_prev` keeps track of the sum of activity levels for distributing up to `C` candies using the first `i` children.
   - For each child, we update the DP array by considering all possible distributions of candies to that child, using the precomputed sums for their possible excitement levels.
