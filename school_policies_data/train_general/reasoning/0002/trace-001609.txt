To solve this problem, we need to compute the digit-by-digit XOR of two binary numbers for multiple test cases. The XOR operation results in 1 if the corresponding bits of the two numbers are different, and 0 if they are the same.

### Approach
1. **Input Reading**: Read the number of test cases, followed by pairs of binary numbers for each test case.
2. **XOR Calculation**: For each pair of binary numbers, iterate through each corresponding pair of digits. If the digits differ, append '1' to the result string; otherwise, append '0'.
3. **Output the Result**: Print the result for each test case after processing the pair of binary numbers.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    idx = 1
    for _ in range(T):
        a = input[idx].strip()
        b = input[idx+1].strip()
        idx += 2
        res = []
        for x, y in zip(a, b):
            res.append('1' if x != y else '0')
        print(''.join(res))
            
if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and split into a list of strings for efficient processing. This is particularly useful for handling large input sizes.
2. **Processing Each Test Case**: For each test case, the two binary numbers are retrieved from the input list. We then iterate over each corresponding pair of digits using the `zip` function.
3. **Constructing the Result**: For each pair of digits, we check if they are different. If they are, we append '1' to the result list; otherwise, we append '0'. The result list is then joined into a string and printed.

This approach ensures that we efficiently handle the input and compute the XOR result in linear time relative to the length of the binary numbers, making it suitable for large inputs up to 10,000 digits.
