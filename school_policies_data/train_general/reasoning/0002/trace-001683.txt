To solve this problem, we need to determine if a set of segments on a circular disc is rotationally symmetric. This means there exists some rotation value \( k \) such that rotating all segments by \( k \) units clockwise results in the same set of segments.

### Approach
1. **Normalization of Segments**: Convert each segment into a normalized form where the smaller point comes first. This helps in consistent comparison of segments.
2. **Candidate Generation**: For each segment, generate possible rotation values \( k \) that could map the first segment to any other segment in the set.
3. **Validation of Candidates**: Check each candidate \( k \) to see if rotating all segments by \( k \) results in the same set of segments.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    m = int(input[idx])
    idx += 1

    segments = set()
    for _ in range(m):
        a = int(input[idx])
        idx += 1
        b = int(input[idx])
        idx += 1
        if a > b:
            a, b = b, a
        segments.add((a, b))
    
    if m == 0:
        print("Yes")
        return
    
    # Get the first segment
    first = next(iter(segments))
    a1, b1 = first
    
    candidates = set()
    for (c, d) in segments:
        # Case 1: (a1 + k) = c, (b1 + k) = d
        k = (c - a1) % n
        if (b1 + k) % n == d % n:
            if k != 0:
                candidates.add(k)
        # Case 2: (a1 + k) = d, (b1 + k) = c
        k = (d - a1) % n
        if (b1 + k) % n == c % n:
            if k != 0:
                candidates.add(k)
    
    for k in candidates:
        valid = True
        for (a, b) in segments:
            new_a = (a + k) % n
            new_a = new_a if new_a != 0 else n
            new_b = (b + k) % n
            new_b = new_b if new_b != 0 else n
            if new_a > new_b:
                new_a, new_b = new_b, new_a
            if (new_a, new_b) not in segments:
                valid = False
                break
        if valid:
            print("Yes")
            return
    print("No")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Normalization**: Each segment is stored as a tuple with the smaller point first to ensure consistency in comparisons.
2. **Candidate Generation**: For each segment, two possible rotation values \( k \) are computed. The first value checks if rotating the segment by \( k \) results in another segment, and the second checks the reverse order.
3. **Validation**: Each candidate \( k \) is validated by rotating every segment and checking if the result exists in the original set. If all segments validate, the answer is "Yes"; otherwise, "No".

This approach efficiently narrows down potential rotation values and checks them against all segments, ensuring correctness while maintaining performance.
