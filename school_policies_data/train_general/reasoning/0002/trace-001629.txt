To solve this problem, we need to determine the minimum and maximum number of isolated vertices in an undirected graph with `n` vertices and `m` edges. An isolated vertex is one that is not connected to any other vertex by an edge.

### Approach

1. **Maximum Isolated Vertices**:
   - To maximize the number of isolated vertices, we need to use the fewest vertices possible to place all `m` edges. This is achieved by forming a complete subgraph with `k` vertices where `k` is the smallest integer such that the number of edges in a complete graph of `k` vertices (which is `k*(k-1)/2`) is at least `m`. The maximum number of isolated vertices is then `n - k`.

2. **Minimum Isolated Vertices**:
   - To minimize the number of isolated vertices, we need to use as many vertices as possible. Each edge can connect two vertices, so the maximum number of vertices that can be covered by `m` edges is `min(2*m, n)`. The minimum number of isolated vertices is then `n - min(2*m, n)`.

### Solution Code

```python
import math

n, m = map(int, input().split())

if m == 0:
    print(n, n)
else:
    # Calculate minimum isolated vertices
    s = min(2 * m, n)
    min_iso = n - s

    # Calculate maximum isolated vertices
    k = math.ceil((1 + math.sqrt(1 + 8 * m)) / 2)
    max_iso = n - k

    print(min_iso, max_iso)
```

### Explanation

1. **Reading Input**:
   - The input consists of two integers `n` (number of vertices) and `m` (number of edges).

2. **Handling Edge Case**:
   - If there are no edges (`m == 0`), all vertices are isolated, so both the minimum and maximum isolated vertices are `n`.

3. **Calculating Minimum Isolated Vertices**:
