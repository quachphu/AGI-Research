To solve this problem, we need to determine the smallest and largest possible initial number of children, \( N \), such that after \( K \) rounds of grouping, exactly two children remain. If no valid \( N \) exists, we return -1.

### Approach
1. **Reverse Analysis**: Instead of simulating the game from the start, we work backwards from the known result (2 children remaining after the last round). This allows us to determine the possible ranges of children that could have existed before each round.
2. **Range Propagation**: For each round in reverse order, we compute the possible range of children that could have existed before that round, given the current range after the round. This involves checking if the current range can be formed by grouping children according to the given constraints.
3. **Edge Case Handling**: If the last round's group size is not 2, it is impossible to end with exactly 2 children, so we immediately return -1.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    K = int(input[0])
    A = list(map(int, input[1:K+1]))
    
    if A[-1] != 2:
        print(-1)
        return
    
    low = 2
    high = 2
    for a in reversed(A):
        q_min = (low + a - 1) // a
        q_max = high // a
        if q_min > q_max:
            print(-1)
            return
        new_low = q_min * a
        new_high = (q_max + 1) * a - 1
        low, high = new_low, new_high
    
    print(low, high)

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read and parsed into the number of rounds \( K \) and the list of group sizes for each round.
2. **Initial Check**: If the last group size is not 2, it is impossible to end with exactly 2 children, so we print -1 and exit.
3. **Reverse Processing**: Starting from the last round (which must result in exactly 2 children), we compute the possible range of children before each round. For each round, we determine the minimum and maximum possible values of children that could form valid groups leading to the current range.
4. **Range Update**: For each group size in reverse order, we calculate the possible range of children before that round. If at any point the range becomes invalid (no possible values), we print -1 and exit.
5. **Output**: After processing all rounds, the valid range of initial children is printed.

This approach efficiently computes the possible values of \( N \) using reverse analysis and range propagation, ensuring correctness and optimal performance even for large input sizes.
