To solve this problem, we need to replace specific filler words in a string with three asterisks (***). The filler words are defined as those starting with "ogo" followed by zero or more "go" sequences. The goal is to identify the longest possible filler words and replace them efficiently.

### Approach
1. **Identify Filler Words**: The filler words start with "ogo" and can be followed by multiple "go" sequences. For example, "ogo", "ogogo", "ogogogo" are valid fillers.
2. **Maximal Replacement**: Each filler word should be replaced by exactly three asterisks regardless of its length. We need to ensure that the longest possible filler is replaced each time we encounter one.
3. **Iterate Through the String**: Traverse the string character by character. When a potential filler is detected starting at "ogo", check subsequent characters to see how long the filler extends by checking for consecutive "go" sequences. Replace the entire detected filler with "***" and continue processing from the end of the filler.

### Solution Code
```python
def process_interview():
    n = int(input())
    s = input().strip()
    result = []
    i = 0
    while i < len(s):
        if i + 2 < len(s) and s[i] == 'o' and s[i+1] == 'g' and s[i+2] == 'o':
            j = i + 3
            while j + 1 < len(s) and s[j] == 'g' and s[j+1] == 'o':
                j += 2
            result.append('***')
            i = j
        else:
            result.append(s[i])
            i += 1
    print(''.join(result))
```

1. **Reading Input**: The code reads the input values, including the length of the string and the string itself.
2. **Processing the String**: The main loop iterates through each character of the string. When it detects the start of a potential filler ("ogo"), it checks subsequent characters to determine the full length of the filler.
3. **Replacing Fillers**: Once a filler is identified, it is replaced with "***" in the result list, and the loop continues from the end of the filler. If no filler is detected, the current character is added to the result as-is.
4. **Output the Result**: The result list is joined into a string and printed, providing the processed string with all fillers replaced by "***".

This approach ensures that we efficiently and correctly replace all maximal filler words with "***", adhering to the problem constraints and requirements.
