To solve this problem, we need to write a Python function that converts uppercase letters to lowercase and lowercase letters to uppercase in a given string, while leaving all other characters unchanged. The solution should read input from standard input and print the converted string.

### Approach
1. **Input Handling**: Read the input string from standard input. This will capture the entire line as provided, including any leading or trailing spaces, except for the trailing newline character.
2. **Character Conversion**: Iterate over each character in the input string. For each character:
   - Check if it is an uppercase letter. If so, convert it to lowercase.
   - Check if it is a lowercase letter. If so, convert it to uppercase.
   - If the character is not an alphabetical letter, leave it unchanged.
3. **String Construction**: Collect all converted characters into a list and join them to form the resulting string.
4. **Output**: Print the resulting string.

This approach ensures that only alphabetical characters are modified, while all other characters (such as punctuation, spaces, and numbers) remain unchanged.

### Solution Code
```python
def main():
    s = input()
    converted = []
    for c in s:
        if c.isupper():
            converted.append(c.lower())
        elif c.islower():
            converted.append(c.upper())
        else:
            converted.append(c)
    print(''.join(converted))

main()
```

### Explanation
- **Reading Input**: The input is read using `input()`, which captures the entire line provided by the user, including spaces and punctuation, but excluding the trailing newline character.
- **Character Iteration**: Each character in the input string is processed individually. The `isupper()` and `islower()` methods are used to determine if a character is an uppercase or lowercase letter, respectively.
- **Conversion Logic**: If a character is uppercase, it is converted to lowercase using `lower()`, and if it is lowercase, it is converted to uppercase using `upper()`. Non-alphabetical characters are added to the result list without modification.
- **Result Construction**: The converted characters are joined into a single string using `join()`, which is then printed as the final output.

This method efficiently processes each character in linear time, making it suitable for input strings of up to the specified constraint length (less than 1200 characters).
