def kosaraju(adj, n):
    visited = [False] * n
    order = []

    # First pass: fill order
    for i in range(n):
        if not visited[i]:
            stack = [(i, False)]
            while stack:
                node, processed = stack.pop()
                if processed:
                    order.append(node)
                    continue
                if visited[node]:
                    continue
                visited[node] = True
                stack.append( (node, True) )
                # Push children in reverse order to process them in order
                for neighbor in reversed(adj[node]):
                    if not visited[neighbor]:
                        stack.append( (neighbor, False) )

    # Second pass on reversed graph
    visited = [False] * n
    sccs = []
    for node in reversed(order):
        if not visited[node]:
            stack = [node]
            visited[node] = True
            scc = []
            while stack:
                v = stack.pop()
                scc.append(v)
                for u in rev_adj[v]:
                    if not visited[u]:
                        visited[u] = True
                        stack.append(u)
            sccs.append(scc)
    return sccs

To solve this problem, we need to determine the number of returnable rooms in a circular arrangement of rooms connected by conveyor belts. A room is returnable if the snake in that room can leave and return later using the conveyor belts.

### Approach
1. **Graph Representation**: Represent the rooms and conveyor belts as a directed graph where each room is a node and each conveyor belt adds directed edges based on its state.
2. **Strongly Connected Components (SCCs)**: Use Kosaraju's algorithm to find SCCs in the graph. An SCC is a maximal subgraph where every node is reachable from every other node in the subgraph.
3. **Cycle Detection**: An SCC with more than one node inherently forms a cycle. Nodes in such SCCs are part of a cycle.
4. **Check Returnable Rooms**: For each node, check if it has at least one outgoing edge (to leave the room) and is part of an SCC with a cycle (to ensure it can return).

### Solution Code
```python
import sys
from sys import stdin

def main():
    sys.setrecursionlimit(1 << 25)
    t = int(stdin.readline())
    for _ in range(t):
        n = int(stdin.readline().strip())
        s = stdin.readline().strip()
        adj = [[] for _ in range(n)]
        for i in range(n):
            c = s[i]
            j = (i + 1) % n
            if c == '>':
                adj[i].append(j)
            elif c == '<':
                adj[j].append(i)
            else:
                adj[i].append(j)
                adj[j].append(i)
        # Build reversed adjacency list
        rev_adj = [[] for _ in range(n)]
        for u in range(n):
            for v in adj[u]:
                rev_adj[v].append(u)
        # First pass to determine the order
        visited = [False] * n
        order = []
        for i in range(n):
            if not visited[i]:
                stack = [(i, False)]
                while stack:
                    node, processed = stack.pop()
                    if processed:
                        order.append(node)
                        continue
                    if visited[node]:
                        continue
                    visited[node] = True
                    stack.append((node, True))
                    # Push children in reversed order to process them in order
                    for neighbor in reversed(adj[node]):
                        if not visited[neighbor]:
                            stack.append((neighbor, False))
        # Second pass to find SCCs using reversed graph
        visited = [False] * n
        sccs = []
        for node in reversed(order):
            if not visited[node]:
                stack = [node]
                visited[node] = True
                scc = []
                while stack:
                    v = stack.pop()
                    scc.append(v)
                    for u in rev_adj[v]:
                        if not visited[u]:
                            visited[u] = True
                            stack.append(u)
                sccs.append(scc)
        # Determine which nodes are in a cycle (SCC size >1)
        in_cycle = [False] * n
        for scc in sccs:
            if len(scc) > 1:
                for node in scc:
                    in_cycle[node] = True
        # Count the number of returnable rooms
        count = 0
        for i in range(n):
            if len(adj[i]) > 0 and in_cycle[i]:
                count += 1
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Graph Construction**: For each conveyor belt, edges are added based on its state. For example, a '>' belt adds an edge from the current room to the next, while a '<' belt adds an edge from the next room to the current.
2. **Kosaraju's Algorithm**: This algorithm is used to find SCCs. It involves two depth-first searches (DFS): the first to get the processing order of nodes, and the second on the reversed graph to identify SCCs.
3. **Cycle Detection**: SCCs with more than one node form cycles. Nodes in these SCCs can return to themselves.
4. **Check Returnable Rooms**: For each node, check if it can leave (has outgoing edges) and is part of a cycle (in an SCC with size >1).

This approach efficiently determines the number of returnable rooms by leveraging graph theory concepts and SCC analysis, ensuring optimal performance for large inputs.
