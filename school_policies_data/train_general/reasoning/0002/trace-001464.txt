To solve this problem, we need to convert given strings into "good" strings with the minimum number of operations. A "good" string is defined as one where all alphabets are either uppercase or lowercase. The solution must handle various constraints and edge cases to ensure valid inputs and correct outputs.

### Approach
1. **Input Validation**: 
   - Check if the number of test cases, T, is between 1 and 10. If not, print "Invalid Test".
   - For each test case, check if the string length is between 1 and 100. If not, print "Invalid Input".
   - Check if the string contains at least one alphabet. If not, print "Invalid Input".

2. **Conversion Calculation**:
   - For each valid string, count the number of changes needed to convert all alphabets to uppercase and the number of changes needed to convert all alphabets to lowercase.
   - The minimum of these two counts is the answer for that test case.

### Solution Code
```python
def main():
    import sys
    input_lines = [line.rstrip('\n') for line in sys.stdin]
    
    if not input_lines:
        print("Invalid Test")
        return
    
    T_line = input_lines[0] if len(input_lines) >= 1 else ''
    
    try:
        T = int(T_line)
    except ValueError:
        print("Invalid Test")
        return
    
    if not (1 <= T <= 10):
        print("Invalid Test")
        return
    
    for i in range(1, T + 1):
        if i >= len(input_lines):
            S = ''
        else:
            S = input_lines[i]
        
        if len(S) < 1 or len(S) > 100:
            print("Invalid Input")
            continue
        
        has_alpha = any(c.isalpha() for c in S)
        if not has_alpha:
            print("Invalid Input")
            continue
        
        count_upper = 0
        count_lower = 0
        
        for c in S:
            if c.isalpha():
                if c.islower():
                    count_upper += 1
                else:
                    count_lower += 1
        
        min_ops = min(count_upper, count_lower)
        print(min_ops)

main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into lines for easier processing.
2. **Handling Test Cases**: The first line is checked for validity as the number of test cases. If invalid, "Invalid Test" is printed.
3. **String Validation**: Each string is checked for length and presence of alphabets. Invalid strings result in "Invalid Input".
4. **Counting Changes**: For each valid string, the number of changes needed to convert to all uppercase and all lowercase is counted. The minimum of these counts is printed as the result for that test case.

This approach ensures that all constraints are met and efficiently calculates the minimum number of operations required to convert each string into a "good" string.
