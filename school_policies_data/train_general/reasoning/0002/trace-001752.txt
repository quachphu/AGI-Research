To solve this problem, we need to maximize the sum of jewels we can hold in our hands after performing up to K operations on a dequeue (double-ended queue) of jewels. The operations allowed are taking jewels from either end of the dequeue and optionally putting some jewels back into the dequeue.

### Approach
The optimal strategy involves considering all possible ways to take jewels from the left and right ends of the dequeue. After taking the jewels, we can put back some of them to maximize the sum. The key steps are:

1. **Take Jewels from Ends**: For each possible number of jewels taken from the left (L) and right (R), ensure that the total number of operations (L + R) does not exceed K and the total number of jewels (L + R) does not exceed the dequeue size (N).

2. **Sort and Select Best Jewels**: After collecting the jewels from both ends, sort them to identify the smallest values (which could be negative) that we can put back to maximize the sum.

3. **Calculate Maximum Sum**: For each valid combination of L and R, compute the sum after putting back the smallest values using the remaining operations. Track the maximum sum obtained through all valid combinations.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    K = int(input[1])
    V = list(map(int, input[2:2+N]))
    
    max_sum = 0
    
    for L in range(0, min(N, K) + 1):
        for R in range(0, min(K - L, N - L) + 1):
            if L + R > N:
                continue
            taken = V[0:L] + V[max(N - R, L):]
            current_sum = sum(taken)
            taken.sort()
            T = L + R
            max_s = min(K - T, T)
            for s in range(0, max_s + 1):
                if s == 0:
                    temp_sum = current_sum
                else:
                    temp_sum = current_sum - sum(taken[:s])
                if temp_sum > max_sum:
                    max_sum = temp_sum
    print(max_sum)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of jewels (N), the maximum operations (K), and the list of jewel values (V).

2. **Iterate Over Possible Combinations**: For each possible number of jewels taken from the left (L) and right (R), we check if the combination is valid (i.e., L + R ≤ N and L + R ≤ K).

3. **Collect and Sort Jewels**: The jewels taken from the left and right ends are collected into a list, sorted to easily identify the smallest values.

4. **Calculate Maximum Sum**: For each valid combination of L and R, we calculate the sum after putting back up to (K - L - R) of the smallest values. The maximum sum is tracked and updated throughout the iterations.

This approach ensures that we explore all possible ways to take and put back jewels efficiently, leading to the optimal solution within the constraints.
