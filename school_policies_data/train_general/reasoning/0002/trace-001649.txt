To solve this problem, we need to implement a user registration system where each username must be unique. If a username is already taken, the system should generate a new username by appending the smallest possible integer starting from 1. This solution must efficiently handle up to 100,000 registration requests.

### Approach
1. **Use a Dictionary for Tracking Usernames**: We use a dictionary to keep track of the number of times each username has been registered. The key is the username, and the value is the count of registrations for that username.
2. **Check and Update Usernames**: For each registration request:
   - If the username is not in the dictionary, it is added with a count of 1, and the response is "OK".
   - If the username already exists, the current count is used to generate the new username (e.g., appending the count as a suffix), the count is incremented for future use, and the generated username is returned as the response.

This approach ensures that each check and update operation is done in constant average time, O(1), making the solution efficient even for the upper limit of input size.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    name_counts = {}
    for _ in range(n):
        name = sys.stdin.readline().strip()
        if name in name_counts:
            cnt = name_counts[name]
            print(f"{name}{cnt}")
            name_counts[name] = cnt + 1
        else:
            print("OK")
            name_counts[name] = 1

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read line by line using `sys.stdin.readline()` for efficiency, especially with large input sizes.
- **Dictionary Operations**: The dictionary `name_counts` tracks each username and its registration count. For each username:
  - If it's a new username, it is added to the dictionary with an initial count of 1, and "OK" is printed.
  - If the username exists, the current count is used to generate the new username, which is printed. The count is then incremented for future registrations.
- **Efficiency**: The use of a dictionary ensures that each check and update operation is done in constant average time, leading to an overall time complexity of O(n), which is optimal for the problem constraints.

This solution efficiently handles the registration requests and ensures that each username is unique by generating the appropriate suffix when necessary.
