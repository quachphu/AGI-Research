To solve this problem, Chef needs to repaint his house such that all rooms have the same color with the minimum number of repaints. The solution involves determining the minimum number of rooms that need to be repainted for each possible target color (red, green, blue) and selecting the minimum among these values.

### Approach
1. **Problem Analysis**: Chef can repaint each room using a specific color to achieve the target color based on mixing rules. However, the key insight is that any room not already of the target color can be repainted once to match the target color. Therefore, the minimum number of repaints required for each target color is simply the number of rooms that are not of that color.

2. **Intuition**: For each target color (red, green, blue), count the number of rooms that are already of that color. The minimum repaints needed will be the total number of rooms minus the count of the most frequent color. This is because repainting the rooms not of the target color will each take exactly one repaint.

3. **Algorithm**:
   - Read the number of test cases.
   - For each test case, read the number of rooms and the current color configuration.
   - Count the occurrences of each color (red, green, blue).
   - Calculate the minimum repaints required for each target color by subtracting the count of each color from the total number of rooms.
   - Print the minimum value among these calculations.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    idx = 0
    T = int(input[idx])
    idx += 1
    for _ in range(T):
        N = int(input[idx])
        idx += 1
        S = input[idx]
        idx += 1
        r = S.count('R')
        g = S.count('G')
        b = S.count('B')
        min_repaints = min(N - r, N - g, N - b)
        print(min_repaints)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
- **Counting Colors**: For each test case, the number of occurrences of each color (red, green, blue) is counted using the `count` method.
- **Calculating Minimum Repaints**: The minimum repaints required for each target color is computed by subtracting the count of each color from the total number of rooms. The minimum of these values is printed as the result for each test case.

This approach efficiently determines the minimum repaints needed by leveraging the fact that each room not of the target color requires exactly one repaint, leading to an optimal solution with a time complexity of O(N) per test case.
