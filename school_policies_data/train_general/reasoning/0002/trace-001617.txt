To solve this problem, we need to determine the number of children standing on each square after each child has moved 10^100 times according to the direction written on their respective squares. The key insight is that children will eventually settle into positions where they oscillate between two adjacent squares or come to a stop.

### Approach
1. **Identify Boundaries**: Find all boundaries where an 'R' is followed by an 'L'. These boundaries are critical because children around these points will oscillate between the two adjacent squares.
2. **Group Runs**: Preprocess the input string into contiguous runs of 'R's and 'L's. This helps in efficiently identifying the regions (runs) that contribute to each boundary.
3. **Calculate Contributions**: For each boundary, calculate how many children from the preceding 'R' run and the succeeding 'L' run will end up on each side of the boundary after 10^100 moves. This is determined by the parity of the distance from the boundary.

def generate_runs(s):
    runs = []
    n = len(s)
    if n == 0:
        return runs
    current_char = s[0]
    start = 0
    for i in range(1, n):
        if s[i] != current_char:
            runs.append((current_char, start, i-1))
            current_char = s[i]
            start = i
    runs.append((current_char, start, n-1))
    return runs
