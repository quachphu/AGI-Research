To solve this problem, we need to determine if a given string could be the result of an obfuscation process where variable names are replaced with sequential letters starting from 'a'. The key observation is that the first occurrence of each new character in the string must follow the order 'a', 'b', 'c', etc.

### Approach
1. **Track First Occurrences**: Iterate through the string and collect the order of the first occurrences of each character.
2. **Validate Order**: Check if the collected order of first occurrences matches the sequence 'a', 'b', 'c', ..., up to the number of unique characters in the string.

### Solution Code
```python
s = input().strip()

order = []
seen = set()
for c in s:
    if c not in seen:
        seen.add(c)
        order.append(c)

expected = [chr(ord('a') + i) for i in range(len(order))]

print("YES" if order == expected else "NO")
```

### Explanation
1. **Track First Occurrences**: As we iterate through the string, we maintain a set to track seen characters and a list to record the order of their first appearances.
2. **Validate Order**: After collecting the order of first occurrences, we generate the expected sequence of letters starting from 'a' up to the length of the collected order. If the collected order matches this expected sequence, the string is valid; otherwise, it is not.

This approach efficiently checks the required condition in linear time relative to the length of the input string, ensuring optimal performance.
