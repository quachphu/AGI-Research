To solve this problem, we need to determine the number of permutations of an array such that the resulting sequence is "good". A sequence is considered good if, for every position from 1 to n-1, the bitwise AND of the elements up to that position is equal to the bitwise AND of the elements from that position to the end.

### Approach
1. **Compute Total AND**: The total AND of the entire array must be the same as the AND of any prefix and suffix in a good permutation. This total AND is computed by iterating through all elements of the array.
2. **Count Elements Equal to Total**: Determine how many elements in the array are equal to the total AND. Let this count be `k`.
3. **Check Validity**: If there are fewer than 2 elements equal to the total AND, no valid permutation exists, and the result is 0.
4. **Calculate Permutations**: If there are at least 2 elements equal to the total AND, the number of valid permutations is calculated by:
   - Choosing 2 elements (one for the start and one for the end of the permutation) from the `k` elements.
   - Permuting the remaining `n-2` elements in the middle positions.

### Solution Code
```python
import sys

MOD = 10**9 + 7

def main():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    
    max_n = 200000
    # Precompute factorials modulo MOD up to max_n
    fact = [1] * (max_n + 2)
    for i in range(1, max_n + 1):
        fact[i] = (fact[i-1] * i) % MOD
    
    for _ in range(t):
        n = int(input[ptr])
        ptr += 1
        a = list(map(int, input[ptr:ptr + n]))
        ptr += n
        
        # Compute total AND of the array
        total = a[0]
        for num in a[1:]:
            total &= num
        
        # Count the number of elements equal to total
        k = a.count(total)
        
        if k < 2:
            print(0)
        else:
            res = (k * (k - 1)) % MOD
            res = (res * fact[n - 2]) % MOD
            print(res)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Precompute Factorials**: Factorials up to the maximum possible array size (200,000) are precomputed modulo \(10^9 + 7\) to efficiently calculate permutations.
2. **Reading Input Efficiently**: The input is read all at once for efficiency, especially given the constraints.
3. **Total AND Calculation**: The total AND of the array is computed by iterating through all elements.
4. **Element Count Check**: The count of elements equal to the total AND determines the validity of permutations.
5. **Permutations Calculation**: Using combinatorial mathematics, the number of valid permutations is derived by selecting the first and last elements from the valid elements and permuting the rest.

This approach ensures that we efficiently compute the required values while adhering to the problem constraints and modulo operations for large numbers.
