### Approach
The key insight is to recognize that the minimum number of operations required is determined by the longest gap between consecutive occurrences of any character, including the start and end of the string. This approach ensures that we consider the worst-case scenario for each character, which in turn gives us the minimum number of steps needed to propagate that character throughout the entire string.

1. **Identify Occurrences**: For each unique character in the string, identify the positions where it occurs.
2. **Extend with Virtual Positions**: Add virtual positions at the start (-1) and end (length of the string) to account for gaps from the start to the first occurrence and from the last occurrence to the end.
3. **Calculate Gaps**: Compute the gaps between consecutive positions (both actual and virtual) for each character.
4. **Determine Steps**: The maximum gap for a character minus one gives the number of steps required for that character. The minimum of these values across all characters gives the solution.

### Solution Code
```python
s = input().strip()
n = len(s)
if n == 0:
    print(0)
    exit()
if all(c == s[0] for c in s):
    print(0)
    exit()

min_operations = float('inf')

for c in set(s):
    positions = [i for i, char in enumerate(s) if char == c]
    extended = [-1] + positions + [n]
    max_gap = max(extended[i+1] - extended[i] for i in range(len(extended)-1))
    operations = max_gap - 1
    if operations < min_operations:
        min_operations = operations

print(min_operations)
```
