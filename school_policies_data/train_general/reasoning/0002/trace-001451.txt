### Approach
1. **Understanding the Period Check**: For a substring to have a period `d`, every character at position `i` must be equal to the character at position `i + d` within the substring. This can be verified by comparing the hash values of two ranges: the first part of the substring and the part shifted by `d`.

2. **Segment Tree with Lazy Propagation**: We use a segment tree to efficiently manage range updates and range hash queries. Each node in the segment tree stores the hash of its range, which allows us to quickly compute and compare hash values for different ranges.

3. **Hashing Technique**: We use a polynomial rolling hash to compute the hash values of substrings. This allows us to efficiently compare the hash values of two ranges to check for equality, which indicates the presence of the required period.
