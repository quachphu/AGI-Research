To solve this problem, we need to determine the first occurrence of a multiple of K in the sequence 7, 77, 777, etc. If no such multiple exists, we should return -1.

### Approach
1. **Understanding the Sequence**: The sequence is formed by appending the digit 7 to the previous number. For example, starting with 7, each subsequent number is formed by multiplying the previous number by 10 and adding 7.
2. **Modular Arithmetic Insight**: Directly generating large numbers in the sequence is impractical. Instead, we use modular arithmetic to track the remainder of each number in the sequence when divided by K.
3. **Pigeonhole Principle**: If after K iterations no remainder becomes 0, the sequence will never contain a multiple of K. This is because there are only K possible remainders (0 to K-1), and if none repeat to 0 within K steps, they never will.

### Solution Code
```python
K = int(input())
remainder = 7 % K
if remainder == 0:
    print(1)
else:
    for i in range(2, K + 1):
        remainder = (remainder * 10 + 7) % K
        if remainder == 0:
            print(i)
            exit()
    print(-1)
```

### Explanation
1. **Initial Check**: Compute the remainder of the first term (7) modulo K. If this remainder is 0, print 1 immediately.
2. **Iterative Remainder Calculation**: For each subsequent term, update the remainder using the formula `(current_remainder * 10 + 7) % K`. This avoids handling large numbers directly.
3. **Termination Check**: If the remainder becomes 0 at any iteration, print the current position. If after K iterations no remainder is 0, print -1.

This approach efficiently handles the problem constraints using modular arithmetic and ensures we do not encounter issues with excessively large numbers. The time complexity is O(K), which is feasible given the constraint \(1 \leq K \leq 10^6\).
