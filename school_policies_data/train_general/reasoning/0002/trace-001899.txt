To solve this problem, we need to find the smallest composite number greater than a given number \( n \) for multiple test cases. A composite number is a positive integer that has at least one positive divisor other than 1 and itself. 

### Approach
1. **Understanding Composite Numbers**: Composite numbers are numbers greater than 1 that are not prime. The smallest composite number is 4.
2. **Efficient Checking**: For each number starting from \( n + 1 \), check if it is composite. If the number is even and greater than or equal to 4, it is immediately composite. For odd numbers, check if they have any divisors other than 1 and themselves.
3. **Prime Check Optimization**: To determine if an odd number is composite, check divisibility from 3 up to the square root of the number. This reduces the number of checks needed compared to checking all numbers up to \( n \).

### Solution Code
```python
import sys
import math

def is_composite(m):
    if m <= 1:
        return False
    if m in (2, 3):
        return False
    if m % 2 == 0:
        return m >= 4
    sqrt_m = math.isqrt(m)
    for i in range(3, sqrt_m + 1, 2):
        if m % i == 0:
            return True
    return False

def next_composite(n):
    m = n + 1
    while True:
        if m % 2 == 0:
            if m >= 4:
                return m
        else:
            if is_composite(m):
                return m
        m += 1

t = int(sys.stdin.readline())
for _ in range(t):
    n = int(sys.stdin.readline())
    print(next_composite(n))
```

### Explanation
1. **Reading Input**: The code reads the number of test cases and each subsequent number \( n \).
2. **Finding the Next Composite Number**:
   - Start checking from \( n + 1 \).
   - If the number is even and at least 4, it is composite.
   - For odd numbers, check if they are composite using a helper function `is_composite`.
3. **Helper Function `is_composite`**:
   - Quickly returns `False` for numbers ≤ 1 and primes 2 and 3.
   - Checks if even numbers are composite by verifying they are ≥ 4.
   - For odd numbers, checks divisibility from 3 up to the square root of the number, which optimizes the prime check.

This approach ensures that each number is checked efficiently, leveraging properties of even numbers and optimized trial division for odd numbers, making the solution both correct and efficient for large input sizes.
