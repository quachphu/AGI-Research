To solve this problem, we need to determine the optimal play for two players, X and Y, who take turns drawing cards from a deck to maximize and minimize the score respectively. The score is the absolute difference between the values of the cards they hold when the deck is exhausted.

### Approach
1. **Game Analysis**:
   - X starts with a card Z and Y starts with a card W.
   - Players take turns drawing one or more cards from the top of the deck, replacing their current card with the last one drawn.
   - The game ends when the deck is empty, and the score is the absolute difference between the players' final cards.

2. **Optimal Play**:
   - X aims to maximize the score, while Y aims to minimize it.
   - We use a recursive approach with memoization to explore all possible moves and outcomes efficiently.

3. **Dynamic Programming with Memoization**:
   - Define a recursive function `dfs(pos, other_card, turn)` where:
     - `pos` is the current position in the deck.
     - `other_card` is the value of the opponent's current card.
     - `turn` indicates whose turn it is (0 for X, 1 for Y).
   - The function returns the optimal score from the given state.

4. **State Transitions**:
   - For each turn, the current player considers all possible moves (drawing from 1 to the remaining cards).
   - The next state is determined by the new position in the deck and the new value of the current player's card.

### Solution Code
```python
import sys
from functools import lru_cache

def main():
    N, Z, W = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    
    @lru_cache(maxsize=None)
    def dfs(pos, other_card, turn):
        if pos >= N:
            return 0  # Should not occur as players must draw at least one
        
        if turn == 0:  # X's turn, maximize the score
            max_val = -float('inf')
            for j in range(pos, N):
                current = a[j]
                new_pos = j + 1
                if new_pos >= N:
                    score = abs(current - other_card)
                else:
                    score = dfs(new_pos, current, 1)
                if score > max_val:
                    max_val = score
            return max_val
        else:  # Y's turn, minimize the score
            min_val = float('inf')
            for j in range(pos, N):
                current = a[j]
                new_pos = j + 1
                if new_pos >= N:
                    score = abs(current - other_card)
                else:
                    score = dfs(new_pos, current, 0)
                if score < min_val:
                    min_val = score
            return min_val
    
    # Initial state: pos=0, other_card=W (Y's initial card), turn=0 (X's turn)
    print(dfs(0, W, 0))

if __name__ == '__main__':
    main()
```

- **Recursive Function `dfs`**:

  - **Y's Turn (Minimize)**: Similarly, compute the score for each move and track the minimum score.

- **Memoization**:
  - Using `lru_cache` to store results of previously computed states avoids redundant calculations and improves efficiency.

This approach efficiently explores all possible game states using dynamic programming and memoization, ensuring optimal play from both players while adhering to the constraints.
