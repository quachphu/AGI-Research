To solve this problem, we need to simulate a card game involving multiple participants drawing cards from a pile according to specific rules. The goal is to determine the number of cards each participant has at the end of the game, along with the remaining cards in the field, and output them in the required format.

### Approach
1. **Input Handling**: Read the input datasets until a line with 0 is encountered. Each dataset consists of the number of participants and a string representing the order of cards.
2. **Initialization**: For each dataset, initialize the participants' card counts and the field count to zero.
3. **Simulation**: Process each card in the given order:
   - **Man (M)**: The participant who draws the card keeps it, incrementing their card count.
   - **Shaven (S)**: The participant places all their cards (including the drawn S) into the field, resetting their card count to zero.
   - **Princess (L)**: The participant takes all cards from the field (including the drawn L), adding them to their count and resetting the field to zero.
4. **Result Compilation**: After processing all cards, sort the participants' card counts in ascending order and append the remaining field count.
5. **Output**: Print the sorted results for each dataset.

### Solution Code
```python
import sys

def process_game():
    while True:
        line = sys.stdin.readline()
        if not line:
            break
        N = int(line.strip())
        if N == 0:
            break
        cards = sys.stdin.readline().strip()
        players = [0] * N
        field = 0
        for i in range(100):
            current_player = i % N
            card = cards[i]
            if card == 'M':
                players[current_player] += 1
            elif card == 'S':
                contribution = players[current_player] + 1
                field += contribution
                players[current_player] = 0
            elif card == 'L':
                players[current_player] += field + 1
                field = 0
        sorted_players = sorted(players)
        print(' '.join(map(str, sorted_players)) + ' ' + str(field))

process_game()
```

- **Input Handling**: The code reads input lines until it encounters a zero, indicating the end of the datasets.
- **Simulation**: For each card drawn, the current participant is determined using modulo arithmetic to cycle through participants. The card type determines the action:
  - **M**: Increment the participant's card count.
  - **S**: Transfer all of the participant's cards plus the drawn S to the field.
