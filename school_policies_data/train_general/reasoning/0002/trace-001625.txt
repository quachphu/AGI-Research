To solve this problem, we need to determine the maximum Manhattan distance between any two buildings ('B') on a grid representing the Hokkaido University Sapporo Campus. The Manhattan distance between two points (i, j) and (i', j') is given by |i - i'| + |j - j'|.

### Approach
The key insight to efficiently solve this problem is to recognize that the Manhattan distance can be maximized by considering two transformed coordinates: (i + j) and (i - j). For all buildings, we compute the maximum and minimum values of these transformed coordinates. The maximum Manhattan distance will be the larger of the differences between the maximum and minimum values of these two transformed coordinates.

1. **Collect Coordinates**: Traverse the grid to collect the coordinates of all buildings ('B').
2. **Compute Transformed Values**: For each building's coordinates (i, j), compute the values (i + j) and (i - j).
3. **Determine Max and Min Values**: Track the maximum and minimum values of both (i + j) and (i - j) across all buildings.
4. **Calculate Distances**: The maximum Manhattan distance is the maximum of the differences between the maximum and minimum values of the transformed coordinates.

### Solution Code
```python
H, W = map(int, input().split())

max_sum = -float('inf')
min_sum = float('inf')
max_diff = -float('inf')
min_diff = float('inf')

for i in range(H):
    line = input().strip()
    for j in range(W):
        if line[j] == 'B':
            actual_i = i + 1
            actual_j = j + 1
            s = actual_i + actual_j
            d = actual_i - actual_j
            if s > max_sum:
                max_sum = s
            if s < min_sum:
                min_sum = s
            if d > max_diff:
                max_diff = d
            if d < min_diff:
                min_diff = d

distance = max(max_sum - min_sum, max_diff - min_diff)
print(distance)
```

### Explanation
1. **Reading Input**: The grid dimensions (H and W) are read first, followed by the grid itself.
2. **Tracking Transformed Values**: As we iterate through each cell in the grid, we check if it contains a building ('B'). For each building, we convert the 0-based indices from the input to 1-based indices and compute the transformed values (i + j) and (i - j).
3. **Updating Max and Min Values**: For each building, we update the maximum and minimum values of the transformed coordinates.
4. **Calculating Result**: The result is the maximum of the differences between the maximum and minimum values of the transformed coordinates, which gives the maximum Manhattan distance between any two buildings.

This approach ensures that we efficiently compute the result in O(H * W) time, which is optimal given the problem constraints.
