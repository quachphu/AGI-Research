To solve this problem, we need to determine the amount of change received when paying for a product using the minimum number of 1000-yen bills. The goal is to find the smallest multiple of 1000 that is equal to or greater than the product's price and then compute the difference between this amount and the product's price.

### Approach
1. **Understanding the Problem**: The problem requires calculating the change when paying with the minimum number of 1000-yen bills. If the price is not a multiple of 1000, the next higher multiple of 1000 will be used to determine the change.
2. **Key Insight**: The change can be computed by finding the remainder when the price is divided by 1000. If the remainder is zero, the price is already a multiple of 1000, and no change is needed. Otherwise, the change is the difference between 1000 and this remainder.
3. **Mathematical Formulation**:
   - Compute the remainder of the price when divided by 1000.
   - If the remainder is zero, the change is zero.
   - Otherwise, the change is 1000 minus the remainder.

### Solution Code
```python
n = int(input())
remainder = n % 1000
print(0 if remainder == 0 else 1000 - remainder)
```

### Explanation
1. **Reading Input**: The input is read as an integer using `input()` and converted to an integer.
2. **Calculating Remainder**: The remainder when the price is divided by 1000 is calculated using the modulus operator `%`.
3. **Determining Change**: If the remainder is zero, it means the price is a multiple of 1000, so the change is zero. Otherwise, the change is computed as `1000 - remainder`, which gives the difference between the next multiple of 1000 and the price.

This approach efficiently computes the change using basic arithmetic operations, ensuring optimal performance even for the upper constraint values.
