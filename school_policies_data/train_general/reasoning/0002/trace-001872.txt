To solve this problem, we need to determine how many queens on a chessboard threaten exactly `i` other queens for each `i` from 0 to 8. Each queen can move horizontally, vertically, or diagonally, and we need to count the number of other queens each queen can attack in these directions.

### Approach
1. **Group Queens by Directions**: We categorize each queen into four groups based on their row, column, and two diagonals (sum and difference of row and column).
2. **Sort Each Group**: For each group, sort the elements to efficiently determine the nearest neighbors in each direction.
3. **Check Neighbors**: For each queen, check its position in each sorted group to determine if there are neighbors in the left, right, up, down, and both diagonal directions. Each neighbor found contributes to the threat count of the queen.

### Solution Code
```python
import bisect

n, m = map(int, input().split())
queens = [tuple(map(int, input().split())) for _ in range(m)]

rows = {}
columns = {}
diag1 = {}  # key: r - c
diag2 = {}  # key: r + c

for r, c in queens:
    if r not in rows:
        rows[r] = []
    rows[r].append(c)
    
    if c not in columns:
        columns[c] = []
    columns[c].append(r)
    
    key = r - c
    if key not in diag1:
        diag1[key] = []
    diag1[key].append(r)
    
    key = r + c
    if key not in diag2:
        diag2[key] = []
    diag2[key].append(r)

# Sort all the lists
for r in rows:
    rows[r].sort()
for c in columns:
    columns[c].sort()
for k in diag1:
    diag1[k].sort()
for k in diag2:
    diag2[k].sort()

counts = [0] * 9

for r, c in queens:
    w = 0
    
    # Check row directions
    cols = rows[r]
    idx = bisect.bisect_left(cols, c)
    if idx > 0:
        w += 1
    if idx < len(cols) - 1:
        w += 1
    
    # Check column directions
    rs = columns[c]
    idx = bisect.bisect_left(rs, r)
    if idx > 0:
        w += 1
    if idx < len(rs) - 1:
        w += 1
    
    # Check diagonal1 (r - c)
    key_d1 = r - c
    d1_list = diag1[key_d1]
    idx = bisect.bisect_left(d1_list, r)
    if idx > 0:
        w += 1
    if idx < len(d1_list) - 1:
        w += 1
    
    # Check diagonal2 (r + c)
    key_d2 = r + c
    d2_list = diag2[key_d2]
    idx = bisect.bisect_left(d2_list, r)
    if idx > 0:
        w += 1
    if idx < len(d2_list) - 1:
        w += 1
    
    counts[w] += 1

print(' '.join(map(str, counts)))
```

### Explanation
1. **Reading Input**: The input is read and parsed into a list of queen positions.
2. **Grouping Queens**: Queens are grouped into rows, columns, and two diagonals. Each group is stored in a dictionary with the appropriate key.
3. **Sorting Groups**: Each group is sorted to allow efficient neighbor checks using binary search.
4. **Checking Directions**: For each queen, binary search is used to find its position in each sorted group. Neighbors in each direction (left, right, up, down, and diagonals) are checked, and the threat count is updated accordingly.
5. **Counting Threats**: The number of queens with each threat count is tallied and printed.

This approach ensures efficient processing by leveraging sorting and binary search, resulting in a time complexity that is manageable even for large input sizes.
