To solve this problem, we need to determine if the given number \( m \) is the next prime number after the prime number \( n \). This involves checking two conditions: first, whether \( m \) itself is a prime number, and second, whether there are no prime numbers between \( n \) and \( m \).

### Approach
1. **Check if \( m \) is a prime number**: If \( m \) is not a prime number, the answer is immediately "NO".
2. **Check for primes between \( n \) and \( m \)**: If there exists any prime number in the range \( n+1 \) to \( m-1 \), then \( m \) cannot be the next prime after \( n \), so the answer is "NO".
3. **Determine the result**: If both checks pass (i.e., \( m \) is prime and there are no primes between \( n \) and \( m \)), the answer is "YES".

### Solution Code
```python
def is_prime(num):
    if num < 2:
        return False
    for i in range(2, int(num ** 0.5) + 1):
        if num % i == 0:
            return False
    return True

n, m = map(int, input().split())

if not is_prime(m):
    print("NO")
else:
    has_prime = False
    for num in range(n + 1, m):
        if is_prime(num):
            has_prime = True
            break
    print("NO" if has_prime else "YES")
```

### Explanation
1. **Prime Check Function (`is_prime`)**: This function checks if a given number is prime by testing divisibility from 2 up to the square root of the number. If any divisor is found, the number is not prime.
2. **Input Handling**: The input values \( n \) and \( m \) are read and parsed.
3. **Check for \( m \) being Prime**: If \( m \) is not a prime, print "NO".
4. **Check for Intermediate Primes**: Iterate through all numbers between \( n+1 \) and \( m-1 \). If any of these numbers is prime, set a flag indicating the presence of an intermediate prime.
5. **Result Determination**: Based on the presence of intermediate primes, print "YES" or "NO".

This approach efficiently checks the necessary conditions using a helper function to determine primality and iterates through the relevant range to ensure correctness.
