To solve this problem, we need to efficiently handle multiple subtree increment operations on a rooted tree and determine the final values of each vertex's counter. Given the constraints, a direct approach would be too slow, so we use a combination of Depth-First Search (DFS) and a difference array to efficiently compute the results.

### Approach
1. **Tree Representation**: Represent the tree using an adjacency list and determine the parent-child relationships using a BFS starting from the root (vertex 1).
2. **DFS for In-Time and Out-Time**: Perform an iterative DFS to compute the in-time and out-time for each vertex. These times help in identifying the contiguous interval of vertices in the subtree rooted at any given vertex.
3. **Difference Array for Range Updates**: Use a difference array to efficiently apply range updates (subtree increments) in O(1) time per operation.
4. **Prefix Sum Calculation**: Compute the prefix sum of the difference array to get the final values for each vertex.

### Solution Code
```python
import sys
from collections import deque

def main():
    sys.setrecursionlimit(1 << 25)
    N, Q = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(N+1)]
    for _ in range(N-1):
        a, b = map(int, sys.stdin.readline().split())
        adj[a].append(b)
        adj[b].append(a)
    
    # Build children structure using BFS
    parent = [0] * (N + 1)
    parent[1] = -1  # Root's parent is marked as -1
    children = [[] for _ in range(N + 1)]
    q = deque([1])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if parent[u] != v:  # Check to avoid parent node
                if parent[v] == 0:  # Not visited yet
                    parent[v] = u
                    children[u].append(v)
                    q.append(v)
    
    # Compute in_time and out_time using iterative DFS
    in_time = [0] * (N + 1)
    out_time = [0] * (N + 1)
    current_time = 1
    stack = [(1, False)]
    while stack:
        u, visited = stack.pop()
        if not visited:
            in_time[u] = current_time
            current_time += 1
            stack.append((u, True))
            # Push children in reversed order to process them in original order
            for v in reversed(children[u]):
                stack.append((v, False))
        else:
            out_time[u] = current_time - 1
    
    # Process each query and update the difference array
    diff = [0] * (N + 2)  # 1-based to N, and R+1 can be N+1
    for _ in range(Q):
        p, x = map(int, sys.stdin.readline().split())
        L = in_time[p]
        R = out_time[p]
        diff[L] += x
        diff[R + 1] -= x
    
    # Compute prefix sum to get the final values
    prefix = [0] * (N + 1)
    for i in range(1, N + 1):
        prefix[i] = prefix[i - 1] + diff[i]
    
    # Prepare the answer based on in_time of each vertex
    ans = []
    for u in range(1, N + 1):
        ans.append(str(prefix[in_time[u]]))
    
    print(' '.join(ans))

if __name__ == '__main__':
    main()
```

### Explanation
1. **Tree Construction**: We first build the adjacency list of the tree and then determine the parent-child relationships using BFS starting from the root (vertex 1).
2. **DFS for Time Intervals**: Using an iterative DFS, we compute the in-time (when a node is first visited) and out-time (after all descendants are processed) for each node. These times help in identifying the contiguous interval of nodes in any subtree.
3. **Difference Array**: For each subtree increment operation, we update the difference array at the start and end+1 positions of the interval. This allows us to efficiently apply range updates.
4. **Prefix Sum**: The prefix sum of the difference array gives the final values for each node, which are then printed based on their in-time values.

This approach ensures that each operation is handled in O(1) time, leading to an overall time complexity of O(N + Q), which is efficient for the given constraints.
