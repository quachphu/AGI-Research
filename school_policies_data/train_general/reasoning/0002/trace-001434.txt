To solve this problem, we need to find the longest contiguous segment of houses where no two adjacent houses have the same color. This can be efficiently determined using a linear scan approach.

### Approach
1. **Problem Analysis**: The problem requires identifying the longest contiguous subarray where each consecutive element is different. This can be achieved by iterating through the array and maintaining a running count of the current valid segment length.
2. **Intuition**: As we traverse the array, we keep track of the current segment length where adjacent elements are different. Whenever we encounter two consecutive elements that are the same, we reset the current segment length. We also keep updating the maximum segment length found so far.
3. **Algorithm**: 
   - Initialize `max_len` and `current_len` to 1 since the minimum length of a valid segment is 1 (a single house).
   - Traverse the array starting from the second element. For each element, check if it is different from the previous element.
   - If they are different, increment the `current_len`. If they are the same, reset `current_len` to 1.
   - Update `max_len` whenever `current_len` exceeds `max_len`.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    k = int(input[1])
    a = list(map(int, input[2:2+n]))
    max_len = 1
    current_len = 1
    for i in range(1, n):
        if a[i] != a[i-1]:
            current_len += 1
        else:
            current_len = 1
        if current_len > max_len:
            max_len = current_len
    print(max_len)

main()
```

### Explanation
- **Reading Input**: The input is read from standard input, where the first line contains the number of houses `n` and the number of colors `k`. The second line contains the colors of the houses.
- **Initialization**: We start with `max_len` and `current_len` set to 1, as the minimum valid segment length is 1.
- **Traversal**: We iterate from the second house to the last. For each house, we check if its color is different from the previous house. If yes, we extend the current valid segment. If not, we reset the current segment length to 1.
- **Updating Maximum Length**: During each iteration, we update the maximum length if the current segment length exceeds the previously recorded maximum.

This approach efficiently computes the result in O(n) time complexity, which is optimal for the given problem constraints.
