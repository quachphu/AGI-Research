To solve this problem, we need to find the maximum sum of a submatrix within a given n x n matrix. The submatrix must consist of consecutive elements in both vertical and horizontal directions. The solution involves efficiently exploring all possible submatrices using a combination of prefix sums and Kadane's algorithm.

### Approach
1. **Prefix Sum Calculation**: Precompute the prefix sums for each row of the matrix. This allows quick calculation of the sum of elements between any two columns in a row.
2. **Iterate Over Column Pairs**: For each possible pair of left and right columns, compute the sum of elements between these columns for each row using the prefix sums.
3. **Kadane's Algorithm**: For each pair of columns, apply Kadane's algorithm on the array of row sums to find the maximum sum of a contiguous subarray. This effectively finds the maximum sum submatrix for the current column pair.
4. **Track Maximum Sum**: Keep track of the maximum sum encountered across all column pairs and their corresponding subarrays.

### Solution Code
```python
n = int(input())
matrix = []
for _ in range(n):
    row = list(map(int, input().split()))
    matrix.append(row)

# Precompute prefix sums for each row
prefix_sums = []
for row in matrix:
    ps = [0]
    current_sum = 0
    for num in row:
        current_sum += num
        ps.append(current_sum)
    prefix_sums.append(ps)

def kadane(arr):
    if not arr:
        return -float('inf')
    max_current = max_global = arr[0]
    for num in arr[1:]:
        max_current = max(num, max_current + num)
        max_global = max(max_global, max_current)
    return max_global

max_sum = -float('inf')

for left in range(n):
    for right in range(left, n):
        current_sums = []
        for i in range(n):
            sum_i = prefix_sums[i][right + 1] - prefix_sums[i][left]
            current_sums.append(sum_i)
        current_max = kadane(current_sums)
        if current_max > max_sum:
            max_sum = current_max

print(max_sum)
```

### Explanation
1. **Reading Input**: The input is read and stored in a matrix.
2. **Prefix Sums**: For each row, a prefix sum array is computed to allow O(1) sum queries between any two columns.
3. **Column Pairs Iteration**: For each possible left and right column pair, the sum of elements between these columns for each row is computed using the prefix sums.
4. **Kadane's Algorithm**: This algorithm is applied to the array of row sums to find the maximum sum of a contiguous subarray, which corresponds to the maximum sum submatrix for the current column pair.
5. **Tracking Maximum Sum**: The maximum sum from all column pairs is tracked and printed as the result.

This approach efficiently reduces the problem complexity to O(n^3), making it feasible for matrices up to 100x100.
