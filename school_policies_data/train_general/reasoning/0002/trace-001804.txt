To solve this problem, we need to determine if the digit 9 is present in a given two-digit integer. The solution involves checking each digit of the number to see if either of them is 9.

### Approach
The approach is straightforward:
1. Read the input as a string.
2. Check if either the first or second character of the string is '9'.
3. Print "Yes" if either character is '9', otherwise print "No".

This method is efficient because it directly checks the characters of the input string without converting it to an integer, which simplifies the process and avoids unnecessary computations.

### Solution Code

```python
def main():
    n = input().strip()
    print("Yes" if '9' in n else "No")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read as a string using `input().strip()`, which ensures any leading or trailing whitespace is removed.
2. **Checking for '9'**: By checking if '9' is present in the string, we directly determine if either the tens or units place of the number contains the digit 9.
3. **Output Result**: Based on the presence of '9' in the string, the appropriate result ("Yes" or "No") is printed.

This approach efficiently leverages string operations to check for the presence of the digit 9, ensuring clarity and simplicity in the solution.
