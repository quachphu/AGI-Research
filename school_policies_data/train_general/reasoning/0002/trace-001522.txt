To solve this problem, we need to determine the winner of a game where players accumulate points over multiple rounds. The winner of each round gets points added to their total, while other players receive zero points for that round. The player with the highest total points after all rounds wins the game. 

### Approach
1. **Input Reading**: Read all input data at once and split it into tokens for efficient processing.
2. **Accumulating Scores**: Use a dictionary to keep track of each player's total score. For each round, update the score of the winning player in the dictionary.
3. **Determine the Winner**: After processing all rounds for a test case, iterate through the dictionary to find the player with the highest score. Since the problem guarantees a unique winner, we can safely return the first player with the maximum score encountered.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    input_data = sys.stdin.read().split()
    ptr = 0
    T = int(input_data[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input_data[ptr])
        ptr += 1
        scores = defaultdict(int)
        for _ in range(N):
            name = input_data[ptr]
            score = int(input_data[ptr + 1])
            ptr += 2
            scores[name] += score
        max_score = -1
        winner = ""
        for name, total in scores.items():
            if total > max_score:
                max_score = total
                winner = name
        print(f"{winner} {max_score}")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into tokens. This allows us to efficiently process each token sequentially using a pointer.
2. **Processing Each Test Case**: For each test case, we read the number of rounds and then process each round to update the scores in a dictionary. The dictionary keys are player names, and the values are their accumulated scores.
3. **Finding the Winner**: After accumulating all scores for a test case, we iterate through the dictionary to find the player with the highest score. This player is declared the winner for that test case.

This approach ensures that we efficiently handle multiple test cases and correctly determine the winner for each game based on the accumulated scores.
