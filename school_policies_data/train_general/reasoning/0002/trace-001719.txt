To solve this problem, we need to reduce the quantities of ingredients in a recipe such that the ratios of the ingredients remain the same, but all quantities are whole numbers and as small as possible. The key is to find the greatest common divisor (GCD) of all ingredient quantities and then divide each quantity by this GCD.

### Approach
1. **Read Input**: Read the number of test cases and the ingredient quantities for each test case.
2. **Compute GCD**: For each test case, compute the GCD of all ingredient quantities. This can be efficiently done using the `reduce` function along with the `math.gcd` method.
3. **Scale Down**: Divide each ingredient quantity by the computed GCD to get the smallest possible whole numbers while maintaining the same ratios.
4. **Output Result**: Print the scaled-down quantities for each test case.

### Solution Code
```python
import sys
import math
from functools import reduce

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        parts = list(map(int, sys.stdin.readline().split()))
        nums = parts[1:]
        gcd_all = reduce(math.gcd, nums)
        scaled = [x // gcd_all for x in nums]
        print(' '.join(map(str, scaled)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using standard input. The first value is the number of test cases. For each test case, we read the number of ingredients followed by their quantities.
2. **Computing GCD**: The `reduce` function is used to apply the `math.gcd` function across all ingredient quantities. This iteratively computes the GCD of the current result with the next ingredient quantity.
3. **Scaling Down**: Each ingredient quantity is divided by the computed GCD, ensuring that the resulting values are the smallest whole numbers that maintain the original ratios.
4. **Output**: The scaled-down quantities are printed as space-separated values for each test case.

This approach efficiently computes the required quantities using the GCD, ensuring optimal performance and correctness.
