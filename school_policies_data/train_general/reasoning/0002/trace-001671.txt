To solve this problem, we need to determine if a jumper can complete a round trip from the left-most trampoline to the right-most trampoline and back again using only allowed jumps. Each trampoline allows jumps within a specified maximum horizontal distance.

### Approach
The solution involves two main checks:
1. **Forward Journey Check**: Determine if the jumper can move from the left-most trampoline to the right-most trampoline.
2. **Backward Journey Check**: Determine if the jumper can return from the right-most trampoline back to the left-most trampoline.

**Forward Journey Check**:
- Track the maximum reachable trampoline starting from the left-most trampoline. If the maximum reachable trampoline is the right-most trampoline, the forward journey is possible.

**Backward Journey Check**:
- Track the minimum reachable trampoline starting from the right-most trampoline. If the minimum reachable trampoline is the left-most trampoline, the backward journey is possible.

Both checks are performed using a greedy approach to efficiently determine reachability in linear time.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    d = list(map(int, input[1:N+1]))
    
    # Check forward journey
    max_reach_forward = 1
    for i in range(1, N + 1):
        if i > max_reach_forward:
            break
        step = d[i-1] // 10
        new_reach = i + step
        if new_reach > max_reach_forward:
            max_reach_forward = new_reach
        if max_reach_forward >= N:
            break
    
    if max_reach_forward < N:
        print("no")
        return
    
    # Check backward journey
    current_min_backward = N
    for i in range(N, 0, -1):
        if i < current_min_backward:
            continue
        step = d[i-1] // 10
        new_min = max(1, i - step)
        if new_min < current_min_backward:
            current_min_backward = new_min
        if current_min_backward == 1:
            break
    
    print("yes" if current_min_backward <= 1 else "no")

main()
```

### Explanation
1. **Forward Journey Check**:
   - Start from the first trampoline and iteratively determine the farthest trampoline reachable using the allowed jumps. If we can reach the last trampoline, proceed to the backward check.

2. **Backward Journey Check**:
   - Start from the last trampoline and iteratively determine the nearest trampoline reachable towards the left. If we can reach the first trampoline, the round trip is possible.

The solution efficiently checks both directions using a greedy approach, ensuring linear time complexity O(N), making it suitable for large input sizes up to 300,000 trampolines.
