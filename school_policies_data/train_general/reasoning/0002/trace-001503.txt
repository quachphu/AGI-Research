To solve this problem, we need to find three displays along a road such that their font sizes are in strictly increasing order and their total rental cost is minimized. If no such triplet exists, we should return -1.

### Approach
1. **Precompute Minimum Costs**:
   - For each display, compute the minimum rental cost of a display to its left with a smaller font size.
   - Similarly, compute the minimum rental cost of a display to its right with a larger font size.

2. **Check Triplets**:
   - For each display, check if there exists a valid triplet (i, j, k) such that i < j < k. The validity is determined by the precomputed minimum costs from the left and right.

### Solution Code
```python
n = int(input())
s = list(map(int, input().split()))
c = list(map(int, input().split()))

left_min = [float('inf')] * n
for j in range(n):
    min_cost = float('inf')
    for i in range(j):
        if s[i] < s[j] and c[i] < min_cost:
            min_cost = c[i]
    left_min[j] = min_cost

right_min = [float('inf')] * n
for j in range(n):
    min_cost = float('inf')
    for k in range(j + 1, n):
        if s[k] > s[j] and c[k] < min_cost:
            min_cost = c[k]
    right_min[j] = min_cost

min_total = float('inf')
for j in range(n):
    if left_min[j] != float('inf') and right_min[j] != float('inf'):
        total = left_min[j] + c[j] + right_min[j]
        if total < min_total:
            min_total = total

print(-1 if min_total == float('inf') else min_total)
```

### Explanation
1. **Precompute Left Minimum Costs**:
   - For each display `j`, iterate through all previous displays `i` (where `i < j`) to find the minimum rental cost of a display with a smaller font size. This is stored in `left_min[j]`.

2. **Precompute Right Minimum Costs**:
   - For each display `j`, iterate through all subsequent displays `k` (where `k > j`) to find the minimum rental cost of a display with a larger font size. This is stored in `right_min[j]`.

3. **Check Valid Triplets**:
   - For each display `j`, if there are valid left and right displays (i.e., `left_min[j]` and `right_min[j]` are not infinity), compute the total rental cost for the triplet (i, j, k) and track the minimum total cost.

This approach ensures that we efficiently find the optimal triplet in O(n^2) time, which is feasible for the given constraints.
