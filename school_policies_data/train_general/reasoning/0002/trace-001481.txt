To solve this problem, we need to determine the type of poker hand from a given set of five cards. The solution involves checking each hand against the hierarchy of poker hands from the highest (royal flush) to the lowest (high card).

### Approach
1. **Parse Input:** Read the number of test cases and each hand of five cards.
2. **Convert Ranks and Suits:** Convert each card's rank to a numerical value for easier comparison and note the suits.
3. **Check Hand Types:** Use a series of checks to determine the type of hand starting from the highest possible (royal flush) down to the lowest (high card). The checks are performed in the following order:
   - **Royal Flush:** Check if the hand is a straight flush with ranks 10, J, Q, K, A.
   - **Straight Flush:** Check if all cards are the same suit and form a consecutive sequence.
   - **Four of a Kind:** Check for four cards of the same rank.
   - **Full House:** Check for three cards of one rank and two of another.
   - **Flush:** Check if all cards are the same suit but not a straight flush.
   - **Straight:** Check if the cards form a consecutive sequence, considering Ace as either high or low.
   - **Three of a Kind:** Check for three cards of the same rank.
   - **Two Pairs:** Check for two different pairs.
   - **Pair:** Check for a single pair.
   - **High Card:** If none of the above checks pass, the hand is classified as high card.
