To solve this problem, we need to determine if there exists an element in an array such that the sum of the elements on its left is equal to the sum of the elements on its right. This check needs to be performed for each element in the array efficiently to handle large input sizes.

### Approach
1. **Read Input Efficiently**: Given the constraints, we need to read input efficiently. Using `sys.stdin.read()` allows us to read all input at once and split it into a list for quick access.
2. **Total Sum Calculation**: Compute the total sum of the array once. This helps in calculating the right sum quickly for each element.
3. **Left and Right Sum Tracking**: As we iterate through each element, maintain a running sum of the elements to the left. The right sum can be derived from the total sum, left sum, and the current element.
4. **Check Equality**: For each element, check if the left sum equals the right sum. If found, print "YES" and exit early; otherwise, continue until the end of the array.

### Solution Code
```python
def solve():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        A = list(map(int, input[ptr:ptr + N]))
        ptr += N
        total_sum = sum(A)
        left_sum = 0
        found = False
        for num in A:
            right_sum = total_sum - left_sum - num
            if left_sum == right_sum:
                found = True
                break
            left_sum += num
        print("YES" if found else "NO")

solve()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings for efficient access. This avoids multiple I/O operations which can be slow.
2. **Total Sum Calculation**: The total sum of the array is calculated once, which is used to determine the right sum for each element in constant time.
3. **Iterating Through Elements**: For each element, the left sum is tracked incrementally. The right sum is computed by subtracting the left sum and the current element from the total sum.
4. **Early Exit**: If at any point the left sum equals the right sum, the function immediately prints "YES" and moves to the next test case. If no such element is found after checking all elements, it prints "NO".

This approach ensures that each element is checked in O(1) time after an initial O(N) sum calculation, leading to an overall time complexity of O(N) per test case, which is efficient for large input sizes.
