To solve this problem, we need to determine the integers written on the scarves of each Snuke Cat based on the XOR values they computed, excluding their own scarf. 

### Approach
1. **Understanding XOR Relationships**: Each Snuke Cat's computed XOR value (a_i) is the XOR of all other cats' scarf values. By leveraging the properties of XOR, we can derive the original values.
2. **Total XOR Calculation**: Compute the XOR of all given a_i values. This total XOR (let's call it `total_xor`) is equivalent to the XOR of all original scarf values. This is because each original value appears an odd number of times (exactly N-1 times, where N is even) in the XOR of all a_i values.
3. **Deriving Original Values**: Using `total_xor`, each original scarf value can be derived by XORing the corresponding a_i with `total_xor`. This works because the XOR operation is both associative and commutative, allowing us to reverse the effect of excluding each value once.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    N = int(input[0])
    a = list(map(int, input[1:N+1]))
    total_xor = 0
    for num in a:
        total_xor ^= num
    x = [num ^ total_xor for num in a]
    print(' '.join(map(str, x)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into an integer list where the first element is N (number of cats) and the subsequent elements are the XOR values computed by each cat.
2. **Computing Total XOR**: We compute the XOR of all given a_i values. This gives us `total_xor`, which is the XOR of all original scarf values.
3. **Calculating Original Values**: For each a_i, the original scarf value is found by XORing a_i with `total_xor`. This step effectively reverses the exclusion of each value from the XOR computation.
4. **Output**: The derived original values are printed in the required format.

This approach efficiently computes the solution in linear time, O(N), making it suitable for the upper constraint of N up to 200,000.
