To solve this problem, we need to determine the minimum number of operations required to make all piles of coins equal in size using two types of operations: removing coins from a pile or adding coins to a pile. The key insight is that the optimal target value for each pile is the one that already appears most frequently, as this minimizes the number of operations needed.

### Approach
1. **Understanding the Problem**: The goal is to make all piles of coins equal with the minimum number of operations. Each operation (either adding or removing coins) counts as one per pile.
2. **Key Insight**: The optimal target value is the one that appears most frequently in the current configuration of piles. This is because the number of operations required is minimized when the target value is the mode of the list.
3. **Algorithm**:
   - For each test case, read the number of piles and their respective coin counts.
   - Use a frequency counter to determine how often each coin count appears.
   - Identify the maximum frequency of any coin count.
   - The minimum number of operations required is the total number of piles minus the maximum frequency (since the most frequent count already matches the target for those piles).

### Solution Code
```python
import sys
from collections import Counter

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        a = list(map(int, sys.stdin.readline().split()))
        cnt = Counter(a)
        max_freq = max(cnt.values())
        print(n - max_freq)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads the number of test cases, followed by the number of piles and their respective coin counts for each test case.
2. **Frequency Counting**: Using the `Counter` from the `collections` module, we count how many times each coin count appears in the list.
3. **Determine Maximum Frequency**: The maximum frequency of any coin count is found, which tells us how many piles already match the optimal target value.
4. **Calculate Minimum Operations**: The minimum number of operations is calculated as the total number of piles minus the maximum frequency. This gives the number of piles that need to be adjusted to match the most frequent coin count.

This approach ensures that we efficiently determine the minimum operations required by leveraging the mode of the list, resulting in an optimal solution with linear time complexity relative to the number of piles.
