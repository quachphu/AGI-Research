To solve this problem, we need to reconstruct a graph from a given array of shortest distances such that each vertex has at most k edges. The solution involves validating the input array and constructing the graph using a BFS-like approach to ensure the shortest distances are maintained.

### Approach
1. **Validation Checks**:
   - Ensure there is exactly one vertex with a distance of 0 (the root).
   - Ensure that for every vertex with distance `d`, there exists at least one vertex with distance `d-1`.
   - Check that the number of vertices at each distance level does not exceed the maximum allowed by the problem constraints.

2. **Constructing the Graph**:
   - Group vertices by their distance from the root.
   - For each vertex in a non-root layer, connect it to a vertex in the previous layer, ensuring each vertex does not exceed the maximum allowed edges (k).

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n, k = map(int, sys.stdin.readline().split())
    d = list(map(int, sys.stdin.readline().split()))
    
    # Check there's exactly one root (d=0)
    root = None
    roots = [i+1 for i in range(n) if d[i] == 0]
    if len(roots) != 1:
        print(-1)
        return
    root = roots[0]
    
    # Group nodes by their distance
    layers = defaultdict(list)
    for i in range(n):
        layers[d[i]].append(i+1)  # node indices are 1-based
    
    # Check all d[i] >=0 (given in input)
    max_d = max(d)
    # Check that layers are contiguous
    for dist in range(1, max_d+1):
        if dist-1 not in layers:
            print(-1)
            return
    
    # Check layer counts
    sorted_dists = sorted(layers.keys())
    if sorted_dists[0] != 0:
        print(-1)
        return
    for i in range(1, len(sorted_dists)):
        if sorted_dists[i] != sorted_dists[i-1] + 1:
            print(-1)
            return
    
    # Now check each layer's size constraints
    for dist in sorted_dists[1:]:
        prev_dist = dist - 1
        current_size = len(layers[dist])
        prev_size = len(layers[prev_dist])
        if dist == 1:
            if current_size > k:
                print(-1)
                return
        else:
            max_allowed = prev_size * (k-1)
            if current_size > max_allowed:
                print(-1)
                return
    
    # Now build the edges
    edges = []
    prev_layer = [root]
    for dist in sorted_dists[1:]:
        current_layer = layers[dist]
        if dist == 1:
            # Connect all current to root
            for node in current_layer:
                edges.append((root, node))
        else:
            # Connect each node in current_layer to a parent in prev_layer
            parent_nodes = layers[dist-1]
            for i, node in enumerate(current_layer):
                parent_idx = i // (k-1)
                parent = parent_nodes[parent_idx]
                edges.append((parent, node))
        prev_layer = current_layer
    
    # Output
    print(len(edges))
    for a, b in edges:
        print(a, b)
    
if __name__ == "__main__":
    main()
```

### Explanation
1. **Validation Checks**:
   - The code first checks if there is exactly one root node (vertex with distance 0).
   - It ensures that each vertex has a valid distance and that the layers of vertices are contiguous.

2. **Graph Construction**:
   - The vertices are grouped by their distance from the root.
   - For each layer, vertices are connected to vertices in the previous layer while ensuring no vertex exceeds the maximum allowed edges (k).

This approach efficiently constructs the graph by leveraging BFS layers and ensuring each vertex's degree constraints are respected, thus maintaining the shortest path distances as given.
