To solve this problem, we need to determine the minimum number of contiguous subarray reversals required to transform Kevin's array into one where all neighboring elements are different. If it's impossible to achieve such an array, we should return -1.

### Approach
1. **Frequency Check**: First, check if it's possible to rearrange the array such that no two adjacent elements are the same. This is determined by ensuring that no element's frequency exceeds `(N + 1) // 2`.
2. **Count Consecutive Duplicates**: If the array is already valid (no consecutive duplicates), return 0. Otherwise, count the number of consecutive duplicate pairs in the array.
3. **Calculate Minimum Reversals**: The minimum number of reversals required is determined by the formula `(count + 1) // 2`, where `count` is the number of consecutive duplicate pairs. This formula works because each reversal can potentially fix up to two consecutive duplicate pairs.

### Solution Code
```python
from collections import defaultdict

def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    
    # Check frequency condition
    freq = defaultdict(int)
    for num in a:
        freq[num] += 1
    max_freq = max(freq.values() if freq else [0])
    if max_freq > (n + 1) // 2:
        print(-1)
        return
    
    # Count consecutive duplicates
    cnt = 0
    for i in range(n-1):
        if a[i] == a[i+1]:
            cnt += 1
    
    print((cnt + 1) // 2)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Frequency Check**: The code first checks if any element's frequency exceeds half the length of the array (rounded up). If it does, it's impossible to rearrange the array to meet Kevin's requirements, so we return -1.
2. **Count Consecutive Duplicates**: We iterate through the array and count how many consecutive pairs of elements are the same. This count helps determine the minimum number of reversals needed.
3. **Calculate Minimum Reversals**: Using the count of consecutive duplicates, we apply the formula `(count + 1) // 2` to determine the minimum number of reversals. This formula ensures that each reversal can address up to two consecutive duplicate pairs, efficiently reducing the problem size.
