def kosaraju(adj, num_nodes):
    visited = [False] * num_nodes
    order = []

    # First pass: fill order
    for i in range(num_nodes):
        if not visited[i]:
            stack = [(i, False)]
            while stack:
                node, processed = stack.pop()
                if processed:
                    order.append(node)
                    continue
                if visited[node]:
                    continue
                visited[node] = True
                stack.append( (node, True) )
                for neighbor in reversed(adj[node]):
                    if not visited[neighbor]:
                        stack.append( (neighbor, False) )

    # Transpose the graph
    transpose_adj = [[] for _ in range(num_nodes)]
    for u in range(num_nodes):
        for v in adj[u]:
            transpose_adj[v].append(u)

    # Second pass: find SCCs
    visited = [False] * num_nodes
    sccs = []
    while order:
        node = order.pop()
        if not visited[node]:
            stack = [node]
            visited[node] = True
            scc = []
            while stack:
                u = stack.pop()
                scc.append(u)
                for v in transpose_adj[u]:
                    if not visited[v]:
                        visited[v] = True
                        stack.append(v)
            sccs.append(scc)

To solve this problem, we need to transform an essay by replacing words with their synonyms such that the resulting essay has the minimum number of 'R' letters (case-insensitive) and, in case of ties, the shortest total length. The replacements must follow the given directed synonym rules.

### Approach
1. **Graph Construction**: Represent each word as a node and each synonym replacement rule as a directed edge in a graph.
2. **Strongly Connected Components (SCCs)**: Use Kosaraju's algorithm to find SCCs in the graph. Words within an SCC can be replaced with each other through a series of synonyms.
3. **Optimal Values Calculation**: For each SCC, determine the word with the minimum number of 'R's and the shortest length. If there are multiple words with the same minimum 'R's, choose the shortest one.
4. **Condensed DAG**: Condense the graph into a Directed Acyclic Graph (DAG) where each node represents an SCC. Process the DAG in reverse topological order to propagate the optimal values from sink nodes to source nodes.
5. **Result Calculation**: For each word in the essay, use the optimal values from its corresponding SCC to compute the total minimum 'R's and length.

                if in_degree[v] == 0:

        return top_order if len(top_order) == num_nodes else None
