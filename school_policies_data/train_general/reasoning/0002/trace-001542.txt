### Approach
1. **Dynamic Programming (DP) Setup**: Use a dictionary of sets to track possible sums. The key is the sum of the subset of coins (sum_S), and the value is a set of possible subset sums (sum_x) that can be formed using those coins.
2. **Processing Each Coin**: For each coin, update the DP state to include both the possibilities of including the coin in the subset sum (sum_S) and whether it contributes to the subset sum (sum_x) or not.
3. **Transition States**: For each coin, generate new states by either including the coin in the subset sum (sum_S) but not in the subset sum (sum_x), or including it in both. This ensures all possible valid combinations are tracked.
4. **Collect Results**: After processing all coins, collect all possible values of sum_x where the sum_S equals k, sort them, and output the results.

def main():
