To solve this problem, we need to determine the probability that a binary number of length N contains at least one contiguous streak of 1's of length K. The solution involves using dynamic programming to efficiently count the valid sequences and then computing the probability as a fraction in its simplest form.

### Approach
1. **Dynamic Programming (DP) Setup**: We use a DP approach to keep track of the number of valid sequences as we build them bit by bit.
2. **State Representation**: The state is represented by three parameters: the current position in the binary number, the length of the current streak of 1's, and a flag indicating whether a streak of length K has been encountered so far.
3. **Transitions**: For each bit position, we consider both possible bits (0 or 1) and update the current streak length and the flag accordingly.
4. **Count Valid Sequences**: After processing all bits, we sum the counts of all valid sequences that have encountered a streak of K 1's.
5. **Probability Calculation**: Convert the count of valid sequences into a fraction and simplify it using the greatest common divisor (GCD).

### Solution Code
```python
import math
from collections import defaultdict

def main():
    import sys
    N, K = map(int, sys.stdin.readline().split())
    
    if K == 0:
        print("1/1")
        return
    
    # Initialize DP for the first bit (i=0)
    prev_dp = defaultdict(int)
    # Case where first bit is 0
    prev_dp[(0, 0)] += 1
    # Case where first bit is 1
    j_prev = 1
    has_prev = 1 if j_prev >= K else 0
    prev_dp[(j_prev, has_prev)] += 1
    
    # Iterate for the remaining N-1 bits
    for _ in range(N-1):
        curr_dp = defaultdict(int)
        for (j_prev, has_prev), cnt in prev_dp.items():
            # Transition for bit 0
            new_j = 0
            new_has = has_prev
            curr_dp[(new_j, new_has)] += cnt
            # Transition for bit 1
            new_j = j_prev + 1
            if new_j >= K:
                new_has = 1
            else:
                new_has = has_prev
            curr_dp[(new_j, new_has)] += cnt
        prev_dp = curr_dp
    
    total = 0
    for (j, has), cnt in prev_dp.items():
        if has:
            total += cnt
    
    denominator = 2 ** N
    gcd_val = math.gcd(total, denominator)
    numerator = total // gcd_val
    denominator //= gcd_val
    print(f"{numerator}/{denominator}")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Initialization**: The DP table starts with the first bit, considering both possibilities (0 or 1) and initializing their respective states.
2. **DP Transitions**: For each subsequent bit, we update the DP states based on the current bit being 0 or 1. If the bit is 0, the streak of 1's resets. If the bit is 1, the streak length increases, and we check if it meets or exceeds K.
3. **Summing Valid Sequences**: After processing all bits, we sum all sequences where a streak of K 1's was encountered.
4. **Fraction Simplification**: The result is simplified using the GCD to ensure the fraction is in its lowest terms.

This approach efficiently counts the valid sequences using dynamic programming, avoiding the need for brute force enumeration, and handles the constraints effectively.
