To solve this problem, we need to find the difference between two sets, A and B, which consists of all elements present in A but not in B. Both sets are given in ascending order, and we need to efficiently determine the result using a linear time complexity approach.

### Approach
The optimal approach to solve this problem involves using a two-pointer technique, which is efficient and works in linear time O(n + m), where n and m are the sizes of sets A and B respectively. Here are the steps:

1. **Read Input**: Read the input values for the sizes of sets A and B, followed by their respective elements.
2. **Initialize Pointers**: Use two pointers, one for each set, starting at the beginning of both sets.
3. **Compare Elements**: Traverse both sets simultaneously:
   - If the current element in A is smaller than the current element in B, add it to the result (since it cannot be present in B).
   - If the current elements in A and B are equal, move both pointers forward (since the element is present in both sets).
   - If the current element in A is larger than the current element in B, move the pointer in B forward to check the next element in B.
4. **Remaining Elements**: After processing elements through the two-pointer technique, any remaining elements in A (if any) are added to the result, as they are not present in B.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    a = list(map(int, input[ptr:ptr + n]))
    ptr += n
    m = int(input[ptr])
    ptr += 1
    b = list(map(int, input[ptr:ptr + m]))
    
    i = j = 0
    result = []
    while i < n and j < m:
        if a[i] < b[j]:
            result.append(a[i])
            i += 1
        elif a[i] == b[j]:
            i += 1
            j += 1
        else:
            j += 1
    while i < n:
        result.append(a[i])
        i += 1
    for num in result:
        print(num)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read in a single read operation for efficiency, especially with large datasets. The input is split into a list of strings which are then converted to integers.
- **Two-pointer Technique**: The two pointers (i for A and j for B) traverse through their respective sets. By comparing elements at these pointers, we efficiently determine which elements of A are not in B.
- **Handling Remaining Elements**: After processing all elements of B, any remaining elements in A are automatically added to the result as they are guaranteed not to be in B.

This approach ensures that we efficiently find the set difference in linear time, making it suitable for large input sizes up to 200,000 elements.
