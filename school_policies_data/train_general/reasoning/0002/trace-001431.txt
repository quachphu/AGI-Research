To solve this problem, we need to determine the winner of a game where two players, Arpit and Nikhil, take turns subtracting 1, 2, or 3 from a number N until one of them makes the result divisible by 4. Arpit starts first, and both players play optimally. The solution requires us to predict the winner based on the initial value of N.

### Approach
The key insight to solve this problem efficiently is to recognize the pattern in the game. The game can be analyzed using modular arithmetic to determine the winning and losing positions:

1. **Winning Condition**: A player wins if they can subtract 1, 2, or 3 from the current number to make the result divisible by 4.
2. **Optimal Play**: If the number N modulo 4 is 0, the player starting the turn (Arpit) cannot win immediately and will eventually lose if both players play optimally. This is because any move Arpit makes (subtracting 1, 2, or 3) will leave a number that Nikhil can then adjust to make divisible by 4.

Thus, the solution can be determined by checking if N modulo 4 is 0:
- If N % 4 == 0, Nikhil (the second player) will win.
- Otherwise, Arpit (the first player) will win by making a move that results in a number divisible by 4.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    T = int(input[0])
    results = []
    for num_str in input[1:T+1]:
        N = int(num_str)
        if N % 4 == 0:
            results.append("Second")
        else:
            results.append("First")
    print('\n'.join(results))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once using `sys.stdin.read()` for efficiency, especially given the constraints where T can be as large as 100,000.
2. **Modulo Operation**: For each number N, we check if N modulo 4 is 0. If it is, Nikhil (Second) wins; otherwise, Arpit (First) wins.
3. **Output**: The results for all test cases are collected in a list and printed at once to minimize the number of I/O operations, which is crucial for handling large input sizes efficiently.

This approach ensures that each test case is processed in constant time O(1), leading to an overall time complexity of O(T), which is optimal for the given constraints.
