To solve this problem, we need to determine the probability of selecting a K-equal triplet from a list of numbers, expressed as a reduced fraction. A K-equal triplet is a group of three numbers all equal to K. The solution involves counting occurrences of K and using combinatorial mathematics to compute the probability.

### Approach
1. **Input Reading**: Read the number of test cases. For each test case, read the values of N (number of elements) and K (target value).
2. **Count Occurrences**: Count how many times K appears in the list of numbers.
3. **Check Validity**: If there are fewer than 3 occurrences of K or if the total number of elements is less than 3, the probability is zero.
4. **Combinatorial Calculation**: Compute the number of ways to choose 3 K's from the occurrences and the total number of ways to choose any 3 elements from the list.
5. **Fraction Reduction**: Use the greatest common divisor (GCD) to reduce the fraction representing the probability to its simplest form.

### Solution Code
```python
import sys
import math

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        K = int(input[ptr + 1])
        ptr += 2
        count = 0
        # Process the next N elements
        for i in range(N):
            num = int(input[ptr + i])
            if num == K:
                count += 1
        ptr += N
        
        if N < 3 or count < 3:
            print("0/1")
        else:
            numerator = count * (count - 1) * (count - 2)
            denominator = N * (N - 1) * (N - 2)
            gcd_val = math.gcd(numerator, denominator)
            a = numerator // gcd_val
            b = denominator // gcd_val
            print(f"{a}/{b}")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and split into a list for efficient processing, which is crucial for handling large input sizes.
2. **Counting Occurrences**: For each test case, we count how many times K appears in the list of numbers.
3. **Validity Check**: If there are fewer than 3 Ks or fewer than 3 elements in total, the probability is zero.
4. **Combinatorial Calculation**: The number of valid triplets (K-equal) is calculated using combinations. The total number of possible triplets is derived from the total number of elements.
5. **Fraction Reduction**: The GCD of the numerator and denominator is used to simplify the fraction, ensuring the result is in its lowest terms.

This approach efficiently handles large input sizes and ensures accurate calculation of probabilities using combinatorial mathematics and fraction reduction.
