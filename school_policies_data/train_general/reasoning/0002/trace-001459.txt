To solve this problem, we need to determine the minimum and maximum number of "good" apartments for Maxim. A good apartment is one that is available for sale and adjacent to at least one inhabited apartment. The solution involves analyzing different configurations of inhabited apartments to find the optimal scenarios.

### Approach
1. **Maximum Good Apartments**:
   - To maximize the number of good apartments, we should spread out the inhabited apartments as much as possible. Each inhabited apartment can potentially make two adjacent apartments good (one on each side). However, the maximum number of good apartments cannot exceed the total available apartments, which is `n - k`. Thus, the maximum good apartments is the minimum of `2 * k` (each inhabited apartment contributing two good apartments) and `n - k` (total available apartments).

2. **Minimum Good Apartments**:
   - To minimize the number of good apartments, we should cluster all inhabited apartments together. If placed at one end of the row, this configuration results in only one adjacent available apartment being good. If there are no available apartments (i.e., all are inhabited), the minimum is zero. Otherwise, if there are any available apartments, the minimum is always 1.

### Solution Code
```python
n, k = map(int, input().split())
if k == 0 or n == k:
    print(0, 0)
else:
    max_good = min(2 * k, n - k)
    print(1, max_good)
```

### Explanation
- **Input Handling**: Read the values of `n` (total apartments) and `k` (inhabited apartments).
- **Edge Cases**: If there are no inhabited apartments (`k == 0`) or all apartments are inhabited (`n == k`), both minimum and maximum good apartments are 0.
- **Maximum Calculation**: The maximum number of good apartments is determined by the minimum value between `2 * k` (each inhabited apartment contributing two good apartments) and `n - k` (total available apartments).
- **Minimum Calculation**: The minimum number of good apartments is always 1 if there are any available apartments (i.e., `n > k` and `k > 0`).

This approach efficiently computes the required values using simple arithmetic checks and ensures optimal performance even for large values of `n` and `k`.
