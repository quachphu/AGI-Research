To solve this problem, we need to determine if a given string meets three specific conditions. The solution involves checking each condition step-by-step and ensuring all are satisfied.

### Approach
1. **Check String Length**: The string must be between 4 and 10 characters long.
2. **Check Initial Character**: The first character must be an uppercase 'A'.
3. **Check for Exactly One 'C'**: There must be exactly one uppercase 'C' between the third character and the second-to-last character (inclusive).
4. **Check All Other Characters**: All characters except the first 'A' and the one 'C' (from step 3) must be lowercase.

### Solution Code
```python
s = input().strip()

def check(s):
    # Check the length condition first
    if len(s) < 4 or len(s) > 10:
        return "WA"
    
    # Check the first character is 'A'
    if s[0] != 'A':
        return "WA"
    
    # Determine the range for the 'C' check
    start = 2
    end = len(s) - 2
    c_count = 0
    c_position = -1
    
    # Check for exactly one 'C' in the specified range
    for i in range(start, end + 1):
        if i >= len(s):
            return "WA"
        if s[i] == 'C':
            c_count += 1
            c_position = i
    
    if c_count != 1:
        return "WA"
    
    # Check all other characters are lowercase except the first 'A' and the 'C' found
    for j in range(len(s)):
        if j == 0 or j == c_position:
            continue
        if not s[j].islower():
            return "WA"
    
    return "AC"

print(check(s))
```

### Explanation
1. **String Length Check**: The function first verifies that the input string's length is between 4 and 10 characters. If not, it returns "WA".
2. **Initial Character Check**: The function checks if the first character is 'A'. If not, it returns "WA".
3. **'C' Check**: The function then checks the substring from the third character to the second-to-last character for exactly one uppercase 'C'. If there are zero or more than one 'C's, it returns "WA".
4. **Lowercase Check**: Finally, the function ensures all other characters (except the first 'A' and the found 'C') are lowercase. If any other uppercase letters are found, it returns "WA".

This approach systematically checks each condition in sequence, ensuring that all constraints are met before confirming the string as valid ("AC").
