To solve this problem, we need to place white (W) and black (B) knights on an n x n chessboard such that the number of duels (pairs of different colored knights attacking each other) is maximized. The key insight is that the chessboard can be colored in a bipartite manner, ensuring each knight's move alternates between colors, thus maximizing duels.

### Approach
1. **Bipartite Coloring**: The chessboard can be colored using a bipartite graph approach where each cell (i, j) is colored such that adjacent cells (by knight moves) have different colors. This ensures every possible attack pair results in a duel.
2. **Checkerboard Pattern**: The optimal coloring is achieved by using the standard checkerboard pattern where each cell (i, j) is colored 'W' if (i + j) is even and 'B' otherwise. This pattern ensures that each knight move flips the color, thus maximizing duels.

### Solution Code
```python
n = int(input())
for i in range(1, n + 1):
    row = []
    for j in range(1, n + 1):
        if (i + j) % 2 == 0:
            row.append('W')
        else:
            row.append('B')
    print(''.join(row))
```

### Explanation
- **Bipartite Coloring**: The chessboard is divided into two sets such that each knight move from a cell in one set lands in the other set. This is achieved by coloring cells based on the parity of (i + j).
- **Checkerboard Pattern Implementation**: For each cell (i, j), if the sum of the row index (i) and column index (j) is even, the cell is colored 'W'; otherwise, it is colored 'B'. This ensures that every possible knight move results in a duel between different colored knights.

This approach guarantees that the number of duels is maximized by leveraging the bipartite nature of the knight's movement graph on the chessboard. The solution is efficient and works for any valid board size n (3 ≤ n ≤ 100).
