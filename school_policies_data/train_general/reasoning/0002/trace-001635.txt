To solve this problem, we need to partition an array of events into contiguous subarrays such that each subarray represents a valid day according to the company's security rules. Each valid day must start and end empty, with employees entering and exiting in a valid order and no employee entering more than once in a day.

### Approach
1. **Track Entries and Exits**: For each day, maintain two sets: one for employees who have entered during the day and another for those currently present in the office.
2. **Check Validity**: For each event, ensure that an employee does not enter more than once and exits only after entering.
3. **Balance Check**: Track the balance of employees in the office. Whenever the balance reaches zero, it indicates a potential end of a valid day.
4. **Reset Tracking**: Once a valid day is identified, reset the tracking sets and balance for the next day.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    
    days = []
    current_start = 0
    current_entered = set()
    current_present = set()
    balance = 0
    
    for i in range(n):
        num = a[i]
        if num > 0:
            if num in current_entered:
                print(-1)
                return
            current_entered.add(num)
            current_present.add(num)
            balance += 1
        else:
            emp = -num
            if emp not in current_present:
                print(-1)
                return
            current_present.remove(emp)
            balance -= 1
        
        if balance == 0:
            days.append(i - current_start + 1)
            current_start = i + 1
            current_entered = set()
            current_present = set()
            balance = 0
    
    if current_start != n:
        print(-1)
    else:
        print(len(days))
        print(' '.join(map(str, days)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of events and the list of events.
2. **Tracking Sets**: Two sets are used to track employees who have entered during the day and those currently present.
3. **Event Processing**: Each event is processed to check if it is a valid entry or exit. Entries are checked against the set of already entered employees to prevent duplicates. Exits are checked against the set of currently present employees.
4. **Balance Check**: The balance of employees in the office is updated with each event. When the balance reaches zero, the current subarray is marked as a valid day, and tracking is reset.
5. **Validation**: After processing all events, if the entire array is partitioned into valid days, the result is printed. Otherwise, an error is returned.

This approach ensures that each day is valid by maintaining the necessary checks and balances, efficiently processing each event in linear time.
