To solve this problem, we need to determine how many numbers Subly changed in the original set given by his father. The original set contains unique elements, and Subly changed some elements to others he liked, which were already present in the original set. The task is to count how many elements were changed.

### Approach
1. **Understanding the Problem**: Subly changed elements he didn't like to elements he liked, which were already in the original set. The input provides the modified set (which may have duplicates), and we need to find out how many elements were changed from the original unique set.
2. **Key Insight**: The number of unique elements in the modified set represents the elements that Subly liked and did not change. Each duplicate element in the modified set indicates that some other element was changed to this value. Therefore, the number of elements changed is the difference between the total number of elements in the original set and the number of unique elements in the modified set.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    arr = input[1:n+1]
    unique_count = len(set(arr))
    print(n - unique_count)

main()
```

### Explanation
1. **Reading Input**: The input is read as a list of strings. The first element is the number of elements `n`, and the next `n` elements are the modified set.
2. **Counting Unique Elements**: Convert the list of modified elements into a set to count the number of unique elements.
3. **Calculating Changed Elements**: Subtract the count of unique elements from the total number of elements `n` to get the number of elements that were changed. This works because each unique element in the modified set represents an element that was not changed, and the difference gives the count of elements that were changed to these unique values.

This approach efficiently determines the number of changed elements using set operations, which are optimal for handling unique values and provide a time complexity of O(n), suitable for the given constraints.
