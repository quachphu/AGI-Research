To solve this problem, we need to determine the minimum total cost for Petya to give presents or cash to his friends such that each friend either receives a present from a specified range or cash equivalent to the cost of the highest present they could receive. The goal is to minimize the total cost by optimally assigning presents.

### Approach
1. **Sort Friends by Present Requirement**: First, sort the friends based on their maximum allowed present index in ascending order. This helps in efficiently determining the optimal presents to allocate.
2. **Binary Search for Optimal Present Allocation**: Use binary search to find the maximum number of presents that can be distributed. This is determined by finding the largest number of presents such that there are enough friends who can receive these presents based on their constraints.
3. **Prefix and Suffix Sums**: Precompute prefix sums of present costs to quickly calculate the total cost of distributing the first few presents. Also, precompute suffix sums of the cash costs of friends to efficiently determine the cost when friends are given cash instead of presents.

### Solution Code
```python
import sys

def solve():
    input = sys.stdin.read().split()
    ptr = 0
    t = int(input[ptr])
    ptr += 1
    for _ in range(t):
        n, m = int(input[ptr]), int(input[ptr+1])
        ptr += 2
        k = list(map(int, input[ptr:ptr+n]))
        ptr += n
        c = list(map(int, input[ptr:ptr+m]))
        ptr += m
        k.sort()
        total_sum = 0
        for ki in k:
            total_sum += c[ki - 1]
        
        # Compute suffix sum of sorted k's cash values
        suffix_sum = [0] * (n + 1)
        for i in range(n-1, -1, -1):
            suffix_sum[i] = suffix_sum[i+1] + c[k[i]-1]
        
        # Compute prefix sum of c
        prefix_c = [0] * (m + 1)
        for i in range(m):
            prefix_c[i+1] = prefix_c[i] + c[i]
        
        max_possible = min(n, m)
        low, high, best_x = 0, max_possible, 0
        while low <= high:
            mid = (low + high) // 2
            if mid == 0:
                best_x = mid
                low = mid + 1
            else:
                req_idx = n - mid
                if req_idx >= 0 and k[req_idx] >= mid:
                    best_x = mid
                    low = mid + 1
                else:
                    high = mid - 1
        
        sum_presents = prefix_c[best_x]
        sum_selected_k = suffix_sum[n - best_x] if best_x != 0 else 0
        total_cost = total_sum - sum_selected_k + sum_presents
        print(total_cost)
```
