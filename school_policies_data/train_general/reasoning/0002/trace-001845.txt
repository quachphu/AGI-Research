To solve this problem, we need to compute the product of all elements in an array and return the result modulo \(10^9 + 7\). The solution involves reading input values, processing them efficiently to avoid overflow, and applying the modulo operation at each step to maintain manageable intermediate values.

### Approach
1. **Reading Input**: The input consists of an integer \(N\) (the size of the array) followed by \(N\) space-separated integers.
2. **Initialization**: Start with a product initialized to 1, as multiplying by 1 does not change the result.
3. **Iterative Multiplication**: For each element in the array, multiply the current product by the element and take the result modulo \(10^9 + 7\). This step ensures that intermediate values remain within the bounds of standard integer operations.
4. **Output the Result**: After processing all elements, print the final product.

### Solution Code
```python
def main():
    MOD = 10**9 + 7
    n = int(input())
    arr = list(map(int, input().split()))
    product = 1
    for num in arr:
        product = (product * num) % MOD
    print(product)

main()
```

### Explanation
1. **Reading Input**: The first line of input is read to get the size of the array \(N\). The next line is read and split into a list of integers.
2. **Modulo Constant**: The constant \(10^9 + 7\) is defined to avoid recalculating it repeatedly.
3. **Product Calculation**: Initialize the product as 1. For each element in the array, update the product by multiplying it with the element and taking modulo \(10^9 + 7\). This ensures that the product does not grow too large, which could be computationally expensive and unnecessary for the final result.
4. **Output**: The final product after processing all elements is printed.

This approach efficiently handles the constraints and ensures that the result is computed correctly even for the upper limits of the input size and values.
