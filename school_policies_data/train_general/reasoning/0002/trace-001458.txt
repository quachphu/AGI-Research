To solve this problem, we need to compute the sum of the maximum distances between all pairs of computers in each non-empty subset of hacked computers, modulo \(10^9 + 7\). The key insight is to efficiently calculate contributions of each computer as the maximum and minimum element in subsets.

### Approach
1. **Sort the Coordinates**: The maximum distance in any subset is determined by the maximum and minimum elements in that subset. Sorting the coordinates simplifies the process of determining these contributions.
2. **Precompute Powers of 2**: Since the number of subsets where an element is the maximum or minimum can be represented using powers of 2, we precompute these values modulo \(10^9 + 7\) for efficiency.
3. **Calculate Contributions**:
   - **S_max**: Sum of contributions where each element is the maximum in its subsets.
   - **S_min**: Sum of contributions where each element is the minimum in its subsets.
4. **Compute Result**: The result is the difference between S_max and S_min, taken modulo \(10^9 + 7\).

### Solution Code
```python
MOD = 10**9 + 7

n = int(input())
x = list(map(int, input().split()))
x.sort()

pow2 = [1] * n
for i in range(1, n):
    pow2[i] = (pow2[i-1] * 2) % MOD

s_max = 0
s_min = 0
for i in range(n):
    s_max = (s_max + x[i] * pow2[i]) % MOD
    s_min = (s_min + x[i] * pow2[(n-1) - i]) % MOD

ans = (s_max - s_min) % MOD
print(ans)
```

### Explanation
1. **Sorting**: By sorting the coordinates, we ensure that for any subset, the minimum and maximum elements are simply the first and last elements in the sorted list when considering the subset.
2. **Power of 2 Precomputation**: This step helps in quickly determining the number of subsets where an element is the maximum or minimum. For an element at position \(i\) (0-based), the number of subsets where it is the maximum is \(2^i\) (all subsets of elements before it combined with itself), and the number of subsets where it is the minimum is \(2^{n-1-i}\) (all subsets of elements after it combined with itself).
3. **Summing Contributions**: By iterating through each element and computing its contributions to S_max and S_min using the precomputed powers of 2, we efficiently compute the required sums in linear time.
4. **Modulo Operation**: Ensures that the result remains within the bounds of \(10^9 + 7\), handling potential overflow issues.

This approach efficiently reduces the problem from an exponential complexity to a linear one, making it feasible for large inputs up to \(3 \times 10^5\).
