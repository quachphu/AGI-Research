To solve this problem, we need to determine how many times each person greets another person while walking along a boulevard. Each person starts walking at a specific time and moves towards their destination at a constant speed. Greetings occur when two people are at the same point at the same time.

### Approach
1. **Movement Analysis**: Each person moves in a straight line from their starting point to their destination at a constant speed (1 unit per second in the appropriate direction). The direction is determined by whether the destination is ahead or behind the starting point.
2. **Active Time Interval**: For each person, we calculate the time interval during which they are on the boulevard, starting from their start time and ending when they reach their destination.
3. **Meeting Check**: For each pair of people, we check if their paths intersect during their active intervals. This involves:
   - **Same Direction Check**: If both people are moving in the same direction, check if they maintain the same relative position over time.
   - **Different Direction Check**: If moving in opposite directions, solve the linear equation to find the intersection time and check if it lies within their active intervals.

### Solution Code
```python
n = int(input())
people = []
for _ in range(n):
    t, s, f = map(int, input().split())
    direc = 1 if f > s else -1
    di = abs(f - s)
    start = t
    end = t + di
    a = s - direc * t
    people.append({'s': s, 'f': f, 'direc': direc, 'start': start, 'end': end, 'a': a})

counts = [0] * n

for i in range(n):
    for j in range(i + 1, n):
        p_i = people[i]
        p_j = people[j]
        t_start = max(p_i['start'], p_j['start'])
        t_end = min(p_i['end'], p_j['end'])
        if t_start > t_end:
            continue
        
        direc_i = p_i['direc']
        direc_j = p_j['direc']
        
        if direc_i == direc_j:
            if p_i['a'] == p_j['a']:
                counts[i] += 1
                counts[j] += 1
        else:
            si = p_i['s']
            sj = p_j['s']
            ti = p_i['start']
            tj = p_j['start']
            denominator = direc_i - direc_j
            numerator = (sj - si) + direc_i * ti - direc_j * tj
            
            if denominator > 0:
                valid = (numerator >= denominator * t_start) and (numerator <= denominator * t_end)
            else:
                valid = (numerator <= denominator * t_start) and (numerator >= denominator * t_end)
            
            if valid:
                counts[i] += 1
                counts[j] += 1

print(' '.join(map(str, counts)))
```

4. **Check for Meetings**: For each pair of people, determine if their active intervals overlap. If they do, check if they meet using either the same direction check or solving the intersection equation for different directions.
5. **Count Updates**: Increment the greeting count for each person if they meet another person during their active intervals.

This approach efficiently checks all pairs of people using mathematical checks to avoid floating-point inaccuracies, ensuring precise and correct results.
