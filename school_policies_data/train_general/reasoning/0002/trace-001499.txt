To solve this problem, we need to determine how many numbers up to a given integer \( n \) are considered "really big" based on a threshold \( s \). A number \( x \) is really big if \( x - \text{sum\_digits}(x) \geq s \), where \(\text{sum\_digits}(x)\) is the sum of the digits of \( x \).

### Approach
1. **Understanding the Condition**: A number \( x \) is really big if \( x - \text{sum\_digits}(x) \geq s \). This means we need to find the smallest \( x \) such that this condition holds true.
2. **Binary Search**: Since the function \( x - \text{sum\_digits}(x) \) is non-decreasing, we can use binary search to efficiently find the smallest \( x \) that meets the condition.
3. **Range Check**: Once we find the smallest valid \( x \), we check if it is within the range \( [1, n] \). If it is, the count of valid numbers is \( n - x + 1 \). Otherwise, the count is 0.

### Solution Code
```python
def sum_digits(x):
    s = 0
    while x > 0:
        s += x % 10
        x = x // 10
    return s

def main():
    import sys
    n, s = map(int, sys.stdin.readline().split())
    low = 1
    high = n
    res = -1
    while low <= high:
        mid = (low + high) // 2
        current = mid - sum_digits(mid)
        if current >= s:
            res = mid
            high = mid - 1
        else:
            low = mid + 1
    print(max(0, n - res + 1) if res != -1 else 0)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Binary Search Setup**: We initialize the binary search with `low` set to 1 and `high` set to \( n \).
2. **Mid Calculation**: For each midpoint `mid` in the current search range, we check if `mid - sum_digits(mid)` meets or exceeds \( s \).
3. **Adjust Search Range**: If the condition is met, we update the result and search the lower half for a potentially smaller valid \( x \). If not, we search the upper half.
4. **Result Calculation**: After the binary search completes, if a valid \( x \) was found, we calculate how many numbers from \( x \) to \( n \) are valid. If no valid \( x \) was found, the result is 0.

This approach efficiently narrows down the possible values of \( x \) using binary search, ensuring we handle even the largest possible values of \( n \) and \( s \) within acceptable time complexity.
