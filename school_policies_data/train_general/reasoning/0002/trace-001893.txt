To solve this problem, we need to determine if a given string is 'hard' or 'easy' to pronounce based on two specific conditions. The string is considered 'hard' if it either has more consonants than vowels or contains three consecutive consonants. 

### Approach
1. **Identify Vowels and Consonants**: The vowels are 'a', 'e', 'i', 'o', 'u', and 'y'. All other lowercase letters are consonants.
2. **Check Conditions**:
   - **Condition 1**: Count the number of vowels and consonants. If the number of consonants is greater than the number of vowels, the string is 'hard'.
   - **Condition 2**: Check if there are three consecutive consonants in the string. If such a triplet exists, the string is 'hard'.

### Solution Code
```python
import sys

def is_hard(s):
    vowels = {'a', 'e', 'i', 'o', 'u', 'y'}
    vowels_count = sum(1 for c in s if c in vowels)
    consonants_count = len(s) - vowels_count
    
    if consonants_count > vowels_count:
        return True
    
    for i in range(len(s) - 2):
        if s[i] not in vowels and s[i+1] not in vowels and s[i+2] not in vowels:
            return True
    
    return False

def main():
    T = int(sys.stdin.readline())
    for _ in range(T):
        s = sys.stdin.readline().strip()
        print("hard" if is_hard(s) else "easy")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The code reads the number of test cases and each string to be evaluated.
2. **Vowel and Consonant Count**: For each string, the number of vowels is counted using a set for quick lookup. The consonant count is derived by subtracting the vowel count from the total length of the string.
3. **Condition Checks**:
   - **Condition 1**: Directly compares the count of consonants to vowels.
   - **Condition 2**: Iterates through the string to check for any triplet of consecutive consonants.
4. **Output**: Based on the checks, the result for each string is printed as either 'hard' or 'easy'.

This approach efficiently checks both conditions in linear time relative to the length of the string, ensuring optimal performance given the problem constraints.
