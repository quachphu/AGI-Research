To solve this problem, we need to determine the maximum possible difference in the number of balls received between the person with the most balls and the person with the fewest balls when distributing N balls to K persons, with each person receiving at least one ball.

### Approach
1. **Problem Analysis**:
   - Each person must receive at least one ball.
   - To maximize the difference between the person with the most and the fewest balls, we should allocate the minimum possible number of balls to K-1 people (which is 1 ball each) and the remaining balls to the last person.
   - If K is 1, the difference is 0 because all balls go to a single person.
   - For K >= 2, the maximum difference is calculated as (N - (K-1)) - 1, which simplifies to N - K.

### Solution Code
```python
n, k = map(int, input().split())
print(0 if k == 1 else n - k)
```

### Explanation
- **Input Handling**: Read the values of N and K from the input.
- **Special Case for K=1**: If there is only one person, they receive all the balls, so the difference is 0.
- **General Case for K>=2**: The maximum difference is achieved by giving 1 ball to K-1 people and the remaining balls to the last person. This results in a difference of (N - (K-1)) - 1, which simplifies to N - K.

This approach efficiently computes the result in constant time, O(1), by leveraging simple arithmetic operations and conditional checks.
