To solve this problem, we need to construct an array such that the minimum mex of all given subarrays is as large as possible. The mex (minimum excluded value) of a set is the smallest non-negative integer not present in the set. The goal is to maximize the smallest mex among all given subarrays.

### Approach
1. **Identify the Minimum Subarray Length**: The maximum possible minimum mex is determined by the smallest length of any subarray given in the input. This is because a subarray of length `k` can at most contain all integers from 0 to `k-1`, making its mex `k`.
2. **Construct the Array**: Construct the array such that each element at position `i` (0-based index) is `i % k`, where `k` is the minimum subarray length. This ensures that every subarray of length `k` contains all integers from 0 to `k-1`, thus achieving the mex of `k`.

### Solution Code
```python
n, m = map(int, input().split())
min_len = float('inf')

for _ in range(m):
    l, r = map(int, input().split())
    current_len = r - l + 1
    if current_len < min_len:
        min_len = current_len

k = min_len
array = [i % k for i in range(n)]

print(k)
print(' '.join(map(str, array)))
```

### Explanation
1. **Reading Input**: The code reads the number of elements `n` and the number of subarrays `m`.
2. **Determine Minimum Subarray Length**: For each subarray defined by its start and end indices, compute its length and track the minimum length found.
3. **Construct Array**: The array is constructed such that each element at position `i` (0-based) is `i % k`, where `k` is the minimum subarray length. This ensures that every subarray of length `k` will contain all integers from 0 to `k-1`, resulting in a mex of `k`.
4. **Output Result**: The maximum possible minimum mex `k` and the constructed array are printed.

This approach efficiently ensures that the minimum mex among all given subarrays is maximized by leveraging the properties of modular arithmetic to guarantee coverage of all necessary values in each subarray.
