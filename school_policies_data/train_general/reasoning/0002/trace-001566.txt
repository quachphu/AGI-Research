To solve this problem, we need to determine the number of successful applicants for the International Competitive Programming College (ICPC) entrance examination based on their scores. The goal is to maximize the gap between the lowest score of successful applicants and the highest score of unsuccessful applicants, while adhering to constraints on the number of successful applicants.

### Approach
1. **Input Reading**: Read the input values which include the number of applicants, the minimum and maximum number of successful applicants, and their scores.
2. **Gap Calculation**: For each possible number of successful applicants (n) within the given range [nmin, nmax], compute the gap between the lowest score of successful applicants and the highest score of unsuccessful applicants.
3. **Maximize Gap**: Identify the value of n that maximizes this gap. If there are multiple values of n with the same maximum gap, choose the largest n.

### Solution Code
```python
import sys

def main():
    while True:
        line = sys.stdin.readline()
        if not line:
            break
        parts = line.strip().split()
        m, nmin, nmax = map(int, parts)
        if m == 0 and nmin == 0 and nmax == 0:
            break
        scores = []
        for _ in range(m):
            p = int(sys.stdin.readline())
            scores.append(p)
        gaps = []
        for n in range(nmin, nmax + 1):
            gap = scores[n-1] - scores[n]
            gaps.append((n, gap))
        # Sort by descending gap, then descending n
        gaps.sort(key=lambda x: (-x[1], -x[0]))
        print(gaps[0][0])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read line by line. The first line of each dataset contains three integers: the number of applicants (m), the minimum (nmin), and maximum (nmax) number of successful applicants. Subsequent lines contain the scores of the applicants in descending order.
2. **Gap Calculation**: For each possible number of successful applicants (n) from nmin to nmax, compute the gap as the difference between the nth highest score (lowest score of successful applicants) and the (n+1)th highest score (highest score of unsuccessful applicants).
3. **Sorting and Selection**: The gaps are sorted in descending order. If multiple values of n yield the same maximum gap, the largest n is chosen by secondary sorting in descending order of n.

This approach ensures that we efficiently determine the optimal number of successful applicants by leveraging sorting and comparison based on the computed gaps.
