To solve this problem, we need to determine the number of swaps performed by the bubble sort algorithm when given a shuffled array. The bubble sort algorithm repeatedly steps through the list, compares adjacent elements, and swaps them if they are in the wrong order. The process continues until the list is sorted.

### Approach
1. **Understanding Bubble Sort**: The bubble sort algorithm works by repeatedly swapping adjacent elements if they are in the wrong order. Each pass through the list places the next largest element in its correct position.
2. **Counting Swaps**: For each test case, we will simulate the bubble sort algorithm on the given array and count the number of swaps performed until the array is sorted.
3. **Input Handling**: Read multiple test cases, each consisting of an integer T followed by T integers representing the shuffled array.
4. **Simulation**: For each test case, apply the bubble sort algorithm exactly as described and count the swaps.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    for _ in range(N):
        T = int(input[ptr])
        ptr += 1
        arr = list(map(int, input[ptr:ptr+T]))
        ptr += T
        count = 0
        n = len(arr) - 1
        for j in range(n + 1):
            for i in range(n):
                if arr[i] > arr[i+1]:
                    arr[i], arr[i+1] = arr[i+1], arr[i]
                    count += 1
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list of strings for efficient processing. The first value is the number of test cases, followed by each test case's data.
2. **Processing Each Test Case**: For each test case, we read the size of the array and the array elements. We then simulate the bubble sort algorithm on this array.
3. **Bubble Sort Simulation**: The algorithm uses nested loops. The outer loop runs from 0 to the length of the array, ensuring all elements are considered. The inner loop compares each pair of adjacent elements and swaps them if they are in the wrong order, incrementing the swap count each time a swap occurs.
4. **Output**: After processing each test case, the total number of swaps is printed.

This approach ensures that we accurately simulate the bubble sort algorithm and count the swaps efficiently, adhering to the problem constraints and requirements.
