To solve this problem, we need to compress files into archives in a way that minimizes the number of archives created while respecting the available space constraints on the hard drive. The challenge is to determine the minimum number of archives required or if it's impossible to compress all files.

### Approach
1. **Problem Analysis**:
   - The goal is to compress all files into the minimum number of archives such that each compression step fits within the available space.
   - Each compression step requires space for both the original files and the new archive. After compression, the original files are removed, freeing up space.

2. **Key Insights**:
   - Use a BFS approach to explore all possible subsets of files that can be compressed at each step.
   - Track the maximum available space for each subset of files (bitmask) to avoid redundant states and ensure optimality.

3. **Algorithm**:
   - Precompute the sum of original sizes (bi) and compressed sizes (ai) for all possible subsets of files.
   - Use BFS to explore states represented by a bitmask of compressed files and the current available space.
   - For each state, generate all valid subsets of remaining files that can be compressed and update the state accordingly.

4. **Optimizations**:
   - Track the maximum available space for each bitmask to prune redundant states and improve efficiency.

### Solution Code
```python
import sys
from collections import deque

def main():
    while True:
        n, m = map(int, sys.stdin.readline().split())
        if n == 0 and m == 0:
            break
        files = []
        for _ in range(n):
            bi, ai = map(int, sys.stdin.readline().split())
            files.append((bi, ai))
        
        # Precompute sum_bi and sum_ai for all possible subsets
        sum_bi = [0] * (1 << n)
        sum_ai = [0] * (1 << n)
        for mask in range(1 << n):
            b_total = 0
            a_total = 0
            for i in range(n):
                if mask & (1 << i):
                    b_total += files[i][0]
                    a_total += files[i][1]
            sum_bi[mask] = b_total
            sum_ai[mask] = a_total
        
        # BFS setup
        steps = [float('inf')] * (1 << n)
        max_available = [-1] * (1 << n)
        steps[0] = 0
        max_available[0] = m
        q = deque([0])
        found = False
        answer = 0
        
        while q:
            mask = q.popleft()
            current_step = steps[mask]
            if mask == (1 << n) - 1:
                answer = current_step
                found = True
                break
            remaining = ((1 << n) - 1) ^ mask
            subset = remaining
            while subset:
                s = subset
                subset = (subset - 1) & remaining
                if sum_ai[s] > max_available[mask]:
                    continue
                new_mask = mask | s
                new_avail = max_available[mask] - sum_ai[s] + sum_bi[s]
                if new_avail < 0:
                    continue
                if new_avail > max_available[new_mask] or (new_avail == max_available[new_mask] and steps[new_mask] > current_step + 1):
                    if steps[new_mask] > current_step + 1:
                        steps[new_mask] = current_step + 1
                        max_available[new_mask] = new_avail
                        q.append(new_mask)
        
        if found:
            print(answer)
        else:
            print("Impossible")

if __name__ == "__main__":
    main()
```

- **State Exploration**: For each state, generate all valid subsets of remaining files that can be compressed given the current available space. Update the state with the new bitmask and available space.
- **Tracking Maximum Available Space**: Ensure that each state (bitmask) is processed with the maximum available space to avoid redundant checks and ensure optimality.
