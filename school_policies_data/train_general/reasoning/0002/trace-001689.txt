To solve this problem, we need to determine if two players, Little X and Little Y, can collectively pass all the levels of a game by combining the levels they can individually pass. The solution involves checking if the union of the levels they can pass covers all levels from 1 to n.

### Approach
1. **Read Input**: Read the total number of levels `n` and the levels each player can pass.
2. **Combine Levels**: Collect the levels passed by both players into sets to handle duplicates automatically.
3. **Check Coverage**: Verify if the combined set of levels covers all levels from 1 to `n` by checking the size of the set against `n`.

### Solution Code
```python
n = int(input())
x_levels = list(map(int, input().split()))[1:]
y_levels = list(map(int, input().split()))[1:]
combined = set(x_levels) | set(y_levels)
print("I become the guy." if len(combined) == n else "Oh, my keyboard!")
```

### Explanation
1. **Reading Input**: The input is read and parsed to extract the levels each player can pass. The first number in each line after `n` indicates the count of levels, which is followed by the actual levels.
2. **Combining Levels**: Using sets ensures that each level is counted only once, even if both players can pass the same level.
3. **Checking Coverage**: By comparing the size of the combined set to `n`, we determine if all levels from 1 to `n` are covered. If they are, the output is positive; otherwise, it is negative.

This approach efficiently handles duplicates and ensures that all levels are checked in linear time relative to the input size, making it both optimal and straightforward.
