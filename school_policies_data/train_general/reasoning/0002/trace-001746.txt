To solve this problem, we need to verify if the total cost (T) provided for each product in a bill matches the calculated product of the price (P) and quantity (Q). The solution involves reading input values, performing the necessary calculations, and outputting the results based on the verification.

### Approach
1. **Read Input**: First, read the number of products, N.
2. **Process Each Product**: For each of the N products, read the values of P (price), Q (quantity), and T (total cost).
3. **Verification**: Check if the product of P and Q equals T. If they match, output "YES"; otherwise, output "NO".

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    index = 1
    for _ in range(n):
        p = int(input[index])
        q = int(input[index + 1])
        t = int(input[index + 2])
        index += 3
        if p * q == t:
            print("YES")
        else:
            print("NO")

main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and split into a list of strings for efficient processing. This is particularly useful for handling larger inputs more efficiently.
2. **Processing Each Line**: The input values are processed sequentially. The first value is the number of products, followed by triples of values representing P, Q, and T for each product.
3. **Verification Check**: For each product, the product of P and Q is computed and compared to T. The result of this comparison determines whether "YES" or "NO" is printed.

This approach ensures that the solution is both efficient and straightforward, handling all edge cases within the given constraints.
