To solve this problem, we need to determine the earliest day when Polycarp will have solved at least half of the total number of problems he plans to solve during his training period. This day is referred to as the equator day.

### Approach
1. **Problem Analysis**: 
   - Polycarp trains for `n` days, solving `a_i` problems on the `i-th` day.
   - We need to find the first day where the cumulative number of problems solved up to that day is at least half of the total problems scheduled for all days.

2. **Key Insight**:
   - Calculate the total number of problems, `total_sum`.
   - Compute the target as `(total_sum + 1) // 2`, which ensures we account for both even and odd totals correctly, effectively rounding up the half-point.

3. **Algorithm**:
   - Iterate through each day, accumulating the number of problems solved.
   - Check if the cumulative sum meets or exceeds the target. The first day this condition is met is the equator day.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    total = sum(a)
    target = (total + 1) // 2
    current = 0
    for i in range(n):
        current += a[i]
        if current >= target:
            print(i + 1)
            return

main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.read()` for efficiency, especially given the constraints.
2. **Total Calculation**: The total number of problems is computed using `sum(a)`.
3. **Target Calculation**: The target is determined as `(total + 1) // 2` to handle both even and odd totals correctly.
4. **Cumulative Check**: We iterate through each day, maintaining a running total of problems solved. The first day this total meets or exceeds the target is printed as the result.

This approach ensures we efficiently determine the equator day in linear time, which is optimal given the problem constraints.
