To solve this problem, we need to determine the number of integers within a given range [a, b] that are divisible by a given integer k. The solution should efficiently handle very large values of k, a, and b, up to 10^18.

### Approach
The key insight is to use mathematical properties of division and floor functions to avoid iterating through each number in the range. The approach involves:
1. Calculating the number of multiples of k up to the upper bound b.
2. Calculating the number of multiples of k just below the lower bound a.
3. Subtracting these two results to get the count of multiples within the range [a, b].

The formula used is:
\[ \text{count} = \left\lfloor \frac{b}{k} \right\rfloor - \left\lfloor \frac{a-1}{k} \right\rfloor \]
This formula works because it efficiently counts the multiples of k by leveraging integer division, which correctly handles both positive and negative ranges.

### Solution Code
```python
k, a, b = map(int, input().split())
count = (b // k) - ((a - 1) // k)
print(count)
```

### Explanation
1. **Reading Input:** The input values k, a, and b are read from standard input.
2. **Calculating Upper Bound Multiples:** The term \( \left\lfloor \frac{b}{k} \right\rfloor \) gives the number of multiples of k from the smallest possible integer up to b.
3. **Calculating Lower Bound Adjustment:** The term \( \left\lfloor \frac{a-1}{k} \right\rfloor \) adjusts for the numbers just below the lower bound a, ensuring we do not include any numbers less than a.
4. **Result Calculation:** Subtracting the lower bound adjustment from the upper bound multiples gives the exact count of multiples of k within the range [a, b].

This approach efficiently computes the result in constant time, O(1), making it suitable for very large input values.
