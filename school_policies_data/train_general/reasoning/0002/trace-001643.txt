To solve this problem, we need to determine the maximum and minimum amount of money the airport can earn when selling tickets to `n` passengers given `m` planes with a certain number of initial empty seats. Each passenger chooses a plane, and the ticket cost is equal to the number of empty seats in the chosen plane at the time of purchase. The goal is to maximize and minimize the total revenue respectively.

### Approach

1. **Maximize Revenue**:
   - **Greedy Strategy**: Always select the plane with the maximum number of available seats. This is achieved using a max-heap (priority queue) where we repeatedly extract the maximum value, add it to the total revenue, and then push the decremented value back into the heap if it remains positive.

2. **Minimize Revenue**:
   - **Greedy Strategy**: Always select the plane with the minimum number of available seats. This is achieved using a min-heap (priority queue) where we repeatedly extract the minimum value, add it to the total revenue, and then push the decremented value back into the heap if it remains positive.

### Solution Code

```python
import heapq

n, m = map(int, input().split())
a = list(map(int, input().split()))

def calculate_max_sum(n, a):
    heap = [-x for x in a]
    heapq.heapify(heap)
    total = 0
    for _ in range(n):
        current = -heapq.heappop(heap)
        total += current
        new_val = current - 1
        if new_val > 0:
            heapq.heappush(heap, -new_val)
    return total

def calculate_min_sum(n, a):
    heap = a.copy()
    heapq.heapify(heap)
    total = 0
    for _ in range(n):
        current = heapq.heappop(heap)
        total += current
        new_val = current - 1
        if new_val > 0:
            heapq.heappush(heap, new_val)
    return total

max_sum = calculate_max_sum(n, a)
min_sum = calculate_min_sum(n, a)

print(max_sum, min_sum)
```

### Explanation

- **Maximize Revenue**:
  - Convert the list of available seats into a max-heap using negative values (since Python's `heapq` module only provides a min-heap).
  - For each passenger, extract the maximum value (using negative values to simulate a max-heap), add it to the total, decrement the value by 1, and push it back into the heap if it remains positive.

- **Minimize Revenue**:
  - Use a min-heap directly with the available seats.
  - For each passenger, extract the minimum value, add it to the total, decrement the value by 1, and push it back into the heap if it remains positive.

This approach efficiently ensures that we always select the optimal plane for each passenger to achieve the desired maximum and minimum revenue using greedy strategies with heaps, resulting in a time complexity of O(n log m) for both cases, where `n` is the number of passengers and `m` is the number of planes.
