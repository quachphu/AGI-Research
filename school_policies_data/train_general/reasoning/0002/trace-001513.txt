To solve this problem, we need to determine if a given 4-character string consists of exactly two different characters, each appearing exactly twice. 

### Approach
1. **Input Handling**: Read the input string.
2. **Frequency Counting**: Use a dictionary to count the occurrences of each character in the string.
3. **Validation Check**: Ensure there are exactly two different characters and each character appears exactly twice.

### Solution Code
```python
def main():
    from collections import Counter
    s = input().strip()
    counts = Counter(s)
    if len(counts) == 2 and all(v == 2 for v in counts.values()):
        print("Yes")
    else:
        print("No")

main()
```

### Explanation
1. **Reading Input**: The input string `S` is read from standard input.
2. **Counting Frequencies**: Using the `Counter` class from the `collections` module, we count how many times each character appears in the string.
3. **Checking Conditions**: 
   - Ensure there are exactly two distinct characters.
   - Verify that each of these characters appears exactly twice.
4. **Output Result**: Print "Yes" if both conditions are met, otherwise print "No".

This approach efficiently checks the required conditions using a frequency counter, ensuring that the solution is both concise and easy to understand.
