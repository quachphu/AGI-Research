To solve this problem, we need to add comments to each command line in an nginx configuration file by appending the server name corresponding to the IP address found in each command line. 

### Approach
1. **Input Reading**: Read the number of servers and the number of command lines.
2. **Server Information Storage**: Store the server names and their corresponding IP addresses in a dictionary for quick lookup.
3. **Command Processing**: For each command line, extract the IP address, look up the corresponding server name from the dictionary, and append the server name as a comment to the command line.

### Solution Code
```python
import sys

def main():
    n, m = map(int, sys.stdin.readline().split())
    ip_to_name = {}
    for _ in range(n):
        name, ip = sys.stdin.readline().strip().split()
        ip_to_name[ip] = name
    for _ in range(m):
        line = sys.stdin.readline().strip()
        ip_part = line.split(' ', 1)[1].rstrip(';')
        name = ip_to_name[ip_part]
        print(f"{line} #{name}")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The first line of input contains two integers, `n` (number of servers) and `m` (number of command lines).
2. **Storing Server Information**: For each server, read the name and IP address, then store them in a dictionary where the IP address is the key and the server name is the value.
3. **Processing Commands**: For each command line, split the line to separate the command and the IP part. Extract the IP address by removing the trailing semicolon. Use the IP address to look up the server name in the dictionary and append the server name as a comment to the original command line.

This approach ensures efficient lookup of server names using a dictionary, resulting in a time complexity of O(n + m), where n is the number of servers and m is the number of command lines. This makes the solution both efficient and straightforward.
