To solve this problem, we need to determine the volume of Ber-Cola to add to each mug so that all mugs end up with the same volume, using exactly the given amount of liquid from the bottle. The solution must ensure that the final volume in each mug is the same and the bottle is emptied completely.

### Approach
1. **Understand the Problem Requirements**: We need to add liquid to each mug such that all mugs have the same volume, and the total added liquid equals the given amount `b`.
2. **Formulate the Solution**:
   - Let the final volume in each mug be `x`. The volume added to each mug `i` will be `x - a_i`, where `a_i` is the current volume in the mug.
   - The sum of all added volumes must equal `b`, leading to the equation `sum(x - a_i) = b`.
   - Solving this equation gives `x = (sum(a_i) + b) / n`, where `sum(a_i)` is the sum of the current volumes in all mugs.
   - Check if this `x` is at least as large as the maximum current volume in any mug. If not, it's impossible to achieve equal volumes without removing liquid, so the answer is `-1`.

### Solution Code
```python
n, b = map(int, input().split())
a = list(map(int, input().split()))

sum_a = sum(a)
max_a = max(a)
x = (sum_a + b) / n

if x < max_a:
    print(-1)
else:
    for ai in a:
        print("{0:.6f}".format(x - ai))
```

### Explanation
1. **Reading Input**: The first line reads the number of mugs `n` and the volume `b` in the bottle. The second line reads the current volumes in each mug.
2. **Calculate Required Values**:
   - Compute the sum of current volumes `sum_a`.
   - Determine the maximum current volume `max_a`.
   - Compute the target volume `x` each mug should have using the formula derived.
3. **Check Feasibility**: If `x` is less than the maximum current volume, output `-1` as it's impossible to equalize without removing liquid. Otherwise, compute and print the required addition for each mug formatted to six decimal places.

This approach ensures that we efficiently determine the solution or its impossibility using straightforward arithmetic and checks, adhering to the problem constraints and requirements.
