   - **Arrival**: When an employee arrives, find the longest free interval, split it, and update the data structures.
   - **Departure**: When an employee leaves, merge adjacent free intervals and update the data structures.
   - **Range Query**: Use the Fenwick Tree to quickly compute the number of coats in a given range.

1. **Fenwick Tree**: This data structure is used to efficiently count the number of coats in a given range using prefix sums.

6. **Range Queries**: The Fenwick Tree allows efficient range sum queries to answer how many coats are present between two hooks.

This approach ensures that all operations (arrival, departure, and range queries) are handled efficiently, making the solution scalable for large input sizes.
