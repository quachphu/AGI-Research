To solve this problem, we need to simulate the movement of a dice based on a series of rotational instructions and calculate the sum of the numbers appearing on the top face after each rotation. The initial state of the dice is given, and each rotation changes the orientation of the dice in a specific way.

### Approach
1. **Initialization**: Start with the dice in the initial orientation where the top face is 1, south face is 2, east face is 3, north face is 5, west face is 4, and bottom face is 6.
2. **Processing Instructions**: For each instruction (North, East, South, West, Right, Left), update the dice's orientation accordingly. Each rotation affects the faces of the dice in a specific pattern.
3. **Sum Calculation**: After each rotation, add the value of the top face to a running total, starting with the initial top face value of 1.

import sys

            break

2. **Dice State Management**: Each instruction is processed by updating the dice's faces based on the rotation. The rotations (North, South, East, West) change the top, bottom, north, and south faces, while horizontal rotations (Right, Left) change the north, east, south, and west faces.
3. **Sum Calculation**: After each rotation, the current top face value is added to the total sum, which starts with the initial top face value of 1.

This approach ensures that each rotation is accurately modeled, and the sum is correctly computed based on the dice's orientation after each move.
