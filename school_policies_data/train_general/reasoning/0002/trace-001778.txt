To solve this problem, we need to determine the probability that the princess wins a game where she and a dragon take turns drawing mice from a bag. The game ends when a white mouse is drawn, and the dragon's turn causes another mouse to panic and jump out of the bag. The solution involves dynamic programming to efficiently compute the probabilities for all possible states of the game.

### Approach
1. **Dynamic Programming (DP) Setup**: We use a 2D array `dp` where `dp[w][b]` represents the probability of the princess winning starting from `w` white mice and `b` black mice.
2. **Base Cases**: If there are no white mice (`w == 0`), the princess cannot win, so `dp[0][b] = 0`.
3. **Recurrence Relation**: For each state `(w, b)`, compute the probability considering both the princess's and the dragon's turns:
   - **Princess's Turn**: She draws a white mouse with probability `w/(w + b)` and wins immediately.
   - **Dragon's Turn**: If the princess draws a black mouse, the dragon then draws a mouse, and another mouse panics. The probability of the princess winning from the resulting state is computed recursively.
4. **Bottom-Up Calculation**: Fill the DP table by iterating over all possible states in increasing order of the total number of mice to ensure dependencies are resolved.

def main():
    import sys
    w, b = map(int, sys.stdin.readline().split())
    max_w = 1000
    max_b = 1000

    # Initialize dp table with dimensions (max_w + 1) x (max_b + 1)
    dp = [[0.0 for _ in range(max_b + 1)] for __ in range(max_w + 1)]
    
    # Iterate over all possible sums of w and b
    for s in range(0, max_w + max_b + 1):
        for w_val in range(0, max_w + 1):
            b_val = s - w_val
            if b_val < 0 or b_val > max_b:
                continue
            
            if w_val == 0:
                dp[w_val][b_val] = 0.0
                continue
            
            total = w_val + b_val
            if total == 0:
                dp[w_val][b_val] = 0.0
                continue
            
            # Probability princess wins on her turn
            prob_white = w_val / total
            res = prob_white
            
            if b_val > 0:
                prob_black = b_val / total
                new_b_dragon = b_val - 1
                dragon_total = w_val + new_b_dragon
                
                if dragon_total == 0:
                    dragon_contribution = 0.0
                else:
                    prob_dragon_white = w_val / dragon_total
                    prob_dragon_black = new_b_dragon / dragon_total
                    
                    # State after dragon draws black
                    state_after_dragon_w = w_val
                    state_after_dragon_b = new_b_dragon - 1
                    m_panic = state_after_dragon_w + state_after_dragon_b
                    
                    if m_panic <= 0:
                        panic_contribution = 0.0
                    else:
                        panic_total = state_after_dragon_w + state_after_dragon_b
                        prob_white_panic = state_after_dragon_w / panic_total
                        prob_black_panic = state_after_dragon_b / panic_total
                        
                        # Possible new states after panic
                        new_w1 = state_after_dragon_w - 1
                        new_b1 = state_after_dragon_b
                        new_w2 = state_after_dragon_w
                        new_b2 = state_after_dragon_b - 1
                        
                        part1 = 0.0
                        if new_w1 >= 0 and new_b1 >= 0:
