To solve this problem, we need to determine the number of balls remaining after one ball with a specific string is thrown away. We are given two types of balls, each labeled with different strings, and their respective counts. The solution involves checking which type of ball is thrown away and adjusting the counts accordingly.

### Approach
1. **Read Input:** First, we read the strings on the balls (S and T), their initial counts (A and B), and the string (U) of the ball that is thrown away.
2. **Determine Thrown Ball:** Check if the thrown ball's string (U) matches the first string (S). If it does, decrement the count of S balls. Otherwise, decrement the count of T balls.
3. **Output the Result:** Print the updated counts of the balls.

### Solution Code
```python
def main():
    S, T = input().split()
    A, B = map(int, input().split())
    U = input().strip()
    if U == S:
        A -= 1
    else:
        B -= 1
    print(A, B)

main()
```

### Explanation
1. **Reading Input:** The input is read in three parts. The first line contains the strings S and T. The second line contains the initial counts A and B. The third line contains the string U of the ball that is thrown away.
2. **Adjusting Counts:** By comparing U with S, we determine whether to reduce the count of S balls (A) or T balls (B). If U matches S, we decrement A by 1. Otherwise, we decrement B by 1.
3. **Output:** The final counts of S and T balls are printed in the required format.

This approach efficiently processes the input and adjusts the counts in constant time, ensuring an optimal solution.
