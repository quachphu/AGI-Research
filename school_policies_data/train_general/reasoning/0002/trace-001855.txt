To solve this problem, we need to determine the total time Joisino will take to solve all problems in a programming contest after consuming each of the available drinks. Each drink affects the time required to solve exactly one problem, and we need to compute the total time for each drink independently.

### Approach
1. **Read Input**: First, we read the number of problems and their respective solving times. Then, we read the number of drinks and their effects.
2. **Compute Original Sum**: Calculate the total time required to solve all problems without any drink.
3. **Adjust for Each Drink**: For each drink, compute the new total time by adjusting the original sum with the effect of the drink. This is done by subtracting the original time of the affected problem and adding the new time specified by the drink.

This approach ensures that we efficiently compute the total time for each drink in constant time after an initial linear time computation of the original sum.

### Solution Code
```python
n = int(input())
t_list = list(map(int, input().split()))
original_sum = sum(t_list)
m = int(input())

for _ in range(m):
    p, x = map(int, input().split())
    diff = x - t_list[p-1]
    print(original_sum + diff)
```

### Explanation
1. **Reading Input**: The input is read in the specified format. The first line gives the number of problems, the second line their solving times, the third line the number of drinks, and subsequent lines describe each drink's effect.
2. **Original Sum Calculation**: The sum of all problem-solving times is computed once. This sum is the baseline without any drinks.
3. **Adjusting for Drinks**: For each drink, the difference between the new time and the original time for the affected problem is calculated. This difference is added to the original sum to get the new total time, which is then printed immediately.

This method ensures that each drink's effect is computed in constant time, making the solution efficient even for the upper limits of the input constraints.
