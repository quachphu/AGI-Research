To solve this problem, we need to calculate the total length of carpet required to cover a series of stairs, where each step's height is determined by one of two possible functions. The solution involves computing the height of each step based on the given functions and summing up the vertical and horizontal contributions of each step to the total carpet length.

### Approach
1. **Understanding the Height Functions**:
   - **Function 1**: The height of the i-th step is `2 * i`.
   - **Function 2**: The height of the i-th step is the height of the previous step plus 1.

2. **Carpet Length Calculation**:
   - Each step contributes both a vertical rise and a horizontal run to the carpet length.
   - The vertical rise for the i-th step is the difference between its height and the previous step's height.
   - The horizontal run for each step is a fixed width `W`.

3. **Iterative Calculation**:
   - For each test case, iterate through each step, compute its height using the specified function, and accumulate the total carpet length by adding the vertical and horizontal contributions of each step.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        W = int(input[ptr])
        N = int(input[ptr + 1])
        ptr += 2
        A = list(map(int, input[ptr:ptr + N]))
        ptr += N
        
        total = 0
        y_prev = 0
        for i in range(1, N + 1):
            a = A[i - 1]
            if a == 1:
                y_current = 2 * i
            else:
                y_current = y_prev + 1
            diff = y_current - y_prev
            total += diff + W
            y_prev = y_current
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints. We parse the input values using a pointer to track our position in the input list.
2. **Processing Each Test Case**:
   - For each test case, read the width `W` and the number of steps `N`.
   - Read the list of function choices `A` for each step.
3. **Computing Heights and Carpet Length**:
   - Initialize the previous height `y_prev` to 0 (starting from the floor).
   - For each step, determine its height based on the function specified in `A`.
   - Calculate the vertical difference from the previous step and add both the vertical and horizontal contributions to the total length.
   - Update `y_prev` to the current height for the next iteration.

This approach efficiently computes the required carpet length by iterating through each step once, ensuring a time complexity of O(N) per test case, which is optimal given the problem constraints.
