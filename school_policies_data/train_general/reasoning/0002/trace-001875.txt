To solve this problem, we need to determine the largest integer \( x \) for each pair of integers \( p \) and \( q \) such that \( p \) is divisible by \( x \) but \( x \) is not divisible by \( q \). 

### Approach
1. **Check Divisibility**: If \( p \) is not divisible by \( q \), the answer is simply \( p \) because \( p \) itself is the largest divisor of \( p \) that is not divisible by \( q \).
2. **Factorize \( q \)**: If \( p \) is divisible by \( q \), we factorize \( q \) into its prime factors.
3. **Compute Maximum \( x \)**: For each prime factor of \( q \), adjust the exponent in \( p \) to ensure the resulting divisor is not divisible by \( q \). The goal is to find the maximum divisor by reducing the exponent of one prime factor in \( p \) such that the result is not divisible by \( q \).

### Solution Code
```python
def factorize(n):
    factors = []
    i = 2
    while i * i <= n:
        if n % i == 0:
            cnt = 0
            while n % i == 0:
                cnt += 1
                n = n // i
            factors.append((i, cnt))
        i += 1
    if n > 1:
        factors.append((n, 1))
    return factors

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    t = int(input[idx])
    idx += 1
    for _ in range(t):
        p = int(input[idx])
        q = int(input[idx + 1])
        idx += 2
        if p % q != 0:
            print(p)
        else:
            factors = factorize(q)
            max_x = 0
            for (s, c) in factors:
                temp_p = p
                a = 0
                while temp_p % s == 0:
                    a += 1
                    temp_p = temp_p // s
                exponent_d = a - c + 1
                d = s ** exponent_d
                x_i = p // d
                if x_i > max_x:
                    max_x = x_i
            print(max_x)

if __name__ == "__main__":
    main()
```

2. **Adjust Exponents**: For each prime factor \( s \) of \( q \), compute how many times \( s \) divides \( p \) (denoted as \( a \)). Adjust \( s \)'s exponent in \( p \) to be \( c-1 \) (where \( c \) is the exponent in \( q \)) to ensure the resulting divisor is not divisible by \( q \).
3. **Compute Divisors**: For each adjusted exponent, compute the divisor \( x_i \) by dividing \( p \) by \( s \) raised to the adjusted exponent. Track the maximum \( x_i \) across all prime factors of \( q \).

This approach efficiently handles the constraints and ensures the solution is optimal by leveraging prime factorization and exponent adjustment.
