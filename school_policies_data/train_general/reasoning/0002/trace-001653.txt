To solve this problem, we need to determine the minimum possible tax Mr. Funt has to pay by optimally splitting his income into parts. The tax for each part is the largest proper divisor of that part. The goal is to minimize the total tax by splitting the income into parts such that each part's tax is minimized.

### Approach
1. **Prime Check**: If the number is a prime, its largest proper divisor is 1. Thus, if the income is a prime number, the minimum tax is 1.
2. **Even Numbers**: For even numbers greater than 2, the minimum tax can be achieved by splitting the number into two primes (as per Goldbach's conjecture), resulting in a tax sum of 2.
3. **Odd Numbers**: For odd composite numbers:
   - If the number can be split into 2 and another prime (i.e., `n-2` is prime), the tax sum is 2.
   - If not, the minimum tax is achieved by splitting into three parts, resulting in a tax sum of 3.

### Solution Code
```python
n = int(input())

def is_prime(m):
    if m <= 1:
        return False
    if m == 2:
        return True
    if m % 2 == 0:
        return False
    sqrt_m = int(m ** 0.5) + 1
    for i in range(3, sqrt_m, 2):
        if m % i == 0:
            return False
    return True

if n % 2 == 0:
    print(1 if n == 2 else 2)
else:
    if is_prime(n):
        print(1)
    else:
        print(2 if is_prime(n - 2) else 3)
```

### Explanation
1. **Prime Check Function**: The `is_prime` function efficiently checks if a number is prime by testing divisibility up to its square root.
2. **Handling Even Numbers**: If the input number is even and not 2, it is split into two primes, resulting in a tax sum of 2.
3. **Handling Odd Numbers**:
   - If the number is prime, the tax is 1.
   - If the number is composite, check if `n-2` is prime. If true, the tax sum is 2; otherwise, the tax sum is 3.

This approach ensures that we efficiently determine the minimal tax by leveraging mathematical properties and efficient primality checks.
