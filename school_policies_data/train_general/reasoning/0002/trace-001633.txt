The solution involves optimally selecting these drink sets and distributing the portions to maximize the number of students who get their favorite drink.

2. **Calculate Required Sets**: For each drink type, determine the minimum number of sets required to cover all students preferring that drink. This is calculated as the ceiling of half the number of students preferring that drink.
3. **Generate Gains**: For each drink type, generate the possible gains from each set. The first few sets contribute 2 portions each, and the last set may contribute 1 or 2 portions depending on whether the count of students preferring that drink is odd or even.
4. **Optimize Selection**: Collect all possible gains, sort them in descending order, and select the top gains corresponding to the required number of sets. Sum these gains to get the maximum number of students who can get their favorite drink.

import sys

def main():
    n, k = map(int, sys.stdin.readline().split())
    freq = [0] * (k + 1)
    for _ in range(n):
        a = int(sys.stdin.readline())
        freq[a] += 1

        num_2s = t_j - 1
        gains.extend([2] * num_2s)

        gains.append(last)

    s = (n + 1) // 2  # ceil(n / 2)
    total = sum(gains[:s])

if __name__ == "__main__":
