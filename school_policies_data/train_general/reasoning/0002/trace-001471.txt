To solve this problem, we need to generate a list of leap years between given years for multiple datasets. A leap year is determined by specific divisibility rules, and we must handle each dataset efficiently while ensuring the correct formatting of the output.

### Approach
1. **Leap Year Determination**: A year is a leap year if:
   - It is divisible by 400, or
   - It is divisible by 4 but not by 100.
   
2. **Input Handling**: Read input lines until encountering "0 0", which signifies the end of input. Each line (except the terminating "0 0") represents a dataset with two integers, a and b.

3. **Processing Datasets**: For each dataset, generate all years between a and b (inclusive) and check each year against the leap year conditions.

4. **Output Formatting**: For each dataset, print all leap years found. If no leap years exist, print "NA". Separate the output of consecutive datasets with a blank line.

### Solution Code
```python
def is_leap(year):
    if year % 400 == 0:
        return True
    if year % 100 == 0:
        return False
    if year % 4 == 0:
        return True
    return False

def main():
    import sys
    datasets = []
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        a, b = map(int, line.split())
        if a == 0 and b == 0:
            break
        datasets.append((a, b))
    
    for i in range(len(datasets)):
        a, b = datasets[i]
        leap_years = []
        for year in range(a, b + 1):
            if is_leap(year):
                leap_years.append(year)
        
        if not leap_years:
            print("NA")
        else:
            for year in leap_years:
                print(year)
        
        if i != len(datasets) - 1:
            print()

if __name__ == "__main__":
    main()
```

### Explanation
1. **Leap Year Check Function**: The `is_leap` function checks if a given year is a leap year based on the defined rules.
2. **Reading Input**: The `main` function reads input lines, processes them into datasets, and stops when encountering "0 0".
3. **Processing Each Dataset**: For each dataset, the code iterates through the range from a to b, checks each year using `is_leap`, and collects leap years.
4. **Output Handling**: After processing each dataset, the results are printed. If there are no leap years, "NA" is printed. A blank line is inserted between the outputs of consecutive datasets to meet the formatting requirements.

This approach ensures that the solution efficiently handles multiple datasets, correctly identifies leap years, and formats the output as specified.
