To solve this problem, we need to maximize the sum of elements at even indices in an array after reversing at most one subarray. The key insight is that reversing an even-length subarray can potentially increase the sum of elements at even indices by swapping elements at even and odd positions within the subarray.

### Approach
1. **Original Sum Calculation**: Compute the sum of elements at even indices in the original array.
2. **Transformed Array**: Create a transformed array where each element at an even index is negated, and each element at an odd index remains the same. This transformation helps in evaluating the potential gain from reversing subarrays.
3. **Maximum Even-Length Subarray Sum**: Use dynamic programming to find the maximum sum of an even-length subarray in the transformed array. This sum represents the maximum gain achievable by reversing an optimal subarray.

import sys

def compute_max_even_subarray(arr):
    max_even = -float('inf')
    current_even = -float('inf')
    current_odd = -float('inf')

        # Calculate new_even
        if current_odd != -float('inf'):
