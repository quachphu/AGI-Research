To solve this problem, we need to determine the number of ways to choose integers A and B such that the second board, formed by shifting the first board by A rows and B columns, is symmetric. A board is symmetric if for every cell (i, j), the value at (i, j) is the same as the value at (j, i).

### Approach
1. **Understanding Symmetry via Shifts**: The key insight is that shifting the original board by A rows and B columns and then checking for symmetry can be transformed into checking if the original board has a specific symmetry. Specifically, for the shifted board to be symmetric, the original board must satisfy the condition where each element at position (u, v) is equal to the element at position ((v + k) % N, (u - k) % N) for some k, where k = (A - B) % N.

2. **Efficient Check for Symmetry**: Instead of checking all possible pairs (A, B) directly, we check for each possible k (0 to N-1) if the original board satisfies the symmetry condition for that k. If a valid k is found, there are N corresponding pairs (A, B) such that A - B ≡ k (mod N), leading to N valid pairs for each valid k.

3. **Algorithm Complexity**: By focusing on k values and checking each k in O(N^2) time, we reduce the overall complexity from O(N^4) to O(N^3), making the solution feasible for large N (up to 300).

### Solution Code
```python
n = int(input())
grid = [input().strip() for _ in range(n)]
count = 0

for k in range(n):
    valid = True
    for u in range(n):
        for v in range(n):
            x = (v + k) % n
            y = (u - k) % n
            if grid[u][v] != grid[x][y]:
                valid = False
                break
        if not valid:
            break
    if valid:
        count += 1

print(count * n)
```

### Explanation
1. **Reading Input**: The input is read and stored in a list of strings, each representing a row of the grid.
2. **Checking Validity for Each k**: For each possible k (from 0 to N-1), we check if the grid satisfies the symmetry condition. This involves verifying that for every cell (u, v), the value at (u, v) matches the value at ((v + k) % N, (u - k) % N).
3. **Counting Valid k Values**: If a k value is valid (i.e., the symmetry condition holds for all cells), it contributes N valid pairs (A, B) where A - B ≡ k (mod N).
4. **Output the Result**: The total number of valid pairs is the count of valid k values multiplied by N.

This approach efficiently reduces the problem complexity by leveraging the symmetry properties of the grid, ensuring the solution is both optimal and easy to understand.
