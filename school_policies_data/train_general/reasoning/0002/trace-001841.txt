To solve this problem, we need to determine the number of valid pairs of junctions that can be connected by a new road such that the shortest path between two specific junctions (s and t) does not decrease. 

### Approach
1. **Graph Representation**: Represent the town's junctions and roads using an adjacency list.
2. **Shortest Path Calculation**: Use Breadth-First Search (BFS) to compute the shortest distances from junction s to all other junctions and from junction t to all other junctions.
3. **Check Valid Pairs**: For each pair of junctions (u, v) that are not already connected by a road, check if adding a new road between them would not decrease the shortest path between s and t. This is done by ensuring that the sum of distances from s to u, plus 1 (for the new road), plus the distance from v to t is at least the original shortest path distance. Similarly, check the reverse path from s to v and then to t via u.

### Solution Code
```python
import sys
from collections import deque

def bfs(start, adj):
    n = len(adj) - 1  # adj is 1-based
    dist = [-1] * (n + 1)
    q = deque([start])
    dist[start] = 0
    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist

def main():
    n, m, s, t = map(int, sys.stdin.readline().split())
    existing_edges = set()
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, sys.stdin.readline().split())
        if u > v:
            u, v = v, u
        existing_edges.add((u, v))
        adj[u].append(v)
        adj[v].append(u)
    
    dist_s = bfs(s, adj)
    dist_t = bfs(t, adj)
    D = dist_s[t]
    
    count = 0
    for u in range(1, n + 1):
        for v in range(u + 1, n + 1):
            if (u, v) not in existing_edges:
                cond1 = (dist_s[u] + 1 + dist_t[v]) >= D
                cond2 = (dist_s[v] + 1 + dist_t[u]) >= D
                if cond1 and cond2:
                    count += 1
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Graph Representation**: The adjacency list `adj` is built from the input roads, and existing roads are stored in a set for quick lookup.
2. **BFS for Shortest Paths**: The BFS function computes the shortest path distances from a starting node to all other nodes. This is done twice, once starting from `s` and once from `t`.
3. **Valid Pair Check**: For each pair of junctions (u, v) not already connected by a road, we check if both possible paths (s -> u -> v -> t and s -> v -> u -> t) do not result in a shorter path than the original shortest distance between s and t. If both conditions hold, the pair is counted as valid.

This approach efficiently checks all potential new roads and ensures that the shortest path between s and t remains unchanged or increases, thus solving the problem within the given constraints.
