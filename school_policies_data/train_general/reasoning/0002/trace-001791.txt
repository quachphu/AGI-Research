To solve this problem, we need to find the largest number in an array that is not a perfect square. A perfect square is defined as a number that can be expressed as the square of an integer. The solution involves checking each element of the array to determine if it is a perfect square and then finding the maximum value among the non-perfect squares.

### Approach
1. **Input Reading**: Read the number of elements and the array elements from standard input.
2. **Check for Perfect Squares**: For each element in the array, determine if it is a perfect square. A number is a perfect square if it is non-negative and its square root is an integer.
3. **Collect Non-Perfect Squares**: Gather all elements that are not perfect squares into a list.
4. **Find Maximum**: Determine the maximum value from the list of non-perfect squares.

### Solution Code
```python
import math

def is_perfect_square(x):
    if x < 0:
        return False
    s = math.isqrt(x)
    return s * s == x

def main():
    n = int(input())
    arr = list(map(int, input().split()))
    non_squares = [num for num in arr if not is_perfect_square(num)]
    print(max(non_squares))

main()
```

### Explanation
1. **Reading Input**: The input is read using standard input functions. The first line gives the number of elements, and the second line provides the array elements.
2. **Perfect Square Check**: The function `is_perfect_square` checks if a number is a perfect square by verifying if the integer square root of the number squared equals the number itself. Negative numbers are automatically excluded as they cannot be perfect squares.
3. **Filtering Non-Perfect Squares**: Using a list comprehension, we filter out all elements that are perfect squares, leaving only those that are not.
4. **Finding Maximum**: The maximum value of the filtered list is printed, which is the required result.

This approach efficiently checks each element and ensures that we correctly identify the largest non-perfect square number in the array. The use of the `math.isqrt` function ensures accurate and efficient computation of integer square roots.
