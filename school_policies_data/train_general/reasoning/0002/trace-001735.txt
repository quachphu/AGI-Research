To solve this problem, we need to count the number of 2x2 squares in a given grid that can be rearranged to form the word "face". Each square must contain exactly one occurrence of each of the letters 'f', 'a', 'c', and 'e'.

### Approach
1. **Input Reading**: Read the dimensions of the grid (n rows and m columns) and then read the grid itself.
2. **Iterate Over Possible 2x2 Squares**: For each possible top-left corner of a 2x2 square in the grid, collect the four characters in that square.
3. **Check Validity**: Check if these four characters can be rearranged to form "face" by sorting them and comparing with the sorted version of "face" (which is ['a', 'c', 'e', 'f']).
4. **Count Valid Squares**: Maintain a counter to keep track of the number of valid 2x2 squares.

### Solution Code
```python
n, m = map(int, input().split())
grid = [input().strip() for _ in range(n)]
count = 0
target = sorted('face')

for i in range(n - 1):
    for j in range(m - 1):
        chars = [
            grid[i][j], grid[i][j+1],
            grid[i+1][j], grid[i+1][j+1]
        ]
        if sorted(chars) == target:
            count += 1

print(count)
```

### Explanation
1. **Reading Input**: The first line of input contains the dimensions of the grid. The subsequent lines represent the grid itself.
2. **Iterating Over Grid**: We loop through each possible starting position (i, j) for a 2x2 square. The loop runs from 0 to n-2 for rows and 0 to m-2 for columns to ensure we stay within the grid bounds.
3. **Collecting Characters**: For each 2x2 square starting at (i, j), we collect the four characters at positions (i, j), (i, j+1), (i+1, j), and (i+1, j+1).
4. **Checking Validity**: By sorting these four characters and comparing them to the sorted version of "face", we determine if they form a valid face. If they do, we increment our counter.
5. **Output Result**: Finally, we print the count of valid 2x2 squares.

This approach efficiently checks all possible 2x2 squares in the grid with a time complexity of O((n-1)*(m-1)), which is feasible given the constraints (1 ≤ n, m ≤ 50).
