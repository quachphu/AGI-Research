To solve this problem, we need to determine if we can rearrange the blocks in such a way that the sequence of stack heights becomes strictly increasing. The allowed moves are taking a block from the i-th stack and putting it into the (i+1)-th stack.

### Approach
The key insight is that the problem can be reduced to checking if the sum of the heights of the blocks is sufficient to form a strictly increasing sequence. The minimal required sum to form a strictly increasing sequence of `n` stacks is `0 + 1 + 2 + ... + (n-1)`, which is equivalent to `(n-1) * n / 2`. If the sum of the given block heights is at least this minimal sum, it is always possible to rearrange the blocks into a strictly increasing sequence. Otherwise, it is impossible.

### Solution Code
```python
import sys

def can_make_increasing():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        h = list(map(int, sys.stdin.readline().split()))
        total = sum(h)
        minimal = n * (n - 1) // 2
        print("YES" if total >= minimal else "NO")

can_make_increasing()
```

4. **Output Result:** If the total sum is at least the minimal required sum, print "YES"; otherwise, print "NO".
