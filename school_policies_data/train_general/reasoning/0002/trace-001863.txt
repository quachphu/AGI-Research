To solve this problem, we need to efficiently manage the connectivity between islands as we process a series of queries. The queries either connect two islands or check if two islands can communicate. This problem can be efficiently solved using the Disjoint Set Union (DSU) data structure with path compression and union by size optimizations.

### Approach
1. **Data Structure**: Use the DSU (Disjoint Set Union) data structure to keep track of connected components. This structure supports two main operations: `find` (to determine the root of an element) and `union` (to merge two sets).
2. **Union by Size**: When merging two sets, attach the smaller tree to the root of the larger tree to keep the tree depth small, which ensures efficient operations.
3. **Path Compression**: During the `find` operation, flatten the tree structure such that each node points directly to the root, which speeds up future operations.
4. **Efficient Input Handling**: Read all input at once for faster processing, especially given the large constraints.

### Solution Code
```python
import sys

def main():
    data = sys.stdin.read().split()
    ptr = 0
    N = int(data[ptr])
    ptr += 1
    Q = int(data[ptr])
    ptr += 1
    
    parent = list(range(N + 1))
    size = [1] * (N + 1)
    
    output = []
    
    def find(x):
        if parent[x] != x:
            parent[x] = find(parent[x])
        return parent[x]
    
    for _ in range(Q):
        t = int(data[ptr])
        x = int(data[ptr + 1])
        y = int(data[ptr + 2])
        ptr += 3
        
        if t == 0:
            x_root = find(x)
            y_root = find(y)
            if x_root != y_root:
                if size[x_root] < size[y_root]:
                    x_root, y_root = y_root, x_root
                parent[y_root] = x_root
                size[x_root] += size[y_root]
        else:
            x_root = find(x)
            y_root = find(y)
            output.append("Yes" if x_root == y_root else "No")
    
    print('\n'.join(output))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Initialization**: The DSU is initialized with each island as its own parent and a size array to track the size of each set.
2. **Union Operation**: For each union query (type 0), the roots of the two elements are found. If they are different, the smaller tree is merged into the larger tree, updating the parent and size arrays.
3. **Find Operation**: For each connectivity check (type 1), the roots of the two elements are compared. If they are the same, the islands are connected; otherwise, they are not.
4. **Efficiency**: The use of path compression and union by size ensures that each operation runs in nearly constant time, making the solution efficient even for the upper constraint limits.

This approach ensures that we handle up to 100,000 islands and queries efficiently, providing quick responses for both union and connectivity check operations.
