To solve this problem, we need to determine the minimum number of scalar multiplications required to multiply a chain of matrices efficiently. This is a classic dynamic programming problem where we break down the problem into smaller subproblems and use their solutions to build up the solution for the entire problem.

### Approach
1. **Dynamic Programming Table Setup**: We use a 2D table `m` where `m[i][j]` represents the minimum number of scalar multiplications needed to multiply matrices from index `i` to `j`.
2. **Chain Length Iteration**: We consider all possible chain lengths from 2 to `n` (since a single matrix requires no multiplications).
3. **Splitting the Chain**: For each chain length, we split the chain at every possible position and compute the cost of each split. The cost of multiplying two resulting matrices from the split is calculated using their dimensions.
4. **Optimal Substructure**: By iterating over all possible splits and taking the minimum cost, we build up the solution for larger chains using solutions of smaller sub-chains.

### Solution Code
```python
n = int(input())
p = []
for _ in range(n):
    r, c = map(int, input().split())
    if not p:
        p.append(r)
    p.append(c)

# Initialize the DP table
m = [[0] * n for _ in range(n)]

# l is the chain length
for l in range(2, n + 1):
    for i in range(n - l + 1):
        j = i + l - 1
        m[i][j] = float('inf')
        for k in range(i, j):
            cost = m[i][k] + m[k+1][j] + p[i] * p[k+1] * p[j+1]
            if cost < m[i][j]:
                m[i][j] = cost

print(m[0][n-1])
```

### Explanation
1. **Reading Input**: The input consists of the number of matrices followed by their dimensions. We construct an array `p` where each entry represents the number of rows or columns of the matrices in sequence.
2. **DP Table Initialization**: The table `m` is initialized with zeros. The entry `m[i][j]` will hold the minimum multiplications needed for matrices from index `i` to `j`.
3. **Filling the DP Table**: For each chain length starting from 2, we compute the minimum cost by considering all possible splits within the chain. The cost of each split is the sum of the costs of the two resulting sub-chains plus the cost of multiplying their results.
4. **Result Extraction**: The minimum number of scalar multiplications needed to multiply all matrices is found in `m[0][n-1]`.

This approach efficiently computes the solution using dynamic programming, ensuring that each subproblem is solved only once, leading to an optimal solution with a time complexity of O(n^3).
