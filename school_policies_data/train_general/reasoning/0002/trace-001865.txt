To solve this problem, we need to calculate the volumes of ice cream in two different types of containers for multiple test cases. The first container is a cone with a hemisphere on top, and the second is a cylinder. We will use precise mathematical formulas to compute these volumes and format the results to meet the required precision.

### Approach
1. **Understanding the Containers**:
   - The first container consists of a cone and a hemisphere with the same radius. The volume of this container is the sum of the cone's volume and the hemisphere's volume.
   - The second container is a simple cylinder, and its volume is calculated using the standard formula for a cylinder.

2. **Mathematical Formulas**:
   - **Cone Volume**: \(\frac{1}{3} \pi r_1^2 h_1\)
   - **Hemisphere Volume**: \(\frac{2}{3} \pi r_1^3\)
   - **Cylinder Volume**: \(\pi r_2^2 h_2\)

3. **Precision Handling**:
   - The input values are given up to two decimal places, and the output must be accurate up to six decimal places. Using Python's `math.pi` ensures high precision for calculations, and results are formatted to nine decimal places to match the sample output format.

### Solution Code
```python
import math

def main():
    import sys
    input_lines = sys.stdin.read().splitlines()
    T = int(input_lines[0])
    for line in input_lines[1:T+1]:
        r1, h1, r2, h2 = map(float, line.strip().split())
        # Calculate volume for the first container (cone + hemisphere)
        cone_volume = (1.0/3.0) * math.pi * (r1 ** 2) * h1
        hemisphere_volume = (2.0/3.0) * math.pi * (r1 ** 3)
        total_volume1 = cone_volume + hemisphere_volume
        # Calculate volume for the second container (cylinder)
        total_volume2 = math.pi * (r2 ** 2) * h2
        # Print with 9 decimal places as per the example
        print("{0:.9f} {1:.9f}".format(total_volume1, total_volume2))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given multiple test cases. Each line is processed to extract the radius and height values for the containers.
2. **Volume Calculations**: Using the mathematical formulas, we compute the volumes for both containers. The cone and hemisphere volumes are calculated separately and then summed for the first container. The cylinder volume is calculated directly.
3. **Precision Formatting**: The results are formatted to nine decimal places using Python's string formatting to ensure the output matches the required precision and format as shown in the sample.

This approach efficiently handles the problem constraints and ensures accurate and precise results formatted correctly for each test case.
