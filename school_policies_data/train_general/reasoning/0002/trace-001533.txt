To solve this problem, we need to normalize a given BerOS path by reducing the number of '/' characters to the minimum possible. The goal is to ensure that the path is represented in its simplest form, using the fewest possible slashes while maintaining the correct structure.

### Approach
1. **Input Reading**: Read the input path which consists of lowercase Latin letters and slashes.
2. **Splitting the Path**: Split the input string by the '/' character. This will handle multiple consecutive slashes by producing empty strings in the resulting list.
3. **Filtering Empty Parts**: Remove all empty strings from the list obtained from splitting the path. These empty strings are a result of consecutive slashes.
4. **Handling Special Cases**: If the filtered list is empty (indicating the root directory), return '/'. Otherwise, join the non-empty parts with a single '/' and prepend a '/' to form the normalized path.

### Solution Code
```python
def normalize_path():
    path = input().strip()
    parts = path.split('/')
    filtered = [p for p in parts if p]
    if not filtered:
        print('/')
    else:
        print('/' + '/'.join(filtered))

normalize_path()
```

### Explanation
1. **Reading Input**: The input is read and stripped of any leading or trailing whitespace (though the problem guarantees no whitespace, this is a precaution).
2. **Splitting the Path**: The path is split using '/' as the delimiter. For example, the input `//usr///local//nginx/sbin` becomes `['', '', 'usr', '', '', 'local', '', 'nginx', 'sbin', '']`.
3. **Filtering Parts**: Empty strings from the split result are removed. This converts the example list to `['usr', 'local', 'nginx', 'sbin']`.
4. **Constructing Normalized Path**: If the filtered list is empty, the path is the root directory, so we print '/'. Otherwise, we join the filtered parts with '/' and prepend a '/' to form the normalized path, resulting in `/usr/local/nginx/sbin` for the example.

This approach efficiently handles all edge cases, including multiple consecutive slashes, trailing slashes, and the root directory case, ensuring the path is normalized with the minimum necessary slashes.
