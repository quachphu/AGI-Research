To solve this problem, we need to determine if we can clear a Tetris field by placing 2x1 vertical figures in such a way that all columns can be reduced to zero height through a series of operations. The key insight is that the parity (even or odd) of the initial heights of the columns plays a crucial role in determining the possibility of clearing the field.

### Approach
1. **Single Column Case**: If there is only one column (n=1), it is always possible to clear the field. This is because we can repeatedly add 2 to the column and then subtract the entire height in one step.
2. **Multiple Columns Case**: For multiple columns (n>1), the solution depends on the parity of the initial heights. All columns must have the same parity (all even or all odd). If they do not, it is impossible to clear the field. This is because each operation (adding 2 to a column and then subtracting the minimum height) must maintain consistent parity across all columns to eventually reach zero.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    if n == 1:
        print("YES")
    else:
        parity = a[0] % 2
        valid = True
        for num in a[1:]:
            if num % 2 != parity:
                valid = False
                break
        print("YES" if valid else "NO")
```

### Explanation
1. **Reading Input**: The code reads the number of test cases and processes each test case individually.
2. **Single Column Check**: For each test case, if there is only one column, the answer is immediately "YES".
3. **Parity Check**: For multiple columns, the code checks if all columns have the same parity. If they do, the answer is "YES"; otherwise, it is "NO".

This approach efficiently determines the possibility of clearing the Tetris field by leveraging the parity check, ensuring optimal performance even for the upper constraint limits.
