To solve this problem, we need to determine if it's possible to travel from planet 0 to a given planet x using spacecrafts with specific travel distances. The solution involves checking if the target planet can be reached using a combination of the given spacecraft distances.

### Approach
1. **Greatest Common Divisor (GCD) Check**: Compute the GCD of all spacecraft distances. If a target planet's distance is not divisible by this GCD, it is impossible to reach that planet.
2. **Transform Problem**: If the target distance is divisible by the GCD, transform the problem by dividing all spacecraft distances and the target distance by the GCD.
3. **Modulo Analysis**: Use the smallest transformed spacecraft distance (m') to check reachability. For each possible remainder when divided by m', compute the minimum sum required to achieve that remainder using a modified Dijkstra's algorithm.
4. **Query Handling**: For each query, check if the transformed target distance is greater than or equal to the precomputed minimum sum for its remainder class.

### Solution Code
```python
import sys
import math
import heapq

def main():
    input = sys.stdin.read().split()
    ptr = 0
    N, Q = int(input[ptr]), int(input[ptr+1])
    ptr += 2
    di = list(map(int, input[ptr:ptr+N]))
    ptr += N
    queries = list(map(int, input[ptr:ptr+Q]))
    
    # Compute GCD of all di
    current_gcd = di[0]
    for d in di[1:]:
        current_gcd = math.gcd(current_gcd, d)
    g = current_gcd
    
    di_primed = [d // g for d in di]
    m_prime = min(di_primed)
    
    if m_prime == 1:
        # All x' are reachable if x is divisible by g
        results = []
        for x in queries:
            if x % g != 0:
                results.append("NO")
            else:
                results.append("YES")
        print('\n'.join(results))
        return
    
    # Compute minimal sums for each residue mod m_prime using Dijkstra
    size = m_prime
    INF = float('inf')
    dist = [INF] * size
    dist[0] = 0
    heap = []
    heapq.heappush(heap, (0, 0))
    
    while heap:
        current_sum, residue = heapq.heappop(heap)
        if current_sum > dist[residue]:
            continue
        for d in di_primed:
            new_residue = (residue + d) % size
            new_sum = current_sum + d
            if new_sum < dist[new_residue]:
                dist[new_residue] = new_sum
                heapq.heappush(heap, (new_sum, new_residue))
    
    # Process queries
    results = []
    for x in queries:
        if x % g != 0:
            results.append("NO")
        else:
            x_prime = x // g
            r = x_prime % m_prime
            if dist[r] == INF:
                results.append("NO")
            else:
                if x_prime >= dist[r]:
                    results.append("YES")
                else:
                    results.append("NO")
    print('\n'.join(results))

if __name__ == "__main__":
    main()
```

### Explanation
1. **GCD Check**: The GCD of all spacecraft distances is computed. If the target distance is not divisible by this GCD, it is impossible to reach.
2. **Problem Transformation**: By dividing all distances by the GCD, the problem is simplified to checking reachability in a transformed space where the GCD is 1.
3. **Modulo Analysis**: Using the smallest transformed distance, we compute the minimum sum required to reach each possible remainder modulo this distance. This is efficiently done using Dijkstra's algorithm to find the shortest path in a graph where nodes represent remainders.
4. **Efficient Query Handling**: For each query, after checking divisibility, we use precomputed minimum sums to determine reachability based on the remainder of the transformed target distance.

This approach ensures that we efficiently handle up to 100,000 queries with large values by leveraging mathematical properties and graph-based shortest path algorithms.
