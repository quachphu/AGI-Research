To solve this problem, we need to determine the minimum number of elements to remove from an array such that the remaining elements form a "beautiful" array. A beautiful array is defined as one where each element occurs exactly C times for some integer C.

### Approach
1. **Frequency Count**: First, we count the frequency of each element in the array.
2. **Unique Frequencies**: Collect all unique frequency values from the frequency count.
3. **Optimal C Calculation**: For each unique frequency, consider it as a potential candidate for C. Calculate the maximum possible sum of elements that can form a beautiful array by ensuring each element occurs exactly C times.
4. **Binary Search**: Use binary search to efficiently determine how many elements can be included in the beautiful array for each candidate C.
5. **Result Calculation**: The minimum number of elements to remove is the total number of elements minus the maximum sum of elements that form the beautiful array.

### Solution Code
