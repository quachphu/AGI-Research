### Approach
1. **Graph Representation**: Model the market as a directed graph where each node is an item and each directed edge represents a trade. The edge weight corresponds to the profit or loss (C) from trading one item for another.
2. **Bellman-Ford Algorithm**: Use the Bellman-Ford algorithm to detect if there is a positive cycle reachable from the starting node (item 1). The Bellman-Ford algorithm is typically used to detect negative cycles, but by inverting our problem to check for positive cycles, we can adapt it here.
3. **Cycle Detection**: After relaxing all edges for N-1 iterations (where N is the number of items), check if we can still relax any edge in the Nth iteration. If we can, it indicates the presence of a positive cycle that is reachable from the starting node.
