To solve this problem, we need to transform a given garland of lamps into a k-periodic garland with the minimum number of state changes. A k-periodic garland has each pair of adjacent turned-on lamps exactly k units apart. 

### Approach
1. **Understanding k-periodic Structure**: For a garland to be k-periodic, all turned-on lamps must be positioned at intervals of k. This means the positions of turned-on lamps must form a sequence like x, x+k, x+2k, etc., for some starting position x.

2. **Residue Classes**: Each position in the garland can be classified by its residue modulo k. For each residue class, we need to determine the optimal way to turn lamps on or off to achieve the k-periodic structure.

3. **Kadane's Algorithm**: For each residue class, we transform the problem into finding the maximum subarray sum where each '1' is treated as 1 and each '0' as -1. This helps in determining the minimum number of changes required by considering the best consecutive sequence of lamps to turn on.

4. **Efficiency**: By iterating over each residue class and applying Kadane's algorithm, we efficiently compute the minimal changes required. The solution involves checking all possible starting positions within each residue class and selecting the optimal one.
