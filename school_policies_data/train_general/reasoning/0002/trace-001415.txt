To solve this problem, we need to determine the minimum possible total cost for a frog to jump from the first stone to the last stone, given that the frog can jump up to K stones ahead. The cost incurred for each jump is the absolute difference in heights between the current stone and the stone landed on.

### Approach
The problem can be efficiently solved using dynamic programming (DP). The key idea is to maintain a DP array where `dp[i]` represents the minimum cost to reach the ith stone. For each stone `i`, we consider all possible jumps from the previous K stones and compute the minimum cost by considering the cost incurred from each possible previous stone.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    n = int(input[0])
    k = int(input[1])
    h = list(map(int, input[2:2+n]))
    
    INF = float('inf')
    dp = [INF] * n
    dp[0] = 0  # Starting at the first stone (0-based)
    
    for i in range(1, n):
        start = max(0, i - k)
        # Calculate the minimum cost from the previous up to K stones
        min_cost = min(dp[j] + abs(h[i] - h[j]) for j in range(start, i))
        dp[i] = min_cost
    
    print(dp[-1])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Dynamic Programming Array Initialization**: We initialize a DP array `dp` where `dp[0]` is set to 0 because the frog starts at the first stone with no cost. All other entries are initialized to infinity (`INF`) to represent initially unreachable stones.

2. **Iterate Over Stones**: For each stone `i` (starting from the second stone), we determine the minimum cost to reach that stone by checking the previous up to K stones. This is done by iterating from the maximum of 0 (to avoid negative indices) and `i - K` (to consider only valid previous stones within the jump range).

3. **Compute Minimum Cost**: For each valid previous stone `j`, we compute the cost to jump from `j` to `i` as `dp[j] + abs(h[i] - h[j])`. The minimum of these values is stored in `dp[i]`.

4. **Result**: The value at `dp[-1]` (the last stone) gives the minimum cost to reach the last stone, which is printed as the result.

This approach efficiently computes the minimum cost using dynamic programming with a time complexity of O(N*K), which is feasible given the problem constraints (N up to 100,000 and K up to 100). The use of a generator expression within the `min` function helps optimize the inner loop in Python.
