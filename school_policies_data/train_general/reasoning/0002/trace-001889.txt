To solve this problem, we need to maximize Ivan's score in a matrix game while minimizing the number of replacements of 1s to 0s. The score is calculated based on the topmost 1 in each column and the number of 1s in a subsequent window of size up to `k`. 

### Approach
1. **Matrix Analysis**: For each column, determine the positions of all 1s.
2. **Evaluate Options**: For each column, evaluate the possible contributions to the score by considering each 1 as the topmost element. Also, consider the option of turning all 1s in the column to 0s.
3. **Optimal Selection**: For each column, select the option that maximizes the score contribution and, in case of ties, minimizes the number of replacements needed.
4. **Sum Results**: Aggregate the results across all columns to get the total maximum score and minimum replacements.

### Solution Code
```python
n, m, k = map(int, input().split())
matrix = [list(map(int, input().split())) for _ in range(n)]

total_score = 0
total_replacements = 0

for j in range(m):  # Iterate over each column (0-based)
    ones = [i for i in range(n) if matrix[i][j] == 1]
    if not ones:
        continue  # Contribution is 0, cost 0, no action needed
    
    # Consider the option of converting all 1s to 0s (contribution 0, cost len(ones))
    options = [(0, len(ones))]
    for i in ones:
        # Calculate cost: number of 1s above i in this column
        cost = sum(1 for x in ones if x < i)
        # Determine window size
        t = min(k, n - i)
        window_end = i + t - 1
        # Contribution is the number of 1s in the window
        contribution = sum(1 for x in ones if i <= x <= window_end)
        options.append((contribution, cost))
    
    # Find the maximum contribution with minimal cost
    max_contribution = max(c for c, _ in options)
    best_options = [(c, cost) for c, cost in options if c == max_contribution]
    best_contribution, best_cost = min(best_options, key=lambda x: x[1])
    
    total_score += best_contribution
    total_replacements += best_cost

print(total_score, total_replacements)
```

### Explanation
1. **Matrix Analysis**: For each column, we collect the indices of all rows where the value is 1. This helps in quickly evaluating possible topmost positions.
2. **Evaluate Options**: For each potential topmost 1 (row index), calculate the score contribution from the subsequent window of up to `k` elements. The cost here is the number of 1s above the current row that need to be turned to 0 to make the current row the topmost.
3. **Optimal Selection**: Among all possible options for each column, select the one that gives the highest score. If there are multiple options with the same score, choose the one with the lowest replacement cost.
4. **Sum Results**: The total score and replacements are accumulated across all columns to give the final result.

This approach ensures that we efficiently evaluate each column's contribution and choose the optimal strategy to maximize the score while minimizing replacements.
