To solve this problem, we need to minimize the total number of uncompleted tasks Chef has after using the Time Machine's buttons optimally. The approach involves using a greedy strategy to maximize the reduction of uncompleted tasks by selecting the most effective buttons first.

### Approach
1. **Calculate the Initial Uncompleted Tasks**: For each day, compute the initial uncompleted tasks as the difference between planned tasks (A) and completed tasks (B).
2. **Sort Days by Uncompleted Tasks**: Sort the days in descending order based on the initial uncompleted tasks. This allows us to prioritize days with the highest uncompleted tasks first.
3. **Sort Buttons by Value**: Sort both white and black buttons in descending order of their values. This helps in selecting the most effective buttons first.
4. **Merge Buttons**: Merge the sorted white and black buttons into a single list while maintaining the descending order. This allows us to process the highest value buttons first, regardless of their type.
5. **Greedy Selection**: Using a two-pointer technique, assign the highest value buttons to the days with the highest uncompleted tasks that can accommodate the button's value. Track the usage of white and black buttons to ensure we do not exceed their respective counts.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N, K, M = map(int, input[ptr:ptr+3])
        ptr += 3
        A = list(map(int, input[ptr:ptr+N]))
        ptr += N
        B = list(map(int, input[ptr:ptr+N]))
        ptr += N
        C = list(map(int, input[ptr:ptr+K]))
        ptr += K
        D = list(map(int, input[ptr:ptr+M]))
        ptr += M
        
        s_list = [A[i] - B[i] for i in range(N)]
        s_list.sort(reverse=True)
        
        # Sort buttons
        C.sort(reverse=True)
        D.sort(reverse=True)
        
        # Merge C and D into merged_buttons in descending order
        merged_buttons = []
        i = 0
        j = 0
        while i < K and j < M:
            if C[i] >= D[j]:
                merged_buttons.append((C[i], 'white'))
                i += 1
            else:
                merged_buttons.append((D[j], 'black'))
                j += 1
        while i < K:
            merged_buttons.append((C[i], 'white'))
            i += 1
        while j < M:
            merged_buttons.append((D[j], 'black'))
            j += 1
        
        # Process merged buttons
        day_ptr = 0
        white_used = 0
        black_used = 0
        total_gain = 0
        
        for x, typ in merged_buttons:
            if day_ptr >= N:
                break
            if typ == 'white':
                if white_used < K and s_list[day_ptr] >= x:
                    total_gain += x
                    white_used += 1
                    day_ptr += 1
            else:  # 'black'
                if black_used < M and s_list[day_ptr] >= x:
                    total_gain += x
                    black_used += 1
                    day_ptr += 1
        
        total_uncompleted = sum(s_list) - total_gain
        print(total_uncompleted)

if __name__ == "__main__":
    main()
```
