The solution involves a systematic approach to determine the optimal value by considering each bit position from the highest to the lowest, ensuring that the selected subsequences contribute to the maximum possible AND value.

1. **Generate Subarray Sums**: Compute all possible sums of contiguous subsequences (subarrays) of the given array. This is done efficiently using prefix sums.
2. **Sort the Sums**: Sorting helps in efficiently filtering sums that meet the criteria for each bit position.
3. **Bitwise Mask Construction**: Iterate from the highest bit (60th bit) down to the lowest (0th bit). For each bit position, check if it can be included in the result by forming a tentative mask and counting how many sums meet the criteria of having all bits in the mask set.
4. **Filtering Valid Sums**: For each bit position, if the count of valid sums is at least K, update the result mask and filter the sums to retain only those that meet the new mask criteria.
