### Approach
1. **Problem Analysis**:
   - A good tree must connect all nodes such that no two nodes from the same group are adjacent.
   - The problem can be reduced to counting the number of spanning trees in a complete n-partite graph where each partition has k nodes.

2. **Key Insights**:
   - When n = 1 and k > 1, no edges can exist between nodes (as they are all in the same group), so the result is 0.
   - For k = 1, the graph is a complete graph, and the number of spanning trees is given by Cayley's formula, \( n^{n-2} \).
   - For other cases, the number of spanning trees in a complete n-partite graph with each partition of size k is derived using a formula involving modular exponentiation.

3. **Formula**:
   - The number of spanning trees is computed using the formula:
     \[
     T = (k^{(n \cdot k - 2)}) \cdot (n^{(n - 2)}) \cdot ((n - 1)^{(n \cdot (k - 1))}) \mod (10^9 + 7)
     \]

### Solution Code
```python
MOD = 10**9 + 7

n, k = map(int, input().split())

if n == 1:
    print(1 % MOD if k == 1 else 0)
else:
    part1 = pow(k, n * k - 2, MOD)
    part2 = pow(n, n - 2, MOD)
    exponent3 = n * (k - 1)
    part3 = pow(n - 1, exponent3, MOD)
    res = (part1 * part2) % MOD
    res = (res * part3) % MOD
    print(res)
```

- **Input Handling**: The code reads two integers, n and k, from the input.
- **Special Case for n = 1**: If there is only one group (n = 1), the result is 1 if k = 1 (single node tree), otherwise 0 (no possible edges).

- **Combining Results**: The results of the three parts are combined and taken modulo \( 10^9 + 7 \) to ensure the result fits within standard integer limits and meets the problem constraints.
