To solve this problem, we need to count how many numbers from 1 to n (inclusive) are composed only of the digits 0 and 1 in their decimal representation. These numbers must start with 1 and can be followed by any combination of 0s and 1s.

### Approach
1. **Problem Analysis**: The valid numbers are those that start with 1 followed by any combination of 0s and 1s. Examples include 1, 10, 11, 100, etc. The challenge is to generate these numbers efficiently and count them without exceeding the given number n.
2. **Intuition**: We can generate these numbers using a breadth-first search (BFS) approach. Starting from 1, each subsequent number can be formed by appending 0 or 1 to the current number. This ensures that all valid numbers are generated in increasing order.
3. **Algorithm**: 
   - Use a queue to generate numbers starting from 1.
   - For each number, check if it is less than or equal to n. If it is, increment the count.
   - Append 0 and 1 to the current number to generate the next valid numbers and add them to the queue.
4. **Complexity**: The algorithm efficiently generates valid numbers using BFS, ensuring that each number is processed once. The time complexity is O(k), where k is the number of valid numbers up to n, which is very efficient given the constraints.

### Solution Code
```python
import sys
from collections import deque

def main():
    n = int(sys.stdin.readline())
    queue = deque([1])
    count = 0
    while queue:
        current = queue.popleft()
        if current > n:
            continue
        count += 1
        next_zero = current * 10
        next_one = current * 10 + 1
        if next_zero <= n:
            queue.append(next_zero)
        if next_one <= n:
            queue.append(next_one)
    print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input number n is read from standard input.
2. **Queue Initialization**: The queue starts with the number 1, the smallest valid number.
3. **BFS Processing**: The loop processes each number in the queue. For each number, if it is within the limit (<= n), it is counted. The next valid numbers are generated by appending 0 and 1, and added to the queue if they are within the limit.
4. **Output**: The total count of valid numbers is printed.

This approach efficiently generates and counts all valid numbers using BFS, ensuring correctness and optimal performance even for large values of n up to 10^9.
