To solve this problem, we need to determine if a given string is "beautiful" based on the condition that every lowercase letter in the English alphabet appears an even number of times. 

### Approach
1. **Input Reading**: Read the input string from standard input.
2. **Character Frequency Check**: For each lowercase letter from 'a' to 'z', count how many times it appears in the string.
3. **Even Check**: Verify if the count of each character is even. If any character has an odd count, the string is not beautiful.
4. **Result Output**: Print "Yes" if all characters have even counts, otherwise print "No".

### Solution Code
```python
def main():
    w = input().strip()
    for c in 'abcdefghijklmnopqrstuvwxyz':
        if w.count(c) % 2 != 0:
            print("No")
            return
    print("Yes")

main()
```

### Explanation
1. **Reading Input**: The function reads the input string using `input().strip()` to remove any leading or trailing whitespace.
2. **Checking Each Character**: The loop iterates over each character from 'a' to 'z'. For each character, it checks the count in the input string using `w.count(c)`.
3. **Even Count Verification**: For each character, if the count modulo 2 is not zero (indicating an odd count), the function immediately prints "No" and exits.
4. **Output Result**: If all characters pass the even count check, the function prints "Yes".

This approach ensures that we efficiently check each character's count in the string, adhering to the problem constraints and providing the correct result in linear time relative to the length of the string.
