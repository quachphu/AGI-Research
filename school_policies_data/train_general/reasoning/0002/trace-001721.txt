To solve this problem, we need to find the maximum amount of gasoline that Nut can have at the end of a path in a tree where each node represents a city with a certain amount of gasoline available, and each edge represents a road with a certain length. The goal is to maximize the remaining gasoline after traversing a path, considering both the gasoline bought in the cities and the gasoline consumed while traveling the roads.

### Approach
1. **Tree Representation**: Represent the tree using an adjacency list where each node keeps track of its neighbors and the corresponding edge lengths.
2. **Post-order Traversal**: Use an iterative post-order traversal to process each node after all its children have been processed. This allows us to compute the maximum path sum starting from each node and extending into its subtree.
3. **Dynamic Programming on Tree**: For each node, maintain two values:
   - `best_single`: The maximum gasoline that can be obtained starting from the node and moving downwards in the tree.
   - `best_combined`: The maximum gasoline that can be obtained by considering paths that might combine two subtrees through the current node.
4. **Global Maximum Update**: Track the global maximum gasoline value by considering the best combined values of all nodes.

### Solution Code
```python
import sys
from sys import stdin

def main():
    sys.setrecursionlimit(1 << 25)
    n = int(stdin.readline())
    w = list(map(int, stdin.readline().split()))
    adj = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v, c = map(int, stdin.readline().split())
        adj[u].append((v, c))
        adj[v].append((u, c))
    
    best_single = [0] * (n + 1)
    best_combined = [0] * (n + 1)
    global_max = 0

    stack = [(1, None, False)]
    
    while stack:
        node, parent, visited = stack.pop()
        if not visited:
            stack.append((node, parent, True))
            for neighbor, c in adj[node]:
                if neighbor != parent:
                    stack.append((neighbor, node, False))
        else:
            current_w = w[node - 1]
            max1 = max2 = -float('inf')
            for neighbor, c in adj[node]:
                if neighbor == parent:
                    continue
                child_val = best_single[neighbor] - c
                if child_val > max1:
                    max2 = max1
                    max1 = child_val
                elif child_val > max2:
                    max2 = child_val
            
            best_single_val = current_w
            if max1 != -float('inf'):
                best_single_val = max(best_single_val, current_w + max1)
            best_single[node] = best_single_val
            
            best_combined_val = best_single_val
            if max1 != -float('inf') and max2 != -float('inf'):
                combined = max1 + max2 + current_w
                if combined > best_combined_val:
                    best_combined_val = combined
            best_combined[node] = best_combined_val
            
            if best_combined_val > global_max:
                global_max = best_combined_val
    
    print(global_max)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Tree Representation**: The tree is built using an adjacency list where each node points to its neighbors along with the edge lengths.
2. **Post-order Traversal**: Using an iterative approach with a stack, we ensure that each node is processed after all its children. This allows us to compute the maximum path sums starting from each node.
3. **Dynamic Programming**: For each node, we calculate `best_single` by considering the maximum gasoline from the node itself or extending into its subtree. The `best_combined` value is computed by considering paths that go through two subtrees via the current node.
4. **Global Maximum**: By updating the global maximum during the traversal, we ensure that the optimal path is found efficiently.

This approach efficiently computes the solution in O(n) time, making it suitable for large trees up to the given constraint of 300,000 nodes.
