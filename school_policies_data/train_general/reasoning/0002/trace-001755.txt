To solve this problem, we need to determine the earliest possible time to reach the final station (Station N) from each starting station (1 to N) in a railroad system where trains operate on specific schedules. The trains from each station depart at fixed intervals starting from a given initial time. 

### Approach
1. **Understanding the Train Schedule**: Each station (i) has trains departing to the next station (i+1) starting from time S_i, with subsequent trains departing every F_i seconds. Each trip takes C_i seconds.
2. **Simulating the Journey**: For each starting station, simulate the journey to the final station by calculating the earliest departure time from each subsequent station and the corresponding arrival time at the next station.
3. **Calculate Departure Time**: For each station, determine the earliest possible departure time based on the current arrival time. This involves checking if the current time is before the first train departure time or finding the next available departure time using ceiling division to handle intervals.

### Solution Code
```python
n = int(input())
stations = []
for _ in range(n - 1):
    c, s, f = map(int, input().split())
    stations.append((c, s, f))

for i in range(1, n + 1):
    if i == n:
        print(0)
        continue
    current_time = 0
    for j in range(i - 1, n - 1):
        c, s, f = stations[j]
        if current_time <= s:
            depart = s
        else:
            delta = current_time - s
            k = (delta + f - 1) // f
            depart = s + k * f
        current_time = depart + c
    print(current_time)
```

### Explanation
1. **Input Reading**: Read the number of stations and the details for each segment between consecutive stations (C_i, S_i, F_i).
2. **Iterate Over Starting Stations**: For each starting station from 1 to N, calculate the earliest arrival time at the final station.
3. **Journey Simulation**: For each segment starting from the current station to the next, compute the earliest possible departure time. If the current time is before the first train's departure time, wait until the first train departs. Otherwise, compute the next available departure time using ceiling division to ensure we catch the next train.
4. **Update Current Time**: After determining the departure time, update the current time to the arrival time at the next station by adding the travel time (C_i).

This approach efficiently calculates the earliest arrival time by iterating through each station segment and adjusting the current time based on the train schedules, ensuring optimal performance even for the upper constraint limits.
