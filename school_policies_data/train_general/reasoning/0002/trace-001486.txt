The friend starts first and can kill 1 or 2 bosses per session, but requires a skip point for each hard boss (type 1) they kill. 

### Approach
1. **Dynamic Programming (DP) Setup**: We use a DP array where `dp[i][p]` represents the minimum number of skip points required to reach the `i`-th boss with the next turn being either your friend's (p=0) or yours (p=1).
2. **Transitions**: For each position `i` and each possible turn `p`, we consider the next moves:
   - **Friend's Turn (p=0)**: The friend can kill 1 or 2 bosses, adding the corresponding skip points for each hard boss.
   - **Your Turn (p=1)**: You can kill 1 or 2 bosses without any skip points.
3. **Initialization**: Start with `dp[0][0] = 0` as the friend starts at the first boss with 0 skip points used.
4. **Result Extraction**: After processing all possible transitions, the result for each test case is the minimum value between `dp[n][0]` and `dp[n][1]`, where `n` is the total number of bosses.
