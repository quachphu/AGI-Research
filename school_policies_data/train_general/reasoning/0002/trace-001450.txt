To solve this problem, we need to determine the maximum square of empty spots in a parking lot after each car parks. The challenge is to efficiently update the maximum square size as each car parks, considering the constraints of the problem.

### Approach
1. **Dynamic Programming (DP) Table Initialization**: We start by creating a DP table where each cell `dp[i][j]` represents the size of the largest square with its bottom-right corner at cell `(i, j)`. This table is initialized based on the initial state of the parking lot.
2. **Update DP Table on Each Insertion**: When a car parks at a specific spot `(x, y)`, we update the DP table starting from `(x, y)` to the bottom-right corner of the grid. This ensures that any changes due to the new car are propagated correctly.
3. **Track Maximum Square**: After each update, we compute the new maximum square size by iterating through the DP table.

import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    m = int(input[ptr])
    ptr += 1
    k = int(input[ptr])
    ptr += 1

    grid = []
    for _ in range(n):
        row = input[ptr]
        ptr += 1
        grid.append(list(row))
    
    dp = [[0]*m for _ in range(n)]
    for i in range(n):
        for j in range(m):
            if grid[i][j] == 'X':
                dp[i][j] = 0
            else:
                if i == 0 or j == 0:
                    dp[i][j] = 1
                else:
                    dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
    
    current_max = max(max(row) for row in dp)
    
    for _ in range(k):
        x = int(input[ptr]) - 1
        ptr += 1
        y = int(input[ptr]) - 1
        ptr += 1
        if grid[x][y] != '.':
            print(current_max)
            continue
        grid[x][y] = 'X'
        dp[x][y] = 0
        for i in range(x, n):
            for j in range(y, m):

                if grid[i][j] == 'X':
                    dp[i][j] = 0
