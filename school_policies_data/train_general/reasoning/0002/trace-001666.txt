To solve this problem, we need to determine the number of valid triples (r, g, b) such that the sum of balls from red, green, and blue boxes equals exactly N. Each box type (red, green, blue) contains a fixed number of balls (R, G, B respectively). The solution involves iterating through possible values of r and g, and checking if the remaining balls can be exactly divided by B to form a valid count of blue boxes.

### Approach
1. **Iterate through possible values of red boxes (r):** For each possible value of r, calculate the remaining number of balls needed after accounting for the red boxes.
2. **Iterate through possible values of green boxes (g):** For each possible value of g given the remaining balls from the red boxes, calculate the remaining number of balls needed.
3. **Check validity of blue boxes (b):** If the remaining balls after accounting for red and green boxes can be exactly divided by B, then the triplet (r, g, b) is valid.

### Solution Code
```python
R, G, B, N = map(int, input().split())

count = 0

max_r = N // R
for r in range(max_r + 1):
    remaining_after_r = N - R * r
    if remaining_after_r < 0:
        break
    max_g = remaining_after_r // G
    for g in range(max_g + 1):
        remaining_after_g = remaining_after_r - G * g
        if remaining_after_g % B == 0:
            count += 1

print(count)
```

### Explanation
1. **Red Box Iteration (r):** We iterate through all possible values of r from 0 up to the maximum possible value (N // R). For each r, we calculate the remaining number of balls after using r red boxes.
2. **Green Box Iteration (g):** For each r, we iterate through possible values of g up to the maximum possible value given the remaining balls after accounting for red boxes. The maximum value of g is determined by (remaining_after_r // G).
3. **Blue Box Check:** For each combination of r and g, we check if the remaining balls (after accounting for red and green boxes) can be exactly divided by B. If true, this combination is valid, and we increment the count.

This approach efficiently narrows down the valid combinations by iterating through possible values of r and g, and checking divisibility for b, ensuring we only count valid triples. The complexity is manageable within the given constraints, making the solution both efficient and effective.
