import sys
import bisect
import heapq

def main():
    n, m = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        a, b, c = map(int, sys.stdin.readline().split())
        adj[a].append( (b, c) )
        adj[b].append( (a, c) )
    
    # Read traveler times for each planet
    S = []
    for _ in range(n):
        parts = list(map(int, sys.stdin.readline().split()))
        k = parts[0]
        times = parts[1:] if k >0 else []
        S.append(times)
    
    # Dijkstra's algorithm
    INF = float('inf')
    dist = [INF] * (n+1)
    dist[1] = 0
    heap = []
    heapq.heappush(heap, (0, 1))
    
    while heap:
        current_time, u = heapq.heappop(heap)
        if u == n:
            print(current_time)
            return
        if current_time > dist[u]:
            continue
        # Compute departure_time
        times_u = S[u-1]
        # Compute departure_time from u
        departure = current_time
        idx = bisect.bisect_left(times_u, departure)
        for t in times_u[idx:]:
            if t <= departure:
                departure = t + 1
            else:
                break
        # For each neighbor
        for v, c in adj[u]:
            arrival = departure + c
            if arrival < dist[v]:
                dist[v] = arrival
                heapq.heappush(heap, (arrival, v))
    
    print(-1 if dist[n] == INF else dist[n])

if __name__ == "__main__":
    main()

To solve this problem, we need to determine the minimum time Jack O'Neill needs to reach planet n from planet 1, considering that he must wait for 1 second each time another traveler arrives at the same planet he is currently on. The solution involves using Dijkstra's algorithm with a priority queue to find the shortest path, while also accounting for the waiting times caused by other travelers.

### Approach
1. **Graph Representation**: Represent the galaxy as a graph using an adjacency list where each node (planet) has edges (stargates) to other nodes with associated travel times.
2. **Traveler Arrival Times**: For each planet, maintain a sorted list of times when travelers arrive. This list is used to calculate the waiting time for Jack.
3. **Dijkstra's Algorithm**: Use Dijkstra's algorithm to find the shortest path from planet 1 to planet n. The priority queue (min-heap) will store the earliest arrival time at each planet.
4. **Departure Time Calculation**: For each planet, compute the earliest departure time considering the waiting times due to other travelers. This is done by iterating through the sorted list of traveler arrival times and adjusting the departure time whenever a traveler arrives during Jack's stay.

### Solution Code
```python
import sys
import bisect
import heapq

def main():
    n, m = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        a, b, c = map(int, sys.stdin.readline().split())
        adj[a].append((b, c))
        adj[b].append((a, c))
    
    # Read traveler times for each planet (1-based index)
    S = []
    for _ in range(n):
        parts = list(map(int, sys.stdin.readline().split()))
        k = parts[0]
        times = parts[1:] if k > 0 else []
        S.append(times)
    
    # Dijkstra's algorithm
    INF = float('inf')
    dist = [INF] * (n + 1)
    dist[1] = 0
    heap = []
    heapq.heappush(heap, (0, 1))
    
    while heap:
        current_time, u = heapq.heappop(heap)
        if u == n:
            print(current_time)
            return
        if current_time > dist[u]:
            continue
        
        # Compute departure time from u
        times_u = S[u-1]  # S is 0-based for planets 1..n
        departure = current_time
        idx = bisect.bisect_left(times_u, departure)
        # Iterate through the times >= departure and check if they are <= current departure
        for t in times_u[idx:]:
            if t <= departure:
                departure = t + 1
            else:
                break
        
        # Explore neighbors
        for v, c in adj[u]:
            arrival = departure + c
            if arrival < dist[v]:
                dist[v] = arrival
                heapq.heappush(heap, (arrival, v))
    
    print(-1 if dist[n] == INF else dist[n])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Graph Representation**: The adjacency list `adj` is built from the input edges, allowing bidirectional travel between planets with given travel times.
2. **Traveler Arrival Times**: Each planet's traveler arrival times are stored in a list `S`, which is sorted as per the input.
3. **Dijkstra's Algorithm**: The algorithm starts from planet 1 with an initial time of 0. The priority queue manages the nodes to explore, ordered by the earliest arrival time.
4. **Departure Time Calculation**: For each planet, after arriving at time `current_time`, the departure time is adjusted by checking each subsequent traveler arrival time. If a traveler arrives at or before the current departure time, the departure time is incremented by 1 for each such traveler until no more consecutive travelers are found.
5. **Edge Exploration**: For each neighbor planet, the arrival time is calculated as the departure time plus the travel time. If this arrival time is earlier than the known shortest time to that planet, it is updated and pushed into the priority queue.

This approach efficiently finds the shortest path while accounting for waiting times due to other travelers, ensuring the solution is optimal and runs in a reasonable time complexity.
