To solve this problem, we need to determine the number of valid ski bases after each new road is added. A valid ski base is a non-empty set of roads that can be partitioned into one or more cycles. The solution involves tracking the number of independent cycles formed as each road is added and using this information to compute the result efficiently.

### Approach
1. **Cycle Detection Using Union-Find**: We use the Disjoint Set Union (DSU) data structure to efficiently track connected components of junctions. Each time a new road is added, we check if it connects two already connected junctions. If it does, it forms a new cycle.
2. **Cycle Count Tracking**: Maintain a counter `c` that increments each time a new cycle is formed. This counter represents the number of independent cycles in the graph.
3. **Precompute Powers of 2**: Since the result for each step is `2^c - 1` modulo `1000000009`, we precompute the powers of 2 up to the maximum possible number of roads to optimize performance.
4. **Modular Arithmetic**: Use modular arithmetic to handle large numbers and prevent overflow, as required by the problem constraints.

### Solution Code
```python
MOD = 10**9 + 9

n, m = map(int, input().split())

# Precompute powers of 2 modulo MOD up to m+1
pow2 = [1] * (m + 1)
for i in range(1, m + 1):
    pow2[i] = (pow2[i-1] * 2) % MOD

parent = list(range(n))
rank = [1] * n

def find(u):
    while parent[u] != u:
        parent[u] = parent[parent[u]]  # Path compression
        u = parent[u]
    return u

c = 0
for _ in range(m):
    a, b = map(int, input().split())
    a -= 1  # Convert to 0-based index
    b -= 1
    root_a = find(a)
    root_b = find(b)
    if root_a == root_b:
        c += 1
    else:
        # Union by rank
        if rank[root_a] > rank[root_b]:
            parent[root_b] = root_a
        else:
            parent[root_a] = root_b
            if rank[root_a] == rank[root_b]:
                rank[root_b] += 1
    ans = (pow2[c] - 1) % MOD
    print(ans)
```

### Explanation
1. **Union-Find Data Structure**: This helps efficiently manage and query connected components. The `find` function uses path compression to flatten the structure, ensuring almost constant time complexity for each query. The union operation uses union by rank to maintain balanced trees.
2. **Cycle Detection**: Each time a new road is added, we check if it connects two nodes that are already in the same component. If they are, it means adding this road forms a new cycle, so we increment the cycle counter `c`.
3. **Precomputed Powers of 2**: This allows us to quickly compute the result for each step using the formula `2^c - 1`, which gives the number of non-empty subsets of cycles formed by the roads added so far.
4. **Efficiency**: The approach efficiently handles up to 100,000 roads and junctions using near-linear time complexity due to the optimized Union-Find operations and precomputation of powers of 2.

This solution ensures that we efficiently track the formation of cycles and compute the required results in an optimal manner, adhering to the problem constraints.
