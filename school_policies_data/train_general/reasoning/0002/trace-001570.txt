To solve this problem, we need to transform each given string according to specific rules where each alphabet character is replaced by the next character in the alphabet, ignoring all non-alphabet characters. If the character is 'z' or 'Z', it should wrap around to 'a' or 'A', respectively.

### Approach
1. **Input Reading**: Read the number of strings and then each string individually.
2. **Character Processing**: For each character in the string:
   - Check if it is an alphabet character.
   - If it is, determine the next character in the alphabet. For 'z' or 'Z', wrap around to 'a' or 'A'.
3. **Result Construction**: Collect all transformed characters and form the resulting string.
4. **Output**: Print each transformed string.

### Solution Code
```python
def process_strings():
    n = int(input())
    for _ in range(n):
        s = input().strip('\n')
        result = []
        for c in s:
            if c.isalpha():
                if c.islower():
                    new_char = chr((ord(c) - ord('a') + 1) % 26 + ord('a'))
                else:
                    new_char = chr((ord(c) - ord('A') + 1) % 26 + ord('A'))
                result.append(new_char)
        print(''.join(result))

process_strings()
```

### Explanation
- **Reading Input**: The function starts by reading the number of strings, then processes each string line by line.
- **Character Check**: For each character in the string, it checks if it is an alphabet using `isalpha()`.
- **Transformation**: If the character is lowercase, it shifts it to the next character using modular arithmetic to handle wrap-around. The same logic applies to uppercase characters.
- **Result Construction**: Transformed characters are collected into a list, which is then joined into a string and printed.

This approach ensures that each string is processed efficiently, adhering to the constraints and requirements specified. The solution handles edge cases such as empty strings and wrap-around characters correctly.
