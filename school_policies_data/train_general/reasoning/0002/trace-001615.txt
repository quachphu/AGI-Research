To solve this problem, we need to determine the number of good observatories in AtCoder Hill. An observatory is considered good if its elevation is higher than all observatories directly connected to it by one road. 

### Approach
1. **Input Reading**: Read the number of observatories (N) and roads (M), followed by the elevations of each observatory and the list of roads.
2. **Track Maximum Neighbor Elevation**: For each observatory, maintain the maximum elevation of its directly connected neighbors. This is done by iterating through each road and updating the maximum elevation for both connected observatories.
3. **Check Good Observatories**: After processing all roads, compare each observatory's elevation with the maximum elevation of its neighbors. If an observatory's elevation is higher than all its neighbors, it is counted as good.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    M = int(input[ptr])
    ptr += 1
    H = list(map(int, input[ptr:ptr+N]))
    ptr += N
    max_neighbor = [0] * N
    for _ in range(M):
        A = int(input[ptr]) - 1
        ptr += 1
        B = int(input[ptr]) - 1
        ptr += 1
        if H[B] > max_neighbor[A]:
            max_neighbor[A] = H[B]
        if H[A] > max_neighbor[B]:
            max_neighbor[B] = H[A]
    count = 0
    for i in range(N):
        if H[i] > max_neighbor[i]:
            count += 1
    print(count)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints. The elevations of observatories and roads are parsed from the input string.
2. **Tracking Maximum Elevation**: For each road, update the maximum elevation of neighbors for both connected observatories. This ensures that each observatory knows the highest elevation it can reach directly via one road.
3. **Determining Good Observatories**: After processing all roads, each observatory's elevation is compared against the highest elevation of its neighbors. If it is higher, the observatory is marked as good.

This approach efficiently processes each road once and checks each observatory once, resulting in a time complexity of O(N + M), which is suitable given the problem constraints.
