The weights of the pieces are given, except for the king, which is ignored. The solution involves reading the board configuration, calculating the total weights for each player, and then comparing these totals to determine the result.

### Approach
1. **Read Input**: The input consists of 8 lines, each containing 8 characters representing the chessboard.
2. **Initialize Weights**: Use a dictionary to map each piece type to its corresponding weight. Kings (both 'K' and 'k') are ignored.
3. **Calculate Totals**: For each character on the board, check if it is a valid piece (excluding kings and empty squares). Add the corresponding weight to the respective player's total based on whether the piece is uppercase (White) or lowercase (Black).
4. **Compare Totals**: After processing all characters, compare the total weights of White and Black. Print "White" if White's total is higher, "Black" if Black's total is higher, and "Draw" if they are equal.

### Solution Code
```python
def solve():
    white = 0
    black = 0
    weights = {
        'Q': 9, 'R': 5, 'B': 3, 'N': 3, 'P': 1,
        'q': 9, 'r': 5, 'b': 3, 'n': 3, 'p': 1
    }
    for _ in range(8):
        line = input().strip()
        for c in line:
            if c in weights:
                if c.isupper():
                    white += weights[c]
                else:
                    black += weights[c]
    if white > black:
        print("White")
    elif black > white:
        print("Black")
    else:
        print("Draw")

solve()
```

### Explanation
1. **Reading Input**: The code reads 8 lines of input, each representing a row on the chessboard.
2. **Weight Mapping**: The dictionary `weights` maps each piece character to its respective weight. Uppercase letters represent White pieces, and lowercase letters represent Black pieces.
3. **Summing Weights**: For each character in each row, the code checks if it is a valid piece (using the dictionary). If it is, the corresponding weight is added to the respective player's total based on the case of the character.
4. **Result Determination**: After processing all characters, the totals for White and Black are compared, and the result is printed based on which total is higher or if they are equal.

This approach efficiently processes the input in linear time relative to the size of the board (O(64) operations), making it optimal for the given problem constraints.
