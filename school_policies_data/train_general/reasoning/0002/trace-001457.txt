### Approach
1. **Segment Trees for Efficient Range Queries**: 
   - Use two segment trees to handle range-based portal plans efficiently. One segment tree (out_tree) handles portals from a specific planet to a range of planets (type 2 plans). The other (in_tree) handles portals from a range of planets to a specific planet (type 3 plans).
   - Each segment tree node represents a range of planets. This allows us to add edges to or from ranges in O(log n) time.

2. **Graph Construction**:
   - Construct the segment trees and precompute edges for moving through the tree nodes with zero cost.
   - For each type of plan, add the appropriate edges to the graph. Type 1 plans are direct edges, while type 2 and 3 plans use the segment trees to add edges efficiently.

3. **Dijkstra's Algorithm**:
   - Use Dijkstra's algorithm to find the shortest path from Earth (s) to all other planets, considering both direct edges and those introduced by the segment trees.

import heapq

def main():
    input = sys.stdin.read().split()

    ptr +=1

    current_id = n + 1

            return node_id
        mid = (l + r) // 2
        left_child = build_in(l, mid)
        right_child = build_in(mid+1, r)
        node_info_in[node_id] = (l, r, left_child, right_child)
        return node_id

    for node_id in node_info_out:

    for node_id in node_info_in:
        l, r, left, right = node_info_in[node_id]
        if left is not None and right is not None:
            edges[left].append( (node_id, 0) )
            edges[right].append( (node_id, 0) )

            edges[l].append( (node_id, 0) )
