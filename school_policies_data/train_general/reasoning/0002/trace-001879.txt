To solve this problem, we need to simulate the process of boys and girls swapping positions in a queue over a given number of seconds. Each second, any boy (B) standing immediately in front of a girl (G) will swap places with her. The challenge is to determine the final arrangement of the queue after the specified number of seconds.

### Approach
1. **Understand the Swapping Mechanism**: Each second, every adjacent pair of a boy followed by a girl (BG) will swap to become GB. This process must be based on the initial state of the queue at the start of each second, meaning all swaps in a given second occur simultaneously based on the initial configuration for that second.
2. **Simulation Over Time Steps**: For each second, create a copy of the current queue configuration. Use this copy to determine which pairs need to be swapped, then apply all swaps simultaneously to generate the new configuration for the next second.
3. **Efficient Swapping**: By iterating through the queue and checking each pair from left to right, we can determine which pairs need to be swapped based on the initial state of the queue at the start of the second. This ensures that swaps do not interfere with each other within the same second.

### Solution Code
```python
def process_queue():
    n, t = map(int, input().split())
    s = input().strip()
    arr = list(s)
    for _ in range(t):
        original = list(arr)
        new_arr = list(original)
        for i in range(len(original) - 1):
            if original[i] == 'B' and original[i+1] == 'G':
                new_arr[i], new_arr[i+1] = new_arr[i+1], new_arr[i]
        arr = new_arr
    print(''.join(arr))

process_queue()
```

### Explanation
1. **Reading Input**: The input consists of two integers (n and t) followed by a string representing the initial queue. The integers are read first, followed by the string.
2. **Initial Setup**: Convert the string into a list of characters for easier manipulation.
3. **Time Steps Simulation**: For each second (from 0 to t-1), create a copy of the current queue configuration. Iterate through each position in the queue to check if the current position has a boy (B) and the next position has a girl (G). If so, mark these positions for a swap.
4. **Simultaneous Swapping**: After identifying all necessary swaps based on the initial configuration of the current second, apply all swaps to generate the new configuration for the next second.
5. **Output the Result**: After processing all seconds, convert the final list back to a string and print it.

This approach ensures that each second's swaps are based on the initial configuration of that second, allowing all swaps to occur simultaneously and correctly updating the queue's state for the next second. This method efficiently handles the constraints and provides the correct result within the given time limits.
