To solve this problem, we need to determine if we can reach the cell (n, m) from (1, 1) in a grid, spending exactly k burles. The movement rules are such that moving right from (x, y) costs x burles, and moving down costs y burles. 

### Approach
The key insight is that regardless of the path taken, the total cost to move from (1, 1) to (n, m) is fixed. This is because the cost depends on the row and column positions at the time of each move, and the sum of these costs can be computed using a formula derived from the grid dimensions.

The formula to compute the exact cost is derived as follows:
1. To move from (1, 1) to (n, m), we need (n-1) down moves and (m-1) right moves.
2. The cost of each right move in row x is x, and the cost of each down move in column y is y.
3. The total cost can be computed as \((n-1) \times m + (m-1)\). This simplifies to \(m \times n - 1\).

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, m, k = map(int, input().split())
    required = (n - 1) * m + (m - 1)
    print("YES" if k == required else "NO")
```

1. **Input Reading**: The number of test cases `t` is read first.
2. **Loop Through Test Cases**: For each test case, read the values of n, m, and k.
3. **Calculate Required Burles**: Using the formula \((n-1) \times m + (m-1)\), compute the exact number of burles needed to reach (n, m).
4. **Check Condition**: Compare the computed value with k. If they match, print "YES"; otherwise, print "NO".

This approach efficiently determines the result in constant time for each test case, ensuring optimal performance even for the upper limits of the input constraints.
