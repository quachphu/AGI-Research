To solve this problem, we need to identify two additional cells in an n×n grid such that they form a rectangle with two given marked cells. The solution must ensure that the sides of the rectangle are parallel to the coordinate axes.

### Approach
1. **Identify Positions**: First, locate the positions of the two existing asterisks ('*') in the grid.
2. **Determine Case**: Check if the two asterisks are in the same row, same column, or neither.
   - **Same Row**: If they are in the same row, choose another row and mark the same columns in that row.
   - **Same Column**: If they are in the same column, choose another column and mark the same rows in that column.
   - **Different Rows and Columns**: If they are in different rows and columns, mark the positions that form the opposite corners of the rectangle defined by the two given points.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    grid = [list(input().strip()) for _ in range(n)]
    stars = []
    for i in range(n):
        for j in range(n):
            if grid[i][j] == '*':
                stars.append((i, j))
    (x1, y1), (x2, y2) = stars
    if x1 == x2:
        x3 = (x1 + 1) % n
        grid[x3][y1] = '*'
        grid[x3][y2] = '*'
    elif y1 == y2:
        y3 = (y1 + 1) % n
        grid[x1][y3] = '*'
        grid[x2][y3] = '*'
    else:
        grid[x1][y2] = '*'
        grid[x2][y1] = '*'
    for row in grid:
        print(''.join(row))
```

### Explanation
1. **Reading Input**: The input is read, including the number of test cases and each grid.
2. **Finding Asterisks**: The positions of the two existing asterisks are identified and stored.
3. **Case Handling**:
   - **Same Row**: If both asterisks are in the same row, a new row is chosen (using modulo operation to ensure it's within bounds), and the same columns in this new row are marked.
   - **Same Column**: If both asterisks are in the same column, a new column is chosen similarly, and the same rows in this new column are marked.
   - **Different Rows and Columns**: If the asterisks form diagonal corners of a rectangle, the other two corners are marked to complete the rectangle.

This approach ensures that the solution is efficient and handles all possible configurations of the input grid correctly. The use of modulo operation ensures that the chosen row or column is always within the grid bounds.
