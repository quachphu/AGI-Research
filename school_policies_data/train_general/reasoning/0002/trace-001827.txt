To solve this problem, we need to determine if a given number \( n \) can be represented as the sum of a certain number of 2020s and 2021s. The solution involves checking if there exist non-negative integers \( a \) and \( b \) such that \( 2020a + 2021b = n \).

### Approach
1. **Mathematical Insight**: The equation \( 2020a + 2021b = n \) can be rewritten using the fact that \( 2021 = 2020 + 1 \). This transforms the equation into \( 2020(a + b) + b = n \), where \( k = a + b \) represents the total number of terms (2020s and 2021s). Thus, the equation becomes \( 2020k + b = n \), where \( b \) is the count of 2021s and must be between 0 and \( k \).

2. **Range of k**: For \( n \) to be expressible, there must exist an integer \( k \) such that:
   - \( 2020k \leq n \leq 2021k \)
   - This translates to checking if there exists an integer \( k \) in the interval \([ \lceil \frac{n}{2021} \rceil, \lfloor \frac{n}{2020} \rfloor ]\).

3. **Efficient Calculation**: Compute the minimum \( k \) (k_min) as \( \lceil \frac{n}{2021} \rceil \) and the maximum \( k \) (k_max) as \( \lfloor \frac{n}{2020} \rfloor \). If \( k_min \leq k_max \), then \( n \) can be expressed as required.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    k_min = (n + 2020) // 2021
    k_max = n // 2020
    print("YES" if k_min <= k_max else "NO")
```

- **Input Handling**: Read the number of test cases.
- **Loop Through Test Cases**: For each test case, read \( n \).
- **Compute k_min and k_max**:
  - **k_min** is calculated using integer division to find the ceiling of \( \frac{n}{2021} \).
  - **k_max** is calculated using integer division to find the floor of \( \frac{n}{2020} \).
- **Check Validity**: If \( k_min \) is less than or equal to \( k_max \), print "YES"; otherwise, print "NO".
