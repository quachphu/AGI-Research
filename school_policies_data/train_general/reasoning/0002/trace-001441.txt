To solve this problem, we need to determine the expected number of lights turned on in William's device before it stops working. The device stops when any k consecutive lights contain more than one turned-on light. The solution involves calculating the expected value using combinatorial mathematics and modular arithmetic to handle large numbers efficiently.

### Approach
1. **Combinatorial Analysis**: The key insight is to compute the probability that the device stops after exactly m steps. This involves ensuring that the first m-1 steps do not create any k-consecutive lit lights, while the m-th step does.
2. **Precomputation**: We precompute factorials and their modular inverses up to the maximum possible value (100,000) to efficiently compute combinations modulo \(10^9 + 7\).
3. **Dynamic Probability Calculation**: For each possible number of steps m, we compute the probability that the first m-1 steps do not violate the k-consecutive lights condition. This is done using combinatorial terms and modular arithmetic.

### Solution Code
```python
MOD = 10**9 + 7
max_fact = 10**5

# Precompute factorial and inverse factorial modulo MOD
fact = [1] * (max_fact + 2)
for i in range(1, max_fact + 1):
    fact[i] = fact[i-1] * i % MOD

inv_fact = [1] * (max_fact + 2)
inv_fact[max_fact] = pow(fact[max_fact], MOD-2, MOD)
for i in range(max_fact - 1, -1, -1):
    inv_fact[i] = inv_fact[i+1] * (i+1) % MOD

def main():
    import sys
    input = sys.stdin.read().split()
    t = int(input[0])
    idx = 1
    for _ in range(t):
        n = int(input[idx])
        k = int(input[idx+1])
        idx += 2
        sum_ans = 0
        for m in range(1, n+1):
            if m == 1:
                sum_ans = (sum_ans + 1) % MOD
                continue
            a = n - (m - 2) * (k - 1)
            if a < m - 1:
                break
            # Calculate combination C(a, m-1)
            if a < 0 or (m-1) < 0 or a < (m-1):
                comb = 0
            else:
                if a > max_fact:
                    comb = 0
                else:
                    comb = fact[a] * inv_fact[m-1] % MOD
                    comb = comb * inv_fact[a - (m-1)] % MOD
            term = comb * fact[m-1] % MOD
            term = term * fact[n - m + 1] % MOD
            term = term * inv_fact[n] % MOD
            sum_ans = (sum_ans + term) % MOD
        print(sum_ans)

if __name__ == "__main__":
    main()
```

2. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
3. **Loop Through Test Cases**: For each test case, we initialize the expected value sum and iterate through possible values of m (number of steps).
