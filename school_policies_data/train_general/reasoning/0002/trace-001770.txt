To solve this problem, we need to determine the maximum number of little pigs that can be eaten by wolves on a two-dimensional grid. Each wolf can eat at most one adjacent pig, and each pig can be eaten by at most one wolf. The problem can be modeled as a bipartite graph matching problem where we find the maximum matching between wolves and pigs.

### Approach
1. **Model the Problem as a Bipartite Graph**: 
   - Wolves and pigs are nodes in two separate sets.
   - Edges exist between a wolf and a pig if they are adjacent on the grid.

2. **Collect Positions**:
   - Identify the positions of all wolves and pigs on the grid.

3. **Build Adjacency List**:
   - For each wolf, determine which pigs are adjacent and create an adjacency list.

4. **Maximum Bipartite Matching**:
   - Use Depth-First Search (DFS) to find the maximum matching in the bipartite graph. This involves finding the maximum number of edges such that no two edges share a common wolf or pig.

def main():
    import sys
    sys.setrecursionlimit(1000000)
    n, m = map(int, sys.stdin.readline().split())
    grid = [sys.stdin.readline().strip() for _ in range(n)]
    
    wolves = []
    pigs = []
    for i in range(n):
        for j in range(m):
            c = grid[i][j]
            if c == 'W':
                wolves.append((i, j))
            elif c == 'P':
                pigs.append((i, j))
    
    # Build pig position to index mapping
    pig_pos_to_idx = {(x, y): idx for idx, (x, y) in enumerate(pigs)}
    
    # Build adjacency list for wolves
    wolf_adj = [[] for _ in range(len(wolves))]
    for w_idx, (i, j) in enumerate(wolves):
        for dx, dy in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
            x = i + dx
            y = j + dy
            if 0 <= x < n and 0 <= y < m:
                if grid[x][y] == 'P':
                    pos = (x, y)
                    if pos in pig_pos_to_idx:
                        p_idx = pig_pos_to_idx[pos]
                        wolf_adj[w_idx].append(p_idx)
    
    # Compute maximum bipartite matching
    pig_matches = [-1] * len(pigs)
    result = 0
    
    def dfs(wolf):
        for p in wolf_adj[wolf]:
            if not visited[p]:
                visited[p] = True
                if pig_matches[p] == -1 or dfs(pig_matches[p]):
                    pig_matches[p] = wolf
                    return True
        return False
    
    for wolf in range(len(wolf_adj)):
        visited = [False] * len(pigs)
        if dfs(wolf):
            result += 1
    
    print(result)

if __name__ == "__main__":
