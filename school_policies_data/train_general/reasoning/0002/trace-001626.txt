To solve this problem, we need to determine if a given triad of musical keys on a circular keyboard is a Major or Minor triad. The solution involves converting the input keys into their respective positions on the keyboard, generating permutations of these positions, and checking each permutation against the criteria for Major and Minor triads.

### Approach
1. **Mapping Keys to Positions**: Each key on the circular keyboard is mapped to a specific position. Sharps are represented by lowercase letters, which are converted to their corresponding positions.
2. **Reading Input**: The number of test cases and each triad of keys are read from the input.
3. **Generating Permutations**: For each triad, all permutations of the three keys are generated to check all possible orderings.
4. **Checking Triad Type**: For each permutation, the steps between consecutive keys are calculated. A Major triad has steps of 4 followed by 3, while a Minor triad has steps of 3 followed by 4. The result is determined based on the first valid permutation found.

### Solution Code
```python
import sys
from itertools import permutations

key_map = {
    'C': 0,
    'c': 1,
    'D': 2,
    'd': 3,
    'E': 4,
    'F': 5,
    'f': 6,
    'G': 7,
    'g': 8,
    'A': 9,
    'B': 10,
    'S': 11
}

def classify_triad():
    T = int(sys.stdin.readline())
    for _ in range(T):
        triad = sys.stdin.readline().strip().split()
        positions = [key_map[c] for c in triad]
        for perm in permutations(positions):
            x, y, z = perm
            step1 = (y - x) % 12
            step2 = (z - y) % 12
            if step1 == 4 and step2 == 3:
                print("Major")
                break
            elif step1 == 3 and step2 == 4:
                print("Minor")
                break
        else:
            pass  # According to the problem statement, this case won't occur

classify_triad()
```

### Explanation
1. **Mapping Keys**: The `key_map` dictionary converts each input character to its corresponding position on the circular keyboard.
