To solve this problem, we need to determine if a given square matrix is symmetric about its vertical axis, horizontal axis, both, or neither. The solution involves checking each row and column for the required symmetries and then combining the results to determine the correct output.

### Approach
1. **Reading Input:** Read the number of test cases. For each test case, read the size of the matrix and then the matrix itself.
2. **Vertical Symmetry Check:** Check if each row of the matrix is a palindrome. If all rows are palindromes, the matrix is symmetric about the vertical axis.
3. **Horizontal Symmetry Check:** Check if each row from the top half of the matrix matches the corresponding row from the bottom half. If all corresponding rows match, the matrix is symmetric about the horizontal axis.
4. **Determine Result:** Based on the results of the vertical and horizontal checks, output the appropriate result for each test case.

### Solution Code
```python
import sys

def check_symmetry():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        matrix = [sys.stdin.readline().strip() for _ in range(n)]
        
        vertical = True
        for row in matrix:
            if row != row[::-1]:
                vertical = False
                break
        
        horizontal = True
        for i in range(n // 2):
            if matrix[i] != matrix[n - 1 - i]:
                horizontal = False
                break
        
        if vertical and horizontal:
            print("BOTH")
        elif vertical:
            print("VERTICAL")
        elif horizontal:
            print("HORIZONTAL")
        else:
            print("NO")

check_symmetry()
```

### Explanation
1. **Reading Input:** The input is read using `sys.stdin.readline()` for efficiency, especially given the constraints. Each matrix is stored as a list of strings.
2. **Vertical Symmetry Check:** For each row, check if it reads the same forwards and backwards (i.e., it is a palindrome). If any row fails this check, vertical symmetry is not present.
3. **Horizontal Symmetry Check:** For each row in the top half of the matrix, check if it matches the corresponding row in the bottom half. If any pair of rows fails this check, horizontal symmetry is not present.
4. **Result Determination:** Combine the results of the vertical and horizontal checks. If both are true, the matrix is symmetric about both axes. If only one is true, output the corresponding axis. If neither is true, output "NO".

This approach efficiently checks the required symmetries in O(n^2) time complexity per test case, which is optimal given the problem constraints.
