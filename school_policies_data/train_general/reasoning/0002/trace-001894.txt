To solve this problem, we need to validate email addresses based on specific criteria for both the username and hostname parts. The validation process involves checking the structure and allowed characters for each part of the email address.

### Approach
1. **Username Validation**: The username must be 1-16 characters long and can include letters (both uppercase and lowercase), digits, and underscores.
2. **Hostname Validation**: The hostname is split into two parts by a dot. The first part (main part) must be 1-16 characters long, include at least one letter, and can contain letters, digits, and hyphens. The second part (extension) must be 1-10 characters long and consist only of lowercase letters.

### Solution Code
```python
import re

def is_valid_email(email):
    # Split into username and hostname parts
    parts = email.split('@')
    if len(parts) != 2:
        return False
    username, hostname = parts
    
    # Validate username
    if not re.fullmatch(r'^[A-Za-z0-9_]{1,16}$', username):
        return False
    
    # Split hostname into main and extension parts
    host_parts = hostname.split('.')
    if len(host_parts) != 2:
        return False
    main_part, ext = host_parts
    
    # Validate main part of hostname
    if not (1 <= len(main_part) <= 16):
        return False
    if not re.fullmatch(r'^[A-Za-z0-9-]*$', main_part):
        return False
    if not re.search(r'[A-Za-z]', main_part):
        return False
    
    # Validate extension part of hostname
    if not (1 <= len(ext) <= 10):
        return False
    if not re.fullmatch(r'^[a-z]*$', ext):
        return False
    
    return True

n = int(input())
for _ in range(n):
    email = input().strip()
    print("YES" if is_valid_email(email) else "NO")
```

### Explanation
1. **Splitting the Email Address**: The email address is split into the username and hostname using the '@' character. If there is not exactly one '@', the email is invalid.
2. **Username Check**: The username is validated using a regular expression to ensure it meets the length and character requirements.
3. **Hostname Check**: The hostname is split into the main part and the extension using the '.' character. The main part is checked for length, allowed characters, and the presence of at least one letter. The extension is checked for length and allowed characters (only lowercase letters).

This approach ensures that each part of the email address is thoroughly validated according to the given criteria, resulting in an efficient and accurate solution.
