To solve this problem, we need to determine the maximum number of petals Marina can collect in a bouquet such that the fortune-telling result ends with "Loves". This happens when the total number of petals is odd, as Marina starts with "Loves" and alternates with each petal.

### Approach
1. **Sum Calculation**: First, calculate the total number of petals from all the flowers.
2. **Check Parity**: If the total number of petals is odd, this is the maximum possible number of petals ending with "Loves".
3. **Adjust for Even Sum**: If the total number of petals is even, we need to adjust it to make it odd by subtracting the smallest odd number of petals from the total. If there are no odd numbers, it's impossible to form a valid bouquet, so the result is 0.

### Solution Code
```python
def solve():
    n = int(input())
    a = list(map(int, input().split()))
    total = sum(a)
    if total % 2 == 1:
        print(total)
    else:
        odds = [x for x in a if x % 2 == 1]
        if not odds:
            print(0)
        else:
            print(total - min(odds))

solve()
```

### Explanation
1. **Reading Input**: The code reads the number of flowers and their respective petal counts.
2. **Total Petals Calculation**: The total number of petals is computed.
3. **Odd Total Check**: If the total is odd, it is printed immediately as the result.
4. **Even Total Handling**: If the total is even, the code checks for the presence of odd petal counts. The smallest odd petal count is subtracted from the total to make it odd. If there are no odd petals, the result is 0.

This approach ensures that we efficiently determine the maximum valid bouquet size using basic arithmetic and list operations, ensuring optimal performance even for the upper input limits.
