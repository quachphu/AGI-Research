### Solution Code
```python
q = int(input())
for _ in range(q):
    s = input().strip()
    t = input().strip()
    if set(s) & set(t):
        print("YES")
    else:
        print("NO")
```

### Explanation
1. **Reading Input:** The number of queries `q` is read first. For each query, the strings `s` and `t` are read.
2. **Check for Common Characters:** For each pair of strings, we convert them into sets of characters and check if there is any intersection between these sets.
3. **Output Result:** If there is an intersection, it means we can transform both strings to a common character, so we print "YES". Otherwise, we print "NO".

This approach efficiently determines the possibility of transforming the strings by leveraging set operations to check for common characters, ensuring an optimal solution with a time complexity of O(n) per query, where n is the length of the strings.
