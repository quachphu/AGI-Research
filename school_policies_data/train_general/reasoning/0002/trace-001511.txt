To solve this problem, we need to find the K-th smallest lunlun number. A lunlun number is defined as a number where each pair of adjacent digits differs by at most 1. The solution involves generating these numbers in ascending order using a breadth-first search (BFS) approach to ensure efficiency and correctness.

### Approach
1. **Breadth-First Search (BFS)**: We use BFS to generate lunlun numbers in ascending order. BFS is suitable here because it explores all numbers level by level, ensuring that numbers are generated in the order of their magnitude.
2. **Queue Initialization**: Start with the initial numbers 1 through 9, as these are the smallest single-digit lunlun numbers.
3. **Generate Next Numbers**: For each number dequeued, generate the next possible numbers by appending a digit that differs by at most 1 from the last digit of the current number. This ensures that each new number maintains the lunlun property.
4. **Track Count**: Keep track of the count of numbers generated. When the count reaches K, the current number is the K-th smallest lunlun number.

### Solution Code
```python
import sys
from collections import deque

def main():
    K = int(sys.stdin.readline())
    queue = deque(range(1, 10))  # Initialize with 1-9
    count = 0
    while queue:
        num = queue.popleft()
        count += 1
        if count == K:
            print(num)
            return
        last_digit = num % 10
        for delta in (-1, 0, 1):
            next_digit = last_digit + delta
            if 0 <= next_digit <= 9:
                new_num = num * 10 + next_digit
                queue.append(new_num)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Queue Initialization**: The BFS starts with numbers 1 through 9 in the queue, as these are the smallest valid lunlun numbers.
2. **Processing Each Number**: For each number dequeued, we check if it is the K-th number. If not, we generate the next possible numbers by considering digits that are ±1 from the last digit of the current number.
3. **Generating New Numbers**: For each valid next digit (0-9), a new number is formed by appending this digit to the current number. These new numbers are added to the queue for subsequent processing.
4. **Termination**: The process continues until we dequeue the K-th number, which is then printed as the result.

This approach efficiently generates lunlun numbers in ascending order using BFS, ensuring that the K-th smallest number is found in O(K) time complexity, which is optimal for the given constraints.
