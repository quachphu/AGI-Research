### Approach
1. **Understanding Flips**: Each flip operation reverses a segment of cups from position L to R. If the ball is within this segment, its new position can be calculated using the formula `L + R - current_position`. This formula works because reversing a segment swaps the positions symmetrically around the midpoint of the segment.
2. **Track Ball Position**: For each test case, start with the initial position of the ball. For each flip operation, check if the ball's current position is within the segment being flipped. If it is, update the position using the formula mentioned above.
3. **Efficiency**: By directly computing the new position of the ball for each relevant flip, we avoid simulating the entire array, leading to an efficient solution with a time complexity of O(Q) per test case, where Q is the number of flip operations.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        C = int(input[ptr + 1])
        Q = int(input[ptr + 2])
        ptr += 3
        for __ in range(Q):
            L = int(input[ptr])
            R = int(input[ptr + 1])
            ptr += 2
            if L <= C <= R:
                C = L + R - C
        print(C)

if __name__ == "__main__":
    main()
```

3. **Applying Flips**: For each flip operation, check if the current position of the ball is within the segment [L, R]. If it is, update the ball's position using the formula `L + R - current_position`.
4. **Output Result**: After processing all flip operations for a test case, print the final position of the ball.

This approach ensures that we efficiently track the ball's position through each flip operation without simulating the entire array, making the solution both optimal and easy to understand.
