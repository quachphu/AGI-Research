To solve this problem, we need to generate a crystal pattern based on an odd integer \( n \). The crystal is represented as an \( n \times n \) matrix where the diamond-shaped cells are filled with the character "D" and the remaining cells with the character "*".

### Approach
1. **Understanding the Pattern**: The diamond shape in the matrix starts from the middle row and expands outward. The number of "D" characters in each row increases symmetrically from the top and bottom towards the middle row.
2. **Middle Row Calculation**: The middle row of the matrix is at index \((n-1) // 2\). This row will have \( n \) "D" characters.
3. **Diamond Shape Calculation**: For each row, the number of "D" characters is determined by the distance from the middle row. The formula used is \( 2 \times (mid - distance) + 1 \), where \( distance \) is the absolute difference between the current row index and the middle row index.
4. **Constructing Each Row**: Each row is constructed by calculating the number of "D" characters and the number of "*" characters on each side to center the "D" characters.

### Solution Code
```python
n = int(input())
mid = (n - 1) // 2
for i in range(n):
    distance = abs(i - mid)
    num_D = 2 * (mid - distance) + 1
    stars = (n - num_D) // 2
    print('*' * stars + 'D' * num_D + '*' * stars)
```

### Explanation
1. **Reading Input**: The input integer \( n \) is read from standard input.
2. **Middle Row Calculation**: The middle row index is calculated as \((n-1) // 2\).
3. **Row Construction**:
   - For each row index \( i \), compute the distance from the middle row.
   - Calculate the number of "D" characters using the formula \( 2 \times (mid - distance) + 1 \).
   - Determine the number of "*" characters on each side to center the "D" characters.
   - Construct the row string by concatenating the appropriate number of "*", "D", and "*" characters.
4. **Output**: Each constructed row is printed to form the crystal pattern.

This approach efficiently constructs each row based on its distance from the middle row, ensuring the diamond shape is centered and symmetric. The solution runs in \( O(n) \) time complexity, making it efficient for the given constraints.
