To solve this problem, we need to find the k-th smallest integer such that all its prime divisors are in a given set of primes. The solution involves generating numbers in increasing order using a min-heap to efficiently track the smallest possible next numbers, while avoiding duplicates using a set.

### Approach
1. **Heap Initialization**: Start with a min-heap initialized with the number 1, as it is the smallest number with no prime factors (trivially satisfies the condition).
2. **Visited Set**: Use a set to keep track of numbers that have already been added to the heap to avoid duplicates.
3. **Extract and Multiply**: Repeatedly extract the smallest number from the heap. For each extracted number, multiply it by each prime in the given set. If the product has not been generated before, add it to both the heap and the visited set.
4. **Iterate k Times**: Perform the extraction and multiplication process k times to reach the k-th smallest number.

### Solution Code
```python
import heapq

def find_kth_number():
    n = int(input())
    primes = list(map(int, input().split()))
    k = int(input())
    
    heap = []
    heapq.heappush(heap, 1)
    visited = {1}
    
    current = 1
    for _ in range(k):
        current = heapq.heappop(heap)
        for p in primes:
            num = current * p
            if num not in visited:
                visited.add(num)
                heapq.heappush(heap, num)
    print(current)

find_kth_number()
```

### Explanation
1. **Heap Initialization**: The heap starts with the number 1, which is the first number in the sequence.
2. **Visited Set**: This set ensures that each number is only processed once, preventing duplicates in the heap.
3. **Extraction and Multiplication**: Each time the smallest number is extracted from the heap, it is multiplied by each prime number in the given set. The products are added to the heap if they haven't been generated before.
4. **k-th Iteration**: By repeating the extraction process k times, the k-th extracted number is the desired result, as each extraction represents the next smallest number in the sequence.

This approach efficiently generates numbers in increasing order using a min-heap and ensures that each number is processed exactly once, making it both time and space efficient for the given problem constraints.
