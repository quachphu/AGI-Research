To solve this problem, we need to determine the number of "lonely" numbers in the range from 1 to n for each test case. A number is considered lonely if it has no friends in the group. Two numbers are friends if their greatest common divisor (gcd) and the quotients obtained by dividing each number by their gcd can form the sides of a valid triangle.

### Approach
1. **Prime Sieve Method**: Use the Sieve of Eratosthenes to precompute prime numbers up to the maximum value encountered in the input.
2. **Prefix Sum Array**: Create a prefix sum array to quickly count the number of primes up to any given number.
3. **Lonely Numbers Calculation**: For each test case, determine the number of primes p such that \( p^2 > n \). Add 1 to include the number 1, which is always lonely.

### Solution Code
```python
import math
import sys

def main():
    input = sys.stdin.read().split()
    if not input:
        return
    t = int(input[0])
    if t == 0:
        return
    ns = list(map(int, input[1:t+1]))
    if not ns:
        return
    max_n = max(ns)
    
    # Sieve of Eratosthenes to compute primes up to max_n
    sieve = [True] * (max_n + 1)
    sieve[0] = sieve[1] = False
    for i in range(2, int(math.isqrt(max_n)) + 1):
        if sieve[i]:
            sieve[i*i : max_n+1 : i] = [False] * len(sieve[i*i : max_n+1 : i])
    
    # Prefix sum array to count primes up to each number
    prefix = [0] * (max_n + 1)
    count = 0
    for i in range(max_n + 1):
        if sieve[i]:
            count += 1
        prefix[i] = count
    
    # Process each test case
    for n in ns:
        if n == 0:
            print(0)
            continue
        if n == 1:
            print(1)
            continue
        sqrt_n = int(math.isqrt(n))
        primes_above_sqrt = prefix[n] - prefix[sqrt_n]
        print(1 + primes_above_sqrt)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Prime Sieve**: The Sieve of Eratosthenes is used to efficiently find all prime numbers up to the maximum value in the input. This helps in quickly determining primes for multiple test cases.
2. **Prefix Sum Array**: This array allows us to quickly compute the number of primes up to any number, which is crucial for efficiently answering each query.
3. **Lonely Number Calculation**: For each number n, the number of lonely numbers is determined by counting primes greater than the square root of n (since their squares will be greater than n) and adding 1 to include the number 1.

This approach ensures that we efficiently handle up to \(10^6\) test cases and values of n up to \(10^6\) with optimal time complexity using precomputation and prefix sums.
