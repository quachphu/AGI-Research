To solve this problem, we need to correct a word by removing vowels that follow another vowel until no consecutive vowels remain. The correction process involves iteratively removing the first occurrence of a vowel that is immediately preceded by another vowel.

### Approach
1. **Identify Consecutive Vowels**: We need to scan the string to find the first occurrence of a vowel that is immediately preceded by another vowel.
2. **Remove the Vowel**: Once such a vowel is found, remove it from the string.
3. **Repeat**: Continue this process until no consecutive vowels are left in the string.

### Solution Code
```python
n = int(input())
s = input().strip()

vowels = {'a', 'e', 'i', 'o', 'u', 'y'}

while True:
    to_delete = -1
    for i in range(1, len(s)):
        if s[i] in vowels and s[i-1] in vowels:
            to_delete = i
            break
    if to_delete == -1:
        break
    s = s[:to_delete] + s[to_delete+1:]
print(s)
```

### Explanation
1. **Reading Input**: The code starts by reading the input values, which include the length of the string and the string itself.
2. **Vowel Set**: A set of vowels is defined to quickly check if a character is a vowel.
3. **Iterative Correction**: The main loop continues until no consecutive vowels are found. In each iteration, the string is scanned from left to right to find the first vowel that is preceded by another vowel. This vowel is then removed from the string.
4. **Termination**: The loop terminates when no more consecutive vowels are found, and the corrected string is printed.

This approach ensures that we efficiently correct the string by removing the problematic vowels step-by-step until the string meets the criteria of having no consecutive vowels. The solution handles all edge cases and processes the string in an optimal manner given the constraints.
