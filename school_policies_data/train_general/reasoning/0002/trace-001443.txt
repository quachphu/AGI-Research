To solve this problem, we need to determine the minimum number of operations required to make all elements in a sequence the same by repeatedly appending the k-th element and removing the first element. If it is impossible, we should return -1.

### Approach
1. **Identify the Target Value**: The k-th element in the initial sequence (1-based index) will be the value we aim to propagate throughout the sequence.
2. **Find the Longest Suffix**: Determine the earliest position in the sequence from which all subsequent elements are the same as the k-th element.
3. **Check Feasibility**: Verify if this position is within the first k elements. If it is, calculate the number of operations needed. If not, it is impossible to achieve uniformity.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))
x = a[k-1]
pos_0 = n  # Initialize to n (0-based, meaning initially no elements after pos_0 are x)
for i in reversed(range(n)):
    if a[i] != x:
        pos_0 = i + 1
        break
else:
    pos_0 = 0  # All elements are x

# Convert to 1-based position
pos_1 = pos_0 + 1

if pos_1 <= k:
    print(pos_1 - 1)
else:
    print(-1)
```

### Explanation
1. **Identify Target Value**: The target value `x` is the k-th element of the sequence (converted to 0-based index as `a[k-1]`).
2. **Find Longest Suffix**: By iterating from the end of the sequence backwards, we find the earliest position `pos_0` (0-based index) where all subsequent elements are `x`. If all elements are `x`, `pos_0` is set to 0.
3. **Check Feasibility**: Convert `pos_0` to a 1-based index (`pos_1`). If `pos_1` is within the first k elements (1-based), the minimum number of operations required is `pos_1 - 1`. Otherwise, output -1 as it is impossible to achieve uniformity.

This approach efficiently determines the solution by leveraging the properties of the sequence and the operations, ensuring optimal performance even for large input sizes.
