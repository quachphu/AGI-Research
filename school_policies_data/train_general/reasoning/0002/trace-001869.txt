The solution involves checking each possible subarray length and verifying if it meets the necessary conditions using efficient precomputed values and range queries.

### Approach
1. **Sum and Maximum Conditions**: For a subarray of length `m` to be a valid subpermutation, it must:
   - Have a sum equal to `m*(m+1)/2`.
   - The maximum element in the subarray must be `m`.
   - The sum of squares of the elements must equal `m*(m+1)*(2m+1)/6` to ensure all elements are distinct and form the sequence from 1 to `m`.

2. **Efficient Range Queries**: Use prefix sums and prefix sums of squares to quickly compute the sum and sum of squares for any subarray. Use a sparse table to efficiently compute the maximum element in any subarray.

3. **Iterate Over Possible Lengths**: For each possible subarray length `m`, check all subarrays of that length using the precomputed values to verify the conditions.

### Solution Code
```python
import sys
import math

def main():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    max_val = max(a)
    
    prefix_sum = [0] * (n + 1)
    prefix_sq_sum = [0] * (n + 1)
    for i in range(n):
        prefix_sum[i + 1] = prefix_sum[i] + a[i]
        prefix_sq_sum[i + 1] = prefix_sq_sum[i] + a[i] ** 2
    
    logn = math.floor(math.log2(n)) if n > 0 else 0
    st = [[0] * n for _ in range(logn + 1)]
    st[0] = a[:]
    for j in range(1, logn + 1):
        for i in range(n - (1 << j) + 1):
            st[j][i] = max(st[j-1][i], st[j-1][i + (1 << (j-1))])
    
    def get_max(l, r):
        length = r - l + 1
        k = length.bit_length() - 1
        return max(st[k][l], st[k][r - (1 << k) + 1])
    
    count = 0
    max_m = max_val
    for m in range(1, max_m + 1):
        s = m * (m + 1) // 2
        sq = m * (m + 1) * (2 * m + 1) // 6
        window_size = m
        if window_size > n:
            continue
        for start in range(n - window_size + 1):
            end = start + window_size
            current_sum = prefix_sum[end] - prefix_sum[start]
            if current_sum != s:
                continue
            current_sq = prefix_sq_sum[end] - prefix_sq_sum[start]
            if current_sq != sq:
                continue
            current_max = get_max(start, end - 1)
            if current_max == m:
                count += 1
    print(count)

if __name__ == "__main__":
    main()
```
