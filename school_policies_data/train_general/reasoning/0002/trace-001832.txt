To solve this problem, we need to efficiently handle two types of queries on a tree structure: painting a node red and finding the shortest distance from a given node to the nearest red node. The initial red node is node 1, and subsequent red nodes are added incrementally. The solution involves using a breadth-first search (BFS) to precompute initial distances and dynamically update distances as new red nodes are added.

### Approach
1. **Initial Distance Calculation**: Use BFS starting from node 1 to precompute the shortest distance from node 1 to all other nodes. This gives the initial minimum distances to the nearest red node (node 1).
2. **Dynamic Updates with BFS**: For each query that paints a node red, perform a BFS starting from that node to update the minimum distances for all nodes that can now be reached more quickly from the newly added red node. This ensures that each node's distance is updated to the shortest possible path from any red node encountered so far.

### Solution Code
```python
import sys
from collections import deque

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n, m = int(input[ptr]), int(input[ptr+1])
    ptr += 2

    adj = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        a = int(input[ptr])
        b = int(input[ptr+1])
        adj[a].append(b)
        adj[b].append(a)
        ptr += 2

    dist = [-1] * (n + 1)
    q = deque([1])
    dist[1] = 0
    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)

    for _ in range(m):
        ti, vi = int(input[ptr]), int(input[ptr+1])
        ptr += 2
        if ti == 1:
            if dist[vi] != 0:
                dist[vi] = 0
                q = deque([vi])
                while q:
                    u = q.popleft()
                    for v in adj[u]:
                        if dist[v] > dist[u] + 1:
                            dist[v] = dist[u] + 1
                            q.append(v)
        else:
            print(dist[vi])

if __name__ == "__main__":
    main()
```

2. **Handling Paint Queries**: When a node is painted red (type 1 query), a BFS is initiated from that node to update the `dist` array. This BFS ensures that any node reachable from the newly painted red node with a shorter path than previously known has its distance updated.
3. **Handling Distance Queries**: For each distance query (type 2 query), the precomputed and dynamically updated `dist` array is used to directly return the shortest distance to the nearest red node.

This approach efficiently handles dynamic updates using BFS, ensuring that each node's distance is updated only when a shorter path is found, thus optimizing the overall performance.
