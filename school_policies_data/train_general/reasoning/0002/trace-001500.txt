To solve this problem, we need to determine the maximum possible beauty for each vertex in a tree rooted at vertex 1. The beauty of a vertex is defined as the greatest common divisor (GCD) of all values along the path from the root to that vertex. Additionally, we can change the value of any one vertex to 0 to maximize the beauty for each vertex independently.

### Approach
1. **Tree Traversal**: Use Breadth-First Search (BFS) to traverse the tree starting from the root. This helps in efficiently processing each node level by level.
2. **GCD Tracking**: For each node, maintain two key pieces of information:
   - **Current GCD**: The GCD of the path from the root to the current node without any omissions.
   - **Omission Set**: A set of GCD values obtained by omitting exactly one node in the path from the root to the current node.
3. **Dynamic GCD Calculation**: For each node, compute the GCD values considering the omission of the node itself or any of its ancestors. This is done by combining the GCD values from the parent node's current GCD and omission set.

### Solution Code
```python
from math import gcd
from collections import deque

def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    
    index = 0
    n = int(data[index])
    index += 1
    a = list(map(int, data[index:index + n]))
    index += n
    
    adj = [[] for _ in range(n)]
    for _ in range(n - 1):
        u = int(data[index]) - 1
        v = int(data[index + 1]) - 1
        adj[u].append(v)
        adj[v].append(u)
        index += 2
    
    # Build parent structure using BFS
    visited = [False] * n
    parent = [-1] * n
    children = [[] for _ in range(n)]
    q = deque()
    q.append(0)
    visited[0] = True
    
    while q:
        u = q.popleft()
        for v in adj[u]:
            if not visited[v]:
                visited[v] = True
                parent[v] = u
                children[u].append(v)
                q.append(v)
    
    current_gcd = [0] * n
    omission_set = [set() for _ in range(n)]
    max_beauty = [0] * n
    
    # Initialize root node
    current_gcd[0] = a[0]
    omission_set[0].add(0)
    max_beauty[0] = max(current_gcd[0], max(omission_set[0]))
    
    q = deque()
    q.append(0)
    
    while q:
        u = q.popleft()
        for v in children[u]:
            parent_gcd = current_gcd[u]
            v_current_gcd = gcd(parent_gcd, a[v])
            current_gcd[v] = v_current_gcd
            
            new_omission = set()
            new_omission.add(parent_gcd)
            for g in omission_set[u]:
                new_gcd = gcd(g, a[v])
                new_omission.add(new_gcd)
            
            omission_set[v] = new_omission
            current_max = current_gcd[v]
            if new_omission:
                current_max = max(current_max, max(new_omission))
            max_beauty[v] = current_max
            q.append(v)
    
    print(' '.join(map(str, max_beauty)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Tree Construction**: The tree is constructed using adjacency lists from the input, and parent-child relationships are determined using BFS.
2. **Root Initialization**: The root node's GCD is initialized to its value, and its omission set starts with 0 (since changing the root to 0 is allowed).
3. **BFS Traversal**: For each node, compute the current GCD by combining the parent's GCD with the node's value. The omission set is built by considering both the parent's GCD (omitting the current node) and the GCDs obtained from the parent's omission set (omitting an ancestor node).
4. **Max Beauty Calculation**: The maximum beauty for each node is determined by taking the maximum value between the current GCD and the maximum value in the omission set.

This approach efficiently computes the maximum possible beauty for each node in O(n log a) time, where a is the maximum value in the input, ensuring it handles the constraints effectively.
