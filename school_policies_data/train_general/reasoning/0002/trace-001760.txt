To solve this problem, we need to minimize the cost of traveling through multiple cities using railroads, where each railroad can be used with either a paper ticket or an IC card. The IC card has an upfront cost but reduces the fare for each subsequent use. The goal is to determine the optimal strategy for purchasing IC cards to minimize the total travel cost.

### Approach
1. **Understand the Travel Path**: Each day's travel between cities involves traversing a contiguous range of railroads. For example, traveling from city 3 to city 5 involves railroads 3 and 4.
2. **Count Railroad Usage**: Track how many times each railroad is used throughout the entire trip. This is efficiently done using a difference array to handle range increments.
3. **Calculate Costs**: For each railroad, compute the total cost using either paper tickets or an IC card. The optimal choice for each railroad is determined by comparing the total costs of both options.

### Solution Code
```python
import sys

def main():
    n, m = map(int, sys.stdin.readline().split())
    p = list(map(int, sys.stdin.readline().split()))
    
    # Read railroad data (index 1 to n-1)
    railroad_data = [None] * (n)
    for i in range(n-1):
        a, b, c = map(int, sys.stdin.readline().split())
        railroad_data[i+1] = (a, b, c)
    
    # Initialize difference array
    diff = [0] * (n + 2)  # 1-based to n, with extra space
    
    for j in range(m-1):
        current = p[j]
        next_city = p[j+1]
        l = min(current, next_city)
        r = max(current, next_city) - 1
        if l <= r:
            diff[l] += 1
            if r + 1 <= n:
                diff[r + 1] -= 1
    
    # Compute prefix sums to get counts
    current_count = 0
    counts = [0] * (n)  # counts[1] to counts[n-1] are used
    for i in range(1, n):
        current_count += diff[i]
        counts[i] = current_count
    
    total_cost = 0
    for i in range(1, n):
        a, b, c = railroad_data[i]
        cnt = counts[i]
        cost_without = a * cnt
        cost_with = c + b * cnt
        total_cost += min(cost_without, cost_with)
    
    print(total_cost)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of the number of cities, the number of travel days, the itinerary, and the fare details for each railroad.
2. **Difference Array**: We use a difference array to efficiently count the number of times each railroad is traversed. For each travel day, we increment the start of the range and decrement the position just after the end of the range.
3. **Prefix Sum Calculation**: Convert the difference array into actual counts using a prefix sum, which gives the number of times each railroad is used.
4. **Cost Calculation**: For each railroad, compute the total cost using both paper tickets and IC cards, then choose the cheaper option. Sum these minimal costs to get the total travel cost.

This approach ensures that we efficiently handle up to 100,000 cities and travel days, providing an optimal solution in linear time.
