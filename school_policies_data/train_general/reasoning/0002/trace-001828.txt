To solve this problem, we need to count the number of valid camel polylines with exactly `t` humps and `t-1` dips, given `n` vertices. Each vertex has specific constraints on its y-coordinate values and their relationships.

### Approach
1. **Dynamic Programming (DP) State Tracking**: We use a dynamic programming approach where we track the state of sequences as they are built step-by-step. The state includes the last two y-values, the count of humps, and the count of dips encountered so far.
2. **Transition Between States**: For each new y-value added, we check if it forms a hump or dip with the previous two y-values. This determines how the counts of humps and dips are updated.
3. **Pruning Invalid States**: During state transitions, we prune states where the counts of humps or dips exceed the required values to optimize the solution.

### Solution Code
```python
from collections import defaultdict
import sys

def main():
    n, t = map(int, sys.stdin.readline().split())

    if n < 3:
        print(0)
        return

    current_dp = defaultdict(int)
    # Initialize for i=2 (sequences of length 2)
    for a in range(1, 5):
        for b in range(1, 5):
            if a != b:
                current_dp[(a, b, 0, 0)] += 1

    for i in range(3, n + 1):
        next_dp = defaultdict(int)
        for (a_pp, a_p, curr_h, curr_d), cnt in current_dp.items():
            for c in range(1, 5):
                if c == a_p:
                    continue  # Skip if same as previous y
                # Check for hump and dip conditions
                is_hump = (a_pp < a_p) and (a_p > c)
                is_dip = (a_pp > a_p) and (a_p < c)
                new_h = curr_h + (1 if is_hump else 0)
                new_d = curr_d + (1 if is_dip else 0)
                # Prune if counts exceed the required
                if new_h > t or new_d > (t - 1):
                    continue
                # Update the next state
                key = (a_p, c, new_h, new_d)
                next_dp[key] += cnt
        current_dp = next_dp

    # Sum all valid sequences where h == t and d == t-1
    result = 0
    for (a_p, c, h, d), cnt in current_dp.items():
        if h == t and d == (t - 1):
            result += cnt

    print(result)

if __name__ == "__main__":
    main()
```
