Each operation allows us to add the value of an element at index `i` to an element at index `j` where `i < j`. The key insight is that elements in `a` can only be -1, 0, or 1, and we need to check if the transformation is possible based on these values.

### Approach
1. **Initial Check**: The first element of `a` must match the first element of `b` because it cannot be modified by any operations.
2. **Track Presence of 1 and -1**: As we iterate through the elements of `a`, we track whether we have encountered a 1 or -1 in the previous elements. This helps us determine if we can increase or decrease subsequent elements as needed.
3. **Delta Calculation**: For each element from the second to the last, calculate the difference (`delta`) between the corresponding elements of `b` and `a`. 
   - If `delta` is positive, we need to have encountered a 1 in the previous elements to allow increasing the value.
   - If `delta` is negative, we need to have encountered a -1 in the previous elements to allow decreasing the value.

import sys

def solve():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    for _ in range(t):
        n = int(data[idx])
        idx +=1
        a = list(map(int, data[idx:idx+n]))

                    break
