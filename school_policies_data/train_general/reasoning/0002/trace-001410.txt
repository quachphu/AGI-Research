To solve this problem, we need to determine if there exists a continuous subarray of friends' gift costs that exactly sums up to a given amount, X. The solution must efficiently handle large input sizes up to the constraints provided.

### Approach
The optimal approach to solve this problem is using the sliding window technique. This technique is suitable because all the costs are positive integers, allowing us to efficiently track the sum of the current window and adjust its size dynamically. Here's a step-by-step outline of the approach:

1. **Initialize Variables**: Use two pointers, `left` and `right`, to represent the current window of elements. Track the sum of the current window using `current_sum`.

2. **Expand the Window**: Iterate through each element with the `right` pointer, adding each element to `current_sum`.

3. **Adjust the Window**: If `current_sum` exceeds X, increment the `left` pointer and subtract the corresponding element from `current_sum` until the sum is less than or equal to X.

4. **Check for Exact Match**: If at any point `current_sum` equals X, immediately return "YES".

5. **Final Check**: If the loop completes without finding a match, return "NO".

This approach ensures that each element is processed at most twice (once when added to the window and once when removed), resulting in an O(N) time complexity per test case, which is efficient for large inputs.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N, X = int(input[ptr]), int(input[ptr + 1])
        ptr += 2
        costs = list(map(int, input[ptr:ptr + N]))
        ptr += N
        left = 0
        current_sum = 0
        found = False
        for right in range(N):
            current_sum += costs[right]
            while current_sum > X and left <= right:
                current_sum -= costs[left]
                left += 1
            if current_sum == X:
                found = True
                break
        print("YES" if found else "NO")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the large potential size. The input is split into a list of strings for easy processing.

2. **Sliding Window Technique**: The main loop iterates over each element with the `right` pointer, expanding the window. If the sum of the current window exceeds X, the `left` pointer is incremented to shrink the window until the sum is within bounds.

3. **Check for Exact Match**: After adjusting the window size, if the sum equals X, the loop breaks early and returns "YES". If no valid window is found after processing all elements, "NO" is returned.

This approach efficiently handles the constraints and ensures that each test case is processed in linear time, making it suitable for large inputs.
