To solve this problem, we need to count the number of valid substrings in a given string, where a valid substring is defined as one that contains at least one 'a' or 'z'. The solution must efficiently handle strings up to 1,000,000 characters in length.

### Approach
1. **Total Substrings Calculation**: The total number of substrings in a string of length \( n \) is given by \( n \times (n + 1) / 2 \).
2. **Invalid Substrings**: Instead of directly counting valid substrings, we count the invalid substrings (those that contain neither 'a' nor 'z') and subtract this from the total substrings. This approach is more efficient.
3. **Identify Invalid Runs**: Traverse the string to identify contiguous sequences (runs) of characters that are neither 'a' nor 'z'. For each such run of length \( k \), the number of invalid substrings is \( k \times (k + 1) / 2 \).
4. **Compute Valid Substrings**: Subtract the count of invalid substrings from the total substrings to get the count of valid substrings.

### Solution Code
```python
def count_valid_substrings(s):
    n = len(s)
    total = n * (n + 1) // 2
    invalid = 0
    current_invalid = 0
    for c in s:
        if c not in {'a', 'z'}:
            current_invalid += 1
        else:
            invalid += current_invalid * (current_invalid + 1) // 2
            current_invalid = 0
    invalid += current_invalid * (current_invalid + 1) // 2
    return total - invalid

def main():
    import sys
    lines = sys.stdin.read().splitlines()
    T = int(lines[0])
    for i in range(1, T + 1):
        s = lines[i].strip()
        print(count_valid_substrings(s))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into lines for efficient processing.
2. **Total Substrings**: For each string, the total number of substrings is calculated using the formula \( n \times (n + 1) / 2 \).
3. **Invalid Runs**: As we traverse the string, we keep track of the length of contiguous invalid characters (those not 'a' or 'z'). When we encounter a valid character, we compute the number of invalid substrings for the current run and reset the counter.
4. **Final Calculation**: After processing the entire string, any remaining invalid run is accounted for. The valid substrings are obtained by subtracting the invalid substrings from the total substrings.

This approach ensures that we efficiently count valid substrings in linear time \( O(n) \) per test case, making it suitable for large input sizes.
