To solve this problem, we need to determine how many users will know the news if a specific user starts spreading it in a social network. The network is structured such that users are grouped into friend groups, and news spreads to all friends (users in the same group) and their friends recursively.

### Approach
1. **Union-Find Data Structure**: We use the Union-Find (Disjoint Set Union, DSU) data structure to efficiently manage and merge groups of users. This helps in determining the connected components of users.
2. **Union Operations**: For each group, we connect all users in the group by union operations. Specifically, we take the first user in each group and union all other users in the group with this first user. This ensures all users in the same group are connected.
3. **Component Size Calculation**: After processing all groups, each user's connected component size can be directly retrieved from the Union-Find structure. This size represents the number of users that will know the news if the respective user starts spreading it.

### Solution Code
```python
import sys

def main():
    sys.setrecursionlimit(1 << 25)
    n, m = map(int, sys.stdin.readline().split())
    
    parent = list(range(n + 1))  # 1-based indexing
    size = [1] * (n + 1)
    
    def find(u):
        while parent[u] != u:
            parent[u] = parent[parent[u]]  # Path compression
            u = parent[u]
        return u
    
    def union(u, v):
        u_root = find(u)
        v_root = find(v)
        if u_root == v_root:
            return
        # Union by size: attach smaller tree to larger tree
        if size[u_root] < size[v_root]:
            u_root, v_root = v_root, u_root
        parent[v_root] = u_root
        size[u_root] += size[v_root]
    
    for _ in range(m):
        parts = list(map(int, sys.stdin.readline().split()))
        k_i = parts[0]
        if k_i == 0:
            continue
        users = parts[1:]
        first = users[0]
        for user in users[1:]:
            union(first, user)
    
    result = []
    for x in range(1, n + 1):
        root = find(x)
        result.append(str(size[root]))
    
    print(' '.join(result))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read efficiently using `sys.stdin` to handle large input sizes.
2. **Union-Find Initialization**: We initialize the Union-Find structure with each user as their own parent and their component size as 1.
3. **Processing Groups**: For each group, we union all users in the group with the first user in the group. This ensures all users in the same group are part of the same connected component.
4. **Finding Component Sizes**: After processing all groups, we determine the size of the connected component each user belongs to using the Union-Find structure. This size is the number of users that will know the news if the respective user starts spreading it.

This approach efficiently handles the problem constraints using the Union-Find data structure with path compression and union by size, ensuring near-linear time complexity.
