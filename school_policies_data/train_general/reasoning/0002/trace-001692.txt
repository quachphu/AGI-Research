To solve this problem, we need to determine if a given photo is colored or black-and-white based on the pixels in the photo matrix. The photo is considered black-and-white if it contains only white (W), grey (G), or black (B) pixels. If any pixel is cyan (C), magenta (M), or yellow (Y), the photo is considered colored.

### Approach
1. **Input Reading**: Read the dimensions of the photo matrix (n rows and m columns).
2. **Check Each Pixel**: For each pixel in the matrix, check if it is one of the colors C, M, or Y.
3. **Early Termination**: If any of the pixels are found to be C, M, or Y, immediately print "#Color" and exit. If all pixels are checked and none are C, M, or Y, print "#Black&White".

This approach ensures that we efficiently determine the result by checking each pixel in the matrix. If we encounter a colored pixel early, we terminate the check immediately, saving unnecessary processing.

### Solution Code
```python
def main():
    n, m = map(int, input().split())
    for _ in range(n):
        row = input().split()
        for pixel in row:
            if pixel in {'C', 'M', 'Y'}:
                print("#Color")
                return
    print("#Black&White")

main()
```

### Explanation
1. **Reading Input**: The first line of input is read to get the dimensions of the matrix. Subsequent lines are read as rows of the matrix.
2. **Checking for Colored Pixels**: Each row is processed, and each pixel in the row is checked. If any pixel is found to be C, M, or Y, the function immediately prints "#Color" and exits.
3. **Output Result**: If no colored pixels are found after checking all rows, the function prints "#Black&White".

This method ensures that we efficiently determine the result with minimal checks, leveraging early termination to optimize the process.
