To solve this problem, we need to determine the year with the maximum number of people alive on Longlifer planet based on given birth and death years. The solution must efficiently handle up to 100,000 individuals and years ranging from 1 to 10^9.

### Approach
1. **Event-Based Processing**: Treat each birth year as an event that increases the count of people alive and each death year as an event that decreases the count. This allows us to process all events in chronological order.
2. **Sorting Events**: Sort events primarily by year. For events occurring in the same year, process death events before birth events to ensure correct count adjustments.
3. **Tracking Counts**: As we process each event, maintain the current count of people alive. Track the maximum count observed and the earliest year this maximum occurs.
4. **Interval Handling**: Between consecutive events, the count remains constant. Check these intervals to determine if the current count exceeds the previously observed maximum or matches it but starts earlier.

### Solution Code
```python
n = int(input())
events = []
for _ in range(n):
    b, d = map(int, input().split())
    events.append((b, 1))
    events.append((d, -1))

events.sort()

prev_year = None
current_alive = 0
max_alive = 0
result_year = 0

for year, delta in events:
    if prev_year is not None and year > prev_year:
        if current_alive > max_alive:
            max_alive = current_alive
            result_year = prev_year
        elif current_alive == max_alive:
            if prev_year < result_year:
                result_year = prev_year
    current_alive += delta
    prev_year = year

# Check after the last event
if current_alive > max_alive:
    max_alive = current_alive
    result_year = prev_year
elif current_alive == max_alive:
    if prev_year < result_year:
        result_year = prev_year

print(result_year, max_alive)
```

### Explanation
1. **Reading Input**: The input is read and converted into a list of events where each birth year adds a `+1` event and each death year adds a `-1` event.
2. **Sorting Events**: Events are sorted by year. If two events occur in the same year, the death event (with `-1`) is processed before the birth event (with `+1`).
3. **Processing Events**: Iterate through sorted events, maintaining the current count of alive people. For each interval between consecutive events, check if the current count sets a new maximum or matches the maximum but starts earlier.
4. **Post-Processing Check**: After all events, check if the count after the last event sets a new maximum or matches it, updating the result year if necessary.

This approach efficiently processes up to 200,000 events (2 per individual) in O(n log n) time due to sorting, making it suitable for large input sizes.
