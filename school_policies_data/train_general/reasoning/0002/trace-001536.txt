To solve this problem, we need to determine the number of primitive roots modulo a given prime number \( p \). A primitive root modulo \( p \) is an integer \( x \) such that none of the integers \( x - 1, x^2 - 1, \ldots, x^{p-2} - 1 \) are divisible by \( p \), but \( x^{p-1} - 1 \) is. The number of primitive roots modulo a prime \( p \) can be found using Euler's totient function \( \phi \) applied to \( p-1 \).

### Approach
1. **Understanding Primitive Roots**: The number of primitive roots modulo a prime \( p \) is given by Euler's totient function \( \phi(p-1) \). This is because the multiplicative group modulo \( p \) is cyclic of order \( p-1 \), and the number of generators (primitive roots) of a cyclic group of order \( n \) is \( \phi(n) \).

2. **Euler's Totient Function**: To compute \( \phi(n) \), we need the prime factorization of \( n \). The function \( \phi(n) \) is calculated as \( n \times \prod_{p \mid n} \left(1 - \frac{1}{p}\right) \), where the product is over the distinct prime factors of \( n \).

3. **Prime Factorization**: Factorize \( n = p-1 \) into its prime factors. For each prime factor, apply the formula to compute the totient function.

### Solution Code
```python
def euler_phi(n):
    if n == 0:
        return 0
    original = n
    factors = set()
    i = 2
    while i * i <= n:
        if n % i == 0:
            factors.add(i)
            while n % i == 0:
                n //= i
        i += 1
    if n > 1:
        factors.add(n)
    result = original
    for p in factors:
        result = result // p * (p - 1)
    return result

def main():
    import sys
    p = int(sys.stdin.readline())
    n = p - 1
    print(euler_phi(n))

if __name__ == "__main__":
    main()
```

3. **Factorize \( n \)**: Use trial division to factorize \( n \) into its prime factors.
4. **Calculate Totient Function**: Using the prime factors, compute the Euler's totient function \( \phi(n) \) using the formula \( n \times \prod_{p \mid n} \left(1 - \frac{1}{p}\right) \).
