To solve this problem, we need to determine the minimum possible maximum number of times Yae has to wear any dress given the number of dresses and the number of parties. The goal is to distribute the parties as evenly as possible across the dresses to minimize the maximum frequency of use for any single dress.

### Approach
The key insight is to recognize that the problem can be reduced to a simple mathematical calculation. The minimum possible maximum frequency of wearing any dress is the ceiling of the division of the number of parties by the number of dresses. This can be efficiently computed using integer arithmetic to avoid floating-point operations.

The formula used is:
\[ \text{max\_frequency} = \left\lceil \frac{B}{A} \right\rceil \]
This can be computed using integer division as:
\[ \text{max\_frequency} = \frac{B + A - 1}{A} \]

### Solution Code
```python
def main():
    import sys
    A, B = map(int, sys.stdin.readline().split())
    print((B + A - 1) // A)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input consists of two integers, A (number of dresses) and B (number of parties).
2. **Mathematical Calculation**: The formula \((B + A - 1) // A\) is used to compute the ceiling of the division of B by A. This formula works because adding \(A - 1\) to B ensures that any remainder in the division results in an increment of the quotient by 1, effectively computing the ceiling without using floating-point arithmetic.
3. **Output the Result**: The result is printed, which represents the minimum possible maximum frequency of wearing any dress.

This approach efficiently computes the result in constant time, \(O(1)\), making it suitable for the input constraints up to \(10^5\).
