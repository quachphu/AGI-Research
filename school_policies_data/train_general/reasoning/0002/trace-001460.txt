To solve this problem, we need to determine the minimum number of steps required to color a rooted tree according to specified target colors. Each step allows us to color an entire subtree rooted at a chosen vertex with a specific color. The goal is to achieve the target coloring with the fewest steps possible.

### Approach
The key insight to solve this problem efficiently is to recognize that each time a subtree is colored, it affects all descendants of the chosen vertex. Therefore, we can minimize the number of steps by considering the color transitions along the path from the root to each node. Specifically, if a node's target color is different from its parent's target color, an additional step is required to color that subtree. 

The approach can be broken down as follows:
1. **Root Node**: The root node (vertex 1) must be colored in its target color, which counts as the first step.
2. **Color Transitions**: For each subsequent node, check if its target color differs from its parent's target color. Each such difference indicates an additional step needed.

By counting these color transitions, we can determine the total number of steps required.

### Solution Code
```python
n = int(input())
p = list(map(int, input().split()))
c = list(map(int, input().split()))

result = 1  # The root must be colored first

for i in range(2, n + 1):
    parent = p[i - 2]  # Parent of node i (since p is 0-based for nodes 2..n)
    if c[i - 1] != c[parent - 1]:
        result += 1

print(result)
```

### Explanation
1. **Reading Input**: The input consists of the number of vertices, the parent list for each vertex (starting from vertex 2), and the target colors for each vertex.
2. **Initial Step**: The root node (vertex 1) is always colored in its target color, which accounts for the first step.
3. **Color Transition Check**: For each vertex from 2 to n, check if its target color differs from its parent's target color. If it does, increment the step count.
4. **Output Result**: The total number of steps is the initial step plus the count of color transitions.

This approach efficiently determines the minimum steps by leveraging the tree structure and color transitions, ensuring an optimal solution in linear time, O(n), where n is the number of vertices.
