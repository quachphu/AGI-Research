To solve this problem, we need to handle a series of queries where we merge groups of campers and, after each query, determine the difference between the largest and smallest group sizes. If all campers are in a single group, the difference is zero.

### Approach
1. **Disjoint Set Union (DSU)**: We use DSU (Union-Find) to efficiently manage merging groups and finding the root of any camper's group. This helps in determining if two campers are already in the same group and merging them if they are not.
2. **Frequency Map**: A dictionary to keep track of the number of groups of each size. This helps in efficiently updating the minimum group size.
3. **Max Size Tracking**: A variable to keep track of the maximum group size, which can be updated in constant time after each merge.
4. **Min Heap**: A min-heap to efficiently retrieve the smallest group size. The heap is maintained lazily, meaning we check and remove invalid entries (sizes with zero frequency) when necessary.

### Solution Code
```python
import sys
import heapq

def main():
    input = sys.stdin.read().split()
    idx = 0
    N = int(input[idx])
    idx += 1
    Q = int(input[idx])
    idx += 1

    parent = list(range(N + 1))
    size = [1] * (N + 1)

    def find(x):
        if parent[x] != x:
            parent[x] = find(parent[x])
        return parent[x]

    frequency = {1: N}
    max_size = 1
    min_heap = [1]
    heapq.heapify(min_heap)
    groups_count = N
    current_answer = 0

    for _ in range(Q):
        A = int(input[idx])
        idx += 1
        B = int(input[idx])
        idx += 1

        x = find(A)
        y = find(B)
        if x == y:
            print(current_answer)
            continue

        a_size = size[x]
        b_size = size[y]

        if a_size < b_size:
            x, y = y, x
            a_size, b_size = b_size, a_size

        parent[y] = x
        size[x] += size[y]
        groups_count -= 1

        frequency[a_size] -= 1
        if frequency[a_size] == 0:
            del frequency[a_size]
        frequency[b_size] -= 1
        if frequency[b_size] == 0:
            del frequency[b_size]

        merged_size = a_size + b_size
        frequency[merged_size] = frequency.get(merged_size, 0) + 1

        if merged_size > max_size:
            max_size = merged_size

        heapq.heappush(min_heap, merged_size)

        if groups_count == 1:
            new_answer = 0
        else:
            while True:
                current_min_candidate = min_heap[0]
                if current_min_candidate in frequency:
                    break
                else:
                    heapq.heappop(min_heap)
            new_answer = max_size - current_min_candidate

        current_answer = new_answer
        print(current_answer)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Initialization**: We initialize the DSU structures, frequency map, max size, and min heap. Each camper starts in their own group of size 1.
2. **Query Handling**: For each query, we check if the campers are in the same group. If they are, we output the current answer. If not, we merge their groups.
3. **Updating Structures**: After merging, we update the frequency map to reflect the new group sizes, adjust the max size if necessary, and push the new group size into the min heap.
4. **Finding Minimum Size**: We lazily check the min heap to ensure the top element is valid (present in the frequency map), removing invalid entries as needed. The difference between the max and valid min size is computed and stored as the current answer.

This approach ensures efficient handling of up to 100,000 queries with a time complexity dominated by the DSU operations and heap maintenance, making it suitable for large input sizes.
