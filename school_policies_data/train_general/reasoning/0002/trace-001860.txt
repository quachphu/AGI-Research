### Approach
1. **Understand the Octahedron Rotation Group**: The octahedron has 24 rotational symmetries, which can be categorized into different conjugacy classes based on their cycle structures.
2. **Cycle Decomposition**: Each rotation can be decomposed into cycles of face permutations. The key insight is that a coloring is fixed by a rotation if and only if all faces in each cycle of the permutation have the same color.
3. **Burnside's Lemma**: The number of distinct colorings is the average number of colorings fixed by each group element. This involves summing the number of fixed colorings for each rotation and dividing by the number of rotations (24).

import sys
from collections import defaultdict

# Define the conjugacy classes of the octahedral rotation group and their cycle decompositions
conjugacy_classes = [
    # Identity: 1 element, cycle decomposition 1^8
    {
        'size': 1,
        'cycles': [1, 1, 1, 1, 1, 1, 1, 1]
    },
    # 180-degree face-axis rotations: 3 elements, cycle decomposition 2^4
    {
        'size': 3,
        'cycles': [2, 2, 2, 2]
    },
    # 180-degree edge-axis rotations: 6 elements, cycle decomposition 2^4
    {
        'size': 6,

    },

    {
        'size': 6,

    },
    # 120-degree vertex-axis rotations: 8 elements, cycle decomposition 3^2 1^2
    {
        'size': 8,
        'cycles': [3, 3, 1, 1]
    }

def count_assignments(cycles, counts_list):
    memo = {}
    n = len(cycles)
    m = len(counts_list)
    
    def backtrack(index, remaining):
        key = (index, tuple(remaining))
        if key in memo:
            return memo[key]
        if index == n:
            if all(x == 0 for x in remaining):
                return 1
            else:
                return 0
        total = 0
        current = cycles[index]
        for i in range(m):
            if remaining[i] >= current:
                new_remaining = list(remaining)
                new_remaining[i] -= current
                total += backtrack(index + 1, new_remaining)
        memo[key] = total
        return total
    
    return backtrack(0, counts_list)
