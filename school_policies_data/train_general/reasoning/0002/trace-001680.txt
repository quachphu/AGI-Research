To solve this problem, we need to determine the maximum path sum in a triangle of numbers where each number can move to the number directly below it or the number diagonally below and to the right. The solution employs dynamic programming to efficiently compute the maximum sum from the top to the bottom of the triangle.

### Approach
1. **Dynamic Programming (DP) Setup**: We use a dynamic programming approach to keep track of the maximum sum that can be achieved up to each element in the triangle.
2. **Bottom-Up Calculation**: Starting from the top of the triangle, we compute the maximum possible sum for each element by considering the maximum sum from the possible previous elements (either directly above or diagonally above-left).
3. **Iterative Update**: For each row, we update the current row's sums based on the previous row's sums. This allows us to build up the solution iteratively without needing to recompute values multiple times.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    for _ in range(n):
        lines = int(sys.stdin.readline())
        triangle = []
        for _ in range(lines):
            row = list(map(int, sys.stdin.readline().split()))
            triangle.append(row)
        if not triangle:
            print(0)
            continue
        prev_sums = triangle[0].copy()
        for i in range(1, lines):
            current_row = triangle[i]
            current_sums = []
            for j in range(len(current_row)):
                if j == 0:
                    current = current_row[j] + prev_sums[0]
                elif j == len(current_row) - 1:
                    current = current_row[j] + prev_sums[-1]
                else:
                    current = current_row[j] + max(prev_sums[j-1], prev_sums[j])
                current_sums.append(current)
            prev_sums = current_sums
        print(max(prev_sums))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency, especially with large input sizes. The number of test cases is read first, followed by each test case's data.
2. **Triangle Construction**: Each test case's triangle is constructed by reading the specified number of rows.
3. **Dynamic Programming Initialization**: The first row of the triangle is used to initialize the previous sums array.
4. **Iterative Sum Calculation**: For each subsequent row, the maximum possible sum for each element is computed by considering the maximum of the two possible previous sums (from the element directly above or diagonally above-left). This is done iteratively for each element in the current row.
5. **Result Extraction**: After processing all rows, the maximum value in the last row of sums is the result for that test case, which is then printed.

This approach ensures that we efficiently compute the maximum path sum using dynamic programming, which runs in O(n^2) time complexity for each test case, where n is the number of rows in the triangle. This is optimal given the problem constraints.
