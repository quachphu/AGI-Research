To solve this problem, we need to determine if a given seating arrangement on a row of chairs is "maximal" according to two conditions: no adjacent seated people and the impossibility of seating another person without violating the first condition.

### Approach
1. **Check Validity**: Ensure that no two adjacent seats are occupied. For seats at the ends (first and last), they are only considered adjacent if there are exactly two chairs.
2. **Check Maximality**: Verify that it's impossible to seat another person. This means every empty seat must have at least one adjacent occupied seat.

                neighbors.append(i-1)
            elif n == 2:
                neighbors.append(1)
            # Right neighbor
            if i < n-1:
                neighbors.append(i+1)
            elif n == 2:
                neighbors.append(0)
            # Check if all neighbors are '0'
            possible = True
            for neighbor in neighbors:
                if s[neighbor] == '1':
                    possible = False
                    break
            if possible:
                can_add = True
                break

    print("No" if can_add else "Yes")

main()

2. **Maximality Check**: After confirming the arrangement is valid, the code checks if any empty seat can be occupied without violating the adjacency rule. If even one such seat exists, the arrangement is not maximal.
