To solve this problem, we need to determine the minimum number of operations required to make the volumes of all chemicals equal using the allowed operations of doubling or halving the volume (integer division). 

### Approach
1. **Generate Possible Targets**: For each chemical, generate all possible target volumes it can reach by repeatedly halving and then doubling. Track the minimum number of operations required to reach each target.
2. **Track Common Targets**: Use a dictionary to track how many chemicals can reach each target and the sum of the operations required for all chemicals to reach that target.
3. **Find Optimal Target**: From the common targets, determine the one with the minimum total operations.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    input = sys.stdin.read().split()
    n = int(input[0])
    a = list(map(int, input[1:n+1]))
    
    x_total = defaultdict(lambda: (0, 0))  # (count, sum_steps)
    
    for num in a:
        local_steps = {}
        current = num
        k = 0
        
        while True:
            v = current
            if v == 0:
                x = 0
                steps = k
                if x not in local_steps or steps < local_steps.get(x, float('inf')):
                    local_steps[x] = steps
                break
            
            m = 0
            while m <= 40:
                x = v * (2 ** m)
                steps = k + m
                if x not in local_steps or steps < local_steps.get(x, float('inf')):
                    local_steps[x] = steps
                m += 1
            
            current = current // 2
            k += 1
        
        for x, steps in local_steps.items():
            count, total = x_total[x]
            x_total[x] = (count + 1, total + steps)
    
    min_total = float('inf')
    for x, (count, total) in x_total.items():
        if count == n and total < min_total:
            min_total = total
    
    print(min_total if min_total != float('inf') else 0)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Generate Possible Targets**: For each chemical volume, we consider all possible values obtained by halving until zero and then doubling. Each possible target volume and the corresponding operations (halves and doubles) are tracked.
2. **Track Common Targets**: Using a dictionary, we count how many chemicals can reach each target and sum the operations needed. This helps identify targets common to all chemicals.
3. **Determine Optimal Target**: The target with the minimum sum of operations across all chemicals is selected. This ensures the solution is both feasible and optimal in terms of operations required.

This approach efficiently explores possible targets and operations, ensuring we find the optimal solution within computational limits.
