To solve this problem, we need to compute the total sum of XOR-sums for all possible subarrays of a given array. The challenge is to do this efficiently given the constraints, which require an optimal solution to avoid excessive computation time.

### Approach
The key insight is to leverage the properties of bitwise XOR operations and prefix sums. By breaking down the problem into individual bit contributions, we can efficiently compute the total sum without iterating over all possible subarrays directly.

1. **Bitwise Contribution**: For each bit position (from 0 to 30), determine how many subarrays have an XOR-sum with that bit set. This is because the XOR-sum of a subarray will have a bit set if there is an odd number of elements with that bit set in the subarray.
2. **Prefix XOR**: Use a prefix XOR array to track the cumulative XOR up to each element. This helps in quickly determining the XOR-sum of any subarray.
3. **Count Pairs**: For each bit position, count the number of valid pairs of prefix XOR values that result in an odd count of that bit. This is done by maintaining counts of prefix XOR values and updating them as we iterate through the array.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        A = list(map(int, input[ptr:ptr + N]))
        ptr += N
        total = 0
        for k in range(31):
            cnt0 = 1  # Initial count for prefix_xor[0] = 0
            cnt1 = 0
            current_xor = 0
            res = 0
            for num in A:
                bit = (num >> k) & 1
                current_xor ^= bit
                if current_xor:
                    res += cnt0
                    cnt1 += 1
                else:
                    res += cnt1
                    cnt0 += 1
            total += res * (1 << k)
        print(total)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input Efficiently**: The input is read all at once and processed using a pointer to handle large input sizes efficiently.
2. **Bitwise Processing**: For each bit position from 0 to 30, we process each number in the array to determine the contribution of that bit to the total sum.
3. **Prefix XOR Tracking**: As we iterate through the array, we maintain the current XOR value and counts of how many times each XOR value (0 or 1) has been seen. This allows us to quickly determine the number of valid subarrays ending at each position that contribute to the current bit's sum.
4. **Result Calculation**: For each bit, the number of valid subarrays is multiplied by \(2^k\) (the value of the bit) and added to the total sum.

This approach ensures that we efficiently compute the result in \(O(N \cdot 31)\) time per test case, which is feasible given the problem constraints.
