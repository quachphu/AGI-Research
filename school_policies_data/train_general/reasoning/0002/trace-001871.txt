To solve this problem, we need to determine the minimum possible equal price for all goods such that the total revenue from selling all goods at this price is at least the same as the total revenue from selling them at their original prices. 

### Approach
1. **Problem Analysis**: The key insight is that the total revenue from the new price must be at least the original total revenue. This translates to finding the smallest integer price \( x \) such that \( x \times n \) (where \( n \) is the number of goods) is greater than or equal to the sum of the original prices.
2. **Mathematical Formulation**: The minimum price \( x \) can be derived using the ceiling of the division of the sum of original prices by the number of goods. This is efficiently computed using integer arithmetic as \( (sum + n - 1) // n \), where `sum` is the sum of the original prices and `n` is the number of goods.
3. **Algorithm**: For each query, read the number of goods and their prices, compute the sum of the prices, and then determine the minimum price using the formula mentioned.

### Solution Code
```python
q = int(input())
for _ in range(q):
    n = int(input())
    a = list(map(int, input().split()))
    total = sum(a)
    print((total + n - 1) // n)
```

### Explanation
1. **Reading Input**: The input consists of multiple queries. For each query, we first read the number of goods and then the list of their prices.
2. **Sum Calculation**: Compute the sum of the original prices.
3. **Minimum Price Calculation**: Using the formula \( (sum + n - 1) // n \), we determine the minimum price that ensures the total revenue is not less than the original. This formula effectively computes the ceiling of the division without using floating-point arithmetic, ensuring accuracy and efficiency.

This approach ensures that we efficiently compute the required minimum price for each query in constant time, making the solution both optimal and easy to understand.
