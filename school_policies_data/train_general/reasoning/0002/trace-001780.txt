To solve this problem, we need to determine the minimum number of elements to add to an array so that its median becomes a specified value, x. The median of an array of length m is the element at position (m-1)//2 after sorting.

### Approach
1. **Sort the Original Array**: This helps in efficiently determining the number of elements less than or equal to x and greater than or equal to x.
2. **Count Elements**: Use binary search to count the number of elements less than or equal to x (original_leq) and the number of elements greater than or equal to x (original_geq).
3. **Iterate to Find Minimum k**: For each possible number of elements to add (k), check if the conditions for x being the median are met. The conditions are:
   - The number of elements less than or equal to x plus k (added elements) should be at least the position of the median plus one.
   - The number of elements greater than or equal to x plus k (added elements) should be at least the remaining elements after the median position.

### Solution Code
```python
import bisect

n, x = map(int, input().split())
arr = list(map(int, input().split()))
sorted_arr = sorted(arr)

original_leq = bisect.bisect_right(sorted_arr, x)
original_geq = len(sorted_arr) - bisect.bisect_left(sorted_arr, x)

k = 0
while True:
    m = n + k
    pos = (m - 1) // 2
    req_leq = pos + 1
    req_geq = m - pos
    if (original_leq + k >= req_leq) and (original_geq + k >= req_geq):
        print(k)
        break
    k += 1
```

### Explanation
1. **Sorting the Array**: Sorting helps in efficiently finding the counts of elements using binary search.
2. **Binary Search Counts**: Using `bisect_right`, we find the count of elements less than or equal to x. Using `bisect_left`, we determine the count of elements greater than or equal to x.
3. **Checking Conditions**: For each possible k (starting from 0), we compute the new array length (m) and the median position (pos). We check if the counts of elements meet the required conditions for x to be the median. The loop continues until the conditions are satisfied, ensuring the minimum k is found.

This approach efficiently iterates through possible values of k, ensuring the solution is both optimal and correct.
