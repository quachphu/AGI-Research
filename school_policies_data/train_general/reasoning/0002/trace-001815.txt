To solve this problem, we need to count the number of times Ilya wakes up while traveling through check-posts on a hilly terrain. She wakes up whenever the terrain changes from increasing to decreasing or vice versa. 

### Approach
1. **Input Reading**: Read the number of test cases. For each test case, read the number of check-posts and their respective heights.
2. **Determine Slopes**: For each consecutive pair of check-posts, determine if the slope between them is increasing (up) or decreasing (down).
3. **Count Slope Changes**: Track the number of times the slope changes from up to down or down to up. Each such change indicates a wake-up.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    for _ in range(T):
        N = int(input[ptr])
        ptr += 1
        A = list(map(int, input[ptr:ptr+N]))
        ptr += N
        
        if N < 2:
            print(0)
            continue
        
        slopes = []
        for i in range(N-1):
            if A[i+1] > A[i]:
                slopes.append(1)
            else:
                slopes.append(-1)
        
        count = 0
        for i in range(1, len(slopes)):
            if slopes[i] != slopes[i-1]:
                count += 1
        
        print(count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints. The input is split into a list for easy processing.
2. **Slope Calculation**: For each consecutive pair of check-posts, we determine the direction of the slope (up or down) and store these directions in a list.
3. **Counting Changes**: We iterate through the list of slopes and count how many times the direction changes from one slope to the next. Each change corresponds to a wake-up event.

This approach efficiently processes each test case in linear time relative to the number of check-posts, making it suitable even for the upper constraint limits.
