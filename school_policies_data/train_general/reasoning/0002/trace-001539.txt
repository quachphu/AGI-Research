To solve this problem, we need to determine the number of unique leaves Alyona has picked based on their species and color. Each leaf is considered unique if there is no other leaf with the same species and color combination.

### Approach
1. **Reading Input**: The first input line gives the number of leaves, `n`. The subsequent `n` lines each contain two strings: the species and color of a leaf.
2. **Tracking Unique Leaves**: Use a set data structure to store each unique combination of species and color. Sets automatically handle duplicates, so adding an existing combination will not increase the set size.
3. **Counting Unique Leaves**: The size of the set after processing all input lines will be the number of unique leaves Alyona has picked.

### Solution Code
```python
def main():
    import sys
    n = int(sys.stdin.readline())
    unique_leaves = set()
    for _ in range(n):
        species, color = sys.stdin.readline().strip().split()
        unique_leaves.add((species, color))
    print(len(unique_leaves))

main()
```

### Explanation
1. **Reading Input**: The code reads the number of leaves `n` and then processes each subsequent line to extract species and color pairs.
2. **Using a Set for Uniqueness**: Each species-color pair is stored as a tuple in a set. Tuples are used because they are hashable and can be elements of a set. The set ensures that only unique pairs are stored.
3. **Output the Result**: The length of the set, which represents the number of unique species-color pairs, is printed as the result.

This approach efficiently handles the problem by leveraging the properties of sets to automatically manage uniqueness, resulting in a solution that is both concise and efficient.
