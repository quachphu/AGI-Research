To solve this problem, we need to determine the number of contiguous subarrays (segments) of an array where a given number \( x \) is the \( k \)-th smallest element. This translates to counting the number of segments where exactly \( k \) elements are less than \( x \).

### Approach
1. **Transform the Array**: Convert the input array into a binary array where each element is 1 if it is less than \( x \), and 0 otherwise. This helps in simplifying the problem to counting subarrays with a specific sum of 1s.
2. **Prefix Sum Calculation**: Compute the prefix sums of the binary array. This helps in efficiently determining the sum of any subarray.
3. **Frequency Count**: Track the frequency of each prefix sum using a dictionary.
4. **Auto-correlation using FFT**: Use Fast Fourier Transform (FFT) to compute the auto-correlation of the frequency array. This allows us to efficiently determine the number of subarrays with each possible sum of 1s.
5. **Adjust for k=0**: Adjust the result for \( k=0 \) by considering valid subarrays and subtracting invalid cases.

### Solution Code
```python
import numpy as np

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    x = int(input[idx])
    idx += 1
    a = list(map(int, input[idx:idx+n]))
    idx += n
    
    # Create the binary array b where b[i] is 1 if a[i] < x else 0
    b = [1 if num < x else 0 for num in a]
    
    # Compute prefix sums
    prefix = [0]
    for num in b:
        prefix.append(prefix[-1] + num)
    
    # Count the frequency of each prefix sum
    from collections import defaultdict
    cnt = defaultdict(int)
    for s in prefix:
        cnt[s] += 1
    
    s_max = max(prefix)
    
    # Create cnt_list where index is the sum and value is the count
    cnt_list = [0] * (s_max + 1)
    for s in range(s_max + 1):
        cnt_list[s] = cnt.get(s, 0)
    
    # Compute auto-correlation using FFT
    L = 1
    while L < 2 * s_max + 1:
        L *= 2
    
    # Perform FFT on the cnt_list padded to length L
    fft_a = np.fft.fft(cnt_list, L)
    # Compute the auto-correlation
    auto_corr = np.fft.ifft(fft_a * np.conj(fft_a)).real
    auto_corr = np.round(auto_corr).astype(int)
    
    # Prepare the answer array
    answer = [0] * (n + 1)
    total = len(prefix)  # n+1
    
    # Handle k=0
    answer[0] = (auto_corr[0] - total) // 2
    
    # Handle k >= 1
    for k in range(1, n + 1):
        if k <= s_max:
            answer[k] = auto_corr[k]
        else:
            answer[k] = 0
    
    # Output the answer
    print(' '.join(map(str, answer)))
```
