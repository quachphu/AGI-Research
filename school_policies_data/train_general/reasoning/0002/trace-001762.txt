To solve this problem, we need to determine the number of terms in the Farey sequence \( F_n \) for given values of \( n \). The Farey sequence \( F_n \) includes all reduced fractions between 0/1 and 1/1 with denominators up to \( n \), sorted in ascending order. The key insight is to efficiently compute the number of these terms using Euler's Totient function, which helps count the number of coprime integers up to \( n \).

### Approach
1. **Euler's Totient Function**: This function, \( \phi(d) \), counts the number of integers up to \( d \) that are coprime with \( d \). For each \( n \), the number of terms in \( F_n \) is given by \( 2 + \sum_{d=2}^{n} \phi(d) \), where the 2 accounts for the endpoints 0/1 and 1/1.

2. **Precomputation**: To efficiently handle multiple test cases, precompute the Totient function for all integers up to the maximum possible value (1,000,000) using a sieve method. This allows us to compute the sum of Totient values up to any \( n \) in constant time.

3. **Prefix Sum Array**: After computing the Totient values, construct a prefix sum array where each entry at index \( i \) contains the sum of Totient values from 2 to \( i \). This allows quick lookup for each test case.

### Solution Code
```python
import sys

def main():
    max_n = 10**6
    phi = list(range(max_n + 1))
    
    for i in range(2, max_n + 1):
        if phi[i] == i:  # i is a prime
            for j in range(i, max_n + 1, i):
                phi[j] -= phi[j] // i
    
    # Compute prefix sums for phi from 2 to max_n
    sum_phi = [0] * (max_n + 1)
    current_sum = 0
    for d in range(2, max_n + 1):
        current_sum += phi[d]
        sum_phi[d] = current_sum
    
    # Read input and process each test case
    input_data = sys.stdin.read().split()
    t = int(input_data[0])
    results = []
    for ni in input_data[1:t+1]:
        n = int(ni)
        results.append(str(sum_phi[n] + 2))
    
    print('\n'.join(results))

if __name__ == "__main__":
    main()
```

2. **Prefix Sum Array**: After computing the Totient values, we build a prefix sum array to store cumulative sums. This allows us to quickly answer each query by summing the relevant range in constant time.

3. **Efficient Query Handling**: By precomputing the necessary values, each test case is answered in constant time, making the solution highly efficient even for large input sizes.

This approach ensures that we handle up to 10,000 test cases efficiently, even with the maximum value of \( n \) being 1,000,000. The use of precomputation and prefix sums allows us to meet the problem's constraints effectively.
