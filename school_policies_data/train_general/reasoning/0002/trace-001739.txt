To solve this problem, we need to determine the maximum travel cost Heidi might incur if she is caught in a prank where she has to deliver a message through a tree of friends starting from Jenny (node 0). The goal is to find the longest path in the tree starting from node 0, where the path cost is the sum of the edge weights along the path.

### Approach
1. **Tree Structure**: The friends' network forms a tree, which is a connected acyclic graph. This means there is exactly one path between any two nodes.
2. **Depth-First Search (DFS)**: We use DFS to explore all possible paths starting from node 0. For each node, we recursively compute the maximum path sum from that node to any leaf node, considering only unvisited nodes (by keeping track of the parent node to avoid cycles).
3. **Dynamic Programming Insight**: For each node, the maximum path sum starting from that node is the sum of the edge cost to one of its children plus the maximum path sum from that child. This allows us to efficiently compute the longest path using a recursive approach.

### Solution Code
```python
import sys
sys.setrecursionlimit(10000)

n = int(sys.stdin.readline())
adj = [[] for _ in range(n)]
for _ in range(n - 1):
    u, v, c = map(int, sys.stdin.readline().split())
    adj[u].append((v, c))
    adj[v].append((u, c))

def dfs(node, parent):
    max_path = 0
    for neighbor, cost in adj[node]:
        if neighbor != parent:
            current = cost + dfs(neighbor, node)
            if current > max_path:
                max_path = current
    return max_path

print(dfs(0, -1))
```

### Explanation
1. **Reading Input**: The input is read and stored in an adjacency list to represent the tree structure.
2. **DFS Function**: The `dfs` function recursively explores each node starting from node 0. For each node, it checks all its neighbors (excluding the parent node to avoid cycles) and computes the maximum path sum from the current node to any leaf node.
3. **Recursion Limit**: The recursion limit is increased to handle the maximum depth of the tree, which can be up to 100 nodes deep.

This approach efficiently computes the longest path starting from node 0 using DFS, ensuring that each node is visited only once. The solution optimally explores the tree structure to determine the maximum possible travel cost Heidi might incur.
