To solve this problem, we need to determine if we can transform matrix B into matrix A using a series of operations where each operation sets all elements of a 2x2 submatrix in B to 1. The key insight is that each 0 in A must not be covered by any operation, while each 1 in A must be covered by at least one operation.

### Approach
1. **Check Validity of 1s in A**: For each cell in A that contains a 1, verify if there exists at least one 2x2 submatrix (starting at some valid position) such that all elements in that submatrix are 1. If any 1 in A cannot be covered by such a submatrix, it's impossible to transform B into A, and we output -1.
2. **Collect Valid Operations**: If all 1s in A can be covered by valid submatrices, collect all such valid 2x2 submatrices. These submatrices are the operations needed to transform B into A.

### Solution Code
```python
n, m = map(int, input().split())
matrix = []
for _ in range(n):
    row = list(map(int, input().split()))
    matrix.append(row)

possible = True

for i in range(n):
    for j in range(m):
        if matrix[i][j] == 1:
            found = False
            # Check possible submatrices covering (i, j)
            for dx in [0, -1]:
                x_candidate = i + dx
                if x_candidate < 0 or x_candidate >= n - 1:
                    continue
                for dy in [0, -1]:
                    y_candidate = j + dy
                    if y_candidate < 0 or y_candidate >= m - 1:
                        continue
                    # Check if the submatrix is all 1s
                    if (matrix[x_candidate][y_candidate] == 1 and
                        matrix[x_candidate][y_candidate + 1] == 1 and
                        matrix[x_candidate + 1][y_candidate] == 1 and
                        matrix[x_candidate + 1][y_candidate + 1] == 1):
                        found = True
                        break
                if found:
                    break
            if not found:
                print(-1)
                exit()

operations = []
for x in range(n - 1):
    for y in range(m - 1):
        if (matrix[x][y] == 1 and
            matrix[x][y + 1] == 1 and
            matrix[x + 1][y] == 1 and
            matrix[x + 1][y + 1] == 1):
            operations.append((x + 1, y + 1))  # Convert to 1-based

print(len(operations))
for op in operations:
    print(op[0], op[1])
```

1. **Reading Input**: The input is read into a matrix where each element is either 0 or 1.
2. **Check Validity**: For each cell containing a 1, we check all possible 2x2 submatrices that could cover this cell. If none of these submatrices are valid (all elements 1), we immediately output -1 and exit.
3. **Collect Operations**: If all 1s are covered, we collect all valid 2x2 submatrices (starting positions) that consist entirely of 1s. These positions are converted to 1-based indexing as required.
4. **Output**: The number of valid operations followed by each operation's starting position is printed.

This approach ensures that we efficiently check the feasibility of transforming B into A and construct the necessary operations if possible. The solution leverages a systematic check of submatrices and collects valid operations to cover all 1s in A.
