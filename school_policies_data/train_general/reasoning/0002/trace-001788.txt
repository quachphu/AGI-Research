The game involves choosing a random integer `c` between 1 and `n`, and the winner is determined based on which player's chosen number is closer to `c`. If both are equidistant, Misha wins.

### Approach
1. **Understanding the Winning Condition**: Andrew wins if his chosen number `a` is closer to `c` than Misha's number `m`. The key insight is to find the midpoint between `a` and `m` and determine the range of `c` values where Andrew's number is closer.
2. **Midpoint Analysis**: For a given `a`, the midpoint between `a` and `m` determines the range of `c` values where Andrew wins. If `a < m`, Andrew wins for `c` values less than the midpoint. If `a > m`, he wins for `c` values greater than the midpoint.
3. **Optimal `a` Selection**: The optimal `a` values to consider are `m-1` (left candidate) and `m+1` (right candidate). These positions are chosen to maximize the range of `c` values where Andrew wins.
4. **Edge Cases**: Handle cases where `m` is at the boundary of the range [1, n], ensuring `a` remains within valid bounds.

### Solution Code
```python
n, m = map(int, input().split())

candidates = []
if m - 1 >= 1:
    candidates.append(m - 1)
if m + 1 <= n:
    candidates.append(m + 1)

if not candidates:
    print(m)

    best_a = None

        else:  # a > m

            best_a = a
    print(best_a)
```

   - For `a = m+1` (right candidate), the count is determined by the range from the ceiling of the midpoint to `n`.
