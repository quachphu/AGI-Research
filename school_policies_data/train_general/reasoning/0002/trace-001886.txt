To solve this problem, we need to determine how many times a given number \( x \) appears in an \( n \times n \) multiplication table where each cell at position (i, j) contains the product \( i \times j \). The solution must efficiently count these occurrences without explicitly constructing the table, as \( n \) can be very large (up to \( 10^5 \)).

### Approach
1. **Check Trivial Case**: If \( x \) is greater than \( n^2 \), it cannot exist in the table, so the result is immediately 0.
2. **Find Divisors Efficiently**: For \( x \) to appear in the table, it must be the product of two integers \( i \) and \( j \) where both \( i \) and \( j \) are between 1 and \( n \). Instead of checking all pairs, we find all divisors of \( x \) up to \( \sqrt{x} \). For each divisor \( d \), the corresponding pair is \( (d, x/d) \).
3. **Check Validity of Divisors**: For each divisor pair \( (d, x/d) \), check if both values are within the bounds of the table (i.e., ≤ \( n \)). If valid, count both pairs unless they are the same (i.e., \( d = x/d \)).

### Solution Code
```python
import math

n, x = map(int, input().split())

if x > n * n:
    print(0)
else:
    count = 0
    sqrt_x = math.isqrt(x)
    for d in range(1, sqrt_x + 1):
        if x % d == 0:
            j = x // d
            if d <= n and j <= n:
                if d == j:
                    count += 1
                else:
                    count += 2
    print(count)
```

### Explanation
1. **Trivial Case Handling**: The code first checks if \( x \) is larger than \( n^2 \). If so, it immediately outputs 0.
2. **Divisor Calculation**: Using a loop up to \( \sqrt{x} \), the code efficiently finds all divisors of \( x \). For each divisor \( d \), the corresponding divisor \( x/d \) is also considered.
3. **Validity Check**: Each pair of divisors \( (d, x/d) \) is checked to ensure both values are within the table bounds. Valid pairs are counted, with special handling for perfect squares to avoid double-counting.

This approach ensures that we efficiently check all possible pairs without explicitly constructing the table, leading to an optimal solution with a time complexity of \( O(\sqrt{x}) \).
