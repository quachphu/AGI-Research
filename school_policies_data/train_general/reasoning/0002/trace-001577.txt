To solve this problem, we need to determine if we can rearrange a given string such that it is not a palindrome. If it's impossible to do so, we should return -1; otherwise, we can return any valid rearrangement.

### Approach
1. **Check for Single Character Strings**: If the string length is 1, it is inherently a palindrome, so we return -1.
2. **Check for Uniform Characters**: If all characters in the string are the same, any rearrangement will still be a palindrome, so we return -1.
3. **Sort the String**: If the string can be rearranged into a non-palindrome, sorting the characters and returning the sorted string will suffice. This works because a sorted string with mixed characters will not be a palindrome due to the order of characters.

### Solution Code
```python
t = int(input())
for _ in range(t):
    s = input().strip()
    if len(s) == 1:
        print(-1)
    else:
        if len(set(s)) == 1:
            print(-1)
        else:
            sorted_s = ''.join(sorted(s))
            print(sorted_s)
```

### Explanation
1. **Input Handling**: Read the number of test cases.
2. **Single Character Check**: Immediately return -1 for strings of length 1.
3. **Uniform Character Check**: Use a set to determine if all characters are the same. If so, return -1.
4. **Sorting and Output**: For valid cases, sort the string and print it. Sorting ensures that the characters are arranged in a non-decreasing order, which, unless all characters are the same, will not form a palindrome.

This approach efficiently checks the necessary conditions and leverages sorting to ensure a non-palindromic arrangement when possible. The time complexity is dominated by the sorting step, which is O(n log n) for each string, where n is the length of the string. This is efficient given the problem constraints.
