To solve this problem, we need to minimize the sum of a list of positive integers after performing a series of operations where we subtract the smaller number from the larger one repeatedly. The key insight is that these operations are analogous to finding the greatest common divisor (GCD) of the numbers. The minimal sum is achieved when each number is reduced to the GCD of the entire list, and the sum is the GCD multiplied by the number of elements.

### Approach
1. **Understanding the Operations**: The operations allowed are similar to the steps in the Euclidean algorithm for finding the GCD. Repeatedly subtracting the smaller number from the larger one reduces the numbers to their GCD.
2. **GCD of the List**: The minimal sum is obtained when each number is reduced to the GCD of the entire list. The sum of these reduced values (each being the GCD) is the GCD multiplied by the number of elements.
3. **Algorithm**: 
   - Compute the GCD of all the numbers in the list.
   - Multiply the GCD by the number of elements to get the minimal sum.

### Solution Code
```python
import sys
import math
from functools import reduce

def main():
    n = int(sys.stdin.readline())
    numbers = list(map(int, sys.stdin.readline().split()))
    gcd = reduce(math.gcd, numbers)
    print(gcd * n)

main()
```

### Explanation
1. **Reading Input**: The input consists of an integer `n` followed by `n` positive integers.
2. **Computing GCD**: Using Python's `math.gcd` function and `functools.reduce`, we compute the GCD of the entire list of numbers. The `reduce` function applies `math.gcd` cumulatively to all elements in the list.
3. **Calculating Minimal Sum**: The minimal sum is the product of the GCD and the number of elements `n`, as each element in the list can be reduced to the GCD value through the allowed operations.

This approach efficiently computes the minimal sum by leveraging the properties of the GCD, ensuring optimal performance even for the upper limits of the input constraints.
