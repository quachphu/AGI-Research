### Approach
1. **Burnside's Lemma**: This lemma helps in counting the number of distinct objects under group actions (rotations, in this case). The lemma states that the number of distinct configurations is the average number of configurations fixed by each group action.

2. **Cube Symmetries**: The cube has 24 rotational symmetries, which can be categorized into five types based on their axes and rotation angles:
   - Identity rotation
   - 90-degree and 270-degree rotations around face axes
   - 180-degree rotations around face axes
   - 120-degree and 240-degree rotations around vertex axes
   - 180-degree rotations around edge axes

3. **Cycle Decomposition**: Each symmetry type can be decomposed into cycles of face positions. The key insight is that a valid coloring must be consistent within each cycle for the coloring to be fixed by that symmetry.

4. **Backtracking with Combinatorics**: For each symmetry type, we use a backtracking approach to count valid color assignments that fit the cycle decomposition, ensuring the sum of cycle lengths for each color matches the given counts.

### Solution Code

import sys
from itertools import combinations
from collections import defaultdict

def count_assignments(cycles, color_counts):
    if not color_counts:
        return 1 if not cycles else 0
    count, color = color_counts[0]
    total = 0
    for subset_size in range(len(cycles) + 1):
        for indices in combinations(range(len(cycles)), subset_size):
            subset = [cycles[i] for i in indices]
            if sum(subset) != count:
                continue
            remaining_cycles = [cycles[i] for i in range(len(cycles)) if i not in indices]
            total += count_assignments(remaining_cycles, color_counts[1:])
    return total

def main():
    input_str = sys.stdin.readline().strip()
    color_count = defaultdict(int)
    for c in input_str:
        color_count[c] += 1
    colors = sorted(color_count.items())
    color_counts = [(count, color) for color, count in colors]
    
    symmetry_types = [
        {'cycles': [1]*6, 'count': 1},
        {'cycles': [4, 1, 1], 'count': 6},
        {'cycles': [2, 2, 1, 1], 'count': 3},
        {'cycles': [3, 3], 'count': 8},
        {'cycles': [2, 2, 2], 'count': 6},
    ]
    
    total = 0
    for st in symmetry_types:
        cycles = st['cycles']
        sym_count = st['count']
        assignments = count_assignments(cycles, color_counts)
        total += assignments * sym_count
    
    print(total // 24)
