To solve this problem, we need to determine the center point of a set of battle-ship positions provided in each test case. The center point is calculated as the average of all x-coordinates and y-coordinates of the battle-ships. The solution must ensure precision in floating-point arithmetic to avoid errors due to rounding.

### Approach
1. **Reading Input**: The input consists of multiple test cases. For each test case, read the number of battle-ships and their coordinates.
2. **Summing Coordinates**: Sum all the x-coordinates and y-coordinates separately.
3. **Calculating Averages**: Compute the average x-coordinate and y-coordinate by dividing the sums by the number of battle-ships.
4. **Precision Handling**: Use the `Decimal` module to handle high precision arithmetic and avoid floating-point errors.
5. **Rounding**: Round the averages to two decimal places using the `ROUND_HALF_UP` rounding mode to ensure correct rounding even when the third decimal digit is exactly 5.
6. **Output Formatting**: Print the results in the required format with two decimal places.

### Solution Code
```python
import sys
from decimal import Decimal, getcontext, ROUND_HALF_UP

getcontext().rounding = ROUND_HALF_UP

def main():
    T = int(sys.stdin.readline())
    for _ in range(T):
        N = int(sys.stdin.readline())
        sum_x = Decimal('0')
        sum_y = Decimal('0')
        for _ in range(N):
            x_str, y_str = sys.stdin.readline().strip().split()
            sum_x += Decimal(x_str)
            sum_y += Decimal(y_str)
        avg_x = sum_x / Decimal(N)
        avg_y = sum_y / Decimal(N)
        rounded_x = avg_x.quantize(Decimal('0.00'))
        rounded_y = avg_y.quantize(Decimal('0.00'))
        print(f"({rounded_x} , {rounded_y})")

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read line by line using standard input. The number of test cases is read first, followed by the details for each test case.
- **Summing Coordinates**: Using the `Decimal` type ensures that we maintain high precision during summation, which is crucial for accurate results.
- **Calculating Averages**: The averages are computed by dividing the sum of coordinates by the number of battle-ships. This is done using the `Decimal` type to preserve precision.
- **Rounding**: The `quantize` method with `ROUND_HALF_UP` ensures that the result is rounded correctly to two decimal places, handling cases where the third decimal digit is exactly 5.
- **Output Formatting**: The results are formatted to two decimal places and printed in the specified format with a space after the comma.

This approach ensures that the solution is both accurate and efficient, handling large inputs and maintaining precision throughout the calculations.
