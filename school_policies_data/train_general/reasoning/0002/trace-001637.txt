To solve this problem, we need to determine if an array can be sorted into non-decreasing order using a specific swap operation. The swap operation allows swapping two elements if their greatest common divisor (GCD) is equal to the minimum element of the array.

### Approach
1. **Identify the Minimum Element**: The minimum element in the array (let's call it `m`) is crucial because the swap operation's validity depends on elements having a GCD equal to `m`.
2. **Check Divisibility by Minimum**: Elements that are not divisible by `m` cannot be swapped with any other elements. Therefore, they must already be in their correct positions in the sorted array.
3. **Generate Sorted Array**: Create a sorted version of the array.
4. **Validate Positions**: For each element in the original array:
   - If the element is not divisible by `m`, it must be in the same position in the sorted array.
   - If the element is divisible by `m`, the corresponding element in the sorted array must also be divisible by `m` to ensure it can be moved to that position through valid swaps.

### Solution Code
```python
import sys

def can_sort():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        a = list(map(int, sys.stdin.readline().split()))
        m = min(a)
        sorted_a = sorted(a)
        possible = True
        for i in range(n):
            if a[i] % m != 0:
                if sorted_a[i] != a[i]:
                    possible = False
                    break
            else:
                if sorted_a[i] % m != 0:
                    possible = False
                    break
        print("YES" if possible else "NO")

can_sort()
```

### Explanation
1. **Reading Input**: The function reads multiple test cases. For each test case, it reads the array and its length.
2. **Finding Minimum Element**: The minimum element `m` is determined to check the validity of swaps.
3. **Sorting the Array**: The array is sorted to compare against the original array.
4. **Checking Validity**:
   - For each element in the original array, if it is not divisible by `m`, its position in the sorted array must match its original position.
   - For elements divisible by `m`, their corresponding elements in the sorted array must also be divisible by `m` to ensure they can be rearranged through valid swaps.
5. **Output Result**: Based on the checks, the result for each test case is printed as "YES" or "NO".

This approach ensures that we efficiently determine the possibility of sorting the array using the given constraints, adhering to the problem's requirements. The time complexity is dominated by sorting, making it O(n log n) per test case, which is efficient given the problem constraints.
