The goal is to minimize the total cost by strategically using the ticket on the most expensive consecutive edges.

### Approach
1. **Graph Representation**: Represent the bus routes as an undirected graph using an adjacency list.
2. **Dijkstra's Algorithm with State Tracking**: Use a modified Dijkstra's algorithm where each state is represented by the current node, whether the ticket has been used, and the cost of the previous edge (if applicable).
3. **State Transitions**: For each node, track the minimum cost under different states:
   - **State 0**: Ticket not used, no previous edge cost tracked.
   - **State 1**: Ticket not used, previous edge cost tracked.
   - **State 2**: Ticket used.
4. **Priority Queue**: Use a priority queue to explore the least costly paths first, updating the minimum costs for each state as we process each node.
