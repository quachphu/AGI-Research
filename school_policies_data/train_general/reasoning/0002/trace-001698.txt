To solve this problem, we need to determine how many soldiers Robb Stark sent to Joffrey Baratheon's party by checking the secret codes provided by attendees. The valid codes are unique, so any duplicates in the input indicate the presence of soldiers.

### Approach
1. **Input Handling**: Read all input data at once for efficiency, especially given the constraints.
2. **Frequency Counting**: Use a counter to track the frequency of each secret code.
3. **Soldier Calculation**: For each code, if it appears more than once, the number of soldiers contributed by that code is its count minus one (since the original invitation is valid).

### Solution Code
```python
import sys
from collections import Counter

def main():
    data = list(map(int, sys.stdin.read().split()))
    ptr = 0
    T = data[ptr]
    ptr += 1
    for _ in range(T):
        N = data[ptr]
        ptr += 1
        codes = data[ptr:ptr + N]
        ptr += N
        cnt = Counter(codes)
        soldiers = 0
        for v in cnt.values():
            soldiers += max(0, v - 1)
        print(soldiers)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and converted into a list of integers for efficient processing.
2. **Processing Each Test Case**: For each test case, we read the number of attendees and their secret codes.
3. **Counting Frequencies**: Using the `Counter` from the `collections` module, we count how many times each secret code appears.
4. **Calculating Soldiers**: For each code, if its frequency is greater than 1, we add the excess count (frequency - 1) to the total number of soldiers. This is because each duplicate entry beyond the first one is considered a soldier.

This approach ensures that we efficiently handle the input and compute the result in linear time relative to the number of attendees, making it suitable for large inputs as specified in the problem constraints.
