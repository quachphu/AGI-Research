To solve this problem, we need to determine pairs of friends based on their message exchanges in a social network. The key criterion is that two users are friends if one user sends a message to another and the recipient responds within a specific time frame.

### Approach
1. **Parse Input**: Read the number of messages and the time window `d`, followed by the messages themselves.
2. **Track Friends**: Use a set to store unique friend pairs, ensuring each pair is stored in a sorted manner to avoid duplicates.
3. **Check Replies**: For each message, check subsequent messages to see if there is a valid reply within the time window `d`. A valid reply is defined as a message from the recipient to the sender within the time window.

### Solution Code
```python
n, d = map(int, input().split())
messages = []
for _ in range(n):
    parts = input().split()
    a, b, t = parts[0], parts[1], int(parts[2])
    messages.append((a, b, t))

friends = set()

for i in range(n):
    a_sender, b_receiver, t1 = messages[i]
    max_time = t1 + d
    j = i + 1
    while j < n and messages[j][2] <= max_time:
        t_j = messages[j][2]
        if t_j > t1:
            sender_j, receiver_j, _ = messages[j]
            if sender_j == b_receiver and receiver_j == a_sender:
                pair = tuple(sorted((a_sender, b_receiver)))
                friends.add(pair)
        j += 1

print(len(friends))
for pair in sorted(friends):
    print(pair[0], pair[1])
```

### Explanation
1. **Reading Input**: The input is parsed into a list of messages, each represented by a tuple containing the sender, receiver, and timestamp.
2. **Finding Friends**: For each message, we check subsequent messages to see if any of them are valid replies. A valid reply is determined if:
   - The subsequent message is sent from the receiver of the original message to the sender of the original message.
   - The timestamp of the reply is within the allowed time window `d` after the original message.
3. **Storing Pairs**: Valid friend pairs are stored in a set to ensure uniqueness. Each pair is stored in sorted order to handle bidirectional friendships (e.g., both A-B and B-A are stored as A-B).

This approach efficiently checks each message against subsequent messages within the time window, ensuring all valid friend pairs are identified and stored uniquely. The use of a set guarantees that each pair is counted exactly once, regardless of the order in which they are detected.
