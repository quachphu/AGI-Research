To solve this problem, we need to calculate the total price of a ramen bowl based on the toppings chosen by a customer. The price starts at 700 yen and increases by 100 yen for each selected topping. The input is a string of three characters where each character indicates the presence ('o') or absence ('x') of a specific topping.

### Approach
1. **Input Reading**: Read the input string which represents the toppings.
2. **Count Toppings**: Determine how many toppings are selected by counting the number of 'o' characters in the input string.
3. **Calculate Total Price**: Compute the total price by adding 700 yen (base price) to 100 yen multiplied by the number of toppings.
4. **Output the Result**: Print the computed total price.

### Solution Code
```python
def main():
    s = input().strip()
    count = s.count('o')
    print(700 + 100 * count)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input string is read using `input().strip()` to ensure there are no leading or trailing whitespace characters.
2. **Counting Toppings**: The `count` method is used on the string to count occurrences of 'o', which indicates a selected topping.
3. **Calculating Price**: The base price of 700 yen is augmented by 100 yen for each 'o' found in the input string. This is computed using the formula `700 + 100 * count`.
4. **Output**: The total price is printed, which is the result of the calculation.

This approach efficiently processes the input and computes the result in linear time, O(3), which is optimal given the fixed length of the input string. The solution is straightforward and leverages Python's built-in string methods for simplicity and readability.
