To solve this problem, we need to determine the day with the least congestion in a year based on the influence of consecutive holidays. Each holiday period contributes to the congestion of days either within the holiday or days close to it. The goal is to find the minimum congestion level across all days in the year.

### Approach
1. **Input Parsing**: Read the number of holidays and their respective details (start date, duration, and influence value).
2. **Holiday Range Calculation**: Convert each holiday's start date into a day number (1 to 360) and compute the end day considering the circular nature of the year.
3. **Congestion Calculation**: For each day in the year, determine the congestion by evaluating the maximum influence from all holidays. The influence from a holiday is either its direct impact if the day is within the holiday period or a decayed value based on proximity to the holiday's start or end.
4. **Determine Minimum Congestion**: Iterate through all days to find the minimum congestion level.

### Solution Code
```python
n = int(input())
holidays = []

for _ in range(n):
    m, d, v, s = map(int, input().split())
    start = (m - 1) * 30 + d
    end = (start + v - 2) % 360 + 1
    holidays.append((start, end, s))

min_congestion = float('inf')

for x in range(1, 361):
    max_inf = 0
    for (start, end, s) in holidays:
        if (start <= end and start <= x <= end) or (start > end and (x >= start or x <= end)):
            influence = s
        else:
            d1 = (start - x) % 360
            d2 = (x - end) % 360
            min_dist = min(d1, d2)
            influence = max(0, s - min_dist)
        if influence > max_inf:
            max_inf = influence
    if max_inf < min_congestion:
        min_congestion = max_inf

print(min_congestion)
```

### Explanation
1. **Input Parsing**: The input is read and parsed into the number of holidays and their details. Each holiday's start date is converted into a day number (1-360).
2. **Holiday Range Calculation**: For each holiday, the start and end days are calculated considering the circular nature of the year. This ensures holidays wrapping around the end of the year are correctly handled.
3. **Congestion Calculation**: For each day in the year, the influence from each holiday is computed. If the day falls within the holiday period, the influence is the holiday's direct value. Otherwise, the influence decays based on the minimum distance to the start or end of the holiday.
4. **Finding Minimum Congestion**: The maximum influence from all holidays is determined for each day, and the minimum of these maximum values across all days is found and printed.

This approach efficiently handles the constraints and ensures accurate calculation of congestion levels using modular arithmetic to manage the circular nature of the year.
