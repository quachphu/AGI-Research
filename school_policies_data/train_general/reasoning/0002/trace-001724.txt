To solve this problem, we need to determine the minimal possible integer Ania can obtain by changing at most `k` digits of the given number `S`, while ensuring that the result does not have leading zeros (unless it's a single-digit zero).

### Approach
1. **Handle the First Digit Separately**:
   - If the number has only one digit (`n == 1`), we can change it to `0` if `k >= 1`.
   - For numbers with more than one digit (`n > 1`), the first digit must be non-zero. We change it to `1` if possible (i.e., if the original digit is greater than `1` and `k` allows it).

2. **Process Remaining Digits**:
   - For each subsequent digit (from the second to the last), change it to `0` if possible, using the remaining allowed changes (`k`). This ensures the smallest possible value by reducing the most significant digits first.

### Solution Code
```python
n, k = map(int, input().split())
s = list(input().strip())

if n == 1:
    if k >= 1:
        s[0] = '0'
else:
    # Process first digit
    if s[0] != '1' and k > 0:
        s[0] = '1'
        k -= 1
    # Process remaining digits
    for i in range(1, n):
        if k == 0:
            break
        if s[i] != '0':
            s[i] = '0'
            k -= 1

print(''.join(s))
```

### Explanation
1. **Reading Input**: The input consists of two integers `n` (number of digits) and `k` (allowed changes), followed by the number `S` as a string.
2. **Single Digit Case**: If `n` is 1, we can directly change the digit to `0` if we have at least one change allowed.
3. **First Digit Handling**: For multi-digit numbers, change the first digit to `1` if it's not already `1` and we have changes left.
4. **Subsequent Digits**: Change each subsequent digit to `0` as long as changes are allowed. This ensures the smallest possible value by leveraging the higher significance of leftmost digits.

This approach efficiently processes each digit in a left-to-right manner, ensuring minimal value by prioritizing changes to the most significant digits first.
