To solve this problem, we need to determine which propositions have the same truth value based on given implications. Propositions are considered equivalent if they mutually imply each other, forming strongly connected components (SCCs) in a directed graph. Each SCC represents a set of propositions with the same truth value.

### Approach
1. **Graph Construction**: Represent each implication as a directed edge in a graph. For each implication "a if b", add an edge from node `b` to node `a`.
2. **Kosaraju's Algorithm**: Use this algorithm to find SCCs in the graph. This involves two main steps:
   - **First DFS Pass**: Perform a DFS on the original graph to determine the finishing order of nodes.
   - **Second DFS Pass**: Process nodes in reverse finishing order using the transposed graph (all edges reversed) to identify SCCs.
3. **Output Preparation**: For each node, output the members of its SCC in ascending order.

import sys

def main():
    sys.setrecursionlimit(1 << 25)
    N, M = map(int, sys.stdin.readline().split())
    original_graph = [[] for _ in range(N + 1)]
    reversed_graph = [[] for _ in range(N + 1)]
    
    for _ in range(M):
        a, b = map(int, sys.stdin.readline().split())
        original_graph[b].append(a)
        reversed_graph[a].append(b)
    
    # First pass to determine the order
    visited = [False] * (N + 1)
    order = []
    for node in range(1, N + 1):
        if not visited[node]:
            stack = [(node, False)]
            while stack:
                v, processed = stack.pop()
                if processed:
                    order.append(v)
                    continue
                if visited[v]:
                    continue
                visited[v] = True
                stack.append((v, True))
                for neighbor in original_graph[v]:
                    if not visited[neighbor]:
                        stack.append((neighbor, False))
    # Reverse the order for the second pass
    order.reverse()
    
    # Second pass to find components in reversed graph
    visited = [False] * (N + 1)
    components = []
    for node in order:
        if not visited[node]:
            stack = [node]
            visited[node] = True
            component = []
            while stack:
                v = stack.pop()
                component.append(v)
                for neighbor in reversed_graph[v]:
                    if not visited[neighbor]:
                        visited[neighbor] = True
                        stack.append(neighbor)
            components.append(component)
    
    # Create a mapping from node to its sorted component
    component_map = {}
    for comp in components:
        sorted_comp = sorted(comp)
        for node in comp:
            component_map[node] = sorted_comp
    
    # Output each node's component
    for i in range(1, N + 1):
        print(' '.join(map(str, component_map[i])))

if __name__ == "__main__":
    main()
