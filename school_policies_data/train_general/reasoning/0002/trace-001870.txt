To solve this problem, we need to count the number of rectangles formed by four segments: two horizontal and two vertical. The horizontal segments must be ordered by their indices, and each horizontal segment must intersect both vertical segments, and vice versa.

### Approach
1. **Segments Separation**: Separate the given segments into horizontal and vertical segments based on their coordinates.
2. **Sort Vertical Segments**: Sort the vertical segments by their x-coordinate to facilitate efficient range queries.
3. **Iterate Over Horizontal Pairs**: For each pair of horizontal segments (h1, h2), compute their overlapping x-interval and the y-interval they span.
4. **Check Valid Vertical Segments**: For each valid x-interval, find vertical segments that lie within this interval and cover the y-interval spanned by the horizontal segments.
5. **Count Valid Pairs**: For each valid pair of vertical segments found, count how many such pairs exist and compute the number of rectangles they form using combinatorial counting.

### Solution Code
```python
import bisect

n = int(input())

horizontals = []
verticals = []

for idx in range(n):
    x1, y1, x2, y2 = map(int, input().split())
    if x1 == x2:
        # Vertical segment
        x = x1
        y_start = min(y1, y2)
        y_end = max(y1, y2)
        verticals.append((x, y_start, y_end))
    else:
        # Horizontal segment
        y = y1  # since y1 == y2 for horizontal
        x_start = min(x1, x2)
        x_end = max(x1, x2)
        horizontals.append((x_start, x_end, y, idx))  # store with original index

# Sort verticals by x-coordinate
verticals_sorted = sorted(verticals, key=lambda v: v[0])
xs = [v[0] for v in verticals_sorted]

count = 0

# Iterate over all pairs of horizontal segments (h1, h2) where h1's index < h2's index
for i in range(len(horizontals)):
    h1 = horizontals[i]
    for j in range(i + 1, len(horizontals)):
        h2 = horizontals[j]
        # Get the original indices to ensure h1's index is less than h2's
        if h1[3] > h2[3]:
            h1, h2 = h2, h1
        
        # Compute overlapping x interval
        x_low = max(h1[0], h2[0])
        x_high = min(h1[1], h2[1])
        if x_low > x_high:
            continue  # no overlap
        
        # Compute y_min and y_max
        y_min = min(h1[2], h2[2])
        y_max = max(h1[2], h2[2])
        
        # Find all vertical segments in x_low <= x <= x_high
        left = bisect.bisect_left(xs, x_low)
        right = bisect.bisect_right(xs, x_high)
        vertical_subset = verticals_sorted[left:right]
        
        # Count how many of these vertical segments cover y_min and y_max
        k = 0
        for v in vertical_subset:
            if v[1] <= y_min and v[2] >= y_max:
                k += 1
        
        # Add the number of ways to choose two vertical segments from k
        count += k * (k - 1) // 2

print(count)
```
