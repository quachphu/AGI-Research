To solve this problem, we need to determine the number of full years it will take for Limak's weight to exceed Bob's weight, given that Limak's weight triples each year while Bob's weight doubles each year.

### Approach
1. **Initialization**: Read the initial weights of Limak and Bob.
2. **Simulation Loop**: Use a loop to simulate each year where:
   - Limak's weight is tripled.
   - Bob's weight is doubled.
   - Increment the year counter each time the loop runs.
3. **Termination Condition**: The loop continues until Limak's weight becomes strictly greater than Bob's weight.
4. **Output**: Print the number of years once the loop terminates.

The loop ensures that we keep updating the weights year by year until the condition is met. This approach efficiently simulates the yearly growth of both weights and checks the termination condition each iteration.

### Solution Code
```python
a, b = map(int, input().split())
years = 0
while a <= b:
    a *= 3
    b *= 2
    years += 1
print(years)
```

### Explanation
- **Reading Input**: The input consists of two integers which are read and stored in variables `a` (Limak's initial weight) and `b` (Bob's initial weight).
- **Yearly Simulation**: Each iteration of the loop represents a year. Within the loop:
  - Limak's weight is tripled.
  - Bob's weight is doubled.
  - The year counter is incremented.
- **Termination Check**: The loop continues as long as Limak's weight is less than or equal to Bob's weight. Once Limak's weight exceeds Bob's, the loop exits and the number of years is printed.

This approach efficiently computes the result by iterating exactly the number of times needed, ensuring optimal performance given the problem constraints.
