To solve this problem, we need to determine the optimal type of box and the number of boxes Dima should buy to transport the maximum number of hamsters. The boxes must be of the same type, and each box must be completely full. The goal is to maximize the number of hamsters transported, and if there are multiple solutions, we can choose any of them.

### Approach
1. **Understand the Problem**: We need to find the box type that allows transporting the maximum number of hamsters. Each box type has a specific capacity, and we can only use boxes of one type.
2. **Edge Case Handling**: If there are no hamsters (N=0), the answer is straightforward as no boxes are needed, so we can choose the first box type.
3. **Iterate Through Box Types**: For each box type, calculate the maximum number of hamsters that can be transported using boxes of that type. This is done by dividing the total number of hamsters by the box capacity and then multiplying back by the capacity to ensure the total is a multiple of the capacity.
4. **Track the Best Solution**: Keep track of the maximum number of hamsters transported and the corresponding box type and count. If multiple box types yield the same maximum, choose the one with the smallest index.

### Solution Code
```python
n, k = map(int, input().split())
if n == 0:
    print(1, 0)
else:
    a_list = list(map(int, input().split()))
    max_transported = -1
    best_type = -1
    best_boxes = -1
    for i in range(k):
        a = a_list[i]
        boxes = n // a
        transported = boxes * a
        if transported > max_transported:
            max_transported = transported
            best_type = i + 1
            best_boxes = boxes
        elif transported == max_transported:
            if (i + 1) < best_type:
                best_type = i + 1
                best_boxes = boxes
    print(best_type, best_boxes)
```

### Explanation
1. **Reading Input**: The first line of input contains the number of hamsters (N) and the number of box types (K). The second line contains the capacities of each box type.
2. **Edge Case Handling**: If there are no hamsters (N=0), we immediately output the first box type and 0 boxes since no transportation is needed.
3. **Calculating Maximum Transported Hamsters**: For each box type, compute the number of boxes needed to transport as many hamsters as possible. This is done using integer division and multiplication to ensure each box is full.
4. **Tracking the Best Solution**: We keep track of the maximum number of hamsters that can be transported and update the best box type and count whenever a new maximum is found. In case of ties, the smallest box type index is chosen.

This approach efficiently processes each box type in linear time, ensuring optimal performance even for large input sizes.
