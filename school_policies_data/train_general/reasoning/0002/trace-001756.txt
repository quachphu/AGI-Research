To solve this problem, we need to compute Snuke's power after he exercises N times, where his power is multiplied by the exercise number each time. The result should be given modulo \(10^9 + 7\) due to potential very large values.

### Approach
1. **Problem Analysis**: Snuke's power starts at 1. Each time he exercises, his power is multiplied by the exercise number. This means after N exercises, his power is the product of all integers from 1 to N, which is N factorial (N!).
2. **Modulo Operation**: Since N can be as large as \(10^5\), directly computing N! might result in extremely large numbers. Using modulo \(10^9 + 7\) at each multiplication step ensures we handle large numbers efficiently and avoid overflow.
3. **Iterative Calculation**: Compute the factorial iteratively, applying the modulo operation at each step to keep the intermediate results manageable.

### Solution Code
```python
MOD = 10**9 + 7

n = int(input())
result = 1
for i in range(1, n + 1):
    result = (result * i) % MOD
print(result)
```

### Explanation
1. **Reading Input**: The input is read as an integer N, representing the number of exercises.
2. **Initialization**: Start with a result initialized to 1.
3. **Iterative Multiplication**: Loop through each integer from 1 to N, multiplying the current result by the integer and taking modulo \(10^9 + 7\) at each step. This ensures that the intermediate values never exceed the limits of typical integer storage.
4. **Output Result**: After processing all integers up to N, the result is printed, which is the factorial of N modulo \(10^9 + 7\).

This approach efficiently computes the result in O(N) time complexity, which is optimal for the given constraint \(1 \leq N \leq 10^5\).
