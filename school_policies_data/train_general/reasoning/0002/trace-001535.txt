To solve this problem, we need to repeatedly extend a number by appending digits such that each new number formed is divisible by a given divisor. The challenge is to determine the digits to append in each step to achieve the desired length while maintaining divisibility.

### Approach
1. **Initial Setup**: Read the input values for the initial number `a`, the divisor `b`, and the number of times `n` we need to extend the number.
2. **Check Initial Divisibility**: Compute the remainder of `a` modulo `b`. This helps in determining the first digit to append.
3. **Find the First Valid Digit**: Iterate through digits 0 to 9 to find the smallest digit that, when appended to `a`, makes the resulting number divisible by `b`.
4. **Check Feasibility of Subsequent Digits**: After the first valid digit, each subsequent digit must be such that the new number remains divisible by `b`. Since appending '0' will always maintain divisibility if the previous number was divisible, we can safely append '0' for the remaining steps.

```python
a, b, n = map(int, input().split())
current_rem = a % b
found = False
first_d = -1

for d in range(0, 10):
    if (current_rem * 10 + d) % b == 0:
        first_d = d
        found = True
        break

if not found:
    print(-1)
else:
    result = str(a) + str(first_d) + '0' * (n-1)
    print(result)
```

### Explanation
1. **Initial Divisibility Check**: By computing the remainder of `a` modulo `b`, we determine the initial state of the number. This helps in checking which digit can be appended first to make the number divisible by `b`.
2. **Finding the First Digit**: We iterate through all possible digits (0-9) to find the smallest digit that, when appended, makes the new number divisible by `b`. If no such digit is found, it's impossible to extend the number, and we return -1.
3. **Appending Subsequent Digits**: Once a valid first digit is found, we append '0' for the remaining `n-1` steps. This works because once a number is divisible by `b`, appending '0' keeps it divisible (as multiplying by 10 maintains divisibility and adding 0 doesn't change the remainder).

This approach ensures that we efficiently find a valid solution or determine impossibility, leveraging modular arithmetic to avoid handling excessively large numbers directly.
