To solve this problem, we need to select exactly `x` pictures from an array such that every segment of at least `k` consecutive pictures contains at least one selected picture. The goal is to maximize the sum of the beauty values of the selected pictures. If it's impossible to meet the conditions, we should return `-1`.

### Approach
1. **Dynamic Programming (DP) Setup**: We use a 2D DP array `dp[i][j]` where `dp[i][j]` represents the maximum sum of beauty values when selecting `j` pictures up to the `i`-th position, with the `i`-th picture being the last selected one.

2. **Initialization**: For the first picture selection (`j=1`), we initialize the DP values for the first `k` positions since the first selected picture must lie within the first `k` positions.

3. **DP Transitions**: For each subsequent number of selections (`j` from 2 to `x`), we update the DP values by considering all valid previous positions that are within the last `k` positions from the current position.

4. **Final Check**: After filling the DP table, we check the last `k` positions to ensure the last selected picture covers the end of the array. If no valid configuration is found, return `-1`.

### Solution Code
```python
import sys

def main():
    n, k, x = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    
    # Special case when k=1: all positions must be selected
    if k == 1:
        if x == n:
            print(sum(a))
        else:
            print(-1)
        return
    
    INF = float('-inf')
    dp = [[INF] * (x + 1) for _ in range(n)]
    
    # Initialize j=1
    for i in range(n):
        if i < k:
            dp[i][1] = a[i]
    
    # Fill DP for j from 2 to x
    for j in range(2, x + 1):
        for i in range(n):
            start = max(0, i - k)
            for prev_i in range(start, i):
                if dp[prev_i][j-1] != INF:
                    dp[i][j] = max(dp[i][j], dp[prev_i][j-1] + a[i])
    
    # Check the last k positions for j=x
    max_sum = INF
    last_start = max(0, n - k)
    for i in range(last_start, n):
        if dp[i][x] > max_sum:
            max_sum = dp[i][x]
    
    print(max_sum if max_sum != INF else -1)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Special Case Handling**: If `k=1`, every single picture must be selected. Thus, if `x` is not equal to `n`, it's impossible to meet the conditions, and we return `-1`.

2. **DP Initialization**: The first row of the DP array is initialized for selecting the first picture within the first `k` positions.

3. **DP Transitions**: For each number of selections `j`, we compute the maximum sum by considering all valid previous positions within the allowed range (up to `k` positions back).

4. **Result Extraction**: After processing all possible selections, we check the last `k` positions to ensure the last selected picture covers the end of the array, thus ensuring all segments are covered.

This approach efficiently computes the maximum sum using dynamic programming while adhering to the constraints, ensuring correctness and optimality.
