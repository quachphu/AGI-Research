To solve this problem, we need to determine if given 12 sticks can form a rectangular parallelepiped. A rectangular parallelepiped has 12 edges, which must be divided into three groups of four sticks each, where each group can form one of the three dimensions (length, width, height). The solution involves checking if the given sticks can be grouped into three sets of four sticks each, regardless of their lengths.

### Approach
1. **Count Frequencies**: Count the frequency of each stick length using a frequency dictionary.
2. **Check Divisibility by 4**: Each dimension requires exactly four sticks, so each length's frequency must be a multiple of 4. If any frequency is not a multiple of 4, it's impossible to form the required groups.
3. **Sum of Groups**: Calculate the total number of groups of four sticks each. The sum of these groups must be exactly 3 to form a rectangular parallelepiped.

### Solution Code
```python
import sys
from collections import Counter

def main():
    sticks = list(map(int, sys.stdin.readline().split()))
    counts = Counter(sticks)
    
    for c in counts.values():
        if c % 4 != 0:
            print("no")
            return
    
    total_groups = sum(c // 4 for c in counts.values())
    print("yes" if total_groups == 3 else "no")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read as a list of integers representing the lengths of the 12 sticks.
2. **Frequency Counting**: Using the `Counter` from the `collections` module, we count how many times each length appears.
3. **Check Divisibility**: For each length, check if its frequency is divisible by 4. If any frequency is not, print "no" and exit immediately.
4. **Calculate Groups**: Sum the number of groups of four sticks each. If this sum is exactly 3, print "yes"; otherwise, print "no".

This approach ensures that we efficiently determine if the sticks can form a rectangular parallelepiped by leveraging frequency counts and divisibility checks.
