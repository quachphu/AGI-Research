To solve this problem, Raju needs to determine if he can obtain a chocolate of exact weight X using either one chocolate or the sum of two different chocolates from a given list. The solution involves checking each test case against the possible weights and sums of weights in the list.

### Approach
1. **Read Input:** Read the number of chocolates and their weights, followed by the number of test cases and each test case value.
2. **Set of Weights:** Convert the list of chocolate weights into a set for O(1) lookups.
3. **Precompute Sums:** Generate all possible sums of two distinct weights from the set and store these sums in another set.
4. **Check Test Cases:** For each test case, check if the value exists in the set of weights or in the set of precomputed sums. If it does, output "I Like You"; otherwise, output "I Hate You".

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    N = int(input[ptr])
    ptr += 1
    chocolates = list(map(int, input[ptr:ptr + N]))
    ptr += N
    S = set(chocolates)
    # Compute all possible sums of two distinct elements in S
    sum_set = set()
    elements = list(S)
    for i in range(len(elements)):
        for j in range(i + 1, len(elements)):
            sum_val = elements[i] + elements[j]
            sum_set.add(sum_val)
    M = int(input[ptr])
    ptr += 1
    for _ in range(M):
        X = int(input[ptr])
        ptr += 1
        if X in S or X in sum_set:
            print("I Like You")
        else:
            print("I Hate You")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The input is read all at once and split into a list for efficient processing. We use a pointer to traverse through the input list.
2. **Set of Weights:** Converting the list of weights into a set allows for O(1) membership checks, which is crucial for efficiency.
3. **Precomputing Sums:** By iterating over all pairs of distinct elements in the set, we compute all possible sums and store them in another set. This allows us to quickly check if a test case value can be formed by summing two different weights.
4. **Checking Test Cases:** For each test case, we check if the value is directly present in the weights set or if it can be formed by summing two different weights (using the precomputed sums set). This results in an efficient O(1) check per test case after the initial preprocessing.

This approach ensures that we efficiently handle each test case by leveraging set operations and precomputed sums, making the solution both optimal and easy to understand.
