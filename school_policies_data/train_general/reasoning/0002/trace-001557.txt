To solve this problem, we need to determine if the sum of the square roots of two integers \(a\) and \(b\) is less than the square root of another integer \(c\). Direct computation of square roots might introduce floating-point inaccuracies, so we use algebraic manipulation to avoid them.

### Approach
1. **Mathematical Insight**: The inequality \(\sqrt{a} + \sqrt{b} < \sqrt{c}\) can be transformed using algebraic manipulation to avoid direct computation of square roots:
   - Square both sides to get \(a + b + 2\sqrt{ab} < c\).
   - Rearrange to isolate the square root term: \(2\sqrt{ab} < c - a - b\).
   - Square both sides again to eliminate the square root: \(4ab < (c - a - b)^2\).

2. **Conditions**:
   - If \(a + b \geq c\), the answer is immediately "No" because the sum of non-negative terms \(a\) and \(b\) being greater than or equal to \(c\) makes the original inequality impossible.
   - Otherwise, check if \(4ab < (c - a - b)^2\). If true, print "Yes"; otherwise, print "No".

### Solution Code
```python
a, b, c = map(int, input().split())
sum_ab = a + b
if sum_ab >= c:
    print("No")
else:
    residual = c - sum_ab
    if 4 * a * b < residual ** 2:
        print("Yes")
    else:
        print("No")
```

### Explanation
- **Reading Input**: The input values \(a\), \(b\), and \(c\) are read and converted to integers.
- **Initial Check**: Compute the sum \(a + b\). If this sum is greater than or equal to \(c\), print "No" because the inequality cannot hold.
- **Residual Calculation**: If \(a + b\) is less than \(c\), compute the residual \(c - (a + b)\).
- **Final Check**: Compare \(4ab\) with the square of the residual. If \(4ab\) is less, print "Yes"; otherwise, print "No".

This approach efficiently avoids floating-point operations and ensures accuracy using integer arithmetic, handling all edge cases within the problem constraints.
