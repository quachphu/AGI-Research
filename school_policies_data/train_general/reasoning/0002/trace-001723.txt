To solve this problem, we need to determine the winner of the game "Put a Knight!" on an n x n chessboard where Petya and Gena take turns placing knights such that no two knights can attack each other. The solution relies on understanding the optimal strategy for placing knights and how the board size affects the outcome.

### Approach
The key insight is that the maximum number of non-attacking knights that can be placed on an n x n board follows a specific pattern based on the parity of n:
- For even-sized boards (n is even), the maximum number of non-attacking knights is even. In such cases, Gena (the second player) will win because the last move will be made by the second player.
- For odd-sized boards (n is odd), the maximum number of non-attacking knights is odd. Here, Petya (the first player) will win because the last move will be made by the first player.

### Solution Code
```python
def determine_winner():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    for n in input[1:T+1]:
        ni = int(n)
        print(1 if ni % 2 == 0 else 0)

determine_winner()
```

### Explanation
The solution reads the input values and checks each board size. For each board size `ni`:
- If `ni` is even, the output is `1` indicating Gena's win.
- If `ni` is odd, the output is `0` indicating Petya's win.

This approach efficiently determines the winner by leveraging the parity of the board size, ensuring an optimal solution with constant time complexity for each test case.
