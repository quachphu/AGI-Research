To solve this problem, we need to determine the longest consecutive sequence of books that can be included in an exposition such that the difference between the tallest and shortest book in the sequence does not exceed a given value \( k \). Additionally, we need to find all such intervals where this maximum length is achieved.

### Approach
1. **Sliding Window Technique**: We use a sliding window approach to efficiently find the longest valid subarray. This technique allows us to dynamically adjust the window size while maintaining the maximum and minimum values within the window using deques.
2. **Deques for Max and Min Values**: We maintain two deques to track the indices of the maximum and minimum values within the current window. This helps in efficiently updating the max and min values as the window slides.
3. **Adjusting the Window**: For each new element added to the window, we adjust the left boundary to ensure the difference between the maximum and minimum values does not exceed \( k \). This involves removing elements from the deques that are out of the current window bounds.
4. **Tracking Intervals**: As we adjust the window, we keep track of the maximum length found and all intervals that achieve this length.

### Solution Code
```python
from collections import deque

def main():
    import sys
    input = sys.stdin.read().split()
    n, k = int(input[0]), int(input[1])
    h = list(map(int, input[2:2+n]))

    max_len = 0
    intervals = []
    max_deque = deque()
    min_deque = deque()
    left = 0

    for right in range(n):
        # Update max_deque
        while max_deque and h[right] >= h[max_deque[-1]]:
            max_deque.pop()
        max_deque.append(right)

        # Update min_deque
        while min_deque and h[right] <= h[min_deque[-1]]:
            min_deque.pop()
        min_deque.append(right)

        # Adjust left to ensure the window is valid
        while True:
            # Remove elements out of the window
            while max_deque and max_deque[0] < left:
                max_deque.popleft()
            while min_deque and min_deque[0] < left:
                min_deque.popleft()

            if not max_deque or not min_deque:
                break

            current_max = h[max_deque[0]]
            current_min = h[min_deque[0]]
            if current_max - current_min > k:
                left += 1
            else:
                break

        current_len = right - left + 1
        if current_len > max_len:
            max_len = current_len
            intervals = [(left, right)]
        elif current_len == max_len:
            intervals.append((left, right))

    # Filter intervals to those of max_len and convert to 1-based indexing
    filtered = []
    for start, end in intervals:
        if end - start + 1 == max_len:
            filtered.append((start + 1, end + 1))

    print(max_len, len(filtered))
    for interval in filtered:
        print(interval[0], interval[1])

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of books \( n \), the maximum allowed height difference \( k \), and the list of book heights.
2. **Sliding Window Initialization**: Two deques are initialized to track the indices of the maximum and minimum values in the current window. The left pointer starts at 0.
3. **Updating Deques**: For each new book added to the window (right pointer), the deques are updated to maintain their properties (max deque in descending order, min deque in ascending order).
4. **Adjusting the Window**: The left pointer is adjusted to ensure the window remains valid (max - min ≤ k). This involves removing indices from the deques that are out of bounds.
5. **Tracking Maximum Length**: The length of the current valid window is checked against the maximum length found so far. If it's longer, the intervals list is reset. If it's equal, the interval is added to the list.
6. **Output**: The intervals are converted to 1-based indexing and printed in the required format.
