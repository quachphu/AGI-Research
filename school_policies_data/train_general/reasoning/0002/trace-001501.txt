To solve this problem, we need to find the minimum spanning tree (MST) of a complete undirected graph where each edge's weight is the XOR of the values of its two vertices. Given the constraints, a brute-force approach is infeasible, so we use a more efficient method based on bitwise operations and divide-and-conquer strategy.

### Approach
1. **Sorting**: Start by sorting the array of vertex values. This helps in efficiently splitting the array based on bit values.
2. **Bitwise Processing**: Process each bit from the highest (29th) to the lowest (0th). For each bit, split the current groups of vertices into those with the bit set and those without.
3. **Finding Minimum XOR**: For each split, compute the minimum XOR value between elements of the two resulting groups. This is done by checking a few elements around the split point to ensure efficiency.
4. **Union-Find Groups**: Maintain groups of vertices and split them recursively based on each bit. The sum of the minimum XOR values from each valid split gives the MST weight.

### Solution Code
```python
import sys

def main():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))
    a.sort()
    groups = [(0, n - 1)]
    total = 0

    for bit in reversed(range(30)):  # from 29 to 0
        new_groups = []
        current_total = 0
        for (start, end) in groups:
            if start >= end:
                new_groups.append((start, end))
                continue

            # Find split position
            mask = 1 << bit
            left, right = start, end
            split_pos = end + 1
            while left <= right:
                mid = (left + right) // 2
                if a[mid] & mask:
                    split_pos = mid
                    right = mid - 1
                else:
                    left = mid + 1

            if split_pos <= start or split_pos > end:
                new_groups.append((start, end))
                continue

            left_start, left_end = start, split_pos - 1
            right_start, right_end = split_pos, end

            # Find minimal XOR between left and right groups
            min_xor = float('inf')
            # Check up to 5 elements before split in left and after in right
            for i in range(max(left_start, left_end - 5), left_end + 1):
                for j in range(right_start, min(right_end, right_start + 5) + 1):
                    if i < left_start or j > right_end:
                        continue
                    current = a[i] ^ a[j]
                    if current < min_xor:
                        min_xor = current

            current_total += min_xor
            new_groups.append((left_start, left_end))
            new_groups.append((right_start, right_end))

        total += current_total
        groups = new_groups

    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Sorting**: The array is sorted to facilitate efficient splitting based on bit values.
2. **Bitwise Processing**: For each bit from 29 down to 0, the array is split into groups where the current bit is set and where it is not. This helps in isolating higher bits first, ensuring minimal weight edges are considered first.
3. **Finding Minimum XOR**: For each split, we check a small window around the split point (up to 5 elements on each side) to find the minimum XOR efficiently. This avoids checking all possible pairs, making the solution feasible for large inputs.
4. **Union-Find Groups**: Groups are maintained and processed recursively. Each valid split contributes the minimum XOR edge to the MST, ensuring the total weight is minimized.

This approach efficiently handles the constraints and leverages bitwise operations to reduce the complexity, making it suitable for large input sizes up to 200,000 vertices.
