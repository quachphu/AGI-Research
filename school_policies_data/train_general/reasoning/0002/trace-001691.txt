To solve this problem, we need to determine if it's possible for Drazil to travel from his home at (0, 0) to Varda's home at (a, b) in exactly s steps. Each step can be in one of the four cardinal directions (up, down, left, right).

### Approach
1. **Manhattan Distance**: The minimum number of steps required to reach from (0, 0) to (a, b) is given by the Manhattan distance, which is the sum of the absolute values of the coordinates: \( d = |a| + |b| \).
2. **Check Feasibility**: 
   - If the given number of steps \( s \) is less than the Manhattan distance \( d \), it's impossible to reach the destination in \( s \) steps.
   - If \( s \) is greater than or equal to \( d \), the difference \( s - d \) must be even. This is because any extra steps beyond the minimum must come in pairs (e.g., moving left then right, or up then down) to ensure the final position remains (a, b).

### Solution Code
```python
a, b, s = map(int, input().split())
d = abs(a) + abs(b)
if s < d:
    print("No")
elif (s - d) % 2 == 0:
    print("Yes")
else:
    print("No")
```

### Explanation
1. **Reading Input**: The input consists of three integers a, b, and s.
2. **Calculate Manhattan Distance**: Compute the Manhattan distance \( d \) as \( |a| + |b| \).
3. **Check Conditions**:
   - If \( s \) is less than \( d \), output "No" because it's impossible to reach the destination in fewer steps than the Manhattan distance.
   - If \( s \) is greater than or equal to \( d \), check if the difference \( s - d \) is even. If it is, output "Yes", otherwise output "No".

This approach efficiently determines the feasibility of reaching the destination in exactly s steps using basic arithmetic checks, ensuring optimal performance even for large input values.
