To solve this problem, we need to simulate the riffle shuffle operation multiple times on a deck of cards and determine the top card after all shuffles. The riffle shuffle involves splitting the deck into two halves, then repeatedly taking a specified number of cards from each half to form a new deck. 

### Approach
1. **Input Reading**: Read the number of cards (n) and the number of riffle operations (r) for each test case.
2. **Deck Initialization**: Start with a deck of cards numbered from 0 to n-1.
3. **Riffle Shuffle Simulation**: For each riffle operation:
   - **Split the Deck**: Divide the current deck into two halves, where the top half (A) has one more card if n is odd.
   - **Form New Deck (C)**: Repeatedly take a specified number of cards (c) from the bottom of each half (A and B) and append them to the new deck (C) until both halves are empty.
4. **Update Deck**: After each shuffle, update the deck to be the newly formed deck (C).
5. **Determine Top Card**: After all shuffles, the top card is the last element of the deck.

### Solution Code
```python
import sys

def main():
    while True:
        line = sys.stdin.readline()
        if not line:
            break
        n, r = map(int, line.strip().split())
        c_list = list(map(int, sys.stdin.readline().strip().split()))
        deck = list(range(n))
        for c in c_list:
            split_idx = len(deck) // 2
            A = deck[split_idx:]
            B = deck[:split_idx]
            C = []
            while A or B:
                take_a = A[:c]
                A = A[c:]
                take_b = B[:c]
                B = B[c:]
                C.extend(take_a)
                C.extend(take_b)
            deck = C
        print(deck[-1] if n > 0 else 0)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read line by line. Each test case starts with two integers (n and r), followed by r integers representing the shuffle parameters.
2. **Deck Initialization**: The initial deck is created using `list(range(n))`, which generates numbers from 0 to n-1.
3. **Splitting the Deck**: The deck is split into two halves (A and B). The top half (A) contains the latter part of the current deck.
4. **Forming the New Deck**: For each shuffle parameter (c), the algorithm repeatedly takes up to c cards from the bottom of each half (A and B) and appends them to the new deck (C). This process continues until both halves are empty.
5. **Updating the Deck**: After each shuffle, the current deck is updated to the new deck (C).
6. **Output the Result**: After all shuffles, the top card (last element of the deck) is printed.
