To solve this problem, we need to determine the minimum number of operations required to make all elements of an array equal, given the option to change one element to any value beforehand. The operations allowed are either increasing or decreasing all elements of a suffix of the array by 1. 

### Approach
1. **Original Sum Calculation**: Compute the initial number of operations required without any element change. This is done by summing the absolute differences between consecutive elements.
2. **Maximize Reduction**: Determine the maximum reduction in the number of operations by changing one element. This involves checking each element and calculating the potential reduction in operations if that element is adjusted optimally.
3. **Adjust for Edge Cases**: Handle the first and last elements separately, as they only affect one adjacent difference each. For other elements, consider the effect of changing the element on both its left and right neighbors.

### Solution Code
```python
import sys

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        a = list(map(int, sys.stdin.readline().split()))
        if n == 1:
            print(0)
            continue
        # Compute initial sum
        initial_sum = 0
        for i in range(n-1):
            initial_sum += abs(a[i] - a[i+1])
        # Find maximum possible reduction
        max_reduction = 0
        for i in range(n):
            if i == 0:
                current = abs(a[0] - a[1])
            elif i == n-1:
                current = abs(a[i-1] - a[i])
            else:
                original = abs(a[i] - a[i-1]) + abs(a[i] - a[i+1])
                new_contribution = abs(a[i-1] - a[i+1])
                current = original - new_contribution
            if current > max_reduction:
                max_reduction = current
        print(initial_sum - max_reduction)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using `sys.stdin` for efficiency, especially given the constraints.
2. **Initial Sum Calculation**: The initial number of operations required is calculated by summing the absolute differences between each consecutive pair of elements in the array.
3. **Max Reduction Calculation**: For each element in the array, compute the potential reduction in operations if that element is changed:
   - For the first and last elements, the reduction is simply the difference from their immediate neighbor.
   - For middle elements, the reduction is calculated by considering the effect of changing the element on both its left and right neighbors, minimizing the sum of their absolute differences.
4. **Output Result**: The result for each test case is the initial sum minus the maximum reduction found.

This approach ensures that we efficiently compute the minimum number of operations by leveraging the optimal change of a single element, leading to an O(n) solution per test case, which is optimal for the given constraints.
