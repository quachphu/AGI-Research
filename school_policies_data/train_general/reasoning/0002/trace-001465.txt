To solve this problem, we need to separate the creatures into zombies and vampires based on their power values (even for zombies and odd for vampires), sort each group, compute their total power, and then format the output as specified.

### Approach
1. **Input Reading**: Read the number of creatures and their respective power values.
2. **Separation**: Divide the power values into two lists: one for even numbers (zombies) and one for odd numbers (vampires).
3. **Sorting**: Sort both lists in ascending order.
4. **Sum Calculation**: Compute the sum of the power values for both groups.
5. **Output Formatting**: Combine the sorted lists with their respective sums and print the result in the required format.

### Solution Code
```python
n = int(input())
nums = list(map(int, input().split()))
evens = []
odds = []
for num in nums:
    if num % 2 == 0:
        evens.append(num)
    else:
        odds.append(num)

evens_sorted = sorted(evens)
sum_evens = sum(evens_sorted)
evens_part = evens_sorted + [sum_evens]

odds_sorted = sorted(odds)
sum_odds = sum(odds_sorted)
odds_part = odds_sorted + [sum_odds]

result = evens_part + odds_part
print(' '.join(map(str, result)))
```

### Explanation
1. **Reading Input**: The first input line gives the number of creatures, and the second line provides their power values.
2. **Separation**: We iterate through each power value, checking if it is even or odd, and place it into the respective list.
3. **Sorting**: Both lists are sorted to ensure the power values are in ascending order.
4. **Sum Calculation**: The sum of each sorted list is computed and appended to the list.
5. **Output**: The formatted result is created by concatenating the sorted even list with its sum, followed by the sorted odd list with its sum. This combined list is then printed as a space-separated string.

This approach ensures that the problem constraints are met efficiently, with a time complexity dominated by the sorting step, making it O(N log N), which is suitable for the input size constraints.
