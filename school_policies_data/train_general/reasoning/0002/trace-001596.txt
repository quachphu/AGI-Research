To solve this problem, we need to determine the number of water bottles and towels required for a tennis tournament following a specific structure. The key insight is that each match in the tournament eliminates exactly one player, leading to a total of \( n-1 \) matches for \( n \) participants. Each match requires a fixed number of water bottles, and each participant receives a fixed number of towels.

### Approach
1. **Water Bottles Calculation**: Each match involves two participants and a judge. For each match, each participant needs \( b \) bottles, and the judge needs 1 bottle. Thus, each match requires \( 2b + 1 \) bottles. With \( n-1 \) matches in total, the total number of water bottles is \( (n-1) \times (2b + 1) \).

2. **Towels Calculation**: Each participant receives \( p \) towels at the start of the tournament. Therefore, the total number of towels required is \( n \times p \).

### Solution Code
```python
def main():
    n, b, p = map(int, input().split())
    x = (n - 1) * (2 * b + 1)
    y = n * p
    print(x, y)

main()
```

### Explanation
- **Water Bottles**: The formula \( (n - 1) \times (2b + 1) \) computes the total number of water bottles needed by considering each match's requirement and the total number of matches.
- **Towels**: The formula \( n \times p \) calculates the total number of towels by multiplying the number of participants by the number of towels each participant receives.

This approach efficiently computes the required values using straightforward arithmetic operations, ensuring optimal performance even for the upper limits of the input constraints.
