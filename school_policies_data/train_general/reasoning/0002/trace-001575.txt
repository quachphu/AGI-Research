To solve this problem, we need to determine the minimum number of moves required to make two given strings equal by repeatedly deleting the leftmost character from either string. The optimal approach involves finding the longest common suffix between the two strings and using this information to compute the minimum deletions required.

### Approach
1. **Identify the Longest Common Suffix**: The key insight is to find the longest suffix (ending part) that both strings share. This is because any common suffix does not need to be deleted, and thus reduces the number of deletions required.
2. **Calculate Moves**: Once the longest common suffix is found, the minimum moves required is the sum of the lengths of the remaining parts of both strings after removing the common suffix. This is calculated as the difference between the original lengths of the strings and the length of the common suffix.

### Solution Code
```python
s = input().strip()
t = input().strip()

i = len(s) - 1
j = len(t) - 1
count = 0

while i >= 0 and j >= 0 and s[i] == t[j]:
    count += 1
    i -= 1
    j -= 1

result = (len(s) - count) + (len(t) - count)
print(result)
```

### Explanation
1. **Reading Input**: The strings `s` and `t` are read from standard input.
2. **Finding Common Suffix**: Two pointers start from the end of each string and move backwards as long as the characters at these positions are equal. The count of matching characters gives the length of the longest common suffix.
3. **Compute Result**: The result is computed by subtracting the length of the common suffix from both strings' lengths and summing these differences. This gives the total number of deletions required to make both strings equal.

This approach efficiently finds the solution in linear time relative to the length of the shorter string, making it suitable for large input sizes up to 200,000 characters.
