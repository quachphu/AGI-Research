To solve this problem, we need to determine the winner of a game played by Ashish and Vivek on a matrix where they take turns claiming cells. The game ends when a player cannot make a move, and the player who cannot move loses. The solution involves analyzing the matrix to determine the optimal moves and the winner based on the initial configuration.

### Approach
1. **Identify Available Rows and Columns**: 
   - A row is considered available if it contains no claimed cells (all elements are 0).
   - A column is considered available if it contains no claimed cells (all elements are 0).

2. **Determine Maximum Moves**:
   - The maximum number of moves possible is determined by the minimum of the number of available rows and columns. This is because each move blocks a row and a column.

3. **Determine the Winner**:
   - If the maximum number of moves (minimum of available rows and columns) is odd, Ashish (the first player) wins.
   - If the maximum number of moves is even, Vivek (the second player) wins.
   - If there are no available moves, Vivek wins by default as Ashish cannot make a move.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    matrix = []
    for _ in range(n):
        row = list(map(int, input().split()))
        matrix.append(row)
    
    available_rows = 0
    for row in matrix:
        if all(cell == 0 for cell in row):
            available_rows += 1
    
    available_cols = 0
    for j in range(m):
        all_zero = True
        for i in range(n):
            if matrix[i][j] != 0:
                all_zero = False
                break
        if all_zero:
            available_cols += 1
    
    k = min(available_rows, available_cols)
    print("Ashish" if k % 2 == 1 else "Vivek")
```

### Explanation
1. **Reading Input**: The code reads the number of test cases and processes each matrix configuration.
2. **Available Rows Check**: For each row, it checks if all elements are zeros to determine if the row is available.
3. **Available Columns Check**: For each column, it checks if all elements are zeros to determine if the column is available.
4. **Determine Moves**: The minimum of available rows and columns gives the maximum possible moves.
5. **Determine Winner**: Based on the parity of the maximum moves, the winner is determined. If the number of moves is odd, Ashish wins; otherwise, Vivek wins.

This approach efficiently checks the matrix configuration and determines the optimal strategy for both players, ensuring the solution is both correct and optimal.
