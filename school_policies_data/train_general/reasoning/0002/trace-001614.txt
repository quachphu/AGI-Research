### Approach
1. **Problem Analysis**: We need to process two types of queries: adding an edge between two vertices and checking if two vertices are in the same connected component. Given the constraints, an efficient solution is necessary to handle up to 200,000 vertices and queries.
2. **Data Structure Selection**: The DSU (Disjoint Set Union) data structure is chosen for its efficient union and find operations. Path compression and union by size ensure near-constant time complexity for each operation.
3. **Algorithm Design**:
   - **Union Operation**: Combines two sets by linking the root of the smaller tree to the root of the larger tree.
   - **Find Operation**: Uses path compression to flatten the structure of the tree, ensuring future queries are faster.
4. **Complexity Analysis**: Both union and find operations operate in nearly constant time due to path compression and union by size, making the solution efficient enough for the given constraints.

### Solution Code
```python
import sys

def main():
    data = sys.stdin.read().split()
    ptr = 0
    N = int(data[ptr])
    ptr += 1
    Q = int(data[ptr])
    ptr += 1

    parent = list(range(N))
    size = [1] * N

    def find(u):
        while parent[u] != u:
            parent[u] = parent[parent[u]]  # Path compression
            u = parent[u]
        return u

    output = []
    for _ in range(Q):
        t = int(data[ptr])
        ptr += 1
        u = int(data[ptr])
        ptr += 1
        v = int(data[ptr])
        ptr += 1

        if t == 0:
            root_u = find(u)
            root_v = find(v)
            if root_u != root_v:
                if size[root_u] < size[root_v]:
                    parent[root_u] = root_v
                    size[root_v] += size[root_u]
                else:
                    parent[root_v] = root_u
                    size[root_u] += size[root_v]
        else:
            if find(u) == find(v):
                output.append('1')
            else:
                output.append('0')
    
    print('\n'.join(output))

if __name__ == '__main__':
    main()
```

- **Initialization**: The DSU is initialized with each vertex as its own parent and size 1.
- **Find Operation**: Uses path compression to ensure each node points directly to the root, reducing the height of the tree.
- **Union Operation**: Merges two sets by attaching the smaller tree under the root of the larger tree, keeping the tree balanced.
- **Query Processing**: For each query, either perform the union operation or check connectivity using the find operation. Results for connectivity checks are collected and printed at the end to minimize I/O operations, which is crucial for performance in Python.

This approach ensures efficient handling of up to 200,000 vertices and queries, adhering to the problem constraints and providing optimal performance.
