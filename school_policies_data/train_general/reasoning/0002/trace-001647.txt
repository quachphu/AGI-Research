To solve this problem, we need to determine the configuration of toy cubes in a box after the gravity is switched to pull all cubes to the right. The solution involves understanding that the cubes will settle in such a way that each column's height is in non-decreasing order from left to right.

### Approach
1. **Problem Analysis**: When gravity is switched to pull cubes to the right, cubes will move from higher columns on the left to fill lower columns on the right. This results in a configuration where the columns are sorted in non-decreasing order.
2. **Intuition**: The final configuration of the columns will be sorted in non-decreasing order because each cube will move as far right as possible until it can't move further due to the presence of higher or equal columns to its right.
3. **Algorithm**: 
   - Read the number of columns and the initial configuration of cubes.
   - Sort the list of column heights in non-decreasing order.
   - Print the sorted list, which represents the columns after the gravity switch.

### Solution Code
```python
n = int(input())
columns = list(map(int, input().split()))
columns.sort()
print(' '.join(map(str, columns)))
```

### Explanation
1. **Reading Input**: The first input line gives the number of columns, `n`. The second line provides the initial number of cubes in each column.
2. **Sorting**: By sorting the list of column heights, we ensure that each column's height is less than or equal to the next column's height. This sorted list represents the configuration after gravity has pulled all cubes to the right.
3. **Output**: The sorted list is printed as space-separated integers, which gives the final configuration of the columns.

This approach efficiently solves the problem with a time complexity of O(n log n) due to the sorting step, which is optimal for the given constraints (1 ≤ n ≤ 100).
