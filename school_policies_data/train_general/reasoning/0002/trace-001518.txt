def point_in_polygon(poly, a, b):
    # Implements ray-casting algorithm to determine if point (a, b) is in poly.
    # poly is a list of (ai, bi) points.
    n = len(poly)
    inside = False
    for i in range(n):
        a1, b1 = poly[i]
        a2, b2 = poly[(i+1) % n]
        if ((b1 > b) != (b2 > b)):
            # Compute the x-intercept of the edge and the ray y = b.
            if a2 - a1 == 0:
                t = (b - b1) / (b2 - b1)
            else:
                t = (b - b1) / (b2 - b1)
            a_inter = a1 + t * (a2 - a1)
            if a <= a_inter:
                inside = not inside
    return inside

def interval_intersection(a, b):
    # Compute the intersection of two interval lists.
    i = 0
    j = 0
    res = []
    while i < len(a) and j < len(b):
        a_start, a_end = a[i]
        b_start, b_end = b[j]
        # Find overlapping interval.
        start = max(a_start, b_start)
        end = min(a_end, b_end)
        if start < end:
            res.append( (start, end) )
        # Move the interval which ends first.
        if a_end < b_end:
            i += 1
        else:
            j += 1
    return res

To solve this problem, we need to determine the maximum volume of a 3D object that is consistent with three given X-ray projections taken from the front, right, and top views. The goal is to find the largest possible volume of the object that fits within the constraints provided by these projections.

### Approach
1. **Understand the Projections**: Each X-ray projection (front, right, top) defines a region in 2D space. The object's 3D volume must fit within the intersection of these regions when projected onto the respective planes.
2. **Check Point Inclusion**: For each integer coordinate (x, y) in the top projection, check if it lies within the top polygon.
3. **Determine Valid Z Ranges**: For valid (x, y) coordinates from the top projection, compute the valid Z ranges from the front and right projections.
4. **Intersection of Z Ranges**: Calculate the intersection of the Z ranges from the front and right projections to determine the valid Z values for each (x, y).
5. **Volume Calculation**: Sum the lengths of the valid Z ranges for all valid (x, y) points to compute the total volume.
