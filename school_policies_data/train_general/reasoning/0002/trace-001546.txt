To solve this problem, we need to determine the minimum amount of gold Vova needs to spend to spread a rumor to all characters in Overcity. The key insight is that once a character is bribed, all their friends (and friends of friends, etc.) will receive the rumor for free. This reduces the problem to finding the minimum cost to bribe at least one character in each connected component of the friendship graph.

### Approach
1. **Graph Representation**: Represent the characters and their friendships as an adjacency list where each node is a character and edges represent friendships.
2. **Connected Components**: Use Breadth-First Search (BFS) to identify all connected components in the graph. Each connected component represents a group of characters who can spread the rumor among themselves once any one of them is bribed.
3. **Minimum Cost Calculation**: For each connected component, determine the minimum cost required to bribe any character in that component. The sum of these minimum costs across all components gives the solution.

### Solution Code
```python
import sys
from collections import deque

def main():
    n, m = map(int, sys.stdin.readline().split())
    costs = list(map(int, sys.stdin.readline().split()))
    adj = [[] for _ in range(n + 1)]  # 1-based indexing

    for _ in range(m):
        x, y = map(int, sys.stdin.readline().split())
        adj[x].append(y)
        adj[y].append(x)

    visited = [False] * (n + 1)
    total = 0

    for i in range(1, n + 1):
        if not visited[i]:
            min_cost = costs[i - 1]
            q = deque()
            q.append(i)
            visited[i] = True
            while q:
                u = q.popleft()
                current_cost = costs[u - 1]
                if current_cost < min_cost:
                    min_cost = current_cost
                for v in adj[u]:
                    if not visited[v]:
                        visited[v] = True
                        q.append(v)
            total += min_cost

    print(total)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Graph Construction**: The adjacency list is built using the given friendships, allowing efficient traversal of connected nodes.
2. **BFS for Connected Components**: For each unvisited node, BFS is used to explore all nodes in its connected component. During this traversal, the minimum cost to bribe any node in the component is tracked.
3. **Summing Minimum Costs**: The minimum cost for each connected component is accumulated to get the total minimum gold required.

This approach efficiently handles up to the maximum constraints (100,000 nodes and edges) using BFS, ensuring linear time complexity relative to the number of nodes and edges, making it suitable for large input sizes.
