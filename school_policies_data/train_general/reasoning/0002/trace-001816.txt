To solve this problem, we need to determine if Chef's Sprout program, which prints a given word with the minimum number of instructions, is simple. A program is considered simple if the number of instructions does not exceed 11 times the length of the word.

### Approach
1. **Convert Characters to Values**: Each character in the word is converted to a corresponding integer value between 0 and 25 (e.g., 'a' becomes 0, 'b' becomes 1, ..., 'z' becomes 25).
2. **Calculate Transitions**: For each consecutive pair of characters in the word, compute the number of increments needed to transition from the previous character to the next. This is done using modular arithmetic to handle wrap-around from 25 to 0.
3. **Sum Increments**: Sum the increments needed for all transitions between consecutive characters.
4. **Total Instructions**: The total number of instructions is the sum of the initial load instruction, all increments, and all print instructions.
5. **Check Simplicity**: Compare the total number of instructions against 11 times the length of the word. If the total is within the limit, the program is simple.

### Solution Code
```python
def main():
    import sys
    input_lines = sys.stdin.read().splitlines()
    T = int(input_lines[0])
    for line in input_lines[1:T+1]:
        word = line.strip()
        if not word:
            print("YES")
            continue
        values = [ord(c) - ord('a') for c in word]
        sum_inc = 0
        for prev, curr in zip(values, values[1:]):
            sum_inc += (curr - prev) % 26
        total = 1 + sum_inc + len(word)
        if total <= 11 * len(word):
            print("YES")
        else:
            print("NO")

main()
```

### Explanation
1. **Input Reading**: The input is read and split into lines. The first line gives the number of test cases.
2. **Character Conversion**: Each character in the word is converted to an integer value using `ord(c) - ord('a')`.
3. **Transition Calculation**: For each pair of consecutive characters, the number of increments needed is calculated using `(curr - prev) % 26` to handle wrap-around.
4. **Summing Instructions**: The total instructions include the initial load (1), all increments, and all print instructions (equal to the length of the word).
5. **Simplicity Check**: The total instructions are compared against 11 times the word length to determine if the program is simple, printing "YES" or "NO" accordingly.

This approach ensures that we efficiently compute the minimal instructions required and check against the given constraints, providing an optimal solution to the problem.
