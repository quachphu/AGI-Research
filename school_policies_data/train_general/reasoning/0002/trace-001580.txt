To solve this problem, we need to count the number of different possible unambiguous arithmetic expressions (UAEs) that, when their parentheses are removed, match the given input string. The result should be computed modulo 1000003.

### Approach
1. **Dynamic Programming (DP) Setup**: We use a DP table `dp[i][j]` where `dp[i][j]` represents the number of valid UAEs for the substring `s[i..j]`.
2. **Precompute Valid Numbers**: Create a 2D array `is_num` to check if a substring `s[i..j]` is a valid number (all digits).
3. **Collect Binary Operators**: Identify positions of binary operators (`+`, `-`, `*`, `/`) in the input string.
4. **Bottom-Up DP Calculation**: Fill the DP table by considering all possible unary operators at the start and binary operators splitting the substring into valid UAEs.

### Solution Code
```python
import bisect

MOD = 10**6 + 3

s = input().strip()
n = len(s)

# Precompute is_num[i][j]: True if s[i..j] is all digits
is_num = [[False] * n for _ in range(n)]
for i in range(n):
    current = True
    for j in range(i, n):
        if i == j:
            current = s[j].isdigit()
        else:
            current = current and s[j].isdigit()
        is_num[i][j] = current

# Collect positions of binary operators
ops = [k for k in range(n) if s[k] in '+-*/']
ops.sort()

# Initialize DP table
dp = [[0] * n for _ in range(n)]

# Fill DP table in bottom-up manner
for i in range(n-1, -1, -1):
    for j in range(i, n):
        if is_num[i][j]:
            dp[i][j] = 1
        else:
            total = 0
            # Check for unary operator at the start
            if s[i] in '+-' and (i + 1 <= j):
                total += dp[i+1][j]
                total %= MOD
            # Check for binary operators
            if ops:
                left_k = i + 1
                right_k = j - 1
                if left_k <= right_k:
                    # Find the range in ops using binary search
                    left = bisect.bisect_left(ops, left_k)
                    right = bisect.bisect_right(ops, right_k)
                    for k in ops[left:right]:
                        left_val = dp[i][k-1] if k-1 >= i else 0
                        right_val = dp[k+1][j] if k+1 <= j else 0
                        total += left_val * right_val
                        total %= MOD
            dp[i][j] = total % MOD

print(dp[0][n-1] % MOD)
```

### Explanation
1. **Precompute Valid Numbers**: The `is_num` array helps quickly determine if a substring is a valid number, which is a base case for the DP.
2. **Binary Operators Handling**: By collecting positions of binary operators and using binary search, we efficiently check valid splits in the substring.
3. **Dynamic Programming**: The DP table is filled bottom-up, considering unary operators at the start and valid splits by binary operators. Each entry `dp[i][j]` accumulates counts from valid splits, ensuring modulo operations to handle large numbers.

This approach efficiently counts valid UAEs by leveraging dynamic programming and optimizations for handling operators, ensuring correctness and performance within constraints.
