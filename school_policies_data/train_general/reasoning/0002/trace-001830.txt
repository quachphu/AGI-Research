class DSU:

    def __init__(self, size):

        self.parent = list(range(size))

        self.size = [1]*size

    def find(self, x):

        if self.parent[x] !=x:

            self.parent[x] = self.find(self.parent[x])

        return self.parent[x]

    def union(self, x, y):

        x_root = self.find(x)

        y_root = self.find(y)

        if x_root == y_root:

            return

        if self.size[x_root] < self.size[y_root]:

            x_root, y_root = y_root, x_root

        self.parent[y_root] = x_root

        self.size[x_root] += self.size[y_root]

3. **Check for Already Connected Graph**: If the graph is already connected (C = 1), the answer is 1 since no additional edges are needed.
4. **Compute the Result Using Combinatorial Mathematics**:
   - **Product of Component Sizes**: Compute the product of the sizes of all connected components modulo k.
   - **Exponentiation**: Calculate \( n^{(C-2)} \) modulo k, where n is the total number of clues.
   - **Combine Results**: Multiply the product of component sizes with the exponentiation result and take modulo k to get the final answer.

### Solution Code
```python
class DSU:
    def __init__(self, size):
        self.parent = list(range(size))
        self.size = [1] * size

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return
        if self.size[x_root] < self.size[y_root]:
            x_root, y_root = y_root, x_root
        self.parent[y_root] = x_root
        self.size[x_root] += self.size[y_root]

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    m = int(input[idx])
    idx += 1
    k = int(input[idx])
    idx += 1

    dsu = DSU(n)
    for _ in range(m):
        a = int(input[idx]) - 1
        idx += 1
        b = int(input[idx]) - 1
        idx += 1
        dsu.union(a, b)

    components = []
    visited = set()
    for i in range(n):
        root = dsu.find(i)
        if root not in visited:
            visited.add(root)
            components.append(dsu.size[root])

    c = len(components)
    if c == 1:
        print(1 % k)
    else:
        product = 1
        for s in components:
            product = (product * s) % k
        exponent = c - 2
        pow_n = pow(n, exponent, k)
        ans = (product * pow_n) % k
        print(ans)

if __name__ == "__main__":
    main()
```

### Explanation
1. **DSU Structure**: The DSU (Disjoint Set Union) helps efficiently manage and merge connected components. It uses path compression and union by size to keep operations nearly constant time.
2. **Connected Components**: After processing all edges, we determine the connected components by checking the root of each node.
3. **Modular Arithmetic**: To handle large numbers and avoid overflow, we use modular arithmetic for both the product of component sizes and the exponentiation step.
4. **Efficiency**: The algorithm efficiently handles the constraints with a time complexity dominated by the DSU operations, which is nearly linear, making it suitable for large inputs up to \(10^5\) nodes and edges.
