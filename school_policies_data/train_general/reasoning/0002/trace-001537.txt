To solve this problem, we need to compute the expected number of collisions between runners in a circular stadium. Each runner starts at a specific point and runs either clockwise or counter-clockwise with equal probability. The goal is to determine the expected number of collisions after a given time `t`.

### Approach
1. **Problem Analysis**:
   - Each runner can choose to run in either direction, leading to four possible direction combinations for any two runners. However, collisions only occur when they run in opposite directions.
   - The problem can be broken down into calculating the expected number of collisions for each pair of runners and summing these values.

2. **Key Insight**:
   - For each pair of runners moving in opposite directions, the number of collisions depends on their initial distance and the time `t`.
   - We need to handle two cases based on whether the total distance covered (2t) is greater than or less than the circumference of the stadium `l`.

3. **Algorithm**:
   - **Case 1 (2t >= l)**:
     - Calculate the number of pairs of runners that meet multiple times around the stadium.
   - **Case 2 (2t < l)**:
     - Calculate the number of pairs of runners that meet within the given time `t` considering their initial positions and directions.

4. **Efficiency**:
   - Using binary search to efficiently count the number of valid pairs for each runner, the solution achieves an O(n log n) complexity, which is feasible for large inputs up to 10^6.

### Solution Code
```python
import bisect

def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    l = int(input[idx])
    idx += 1
    t = int(input[idx])
    idx += 1
    a = list(map(int, input[idx:idx + n]))
    
    two_t = 2 * t
    if two_t >= l:
        q = two_t // l
        r = two_t % l
        count_gr_r = 0
        for i in range(n):
            target = a[i] + r
            j = bisect.bisect_right(a, target, i + 1, n)
            count_gr_r += (n - j)
        
        target_l_r = l - r
        count_ge_l_r = 0
        for i in range(n):
            target = a[i] + target_l_r
            j = bisect.bisect_left(a, target, i + 1, n)
            count_ge_l_r += (n - j)
        
        total_pairs = n * (n - 1) // 2
        sum_S = (2 * q - 1) * total_pairs + (count_ge_l_r - count_gr_r) + n * (n - 1)
    else:
        l_minus_two_t = l - two_t
        A = 0
        for i in range(n):
            target = a[i] + two_t
            j = bisect.bisect_right(a, target, i + 1, n)
            A += (j - i - 1)
        
        B = 0
        for i in range(n):
            target = a[i] + l_minus_two_t
            j = bisect.bisect_left(a, target, i + 1, n)
            B += (n - j)
        
        sum_S = A + B
    
    expectation = sum_S * 0.25
    print("{0:.10f}".format(expectation))

if __name__ == "__main__":
    main()
```

### Explanation
- **Case Handling**:
  - **Case 1 (2t >= l)**: This case involves multiple loops around the stadium. We calculate the number of full loops and remaining distance to determine collisions.
  - **Case 2 (2t < l)**: Here, we directly count valid pairs of runners that collide within the given time using binary search for efficiency.

- **Binary Search**:
  - Used to efficiently count the number of valid pairs for each runner, reducing the complexity from O(n^2) to O(n log n).

This approach ensures that we handle both small and large values of `t` efficiently, providing the correct expected number of collisions with high precision.
