To solve this problem, we need to determine the first minute at which a monster's HP drops to zero or below during a battle with a superhero. The battle consists of repeating rounds, each lasting exactly `n` minutes, and each minute's effect on the monster's HP is given by a sequence of integers.

### Approach
1. **Initial Check in First Round**: Simulate the first round and check if the monster's HP drops to zero or below in any minute. If it does, return that minute immediately.
2. **Check for Infinite Battle**: Calculate the total HP change per round. If this total is non-negative, the battle will continue infinitely, so return `-1`.
3. **Calculate Minimum Time for Subsequent Rounds**: If the total HP change per round is negative, compute the minimum number of rounds required after the first round for the monster's HP to drop to zero or below in any subsequent round. This involves calculating the earliest possible minute in each subsequent round where the HP condition is met.

### Solution Code
```python
H, n = map(int, input().split())
d = list(map(int, input().split()))
prefix = []
current = 0
for i in range(n):
    current += d[i]
    prefix.append(current)
    if H + current <= 0:
        print(i + 1)
        exit()

    print(-1)
    exit()
abs_s = -sum_d
min_time = float('inf')
for i in range(n):
    current_prefix = prefix[i]
    numerator = H + current_prefix
    denominator = abs_s
    k_i = (numerator + denominator - 1) // denominator
    time_i = k_i * n + (i + 1)
    if time_i < min_time:
        min_time = time_i
print(min_time)
```

3. **Subsequent Rounds Calculation**: For each minute in the first round, we determine how many full rounds are needed such that the HP drops to zero or below in that minute of a subsequent round. This is done using ceiling division to find the minimum number of rounds required, then calculating the exact minute considering the total minutes from these rounds and the specific minute within the next round.
