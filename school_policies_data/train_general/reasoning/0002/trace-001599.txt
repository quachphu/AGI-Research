To solve this problem, we need to determine if a given text matches a specified verse pattern based on the number of syllables in each line. A syllable is defined as a substring containing exactly one vowel (including 'y'), and words without any vowels are ignored.

### Approach
1. **Reading Input:** First, we read the number of lines, the verse pattern, and the text lines.
2. **Counting Syllables:** For each line of text, split it into words. For each word, count the number of vowels (including 'y'). Words with zero vowels are ignored. The total number of syllables for a line is the sum of the vowel counts of its valid words.
3. **Matching Pattern:** Compare the syllable count of each line with the corresponding value in the verse pattern. If all lines match their respective pattern values, the output is "YES"; otherwise, it is "NO".

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split('\n')
    ptr = 0
    n = int(input[ptr].strip())
    ptr += 1
    p = list(map(int, input[ptr].strip().split()))
    ptr += 1
    text_lines = []
    for _ in range(n):
        if ptr >= len(input):
            line = ''
        else:
            line = input[ptr].strip()
        text_lines.append(line)
        ptr += 1
    
    for i in range(n):
        current_p = p[i]
        line = text_lines[i]
        words = line.split()
        syllables = 0
        for word in words:
            vowels = 0
            for c in word:
                if c in {'a', 'e', 'i', 'o', 'u', 'y'}:
                    vowels += 1
            if vowels > 0:
                syllables += vowels
        if syllables != current_p:
            print("NO")
            return
    print("YES")

main()
```

### Explanation
1. **Reading Input:** The input is read all at once and split into lines for easier processing. This helps handle cases where input lines might be read inconsistently due to trailing newlines or other issues.
2. **Processing Each Line:** For each line, split it into words and count the vowels in each word. Words with vowels contribute their vowel count to the total syllables for that line.
3. **Validation:** Each line's syllable count is compared against the corresponding value in the verse pattern. If any line's count does not match, the result is immediately "NO". If all lines match, the result is "YES".

This approach efficiently checks each line against the pattern using straightforward vowel counting, ensuring correctness and adherence to the problem constraints.
