A valid shiritori sequence requires that each consecutive word starts with the last character of the previous word, and the sequence forms a cycle where the first character of the first word matches the last character of the last word. 

### Approach
1. **Graph Representation**: Treat each word as a directed edge from its first character to its last character.
2. **In-degree and Out-degree Check**: For the sequence to form a valid cycle, every character node must have equal in-degree and out-degree.
3. **Strong Connectivity Check**: Ensure that all character nodes form a single strongly connected component (SCC) using Kosaraju's algorithm. This ensures that there is a path between any pair of nodes in both directions.

def main():

                continue
            s = word[0]

            in_degree[e] += 1
            original_edges[s].append(e)
            reversed_edges[e].append(s)
            nodes.add(s)
            nodes.add(e)
        
        valid = True
        all_nodes = list(nodes)

            if in_degree.get(node, 0) != out_degree.get(node, 0):

            continue
        
        if not all_nodes:
            print("NG")
            continue
        
        visited = set()
        order = []
        for node in all_nodes:
            if node not in visited:
                stack = [(node, False)]
                while stack:
                    current, processed = stack.pop()
                    if processed:
                        order.append(current)
                        continue
                    if current in visited:
                        continue
                    visited.add(current)
