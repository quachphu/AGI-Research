To solve this problem, we need to determine the number of ways Iahub can take a photo of a contiguous subarray of devices such that the total matter and antimatter produced are equal. Each device can either produce its value in matter or antimatter.

### Approach
1. **Problem Analysis**:
   - The sum of the subarray must be even because the total matter and antimatter must be equal.
   - For each valid subarray (with an even sum), we need to count the number of ways to split the elements into two groups with equal sums.

2. **Dynamic Programming Approach**:
   - Use dynamic programming (DP) to track the number of subsets that sum to a specific value for each subarray starting from index `i` and ending at index `j`.
   - For each starting index `i`, iterate through all possible ending indices `j`, updating the DP array to include the current element and track possible sums.

3. **Optimization**:
   - Use a 1D DP array to keep track of subset sums efficiently.
   - Update the DP array in reverse order to avoid overwriting values prematurely.

### Solution Code
```python
MOD = 10**9 + 7

n = int(input())
a = list(map(int, input().split()))
total = 0

max_sum = sum(a)  # Sum of the entire array, which is <=10000

for i in range(n):
    dp = [0] * (max_sum + 1)  # Initialize with max_sum +1 elements
    dp[0] = 1
    current_sum = 0
    for j in range(i, n):
        current_val = a[j]
        current_sum += current_val
        # Update dp in reverse to prevent overcounting
        for s in range(current_sum, current_val - 1, -1):
            dp[s] = (dp[s] + dp[s - current_val]) % MOD
        # Check if current_sum is even
        if current_sum % 2 == 0:
            target = current_sum // 2
            if target <= max_sum:
                total = (total + dp[target]) % MOD

print(total % MOD)
```

- **Dynamic Programming Array**: The `dp` array tracks the number of ways to achieve each possible sum using elements from the subarray starting at index `i` up to the current index `j`.
- **Reverse Order Update**: By updating the DP array in reverse order, we ensure that each element's contribution is counted only once per iteration, avoiding overcounting.
- **Sum Check**: For each subarray, if the sum is even, check how many subsets sum to half of this total, which gives the valid ways to split the subarray into equal parts.
