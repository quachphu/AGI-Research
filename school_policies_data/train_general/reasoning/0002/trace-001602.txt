To solve this problem, we need to efficiently compute the function f(x, y) as defined by Vasya. The function is defined recursively, but directly simulating each step would be too slow for large values of y. Instead, we use mathematical insights to optimize the computation.

### Approach
1. **Understanding the Function**: The function f(a, b) is defined such that each step reduces the second argument by the greatest common divisor (gcd) of the two arguments until the second argument becomes zero.
2. **Efficient Steps Calculation**: Instead of simulating each step, we determine how many steps can be taken with the same gcd value before it changes. This is done by considering the prime factors of the quotient of the first argument divided by the current gcd.
3. **Prime Factorization**: For each step, we factorize the quotient of the first argument divided by the current gcd to determine the minimal steps required before the gcd changes.

### Solution Code
```python
import sys
import math

def get_prime_factors(n):
    factors = set()
    if n % 2 == 0:
        factors.add(2)
        while n % 2 == 0:
            n //= 2
    i = 3
    while i * i <= n:
        if n % i == 0:
            factors.add(i)
            while n % i == 0:
                n //= i
        i += 2
    if n > 1:
        factors.add(n)
    return factors

def compute_f(x, y):
    count = 0
    while y > 0:
        g = math.gcd(x, y)
        if g == y:
            count += 1
            break
        x_div = x // g
        y_div = y // g
        if x_div == 1:
            count += y_div
            break
        primes = get_prime_factors(x_div)
        min_m = float('inf')
        for p in primes:
            mod = y_div % p
            if mod < min_m:
                min_m = mod
        count += min_m
        y -= min_m * g
    return count
```
