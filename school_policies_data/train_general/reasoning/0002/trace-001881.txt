To solve this problem, we need to efficiently handle three types of operations on an array: updating an element, incrementing all elements, and querying an element. Given the constraints, a direct approach would be too slow, so we use an optimized method to track changes using a global offset.

### Approach
1. **Stored Values and Global Offset**: Maintain an array `stored` to keep track of the base values of elements, and a variable `global_add` to accumulate all increments applied to every element.
2. **Operation Handling**:
   - **Type 1 (Update Element)**: Adjust the value in the `stored` array by subtracting the current `global_add` to ensure future increments are correctly applied.
   - **Type 2 (Increment All Elements)**: Simply update `global_add` by the given increment value.
   - **Type 3 (Query Element)**: Compute the current value of the element by adding `global_add` to the stored value.

This approach ensures each operation is handled in O(1) time, making the solution efficient even for large inputs.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    m = int(input[ptr])
    ptr += 1
    
    stored = list(map(int, input[ptr:ptr+n]))
    ptr += n
    
    global_add = 0
    
    for _ in range(m):
        t = int(input[ptr])
        ptr += 1
        if t == 1:
            vi = int(input[ptr]) - 1  # Convert to 0-based index
            ptr += 1
            xi = int(input[ptr])
            ptr += 1
            stored[vi] = xi - global_add
        elif t == 2:
            yi = int(input[ptr])
            ptr += 1
            global_add += yi
        elif t == 3:
            qi = int(input[ptr]) - 1  # Convert to 0-based index
            ptr += 1
            print(stored[qi] + global_add)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input Efficiently**: The input is read all at once and split into a list for faster processing.
- **Global Offset Management**: The `global_add` variable accumulates all increments applied to every element, avoiding the need to update each element individually.
- **Handling Updates**: When an element is updated, its new value is stored after adjusting for the current `global_add` to ensure future increments are correctly applied.
- **Querying Elements**: The current value of an element is computed by adding the `global_add` to the stored value, ensuring efficient lookups.

This method efficiently handles all operations in constant time, making it suitable for large input sizes up to 100,000 operations.
