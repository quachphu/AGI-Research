   - The optimal distribution of pillows around Frodo's bed forms a "pyramid" structure, where the number of pillows decreases by 1 as we move away from Frodo's bed until reaching the minimum of 1 pillow per bed.

3. **Binary Search**:
   - Use binary search to determine the maximum number of pillows Frodo can have. For each candidate number of pillows, calculate the minimum total required to maintain the pyramid structure and check if it does not exceed m.

4. **Sum Calculation**:
   - For a given number of pillows on Frodo's bed (x), compute the required pillows for the left and right neighbors using arithmetic series, ensuring each bed has at least 1 pillow.

### Solution Code
```python
def calculate_sum(x, n, k):
    left = k - 1
    right = n - k

    # Calculate sum for left side
    t_left = min(x - 1, left)
    sum_left_part1 = ((x - 1) + (x - t_left)) * t_left // 2
    sum_left_part2 = (left - t_left) * 1
    sum_left = sum_left_part1 + sum_left_part2

    # Calculate sum for right side
    t_right = min(x - 1, right)
    sum_right_part1 = ((x - 1) + (x - t_right)) * t_right // 2
    sum_right_part2 = (right - t_right) * 1
    sum_right = sum_right_part1 + sum_right_part2

    return sum_left + sum_right + x

def main():
    import sys
    n, m, k = map(int, sys.stdin.readline().split())
    low = 1
    high = m
    ans = 1
    while low <= high:
        mid = (low + high) // 2
        current_sum = calculate_sum(mid, n, k)
        if current_sum <= m:
            ans = mid
            low = mid + 1
        else:
            high = mid - 1
    print(ans)

if __name__ == "__main__":
    main()
```

### Explanation
- **Binary Search**: The binary search is used to efficiently find the maximum number of pillows Frodo can have. The search range is between 1 and m (the total number of pillows).
- **Sum Calculation**: For each candidate number of pillows (mid) during the binary search, we calculate the total required pillows by considering the arithmetic series sum for the left and right neighbors of Frodo's bed. This ensures that the distribution adheres to the constraints of adjacent differences and minimum pillows per bed.
- **Efficiency**: The binary search operates in O(log m) time, and each sum calculation is done in O(1) time, making the solution efficient even for large input values up to 10^9.
