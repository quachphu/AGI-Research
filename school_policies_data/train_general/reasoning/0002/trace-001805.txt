To solve this problem, we need to determine the day of the week for a given date in the year 2004, which is a leap year. The input consists of multiple dates, and we need to print the corresponding day for each date until the termination condition (0 0) is encountered.

### Approach
1. **Understanding the Problem**: The year 2004 is a leap year, so February has 29 days. We know that January 1, 2004, is a Thursday. Our task is to compute the day of the week for any given date in 2004.
2. **Days Calculation**: For a given date (month, day), calculate the total number of days elapsed from January 1 to that date. This can be done by summing the days of all months preceding the given month and adding the day of the month minus one (since January 1 is day 0).
3. **Day of the Week**: Once we have the total days elapsed, we can determine the day of the week by using modulo 7 arithmetic. Since January 1 is a Thursday (which is the 4th day if we consider Monday as the first day), we add 3 to the total days before taking modulo 7 to get the correct index.

### Solution Code
```python
def main():
    days = ['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday', 'Sunday']
    days_in_month = [0, 31, 29, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]  # 2004 is a leap year
    
    import sys
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        m, d = map(int, line.split())
        if m == 0 and d == 0:
            break
        # Calculate total days from Jan 1 (0 days) to the given date
        total_days = sum(days_in_month[1:m]) + (d - 1)
        day_index = (3 + total_days) % 7  # Jan 1 is Thursday (index 3)
        print(days[day_index])

main()
```

### Explanation
1. **Days List**: The list `days` is ordered from Monday to Sunday to match the required output format.
2. **Days in Month**: The list `days_in_month` contains the number of days for each month in 2004, considering February has 29 days.
3. **Reading Input**: The code reads input lines until it encounters "0 0", which signals the end of input.
4. **Total Days Calculation**: For each valid date (month, day), the code calculates the total days elapsed from January 1 by summing the days of all preceding months and adding the day of the current month minus one.
5. **Day Index Calculation**: The day index is computed using `(3 + total_days) % 7` because January 1 is a Thursday (index 3). The result is used to index into the `days` list to get the corresponding day name.

This approach efficiently computes the day of the week for any given date in 2004 using basic arithmetic and list operations, ensuring correctness and optimal performance.
