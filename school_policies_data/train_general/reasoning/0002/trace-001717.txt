To solve this problem, we need to determine the number of ways to tile a 2xN grid using 1x2 tiles. The solution involves recognizing a pattern similar to the Fibonacci sequence, where each number of ways to tile the grid can be derived from previous results.

### Approach
1. **Problem Analysis**: The problem can be reduced to finding the (N+1)-th Fibonacci number. This is because tiling a 2xN grid can be done by either placing a vertical tile (leading to solving the problem for 2x(N-1)) or placing two horizontal tiles (leading to solving the problem for 2x(N-2)).

2. **Dynamic Programming**: Precompute Fibonacci numbers up to the maximum possible value of N (1,000,000) using dynamic programming. This allows us to answer each query in constant time after preprocessing.

3. **Modulo Operation**: Since the result can be very large, we use modulo \(10^9 + 7\) to keep the numbers manageable and prevent overflow.

### Solution Code
```python
MOD = 10**9 + 7

def main():
    import sys
    input = sys.stdin.read().split()
    T = int(input[0])
    cases = list(map(int, input[1:T+1]))
    max_n = max(cases) if T > 0 else 0  # handle T=0, though constraints say T>=1
    
    max_fib = max_n + 1
    # Initialize fib array with 0s up to max_fib +1 to handle max_fib
    fib = [0] * (max_fib + 2)  # +2 to avoid index issues
    if max_fib >= 1:
        fib[1] = 1
    if max_fib >= 2:
        fib[2] = 1
    for i in range(3, max_fib + 1):
        fib[i] = (fib[i-1] + fib[i-2]) % MOD
    
    for n in cases:
        print(fib[n + 1] % MOD)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Precomputation**: The Fibonacci numbers up to the maximum required value (N+1) are precomputed using dynamic programming. This ensures that each query can be answered in constant time.
3. **Modulo Operation**: Each Fibonacci number is computed modulo \(10^9 + 7\) to handle large numbers and prevent overflow.
4. **Query Handling**: For each test case, the result is simply the precomputed Fibonacci value at the required index, ensuring efficient query resolution.

This approach efficiently handles up to 1000 test cases with values of N up to 1,000,000 by leveraging precomputation and dynamic programming.
