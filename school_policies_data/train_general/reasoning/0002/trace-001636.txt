To solve this problem, we need to determine how many numbers from 1 to n (inclusive) are considered "beautiful" according to Polycarp's definition. A beautiful number is one where all digits are the same, such as 1, 22, 333, etc.

### Approach
1. **Understanding Beautiful Numbers**: A beautiful number consists of the same digit repeated one or more times. For example, 1, 22, 333, etc. Each digit from 1 to 9 can form such numbers.
2. **Generating Beautiful Numbers**: For each digit `d` (from 1 to 9), generate numbers of increasing length (starting from 1) and check if they are less than or equal to `n`. The number formed by repeating digit `d` `l` times can be computed as `d * (10^l - 1) // 9`.
3. **Efficient Checking**: For each digit `d`, generate numbers of increasing length until the generated number exceeds `n`. Count how many such valid numbers exist for each digit.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n = int(input())
    count = 0
    for d in range(1, 10):
        l = 1
        while True:
            num = d * ((10 ** l - 1) // 9)
            if num > n:
                break
            count += 1
            l += 1
    print(count)
```

### Explanation
1. **Reading Input**: The code starts by reading the number of test cases `t`.
2. **Processing Each Test Case**: For each test case, read the integer `n` which represents the age Polycarp has turned.
3. **Counting Beautiful Numbers**: For each digit `d` from 1 to 9:
   - Initialize the length `l` to 1.
   - Generate the beautiful number formed by repeating `d` `l` times using the formula `d * (10^l - 1) // 9`.
   - Check if this number is less than or equal to `n`. If yes, increment the count and check the next length. If no, break the loop for the current digit.
4. **Output the Result**: After processing all digits for the current test case, print the count of beautiful numbers.

This approach efficiently checks each possible beautiful number by generating them in increasing order of length and stopping early when the generated number exceeds `n`, ensuring optimal performance even for large values of `n`.
