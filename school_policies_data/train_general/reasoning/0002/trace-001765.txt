To solve this problem, we need to generate detailed information for each node in a rooted tree, including its parent, depth, type (root, internal node, or leaf), and list of children. The solution involves parsing the input to build the tree structure, computing the depth of each node using BFS, and then generating the required output.

### Approach

1. **Parse Input and Build Tree Structure**: 
   - Read the number of nodes `n`.
   - For each node, read its children and update the parent-child relationships. This helps in constructing the tree using adjacency lists for children and an array to track each node's parent.

2. **Identify the Root Node**:
   - The root node is identified as the node with no parent (i.e., its parent value remains `-1` after processing all nodes).

3. **Compute Depth Using BFS**:
   - Starting from the root node, use a breadth-first search (BFS) to compute the depth of each node. The depth of a node is its distance from the root, which is incremented by 1 from its parent's depth.

4. **Determine Node Type**:
   - For each node, determine its type based on its parent and children:
     - **Root**: Node with no parent.
     - **Leaf**: Node with no children.
     - **Internal Node**: Node with children.

5. **Generate Output**:
   - Format and print the information for each node in the specified order.

### Solution Code

```python
import sys
from collections import deque

def main():
    n = int(sys.stdin.readline())
    parent = [-1] * n
    children = [[] for _ in range(n)]
    
    for _ in range(n):
        parts = list(map(int, sys.stdin.readline().split()))
        node_id = parts[0]
        degree = parts[1]
        if degree > 0:
            children_list = parts[2:2 + degree]
            children[node_id] = children_list
            for child in children_list:
                parent[child] = node_id
        else:
            children[node_id] = []
    
    # Find the root node
    root = parent.index(-1)
    
    # Calculate depths using BFS
    depth = [0] * n
    queue = deque([root])
    while queue:
        current_node = queue.popleft()
        for child in children[current_node]:
            depth[child] = depth[current_node] + 1
            queue.append(child)
    
    # Generate output for each node
    for node_id in range(n):
        p = parent[node_id]
        d = depth[node_id]
        if p == -1:
            node_type = 'root'
        elif len(children[node_id]) == 0:
            node_type = 'leaf'
        else:
            node_type = 'internal node'
        print(f"node {node_id}: parent = {p}, depth = {d}, {node_type}, {children[node_id]}")

main()
```
