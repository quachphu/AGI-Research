The BIT in Python:

A BIT supports two operations:

1. Update: Add a delta to a specific index.

2. Query: Get the sum from index 0 to index i.

For each x's BIT, the indices are 0-based. The BIT's size is the length of pos_x. Each element is 1 if active, 0 if inactive.

For the global BIT, the indices are the original positions.

Implementing the BIT:

class BIT:
    def __init__(self, size):
        self.size = size
        self.tree = [0] * (self.size + 1)

    def update(self, idx, delta):
        # 1-based index
        idx += 1
        while idx <= self.size:
            self.tree[idx] += delta
            idx += idx & -idx

    def query(self, idx):
        # Sum from 0 to idx (0-based)
        # convert to 1-based
        idx += 1
        res = 0
        while idx > 0:
            res += self.tree[idx]
            idx -= idx & -idx
        return res

But for each x's BIT, we need to find the smallest j where the sum up to j is K. This can be done via binary search.

Function to find the K-th active element in x's BIT:

def find_kth(bits, k):
    low = 0
    high = bits.size - 1
    res = -1
    while low <= high:
        mid = (low + high) // 2
        s = bits.query(mid)
        if s >= k:
            res = mid
            high = mid - 1
        else:
            low = mid + 1
    return res

To solve this problem, we need to efficiently process multiple queries that delete the K-th occurrence of a specific character in a string. The challenge is to handle these deletions efficiently given the constraints on the string length and the number of queries.

### Approach
1. **Preprocessing**: For each character in the input string, store the positions where it occurs. This allows us to quickly access the positions of each character when processing queries.
2. **Binary Indexed Tree (BIT)**: Use a BIT (also known as a Fenwick Tree) for each character to keep track of active occurrences. This data structure helps efficiently compute prefix sums and update values in logarithmic time.
3. **Global BIT**: Maintain a global BIT to track the active positions in the original string. This helps in efficiently determining the current state of the string after each deletion.
4. **Query Processing**: For each query, determine the K-th active occurrence of the specified character using the character-specific BIT. Update both the character-specific BIT and the global BIT to mark the position as deleted.
5. **Result Construction**: After processing all queries, construct the resulting string by checking which positions are still active using the global BIT.

### Solution Code
```python
from collections import defaultdict

class BIT:
    def __init__(self, size):
        self.size = size
        self.tree = [0] * (self.size + 1)  # 1-based indexing

    def update(self, idx, delta):
        # Converts to 1-based index
        idx += 1
        while idx <= self.size:
            self.tree[idx] += delta
            idx += idx & -idx

    def query(self, idx):
        # Sum from 0 to idx (0-based), convert to 1-based
        res = 0
        idx += 1
        while idx > 0:
            res += self.tree[idx]
            idx -= idx & -idx
        return res

def find_kth(bits, k):
    low = 0
    high = bits.size - 1
    res = -1
    while low <= high:
        mid = (low + high) // 2
        s = bits.query(mid)
        if s >= k:
            res = mid
            high = mid - 1
        else:
            low = mid + 1
    return res

# Read input
import sys

def main():
    data = sys.stdin.read().split()
    ptr = 0
    s = data[ptr]
    ptr += 1
    m = int(data[ptr])
    ptr += 1
    queries = []
    for _ in range(m):
        k = int(data[ptr])
        x = data[ptr + 1]
        queries.append((k, x))
        ptr += 2

    # Preprocess character positions
    pos = defaultdict(list)
    for i, c in enumerate(s):
        pos[c].append(i)

    # Initialize BITs
    global_bit = BIT(len(s))
    for i in range(len(s)):
        global_bit.update(i, 1)

    bits_dict = dict()
    for c in pos:
        lst = pos[c]
        bit = BIT(len(lst))
        for i in range(len(lst)):
            bit.update(i, 1)
        bits_dict[c] = bit

    # Process queries
    for k, x in queries:
        if x not in pos:
            continue
        bits = bits_dict[x]
        j = find_kth(bits, k)
        original_pos = pos[x][j]
        # Update bits and global_bit
        bits.update(j, -1)
        global_bit.update(original_pos, -1)

    # Build the result
    result = []
    for i in range(len(s)):
        # Check if the i-th position is active
        cnt = global_bit.query(i) - (global_bit.query(i - 1) if i > 0 else 0)
        if cnt == 1:
            result.append(s[i])
    print(''.join(result))

if __name__ == "__main__":
    main()
```

3. **Preprocessing**: We store the positions of each character in a dictionary to quickly access them during queries.
4. **BIT Initialization**: A global BIT tracks active positions in the original string, and each character has its own BIT to track active occurrences.
5. **Query Processing**: For each query, we determine the K-th active occurrence using the character's BIT, update the BITs, and mark the position as deleted.
6. **Result Construction**: After processing all queries, we construct the resulting string by checking the active positions using the global BIT.

This approach ensures efficient handling of deletions and maintains the required operations within acceptable time complexity bounds.
