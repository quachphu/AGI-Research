To solve this problem, we need to determine the color in an undirected graph that has the most diverse neighboring colors. The neighboring color diversity for a color \( k \) is defined as the number of distinct colors that are adjacent to any vertex of color \( k \). If there are multiple colors with the same maximum diversity, we choose the smallest color.

### Approach
1. **Input Reading**: Read the number of vertices and edges, followed by the color of each vertex and the edges connecting the vertices.
2. **Graph Construction**: Use an adjacency list to represent the graph.
3. **Neighboring Colors Tracking**: For each edge, track the neighboring colors for each vertex's color using a dictionary of sets. This ensures that each color is only counted once even if there are multiple edges between the same pair of colors.
4. **Determine Maximum Diversity**: Iterate through each color present in the graph, compute the size of its neighboring color set, and keep track of the color with the maximum diversity. If there are ties, the smallest color is chosen.

### Solution Code
```python
import sys
from collections import defaultdict

def main():
    n, m = map(int, sys.stdin.readline().split())
    c = list(map(int, sys.stdin.readline().split()))
    present_colors = set(c)
    
    Q = defaultdict(set)
    
    for _ in range(m):
        u, v = map(int, sys.stdin.readline().split())
        cu = c[u-1]
        cv = c[v-1]
        if cu != cv:
            Q[cu].add(cv)
            Q[cv].add(cu)
    
    sorted_colors = sorted(present_colors)
    max_size = -1
    best_color = None
    
    for color in sorted_colors:
        current_size = len(Q.get(color, set()))
        if current_size > max_size:
            max_size = current_size
            best_color = color
    
    print(best_color)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read using standard input for efficiency, especially given the constraints.
2. **Tracking Neighboring Colors**: For each edge, if the vertices connected by the edge have different colors, each color is added to the other's set of neighboring colors. This ensures we only count distinct colors.
3. **Finding the Maximum Diversity**: By iterating through the sorted list of present colors, we ensure that in case of ties, the smallest color is selected. The use of sets guarantees that each neighboring color is counted only once.

This approach efficiently handles the constraints and ensures the solution is optimal in both time and space complexity.
